# TUFT · R27 —— RW ↔ Zerilli 等谱性：Chandrasekhar / SUSY(Darboux) 变换证明

> 一句话：R26 结构诊断出「RW 势给 3 项递推、Zerilli 势给 5 项递推」，故 Zerilli 的直接连分式需 Nollert 广义连分式。R27 不走数值路线，而是**证明 RW 与 Zerilli 势为 SUSY(Darboux) 伙伴**——
> `V_RW = W̃² + dW̃/dr* + C`，`V_Z = W̃² − dW̃/dr* + C`（对 l=2..6 **精确成立**），
> 超势闭式 `W̃ = W + s`，`s = −λ(λ+1)/3`、`C = −[λ(λ+1)/3]²`（λ=(l−1)(l+2)/2）。
> 于是 `H_RW = AA†+C`、`H_Z = A†A+C`（A=d/dr*+W̃），**两谱严格相同** ⇒ R25 的 RW 特征值级谱即为 Zerilli 谱，**R26 的 5 项递推缺口以更强的解析路线闭合**。

评级 **O / L2**。红线：数学自洽 ≠ 实验证实；仅非旋转 Schwarzschild；等谱是解析事实，不含新物理预言。

## 零、动机（承接 R26）

R26 用同一 Leaver ansatz 分别约化 RW 与 Zerilli：
- RW 势 → 递推偏移 {−1,0,1} ⇒ **3 项**（Leaver 标准，直接连分式）；
- Zerilli 势 → 递推偏移 {−3,−2,−1,0,1} ⇒ **5 项**（需 Nollert 广义/矩阵连分式）。

R27 选择**更本质**的路线：不实现 5 项广义连分式，而是证明**两势等谱**（这正是引力扰动奇偶宇称等谱性的根）。

## 一、方法

几何单位 G=c=M=1；tortoise 坐标 r*，`d/dr* = f d/dr`，`f = 1−2M/r`。

1. 由 `V_RW − V_Z = 2 dW̃/dr*` 得 `dW/dr = (V_RW−V_Z)/(2f)`，积分得 W（sympy `integrate`）。
2. 平移 `W̃ = W + s` 使 `(V_RW+V_Z)/2 − W̃² = C` 为**常数**：由 `d/dr[(V_RW+V_Z)/2 − W²] = 2s dW/dr` 解出 s。
3. 记 `A = d/dr* + W̃`、`A† = −d/dr* + W̃`，则

$$H_{RW} = -\tfrac{d^2}{dr_*^2} + V_{RW} = AA^\dagger + C,\qquad H_Z = -\tfrac{d^2}{dr_*^2} + V_Z = A^\dagger A + C$$

4. 于是 `H_Z A† = A†H_RW`：若 RW 方程 `H_RW X = ω²X`，则 `Z = A†X` 满足 `H_Z Z = ω²Z`。
   W̃ 在视界与无穷**有界**（W→0，W̃→s），故 `A†` 保持「视界入波 / 无穷出波」的 QNM 边界条件 ⇒ 等谱。
