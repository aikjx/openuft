# 黑洞信息悖论

> 黑洞蒸发是否违反量子力学的幺正性？信息落入黑洞后是否永久丢失？

## 问题定义

1976 年霍金提出：黑洞通过热辐射蒸发，辐射是纯热的（与物质无关），导致信息丢失——违反量子力学幺正性。

**核心矛盾**：
- 广义相对论：事件视界使信息无法逃逸
- 量子力学：纯态演化为纯态，信息守恒
- 霍金辐射：热辐射（混合态），信息丢失

**解决方案候选**：
1. **信息守恒**：辐射非完全热，含信息关联
2. **残余物**：蒸发终结留下含信息的残余
3. **防火墙**：视界处高能量壁销毁信息
4. **全息原理**：信息编码在视界上
5. **ER=EPR**：纠缠=虫洞，信息通过虫洞逃逸
6. **岛公式**：Page 曲线恢复幺正性
