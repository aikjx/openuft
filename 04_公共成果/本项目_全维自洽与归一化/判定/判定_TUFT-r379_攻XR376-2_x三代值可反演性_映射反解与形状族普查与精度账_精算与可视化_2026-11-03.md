## 二、算术地基：p_x(1/2) ≡ x/sinh(x)（P01）

来料只给密度 p_x(z) = 2x e^{-2xz}/(1-e^{-2x})，「x 由质量反求」落在 z=1/2 的中点。代入：

- p_x(1/2) = 2x e^{-x}/(1-e^{-2x})；
- sinh(x) = (e^x − e^{-x})/2 ⇒ 2x/(e^x − e^{-x}) = **x/sinh(x)**；

这是**恒等而非近似**。三路对拍（不做化简的数值直算 / 只用 sinh 的闭式 / 保留 1/(1-e^{-2x}) 因子的指数式）在三点上残差 ≤ **1.25e-61**（工作精度 dps=60，见 G05）。第三路与第一路同分支、第二路独立 ⇒ 残差是机器零而不是巧合。

## 四、z\* 不是自由旋钮（P06 / C2）

若 z\* 可自由调节，「p_x(z\*) 拟合三代质量」就是 2 参数 2 约束的恒真命题。实测 1e-6 网格全局最优落在 **z\* = 0.499999**（目标函数 2.148e-05），固定 1/2 时 3.939e-05（只差 1.8 倍）；但挪动 1e-3 立刻放大 **455.8 倍**、挪 1e-2 放大 **4549 倍**。

⇒ z\* 在 5e-5 内被钉死在**区间几何中点**，不是拟合出来的自由参数。

## 五、精度账：为什么 BOUNDARY（P10 / P08 / C8）

传导式：x 的有效位数 = −log10(δx/x)，而 δx/x = (δm/m)/|dln m/dln x|，其中

> dln m/dln x = 1 − x·coth(x) = 1 − 2x/(1−e^{-2x})，

在 x_tau 处 = **6.26**（该映射的敏感度只有同量级幂律的一半，故同样的 1e-5 质量精度只能撑约 5 位）。

- 位数账：报 **9.0** 位 vs 支撑 **4.967** 位 ⇒ 缺 **4.033** 位；要 9 位需 m_tau 相对精度 6.26e-09（1.11e-05 MeV），实有 1.20e-01 MeV ⇒ 差 **1.08e+04 倍**。
- **反解可逆性仍成立**（P08）：把 CM 映射反过来求 x(m) 能回到同一组数 —— x_e 机器零（C 由它定，真正的检验位是 mu/tau）、x_mu 回到 5.51e-10、x_tau 回到 6.29e-06（绝对差 4.57e-05，与 m_tau 误差经 sens=6.26 传播一致）。
- **判据不是恒 FAIL**（C8）：同一判据在「报 4 位」时放行（4 ≤ 4.97）、「报 9 位」时拦截 ⇒ 它区分的是「精度声明 vs 支撑精度」，不是「有无映射」。

⇒ **结论不是「映射错」，而是「x_tau 的末 4.0 位不可能来自 PDG 的 m_tau」**：要么来自更高精度的 m_tau 口径，要么是从别处搬来的。本卷不代选（P09 把 m_tau = 1776.929997 MeV 与 PDG 的 +0.0700 MeV / 0.58σ 差摆出来，两种解释并列）。

## 六、Parseval 恒等式与尾段律（P12 / P13 / C7）

- **正确式**：Σa_n² = x·coth(x) − 1（**不是 2 倍**），N=400 与闭式一致到 **7.743e-06**。
- 推导：a_n = √2∫cos(nπz)p dz = c_n/√2，Parseval 给 ∫p² = c_0² + ½Σc_n²，而 ∫₀¹p²dz = x·coth(x) ⇒ Σc_n² = 2(x coth x − 1) ⇒ Σa_n² = x coth x − 1。
- **尾段律**：Parseval 截断残差 = **−0.99 × 32x⁴/(3π⁴N³)**（ratio 随 N 单调趋 −1；三点×三 N 共 9 组，全部落在 (−0.9936, −0.9994)）⇒ 残差 **100% 是截断、0% 是系数错**。

## 十、自伤登记（诚实留痕）

1. **Parseval 写成 2 倍**：上一轮口头结论把 Σa_n² = x coth x − 1 记成 2(x coth x − 1)；本轮第一版原型照抄，残差读成 −15.218（整量级偏差），被 C7 的反照抓住 ⇒ 已更正为 1 倍，并把该错写永久留作牙齿。
2. **「唯一命中」的措辞过强**：首版把 `x/sinh(x)` 报成普查唯一头名；实算是 `x·e^{-x}` 头名、`x/sinh(x)` 次名，两者差 1.3% ⇒ 已改成「命中 `x·e^{-x}` 族 + 近简并不可分辨」，并单列 P05 说明机制（e^{-2x}/(1-e^{-2x})）。
3. **P02 初版判 PASS 未带精度条件**：单看 mu/tau 偏差（2.39σ / 0.58σ）会读成「漂亮命中」；补 P07（p=0.0484 在 5% 边缘）与 P10（位数缺 4.03 位）后 verdict 才落到 BOUNDARY。
4. **C 组首版按 7 个实参写**（崩在 TypeError）⇒ G02 因此立账。

**方法论沉淀（可复用）**：
- **「形状族普查必须报第二名与近简并」**：只报头名的 max rel 会把「族内不可分辨」包装成「唯一解」。正确写法是同时报 best / second / third + 一个「形状层差 vs 模型残差」的比值（本卷 4.94e-07 / 3.94e-05 = 1.3%）。
- **「反解的可信度由正向敏感度定价」**：反解 x(m) 的位数不是由算法精度决定，而是由 dln m/dln x 决定。本卷 sens=6.26 ⇒ 同样的质量精度只能撑 1/6.26 的位数。任何「反解出 N 位」的声明都必须先算这条敏感度。
- **「锚点自证不算检验」**：以 m_e 锚定 C 后 e 点必然精确（C5 的 3/3 恒零），真正的检验位只有另外两点，且必须给出跨点残差的下界。
