# 下一阶段 V135 的可执行研究入口

路线 A：选择满足 Spin 的内部空间，从 **完整的高维作用量** 导出不同内部场的稳定背景；若另引入 Spin^c 扭转必须展示其全球丛与规范荷归一化。

路线 B：给出 11D 独立变量、基本尺度及可微分变分原则，构造包含场通量的解。检查 \(R_{MN}\)、Bianchi 恒等式、能动张量守恒、负范数模及 radion 有效势 Hessian。

路线 C：由内部 Dirac 算符的核计算真实的四维费米子手征零模；标出表示、超荷、反常与三代结构。禁止把模式数设为 3 后再声明独立推出三代。

路线 D：从已生成的四维有效规范场的动能项规范化中计算 \(g_1,g_2,g_3\)，进行实测阈值匹配；不能按三个实测耦合各设一个独立半径后宣布预测成功。

路线 E：至少给出一个在不参与参数拟合的实验数据上的定量预测，包括误差、对照模型、仪器系统误差、选择偏差与失败阈值。

**核验门槛**：所有 P0 完成后才把模型叫作候选统一理论；P1 也通过且有新实验支持后才能讨论新物理证据；不能以算术断言数代替实验验证。
