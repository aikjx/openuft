## 三、当前判定摘要

- **成立（属重述）**：`A/4l_P²`、`T_H`、四个黑洞热力学定律、GSL 相消、`Q=T₃+Y` 与五类反常消除、
  A/Z 混合正交性、霍金温度的合法几何形式 `T_H = ħc√K(r_h)/(4πk_B)`（与标准式代数恒等，偏差 2e-16）。
- **不成立（FAIL）**：挠率多分量"相加"（类型错误）；"3:1 维度比 → sin²θ_W"（差 8.12%）；
  "M_GUT 汇聚"（10^16 GeV 处 21.0% 分散）；"四力归一"（结构群为直积）；统一作用量无特有项；
  `T_H=ħc/(8πGM)` 与 `M=(1/c²)∫αKTΩ` 量纲非法；"元胞 1 比特"与 `A/4l_P²` 差因子 4；
  "半整数环绕数"（Gauss 环绕数实算为整数）；真空挠率剖面与自身作用量矛盾；信息悖论消解不可证伪。

- **判据门禁（自动，见 [tuft_判据门禁](13_论文与成果/论文正文/tuft_判据门禁.md)）**：
  量纲门禁 **7/12 通过、5 条量纲非法** —— 恰是前几轮人工确认的那一批：
  `αKTΩ/c²`（实算 `L^-5·T²`）、`ρ=αKTΩ`（`L^-3`）、`T_H=ħc/(8πGM)`（`M`）、
  `F_T=1+⟨T⟩²/K_sat²`（`L²`）、慢滚 `ε` 的 κ 单位约定（`M·L·T^-2`）；
  可观测锚门禁标出「色挠率 SU(3)」无观测锚（不可判决）。

- **跨册结构性病根（自动统计，见 [跨册缺陷族](13_论文与成果/论文正文/tuft_跨册缺陷族.md)）**：
  「量纲非法」复现册数最多（8 册）——`αKTΩ/c²`、`F_T`、`T_H` 属同一类错误；
  「无构造/仅命名」「挠率无动力学」「代码与文字不符」跨 4–6 册复发 ⇒ 缺陷不是个别笔误，而是少数结构性病根。

- **第 11 册（暴胀/CMB）新增 FAIL 35**：势能 `V=V0Ω(1−Ω)` 实为凹函数且 `Ω∉[0,1]` 时**无下界**（`H²<0`）；
  滚动方向反（`Ω` 朝 0 滚，实测越界到 `−0.0002`）；`N≈60`（实为 `0.2247κ`，`κ=1 → 0.22`）与
  `n_s≈0.965`（需 `κ=474.4`，与 `N=60` 所需的 `267.1` **互斥**）不能同时成立；
  `F_T` 量纲非法且数值 `=1+1.06e-103`；`Π_T` 手性来源与电弱破缺能标**差 12 个数量级**；
  原文代码 `SyntaxError` + `math domain error`，四条"预期输出"全错。

- **方案预研（附册）**：挠率探测实验设计——数值层 FAIL（`S_tot` 偏低 12 倍）、可行性 FAIL（EC 天然挠率与目标差 `10²⁸`）；判定与修复见 [挠率探测方案_判定与修复](11_证伪与反例/挠率探测方案_判定与修复.md)。
- **双分量干涉屏蔽门禁（2026-09-30）**：候选函数的代数根成立，但旧 `r` 分支几乎不被屏蔽；归一化相反流应为 `(1-s²)/(1+s²)`；EDM 公式量纲与分母化简均错误，按 `γ=λ_C²` 修复后仍超 ACME `4.06e15` 倍；保持现有 EC-TUFT 作用量不变时也没有可确定连续振幅比的第二传播模。见 [全维求导审计](04_理论推导/TUFT_双分量干涉屏蔽因子_g-2与EDM联合约束_审计.md)，实跑 `PASS=8/FAIL=7/BOUNDARY=2/INFO=3`；OPEN5/OPEN6 否决态维持。

- **卷十七 RG 全局相图（2026-09-30）**：结构 + 数值审计 `PASS=17/FAIL=9/BOUNDARY=4/OPEN=1/INFO=8`（39 项，53.5 s）。**结构层**：草稿一圈 β 除 `β_λ` 外齐次 2 次，而 `β_λ = B1 λ g0 + B2 g0² + B3 g3² + B4 g1` 含一次项 ⇒ ①草稿 §3「所有 β 均为二次」被其自身 §4 推翻；②纯二次模型下非高斯不动点必然成过原点**射线族**、临界指数随射线位置线性缩放 ⇒ 不可唯一；③高斯不动点雅可比仅含一个非零元（幂零）⇒ 本征值全 0 ⇒ **非双曲**，草稿「FP-G 本征值全正」错误。**决定性判定**：以草稿自身系数（`A1,A2,A3=0.8,0.4,0.2`）代入，非高斯不动点存在性判据 `A2² ≥ 4 A1 A3` 给出 `−0.48 < 0` ⇒ **FP-AS 不存在**；唯一非退化不动点集是沿 `λ` 轴的**固定线** `{(0,λ,0,0,0,0)}`。补入正则线性项（`g0:+2, λ:−4`，其余 0）后得 4 个孤立非高斯不动点，但**全部落在挠率关闭面 `{g3=g4=0}` 上** ⇒ 草稿「FP-AS 携带非零挠率、普朗克尺度天然携带挠率」不成立；最小自由参数不动点 `n_rel=1, dim_crit=4`。**其他**：草稿 §5 能标方向整体反向（μ 增大应指向紫外）；「临界指数 → CMB 非高斯谱指数」无映射方程（判据 F 无可算预言）；草稿附录代码**完全未实现** §7 的雅可比/临界指数计算且 Newton 在奇异点静默 `break`。**可保留稳健成果**：三个不变子流形、`R²` 与 `Λ` 的诱导生成（`{g1=0}`、`{λ=0}` 均非不变）、判据 `A2² ≥ 4 A1 A3`、高斯点一圈非双曲性、`g4` 方向恒边际、以及方法学结论「RG 不动点搜索必须用相对容差/最小范数截断」（绝对容差在 4 个正则边际方向上产生**四维伪不动点集合**，本审计首轮即被误导出 1200+ 个伪不动点）。蒙特卡洛（系数 i.i.d.
