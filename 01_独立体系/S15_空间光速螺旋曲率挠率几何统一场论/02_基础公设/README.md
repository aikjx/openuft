# 02 基础公设

本体系冻结 4 条公设（S15-A1 ~ S15-A4），详见 [postulates.md](postulates.md)。

- A1 空间内禀光速螺旋 v≡c
- A2 曲率-挠率几何（κ=ρ/(ρ²+b²)、τ=b/(ρ²+b²)、α=κ/τ=ρ/b）
- A3 尺度变换不变性（κ'=κ/k、τ'=τ/k、α'=α）
- A4 万物几何化（所有常数=f(κ,τ,c)）

诚实边界：A4 实为「以 CODATA 常数为锚的几何重参数化」，其循环自证性质见 [../10_误差与不确定性/循环自证与版本分歧.md](../10_误差与不确定性/循环自证与版本分歧.md)；α=κ/τ 是螺旋参数定义而非独立拓扑推导（见 claims S15-C0004）。
