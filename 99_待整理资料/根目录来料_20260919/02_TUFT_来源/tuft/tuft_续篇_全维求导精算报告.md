## 二、逐节精算结果

### §1 闭环螺旋拓扑与自旋 1/2

- **[PASS] S1.1** 符号证明 `N(2π) = −N(0)`：sympy 给出 `N(2π)+N(0) = [0,0,0]`（零矢量，符号精确）。
- **[PASS] S1.1** 符号证明 `N(4π) = +N(0)`：`N(4π)−N(0) = [0,0,0]`。
- **[PASS] S1.1** 推论 `ψ(θ+2π)=−ψ, ψ(θ+4π)=+ψ`：数值参照 `frame_closure(1)`，`‖N(2π)+N(0)‖=2.7e-16`、`‖N(4π)−N(0)‖=5.5e-16`。
- **[BOUNDARY] S1.2** 术语审查 `Lk = Tw + Wr ∈ ½ℤ`：原稿称"拓扑环绕数 W∈ℤ+½"。严格地，S¹ 的 winding number ∈ ℤ（π₁(S¹)=ℤ）；半整数只出现在**自链接数 Lk**（Călugăreanu–White，可定向带 Tw=n/2，n 奇 ⇒ Möbius 型）。**属性判断正确，术语误用**（应称 Lk）。
- **[PASS] S1.3** 相位关系 `Δφ = ∮ω dτ` 量纲自洽：[ω]=T⁻¹，[τ]=T ⇒ [Δφ]=1（无量纲）。

### §2 自旋角动量与 SU(2) 代数

- **[PASS] S2.1** 符号验证 `[S_i,S_j] = iℏε_ijk S_k`（S=ℏσ/2）：sympy 全 9 组对易残差 0（Pauli 代数符号恒等）。
- **[PASS] S2.2** 符号验证 `S² = s(s+1)ℏ² = (3/4)ℏ²·I`：`S² = 3ℏ²/4 · I`。
- **[BOUNDARY] S2.3** 记号风险：若把 `S = (ℏ/2)·(T̂ 的单位矢量)` 按**矢量**字面读，则模方 `ℏ²/4 ≠ 3ℏ²/4`（差 3 倍，不自洽）。S 必须是**算符矢量** `(Sx,Sy,Sz)=(ℏ/2)(σx,σy,σz)`，`T̂` 只承担 `S_z` 的量化轴。
- **[INFO] S2.4** SU(2) 来源：`S=(ℏ/2)σ` 满足 su(2) 是 1/2-旋量表示的普遍事实；TUFT 目前**赋以**该表示，挠率手性只提供量化轴，不生成表示论。

### §3 自旋-统计定理

- **[PASS] S3.1** 交换前 `Lk≈0`：Gauss 双链积分 `Lk_before = −0.0000`。
- **[PASS] S3.1** 交换后构成 Hopf 链 `abs(Lk)≈1`：`Lk_after = −1.0000`。
- **[PASS] S3.1** 交换使 `ΔLk = ±1`：`ΔLk = −1.0000`。
- **[PASS] S3.2** 费米子交换相位 `exp(iπΔLk) = −1`：`phase = −1.0000−0.0000j`（反对称）。
- **[PASS] S3.2** 玻色子交换相位 `= +1`（与链数无关）。
- **[INFO] S3.3** 模型循环性："费米子世界线设为 Möbius 型 W=½"是**输入假设**，由此得 `−1` 再"证明"反对称——框架内自洽的表示，非对标准自旋-统计定理的独立证明。
- **[PASS] S3.4** 泡利不相容：`Ψ(x1,x2)=−Ψ(x2,x1)`；令 x1=x2 ⇒ Ψ=0；等价于 Slater 行列式两列相同 =0（已知结论）。

### §4 手性与弱相互作用（类型审查）

- **[PASS] S4.1** `γ₅` 的数学身份：shape=(4,4)，本征值 {−1,+1}。
- **[FAIL] S4.1** **类型审查**：`γ₅ ∝ T̂/单位矢量` —— γ₅ shape=(4,4) 与 T̂ shape=(3,1) **维数/类型不匹配**，"矩阵 ∝ 矢量"是范畴错误。唯一合法对应是**符号对应**：手性本征值 ±1 ↔ `sign(T)`。
- **[INFO] S4.2** V−A 结构 `(1−γ₅)/2` 只耦合左手：标准模型既定结构；TUFT 侧为几何直觉，未从总作用量变分导出。

### §5 费米子拉氏量与质量内生公式

- **[FAIL] S5.1** 原稿 `m = α·K·T·Ω/c²` 量纲非法：`[m] = L⁻⁴T²`，**非 [M]**（质量量纲）。该式不能作质量表达式。
- **[PASS] S5.2** 修正式 `m = ℏ√(κ²+τ²)/c = ℏΩ_w/c²` 量纲 = M：取 κ=1/λ_C、τ=0 ⇒ `m = 9.109384e-31 kg`（电子 9.109384e-31 kg，比值 1.000000）—— **数值自洽但为反推**（由 λ_C 定义 κ，非由 κ 导出 λ_C）。
- **[INFO] S5.3** 尺度生成机制仍开放（为何 κ=1/λ_C 而非 1/l_P）；属"方向正确、数值待赋"唯象式。

### §7 双时空结交换仿真

- **[PASS] S7.1** 原代码交换相位 `Δφ = 0.000e+00` —— `phi_swap ≡ phi_total`（加法交换律），**不能演示交换变号**；原稿声称 `Δφ≈π` 与代码逻辑矛盾。
- **[FAIL] S7.2** **代码量纲**：`dφ=ω√(αKT)·dr` 量纲 = **T⁻¹**，非无量纲相位（代码混用了 `K·T·Ω` 与 `√(αKT)` 两套 ω）。
- **[INFO] S7.3** 正确交换相位须来自世界线编织（§3 的 Gauss 链），非剖面相加。
