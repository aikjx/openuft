## §3 承重裁定：唯一门从未写进任何一套验收条件（E03）

`r134` 判出「**唯一门 = 前提净下降**，净变化 **+11** 未通过，须消除 **37** 个未导出前提」。本册现场解析五套必要条件清单与一套记分板，构成 **43 行三层对账矩阵**（G03/G04/G06）：

| 层 | 集合 | 行数 | 严格方向门命中 | 弱门词命中 |
|---|---|---:|---:|---:|
| LEDGER | C1–C8（蓝本 v0）/ N1–N18（G1 清单）/ U1–U7（r119）/ R1–R4（终版四根因族） | **37** | **0** | 0 |
| SCOREBOARD | J99 一方程记分板（0/6） | **6** | **0** | **1** |

- **严格方向门词表** = `净减 / 净下降 / 前提减少 / 前提净减少 / 参数净减 / 净变化` ⇒ 清单 **0/37**、记分板 **0/6**。
- **弱门词** = 严格词 + `参数计数 / 不劣于对照` ⇒ 记分板唯一命中 **J#2「参数计数不劣于对照理论」**，但它是**水平比较** `n ≤ n_ctrl`，不是 `Δ < 0` 的方向约束（G17 词表有牙守卫锁死：U7「与全部精密观测相容」不命中弱门）。
- **三动作覆盖矩阵**：G1 清单 **0** / 记分板 1（即 J#2 弱相关）；G2 **0 / 0**；G3 **1 / 0**。

⇒ **精确缺口位置**：门在 `r134` 的**裁定层**被命名，却从未回写进 C/N/U/R 任一验收清单，也未写进 J99 记分板；它只以「事后读数」出现。清单约束的是「不许有什么 / 必须有输出」（LEVEL 型），而决定成败的是「前提净变化必须为负」（GATE 型）。**这不是又一条根因，而是根因族与验收判据之间的错层**。

## §4 充分性首次机器化证明：LEVEL ⊬ GATE（E04）

G1 清单 L53 自陈「本清单为必要条件（考试卷），**非充分条件集**」但从未证明。本册把它变成可穷举命题：

- `LEVEL(n_in, n_out, extra, moduli)` = `n_out ≥ 1 ∧ extra = 0 ∧ moduli = 0 ∧ n_in ≥ 0`（清单语义：有输出、无额外输入、无模量）
- `GATE(n_in, n_out)` = `n_in − n_out < 0`（唯一门：前提净下降）
- 在 `n_in, n_out ∈ [0,6]` 共 **49** 组穷举：**LEVEL 集 42 组**，其中**不满足 GATE 的反例 21 组**、满足 GATE 的 **21 组**——在 LEVEL 集内两者**精确各占一半**，即清单对方向门**零判别力**（不是略微不足）。
- 反例样本 `(1,1), (2,1), (2,2), (3,1), (3,2), (3,3)`；承重反例 **`(2,1)`**：所有静态上限都满足（有 1 个输出、零额外输入、零模量），但 `Δ = +1 ≥ 0` ⇒ 门未过。阳性对照 `gate(1,2) = True`、边界 `gate(1,1) = False`（G09）。

⇒ **「把 37 条必要条件全部修好」在逻辑上不蕴含「通过唯一门」**。这就是「为什么按清单补齐仍不攻破」的机器证明，也是本册相对既有元分析册的实质增量。

## §6 反向代价两难（E06）

从 `0/6` 到非零至少需要 **1 个由结构生成的内生输出**；`attack53` 现场给出每个桥接签名类至少 **+1 新自由常数**（23 类下界）、归一正本 `UFE-1 INPUT 19→26`、`r406` Omega5-S 10 条出口 `ACCEPTED 0`。而 J99 记分板 **#1「单一耦合关系（不需额外质量标度）」** ⇒ `max_extra = 0`。

- `feasible(need, cost, max) := need ≥ 1 ∧ cost ≥ 1 ∧ need·cost ≤ max`（双前提排除「放弃生成」与「零成本生成」两种退化逃逸）
- 真实态 `feasible(1,1,0) = False`（**INFEASIBLE**）；放宽 `max = 1` 阳性对照 `True`（G11）
- 五组反事实定向翻转 `[0,0,1,0,0]`（G12）

⇒ 现有公理配额内「生成动作」与「不许加输入」互斥。这是**反向推导给出的不可达证明**，不是新物理、不宣称统一场论不可能。
