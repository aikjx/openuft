## 2.1 空间曲线的运动学：Frenet–Serret 方程（求导证明）

**设定**。设 $\boldsymbol r(s)$ 是 $\mathbb R^3$ 中一条以弧长 $s$ 参数化的
$\mathcal C^3$ 正则曲线，即 $\big|\boldsymbol r'(s)\big| = 1$。定义：

$$
\boldsymbol t(s) = \boldsymbol r'(s),\qquad
\kappa(s) = \big|\boldsymbol t'(s)\big| \ge 0,\qquad
\boldsymbol n(s) = \frac{\boldsymbol t'(s)}{\kappa(s)}\quad(\kappa>0),
\qquad \boldsymbol b(s) = \boldsymbol t(s)\times\boldsymbol n(s).
$$

**命题 2.1（Frenet–Serret）**。存在函数 $\tau(s)$，使得

$$
\frac{d\boldsymbol t}{ds} = \kappa\,\boldsymbol n,\qquad
\frac{d\boldsymbol n}{ds} = -\kappa\,\boldsymbol t + \tau\,\boldsymbol b,\qquad
\frac{d\boldsymbol b}{ds} = -\tau\,\boldsymbol n.
$$

**证明**。（1）$\boldsymbol t' = \kappa\boldsymbol n$ 是定义。
（2）由 $\boldsymbol t\cdot\boldsymbol n=0$ 求导：$\boldsymbol t'\cdot\boldsymbol n
+ \boldsymbol t\cdot\boldsymbol n' = 0$，即 $\kappa + \boldsymbol t\cdot\boldsymbol n'=0$，
故 $\boldsymbol t\cdot\boldsymbol n' = -\kappa$。
（3）由 $\boldsymbol n\cdot\boldsymbol n=1$ 求导：$\boldsymbol n\cdot\boldsymbol n'=0$，
故 $\boldsymbol n'$ 与 $\boldsymbol n$ 正交，可展开为 $\boldsymbol n' = \alpha\boldsymbol t
+ \tau\boldsymbol b$（$\alpha,\tau$ 待定）。结合 (2) 得 $\alpha=-\kappa$。
（4）由 $\boldsymbol b = \boldsymbol t\times\boldsymbol n$ 求导并使用
$\boldsymbol t\times\boldsymbol t'=0$：
$$
\boldsymbol b' = \boldsymbol t'\times\boldsymbol n + \boldsymbol t\times\boldsymbol n'
= \underbrace{(\kappa\boldsymbol n)\times\boldsymbol n}_{0}
+ \boldsymbol t\times(-\kappa\boldsymbol t + \tau\boldsymbol b)
= \tau\,\boldsymbol t\times\boldsymbol b = -\tau\,\boldsymbol n,
$$
其中 $\boldsymbol t\times\boldsymbol b = -\boldsymbol n$。证毕。

**注释**：$\kappa(s)$ 为曲率（弯曲程度），$\tau(s)$ 为挠率（扭曲程度）。
三个方程可合写为矩阵形式

$$
\frac{d}{ds}\begin{pmatrix}\boldsymbol t\\\boldsymbol n\\\boldsymbol b\end{pmatrix}
= \begin{pmatrix}0&\kappa&0\\-\kappa&0&\tau\\0&-\tau&0\end{pmatrix}
\begin{pmatrix}\boldsymbol t\\\boldsymbol n\\\boldsymbol b\end{pmatrix},
$$

系数矩阵反对称——这是标架等距变换的无穷小生成元，正是下方 Darboux 矢量
的解释入口。

## 2.2 Darboux 矢量：单矢量编码整个标架旋转（求导证明）

**命题 2.2（Darboux 矢量存在且唯一）**。对任意弧长参数化曲线，存在唯一的
矢量 $\boldsymbol\omega_D(s)$，使

$$
\boldsymbol\omega_D\times\boldsymbol t = \boldsymbol t',\quad
\boldsymbol\omega_D\times\boldsymbol n = \boldsymbol n',\quad
\boldsymbol\omega_D\times\boldsymbol b = \boldsymbol b'.
$$

**构造**。令 $\boldsymbol\omega_D = \tau\boldsymbol t + \kappa\boldsymbol b$。
逐条验证（利用 Frenet–Serret）：
$$
\boldsymbol\omega_D\times\boldsymbol t
= (\tau\boldsymbol t + \kappa\boldsymbol b)\times\boldsymbol t
= \kappa\,\boldsymbol b\times\boldsymbol t = -\kappa\,\boldsymbol n \times (\text{重排})
$$
计算需小心符号。$\boldsymbol b\times\boldsymbol t = -(\boldsymbol t\times\boldsymbol b)
= -(-\boldsymbol n) = \boldsymbol n$，故 $\boldsymbol\omega_D\times\boldsymbol t
= \kappa\boldsymbol n = \boldsymbol t'$ ✓。
$$
\boldsymbol\omega_D\times\boldsymbol n = \tau\,\boldsymbol t\times\boldsymbol n
+ \kappa\,\boldsymbol b\times\boldsymbol n = \tau\boldsymbol b - \kappa\boldsymbol t
= \boldsymbol n' $$ ✓（用到 $\boldsymbol b\times\boldsymbol n
= -(\boldsymbol n\times\boldsymbol b) = -\boldsymbol t$）。
$$
\boldsymbol\omega_D\times\boldsymbol b = \tau\,\boldsymbol t\times\boldsymbol b
= -\tau\boldsymbol n = \boldsymbol b'$$ ✓。
**唯一性**：若 $\boldsymbol\omega,\boldsymbol\omega'$ 都满足，则
$(\boldsymbol\omega-\boldsymbol\omega')\times\{\boldsymbol t,\boldsymbol n,\boldsymbol b\}=0$，
即差矢量与标架三基矢均正交，故差为零矢量。证毕。

**物理解读**：$\boldsymbol\omega_D$ 是「沿曲线平移标架 $\{\boldsymbol t,\boldsymbol n,\boldsymbol b\}$」
所需旋转的角速度矢量（单位弧长转角）。它的模
$|\boldsymbol\omega_D| = \sqrt{\tau^2+\kappa^2} =: K$（因 $\boldsymbol t\perp\boldsymbol b$），
方向给出瞬时转动轴。

## 2.3 常曲率常挠率曲线：螺旋的唯一性（解析求解）

**命题 2.3**。设 $\kappa(s)=\kappa>0$、$\tau(s)=\tau$ 均为常数。则曲线是以
$\boldsymbol\omega_D = K\,\hat{\boldsymbol z}$ 为轴的圆螺旋，$K=\sqrt{\kappa^2+\tau^2}$，
且**实验室系 Darboux 矢量恒定**：$d\boldsymbol\omega_D/ds=0$。

**证明（两步）**。（i）**转动轴固定**：由 $\boldsymbol\omega_D = \tau\boldsymbol t+\kappa\boldsymbol b$
与 Frenet–Serret：
$$
\frac{d\boldsymbol\omega_D}{ds}
= \tau\boldsymbol t' + \kappa\boldsymbol b'
= \tau(\kappa\boldsymbol n) + \kappa(-\tau\boldsymbol n) = 0.
$$
故 $\boldsymbol\omega_D$ 是常矢量；取其为实验室 $\hat{\boldsymbol z}$ 方向，$|\boldsymbol\omega_D|=K$。
（ii）**螺旋显式解**：在 $\boldsymbol\omega_D = K\hat{\boldsymbol z}$ 下，解
Frenet–Serret 常系数方程组。设 $\boldsymbol t = (t_x,t_y,t_z)$，由
$\boldsymbol\omega_D\times\boldsymbol t = \boldsymbol t'$ 得分量方程
$$
t_x' = K t_y,\quad t_y' = -K t_x,\quad t_z' = 0,
$$
解为 $t_z = \tau/K$（常数），$(t_x,t_y) = (-\frac{\kappa}{K}\sin Ks,
\frac{\kappa}{K}\cos Ks)$（取合适初始相位）。积分得弧长参数化螺旋：
$$
\boldsymbol r(s) = \left(\frac{\kappa}{K^2}\cos Ks,\;
\frac{\kappa}{K^2}\sin Ks,\; \frac{\tau}{K}\,s\right),\qquad
K^2 = \kappa^2+\tau^2.
$$
**自洽校验**（可机器验证）：$|\boldsymbol r'(s)| = \sqrt{\kappa^2/K^2+\tau^2/K^2}=1$；
$|\boldsymbol r''(s)| = \kappa$；$\tau = \boldsymbol b'\cdot(-\boldsymbol n)$ 回代等于输入 $\tau$。
螺旋半径 $R=\kappa/K^2$、螺距 $P=2\pi\tau/K$、轴方向 $\hat{\boldsymbol z}=\boldsymbol\omega_D/K$。

> **判据 S02-008（§15 引入，本书全卷复用）**：常 $\kappa,\tau$ 螺旋的实验室系
> Darboux 矢量必须恒定，且等于 $K\hat{\boldsymbol z}$。任何「螺旋标架」若在该判据上
> 残差为 O(1)，即非 Frenet 自洽标架。`momentum_darboux.py` 实跑：
> $\max|\boldsymbol\omega_D(s)-\boldsymbol\omega_D(0)| \sim 10^{-16}$（机器零）。

## 2.4 平面曲线极限与「τ≡0」定理（S02-004 的数学基础）

**命题 2.4**。若一条弧长参数化曲线的挠率恒为零（$\tau\equiv0$），则它落在
某个平面内；反之，平面正则曲线（$\kappa>0$）的挠率恒为零。

**证明**。$\boldsymbol b' = -\tau\boldsymbol n$，故 $\tau\equiv0 \Rightarrow
\boldsymbol b'=0 \Rightarrow \boldsymbol b=\text{常矢量}$。于是
$d(\boldsymbol r\cdot\boldsymbol b)/ds = \boldsymbol t\cdot\boldsymbol b = 0$，
即 $\boldsymbol r\cdot\boldsymbol b$ 为常数：曲线落在平面
$\{\boldsymbol x : \boldsymbol x\cdot\boldsymbol b = \text{const}\}$ 内。
反之若曲线在平面内，$\boldsymbol b$ 恒为该平面法向，$\boldsymbol b'=0$，由
Frenet 第三式 $\tau=0$。证毕。

**推论（卷III ch18 引用）**：横波场（如真空电磁平面波）的电场矢量在空间中的
方向曲线若处处有非零曲率，则该曲线必为平面曲线——这一纯几何事实是
§12.5「$\tau\equiv0$」结论与推广不变量 $\langle\kappa\rangle\cdot L = 2\pi$
（全曲率定理 $\oint\kappa\,ds = 2\pi$）的数学依据，见 ch18。

## 2.5 曲率-挠率-频率体系：K 作为几何频率（S02 桥接）

对常 $\kappa,\tau$ 螺旋，$K=\sqrt{\kappa^2+\tau^2}$ 有三维独立身份：

1. **几何**：Darboux 矢量模 $|\boldsymbol\omega_D| = K$（单位弧长转角）；
2. **运动学**：螺旋在轴向上每前进 $\Delta z$ 转过的相角 $\Delta\phi = K\Delta z$
   （因 $z$ 方向相位速率恰为 $K$——见 ch18 的 $\omega/K=c$ 关系）；
3. **频率**：若螺旋以光速 $c$ 展开（$u = ds/dt$ 约定），轴向相位频率
   $\omega = cK$。

这三点是 S02「空间光速螺旋统一力」把曲率-挠率-频率统一进一个 $K$ 的数学核心。
**但必须注意（红线）**：$K$ 的物理可观测性取决于承载它的场/粒子模型；
真空电磁场中「偏振基沿传播方向旋转」被 §15 no-go 定理证否（ch21 全章），
因此 $K$ 作为几何频率的角色在涡旋光方案（ch22，LG₀ₗ 相位拓扑 $l$）中
重新落地——共振条件 $\sqrt{\kappa^2+\tau^2}=k$ 正是本章 $K$ 与载波波数 $k$
的匹配。

## 2.6 测地线与螺旋世界线（通向卷II/IV）

在闵氏时空（ch03 展开）中，类时测地线由 $u^\alpha\nabla_\alpha u^\mu = 0$ 定义。
在「螺旋几何」框架内，常 $\kappa,\tau$ 螺旋不是闵氏测地线（其 4 加速度非零，
$a^\mu = u^\alpha\nabla_\alpha u^\mu$ 正比于 $\kappa$），而是一种**有固有曲率的
类时世界线**。ECSK 引力（ch07）允许自旋-挠率耦合，正是这类世界线的自然宿主：
$$
m\frac{Du^\mu}{Ds} = f^\mu_{\text{geo}},
$$
其中几何力来自场梯度（ch22 §16.7 给出真空涡旋场的 4 力 $f^\mu
= \tfrac12 u_\nu F^{\alpha\sigma}\nabla^\mu F_{\alpha\sigma}$，无需电荷）。
这是卷IV「引力-电磁几何统一」（ch24）的入口。
