二、任务全链路时序（开页面 → 截图 → OCR → 落库）

步骤发起 → 接收动作性能要点
1Java → MySQL/Redis落 rpa_task(待执行) + LPUSH 任务队列队列削峰
2Worker → RedisBRPOP 阻塞领取任务多 Worker 竞争消费，天然扩容
3Worker → ChromiumCDP 复用常驻浏览器，goto + actions浏览器只启动一次，省数秒冷启动
4Chromium → 共享卷截图写 /data/<task>.png三容器同挂一卷
5Worker → OCRPOST /ocr 只传文件路径，不传图片字节零序列化，IPC 开销 <10ms
6Worker → MySQL/Redisstatus=2 + 识别文本回写 + 结果队列通知单实例 OCR 串行，高并发扩副本
