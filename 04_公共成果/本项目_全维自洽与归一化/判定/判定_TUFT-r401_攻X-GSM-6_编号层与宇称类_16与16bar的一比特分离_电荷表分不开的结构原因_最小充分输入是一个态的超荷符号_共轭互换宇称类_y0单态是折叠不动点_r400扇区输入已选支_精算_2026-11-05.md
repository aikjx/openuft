## 四、主册逐条

### A1 两个宇称类（地皮）

- 判据：32 个旋量权按「负号个数」的奇偶分成两类，重数须等于二项式 `C(5,k)`；两类不相交、并集为全部 32 个 `(±1/2)^5`；奇类权集须等于 −偶类权集；两类字典序最高权须不同。
- 读数：偶类重数 `{0:1, 2:10, 4:5}`、奇类 `{1:5, 3:10, 5:1}`；不相交 True；并集 32/32；奇类 == −偶类 True；最高权 `(1/2,1/2,1/2,1/2,1/2)` vs `(1/2,1/2,1/2,1/2,-1/2)`。
- 为什么这样判：重数的期望值来自组合计数（独立路径），实测来自 MINUS 块 Σ 的虚部对角（另一条独立路径）；最高权不同 ⇒ 两类是 so(10) 的不等价不可约表示，这是「16 与 16bar 不同」的权层判定。
- 命名纪律：谁叫 16 谁叫 16bar 依赖 Γ 编号，是**命名约定**。本卷只断言「两类不等价、SM 一代住偶类（手征 +1 块）」。

### A2 折叠机制（免疫的结构原因）

- 判据：对线性 χ（A / T3L / K3 的任意有理组合），须有 multiset(χ|奇类) = −multiset(χ|偶类)；对 χ = Q 再须两类都折出 SM 电荷表。
- 读数：Q 奇==−偶 True；y 奇==−偶 True；Q|偶 == SM_Q True；Q|奇 == SM_Q True。
- 为什么这样判：这条一半是结构（A1 + 线性），一半是实测 —— `Q|奇 == SM_Q` 是从 MINUS 块矩阵对角折出来的，不是从 −偶类反推。免疫的机制到此说清：**Q 折叠对共轭免疫，等价于 SM_Q 自共轭**。这不是 Q 的性质，是那张表的性质。

### A3 主判定（Q 分不开 / y 分得开）

- 判据：Q 表自共轭 ⇒ 分不开；y 表非自共轭 ⇒ 分得开（偶类 == SM 超荷表、奇类 == 其逐项取反）。
- 读数：Q 表自共轭 True；y 表自共轭 False；y|偶 == SM_Y True；y|奇 == SM_Y False；y|奇 == −SM_Y True；四张表全文入读数（供图与判定册取用）。
- 为什么这样判：同一套折叠、同一个线性机制，差别**只在表自己的对称性**。SM_Q 的 7 个值在取反下配对闭合，SM_Y 的 6 个值不闭合（取反后只剩 0 一个公共值）。SM_Y 是外部物理输入（16 项），偶类的 y 表与它相等 ⇒ **SM 一代住偶类**。

### A4 一比特 · 表述一（e 态）

- 判据：`(T3L, y) = (−1/2, −1/2)` 的态须在偶类恰 1 个、奇类 0 个。
- 读数：偶类 1 态，权 `(1/2,1/2,1/2,-1/2,-1/2)`，`#(−1/2)=2`；奇类 0 态。
- 为什么这样判：机制是双态 `K3 = 0` ⇒ `(T3L, y)` 定 `A` ⇒ 定整个权 ⇒ 定宇称类。期望的「奇类 0 态」从外部表推（−SM_Y 不含 −1/2），实测从矩阵对角折 —— 两路独立。

### A5 一比特 · 表述二（ν^c 的编号）

- 判据：`y = 0` 的单态须在偶类 B−L = +1、奇类 = −1，且两态权互为取反。
- 读数：偶类 1 态 B−L = 1（权 `(-1/2,-1/2,-1/2,-1/2,1/2)`，`#(−1/2)=4`）；奇类 1 态 B−L = −1（权 `(1/2,1/2,1/2,1/2,-1/2)`，`#(−1/2)=1`）。
- 为什么这样判：SM 里 ν^c 的 B−L = +1（与 e^c 同占 `{1:2}` 那两格，r400 A2 读数）。共轭把这一格送到 −1。**「哪个 y = 0 单态叫 ν^c」就是那层编号**，它是一比特。

### A6 一比特 · 表述三（扇区分辨电荷表）

- 判据：双扇区（`K3 = 0` 的 8 态）的 Q 多重集须两类互为取反、且偶类那个子表非自共轭。
- 读数：偶类 `{-1:1, -1/3:3, 0:1, 2/3:3}`；奇类 `{-2/3:3, 0:1, 1/3:3, 1:1}`；互为取反 True；偶类表自共轭 False；扇区数 (8, 8)；`K3 = 0` 取反不变 True。
- 为什么这样判：总表对称而**扇区表**不对称 —— 把同一张电荷表按扇区切开，比特就露出来了。这正是 r400 A5 用的输入，所以 r400 的「λ_A 唯一」其实是在**已经选支**的输入下给的（A8 显式化）。

### A7 下界（0 比特不够）与 4 解分类

- 判据：`|y|` 与 `|Q|` 幅值表须两类全同；全网格 4 解须按 λ_A 符号分成两支（λ_A < 0 给 SM 表、λ_A > 0 给 −SM 表），且不得有无法分类的项。
- 读数：`|y|` 两类同 True（`{0:1, 1/6:6, 1/3:3, 1/2:2, 2/3:3, 1:1}`）；`|Q|` 同 True；4 解 = `{±1/3}×{±1/2}`；分类 `-1/3` 两支 SM、`1/3` 两支 NEG；按 λ_A 分支正确 True。
- 为什么这样判：把「最小」钉死在两头 —— 充分由 A4/A5/A6 给，必要由本条给（幅值运算与取反对易，任何只看幅值的判据对共轭盲）。4 解 = Z2(共轭) × Z2(编码约定)，只有前者翻表。

### A8 r400 张力显式化（输入已选支）

- 判据：用 SM 扇区表解得 λ_A = −1/3 唯一；换共轭扇区表解得 +1/3 唯一；SM 扇区表自共轭须为 False。
- 读数：`['-1/3']` / `['1/3']` / False。
- 为什么这样判：这是对 r400 的**诚实记账**，不是勘误。r400 读数全对，但「λ_A 唯一」这句话的适用范围要写明 —— 输入非自共轭，已把共轭支排除。r400 文件不动，读数不改。

### A9 对称稳定性（判别力双向）

- 判据：`ε4↔ε5`（r400 A8 的编号约定）须在偶类内闭环、不换类、不翻 ν^c 的 B−L；共轭须换类、翻 B−L。
- 读数：闭环 True；不换类 True；保 B−L True；共轭翻 B−L True（1 → −1）。
- 为什么这样判：判据要测它想测的东西 —— 比特必须**对编号约定稳定**、**对共轭敏感**。缺任一头这个比特都不成立。

### A10 共轭完成自洽（边界的另一半）

- 判据：在奇类上用 −Y 折叠，y 表须 == SM 超荷表、Q 表须 == SM 电荷表。
- 读数：`−y|奇 == SM_Y` True；`(T3L − y)|奇 == SM_Q` True。
- 为什么这样判：A7 说 0 比特分不开（不存在更小输入），本条说分不开的**另一个世界真的存在**。两个自洽完成并存 ⇒ 「SM 一代住偶类」不是电荷层的胜利，是一比特物理输入的胜利。

## 八、诚实边界

1. 「一比特」本身是**物理输入**（ν^c 的 B−L = +1，或等价的 e 态 `(T3L,y) = (−1/2,−1/2)`）。本卷证明的是它**必要且充分**，不是「没有输入」。
2. 全部在**权层**：不构造 16 ↔ 16bar 的矩阵层共轭算子，不在矩阵层验证表示不等价（不等价由最高权判定）。谁叫 16 谁叫 16bar 是命名约定。
3. r400 A5 的唯一性重读：其扇区输入已选支。r400 文件不动、读数不改。
4. ν^c / ν 是折叠的不动点（两类各 1 态，`(T3L,y)` 都是 (0,0)）⇒ 分开这一对**必须**用 B−L，也就是命名。这是「编号层」这个名字的精确含义。
5. 「分离」不产生新预言：给出的是**类的判定**，独有预言 0、不占度（度数链维持 36，r264 止）。
6. 不含质量谱 / Yukawa / 混合角，不构造 `16×16×126bar` 型不变量 —— 分开了类不等于定下类上的动力学。

## 十一、判据谱系（本卷用到与新增的刀）

- **表自共轭刀（新）**：一个多重集判据 χ 能否分辨共轭，等价于 χ 在单个类上的多重集是否自共轭。Q 自共轭 ⇒ 盲；y 不自共轭 ⇒ 灵；`|y|` 天然自共轭 ⇒ 恒盲。
- **两类互补账（新）**：32 = 16 + 16，重数是二项式系数；两类最高权不同 ⇒ 不等价。这是「不等价」在权层的可算判定。
- **一比特最小性双端（新）**：充分由三个等效表述给，必要由幅值表同表给。只有一端不算「最小」。
- **折叠不动点刀（新）**：`f(x) = f(−x)` 的点对该判据无判别力。ν^c / ν 就是这种点，所以必须换判据（B−L）而不能加大统计量。
- **输入选支刀（新，承 r400 A5 张力）**：判据的输入若本身非对称，结论就已隐含选支 —— 报告必须写明适用范围。
- 承前：期望值反抄（G11 用 r400 读数）、两路机拼（G14 / G12）、控制组两两不同读数（G03）、`final_of` 守卫敏感（G13）、AST 层防写死（G01）。

## 十五、结论

1. 16 与 16bar 的差别在权层是**宇称类**（`#(−1/2)` 偶 / 奇），两类不相交、并满 32、互为取反、最高权不同 ⇒ 不等价。
2. 电荷判据分不开它们，原因是**SM 电荷表自共轭**（不是 Q 的性质，是表的性质）；超荷表分得开，因为 SM 超荷表不自共轭。
3. 分开的**最小充分输入是一比特**：任取一个非零超荷态的 (T3L, y)（如 e 态），或 y = 0 单态的 B−L，或扇区分辨的电荷表 —— 三者等效。0 比特（幅值层）不够。
4. r400 A5 的「λ_A 唯一」在「给定 SM 扇区指认」下成立；把输入换成共轭扇区表，唯一解翻到 +1/3。这不是勘误，是适用范围。
5. 本卷不产生新物理：它把「一比特约定」说成「一比特物理输入」，并且只说到这里。
