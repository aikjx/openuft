# 宇宙大统一方程 求导证明

## 原公式

$\vec{F} = \dfrac{d\vec{P}}{dt} = \vec{c}\dfrac{dm}{dt} - \vec{v}\dfrac{dm}{dt} + m\dfrac{d\vec{c}}{dt} - m\dfrac{d\vec{v}}{dt}$

## 求导分析

### 微分运算符

- $\dfrac{d}{dt}$

### 求导规则应用

1. **基本求导规则**
   - $\dfrac{d}{dt}(t^n) = n t^{n-1}$
   - $\dfrac{d}{dt}(\sin t) = \cos t$
   - $\dfrac{d}{dt}(\cos t) = -\sin t$
   - $\dfrac{d}{dt}(e^t) = e^t$
   - $\dfrac{d}{dt}(\ln t) = \dfrac{1}{t}$

2. **乘积法则**
   - $\dfrac{d}{dt}(uv) = u\dfrac{dv}{dt} + v\dfrac{du}{dt}$

3. **商数法则**
   - $\dfrac{d}{dt}(\dfrac{u}{v}) = \dfrac{v\dfrac{du}{dt} - u\dfrac{dv}{dt}}{v^2}$

4. **链式法则**
   - $\dfrac{d}{dt}(f(g(t))) = f'(g(t)) \cdot g'(t)$
