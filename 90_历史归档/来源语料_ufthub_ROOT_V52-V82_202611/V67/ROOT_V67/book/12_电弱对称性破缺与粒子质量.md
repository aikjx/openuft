# 第十二章｜电弱相互作用、Higgs 机制与粒子谱

标准电弱理论将 SU(2)_L 与 U(1)_Y 规范场耦合到左手轻子和夸克双重态。Higgs 场是复 SU(2) 双重态，其势 `V(Φ)=−μ_H² Φ†Φ+λ_H(Φ†Φ)²`，当参数满足适当条件时，真空具有非零期望值 `v`。选择规范后 `Φ=(0,(v+h)/√2)`，电弱规范玻色子产生树级质量 `m_W=gv/2`、`m_Z=v√(g²+g'²)/2`，光子保持无质量。由 `cos²θ_W=g²/(g²+g'²)` 得树级 `ρ=m_W²/(m_Z²cos²θ_W)=1`，这在程序中进行了可复算测试。量子圈修正与重整化在真实精密数据中不可忽略。

Yukawa 耦合使费米子质量依赖于不同的矩阵参数：例如 `m_f=y_f v/√2`（简化单味道表示）。味道混合、CP 相位、夸克束缚态质量、轻中微子质量与混合等，都需要更丰富的场与量子动力学。单一的“螺旋角度”无法自动给出所有这些相互独立的观测事实。

强作用的 SU(3) 规范动力学具有禁闭和渐近自由等非微扰效应；要从基本公设计算强子质量谱，通常需要格点 QCD 等非微扰方法，而不能只把一条力写成 `F∝1/r²`。弱相互作用具有左手手征选择性和电弱对称性破缺尺度，不能简单解释为引力、电力、磁力之外的另一根欧氏空间法向矢量。

大统一理论不能只统一写法，还必须解释这些物质表示和耦合为何具有实测结构；要宣称已“全部攻破”则需要远超过本卷已求导的条件式。
