## 🎯 用户使用指南

### 最快配置方式（推荐）

**步骤**：
1. 打开Obsidian设置 ⚙️
2. 搜索"公式"或"Math"
3. 启用以下选项：
   - ✅ Enable inline math（启用行内公式）
   - ✅ Enable MathJax（启用MathJax）

**完成！** 现在可以正常查看所有公式了。

### 高级配置（可选）

如果需要更强大的LaTeX支持：

1. **安装MathJax插件**
   - 设置 → 社区插件 → 浏览
   - 搜索"MathJax" → 安装

2. **配置包**
   ```json
   {
     "packages": {
       "[+]": [
         "amsmath",
         "amssymb",
         "mathtools"
       ]
     }
   }
   ```

3. **启用SVG渲染**
   - 在插件设置中勾选"Use SVG for output"
