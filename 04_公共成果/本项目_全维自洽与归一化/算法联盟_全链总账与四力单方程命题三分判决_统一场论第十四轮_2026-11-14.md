## 八、本轮新发现：三重门不是各自承重，最小承重割为 `2`

★按「预设被自己数据推翻时须改判据驱动量并如实报负读数」的纪律，本轮遇到一次反噬：

改驱动量为「最小承重割」：枚举 `2^3 = 8` 个拆门子集，找使误放行 `>0` 的最小拆门数。

| 拆门掩码 | 拆门数 | 误放行配置数 |

| 0 | 0 | 0 |
| 1 | 1 | 0 |
| 2 | 1 | 0 |
| 3 | 2 | 0 |
| 4 | 1 | 0 |
| 5 | 2 | 0 |
| 6 | 2 | 4 |

- 最小承重割 `2`，最大误放行 `4` 个，基线 `0` 个。
