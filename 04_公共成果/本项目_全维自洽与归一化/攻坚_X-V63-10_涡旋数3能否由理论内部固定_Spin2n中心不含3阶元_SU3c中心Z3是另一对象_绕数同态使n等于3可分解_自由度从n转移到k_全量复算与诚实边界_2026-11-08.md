## 四 主定理 A：Spin(2n) 中心给不出 3 阶元，但 SU(3)_c 给得出

`D_n` 根格取 `{v ∈ ℤⁿ : Σvᵢ 为偶数}`，权格对它有 4 个陪集，代表为 `0`、`e₁`、`(1/2)ⁿ`、`(1/2,…,1/2,−1/2)`。**元素阶 = 最小正整数 `k` 使 `k·rep` 落回根格**——全部由整数判据枚举，不抄群论结论：

| n | 陪集阶 | 群型 |
|---|---|---|
| 3 | `[1, 2, 4, 4]` | Z4 |
| 4 | `[1, 2, 2, 2]` | Z2xZ2 |
| 5 | `[1, 2, 4, 4]` | Z4 |
| 6（Spin(12)） | `[1, 2, 2, 2]` | Z2xZ2 |
| 7 | `[1, 2, 4, 4]` | Z4 |
| 8 | `[1, 2, 2, 2]` | Z2xZ2 |

交替的来历是可算的：`2·(1/2)ⁿ = (1,…,1)` 的坐标和为 `n`，`n` 偶时在根格内（阶 2）、`n` 奇时不在（须 `k=4`）。六档**全部元素阶集合 `[1, 2, 4]`，含 3 阶元 `0` 档**（显式报零的个数）。

**陷阱（`A04`）**：商群阶恒为 4。若把「阶为 4」误读成「含 4 阶元」，`D_6` 会给 `4` 而真实最大阶是 `2`；`D_5` 上两者恰好都是 `4`，会给出假安慰。所以负对照必须在**偶 n** 上测——这是「构造负控前先估坏值落在哪一侧」的一次实际应用。

> **本节最该被引用的是边界，不是结论。** 起草主文时差点写成「群论层给不出 Z_3」；但 `SU(3)_c` 的中心恰是 `Z_3`。本册于是补算 `A08`：取 `A_2` 基本权 `ω₂ = (1/3, 1/3, −2/3)`，根格为 `{v ∈ ℤ³ : Σvᵢ = 0}`，最小 `k` 使 `k·ω₂` 落回根格是 `3` ⇒ 中心 `Z3`。**这是范围外第一条就错的例子**：「范围内全对」必须同时报「范围外第一条就错」。本册的定理因此收窄为「**Spin(2n) 大统一群中心**不含 3 阶元」，不覆盖低能色群中心。若能把 `SU(3)_c` 的 `Z_3` 与内部空间涡旋数投影联系起来，`B06` 需重判；本册未做，`D04` 记为 OPEN。

## 五 主定理 B：3 不是拓扑荷的原子

绕数器对 `n` 取 `81` 组 `a,b ∈ [−4,4]` 全网格验证 `wind(a)+wind(b) = wind(a+b)`，`81/81` 吻合、失配 `0`。由此：

- 最小正拓扑荷是 `1`（`n=1` 单值闭合），**没有拓扑理由单独禁戒 `n=1` 与 `n=2`**；
- `n=3` 可分解：和为 3 的三元组共 `52` 个，含 `(1,1,1)`，其中全单位分解 `1` 个；
- 对目标 `1..8` 每个 `t` 都存在 `n=t` 使 `wind=t` ⇒ 「理论允许 `t`」是 100% 通过的谓词，**判别力 0**（承接 V63 `C10`）。

`B09` 给出更硬的一刀：**3 个 `n=1` 缺陷**与 **1 个 `n=3` 缺陷**的总绕数同为 `3`，但缺陷数是 `3` 对 `1`（差 `2`）。即便固定总绕数，对应的物理构型仍不唯一——「三代」指哪个对象都没定下来。

## 六 主定理 C：唯一真判负——自由度只是从 n 转移到 k

最自然的内部固定机制是离散规范投影 `Z_k`：要求 `n ≡ 0 (mod k)` 则最小正绕数为 `k`。本册枚举 `k=2..9`，得 `n_min = 2,3,4,5,6,7,8,9`，**`k=3` 确实给 `n_min=3`**。

但 `k` 必须由理论给出，而 `B08` 显示 `k` 的候选网格不是 Spin(2n) 中心阶集合 `[2, 4]` 的子集；中心能给的只有 `Z_2×Z_2` 与 `Z_4`。于是三条独立路径各自检查：

| 路径 | 读数 | 是否固定 3 |
|---|---|---|
| Spin(2n) 中心元素阶 | `[1, 2, 4]`，含 3 阶元 `0` 档 | 否 |
| `q_Y` holonomy gcd | `1` ⇒ 只逼 `n ∈ ℤ` | 否 |
| 最小正拓扑荷 | `1` | 否 |

**内部固定机制 `0/3`** ⇒ `B06` 对「涡旋数 3 由理论内部固定」判 **FAIL**（已登记）。`Z_3` 只能作为新输入引入；自由度从 `n` 转移到 `k`，「为什么是 3」仍无答案。冻结在 `k=3` 一档会给 `1/1` 的假绿，全档是 `1/8`——冻结参数刀第三次复现。
