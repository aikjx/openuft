五维 Kaluza–Klein 标量一致性

φ 固定时是否满足纯真空 5D 标量方程？

对于 κφ≠0 的标准真空 KK 模型：□φ ∝ F²。φ 严格恒定时必须有 F²=0。该滑块仅用于说明数学条件，不是测量的场强值。

理论范围：4D Einstein–Maxwell + 特定 5D 真空 KK 圆维构造。G 为实验输入。任何独立新理论仍须满足等效原理、PPN、引力波及量子一致性检验。
