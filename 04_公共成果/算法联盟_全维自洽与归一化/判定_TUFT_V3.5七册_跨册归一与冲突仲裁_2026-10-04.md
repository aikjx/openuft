## 一、抓到的五处漂移（全部机器读出，非人工印象）

### ★D1 力程 2π 漂移（最硬的一处）· A-01 · **已处置（BOUNDARY）**

同一组 (κ,τ) = (2.5, 4.0)：

- **FIXV** 的样本力程 L = **0.212000**（对应 L = 1/√(κ²+τ²)，**无 2π**）
- **SPEC/ATTACK** 的定标 L = 2π/√(κ²+τ²) = **1.332033**

⇒ **相差 6.2832 倍，正是 2π**。两份产物若同时被引用，同一个力会算出两个数。

**裁定：真口径漂移，必须统一。**
**仲裁：以 2π 版为准** —— ATTACK 册已用 sympy 证明 2π/√(κ²+τ²) **= 一整圈螺旋的弧长**（几何身份唯一），无 2π 版只是它的 1/2π（约化量，缺几何身份）；代价已在 SPEC 册 R-01 量化（2π 版对表核能标偏大 4.13~6.20 倍 / 15.42 倍）。

### ★D2 册内自相矛盾（FIXV 的 md 与它自己的 json 打架）· A-02 · **已处置（BOUNDARY）**

- FIXV 的**整理 md** 第二节：引力区符号「**自动导出**、由 x−y 代数决定、**非人工硬编码**」，并称「首次让引力吸引由代数导出而非输入」；
- **同一册**的 json guard `omega_gravity_sign_is_choice`：引力区符号「来自**候选式选择**，−Ω 同样合格（**非自动导出**，审计 F-01）」。

⇒ **同一册的机器产物与文字结论直接相反**。

**裁定：以机器 guard 为准**（它与 OMEGA 册 T1「Ω 与 −Ω 双双合格 ⇒ P2 不可满足」完全一致）；md 那句属表述层残留，按 SPEC 册 W-01 替换表改写。
**这一条是本册最有价值的发现：它证明 md 与 json 会不同步，只看 md 的读者会得到与机器相反的结论。**

### D3 分区覆盖率两值 · A-03 · BOUNDARY

FIXV：重叠 **2.0544%** / 未覆盖 **59.85%**；REORG：重叠 **0.0280%** / 未覆盖 **96.42%** ⇒ 重叠率相差 **73 倍**。
**裁定：口径差，不是冲突**（网格与阈值 B 取值不同，都是对同一形式缺陷的**统计**，结论同向）。
且 ATTACK 册已把它升级为**构造性全域证明**（对任意有限阈值必然存在重叠与空隙），故统计数值不再需要对齐——引用时以构造性结论为准，数值仅作见证。

### D4/D5 耦合数值微漂移 · A-04 · BOUNDARY

- α(M_Z)：FIXV **0.007818608** / SPEC **0.007815431**（=1/127.952）/ ATTACK **0.007815431** ⇒ 极差 **4.07e-4（0.041%）**
- α_W(费米定义)：FIXV **0.016960486** / ATTACK **0.016961330** ⇒ 差 **4.98e-5（0.0050%）**

**裁定：口径差，不影响任何结论**（相对差 ≤4e-4，远小于 α₂ 两定义间的 **2.000 倍**，也远小于 α(0) 与 α(M_Z) 之间的 **7.10%**）。但按 SPEC 册 U5/U6 仍应统一为单一命名常量，避免第四次串号。

### A-05 · 互补性争点（**不构成冲突**）· PASS

- **g−2**：REORG D-01（既有 ansatz a=α/8π 偏差 74.96%）vs ATTACK E-02（自然耦合量级高 8.06 个量级）⇒ 一个对**既有具体公式**对表、一个是**一般性量级估计**，结论**同向**（窗口已关闭）⇒ 互补。

⇒ **七册之间未发现真正的结论性冲突**；唯一真冲突是 A-02 的册内矛盾，A-01 是口径漂移。
