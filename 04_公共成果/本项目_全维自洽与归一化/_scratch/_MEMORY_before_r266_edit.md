## 一、环境 workaround
- 中文路径禁入 argv ⇒ UTF-8 源码 + ASCII runner；脚本内 raw Windows 路径（export 会被 MSYS 转坏）。
- py3.13 无 numpy/sympy/mpmath ⇒ **Decimal(prec=60) + Fraction**，自写 PiNum + Newton sqrt。
- git：PortableGit + GIT_TERMINAL_PROMPT=0；删除走 shutil.move 入 scratch/，**禁 rm -rf**。
- ★★★**来料 LaTeX 被批量污染，「五种」形式**：①`\boldsymbol{b}`（花括号，最多；r241 来料 4391 处）②`\boldsymbol n`（空格无括号，`Frenet`→`Fre(\boldsymbol n)et`）③`\(\boldsymbol p\)` ④**整段公式加粗嵌套** `\boldsymbol{m=\frac{\hbar\omega}{c^2}}`（`[^{}]*` 命不中，残留 22 处）⑤**不对称括号** `\(\boldsymbol n)`（把 `\neq` 切成 `\(n)eq`、`n_B` 切成 `(n)*B`，引文失真）。
  ⇒ **唯一可靠解法：配平括号扫描** `_unbold()`（遇 `\boldsymbol`：下一非空是 `{` 数深度剥壳递归；是空格跳字母；是 `\` 保留整命令）+ **前置两条还原正则**：`\\\(\\boldsymbol\s+([A-Za-z])\)([A-Za-z])` → `\\\1\2`（救 `\neq`）、`\\\(\\boldsymbol\s+([A-Za-z])\)` → `\1`。**只写花括号正则必漏**（先漏 42、再漏 22）。审计前先查 `\boldsymbol` 标记本身。
- ★他人产物可能有 `\r\r\n` 双换行 ⇒ 解析前 `re.sub(r"[\r\n]+","\n",…)`。
- 串内 `\approx`/`\pi` 会被吃成 BEL ⇒ 含 LaTeX 用 `r"""`；裸 Decimal ⇒ `fmt_rel`；中文文案内**禁用 ASCII 双引号**（用「」）。

## 三、跨册判据门禁族（元纪律）
- 判据反噬自己 + 必设控制组（失控 ⇒ rc 2）；坏门槛假绿 ⇒ 回溯；verdict 机读驱动。**★★★守卫/控制组 ok 禁写死 True**。

- **定义恒等式通用刀**：参数用其**定义**展开成单项式，残差 0 ⇒ 相符是**规定**不是推导。「推导方程」计数必配正对照（否则恒 0 无分辨力）；单字母符号须边界正则。

- ★**定价槽位必须覆盖本卷最硬的量化发现**，否则定价与判词脱节；定价 FAIL 后必做，位掩码 2^n + 最小集剔除，**先判条件齐备再判自杀**，双档都报；**旧定价若对任何靶恒等（零判别力）必须废弃重算。**
