# V96 定理、反例及不成立的强结论

| 条目 | 逻辑状态 | 论据 |
|---|---|---|
| M1：外部环形光滑电流分布可定义 | 严格模型 | Jφ(r,z) 不依赖方位角，divJ=0；有限截面紧支撑 |
| M2：连续光滑线圈静磁场能量有限 | 条件严格 | 局部 B 有界且磁偶极远场衰减；不适用于单根零截面理想线丝 |
| M3：粒子通道 J=0、curlB=0、divB=0 | 严格解析 + 数值核验 | 粒子轨迹与电流支撑有正间隙，Biot–Savart 场解满足 Maxwell |
| M4：静磁圆周轨道存在 | 条件严格 | 调 I 使 |q|B=γm v/r0，洛伦兹力提供向心力 |
| M5：弱聚焦公式 | 已知理论严格线性化 | νr²=1−n，νz²=n |
| M6：0<n<1 必要条件 | 指定纯磁轴对称中面模型的线性聚焦 | 若 n≤0 垂直方向不恢复；若 n≥1 径向方向不恢复（边界为中性） |
| M7：一般径向与轴向振荡严格闭合 | 反例/不普适 | 两频率与主轨道一般不可通约 |
| M8：n=9/25 五圈共振 | 线性化严格；非线性非精确 | 理论频率 4/5 与 3/5；全方程微扰后返回偏差不为零 |
| M9：100 圈稳定即无限时间稳定 | 不成立 | 有限时间积分不能推出任意时间 KAM/非线性稳定 |
| M10：理想线环的总磁能有限 | 不成立 | 零截面电流近处 B∼1/ρ，能量积分出现对数发散 |
| M11：纯静磁自维持辐射电子闭环 | 不成立于经典模型 | 磁力不做功，电子加速有辐射损耗 |
| M12：绕行频率统一强弱电磁引力 | 未建立 | 无标准模型手征、色荷、耦合及量子规范结构，不能预测 G |
| M13：Floquet 全单位模意味着渐近吸引 | 错误 | Hamilton 磁场动力学保体积，单位模不排除中性漂移 |
| M14：外部真实电流装置自然 E=0 | 不可直接推广 | 实际供电与电荷分布可能在粒子通道形成附加电场 |
| M15：线性稳定圆轨道就是 V93 三叶结 | 不成立 | 拓扑与轨道结构不同，V96 仅证明圆周及邻域振荡 |

**物理边界：** `v_total=c` 不适用于此处电子的实测三维速度。本轮采用 `β=0.1`，并以经典轨迹为条件。不能据此证明空间本体执行光速螺旋。
