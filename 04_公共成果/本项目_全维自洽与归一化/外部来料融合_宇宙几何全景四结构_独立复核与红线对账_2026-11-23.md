## 二、三条标准公式复核（逐项）

### 2.1 曲面：环面高斯曲率

`K(θ) = cosθ / (r(R + r cosθ))`，取 R=2.0、r=0.65：

| 位置 | 解析式 | 读数 | 来料声称 |
|---|---|---|---|
| 外赤道 θ=0 | `1/(r(R+r))` | +0.580552 | 正曲率 ✓ |
| 内赤道 θ=π | `−1/(r(R−r))` | −1.139601 | 负曲率 ✓ |
| 腰线 θ=π/2 | 0 | 0 | K=0 ✓ |

负对照：换 R=1.2、r=1.0 后外正（0.4545）/内负（−5）结构不变——符号结构不依赖专用参数组。来料「升到曲面维度需要全新的两个数，不是给旧符号加下标」的表述与曲面基本定理一致。

### 2.2 规范场：AB 相位正比磁通

来料引擎 `accumPhase += dt·ω·flux`，一圈 `dt·ω=2π` ⇒ 每圈相位增量 `2π·Φ`。复核：

| flux | 每圈相位 (rad) |
|---|---|
| 1.20 | 7.539822 |
| 2.40 | 15.079645（=2×） |
| 0.00 | 0 |

相位比=磁通比=2，线性性与单点读数两路一致。来料诚实标注「已放大便于观察，真实 AB 相位远小于一整圈」——这个自我限定正确，不夸大。

### 2.3 时空：弱场偏转读数

`δ = 4GM/(c²b) = 2r_s/b`，三条撞击参数 `b=[2.0, 3.2, 4.8] r_s`：

| b / r_s | δ (rad) | δ (°) | 来料显示 |
|---|---|---|---|
| 2.0 | 1.000 | 57.30 | 57.30° ✓ |
| 3.2 | 0.625 | 35.81 | 35.81° ✓ |
| 4.8 | 0.417 | 23.87 | 23.87° ✓ |

公式与读数逐位复现。恒等门 `4GM/(c²b) ≡ 2r_s/b`（`r_s=2GM/c²`）单列不承重。

## 三、适用范围边界（本轮唯一增量，可翻覆）

来料 dock 写「光线偏转角用**真实弱场公式**…精确计算」。机验发现两处适用性问题：

1. **小角近似越界**：最内侧 `δ=1 rad`（57.3°），弱场公式的前提是 `δ≪1`。1 rad 偏离一个量级以上，该点已非弱场。
2. **光子捕获截面**：史瓦西光子球捕获临界撞击参数 `b_crit = 3√3/2 r_s ≈ 2.598076 r_s`。最内侧 `b=2.0 r_s < b_crit` ⇒ 该光子落入视界、不逃逸；来料把它画成逃逸光线并标 57.30°，是强场区误用。

| 检验 | 配置 | 读数 | 判定 |
|---|---|---|---|
| 内圈越界 | b=2r_s | δ=1 rad；b<b_crit | 越界（gate） |
| 远场负对照 | b=20r_s | δ=0.1 rad；b>b_crit | 弱场有效，证明非恒错（neg） |
| 换参数负对照 | R=1.2,r=1.0 | 外正内负不变 | 曲面结构稳健（neg） |
| 反噬 | 注入 b_crit=1.5r_s | 捕获判定 True→False | 判据非写死（neg） |

**裁定**：这是「公式正确、适用范围被越过」的边界问题，不是来料整体错误；来料主论断（四几何不统一）不受影响。**改进建议**（不回写原文，仅记录）：若把三条撞击参数改为全部 `b>3r_s`（如 3.2/4.8/7.0 r_s），则弱场公式自洽；或保留 2r_s 但标注「该光线实际被捕获，此处仅示意强场弯曲」。这属于可视化精度改进，不涉及物理结论更改。
