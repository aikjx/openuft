## §2 动作空间与可导出性约束

把「换公理集 / 新来料」参数化为五元组：

| 变量 | 含义 |
|---|---|
| `a` | 动作新增的独立自由输入数（新公理携带的常数 / 标度 / 自由函数） |
| `e` | 被消除的既有独立自由输入数（因被导出而不再自由） |
| `s` | `AXIOM_SWAP` 标志（替换 / 新增公理，或引入新来料） |
| `R` | 既有输入之间**尚未被使用的结构依赖**存量 |
| `o` | 内生输出数（G2 型无量纲闭式 / G3 型先于观测的单点预言） |

- `delta = a − e`；**GATE**：`delta < 0`（r134 唯一门「前提净下降」）。
- **可导出性约束（承重）**：每个被消除的输入必须由 1 个新增独立输入或 1 个存量依赖 `R` 导出（若 1 个新增输入能导出多个旧输入，它本身是被压缩的表示，`a` 应计 1）。`AXIOM_SWAP` 按定义**替换旧结构**，故 `R = 0` 且 `a ≥ 1` ⇒ `e ≤ a` ⇒ **`delta ≥ 0`**。
- 合法规则：`o ≥ 1`；`s=1 ⇒ a≥1 ∧ R=0 ∧ e≤a`；`s=0 ⇒ e≤a+R`。

**穷举网格**：`a,e∈[0,6]`、`s∈{0,1}`、`R∈[0,3]`、`o∈{1,2}` ⇒ **784 组**（G09 用 `7*7*2*4*2` 乘积式现场核算，见 §6 自抓）。

## §4 承重裁定二：可达路径分类定理（E03/E04）

784 组穷举结果（G09–G12）：

| 量 | 值 |
|---|---:|
| 网格 | **784** |
| 合法动作 | **342** |
| GATE 通过 | **64** |
| `AXIOM_SWAP` 通过 | **0** |
| `STRUCTURE_IDENTIFY` 通过 | **64** |
| 全部通过解满足 `R ≥ 1` | **True** |

**定理**：`GATE(delta<0) ⇒ s = 0 ∧ R ≥ 1`。即方向门的通过完全依赖「既有输入之间尚未被使用的结构依赖存量」，与「新增输入 / 换公理」无关，后者只会把 `delta` 推回非负。这是 attack54「方向门从未写进清单」之后，对**门本身可达路径**的首次分类。

**阳性 / 边界 / 变异守卫**（G11/G12，证明非恒假）：

- 电弱 `(a=0,e=1,s=0,R=1,o=1)` 在通过集（净减 1 个自由参数）；
- 边界 `(a=1,e=1,s=1,R=0,o=1)` 合法但 `delta=0` 不通过；
- 变异①解锁 `s=1` 的 `R` ⇒ SWAP 出现 **52** 组通过解；
- 变异②把 `e≤a` 放宽为 `e≤a+1` ⇒ SWAP 出现 **10** 组通过解。

⇒ 互斥来自「`R` 在换公理集下不可用」这一**结构性前提**，不是恒假守卫、不是数值精度问题。
