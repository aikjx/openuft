# TUFT-r385 · 最本源方程的求导与证明

> **判词**
> `R385-SOURCE-EQUATION-UNIQUE-NULL-CONSTRAINT-OK-MOTHER-IDENTITY-BIJECTION-OK-THETA-ZERO-MODE-OK-INTERIOR-NEEDS-TWO-COUPLINGS-OK-ALPHA-NOT-INTERNAL-FAIL-SINGLE-SCALE-ONLY-OK-UNIQUE-PREDICTION-0`

**条目 40（PASS 28 / FAIL 5 / INFO 7），守卫 6/6。** 分层：A 精确代数（Fraction，残差必须精确 0）／B 高精度数值（Decimal prec=50）／G 判决／C 对照／E 仪器自捕／P 定价。**分层条目不可相加。**

## 一、一句话答案：最本源方程是哪一条

在「光速螺旋」这套记账里，唯一一条**不含任何自由参数、且其余所有方程都由它代数推出**的，是零模（光速）条件：

```
g_{mu nu} xdot^mu xdot^nu = 0    <=>    |v|^2 = c^2    <=>    (R w)^2 + u^2 = c^2
```

它是一条**约束**，不是运动方程。全式只含一个常数 `c`，没有长度、没有质量、没有角度。

其余四条常见「候选本源方程」全部被排除（§二）。所以对「最本源的方程式」的严格回答是：

> **只有一条，就是零模条件；而一条方程不足以定出唯一世界线 —— 余下的 1 维自由度正是 θ，也就是 α 之所以是输入而非输出的全部原因。**

这不是「还没算出来」，是**自由度账算得出来的**（§四）。要消除它，必须补一条**不含新自由参数**的第二方程；本框架内不存在这样的方程（§二末行）。

## 二、排除法：为什么其余候选都不是

| 候选 | 层级 | 判据（条目） | 读数 | 结论 |
|---|---|---|---|---|
| 零模条件 `eta(xdot,xdot)=0` | 0 | 一条、一个常数；24 例精确回代（A01） | max\|res\| = 0 | **唯一本源方程** |
| 母式 `w^2=c^2(k^2+t^2)` | 1 | 雅可比 `detJ=-c^2/w != 0`（A04）；逆命题精确闭合（A03） | −500/9；res = 0 | **双射 = 重参数化**，0 新信息 |
| 四量闭式 `m=hbar*w/c^2` 等 | 2 | 纯单位换算，无时间导数、无初值问题 | — | **定义级**，0 新信息 |
| 极值条件 `N'(theta)=0` | 3 | 需引入 `a1,a2,g` 三个新参数（A11） | 12/12 命中且互不相同 | 补 1 条方程、加 3 个参数 ⇒ **更不唯一** |

层级 1 的证明是干净的：给定 `(kappa,tau)`，`omega=c|K|`、`theta=atan(kappa/tau)` 是可逆的；反向 `R=kappa/(kappa^2+tau^2)`、`u=c^2 tau/omega` 也在 24 例上精确闭合到 0。**一个双射不减少自由度**，所以母式是坐标变换，不是约束，更不是动力学。

负对照 C06 检验这把尺：把 `R` 故意误写成 `kappa/(kappa^2+tau^2)^2`，回代值从 `2` 变成 `200/9`（精确有理），尺有判别力。

## 四、自由度账：α 不能内生的真正原因

| 步 | 未知量数 | 独立方程数 | 解族维数 | 条目 |
|---|---|---|---|---|
| 零模条件 | 2（`kappa,tau`） | 1 | **1** | A10 |
| 加 `a1,a2` 各向异性 | 2 | 1 | 1（θ 仍自由；A06 平坦、A07 只在边界） | A06/A07 |
| 再加手性项 `g*tau` | 2 + 3（`a1,a2,g`） | 2（零模 + `N'=0`） | **3** | A11 |

- **A10**：6 个互不相同的 `(kappa,tau)` 全部满足 `kappa^2+tau^2=常数`，展布精确 0 ⇒ 解集至少 1 维。这一维就是 `theta = atan(kappa/tau)`。
- **A11**：12 组（4 个 `a1:a2` 比例 × 3 个整体尺度）各自反解出自己的 `g*`，全部精确命中 `N'(theta*)=0`，且 12 个三元组互不相同 ⇒ **补一条方程反而把解族从 1 维抬到 3 维**。

这是本卷最硬的一条负面结论：**在这个框架里，「加一个新耦合来选 θ」是方向性错误** —— 每加一个耦合就多一个拟合旋钮，净唯一性下降。

## 五、θ 零模定理与四格分类

取泛函 `E = int (a1 kappa^2 + a2 tau^2 + g tau) ds`，代入 `kappa=(w/c)cos(theta)`、`tau=(w/c)sin(theta)`：

```
N(theta)  = a1 cos^2 + a2 sin^2 + g sin
N'(theta) = 2(a2-a1) sin*cos + g cos = cos(theta) * [2(a2-a1) sin(theta) + g]
```

| `a1` vs `a2` | `g` | `N'(theta)=0` 的解集 | 几何 |
|---|---|---|---|
| 相等 | 0 | **全部 θ** | 零模：`E` 与 θ 完全无关（B01 展布 1.290E−48） |
| 相等 | 非零 | `theta = ±pi/2` | 圆（τ 取极值） |
| 不等 | 0 | `theta = 0` 或 `±pi/2` | 直线或圆（内点 0 个零点：A07 = 0/6） |
| 不等 | 非零 | 内点 `sin(theta*) = g / (2(a1-a2))` | 真螺旋 |

### 5.1 一处必须记下的修正（E02）

首稿把 `d(tau)/d(theta)` 写成 `(w/c) sin(theta)`，正确的是 `(w/c) cos(theta)`。于是内点条件被误写成

```
误：cos(theta*) = g / (2(a1-a2))        读数 -4 cos(theta*) = -3.9999
正：sin(theta*) = g / (2(a1-a2))        读数 -4 sin(theta*) = -0.029189
```

差 **137.0 倍 ≈ 1/α**。这不是排版错误，是两个定性结论的改变：

1. **需要的手性耦合量级从 O(1) 降到 O(α)**：`g*/(hbar w) = -2.9189E-02`，即 `-4 alpha` 量级。若有人真去做这个模型，耦合强度的量级差了两个半数量级。
2. **内点存在性变成一条有界的判据**：`|g| <= 2|a1-a2|`（等价 `|sin theta*| <= 1`）。以 `a1:a2=1:3` 计，上限 `g_max=4`；物理点只用 `0.0292` ⇒ **上界从不 binding** ⇒ `(0, pi/2)` 内每个 θ 都可达（B10）。

### 5.2 判别力为什么是 0（B08 / B09）

- **B08** 走两条互不依赖的路径：一条是闭式反解 `g*/(2(a1-a2))`，另一条是用**二分法**在 `N'(theta)=0` 上求根再取 `sin`。两者给出 `7.29715828011E-003` 与 `7.29715828011E-003`，相对偏差 < 1e−30。这条独立路径是专门用来防「同源回验」的（旧稿 B05 的 `exp` 与 `act` 是同一个闭式，属同义反复 —— 登记 E03）。
- **B09** 取 5 个目标 θ（0.30/0.60/1.00/1.30/1.50 rad），各自反解 `g*`，再各自二分回收，最大偏差 **6.0E−49**，且 `g*` 严格单调。⇒ `theta <-> g*` 在一一对应区间内**满射**。任何你想让 θ 取的值，都能凑出一个 `g` 让它成为驻点。

> 这就是「可调参数不是预言」的定量形态：不是「拟合得不够好」，是**映射本身是满射**（与本库 r272 / r374 V30-2 / r365 同一族结论）。

## 七、判负五条与定价

| 命题 | 裁定 | 理由 |
|---|---|---|
| 母式是动力学方程 | **FAIL** | 不含时间导数、无初值问题；双射 ⇒ 不产生演化 |
| 母式把 2 个自由常数压到 0 | **FAIL** | `2 -> 2`：一般 null 曲线 2 个自由函数；限定常 `kappa,tau` 后仍 2 个自由常数 |

**定价**：`S1..S5` 全否，`SURVIVE = 0` ⇒ **本卷不占度**。度数链最大仍为 **36（r264 止）**，候选 37 不变。可入池的第一性输出 **0 条**（P02）。

## 九、遗留 OPEN

- **`X-R385-1`**：是否存在「不含新自由参数」的第二方程？等价于问：除零模外还有没有第二个几何不变量能给出独立关系。本卷只证了「现有候选都不行」，没证「不存在」。
- **`X-R385-2`**：`g` 的物理来源。若手性项 `g*tau` 来自挠率的拓扑荷（`H^3` 周期），则 `g` 应是量子化的而不是连续自由参数 —— 这会直接改写 §5.2 的满射结论。
- **`X-R385-3`**：内点条件 `sin(theta*)=g/(2(a1-a2))` 与 r339/r346 的整性定理能否合流。若 `g` 量子化，`sin(theta*)` 的取值就分立，与「`S` 是有限个 AP 之并」可能有共同结构。
- **`X-R385-4`**：θ 零模的稳定性。`a1=a2` 且 `g=0` 时 θ 是**全平方向**（不只是驻点）；任一微扰都把它变成 modulus —— 这类方向在量子化后是零模还是快子，本卷未判。

## 十、与既有卷的关系（**条目不可相加**）

- 本卷**不新增度数**，不与 r383（四量本质）、r375（V34）、r374（V30/V31）、r370（V32）的条目相加。
- r383 的「四量同源」在本卷得到解释：四量是**同一个 `w` 的四种单位**；而 `w` 由零模 + θ 决定，θ 自由 ⇒ 凡带 θ 的量（`rho`、`Hv`，均 `∝ 1/sin^3 theta`）就**非内禀**。
- 本卷与 r366（定理 H，判别力翻转）同族：都是把「判据通过」换成「判据能判什么」。r366 说整性判不出几何，本卷说驻点条件判不出 θ。
