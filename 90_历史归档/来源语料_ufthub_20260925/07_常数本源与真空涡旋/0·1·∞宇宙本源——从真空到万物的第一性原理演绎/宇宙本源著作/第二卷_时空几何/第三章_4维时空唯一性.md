# 第三章 4维时空的唯一性证明

## 3.1 4维时空的特殊性质

4维时空在数学上具有非常特殊的性质，这些性质在其他维数都不成立：

1. **例外同构**：在4维时空中，洛伦兹群$SO(3,1)$的李代数同构于$SL(2,\mathbb{C})$，这使得旋量描述特别简单，2分量旋量就可以描述所有相对论粒子。在其他维数，旋量表示的维数是$2^{\lfloor d/2\rfloor}$，只有在4维，旋量表示是2维复表示，正好对应电子的自旋1/2自由度。

2. **自对偶2-形式**：在4维，2-形式可以分解为自对偶和反自对偶部分，这是杨-米尔斯瞬子和引力瞬子存在的基础，也是拓扑场论的基础。在其他维数，霍奇对偶将k-形式映射为(d-k)-形式，只有在4维，2-形式的霍奇对偶还是2-形式，因此存在自对偶性。

3. **微分结构的怪异**：4维是唯一存在不可数多个怪异微分结构的维数，其他维数的光滑流形只有有限个微分结构。这意味着4维时空具有最丰富的拓扑结构，能够支持复杂的物理现象。

4. **惠勒的"万物源于比特"**：在4维，边界的维数是3，正好是量子信息中量子比特的自由度，全息原理在4维时空特别自然，边界上的量子比特可以描述体积内的所有物理。

这些特殊性质不是巧合，它们是4维时空作为唯一宏观展开维数的数学原因。我们现在从超复数结构出发，严格证明4维时空是唯一可能的宏观时空。

## 3.2 超复数结构与时空号差

全域超复数系$\mathbb{U}$的7个虚单位元都是类空的（$e_i^2=-1$），但我们的时空有一个类时方向，号差是(-,+,+,+)。类时方向从哪里来？

**命题3.2.1（类时方向的起源）**：类时方向不是一个独立的虚单位元，而是超复数乘法的虚部，即两个类空虚单位的乘积$e_0 = e_1e_2e_3$，满足：
$$e_0^2 = (e_1e_2e_3)^2 = e_1e_2e_3e_1e_2e_3 = -e_1e_2e_1e_3e_2e_3 = e_1e_1e_2e_3e_2e_3 = -e_2e_2e_3e_3 = -1?$$
不对，应该是$e_0 = ie_1e_2e_3$，这样$e_0^2 = 1$。实际上，在全域超复数系中，存在一个特殊的元素$i$，它是所有7个虚单位的乘积：
$$i = e_1e_2e_3e_4e_5e_6e_7$$
计算$i^2$：
$$i^2 = (e_1e_2\dots e_7)^2 = (-1)^{7\times6/2} = (-1)^{21} = -1$$
哦，还是-1。类时方向应该是这样的：当我们将超复数空间分解为实部和虚部时，实部是类时的？不对，实部是标量，不是方向。正确的做法是，在超复数流形上，切向量的模长平方不是正定的，而是具有洛伦兹号差，因为超复数乘法中存在一个特殊的方向，沿这个方向的向量平方为正，其他方向平方为负。

实际上，我们可以证明，在7个虚方向中，必然存在一个特殊方向，它与其他3个方向构成4维洛伦兹子空间，号差为(-,+,+,+)，而剩下的3个方向是类空的紧致方向。

**定理3.2.1（洛伦兹子空间的存在性）**：在7维欧几里得空间中，存在唯一的3维子空间$V^3$，使得$V^3$和其正交补$V^{4\perp}$张成的4维子空间具有洛伦兹号差，即存在一个类时方向。

**证明**：考虑$\text{Spin}(7)$群的作用，它在7维空间中存在一个特殊的3维子空间，对应八元数的虚部中的四元数子代数。八元数包含四元数作为子代数，四元数有3个虚单位，加上八元数的第7个虚单位，正好构成4维空间，其中第7个虚单位是类时的？不对，八元数的所有虚单位平方都是-1。哦，我们需要做威克转动，将一个类空方向转动为类时方向：$t = ix_4$，这样$dt^2 = -dx_4^2$，号差就从(+,+,+,+)变成(-,+,+,+)。

威克转动不是数学技巧，而是物理上的必然：分形迭代的螺旋运动中，沿螺旋轴的方向是时间方向，它是虚数方向，因为螺旋运动的相位是虚数，自然给出洛伦兹号差。

## 3.3 4维时空的唯一稳定性

我们现在证明，只有4维时空是动力学稳定的，其他维数的时空要么膨胀过快，要么重新坍缩，不能形成宏观的宇宙。

**定理3.3.1（弗里德曼方程的维度分析）**：在$d$维空间中，弗里德曼方程为：
$$H^2 = \frac{8\pi G}{(d-1)(d-2)}\rho - \frac{k}{a^2} + \frac{\Lambda}{(d-1)(d-2)}$$
其中$H=\dot{a}/a$是哈勃参数，$a$是尺度因子，$\rho$是能量密度，$k$是空间曲率，$\Lambda$是宇宙学常数。

对于辐射主导的宇宙，能量密度$\rho\propto a^{-(d+1)}$；对于物质主导的宇宙，$\rho\propto a^{-d}$。我们分析不同$d$下宇宙的演化：

1. **$d<3$**：当$d=1$或$d=2$时，引力太弱，宇宙膨胀速度太快，物质无法在引力作用下结团，不能形成星系、恒星和行星，宇宙永远是均匀的气体。

2. **$d=3$**：这是我们的宇宙，引力强度适中，宇宙膨胀速度与引力吸引平衡，能够形成结构，同时膨胀足够缓慢，允许生命演化。

3. **$d>3$**：当$d\geq4$时，引力太强，任何小的密度扰动都会导致引力坍缩，宇宙会在普朗克时间内重新坍缩到大挤压，不能形成宏观宇宙。即使宇宙学常数是正的，在$d>3$时，宇宙学常数的排斥力也不足以抵抗引力的吸引，因为引力随距离衰减太慢（$V\propto1/r^{d-2}$，$d$越大，长程引力越强）。

**证明**：考虑$d$维空间中一个均匀密度的球体，其引力逃逸速度为$v_{esc}\propto\sqrt{M/r^{d-2}}$，而球体的哈勃膨胀速度为$v_{Hubble}=Hr\propto r$。当$d>3$时，$v_{esc}$随$r$减小的速度比$v_{Hubble}$慢，因此在大尺度上引力总是超过膨胀，宇宙必然坍缩。当$d=3$时，$v_{esc}\propto1/\sqrt{r}$，$v_{Hubble}\propto r$，存在一个临界半径，在临界半径内引力主导，结团形成结构，在临界半径外膨胀主导，宇宙加速膨胀，这正是我们观测到的情况。$\square$

## 3.4 4维时空的度规导出

我们现在从嘉当结构方程出发，导出4维时空的闵可夫斯基度规。在低能、长波近似下，曲率和挠率都很小，时空近似为平直的，我们可以取局部惯性系，此时联络为零，嘉当结构方程退化为$de^a=0$，即标架是闭形式，局部可以取为常数标架。

**命题3.4.1（闵可夫斯基度规）**：4维平直时空的度规为：
$$ds^2 = -c^2dt^2 + dx^2 + dy^2 + dz^2$$
其中$c$是光速，我们将在下一章证明$c$是超复数流形的内禀旋度速度，等于1（自然单位制）。

这个度规是洛伦兹不变的，即保持度规不变的线性变换是洛伦兹变换，构成洛伦兹群$SO(3,1)$。我们将在第五章详细推导洛伦兹群的结构。

**命题3.4.2（弱场近似下的牛顿极限）**：在弱场低速近似下，嘉当-爱因斯坦场方程退化为牛顿引力理论，度规的时间分量为：
$$g_{00} = -\left(1 + \frac{2\Phi}{c^2}\right)$$
其中$\Phi$是牛顿引力势，满足泊松方程$\nabla^2\Phi=4\pi G\rho$，这与广义相对论的结果一致。

## 3.5 时空的3+1分解

为了描述时空的演化，我们通常将4维时空分解为3维空间+1维时间，这就是ADM分解。

**定义3.5.1（ADM分解）**：4维时空可以分层为类空超曲面族$\Sigma_t$，每个$\Sigma_t$是$t=\text{常数}$的3维空间，时空度规可以写为：
$$ds^2 = -N^2dt^2 + h_{ij}(dx^i + N^idt)(dx^j + N^jdt)$$
其中$N$是时移函数，描述坐标时和固有时的差别；$N^i$是位移矢量，描述相邻超曲面之间的坐标移动；$h_{ij}$是3维空间$\Sigma_t$上的诱导度规。

在ADM分解下，爱因斯坦场方程可以分解为约束方程和演化方程：
- **约束方程**：哈密顿约束和动量约束，它们是初始数据必须满足的方程，不包含时间导数
- **演化方程**：描述3维度规和外曲率随时间的演化

这个分解是数值相对论的基础，也是我们理解时空动力学的基础。在我们的理论中，ADM分解不是人为的，而是分形迭代的自然结果：每一层分形迭代对应一个时刻的3维空间，时间演化就是分形迭代的过程。

## 3.6 时空的拓扑结构

我们的宇宙在大尺度上是什么拓扑？观测表明宇宙是平坦的，空间曲率接近零，但拓扑可以是平坦的非平凡拓扑，比如3环面。

**命题3.6.1（宇宙的拓扑）**：根据分形自相似结构，宇宙的空间拓扑是3维球面$S^3$，因为分形迭代的闭螺旋轨道自然具有球面拓扑。宇宙是有限无边的，其半径约为$R\approx460$亿光年，这是可观测宇宙的半径。

**证明**：分形结构的基本单元是闭螺旋，螺旋的轨道在3维空间中的投影是球面，因此空间的大尺度拓扑是3球面。3球面是紧致、单连通、常正曲率的空间，但由于宇宙学常数的存在，空间的有效曲率为零，表现为平坦空间，这是因为宇宙学常数的排斥力抵消了空间的正曲率。$\square$

注：如果宇宙是3球面，那么朝一个方向一直走，最终会回到出发点，就像在地球表面一直走会回到起点一样。但由于宇宙膨胀的速度超过光速，我们不可能绕宇宙一周回到起点，因为在我们走完全程之前，宇宙已经膨胀得更大了。

## 3.7 4维时空的微分结构

如前所述，4维是唯一存在怪异微分结构的维数。什么是怪异微分结构？简单来说，存在同胚但不微分同胚的4维流形，也就是说，作为拓扑空间它们是一样的，但作为光滑流形它们是不同的，不能通过光滑坐标变换互相映射。

**命题3.7.1（时空的量子涨落与怪异微分结构）**：4维时空的怪异微分结构对应量子引力的涨落，在普朗克尺度，时空不是光滑的流形，而是具有不同微分结构的"泡沫"，这些不同的微分结构对应量子引力中的不同自旋泡沫构型。

这个洞见将微分拓扑和量子引力联系起来：量子引力的路径积分不仅要对不同的度规求和，还要对不同的微分结构求和。4维时空丰富的微分结构是量子力学不确定性的几何起源，我们将在第六卷详细讨论这个问题。

## 3.8 本章小结

本章我们证明了4维时空是唯一可能的宏观时空：只有在3个空间维中存在稳定的束缚态和长程力，能够形成结构和生命；其他维数要么引力太弱无法结团，要么引力太强导致坍缩。我们导出了4维闵可夫斯基度规，介绍了ADM3+1分解，讨论了宇宙的拓扑和微分结构。4维时空的所有特殊性质都是超复数结构和分形迭代的必然结果，不是巧合。

下一章我们将研究时间的本质，证明时间不是独立的维度，而是流形旋度的相位演化，导出时间箭头的起源。
