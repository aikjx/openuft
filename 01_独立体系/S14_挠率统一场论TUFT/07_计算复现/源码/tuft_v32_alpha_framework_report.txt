TUFT V3.2 分支TS9 - alpha 派生机制的充分条件框架（公理化 + 诊断目标量）
运行时间: 2026-10-07  Python 3.14.7

=== 约束 A1-A6（候选 U_Q(rho) 必须同时满足）===
  A1 静态解存在性：E-L 稳定点给两尺度晕轮廓（exp 尾）或相容；能量有下界
  A2 无 alpha 调参：不含为凑 alpha=1/137 设的无量纲自由参数；耦合由作用量自身固定
  A3 质量一致性：Mc2=M_core c2+U_EM；自能为明确定义占比（兼容 C0089 4.28% 张力）
  A4 点状电形状因子（C0091 硬约束）：电子尺度电 F~1；电荷有效半径 << lambda_C
  A5 涌现尺度：晕尺度由 lambda_C=1/M 涌现（C0081）；自能不改变 M 物理定义
  A6 可检验预言：至少给一个与 alpha 独立可测的量（c_geom、UV 调节函数）供证伪

=== 诊断目标量（候选作用量须复现）===
  D1 电磁自能占比 U_EM/Mc2 = c_geom*alpha = 5.8716*alpha ~ 4.2847%（exp 晕 c_geom=5.87164）
  D2 点状电约束：电有效半径 r_E 需 < ~1e-19 m（实验上限 1e-18 m）=> 自能须 UV 调节
     lambda_C = 3.861593e-13 m，故 r_E << lambda_C（差 ~6 量级）；lambda_C 尺度分布已被 C0091 证伪
  D3 质量分离：自能计入质量 => 裸核 M_bare = M_e(1-5.87alpha) = 0.957153*M_e = 8.719070e-31 kg
  D4 涌现尺度：lambda_C=1/M_nat=3.861593e-13 m；g=2 涌现（C0081）
     l_P=1.616255e-35 m（核/UV 尺度，~23892223814139513929728 倍小于 lambda_C）

=== 张力（为什么难）===
  T1 A4 vs 自能来自空间分布：点状电荷自能发散 => 需 UV 调节（核尺度 l_P）=> 即重整化
  T2 A2 vs 固定 alpha：含耦合常数的作用量总有调 alpha 自由，除非耦合由更深原理固定

=== 结论 ===
  纯空间几何难派生 alpha（张力 T1/T2）；alpha 更可能来自 QED 型 UV 调节（与 C0092 重定位一致；
  反常磁矩已归 QED）。本框架给出合法 alpha 派生的充分条件清单（A1-A6）与诊断目标量（D1-D4）；
  满足 A1-A6 且复现 D1-D4 的作用量 U_Q(rho) 即合法预言 alpha。
红线：本步为框架/公理，不含对 alpha 的虚构预言；alpha 仍为输入。
