----------------------------------------------------------------------

  1. 三胶子顶点 ggg：
     费曼规则：
     V^{abc}_{μνρ}(k1,k2,k3) = g_s f^{abc} [
       g_{μν}(k1-k2)_ρ + g_{νρ}(k2-k3)_μ + g_{ρμ}(k3-k1)_ν

     结构常数 f^{abc}：SU(3)有 12.0 = 12 个非零分量
     最大 |f^{abc}| = 1（如 f^{123}=1）

  2. 四胶子顶点 gggg：
     费曼规则：
     V^{abcd}_{μνρσ} = -i g_s² [
       f^{abe}f^{cde}(g_{μρ}g_{νσ}-g_{μσ}g_{νρ})
       + f^{ace}f^{bde}(g_{μν}g_{ρσ}-g_{μσ}g_{νρ})
       + f^{ade}f^{bce}(g_{μν}g_{ρσ}-g_{μρ}g_{νσ})
     ]

  3. 胶子自相互作用的螺旋几何化解释：
     - 胶子是螺旋运动的色场量子
     - 三胶子顶点 = 三个螺旋的耦合（螺旋合并/分裂）
     - 四胶子顶点 = 四个螺旋的散射（螺旋-螺旋散射）
     - 自相互作用导致胶子凝聚 → 真空是螺旋凝聚态

  4. 渐近自由的根源（胶子自相互作用）：
     - 夸克贡献：反屏蔽（类似QED，使耦合增强）
     - 胶子贡献：屏蔽（使耦合减弱）
     - 胶子贡献 > 夸克贡献 → 净屏蔽 → 渐近自由
     - b₀ = (11N_C - 2n_f)/3 = (33 - 2n_f)/3

     - 自相互作用强度由螺旋参数的重叠决定
     - 高能（短距离）→ 螺旋半径小 → 重叠少 → 耦合弱（渐近自由）
