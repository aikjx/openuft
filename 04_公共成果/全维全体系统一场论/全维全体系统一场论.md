## 二、引力的本源（G 由几何涌现）

引力不是「额外的作用」，而是普朗克尺度几何的固定点。三条恒等式在 80 位精度下机器零：

```
C01  m_P = √(ℏc / G)                        残差 0（定义式自洽）
C02  G   = ℏc / m_P²                        残差 0（G 由几何固定）
C03  √(Gℏc) / m_P = G                       残差 0（κ-Φ 桥接，v15 A01）
```

**含义**：把普朗克质量 `m_P = √(ℏc/G)` 作为几何标度锚，则牛顿常数 `G` 不再独立——它由 `ℏ, c, m_P` 的几何关系唯一确定。这是「引力本源」的核心可计算结论：**引力耦合是普朗克尺度上曲率/挠率幅值的几何结果，而非基本常数**。

A07（S05）进一步说明：在「几何由度规描述 + 广义协变 + ≤2 阶导数局域性 + 无 Ostrogradsky 鬼」四条假设下，Lovelock 定理（4D）唯一确定 EH 作用量 `S = ∫√-g (αR + 2Λ)`；螺旋公设贡献其源 `T^μν`（世界线作用量变分 `δS/δg ∝ u^μu^ν`）。EH 作用量本身不能被螺旋公设单点第一性推出——这是诚实残留缺口（见红线）。

## 三、四力方程（统一形式）

四力统一为**几何投影**：

```
F_i = α_i · ℏc / r²
```

| 力 | 耦合 α_i | 还原形式 | 验证编号 |
|---|---|---|---|
| 电磁 | α (精细结构) | `αℏc/r² = k_e e²/r²` | C04 |
| 引力 | α_grav = G m₁m₂/(ℏc) | `G m₁m₂/r²` | C05, C06 |
| 弱 | `λ_W = ℏ/(m_W c)`（力程） | 短程，由 W 质量定标 | C07 |
| 强 | `λ_π = ℏ/(m_π c)`（力程） | 短程剩余强相互作用 | C08 |

力比 `F_E / F_G = α (m_P/m_p)²`（C09，残差 3e-12，受 α 实验精度限制）把电磁与引力在同一条几何公式里对齐——二者相差仅一个「普朗克质量平方比」的几何因子。

**四力同源的几何判据**：普朗克极限 `α→1` 时 `κ̃ = τ̃ = 1/√2`（C21），四力在该极限下完全同源。

```
κ̃ = 1/√(1+α²)      τ̃ = α/√(1+α²)       κ̃² + τ̃² = 1   （C20，全粒子机器零）
```
