# 第 00 章 前言与体例

> 卷：卷0 · 元理论 | 生命周期：04_理论推导 | claims 引用：无（元文本）
> 红线声明：本章不声称任何物理结果；它只规定本书如何被写作、验证与证伪。

## 0.1 本书是什么

本书《统一场论》（OpenUFT 丛书）是对「统一场论」这一物理学终极目标的一次
**开放性、可审计、可证伪**的工程化呈现。它不是一部宣称「大功告成」的著作，
而是一部把**已证结论、已证伪拟设、未解问题**三者并列的诚实档案：
一个只列出成功的研究框架不是科学，是广告。

基线理论 **UFE-1** = ECSK 引力（含自旋挠率）+ 标准模型（含 3 个右手中微子），
通过 47 项机器验证（PASS 39 / FAIL 2 / INFO 6），但规范群仍是直积、26 个参数
仍是输入。因此本书的核心姿态是：**正确但不完整；诚实登记失败；给出通往
「真正统一」的路径与判据。**

## 0.2 八全维度定义（本书覆盖承诺）

1. **全维度**：时空维度（0–4D）、相空间、希尔伯特空间、纤维丛结构；
2. **全链路**：公理 → 定理 → 数值验证 → 预言 → 实验判据 → 证伪 → 归档；
3. **全体系**：UFE-1（统一场方程）、S02（空间光速螺旋统一力）、UFT-2/3（路径体系）；
4. **全属性**：质量、自旋、电荷、色荷、味、拓扑荷、能量动量；
5. **全元数据**：claims 登记、证据分级、版本快照、审计轨迹、机器门禁；
6. **全特性**：色散、螺旋、挠率、涡旋、禁闭、对称性破缺、耦合统一；
7. **全现象**：现象覆盖矩阵（09_现象覆盖矩阵.md）与证据强度分级；
8. **全基础理论**：微分几何、狭义相对论、电磁场论、量子力学、群论、广义相对论。

八维不是并列的装饰：**每一章都必须在某几维上产出可核验内容**，缺失的维度
在章首显式声明。

## 0.3 写作公约（算法联盟体例）

每章必须按以下顺序组织：

1. **红线声明**：先说自己不声称什么；
2. **正式陈述**：可判定的定理/命题，注明适用范围；
3. **解析求导证明**：逐步推导，标明引用（章-节-式）；
4. **数值验证**：零依赖可复跑脚本，残差给出量级与判据；
5. **结论分层**：已确认（verified）/ 已证伪（falsified）/ 已收窄（superseded）/ 开放（open）；
6. **开放项**：未解问题 + 建议路线；
7. **一句话结论**。

数字纪律：每个数字必须来自输入、具体信源或可复现计算；残差必须给出量级
（如 `~10⁻¹⁶` 浮点噪声、`0.5–1.0` 为 O(1) 硬破缺）；「已查证」与「一方称」严格区分。

## 0.4 验证协议（机器门禁）

- **claims.csv**：14 列登记表；evidence_level 在第 12 列、status 在第 13 列；禁止列漂移。
  - status ∈ {verified, falsified, open, superseded}
  - evidence_level ∈ {mathematical_result, numerical_check, experimental, observational}
- **verify.py**：门禁。`python3 -B verify.py` 全绿方可定稿。
- **module_catalog.py**：system.json 全量快照比对；source_records 变更必须 refresh。
- **生命周期**：04 推导 → 07 复现 → 08 预言 → 09 现象 → 11 证伪（负面不得删）→ 12 结论。

## 0.5 如何阅读本书

- **路线 A（从结论读）**：卷V ch29（否定清单）→ 卷III ch21（no-go）→ 卷II ch16（统一状态）。
- **路线 B（从基础读）**：卷I 全卷 → 卷II（UFE-1）→ 卷III（S02 螺旋）→ 卷IV（统一与预言）。
- **路线 C（从验证读）**：附录B（验证报告）→ 各章数值脚本 → claims.csv 反查。

每章末尾的「开放项」是本书最重要的部分之一：**它划定了本书不能回答的问题，
以及回答它们的路径。**

## 0.6 符号约定（本书全局）

- 自然单位：$c = 1$（在需要 SI 数值处显式恢复）；闵氏度规 $\eta_{\mu\nu}=\mathrm{diag}(1,-1,-1,-1)$。
- 弧长参数：$s$；4 速度 $u^\mu = dx^\mu/ds$，$u_\mu u^\mu=1$。
- Frenet 标架：$\{\boldsymbol t, \boldsymbol n, \boldsymbol b\}$；曲率 $\kappa$，挠率 $\tau$；
  Darboux 矢量 $\boldsymbol\omega_D = \tau\boldsymbol t + \kappa\boldsymbol b$。
- 电磁：$F_{\mu\nu} = \partial_\mu A_\nu - \partial_\nu A_\mu$；时谐 $\partial_t \to -i\omega$；真空 $\omega = k$。
- 能动张量：$T^{\mu\nu} = F^{\mu\alpha}F^\nu{}_\alpha - \tfrac14\eta^{\mu\nu}F_{\alpha\beta}F^{\alpha\beta}$。
- 角动量：$J_z = L_z + S_z$，$S_z = \sigma\hbar$，$L_z = l\hbar$（OAM 拓扑荷 $l$）。
- claims 编号：`体系-NNN`（如 S02-008、UFE-003）。
