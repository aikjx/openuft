## 测试中发现并修复的问题

1. 测试初稿把默认非零振幅误当成常量 θ，导致 5 个不合理失败案例；修正为振幅 0 后通过。
2. 测试内对 `pytest.approx` 使用单目负号导致对象操作错误；改为先取负值再比较。
3. 项目 `pytest` 直接命令与 `python -m pytest` 的导入路径不一致；正式入口统一用 `python run_all.py`。
4. Chromium 在当前安全环境阻止打开本地 `file://` URL；测试改用 `page.set_content` 加载同一份 HTML 后验证，不声称实际 URL 打开成功。
5. V108 已挂载目录未包含全部源码；独立解压原始 ZIP 后复跑历史测试，避免只检查片段。
