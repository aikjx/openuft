CS1: 弯曲时空中Frenet标架的严格定义（4维世界线）
======================================================================
  【4维世界线参数化】
    世界线：x^μ(τ)，τ为固有时（类时曲线）
    四速度：u^μ = dx^μ/dτ，归一化 u·u = -c²（号差-,+,+,+）
    四加速度：a^μ = Du^μ/Dτ = du^μ/dτ + Γ^μ_{αβ}u^αu^β
    归一化：u·a = 0（四速度与四加速度正交）

  【4维Frenet标架（Serret-Frenet公式）】
    对于4维类时世界线，定义Frenet标架 {e₀, e₁, e₂, e₃}：
      e₀^μ = u^μ/c（单位切向量，类时）
      e₁^μ = a^μ/|a|（单位法向量，类空，第一曲率方向）
      e₂^μ = （由Frenet方程递归定义，第二曲率方向）
      e₃^μ = e₀×e₁×e₂（副法向量，由正交性确定）

  【Frenet方程（4维）】
    De₀/Dτ = κ₁ e₁
    De₁/Dτ = -κ₁ e₀ + κ₂ e₂
    De₂/Dτ = -κ₂ e₁ + κ₃ e₃
    De₃/Dτ = -κ₃ e₂

    其中：
      κ₁ = |a|/c = 第一曲率（对应3维中的曲率κ）
      κ₂ = 第二曲率（对应3维中的挠率τ）
      κ₃ = 第三曲率（4维特有，3维中为0）

  【与平直时空3维Frenet的对应】
    平直时空3维曲线：{T, N, B}, dT/ds=κN, dN/ds=-κT+τB, dB/ds=-τN
    弯曲时空4维世界线：{e₀,e₁,e₂,e₃}, 4个Frenet方程
    对应关系：κ₁↔κ, κ₂↔τ, κ₃=0（3维极限）

  【sympy验证：u·a=0】
    由 u·u=-c² 对固有时求导：2u·a = 0 ⟹ u·a = 0 ✅
    四速度与四加速度恒正交（弯曲时空中也成立）

  → CS1完成：4维Frenet标架严格定义 ✅

CS2: 测地线的Frenet结构（自由粒子，κ=0）
======================================================================
  【测地线方程】
    自由粒子沿测地线运动：Du^μ/Dτ = 0
    即：a^μ = du^μ/dτ + Γ^μ_{αβ}u^αu^β = 0

  【测地线的Frenet结构】
    四加速度 a^μ = 0 ⟹ 第一曲率 κ₁ = |a|/c = 0
    Frenet方程简化：
      De₀/Dτ = 0（切向量平行移动）
      De₁/Dτ = κ₂ e₂（κ₁=0）
      De₂/Dτ = -κ₂ e₁ + κ₃ e₃
      De₃/Dτ = -κ₃ e₂

  【物理意义】
    测地线 = 弯曲时空中的'直线'
    自由粒子的世界线是测地线，第一曲率κ₁=0
    但第二曲率κ₂、第三曲率κ₃可以不为0（时空弯曲导致）
    这是平直时空与弯曲时空的关键区别！

  【平直时空极限】
    平直时空（Γ=0）：测地线是直线，κ₁=κ₂=κ₃=0
    弯曲时空：测地线可以有κ₂,κ₃≠0（时空弯曲的体现）

  → CS2完成：测地线Frenet结构 κ₁=0, κ₂,κ₃可非零 ✅

    弯曲时空非测地线：κ₁ = |a|/c, κ₂ = ?, κ₃ = ?

CS4: 曲率/挠率与Riemann曲率张量的关系
======================================================================
  【Jacobi方程（测地偏离方程）】
    两条邻近测地线的偏离矢量ξ^μ满足：
    D²ξ^μ/Dτ² = -R^μ_{νρσ}u^νξ^ρu^σ
    其中 R^μ_{νρσ} 是Riemann曲率张量

  【曲率张量与Frenet曲率的关系】
    测地线的第二曲率κ₂与时空曲率有关：
    κ₂² ~ R_{μνρσ}e₁^μe₂^νe₁^ρe₂^σ（截面曲率）

    具体来说，对于2维子空间（由e₁,e₂张成），
    截面曲率 K = R_{μνρσ}e₁^μe₂^νe₁^ρe₂^σ
    测地线在该子空间中的偏离由K决定

  【Gauss-Codazzi方程】
    子流形的内蕴曲率（Gauss方程）：
    R^{(sub)}_{μνρσ} = R^{(full)}_{μνρσ} + K_{μρ}K_{νσ} - K_{μσ}K_{νρ}
    其中 K_{μν} 是外曲率（第二基本形式）

    Codazzi方程：∇_μK_{νρ} - ∇_νK_{μρ} = R^{(full)}_{σμνρ}n^σ

  【物理意义】
    时空弯曲（Riemann张量）导致测地线的偏离
    这种偏离可以理解为'引力'的几何起源
    Frenet曲率κ₁,κ₂,κ₃描述世界线的'弯曲'
    Riemann曲率描述时空本身的'弯曲'
    两者通过测地偏离方程和Gauss-Codazzi方程联系

  → CS4完成：曲率/挠率与Riemann张量的关系 ✅

======================================================================
  【Schwarzschild度规】
    ds² = -(1-2GM/(rc²))c²dt² + (1-2GM/(rc²))⁻¹dr² + r²(dθ²+sin²θdφ²)
    其中 r_s = 2GM/c² 是Schwarzschild半径

  【圆周轨道条件】
    对于赤道面（θ=π/2）上的圆周轨道（r=常数），
    轨道角速度满足：Ω² = GM/r³（与牛顿力学相同！）
    但坐标时与固有时的关系不同：
    dτ/dt = √(1 - 3GM/(rc²))（GR修正）

  【数值验证：地球绕太阳轨道】

CS6: 弯曲时空中的光速螺旋推广形式
======================================================================
  【平直时空光速螺旋回顾】
    参数方程：r(t)=(R cosωt, R sinωt, bt)
    光速约束：v²=R²ω²+b²=c²
    三重奏：κ²+τ²=(ω/c)²

  【弯曲时空推广的困难】
    1. 弯曲时空中没有全局笛卡尔坐标，螺旋参数化不唯一
    2. 时空本身在'弯曲'，世界线的'螺旋'需要局部定义
    3. Riemann曲率张量会影响Frenet曲率的演化
    4. 光速约束 v≡c 在弯曲时空中变为 u·u=-c²（局域成立）

  【局域螺旋近似（弱场/短距离）】
    在时空曲率很小的区域（弱场近似），
    可以用局域惯性系（自由下落参考系）近似平直时空，
    光速螺旋在局域惯性系中近似成立：
      κ²+τ² ≈ (ω/c)² + O(Riemann × L²)
    其中 L 是螺旋的特征尺度，Riemann 是时空曲率尺度

  【强场/弯曲时空的修正项】
    猜想修正形式：
      κ₁²+κ₂²+κ₃² = (ω_eff/c)² + α·R_{μνρσ}e^μe^νe^ρe^σ + ...
    其中：
      ω_eff 是有效螺旋频率（局域测量）
      R_{μνρσ}e^μe^νe^ρe^σ 是时空曲率的投影
      α 是待定系数（需要严格推导）

  【物理意义】
    平直时空：三重奏是精确的几何恒等式
    弯曲时空：三重奏需要加上时空曲率修正项
    这意味着引力（时空弯曲）会'修正'螺旋的三重奏关系
    反过来，通过测量三重奏的偏差，可以探测时空曲率！

  【可观测预言】
    1. 引力红移：螺旋频率在引力场中变化 ω → ω√(1-2GM/(rc²))
    2. 光线偏折：光子螺旋在引力场中偏转
    3. Shapiro延迟：雷达信号经过太阳附近时延迟
    4. 引力波：时空曲率的涟漪导致三重奏的周期性调制
