## 1. 设定

四旋钮分两类扇区：

| 旋钮 | 扇区 | 含义 |
|---|---|---|
| $R$ | 几何 | 螺旋半径 |
| $b$ | 几何 | 螺距 |
| $\tilde g$ | 耦合 | 对偶规范耦合 |
| $\tilde g'$ | 耦合 | $U(1)$ 耦合 |

两个靶：

- $\alpha_{\rm couple}\propto \dfrac{\tilde g^{2}\tilde g'^{2}}{\tilde g^{2}+\tilde g'^{2}}$ —— **真 $\alpha$ 的代数原型**（耦合型，2 次齐次）
- $\alpha_{\rm geo}=\dfrac{R}{\sqrt{R^{2}+b^{2}}}$ —— 第62章的 $\sin\theta$（几何比值型）

约束清单：

| 编号 | 约束 | 扇区 | 齐次性 |
|---|---|---|---|
| $E_{\rm couple}$ | $\tilde g'^{2}-\tilde g^{2}/3=0$ | 耦合 | 齐次（2 次） |
| $E_{\rm pitch}$ | $b-\ell=0$ | 几何 | **非齐次**（砖①） |
| $E_{\rm radius}$ | $R-R_0=0$ | 几何 | **非齐次** |
| $E_{\rm couple}^{\rm abs}$ | $\tilde g-c=0$ | 耦合 | **非齐次**（需外界输入） |

## 3. 结论一：砖① 对 $\alpha$ 无效（块对角解耦）

对比 S0 与 S1/S2：

| 场景 | $\operatorname{rank}$ | $\operatorname{nullity}_{\rm dyn}$ | $\alpha_{\rm couple}$ | $\alpha_{\rm geo}$ |
|---|---|---|---|---|
| S0 | 1 | 3 | **自由** | **自由** |
| S1 | 2 | 2 | **自由** | **自由** |
| S2 | 3 | 1 | **自由** | 固定 |
| S3 | 4 | 0 | 固定 | 固定 |

**关键读数**：

1. 砖①（$E_{\rm pitch}$）确实**杀死了长度扇区的一条方向**（$\operatorname{nullity}_{\rm dyn}: 3\to2$）——它完成了几何标度破缺。
2. 但 $\alpha_{\rm couple}$ 的 $dq\|_{\ker J_E}$ **仍不为零**：因为 $J_E$ 在
   「几何 ⊕ 耦合」上**块对角**，几何约束的行在耦合列上全为 $0$，
   碰不到耦合扇区。
3. S2 把几何扇区**全部**钉死（$R,b$ 都定），$\operatorname{nullity}_{\rm dyn}$ 降到 1，
   但剩下的那 1 维恰好是**耦合整体标度方向**，$\alpha$ 依旧自由。

> **所以：无论加多少条几何标度破缺项，都不能锁定 $\alpha$。**

## 4. 定理 E 的严格版（齐次性障碍）

**命题（齐次性障碍）**：若约束 $E$ 在耦合上是 $d$ 次齐次函数（各项同次、无常数项），
则在约束面 $E=0$ 上，欧拉定理给出

$$\sum_i \tilde g_i\,\frac{\partial E}{\partial \tilde g_i}=d\,E=0,$$
即「耦合整体重标度方向」$s=(\tilde g,\tilde g')$ 恒属于 $\ker J_E$。

sympy 符号验证（举一般 4 次齐次式）：

```
E_hom = g~^4 + a4 g~^2 g~'^2 + c4 g~'^4          (4 次齐次)
sum_i g_i dE/dg_i  -  4 E_hom  =  0      (恒为 0)
```

**推论**：任何齐次约束系统都有 $\operatorname{nullity}_{\rm dyn}\ge1$（含标度方向），
故对一切依赖耦合整体标度的靶（$\alpha$ 型，2 次齐次）必有
$d\alpha\|_s = 2\alpha\ne0$ ⇒ **$\alpha$ 自由。这是定理 E 的严格形式。**

## 5. 定理 F（输入壁垒）

### 5.1 陈述

要杀死耦合扇区的标度方向（即让 $\alpha$ 的 $dq\|_{\ker J_E}=0$），
约束 $E$ 必须**非齐次**（含异次项或常数项）。而任何非齐次约束都必然
引入一个**不由该齐次结构本身决定的新系数**。该系数的来源穷尽为三类：

1. **实测值** ⇒ 落入定理 C 情形 2：$\alpha$ 恒可反解 ⇒ **定义，不是预言**；
2. **结构数**（整数 / 表示维数 / 有理数） ⇒ 解是**代数数**（见下），
   其命中必须靠数检索 ⇒ 由第58章 $V_3$ 判为 numerology；
3. **另一个无量纲本征值** ⇒ 问题**递归**（需先有那个本征值），不构成解锁。

三类均不解锁 UFT-3。∎

### 5.2 机制验证：非齐次约束确实能杀死标度方向

取整数系数的非齐次约束 $E=\tilde g^{4}-3\tilde g^{2}=\tilde g^{2}(\tilde g^{2}-3)=0$：

```
E_nh = g~^4 - 3 g~^2 = 0
解： g~ = sqrt(3)      (非零解为代数数 sqrt(3))
欧拉和 sum g dE/dg = 2*g**2*(2*g**2 - 3)  != 0  (在 g~^2=3 处为 18)
```

**验证通过**：非齐次约束确实把标度方向移出 $\ker J_E$（欧拉和不为零）。
但注意其非零解 $\tilde g=\sqrt3$ 是**代数数**——由整数系数产生的一切解都落在
代数数集内。这就是来源②的特征，也是它的天花板。

## 6. 定量检验：$\alpha$ 不是小分母有理数

来源②的危险在于「找一个结构比恰好等于 $\alpha$」。用连分数做定量筛查。

- 采用 $\alpha^{-1}=137.035999084$（CODATA 2018），不确定度 $\pm2.1e-08$

- $\alpha^{-1}$ 的连分数展开：$[137, 27, 1, 3, 1, 1, 16, 1, 10, 3, 1, 2,\dots]$

| 收敛子 $p/q$ | 小数 | 与 $\alpha^{-1}$ 之差 |
|---|---|---|
| 137/1 | 137.0000000000 | 3.600e-02 |
| 3700/27 | 137.0370370370 | 1.038e-03 |
| 3837/28 | 137.0357142857 | 2.848e-04 |
| 15211/111 | 137.0360360360 | 3.695e-05 |
| 19048/139 | 137.0359712230 | 2.786e-05 |
| 34259/250 | 137.0360000000 | 9.160e-07 |

- 分母 $\le 4000$ 的最佳有理逼近：$532933/3889$，误差 $1.125e-07$
- 进入 $100\sigma$ 所需的最小分母：$q^*_{100}=250$
- **达到 $1\sigma$（当前测量精度）所需的最小分母**：$q^*_{1}=4389$

**结论**：由群维数 / 表示论得到的结构数，其分母来自少量小整数的组合
（$SU(3)\times SU(2)\times U(1)$ 的维数 3/2/1、秩 2/1、Casimir 等，分母量级 $\lesssim 10^{2}$）。
而 $\alpha^{-1}$ 的连分数部分商含 $27$ 与 $16$（大数）⇒ 它对简单有理数**排斥**：
要逼近到当前测量精度（$1\sigma$），至少需要分母 $q^*_1\approx4389$。
这与可枚举的结构比集合在**分辨率上不可通约**。
注：本检验只排除**小分母有理数**；一般代数数（如 $\sqrt{3}$ 的组合）的穷尽搜索属 [C] 待建。
这与第56章 §56.3.3「纯数因子盲区」互补：那里说量纲矩阵看不见 $4\pi$；
这里说即使看见，结构数的分辨率也够不到 $\alpha$。

## 7. 判定汇总

| 项 | 结果 |
|---|---|
| 砖①（几何标度破缺）是否杀死长度扇区的标度方向 | **是**（$\operatorname{nullity}_{\rm dyn}:3\to2$） |
| 砖① 是否锁定 $\alpha$ | **否**（块对角解耦，$d\alpha\|_{\ker J_E}\ne0$） |
| 几何扇区全部钉死后 $\alpha$ 是否锁定 | **否**（剩 1 维恰为耦合标度方向） |
| 锁定 $\alpha$ 所需的最小改动 | 一条**非齐次耦合约束**（$E_{\rm couple}^{\rm abs}$） |
| 该约束的系数来源 | 实测（C2）/ 结构数（代数数，$V_3$ 判）/ 另一本征值（递归）——均不解锁 |
| 定量筛查 | $\alpha^{-1}$ 非小分母有理数（$q^*$ 见 §6） |
| **S13 / 联盟是否解锁 UFT-3** | **否** |
| UFT 联盟层达成度 | 仍 2/6（未实现） |

### 7.1 对第64章 §64.7 处方的**修正**（诚实自评）

第64章说：解锁缺口是「一条打破标度不变性的非齐次第一性原理变分项」。
本轮的实算表明该处方**必要但不充分**，应修正为：

> **必须是一条既非齐次、又作用于「耦合扇区」的约束**——只打破几何标度
> 不变性（砖①②）不够，因为 $J_E$ 的几何块与耦合块**解耦**。

这是本编的第一次**自我修正**：第64章的定理 E 正确地识别了「齐次性障碍」，
但把「打破标度不变性」当成了充分条件；定理 F 补上了「必须落在耦合扇区」
这一半。两半合起来，缺口才被完全刻画。

## 8. 诚实边界

### 已确认 [A]（sympy 精确）

1. 四场景的 $\operatorname{rank}(J_E)$ 与 $\ker J_E$ 实算：S0 1/3、S1 2/2、S2 3/1、S3 4/0。
2. 砖① 与几何钉死均不改变 $\alpha_{\rm couple}$ 的 $dq\|_{\ker J_E}\ne0$。
3. 齐次性障碍：4 次齐次式欧拉和恒为零（符号验证）。
4. 非齐次机制：$\tilde g^{4}-3\tilde g^{2}=0$ 的欧拉和不为零（$=18$ 于 $\tilde g^{2}=3$）。
5. 连分数与最小分母 $q^*$ 为数值精确结果。

### [B] 框架映射

1. 「几何扇区 / 耦合扇区」的划分是本册的建模选择；其正当性来自
   量纲/标度结构（几何旋钮带量纲、耦合旋钮无量纲），与第64章一致。
2. 定理 F 的「三类来源穷尽」是分类断言，依赖「新系数必须来自某处」
   这一物理前提——与定理 C 的「已测/未测二分」同源，边界相同。

### [C] 待建

1. **存在性搜索**：是否**存在**一条非齐次耦合约束，其系数全部为结构数而又
   恰好给出 $\alpha$？§6 只排除了**小分母有理数**；完整的代数数搜索未做
   （需对给定代数次数枚举）。这是可计算的，是真正的下一步。
2. **与 $V_3$ 的复合口径**：把「定理 F 排除的搜索空间」计入 $V_3$ 的 Bonferroni
   惩罚，可使 $V_3$ 对代数数靶也有免疫力（承接 §64.9 [C]2）。
