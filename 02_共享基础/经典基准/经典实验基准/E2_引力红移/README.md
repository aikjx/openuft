# E2 · 引力红移

## 观测结果

引力势 $\Phi$ 差导致的红移：

$$z = \frac{\Delta\lambda}{\lambda} = \frac{\Delta\Phi}{c^2}$$

- Pound-Rebka 实验（1959）：哈佛塔 22.6 m，验证精度 1%
- 现代验证：GPS 卫星必须修正引力红移，否则每天误差 ~10 km

## 物理机制

GR 中，弱引力场下时钟速率与引力势相关：

$$\frac{\Delta t}{\Delta t_0} = 1 + \frac{\Phi}{c^2}$$
