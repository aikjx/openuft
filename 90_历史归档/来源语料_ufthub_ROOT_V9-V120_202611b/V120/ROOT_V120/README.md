# ROOT V120 · 离散谱 / Yukawa 假设独立审计

> **研究用途，不是第五力发现，也不是四力统一证明。** 所有本包轨道加速度、红移和 Monte Carlo 数值均为理论模型/合成数据结果；本包没有真实卫星观测值。

## 交付内容

- `ROOT_V120_科研报告.md`：数学证明、V119 勘误、数值审计、物理解释和 OPEN 列表。
- `rootv120.py`：数值稳定的地球形状因子、五/六高度反演、谱检验、GLS 剖面拟合、近圆进动、引力势和时钟频移。
- `test_rootv120.py`：11 个通过的自动化测试，包括 mpmath 90 位精度交叉核验和双作用程反例。
- `run_analysis.py`：固定种子的 4×12,000 次噪声模拟、2,500 次三高度反演、合成双尺度留出验证、输出 CSV/JSON/PNG。
- `results/`：机器可读表格与统计数字；`figures/`：图片。
- `docs/实验预注册与真实数据验收.md`：数据、协方差、盲测与证伪标准。
- `sources.md`：可追踪的权威文献、使用范围与谨慎事项。
- `MANIFEST.sha256`：归档内文件校验码。

## 环境与一键复现

Python 3.11+；需要 `numpy scipy matplotlib pytest mpmath`。

```bash
python -m pip install -r requirements.txt
python -m pytest -q
python run_analysis.py > run_output.txt
```

测试执行记录：本环境 **11 passed**；MC 使用随机种子 `20261120`。运行生成结果应与 `results/metrics.json` 一致，浮点末位或软件版本差异除外。

## 最重要的勘误

V119 的 `H[1]/H[0]` 需要 **六高度**（K0..K5），不是五高度。新的真正五高度构造为

\[
q = \frac{D_0D_3-D_1D_2}{2(D_0D_2-D_1^2)},\qquad
\ell=-\frac{\Delta r}{\ln q}.
\]

但此式仅检验**重根指数多项式结构**，还需检测 Yukawa 模型强制的 `u/v=(ell+r0)/Delta`，并做独立留出数据验证。低噪声下有代数正确性，高噪声下不具稳健性。
