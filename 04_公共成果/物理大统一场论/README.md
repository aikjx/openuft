本目录是 openuft 项目内各独立体系（S01–S12）与 v8.1–v35 系列推导中**已通过求导证明或数值核验的公式**的收敛汇总。

> **诚实性声明（项目红线）**：本汇总仅证明「数学自洽」与「与已知实验值机器级一致」，**不声称**已被公认的大统一场论已经成立。凡标记为开放问题者均如实保留，未用循环论证掩盖。

## 公式覆盖范围

1. 几何骨架：Frenet 螺旋曲率/挠率、形变守恒恒等式、归一化本源方程、对偶反演（D01–D10）
2. 统一场方程与四力还原：Proca 型场方程、引力/电磁/弱力程/强力程（D11–D16）
3. 常数恒等式簇：ε₀/μ₀/c/G/ℓ_P、K\* 量纲审计（D17–D23）
4. 变分与 β 函数：Klein–Gordon、SM 2-loop 正确符号（渐近自由、无 Landau 极点）（D24–D26）
5. 拓扑涌现规范论 TEGT：SU(2)\_k 量子维度（φ 拓扑起源）、三代计数、B₃ 辫关系（D27–D29）
6. 宇宙学：EH + Λ 迹关系、FRW / Friedmann（D30–D31）

## 运行验证

```text
python 源码/verify_unified_field.py     # 求导证明 / 数值核验（31/31 PASS）
python 源码/精算分析.py                 # 80 位高精度精算 → 数据/精算数据表.md + .json（32/32 PASS）
```

> 精算脚本精度修正：初版误用 `mp.dps=80`（mpmath 模块无此属性，精度静默退化为 ~15 位），
> 已改为 `mp.mp.dps=80`，代数恒等式残差由 ~1e-16 提升到 ~1e-81（真·80 位机器零）。
