### 问题2：引力波频率公式不准确 🟡

**位置**：第三章第9节

**问题描述**：
引力波频率的公式和缩放关系描述不够准确。

**当前表述**：
```markdown
**公式**：$\displaystyle f \propto \sqrt{\frac{G M}{r^3}}$
**缩放关系**：$f \propto G^{1/2}$
**结论**：**仅与 G 成正比（平方根）；与 c 无关**

**物理意义**：引力波频率反映了产生引力波系统的动力学特性。对于双星系统：
- G 增大时，引力波频率略有增加（立方根关系）
- c 增大时，引力波频率也有增加，但相对更明显一些（2/3次方关系）
```

**问题分析**：
1. 缩放关系说"与c无关"，但物理意义中又说"c增大时频率增加"，矛盾
2. "立方根关系"应该是"平方根关系"
3. 对于轨道频率，实际上 $f \propto \sqrt{GM/r^3} = \sqrt{GM}/r^{3/2}$

**修复建议**：
```markdown
**公式**：$\displaystyle f \propto \sqrt{\frac{G M}{r^3}}$
**缩放关系**：$f \propto G^{1/2} r^{-3/2}$（对于固定轨道半径r）
**结论**：**对 G 正比（平方根）；对 c 无直接依赖**

**物理意义**：引力波频率反映了产生引力波系统的动力学特性。对于双星系统：
- G 增大时，轨道频率增加（平方根关系）
- 引力波频率通常是轨道频率的2倍
- 在牛顿近似下，频率与c无直接关系
- 但在后牛顿修正中，会出现c的依赖项

**注意**：这里的分析基于牛顿近似。在完整的广义相对论处理中，
引力波频率的演化会涉及c的高阶修正项。
```
