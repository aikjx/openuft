# C 级登记再校准机制（2026-10-30 · P3）

## 一、现状

- 520 项 C 级登记已补 `source`/`updated` 字段（5 个 CLEAR JSON 实改）：
  - **观测 = 55**（实测/约束/上限/最佳拟合：H0、S8、FIRAS、δ_CP、τ_e 等）
  - **判据 = 172**（判据/指标/归一化/阈值：value∈{1,0,0.5,2} 类判据占位）
  - **模型 = 83**（模型标度/参数窗口：Tc、能隙、截面、谱指数等）
  - **理论 = 210**（理论开放/诠释/严格化：千禧年类、构造性证明类）
- 登记值质量基准：2026-10-30 抽样审计 61 项（11.7%）0 硬错。

## 二、再校准流程（新实验发布 → 校准登记）

1. **触发**：任一观测类登记项对应的实验发布新结果（MOLLER sin²θ_W、XENONnT μ_ν、CMB-S4 H0/S8、LISA GW 背景、DUNE 质量排序、Lattice ε'/ε 等）
2. **定位**：按 `source=观测` 过滤 JSON，按 T 编号定位受影响条目
3. **校准**：mpmath 250 位代入新值，守卫区间按新实验误差带更新，`updated` 置为校准日期，旧值留痕于 JSON `prev` 字段
4. **登记**：校准变更记入《全维总成》§C 级登记变更日志（日期/项/旧值/新值/来源）
5. **纪律**：只更新观测类（55 项）；判据/模型/理论类不因实验变动（判据=口径恒定，模型=依赖输入另行评估，理论=不深攻）；不硬造闭合

## 三、字段规范

```json
{"source": "观测|判据|模型|理论", "updated": "YYYY-MM-DD", "prev": "旧值（校准后留痕，可省）"}
```
