# 第六章 · 三道障碍

前三章给的是"**能算什么**"。本章给的是"**算不出什么**"。后者更重要，因为前者可以靠更快的机器改进，后者不能。

三道障碍分别是：秩一、CP、简并。它们看起来是三个不同的技术问题，实则是同一件事从三个角度照过来。

## 6.1 第一道：秩一

### 6.1.1 设定

如果 Higgs 只局域在第五维的一个固定位置 `y_H`，所有五维 Yukawa 矩阵元都等于同一个常数 `y_*`，并且只有这一组耦合负责三代质量，那么

$$\tag{6.1} (M_e)_{ij}=\frac{v}{\sqrt2}y_*f_{L,i}(y_H)f_{R,j}(y_H).$$

注意 `i` 只出现在左边因子的第一个下标、`j` 只在第二个。所以

$$\tag{6.2} \boxed{\;M_e=C\,l\,r^{T}\;}\Longrightarrow\;\operatorname{rank}M_e\le1 .$$

这是**外积**。外积的秩恒为 1（除非某个因子为零），所以三代最多只有一个非零 Dirac 质量。

机核：奇异值 `(1.8831, 4.1e-18, 1.8e-34)`，rank=1（`S7a`）。

### 6.1.2 前提必须写全

这道障碍**只在"单一 brane Higgs ＋ 全同 Yukawa 矩阵元"时成立**。这是本书对上游最重要的一处补充，因为它极容易被误读成"brane Higgs 不能给三代质量"。

对照实验：改用对角 Yukawa（`y_i f_{L,i}f_{R,i}`，每代一个自己的耦合），立刻

$$\text{rank}=3,\qquad\text{奇异值}=(1.77693,\;0.105658,\;0.000511)\ \text{GeV}$$

（`S7b`）。**这三个数恰好就是三代质量本身。**

$$\boxed{\text{三代质量不是被 (6.1) 禁止，是被"普适 Yukawa"禁止。}}$$

正确的表述是"单一 brane Higgs ＋ 完全相同的 Yukawa 矩阵元 ⇒ rank≤1"，不可简化为"brane Higgs 不能给三代质量"。上游来料 §6 的表述本身是准确的、克制的（它明确写了"不排除沿第五维分布的 Higgs、非平凡 Yukawa 矩阵、多重标量"）；本书只补前提，不改结论。

## 6.2 第二道：CP

### 6.2.1 障碍

若所有质量矩阵与 Yukawa 耦合可同时取实，则混合矩阵实正交，Jarlskog 不变量

$$\tag{6.3} J=\operatorname{Im}\bigl(V_{us}V_{cb}V^*_{ub}V^*_{cs}\bigr)=0 .$$

这是 CP 破坏的充要量：`J=0` ⇔ 无 CP 破坏（在 CKM 框架内）。

机核：实正交 `V` 的 `J=0.000e+00`（`|V†V−I|=2.55e-17`）（`S8`）。

### 6.2.2 反命题不成立

同一组角度，加一个标准复相位 `δ=1.1`：

$$J=6.18\times10^{-4}$$

（`S8b`）。这个数与观测同量级，但——**能造出非零 `J`，不等于能解释观测到的 `J`**。

原因有两层：

- **量级**：`δ` 是自由参数，取任何值都给出不同的 `J`；这只是一个"可以有一相位"的证明，不是一个"相位必须是这个值"的推导。
- **来源**：复相位从哪来？若来自 Yukawa 矩阵的复数矩阵元，那是把 `J` 的起因推给了更深的输入；若来自自发 CP 破缺，需要一个能给出正确相位的标量势——两者在本链上都没有。

$$\boxed{\;\text{"全实参数 ⇒ 无 CP" 成立；"有复相位 ⇒ 有 CP" 成立；"有复相位 ⇒ 解释了 CP" 不成立.}\;$$

第三条与第二条差一个词，但差的是整个理论。

## 6.3 第三道：简并（本链最锋利的一刀）

### 6.3.1 定理

设三代共享**同一个背景** `Φ(y)` 与**同一味普适耦合** `λ`。则零模方程

$$\tag{6.4} \bigl[\partial_y+\lambda\Phi(y)\bigr]f_{L,i}(y)=0$$

对 `i=e,μ,τ` 给出同一个解：

$$\tag{6.5} f_{L,i}(y)=N\exp\Bigl[-\lambda\int_0^y\Phi(s)\,ds\Bigr]\quad(\text{与 }i\text{ 无关}).$$

于是质量矩阵与谱塔矩阵都是秩 1：

$$\tag{6.6} M_{ij}=\frac{v}{\sqrt2}y_*f_L(y_H)f_R(y_H)=C\,l_ir_j,\qquad S_{ij}\ \text{三行完全相同}.$$

### 6.3.2 机核

用 `φ⁴` kink 背景（`w=1.5`），以 `m_μ` 定共同 `λ`：

| 量 | 读数 |
|---|---|
| 共同 `λ` | `18.194710` |
| 三代质量 | `105.658375 / 105.658375 / 105.658375` MeV |
| 与真实谱偏差 | `+105.147 / 0 / −1671.272` MeV |
| `S` 本征值 | `−1.76e-16 / 8.42e-16 / 8.297` |
| 秩判据 `λ₂/λ₃` | `1.01e-16` |

（`T1a,T1b`）

### 6.3.3 杀伤面

这道定理读起来像同义反复——"三代用同一个函数，当然是同一个质量"。但它杀掉的东西比看起来多：

**它杀掉"精巧背景"这一整类想法。** 上游 V48 §8 把下一步押在

$$\bigl[\partial_y+\lambda_i\Phi(y)\bigr]f_{L,i}=0,\qquad\Phi\ \text{由自身作用量变分求出}$$

并希望"某个有物理依据的共同标量背景、规范对称性和边界条件，能够不逐代调节 `λ_i`，就产生三种不同且稳定的局域化本征态"。

定理 (6.6) 说：**不可能。** 理由在第二章 §2.2——一阶方程的解空间维数是 1，与 `Φ` 多精巧无关。`Φ` 是一个函数，一个函数只给一个解。

$$\boxed{\text{无论 } \Phi \text{ 多精巧，只要 } \lambda \text{ 味普适，三代就不会分开。}}$$

### 6.3.4 它同时改写了一句叙述

上游 V48 §1 说"独立求解的三代无量纲局域化参数"。定理 (6.6) 把这句话的含义翻转：

$$\boxed{\text{"三个 } z_i \text{" 本身就已经是三个味参数，不可能"由一个共同背景产生"。}}$$

因为它们必须由三个不同的 `z`（或三个不同的 `λ`，或三个不同的 Yukawa）产生——即必须由**味依赖**产生。这是本书对"三代局域化参数"这一表述的正式更正。

## 6.4 三道障碍是同一件事的三个投影

| 障碍 | 被禁止的写法 | 共同的形状 |
|---|---|---|
| 秩一 | 单一位置 Higgs ＋ 全同 Yukawa | 三代共用同一个"质量生成器" |
| CP | 全实参数 | 三代共用同一个"实相位" |
| 简并 | 单一背景 ＋ 味普适耦合 | 三代共用同一个"波函数" |

三者的共同形状是：**只要把"三代"当成三个同样的东西，就必然只剩一个自由度。**

这句话近乎同义反复，却是本链上唯一被严格证明过的结构性事实。它的反面是本书给后来者的建议：

$$\boxed{\text{三代的层级信息，只能存在于"三代不一样"的那个地方。}}$$

## 6.5 这三道障碍没有杀掉什么

必须对称地写清"没杀掉什么"，否则读者会误以为整条路线已死：

| 仍开放 | 状态 |
|---|---|
| 对角或非平凡 Yukawa 矩阵 | 可以给 rank 3（`S7b`） |
| 沿第五维分布的 bulk Higgs | 不受 (6.1) 限制（前提失效） |
| 多重标量 | 同上 |
| 味依赖 `λ_i` | 可以复现三代（但是拟合，见第七章） |
| 拓扑/指标机制 | 另一条路线（把 3 个连续参数压成 1 个整数） |
| 自发 CP 破缺 | 有复相位的可能来源，但需另一套势 |

**本书的态度**：这三道障碍不是"路线已死"的判决，是"这条路线上最便宜的三个出口已被封"的记录。剩下的出口每一个都要多付一样东西：味参数、拓扑量子数、或多重标量。
