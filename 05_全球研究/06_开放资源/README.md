# 全球开放资源

[全球研究](../README.md)

以下链接指向公开服务，说明使用中文。尚未下载具体数据或建立本项目镜像；引用与复现应指向具体记录及版本。

## arXiv 论文预印本

查找物理与数学原始论文，保留版本号；收录不等于同行评审通过。

[访问入口](https://arxiv.org/) · [官方说明](https://arxiv.org/)

## INSPIRE 高能物理文献

检索高能物理学术信息与原始来源。

[访问入口](https://inspirehep.net/) · [官方说明](https://help.inspirehep.net/knowledge-base/about-inspire/)

## CERN 开放数据

查找粒子物理数据、分析软件、环境和说明；使用具体数据前核对其版本与条款。

[访问入口](https://opendata.cern.ch/) · [官方说明](https://opendata.cern.ch/)

## Zenodo 研究成果存档

查找或归档研究成果，按具体记录引用；存档不代表科学审定。

[访问入口](https://zenodo.org/) · [官方说明](https://about.zenodo.org/)
