## 一、产品概述

### 1.1 核心功能

通过 10kV 高压电晕放电电离空气，定向加速单极性离子（正 / 负电荷二选一），兼具静电中和、灰尘去除与空气净化三重作用，离子风覆盖范围广、加速稳定性强。

### 1.2 电荷加速核心规律

加速电荷类型由「针尖极性」唯一决定（默认出厂为正极性，支持电路切换），具体参数如下：



| 针尖极性 | 加速电荷类型 | 核心离子成分  | 离子风速     | 核心优势       |
| ---- | ------ | ------- | -------- | ---------- |
| 正极性  | 正电荷    | O₂⁺、N₂⁺ | 10-15m/s | 稳定性强、击穿风险低 |
| 负极性  | 负电荷    | O₂⁻、N₂⁻ | 15-18m/s | 迁移率高、净化效率高 |

### 1.3 适用场景



* 正电荷加速：工业静电消除（中和负电尘埃 / 工件表面电荷）、电子厂元器件除静电、半导体车间粉尘净化；

* 负电荷加速：医疗场所空气净化（负离子杀菌）、实验室正电污染物中和、精密仪器静电防护。

## 二、工作原理（简化版）



1. 10kV 高压施加于离子风枪针尖，与接地平板形成针 - 板非均匀电场，针尖附近场强可达≈300kV/m（远超空气电离阈值 3kV/mm）；

2. 空气中的 O₂、N₂中性分子在高场强下发生电离，产生自由电子与正负离子；

3. 电荷分离与加速：

* 正极性针尖：带正电的针尖吸附自由电子，仅保留正离子，正离子在电场力作用下沿「针尖→平板」方向加速，形成正离子风；

* 负极性针尖：带负电的针尖排斥自由电子，电子快速附着于 O₂、N₂分子形成稳定负离子，负离子沿「针尖→平板」方向加速（与电场方向反向），形成负离子风；

1. 加速后的离子流兼具电荷传递（中和静电）与气流吹扫（去除灰尘）双重作用。

## 三、操作指南

### 3.1 极性选择与切换

#### 3.1.1 极性确认



* 查看设备铭牌标注（明确标注 “正离子风枪” 或 “负离子风枪”）；

* 无标注时，通过后续 “极性验证” 步骤确认。

#### 3.1.2 极性切换



1. 关闭离子风枪电源，拔掉高压线缆插头（确保断电操作）；

2. 打开高压发生器外壳，找到极性切换开关（或接线端子），按设备说明书调整接线（切换正负极接入）；

3. 重新连接线缆，通电前检查接线牢固性，避免高压放电。

#### 3.1.3 极性验证



* 工具：静电计或验电器；

* 方法：将验电器充电至带正电，靠近离子风枪出风口，若验电器快速放电则为负离子风（加速负电荷）；若验电器无明显放电，换用带负电的验电器，放电则为正离子风（加速正电荷）。

### 3.2 高效加速设置

#### 3.2.1 电极间距



* 默认安全间距：≥25cm（10kV 电压下避免击穿，符合 GB50169-92 标准）；

* 若需增强离子风强度，可在 25-40cm 范围内调整，超过 40cm 会导致加速效率下降（场强衰减）。

#### 3.2.2 环境控制



| 加速电荷类型 | 湿度要求   | 温度要求  | 备注           |
| ------ | ------ | ----- | ------------ |
| 正电荷    | ≤80%RH | 0-40℃ | 湿度超标易导致针尖结露  |
| 负电荷    | ≤50%RH | 0-40℃ | 湿度超标会加速负离子重组 |

#### 3.2.3 气压调节



* 输入气压范围：0.3-0.5MPa；

* 推荐气压：0.5MPa（空气消耗量约 380Nl/min，离子风覆盖面积最大，加速稳定性最优）；

* 调节方式：通过离子风枪配套调压阀旋钮顺时针增大、逆时针减小气压，观察压力表读数至目标值。

### 3.3 安全操作规范

#### 3.3.1 接地要求



* 接地体：采用镀锌钢管（直径≥20mm）或扁钢（宽度≥20mm），埋设深度≥0.6m；

* 接地线：选用截面≥2.5mm² 的铜芯线，宽度≥2 倍搭接长度，接地电阻≤4Ω；

* 验证：使用接地电阻测试仪检测，确保电阻值符合要求后再通电。

#### 3.3.2 人员防护



* 操作时必须佩戴绝缘手套（耐压等级≥10kV）、绝缘鞋，禁止徒手触碰针尖、高压线缆及接线端子；

* 设备周围 1m 范围内设置高压警示牌（标注 “高压危险，禁止靠近”），禁止非专业人员进入操作区域。

#### 3.3.3 高压叠加注意事项

若后续叠加 120kV 高压模块（总电压 130kV），需满足以下要求：



* 电极间距增至≥30cm；

* 更换耐压等级≥150kV 的高压线缆；

* 使用量程≥200kV 的数字分压器监测电压，避免过载击穿。

## 四、维护保养

### 4.1 针尖维护



* 清洁周期：每 200 小时运行后清洁一次；

* 清洁方法：用酒精棉轻轻擦拭针尖表面，去除电离残留的污垢、氧化物，维持针尖曲率半径≈0.1mm；

* 更换周期：当检测到场强下降≥20%（或针尖出现明显磨损、腐蚀）时，更换同规格抵抗连接型离子针（需匹配设备型号）。

### 4.2 配件维护



| 配件名称    | 维护周期   | 维护要求                                   |
| ------- | ------ | -------------------------------------- |
| 空气过滤器   | 每 3 个月 | 更换 0.2 微米规格过滤器，避免灰尘进入枪体影响电离效果          |
| 高压线缆    | 每月检查   | 检查屏蔽层完整性，避免机械损伤、老化开裂，线缆长度建议≤6m（减少电压损耗） |
| 调压阀、压力表 | 每 6 个月 | 校准压力表精度，清洁调压阀内部阀芯，确保气压调节顺畅             |

### 4.3 校准要求



* 校准周期：每 6 个月校准一次；

* 校准工具：法拉第杯、数字分压器、离子流测试仪；

* 校准项目：电压精度（误差≤±5%）、离子流稳定性（波动≤±10%）、加速速度（误差≤±1m/s）；

* 处理：校准结果超出允许范围时，联系厂家进行维修或调试。

## 六、注意事项



1. 设备运行时，禁止在出风口附近放置易燃易爆物品（避免电晕放电引发危险）；

2. 禁止在潮湿、多尘、腐蚀性气体环境中使用，否则会缩短设备寿命并增加安全风险；

3. 长期不使用时，需关闭电源、拔掉插头，将设备存放在干燥通风的环境中，定期检查配件完整性；

4. 本手册仅适用于 10kV 单极性离子风枪，若设备型号、规格变更，需参照对应技术文档操作；

5. 所有操作必须严格遵循本手册及设备说明书，违规操作可能导致设备损坏或人员触电风险。
