第三步：常数 f = √(Z/Z‘) · (c/2) 的推导与诠释

常数 Z 与 Z‘ 的定义与验证：
引力几何常数 Z： 定义为 Z = G c / 2。

量纲： [Z] = [G][c] = (L³M⁻¹T⁻²)(LT⁻¹) = L⁴M⁻¹T⁻³ 。这与理论中“空间位移条数流量密度”的量纲相符。
数值验证：代入 CODATA (2018) 值： G≈6.67430×10⁻¹¹ m³·kg⁻¹·s⁻² ， c=299792458 m/s ，计算得  Z ≈ 0.0100 m⁴·kg⁻¹·s⁻³ 。文档指出该值与理论预期高度吻合（《引力光速统一方程》元数据报告）。
物理意义： Z  表征时空“径向发散”运动模式（对应引力相互作用）的固有几何强度。
电磁几何常数 Z‘： 定义为 Z‘ = c / (8πε₀)。

量纲： [Z‘] = [c]/[ε₀] = (LT⁻¹)/(M⁻¹L⁻³T⁴Q²) = ML⁴T⁻³Q⁻² 。
数值与精确验证：代入  ε₀≈8.8541878128×10⁻¹² F·m⁻¹ ，计算得  Z‘ ≈ 1.347×10¹⁸ 。更重要的是，通过  Z‘  可精确导出精细结构常数 α： α = e²/(4πε₀ħc) = (2e² Z’)/(ħ c²) ，计算结果与实验值吻合度极高（相对误差 ~0.00065%），这是  Z‘  正确性的强有力证据（《电磁光速几何耦合常数Z'的第一性原理推导与严格验证》）。
