## 二、修正后的正确实现（要点）

**度规与结构方程（标准 GR-TOV，自洽）**
```
e^{-2λ} = 1 - 2Gm/(c²r)                         (由质量函数定义)
dp/dr = -G(ρc²+p)(m + 4πr³p/c²) / [r²c²(1-2Gm/(rc²))]     (★ TOV)
dρ/dr = (dρ/dp)·dp/dr ,   dρ/dp = 1/(Γ·K·ρ^{Γ-1})
dm/dr = 4πr²·ρ_eff
```
**修改闭包**（使 α=0 精确回到 GR，且额外曲率为 α-比例正项）：
```
ρ_eff = ρ + (c²/8πG)·(α/ρ_c)·e^{-2λ}·(dρ/dr)²/(ρ+ρ_min)
```
> 说明：你原文"α=0 即 GR 基线"在**场方程(4)原形式**下不成立——(4)在 α=0 给 R=0（迹自由理论），并非 GR 的 `R=8πG(ρ-3p/c²)/c²`。上述闭包把(4)解释为"对 GR 叠加 α-比例梯度项"，才使 α=0 严格还原 GR。这是对该预测唯一自洽的接入方式。

## 四、诚实结论（不粉饰）

1. **场方程(4)在核心处并非可忽略**（R_mod/R_GR≈7），但源项 `(dρ/dr)²` 恒正、且在星体表面密度梯度最陡处发散，形成**正反馈**——α=1.87 时系统数值发散/塌缩，得不到温和偏移。这是式(4)作为闭包 ODE 的**结构不稳定**，需对梯度项做饱和/正则化才能成物理理论。

2. **"α=1.87, 偏移 0.3~0.6 km, M_max≈2.01 M⊙"三件事不能同时成立。**
   - 要得到 0.3~0.6 km 偏移，α 需 ~0.01–0.03；

   ⇒ 该预言曲线在当前方程下**不可同时与质量约束和分辨率窗口兼容**。

3. **α=0 ≠ GR**（见第二节）。你给的"GR 基准 α=0"是概念错误，必须改用修正闭包。
