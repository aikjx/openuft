# ROOT V64 数学专著 III｜四种相互作用的共同作用量、真实一致性条件与新模型候选

## 1. 两种“统一”绝不能混淆

**形式的统一**：将引力作用量、标准模型作用量和候选场写成一个积分。可以做到，完全不意味着它们有相同本源。

**动力学的统一**：从一个先于这些场的基本结构，独立推导规范群、重力、粒子多重态、耦合常数、质量谱、相位结构，并事前给出新预测。ROOT 目前未做到。

## 2. 一致的已知基线：GR + Standard Model [C]

采用自然单位（`ℏ=c=1`）和 `(-+++)` 号差，概念上可写

`S_baseline = ∫d⁴x√−g [(M_P²/2)(R−2Λ) − (1/4)∑_A F^A_{μν}F_A^{μν} + L_fermion + L_Higgs + L_Yukawa]`。

`M_P²=1/(8πG)` 是**输入的**约化普朗克质量平方（该等式在自然单位下成立）。规范群 `SU(3)_C×SU(2)_L×U(1)_Y` 与手征表示、Yukawa 常数、Higgs 势参数都先验写入。

- 变分 `g^{μν}`：`G_{μν}+Λg_{μν}=8πG T_{μν}`。
- 变分规范场：`D_μ F^{Aμν}=J^{Aν}`（电流系数按定义吸收耦合）。
- 变分标量：`D_μD^μH−∂V/∂H†=...`（与 Yukawa 项相关）。
- 变分费米场：曲率背景中的协变 Dirac 方程。

这些都是已有理论的结构；“四个场方程并列”不是新统一机制。

## 3. 为什么线性速度投影不足以解释规范作用 [P/S]

在经典电磁学中，测试电荷 q 的洛伦兹力：

`F_EM=q(E+v×B)`，

`v·(v×B)=0`、`B·(v×B)=0`。

电场力 `qE` 可与重力 `mg` 平行、反平行或不垂直。只要改变 q 的符号，不改变给定瞬间的粒子位置和速度，电磁力就改变符号。这提供一个严格**反例**：如果力仅是 `r(t)` 的几何曲率和角度决定、没有任何附加电荷信息，就不可能唯一确定电磁力。要解释电荷，必须提供独立的内部自由度或从更深结构导出它。

一般非阿贝尔规范场的场强：

`F^a_{μν}=∂_μA^a_ν−∂_νA^a_μ + g f^a_{bc}A^b_μA^c_ν`。

与电磁学相比，存在由 `f^a_{bc}` 决定的非线性规范自耦合。它们不是从三维欧氏 Frenet 标架的三个正交方向自动得出。完整强/弱理论还需要手征表示、Higgs 机制、量子异常抵消、重整化与 QCD 禁闭的解释。

## 4. 关于引力的自旋 2 一致性 [C]

在已知的自旋 2 研究路线中，如果假设质量为零的自旋 2 模式及必要的一致性、自耦合和普适耦合要求，可以在一定条件下重建广义相对论的非线性结构。该结论并不确定耦合常数 G 的数字，也不推出物质场的标准模型结构。不能把这种有条件重建再包装为 ROOT 已经证明了 G 起源。

## 5. 一个可以严格变分的 ROOT 候选延伸 [S]

选择与标准模型无直接电荷耦合的复标量 `Ψ`，设

`S_candidate=∫d⁴x√−g [ (M_0²/2)R − g^{μν}∇_μΨ*∇_νΨ − μ²|Ψ|² − ξ R|Ψ|² + L_SM ]`。

它是标准的非最小耦合标量–引力有效理论类型（作为 ROOT 候选时并无原创验证），且 `M_0, μ, ξ` 都是自由参数。

整理曲率系数：

`[M_0²/2−ξ|Ψ|²]R = (M_eff²/2)R`，

`M_eff²=M_0²−2ξ|Ψ|²`。

若只讨论局部缓慢变化的背景并忽略导数混合，形式上 `G_eff=1/(8πM_eff²)`（自然单位）。对 `|2ξΨ²/M_0²|≪1`，

`ΔG_eff/G_0≈2ξ Δ|Ψ|²/M_0²`。

**这不是无需参数的 G 预测。** 严格的可观测加速度还受到标量涨落、物质耦合方式、参考系、屏蔽机制、边界条件和完整场方程影响，不能直接用上式推断所有材料的自由落体差异。

### 5.1 候选标量方程

对 `Ψ*` 变分得到

`(□−μ²−ξR)Ψ=0`（忽略自相互作用与其他耦合）。

若另有势 `V(|Ψ|²)`，相应出现 `−∂V/∂Ψ*` 项。新场可以拥有相位涡旋，但是否存在、稳定、普遍充满时空、是否等价于“空间光速螺旋”，均未由模型证明。

### 5.2 约束和稳定性条件

`M_eff²>0` 是不让曲率动能系数翻号的必要检查之一；还需要二阶扰动的 ghost、梯度稳定性检查、背景/宇宙学解、局域太阳系引力实验约束和有效理论截止自洽性。只检查 `M_eff²>0` 不足以证明所有解稳定。

## 7. 一个明确可证伪但尚未由 ROOT 得出的试验参数化

选择在牛顿势中加入 Yukawa 修正：

`V(r)=−Gm₁m₂/r·[1+α_Y exp(−r/ℓ_Y)]`。

负梯度求得径向引力相对牛顿基线的修正

`Δg/g_N=α_Y(1+r/ℓ_Y)exp(−r/ℓ_Y)`。

`α_Y` 是额外相互作用强度，`ℓ_Y` 是作用距离。两者必须由候选理论推导或通过独立实验拟合，不可宣布它们源自空间螺旋角。程序通过数值微分交叉核验势的导数与这个表达式。

如果某个实现给出成分依赖的加速度，必须与 MICROSCOPE 数据比较：`η(Ti,Pt)=[−1.5±2.3(stat)±1.5(syst)]×10^-15`（文献原文；注意系统误差、模型依赖和检验构型）。这不能被错误地当作所有类型新力通用的同一参数上限。

此外，GW170817 与 GRB170817A 的观测时差约 1.7 秒，为模型中引力波传播速度、色散与额外自由度提供严苛约束；需处理源端发射时差，不可简单直接把 1.7 秒除以传播总时长当作精确模型检验。
