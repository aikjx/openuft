    β(α) = μ dα/dμ = (2α²/3π) · Σ_f N_{c,f} Q_f²  > 0   (费米子圈，α 随能标增大)

D. 三重奏框架内 α 重构（κ_e·r_e 恒等链）
==============================================================================

  经典电子半径 r_e = e²/(4πε₀m_ec²) = 2.81794032236905e-15 m
  约化康普顿波长 λ̄_C = ħ/(m_ec) = 3.8615926719863e-13 m
  电子螺旋曲率 κ_e = 1/λ̄_C = 2589605079930.99 1/m
  康普顿角频率 ω_e = m_ec²/ħ = 7.76344072161797e+20 rad/s
  α = r_e/λ̄_C            = 0.00729735257374926  (恒等链1)
  α = κ_e·r_e            = 0.00729735257374926  (恒等链2：曲率×电荷半径)
  α = ω_e·r_e/c          = 0.00729735257374926  (恒等链3：频率×半径/光速)
  三者与 CODATA α 相对偏差 = 6.0970902e-10

  【诚实标注】上述三条链是 α 定义的代数重排（重言式），不是预言：
  它们没有减少自由参数。三重奏要宣称"解开 α"，必须满足判据 F1-F3。

E. 数值巧合候选谱系测试（证伪判据）
==============================================================================
  目标：1/α = 137.035999083696，判据精度 ≤ 1e-8（CODATA 相对不确定度 1.5e-10）

  c1: 1/α ≈ 137（整数近似）                        = 137.0   偏差 0.000262698   ✗ 不达标
  c2: 1/α ≈ 2π·21.81（π 缩放）                   = 137.03627155   偏差 1.98828e-6   ✗ 不达标
  c3: 1/α ≈ 4π³ + 13（π³ 组合）                  = 137.025106721   偏差 7.94854e-5   ✗ 不达标
  c4: 1/α ≈ 2·(2π)³/2.31（纯 π 幂）              = 214.762089561   偏差 0.567195   ✗ 不达标
  c5: 1/α ≈ e^π + e^e（超越组合）                  = 38.2949548743   偏差 0.720548   ✗ 不达标

  搜索结论：常见超越数组合在 1e-8 级全部落空（如上 5 例），
  而"凑出 1e-8 的组合"必然依赖多参数拟合 → 无预测力（overfitting）。
  判定：纯数值巧合路线【不可证伪 → 无科学内容】，排除。

  证伪判据（α 几何起源的可接受标准）：
    F1. 无自由参数（表达式只含已确定常数/几何量）；
    F2. 预测精度 ≤ 1e-8（与 CODATA 2022 相对不确定度 1.5e-10 兼容的显著水平）；
    F3. 有动力学推导链（从公理经变分/量子化/RG 到 α），而非事后拟合。
  目前（2026-09-07）无任何候选同时满足 F1-F3 → α 几何起源维持 OPEN。
