## 二、修补后的公理体系（TUFT 公理化 v2 草案）

### 公理0′（时空与 Cartan 结构）
`(M,g)` 为 4 维光滑可定向赝黎曼流形，符号 `(-,+,+,+)`。基本几何为 **Cartan 几何** `(P→M, ω)`，模型空间 `ISO(1,3)/SO(1,3)`，联络 1-形式取值
```
ω = ( ω^{ab} , e^a )   ∈  iso(1,3) = so(1,3) ⊕ ℝ⁴
```
曲率与挠率 2-形式：
```
R^a_b = dω^a_b + ω^a_c ∧ ω^c_b ,        T^a = de^a + ω^a_b ∧ e^b
```
`e^a` 是**焊接形式（soldering）**；正是焊接使得 `T^a` 成为曲率型对象。度量由焊接给出：`g_{μν} = η_{ab} e^a_μ e^b_ν`。

### 公理1′（规范结构为附加丛，非「统一」）
内部规范群 `G_int = (SU(3)×SU(2)×U(1))/Z₆` 的丛 `P_int → M` 与上述 Cartan 几何 **并列**，两者仅通过物质场最小耦合相连。
**明确声明**：直积结构不产生任何群论关系（`so(1,3)⊕u(1)⊕su(2)⊕su(3)` = 18 维 vs 单群 `SU(5)` 24 维），故本体系**不主张**「四力归一」；「归一」需另设大统一嵌入，而 `SL(2,C)` 非紧、不能嵌入紧致单群 ⇒ 二者只能分项申报。

### 公理2′（几何权重场与归一化）
```
Ω(x) = φ(x)/f ,   [φ]=M¹ ,  [f]=M¹
```
`φ` 为 `M` 上正则实标量场。**分名约定**：`Ω(x)` 为局域场，`⟨Ω⟩ = θ₀ = 11/16` 为宇宙学平均值（后者的地位见公理3′）。
**取消**原「`Ω∈[0,1]` 作为场的硬约束」；若保留为模型假设，须声明其后果（限制势的形状）。

### 公理3′（作用量，量纲已配平）
```
S = ∫ [ R/(2κ)  +  ξ·(Ω R T)/(2κ M_P)  +  L_φ  +  L_int ] √-g d⁴x

L_φ = -½ g^{μν} ∂_μ φ ∂_ν φ - V(φ)
V(φ) = V₀ (φ/f - θ₀)² + Λ_eff        θ₀ = 11/16 （唯象外锚）
```
可选（若采用 R9 的 (b) 分支，给挠率动力学）：
```
L_T = -(β/4) T^a_{μν} T_a^{μν}        （β 无量纲，独立耦合）
```
量纲逐项核验（`ħ=c=1`，`[M]^n`；`R=2, T=1, Ω=0, d⁴x=-4, √-g=0, 1/2κ=2, M_P=-1`）：
`R/(2κ)`: `2+2-4=0` ✓；`ξΩRT/(2κM_P)`: `2-1+0+2+1-4=0` ✓；`½f²(∂Ω)²`: `0+2+2-4=0` ✓；`V(φ)`: `0+4-4=0` ✓；`βT²`: `0+2-4=…`→ 需写成 `(β/4)T²` 且该项以 `√-g` 权重进入时为 `4-4=0` ✓（`T²` 的密度量纲为 `[M⁴]`，与 `L_int` 同类）。

**新增自由度账（诚实披露）**：`ξ, β, f, V₀, θ₀, Λ_eff` —— 6 个新参数。本修补**不与**「减少自由参数」的叙事相容；它换来的是写形合法与可检验性。

### 公理4′（曲率饱和：外加唯象边界条件）
```
|R| ≤ K_sat = 1/l_P²
```
**地位声明**：这不是动力学方程，也不是「无奇点定理」，而是**外加的构型约束**。量级核验（脚本 §4）：

| 天体 | `1/r_h² / K_sat` | `Kretschmann / K_sat` |
|---|---|---|
| 1 M☉ | 2.995e-77 | 1.076e-152 |
| Sgr A* | 1.620e-90 | 3.148e-179 |
| M87* | 7.089e-97 | 6.030e-192 |

⇒ 对一切已知黑洞相差 `76.5～152` 个数量级，**只在普朗克曲率区生效**，现阶段不可检验。
另注：Schwarzschild 真空 `R=0` 使该约束被平凡满足；真正发散的是 Kretschmann（`[M⁴]`），与 `R`（`[M²]`）不是同一个量。

### 公理5′（变分与场方程，符号自洽）
对公理3′ 的 `φ` 变分（真实 Euler–Lagrange，脚本 §3）：
```
□φ = V′(φ) -  ξ l_P R T /(2κ f)          ,  □ = g^{μν}∇_μ∇_ν   （签名 -+++）
```
- 与原文 `□Ω - V′ - αRT = 0` 的差别：`V′` 与耦合项**异号**（原文同号，两项全反）。
- 动能号已修正 ⇒ `H = ½π² + ½|∇φ|² + V ≥ 0`，平面波色散 `ω² = k² + V′′`（无虚频）。
- 由 `V=V₀(φ/f-θ₀)²` 得**真空位移**（可检验形式）：
```
⟨Ω⟩ = θ₀ +  ξ l_P ⟨R T⟩ / (4κ V₀)
```
**两项直接后果（新增、可判定）**：
1. 在 `R=0` 的真空（如 Schwarzschild 外区）耦合项恒为零 ⇒ `Ω` 与几何在该区**解耦**；
2. 若采用 EC 代数约束（宇宙学尺度自旋密度≈0 ⇒ `⟨T⟩≈0`），则 `⟨RT⟩≈0` ⇒ **该耦合项在宇宙学上惰性，无法解释 `θ₀=11/16` 本身**。要让它起作用，必须走 R9(b) 分支（挠率有独立动力学）或引入非零背景挠率。

### 公理6′（拓扑荷：Nieh–Yan）
```
W_NY = (l_P²/16π²) ∫_{M₄} ( T^a∧T_a − R_{ab}∧e^a∧e^b )  = (l_P²/16π²) ∫ d(e^a∧T_a)
```
- 量纲：`T²` 与 `R e e` 同为 `[M²]` 的 4-形式，乘 `l_P²` ⇒ 无量纲 ✓（原 `∫T∧T` 差 `l_P²`）。
- 恰当形式 ⇒ 在适当拓扑/边界条件下给出整数值（Nieh–Yan 数），是**真正的**不变量候选。
- 原文 `W=(1/8π²)∫_Σ T∧T` 的两处问题同时解决：`Σ` 维数不再歧义（须 4 维）、`T^a` 自由指标被收缩。
- **撤回**「半整数环绕数」：既有精算实算 Gauss 环绕数为整数 `-1.0000`。

### 公理7′（守恒律）
采用含挠 Bianchi 恒等式，能量动量守恒形如 `∇̂_μ T^{μν} = 源项(挠率–自旋)`；若采用 EC 守恒律须显式声明。

### 公理8′（极限归属）
```
ξ→0 或 Ω→0 且 β=0：真空 ⇒ GR + SM；含自旋物质 ⇒ 有效 Einstein–Cartan 接触项
T→0：GR + SM
β≠0：挠率有传播自由度 ⇒ 真正的 Einstein–Cartan 推广（这才是 EC 的「TUFT 增量」位置）
```
