# 科学来源与资料溯源

1. CODATA 2022 基本常数： https://physics.nist.gov/cuu/pdf/JPCRD2022CODATA.pdf 。其中 `G_ref` 带实验不确定度，`c` 为 SI 定义精确值。
2. Panda et al., *Measuring gravitational attraction with a lattice atom interferometer*, Nature 631, 515–520 (2024), https://www.nature.com/articles/s41586-024-07561-3 。文章报告 `33.3±5.6(stat)±2.7(syst) nm/s²`，其已发表实测数据**未进入本包模拟 CSV**。
3. NIST Fundamental Physical Constants, https://physics.nist.gov/cuu/Constants/ 。
4. Isaac Newton/Poisson 球壳定理、Yukawa 势的均匀球体体积积分、最小二乘理论：数学方法，不以特定天文观测作为模型信号的证据。
5. ROOT V83（用户前版）作为实验语言与双传感器奇偶对称设计的历史参考，V84 的所有测试及数据在本包内独立可复算。

所有参考数值、单位、假说和结果状态应以相应代码及 `PROOF_STATUS.md` 为准；链接需联网打开，本包本身不联网。
