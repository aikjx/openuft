## 2 求导链证明要点

### 2.1 Frenet-Serret（C02）

螺旋 `R(θ)=(ρcosθ, ρsinθ, bθ)`，弧长参数 `s=θ·√(ρ²+b²)`：

```
T = dR/ds = (-ρsinθ, ρcosθ, b)/L,        L=√(ρ²+b²)
dT/ds = (-ρcosθ, -ρsinθ, 0)/L²
κ = |dT/ds| = ρ/(ρ²+b²)          ✓（C02）
N = (-cosθ, -sinθ, 0)
B = T×N = (b sinθ, -b cosθ, ρ)/L
dB/ds = (b cosθ, b sinθ, 0)/L²
τ = -N·dB/ds = b/(ρ²+b²)          ✓（C02）
```

### 2.2 基底速率（C24/C39）

`R'(t)=ω(-ρsinθ, ρcosθ, b)` ⇒ `|R'| = ω√(ρ²+b²) = (c/L)·L ≡ c` —— **解析恒等**（由光速约束定义，非数值巧合）。

### 2.3 Binet 方程（C59）

标准恒等式：`u''+u = -f_r(1/u)/(h²u²)`，`u=1/r`，`h=r²φ̇`。

- **开普勒**：`f_r=-GMu²`、`h²=GM·p` ⇒ 右端=`GM/h²=1/p`；椭圆 `u=(1+e·cosφ)/p` 数值验证 `u''+u=1/p`（250 位一致）。
- **GR 1PN**：`u''+u = GM/h² + 3GM·u²/c²`（水星参数抽样一致）。
- **符号判定（C59 核心）**：草稿力律 `F_r=-GMm/r² + GMm·λgΦ0/r⁴` 经标准 Binet 变换应得 **负号** `-GM·λgΦ0·u²/h²`，草稿写作正号 ⇒ 与自身力律不自洽；匹配 GR 需 `λgΦ0=-3h²/c² = -2.4568e14`（负值）——复核与登记一致。

### 2.4 薛定谔量纲（C58）

`-ℏ²d²/ds²`：ℏ 量纲 `[M·L²·T⁻¹]` ⇒ `[ℏ²]/[L²] = [M²L²T⁻²]`（动量²）。`V0` 无量纲时 `V(s)=V0·ω²/c²` 具 `[L⁻²]`；三项互不一致——复核与登记一致。
