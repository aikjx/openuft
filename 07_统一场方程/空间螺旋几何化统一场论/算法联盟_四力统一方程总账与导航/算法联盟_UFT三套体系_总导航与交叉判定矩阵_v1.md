## 4. 关键交叉判定（哪些主张跨体系被否定 / 不矛盾）

**① #19 的 NF-2（四力无公共交点 / SM 三耦合不汇聚）vs #21 的「四力统一场方程」**
- **不矛盾**。#21 的「统一」是**动力学结构层**（四力服从同一形式场方程，靠源荷/力程/符号区分）；NF-2 指向的是 **RGE 耦合汇聚层**（SM 三耦合在已知能标不交汇、四力无公共统一能标）。
- #21 自身诚实标注「四耦合常数 G,α,α_W,α_S 均为实验输入，未第一性推导」——即它**未反驳** NF-2。二者在「耦合常数汇聚」上一致（都未达成）。

**② #19 与 #21 在「耦合常数/质量谱未第一性推导」上完全一致**
- #19：质量谱/绝对标度/耦合汇聚/U(1)_Y 群结构仍外部（O-MASS/O-SCALE/O-GUT/O-COUPLING）。
- #21：测量锚开放项 α（螺距比未推出数值）、Λ（非零残值未推出）、G 循环、四耦合输入、代质量层级缺口 ~500×。
- 二者是**物理 UFT 的两条平行高完成度候选路线**，路径不同但诚实边界同源。

**③ #20 与 #19/#21 正交**
- #20 是数学统一纲领竞技场，**无实验裁判**；#19/#21 受实验约束（#21 的 v14 压力测试即例）。
- 任何「数学上统一了 X 与 Y」的纲领成就，**不构成**物理 UFT 突破；反之物理 UFT 的数值还原也**不评级**数学纲领。

**④ #19 实验窗口关闭 vs #21 实验正面攻击**
- #19 多个可检验窗口已关闭（g-2 偏差 74.96%、EDM 超上限 1.28e16 倍、β 跑动定理 N 满足度 0、ringdown 反射壁被 LIGO 排除 5.74σ）。
- #21 的 α/Λ/SM 群结构正面攻击（v31–v35）多为 FAIL（诚实标注为测量锚/物理硬边界），但**未出现伪证伪**（v33 已驳斥旧 N=137 伪推导）。
- 二者共同揭示：**当代物理 UFT 的瓶颈是耦合常数与质量谱的第一性推导**，非动力学结构。

## 5. 决策树：遇到一个新的「统一场论」主张如何判定

```
新主张 M
 ├─ M 是「数学结构的统一」（范畴/同调/表示/导出）→ 进 #20 竞技场评估（无实验裁判）
 ├─ M 是「物理四力/标准模型+GR 的统一」
 │   ├─ 主张「四力动力学形式统一」（同一方程/同一几何来源）→ 对照 #21 GAQ-UFT 路径
 │   │     └─ 判定：结构统一可接受；若宣称「耦合常数/质量谱已第一性推导」→ 触发 X25，驳回
 │   ├─ 主张「自旋/统计/规范量子数拓扑编码」→ 对照 #19 TUFT 路径
 │   │     └─ 判定：编码框架可接受；若宣称「质量谱/耦合汇聚已第一性产生」→ 触发 X23，驳回
 │   └─ 主张「四力耦合常数在单一能标汇聚（GUT 式）」→ 对照 #19 NF-2 / #21 B 类测量锚
 │         └─ 判定：当前三套体系均无此能力 → 标记为「开放/未解」，不得宣称已统一
 └─ M 是「三套体系的合并结论」→ 触发 X26，禁止合并评级为「已突破」
```
