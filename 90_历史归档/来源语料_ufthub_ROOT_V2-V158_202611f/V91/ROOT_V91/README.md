# ROOT V91 — Noise-aware identifiability research prototype

Requires Python 3.10+ and numpy. Run `python run_all.py` from this folder.

`results/design.json` records actual results of the executable model. This package is NOT a quantum-gravity discovery or a physical experiment sensitivity forecast. Shape columns are individually normalized, and noise is arbitrarily chosen. It tests identifiability only, not the absolute physical signal size.

`src/v90_model.py` is copied from the inspected ROOT V90 source for continuity; ROOT V90 ZIP is not embedded.
