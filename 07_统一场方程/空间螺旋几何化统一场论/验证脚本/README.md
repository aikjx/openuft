# 验证脚本 · 空间螺旋几何化统一场论

> 本目录为该理论体系提供**独立复算层**。上层文档（`00_核心理论体系总纲.md`、
> `01_全维评级与诚实边界.md`）的评级此前全部是**人工审计**、且依赖原文献自陈的
> 「精算 PASS」。本目录用 CODATA 常数 + 纯数学恒等式把能复算的部分重算一遍。

## 1. 环境依赖

| 项 | 要求 |
|----|------|
| Python | **3.8+**（实测 CPython 3.8 / 3.11 均可） |
| 第三方库 | **无**。仅 `math / csv / os / re / sys / importlib` 标准库 |
| 操作系统 | 与平台无关（脚本内已做 GBK 控制台 `errors="replace"` 保护） |
| 网络 | 不需要 |

> 刻意**不引入** sympy / mpmath：本体系的判定只在双精度（1e-16）量级上有意义，
> 高精度不会改变任何结论，却会引入依赖与不可复现风险。

## 3. 复现步骤

```
cd 07_统一场方程/空间螺旋几何化统一场论/验证脚本

python run_all_checks.py            # 生成 audit_report.md
python run_all_checks.py --stdout   # 只打印不落盘
python spiral_geometry_audit.py     # 只跑数值复算
python csv_validate.py              # 只跑 CSV 校验

python rerun_source_scripts.py --timeout 900   # 放宽单脚本超时
```

退出码恒为 0：**审计脚本不因发现矛盾而失败**，矛盾体现在报告判定里。

> `rerun_source_scripts.py` 需要被复跑的脚本自身依赖（`mpmath` / `sympy` / `numpy` + `matplotlib`）；
> 其余脚本只用标准库。它把变异体写在临时目录，**不改归档**。

| 读数 | 值 |

| α 改错 1e-8 后判定与失败项均不变的脚本 | **4 / 7**（有判定语句的脚本） |
| α 改错 1e-8 后产物结论句逐字保留 | **3 / 3** |

三条最该记住的：

1. **失败项全是输入侧 / 阈值侧的。** `[FAIL] alpha = e²/(4πε₀ℏc)`、`G = 4πα³ℏcρ²/e²`、`G·e² = 4πα³ℏcρ²`
   是 CODATA 常数彼此的互验（口径问题）；`infinite_dimension_verification.py` 用 `1e-90` 去卡一个**截断到 100 项**的级数。
   把 α 改错 1e-8，这些失败项的**数目一个不变**（1→1、3→3、2→2）⇒ 与 α 的取值无关。
2. **结论句与算出来的数没有耦合。** 12 处结论句都不在任何条件分支内；把 α 改错 1e-8，
   产物里的结论句 **3/3 逐字保留**。最极端的一例：`infinite_dimension_verification.py`
   同一次运行里 9 条条目判定中有 2 条打「失败」，紧接着第 198 行仍打「✅ 所有验证全部通过！」、
   第 244 行仍往结果文件写「综合结论：所有验证全部通过！」——**归档的那份 txt 里没有任何失败痕迹**。
3. **两处口径的代码层原型**（把已有的 X13 落到实处）：
   `1.py` 第 106–112 行 `norm_total = ΣF_i / ΣF_j ≡ 1` —— 把恒等式当成「五力归一化 = 1」的检验；
   `core_verification.py` 第 57 行把「四力」补到 `1/α⁷` 才够过 `1e-10` 阈值
   （只取四力时缺口正是 X13 的 **2.836e-09**）。

⇒ 这批脚本能证明的只有一件事：**作者自己的定义链在代数上自洽**。
它不构成 α、G、ρ 取值的任何证据。本节不改变 §4 的任何判定，只把「原文献自陈的精算 PASS」
这一栏从「未纳入复算」改写为「已核验：**无信息量**」。

## 5. 误差来源说明

1. **常数精度**：全部取 CODATA 2018。`ε₀μ₀c²` 复算残差 4.34e-14（SI 2019 后 ε₀ 由 μ₀、c
   定义，该残差来自 ε₀ 的测定不确定度，非公式误差）。
2. **双精度截断**：恒等式类条目（S1-01/S1-02/S3-06）残差在 1e-16 量级，属浮点极限。
3. **文献取整**：文献大量使用 `α=1/137`（与 CODATA 差 0.026%）与 `c=3.00e8`。
   脚本对两种口径**分别计算**，不做统一，以便暴露口径漂移（见 X1）。
4. **量纲判定不受数值精度影响**：X8/X11/X14/X15 是符号级结论，与常数取值无关。

## 6. 哪些只是「拟合 / 恒等式」，不是第一性推导

| 条目 | 性质 | 说明 |
|------|------|------|
| S1-01/02/03 | 数学恒等 | Frenet 标准公式 + 定义式，无物理信息 |
| S2-01 α=τ/κ | **参数化** | 把已知常数 α 换写成几何比值，L1 重述 |
| S2-03 α=sin(1/(N+Δ_top)) | **反解** | N=137 是输入；Δ_top=0.0359 由 α 反解，无预测力 |
| S3-06/S7-01 | 几何级数恒等 | 数学恒等 |
| S4-01 | 恒等 + 语义诠释 | 三角恒等（L0）+ 阴阳映射（L1，不可证伪） |
| S5-01 ε₀μ₀=1/c² | **定义式** | SI 2019 后由定义保证 |
| S5-02 e²=4πε₀ℏcα | **由 α 定义反推** | 恒等式 |
| S5-03 G=ℏc/m_P² | **定义式** | 普朗克质量定义 |
| S5-05 ρ 反解 | **循环** | 由 G 反解 ρ，原文献已自陈 |
| S9-01 99.27% | 归一化约定 | 把 1/αⁿ 分配给某力是约定非推导 |
| S10-01/02 | 数学事实 | 素数性可验证，但与物理无因果关系 |

真正具有信息量、且被本轮判定为**不成立**的，恰好是理论最想成立的那几条：
`G` 的几何化（X8）、第五力（X11）、频率控制的场量纲（X14/X15）。
