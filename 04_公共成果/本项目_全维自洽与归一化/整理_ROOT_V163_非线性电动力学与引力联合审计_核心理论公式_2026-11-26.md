## 2. 核心理论体系公式链

### 2.1 作用量、场不变量与应力张量

采用来料约定 `c=1`、度规号差 `-+++`、`[ħ]=M L`、`[G]=L/M`，并取 `[F]=[H]=L^-4`：

1. 作用量：
   `S = ∫√(-g) [ R/(16πG) - ħ H(F) ] d⁴x`。
2. 电磁不变量：
   `F = Fμν F^μν / 4`。
3. 应力张量：
   `Tμν = ħ ( H_F Fμα Fν^α - gμν H )`，其中 `H_F = dH/dF`。
4. 纯磁球对称场：
   `B = Q_m / r²`，
   `F = Q_m² / (2 r⁴)`，
   `F' = -4F/r`。
5. 能量密度与主/切压强：
   `ρ = ħ H`，
   `p_r = -ρ = -ħ H`，
   `p_t = ħ ( 2 F H_F - H )`。

这里的 `H(F)` 是单不变量模型函数，不是完整双不变量 NLED 拉氏量。V163 的 BI 一栏只取纯磁单不变量分支 `H(F)=√(1+2F)-1`，不等同于完整 Born–Infeld 双不变量理论。

### 2.2 静态球对称度规、质量函数与守恒

1. 度规函数：
   `A(r) = 1 - 2G m(r) / r`。
2. 质量函数：
   `m'(r) = 4π r² ρ(r)`，`m(0)=0`（不另加中心点质量）。
3. 因 `p_r=-ρ`，另一度规函数可取常数。
4. 应力守恒：
   `p_r' + (ρ+p_r) A'/(2A) + 2(p_r-p_t)/r = 0`。
   因为 `ρ+p_r=0`，且 `p_r-p_t=-2ħF H_F`，代入 `F'=-4F/r` 后逐项相消，守恒式由纯磁径向依赖恢复。
5. 径向类时测地加速度（以固有时间求导）：
   `A' = 2Gm/r² - 8πG r ρ`，
   `r¨ = -A'/2 = -Gm/r² + 4πG r ρ`。
   该量是测地坐标加速度，不是任意测量仪读数。
6. 标量曲率：
   `T = gμν Tμν = 4ħ(F H_F - H)`，
   迹方程给出 `R_scalar = -8πG T = 32πGħ(H - F H_F)`。

### 2.3 纯磁背景传播判据

局部惯性系取背景磁场 `B` 沿 `z`，扰动波矢沿 `x`：

1. 线性本构：
   `δD = H_F δE`，
   `δH_vec = H_F δB + H_FF B (B·δB)`。
2. Maxwell 旋度线性化得到一种模式的速度平方：
   `v₁² = 1`；
   另一个为：
   `v² = 1 + 2F H_FF / H_F`。
3. 所检验方向的必要条件：
   `H_F > 0` 且 `H_F + 2F H_FF ≥ 0`。
   这只是定域、定方向特征速度判据，不等于全局 Cauchy 稳定性或完整动力学稳定性。
4. 若上述条件对所有 `F≥F0` 成立，则
   `(√F H_F)' = (H_F + 2F H_FF)/(2√F) ≥ 0`，
   积分得
   `H(F) ≥ H(F0) + 2√F0 H_F(F0)(√F - √F0)`。
   因纯磁 `√F∝r^-2`，中心密度 `ρ=ħH` 必有发散趋势；这是来料给出的正则磁黑洞限制的简单推导。

### 2.4 幂律窗与中心奇异性

令 `H ∼ C F^p`（`C>0`、`p>0`，导数同阶渐近）：

- `H_F ∼ p C F^{p-1}`；
- `H_FF ∼ p(p-1) C F^{p-2}`；
- 渐近传播速度平方：`v² → 1 + 2(p-1) = 2p - 1`；
- 中心质量积分：`∫ r² ρ dr ∼ ∫ r^{2-4p} dr`，在 `r=0` 收敛当且仅当 `p<3/4`；
- 非负渐近速度要求 `p≥1/2`；
- 因此 `1/2≤p<3/4` 同时给出有限质量与非负渐近 `v²`，但 `H` 在中心仍发散，故不是完整正则粒子构造；
- `p=1/2` 的边界需要检查次领先项，不能仅由领先幂判定稳定性。

## 3. 无量纲计算与模型读数

来料取 `x=r/L0`、`f=L0^4 F=x^-4`（选 `Q_m=√2`）、`H=L0^-4 h(f)`，并引入独立无量纲参数

`γ = 4πGħ / L0²`。

定义

`I(x)=∫₀ˣ t² h(t^-4) dt`，

`m = 4πħ I / L0`，
`A = 1 - 2γ I / x`，
`r¨ L0 = γ ( x h - I/x² )`，

### 3.3 中心正则性与传播速度的交叉约束

- Rational / Arctan：度规曲率中心有限，但规范场强与密度仍按幂律发散，且高场 `v²→-3`，所检验方向先失稳。
- Log：总质量有限，但中心曲率发散且高场 `v²→-1`。
- Born-Infeld 单不变量纯磁分支：总质量有限、所检验 `v²` 在有限场为正且趋于 `0`，但中心曲率仍发散，并且不是完整双不变量 Born–Infeld。
- Maxwell：中心质量积分发散，不绘制 `m(0)=0` 曲线。
- 因此这些模型共同呈现 V163 的核心障碍：有限质量、非负传播速度与中心完整规范场正则性不能在该单不变量纯磁族内同时成立。
