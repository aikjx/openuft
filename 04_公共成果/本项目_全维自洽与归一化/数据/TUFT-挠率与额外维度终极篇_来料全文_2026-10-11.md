## 25. 异致弦 GUT 模型的具体粒子谱

### 25.1 从 $E_8$ 到标准模型：破缺链的选择

$E_8$ 的维数为 248，秩为 8。其根系是 8 维空间中的 240 个向量。

**两条主要破缺链**：

**链 A（经 $SO(10)$）**：

$$E_8 \xrightarrow{\langle\Phi_1\rangle} SO(10)\times SU(4)_{\text{flavor}} \xrightarrow{\langle\Phi_2\rangle} SO(10)\times U(1)^3$$

$$\xrightarrow{\langle\Phi_3\rangle} SU(5)\times U(1)^4 \xrightarrow{\langle\Phi_4\rangle} SU(3)\times SU(2)\times U(1)^5$$

**链 B（经 $E_6$）**：

$$E_8 \xrightarrow{SU(3)_{\text{hol}}} E_6 \times SU(3)_{\text{family}} \xrightarrow{\text{Wilson line}} SO(10)\times U(1) \xrightarrow{\text{Wilson line}} SU(5)\times U(1)^2$$

$$\xrightarrow{\text{Higgs}} SU(3)_C\times SU(2)_L\times U(1)_Y\times U(1)_{B-L}$$

本文重点跟踪**链 B**，因为它在异致弦紧致化中自然实现。

### 25.2 $E_8$ 伴随表示的逐步分解

#### 第一步：$E_8 \to E_6 \times SU(3)_F$

$E_8$ 的 248 维伴随表示在 $E_6 \times SU(3)_F$ 下分解：

$$\boxed{{\bf 248} = ({\bf 78}, {\bf 1}) \oplus ({\bf 1}, {\bf 8}) \oplus ({\bf 27}, {\bf 3}) \oplus (\overline{{\bf 27}}, \bar{{\bf 3}})}$$

验证维度：$78\times1 + 1\times8 + 27\times3 + 27\times3 = 78 + 8 + 81 + 81 = 248$ ✓

物理解释：
- $({\bf 78}, {\bf 1})$：$E_6$ 的规范玻色子
- $({\bf 1}, {\bf 8})$：$SU(3)_F$ 的规范玻色子（"family symmetry"）
- $({\bf 27}, {\bf 3})$：三代物质场（每代在一个 ${\bf 27}$ 中）
- $(\overline{{\bf 27}}, \bar{{\bf 3}})$：反物质场（在有 Calabi-Yau 紧致化时，${\bf 27}$ 和 $\overline{{\bf 27}}$ 的零模数由 $h^{1,1}$ 和 $h^{2,1}$ 决定）

#### 第二步：$E_6 \to SO(10) \times U(1)_\psi$

$E_6$ 的基本表示 ${\bf 27}$ 在 $SO(10)\times U(1)_\psi$ 下分解：

$$\boxed{{\bf 27} = {\bf 16}_{1} \oplus {\bf 10}_{-2} \oplus {\bf 1}_{4}}$$

验证：$16 + 10 + 1 = 27$ ✓

物理解释：
- ${\bf 16}$：包含一整代标准模型费米子 + 右手中微子 $\nu_R$
- ${\bf 10}$：包含额外的 Higgs 二重态 + 色三重态（exotics）
- ${\bf 1}$：exotic singlet（可能是暗物质候选或 moduli 场）

**${\bf 16}$ 在 $SU(5)$ 下的进一步分解**：

$${\bf 16} = {\bf 10}_{1} \oplus \bar{{\bf 5}}_{-3} \oplus {\bf 1}_{5}$$

其中：
- ${\bf 10} = (u_L, d_L, u_R^c, e_R^c)$：左手夸克双重态 + 右手上夸克 + 右手电子
- $\bar{{\bf 5}} = (d_R^c, L_L)$：右手下夸克 + 左手轻子双重态
- ${\bf 1} = \nu_R^c$：右手中微子

这正是**一整代标准模型费米子 + 右手中微子**！

#### 第三步：$SO(10) \to SU(5) \times U(1)_\chi$

$$\boxed{{\bf 16} = {\bf 10}_1 \oplus \bar{{\bf 5}}_{-3} \oplus {\bf 1}_5}$$

$${\bf 10} = {\bf 5}_{-2} \oplus {\bf 5}_{2}$$

#### 第四步：$SU(5) \to SU(3)_C \times SU(2)_L \times U(1)_Y$

### 25.4 Wilson line 破缺的详细机制

设 Calabi-Yau 流形的基本群 $\pi_1(K) = \mathbb{Z}_n$（通过 freely acting involution 构造）。

Wilson line $W \in E_6$ 沿非收缩回路 $\gamma$：

$$W = \exp\left(\frac{2\pi i}{n}\,Q_V\right)$$

其中 $Q_V$ 是 $E_6$ 的某个生成元（选择决定破缺方向）。

**选择 $Q_V = Q_\chi$（$SO(10)$ 中的 $U(1)_\chi$ 生成元）**：

$$W = \exp\left(\frac{2\pi i}{n}\,Q_\chi\right)$$

在 $\mathbb{Z}_3$ 情况下（$n = 3$）：

对 ${\bf 27}$ 中各分量的作用（乘以 $e^{2\pi i q_\chi/3}$）：

| 分量 | $Q_\chi$ | 相位 $e^{2\pi i Q_\chi/3}$ | 是否不变 |
|------|----------|--------------------------|---------|
| ${\bf 16}$ | 1 | $e^{2\pi i/3}$ | 否 → 被投影掉？ |

等一下——这样会投影掉所有费米子。需要更仔细的选择。

**正确的选择**：$Q_V$ 应该使得标准模型粒子不变，exotic 粒子获得非平凡相位。

选取 $Q_V$ 为 $SU(5)$ 中 trivially acting 的生成元：

$$Q_V = \text{diag}(0, 0, 0, 0, 0 | q_1, q_2, q_3, q_4, q_5)$$

使得 ${\bf 10}$ 和 $\bar{{\bf 5}}$ 中的 SM 费米子有 $Q_V = 0$，但 ${\bf 10}$ 中的 exotic 部分有 $Q_V \neq 0$。

具体构造（以 $\mathbb{Z}_3$ orbifold 为例）：

定义 Wilson line $W = (1, 1, 1, \alpha, \alpha^2)$，其中 $\alpha = e^{2\pi i/3}$。

作用在 ${\bf 27}$ 的分量上：

- ${\bf 16} \to {\bf 16}$（不变，因为 $Q_V({\bf 16}) = 0$）
- ${\bf 10} \to \alpha\,{\bf 10}$（获得相位 $\alpha$）
- $\bar{{\bf 10}} \to \alpha^2\,\bar{{\bf 10}}$
- ${\bf 1} \to {\bf 1}$（不变）

在 $\mathbb{Z}_3$ orbifold 投影下，只有 $W$-不变的分量保留零模：

$$\boxed{n({\bf 16}) = h^{1,1}, \quad n({\bf 10}) = 0, \quad n(\overline{{\bf 27}}) = h^{2,1}}$$

**结果**：
- 三代 ${\bf 16}$ 保留 → 三代标准模型费米子 ✓
- exotic ${\bf 10}$ 被投影掉 → 无 exotics ✓
- $H_u, H_d$（在 ${\bf 10}$ 中）也被投影掉 → 需要另找 Higgs 机制（这是此类模型的难点）

## 26. 圈量子引力中挠率的量子化

### 26.1 圈量子引力 (LQG) 的基本框架

LQG 从 Einstein-Cartan 形式的广义相对论出发，将其改写为 $SU(2)$ Yang-Mills 型理论，然后进行正则量子化。

**Ashtekar-Barbero 变量**：

基本变量不是度规，而是：

- **Ashtekar 联络** $A_a^i$：$SU(2)$ 规范联络（$a$ 是空间指标，$i$ 是 $SU(2)$ 内部指标）
- **密度化的 triad** $E^a_i$：共轭动量

定义：

$$A_a^i = \Gamma_a^i + \beta K_a^i$$

其中 $\Gamma_a^i$ 是与 triad $e_a^i$ 相容的自旋联络，$K_a^i$ 是外曲率，$\beta$ 是 Barbero-Immirzi 参数（实数）。

**Poisson 括号**：

$$\{A_a^i(x), E^b_j(y)\} = \beta\kappa\,\delta_a^b\,\delta^i_j\,\delta^3(x-y)$$

### 26.2 挠率在 Ashtekar 变量中的角色

**关键洞察**：Ashtekar 联络 $A_a^i$ 本身就包含挠率的信息。

在有挠率时空中，自旋联络 $\omega_a^{IJ}$ 分解为：

$$\omega_a^{IJ} = \mathring{\omega}_a^{IJ}(e) + K_a^{IJ}$$

其中 $\mathring{\omega}$ 是无挠自旋联络（由 triad 唯一确定），$K_a^{IJ}$ 是 contortion。

在时间规范 (time gauge) $e_0^i = 0$ 下，$SU(2)$ 联络为：

$$A_a^i = \Gamma_a^i(e) + \beta K_a^i$$

其中 $\Gamma_a^i = -\frac{1}{2}\epsilon^{ijk}\mathring{\omega}_a^{jk}$。

**挠率的来源**：

$$K_a^{IJ} = \kappa\,s_a^{IJ}$$

代入 Ashtekar 联络：

$$\boxed{A_a^i = \Gamma_a^i(e) + \beta\kappa\,s_a^i}$$

**物理含义**：在 LQG 中，挠率（自旋密度）直接修改 Ashtekar 联络 → 修改 holonomy → 修改量子态。

### 26.3 Spin Network 态与挠率

LQG 的运动学 Hilbert 空间由 **spin network 态** $|S\rangle$ 张成。

一个 spin network 是图 $\Gamma$，其每条边 $e$ 标记 $SU(2)$ 自旋 $j_e$，每个顶点 $v$ 标记 intertwining 算子 $\iota_v$。

**holonomy**（沿边 $e$ 的联络平行输运）：

$$h_e[A] = \mathcal{P}\exp\int_e A_a^i\tau_i\,dx^a$$

其中 $\tau_i = -i\sigma_i/2$ 是 $SU(2)$ 生成元。

当有挠率时，$A_a^i = \mathring{A}_a^i + \beta\kappa s_a^i$：

$$h_e[A] = h_e[\mathring{A}]\cdot\mathcal{P}\exp\int_e\beta\kappa\,s_a^i\tau_i\,dx^a$$

**如果自旋密度 $s_a^i$ 集中在一条线上**（如宇宙弦或旋涡线），则 holonomy 获得额外相位：

$$\Delta h_e = \exp(\beta\kappa\,S^i\tau_i)$$

其中 $S^i = \int_e s_a^i\,dx^a$ 是沿线的总自旋。

**这意味着**：挠率在 spin network 中表现为**边的额外旋转**——相当于在边上插入了一个"自旋缺陷"。

### 26.4 面积算子的挠率修正

LQG 中的面积算子：

$$\hat{A}(\Sigma) = 8\pi\gamma l_{\text{Pl}}^2\sum_p\sqrt{j_p(j_p+1)}$$

其中求和跑过穿过曲面 $\Sigma$ 的 spin network 边，$j_p$ 是边 $p$ 的自旋，$\gamma = \beta$ 是 Immirzi 参数。

**挠率如何修正面积谱？**

在有挠率时，$E^a_i$ 的共轭变量关系被修改。Poisson 括号变为：

$$\{A_a^i(x), E^b_j(y)\} = \beta\kappa\delta_a^b\delta^i_j\delta^3(x-y) + \text{torsion corrections}$$

挠率修正来自 Dirac 括号的约束分析（当自旋密度非零时，第二约束的代数被修改）。

**结果**（Mercuri, 2006）：面积谱变为：

$$\hat{A}(\Sigma) = 8\pi\gamma l_{\text{Pl}}^2\sum_p\sqrt{(j_p + \delta j_p)(j_p + \delta j_p + 1)}$$

其中挠率修正 $\delta j_p \propto \kappa s$（$s$ 是穿过曲面的自旋通量）。

**对于微观挠率**（如 Planck 标度的自旋涨落），$\delta j_p$ 是 $O(1)$ 的修正——面积谱的**间距**被修改，但离散性保持。

### 26.5 Barbero-Immirzi 参数的物理意义

$\beta$ (Barbero-Immirzi 参数) 在经典理论中是不可观测的（不同 $\beta$ 的经典理论等价）。但在量子理论中，它出现在面积谱中，影响黑洞熵的计算。

**黑洞熵**（LQG 计算）：

$$S_{\text{BH}} = \frac{\ln 2}{\pi\sqrt{3}\beta}\frac{A}{4l_{\text{Pl}}^2}$$

要求 $S_{\text{BH}} = A/(4l_{\text{Pl}}^2)$（Bekenstein-Hawking 熵）：

$$\beta = \frac{\ln 2}{\pi\sqrt{3}} \approx 0.1274$$

**挠率对 Immirzi 参数的影响**：

当引入挠率（即自旋密度不为零）时，$\beta$ 的角色发生变化。

**Holst 作用量**（LQG 的起点）：

$$S_{\text{Holst}} = \frac{1}{2\kappa}\int e^I\wedge e^J\wedge\left(\star + \frac{1}{\beta}\right)F_{IJ}$$

在有挠率时，Holst 项 $\frac{1}{\beta}\int e\wedge e\wedge F$ 不再是拓扑不变量（其变化正比于挠率的 Nieh-Yan 不变量）：

$$d(e^I\wedge T_I) = T^I\wedge T_I - e^I\wedge e^J\wedge F_{IJ}$$

其中 $T^I = de^I + \omega^I{}_J\wedge e^J$ 是挠率 2-形式。

**Mercuri-Randono 结果**：在量子水平上，$\beta$ 不再是自由参数，而是被挠率的拓扑（Nieh-Yan 数）量子化：

$$\beta = \frac{n}{2\pi}, \quad n \in \mathbb{Z}$$

这意味着 **$\beta$ 的量子化来自挠率的拓扑量子化**——一个深刻的结果。

### 26.6 圈量子宇宙学中的挠率

**圈量子宇宙学 (LQC)** 是 LQG 在 FRW 宇宙学中的对称性约化。

基本变量：$(c, p)$，其中 $c \sim \dot{a}$，$p \sim a^2$。

经典 Hamiltonian 约束：

$$H = -\frac{3}{\kappa\gamma^2}c^2\sqrt{|p|} + H_{\text{matter}} = 0$$

LQC 的量子修正将 $c$ 替换为 $\sin(\mu c)/\mu$（holonomy 修正），导致 Friedmann 方程被修改：

$$H^2 = \frac{8\pi G}{3}\rho\left(1 - \frac{\rho}{\rho_c}\right)$$

其中 $\rho_c \sim 0.41\rho_{\text{Pl}}$ 是临界密度。

**加入挠率**（自旋密度 $s$）：

Hamiltonian 约束获得额外项：

$$H = -\frac{3}{\kappa\gamma^2}c^2\sqrt{|p|} + \frac{\kappa}{2}s^2|p|^{3/2} + H_{\text{matter}} = 0$$

修改的 Friedmann 方程：

$$\boxed{H^2 = \frac{8\pi G}{3}\left(\rho - \frac{\kappa}{4}s^2\right)\left(1 - \frac{\rho - \frac{\kappa}{4}s^2}{\rho_c}\right)}$$

**物理效应**：

1. **大爆炸奇点消除**：$\rho_{\text{eff}} = \rho - \frac{\kappa}{4}s^2$ 在 bounce 处达到 $\rho_c$，此时 $H = 0$，宇宙从收缩转为膨胀
2. **挠率使 bounce 提前**：$\rho_{\text{eff}} < \rho$，所以 bounce 在更低的 $\rho$ 处发生
3. **暴胀的自然起始**：bounce 后的膨胀相可以自然地进入慢滚暴胀

**数值估计**：对于 Dirac 场的自旋密度 $s \sim n\hbar$，在 Planck 密度 $\rho \sim \rho_{\text{Pl}}$ 处：

$$\frac{\kappa s^2/4}{\rho} \sim \frac{G n^2\hbar^2/c^4}{\rho} \sim \frac{G(\rho/m_p)^2\hbar^2}{c^4\rho} = \frac{G\rho\hbar^2}{m_p^2 c^4} \sim \frac{\rho}{\rho_{\text{Pl}}}\left(\frac{l_{\text{Pl}}}{\lambda_C}\right)^2 \sim 10^{-38}$$

即使在 Planck 密度，挠率修正仍然很小（因为 $\lambda_C \gg l_{\text{Pl}}$）。

**但如果考虑 Planck 标度的基本自旋激发**（如 spin network 本身的量子涨落），则 $s$ 可以很大，挠率修正可以在 bounce 处起主导作用。

### 26.7 挠率与圈量子引力的黑洞物理

**旋转黑洞的挠率**：

Kerr 黑洞的角动量 $J$ 可以在 LQG 框架中被重新解释为**挠率的宏观表现**。

在 Einstein-Cartan 理论中，角动量与自旋密度的关系：

$$J = \int_\Sigma s^{0ij}\,d^3x$$

对于宏观天体，这是自旋密度的积分。但在 LQG 中，黑洞的角动量量子化为：

$$J^2 = j(j+1)\hbar^2, \quad j = 0, 1, 2, \ldots$$

**关键联系**：黑洞视界的 spin network 态中，每条穿过视界的边贡献面积 $\sim \sqrt{j_p(j_p+1)}$ 和角动量 $\sim j_p$。

挠率的角色：在视界附近，spin network 的高密度产生有效的挠率场，修改视界几何。

**对黑洞熵的修正**：

$$S = \frac{A}{4l_{\text{Pl}}^2} + \alpha\ln\frac{A}{l_{\text{Pl}}^2} + \cdots$$

对数修正系数 $\alpha$ 在 LQG 中通常给出 $-1/2$。挠率的贡献修改为：

$$\alpha = -\frac{1}{2} + \delta\alpha_{\text{torsion}}$$

其中 $\delta\alpha_{\text{torsion}} \propto s^2 l_{\text{Pl}}^4$（在 Planck 标度可能有 $O(1)$ 修正）。

$$\Delta t \approx \frac{D}{2c}\left(\frac{m_T^2}{k_1^2} - \frac{m_T^2}{k_2^2}\right)$$

### 28.2 两条路线的交汇

在弦论/M 理论中，两条路线最终合流：

1. **挠率 = $H$-flux**：路线一的挠率张量在弦论中是 NS-NS 反对称张量场 $B_2$ 的场强
2. **超对称保证一致性**：路线二的超对称保证了路线一中挠率量子效应的可控性（消除发散）
3. **Strominger 系统**：保持超对称的紧致化**必须**包含挠率（$H$-flux），这意味着挠率不是修正，而是弦论几何的核心
4. **圈量子引力**：路线一的挠率在量子化后产生路线二中额外维度的某些效应（如 Immirzi 参数的拓扑量子化）

### 28.3 未解问题

1. **非微扰弦论**：$H$-flux 紧致化的完整模空间稳定化尚未解决
2. **量子挠率的传播**：圈量子引力中挠率是否获得传播自由度？
3. **SUSY 破缺机制**：如果超对称存在，其破缺的精确机制是什么？
4. **实验判决**：是否存在一个"smoking gun"实验，能同时检验挠率和额外维度？
5. **数学基础**：Strominger 系统的解空间分类（所有 torsional CY 的模空间）

### 28.4 哲学反思

两条路线代表了对引力本质的两种不同理解：

- **路线一（挠率）**：引力不仅是时空弯曲，还包括时空扭转。自旋与挠率的关系如同质量与曲率的关系——物质的内禀角动量弯曲了时空的"纤维"。
- **路线二（额外维度）**：引力的特殊性只是表象——所有力都是高维几何的不同投影。电磁力是第五维的曲率，弱力和强力是更高维的等距群。

在弦论中，这两种理解被统一：**时空不仅有曲率和挠率，还有额外的维度和超对称**。而所有这些几何结构都是同一个基本对象——弦——的不同振动模式。

也许最终的真相是：**几何本身就是物理**。从黎曼到嘉当，从 Kaluza 到 Strominger，这条线索指向同一个结论：自然界的力是时空几何的不同面相。
