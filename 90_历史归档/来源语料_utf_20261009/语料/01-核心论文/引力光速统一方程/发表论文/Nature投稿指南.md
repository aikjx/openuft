## Nature 格式要求

### 文章结构（严格遵守）

1. **标题** (≤20 words)
   - ✅ 当前：12 words
   - 要求：简洁、准确、吸引人

2. **作者与单位**
   - 格式：姓名¹ & 姓名²
   - 需要完整单位信息

3. **摘要** (≤200 words)
   - ✅ 当前：~150 words
   - 要求：独立完整、突出重要性

4. **正文** (≤3,000 words)
   - ✅ 当前：~2,000 words
   - 结构：引言→结果→讨论→结论
   - 无章节编号

5. **Methods** (无字数限制)
   - 详细的技术细节
   - 可重复性描述

6. **参考文献** (≤50篇)
   - ✅ 当前：10篇核心文献
   - Nature格式引用

7. **Extended Data** (≤10项)
   - 图表、补充分析
   - 支持主要结论

8. **Supplementary Information**
   - 详细推导
   - 额外数据

## 投稿流程

### 第一步：在线注册
- 访问：https://mts-nature.nature.com/
- 创建账户
- 完善个人信息

### 第二步：准备文件
1. **主文档**: Word (.docx) 或 LaTeX (.tex + .pdf)
2. **图表**: 单独文件，TIFF/EPS格式，300+ dpi
3. **补充材料**: PDF格式
4. **Cover Letter**: 单独文档

### 第三步：在线提交
1. 选择文章类型：Article
2. 上传主文档
3. 上传图表（按顺序）
4. 上传补充材料
5. 填写元数据（标题、作者、摘要等）
6. 上传Cover Letter
7. 建议/排除审稿人
8. 确认并提交

### 第四步：等待初审
- 时间：1-2周
- 结果：
  - 送审（进入同行评审）
  - 拒稿（可申诉或改投其他期刊）

### 第五步：同行评审
- 时间：4-8周
- 通常2-3位审稿人
- 可能结果：
  - 接受（罕见）
  - 大修后重审
  - 小修后接受
  - 拒稿

### 第六步：修改与回复
- 逐条回复审稿意见
- 修改稿标注变化
- 提交修改说明

### 第七步：最终决定
- 接受：进入出版流程
- 拒稿：可改投其他期刊

## 需要创建的图表

### Figure 1: 几何投影示意图

**内容要求：**
- 3D球面坐标系
- 投影到2D平面的过程
- 标注极角θ、方位角φ
- 显示投影效率μ(θ) = |cosθ|
- 标注几何因子η = 2

**技术规格：**
- 软件：Mathematica, MATLAB, 或 Python (matplotlib)
- 格式：TIFF或EPS
- 分辨率：≥300 dpi
- 尺寸：单栏(89mm)或双栏(183mm)宽
- 颜色：RGB或CMYK

**示例代码（Python）：**
```python
import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

# 创建球面
theta = np.linspace(0, np.pi, 100)
phi = np.linspace(0, 2*np.pi, 100)
THETA, PHI = np.meshgrid(theta, phi)

X = np.sin(THETA) * np.cos(PHI)
Y = np.sin(THETA) * np.sin(PHI)
Z = np.cos(THETA)

# 绘制3D图
fig = plt.figure(figsize=(10, 8))
ax = fig.add_subplot(111, projection='3d')
ax.plot_surface(X, Y, Z, alpha=0.3, color='blue')

# 添加投影平面
xx, yy = np.meshgrid(np.linspace(-1, 1, 10), np.linspace(-1, 1, 10))
zz = np.zeros_like(xx)
ax.plot_surface(xx, yy, zz, alpha=0.2, color='red')

# 添加标注
ax.set_xlabel('X')
ax.set_ylabel('Y')
ax.set_zlabel('Z')
ax.set_title('Geometric Projection: 3D Sphere to 2D Plane')

plt.savefig('geometric_projection.tiff', dpi=300, bbox_inches='tight')
```
