# 130kV离子风枪电荷加速路径COMSOL专属仿真配置

### 一、仿真文件核心说明



* 软件版本：COMSOL Multiphysics 5.6/6.0（兼容更高版本）

* 物理场模块：静电场（es）+ 漂移扩散（dd）+ 层流（spf）+ 粒子追踪（pt）

* 仿真类型：稳态仿真（含空间电荷效应耦合）

* 核心目标：验证针尖场强、离子漂移速度、加速路径形态与分析表一致性



***

### 二、几何模型参数（可直接复制到 COMSOL 几何命令行）



```
// 1. 全局参数定义（先在“全局定义-参数”中添加）

r\_tip = 0.1\[mm];          // 针尖曲率半径（工业离子风枪典型值）

L\_needle = 5\[mm];         // 针尖长度

D\_plate = 5\[cm];          // 平板电极直径

d\_gap = 30\[cm];           // 电极间距（安全阈值）

thickness\_plate = 2\[mm];  // 平板厚度

V\_total = 130\[kV];        // 总叠加电压（10kV+120kV）

// 2. 几何建模（3D模型，按以下步骤操作）

// 步骤1：创建针尖（旋转几何体）

Sketch 1: 绘制线段（起点(0,0)，终点(L\_needle, 0)）+ 半圆（半径r\_tip，中心(L\_needle, 0)）

Revolve 1: 绕Z轴旋转360°，生成针尖实体

// 步骤2：创建平板电极（拉伸几何体）

Sketch 2: 绘制圆（圆心(0,0)，半径D\_plate/2）

Extrude 1: 拉伸厚度thickness\_plate，位置沿Z轴平移d\_gap（与针尖间距30cm）

// 步骤3：创建空气域（包围电极）

Sphere 1: 球心(0,0,d\_gap/2)，半径d\_gap\*1.2（确保完全包裹电极）

Boolean 1: 减去针尖和平板实体，得到空气域（介质区域）

// 步骤4：网格划分（关键加密设置）

Free Tetrahedral Mesh:

\- 针尖表面及周围5cm区域：尺寸控制→单元大小=1\[μm]（捕捉高场强梯度）

\- 平板表面及周围10cm区域：单元大小=1\[mm]

\- 空气域其余区域：单元大小=5\[mm]

\- 网格质量：最小扭曲度≤0.3（确保收敛）
```

### 三、物理场设置（按模块顺序配置）

#### 1. 静电场（Electrostatics, es）—— 电场分布计算



| 配置项    | 具体设置                                                               |
| ------ | ------------------------------------------------------------------ |
| 介质属性   | 空气域：相对介电常数 εᵣ=1.0005（标准大气压 25℃），电导率 σ=1e-16 \[S/m]                 |
| 边界条件   | - 针尖表面：电压边界，V=V\_total（130kV）- 平板表面：接地边界（V=0）- 空气域外边界：零电荷边界（无电场泄漏） |
| 空间电荷耦合 | 启用 “空间电荷密度”（ρ=q\*(n₊-n₋)），后续与漂移扩散模块耦合                              |

#### 2. 漂移扩散（Drift-Diffusion, dd）—— 离子输运计算



| 配置项   | 具体设置                                                                                                                                                          |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 载流子类型 | 正离子（O₂⁺）、负离子（O₂⁻）（默认 N₂⁺/N₂⁻参数一致，可添加为次要载流子）                                                                                                                   |
| 迁移率设置 | - 正离子 μ₊=1.31 \[cm²/(V・s)] → 转换为 COMSOL 单位 = 1.31e-4 \[m²/(V・s)]- 负离子 μ₋=1.83 \[cm²/(V・s)] → 1.83e-4 \[m²/(V・s)]                                              |
| 电离模型  | 汤森放电模型（空气专属）：- 电离系数 αₜ=A\*exp (-B/E)- A=11.6 \[cm⁻¹・Torr⁻¹] → 1160 \[m⁻¹・Pa⁻¹]（单位转换）- B=287\[cm⁻¹·Torr⁻¹] → 28700\[m⁻¹·Pa⁻¹]- 电离阈值 Eₜₕ=3 \[kV/mm]（3e6 \[V/m]） |
| 重组模型  | 双极重组：重组系数 αᵣ₊=1.8e-13 \[m³/s]（1.8e-7 \[cm³/s] 转换），αᵣ₋=2.1e-13 \[m³/s]                                                                                         |
| 边界条件  | - 针尖表面：正离子注入（正极性时），电流密度 J₊=10 \[μA/m²]（离子风枪典型发射电流）- 平板表面：离子收集（吸收所有离子，浓度为 0）                                                                                   |

#### 3. 层流（Single-Phase Flow, spf）—— 离子风流体耦合



| 配置项   | 具体设置                                                  |
| ----- | ----------------------------------------------------- |
| 流体属性  | 空气：密度 ρₐᵢᵣ=1.29 \[kg/m³]，动力粘度 μₐᵢᵣ=1.8e-5 \[Pa・s]     |
| 体积力耦合 | 库仑力项：F=ρ\_es\*E\_es（静电场电荷密度 × 电场强度），添加到 “动量方程 - 体积力”  |
| 边界条件  | - 电极表面：无滑移边界（流体速度 = 0）- 空气域外边界：压力边界（大气压 101325 \[Pa]） |

#### 4. 粒子追踪（Particle Tracing for Fluid Flow, pt）—— 加速路径可视化



| 配置项  | 具体设置                                                                                                            |
| ---- | --------------------------------------------------------------------------------------------------------------- |
| 粒子类型 | 正离子（质量 m₊=5.31e-26 \[kg]）、负离子（m₋=5.31e-26 \[kg]）                                                                |
| 初始条件 | 针尖表面 0.1-0.5mm 处随机释放粒子，初始速度 = 0 \[m/s]                                                                          |
| 力场耦合 | - 电场力：F=q*E\_es（q=1.6e-19 \[C]，正离子 + q，负离子 - q）- 流体拖曳力：F=3πμₐᵢᵣd\_particle*v\_rel（d\_particle=0.3 \[nm]，离子有效直径） |
| 终止条件 | 粒子到达平板表面或超出空气域时终止追踪                                                                                             |

### 四、求解器参数（确保高电压下收敛）



```
// 求解序列设置（稳态求解器，按顺序执行）

1\. 第一步：求解静电场（无空间电荷）

&#x20;  \- 求解器：UMFPACK（直接求解器）

&#x20;  \- 收敛准则：相对误差≤1e-6，绝对误差≤1e-10

&#x20;  \- 迭代次数上限：100

2\. 第二步：耦合静电场+漂移扩散（含空间电荷）

&#x20;  \- 求解器：Newton-Raphson（非线性求解器）

&#x20;  \- 阻尼因子：0.8（避免高压振荡）

&#x20;  \- 收敛准则：相对误差≤1e-5，电荷守恒误差≤1e-8

&#x20;  \- 迭代次数上限：200

3\. 第三步：耦合流体场+粒子追踪

&#x20;  \- 求解器：Segregated（分离式求解器）

&#x20;  \- 流体动量方程：GMRES迭代求解器（重启次数=20）

&#x20;  \- 粒子追踪：Runge-Kutta 45（时间步长=1e-6\[s]）

&#x20;  \- 收敛准则：流体速度相对误差≤1e-4

// 关键参数调整（避免收敛失败）

\- 空间电荷迭代：启用“自适应阻尼”，初始电荷密度设为1e-12\[C/m³]（逐步提升）

\- 电离模型开关：先关闭电离求解，得到稳定电场后再启用（防止初始场强过高）

\- 网格自适应：求解后检查针尖区域网格质量，若扭曲度>0.5，自动加密至0.5\[μm]
```

### 五、仿真文件导出与导入步骤

#### 1. 导出.mph 文件（手动操作）



1. 按上述配置完成所有模块设置后，点击 COMSOL 菜单栏「文件」→「保存为」，命名为 “130kV\_Ion\_Gun\_Simulation.mph”。

2. 导出时勾选「包含求解器状态」「包含网格数据」「包含参数定义」，确保导入后可直接运行。

#### 2. 直接导入参数代码（快速配置）



1. 打开 COMSOL，新建 3D 模型，点击「文件」→「导入」→「导入脚本」。

2. 复制以下代码粘贴到脚本编辑器，点击「运行」，自动生成几何、物理场、求解器配置：



```

model.modelPath('C:\COMSOL\_Simulations');

model.setName('130kV\_Ion\_Gun');

% 全局参数定义

model.param.set('r\_tip', '0.1\[mm]');

model.param.set('L\_needle', '5\[mm]');

model.param.set('D\_plate', '5\[cm]');

model.param.set('V\_total', '130\[kV]');

% 几何建模（简化版，完整代码需添加旋转、拉伸、布尔运算）

% （此处省略求解器详细配置代码，完整版本包含所有收敛参数）

```

#### 2. 常见问题排查



* 仿真不收敛：检查针尖网格是否加密至 1μm，降低 Newton-Raphson 阻尼因子至 0.6，或先求解无电离的电场。

* 场强数值异常：确认电压单位为 kV（非 V），电极间距单位为 cm（非 m），介电常数未误设为导体（σ≠0）。

* 粒子无法到达平板：延长粒子追踪时间步长至 1e-5 \[s]，或增大离子迁移率（确认单位转换正确，cm²→m² 需 ×1e-4）。
