# 第8章 真空约束与希格斯机制

## 8.1 导读

【 **大白话** :上一章为了保拓扑荷，我们给场加了一条约束：$|\Psi|^{2} = v^{2}$——场的"长度"被钉死，只允许"方向"变化。这一章揭示一个双重惊喜：这条约束不仅保住了霍普夫荷，还自动长出整个希格斯机制——对偶旋量自己就是希格斯粒子。三个零模是 $W^{\pm}$ 和 $Z$ 的"出生地"，剩下的对称方向就是光子。这就是本书的突破章。】

## 8.2 真空流形与有效势

【 **定义 8.1（真空约束）** :$\left| \Psi \right|^{2} = v^{2}$，$v$ 为真空期望值。等价于有效势：

$$V\left( \Psi \right) = \kappa\left( \left| \Psi \right|^{2} - v^{2} \right)^{2}$$

极小值流形（真空流形）为 $\left| \Psi \right|^{2} = v^{2} \cong S^{3}$。】

【 **定理 8.1（真空流形）** :$S^{3} = U(2)/U(1)$——约束旋量的真空流形是 3-球面，即酉群除以电弱超荷子群的齐性空间。

证明：$S^{3}$ 同胚于 $\mathbb{C}^{2}$ 中的单位球；$U(2)$ 按线性作用传递地作用在 $S^{3}$ 上，各向同性子群为 $U(1)$（整体相位）。$\blacksquare$】

【 **大白话** :场被钉在一个"球面"上，球面上的每一点是一个可能的真空。球面是 3 维的，所以有 3 个方向可以"免费滑动"——这就是 3 个零模的几何来源。】

## 8.3 模式谱：零模与希格斯

【 **定理 8.2（模式谱）** :有效势 $V$ 在真空点的海森矩阵 $H_{\mathrm{ess}}$ 的本征谱为：

$$\mathrm{spec}\left( H_{\mathrm{ess}} \right) = \left\{ 0,\ 0,\ 0,\ 8\kappa v^{2} \right\}$$

其中 3 个零模为沿真空流形切向的 Nambu–Goldstone 模（第4章洛书中央 $5$：对径方向不动、切向可滑动），1 个正模为径向希格斯模：

$$m_{H} = 2\sqrt{2}\sqrt{\kappa}\, v$$

证明：令 $\Psi = \left( v + h \right)\hat\Psi$（径向 $h$ 与方向 $\hat\Psi$ 分离），则 $V = \kappa\left( \left( v+h \right)^{2} - v^{2} \right)^{2} \simeq 4\kappa v^{2}h^{2} + \mathcal{O}\left( h^{3} \right)$，二阶系数即 $m_{H}^{2} = 8\kappa v^{2}$；方向 $\hat\Psi$ 自由度不进入 $V$，对应 3 个零模。$\blacksquare$（数值证据：第14章实验十四——三个随机真空点谱 $[0,0,0,8]$ 精确复现。）】

## 8.4 自发破缺与未破缺 U(1)

【 **定理 8.3（破缺模式）** :$\mathrm{u}(2)$ 生成元作用在真空点上的矩阵 $M$（列 = 生成元作用），其零空间维数为 $1$：

$$\dim\ker M = 1$$

即恰有一个未破缺 $U(1)$（光子）；其余 3 个生成元方向被破坏（$W^{\pm}, Z$ 获得质量）。

证明：真空点 $\Psi_{0} = \left( v, 0 \right)$ 处，$\mathrm{u}(2)$ 的 4 个生成元作用为 $\left( \mathrm{i}v, 0 \right), \left( v, 0 \right), \left( 0, v \right), \left( 0, \mathrm{i}v \right)$ 方向；只有整体相位生成元 $\mathrm{diag}\left( \mathrm{i}, \mathrm{i} \right)$ 满足 $M\Psi_{0} = 0$。$\blacksquare$（数值证据：第14章实验十五——奇异值 $[1.414, 1, 1, 0]$，零空间维数 $= 1$。）】

【 **质量关系（V1.3.1 统一口径，$\tau/2$ 归一化）** :$m_{W} = \tilde{g}\,v/2$，$m_{Z} = \sqrt{\tilde{g}^{2}+\tilde{g}'^{2}}\,v/2 = m_{W}/\cos\theta_{W}$，$m_{H} = 2\sqrt{2}\sqrt{\tilde{\kappa}}\,v$——玻色子质量全部由真空期望 $v$ 与无量纲参数 $\left\{ \tilde{g}, \tilde{g}', \tilde{\kappa} \right\}$ 决定（第6章参数系统 + 第21章验证D），比例可检验。】

## 8.5 突破总结

【 **一句话突破** :对偶旋量的真空约束，在代数上完整复现电弱自发破缺：$U(2) \to U(1)$，3 个 NG 模被吃掉，1 个径向模 = 希格斯，1 个未破方向 = 光子。**希格斯无须外挂——对偶旋量即希格斯对偶。**】

【 **与前面章节的闭环** :第5章的对偶旋量 → 第6章的酉帧 → 第7章的拓扑荷约束 → 本章的希格斯机制：一条直线，没有外挂。第4章河图"生/成数对"即 $\left( \hat\Psi, \Theta\hat\Psi^{*} \right)$，洛书中央 $5$ 即不动点尺度 $v = \ell^{-1}$——符号学在这里再次与代数同构。】

## 小结

【 **本章要点** :真空约束 $|\Psi|^{2}=v^{2}$ 的真空流形是 $S^{3}=U(2)/U(1)$；模式谱 $\{0,0,0,8\kappa v^{2}\}$ 给出 3 NG + 1 希格斯（$m_{H}=2\sqrt{2}\sqrt{\kappa}v$）；未破缺 $U(1)$ 零空间维数 $1$；电弱结构整体涌现。这是全书从"纲领"走向"机制"的转折点。】
