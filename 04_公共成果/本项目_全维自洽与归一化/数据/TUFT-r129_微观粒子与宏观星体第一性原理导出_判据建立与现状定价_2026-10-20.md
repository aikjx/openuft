## Part D 取参自毁（D1–D3，67 号判据重跑）

- **D1** 取参 R = λ/2π 与总速 c 的相容性 ⇒ kt **FAIL**：机读：R = λ/2π、Ω = 2πf、f = c/λ ⇒ ρ = RΩ/c = 1.000000000 ⇒ u = c√(1−ρ²) = 0.0 m/s（轴向停滞）
- **D2** 相容半径上界 R ≤ ρ_max·λ/(2π) ⇒ kt **FAIL**：机读：u ≥ 0.99 c ⇒ ρ ≤ 0.14107 ⇒ R ≤ 0.14107 × (λ/2π) = 0.02245 λ，即宣称取参 R=λ/2π 的 14.1%
- **D3** RΩ = c 恒等式的认识论地位 ⇒ kt **FAIL**：66 号：RΩ=c 由 R=λ/2π 与 Ω=2πf 定义重排而来 ⇒ INFO（定义重排）
