## 三分钟启动

1. 解压 ZIP，保持 `ROOT_V63/` 目录结构。
2. 直接用支持 WebGL2 的现代浏览器打开 `ROOT_V63/web/index.html`，旋转/缩放地球、选择螺旋模式、调节角度/半径/场数/曲率耦合/截止长度。WebGL2 不可用时将使用 Canvas2D 备用渲染。
3. Python ≥3.10，在包根目录运行：

   ```bash
   python -m unittest discover -s tests -v
   python experiments/run_experiments.py
   ```

   Linux/macOS 用 `python3` 替代 `python`（视安装情况）。不需要安装第三方包即可运行核心程序与测试。安装 matplotlib 可重新生成 PNG 曲线；已有预渲染 PNG 也可直接查看。

4. 研究正文：`book/ROOT_V63_研究专著.md`；严格审计：`book/公式核验与反例.md`；实验设计：`book/可证伪性与后续证明义务.md`。

## 核心关系及含义

| 内容 | 公式 | 状态 |
|---|---|---|
| 圆柱螺旋速度 | `(R omega)^2 + u^2 = c^2` | 对特定运动模型**施加的假设** |
| 曲率/挠率 | `kappa=cos²(lambda)/R`, `tau=sin(lambda)cos(lambda)/R` | 给定模型下数学可证明 |
| 圆柱面波模 | `Omega²/c² = k_z²+(n/R)²+(mc/hbar)²` | 在指定自由波动方程中可证明 |
| 欧氏热核曲率项 | `a1=(1/6-xi) R` | 给定微分算子下的已知单圈技术 |
| 模拟诱导引力 | `1/G_ind = N(1-6xi) hbar F(mu)/(12 pi c³ ell²)` | **特定截止正则化、零裸引力参数的模型依赖结果** |
| 反向拟合长度 | `ell_fit = sqrt(N(1-6xi)G_obs hbar/(12 pi c³))` | 使用实测 G，绝非预测 |
| ROOT 新机制给出 G | 未知 | **未证明** |
| ROOT 统一四力 | 未知 | **未证明** |

`F(mu) = ∫_0^1 exp(-mu²/t)dt`, `mu=m c ell/hbar`。当 `xi=1/6` 且裸项为零时，模型中主导的诱导曲率项消失；系数不能被解释为实在的零引力。`xi>1/6` 的单一实标量主导项符号不合适，显示模型本身需要其他物质内容和重整化条件。

**重要：** 只有 NIST/CODATA 的 `G` 是输入观测量。图中 `G_ind / G_obs` 使用 `ell_P=sqrt(hbar G_obs/c³)` 进行尺度归一化，不能当作独立预言。

## 不包含的内容

- 没有真实 IGRF 地磁球谐系数或 EGM2008 地球重力数据；网页中的地磁是理想磁偶极，重力是牛顿球对称近似。
- 没有通过实验确证新物理、无自由参数确定 `G`、质量谱或精细结构常数。
- 不是高分辨率地球数字孪生、不是实时卫星资料，也不是四力统一已完成。
- 浏览器渲染经过 Chromium **Canvas2D 降级路线**交互测试；本环境 Chromium WebGL2 被禁用，**原生 WebGL2 分支尚未在真实 GPU 上完成端到端验证**，已进行静态审查。

## 关键输出（独立复算）

- CODATA 2022 观测值：`G=6.67430(15)×10⁻¹¹ m³ kg⁻¹ s⁻²`。
- 从观测 G 得到的普朗克长度：约 `1.6162550×10⁻³⁵ m`。
- 单标量、`xi=0`, `N=1`, 零裸参数的**反向拟合**长度：约 `2.6323542×10⁻³⁶ m`。
- 先前的 `alpha=1/(4pi³+pi²+pi)` 不是精确常数关系，相对误差约 `−2.22×10⁻⁶`。
- 先前的 `2 pi·3³+2pi =56pi≈175.93`，**不等于**质子/电子质量比约 `1836.15`。
