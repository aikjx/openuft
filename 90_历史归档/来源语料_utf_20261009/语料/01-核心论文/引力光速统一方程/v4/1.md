## 三、万有引力常量$G$几何表达式的严格求导推导
本节通过零跳步的运动学求导，严格证明$G$的几何表达式完全由螺旋运动的时间导数结合公理体系导出，无逻辑瑕疵、无循环论证。

### 3.1 螺旋运动的标准运动学参数化
取惯性系中螺旋中心轴为$z$轴，固定正交单位基矢为$\vec{i},\vec{j},\vec{k}$，满足$\frac{d}{dt}\vec{i}=\frac{d}{dt}\vec{j}=\frac{d}{dt}\vec{k}=0$（惯性系基矢不随时间变化）。根据公理1，稳态圆柱螺旋的位置矢量为：

$$\vec{r}(t) = R\cos(\omega t)\vec{i} + R\sin(\omega t)\vec{j} + v_\parallel t \vec{k} \tag{1}$$

式中：$R$为螺旋半径（稳态常量），$\omega$为角频率（稳态常量），$v_\parallel$为轴向平动速度（稳态常量），$t$为惯性系坐标时。

### 3.2 一阶时间求导：速度矢量与核心约束方程
对位置矢量式(1)求**一阶时间导数**（运动学速度的定义），根据导数的线性运算法则，直接得到速度矢量：

$$\vec{v}(t) = \frac{d\vec{r}(t)}{dt} = -R\omega\sin(\omega t)\vec{i} + R\omega\cos(\omega t)\vec{j} + v_\parallel \vec{k} \tag{2}$$

定义垂直于螺旋轴的切向圆周运动线速度$v_\perp = R\omega$（稳态常量），则式(2)可简化为：

$$\vec{v}(t) = -v_\perp\sin(\omega t)\vec{i} + v_\perp\cos(\omega t)\vec{j} + v_\parallel \vec{k} \tag{3}$$

根据公理1的光速不变约束$|\vec{v}(t)| \equiv c$，对速度矢量取模值的平方，结合三角恒等式$\sin^2x+\cos^2x=1$化简，得到螺旋运动的核心约束方程：

$$|\vec{v}(t)|^2 = v_\perp^2\sin^2(\omega t) + v_\perp^2\cos^2(\omega t) + v_\parallel^2 = v_\perp^2 + v_\parallel^2 = c^2 \tag{4}$$

式(4)完全由求导运算与光速不变公理导出，无任何额外假设，是稳态光速螺旋的核心本征约束。

### 3.3 二阶时间求导：加速度矢量与向心加速度
对速度矢量式(3)求**一阶时间导数**（即位置矢量的二阶时间导数，运动学加速度的定义），得到加速度矢量：

$$\vec{a}(t) = \frac{d\vec{v}(t)}{dt} = -v_\perp\omega\cos(\omega t)\vec{i} - v_\perp\omega\sin(\omega t)\vec{j} + \frac{dv_\parallel}{dt}\vec{k} \tag{5}$$

根据公理1的稳态条件，$v_\parallel$为与时间无关的常量，因此$\frac{dv_\parallel}{dt}=0$，轴向加速度为0。代入$v_\perp=R\omega$，式(5)可简化为：

$$\vec{a}(t) = -R\omega^2\left[\cos(\omega t)\vec{i} + \sin(\omega t)\vec{j}\right] \tag{6}$$

对加速度矢量取模值，结合三角恒等式化简，得到加速度的大小：

$$|\vec{a}(t)| = R\omega^2 = \frac{(R\omega)^2}{R} = \frac{v_\perp^2}{R} \tag{7}$$

从式(6)可直接看出，加速度矢量的方向始终指向螺旋中心轴，为**纯径向向心加速度**，无轴向分量。该结果完全由运动学求导导出，无任何额外假设，数学上严格自洽。

### 3.4 联立公理体系，导出$G$的几何表达式
根据公理2的强等效原理，螺旋运动的向心加速度，等价于中心天体在该位置产生的引力加速度；根据公理3的对应原理，弱场下引力加速度满足牛顿万有引力公式，且场点到中心天体的距离$r$与螺旋半径$R$完全等价，因此有：

$$|\vec{a}(t)| = \frac{v_\perp^2}{R} = \frac{GM}{R^2} \tag{8}$$

对式(8)做等价代数变换，两边同乘$R^2$、同除$M$，直接得到万有引力常量$G$的几何表达式：

$$G = \frac{v_\perp^2 R}{M} \tag{9}$$

代入$v_\perp=R\omega$，可得到等价形式$G=\frac{R^3\omega^2}{M}$，与原推导形式完全一致。

> **本节结论**：$G$的几何表达式，完全由稳态螺旋运动的运动学求导（位置→速度→加速度），结合强等效原理、对应原理严格导出，推导过程无逻辑跳步、无循环论证、无额外假设，数学与物理上完全自洽，澄清了关于求导合法性的质疑。

$$E_{k总} = E_{k\perp} + E_{k\parallel} = 2E_{k\perp} = \frac{1}{2}Mc^2$$
