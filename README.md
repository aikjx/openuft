## 关于“不同体系的统一场论”

本仓库不预设某一条路线正确，而是把互不相让的体系按原始假设分别登记，再在 [统一体系层](06_统一体系层/README.md) 提供共同坐标系、[实现方式总览](06_统一体系层/实现方式总览/README.md) 与 [关系体系图](06_统一体系层/关系体系图/体系关系图.html)。

需要明确区分两件事：**架构统一**（本层已完成，即所有体系可在同一组问题上对照）与**物理统一**（尚未达成）。建立统一层不意味着任何一个统一场论成立，也不提升任何体系的证据等级；已登记为证伪的结论照旧为证伪。
