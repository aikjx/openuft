# 第七章 宇宙的未来与热寂
## 7.1 永远加速膨胀
因为暗能量是宇宙学常数，w=-1，宇宙会永远加速膨胀，不会再收缩，不会有大挤压，也不会有大撕裂，因为暗能量密度是常数，不会增加，所以宇宙的膨胀率趋近于常数，最终趋近于德西特时空。

## 7.2 宇宙的演化未来
- 10^14年后，所有恒星都熄灭，宇宙中只剩下黑洞、中子星、白矮星、行星；
- 10^17年后，行星脱离恒星，恒星脱离星系；
- 10^40年后，质子衰变（如果质子寿命是10^36年），所有重子物质衰变为光子和中微子；
- 10^67年后，恒星级黑洞通过霍金辐射蒸发；
- 10^100年后，超大质量黑洞蒸发；
- 10^1000年后，宇宙中只剩下光子、中微子、暗能量，温度趋近于绝对零度，达到热寂状态，熵达到最大，不再有任何宏观过程。

## 7.3 第七卷总结
第七卷我们构建了完整的宇宙学模型：
1.  大爆炸奇点被挠率消解，宇宙从大反弹开始，没有奇点；
2.  挠率场自然驱动暴胀，解决视界、平坦性、磁单极问题，原初涨落和观测一致；
3.  宇宙热历史、原初核合成、CMB、结构形成都和标准宇宙学一致，和观测符合；
4.  宇宙永远加速膨胀，最终热寂，没有大挤压也没有大撕裂。
