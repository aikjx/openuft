# 判定册 · TUFT-r161｜电荷几何化 q = k′·dm/dt 的求导证明验证精算

## 一、编号与定位

- **编号 r161**（实测首空号；r156–r160 均已占用，r158 属另一并行线，本线不触碰其字节）
- **靶**：S17《宇宙大统一方程（力方程）》**公设层** §2.1「电荷几何化：q = k′ dm/dt」
- **与 r160 的分工**（条目不可相加）：r160 = 力方程**四项诠释**；本卷 = **电荷/质量定义公设**

## 二、判词

`CHARGE-GEOMETRIZATION-IMPLIES-MASS-DRIFT-AND-BREAKS-LORENTZ-INVARIANCE-OR-IDENTICAL-PARTICLES`

电荷几何化 ⇒ 带电粒子质量漂移，且要么破坏洛伦兹协变性、要么破坏粒子全同性。

## 三、机读推导

```
q = k′ · dm/dt   （k′ 为常数，量纲 C·s·kg⁻¹，原文未给数值）
⇒ q 恒定 ⇒ dm/dt = q/k′ = 常数 ≠ 0
⇒ m(t) = m₀ + (q/k′)·t    —— 带电粒子质量**线性漂移**
⇒ 中性粒子 q = 0 ⇒ dm/dt = 0 ⇒ 质量恒定
```

## 四、先给靶应得的 PASS：可加性自洽

因 d(Σm)/dt = Σ(dm/dt)（导数线性）且电荷可加 ⇒ 该公设在**记账层自洽**：

| 检验 | 电荷 | dm/dt（∝ q） | 残差 |
|---|---|---|---|
| β 衰变 n→p+e⁻+ν̄ | 0 = (+e)+(−e)+0 | 0 = e/k′+(−e/k′)+0 | 0 |
| 氘核 D = p+n | +e = (+e)+0 | e/k′ = e/k′+0 | 0 |

## 五、后果层（B）

- **B1** 带电粒子质量线性漂移；中性粒子恒定 ⇒ 两类粒子演化规律不同
- **B2** 相对漂移率 ∝ 1/m ⇒ 电子是质子的 **1836.15 倍**（= 质量比 m_p/m_e）
- **B3** dE/dt = c²·q/k′ ≠ 0（对任何有限 k′）⇒ **能量不守恒**（存在性判决）
- **B4** 由 m_e 观测反推 k′ > **5.4172e+29** C·s·kg⁻¹（原文未给值，故为 BOUNDARY）

## 六、协变性层（C，最硬且不依赖 k′）

| 读法 | dt 指 | 结果 | 判定 |
|---|---|---|---|
| C | 坐标时 | q′ = q/γ ⇒ β=0.9 时 **-56.411%** | FAIL 破坏洛伦兹协变性 |
| P | 固有时 | 等式协变 ✓，但质量依赖固有时 ⇒ 破坏电子全同性（相对差 **+56.411%**） | FAIL |

**两难（C4）**：k′ 有限 ⇒ 漂移 + 协变破缺；k′ → ∞ ⇒ 所有电荷恒为零 ⇒ 无电磁。

## 七、条目总表

- **A1** [PASS] 可加性自洽：电荷可加 ⇔ 质量漂移率可加（导数线性） — 因为 d(Σm)/dt = Σ(dm/dt)（**导数是线性的**）且电荷可加 ⇒ 该公设在**记账层自洽**。机读两组检验：①β 衰变 n→p+e⁻+ν̄：电荷残差 +0.0e+00、dm/dt 残差 +0.0e+00（因为 e/k′ + (−e/k′) = 0）；②氘核 D=p+n：电荷残差 +0.0e+00（D 的 dm/dt = e/k′ + 0 = e/k′，与其电荷 +e 一致）。**这是本卷对靶有利的结论，诚实登记** —— 该公设不是「一算就错」，它在守恒量记账上站得住；问题出在下面 B/C 两层。
- **A2** [BOUNDARY] 量纲自洽：k′ 的量纲为 C·s·kg⁻¹（但原文未给 k′ 的数值） — [q] = C，[dm/dt] = kg·s⁻¹ ⇒ [k′] = C·s·kg⁻¹，量纲**闭合**。但原文只说「k′ 为常数」，**从未给出其数值或量级** ⇒ 一切与 k′ 成正比的可检验量（质量漂移率、能量得失率）**在靶的框架内不可定量**。本卷据此把 B 层的定量结论登记为「存在性判决 + 反推约束」，不作数值指控（防过度指控）。
- **B1** [FAIL] 带电粒子质量线性漂移：m(t) = m₀ + (q/k′)·t（中性粒子则恒定） — 由 q = k′ dm/dt 且 q 恒定 ⇒ dm/dt = q/k′ = **常数** ⇒ m(t) = m₀ + (q/k′)·t。即：**任何带恒定电荷的粒子，其质量必须随时间线性漂移**；而中性粒子（q=0）质量恒定。⇒ 带电与中性粒子遵循**不同的质量演化规律**。这与「电子/质子质量是基本常数」（CODATA 相对不确定度 ~3e−10，且数十年跨度的独立测量一致）直接冲突。
- **B2** [FAIL] 相对漂移率 ∝ 1/m：电子的漂移速率是质子的 1836.15 倍（= 质量比） — |dm/dt| = |q|/k′ 对**所有**单位电荷粒子**相同**（与质量无关），故相对漂移率 (dm/dt)/m ∝ **1/m** ⇒ 越轻的粒子相对漂移越快。机读 m_p/m_e = **1836.1527** ⇒ 电子的相对质量漂移是质子的 **1836.15 倍**（与 r155「τ ∝ 1/m、标度 = 质量比 1836.15」同型数字）。⇒ 检验该公设最灵敏的探针是**电子**（最轻的带电粒子）。
- **B3** [FAIL] 能量不守恒：孤立带电粒子 dE/dt = c²·q/k′ ≠ 0（对任何有限 k′） — E = mc² ⇒ dE/dt = c²·dm/dt = c²·q/k′。只要 k′ **有限**，该项 **≠ 0** ⇒ 一个孤立带电粒子会无源地持续获得（或失去）能量 ⇒ **违反能量守恒**。这是**存在性**判决，不依赖 k′ 取什么值。若取 B4 反推出的 k′ 下界，机读 dE/dt ≈ 2.657e-32 W（极小但非零）。
- **B4** [BOUNDARY] 由电子质量观测反推：k′ > 5.4172e+29 C·s·kg⁻¹（原文未给任何值） — 取 m_e 的 CODATA 相对不确定度 3.074e-10 与 30 年观测跨度 ⇒ |dm/dt| < 2.9576e-49 kg/s ⇒ **k′ > 5.4172e+29 C·s·kg⁻¹**；对应 |dE/dt| < 2.6581e-32 W。原文**从未给出 k′ 的数值**，故无法据此直接证伪，只能给出相容性下界 —— 本卷诚实登记为 BOUNDARY，不作数值指控，但**存在性结论（B1/B3）不受影响**。
- **C1** [BOUNDARY] 读法歧义：dm/dt 的 dt 未声明是坐标时 t 还是固有时 τ — 记忆纪律：**凡含时间导数的式子都要先问读法**。原文的 dm/dt 未声明 dt 指坐标时还是固有时，而这两种读法给出**不同的物理后果**，且**两支都不利**。本卷两支都算、都登记（两难写法）。注：本卷不代靶选择读法。
- **C2** [FAIL] 读法 C（坐标时）：电荷依赖参考系，β=0.9 时偏差 -56.411% — 电荷 q 是**洛伦兹不变量**（实验铁律：电荷与运动状态无关）。若 dm/dt 的 dt 取**坐标时**，则 dm/dt 在洛伦兹变换下按 dt′ = dt/γ 变换 ⇒ **q′ = q/γ ≠ q**。机读 β=0.9 ⇒ γ = 2.294157 ⇒ q′ = 0.4358898944 q，偏差 **-56.411%**。即该定义**破坏洛伦兹协变性**：等式左边是不变量，右边不是。
- **C3** [FAIL] 读法 P（固有时）：等式协变，但破坏电子全同性（质量依赖运动历史） — 若 dt 取**固有时**，则 dm/dτ 是洛伦兹标量 ⇒ 等式协变 ✓（此支对靶有利，诚实登记）。**但**质量演化随之依赖**固有时** ⇒ 运动历史不同的同种粒子质量不同：静止电子 A 与以 β=0.9 运动 10 年的电子 B，固有时之比 2.294157 ⇒ 质量漂移量之比 = γ = 2.294157，相对差 **+56.411%**。而实验上**所有电子质量相同**（全同粒子，与历史无关）⇒ 冲突。⇒ 读法 P 用「破坏粒子全同性」换取了协变性。
- **C4** [FAIL] 两难：k′ 有限 ⇒ 质量漂移 + 协变破缺；k′ → ∞ ⇒ 所有电荷恒为零 — 两难（记忆纪律：归属未定写两难，两支都不利）：① 若 k′ **有限** ⇒ B 层质量漂移（与「质量是常数」冲突）+ C 层协变性/全同性破缺；② 若 k′ → **∞**（或 dm/dt ≡ 0）⇒ q = k′·dm/dt ≡ 0 ⇒ **一切电荷恒为零** ⇒ 该理论无法描述任何电磁现象，其「电场力 / 磁场力」两项（r160 已判落空）连前提都没有。两支都不通，本卷不代靶选择。
- **D1** [FAIL] 修复定价：3 动作 ⇒ 存活 1、零代价 0 — 让电荷定义站得住的唯一办法是 **REPLACE**：把 q 改为**独立基本量**、不再由 dm/dt 导出。但这样一来原文的「**电荷几何化**」（用质量变化率解释电荷起源）这一核心主张**作废** —— 电荷重新成为外部输入 ⇒ **「修复即自杀」第十度复发**。KEEP ⇒ B/C 层缺陷不变；DEL ⇒ 电磁项失去前提。**零代价解 0**。修复空间为低阶（3 动作），高阶新增型未枚举。
