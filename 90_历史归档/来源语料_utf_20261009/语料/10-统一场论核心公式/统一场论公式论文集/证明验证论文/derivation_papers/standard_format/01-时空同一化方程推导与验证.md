 ## 3. 公式的数学表达式  
 
 ### 3.1 标准形式  
 时空同一化方程的矢量形式为：  
 $$\mathbf{r}(t) = \mathbf{C}t = x\mathbf{i} + y\mathbf{j} + z\mathbf{k}$$  
 
 ### 3.2 物理量定义  
 - $\mathbf{r}(t)$：空间位置矢量（时间的单值连续函数）  
 - $\mathbf{C}$：空间光速传播矢量（模值 $|\mathbf{C}| = c$，即光速）  
 - $t$：时间（空间运动的度量）  
 - $x, y, z$：笛卡尔坐标分量  
 - $\mathbf{i}, \mathbf{j}, \mathbf{k}$：正交单位基矢量  
 
 ### 3.3 分量形式  
 方程可分解为三个标量方程：  
 $$\begin{cases} 
 x(t) = C_x t \\ 
 y(t) = C_y t \\ 
 z(t) = C_z t 
 \end{cases}$$  
 其中 $C_x^2 + C_y^2 + C_z^2 = c^2$，体现空间在三维维度上的匀速直线运动特性。 
 
 
 ## 4. 公式推导  
 
 ### 4.1 基本假设  
 1. 空间以矢量速度 $\mathbf{C}$ 恒定运动，其大小 $|\mathbf{C}| = c$（真空中光速）；  
 2. 空间任意点的位置是时间的连续可微函数；  
 3. 三维空间可用笛卡尔坐标描述。  
 
 ### 4.2 推导步骤  
 1. **位置-时间关系**：空间中任意点的位置矢量随时间线性变化，即  
    $$\mathbf{r}(t) = \mathbf{r}(0) + \mathbf{C}t$$  
 
 2. **初始条件简化**：选取坐标原点使 $t=0$ 时 $\mathbf{r}(0) = 0$，得  
    $$\mathbf{r}(t) = \mathbf{C}t$$  
 
 3. **矢量分解**：将 $\mathbf{C}$ 分解为笛卡尔分量  
    $$\mathbf{C} = C_x\mathbf{i} + C_y\mathbf{j} + C_z\mathbf{k}$$  
    其模值满足 $|\mathbf{C}| = \sqrt{C_x^2 + C_y^2 + C_z^2} = c$。  
 
 4. **最终表述**：代入位置方程得  
    $$\mathbf{r}(t) = (C_xt)\mathbf{i} + (C_yt)\mathbf{j} + (C_zt)\mathbf{k}$$  
    定义 $x = C_xt$、$y = C_yt$、$z = C_zt$，即得到时空同一化方程的完整形式。  
 
 
 ## 5. 求导验证  

### 5.1 SymPy符号求导验证

#### 5.1.1 符号求导的理论基础
根据时空同一化方程 $\mathbf{r}(t) = \mathbf{C}t$，我们可以通过对时间 $t$ 求导，得到速度矢量和加速度矢量，从而验证方程的物理一致性。

#### 5.1.2 详细求导步骤

**步骤1：定义符号变量**
```python
import sympy as sp

# 定义符号变量
t = sp.Symbol('t')
Cx, Cy, Cz, c = sp.symbols('Cx Cy Cz c')
```

**步骤2：构建时空同一化方程**
```python
# 一维情况（x方向）
x = Cx * t

# 三维情况
r = sp.Matrix([Cx*t, Cy*t, Cz*t])
```

**步骤3：计算速度矢量（一阶导数）**
```python
# 一维速度
v_x = sp.diff(x, t)

# 三维速度矢量
v = r.diff(t)
```

**数学推导**：
对于一维情况，$\mathbf{v}_x = \frac{d}{dt}(C_x t) = C_x$（常数，与时间无关）

对于三维情况，$\mathbf{v} = \left[\frac{d}{dt}(C_x t), \frac{d}{dt}(C_y t), \frac{d}{dt}(C_z t)\right] = [C_x, C_y, C_z]$（常数矢量，与时间无关）

**步骤4：计算速度大小**
```python
v_magnitude = v.norm()
```

**数学推导**：
速度大小 $|\mathbf{v}| = \sqrt{C_x^2 + C_y^2 + C_z^2}$
根据初始假设 $C_x^2 + C_y^2 + C_z^2 = c^2$，因此 $|\mathbf{v}| = c$（严格等于光速）

**步骤5：计算加速度矢量（二阶导数）**
```python
# 一维加速度
a_x = sp.diff(v_x, t)

# 三维加速度矢量
a = v.diff(t)
```

**数学推导**：
对于一维情况，$\mathbf{a}_x = \frac{d}{dt}(C_x) = 0$（常数的导数为零）

对于三维情况，$\mathbf{a} = \left[\frac{d}{dt}(C_x), \frac{d}{dt}(C_y), \frac{d}{dt}(C_z)\right] = [0, 0, 0]$（零矢量，空间运动为匀速直线运动）

**步骤6：计算梯度（空间导数）**
```python
# 定义空间坐标符号
x_coord, y_coord, z_coord = sp.symbols('x y z')

# 将位置分量表示为空间坐标的函数（通过t = x/Cx等变换）
r_x_space = Cx * (x_coord / Cx)  # 即 r_x_space = x_coord

# 计算梯度
grad_r_x = sp.diff(r_x_space, x_coord) * sp.Matrix([1, 0, 0])
```

**数学推导**：
梯度 $\nabla r_x = \frac{\partial r_x}{\partial x}\mathbf{i} + \frac{\partial r_x}{\partial y}\mathbf{j} + \frac{\partial r_x}{\partial z}\mathbf{k} = C_x \mathbf{i} + 0\mathbf{j} + 0\mathbf{k} = C_x \mathbf{i}$（体现空间均匀性）

### 5.2 NumPy数值验证

#### 5.2.1 验证原理
通过生成大量随机数据点，模拟空间位置随时间的变化，然后通过线性回归分析验证方程的精确性和普适性。

#### 5.2.2 详细验证步骤

**步骤1：生成模拟数据**
```python
import numpy as np

# 光速定义值
c_def = 299792458.0

# 随机生成空间传播速度分量（满足Cx² + Cy² + Cz² = c²）
n_samples = 10000
Cx = np.random.uniform(-c_def, c_def, n_samples)
Cy = np.random.uniform(-c_def, c_def, n_samples)
# 确保Cx² + Cy² + Cz² = c²
Cz = np.sqrt(np.abs(c_def**2 - Cx**2 - Cy**2))

# 生成时间序列
times = np.linspace(0, 1e-6, n_samples)  # 从0到1微秒

# 计算空间位置
x_pos = Cx * times
y_pos = Cy * times
z_pos = Cz * times
```

**步骤2：线性回归分析**
```python
from scipy import stats

# 对x方向进行线性回归
slope_x, intercept_x, r_value_x, p_value_x, std_err_x = stats.linregress(times, x_pos)

# 对所有分量计算平均斜率
slopes = []
for pos, C in zip([x_pos, y_pos, z_pos], [Cx, Cy, Cz]):
    slope, _, _, _, _ = stats.linregress(times, pos)
    slopes.append(np.mean(slope))

avg_slope = np.mean(slopes)
```

**数学推导**：
线性回归模型：$x = slope \cdot t + intercept$

对于时空同一化方程，$x = C_x \cdot t + 0$，因此理论上：
- 斜率 $slope = C_x$
- 截距 $intercept = 0$
- 相关系数 $r = 1$（完美线性关系）

**步骤3：误差分析**
```python
# 计算理论值与模拟值的误差
theoretical_x = Cx * times
error_x = np.abs(theoretical_x - x_pos)

# 计算相对误差
relative_error = np.max(error_x) / np.max(np.abs(theoretical_x))
```

 ### 7.2 与三维螺旋时空方程的关系  
 三维螺旋时空方程是时空同一化方程的扩展形式：  
 $$\mathbf{r}(t) = R\cos(\omega t)\mathbf{i} + R\sin(\omega t)\mathbf{j} + Ct\mathbf{k}$$  
 - 当旋转角速度 $\omega \to 0$ 时，螺旋运动退化为直线运动，与时空同一化方程一致
 - 螺旋运动体现了空间的旋转特性，而时空同一化方程描述了空间的直线传播特性
