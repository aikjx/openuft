## 一、TUFT 黑洞的几何结构（修订）

**修订 1（曲率饱和的适用范围 · 数值）**：

```
r_h(1 M☉) = 2953.3 m
K_sat / (1/r_h²) = 3.339e+76          →  相差 77 个数量级
```

⇒ `K_sat = 1/l_P²` 只在 `r_h ~ l_P`（即 `M ~ m_P = 2.18e-8 kg`）附近才对视界曲率起作用。
对**所有天体黑洞**，视界处"曲率饱和"完全未触发。原稿"内部曲率持续升高、逼近饱和"
在**数量级上**即不成立。

**修订 2（奇点移除不构成证明）**：Penrose-Hawking 定理讲的是**测地线不完备**，
不是"曲率发散到无穷"。给曲率设上界不自动消除测地线不完备。真正的正则黑洞需要
**特定的 `f(r)`**（Bardeen/Hayward 型），例如

```
Hayward:  f(r) = 1 - 2Mr²/(r³ + 2M l²)   ⇒   Kretschmann(r→0) = 24（有限，de Sitter 核）
```

而这需要把相应的有效物质项写进**作用量**。TUFT 的作用量（前一分册 §3.2）中**没有**任何此项
⇒ 声称的"奇点移除"**无实施路径**。

**修订 3（挠率剖面的可容许性 · 关键）**：TUFT 的统一作用量**不含挠率动能项 `T²`、无挠率势**，
故挠率的场方程是**代数约束**（Einstein-Cartan 型：挠率 ∝ 自旋密度）。
真空中自旋密度 = 0 ⇒ **T = 0**。因此静态真空黑洞外部**不可能**存在非零挠率剖面 `T(r)`。
⇒ 本册所需的 `T(r)` 结构与其自身作用量**互相矛盾**（跨册一致性 FAIL）。

**保留（成立）**：`l_P = 1.616255e-35 m`；`K_sat = 1/l_P² = 3.828e+69 m⁻²` 量纲 L⁻² ✓；
挠率 `T(r)` 在视界处**连续、梯度跃变** —— 此条与原文代码一致（但 0.8 是任意常数，无方程确定）。

## 二、黑洞熵（修订）

**保留**：`S_BH = A/(4l_P²)`（及积分形式）是 Bekenstein-Hawking 熵的标准形式。
数值：1 M☉ → `S = 1.0490e+77 nats = 1.5133e+77 bit`。

**修订 1（因子 4）**：
- 若元胞面积 = `l_P²` 且每元胞 1 nat ⇒ `S = A/l_P²`，是 B-H 的 **4 倍**；
- 要与 `A/(4l_P²)` 自洽，元胞面积必须是 **`4l_P² = 1.0449e-69 m²`**
  （等价表述：**每普朗克面积 1/4 nat**）。

原稿文字（"普朗克尺度元胞、每元胞 1 比特"）与公式相差因子 4 ⇒ 该因子是**事后拟合**，
不是从元胞计数导出。

**修订 2（态计数缺失）**：原稿称"熵的微观来源是挠率拓扑自由度计数"，但**全册零计算**
（无配分函数、无态数 N、无 ln N）。B-H 熵的系数 1/4 在弦论/LQG 中是**被算出来**的。

**修订 3（半整数环绕数）**：Gauss 环绕数（Hopf 链双线积分，400² 网格）实算 = **−1.0000**，
即**整数**。环绕数/链环数对闭曲线恒为整数；**半整数**来自自旋 1/2 的**双覆盖**
（2π 旋转 → −1），与环绕数无关。本项亦与《续篇》自洽结论（费米相位 −1 ↔ Lk = −1，整数）冲突。

## 三、霍金辐射（修订 · 量纲）

**修订 1（温度公式）**：

| 形式 | 量纲 | 1 M☉ 数值 |
|---|---|---|
| 原稿 `ħc/(8πGM)` | **[M]**（质量）✗ | 9.4783e-48 |
| 正确 `ħc³/(8πGk_BM)` | 温度 ✓ | **6.170074e-08 K** |
| 几何形式 `ħc√K(r_h)/(4πk_B)`（K=1/r_h²） | 温度 ✓ | **6.170074e-08 K**（偏差 2e-16） |

> **正面产出**：几何形式**可以**写对 —— 但正确组合是曲率的**平方根 √K**，
> 而非原稿的 `K·T`。因 `√K = 1/r_h = c²/(2GM)`，该式与标准 Hawking 温度**代数恒等**。

**修订 2（`T_H ∝ K·T` 删去）**：`[K]·[T] = L⁻³`，不是温度；且比例系数未给。

**修订 3（质量公式 · 量纲非法）**：`M = (1/c²)∫αKTΩ·4πr²dr` 的量纲为 **L⁻²T²**，不是质量。
正确关系：`M = c²r_h/(2G)`（1 M☉ ↔ r_h = 2953.3 m，已数值核对）。

> 这是同一缺陷族（"`αKTΩ/c²` 当作质量"）的**第 3 次重现**：
> 《续篇》§5.1、《色挠率 SU(3)》§5.1、本册 §3。

**修订 4（隧穿机制）**：Hawking 辐射的既有严格方法（Bogoliubov 变换 / Parikh-Wilczek 隧穿）
都需要计算振幅或作用量虚部。原稿只给"拓扑拆分"的叙事 ⇒ 机制未被推导。

**修订 5（势垒自相矛盾）**：§1 称"挠率在视界上连续"，§3 又称"视界内外 Ω 不连续形成势垒"；
且代码中 Ω 两侧同为 0.9375（**连续**）⇒ 三处互斥，删去"势垒"论述。

## 四、信息悖论（修订）

**保留（成立但非增量）**：B-H 熵即区域最大熵（全息界），故"信息写在视界层"在**容量上**不矛盾 ——
但这是全息原理的**已知陈述**，不是 TUFT 增量。

**修订 1（方向反了）**：全息原理（'t Hooft-Susskind）本身是**关于任意区域最大熵的原理**，
B-H 熵是其锚点。原稿称"全息原理是挠率拓扑的直接推论"⇒ **把前提当结论**。

**修订 2（幺正性不可证伪）**：信息逃逸的唯一半经典标志是**辐射细致谱偏离严格热谱**
（Page 曲线）。原稿给出 **0 个**：无 Page 曲线、无偏离量、无 S 矩阵、无微扰计算。
定量：1 M☉ 黑洞 `t_evap = 2.096e+67 yr`，Page 时间约 `1.355e+67 yr`（0.646 t_ev）；
原稿未给任何 t_Page 或谱偏离的预言。

**修订 3（"视界只是坐标面"）**：GR 事件视界是**全局定义**的类光面（Killing 视界 /
未来零无穷的边界），不是"坐标面"；只有 Rindler 型加速观察者的视界才坐标相关。

**保留（重要张力）**：原稿同时接受"辐射为**严格黑体谱**"与"全程**幺正无信息丢失**" ——
这两者正是**信息悖论的核心矛盾**；不给出谱偏离，就无法同时成立。应如实标注为**开放问题**。

## 五、黑洞热力学（修订）

**保留（成立）**：`dM = T_H dS + ΦdQ`（RN 第一定律）✓；经典面积定理 `dA ≥ 0` ✓。

**修订 1（面积定理的条件）**：`dA ≥ 0` 的条件来自**能量条件**，与"曲率饱和约束"无关
⇒ 原稿附加条件多余（且是错误归因）。

**修订 2（逻辑矛盾 · 关键）**：原稿同时断言
(a) `dA ≥ 0` 是定理；(b) 霍金辐射使"视界面积缩小"。二者不能同真：
**霍金辐射恰恰破坏**经典面积定理（量子效应，半经典计算给 `dA/dt < 0`）。
原稿用"不违反"把矛盾表述掩盖过去，应如实区分既念。

**修订 3（GSL 的定量地位）**：
`dS_BH/d|dM| = 8πGM/(ħc)`，`dS_rad/d|dM| = c²/T_H = 8πGM/(ħc)` ⇒ **两者精确相消**，
`dS_tot = 0`（**临界饱和**）。故"GSL 成立"在半经典纯热辐射下是**等式**而非不等式；
真正需要解释的是**纠缠熵修正**（Page），原稿未涉及。

## 七、下一阶段方向的修订（原 §7）

原 §7 给出三个方向（宇宙暴胀 / 人工引力场工程 / 挠率探测实验）。
按本册判定，**在执行前必须先解决前置约束**：

1. **挠率动力学**：作用量补 `T²` 项与独立耦合常数（否则真空中挠率恒为 0，任何"挠率结构"都无源）；
2. **正则黑洞 `f(r)`**：给出有效作用量项（否则"奇点移除"无实施路径）；

**"人工引力场"方向特别提示**：前序分册（B 路线）已给出判决 ——

## 八、诚实边界与结论

1. **本册没有"几何解"**：无度规、无场方程、无求解过程；§6"仿真"实为绘图脚本；
2. **挠率不自洽**：作用量无挠率动能项 ⇒ 真空挠率须为 0，而本册需要 `T(r) ≠ 0`；
3. **两处关键公式量纲非法**：`T_H = ħc/(8πGM)`（应含 c³）、`M=(1/c²)∫αKTΩ`（应为 `c²r_h/2G`）；
4. **奇点移除未实施**：`K_sat` 对天体黑洞低 77 个量级；真正的正则黑洞需特定 `f(r)`；
5. **熵的微观来源零计算**："每元胞 1 比特"与 `A/4l_P²` 差因子 4；"半整数环绕数"与整数 Gauss 环绕数矛盾；
6. **信息悖论未消解**：无 Page 曲线/谱偏离/S 矩阵 ⇒ 不可证伪；且"全息原理是推论"方向反了；
7. **红线**：本册**成立的部分**（`A/4l_P²`、`T_H`、四定律、GSL 相消）全部是
   **标准黑洞热力学的重述**；TUFT 特有部分（挠率膜、拓扑隧穿、元胞计数）**均无计算支撑**。

> 本册最有价值的产出是 **B3.2**：给出与标准 Hawking 温度代数恒等的几何形式
> `T_H = ħc√K(r_h)/(4πk_B)`（应取曲率**平方根**，而非 `K·T`）。
