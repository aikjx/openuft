### 2.2 第3章：中心力场运动方程的重构

#### 🔴 严重问题：推导断层

**问题1：从 dC/dt 到修正项的跳跃** (203-209行)

论文声称：
```markdown
经过详细计算（见附录A.1），dC/dt 在极坐标下的分量为：
(dC/dt)_r = -3/2 · (v_r · ω_s)/c + (v_θ²)/(c² r)
(dC/dt)_θ = (v_r · v_θ)/(c² r)
```

但查看附录A.1 (936-1012行)，附录中的计算与正文不一致！

**附录A.1的结果** (1006-1010行)：
```markdown
(dC/dt)_r = c ω_s sin[ω_s t - θ]
(dC/dt)_θ = -c ω_s cos[ω_s t - θ]
```

**矛盾分析：**

1. **正文形式**：包含 $v_r, v_θ$ 分量
2. **附录形式**：不含 $v_r, v_θ$，仅含 $\omega_s$ 和 $t$

这两者完全不匹配！这是论文中最严重的数学错误。

#### 🔴 严重问题：从附录A.1无法得到正文公式

让我们验证附录A.1的推导是否正确：

给定 (940-944行)：
```
C(r, θ, t) = c [cos(ω_s(r)t), sin(ω_s(r)t), h(r)/c]ᵀ
```

全导数 (946行)：
```
dC/dt = ∂C/∂t + v_r(∂C/∂r) + (v_θ/r)(∂C/∂θ)
```

**步骤1：时间偏导数** (950-954行)
```
∂C/∂t = c ω_s(r) [-sin(ω_s t), cos(ω_s t), 0]ᵀ
```
✅ 正确

**步骤2：径向偏导数** (958-966行)
```
∂C/∂r = c t (dω_s/dr)[-sin, cos, 0]ᵀ + [0, 0, dh/dr]ᵀ
```
✅ 正确

其中 (970行)：
```
dω_s/dr = -3/2 · ω_s/r,  dh/dr = -2h/r
```
✅ 正确（如果 $\omega_s \propto r^{-3/2}$）

**步骤3：角向偏导数** (974-978行)
```
∂C/∂θ = [0, 0, 0]ᵀ
```
✅ 正确

**步骤4：组装全导数** (984-996行)
```
dC/dt = c ω_s[-sin, cos, 0]ᵀ + v_r{c t(dω_s/dr)[-sin, cos, 0]ᵀ + [0,0,-2h/r]ᵀ}
```
✅ 数学正确

**步骤5：投影到极坐标** (1006-1010行)
这里论文声称：
```
(dC/dt)_r = c ω_s sin[ω_s t - θ]
(dC/dt)_θ = -c ω_s cos[ω_s t - θ]
```

**问题：** 这个投影是如何得到的？论文没有说明基矢量的投影方法！

**正确的投影应该是：**
如果 $\hat{r} = [\cosθ, \sinθ, 0]ᵀ$, $\hat{θ} = [-\sinθ, \cosθ, 0]ᵀ$，那么：
```
(dC/dt)_r = (dC/dt) · r̂
         = c ω_s[-sin(ω_s t)cosθ + cos(ω_s t)sinθ] + 对流项
         = c ω_s sin(ω_s t - θ) + 对流项

(dC/dt)_θ = (dC/dt) · θ̂
         = c ω_s[sin(ω_s t)sinθ + cos(ω_s t)cosθ] + 对流项
         = c ω_s cos(ω_s t - θ) + 对流项
```

但论文忽略了**对流项**的投影！这是错误的。

#### 🟠 中等问题：从轨道方程到修正项的转换

**问题3：第3.4节的量纲不一致** (283-286行)

论文给出：
```
δA_r = -3GM h²/(c²) · u⁴
```

其中 $u = 1/r$。

**量纲验证：**
```
[δA_r] = [L][T]^{-2}
[-3GM h² u⁴/c²] = [L³ M⁻¹ T⁻²] × [M] × [L]⁴ T⁻² × [L]⁻⁴ / [L]² T⁻²
                = [L⁵ M T⁻⁴] / [L² T⁻²]
                = [L³ M T⁻²]
```

**错误：** 多出了 $[M]$ 量纲！

**正确形式应该是：**
```
δA_r = -3G² M²/(c²) · u⁴
```

量纲验证：
```
[G² M² u⁴/c²] = [L⁶ M⁻² T⁻⁴] × [M]² × [L]⁻⁴ / [L]² T⁻²
              = [L⁰ T⁻²]
```

**还是不对！** 应该是 $[L][T]^{-2}$。

**实际上，正确的形式应该是：**
```
从 ⟨δA_r⟩ = -h²/c² p³ 出发
使用 p = h²/(GM)
⟨δA_r⟩ = -h²/c² · (GM)³/h⁶ = -G³ M³/(c² h⁴)
代入 h² = GMp
⟨δA_r⟩ = -G³ M³/(c² G² M² p²) = -GM/(c² p²) = -GM/(c²) · u²
```

但论文给出的方程 (309行) 中，修正项是 $3GM/(c²) u²$。

**发现：** 论文在285行写错了！应该是 $u²$ 而不是 $u⁴$！

### 2.3 第4章：进动角的严格推导

#### ✅ 验证通过的部分

**轨道微分方程** (309行)：
```
d²u/dθ² + u = GM/h² + (3GM/c²) u²
```
✅ 量纲正确（每项都是 $[L]^{-1}$），形式与GR一致

**零阶解** (333行)：
```
u₀(θ) = (1/p)(1 + e cosθ)
```
✅ 正确的标准椭圆解

**微扰展开** (355-363行)：
```
d²u₁/dθ² + u₁ = 3GM/(c² p²)(1 + 2e cosθ + e² cos²θ)
              = 3GM/(c² p²)[(1 + e²/2) + 2e cosθ + (e²/2) cos2θ]
```
✅ 正确

**特解求解**：
- 常数项 (369行)：✅ 正确
- $\cos 2θ$ 项 (383-385行)：✅ 正确
- $\cos θ$ 项 (391-403行)：✅ 正确，这是产生进动的关键

#### 🟠 中等问题：进动角识别的近似

**问题4：第4.2节的近似假设** (421-431行)

论文假设：
```
θₙ ≈ 2πn (1 + δ)
```

其中 $\delta$ 是"每弧度的进动率"。

**问题：** 这个假设没有严格证明！为什么进动率是常数？

**更严格的做法：** 应该从微分方程的解直接识别进动角。

**正确的识别方法：**

完整的一阶解 (409行)：
```
u(θ) = (1/p)(1 + e cosθ) + 3GM/(c² p²)(1 + e²/2) 
      + (3GMe)/(c² p²) θ sinθ - (GM e²)/(2c² p²) cos2θ
```

近日点条件：$du/dθ = 0$ (413行)

求导：
```
du/dθ = -e/p sinθ + (3GMe)/(c² p²)(sinθ + θ cosθ) + (GM e²)/(c² p²) sin2θ
```

**关键观察：** 包含 $\theta \cos\theta$ 项，这导致方程不是严格 $2\pi$ 周期的。

**论文的解法** (423-431行)：
在 $\theta \approx 2\pi$ 附近展开，令 $du/dθ = 0$，解得：
```
δ = 3GM/(c² p)
```

**验证：**
- 数量级：$3GM/(c² p) \sim 10^{-7}$（小量）✅
- 量纲：$[1]$ ✅
- 与GR一致 ✅

**结论：** 推导方法虽然不够严谨，但结果正确。
