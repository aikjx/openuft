## 〇 一句话裁定

V48 把下一步押在一个方程上：

$$\bigl[\partial_y+\lambda_i\Phi(y)\bigr]f_{L,i}(y)=0,\qquad \Phi \text{ 由自身作用量变分求出}\tag{48-10}$$

本册把它拆成两个**严格**结论和一个**工具**，全部机核通过：

1. **简并定理（no-go）**：若 `λ` 味普适（三代同一个 `λ`），则三代波函数完全相同 ⇒ 质量全同、`M` 与 `S` 均为秩 1。机核：共同 `λ=18.194710` 时三代质量都是 `105.658375 MeV`；`S` 的本征值 `[-1.8e-16, 8.4e-16, 8.297]`。⇒ **单一背景 + 味普适耦合，在数学上不可能产生层级**。
2. **计数定理**：若允许 3 个 `λ_i`，三代质量可复现到 1e-12，但这是 3 个参数换来 3 个质量；`dm/dλ` 在全网格严格为负（max `−1.83e-9`、min `−6.15e3`）⇒ 质量与 `λ` 一一对应，**没有净参数约化**。`(48-10)` 只是把 V48 的 `z_i` 改名为 `λ_i`（同 V39 的 `4↔4`）。
3. **形状判别器（新工具）**：同一组三代质量、只改背景壁厚 `w`，`S` 的相对偏离从 `0.087%`（w=0.25）单调升到 `6.13%`（w=2.0）；`Q_eμ` 变动 `−19.5%`。⇒ **谱塔是背景形状的可观测函数**，不只是记账工具。反过来说，V44 那张 `S` 矩阵**隐含了"指数型"形状假设**，来料从未声明这一点。

`V49_UNIVERSAL_LAMBDA_DEGENERATES__THREE_LAMBDA_IS_REFIT_NOT_PREDICTION__SPECTRAL_TOWER_IS_SHAPE_SENSITIVE__FLAVOR_PRINCIPLE_ABSENT__NO_FOUR_FORCE_UNIFICATION`

## 一 上游原意与本册的改写

V48 §8 的期望是：找一个**有物理依据的共同标量背景** `Φ(y)` 与规范/边界条件，使三代**不靠逐代调 `λ_i`** 就出现三个不同且稳定的局域化本征态。

本册把这个期望改写成两条可判命题：

- **P1（存在性）**：是否存在 `(Φ, λ)` 使三代质量谱出现？
- **P2（预测性）**：这些质量是**被算出来**的，还是**被拟合出来**的？

机核结果：P1 在"味普适"口径下**否**（简并定理）；放弃普适后 P1 变为**平凡真**（3 个 `λ_i` 拟合任意 3 个质量），但 P2 **否**（计数定理）。这正是 V49 需要被"攻破"的真实位置：**不是解不出方程，而是方程里没有决定 `λ` 比值的原理**。

## 二 T0：一个可解的背景——φ⁴ kink

取

$$\Phi(y)=\tanh\!\Bigl(\frac{1.5-y}{w}\Bigr),\qquad V(\phi)=\frac{(\phi^2-1)^2}{2w^2},$$

它精确满足 `Φ'' = V'(Φ) = 2Φ(Φ²−1)/w²`：机核残差在 `w=0.25/1.5`、`y=0.2/0.5/0.8` 六点上为 **0.000e+00**（解析式代入，非差分）。

这是标准 `φ⁴` 双井的 kink 解，壁在 `y=1.5`（区间 `[0,1]` 之外），故区间内看到的是**kink 尾部**：`Φ` 单调下降、恒正、无零点。选它的理由只有一条：**它是真实作用量的精确解**，不是随手指定的函数——正好回应 V48「Φ 必须由自身作用量变分求出」的要求。

**边界诚实**：本册只把 `Φ` 当作背景 ansatz，**没有**对 `[0,1]` 做端点变分（真实边值问题需镜像或周期延拓）。所以 T0 成立的是"它是 φ⁴ 的精确解"，不是"它是本区间边值问题的解"。

## 三 T1：简并定理（no-go）

### 3.1 陈述与证明

设三代共享同一 `λ`。则

$$f_{L,i}(y)=N\exp\Bigl[-\lambda\textstyle\int_0^y\Phi\Bigr],$$

与 `i` 无关 ⇒ 三个 `f_{L,i}` 是**同一个函数**。于是

$$M_{ij}=\frac{v}{\sqrt2}y_* f_{L}(y_H)f_{R}(y_H)=C\,l_i r_j,\qquad l=(1,1,1),\ r=(1,1,1)\ \text{(比例)}$$

是秩 1 外积 ⇒ 最多一个非零奇异值 ⇒ **最多一个非零 Dirac 质量**。同理 `G_n` 的三行完全相同 ⇒ `S` 秩 1。

### 3.2 机核

| 检验 | 读数 |
|---|---|
| 共同 `λ`（由 `m_μ` 定） | 18.194710 |
| 三代质量 | 105.658375 / 105.658375 / 105.658375 MeV |
| 与真实谱偏差 | +105.147 / 0 / −1671.272 MeV |
| `S` 本征值 | −1.76e-16 / 8.42e-16 / 8.297 |
| 秩判据 `λ₂/λ₃` | 1.01e-16 |

### 3.3 这条定理的杀伤面

它把 V48 §1 的叙述修正为：**"三个 `z_i`"本身就已经是三个味参数**。它们不可能"由一个共同背景产生"——共同背景只会产生一个函数。V48 §6 的 rank≤1 是同一件事的另一面（那里用的是"普适 Yukawa"口径）。⇒ **V49 若继续只调 `Φ`，无论 `Φ` 多精巧，都不会让三代分开**；分开的唯一来源是味依赖（`λ_i`、对角 Yukawa 或味对称荷）。

## 四 T2：计数定理——3 个 `λ` 换 3 个质量

### 4.1 拟合结果（w=1.5）

| 量 | 数值 |
|---|---|
| 拟合 `λ` | `[28.318812, 18.194710, 12.616122]` |
| 复算质量 | `[0.510999, 105.658375, 1776.930000]` MeV（输入同位一致到 1e-12） |
| 等效总指数 `λ_i·∫Φ` | `[16.108785, 10.349822, 7.176516]` |
| V44 的 `z_i` | `[16.218066, 10.446620, 7.260337]` |
| 两者相对差 | 约 `0.7%`（**形状效应**：kink 剖面不是纯指数） |

### 4.2 单调性与双射

`m(λ)` 在 `λ∈[1,60]` 的 300 点网格上严格单调下降（`Δm` 最大值 `−1.83e-9`、最小值 `−6.15e3`，无变号）。⇒ 每个质量唯一确定一个 `λ`，反之亦然。**3 个质量 ⇔ 3 个 `λ`，自由度不变。**

### 4.3 结论

`(48-10)` 在"能复现三代"的意义上**可解**（本册给出了一个精确可解背景 + 三个拟合值），但在"预测三代"的意义上**无进展**：`λ_i` 是反演量，不是本征值。这与 V39 册「KK 参数 4↔4」是同一种病：**换名不约化**。

## 五 T3：谱塔是背景形状的判别器

同一组三代质量、只改壁厚 `w`，重新拟合 `λ` 后重算 `S`：

| `w` | `‖ΔS‖/‖S‖`（相对 V44 矩阵） |
|---|---|
| 0.25 | 0.0866% |
| 0.50 | 1.2156% |
| 0.75 | 2.7872% |
| 1.00 | 4.0188% |
| 1.25 | 4.8680% |
| 1.50 | 5.4454% |
| 2.00 | 6.1292% |

- **单调递增** ⇒ 形状越"厚"，偏离指数型越远（T3d 成立）。
- **薄壁极限回到 V44**：`w=0.25` 时 `Φ≈1`，剖面 `≈e^{−λy}`，`S` 与 V44 只差 `0.087%`。这解释了 V44 的 `S` 为何能只用三个 `z` 描述——**它隐含 `Φ` 常数/指数型剖面**，但 V44/V48 从未把这条假设写出来。
- **味改变量随之改变**：同一组质量与同一组示范角下，`Q_eμ` 由 `0.000683980`（指数型）变为 `0.000550276`（厚壁），**降 19.5%**。

**这条结果的实际价值（也是本册最值得留给后续的一条）**：`S` 不是"由 `z_i` 决定的记账表"，而是 `Φ` **形状**的泛函。若将来 `S` 被某个独立途径确定（例如从 KK 规范耦合的精密测量反演），则它能**反过来排除背景形状**——这给"高维局域化"提供了一条真正可观测的通道。反过来，任何只用三个 `z` 报价 `S` 的结论，都在暗中假设了指数形状。

## 六 T4：V49 的准入线（本册判据，非物理定理）

若一个方案声称"预测三代质量"，它至少必须给出两个**无量纲比值**

$$\frac{\lambda_\mu}{\lambda_e},\qquad \frac{\lambda_\tau}{\lambda_\mu}$$

且不含连续自由参数。理由：三代只有一个整体标度可由 `v` 吸收，剩下两个比值是全部信息量；任何连续可调的比值都等价于两个拟合参数。

据此：

- V48 的 `(48-10)` **不含**固定比值的原理 ⇒ 预测力 `0`；
- 可行的最小扩展是**味荷量子化**：`λ_i ∝ ε^{q_i}`（`q_i` 为整数味荷），比值由整数对 `(q_μ−q_e, q_τ−q_μ)` 决定，至多 2 个离散参数，可被实验排除；
- 更强的要求是让 `λ_i` 成为某个味算符的**本征值**（离散谱），此时比值自动固定——但这需要先写出那个味算符的作用量，本册**未做**。

**注意**：准入线是审计判据，不是"自然必须如此"。它只回答"这个方案是否在预测，而不是在拟合"。

## 八 边界与自抓

1. **不产生新物理**：T1/T2 是线性代数与单调性，T3 是数值泛函；三者都不宣称自然选择。
2. **kink 的边界诚实**：`Φ` 在 `[0,1]` 上只是精确解的尾部，未做端点变分。
3. **T1 的适用范围**：只排除"味普适 `λ`"；不排除味依赖 `λ`、非平凡 Yukawa、多标量、bulk Higgs。
4. **T2 的"可复现"**：质量复现是**构造性**的（先有质量再解 `λ`），不是预测。
5. **T3 的口径**：`Q` 仍用 V44 的示范角（0.20/0.12/0.03），是演示值；`S` 的形状敏感性与角度无关，故该结论不依赖角度选择。
6. **数值精度**：`w=2.0` 时 `S` 的相对偏离 `6.13%` 是 float64 下稳定值（quad 容差默认 1.49e-8，相对误差 <1e-6）。
7. **未做**：`Φ` 的边值问题、味算符的本征值谱、把准入线落到具体可排除的实验数字。
