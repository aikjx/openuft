# 第二十章｜可执行研究任务、验收矩阵与软件复现

## 20.1 代码如何运行

Python 3.10+ 环境：`python run_all.py` 执行 120 项数学/软件回归测试，结果写入 `results/verification_report.json` 和 `results/test_log.txt`。安装 `numpy scipy sympy matplotlib` 后，运行 `python experiments/generate.py`，生成数学符号求导报告、规范耦合曲线、G 参数退化图、KG 能量积分以及组成依赖第五力示意图。双击 `web/index.html` 可访问本地科研交互页面，无需连接远程服务器；图形通过 Canvas2D 三维透视完成，不能误称为完整 WebGL 数字孪生。

## 20.2 五类不同验收不能混淆

- **源码正确性：** 单元测试与类型、异常输入、边界条件正确。
- **数学一致性：** 解析恒等式在符号和数值两套实现中成立。
- **模型可解性：** 选定作用量及边界的方程有可计算解。
- **观测兼容性：** 一组未参与该模型拟合的公开数据与预测相容，且报告统计不确定度。
- **新理论独立性：** 产生不同于既有理论的独立预测并经实验支持，参数由微观公设预先确定。

本包只在第一、第二和部分第三层建立可复查的成果，并用少量已知观测值实施第四层的初步筛选。没有第五层的独立实证，不能宣布大统一已获证明。

## 20.3 最有希望的一条明确路线

可以从能够产生自旋与螺旋相位的微观场出发，优先寻找独立可观测的传播或偏振效应，再将其引力应力张量与 GR 的现有预测严格分离。如果新效应不存在，应如实收紧候选耦合的上界或剔除模型；如果存在，需要排除仪器系统误差、标准模型背景以及既有替代理论的解释。只有在这种可证伪研究链条下，ROOT 才可能获得新的可信科学进展。

## 20.4 发布与知识产权注意

数学恒等式、经典物理事实和已有公开研究不因本研究重写而获得专有权。新候选机制是否具有原创性，需要严谨的文献和专利检索；科学主张不能用“算法联盟最高权限”“无限算力”等表达替代同行审查。研究成果若未来需要发表，应注明模型版本、方法、代码、原始数据、未完成项和所有外部文献来源。
