# ROOT V95｜有限磁场能量条件下的内外螺旋闭环：从局部 Maxwell 场到能量—曲率定律

**研究日期：2026-11-18**  
**审查等级：定理（给定光滑曲线及理想场源的数学命题）／条件数值模拟／反例／开放任务。**  
**声明：未证明“普遍光速螺旋公设”、G 来源、四力统一、引力子观测或真实可运行装置。**

## 摘要

V94 的逆向设计使用全空间理想外场，具有无限磁场能量。本轮解决该特定缺陷：任取一条光滑嵌入闭合空间曲线、一个不超过光速的恒速带电测试粒子，可以在曲线的足够小管状邻域构造一个 **时间无关、C∞、紧支撑、有限能量** 的 Maxwell 磁场，使目标曲线在**忽略粒子自场和辐射反作用**时成为准确的测试粒子轨道。该结果不意味着存在无源静磁结，外部电流必须存在；也不意味着给定轨道稳定。对于本包指定截断函数，磁场能量具有曲率平方积分决定的领先项，并有独立数值积分检验。

## 1. 数学对象与边界

令光滑嵌入闭合曲线 `X(s): S¹→R³` 以弧长参数化，长度 `L`，单位切向量 `T=dX/ds`，曲率向量 `K=dT/ds`，曲率 `κ=|K|`。嵌入并非自交：存在一个足够小的正管状半径 ε，使附近空间点唯一表示为 `x=X(s)+ξ`，`ξ·T(s)=0`，`|ξ|<ε`。需要满足 `D=1−ξ·K(s)>0` 及全局最近点唯一性。**仅有 ε 小于曲率半径并不能排除不同路径段的管道相撞。**

给定测试粒子参数 `m0>0, q≠0, 0<v<c`，`γ=(1−v²/c²)^−1/2`。沿曲线移动的理想运动满足 `v_vec=vT`、`a_vec=v²K`。Lorentz 方程在 `E=0` 时要求 `q v_vec×B0=γm0 a_vec`；最小范数且正交于轨道速度的解是：

`B0(s) = (γ m0 v/q)[K(s)×T(s)]`。

因此 `B0·T=0`，`q vT×B0=γm0 v²K`。该公式由**已知电磁动力学反求**，不是新的基本力律。

## 2. 严格存在性定理：紧支撑静态 Maxwell 逆向场

选用 `f(t)=exp(−t²/(1−t²))`（`0≤t<1`），`f(t)=0`（`t≥1`）；取 `χ_ε(ρ)=f(ρ/ε)`。它在整个区间平滑且所有边界导数为零，满足 `f(0)=1`。

对 `x=X(s)+ξ` 令

`A(x) = χ_ε(|ξ|) [B0(s)×ξ]`，管外取 `A(x)=0`。

设 `B=curl A`、`E=0`、`ρ_external=0`、`J_external=curl B/μ0`。那么：

- `A` 及 `B` 在整个空间光滑（给定足够光滑曲线），支撑集包含于有限管状区域；
- `div B = div curl A = 0`，Faraday 定律由 `E=0` 和 `∂tB=0` 自动满足；
- `curl B = μ0 J_external` 且 `div J_external=0`；
- `U_B=∫ B²/(2μ0)d³x <∞`；
- 在轴线上，`B(X(s))=B0(s)`，带电测试粒子沿预定轨道运行。

注意：`J_external` 并不自动位于轨道之外，可能会穿越粒子通行区。**这只是连续介质电流源的存在性构造，不是已制造的实体线圈。**

## 3. 精确磁场公式及证明

最近点条件 `ξ·T=0` 意味着 `∇s=T/D`，`D=1−ξ·K`。由 `B0·T=0`、`B0'·T=−B0·K` 和矢量恒等式得到（`ρ=|ξ|`）：

```
B(x) = χ[ B0 (2−1/D) + ξ (B0·K)/D ]
     + χ'[ ρ B0 − ξ (B0·ξ)/ρ ] .
```

对 `ρ=0` 取连续极限，第二行归零，`D=1`，所以 `B=B0`。本包数值通过两条独立途径对比：直接计算上式、通过数值差分 `curl A`，并用中心差分独立计算 `div B`。这不是对数值差分精度之外的全部误差的证明；解析 Maxwell 恒等式来自 `B=curl A`。

## 4. 新的曲率—磁能渐近公式

令 `ξ=ερ e_φ`（此处 `0≤ρ≤1` 为无量纲半径）。细管极限 `ε→0` 时，场的领先横截面部分为

`B_lead = f(ρ)B0 + ρf'(ρ)[B0−(B0·e_φ)e_φ]`。

横截面对角度平均后

`⟨|B_lead|²⟩_φ = |B0|² [f²+ρ f f'+(ρ²/2)(f')²]`。

径向积分 `∫₀¹ ρ[f²+ρff']dρ=0`（边界项消失），留下

`I_f=∫₀¹ ρ³ (f'(ρ))² dρ`。

对本轮具体 `f(ρ)=exp[-ρ²/(1−ρ²)]`，令 `z=ρ²/(1−ρ²)`，得：

`I_f = 2∫₀∞ z²e^(−2z)dz = 1/2`。

因此领先能量为

**`U_B(ε) = [π ε²/(4 μ0)] (γm0 v/q)² ∮κ² ds + O(ε⁴)`**。

余项的偶次性质来自关于截面坐标 `ξ→−ξ` 的角积分对所有奇次项消零（固定光滑嵌入曲线、足够小的均匀管道和上述径向截断）。在不同截断函数下系数不同，**这不是一个普遍的新基本物理常数**。

这进一步说明：未额外约束电流密度和源体分辨率时，令 `ε→0`，数学上 `U_B→0`，但 `|J|` 的典型量级随 `1/ε` 增长。因此单凭总磁能有限或趋零无法说明工程可行性；实际装置需要对最大电流密度、热耗散、绝缘隔离和材料强度设限。

## 5. 无源紧支撑静磁场不可能非零：严格反例

假设全空间 `div B=0`、`curl B=0`、场 C² 且紧支撑，则 `ΔB=grad(div B)−curl(curl B)=0`。分量乘 `B` 积分、分部积分：

`∫|∇B|² d³x = −∫ B·ΔB d³x = 0`。

故 `B` 为常量，紧支撑迫使该常量为零。**所以本轮非零局域静态 B 必有非零外部电流 J**。

应区分两类不同对象：Rañada/Hopfion 等 **动态真空 Maxwell 结状场**可具有有限能量，某些场线存在拓扑结；而本轮是**有外部电流的静态磁场，驱动带电测试粒子轨迹**。场线、粒子轨道、光子的轨迹不是同一概念。

## 6. 量纲对碰

`[B]=M I⁻¹T⁻²`，`[A]=M L I⁻¹T⁻²`，`[J]=I L⁻²`，`[μ0]=M L I⁻²T⁻²`；

`[γm0 v κ/q]=M I⁻¹T⁻²`；

`[(B²/μ0)ε²ds]= M L² T⁻²=焦耳`；

`[∮κ²ds]=L⁻¹`；

`[q²γ⁴v³/(ε0 c³) ∮κ²ds]=能量`；

`G=c³/(ħ κ_*²)` 在量纲上成立，但若 κ_* 从 G 的普朗克长度倒推，即循环定义；旧式 `G=cκ` 等不成立。

本包程序审计 24 条等式，20 条通过，4 条故意设置的错误候选被明确拒绝；量纲正确不能推出物理正确。

## 8. 稳定性、相空间、辐射三道无法绕开的困难

1. **稳定性**：此次静场紧支撑构造对一个 2 μm 初始横向偏差，数值粒子在单周期内离开原始轨道；不能用精确解存在性直接宣布稳定。需要专门求解六维辛返回映射及物理电流约束下的稳定可行设计。
2. **保体积**：无辐射反作用的静磁 Hamilton 动力学是保辛/保相空间体积的，不能把孤立稳定闭环误称具有全空间耗散吸引能力。可有中性、椭圆稳定等，不能无条件说所有闭轨都不稳定。
3. **辐射**：加速的带电粒子按经典 Liénard 公式辐射。因为静态磁场严格有 `q(v×B)·v=0`，它不能补偿这部分粒子能量。把反作用加入完整模型后，若要持续严格周期运行，必须另行提供能量或动力学机制。此结论适用于经典辐射模型及其假设，不直接推广到任意量子束缚态。

另外，`B` 的总能量约为单个测试电子动能的 7.14×10⁹ 倍，说明不能把“单电子所需的力”与“整个外部场系统的能量资源”混为一谈。这不是精确定义的最小工程成本。

## 9. 对“所有力由曲率、挠率、角速度统一”的科学裁定

曲率和挠率是轨迹的几何表征，逆向磁场给出了 **已知电磁力在特定轨迹上的几何重新表达**。它不推出电荷量子化、标准模型 `SU(3)×SU(2)×U(1)` 的耦合和粒子谱，也不独立决定引力常数 `G`。加速粒子在电场中沿直线运动时可有零空间曲率而受力非零；普通空间曲率/挠率依赖参考系。真正的统一仍要求协变作用量、正确的量子规范结构、无异常、已知实验极限和独立可证伪预测。
