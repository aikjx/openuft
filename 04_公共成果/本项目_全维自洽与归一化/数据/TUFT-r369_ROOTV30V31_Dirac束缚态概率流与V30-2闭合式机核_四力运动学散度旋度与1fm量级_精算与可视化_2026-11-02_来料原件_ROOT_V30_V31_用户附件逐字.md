# ROOT V30｜从真实 Dirac 束缚态找到精确的旋转电流与能量闭合关系

这轮取得了一项比前面假设内部光速旋转更扎实的结果：氢原子基态的精确 Dirac 方程，即使没有额外引入负能量态，也允许电子概率电流在空间中形成环形流动。

我已完成符号求导和 65 位高精度积分，并独立复算出已知的束缚电子磁矩公式。

## 一、从 Dirac 方程得到旋转速度

在固定、点状原子核的库仑场中：

\[ \left[c\boldsymbol{\alpha}_D\cdot\mathbf p+ \beta_Dm_ec^2-\frac{Z\alpha\hbar c}{r}\right]\psi=E\psi \]

对 \(1s_{1/2}\) 自旋向上态，可取如下精确旋量形式：

\[ \psi= \frac{F(r)}{\sqrt{4\pi}} \begin{pmatrix} 1\\ 0\\ iq\cos\theta\\ iq\sin\theta e^{i\phi} \end{pmatrix} \]

其中：

\[ \gamma_Z=\sqrt{1-(Z\alpha)^2}, \qquad q=\frac{Z\alpha}{1+\gamma_Z} \]

\[ F(r)=Nr^{\gamma_Z-1}e^{-\lambda r}, \qquad \lambda=\frac{m_ecZ\alpha}{\hbar} \]

代入 Dirac 方程，径向方程严格成立。

再计算概率电流：

\[ \rho=\psi^\dagger\psi,\qquad \mathbf j=c\psi^\dagger\boldsymbol{\alpha}_D\psi \]

得到：

\[ \boxed{ \mathbf j=\rho\,cZ\alpha\sin\theta\,\hat{\boldsymbol\phi} } \]

因此，局域概率流速度为：

\[ \boxed{ \mathbf v_{\rm flow}=\frac{\mathbf j}{\rho} =cZ\alpha\sin\theta\,\hat{\boldsymbol\phi} } \tag{V30-1} \]

这是严格的 Dirac–Coulomb 结果，不是人为指定的螺旋轨迹。

对于普通氢原子 \(Z=1\)，赤道方向最大速度为：

\[ \boxed{v_{\rm flow,max}=0.00729735256433\,c} \]

约为 \(2.188\times10^6\ \mathrm{m/s}\)。

但请注意：这是概率电流的局域速度，不是已经测量到某个电子小球沿圆周运动的轨迹。

## 二、发现一个精确的几何—能量闭合式

同一个 Dirac 基态的能量为：

\[ E_{1s}=m_ec^2\sqrt{1-(Z\alpha)^2} \]

结合式 (V30-1)，立即得到：

\[ \boxed{ \left(\frac{v_{\rm flow,max}}c\right)^2+ \left(\frac{E_{1s}}{m_ec^2}\right)^2=1 } \tag{V30-2} \]

这是一个严格的无量纲恒等式。

它在形式上非常接近 ROOT 过去研究的速度分解关系，但这里第二项是束缚态的总能量比，不是独立测得的时间方向速度，也不能直接解释成电子的固有时间流速。

这一结果的重要意义在于：我们找到了一个由已确立 Dirac 动力学支持的、可精确计算的几何—能量对应，而不必先假设电子内部存在实体光速螺旋。

# ROOT V31｜引力、电场力、磁场力与核力：底层运动、方向、距离与散度统一审计

本轮已经完成第一批实际计算和符号核验，得到一个明确的研究结论：

四种基本相互作用可以用场、几何曲率、能量动量交换和运动方程建立统一的数学描述；但它们尚不能被证明是同一种空间光速螺旋运动的简单“发散”。

更准确的攻坚方向，是将底层运动分解为膨胀、旋转、剪切和加速度，再研究不同场如何改变这些运动量。

## 一、首先严格证明：旋转运动不等于空间散度

考虑一种连续的螺旋速度场：

\[ \boxed{ \mathbf v(x,y,z)=(-\Omega y,\Omega x,u) } \]

沿它的流线运动，可以得到圆柱螺旋。

对三个空间方向求散度：

\[ \nabla\cdot\mathbf v =\frac{\partial v_x}{\partial x} +\frac{\partial v_y}{\partial y} +\frac{\partial v_z}{\partial z} \]

得到：

\[ \boxed{\nabla\cdot\mathbf v=0} \]

但计算旋度：

\[ \boxed{ \nabla\times\mathbf v=(0,0,2\Omega) } \]

进一步计算物质导数：

\[ \mathbf a =\frac{\partial\mathbf v}{\partial t} +(\mathbf v\cdot\nabla)\mathbf v \]

得到：

\[ \boxed{ \mathbf a=(-\Omega^2x,-\Omega^2y,0) } \]

这意味着：

- 运动速度场没有局部体积膨胀；
- 它仍然具有非零旋转；
- 它仍然具有真实的向心加速度；
- 带电粒子可以通过磁场力维持这种运动。

散度为零但旋度和向心加速度非零的旋转速度场

由实际计算生成的旋转速度场。散度严格为零，但旋转与加速度并未消失。

因此，一个必须修正的理论命题是：

\[ \boxed{ \text{所有力}=\text{运动速度场的散度} } \]

这个简单形式不成立。

但更完整的命题——力与运动场的膨胀、旋转、剪切、曲率及加速度之间存在统一动力学联系——值得继续研究。

## 三、从引力、电场力、磁场力到核力的逐项求导

### 1. 引力：由势的空间梯度得到吸引方向

对球对称质量 \(M\)，牛顿弱场势为：

\[ \Phi_g=-\frac{GM}{r} \]

因此：

\[ \boxed{ \mathbf F_g=-m\nabla\Phi_g =-\frac{GMm}{r^2}\hat{\mathbf r} } \]

散度方程为：

\[ \boxed{\nabla\cdot\mathbf g=-4\pi G\rho_m} \]

这个方程描述引力场的质量源，并不是运动速度的散度。在广义相对论中，需要进一步用时空曲率和测地线方程解释自由落体。

### 2. 电场力：相同逆平方形式，但方向可反转

\[ \boxed{ \mathbf F_E=\frac{qQ}{4\pi\varepsilon_0r^2} \hat{\mathbf r} } \]

当 \(qQ>0\)，相互排斥；当 \(qQ<0\)，相互吸引。

与引力相比，两者的径向距离规律相同，但是源的类型、符号规则和耦合强度不同。

### 3. 磁场力：方向由叉积决定

\[ \boxed{\mathbf F_B=q\mathbf v\times\mathbf B} \]

其三个方向分量为：

\[ \begin{aligned} F_x&=q(v_yB_z-v_zB_y)\\ F_y&=q(v_zB_x-v_xB_z)\\ F_z&=q(v_xB_y-v_yB_x) \end{aligned} \]

并且：

\[ \boxed{ \mathbf F_B\cdot\mathbf v=0,\qquad \nabla\cdot\mathbf B=0 } \]

磁场有旋度源，却没有普通磁单极子的散度源。这是任何 ROOT 统一公式必须满足的重要约束。

### 4. 强核力：必须区分两个不同尺度

对于静态重夸克—反夸克，采用近似 Cornell 势：

\[ V_{q\bar q}(r)=-\frac{k}{r}+\sigma r \]

求导：

\[ \boxed{ \mathbf F_{q\bar q} =-\left(\frac{k}{r^2}+\sigma\right)\hat{\mathbf r} } \]

其中 \(\sigma\) 是色弦张力。这个线性势是禁闭的有效描述，不能无限延伸到所有距离，也不能直接当作质子之间的核力。QCD 的基本场强具有非阿贝尔自相互作用，这是它与 Maxwell 电磁场的重要区别。

pdg.lbl.gov

核子之间的剩余核力则可以用 Yukawa 尾部作简化近似：

\[ V_N(r)=-A\frac{e^{-r/\lambda_\pi}}r \]

因此：

\[ \boxed{ \mathbf F_N= -Ae^{-r/\lambda_\pi} \left(\frac1{r^2}+\frac1{\lambda_\pi r}\right)\hat{\mathbf r} } \]

真实核力还具有自旋、同位旋和张量结构；不能由一个普适径向标量函数完全描述。

## 五、统一螺旋：把力和运动参数真正连接起来

对匀强磁场中的带电粒子，忽略辐射损耗：

\[ \omega_c=\frac{|q|B}{\gamma m}, \qquad R=\frac{\gamma mv_\perp}{|q|B} \]

如果轴向运动速度为 \(u\)，则：

\[ \kappa=\frac{R\omega_c^2}{v^2}, \qquad |\tau|=\frac{|u|\omega_c}{v^2} \]

因此：

\[ \boxed{ \frac{\kappa}{|\tau|} =\frac{v_\perp}{|u|} } \]

这建立了磁场力—运动频率—速度分解—曲率—挠率的闭合计算。

## 六、最有希望的统一突破：Raychaudhuri 运动膨胀方程

这是本轮最值得继续深入的数学框架。

设相邻物质世界线组成一束，定义四维膨胀率：

\[ \Theta=\nabla_\mu u^\mu \]

利用四维曲率与速度梯度，可以推导：

\[ \boxed{ \frac{d\Theta}{d\tau} = -\frac13\Theta^2 -\sigma_{\mu\nu}\sigma^{\mu\nu} +\omega_{\mu\nu}\omega^{\mu\nu} -R_{\mu\nu}u^\mu u^\nu +\nabla_\mu a^\mu } \]

其中：

- \(\Theta\)：相邻运动轨迹的膨胀或收缩；
- \(\sigma_{\mu\nu}\)：剪切；
- \(\omega_{\mu\nu}\)：旋转或涡量；
- \(R_{\mu\nu}\)：引力时空的 Ricci 曲率；
- \(a^\mu\)：非测地线运动的四加速度。

这是已确立的相对论几何关系，并不是新提出的未经检验方程。

对于经典带电物质，可以通过：

\[ a^\mu=\frac qm F^\mu{}_\nu u^\nu \]

使电磁作用进入 \(\nabla_\mu a^\mu\)。对于色荷，可以建立半经典的非阿贝尔对应，但真实 QCD 禁闭和弱相互作用的粒子转换仍需完整量子场论处理。

所以，我们获得一个非常重要的区分：

\[ \boxed{ \text{各种相互作用影响同一运动几何} } \]

这在合适的适用范围内可以严格成立。

但：

\[ \boxed{ \text{各种相互作用都由同一种螺旋运动唯一产生} } \]

目前仍是需要额外动力学证明的假设。

## 八、最终攻坚结论

本轮真正完成了三件事。

第一，统一了运动的几何描述。 螺旋运动的频率、曲率、挠率、速度分解，与膨胀、旋转、剪切和加速度可以放进相互兼容的数学体系。

第二，明确了各力为什么不同。 引力对能量动量响应；电磁作用对电荷响应；强作用涉及非阿贝尔色荷与禁闭；弱作用具有质量尺度、手征结构和粒子转换。共同的几何描述不能省去这些物理区别。

第三，发现了必须修复的理论缺口。 若 ROOT 真要从一个底层运动导出四种相互作用，就需要同一个 Lorentz 协变作用量，同时推出四种场的源方程、正确力的方向、距离、大小、守恒律及实验规律，而不能只从一个散度或螺旋角度定义四种耦合。

本轮的突破是建立了严格可计算的统一运动学框架，并排除了简单“单一散度产生所有力”的错误版本。尚未完成的是证明四种基本相互作用具有同一个空间光速螺旋微观起源。
