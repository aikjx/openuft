## §2 方法论体系（五层，逐层可复跑）

### 2.1 评级口径：H/O/C/U + L0–L3 + 四态

| 维度 | 含义 |
|---|---|
| **H** | 数学自洽、可独立验证、无循环依赖（可信地基） |
| **O** | 欠定 / 依赖经验锚 / 自承为边界假设（诚实边界） |
| **C** | 内部不自洽、循环论证、数值与文献矛盾（缺陷/冲突） |
| **U** | 仅提出框架、未推导、未验证（未展开） |

层级 **L0**（恒等/同义反复）→ **L1**（概念重述/参数化）→ **L2**（部分推导，依赖外部锚）→ **L3**（第一性推导 + 带误差棒的可检验预言）。
四态判定：`PASS` / `BOUNDARY` / `INFO` / `FAIL`——**任何一份产物必须四态齐备**（吸取「四态退化为二态」的教训，C57 ③）。

> **口径纪律**：数学自洽 ≠ 实验证实 ≠ L3 第一性推导。「精算通过」只说明没被本次复算推翻。

### 2.2 判别式体系（信息论与秩层）：V / V3 / V4 / V5

| 判别式 | 内容 | 出处 |
|---|---|---|
| **V** | 信息增益判别式 $V=(n_{\rm hit}-n_{\rm free}-n_{\rm anchor})/n_{\rm hit}$；$V>0$ 才算派生，$V\le0$ 判伪派生 | `无量纲靶场审计.py` |
| **V3** | $P=h_{\rm ind}-f$、$E=h_{\rm ind}-f-a$ | 书 第56章 |
| **V4** | 秩口径（**唯一不含尺度参数的口径**）：$V_4\le(-\operatorname{rank}(D_A)-\nu)/(\kappa+k)\le0$ | 派生核算 I |
| **V5** | 信息论版（引入 $U,\delta$ 三个可调旋钮 ⇒ 结论不如 V4 可信） | 派生核算 II |

**读数**：18 体系登记的无量纲预测数 = **0** ⇒ 「登记链路能登记、无人填」，这是全仓库最硬的缺口。

### 2.3 定理账本（字母表全局唯一，A–T 见 README 定理登记表；UFS-Δ 系列用希腊字母）

| 定理 | 内容（一句话） | 封死/放行的路线 |
|---|---|---|
| **A** | 独立无量纲数 = nullity$(D_A)$ | 量纲代数的天花板 |
| **C** | 量纲代数**不可能**给出可检验的无量纲预言（两情形穷尽） | **封死**量纲代数 |
| **D** | 旋钮零空间 $\text{nullity}_{\rm dyn}=n-\operatorname{rank}(J_E)$ | 动力学化的判据 |
| **E** | 齐次约束 ⇒ 不能锁定绝对标度 | 封死「标度」 |
| **H** | 7 个初等几何作用量：5 个不能固定 α，其余只到阶 1 值；全局极小必在边界 ⇒ 预言 α∈{0,∞} | **封死**几何作用量 |
| **F/G** | 算子谱路线**条件可行**（需超几何负挠率耦合 + $O(\alpha^2)$ 微调）；几何自然参数全在可行区外 | 放行（带规格） |
| **T** | 精确规格 $\alpha^2=P/(2Q-P)$；钉死 $(A,c)$ ⟺ $\lvert P/Q\rvert=2\alpha^2/(1+\alpha^2)$（**自指循环**）；离散可达集随 N 稠密 ⇒ 大 N 命中无信息量 | **封死**算子谱的钉死 |
| **I/J/K/L** | $h_{\rm eff}=\operatorname{rank}(J)$；纯数因子可提取；代数型派生 $V_4\le0$；谱型**不是**逃生口 | 秩上界 |
| **W** | 十三条定理归约为一条：$m_{\rm rank}\le p-a_{\rm eff}$ ——「派生不产生信息，只产生记账方式」 | 本源不等式 |
| **Θ/Φ/Γ/Λ** | 完备枚举 + 严格显著界 + 平台指数；六种记账约定下结论不变 | 可证伪性 |
| **Σ_cov/Υ** | 账本协方差可反解（$\rho(m_P,m_e)=+0.9812$，余量 254×）；$\nu_{\rm eff}=K(\xi\bmod G)$ | 统计层 |
| **Ω_bits/Φ_bits** | 净比特公式；**二分律**——不存在既净正又有内容的派生声明（裕度 2.49 bit，提高账本位数即可证伪） | 信息预算 |
| **Ξ_alg/Π_code/Ρ_crit/Σ_self** | ν 不可计算但「ν>c」半可判定；码不变性；可证伪阈值 $\Delta^*$；自指闭包 | 元层 |

**三条路线的总账**：量纲代数（**C**，封死）· 几何作用量（**H**，封死）· 算子谱+量子化（F/G 条件可行 → **T** 判钉死不可由本公设闭合）。
共同缺口：**一个打破标度不变性、并提供 $O(\alpha^2)$ 近消去残余的第一性原理项**——且该残余恒等于待预测量本身（T1 自指性）。

## §3 三个结构性结论（全仓库最重要的发现）

### 3.1 普朗克锚定谬误（M02）

$G=c^3/[\hbar(\kappa^2+\tau^2)]$ 与 $m=\hbar\sqrt{\kappa^2+\tau^2}/c$ 联立**必然**推出 $m=m_P$。
正确形式是 $\alpha_{\rm grav}=(m/m_P)^2$。影响 GAQ 谱系全部派生式——曾被「113 项精算 100% 通过」的表象掩盖。

### 3.2 UFT-3 = 0 是**结构性的**，不是努力问题

- 定理 C 扫描 18 体系：动力学本征值 **1** · 量纲代数 **9** · 计数匹配 **2** · 无主张 **2**；
- 三条候选路线被 **C / H / T** 依次封死（几何作用量与量纲代数彻底，算子谱的钉死带自指性）；
- 唯一未封死路线：**动力学本征值**（作用量 + 量子化/边界条件 ⇒ 无量纲数由**解**给出）；
- 因此「再写多少个体系都是 0」——**不换路线，UFT-3 不会自己变正**。

### 3.3 「数学自洽 ≠ 实验证实」被机器化

L3 = 0、UFT-3 = 0、falsified 基线、四态齐备、门禁负向测试——
这些把一条**方法论纪律**变成了**可执行的不变量**。任何人（包括后续会话）想把已判 `falsified` 的主张改回 `pass`，守卫立刻以退出码 1 报警。

## §6 诚实边界与红线（本联盟自己立的规矩）

1. 精算只证「数学自洽」与「与已知实验值一致」，**不证第一性推导**；量纲常数的「导出」是单位换算。
2. **第一性真正靶心是无量纲量**（α、质量比、α_grav）；「导出 c/ℏ/G」是伪目标。
3. 冲突一律如实标 FAIL/BOUNDARY，**不粉饰**；「用了更多符号」不等于「解释力增加」；循环性换壳记为未解除。
4. 不删除不利结果；已判 `falsified` 为终态，条目不得删除（守卫 G4/G5 机器执行）。
5. **不使用夸大表述**（ROADMAP 明文）；「ROOT 最高权限 ✅ 全部通过」类认证已登记为**自封**（S15-C0030）。
6. 证据不得跨体系转移；目录完整、代码跑通、书稿成文**都不构成理论认证**。
