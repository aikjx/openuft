# ROOT V73 版本记录（研究程序版本，不代表物理理论已经验证）

- 新增 RG 指数尺度生成与 UV 输入敏感性；强调其“标度产生 ≠ 预测 G”。
- 新增地球分层球 Yukawa 正确源积分，并修复短程 `exp(R/λ)` 溢出；针对极小 `R/λ` 使用幂级数。
- 将双反转扩展为三重反转 8 状态正交矩阵，保留最重要的同形系统伪差信号反例。
- 新增 4 个浏览器标签页面、离线 Canvas 曲线、11 项 Chromium 交互检查。
- 新增 49 项自动数值/逻辑测试与 11 项 SymPy 条件符号检验。
- 新增 77 条方程索引、37 条方法矩阵、5 组 CSV、4 张计算曲线。
- 明确已证明、条件计算、假设性结果、开放问题和反例状态。
- 继承 V72 历史 ZIP 供参考，不暗示历史版本每项结论都已经重新验证。
