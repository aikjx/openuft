$$
\mathbf{g}(t)=\mathbf{g}_{\text{UV}}+\int_{t_{\text{UV}}}^{t}\boldsymbol{\beta}\big(\mathbf{g}(s)\big)\,ds

1. **吸引盆**：紫外极限下收敛到同一紫外不动点的轨线集合；
2. **分界面（临界曲面）**：轨线跨过该曲面时挠率耦合 $g_3$ 快速变化，对应宇宙拓扑相变 $t_c$；

> **口径澄清（§13 使用）**：设不动点处稳定性矩阵 $B_{ij}=\partial\beta_i/\partial g_j$，

$$
\boldsymbol{\beta}(c\,\mathbf{g})=c^2\boldsymbol{\beta}(\mathbf{g})

## 11. 理论不确定性与高阶修正

1. **本卷仅一圈**；两圈及更高阶会修正 β 系数，移动不动点位置与临界指数的数值 —— 但
   **不会改变 §4.2 的结论**：唯一能给出孤立不动点的是**正则线性项**，与圈数无关。
2. **截断近似**：有效作用量只保留到曲率、挠率二次项；更高阶张量项会扩大相空间维度。
3. **泛函 RG（FRG）**：完整 FRG 比维度正规化更适合引力 RG，后续可替换（结构性替代方案）。
4. **欧氏 vs 洛氏**：本圈 RG 在欧氏时空定义；洛伦兹时空的 RG 流有额外技术复杂性。
5. **本卷未做的关键一项**：A–F 系数的一圈迹计算 ⇒ 见 §13 `V17-H1`。
6. **数值方法学陷阱（本审计新增，务必记住）**：由于 $g_1..g_4$ 无正则线性项，
   $|\boldsymbol{\beta}|=O(|\mathbf{g}|^2)$ 在原点邻域满足 $|\boldsymbol{\beta}|<\epsilon_{\text{abs}}$
   的区域是**四维**的。用绝对容差搜索不动点会得出一整片**伪不动点**
   （本审计首轮即被此陷阱误导出 1200+ 个伪不动点）。
   ⇒ 必须使用**相对容差或最小范数截断**（`V17-W1 = BOUNDARY`）。

### 12.3 数值 RG 流求解代码（清理后的最小可运行版）

> 说明：草稿原文的附录代码存在两类问题 ——(a) 标识符中混入 LaTeX 残片；

> [`tuft_卷十七_RG流与不动点.py`](../07_计算复现/源码/tuft_卷十七_RG流与不动点.py)。

```python
# -*- coding: utf-8 -*-
"""TUFT 卷十七 · 6 维一圈 beta · 最小可运行演示（模型 A / 模型 B 对照）"""
import numpy as np

NAMES = ["g0", "lam", "g1", "g2", "g3", "g4"]

COEF = {                       # 草稿示意系数（非物理推导值）
    "A1": 0.8, "A2": 0.4, "A3": 0.2,
    "B1": -1.2, "B2": 0.5, "B3": 0.3, "B4": 0.1,
    "C1": 1.0, "C2": 0.3, "C3": -0.6, "C4": 0.2,
    "D1": 0.9, "D2": 0.2, "D3": -0.5,
    "E1": 0.7, "E2": -0.4, "E3": 0.2, "E4": 0.1,
    "F1": 0.6, "F2": 0.3,
}

THETA_CANON = np.array([2.0, -4.0, 0.0, 0.0, 0.0, 0.0])   # 模型 B 的正则线性项


def beta_quad(g, c=COEF):
    """模型 A：草稿原文的纯二次 beta（仅 beta_lam 含一次项 B4 g1）"""
    g0, lam, g1, g2, g3, g4 = g
    return np.array([
        c["A1"] * g0 ** 2 + c["A2"] * g0 * g3 + c["A3"] * g3 ** 2,
        c["B1"] * lam * g0 + c["B2"] * g0 ** 2 + c["B3"] * g3 ** 2 + c["B4"] * g1,
        c["C1"] * g1 ** 2 + c["C2"] * g1 * g2 + c["C3"] * g0 * g1 + c["C4"] * g0 * g3,
        c["D1"] * g2 ** 2 + c["D2"] * g1 * g2 + c["D3"] * g0 * g2,
        c["E1"] * g3 ** 2 + c["E2"] * g0 * g3 + c["E3"] * g1 * g3 + c["E4"] * g2 * g3,
        c["F1"] * g4 ** 2 + c["F2"] * g3 * g4,
    ])


def beta_canon(g, c=COEF):
    """模型 B：最小正则补全"""
    return beta_quad(g, c) + THETA_CANON * np.asarray(g, dtype=float)


def jac(f, g, c=COEF, h=1e-7):
    g = np.asarray(g, dtype=float)
    J = np.zeros((6, 6))
    for i in range(6):
        d = np.zeros(6)
        d[i] = h
        J[:, i] = (f(g + d, c) - f(g - d, c)) / (2.0 * h)
    return J


def newton(f, x0, c=COEF, tol=1e-13, itmax=200):
    """阻尼牛顿；返回 (x, 是否收敛)。收敛标志必须返回给调用方。"""
    x = np.array(x0, dtype=float)
    for _ in range(itmax):
        b = f(x, c)
        bn = float(np.max(np.abs(b)))
        if bn < tol:
            return x, True
        try:
            dx = np.linalg.solve(jac(f, x, c), b)
        except np.linalg.LinAlgError:
            return x, False
        step = 1.0
        for _ls in range(12):
            xn = x - step * dx
            if np.all(np.isfinite(xn)) and float(np.max(np.abs(f(xn, c)))) < bn:
                break
            step *= 0.5
        x = x - step * dx
    return x, False


def find_fixed_points(f, n_starts=1200, box=3.0, min_norm=0.05, seed=20260930, c=COEF):
    """多起点牛顿。min_norm 截断用于排除边际方向上的原点邻域伪不动点。"""
    rng = np.random.RandomState(seed)
    out = []
    for _ in range(n_starts):
        x, ok = newton(f, rng.uniform(-box, box, size=6), c)
        if not ok:
            continue
        nrm = float(np.max(np.abs(x)))
        if nrm < min_norm:
            continue
        if float(np.max(np.abs(f(x, c)))) > 1e-9 * max(1.0, nrm * nrm):
            continue
        if not any(float(np.max(np.abs(x - y))) < 1e-5 * max(1.0, nrm) for y in out):
            out.append(x)
    return out


def report(f, tag, c=COEF):
    print("=== " + tag + " ===")
    for x in find_fixed_points(f, c=c):
        ev = np.linalg.eigvals(jac(f, x, c))
        ev = np.sort(np.real(ev))
        n_uv = int(np.sum(ev < -1e-6))
        n_ir = int(np.sum(ev > 1e-6))
        print("  g* = " + np.array2string(x, precision=6))
        print("  theta = " + np.array2string(ev, precision=6)
              + "   dim_crit = %d  n_rel = %d" % (n_uv, n_ir))


if __name__ == "__main__":
    report(beta_quad, "模型 A：草稿原文（纯二次）")
    report(beta_canon, "模型 B：最小正则补全")
    print("提示：模型 A 的 (g0,g3) 二次型正定 => 无非高斯不动点；")
    print("      模型 B 的非高斯不动点全部落在挠率关闭面 {g3=g4=0} 上。")
```

对各系数独立取 $U(-1,1)$，共 160 个样本，每个样本用 20 个起点搜索孤立不动点：

| 统计量 | 结果 |
|---|---|
| 存在非高斯孤立不动点 | 123 / 160 = **76.9 %** |
| 存在 $n_{\text{rel}}\in[1,5]$ 的不动点 | 123 / 160 = **76.9 %**（与上一行同集） |
| 其中 $n_{\text{rel}}\le2$（较可预言） | 98 / 160 = **61.2 %** |
| 且该不动点挠率分量非零 | 63 / 160 = **39.4 %** |
| $n_{\text{rel}}$ 分布（各样本取最小 $n_{\text{rel}}$） | $\{1:65,\ 2:33,\ 3:18,\ 4:5,\ 5:2\}$ |
| 耗时 | 14.7 s |

> 说明：$n_{\text{rel}}$ 分布的分母是「存在非高斯不动点的样本数」（123），不是全部样本数（160）；
> 因此分布计数之和 123 与上表一致。

> 意义：**不动点的存在性、可预言性与「挠率是否被激活」三者都随系数取值大幅摆动。**

> ⇒ `V17-MC1 = BOUNDARY`、`V17-MC2 = OPEN`。
