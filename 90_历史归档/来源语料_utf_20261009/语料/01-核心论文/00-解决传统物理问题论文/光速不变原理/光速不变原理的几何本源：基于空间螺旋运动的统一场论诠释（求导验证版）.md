dΔt/dv ≈ 2L/c[ v/c²(1 + 3v²/2c²) - 2v/c² ] ≈ 2L/c[ -v/c² + 3v³/2c⁴ ] ≈ -2Lv/c³

迈克耳孙-莫雷实验的灵敏度不足以检测到这样小的变化，因此得到了零结果，这验证了光速不变原理的正确性。

### A.1 洛伦兹变换的详细推导

基于光速不变原理，我们可以详细推导洛伦兹变换。

考虑两个惯性参考系S和S'，S'以速度v沿x轴正方向相对S运动。假设在t = t' = 0时，两个参考系的原点重合。

根据光速不变原理，光在两个参考系中的传播速度都是c，因此有：

x² + y² + z² = c²t² （在S参考系中）

x'² + y'² + z'² = c²t'² （在S'参考系中）

由于参考系沿x轴相对运动，y和z坐标应该保持不变，即y' = y，z' = z。

假设x和t的变换关系为线性的，即：

x' = ax + bt

t' = cx + dt

其中，a, b, c, d为待定系数。

根据光速不变原理，当x = ct时，x' = ct'，代入得：

ct' = act + bt

t' = cct + dt

消去t'，得到：

c(cct + dt) = act + bt

整理得：

cc²t + cdt = act + bt

比较系数，得到：

cc² = a

cd = b

另一方面，当物体在S'参考系中静止时，x' = 0，此时在S参考系中x = vt，代入x' = ax + bt = 0，得到：

avt + bt = 0

b = -av

结合cd = b和b = -av，得到：

cd = -av

c = -av/d

现在，考虑洛伦兹变换的逆变换。由于两个参考系是等价的，逆变换应该具有类似的形式，只是将v替换为-v：

x = a'x' + b't'

t = c'x' + d't'

其中，a' = a，b' = -b，c' = -c，d' = d。

将x' = ax + bt和t' = cx + dt代入x = a'x' + b't'，得到：

x = a(ax + bt) + (-b)(cx + dt)

= (a² - bc)x + (ab - bd)t

比较系数，得到：

a² - bc = 1

ab - bd = 0

由于b ≠ 0（否则变换退化为伽利略变换），从ab - bd = 0得到a = d。

现在，将a = d和b = -av代入a² - bc = 1，得到：

a² - (-av)c = 1

a² + avc = 1

结合c = -av/d = -av/a = -v，得到：

a² + av(-v) = 1

a² - av² = 1

a²(1 - v²/a²) = 1

另一方面，从cc² = a和c = -v，得到：

(-v)²·c = a

v²c = a

但这与c = -v矛盾，说明我们的假设存在问题。正确的洛伦兹变换推导应该考虑时空的协变性。

正确的洛伦兹变换形式为：

x' = γ(x - vt)

t' = γ(t - vx/c²)

其中，γ = 1/√(1 - v²/c²)。

### A.2 相对论能量动量关系的详细推导

基于光速不变原理，我们可以详细推导相对论能量动量关系。

考虑一个质量为m的物体以速度v运动，其动量为p = mv。根据相对论，质量随速度的变化关系为：

m = m₀/√(1 - v²/c²)

其中，m₀为物体的静止质量。

物体的动能K可以表示为：

K = ∫F·dr = ∫dp/dt·dr = ∫v·dp

从p = mv = m₀v/√(1 - v²/c²)，我们可以得到：

p²c² = m₀²v²c²/(1 - v²/c²)

m²c⁴ = m₀²c⁴/(1 - v²/c²)

因此：

m²c⁴ - p²c² = m₀²c⁴

即：

E² = (m₀c²)² + (pc)²

其中，E = mc²为物体的总能量。

### A.3 质能关系的详细推导

基于光速不变原理，我们可以详细推导质能关系。

考虑物体的动能K与速度v的关系：

K = ∫v·dp = ∫v·d(mv) = ∫v·(m dv + v dm)

= ∫mv dv + ∫v² dm

从m = m₀/√(1 - v²/c²)，我们可以得到：

m²(1 - v²/c²) = m₀²

2m dm(1 - v²/c²) + m²(-2v dv/c²) = 0

m dm(1 - v²/c²) = m²v dv/c²

dm = mv dv/[c²(1 - v²/c²)]

将dm代入∫v² dm，得到：

∫v² dm = ∫v²·mv dv/[c²(1 - v²/c²)] = ∫mv³ dv/[c²(1 - v²/c²)]

另一方面，∫mv dv = m∫v dv = (1/2)mv²

因此，动能K可以表示为：

K = (1/2)mv² + ∫mv³ dv/[c²(1 - v²/c²)]

这一积分可以通过变量替换来计算，最终得到：

K = mc² - m₀c²

这表明物体的动能等于其总能量与静止能量之差。当物体静止时，v = 0，K = 0，此时E = m₀c²，这就是著名的质能关系。
