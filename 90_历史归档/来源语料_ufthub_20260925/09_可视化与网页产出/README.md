## 如何把它登记为体系证据

1. 读材料本身，确认它证明/否证了什么；
2. 在目标体系的 `claims.csv` 增行，`evidence` 指向本目录下的具体文件；
3. 若无法归入 S01–S14 中任何体系，按 `01_独立体系/新体系模板` 建新体系；
4. 归属完成后，把文件移出本目录，并在 `90_历史归档/迁移记录` 留痕。
