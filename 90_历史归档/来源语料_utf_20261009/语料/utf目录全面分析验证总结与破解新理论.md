**致命问题**：
- 从纯几何（仅含长度L和时间T）无法导出含质量M和电流I量纲的常数

**数学表示**：
```

```

**结论**：仅从c（L/T）无法导出h（ML²/T）和e（IT），除非引入额外假设。

**问题**：
- 仅有x,y分量，**无z分量**

**正确约束**：
$c = \sqrt{(r\omega)^2 + v_z^2}$
$\Rightarrow r\omega < c$（而非论文的 $r\omega = c$）
