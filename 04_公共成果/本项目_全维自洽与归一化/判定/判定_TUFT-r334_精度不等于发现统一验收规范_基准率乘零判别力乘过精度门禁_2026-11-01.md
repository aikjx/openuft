## 〇、一句话结论

本册把本线程三把分散的刀——**r293 巧合基准率、r66/r67「零判别力」、r310 过精度**——
合成一把**可复用、可机读**的统一验收门禁 `discriminate()`。它对任何「我们预言了常数！」类声称做四问：
**超定了吗（盈余≥1）？带内吗？独立（非拟合目标）吗？真针对目标量吗？**
四判例证明它**既不误杀真预言（GR 水星进动），也不误杀真结构进展（r311 BZ 固定点），更不漏放数值拟合（V20 四次候选）**。
判词：**`PRECISION_NEQ_DISCOVERY__UNIFIED_GATE_SHIPS`**

## 一、门禁定义（四问）

```
def discriminate(候选, 中心值, σ, n_matched, n_free, 是否拟合目标, 是否针对目标量):
    surplus      = n_matched - n_free        # r69/r70 超定判据
    within_band  = |候选-中心| ≤ 5σ          # 须在不确定度带内
    残留_rel    = |候选-中心| / |中心|
    if surplus < 1:                 return RELATION_OR_FIT            # 关系非预言
    if not within_band:             return FALSIFIED_AS_PREDICTION    # 过定但数值错
    if 是否拟合目标:                return RELATION_OR_FIT            # 稀有但拟合 ⇒ 非发现
    if not 是否针对目标量:          return STRUCTURAL_ADVANCE_NOT_TARGET
    if 残留_rel < 1e-5 (r293稀有):  return NOTABLE_INDEPENDENT_PREDICTION
    else:                          return GENUINE_PREDICTION
```

### 为什么四问缺一不可（必要性自检，全过）
- **盈余必要**：`surplus=0` 即便带内且独立 ⇒ `RELATION_OR_FIT`（r69：单方程单未知只是关系）。
- **带内必要**：`surplus=1` 但带外（如 V20 简单候选 14505σ）⇒ `FALSIFIED_AS_PREDICTION`。
- **独立必要**：`surplus=1` 带内但「拟合目标」⇒ `RELATION_OR_FIT`（基准率稀有 ≠ 发现）。

## 二、四判例

| 判例 | surplus | 带内 | 残留_rel | 基准率区 | 判定 | 发现? |
|---|---|---|---|---|---|---|
| V20 四次候选 137.0359991772160… | 0 | 是 | 1.58e-12 | RARE(<1e-5) | RELATION_OR_FIT | 否 |
| V20 简单候选 4π³+π²+π=137.03630… | 0 | 否 | 2.22e-6 | COMMON | RELATION_OR_FIT | 否 |

- **V20 四次候选**：surplus=0 + 拟合目标 ⇒ `RELATION_OR_FIT`。其残留 `1.58e-12` 落在 r293 稀有区（<1e-5），
  但因「拟合 CODATA」而**稀有≠发现**——这正是 r310 过精度铁证的形式化。
- **V20 简单候选** `4π³+π²+π`：纯几何数、不针对 α、带外 14505σ ⇒ 非发现（且作为预言已被证伪）。
- **GR 水星进动**（r72 正对照）：surplus=+1、带内、独立、针对目标量 ⇒ 闸门认出**真预言**，证明有牙齿非恒否。
- **r311 BZ 红外固定点**：surplus=+1、真结构进展，但选的是**强扇区耦合**而非 α_em ⇒ `STRUCTURAL_ADVANCE_NOT_TARGET`——
  闸门把它与「数值拟合」区分开，也指出它**不构成 α 的第一性预言**（与 r311 判词 STILL-NOT-A-PREDICTION 一致）。

## 五、诚实边界

1. 本册产出的 `discriminate()` 是**判据工具，不是物理**；它不预言任何新现象，只判决声称。
2. 门禁的「基准率稀有阈值 1e-5」取自 r293 的 229785 对经验表，是经验值非定理；宽严可调。
3. `STRUCTURAL_ADVANCE_NOT_TARGET` 与 `FALSIFIED_AS_PREDICTION` 是**不同性质**的否定：前者肯定进展、只否认它预言目标量；后者否定数值本身。混用会误读 r311。
4. 红线重申：数学自洽 ≠ 实验证实；高精度数值拟合（无论多「准」）在未引入独立选择方程前，永远是关系不是预言。
