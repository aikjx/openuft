# 光速波动验证项目

本项目旨在通过Python模拟电磁波在真空中的传播，验证光速的恒定特性，并从多个角度展示和验证光速的物理性质。

## 项目结构

```
09引力场与旋转速度关系/
├── 1.py                     # 引力场与旋转速度关系方程可视化（原有文件）
├── light_speed_verification.py  # 光速波动验证主程序
└── README.md                # 项目说明文档
```

## 功能介绍

`light_speed_verification.py` 文件实现了以下功能：

1. **一维电磁波传播模拟**：基于麦克斯韦方程组的波动解，模拟电磁波在真空中的传播过程
2. **光速测量验证**：通过追踪波前位置随时间的变化，测量并验证电磁波的传播速度
3. **可视化结果展示**：生成三种不同的可视化图表，直观展示电磁波传播特性
4. **综合光速验证**：从多个角度验证光速的恒定性质，包括：
   - 从电磁常数计算光速
   - 波包传播速度验证
   - 波长-频率关系验证
5. **相对论背景下的光速不变性验证**：展示在不同参考系中光速保持恒定的特性

## 理论基础

本项目基于以下物理理论：

1. **麦克斯韦方程组**：描述电磁场的基本方程，可以推导出电磁波的波动方程
2. **波动方程**：形式为 ∇²E = (1/c²)∂²E/∂t²，其中c为光速
3. **光速的恒定性质**：真空中的光速是一个物理常数，不随参考系变化
4. **相对论**：特别是光速不变原理，这是狭义相对论的基本假设之一

## 运行方法

确保已安装所需的Python库：

```bash
pip install numpy matplotlib
```

然后直接运行主程序：

```bash
python light_speed_verification.py
```

## 输出结果

程序运行后将输出以下内容：

1. **控制台输出**：各种验证结果的数据，包括计算得到的光速、测量到的波速及其相对误差等
2. **可视化图表**：展示电磁波传播过程、波前位置随时间变化、波动方程验证等三个图表
3. **结果图片**：程序会在当前工作目录下生成 `light_speed_verification_results.png` 文件，保存可视化结果

## 关键参数

程序中的关键物理参数包括：
- 光速 c = 3e8 m/s
- 真空磁导率 μ0 = 4πe-7 H/m
- 真空介电常数 ε0 = 1/(μ0·c²) F/m

模拟参数：
- 空间步长 dx = 1e-9 m
- 时间步长 dt = dx/(2c) s (满足CFL条件)
- 模拟空间范围 x_max = 3e-6 m
- 模拟时间范围 t_max = 2e-14 s

## 程序结构

程序采用面向对象的设计，主要由 `LightSpeedVerification` 类实现所有功能：

- `__init__`：初始化物理常数
- `simulate_em_wave_propagation`：模拟一维电磁波传播
- `measure_wave_speed`：测量波的传播速度
- `visualize_results`：可视化验证结果
- `comprehensive_light_speed_verification`：综合光速验证
- `relativistic_light_speed_verification`：相对论光速不变性验证
- `run_complete_verification`：运行完整的验证流程

## 注意事项

1. 程序可能会输出关于特殊数学符号（如∇）在当前字体中缺失的警告，这不影响程序功能
2. 可视化结果图片会保存在程序运行的当前工作目录
3. 模拟过程中使用了高斯脉冲源，更符合实际物理情况
4. 程序采用了数值解法来模拟电磁波传播，考虑了数值稳定性
