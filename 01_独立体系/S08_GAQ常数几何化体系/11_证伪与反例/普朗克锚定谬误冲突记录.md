# 冲突记录：常数几何化的方向性误置与普朗克锚定谬误

> 体系：GAQ 常数几何化体系（S08） · 假设版本 v5（继承 v4）
> 出处：算法联盟全维自洽引擎 M02 / D10 / J01 组（2026-09-15，mpmath 80 位 + sympy 符号求导）
> 状态：**内部冲突（internal_conflict）** + **方向误置（misdirected_goal）**
> ——本体系同时命中两类问题：①与 S07 同源的普朗克锚定谬误；②把单位定义常数当作「几何化成就」。

## 一、冲突一：普朗克锚定谬误（与 S07 同源）

本体系 v5 继承 v4 的 `S08-A2`（`|Ξ|² = κ²+τ² = 1/R²`）与 G 的派生式，
并新增 `S08-A4`（`ħ = m·c·R`）。把 A2 代入 G 式：

```
G = c³/(ℏ · 1/R²) = c³R²/ℏ   ⟹（G 普适）⟹   R = ℓ_P  ⟹   m = ℏ/(cR) = m_P
```

即预言**所有粒子质量 = 普朗克质量**，与 `m_p/m_e = 1836.15` 冲突 **1835 倍**（引擎 `M01-n`，FAIL）。

完整根因诊断见 [S07 同目录记录](../../S07_GAQ复曲率融合体系/11_证伪与反例/普朗克锚定谬误冲突记录.md)。
正确形式为 `α_grav = Gm²/(ℏc) = (m/m_P)²`（引擎 `M02-n`，PASS，残差 `1.69e-81`）。

## 二、冲突二：把单位定义常数当作物理成就（方向误置）

本体系主张「100% 零人为常量，仅 (κ, τ) 两个几何量」，核心动作是
`c = ω·R`（A3）与 `ħ = m·c·R`（A4）把 c、ħ 降为几何桥梁。

**问题**：在 SI 2019 之后——

| 常数 | 性质 | 不确定度 |
|---|---|---|
| `c = 299792458 m/s` | **定义常数**（米的定义） | 精确 0 |
| `h = 6.62607015e-34 J·s` | **定义常数**（千克的定义） | 精确 0 |
| `k_B = 1.380649e-23 J/K` | **定义常数**（开尔文的定义） | 精确 0 |
| `e = 1.602176634e-19 C` | **定义常数**（安培的定义） | 精确 0 |

它们的值由**单位制约定**固定，不是自然界的待解释量。
「从几何导出 c」等价于「从几何导出米的定义」——**是单位换算，不是物理预言**。

### 无量化判据（本次审计的核心方法论）

在普朗克/自然单位制（`c = ℏ = G = 4πε₀ = 1`）下，全部量纲常数的值都被归一为 1；
**残留的只有无量纲数**。因此：

- 「导出 c、ℏ、G」→ 伪目标（单位换算因子）
- 「导出 `α = 1/137.036`、`m_τ/m_e = 3477.2`、`m_μ/m_e = 206.768`」→ **真目标**

**本体系压缩掉的是单位换算因子，保留下来的 α 与质量比才是尚未解决的问题。**
所谓「压缩到 (κ, τ) 两个几何量」并未减少第一性待解释量。

## 三、自由度审计的定量裁决

对 v4/v5/S10 声称的 12 条派生关系、14 个变量构造符号雅可比（列归一化后求秩）：

| 口径 | 秩 | 变量 | 自由度 |
|---|---|---|---|
| 一般位置（泛型秩） | 12 | 14 | 2 |
| 普朗克锚点解流形 | 11 | 14 | 3（理想精确解 10 → 4） |
| 自然单位归一化后 | 5 | 7 | **2** |

（引擎 `H01` / `H01b` / `H04`）

**归一化后仍剩 2 个自由输入：α（耦合强度）与 m/m_P（质量尺度）。**
这两个恰是标准模型同样视为外部输入的量。

> 结论：本体系**并未比标准模型减少自由参数**，只是把参数换成了几何语言表述——
> **形式增益，非信息增益**。

## 四、「零自由参数」的准确含义

`H02` 判定：**「零自由参数」是误述，实为「无拟合参数」。**

- 「无拟合参数」：无需为拟合数据而调节的额外参数 —— 形式上成立
- 「无外部输入」：能从零导出全部常数 —— **不成立**，仍需 α、m_e、G 等测量锚

两者常被混淆。建议在体系文档中固定使用「无拟合参数」表述。

## 五、循环项识别

| 声称的独立关系 | 实际 |
|---|---|
| `ħ = mcR` 与 `m = ℏ/(cR)` | **同一约束**的两种写法（雅可比行成比例，系数 `−1/(cR)`） |
| `e = √(4πε₀·τ/κ·ℏc)` | 代入 `α = τ/κ` 与 `ε₀ = e²/(4παℏc)` 后化为**恒等式 `e² = e²`** |
| `c = ωR` | R 由 c 反定，属定义回指 |

（引擎 `H03`）

## 六、修正建议

1. 把 `c = ωR`、`ħ = mcR` 明确标注为**单位制桥梁**（提供几何图像，不提供物理预言）；
2. G 的派生式降级为普朗克锚点定义式，粒子尺度改用 `α_grav = (m/m_P)²`；
3. 把「零人为常量」改为「无拟合参数」，并注明归一化后仍剩 2 个外部无量纲输入；
4. 真正的攻坚目标重定向至 `α` 与质量比的**第一性导出**——这是本体系目前未触及的部分。

**诚实声明**：本记录为理论内部自洽性审计结论，非实验证伪。
它不否定「几何语言可统一表述常数关系」这一工作（该表述在数学上自洽且有一定教学/组织价值），
但确证两点主张**已失败**：①「由 (κ,τ) 导出 G 并与质量谱共存」；②「常数几何化减少了第一性待解释量」。
