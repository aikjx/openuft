## 四、定理 B · `Z` 恒含于整性集（本卷最硬）

### 陈述

`P(k) = Σ a_j C(k,j)`，`a_j = Δ^j P(0)`（Newton 有限差分）。则

```
a_j ∈ Z  ⇒  P(k) ∈ Z  ∀k ∈ Z  ⇒  Z ⊆ S
```

### 读数

| 条目 | 内容 | 分母 | 读数 |
|---|---|---|---|
| `B01` | `a_j` 全整 | 30 组 | 非整 **0** |
| `B02` | `Z ⊆ S` | 510 点（30 组 × 17） | 违例 **0** |
| `B03` | 反例对照：`a_2 → 1/2` | 13 点 | 不整 **7** |

### 为什么这条改变了四卷的读法

`χ(O_X(kH))` 是**欧拉示性数**（`Σ(−1)^i h^i`），在整数 `k` 上必为整数。所以 `a_j ∈ Z`、`Z ⊆ S` 都是它的直接后果。

**关键在反面**：如果 `Z` 永远在里面，那么「整性逼出格」就**不能**读成「整性把连续通量离散化」——通量早被 `H²(X,Z) = Z·H` 离散化了。整性只是**不反对**它。

> **纪律**：凡报「某条件给出格」，必须与**同题的几何格**逐点比对，报「包含 / 被包含 / 交叉」。只报「是格」是不够的。

### 5.2 `n=1`：解析可证

曲线 `X_d ⊂ CP²` 的 Riemann–Roch：`χ(O(kH)) = dk + 1 − g`。

```
χ ∈ Z  ⟺  dk ∈ Z  ⟺  k ∈ (1/d)Z         机检 d=1..4  4/4
```

**这是本卷唯一有完整证明的一类**，其余靠机检。

## 六、定理 D · `Z+1/2` 是坐标假象（判词主轴）

### 6.1 坐标换算

```
k = q − (n+1)/2
```

`n` 偶 ⇒ 偏移**半整数**。r325 说 `CP²` 的格是 `Z + 1/2`；换到 `k`：

```
q ∈ Z + 1/2   ⟺   k = q − 3/2 ∈ Z          （E01: n=1,2,3,4 全对 4/4）
```

**同一张格两个名字。**

### 6.2 这不是推翻 r325

r325 的格**是对的**。被解释掉的是它的**名字**：`Z+1/2` 让人以为那里有几何内容（`spin^c`、`w₂`）。**在 `k` 坐标下，那个内容为零。**

同理 r331 的功绩要重述：它证明的是「`n_R ∈ Z` 这一条**足以**把 `q` 逼到 `Z`/`Z+1/2`，**不需要 `spin^c`**」——这是对的，且是**削假设**。但它**没有**新增约束，因为 `Z` 早被 `H²(X,Z) = Z·H` 放在那儿了。

> r331 的 `B06`（「判据只是偏移的模 1 类」）说的就是这件事；本卷把它钉到具体数值。

## 七、判据与方法（沉淀给后续卷）

1. **窗口 ≥ `n/2 + 2`**。`d=2` 的额外点恰在 `k = −n/2`；`n=7` 时是 `−7/2`，`[-3,3]` 装不下 ⇒ **非陪集被误判成陪集**。
2. **陪集只能用仿射封闭测**（`u−v+w ∈ S`）。r335 已登记，本卷首版又踩一次（差集封闭）。
3. **测试点不要取 `k=1`**：`C(1,2) = 0`，人为非整系数 `1+k²/2` 在 `k=1` 上仍整。
4. **判「格」必须与几何格逐点比对**，报包含关系，不能只报「是格」。
5. **凡报整性集，必须同时报 `Z ⊂ S` 是否成立** —— 否则读者会以为整性约束了通量。
6. **换坐标时必须报偏移**（`k = q − (n+1)/2`），否则「半整数格」会被当成几何。
