# 第50章 OPEN缺口与攻关路径

> **【整合体系】**：本章是第九编与全书的**缺口总账**。把 V4（四力大统一）、`g2_真推导_电子EDM预测.py`、`α起源探索_诚实分析.py`、`full_verification_report.txt` B31–B40 以及前八编已确认的 openuft 跨体系矛盾，全部登记为 **OPEN** 项，并给出"现状 → 失败原因 → 攻关路径 → 预期里程碑"。
> **【诚实分级】**：所有 **OPEN** 项的失败原因与现状为 **[A]**（脚本已实跑、已登记）；其攻关路径为 **[C]**（待建假设）；任何"宣称已解决"的措辞若无可复现脚本与 CODATA 对标，一律不予采信。B31–B40 全部标注**"概念探索，非已证物理"**。
> **【关键事实】**：候选 ≠ 已验证；数学闭合 ≠ 物理成立；恒等改写 ≠ 第一性推导。本章不掩盖任何缺口，也不为任何 **OPEN** 项预先盖上"已解决"章。

## 50.1 OPEN 缺口总览（五类）

合计 **18 个独立 OPEN 单元**（B31–B40 计 1 组）。

把缺口分成五类，是为了避免把"还没想清楚的概念"和"已经算出来但对不上实验的硬伤"混为一谈。前三类是**可计算缺口**：它们要么有明确的失败数值（如 g-2 偏大、G 差 100%），要么有清晰的待证命题（如拓扑孤子稳定性），可以靠新数学工具或更精细的数值方法推进。第四类 B31–B40 是**概念缺口**：它们连"预言什么可测量"都还没说清，本质上是猜想而非计算。第五类跨体系矛盾则是**内部一致性缺口**：openuft 不同子体系之间的闭式、计数、量纲互相打架，必须先内部自洽，才谈得上对外预言。五类的攻关顺序因此不能颠倒——内部矛盾不清，外推到基本常数就是空中楼阁。

## 50.2 基本常数起源 OPEN（G / ħ / α）

**OPEN-1　G 的独立推导**
- 现状：G 是独立输入常数。旧公式 $G=c^3\alpha^4/[\hbar\kappa_{\rm P}^2(\alpha^2+1)^2]$ 已被 V4 移除。
- 失败原因：① 含循环论证（$\kappa_{\rm P}=1/(2\ell_{\rm P})$，而 $\ell_{\rm P}=\sqrt{\hbar G/c^3}$ 本身含 G）；② 数值与 CODATA $G=6.67430\times10^{-11}$ 差约 100%。另注意：full_verification_report 第128行把 $G=c^3/[2\hbar(\kappa_{\rm P}^2+\tau_{\rm P}^2)]$ 标 [PASS]，但 V4 诚实版明确判其为同义反复（TAUT），**以 V4 为准**。
- 攻关路径：找不依赖 $m_{\rm P}$ 的 G 表达式；或从几何拓扑第一性原理（如曲率自洽条件）导出。
- 预期里程碑：得到一个不含 $\ell_{\rm P}$、不含 G 自身、且与 CODATA 误差 $<1\%$ 的 G 闭式。**[C]**

**OPEN-2　ħ 的独立推导**
- 现状：ħ 是独立输入。旧公式 $\hbar=c\,m_{\rm p}/(4\pi\sqrt{\kappa\tau})$ 已被移除。
- 失败原因：① 无物理依据（为何取 $m_{\rm p}$？为何 $4\pi\sqrt{\kappa\tau}$？）；② 数值不匹配（普朗克尺度差 ~100%，电子尺度差 ~$1.7\times10^5\%$）。
- 攻关路径：从螺旋几何的量子化条件（作用量量子化 $\oint p\,dx=nh$、或角动量量子化）导出 ħ。
- 预期里程碑：$S=\hbar$ 量级的作用量量子化从螺旋边界条件自然涌现。**[C]**

**OPEN-3　α 数值的第一性推导**
- 现状：仅能定义 $\alpha=\kappa/\tau=\rho/b=7.2973525693\times10^{-3}$，**不能推导**其 $\approx1/137$。
- 失败原因（`α起源探索_诚实分析.py` 实跑）：① Neumann 边界 $2x=\tan x$ 只给 $\alpha^2$ 与 $R$ 的关系；② Dirichlet 偏差 15 个数量级；③ 统计力学启发式给不出 1/137；④ 数论（137 为素数、连分数）无法接物理；⑤ 空间离散化（格点数 $\sim2.4\times10^{22}$）无法用小整数比表达。
- 攻关路径：非交换几何、弦紧致化、人择原理、宇宙初始条件；或寻找全新数学结构。
- 预期里程碑：从无自由参数的结构算出 $\alpha^{-1}\approx137.036$。**[C]**（当前判定为**本框架内不可解**，见 OPEN-18）。

这里要特别记录一次"诚实的认输"。`α起源探索_诚实分析.py` 不是一个碰运气的脚本，它系统试了五条当时看起来最有希望的路：从场方程边界条件、到统计力学、到数论连分数、到空间离散格点，每一条都单独写了推导、跑了二分求根、并与 CODATA 对比。五条全部失败，且失败方式清楚——要么只给出关系不给数值，要么差十几个数量级，要么数论观察与物理量之间根本接不上。脚本最后的结论写得很直白：在当前框架内，$\alpha$ 只能是输入。这不是工作不努力，而是说明**光靠"几何 + 边界条件"这一套，在数学上就没有足够的自由度把 $\alpha$ 定死**。承认这一点，比再编一个凑数的闭式要宝贵得多——它告诉后续版本，要解决 $\alpha$，必须引入框架外的新结构（非交换几何、弦紧致化，或干脆承认它是宇宙初始条件），而不是在原方程里反复调边界。

## 50.3 粒子物理 OPEN

**OPEN-4　粒子质量谱 $m_e/m_p$**
- 现状：质量公式 $m=\hbar\sqrt{\kappa^2+\tau^2}/c$ 对单粒子自洽（与 $m_e$ 误差 $<0.01\%$），但**无法**从第一性得到 $m_e/m_p\approx1/1836$。
- 攻关路径：从拓扑孤子稳定性条件导出质量量子化；或从重整化群流推导质量比。
- 预期里程碑：预测 $m_\mu/m_e,m_\tau/m_e$ 在实验误差内。**[C]**

**OPEN-5　g-2 修正**
- 现状：`g2_真推导_电子EDM预测.py` 由螺旋形状因子（雅可比–安格尔展开）算一圈顶点修正，得到的修正量 $\sim\alpha/(8\pi)$，与标准 QED 的 $\alpha/(2\pi)$ 及实验 $a_e$ 矛盾——**修正太大**。
- 攻关路径：更精确的形状因子（高阶贝塞尔项、多模式贡献），或引入辐射重求和。
- 预期里程碑：$a_e$ 预测与 CODATA $a_e\approx1.16\times10^{-3}$ 误差 $<0.1\%$。**[C]**

**OPEN-6　独立于标准物理的新预言（除 EDM 外）**
- 现状：当前唯一可观测新预言是电子 EDM；除此**无真正独立**于标准模型的预言。
- 攻关路径：从螺旋几何推导轻子味破坏、额外维度信号、CP 破坏新相位等。
- 预期里程碑：至少一条"标准模型不预言、而本框架定量预言"的可测量。**[C]**

**OPEN-7　色禁闭 / 质量间隙（S13）**
- 现状：S13 色 SU(3) 禁闭与质量间隙 OPEN，$\alpha_s/\Lambda_{\rm QCD}$ 量级未解，S13 完成度 66%。
- 攻关路径：螺旋拓扑结的弦张力 $\sigma$ 第一性推导，对接格点 QCD。
- 预期里程碑：$\Lambda_{\rm QCD}$ 与弦张力从几何导出。**[C]**

## 50.12 诚实边界与全书总结（章末总结）

**已实现统一的范围 [A]/[B]**：螺旋几何恒等式、KG 型场方程的数学自洽、守恒律可复算数值、NS 涡量方程与螺旋度守恒、形式分离变量解——这些在数学与数值层自洽。

**未实现的范围 [C]**：G/ħ/α 第一性推导、质量谱、g-2、NS↔洛伦兹约化、拓扑孤子稳定性、连续↔离散采样、跨体系矛盾清理、P01–P04 建模。

**红线重申**：
1. **候选 ≠ 已验证**：所有 [B] 映射未经实验确认前，不写入物理事实层。
2. **数学闭合 ≠ 物理成立**：KG 方程自洽不证明真空真是螺旋流形。
3. **恒等改写 ≠ 第一性推导**：Gε₀、G=c³/[2ℏ(κ²+τ²)] 等为定义式组合（TAUT），不构成预言。
4. **B31–B40 为概念探索**，非已证物理，须出可检验预言方可升级。
5. **S01 已证常数生成不可能**：本框架在现有数学结构内对 α/G/ħ 是有效理论（输入常数、输出推论），这不是缺陷，而是当前边界。
6. 全书至此：统一场论 v1 在"几何恒等 + 数值自洽 + 方程形式"三层站住，在"基本常数起源 + 粒子物理 + 完整约化链"三层开放。后续版本（V1.1→V4.0）逐项攻关，不预设成功。
