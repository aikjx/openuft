A. 规范群嵌入检验（P-H4 检验项1 / 阵线1-8）—— 代数层面
------------------------------------------------------------------------------

A1 目标群与被嵌群的维数/秩对照：
    群                                       实维数        秩
    SU(3)xSU(2)xU(1) (标准模型)                  12        4   目标：必须被嵌入
    Spin(1,3) = SL(2,C)                       6        1   洛伦兹自旋群
    Aut(Cl(1,3)) = PGL(4,R)                  15        2   极大紧子群 SO(4)，秩 2
    Aut(Cl(1,3)xC) = PGL(4,C)                30        3   极大紧子群 PSU(4)，秩 3
    SU(4)                                    15        3   4 复维 Clifford 模的幺正群
    SU(5) (最小 GUT)                           24        4   秩刚好容纳 SM
    SO(10) (GUT)                             45        5   秩 5

    >>> 秩障碍：SM 规范群秩 = 4，而 Aut(Cl(1,3)) 的极大紧子群秩 = 2，
        复化后 PGL(4,C) 的极大紧子群 PSU(4) 秩 = 3。
        定理：紧子群的秩不超过母群的秩（Cartan 子群维数单调）。
        4 > 3 >= 2  =>  SU(3)xSU(2)xU(1) 不可能嵌入 4 维 Clifford 代数的自同构群。

    >> R2（规范群嵌入失败）不是『未来风险』，是定理级不可能。

A4 实 Clifford 代数 Cl(p,q) 不可约模的实维数（p=类时, q=类空, n=p+q）
    判据：k=(p-q) mod 8，模实维数 = 2^((n+delta(k))/2)

    (p,q)             n      k       模实维数   Weyl  Major     MW
    (1, 3)            4      6          4   True   True  False
    (1, 9)           10      0         32   True   True   True
    (1, 11)          12      6         64   True   True  False
    (0, 4)            4      4          8   True  False  False
    (0, 8)            8      0         16   True   True   True
    (0, 10)          10      6         32   True   True  False
    (1, 10)          11      7         32  False   True  False
    (1, 1)            2      0          2   True   True   True

    锚点自检（上轮已验证的 7 锚点，此处用同一套函数复算，交叉验证）：

A5 粒子态空间容量对照（决定性）：
    一代标准模型费米子（含 nu_R）= 16 个左手 Weyl 旋量
      = 16 x 2 复分量 = 32 复 = 64 实   （与 Dixon 代数 RxCxHxO 的 64 实维一致）
    Cl(1,3) 不可约模实维数 = 4
    >>> 缺口 = 64 / 4 = 16.0 倍  => 1.20 dex
        三代 = 192 实  => 缺口 48.0 倍

    F4 范畴混装警告：dim_R Cl(1,3) = 16，而一代所需内部空间也正好 16 实维。
      但 16 是【算符代数】的维数，不是【态空间】的维数；态空间只有 R^4。
      把代数维数当粒子态维数 = 范畴混装，不得作为『16 对上了』的理由。

    容量足够的 Lorentz 型 Clifford 代数：
      (p,q)=(1,11)  n=12  模实维数=64  <= 最小解
    >>> 最小解为 Cl(1,11)：12 维时空。P-H1 声明 4 维 => P-H1 与 P-H4 直接互斥。

        正是教科书已知结果，方法复现了它，说明下面对几何统一的判决可信）。


  B3 质子衰变约束（Super-K: tau(p->e+ pi0) > 1.6e34 yr, 90% CL）：
    标定：最小 SU(5) @ M_GUT=1e15 GeV  =>  tau ~ 1e31 yr（量级，强子矩阵元 +-1 dex）

    SM   M_GUT=1.032925e+13 GeV  =>  tau ~ 1.13835e+23 yr
         低于实验下限 1.40555e+11 倍 => 11.15 dex
    MSSM M_GUT=2.0136748e+16 GeV  =>  tau ~ 1.64421e+36 yr
         与实验下限比值 102.763
    >>> 几何统一若取 SM 粒子内容，质子寿命比实验下限低 ~11 dex，已被排除。
        若要躲开，必须引入 MSSM 级别的新粒子谱（~105 个新参数，LHC 未见）。
