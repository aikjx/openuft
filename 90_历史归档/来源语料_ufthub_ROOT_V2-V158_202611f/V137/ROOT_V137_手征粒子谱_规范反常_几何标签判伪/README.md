# ROOT V137｜几何零模—标准模型谱—异常与电荷审查

- **适用环境**：Windows / Linux；Python 3.10+，无第三方依赖。
- **运行**：Windows 双击 `一键验证.bat`，Linux/macOS 执行 `bash 一键验证.sh`，或者 `python src/verify_v137.py`。
- **主要产物**：`研究报告.md`、`核心公式.tex`、`data/verification_results.json`、`data/index_sweep.csv`、`data/representation_template.csv`、`data/anomaly_checks.csv`、`data/named_checks.csv`。
- **历史**：`archive/ROOT_V136_统一场论_十维磁通_手征性_全成果.zip` 是保留原样的上一轮综合研究包，不等于全部旧版本的独立文件逐一复测。
- **测试解释**：大量检查来自有限整数参数扫描。数学恒等式验证**不是**物理发现；标准模型异常消除使用的是人工输入的熟知超荷；理论新颖性与真实实验均未验证。
- **本轮可证伪要点**：单个线丛指标 3 不能自动产生三代规范单态；只用 `(q,m)` 不能给 `u^c` 和 `d^c` 分别决定不同超荷；全球规范群与十维异常未闭合。
- **单位**：仅 `c=1`；`ℏ`、`G` 有量纲且不设置为 1。
