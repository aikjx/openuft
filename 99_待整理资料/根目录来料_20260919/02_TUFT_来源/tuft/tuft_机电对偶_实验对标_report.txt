  §I 材料常数与器件常数的**独立**一致性（非循环）
==============================================================================
  石英 AT 切：ρ = 2650 kg/m³ ，μ = 2.947e+10 Pa（材料测量）
  剪切波速 v = sqrt(μ/ρ) = 3334.78 m/s
  频率常数预测 N = v/2 = 1667.4 Hz·m ；器件手册值 N = 1661 Hz·m
  [PASS] I1 由材料常数预测的 AT 切频率常数与器件手册值一致
         预测 1667 vs 手册 1661 Hz·m，相对偏差 3.847e-03（ρ、μ 与 N 来自不同测量 ⟹ **独立检验**）
  I2 由 N = f0·t 反解真实晶片厚度：
       f0 =      32768 Hz  ⟹  t = 0.0506897 m = 50.6897 mm（AT 切基模）
       f0 =      4e+06 Hz  ⟹  t = 0.00041525 m = 0.41525 mm（AT 切基模）
       f0 =      1e+07 Hz  ⟹  t = 0.0001661 m = 0.1661 mm（AT 切基模）
       f0 =    1.6e+07 Hz  ⟹  t = 0.000103812 m = 0.103813 mm（AT 切基模）
  [INFO] I3 音叉（32.768 kHz）不适用厚度切变公式
         手表音叉是弯曲振动模式，其频率由梁长而非厚度决定；上表对音叉给出的「等效厚度」只是形式换算，物理上是梁长尺度。本册后续对音叉只使用其**电路等效参数**，不套用厚度公式（避免模式错配）。

==============================================================================
  §J 压电本构方程 ⟹ 机电对偶的标定常数（填补 EMD-1 §C4 缺口）
==============================================================================
  [PASS] J1 由本构推出 x = F/k + d·V（k = A/(s^E t)）
         x = V*d + F*s^E*t/A ；减去 F/k + d·V 后 simplify = 0
  [PASS] J2 由本构推出 Q = d·F + C0·V（C0 = ε^T A/t）
         Q = A*V*epsilon^T/t + F*d ；减去 d·F + C0·V 后 simplify = 0
  [PASS] J3 机电耦合系数 k² = d²k/C0 = d²/(s^E ε^T)（无量纲，无自由参数）
         d²k/C0 = d**2/(epsilon^T*s^E) ；d²/(s^E ε^T) = d**2/(epsilon^T*s^E) ；差 simplify = 0
  J4 石英数值：d = 2.31e-12 C/N ，s^E = 1.277e-11 m²/N ，ε^T = 3.984e-11 F/m
      k² = d²/(s^E ε^T) = 0.0104875  ⟹  k = 0.102408
  [PASS] J4 石英机电耦合系数量级正确（k ≈ 0.1，教科书量级）
         k² = 1.049% ，k = 0.1024（石英属弱耦合压电体，对比 PZT 陶瓷 k ~ 0.5-0.7）
  [BOUNDARY] J5 这就是 EMD-1 §C4 缺的那个「标定常数」——但它仍是材料参数，不是普适常数
         EMD-1 证明 [m]/[L] = L⁻²T²I² ≠ 1，故「m 就是 L」非法；本册给出：在压电体中该换算由 k² = d²/(s^E ε^T) 承载（还可写成力-电变换比 φ：L₁ = m/φ², C₁ = φ²/k）。关键：k² **依赖材料与切型**（石英 ~1%、PZT ~50%），所以它是**具体系统的物理参数**，不是宇宙常数。=> 机电对偶的「量化」只能在具体压电体内完成，不能跨材料推广。

==============================================================================

  [BOUNDARY] K3 【循环性警告】Sauerbrey 常数的一致性**不是独立实验验证**

  [PASS] M3 包络衰减率 γ = c/(2m) = R/(2L)（数值峰值拟合）
         拟合 γ = 0.00999998 ；解析 c/(2m) = 0.01000000 = R/(2L) = 0.01000000 ；相对差 1.667e-06
  [PASS] M4 对偶频响逐点重合（|x/F| = |q/V|），导纳 -3dB 带宽 Δω = R/L（Δω/ω0 = 1/Q）

  M6 真实系统 Q 的典型量级（工程范围，非特定测量）：
       石英音叉 32.768 kHz          Q ~ 5e+04
       AT 切 MHz 晶体              Q ~ 1e+05
       MEMS 硅谐振器                Q ~ 1e+04
       超导 Nb 谐振腔                Q ~ 1e+05
       超导 LC (平面)               Q ~ 1e+04
       宏观弹簧（空气）                 Q ~ 1e+02
  [BOUNDARY] M7 Q 不是对偶不变量，而是**损耗机制**的度量
         对偶只保证 Q 的**算式**同形（ω0 m/c = ω0 L/R），但 Q 的**数值**由各自的损耗物理决定（机械：支撑/空气/材料内耗；电路：欧姆/辐射/介质损耗）。实测石英 Q ~ 1e5 而宏观弹簧 Q ~ 1e2，相差 3 个数量级。=> 对偶可以**搬运公式**，不能**搬运 Q 值**；这也是「同一结构」主张的又一处失效点。

==============================================================================
  §O 收口：把「宇宙本源」拆成可证伪的四条，逐条判定
==============================================================================
  主张 P：力学与电磁「底层是同一个振荡结构」。下面把它拆成 4 个可检验子命题：

  [检验 1] 同一物理载体内，机械 Q 与电学 Q 必须不可区分（同一损耗的两种描述）
      ⇒ PASS。压电谐振器的 BVD 参数满足 Q = ω L1/R1 = 1/(ω C1 R1)，且与机械
        振动衰减法测得的 Q 是同一个数（§L/§M）。这是**唯一**让「m 就是 L」
        获得物理意义的场合：不是类比，是同一自由度。

  [检验 2] 存在机械量 ⟷ 电学量的**定量**转换（Sauerbrey / QCM）
      ⇒ 方程本身 PASS，但**证据独立性**降级：QCM 常数由同一公式定义（§K3 循环），
        真正的独立支持来自 QCM 实验的 ng 级秤重能力（实验事实，非本册产出）。

  [检验 3] 跨载体（无共同物理载体）时，同构能给出定量预测
      ⇒ FAIL（EMD-1 §H 双锚点检验）：由 (m,k) 推不出 (L,C)，只有 ω 一个可测量。

  [检验 4] 相对论/高频 regime 下对偶保持
      ⇒ FAIL（EMD-1 §D5）：机械侧有速度上限、EOM 非线性；集总 LC 无协变形式，
        λ ~ c/ω 时必须改 PDE（传输线），自由度无限，不再同构。

  [PASS] O1 四条子命题中，只有「同一载体」的两条成立，跨载体的两条不成立
         检验1 PASS / 检验2 PASS(证据循环，降级) / 检验3 FAIL / 检验4 FAIL ⇒ 主张 P 若解读为「跨系统的宇宙本源」，被证伪；若解读为「压电体内的机电同一」，成立且已被工程使用。
  [BOUNDARY] O2 因此「突破宇宙的秘密」在本册的诚实答案是：**没有宇宙级突破**
         本册真正拿到的是三件小事，但它们是硬的：① EMD-1 §C4 悬空的「标定常数」被落实为材料参数 k² = d²/(s^E ε^T)（无自由参数），机电对偶由此从「类比」升级为「可计算的等效电路」；② 补上阻尼对偶 c↔R 与 -3dB 带宽判据，使对偶可与真实仪器读数直接对照；③ 材料常数与器件常数的一条独立一致性（频率常数 N，0.4% 内）。除此之外，「宇宙底层是同一振荡结构」既无跨系统定量预测力，也在相对论 regime 断裂。
  [INFO] O3 若要继续推进（下一步的真实工作，不是许诺）
         (1) 用具体器件的**实测** datasheet（f_s、f_p、C0、C1、R1、Q）替换本册的典型值，重跑 §L 自洽三式；(2) 补 AT 切张量旋转，把 §L3 的两条 k² 路径从量级一致推到数值一致；(3) 用真实 VNA 扫频数据验证 §M4 的 -3dB 带宽 = 1/Q。这三项都需要真实器件/仪器数据，本册不冒充已完成。

  汇总
==============================================================================
  PASS = 18   FAIL = 0   BOUNDARY = 6   INFO = 4

  本册补齐了 EMD-1 的两个缺口：
   · 标定常数：k² = d²/(s^E ε^T)（压电本构推出，无自由参数，但依赖材料与切型）
   · 阻尼对偶：c ↔ R，Q = ω0 m/c = ω0 L/R = 1/(ω0 C R)，-3dB 带宽 Δω/ω0 = 1/Q
  本册的负面结论（不粉饰）：
   · Sauerbrey 常数的「一致」是循环自证，不是独立实验验证
   · 材料路径与器件路径的 k² 只到量级一致（差约 1.7 倍，需切型张量旋转）
   · Q 值不由对偶决定，而由各自损耗机制决定（石英 1e5 vs 弹簧 1e2）
   · 跨载体同构仍零定量预测力；相对论 regime 对偶仍断裂
