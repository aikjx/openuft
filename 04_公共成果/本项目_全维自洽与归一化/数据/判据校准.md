## V3 判别式对 numerology 的免疫力

> Wyler (1969) 等巧合公式的历史事实：其给出的 α⁻¹ 与观测值极接近（文献记载的“数值巧合”）。
V3 判别式的排除**不靠“数值不够近”**，而靠两层闸门；本例用“3σ 边界巧合”作样本演示搜索空间惩罚：

| 量 | 值 |
| --- | --- |
| α 相对不确定度 | 1.6e-5 |
| 3σ 边界相对偏差（巧合样本） | 4.8e-5 |
| 搜索空间 N（{π,e,小整数} 代数式组合数，保守下界） | 1.0e+12 |
| Bonferroni 阈值 (3/√N) | 3.0e-6 |
| raw 3σ 判定 | ✅ 误判命中 |
| Bonferroni 判定 | ❌ 正确排除 |

**结论**：若 UFT-3 只用 raw 3σ，任何“落在 3σ 内的巧合公式”会**误判为✅**；
经 V3 的两层闸门——`formula_origin` 归桶 + Bonferroni 搜索空间惩罚——**正确排除**。
这证明 V3 判别式是 UFT-3 不可分割的一部分：单条 UFT-3 不足以认定“派生成功”，
必须叠加来源审查与搜索空间惩罚。第57–58章的双口径设计正源于此。

> Wyler 等巧合公式的历史事实：数值落在 α 观测精度内。但 V3 判别式的排除不靠'数值不够近'，而靠两层闸门：(1) formula_origin ∈ {numerology, imported_constant} → 在'仅自身公设'口径下直接归 excluded 桶；(2) 即便按数值口径，搜索空间惩罚使 Bonferroni 阈值收紧至 3/√N。本例 N=1e12 时阈值=3e-6 << 3σ 边界 4.8e-5，故正确排除。

## 校准裁定

判据**有效**：公认理论 SM/GR 得 5–6/6（高分），本联盟 UFE-1 得 2/6（与联盟自身 2/6 一致），numerology 负控制经 V3-Bonferroni 判❌。判据未把'SM+GR 重写'误判为高分，也未把巧合公式放行，说明它测的是'解释/特有结构'而非'覆盖广度'。

### 判据的残余弱点（校准后仍存）

1. **UFT-1 的✅ 仍廉价**：SM/GR/UFE-1/numerology 都得✅，因为它只测'无硬冲突'。
2. **UFT-2'特有项'仍靠人工判词**：UFE-1 的'无特有项'由 README 自承 + 人工判定，未形式化。
3. **档位边界人为**：6/4–5/2–3/0–1 的切法变动，绝对分数不变但档位可能变。
4. **校准组是公认事实的映射，非独立复算**：SM/GR 的打分来自物理学界共识，本引擎未重新推导 SM。

> **校准后的诚实立场**：'联盟 2/6'现在有了标尺——它不是因为判据太松而虚高，
> 也不是因为判据太严而虚低。公认理论在同样尺子下得 4–6/6，本联盟得 2/6，
> 差距来自 UFT-2/4/5/6 的真实缺口，而非尺子本身的问题。
