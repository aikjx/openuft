## 一、这本书回答的唯一大问题

来料几乎不算错——那么「它算对了」和「它预言了」之间差什么？本书的答案是四类可印出来的形状：**双射（0 bit）、坐标伪影（任意目标可造）、自由除数（整数住在定义因子裡）、状态条件（codim 零测）**，以及一条准入线：**自由度账 $n_{\text{free}}\le n_{\text{obs}}-1$** 与**通过率定价**。

## 五、诚实边界

1. **覆盖面由针的形状决定**：「被三把尺取到」是现有尺能解析的面数（现值挂 `精算/_census_report.txt` 账一节，本行不复述）；其余未提取面是模板异代，不是缺陷，也不许并入平均。
2. **PASS 高不等于主张成立**：绝大多数 PASS 住在 A/B 层（条数见 §三 表体），含义是「来料没算错」；判决层几乎单向转否。
3. **不裁定不是否证**：BOUNDARY 与 O 层全部标「未算」。
4. **无观测侧**：本书审计文本的内部一致性与既有常数（CODATA/PDG）的归属关系，不做测量、不与实验装置对接。
5. **不裁物理真**：不判「空间光速螺旋是否为真实自然图景」，只判「这句话此刻是否构成可被否证的预言」。
6. **收录 ≠ 背书**：来料原文以正本形式逐字留档于各卷 `数据/`，本项目不因本书而认可其物理主张，也不因本书否认其代数计算。

## 八、登记轮（2026-11-03）的自陈：本书自己被抓了现行

登记进上级 `openuft/书籍/README.md` 时，登记行的首版把成稿件数**手打**成「精算 5 件」，而盘上是 8 件（普查脚本／读数面／json／登记器＋其 4 份 stdout）。这正是第三章与第五章判给来料的那一类缺陷——**抄进文档的数没有载体，落盘即成假账**。五处自捕，逐条就地处置，凭证留在 `精算/`：

1. **件数改为现扫**：`read_inventory()`＋`scan_num()` 从目录算，且加和必须闭合——每个 `精算/` 文件都要被登记行的名目点名一次；多一件没点名（N14）或缺必需件（N13）⇒ 硬失败，**不许把缺件报成更小的件数**。
2. **`--amend` 而非第二次插入**：更正只替换本轮登记块（行 1 + 树 5），并断言「块外 127 行逐字未动、总行数不变」（守卫 `cut()` 在写盘之前跑，红则不落笔）。旧登记行与旧树块逐字存档在 `精算/_amend_reg_book04.txt` ⇒ 更正记录本身即凭证，不另立台账。
3. **抄录账要有针**：`--check` 的 C6 把本书 §三 表格里的每个抄录值打回普查面重建值。首跑即抓到 3 处红（`139／28／111`、`6 207 B`、`da35c140`）——起因是被审卷在并发推进：判定面分母 139→**140**、未提取 111→**112**，普查面自身也从 6 207 B 变到 6 208 B。文档红 ⇒ 就地更正为上表值；**这就是「引用前重跑」不是客套话的证据**。
4. **git 口径的坑（本轮两次移动）**：`git diff --numstat` 在本库被并发写入者的宽 `git add` 改变语义（状态 `MM` ⇒ 它只印「本轮那一步」4/4，不印累计登记量），累计账须读 `git diff HEAD`；更晚一步，并发提交又把本书登记的**旧像**带进了 HEAD（C5 现印 HEAD=已含｜index=已含｜工作树=是），于是原 C4「删回本轮行 == HEAD 那份」的前提（HEAD 是登记前的面）当场作废 ⇒ 见证改成与 HEAD 版本无关：**两侧各按结构剪掉本书登记块，再比「其余面」**（本轮 127 行 ↔ 127 行等像）。N15 给这条改法定价：同一陈旧面若按值删，剪不掉旧措辞，会谎报「有人改了登记行」。另：`core.autocrlf=true` ⇒ 工作树 CRLF、blob LF，含行尾的直接等像本就不可比，一律在 LF 归一口径上做，并把两侧的 CRLF 数一并印出（不把归一说成「零差异」）。

5. **C6 这根针先咬了自己三口**（都在写盘之前，登记面字节零变动——`--check` 只读）：① `TypeError`：把 list 接到 tuple 上，即「结论行没算完就进了打印流」那一类；② 夹具污染分母：文档变异体夹具与件数夹具同放一个目录，件数针把 `README_clean.md` 当成「精算里多出来的一件」⇒ 夹具按目录分家，并断言「恰 1 针因读自身 stdout 除名」；③ `bytes` 面用 `str` 去 replace ⇒ 变异必须落在真实字节口径上。另记一条**结构性盲区**（不是已修的缺陷）：C6 有一针要读登记器自己的 stdout，而 `--selftest` 那跑该面正被 shell 重定向截断 ⇒ 仪器看不见自己，那针只能由 `--check` 定价。

还有一枚仪器自身的坑记在第六章名下：变异体 N14 起初打在 N13 的残局上（挪走 `audit_corpus_census.json` 后未复原就加杂物 ⇒ 两个断言共用一个失效因）——**反对照必须各自动一根自由度**，否则后一条只是前一条的回声。已补「先复原再加杂物」，并为本轮的 HEAD 口径加了两针（L4 正对照＋N15 负对照：同一陈旧面按值删剪不掉旧措辞，据此会谎报「有人改了登记行」）；枚数以 `精算/_selftest_reg_book04.txt` 末行为准（§三 那行由 C6 现读打回）。

登记轮另记一条边界（不并进 §五 的六条编号——并进就会同时移动登记行里的「诚实边界条数」，须同轮 `--amend`，属两针混因）：登记行的件数取自**写盘前像**。若有人再往 `精算/` 加一份 stdout，本行立即落后一格，`--check` 的 C1 会逐字红 ⇒ 只能 `--amend`，不得留下「文档说 8、盘上 9」的缝。
