## 使用红线

1. **本目录内容不等于本仓库立场**。源材料含「本项目 ROOT 最高权限 ✅ 全部通过」「人类物理学史里程碑」等来源自封断言，本仓库**不沿用**。
2. 引用本目录材料时，必须经由 [../claims.csv](../claims.csv) 的 claim 编号或 [../11_证伪与反例/](../11_证伪与反例/) 的审计结论，不得直接把原文断言当作结论引用。

   [../11_证伪与反例/核心公式常数层_缺陷记录_2026-09-29.md](../11_证伪与反例/核心公式常数层_缺陷记录_2026-09-29.md)。
