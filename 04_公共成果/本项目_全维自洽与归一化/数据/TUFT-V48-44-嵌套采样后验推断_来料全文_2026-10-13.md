## 4.4 嵌套采样后验推断：$\theta$ 全局倾角参数拟合与参数相容性检验

> 目标：使用 dynesty 嵌套采样，在单参数 $\theta\in(0,\pi/2)$ 参数空间，最小化总 $\chi^2$，得到最优倾角 $\theta^*$、后验分布，同时核验 $m_\tau<m_\text{max}$ 稳态约束，输出电子、μ子 TUFT 反常磁矩修正、理论引力常数 $G_\text{th}(\theta)$。
> 前置：上节给出的 $\chi^2(\theta)$ 目标函数与 ptform 先验变换，$m_\text{max}=\dfrac{m_P}{4\pi\sin^2\theta}$。

### 4.4.1 参数空间与先验设定

物理约束：$\theta$ 非常接近 $\pi/2$，$\sin\theta\ll1$，定义小偏移量

$$\delta = \frac{\pi}{2}-\theta,\quad \delta>0,\quad \delta\ll1$$

$$\sin\theta=\sin(\pi/2-\delta)=\cos\delta\approx1-\frac{\delta^2}{2}$$

$$\sin^2\theta\approx 1-\delta^2$$

原 ptform 映射：

$$\delta = 10^{-48+8u},\quad u\in[0,1]$$

- $u=0 \implies \delta=10^{-48}$，$\sin\theta\approx1-5\times10^{-97}$；
- $u=1 \implies \delta=10^{-40}$，$\sin\theta\approx1-5\times10^{-81}$。

> 物理含义：全局倾角偏离直角的偏移 $\delta$ 落在 $[10^{-48},10^{-40}]$ 区间；该区间保证 $m_\text{max}\gg m_\tau$，满足 τ 子稳态存在条件。
> 先验为**对数均匀先验**在 $\delta$ 空间，对应 ptform 中 $u$ 线性映射到 $\log_{10}\delta$。

### 4.4.2 目标函数回顾

$$\chi^2(\theta)=\chi_e^2+\chi_\mu^2+\chi_G^2+\chi_\tau^2$$

$$\chi_e^2=\left(\frac{a_e^\text{pred}-a_e^\text{exp}}{10^{-12}}\right)^2,\quad
\chi_\mu^2=\left(\frac{a_\mu^\text{pred}-a_\mu^\text{exp}}{4\times10^{-7}}\right)^2$$

$$\chi_G^2=\left(\frac{G_\text{th}(\theta)-G_\text{exp}}{G_\text{exp}\cdot10^{-5}}\right)^2$$

$\chi_\tau^2$：当 $\kappa_\text{tau}$ 可求解（$m_\tau<m_\text{max}$）置 0；找不到实根（τ 子超出稳态上限）则惩罚项 $\chi_\tau^2=10^{12}$。

理论引力耦合（TUFT 几何关系）

$$G_\text{th}(\theta)=\frac{c^3 l_P^2}{\hbar\sin\theta}$$

TUFT 反常磁矩修正项：

$$a_\text{TUFT}=-\frac{3c\cot\theta}{4e\hbar},m\kappa_0$$

总预测反常磁矩

$$a^\text{pred}=a^\text{QED}+a_\text{TUFT}$$

质量-曲率隐式方程：

$$m=\frac{\hbar\kappa_0}{c\sin\theta}-\frac{\pi\hbar l_P}{c^3}\kappa_0^2$$

给定 $m,\theta$，`findroot` 求解 $\kappa_0$。

### 4.4.3 嵌套采样执行脚本（dynesty，mpmath 高精度 250 位）

```python
import mpmath as mp
import dynesty
import numpy as np

mp.mp.dps = 250
c    = mp.mpf('299792458')
hbar = mp.mpf('1.0545718176461565e-34')
e    = mp.mpf('1.602176634e-19')
me   = mp.mpf('9.1093837015e-31')
mmu  = mp.mpf('1.883531627e-28')
mtau = mp.mpf('3.16754e-27')
lP   = mp.mpf('1.616255078e-35')
Gexp = mp.mpf('6.67430e-11')
mP   = hbar/(lP*c)

def Rc_of_kap(kap):
    return ((kap * lP**2)/(mp.sqrt(2)*c))**(2/3)

def U_self(kap):
    return (mp.pi*hbar*lP/c) * kap**2

def m_eq(kap, theta):
    sin_th = mp.sin(theta)
    return (hbar*c*kap / sin_th - U_self(kap)) / c**2

def kappa(m, theta):
    def f(kap):
        return m_eq(kap, theta) - m
    # 初始猜测取高曲率尺度
    return mp.findroot(f, 1e34)

def a_tuft(m, theta):
    cot_th = mp.cot(theta)
    kap = kappa(m, theta)
    return -3*c*cot_th/(4*e*hbar) * m * kap

def chi2(theta):
    ae_qed  = mp.mpf('1.15965218128e-3')
    ae_exp  = mp.mpf('1.15965218059e-3')
    amu_qed = mp.mpf('1.16591810e-3')
    amu_exp = mp.mpf('1.16592040e-3')
    sin_th = mp.sin(theta)
    G_th = c**3 * lP**2/(hbar*sin_th)
    ae_pred = ae_qed + a_tuft(me,theta)
    amu_pred = amu_qed + a_tuft(mmu,theta)
    chi_e  = ((ae_pred - ae_exp)/1e-12)**2
    chi_mu = ((amu_pred - amu_exp)/4e-7)**2
    chi_G  = ((G_th - Gexp)/(Gexp*1e-5))**2
    try:
        kap_tau = kappa(mtau,theta)
        chi_tau = mp.mpf('0')
    except:
        chi_tau = mp.mpf('1e12')
    return chi_e + chi_mu + chi_G + chi_tau

def log_likelihood(params):
    theta = params[0]
    return -0.5 * chi2(theta)

def ptform(u):
    # u ∈ [0,1] -> δ ∈ [10^-48, 10^-40]
    log10_delta = -48 + 8*u[0]
    delta = mp.mpf(10)**log10_delta
    theta = mp.pi/2 - delta
    return [theta]

# 嵌套采样初始化
ndim = 1
sampler = dynesty.NestedSampler(log_likelihood, ptform, ndim, nlive=1000)
sampler.run_nested()
res = sampler.results

# 后验汇总
samples = res.samples
logwt = res.logwt
weights = np.exp(logwt - res.logz[-1])

# 后验期望与误差
theta_samp = np.array([float(s[0]) for s in samples])
theta_mean = np.average(theta_samp, weights=weights)
theta_std = np.sqrt(np.average((theta_samp-theta_mean)**2, weights=weights))

delta_mean = float(mp.pi/2 - theta_mean)
sin_th_mean = float(mp.sin(theta_mean))
m_max_mean = float(mP/(4*mp.pi*sin_th_mean**2))
G_th_mean = float(c**3 * lP**2/(hbar*mp.sin(theta_mean)))

print(f"θ mean = {theta_mean:.20e} rad")
print(f"δ = π/2−θ = {delta_mean:.20e} rad")
print(f"sin(θ) = {sin_th_mean:.20e}")
print(f"m_max = {m_max_mean:.4e} GeV")
print(f"G_th = {G_th_mean:.4e} m^3 kg^-1 s^-2")
print(f"G_exp = {float(Gexp):.4e}")

# 粒子预测
def evaluate_at_theta(th):
    sinth = mp.sin(th)
    kap_e = kappa(me, th)
    kap_mu = kappa(mmu, th)
    kap_tau = kappa(mtau, th)
    ae_t = a_tuft(me,th)
    amu_t = a_tuft(mmu,th)
    return kap_e, kap_mu, kap_tau, ae_t, amu_t

kap_e_opt, kap_mu_opt, kap_tau_opt, ae_t_opt, amu_t_opt = evaluate_at_theta(mp.mpf(theta_mean))
print(f"\n核心曲率：")
print(f"κ_e = {float(kap_e_opt):.4e} m⁻¹")
print(f"κ_μ = {float(kap_mu_opt):.4e} m⁻¹")
print(f"κ_τ = {float(kap_tau_opt):.4e} m⁻¹")
print(f"\nTUFT修正：")
print(f"a_e(TUFT) = {float(ae_t_opt):.12e}")
print(f"a_μ(TUFT) = {float(amu_t_opt):.12e}")
```

### 4.4.4 解析预判（采样前解析估计）

由 $G_\text{th}=G_\text{exp}$ 做零阶近似，锁定 $\sin\theta$：

$$G_\text{exp}=\frac{c^3 l_P^2}{\hbar\sin\theta^*}$$

$$\sin\theta^*=\frac{c^3 l_P^2}{\hbar G_\text{exp}}$$

代入常数做量级估算：
$c^3\approx2.694\times10^{25},\ l_P^2\approx2.612\times10^{-70},\ \hbar\approx1.0546\times10^{-34},\ G_\text{exp}\approx6.6743\times10^{-11}$

$$\sin\theta^* \approx \frac{2.694\times10^{25}\times 2.612\times10^{-70}}{1.0546\times10^{-34}\times 6.6743\times10^{-11}}$$

$$\sin\theta^* \approx 0.999717$$

> 这里出现关键信号：零阶引力匹配给出 $\sin\theta^*\approx0.999717$，$\delta=\pi/2-\theta\approx\sqrt{2(1-\sin\theta)}\approx0.0238,\text{rad}$。
> 这和我们预设的 ptform 先验区间 $\delta\in[10^{-48},10^{-40}]$ **严重冲突**。

#### 冲突诊断

1. 旧 ptform 强行锁定 $\delta$ 到极小 $10^{-40}\sim10^{-48}$，也就是强制 $\sin\theta\approx1$；但引力常数的几何公式 $G_\text{th}(\theta)$ 直接给出 $\sin\theta^*$ 接近 1 但有明显偏移，$\delta$ 是 $10^{-2}$ 量级，不是 $10^{-40}$。
2. 原先验范围是基于“$\sin\theta$ 极接近 1”的早期猜想，**与引力耦合方程自相矛盾**。
3. 后果：dynesty 采样被限制在错误参数区域，无法找到全局最优；$\chi^2$ 将维持巨大残差。

> 修正方案：重写 ptform，将 $\delta$ 先验改为覆盖合理区间 $\delta\in[10^{-6},0.1],\text{rad}$，对数均匀先验。

```python
def ptform(u):
    # u ∈ [0,1] → log10 δ ∈ [-6, -1]
    log10_delta = -6 + 5*u[0]
    delta = mp.mpf(10)**log10_delta
    theta = mp.pi/2 - delta
    return [theta]
```

新参数域：

- $u=0:\delta=10^{-6}\implies\sin\theta\approx 1-5\times10^{-13}$
- $u=1:\delta=0.1\implies\sin\theta=\cos(0.1)\approx0.995004$

这个区间包含引力匹配的 $\delta\approx0.0238$，允许采样器找到最小 $\chi^2$。

### 4.4.5 约束相容性检验清单（采样完成后执行）

采样输出最优 $\theta^*$ 之后，逐项核验：

1. 质量上限检验：$m_\text{max}=\dfrac{m_P}{4\pi\sin^2\theta^*}>m_\tau$；τ 子稳态解存在，`findroot` 成功收敛。
2. 引力耦合检验：$G_\text{th}(\theta^*)$ 落在实验 $G$ 的误差带内。
3. 电子反常磁矩残差：$a_e^\text{pred}$ 匹配高精度电子 $g-2$。
4. μ子反常磁矩残差：$a_\mu^\text{pred}$ 匹配 μ子 $g-2$ 偏差。
5. 曲率物理范围：$\kappa_e,\kappa_\mu,\kappa_\tau$ 均小于临界曲率 $\kappa_\text{crit}$，全部落在稳态域。
6. 自能量级检验：$U_\text{self}\ll mc^2$，轻子自能为小修正，不主导静质量。
7. 边界尺度检验：$R_c\gg l_P$，验证 $R_c\gg l_P$ 近似有效；若 $R_c$ 接近 $l_P$，需要进入精确自能修正章节。

### 4.4.6 待解决的次级问题

1. $G_\text{th}(\theta)$ 的推导溯源：确认引力耦合公式来自作用量引力-螺旋场交叉项，不是单纯几何猜式。
2. 误差相关性：$G$、$a_e$、$a_\mu$ 的实验误差之间是否存在协方差，当前 $\chi^2$ 是对角近似。
3. 简并问题：是否存在多个局部极小（多 $\theta$ 值给出相近 $\chi^2$）。
4. 截断误差：$R_c\gg l_P$ 近似带来系统偏差，需要估计并加到总误差预算。
