> **【整合体系】** 算法联盟审计层（`04_公共成果/算法联盟_全维自洽与归一化`）；校准对象含公认理论与本联盟新体系 UFE-1
> **【诚实分级】** 校准方法=[B]（本书自建对照基线）；对照组打分=[A]（映射到物理学界公认事实，非本联盟自评）

## 60.1 为什么必须做外部校准

第55章 §55.8 [C] 待建第1条明确写明了这一缺口：

> UFT-1..6 从未与任何已公认理论（如标准模型、广义相对论）做过对照打分。若把它们打到 6/6，说明判据太松；若打到 2/6，说明判据可能有误。**这个校准不做，判据的信度无从谈起。**

这句话不是谦虚，是方法论的硬要求。一把尺子若只量过自己人造的物件，它的刻度准不准无人知道。要给"联盟 2/6"一个意义，必须先拿这把尺子去量公认理论，看它会不会把标准模型量成 2/6（太严）或 6/6 到毫无区分度（太松）。

本章用 `源码/判据外部校准引擎.py` 把 UFT-1..6 打到 5 个对照组，并专项检验 V3 判别式对 numerology 负控制的免疫力。

## 60.2 校准方法与对照组

判据定义取自第55章 §55.2，逐字沿用，不在校准时改动：

| 编号 | 判据 | 判定方式 |
|---|---|---|
| UFT-1 | 数学自洽 | 硬冲突数 = 0 且有公设可自洽 |
| UFT-2 | 四力统一 | 含本体系特有项的统一作用量 |
| UFT-3 | 常数派生 | 登记无量纲靶 ≥ 3 且 V2 > 0（V3 判别式） |
| UFT-4 | 观测复现 | 复现 SM 粒子谱/耦合，偏差在观测不确定度内 |
| UFT-5 | 可证伪预言 | 有与已知理论不同的可检验预言 |
| UFT-6 | 外部验证 | 生命周期进入 reviewed / validated |

五个对照组：

1. **C1 标准模型 SM**：公认，统一 EM/Weak/Strong 三力，约 19 个自由参数。
2. **C2 广义相对论 GR**：公认，纯经典引力。
3. **C3 SU(5) GUT**：候选框架，单群 SU(5) 统一三力。
4. **C4 本联盟 UFE-1**：`07_统一场方程`——Einstein–Cartan + SM 的形式化核心（README 自承 = SM+GR 重写）。
5. **C5 numerology 负控制**：Wyler α 公式一类纯算术巧合，无作用量、无可检验预言。

对照组的 UFT 打分是对**公认事实**的诚实映射，不是本联盟的自评。例如 SM 得 UFT-4 ✅，是因为它确实复现了全部已观测粒子谱——这是物理学界共识，本引擎未重新推导 SM。

| 对照组 | U1 | U2 | U3 | U4 | U5 | U6 | 得分 |

| 广义相对论 GR | ✅ | ❌ | ❌ | ✅ | ✅ | ✅ | **4/6** |

**定位解读**：

- **SM (5/6)、GR (4/6)**：公认理论应当高分，判据给高分，说明不欠宽松。注意三者都在 UFT-3 上 ❌——因为 α、粒子质量等自由参数对它们都是**输入**，不是派生。这恰与第56章定理 C（无量纲常数从 {c,ℏ,G} 不可派生）一致。
- **SU(5) GUT (5/6)**：候选框架，得分与 SM 同档，符合"结构成立、验证未完"的档位。它 UFT-3 仍 ❌——耦合在 ~10¹⁵ GeV 收敛，但 α 仍非第一性派生；质子衰变尚未观测。
- **UFE-1 (2/6)**：本联盟新体系。**得分与本联盟自身 2/6 完全一致**。这是校准最关键的证据：**判据没有把"SM+GR 重写"误判为高分**。UFE-1 在 UFT-2 上 ❌（无特有项，是 EH+YM+Dirac 重写），UFT-5 上 ❌（其"预言"多为 SM 继承），UFT-6 上 ❌（unreviewed）。它测的是"你解释了什么新东西"，不是"你覆盖了多少已知物理"。
- **numerology (1/6)**：无作用量、无预言，UFT-2/4/5/6 全 ❌，UFT-3 详见 §60.4——经 V3 判别式判 ❌。

## 60.4 V3 判别式对 numerology 的免疫力

UFT-3 单条若只用 raw 3σ，Wyler 这类"数值巧合"会被误判为 ✅。V3 判别式用两层闸门排除它，本引擎用"3σ 边界巧合"样本演示搜索空间惩罚：

| 量 | 值 |
| --- | --- |
| α 相对不确定度 | 1.6e-5 |
| 3σ 边界相对偏差（巧合样本） | 4.8e-5 |
| 搜索空间 N（{π,e,小整数} 代数式组合数，保守下界） | 1.0e+12 |
| Bonferroni 阈值 (3/√N) | 3.0e-6 |
| raw 3σ 判定 | ✅ 误判命中 |
| Bonferroni 判定 | ❌ 正确排除 |

**结论**：3σ 边界巧合（相对偏差 4.8e-5）在 raw 3σ 下被误判为命中；但搜索空间 N=10¹² 时 Bonferroni 阈值收紧到 3e-6，远小于 4.8e-5，故正确排除。这证明 V3 判别式是 UFT-3 不可分割的一部分——单条 UFT-3 不足以认定"派生成功"，必须叠加 `formula_origin` 归桶（第57章）与搜索空间惩罚（第58章）。

> 另一层闸门：Wyler 公式的 `formula_origin = numerology`，在第58章双口径下直接进入 excluded 桶，根本不进入命中计数。数值惩罚是第二道防线，来源审查是第一道。

## 60.5 校准裁定

判据**有效**。理由：

1. 公认理论在同样尺子下得 4–5/6（高分但不满分），说明判据既不欠宽松也不失真。
2. 本联盟 UFE-1 得 2/6，与联盟层自身 2/6 一致——判据对"重写"与"原创"有区分力。
3. numerology 负控制经 V3 判 ❌，说明判据不会被数值巧合刷分。

**"联盟 2/6"现在有了标尺**：它不是因为判据太松而虚高，也不是因为判据太严而虚低。公认理论与本联盟的差距来自 UFT-2/4/5/6 的真实缺口，而非尺子本身的问题。

## 60.6 判据的残余弱点（校准后仍存）

1. **UFT-1 的 ✅ 仍廉价**：SM/GR/UFE-1/numerology 都得 ✅，因它只测"无硬冲突"。
2. **UFT-2 "特有项"仍靠人工判词**：UFE-1 的"无特有项"由 README 自承 + 人工判定，未形式化。什么叫"特有"？多一项 R² 算不算？缺可判定准则。
3. **档位边界人为**：6/4–5/2–3/0–1 的切法变动，绝对分数不变但档位可能变。
4. **校准组是公认事实的映射，非独立复算**：SM/GR 的打分来自物理学界共识，本引擎未重新推导 SM。

## 60.7 本章小结

本章填补了第55章最大的结构性弱点。校准后，"联盟 2/6"从一个容易被质疑的孤立数字，变成了一把已被公认理论标定的尺子上的读数。这把尺子量 SM 得 5/6、量 UFE-1 得 2/6、量 numerology 得 1/6——它有区分度，且区分的方向正确。

> **本章结论**：UFT-1..6 判据经 5 个对照组校准后判定**有效**。SM/GR/SU(5) 得 4–5/6，本联盟 UFE-1 得 2/6（与联盟自身 2/6 一致，未被"SM+GR 重写"虚高），numerology 负控制经 V3-Bonferroni 判 ❌（1/6）。"联盟 2/6" 现已有标尺：差距来自 UFT-2/4/5/6 的真实缺口，而非判据缺陷。判据残余弱点为 UFT-1 ✅ 廉价、UFT-2"特有项"未形式化、档位边界人为、校准组非独立复算。
