# 统一场论核心公式 - 知识图谱关联关系可视化系统

## 项目概述

这是一个震撼全球的知识图谱可视化系统，展示统一场论20个核心公式之间的关联关系。通过最先进的可视化技术，使复杂的物理概念变得人人可理解。

## 技术特点

### 1. 多维度可视化
- **2D力导向图**：清晰展示公式间的关联网络
- **3D知识球体**：提供全局视角的空间关系
- **热力图**：展示公式关联强度
- **时序图**：展示公式推导顺序和抽象层次
- **力链图**：展示物理概念间的传递关系

### 2. 智能算法
- **社区检测**：自动识别相关公式群组
- **中心性分析**：识别核心公式节点
- **路径分析**：找出公式间的最短推导路径
- **布局优化**：自适应屏幕尺寸的智能布局

### 3. 交互式探索
- **节点点击**：展开公式详情和可视化
- **关系悬停**：显示关系类型和强度
- **缩放平移**：自由探索图谱结构
- **筛选功能**：按物理领域、公式类型筛选
- **搜索功能**：快速定位特定公式

### 4. 教育价值
- **公式详情面板**：包含完整数学表达式
- **物理意义解释**：每个公式的物理诠释
- **推导过程展示**：公式间的逻辑关系
- **可视化切换**：关联到现有公式可视化
- **知识问答系统**：基于图谱的智能问答

## 技术架构

### 前端技术栈
- **HTML5 + CSS3 + JavaScript**：基础网页结构
- **D3.js**：力导向图布局和2D可视化
- **Three.js**：3D知识球体可视化
- **ECharts**：热力图、时序图等高级图表
- **KaTeX**：数学公式渲染

### 核心文件结构
```
知识图谱关联关系可视化/
├── index.html              # 主页面
├── data/
│   └── knowledge_graph.json  # 知识图谱数据
├── js/
│   └── threejs_visualization.js  # Three.js 3D可视化
├── css/                    # 样式文件目录
└── img/                    # 图片资源目录
```

## 使用方法

### 本地运行
1. 直接在浏览器中打开 `index.html` 文件
2. 等待知识图谱数据加载完成
3. 使用控制面板调整可视化参数
4. 点击节点查看公式详情
5. 切换不同视图模式探索数据

### 主要功能

#### 视图切换
- **2D力导向图**：默认视图，展示公式关联网络
- **3D知识球体**：全局视角的空间关系
- **热力图**：展示公式关联强度
- **时序图**：展示公式推导顺序
- **力链图**：展示物理概念传递关系

#### 控制面板
- **力导向强度**：调整节点间的排斥力
- **连接距离**：调整节点间的理想距离
- **电荷强度**：调整节点的电荷强度
- **节点大小**：调整节点显示大小
- **连接宽度**：调整连接线宽度
- **按类别筛选**：筛选特定物理领域的公式

#### 布局算法
- **力导向布局**：基于物理模拟的动态布局
- **环形布局**：公式排列成环形结构
- **层次布局**：按抽象层次排列公式
- **重置布局**：恢复默认布局

#### 分析工具
- **社区检测**：识别相关公式群组并着色
- **中心性分析**：基于连接度调整节点大小
- **路径分析**：分析公式间的推导路径
- **导出图谱**：导出知识图谱数据为JSON文件
