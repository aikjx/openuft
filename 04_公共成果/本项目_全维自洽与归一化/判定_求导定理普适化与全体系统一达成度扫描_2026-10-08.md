## 一、普适化：从圆柱螺旋到任意曲线

方法：给定 κ(s)、τ(s)（**不再要求为常数**），积分 Frenet 系统

$$\frac{d\boldsymbol r}{ds}=\hat T,\quad \frac{d\hat T}{ds}=\kappa\hat N,\quad \frac{d\hat N}{ds}=-\kappa\hat T+\tau\hat B,\quad \frac{d\hat B}{ds}=-\tau\hat N$$

（RK4 + 每步 Gram–Schmidt 正交化），再对生成的 r(s) 做五点有限差分复算一阶/二阶导，与 κ(s)、τ(s) 对拍。**全程不碰解析式，是真正的独立复算**。

### 1.1 六条剖型（G-01）

| 剖型 κ(s) / τ(s) | \|d²r/ds²\| vs κ 偏差 | 二阶导·B / \|a\| | 弧长速率偏差 |
|---|---|---|---|
| 常数（圆柱螺旋） | 2.09e−10 | 3.12e−10 | 2.37e−12 |
| 曲率正弦调制 | 1.14e−10 | 1.95e−10 | 5.94e−12 |
| **τ 大幅调制、κ 常数**（τ: 0.2↔2.7） | 3.26e−10 | 4.13e−10 | 1.36e−11 |
| κ 线性增长 + τ 余弦 | 1.76e−10 | 3.11e−10 | 1.13e−11 |
| κ 光滑阶跃（tanh） | 4.35e−10 | 5.25e−10 | 2.74e−11 |
| 强挠率弱曲率 | 4.55e−10 | 5.17e−10 | 1.87e−12 |

⇒ **τ 零贡献从「一条曲线的测试」升格为一般定理**：τ(s) 怎么变，副法向分量都是 ~1e−10（数值噪声级）。上一册 C-03 的牙齿测试由此获得普适性。

### 1.2 自我修正（G-02，MISMATCH 留痕）

判据换成 **N(s) 的共面性**（任取三个 N 的标量三重积最大值）：

| 剖型 | 共面性（三点行列式） |
|---|---|
| **常数（圆柱螺旋）** | **5.50e−14**（共面 ⇒ 方向退化） |
| 曲率正弦调制 | 9.27e−2 |
| τ 大幅调制 | **8.00e−1** |
| κ 线性 + τ 余弦 | 2.89e−1 |
| κ 光滑阶跃 | 4.99e−1 |
| 强挠率弱曲率 | 6.55e−3 |

⇒ **上一册 B-03「方向恒向心、零信息量」降级为圆柱螺旋特例**。一般曲线下 N(s) 扫过球面、方向要素**可变**；但加速度恒沿 +N(s)（指向局部曲率中心，6 条剖型 cos(a,N) 最小 0.999999775）⇒ **「排斥型力不可由该几何导出」的结论不受影响**。

> 这是本系列又一次「自我推翻留痕」：变的是「方向恒定」这一**过强表述**，不变的是「排斥缺失」这一**实质结论**。

### 1.3 普适版传播–力互斥（G-03）

不再需要定义螺旋轴与半径：

$$\text{沿固定方向 }\hat d\text{ 以 }c\text{ 传播}\iff \hat T\equiv\hat d\iff \frac{d\hat T}{ds}=0\iff \kappa\equiv0\iff \boldsymbol F\equiv0$$

机器：κ≡0 且取 T₀=ẑ 时，全程 **T·ẑ = 1.000000000000**（沿 z 以 c 传播），但 κ=0 ⇒ F=0；而 6 条 κ>0 曲线的切向相对初值偏离 **0.166 ~ 1.765**，无法沿任何固定方向传播。

⇒ **比圆柱螺旋版更强**：任何「以 v=c 螺旋为本体、又要求相互作用以 c 传播」的方案，其力恒为零。

## 五、本轮自抓 4 处（已修并复跑 4/4）

1. **κ 硬阶跃剖型**污染有限差分（残差 2.2e−1，纯数值伪影）⇒ 改 tanh 光滑阶跃。教训：**验证定理时剖型必须满足定理的前提（C³），否则测的是差分格式不是物理**。
2. **方向判据选错参考轴**：首版用 N·ẑ 的点积跨度，而圆柱螺旋的轴一般不是 z（初始 T₀=(1,0,0) 时轴沿 Darboux 方向 τT+κB）⇒ 误得「圆柱螺旋也不恒定」。改用**与参考方向无关的共面性判据**（三点行列式）。
3. **直线极限的初值方向**：首版用默认 T₀=(1,0,0) 跑 κ≡0，得 T·ẑ=0 而误判定理失败。「沿某方向传播」要求初始切向**就是**该方向 ⇒ 显式传 T₀=ẑ 后得 1.000000000000。
4. **最小解「不可替代」的统计口径**：首版只对第一个最小解算「去掉它就失败」，结论随取出哪个解而变（偏斜）；改为求**全部最小解的交集** + 频次统计 ⇒ 得到唯一不可替代条目 M3。
