## 〇 必须先回答的问题：什么叫「完成」？

「完成统一场论」在没有可执行定义时不是可判命题——任何人都可以宣称完成了。本册先给出**七条必要条件**（每条均可机读），再判定现状。**七条全过才算完成**。

| 条件 | 名称 |
|---|---|
| U1 | 框架容纳 SM 规范群与全部费米子表示 |
| U2 | 三规范耦合汇聚，且与质子衰变相容 |
| U3 | 引力纳入 |
| U4 | 导出（非拟合）费米子质量与混合参数 |
| U5 | 自由参数数 ≤ 观测数 − 1 |
| U6 | 给出新的**可检验**预言（判别力） |
| U7 | 与全部精密观测相容 |

**U7 是最弱的一条**：相容 ≠ 统一。一个什么都不统一的理论也可以与观测相容。所以 1/7 意味着——**只有"没被排除"这一条成立，统一本身一条都没成立**。

## 一 靶：四力/大统一的判定结果（1/7）

| 条件 | 判决 | 机读 |

### U3 是本册新增的定量定价（此前未给数字）

引力耦合 α_G(E) = (E/E_Pl)²。把它与统一耦合放在一起，缺口一目了然：

- 在 M_GUT = 2.014×10¹⁶ GeV 处，α_G = **2.721×10⁻⁶**，而 α_GUT = 1/24.3 = **4.115×10⁻²** ⇒ **差 1.51×10⁴ 倍 = 4.18 个量级**。
- 反过来说：要让引力"赶上"另三个力，统一点必须在 **2.48×10¹⁸ GeV**；但三力汇聚发生在 2.014×10¹⁶ GeV ⇒ **两者相差 123 倍（2.09 个量级）**。

**这就是"四力统一"与"三力统一"之间的那道坎**：它不是技术困难，是两个能标数量级上的错配。sanity 检验：α_G(E_Pl) = 1 ✓。

## 二 控制组：同一套判据判电弱统一（6/6）

**为什么必须有控制组**：如果一套判据对什么都判 FAIL，它没有任何信息量。电弱统一是人类**唯一真正完成**的统一（Glashow–Weinberg–Salam，1979 诺奖），判据必须给它高分。

| 条件 | 判决 | 机读 |
|---|---|---|
| U1 | **PASS** | SU(2)_L×U(1)_Y 秩 2，容纳全部已知费米子表示 |
| U2 | **PASS** | g 与 g′ 由单一混合角联系：**e = g sinθ_W = g′ cosθ_W**（Fraction 精确层已验证） |
| U3 | N/A | 电弱统一不含引力 |
| U4 | **PASS** | M_W/M_Z = 0.881361 vs cosθ_W = 0.876801 ⇒ **ρ = 1.01043**（树级预言 1，偏差 0.52% 由 m_t/Higgs 圈修正解释） |
| U5 | **PASS** | 统一后 g、g′、θ_W 三者仅 2 个独立 ⇒ 净减 1 个自由参数；v = **246.22 GeV** |
| U6 | **PASS** | 预言中性流（1973 证实）、W/Z 质量（1983 证实）；由精密拟合**预言 m_t = 173 GeV，实测 172.76 GeV ⇒ 偏差 0.139%** |
| U7 | **PASS** | 精密电弱拟合全局一致 |

**精确层校验**：取 sinθ = 3/5、cosθ = 4/5（勾股数），则 g = 5e/3、g′ = 5e/4、g²+g′² = 625e²/144、√(g²+g′²) = 25e/12 ⇒ **M_W/M_Z = (5e/3)/(25e/12) = 4/5 = cosθ_W**（Fraction 精确恒等，非数值近似）。

## 三 结论：统一场论处于什么状态

**未完成，且缺口是结构性的，不是"再算一算"能补的。**

1. **三力统一三条路径已全部收口**（openuft_49 第六轮）：换运行方式 = 重参数化（白费劲）；换谱 ⇒ 质子衰变比实测快 7 个量级；换群 ⇒ 要么把统一点当自由输入（等于没预言），要么预言测不出来。
2. **引力是第二道坎**：与三力差 4.18 个量级，统一能标错配 123 倍（本册 U3 定价）。
3. **判别力缺失**是致命项：唯一可检验的预言（质子衰变）超出近期可及 0.53 个量级 ⇒ 即便理论正确，也**无法在本代实验内被证实或否证**。

**唯一达到「完成」标准的是电弱统一**——它在弱电 sector 内通过了全部适用条件，并给出了被实验证实的定量预言。
