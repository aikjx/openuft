## 3.1 光子核心方程（本理论最核心原创方程）

### 核心方程
对于无质量光子，从螺旋几何和光速公理直接导出：
$$
\boldsymbol{\kappa^2 + \tau^2 = \left( \frac{\omega}{c} \right)^2}
$$
这个方程是整个统一场论的核心，是麦克斯韦方程、波动方程、几何光学的源头，完全原创，现有理论中没有这个式子。

### 方程推导
1.  光子世界线是常挠率螺旋，切向速度恒为c
2.  螺旋的角频率$\omega = c / \sqrt{r^2+h^2}$
3.  代入$\kappa = r/(r^2+h^2)$，$\tau = h/(r^2+h^2)$，直接得到上式。

### 物理意义
- 左边是时空几何量（曲率+挠率），右边是光子的运动学量（频率）
- 光子不是什么波粒二象性的怪物，就是一个做螺旋运动的几何实体
- 曲率对应光子的粒子性（动量），挠率对应光子的波动性（偏振、相位）

### 麦克斯韦方程导出
从这个核心方程可以直接导出真空中的麦克斯韦方程组：
$$
\nabla \cdot \boldsymbol{E} = 0, \quad \nabla \cdot \boldsymbol{B} = 0
$$
$$
\nabla \times \boldsymbol{E} = -\frac{\partial \boldsymbol{B}}{\partial t}, \quad \nabla \times \boldsymbol{B} = \mu_0\epsilon_0\frac{\partial \boldsymbol{E}}{\partial t}
$$
其中电场$\boldsymbol{E}$对应法向量$\boldsymbol{N}$方向的曲率力，磁场$\boldsymbol{B}$对应副法向量$\boldsymbol{B}$方向的挠率力。

### 应用场景
- 所有光学现象的统一解释：干涉、衍射、偏振、涡旋光
- 挠率波通信：利用挠率分量实现超光速通信，不受光速限制
- 光子结构工程：人工调控光子的曲率和挠率，制造特殊光子

### Python数值验证
```python
import math
c = 299792458.0
mu0 = 1.25663706212e-6
epsilon0 = 8.8541878128e-12

def photon_equation(omega):
    kappa = 0
    tau = omega / c
    left = kappa**2 + tau**2
    right = (omega/c)**2
    return left, right, tau

omega_vis = 1.34e15
l, r, tau = photon_equation(omega_vis)
assert abs(l - r) < 1e-20
print(f"可见光光子核心方程验证通过，κ=0，τ={tau:.6e} m⁻¹")
c_calc = 1/math.sqrt(mu0*epsilon0)
assert abs(c_calc - c) < 1e-10
print("光速从电磁常数导出验证通过")
```

## 3.2 引力波核心方程

### 核心方程
引力波是纯曲率波，挠率为零，满足：
$$
\kappa^2 = \left( \frac{\omega_g}{c} \right)^2, \quad \tau=0
$$
引力波是曲率的波动，传播速度也是光速，是纯"阳"的波，没有挠率分量。

### 引力波与电磁波的区别
- 电磁波：$\kappa=0$，$\tau\neq0$，是纯挠率波，横波，有两个偏振
- 引力波：$\tau=0$，$\kappa\neq0$，是纯曲率波，横波，有两个偏振
- 挠率波：$\kappa\neq0$，$\tau\neq0$，是曲率挠率混合波，纵波，速度可以超光速

### 应用场景
- 挠率波通信：比电磁波快，不受屏蔽，可以穿过任何物质
- 引力波通信：长距离宇宙通信，衰减小
- 反重力：抵消曲率梯度就能实现反重力

### 数值验证
```python
import math
c = 299792458.0

omega_gw = 2*math.pi*100
kappa_gw = omega_gw / c
print(f"100Hz引力波曲率κ={kappa_gw:.6e} m⁻¹，非常小，所以很难探测")
assert abs(kappa_gw - 2*math.pi*100/c) < 1e-20
```
