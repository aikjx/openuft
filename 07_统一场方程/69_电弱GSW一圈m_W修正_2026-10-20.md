## 1. 树级关系（on-shell 方案手推）

弱混合角由 `M_W` 定义：`M_W² = M_Z² cos²θ_W = M_Z²(1 − sin²θ_W)`。

μ 衰变给出 `G_F`：
```
G_F/√2 = g²/(8 M_W²),   g² = e²/sin²θ_W = 4πα/sin²θ_W
⇒ G_F/√2 = πα / (2 M_W² sin²θ_W)
```
代入 `M_W² = M_Z²(1 − sin²θ_W)`，令 `s ≡ sin²θ_W`：
```
s(1 − s) = πα / (√2 G_F M_Z²)        ← 树级（Δr = 0）
```
对 `s` 解二次方程取小根，即得树级 `sin²θ_W^tree` 与 `M_W^tree`。

```
s(1 − s) = πα / (√2 G_F M_Z² (1 − Δr))
Δr = Δα − (cos²θ_W/sin²θ_W)·Δρ_top + Δr_rem
```
