## 2. 张量应力平衡核算

来料的条件是 Minkowski、静态、完整孤立系统、边界通量足够快消失。此时 `∂_k T^{kj}=0`，并且恒等式

`∂_k(x^i T^{kj}) = δ^i_k T^{kj} + x^i ∂_k T^{kj} = T^{ij}`

成立。对全空间积分并用边界通量消失，得到

`∫ T^{ij} d³x = 0`

这就是静态孤立系统的 Laue 型应力平衡。核对要点如下：

1. `T^{ij}` 的空间积分是张量整体约束，不要求局域每点应力为零，也不要求每种成分单独为零。
2. 正能量零间隔流 `T_motion^{ij}=Σρ_a n_a^i n_a^j` 对任意向量 `v_i` 给 `v_i T^{ij} v_j = Σρ_a (v·n_a)^2 ≥ 0`，故半正定；其迹为 `Σρ_a = ρ_total`。
3. 若 `ρ_total > 0` 且只有这类半正定运动应力，则 `∫ T_motion^{ij} d³x` 不能全零；必须有相互作用/束缚应力承担相反积分：`∫ T_interaction^{ij} = -∫ T_motion^{ij}`。
4. 结论依赖“孤立 + 边界消失 + 静态”三条件。强曲率、截断区域、忽略边界通量的系统不适用。
5. 来料 256 组、每组 128 方向、共 32768 样本是数值检查，不是物理实验；它只检查半正定与迹读数，不把模型提升为实验事实。

边界：该定理没有推出“引力必须是负应力场”，也没有推出四力共同起源；它只说明在一个定义清楚的静态孤立系统里，正能量运动项若存在，整体账必须由非运动项抵消。

## 3. 三维仿射稳定性核算

来料采用 Skyrme 静态能量写法：`E2=∫tr D`、`E4=∫tr cof D`、`D_ij=-Tr(R_i R_j)/2`。球对称 hedgehog 下

`D = t I + (p-t) nn^T`，其中 `p=F'^2`、`t=sin²F/r²`；
`cof D = pt I + (t²-pt) nn^T`。

用 `∫ n_i n_j dΩ = 4πδ_ij/3` 得 `∫D=(E2/3)I`、`∫cof D=(E4/3)I`。对常矩阵可逆仿射 `x=L y`、det L>0、`U_L(x)=U(y)`，右电流与余子式变换给

`D_L = L^{-T} D L^{-1}`，`cof D_L = (det L)^-2 L cof(D) L^T`，

体积元乘 `det L`，因此

`E_L = E2 det L tr(L^{-1} L^{-T})/3 + E4 tr(L^T L)/(3 det L)`。

令奇异值 `s_i=e^{x_i}`、`S=Σx_i`，得到

`E_L = [E2 Σ e^{S-2x_i} + E4 Σ e^{2x_i-S}]/3`。

在 `E2=E4=E0/2` 时，

`E_L/E0 = Σ cosh(S-2x_i)/3 ≥ 1`，

等号当且仅当所有 `x_i=0`，即 `L` 为刚性旋转。这与 Hessian 谱 `1/3, 4/3, 4/3` 一致：只有整体旋转零模，三个非平凡方向二阶项为正。

边界：这是“球对称 hedgehog + 常矩阵、保方向可逆仿射 + E2=E4 平衡条件”下的全局极小证明。它不覆盖一般非均匀形变、完整动态扰动谱、量子涨落或量子稳定性。V161 README 也明确没有执行真正任意三维动态扰动模拟。

## 4. 吸引与排斥：同一传播核不决定符号

静态 Green 核定义为

`K_mu(r) = exp(-mu r)/(4πr)`，`[mu]=L^-1`。

在来料的静态近似范围内：

- 标准正能动能、线性实标量耦合、静态同号源消去标量场后：`V_s = -hbar g1 g2 K_mu`；
- 标准 Maxwell/Proca 型矢量场、静态同号守恒荷：`V_v = +hbar q1 q2 K_mu`。

对 `r` 求导，同号荷下 `F_r = ± hbar q1 q2 (1+mu r) exp(-mu r)/(4πr²)`，矢量取正、标量取负。于是 `mu=0` 时两种场都可以有光速自由传播，但静态力符号相反；`mu≠0` 时特征速度仍为 `c`，群速度不等于 `c`。

核算结论：传播核 `K_mu` 只承载距离依赖与质量尺度，不承载力的吸引/排斥符号；符号由场的自旋结构、耦合定义和源荷约定决定。该结论不能反推“牛顿引力就是标量场”，也不能概括强力禁闭与弱力手征性。
