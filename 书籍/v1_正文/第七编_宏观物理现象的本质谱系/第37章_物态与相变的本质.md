## 37.1 本源定义：物态是什么

**定义 37.1（宏观物态）**：物态是大量粒子（$\sim 10^{23}$ 量级）在给定温度 $T$、压强 $p$ 下，其集体自由度（位置分布、振动谱、电离度）所取的稳定构型。

**大白话**：单个原子谈不上"固态液态"——固态不是原子硬，而是原子被"卡"在位置上集体振动；液态是"有位置但不固定"；气态是"几乎不管邻居"；等离子态是"电子被撞出来分家"。物态不是物质的标签，是集体自由度的一种**统计平衡构型**。

**统一场论定位（B 类候选）**：M5 对偶镜像度规 $g^{\mathrm{eff}}(r)=g^{\mathrm{eff}}(\ell^2/r)$ 给出"同一物质在不同观测尺度 $r$ 上呈现不同几何相"的可能——固液气等离子在标准物理里是 $T,p$ 平面上的相区，在 M5 图景里可读作"同一基底在不同尺度窗口下的几何投影"。此为结构对应，不作数值断言。

## 37.2 本源方程：四态的第一性原理

### 37.2.1 固态：晶格振动（Debye 模型）

**推导步骤（A 类，标准固体物理）**：

1. $N$ 个原子的晶体有 $3N$ 个正则振动模（三维简正模分解）。
2. 长波近似下声子色散线性：$\omega = v_s k$。
3. 单位体积声子态密度 $g(\omega)=\dfrac{3V\omega^2}{2\pi^2 v_s^3}$（三维波矢球壳计数）。
4. 截止频率由模数守恒定出：$\displaystyle\int_0^{\omega_D} g(\omega)\,\mathrm{d}\omega=3N$，定义 Debye 温度 $\theta_D=\hbar\omega_D/k_B$。
5. 每个频率 $\omega$ 的平均声子数为 Bose 分布 $n_B(\omega)=1/(\mathrm{e}^{\hbar\omega/k_BT}-1)$，积分得内能：

$$U=9Nk_BT\left(\frac{T}{\theta_D}\right)^3\int_0^{\theta_D/T}\frac{x^3}{\mathrm{e}^x-1}\,\mathrm{d}x\qquad\textbf{[A]}$$

低温极限 $T\ll\theta_D$ 给出 $U\propto T^4$、$C_V\propto T^3$（Debye $T^3$ 定律），与低温固体比热实验一致。

### 37.2.2 液态：径向分布函数

**推导步骤（A 类，统计力学）**：

1. 液体无长程平移序，但有短程关联；用对分布函数 $g(r)$ 描述"在距某粒子 $r$ 处再找到一个粒子"的概率相对密度。
2. 成对加和近似下，构型内能（忽略动能）由势能面与结构积分给出：

$$U=2\pi N\rho\int_0^\infty u(r)\,g(r)\,r^2\,\mathrm{d}r\qquad\textbf{[A]}$$

其中 $\rho=N/V$ 为数密度，$u(r)$ 为两两分子对势。
3. 压力方程（virial 方程）：

$$p=\rho k_BT-\frac{2\pi\rho^2}{3}\int_0^\infty r\frac{\mathrm{d}u}{\mathrm{d}r}g(r)\,r^2\,\mathrm{d}r\qquad\textbf{[A]}$$

$g(r)$ 由散射实验（X 射线/中子衍射）实测反演，本式不引入新假设。

### 37.2.3 气态：理想气体与 van der Waals 修正

**推导步骤（A 类，热力学）**：

1. 无相互作用、无体积点粒子：压强由动量流给出，$pV=Nk_BT$（理想气体状态方程）。
2. 计入分子本身体积（可占体积修正 $V\to V-b$）与分子间吸引（平均场修正压强 $p\to p+a/V^2$）：

$$\left(p+\frac{a}{V^2}\right)(V-b)=Nk_BT\qquad\textbf{[A]}$$

van der Waals 方程给出临界点判据 $(\partial p/\partial V)_T=(\partial^2p/\partial V^2)_T=0$，可解析推出临界点 $(p_c,V_c,T_c)$ 间的关系 $p_cV_c/(Nk_BT_c)=3/8$。

### 37.2.4 等离子态：Saha 热电离平衡

**推导步骤（A 类，热电离统计）**：

1. 电离平衡反应 $A^0 \rightleftharpoons A^+ + e^-$，化学势平衡 $\mu_0=\mu_++\mu_e$。
2. 各组分用理想气体化学势 $\mu=\mu_0+k_BT\ln(n/n_0)$ 代入，配分函数计入电子自旋简并因子 $2$ 与离子基态简并比 $g_i/g_n$：

$$\frac{n_i^2}{n_n}=\left(\frac{2\pi m_e k_BT}{h^2}\right)^{3/2}\left(2\frac{g_i}{g_n}\right)\mathrm{e}^{-U_i/k_BT}\qquad\textbf{[A]}$$

其中 $U_i$ 为电离能。温度高到 $k_BT\sim U_i$ 时电子大量脱出，物质由中性气体转为导电等离子体——恒星大气、日光灯焰即此相。

## 37.3 相变临界：一级/二级、临界指数、标度律

### 37.3.1 相变的热力学判据（A 类）

**推导步骤**：

1. 平衡判据：恒温恒压下 Gibbs 自由能 $G=U-TS+pV$ 取极小，其全微分为

$$\mathrm{d}G=-S\,\mathrm{d}T+V\,\mathrm{d}p+\sum_i\mu_i\,\mathrm{d}N_i\qquad\textbf{[A]}$$

2. 一阶导数给出广延量：$(\partial G/\partial p)_T=V$，$(\partial G/\partial T)_p=-S$。
3. **一级相变**：两相 $G$ 相等但一阶导数跳变，$\Delta S\neq0$、$\Delta V\neq0$，故有潜热 $L=T\Delta S\neq0$（如熔化、蒸发）。
4. **二级（连续）相变**：$G$ 一阶导数连续、二阶导数跳变或发散，无潜热，序参量 $\phi$（如磁化强度 $M$）在 $T>T_c$ 连续趋于零。

### 37.3.2 临界指数与标度律（A 类）

约化温度 $t=(T-T_c)/T_c$。临界区附近各观测量服从幂律：

| 观测量 | 幂律 | 指数 |
|---|---|---|
| 序参量（$T<T_c$） | $\phi\propto(-t)^\beta$ | $\beta$ |
| 磁化率 | $\chi\propto\|t\|^{-\gamma}$ | $\gamma$ |
| 比热 | $C_p\propto\|t\|^{-\alpha}$ | $\alpha$ |
| 临界等温线 | $p\propto\phi^\delta$ | $\delta$ |
| 关联长度 | $\xi\propto\|t\|^{-\nu}$ | $\nu$ |
| 关联函数 | $G(r)\propto r^{-(d-2+\eta)}$ | $\eta$ |

**标度律（A 类，由广义齐次假设严格导出）**：

$$\alpha+2\beta+\gamma=2,\qquad \gamma=\beta(\delta-1),\qquad \nu d=2-\alpha\qquad\textbf{[A]}$$

实验验证：液气临界点、铁磁体居里点、二元混合液在 $1\%$ 精度内满足上述关系——标度律是普适的，与微观细节无关（普适类）。

### 37.3.3 统一场论映射（B/C 类，明确标注）

- **B 类·M4 重整化群不动点**：相变临界点正是 Wilson RG 流的红外不动点——粗粒化到无穷尺度时系统耦合流向 $g^*$，关联长度发散 $\xi\to\infty$ 即"无特征尺度"。本理论 M4 给出成对不动点 $\pm g^*=\pm\sqrt{\varepsilon/c}$（S13 ch09，verified 实验三），可作"相变=β流不动点跃迁"的结构对应。**注意**：S13 的不动点是耦合流不动点，与热力学临界点的对应是**结构类比**，尚未把 $T_c$ 与 $\ell$ 定量挂钩，属 B 类。
- **B 类·M5 对偶度规**：不同物态读作"同一物质在不同尺度 $r$ 下 $g^{\mathrm{eff}}(r)$ 取的不同几何相"——投影是结构候选。
- **C 类·S10 频率本源**：S10 主张"振动（频率）是第一物理量"，物态可读作"振动模分布的相变"（Debye 谱→液态准弹性谱→Maxwell 速度分布→电离连续谱）。此为框架对接，**推导待建**，不写为已证。

## 37.4 量纲定位与维度谱表

自然单位 $c=\hbar=k_B=1$ 下：温度 $T\cong\ell^{-1}$，能量 $\cong\ell^{-1}$，压强/能量密度 $\cong\ell^{-4}$，比热/熵 $\cong\ell^0$，临界指数 $\cong\ell^0$。

| 维度层级 | 物态对应 | 量纲变化 |
|---|---|---|
| 0D（基元/荷） | 单原子/单离子，拓扑荷 $Q\in\mathbb{Z}$ | $\ell^0$ |
| 1D（线密度/绕数） | 单链声子谱、一维振动模 $\omega(k)$ | $\ell^{-1}$（频率） |
| 2D（面密度/分形） | 层状晶体 $g(r)$ 的截面、二维熔化 | $\ell^{-2}$ |
| 3D（体密度/霍普夫） | 三维晶格、液体体分布、霍普夫荷 $Q_H$ | $\ell^{-4}$（密度/压强） |
| 3+1D（物理时空） | 宏观热力学相（固/液/气/等离子） | $T,p$ 平面分区 |
| 4D（标度空间） | β流不动点、临界区幂律 $m(\mu)\propto(\mu/\mu_0)^{-\gamma}$ | 分形维 $D=4-\gamma$ |

**读法**：物态从 0D 的单个荷，经 1D 振动模、2D 层关联、3D 体密度，涌现为 3+1D 宏观相；相变则发生在 4D 标度空间——粗粒化流的不动点跃迁。

## 37.6 精算示例：水三相点的量纲自洽

以自然单位复算三相点：

$$k_BT=k_B\times273.16\,\mathrm{K}\approx 0.0233\,\mathrm{eV}\cong\ell^{-1}$$

对应长度 $\ell\sim 1/(0.0233\,\mathrm{eV})\approx5.3\times10^{-8}\,\mathrm{m}$（取 $\hbar c\approx197\,\mathrm{MeV\cdot fm}$ 折算）。该长度正是水分子间氢键关联长度的常识量级——量纲系统把"温度"直接折算成"关联长度"，与液态 $g(r)$ 的主峰位置（$\sim0.28\,\mathrm{nm}$ 即氢键长度）同阶。**此为量纲自洽性核对，非新物理预言**。

## 37.8 诚实边界与待研究问题

1. **A 类已闭合**：四态本源方程、一级/二级相变判据、临界指数与标度律——全部来自标准物理，实验验证充分，本章仅整理不创新。
2. **B 类候选**：把临界点映射到 M4 β流不动点、把物态映射到 M5 对偶度规相，目前只有**结构同构**证据（"不动点↔无特征尺度""对偶尺度↔多相"），**尚未建立 $T_c$ 与 $\ell$ 的定量公式**，不得宣称已解释临界温度。
3. **C 类待建**：S10"物态=振动频率分布相变"的对接路径（Debye 谱/准弹性谱/Maxwell 谱/电离连续谱→单一频率本体）仅有概念草图，推导待建。
4. **禁止越界**：本章不给出新的相变温度预言；水三相点、居里点等数值均为实验值引用，不冒充理论计算结果。
