# ROOT 后续 V134–V137 可执行研究任务

## V134｜从单一几何作用量中推导内部规范群（难度最高）

**输入最小化：** 明确唯一基本变量，写出没有事先植入标准模型规范群的作用量，给出所有场的表示、约束和自由度。**通关：** 推出规范群、粒子谱与电荷，并证明规范反常及全局异常抵消。**失败判据：** 若手工补上需要导出的 SU3/SU2/U1 或超荷，则不算第一性原理推导。

## V135｜严格的螺旋光子传播微观实验

要事先公布：\(R(k)\)、\(\Omega(k)\)、可观测偏振/相位/到达时间函数、误差模型；用独立实验波长做盲测。对照标准量子电动力学中已知的圆偏振、光束轨道角动量、Berry 相位、环境色散；不能把普通偏振旋转当作 ROOT 特有新效应。

## V136｜从高维度规计算 G 而不是代数反算

需要无实验 G 输入的基本高维动力学尺度、紧化半径与稳定机制。量纲计算、微扰自由度计数、引力短程实验/宇宙学约束必须联合通过。\(G_4=G_5/(2\pi R)\) 仅是条件性约化式。

## V137｜统一模型的独立留出数据验证

给出公开不可变的理论版本及先验参数。先在训练样本定参数，再用未参与拟合的独立数据做误差统计；至少在光学、粒子、引力各一个跨领域预测中检验一致性。仅验证模型自己生成的合成数据不计为实验确认。

## 项目质量门禁

1. LaTeX/符号推导明确变量、量纲、变分边界条件与正负号。
2. 运行 `python verify_v133.py`；主张物理真实性必须另附真实实验数据及出处。
3. 高维模型新增粒子时必须补充 gauge/global anomaly、手征投影、ghost/tachyon、单幺正性、Ward identity、有效场论适用域。
4. 每次发布生成 SHA256 校验清单，并保留前一个版本供对比。
