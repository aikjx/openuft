## 5.1 电磁波方程——挠率场传播

### 电磁波的标准方程

$$\square \boldsymbol{E} = \mu_0 \varepsilon_0 \frac{\partial^2 \boldsymbol{E}}{\partial t^2} = \frac{1}{c^2}\frac{\partial^2 \boldsymbol{E}}{\partial t^2}$$

其中 $\square = \partial^2/\partial t^2 - c^2\nabla^2$ 为达朗贝尔算符。

### 电磁的几何化

利用 $\varepsilon_0 = e^2/(4\pi\alpha\hbar c)$ 和 $\mu_0 = 1/(\varepsilon_0 c^2)$：

$$\mu_0 \varepsilon_0 = \frac{1}{c^2}$$

改写为螺旋几何形式——质量色散统一（见 §5.4）：

$$\boxed{\;\frac{1}{c^2}\square \boldsymbol{E} = (\kappa^2+\tau^2)\boldsymbol{E}\;}$$

**量纲核验**：$[\frac{1}{c^2}\square] = \mathrm{m}^{-2}$，$[\kappa^2+\tau^2] = \mathrm{m}^{-2}$ ✓

**光子无质量极限**：光子 $m=0$ 时 $c^2(\kappa^2+\tau^2)=(mc^2/\hbar)^2=0$，故 $\kappa^2+\tau^2=0$，方程退化为真空达朗贝尔方程：

$$\square \boldsymbol{E} = 0$$

**物理意义**：电磁波以光速传播，其根源是光子无质量极限 $(\kappa^2+\tau^2)\to 0$。而 $\alpha^{-1}=\kappa/\tau=137.036$ 是螺旋升角决定的电磁**耦合强度**（形状参数），并非波动算符，二者不应混淆。

### 磁场的对应方程

$$\frac{1}{c^2}\square \boldsymbol{B} = (\kappa^2+\tau^2)\boldsymbol{B},\qquad \kappa^2+\tau^2=0\ \ (\text{光子})$$

### 验证

**经典解**：$\boldsymbol{E} = E_0 \sin(\omega t - kz)$，代入：
$$(-\omega^2 + c^2 k^2) E_0 = -(\kappa^2+\tau^2)E_0$$

解得色散关系 $\omega^2 = c^2 k^2 + c^2(\kappa^2+\tau^2)$，光子极限下 $\omega^2=c^2k^2$，即电磁波以光速传播 ✅

## 5.2 物质波方程——螺旋运动传播

### 标准量子力学方程

Schrödinger 方程：
$$i\hbar \frac{\partial \psi}{\partial t} = -\frac{\hbar^2}{2m}\nabla^2 \psi + V\psi$$

### 几何化物质波

代入质量本源公式 $m = \hbar\sqrt{\kappa^2+\tau^2}/c$ 和势能的几何化形式：

$$\boxed{i\hbar \frac{\partial \psi}{\partial t} = -\frac{\hbar^2}{2m}\nabla^2 \psi + V_{\text{geo}}\psi}$$

> **注意**：$V_{\text{geo}}$ 为几何化势能项，需具有能量量纲（J）。将 $(\kappa^2+\tau^2)$ 直接作为势能项**量纲不正确**（m⁻² ≠ J），需补充 $\hbar^2 c^2$ 等因子。当前为启发式构造，尚未完成严格推导。

### 与螺旋运动的关系

物质波描述的是螺旋运动的量子力学传播。螺旋的曲率-挠率决定了波函数的局域化程度。

**验证**：自由粒子解 $\psi = A e^{i(kx-\omega t)}$ 满足：
$$\hbar\omega = \frac{\hbar^2 k^2}{2m} + V_{\text{geo}}$$

这是相对论能量-动量关系 $E^2 = (pc)^2 + (mc^2)^2$ 的非相对论近似 ✅

## 5.3 引力波方程——曲率场传播

### 引力波的标准方程

$$\square h_{\mu\nu} = \frac{16\pi G}{c^4} T_{\mu\nu}$$

在真空（$T_{\mu\nu}=0$）中：

$$\square h_{\mu\nu} = 0$$

### 引力波的几何化

改写为螺旋几何形式：

$$\boxed{\;\frac{1}{c^2}\square h_{\mu\nu} = \kappa^2 h_{\mu\nu}\;}$$

**量纲核验**：$[\frac{1}{c^2}\square] = \mathrm{m}^{-2}$，$[\kappa^2] = \mathrm{m}^{-2}$ ✓

**物理意义**：引力波是曲率场（κ）的传播。

### 引力波的偏振

引力子有两个独立的偏振态（"+" 和 "×"），对应螺旋的两种独立振动模式。

### 验证

**平面波解**：$h_{\mu\nu} = \epsilon_{\mu\nu} e^{i(kx-\omega t)}$，代入方程：
$$(-\omega^2/c^2 + k^2) \epsilon_{\mu\nu} = \kappa^2 \epsilon_{\mu\nu}$$

解得 $k^2 = (\omega/c)^2 + \kappa^2$——引力波有量纲正确的质量隙 κ ✅

## 5.4 统一波动方程

### 启发式统一方程

$$\boxed{\;\frac{1}{c^2}\square \psi - (\kappa^2+\tau^2)\psi = 0\;}$$

> **量纲核验**：$[\frac{1}{c^2}\square] = [\kappa^2+\tau^2] = \mathrm{m}^{-2}$ ✓
>
> **注**：此为启发式构造，将 $\kappa^2+\tau^2$ 作为波动方程的质量项。不同场（电磁/物质/引力）对应不同的 $\psi$ 和不同的 $\kappa^2+\tau^2$ 取值，但此对应关系尚未严格推导。

其中 $\psi$ 可以代表：
- 电磁波矢量：$\psi \mapsto \boldsymbol{E}$ 或 $\boldsymbol{B}$
- 物质波函数：$\psi \mapsto \psi_{\text{Schrödinger}}$
- 引力波张量：$\psi \mapsto h_{\mu\nu}$

### 色散关系

$$\boxed{\;\omega^2 = c^2(k^2 + \kappa^2+\tau^2)\;}$$

### 各类波动方程汇总

| 波动类型 | 方程 | 几何本源 | 色散关系 |
|:---|:---|:---|:---|
| 电磁波 | $\square E = 0$（光子无质量极限） | 挠率场传播，$\kappa^2+\tau^2=0$ | $\omega^2 = c^2 k^2$ |
| 物质波 | $i\hbar\partial_t\psi = -\frac{\hbar^2}{2m}\nabla^2\psi + V_{\text{geo}}\psi$ | 螺旋运动传播 | $E^2 = (pc)^2 + (mc^2)^2$ |
| 引力波 | $\frac{1}{c^2}\square h_{\mu\nu} = \kappa^2 h_{\mu\nu}$ | 曲率场传播 | $\omega^2 = c^2 k^2 + c^2\kappa^2$ |
| **统一波** | $\frac{1}{c^2}\square\psi = (\kappa^2+\tau^2)\psi$ | 曲率-挠率统一传播 | $\omega^2 = c^2(k^2+\kappa^2+\tau^2)$ |

> **注意**：表中物质波方程的 $V_{\text{geo}}$ 项量纲尚未解决；物质波的色散关系 $E^2=(pc)^2+(mc^2)^2$ 与统一波色散关系 $\omega^2=c^2(k^2+\kappa^2+\tau^2)$ 的对应需要 $mc^2 = \hbar c \sqrt{\kappa^2+\tau^2}$，即质量本源公式。

### 验证

**色散关系验证**：

```python

# CODATA 2022 基准值
```

## 5.5 QFT 路径积分核

### 几何作用量

螺旋在周期 T 内的几何作用量：

$$S_g = 2\pi\,\omega R/c$$

推导：
- 螺旋的空间弧长：$s = 2\pi R$（每圈的总路径）
- 运动时间：$T = 2\pi/\omega$
- 几何作用量：$S_g = \omega T \cdot R/c = 2\pi\omega R/c$

### QFT 路径积分核

$$\boxed{\mathcal{K} = \exp\!\left(i\frac{S_g}{\hbar}\right) = \exp\!\left(i\frac{2\pi\,\omega R/c}{\hbar}\right)}$$

### 与标准 QFT 的关系

- $S_g/\hbar$ 严格无量纲
- 与标准 QFT 费曼核同构
- 螺旋的每个周期对应一个量子激发

### 量子传播子

$$\Delta_F(x-y) = \int \frac{d^4k}{(2\pi)^4}\frac{i}{k^2 - (\kappa^2+\tau^2) + i\epsilon}e^{-ik\cdot(x-y)}$$

这是带有质量 $m_{\text{eff}} = \hbar\sqrt{\kappa^2+\tau^2}/c$ 的 Klein-Gordon 传播子。

## 5.6 统一拉格朗日量

### 完整拉格朗日量

$$\boxed{\mathcal{L} = -\frac{1}{4}\frac{\kappa}{\tau}F_{\mu\nu}F^{\mu\nu} - \frac{1}{2}\kappa\tau W_{\mu\nu}W^{\mu\nu} - \frac{1}{4}(\kappa^2+\tau^2)G_{\mu\nu}G^{\mu\nu} + \kappa^2 R + \bar{\psi}i\gamma^\mu D_\mu\psi}$$

各项的物理意义：
- $\mathcal{L}_{\text{EM}} = -\frac{1}{4}\frac{\kappa}{\tau}F_{\mu\nu}F^{\mu\nu}$：电磁拉格朗日（α 加权）
- $\mathcal{L}_{\text{weak}} = -\frac{1}{2}\kappa\tau W_{\mu\nu}W^{\mu\nu}$：弱相互作用拉格朗日（κτ 加权）
- $\mathcal{L}_{\text{strong}} = -\frac{1}{4}(\kappa^2+\tau^2)G_{\mu\nu}G^{\mu\nu}$：强相互作用拉格朗日（κ²+τ² 加权）
- $\mathcal{L}_{\text{gravity}} = \kappa^2 R$：引力拉格朗日（κ² 加权）
- $\mathcal{L}_{\text{fermion}} = \bar{\psi}i\gamma^\mu D_\mu\psi$：费米子拉格朗日

### 作用量原理

$$S = \int \mathcal{L}\,d^4x$$

最小作用量原理：$\delta S = 0$ 给出所有场方程。

### 垂直原理的矩阵形式

$$\boxed{\begin{pmatrix}\kappa & 0 \\ 0 & \tau\end{pmatrix} \cdot \begin{pmatrix}\tau & 0 \\ 0 & \kappa\end{pmatrix} = \begin{pmatrix}\kappa\tau & 0 \\ 0 & \kappa\tau\end{pmatrix}}$$

**物理意义**：
- 曲率 κ 和挠率 τ 作为正交的几何基
- 它们的乘积 κτ 构成弱相互作用的本源
- 这种矩阵结构保证了四力的统一描述
