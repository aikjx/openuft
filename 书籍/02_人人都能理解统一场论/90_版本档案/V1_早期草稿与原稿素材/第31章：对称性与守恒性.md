# 第31章：对称性与守恒性

## 核心观点预览

- 对称性是物理世界的基本特征，它体现了物理规律的简洁性和和谐性
- 守恒律是物理世界的基本规律，它反映了物理量的不变性
- 诺特定理将对称性与守恒律联系起来，揭示了它们之间的内在联系
- 统一场论中的对称性具有更广泛的意义，它是统一各种相互作用的基础
- 对称性破缺是物理世界多样性的来源，它解释了为什么物理世界如此丰富多彩
- 对称性和守恒性是理解物理世界本质的重要工具
- 统一场论的目标之一是寻找更高层次的对称性，实现各种相互作用的统一

## 引言

想象一下，如果我们将一个物体旋转180度，它看起来和原来完全一样，我们就说这个物体具有旋转对称性。如果我们将一个物体平移一段距离，它看起来和原来完全一样，我们就说这个物体具有平移对称性。对称性是物理世界的基本特征，它体现了物理规律的简洁性和和谐性。

在物理学中，对称性的概念更加广泛，它不仅包括几何对称性，还包括物理规律的对称性。物理规律的对称性是指，当我们对物理系统进行某种变换时，物理规律保持不变。例如，物理规律在时间平移下保持不变，这意味着物理规律今天和明天是一样的；物理规律在空间平移下保持不变，这意味着物理规律在这里和那里是一样的。

守恒律是物理世界的另一个基本特征，它反映了物理量的不变性。例如，能量守恒定律告诉我们，能量既不会凭空产生，也不会凭空消失，它只能从一种形式转化为另一种形式；动量守恒定律告诉我们，在一个孤立系统中，总动量保持不变；角动量守恒定律告诉我们，在一个孤立系统中，总角动量保持不变。

诺特定理将对称性与守恒律联系起来，它揭示了对称性和守恒律之间的内在联系：每一种对称性都对应着一个守恒律，每一个守恒律都对应着一种对称性。这一深刻的联系，为我们理解物理世界的本质提供了重要的工具。

在统一场论中，对称性具有更广泛的意义，它是统一各种相互作用的基础。统一场论的目标之一是寻找更高层次的对称性，实现各种相互作用的统一。本章将探讨对称性与守恒性的基本概念、它们之间的关系，以及它们在统一场论中的应用。

## 31.1 对称性的基本概念

本节导读：对称性是物理世界的基本特征，它体现了物理规律的简洁性和和谐性。本节将介绍对称性的基本概念，包括几何对称性和物理规律的对称性。

### 31.1.1 对称性的定义

**对称性**是指系统在某种变换下保持不变的性质。具体来说，如果我们对系统进行某种变换，变换后的系统与原系统在某种意义上等价，我们就说系统具有这种对称性。

对称性的数学表达是：如果存在一个变换T，使得变换后的系统S' = T(S)与原系统S在某种意义上等价，即S' ≡ S，那么系统S具有变换T下的对称性。

### 31.1.2 几何对称性

**几何对称性**是指物体或图形在几何变换下保持不变的性质。常见的几何对称性包括：

1. **平移对称性**：物体在平移变换下保持不变，例如无限长的直线、无限大的平面等
2. **旋转对称性**：物体在旋转变换下保持不变，例如圆、球等
3. **反射对称性**：物体在反射变换下保持不变，例如平面镜成像、对称图形等
4. **螺旋对称性**：物体在螺旋变换下保持不变，例如DNA分子、螺旋桨等
5. **伸缩对称性**：物体在伸缩变换下保持不变，例如分形图形等

几何对称性是最直观的对称性，它在日常生活中随处可见。

### 31.1.3 物理规律的对称性

**物理规律的对称性**是指物理规律在某种变换下保持不变的性质。常见的物理规律的对称性包括：

1. **时间平移对称性**：物理规律在时间平移变换下保持不变，即物理规律今天和明天是一样的
2. **空间平移对称性**：物理规律在空间平移变换下保持不变，即物理规律在这里和那里是一样的
3. **空间旋转对称性**：物理规律在空间旋转变换下保持不变，即物理规律在各个方向上是一样的
4. **时间反演对称性**：物理规律在时间反演变换下保持不变，即物理规律在时间倒流时仍然成立
5. **电荷共轭对称性**：物理规律在电荷共轭变换下保持不变，即物理规律在粒子和反粒子之间是对称的
6. **宇称对称性**：物理规律在空间反演变换下保持不变，即物理规律在镜像世界中仍然成立

物理规律的对称性是物理学的基本假设之一，它体现了物理世界的简洁性和和谐性。

### 31.1.4 对称性的分类

根据不同的分类标准，对称性可以分为不同的类型：

1. **连续对称性**：变换可以连续进行，例如时间平移对称性、空间平移对称性、空间旋转对称性等
2. **离散对称性**：变换只能离散进行，例如时间反演对称性、电荷共轭对称性、宇称对称性等
3. **全局对称性**：变换在整个空间中是相同的，例如全局U(1)对称性、全局SU(2)对称性等
4. **局域对称性**：变换在不同空间点可以不同，例如局域U(1)对称性、局域SU(2)对称性、局域SU(3)对称性等

连续对称性和离散对称性的区别在于变换的性质，全局对称性和局域对称性的区别在于变换的范围。

## 31.2 守恒律的基本概念

本节导读：守恒律是物理世界的基本规律，它反映了物理量的不变性。本节将介绍守恒律的基本概念，包括能量守恒定律、动量守恒定律、角动量守恒定律等。

### 31.2.1 守恒律的定义

**守恒律**是指在一个孤立系统中，某个物理量的总量保持不变的规律。具体来说，如果一个物理量在系统的演化过程中总量保持不变，我们就说这个物理量遵循守恒律。

守恒律的数学表达是：如果物理量Q的时间变化率dQ/dt = 0，那么Q是守恒量，即Q(t) = Q(0)对所有时间t成立。

### 31.2.2 经典物理中的守恒律

在经典物理学中，常见的守恒律包括：

1. **能量守恒定律**：在一个孤立系统中，总能量保持不变，即E = 常数
2. **动量守恒定律**：在一个孤立系统中，总动量保持不变，即p = 常数
3. **角动量守恒定律**：在一个孤立系统中，总角动量保持不变，即L = 常数
4. **电荷守恒定律**：在一个孤立系统中，总电荷保持不变，即Q = 常数

这些守恒律是经典物理学的基本规律，它们在各种物理现象中都得到了验证。

### 31.2.3 量子物理中的守恒律

在量子物理学中，守恒律的概念更加广泛，它与对称性的关系更加密切。常见的量子物理中的守恒律包括：

1. **能量守恒定律**：在量子系统中，能量的本征值是守恒的
2. **动量守恒定律**：在量子系统中，动量的本征值是守恒的
3. **角动量守恒定律**：在量子系统中，角动量的本征值是守恒的
4. **电荷守恒定律**：在量子系统中，电荷的本征值是守恒的
5. **自旋守恒定律**：在量子系统中，自旋的本征值是守恒的
6. **同位旋守恒定律**：在强相互作用中，同位旋的本征值是守恒的
7. **重子数守恒定律**：在强相互作用和电磁相互作用中，重子数是守恒的
8. **轻子数守恒定律**：在弱相互作用中，轻子数是守恒的

这些守恒律是量子物理学的基本规律，它们在各种量子现象中都得到了验证。

### 31.2.4 守恒律的意义

守恒律是物理世界的基本规律，它具有重要的意义：

1. **简化物理问题**：守恒律可以帮助我们简化物理问题，减少需要考虑的变量
2. **预测物理现象**：守恒律可以帮助我们预测物理现象，例如根据能量守恒定律预测反应产物
3. **验证物理理论**：守恒律可以帮助我们验证物理理论，例如通过实验验证能量守恒定律
4. **揭示物理本质**：守恒律可以帮助我们揭示物理本质，例如通过守恒律理解对称性的意义

守恒律是物理学的核心概念之一，它为我们理解物理世界提供了重要的工具。

## 31.3 诺特定理：对称性与守恒律的联系

本节导读：诺特定理将对称性与守恒律联系起来，它揭示了对称性和守恒律之间的内在联系：每一种对称性都对应着一个守恒律，每一个守恒律都对应着一种对称性。

### 31.3.1 诺特定理的基本内容

**诺特定理**（Noether's theorem）是由德国数学家艾米·诺特（Emmy Noether）在1915年提出的，它是物理学中最重要的定理之一。诺特定理的基本内容是：

**对于每一种连续对称性，都存在一个对应的守恒律；对于每一个守恒律，都存在一个对应的连续对称性。**

具体来说，如果物理系统具有某种连续对称性，那么系统中必然存在一个守恒量，该守恒量的时间变化率为零；反之，如果系统中存在一个守恒量，那么系统必然具有某种连续对称性，该对称性对应的变换保持守恒量不变。

### 31.3.2 诺特定理的数学表达

诺特定理的数学表达比较复杂，它涉及到拉格朗日力学和变分法。简单来说，诺特定理可以表述为：

如果物理系统的拉格朗日量L在连续变换q_i → q_i + δq_i下保持不变，即δL = 0，那么存在一个守恒量Q，其表达式为：

Q = Σ (∂L/∂(dq_i/dt)) * δq_i = 常数

其中，q_i是系统的广义坐标，dq_i/dt是系统的广义速度，Σ表示对所有广义坐标求和。

### 31.3.3 诺特定理的应用举例

诺特定理的应用非常广泛，以下是几个常见的例子：

#### 1. 时间平移对称性与能量守恒定律

如果物理系统具有时间平移对称性，即拉格朗日量L在时间平移变换t → t + δt下保持不变，那么根据诺特定理，系统中存在一个守恒量，这个守恒量就是能量E。

能量守恒定律的表达式为：E = 常数，其中E是系统的总能量。

#### 2. 空间平移对称性与动量守恒定律

如果物理系统具有空间平移对称性，即拉格朗日量L在空间平移变换r → r + δr下保持不变，那么根据诺特定理，系统中存在一个守恒量，这个守恒量就是动量p。

动量守恒定律的表达式为：p = 常数，其中p是系统的总动量。

#### 3. 空间旋转对称性与角动量守恒定律

如果物理系统具有空间旋转对称性，即拉格朗日量L在空间旋转变换θ → θ + δθ下保持不变，那么根据诺特定理，系统中存在一个守恒量，这个守恒量就是角动量L。

角动量守恒定律的表达式为：L = 常数，其中L是系统的总角动量。

#### 4. 全局U(1)对称性与电荷守恒定律

如果物理系统具有全局U(1)对称性，即拉格朗日量L在全局U(1)变换ψ → e^{iθ}ψ下保持不变，那么根据诺特定理，系统中存在一个守恒量，这个守恒量就是电荷Q。

电荷守恒定律的表达式为：Q = 常数，其中Q是系统的总电荷。

### 31.3.4 诺特定理的意义

诺特定理具有重要的意义：

1. **揭示了对称性与守恒律的内在联系**：诺特定理将对称性与守恒律联系起来，揭示了它们之间的深刻关系
2. **统一了物理学的基本概念**：诺特定理将经典物理学和量子物理学中的对称性与守恒律统一起来
3. **指导了新物理理论的发展**：诺特定理指导了新物理理论的发展，例如量子场论、弦论等
4. **提供了研究物理系统的重要工具**：诺特定理为研究物理系统提供了重要的工具，帮助我们理解物理系统的性质

诺特定理是物理学中最重要的定理之一，它为我们理解物理世界的本质提供了重要的工具。

## 31.4 对称性破缺

本节导读：对称性破缺是指系统在某种条件下失去原有的对称性，它是物理世界多样性的来源。本节将介绍对称性破缺的基本概念、类型和意义。

### 31.4.1 对称性破缺的定义

**对称性破缺**（symmetry breaking）是指系统在某种条件下失去原有的对称性，即系统在变换后的状态与原状态不再等价。具体来说，如果系统在变换T下的状态S' = T(S)与原状态S不再等价，即S' ≢ S，那么系统发生了对称性破缺。

对称性破缺的数学表达是：虽然物理规律具有某种对称性，但系统的实际状态不具有这种对称性，即物理规律的对称性没有在系统的实际状态中体现出来。

### 31.4.2 对称性破缺的类型

根据不同的分类标准，对称性破缺可以分为不同的类型：

1. **自发对称性破缺**：系统的拉格朗日量具有某种对称性，但系统的基态（最低能量状态）不具有这种对称性，例如铁磁体的自发磁化、希格斯机制等
2. **显式对称性破缺**：系统的拉格朗日量不具有某种对称性，例如弱相互作用中的宇称破缺、电荷共轭破缺等
3. **动力学对称性破缺**：系统的对称性在动力学演化过程中被打破，例如重子生成中的CP破缺等

自发对称性破缺是最常见的对称性破缺类型，它是物理世界多样性的来源。

### 31.4.3 自发对称性破缺的例子

自发对称性破缺的例子非常多，以下是几个常见的例子：

#### 1. 铁磁体的自发磁化

铁磁体在高温下是顺磁性的，具有旋转对称性，即磁化强度为零，各个方向是等价的。当温度降低到居里温度以下时，铁磁体发生自发磁化，磁化强度不为零，指向某个特定方向，失去了旋转对称性。这就是自发对称性破缺的例子。

#### 2. 希格斯机制

希格斯机制是标准模型中的重要机制，它解释了基本粒子质量的来源。希格斯场具有全局U(1)对称性，但希格斯场的基态不具有这种对称性，导致对称性破缺。这种对称性破缺使得基本粒子获得了质量。

#### 3. 晶体的形成

晶体在形成过程中，原子排列成规则的晶格结构，失去了连续的平移对称性，只保留了离散的平移对称性。这也是自发对称性破缺的例子。

### 31.4.4 对称性破缺的意义

对称性破缺具有重要的意义：

1. **解释了物理世界的多样性**：对称性破缺是物理世界多样性的来源，它解释了为什么物理世界如此丰富多彩
2. **解释了基本粒子质量的来源**：希格斯机制通过自发对称性破缺解释了基本粒子质量的来源
3. **解释了宇宙的演化**：对称性破缺在宇宙演化中扮演了重要角色，例如宇宙早期的对称性破缺导致了物质的产生
4. **指导了新物理理论的发展**：对称性破缺指导了新物理理论的发展，例如超对称理论、大统一理论等

对称性破缺是物理学中的重要概念，它为我们理解物理世界的多样性提供了重要的工具。

## 31.5 统一场论中的对称性

本节导读：在统一场论中，对称性具有更广泛的意义，它是统一各种相互作用的基础。本节将介绍统一场论中的对称性，包括局域对称性、规范对称性、大统一对称性等。

### 31.5.1 局域对称性与规范对称性

**局域对称性**（local symmetry）是指变换在不同空间点可以不同的对称性，它是统一场论中的重要概念。局域对称性也称为**规范对称性**（gauge symmetry），它是规范场论的基础。

规范对称性的基本思想是：物理规律在局域变换下保持不变，这种局域变换由规范场来描述。规范场是传递相互作用的媒介，例如电磁场、弱相互作用场、强相互作用场等。

### 31.5.2 四种相互作用的对称性

四种基本相互作用（引力、电磁相互作用、弱相互作用、强相互作用）都具有各自的规范对称性：

1. **引力相互作用**：具有局域洛伦兹对称性，由引力场（时空曲率）来描述
2. **电磁相互作用**：具有局域U(1)对称性，由电磁场来描述
3. **弱相互作用**：具有局域SU(2)对称性，由弱相互作用场（W、Z玻色子）来描述
4. **强相互作用**：具有局域SU(3)对称性，由强相互作用场（胶子）来描述

这些规范对称性是四种基本相互作用的核心，它们决定了相互作用的性质。

### 31.5.3 大统一对称性

**大统一对称性**（grand unified symmetry）是指将电磁相互作用、弱相互作用和强相互作用统一起来的对称性。大统一理论（GUT）认为，在高能条件下，这三种相互作用具有相同的强度，它们是同一种相互作用的不同表现形式。

常见的大统一对称性包括：

1. **SU(5)对称性**：将电磁相互作用、弱相互作用和强相互作用统一为SU(5)对称性
2. **SO(10)对称性**：将电磁相互作用、弱相互作用和强相互作用统一为SO(10)对称性
3. **E6对称性**：将电磁相互作用、弱相互作用和强相互作用统一为E6对称性

大统一对称性是实现三种相互作用统一的基础，它为我们理解物理世界的统一性提供了重要的工具。

### 31.5.4 超对称性

**超对称性**（supersymmetry）是指将玻色子和费米子统一起来的对称性。超对称理论认为，每一种玻色子都有一个对应的费米子伙伴，每一种费米子都有一个对应的玻色子伙伴。

超对称性的基本思想是：物理规律在超对称变换下保持不变，这种超对称变换将玻色子转换为费米子，将费米子转换为玻色子。超对称性是弦论的重要基础，它为我们理解物理世界的统一性提供了重要的工具。

### 31.5.5 统一场论的对称性目标

统一场论的目标之一是寻找更高层次的对称性，实现各种相互作用的统一：

1. **实现四种相互作用的统一**：寻找将引力相互作用、电磁相互作用、弱相互作用和强相互作用统一起来的对称性
2. **实现玻色子和费米子的统一**：通过超对称性将玻色子和费米子统一起来
3. **实现时空和物质的统一**：将时空和物质统一为一个整体，例如弦论中的弦

统一场论的对称性目标是实现物理世界的完全统一，它为我们理解物理世界的本质提供了重要的方向。

## 31.6 对称性与守恒性在统一场论中的应用

本节导读：对称性与守恒性在统一场论中具有重要的应用，它们是统一各种相互作用的基础。本节将介绍对称性与守恒性在统一场论中的应用，包括规范场论、大统一理论、超对称理论等。

### 31.6.1 规范场论

**规范场论**（gauge field theory）是基于规范对称性的物理理论，它是描述基本相互作用的重要工具。规范场论的基本思想是：物理规律在局域变换下保持不变，这种局域变换由规范场来描述，规范场是传递相互作用的媒介。

规范场论的核心是规范对称性，它决定了相互作用的性质。例如，量子电动力学（QED）是基于局域U(1)对称性的规范场论，它描述了电磁相互作用；量子色动力学（QCD）是基于局域SU(3)对称性的规范场论，它描述了强相互作用；电弱统一理论是基于局域SU(2)×U(1)对称性的规范场论，它描述了电磁相互作用和弱相互作用的统一。

### 31.6.2 大统一理论

**大统一理论**（grand unified theory, GUT）是基于大统一对称性的物理理论，它的目标是将电磁相互作用、弱相互作用和强相互作用统一起来。大统一理论认为，在高能条件下，这三种相互作用具有相同的强度，它们是同一种相互作用的不同表现形式。

大统一理论的核心是大统一对称性，例如SU(5)对称性、SO(10)对称性等。大统一对称性通过自发对称性破缺，分解为电磁相互作用、弱相互作用和强相互作用的对称性，从而解释了这三种相互作用的性质。

### 31.6.3 超对称理论

**超对称理论**（supersymmetric theory）是基于超对称性的物理理论，它的目标是将玻色子和费米子统一起来。超对称理论认为，每一种玻色子都有一个对应的费米子伙伴，每一种费米子都有一个对应的玻色子伙伴。

超对称理论的核心是超对称性，它通过超对称变换将玻色子转换为费米子，将费米子转换为玻色子。超对称性是弦论的重要基础，它为我们理解物理世界的统一性提供了重要的工具。

### 31.6.4 弦论

**弦论**（string theory）是基于弦的物理理论，它的目标是实现四种相互作用的统一。弦论认为，所有基本粒子都是由一维的弦振动产生的，不同的振动模式对应不同的基本粒子。

弦论的核心是对称性，它具有极高的对称性，包括超对称性、对偶对称性等。这些对称性是弦论实现四种相互作用统一的基础，它们为我们理解物理世界的本质提供了重要的工具。
