## 二 三条定理（本册的承重结论）

### 定理 A（II01，FAIL）· 载体二选一**观测等价**，数据无权裁决

载体分解 `a(m) = K·m²·F(m)·C(m)·cotθ(m)`，记净因子 `𝔽 ≡ F·C·cotθ`。可变号因子只有耦合层的两个：`cotθ(m)` 与 `C(m)`（`F(m)=κ/κ_lin` 由 r55 III01 四判据证其 ∈[1.027, 8.25] 恒正；`m` 恒正）。二者**只以乘积进入**任何可观测量。

取分裂 `cotθ(m) = λ·Ψ(m)`、`C(m) = Ψ(m)/λ`，则：

- 机器结果：λ ∈ {1e−20, 1, 1e20, λ_max} 四档下 `a_e = -6.900000000000E-13`、`a_μ = 2.300000000000E-9`、`a_τ = 1.435895864694E-4` **逐位相同**（guard `carrier_split_leaves_g2_identical`）。
- G 侧是唯一区分通道：`ΔG/G = √(1+cot²θ) − 1`，由 `u_G = 2.2e-5` 反解 `|cotθ| ≤ 6.633286063483E-3`，而 fitted `|cotθ| ~ Ψ_e = 6.58949e-48` ⇒ **λ 可在 `(0, 5.879474515598E+43]` 内任意取值（跨 63.8 个十倍程）而所有 g-2 读数不变**。
- λ=1 时 `ΔG/G(m_τ) = 6.364296926816E-93`，需 G 精度再提升 **3.456784033332E+87** 倍才能开始区分（II03，BOUNDARY：原则上非零、事实上不可达）。

⇒ **r55 待裁决项①（`θ(m)` vs `C(m)`）不是物理选择而是约定选择**：它是耦合层 `C` 与 `cotθ` 之间的**规范冗余**。「必须由用户二选一」应更正为「任选其一即可，选了也不产生新预言」（II06 CORRECTED）。

### 定理 B（II04，FAIL）· `a_τ` 是**形状约定的推论**，不是框架预言

数据只钉死一件事：`ρ ≡ 𝔽(m_μ)/𝔽(m_e) = (Δa_μ/Δa_e)/(m_μ/m_e)² = -7.796701413317E-2`。`𝔽(m_e)` 的绝对值、函数形状、零点位置、`𝔽(m_τ)` 的取值**都不是数据**。

`a_τ = K_TAU·x`，`K_TAU = Δa_e·(m_τ/m_e)² = -8.342866905395E-6`，`x ≡ 𝔽(m_τ)/𝔽(m_e)` **不被 e/μ 数据约束**。只要 `x ∈ [-1.558217354707E+3, 6.232869418829E+3]`，`a_τ` 就落在 DELPHI 95% CL `[-0.052, 0.013]` 之内 ⇒ **DELPHI 对分支2 零判别力**。

- 接受「最小线性形状 `𝔽 ∝ (1−m/m₀)`」⇒ `x = -1.721106043015E+1`、`a_τ = 1.435895864694E-4`（与 r55 登记逐位一致，回链成立），但它只是允许带里的**一个点**。
- 再外加「`𝔽` 单调递减」⇒ 允许带收窄为 `a_τ ∈ [6.504684219241E-7, 1.300000000000E-2]`，**仍跨 4.3 个量级，仍不是预言**（II07 BOUNDARY）。

⇒ r55 II05 的定性「存在，但比现有实验精度低 2 个量级」须**降级**：放弃形状约定后，连「存在」都没有。

### 定理 C（IV01，FAIL）· 载体/形状未定时 dynesty 的后验 = 先验复读

可观测约束只有 **1 条**（ρ），待定对象含 `(λ, Ψ_e, m₀, 𝔽 形状)` ⇒ 似然在至少 **2 个方向严格平坦**（λ 已被机器证明为纯平坦方向）。平坦方向上的后验 = 先验 ⇒ **任何 posterior 都是 prior 的复读**。

⇒ 对「跑不跑 dynesty」的答复升级为两级：①先由**公设层**钉死 `𝔽` 的函数形式（这不是拟合工作）；②再谈拟合——此时待拟合的量只剩 `m₀` 一个数。复发第十二轮步 3 的可识别性结论（1 函数 / 2 数据点 ⇒ 欠定）。

### 附：自由度记账（III01，FAIL）

参数 `(λ, Ψ_e, m₀)` 记账 3，但可观测量只依赖乘积 `Ψ_e` 与 `m₀` ⇒ **λ 是纯冗余维度**，真实自由度 = 2。⇒ **Ω5 的判定本身依赖记账约定**（复发 r15「口径 I 无效」）。

本册新增判据：**先做冗余维度检测（参数是否只在可观测量上以乘积/组合出现），再数自由度**。诚实读数：即便按最省口径（2），也已超过 Ω5 的 ≤1 ⇒ **撞 Ω5 的结论不因口径而变**。
