# 突破：通用语言下的双边不变性与 O-23 闭合（派生核算 X）

> 一句话结论：第九册留下的 OPEN（O-23 不变性常数 $c_{Python\to L}$ 不可显式构造、跨语言下界转移非对称）被本册
> **闭合**——只要把描述语言 $L$ 换成**通用**语言 $\mu$Lisp，非对称性即消失：两个方向的 $c_{ij}$ 都由真实、
> 可运行、可逐字节复核的解释器测得（$c_{L\to Python}=44400$ bit、$c_{Python\to L}=23840$ bit），
> $K$ 的下界首次可**跨语言对称搬运**。

## 1. 起点：O-23 非对称性的真正根因

第九册（不变性常数显式构造与语言无关下界）把 $c_{ij}$ 从保守占位变为显式常数，闭合 O-20 / O-21，
但诚实登记了一条新 OPEN：

- **O-23**：逆向常数 $c_{Python\to L}$（把 Python 程序解释回 $L$）**不可显式构造**——
  因为 Python 图灵完备、而所用 $L$ 仅描述有理数，逆向翻译不存在。故 $K$ 的**下界**跨语言转移非对称。

第九册当时的诊断是「Python 完备 / $L$ 不完备」。本册指出：**这非对称不是不变性定理的缺陷，而是语言选择的伪影**。
不变性定理对**任意**两种通用（前缀）语言 $i,j$ 都给出双向常数；只要 $L$ 本身通用，双向 $c_{ij}$ 都可写出。

## 2. 核心构造：$L=\mu$Lisp（一个具体、确定的最小 Lisp）

取 $\mu$Lisp 为 $L$：递归 + 算术 + 一等函数 $\Rightarrow$ 图灵完备。通用性使**双向**解释器都可写：

| 常数 | 构造方式 | 显式值 |
| --- | --- | --- |
| $c_{L\to Python}$ | $\mu$Lisp 解释器（Python 源码）测长 | $44400$ bit（5550 字节） |
| $c_{Python\to L}$ | Python 子集 AST 求值器（$\mu$Lisp 源码）测长 | $23840$ bit（2980 字节） |

两解释器均为**真实可运行**，且被真运行以验证正确性（非仅测长文本）：

- $\mu$Lisp 解释器：求递归阶乘 $(\mathrm{fact}\ 5)=120$、高阶 $(\mathrm{twice}\ \mathrm{sq}\ 3)=81$；
- Python 求值器：跑 Python 阶乘 AST 输出 `120`、跑赋值 AST 输出 `20`。

$c_{ij}$ 度量 = 解释器源码 UTF-8 字节数 × 8，**显式、可逐字节复核**。
Python 程序以「AST（$\mu$Lisp 直接承载的 Python list 值）」作为 $L$ 中的描述，求值器即执行器。

## 3. 定理 Ξ-8（O-23 闭合）：通用语言下双边 $c_{ij}$ 均可显式构造

不变性定理（已知）$\;K_i(x)\le K_j(x)+c_{ij}$。当 $L=\mu$Lisp 通用时，两个方向同时可显式：

$$
c_{L\to Python}=44400\ \text{bit},\qquad c_{Python\to L}=23840\ \text{bit}.
$$

逆向那一支（第九册声称「不可构造」）现以 $\mu$Lisp **显式给出**。Chaitin 自检：
$c_{max}=44400$ bit $\ll K(F)\approx2.869$ Mbit ⇒ 构造落在可证范围内，非不可证大数。

## 4. 定理 Ξ-9：双向不变性不等式的具体验证

两个方向的不变性不等式（含 glue 余量）在具体样例上均成立：

| 方向 | $K_{\text{源}}$ | $K_{\text{目标}}$ | $c$ | glue | 成立 |
| --- | --- | --- | --- | --- | --- |
| 正向 $K_{Python}\le K_L+c_{L\to Py}+\mathrm{glue}$ | $K_L=624$ | $K_{Py}=45256$ | $44400$ | $856$ bit | ✓ |
| 逆向 $K_L\le K_{Python}+c_{Py\to L}+\mathrm{glue}$ | $K_{Py}=1448$ | $K_L=25440$ | $23840$ | $1600$ bit | ✓ |

逆向一行即 O-23 的闭合点：$K$ 的**下界**现也能跨语言（对称）搬运，不再只限上界。

## 5. 诚实边界

- $c_{max}=44400$ bit $\gg$ 第八册的 margin（$\approx11.13$ bit）$\Rightarrow$ 语言无关下界的**数值仍不紧**，
  这正是 O-17 已承认的降级，**本册不声称闭合 O-17**。
- **新增 OPEN O-24**：$c_{ij}$ 以「源码字节 × 8」计量，**未做最优编码**（如算术编码）。
  严格最小的 $c$ 应取 $K(\text{解释器})$，本册只给出一个**显式上界**，登记不掩盖。
