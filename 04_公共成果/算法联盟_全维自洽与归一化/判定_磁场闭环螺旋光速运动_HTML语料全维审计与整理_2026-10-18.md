## 二、六条承重裁定

### 裁定 1（C01/C02 FAIL）—— 传播条件在四篇正文里恒不可满足，该族全部模态是倏逝的

`index.html` / `academic-report.html` / `paper-final.html` 三篇（`verification-report.html` 与之同族）写的是：

- 纵向闭环 `k_n = 2πn/h`，同时螺距参数 `b = h/2π`，于是 **`k_n = n/b`**；
- 光速约束 `ω = c/√(a²+b²)`；
- 色散 `κ² = ω²/c² − k_n²`；
- 参数表里印着传播条件 `κ² ≥ 0：1/(a²+b²) ≥ (2πn/h)²`。

代入后 `κ² = 1/(a²+b²) − n²/b²`。传播条件等价于 `b²(1−n²) ≥ n²a²`：**n ≥ 1 时左侧 ≤ 0 而右侧 > 0，对任何 a > 0 恒不成立**。机器网格 12×9×12 = **1296 组 `(a,b,n)` 全部 `κ² < 0`，非负组数 = 0**。

后果不是「参数选得不好」，而是：`J_m(κr)` 在 κ 为纯虚数时化为 `I_m(|κ|r)` 型倏逝解，**根本不沿轴传播**，「磁场沿螺旋线以光速运动」在这三篇自身写出的方程组里没有定义域。

两个自证算例：

- `index.html` PART 08 可视化明写「a = 1, b = 0.5, m = 2」，取 n=1 机器给 **`κ² = −3.2 m⁻²`**；
- `3d-animation.html` 参数控制 a=1.0、b=0.6，实时显示「径向波数 κ = 0.90 m⁻¹」「纵向波数 k = 1.67 /λ」；按其自家色散机器给 **`κ² = −2.042484 m⁻²`**，即 κ 应为纯虚数 `1.4292 i m⁻¹`。页面显示的正实数 0.90 ≈ 1/√(1+0.25) 对应的是 b=0.5，疑为参数串页。

**对照（C04 PASS）**：`paper.html` 改用 `k_n = 2πn/L`（L 为自由纵向周期），此时确有传播模态，`n_max = ⌊L/(2π√(a²+b²))⌋`；取该文 §4.1 的 a=b=0.01 m、L=1.0 m 复现 **n_max = 11**，与论文宣称逐位一致。**C01 与 C04 的差别正是配套代码 `02_constraints.py` §2.1 自己抓到的 h/L 混淆**（该脚本原文：「原式中 `k_n=2πn/h` 的 h 应为纵向周期长度 L（量纲分析确认），非普朗克常数」）——但四篇正文从未同步这个修订。

### 裁定 2（E01/E02 FAIL）—— 「定理：v_总 = c」的证明是循环的

`paper-final.html` PART 04.2 的证明只有三步：

1. 定义 `v_总 = ω√(a²+b²)`；
2. 前提「由光速约束条件（磁场沿螺旋线以光速运动）：`ω√(a²+b²) = c`」；
3. 「代入得 `v_总 = ω√(a²+b²) = c`　∎」。

令 `X = ω√(a²+b²)`：定理是 `X = c`，而第二步的前提就是 `X = c`，第三步只是把 `X` 替换回它自己的定义。**结论中除前提外新出现的符号数 = 1（仅 `v_总` 这个被定义的名字），信息量为零。**

更一般地（E02）：`ω = c/√(a²+b²)` 本身就是由「设 v=c」定义的（§3.2 原文），机器核对以 c 反解 ω 后再正算 `v/c = 1.000000000000000`。整条推导**没有任何独立输入**——既不来自色散关系，也不来自闭环量子化——因此它不可能被任何实验否证：它不是物理命题，只是术语重排。

**诚实标注（E03 BOUNDARY）**：`verification-report.html` 把该恒等式列为「严格数值验证」并给出 10 组参数表、最大相对误差 1.99e-14%。算术无误（本册 B01 已独立复现，最大相对误差 1.99e-16），但读者会误以为得到了独立数值支持。

### 裁定 3（F02/F03 FAIL）—— `∇·B = 0` 的验证偷换了对象，而主张的解确实不无散

`verification-report.html` 验证 07 用的是标准磁偶极子场 `B_r = 2μcosθ/r³`、`B_θ = μsinθ/r³`，结论写「磁感线全部闭合，无磁单极存在 ✓」。但论文 PART 07 的主张解是 `B = A J_m(κr) e^{i(mθ−k_n z −ωt)}·b̂`——**两者是不同的场**。PART 05.3 又写「对于横电磁（TEM）型螺旋波，B 的主要分量为 B_θ 和 B_z，径向分量 B_r = 0 时自动满足无散条件」，「自动满足」四字没有任何推导。

机器复核（取该族可视化参数 m=3、κ=0.90 m⁻¹、k=1.67 m⁻¹、r=1 m，`|∇ψ| = 0.064850` 作归一）：

| 偏振 b̂ | abs(∇·B) | 相对 abs(∇·B)/abs(∇ψ) |
|---|---|---|
| θ̂ | 0.043302 | **0.668** |
| ẑ | 0.024105 | **0.372** |
| (0.3, 0.6, 0.741) | 0.018729 | **0.289** |

解析判据：`∇·B = 0` 要求 `b_r·J_m′/J_m + b_θ·im/r − i k b_z = 0` 对所有 r 成立，而 `J_m′/J_m` 不是 `1/r` 的比例函数，故**只有 m=0 且 k=0 才可能为零**——阳性对照（m=0, k=0）机器给 `abs(∇·B) = 0` 精确成立，而那一支正是退化为无螺旋均匀场的情形。

同时（F04 FAIL）：七项验证**完全未触及「传播条件 κ² ≥ 0」**，而它是来料参数约束表的正式一项，也正是裁定 1 的那个决定性条件。

### 裁定 4（D01/D02/D03 FAIL）—— 相位匹配缺一层；补上之后「闭环螺旋」自己消失

场解 `B = A J_m(κr) e^{i(mθ − k_n z − ωt)}`，螺旋轨迹 `z = bθ`，代入得相位 `φ = (m − k_n b)θ − ωt`。刚性运动（恒定相位）要求 `(m − k_n b)·θ̇ = ω`，故

> **真实的恒定相位线速度是 `v = ω√(a²+b²)/(m − k_n b)`，不是 `ω√(a²+b²)`。**

四篇正文一律写作 `v = ω√(a²+b²)`，等价于默认 `m − k_n b = 1`——一个既未声明也未验证的附加条件。以 `paper.html` §4.1 自身参数（a=b=0.01, L=1, n=1, m=1）算：`m − k_n b = 0.937168 ≠ 1`，真实速度 `3.19892e+08 m/s`，比假设的 `c` 大 **6.71%**。

`paper.html` §3.3 **自己写出了这个因子和修正式** `ω = c(m−k_nb)/√(a²+b²)`，并指出这引出额外螺距量子化 `b = (m−1)/k_n`——但它的 PART 04/结论与其余四篇仍沿用未修正形式。

**本册新增的机器后果（D03）**：把修正式当真、按 `b_nm = (m−1)/k_n` 完整联立（复算 `02_constraints.py` §2.5，a=0.01 m、L=1 m、n=1..5、m=0..4），传播解共 **10 个，`b_nm = 0` 的占 10 个（100%）**。`m=1` 一支由 `(m−1)/k_n = 0` 直接给出零螺距；`m=0` 一支是代码的特殊处理（公式会给 −1/k_n 的负螺距，代码置 0）。`b_nm = 0` 意味着**螺旋退化成半径 a 的圆，没有轴向推进**——「闭环螺旋」的物理图像在它自身的自洽化修正下消失。配套代码打印了那 10 个解的 `b_nm` 列（全为 `0.000000`）却没有在结论文本里指出这一点。

### 裁定 5（G01/G02 FAIL）—— κ 与 ω 均在同一文档内同名异义

| 符号 | 含义一 | 含义二 | 量纲 |
|---|---|---|---|
| `κ` | 径向波数 `√(ω²/c² − k²)`（PART 02/04/07） | Frenet 曲率 `a/(a²+b²)`（PART 03.3 / 验证 05/06） | 均 `L⁻¹` |
| `ω` | 波角频率，见于 `e^{−iωt}` 与色散式 | 沿螺旋轨迹的角速率 `dθ/dt`，见于「设 θ = ωt」 | 均 `T⁻¹` |
| `h` | 普朗克常数（`02_constraints.py` 量纲审查的靶子） | 轴向螺距（`b = h/2π`） | 不同，可被量纲抓到 |

两处 `L⁻¹` / `T⁻¹` 的同名异义**无法靠量纲发现**，只能靠追踪定义。`paper-final.html` 的结论式把两种 κ 并排写出：`B = A J_m(κr)e^{i(mθ−kz−ωt)}` 用含义一，`ω = c√(κ²+τ²)` 用含义二。数值上 a=1、b=0.6、k=n/b 时含义一是纯虚数 `1.4292 i m⁻¹`，含义二是 `0.7353 m⁻¹`。

附带证据（G03 INFO）：`3d-animation.html` 把角频率的单位标成「/τ」——把角频率和挠率符号混在一起，是这套符号混乱的可视化侧证据。

### 裁定 6（H03 FAIL）—— 同一语料库内部自相矛盾，且持误读方是被实验否决的一方

这是本册最有价值的一条。**同一个 `ufthub/html` 目录里**，`deepseek_html_20260911_fc8303.html` 写着：

> 「螺旋 = 场矢量取向随位置排成的形状；**没有东西沿着螺旋本身跑**。真实传播永远是沿 z 的直线，速率 c。」
> 「常见误读：把 x, y 当成光子真实横向空间坐标 → 会推出路径速度 ≈6.36c 或前向 <c → 与实测光速 c 冲突，**已被实验否决**。」

而 `index` / `academic` / `verification` / `paper-final` 四篇的承重主张，正是「磁场沿螺旋线以光速运动，`v_总 = ω√(a²+b²) = c`」——**恰好就是被标为「误读」的那一种读法**。该页的 `6.36c` 可复算：`√(1+4π²)c = 6.362265 c`（横向尺度取波长 λ 时的误读后果）。

⇒ 这不是两个独立结论的分歧，而是同一库内的自相矛盾；语料库自身持有正确的一方（H04：该页三点全部成立——固定 z 截面上 E 矢量原地旋转、横向位移为 0；波前/能量/相位沿 z 以 c 传播；「螺旋在场矢量维度里是真实的，在光子轨迹维度里不存在」），而磁场闭环螺旋族站在被实验否决的一侧。
