光子的两种螺旋度，会怎样传播？

探索一个动态手性背景 θ(t) 下的两种圆偏振模。仅设 c=1，ħ 与 G 仍为独立有量纲常数。这里的 b=η θ̇ 是模型参数，不是自然界已测得的空间螺旋速度。

模型约束与实验含义

低频不稳定带（σb>0）
0 < k < |b|
最快增长率
γmax = |b|/2

群速度可在部分实频分支大于 1，但最高阶波算符仍为普通的波动算符，不能据此宣称信息超光速。若把背景场与光场联合演化，能量通过 η θ̇ E·B 项交换，总能量守恒。

∂t(uEM + uθ) + ∇·(SEM + Sθ) = 0

示例：可复算但并非实测的输入

仅为量纲演示：设 b=10⁻⁶ m⁻¹、λ=550 nm、光路 L=1000 m，则 b/k≈8.75×10⁻¹⁴，|β|≈bL/2=0.0005 rad≈0.02865°；稳定螺旋度分支的 vg²−1≈1.92×10⁻²⁷。不要把这些假设参数当作自然界允许范围。

更多证明、单位、对照文献与完整动态回馈数值积分，参见同一 ZIP 的 研究报告.md、verify_v131.py 和 verification_results.json。

结论：模型解释一种可能的手性偏振传播机制，但尚未独立推导 SU(3)×SU(2)×U(1)、粒子质量、G 或真实光子机械螺旋轨迹。模型演示不等于 ROOT 统一场论获得验证。
