# ROOT V64 数学专著 II｜诱导引力、G 的系数及为什么仍没有独立预测

## 1. 量纲障碍 [P]

在 SI：`[G]=L³M⁻¹T⁻²`；`[c]=LT⁻¹`；`[ℏ]=ML²T⁻¹`，无量纲角度 λ 不能提供新维度。

假设 `G ∝ c^a ℏ^b`，则质量指数 `b=-1`，时间指数 `−a−b=−2` 给 `a=3`，长度指数却是 `a+2b=1`，与所需的 3 不相等：矛盾。

因此，**仅用 c、ℏ、无量纲角度无法构造 G 的量纲**；还缺一个长度平方量纲或等价能标。可以写

`G = γ c³ ℓ_*² /ℏ`，但 `γ,ℓ_*` 的物理值未确定。将 `ℓ_*` 设为通过 G 定义的普朗克长度 `ℓP=√(ℏ G/c³)` 只是恒等关系。

## 2. Sakharov 型诱导引力条件推导 [C]

取实标量二次算子（欧氏背景）

`D=−∇²+m²+ξ R`。

对背景度规的单圈有效作用量：

`Γ_E^(1)=½ Tr ln D`。

引入固有时间（sharp proper-time）UV 截止：

`Γ_E^(1) = −½ ∫_{Λ^-2}^∞ (ds/s) Tr exp(−sD) + 常数`。

四维热核短时展开：

`Tr e^(−sD) ≈ [1/(4πs)²] ∫√g e^(−sm²) [1+s(1/6−ξ)R+O(s²)]`。

提取曲率项：

`Γ_E,R^(1)=−[(1/6−ξ)/(32π²)] [∫_{Λ^-2}∞ ds s^-2 e^(−m²s)] ∫√g R`。

设 `μ=m/Λ` 和

`F(μ)=∫₀¹ exp(−μ²/t)dt`，

则 `∫_{Λ^-2}∞ ds s^-2 exp(−m²s)=Λ² F(μ)`。采用欧氏 Einstein–Hilbert 约定 `S_EH,E = −1/(16πG)∫√g R`，比较系数：

`δ(1/G) = [(1−6ξ)/(12π)] Λ² F(μ)`（自然单位）。

恢复 SI，并用 `ℓ=ℏc/E_UV` 与 `μ=m_phys c ℓ/ℏ`：

`1/G_ren = 1/G_bare + N(1−6ξ)ℏ F(μ)/(12π c³ ℓ²)`。

**限制**：它是指定纯实标量谱、单圈、固定截止、低阶局域曲率项的结果；它不是普适、物理可观测的 G 值。`G_bare` 表示与该截止方案匹配的裸系数；必须用一致的重整化处理。高曲率项、边界项、其他粒子自旋/统计因子被省略。

## 3. 三重欠定性证明 [P]

### 3.1 场数—截止退化

无质量、ξ=0、裸项零的最简选择：

`1/G_ind = N ℏ/(12πc³ℓ²)`。

变换 `N -> 4N`、`ℓ -> 2ℓ`，右侧完全不变。因此仅凭观测到的 G，不能确定微观场数与截止长度；这两个物理量在该近似下不可辨识。

### 3.2 裸项退化

给定任意 `(N,ℓ,ξ,m)`，总可选择

`1/G_bare=1/G_obs - N(1−6ξ)ℏ F(μ)/(12πc³ℓ²)`，

使计算得到的 `G_ren` 恰好等于 `G_obs`。这表明若裸耦合未由独立定理固定，**任意成功数值拟合都没有证明 G 源自微观螺旋**。

### 3.3 正则化方案依赖

热核的二次发散项依赖 cutoff prescription；不同 regulator 下会改变局域计数，经过重整化后可测参数按物理条件定义。不能把单一裸环路的二次发散系数当作普适重整化群不变量。

## 4. 必须防止的数值伪证据

本包输入 NIST CODATA 2022 观测值 `G_obs=6.67430(15)×10^-11 SI`。由此计算 `ℓP=1.6162550244×10^-35m`。对最简 N=1, ξ=0, μ=0, 裸项零，若输入 `ℓ=ℓP`：

`G_ind / G_obs = 12π ≈ 37.6991`。

若要求 `G_ind=G_obs`，必须将 `ℓ` **反向标定**为

`ℓ_fit=√[ℏG_obs/(12π c³)] = 2.6323542160×10^-36m =0.16286750 ℓP`。

这只是代数逆运算。不能声称“从无自由参数计算出 G”。

## 5. 更深的障碍：宇宙学常数与曲率平方项

热核展开中的常数项（`a0`）产生约 UV cutoff 四次方的真空能项；`a2` 提供曲率平方及其他局部项。在极高截止能标下，若不说明如何消除或匹配这些项，不能声称仅凭 a1 便构成完整引力起源理论。特别是宇宙学常数的观测小尺度仍是重要开放问题。

## 6. 什么才算真的导出了 G？

必须先在**不输入 G_obs、ℓP(G_obs) 或同等信息**时给出：

- 独立可计算的微观场谱，N 与 ξ 等不是自由拟合参数。
- 可观测或理论唯一确定的物理微观能标 ℓ_*，含不确定度与独立验证。
- 明确可重整化条件/UV 完成，确保 `G_ren` 与 cutoff 的任意形式无关。
- 能同时解释宇宙学常数、额外自由度与已知的引力精密检验。
- 在这些条件下事前计算 `G_pred±σ`，再与 CODATA 2022 比较。

**上述证明目前没有完成。** 正确的可证伪新模型应该先提出可区分 GR 的可测效应，而非只复现已经输入的 G。
