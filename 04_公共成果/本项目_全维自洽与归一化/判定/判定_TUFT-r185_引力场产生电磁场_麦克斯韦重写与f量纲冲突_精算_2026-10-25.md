## 4. 关键读数

**4.1 公理自毁是结构性的，非数值误差。** `R(t)=Ct` 是靶文明文公设（V3 §2.1 `R = Ct`、§2.2 `A = d²R/dt²`）。对任一有限差分步长，`A = C·(h − 2·0 + (−h))/h² = 0` 逐位精确（K01/G14）。于是 `E = −f ∂A/∂t` 与 `B = f ∇×A` 全为 0——旗舰方程描述一个零场宇宙。这不是「差一个常数」，而是公设直接给出 `A ≡ 0`。

**4.2 「第一性原理推导」的承重链条缺一环。** 把安培定律从「被采纳的前提」（V3 eq 2）当作「由公理导出」的结论，是唯一能让方程看起来「来自引力」的步骤。撤掉这一假定，方程无从导出（A02/D01）；保留它，方程就是麦克斯韦（K07 残差机器零）。`A = −E/f` 重标号与 r169 同型：电磁矢势除以 f 不是「引力产生电磁」，只是换了记法。

**4.3 f 的公式维与所需维差一个长度因子（头条）。** 由 `E = −f ∂A/∂t`：`[f] = [E]/[∂A/∂t] = (1,1,−3,−1)/(0,1,−3,0) = (1,0,0,−1) = M·I⁻¹`（V2 §3.2 自证）。但 `f = (c/2)√(4πε₀G)`：`[c]=(0,1,−1,0)`，`[√(ε₀G)] = ((−1,−3,4,2)+(−1,3,−2,0))/2 = (−1,0,1,1)`，乘积 `(−1,1,0,1) = M⁻¹·L·I`。二者不等（K03/G06 机读触发），差 `(−2,1,0,−2) = M⁻²·L·I⁻²` 即一个长度因子。故 `f = 0.012917` 的「kg/A」单位错误；真单位应为 `m·A/kg`。

**4.4 v1 的 `f ~ √(G/ε₀)` 是家族内第三种口径。** `[G/ε₀]^½ = ((−1,3,−2,0)−(−1,−3,4,2))/2 = (0,3,−3,−1) = L³T⁻³I⁻¹`（K06），与公式维 `M⁻¹LI`、定义维 `MI⁻¹` 三者两两互斥，与 r168「f 五口径互斥」互印（不并入）。

**4.5 v1/v3 在电场定义与 f 表达式上自相矛盾。** 同一核心公式：v1 `E = +f Ω² ∂A/∂t`、`f = √(G/ε₀)`；v3 `E = −f ∂A/∂t`、`f = (c/2)√(4πε₀G)`。符号、Ω² 因子、f 的表达式三处互斥（C01/C02，K11/G03 文本证据）。

**4.6 v2 的数值输出链不自洽且不可复现。** 展示 `4πε₀G = 7.42618e−20`（正确值 `7.426e−21` 的 10 倍）却给出正确终值 `f = 0.012917`；其 sympy 代码实算为 `7.426e−21`（G08 文本证据）。打印链 e−20→e−10→e−2 在中间为 e−10 时 f 应为 0.129，与终值 0.012917 矛盾。另 sympy 验证用 `V²` 替 `c²`，对系数不敏感（E02/E03）。

**4.7 有利项全是「量纲/标定层」闭合，无一条涉及预测。** P01–P08 八条 PASS 没有一条给出超出标准电动力学的可检验预言；`A = −E/f` 重标号下「能退化到经典电动力学」恰是因为它本就是麦克斯韦（P08）。
