## 6.1 大尺度螺旋宇宙核心方程

### 核心方程
宇宙在大尺度上是一个巨大的圆柱螺旋，星系都沿着螺旋线运动，所以星系旋转曲线是平坦的，不需要暗物质：
$$
v(r) = \frac{h}{\sqrt{r^2+h^2}} c \approx \text{常数}
$$
当r很大时，切线速度趋近于常数，正好和观测到的星系旋转曲线平坦一致，完全不需要暗物质。

### 不需要暗物质
星系旋转曲线平坦是大尺度螺旋几何的自然结果，不是因为有暗物质，暗物质是不存在的，是我们把螺旋运动当成了圆周运动才假设出来的。

### 不需要暗能量
宇宙加速膨胀是挠率场的负压强效应，挠率场的状态方程$w=-1$，自然产生加速膨胀，不需要暗能量。

### 黑洞无奇点
黑洞中心曲率是有限的，$\kappa_{max} = c^3/(G\hbar) \approx 10^{70} m^{-1}$，不是无限大，所以没有奇点，黑洞是一个极高曲率的螺旋球，物质不会坍缩到无限小。

### 宇宙年龄
宇宙是永恒的，没有大爆炸起点，我们观测到的宇宙膨胀是大螺旋的局部运动，宇宙在时间上是无限的，空间上也是无限的，分形嵌套，无穷无尽。

### 应用场景
- 解释所有天文观测：星系旋转曲线、引力透镜、宇宙微波背景、元素丰度，都可以用螺旋宇宙解释，不需要暗物质暗能量
- 宇宙航行：沿着螺旋臂运动可以自然获得很高的速度，不需要太多能量
- 黑洞利用：黑洞是天然的曲率引擎，可以用来做星际航行的动力源

### 数值验证
```python
import math
c = 299792458.0

def galaxy_rotation_curve(r, h_spiral=10e3*3.086e16):
    v = c * h_spiral / math.sqrt(r**2 + h_spiral**2)
    return v
r1 = 10e3*3.086e16
v1 = galaxy_rotation_curve(r1)
r2 = 100e3*3.086e16
v2 = galaxy_rotation_curve(r2)
print(f"1万光年处速度{v1/1000:.0f}km/s，10万光年处速度{v2/1000:.0f}km/s，近似平坦，符合观测，不需要暗物质")
assert abs(v2 - v1)/v1 < 0.5

kappa_max = c**3/(G*hbar)
print(f"黑洞中心最大曲率κ_max={kappa_max:.2e} m⁻¹，有限值，无奇点")
```
