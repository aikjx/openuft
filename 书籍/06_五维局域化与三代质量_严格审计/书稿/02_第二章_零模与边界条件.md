# 第二章 · 零模与边界条件

## 2.1 五维费米子的一阶方程

区间 `0≤y≤L` 上，五维费米子作用量

$$\tag{2.1} S_\Psi=\int d^4x\,dy\;\bar\Psi\bigl(i\Gamma^MD_M-\mathcal M(y)\bigr)\Psi .$$

用 `\Gamma` 而非 `\gamma`，是为了提醒：这是五维旋量，`M` 从 0 到 4。四维部分照常，第五维给出一个**一阶**方程。这一点决定了整章的骨架——一阶方程只有一个解（不是两个），所以零模是"定"的，不是"挑"的。

在简化模型中取常数体质量 `\mathcal M(y)=k`（轨道折叠模型里它可读作奇宇称质量在基本区间内的取值）。左手零模满足

$$\tag{2.2} (\partial_y+k)f_L^{(0)}(y)=0 .$$

## 2.2 一阶方程的解空间是"一维"——这条最重要

(2.2) 是**一阶线性常微分方程**。一阶意味着：给定一点的值，全程唯一确定。解空间维数 = 1。

这一句话看起来平淡，其实是整本书地基上最深的一根桩。第三章要证的"简并定理"、第六章要证的"三代不能由一个背景产生"，都是它的直接推论：

$$(\text{一阶方程})\;\Longrightarrow\;\dim\ker D_L\le1\;\Longrightarrow\;\text{一个背景最多给你一个零模}\;.$$

三代需要三维。所以三代必须来自三样东西之一：三个味参数（＝三个拟合量）、一个拓扑指标 `N=3`（把连续参数压成整数，但仍需解释 `N=3`）、或一个离散的味算符谱（尚未写出）。**这不是技巧问题，是维数问题。**

## 2.3 解出来

直接积分：

$$\frac{df_L^{(0)}}{f_L^{(0)}}=-k\,dy\;\Longrightarrow\;f_L^{(0)}(y)=N_L\,e^{-ky}.$$

归一化 `∫₀^L|f_L^{(0)}|²dy=1`：

$$\int_0^Le^{-2ky}dy=\frac{1-e^{-2kL}}{2k}\;\Longrightarrow\;N_L=\sqrt{\frac{2k}{1-e^{-2kL}}} .$$

所以

$$\tag{2.3} \boxed{\;f_L^{(0)}(y)=\sqrt{\frac{2k}{1-e^{-2kL}}}\;e^{-ky}\;} .$$

用另一组具有**相反手征边界条件**的五维费米子，可以得到局域在另一端的右手零模：

$$\tag{2.4} \boxed{\;f_R^{(0)}(y)=\sqrt{\frac{2k}{1-e^{-2kL}}}\;e^{-k(L-y)}\;} .$$

机核：`∫|f_L|²=1.000000000000000`（残差 `6.66e-16`），`∫|f_R|²=1.000000000000001`（残差 `6.66e-16`）（`S1a`）。

## 2.4 边界条件才是内容

上面的推导只用到一个物理输入：**边界条件**。这是本章最需要强调的：

- 若两端取**同号**手征条件，零模在两端都被排除，dirichlet 化，无解；
- 若取**周期**条件，`y` 与 `y+L` 等价，指数解不满足 `f(y+L)=f(y)`，除 `N_L=0` 外无解；
- 只有**相反**（一端 `+`、一端 `−`）的手征条件，才允许"一端指数衰减、另一端指数增长"的解存活。

所以零模的存在，本质上是**拓扑性的**：它是两个边界条件的"差"导致的。说"我们把常数 `k` 写进了作用量"，不如说"我们选了一对边界条件，剩下的都是必然的"。

这也解释了一个常被忽略的点：**`k` 的大小不决定零模的"有/无"，只决定它"多靠边"。** `k=0` 时 `f_L` 均匀；`k→∞` 时 `f_L` 越来越贴 `y=0`。零模的**存在**由边界条件定，零模的**形状**由 `k` 定。

## 2.5 为什么要左右手两组不同的费米子

(2.3) 与 (2.4) 不能是同一个场的左右手分量。原因很直接：同一个五维场只满足一套边界条件，不可能同时在两端各局域化一个。要让左手贴一端、右手贴另一端，必须引入**两个五维费米子**，给它们相反的边界条件，再由 Higgs 把它们连起来。

这一步是必需的，也是常被省略的。省略它的后果是：读者会以为"零模"是一个场的一个分量，然后困惑于"质量项需要左右手一起出现，那为什么它们局域在两端"。

$$\text{左手贴 }0,\ \text{右手贴 }L\;\Longrightarrow\;\text{重叠 }\int f_Lf_R\;\text{被指数压制}\;\Longrightarrow\;\text{质量小}\;.$$

这正是第三章 `z/sinh z` 的物理内容。

## 2.7 一个必须提前说明的边界

本章的所有结论都站在一个**平直区间**上：`0≤y≤L`，无挠率、无曲率、无常数背景涨落。若第五维是轨道折叠 `S¹/Z₂`，`y` 的定义域是 `[0,L]` 而 `−y` 与 `y` 等价，`k` 必须理解为**奇宇称质量在基本区间内的取值**（严格地说 `\mathcal M(y)=k\,\mathrm{sgn}(y)`）。两种写法在本章给出同一个 (2.3)，但它们的**边界项**不同；本书不处理边界项，凡涉及端点变分处，一律标"未做"。

这句话在第七章还会再出现一次：kink 背景只是 `φ⁴` 的一个精确解，不是 `[0,1]` 边值问题的解。全书对"边界"的态度是一致的：**给出解的，标解；没做的，标没做。**
