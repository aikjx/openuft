## 通用检查清单（每个章节都必须检查）

### LaTeX公式格式
- [ ] 所有数学公式使用LaTeX格式
- [ ] 行内公式使用 `$公式$` 格式
- [ ] 独立公式使用 `$$公式$$` 格式
- [ ] 矢量使用 `\vec{符号}` 格式
- [ ] 导数使用 `\frac{d}{dt}` 格式
- [ ] 微分使用 `d` 而不是 `∂`（除非是偏导数）

### 量纲标注
- [ ] 所有物理量添加量纲标注
- [ ] 量纲标注格式：`[量纲]` 或在符号说明中说明
- [ ] 基本量纲：[M]质量、[L]长度、[T]时间
- [ ] 复合量纲正确（如[MLT⁻¹]动量、[ML²T⁻²]能量）
- [ ] 常数有量纲标注（如G、c、h等）

### 布局优化
- [ ] 公式与文本之间有空行
- [ ] 符号说明使用列表格式
- [ ] 推导过程分步展示（第一步、第二步...）
- [ ] 对比内容使用表格
- [ ] 引用块用于重要观点

### 理论准确性
- [ ] 核心公式与《大道至简》一致
- [ ] 物理机制描述准确
- [ ] 术语使用规范统一
- [ ] 没有错误的理论解释

### 核心观点强调
- [ ] 核心方程使用强调框或引用块
- [ ] 震撼观点使用引用块
- [ ] 关键结论突出显示
- [ ] 与传统理论的对比说明清晰

### 格式规范
- [ ] Markdown格式正确
- [ ] 标题层级合理（一级标题#、二级标题##等）
- [ ] 列表格式统一（使用 - 或 1.）
- [ ] 没有冗余空行
