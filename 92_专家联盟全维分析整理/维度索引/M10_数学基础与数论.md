## 三、判定口径与正确核

三级判定（`理论体系方程总汇_正确方程集_2026-10-14.md` §0）：**A** 机器校验通过（量纲四轴零缺口且数值复算到机器零）；**B** 体系级健康（H）；**C** 册级 PASS。

正确核 **22 条（K-01–K-22）** 经 A 级判定存活（PASS 22 / FAIL 16 / BOUNDARY 5 / INFO 7）。但红线必须连读：**正确核里没有一条是新增物理**——量纲类 18＋数值/恒等类 4；真正站得住的是教科书物理的记号改写（牛顿、库仑、波动方程、质能、α 定义等）＋已证几何–运动学定理（归一正本 §10；正确方程集头部红线）。

方法论含义：D10 的价值不在「数学对了多少」，而在把「数学对」与「物理成立」用同一套分层标签分开。对外唯一出口判据是 method_F：**第一性内容 ⟺ 无量纲量的数值**（`04_公共成果/状态看板.md` §四，判据原文在 `02_共享基础/研究规范/method_F_第一性判据.md`）；「几何化导出 c、ħ、G」是伪目标，「导出 α 或质量比」才是真目标。

## 五、数论语料的诚实定位

- 登记册三层：A 层公认开放问题 69 / B 层可判子题 143 / C 层自洽校验 78，共 290，去重 6，缺 710（`07_统一场方程/卷宗总表.md` J99 行；`04_公共成果/本项目_统一场论攻破/布局_物理Top1000难题攻破清单_2026-10-21.md`）。一方程记分板 **0/6**，为唯一对外读数（归一正本 §0）。
- D10 语料 712 会话（全维分析总览 D10 行），含大量哥德巴赫/素数/π–e 类内容。论文台账头部明文：「**哥德巴赫猜想仍未证明；统一场论仍未成立**」。仓库对这类语料没有「热度即证据」的口子——按待整理区规则须先算后归；证明性主张不得以语料数量为据。
- 可机验部分（枚举、回溯算法、数值验证脚本）可作 C 层自洽校验素材登记；「强哥德巴赫猜想完整证明」类会话主张一律按未核验语料处置。

## 六、建议

1. 双标签维护：每条正确核引用时必须连「性质列」（定义式/教科书改写/恒等式）与三级判定级别。
2. 数论语料分流：可机验的枚举/算法部分走 C 层登记通道；证明性主张先算后归。
3. `THEOREMS.md` 与 `07_统一场方程/卷宗总表.md` 加互链并注明两套账分工（建议，须走维护契约，本报告不代改）。
4. method_F「无量纲量数值」判据继续作为 D10 对外唯一出口判据；量纲自洽的命题一律不得单独作为成果引用（归一正本 §10 X-3 为教科书级反例）。

## 七、一句话结论

D10 的地基扎实而边界清楚：五卷方法库与经典基准构成可复用的判定机器，22 条正确核全部是记号改写与已证定理而非新物理，S01 三重奏是唯一 H 级数学框架且已证不能反向生成物理常数；数论语料量最大（712 会话）但与主线之间只有「先算后归」一条合法通道。
