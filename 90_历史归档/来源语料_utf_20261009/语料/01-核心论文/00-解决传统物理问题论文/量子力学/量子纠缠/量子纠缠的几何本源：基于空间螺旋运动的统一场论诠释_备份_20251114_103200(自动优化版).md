## 理论框架

局域隐变量理论假设，量子力学的统计特性是由于存在未被测量的隐变量λ，这些隐变量决定了测量结果，但我们无法精确知道它们的值，只能对它们进行统计平均。

在局域隐变量理论中，关联函数E(a,b)可以表示为：

E(a,b) = ∫dλρ(λ)A(a,λ)B(b,λ)

其中，ρ(λ)为隐变量的概率分布，A(a,λ)和B(b,λ)为在方向a和b上测量两个粒子的结果，取值为±1。

## 数学推导

考虑三个方向a、b、c，我们可以定义：

E(a,b) - E(a,c) = ∫dλρ(λ)[A(a,λ)B(b,λ) - A(a,λ)B(c,λ)]
= ∫dλρ(λ)A(a,λ)[B(b,λ) - B(c,λ)]

由于B(b,λ)和B(c,λ)的取值为±1，我们有：

B(b,λ) - B(c,λ) = ±2 或 0

当B(b,λ) = B(c,λ)时，差值为0；当B(b,λ) ≠ B(c,λ)时，差值为±2。

我们可以将差值表示为：

B(b,λ) - B(c,λ) = B(b,λ)[1 - B(b,λ)B(c,λ)]

因为当B(b,λ) = B(c,λ)时，右边为B(b,λ)[1 - 1] = 0；当B(b,λ) ≠ B(c,λ)时，右边为B(b,λ)[1 - (-1)] = 2B(b,λ)，其绝对值为2，与左边一致。

因此，我们有：

E(a,b) - E(a,c) = ∫dλρ(λ)A(a,λ)B(b,λ)[1 - B(b,λ)B(c,λ)]
= ∫dλρ(λ)A(a,λ)B(b,λ) - ∫dλρ(λ)A(a,λ)B(b,λ)B(b,λ)B(c,λ)
= E(a,b) - ∫dλρ(λ)A(a,λ)B(c,λ)
= E(a,b) - E(a,c)

这似乎没有进展，让我们换一种方法。考虑：

|E(a,b) - E(a,c)| = |∫dλρ(λ)A(a,λ)[B(b,λ) - B(c,λ)]|
≤ ∫dλρ(λ)|A(a,λ)[B(b,λ) - B(c,λ)]|
= ∫dλρ(λ)|B(b,λ) - B(c,λ)|

由于B(b,λ)和B(c,λ)的取值为±1，我们有：

|B(b,λ) - B(c,λ)| = 2|(B(b,λ) - B(c,λ))/2| = 2|sin(θ/2)|

其中，θ为方向b和c之间的夹角。

然而，更简单的方法是注意到：

[B(b,λ) - B(c,λ)] = B(b,λ)[1 - B(b,λ)B(c,λ)]

因此：

|E(a,b) - E(a,c)| = |∫dλρ(λ)A(a,λ)B(b,λ)[1 - B(b,λ)B(c,λ)]|
≤ ∫dλρ(λ)|A(a,λ)B(b,λ)[1 - B(b,λ)B(c,λ)]|
= ∫dλρ(λ)|1 - B(b,λ)B(c,λ)|

因为|A(a,λ)B(b,λ)| = 1。

又因为：

|1 - B(b,λ)B(c,λ)| = 1 - B(b,λ)B(c,λ)

当B(b,λ)B(c,λ) = 1时，右边为0；当B(b,λ)B(c,λ) = -1时，右边为2。

因此：

|E(a,b) - E(a,c)| ≤ ∫dλρ(λ)[1 - B(b,λ)B(c,λ)] = 1 - E(b,c)

这就是贝尔不等式的一种形式：

|E(a,b) - E(a,c)| ≤ 1 - E(b,c)

另一种常见的形式是：

|E(a,b) - E(a,c)| + |E(a',b) - E(a',c)| ≤ 2

其中，a'为另一个方向。
