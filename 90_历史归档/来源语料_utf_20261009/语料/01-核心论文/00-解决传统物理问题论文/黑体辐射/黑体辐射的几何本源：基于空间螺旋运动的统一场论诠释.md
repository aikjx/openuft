### A.1 普朗克公式的详细推导

基于空间螺旋运动假设，我们可以详细推导普朗克公式。

#### A.1.1 黑体空腔中的电磁辐射模式数

在一个体积为V的黑体空腔中，频率在ν到ν+dν之间的电磁辐射模式数可以通过考虑电磁波的边界条件来确定。对于三维空腔，波矢k的三个分量满足：

k_x = n_xπ/L, k_y = n_yπ/L, k_z = n_zπ/L

其中，L为空腔的边长，n_x, n_y, n_z为正整数。在波矢空间中，每个模式占据的体积为(π/L)³，因此在k到k+dk之间的模式数为：

dN' = V/(2π³) × 4πk²dk

考虑到电磁波的两个偏振态，总的模式数为：

dN = 2dN' = V/(π²)k²dk

利用k = 2πν/c，我们可以将模式数表示为频率的函数：

dN = (8πVν²/c³)dν

#### A.1.2 量子化能量的平均分布

根据普朗克的能量量子化假设，每个电磁辐射模式的能量只能取0, hν, 2hν, ...等离散值。根据玻尔兹曼分布，能量为nhν的概率为：

P(n) = e^(-nhν/kT)/Z

其中，Z为配分函数：

Z = Σₙ=0^∞ e^(-nhν/kT) = 1/(1 - e^(-hν/kT))

因此，每个模式的平均能量为：

<E> = Σₙ=0^∞ nhνP(n) = hνe^(-hν/kT)/(1 - e^(-hν/kT)) = hν/(e^(hν/kT) - 1)

#### A.1.3 普朗克公式的推导

黑体辐射的能量密度为单位体积内的总能量，因此：

u(ν, T) = (dN/dV)·<E> = (8πhν³/c³)/(e^(hν/kT) - 1)

转换为波长表示，利用ν = c/λ，dν = -c/λ²dλ，我们得到：

u(λ, T) = (8πhc/λ⁵)/(e^(hc/λkT) - 1)

这就是普朗克黑体辐射公式。

### A.2 斯特藩-玻尔兹曼定律的详细推导

通过对普朗克公式在所有波长范围内积分，我们可以推导出斯特藩-玻尔兹曼定律。

令x = hc/(λkT)，则λ = hc/(xkT)，dλ = -hc/(x²kT)dx。当λ从0到∞时，x从∞到0。代入普朗克公式，我们得到：

u(T) = ∫₀^∞ u(λ, T)dλ = ∫₀^∞ (8πhc/λ⁵)/(e^(hc/λkT) - 1)dλ = ∫_∞^0 (8πhc/(hc/(xkT))^5)/(e^x - 1)·(-hc/(x²kT))dx = (8πk^4T^4)/(h³c³)∫₀^∞ x³/(e^x - 1)dx

积分∫₀^∞ x³/(e^x - 1)dx = π⁴/15，因此：

u(T) = (8π^5k^4)/(15c²h³)T^4

根据电磁理论，黑体的辐射出射度（单位面积的辐射功率）与能量密度的关系为：

M(T) = (c/4)u(T) = (2π^5k^4)/(15c²h³)T^4 = σT^4

其中，σ = (2π^5k^4)/(15c²h³)为斯特藩-玻尔兹曼常数。

### A.3 维恩位移定律的详细推导

通过对普朗克公式求导并找到最大值，我们可以推导出维恩位移定律。

令x = hc/(λkT)，则普朗克公式可以表示为：

u(x, T) = (8πk^5T^5)/(h^4c³)x^5/(e^x - 1)

为了找到最大值，我们对u(x, T)关于x求导并令其等于零：

du/dx = (8πk^5T^5)/(h^4c³)[5x^4(e^x - 1) - x^5e^x]/(e^x - 1)^2 = 0

解得：

5(e^x - 1) = xe^x

这是一个超越方程，其数值解为x ≈ 4.965。因此，峰值波长λ_max为：

λ_max = hc/(xkT) = hc/(4.965kT)

即：

λ_max·T = hc/(4.965k) = b

其中，b = 2.898×10^-3 m·K为维恩位移常数。

### A.4 瑞利-金斯公式和维恩公式的推导

在长波区域（低频），hc/(λkT) << 1，e^(hc/λkT) ≈ 1 + hc/(λkT)，因此普朗克公式可以近似为：

u(λ, T) ≈ (8πhc/λ⁵)/(hc/(λkT)) = 8πkT/λ⁴

这就是瑞利-金斯公式，它适用于长波区域。

在短波区域（高频），hc/(λkT) >> 1，e^(hc/λkT) >> 1，因此普朗克公式可以近似为：

u(λ, T) ≈ (8πhc/λ⁵)e^(-hc/(λkT))

这就是维恩公式，它适用于短波区域。

普朗克公式在所有波长范围内都与实验数据高度吻合，它成功地统一了瑞利-金斯公式和维恩公式。
