# E1 · 光线引力偏折

## 观测结果

掠过太阳边缘的光线偏折角：
- 牛顿预言：$0.875''$
- **GR 预言：$1.75''$**（牛顿的 2 倍）
- 1919 年 Eddington 日食观测确认 GR 预言
- 现代 VLBI 测量精度达 $10^{-4}$

## 物理机制

GR 中，光子沿零测地线运动，太阳引力场使时空弯曲，光线偏折角：

$$\delta = \frac{4GM}{c^2 b}$$

其中 $b$ 为碰撞参数。
