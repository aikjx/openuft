## 一、全维求导（微分结构）

### 1.1 旋量对偶方程求导 → 流守恒

【 **推导** :定义 $J^{\mu} = \Psi^{\dagger}\sigma^{\mu}\Psi$，取全微分：

$$\partial_{\mu}J^{\mu} = \left( \partial_{\mu}\Psi^{\dagger} \right)\sigma^{\mu}\Psi + \Psi^{\dagger}\sigma^{\mu}\partial_{\mu}\Psi = 2\,\mathrm{Re}\left( \Psi^{\dagger}\sigma^{\mu}\partial_{\mu}\Psi \right)$$

代入旋量对偶方程 $\sigma^{\mu}\partial_{\mu}\Psi = \lambda\,\Theta\,\Psi^{*}$：

$$\partial_{\mu}J^{\mu} = 2\lambda\,\mathrm{Re}\left( \Psi^{\dagger}\Theta\,\Psi^{*} \right) = 2\lambda\,\mathrm{Re}\left( \psi_{0}^{*}\left( -\psi_{1}^{*} \right) + \psi_{1}^{*}\psi_{0}^{*} \right) = 0$$

源项为"同相共轭配对"，实部恒零——**阴阳互源的净效果为零，流严格守恒**。此为纯代数恒等式，不依赖任何近似。】

### 1.2 拓扑荷求导 → 条件守恒（伏笔）

【 **推导** :对绕数 $Q = \frac{1}{2\pi\mathrm{i}}\oint \mathrm{d}z/z$（$z = \psi_{0}/\psi_{1}$）取时间微分，$\mathrm{d}Q/\mathrm{d}t \neq 0$ 当且仅当 $z$ 扫过 $0$ 或 $\infty$，即 $\psi_{0}$ 或 $\psi_{1}$ 在某点过零。结论：绕数是**条件守恒量**，其守恒依赖于"零振幅事件不发生"——这是本报告最关键的一处伏笔，第三节将被数值证伪坐实。】

### 1.3 β 函数求导 → 不动点与稳定性

【 **推导** :记 $s = \ln\left( \mu/\mu_{0} \right)$，$\frac{\mathrm{d}^{2}g}{\mathrm{d}s^{2}} = \beta'\left( g \right)\beta\left( g \right)$。对 $\beta\left( g \right) = \varepsilon g - cg^{3}$，不动点 $g^{*} = \sqrt{\varepsilon/c}$ 处 $\beta'\left( g^{*} \right) = \varepsilon - 3cg^{*2} = -2\varepsilon < 0$，稳定收敛；由 $\beta$ 为奇函数，$-g^{*}$ 处 $\beta'\left( -g^{*} \right) = \beta'\left( g^{*} \right) < 0$，同样稳定——**阴阳两个不动点互为镜像，流向对称**。】

### 1.4 对偶度规求导 → 曲率闭式

【 **推导** :取 $A\left( r \right) = 1 - k\,r/\left( r^{2} + \ell^{2} \right)$（$k = 2GM/\ell$），对二维度规 $\mathrm{d}s^{2} = -A\,\mathrm{d}t^{2} + A^{-1}\mathrm{d}r^{2}$，曲率标量 $R = -A''$。逐项求导：

$$f\left( r \right) = \frac{r}{r^{2}+\ell^{2}}, \qquad f'' = \frac{2r\left( r^{2} - 3\ell^{2} \right)}{\left( r^{2}+\ell^{2} \right)^{3}}$$

$$R\left( r \right) = -A''\left( r \right) = \frac{2k\,r\left( r^{2} - 3\ell^{2} \right)}{\left( r^{2}+\ell^{2} \right)^{3}}$$

令 $R' = 0$：$r^{4} - 6\ell^{2}r^{2} + \ell^{4} = 0$，得 $r = \sqrt{3 \pm 2\sqrt{2}}\,\ell = \left( \sqrt{2} \pm 1 \right)\ell$。代入得曲率上界闭式：

$$\left| R \right|_{\max} = \frac{\left( 3 + 2\sqrt{2} \right)GM}{2\ell^{3}}$$

端点行为 $R\left( 0^{+} \right) = R\left( \infty \right) = 0$——曲率全域有界，奇点被逐出。】

### 1.5 因果畴求导 → 通量平衡

【 **推导** :Stokes 定理直接给出 $\frac{\mathrm{d}}{\mathrm{d}t}\int_{\mathcal{C}}\omega = \oint_{\partial\mathcal{C}}\Theta$——畴内变化率恒等于穿壁通量，无新假设；对偶翻转 $\rho \to -\rho$ 保证全时空总荷 $\equiv 0$。】
