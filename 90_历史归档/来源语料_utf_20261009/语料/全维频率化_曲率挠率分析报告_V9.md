#### 核心证明定理

**定理 1 (公理链无循环性)**: 公理体系 A0-A5 中不存在循环依赖。
- A0: ω [原始量, s⁻¹]
- A1: κ, τ [原始量, m⁻¹]  
- A2: c = ω·R, R = 1/√(κ²+τ²) [推导量]
- A3: ℏ = m·ω·R² [推导量]
- A4: α = τ/κ [几何比]
- A5: m = ℏ·√(κ²+τ²)/c [推导量]

**证明**: 假设存在循环依赖 f₁ → f₂ → ... → f₁。由于 ω, κ, τ 是原始量（无推导），循环只能涉及 {c, ℏ, G, m}。由 A2: c = ω/√(κ²+τ²)，由 A3+A5: ℏ = mc²/ω → m = ℏ√(κ²+τ²)/c。代入得: c = ω/√(κ²+τ²), ℏ = mω/(κ²+τ²), m = ℏ√(κ²+τ²)/c。可联立求解，无循环。 ✓

**定理 2 (R 的纯几何定义等价性)**: R = 1/√(κ²+τ²) ≡ R = ℏ/(mc)
- 由螺旋参数化: κ = cosθ/R, τ = sinθ/R
- κ² + τ² = cos²θ/R² + sin²θ/R² = 1/R²
- ∴ R = 1/√(κ²+τ²) ✓（纯几何，不含 ℏ, m）
- 由 A5: m = ℏ/(c·R) → R = ℏ/(mc) ✓（与几何定义一致）

**定理 3 (频率-几何对偶性)**: ν_s = 1/(2πR) = mc/h
- 由 R = 1/√(κ²+τ²): 1/R = √(κ²+τ²)
- ν_s = 1/(2πR) = √(κ²+τ²)/(2π) = |N| (复频率模)
- 由 A5: m = ℏ√(κ²+τ²)/c → √(κ²+τ²) = mc/ℏ = 2πmc/h
- ∴ ν_s = 2πmc/(2πh) = mc/h ✓（Compton 频率 = 几何频率）

**定理 4 (力的几何梯度本质)**: F = -h∇ν_t = -ℏ∇ω = -ℏc∇(1/R)
- 从能量-频率关系: E = hν_t
- 力的定义: F = -dU/dx = -d(hν_t)/dx = -h∇ν_t ✓
- 由 ν_t = ω/(2π): F = -h·∇(ω/(2π)) = -ℏ∇ω ✓
- 由 ω = c/R: F = -ℏ·∇(c/R) = -ℏc∇(1/R) ✓

**定理 5 (时空频率不变量)**: ν_t² - (ν_dB·c)² = (mc²/h)²
- 静止粒子: ν_t = mc²/h, ν_dB = 0 → ν_t² - 0 = (mc²/h)² ✓
- 运动粒子: ν_t = γmc²/h, ν_dB = γmv/h
  → ν_t² - (ν_dB·c)² = γ²(mc²/h)² - γ²(mvc/h)²
  = γ²(mc²/h)²(1 - v²/c²) = (mc²/h)² ✓
- 光子 (m=0): ν_t = ν, ν_dB = ν/c → ν_t² - ν_t² = 0 ✓

**定理 6 (精确力比公式)**: F_em/F_grav = α·M_P²/(m_e·m_p)
- F_em = e²/(4πε₀r²) = αℏc/r²

- F_em/F_grav = αℏc · M_P²/(ℏc·m_em_p) = α·M_P²/(m_em_p) ✓
