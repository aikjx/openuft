## 二、A. E7 独立复核（重大发现：**符号修正**）

**做法**：数值求解指数度规 `β₁=e^{−2U}`（isotropic）的零测地线：

```
ds² = −e^{−2U}c²dt² + e^{2U}(dr² + r²dΩ²),  U = m/r,  m = GM/c²
零测地线:  (du/dφ)² = e^{4mu}/b² − u²   (u = 1/r)
α(m,b) = 2∫₀^{u₀} du/√(e^{4mu}/b² − u²) − π
```

（替换 `u = u₀ sinθ` 消端点 √ 奇异；mpmath 60 位）

**数值结果**（m=1e−3）：

| b | α（数值） | 1PN 期望 4m/b |
|---|---|---|
| 1.0 | 4.0126145706e−3 | 4.000e−3 |
| 2.0 | 2.0031476032e−3 | 2.000e−3 |
| 4.0 | 1.0007861469e−3 | 1.000e−3 |

**2PN 系数提取**（对 m/b→0 外推）：

```
c2（数值）      = 12.566274
+4π             = 12.566371   （差 0.0001）  <-- 吻合
−4π             = −12.566371  （差 25.13）
GR 的 15π/4     = 11.780972   （差 0.785）
```

### 结论

1. **E7 的符号错误**：TUFT 指数度规的 2PN 系数是 **`+4π`**（数值 12.566274，与 +4π 差 1e−4），
   报告写的 **`−4π`** 符号反了；
2. **D5 仍为可区分点**：TUFT `+4π = 12.566` ≠ GR `15π/4 = 11.781`，**相差 6.7%** ——
   2PN 光偏折确实是 TUFT 与 GR 的可观测差异（虽极小，需未来 VLBI/空间天体测量）；
3. **建议**：把 E7 与 D5 的 `−4π` 改为 **`+4π`**；D5 的"与 GR 2PN 的可观测差"由"符号差"修正为"系数差 6.7%"。
