## 一、时空螺旋闭环拓扑：费米子几何定义

TUFT 公理：粒子 = **稳态闭合光速螺旋形变结**，局部线元始终满足本征条件 `v_local = c`。

### 1.1 闭环螺旋的拓扑环绕数 W

定义**拓扑环绕数（winding number）**：螺旋沿闭合轨道绕空间轴旋转总圈数。由 Călugăreanu–White 公式 `Lk = Tw + Wr` 且 `Lk ∈ ½ℤ`，取基态 `W = |Lk|`：

| 类型 | 环绕数 W | 几何闭合 | 波函数周期 |
|---|---|---|---|
| 玻色子 | `W ∈ ℤ` | 可定向带（n 偶） | 2π |
| 费米子 | `W ∈ ℤ + ½` | Möbius 型（n 奇） | 4π |

物理图像：费米子时空螺旋走**闭合回路一圈（空间 2π）**，标架相位翻转 π；必须旋转 **4π（两圈空间绕行）**，几何形变构型才完全复原。这就是自旋 1/2 的几何本源，不是人为赋予的量子数。

### 1.2 螺旋相位本征关系（已数值核验）

设螺旋本征角频率 `ω = 2πf`，`τ` 为螺旋固有时。费米子单圈（2π 空间旋转）相位增量 `Δφ_{2π} = π + 2πn`；4π 后 `Δφ_{4π} = 2π + 4πn` ⇒ 构型复原。

据此旋量变换语言 **直接由时空螺旋拓扑导出**（无需预置旋量场）：

```
ψ(θ + 2π) = −ψ(θ)
ψ(θ + 4π) = +ψ(θ)
```

这正是狄拉克旋量的 4π 周期性质。其机器级核验见 `tuft_fermion_spin.py` 的 `frame_closure(1)`：`N(2π)` 与 `−N(0)` 间距 2.7e-16、`N(4π)` 与 `N(0)` 间距 5.5e-16。

> **诚实边界**：1.2 节的"相位本征关系"与 R2 的 Möbius 标架 4π 闭合是同一事实的两种表述；它不是 TUFT 的新推导，而是把已知拓扑结论接入 TUFT 的几何语言。

## 二、自旋角动量几何表达式（TUFT 形式）

螺旋形变的角动量由曲率 κ、挠率 τ、频率 ω 共同构成：

```
S = (ℏ/2) · (T̂ / |T̂|)
```

- `T̂/|T̂|`：挠率手性单位矢量（螺旋旋向，±1，对应自旋向上/向下）
- 因子 `½` 来自半整数环绕拓扑 `W = ½`

总角动量守恒：`J = L + S`，`L` 为轨道角动量（曲率环流贡献），`S` 为内禀自旋（挠率手性拓扑贡献）。

### 2.1 自旋算符对易关系（诚实标注）

```
[ S_i , S_j ] = iℏ ε_{ijk} S_k
```

这是 SU(2) 代数。需要**精确**说明其来源：

- SU(2) 是三维空间旋转代数；任何自旋-1/2 表示（泡利矩阵）都满足此对易关系。
- `T̂/|T̂|` 是**自旋的量化轴（S_z 的本征方向）**，而不是生成元。严格而言，"SU(2) 代数继承于挠率场的三维旋度结构" 这一表述是**几何直觉而非推导**——挠率方向提供了量化轴，SU(2) 代数本身来自 1/2-旋量的表示论。
- 本征值 `S²|s,m⟩ = s(s+1)ℏ²|s,m⟩`、`S_z|s,m⟩ = mℏ|s,m⟩`：费米子 `s=½, m=±½`；玻色子 `s=0,1,2,…`。

> **诚实边界（§2）**：`S = (ℏ/2)T̂/|T̂|` 把"自旋方向"锚定到挠率手性，是 TUFT 的几何对应；但 SU(2) 代数的成立依赖"电子是 1/2-旋量"这一表示论事实，TUFT 目前是**赋以**而非**导出**该表示。这是框架的接入点，不是闭环推导。

## 三、自旋-统计定理（TUFT 拓扑证明）

交换两个时空结粒子（两条稳态螺旋形变）等价于：**将其中一个粒子的拓扑环绕路径扭转 π**，即其世界线在时空里构成 Hopf 链（linking number 改变 1）。

### 3.1 两费米子交换 → 反对称

```
P̂ ψ(x₁,x₂) = −ψ(x₁,x₂)
```

波函数变号 ⇒ 反对称。

### 3.2 两玻色子交换 → 对称

```
P̂ ψ(x₁,x₂) = +ψ(x₁,x₂)
```

波函数不变号 ⇒ 对称。

> 传统量子场论的自旋-统计定理依赖洛伦兹不变性 + 定域因果；TUFT 版本把自旋-统计归约为**时空闭环螺旋拓扑的 4π 周期 + 交换 = Hopf 编织**这一更底层的事实。

### 3.3 数值核验（本章第七节升级仿真，`tuft_续篇_双结交换仿真.py`）

交换前后两世界线的 Gauss 双链积分：

| 量 | 数值 |
|---|---|
| 交换前 Lk（平行不链） | `−0.0000` |
| 交换后 Lk（Hopf 链） | `−1.0000` |
| 链数改变 ΔLk | `−1.0000` |
| 费米子交换相位 `exp(iπ·ΔLk)` | `−1.0000` |
| 玻色子交换相位 `exp(0·ΔLk)` | `+1.0000` |
| TUFT 缠绕数 W 关联 `exp(i·2π·W_f)`, `W_f=½` | `−1.0000` |
| TUFT 缠绕数 W 关联 `exp(i·2π·W_b)`, `W_b=1` | `+1.0000` |

费米子交换相位 `−1` 与 Hopf 链相位、`W=½` 缠绕数三者**数值一致**（PASS）。玻色子恒为 `+1`（与链数无关）。

### 3.4 泡利不相容原理直接推论

两费米子总波函数反对称：

```
ψ(x₁,s₁; x₂,s₂) = −ψ(x₂,s₂; x₁,s₁)
```

若两费米子占据完全相同空间位置 + 相同自旋（全同量子数）：`ψ = −ψ ⇒ ψ = 0`。
⇒ 不可能存在两个全同费米子处于同一量子态。

符号核验（`tuft_fermion_spin.py`）：两费米子同轨 2×2 Slater 行列式恒为 `0`（机器精确）。泡利原理不再是独立公理，是拓扑螺旋交换反对称的必然结果——**但需注明**：自旋-统计定理与泡利原理本身是已知量子力学结论，本章仅在 TUFT 拓扑框架内复现其代数，不主张为 TUFT 新发现。

## 四、手性与弱相互作用宇称破缺（TUFT 几何解释）

挠率 `T` 是**手性张量**：存在两个本征符号——`T>0` 右手螺旋，`T<0` 左手螺旋。定义手性算符 `γ̂₅ ∝ T̂/|T̂|`（手性投影算符）。

弱相互作用核心：`𝒪_weak ∝ J^μ A_μ · (1−γ₅)/2`，即时空挠率场**只耦合左手费米子（`T<0`）**，不耦合右手费米子。

几何解释：弱力是极高频、短程挠率畸变；真空基底几何权重 `Ω` 的拓扑势只允许**左手螺旋形变**参与挠率衰变通道，右手螺旋的挠率构型与真空势正交，无耦合。

> **诚实边界（§4）**：这是李-杨宇称不守恒的**几何直觉版解释**——"挠率场本身手性不对称，真空优先选择左手螺旋通道"。它**与已知物理一致**（V-A 结构），但本章**未从 TUFT 总作用量变分导出 W/Z 耦合强度或 (1−γ₅) 投影算符**；`γ̂₅ ∝ T̂/|T̂|` 是几何对应假设，不是推导。弱相互作用的定量预言（费米常数、W 质量）仍来自标准模型，未被 TUFT 重算。

## 五、费米子场拉格朗日量（从 TUFT 总作用量约化）

从 `S_TUFT` 对旋量场约化，得到 TUFT 狄拉克拉氏量：

```
𝒪_D = ψ̄ ( iγ^μ ∇_μ − m(K,T,Ω) ) ψ
```

### 5.1 质量内生公式（**必须修正**）

文档原稿给出 `m = α·K·T·Ω / c²`。**该式量纲非法**，已诚实标注为缺陷：

```
[α] = 1, [K] = L⁻¹, [T] = L⁻¹, [Ω] = 1, [c²] = L²T⁻²
⇒ [m] = L⁻³ T²     （非质量 [M]）
```

正确 TUFT 质量（来自 R1 已闭合的 `m = ℏ·√(κ²+τ²)/c`，即 `Ω = c√(κ²+τ²)` 与康普顿关系 `m = ℏΩ/c²` 的组合）：

```
m = ℏ·√(κ² + τ²) / c = ℏ·Ω_w / c² ,   Ω_w = c·√(κ²+τ²)
```

量纲核验：`[ℏ] = M L² T⁻¹`，`[Ω_w] = T⁻¹`，`[c²] = L² T⁻²` ⇒ `[m] = M` ✓。

- 粒子内核 `K,T` 大 ⇒ `m` 大
- 光子：无闭环，`Ω_w = 0` ⇒ `m = 0`

> **诚实边界（§5）**：即便量纲修正后，`m = ℏ√(κ²+τ²)/c` 也是由"光速螺旋本征频率"与康普顿关系**组合**而来，并非由 TUFT 总作用量变分**独立导出**。电子质量的**数值**仍由结尺度（康普顿波长 λ_C）反推得到；"为何结尺度是 λ_C 而非普朗克长度 l_P"的**尺度生成机制**仍是开放项。质量内生是方向正确、数值待赋的唯象公式。
