## 一、公理的形式化与定理 1–3（A 组）

四条公理记为可判定谓词：
**P1** 无量纲实值；**P2** `sign(Ω)` 在 D_G 上**由公理唯一确定**为负；**P3** 跨边界连续光滑；**P4** 自由常数 ≤ 1。

**T1（符号不变性 · 本册最强结论）**：取**严格满足 P4** 的族 `Ω = c₀·cos²θ`（c₀ = α_s = 0.1179，形状固定、常数仅一个），机器验证 Ω 与 −Ω **双双通过 P1/P3/P4**（无量纲性、光滑性、常数个数在取负下全部不变）。

⇒ 引力区给出 Ω < 0 与给出 Ω > 0 是**同等的合格解** ⇒ **P2 不可满足**。
这比元审计册 B-08 的表述更强：不是「当前没有机制」，而是**公理集本身不禁止反面** ⇒ 补机制之前，先要改公理。

**T2（尺度盲性）**：λ = 1e6 缩放后 θ 变化 **0.000e+00**（机器零），而力程变 1e6 倍 ⇒ 四力的力程（∞、∞、1e-15、1e-18）不可能由 Ω 决定。

**T3（外锚计数）**：四力中有限力程 2 个 ⇒ 至少 2 个独立尺度锚；若要求「单一公式 λ(θ) 统一给出」，那本身又是 1 条新假设 ⇒ **P4 无论哪种读法都不成立**。

**A-06（P3 的循环）**：若分区边界由 Ω 的行为定义（如「Ω < 0 即 D_G」），则 P3 的「跨边界连续」要求先有边界 ⇒ **边界与 Ω 互为前提** ⇒ P3 当前不可判定（BOUNDARY）。

| **A3 符号机制** | 使 `sign(Ω)` 唯一确定的对称/破缺机制 | T1 ⇒ D-01 不可消除 |
| **A4 节点约束** | 分区节点 θ_i 由外部理论给定 | 见 C-03：自由度转移进 θ_i ⇒ P4 失效 |

四条各自必要 ⇒ **最小增广 = 4 条新假设**。
对照 S17 闭合代价册的「最小增广集 4 行 = 3 条新假设」⇒ 两个体系的闭合瓶颈**同量级**，本册多出的 A4 是**本册新发现**。

### 3.2 C-03（本册新发现）：P4 的「限常数」可被分区节点绕过

构造性反例：取**严格满足 P4** 的 `Ω(θ) = c₀·cos²θ`，由 `cos²θ_i = α_i/c₀` 反解节点角：

| 力 | 节点角 θ_i（rad） | 回代残差 |
|---|---|---|
| 强核 | 0.0000 | 6.158e-16 ✓ |
| 弱核 | 1.0058 | 6.158e-16 ✓ |
| 电磁 | 1.3104 | 6.158e-16 ✓ |
| 引力 | 1.570796（→ π/2） | **7.485e+04 ✗** |

⇒ **四目标在数学上仍被命中，而 P4 形式上未被违反**（常数确实只有 1 个）——**代价是自由度全部转移进了分区节点 θ_i**：θ_i 不是预测出来的，是拟合出来的，且每个节点有 ± 对称支 ⇒ 至少 **8 组等合格解**。
⇒ **结论：「限制常数个数」这条公理无法限制预测力**；真正要约束的是「自由函数 + 自由节点」的**总自由度**（增广 A4 的来源）。

### 3.3 C-05 / T6（guard 抓出，非事后补）：数值两难

回代时发现**引力档残差 7.485e+04**——命中引力强度需要 `|θ − π/2| = √(α_G/c₀) = 2.238e-19` rad，而 π/2 附近双精度分辨率 `ulp = 2⁻⁵² = 2.220e-16`，**所需偏移比最小可表示步长还小 ~1e3 倍** ⇒ acos 只能返回 π/2 的最近浮点，cos 给出 ~1e-17 ⇒ Ω 落到 ~1e-34 而非目标 5.9e-39（**差 7.5e4 倍**）。

⇒ **两难**：(a) 严守 P4 ⇒ 引力档**不可数值实现**；(b) 放宽为自由函数 ⇒ 可精确命中（5.97e-15）但**唯一性彻底丧失**。
⇒ **没有任何一条路同时具备「可实现」与「可预测」**（定理 6）。

> 工程提示：若用单精度或任何固定形状函数实现 Ω，引力档会**静默**偏 4~5 个量级而不报错。

## 四、建设性出口：判死之后仍可落地什么（D 组）

本册不只想判死，也给出**降级后诚实可用的形式**：

**D-01 降级方案**：把 **P2 从「导出」降级为「显式登记的输入假设」**——
`Ω(θ) = c₀·f(θ)`，f 固定（如 cos²θ），c₀ = α_s；θ_i 由观测反解；`sign(Ω)` 在 D_G 上**明写为负**。
代价：D-01 的 FAIL 不消除，但**从「循环论证」降级为「显式假设」**（类比：QED 把 α 作为输入，不宣称导出）。

**D-02 四力样本（诚实：仍只有两类）**：
强核（L = 1e-15）：κ = 7.0711e+14、τ = 7.0711e+14；弱核（L = 1e-18）：κ = −7.0711e+17、τ = 7.0711e+17；
**引力与电磁无限力程 ⇒ κ = τ = 0 ⇒ θ = atan2(0,0) 未定义 ⇒ Ω 无法求值**。
⇒ 即便接受全部降级，**「四组样本」仍只能给出两组**（与元审计 B-07/E-01 同型，本册再次独立确认）。

**D-03 工程陷阱（机器实测）**：`math.atan2(0.0, 0.0)` 返回 **0.0**（IEEE 754 规定值），而 0.0 落在强核扇区 [0, π/2) ⇒ **引力与电磁会被静默归类为强核且不报错**。数学上 atan2(0,0) 无定义，返回值是约定而非推导 ⇒ **实现必须在分区前加原点守卫**。

**D-04 定位**：C-03 的反解用了 4 个观测 ⇒ 5 个自由度对 4 个观测 ⇒ 属于**标定（fit）**，不是**预测（prediction）**；写进代码时必须标注「输入量：α_s, α_2, α(M_Z), α_G(m_p)」。

**D-05 分支①的代码基线**（若要写修复版 Python，按此可规避已知返工点）：
1. 力程用 `L = 1/√(κ²+τ²)`（= c/ω），**不要**用 `(c/f)/√(...)` 或 `c/(f√(...))`（二者恒等且量纲 L²）；
2. 分区边界写**比值/角度式**，禁止 `|κ| < B_i`（量纲非法）；
3. 分区前加**原点守卫**（κ²+τ² < ε 判为「无限力程类」，不走 atan2）；
4. 引力/电磁输出「力程 ∞」而非 (κ,τ) 数值；
5. `sign(Ω)` 作为**显式输入**登记，不写成导出；
6. 强度表统一 μ = M_Z、点名 α_W 口径、声明引力参考质量；
7. 任何 Ω 输出附带「自由度来源」标注（拟合了哪些观测）。
