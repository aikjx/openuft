## 二、诚实边界（必读）

按 openuft 的诚实原则，本书的性质与边界必须写清楚：

1. **理论来源**：本书讲解的是**张祥前提出的统一场论**（民间研究者方案），核心主张包括「空间以光速作圆柱状螺旋运动」
   「物理量几何化」「$P=m(\vec C-\vec v)$ 统一动量方程」「四种力统一于空间运动」等。
2. **非主流、未同行评议**：该体系**不在主流物理学教科书序列内**，其核心方程未被标准模型／广义相对论接纳，
   也没有经同行评议期刊认可的实验验证。书中「光速飞行与飞碟原理」「意识与生命」「反引力场」「人工场扫描技术」
   等章节属**作者设想／假说**，不是已实现的工程技术。
3. **本书未经过 openuft 判据审计**：openuft 对统一理论有独立的六判据 UFT-1…UFT-6（见 `01_整合版目录.md` 与
   第十一编，当前联盟层结论为 **2/6 未达成**）。本书是**科普书稿**，未参与该审计，**不得**因被收录而推断为
   「openuft 认可该理论」；其中与「空间光速螺旋」相关的主题在 openuft 内部另由
   `01_独立体系/S02_空间光速螺旋统一力`、`S12_空间光速螺旋统一体系`、`S15_空间光速螺旋曲率挠率几何统一场论`
   等体系按七阶段生命周期独立处置，与本处科普稿**结论不互通**。
4. **数值未复核**：书中出现的物理常数、公式推导、数量级估算在本次整理中**只做结构与可读性整理，未做逐项复算**。
   任何引用本书数值的研究用途，须回到原始来源核验。
5. **AI 参与的事实**：本书由「本项目」流程生成（见 [原始写作要求.md](./原始写作要求.md)），属于人机协作产物，
   过程文档保留在 `90_版本档案/`，可追溯每一轮改写指令与修复记录。
