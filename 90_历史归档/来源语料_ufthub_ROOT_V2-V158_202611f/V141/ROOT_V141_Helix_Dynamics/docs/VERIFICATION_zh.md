# ROOT V141｜数值结果与认证范围

## 复核方法

- 运行 `python run_all.py`：计算预设的无量纲 ODE 初值问题，生成 `results/coupled_helical_mode.csv` 和 `results/summary.json`，执行所有标准库 unittest + SymPy 符号检查。
- 可选运行 `python tools/independent_check.py`：使用与项目内部 RK4 不同的 SciPy DOP853 进行独立数值求解；输出 `results/independent_integrator_check.json`。
- 可选运行 `python tools/plot.py`：使用 matplotlib 生成结果图。

## 输入与精度

输入（纯模型示例，**不来自观测**）：`k=1, g=1, f=1, lambda=0.6`，初值 `(a, a_dot, theta, theta_dot)=(0.3,0.2,0,0.3)`，积分区间 `[0,80]`，RK4 步长 `0.005`。

- 初始总能量（按 `ℏ/L₀⁴` 归一化）为 `0.11`。
- 总能量最大相对漂移约 `1.54×10⁻¹²`。
- 相位 Noether 荷最大绝对漂移约 `2.35×10⁻¹³`。
- RK4(0.005) 与 DOP853 最终四元状态最大绝对差约 `8.25×10⁻¹¹`。
- RK4(0.0025) 与 DOP853 最终四元状态最大绝对差约 `3.07×10⁻¹²`。
- 能量从相位场流向规范场，或反方向流动，但总能量常数是解析推导结果。

## 何种层次的验证？

上述是**数值算法验证与数学内部一致性验证**。它只能表明我们正确地解出了所设方程，不能确认真实世界存在这样的内部相位耦合、也不能证明所有四种基本相互作用具有相同起源。

## 与标准理论的关系

该模型的内部相位与电磁场耦合采用**类轴子电动力学**的标准形式，已有文献研究了其场方程、能量交换和物理实验约束。它不是 ROOT 发现的新基本方程。模型中的引力项仍是输入的 Einstein–Hilbert 作用量；未从螺旋微观规律得到。
