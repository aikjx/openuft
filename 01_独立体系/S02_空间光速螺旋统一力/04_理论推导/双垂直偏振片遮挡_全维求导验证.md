# 双垂直偏振片遮挡：原因 · 全维求导 · 验证精算

> 接前两份辨析（超光速、偏振片机制）。红线同前：偏振是电动力学标准结论；与「空间光速螺旋」空间轨迹层级不同，偏振片不能验证空间轨迹假设。（注：用户所写「偏正片」即偏振片。）

## 0. 结论速览

- 两个透光轴互相垂直的偏振片（交叉偏振片）能挡住光，因为**第一个把光投影到轴 1，第二个再投影到与轴 1 垂直的轴 2；而沿轴 1 的场在轴 2 上分量为零**，故第二次投影结果为 0。
- 数学上是两次正交投影：`P2·P1 = 0`（零矩阵），任意输入经两者后强度为 0。
- 螺旋对应：第一个把螺旋投影成直线（轴 1），第二个把该直线投影到垂直方向 → 退化为点（零振幅）。

## 1. 原因（cause 链）

1. 光是横电磁波，E 场在二维横截面内，可分解为任意正交基 `(â1, â2)` 的两个分量。
2. 偏振片 = 沿其透光轴的投影（各向异性响应，见《偏振片机制》）：只透过平行轴的分量，垂直分量被阻尼吸收。
3. 第一个偏振片（轴 `â1`）把入射场投影到 `â1`：`E1 = (E·â1) â1`。对未偏振光，各方向平均 ⇒ 强度 `I0/2`，且场完全沿 `â1`。
4. 第二个偏振片（轴 `â2 ⊥ â1`）再投影：`E2 = (E1·â2) â2`。因 `E1 ∥ â1`、`â1·â2 = 0` ⇒ `E1·â2 = 0` ⇒ `E2 = 0`。**全挡。**

## 2. 求导证明：马吕斯 + 正交投影

设第一片轴为 `x`，第二片轴为 `y`（⊥`x`）。

- 入射线偏振与 `x` 轴夹角 `θ`：`E_in = E0 (cosθ, sinθ)`。
  - 经 `Px = diag(1,0)`：`E1 = (E0 cosθ, 0)`，`I1 = I0 cos²θ`。
  - 再经 `Py = diag(0,1)`：`E2 = (0, 0)`，`I2 = 0`。
  - 即 `I2 = I1 cos²(90°) = 0` ✓（马吕斯定律，Δθ = 90°）。
- 矩阵形式：`Py·Px = [[0,0],[0,0]] = 0`，故任意输入经两者后为零。顺序无关（`Px·Py = 0` 同样）。

未偏振输入：`θ` 均匀，`⟨cos²θ⟩ = 1/2` ⇒ `I1 = I0/2`；`I2 = 0`。

## 3. 关键对照：为何不是「再挡一半」而是全挡？

单看第二个偏振片，若输入是未偏振光，它本应透过 1/2。但第一个已把光变成**完全沿 â1 的线偏振**，在 â2 上没有任何分量可透过——所以第二个吸收的是 100%，不是 50%。这正是「投影」而非「固定削减」的本质。

## 4. 验证精算

- **交叉两片（未偏振 `I0`）**：`I1 = I0/2`，`I2 = 0`。遮挡率 100%。
- **交叉两片 + 中间插 45° 第三片（经典三偏振片悖论）**：
  - 未偏振 `I0` → `Px`：`I1 = I0/2`（沿 x）
  - → `P45`（与 x 夹角 45°）：`I2 = I1 cos²45° = I0/4`（沿 45°）
  - → `Py`（与 45° 夹角 45°）：`I3 = I2 cos²45° = I0/8`
  - 即中间插 45° 后反而有 `I0/8` 透过。
  - 若输入本就是沿 x 的线偏振 `I0`：`I1=I0` → `P45`：`I0/2` → `Py`：`I0/4`。
- **Jones 验证交叉**：`Py·Px·[cosθ, sinθ]ᵀ = [0,0]ᵀ`，强度 0，对所有 `θ` 成立。

## 5. 与螺旋模型对接

圆偏振 `E(t) = E0[cosωt·x̂ + sinωt·ŷ]`，矢量尖端画圆（螺旋）。

- `Px`：投影到 `x` ⇒ `E_x = E0 cosωt·x̂`（线偏振 x），螺旋塌缩为直线。
- `Py`（⊥`x`）：再把这条直线投影到 `y` ⇒ 分量恒为 0 ⇒ 点（零）。

即「螺旋 → 直线 → 点」，两次正交投影归零，直观对应「交叉偏振片全挡」。

## 6. 诚实边界（红线）

- 交叉偏振片遮挡是电动力学 / 偏振投影的标准结论，非框架独有。
- 框架「空间光速螺旋」指光子空间轨迹几何模型；偏振作用于场矢量，二者层级不同，偏振片不能验证空间轨迹假设。
- 本分析不扩展框架边界（S02-A4：三重奏非万有理论，不解释引力、不生成常数、不完成四力统一）。

## 7. 边界澄清：本分析是否「证明空间螺旋 / 出光速」

> 针对追问：双垂直偏振片分析是否证明了「光做螺旋空间运动」，是否由此「出光速」。

- **未证明空间螺旋。** 全部推导（马吕斯、Jones、投影链）作用在**场矢量 E** 上，是标准偏振物理。结论「螺旋 → 直线 → 点」里的「螺旋」指圆偏振 **E(t) 端点**在二维场空间的圆周轨迹，属**场矢量空间**的数学描述，不是光子在三维空间里绕轴前进的真实轨迹。因此该现象既不支持、也不否定框架的「空间螺旋」假设——标准电磁解释已完整自洽。
- **未出光速。** 旋转的是场矢量而非实物点。波前始终以 `c` 传播；E 端点画圆是场振荡的数学图像，没有实物以 `ωE0` 在空间中运动，更无超光速。
- **「一边螺旋运动」作为真实空间轨迹仍是假设。** 若把框架的「光子一边前进一边绕轴转」当真实空间运动，按《超光速辨析》：螺距≈波长 `λ`、半径量级 `λ` 时，横向「速度」≈`2πc`，已越过 `c`，正是其不能直接被视为真实空间运动的症结。本分析既未证明、也未否定该假设。
- **红线重申。** 本分析不得据偏振结果声称「证明了空间螺旋」或「出光速」——那会越界 S02-A4（三重奏非万有理论，不生成常数、不完成统一）。偏振片全挡 = 场矢量正交投影归零，仅此而已。

## 8. 若「光速空间螺旋」为真，是否也会复现偏振效果？

> 用户追问：若光真做空间螺旋运动（绕轴前进），是否也会出现偏振光的效果（偏振片透光、马吕斯、交叉遮挡）？

- **先区分两种螺旋：**
  - **A. 场矢量螺旋（标准）**：`E(t)` 在横截面内旋转 = 圆偏振。这本身就是偏振现象。
  - **B. 空间轨迹螺旋（框架假设）**：单光子位置 `r(t) = (R cosωt, R sinωt, ct)` 绕轴前进。
- **B 要产生「偏振效果」，必须规定偏振片对光子的横向速度（或位置）矢量做投影：**
  - *按横向位置选择*：螺旋光子在偏振片平面上的横截位置随时间画圆，任一时刻只是一个点，点本身没有「方向」。若偏振片只放「落在轴 â 上的那部分点」，其透射律由通带宽度决定，**不会自然给出 `cos²θ` 马吕斯律**，且交叉两片不会互相阻断。→ **不能复现偏振。**
  - *按横向速度方向投影到 â*：单光子透射分量 ∝ `cos²(横向速度方向与 â 夹角)`。过第一片后横向速度对齐 `â1`（线偏振）；第二片 `â2 ⊥ â1` → 投影为 0。**复现马吕斯律与交叉遮挡。**
- **结论：**
  - B 只有在「假定偏振片作用于横向速度矢量」时，才复现偏振效果；而此时**数学与标准偏振完全同构**（仅把 E 矢量换成横向速度矢量），是同一套向量投影规则的重新命名。
  - 因此它**不独立解释/导出偏振**，也不产生超出标准 EM 的新预言（S02-A4 红线：非竞争理论）。
  - 偏振片实验**无法区分 A 与 B**（结果相同），故不能用来「证明」空间螺旋——与第 7 节边界一致。
  - 且若把 B 当字面真实空间运动（螺距≈`λ`、半径量级 `λ`），横向速度≈`2πc` 已超 `c`（见超光速辨析），字面解释仍不可取。
- **红线：** 空间螺旋可「重述」偏振数学，但既不证实自身、也不取代标准偏振理论。偏振现象是场矢量投影，空间轨迹螺旋是其几何重述，二者层级不同、不可互相证明。
