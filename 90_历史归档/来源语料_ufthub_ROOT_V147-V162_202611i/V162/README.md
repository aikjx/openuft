# ROOT V162 非线性光速流交叉与束缚审计

## 目标及边界
仅 c=1；ħ、G 独立有量纲。[ħ]=ML，[G]=L/M。选取 [E]=[B]=L^-2，S=ħ∫L d⁴x；物理应力为 ħ 乘以下归一化应力。a,b 的量纲 L⁴，数值例采用 L0 归一化，不是 QED 的实际强度。G 不参与此次平直时空仿真。这里是已知非线性电动力学的限定模型审计，不是四力统一证明。

## 求导及证明
X=(E²−B²)/2，Y=E·B，L=X+aX²+bY²。D=∂L/∂E=(1+2aX)E+2bYB，H=−∂L/∂B=(1+2aX)B−2bYE。无源方程 B_t=−curl E,D_t=curl H。单个光滑 null Maxwell 解 X=Y=0 时也是这个模型的解；这不等于任意两束叠加仍是解。

取 n1=z,n2=(sinθ,0,cosθ)，E1=A1 x，E2=A2(cosψ cosθ,sinψ,−cosψ sinθ)，Bi=ni×Ei。直接展开得 X=−A1A2(1−cosθ)cosψ，Y=A1A2(1−cosθ)sinψ。L_int=A1²A2²(1−cosθ)²(a cos²ψ+b sin²ψ)。这是给定叠加场上的局部作用量密度，不是两物体相互作用势或真实动力学叠加解。

取 u=(E²+B²)/2，X²+Y²≤u²（Cauchy-Schwarz）。采用 −+++ 度规，T^μ_μ=4(L−XL_X−YL_Y)=−4(aX²+bY²)，ρ=E·D−L=u+a(2Xu+X²)+bY²。故 ΣT^ii=ρ+T^μ_μ=u+2aXu−3aX²−3bY²。若 a,b≥0，q=max(a,b)，则 ΣT^ii≥u−5qu²。若所有位置 qu<1/5，除零场外严格为正，不能满足完整静态孤立系统在平直时空的 Laue 条件 ∫ΣT^ii=0（假设局部守恒且边界项消失）。同一不等式配合二阶矩 I''=2∫ΣT^ii 可用于一致弱场界的动态扩散论证；本版不假设强场、引力或外界应力。不是所有 NLED 的普适不可能定理。

恒定 B0 沿 z，微扰传播沿 x：线性化 ε=(1−aB0²)I+2b B0⊗B0，逆磁导 μ^-1=(1−aB0²)I−2a B0⊗B0。故 v_perp²=(1−3aB0²)/(1−aB0²)，v_parallel²=(1−aB0²)/(1−aB0²+2bB0²)。这是低阶模型的局部特征速度，不是完整 UV 理论的前沿速度。纯磁背景空间应力迹为 u(1−5au)，开始非正需 aB0²≥0.4；但在常规正电动能分支 aB0²<1，横向模式从 aB0²>1/3 已出现 v²<0。不能以截断强场的负应力直接宣称稳定束缚。

## 数值验证
1D 周期域 [-20,20)，E_y、B_z，Y=0。D=(1+a(E²−B²))E，H=(1+a(E²−B²))B。D_t=−H_x,B_t=−E_x。初始 E=E_++E_−，B=E_+−E_−，E_±=0.5 exp[−(x±5)²/(2*1.2²)]。FFT 空间求导，RK4 时间积分，Newton 反解 E，终止 t=12。三种网格，a=0、0.2；b 在此偏振子空间无贡献。监控能量、总动量、积分通量、构成关系和弱场条件；不包含 3D 局部束缚或真实实验。边界周期化且脉冲远离边界；未使用去混叠滤波，网格收敛支持本例但不能替代通用稳定性分析。

## QED 基准
λe=ħ/m_e，a_QED=(8α²/45)λe⁴,b_QED=(14α²/45)λe⁴（最低阶、低能弱场）。低能非偏振光子散射总截面 σ=973/(10125π) α⁴ (Eγ/m_e)^6 λe²，Eγ 是质心系单光子能量。用 CODATA 2022 常数作为输入，未独立导出。ATLAS 2019 光光散射观测在高能重离子碰撞中，不能拿其 fiducial 截面直接与光学低能公式比较。实验支持 QED 光光相互作用，不验证 ROOT 四力统一。
