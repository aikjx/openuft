## 一、M1 ↔ M4：不相容与语义分叉

机器求导：ω = c√(κ²+τ²) 对 k 的数值偏导 = **0.000e+00**。

⇒ 满足 M1 就**无色散**（无传播、无因果结构，第十轮 W4 已判 FAIL）；满足 M4 就**不再是「ω 由几何决定」**。

**N-02 三条出路（每条都有代价）**：

| 出路 | 后果 |
|---|---|
| **(a) 保持 κ,τ 为几何量** | 接受无色散 ⇒ **放弃 M4** ⇒ 体系不能有传播子 |
| **(b) 把 κ,τ 改释为「模态量」**（κ = κ(k)） | 可满足 M4，但这是**重新定义基本量**＝引入一条新假设，且 κ²+τ²=(ω/v)² 等既有关系需重标 |
| **(c) 放弃 M1** | 体系当前的运动学核心式失去地位 |

⇒ **这是攻 W2 的前置决策**，不是实现细节。

**N-03（正面）**：M3 是唯一已验证与 M1 相容的判据（v_obs/c = τ/√(κ²+τ²) < 1 在 κ≠0 时恒成立），且第十二轮已证它**不依赖度规选择** ⇒ **体系最稳固的一条**。

## 二、M1 ∧ M2 ⇒ 短程失效边界 r ≥ 0.7071 r_s

**推导**（全部用体系自己的式子）：
- M2 要求势 ∝ 1/r；体系 `E = (ℏc/2)(κ+τ)` ⇒ **|κ+τ| = A/r**，A = 2GMm/(ℏc)
- M1 要求 **κ²+τ² = Ω₀²**；体系自有 `m = ℏΩ₀/c` ⇒ Ω₀ = mc/ℏ
- κ,τ 为实数需判别式 **Δ = 2Ω₀² − (κ+τ)² ≥ 0** ⇒ r ≥ A/(√2·Ω₀) = **√2·GM/c²**

**机器验证**（太阳，M = 1.98892e30 kg）：

| 量 | 值 |
|---|---|
| r_min = √2·GM/c² | **2088.8 m** |
| r_s = 2GM/c² | 2954.0 m |
| 比值 | **0.7071 = √2/2** |
| 判别式 @ r = 0.5 r_min | **−4.024e+25**（负 ⇒ 无实数 (κ,τ)） |
| 判别式 @ r = 2 r_min | **+1.006e+25**（正 ⇒ 有解） |

⇒ **若坚持 M1 与 M2 同时成立，体系在 r < 0.7071 r_s 无解。**

**N-06（不夸大）**：这条边界由**体系自己的两条判据**推出，不是外部输入；它落在 Schwarzschild 半径同量级，与「强场/黑洞内部需要新物理」方向一致。
但**不宣称**它是引力理论的正确边界——它只说明 M1∧M2 在该区域无解；这可以是体系缺陷，也可以是该区域本就超出有效域，**二者需实验或更完整理论区分，本册不判定**。

**N-07（对攻 W2 的后果）**：任何候选作用量若要同时满足 M1 与 M2，**必然继承这条边界** ⇒ 建议把它作为**第 6 条判据 M6**：「候选必须显式声明其有效域是否覆盖 r < 0.7071 r_s」。
