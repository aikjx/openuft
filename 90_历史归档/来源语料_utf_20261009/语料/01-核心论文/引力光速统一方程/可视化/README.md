# 统一场论研究项目导航文档

## 项目概述
本项目是关于张祥前统一场论的研究资料整理与代码实现，包含了核心论文、分析推导、验证脚本及相关文档。

## 目录结构

```
统一场论研究项目/
├── 00-项目文档/          # 项目相关文档目录
│   ├── 01-验证报告/      # 数值验证和实验报告
│   ├── 02-修复文档/      # 代码修复和问题解决文档
│   ├── 03-优化方案/      # 性能优化和结构改进方案
│   ├── 04-总结报告/      # 项目总结和最终报告
│   └── 05-图表资源/      # 文档中使用的图表和可视化资源
├── 01-核心论文/          # 统一场论核心理论论文
├── 11-统一场论公式论文集/# 公式推导和验证论文集
└── README.md             # 项目导航文档（当前文件）
```

## 文件组织说明

### 项目文档（00-项目文档）
- **总结报告**：包含最终优化完成报告和目录结构优化方案
- **验证报告**：包含数值计算验证结果和实验数据
- **其他子目录**：根据需要存放相应类型的文档

### 核心文件说明
- **连接常数r_k的完整分析与推导.md**：关于统一场论中连接常数的详细推导
- **水星进动推导验证.py**：使用Python进行水星进动计算验证的脚本
- **引力光速统一方程分析报告.html**：引力与光速统一方程的可视化分析报告
- **日志文件**：包含公式转换和验证过程的记录

## 使用指南
1. 首先阅读核心论文目录下的基础理论文档
2. 参考公式推导和验证资料理解数学模型
3. 运行验证脚本查看计算结果
4. 查阅总结报告了解项目整体情况

## 注意事项
- 本项目文档结构持续优化中
- 所有文件路径均为相对路径
- 代码验证需要Python环境支持
