### 明确的局限

1. 只检验当前平坦背景与指定类型的 Boost；未完成任意曲率背景或完整非线性计算。
2. Maxwell 与引力作用量是**外部输入**，没有从单一微观螺旋运动推出。
3. 256 组随机测验不证明所有输入情况下程序都正确；符号校验仅覆盖明确列出的数学恒等式。
4. 仍未生成标准模型强弱相互作用、手征谱、耦合常数、`G`、`ħ`、`α` 的第一性原理预测。
5. 没有对未参与标定的地月数据、引力波数据或粒子实验做 ROOT 新预测的观测拟合。
