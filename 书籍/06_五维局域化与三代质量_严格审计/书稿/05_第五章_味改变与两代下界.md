# 第五章 · 味改变与两代下界

## 5.1 为什么要算味改变

上一章的 `S` 描述的是"同一族粒子与 KK 模的耦合强度"。它本身不是观测量。要把它接上实验，必须走味改变：如果三代在第五维的密度分布不同，那么同一个规范 KK 模与三代的耦合就不完全同比例，于是**味道会变**。

味改变的有效强度，是把 `S` 用混合矩阵的权重组合起来：

$$\tag{5.1} Q_{\alpha\beta}=\sum_{i,j}w_iw_j^*S_{ij},\qquad w_i=U^*_{i\alpha}U_{i\beta}\ (\alpha\ne\beta).$$

## 5.2 一个更省的办法

直接用 (5.1) 要先把 `S` 算出来（虽然第四章已把它变成一维积分，但仍要三次积分＋外积）。有一个更直接的形式：

酉性要求 `Σ_iw_i=0`（因为 `Σ_i|U_{iα}|²=1` 与 `Σ_i|U_{iβ}|²=1`，交叉项之和对角为零时，非对角列正交）。于是

$$\tag{5.2} \boxed{\;Q_{\alpha\beta}=\pi^2\int_0^1\Bigl|\sum_iw_iF_i(t)\Bigr|^2dt\;} .$$

推导：把 `Σw_i=0` 代入 `Σw_i a_n^{(i)}` 的分部积分式 (4.6)，常数项 `t` 被 `Σw_i=0` 消掉，只剩 `H_i`；再用 Parseval。

(5.2) 有三重身份：

| 身份 | 内容 |
|---|---|
| 非负性证明 | 被积函数是模方，积分必 $\ge0$ |
| 计算法 | 一次一维积分，不必截断数千模 |
| 结构判据 | 若 `Σw_iF_i≡0`，则 `Q=0`；这只在 `F_i` 线性相关时可能 |

机核：矩阵／20 万求和／一维积分三法最大差 `4.86e-17`（`S5c`）。

取 V44 的示范角 `(θ₁₂,θ₂₃,θ₁₃)=(0.20,0.12,0.03)`：

| 量 | 数值 |
|---|---|
| `Q_eμ` | `0.000683979593` |
| `C_{eμee}`（四轻子算符系数） | `0.023475105342` |
| 最小谱塔本征值 | `0.00023210914` |

**`[模型]`**：示范角是演示值，不是实验拟合值。第五章起的所有 `Q` 都带这个前提。

## 5.3 两代下界：一条真正的严格结果

这一节是全书**唯一的条件性严格下界**，值得慢慢写。

设定：两代左手夸克双重态具有相同的局域化基底，但上型与下型夸克的质量矩阵分别通过角度 `α` 与 `α+θ` 对角化。`θ` 是两代 CKM 混合角。

先定义**几何差**——两个密度剖面之间的"全谱塔距离"：

$$\tag{5.3} D_{12}=\sum_{n=1}^{\infty}\frac{|a_n(z_1)-a_n(z_2)|^2}{n^2}=\pi^2\int_0^1|F_{z_1}(t)-F_{z_2}(t)|^2dt .$$

等号右边用 (4.7) 的线性性：`H_1−H_2=F_1−F_2`（`t` 相消）。

于是上型、下型的非对角平方和：

$$\tag{5.4} Q_u=\frac{D_{12}}4\sin^2(2\alpha),\qquad Q_d=\frac{D_{12}}4\sin^2(2\alpha+2\theta).$$

对 `α` 求最小值。用 `sin²x=(1−cos2x)/2`，两项之和为

$$\frac{D_{12}}8\Bigl[2-\cos(2\alpha)-\cos(2\alpha+2\theta)\Bigr]=\frac{D_{12}}4\Bigl[1-\cos2\theta\cdot\cos(2\alpha+\theta)\cdot\ldots\Bigr]$$

更简单：`sin²x+sin²y=1−cos(x+y)cos(x−y)`。取 `x=2α`、`y=2α+2θ`：

$$\tag{5.5} \boxed{\;\min_\alpha(Q_u+Q_d)=\frac{D_{12}}4\bigl(1-|\cos2\theta|\bigr)\;} .$$

当 `|θ|≤π/4`，`cos2θ≥0`，于是 `1−cos2θ=2sin²θ`，得

$$\tag{5.6} \boxed{\;Q_u+Q_d\ge\frac{D_{12}}2\sin^2\theta\;} .$$

机核：`D₁₂=0.2852585282`（`S6a`）；取 `sinθ=0.225` 时解析下界 `0.0072206065`，1e6 角度扫描同值（差 `5.69e-14`，`S6b`）。

## 5.4 绝对值是内容，不是书写习惯

这是本章最值得记住的一条。θ=0.9 rad（`>π/4`）时：

| 口径 | 值 |
|---|---|
| 1e6 角度扫描最小值 | `0.0551117983` |
| `D₁₂(1−|cos2θ|)/4` | `0.0551117983` ✔ |
| `D₁₂(1−cos2θ)/4`（误用） | `0.0875174658` ✘ |

误用版本**高于真下界 59%**。这意味着什么？下界的作用是"排除不可行域"：若真下界是 `0.055`，则实验上限若为 `0.07`，该点在可行域内；若错用 `0.0875`，则被判为"已排除"。**一个写错的绝对值，会把可行域判成不可行域，然后宣布模型被实验杀死——而它其实还活着。**

$$\boxed{\text{绝对值项是这条判据正确性的一部分，不是书写习惯。}}$$

来料写对了这一点，但没说明它为什么必需。本书补上这句。

## 5.5 一条必须写清的实验边界

`Q_u,Q_d` 已除去共同的四维规范耦合，只作 `1/n²` 加权。它**不是** `K`、`D`、`B` 介子混合或稀有衰变的下界。

要把它换成实验约束，至少还要五样东西：

| 缺项 | 作用 |
|---|---|
| 规范耦合 `g₄` | 把无量纲 `Q` 换成物理振幅 |
| KK 质量谱 `M_n` | 决定每个模的传播子压制 |
| 左右手算符结构 | 决定是 `(V−A)(V−A)` 还是别的 |
| 强子矩阵元 | 把夸克级算符换成介子量 |
| 重整化群演化 | 从 KK 能标跑到低能 |

本节到此为止。**不代换、不暗示"已在实验允许范围内"。**

## 5.6 与第四章的关系：同一件事的两个读法

`S` 是"族空间矩阵"，`Q` 是"同一矩阵的味空间投影"。二者的关系：

$$Q_{\alpha\beta}=w^\dagger Sw .$$

第四章的 `(4.7)` 与本章的 `(5.2)` 是同一个 Parseval 恒等式在两个基底上的写法。这就是为什么第五章的所有机核都与第四章同级（`1e-17`）——它们本来就是同一个积分。

## 5.8 一个诚实的注脚

(5.6) 是**条件性**严格：它成立的前提是"两代左手夸克共享局域化基底，上/下型仅差一个角度"。这个前提在任何具体模型里都要单独验证。本书把它列在 `[恒等]` 类，但请读者记住：**恒等式的前提不是恒等式**。

这也是本书把"三条恒等式"与"三条障碍"分开写的原因——前者是数学，后者是结构；而所有"条件性严格"都夹在两者之间。
