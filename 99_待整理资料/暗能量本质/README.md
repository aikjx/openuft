# 暗能量本质

> 解释宇宙加速膨胀的物理机制——暗能量的本质是宇宙学常数、动力学场还是引力修正。

## 问题定义

1998 年 Ia 型超新星观测发现宇宙加速膨胀，归因于"暗能量"，占宇宙能量密度约 68%。核心候选：
1. **宇宙学常数 $\Lambda$**：真空能，状态方程 $w = -1$
2. **动力学暗能量**：quintessence 标量场，$w$ 随时间演化
3. **修改引力**：大尺度修改 GR，无需暗能量
4. **全息暗能量**：全息原理导出的有效暗能量

**核心问题**：暗能量是常数还是动力学？其微观起源是什么？

## 当前进展（2020–2026）

| 观测 | 结果 |
|---|---|
| Planck 2018 | $\Omega_\Lambda = 0.6889 \pm 0.0056$，$w = -1.03 \pm 0.03$ |
| DESI 2024 | 重子声学振荡测量，支持 $\Lambda$CDM |
| Pantheon+ 2022 | 超新星数据，$w$ 与 $-1$ 一致 |
| 哈勃张力 | $H_0$ 本地测量（73.0 km/s/Mpc）与 CMB 推断（67.6）冲突 |

**理论问题**：
- **宇宙学常数问题**：量子场论真空能预言比观测大 $10^{120}$ 倍
- **巧合问题**：为何暗能量在当前时期主导？
- **哈勃张力**：可能暗示新物理或系统误差

## 证伪条件

- 若 $w$ 被精确测量为 $-1$，则宇宙学常数获得支持
- 若 $w$ 随时间演化被观测，则动力学暗能量获得支持
- 若哈勃张力被新物理解释，则暗能量模型需修正
- 若引力修正方案能解释所有观测，则暗能量假设被削弱
