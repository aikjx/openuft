# 历史工作摘要：ROOT V76–V86 → V87 的承接

- V76：量子场、磁能、电磁交叉能和核结合能进入总应力能量张量；防双次计数。
- V77：`G=2Z/c` 是 Z 定义后的恒等式；Planck 长度、引力半径与量子尺度彼此关联，但不独立给出 G。
- V78–V79：时变电磁场的 f/2f 频率选择、手性耦合的奇偶性假设；磁场能量的引力源不意味着 G 改变。
- V80–V81：微观物质与磁星/行星的跨尺度质量能量、紧致度与磁能评估；仍缺独立新引力证据。
- V82–V84：移动源质量的真实引力调制、双传感器与多距离实验、有限程第五力和仪器伪差。
- V85：径向形状 Q、星球×材料差异矩阵与 GM 不可辨识性。
- V86：地球 J2 假阳性、Eötvös 矩阵归一化修复、相关噪声与有限源尺寸建模。
- **V87 本轮**：在上述严谨实验框架上，首次系统并列证明 Einstein→Newton 与 curved KG→Schrödinger 两条低能极限，明确量子相位—经典 g—GR 钟差的理论桥梁及 `G,M` 雅可比退化。

历史详本在 `archive/ROOT_V86.zip`，用于追溯，不代表历史每项候选理论都成立。
