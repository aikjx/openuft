## 二 四条承重裁定（详）

### B04 螺旋度规是平直的（结构性前提不成立）

机器（有限差分 Riemann，h=1e-4，c=1 自然单位）：

```
max|R^a_bcd| (螺旋度规)      = 4.184269443262446e-08      ← 数值零
max|R^a_bcd| (阳性对照度规)  = 0.2999999999998468          ← 非零
h=1e-5 复算螺旋度规           = 仍为数值零（G7-1/G7-2）
```

解析上这是必然：变换 `(r=ρ, φ=χ+βζ, z=ζ)` 是平直空间的**微分同胚**，曲率是坐标无关量。来料 §1.3 注意到 `det(g)` 与平直柱坐标相同，但只把它当作"体积元不变"的提示（见 B06），**未追问曲率**。

⇒ 结论：**「螺旋空间」不是弯曲空间**。因此"光在螺旋空间中如何运动"这一问题在来料的框架内等价于"光在平直空间的某个非惯性坐标下如何运动"——**所有所谓螺旋效应必须是坐标效应或场效应，不可能来自曲率**。来料情形 B 的"坐标旋转是假象"已触及此点，但 §4/§5/§6 全程按"弯曲空间"处理。

**边界（B05）**：该坐标变换还只在**局部**成立——χ 在绕轴一周后不单值（φ 的 2π 周期性无法在 χ 上实现），故"螺旋空间"连全局坐标都不是。

### C04 情形 C（恒定 ρ 的螺旋轨道）不是测地线

来料**附录 A 自己**推出 ρ 分量的测地线方程：

```
ρ̈ − ρ(χ̇+βζ̇)² = 0 ，代入 χ̇+βζ̇ = ℓ/ρ²  ⇒  ρ̈ = ℓ²/ρ³
```

而情形 C 的前提是 `ρ̇ = 0`（ρ 为常数）⇒ `ρ̈ = 0` ⇒ 由上式要求 `ℓ = 0`，与 `ℓ ≠ 0` 矛盾。

机器：ρ=0.7、ℓ=0.91 时测地线方程给出 `ρ̈ = 2.414285714285715`，情形 C 假设值 `0`，差 `2.4142857`（O(1)，非数值精度问题）。

**独立反证（C05）**：从同一组 (E, ℓ, P) 出发 RK4 积分平直空间零测地线（4000 步），轨迹变换到笛卡尔后相对最佳直线的最大垂直偏差

```
自由零测地线   3.486127789890094e-14     ← 直线
阳性对照（加恒力）0.046633623838641294    ← 非直线
```

且 ρ 从 0.7 立刻偏离（ρ̈=ℓ²/ρ³>0），从不保持常数。⇒ 真实零测地线在柱坐标下的形态正是来料**情形 E 的散射解**，不是情形 C 的螺旋。

⇒ 情形 C 以及建立其上的"轴向速度减小/增大（C2/C3）"、"临界束缚态 C4"、"反向传播 C5"、"等效质量"、"截止频率"都与自由测地线不相容。**唯一能救情形 C 的方式是声明它是一个受约束系统**（例如介质/波导中的有效世界线），来料未作此声明。

### E02/E03 Maxwell：单分量 ansatz 不是模式，且推导漏一个交叉项

**E02（根因定位）**：在 `ν = χ` 分量里，`F^{ζχ} = g^{ζα}g^{χβ}F_{αβ}` 的 (α,β) 双和有两项：

```
(α,β)=(ζ,χ):  g^{ζζ}g^{χχ}F_{ζχ} = (1+β²ρ²)/ρ² · F_{ζχ}
(α,β)=(χ,ζ):  g^{ζχ}g^{χζ}F_{χζ} = (−β)(−β)(−F_{ζχ}) = −β² F_{ζχ}
合并               ⇒  F_{ζχ}/ρ²
```

来料只保留第一项（并在同处保留了恒为零的 `F_{χχ}` 项），于是其"部分和"比完整值多一个 `(1+β²ρ²)` 因子。

机器（探针场取来料 §5.3 的 χ 单分量模式，ρ=0.7、β=1/1.3）：

```
部分和/完整和 = 1.2899408284023668
(1+β²ρ²)     = 1.2899408284023668      ← 逐位一致
```

这正是 §5.3 色散式中 `√(1+β²ρ²)` 的**唯一来源**。补回漏项后 `F^{ζχ} = F_{ζχ}/ρ²`，与平直柱坐标（β=0）形式一致。

**E03（更强）**：即使不管漏项，来料的单分量 ansatz **本身就不是 Maxwell 的解**。机器（四阶中心差分，残差按 k²|A| 归一）：

```
A_χ(ζ,t) 模式、ω = c k（正确零条件值）     归一化残差 0.5384615384568875
A_χ(ζ,t) 模式、ω = c k/√(1+β²ρ²)（来料值） 归一化残差 0.4740998230315882
A_ρ(ζ,t) 模式、ω = c k                     归一化残差 O(1)
```

根因：在曲线坐标下 `A_ρ / A_χ` 是**位置相关基**上的分量，单一分量的常数振幅不是固定偏振的平面波。真平面波经同一坐标变换后 `A_ζ = βA_χ ≠ 0` 且分量含 ρ、χ 依赖（见 E05）。

### E04/E05 色散与自身零条件矛盾；正解是 ω = c k 且两偏振简并

**E04**：对模式 `k_μ = (−ω, 0, 0, k)`（χ 方向波数为零，故 g^{χζ} 不参与）计算 `g^{μν}k_μk_ν = −ω²/c² + k²`，置零即得 `ω = c k`。机器：

```
k = 2.0
ω（几何零条件）= 2.0
ω（来料 §5.3） = 1.7609421998443504
相对差         = 0.1195289…  = 1 − 1/√(1+β²ρ²)
```

**E05（正解）**：构造真平直空间平面波 `A_x = exp(i(kz−ωt))`（或 A_y），经坐标变换把协变分量搬到螺旋坐标（`A_ρ = A_x cosφ`、`A_χ = −A_x ρ sinφ`、`A_ζ = −βA_x ρ sinφ`），用四阶中心差分算四条 `∂_μ(√−g F^{μν})`：

```
x 偏振归一化残差  4.038724528594848e-12
y 偏振归一化残差  1.9778738426073034e-11
阳性对照（ω 偏 1e-3）0.0014007000149359738
```

⇒ 两偏振**同速**（ω=ck）⇒ **真空无螺旋双折射、无真空旋光性**；这与 B04（度规平直）+ 协变 Maxwell 互为印证。§5.4 的"真空旋光性"、§6.2 的"手征质量分裂"、§6.4 的"截止频率"一并作废。
