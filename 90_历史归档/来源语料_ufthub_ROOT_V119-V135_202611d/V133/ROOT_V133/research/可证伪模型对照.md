# ROOT V133｜可证伪性、缺口与最小实验判据

## 1. 预注册模型 M0：单一、物种无关的 S¹ 内部转子

固定所有物种共用 `(m0,I,λ)` 且电荷均为 `q=±q1`。由于 `q_n=nλℏ`，电子、μ 子必须对应 `|n|=1`，因此模型预测：

\[m_\mu=m_e=m_0+\hbar^2/(2I).\]

CODATA 2022：`m_mu / m_e = 206.7682827(46)`。因此该**最小普适单转子假设与测量不符**。容许物种特定 `m0` 或 `I` 虽可避免矛盾，却重新引入自由参数，并不解释质量谱。

## 2. 预注册模型 M1：同一转子的电荷—质量塔

\[q_n=nq_1,\quad m_n-m_0=n^2(m_1-m_0).\]

一旦选定 `I,m0,λ`，这个塔的关系完全固定。但在已知粒子谱中不能把它无条件视为现存粒子的来源；只可作为待检验的有条件理论预言。

## 3. 精细结构常数缺乏唯一性

\[\alpha_1=\lambda^2\hbar/(4\pi\varepsilon_0).\]

同一几何 `S¹`，任意 `λ>0` 允许任意正 `α_1`。这构成一族连续反例，严格证明“单靠圆周拓扑与相位周期性”不足以唯一决定 `α`。

此外，低能 `α(0)^{-1}=137.035999177(21)` 与特定 MS-bar 定义的 `\hat α^{(5)}(M_Z²)^{-1}≈127.930(8)` 不相同。任何普适等式必须注明重整化能标与方案；不能将一个固定几何角无解释地匹配所有实验能标。

## 4. 光速三维螺旋的狭义相对论障碍

在惯性参考系中 `R²ω²+u²=1` 的**真实三维**轨迹为零间隔轨迹，不能作为有静质量粒子的类时世界线。沿轴 boost 下 `u'=(u−β)/(1−βu)`，因此 `u=α` 不是 Lorentz 不变量。内部二维纤维作为独立变量可绕开此简单反例，但不是自动验证了 ROOT 公设。

## 5. 量子自旋和规范群

周期性标量角只产生整数 `n`，不能直接给出四维 spin-1/2 的双值表示。SO(2) 与 U(1) 局部同构，却不等于 SU(2) 或 SU(3)；后者需要非 Abelian 曲率、手征谱和量子反常消除。

## 7. 防止伪突破的原则

每个“闭环”都须区分定义、数学定理、从额外公设推导的结论和经过实验证实的结论。数值拟合 `α` 不是预测 `α`；同一模型恒等式的自动测试不是自然界验证。引用已发表的 Hasimoto、Kaluza–Klein 与量子环模型时须标明其历史来源。
