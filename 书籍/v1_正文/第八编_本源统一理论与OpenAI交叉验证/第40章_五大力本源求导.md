## 40.1 统一结论（本源定义）

TUFT 公理基底（第 39 章）推出如下统一主张 [B]：

> **不存在"四种基本力"**。宇宙只有一类底层实体——真空光速螺旋流；以及它在流形联络上的两种几何相互作用模式：
>
> - **① 径向曲率伸缩 → 势能力**（做功、保守、$F=-\nabla U$）：电场力、引力、弹性力；
> - **② 环向挠率涡旋横向耦合 → 横向力**（不做功、$F\perp\boldsymbol v$）：磁场力、惯性力、流体涡力（科里奥利力）。
>
> 强/弱相互作用是上述两类在短程拓扑束缚尺度上的特殊表现 [B]；其定量推导 [C] 待建。

**诚实标注**：此节为 [B] 统一主张，**不是** [A] 物理结论。标准模型仍以 SU(3)×SU(2)×U(1) 规范群描述强、弱、电磁三种相互作用，引力由 GR 描述——TUFT 的"两类几何相互作用"是对这四类力的**候选几何重构**，不替代标准模型与 GR 的实验有效性。

## 40.2 惯性力（本源方程 + 求导）

### 40.2.1 本源定义

TUFT 诠释 [B]：惯性力是"螺旋结相对背景螺旋流场平移时的几何阻抗"——流形对**局域扰动平移**的反作用，对应 NS 方程中 $(\boldsymbol u\cdot\nabla)\boldsymbol\omega$ 项在拉格朗日观点下的宏观投影。

### 40.2.2 本源方程（[A] 牛顿第二定律）

$$F_{\text{惯}} = \frac{d\boldsymbol p}{dt} = m\frac{d\boldsymbol v}{dt} = m\boldsymbol a \tag{40.1}$$

**严格求导链**：

1. [A] 动量定义 $\boldsymbol p = m\boldsymbol v$；
2. [A] 对时间求导 $d\boldsymbol p/dt = m\,d\boldsymbol v/dt + \boldsymbol v\,dm/dt$；
3. [A] 封闭系统质量守恒 $dm/dt=0$，故 $F=ma$。

**机电对偶**（承接第 39 章 39.4）：$m\,dv/dt \leftrightarrow L\,dI/dt$，即"电感阻碍电流变化"在力学侧的对应物。[A] 形式同构；[B] TUFT 诠释为"流形对螺旋流平移的阻抗"。

### 40.2.3 与 S02 对照（[B]）

S02 统一力方程：$F=dP/dt$，$P=m(c-v)$（S02-A1/A2，postulates §2）。展开：

$$F = \frac{d}{dt}[m(c-v)] = -m\frac{dv}{dt}\quad(m=\text{const})$$

即 S02 的 $P=m(c-v)$ 与标准 $p=mv$ 仅差常数项 $mc$，对时间求导后**动力学方程完全一致**。TUFT 采纳 $F=dp/dt$ 形式 [B]，但不保留 S02 的 $c-v$ 项——按 S02 postulates §3 "S02 不主张内部运动恒等于 c"，TUFT 与 S02 在此处结构同源、本体不同，**不得互相认证**。

### 40.2.4 量纲与数值验证

- 量纲：$[F]=[M][L]/[T]^2=\ell^{-1}\cdot\ell/\ell^2=\ell^{-2}$；$[m]=\ell^{-1}$；$[a]=\ell^{-2}/\ell^{-1}=\ell^{-1}$。[A] 自洽。
- 数值（[A] 常识值）：$m=1\,\mathrm{kg}$，$a=9.8\,\mathrm{m/s^2}$（地球表面重力加速度，作惯性力测度）→ $F=9.8\,\mathrm{N}$。

## 40.3 弹性 / 保守势能力（本源方程 + 求导）

### 40.3.1 本源定义

TUFT 诠释 [B]：弹性力是螺旋流在径向被拉伸后、流形曲率恢复平衡时的"回弹"——与电场力同属"径向曲率伸缩"类，二者共享 $F=-\nabla U$ 的保守力结构。

### 40.3.2 本源方程（[A] 胡克定律）

$$U = \tfrac12 k(\Delta x)^2,\qquad F = -\frac{dU}{dx} = -k\Delta x \tag{40.2}$$

**严格求导链**：

1. [A] 势能定义 $U(x)=\tfrac12 k x^2$；
2. [A] 求导 $dU/dx = kx$；
3. [A] 保守力 $F = -dU/dx = -kx$。

### 40.3.3 电场力对偶（[A] 机电对偶）

电容储能 $U_E = \tfrac12 q^2/C$，电场力 $F_E = qE$。按对偶表 $k\leftrightarrow 1/C$、$\Delta x\leftrightarrow q$：

1. [A] $U_E = \tfrac12 (1/C) q^2$，与 $U=\tfrac12 k(\Delta x)^2$ 同构；
2. [A] 电场 $E = -d\phi/dx$，$\phi = q/C$（平行板电容电势）；
3. [A] $F_E = qE = q(-d\phi/dx) = -dU_E/dx$，仍为保守力。

### 40.3.4 量纲与数值验证

- 量纲：$[k]=[F]/[L]=\ell^{-2}/\ell=\ell^{-3}$；$[1/C]$ 按第 39 章口径 $\ell^{-1}$（与 $k$ 差 $\ell^{-2}$，见 39.4.4 诚实标注）。[A]
- 数值（[A]）：$k=100\,\mathrm{N/m}$，$\Delta x=0.1\,\mathrm{m}$ → $F=10\,\mathrm{N}$，$U=\tfrac12\times100\times0.01=0.5\,\mathrm{J}$。

## 40.4 磁场力（本源方程 + 求导）

### 40.4.1 本源定义

TUFT 诠释 [B]：磁场力是螺旋流环向挠率涡旋场对带电粒子的横向耦合，与旋转参考系中的科里奥利力 $F_c=-2m\boldsymbol\Omega\times\boldsymbol v$ 数学同构——本质都是"涡旋场对横向运动的几何偏转"。

### 40.4.2 本源方程（[A] 洛伦兹力）

$$\boldsymbol F_B = q\,\boldsymbol v\times\boldsymbol B \tag{40.3}$$

**关键性质 1：不做功** [A]

$$\boldsymbol F_B\cdot\boldsymbol v = q(\boldsymbol v\times\boldsymbol B)\cdot\boldsymbol v \equiv 0$$

由混合积循环置换 $(\boldsymbol a\times\boldsymbol b)\cdot\boldsymbol a=0$ 严格成立。故磁场力只偏转方向、不改变速率，与"横向耦合"几何直觉一致 [B]。

**关键性质 2：磁场无散** [A] Maxwell 方程 $\nabla\cdot\boldsymbol B=0$，对应 NS 涡量方程中 $\nabla\cdot\boldsymbol\omega=\nabla\cdot(\nabla\times\boldsymbol u)\equiv 0$（矢量恒等式）——结构同源 [B]。

### 40.4.3 从拉格朗日到洛伦兹力（严格求导，[A] 3 步）

取规范势 $\boldsymbol A$ 满足 $\boldsymbol B=\nabla\times\boldsymbol A$，带电粒子拉格朗日量：

$$L = \tfrac12 m v^2 + q\boldsymbol v\cdot\boldsymbol A \tag{40.4}$$

欧拉–拉格朗日方程：

$$\frac{d}{dt}\left(\frac{\partial L}{\partial\boldsymbol v}\right) = \frac{\partial L}{\partial\boldsymbol r} \tag{40.5}$$

求导链：

1. [A] $\partial L/\partial\boldsymbol v = m\boldsymbol v + q\boldsymbol A$；
2. [A] 对时间全导 $d/dt(\cdot) = m\dot{\boldsymbol v} + q\,\partial_t\boldsymbol A + q(\boldsymbol v\cdot\nabla)\boldsymbol A$；
3. [A] $\partial L/\partial\boldsymbol r = q\,\nabla(\boldsymbol v\cdot\boldsymbol A)$；
4. [A] 整理并使用恒等式 $\nabla(\boldsymbol v\cdot\boldsymbol A) = (\boldsymbol v\cdot\nabla)\boldsymbol A + \boldsymbol v\times(\nabla\times\boldsymbol A) + (\boldsymbol A\cdot\nabla)\boldsymbol v + \boldsymbol A\times(\nabla\times\boldsymbol v)$（$\boldsymbol v$ 与 $\boldsymbol r$ 无关后两项为 0），代入 $\boldsymbol B=\nabla\times\boldsymbol A$，得

$$m\dot{\boldsymbol v} = q(\boldsymbol v\times\boldsymbol B) - q\left(\partial_t\boldsymbol A + \nabla\phi\right)$$

其中 $\phi$ 为标势，电场 $\boldsymbol E=-\nabla\phi-\partial_t\boldsymbol A$，即完整洛伦兹力 $\boldsymbol F=q(\boldsymbol E+\boldsymbol v\times\boldsymbol B)$。

### 40.4.4 与科里奥利力同构（[A]）

旋转参考系角速度 $\boldsymbol\Omega$ 下，质点受科里奥利力：

$$\boldsymbol F_c = -2m\,\boldsymbol\Omega\times\boldsymbol v \tag{40.6}$$

与 (40.3) 对照：$q\boldsymbol B \leftrightarrow 2m\boldsymbol\Omega$——**数学结构完全同构**。[A] 旋转参考系标准结论；[B] TUFT 读作"磁场 = 真空微元螺旋流的局域旋转角速度场"。

### 40.4.5 量纲与数值验证

- 量纲：$[q]=\ell^0$，$[v]=\ell^0$，$[B]=\ell^{-2}$，故 $[F_B]=\ell^{-2}$ ✓ [A]。
- 数值（[A] 常识值）：电子 $q=1.602\times10^{-19}\,\mathrm{C}$，$v=10^6\,\mathrm{m/s}$，$B=1\,\mathrm{T}$，取 $v\perp B$：$F=qvB=1.602\times10^{-13}\,\mathrm{N}$；$F\cdot v=0$ 验证成立。

## 40.5 引力（本源方程 + 求导）

### 40.5.1 本源定义

TUFT 诠释 [B]：引力是大尺度上螺旋流场整体曲率与挠率耦合的宏观表现——与弹性力同属"径向曲率伸缩"类，但发生在流形曲率被大质量源整体弯曲的尺度上。

### 40.5.2 本源方程

**弱场形式**（[A] 牛顿万有引力）：

$$F_g = -\frac{GMm}{r^2} \tag{40.7}$$

**强场形式**（[A] 广义相对论测地线方程）：

$$\frac{d^2 x^\mu}{d\tau^2} + \Gamma^\mu_{\alpha\beta}\frac{dx^\alpha}{d\tau}\frac{dx^\beta}{d\tau} = 0 \tag{40.8}$$

### 40.5.3 从 GR 测地线到牛顿引力（严格 4 步，[A]）

1. [A] 弱场近似 $g_{\mu\nu}=\eta_{\mu\nu}+h_{\mu\nu}$，$|h_{\mu\nu}|\ll 1$；
2. [A] 静态度规 $g_{00}\approx-(1+2\phi/c^2)$，$\phi=-GM/r$ 为牛顿势；
3. [A] 联络分量 $\Gamma^0_{0i}\approx(1/c^2)\partial\phi/\partial x^i$；
4. [A] 代入 (40.8) 空间分量 $d^2x^i/dt^2 = -\partial\phi/\partial x^i$，即 $\boldsymbol a = -\nabla\phi$，乘 $m$ 得 $F=-GMm\hat r/r^2$。

### 40.5.4 量纲与数值验证

- 量纲：$[G]=\ell_P^2=\ell^{+2}$（S13 ch17 §17.3），$[M]=\ell^{-1}$，$[r]=\ell$，故 $[F]=[G][M]^2/[r]^2=\ell^{+2}\cdot\ell^{-2}/\ell^2=\ell^{-2}$ ✓ [A]。
- 数值（[A] 实验值）：地球表面 $g=9.81\,\mathrm{m/s^2}$，$GM_\oplus/R_\oplus^2=9.81\,\mathrm{m/s^2}$ 验证；弱场近似在太阳系尺度适用（水星近日点进动 $43''/$ 世纪由 GR 修正，[A] 实验验证）。

## 40.6 强 / 弱力（本源方程 + 求导）

### 40.6.1 标准模型描述（[A]）

- **强相互作用**：SU(3) 色规范场（量子色动力学 QCD），耦合常数 $\alpha_s(Q^2)$ 随能标 $Q^2$ 跑动，**渐近自由** $\alpha_s(Q^2)\to 0$（$Q\to\infty$）。实验值 $\alpha_s(M_Z^2)\approx 0.118$（PDG 2022）。
- **弱相互作用**：SU(2)×U(1) 电弱统一，W±/Z 玻色子质量 $m_W\approx 80.4\,\mathrm{GeV}$、$m_Z\approx 91.2\,\mathrm{GeV}$；弱作用只耦合左手费米子（V-A 结构），实验事实 [A]。

### 40.6.2 夸克禁闭（[A] 格点 QCD 数值证据，非解析证明）

强子内夸克不能自由分离，线性禁闭势：

$$V(r) \approx \sigma r,\qquad \sigma\approx 1\,\mathrm{GeV/fm} \tag{40.9}$$

弦张力 $\sigma$ 由格点 QCD 数值模拟给出（非解析证明），量纲 $[σ]=[E]/[L]=\ell^{-4}/\ell=\ell^{-3}$（按 S13 ch17 能量密度 $\ell^{-4}$、长度 $\ell$ 推导）。

### 40.6.3 TUFT 几何化诠释（[B] 结构对应；[C] 定量待建）

- **强相互作用** [B]：短程拓扑螺旋结耦合——夸克 = 螺旋流上的稳定拓扑孤子结，色荷 = 螺旋手性指标，线性禁闭势 $V(r)\approx σr$ 对应"螺旋张力随距离线性上升"。**从螺旋流第一性原理推导弦张力 $\sigma$ 的数值 [C] 待建**。
- **弱相互作用** [B]：手性翻转跃迁——弱作用只耦合左手费米子，TUFT 读作"螺旋流手性（左旋 / 右旋）之间的量子跃迁通道"。**从螺旋流第一性原理推导 W±/Z 质量 $m_W,m_Z$ [C] 待建**。

### 40.6.4 与 S13 M3 拓扑荷对照（[B]）

S13 M3 霍普夫拓扑荷 $Q_H\in\mathbb Z$ 与夸克色荷（红/绿/蓝三重态）结构上同属"离散拓扑量子数"。TUFT 把强子拓扑荷读作螺旋流上的霍普夫荷投影 [B]——**结构借鉴，不构成数值认证**。

## 40.10 诚实边界与待研究问题

1. **惯性力 / 弹性力 / 磁场力 / 引力的本源方程均为 [A] 标准物理已证实**；TUFT 对它们的"几何本质"诠释为 [B]——**解释不等于证明**。
