## 数值方法学教训（来自 R11）

验证「恒等式精确成立」时，float64 差分截断误差(O(dt²))必须低于目标精度。
R11 中 ωΔt=0.0176 时 sin(ωΔt)/(ωΔt)≈1−5e-5，完全掩盖物理信号；
mpmath 50 位 + 四阶差分 + dt=1e-15 将噪声压至 1e-18。
