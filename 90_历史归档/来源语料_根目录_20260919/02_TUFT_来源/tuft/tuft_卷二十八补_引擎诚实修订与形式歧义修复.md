1. **CKM 玩具矩阵非幺正**：`0.15·e^{iαQ(i−j)}/(1+|i−j|·0.4)` 对角全 0.15、行范数 0.20（幺正要求 ~1.0）→ 不是合法混合矩阵；
2. **质量无 GeV 标度**：`0.21·Q²+0.08·n_s+κ(πn)²` 是无量纲数，系数全自由，不能预言电子 0.511 MeV；

## 2. 修复一 · CKM/PMNS 幺正化（真修复）
SM 中 CKM 幺正性来自 `V = U_u†·U_d`（上下型各对角化于不同基底）。H-TUFT 应同构建模：**每个味扇区有厄米质量算符，对角化给出幺正 `U`，交叠矩阵 `V = U_u†·U_d` 自动幺正**。
```python
import numpy as np
def build_unitary_overlap(H):
    # H 厄米 -> eigh 给出幺正特征向量 evec, V = evec·diag(e^{iλ})·evec† 必幺正
    ev, evec = np.linalg.eigh(H - H.conj().T)   # 强制厄米
    return evec @ np.diag(np.exp(1j*ev)) @ evec.conj().T
```
**实跑验证（2026-09-30）**：行范数 `[1.0,1.0,1.0]`、列范数 `[1.0,1.0,1.0]` → **幺正性已修复**。

> **诚实二级结论（关键）**：幺正性是结构修复，不是预言修复。若非对角耦合取「纯拓扑」`H_ij ∝ α·Q·(i−j)/Δm_ij`，因 `Δm_ij` 是 205/3270 量级，`H_ij ~ 5e-5` ⇒ `V ≈ I`（近单位阵，**不是 CKM 结构**，CKM 需 `|V12|≈0.225`）。要得到 CKM 量级混合角，必须引入**自由混合参数** `θ ~ 0.2`（`H_ij = θ·(i−j)` ⇒ `|V12| = sin θ ≈ 0.223` 匹配 CKM）。**⇒ H-TUFT 与 SM Yukawa 同现状：CKM 数值需外部/自由参数，纯拓扑不导出。** 修复只让矩阵合法，未让理论可预言。

## 3. 修复二 · 形式度歧义（真修复）
交叠积分从「楔积 2-形式」改为**孤子截面空间的 L² 内积**（0-形式截面，积分域为 4 维底流形 M 配丛测度 `dμ_P`）：
```python
# 正确 L2 内积（标量，良定义）
def yukawa_overlap(Psi_i, Psi_j, measure):
    return np.sum(Psi_i.conj() * Psi_j * measure)          # ∫_P Psi_i^† Psi_j dμ_P
# 曲率加权项用厄米算符内积（非楔积）
def yukawa_curvature(Psi_i, Psi_j, D_A, measure):
    return np.sum(Psi_i.conj() * (1j*D_A) @ Psi_j * measure)  # ∫_P Psi_i^†(iD_A·g)Psi_j dμ_P
```
`Ψ` 是丛截面（0-形式/旋量），`Ψ†Ψ` 是标量密度，在 4 维 M 上积分良定义；曲率项由**协变导数算符** `iD_A·g` 作用于截面得同型截面再内积，仍是标量。**形式度歧义消除**（与卷二十六 §3 同源问题的同构修复）。

## 4. 修复三 · 质量标度锚定（真修复但诚实标注）
引入外部质量锚 `M0 = 0.511e-3 GeV`（电子质量，实验输入）给公式 GeV 单位：
```python
M0 = 0.511e-3  # GeV, 电子质量外锚（实验输入，非第一性）
def m_physical(Q_hel, n_s, kappa, n, m0=M0):
    return m0 * (0.21*Q_hel**2 + 0.08*n_s + kappa*(np.pi*n)**2)
```
**实跑（2026-09-30）**：三代质量 `[2e-4, 2e-4, 3e-4] GeV`，带单位。**但层级比仍为 1:1.32:1.85（基项主导）或 1:4:9（纯模态），实测 1:206.77:3477.2** ⇒ `M0` 只补单位，不解决量级。开放项「代质量层级绝对值」未闭合（与记忆 84665624 / v30「~500× 缺口需 Yukawa」一致）。
