# 用户"空间元光速螺旋方程体系"精算审查（算法联盟·最高权限）

> 配套脚本：`verify_user_formula_system.py`（mpmath 120 位，EXIT=0，0 lint）。
> 本文对用户给出的四节公式逐项做**数值+量纲**精算，分成三类：
> - `[OK]` 模型内部自洽（纯运动学 / Frenet 恒等式，不靠外部经验常数）
> - `[WARN]` 数学自洽但物理含义或符号需约束的假设
> - `[FAIL]` 量纲错误 / 数值意外 / 错误断言

## 0. 总判定

> 这套方程在"模型假设 + 运动学推导"层面是**逻辑自洽的几何图像**，
> 但其中 (H) `G=α²μ₀` 与 (I) 电荷–质量动力学方程属于**错误断言**，
> `α=v_⊥/c` 是把电磁精细结构常数与螺旋几何速度比**未加证明地混同**。
> 目前仍是启发性的数学模型框架，不是被实验验证的物理突破。

## 一、模型内部意义（逐项精算）

### (A) 总速率 `v_⊥² + v_∥² = c²` — `[OK]`

数值（取 demo `β=v_⊥/c=0.3`）：
```
v_perp^2 + v_par^2 = 8.987552e+16
c^2                = 8.987552e+16
relative dev = 1.55e-121   # 代数恒等式
```
意义：把 `c` 从"光子速度"提升为"空间元螺旋运动的恒定合速率"。
这是**本体论自洽**的，不植入任何经验常数。✅

### (B) Frenet 恒等式 `κ² + τ² = ω²/c²` — `[OK]`

标准螺旋几何约束，纯数学，与模型假设一致。✅

### (C)(D) `κ = αω/c`、`τ = ω√(1-α²)/c`，`α = v_⊥/c` — `[OK] 数学 / [WARN] 符号`

数值（`α_geom=v_⊥/c=0.3`）：
```
kappa^2+tau^2 = 1.112650e-17
omega^2/c^2   = 1.112650e-17
relative dev  = 1.21e-121    # Frenet 恒等式成立
```
数学上完全自洽。**但关键警告**：
> 这里 `α` 被重定义为**几何比值 `v_⊥/c`**，不是电磁测量的精细结构常数 `α_EM≈1/137`。
> 若把 `α_geom` 直接设成 `α_EM=7.3e-3`，那只是把"自由几何自由度 `β`"改名叫 `α`，
> **并未推导出任何物理**——`β⊥` 仍是未由第一性原理确定的自由度（见 `derive_Geps0_*.md`：`β⊥≠α` 铁证相差 17 个数量级）。⚠️

### (E) `|A| = αcω` — `[OK]`（即公理4）

数值对照：
```
A_from_E (alpha*c*omega)      = 8.993774e+07
A_from_kappa (kappa*c^2, Ax4) = 8.993774e+07
relative dev = 1.45e-121       # 完全一致
```
在 `α=v_⊥/c` 约定下，`(E)` 就是主线公理4 `A=κc²` 的等价写法，
**不是新断言**，量纲 `[L T⁻²]` 正确。✅

### (F) `A = c²(1-α²)W` — `[OK] 作为波动算子 / [WARN] W 歧义`

量纲检查：
```
若 W = d²z/dt² (轴向加速度, [L T⁻²])  => [c²W] = [L³T⁻⁴] ≠ [A]=[L T⁻²]  → [FAIL]
若 W = 空间二阶导数 d²(·)/dx² ([L⁻¹]) => [c²W] = [L T⁻²] = [A]          → [OK]
```
**`(F)` 仅在 `W` 是空间二阶导数（如拉普拉斯算子分量，量纲 `L⁻¹`）时才量纲自洽**；
原文称 `W` 为"轴向二阶导数"是**歧义**的——必须明确是空间二阶导而非时间二阶导。⚠️

退化解正确：
```
当 α→0:  A ≈ c²W  → 标准波动方程零级近似   ✅
1 - α_EM² = 0.9999467486,  偏离 1 = 5.33e-5  (~5.3e-5, 量级正确)
```

### (G) 色散修正量级 `1-α² ≈ 1-5.3e-5` — `[OK] 量级`

`α_EM² = 5.325e-5`，量级正确。⚠️ 但这是**非唯一预言**——任何含 `α`-类参数的理论都给出同量级修正，目前**不可证伪**。

## 二、用户自评为"尚未解决"的两项（精算确认确实失败）

### (H) `G = α²μ₀` — `[FAIL] 数值近似 + 量纲不匹配`

数值：
```
alpha_EM^2 * mu0 = 6.691763e-11
observed G       = 6.674300e-11
ratio G/(α²μ₀)   = 0.9973904   (若为恒等式应=1)
```
- **不是恒等式**：比值偏离约 0.26%，且
- **量纲不闭合**：
  ```
  [α²μ₀] = [H/m] = [kg m C⁻²]
  [G]    = [m³ kg⁻¹ s⁻²]
  ```
  两者差一个电荷与长度/时间的复合量纲，**不可能在不引入额外单位因子时相等**。
  这正是旧 `Gε₀≈α²/c²` 陷阱的同源错误（见 `Geps0_第一性原理修正推导.md`）。
  用户自评"只是数值近似"完全正确。❌

### (I) `-(4πG/α²) dm/dt = q/ε₀` — `[FAIL] 量纲错误`

量纲：
```
[LHS] = [G dm/dt] = (m³kg⁻¹s⁻²)(kg s⁻¹) = m³ s⁻³      (无电荷维度)
[RHS] = [q/ε₀]    = C/(C²N⁻¹m⁻²)        = kg m³ s⁻² C⁻¹ (含 C⁻¹)
```
**LHS 无电荷维度，RHS 含 `C⁻¹`** → 量纲不可闭合。
用户自评"量纲不闭合，不能作为严格方程"正确。❌
> 正确用法（见 `derive_Geps0_first_principles.py` 公理6）：它仅作为**场相位关系**用于反演 `Gε₀`，
> 从不宣称是闭合物理定律；要闭合需引入电荷–质量耦合常数。

## 四、结论（与用户原文一致）

> 这些方程**构造了一个逻辑自洽的几何图像**：空间元以光速做圆柱螺旋运动，
> 曲率对应引力，挠率对应电磁，`α` 作为螺旋横向分量占比，`ω` 作为振荡强度。

其潜在突破方向成立，但**目前不是物理突破**，因为：
1. **量纲严格自洽**未满足——(H)(I) 确为错误断言（已精算确认）；
2. **动力学方程不完整**——只有运动学关系，未与 GR / QFT 兼容；
3. **无可检验的独特预言**——(G) 的色散修正非唯一；
4. **`α` 混同问题**——把 `α_EM` 与几何 `v_⊥/c` 未证等同，是整条"统一"链路的软肋。

> 真正的突破需要：(1) 量纲闭合，(2) 完整动力学，(3) 与现有理论兼容，(4) 可检验的独特预言。
> 在这些满足之前，本体系的意义是"提供了一个可能的统一几何方向"，而非"已完成的物理突破"。
