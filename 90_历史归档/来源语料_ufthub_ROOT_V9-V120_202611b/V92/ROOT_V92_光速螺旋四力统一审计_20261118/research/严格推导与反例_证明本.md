## 定理 1：非退化常速圆柱螺旋的 Frenet 闭合

条件：在固定欧氏三空间惯性坐标中，`R>0,ω>0,p∈R` 常数。设 `r=(Rcosωt,Rsinωt,p t)`。常速 `v=sqrt(R²ω²+p²)>0`，曲率和挠率定义为

```
κ=|r'×r''|/|r'|³
τ=det(r',r'',r''')/|r'×r''|².
```

通过逐分量叉积和行列式计算：

```
|r'×r''|² = R²ω⁴(R²ω²+p²)
det(r',r'',r''') = p R²ω⁵
κ=Rω²/(R²ω²+p²)
τ=pω/(R²ω²+p²).
```

代数展开：

```
κ²+τ² = (R²ω⁴+p²ω²)/v⁴
         = ω²(R²ω²+p²)/v⁴
         = ω²/v².
```

因此 `ω=v sqrt(κ²+τ²)`。逆几何为 `R=κ/(κ²+τ²)` 和 `p=vτ/sqrt(κ²+τ²)`。这是等价参数化；其中没有独立决定 v 的方程。QED.

## 定理 2：真实三维 v=c 的必要充分约束

同一定义下，`v=c ⇔ R²ω²+p²=c²`。若 `Rω=c` 且 `p≠0`，则 `v²=c²+p²>c²`，因此这种版本与原本 c 的总速解释直接矛盾。QED.

## 定理 3：三维空间挠率不是普遍 Lorentz 标量

沿 z 方向进行速度 u 的 Lorentz 变换：

```
t'=γu(t-u z/c²)=γu(1-up/c²)t
z'=γu(z-ut)=γu(p-u)t
x'=x, y'=y
```

对时间 t' 重参数化，依然是圆柱螺旋，但 `R'=R, ω'=ω/[γu(1-up/c²)], p'=(p-u)/(1-up/c²)`。对于 `|p|<c`，取 u=p，则 `p'=0`，原来 `τ≠0` 的运动变成 `τ'=0` 的平面圆轨道。几何挠率不是 Lorentz 观察者独立常数。QED.

## 定理 4：仅 κτ频率不足以普遍确定力

考虑平直时空均匀电场 `E=E0 xhat` 中 q≠0 的质量粒子，在 x 方向由静止开始。`dp_x/dt=qE0≠0`，但轨迹始终在 x 轴上，任何具有非零瞬时速度的区间，其空间曲率 `κ=0`，角速度 `ω=0`，挠率不能承载非零转向信息。若存在无其它动态输入的普遍函数 `F=f(κ,τ,ω)`，则该轨迹与自由直线的几何参数相同，却具有不同受力，与唯一决定假设矛盾。QED.

## 定理 5：螺旋法向动力学的条件重写

在固定惯性参考系中定义 `T=vvec/v`、`N` 为主法线。速度变化 `d(vT)/dt = vdot T+v²κN`。对动量 `p=γ m0 vT` 微分：

```
F=γ³m0 vdot T + γ m0 v²κ N.
```

这是狭义相对论三力定义的精确分解（不考虑粒子质量变化）；当 v 常数时 `F=γm0 v²κN`。挠率出现在 N、B 随弧长的演化中，并不能由这些等式解出四种微观相互作用源。QED.

## 定理 6：质量维数障碍与条件尺度构造

采用 `[M,L,T,I]`。`[G]=(-1,3,-2,0)`、`[c]=(0,1,-1,0)`、`[κ]=[τ]=(0,-1,0,0)`、`[ω]=(0,0,-1,0)`。不论实数指数取何值，`c^aκ^bτ^dω^e` 质量指数始终为零，绝不可能匹配 G 的 -1。仅凭这些量不能生成 G。引入 `[ħ]=(1,2,-1,0)` 后：

```
[c³/(ħ κ²)] = [G].
```

这只意味着需要一个质量尺度与长度尺度（经 ħ 与 κ 描述）才能构造 G；未从独立公设决定 κ 与比例系数之前，不能称为预测 G。QED.

## 反例 7：同一磁螺旋不意味着同一种底层运动起因

已知 `ω=|q|B/(γm)`。把 `m→a m, B→a B`、同时保持相同 q、相同入射速度与倾角，则 `ω`、`R`、`κ`、`τ` 都完全不变，但磁场能量和粒子的静质量改变。它说明仅靠轨迹运动学不足以反推出独立的力场与源，且相同轨迹也可由其他外力约束产生。QED.

## 反例 8：光子自由螺旋 vs 零测地线

在平直 Minkowski 真空中，如果自由光子沿仿射零测地线满足 `d²xμ/dλ²=0`，其惯性坐标下空间速度方向不随时间改变。对非退化螺旋，`|r''|=Rω²>0`，空间加速度非零，故不能同时描述同一无外场自由传播情况。含外场、折射、波包/能流与弯曲时空时，应单独建模；该反例仅否定无外场自由光子的普遍螺旋。QED.

## 反例 9：GR 自由落体 vs 三维曲率

自由落体世界线可满足 `DUμ/dτ=0`，即固有加速度零，但相对于外部坐标观测者具有曲折空间投影（例如轨道）；因此不能把任意空间 κ 非零解释成具有非引力基本三力的证据。需要始终区分轨迹投影、坐标加速度与固有加速度。

## 条件解释 10：同一个纤维丛几何语言 ≠ 统一场论证明

联络的曲率 `[Dμ,Dν]` 能容纳重力自旋联络以及 U(1)、SU(2)、SU(3) 的场强。这是可用的数学组织形式，独立动力学耦合、量子表示、异常抵消、光谱及参数并不由“同为曲率”自动确定。若要证明真正的共同本源，需将这些自由输入缩减并引入独立新预测。状态：开放。
