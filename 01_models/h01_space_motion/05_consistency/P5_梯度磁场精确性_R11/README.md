## 核心定理

> 对方向不变的任意空间梯度磁场 $\mathbf{B}(\mathbf{x})$，带电粒子轨迹的三重奏**精确成立**：
> $$\kappa^2 + \tau^2 = \left(\frac{q B(\mathbf{x})}{m v}\right)^2$$
> 这是**精确恒等**（非近似）。

## 解析证明

由运动方程 $x'' = -\omega_c(x) y'$，$y'' = \omega_c(x) x'$ 代数推导：
- $\kappa^2 = \omega_c^2 v_\perp^2 / v^4$
- $\tau^2 = \omega_c^2 v_\parallel^2 / v^4$
- ⟹ $\kappa^2 + \tau^2 = \omega_c^2 / v^2$ **精确恒等**

## 物理意义

- 真实磁约束聚变装置中，磁场必然非均匀
- R11 给出"即使在非均匀磁场中，三重奏依然精确成立"的保证
- 直接应用：磁约束诊断、磁场质量检测
