## 2.2 判定矩阵读出的事实

### 事实一：深度高度集中

登记主张 477 条，其中 S02（115）、S03（89）、S14（140）、S15（43）、S17（40）五个体系占 427 条，即 **89.5%**。其余十七个体系合计 50 条。

这不是缺陷，是**真实重心**：本库的正文深度几乎全部压在「螺旋运动学 + TUFT + 核心公式」三处。任何声称「二十二体系均等展开」的叙述，都与账不符。

### 事实二：七个体系零主张

P01、P02、P04、S01、S04、S11、S16 的 `claims.csv` 非空行为 0。

零主张有三种来源，必须分开写：

- **终审为空标签**：P01/P02/P04。第 86 章逐条查过：公设 0、本体系自身材料 0、实质文件 0。零主张是结论，不是遗漏。
- **框架无独立主张**：S01/S11/S16。它们是底座或并册，主张寄存在被服务的体系里。
- **正文有章、登记缺行**：S04（第 11 章有定理 I1–I3）在 `claims.csv` 里没有对应行。这是**账实不符**，属登记债，不是物理债。

最后一种最值得记：书里有推导，账上却没有登记。它不会让物理更对，只会让账更假。本书把它单列为「待回填」（见第七章 §7.4）。

### 事实三：status 只对 364 条有意义

列宽合格的 364 条里：

| status | 条数 | 含义 |
|---|---:|---|
| verified | 166 | 数值／符号复跑通过（不区分恒等式与预言） |
| falsified | 96 | 被反例、实验上限或量纲判死 |
| unreviewed | 58 | 登记了但未过任何外部评审 |
| structural | 16 | 结构陈述，不构成数值判决 |
| unreproduced | 11 | 声称过、复跑未复现 |
| open | 8 | 明确留开 |
| repaired | 5 | 修过并留痕 |
| proposed | 3 | 提议，未验证 |
| structural_failure | 1 | 结构性失败 |

**166 个 verified 不是 166 个物理胜利**。本库的 verified 里，绝大多数是「定义链闭合」：质量由 κ 定义，则 m↔ω 自然成立。这类在 `04_来料审计论` 里叫 TAUT。把它们读成预言，是本书要防的第一类误读。

### 事实四：只有一个 active

S18 是唯一 `active` 的体系，8 条主张。它的存在说明登记表不是墓碑：新路线仍可进入。但 active 不等于被验证，只等于「维护轮仍在推进」。

## 2.3 六族归并

`01_整合版目录.md` 附录 F 把早期十八体系归为六族。按现值和类型重排：

1. **螺旋运动学族**：S01、S02、S12、S15（曲率—挠率语言）。
2. **GAQ 演进族**：S03、S07、S08、S09（几何原子 → 复曲率 → 常数 → 质量谱）。
3. **高维／拓扑／信息族**：S04、S05、S06（信息引力、紧致化、边界态）。
4. **本体候选族**：S10、S11、S13（频率本体、几何自由度、对偶分形）。
5. **TUFT 族**：S14、S16、S17（主册、归一化、核心公式）。
6. **方向与终审族**：P01–P04 + S18。

归并的用途只有一个：**避免把同族内的重述当成独立证据**。S03 与 S08 都讲几何常数，若两者给出同一个 `α`，那是同一族内的回声，不是两条独立验证。

## 2.4 本章的结论

二十二个体系的判定矩阵给出三句话：

1. **广度是登记的广度，深度是五個体系的深度**（89.5% 主张集中）。
2. **零主张不等于零工作**，但「书里有、账上无」必须记为登记债（S04）。
3. **status 只在 364 条上成立**，其余 113 条先修记录形态，再谈判决。

下一章逐条走「修过什么」：从 S02 的 α 断言，到 S06 的计数矛盾，到 S07 的普朗克锚定，再到本轮新抓的 113 行列宽异常。
