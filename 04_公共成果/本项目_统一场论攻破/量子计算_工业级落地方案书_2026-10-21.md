## 一、STEP 1 · 数据中心基础设施交付（第 1–3 个月）

### 1.1 机位规格（按 1 台 QPU + 2 台经典协同节点计）
- 占地：1 个 19 英寸标准机架 × 2（QPU 1 架 + 控制/经典 1 架），预留 1 架扩展
- 供电：≥20 kW/机架（Diraq 8 比特整机 <20 kW 为下限；超导 100 比特级需 40–80 kW，含稀释制冷压缩机组）
- 冷却：液冷回路（水温 18–22 °C）＋空调冗余 N+1

### 1.2 稀释制冷机（超导路线核心）
| 参数 | 规格要求 | 说明 |
|---|---|---|
| 最低温 | ≤15 mK（基础温度） | 超导量子比特工作点 10–20 mK |
| 冷量 | 100 mK 平台 ≥400 μW | 支撑 100+ 比特微波布线 |
| 振动 | 台面 <10 nm RMS | 振动会退相干；采用 Bluefors 模块化低温平台（可按比特数扩展，无需重建） |
| 氦-3 供应 | 年用量合同（混合制冷剂） | **ORNL 2026：规模化先撞氦-3 供应瓶颈，需锁定供应商** |
| 磁屏蔽 | μ-金属多层屏蔽，屏蔽因子 ≥10⁴ | 地磁/噪声耦合 |

### 1.3 基础设施验收标准（Checklist）
- [ ] 基础温度达标（≤15 mK）持续 72 小时
- [ ] 振动 <10 nm RMS 全程监测
- [ ] 供电波动 <±2%，UPS 冗余 ≥15 分钟
- [ ] 电磁背景：10 Hz–10 GHz 屏蔽室实测频谱低于指标
- [ ] 氦-3/液氦库存 ≥3 个月用量

## 二、STEP 2 · QPU 硬件选型与验收（第 2–4 个月）

### 2.1 采购目标（超导路线，100–200 物理比特）
- 单比特门保真度 ≥99.9%，双比特门 ≥99.0%（对标 Rigetti Cepheus-1-108Q：99.9%/99.1%；本源悟空-180：99.9%/99%）
- 相干时间 T₁ ≥40 μs（对标浙大昆仑 T₁=41.8 μs）
- 可调耦合器 ≥2×比特数（对标 IBM 夜鹰 218 耦合器/120 比特）

### 2.2 验收流程（分 4 步，每步有门禁）
1. **出厂参数核对**：厂家报告 vs 我方独立测试（量子过程层析 QPT 复测门保真度）
2. **基准测试套件**：随机化基准（RB）＋XEB（交叉熵基准）＋单次/重复读出保真度
3. **稳定性测试**：连续运行 7×24 小时，漂移 <10% 门保真度
4. **部署验收**：机架就位后冷启动 ≤48 小时达到工作点

## 三、STEP 3 · 控制电子学与测控系统（第 3–5 个月）

### 3.1 硬件栈（按层）
```
用户作业
   ↓ (QASM/OpenQASM 3)
编译层（Transpiler：门分解/映射/优化）
   ↓
实时控制（FPGA 波形生成：微波 4–6 GHz、单/双比特脉冲）
   ↓
低温链路（同轴/超导微波线，衰减+滤波，热锚定）
   ↓
QPU 芯片（Transmon 阵列）
   ↓
读出链路（JPA 量子放大器→HEMT→ADC，单次读出保真度 ≥98%）
```

### 3.2 关键器件规格
- 任意波形发生器（AWG）：采样率 ≥2 GSa/s，通道数 ≥2×比特数
- 微波源：4–6 GHz，相位噪声 <-130 dBc/Hz @10 kHz
- 读出：量子限制放大器（JPA/JTWPA）+ 高电子迁移率晶体管（HEMT）前置放大
- 时钟：10 MHz 铷原子钟 + 1 PPS 同步，抖动 <1 ps

### 3.3 校准与漂移管理（工业级关键）
- 每日自动校准：频率/幅度/相位自校准（对标玻色"闲时自检+故障自愈"，44 天连续运行纪录）
- 每周深度校准：QPT 全门集复测
- 漂移预警：门保真度低于阈值 90% 时自动触发重校准（不停机滚动执行）

## 四、STEP 4 · 软件栈与混合调度（第 4–6 个月）

### 4.1 软件栈清单
| 层 | 组件 | 说明 |
|---|---|---|
| 编程框架 | Qiskit / Cirq / Q# / 量子云枢类 SDK | 用户入口，嵌入 PyTorch 生态（玻色量子已验证） |
| 编译器 | Qiskit transpiler / tket | 门分解→物理映射→脉冲级 |
| 中间表示 | OpenQASM 3 | 标准可交换格式 |
| 纠错解码 | 表面码实时解码器（FPGA） | 单轮解码 <1 μs（错误率低于阈值 ~1%） |
| 混合调度 | 量子-经典协同（HPC 工作流对接） | OQC 教训：HPC 调度器按天计、量子运行按秒计，须自研桥接层 |
| 云 API | REST/gRPC + 任务队列 + 租户隔离 | 对标"量子云枢"四层架构 |

### 4.2 量子-经典混合执行流（一步步）
1. 用户提交任务（经典预处理 + 量子线路）
2. 调度器拆分：经典部分→GPU 集群；量子部分→QPU 队列
3. 量子线路编译→控制电子学→执行（毫秒–秒级）
4. 测量结果回传→经典后处理（VQE/QAOA 迭代中重复 2–4）
5. 结果返回用户 + 计量计费

## 五、STEP 5 · 量子纠错部署（第 6–12 个月，容错线）

### 5.1 纠错路线（对标行业）
- 表面码为主（阈值 ~1%），qLDPC 优化（IBM 2025 后主推，288 硬件比特可替代 4000 比特表面码方案）
- 逻辑比特 = 物理比特 × 编码开销（表面码距离 d，开销 ~2d²）

### 5.2 里程碑
| 里程碑 | 目标 | 验收 |
|---|---|---|
| M1 | 1 个逻辑比特（距离 3–5） | 逻辑错误率 <物理错误率（纠错增益为正） |
| M2 | 2 个逻辑比特 + 逻辑 CNOT | 逻辑门保真度 >99% |
| M3 | 逻辑比特寿命超盈亏平衡点 | 对标深圳量子院 2023 突破 |

### 5.3 实时解码架构
- 物理比特读出→FPGA 稳定子测量→解码器（MWPM/UF 算法，<1 μs/轮）→错误校正反馈
- 备用：AI 辅助解码（Google 路径）作为加速器

## 附录 A · 关键公式（LaTeX）
- 门保真度（随机化基准）：$F_{\rm RB}=1-\frac{d-1}{d}p$（$p$ 为每克ifford错误率，$d=2^n$）
- 表面码开销：$N_{\rm phys}\approx 2d^2 N_{\rm log}$（距离 $d$，逻辑比特 $N_{\rm log}$）
- 纠错增益条件：$p < p_{\rm th}\approx1\%$（阈值定理）
- 稀释制冷冷却功率：$\dot{Q}=\dot{n}_{\rm He3}\cdot L_{\rm He3}$（氦-3 蒸发潜热 $L_{\rm He3}\approx0.23$ kJ/mol @0.3 K）
- XEB 保真度：$F_{\rm XEB}=2^n\langle P_{\rm ideal}\rangle-1$
