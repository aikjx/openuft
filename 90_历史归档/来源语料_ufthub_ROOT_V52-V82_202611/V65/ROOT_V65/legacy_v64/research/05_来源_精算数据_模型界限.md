## 物理常数

- NIST: CODATA recommended values, 2022 adjustment; NIST 概览：https://www.nist.gov/publications/codata-recommended-values-fundamental-physical-constants-2022
- NIST 物理常数主页：https://physics.nist.gov/cuu/Constants/
- 本包使用 `G=6.67430(15)×10^-11 m³ kg^-1 s^-2`，`c=299792458m/s`（精确），`h=6.62607015×10^-34J·s`（精确），`ℏ=h/2π`，`α=7.2973525643×10^-3`。
- 外部精确数据**是输入，不是本理论推导**。

## 工程依赖与验证边界

- `src/root_v64.py` 与 `tests/test_core.py` 仅需 Python >=3.10 标准库。
- `experiments/run.py` 标准库运行，安装 matplotlib 时可额外生成 PNG；若 matplotlib 缺失，CSV 和 JSON 仍可生成。
- 3D 网页为浏览器离线绘图，不下载外网图片，不获取实时地球数据。
- 测试通过意味着数学实现符合指定理想模型，**不能证明**未给定的新自然规律或大统一命题。
