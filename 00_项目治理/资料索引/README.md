在 openuft 根目录执行 `python 00_项目治理/维护工具/refresh_catalog.py` 更新当前索引；加 `--check` 则**只读对账**（印出可索引文件数、盘上行数、尚未索引数、已失效行数、`.git` 泄漏数、畸形行 `- [[` 数，一字不写）。有并发写者时先跑 `--check`，不要直接落盘——整体重生成会把他人更大的正本回退（此红线见 `04_公共成果/本项目_统一场论攻破/` 各轮）。工具按目录段排除 `.git` 与 `__pycache__`（本仓库自带 `openuft/.git`，裸 rglob 会把仓库记账对象索引进正本）；契约与变异体见 `00_项目治理/维护工具/test_refresh_catalog.py`。手工插行仍须按生成器口径：行相对 `00_项目治理/资料索引/` 取 `../../<path>`，`() #` 与空格转义为 `%28 %29 %23 %20`，Windows `Path` 排序大小写不敏感。历史总表和研究报告保留原有主张，科学状态以各模型证据登记和实际审查为准。
