  量子比特（qubit）：

  经典比特：0 或 1
  量子比特：|ψ⟩ = α|0⟩ + β|1⟩
    其中 |α|² + |β|² = 1（归一化）

  Bloch球表示：
    |ψ⟩ = cos(θ/2)|0⟩ + e^(iφ)sin(θ/2)|1⟩
    量子比特状态 = Bloch球表面一点
    θ：极角, φ：方位角

  测量：
    测量|0⟩概率：|α|²
    测量|1⟩概率：|β|²
    测量后状态坍缩（不可逆）

  Bloch球计算：
    θ = 0.33π, φ = 0.25π
    α = cos(θ/2) = 0.8660
    β = sin(θ/2)e^(iφ) = 0.3536+0.3536j
    P(0) = |α|² = 0.7500, P(1) = |β|² = 0.2500
    归一化：1.000000（=1）

【QI2】量子纠缠
----------------------------------------------------------------------

  量子纠缠：

  纠缠态是两个或多个量子比特的关联态：
    |Φ⁺⟩ = (|00⟩ + |11⟩)/√2（Bell态）
    |Φ⁻⟩ = (|00⟩ - |11⟩)/√2
    |Ψ⁺⟩ = (|01⟩ + |10⟩)/√2
    |Ψ⁻⟩ = (|01⟩ - |10⟩)/√2

  纠缠的关键特性：
    1. 不可分离性：不能写成直积态
    2. 非局域性：测量一个比特影响另一个
    3. 不可克隆性：不能复制未知量子态

  EPR佯谬与Bell不等式：

  EPR佯谬（Einstein-Podolsky-Rosen, 1935）：
    Einstein认为量子力学不完备
    主张存在隐变量理论
    称纠缠为“spooky action at a distance”

  Bell不等式（1964）：
    任何局域隐变量理论满足：
    CHSH：⟨AB⟩ + ⟨A'B⟩ + ⟨AB'⟩ - ⟨A'B'⟩ ≤ 2
    量子力学预言：最大值 2√2 ≈ 2.828

  Bell实验（Aspect 1982, 2015无漏洞）：
    实验测量值 > 2（违反Bell不等式）
    局域隐变量理论被排除
    量子力学正确！

  CHSH不等式计算：
    局域隐变量界限：S ≤ 2.0
    量子力学预言：S = 2.8284 = 2√2
    违反幅度：ΔS = 0.8284

  纠缠度量：

  von Neumann熵：
    S(ρ_A) = -Tr(ρ_A log ρ_A)
    纯态纠缠：S > 0
    最大纠缠态：S = log₂(d)

  Bell态熵：S = 1 bit（2维）
  Concurrence（两比特）：C ∈ [0,1]

  von Neumann熵计算（Bell态）：
    约化密度矩阵特征值：λ₁=λ₂=0.5
    S(ρ_A) = -Σλlogλ = 1.0000 bit（最大纠缠）

  纠缠的应用：

    1. 量子隐形传态：利用纠缠传输量子态
    2. 量子密钥分发：纠缠保证安全性
    3. 量子计算：纠缠是并行计算的资源
    4. 量子超密编码：2比特信息用1比特传输
    5. 量子网络：纠缠分发和存储

  螺旋几何化解释：

  1. 量子纠缠的螺旋几何化
     - 纠缠态 = 共享螺旋相位的关联态
     - Bell态 = 螺旋相位的同步组合
     - 非局域性 = 共享螺旋的全局相位
     - 不可克隆 = 螺旋相位不可复制

  2. Bell实验的螺旋解释
     - 测量关联 = 螺旋相位的关联
     - CHSH违反 = 螺旋相位的非经典关联
     - 局域性 = 螺旋的分离性
     - 非局域 = 共享螺旋的不可分离性

  3. 纠缠熵的螺旋解释
     - 纠缠熵 = 螺旋信息的共享量
     - 最大纠缠 = 螺旋相位全共享
     - 混合态 = 螺旋相位的统计混合

  量子计算原理：

  量子比特的计算优势：
    n个量子比特：2ⁿ维叠加态
    量子并行：同时处理所有叠加分量
    干涉增强：正确的计算路径增强，错误的相消

  n比特量子态：
    |ψ⟩ = Σ c_x |x⟩, x ∈ {0,1}ⁿ
    Σ|c_x|² = 1
    c_x 个数：2ⁿ

  量子态维度计算：
    n = 50 量子比特
    态空间维度 = 2ⁿ = 1.1e+15
    经典模拟需要 1.1e+15 个复数（~18014399 GB内存）

  量子门：

  单比特门：
    Pauli-X：|0⟩↔|1⟩（类似NOT）
    Pauli-Y：X门+相位
    Pauli-Z：|1⟩→-|1⟩（相位翻转）
    Hadamard H：|0⟩→(|0⟩+|1⟩)/√2（叠加）
    S门：|1⟩→i|1⟩（π/2相位）
    T门：|1⟩→e^(iπ/4)|1⟩（π/4相位）

  两比特门：
    CNOT：控制比特=1时翻转目标比特
    SWAP：交换两比特
    CZ：控制Z门

  通用门集合：
    {H, S, T, CNOT}：通用（任意量子计算）

  Hadamard验证：
    H² = I? True

  量子电路模型：

  量子算法流程：
    1. 制备初态 |0...0⟩
    2. 叠加：H⊗n → 均匀叠加
    3. 演化：幺正电路 U
    4. 测量：读出结果

  噪声量子计算（NISQ）：

  NISQ（含噪声中等规模量子）：
    当前时代：50-1000量子比特
    噪声：退相干 + 门错误
    应用：变分量子算法（VQE, QAOA）

【QI4】量子算法
----------------------------------------------------------------------

  重要量子算法：

  1. Shor算法（1994）：质因数分解
     经典复杂度：O(exp(1.9 n^(1/3) log^(2/3)n))
     量子复杂度：O((log N)²(log log N)(log log log N))
     指数加速！威胁RSA密码

  2. Grover算法（1996）：无序搜索
     经典复杂度：O(N)
     量子复杂度：O(√N)
     平方加速

  3. 量子傅里叶变换（QFT）：
     经典FFT：O(N log N)
     量子QFT：O((log N)²)
     指数加速！Shor算法的核心

  4. HHL算法（2009）：线性方程组
     经典：O(N√κ)
     量子：O(log(N)·κ²/ε)
     指数加速（稀疏矩阵）

  5. 变分量子本征求解器（VQE）：
     量子-经典混合
     化学分子基态计算
     当前NISQ主力算法

  Grover算法加速计算：
    数据库 N = 1e+06
    经典搜索：O(N) = 1e+06 次
    量子搜索：O(√N) = 1e+03 次
    加速比：1000×

  Shor算法原理：

  质因数分解流程：
    1. 随机选 a，求 gcd(a, N)
    2. 用量子电路求 a 的模阶 r
       a^r ≡ 1 (mod N)
    3. 计算 gcd(a^(r/2)±1, N)
    4. 得到非平凡因子

  量子部分：周期查找（QFT）
    经典部分：数论后处理

  量子算法的应用：

    - 密码学：RSA破解（Shor），对称密码安全（Grover减半）
    - 化学：分子模拟（VQE）
    - 优化：组合优化（QAOA）
    - 机器学习：量子机器学习（QML）
    - 金融：投资组合优化、风险分析
    - 材料：量子材料模拟

【QI5】量子密码学与量子纠错
----------------------------------------------------------------------

  量子密码学：

  量子密钥分发（QKD）：
    无条件安全性基于量子力学原理
    窃听必然留下痕迹（不可克隆+测量坍缩）

  BB84协议（Bennett-Brassard, 1984）：

  流程：
    1. Alice随机选择基（Z或X）发送量子比特
    2. Bob随机选择基测量
    3. 公开比对基（不公开值）
    4. 基相同的位置保留为密钥
    5. 随机抽样检测窃听（错误率>11%则放弃）

  安全性：
    窃听者Eve无法复制未知量子态
    测量必然扰动：错误率暴露窃听

  E91协议（Ekert, 1991）：

    基于纠缠态和Bell不等式
    纠缠分发：Alice和Bob共享Bell态
    安全检测：CHSH测试
    违反Bell不等式 → 无窃听

  量子隐形传态：

  流程：
    1. Alice和Bob共享Bell态
    2. Alice对要传的态和她的Bell比特做Bell测量
    3. Alice通过经典信道发送2比特结果
    4. Bob根据结果做幺正变换恢复原态

  注意：
    - 不传输信息（经典信道限制速度）
    - 不复制量子态（原态被破坏）
    - 传输的是量子态而非物质

  量子纠错：

  为什么需要量子纠错：
    量子态不可克隆 → 不能简单复制备份
    测量破坏量子态 → 不能直接检测错误
    退相干 → 相位信息丢失

  量子纠错码原理：

  Shor码（9比特纠错1比特）：
    9个物理比特编码1个逻辑比特
    可纠正任意单比特错误

  Steane码（7比特）：
    基于CSS构造（Calderbank-Shor-Steane）
    稳定子形式

  表面码（Surface Code）：
    二维网格布局
    容错阈值：~1%（远高于当前硬件错误率）
    Google/IBM主流方案

  表面码开销计算：
    物理错误率 p = 0.001
    表面码阈值 p_th = 0.01
    距离 d = 7
    逻辑错误率 p_L ≈ (p/p_th)^((d+1)/2) = 1.00e-04
    物理比特数 n = 2d²-1 = 97

  容错阈值定理：

  如果物理错误率低于阈值：
    可以任意精度进行量子计算
    错误率低于阈值：1-10⁻²（不同码不同）
    通过分层编码实现容错

  当前状态：
    2023 Google：表面码d=3逻辑量子比特
    2023-2024：d=5, d=7表面码
    100万物理比特 ≈ 1万逻辑比特（估算）

  螺旋几何化解释：

  1. 量子密码的螺旋几何化
     - 密钥 = 螺旋相位的秘密序列

     - 安全 = 螺旋相位的不可克隆

  2. 隐形传态的螺旋解释
