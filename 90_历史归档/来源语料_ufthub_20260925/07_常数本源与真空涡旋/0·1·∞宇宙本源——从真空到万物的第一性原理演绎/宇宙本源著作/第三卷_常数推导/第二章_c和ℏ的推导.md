# 第二章 光速$c$与普朗克常数$\hbar$的几何起源

## 2.1 光速$c$的几何意义

我们在第二卷已经指出，光速是超复数流形的内禀旋度速度，是超复数乘法的传播速度。现在我们严格推导光速的几何意义。

**定理2.1.1（光速是内禀旋度速度）**：光速$c$是128维超复数流形中，内禀旋度算子$\partial_t$与空间梯度算子$\nabla$的比值，即超复数波动方程的传播速度：
$$\left(\frac{1}{c^2}\partial_t^2 - \nabla^2\right)\psi = 0$$
这个方程是超复数乘法的直接结果，因为超复数乘法满足$(\partial_t + c\nabla)(\partial_t - c\nabla)\psi = 0$，其解是波速为$c$的波动。

**几何解释**：超复数流形的每个点都在以光速$c$绕i轴旋转，这个旋转的传播速度就是光速。就像旋转的绳子上的波以固定速度传播一样，超复数旋转的传播速度是固定的，与参考系无关，这就是光速不变原理的几何起源。

在自然单位制中，我们定义$c=1$，这是因为我们选择时间单位使得光走单位长度的时间为1单位时间。在国际单位制中，$c=299792458m/s$，这个数值是人为定义的，因为米被定义为光在1/299792458秒内传播的距离，因此光速的精确值是定义出来的，不是测量出来的。

**命题2.1.1（光速的普适性）**：光速是普适常数，对所有惯性系都相同，因为超复数结构在流形的所有点都是相同的，内禀旋度速度不随位置或参考系变化。这解释了为什么迈克尔逊-莫雷实验没有观测到光速的变化——光速是空间的内禀性质，与光源和观察者的运动无关。

## 2.2 普朗克常数$\hbar$的几何意义

普朗克常数是量子力学的基本常数，它描述了量子的大小，即作用量的最小单元。

**定理2.2.1（$\hbar$是分形迭代的基本作用量子）**：约化普朗克常数$\hbar$是分形迭代每一步的基本作用量，即分形螺旋每旋转一周的作用量：
$$\hbar = \oint p dx$$
其中积分是沿闭螺旋轨道的积分，这个积分是拓扑不变量，等于螺旋的缠绕数乘以基本作用量子。

**几何解释**：分形迭代是离散的，每一步迭代对应一个最小的作用量单元，这就是$\hbar$。就像螺旋每转一圈有一个固定的角动量一样，分形螺旋每转一圈的作用量是固定的，就是$\hbar$。这解释了为什么作用量是量子化的——因为分形迭代是离散的，作用量只能是$\hbar$的整数倍。

在自然单位制中，我们定义$\hbar=1$，这是因为我们选择角动量单位使得螺旋的基本角动量为1。在国际单位制中，$\hbar=1.054571817\times10^{-34}J\cdot s$，这个数值同样是单位定义的结果，因为焦耳和秒都是人为定义的单位。

**命题2.2.1（不确定关系的几何起源）**：海森堡不确定关系$\Delta x\Delta p\geq\hbar/2$是分形结构的必然结果。因为分形上的点不是精确的点，而是有最小尺度（普朗克长度）的分形元，位置和动量不能同时精确测量，它们的不确定度乘积至少为$\hbar/2$。

不确定关系不是测量仪器的限制，而是时空本身的分形性质：在普朗克尺度下，时空不是光滑的点，而是分形结构，不存在精确的位置或动量，这是几何上的不确定，不是认识论的不确定。

## 2.3 $c$和$\hbar$作为单位转换因子

$c$和$\hbar$本质上是单位转换因子，它们将不同的物理量联系起来：
- $c$将时间和长度联系起来：$长度 = c\times时间$
- $\hbar$将能量和时间联系起来：$能量 = \hbar/时间$
- $c$和$\hbar$一起将质量和长度联系起来：$质量 = \hbar/(c\times长度)$

在自然单位制中，这些转换因子都是1，因此时间、长度、质量、能量的倒数都用同一个单位测量，这大大简化了物理公式。

**命题2.3.1（常数的定义性）**：$c$和$\hbar$现在都是国际单位制中的定义常数，它们的数值是精确的，没有误差：
- 光速$c=299792458m/s$（精确值，1983年定义）
- 约化普朗克常数$\hbar=1.0545718176461565\times10^{-34}J\cdot s$（精确值，2019年国际单位制修订后定义）

因此，我们不需要"推导"$c$和$\hbar$的数值，因为它们是定义出来的。我们需要推导的是无量纲常数，它们不依赖于单位选择，是真正的物理常数。

## 2.4 波粒二象性的几何起源

$c$和$\hbar$一起给出了波粒二象性：所有粒子都同时具有波动性和粒子性。

**命题2.4.1（德布罗意关系）**：德布罗意关系$p=\hbar k$，$E=\hbar\omega$是分形螺旋的直接结果。分形螺旋的波矢$k=2\pi/\lambda$对应动量，角频率$\omega=2\pi/T$对应能量，它们的比值是$\hbar$，因为螺旋每转一圈的作用量是$\hbar$。

粒子性来自分形螺旋的局域性（拓扑残差是局域的点缺陷），波动性来自螺旋的转动（螺旋转动产生波），因此波粒二象性是分形螺旋结构的自然表现，不是神秘的量子性质。

## 2.5 本章小结

本章我们解释了$c$和$\hbar$的几何意义：$c$是超复数流形的内禀旋度速度，是波动方程的传播速度；$\hbar$是分形迭代的基本作用量子，是螺旋每转一圈的作用量。这两个常数现在都是国际单位制中的定义常数，数值精确，没有误差，它们本质上是单位转换因子，不是需要测量的物理常数。真正需要推导的是无量纲常数，下一章我们将推导第一个有量纲但非定义的常数：万有引力常数$G$。
