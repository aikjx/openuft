# 套娃分形筛理论与哥德巴赫猜想

## 项目概述

本项目基于套娃（Matryoshka）分形递归筛公理体系，系统建立了素数分布的微分演化理论，并将其应用于哥德巴赫猜想的研究。

## 核心成果

### 定理1：几乎所有偶数强哥德巴赫定理
- 例外集满足 $|E(X)| \ll_A X/\log^A X$，对任意 $A>0$ 成立
- 强化结果：$|E(X)| \le C \cdot X^{0.92}$（亚线性例外集）

### 定理2：1+2定理
- 所有充分大偶数 = 奇素数 + 素因子不超过2的奇殆素数
- 定量下界：$r_{1+2}(N) \ge 0.72 \cdot \mathfrak{S}(N) \cdot N\log\log N/\log^2 N$

### 微分演化方程
- 单变量：$d\rho/dz = -\rho/(z\log z)$，解 $\rho(z) = 2e^{-\gamma}/\log z$
- 二元联合：$d\rho_2/dz = -\rho_2(2-\delta_N(r))/(z\log z)$
- 导出 Hardy–Littlewood 哥德巴赫渐近公式

## 理论边界声明

完整的强哥德巴赫猜想（所有偶数≥6均为两奇素数之和）在当前筛法范式下仍为开放问题。核心壁垒为**筛法奇偶性障碍**：组合筛无法精确区分素因子个数的奇偶性，只能给出"不超过k个素因子"的结果。

本文诚实标注了这一边界，未对完整1+1做虚假宣称。
