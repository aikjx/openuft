## 路线一：含挠率的作用量 → 场方程 → PPN参数 → 实验对比

### 1.1 几何框架：Riemann-Cartan 时空

在 Riemann-Cartan 几何中，仿射联络 Gamma^lambda{}_{munu} 不再对称，挠率张量定义为：

`T^lambda{}_{munu} equiv Gamma^lambda{}_{munu} - Gamma^lambda{}_{numu}`

联络可分解为 Levi-Civita 部分与 contortion（扭率）张量之和：

`Gamma^lambda{}_{munu} = mathring{Gamma}^lambda{}_{munu} + K^lambda{}_{munu}`

其中 mathring{Gamma} 是无挠 Christoffel 符号，contortion 张量为：

`K^lambda{}_{munu} = frac{1}{2}left(T^lambda{}_{munu} - T_mu{}^lambda{}_nu - T_nu{}^lambda{}_muright)`

### 1.2 挠率的不可约分解

在 Lorentz 群下，挠率张量分解为三个不可约分量：

| 分量 | 定义 | 自由度 |
| --- | --- | --- |
| 矢量挠率 V_mu | `V_mu = T^lambda{}_{lambdamu}` | 4 |
| 轴矢挠率 A^mu | `A^mu = frac{1}{6}epsilon^{munurhosigma}T_{nurhosigma}` | 4 |
| 纯张量部分 q^lambda{}_{munu} | 满足 `q^lambda{}_{lambdamu}=0,; epsilon^{munurhosigma}q_{nurhosigma}=0` | 16 |

完整分解式：

`T_{lambdamunu} = frac{1}{3}(g_{lambdamu}V_nu - g_{lambdanu}V_mu) + epsilon_{lambdamunusigma}A^sigma + q_{lambdamunu}`

### 1.3 最一般的含挠率拉氏量

曲率标量与无挠部分的关系为：

`R(Gamma) = mathring{R} + mathring{nabla}_mu(K^{mulambda}{}_lambda - K^{lambdamu}{}_lambda) - K_{munulambda}K^{lambdamunu} + K_{mulambda}{}^lambda K_{nu}{}^{munu}`

利用不可约分解，拉氏量中的挠率二次项可写为：

`mathcal{L}_{text{torsion}} = a_1 V_mu V^mu + a_2 A_mu A^mu + a_3 q_{lambdamunu}q^{lambdamunu}`

最一般的宇称守恒引力拉氏量（含宇宙学常数）：

`boxed{mathcal{L} = frac{1}{2kappa}left[mathring{R} - 2Lambda + a_1 V_mu V^mu + a_2 A_mu A^mu + a_3 q_{lambdamunu}q^{lambdamunu}right] + mathcal{L}_{text{matter}}(e^a{}_mu, omega^{ab}{}_mu, psi)}`

其中 `kappa = 8pi G/c^4`。

Einstein-Cartan (EC) 理论是特殊情况：`a_1 = -frac{2}{3},; a_2 = frac{3}{2},; a_3 = -frac{2}{3}`（这些系数使得拉氏量等于 `frac{1}{2kappa}R(Gamma)`）。

### 1.4 变分与场方程

采用四维标架 (tetrad) 形式，令 `e^a{}_mu` 为标架场，`omega^{ab}{}_mu` 为自旋联络。作用量为：

`S = frac{1}{2kappa}int d^4x, |e|, R(e, omega) + S_{text{matter}}`

对 `e^a{}_mu` 变分（能量-动量场方程）：

`G_{munu}(Gamma) = kappa, Sigma_{munu}`

其中 Sigma_{munu} 是正则（非对称）能量-动量张量。

对 `omega^{ab}{}_mu` 变分（挠率/自旋场方程）：

`T^lambda{}_{munu} + delta^lambda_mu T^rho{}_{rhonu} - delta^lambda_nu T^rho{}_{rhomu} = kappa, s^lambda{}_{munu}`

其中 `s^{lambda}{}_{munu}` 是物质的自旋角动量密度：

`s^{lambda}{}_{munu} = frac{1}{|e|}frac{delta mathcal{L}_{text{matter}}}{delta omega^{ab}{}_lambda}, e^a{}_mu, e^b{}_nu`

关键性质：**挠率方程是代数的，不是微分的。挠率不传播，它局域地由自旋密度决定。**

### 1.5 Einstein-Cartan 理论的精确求解

对于 EC 的特殊系数，挠率方程的解为：

`T_{lambdamunu} = frac{kappa}{2}left(s_{lambdamunu} - s_{mulambdanu} + s_{nulambdamu} + g_{lambdamu}s^rho{}_{rhonu} - g_{lambdanu}s^rho{}_{rhomu}right)`

Dirac 场的自旋密度：

`s_{lambdamunu} = frac{1}{2}epsilon_{lambdamunusigma},bar{psi}gamma^sigma gamma_5psi = frac{1}{2}epsilon_{lambdamunusigma},J_5^sigma`

代入得到挠率的显式解：

`T_{lambdamunu} = frac{kappa}{4},epsilon_{lambdamunusigma},J_5^sigma`

即挠率完全由轴矢挠率分量贡献：`A^sigma = frac{kappa}{8}J_5^sigma`。

### 1.6 有效拉氏量——四费米子接触相互作用

将挠率解代回作用量，挠率的二次项变成自旋密度的四次项：

`mathcal{L}_{text{eff}} = frac{1}{2kappa}mathring{R} + mathcal{L}_{text{Dirac}}(mathring{omega}) + mathcal{L}_{text{4-fermi}}`

其中四费米子相互作用项为：

`boxed{mathcal{L}_{text{4-fermi}} = -frac{3kappa}{16}left(bar{psi}gamma^mugamma_5psiright)left(bar{psi}gamma_mugamma_5psiright) = -frac{3pi Ghbar^2}{c^3}left(J_5^mu J_{5mu}right)}`

这是 Einstein-Cartan 理论的核心预言：引力通过挠率产生自旋-自旋接触相互作用。

与弱中性流对比：

`mathcal{L}_{text{weak}} = -frac{G_F}{2sqrt{2}},J_mu^{NC}J^{mu,NC}`

等效耦合常数之比：

`frac{G_{text{torsion}}}{G_F} = frac{3pi Ghbar^2}{G_F c^3} approx left(frac{E}{E_{text{Planck}}}right)^2`

在低能下（E ll E_{text{Planck}} sim 10^{19}text{ GeV}），挠率效应极度被压低。

### 1.7 后牛顿展开与 PPN 参数

其中 U 是牛顿引力势，Phi_1–Phi_4、V_i、W_i 是标准后牛顿势函数。

挠率的量级估计：对于普通天体（太阳系），自旋密度的量级为

`s sim rho cdot v cdot hbar / (m_p c) sim rho cdot frac{v}{c} cdot lambda_C`

其中 lambda_C 是质子的 Compton 波长。自旋密度对能量-动量张量的贡献为：

`Delta T_{munu} sim kappa s^2 sim kappa rho^2 left(frac{v}{c}right)^2 lambda_C^2 sim rho c^2 cdot left(frac{rho}{rho_{text{Planck}}}right)left(frac{v}{c}right)^2`

结论：在 Einstein-Cartan 理论中，挠率对 PPN 参数的修正量级为

`boxed{Deltagamma sim Deltabeta sim Oleft(frac{rho}{rho_{text{Planck}}}right) sim 10^{-94} quad (text{太阳系})}`

这远远低于任何可观测水平。

## 路线二：Kaluza-Klein → 4D引力+电磁 → 为什么需要超对称

### 2.1 5D Einstein-Hilbert 作用量

从五维纯引力出发：

`S_5 = frac{1}{2hat{kappa}}int d^5x,sqrt{|hat{g}|},hat{R}`

其中 `hat{kappa} = 8pi hat{G}/c^4`，hat{G} 是五维引力常数。

5D 度规的 Kaluza-Klein 拟设（cylinder 条件：partial_5(·) = 0）：

`dhat{s}^2 = hat{g}_{AB},dx^A dx^B = g_{munu},dx^mu dx^nu + phi^2(dy + kappa A_mu dx^mu)^2`

写成分块矩阵：

`hat{g}_{AB} = begin{pmatrix} g_{munu} + phi^2 kappa^2 A_mu A_nu & phi^2 kappa A_mu \ phi^2 kappa A_nu & phi^2 end{pmatrix}`

其中：g_{munu}(x) — 4D 度规（引力子）；A_mu(x) — 矢量场（光子）；phi(x) — 标量场（radion/dilaton）；`y in [0, 2pi R)` — 紧致第五维坐标。

行列式：`sqrt{|hat{g}|} = sqrt{|g|},phi`

### 2.2 5D Christoffel 符号的计算

利用 `partial_5 hat{g}_{AB} = 0` 逐一计算（定义 `F_{munu} = partial_mu A_nu - partial_nu A_mu`）：

`hat{Gamma}^lambda{}_{munu} = mathring{Gamma}^lambda{}_{munu} + frac{1}{2}phi^2kappa^2(F^lambda{}_mu A_nu + F^lambda{}_nu A_mu) + phi^{-1}(partial^lambdaphi, g_{munu} - delta^lambda_mupartial_nuphi - delta^lambda_nupartial^lambdaphi) cdot (cdots)`

关键的非零分量：

`hat{Gamma}^5{}_{munu} = frac{1}{2}kappaphi^2(nabla_mu A_nu + nabla_nu A_mu) + kappa A_lambda hat{Gamma}^lambda{}_{munu} + A_mupartial_nuphi + A_nupartial_muphi`

`hat{Gamma}^lambda{}_{mu 5} = frac{1}{2}kappaphi^2 F^lambda{}_mu + phi^{-1}delta^lambda_mu partial_5phi = frac{1}{2}kappaphi^2 F^lambda{}_mu`

`hat{Gamma}^5{}_{mu 5} = phi^{-1}partial_muphi`

`hat{Gamma}^lambda{}_{55} = -phi,partial^lambdaphi`

### 2.3 5D Ricci 标量的分解

经过系统计算（利用 `hat{R} = hat{g}^{AB}hat{R}_{AB}`），得到标准结果：

`boxed{hat{R} = R^{(4)} - frac{1}{4}phi^2kappa^2 F_{munu}F^{munu} + frac{2}{phi}mathring{Box}phi - frac{2}{phi^2}partial_muphi,partial^muphi}`

其中 R^{(4)} 是由 g_{munu} 计算的 4D Ricci 标量，mathring{Box} 是 4D 协变 d'Alembert 算子。

### 2.4 降维后的有效作用量

将 `sqrt{|hat{g}|} = sqrt{|g|},phi` 和 hat{R} 代入 S_5，对 y 积分（int_0^{2pi R}dy = 2pi R）：

`S_4 = frac{2pi R}{2hat{kappa}}int d^4x,sqrt{|g|}left[phi R^{(4)} - frac{1}{4}phi^3kappa^2 F_{munu}F^{munu} + 2mathring{Box}phi - frac{2}{phi}partial_muphi,partial^muphiright]`

`S_4 = frac{2pi R}{2hat{kappa}}int d^4x,sqrt{|g|}left[phi R^{(4)} - frac{1}{4}phi^3kappa^2 F_{munu}F^{munu} - frac{2}{phi}partial_muphi,partial^muphiright]`

### 2.5 冻结标量场 → Einstein-Maxwell 理论

原始 Kaluza-Klein 简化：令 `phi = text{const} = 1`（紧致化半径不变），定义 `M_{text{Pl}}^2 = frac{2pi R}{hat{kappa}}`：

`S_4 = int d^4x,sqrt{|g|}left[frac{M_{text{Pl}}^2}{2}R^{(4)} - frac{M_{text{Pl}}^2kappa^2}{8}F_{munu}F^{munu}right]`

`boxed{kappa = frac{2sqrt{G}}{c^2sqrt{epsilon_0}} approx 5.1times10^{-18}text{ (SI)}^{1/2}}`

### 2.7 Kaluza-Klein 的质量谱

如果第五维是半径为 R 的圆 S^1，场可以 Fourier 展开：

`Phi(x, y) = sum_{n=-infty}^{infty}phi_n(x),e^{iny/R}`

代入 5D Klein-Gordon 方程 hat{Box}Phi = 0：

`left(Box^{(4)} - frac{n^2}{R^2}right)phi_n = 0`

第 n 阶 Kaluza-Klein 模的有效质量：

`m_n = frac{|n|hbar}{Rc}`

若 `R sim l_{text{Planck}} sim 10^{-35}text{ m}`，则 `m_1 sim M_{text{Planck}}/c^2 sim 10^{-8}text{ kg} sim 10^{19}text{ GeV}` —— 远超加速器能量，解释了为什么只看到零模（n=0）。

### 2.8 为什么纯引力 KK 不能装入强、弱力

**问题一：规范群的维度要求**

要把标准模型规范群 `G_{text{SM}} = SU(3)_C times SU(2)_L times U(1)_Y` 从纯引力的高维微分同胚获得，需要紧致空间的等距群 `text{Isom}(K) supset G_{text{SM}}`。

`dim G_{text{SM}} = 8 + 3 + 1 = 12`

最小需要的紧致流形维度 `d geq 12`（因为 d 维流形的最大等距群维度为 d(d+1)/2，但实际可用的连续等距群小得多）。总维度至少 `4 + 12 = 16`。

**问题二：手征费米子不可能（Witten no-go 定理, 1981）**

Witten 证明：在光滑紧致流形上，纯高维引力的维数约化不可能产生 4D 手征费米子。原因：高维 Dirac 算子在偶数维紧致流形上的零模总是矢量型的（左手和右手零模成对出现），而弱相互作用要求手征费米子（SU(2)_L 只耦合左手费米子）。这意味着：无论紧致空间多复杂，纯 KK 引力无法解释宇称破缺的弱力。

**问题三：耦合常数不统一**

KK 理论中，每个规范耦合由对应的紧致化半径决定：`g_{text{YM}}^2 sim frac{hat{G}}{R^{d_{text{gauge}}}}`。不同规范群因子需要不同的 R，没有机制保证它们在某一能标统一。
