## E1 标准定理（观测与理论基准）

- **Carnot 上界**：任意热机效率不超过可逆 Carnot 界
  $$\eta_C = 1 - \frac{T_c}{T_h}$$
  与工作物质（经典或量子）无关，是热力学第二定律的定理性输出。
- **Curzon-Ahlborn 最大功率效率**（端到端、不可逆但稳态工作）：
  $$\eta_{CA} = 1 - \sqrt{\frac{T_c}{T_h}}$$
  对应最大功率点，介于 η_CA 与 η_C 之间。
- **量子 Otto 循环**（三能级 / 谐振子，绝热膨胀-压缩，频率比 $\omega_h/\omega_c = T_h/T_c$）：
  $$\eta_{Otto} = 1 - \frac{\omega_c}{\omega_h}$$
  可逆极限下回到 Carnot 界。以上均为标准量子热力学闭式（引用，不复算）。

## E2 核心公式第一性推导 + 精算

基准 $T_h=300\ \mathrm{K}$、$T_c=100\ \mathrm{K}$，温度比 $r=T_c/T_h=1/3$。

```
η_C   = 1 − T_c/T_h        = 1 − 1/3 = 2/3（Fraction 精确）
η_CA  = 1 − √(T_c/T_h)     = 1 − 1/√3
η_Otto= 1 − ω_c/ω_h        = 1 − 1/3 = 2/3（可逆 = Carnot）
```

## E3 解析求导验证（用户指定「求导证明」线）

令 $r=T_c/T_h$，$x=\omega_c/\omega_h$。

```
dη_CA/dr  = −1/(2√r)  < 0        （η_CA 随 r 单调递减）
dη_C/dr   = −1                 （常数斜率，线性）
dη_Otto/dx= −1                 （常数斜率，线性）
```

r = 1/3 处：

```
dη_CA/dr = −1/(2√(1/3)) = −√3/2 = −0.866025403784438646763723170753…
```

- 单调性结论：冷源相对热源越热（r↑），效率界越低；η_CA 降幅随 r 增大而趋缓（凹函数）。
- 线性结构：Carnot 与可逆 Otto 对各自比量的斜率恒为 −1，与温度/频率绝对值无关。
