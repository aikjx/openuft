## 1. 全维分析的方法论

本归档沿用 openuft 的评级口径，对每一个子系统给出四维判定：

| 维度 | 含义 |
|------|------|
| **H**（Healthy，可信地基） | 数学自洽、可独立验证、无循环依赖 |
| **O**（Open，诚实边界） | 欠定 / 依赖经验锚 / 自承为边界假设 |
| **C**（Conflict，缺陷/冲突） | 内部不自洽、循环论证、数值与文献矛盾 |
| **U**（Unexpanded，未展开） | 仅提出框架、未推导、未验证 |

层级（L0–L3）：

- **L0** 恒等/同义反复（如 cos²+sin²=1）
- **L1** 概念重述或参数化（把已知量换成几何符号）
- **L2** 部分推导（依赖若干外部锚或假设）
- **L3** 第一性推导 / 可检验预言（本体系**极少**达到）

判定结果沿用四态：`PASS`（自洽）、`BOUNDARY`（边界/条件成立）、`INFO`（信息性）、`FAIL`（已证伪/循环）。

> **红线**：数学自洽 ≠ 实验证实。本体系大量结论属于「精算通过但依赖实验锚（α、c、G、ℏ、e）」的几何重排，并非由第一性原理独立推出。原文献自身已多处声明循环依赖、`ρ` 无独立来源、高阶力缺可观测验证等局限，本归档照实收录，不粉饰。

## 4. 已登记的跨体系冲突（必读）

1. **N 定义不一致**：定义 A `N=1/[α²(1−α)]≈18916.9` 与定义 B `N=1/α²+1/α+1+α≈18907` 在多文献并存，数值差约 10。
2. **G 循环论证**：`G=α²μ₀c²ρ²` 中 `ρ` 由 G 反推，差值恒为 0 是代数恒等式而非物理推导。
3. **ρ 无独立来源**：螺旋半径 `ρ≈3.33×10⁻⁹ m` 由 G 反解得到。
4. **α 拓扑本源未闭合**：`α=sin(1/(N+Δ_top))` 要求 N=137 由拓扑本征值推出，目前仍属目标而非已证结论。
5. **文献内部数值不自洽**：拓扑绕数推导 `tanθ=√N`（=√137≈11.7）与主体 `α=tanθ=1/137` 数值矛盾。
