# 附录　术语、载体索引与时点号段

## A　术语表（本书用法的窄定义）

| 术语 | 本书的定义 | 不是什么 |
|---|---|---|
| **来料** | 用户粘贴进本项目的外部理论文稿，代号 ROOT V\<N\> | 不是「文献综述」意义上的参考文献 |
| **正本** | 来料的逐字留档件，审计期间只读，字节与 md5 被闸门自证 | 不是「整理版」「摘要版」 |
| **判定面／判定册** | 一卷的判决台账 `判定/判定_TUFT-r*.md` | 不是论文，不承担叙述功能 |
| **条目** | 一条机读判据（A/B/G/C/E/P/O 之一） | 不是「成果」；不可跨层相加 |
| **判决** | G 层条目：这条主张是否构成预言 | 不是「来料有没有算错」 |
| **变异体** | 具名的改坏方案：改 X 后本判据必须不再成立 | 不是「测试覆盖率的装饰」 |
| **判别力** | 该判据能否区分不同结果；双射⇒0 bit | 不是「精度」 |
| **占度** | 该构造满足成立所需条件槽的比例；0/5 ⇒ 不占度 | 不是「完成度」 |
| **供给** | 可入池的第一性输出条数 | 不是 PASS 条数 |
| **半 ulp** | 一个**印刷字段**最后一位的一半，是该字段自身的属性 | 不是双精度的 eps |
| **传播容差** | 输入字段半 ulp 经条件数放大后的容差 | 不是被比较字段自己的宽度 |
| **坐标伪影** | 随变量定义改变而改变的数值断言 | 不是「坐标系选择」这一合法自由 |
| **自由除数** | 关键整数住在定义因子裡（$L=\hbar/k$） | 不是「参数拟合」那样有约束的东西 |
| **codim-3** | 三个独立标量约束刻出的状态子流形，测度零 | 不是理论的参数空间维数 |
| **不裁定（BOUNDARY）** | 缺输入 ⇒ 未算 | 不是「错」，也不是「对」 |
| **三面收口** | 登记行／stdout／判定册之间只比值不串 | 不是「三处都写了同一个字符串」 |
| **现扫／只作当下观察** | 该数由某台仪器在某时刻印出，可能被并发落地移动 | 不是承诺永久成立 |
