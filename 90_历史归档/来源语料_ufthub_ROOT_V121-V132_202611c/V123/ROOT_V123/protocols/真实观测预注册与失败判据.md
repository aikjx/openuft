# ROOT V123/V124 真实观测预注册协议（待执行，非观测报告）

## 假设

- H0：广义相对论/牛顿重力（选定统一的地球引力模型及相对论修正），无额外 Yukawa。
- H1：同一背景+固定 α_Y=1/3、λ=124600 m（不事后重新拟合）、指定 Fayet 近似球对称密度外场。若未来考虑非球形源，在同一观测和数据质量下另立 H1b，不混作同一“无自由参数”模型。
- 归一化和参考 G：同时明确实验室 G_lab 与长程 G_inf 的含义；地球 μ=GM 与绝对质量 M 不得混作独立已知参数。

## 不得遗漏的观测变量

轨道及重力梯度测量的时间戳、坐标参考系、姿态、星载加速度计、GPS 定轨、卫星间测距、太阳辐射压、热/气动扰动、地球固体潮及海潮、质量重新分布、重力多极及协方差、仪器偏置与长期漂移、时钟对时。

## 数据划分

- 预先确定训练窗口（建模与背景约束）与留出窗口（在模型参数冻结后验证）。
- 不能将同源卫星数据的合成重力模型再算作独立观测；需记录共享数据和协方差来源。
- 必须公开 raw/processed 数据 DOI/hash，处理脚本版本、模型误差、缺失和异常值处理。

## 统计判据

- 比较 H0/H1 的完整轨道残差 GLS/贝叶斯模型证据，允许**相同**的 nuisance 变量拟合而不单方面给予更大自由度。
- 检查 nuisance 与 Yukawa 模板的 Fisher 退化；不能辨识则报告不可辨识。
- 以独立时间段、高度或不同任务进行预先指定的外部验证。
- 只有真实观测与可审查的系统误差链俱全，才能作出“排除”、“支持”或“无结论”的统计裁定。未执行前持续标注 OPEN。

## 失败即失败

- 如果固定模型无法通过预注册的留出验证，应标记“固定 α=1/3、λ=124.6 km 候选失败”，不可改变 λ、引入新的屏蔽或调整地球密度当作同一次盲测通过。
- 任何事后改写需要注册为新理论版本并重新独立验证。
