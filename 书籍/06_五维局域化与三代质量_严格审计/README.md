## 一 这本书在做什么

一条链子在 2026-11-02 至 11-03 三天里被反复推进：

$$\text{五维作用量}\;\longrightarrow\;\text{手征零模 }f_L,f_R\;\longrightarrow\;\text{质量重叠 }m\; \longrightarrow\;\text{KK 耦合 }a_n\;\longrightarrow\;\text{谱塔 }S\;\longrightarrow\;\text{味改变 }Q_{\alpha\beta}\;\longrightarrow\;\text{实验边界}$$

每一步都有人算过，每一步都留下过数字。但**没有一件产物把它当成一个整体来审**：哪一步是恒等式，哪一步是模型约定，哪一步是反演，哪一步是预测——四者混在同一个"已验证"字样之下，正是本项目最常抓的病。

本书做四件事：

1. **把链子串起来**，用统一记号重写九个公式，使每个常数都有出处、每个符号都有定义域；
2. **把每条结论贴上身份标签**：`[恒等]`（可证、与输入无关）、`[模型]`（依赖约定）、`[反演]`（先有数据后有参数）、`[未证]`（提案）；
3. **把三代问题单独抽出来**，给出两条**严格**的定理（简并定理、计数定理）与一个**判别器**（形状敏感性），并明说它们各自只杀掉什么、没杀掉什么；
4. **把四力问题摆在正确的位置**：它是本书的**边界**，不是本书的结论。

**本书不宣称四力统一，不宣称量子引力，不宣称三代质量已被预测。** 这句话不是免责声明，是全书最硬的结论之一——第八、九、十章的全部工作就是为了让它可核。

## 四 本书的六条诚实边界

1. **链条的起点仍是输入**。五维作用量、手征边界条件、Higgs 沿第五维的分布、`y_*=1`、`v=246.22 GeV`——全部是**写进去的**，不是推出来的。本书审的是"从这些输入到那些数字"是否成立，不是"这些输入是否对"。

2. **"重建"一律是反演，不是预测**。三代 `z_i` 由三代质量反解（`brentq`），三步都隐含同一个 `v`；`δv/v=8.9e-4` 就足以把 `z_i` 推开 1e-4 量级。任何把 `z_i` 称为"被求出的本征值"的说法，本书一律判为 `[反演]`。

3. **谱塔恒等式是标准数学，不是新定理**。`S=π²·Gram(H)` 是 `L²[0,1]` 正弦基的 Parseval 恒等式（高斯 profile 对照 `3.33e-16` 证实其与形状无关）；它的价值在**可算**，不在**新颖**。本书把它列为 `[恒等]`，并在正文中如实写明这是"标准工具升级"。

4. **"20 万模"没有独立信息**。`a_n n²→4√2z²/π²` ⇒ 尾部 `~n⁻⁶`；`N=10000` 与 `N=200000` 逐位相同。任何报告"大 N 模求和已收敛"的地方，必须附截断表；不附的，本书视为装饰。

5. **三代问题只有两条严格定理与一个判别器**。简并定理（味普适 λ ⇒ 三代全同）与计数定理（3 个 λ ⇔ 3 个质量，自由度不变）都只说明"现有写法不预测"；它们**不排除**味依赖 λ、非平凡 Yukawa、多标量、bulk Higgs、拓扑机制（六维磁通指标定理走的就是最后一条，且它把 3 个连续参数压成 1 个整数，仍未归零）。形状判别器说明 `S` 是 `Φ` 形状的泛函，这只是**可观测通道**，不是**预测**。

6. **四力是边界，不是结论**。本书第八章只做一件事：把"我们有的两条链"与"四力统一需要的结构"逐项并排，指出缺口在哪。它不给统一方案，也不暗示"快到了"。判词末段 `NO_FOUR_FORCE_UNIFICATION` 是本书的正式结论，不可删改。
