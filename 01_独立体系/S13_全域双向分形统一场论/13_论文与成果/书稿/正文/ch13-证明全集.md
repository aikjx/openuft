## 13.3 定理与证明

【 **定理 13.1（流守恒）** :$\sigma^{\mu}\partial_{\mu}\Psi = \lambda\Theta\Psi^{*} \Rightarrow \partial_{\mu}J^{\mu} = 0$，$J^{\mu} = \Psi^{\dagger}\sigma^{\mu}\Psi$。

证明：$\partial_{\mu}J^{\mu} = 2\,\mathrm{Re}\left( \Psi^{\dagger}\sigma^{\mu}\partial_{\mu}\Psi \right) = 2\lambda\,\mathrm{Re}\left( \Psi^{\dagger}\Theta\Psi^{*} \right)$；而 $\Psi^{\dagger}\Theta\Psi^{*} = -\psi_{0}^{*}\psi_{1}^{*} + \psi_{1}^{*}\psi_{0}^{*} = 0$。$\blacksquare$（数值：实验一，漂移 $2.1\times10^{-13}$。）】

【 **定理 13.2（维数选择）** :$\hat\Psi : \mathbb{R}^{d} \to S^{2}$ 的拓扑荷定义域必须满足 $\pi_{d}\left( S^{2} \right) \neq 0$；物理上有 $\pi_{1}\left( S^{2} \right) = 0$、$\pi_{3}\left( S^{2} \right) = \mathbb{Z}$。

证明：$\pi_{1}\left( S^{2} \right) = 0$ 是 $S^{2}$ 单连通的经典结果；$\pi_{3}\left( S^{2} \right) = \mathbb{Z}$ 是霍普夫纤维化 $S^{3} \to S^{2}$ 的同伦群计算（长正合列：$\pi_{3}\left( S^{1} \right) = 0 \to \pi_{3}\left( S^{3} \right) = \mathbb{Z} \to \pi_{3}\left( S^{2} \right) \to \pi_{2}\left( S^{1} \right) = 0$）。$\blacksquare$（数值：实验九，1D 绕数 $1\to0$ 突变。）】

【 **定理 13.3（荷整性）** :光滑、无穷远归一化的 $\hat\Psi$ 的霍普夫荷为整数。

证明：$Q_{H} = \frac{1}{4\pi^{2}}\int\epsilon^{ijk}a_{i}\partial_{j}a_{k}$ 是霍普夫不变量 $H$ 的联络表示；$H$ 是同伦类 $\pi_{3}\left( S^{2} \right) = \mathbb{Z}$ 的计数，故 $Q_{H} \in \mathbb{Z}$。$\blacksquare$（数值：实验十一，$Q_{H} = 1.000$ / $3.79$；实验十二约束下保持 $10^{-3}$ 级。）】

【 **定理 13.4（约束守恒）** :$|\Psi|^{2} = v^{2} \Rightarrow \mathrm{d}Q_{H}/\mathrm{d}t = 0$。

证明：约束下 $\hat\Psi$ 处处良定义且连续，时间演化 $t \mapsto \hat\Psi\left( \cdot, t \right)$ 是同伦；同伦不变 $Q_{H}$ 恒定。反之无约束时 $\min|\Psi| \to 0$ 使 $\hat\Psi$ 在节点处无定义，同伦类可跳变。$\blacksquare$（数值：实验十二——线性动力学 $Q_{H}$ 从 $+0.875$ 跳至 $-0.162$，约束下保持。）】

【 **定理 13.5（曲率有界）** :见第12章推导 12.7。$\left| R \right|_{\max} = \left( 3+2\sqrt{2} \right)GM/\left( 2\ell^{3} \right)$，位置 $r = \left( \sqrt{2}\pm 1 \right)\ell$。$\blacksquare$（数值：实验六，$2.9142135624$ vs $2.9142135543$。）】

【 **定理 13.6（畴守恒）** :$\frac{\mathrm{d}}{\mathrm{d}t}\int_{\mathcal{C}}\omega = \oint_{\partial\mathcal{C}}\Theta$。

证明：$\frac{\mathrm{d}}{\mathrm{d}t}\int_{\mathcal{C}}\omega = \int_{\mathcal{C}}\partial_{t}\omega = \int_{\mathcal{C}}\mathrm{d}\left( \mathrm{i}_{v}\omega \right) - \int_{\mathcal{C}}\partial_{\mu}J^{\mu} = \oint_{\partial\mathcal{C}}\Theta$，末步用 T1。$\blacksquare$（数值：实验八，残差 $8.4\times10^{-14}$。）】

【 **定理 13.7（希格斯谱）** :有效势 $V = \kappa\left( |\Psi|^{2} - v^{2} \right)^{2}$ 在真空点的谱 $\{0,0,0,8\kappa v^{2}\}$，且 $\dim\ker M = 1$（未破缺 $U(1)$）。

证明：径向/方向分离 $\Psi = \left( v + h \right)\hat\Psi$，$V \simeq 4\kappa v^{2}h^{2}$ 给 $m_{H}^{2} = 8\kappa v^{2}$，方向自由度零模；$\mathrm{u}(2)$ 生成元作用真空仅整体相位方向零。$\blacksquare$（数值：实验十四/十五，$[0,0,0,8]$ 与零空间维数 $1$。）】
