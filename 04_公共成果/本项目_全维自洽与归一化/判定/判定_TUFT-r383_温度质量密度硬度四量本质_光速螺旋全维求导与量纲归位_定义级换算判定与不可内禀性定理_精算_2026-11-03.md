## 一、结论摘要

用户命题要求「攻破四量本质」。本卷的答案是：**这四个量在 `v_总=c` 框架里不是四个对象，而是同一个几何量 `ω` 的四种单位换算**；其中两个（质量、温度）**只依赖 `ω`**，另两个（密度、硬度）**额外依赖一个自由参数 `θ`**，因而对后者是**满射**、零预测力。

| 主张 | 裁定 | 依据 |
|---|---|---|
| 四量可由 `ω` 与 `θ` 完全参数化（同源） | **成立**（结构陈述） | A07、A11、A12、G01、G07 |
| 质量 = 世界线总曲率（`m=(ħ/c)√(κ²+τ²)`） | **成立，但为定义级重述** | A07（残差 0） |
| 温度 = 质量（同一钟速的两种单位），`T/m=c²/k_B` | **成立，但为定义恒等式** | A08、A09、B05 |
| Unruh 温度与康普顿温度之比 `= sinθ/(2π)` | **成立（本卷新导的恒等式）** | A10、B04 |
| 密度可内禀定义 | **不成立**（无内禀体积） | G03 |
| 硬度可内禀定义 | **不成立**（量纲归位 + 口径依赖 + 统计量） | G04、A16、A17 |
| 框架能给出分立质量谱 | **不成立**（`ω↦m` 双射 ⇒ 谱连续） | B07、B08、G02 |
| 本卷给出可证伪独有预言 | **不成立**（0 条） | G06 |

**一句话**：`v_总=c` 把「质量」压成「转得多快」，把「温度」压成「同一个转得多快」，然后**把「密度」和「硬度」留在一个不被几何固定的体积里**——而这体积在 V28 构造里连「尺寸」都不是，它是积分常数。所以「本质」确实被攻破了，但攻破的方式是否证：**四量不是四个本质，是一个本质的四次换单位，外加同一个缺口的三次复现**。

## 二、全维求导（A01–A06）

设定 `r(t)=(R cos ωt, R sin ωt, u t)`、`R²ω²+u²=c²`。在 **6 个有理相位 × 4 组勾股族 = 24 例**上做精确有理核验（Fraction，无浮点）：

| 量 | 判据（两条不共享中间量的路径） | 残差 |
|---|---|---|
| 速度模方 | 分量求和 `R²ω²+u²` 对 `c²` | **0** |
| 加速度 | 分量式 `a` 对 `−ω²(x,y,0)` | **0** |
| 曲率 | 叉积路径 `\|v×a\|²/\|v\|⁶` 对闭式 `(Rω²/c²)²` | **0** |
| 挠率 | `(v×a)·ȧ/\|v×a\|²` 对闭式 `uω/c²` | **0** |
| 三重奏 | `κ²+τ²` 对 `(ω/c)²` | **0** |
| 螺旋角 | 叉积得的 `(κ/\|τ\|)²` 对几何式 `(Rω/u)²` | **0** |

★ 残差是**精确 0**，不是 1e−16 级的「机器零」。**差分只能证伪不能证零**，故本卷不用差分，全部走叉积与闭式的代数比对。

## 三、四量的本质：一个自变量，四种单位

| 量 | 闭式 | 依赖 | 性质 |
|---|---|---|---|
| 质量 | `m = (ħ/c²)·ω` | `ω` | 线性；与 `θ` 无关 |
| 温度 | `T = (ħ/k_B)·ω` | `ω` | 线性；与 `θ` 无关 |
| 密度 | `ρ = (3ħ/(4πc⁵))·ω⁴/sin³θ` | `ω, θ` | 四次幂 + 自由参数 |
| 硬度 | `Hv = (ħ/c³)·ω⁴/sin³θ` | `ω, θ` | 四次幂 + 自由参数 |

由 A07 `m=(ħ/c)√(κ²+τ²)`：**质量就是世界线的总曲率模**（单位 `ħ/c`）。由 A08：`E=ħω` 与 `E=mc²` 合并即得 `T=ħω/k_B=mc²/k_B`，所以**温度与质量是同一个数的两种单位**，比值是普适常数

```
T/m = c²/k_B = 6.50965726073E+39  K/kg
```

三族实测（B05）：电子 `T=5.929896575E+09 K`、质子 `1.088819545E+13 K`、Planck 质量 `1.416783939E+32 K`，与该常数的相对偏差 `3.07E−50`。★但须同时声明：**这个一致是定义使然**（三者都按 `T:=mc²/k_B` 算），本项只作仪器一致性检查，**不是独立验证**，故记 INFO 而非 PASS。

### 3.1 本卷新导的一条恒等式

对匀速圆周/螺旋运动，向心加速度 `a=Rω²`，Unruh 温度 `T_U=ħa/(2πk_Bc)`，康普顿温度 `T_C=ħω/k_B`，于是

```
T_U / T_C = a/(2πcω) = Rω/(2πc) = sinθ/(2π)
```

A10 精确残差 0；B04 电子族数值 `1.161378811E−03`，闭式 `sinθ/(2π)` 同值（rel < 1e−25）。因 `θ` 取 `arctan α`，该数 **≈ `α/2π`**（相对差 `α²/2=2.66E−05`，不是恒等）。

★ 但它是**恒等式**：`θ` 自由，故对任意目标比值都能反解出一个 `θ`（G05 判 FAIL，与 r354 G01 同型）。**新导 ≠ 有判别力。**

## 四、五条判负

### G02 质量谱分立性不可由几何导出（FAIL）

`ω ↦ m = ħω/c²` 是 `(0,∞)→(0,∞)` 的严格单调双射（B07：200 点全递增；B08：往返 max rel < 1e−40）。母式不含任何量子化条件 ⇒ **谱连续**。观测质量谱分立且比值多为无理数，故框架若要给谱，必须外挂一条使 `ω` 离散的独立方程——**缺的正是这条方程**，不是算错了。这与 r264「内生 0」、r267「独有预言 0」同向。

### G03 密度不可内禀定义（FAIL）

密度需要体积。本框架里唯一可用的长度是螺旋半径 `R`，而 **`R` 是积分常数、不是解的尺度**（r354 G06：`p=0` 平面波平移简并，任意平移都是一条合法流线）。⇒ 无内禀体积，`ρ` 完全由外部选定的 `V` 决定（C04：`V=R³` 与 `V=(4π/3)R³` 差 **4.18879** 倍）。

即便强行取 `V=(4π/3)R³`，`ρ ∝ ω⁴/sin³θ` 而 `θ` 自由（r365 R6），同一质量下 `ρ` 可取 (ρ_min, ∞) 上任意值（B06）：

| θ | 45° | 15° | 1° | 0.1° |
|---|---|---|---|---|
| ρ (kg/m³) | 1.07E+07 | 2.18E+08 | 7.10E+11 | 7.10E+14 |

⇒ **满射，零预测力。**

### G04 硬度不可内禀定义（FAIL）

三步归位：

1. **量纲**：硬度（维氏/布氏）单位 Pa，`[M L⁻¹ T⁻²]` = 应力 = **能量密度**（A16）。把硬度当能量是 `L³` 级错位（A17、C05）。
2. **口径**：本框架唯一可造的能量密度是 `ħω/R³`；而能量密度本身已被证明**口径依赖**（r360 G01：固定 `ρ` 给 `U∝L⁵`，固定 `Q=e` 给 `U∝1/L`，一个递增一个递减）。⇒ 硬度继承该缺口。
3. **类别**：硬度是**塑性屈服阈值**，由位错运动与键合决定，是 N 体统计量；单条世界线的 `κ,τ` 不携带该信息。

⇒ 「硬度 = f(κ,τ)」只能是**字典指派**（与 r241 E17「垂直原理零判别力」同型），不是推导。

### G05 Unruh–Compton 比值无判别力（FAIL）

见 §3.1。一参数、一目标、残差恒 0。

### G06 可证伪独有预言 = 0（FAIL）

四条闭式全是定义级换算或其代数改写；本卷无一条能给出「若观测到 X 则本框架错」。

## 七、对照与仪器自捕

对照 **7/7 PASS**（C01–C07），每条都有牙：`ħ→2ħ` 必须让 `m` 翻倍；`ω` 两独立路径必须一致；`a=Rω` 少一个 `ω` 必须让比值偏离 `ω_C` 量级；体积口径必须差 4.18879 倍；硬度当能量必须差 `L³`；`m∝ω²` 的 log-log 斜率必须给 2 而 `m∝ω` 给 1。

**仪器自捕 2 条**（E01/E02，均未带病落盘）：

- **E01**：`C03` 首版把方向写反——坏值比目标**小**了 `1/ω_C` 量级，我却用 `rel(坏值,目标) > 1e10` 去判「偏离大」，恒假。改为 `目标/坏值 = ω_C > 1e15`。教训：**构造负对照前先估坏值落在目标的哪一侧。**
- **E02**：`C06` 首版在**等比网格**上用「相邻比恒定」判幂律——任意幂律在等比网格上相邻比都恒定，即**退化点恒绿**。改为 log-log 斜率（1 vs 2）。教训：**等比网格上的比值不携带幂次信息。**

## 九、终审判词

> `v_总=c` 确实把四个量压到了同一个几何量上：质量是**转得多快**（`ħω/c²`），温度是**同一个转得多快的另一种单位**（`ħω/k_B`），二者之比是普适常数 `c²/k_B`；密度与硬度是**同一个转得多快除以一个体积**（`ω⁴/sin³θ`），而这个体积在框架里既不被几何固定、也不是解的尺度（`R` 是积分常数），于是二者对自由参数 `θ` 满射。
> 全维求导 24 例精确残差 0，新导出 `T_U/T_C=sinθ/(2π)` 也是精确恒等式——**数学全部正确**。
> 但四条判负同样硬：**谱必须连续**（双射，无量子化方程）、**密度无内禀定义**（无体积）、**硬度无内禀定义**（应力归位 + 口径依赖 + 统计量类别错位）、**独有预言 0**。
> 一句话：**四量不是四个本质，是一个本质的四次换单位，加上同一个缺口——「框架里没有独立的第二个长度尺度」——的三次复现。**

## 十、诚实边界与 OPEN

1. 本卷只审「`v_总=c` 的圆柱螺旋」模型类；**不**主张四量在真实世界中的本质即此，也**不**否证几何统一路线。
2. `ρ`、`Hv` 两列的数值是**口径产物**（`V=(4π/3)R³`），无物理指称；报出只为让「口径依赖」这一结论有读数可核。
3. Unruh 温度用**标准（小加速度）公式**；圆轨道的 Bell–Leinaas 型修正未算 ⇒ `X-R383-4`。
4. 未做：局域 Maxwell–Dirac 驻定解（Esteban–Georgiev–Séré 族）的体积与密度；未做位错动力学与 `ħω/R³` 的对接。

- **`X-R383-1`**：是否存在一条几何量子化条件（如 `∮p·dq ∈ 2πħZ` 加在螺旋上）使 `ω` 离散 ⇒ 质量谱分立。这是本卷判负的**唯一逃生路线**。
- **`X-R383-2`**：局域 MD 驻定解是否给出内禀体积 ⇒ 密度可内禀。若有，则 G03 需改写。
- **`X-R383-3`**：硬度与能量密度的映射能否由位错动力学闭合（需要 N 体，超出单世界线）。
- **`X-R383-4`**：圆轨道 Unruh 效应（Bell–Leinaas）对 `T_U/T_C=sinθ/(2π)` 的修正量级。
