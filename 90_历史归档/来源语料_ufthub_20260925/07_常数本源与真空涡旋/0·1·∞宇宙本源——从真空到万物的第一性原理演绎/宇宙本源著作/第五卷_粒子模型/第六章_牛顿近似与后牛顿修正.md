# 第六章 牛顿引力近似与后牛顿修正
## 6.1 弱场低速近似
在弱场低速下，也就是v<<c，引力势Φ<<c²，度规可以展开为闵氏度规加小扰动，这时候爱因斯坦场方程退化为牛顿引力方程，我们日常遇到的引力现象都可以用牛顿引力描述：苹果下落、月球绕地球转、行星绕太阳转、人造卫星轨道，等等。

牛顿引力是我们理论的最低阶近似，在弱场低速下完全正确，我们不需要修改牛顿引力，它在适用范围内非常精确。

## 6.2 后牛顿形式
当需要更高精度，比如计算水星近日点进动、光线偏折、引力时间延迟，或者卫星导航的相对论修正，就需要后牛顿修正，也就是广义相对论的一阶修正。我们的理论在无挠近似下后牛顿参数和广义相对论完全相同：
- γ=1，对应光线偏折和时间延迟，和观测一致；
- β=1，对应水星近日点进动，和观测一致；
- 其他后牛顿参数都和广义相对论相同，所有太阳系实验都符合。

## 6.3 太阳系检验
太阳系是检验引力理论的最好实验室，所有广义相对论的检验都在太阳系完成：
1.  水星近日点进动：每百年43角秒，和理论一致；
2.  光线偏折：日全食时恒星光线偏折1.75角秒，和观测一致；
3.  引力红移：庞德-雷布卡实验验证了引力红移，和理论一致；
4.  雷达回波延迟：海盗号火星探测器验证了时间延迟，和理论一致；
5.  引力探测器B：验证了测地线效应和参考系拖拽，和广义相对论一致；
6.  卡西尼号：测量了引力时间延迟，γ=1+(2.1±2.3)×10^-5，和理论一致。

所有这些实验都验证了我们的理论，因为我们的理论在太阳系尺度下和广义相对论完全一致，挠率效应太小，无法观测。

## 6.4 本章小结
本章我们讨论了牛顿近似和后牛顿修正：
- 弱场低速下退化为牛顿引力，日常现象完全适用；
- 后牛顿参数和广义相对论一致，所有太阳系实验都符合；
- 太阳系尺度下挠率效应可以忽略，广义相对论完全正确。
