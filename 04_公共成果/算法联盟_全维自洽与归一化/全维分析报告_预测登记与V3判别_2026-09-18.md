## 一、先修一个哑缺陷：`n_registered_predictions` 是硬编码的 0

`无量纲靶场审计.py` 里这一行从未被质疑过：

```python
"n_registered_predictions": 0,   # 需体系自行登记，扫描无法判定
```

后果是：无论体系实际登记了多少，**"18 体系预测数 = 0"这条结论永远成立**。
它不是审计结果，它是一个不可被推翻的常量。这与本仓库反复警告的
「看起来在验证、实则永不报警」属同一类缺陷——只是这次发生在审计工具自己身上。

`预测登记与V3判别引擎.py` 改为**直接读 claims.csv 的 `prediction_value` / `prediction_urel` 两列**
真读数，并在 claims.csv 尚未全量升级时回落到 `数据/预测登记源_*.json` 且**明示读数模式**。

当前真读数：**claims.csv 中含数值或误差的行数 = 0**（各体系只用文字叙述宣称，
未填写数值列）。这不是"等于 0"的判决，而是"此刻为 0"的读数——两者差别很大。

## 三、判据与双口径

命中：`|v_pred/v_obs − 1| ≤ 3·u_obs`（整数靶要求精确相等）。
Bonferroni：π/n、小整数比等搜索式按候选数 N 放宽阈值至 `3·u_obs·N`。
相关靶按 **(体系, dup_group)** 合并，只取偏差最小者计入，靶只算一次。

**为什么要分两个口径**：登记表里混着三类东西——

| 来源 | 条数 | 说明 |
|---|---|---|
| `system_postulate` 体系自身公设导出 | 22 | 评价**体系**时只计这一类 |
| `known_literature` 既有文献关系移植 | 9 | Wyler α、Koide K、Barut m_μ/m_e、GST 关系… |
| `numerology` 小整数/π/n 搜索式 | 10 | π/14、π/21、3/13、6π⁵、α^{-3}… |
| `imported_constant` 外部模型输出 | 2 | α_GUT⁻¹ 等不可观测量 |

不分口径会把已知数值巧合计成某个体系的得分。**这是本轮最重要的一次自查修正。**

## 五、逐条最容易看错的地方（诚实边界）

1. **`N_gen = 3` 是事后对齐（postdiction），不是预测。**
   三个体系（S03 / S06 / S13）都是在三代已知之后才给出的解释。
   整数靶取值空间极小，随机对齐的概率本就不低。**它通过了 hit-test，不代表它有判别力。**

2. **Koide 角"通过"是因为 τ 质量的误差比效应本身大。**
   引擎按 PDG 三代带电轻子质量重算：偏离 45° 为 **0.952 角秒**，但一阶传播出的
   相对不确定度达 **~100%**（源自 m_τ = 1776.86±0.12 MeV）。
   即"偏离 45°"在统计上与 0 不可区分。**这不是命中，这是不够灵敏。**

3. **α = τ/κ 一类（S07/S12/S10 共 5 条）已移入 `calibrated_tautology` 桶。**
   它们的"命中残差"（1e-16 ~ 1e-12）远小于 α 的观测不确定度 1.5e-10 ——
   残差比测量精度还小，唯一解释就是参数由该靶反定标。
   **这类条目不参与组内最优竞争**，否则它 dev=0 会把同组里诚实的尝试（如 Wyler 型）"碾掉"。

4. **`bh_gr_deviation`（S14）是全靶场最弱的一条。**
   LIGO 约束 0.10 与 urel=0.5 是我给出的粗粒度标尺，不是精密观测量，
   换成别的量级约定结论会动。**本条只能作参考，不能作判决。**

5. **`n_free` / `n_anchor` 全部是审计估算。** 18 个体系从未自行登记过自由度，
   本轮按 `登记源_标注公式来源.py` 与引擎文档所述的 4 条规则推定，
   **每一条都可推翻**——改值重跑即可，不需要改代码。
