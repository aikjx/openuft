## 判定口径

四态：`PASS`（自洽）· `BOUNDARY`（边界/条件成立）· `INFO`（信息性）· `FAIL`（已证伪/循环/量纲失败）。
判据**不新造**，一律复用 openuft 既有工具：量纲账本、Buckingham Π 定理、定理 C、定理 H/F/G、
信息增益判别式 V、自由度审计。

**红线**：本目录的结论只涉及数学自洽性与第一性层级；数学自洽 ≠ 实验证实，更 ≠ L3 第一性推导。
