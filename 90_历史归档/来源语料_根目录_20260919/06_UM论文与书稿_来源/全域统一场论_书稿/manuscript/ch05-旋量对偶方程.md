# 第5章 旋量对偶方程

## 5.1 导读

【 **大白话** :前四章立了公理、编了符号。现在问第一个物理问题：场是什么、怎么演化？答案出奇地简洁——一切场归约为一个两分量旋量 $\Psi$，它的演化由一条方程决定：$\sigma^{\mu}\partial_{\mu}\Psi = \lambda\,\Theta\,\Psi^{*}$。翻译成人话：阴分量的"源"是阳分量的镜像，阳分量的"源"是阴分量的镜像——阴生阳、阳生阴，互为源泉。这一章把这条方程从公理里"逼"出来。】

## 5.2 从公理到方程（第一性推导）

【 **步骤一（对象）** :对偶公理要求基元对 $\left( 0, 1 \right)$ 以对偶对形式存在。场论中承载对偶对的最小对象是两分量旋量 $\Psi = \left( \psi_{0}, \psi_{1} \right)^{\mathsf{T}}$，其中 $\psi_{0}$ 承阴（$0$ 基元）、$\psi_{1}$ 承阳（$1$ 基元）。】

【 **步骤二（算符）** :洛伦兹不变的最小一阶微分算子是 $\sigma^{\mu}\partial_{\mu}$（泡利矩阵 $\sigma^{\mu}$），这是旋量场的"发动机"——它把时空平移与旋量转动耦合在一起，不能再小。】

【 **步骤三（源项）** :对偶公理要求"源即镜像"：方程的右侧必须是场自身的对偶。二维复空间上满足辛结构的对偶算子最小实现是 $\Theta = \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}$（第2章）。把源项定为 $\lambda\,\Theta\,\Psi^{*}$，其中 $\lambda$ 为对偶耦合常数（量纲为质量）。】

【 **方程 5.1（旋量对偶方程）** :

$$\sigma^{\mu}\, \partial_{\mu}\Psi \;=\; \lambda\, \Theta\, \Psi^{*}$$】

【 **唯一性论证** :在"两分量旋量 + 一阶洛伦兹算符 + 源为对偶镜像"三个条件下，上式是唯一自洽选择——左侧只能是 $\sigma^{\mu}\partial_{\mu}\Psi$，右侧只能是 $\lambda\Theta\Psi^{*}$，别无他选。这就是奥卡姆剃刀的结果：不是众多方程里挑一个，而是只有一个方程存在。】

## 5.3 流守恒（本书第一条定理的推导）

【 **定义 5.1（守恒流）** :$J^{\mu} = \Psi^{\dagger}\sigma^{\mu}\Psi$。在 $1+1$ 维取 $\sigma^{0} = I$、$\sigma^{1} = \sigma_{z}$ 时，$J^{0} = \left| \psi_{0} \right|^{2} + \left| \psi_{1} \right|^{2}$（总密度），$J^{1} = \left| \psi_{0} \right|^{2} - \left| \psi_{1} \right|^{2}$（阴阳差密度）。】

【 **定理 5.1（流守恒）** :旋量对偶方程蕴含 $\partial_{\mu}J^{\mu} = 0$。

证明：取全微分：

$$\partial_{\mu}J^{\mu} = 2\,\mathrm{Re}\left( \Psi^{\dagger}\sigma^{\mu}\partial_{\mu}\Psi \right) = 2\lambda\,\mathrm{Re}\left( \Psi^{\dagger}\Theta\,\Psi^{*} \right)$$

而 $\Psi^{\dagger}\Theta\,\Psi^{*} = \psi_{0}^{*}\left( -\psi_{1}^{*} \right) + \psi_{1}^{*}\psi_{0}^{*} = 0$（同相共轭配对相消），实部恒零。$\blacksquare$】

【 **大白话** :源项是"纯虚配对"，取实部必为零——阴阳互源的净效果为零，流严格守恒。这不是近似，是代数恒等式；数值上它守恒到 $10^{-13}$（第14章实验一）。】

## 5.4 关键性质一览

【 **性质 5.1（线性）** :方程对 $\Psi$ 是线性的（源项是 $\Psi^{*}$ 的线性函数），因此可做谱方法与傅里叶分解——这也是第12、14章数值化的基础。】

【 **性质 5.2（对偶协变）** :方程在电荷共轭 $\Psi \to \Psi^{c}$ 下映射到自身（$\Theta^{2} = -I$ 保证两轮共轭回到 $-\Psi$，与周期 4 自洽）。】

【 **性质 5.3（极限）** :$\lambda = 0$ 时退化为自由旋量方程 $\sigma^{\mu}\partial_{\mu}\Psi = 0$——对偶耦合关闭，回到普通无质量旋量；第7、15章将用它做对照实验。】

## 小结

【 **本章要点** :旋量对偶方程是三公理在"最小一阶算符"约束下的唯一解；流守恒 $\partial_{\mu}J^{\mu} = 0$ 是代数恒等式；它是全书主系统 M1 的核心，下一章看它如何长出规范场。】
