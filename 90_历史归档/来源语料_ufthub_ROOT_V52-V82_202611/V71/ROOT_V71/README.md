# ROOT V71 · 全方法统一场论研究包

> **可以实际复算，但并未证明四力大统一或发现第五力。** 本项目是在明确假设下推导有限尺寸力场并系统整理前代研究的开放问题。

## 这次真正新增什么

1. **有限尺寸纠错**：将 V70 的假设性 Yukawa 点源星体响应升级为均匀球解析积分、任意径向分层源积分及 `R/λ` 大小两端的稳定算法；证明同质量不同密度分层的牛顿外场相同，但其有限程 Yukawa 源积分一般不同。
2. **数学验证**：严格复算源形状因子、求势导数、微观螺旋 Frenet 公式、G 的量纲障碍、标准模型单代异常和一圈规范耦合。
3. **实验设计**：跨地球/月球/火星/木星及高度、材料差分与方向调制，比较线性设计矩阵秩与条件数；所有材料荷与观测响应都是**合成演示**，不代表实测元素属性。
4. **方程与方法数据库**：`data/ROOT_V71_全部核心方程目录.csv` 共 95 条；`data/ROOT_V71_跨学科全部主要方法检验矩阵.csv` 共 67 条，可按领域与证明状态筛选。
5. **离线实验网页**：`web/index.html` 可直接打开。星体、λ、α、核心/外壳源荷及高度均可调整；另包含可搜索的全部方程及方法清单，不需要网络或 JS CDN。
6. **研究专著**：22 章正文及附录，明确 [E]既有定律、[C]条件证明、[H]候选假说、[S]合成实验和 [OPEN]开放问题。

## 解压后运行

请使用 Python 3.10+（推荐 3.11—3.13）。

```bash
python -m pip install -r requirements.txt
python run_all.py
```

运行会自动重新生成目录、数据、图表、符号审核与单元测试报告。无需外网的数据 API；安装依赖的过程可能需要软件包仓库。

```bash
python symbolic_audit.py
python -m unittest discover -s tests -v
python browser_smoke.py      # 可选；需要 Playwright 和系统 Chromium
python verify_release.py     # 校验未修改的发布版源码与 ZIP 验收前文件
```

Windows 也可运行 `RUN_ALL.bat`；Linux/macOS 可运行 `sh RUN_ALL.sh`。

离线 HTML `web/index.html` 仅需现代浏览器，不需要安装 Python。当前 UI 使用 Canvas2D 实现三维感球体示意及有限尺寸模型曲线，**不是**高精度 WebGL 宇宙模拟或测得的力场数字孪生。

## 实测数据与假设参数的区别

- `G=6.67430e-11` SI 来自 CODATA 已测值，**不是本项目预测值**。
- 参考球半径/GM 来自前版 NASA/IERS 近似参数，仅是场景输入。
- α、λ、各分层 q、不同元素数学荷、优选方向幅度，全是**用户可调的假设参数**，不是对真实存在第五力的宣告。
- 所有“观测样本”都是带固定随机种子的**人工合成观测**，没有做新仪器实验，也没有独立高能碰撞、量子引力或天体观测。
- 量子一致性所需的幺正、异常消除及高能 UV 完备性**没有**通过软件测试得到全面证明。

## 科研结论

有限尺寸源的正确数学处理改进了之前的候选新力计算，但**尚不能**从同一微观公设独立预测 G、产生完整 SM 规范群及粒子谱，更不能以模拟证明四力统一。请以 `book/` 的证明边界和 `SOURCES.md` 为准。
