# 算子统一系统 (Operator Unified System)

基于6大数学公理构建的通用计算框架，实现"万物皆算子"的范畴论统一抽象。

## 🌟 核心特性

### 六大数学公理
1. **万物皆算子** - 所有操作抽象为范畴论中的态射
2. **状态高维向量** - 系统状态表示为希尔伯特空间中的向量
3. **关联关系加权有向图** - 知识图谱基于图论建模
4. **范畴论态射规则** - 算子组合满足结合律、单位律
5. **资源约束优化** - 基于DAG的调度和资源管理
6. **扩展性闭包** - 单子模式封装副作用，支持WASM插件

### 技术栈
- **后端**: Rust + Tokio + Axum
- **核心计算**: nalgebra线性代数 + petgraph图算法
- **插件系统**: WASM (wasmer) 沙箱执行
- **前端**: Vue3 + Three.js + ECharts + 3D力导向图
- **数学基础**: 范畴论 + 希尔伯特空间 + 单子论

## 🔌 插件开发

### WASM插件接口
WASM插件需要导出以下函数：
```c
// 算子执行函数
// input_ptr: 输入f64数组指针
// output_ptr: 输出f64数组指针
// n: 向量维度
// 返回值: 0表示成功，非0表示错误
int operator_apply(double* input, double* output, int n);
```

将编译好的`.wasm`文件放入`plugins/`目录，系统会自动加载。

## 📐 核心数学概念

### 范畴论基础
- **对象**: 高维状态向量空间
- **态射**: 算子 (Operator)
- **组合**: g∘f 表示先执行f再执行g
- **恒等态射**: id算子
- **张量积**: f⊗g 表示并行执行

### 单子模式
Op单子封装可能失败的计算，满足：
- **左单位律**: `return x >>= f = f x`
- **右单位律**: `m >>= return = m`
- **结合律**: `(m >>= f) >>= g = m >>= (\x -> f x >>= g)`

### 守恒律
- **L1范数守恒**: 概率总和不变
- **L2范数守恒**: 正交变换下能量守恒
- **残差监控**: 实时计算数值误差
