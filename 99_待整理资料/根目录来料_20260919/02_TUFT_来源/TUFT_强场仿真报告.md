## 一、光子球与阴影（解析 + 数值）

**TUFT 指数度规** `β₁=e^{−2U}`（isotropic），零测地线 `(du/dφ)² = e^{4mu}/b² − u²`。

**光子球条件**（`E=0` 且 `dE/du=0`）：

```
E=0   :  e^{4mu}/b² = u²
dE/du :  4m·e^{4mu}/b² = 2u
联立  :  u² = u/(2m)  =>  u_ph = 1/(2m),  r_ph = 2m
         b_crit = e^{2m·u_ph}/u_ph = 2e·m
```

| 量 | TUFT | GR (Schwarzschild) | 差异 |
|---|---|---|---|
| 光子球（isotropic r） | **2m** | 1.866 m | — |
| 临界冲击参数 `b_crit` | **2e·m = 5.436564** | **3√3·m = 5.196152** | **+4.63%** |
| **阴影直径** `d=2b_crit` | 10.873127 m | 10.392305 m | **+4.63%** |

- **解析 = 数值**（`b = 5.436564`，PASS）；
- 数值验证临界性：`b=0.99·b_crit ⇒ 捕获`；`b=1.01·b_crit ⇒ 偏折 4.17 rad（逃逸）` ✓
