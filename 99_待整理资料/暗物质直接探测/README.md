# 暗物质直接探测

> 通过地下实验直接探测暗物质粒子与普通物质的相互作用，确定暗物质的粒子性质。

## 问题定义

宇宙中约 27% 的能量密度由暗物质构成，但暗物质的粒子本质未知。核心候选：
- **WIMP**（弱相互作用大质量粒子）：$\sim 100$ GeV–TeV，热遗迹
- **轴子**：$\sim 10^{-6}$ eV，解决强 CP 问题
- **暗光子**：$U(1)'$ 规范玻色子
- **惰性中微子**：keV 量级，温暗物质

**核心目标**：探测暗物质粒子与靶核的弹性散射或吸收信号。

## 当前进展（2020–2026）

| 实验 | 结果 |
|---|---|
| LUX-ZEPLIN (LZ) 2023 | 未发现 WIMP；排除自旋无关截面 $\sigma < 9.2 \times 10^{-48}$ cm²（30 GeV） |
| XENONnT 2023 | 未发现 WIMP；LZ/XENONnT/PandaX 联合排除 |
| ADMX 2023 | 轴子搜索；排除部分参数空间 |
| 总体 | 无确认暗物质直接探测信号 |

**间接探测**：
- 宇宙线反物质（AMS-02）正电子超出，未确认是暗物质还是脉冲星
- 矮星系伽马射线未确认暗物质湮灭信号

## 证伪条件

- 若暗物质直接探测实验长期无信号且灵敏度达到中微子背景，则 WIMP 路线受压
- 若引力修正方案（如 MOND）能解释所有观测，则暗物质粒子假设被削弱
- 若发现确定的暗物质粒子信号，则粒子暗物质方案获得确认
