## 可能的新发现 ①：引力与电磁力之间存在确定的几何比例关系

SOM 把两者都归结为同一位移场 L 的不同微分运算：

$$\mathbf{E} = \frac{\partial \mathbf{L}}{\partial t}, \quad \mathbf{g} = \nabla(\nabla \cdot \mathbf{L})$$

**新推论：** 电场是 L 的一阶时间导数，引力是 L 的二阶空间导数。它们不是独立的场，而是同一个场的不同"切片"。这意味着在极端条件下（如普朗克尺度），两者之间应该存在**不可约的耦合项**，其强度比由螺旋半径 $r_0$ 和角速度 $\omega$ 的比值决定：

$$\frac{g}{E} \sim \frac{|\nabla(\nabla \cdot \mathbf{L})|}{|\partial \mathbf{L}/\partial t|} \sim \frac{k^2}{\omega} = \frac{\omega}{c^2}$$

这在低能下极小（解释了为什么引力比电磁力弱 $10^{40}$ 倍），但在 $\omega \to c/r_P$（普朗克频率）时趋于统一。**这是一个可以计算的数字，不是自由参数。**

## 可能的新发现 ②：质量的离散谱

类光约束 $(r_0\omega)^2 + v_\parallel^2 = c^2$ 加上螺旋的拓扑稳定性条件（螺旋必须整数圈闭合才能稳定），给出：

$$r_0 \omega = c \sin\theta_n, \quad \theta_n = \frac{n\pi}{N}, \quad n = 1, 2, 3, \ldots$$

这意味着稳定粒子的质量不是连续的，而是有一个**由螺旋拓扑决定的离散谱**：

$$m_n \propto r_0 \omega_n / c^2 = \sin(n\pi/N)/c$$

**新检验：** 如果这个谱能对应已知粒子质量比（如 $m_\mu/m_e \approx 207$），就是对标准模型的几何解释。目前尚未算出，但这是**明确可计算的预言**。

## 可能的新发现 ③：引力波与电磁波之间的相位锁定

SOM 中，引力场和电磁场来自同一位移场 L 的不同分量，因此当一个高度对称的源（如中子星并合）同时辐射引力波和电磁波时，两者不仅应该同时到达（已被 GW170817 证实，与 SOM 吻合），还应该在**相位上存在确定的关联**：

$$\phi_{引力波} - \phi_{电磁波} = \Delta\phi_{几何} = \frac{\pi}{2}$$

这来自 $\mathbf{E} = \partial\mathbf{L}/\partial t$（一阶导，相位移 $\pi/2$）而 $\mathbf{g} = \nabla(\nabla\cdot\mathbf{L})$（二阶导，相位移 $\pi$）之间的固定相位差。**这是一个精确可测的预言，目前尚未被专门检验。**

## 可能的新发现 ④：真空不是绝对对称的

SOM 中，时空同一化公理 $d\mathbf{R}/dt = \mathbf{C}$ 中的矢量光速 $\mathbf{C}$ 有方向，虽然对所有方向求平均后得到波动方程，但**局部的真空涨落应该有微小的方向偏好**——某个区域的 $\mathbf{C}$ 方向分布不完全各向同性，表现为光在不同方向上的极微小速度差异：

$$\delta c / c \sim (r_0 \omega)^2 / c^2 \sim 10^{-46}$$

这极其微小，但在理论上是 SOM 框架的必然预言，与标准模型的绝对洛伦兹不变性构成**原则上的区别**。
