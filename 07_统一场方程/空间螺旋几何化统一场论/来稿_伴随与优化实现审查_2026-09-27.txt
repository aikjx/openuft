## 2. 致命问题：代码中存在非法 Python 变量名

代码里大量出现：

```python
\(\mathcal C\)_num = ...

print(f"TUFT辐射修正系数 \(\mathcal C\)_opt = {\(\mathcal C\)_opt}")
```

这些不是合法 Python 标识符。Python 变量名不能包含 `\`、`(`、`)`、空格、`\mathcal` 等。

因此当前代码会直接 `SyntaxError`，无法运行。

应改成例如：

```python
C_num = ...
C_opt = ...
Cs = ...
```

## 3. 原孤子 ODE 与文档不一致

文档写：

\[
F=-\psi''-\frac{2}{r}\psi'-V_1\psi^3+V_2\psi^5=0
\]

即：

\[
\psi''=-\frac{2}{r}\psi'-V_1\psi^3+V_2\psi^5
\]

但代码写的是：

```python
ddpsi = -(2/r)*dpsi + V1 * psi**3 - V2 * psi**5
```

即：

\[
\psi''=-\frac{2}{r}\psi'+V_1\psi^3-V_2\psi^5
\]

这相当于把 \(V_1,V_2\) 的符号反了。若文档为准，代码应改为：

```python
ddpsi = -(2/r)*dpsi - V1 * psi**3 + V2 * psi**5
```

否则求出的孤子轮廓、能量、质量、磁矩全部会对应另一个方程。

这是**根本性错误**。

---

## 4. 能量泛函与 ODE 符号也不一致

代码中能量写成：

\[
E_0=\int 4\pi r^2\left[\frac12\psi'^2+\frac{V_1}{4}\psi^4-\frac{V_2}{6}\psi^6\right]dr
\]

这与文档的 \(F\) 形式一致，但与代码中的 ODE 符号不一致。

如果代码 ODE 是：

\[
\psi''+\frac{2}{r}\psi'=V_1\psi^3-V_2\psi^5
\]

那么能量势能项通常应是负号，或者 \(V_1,V_2\) 的定义要整体改。

因此：**ODE、能量泛函、伴随线性化必须统一到同一个 \(F\) 定义，目前没有统一。**

## 5. 伴随方程推导错误

文档给出的伴随算子：

\[
F^*[\psi_a]=-\psi_a''+\frac{2}{r}\psi_a'-3V_1\psi_s^2\psi_a+5V_2\psi_s^4\psi_a=\text{src}
\]

但你的灵敏度公式使用的是：

\[
dJ/d\lambda=\partial J/\partial\lambda-\int \psi_a\,\partial F/\partial\lambda\,4\pi r^2dr
\]

这对应拉格朗日乘子形式：

\[
\mathcal L=J-\int \psi_a F\,4\pi r^2dr
\]

也就是说，伴随方程应在**加权内积 \(r^2dr\)** 下定义。对于球坐标算子：

\[
L=-d^2-\frac{2}{r}d+a(r)
\]

在权重 \(r^2\) 下是自伴的，因此正确伴随应为：

\[
-\psi_a''-\frac{2}{r}\psi_a'-3V_1\psi_s^2\psi_a+5V_2\psi_s^4\psi_a=\text{src}
\]

而代码中写的是：

```python
ddpsi_a = (2/r)*dpsi_a - 3*V1*psi_s(r)**2 * psi_a + 5*V2*psi_s(r)**4 * psi_a - src(r)
```

即：

\[
-\psi_a''+\frac{2}{r}\psi_a'-3V_1\psi_s^2\psi_a+5V_2\psi_s^4\psi_a=\text{src}
\]

这里 \(\frac{2}{r}\psi_a'\) 的符号错了。正确形式应为：

```python
ddpsi_a = -(2/r)*dpsi_a - 3*V1*psi_s(r)**2 * psi_a + 5*V2*psi_s(r)**4 * psi_a - src(r)
```

因此，当前伴随求解器解的不是正确的伴随方程，后续所有 \(dN/dV_1,dE_0/dV_1,dI_\mu/dV_1\) 都不可信。

## 6. 伴随源项也有错误

### 6.1 \(N\) 的源项

\[
N=\int 4\pi r^2\psi^2dr
\]

在加权拉格朗日形式下，源项应为：

\[
\text{src}_N=2\psi_s
\]

代码写成：

```python
src_N = lambda r: (8*mp.pi*r**2 * psi_s(r)) / (4*mp.pi*r**2)
```

数学上等于 \(2\psi_s\)，但数值上在 \(r=0\) 会除零。应直接写：

```python
src_N = lambda r: 2*psi_s(r)
```

### 6.2 \(I_\mu\) 的源项

\[
I_\mu=\int 2\pi r^3\psi^2dr
\]

源项应为：

\[
\text{src}_{I_\mu}=r\psi_s
\]

代码数学上是对的，但同样在 \(r=0\) 有除零风险。

### 6.3 \(E_0\) 的源项错误

代码写：

```python
src_E0 = lambda r: (4*mp.pi*r**2 * (V1*psi_s(r)**3 - V2*psi_s(r)**5))/(4*mp.pi*r**2)
```

即：

\[
\text{src}_{E_0}=V_1\psi_s^3-V_2\psi_s^5
\]

但 \(E_0\) 包含动能项 \(\frac12\psi'^2\)，泛函导数不是这么简单。利用原方程后可得到：

\[
\text{src}_{E_0}=2(V_1\psi_s^3-V_2\psi_s^5)
\]

代码少了因子 2。因此 \(dE_0/dV_1,dE_0/dV_2\) 错误。

## 7. \(r=0\) 边界处理错误

代码中：

```python
if r < mp.mpf("1e-30"):
    return [mp.mpf(0), mp.mpf(0)]
```

这会把 \(r=0\) 处的导数强制为 0，但实际 \(\psi''(0)\) 不一定为 0。

对于文档 ODE：

\[
\psi''+\frac{2}{r}\psi'+V_1\psi^3-V_2\psi^5=0
\]

在 \(r=0\) 附近，\(\psi'(0)=0\)，设 \(\psi=\psi_0+b r^2\)，则：

\[
6b+V_1\psi_0^3-V_2\psi_0^5=0
\]

所以：

\[
\psi''(0)=2b=\frac{V_2\psi_0^5-V_1\psi_0^3}{3}
\]

伴随方程在 \(r=0\) 也需要类似泰勒展开。当前返回 `[0,0]` 是错的，会导致 shooting 和 ODE 积分精度严重受损。

## 8. 量纲问题：\(N=\hbar\) 约束不成立

代码使用 SI 常数：

```python
Me = 9.109e-31 kg
Qe = 1.602e-19 C
mue = -9.284e-24 J/T
hbar = 1.054e-34 J*s
c = 299792458 m/s
```

但 \(N\) 定义为：

\[
N=\int 4\pi r^2\psi^2dr
\]

若 \(r\) 单位是米，\(\psi\) 无量纲，则 \(N\) 的量纲是 \(\text{m}^3\)，不可能是 \(\hbar\) 的 \(\text{J·s}\)。

因此分支 B 中：

```python
N - hbar = 0
```

量纲不一致。除非模型已经无量纲化，并且 \(\hbar\) 被设为 1 或其他自然单位。但当前代码没有体现这一点。

所以：**分支 B 的约束本身量纲错误。**

## 9. 简并流形扫描有严重错误

扫描代码中：

```python
\(\mathcal C\)num_s = mp.quad(
    lambda r: 4*mp.pi*r**2 * psi_s_opt(r)**2 *
    (3*mp.mpf(v1s)*psi_s_opt(r)**2 - 5*mp.mpf(v2s)*psi_s_opt(r)**4)*r**2,
    [0, r_max]
)
```

这里用的是全局最优点的 `psi_s_opt`，而不是当前扫描点 \((v1s,v2s)\) 对应的孤子解。

也就是说，扫描时参数变了，但波函数仍用旧的最优解。这样得到的 \(\mathcal C\) 和 \(g_e\) 完全错误。

正确做法是每个扫描点重新：

```python
sol_scan, _ = solve_soliton(mp.mpf(v1s), mp.mpf(v2s))
psi_scan = lambda r: sol_scan(r)[0]
```

再计算 \(\mathcal C\)。

另外，扫描没有检查条件优化后的 \(\chi^2\) 是否仍接近 \(\chi^2_{\min}\)。如果 \(\chi^2\) 明显变大，那它根本不是简并流形。

## 10. SLSQP 精度说法不成立

虽然设置了：

```python
mp.mp.dps = 250
```

但 `scipy.optimize.minimize` 的 SLSQP 使用双精度浮点数。参数 \(x\) 是 `numpy.float64`，雅可比也转成 `float`：

```python
jac_vec = np.array([float(dchi_dV1), ...])
```

所以最终优化精度受限于双精度，不是 250 位高精度。内部用 mpmath 只减少部分数值误差，但不能让 SLSQP 变成 250 位优化器。

## 11. 其他数值风险

- `mp.quad` 积分到 \(r_{\max}=40\)，但未检查孤子在 \(r_{\max}\) 是否充分衰减，截断误差可能很大。
- `mp.findroot` 的 shooting 初始猜测没有物理区间限制，可能收敛到非物理解。
- `chi2` 中异常返回 `1e12`，但 `chi2_jac` 没有对应异常处理，可能导致 SLSQP 使用不一致的梯度和函数值。
- `solve_adjoint` 的 shooting 同样受 \(r=0\) 错误处理影响。
- `src_N`、`src_E0`、`src_Imu` 在 \(r=0\) 除零，虽然数学上可化简，但代码未化简。
