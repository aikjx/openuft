## 零、要做什么

R14 的决定性结论把 TUFT 推到「不可计算」边界：**单值 Lk 只提供 log₂(3)=1.58 bits（仅自旋层 0/½/1），区分 10 个 SM 场需要 3.32 bits，缺口 1.74 bits ⇒ Lk 零区分力**，根因判定为「规范量子数是群表示论对象，Lk/W/亏格是曲线拓扑不变量，不同范畴且无自然函子 ⇒ 缺定义非计算失败」。

R17 已把规范量子数层闭合（(j_SU2, N_color_SU3, Y) 逐分量派生），但 O-KNOTMAP（结类型 → SM 场**目录**）仍标记为开放。本册正面攻击该缺口：把「单 Lk 函数」升级为**结群拓扑不变量族群**（结行列式 det(K) + 已导出的 (j, color, Y)），构造一个具体的候选函子，并诚实标注残余自由度。

## 一、结行列式 det(K)：比 Lk 更丰富的拓扑不变量

对任一素数结 K，Alexander 多项式 Δ_K(t) 对称，结行列式定义为 **det(K) = |Δ_K(−1)|**，是标准拓扑不变量（对素数结恒为正奇数）。本册显式计算 8 个标准结并对照结表值，**全部逐个一致**：

| 结 | Δ_K(t)（对称写法） | det(K) 计算 | 结表值 |
|---|---|---|---|
| 3₁ 三叶结 | −1 + (t + t⁻¹) | 3 | 3 ✓ |
| 4₁ 八字结 | −3 + (t + t⁻¹) | 5 | 5 ✓ |
| 5₁ 环面 T(5,2) | 1 − (t + t⁻¹) + (t² + t⁻²) | 5 | 5 ✓ |
| 5₂ | −3 + 2(t + t⁻¹) | 7 | 7 ✓ |
| 6₁ | 5 − 3(t + t⁻¹) + (t² + t⁻²) | 13 | 13 ✓ |
| 6₂ | 5 − 5(t + t⁻¹) + 2(t² + t⁻²) | 19 | 19 ✓ |
| 6₃ | 3 − 3(t + t⁻¹) + (t² + t⁻²) | 11 | 11 ✓ |
| 7₁ 环面 T(7,2) | −1 + (t + t⁻¹) − (t² + t⁻²) + (t³ + t⁻³) | 7 | 7 ✓ |

计算式：Δ(−1) = c₀ + Σ_{k≥1} c_k · 2·(−1)^k（t^k + t^{−k} 在 t=−1 取值 2·(−1)^k），取绝对值即 det。

## 二、关键桥接：det(3₁)=3 ↔ SM 三代数量【本册核心新连接】

三叶结的结行列式 **det(3₁) = 3**。这恰与 SM 的**三代数量**一致，且三叶结**正是 R15/R16 已用于导出 SU(2)/SU(3) 表示的同一个结**——因此「代=3」与「结群表示来源」在**同一个结**上自洽闭合，而非引入新独立假设。

该连接是**第一性来源候选**而非拟合，依据是标准定理：

> **det(K) = |H₁(Σ₂(K); ℤ)|**，其中 Σ₂(K) 是绕 K 的 2-重分支覆盖。
> 对三叶结 Σ₂(3₁) = 透镜空间 L(3,1)，H₁ = ℤ/3 ⇒ det(3₁) = 3。

即「代=3」＝「三叶结分支双覆盖同调的阶」——一个干净的拓扑计数，与 R17 的 **k=2 机制**（CS level k=2 ⇒ SU(2)_k 不可约表示数 = k+1 = 3）**同源但独立**：前者来自 branched-cover 同调阶，后者来自 CS level 表示数。两条独立路线均给出「3」，构成对「代数量=3」的**双重拓扑支撑**。

## 三、信息论：R14 的 1.74-bit 缺口在信息论层可覆盖

SM 基本 Weyl 费米子目录 = 6 场型 × 3 代 = **18 个场槽位**，需 **log₂(18) = 4.170 bits** 标识。

- 代层：det(3₁)=3 提供 **log₂(3) = 1.585 bits**；
- 场型层：已导出的 (j_SU2, N_color_SU3) 区分 6 个场型（Q_L/u_R/d_R 为色三重态，L/e_R/ν_R 为色单态；Q_L/L 为 j=½ 双重态，其余 j=0 单态），提供 **log₂(6) = 2.585 bits**。

合计 **4.170 bits ≥ 4.170 bits** ⇒ **R14 的 1.74-bit 缺口在信息论层可覆盖**。

对照 R14：单值 Lk 仅 1.585 bits（自旋层），与 det(3₁) 代层位容量相同——但 det 同时携带 branched-cover 同调语义（扇区数），而 (j, color) 由 R15/R16/R17 派生补足**场型层**。即 R14 的反例（「一个 Lk 值对六个不同 Y」）被「det 区分代 + 派生量子数区分场型」绕开——有效域收窄，非否定 R14 的决定性结论（R14 针对单值 Lk 函数，本册换用不变量族群）。

## 四、候选函子 F 与诚实残余

**函子草型（可构造）**：

```
F: 结类型 K ──► ( gen ∈ Z/det(K),  field-type ∈ {(j_SU2, N_color_SU3)} )
   gen 来自 det(K)（K=3_1 ⇒ gen∈{1,2,3}）
   field-type 来自 R15/R16/R17 派生的 (j, color)
⇒ 18 个场槽位与 SM Weyl 费米子一一对齐
```

**诚实残余（不粉饰，标记 BOUNDARY/FAIL）**：

- **(a) 首选结选择规则未派生**：为何恰好选三叶结 3₁ 作「代结」？其它结 det(4₁)=5、det(6₂)=19 等会给出 ≠3 的扇区数，与 SM 不符 ⇒ 它们对应「未实现的拓扑扇区 / 外秘扇区」。目前**无方程强制代结必为 3_1**——这是选择规则，非第一性导出。
- **(b) 场名标记仍是字典**：同一代内 (j, color) 组合 → 具体场名（Q_L 双重态 vs e_R 单态、L vs ν_R）的对应是**约定**，TUFT 给出 (j, color, Y) 量子数但**不派生场名**。R14 §4「一个结只对应一个表示，不能区分 Q_L 与 e_R」在此仍成立，只是现在「一个结 + 派生量子数」区分的是「场型」而非「场名」。

⇒ **O-KNOTMAP 完全从第一性派生：FAIL**（诚实标注）。本册把 O-KNOTMAP 从「完全无函子」收窄为「函子存在于（代层 det + 量子数层 (j,color)），残余 = 场名标记字典 + 首选结(3_1)选择规则」，但未消除其开放状态。

## 六、结论

1. **新连接**：det(3₁)=3 ↔ SM 三代，是 branched-cover 同调阶的标准拓扑事实，与 R17 的 k=2 机制**双重独立支撑**「代数量=3」。
2. **信息论闭合**：det(3₁) 代层 + 派生 (j,color) 场型层合计 4.170 bits ≥ 场目录需求，R14 的 1.74-bit 缺口在信息论层可覆盖。
3. **诚实边界**：O-KNOTMAP 未完全派生——残余为场名标记字典 + 首选结(3_1)选择规则，两者均非第一性导出。
4. **定位升级**：TUFT 现具备「结群 → 代数量(3) + 规范量子数(j,color,Y)」的构造性来源，残余仅余「场名标记 + 代结选择」两项约定层自由度。

红线：数学自洽 != 实验证实；本册不粉饰残余为已证结论。
