# ROOT V133｜从光速螺旋到四种相互作用：可复算的数学与实验约束审计

**版本日期：2026-11-24**。**重要结论：没有证明四力统一；得到针对明确假设的条件性排除、已知量子几何的一致性计算，以及标准模型规范耦合一圈运行的量化障碍。**

## 0. 审查约定与证据分层

- 只采用 **\(c=1\)**。**没有**将 \(\hbar=1\) 或 \(G=1\)；\(\hbar\) 和 \(G\) 保留独立有量纲常数。
- 取质量维度 \(M\)、长度维度 \(L\)。\([\hbar]=ML\)、\([G_4]=L/M\)、\([G_5]=L^2/M\)。\([S]=ML=[\hbar]\)。
- 数据分为：I 已确立的理论/观测；II 在指定假设下的严格数学结果；III 数值演示；IV 尚未证明的 ROOT 猜想。**禁止把 II/III 当成 IV 的实验证明**。
- 采用平直度规号差 \((-+++)\)。以能量为变量的重整化标度 \(\mu\) 使用 GeV 标签；物理转换仍由 \(\ell=\hbar/\mu\)（\(c=1\)）给出，GeV 与 SI 的联系需要明确保留 \(\hbar,c\) 数值。\(\alpha_i\) 是正规化后测得的**无量纲**耦合，不代表把 \(\hbar\) 设置为 1。

## 1. 严格条件性结论：固定半径与光学角频率的真实螺旋模型不能无限频成立

假定真实空间轨迹（不是圆偏振电场矢量）为

\[
\boldsymbol r(t)=(R\cos\Omega t,\ R\sin\Omega t,\ ut),\qquad
|\dot{\boldsymbol r}|^2=R^2\Omega^2+u^2=1.
\]

这是**只对所假定空间轨迹成立**的速度关系。再假设 \(R=R_0>0\) 对所有光子固定且 \(\Omega=\omega=k=2\pi/\lambda\)，则

\[
\boxed{u^2=1-R_0^2k^2\geq0\ \Longrightarrow\ R_0\leq1/k=\lambda/(2\pi).}
\]

对于任意固定 \(R_0>0\)，取 \(k>1/R_0\) 立即矛盾。因此不存在对无限高波数均成立的上述**固定半径 + 机械角频率等于光学频率 + 总速度为 1**的经典轨迹模型。该结论**并不排除**：\(R=R(k)\)、\(\Omega\neq\omega\)、非机械内部自由度、非自由传播等不同假设。

特别注意，若强行取 \(R=\lambda/(2\pi)\)、\(\Omega=k\)，则横向速度恰为 1 而轴向 \(u=0\)。若光同时要求以轴向速度 \(u=1\) 前进，则 \(R\Omega=0\)。这不是“光子自旋不可能”的论证，因为**量子自旋不是经典轨迹**。

程序 `data/helix_bound.csv` 在**固定假设半径 1 nm**的例子下检查多种真空波长（包括从 0.001 nm 到毫米数量级）。这些数值是模拟输入，不是光子半径的测量。

### 1.1 更强的自由传播障碍：非退化的真实圆柱螺旋不是真空自由零测地线

在平直时空令 \(x^\mu(t)=(t,R\cos\Omega t,R\sin\Omega t,ut)\)。若速度约束成立，则切向量为零矢量：

\[
\eta_{\mu\nu}\frac{dx^\mu}{dt}\frac{dx^\nu}{dt}=-1+R^2\Omega^2+u^2=0.
\]

但对 \(t\) 再求导：

\[
\frac{d^2x^\mu}{dt^2}=(0,-R\Omega^2\cos\Omega t,-R\Omega^2\sin\Omega t,0),
\quad
\eta_{\mu\nu}\frac{d^2x^\mu}{dt^2}\frac{d^2x^\nu}{dt^2}=R^2\Omega^4>0.
\]

这里是对参数 \(t\) 的切向量求导，**不是**无质量粒子的“固有加速度”。在平直时空、标准惯性坐标下，自由零测地线必须具有 \(d^2x^\mu/dt^2=0\)（适当仿射参数），而非退化圆柱螺旋不满足。因此**如果螺旋被认为是自由光子中心的真实空间轨迹**，就必须引入额外作用或修改自由传播动力学，并具体说明为何没有与光的已知传播规律冲突。若“螺旋”仅指内部态/场矢量，结论则不适用。


## 2. 已知的真正几何关联：光子螺旋度与 Berry 几何相位

光子自由传播态具有螺旋度 \(\sigma=\pm1\)。对逐渐转向的传播方向 \(\hat{\boldsymbol k}\)，在动量方向单位球面上取局部正交基 \(\boldsymbol e_\theta,\boldsymbol e_\phi\)，定义圆偏振基

\[
\boldsymbol e_\sigma=(\boldsymbol e_\theta+i\sigma\boldsymbol e_\phi)/\sqrt 2.
\]

Berry 联络为

\[
\mathcal A_\sigma=i\boldsymbol e_\sigma^*\cdot d\boldsymbol e_\sigma
=\sigma\cos\theta\,d\phi,
\qquad
\mathcal F_\sigma=d\mathcal A_\sigma
=-\sigma\sin\theta\,d\theta\wedge d\phi.
\]

故闭合方向回路 \(C\) 的几何相位

\[
\boxed{\gamma_\sigma(C)=\oint_C\mathcal A_\sigma=-\sigma\Omega_{\rm solid}(C)\pmod{2\pi}.}
\]

这里 \(\Omega_{\rm solid}\) 是\(\hat{\boldsymbol k}\)回路包围的**有向立体角**，不是机械角速度。相位的符号随基矢/回路定向约定而变，但两螺旋度相位相反且其与立体角的关系不变。

**数值核查：** 用 \(\prod_j\langle e_{\sigma,j}|e_{\sigma,j+1}\rangle\) 的离散闭合 holonomy 直接计算相位，重复 \(\theta=0.35,0.6,1.1\) rad、\(\sigma=\pm1\)、\(N=32\ldots1024\)。程序用圆周角差与解析式对比，并检验误差随采样数收敛。详情 `data/berry_phase_convergence.csv`。

**物理意义：** 几何确实会影响光子的偏振相位，已被螺旋光纤实验观测；但此效应是光沿外部弯曲路径或方向空间中的几何相位，不是证明自由光子内部存在真实螺旋轨道。尤其不要把动量空间中的 Berry \(U(1)\) 联络与电荷的时空 \(U(1)_Y\) 规范场等同。

## 3. 高维几何确实能出现规范场：但最简单模型只给出 U(1)

取五维空间为四维时空与一个半径为 \(R\) 的圆周 \(S^1\)。令 \(y\in[0,2\pi)\)，度规形式

\[
\boxed{ds_5^2=g_{\mu\nu}(x)dx^\mu dx^\nu+R^2\left(dy+\kappa A_\mu(x)dx^\mu\right)^2.}
\]

在坐标变换 \(y'=y+\chi(x)\) 下，\(A'_\mu=A_\mu-\partial_\mu\chi/\kappa\)，从而 \(dy'+\kappa A'=dy+\kappa A\)：一个四维 \(U(1)\) 规范变换源自五维坐标变换（几何起源的**例子**）。

用五维 Einstein–Hilbert 项并对圆周积分，若额外维半径为常数，得到

\[
S_5=\frac1{16\pi G_5}\int d^5x\sqrt{-g_5}\,\mathcal R_5,
\qquad
\boxed{G_4=\frac{G_5}{2\pi R}.}
\]

**量纲：** \([G_4]=L/M\)、\([G_5]=L^2/M\)，与 \(G_5/(2\pi R)\) 一致。该式不是从零推导出的 \(G_4\)，因为引入了独立未知量 \(G_5,R\)。如果实验给出 \(G_4\) 而反算 \(G_5\)，则绝对不能宣称已预测万有引力常数。

圆周上的动量量子化为 \(p_5=n\hbar/R\)，相应非零 KK 激发的质量尺度 \(m_n\sim|n|\hbar/R\)（仅 \(c=1\)），未设 \(\hbar=1\)。纯粹的一个圆周的连续等距群为 \(U(1)\)，并不自动产生 \(SU(2)_L\times SU(3)_C\)，也不自动得到正确的四维手征费米子谱。

**演示**：取假设 \(R=10^{-18}\) m，第一 KK 模式的能量为 \(\hbar c/R\approx197.327\) GeV。此处 SI 换算显式恢复 \(c_{\rm SI}\)；不是新粒子的预测。实际高维谱受边界条件、紧化和耦合影响。

## 4. 第三项量化结果：最小标准模型的规范耦合一圈运行不能精确交于一点

对 \(SU(5)\) 规范化的 \(U(1)_Y\) 耦合与 \(SU(2),SU(3)\)，采用经典的一圈系数

\[
(b_1,b_2,b_3)=\left(\frac{41}{10},-\frac{19}{6},-7\right),\qquad
\boxed{\alpha_i^{-1}(\mu)=\alpha_i^{-1}(M_Z)-\frac{b_i}{2\pi}\ln\frac\mu{M_Z}}.
\]

这是保持最小标准模型粒子谱且忽略额外阈值/两圈修正的**一圈近似**。输入取代表值 \(M_Z=91.1876\) GeV、\(\alpha_{\rm em}^{-1}(M_Z)=127.955\)、\(\sin^2\theta_W(M_Z)=0.23122\)、\(\alpha_3(M_Z)=0.1180\)。这些是**现有观测的近似参考输入而非 ROOT 预言**；\(\alpha_{\rm em}\) 和 \(\sin^2\theta_W\) 有不同重整化定义，精密拟合需要严谨 scheme-matching 和阈值校正；此处只作可核对的定性一圈基准。

\[
\alpha_1^{-1}(M_Z)=\tfrac35(1-\sin^2\theta_W)\alpha_{\rm em}^{-1},\quad
\alpha_2^{-1}(M_Z)=\sin^2\theta_W\alpha_{\rm em}^{-1},\quad
\alpha_3^{-1}(M_Z)=1/\alpha_s.
\]

程序得到

| 两条曲线交点 | 能量尺度 \(\mu\)（GeV） | 第三条是否也相交？ |
|---|---:|---|
| \(\alpha_1=\alpha_2\) | \(1.0317\times10^{13}\) | 否 |
| \(\alpha_1=\alpha_3\) | \(2.4326\times10^{14}\) | 否 |
| \(\alpha_2=\alpha_3\) | \(9.7252\times10^{16}\) | 否 |

让三个**逆耦合**最接近的最小二乘尺度约 \(1.6089\times10^{14}\) GeV，在此它们分别是 \((40.6208,43.7977,39.8904)\)，最大差约 **3.9073**，未精确合一。25 组? 实际执行 27 组输入应力扰动（每项三个选值），仍不出现精确交点；这些人为扰动**不是统计置信区间**。

**限制：** 这既不否定有新粒子阈值、超对称、中间对称破缺或不同 GUT 扩展，也不构成 ROOT 的统一证据。它说明必须给出明确的新粒子、阈值与 beta 系数，而不能把“不同力都是运动，因此自然合一”当成定量证明。

## 5. 从曲率、挠率到四力：关键的类型与对称性障碍

- 空间曲线 Frenet–Serret 挠率 \(\tau\) 是曲线标量；时空 Cartan 挠率 \(T^\rho{}_{\mu\nu}\) 是联络的张量；动量球面 Berry 曲率 \(\mathcal F\) 是参数空间二形式；内部规范曲率 \(F^a_{\mu\nu}\) 是 Lie-代数值二形式。**量纲相同也不说明它们物理等价**。
- 朴素地定义 \(F^{\rm naive}_{\mu\nu}=\nabla_\mu A_\nu-\nabla_\nu A_\mu\)，则 \(\delta F_{\mu\nu}^{\rm naive}=-T^\rho{}_{\mu\nu}\partial_\rho\chi\)。一般破坏 \(U(1)\) 规范不变性。标准的 \(F=dA\) 没有该问题，但也没有因此推出时空挠率是电磁起源。
- 对一代最小 SM Weyl 费米子，配合 Higgs、Yukawa 和异常抵消，\(Y_Q=1/6\)。加入右手中微子和 Dirac 耦合后，存在一参数无局部异常超荷族，说明仅靠异常抵消还不总能唯一选择自然界电荷结构。详情参见 V132 与本轮代码精确有理数扫描。
- 通过 \(D_\mu=\partial_\mu+\omega_\mu+\mathcal A_{\mu}^{SU3}+\mathcal A_\mu^{SU2}+\mathcal A_\mu^{U1}\) 书写统一协变导数，是**已有群的直和记号**，不是它们从同一个基本运动原理的推导。
- 在粒子物理中，\(SU(5)\) 的 \(\overline{\mathbf5}\oplus\mathbf{10}\) 可以组织一代标准模型左手费米子，给出电荷量子化的结构性解释；但这是**选择一个更大群及表示**，不是由曲线 \((\kappa,\tau)\) 独立决定。中微子质量、质子衰变、阈值修正和完整量子一致性仍需额外研究。

## 6. 为什么从 \(c=1\) 与 \(\hbar\) 不能独立推出 \(G\)

\[
[G]=L/M,\quad [\hbar]=ML,\quad[G\hbar]=L^2.
\]

可以定义 \(\ell_P=\sqrt{G\hbar}\)。然而若将 \(G=\ell_P^2/\hbar\) 再称为 \(G\) 的推导，便是循环定义。欲建立独立预测，至少应从微观作用量中给出**不依赖实测 \(G\)** 的长度尺度 \(L_*\) 以及无量纲系数 \(\zeta\)：

\[
G_{\rm candidate}=\zeta L_*^2/\hbar,
\]

并明确它们的独立来源、计算误差、有效范围与观测一致性。只有一条几何恒等式无法确定质量/长度绝对尺度。

## 7. 独立实验应该如何判伪 ROOT

| 实验路线 | 已知理论的基线 | ROOT 必须额外给出的独立结果 | 关键混淆因素 |
|---|---|---|---|
| 真空光传播 | 局部 null cone、光子无质量 | \(R(k),\Omega(k)\) 或延迟的精确函数 | 仪器色散、材料路径、时钟同步 |
| 弯曲光纤偏振 | \(\gamma_\sigma=-\sigma\Omega_{solid}\) | 超出已知 Berry 相位的可复验偏差 | 纤维应力双折射、动态相位 |
| 精密圆偏振传播 | 两螺旋度传播基线 | 非零真空双折射且定量预测 | 磁场、材料和校准 |
| 高能耦合运行 | 标准模型 RGE | 明确的额外阈值与 beta 变化 | 匹配方案、未知谱 |
| 粒子谱/电荷 | 已知 SM 与异常抵消 | 不输入群/表示即可推出谱、电荷 | 任意参数与后验选择 |
| 引力 | GR + 完整应力能量张量 | 不反向标定的 \(G\)、或独立强约束偏离 | 多极矩、潮汐、轨道拟合 |
| 量子引力 | GR EFT 的低能基准 | 独立量子可观测量与误差预算 | 经典噪声、伪纠缠、环境作用 |

**优先顺序：** 先做“固定半径机械螺旋”的一致性筛选；再用 Berry 相位作无新参数的基准；最后才谈可检验的超出标准理论的额外效应。任何新参数必须事先固定，并在未用于拟合的数据上验证。
