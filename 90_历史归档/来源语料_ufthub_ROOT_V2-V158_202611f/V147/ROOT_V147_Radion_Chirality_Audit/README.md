## 30 秒启动

- **Windows**：双击 `scripts/运行_Windows.bat`（安装 Python 3.10+）。
- **Linux/macOS**：`bash scripts/run_linux.sh`。
- **命令行**：`python run_all.py`。

## 本轮五项定量结果

1. **磁通符号简并**：`V(R,+n)=V(R,-n)`，但内部 Dirac 指标 `ind(D)=qn` 反号。稳定性不能直接决定手征方向。
2. **临界轻径向场**：`D=B²−3AC>0`，`μ²=2√D/(K4 R_min^4)`，当 `D→0+`，径向场作用程增长，半径对参数敏感。
3. **条件性 Yukawa 第五力**：四维测试物质若耦合到 Jordan 度规，则标量力对**裸自旋2引力**的相对强度 `α=1/2`；真正作用程未独立给定。
4. **中性测试标量 KK 质量谱**：`μ_l²=μ6²+l(l+1)/R²`，简并 `2l+1`；这不是耦合引力—Maxwell 的全谱。
5. **规范异常不可只靠单态补救**：统一 `F=+1` 的三代标准模型需要抵消 `SU3²F=6`、`SU2²F=6`，增加仅为标准模型规范单态的费米子不能改变这两项；`B−L` 加右手中微子是一个已知异常可消的对照例。

## 边界和重要修正

- 此模型只是 V146 的 **Einstein–Maxwell–Λ 六维磁通紧化**加上新审计；它并没有从基础光速螺旋独立推导出作用量。
- `n=3` 仍是示例参数被特意调整后的结果，不是预测。
- `ℏ` 与 `G` 始终保留独立量纲，**只设置 c=1**。
- 不能把 63 项程序测试通过说成 63 项实验通过。
- 没有获取 GOCE、GRACE-FO、GRAIL、Eöt-Wash 的完整原始测量并做协方差拟合。
- 没有做完整六维混合涨落谱、六维手征异常抵消、量子辐射稳定性和非微扰真空跃迁。
