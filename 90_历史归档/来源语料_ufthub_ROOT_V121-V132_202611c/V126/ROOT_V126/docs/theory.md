# ROOT V126 理论审计

## 1. 候选三模式
S 标量扰动，V 矢量扰动，T 张量扰动。完整的矢量与张量场具有多个分量和规范约束。用三个标量幅度代表它们，仅在已选定物理极化并线性化后才可能有意义。

## 2. 色散严格推导
取 `(∂t²-∇²)Ψ+M²Ψ=0`，代入 `Ψ=u exp[i(kx-ωt)]`，得 `(M²-(ω²-k²)I)u=0`。非零解要求行列式为零。若 M² 为实对称半正定，存在正交变换对角化，得到 `ω²=k²+μ²`。正频分支的群速度 `vg=k/sqrt(k²+μ²)≤1`。如果存在负本征值，则长波 `k²<|μ²|` 会出现指数增长；所以“任何三波耦合均稳定”是错误命题。

## 3. 不可忽略的物理障碍
- 无质量矢量波的规范不变性需要横向物理自由度；任意 S-V-T 混合质量矩阵通常不满足规范不变性。
- 无质量自旋2的线性规范对称性及非线性一致性极其严格；不能任意混入质量项而仍声称是 GR。
- 弱、强相互作用涉及 SU(2) 与 SU(3) 非阿贝尔规范结构、手征费米子和量子化；S/V/T 自旋分类不自动产生这些群。
- 相对论的局域因果性要求检验完整偏微分方程的主符号和传播前沿；群速度≤1 的数值例子不能替代该证明。
- 黎曼猜想与零点谱之间没有已证实的四力物理对应。

## 4. 几何与平衡的闭环
可检验的基础是由具体作用量变分得出运动方程，并由对称性导出 Noether 守恒量；`δS=0` 本身不是完整物理理论。螺旋曲率 κ、挠率 τ 的恒等式描述几何，不自动生成引力耦合常数 G、粒子质量或电荷。

## 5. 下一轮明确判据
1. 指定完整协变场与规范变换；2. 推导允许的耦合并检查鬼场、梯度不稳定性和超光速前沿；3. 得到 GR+标准模型极限；4. 提出一个非调参、实验可否证的观测量；5. 与现有引力波、等效原理、原子钟、粒子散射实验对照。

## 6. 工程边界
点质量产生 1g 的公式 `M=gr²/G`；旋转等效重力 `rpm=60/(2π)*sqrt(g/R)`；磁能 `U=B²V/(2μ0)`。这些属于已知物理基准，不是可控新引力技术。真实引力控制没有在此得到证明。
