### 2.1 时空同一化的微分表达
根据公理2的时空同一化恒等式$d\boldsymbol{R}=\boldsymbol{C}dt$，对两边取模方可得：
$$d\boldsymbol{R} \cdot d\boldsymbol{R} = c^2 dt^2 \tag{6}$$

对于空间位移场$\boldsymbol{L}(\boldsymbol{r},t)$，其为空间坐标$\boldsymbol{r}=(x,y,z)$与时间$t$的函数；而根据公理2，空间坐标$\boldsymbol{r}$本身是时间$t$的函数，即空间几何点以光速$\boldsymbol{C}$运动，满足$d\boldsymbol{r}/dt=\boldsymbol{C}$。

时空同一化的核心是：时间与空间位移完全等价，因此任意场量的时间演化完全由空间位移的演化决定，即$\boldsymbol{L}(\boldsymbol{r},t)=\boldsymbol{L}(\boldsymbol{r}, R/c)$。根据多元函数链式法则，位移场对时间的一阶偏导满足：
$$\frac{\partial \boldsymbol{L}}{\partial t} = \frac{\partial \boldsymbol{L}}{\partial R} \cdot \frac{\partial R}{\partial t} = c \nabla \boldsymbol{L} \cdot \frac{\boldsymbol{C}}{c} = \nabla \boldsymbol{L} \cdot \boldsymbol{C} \tag{7}$$
该式建立了位移场时间演化与空间梯度的核心关联，是推导空间波动方程的关键桥梁。

### 2.2 二阶偏导与空间波动方程的严格推导
对式(7)两边再次求时间的一阶偏导，得到位移场对时间的二阶偏导。由于$\boldsymbol{C}$为常矢量（空间各向同性，光速的大小与方向均为常量），偏导算符$\partial/\partial t$与梯度算符$\nabla$可交换顺序，因此：
$$\frac{\partial^2 \boldsymbol{L}}{\partial t^2} = \frac{\partial}{\partial t} \left( \nabla \boldsymbol{L} \cdot \boldsymbol{C} \right) = \boldsymbol{C} \cdot \nabla \left( \frac{\partial \boldsymbol{L}}{\partial t} \right) \tag{8}$$

将式(7)的一阶偏导结果代入式(8)，可得：
$$\frac{\partial^2 \boldsymbol{L}}{\partial t^2} = \boldsymbol{C} \cdot \nabla \left( \nabla \boldsymbol{L} \cdot \boldsymbol{C} \right) \tag{9}$$

采用爱因斯坦求和约定（重复指标代表求和）对式(9)进行张量展开，设空间坐标为$x_i(i=1,2,3)$，对应$x,y,z$，矢量$\boldsymbol{C}$的分量为$C_i$，位移场$\boldsymbol{L}$的分量为$L_j$，则：
$$\boldsymbol{C} \cdot \nabla \left( \nabla \boldsymbol{L} \cdot \boldsymbol{C} \right) = C_i C_k \frac{\partial^2 L_j}{\partial x_i \partial x_k} \boldsymbol{e}_j \tag{10}$$

根据空间各向同性，宇宙空间在所有方向上具有完全相同的物理性质，结合时空同一化的核心关系$R=ct$，时间与空间位移的标量等价性直接消除了方向依赖，因此：
$$C_i C_k \frac{\partial^2 L_j}{\partial x_i \partial x_k} = c^2 \frac{\partial^2 L_j}{\partial x_i \partial x_i} = c^2 \nabla^2 L_j \tag{11}$$

将式(11)代入式(9)，整理后得到**空间波动方程的标准形式**：
$$\nabla^2 \boldsymbol{L} = \frac{1}{c^2} \frac{\partial^2 \boldsymbol{L}}{\partial t^2} \tag{12}$$
其齐次波动形式为：
$$\nabla^2 \boldsymbol{L} - \frac{1}{c^2} \frac{\partial^2 \boldsymbol{L}}{\partial t^2} = 0 \tag{13}$$

至此，我们完全基于SOM的两条第一性公理，无任何额外假设，严格推导出了空间波动方程，证明其是SOM公理体系的必然数学结果，而非独立的特设假设。

### 2.3 SOM螺旋位移场的本征解全矢量验证
本节将SOM的基础类光螺旋位移场代入空间波动方程，完成全矢量验证，证明其是方程的严格本征解。

取沿任意波矢$\boldsymbol{k}$方向传播的SOM螺旋位移场，$\boldsymbol{e}_1, \boldsymbol{e}_2, \boldsymbol{k}/k$构成正交右手系，其表达式为：
$$\boldsymbol{L}(\boldsymbol{r},t) = r_0 \left[ \boldsymbol{e}_1 \cos(\boldsymbol{k}\cdot\boldsymbol{r} - \omega t + \phi_0) + \boldsymbol{e}_2 \sin(\boldsymbol{k}\cdot\boldsymbol{r} - \omega t + \phi_0) \right] + v_\parallel \frac{\boldsymbol{k}}{k} t \tag{14}$$

#### 步骤1：计算时间二阶偏导
对式(14)求时间二阶偏导，轴向分量的二阶偏导为0，仅横向分量有贡献：
$$\frac{\partial^2 \boldsymbol{L}}{\partial t^2} = - r_0 \omega^2 \left[ \boldsymbol{e}_1 \cos(\dots) + \boldsymbol{e}_2 \sin(\dots) \right] = - \omega^2 \boldsymbol{L}_\perp \tag{15}$$
其中$\boldsymbol{L}_\perp$为位移场的横向分量。

#### 步骤2：计算拉普拉斯算符作用结果
对式(14)作用三维拉普拉斯算符，轴向分量的拉普拉斯运算结果为0，横向分量满足：
$$\nabla^2 \boldsymbol{L} = - r_0 k^2 \left[ \boldsymbol{e}_1 \cos(\dots) + \boldsymbol{e}_2 \sin(\dots) \right] = - k^2 \boldsymbol{L}_\perp \tag{16}$$

#### 步骤3：代入波动方程验证
将色散关系$\omega=ck$代入式(16)，可得：
$$\nabla^2 \boldsymbol{L} = - k^2 \boldsymbol{L}_\perp = - \frac{\omega^2}{c^2} \boldsymbol{L}_\perp = \frac{1}{c^2} \frac{\partial^2 \boldsymbol{L}}{\partial t^2} \tag{17}$$

可见，SOM类光螺旋位移场的横向分量与轴向分量均严格满足空间波动方程，证明稳态类光圆柱螺旋是空间波动方程的天然本征模式。

### 3.1 一维空间波动方程的通解（达朗贝尔公式）

$$\frac{\partial^2 L}{\partial z^2} = \frac{1}{c^2} \frac{\partial^2 L}{\partial t^2} \tag{18}$$

引入特征变量$\xi = z - ct$，$\eta = z + ct$，将方程转化为可直接积分的形式：
$$\frac{\partial^2 L}{\partial \xi \partial \eta} = 0 \tag{19}$$

对$\xi$和$\eta$分别积分，得到一维波动方程的通解——达朗贝尔公式：
$$L(z,t) = f(z - ct) + g(z + ct) \tag{20}$$
其中$f$和$g$为任意二阶可微函数，由初始条件与边界条件唯一确定。

**SOM体系下的物理意义**：
- $f(z-ct)$：沿$z$轴正方向传播的右行波，对应SOM体系中正向类光螺旋波，是空间发散运动的数学表达，对应电磁场辐射、物质的运动效应；

### 3.2 三维空间波动方程的通解
#### 3.2.1 球对称通解（球面波形式）
对于球对称场景，位移场仅与径向距离$r=|\boldsymbol{r}|$和时间$t$相关，与角度无关，三维波动方程在球坐标系下简化为：
$$\frac{1}{r^2} \frac{\partial}{\partial r} \left( r^2 \frac{\partial L}{\partial r} \right) = \frac{1}{c^2} \frac{\partial^2 L}{\partial t^2} \tag{21}$$

引入辅助函数$V(r,t) = r L(r,t)$，方程可转化为一维波动方程，求解后代入辅助函数，得到球对称三维波动方程的通解：
$$L(r,t) = \frac{f(r - ct)}{r} + \frac{g(r + ct)}{r} \tag{22}$$

**SOM体系下的物理意义**：
- $\frac{f(r-ct)}{r}$：从原点向外发散的球面波，振幅随$1/r$衰减，对应SOM体系中物质周围空间的光速发散螺旋运动，是电磁场、电磁辐射的本源，其$1/r$衰减规律与库仑场、毕奥-萨伐尔定律完全一致；

#### 3.2.2 一般三维场景的通解（平面波叠加与完备性证明）
对于任意非球对称的三维场景，波动方程的通解可通过傅里叶变换分解为任意方向平面波的叠加：
$$\boldsymbol{L}(\boldsymbol{r},t) = \int_{\mathbb{R}^3} \left( \boldsymbol{A}(\boldsymbol{k}) e^{i(\boldsymbol{k}\cdot\boldsymbol{r} - \omega t)} + \boldsymbol{B}(\boldsymbol{k}) e^{i(\boldsymbol{k}\cdot\boldsymbol{r} + \omega t)} \right) d^3 k \tag{23}$$

**SOM螺旋本征模式的完备性证明**：
取波矢$\boldsymbol{k}$沿$z$轴方向，即$\boldsymbol{k}=(0,0,k)$，并取振幅$\boldsymbol{A}(\boldsymbol{k})=(A, iA, 0)$，代入式(23)取实部，直接得到SOM基础圆柱螺旋位移场：
