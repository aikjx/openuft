【垂直原理（定性）】
  空间中任意一点最多可作三条相互垂直的直线（三维垂直状态）。
  处于垂直状态中的空间点必然运动，且运动轨迹重新构成垂直状态。

【数学推论链】
  三维垂直 → 运动方向不断变化 → 曲线运动
  → 圆周只有2条垂直切线（T,N），不足以覆盖三维
  → 必须叠加垂直方向直线 → 圆柱螺旋 r=(R cosωt, R sinωt, bt)
  → Frenet标架{T,N,B}两两垂直（第三条切线=副法向B）
  → 速度分解 v²=v⊥²+v∥² → 光速约束 v⊥²+v∥²=c²
  → 三重奏 κ²+τ²=(ω/v)²（R4/R9已严格证明）

V4: 垂直原理→三重奏对接 κ²+τ²=(ω/v)²
======================================================================
  垂直原理 ⟹ 圆柱螺旋运动 r(t)=(R cosωt, R sinωt, bt)
  螺旋的Frenet曲率/挠率（解析）：
    κ = Rω² / v²
    τ = ωb / v²
    κ² + τ² = (R²ω⁴ + ω²b²) / v⁴ = ω²(R²ω²+b²) / v⁴ = ω²v² / v⁴ = (ω/v)²

【结论】
  1. 垂直原理在数学上等价于'空间点做圆柱螺旋运动'
  2. 螺旋的Frenet标架{T,N,B}精确满足三维正交性（sympy证明）
  3. 速度分解 v²=v⊥²+v∥²，光速约束下 v⊥²+v∥²=c²
  4. 垂直原理⟹三重奏定理 κ²+τ²=(ω/v)²（已严格证明）
  5. 纯圆周(b=0)退化为二维、直线(R=0)退化为一维，
     从反面验证了三维垂直原理要求螺旋运动的必要性

【诚实标注】
  - 垂直原理本身是公理/假设（张祥前统一场论基本假设）
  - 从垂直原理到螺旋运动是定性推理+数学形式化
  - 螺旋运动的Frenet正交性、速度分解、三重奏是严格定理
  - '空间以光速运动'是额外公设，非垂直原理本身的推论
  - 垂直原理尚未被实验直接验证，属于理论自洽的公理体系
