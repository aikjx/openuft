### A.1 康普顿波长偏移公式的详细推导

基于空间螺旋运动假设，我们可以详细推导康普顿波长偏移公式。

#### A.1.1 能量守恒和动量守恒

考虑一个初始波长为λ₀的光子与一个静止的电子发生碰撞，碰撞后光子的波长为λ，散射角为θ，电子获得的动量为p_e，动能为T。

根据能量守恒定律，我们有：

E₀ + m₀c² = E + (m₀c² + T)

其中，E₀ = hc/λ₀为入射光子的能量，E = hc/λ为散射光子的能量，m₀c²为电子的静止能量。

整理后得到：

E₀ - E = T  (A.1)

根据动量守恒定律，在光子的入射方向和散射方向上，我们有：

p₀ = pcosθ + p_e cosφ  (A.2)
0 = psinθ - p_e sinφ  (A.3)

其中，p₀ = h/λ₀为入射光子的动量，p = h/λ为散射光子的动量，φ为电子的反冲角。

#### A.1.2 相对论能量动量关系

根据相对论能量动量关系，电子的能量和动量满足：

(E_e)² = (m₀c²)² + (p_e c)²  (A.4)

其中，E_e = m₀c² + T为电子的总能量。

将式(A.4)展开，我们得到：

T² + 2T m₀c² = (p_e c)²  (A.5)

#### A.1.3 推导波长偏移公式

从式(A.2)和式(A.3)中消去φ，我们可以得到：

p_e² = p₀² + p² - 2p₀pcosθ  (A.6)

将式(A.6)代入式(A.5)，并利用式(A.1)，我们可以得到：

(E₀ - E)² + 2(E₀ - E)m₀c² = (p₀c)² + (pc)² - 2p₀pc cosθ  (A.7)

由于光子的能量和动量满足E = pc，因此有p₀c = E₀，pc = E。代入式(A.7)，我们得到：

(E₀ - E)² + 2(E₀ - E)m₀c² = E₀² + E² - 2E₀E cosθ  (A.8)

展开并整理式(A.8)，我们得到：

E₀² - 2E₀E + E² + 2E₀m₀c² - 2E m₀c² = E₀² + E² - 2E₀E cosθ  (A.9)

化简后得到：

-2E₀E + 2E₀m₀c² - 2E m₀c² = -2E₀E cosθ  (A.10)

进一步整理得到：

E₀E(1 - cosθ) = m₀c²(E₀ - E)  (A.11)

利用E₀ = hc/λ₀和E = hc/λ，代入式(A.11)，我们得到：

(hc/λ₀)(hc/λ)(1 - cosθ) = m₀c²(hc/λ₀ - hc/λ)  (A.12)

化简后得到：

λ - λ₀ = (h/(m₀c))(1 - cosθ)  (A.13)

这就是康普顿波长偏移公式，其中λ_c = h/(m₀c)为电子的康普顿波长。

### A.2 康普顿散射截面的推导

基于空间螺旋运动假设，我们可以推导出康普顿散射截面。

#### A.2.1 克莱因-仁科公式

康普顿散射截面可以用克莱因-仁科公式表示：

(dσ)/(dΩ) = (r_e²/2)(E/E₀)²[E₀/E + E/E₀ - sin²θ]  (A.14)

其中，r_e = e²/(4πε₀m₀c²)为康普顿波长，E₀为入射光子能量，E为散射光子能量，θ为散射角。

#### A.2.2 低能极限

在低能极限下（E << m₀c²），E ≈ E₀，克莱因-仁科公式可以简化为汤姆孙散射截面：

(dσ)/(dΩ) = (r_e²/2)(1 + cos²θ)  (A.15)

这与经典电磁理论的结果一致。

#### A.2.3 高能极限

在高能极限下（E >> m₀c²），克莱因-仁科公式可以简化为：

(dσ)/(dΩ) ≈ (r_e²/2)(E₀/E)[1 - (E/E₀)sin²θ]  (A.16)

这反映了高能光子与电子相互作用的相对论特性。

### A.3 反冲电子能量的推导

基于空间螺旋运动假设，我们可以推导出反冲电子的能量与散射角的关系。

#### A.3.1 反冲电子能量的表达式

反冲电子的能量T可以表示为：

T = E₀ - E  (A.17)

利用康普顿波长偏移公式，我们可以将E表示为：

E = E₀/(1 + (E₀/(m₀c²))(1 - cosθ))  (A.18)

代入式(A.17)，我们得到：

T = E₀[1 - 1/(1 + (E₀/(m₀c²))(1 - cosθ))]  (A.19)

化简后得到：

T = E₀²(1 - cosθ)/(m₀c² + E₀(1 - cosθ))  (A.20)

这就是反冲电子能量与散射角的关系。

#### A.3.2 最大反冲电子能量

当散射角θ = 180°时，反冲电子的能量最大，此时：

T_max = 2E₀²/(m₀c² + 2E₀)  (A.21)

在高能极限下（E₀ >> m₀c²），最大反冲电子能量可以近似为：

T_max ≈ E₀ - m₀c²/2  (A.22)

这反映了高能光子与电子相互作用的相对论特性。
