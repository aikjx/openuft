attack_C0179 · 胶球质量谱与 f0(1500)/f0(1710) 混合（母册 T339）攻破

[E1] 实验候选事实（PDG 只引用不复算）
  f0(1500) = 1505 MeV；f0(1710) = 1714 MeV
  任务取整口径：1500 / 1710 MeV ⇒ 质量差 210 MeV
  => 两个标量共振，被视为 0⁺⁺ 胶球与 u/d/s 夸克态的混合候选。

[E2] 格点 QCD 胶球谱比独立精算（本册核心）
  格点纯胶谱（中心）：0⁺⁺=1600 MeV、2⁺⁺=2400 MeV、0⁻⁺=2600 MeV
  R(2⁺⁺/0⁺⁺) 中心 = 1.500000（=2400/1600）
  R(0⁻⁺/0⁺⁺) 中心 = 1.625000
  0⁺⁺ 误差带 1.5–1.7 GeV 滑动 ⇒ R(2⁺⁺/0⁺⁺) ∈ [1.411765, 1.600000]
                     R(0⁻⁺/0⁺⁺) ∈ [1.529412, 1.733333]
  => 轨道/激发态比基态重 ~1.4–1.6 倍，与格点 QCD 标准预言一致。

[E3] f0(1500)/f0(1710) 两态 2x2 混合反演（取 M_g=1650 MeV）
  Δ = m2 - m1 = 1714 - 1505 = 209 MeV
  迹不变量 trace = 1505 + 1714 = 3219 MeV ⇒ M_q = trace - M_g = 1569 MeV
  对角分裂 Δd = |M_q - M_g| = 81 MeV；要求 Δ ≥ Δd 才物理（209 ≥ 81）
  非对角混合元 V = 0.5*sqrt(Δ²-Δd²) = 96.3328 MeV
  tan(2θ) = 2V/Δd = 2.378587；cos(2θ) = 1/sqrt(1+tan²2θ) = 0.387560
  => 混合角自由度存在；f0(1710) 胶球成分分数 = 0.693780（≈ 69.38%）

[E4] 胶球占比约束：M_g 在格点带 1.5–1.7 GeV 扫描
  M_g=1500 MeV ⇒ 判别式 -4280 < 0 ⇒ 非物理（无实混合元）
  M_g=1650 MeV ⇒ M_q=1569 MeV, V=96.33 MeV, f0(1710) 胶球占比=0.6938（69.38%）
  M_g=1600 MeV ⇒ M_q=1619 MeV, V=104.07 MeV, f0(1710) 胶球占比=0.5455（54.55%）
  M_g=1700 MeV ⇒ M_q=1519 MeV, V=52.25 MeV, f0(1710) 胶球占比=0.9330（93.30%）
  => 格点带内物理点 f0(1710) 胶球占比 54.6%–93.3%，与文献『胶球富集』定性一致；
     M_g=1500 MeV 端判别式为负 ⇒ 纯胶态不能低至 1.5 GeV 而仍给出实分裂。

[E5] 裁定
  胶球谱与 f0 混合的物理内容 = SU(3) 规范场纯胶态的禁闭动力学（格点 QCD 数值）。
  (a) 谱比 R(2⁺⁺/0⁺⁺) 由格点纯胶作用量给定（E2）；
  (b) f0 混合由夸克-胶 2x2 矩阵给定（E3/E4），V 是强子物理拟合量。
  TUFT/几何框架：无胶场自由度、无格点纯胶作用量、无夸克-胶混合元供给。
  => 胶球谱依赖 SU(3) 规范场纯胶态动力学（格点 QCD），
     TUFT 无胶场/无格点谱供给 ⇒ 结构性负面，按母册登记撞 C6/C7。
