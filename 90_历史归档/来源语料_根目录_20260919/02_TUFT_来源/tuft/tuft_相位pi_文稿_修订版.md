## 一、基础几何设定（修订）

费米子 = 局部满足 `v_local = c` 的**类光闭合螺旋**。

**修订 1（参数化）**：类光曲线 `ds² = c²dt² − |dx|² = 0` ⇒ **固有时 `dτ = ds/c = 0` 处处为零**。
故不能用固有时参数化。改用**仿射参数 λ**：`dx/dλ = c·û(λ)`（把仿射速度归一为 c）。

**修订 2（Frenet–Serret）**：设 `û = t̂`、`n̂`、`b̂` 为 Frenet 标架，则

```
dt̂/ds =  κ·n̂          （切矢变化率由【曲率 κ】驱动）
dn̂/ds = −κ·t̂ + τ·b̂
db̂/ds = −τ·n̂          （【挠率 τ】是副法矢的导数）
```

> 原稿写 `dû/dτ = T·n̂` 把 **κ 与 τ 的角色互换**——这是实质性错误，已修正。

## 二、两种转动：必须区分（修订 5）

| 操作 | 数学身份 | 结论 |
|---|---|---|
| 外部空间旋转 2π | SO(3) 绕固定轴转一圈 | 其 1/2 自旋表示给 −1（**表示论**） |
| 莫比乌斯带中心线走一圈 | 带子的**单侧性**（法向翻转） | 几何相位翻转 |

> **诚实标注**：两者"相位相等"在原稿中**被直接断言但未证明**。本修订版明确：这是**待证明的对应**，
> 不是推导结论。（自旋 1/2 的严格根源是 `π₁(SO(3)) = ℤ₂` 双覆盖，与莫比乌斯带无逻辑必然联系。）

## 三、相位 = π 的推导（修订 3、4）

原稿链条为：

```
Δφ = (2π/ℏ)·αKΩ · ∮T dτ · 1/(2π)
```

**修订 3**：由通式 `Δφ = (αKΩ/ℏ)·X`（`X = ∮T dτ`），要得 `Δφ = π` **必须** `X = ℏπ/(αKΩ)`。
原稿直接把该值作为"挠率线积分"给出 —— 这是**倒推**（以"莫比乌斯给 π"为输入反解 ∮T dτ，再回到 π）。

**修订 4**：末尾 `1/(2π)` 是为凑 π 而加的补偿因子（`ω = dφ/dτ` 本已定义相位），**删除**。

**修订后的正确表述（条件推导）**：

> 若独立地证明了 `∮T dτ = ℏπ/(αKΩ)`（例如由 TUFT 场方程与结的解给出），则 `Δφ = π`。
> **当前该积分值无独立来源**，故 `Δφ = π` 在本框架内是**待证命题**，不是已成立结论。

## 四、玻色子对比（修订 7）

- **轨道/标量相位**：绕轴旋转 2π ⇒ `ψ → +ψ`（标量/轨道相位）；
- **交换对称性**：交换两玻色子 ⇒ `+ψ`。

> 这两者**不是同一操作**。原稿用"一圈相位 2π ⇒ 波函数不变 ⇒ 交换对称"把二者混为一谈，已修正。

---

## 五、误区澄清（修订 6）

**误区**："挠率是费米子自旋拓扑的必要条件。"

**修正**：纯黎曼时空（`T = 0`）中，只要存在**自旋结构**，Dirac 旋量与自旋-1/2 表示**完全良定义**
（弯曲时空 Dirac 方程成熟）。**挠率（爱因斯坦-嘉当）是可选的扩展，不是自旋的必要条件。**
自旋 1/2 的拓扑根源是 **SO(3) 的 ℤ₂ 双覆盖**。

## 六、拓扑不变量（修订）

- **正确对象**：A 用 `Lk = Tw + Wr ∈ ½ℤ`（自链接数）；`Tw = n/2`（半扭转数）。
- **术语纠正**：S¹ 的 winding number ∈ ℤ（整数）；半整数只出现在 **Lk**。
- **积分身份**：`(1/4π)∮ û·(dû×d²û) dλ` 是切标架的 **writhe**，不是"挠率线积分 Tw"，两者是不同量。

## 七、定量小结（修订版）

| 拓扑类型 | 一圈行为 | 波函数 | Lk |
|---|---|---|---|
| 费米子（莫比乌斯型闭合带，n 奇） | 法向翻转 | `ψ(θ+2π) = −ψ` | `n/2 ∈ ℤ+½` |
| 玻色子（可定向闭合带，n 偶） | 法向不变 | `ψ(θ+2π) = +ψ` | `n/2 ∈ ℤ` |

> 注：左列"一圈行为"是**几何**（带子单侧性）；右列"波函数"是**表示论**（SO(3) 双覆盖）。
> 二者的严格桥梁 = 自旋-统计定理，**不是**本稿的一句话推导。

## 八、数值验证（修订 8、9）：正确代码

**原稿缺陷**：`x=(2+0.5cos(τ/2))cos τ` 使中心线半径从 2.5 变到 1.5 ⇒ **曲线不闭合**
（起点 `(2.5,0,0)`、终点 `(1.5,0,0)`、间距 1.0000）⇒ W 积分无拓扑意义；实跑得 `W = −0.0029`。

**修正构造**：中心线 = **闭合**单位圆；法向标架 = 半扭转（莫比乌斯）。
用 Gauss 双链积分计算带子与其法向偏移副本的**链接数 Lk**：

| 构造 | Lk 数值 | 判定 |
|---|---|---|
| 普通环（0 半扭转） | `+0.0000` | 整数（玻色）✓ |
| **莫比乌斯带（1 半扭转）** | **`−0.4999`** | **半整数（费米）✓** |
| 2 半扭转（可定向） | `−1.0000` | 整数（玻色）✓ |

**White 公式交叉验证**：中心线为平面圆 ⇒ `Wr = 0` ⇒ `Lk = Tw = 1/2` ✓ 与数值一致。

> **正面结论**：原稿声称的"半整数环绕 1/2"**在闭合构造下确实成立**；
> 原稿的问题只在**数值实现**（不闭合），而非拓扑断言本身。

## 九、诚实边界与结论

1. **成立的部分**：`ψ(θ+2π) = −ψ`、`ψ(θ+4π) = +ψ`（SU(2)/SO(3) 双覆盖，表示论事实）；
   闭合莫比乌斯带的 `Lk = ±1/2`（数值 PASS）。
2. **未证明的部分**：`∮T dτ = ℏπ/(αKΩ)`（反设）；"莫比乌斯绕行 = 外部旋转"（跳跃）；
   "挠率是自旋必要条件"（与已知物理矛盾，已删）。
3. **红线**：本修订版只做框架内自洽与数值修正，**不主张** TUFT 比标准量子场论更基本，
   也不否认"莫比乌斯带 → 费米统计"是已知拓扑事实（Leinaas–Myrheim / Laidlaw–DeWitt）。
