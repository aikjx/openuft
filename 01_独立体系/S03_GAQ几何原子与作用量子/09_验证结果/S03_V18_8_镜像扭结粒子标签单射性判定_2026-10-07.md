## §0 一句话结论

「正反费米子 = 左右手镜像扭结」在**窄域**（固定的单个手性纽结，区分它与它的镜像）数学上成立（V8-e，PASS）。但作为**粒子身份标签**彻底失败：手性/镜像标签至多 2 值，违反 V18.2 V2-d 的单射性（V8-a）与单调性（V8-d）；若改用 `Wr` 符号作代理，则 `Wr` 本身不是拓扑不变量（V8-b，机器：unknot 加 R1 小结后 `Wr` 从 0 变 0.439）。

⇒ GAQ 用「镜像扭结」只能解决**粒子 vs 反粒子**这一对，对 SM 的代际、轻子味、中微子、电荷等自由度无能为力（V8-f）。这恰好坐实 V18.6 §7 的缺口 1、2（电荷未定义、量子化未导出）。

## §2 Writhe 不是拓扑不变量（V8-b，FAIL）

**FAIL（V8-b）**：若 GAQ 以「`Wr` 符号」作手性标签，则标签依赖空间嵌入而非拓扑类型——同一纽结类型的不同嵌入可有不同 `Wr`。Reidemeister I 移动不改变纽结类型却改变 `Wr`。

机器（SC2）：在 unknot 上插入一个 R1 小结（kink），按 R1 不变性纽结类型仍为 unknot，但 `Wr` 从 `0` 变为 `0.439463`。⇒ `Wr` 非拓扑不变量。

**后果**：若用 `Wr` 符号当物理标签，同一粒子（同一拓扑类型）在不同空间取向/嵌入下会得到**不同的标签** ⇒ 物理上不一致。必须用**手性 chirality**（拓扑量，2 值）而非 `Wr` 符号。而手性本身也只有 2 值（见 §3）。

## §3 手性标签的承载容量：单射性与单调性（V8-a / V8-d）

手性作为拓扑量只有 2 个取值：`chiral` / `achiral`；或等价地，固定嵌入下的 `Wr` 符号：`−1 / +1 / 0`。**一个 2 值标签至多区分 2 个拓扑类。**

### 单射性失败（V8-a，FAIL）

SM 费米子物种（含反粒子、三代、三色夸克）= **48**；仅带电轻子 + 反粒子 = 6；仅轻子（含中微子）含反粒子 = 12。

| 费米子 | 手性符号 | 是否被区分 |
|---|---|---|
| `e⁻ / μ⁻ / τ⁻` | `−1` | 三者同标签 ⇒ 混淆 |
| `ν_e / ν_μ / ν_τ` | `−1` | 与带电轻子同标签 ⇒ 混淆 |
| `e⁺ / μ⁺ / τ⁺` | `+1` | 三者同标签 ⇒ 混淆 |

机器（SC5）：12 个轻子物种 > 2 个标签容量。

机器（SC4，更强的证据）：`(2,3)` 与 `(2,5)` 是两个**拓扑不同**的手性纽结，但在「左手」嵌入下 `Wr` 同为 `−`（`−3.518030` / `−6.865786`）⇒ 它们落入**同一个手性标签** ⇒ 即便限定 chiral，仍不能区分代际。

**FAIL（V8-a）**：手性/镜像标签至多 2 值 ⇒ 不能单射区分多物种费米子 sector，违反 V18.2 V2-d 的单射性。

### 单调性失败（V8-d，FAIL）

机器（SC6）：带电轻子 3 代（`e⁻ / μ⁻ / τ⁻`）需要 `≥3` 个可排序的标签来表达质量层次 `e < μ < τ`；`±1` 提供不了任何序。

**FAIL（V8-d）**：手性符号 `∈ {±1}` 无法承载代际/质量层次，违反 V18.2 V2-d 的单调性。

## §4 窄域成立项与边界

**PASS（V8-e）**：镜像操作对**单一**手性纽结正确区分粒子与其反粒子（`e⁻` 与 `e⁺`）。镜像 `Wr` 严格反号（SC3/SC4，机器零误差）。「正反费米子 = 镜像扭结」作为 **粒子↔反粒子成对区分**的窄域主张数学上成立。

**BOUNDARY（V8-c）**：基底纽结必须本身 `chiral`；若选 `amphichiral`（如 figure-eight 4_1）纽结，则镜像 = 自身 ⇒ `e⁻ = e⁺`（无反粒子），错误。GAQ 未指定「取哪个 chiral 纽结」⇒ **自由参数**；且不同 chiral 纽结（`3_1`、`5_1`）均落入同一「chiral」标签，故即使限定 chiral，仍不能区分代际（SC4）。

**INFO（V8-f）**：GAQ 仍未给出轻子味 / 中微子 / 电荷的独立拓扑标签（承接 V18.6 §7 缺口 1、2）。手性标签只解决「粒子 vs 反粒子」这一对，对 SM 其余自由度无能为力。

## §5 与既有判决的合流

- 与 V18.2 V2-d（标签须单射且单调）：本册是 V2-d 标准的**直接应用**——手性标签 2 值，单射性与单调性双失败。

- 与 V18.6 V6-f（镜像 `Wr` 机器零反号）：本册在 V6-f 的「可算」之上补了「**不可作身份标签**」的判定——可算 ≠ 可用作粒子标签。
- 与 V18.7（闭合性二难）：GAQ 两端孤子（闭合费米扭结 / 开式光子）本身连 `Lk` 都无良定义（V18.7 V7-a、V18.6 V6-e），故「镜像扭结」在 GAQ 实际场线上的**几何载体仍缺失**——本册的标签容量问题叠加其上，使分支三的可判决量进一步收窄到「仅粒子↔反粒子成对区分」。

## §6 裁定

| 子主张 | 裁定 | 依据 |
|---|---|---|
| 正反费米子 = 镜像扭结（窄域：区分一对） | **PASS** | SC3/SC4 镜像 `Wr` 反号 |
| 手性标签可作粒子身份标签 | **FAIL** | V8-a 单射失败（2 值 vs ≥12 物种）；V8-d 单调失败 |
| 以 `Wr` 符号作标签 | **FAIL** | V8-b `Wr` 非拓扑（unknot+kink：`Wr` 0→0.439） |
| 基底须 chiral（否则 `e⁻=e⁺`） | **BOUNDARY** | V8-c 自由参数 |
| 代际/味/电荷标签 | **INFO（未提供）** | V8-f 承接 V18.6 缺口 |

**对分支三的净效果**：分支三唯一还站得住的用途是「`e⁻ ↔ e⁺` 成对区分」。但 V18.7 已表明 GAQ 两端孤子的 `Lk` 均无良定义，且本册表明即使有良定义的手性标签也**装不下 SM 的多重自由度**。⇒ **分支三无法支撑 GAQ 的费米子 sector 身份理论**；要支撑必须另引入未提供的标签（代际、味、电荷各自的拓扑不变量）。
