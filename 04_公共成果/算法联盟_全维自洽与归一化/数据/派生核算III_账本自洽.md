### 1.2 R0-b 谱族秩饱和：符号版

模型 `E(n) = -R/n^2 (1 + alpha^2/n + mu*alpha^3/n^2)`，雅可比的
三个符号列函数为：

$$\frac{\partial \ln E}{\partial \ln \theta_{1}} = 1$$
$$\frac{\partial \ln E}{\partial \ln \theta_{2}} = \frac{\alpha^{2} \left(3 \alpha \mu + 2 n\right)}{\alpha^{3} \mu + \alpha^{2} n + n^{2}}$$
$$\frac{\partial \ln E}{\partial \ln \theta_{3}} = \frac{\alpha^{3} \mu}{\alpha^{3} \mu + \alpha^{2} n + n^{2}}$$

列数恒为 3，与 `N` 无关，故 `rank(J[:N]) <= 3` 对**一切** `N` 成立。
前 3 行符号行列式非零，故 `N >= 3` 时秩达到 3。

## 2. 定理 Q：残差自洽 —— 前册的「高精度命中」是表自己的闭合误差

这是本册最要紧的一条。**II 册报告的核心成果**
「复现 `xi = 1/(4pi)`，相对残差 `6.097090e-10`」与
**锚表内部的 `eps0 <-> alpha` 不一致**是同一个算术量的两种写法：

| 量 | 值 |
| --- | --- |
| xi 的绝对残差（II 册报告的 4.85e-11） | 4.851910231397964e-11 |
| xi 的相对残差 `rel_xi` | 6.097090215534799e-10 |
| eps0 <-> alpha 表内不一致 `rel_tab` | 6.097090219252250e-10 |
| 两者之差 | 3.717e-19 |
| `X = 4 pi alpha eps0 hbar c / e^2` | 1 -6.097e-10 |
| `rel_tab * X - rel_xi` | 0.000e+00 |

令 `X := 4\pi\alpha\varepsilon_0\hbar c / e^2`，则

$$\mathrm{rel}_{\xi}=|X-1|,\qquad\mathrm{rel}_{tab}=\left|\tfrac1X-1\right|=\frac{|X-1|}{X}\quad\Rightarrow\quad \mathrm{rel}_{tab}\cdot X=\mathrm{rel}_{\xi}$$

该恒等式 sympy 化简为 **0**（自检 Q-1b），因此两边相差只是 `delta^2` 量级，
不是两个独立事实偶然相等。

原因：`eps0` 不是独立测量，它在 SI 中定义为

$$\varepsilon_0 = \frac{e^2}{4\pi\alpha\hbar c}$$

于是 `alpha` 在表里登记了**两次** —— 一次藏身锚 `eps0`，
一次作为靶 `alpha`。声称「由 `{e, eps0, hbar, c}` 派生 `alpha`」，
是在拿 `alpha` 自己比 `alpha`。

| 声明 | 相对残差 | 诊断 |
| --- | --- | --- |
| alpha <- {e, eps0, hbar, c} | 6.097090e-10 | eps0 = e^2/(4 pi alpha hbar c) 是 SI 定义式；alpha 以锚 eps0 与靶 alpha 两次登记 |
| m_P <- {hbar, c, G} | 1.571613e-07 | m_P = sqrt(hbar c/G) 是定义式；残差纯属位数截断 |
| m_mu/m_e <- {m_mu, m_e} | 7.822514e-11 | 同名比；残差 7.823e-11 属位数限制 |
| 锚表自身的 eps0 <-> alpha 闭合 | 6.097090e-10 | 超出标称不确定度 4.1 倍，表不自洽 |

> **残差 = 表的算术闭合误差，不是理论对自然的拟合优度。**
> 该类声明的可计入信息量为 0，`h_eff` 应记 **0**。

### 1.3 反身一击：这个残差还超出了表自己的标称精度
