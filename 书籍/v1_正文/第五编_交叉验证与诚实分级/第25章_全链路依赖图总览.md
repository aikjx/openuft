## 25.1 各体系内部依赖图

全链路方法论要求：每条物理结论都能沿"公设→引理→定理→公式"追溯到第一性公设，且图上无环。下面把主要体系的内部依赖链逐条画出。

### 25.1.1 S13：三公理 → 六方程 M1–M6

S13 是全书中唯一做过**传递闭包实测**的体系。依赖结构：

```
公理一(对偶0/1) ─┐
公理二(守恒)   ─┼─→ M1 旋量方程 ─→ 归一化 ─→ M2 涌现规范 ─→ M3 霍普夫荷
公理三(自相似) ─┘                     │
                                       ├─→ M1+真空约束 ─→ 希格斯谱
公理三 ─────────────────→ M4 双向β流 ─→ 不动点 ─→ 分形维 D=4−γ
公理三 ─────────────────→ M5 对偶镜像度规 ─→ 曲率有界
M1(流守恒) + M5(零面) ────────────────→ M6 因果畴通量
```

**实测结果**（S13 ch19/ch20）：

- 邻接矩阵构造后做传递闭包：从任一公理出发，六方程全部可达（**公理全可达 = 真**）。
- 任取两方程检查双向可达：15 对中**双向可达对数 = 0**——图是严格无环的树。
- 这排除了"用结论反推公设"的循环论证嫌疑。

### 25.1.2 S01：A1 → Frenet → κ/τ → 三重奏

```

A3(D维生成元) → Σκᵢ² = −tr(A²)/(2v²)
```

### 25.1.3 S02：v=c 特化 + 独立的动力学链

S02 有**两条互不相交的链**：

```
链一(几何)：v=c → Frenet → κ/τ → 三重奏特化 → Darboux 标架 ω_D
链二(动力学)：A1 P=m(c−v) → A2 F=dP/dt → D5 展开式
```

链一无环。链二同样无环，但 D5 展开式 $\boldsymbol F=\boldsymbol c\dot m-\boldsymbol v\dot m+m\dot{\boldsymbol c}-m\dot{\boldsymbol v}$ 只是 $d[m(c-v)]/dt$ 的代数恒等，**四力物理对应未论证**——动力学链在"恒等展开"到"四力标签"之间断裂。

```
                                          ├→ T2 G=ħc/M_p²
```

无环。但 T1 是 A5 定义式的直接代入（1 步），T2/T3 是 T1 的定义重排——**整条链在数学上闭合，物理独立性接近零**。

## 25.2 跨体系依赖图（借用关系）

跨体系边分两类：**数学借用**（借公式语言，不借物理结论）与**物理借用**（直接把上游方程放进自己的公设）。

```
S01 ──数学借用──→ S02（三重奏 v=c 特化）
S01 ──数学借用──→ S07（Frenet、复曲率）
S01 ──数学借用──→ S10（复曲率 Ξ=κ+iτ）
S01 ──数学借用──→ S12（核心恒等式）
S02 ──物理借用──→ S12（A4：P=m(c−v)、F=dP/dt）
S03 ──母本─────→ S04 / S05 / S07 / S08 / S09
S04 + S05 + S06 ─组合─→ S07(v4)
S07(v4) ──演进──→ S08(v5) ──演进──→ S09(v6)
S13 ──独立─────→ 仅借 S01 数学语言，不继承任何体系物理结论
```

**关键边的诚实标注**：

- **S01→S02/S07/S10/S12**：纯数学借用。S01 的三重奏是定理，S02/S07/S10/S12 把它"特化"到自己的本体里。数学成立 ≠ 本体成立。
- **S02→S12**：S12-A4 **明示借用** S02 的统一力方程，且文档自承"不因使用而获独立证据"。这条边是物理借用，但 S02 自己的动力学链本就未接，S12 借过来的是一个**未接动力学的方程**。
- **S03→S04/S05/S07/S08/S09**：S03 是 GAQ 母本。但 S04/S05/S06 在 v3 时已提出自己的公设，不是 S03 的纯推论。
- **S13 独立**：S13 的三公理与上述任何体系无引用关系。它借用 S01 的数学语言（旋量几何、Frenet 风格的表述），但物理本体（对偶 0/1、拓扑荷、双向分形）是新立的。

## 25.3 依赖图无环验证方法论

S13 把这套方法论写成了可复现流程，本节把它一般化。

### 25.3.1 三步法

1. **邻接矩阵构造**：把每个公设/方程编为节点 $V$，把"节点 A 是节点 B 的直接推导前提"记为有向边 $A\to B$，构造邻接矩阵 $M$。
2. **传递闭包计算**：$M^\ast = I + M + M^2 + \cdots + M^{|V|-1}$（布尔幂）。$M^\ast_{ij}=1$ 表示 $i$ 可达 $j$。
3. **两个判定**：
   - **无环判定**：统计双向可达对数 $\#\{(i,j): M^\ast_{ij}=1 \wedge M^\ast_{ji}=1\}$。若 = 0，则图无环（DAG）。
   - **完备性判定**：从所有公设节点做并集闭包，检查是否覆盖全部方程节点。若全覆盖，则公设集完备。

### 25.3.2 S13 实测

- 节点数：3 公理 + 6 方程 = 9（外加 4 条预言作为叶子）。
- 双向可达对数：**0/15**。
- 公理全可达：**真**。
- 结论：依赖图是严格无环树，无循环论证。

### 25.3.3 对其他体系的适用性

这套方法**应该**被应用到 S01/S02/S03/GAQ 版本线上，但目前只有 S13 做了实测。其余体系的"无环"判断来自文字追溯，未做矩阵化实测——这本身是一条待建链（见 25.4）。

## 25.5 循环论证检测记录

依赖图无环不等于"每个公式都非循环"。下面三条是跨体系审查中抓到的**恒等回路/不自洽**记录。它们不是图论意义上的环（A→B→A），而是"两个方程互为定义"或"联立矛盾"。

### 25.5.1 S12 α 闭式矛盾（非循环，但不自洽）

S12 同时写：
$$\alpha=\tan\theta,\qquad \alpha^{-1}=\frac{2\pi}{\theta}=137.035999084$$

联立得 $\tan\theta\approx 2\pi\theta$。小角近似下 $\tan\theta\approx\theta$，退化为 $1\approx 2\pi$，**两式不能同真**。这不是循环论证（不是用 α 推 θ 再用 θ 推 α），而是两条独立公式内部不自洽。S12 把 CODATA 测量值反代为 $\theta=2\pi/137$ 再"宣布"α 闭式，是测量锚回代。

### 25.5.2 S03 T1 恒等非循环

T1：$M_p c L_p=\hbar$。表面是定理，实际是 A5（$M=M_p N$）+ A4（$c=L_p/T_p$）+ A1（$\hbar$ 元胞作用）的**定义式直接代入**——1 步。这不是循环论证（图上是单边 A1+A4+A5→T1），但它也**不是独立推导**：$M_p$、$L_p$、$\hbar$ 三个量本身就是 Planck 单位制的定义三元组，它们的乘积恒等于 $\hbar$ 是定义级事实。

### 25.5.3 S08 v5 恒等回路（自承）

v5 §9.1 自承：
$$c=\omega R,\qquad \omega:=\frac{c}{R}\ \Rightarrow\ c=\frac{c}{R}\cdot R=c$$
$$\hbar=mcR,\qquad m:=\frac{\hbar}{cR}\ \Rightarrow\ \hbar=\frac{\hbar}{cR}\cdot cR=\hbar$$

这两个等式在图论上构成自环（$c\to\omega\to c$），但 v5 §9 原文**已经承认**这是同义反复，并把 v5 的价值定位为"概念澄清"（区分单位制桥梁与物理常数）。本书照录这一自承，不另作指控。

## 诚实边界与待研究问题

- 依赖图无环是**必要非充分**条件。无环只说明逻辑不自相矛盾，不说明公设本身与物理世界相符。
