## 1. 公理基底（O 公理集，本体系唯一理论根）

以下 6 条公理构成 1000 个单元可被组织为**一个**统一场论体系的共同根。每个单元须与至少一条 O 公理显式关联（在"逻辑链"中标注 O-1…O-6）。

- **O-1 时空几何本源公设**：物理内容全部编码于时空几何结构（度规、联络、挠率、曲率、拓扑），不存在几何之外的第一性实体；质量、荷、自旋均为几何构型的投影。
- **O-2 现象等价公设**：一切可观测现象是同一"几何-信息场"在不同标度、不同投影方向上的相；不同力、不同物质相是同一场的不同相角/不同纤维。
- **O-3 标度自相似公设（分形递归）**：物理定律在标度变换下呈自相似递归结构，微观-介观-宇观由同一递归内核生成；分形维数与递归系数是编码"物质-几何耦合阶"的参数。
- **O-4 0-1 阴阳对偶公设**：每个物理自由度以对偶对存在（连续↔离散、定域↔非定域、序↔混沌、几何↔拓扑、正↔负），对偶间以守恒量耦合；宇称/手征/正反物质不对称是 0-1 对偶在特定相上的投影。
- **O-5 奥卡姆边界公设**：理论价值由"预测精度/描述长度"比值度量；未达实验约束的假设必须显式标记未证实；禁止用无穷参数拟合换取表面一致。
- **O-6 现象锚定公设**：每个理论单元必须至少锚定一个现实世界可观测现象（湍流、超导、宇宙膨胀、中微子振荡、引力透镜、生物节律、气象系统等），并说明融合方式；**禁止纯数学空转**。

## 3. 单元模板（六要素，硬规格）

每个单元严格按以下结构，且**所有数理符号强制 LaTeX 行内公式包裹（$...$）**：

```markdown
### F### · 单元标题（8–20 字，凝练机制）

**公式**：$<LaTeX 公式，必须出现且自洽>$

**量纲核验**：$[<量>]=\mathrm{L}^{a}\mathrm{T}^{b}\mathrm{M}^{c}$（或自然单位 $c=\hbar=k_{B}=1$ 说明），逐项给出，结论"自洽/闭合"。

**假设/猜想**：一条可陈述的猜想（对称性猜想 / 机制猜想 / 数值关系猜想 / 结构猜想，四选一标注）。

**逻辑链**：第一性原理出发 ≤ 4 步，每步箭头，标注所用思维范式（O-1…O-6 公理 + 范式词典词条）；以"闭环/待验证"结尾。

**现象锚定**：≥1 个现实世界现象 + 一句话融合说明（本单元如何解释/编码该现象）。

**诚实标界**：探索性理论构建·未证实（可附"可证伪预言窗口：…"）
```

### 量纲核验三规则
1. SI 与自然单位二选一，全卷统一；混用须显式说明换算。
2. 逐项列 $[\cdot]$，最后一句必须给出整体量纲并判定"自洽"或"闭合（无量纲化）"。
3. 出现新符号（如自创场、自创常数）必须当场定义量纲，禁止未定义符号进入公式。

## 5. 模板示范（F001–F003 种子单元，模式基准）

### F001 · 曲率-拓扑对偶荷

**公式**：$Q_{CT} = \dfrac{\chi(\mathcal{M})}{4\pi\,\ell_{P}^{2}}\displaystyle\int_{\mathcal{M}}\sqrt{-g}\,R\,d^{4}x$

**量纲核验**：$[\chi]=1$（欧拉示性数，拓扑不变量）；$[\sqrt{-g}\,d^{4}x]=L^{4}$；$[R]=L^{-2}$（Ricci 标量曲率）；$[\ell_{P}^{-2}]=L^{-2}$；总体 $[Q_{CT}]=L^{-2}\cdot L^{4}\cdot L^{-2}=1$ → **无量纲闭合**。

**假设/猜想**：结构猜想——惯性质量的正定性与同号性是时空拓扑不变量（欧拉示性数）在局域的投影：$m_{i}\propto Q_{CT}^{(i)}$ 且恒正。

**逻辑链**：O-1（质量=几何投影）→ 可观测量须无量纲（归一化，O-5）→ 用普朗克面积 $\ell_{P}^{2}$ 归一化曲率积分 → 拓扑不变量 $\chi$ 作量子化因子（0-1 对偶：连续曲率↔离散拓扑）→ 闭环：惯性正定性涌现。**待验证**。

**现象锚定**：马赫原理与惯性——为何一切物体质量同号（无负惯性质量观测）；星系旋转曲线平坦化的拓扑项贡献候选机制。

**诚实标界**：探索性理论构建·未证实。可证伪预言窗口：若 $\chi$ 的拓扑修正参与局域动力学，应在强曲率区（中子星/黑洞吸积盘）出现可探测的等效加速度修正。

### F002 · 标度自相似递归核

**公式**：$g_{\mu\nu}(x;\lambda) = \sum_{n=0}^{\infty}\lambda^{-n\,d_{f}}\; g_{\mu\nu}^{(n)}\!\left(\dfrac{x}{\lambda^{n}}\right),\qquad d_{f} = \lim_{n\to\infty}\dfrac{\ln N_{n}}{\ln \lambda^{n}}$

**量纲核验**：$g_{\mu\nu}^{(n)}$ 与 $g_{\mu\nu}$ 同为度规张量 $[g]=1$；系数 $\lambda^{-n d_{f}}$ 中 $\lambda$ 为无量纲标度因子、$d_{f}$ 为无量纲分形维 → 每一项无量纲 → **自洽**。

**假设/猜想**：对称性猜想——时空度规是标度半群 $x\mapsto x/\lambda$ 下的自相似递归不动点，分形维 $d_{f}$ 编码物质-几何耦合的"阶"，不同标度现象由同一递归核生成。

**逻辑链**：O-3（标度自相似公设）→ 度规按标度层展开（全维分析：微观层 $g^{(0)}$、介观层 $g^{(1)}$…）→ 收敛条件 $\lambda^{d_{f}}>1$ 约束耦合阶 → 奥卡姆剃刀：一个递归核替代无穷多独立常数 → 闭环。**待验证**。

**现象锚定**：湍流标度律（Kolmogorov 谱 $E(k)\propto k^{-5/3}$ 的自相似级联特征）；宇宙大尺度结构自相似性（星系分布观测分形维 $\sim2$）。

**诚实标界**：探索性理论构建·未证实。可证伪预言窗口：$d_{f}$ 若为全局常数，则湍流耗散尺度与星系聚类维数应满足同一递归关系——可直接对测数据检验。

### F003 · 几何熵梯度流

**公式**：$\dfrac{\partial g_{\mu\nu}}{\partial \tau} = -\,\ell_{P}^{2}\,G_{\mu\nu} + \gamma\,\ell_{P}^{2}\,\nabla_{\mu}\nabla_{\nu}S_{g},\qquad \tau = \dfrac{t}{\ell_{P}}$

**量纲核验**：$\tau$ 无量纲（时间以普朗克时间归一）；$[G_{\mu\nu}]=L^{-2}$，乘 $[\ell_{P}^{2}]=L^{2}$ → 无量纲；熵 $[S_{g}]=1$（$k_{B}=1$），$[\nabla_{\mu}\nabla_{\nu}]=L^{-2}$，乘 $\ell_{P}^{2}$ → 无量纲；$\gamma$ 无量纲耦合 → **全项无量纲闭合**。

**假设/猜想**：机制猜想——引力是几何熵 $S_{g}$ 的梯度流：度规沿熵增方向演化，爱因斯坦方程是该流的稳态解（耗散-几何对偶）。

**逻辑链**：O-4（熵-信息视角）→ 热力学第二定律要求熵增 → 度规动力学写成梯度流（闭环：稳态即 $G_{\mu\nu}\propto\nabla_{\mu}\nabla_{\nu}S_{g}$）→ 稳态解回到爱因斯坦方程（涌现-还原对偶）→ 待验证。

**现象锚定**：引力时间膨胀（GPS 星载钟相对论修正）；黑洞霍金辐射（事件视界作为几何熵流的边界条件，熵流即蒸发通量）。

**诚实标界**：探索性理论构建·未证实。可证伪预言窗口：$\gamma$ 驱动的非稳态涨落应在黑洞视界附近产生与霍金谱偏差的次领头修正。
