## 解压后最快使用

1. 浏览器直接打开 `ROOT_V65/web/index.html`。内置三维螺旋投影、数学反演、诱导引力参数扫描和第五力等效原理比对；不需要联网。
2. 通过页面链接打开 `ROOT_V65/legacy_v64/web/index.html`，查看既有 WebGL2 地球/螺旋三维视图及 Canvas 降级路线；点击 V64 的精算仪表盘观察其他五组曲线。
3. 阅读 `research/00_研究总论与成果边界.md`、`research/08_失败原因与修复工单.md`。全部 56 项缺口的状态已标注；不要把 `OPEN` 当作 `PASS`。
4. 从项目根目录运行：

   ```bash
   sh RUN_ALL.sh                   # Linux/macOS，Python 3.10+ 标准库
   # 或 Windows 双击 RUN_ALL.bat
   # 手动单独运行：
   python -m unittest discover -s tests -v
   (cd legacy_v64 && python -m unittest discover -s tests -v)
   python experiments/generate.py
   ```

5. 可选浏览器端自动化（需要本机 Playwright + Chromium）：`python experiments/browser_smoke.py`。

## 主要数学成果与不成功原因

- **圆柱螺旋反演**：`R=κ/(κ²+τ²)`、`ω=v√(κ²+τ²)`、`u=vτ/√(κ²+τ²)`，只在 `κ>0` 的标准圆柱螺旋模型内成立。
- **非普适正交反例**：同一位置、同一速度、相反电荷的两个粒子有相反电场力；纯空间角度不能区分这两个结果。
- **量子微观场与引力源**：由 Bessel-KG 能量分布在给定 GR/牛顿方程及 G 后得到条件引力场，不是推导 G。
- **热核模型**：`1/G_eff=1/G_bare+N(1−6ξ)ℏ F(μ)/(12πc³ℓ²)`，其中 `F=e^(−μ²)−μ² E1(μ²)`。截止、场谱、非最小耦合与裸项均需独立给定。
- **不可辨识**：`N→s²N, ℓ→sℓ` 保持质量可忽略的单圈项完全不变。单个 G 测量不能识别全部微观参数。
- **统一作用量**：显式变分能够得到已给定的 GR、标准模型及附加标量方程，不等于从螺旋自行推出强弱规范群。

## 重要数据伦理和可运行范围

`data/` 全部 CSV 是方程生成值，没有实测 IGRF/EGM2008 系数。NIST CODATA 2022 的 G 是观测输入，普朗克长度亦由该 G 计算。MICROSCOPE 数值是文献输入，其余新力耦合是人工模拟。全套测试仅验证程序与模型的一致性，不是理论的独立实验验证。

外部 WebGL2 GPU 设备没有在本环境获得完整的原生硬件验证；支持 Canvas2D 降级。图片与代码环境之间的能力差异需在部署场所重新检查。

本项目不是一份已被同行评议的 GUT 发现公告。**正式科研裁定：ROOT 有明确的数学工具和可证伪研究方向，四力共同起源、G 独立预测、量子一致性仍为 OPEN。**

**实际回归执行**：V65 65 项 + V64 63 项 = **128 项通过**。并执行了可选 Chromium `set_content` 页面参数联动冒烟测试（不是完整网站导航或 GPU 测试）。
