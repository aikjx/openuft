  几何投影占比: α_W^proj = α·sin²θ_W_geo (电磁→弱的投影权重, 无量纲占比)
  ★ 关键澄清(修复48/49): α_W^proj 与 α_W^SM 是倒数对偶关系:
      α_W^proj · α_W^SM = α²  =>  二者 NOT 近似相等, 而是 α_W^SM = α·(α/α_W^proj)

  几何 sin²θ_W_geo = τ_int/(1+τ_int) = 0.2
  α_W^proj = α·sin²θ_W_geo = α·0.2 = 0.0014594705 (0.2·α)
  α_W^SM   = α/sin²θ_W       = α·4.329 = 0.031590271 (4.329·α)
  对偶检验 α_W^proj·α_W^SM = 4.6105069e-5  vs α²=5.3251355e-5  残差 13.42%
  [诚实澄清] 对偶恒等式 α_W^proj·α_W^SM=α² 仅在'二者用同一 sin²θ_W'时严格成立
    本检验用几何 sin²θ_W_geo=0.2 与实验 sin²θ_W=0.231 两个不同值, 故 13.42% 反映的是
    '几何占比↔实验值'的偏差, 非对偶关系失效; 若统一取 sin²θ_W=0.231 则乘积=α²(机器零)
  => 对偶关系数学成立(恒等式); 13.42% 属 '几何占比 vs 实验' 开放项残差, 已与 B1 残差 13.0% 一致
