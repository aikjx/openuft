二、定理 N · Schur 标量性：相位指数与 k 向量

三、定理 P · 自我纠正：3t 与 N 不是同一个量

同一组 t 上并列两个量：r305 的最小 K = 3t（λ=0 切片）与 该解实际的代数 N = λ + t = t。两者在对角线上恰好相等 ⇒ 数字一个不差，标签却错了。
这是削弱，不是加强，必须明写。修正后的门槛是 K ≥ 3（k=(3,3,3,3,3)、t=0、q=0、六条反常全零）， 而 r305 说的是 K ≥ 9。no-go 比 r305 自述的脆弱 3 倍。

四、定理 Q · 复制不可约化：N ≤ c

内部空间有 c 个连通分量、各带独立扭转 ⇒ 可达 [0,c]⁵ ⇒ K = c ⇒ 由定理 P，Ngen ≤ c。三代 ⟺ c ≥ 3（柱高即该 c 下的最大代数）。
