## 一、问题

R1 的引力扇区给出唯一**定量超越 GR** 的效应：非线性自屏蔽

`∇²u = −(8πG/c²)·ρ·exp(−u)`，外部 `u = 2GM_eff/(c²r)`，`M_eff ≤ M`

**可检验命题**：TUFT 的"有效引力质量"`M_eff` 低于物质质量 `M` ⇒ 引力波波形与 GR 有偏差 `δh/h ~ (1−M_eff/M)`。
问：该偏差是否已被 LIGO/Virgo 排除？

---

## 二、建模（无量纲化）

取 `x = r/R`、`ξ = GM/(c²R)`（致密系数）、`u = ξ·w`：

- 球内：`w'' + (2/x)w' = −6·exp(−ξw)`
- 球外：`w = C/x`，`C = 2·M_eff/M`
- 边界：`w'(0) = 0`；匹配 `w(1) + w'(1) = 0`

**弱场解析自检**：`ξ→0` 时 `w = 3 − x²` ⇒ `C = 2` ⇒ `M_eff/M = 1` ✓

## 五、对标观测与判决

- **LIGO/Virgo 对 GR 的检验精度** ~ 10%（波形相位，双黑洞并合）。
- 本模型偏离达 10% 的临界致密系数：**ξ_max ≈ 0.0490**。
- **黑洞 ξ=0.5 的偏离 = 46.82% ≫ 10%** ⇒ 若 R1 自屏蔽被视为真实物理，**与现有引力波观测矛盾（被排除）**。

**判决（FAIL）**：TUFT 的自屏蔽效应在致密天体下不可忽略，**与 LIGO 观测不一致**。

## 六、修复路径（三选一）

1. **检验推导**：R1 场方程是否多出一个 `exp(−u)` 因子？若去掉，`M_eff = M`，TUFT 退化到 GR（自屏蔽消失）；
2. **UV 完成**：引入高阶曲率项，使 `exp(−u)` 在致密区被抑制；
3. **接受并寻找可分辨观测**：EMRI 长期积累/多历元（但 46.82% 已远超当前约束）。
