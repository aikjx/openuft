S13 的核心叙事是「三公理 → 六方程闭环 → **自涌现**出电弱规范结构、希格斯、三代费米子、色 SU(3)」。本轮攻破要判别的正是这个「自涌现」：

## 一、攻破③：费米子代「三代 = Z₄ 三实表示」是数字巧合

**S13 声称**：代结构 ← 对偶周期 4 的表示论；三代 = Z₄ 的三个实不可约表示（1,1,2 维）；第四代被表示论禁戒。

**反例独立复算（证据）**：Zₙ 循环群的实不可约表示数随 n 变化：

| 群 | 实表示数 | 若「代=实表示数」 |
|---|---|---|
| Z₂ | 2 | 应有 2 代 |
| Z₃ | 2 | 应有 2 代 |
| **Z₄** | **3** | S13 取此 → 声称 3 代 |
| Z₅ | 3 | 应有 3 代 |
| Z₆ | 4 | 应有 4 代 |
| Z₈ | 5 | 应有 5 代 |

**攻破逻辑**：
- Z₄ 有 3 实表示是**纯群论事实**——任何具有 Z₄ 对称性的系统（从晶体到量子比特）都自动有 3 实表示，与"费米子"毫无关系；
- S13 从"旋量对偶周期 4（Θ²=−I）"等同到"Z₄ 群表示论"，再宣称"3 实表示 = 三代费米子"——**这是类比跳跃**。旋量的 4π 回归与费米子代数之间没有任何推导环节；
- 反例铁证：**同一种方法，若对偶周期是 2 或 6，就"推导"出 2 代或 4 代**。证明"代数"完全由"你选哪个群"决定，不是从 0/1 对偶必然推出。

**体系自证**：`fermion_family_verify.py` 第 88/100/111 行已诚实标注「代内量子数分配（为何 Q 带色、L 不带）仍未推导——OPEN」「本定理给出代数的上限与来源，不给出代内量子数」「CKM/PMNS 混合仍 OPEN」。反向坐实：**数字对齐，非推导**。

**判定**：攻破成立。「三代费米子」= 群论事实（真）+ 与实验代数的数字耦合（借用/类比）。

## 二、攻破④：色 SU(3)「CP² 等距涌现」是选择性建模

**S13 声称**：对偶旋量目标空间升级 CP¹(S²) → CP²，等距群 SU(3)/Z₃ 涌现为色；稳定子 U(2) ⊃ SU(2)×U(1) 涌现为电弱。

**攻破逻辑（证据）**：脚本「数学确定部分」验证的**全部是 CP² 与 SU(3) 的固有性质，任何 CP² 流形皆成立，不依赖 S13 任何公设**：
- CP² 的等距群 = SU(3)/Z₃（微分几何已知定理）；
- 固定点稳定子 = U(2) ⊃ SU(2)×U(1)（固有几何）；
- 3|SU(2)×U(1) = 2 ⊕ 1（表示论分支规则恒等式）；
- 单态条件 3^k⊗3̄^l ⟺ k≡l (mod 3)（SU(3) 表示论）。

S13 只需**声明「对偶旋量目标空间 = CP²」**就自动获得全部这些——因为它们是 CP² 与生俱来的。但：

> **「为什么对偶旋量目标空间必须是 CP²，而非 CP¹、S⁵、Gr(2,4)、T²……？」没有任何推导。**

这是**为匹配色 SU(3) 而选空间**（CP² 恰好等距群是 SU(3)/Z₃），属选择性建模——预设了标准模型的 SU(3)，再反推一个能实现它的目标空间。第一性原理要求空间结构从公设推出，而非按目标倒推。

**体系自证**：脚本验证 E 已诚实标注「π₃(CP²)=0 → CP² 无霍普夫荷；色拓扑候选与对偶旋量霍普夫荷的共存机制 OPEN——不冒充已解」；「禁闭是动力学（千禧年问题），代数不解决——OPEN」。

**判定**：攻破成立。「色 SU(3) 从几何涌现」= 几何固有事实（真）+ 选择性选空间（非推导）。

## 三、攻破⑤：Yang–Mills 动力学作用量「未定型」= 教科书重述

**S13 声称**：涌现规范场 a_μ（M2）具有 Yang–Mills 动力学。

**攻破逻辑（证据）**：`yang_mills_verify.py` 验证的实为**标准教科书对象**：
- 验证 C：plaquette 作用量规范不变——这是**任何 U(2) 联络的格点 Yang–Mills 固有性质**（教科书），不是 S13 推导的动力学；
- 验证 D：希格斯质量谱 {0, m_W², m_W², m_Z²}——这是**标准希格斯机制**的教科书结果，且参数 $g,g',v$ 是**手动输入**的，非从六方程推出；
- 验证 A：A_μ = E†∂_μE 取值 u(2)——**定义性恒等式**（E∈U(2) 则联络自动在 u(2)）。

**核心攻破**：脚本验证的是「若作用量是标准 plaquette/标准希格斯，则规范不变、质量谱成立」——但**没有从 S13 六方程推导出"作用量为什么是这种形式"**。诚实边界「Yang–Mills 动力学作用量未定型」完全正确，但更精确的定性是：**作用量借用了标准形式，S13 未提供它的第一性来源**。所谓"动力学定型（V1.3）"实为对标准 Yang–Mills + 标准希格斯的机器复述。

**判定**：攻破成立。Yang–Mills 动力学 = 教科书重述（真）+ 第一性来源缺失。

## 四、攻破总纲：涌现叙事模式识别（本轮核心成果）

将第一轮（常数统一）与本轮（代/色/作用量）合并，浮现**贯穿四大 OPEN 项的统一模式**：

$$\underbrace{\text{数学确定部分（全 PASS）}}_{\text{教科书重述}}\ +\ \underbrace{\text{「涌现」宣称}}_{\text{选择性建模}}$$

| OPEN 项 | 数学确定部分（教科书/固有事实） | 「涌现」实质 |
|---|---|---|
| 常数统一 | MSSM 三线汇聚（教科书） | 借用 MSSM（第一轮） |
| 费米子代 | Z₄ 三实表示（群论事实） | 数字巧合耦合"三代" |
| 色 SU(3) | CP² 等距/分支规则（几何事实） | 选 CP² 实现 SU(3) |
| Yang–Mills | plaquette/希格斯（教科书） | 借标准作用量 |

**一句话（0/1 对偶）**：S13 的「1」是它诚实证明了的大量**数学恒等式**（流守恒、曲率闭式、质量谱、李代数一致性——全机器零）；但它尚未证明的，是「这些恒等式**如何从三公理生成标准模型**」——这一步目前是「0」。它做的是**重述 + 事后几何化**，不是**从 0/1 基元生成**。

**这不是指控体系造假**——S13 的诚实边界（OPEN/conjecture/falsified 标注、不冒充已解）在所有候选体系里做得最好。攻破的意义在于把「涌现已完成、只差禁闭和常数」的乐观叙事，校准为「标准模型结构已被**选择性重述**，第一性生成尚未开始」——这是统一场论的真实状态。
