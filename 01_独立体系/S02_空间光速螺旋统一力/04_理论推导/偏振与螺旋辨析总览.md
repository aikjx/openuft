## 0. 总结论

1. **没有任何分量超光速**：若光子沿速率 c 的螺旋运动，则轴向 `u` 与切向 `RΩ` 满足 `c² = u² + (RΩ)²`，二者均 ≤ c。
2. **偏振片是场矢量投影**：各向异性响应 + 马吕斯 `I = I0 cos²θ`；圆偏振过片塌缩为线偏振（螺旋→直线）。
3. **两垂直偏振片全挡 = 两次正交投影归零**：`Py·Px = 0`。
4. **「直线光速 c」与「空间螺旋」互斥**（若螺旋字面化为轨迹）：在 `{路径速度=c, 前向速度=c, 螺旋半径>0}` 三条件中至多取二。
5. **唯一自洽解**：螺旋在**场矢量维度**（圆偏振 E 矢量旋转），轨迹在**直线维度**（沿 z 以 c 传播）。二者层级不同，不冲突。
6. **实验判定**：光速 c 精确定义且全球一致；马吕斯、交叉消光、三偏振片悖论、圆偏振均被严格验证；**字面空间螺旋因预言超光速/横结构而缺乏实验支持**。

## 1. 全维理论框架（四个证明）

### 1.1 超光速辨析：螺旋速率 c 下分量不超光速

螺旋参数化 `x=R cosΩt, y=R sinΩt, z=ut`，速率 `|v|² = (RΩ)² + u²`。
令 `|v| = c` ⇒ `c² = u² + (RΩ)²` ⇒ `u ≤ c, RΩ ≤ c`。**无超光速。**
对接三重奏：Frenet 下 `κ²+τ² = Ω²/c² = (ω/v)²`（v=c, ω=Ω），几何自洽但无新物理。

### 1.2 偏振片机制：各向异性 + 投影 → 马吕斯

介质择优方向使 `ε,σ` 各向异性 `≈ diag(∥,⊥)`；沿吸收轴的 E 被阻尼，垂直分量透过。
对任一场做投影 `E_out = P·E_in, I_out = |⟨â|E_in⟩|²` ⇒ `I = I0 cos²θ`。
圆偏振 `E(t)=E0[cosωt x̂ + sinωt ŷ]` 投影到轴 `â` ⇒ `E0 cos(ωt−φ)`：线偏振（螺旋→直线），强度 `I0/2`。

### 1.3 双垂直遮挡：两次正交投影归零

第一片轴 `â1` 投影：`E1=(E·â1)â1`；第二片轴 `â2⊥â1` 再投影：`E2=(E1·â2)â2=0`。
Jones：`Py·Px = 0`（零矩阵），任意输入经两者后强度 0。
三偏振片悖论：未偏振 `I0` → `Px`(I0/2) → `P45`(I0/4) → `Py`(I0/8)，插 45° 反而透光。

### 1.4 直线光速 + 螺旋：三约束互斥（核心）

设 `R` 螺旋半径、`v_fwd` 前向速度、`v_⊥=ωR` 横向速度、`v_path=√(v_fwd²+v_⊥²)`。
三自然约束：

```
(A) v_path = c       (B) v_fwd = c       (C) R > 0 ⇔ v_⊥ > 0
```

(A)+(B) ⇒ `c² + v_⊥² = c²` ⇒ `v_⊥=0` ⇒ `R=0`，与 (C) 矛盾。**至多取二：**

| 选取 | 结果 | 评价 |
|---|---|---|
| A+B | R=0 | 直线，标准光，**唯一自洽** |
| A+C | v_fwd=√(c²−v_⊥²) < c | 螺旋存在但前向<c，与光速测量冲突 |
| B+C | v_path=√(c²+v_⊥²) > c | 前向=c但路径超光速，违反相对论 |

数值（螺距=λ、R~λ）：`v_⊥=2πc`，`v_path≈6.36c > c` ← 与超光速辨析一致，**字面空间螺旋被否**。

## 2. 正规实验数据验证

> 以下为电动力学/光学长期确立的实验事实（教科书与计量标准），用于验证上述理论。非本框架新测量；本框架未产生、也未声称产生超出标准理论的新预言。

### 2.1 光速 c：定义值与全球一致

- **定义（1983, 17th CGPM）**：`c = 299 792 458 m/s`（精确值，作为米定义基础）。
- 历代测量（Fizeau 1849、Michelson-Morley 1887、现代腔法/天文测距）两路与一路结果均与 c 一致；**从未观测到真空信号超 c**。
- **判定含义**：若光子字面空间螺旋且 `v_path≈6.36c`（R~λ 情形），将直接违反此全球一致结果 → 字面空间螺旋不成立。

### 2.2 马吕斯定律：实验验证

理论 `I/I0 = cos²θ`。典型偏振实验（本科光学标准结果，误差通常 < 1–2%）：

| θ (°) | cos²θ（理论） | I/I0（典型实测，示意） |
|---|---|---|
| 0 | 1.000 | 1.000 |
| 15 | 0.933 | 0.931 |
| 30 | 0.750 | 0.748 |
| 45 | 0.500 | 0.497 |
| 60 | 0.250 | 0.252 |
| 75 | 0.067 | 0.069 |
| 90 | 0.000 | ≈0（消光） |

残差在实验误差内，**马吕斯律被严格验证**。这正是 1.2/1.3 投影证明的实验基础。

### 2.3 交叉偏振片消光

- 理论：两片轴夹角 90° ⇒ `I/I0 = cos²90° = 0`。
- 实测：高质量偏振片（如 Glan–Taylor）消光比 `ρ = I_trans/I_inc ~ 10⁻⁵–10⁻⁶`，即近乎全挡；残余透射来自偏振片不完美（有限消光比），**非理论偏差**。
- 与 1.3 的 `Py·Px=0` 一致。

### 2.4 三偏振片悖论

- 装置：未偏振光 → `P_x` → `P_{45°}` → `P_y`（后两片交叉）。
- 理论：`I = I0·(1/2)·cos²45°·cos²45° = I0/8`。
- 实验：插入 45° 第三片后确有显著透射（约 `I0/8` 量级），移除则归零。经典演示，**验证投影的序贯性**（第二个片重新定向偏振，第三个才有分量可投）。

### 2.5 圆偏振（场矢量螺旋）的确认

- 装置：线偏振器 + 1/4 波片 → 圆偏振；其后旋转分析仪，强度恒定（圆偏振对任意线偏振轴投影均为 `I0/2`）。
- 这直接确认：**E 矢量在横截面内旋转（场矢量螺旋）是真实存在的场结构**，而非空间轨迹。
- 与 1.2「圆偏振过片塌缩为线偏振（螺旋→直线）」互证。

### 2.6 空间螺旋字面化的实验否决

若把 S02 的「空间螺旋」当作光子**空间轨迹**字面现实，则：

1. 由 1.4，R~λ 时 `v_path≈6.36c > c`，与 2.1 的全球光速测量矛盾；
2. 字面螺旋应使光子带可观测横动量/横结构（一圈一波长量级的横向位移），但直线射线模型 + 波前法线在激光测距、GPS、干涉仪中精度达 `10⁻⁹`–`10⁻¹²` 量级，无此类横结构迹象；
3. 偏振实验（2.2–2.5）全部可由**场矢量螺旋**解释，无需、也不能区分「轨迹螺旋」假说。

⇒ **字面空间螺旋缺乏实验支持；它只能作为场矢量螺旋的几何重述。**

## 3. 红线与边界（S02-A4）

- 偏振、马吕斯、光速 c 均为电动力学/计量标准结论，**非框架独有发现**。
- 「空间光速螺旋」是 S02 的几何公设（三重奏 `κ²+τ²=(ω/v)²` 的几何基石），**未被独立实验判定为光子空间轨迹**。
- 四份辨析均不证明、也不否定该公设；它们仅说明：在标准物理内，螺旋属于**场矢量维度**，轨迹属于**直线维度**。
- 不得据偏振/光速结果声称「证明了空间螺旋」或「出光速」——越界 S02-A4。

## 5. 最终裁决：光到底是否光速螺旋运动

直接回答，分三层：

1. **作为字面「空间轨迹螺旋」——否。** 标准物理与全部实验表明：光子（或光波前）沿直线 / 波前以 `c` 传播，不做绕轴空间螺旋。理由：
   - 若轨迹螺旋且 `R~λ`，路径速度 `≈6.36c`（§1.4、§2.6），与精确定义的光速 `c = 299 792 458 m/s` 及全球一致测量**直接矛盾**；
   - 直线射线模型在激光测距、GPS、干涉仪中精度达 `10⁻⁹–10⁻¹²`，**无任何横向螺旋结构迹象**。
   ⇒ 字面空间螺旋被实验否决。

2. **作为「场矢量螺旋」（圆偏振）——是，且已被实验确认。** 圆偏振的 E 矢量在横截面旋转，叠加传播即在场空间描出螺旋。QWP + LP + 旋转分析仪强度恒定（§2.5）即证。但这**是标准电动力学结论**，并非框架独有发现。

3. **作为框架 S02 的几何公设——未判定，且字面解读站不住脚。** 三重奏 `κ²+τ²=(ω/v)²` 是匀速螺旋在速率 `c` 下的 Frenet 恒等式（几何自洽），但它是框架对「空间轨迹」的假设，未被独立实验证明；当把它字面化为真实轨迹时，即陷入超光速 / 前向 `<c` 的矛盾（§1.4）。

**一句话结论**：科学上，光**不是**做空间螺旋运动；说它「螺旋」，仅指**电场矢量的螺旋（偏振）**，那是已验证的标准现象。框架的「空间光速螺旋」目前应定位为**几何类比 / 公设**，不能作为已被证实的物理现实——否则越界 S02-A4 并抵触实验。
