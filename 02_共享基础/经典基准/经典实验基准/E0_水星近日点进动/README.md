# E0 · 水星近日点进动

## 观测结果

水星轨道近日点每世纪进动 **574.10″**，其中：
- 531.63″：其他行星的牛顿引力摄动
- **42.98″**：广义相对论修正（无法用牛顿力学解释）

GR 预言值：$42.98''$/世纪，与观测精确一致。

## 物理机制

GR 中，弱场近似下的有效势能含 $1/r^3$ 修正项：

$$V_{\rm eff}(r) = -\frac{GMm}{r} + \frac{L^2}{2mr^2} - \frac{GML^2}{mc^2 r^3}$$

第三项导致近日点进动。
