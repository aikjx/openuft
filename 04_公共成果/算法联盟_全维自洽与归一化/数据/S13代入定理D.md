## 1. 形式化设定

### 1.1 无量纲参数空间 Theta

S13 经奥卡姆归并后（第25章 §25.2 对接程序）的无量纲参数为

```
Theta = { g~ , g~' , kappa~ }        (n = 3 个无量纲旋钮)
```

其中 `g~` 为对偶规范耦合、`g~'` 为 U(1) 耦合、`kappa~` 为真空自耦合。
带量纲尺度 `v`（= ell^{-1}）与 `ell` 不计入 Theta —— 它们是标度，不是
无量纲旋钮（定理 D 只作用于无量纲参数空间）。

### 1.2 第一性原理约束 E(theta) = 0

S13 对**无量纲扇形**真正施加的第一性原理约束：

| 编号 | 约束 | 出处 | 类型 |
|---|---|---|---|
| E1 | `g~'/g~ = 1/sqrt(3)`（CP^2 稳定子嵌入，同一规范耦合 g3） | ch25 定理25.4 | **连续、齐次** |
| E2 | 拓扑荷 `Q_H in Z`、`min|Q|=1` | 公设 A2 | 整数型（离散） |
| E3 | 真空模式谱 `{0,0,0,8 kappa~ v^2}`、未破缺 U(1) 零空间维数 = 1 | ch18 / 验证结果 | 计数型（离散） |
| E4 | 电荷步长 `1/3` = 色表示维数 3 的倒数 | ch25 定理25.3 | 有理数型（离散） |

**关键观察**：E2/E3/E4 是**离散/整数型**约束（拓扑、计数、维数），它们
不作用于连续旋钮空间 Theta，故对 J_E 贡献为 0。只有 E1 是作用于 Theta
的**连续**约束。这正是 S13「结构性预测」的代数根源。

### 1.3 约束雅可比 J_E

```
E1(theta) = g~'^2 - g~^2 / 3 = 0
J_E      = [ dE1/dg~ , dE1/dg~' , dE1/dkappa~ ]
         = [ -2 g~/3 ,  2 g~'  ,  0 ]
```

（E2/E3/E4 为离散约束，不产生 J_E 行。）

## 2. 秩与零度实算（sympy）

在满足约束的点上取 `g~ = 1`，则 `g~' = 1/sqrt(3)`（E1 的解）。

```
J_E(1, 1/sqrt(3), * ) = [ -2/3 ,  2/sqrt(3) ,  0 ]
rank(J_E)      = 1
n              = 3
nullity_dyn    = n - rank(J_E) = 2
```

**零空间基**（ker J_E 的两条基向量）：

- `k = ( sqrt(3), 1, 0 )`
- `k = ( 0, 0, 1 )`

数值化：
- `k = ( +1.732051,  +1.000000,  +0.000000 )`
- `k = ( +0.000000,  +0.000000,  +1.000000 )`

**几何意义**：

- `k1 = (1, 1/sqrt(3), 0)` 是**耦合整体重标度方向**：`g~ -> lambda g~`、
  `g~' -> lambda g~'` 同时缩放，比值 `g~'/g~ = 1/sqrt(3)` 不变。
- `k2 = (0, 0, 1)` 是**真空自耦合方向**：`kappa~` 完全自由。

即：**S13 的无量纲扇形留有两个自由方向**——一个整体标度 + 一个自耦合。

## 3. 靶投影检验：`dq|_D = 0 ?`

按定理 D，靶 q 是真预言候选 **当且仅当** `dq|_{ker J_E} = 0`。

### q1  sin^2 theta_W = g~'^2/(g~^2+g~'^2)

- 描述：电弱混合角（比值型）
- `dq/dg~ = -2*g*gp**2/(g**2 + gp**2)**2`
- `dq/dg~' = 2*g**2*gp/(g**4 + 2*g**2*gp**2 + gp**4)`
- `dq/dkappa~ = 0`
- 沿 k1（整体重标度）: `dq|_k1 = 0`
- 沿 k2（自耦合方向）: `dq|_k2 = 0`
- **判定**：`dq|_D = 0` ⇒ **真预言候选**

### q2  alpha ~ e^2 = g~^2 g~'^2/(g~^2+g~'^2)

- 描述：精细结构常数（绝对耦合尺度型）
- `dq/dg~ = 2*g*gp**4/(g**4 + 2*g**2*gp**2 + gp**4)`
- `dq/dg~' = 2*g**4*gp/(g**4 + 2*g**2*gp**2 + gp**4)`
- `dq/dkappa~ = 0`
- 沿 k1（整体重标度）: `dq|_k1 = sqrt(3)/2`
- 沿 k2（自耦合方向）: `dq|_k2 = 0`
- **判定**：`dq|_D != 0` ⇒ **拟合/对接**

### q3  kappa~

- 描述：真空自耦合（无约束旋钮）
- `dq/dg~ = 0`
- `dq/dg~' = 0`
- `dq/dkappa~ = 1`
- 沿 k1（整体重标度）: `dq|_k1 = 0`
- 沿 k2（自耦合方向）: `dq|_k2 = 1`
- **判定**：`dq|_D != 0` ⇒ **拟合/对接**

### q4  g~' (绝对耦合)

- 描述：绝对耦合（整体标度型）
- `dq/dg~ = 0`
- `dq/dg~' = 1`
- `dq/dkappa~ = 0`
- 沿 k1（整体重标度）: `dq|_k1 = 1`
- 沿 k2（自耦合方向）: `dq|_k2 = 0`
- **判定**：`dq|_D != 0` ⇒ **拟合/对接**

### 3.1 检验结果汇总

| 靶 | 描述 | dq&#124;k1 | dq&#124;k2 | 判定 |
|---|---|---|---|---|
| q1 | 电弱混合角（比值型） | 0 | 0 | **真预言候选** |
| q2 | 精细结构常数（绝对耦合尺度型） | sqrt(3)/2 | 0 | **拟合/对接** |
| q3 | 真空自耦合（无约束旋钮） | 0 | 1 | **拟合/对接** |
| q4 | 绝对耦合（整体标度型） | 1 | 0 | **拟合/对接** |

**结论**：`sin^2 theta_W` 沿两条零空间方向导数**同时为零** ⇒ 它是 S13 的
真预言候选（结构固定为 1/4）。而 `alpha` 沿整体重标度方向 k1 的导数
`= sqrt(3)/2 != 0`（按单位标度方向即 `2 alpha != 0`，见 §4.2 基归一化说明）
⇒ **alpha 是拟合/对接，不是预言**。这与 S13 自身诚实边界完全一致
（ch25 §25.7：alpha 目前只是输入/对接，不是输出）。

## 4. 标度不变性壁垒（定理 E）

上面算例揭示了一个**结构性根源**：S13 的约束 E1 是耦合的**齐次**函数。
下面把它一般化并符号验证。

### 4.1 陈述

**定理 E（标度不变性壁垒）** 设动力学路线的第一性原理约束 E 在耦合
整体重标度 `g -> lambda g` 下**齐次**（保持 E=0 的解集不变），则

1. `ker J_E` 至少含一个**整体标度方向** `s = (g~, g~', ...)`；
2. 只依赖**重标度不变量**（比值、混合角、量子化步长、计数）的靶满足
   `dq|_D = 0`，可为真预言候选；
3. 任何依赖**耦合绝对标度**的靶（如 `alpha`）必有 `dq|_D != 0`，
   只能是拟合或对接（corresponds to 定理 C 情形 2）。

### 4.2 符号验证：齐次性与欧拉定理

```
sin^2 theta_W(lam g, lam g') - sin^2 theta_W(g,g')   = 0   (标度不变, 度 0)
(alpha 型)(lam g, lam g') - lam^2 (alpha 型)(g,g')    = 0   (2 次齐次, 度 2)
kappa~(lam) - kappa~                                  = kappa*(lambda - 1)   (kappa~ 不参与耦合标度)
```

沿整体标度方向 `s` 的方向导数（欧拉定理）：

```
dq1|_s = 0        (度 0 => 零)
dq2|_s = 2*g**2*gp**2/(g**2 + gp**2)   (度 2 => 欧拉定理 = 2 q2, 非零)
```

**基归一化说明**：sympy 返回的零空间基 `k1 = (sqrt(3), 1, 0)` 并非单位
标度方向，而是 **`sqrt(3)` 倍的自然标度方向** `s = (1, 1/sqrt(3), 0)`。因此
§3 表中 `dq2|_k1 = sqrt(3)/2` 与本节 `dq2|_s = 2 q2` 一致：

```
(sqrt(3)/2) / sqrt(3) = 1/2 = 2 * q2 = 2 * (1/4) = 2 alpha
q2 = alpha 型在 (g~,g~')=(1,1/sqrt(3)) 处取值 = 1/4 = alpha 的代数原型
dq2|_s(数值) = 1/2  = 2 alpha  != 0
```

无论取哪条基，结论相同：**`dq2|_D != 0` ⇒ alpha 非线性可调方向被完全固定。**

**验证通过**：标度不变靶的标度方向导数为零，绝对标度靶的标度方向导数
等于其齐次度数乘自身（欧拉定理），恒不为零。**这就是壁垒。**

### 4.3 S13 三公设的标度性质审计

| 公设 | 内容 | 是否含绝对标度锚 |
|---|---|---|
| S13-A1 对偶公理 | `D^2 = 1`（Z_2 对合） | 否（纯代数） |
| S13-A2 守恒公理 | `Q in Z`（拓扑整数） | 否（整数，无标度） |
| S13-A3 自相似公理 | `beta(-g) = -beta(g)`、`g* = sqrt(eps/c)`（比值） | 否（比值，齐次） |

**三条公设全部标度不变** ⇒ 由定理 E，S13 的公设集在原理上不能锁定
耦合绝对标度 ⇒ **不能预言 `alpha`**。这是「S13 未导出 alpha」的代数根源，
把一句观察升级为一条定理。

## 5. 与定理 A / 定理 C 的接口

| | 定理 A（量纲零空间） | 定理 C（两种情形） | 定理 D（旋钮零空间） | 定理 E（标度壁垒） |
|---|---|---|---|---|
| 工具 | `nullity(D_A)` | 分类 | `nullity_dyn = n - rank(J_E)` | 齐次性 / 欧拉定理 |
| 结论 | 锚集能造几个无量纲数 | 量纲代数无预言 | 靶是否被固定 | 齐次约束不能定绝对标度 |
| 对 alpha | 从 {c,h,G} 造不出（=0） | 必落情形 2 | 落在非零方向（拟合） | 三公设全齐次 ⇒ 不能锁定 |

**三定理互证**：定理 A 说「量纲代数的锚不够」；定理 C 说「换任何量纲锚都不够」；
定理 D/E 说「换成动力学路线，只要公设齐次，仍然不够——缺的是**标度对称破缺**」。
三者从三个方向指向同一个缺口：**一个打破标度不变性的第一性原理变分项**。

### 5.1 S13 的 alpha 属于定理 C 情形 2

S13 ch25 §25.2 的对接程序把 alpha 作为**输入**，反解出 {g~, g~', kappa~}。
这正是定理 C 情形 2 的动力学版：**靶含自有量（此处为绝对耦合 e）⇒ 恒可反解 ⇒ 定义而非预言**。
对接（docking）在代数上与「装常数」不可区分——这是 S13 自己承认的边界。

### 6.1 对第63章 §63.5「下一步」的回答

第63章问：S13 的谱问题是否满足 `nullity_dyn = 0`？

**答**：对 `alpha` —— **不满足**（`nullity_dyn = 2 >= 1`）。对 `sin^2 theta_W` 等
比值型靶 —— 满足（落在零空间核里，`dq|_D = 0`）。因此：

- S13 **确实**是唯一走在动力学路线上、且**确实**有一个结构预言（`sin^2 theta_W = 1/4`）的体系；
- 但该预言**不是 alpha**，且其数值（1/4）被实验否证（树级差 8.1%）；
- **S13 不解锁 UFT-3**：解锁 UFT-3 需要 alpha 级别的连续无量纲预言，
  而 S13 的公设集齐次 ⇒ 由定理 E 不能产生。

### 6.2 解锁 UFT-3 的**精确**缺口（本册最新结论）

综合定理 A/C/D/E，缺口的描述已可精确化：

> **缺的不是「动力学路线」，而是「打破标度不变性的动力学路线」。**
> 具体地：需要一个第一性原理变分项，它在耦合整体重标度 `g -> lambda g` 下
> **不齐次**（即含一个绝对标度、且该标度由变分原理**定出**而非自由），
> 使 `ker J_E` 中的整体标度方向被**消除**（`nullity_dyn` 减少 1）。
> 届时 `alpha` 的 `dq|_D` 才可能为零。

这比第62/63章的「要补三块砖」更锐利：三块砖中，**砖①「显式依赖螺距的变分项」
的真正作用就是打破标度不变性**——本册现在能说清它为什么必需。
