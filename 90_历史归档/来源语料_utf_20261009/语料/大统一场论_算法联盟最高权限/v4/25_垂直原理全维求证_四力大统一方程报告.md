## 一、什么是"垂直原理"？—— v4 体系中的定位

01 号公理体系第 16 行明确：

> `ε·ε⁻¹ = 1` 自然导出 **Frenet 标架的 T/N/B 三元正交结构**。

在 v4 螺旋几何中，"垂直原理"即 **Frenet 标架三元正交**：

$$ \mathbf{T}\perp\mathbf{N}\perp\mathbf{B},\qquad |\mathbf{T}|=|\mathbf{N}|=|\mathbf{B}|=1 $$

- `T`（切向）= 速度方向，螺旋沿 T 前进（轴向匀速 + 环绕）
- `N`（法向）= 曲率方向，`dT/ds = κ·N`（弯曲）
- `B`（副法向）= `T×N`，扭转方向，`dB/ds = -τ·N`（挠率）

**核心洞察**：曲率 `κ` 活在 `(T,N)` 弯曲平面，挠率 `τ` 活在 `(T,B)` 扭转平面——二者在 T/N/B 正交系中**天然解耦**。这正是四力（引力⊥电磁）能统一于单一复曲率场 `Ξ=κ+iτ` 的几何根源。

## 二、PART A · 垂直原理的符号求导证明（实跑 PASS）

→ 瞬时光速公理成立，空间**动态运行**而非静态容器。

### A.2 Frenet 标架（归一化求导）
$$ \mathbf{T}=\frac{\mathbf{v}}{|\mathbf{v}|},\quad \mathbf{N}=\frac{\mathbf{a}}{|\mathbf{a}|},\quad \mathbf{B}=\mathbf{T}\times\mathbf{N} $$

```

N = (-cosθ, -sinθ, 0)

```

### A.3 垂直原理检验（三元正交）
```
T·N = 0  ✅ 垂直
N·B = 0  ✅ 垂直

|T|=|N|=|B|=1

→ **垂直(正交)原理 [PASS]**：对偶算子 `ε·ε⁻¹=1` 在微分几何中表现为 `T⊥N⊥B`。

### A.4 曲率/挠率几何定位
```
dT/ds = κ·N,  κ = ρ/(ρ²+b²)   (弯曲, 活在 T⊥N 平面)
