# 审计与研究路线

## 已完成
1. 证明标准圆柱螺旋 κ²+τ²=ω²/v²；c=1 归一后简化为 ω²。
2. 给出一维周期自伴谱算子及可直接求解的本征值公式；该算子不是四力统一证明。
3. 用标准常数完成理想质量源、电磁能量源、旋转栖居地量级计算。
4. Python 标准库自动测试四项：螺旋恒等式、引力质量反算、磁能 B² 标度、旋转加速度。

## 关键未解决（OPEN）
- 没有从微观螺旋推导四维协变动力学；没有给出量子化与路径积分。
- 没有从谱作用量无调参导出 SU(3)×SU(2)×U(1) 和粒子谱。
- 没有黎曼零点与物理谱的严格映射；不能宣称证明黎曼猜想。
- 没有超越 GR/标准模型且通过独立实验的数值预测。
- 没有实验确认的可控额外引力效应。

## 下一阶段可证伪里程碑
M1：定义四维洛伦兹协变的几何/谱模型，写出全部自由度与边界条件。
M2：解析求变分方程，检查守恒、鬼场、超光速模和量纲。
M3：计算 PPN 参数、引力波速度、弱场第五力和短程偏差，与现有实验比较。
M4：预注册实验，建立系统误差预算和统计功效分析。
M5：若模型未产生无自由调参的新预测，明确判定其为重新表述而非突破。
