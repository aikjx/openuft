关键的数学结论

固定能量、正则角动量的轴对称哈密顿系统，若从 r、z 两个转折点出发并发生五圈完整周期回归，则 t 和 T−t 的径向、轴向坐标相同，方位角互为 10π 减去原角。由此在 φ=kπ (k=1,2,3,4) 必然出现不同时间的空间重合。若轨迹发生自交，普通结多项式不再有定义。

人为偏移 0.15 µm 的离散多边形，三种投影的 Fox 结行列式均为 9；这是数学示例，不是原物理轨道的结类型，也不是证明存在新相互作用。
