## 一 来料还原：LaTeX 机械污染的定位与修复

来料全文不是「个别笔误」，而是**多个全局 token 替换叠加**：`A → \(\mathcal A\)`、`F → \(\mathcal F\)`、`g → \(\mathfrak g\)`（含 `\mathrm{Tr} → \mathrm{\(\mathrm{Tr}\)}` 一类同型污染）。因此污染形散落在每个 TeX 命令内部。还原表（代表项）：

| 污染形 | 还原形 | 出现位置 |
|---|---|---|
| `\mathcal \(\mathcal A\)` | `\mathcal A` | 主联络 |
| `\mathcal \(\mathcal F\)` | `\mathcal F` | 场强 2-形式 |
| `\mathrm{\(\mathrm{Tr}\)}` | `\mathrm{Tr}` | §2 作用量与能动张量 |
| `\ri\(\mathfrak g\)htarrow` | `\rightarrow` | 标题、$\not\rightarrow$ |
| `Yan\(\mathfrak g\)-Mills` | `Yang-Mills` | 全文 11 处 |
| `\bi\(\mathfrak g\)(` | `\big(` | §2 作用量 |
| `\ri\(\mathfrak g\)ht` | `\right` | §2 公式括号 |
| `\wed\(\mathfrak g\)e` | `\wedge` | §1 主曲率 |
| `Ome\(\mathfrak g\)a` | `\Omega` | §1 黎曼曲率 |
| `ome\(\mathfrak g\)a` | `\omega` | §1 黎曼联络 |
| `\(\mathfrak g\)amma` | `\gamma` | §2 协变导数 |
| `si\(\mathfrak g\)ma` | `\sigma` | §2 能动张量 |
| `\(\mathfrak g\)`（孤立） | `g` | `\sqrt{-g}`、`g_{μν}`、`g_{SU3}` 等 |

**处置**：本册所有引用一律用还原后的写法；**来料字节未改动、未落盘替代原件**。只做还原 + 编号定位，不重写来料论证。

## 三 本轮新增审计增量（I1–I5，全部机核）

脚本 [`源码/v39_next_audit.py`](源码/v39_next_audit.py)；下表 `value` 为脚本实际输出，`成立` 表示**本审计断言**在此成立（不是「来料正确」）。

### I1 作用量符号与归一化：`+¼ Tr(F²)` 与 C1+C4 冲突（4 条，全成立）

取 E=(1,0,0)、B=(0,2,0)：

| 检验 | 机核值 | 含义 |
|---|---|---|
| `F_{μν}F^{μν}` | 6.000000（=−2E²+2B²） | C1 下的定值 |
| `L(+¼)` / `L(−¼)` | +1.500000 / −1.500000 | 来料符号 |
| `T00`（来料给的 T 公式） | **+2.500000**（=(E²+B²)/2） | —— |
| `T00`（由 +¼ 作用量真变分） | **−2.500000** | **同文两式符号互斥** |
| `T^μ_μ` | 0.00e+00 | 4 维 YM 共形无迹 |
| C4 下 `+¼Tr` / 标准 `−¼Σ` | **−0.500** | 除符号外还差因子 2 |

**裁定**：来料 §2 的 `+¼ Tr(F_{μν}F^{μν})` 在 C1（(−,+,+,+)）下给出负能/鬼态；而同文 `T^{YM}_{μν}=Tr(F_{μρ}F_ν^ρ −¼g_{μν}F²)` 恰是 **−¼** 作用量的变分结果。二者不可同时成立。按 C4（`Tr(T^aT^b)=½δ^ab`）还需把系数写成 **−½ Tr**（等价 `−¼ Σ_a F^a F^a`）。**这是 V39 障碍 #5「号差/Tr 未定」的定量实例：不是「约定未声明」而已，是写下来的两个式子互相矛盾。**

### I2 非阿贝尔「对偶」不存在：`d*F = −[A,*F] ≠ 0`（2 条，全成立）

构型 A₀=xT¹、A₂=xT²（g=1，SU(2)，Tr(T^aT^b)=½δ^ab）：

| 检验 | 机核值 | 含义 |
|---|---|---|
| `F_02` | `diag(−x²/2, +x²/2)` | 非阿贝尔场强 |
| `max|d(*F)|`（x=1 处） | **1.0** | ***F 非闭** |
| `max|d(*F)+i[A,*F]|` | **0.0** | Bianchi 恒等式仍成立 |

**裁定**：U(1) 情形 `dF=0 ⇒ d*F=0 ⇒ *F 局部恰当 ⇒ 存在对偶势`，故对偶旋转是**方程层对称**、带源后破缺（既有 2.4 数值已验）。非阿贝尔情形 `d*F = −[A,*F] ≠ 0`，`*F` 连**闭形式**都不是，**不存在对偶势**，对偶旋转不是联络空间上的映射。⇒ 来料 §4 的「对偶简并破缺」**只对 U(1) 因子有效，对 SU(3)×SU(2) 部分是空论断**（那里本来就没有该对称性可破）。「SM 无磁单极流」是模型输入，不是几何定理。

### I3 KK 的真实代价：等距方向 ≥23、模数=3、参数 4↔4（2 条，全成立）

| 检验 | 机核值 | 含义 |
|---|---|---|
| dim(Ad-不变对称型, su(2)) | **1** | 每个单因子只有 Killing 型（唯一尺度） |
| dim(Ad-不变对称型, su(3)) | **1** | 同上 |
| dim(G) | 8+3+1=**12** | SM 内部代数 |
| dim(Isom)（乘积双不变度规） | ≥2·8+2·3+1=**23** | 比 SM 多 ≥11 个规范方向 |
| G-不变度规模数 | 1+1+1=**3** | 三个因子各一尺度 |
| 自由参数 | {κ_D, λ₃, λ₂, λ₁}=**4** ↔ {κ₄, g₃, g₂, g₁}=**4** | **只换名，不约化** |

**裁定**：
- 来料 §3 的 ①「额外维必须拥有 12 个 Killing 矢量」**可满足**（Y=G，左平移即给 12 个 Killing 矢量），不构成障碍；
- 「Isom(Y) 必须**正好**等于 G」是过强条件，且在 Y=G 上必然失败——Ad-不变性把度规强制为双不变，等距代数至少 23 维（**多出 ≥11 个规范玻色子**，须逐个赋质量）；
- 来料 §3 的 ②③（模场、手征）成立；但「12 vs 6 维数不匹配」**是伪障碍**：洛伦兹代数与内部代数不要求同维，§1 自己已禁止把两者等同；
- **攻破点 #1 因此被加强**：KK 不是「生成耦合」，而是把 **3 个内部模数 + 1 个 D 维引力常数** 一一映射为 **3 个规范耦合 + 1 个 4 维牛顿常数**；参数个数守恒，α 仍为输入。

### I4 null 场：F²=F*F=0 但多生成元 T²≠0（3 条，全成立）

取两个不同零方向的 SU(2) 生成元：$E_1=(1,0,0),B_1=(0,1,0)$ 与 $E_2=(0,0,1),B_2=(1,0,0)$（均 E⊥B、|E|=|B|）：

| 检验 | 机核值 | 含义 |
|---|---|---|
| `F_a²` / `F_a·*F_a` | [0,0] / [0,0] | 每个生成元幂零 |
| `tr(T^μ_ν)` | 0.00e+00 | 无迹 |
| `‖T²‖_F` | **3.162278** | 多生成元 T² ≠ 0 |
| `max|T²−¼tr(T²)I|` | **1.500000** | 不∝I |

**裁定**：来料 §5 的「null 退化在非阿贝尔 YM 中保留、但代数结构更复杂」**成立**，并首次给出矩阵实例：**单场幂零 ≠ 多生成元幂零**；Rainich 的 null 专用判别条件不能平移，须另造 YM 版可积性条件（与来料一致，无冲突）。

### I5 Palatini「无挠」与旋量耦合的矛盾（1 条，成立）

| 检验 | 机核值 | 含义 |
|---|---|---|
| `<ψ̄ γ^μ Σ₀₁ ψ>`（一般旋量 ψ=(1,2,3,4)） | (10, 15, 5i, 0)，max=**15.0** | 自旋联络有非零源 |
| 同式对 ψ=(1,0,0,0) | 0 | 特例为零，不是恒等 |

**裁定**：Palatini 变分「联络=Levi-Civita、无挠」的定理**前提是 S_matter 不依赖联络**。来料同一节把 `D_μ=∂_μ+Γ_μ+igA_μ` 作用于 ψ，则 `δS_matter/δΓ ≠ 0` ⇒ **挠率被自旋流激发**（回到 Einstein–Cartan），与 §2 第 1 步结论冲突。V45 **C6** 的修法是**约定**：「仿射联络=Levi-Civita、自旋联络由 tetrad 相容条件唯一导出」——即把理论**定义**成无挠，而非**推出**无挠。这一条与库内 r341「挠率是代数 slave」、以及本册 §4 对 EC 覆盖的盘点互相印证。
