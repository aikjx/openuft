任务 1NS 自相似爆破（连续动力学）

  • 涡量方程：∂tω + (u·∇)ω = (ω·∇)u + νΔω
  • 标度匹配：α+β = 1，α > β → α = 2/3，β = 1/3
  • 自相似解：u = τ−2/3U(x/τ1/3)，ω = τ−1Ω(x/τ1/3)
  • 爆破判据：ω→∞，∇u→∞；E ∝ τ−1/3（局部）
  • 机制：涡拉伸 (ω·∇)u 局部压倒粘性 νΔω；2026 已构造有限时间爆破解（带光滑紧支撑外力）

任务 2洛伦兹力 = 涡旋横向耦合

  • TUFT 同构：ω ↔ B，u ↔ v，qeff ↔ q
  • Biot–Savart：Γ ↔ μ0I，du ↔ dB
  • 耦合导出：F = qeff·v×ω　→　F = q·v×B
  • F ⊥ v，不做功；电场 ↔ 无旋势梯度（曲率伸缩），磁场 ↔ 有旋挠率叉乘

任务 3三维螺旋点阵 · Erdős 单位距离

  • 单根螺旋：rk = (R cos kθ, R sin kθ, kh)，θ = 2π/N（分圆根）
  • 单位距离：2R²(1 − cos Δkθ) + h²Δk² = 1
  • 多螺旋叠加：θj = θ0 + 2πj/M；约束 |r−r′| ≥ 1 → 球堆积
