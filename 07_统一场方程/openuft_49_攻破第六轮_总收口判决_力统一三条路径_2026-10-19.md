**总判决：`TOTAL_NO_TESTABLE_ROUTE`**

> **大白话**：想让三个力合成一个，只有三条路——换"怎么跑"（A）、换"跑什么粒子"（B）、换"什么群"（C）。
> A 是白费劲（换个说法而已，判决不变）；B 能做到"三线共点"，但共点太低，质子会衰变得比实测快 7 个量级；C 没被排除，可它要么把统一点当自由输入（等于没预言），要么给出质子寿命长到近期测不出来。
> **所以：本框架内不存在"可行且可检验"的力统一路径。**

---

## 一、为什么只有这三条路（决策树）

一圈 RG 下 $\alpha_i^{-1}(\mu)=A_i-\frac{b_i}{2\pi}\ln(\mu/M_Z)$，其中 $A_i$ 为**实测**、$b_i$ 由**粒子谱**决定。要产生"三耦合汇聚"，只能改三样东西之一：

1. **改 $\mu$ 的含义**（空间运行方式 = 几何量随能标变化）→ 路径 A；
2. **改 $b_i$**（换谱）→ 路径 B；
3. **改 $A_i$ 的约束来源**（换群/换对称性，使 $A_i$ 不再是三个自由输入）→ 路径 C。

第四、五轮已分别闭合 A、B；本轮补上 C 并合并。

---

## 二、路径 A：空间运行方式 = 重参数化（CLOSED，复算）

共线判据：$r\equiv\frac{b_2-b_1}{b_3-b_1}$ 必须等于 $r^*\equiv\frac{A_2-A_1}{A_3-A_1}$。

- $r^*=0.582379$；SM $r=0.654655$（差 0.0723）；MSSM $r=0.583333$（差 0.00095）。
- 判据**不含 $\mu$** ⇒ 任何单调空间运行方式（$\kappa(\mu),\tau(\mu),\dots$）只是重参数化。
- **复算**：解析最小弥散经 $s=u^2$、$s=e^u-1$ 往返，差值 $=0.000\text{e+}00$（精确为零）。

⇒ 5 类运行方式（固定螺旋/幂律/双参数/谱匹配/振荡）**全部 0 存活**。

---

## 三、路径 B：换谱能共点，但共点太低（CLOSED，复算）

- 扫描：234 表示基元 ×（单表示 $n\le10$ + 色单态两两组合）= 约 24k 条目。
- **100 个候选命中 $r^*$** ⇒ 换谱确实能让三线共点（这点本轮如实承认）。
- 但这些候选的 $M_{\rm GUT}\le2.18\times10^{14}$ GeV ⇒ $\tau_p\le1.42\times10^{27}$ yr。
- Super-K 下限 $1.6\times10^{34}$ yr ⇒ **100 个全部被否决，存活 0**。
- 唯一能把 $M_{\rm GUT}$ 抬到 $10^{16}$ 的是 MSSM 式**成套超伴子**——那是**换对称性**（SUSY），不是换谱，且 ~105 参数 > 7、LHC 未见、维度-5 质子衰变排除。

## 四、路径 C：扩群 SO(10)——未排除，但不交付（归因）

来源：`验证脚本/SO10链统一报告.md`（`so10_chain.py` 探针）。**本轮不复算其数字，只合并其判决。**

| 链 | $M_{\rm GUT}$ | 是否预言 | 备注 |
|---|---|---|---|
| PS422 | **输入**（1 参数族）| **否** | 只预言 $M_{PS}(M_{\rm GUT})$、$M_R(M_{\rm GUT})$、$\tau_p(M_{\rm GUT})$；次序窗口 $[2.64\rm e15,1.99\rm e17]$，叠质子后存活带 $[1.17\rm e16,1.99\rm e17]$ |
| R421 | **输入**（1 参数族）| **否** | 同上 |
| R3221 | $\{2.3\times10^{16},\,2.0\times10^{17}\}$ GeV | **是（唯一解）** | $\alpha_{\rm GUT}^{-1}\in\{45.42,47.82\}$；$\tau_p\in\{3.4\times10^{35},\,2.1\times10^{39}\}$ yr；三条情形全过 Super-K |

**为什么判"不交付"**：

1. **2/3 条链不给 $M_{\rm GUT}$ 预言**——统一点是自由输入，不是推论。该探针自己已写明：「三耦合能在线性方程组下精确相遇」是**参数计数的结果**（未知量数 = 方程数），**不是独立证据**。
2. **唯一预言链（R3221）近期不可检验**：最低 $\tau_p=3.4\times10^{35}$ yr，对 Hyper-K/DUNE 可及 $\sim10^{35}$ yr 高出 **0.53 量级**；探针自陈"实践上近期不可证伪"，且质子寿命为量级标定（短程 QCD 增强与强子矩阵元未计入，约 1 个数量级）。
3. **与 P4 直接冲突**：P4（UFE-1 v1）说 $\tau_p=\infty$（$B-L$ 严格守恒、无 $X/Y$ 玻色子）；SO(10) 说 $\tau_p$ 有限。**二者不能同时为真**；任何一次质子衰变观测都同时否证两者。

⇒ **路径 C 未被排除**（SO(10) 是合法研究纲领），但在本框架门禁下**不交付可检验的力统一预言**。

## 五、总判决的含义

```
收紧（要求"自然统一"）：
   SM 谱      -> 52σ 否决（第四轮复算）
   纯换谱     -> 共点但 M_GUT≤2.2e14，τ_p 差 7 量级（第五轮）
   SO(10)     -> 2/3 链无预言；1/3 链预言超可及 0.53 量级，且与 P4 冲突
放松（引入自由参数拟合）：
   换运行方式 -> 空转（重参数化，判决不变）
   PS422/R421 -> M_GUT 成自由输入，参数计数门不过
   MSSM       -> 通过但需 ~105 参数 + LHC 未见 + 维度-5 排除
```

**三条路都通向"要么被否决、要么不可检验"。** 这与第一轮（P-H3 夹死）、第二轮（P-H4 夹死）同构，但本轮把它推到了**穷尽层面**：不是"我们没找到"，而是"决策树上的三条分支逐条被机器判过"。

## 六、诚实边界

1. **路径 C 不自造数字**：全部归因 `SO10链统一报告.md`；若该探针口径变更，本节需重读。
2. **路径 B 未穷尽**：未扫三元及以上组合、色六重态等高阶表示。结构原因（小 $\Delta b$ 抬不高 $M_{\rm GUT}$）支持定性结论，但**不是数学完备性证明**。
3. **质子衰变用维度-6 粗估** $\tau_p\propto M_{\rm GUT}^4$：路径 B 最优者差 7 量级，放宽 3 量级也不改判；路径 C 的 0.53 量级**对标定误差敏感**——计入强子矩阵元的 ~1 量级后，可与可及性相当，故路径 C 判"不交付"而非"已排除"。
4. **未判**：量子引力/弦论/非微扰能标处的统一；本轮限一圈微扰 RG 框架。

## 七、防过度指控

1. **不主张** SO(10) 被证伪——它**未被排除**，只是不交付可检验预言。
2. **不主张**"几何统一不可能"——只主张三条具体路径在本框架门禁下不成立。
3. **不否认** MSSM 在耦合统一上成功（1.27σ）；否认的是它作为"换谱"定义内的出路，以及它被三重排除的可行性。
4. **不宣称**任何"突破"——本系列六轮均为**闭合性判决**。
