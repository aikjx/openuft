# V128 严格预注册：防止以定义冒充推导

## 初始模型冻结

1. 先给定局域 Lorentz 协变、微观幺正的作用量，不允许以后根据已知电子/μ子数据逐个选取不同的自由几何半径。
2. 固定粒子谱、规范群、量子相位、\(\hbar\) 数值来源与重整化流程。
3. 写出无需实验后调参的预测区间及误差，含电子 g 因子、\(m_\mu/m_e\)、\(\alpha\)、光子质量为零和光速关系。
4. 理论必须面对 Standard Model 的手征规范表示、三代粒子、实验室磁矩与 Lorentz 不变性；不能只拟合一个公式。
5. 对已固定的第五力候选 \(\alpha_Y=1/3,\ell=124.6\) km，保持预注册数值，不以调整地球密度或新参数规避真实约束。

## 硬失败条件

- 只是用 \(r=\hbar/(mc)\) 改写 \(m=\hbar/(cr)\) 而没有独立求出 \(r\)。
- 简单整数 KK 质量塔预测所有轻子质量比为整数。
- 同一三维轨迹同时具有轴向光速和额外非零横向速度。
- 经典圆周电荷仅产生 g=1 却宣称证明电子 g≈2。
- 只有数值合成测试、没有实验数据，却宣称已发现新量子规律。

## 下一步最有价值的验证

先做最小旋量—螺旋耦合拉格朗日量的谱、规范及旋量自旋审计。必须在预先固定参数后与 CODATA 2022、PDG 2025 标准值比较。给出至少一个不同于标准理论的明确、独立且可观测预言；否则仅称既有理论的重新表述。
