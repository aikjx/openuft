## 18.0 总纲：v_总 = c 的物理含义

### 18.0.1 光速公理

**核心公理**：一切物理粒子在空间中以螺旋轨迹运动，其**总速度恒为光速 c**。

$$v_{\text{total}} = \sqrt{v_\perp^2 + v_\parallel^2} = c \quad \text{（公理）}$$

**物理解释**：
- v_⊥：螺旋横向速度（被观测的"粒子运动速度"）
- v_∥：螺旋轴向速度（维持 v_total=c 的内禀运动）
- 宏观"静止"粒子：v_⊥=0, v_∥=c → 粒子以光速绕轴旋转
- 宏观"运动"粒子：v_⊥>0, v_∥<c → 螺旋角动量产生线速度分量

### 18.0.2 频率作为桥梁

频率 ω 是连接传统物理学与几何框架的唯一桥梁参数：

$$\omega = c\sqrt{\kappa^2 + \tau^2} = \frac{c}{R} = \frac{E}{\hbar} = \frac{mc^2}{\hbar}$$

五种等价表达式：

| 表达式 | 含义 | 来源 |
|:---|:---|:---|
| ω = c/R | 曲率半径决定频率 | 几何 |
| ω = c√(κ²+τ²) | 曲率+挠率决定频率 | Frenet-Serret |
| ω = E/ℏ | 能量决定频率 | 量子力学 |
| ω = mc²/ℏ | 质量决定频率 | 质能等价 |
| ω = c/√(ℏG/c³) | 普朗克频率 | 引力+量子 |
