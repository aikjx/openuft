## 问题定义

强相互作用由 SU(3)_C 描述，核心挑战：①禁闭（夸克胶子囚禁于强子）②渐近自由（高动量耦合减弱）③强子质量谱 ④核力。核心问题：能否从统一场论几何第一性精确导出 QCD 定量结果？

## 当前进展（2020–2026）

| 方向 | 进展 |
|---|---|
| 格点 QCD | 强子质量谱精度 1–2%；核子结构函数 |
| 渐近自由 | Gross-Wilczek-Politzer 定理（1973）已严格证明 |
| 禁闭 | 无解析证明；格点数值支持；千禧年奖问题 |
| 统一场论 | 无统一场论能从第一性精确导出 QCD 定量结果 |

## 证伪条件

- 若统一场论预言强子质量与实验不符，该预言被证伪
- 若禁闭机制与格点 QCD 冲突，该方案排除
- 若渐近自由无法恢复，与 QCD 不兼容

## 入库触发与状态

- **入库触发**：从该体系推导的强子质量谱与格点 QCD 在 1–2% 内吻合
- **当前状态**：开放问题；QCD 已实验验证，统一场论精确化未实现

## 分析进展（求导证明验证 + 精算分析）

脚本 `verify_qcd_precision.py`：

- **渐近自由**：α_s 随 Q 增大而减小（单圈 RGE 复算通过，PASS）
- **Z 极点**：α_s(M_Z)≈0.117，与 PDG 0.1179±0.0010 同阶（PASS）
- **组夸克质子质量**：2m_u+m_d≈1012 MeV vs 实验 938 MeV，偏差 ~8%（BOUNDARY，玩具模型漏胶子/动能/海夸克）

## 诚实边界（红线，不粉饰）

1. 本册为标准 QCD 跑动与组夸克玩具模型，非统一场论第一性推导禁闭
2. 禁闭（千禧年问题）无解析证明，格点 QCD 给出 1–2% 质量谱，UFT 未达此精度
3. 数学自洽 ≠ 实验证实：QCD 本身已被实验精验，统一场论的精确化未实现
