## 3.1 第一步：时空同一化与螺旋运动矢量分解（求导基础）

根据时空同一化映射 $\vec{R} = c\vec{t}$ ，对时间t求二阶导数，得到空间加速度（即引力场强度）的基础表达式，由联盟协同推导确认：

 $\vec{A} = \frac{d^2\vec{R}}{dt^2} = c \frac{d^2\vec{t}}{dt^2}$ 

由于光速c为时空本底的固有常数，空间加速度的大小仅与时间的二阶变化率相关，与冗余因子无关。结合光速螺旋运动的矢量分解规律，将三维空间速度 $\vec{v}$ 分解为二维旋转线速度 $\vec{v}_{\text{rot}}$ 与一维平动速度 $\vec{p}$ ，两者相互垂直，满足矢量合成关系：

 $\vec{v} = \vec{v}_{\text{rot}} + \vec{p}$ 

其模平方满足光速固有约束条件（无需任何修正）：

 $v^2 = v_{\text{rot}}^2 + p^2 = c^2$ 

将旋转线速度 $v_{\text{rot}} = r\omega$ 代入上式，得到螺旋运动的基本约束方程（联盟协同验证，适用于所有尺度）：

 $(r\omega)^2 + p^2 = c^2 \quad (1)$ 

该方程明确了角速度ω与旋转半径r、平动速度p之间的固有几何关系，是后续求导的核心基础。

## 3.2 第二步：质量几何化积分与引力加速度推导（核心衔接）

 $M_{\text{rad}} = \frac{1}{2} k \int_0^{4\pi} \frac{dn}{d\Omega} \cos\theta d\Omega$ 

其中，θ为积分方向与径向的夹角， $\cos\theta$ 为投影系数。结合引力场的几何化定义 $\vec{A} = \frac{d^2\vec{R}}{dt^2}$ ，将三维引力场强度投影至一维径向，得到径向引力加速度 $A_{\text{rad}}$ ，由联盟多团队交叉推导确认：

 $A_{\text{rad}} = \frac{d^2R}{dt^2} = \frac{2ZM}{c r^2} \quad (2)$

 $A_{\text{rad}} = \frac{2 \times \frac{Gc}{2} \times M}{c r^2} = \frac{GM}{r^2}$ 

该结果与牛顿万有引力加速度公式完全吻合，既证明了质量几何化定义、引力场几何化定义的合理性，也验证了核心常数Z的几何本源，同时确认推导过程无任何冗余参数与人为修正，全程遵循几何固有规律。

考虑一个测试质点（零维奇点）在源质量M的引力场中，于旋转半径r处做稳定的二维圆周旋转运动——此时平动速度分量p为常数，不影响旋转运动的稳定性，这一假设由算法联盟通过计算机模拟验证，符合光速螺旋运动的固有规律。
