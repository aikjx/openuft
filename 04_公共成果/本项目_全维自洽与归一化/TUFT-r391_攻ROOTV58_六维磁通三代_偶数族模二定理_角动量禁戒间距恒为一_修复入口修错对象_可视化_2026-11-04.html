图 1　主定理：奇偶性由模 2 锁死，与族数无关

三行证明：前提 Σ sᵢqᵢ² = 0 乘上 N² 得 Σ sᵢQᵢ² = 0；对整数恒有 Q² ≡ Q (mod 2)； 两式相接即 n = Σ sᵢQᵢ ≡ Σ sᵢQᵢ² ≡ 0。关键在 sᵢ = ±1 在模 2 下等于 1—— 所以结论对任意族数、任意符号分配、任意电荷都成立。右侧两列是两条不同代码路径的实测： 107 组构造族（q 的多重集配对）与 6336 组（直接遍历 Q 与符号）都全偶。

图 2　族数可行性：k=1、3 是代数上无解，不是整数性产物

纵轴为 log₁₀(1+解数)（否则 2044 会把其余压成一条线），柱上是真实解数。 k=1 与 k=3 的解数精确为 0，理由不是「q 不够大」而是 Σu = u₀ ∧ Σu² = u₀² ⇒ 2e₂ = 0： 一侧单项、另一侧多项时，至多一个 u 非零 ⇒ 退化解。K3 用四元组另测过一遍，同样全不相等。 零值用基线短横表示（高度为 0 的柱子看不见，会被几何体检判红）。

图 3　角动量禁戒：间距恒为 1，对任意零模数 Q

把两个角动量都写成零模数 Q = q_f·N 的函数：j_f = (Q−1)/2、j_H,min = |q_H|N/2 = Q （因 q_H = −2q_f）。于是 j_H,min − 2j_f = Q − (Q−1) = 1，恒等于 1， 与 Q、q_f、N 全部无关。来料只写了不等式 N > N−1，本卷把它收紧为等式。 B2 又用 (N,k) 参数化独立扫了 35 组，全为 1（G13 记两条路径独立）。

图 4　修复入口修错对象：3×3 质量矩阵在这个机制里不存在

来料第七节把「j_S=1 背景场 ⇒ 三代质量矩阵」定为下一轮主攻方向。 但本卷主定理说族数恒为偶数，最小非零是 n = 2q₊N = 2。偶数族的 Yukawa 矩阵是 2×2；要 3×3 就得先有 3 族，而 3 永远不可能出现。所以角动量禁戒解除与否 救不了三代 —— 修的是一个不存在的对象（B4，已登记判负）。

图 5　来料列的两条出路在本机制内都关闭

来料据此声称「这不是不可能性证明」。本卷逐条测过：额外场被模二定理关掉（图 1： 加多少 16 都不改奇偶）；Green–Schwarz 被 A3 关掉 —— GS 可分解性等价于 I₈ = 0 （5 组实测 5 组吻合），因为净 8 形式里 T²、p₁² 系数恒为 0 ⇒ 平方要求 β=γ=0， 而 x²T、x²p₁ 又非零 ⇒ 只能回到原矛盾。两条出路都不是独立出路（E1，已登记判负）。

图 6　CG 系数 1/√(2Q+1)：来料只报了最有利的那一点

来料给出 1/√7 ≈ 0.378（Q=3）。本卷把它推广成闭式：单因子 ⟨j,−j;1,1|j−1,−(j−1)⟩² = (2j−1)/(2j+1)，全链条（两费米子 → H⊗S → 总角动量 0） = 1/(2Q+1) ⇒ 系数 1/√(2Q+1) 随 Q 单调衰减。 Q=3 恰好是曲线上较高的点；Q 越大越救不回三代（这与「Q 越大越像三代」的直觉相反）。

一句话：ROOT V58 的「关键障碍」诊断对了（角动量禁戒确实存在，本卷还把它从不等式收紧成等式）， 但「修复入口」修错了对象 —— 该机制的族数谱是偶数集 {2,4,6,…}，三代 n=3 不在谱内， 3×3 质量矩阵无从谈起；两条备用出路（额外场、Green–Schwarz）也分别被模二定理与 I₈=0 等价性关闭。 供给 0，不占度，度数链维持 36。
