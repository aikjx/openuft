## 一、ufthub 是什么

`my_lib/ufthub/` 是「统一场论来料中枢」：一个按**文件格式**（md / html / zip）平铺存放的 AI 生成内容仓库，来源混杂（Doubao、miaoda-code、deepseek、「算法联盟最高权限」等），**未经体系化归属**。

它与 openuft 的关系：

| 层 | 位置 | 职责 |
|---|---|---|
| 原始来料 | `my_lib/ufthub/` | 按格式（md/html/zip）平铺，只登记不归属 |
| 主题分箱 | `openuft/90_历史归档/来源语料_ufthub_20260925/` | 按**主题域**重分为 11 箱，151 条目 / 1131 文件 / 34.39 MB；63 条目 / 2.67 GB 亿字级语料**只登记未写入**（留原处保「克隆即可校验」） |
| 正式体系 | `openuft/01_独立体系/` | 18 个本地模块（S01–S14、P01–P04），各自管理公设、推导、代码、证据 |

> 关键：ufthub 本身应保持「来料」定位，不要在其内部建体系目录。真正的整理发生在 openuft 的归档分箱与 `01_独立体系/`。

## 三、各理论家族核心主张与关键公式

### 3.1 空间光速螺旋 / 曲率-挠率-频率体系（最大主线，箱 03）

代表文件：`空间光速螺旋模型_正确表达式汇编.md`、`光速螺旋时空统一场论：全文总结+全维度理论分析+Python精算验证报告.md`、`曲率挠率与ω_c全维统一体系*.md`。

**公设（A1–A3）**
- A1（光速螺旋）：空间元沿圆柱螺旋运动，合速率恒为 `v_total = c`。
- A2（α 速度分配）：`α = v⊥ / c`（数值上 `α c = 2.188e6 m/s` 恰为玻尔电子速度——动机，非推导）。
- A3（如需连接质量，须显式引入）：`m = k_m · ω`，`k_m` 为带量纲耦合常数。

**核心恒等式**（Frenet 标准结果；文档自称 200 位 mpmath 精算机器零）
```
圆柱螺旋参数方程： x=r cos(ωt), y=r sin(ωt), z=h ωt
ds/dt = ω√(r²+h²) = c                              [m·s⁻¹]
v⊥=rω,  v∥=hω,  v⊥²+v∥² = c²
κ = rω²/c²,  τ = hω²/c²                          [m⁻¹]
κ² + τ² = ω²/c²                                   [严格恒等式]
```
**态度分层（重要）**：同一文档明确标注——`κ²+τ²=ω²/c²` 是**严格恒等式**；而 `G ≈ α²μ₀`、`Gε₀ ≈ α²/c²` 被标为**数值巧合 / 量纲破缺 / 应弃用**（量纲 `[Gε₀]=C²·kg⁻²` 与 `[α²/c²]=s²·m⁻²` 不同）。即其内部已有诚实自检。

**对应 openuft 体系**：S02 空间光速螺旋统一力、S12 空间光速螺旋统一体系、S01 螺旋三重奏 `κ²+τ²=(ω/v)²`（泛化版）。

## 五、内容质量与去重问题（整理时必须记录）

1. **海量重复 / 副本**：同一「统一场论全书」竟有 v1–v10 + 终稿 + 最新完整版 + 压缩包。归档 README 已确认 `miaoda-code-《超宇宙…》.md` 与 `2a6d51….md` **指纹完全相同**、`统一场论全书_最新完整版` 与 `v4` 完全相同。应去重后只保留版本序列。
2. **亿字级自动生成语料未进仓库**（合理）：`《超宇宙…》1.01亿字全知版.md`（242.8 MB）、`9d4aee….md`（242.8 MB）、两个 1.08 GB 包——只登记不写入，避免破坏克隆校验。
3. **物理主张成熟度参差**：少数文档（如「正确表达式汇编」）有诚实的「数值巧合 / 应弃用」分层；另一些（大典 / 全书）把公设当结论、体量巨大但可检验性低。
4. **红线一致**：openuft 的红线「目录完整 / 来源核对 / 代码可跑，都不表示任何统一场论成立」必须照搬到 ufthub 的整理说明中。
