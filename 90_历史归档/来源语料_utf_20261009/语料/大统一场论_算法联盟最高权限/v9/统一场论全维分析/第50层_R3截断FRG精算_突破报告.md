## 二、M1：R³截断FRG β函数推导

### R³截断作用量
```
S = ∫d⁴x√g [ (1/(16πG))(R - 2Λ) + a_R2 R² + a_R3 R³ ]
```

### 4个跑动耦合
| 耦合 | 定义 | 工程维度 |
|---|---|---|
| g | G k² (无量纲牛顿耦合) | +2 |
| λ | Λ/k² (无量纲宇宙常数) | -2 |
| g_R2 | a_R2 k² (无量纲R²耦合) | -2 |
| g_R3 | a_R3 k² (无量纲R³耦合) | -2 |

### β函数形式（FRG, Litim调节器, 含SM物质场）
```
β_g  = (2+η_N)g - (B_g/16π²)g²
β_λ  = -(2+η_N)λ + (B_λ/16π²)g
β_g2 = (-2+η_N)g2 + (B_g2/16π²)g·g2 + C_g2·g²
β_g3 = (-2+η_N)g3 + (B_g3/16π²)g·g3 + C_g3·g·g2 + D_g3·g³
```

### SM物质场计数
- N_S = 4（希格斯实分量）
- N_F = 24（外尔费米子 = 12 Dirac等价）
- N_V = 12（矢量玻色子：1光子+3弱+8胶子）
- 有效计数 N_eff = N_S + 2N_F + 4N_V = 100
