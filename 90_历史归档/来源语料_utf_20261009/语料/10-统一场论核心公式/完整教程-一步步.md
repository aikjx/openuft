# 第二章：几何基础

## 2.1 什么是维度？

维度是描述空间位置所需的独立坐标数量：

| 维度 | 坐标 | 几何对象 |
|------|------|----------|
| 0维 | (0) | 点 |
| 1维 | (x) | 线 |
| 2维 | (x, y) | 面 |
| 3维 | (x, y, z) | 体 |

## 2.2 曲线的参数化

一条曲线可以用参数方程表示：

$$r(t) = (x(t), y(t), z(t))$$

其中 `t` 是参数（通常是时间）。

## 2.3 切线向量

曲线在某点的切线向量是位置向量对参数的导数：

$$v(t) = \frac{dr}{dt} = (x'(t), y'(t), z'(t))$$

## 2.4 法线向量

曲线在某点的法线向量是切线向量对参数的导数：

$$a(t) = \frac{dv}{dt} = (x''(t), y''(t), z''(t))$$

# 第三章：三维圆柱螺旋线

## 3.1 螺旋线的定义

三维圆柱螺旋线是空间中最基本的曲线之一，具有以下特征：
- 在圆柱面上运动
- 同时做圆周运动和轴向运动
- 保持恒定的螺距

## 3.2 参数方程

三维圆柱螺旋线的参数方程为：

$$r(t) = (\rho\cos(\omega t), \rho\sin(\omega t), b\omega t)$$

其中：
- ρ：螺旋线半径（回转半径）
- ω：角速度
- b：轴向参数（螺距的1/(2π)）

## 3.3 示例计算

假设 ρ = 1, ω = 2π, b = 1：

```python
import numpy as np

rho = 1.0
omega = 2 * np.pi
b = 1.0

t = 0.5
x = rho * np.cos(omega * t)  # = cos(π) = -1
y = rho * np.sin(omega * t)  # = sin(π) = 0
z = b * omega * t            # = π ≈ 3.14
print(f"r(t=0.5) = ({x}, {y}, {z})")  # (-1, 0, 3.14)
```

## 3.4 切线向量计算

$$v(t) = \frac{dr}{dt} = (-\rho\omega\sin(\omega t), \rho\omega\cos(\omega t), b\omega)$$

```python
v_x = -rho * omega * np.sin(omega * t)
v_y = rho * omega * np.cos(omega * t)
v_z = b * omega
print(f"v(t=0.5) = ({v_x}, {v_y}, {v_z})")
```

## 3.5 法线向量计算

$$a(t) = \frac{dv}{dt} = (-\rho\omega^2\cos(\omega t), -\rho\omega^2\sin(\omega t), 0)$$

```python
a_x = -rho * omega**2 * np.cos(omega * t)
a_y = -rho * omega**2 * np.sin(omega * t)
a_z = 0.0
print(f"a(t=0.5) = ({a_x}, {a_y}, {a_z})")
```

# 第四章：曲率与挠率

## 4.1 曲率的定义

曲率描述曲线的弯曲程度，定义为：

$$\kappa = \frac{|v \times a|}{|v|^3}$$

其中 `×` 表示叉积。

## 4.2 挠率的定义

挠率描述曲线的扭转程度，定义为：

$$\tau = \frac{(v \times a) \cdot j}{|v \times a|^2}$$

其中 `j` 是加加速度向量，`·` 表示点积。

## 4.3 示例计算

```python
import numpy as np

rho = 1.0
omega = 2 * np.pi
b = 1.0
t = 0.0

v = np.array([-rho*omega*np.sin(omega*t), 
              rho*omega*np.cos(omega*t), 
              b*omega])
a = np.array([-rho*omega**2*np.cos(omega*t), 
              -rho*omega**2*np.sin(omega*t), 
              0.0])
j = np.array([rho*omega**3*np.sin(omega*t), 
              -rho*omega**3*np.cos(omega*t), 
              0.0])

v_mag = np.linalg.norm(v)
cross = np.cross(v, a)
cross_mag = np.linalg.norm(cross)

kappa = cross_mag / v_mag**3
tau = np.dot(cross, j) / cross_mag**2

print(f"kappa = {kappa:.6f}")
print(f"tau = {tau:.6f}")
```

## 4.4 几何公式

对于圆柱螺旋线，曲率和挠率可以简化为：

$$\kappa = \frac{\rho}{\rho^2 + b^2}, \quad \tau = \frac{b}{\rho^2 + b^2}$$

验证一下：

```python
rho = 1.0
b = 1.0
denom = rho**2 + b**2

kappa_geo = rho / denom
tau_geo = b / denom

print(f"kappa_geo = {kappa_geo:.6f}")
print(f"tau_geo = {tau_geo:.6f}")
```

# 第五章：精细结构常数

## 5.1 α的定义

精细结构常数α是物理学中最重要的无量纲常数：

$$\alpha = \frac{e^2}{4\pi\varepsilon_0 \hbar c} \approx \frac{1}{137.035999}$$

## 5.2 α的几何意义

α是曲率与挠率的比值：

$$\alpha = \frac{\kappa}{\tau} = \frac{\rho}{b}$$

验证：

```python
rho = 1.0
b = 1.0 / 137.035999  # 因为 α = rho/b ≈ 1/137

alpha_geo = rho / b
print(f"alpha_geo = {alpha_geo:.15f}")  # ≈ 1/137.035999
```

## 5.3 α的物理意义

α决定了电磁相互作用的强度：
- α ≈ 1/137：电磁力相对较弱
- α越小，电磁相互作用越弱

# 第六章：质量与电荷的几何起源

## 6.1 质量的几何起源

粒子质量由几何尺度决定：

$$m = \frac{\hbar}{c \rho}$$

其中 ρ 是粒子的康普顿半径。

示例——计算电子质量：

```python
hbar = 1.0545718176461565e-34
c = 299792458.0

rho_e = 3.861592679e-13  # 电子康普顿半径
m_e = hbar / (c * rho_e)
print(f"电子质量 = {m_e:.2e} kg")  # ≈ 9.11e-31 kg
```

## 6.2 电荷的几何起源

元电荷由曲率-挠率比值决定：

$$e = \sqrt{4\pi \alpha \varepsilon_0 \hbar c}$$

示例——计算元电荷：

```python
import math

alpha = 7.2973525693e-3
eps0 = 8.854187817e-12

e = math.sqrt(4 * math.pi * alpha * eps0 * hbar * c)
print(f"元电荷 = {e:.2e} C")  # ≈ 1.60e-19 C
```

# 第七章：物理常数的几何化

## 7.1 万有引力常数G

$$G = \frac{c^3 \rho^2}{\hbar}$$

其中 ρ 是普朗克长度。

```python
rho_pl = 1.616255e-35  # 普朗克长度
G = c**3 * rho_pl**2 / hbar
print(f"万有引力常数 G = {G:.2e} N·m²/kg²")  # ≈ 6.67e-11
```

## 7.2 真空介电常数ε₀

$$\varepsilon_0 = \frac{e^2}{4\pi \alpha \hbar c}$$

```python
e = 1.602176634e-19
eps0 = e**2 / (4 * math.pi * alpha * hbar * c)
print(f"真空介电常数 eps0 = {eps0:.2e} F/m")  # ≈ 8.85e-12
```

## 7.3 归一化恒律

$$\kappa^2 + \tau^2 = \frac{1}{\rho^2 + b^2}$$

```python
rho = 1.0
b = 1.0 / alpha

denom = rho**2 + b**2
kappa = rho / denom
tau = b / denom

sigma_calc = kappa**2 + tau**2
sigma_expected = 1 / denom

print(f"sigma_calc = {sigma_calc:.6f}")
print(f"sigma_expected = {sigma_expected:.6f}")
print(f"误差 = {abs(sigma_calc - sigma_expected):.2e}")
```

# 第八章：四大力的统一

## 8.1 电磁力

耦合常数：α ≈ 1/137

## 8.2 弱力

耦合常数：α_W ≈ α/(α²+1) ≈ α

```python
alpha_W = alpha / (alpha**2 + 1)
print(f"弱力耦合常数 alpha_W = {alpha_W:.15f}")
```

## 8.3 强力

耦合常数：α_S ≈ 1 + 1/α² ≈ 1/α²

```python
alpha_S = 1 + 1 / alpha**2
print(f"强力耦合常数 alpha_S = {alpha_S:.2e}")  # ≈ 1.88e+04
```

## 8.4 引力

耦合常数：α_G = Gm_p²/(ℏc)

```python
m_p = 1.67262192369e-27  # 质子质量
alpha_G = G * m_p**2 / (hbar * c)
print(f"引力耦合常数 alpha_G = {alpha_G:.2e}")  # ≈ 5.91e-39
```

## 8.5 耦合常数层级

```python
print(f"强力/电磁力 = {alpha_S / alpha:.2e}")    # ≈ 2.57e+06
print(f"电磁力/引力 = {alpha / alpha_G:.2e}")     # ≈ 1.24e+36
print(f"总跨越范围 = {math.log10(alpha_S/alpha_G):.1f} 个数量级")  # ≈ 42.5
```

# 第九章：时间维度与运动参数化

## 9.1 时间的几何意义

时间是空间螺旋运动的参数化：

$$t = \frac{\theta}{\omega} = \frac{s}{c}$$

其中 θ 是角度，s 是弧长。

## 9.2 螺旋运动参数

```python
rho = 3.861592679e-13  # 电子康普顿半径
b = rho / alpha        # 轴向参数

omega = c / math.sqrt(rho**2 + b**2)
v_z = c * b / math.sqrt(rho**2 + b**2)
v_perp = rho * omega

print(f"角速度 omega = {omega:.2e} rad/s")
print(f"轴向速度 v_z = {v_z:.2e} m/s")
print(f"横向速度 v_perp = {v_perp:.2e} m/s")
print(f"总速度 |v| = {math.sqrt(v_perp**2 + v_z**2):.2e}")  # ≈ c
```

## 9.3 螺旋周期

```python
T = 2 * math.pi / omega
delta_z = v_z * T
circum = 2 * math.pi * rho

print(f"周期 T = {T:.2e} s")
print(f"轴向前进 delta_z = {delta_z:.2e} m")
print(f"圆周周长 circum = {circum:.2e} m")
print(f"delta_z / circum = {delta_z / circum:.6f}")  # ≈ 1/alpha
```

# 第十章：量纲分析

## 10.1 基本量纲

| 量 | 符号 | SI单位 |
|----|------|--------|
| 长度 | [L] | m |
| 质量 | [M] | kg |
| 时间 | [T] | s |
| 电流 | [I] | A |

## 10.2 导出量纲

| 量 | 量纲表达式 | SI单位 |
|----|-----------|--------|
| 速度 | [L][T]⁻¹ | m/s |
| 加速度 | [L][T]⁻² | m/s² |
| 力 | [M][L][T]⁻² | N |
| 能量 | [M][L]²[T]⁻² | J |
| 曲率 | [L]⁻¹ | m⁻¹ |

## 10.3 量纲验证示例

验证质量公式 m = ℏ/(cρ)：
- ℏ：[M][L]²[T]⁻¹
- c：[L][T]⁻¹
- ρ：[L]
- cρ：[L]²[T]⁻¹
- m = ℏ/(cρ)：[M][L]²[T]⁻¹/[L]²[T]⁻¹ = [M] ✓

验证力公式 F = Gm₁m₂/r²：
- G：[L]³[M]⁻¹[T]⁻²
- m₁m₂：[M]²
- r²：[L]²
- F = Gm₁m₂/r²：[L]³[M]⁻¹[T]⁻² × [M]² / [L]² = [M][L][T]⁻² ✓

# 第十二章：升维算法

## 12.1 升维原理

升维是从低维度到高维度的数学映射，核心是保持α不变：

$$\alpha = \frac{\kappa}{\tau} = \frac{\rho}{b} = \text{跨维度不变量}$$

## 12.2 升维步骤

### 步骤1：从3维到4维

引入时间维度：

$$x_4 = ct, \quad t = \frac{s}{c}$$

### 步骤2：从4维到5维

引入信息维度：

$$x_5 = \int \alpha dt$$

### 步骤3：从5维到6维

引入能量维度：

$$x_6 = \int mc^2 dt$$

## 12.3 升维能量计算

$$E_{\text{升维}} = mc^2 \cdot \frac{D}{3} \cdot \frac{1}{\alpha}$$

```python
def calculate_ascension_energy(m, target_dimension):
    c = 299792458.0
    alpha = 7.2973525693e-3
    
    base_energy = m * c**2
    dimension_factor = target_dimension / 3
    information_factor = 1.0 / alpha
    
    return base_energy * dimension_factor * information_factor

# 计算1kg物质升维到5维所需能量
energy = calculate_ascension_energy(1.0, 5)
print(f"升维能量 = {energy:.2e} J")
```
