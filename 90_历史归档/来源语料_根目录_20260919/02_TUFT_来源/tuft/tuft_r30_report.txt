  [PASS] D1 强化（代入 Ω 闭式后为恒等式）  |  代入 ω=c√(κ²+τ²) 后残差化简为 0 ⇒ 该求导是约束的微分推论，不含独立物理信息

  (D2) 稳态孤子 ∇_μω = 0 ⇒ κ∇_μκ + τ∇_μτ = 0 ⇒ ∂_μ(κ²+τ²) = 0

  [PASS] D2 稳态条件成立（对任意 φ）  |  κ²+τ²=R² 恒定、∂_ν(κ²+τ²)=0 ⇒ ω = c·R = 常数；稳态条件与公理 A 相容

  [PASS] D3 代数自洽（纯代数层面）  |  联立消去本身无误：g = 2(1+τ/κ) ⇒ g−2 = 2τ/κ

  2. 新判定：稳态 + 螺旋约束 ⇒ κ,τ 常数 ⇒ β≡0（第二次独立推导）

  3. 新判定：κ = α/ρ_C , τ = √(1−α²)/ρ_C —— 显式闭式与第三次 β≡0
==============================================================================
  由 S12 严格几何（a = α·ρ_C, b = ρ_C√(1−α²)）代入 Frenet 闭式 κ=a/(a²+b²), τ=b/(a²+b²)：
      κ = α/ρ_C            τ = √(1−α²)/ρ_C
      检验 √(κ²+τ²) − 1/ρ_C = 0   （应为 0）
  [PASS] κ,τ 显式闭式自洽（公理 A 自动满足）  |  κ²+τ² = (α² + 1 − α²)/ρ_C² = 1/ρ_C² ⇒ 与公理 A 的 ω²/c² 相容，ω = c/ρ_C（康普顿频率）

  【电子数值】ρ_C = ħ/(m_e c) = 3.861593e-13 m
      κ_e = α/ρ_C            = 1.889726e+10 m⁻¹
      τ_e = √(1−α²)/ρ_C      = 2.589536e+12 m⁻¹
      κ_e/τ_e                = 7.2975468740e-03   (对照 tanθ = 7.2975468740e-03)
      √(κ_e²+τ_e²)·ρ_C       = 1.000000000000000    (应为 1)
  [PASS] 第三次得到 β≡0（显式闭式路径）  |  κ,τ 皆由 (m_e, α) 唯一锁定：κ=αm_ec/ħ、τ=√(1−α²)m_ec/ħ ⇒ 无残余 μ 自由度 ⇒ dκ/dμ=dτ/dμ=0 ⇒ β≡0

  4. 新判定（模块 A2）：Cartan 方程确定的 K 与守恒约束的相容性
==============================================================================
  R29 已证 F^ν := K^μ_{μλ}T^{λν} + K^ν_{μλ}T^{μλ}，且 K↦F^ν 满秩 4（一般 K 空间）。
  但 EC 中 K 不是自由的：Cartan 方程把挠率（⇒contortion）与自旋源代数绑定。
  取最一般假设『K 与轴张量 S 之间存在线性对应 K = W·S』（所有 EC 版本的共同点），
  其中 S 有 6 个独立分量、K 有 24 个 ⇒ W 为 24×6 随机矩阵，扫描其相容性。

  随机线性对应扫描：trials=300，F^ν ≠ 0 的比例 = 100.0%（‖F‖ 中位 4.794e+00）
  存在性检验：对给定 S，使 F≡0 的 K-系数构成 R^24 中的 20 维子空间（余维 4，非空）
  [FAIL] Cartan 确定 K 与守恒约束需精细调节  |  随机线性对应下 100.0% 不相容；虽解空间非空（dim=20），但属零测度 ⇒ TUFT 若同时要求『挠率来自物质』与『∇^(EC)·T=0』，必须额外给出这份 fine-tuning 机制
  [INFO] 新登记开放项 EC-CONSERVE-TUNE  |  Cartan(挠率↔自旋) 与协变守恒的相容需精细调节，TUFT 未提供该机制 ⇒ 第三个性结构缺口（与 Λ 不可辨识同源）

  5. 新判定（模块 B2）：Λ–ακ 破简并 —— 不可能 vs 可借用边界
==============================================================================
  R29 结论：破简并充要条件 = ≥2 个互异且数值已知的 κ_i。
  由 §3 闭式 κ_i = α·m_i c/ħ ⇒ 不同 κ_i ⇔ 不同质量锚 m_i。
  ⇒ 分两种情形（必须诚实区分）：

    情形 A【单一锚 m_e】：可用 κ 只有 1 个 ⇒ rank(J) = 1 < 2 ⇒ **不可能破简并**
  [FAIL] 情形 A：单锚下 Λ–ακ 破简并数学不可能  |  κ 由 (m_e, α) 唯一锁定（§3 闭式），单一 TUFT 粒子不提供第二个 κ ⇒ rank=1，Λ_eff = Λ − 8πG·ακ 永远不可分离
    情形 B【借用多个外部质量锚 ['9.109e-31', '1.673e-27', '1.884e-28']】：κ_i 互异 ⇒ rank(J) = 2 ⇒ 数学上可破简并
            但这要求输入多个外部粒子质量 —— 正是 O-SCALE『最小锚定定理』所说的外部锚定
  [BOUNDARY] 情形 B：可借用才破，等价于承认 [B] 级有效编码  |  与 OPEN-7 §4 同构（借用标准 RGE 才升 [A]）：破简并要以多个外部质量为输入，⇒ Λ 与 ακ 的分离不是 TUFT 第一性导出，而是借用 ⇒ 登记第四同源边界 **O-SCALE-BREAK**

  ⇒ 四条同源边界正式收敛为同一结构性事实：
     O-SCALE（尺度秩=1 须外部锚） / D3（K_sat 手写普朗克锚） /
