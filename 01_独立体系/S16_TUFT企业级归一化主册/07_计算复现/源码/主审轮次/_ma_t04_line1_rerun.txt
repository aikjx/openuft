[1] M1 深化审计
----------------------------------------------------------------------

[1.1] 经典世界为何 "天然确定"?
  经典场论 (TUFT 的本体层) 的态是 C-number 场构型 phi(x), 是时空点上取
  确定实数值 (或确定旋量/规范分量) 的函数. 其运动方程是非线性 Euler-
  Lagrange 双曲 PDE. 关键结构性事实:
    (a) 没有态空间的叠加原理.  若 phi1(x) 与 phi2(x) 都是解, 经典非线性
        PDE 一般不保证 a*phi1 + b*phi2 也是解 (线性叠加只在线性方程成立).
        => "phi = (phi1 + phi2)/sqrt2" 在经典层根本不是一个合法的候选态.
    (b) 给定类空 Cauchy 面上的场值 + 法向导数, 局部适定性给出唯一未来场
        构型 (在 TUFT 孤子/反射壁所依赖的正则性假设下). 无随机性, 无分支.
  => 在 TUFT 本体层, "一次测量交互后指针取某一确定值" 不是一个需要解释
     的现象, 而是框架的定义性结构: 场从来只有一个值, 从来没有两个值
     的线性组合待 "坍缩". 这就是 v8 所说 "经典世界天然确定".

[1.2] 为什么 "取消叠加" != "解释坍缩"?
  量子测量问题 (measurement problem) 的完整三件套是:
      M1 确定结果:   测量给出唯一结果;
      M2 Born 规则:  结果概率 = |<a|psi>|^2;
      M3 (幺正/线性): 态按 Schrödinger 方程线性幺正演化.
  M1 与 M3 在教科书 QM 表面上冲突: M3 把 "系统+仪器" 纠缠成
      |Psi> = a|up>|UP> + b|down>|DOWN>,
  而经验是指针只停在 |UP> 或只停在 |DOWN> (M1).  坍缩假设 (或退相干 /
  多世界 / Bohm) 是用来调和 M1 与 M3 的.

  TUFT 的做法是: 它的本体层根本没有 |Psi> 这种线性叠加态 (见 1.1a).
  于是它不是 "解释了 M1 与 M3 的冲突", 而是 "M3 这个前提在 TUFT 本体层
  不存在". 这在逻辑上是两回事:
      * 解释坍缩 = 在承认叠加 (M3) 的前提下, 说明叠加如何退化为单一结果;
      * 取消叠加 = 换一个没有叠加的本体, 于是问题消失.
  后者是把待解释项 (explanandum) 删掉, 不是把它解释掉. 这正是 v8 判
  M1 = PARTIAL 而非 PASS 的核心理由: TUFT 满足了 M1 的字面结论, 但没有
  提供从 "叠加经验" 到 "单一结果" 的机制桥梁.

[1.3] 经典场论框架下 "确定结果" 的确切含义 (操作化)
  在 TUFT 中, 一次 "测量" 必须被重述为: 经典场自由度之间的一次非线性耦合
  交互, 其中被称为 "指针/粗观测量" 的子集 (宏观孤子/反射壁的某个集体坐标)
  最终落入一个局域吸引子. "确定结果" 的可操作含义只有一句:
      给定初值, 指针集体坐标的终态是唯一的 (确定性动力系统).
  它不涉及概率幅, 不涉及本征态, 不涉及投影. 终态唯一 = M1 的全部内容.

[1.4] 与量子力学 "确定结果" 概念的逐项对比

  维度                    量子力学 (M1)                     TUFT 经典场 (M1)                 
  ----------------------------------------------------------------------------------
  态的载体                  Hilbert 空间矢量 |psi>            C-number 场构型 phi(x)           
  是否有叠加原理               有 (线性空间封闭)                    无 (非线性 PDE, 叠加非解)             
  测量前指针                 纠缠叠加 a|UP>+b|DOWN>            场只有一个确定值                      
  结果唯一性来源               需坍缩/退相干/分支选取, 有争议             定义性结构, 无需额外机制                 
  结果概率来源                Born 规则 |a|^2 / |b|^2         初始条件集合的统计 (见[3])              
  是否解释坍缩                坍缩本身即公设或待解释                   不适用: 无叠加可坍缩                   

  结论一句话: TUFT 的 M1 是 'vacuous/trivial satisfaction' (空满足) ——
  因为它从不拥有 M3 的叠加前提, 所以 M1 自动成立; 但这种成立不构成对
  量子坍缩现象的解释, 只构成对该现象的本体论拒认.

[2] 数值演示: 指针变量的确定性选择 (dphi/dt = phi - phi^3)
------------------------------------------------------------------------

模型设定: 把 TUFT 测量边界的 "指针集体坐标" 理想化双稳, 两个吸引子
phi = +1 / -1, 分离线 phi = 0.  初值 phi(0) = eps (量级 1e-6 ~ 1e-2),
代表 "系统+仪器" 交互后指针被推到分离线附近的微小偏移.

[2.1] 决策时间 t* (phi 首次到达 |phi|=0.9 的时间; 解析小 eps 近似):
          |phi0|=eps    t*=ln(target/eps)        数值终态(RK4)      落入阱
       1.0e-02               5.3302         1.000000/-1.000000    +/     -
       1.0e-03               7.6328         1.000000/-1.000000    +/     -
       1.0e-04               9.9353         1.000000/-1.000000    +/     -
       1.0e-05              12.2379         1.000000/-1.000000    +/     -
       1.0e-06              14.5405         0.999998/-0.999998    +/     -
       1.0e-07              16.8431         0.999788/-0.999788    +/     -

  读数:
    (i) 终态符号 = sign(phi0), 与解析一致 (RK4 背书);
    (ii) t* ~ ln(1/eps): 偏移越接近平衡, 指针在分离线附近犹豫越久,
         但一旦决定就锁死在一个阱. 这就是经典层 '确定结果' 的微观像:
         每一次运行都给唯一结果 (M1 字面满足), 无叠加, 无坍缩.
    (iii) 关键: 哪一阱由 eps 的符号决定. eps 是外部/初始扰动, 不是
          量子振幅. 经典层本身不提供 eps 的概率分布.

[3] 盆地分数 vs Born 规则: 为什么 M1 的满足不自动带来 M2
------------------------------------------------------------------------

若把多次测量看作初始扰动 phi(0) 的一个集合分布, 则经典确定性动力给出
落入 +1 阱的分数:
    f(+) = P(phi0 > 0) = 0.5 [1 + erf(mu / (sqrt2 sigma))]
其中 (mu, sigma) 是该集合分布的均值与宽度.  注意:
  - f(+) 完全由外部给定的集合分布 (mu, sigma) 决定;
  - 经典方程 dphi/dt = phi - phi^3 本身不含任何参数去锁定 (mu, sigma);
  - 要它碰巧等于 Born 概率 |alpha|^2, 必须人为调 mu.

[3.1] 反向微调: 为得到 Born 概率 p=|alpha|^2, 需要的 mu/sigma:
          目标 p=|alpha|^2      需要 mu/sigma                             解读
              0.50          -0.0000                        对称(无需偏)
              0.60           0.2533                          需外部偏移
              0.70           0.5244                          需外部偏移
              0.80           0.8416                          需外部偏移
              0.90           1.2816                          需外部偏移
              0.95           1.6449                          需外部偏移
              0.99           2.3263                          需外部偏移

[3.2] 正算复核 (sigma=1, mu 取上表值, f(+) 是否回到 p):
      p=0.50 -> mu=-0.0000 -> f(+)=0.500000  (误差 0.00e+00)
      p=0.70 -> mu=+0.5244 -> f(+)=0.700000  (误差 0.00e+00)
      p=0.90 -> mu=+1.2816 -> f(+)=0.900000  (误差 1.11e-16)

  读数与审计裁决:
    (a) 经典双稳系统确实能给出 '唯一结果' (M1), 也确实能通过调节
        外部集合偏置 mu 拟合出任意 0~1 的频率 f(+).
    (b) 但 mu 是手放的: 它不来自 dphi/dt=phi-phi^3, 不来自 TUFT 本体,
        也不来自任何量子振幅. 用一个手放参数去凑 |alpha|^2, 是微调
        (fine-tuning), 不是推导.
    (c) 因此: M1 的确定性满足 与 M2 的 Born 概率导出, 是两件独立的事.
        取消叠加 (M3 前提) 让 M1 自动成立, 但对 M2 毫无帮助. 这从数值上
        坐实了 v8 '取消叠加 != 解释坍缩' 的判词: 连概率从哪来都还没着落.

------------------------------------------------------------------------
[4] 边界分析: TUFT 纯经典场论框架下 M1 满足到什么程度
------------------------------------------------------------------------

[4.1] 满足到什么程度?
  在 TUFT 本体层 (纯经典场/孤子), M1 的字面陈述 "测量给出唯一确定结果"
  是结构性成立的: 见 [1.1] 叠加原理缺失 + Cauchy 唯一演化; 见 [2] 数值上
  指针每次锁死单一吸引子. 这一部分不是猜测, 是经典 PDE 适定性 + 双稳
  动力学的直接推论.  => M1 的 "唯一结果" 维度: 满足.

[4.2] 剩余缺口 (PARTIAL 的 "不" 那一半)
  缺口 1 (解释缺口): TUFT 没有, 也不声称有, 从 "量子叠加经验" 到 "经典
        单一结果" 的导出链. 它只是换了本体. 经验世界里我们看到干涉条纹
        (叠加确实在某处生效), TUFT 必须先把干涉 reproduce 出来, 才谈得
        上解释它如何退成单一结果. 这一步 v8 E333-E336 已判定未做.
  缺口 2 (概率缺口): 见 [3]. 结果的频率分布必须等于 |alpha|^2, 而经典
        双稳的频率由手放集合偏置 mu 决定, 无任何内在机制锁定 mu =
        sqrt2 sigma erf^{-1}(2|alpha|^2 - 1). M2 未证.
  缺口 3 (边界划界缺口): TUFT 没有形式化 "哪里算经典指针, 哪里算量子系统"
        的分界. 既然本体全是经典场, "测量边界" 本身是一个粗粒化/涌现
        概念, 需要一条边界公设来定义粗观测量与退相干标度. 该公设目前
        不在主册中.

[4.3] 是否需要边界公设?
  判定: 需要. 且它不是可选润色, 是 M1 从 "空满足" 升级为 "有效理论陈述"
  的前提. 最小边界公设应至少回答三件事:
      P-B1: 在 TUFT 场上, 哪个集体坐标被粗粒化为 "指针/观测仪器"?
      P-B2: 量子振幅 (干涉) 如何从纯经典场的线性/非线性波中涌现?
            (即 TUFT 对 M3 的对应物是什么)
      P-B3: 结果频率为何是 |alpha|^2?  (对 M2 的对应物)
  在 P-B1/P-B2/P-B3 登记之前, TUFT 说 "测量有确定结果" 与 QM 说 "测量有
  确定结果" 只是同形异义字 (homonym), 不能互相对接.

========================================================================
[5] 四态分级 (M1 在 TUFT 框架下的状态)
========================================================================

【严格定理】
  - 经典非线性场论无叠加原理: 一般 phi1, phi2 的线性组合不再是解
    (线性性仅对线性 PDE 成立). => TUFT 本体层无「叠加态」可坍缩.
  - 双曲 PDE 局部适定性: 给定 Cauchy 数据, 未来场构型唯一.
    => 单次指针交互终态唯一 (M1 的「唯一结果」维度).
  - 双稳序参量符号律: 终态 sign = sign(phi0), t* ~ ln(1/eps)
    (解析 + RK4 数值背书, 见 [2]).

【条件定理】
  - 指针变量须能被理想化为双稳 (或多稳) 吸引子系统, 上述符号律才适用;
    该理想化依赖 P-B1 (指针坐标定义), 属条件成立.
  - 盆地分数 f(+) = 0.5[1+erf(mu/(sqrt2 sigma))] 只在 小 eps、终态符号
    由初值符号决定 的双稳近似下成立; 强非线性/噪声情形需重算.

【定义识别】
  - TUFT 的「确定结果」(= 经典指针集体坐标终态唯一) 与 QM 的「确定结果」
    (= 叠加态投影到某一本征态) 是两个不同范畴的定义, 不是同一个命题.
    二者共享「唯一结果」字面, 但前者无叠加前提, 后者以叠加为前提.
  -「测量」在 TUFT 中 = 经典场非线性耦合交互; 在 QM 中 = 投影公设.
    这是定义选择, 不是可证伪定理.

【开放命题】
  - TUFT 能否从纯经典场 reproduce 量子干涉/双缝现象 (M3 对应物): 未证.
  - 结果频率为何 = |alpha|^2 (M2): [3] 显示需手放集合偏置 mu, 无内在
    推导; 在 P-B3 登记前保持开放, 禁止伪闭合为「TUFT 导出 Born 规则」.
  - 测量边界公设 P-B1/P-B2/P-B3 是否存在、形式如何: 未在主册登记.
  - v8 E333-E336 判定的 M1/M2/M3 整体 OPEN 状态, 本轮只把 M1 钉到
   「唯一结果维度严格成立 / 解释与概率维度开放」, 不改变整体 OPEN.
