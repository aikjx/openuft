# 空间光速螺旋曲率挠率几何统一场论

编号：`s15_light_speed_helix_ct_uft`；类型：`candidate_theory`。

## 与兄弟体系的边界

本体系与 [S12 空间光速螺旋统一体系](../S12_空间光速螺旋统一体系/README.md) 同母题（v≡c 空间光速螺旋），但扩展为「曲率-挠率尺度分层」并把分支推进到全物理领域（相对论、量子、电磁、标准模型、宇宙学、热力学、量子引力等）。本仓库按原始主张独立登记，不沿用来源自封的「算法联盟 ROOT 最高权限」认证。

声明的关系（借用，非已证明的逻辑依赖，不转移证据等级）：

- [S01 螺旋三重奏与谱几何](../S01_螺旋三重奏与谱几何/README.md)：借用曲率/挠率螺旋数学；数学恒等式不能认证本体系本体公设。
- [S02 空间光速螺旋统一力](../S02_空间光速螺旋统一力/README.md)：借用统一力方程 P=m(c−v)、F=dP/dt 的动力学形式（见 C0006 循环自证标注）。
- [S10 频率本源与复螺旋宇宙](../S10_频率本源与复螺旋宇宙/README.md)：共用 κ、τ 几何骨架，但本体系以 v≡c 恒等、S10 以 v≤c 上限，互不认证。
- [S14 挠率统一场论 TUFT](../S14_挠率统一场论TUFT/README.md)：同属「光速螺旋形变 + 曲率/挠率」路线，但 S14 以挠率张量多分量内禀代数承载规范群，本体系以 κ/τ 比承载常数；两体系独立审查。

## 诚实评级口径（必读）

来源文本大量使用「全域零误差」「万物统一」「算法联盟 ROOT 最高权限 ✅ 全部通过」等绝对化断言。本仓库按 openuft 统一口径，将每条核心公式登记为带 `evidence_level` 的 claim：

- `H`：数学恒等式/定义层结果（如 κ²+τ²=ω²/c²），属代数自洽。
- `O`：诚实边界——几何重述成立但未给出独立于现有物理的新预言（如 α=κ/τ 作为「拓扑不变量」、统一场方程作为几何重写）。
- `C`：冲突/缺陷——循环自证（用 CODATA 常数反算自身）、版本矛盾（G 至少 5 种互不等价写法且其一量纲非法）、或与实验冲突的预测。
- `U`：未展开方向。

详见 [claims.csv](claims.csv) 与 [11_证伪与反例](11_证伪与反例/README.md)。
