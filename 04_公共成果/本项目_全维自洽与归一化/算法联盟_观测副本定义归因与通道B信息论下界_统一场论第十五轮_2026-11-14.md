## 一、结论先行

本轮做两件事，都不造新物理、不放宽判据：

1. **口径修正**：此前第九、十一、十二轮把「与实验锚逐位相等的字面量」一律记为观测副本。本轮按来料 `kind` 四分归因后发现，其中 **`318` bit 是 SI 定义公理复用**（c、h、e），不是观测搬运。真实观测比特应从 `935` 修正为 **`617` bit**（占 `65.989%`）。
2. **结论不推翻**：修正后实测唯一副本仍有 **`10` 个**（measured `9` + measured-bound `1`）、`617` bit > 0 ⇒「零自由参数靠把观测搬进源码」**依然成立**，只是读数被钉死到诚实值。

在此基础上给出本轮的主结论：

> **硬出口通道 B 在 46 项锚上信息论不可满足。**
> 「程序侧不含观测副本（0 bit）」与「输出与 46 锚相容」不能同时成立：按最宽口径，相容至少需要 **`217.887` bit** 观测信息。

## 二、副本三分归因：`935` bit 里有多少是观测

方法：把第九轮登记的 `13` 个唯一副本值逐一用精确 `Fraction` 匹配回 46 项锚，取该锚的 `kind`，再按 `bits(q)=bit_length(|分子|)+bit_length(分母)` 累加。

| --- | --- | --- |
| SI-definition | 3 | 318 |
| derived | 0 | 0 |
| measured | 9 | 501 |
| measured-bound | 1 | 116 |

`13` 个唯一副本、`24` 次出现、合计 `935` bit；出现次数与描述长度两路与第九轮逐位相等（见第九节）。逐行明细：

- **SI 定义 `318` bit**：`c`（299792458）、`h`、`e` 三个 2019 SI 定义值。它们是**公理**，任何程序都可以合法携带，不构成「抄观测」。

- 修正方向是**下调** `935 − 617 = 318` bit，不是上调。

## 三、σ=0 不等于定义值：一个必须钉住的口径陷阱

19 项 σ=0 的锚里，只有 3 项是 SI 定义、1 项是派生：

| kind | 项数 | 全精度 bit |
| --- | --- | --- |
| SI-definition | 3 | 318 |
| derived | 1 | 173 |
| measured | 13 | 772 |
| measured-bound | 2 | 126 |

★其中 **`15` 项 kind 是 measured / measured-bound 却 σ=0**（如 `P14 a_mu`、`K08 Omega_Lambda`、`K09 age_universe`）。这说明「σ=0」的语义是**误差未登记**，不是「精确值」也不是「定义值」。

因此**不能**拿 σ=0 当公理白名单：若那样做，会把 772 + 126 bit 的实测信息误判为公理，下界被人为清零。本轮显式机读钉住这条口径。

---

## 四、通道 B 的信息论下界：三种口径同向

相容只要求理论值落在 `[O − zσ, O + zσ]`（`z = 1.959963984539`），不要求逐位等于 O。因此「必须携带的信息」不是 O 的全部精度，而是**指定落在哪个窗口**所需的比特：

`window_bits = log2( |O| / (2 z σ) )`，取正部。

`27` 项双侧锚的窗口比特合计 **`246.869` bit**（measured `217.887` + derived `28.981`）。

三种口径（对同一对象的三层放宽，**不相加、不互相替代**）：

| 口径 | 含义 | 下界 |
| --- | --- | --- |
| 严 | 要求逐位精确等于锚 | `1523` bit |
| 窗口 | σ=0 的实测类按全精度、σ>0 按窗口 | `1115.887` bit |
| 最宽 | 把 19 个 σ=0 项**一律**当公理，只留 σ>0 窗口 | `217.887` bit |

三口径单调 `217.887 ≤ 1115.887 ≤ 1523` 且**全为正**。即使采用最不讲理的最宽口径，仍须 `217.887` bit ⇒ **下界不是口径造成的**。

**0 bit 即可相容的双侧锚：`0` 个。** 全部 `27` 项的窗口都比锚本身窄，必须携带信息才能落进窗口。

## 五、最小代价反演：要 0 bit 相容得把误差棒放多宽

对每个 σ>0 的锚，`factor = |O| / (2 z σ)`，把 σ 放大 `factor` 倍即可让窗口比特归零。

| 读数 | 值 |
| --- | --- |
| 最小代价锚 | `G04`（GW150914_radiated），只需放宽 `1.531` 倍 |
| 最大代价锚 | `C06`（alpha_inv），须放宽 `1664705020.554` 倍 |
| 代价谱 | ≤2 倍 `1` 项 / 2~10 倍 `3` 项 / >10 倍 `23` 项 |

含义：只有 `1` 项误差棒再放宽不到 2 倍就能 0 bit 相容；`23` 项要放宽一个数量级以上——那等于让误差棒失去意义。要把 `27` 项全部 0 bit 相容，须统一放大到 `1664705020.554` 倍。

> 要么给出**误差棒宽到窗口比特为 0** 的新读数（见第五节代价谱），

二者缺一，通道不通。本册未给出任何一个。

## 八、三重认证门与反噬

本轮三门是**认证门**（归因正确 / 下界成立 / 不可满足），不是误放行计数门：本轮无候选配置可被误放行（误放行 `0` 个），门的承重体现在守卫链上。这是与第十四轮「最小承重割 2」不同形态的如实声明，**不重复其结论**。

三次反噬每次只动一个判据，分别拆 `GATE_ATTRIBUTION_ACTIVE` / `GATE_LOWERBOUND_ACTIVE` / `GATE_INFEASIBLE_ACTIVE`：三次各自击中对应的 `GATE-*-BEARING` 守卫，`final` 均变 `GATES-FAIL`，四次读数两两不同。

反事实控制组（每组两读数不同，同口径）：

- **归因**：把 SI 定义算回观测，观测比特从 `617` 涨到 `935`。
- **窗口**：σ 统一放大 2 倍，窗口比特精确减少 `27` bit（每项恰减 1），机制自洽。
- **定义**：把 σ=0 的 19 项全当公理，下界从 `1115.887` 降到 `217.887`，**仍是正数**。

阴性对照（扫描 0 个锚时四项读数恒 0）单列 `IDENTITY` 配 `NOT-ALL-GREEN`；正对照（描述长度 `935`、观测 `617`、窗口 `246.869`、实测副本 `10` 均非零）说明判据不是恒绿空表。

## 九、两路与三路机拼

- **副本两路**：`act` 用 `json.load` 读第九轮登记的 `13` 个唯一分数；`exp` 独立把理论脚本源码 `tokenize` 后与 46 锚精确匹配，得同一集合、同一出现次数 `24`。
- **描述长度两路**：独立复算 13 个唯一值 bit 之和 `935`，与第九轮 `H_copied_unique_bits` 逐位相等。
- **归因第三路**：核验器另起一遍，直接从第九轮 JSON 与来料表重算 `SI 318 / measured 501 / measured-bound 116`，与机核结果一致。
- **★取数陷阱**：AST 给的是**二进制 float**，`Fraction(6.62607015e-34)` 与锚的十进制文本不等，只有整数型才能对上（首跑只剩 2 个副本）。必须走 `tokenize` 的原始十进制文本——这是本轮真实发生的实现事故，见第十一节。

## 十、边界与红线

- 结论限于 `openuft` 既有 `46` 项锚与**单个理论脚本**的输出字面量；**不是关于全人类实验数据或任意理论程序的定理**，也不覆盖尚未写出的方程族。
- 比特数是**固定编码**（分子/分母二进制位数之和）下的描述长度上界，**不是 Kolmogorov 复杂度**；换编码会改变绝对值，但观测/定义的拆分比例与三口径同向不变。
- 数学自洽 ≠ 实验证实；全部结论来自两路机读、精确 `Fraction` 匹配与 `Decimal` 窗口计算，不是实验证实，不产新物理。
- 四力大统一正确方程 `0` 条、独立实验预言 `0`；**不宣称攻破统一场论，不宣称攻破力的统一**。
- 本册**修正**了第九轮的一个口径读数（`935` → `617` bit），但**没有**推翻任何物理结论，也没有放宽任何判据。

## 十一、实现事故与纪律留档

1. **AST float ≠ 十进制字面量**：`exp` 路径初版用 `Fraction(ast_float)`，`6.62607015e-34` 的二进制近似与锚不相等，13 个副本只匹配到 2 个（`299792458`、`3`）。改为 `tokenize` 取原始文本后恢复 13 个。**这是「字面量按 AST 实际形态机读」的镜像陷阱：AST 形态是二进制，语义形态是十进制。**
2. **占比用 Decimal 除法不精确**：`617/935 + 318/935` 在 60 位十进制下不逐位等于 1。改精确 `Fraction`，守卫断言 `OBS_SHARE + SI_SHARE == 1`。
3. **JSON 序列化撞 Decimal**：`WINDOW_ROWS` 的内部 `b`、`COST_ROWS` 的内部 `f` 被直接序列化。改为输出时剔除内部十进制字段，只留 `dstr` 串。
4. **链接体检口径**：来料总表是 json 但无配套 report，`n_json == n_txt` 断言错误。改为 `n_json == n_report + 1`，并在 note 里写明这是预期结构。
5. **多目录并存**：并行会话新增了两个同形 `04_*/…/源码` 目录，`glob` 命中 3 个。改用唯一既有产物反查主目录，避免误写他人目录。
6. **舍入串不能当精确值**：核验器初版拿 `F(K["bound_window"])` 与精确 `Decimal` 比较，3 位舍入造成假 FAIL。改为同一 `dstr` 口径比较，或回到机核内精确值验分解。
7. `add()` 由 `ok` 驱动 `kind`；`NO-HARDCODE-OK` 用 AST 扫布尔字面量，命中 0；`final_of` 守卫 FAIL 挡门、缺 `n_decl` 报 `GATES-FAIL`。
