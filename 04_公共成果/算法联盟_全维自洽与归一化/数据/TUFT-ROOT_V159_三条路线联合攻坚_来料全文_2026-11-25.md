## 一、总命题

三种不同数学方法直接检验基本原理：

\boxed{ \text{光速螺旋发散} +\text{平行平衡} +\text{垂直原理} \overset{?}{\Longrightarrow} \text{全部相互作用} }

## 二、第一种方法：从光速约束直接求导

定义基础运动的四维相位梯度：

\( k_\mu=\nabla_\mu\theta \)

光速条件：

\( k^\mu k_\mu=0 \)

对条件求导，利用无挠率联络下标量二阶导数的对称性：

\( k^\nu\nabla_\nu k_\mu = k^\nu\nabla_\mu k_\nu = \frac12\nabla_\mu(k^\nu k_\nu) = 0 \)

得到：

\boxed{ k^\nu\nabla_\nu k^\mu=0 }

含义：在光滑的单相位零间隔模型中，运动必须沿仿射参数化的零测地线进行。

进一步：

\( \nabla_\mu k_\nu-\nabla_\nu k_\mu=0 \)

相应光线束的光学扭转为零。

**第一项严格结论**：如果空间是平直的，单独的光速相位梯度不能自动形成弯曲的螺旋轨迹。要保留螺旋思想，就需要引入多个运动场、独立旋转自由度或者真实的时空曲率。这是确定产生螺旋的必要动力学条件，不是否定螺旋几何。

## 三、第二种方法：多股光速运动、垂直平衡与应力分析

不再限制只有一个运动方向，允许空间中存在任意数量的光速运动场：

\boxed{ T^{\mu\nu}=\sum_{a=1}^{N}\rho_a k_a^\mu k_a^\nu }

其中 \( k_a^\mu=(1,\mathbf n_a),\ |\mathbf n_a|=1 \)。

六个运动方向：\( +\mathbf e_x,-\mathbf e_x,+\mathbf e_y,-\mathbf e_y,+\mathbf e_z,-\mathbf e_z \)，每个方向能量密度相同，则：

\boxed{ T^{\mu\nu}=\mathrm{diag}(\rho,\rho/3,\rho/3,\rho/3) }

即使六个方向完全平衡、总动量为零，内部仍具有三个垂直方向的压力 \( p_x=p_y=p_z=\rho/3 \)。

**第二项严格结论**：平行、反向、垂直运动能够形成非零的不变质量和内部应力，但不能仅凭运动方向平衡形成稳定物质，必须进一步产生向内的束缚作用。

## 四、第三种方法：让光速运动通过自身引力形成闭环

不再预先指定向心力，引入完整 GR 自引力薄壳模型。光速运动沿球形薄壳切向传播并各向同性平均，表面压力 \( p=\sigma/2 \)，\( \sigma \) 为表面能量密度。

能量守恒 \( dm+p\,d(4\pi R^2)=0 \) 给：

\boxed{ m(R)=A/R }

Israel 连接条件给总引力质量：

\boxed{ M=\frac{A}{R}\sqrt{1+\dot R^2}-\frac{GA^2}{2R^3} }

静止条件 \( \dot R=0 \)：\( M=A/R-GA^2/(2R^3) \)。一次求导：

\( dM/dR=-A/R^2+3GA^2/(2R^4)=0 \Rightarrow R_*^2=3GA/2 \)

联立得到：

\boxed{ R_*=\frac94 GM }

二次求导：

\boxed{ M''(R_*)=-2A/R_*^3<0 }

平衡为能量极大值。微扰方程：

\boxed{ d^2\delta R/d\tau^2=(2/R_*^2)\,\delta R }

存在指数增长模式：向外压力与自身引力可暂时平衡，但最简薄壳中不稳定。
