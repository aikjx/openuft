# ROOT V145｜从螺旋闭环到拓扑磁通、内部零模、手征性和量子异常

版本：2026-11-24。理论约定仅设 c=1；G、ℏ 独立保留量纲。本文是研究审计，不是统一场论证明。全部数值结果来自现有磁通紧化模型的可复现计算。

## 0. 假设与结论边界

【已确立的数学机制】第一 Chern 数量子化；磁单极子的两个规范局部片；S² 上带背景磁通的扭曲 Dirac 算子及其指数；规范反常抵消的必要性。

【额外模型假设】物理时空取 M4 × S²；内部球面有背景 U(1) 规范联络；有特定的六维费米子手征性；S² 半径 R 固定；n 取 3；如果使用 U(1)_F，需引入家族场。

【未成立】内部空间由光速螺旋独立生成；背景磁通由运动方程自动产生；R 和 n 从无自由参数原理推出；粒子真实质量和耦合；标准模型完整规范群；引力和三种规范力获得共同微观起源。

## 1. 基本几何

六维流形 M6=M4×S²，二维部分取

ds²_int=R²(dθ²+sin²θ dφ²).

注意：内部球面是额外几何自由度，不等同于 3D Frenet–Serret 标架，也不等同于粒子真实轨迹。内部坐标 φ 的闭环与 n 的拓扑量子化之间是模型构造上的联系，而非已经确认的微观实在。

## 2. 两局部片的规范联络及 Chern 数

在北片和南片分别取 A_N=(n/2)(1−cosθ)dφ、A_S=−(n/2)(1+cosθ)dφ。二者在重叠处相差 n dφ=d(nφ)。对于单位电荷，过渡函数 exp(i n φ) 在 φ→φ+2π 后单值需 n∈Z。

局部曲率相同：

F=dA=(n/2)sinθ dθ∧dφ。

因此

(1/2π)∫_{S²}F=(1/2π)(n/2)(∫_0^{2π}dφ)(∫_0^π sinθ dθ)=n。

测试：通过数值 Simpson 积分独立求 ∫F 与 2πn 的误差（见 results/flux_scan.csv）。这个结论不代表物理世界存在该磁单极子。

## 3. 内部 Dirac 指标与零模

将带单位归一化整数荷 q 的六维费米子耦合到局部联络。内部分块的二维 Dirac 算子为

D_int=i γ^a e_a^m(∂_m+spin connection_m+i q A_m)。

指标（左右号由取向约定确定）

index(D_int)=N_+−N_−=(q/2π)∫_{S²}F=q n。

其中 n 整数、q 按最小电荷量单位做整数归一化。在标准球面对称磁通背景中，全部 |qn| 个零模具有相同的内禀手征性（此结论比指标只给差值更强）。

数学的第二条计数路线：S²≅CP¹，复线丛 L_n=O(n)，正手征内自旋丛 K^(1/2)=O(-1)。因此 ker D_+≅H⁰(CP¹,O(n−1))。当 n>0，基可写为 {1,z,...,z^(n−1)}，维数 n。负 n 情形手征性反向；n=0 没有零模。

在复坐标 z=r exp(iφ) 下，用线丛自然度规，z^k 的正定范数为

||z^k||²=4πR² B(k+1,n−k)=4πR² k!(n−1−k)!/n!，k=0,...,n−1。

该 Beta 积分与直接数值积分是独立交叉检查。n=3 时三个基态的 norm/(4πR²) 为 1/3、1/6、1/3，均有限。

关于四维手征性的关键限定：单个六维 Weyl 费米子与内部指数组合，可在适当约定下产生净四维 Weyl 手征性；完整六维 Dirac 费米子包含两个六维手征分量，通常给出四维左、右成对的 vectorlike 零模。本工程显式测试二者差别。

## 4. 完整的内部 Dirac 激发谱

在该标准球面对称磁通背景，记 m=q n、k=1,2,...；非零本征值成对出现：

λ_(k,±)=±sqrt[k(k+|m|)]/R。

每个正号或负号本征值的简并度 d_k=|m|+2k。k=0 时只有 |m| 个零模；当 m=0 时不存在零模（不能把 k=0 的 d=0 当作粒子）。

使用 c=1，谱生成的质量尺度 m_k=ℏ |λ_k|。若要以 SI 的 GeV 表示能量，必须明确恢复 SI 的光速 c_SI：E_k=ℏ_SI c_SI |λ_k|，同时保留 G 独立。代码的 units.py 仅在输出转换时使用 c_SI，不是在理论中把 c 与 ℏ 同时设为 1。

示意案例：n=3，q=1，R=10^(-18) m；k=1 对应 sqrt(4)/R=2/R，E1≈394.65396 GeV。R 由人为给定，不能宣称新粒子质量预测；若 R 取更大或更小，能量按 1/R 改变。无需引用 G 的测量值即可完成这一纯几何谱计算。

## 5. 单一超荷磁通方案的可证伪障碍

如果唯一背景 U(1) 同时就是标准模型的超荷 U(1)_Y，统一采用整数荷 Q̃=6Y。对一代中五种左手表示，Q̃ 依次为：

Q_L: +1; u_L^c: −4; d_L^c: +2; L_L: −3; e_L^c:+6。

由 index=q n，若 n=3，指标依次为 +3,−12,+6,−9,+18。不同表示的模态数无法自动都等于三。更换各高维场的六维手征符号可以改变四维手征符号，却不能消去这些绝对值差异。

这是对【单一磁通 + 所有物质仅按自身超荷耦合 + 无额外投影/耦合】的严格限制；不排除多个背景磁通、非阿贝尔内部场、局域化、orbifold、或与超荷分开的家族 U(1)_F。若使用额外 U(1)_F 且所有物质内部荷相同，取 n=3 就可让每类都得到三零模，但这并没有解释为什么应选 n=3，也带来新的规范场/反常问题。

## 6. 四维规范异常不可忽视

孤立单个电荷为 +1 的六维 Weyl 场在 n=3 下若得到 3 个四维左手荷 +1 Weyl 粒子，则四维 U(1)^3 三角异常的相对系数为 3×1³=3、U(1)-引力混合异常为 3×1=3，均不为零。拓扑零模形成并不保证量子一致性；需要补充异常抵消机制或其他场。

标准模型【一代】以全左手 Weyl 约定的表示：

Q_L:3×2, Y=1/6;
 u_L^c:3×1,Y=−2/3;
 d_L^c:3×1,Y=+1/3;
 L_L:1×2,Y=−1/2;
 e_L^c:1×1,Y=+1。

其条件：

A_[Y³]=6(1/6)³+3(−2/3)³+3(1/3)³+2(−1/2)³+(1)³=0；
A_[grav²Y]=6/6−3×2/3+3/3−2/2+1=0；
A_[SU(2)²Y]∝3/6−1/2=0；
A_[SU(3)²Y]∝2/6−2/3+1/3=0；
SU(2) 左手双重态数是 3+1=4 (偶数)，满足 Witten 全局异常的必要检查。

这些只是在标准模型既有粒子谱中验证已知抵消性质；并没有从 ROOT 动力学中推导出该谱。此外，六维自身的规范、引力和混合异常需要单独检查，本工程没有完成六维完整异常多项式或其消除机制。

## 7. 对光速螺旋和三方向垂直原理的结果

此前 V138–V142 的重要限制仍然成立：三维螺旋 Frenet–Serret 几何只是运动学；其三个正交方向并不足以独立产生标准模型的 12 个规范生成元；纯标架联络局部曲率为零；单纯的几何方向场构造通常缺乏完整光子传播自由度。

V145 的拓扑闭环绕数可提供离散指数和零模保护机制，却必须有独立物理解释说明 S² 和 U(1) 通量为何由原初光速运动产生。仅添加新的背景场不会自动统一四力。

## 8. 模型缺口、独立可观测预测、研究优先级

(1) 解决从基础螺旋动力学变分得到非平凡背景 F 而不是手选 F 的问题。
(2) 对磁通和 R 的背景方程求解并分析稳定性；当前 R 只是输入。
(3) 从同一作用量推出正确 SU3×SU2×U1 及耦合大小、质量谱，不可人为贴标签。
(4) 对六维和四维规范/引力异常做完整审计。
(5) 对每一类物质的净零模指标要得到正好三代，而非选择性调参。
(6) 分离可证伪的预言：KK 激发质量 ∝1/R、同背景下荷依赖的零模数量、可能存在额外矢量/标量；这些都须结合真实实验数据的排除界。
(7) 若再加入引力，需得到广义相对论极限并说明 G 的起源，避免只在作用量中插入 G。
