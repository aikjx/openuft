## 2. 文档格式规范

### 2.1 Markdown格式要求
- 使用标准Markdown语法
- 标题层级清晰（#、##、###）
- 代码块使用 ``` 包裹
- 数学公式使用 $ 或 $$ 包裹
- 表格使用标准Markdown表格格式
- 引用使用 > 符号
- 列表使用 - 或数字

### 2.2 交叉引用规范
- **内部交叉引用**：使用相对路径和锚点
  ```markdown
  [参考核心范畴定义](./modules/introduction/00-core-category.md#1-范畴名称与标记)
  ```
- **外部交叉引用**：使用完整路径
  ```markdown
  [参考公式分析报告](./code/output/formula_analysis_report.md)
  ```
- **公式引用**：使用统一编号
  ```markdown
  如公式 \ref{eq:momentum} 所示
  ```
- **图表引用**：使用统一编号
  ```markdown
  如图 \ref{fig:module_relation} 所示
  ```

### 2.3 数学公式规范
- 使用LaTeX语法
- 变量使用斜体
- 向量使用 \vec{}
- 微分使用 \dfrac{}
- 公式编号使用 \tag{}

## 3. 内容组织优化

### 3.1 模块化内容组织
1. **核心范畴定义**：明确范畴边界、对象集合、态射约束
2. **对象定义**：详细定义每个物理对象的数学表达和物理意义
3. **态射网络**：构建对象之间的逻辑关系网络
4. **交换图验证**：验证不同推理路径的一致性
5. **函子映射**：实现跨范畴知识迁移
6. **泛性质分析**：提炼核心概念的泛性质
7. **应用指南**：提供实际应用方法和案例
8. **验证方法**：详细说明实验验证步骤

### 3.2 内容深度层次
- **基础层**：概念定义、数学基础
- **核心层**：公式推导、物理意义
- **应用层**：实际应用、实验验证
- **扩展层**：与其他理论的关联、未来发展

## 5. 交叉引用最佳实践

### 5.1 内部文档交叉引用
- **同一模块内**：使用锚点链接
  ```markdown
  [参见质量定义](#3-质量几何化公理)
  ```
- **不同模块间**：使用相对路径
  ```markdown
  [参见场论模块](./modules/field-theory/04-unified-force.md)
  ```

### 5.2 代码与文档交叉引用
- **代码引用文档**：在代码注释中引用相关文档
  ```python
  # 参考文档：modules/field-theory/04-unified-force.md
  def calculate_unified_force():
      pass
  ```
- **文档引用代码**：在文档中引用相关代码
  ```markdown
  代码实现见 [formula_analysis.py](./code/formula_analysis.py)
  ```

### 5.3 验证报告交叉引用
- **引用验证结果**：在理论文档中引用验证报告
  ```markdown
  验证结果见 [公式分析报告](./验证报告/公式分析准确性验证.md)
  ```
- **引用理论基础**：在验证报告中引用理论文档
  ```markdown
  基于 [核心范畴定义](./modules/introduction/00-core-category.md)
  ```
