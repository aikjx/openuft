## 1. §15 C25 续：高阶本征能级 n 域扩展扫描

### 1.1 解析核心（本轮新增，比 V21 更强）

草稿式：`E_n = (ω²/c²)(V0 + n²ℏ²/N²)`，`𝒞 = α_obs·m_e c²/E_1`，`α_n = 𝒞·E_n/(m_e c²)`。

⇒ 代数恒等：**`α_n/α_obs = E_n/E_1 = f_n/f_1`（`f_n = V0 + n²ℏ²/N²`），ω 与 c 严格约去**。

这比 V21 的"不确定度抵消"更强：不是"两个不确定度互相抵消的估计"，而是**代数上根本不出现**。
故草稿误差棒公式 `sqrt(dω_rel² + …)` 中的 `dω_rel = 1e-12` 项属**双重计账**（该项恒为 0）。

| 1 | 0 | 1.0e-12 | 0 | 0 |
| 6 | 1.08887e-75 | 1.0e-12 | 2.17774e-87 | 7.25912e-66 |
| 12 | 4.4488e-75 | 1.0e-12 | 8.8976e-87 | 2.96587e-65 |
| 10^12 | 3.11105e-53 | 1.0e-12 | 6.2221e-65 | 2.07403e-43 |
| 10^30 | 3.11105e-17 | 1.0e-12 | 6.2221e-29 | 2.07403e-7 |
| 10^34 | 3.11105e-9 | 1.0e-12 | 6.2221e-21 | 20.7403 |

## 2. §16 C35 续：多行星进动 + β 普适性结构审计

### 2.1 结构同一性（本轮关键新结果）

草稿 Binet：`u''+u = GM/h² + (GM·β/h²)u²`；GR 1PN：`u''+u = GM/h² + (3GM/c²)u²`。

取 `β0 = 3h²/c² = 2.456901853e14`（水星）⇒ 草稿 u² 系数 `(GM/h²)·β0 = 4430.009073` **精确等于** GR 系数 `3GM/c² = 4430.009073`（相对偏差 0.0）。

⇒ **该分支下「几何修正」就是 GR 的 1PN 项本身**：不是独立预言，是 GR 复述。

### 2.2 β-free 形状比（唯一独立于标定的候选可证伪量）

`R_p = Δφ_geo,p/Δφ_GR,p`；比值 `R_p/R_水星` 中 β 约去：

| 行星 | 正确 Binet 式（比例 1/a） | 草稿式（比例 1/a²） |
|---|---|---|
| 水星 | 1.0 | 1.0 |
| 金星 | 0.51255448 | 0.27429846 |
| 地球 | 0.37083357 | 0.14354897 |

⇒ 同一理论的两条公式给出**不同形状**，互差 **金星 1.8686×、地球 2.5833×** ⇒ 形状检验与「a² vs a³」框架歧义（§13-C35-3）耦合，**歧义消除前不能判别理论**。

### 2.3 标定靶 = 最佳靶（独立判别力为零）

`R ∝ 1/(a(1−e²))` 对 a 单调 ⇒ 太阳系行星中**水星信号最大**（R = 1.1159e-3），而水星正是 β 的标定靶。
金星 R = 5.71959e-4（0.513×水星）、地球 R = 4.13813e-4（0.371×水星）——**"独立预测"靶恰好是信号更弱的靶**。

### 2.4 可观测性（假设已声明）

假定历表约束量级 `σ_obs = 0.1` 角秒/百年（**外部输入·待核实**）：金星修正 4.9330717e-3″/百年 = 0.049σ、地球 1.5885551e-3″/百年 = 0.016σ ⇒ 当前不可判；可判需达 ~1.6e-3″/百年精度。
