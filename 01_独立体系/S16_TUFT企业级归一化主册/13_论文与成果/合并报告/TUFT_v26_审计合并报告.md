## 2. A 路：v26 Wronskian 伪点独立审计（E455，REJECT / Grade D）

**对象**：联盟 `tuft_v26_wronskian_poles.py` 报出的 TUFT 复极点
`ω = 0.446860296 − 0.012798531i`（|ω_i|=0.0128，Q≈17.5），并称"独立复根把阻尼从 0.056 修正为 0.0128、与 v25 实频宽度 g~0.01 一致"。

**GR 门（前置门）——PASS**
- 标准 Jansen 紧化三-N spread = **2.720e-10**（~9.5 位）；跨 b 不变性 = **3.095e-11**。
- 说明求解器机器本身可信，问题不在机器。

**伪根复现（错误 1/s 边界）**
- s_out=60 → **w = 0.446860296 − 0.012798531i**（与联盟值 |Δw| = 5.545e-7）。
- 远场 b(s_out) 漂移 max |Δw| = **1.001e-2**，**非单调、无平台**（不收敛）。

**GR 自洽门（致命门）——FAIL**
- 近 QNM 种子 + 正确 1/s² 边界：s_out=30 → |w − w_ref| = **0.0190**；
- 随 s_out 增大**发散**：60/80/120/160/200 = 0.0848 / 0.116 / 0.149 / 0.188 / **0.232**。
- 粗糙初值另现伪根 **0.594092877 − 0.160986693i**。

**与可信簇的距离**
- vs E450/E452（Grade C 可信簇 0.434445−0.056448）：|Δw| = **4.538e-02**，约为 Grade C 散布 ~5e-6 的 **1e4 倍**，在散布**外**。
- 换成正确 1/s² 边界后 |w_i| 立即回到 **0.04867 – 0.05397（≈0.056）**；0.0128 是**错误渐近幂的人工产物**，非物理阻尼。
- 未报泛音族。

**REJECT 依据（分层）**
1. 前置 GR 门虽 PASS，但**致命的 GR 自洽门 FAIL**：同一两解匹配器在已知 GR 答案上仅 0.0190 且随边界外推发散——一个在已知答案上都过不了自洽门的匹配器，无权在未知 TUFT 根上发 PASS。
2. 残差 ~1e-15 只表示"精确解了一个错误边值问题"；N 网格稳定是对无关旋钮的假收敛。
3. 远场漂移 1.00e-2 非单调无平台，本身即不收敛。
4. 与可信簇差 4.54e-2 在 Grade C 散布外，且正确边界 |w_i| 回到 ~0.056。

**裁决**：**再确认勘误 #32 REJECT**；"阻尼 0.056→0.0128"撤销；TUFT 极点回到 **E450/E452 Grade C 0.434445−0.056448**；**直接 IVP Wronskian 死路二次坐实**。
