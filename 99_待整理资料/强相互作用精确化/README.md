# 强相互作用精确化

> 从统一场论的第一性原理精确推导量子色动力学（QCD）的定量预言，包括禁闭、渐近自由、强子质量谱。

## 问题定义

强相互作用由 $SU(3)_C$ 规范场描述，核心挑战：
1. **禁闭**：夸克与胶子被囚禁在强子内部，无自由夸克
2. **渐近自由**：短距离耦合减弱，高动量下渐近自由
3. **强子质量谱**：从 QCD 拉氏量计算强子质量
4. **核力**：强子间的残余强相互作用

**核心问题**：能否从统一场论的几何第一性原理精确导出 QCD 的定量结果？

## 当前进展（2020–2026）

| 方向 | 进展 |
|---|---|
| 格点 QCD | 强子质量谱计算精度达 1–2%；核子结构函数 |
| 渐近自由 | Gross-Wilczek-Politzer 定理（1973）已严格证明 |
| 禁闭 | 无解析证明；格点数值证据支持；千禧年奖问题 |
| 强子谱 | 格点 QCD 成功重现轻强子谱；奇特态（四夸克、五夸克）发现 |
| 统一场论 | 无统一场论能从第一性原理精确导出 QCD 定量结果 |

## 证伪条件

- 若统一场论预言的强子质量与实验不符，则该预言被证伪
- 若禁闭机制与格点 QCD 冲突，则该方案被排除
- 若渐近自由性质无法恢复，则与 QCD 不兼容

## 状态

开放问题。QCD 本身已被实验精确验证，但统一场论的精确化尚未实现。
