## 摘要

对 115 项现存研究问题建立单项任务、错误来源、修复路径、验收条件和证据级别。对 ROOT 历史公式的循环定义、超光速螺旋运动、强场角频率弱场不相容、ISCO、精细结构常数误差、粒子质量比算术错误和量纲错配进行判定。针对 V89/V90 两量子位置分支模型，进一步独立推出以下三类严格（具有模型前提）的数学结果：

1. **Yukawa 核单调定理：** 在固定四分支几何与正中心间距下，令 `μ=1/λ`，有 `dF_Y/dμ = 4e^{-μd}sinh(μa/2)sinh(μb/2)>0`，因此 `F_N<F_Y<0`。
2. **全尺度上下界：** `ab∫₀^μ t²e^{-dt}dt ≤ F_Y−F_N ≤ ab∫₀^μ t²e^{-δt}dt ≤ abμ³/3`，其中 `δ=d−(a+b)/2>0`。该约束适用于任何正 λ；不是仅在 λ≫d 才成立的级数。
3. **未知背景阶数的灵敏度退化定理：** 如果四分支间距 a,b 固定，且在不同中心距 d 上允许任意至 p 次的未知多项式相位背景，则长程 Yukawa 与 Newton 核的额外可辨识部分从 `λ^{-(p+4)}` 开始（无多项式背景为 `λ^-3`）。当 λ 固定、观测噪声协方差独立于 λ 时，相应线性幅度 Fisher 信息以 `λ^{-2(p+4)}` 衰减；这一结论需保证足够多、几何非退化的距离采样和正确的 nuisance 模型。

提供 Einstein-frame 标量场扩展作为明示的、协变的 **低能候选场论**，推导相对 Yukawa 强度 `α_AB=2β_Aβ_B`，并讨论不能从一个标量自动导出 QCD、电弱手征结构、所有粒子质量和 G 的数值。

软件采用正积分形式避免在长作用距离下做两大数相减；经过 107 项 V91 Python 测试、19 项精确 SymPy 等式、8 组独立 100 位高精度交叉检查与 151 点参数扫描；原 V90 65 项测试也再次通过。所有图表和数据仅属于 THEORY/SYNTHETIC。

## 第三章：原公式的可判定修复

### 3.1 循环定义不得称 G 的独立预测

若定义 `Z=Gc/2`，则 `G=2Z/c` 是严格恒等式。若定义 `r=Gm/c²`，则 `G=c²r/m` 同样为恒等式。`r=ħ/(mc)` 常只是约化康普顿波长定义。只有新理论不使用 G 来确定 Z/r 的数值，而是能独立计算其值与误差时，才有机会推导 G。

`[G]=L³M⁻¹T⁻²`、`[c]=LT⁻¹`、`[ħ]=ML²T⁻¹`。仅用 c 和 ħ 的乘幂构造 G 无解；新动力学必须给出独立质量/长度尺度，而非借助已含 G 的 Planck 单位循环算回。

### 3.2 三维螺旋速率合成

对于 `r=(R cos ωt,R sin ωt,pt)`：`v²=(Rω)²+p²`。若定义的 v 是真实三维空间速度，并要求光速总模长，则 `(Rω)²+p²=c²`。同时令 `Rω=c` 且 `p≠0` 与该约束矛盾。波的相速度、内部相位变化不能不加解释地替代物质轨迹的三维速度。

### 3.3 强场、ISCO、相对论钟

历史强场 ω∝[R−GM/c²]^−1/2 在大 R 时衰减 R^−1/2，与牛顿轨道频率 ∝R^−3/2 不同。若指同一轨道角频率则不能宣称弱场一致。Schwarzschild 度规下的标准 ISCO 是 `6GM/c²=3r_g`，旧候选 `r_g/2` 位于事件视界内。静态 Schwarzschild 坐标钟满足 `dτ/dt=sqrt(1−2GM/(rc²))`；一般运动需直接使用完整度规 `dτ²=−gμν dxμdxν/c²`，不能把一条特定坐标弱场根式推广成无条件精确式。

### 3.4 基本常数审计

历史 `α_inv=4π³+π²+π=137.036303775878...` 与 CODATA 2022 的 `137.035999177(21)` 相差约 `2.222765 ppm`，不能当精确物理恒等式。`2π·3³+2π=56π=175.929188601...`，并非 1836.152673。若 `Z` 与 `Z′` 量纲不同，则 `Z+iZ′` 需要先明确相同量纲的规范化/物理耦合定义。

## 第四章：共同低能作用量与真正开放问题

取自然单位 `ħ=c=1`、度规号规 `(-,+,+,+)`。可作为一条有明确边界的基准：

`S_EFT=∫d⁴x√−g [ M_*² R/2 + L_SM(g,Ψ) + Σ c_i O_i/Λ^(dim_i−4)]`，其中 `M_*²=1/(8πG_*)`。

这里的 c_i、规范群、粒子谱和 G_* 本身是**被输入的**。要宣称根本统一，还必须独立说明它们的来源，以及量子化后是否满足局域性、Lorentz 协变、异常抵消、幺正性、稳定性、低能匹配与高能可控性。局域 EFT 在低能可预测，但不能直接证明 UV 完备。

## 第五章：两个质量位置分支的数学骨架

A 分支位置 `−a/2,+a/2`；B 分支位置 `d−b/2,d+b/2`，要求 `d>(a+b)/2`。四个距离 `r00=d+(a−b)/2`、`r01=d+(a+b)/2`、`r10=d−(a+b)/2`、`r11=d+(b−a)/2`。定义 `D[f]=f(r00)−f(r01)−f(r10)+f(r11)`。

对二阶可微径向核：`D[f]=−∫_{−a/2}^{a/2}du ∫_{−b/2}^{b/2}dv f''(d+v−u)`。因此常数与线性项都被严格消去。适用于冻结路径纯态的非局部相位：`Δ_N=Gm_A m_B t D[1/r]/ħ`，等幅纯态 concurrence 为 `C=|sin(Δ_N/2)|`。这不是现实双体纠缠实验已完成的证据。

## 第六章：新定理一——Yukawa 单调性与零假说不等式

详见 `研究/严格证明_全尺度界与背景阶数.md`。摘要推导：

`F_Y(μ)=Σ w_ij exp(−μr_ij)/r_ij`，直接求导：

`dF_Y/dμ=−Σ w_ij exp(−μr_ij)=4 exp(−μd)sinh(μa/2)sinh(μb/2)`。

只要 `a,b,μ>0`，导数严格大于零。又 `F_Y(0)=F_N<0` 且 `lim_{μ→∞}F_Y(μ)=0`，所以 `F_N<F_Y(μ)<0`。进一步利用 `sinh(x)≥x` 和 `sinh(x)≤xe^x`（x≥0），得：

`ab∫₀^μ t²e^(−dt)dt ≤ F_Y−F_N ≤ ab∫₀^μ t²e^(−δt)dt ≤ abμ³/3`。

**物理含义仅是对核形状的约束。** 实际相位还需乘 `α GmAmBt/ħ`，`α` 并非无条件为 1，并且电荷、退相干、材料和几何不确定度可能完全掩盖该差异。

## 第七章：新定理二——未知背景的阶数与灵敏度退化

固定 a,b 且改变 d。定义 `M_k(d)=D[r^k]`。`M0=M1=0`；对于 k≥2，M_k 是 d 的 k−2 次多项式，最高次项 `−ab k(k−1)d^(k−2)`。展开 `e^(−r/λ)/r`，最早差异从 `λ^-3` 开始，其 `λ^-n` 项是 d 的 n−3 次多项式。

如果存在未知背景 `B(d)=Σ_{j=0}^p b_j d^j`，对数据作投影并消除所有 p 次及以下的多项式成分，那么 n=3,...,p+3 项被**严格消掉**，首次可能保留的项为 `n=p+4`。

用固定协方差和固定有限个测量距离，求幅度 α 的 Fisher 信息：

- 无多项式背景：灵敏度 `O(λ^-3)`，Fisher 信息 `O(λ^-6)`；
- 未知常数：`O(λ^-4)`，Fisher `O(λ^-8)`；
- 常数+线性：`O(λ^-5)`，Fisher `O(λ^-10)`；
- 至二次：`O(λ^-6)`，Fisher `O(λ^-12)`。

需强调：`O` 给出渐近阶数，不保证存在足够实验信噪比。若距离点不足、非退化条件不成立或源体参数不独立，可能更糟；若不同材料、不同 a,b 或独立仪器标定，则上述特定同几何 no-go 条件可能被打破。

## 第八章：参数退化与电磁反例

若净电荷库仑项和牛顿项都是 `1/r` 核，单独改变 d 永远不能区分两个未知幅度。电荷反向 `s=±1` 可以在**带符号、已展开的线性相位**中消去电荷奇分量，但若存在随电荷反向保持不变且具有 `1/r` 形状的背景项 b，设计矩阵的引力列与 b 列完全相同，即使加无限距离点仍秩亏。

本轮明确算出该模型线性代数结果：`rank([g,charge_odd,charge_even])=2`，加入一项**独立背景校准观测**后可变为 3。这说明为什么电荷反向不是万能纠偏手段，也说明具体缺失的是独立观测而非更多同型数据。

Concurrence `|sin(Δ/2)|` 非线性，不能直接取反向平均；必须使用正确的相位展开、层析和物理读出过程。

## 第九章：具体候选模型——协变标量扩展

提出/实现的是常见 Einstein-frame 标量—张量**候选**，并非宣称原创的完整统一场论。取自然单位：

`S=∫d⁴x√−g [ M_*² R/2 − (∂φ)²/2 − m_φ² φ²/2 ] + S_SM[e^(2βφ/M_*)g, Ψ]`。

这里 `M_*²=1/(8πG_*)`，`φ` 是质量维 1 的实标量。弱场非相对论、单标量交换和正则动能下，对两个物体 A/B 的有效相互作用可写为：

`V_AB(r)=−G_*m_Am_B/r [1+2β_Aβ_B e^(−r/λ)]`，`λ=ħ/(m_φ c)`（将标量粒子质量恢复为 SI）。

故 `α_AB=2β_Aβ_B`（同种普适耦合 β 时 α=2β²≥0），加速度比值：

`F/F_Newton=1+α(1+r/λ)e^(−r/λ)`。

需要进一步开展 PPN、等效原理、第五力、宇宙学、自然性和量子修正约束。若物质耦合非普适，β_A 与 β_B 必须由复合质量对 φ 的响应定义，不能简单给每个元素任意数值。这里 SM 已被输入，G_* 也被输入，因此该模型**没有解决四力共同来源或 G 的数值**。

## 第十章：数值和实验可行性

V91 用积分型稳定计算：`ΔF=ab μ³∫₀¹u²exp(−μdu)sinhc(μau/2)sinhc(μbu/2) du`，其中 `sinhc(x)=sinh(x)/x`。这种算法在 λ 极大时不依赖两个接近 `F_Y`,`F_N` 的双精度相减。

程序使用 100 位 `mpmath` **从四个直接指数项独立重算**作为交叉核对，8 组案例最大相对差约 `2.0×10^-15`。101+ 项自动化回归检验不等式、导数、随机参数、极限、信息矩阵秩与异常输入。151 点扫描展示加入多项式背景后灵敏度下降。

假设每个相位点有 σ=10^-4 rad、任意点间的相关系数 ρ=0.35，仅是合成噪声示范。所有 SNR 和 Fisher 数字不应解释为现有仪器能力。实际实验必须独立标定电荷、斑块电势、Casimir、磁场、温度、真空、机械振动、质量和波包动力学。

## 第十一章：为什么目前不能宣布攻破统一场论

1. 尚无独立推导标准模型群、手征谱、三代、Higgs、QCD 禁闭与 G 数值的基础作用量。
2. 尚未提供候选量子引力的规范不变高能完备定义与完整 anomaly/ghost/unitarity 论证。
3. 本轮 Yukawa/scalar 是一个**已知类型**的可检验有效场论扩展，不等于原始四力统一。
4. 所有 numerical/plots 都是自定参数、模型计算或合成噪声，没有任何本团队生成的自然界新力测量。
5. 当前关于经典引力、纠缠与可检验引力子推论仍有理论前提争论；不能以单个玩具纠缠量取代模型对照。
