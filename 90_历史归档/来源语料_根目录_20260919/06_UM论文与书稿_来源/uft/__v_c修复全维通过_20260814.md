## 一、v=c 核心原理

### 1.1 什么是 v=c？

```
v = 螺旋前进速度
c = 光速（精确值）
v = c → 螺旋以光速运动

这不是"光以c传播"
这是"空间（螺旋几何）以c运动"
光 = 螺旋振荡
空间 = 螺旋运动
v = c = 空间本身的速度
```

### 1.2 为什么 v 必须等于 c

```
若螺旋 v < c：
  → 空间比光慢
  → 光（作为空间运动）速度 < c
  → 与 c 的定义矛盾

若螺旋 v > c：
  → 超过光速
  → 因果律破坏
  → 信息可超光速传播

结论：v = c 是唯一一致的选择
```

## 二、螺旋几何与 v=c

### 2.1 螺旋基本方程

```
位置矢量：
  r(θ) = R·cos(θ)·e_x + R·sin(θ)·e_y + (τ/κ)·θ·e_z

弧长：
  ds² = R²dθ² + (τ/κ)²dθ²
  ds = √(R² + (τ/κ)²) dθ

对于 v=c：
  v = ds/dt = c
  c = √(R² + (τ/κ)²) · ω
```

### 2.2 关键洞察

```
相速度 v_p = ω/k = c/α
群速度 v_g = dω/dk = c·α
v_p · v_g = c²

螺旋几何中：
  相速度 = 螺旋方向速度
  群速度 = 波前垂直方向速度
  比值 = τ/κ = α

验证：
  c² = (c/α) · (c·α) = c² ✓
```
