## 三、定理 I · 通量量子 M 被完全消去

**命题**：等谱条件 `n_R = M·q_R·d_R + k_R = N` 反解出 `q_i = (N−k_i)/(M·d_i)`。把它代入六条反常：

| 反常 | 对 M 的依赖 | 约化方式 |
|---|---|---|
| `A₃`、`A₂`、`A_g`、`A_YY` | ∝ **1/M** | 乘 `M` |
| `A_YF` | ∝ **1/M²** | 乘 `M²` |
| `A_FF` | ∝ **1/M³** | 乘 `M³` |

⇒ **约化残差与 M 完全无关**（M ≠ 0）。

**机检（B01–B07）**：6 个 k 向量（T0/T3/T2/T32/家族 t=3/任意乱序 `(2,5,1,3,0)`）× 4 个 N = **24 组**，每组在 **12 个有理 M**（1, 2, 3, 5, −1, −5, 7, **1/2, 1/3, 2/3, −1/7, 5/3**）上算约化残差 ⇒ **24/24 与 M 无关，反例 0**。

以 T3、N=1 为例，六条约化残差为：

```
(A₃, A₂, A_g, A_YY, A_YF, A_FF) = (1, 1/2, 3, 7/12, −1/12, 1/4)
```

**六条全部非零，且是常数** ⇒ 阻碍不是「某个 M 不行」，是**任何 M 都不行**。

> **意义**：r302 用 96 个整数 M 做穷举，本质上是**在验证一个与 M 无关的命题**。本卷说明这个命题的正确形式，因此 Z_N 分数通量在**结构上**不构成退路——不需要逐个数。

## 四、定理 J · 四条线性反常的完整分类，且 q ∝ Y

把 `q_i = (N−k_i)/(M d_i)` 代入四条线性反常并乘掉 M，得到**关于 (N, k₁…k₅) 的线性方程组**：

```
A₃·M :  6N − 2k₁ − 2k₂ − 2k₃ = 0
A₂·M :  6N − 3k₁ − 3k₄ = 0
A_g·M : 5N − k₁ − k₂ − k₃ − k₄ − k₅ = 0
A_YY·M: (11/6)N − (1/36)k₁ − (4/9)k₂ − (1/9)k₃ − (1/4)k₄ − k₅ = 0
```

**精确 RREF（秩 = 4，未知量 6）**：

```
R1  [1, 0, 0, 0, −1/2, −1/2]
R2  [0, 1, 0, 0,   0,   −1 ]
R3  [0, 0, 1, 0, −3/2,  1/2]
R4  [0, 0, 0, 1,   0,   −1 ]
```

即

```
N = (k₄ + k₅)/2,   k₁ = k₅,   k₂ = (3k₄ − k₅)/2,   k₃ = k₅
```

以 `λ = k₅` 重参数化，**解空间是 2 参数族**：

```
k = (λ, 3N − 2λ, λ, 2N − λ, λ)
```

**并且此时荷型唯一**：

```
q_i = (t/M)·Y_i,    t = N − λ
```

- **C01–C02**：秩 4、维数 2（满秩 ⇒ 无冗余方程；维数 2 ⇒ 线性部分定不死，必须再看非线性）。
- **C04**：RREF 四行逐点回代，7 组 (N,λ) × 4 行 = **28 个恒等式全部成立**。
- **C05**：该族与 RREF 解集**逐点等价**（35 组 (N,λ) 全过）。
- **C06**：族内 96 组 (N,λ,M) 代入六条反常**全部为零** ⇒ 该族是解集，不只是线性部分的子集。
- **C07**：`q = (t/M)·Y` 在 60 组上**逐分量精确**成立。

> **这是本卷最重要的结构性发现**：r294 与 r295 都把「通量沿超荷方向」当作**前提**（因为要 `[Q, G_SM] = 0`）。本卷证明：**只要要求五表示等谱，荷型就被逼成 `q ∝ Y`**——不是我们选的方向，是等谱唯一允许的方向。r294/r295 的假设因此变成定理的推论。

## 五、定理 K · 两条非线性反常化为 SM 自身的反常自由

族内解的偏差向量是

```
N − k = t·(1, −2, 1, −1, 1) = t·tr_R(Y)
```

**它恰好就是 `dim·Y`**。于是

```
A_YF = Σ d_i Y_i q_i²  = Σ d_i Y_i (tY_i/M)² = (t²/M²)·Σ d_i Y_i³
A_FF = Σ d_i q_i³      = Σ d_i (tY_i/M)³     = (t³/M³)·Σ d_i Y_i³
```

而 `Σ d_i Y_i³ = 0`（SM 自身的 `U(1)_Y³` 反常为零，A06）⇒ **两条非线性反常在解集上恒为零**。

- **D01**：`N − k = t·tr_R(Y)` 在 48 组上精确成立。
- **D02–D03**：`A_YF·M² = t²ΣdY³`、`A_FF·M³ = t³ΣdY³` 各 12/12 成立。
- **D04–D05（非平凡正对照）**：把 `Y₅` 扰动 `+1/10`，`ΣdY³` 变成 **331/1000 ≠ 0**，两个恒等式**仍 9/9 成立且两边均非零** ⇒ 这是**真身份**，不是 `0 = 0` 的空转。

> **意义**：六条反常里真正起独立约束作用的只有四条线性方程；两条非线性在等谱族上退化为 SM 自己的反常自由条件。**「六条全查」是安全做法，但不是必要条件。**

## 六、定理 L · `k_R ≤ 1` 锁定一代

把 `N = λ + t` 代入族：

```
k = (λ, λ + 3t, λ, λ + 2t, λ)
```

等谱对 k 的要求**极其具体**：`u_R^c` 必须比其余高 **3t**、`d_R^c` 高 **2t**。

若 `k_R ∈ {0,1}`（不可约表示至多一份常数截面），在有理网格（N 分母 ≤ 12、λ 分母 ≤ 6，共 **152,856** 组）上穷举：

| N | λ | k | 说明 |
|---|---|---|---|
| 0 | 0 | (0,0,0,0,0) | 平凡，无物质 |
| **1** | **1** | **(1,1,1,1,1)** | **恰好一代** |

**只有这两个解**（E02/E03），且两者都满足 `N = λ` ⇒ **t = 0 ⇒ q = 0 ⇒ n_R = k_R ∈ {0,1}**（E04）。
**N = 3 的解数 = 0**（E05）⇒ 三代不可达，**且这个结论完全不含 M**。

## 七、定理 M · 最小 K = 3t

把 `k_R ≤ 1` 放宽为 `k_R ≤ K`，问「要 t 代，K 至少多大」。构造性搜索（`K` 从 0 往上扫，`λ` 遍历）：

| t | K_min | 构造的 k |
|---|---|---|
| 0 | **0** | (0,0,0,0,0) |
| 1 | **3** | (0,3,0,2,0) |
| 2 | **6** | (0,6,0,4,0) |
| 3 | **9** | (0,9,0,6,0) |
| 4 | 12 | (0,12,0,8,0) |
| 5 | 15 | (0,15,0,10,0) |
| 6 | 18 | (0,18,0,12,0) |

**K_min = 3t**，逐点成立、严格递增。

**三代的具体代价**（F03–F05）：需要

```
k = (0, 9, 0, 6, 0)       即 u_R^c 有 9 份、d_R^c 有 6 份常数截面
配 q = 3Y（M = 1）⇒ n = (3,3,3,3,3)
且六条反常全零 —— 这个「三代解」在内都是自洽的
```

> **这就是本卷最锋利的一句**：三代不是被算术挡住的，也不是被反常挡住的，**是被 `k_R ≤ 1` 挡住的**。只要某个紧致化能让 `u_R^c` 拿到 9 份常数截面而 `d_R^c` 拿到 6 份，三代立刻可得且自洽。这是一个**可被单一反例推翻的判词**——本库少见的、指向明确的否证入口。

2. **承重点只有一条：`k_R ≤ 1`**。本卷把它从「隐含假设」提成**显式公设**并量化了后果。若它不成立，三代立刻可得（CTL6）。这是**优点不是缺点**——判词因此可被单一反例推翻。
3. **`k_R ≤ 1` 的物理依据是「不可约 + 投影」**：一个不可约表示在扭折扇区要么有一份常数截面、要么没有。本卷**没有**从第一原理推导它，只登记为物理公设 P1。若有人认为高阶扭转能给出多重常数截面，那就是本卷的否证入口（见 `X-R305-1`）。
4. **本卷假定 `q_R = q(R)`（荷只依赖表示，不依赖代指标）**。若允许代指标依赖，「等谱」退化为逐代手工输入（承 r302 §七.5）。
5. **「q ∝ Y 是等谱逼出来的」这一条依赖「等谱」这个强要求**。若只要求「代数 = 3」而不要求「五表示全等」（允许不完整谱/镜像谱），本卷不适用（承 r302 `X-R302-1`）。
