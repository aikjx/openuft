## 第二章 光速螺旋的几何结构

### 2.1 圆柱螺旋的严格参数化

基本粒子的内禀运动轨迹为三维圆柱螺旋线，参数方程：

$$\boldsymbol{r}(\theta) = \rho\cos\theta\,\boldsymbol{i} + \rho\sin\theta\,\boldsymbol{j} + b\theta\,\boldsymbol{k}$$

其中：
- **ρ**：螺旋横向回旋半径（垂直于螺旋轴的平面内圆周运动半径）
- **b**：螺旋导程参数（方位角θ每变化1弧度时沿z轴前进的距离）
- **θ = ωt**：方位角参数

### 2.2 速度分解与光速约束

对参数方程求导得到切向方向矢量：
$$\frac{d\boldsymbol{r}}{d\theta} = (-\rho\sin\theta, \rho\cos\theta, b)$$

**合速度矢量**：
$$\boldsymbol{v}_{\text{总}} = \omega(-\rho\sin\theta, \rho\cos\theta, b)$$

**光速约束**（合速度恒等于c）：
$$c = \omega\sqrt{\rho^2+b^2}$$

**速度正交分解**：
$$v_\perp = \omega\rho, \quad v_\parallel = \omega b$$

满足关键关系：
$$v_\perp^2 + v_\parallel^2 = c^2$$

## 第三章 曲率 κ 与挠率 τ 的几何本源

### 3.1 Frenet-Serret 框架

沿曲线运动的最自然参考系是**Frenet 活动标架** {T, N, B}：

- **T**：切向量，指向运动方向
- **N**：主法向量，指向弯曲方向
- **B**：副法向量，T × N，垂直于 T 和 N

**Frenet-Serret 公式**：
$$\frac{d}{ds}\begin{pmatrix}T\\N\\B\end{pmatrix} = \begin{pmatrix}0&\kappa&0\\-\kappa&0&\tau\\0&-\tau&0\end{pmatrix}\begin{pmatrix}T\\N\\B\end{pmatrix}$$

**物理解读**：
- T' = κN：切向量以速率 κ 向主法向量弯曲（→ 引力）
- N' = -κT + τB：主法向量向两侧扭转（→ 混合效应）
- B' = -τN：副法向量以速率 -τ 绕主法向量扭转（→ 电磁力）

### 3.2 曲率 κ 的严格推导

曲率度量曲线偏离直线的程度。公式：

$$\kappa = \frac{|\boldsymbol{r}' \times \boldsymbol{r}''|}{|\boldsymbol{r}'|^3}$$

**圆柱螺旋的曲率**：
$$\boxed{\kappa = \frac{\rho}{\rho^2+b^2} = \frac{\rho}{R^2}}$$

**物理意义**：
- κ 由回转半径 ρ 决定
- ρ 越大（螺旋越"松"），κ 越小（越接近直线）
- ρ 越小（螺旋越"紧"），κ 越大（弯曲越厉害）
- **κ 对应质量与引力的几何本源**

### 3.3 挠率 τ 的严格推导

挠率度量曲线偏离平面曲线的程度。公式：

$$\tau = \frac{(\boldsymbol{r}' \times \boldsymbol{r}'') \cdot \boldsymbol{r}'''}{|\boldsymbol{r}' \times \boldsymbol{r}''|^2}$$

**圆柱螺旋的挠率**：
$$\boxed{\tau = \frac{b}{\rho^2+b^2} = \frac{b}{R^2}}$$

**物理意义**：
- τ 由螺距参数 b 决定
- b = 0 时 τ = 0，曲线是平面圆（无扭转）
- b > 0 是右手螺旋，b < 0 是左手螺旋
- **τ 对应电荷与电磁力的几何本源**

### 3.4 复曲率 Ξ = κ + iτ

**定义复曲率**：
$$\boxed{\Xi = \kappa + i\tau = \frac{\rho+ib}{\rho^2+b^2} = \frac{1}{R}e^{i\theta_0}}$$

**代数性质**：

| 性质 | 表达式 | 物理意义 |
|------|--------|---------|
| 模长 | \|Ξ\| = √(κ²+τ²) = 1/R | 对偶不变量，特征尺度的倒数 |
| 幅角 | θ₀ = arctan(τ/κ) = arctan(b/ρ) | 螺旋基本倾角 |
| 共轭 | Ξ* = κ - iτ | 手性翻转（左↔右） |
| 旋转 | Ξ → Ξe^{iφ} | Frenet 标架的旋转 |

### 3.5 对偶不变量 I = κ² + τ²

**定义**：
$$\boxed{I \equiv \kappa^2+\tau^2 = \frac{1}{\rho^2+b^2} = \frac{1}{R^2}}$$

**物理解读**：
- I 度量螺旋的"总几何密度"
- 无论 κ 和 τ 如何分配，只要 I 相同，螺旋特征尺度就相同
- I 是**旋转不变量**，与观察者视角无关
- I = 1/R² 是质量几何化的数学根据

### 3.6 曲率-挠率的物理对应表

| 几何量 | 数学定义 | 物理对应 | 特征 |
|--------|---------|---------|------|
