## 二、P0-1 复核：作用量回括号，闭合 W14

### 量纲基准（自然单位，[G]=L²）
- `[κ] = [τ] = L⁻¹`（弧长倒数，v_eq_c 主线冻结）
- `[R] = L⁻²`
- `[1/κ_G] = L²`（κ_G = 8πG）
- 拉氏量密度齐次目标量纲 = L⁻⁴

### r29 W14 原始失败（料1 写法）
料1 把挠率项移出括号，写成：
```
ℒ = (1/(2κ_G))·R  +  (1/4)·τ²
```
- `[(1/(2κ_G))R] = L⁻² · L⁻² = L⁻⁴`
- `[(1/4)τ²] = [τ²] = L⁻²`
- 两项量纲差 **L²**，不可相加 ⇒ W14 成立（本册 P01a 机器复现 FAIL）

### 修复 P0-1 两条子修法（均零新参数）
- **子修法 A（移回括号）**：`ℒ = (1/(2κ_G))(R + α·τ²)`，`α` 无量纲
  - `[α·τ²] = L⁻² = [R]` ⇒ 括号内齐次 L⁻²
  - 乘 `1/(2κ_G)`（L²）⇒ 整体 L⁻⁴ 闭合（**P01b PASS**）
- **子修法 B（补系数）**：`ℒ = (1/(2κ_G))R + (1/(2κ_G))α·τ²`
  - 两项同量纲 L⁻⁴，与 A 等价（**P01c PASS**）

### 裁定
- **P0-1 是零新参数纯改写，可闭合 W14 而不违 Ω5**（P01d PASS）
- 这是 r29 第十三章"方向乙"里成本最低、收益确定的一步；与 r27 记录过的"量纲相加须由机器断言兜底"纪律一致（本册 P01e 自检 3 项全过）

## 三、P1-2 复核：L_fluct 显式化，撞 Ω5

### 显式形式（取 Proca 型标量 τ 动力学）
```
L_fluct = (Z_τ/2)(∂_μ τ)(∂^μ τ) + (m_τ²/2)τ² + λ·τ⁴
```
τ 是框架已有场（[τ]=L⁻¹），但 **Z_τ、m_τ、λ 是新参数**。

### 量纲自洽（P12a PASS）
- `[(∂τ)²] = L⁻⁴`，`[Z_τ]=1`（无量纲，可吸收进场重定义）
- `[m_τ²τ²] = L⁻⁴` ⇒ `[m_τ]=L⁻¹`（新质量/长度标度）
- `[λτ⁴] = L⁻⁴` ⇒ `[λ]=1`（无量纲耦合）
- 三项均 L⁻⁴，量纲自洽 ⇒ P12a PASS（本册修正了初版把 [∂τ] 误算成 L⁻⁴ 的笔误，复跑后量纲正确）

### 参数代价（P12b FAIL）
- 至少引入 **2 个新自由参数**：`m_τ`（新质量标度）、`λ`（新耦合）
- `Z_τ` 无量纲可被场重定义吸收，保守不计
- 引用 **r15 读数**：Ω5 口径 II（常数 + 分区节点）自由度 = 5，模型已在使用未声明外部输入
- P1-2 再 +2 参数 ⇒ 与 r29 Y38（来料自身式集有 12 个未由 κ/τ 定义的独立符号）互相印证

### 与声明矛盾（P12d FAIL）
- P1-2 与"无外挂场·无独立耦合·无额外参数"叙事直接冲突
- 这正是 r29 判定册给的"方向丙（概念收缩）"的真实账单：显式化动力学场必然引入未声明自由参数
