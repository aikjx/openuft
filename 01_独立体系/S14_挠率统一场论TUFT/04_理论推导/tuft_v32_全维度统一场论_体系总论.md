## 七、α 派生机制框架（TS9，C0095）与文献交叉核验

**充分条件 A1–A6**：静态解存在 / 无 α 调参 / 质量一致性 / 点状电形状因子（C0091 硬约束）/ 涌现尺度 / 可检验预言。

**张力 T1/T2**：点状电 vs 自能空间分布（需 UV 调节即重整化）；无调参 vs 固定 α。

**文献交叉核验（已查证）**：
- α 在标准模型中为**无量纲自由参数**，全域无被主流接受的从第一性原理派生 ["https://illuminating.science/constants/fine-structure-constant/"]
- 经典电子半径 r_e=e²/(4πε₀m_ec²)=αλ_C 是"库仑自能=静能"的**定义式**（确认 C0089 分类）["https://handwiki.org/wiki/Physics:Renormalization"]
- 电子质量重整化（裸质量+自能）是既有正确框架（确认 C0092/95 的 UV 调节方向）["https://arxiv.org/html/0704.2276v1","https://arxiv.org/html/2512.18802"]

**结论**：TUFT 派生 α 的困难是**全域共有的困难**（α 处处是自由参数），非 TUFT 特有失败。TUFT 的合法贡献是两尺度结构统一经典/原子可观测量；α 派生的机制缺口（电荷场自耦合 U_Q(ρ)）满足 A1–A6 即成立，且更可能来自 QED 型 UV 调节。
