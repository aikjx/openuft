# 可核查来源与数值前提

1. NIST/CODATA 2022 常数： https://physics.nist.gov/cuu/pdf/JPCRD2022CODATA.pdf 。G = 6.67430(15)e-11，c SI 定义精确。
2. JPL DE440 Astrodynamic Parameters： https://ssd.jpl.nasa.gov/astro_par.html 。Earth GM = 398600.435507 km^3/s^2，Moon GM = 4902.800118 km^3/s^2，Sun heliocentric GM = 132712440041.279419 km^3/s^2，Jupiter *system* GM = 126712764.100000 km^3/s^2。表中以 1 km^3/s^2 = 1e9 m^3/s^2 换算；木星系统 GM 配木星半径仅为近似量级示意。
3. MICROSCOPE final Eötvös parameter result： https://pubmed.ncbi.nlm.nih.gov/36179190/ ; https://journals.aps.org/prl/abstract/10.1103/PhysRevLett.129.121102 。-1.5±2.3_stat±1.5_syst (in 1e-15), no detected violation.
4. NIST Cassini Shapiro delay literature： https://www.nist.gov/publications/accurate-light-time-correction-due-gravitating-mass 。Cassini PPN γ consistent with 1; sensitivity ~2.3e-5.
5. LLR perspective (2026 review on propagation/systematics)： https://www.mdpi.com/2073-8994/18/1/50 。

**注意：** 天体参考数值是外部真实参数的选取，白矮星/中子星数值是人为基准；所有“第五力信号”“跨星体材料差矩阵”“噪声曲线”都是合成示例。
