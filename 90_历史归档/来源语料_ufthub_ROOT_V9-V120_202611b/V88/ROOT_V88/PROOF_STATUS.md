# ROOT V88｜证明与证据状态

## [E] 数学严格成立（给定模型）

1. 固定位置分支的 Newton 势 U_ij = -G m1 m2/r_ij 可作为两质量的相互作用 Hamiltonian 近似；分支相位 θ_ij=Gm1m2 t/(ħ r_ij)。
2. 初始四分支等幅独立纯态，控制相位 Δ=θ00−θ01−θ10+θ11；纯态 concurrence = |sin(Δ/2)|，纠缠负性 = concurrence/2。
3. 单粒子局部相位对 Δ 不产生影响；仅当 Δ 非 2π 整数倍时，该理想模型生成纠缠。
4. 对初始可分的两体，严格 LOCC 类操作不能产生纠缠；这是受假设限制的数学定理。
5. 引力与残余点电荷的 Coulomb 势都呈 1/r：只看同一装置的空间相位形状无法辨别两者。
6. 若量子相位只测得 Gm1m2 的乘积且质量未独立标定，则不能单独决定 G。
7. 给定局部 Z 退相干渠道，密度矩阵映射是完全正、迹保持，数值部分转置负性可复算。

## [C] 条件结论

1. G 与量子力学的低能兼容，不等于完整量子引力场方程已统一。
2. 实验测出两体纠缠，在初始无纠缠、只有重力媒介、媒介局域/成分关系明确等条件下，可排除特定纯经典局部通信模型。
3. 不同经典、混合、非局域或含量子物质交换的模型可能产生不同预言；需要逐项比较而不是一刀切。
4. V88 的局部退相干临界阈值只对所设置的冻结路径/两个独立退相干率/固定 t 等假设成立。

## [OPEN] 未证明

1. 未证明引力场本身在自然界具有量子自由度。
2. 未证明 G 的数值及其本源；仍然是外部输入。
3. 未证明四力统一，或 ROOT 光速螺旋是自然微观公设。
4. 未完成实际量子质量超位置实验、量子态层析、仪器误差验证。
5. 未排除所有经典/混合媒介理论；2025–2026 最新文献对此存在不同解释。

## [R] 已排除或纠正的错误断言

- 只要测得量子引力相位就证明引力场量子化（错误）。
- BMV 理想纠缠非零就说明当前实验已成功（错误）。
- 任意经典媒介都无法产生纠缠（若不明确 LOCC 等前提，结论过强）。
- Coulomb 势距离曲线与 Newton 势天然可用几何测量区分（两者均为 1/r）。
- 改进量子相位测量就能在没有独立质量测量时单独推导 G（参数退化）。
