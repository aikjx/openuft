为什么一条螺旋轨迹不能唯一决定电磁场？

可调节第 3 组探针的速度差方向，并选择同时使用几组速度测量。界面即时计算真实线性代数矩阵的秩、条件数及能否反演六个电磁场分量；所有数值均为合成例子。

局部电磁场是否可唯一反演？
算法：对实际 3N×6 设计矩阵做消元秩检验，并对 Gram 矩阵进行 Jacobi 特征值迭代。条件数无量纲；接近共线时大幅恶化。
物理结论
曲率/挠率反映粒子所受净力后的运动，但同一时空位置的单探针力无法分开电场和磁场。两组不同速度一般仍缺少一个磁场分量。三组非共线速度差可在理想条件下恢复六个分量，但必须独立校准电荷、速度和外源场，且场在不同探针测量期间相同。
