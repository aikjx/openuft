## 🌌 系统概述
本系统是基于**Fractal-Dual分形对偶布局算法**的3D关系网可视化引擎，实现亿级节点毫秒级分形布局，支持动态加载、实时交互、全参数可调，视觉效果达到宇宙星河级渲染标准。

核心算法继承《0·1·∞三元一体全域超复数统一场论》双向对偶算子代数，采用下行扩张⊛、上行收敛⊛⁻¹双算子，实现：
- O(logN)时间复杂度粗布局，亿级节点毫秒级完成
- 视距外节点动态剪枝加载，保证交互流畅无卡顿
- 节点属性映射斥力、关联度映射引力，自然聚类分形
- T_cut=240高截断收敛保证，无布局震荡
- 3D发光粒子效果，2万颗背景星空，Additive混合实现星河发光质感

11. **重新分形生长**：重置节点位置，重新播放分形生长动画

## 🔬 核心算法原理
### Fractal-Dual分形对偶布局算法
#### 1. 双向算子体系
- **下行扩张算子⊛**：二分集群并行粗布局，每一层将节点集群拆分为2个子集群，O(logN)时间复杂度完成全局粗定位
- **上行收敛算子⊛⁻¹**：视距外节点动态剪枝，仅加载相机附近节点，远距离节点仅保留拓扑索引，大幅降低计算量

#### 2. 力导向布局改进
- 节点斥力：与节点影响力（属性值）正相关，高影响力节点自然占据更大空间
- 关联引力：与边关联度正相关，强关联节点自然聚集形成分形簇
- 分形衰减步长：步长随迭代次数指数衰减(0.5^t)，前期快速铺开，后期精细收敛，无震荡

#### 3. 数学收敛性证明
全局拓扑残差：
$$\bar{\epsilon} = \frac{1}{N(N-1)}\sum_{i\neq j}\epsilon_{ij}$$
收敛条件：$d\bar{\epsilon}/dt < 10^{-4}$，分形步长保证240次迭代内必然收敛，无布局震荡。
