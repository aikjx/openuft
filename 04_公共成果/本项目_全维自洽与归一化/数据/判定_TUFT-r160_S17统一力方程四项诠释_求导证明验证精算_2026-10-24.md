## 三、靶的方程与四项诠释

```
P = m (C − V)
F = dP/dt = C dm/dt − V dm/dt + m dC/dt − m dV/dt
  ①  C dm/dt  → 电场力      （方向沿 C）
  ② −V dm/dt  → 磁场力      （原文自承「方向与 V 相反」）
  ③  m dC/dt  → 核力        （C 方向剧变时激活）
  ④ −m dV/dt  → 惯性力/引力 （= −m a）
```

## 六、内部矛盾（本卷最硬）

公设称 C 为**空间光速圆柱螺旋运动**矢量 ⇒ dC/dt ≠ 0 恒成立；
但原文在静止/匀速/宏观三处**假设 dC/dt = 0** 才得「核力消失、F = 0」⇒ **互斥**。

机读：r = ħ/(2mc) = 1.930796e-13 m ⇒ ω = c/r = 1.552688e+21 s⁻¹ ⇒ |dC/dt| = c²/r = 4.654842e+29 m/s²
⇒ 核力项 m·|dC/dt| = **4.240274e-01 N**（电子，恒定、与距离无关），是电子在 1 V/m 电场中受力的 **2.647e+18 倍**；与 r155 机读 0.4240274 N 跨卷一致（偏差 3.21e-08）。

## 七、符号层与两难

原文把 F = −m a 的负号解释为「约定差异：牛顿的 F 是外界合力，此处的 F 是动量变化率」。
**不成立** —— 牛顿第二定律的原始表述正是「合力 = 动量变化率」，二者本是一物；
真正的差别在动量定义（m(C−V) vs mv），不在 F 的语义。
机读：自由落体 −m a = **向上**，与牛顿反号（比值 −1.000000000），与 r148 B1、r159 引力侧同一负号**第三次**出现。

**两难**：F 若指合力 ⇒ 与牛顿矛盾；若非合力 ⇒ 它不是力方程，四项诠释全部落空。

## 八、条目总表

- **A1** [PASS] 求导正确：d[m(C−V)]/dt 四项展开与数值差分一致（残差 3.73e-09） — 以具体 m(t)=m₀(1+αt)、C(t)=c(cos ωt, sin ωt, 0)、V(t)=(v₀+βt,0,0) 代入：解析四项之和与中心差分相对残差 **3.732e-09**，且收敛阶扫描单调（3.73e-09 / 9.35e-10 / 2.33e-10）⇒ **求导本身正确**，靶在求导这一步没有问题。这是本卷对靶有利的结论，诚实登记。
- **A2** [PASS] 量纲自洽：四项量纲均为力 [M L T⁻²]（复现原文 §4.1 自承） — ① C·dm/dt：(m/s)(kg/s)=kg·m/s² ② V·dm/dt 同 ③ m·dC/dt：(kg)(m/s²) ④ m·dV/dt 同 ⇒ 四项量纲**均为力**，原文 §4.1 的「量纲始终自洽」**成立**。注意：**量纲对 ≠ 物理对**（记忆纪律：量纲门对读法无分辨力），量纲通过不构成对四项诠释的支持。
- **B1** [FAIL] 磁场力：来料项与 V 反平行（180°），洛伦兹磁力 ⊥ V（90°） — 机读夹角：洛伦兹磁力与速度 **90.00°**（⊥，且做功 = 0.000e+00 W ≡ 0，磁力不做功）；来料项 −V·dm/dt 与速度 **180.00°**（**反平行**），做功 = -1.6022e-07 W ≠ 0 ⇒ 会把运动电荷持续减速。方向差 90.0°，是**系统性**错误而非量级问题。原文自承「矢量形式与经典洛伦兹力不同」——本卷确认：不是「形式不同」，是**方向相反且违反磁力不做功**。
- **B1b** [FAIL] 磁场力：来料项不含外磁场 B，对 B 的敏感度 = 1.000（洛伦兹 = 2.000） — 把外磁场由 1 T 加倍到 2 T：洛伦兹磁力 ×**2.0000**，来料项 ×**1.0000**（**完全不变**）。⇒ 来料的「磁场力」**不含磁场**，无法表现磁场强弱、源电荷、距离任何一项；它只依赖受力物体自身的速度与自身电荷 ⇒ 不是磁场力。（大小因 k′ 未给而不可定，故只判方向与敏感度，此项诚实登记为不可定量。）
- **B2** [FAIL] 电场力：来料项方向被锁死在 C（空间本底方向），无法跟随外电场 E — 来料电场力 C·dm/dt 的方向**恒等于 C 的方向**，而实际库仑力 qE 沿 **E** 的方向。本例 E 沿 +x、C 沿 +z ⇒ 夹角 **90.00°**。除非 E ∥ C（特例），否则方向全错；且来料项**不含 E** ⇒ 与磁场项同病：不随外场变化。一个方向不能跟随电场的「电场力」，无法描述任意方向的电场。
- **B3** [FAIL] 核力项 m·dC/dt 不含距离与耦合常数，无法表现核力的短程性与饱和性 — 核力的三个观测特征 —— 短程（~1–2 fm 外为零）、饱和性、与核子种类相关 —— 在 m·dC/dt 中**一个都没有**：无距离 r ⇒ 不随距离衰减（长程）；无耦合常数 ⇒ 强度不可标定；无核子种类依赖 ⇒ 无法区分 pp / pn / nn。符号清点命中：距离 0 / 耦合常数 0 / 核子种类 0。该项提供的是**几何起源叙事**，不是核力。
- **B4** [FAIL] 引力项 −m a 不含 G / M / r，只能事后代入观测加速度（记账式） — 万有引力 F = GMm/r² 需要 G、源质量 M、距离 r；来料项 −m a 三者皆无，只能把**已经观测到的**加速度 a 代进去反推「力」⇒ 这是**记账式**而非**约束式**（与 r149「记账式统一 ≠ 约束式统一」同型）。且符号为 **−**（见 D1）。
- **C1** [FAIL] ★C 螺旋公设与「dC/dt = 0」假设互斥：核力项恒非零且达 0.4240 N — 公设称 C 为**空间光速圆柱螺旋运动**矢量 ⇒ 方向持续旋转 ⇒ dC/dt ≠ 0 **恒成立**。但原文在静止 / 匀速 / 宏观低速三处均**假设 dC/dt = 0** 才得到「核力消失、F = 0」。两者**互斥**：若 C 真在螺旋，核力项 m·dC/dt 处处非零 —— 机读其值为 m·c²/r = **4.240274e-01 N**（电子，恒定、**与距离无关**），是电子在 1 V/m 电场中受力的 **2.647e+18 倍**。与 r155 机读 a_c = 4.6548e+29 m/s²、F = 0.4240 N 跨卷一致（偏差 1.15e-08 / 3.21e-08）。⇒ 要么放弃螺旋公设（理论地基），要么承认每个电子都承受一个 0.42 N 的、不随距离衰减的恒定力（与观测矛盾）。
- **C2** [BOUNDARY] 光速状态：m 的语义在「静止质量为零」与「能量等效质量」间滑动 — 原文 §3.4 称 |V| = c 时「静止质量 m₀ 必须为零」，却又令「m 理解为运动质量或能量等效质量」，同时又设 dm/dt = 0（光子电荷为零）。**同一段里 m 承担了三种语义**，而力方程的求导 （A1 已验证正确）要求 m(t) 是一个确定的可微函数 ⇒ 该状态下方程的代入**未定义**。本卷登记为 BOUNDARY（口径未定），不作有利也不作不利结论。
- **D1** [FAIL] F = −m a 精确反号（比值 −1.000000000）；原文的「约定差异」解释不成立 — 原文解释负号为「约定差异：牛顿定律中的 F 是外界施加的合力，而方程中的 F 被解释为物体动量的变化率」。**这不成立**：牛顿第二定律的原始表述正是「**合力 = 动量变化率**」（F = d(mv)/dt），两者是同一个量，不存在约定差异。真正的差别在动量的**定义**（m(C−V) vs mv），不在 F 的语义。机读：自由落体下 −m a = **+9.806650 N（向上）** vs 牛顿 -9.806650 N（向下），比值 -1.0000000000。⇒ 与 r148 B1、r159 引力侧的同一负号**第三次**出现（跨卷一致性）。
- **D2** [BOUNDARY] 两难：F 若指合力 ⇒ 与牛顿矛盾；若非合力 ⇒ 四项诠释全部落空 — 两难（记忆纪律：归属未定写两难，两支都不利）：① 若原文的 F 是**合力** ⇒ F = −m a 与牛顿 F = +m a 直接矛盾（引力反号，与 r159「引力外推得万有斥力」同一结论）；② 若原文的 F **不是合力**（只是某个动量变化率）⇒ 它就不是力方程，四项「电场力 / 磁场力 / 核力 / 万有引力」的诠释**全部落空**。本卷不代靶决定归属，两支都登记。
- **D3** [FAIL] 「平滑退化至牛顿力学」不成立：退化出的是**反号**的牛顿力学 — 原文 §4.2 称「低速宏观极限下方程退化为 F = −m a，与牛顿力学衔接」。机读：退化结果比牛顿**精确反号**（比值 −1.000000000）⇒ 不是「衔接」，是**反号**。反号的牛顿力学给出：自由落体向上、引力变斥力（r159 同判）、圆轨道无实数解（r159 同判）⇒ 该「平滑过渡」宣称不成立。
