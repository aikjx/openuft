## 二、一步步求导证明

### 1. 参数化与弧长条件

圆柱螺旋写成
\[
\mathbf r(s)=\left(R\cos\frac{s}{L},\;R\sin\frac{s}{L},\;\frac{Hs}{L}\right).
\]
求导：
\[
\mathbf r'(s)=\left(-\frac{R}{L}\sin\frac{s}{L},\;\frac{R}{L}\cos\frac{s}{L},\;\frac{H}{L}\right).
\]
若 \(s\) 是弧长参数，则必须
\[
|\mathbf r'(s)|=1.
\]
计算：
\[
|\mathbf r'(s)|^2
=
\frac{R^2}{L^2}\sin^2\frac{s}{L}
+
\frac{R^2}{L^2}\cos^2\frac{s}{L}
+
\frac{H^2}{L^2}
=
\frac{R^2+H^2}{L^2}.
\]
因此必须取
\[
\boxed{L^2=R^2+H^2.}
\]

---

### 2. 切向量

\[
\mathbf t=\mathbf r'(s)
=
\left(
-\frac{R}{L}\sin\frac{s}{L},\;
\frac{R}{L}\cos\frac{s}{L},\;
\frac{H}{L}
\right).
\]
由上面可知
\[
|\mathbf t|=1.
\]

---

### 3. 曲率 \(\kappa\) 的求导

\[
\frac{d\mathbf t}{ds}
=
\left(
-\frac{R}{L^2}\cos\frac{s}{L},\;
-\frac{R}{L^2}\sin\frac{s}{L},\;
0
\right).
\]
曲率定义为
\[
\kappa=\left|\frac{d\mathbf t}{ds}\right|.
\]
所以
\[
\kappa
=
\sqrt{
\frac{R^2}{L^4}\cos^2\frac{s}{L}
+
\frac{R^2}{L^4}\sin^2\frac{s}{L}
}
=
\frac{R}{L^2}.
\]
即
\[
\boxed{\kappa=\frac{R}{L^2}=\frac{R}{R^2+H^2}.}
\]

---

### 4. 主法向

\[
\mathbf n
=
\frac{1}{\kappa}\frac{d\mathbf t}{ds}
=
\left(
-\cos\frac{s}{L},\;
-\sin\frac{s}{L},\;
0
\right).
\]

---

### 5. 副法向

\[
\mathbf b=\mathbf t\times\mathbf n.
\]
计算得
\[
\mathbf b
=
\left(
\frac{H}{L}\sin\frac{s}{L},\;
-\frac{H}{L}\cos\frac{s}{L},\;
\frac{R}{L}
\right).
\]

---

### 6. 挠率 \(\tau\) 的求导

对 \(\mathbf b\) 求导：
\[
\frac{d\mathbf b}{ds}
=
\left(
\frac{H}{L^2}\cos\frac{s}{L},\;
\frac{H}{L^2}\sin\frac{s}{L},\;
0
\right).
\]
而
\[
\mathbf n
=
\left(
-\cos\frac{s}{L},\;
-\sin\frac{s}{L},\;
0
\right).
\]
所以
\[
\frac{d\mathbf b}{ds}
=
-\frac{H}{L^2}\mathbf n.
\]
Frenet–Serret 方程要求
\[
\frac{d\mathbf b}{ds}=-\tau\mathbf n.
\]
比较得
\[
\boxed{\tau=\frac{H}{L^2}=\frac{H}{R^2+H^2}.}
\]

---

### 7. 恒等式

\[
\kappa^2+\tau^2
=
\frac{R^2}{L^4}+\frac{H^2}{L^4}
=
\frac{R^2+H^2}{L^4}
=
\frac{L^2}{L^4}
=
\frac{1}{L^2}.
\]
所以
\[
\boxed{\sqrt{\kappa^2+\tau^2}=\frac{1}{L}.}
\]

---

### 8. 倾角 \(\theta\)

定义
\[
\sin\theta=\frac{R}{L},\qquad
\cos\theta=\frac{H}{L}.
\]
则
\[
\frac{\tau}{\kappa}
=
\frac{H/L^2}{R/L^2}
=
\frac{H}{R}
=
\cot\theta.
\]
所以
\[
\boxed{\tau=\kappa\cot\theta.}
\]

---

### 9. Frenet 标架旋转角频率 \(\omega\)

Frenet 标架角速度矢量为
\[
\boldsymbol\omega_{\rm FS}=\tau\mathbf t+\kappa\mathbf b.
\]
其模长为
\[
|\boldsymbol\omega_{\rm FS}|
=
\sqrt{\kappa^2+\tau^2}.
\]
这是单位弧长的标架旋转角。因为
\[
ds=c\,dt,
\]
所以时间角频率为
\[
\omega
=
c|\boldsymbol\omega_{\rm FS}|
=
c\sqrt{\kappa^2+\tau^2}
=
\frac{c}{L}.
\]
又因为
\[
\sin\theta=\frac{R}{L},
\qquad
\kappa=\frac{R}{L^2},
\]
所以
\[
\frac{c\kappa}{\sin\theta}
=
\frac{c(R/L^2)}{R/L}
=
\frac{c}{L}.
\]
因此
\[
\boxed{\omega=\frac{c\kappa}{\sin\theta}=c\sqrt{\kappa^2+\tau^2}.}
\]

---

### 10. 实验室轨道角速度 \(\Omega\)

螺旋绕轴转过的角度为
\[
\varphi=\frac{s}{L}.
\]
因为 \(s=ct\)，所以
\[
\Omega=\frac{d\varphi}{dt}
=
\frac{1}{L}\frac{ds}{dt}
=
\frac{c}{L}.
\]
因此
\[
\boxed{
\Omega=\frac{c}{L}
=
c\sqrt{\kappa^2+\tau^2}
=
\frac{c\kappa}{\sin\theta}
=
\omega.
}
\]

所以：
\[
\boxed{\Omega=\frac{c\kappa}{\sin\theta}}
\]
而不是
\[
\Omega=c\kappa.
\]

## 四、验证分析结论

| 项目 | 结果 |
|---|---|
| 参数化 \(\mathbf r(s)\) | 必须写为 \( (R\cos(s/L),R\sin(s/L),Hs/L)\)，且 \(L=\sqrt{R^2+H^2}\) |
| \(\kappa=\frac{R}{R^2+H^2}\) | 正确 |
| \(\tau=\frac{H}{R^2+H^2}\) | 正确 |
| \(\kappa^2+\tau^2=\frac{1}{R^2+H^2}\) | 正确 |
| \(\tau=\kappa\cot\theta\) | 正确 |
| \(\omega=c\sqrt{\kappa^2+\tau^2}=\frac{c\kappa}{\sin\theta}\) | 正确 |
| \(\Omega=\frac{c\kappa}{\sin\theta}=\omega\) | 正确 |
| \(\Omega=c\kappa\) | **错误**，仅在 \(H=0,\sin\theta=1\) 的圆环退化情形碰巧成立 |
| 量纲 | \(\kappa,\tau\sim \text{m}^{-1}\)，\(\omega,\Omega\sim \text{s}^{-1}\)，正确 |
| 作用量系数 \(\hbar/(2c)\) | 量纲不对，需按体积元约定改为 \(\hbar/2\) 或 \(\hbar c/2\) |
| 逗号代替乘号 | Frenet 方程、\(\sqrt g\,\mathcal H\)、\(\sigma K\) 等处仍需改完 |
