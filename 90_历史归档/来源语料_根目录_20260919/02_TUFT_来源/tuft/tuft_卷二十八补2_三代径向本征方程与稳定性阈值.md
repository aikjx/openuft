## 1. 径向本征方程（稳定性算符）

拓扑孤子解 `u_s(x)` 的线性化扰动 `δu = η(x) e^{iωt}` 满足标准稳定性（Sturm-Liouville）方程：
```
( -d²/dx² + V_stab(x) ) η = ω² η ,      V_stab(x) = U''(u_s(x))
```
**关键事实**：拓扑孤子的 `V_stab` 属「反射无反射」(reflectionless) 族，最通用的精确可解代表是 **Pöschl-Teller**
```
V_stab(x) = -s(s+1)/cosh²x
束缚态闭式解：  E_n = ω_n² = -(s-n)² ,   n = 0,1,2,…  （E_n<0 为束缚）
束缚态数量 N 由势深参数 s 决定。
```
（这是 φ⁴-kink、sine-Gordon 孤子稳定性算符的通用数学结构：形状模 = sech² 势的束缚态。）

## 2. 数值验证（§A）

有限差分（dr=0.02，L=60，tridiagonal 精解）与解析 `E_n=-(s-n)²` 逐点一致：

| s | N_bound | E_num | 解析 -(s-n)² |
|---|---|---|---|
| 1.0 | 1 | −1.0 | −1 |
| 2.0 | 2 | −4.0, −1.0 | −4, −1 |
| 2.5 | 3 | −6.25, −2.25, −0.25 | −6.25, −2.25, −0.25 |

| 4.0 | 4 | −16, −9, −4, −1 | 同 |
| 10.0 | 10 | −100, −81, … | 同 |

✅ **[PASS]** 数值与解析最大偏差 5.19e-02（有限差分截断量级）。
**重要发现**：原稿「模态谱 1:4:9」并非任意——**它恰是 Pöschl-Teller s=3 的精确束缚态谱**（|E| = 9,4,1）。即「粒子代 = 离散束缚模态」是孤子稳定性算符的**通用特征**（非人为）。

## 4. 质量比匹配：3 能级谱只有 1 个自由参数（§C）

3 束缚态窗口 `s∈(2,3]`：`|E| = s², (s-1)², (s-2)²`（最重 = gen3）。
两个独立质量比：
```
r1 = m3/m1 = s²/(s-2)² ,    r2 = m2/m1 = (s-1)²/(s-2)²
```
**问题**：3 能级谱只有 **1 个自由参数 s**，却有 **2 个比值要匹配** ⇒ 一般不可同时匹配。

实跑（由 r1 反解 s，再预测 r2 与实测比）：

| 味 | 目标 r1 | 目标 r2 | 反解 s | 预测 r2 | 偏差 |
|---|---|---|---|---|---|
| 带电轻子 e:μ:τ | 3477.2 | 206.8 | 2.0345 | 899.0 | **4.35×** |
| 上型 u:c:t | 79981 | 136.0 | 2.0071 | 20137 | **148×** |
| 下型 d:s:b | 895.1 | 44.9 | 2.0692 | 239.0 | 5.32× |

（核对：s=3 → |E|=9,4,1 → m1:m2:m3 = 1:4:9，即原稿谱。）

❌ **[FAIL]** 三组味**全部**只能匹配一个比值；**第二个比值偏 4.35×（轻子）/ 148×（上型）/ 5.32×（下型）**。
⇒ **一张 3 能级拓扑阶梯在数学上无法同时给出 SM 的两个独立质量比。**

## 5. 谱形方向性错误（§D）

相邻比 `(s-n)²/(s-n-1)² = (1 + 1/(s-n-1))² → 1`（s 增大时）：

| s | 相邻比 |
|---|---|
| 3.0 | 2.25, 4.00 |
| 5.0 | 1.56, 1.78 |
| 10.0 | 1.24, 1.27 |
| 30.0 | 1.07, 1.07 |

❌ **[FAIL]** **方向性错误**：s 越大谱越**近简并**（相邻比→1），与 SM 需要的巨大层级（1:207:3477）**方向相反**。要大连层级须 `s→2⁺`，但那时第三个束缚态 `E→0⁻` 几近**离域**。
⚠️ **[BOUNDARY]** `s→2⁺` 可达大连层级，但第三态趋于离域（稳定性/可辨识性存疑）。
