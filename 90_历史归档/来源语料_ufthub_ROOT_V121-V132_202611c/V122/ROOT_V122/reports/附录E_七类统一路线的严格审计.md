# 附录 E｜从 ROOT 空间螺旋到量子场论：七类统一路线的逻辑审计

这是一份**路线决策图**，不把数学上的可构造性宣称为自然界已经验证的物理事实。

## 1. ROOT 的三维圆柱螺旋：仅有运动学，不是场论

给定

$$\mathbf r(t)=(R\cos\omega t,R\sin\omega t,pt),\qquad
v^2=(R\omega)^2+p^2.$$

若把三维总速率设为 $c$，则有 $(R\omega)^2+p^2=c^2$。不能再额外令轴向 $p=c$ 且 $R\omega\ne 0$，否则在同一个三维参考系超过光速。对带质量的观测者，$|\mathbf v|<c$；对光子，不存在普通的静止参考系。可将螺旋作为场振幅/相位的空间图像，但其图像自身不提供光子世界线的可观测内部超光速自由度。

更强的必要条件是同时展示 $\omega$、曲率 $\kappa$、挠率 $\tau$ 经过 Lorentz 变换后的可观测预测，并证明归一化条件是协变定义而非某个坐标下的巧合。

## 2. 5D 零线元与 Kaluza–Klein 塔

对最简单平坦额外紧致维 $y\sim y+2\pi L$，可写

$$ds_5^2=\eta_{\mu\nu}dx^\mu dx^\nu+dy^2.$$

第五维动量量子化 $p_5=n\hbar/L$。若高维场无质量，4D 模式满足

$$E_n^2=(\mathbf p c)^2 +m_n^2c^4,\qquad
m_n=|n|\frac{\hbar}{Lc}.$$

这是正确的 KK 运动学，但并不自动给出标准模型的 $SU(3)\times SU(2)\times U(1)$ 手征粒子谱、三个世代或观测到的质量等级。$L$ 仍是新自由参数；若拿测量到的电子质量反算 $L$，只是用电子质量定义半径，不能称独立预测。

## 3. Einstein–Hilbert + Standard Model：统一写法≠统一物理来源

在自然单位下可以写

$$S_{\rm EFT}=\int d^4x\sqrt{-g}\left[
\frac{M_P^2}{2}R-\frac14\sum_{a}F^a_{\mu\nu}F^{a\mu\nu}
+\bar\psi i\gamma^\mu D_\mu\psi + |D_\mu H|^2-V(H)+\cdots\right].$$

这保证了在定义域内已有规范场、粒子与引力耦合能以协变方式共同表示。它既未推导强弱电规范耦合的共同起源，也未解决量子引力在任意高能处的有效性问题。ROOT 必须给出超出“把成熟项写在一个式子里”的可计算差别。

## 4. 曲率二次项 $R^2$：额外标量，不是四力统一

其 4D 动力学相当于 GR+一个带势能的普适耦合标量（在适当条件下）。$\alpha_Y=1/3$ 在线性化、未屏蔽与点源极限下固定，而标量质量与作用程由 $R^2$ 系数确定。若 ROOT 对此只有同样的预测，则它目前只是一种已有模型的重述；需要给出不同、且可验证的新预言才有研究优势。

## 5. 简单规范群 GUT（例如 SU(5)、SO(10)）

这些方案可以在更高能标中使三个规范耦合运行的关系获得约束，但必须具体处理规范玻色子谱、手征表示、对称性破缺链、质子衰变及中微子质量。直接引入规范群不自动决定实验上观测的全部参数，必须逐项与既有高精度实验对比。ROOT 的曲率/挠率若参与该结构，应明确如何映射到规范联络与表示，而不是把曲率、挠率直接命名为强/弱力。

## 6. 振幅双拷贝、弦论、量子引力等不同候选方法

色—运动学对偶与双拷贝在某些散射振幅结构上联系规范理论和引力，是值得研究的数学桥梁；但不能直接证明现实标准模型 + 宏观引力唯一来自同一三维几何螺旋。弦论/其他量子引力方案同样有非平凡谱、低能极限与可证伪性问题。应逐项审查物理假设，而非累加比喻。

## 7. 从观测反推：把“解释所有”改为“预先下注一个区分性预言”

最低标准为：

- **不含事后可调参**：事先固定新机制会怎样改变某个可测物理量。
- **物理可辨识**：该改变不能被共同 $GM$、校准漂移、地球球谐或者其他未约束的系统误差严格模拟。
- **定量闭环**：从同一作用量得到运动、红移、光传播以及量子可观测量；常数和单位自洽。
- **失败后状态更新**：明确拒绝被证伪的版本，而不是在保持同一名称时悄悄调整参数。

### 当前路线优先级

第一优先：V119 固定的 124.6 km、$1/3$ Yukawa 候选在真实低轨证据下能否幸存；第二优先：构造并验证一个能连接 ROOT 螺旋与局域规范/引力作用量的协变映射；第三优先：从该映射独立预测至少一个与已有 $f(R)$ 不同的无量纲比值。前两项没有结果前，不能宣称完成四力统一。
