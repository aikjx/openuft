9'. **解析预期符号写反（V18_6）**：解析 Twist 误用反序叉积 `(du/ds × u)·T` 得 `Tw = -n`；标准式 `Tw = (1/2π)∮ (u × du/ds)·T ds` 给 `+n`。数值一直正确（`|Lk|=1.00020 / 2.00074` 对 `n=1/2`），错的是解析预期，由 SC4 抓出。教训：**数值—解析对拍时先查自己的符号约定，不要先怀疑数值**。
