## 一、一句话结论

**「整性把通量限制住」这句话在本卷被彻底拆开**：`a_j ∈ Z` 与 `Z ⊆ S` 都是关于**多项式**的平凡事实（前者是有限差分的整数组合，后者是 `S` 的定义），对任意射影簇都成立、判别力为 0；r339 拿它们当几何定理是**读高了**。真正有内容的只有两条初等定理：**分母整除首项 Newton 系数**（`k = r/M ∈ S ⇒ M | a_n`，无任何假设）与**陪集内积分性的周期性**（⇒ `S` 是有限个等差级数之并）。前者把 `S` 压进 `(1/d)Z`，后者解释掉 r339 的「非陪集」。

## 三、引理 L：三行证明

设 `P ∈ Q[k]`、`deg P = n`、`P(Z) ⊆ Z`。则 Newton 系数

```
a_j = Δ^j P(0) = Σ_{i=0}^{j} (-1)^{j-i} C(j,i) P(i)          (★)
```

是**整数的整数组合**（`C(j,i) ∈ Z`、`P(i) ∈ Z`）⇒ `a_j ∈ Z`。∎

**这条证明没有用到任何几何**：主语是多项式，不是流形。`(★)` 的机械核对见 `A01`：**130 项（30 组 × (n+1)）逐项一致，失配 0**。

**前提不可去**（`A02`）：三个 `P(Z) ⊄ Z` 的多项式（`k/2`、`k²/2`、`C(k,2)+k³/3`）的 Newton 系数**全部非整**，3/3 命中 ⇒ 前提是真前提，不是装饰。

**无几何版直接构造**（`A03`）：`P(k) = C(k,2) + 3C(k,3)` 不对应任何射影簇，`a_j = (0,0,1,3)` 全整、`P(Z) ⊆ Z` 在 `k = −8..8` 全 17 点成立 ⇒ **同一个引理，零几何输入**。

## 五、引理 Z：`Z ⊆ S` 的全域性与零判别力

`S := {k ∈ Q : P(k) ∈ Z}`。由于 `χ ∈ Z` 对一切整数 `k` 成立，`Z ⊆ S` 对**任意射影簇 + 任意线丛**都成立。r339 把它写成「整性从不排除整数通量」是对的，但那是**定义的同义反复**：`S` 里必然包含所有整数，因为 `S` 是按「`χ` 是否整」定义的，而 `χ` 在整数处当然整。

这不是「结论变弱」，而是**读法要改**：`Z ⊆ S` 这条信息量恰为 0；有信息量的是 `S \ Z`（额外点）与 `S` 的上界。

## 六、定理 C：分母整除首项（本卷的主产出）

> **定理 C**（**无假设**）。设 `P(k) = Σ_{j=0}^{n} a_j C(k,j)`（`a_j ∈ Q` 任意）、`a_n ≠ 0`。若 `k = r/M` 为最简分数（`M ≥ 2`）且 `P(k) ∈ Z`，则 `M | a_n`。

**证明（四行）**。以 `M^n n!` 乘之：

```
M^n n! P(r/M) = Σ_j a_j (n!/j!) M^{n-j} N_j(r),   N_j(r) = Π_{i<j} (r - iM)
```

左端被 `M^n n!` 整除 ⇒ 被 `M` 整除。取模 `M`：`N_j(r) ≡ r^j (mod M)`，而 `j < n` 的项还带 `M^{n-j}`（`n-j ≥ 1`）⇒ 全部消掉，只剩 `j = n`：

```
0 ≡ a_n r^n (mod M).   由 gcd(r,M) = 1 ⇒ M | a_n.   ∎
```

**注意这里没有任何关于 `a_j` 的假设** —— 连 `a_j ∈ Z` 都不需要。`(★)` 的两步机制由 `B02` 机械核对：`N_j(r) ≡ r^j (mod M)` 在 **900 个 `(M,r,n,j)` 三元组**上失配 0。

**主验证 `B01`**：72 组 × `M ≤ 24` 全扫，出现的 `M` 全部整除 `a_n`，**违例 0**。
**`a_n = d` 独立核对 `CTL11`**：`a_n` 恒等于次数（`72` 组，违例 `0`）—— 因为 `P` 的首项系数是 `d/n!`，而 `Δ^n P(0) = n!·(首项系数)`。

## 八、定理 D：陪集内周期性 ⇒ 有限个等差级数之并

> **定理 D**。固定 `c ∈ (1/M)Z`，令 `Q(m) = P(c+m)`，`b_i = Δ^i Q(0)`。则 `M^n n! b_i ∈ Z`，取 `N0 = (M^n n!)^2` 即有 `Q(m+N0) − Q(m) ∈ Z` ⇒ `{m : Q(m) ∈ Z}` 以 `N0` 为周期。

**键恒等式 `C01`**：`b_i = Σ_{j≥i} a_j C(c, j−i)`（即 `Δ^i C(x,j) = C(x,j−i)`）—— **396 个陪集，失配 0**。
**键整性 `C02`**：`M^n n! b_i ∈ Z` —— **1782 项，非整 0**。
**上界合法性 `C04`**：实测周期 `N ≤ (M^n n!)^2` **81 个陪集全部成立**（上界是粗界，只作合法性不作紧性）。

**实测周期 `C03`**：81 个「窗口内至少 2 个整点」的陪集，最小周期取值 `{1, 2, 4, 16, 32, 64}`，最大 **64**（其中 `N=1` 占 70 个 —— 即整段陪集全中）。

**结构推论 `C05`**：按陪集逐个重构的 `S`（每陪集独立判定）与直接穷举的 `S` **完全相同**，30 组失配 0 ⇒ **`S` 是有限个等差级数之并**。

**这直接解释掉 r339 的「非陪集」**：`Z ∪ (Z + 1/2)` 这类并集当然不是任何 `aZ+b` 的陪集 —— 所以 r339 在 `(3,2)` 上看到的 `u−v+w = −9/2 ∉ S`（`u=−6, v=−11/2, w=−4`）不是「混乱」，而是**两个不同模数的等差级数拼在一起**。仿射封闭在并集上失败是**结构性必然**。

**稀疏化 `C06`**：`c = 1/2` 陪集在 `[-240,240]` 内的整点数：`n=5 → 7`、`n=6 → 0`、`n=7 → 1`（两条独立路径给出同一组数：直接扫描 vs 陪集枚举）⇒ 周期随 `n` 迅速变长，额外点趋于消失。

## 十、判据与方法（本卷沉淀）

1. **一条谓词若 100% 输入通过，它不是判据**。`a_j ∈ Z` 对任意正确计算恒真 ⇒ 只能当 bug 探测器；要当判据必须给出「什么情况下它会假」，本卷给的是 `A05`（算错则假 27/30、29/30）与 `A06`（但漏 3 组、1 组）。
2. **必要非充分要说清**：`a_j ∈ Z` 通过 ≠ 算对。`(1,2)` 错给 `(0,2)` 仍全整 —— 这类「整数守恒的错」是最好骗过筛子的错。
3. **证明要问「主语是谁」**：引理 L 的主语是多项式；把它套在 `χ` 上不增加任何几何内容。凡「定理」只用到 `χ ∈ Z`，它就没用到流形。
4. **期望值不得猜**：`C06` 首跑期望写成 `7,1,1`（猜的），实测 `7,0,1` ⇒ 改为**两条独立路径交叉**（直接扫描 vs 陪集枚举），期望取自另一条路径。
5. **结构性重构不得依赖「能不能测出周期」**：`C05` 首跑在周期超窗时把整个陪集丢掉 ⇒ 重构缺项 ⇒ 3 组假 FAIL。
6. **口径窗口必须两端一致**：探查脚本的穷举分支没夹 `[-6,6]`，与网格分支差一两点 ⇒ 4 组假「口径差」（`CTL8` 专守这条）。
7. **敏感性检验要打在「被钉住的位」上**：翻转自由位当然仍可行；`E03` 首跑正因打错方向而假 FAIL，而「自由位有 2 个」本身升格为 `E02` 的读数。
8. **假守卫三字母就能让门禁变装饰**：本卷首跑自己写了三处 `guard(..., True, ...)`（`G04/G09/G17`）⇒ 新增 `G19` 做结构性防线（`ctl/guard` 的 `ok` 顶层不得是常量；负对照实测：写死 `True`/`False` 被抓、真判据放行）。
9. **守卫不得读自己源码的字符串字面量**（本库第三次踩）：`src.count("random")` 数到了守卫自己那行 ⇒ 一律改 **AST 层**判 `Import` / `Constant` 类型。

2. `a_n = d` 依赖 `X_d ⊂ CP^{n+1}` 的光滑性与 `H^n = d`；一般极化簇上定理 C 仍成立，但推论要换成 `S ⊆ (1/H^n)Z`。
3. 定理 D 的周期界是**粗界**，且实测周期随 `n` 迅速变长（`n=7, d=2` 的 `c=1/2` 陪集在 `[-240,240]` 只有 1 点）—— 「有限个等差级数之并」是**结构陈述**，不排除「几乎为空」。
4. `C03` 的周期是在窗口 `[-96,96]` 内测的；超出窗口的周期无法排除，故只报「实测最小周期 ≤ 64」。
5. 72 组样本（`n ≤ 6, d ≤ 12`）不是穷举；定理 C 的证明是**一般证明**（不依赖样本），但 `B04` 的尖锐性（`n=1` 精确）只机检到 `d = 24`。
6. 「判别力 0」是针对 `Z ⊆ S` 这个**特定谓词**说的，不是说 r339 全卷无价值：r339 的 `X-R335-2` 关闭与 `Z+1/2` 坐标假象两条结论**不受影响**。
7. 本卷不改 r339 任何文件字节；只读其落盘 JSON 作跨卷回验（`G11`）。
