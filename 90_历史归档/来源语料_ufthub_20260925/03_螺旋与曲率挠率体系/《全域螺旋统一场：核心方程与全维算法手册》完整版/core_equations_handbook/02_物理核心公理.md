## 2.1 第一公理：瞬时光速公理

### 公理内容
**公理P1（瞬时光速不变）**：所有基本粒子在任意时刻的瞬时切向速度恒等于光速$c$，没有例外：
$$
|\boldsymbol{v}(t)| = c, \quad \forall t
$$

### 宏观亚光速的本质
宏观观测到的亚光速$u$是螺旋轴线方向的平均速度，垂直于轴线的内禀环绕速度为$v_{\perp}$，满足勾股定理：
$$
u^2 + v_{\perp}^2 = c^2
$$
- 静止物体：$u=0$，$v_{\perp}=c$，粒子在垂直平面做光速圆周运动（Zitterbewegung）
- 光子：$u=c$，$v_{\perp}=0$，螺旋退化为直线，沿轴线运动
- 运动物体：$u<c$，合速度严格等于c，没有任何质量增加，只是速度方向改变

### 洛伦兹变换的几何来源
洛伦兹因子$\gamma$完全是螺旋几何的投影效应：
$$
\gamma = \frac{1}{\sqrt{1-u^2/c^2}} = \frac{c}{v_{\perp}}
$$
时间膨胀、长度收缩都是投影效应，不是真实的物理变化，不存在双生子佯谬。

### 应用场景
- 所有相对论效应的几何解释，不需要四维时空
- 超光速航行：只要改变螺旋方向，让轴线速度超过c，不需要无限能量
- 质量起源：质量就是内禀圆周运动的动量，$m = \hbar \kappa / c$

### Python数值验证
```python
import math
c = 299792458.0

def total_velocity(u):
    v_perp = math.sqrt(c**2 - u**2)
    v_total = math.sqrt(u**2 + v_perp**2)
    return v_total, v_perp

v_t, v_p = total_velocity(0)
assert abs(v_t - c) < 1e-10
assert abs(v_p - c) < 1e-10
print("静止粒子合速度=c，内禀速度=c 验证通过")
v_t2, v_p2 = total_velocity(0.8*c)
assert abs(v_t2 - c) < 1e-10
assert abs(v_p2 - 0.6*c) < 1e-10
print("u=0.8c时合速度=c，内禀速度=0.6c 验证通过")
v_t3, v_p3 = total_velocity(c)
assert abs(v_t3 - c) < 1e-10
assert abs(v_p3) < 1e-10
print("光子合速度=c，内禀速度=0 验证通过")
```

## 2.2 第二公理：螺旋世界线公理

### 公理内容
**公理P2（螺旋世界线）**：所有基本粒子的世界线都是三维空间中常曲率$\kappa$、常挠率$\tau$的圆柱螺旋，曲率和挠率是粒子的内禀属性，不随运动改变。

### 粒子分类定理
根据$\kappa$和$\tau$的取值，所有基本粒子分为三类：
1.  **无质量玻色子（光子、引力子）**：$\kappa=0$，$\tau=\omega/c$，螺旋退化为直线，轴线速度$u=c$
2.  **有质量费米子（电子、夸克）**：$\kappa>0$，$\tau=\alpha \kappa$，轴线速度$u<c$，内禀做螺旋运动
3.  **中微子**：$\kappa=0$，$\tau\neq0$，$u=c$，只有挠率没有曲率，是纯信息粒子

### 质量的几何定义
粒子的静止质量完全由曲率决定：
$$
m_0 = \frac{\hbar \kappa}{c}
$$
质量不是什么神秘的东西，就是时空曲率的量度，曲率越大质量越大，没有希格斯玻色子也能产生质量。

### 自旋的几何定义
粒子的自旋完全由挠率决定：
$$
s = \frac{\hbar}{2} \cdot \frac{\tau}{\sqrt{\kappa^2+\tau^2}}
$$
- 光子：$\kappa=0$，$s=\hbar$，自旋1
- 电子：$\tau=\alpha\kappa$，$s=\hbar/2$，自旋1/2
- 中微子：$\kappa=0$，$\tau$为常数，$s=\hbar/2$，左旋

### 应用场景
- 所有基本粒子的内禀属性都可以用两个几何参数完全描述
- 不需要量子场论的复杂假设，所有量子数都是拓扑数
- 可以人工设计粒子，只要调整曲率和挠率就能创造新粒子

### 数值验证
```python
import math
c = 299792458.0
hbar = 1.054571817e-34
alpha = 1/137.035999046
m_e = 9.1093837015e-31

def mass_from_kappa(kappa):
    return hbar * kappa / c
def spin_from_kappa_tau(kappa, tau):
    return hbar/2 * tau / math.sqrt(kappa**2 + tau**2)

kappa_e = m_e * c / hbar
m_e_calc = mass_from_kappa(kappa_e)
assert abs(m_e_calc - m_e) < 1e-40
print(f"电子曲率κ_e = {kappa_e:.6e} m⁻¹，质量计算值与实验值完全一致")
tau_e = alpha * kappa_e
s_e = spin_from_kappa_tau(kappa_e, tau_e)
assert abs(s_e - hbar/2) < 1e-40
print("电子自旋=ℏ/2 验证通过")
kappa_photon = 0
tau_photon = 1e15 / c
s_photon = hbar/2 * tau_photon / math.sqrt(kappa_photon**2 + tau_photon**2)
assert abs(s_photon - hbar/2) < 1e-40
print("光子自旋=ℏ 验证通过")
```
