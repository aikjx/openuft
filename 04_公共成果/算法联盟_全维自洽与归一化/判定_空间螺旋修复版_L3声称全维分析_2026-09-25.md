## 3. 逐条判定

### 3.1 公理1 基底 R(t) = (A cos ωt, A sin ωt, c t) —— FAIL

把轴向分量写死为 `c·t` 后：

\[
|R'|=\sqrt{A^2\omega^2+c^2}\;>\;c\quad(\text{只要 }A\omega>0)
\]

与本体「空间中每一点作**光速**螺旋运动」直接冲突。更尖锐的是：**为了让 §2 的 α 公式命中观测**，必须取

\[
\frac{\omega A}{c}=\frac{1}{2\sqrt{N}\,\alpha}=0.49830284
\;\Longrightarrow\;
|v| = \sqrt{1+0.4983^2}\,c = 1.117276\,c
\]

即**超光速 11.73%**。这是本次审计最硬的一条数值结果：不是「暂时未定」，而是「要匹配 α 就必须超光速」。

若改按「读数B」（恢复原约束 ω√(A²+b²)=c，则 c 不是轴向速率），超光速消失，但 τ/κ = b/A ≠ c/(ωA) = secθ ⇒ **同一式子在两种合规补全下给出不同的 τ/κ**，且要求二者同为 τ/κ 会推出 tanθ = secθ（sinθ=1，无解）。

> **最小修复**：把第三分量改为 `b·ω·t`，并显式重列 `ω√(A²+b²)=c`。这一步是**纯形式替换，零代价**，建议采用。

### 3.2 α = (1/(2√N))·c/(ωA) —— FAIL（三条独立理由）

| 理由 | 数值证据 |
|---|---|
| **不可证伪**：两个未知量（N、ωA）对一个方程 | N 取 4695 / 18907 / 1e5 / 1e9 **四个数量级**，反解 ωA 后重算 α 的偏差均 < 2.7e-51；读数B 下唯一被排除的只是 N < 4694.7，读数A 下连该约束也没有 |
| **判别式 V = −2 ≤ 0** | n_hit=1（α）· n_free=2（N、ωA）· n_anchor=1（c）⇒ 落在「净消耗」区，与 M02 普朗克锚定谬误（V=−3）同型 |
| **tanθ 冲突由二方扩为四方** | tanθ 同时被要求为 0.0072974（原主体 α=τ/κ）／137.503（原拓扑绕数 √N）／2.00681（修复版读数A）／1.73991（修复版读数B） |

所谓「彻底消解 tanθ 与 α 的数值矛盾」的**实现方式是新公式不再使用 α=τ/κ**——即把冲突的一侧删掉，而不是把两侧调和。原 claims C03 与 C23 仍然有效且互斥。

补充一条社论式的定量：在相容读数B下（恢复光速约束且保留 α=τ/κ），该公式给出

\[
\alpha_{\rm pred}=\frac{\sqrt{1+\alpha^2}}{2\sqrt{N}}=3.6364\times10^{-3}
\]

比观测值低 **50.17%**，是观测不确定度（1.5e-10）的 3.3×10⁹ 倍。

> 这不是孤例。openuft **定理 H** 已证：7 个初等几何作用量无一能把 α 固定到 1/137；**定理 C 情形 2** 已证：含未测量自有量的等式等价于该量的定义。ωA 正是未测量自有量。

### 3.3 N = ⌊2π/Δθ_min⌋ —— FAIL / BOUNDARY

- **floor 取整使定义 A 不可复现**：定义 A = 1/[α²(1−α)] = **18916.90839 非整数**，而 ⌊·⌋ 只能产出整数 ⇒ 「彻底消除双值冲突」实为**抛弃其中一个值**。C21 在台账中仍为 falsified。
- **Δθ_min 无第一性来源**：要复现 N=18907 需 Δθ_min = 3.323206e-4 rad，文中未给任何推导或约束方程 ⇒ 自由度从「N 手填」平移为「Δθ_min 手填」，**总数不降**。

### 3.4 G = c⁴α²/(8πK₀) —— FAIL（三处硬伤）

1. **量纲**：[K₀] = [c⁴]/[G] = **[L¹M¹T⁻²]（牛顿·力）**，而曲率量纲为 [L⁻¹] ⇒ 把 K₀ 称做「时空基底曲率」与量纲账本**直接冲突**。反解值 K₀ = 2.5642944e+38 N = α²·F_Planck/(8π)，没有任何已知物理量在该量级上**独立**存在。
2. **Buckingham Π 定理**：声称「K₀ 可由 N、α 直接推导」不成立——**无量纲输入不可能产出有量纲输出**。这是结构性不可能，不是精度问题。
3. **循环性搬家**：原式 ρ = √(G/(α²μ₀c²)) 由 G 反推；新式 K₀ = α²c⁴/(8πG) 同样由 G 反推。**两式同构**，故 C12 的 falsified 标记**不能被撤销**。

> 顺带给出正确的靶：有意义的是无量纲的 **α_grav(m) = Gm²/(ℏc) = (m/m_P)²**。「导出 G」等价于「导出 m_e/m_P」——只有后者才是 openuft 登记的无量纲靶，且必须**带预测值与误差棒**（本体系现登记 0 条）。

### 3.5 ρ = (1/V)∮S·dl —— FAIL

要给出质量密度 [M·L⁻³]，S 必须具有 **[M·L⁻¹]（质量每长度）** 的量纲——这不是任何标准「通量矢量」的量纲；且通量的自然积分域是**面积 dA** 而非线元 **dl**（范畴错误）。此外，修复版把 ρ 从 G 中移除后，**10 个子系统中无任何方程消费 ρ** ⇒ ρ 成为孤儿量。

> 诚实的建议：**直接删除 ρ**。删除依赖本身就是进步，再把它请回来只会新增一个 U 类项。

### 3.6 场耦合方程 —— FAIL（四处）

- **∇×B = (1/c²)∂E/∂t + α²K(R)**：标准两项量纲一致（✓ 这是全文**唯一通过**的量纲检查），但 [α²K] = [L⁻¹] 与其余各项 [L⁻¹M¹T⁻²I⁻¹] 相差 [M¹T⁻²I⁻¹]，非无量纲 ⇒ 附加项量纲失败。
- **缺少 μ₀J**：稳恒情形要求 α²∫K·dA = μ₀I_enclosed 对**一切**电流分布成立 ⇒ 这等于把 K 规定为电流分布的泛函，与「K 为时空曲率」的定位冲突。
- **电荷守恒**：取散度得 ∇·J = (α²/μ₀)∇·K。若 ∇·K≡0 则该项无源（无法担当「几何源」）；若不恒为零则电荷守恒被修改。文中两者都未声明。
- **F_grav = −G m₁m₂/r² · ∇Φ/Φ₀**：设 Φ∝r^n ⇒ 力律为 r^(n−3)。恢复牛顿 1/r² **唯一要求 n=1**，此时 ∇Φ/Φ₀ 为常数，可整体吸收进 G ⇒ **零内容**；n≠1 则不再是 1/r²，与行星闭合轨道冲突（**Bertrand 定理**：仅 1/r² 与 ∝r 给出闭合稳定轨道）。另 [Φ₀] 必须等于 [∇Φ]=[Φ]/L 而非 [Φ]，记号上也不自洽。

### 3.7 公理2 ∇Φ ≡ K —— BOUNDARY（可接受，但不可计入 L3）

量纲可相容（Φ 取无量纲相位时 [∇Φ]=[K]=L⁻¹），但**类型不匹配**（向量 ≡ 标量）。本质是给同一数学对象换名字——本仓库 UFT 体系已有同类桥接 `κ = ½|∇ln β₁|`。作为约定可接受，**不得**计入「L3 第一性推导」的证据清单。
