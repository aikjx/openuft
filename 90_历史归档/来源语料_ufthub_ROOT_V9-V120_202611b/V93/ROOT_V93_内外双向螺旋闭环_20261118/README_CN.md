## 这次真正研究了什么

从 V92 的无限圆柱螺旋推进到数学上闭合的三维环面螺旋：

`r(u)=((R+a cos nu) cos mu,(R+a cos nu) sin mu,a sin nu)`，R>a>0。

核心结果：

- **空间闭合条件：** m/n∈Q；m,n 正整数的原始周期 U=2π/gcd(m,n)。
- **内外半径循环：** ρ=R+a cos(nu)，在 R−a 与 R+a 之间来回变化。
- **恒速时间重参数化：** `dt/du=σ/(βc)`，`σ=sqrt((an)²+m²ρ²)`；几何可以令 β=1，但真实带质量粒子必须 β<1。
- **角速度和半径联动：** `Ω=mβc/σ`，内部角速度比外部大。
- **曲率挠率计算：** 全路径三阶微分、Frenet 曲率挠率，严禁套用 V92 无限圆柱常量关系。
- **逆动力学：** `|F|=γm0(βc)²κ`，只是外力需求，不是新自然定律。
- **理想周期总冲量与净功：** 皆为零；真实带电粒子可能辐射，不是永动机。
- **磁矢势环路积分：** `∮A·dl=π B (m/g)(R²+a²/2)`，不自动量子化。
- **结与曲率：** (m,n)=(2,3) 为三叶结；数值总曲率大于 4π，符合 Fáry–Milnor 定理。
- **四力统一状态：** 仍无独立作用量、标准模型粒子谱和 G 来源的完整推导，属于 OPEN。

## 立即复现

需要 Python 3.10+；Windows 双击 `RUN_WINDOWS.bat`，Linux/macOS 执行 `sh RUN_LINUX_MAC.sh`。或在解压后根目录：

```bash
python -m pip install -r requirements.txt
python verify_checksums.py    # 建议先检查原始交付；重新生成文件后哈希可能变化
python run_all.py            # 运行单测、SymPy、量纲、85 位交叉积分、图像
```

浏览器脚本还需要 Playwright Python 包和 Chromium 可执行文件，属于可选附加验证：

```bash
python -m pip install playwright
python web/browser_smoke.py
```

浏览器验证脚本默认要求系统存在 `/usr/bin/chromium`，若在 Windows 上请将脚本 `executable_path` 改为本机 Chromium 路径，或使用 Playwright 安装的浏览器。HTML 本身不依赖网络，直接双击 `web/index.html` 即可在常规浏览器打开。部分受限测试环境禁止自动访问 file://，此时脚本加载同一 HTML 文本进行交互测试，而**不声称 file:// 实际通过**。
