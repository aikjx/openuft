## 0. 判决摘要

**一句话：相变可被描述（唯一存活图像是「挠率释放」），但不可被判决——守恒律是一维连续族（自由权重 w），且全部候选守恒量都不含质量分量，能量收支无法计算。**

因此本册**修正** S03-V18.5 的裁决：分支三不是「可行」，而是**「可执行、已执行、结论为不可判决」**。

| 项 | 裁定 | 一句话理由 |
|---|---|---|
| 零模条件 | BOUNDARY | 取决于守恒量的选择：m' 比例于 ∫tau ds 时零模是 ∫tau ds = 0，**不是** tau 恒 0；V5-d 的否证不得外推 |
| 构造族内非平凡闭合零模 | FAIL | 61 点全矢量残差搜索，最小非平凡残差 0.157 m（远离闭合）；唯一闭合零模是平面圆 |
| 步长收敛 | INFO（正面） | 残差在 6000→48000 步之间逐位一致，说明残差是真实物理结果而非积分误差 |
| 缠绕数可用性 | BOUNDARY | Călugăreanu–White 只对闭合曲线成立；本构造族内 Lk = 0，一般情形未判定 |
| 守恒律唯一性 | FAIL | C2/C3/C4 全部保留，C4 为含自由权重 w 的连续族；Fáry–Milnor 对 w 属于 [0,1] 一律放行，无筛选力 |
| 可判决性 | FAIL | 一维连续族 vs 单条数据 ⇒ 参数 1 / 约束 1 欠定，任何数据都能被某个 w 拟合（同 C0023 型） |
| 质量/能量侧 | FAIL | 全部几何候选量纲为 1，机器枚举确认质量分量为 0；能量收支须外加 G ⇒ 落回公设边界 |

## 1. 任务与口径

S03-V18.5 把三条分支裁为：分支一阻塞（耦合常数的质量量纲）、分支二阻塞（挠率能量与 k 平行 B 互斥）、**分支三输入全部存活故执行**。本册执行分支三，追问：类时孤子（m' 大于 0）与光子零模（m' = 0）之间的「相变」若存在，什么量守恒？该守恒律能否由公设唯一确定？

红线：

1. 全部结论为**可否证性裁定**，不含正面支持证据。
2. 数值只用于裁定自洽性与可判决性，**不用于拟合任何实验值**。
3. 构造中的 kappa、tau 取值是构造性选择，**不声称代表任何真实粒子**。
4. **「守恒律不可判决」不得改写为「守恒律不存在」**——两者严格区分。

## 2. 零模条件的精确化（V6-a）

上一轮 V5-d 判定：在单条空间曲线的 F–S 实现下，「能量来自 ∫tau dS」与「k 平行 B」不可共存，因为 B 平行于固定方向时 dB/ds = 0 蕴含 tau 恒 0。

但零模的必要条件**取决于守恒量的选择**：

| 零模定义 | 条件 | 与 V5-d 的关系 |
|---|---|---|
| 逐点条件 | tau(s) 恒 0 | V5-d 已否证其与挠率型能量的共存 |
| 积分条件（来稿 §1 赋值） | ∫tau ds = 0（净扭转抵消，tau 可变号） | **V5-d 不可外推** |

**登记要求**：后续任何「零模」叙述必须声明采用哪一条，否则会出现「零模蕴含平面」的伪推论。

## 3. 构造族内的存在性判定（V6-b / V6-b-conv / V6-b-Lk）

### 3.1 构造族与积分器验证

构造：kappa 恒为 1 每米、L = 2π/kappa、tau(s) = −amp·cos(s)（变号）。积分器先在 amp = 0（平面圆，应精确闭合）上验证：

| 量 | 值 |
|---|---|
| 闭合残差 | 2.594e-14 m |
| 总曲率 TC | 6.283185307 |

积分器可信。

### 3.2 步长收敛（正面读数）

| amp | 6000 步 | 12000 步 | 24000 步 | 48000 步 |
|---|---|---|---|---|
| 0.50 | 1.537 | 1.537 | 1.537 | 1.537 |
| 1.00 | 2.878 | 2.878 | 2.878 | 2.878 |
| 1.50 | 3.852 | 3.852 | 3.852 | 3.852 |
| 2.00 | 4.351 | 4.351 | 4.351 | 4.351 |
| 2.50 | 4.384 | 4.384 | 4.384 | 4.384 |

（单位 m，残差与步长**逐位一致**）本构造族的 RK4 积分已达机器精度，残差是真实物理结果。

### 3.3 全矢量搜索结果

61 个 amp 网格点（步长 0.05，RK4 48000 步）：

- 非平凡最小残差 **0.157046 m**（在 amp = 0.05 处），远离闭合；
- amp = 0（平面圆）残差 2.594e-14 m。

**裁定（FAIL，射程受限）**：在本构造族（kappa 常数、tau 单谐波）内，**闭合零模只能是平面圆**，即退化回 tau 恒 0 情形。

**射程声明**：这是构造族的性质，**不是「零模必为平面」的一般性证明**。一般 tau(s) 下的闭合零模是否存在，本册未判定。

### 3.4 方法论教训（判据设计）

脚本首版曾在粗步长下看到分量 gz 的符号变化并据此二分求根，得到 amp 约 1.0085 的伪根，二分后残差仍为 2.898 m。诊断给出两条可复用教训：

1. **单分量变号不是闭合证据**：闭合要求位置矢量差的三分量同时为零；只监视 gz 会把「该分量过零」误读为「曲线闭合」。求根/判根必须用全矢量残差。
2. **步长收敛检验是必需的**：本例中它同时排除了「数值误差制造伪根」这一解释。若没有这一步，会把判据错误误归罪于数值误差，得出错误根因。

## 4. 定理适用性（V6-c）

| 定理 | 适用条件 | 本册读数 |
|---|---|---|
| Milnor 总挠率界 abs(Tw) <= TC/(2π) | 闭合曲线 | TC/(2π) = 1.000000；abs(Tw) = 0 ⇒ 满足 |
| Fáry–Milnor：TC < 4π 蕴含无自交 | 闭合简单曲线 | TC = 6.283185 < 12.566371 ⇒ 满足 |
| Călugăreanu–White：Tw = Lk·Wr | **仅闭合曲线** | 本构造族 Lk = 0、Tw = 0、Wr = 0 |

**推论**：任何以缠绕数 Lk 为守恒量的相变叙述，必须先证明光子螺旋闭合——而光子世界线在实验室系一般是开线，Lk 无定义。

## 5. 守恒律候选集枚举（V6-d）

| 候选 | 量纲 | 末态取值 | 裁决 |
|---|---|---|---|
| C1 Tw = (1/2π)∫tau ds | 1 | 初态非零，末态为零 | **排除**：守恒则相变不可能 |
| C2 TC = ∫kappa ds | 1 | kappa' = kappa0 | 保留 |
| C3 ∫Omega ds，Omega = sqrt(kappa²+tau²) | 1 | kappa' = kappa0·sqrt(1+alpha²) | 保留 |
| C4 ∫(kappa + w·tau) ds | 1 | kappa' = kappa0·(1 + w·alpha) | 保留（w 自由） |
| C5 H = ∫A·(∇×A) dV | M²L⁴T⁻⁴I⁻² | 需质量量纲耦合常数 | 不可算 |
| C6 m' c² | ML²T⁻² | m' 归零 ⇒ 能量不守恒 | **排除** |
| C7 abs(dr/dt) = c | LT⁻¹ | 恒等式 | 无鉴别力 |

C4 是**一维连续族**：末态 kappa'/kappa0 = 1 + w·alpha 连续覆盖 [1.0000000, 1.0072974]；Fáry–Milnor 只要求 kappa'/kappa0 < 2，即 w < 137.036，**对 [0,1] 内全部候选一律放行，不产生任何筛选力**。

**裁定：不存在唯一守恒律；守恒量候选空间未被公设约束。**

## 6. 可判决性（V6-e）

| 量 | 值 |
|---|---|
| 候选族末态差异区间宽度 | 7.297e-03（0.73%） |
| 极端候选 C2 对 C3 的差异 | 2.663e-05 |
| 原理上可分辨的长度比测量精度 | 约 1e-06 |

单看极端候选，0.73% 的差异原理上可分辨。**但**候选族是一维连续族（自由权重 w），**任何单条数据都能被某个 w 拟合**（参数 1、约束 1 ⇒ 欠定）。

**裁定：守恒律不能由数据确定，只能由公设确定**；而 GAQ 现有公设集内没有给出该权重的地方。此与既有 S03-C0023（6 参数对 4 约束、余量 2 ⇒ 不可证伪）**同型**。

## 7. 质量与能量侧（V6-f）

机器枚举确认：全部几何守恒量候选（Tw、TC、∫Omega ds、∫(kappa+w·tau) ds）的**质量分量全为 0**。

而相变的定义本身涉及静质量 m' 由非零变零。要写出能量收支 E = m'c² 必须引入具质量量纲的量，而唯一的此类输入 G 在 C0027 / C0028 中已被判为外加初值。

**裁定：相变的能量/质量侧不可算；一旦被追问「能量从哪来」，立即落回公设边界。**

## 9. 唯一存活的相变图像

```
初态（类时孤子）  : tau0 非零, kappa0 > 0, Tw0 非零, m' > 0
末态（光子零模）  : ∫tau ds = 0, kappa' > 0, Tw = 0, m' = 0

相变 = 挠率释放（torsion release）：净扭转转移给曲率。
转移由权重 w 支配：kappa' = kappa0 · (1 + w·alpha)，w 自由。
无任何可接受的守恒量携带质量分量 ⇒ 释放的能量收支不可算。

裁定：可描述（describable），不可判决（not adjudicable）。
```

**幸存的定量后果**（若外加一个权重）：kappa'/kappa0 落在 [1, 1.0073] 区间内，且该区间不违反 Fáry–Milnor。这给出一个**弱可检验窗口**：若未来声称测得光子螺旋的曲率与孤立子螺旋曲率之比落在该区间内，则与本册图像相容；落在区间外则否证本册图像。**但该判据无法区分区间内的不同 w**，故只能否证、不能确认。
