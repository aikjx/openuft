### 3.1 引力未统一（关键）

```
问题：引力无法与其他三力统一

原因：
  [1] G依赖宇宙学边界 Ξ = c
      G = πc³/(S_dS·ℏ·H₀²)
      这是宇宙学量，非拓扑量
  [2] 引力耦合有量纲 [E]⁻²
      EM/Strong/Weak 耦合是无量纲
  [3] 引力不是规范理论
      EM/Strong/Weak 有规范群 U(1)/SU(2)/SU(3)
      引力是 Diff(M)（微分同胚不变性）

后果：
  框架实现"3+1"统一，而非"4"统一
  三力 = 拓扑的、局域的
  一力 = 宇宙学的、边界依赖的

状态：⚠️ 承认，未解决
```
