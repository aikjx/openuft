## 一、闭合目标：第49层遗留的λ方向伪影

第49层（R³截断FRG）诚实标注了三大遗留，其中最关键的一项：

> **λ方向为线性化伪影**：简化模型 β_λ = (4−η_N)λ − (B_λ/16π²)g 的 λ 依赖为线性，∂β_λ/∂λ = +4.05 恒正 → θ_λ = −4.05（被误判为无关方向）。文献完整FRG中 **λ 是相关方向（θ₂ = 1.5 > 0）**。

第51层根因分析发现伪影有**两个叠加来源**：

1. **符号约定非标准**：第47/49层线性模型取 β_λ = +(4−η_N)λ − 量子项（λ项为正号），而文献标准 Wetterich 流为 **β_λ = −(2−η_N)λ + 量子项**（λ项为负号）。正号约定使 ∂β_λ/∂λ 恒为 +4.05，λ 方向必然被误判为无关。
2. **阈值函数缺失**：完整FRG中量子项携带 Litim 截断阈值函数 Φ(w) ∝ (1−2w)^{−n}（w = −2λ），在物理区 λ>0 单调递减，其**负斜率**与负号λ项叠加，使 ∂β_λ/∂λ < 0 → θ_λ > 0。

```
Φ₂²(w) ∝ (1 − 2w)^{-n},   w = −2λ  →  极点因子 (1 + 4λ)^{-n}
```

- 极点位于 w = 1/2，即 λ = −1/4（物理区 λ>0 无极点，无奇性）；
