∇·(∇ × **B**) = ∇·(μ₀**J** + μ₀ε₀∂**E**/∂t)

由于左边∇·(∇ × **B**) = 0，因此：

0 = μ₀∇·**J** + μ₀ε₀∂(∇·**E**)/∂t

根据高斯定律，∇·**E** = ρ/ε₀，代入上式，得到：

0 = μ₀∇·**J** + μ₀ε₀∂(ρ/ε₀)/∂t = μ₀(∇·**J** + ∂ρ/∂t)

因此，∇·**J** + ∂ρ/∂t = 0，这就是连续性方程，表明电荷守恒定律是麦克斯韦方程组的必然结果。

### A.3 相对论性电荷守恒的详细推导

在相对论中，电流密度可以表示为四维矢量Jᵘ = (cρ, Jˣ, Jʸ, Jᶻ)，其中c为光速，ρ为电荷密度，Jˣ, Jʸ, Jᶻ为电流密度的三个分量。

四维散度算符为∂ᵤ = (∂/∂(ct), ∂/∂x, ∂/∂y, ∂/∂z)。

相对论性电荷守恒定律可以表述为四维电流密度的散度为零：

∂ᵤJᵘ = 0

展开后得到：

∂(cρ)/∂(ct) + ∂Jˣ/∂x + ∂Jʸ/∂y + ∂Jᶻ/∂z = 0

化简后得到：

∂ρ/∂t + ∇·**J** = 0

这就是连续性方程的标准形式，表明相对论性电荷守恒与经典电荷守恒是一致的。

### A.4 电荷守恒与规范对称性的关系

在量子电动力学中，电荷守恒与电磁规范对称性密切相关。电磁规范变换可以表示为：

Aᵘ(x) → Aᵘ(x) + ∂ᵘΛ(x)

其中，Aᵘ为四维矢量势，Λ(x)为任意标量函数。

在规范变换下，电磁场张量Fᵘᵛ = ∂ᵘAᵛ - ∂ᵛAᵘ保持不变，因此物理规律也保持不变。

根据诺特定理，连续对称性对应于守恒定律。电磁规范对称性对应于电荷守恒定律，这表明电荷守恒是空间螺旋运动几何对称性的必然结果。
