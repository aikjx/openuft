## 〇、结论先行

**两尺度电子的辐射修正 C(ω)**（相对点电荷 Larmor）：

$$C(\omega) = \left|F(\omega/c)\right|^2 = \left[\frac{1}{1+(\omega\, l_Q/c)^2}\right]^{4}$$

- 由涌现晕 `ρ_Q=A·e^{-r/l_Q}`（⟨r⟩=1.00116·λ_C）的弹性形状因子 `F(q)=[1/(1+(q·l_Q)²)]²` 导出，**无 V1,V2 假设**。
- 低频 `C→1`（Larmor 恢复，总电荷守恒）；辐射偏离自康普顿频率起显著：`C(ω_C)=0.655`（偏 34.5%）、`C(2ω_C)=0.229`、`C(3ω_C)=0.062`（偏 93.8%）。
- **特征偏离频率由质量定标**：`ω_C = c/λ_C = c·M/ħ = 7.763e20 rad/s`；半功率点 `ω_½=1.303·ω_C`。
- 小 q 形状因子由形状矩 `⟨r²⟩=1.99e-25 m²` 定：`F(q)≈1−⟨r²⟩q²/6`。

**与源稿 C 的关系（如实）**：源稿 `C=(1/N)∫4πr⁴ρ(3V1ρ−5V2ρ²)dr` 依赖电荷场自耦合 V1,V2（其孤子不可归一化，C0039–47 已证伪）；本 C(ω) 以可计算、可观测的形式**兑现源稿"强加速粒子辐射偏离 Larmor"的物理意图**，是两尺度结构的可测预言，**非对源稿公式字面复算**。

## 一、物理动机与公式

- 电荷/磁晕：`ρ_Q=A·e^{-r/l_Q}`，`l_Q=⟨r⟩/3=1.28878e-13 m`（C0081，g_e 一致）。
- 弹性形状因子（exp 晕的 3D Fourier）：`F(q)=∫ρ e^{iq·r}d³r = [1/(1+(q·l_Q)²)]²`。
- 辐射修正：`C(ω)=|F(ω/c)|²`。
- 小 q 展开：`F(q)≈1−⟨r²⟩q²/6`，`⟨r²⟩=12·l_Q²=1.993e-25 m²`。

## 三、物理内容与可测预言

1. C(ω) 由涌现结构唯一确定，无 V1,V2 假设（F(q) 为 exp 晕 3D Fourier）。
2. 低频 C→1（Larmor 恢复）；偏离自康普顿频率起显著。
3. 特征偏离频率 `ω_C=c/λ_C=c·M/ħ`（质量定标）⇒ 强加速辐射偏离 Larmor 的量表是康普顿频率。
4. 小 q 形状因子由 ⟨r²⟩ 定（连接 C0082 形状矩）；**可被 e-p 散射 / 高能辐射检验**。
5. 源稿 C（V1,V2 抽象积分）不可算（C0051 挂账延续）；本 C(ω) 以可观测形式兑现其物理意图，非字面复算。
