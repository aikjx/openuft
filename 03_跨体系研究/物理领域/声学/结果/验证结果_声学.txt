【AC1】声波基础
----------------------------------------------------------------------

  声学概述：

  声学是研究声波的产生、传播、接收和效应的学科。
  它是经典力学和波动理论的交叉领域，在建筑、音乐、医学、海洋等领域有广泛应用。

  声学的主要分支：
    - 物理声学：声波的基本物理
    - 建筑声学：厅堂音质与噪声控制
    - 超声学：超声波的产生与应用
    - 心理声学：人对声音的感知
    - 水声学：水下声传播
    - 音乐声学：乐器与音乐
    - 生物声学：动物发声与听觉

  声波基本性质：

  声波是弹性介质中的机械波：
    - 纵波：质点振动方向与传播方向平行（空气中）
    - 横波：质点振动方向与传播方向垂直（固体中）
    - 需要介质传播，不能在真空中传播

  声速：
    - 空气（20°C）：343 m/s
    - 水（20°C）：1482 m/s
    - 钢：5900 m/s
    - 骨骼：3500 m/s

  声学量定义：

  1. 声压 p：声波引起的压强变化（Pa）
     人耳听阈：2×10⁻⁵ Pa
     痛阈：20 Pa

  2. 声强 I：单位面积声功率（W/m²）
     人耳听阈：10⁻¹² W/m²
     痛阈：1 W/m²

  3. 声压级 SPL = 20 log₁₀(p/p₀) dB
     p₀ = 2×10⁻⁵ Pa（听阈参考）

  4. 声强级 SIL = 10 log₁₀(I/I₀) dB
     I₀ = 10⁻¹² W/m²

  声压级计算：
    正常谈话声压 p = 0.02 Pa
    SPL = 20log₁₀(p/p₀) = 60.0 dB

  声波频率与波长：

  声频范围：
    人耳可听：20 Hz - 20 kHz
    次声波：<20 Hz
    超声波：>20 kHz
    超声诊断：1-20 MHz

  波长：λ = c/f
    20 Hz 空气中：λ = 17.2 m
    20 kHz 空气中：λ = 1.7 cm
    3.5 MHz 水中：λ = 0.42 mm（医学超声）

  波长计算：
    20 Hz 空气中：λ = 17.2 m
    20 kHz 空气中：λ = 1.7 cm
    3.5 MHz 水中：λ = 0.42 mm

  声阻抗：

  特征声阻抗：Z = ρc
    - 空气：Z = 1.225 × 343 = 420 Pa·s/m
    - 水：Z = 1000 × 1482 = 1.48×10⁶ Pa·s/m
    - 钢：Z = 7800 × 5900 = 4.6×10⁷ Pa·s/m

  声阻抗失配：
    - 空气-水界面反射率 R = (Z₂-Z₁)²/(Z₂+Z₁)²
    - 空气→水：R ≈ 0.999（99.9%反射！）
    - 这是超声需要耦合剂的原因

  声阻抗失配计算：
    空气 Z₁ = 421 Pa·s/m
    水 Z₂ = 1.48e+06 Pa·s/m
    空气→水反射率 R = 0.9989（99.9%）

  螺旋几何化解释：

  1. 声波的螺旋几何化
     - 声波 = 介质分子/原子的螺旋振动
     - 纵波 = 螺旋振动沿传播方向的分量
     - 声速 = 螺旋振动传播速度
     - 声压 = 螺旋压缩/稀疏的振幅

  2. 声学量的螺旋解释
     - 声强 = 螺旋动能流密度
     - 声阻抗 = 介质对螺旋振动的阻力
     - 声压级 = 螺旋振幅的对数度量
     - 频率 = 螺旋振动的角频率

【AC2】声学波动方程
----------------------------------------------------------------------

  声学波动方程：

  声波满足波动方程：
    ∂²p/∂t² = c² ∇²p

  推导（从连续介质力学）：
    1. 连续性方程：∂ρ/∂t + ∇·(ρv) = 0
    2. 动量方程：ρ Dv/Dt = -∇p
    3. 本构关系：p = c²ρ'（等熵）
    组合三式得波动方程

  一维平面波解：
    p(x,t) = p₀ cos(kx - ωt)
    ω = ck

  声速的推导：

  理想气体中：
    c = √(γRT/M)
    其中 γ = c_p/c_v = 1.4（空气）

  牛顿近似（等温）vs Laplace修正（绝热）：
    c_Newton = √(p/ρ) = 290 m/s（错误）
    c_Laplace = √(γp/ρ) = 343 m/s（正确）
    Laplace修正：声波传播太快，无热交换，绝热过程

  声速计算（Laplace修正）：
    c = √(γRT/M) = √(1.4×8.314×293.15/0.02897) = 343.2 m/s
    实验值（20°C）：343 m/s
    误差：0.06%

  驻波与共振：

  两端固定弦：
    λ_n = 2L/n, f_n = nv/(2L)

  一端开放管：
    λ_n = 4L/(2n-1), f_n = (2n-1)v/(4L)

  两端开放管：
    λ_n = 2L/n, f_n = nv/(2L)

  管乐器基频计算（L=0.5m）：
    两端开放：f₁ = v/(2L) = 343.5 Hz
    一端封闭：f₁ = v/(4L) = 171.8 Hz

  Doppler效应：

  声源运动、观察者运动或两者都运动时的频率变化：
    f' = f (c ± v_o)/(c ∓ v_s)
    观察者靠近声源取+，声源靠近观察者取-

  应用：
    - 雷达测速（电磁波Doppler）
    - 医学超声多普勒血流测量
    - 天文红移（光Doppler）

  Doppler频移计算：
    声源频率 f = 1000.0 Hz
    声源速度 v_s = 30.0 m/s（接近）
    观察频率 f' = 1095.7 Hz
    频移 Δf = 95.7 Hz

  螺旋几何化解释：

  1. 波动方程的螺旋几何化
     - 波动方程 = 螺旋振动的传播方程
     - 平面波 = 螺旋相位的传播
     - 驻波 = 螺旋振动的干涉叠加
     - 共振 = 螺旋振动的频率匹配

  2. 声速的螺旋解释
     - 声速 = 分子螺旋振动的链式传播
     - Laplace修正 = 螺旋振动的绝热条件
     - 声速依赖 = 介质螺旋刚度的函数
     - 温度依赖 = 螺旋动能的影响

  3. Doppler效应的螺旋解释
     - 频移 = 螺旋振动的压缩/拉伸
     - 接近 = 螺旋波前的压缩
     - 远离 = 螺旋波前的拉伸
     - 声爆 = 螺旋波前的叠加（Ma>1）

【AC3】声学现象
----------------------------------------------------------------------

  声波的传播现象：

  1. 反射：
     - 声波遇到界面反射
     - 反射定律：入射角=反射角
     - 回声：反射声与直达声时差>50ms

  2. 折射：
     - 声速变化导致声波弯曲
     - Snell定律：sinθ₁/c₁ = sinθ₂/c₂
     - 温度梯度、风速梯度引起折射

  3. 衍射：
     - 声波绕过障碍物
     - 衍射条件：障碍物尺寸 ~ 波长
     - 低频声更容易衍射（波长长）

  4. 干涉：
     - 声波叠加产生加强/减弱
     - 杨氏双缝声学实验
     - 拍频：Δf = |f₁-f₂|

  混响与吸声：

  混响时间（Sabine公式）：
    RT₆₀ = 0.161V/A
    其中 V 是房间体积（m³），A = ΣαᵢSᵢ 是总吸声量（m²）

  典型混响时间：
    音乐厅：1.8-2.2 s
    报告厅：0.8-1.2 s
    录音室：0.3-0.5 s

  混响时间计算（Sabine）：
    房间体积 V = 1000.0 m³
    总吸声量 A = 75.0 m²
    RT₆₀ = 0.161V/A = 2.15 s

  吸声材料：

  吸声系数 α（20°C, 常见材料）：
    大理石/瓷砖：0.01（高反射）
    混凝土墙：0.02-0.05
    地毯：0.2-0.4
    玻璃纤维：0.6-0.9
    多孔吸声板：0.5-0.9

  隔声：

  质量定律（隔声量）：
    TL = 20log₁₀(f·m_s) - 47 dB
    其中 m_s 是面密度（kg/m²）
    质量加倍 → 隔声量+6dB

  隔声量计算（质量定律）：
    频率 f = 1000.0 Hz
    面密度 m_s = 50.0 kg/m²
    TL = 20log₁₀(f·m_s) - 47 = 47.0 dB

  螺旋几何化解释：

  1. 声学现象的螺旋几何化
     - 反射 = 螺旋波前的方向反转
     - 折射 = 螺旋波前的方向弯曲
     - 衍射 = 螺旋波前的绕过传播
     - 干涉 = 螺旋振动的相位叠加

  2. 混响的螺旋解释
     - 混响 = 螺旋声波的多径反射
     - 吸声 = 螺旋振动的能量耗散
     - 扩散 = 螺旋声波的均匀分布
     - 声场 = 螺旋声线的统计分布

  3. 隔声的螺旋解释
     - 隔声 = 螺旋振动的屏障
     - 质量定律 = 螺旋惯性的隔声效果
     - 共振透射 = 螺旋共振的声透射
     - 吻合效应 = 螺旋波长的匹配

【AC4】建筑声学与噪声
----------------------------------------------------------------------

  建筑声学概述：

  建筑声学研究厅堂和建筑中的声学问题：
    - 厅堂音质设计：音乐厅、歌剧院、报告厅
    - 噪声控制：建筑隔声、设备降噪
    - 声学材料：吸声、隔声、扩散材料

  厅堂音质评价指标：

  1. 混响时间 RT₆₀：
     - 音乐厅理想值：1.8-2.2 s
     - 报告厅理想值：0.8-1.2 s

  2. 早期反射声：
     - 直达声后20-50ms内的反射声
     - 提高清晰度和空间感

  3. 明晰度 C₈₀：
     - C₈₀ = 10log₁₀(E₈₀/E₈₀∞)
     - E₈₀：前80ms声能，E₈₀∞：80ms后声能

  4. 声场不均匀度：
     - 厅堂各位置声压级差异
     - 理想：<6 dB

  经典音乐厅：

  Vienna Musikverein（1870）：
    - RT₆₀ = 2.05 s（满场）
    - 被誉为世界最佳音乐厅
    - 鞋盒式设计（宽19.5m, 高17.5m）

  Berlin Philharmonie（1963）：
    - RT₆₀ = 2.0 s
    - 葡萄园式设计（听众环绕乐队）
    - 开创了环绕式音乐厅设计

  噪声控制：

  噪声标准（中国GB 3096）：
    0类：疗养区 昼50/夜40 dB
    1类：居住区 昼55/夜45 dB
    2类：商业区 昼60/夜50 dB
    3类：工业区 昼65/夜55 dB
    4类：交通干线 昼70/夜55 dB

  噪声控制三途径：
    1. 声源控制：降低声源噪声（最有效）
    2. 传播途径：隔声、吸声、消声器
    3. 接收者保护：耳塞、耳罩、隔声室

  噪声的生理效应：

    85 dB：长期暴露听力损伤
    100 dB：短期暴露听力损伤
    120 dB：痛阈，立即损伤
    140 dB：听力即刻丧失
    噪声性耳聋：>85 dB 8h/天 长期

  螺旋几何化解释：

  1. 建筑声学的螺旋几何化
     - 音乐厅形状 = 螺旋声线的几何设计
     - 鞋盒式 = 螺旋反射的均匀分布
     - 葡萄园式 = 螺旋声场的环绕
     - 扩散体 = 螺旋声波的散射结构

  2. 噪声的螺旋解释
     - 噪声 = 无序螺旋振动的混合
     - 白噪声 = 所有频率螺旋振动的叠加
     - 粉红噪声 = 1/f螺旋谱
     - 降噪 = 螺旋振动的抑制/抵消

  3. 主动降噪（ANC）的螺旋解释
     - ANC = 反相螺旋波的干涉相消
     - 反相声波 = 相位差π的螺旋振动
     - 降噪量 = 螺旋干涉的消光效率

【AC5】超声学
----------------------------------------------------------------------

  超声学概述：

  超声学是研究频率高于20kHz的声波的学科。
  超声波具有方向性好、穿透力强、能承载能量等优点。

  超声波的产生：

  压电效应（Pierre Curie, 1880）：
    - 正压电效应：机械变形产生电荷
    - 逆压电效应：电场产生机械变形
    - 应用：超声换能器

  压电材料：
    - PZT（锆钛酸铅）：最常用
    - 石英：高稳定性
    - PVDF（聚偏氟乙烯）：柔性
    - 压电复合材料：医学超声探头

  超声检测原理：

  A超（幅度显示）：
    回波幅度-时间曲线
    应用：厚度测量、缺陷检测

  B超（亮度显示）：
    回波亮度-位置二维图
    应用：医学影像

  C超：
    等深度平面扫描
    应用：材料检测

  超声相控阵：
    多阵元电子聚焦和偏转
    实时动态聚焦

  超声无损检测（NDT）：

  缺陷检测原理：
    - 超声波遇到缺陷产生反射
    - 通过回波时间定位缺陷：d = ct/2
    - 通过回波幅度判断缺陷大小

  缺陷定位计算（钢，声速5900m/s）：
    回波时间 t = 100 μs
    缺陷深度 d = ct/2 = 29.5 cm

  医学超声：

  诊断超声（1-20 MHz）：
    - 频率越高分辨率越高，但穿透越浅
    - 3.5 MHz：腹部深部成像（穿透~20cm）
    - 7.5 MHz：浅表成像（甲状腺、乳腺）
    - 10-20 MHz：眼科、皮肤科

  超声多普勒血流测量：
    - 红细胞反射超声产生多普勒频移
    - 血流速度：v = cΔf/(2f₀cosθ)

  高强度聚焦超声（HIFU）：

  治疗原理：
    - 聚焦超声波在焦点产生高温（>60°C）
    - 热消融肿瘤组织
    - 无创、无辐射

  HIFU应用：
    - 子宫肌瘤（最成熟）
    - 前列腺癌
    - 肝癌、胰腺癌
    - 骨肿瘤

  超声的其他应用：

    - 超声清洗：空化效应去除污垢
    - 超声焊接：塑料焊接
    - 超声加工：硬脆材料加工
    - 声呐：水下探测
    - 超声流量计：流量测量
    - 超声乳化：白内障手术

  螺旋几何化解释：

  1. 超声的螺旋几何化
     - 超声波 = 介质粒子的螺旋振动传播
     - 压电效应 = 螺旋晶格的电-力耦合
     - 换能器 = 螺旋振动的电-声转换
     - 聚焦 = 螺旋波前的汇聚

  2. 超声成像的螺旋解释
     - 回波 = 螺旋声波的反射
     - 成像 = 螺旋回波的时延重建
     - 多普勒 = 螺旋运动的频移
     - 弹性成像 = 螺旋剪切波的测量

  3. HIFU的螺旋解释
     - 聚焦 = 螺旋声波的几何聚焦
     - 热效应 = 螺旋振动能量→热能
     - 空化 = 螺旋声场的气泡振荡
     - 消融 = 螺旋能量沉积的精确控制
