## 1. 定理 S：判定与归一化无关

公理 A1（证据单调）/ A2（成本单调）/ A3（边际可替代）/ A4（零基准）/
A5（严格单调）迫使 `V = Psi(m)`，`m = h_eff − C`，`Psi(0) = 0`。

- 电池 42 条声明、24 条可比：V4 / V\* / V/C / V/(h+C) **符号全同**，
  分歧 0 条。
- V4 本身**不**属于该类（同为 m=1，(h,C)=(3,2) 给 0.3333、(30,29) 给 0.0333），
  只是符号一致。故前三册的**判定**成立，把 V4 的**数值**当可比量不成立。
- V4 在 h_eff = 0 处无定义（电池中 18 条），V\* 有定义 —— 判别式
  在最需要判定的点上失效。

## 2. 定理 K''：统一闭式与核心等价

在旋钮的三种计费口径下统一成立：

```
V  <=  ( kappa(S) − a_eff(S) − nu ) / rank(E),   kappa(S) = |S| − rank(D_S)
```

| 口径 | 旋钮计费 f | 完备枚举 35308 组中 V>0 出现次数 | max V |
| --- | --- | --- | --- |
| 1（前三册默认） | k | 0 | -0.6667 |
| 2 | rank(E_K) | 0 | -0.6667 |
| 3（最宽容，只计边际） | rank(E) − rank(E_A) | 0 | -0.6667 |

核心等价：

```
V > 0  <=>  kappa(S) > a_eff(S) + nu
```

这是一条鸽笼原理：**从 N 个独立测量里取不出超过 N 个独立的无量纲预言**。
SI-2019 表上 `kappa = 5 = a_eff`（等号、零余量）⇒ `V <= −nu/rank(E) <= 0`，
且 nu = 0 时上确界 0 **可达**。

> 前三册称之为「代数派生不可能定理（物理）」，叫错了。
> 它是**账本完备性定理**：说的不是自然不允许，是不允许你把同一个自由度记两次。

## 3. 定理 U：循环格的完备枚举（闭合 OPEN O-7 的一半）

量纲矩阵秩 5 ⇒ `Lambda_dim = ker_Z(D_A)` 秩 5。格基：

- `c^1 * hbar^1 * e^-2 * eps0^1`
- `c^1 * hbar^1 * G^-1 * m_e^-2`
- `c^1 * hbar^1 * G^-1 * m_mu^-2`
- `c^1 * hbar^1 * G^-1 * m_p^-2`
- `c^1 * hbar^1 * G^-1 * m_P^-2`

完备枚举 λ ∈ [−3,3]^5（共 16807 组），按不确定度传播界判定数值闭合：

| 格 | 秩 |
| --- | --- |
| Lambda_dim（量纲闭合） | 5 |
| Lambda_val（数值闭合） | 1 |

闭合的非零向量共 6 个，**全部是 m_P 循环的整数倍** —— 账本里只有
1 个冗余锚，另外 4 个无量纲循环是真实测量。III 册靠肉眼找到 2 个，
本册给的是算法，并证明没有第三个。

- k_B 不参与任何无量纲循环（温度维度孤立）⇒ 涉及 k_B 的声明 kappa 贡献为 0。
- `c*hbar*eps0/e^2 = 1/(4 pi alpha)` 属于 Lambda_dim 但**数值不闭合**
  （ln=2.3892，界 1.50e-10）：Q 型循环（靶↔锚）不在整数格框架内。

## 6. 诚实边界（OPEN）

- **O-9 已闭合**（本册 R0-a）：残差 = hbar 截断 − eps0 末位舍入，
  相符到 9 位有效数字；III 册的「表不自洽」说法作废。
- **O-7 闭合一半**（本册 §3）：锚内循环（`Lambda_val`）已可算法完备枚举，
  并证明秩为 1；靶↔锚的 Q 型循环不在整数格框架内。
- **O-10（新增）`kappa <= a_eff` 不是纯数学**：它依赖「定义常量量纲独立」
  这一单位制构造性质。SI-2019 下等号成立、**零余量**。若某单位制把两个
  量纲平行的量同时定为定义量，则 d 上升而 rank 不升，kappa 可能超过
  a_eff，定理 K 的界会被击穿。本册不声称已排除该情形。
- **O-11（新增）Q 型循环仍需人工标注**：`eps0 = e^2/(4 pi alpha hbar c)`
  这类**跨表恒等式**的识别依赖单位制知识，无法从量纲格推出。
  本册只把「找循环」的一半变成了算法。
- **O-12（延续）nu 无机械定义**：「为命中而必须调定的纯数个数」
  仍靠人工判定，本册未闭合。注意核心等价 `V>0 <=> kappa > a_eff + nu`
  把 nu 变成了**唯一可能翻案的杠杆** —— 谎报 nu 是最直接的攻击面。
- **O-6（延续）不确定度表是外部数据**：`Lambda_val` 的判定阈值直接依赖
  `UNC_REL`，未做本册的敏感性扫描（沿用 III 册 P-4 的结论）。
- **O-5（延续）**：本册不断言任何物理结论，全部是审计架构层面的元结论，
  不升级也不降级任何体系评级。
