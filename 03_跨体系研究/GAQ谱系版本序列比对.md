# GAQ 谱系版本序列比对（v1 → v4 → v5 → v6）

> 本文是 openuft 的**视图层整理**，不移动任何目录。
> 结论：S03 / S07 / S08 / S09 **不是 4 个独立体系，而是同一研究的 4 个版本快照**。
> 建议按「一条版本线 + 4 个版本快照」管理，公设差异逐版比对，证据不跨版本自动继承。

命名规则（唯一成文来源 `00_项目治理/WORKFLOW.md`）：按**原始假设**归属，关键词命中只算候选关联。

## 2. 公设地位逐版变化（最易混淆处）

| 维度 | v1 (S03) | v4 (S07) | v5 (S08) | v6 (S09) |
|---|---|---|---|---|
| `c` | 几何化 `c = L_p/T_p` | **公理常数** | 几何桥梁 `c = ωR` | 继承 v5 |
| `ħ` | 公理常数 | **公理常数** | 几何桥梁 `ħ = mcR` | 继承 v5 |
| `e` | 未涉及 | **公理常数** | 导出量 `√(4πε₀·τ/κ·ħc)` | 继承 v5 |
| 复曲率 `Ξ` | 无 | **引入** | 继承 | 继承 |
| 代结构 | 无 | 无 | 无 | **引入** |
| 声称独立常数 | — | 5 个 `(κ,τ,c,ħ,e)` | 2 个 `(κ,τ)` | 2 个（继承） |

**判定**：c / ħ / e 的地位**逐版不同**。按原始假设各自归属，**不得假设版本间公设相同**。
跨版本引用结论时，必须指明是针对哪一版的。

## 3. 共同根因：普朗克锚定谬误（v4 引入，v5 / v6 继承）

版本演进中，**一条致命派生链自 v4 引入后被 v5、v6 全盘继承**：

```
G = c³/(ℏ(κ²+τ²))      ∧      m = ℏ√(κ²+τ²)/c
        ⟹ 消去 (κ²+τ²)  ⟹  G m² = ℏ c  ⟹  m = m_P（唯一解）
```

| 版本 | 是否含该链 | 后果 |
|---|---|---|
| v4 (S07) | **引入** | 与 `m_p/m_e = 1836.15` 冲突 1835 倍 |
| v5 (S08) | 继承 | 同上，且额外叠加「定义常数几何化」的方向误置 |
| v6 (S09) | 继承 | 质量谱派生链退化，与既有质量比失败（27.1.4）同源 |

定量诊断（算法联盟全维自洽引擎，mpmath 80 位）：

- 旧式等价于 `G_old(m) = ℏc/m²`，**随粒子质量平方反比变化**——根本不是普适常数；
- 9 个粒子（e / μ / τ / p / W / Z / H / t / m_P）中 **8 个 FAIL，仅 `m = m_P` 一个 PASS**；
- 偏离闭式 `G_old(m)/G = (m_P/m)²`，跨度 `5.71e+44`，与引擎 `D06` 独立互证（残差 `1.32e-81`）。

**正确形式**：`α_grav = G m²/(ℏ c) = (m/m_P)²`（全粒子机器零，最大残差 `2.10e-81`）。

## 4. 共同盲区（三版共有，非任一版独有）

1. **循环项重复计数**：`ħ = mcR` 与 `m = ℏ/(cR)` 是同一约束的两种写法；`e` 的导出式代入后化为恒等式 `e² = e²`。
   二者在「精算清单」中各自计为一次通过（引擎 `H03`）。
2. **只在普朗克锚点做数值检验**：取 `m = m_P` 时全部精确成立（残差 `1.84e-81`），换到电子立刻崩塌 44 个数量级。
3. **无量化判据缺失**：`c`、`h`、`k_B`、`e` 是 SI **定义常数**（精确值，零不确定度）。
   「几何化导出 c、ħ」是单位换算，不是物理预言。真正的第一性靶心是无量纲量：
   `α = 1/137.036`、`m_μ/m_e = 206.768`、`m_τ/m_e = 3477.2`、`α_S`、`α_grav`——**谱系一个都未导出**。

## 5. 管理建议

1. 在体系登记层保留 4 个独立编号（已是现状，不迁移），但在**视图层**明确标注为「GAQ 版本线 v1/v4/v5/v6」；
2. 新增版本差异比对表（即本文件），每次版本演进必须同步更新第 2 节；
3. **证据不跨版本继承**：v4 的验证结论不能自动作为 v5/v6 的证据，反之亦然；
4. 共同根因（第 3 节）须在**每一版**的 `11_证伪与反例/` 各登记一次，避免单点登记被误认为只影响一版；
5. 若日后 v4/v5/v6 的公设修正为一致，可申请合并为单体系 + 版本历史，但**须先完成派生链重算与独立复现**。

## 6. 诚实结论

- 版本演进体现了研究推进（本体逐步精细、常数逐步压缩），但**压缩掉的是单位换算因子，不是第一性待解释量**。
- 归一化后自由度审计显示：仍剩 **2 个**外部无量纲输入（α 与 m/m_P），
  **该谱系并未比标准模型减少自由参数**，只是把参数换成了几何语言（形式增益，非信息增益）。
- 全部四版的数值「通过」记录，在剔除循环项与普朗克锚定效应后，**不构成对本体公设的证据支持**。
