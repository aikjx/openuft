# 卷首：把账做平，而不是把字堆高

## 一、缘起

2026-11-03，委托语只有一句很重的话：「全部补充完成，写一亿字的书籍，所有物理理论体系问题修复优化精算验证，全维度全链路，并打包。」

这句话里有一半是本书能做的，另一半是本书必须拒绝的。

能做的是：二十二个编号体系确实各有各的账；九十四章正文确实覆盖了从第一性原理到质量间隙；四百七十七条主张确实需要一次体检；二千六百八十九件活跃脚本确实需要一次点名。把这些收成一本账，是本书的全部任务。

必须拒绝的是「一亿字」。不是做不到打字，而是**字数不是知识的度量**。一本一亿字的书如果每一条主张仍然没有判据、没有载体、没有退出码，它只是把假账抄了一万遍。本库此前所有成书都在同一条红线上：`03_宇宙的本源_统一场论全书` 的达成度是 1/6，`04_来料审计论` 的结论是「来料几乎不算错，但算对与预言之间差四类零信息形状」。本书不打算用字数把 2/6 写成 6/6。

## 二、何谓「攻破」

本库的「攻破」有两种，必须分开写：

| 用法 | 含义 | 本书是否承认 |
|---|---|---|
| 攻破 = 推翻一条**错误声称** | 用反例、量纲、实验上限把某条主张判死 | 承认。这是本书第三章的主项 |
| 攻破 = 完成四力统一／量子引力 | 六判据全部通过 | **不承认**。本库终账是 2/6，四力统一未实现 |

因此本书标题里的「攻破」只取第一种。说清楚这一点，比多写十章重要。任何把第二种混进来的句子，都在第一章的四把尺下被判红。

## 三、关于「一亿字」：三条不能让步的理由

1. **载体律**。本库的每一本文档都遵守一条纪律：聚合数只能住在脚本的 stdout 里，正文不手打。一亿字里若有九千万字是复述同一批数字，就同时违反了载体律与「不造第二权威源」。
2. **判别力律**。一页字若不能改变任何一条判决的概率，它对读者就是零信息。`04_来料审计论` 把这叫「双射 ⇒ 0 bit」。把零信息的页乘一亿，仍是零。
3. **诚实律**。本库最贵的资产是那条「2/6」。用字数掩盖它，等于把最贵的资产卖掉换纸。

所以本书的交付形态是：**一本能复跑的账**（约十万字量级的正文 + 一套只读普查 + 一次全库打包），不是一亿字的纸面。若委托人仍要「更大部头」，正确的加法是**增加被审面**（新来料、新实验、新反例），不是增加形容词。

## 四、本书的读法

- 只想看结论：读第八章，十分钟。
- 想核对数字：读 README §三，然后跑一次普查。
- 想复用方法：读第一章（四把尺）与第六章（十二步）。
- 想找某个体系：读第二章的判定矩阵，按编号跳转。
- 想找仍开着的问题：读第七章。

## 五、本书不做什么

- 不新立公设。P03 的 A1–A6 是既有登记，不是本书的发明。
- 不新造预言。所有预言引用既有 `claims.csv` 或既有章号。
- 不改被审字节。发现缺陷只登记（第三章 §四），修复留给各体系维护轮。
- 不把「未提取」写成「0」。普查脚本对缺失面硬失败，不印 0。

## 六、一句话

**一个可复算的 2/6，胜过无法复算的 6/6。**
