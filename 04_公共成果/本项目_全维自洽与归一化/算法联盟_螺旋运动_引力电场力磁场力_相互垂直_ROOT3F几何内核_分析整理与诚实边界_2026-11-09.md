# 算法联盟：螺旋运动 引力/电场力/磁场力 相互垂直（ROOT-3F 几何内核）分析 整理与诚实边界

## 一、用户指向与问题
用户指出：螺旋运动 中，引力、电场力、磁场力 相互垂直，问能否据此攻破统一场论。
这一指向对应的是算法联盟此前 ROOT-3F 项目的几何内核——把三种力映射到一条螺旋曲线的 Frenet（活动标架）(T,N,B) 上，使它们分别落在三个互相正交的方向，从而「相互垂直」。本册的任务不是迎合这个直觉，而是用机器核验把「相互垂直」的真正来源说清楚，并诚实判定它离统一场论有多远。

## 二、ROOT-3F 几何内核是什么
ROOT-3F 的核心画面：任一空间曲线（含螺旋）在每一点都有一个 Frenet 标架 (T,N,B)：
- T 是单位切向量（运动方向）；
- N 是主法向量（曲率方向）；
- B = T × N 是副法向量（挠率方向）。
这三个向量按构造正交归一。ROOT-3F 把引力、电场力、磁场力分别安放到 T、N、B 三个方向上，于是它们「相互垂直」。问题在于：这种垂直是标架本身的几何事实，还是三力的内在物理统一？

## 三、机核核验一：标架正交归一是普遍曲线几何
机核取两条几何参数完全不同的螺旋（螺旋1：R=1、h=0.5、ω0=2.0、t=0.7；螺旋2：R=2、h=0.3、ω0=1.5、t=1.1），在采样点直接计算 Frenet 标架并做正交归一检验：
- 螺旋1：T·N、N·B、B·T 均 ≈ 0（最大残差 −5.55e-17），且 |T|=|N|=|B|=1；
- 螺旋2：同样三者点积 ≈ 0，单位归一。
两条不同螺旋都通过，说明 T·N=N·B=B·T≈0 不是特例，而是任意空间曲线 Frenet 标架的普遍性质。这是微分几何的定理，不是新物理。

## 四、机核核验二：三种物理力并不一般相互垂直
机核给出反例：固定引力方向 Fg=(0,0,−1)（指向质量，向下），取两种电场力构型：
- 电场水平 Fe_horiz=(0,1,0) ⇒ Fg·Fe_horiz = 0（此时垂直）；
- 电场也向下 Fe_vert=(0,0,1) ⇒ Fg·Fe_vert = −1（此时不垂直）。
同样两个力，仅因电场方向不同，点积从 0 变到 −1。这说明「三力相互垂直」取决于具体构型与观测方向，不是对三种力的普遍物理定律。磁场力亦然（洛伦兹力 qv×B 本身就与速度、磁场都垂直，但其与引力/电场力的夹角完全由外部场配置决定）。

## 五、关键区分：标架正交是几何事实，不是力的统一
把引力、电场力、磁场力映射到正交的 (T,N,B) 上使其「相互垂直」，本质是一种坐标选择：先选定三条互相垂直的轴，再把力投影上去。标架自身的正交性是曲线几何给的，与力是否统一无关。判定统一场论需要的是：能从单一 Lagrangian/对称性导出四力的相互作用与耦合流形，使它们在同一个动力学框架内被描述。映射到一个现成正交标架并不提供这种导出——它是描述方便，不是统一。

## 六、ROOT-3F 项目既有裁定回顾
ROOT-3F 此前已被算法联盟裁定为：条件性运动学恒等式，surplus=−2（与平行罗列等价，不构成统一），已降级为封死/保留资产。本册的核验与之完全一致：三力垂直只是把几何标架的正交性挪用为「力的正交」，没有改变其 surplus=−2 的判定。

## 七、为什么这不构成统一场论
- 不含 Lagrangian/场方程：该相互垂直结构不产生 Maxwell 方程、Yang–Mills 方程或 Einstein 场方程，故连一个独立的场论都谈不上。
- 无规范群合成：统一四力需要把引力、电磁、弱、强放进同一个规范/几何结构（如 SU(5) 或超引力），本结构没有群合成步骤。
- 无耦合流形：没有参数空间把四力的耦合常数连成单一流形，更谈不上由自洽性唯一钉死（这正是 TUFT 链 X-V63-13/14/15/16 反复确认的病根：统一参数未被内部机制唯一固定）。

## 八、与本轮其他册的关系
- 与《光速螺旋 S02/S12 falsification 精确化更正》互补：S02/S12 的动力学（动量 ansatz、力定律）已被证伪，但螺旋的运动学几何恒等式仍真；本册延续这一区分——垂直性来自几何，不救动力学。
- 与《v=c 螺旋几何恒等式分析》互补：ω²=c²(κ²+τ²) 是 Frenet–Darboux 真几何恒等式，本册的标架正交是其更底层的事实；二者同为「保留资产」，但都不是统一场论。
- 与 TUFT 审计线（r403=0 条四力大统一、r404=7 选 0、k 未钉死、rank(M)=4）一致：几何层面的漂亮结构无法弥补四力统一的动力学缺口。

## 九、诚实总判与红线
- 三力相互垂直的真实来源是任意空间曲线的 Frenet 标架正交归一，是一条普遍几何定理，不是三力的内在统一。
- ROOT-3F 维持降级为保留资产（surplus=−2），不构成统一场论。
- 全局红线不变：四力达成度 2/6（电弱已统一、引力未、候选待实验）；四力大统一仍 0 条正确解；独立实验预言 0；数学自洽 ≠ 实验证实。
- 不宣称攻破统一场论。本册是几何内核的诚实整理，不是突破。
