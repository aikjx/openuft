【SP1】统计物理概述与基本概念
----------------------------------------------------------------------

  统计物理研究的对象：
    1. 大量粒子（~10^23）组成的系统的宏观性质
    2. 从微观力学定律推导宏观热力学定律
    3. 平衡态与非平衡态统计
    4. 相变与临界现象
    5. 涨落与关联

  统计物理的主要分支：

  分支                   研究内容                                          状态
  --------------------------------------------------------------------------------
  平衡态统计力学              系综理论、玻尔兹曼统计、量子统计                              经典领域
  热力学                  热力学定律、状态方程、热力学势                               经典领域
  相变与临界现象              一级/连续相变、临界指数、重整化群                             活跃领域
  非平衡统计                输运理论、涨落耗散定理、不可逆过程                             前沿领域
  量子统计                 玻色-爱因斯坦统计、费米-狄拉克统计                            经典领域
  统计场论                 路径积分、重整化群、拓扑场论                                理论前沿
  复杂系统                 网络、混沌、自组织临界性                                  交叉领域
  生物物理统计               蛋白质折叠、基因调控、生命系统                               交叉前沿

  统计物理的基本假设：

  1. 等概率原理（微正则系综）：
     孤立系统在平衡态时，所有可达微观态出现的概率相等
     这是统计物理的最基本假设

  2. 各态历经假设：
     系统在足够长时间内会遍历所有可达微观态
     时间平均 = 系综平均

  3. 分子混沌假设（Stosszahlansatz）：
     碰撞前粒子的速度分布是无关联的
     这是玻尔兹曼方程的基础

  4. 热力学极限：
     N → ∞, V → ∞, N/V = 常数
     在热力学极限下，涨落趋于零，宏观量确定

  统计物理的重要概念：

  概念              描述                             公式                        意义
  -----------------------------------------------------------------------------------------------
  熵               系统微观态数的对数度量                    S = k_B ln Ω              热力学第二定律的核心
  配分函数            所有微观态的玻尔兹曼因子之和                 Z = Σ e^{-βE_i}           统计物理的核心工具
  系综              大量相同系统的集合                      微正则/正则/巨正则                统计平均的框架
  温度              系统平均动能的度量                      1/T = ∂S/∂E               热平衡的判据
  化学势             增加一个粒子所需的能量                    μ = ∂E/∂N                 粒子平衡的判据
  自由能             可用于做功的能量                       F = E - TS                正则系综的热力学势
  涨落              宏观量围绕平均值的偏离                    ⟨(ΔA)²⟩ = k_B T χ         关联函数与响应函数
  关联长度            涨落关联的空间范围                      ξ ~ |T-T_c|^{-ν}          临界现象的核心

  1. 统计物理的螺旋几何化
     - 微观态 = 螺旋粒子的具体运动状态
     - 熵 = 螺旋运动可能状态数的对数
     - 温度 = 螺旋运动的平均动能
     - 配分函数 = 所有螺旋状态的玻尔兹曼权重和

     - 热力学第三定律 = 螺旋运动的零点能
     - 热力学势 = 螺旋系统的极值原理

  3. 涨落的螺旋几何化

【SP2】热力学基本定律
----------------------------------------------------------------------

  热力学第零定律：

  表述：如果两个系统分别与第三个系统处于热平衡，
        则这两个系统也处于热平衡。

  意义：定义了温度的概念
        温度是判断系统是否处于热平衡的状态函数

  热力学第一定律（能量守恒定律）：

  表述：能量既不能被创造也不能被消灭，只能从一种形式转化为另一种形式。

  数学表达式：
    dU = δQ - δW
    其中 U 是内能，Q 是吸收的热量，W 是对外做的功

  对于准静态过程：δW = p dV
    dU = δQ - p dV

  对于循环过程：ΔU = 0，W = Q_in - Q_out

  热力学第二定律：

  克劳修斯表述：热量不能自发地从低温物体传到高温物体。

  开尔文表述：不可能从单一热源吸取热量，使之完全变为有用功而不产生其他影响。

  数学表达式（熵增原理）：
    dS ≥ δQ/T
    对于可逆过程：dS = δQ/T
    对于不可逆过程：dS > δQ/T
    对于孤立系统：dS ≥ 0（熵永不减少）

  卡诺定理：
    所有工作在两个恒温热源之间的热机，以可逆机的效率为最高。
    卡诺效率：η = 1 - T_c/T_h
    其中 T_h 是高温热源温度，T_c 是低温热源温度

  卡诺效率计算示例：
    高温热源 T_h = 500.0 K
    低温热源 T_c = 300.0 K
    卡诺效率 η = 1 - T_c/T_h = 40.0%

  热力学第三定律：

  能斯特表述：当温度趋于绝对零度时，系统的熵趋于一个常数（通常取为零）。

  普朗克表述：当 T → 0 时，S → 0。

  不可达表述：不可能通过有限步骤使系统温度达到绝对零度。

  推论：
    1. 当 T → 0 时，热容 C → 0
    2. 当 T → 0 时，热膨胀系数 α → 0
    3. 当 T → 0 时，熵变 ΔS → 0

  热力学势：

  热力学势                   自然变量            全微分                                 极值原理
  -----------------------------------------------------------------------------------------------
  内能 U                   S, V, N         dU = TdS - pdV + μdN                孤立系统平衡时U最小
  焓 H                    S, p, N         dH = TdS + Vdp + μdN                等压绝热系统平衡时H最小
  亥姆霍兹自由能 F              T, V, N         dF = -SdT - pdV + μdN               等温等容系统平衡时F最小
  吉布斯自由能 G               T, p, N         dG = -SdT + Vdp + μdN               等温等压系统平衡时G最小
  巨热力学势 Ω                T, V, μ         dΩ = -SdT - pdV - Ndμ               等温等容等化学势系统平衡时Ω最小

  麦克斯韦关系：

  从热力学势的全微分和混合偏导相等得到：

  从 dU = TdS - pdV：
    (∂T/∂V)_S = -(∂p/∂S)_V

  从 dH = TdS + Vdp：
    (∂T/∂p)_S = (∂V/∂S)_p

  从 dF = -SdT - pdV：
    (∂S/∂V)_T = (∂p/∂T)_V

  从 dG = -SdT + Vdp：
    (∂S/∂p)_T = -(∂V/∂T)_p

  螺旋几何化解释：

  1. 热力学定律的螺旋几何化
     - 第零定律 = 螺旋系统热平衡的传递性
     - 第一定律 = 螺旋能量守恒
     - 第二定律 = 螺旋运动的熵增原理（时间箭头）
     - 第三定律 = 螺旋运动的零点能（量子效应）

  2. 热力学势的螺旋几何化
     - 内能 = 螺旋系统的总能量
     - 焓 = 螺旋系统在等压下的有效能量
     - 自由能 = 螺旋系统可用于做功的能量
     - 吉布斯自由能 = 螺旋系统在等温等压下的有效能量

  3. 熵的螺旋几何化
     - 熵 = 螺旋运动可能状态数的对数
     - 玻尔兹曼熵：S = k_B ln Ω
     - 吉布斯熵：S = -k_B Σ p_i ln p_i
     - 香农熵：S = -Σ p_i log₂ p_i（信息论）
     - 熵增 = 螺旋运动从有序到无序的演化

【SP3】系综理论
----------------------------------------------------------------------

  系综的概念：

  系综是大量相同系统的集合，每个系统都处于相同的宏观条件下，
  但可能处于不同的微观态。统计平均就是对系综中所有系统求平均。

  三种基本系综：

  系综              固定量          概率分布                           热力学势                      适用系统
  ----------------------------------------------------------------------------------------------------
  微正则系综           E, V, N      P_i = 1/Ω (等概率)                熵 S = k_B ln Ω            孤立系统
  正则系综            T, V, N      P_i = e^{-βE_i}/Z              自由能 F = -k_B T ln Z       与热源接触的封闭系统
  巨正则系综           T, V, μ      P_{i,N} = e^{-β(E_i-μN)}/Ξ     巨势 Ω = -k_B T ln Ξ        与热源和粒子源接触的开放系统

  正则系综详细推导：

  配分函数：
    Z = Σ_i e^{-βE_i}, β = 1/(k_B T)

  对于连续谱：
    Z = (1/N! h^{3N}) ∫ d^{3N}p d^{3N}q e^{-βH(p,q)}

  热力学量与配分函数的关系：

  物理量             公式
  ------------------------------------------------------------
  自由能             F = -k_B T ln Z
  内能              U = ⟨E⟩ = -∂ ln Z/∂β = k_B T² ∂ ln Z/∂T
  熵               S = k_B (ln Z + βU) = -∂F/∂T
  压强              p = k_B T ∂ ln Z/∂V = -∂F/∂V
  热容              C_V = (∂U/∂T)_V = k_B β² (⟨E²⟩ - ⟨E⟩²)
  化学势             μ = (∂F/∂N)_{T,V} = -k_B T ∂ ln Z/∂N

  理想气体的配分函数：

  单粒子配分函数：
    Z_1 = V (2π m k_B T / h²)^{3/2}

  N粒子配分函数（考虑全同粒子）：
    Z_N = Z_1^N / N!

  热力学量：
    F = -N k_B T [ln(V/N) + (3/2) ln(2π m k_B T/h²) + 1]
    p = N k_B T / V （理想气体状态方程）
    U = (3/2) N k_B T
    S = N k_B [ln(V/N) + (3/2) ln(2π m k_B T/h²) + 5/2]
    C_V = (3/2) N k_B

  理想气体标准状况计算：
    温度 T = 273.15 K
    压强 p = 101325 Pa
    摩尔体积 V_m = RT/p = 22.4140 L/mol
    摩尔内能 U_m = (3/2)RT = 3.4066 kJ/mol
    摩尔定容热容 C_V,m = (3/2)R = 12.4717 J/(mol·K)

  巨正则系综详细推导：

  巨配分函数：
    Ξ = Σ_{N=0}^∞ Σ_i e^{-β(E_{i,N} - μN)} = Σ_N e^{βμN} Z_N(T,V)

  对于理想气体：
    Ξ = exp(z Z_1), z = e^{βμ}（逸度）

  热力学量：
    Ω = -k_B T ln Ξ = -pV
    ⟨N⟩ = (1/β) ∂ ln Ξ/∂μ = z ∂ ln Ξ/∂z
    ⟨E⟩ = -∂ ln Ξ/∂β + μ⟨N⟩
    粒子数涨落：⟨(ΔN)²⟩ = (1/β) ∂⟨N⟩/∂μ = k_B T (∂N/∂μ)_{T,V}

  系综等价性：

  在热力学极限下（N→∞, V→∞, N/V=常数），三种系综等价：
    - 相对涨落 ⟨(ΔE)²⟩/⟨E⟩² ~ 1/N → 0
    - 相对涨落 ⟨(ΔN)²⟩/⟨N⟩² ~ 1/N → 0
    - 宏观量的分布趋于δ函数

  因此，对于宏观系统，可以选择最方便的系综进行计算。

  螺旋几何化解释：

  1. 系综的螺旋几何化
     - 微正则系综 = 螺旋能量固定的系统集合
     - 正则系综 = 螺旋温度固定的系统集合
     - 巨正则系综 = 螺旋温度和化学势固定的系统集合
     - 等概率原理 = 螺旋运动状态的等概率假设

  2. 配分函数的螺旋几何化
     - 配分函数 = 所有螺旋状态的玻尔兹曼权重和
     - 玻尔兹曼因子 = 螺旋能量的指数衰减
     - 自由能 = 螺旋配分函数的对数
     - 热力学量 = 螺旋配分函数的导数

  3. 系综等价性的螺旋几何化
     - 热力学极限 = 螺旋粒子数趋于无穷
     - 涨落趋于零 = 螺旋运动的统计涨落被平均掉
     - 宏观量确定 = 螺旋系统的平均行为确定

【SP4】量子统计
----------------------------------------------------------------------

  全同粒子与量子统计：

  在量子力学中，全同粒子是不可区分的。
  交换两个全同粒子，波函数要么对称（玻色子），要么反对称（费米子）。

  玻色子：
    - 自旋为整数（0, 1, 2, ...）
    - 波函数在交换下对称
    - 服从玻色-爱因斯坦统计
    - 可以有任意多个粒子处于同一量子态
    - 例子：光子、声子、氦-4原子、希格斯玻色子

  费米子：
    - 自旋为半整数（1/2, 3/2, ...）
    - 波函数在交换下反对称
    - 服从费米-狄拉克统计
    - 每个量子态最多容纳一个粒子（泡利不相容原理）
    - 例子：电子、质子、中子、夸克、中微子

  自旋-统计定理（Pauli, 1940）：
    在相对论量子场论中，整数自旋粒子必然是玻色子，
    半整数自旋粒子必然是费米子。这是相对论性量子场论的严格结果。

  玻色-爱因斯坦分布：

  平均粒子数：
    ⟨n⟩ = 1 / (e^{β(ε-μ)} - 1)

  对于光子（化学势μ=0）：
    ⟨n⟩ = 1 / (e^{βε} - 1) （普朗克分布）

  对于声子（化学势μ=0）：
    ⟨n⟩ = 1 / (e^{βε} - 1)

  费米-狄拉克分布：

  平均粒子数：
    ⟨n⟩ = 1 / (e^{β(ε-μ)} + 1)

  T = 0 时：
    ⟨n⟩ = 1 （ε < μ = ε_F，费米能）
    ⟨n⟩ = 0 （ε > ε_F）

  这就是费米海，所有低于费米能的态都被填满。

  铜的自由电子气计算：
    电子数密度 n = 8.47e+28 m⁻³
    费米波矢 k_F = (3π²n)^(1/3) = 1.36e+10 m⁻¹
    费米能 ε_F = ħ²k_F²/(2m) = 7.03 eV
    费米温度 T_F = ε_F/k_B = 8.16e+04 K
    费米速度 v_F = √(2ε_F/m) = 1.57e+06 m/s = 0.0052c

  玻尔兹曼分布（经典极限）：

  当 e^{β(ε-μ)} >> 1 时（高温低密度）：
    玻色分布和费米分布都趋近于玻尔兹曼分布：
    ⟨n⟩ ≈ e^{-β(ε-μ)} = z e^{-βε}

  简并温度（量子效应显著的温度）：
    对于费米子：T_F = ε_F/k_B
    对于玻色子：T_BEC = (2πħ²/mk_B)(n/ζ(3/2))^{2/3}

  光子气体（黑体辐射）：

  态密度（考虑偏振）：
    g(ε) dε = (V/π²) (ε²/(ħ³c³)) dε

  内能密度：
    u = U/V = (π² k_B⁴ / 15 ħ³ c³) T⁴ = a T⁴

  辐射压强：
    p = u/3 = a T⁴ / 3

  斯特藩-玻尔兹曼定律：
    I = σ T⁴, σ = c a / 4 = 2π⁵ k_B⁴ / (15 h³ c²)

  斯特藩-玻尔兹曼常数计算：
    σ = 2π⁵k_B⁴/(15h³c²) = 5.6704e-08 W/(m²·K⁴)
    标准值：5.6704e-8 W/(m²·K⁴)
    相对误差：99.5969%

  声子气体（德拜模型）：

  德拜频率：ω_D = v_s (6π² n)^{1/3}
  德拜温度：Θ_D = ħω_D/k_B

  低温热容（T << Θ_D）：
    C_V = (12π⁴/5) N k_B (T/Θ_D)³
    这就是德拜T³定律

  高温热容（T >> Θ_D）：
    C_V = 3 N k_B （杜隆-珀蒂定律）

  玻色-爱因斯坦凝聚（BEC）：

  临界温度：
    T_c = (2πħ²/mk_B) (n/ζ(3/2))^{2/3}
    其中 ζ(3/2) ≈ 2.612

  凝聚比例：
    N_0/N = 1 - (T/T_c)^{3/2} （T < T_c）

  1995年首次在稀薄碱金属原子气体中实现（Cornell, Wieman, Ketterle）
  2001年诺贝尔物理学奖

  铷-87原子BEC临界温度计算：
    原子质量 m = 87 u = 1.44e-25 kg
    数密度 n = 1e+20 m⁻³
    临界温度 T_c = 0.40 μK
    典型实验值：~100 nK - 1 μK（密度更低）

  螺旋几何化解释：

  1. 量子统计的螺旋几何化
     - 玻色子 = 整数自旋的螺旋粒子（螺旋旋转对称）
     - 费米子 = 半整数自旋的螺旋粒子（螺旋旋转反对称）
     - 泡利不相容原理 = 螺旋费米子的不相容性
     - 玻色凝聚 = 螺旋玻色子的宏观量子态聚集

  2. 分布函数的螺旋几何化
     - 玻色分布 = 螺旋玻色子的统计分布
     - 费米分布 = 螺旋费米子的统计分布
     - 玻尔兹曼分布 = 螺旋粒子的经典极限
     - 普朗克分布 = 螺旋光子的统计分布

  3. 量子气体的螺旋几何化
     - 光子气体 = 螺旋电磁波的集合
     - 声子气体 = 螺旋晶格振动的集合
     - 电子气 = 螺旋电子的集合（费米海）
     - BEC = 螺旋玻色子的宏观凝聚态

【SP5】相变与临界现象
----------------------------------------------------------------------

  相变的分类：

  类型                 特征                                       例子
  ------------------------------------------------------------------------------------------
  一级相变               序参量不连续，有潜热，有亚稳态                          气-液相变、固-液相变、大多数结构相变
  连续相变（二级）           序参量连续，无潜热，关联长度发散                         铁磁-顺磁、超流-正常、超导-正常
  无限阶相变              所有阶导数连续，关联函数幂律                           BKT相变（二维XY模型）
  量子相变               在T=0时由量子涨落驱动                             量子霍尔、重费米子、超导体-绝缘体
  拓扑相变               由拓扑序变化驱动，无局域序参量                          量子霍尔、拓扑绝缘体、2016诺贝尔奖

  伊辛模型（Ising Model）：

  哈密顿量：
    H = -J Σ_{<ij>} σ_i σ_j - h Σ_i σ_i
    其中 σ_i = ±1 是自旋，J 是交换耦合，h 是外场

  一维伊辛模型：
    严格解（Ising, 1925）：无有限温度相变
    配分函数：Z = (2 cosh βJ)^N （周期边界）
    自由能：f = -k_B T ln(2 cosh βJ)
    关联长度：ξ = -1 / ln(tanh βJ)
    T → 0 时 ξ → ∞，但 T_c = 0

  二维伊辛模型：
    严格解（Onsager, 1944）：有有限温度相变
    临界温度：k_B T_c = 2J / ln(1+√2) ≈ 2.269 J
    临界指数：α=0（对数发散）, β=1/8, γ=7/4, δ=15, ν=1, η=1/4
    这是第一个被严格求解的显示相变的模型

  二维伊辛模型临界温度：
    k_B T_c / J = 2/ln(1+√2) = 2.2692
    即 T_c ≈ 2.269 J/k_B

  三维伊辛模型：
    无严格解析解，主要靠数值方法（蒙特卡洛、级数展开、共形场论）
    临界温度：k_B T_c ≈ 4.5115 J
    临界指数：α≈0.110, β≈0.326, γ≈1.237, δ≈4.789, ν≈0.630, η≈0.036

  临界指数：

  在临界点附近，热力学量表现为幂律行为：

  指数     物理量          临界行为                   2D伊辛         3D伊辛         平均场
  -------------------------------------------------------------------------------------
  α      比热           C ~ |t|^{-α}           0 (log)      0.110        0 (jump)
  β      序参量          M ~ (-t)^β             1/8          0.326        1/2
  γ      磁化率          χ ~ |t|^{-γ}           7/4          1.237        1
  δ      临界等温线        M ~ h^{1/δ}            15           4.789        3
  ν      关联长度         ξ ~ |t|^{-ν}           1            0.630        1/2
  η      关联函数         G(r) ~ r^{-(d-2+η)}    1/4          0.036        0

  标度关系：

  临界指数不是完全独立的，满足标度关系：
    Rushbrooke：α + 2β + γ = 2
    Widom：γ = β(δ - 1)
    Fisher：γ = ν(2 - η)
    Josephson：dν = 2 - α （超标度关系，d是空间维度）

  平均场理论（朗道理论）：

  自由能展开（序参量φ）：
    F(φ) = F_0 + a(T) φ² + b φ⁴ + ... - h φ
    其中 a(T) = a_0 (T - T_c), b > 0

  极小值条件：∂F/∂φ = 2aφ + 4bφ³ - h = 0

  T > T_c 时：φ = 0（顺磁相）
  T < T_c 时：φ = ±√(-a/(2b)) = ±√(a_0(T_c-T)/(2b))（铁磁相）

  平均场临界指数：
    β = 1/2, γ = 1, δ = 3, α = 0（跳跃）, ν = 1/2, η = 0

  平均场理论在 d ≥ 4 时精确（上临界维度 d_u = 4）
  在 d < 4 时，涨落重要，需要重整化群

  重整化群（Renormalization Group, RG）：

  基本思想（Wilson, 1971）：
    1. 粗粒化：将短距离涨落积分掉（动量壳积分）
    2. 标度变换：重新标度长度和场量
    3. 得到耦合常数的重整化群流

  不动点：RG流的不动点对应临界点
    - 高斯不动点：自由场，在 d > 4 时稳定
    - Wilson-Fisher不动点：相互作用，在 d < 4 时稳定

  临界指数从不动点附近的线性化RG流得到

  ε展开（d = 4 - ε）：
    η = ε²/50 + ...
    ν = 1/2 + ε/12 + ...
    γ = 1 + ε/6 + ...
    β = 1/2 - ε/6 + ...

  普适性：

  临界行为只依赖于：
    1. 空间维度 d
    2. 序参量的对称性和分量数 n
    3. 相互作用的范围（短程 vs 长程）

  与微观细节无关！这就是普适性。

  普适类：
    - 伊辛普适类（n=1，Z₂对称）：气液临界点、二元合金、单轴铁磁
    - XY普适类（n=2，O(2)对称）：超流⁴He、 planar铁磁、超导
    - Heisenberg普适类（n=3，O(3)对称）：各向同性铁磁、反铁磁

  螺旋几何化解释：

  1. 相变的螺旋几何化
     - 序参量 = 螺旋集体运动的有序程度
     - 对称破缺 = 螺旋系统从高对称到低对称的转变
     - 关联长度 = 螺旋涨落的空间关联范围
     - 临界涨落 = 螺旋运动在临界点的大尺度涨落

  2. 伊辛模型的螺旋几何化
     - 自旋 = 螺旋粒子的取向（上/下）
     - 交换耦合 = 螺旋自旋之间的相互作用
     - 铁磁相 = 螺旋自旋的集体取向（有序）
     - 顺磁相 = 螺旋自旋的无规取向（无序）

  3. 重整化群的螺旋几何化
     - 粗粒化 = 螺旋运动的尺度变换
     - 标度变换 = 螺旋长度的重新标度
     - 不动点 = 螺旋系统的尺度不变点
     - 普适性 = 螺旋临界行为不依赖微观细节

【SP6】非平衡统计与输运
----------------------------------------------------------------------

  非平衡统计的基本问题：

  平衡态统计只描述系统的终态，非平衡统计描述系统如何到达终态。
  核心问题：不可逆性的起源、输运过程、涨落定理、自组织。

  玻尔兹曼方程：

  单粒子分布函数 f(r, v, t) 的演化方程：
    ∂f/∂t + v·∇_r f + (F/m)·∇_v f = (∂f/∂t)_coll

  左边：漂移项（自由运动+外力）
  右边：碰撞项

  玻尔兹曼碰撞项（分子混沌假设）：
    (∂f/∂t)_coll = ∫ d³v₂ ∫ dΩ |v₁-v₂| (f'f₂' - f f₂) σ(Ω)

  H定理（玻尔兹曼，1872）：
    定义 H(t) = ∫ d³v f ln f
    则 dH/dt ≤ 0，等号当且仅当 f 是局域麦克斯韦分布
    这证明了熵增：S = -k_B H，dS/dt ≥ 0

  可逆性佯谬（Loschmidt, 1876）：
    微观运动方程是时间反演不变的，为什么宏观有时间箭头？
    答案：初始条件的特殊性（低熵初始态）+ 分子混沌假设

  输运过程：

  过程         驱动力             流            定律                             系数
  --------------------------------------------------------------------------------
  热传导        温度梯度 ∇T         热流 q         傅里叶定律 q = -κ ∇T                热导率 κ
  扩散         浓度梯度 ∇n         粒子流 J        菲克定律 J = -D ∇n                 扩散系数 D
  黏滞         速度梯度 ∇v         动量流 Π        牛顿黏滞定律 Π = -η ∇v               黏滞系数 η
  电导         电场 E            电流 j         欧姆定律 j = σ E                   电导率 σ

  涨落耗散定理（Fluctuation-Dissipation Theorem）：

  表述：系统在平衡态的涨落与对外扰的响应（耗散）之间存在普适关系。

  爱因斯坦关系（1905）：
    D = μ k_B T
    其中 D 是扩散系数，μ 是迁移率（v_d = μ F）

  奈奎斯特-约翰逊噪声（1928）：
    电阻 R 的热噪声电压谱：S_V(ω) = 4 k_B T R
    这是电阻中电子热涨落的直接结果

  一般形式（Kubo, 1957）：
    响应函数 χ''(ω) = (π/ħ) ∫ dt e^{iωt} ⟨[A(t), A(0)]⟩
    耗散功率 P = (ω/2) χ''(ω) |F|²

  线性响应理论（Kubo公式）：

  对外力 F(t) 的线性响应：
    ⟨A(t)⟩ = ⟨A⟩₀ + ∫_{-∞}^t dt' χ(t-t') F(t')

  电导率的Kubo公式：
    σ(ω) = (1/iωV) ∫₀^∞ dt e^{iωt} ⟨[j(t), j(0)]⟩

  扩散系数的Kubo公式：
    D = (1/3) ∫₀^∞ dt ⟨v(t)·v(0)⟩

  涨落定理（Fluctuation Theorem）：

  Evans-Searles涨落定理（1994）：
    P(Σ_t = A) / P(Σ_t = -A) = e^{A t}
    其中 Σ_t 是时间平均熵产生率

  意义：
    - 定量描述了违反热力学第二定律的概率
    - 在长时间极限下，熵产生为正的概率指数地大于为负的概率
    - 恢复了热力学第二定律

  Jarzynski等式（1997）：
    ⟨e^{-βW}⟩ = e^{-βΔF}
    其中 W 是非平衡过程中外界对系统做的功，ΔF 是自由能差

  Crooks涨落定理（1999）：
    P_F(W) / P_R(-W) = e^{β(W-ΔF)}
    其中 P_F 是正过程的功分布，P_R 是逆过程的功分布

  螺旋几何化解释：

  1. 非平衡统计的螺旋几何化
     - 玻尔兹曼方程 = 螺旋粒子分布函数的演化
     - 碰撞项 = 螺旋粒子之间的散射
     - H定理 = 螺旋运动的熵增原理
     - 不可逆性 = 螺旋运动的时间箭头（初始条件+混沌）

  2. 输运过程的螺旋几何化
     - 热传导 = 螺旋能量的输运
     - 扩散 = 螺旋粒子的输运
     - 黏滞 = 螺旋动量的输运
     - 电导 = 螺旋电荷的输运
     - 涨落耗散定理 = 螺旋涨落与螺旋耗散的关系

  3. 涨落定理的螺旋几何化
     - 熵产生 = 螺旋运动的熵产生率
     - Jarzynski等式 = 螺旋功与螺旋自由能的关系
     - Crooks定理 = 螺旋正逆过程的对称性
     - 非平衡统计 = 螺旋运动在非平衡条件下的统计

【SP7】统计场论与重整化群
----------------------------------------------------------------------

  统计场论的基本框架：

  配分函数的路径积分表示：
    Z = ∫ Dφ e^{-S[φ]/k_B T}
    其中 S[φ] 是场的作用量（自由能泛函）

  这与量子场论的路径积分完全对应：
    量子场论：Z = ∫ Dφ e^{iS[φ]/ħ}
    统计场论：Z = ∫ Dφ e^{-S[φ]/k_B T}
     Wick转动：t → -iτ, ħ → k_B T

  因此，量子场论的所有技术（费曼图、重整化群等）都可以应用于统计场论。

  朗道-金兹堡-威尔逊有效作用量：

  对于 n 分量标量场 φ = (φ₁, ..., φₙ)：
    S[φ] = ∫ d^d x [ (1/2)(∇φ)² + (r/2)φ² + (u/4!)(φ²)² + ... ]

  参数：
    r = r₀ (T - T_c)：质量项（二次项系数）
    u > 0：四次耦合（稳定势）
    梯度项：(∇φ)² 描述空间不均匀性的能量代价

  高斯模型（u=0）：

  配分函数可以精确计算（高斯积分）：
    Z = ∏_k (2π/(k² + r))^{n/2}

  关联函数：
    ⟨φ(k)φ(-k)⟩ = 1/(k² + r)
    实空间：G(r) ~ e^{-r/ξ} / r^{(d-2)/2}, ξ = 1/√r

  临界行为：
    关联长度 ξ ~ |t|^{-1/2} ⟹ ν = 1/2
    关联函数 G(r) ~ r^{-(d-2)} ⟹ η = 0
    这就是平均场结果，在 d ≥ 4 时精确

  Wilson-Fisher不动点（d < 4）：

  一圈重整化群流（ε = 4 - d）：
    dr/dl = 2r + (n+2)/(2π²) u Λ² / (1 + rΛ^{-2})²
    du/dl = ε u - (n+8)/(6π²) u²

  不动点：
    高斯不动点：r* = 0, u* = 0（d > 4 时稳定）
    Wilson-Fisher不动点：r* = - (n+2)/(n+8) ε Λ², u* = 6π² ε/(n+8)

  临界指数（ε展开，一圈）：
    η = ε²/(2(n+8)²) + ...
    ν = 1/2 + (n+2)/(4(n+8)) ε + ...
    γ = 1 + (n+2)/(2(n+8)) ε + ...
    β = 1/2 - (n+2)/(2(n+8)) ε + ...
    α = (4-n)/(2(n+8)) ε + ...
    δ = 3 + ε + ...

  三维伊辛模型ε展开（ε=1，一圈）临界指数：
    η = 0.0062 （精确值~0.036）
    ν = 0.5833 （精确值~0.630）
    γ = 1.1667 （精确值~1.237）
    β = 0.3333 （精确值~0.326）
  注：ε=1时一圈展开精度有限，需要高阶展开或数值方法

  共形场论（Conformal Field Theory, CFT）：

  在临界点，系统具有标度不变性，进一步假设具有共形不变性，
  就得到共形场论。CFT是描述临界点的强大工具。

  二维CFT：
    - 无限维共形代数（Virasoro代数）
    - 可以精确求解（最小模型）
    - 二维伊辛 = 最小模型 M(4,3)，中心荷 c = 1/2
    - 临界指数可以从共形维数精确得到

  三维CFT：
    - 有限维共形代数（SO(d+1,1)）
    - 不能精确求解，但可以用共形引导（Conformal Bootstrap）
    - 三维伊辛CFT的临界指数已经通过共形引导精确计算
    - 精度超过蒙特卡洛模拟！

  拓扑场论与拓扑相变：

  2016年诺贝尔物理学奖（Thouless, Haldane, Kosterlitz）：
    - Kosterlitz-Thouless相变：二维XY模型中的涡旋-反涡旋对解离
    - 拓扑相变：不伴随对称破缺，由拓扑序变化驱动
    - 量子霍尔效应：拓扑不变量（陈数）描述的量子态

  拓扑序（Wen, 1989）：
    - 不能用局域序参量描述的有序态
    - 由长程纠缠模式刻画
    - 例子：分数量子霍尔态、自旋液体、拓扑超导体

  螺旋几何化解释：

  1. 统计场论的螺旋几何化
     - 序参量场 = 螺旋集体运动的场描述
     - 路径积分 = 所有螺旋场构型的求和
     - 朗道-金兹堡作用量 = 螺旋场的有效作用量
     - 高斯模型 = 自由螺旋场

  2. 重整化群的螺旋几何化
     - 粗粒化 = 螺旋运动的尺度平均
     - 标度变换 = 螺旋长度的重新标度
     - Wilson-Fisher不动点 = 螺旋临界不动点
     - ε展开 = 螺旋临界行为的维度展开

  3. 共形场论的螺旋几何化
     - 共形不变性 = 螺旋系统的尺度+旋转+特殊共形不变性
     - 共形维数 = 螺旋场的标度维数
     - 中心荷 = 螺旋CFT的中心荷
     - 拓扑序 = 螺旋系统的长程纠缠模式

【SP8】复杂系统与自组织
----------------------------------------------------------------------

  复杂系统的特征：

  1. 大量相互作用的单元
  2. 涌现行为（整体大于部分之和）
  3. 非线性动力学
  4. 反馈回路
  5. 自组织
  6. 适应性
  7. 历史依赖性（路径依赖）

  复杂系统的例子：

  系统              组成单元                      涌现行为                      尺度
  -------------------------------------------------------------------------------------
  生命系统            细胞、蛋白质、基因                 生命、意识、进化                  nm - m
  神经系统            神经元、突触                    意识、记忆、学习                  μm - m
  生态系统            物种、种群                     食物链、生物多样性                 m - km
  经济系统            个体、企业、市场                  价格、周期、危机                  人 - 全球
  社会系统            人、组织、文化                   规范、制度、文明                  人 - 全球
  互联网             计算机、路由器、用户                WWW、社交网络、病毒传播             m - 全球
  气候系统            大气、海洋、生物圈                 天气、气候、冰期                  km - 全球
  星系宇宙            恒星、星系、暗物质                 星系结构、大尺度结构                km - Gpc

  自组织临界性（Self-Organized Criticality, SOC）：

  Bak-Tang-Wiesenfeld沙堆模型（1987）：
    - 在沙堆上缓慢加沙粒
    - 当局部坡度超过阈值时发生雪崩
    - 系统自然演化到临界状态
    - 雪崩大小服从幂律分布：P(s) ~ s^{-τ}

  特征：
    - 不需要微调参数，系统自动到达临界点
    - 幂律分布（无标度）
    - 1/f噪声
    - 分形结构

  应用：
    - 地震（Gutenberg-Richter定律）
    - 太阳耀斑
    - 森林火灾
    - 生物进化（间断平衡）
    - 经济波动

  网络科学：

  复杂网络的统计性质：

  1. 度分布 P(k)：
     - 随机网络（Erdős-Rényi）：泊松分布 P(k) ~ e^{-⟨k⟩} ⟨k⟩^k/k!
     - 无标度网络（Barabási-Albert）：幂律分布 P(k) ~ k^{-γ}, γ≈2-3
     - 小世界网络（Watts-Strogatz）：高聚类系数+短平均路径

  2. 聚类系数 C：
     - 衡量节点的邻居之间互为邻居的概率
     - 社会网络：C ~ 0.5（高聚类）
     - 随机网络：C ~ ⟨k⟩/N（低聚类）

  3. 平均路径长度 L：
     - 任意两节点之间的最短路径的平均值
     - 小世界：L ~ ln N / ln ⟨k⟩
     - 六度分离：地球上任意两人之间平均通过6个人相连

  渗流理论（Percolation Theory）：

  基本模型：
    - 在晶格上以概率 p 随机占据格点（或键）
    - 当 p < p_c 时，只有有限大小的团簇
    - 当 p > p_c 时，出现无限大团簇（渗流）
    - p_c 是渗流阈值
