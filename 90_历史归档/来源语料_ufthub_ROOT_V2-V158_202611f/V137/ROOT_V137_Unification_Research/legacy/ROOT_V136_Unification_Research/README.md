## 重要进展（不等于新物理发现）

1. **不依赖裸 GM 的双高度诊断**：`D(r1,r2) = [r1²|g(r1)|]/[r2²|g(r2)|]-1 = [eps(r1)-eps(r2)]/[1+eps(r2)]`，仅在球对称、其他扰动已排除的条件下适用。
2. **不依赖 α、GM、球对称源密度的三高度形状比**：`Q = [A(r0)-A(r1)]/[A(r1)-A(r2)]`，其中 `A(r)=r²|g(r)|`、`r0<r1<r2`。该式仍**依赖 λ 与半径及观测清理**；若新力为零则为无定义的 `0/0`。
3. **径向导数—轨道进动联动**：`kappa_r²=GM/r³*[1+eps(r)+r eps'(r)]`；`Omega²=GM/r³*[1+eps(r)]`。不必重新引入自由进动系数。
4. **三力垂直反例**：任意平行的静电场与磁场满足 `E·B != 0`，而 `E·B` 是洛伦兹不变量，不能成为普适三正交力定律。
5. **纯几何不能唯一预测 α_EM**：`tau/kappa = u/(aω)`，在 `a²ω²+u²=1` 下通过任意选取 `u` 可匹配任何正实数。若无额外动力学和无自由参数极值机制，拟合精细结构常数不算推导。
6. **自由光速螺旋不是平直时空自由运动**：该螺旋在坐标时间下有非零空间加速度；需要给出场或有效几何产生的动力学，否则不能视为已推导出的光子自由传播。
