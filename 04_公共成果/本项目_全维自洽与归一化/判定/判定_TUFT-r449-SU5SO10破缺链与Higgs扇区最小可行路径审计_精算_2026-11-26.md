## 〇、一句话结论

**最小 SU(5) 不能只用 `24_H`：`24` 的 SM 分解没有弱双态，必须补 `5_H+5bar_H`，并立刻承担 doublet–triplet 分裂与中微子单态外源。受控路径表中，SO(10) 的 `45_H+126_H+10_H` 是唯一同时覆盖「到 SM / 弱双态 / ν_R Majorana」三项硬需求的三场最小集；`45_H+16_H+16bar_H+10_H` 缺可归一化 Majorana，`126_H` 单独不能到 SM。所有 PASS 只是群论与账本自洽，不表示 TUFT 派生出 GUT，也不表示自然界采用 SU(5) 或 SO(10)。**

## 二、SU(5)：物质侧闭合，Higgs 侧必须外补

`5bar+10` 分解为 `d^c(3bar,1)_{1/3} + L(1,2)_{-1/2} + Q(3,2)_{1/6} + u^c(3bar,1)_{-2/3} + e^c(1,1)_1`，逐块维数 `3+2+6+3+1 = 15`。在 `Q=T3+Y` 下机器给出：

| 反常矩 | 值 |
|---|---|
| `TrY` | `0` |
| `TrY^3` | `0` |
| `[SU(2)_L]^2 U(1)_Y` | `0` |
| `[SU(3)_C]^2 U(1)_Y` | `0` |

阳性对照把五个 SM 块的 `Y` 全置 `1`，得到 `TrY=15`，所以「全零」不是解析器失效。物质侧无 exotic：一代正好 SM15；这比 r448 trinification 27 的 `5+7=12` 个外态更省谱。代价在 Higgs：最小 SU(5) 无 `nu_R`，中微子 Majorana 质量要额外单态或高阶算符。

规范伴随 `24` 分解为 `8+3+1` 加 `12` 个 X/Y 型重向量，维数闭合 `24=12+12`。但 `24_H` 的 SM 双态数为 **0**，所以「只用 `24_H`」是硬 FAIL；必须有 `5_H+5bar_H`。这同时带入一对色三重态 T/Tbar：若取 `M_GUT=2e16 GeV`、`m_H=125 GeV`，双重态—三重态分裂记价为 `1.600000000000E+14`。这个比值是外部质量选择，不是群论结论。

## 三、SO(10)：谱优势明确，最小可走场集仍带外生阈值

SO(10) 一代 `16 = 10 + 5bar + 1`，即 SM15 加 `nu_R`；这比最小 SU(5) 多了 Majorana 质量的谱载体。伴随 `45` 减去 SM 的 `8+3+1` 后剩 `33` 个重向量，维数闭合，但质量化仍是外部输入。

受控场集表：

| 路径 | 场集 | 到 SM | 弱双态 | ν_R Majorana | 判定 |
|---|---|---|---|---|---|
| `SU5_24_only` | `24_H` | 否 | 否 | 否 | FAIL |
| `SU5_24_plus_5pair` | `24_H+5_H+5bar_H` | 是 | 是 | 否 | 最小但外源 |
| `SO10_45_126_10` | `45_H+126_H+10_H` | 是 | 是 | 是 | 受控集内最小可走 |
| `SO10_45_16pair_10` | `45_H+16_H+16bar_H+10_H` | 是 | 是 | 否 | 需额外单态/高阶 |
| `SO10_126_only` | `126_H` | 否 | 是 | 是 | FAIL |

`126_H` 单独可给 B-L 破缺与 `nu_R` 质量载体，但保留 SU(5) 方向，不能单独到 SM；`16_H/16bar_H` 可做方向 Breaking，`10_H` 可给双态，但没有 `126_H` 或额外单态/高阶算符时，不可归一化地给 `nu_R` Majorana 质量。因此受控集内最小可走路径是 `45_H+126_H+10_H`，其代价是 `126_H` 的 10、15、45、50 等非 SM 成分必须质量化，并且仍有 doublet–triplet 分裂。

## 四、与 r448 的对照：不是「谁零代价」，而是「代价落在哪」

r448 的 trinification 27 经 SM 匹配后可定标 `(a,b)=(-1/2,1)`，但含 `15+5+7=27`：额外 SM 5 态与纯 exotic 7 态都需要质量机制。SU(5) 的物质侧代价最低（0 exotic），代价移到 Higgs 双重态—三重态分裂与中微子单态；SO(10) 的物质侧多一个 `nu_R`，代价移到 126 外态与阈值谱。三者的共同点是：**场集选择只决定外部输入落点，不消灭外部输入。**
