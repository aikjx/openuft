## 五、为什么不直接写体系归属

文件名同名不等于同一体系。已知案例：本批 `momentum_darboux.py`、
`oam_tuft_couple_audit.py` 与现行 `01_独立体系/S02_空间光速螺旋统一力/04_理论推导/`
下的同名文件是同源副本；而 `全域统一场论_*.md` 一类文件名带 TUFT、本体却可能是
另一体系。因此本目录只做主题分箱，归属一律记 `待归属`，附**线索**而非结论。
