# 数学定理与严格审计｜ROOT V91

> 所有结论限定在两个位置量子比特的冻结轨迹、点源径向势、固定正几何距离、经典中心距和实正 Yukawa 作用距离。数学定理不是对自然界第五力的实测。

## 定义

令 `a,b>0`、`d>(a+b)/2`、`δ=d−(a+b)/2>0`。取 A 位于 `x0=−a/2, x1=+a/2`，B 位于 `y0=d−b/2, y1=d+b/2`。四个距离 `r_ij=y_j−x_i` 严格为正。令 `D[f]=f(r00)−f(r01)−f(r10)+f(r11)`，以及 `F_N=D[1/r]`，`F_Y(μ)=D[e^(−μr)/r]`。

### 定理 1：精确混合二阶积分

若 f 二次连续可微，`D[f]=−∫_{−a/2}^{a/2}du∫_{−b/2}^{b/2}dv f''(d+v−u)`。证明：对 `g(u,v)=f(d+v−u)` 运用两次微积分基本定理，`∂u∂vg=−f''`。四边项恰好给出交叉差分。因而 `D[1]=D[r]=0`。对于 `f''>0` 有 `D[f]<0`。

### 定理 2：Yukawa 形状单调性

对 μ 求导，

`dF_Y/dμ=−[e^(−μr00)−e^(−μr01)−e^(−μr10)+e^(−μr11)]`

`=−2e^(−μd)[cosh(μ(a−b)/2)−cosh(μ(a+b)/2)]`

`=4e^(−μd)sinh(μa/2)sinh(μb/2)>0`。

`F_Y(0)=F_N<0`，`F_Y(∞)=0`（四个中心距全为正），故 `F_N<F_Y(μ)<0`。对任何正 μ 均成立。

### 定理 3：全区间上、下界

积分得：

`F_Y(μ)−F_N=4∫₀^μ e^(−td)sinh(ta/2)sinh(tb/2)dt`。

对 x≥0，`x≤sinh x≤xe^x`，故

`ab t²e^(−td) ≤ 4e^(−td)sinh(ta/2)sinh(tb/2) ≤ ab t² e^(−tδ)`。

积分得到严格不等式：

`ab∫₀^μ t²e^(−td)dt ≤ F_Y−F_N ≤ ab∫₀^μ t² e^(−tδ)dt ≤ abμ³/3`。

积分可用闭式 `∫₀^μ t² e^(−zt) dt=2/z³[1−e^(−zμ)(1+zμ+(zμ)²/2)]`（z>0），但在 zμ 很小时直接用该闭式会发生消去误差；程序使用正积分求积。长程上界收敛阶次 `O(λ^-3)` 是严格的，除可能因 a 或 b 为 0 导致全零的退化情形。

### 定理 4：未知背景阶数的精确消零

用 µ=1/λ，把 `F_Y−F_N` 展开为 `Σ_{n≥1} (−1)^n µ^n/n! D[r^{n−1}]`。n=1,2 项严格为零。若 n≥3，混合二阶积分对 `f(r)=r^{n−1}` 给：

`D[r^{n−1}]=−(n−1)(n−2)∫du∫dv (d+v−u)^{n−3}`。

所以它是 d 的至多 n−3 次多项式，最高次系数 `−ab(n−1)(n−2)`。于是 n≥3 项的最高次部分为

`(−1)^{n+1} ab d^{n−3} µ^n/[n(n−3)!]`。

若未知相位背景跨 d 为 `B_p(d)=Σ_{j=0}^p b_j d^j`，且 a,b 固定、所有观测点在同一几何/时间标定下，令 P 消除多项式空间 `span{1,d,...,d^p}`。则对所有 `3≤n≤p+3`，`P D[r^{n−1}]=0`。故

`P(F_Y−F_N) = O(µ^{p+4}) = O(λ^{−(p+4)})`。

当观测距离足够多且 `P(d^{p+1})` 非零（并且新增的其它 nuisance 方向并不将其完全吸收），该阶数一般有非零首项。否则它可能被进一步消掉，不能反向保证必有可见信号。无多项式背景 p=−1 时可单独规定按 µ³ 起始。

**Fisher 后果**：给定固定的正定协方差 Σ、固定 λ、线性幅度 α 和固定 nuisance 空间，`I_α = (∂_α y)^T Σ^{-1}P_Σ (∂_α y)`，若 `∂_α y ∼ µ^{p+4}`，则 `I_α = O(µ^{2(p+4)})`。若 λ 也未知，第一领先阶的 α 与 λ 通常退化，不得宣称两者已被精确识别。

### 定理 5：电荷反转不能消去电荷偶同核背景

假设同核 f(d)=F_N(d)，有两种电荷设置 `y_s(d)=[g+u+s e]f(d)+noise`，s=+1,−1，g 是引力幅度、u 是电荷偶/其它未知背景、e 是电荷奇项。对任意测量距离向量 f，雅可比三个列是 `(f,sf,f)`，所以第一列与第三列相等，矩阵最大秩 2；即使数据无限精确也无法由此模型单独分离 g 与 u。

如果增加一项对 u 的**独立校准观测** `z=u+noise`，矩阵多一行 `(0,1,0)`（按具体列排列），在至少一个非零 f 和两种 s 配置下秩可达 3。这是仅针对相同 1/r 核、线性带符号相位的严格可辨识性结论；真实电磁背景不必为同核，也可能随实验操纵发生变化。

## 独立计算与限制

- 19 项 SymPy 等式检查与 107 项单元测试，含 80 个参数化几何/作用距离组合。
- 100 位 mpmath 基于四个指数项直接算差，独立交叉验证正积分方法。请勿把这种数值精度理解为实验仪器精度。
- 两个均匀球的 Newton 壳层定理不能直接推广至任意材料 Yukawa 核或动力学过程。
- 理论相位 `Δ=(Gm_Am_B t/ħ)F` 在冻结理想模型中计算，真实纠缠见证还必须包含状态准备、测量、退相干和所有背景。
