### 五条核心裁定

1. **原始版本不可用**：`m=ω²r³` 左右量纲差恰为 `[G]`；原始场 `A=-m/R²` 量纲 `(M⁻¹L⁻²)` 非加速度场——两处真实硬伤。

4. **本源质量定义未真正修复（诚实追加 D09）**：`m=n₀/4π` 即使固定 `n₀` 仍无量纲≠`[M]`；令 `n₀` 自带 `[M]` 则循环定义。原稿「固定 n₀ 即自洽」只对轨道/Gauss 部分成立。
