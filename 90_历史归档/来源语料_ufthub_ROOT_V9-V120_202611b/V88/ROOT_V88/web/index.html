核心公式：Δ = (Gm₁m₂ − q₁q₂/4πε₀)t/ℏ · (1/r₀₀ − 1/r₀₁ − 1/r₁₀ + 1/r₁₁)。纯态纠缠 C = |sin(Δ/2)|。局部退相干通过 4×4 密度矩阵部分转置特征值求负性。


证据等级与已知局限
数学上成立
给定两体 Newton 势算符、冻结路径、初始无纠缠等条件，非局部相位和纯态 concurrence 可严格推出。局部经典通信通道无法从可分初态生成纠缠。
没有证明
本模拟不证明引力场本身已经量子化，更没有解释 G 的起源、统一四种相互作用或排除所有经典／混合模型。若存在电磁或其他量子通信通道，纠缠不必源于引力。
