【OP2】几何光学
----------------------------------------------------------------------

  几何光学基本定律：

  1. 光的直线传播定律：
     在均匀介质中，光沿直线传播。
     这是短波长极限（λ→0）下的近似。

  2. 反射定律：
     入射角 = 反射角
     θ_i = θ_r
     入射光线、反射光线、法线在同一平面内

  3. 折射定律（斯涅尔定律，Snell's Law, 1621）：
     n1 sin θ1 = n2 sin θ2
     其中 n1, n2 是两种介质的折射率
     入射光线、折射光线、法线在同一平面内

  折射定律计算示例：
    空气(n1=1.0) → 玻璃(n2=1.5)
    入射角 θ1 = 45.0°
    折射角 θ2 = arcsin(n1 sin θ1 / n2) = 28.13°

  4. 全反射：
     当光从光密介质射向光疏介质（n1 > n2）时，
     当入射角大于临界角时，发生全反射。
     临界角：θ_c = arcsin(n2/n1)

  全反射临界角计算（玻璃→空气）：
    n1 = 1.0 (玻璃), n2 = 1.5 (空气)
    临界角 θ_c = arcsin(n2/n1) = 90.00°
    应用：光纤、全反射棱镜、隐失波

  费马原理（Fermat's Principle, 1657）：

  光在两点之间传播的路径是光程取极值（最小值、最大值或恒定值）的路径。

  数学表达式：
    δ ∫ n(s) ds = 0
    其中 n(s) 是路径上的折射率，ds 是路径元

  透镜成像：

  薄透镜公式：
    1/f = 1/d_o + 1/d_i
    其中 f 是焦距，d_o 是物距，d_i 是像距

  放大率：
    M = -d_i / d_o = h_i / h_o

  透镜制造者公式：
    1/f = (n-1)(1/R1 - 1/R2)

  透镜焦距计算示例（双凸透镜）：
    折射率 n = 1.5
    曲率半径 R1 = 100 mm, R2 = -100 mm
    焦距 f = 1/[(n-1)(1/R1 - 1/R2)] = 100.0 mm

  螺旋几何化解释：

  1. 几何光学的螺旋几何化
     - 光线 = 螺旋光的能量传播方向（坡印廷矢量方向）
     - 直线传播 = 均匀介质中螺旋光沿直线传播
     - 反射 = 螺旋光在界面的反射
     - 折射 = 螺旋光在不同介质中传播速度变化导致的偏折

  2. 费马原理的螺旋几何化
     - 光程 = 螺旋光传播路径的光学长度
     - 极值原理 = 螺旋光选择光程极值的路径
     - 这是最小作用量原理在光学中的体现

【OP3】波动光学
----------------------------------------------------------------------

  光的波动性：

  光是电磁波，由互相垂直的电场和磁场振荡组成，
  传播方向垂直于电场和磁场（横波）。

  平面电磁波：
    E(r,t) = E0 cos(k·r - ωt + φ)
    B(r,t) = B0 cos(k·r - ωt + φ)
    其中 k = 2π/λ 是波矢，ω = 2πν 是角频率
    关系：ω = ck, E0 = c B0

  光的偏振：

  偏振类型         描述                             分量关系
  ----------------------------------------------------------------------
  线偏振          电场矢量在固定平面内振荡                   Ex, Ey 同相或反相
  圆偏振          电场矢量旋转，大小不变                    Ex, Ey 振幅相等，相位差±π/2
  椭圆偏振         电场矢量旋转，大小变化                    Ex, Ey 振幅不等，相位差任意
  自然光          偏振方向随机变化                       各方向均匀分布，无固定相位关系
  部分偏振         介于自然光和线偏振之间                    有一个方向占优

  光的干涉：

  两束相干光叠加时，产生干涉条纹。

  双缝干涉（杨氏双缝，Thomas Young, 1801）：
    条纹间距：Δy = λ L / d
    其中 λ 是波长，L 是缝到屏的距离，d 是双缝间距

  双缝干涉计算示例：
    波长 λ = 550 nm (绿光)
    缝到屏距离 L = 1.0 m
    双缝间距 d = 0.10 mm
    条纹间距 Δy = λL/d = 5.50 mm

  光的衍射：

  圆孔衍射（艾里斑，Airy pattern, 1835）：
    第一暗环角位置：sin θ = 1.22 λ / D
    其中 D 是圆孔直径
    瑞利判据（Rayleigh criterion, 1879）：
    最小分辨角：θ_min = 1.22 λ / D

  望远镜分辨率计算（哈勃望远镜）：
    口径 D = 2.4 m
    观测波长 λ = 550 nm
    最小分辨角 θ_min = 1.22λ/D = 0.280 μrad = 0.058 角秒

  光的散射：

  散射类型         条件                 波长依赖               例子
  ----------------------------------------------------------------------
  瑞利散射         粒子尺寸 << λ          I ∝ 1/λ^4          天空蓝色、日落红色
  米氏散射         粒子尺寸 ~ λ           弱依赖                云雾、牛奶
  拉曼散射         非弹性散射              频率移动               拉曼光谱
  布里渊散射        声子散射               频率移动               布里渊光谱
  康普顿散射        X射线/γ射线            波长变长               X射线散射

  螺旋几何化解释：

  1. 波动光学的螺旋几何化
     - 光波 = 螺旋电磁波
     - 偏振 = 螺旋电场矢量的振荡取向
     - 干涉 = 两束螺旋光的相干叠加
     - 衍射 = 螺旋光绕过障碍物的传播
     - 散射 = 螺旋光与粒子的相互作用

  2. 偏振的螺旋几何化
     - 线偏振 = 螺旋电场在固定平面内振荡
     - 圆偏振 = 螺旋电场矢量旋转（左旋/右旋）
     - 圆偏振光携带自旋角动量（±ħ per photon）

【OP4】量子光学
----------------------------------------------------------------------

  光子的基本性质：

  光子是光的量子，是电磁辐射的能量量子。

  基本性质：
    - 能量：E = hν = ħω
    - 动量：p = h/λ = ħk
    - 静止质量：0
    - 自旋：1（玻色子）
    - 速度：c（真空中）
    - 电荷：0

  光子能量计算：
    无线电波(1m)          : E = hc/λ = 1.2398e-06 eV
    微波(1cm)           : E = hc/λ = 1.2398e-04 eV
    红外(1um)           : E = hc/λ = 1.2398e+00 eV
    可见光(550nm)        : E = hc/λ = 2.2543e+00 eV
    紫外(100nm)         : E = hc/λ = 1.2398e+01 eV
    X射线(1nm)          : E = hc/λ = 1.2398e+03 eV
    γ射线(1pm)          : E = hc/λ = 1.2398e+06 eV

  光电效应（Einstein, 1905，1921诺贝尔奖）：

  爱因斯坦方程：
    hν = W + K_max
    其中 W 是逸出功，K_max 是最大动能

  关键特征（无法用经典波动理论解释）：
    1. 存在截止频率，低于此频率无论光强多大都没有光电子
    2. 光电子最大动能只与频率有关，与光强无关
    3. 光电效应是瞬时的（<10^-9 s）

  康普顿散射（Compton, 1923，1927诺贝尔奖）：

  X射线被电子散射后波长变长，证明光子具有动量。

  康普顿公式：
    Δλ = λ' - λ = (h/(m_e c))(1 - cos θ)
    其中 λ_C = h/(m_e c) = 2.426×10^-12 m 是电子康普顿波长

  电子康普顿波长：
    λ_C = h/(m_e c) = 2.4263 pm
    康普顿 shift at θ=90°: Δλ = λ_C = 2.4263 pm

  量子光学基本概念：

  概念                   描述                                  性质
  --------------------------------------------------------------------------------
  光子数态(Fock态)          光子数确定的态 |n⟩                         相位完全不确定
  相干态                  最接近经典电磁波的量子态 |α⟩                    泊松光子数分布, 最小不确定
  压缩态                  一个正交分量噪声低于散粒噪声                      另一个分量噪声增加
  纠缠态                  两个或多个光子的量子关联                        违反Bell不等式
  单光子源                 每次只发射一个光子                           反聚束效应

  相干态（Glauber, 1963，2005诺贝尔奖）：

  定义：湮灭算符的本征态 a |α⟩ = α |α⟩

  光子数分布：泊松分布
    P(n) = |⟨n|α⟩|² = e^{-|α|²} |α|^{2n} / n!
    平均光子数：⟨n⟩ = |α|²
    光子数方差：⟨(Δn)²⟩ = |α|² = ⟨n⟩

  压缩态：

  正交分量：X1 = (a + a†)/√2, X2 = (a - a†)/(i√2)
  不确定关系：ΔX1 ΔX2 ≥ 1/2

  压缩态：一个正交分量的噪声低于散粒噪声极限
    ΔX1 < 1/√2 （压缩）
    ΔX2 > 1/√2 （反压缩）
    保持 ΔX1 ΔX2 = 1/2

  应用：
    - 引力波探测（LIGO使用压缩光提高灵敏度）
    - 量子通信
    - 精密测量

  量子纠缠与Bell不等式：

  EPR佯谬（Einstein, Podolsky, Rosen, 1935）：
    量子力学是否完备？纠缠态是否意味着超光速通信？

  Bell不等式（Bell, 1964）：
    任何定域隐变量理论都满足 Bell 不等式
    量子力学预言违反 Bell 不等式

  实验验证（Aspect, 1982；Zeilinger, 1990s；2022诺贝尔奖）：
    实验明确违反 Bell 不等式，排除定域隐变量理论
    2022年诺贝尔物理学奖（Aspect, Clauser, Zeilinger）

  螺旋几何化解释：

  1. 光子的螺旋几何化
     - 光子 = 螺旋电磁波的量子
     - 能量 = 螺旋振荡的能量量子
     - 动量 = 螺旋波的动量
     - 自旋 = 螺旋偏振的内禀角动量
     - 光电效应 = 螺旋光子被电子吸收
     - 康普顿散射 = 螺旋光子与电子的弹性碰撞

  2. 量子光学的螺旋几何化
     - Fock态 = 螺旋光子数确定的态
     - 相干态 = 螺旋光的最经典量子态
     - 压缩态 = 螺旋正交分量的噪声压缩
     - 纠缠态 = 螺旋光子之间的量子关联
     - 腔QED = 螺旋光子与螺旋原子在腔中的强耦合

【OP5】非线性光学
----------------------------------------------------------------------

  非线性光学基本原理：

  当光强足够大时，介质的极化强度与电场强度呈非线性关系。

  极化强度展开：
    P = ε0 (χ^(1)E + χ^(2)E² + χ^(3)E³ + ...)
    其中 χ^(1) 是线性极化率，χ^(2), χ^(3) 是非线性极化率

  二阶非线性效应（χ^(2)）：

  效应                     过程                     应用
  ----------------------------------------------------------------------
  二次谐波产生(SHG)            ω + ω → 2ω             频率倍频、绿光产生
  和频产生(SFG)              ω1 + ω2 → ω3           频率上转换、紫外产生
  差频产生(DFG)              ω1 - ω2 → ω3           红外产生、太赫兹产生
  光参量放大(OPA)             ωp → ωs + ωi           光参量振荡器、宽带光源
  线性电光效应(Pockels)        电场调制折射率                电光调制器、Q开关

  二次谐波产生（SHG, Franken et al., 1961）：

  两个频率为ω的光子合并为一个频率为2ω的光子。

  相位匹配条件：
    k(2ω) = 2k(ω)
    即 n(2ω) = n(ω)

  常用晶体：
    - KDP (KH2PO4)
    - BBO (β-BaB2O4)
    - LBO (LiB3O5)
    - LiNbO3

  三阶非线性效应（χ^(3)）：

  效应                     过程                        应用
  ---------------------------------------------------------------------------
  三次谐波产生(THG)            ω + ω + ω → 3ω            紫外产生、显微镜
  四波混频(FWM)              ω1 + ω2 - ω3 → ω4         相位共轭、波长转换
  光克尔效应                  n = n0 + n2 I             光开关、锁模、光限幅
  自相位调制(SPM)             相位随光强变化                   超连续谱产生、脉冲压缩
  交叉相位调制(XPM)            一束光调制另一束光的相位              光开关、波长转换
  受激拉曼散射(SRS)            光子+声子→光子                  拉曼激光器、光纤通信
  受激布里渊散射(SBS)           光子+声波→光子                  相位共轭、光纤传感
  双光子吸收(TPA)             同时吸收两个光子                  三维光存储、双光子显微镜

  光克尔效应与自聚焦：

  折射率随光强变化：
    n(I) = n0 + n2 I
    其中 n2 是非线性折射率系数

  自聚焦：
    高斯光束中心光强大，折射率高，相当于凸透镜
    当功率超过临界功率时，发生自聚焦
    临界功率：P_cr ≈ λ² / (2π n0 n2)

  超连续谱产生（Supercontinuum Generation）：

  当强激光脉冲在非线性介质（如光子晶体光纤）中传播时，
  多种非线性效应（SPM, SRS, FWM, 孤子裂变等）共同作用，
  产生从可见光到红外的超宽连续光谱。

  应用：
    - 光频梳（2005诺贝尔奖，Hänsch, Hall）
    - 光学相干断层扫描（OCT）
    - 光谱学
    - 电信（WDM光源）

  螺旋几何化解释：

  1. 非线性光学的螺旋几何化
     - 非线性极化 = 强光下螺旋电场与物质的非线性相互作用
     - χ^(2)效应 = 两个螺旋光子合并/分裂
     - χ^(3)效应 = 三个螺旋光子相互作用
     - 相位匹配 = 螺旋光子的动量守恒

  2. 二次谐波的螺旋几何化
     - SHG = 两个低频螺旋光子合并为一个高频螺旋光子
     - 能量守恒：2ħω = ħ(2ω)
     - 动量守恒：2k(ω) = k(2ω)
     - 这是螺旋光子的非线性相互作用

【OP6】激光物理
----------------------------------------------------------------------

  激光的基本原理：

  LASER = Light Amplification by Stimulated Emission of Radiation
  受激辐射光放大

  激光产生的三个条件：
    1. 增益介质（实现粒子数反转）
    2. 泵浦源（提供能量）
    3. 光学谐振腔（提供反馈和选频）

  爱因斯坦辐射理论（1917）：

  三种辐射过程：
    1. 自发辐射：A21 N2（激发态原子自发跃迁）
    2. 受激吸收：B12 ρ(ν) N1（基态原子吸收光子）
    3. 受激辐射：B21 ρ(ν) N2（激发态原子在光子激励下辐射）

  爱因斯坦关系：
    A21/B21 = 8πhν³/c³
    B12 = B21（简并度相等时）

  粒子数反转：N2 > N1
    这是激光放大的必要条件
    需要外界泵浦能量来实现

  激光器的类型：

  类型              增益介质                      波长                        泵浦              应用
  ----------------------------------------------------------------------------------------------------
  固体激光器           Nd:YAG, 红宝石, 钛宝石          694nm, 1064nm, 650-1100nm 闪光灯, 激光二极管      工业加工, 医疗, 科研
  气体激光器           He-Ne, Ar+, CO2, 准分子      633nm, 488/514nm, 10.6um, 193/308nm 气体放电            全息, 光谱, 医疗, 光刻
  半导体激光器          GaAs, InP, GaN            405-1550nm                电流注入            通信, 存储, 显示, 医疗
  光纤激光器           掺稀土光纤 (Er, Yb, Tm)        1064nm, 1550nm, 2um       激光二极管           工业加工, 通信, 医疗
  染料激光器           有机染料溶液                    可调(400-900nm)             其他激光            光谱, 科研
  自由电子激光器         相对论电子束                    可调(微波-X射线)                电子加速器           科研, 国防

  激光的特性：

  1. 单色性：谱线宽度极窄（Δλ/λ ~ 10^-10 或更窄）
  2. 方向性：发散角极小（接近衍射极限）
  3. 相干性：时间相干和空间相干都很好
  4. 高亮度：能量在空间和频率上高度集中
  5. 偏振性：通常是线偏振

  调Q技术（Q-switching）：

  通过调制谐振腔的Q值，实现巨脉冲输出。

  方法：
    - 电光调Q（Pockels盒）
    - 声光调Q
    - 饱和吸收体调Q（被动调Q）
    - 机械转镜调Q

  结果：
    - 脉冲宽度：纳秒量级（1-100 ns）
    - 峰值功率：兆瓦-吉瓦量级

  锁模技术（Mode-locking）：

  使所有纵模之间保持固定相位关系，产生超短脉冲。

  方法：
    - 主动锁模（电光调制器、声光调制器）
    - 被动锁模（饱和吸收体、克尔透镜锁模）
    - 混合锁模

  结果：
    - 脉冲宽度：飞秒-阿秒量级（10^-15 - 10^-18 s）
    - 峰值功率：太瓦-拍瓦量级
    - 重复频率：MHz-GHz量级

  超快激光与阿秒科学：

  飞秒激光（10^-15 s）：
    - 钛宝石激光器：~5 fs（~2个光学周期）
    - 应用：飞秒化学、飞秒医学、精密测量

  阿秒激光（10^-18 s）：
    - 高次谐波产生（HHG）：强激光与气体相互作用
    - 最短脉冲：~43阿秒（2017年）
    - 应用：电子动力学、原子分子物理
    - 2023年诺贝尔物理学奖（Agostini, Krausz, L'Huillier）

  螺旋几何化解释：

  1. 激光的螺旋几何化
     - 受激辐射 = 入射螺旋光子激发原子螺旋跃迁，发出同相螺旋光子
     - 粒子数反转 = 螺旋原子在高能级的聚集
     - 光学谐振腔 = 螺旋光的驻波模式选择
     - 激光 = 相干螺旋电磁波的受激放大

  2. 激光模式的螺旋几何化
     - 横模 = 螺旋光在腔内的空间模式
     - 纵模 = 螺旋光在腔内的频率模式
     - 高斯光束 = 螺旋光的基横模
     - 锁模 = 所有纵模螺旋相位锁定，产生超短脉冲

  3. 超快激光的螺旋几何化
     - 飞秒脉冲 = 螺旋光的超短时间包络
     - 阿秒脉冲 = 螺旋光的单个或半个光学周期
     - 高次谐波 = 强螺旋光与原子的非线性相互作用
     - 超快动力学 = 螺旋电子在阿秒时间尺度的运动

【OP7】光子学与集成光学
----------------------------------------------------------------------

  光子学概述：

  光子学是研究光子的产生、传输、控制、检测和应用的学科。
  类似于电子学研究电子，光子学研究光子。

  光子学的优势：
    1. 高速：光速传输，带宽大（THz量级）
    2. 低损耗：光纤损耗~0.2 dB/km
    3. 抗干扰：不受电磁干扰
    4. 并行性：可利用波长、偏振、空间等多维度复用
    5. 短波长：高分辨率成像、光刻

  光纤光学：

  光纤结构：
    - 纤芯：n1（光传输区域，直径~9-50 μm）
    - 包层：n2 < n1（直径~125 μm）
    - 涂覆层：保护（直径~250 μm）

  全反射条件：
    sin θ_c = n2/n1
    数值孔径：NA = √(n1² - n2²) ≈ n1 √(2Δ)
    其中 Δ = (n1 - n2)/n1 是相对折射率差

  光纤数值孔径计算：
    纤芯折射率 n1 = 1.45
    包层折射率 n2 = 1.44
    数值孔径 NA = √(n1²-n2²) = 0.1700
    最大接收角 θ_max = arcsin(NA) = 9.79°

  光纤类型：

  类型                   纤芯直径            特性                             应用
  ------------------------------------------------------------------------------------------
  单模光纤(SMF)            8-10 μm         只传基模, 色散小, 带宽大                 长距离通信, 高速数据传输
  多模光纤(MMF)            50/62.5 μm      传多个模式, 模间色散大                   短距离通信, 局域网, 数据中心
  保偏光纤(PMF)            ~9 μm           保持偏振态, 双折射结构                   光纤陀螺, 相干通信, 光纤传感
  光子晶体光纤(PCF)          ~1-100 μm       微结构包层, 奇特光学特性                  超连续谱, 高功率传输, 传感
  掺铒光纤(EDF)            ~4-9 μm         掺铒离子, 光放大                      EDFA光放大器, 光纤激光器
  双包层光纤                ~4-100 μm       双包层结构, 高功率泵浦                   高功率光纤激光器

  光纤通信：

  光纤通信窗口：
    - 850 nm：第一代，短距离多模
    - 1310 nm：零色散窗口
    - 1550 nm：最低损耗窗口（0.2 dB/km）
    - C波段（1530-1565 nm）：EDFA放大窗口
    - L波段（1565-1625 nm）：扩展波段

  波分复用（WDM）：
    - 利用不同波长传输不同信道
    - 密集波分复用（DWDM）：信道间隔50/100 GHz
    - 单根光纤可传输~100个信道，总容量~10 Tbps

  光放大器：
    - EDFA（掺铒光纤放大器）：1550 nm波段，增益~30 dB
    - 拉曼放大器：利用受激拉曼散射，宽带放大
    - 半导体光放大器（SOA）：集成化，小体积

  集成光学与光子集成电路（PIC）：

  将多个光学器件集成在单一芯片上，类似于电子集成电路。

  材料平台：
    - 硅光子学（Silicon Photonics）：与CMOS兼容，高折射率差
    - 磷化铟（InP）：有源器件（激光器、放大器、探测器）
    - 氮化硅（Si3N4）：低损耗，宽带
    - 铌酸锂（LiNbO3）：高速电光调制
    - 聚合物：低成本，柔性

  基本器件：
    - 波导：光传输通道
    - 分束器/合束器：光功率分配/合并
    - 耦合器：光耦合
    - 调制器：电光/热光调制
    - 滤波器：波长选择
    - 光开关：光路切换
    - 激光器：光源
    - 探测器：光检测

  应用：
    - 光通信（收发器、路由器）
    - 光计算（光子神经网络、量子计算）
    - 光传感（生物传感、化学传感、物理量传感）
    - 激光雷达（LiDAR）
    - 医疗诊断（光学相干断层、流式细胞仪）

  光子晶体：

  折射率周期性调制的人工微结构，周期~光波长量级。

  光子带隙（Photonic Band Gap, PBG）：
    类似于半导体中的电子带隙，某些频率的光无法传播

  维度：
    - 一维光子晶体：布拉格反射镜、DBR
    - 二维光子晶体：光子晶体光纤、光子晶体波导
    - 三维光子晶体：完全光子带隙

  应用：
    - 光子晶体光纤（PCF）：超连续谱、高功率传输
    - 光子晶体激光器：低阈值、单模
    - 光子晶体波导：慢光、光缓冲
    - 超材料、超表面

  螺旋几何化解释：

  1. 光子学的螺旋几何化
     - 光子 = 螺旋电磁波的量子
     - 光纤 = 螺旋光的波导传输
     - 全反射 = 螺旋光在光纤界面的全反射
     - 光子晶体 = 螺旋光的周期性调制结构
     - 光子带隙 = 螺旋光的禁止传播频率范围

  2. 光纤通信的螺旋几何化
     - WDM = 不同波长螺旋光的并行传输
     - EDFA = 螺旋光的受激辐射放大
     - 色散 = 螺旋光在光纤中的速度色散
     - 非线性 = 强光下螺旋光与光纤的非线性相互作用

  3. 集成光学的螺旋几何化
     - 波导 = 螺旋光的受限传输通道
     - 调制器 = 螺旋光的相位/振幅调制
     - 滤波器 = 螺旋光的频率选择
     - PIC = 螺旋光器件的集成芯片

【OP8】光学的螺旋几何化统一解释
----------------------------------------------------------------------

  核心命题：光学的所有现象都可以用螺旋电磁波的几何来统一解释

  1. 光的本质的螺旋几何化：

    基本假设：
      - 光是螺旋电磁波，电场和磁场在垂直于传播方向的平面内螺旋振荡
      - 光子是螺旋电磁波的量子，能量E=ħω，动量p=ħk
      - 偏振是螺旋电场矢量的振荡取向
      - 圆偏振光携带自旋角动量（±ħ per photon）

    推论：
      a) 光速不变 = 螺旋电磁波在真空中的传播速度恒为c
      b) 横波性 = 螺旋电场和磁场都垂直于传播方向
      c) 偏振 = 螺旋电场矢量的振荡取向
      d) 光子自旋 = 圆偏振螺旋光的内禀角动量
      e) 波粒二象性 = 螺旋电磁波的波动性和粒子性的统一

  2. 几何光学的螺旋几何化：

    基本假设：
      - 光线是螺旋光的能量传播方向（坡印廷矢量方向）
      - 在短波长极限（λ→0）下，螺旋光沿光线传播
      - 费马原理是螺旋光选择光程极值路径的原理

    推论：
      a) 直线传播 = 均匀介质中螺旋光沿直线传播
      b) 反射定律 = 螺旋光在界面的反射（入射角=反射角）
      c) 折射定律 = 螺旋光在不同介质中传播速度变化导致的偏折（n1sinθ1=n2sinθ2）
      d) 全反射 = 螺旋光从光密到光疏介质时，入射角大于临界角时完全反射
      e) 透镜成像 = 透镜通过折射率分布改变螺旋光的波前，实现成像

  3. 波动光学的螺旋几何化：

    基本假设：
      - 干涉是两束或多束螺旋光的相干叠加
      - 衍射是螺旋光绕过障碍物传播的现象
      - 散射是螺旋光与粒子相互作用后改变传播方向的现象

    推论：
      a) 双缝干涉 = 两束螺旋光的相位差导致的强度调制（杨氏实验）
      b) 薄膜干涉 = 螺旋光在薄膜上下表面反射后的干涉（增透膜、牛顿环）
      c) 单缝衍射 = 螺旋光通过单缝后的衍射图样
      d) 圆孔衍射 = 螺旋光通过圆孔后的艾里斑图样
      e) 瑞利判据 = 两个螺旋光源刚好可分辨的极限（θ_min=1.22λ/D）
      f) 光栅衍射 = 周期性结构对螺旋光的调制（光栅方程d sinθ=mλ）
      g) 瑞利散射 = 小粒子对螺旋光的散射（I∝1/λ^4，天空蓝色）

  4. 量子光学的螺旋几何化：

    基本假设：
      - 光子是螺旋电磁波的量子，具有粒子性
      - 光电效应是螺旋光子被电子吸收，电子获得能量逸出
      - 康普顿散射是螺旋光子与电子的弹性碰撞
      - 量子纠缠是螺旋光子之间的量子关联

    推论：
      a) 光电效应 = 螺旋光子能量被电子吸收（hν=W+K_max）
      b) 康普顿散射 = 螺旋光子与电子碰撞后波长变长（Δλ=λ_C(1-cosθ)）
      c) 相干态 = 螺旋光的最经典量子态（泊松光子数分布）
      d) 压缩态 = 螺旋正交分量的噪声压缩（ΔX1<1/√2）
      e) 量子纠缠 = 两个螺旋光子的量子态不可分解（违反Bell不等式）
      f) 腔QED = 螺旋光子与螺旋原子在光学腔中的强耦合

  5. 非线性光学的螺旋几何化：

    基本假设：
      - 非线性效应是强光下螺旋电场与物质的非线性相互作用
      - 二阶非线性是两个螺旋光子的合并/分裂
      - 三阶非线性是三个螺旋光子的相互作用

    推论：
      a) 二次谐波产生 = 两个低频螺旋光子合并为一个高频螺旋光子（ω+ω→2ω）
      b) 和频/差频产生 = 两个螺旋光子合并/分裂为不同频率的螺旋光子
      c) 光参量放大 = 一个泵浦螺旋光子分裂为信号和闲置螺旋光子
      d) 光克尔效应 = 强光下螺旋电场改变介质折射率（n=n0+n2I）
      e) 自聚焦 = 螺旋光束自身的透镜效应（高斯光束中心光强大）
      f) 自相位调制 = 螺旋脉冲自身强度变化导致的相位调制
      g) 超连续谱 = 螺旋脉冲在非线性介质中的多种非线性效应共同作用导致的频谱展宽

  6. 激光物理的螺旋几何化：

    基本假设：
      - 受激辐射是入射螺旋光子激发原子螺旋跃迁，发出同相螺旋光子
      - 粒子数反转是螺旋原子在高能级的聚集
      - 光学谐振腔是螺旋光的驻波模式选择

    推论：
      a) 激光 = 相干螺旋电磁波的受激放大（Light Amplification by Stimulated Emission of Radiation）
      b) 单色性 = 螺旋光的频率选择（谐振腔选频）
      c) 方向性 = 螺旋光的发散角极小（接近衍射极限）
      d) 相干性 = 螺旋光的相位相干（受激辐射同相）
      e) 调Q = 调制谐振腔Q值实现巨脉冲（纳秒脉冲）
      f) 锁模 = 所有纵模螺旋相位锁定，产生超短脉冲（飞秒/阿秒脉冲）
      g) 超快激光 = 螺旋光的超短时间包络（飞秒/阿秒量级）

  7. 光子学的螺旋几何化：

    基本假设：
      - 光子学是研究螺旋光子的产生、传输、控制、检测和应用的学科
      - 光纤是螺旋光的波导传输（全反射）
      - 光子晶体是螺旋光的周期性调制结构
      - 集成光学是螺旋光器件的集成芯片

    推论：
      a) 光纤 = 螺旋光在纤芯中通过全反射传输
      b) 数值孔径 = 螺旋光进入光纤的最大接收角（NA=√(n1²-n2²)）
      c) 单模/多模 = 螺旋光在光纤中传播的模式数
      d) WDM = 不同波长螺旋光的并行传输（波分复用）
      e) EDFA = 螺旋光的受激辐射放大（掺铒光纤放大器）
      f) 光子晶体 = 螺旋光的周期性折射率调制
      g) 光子带隙 = 螺旋光的禁止传播频率范围（类似于电子带隙）
      h) PIC = 螺旋光器件的集成芯片（光子集成电路）

  螺旋几何化的预言与可证伪性：

  预言1：光的所有现象都可以用螺旋电磁波的几何来统一描述
    - 这是光学的基本假设（麦克斯韦方程组）的螺旋版本
    - 证伪：如果发现无法用麦克斯韦方程组描述的光学现象，则螺旋模型失败

  预言2：光子的内部螺旋结构
    - 光子可能具有内部螺旋结构（类似于电子的光速螺旋）
    - 但光子静止质量为零，螺旋半径可能为零或无穷大
    - 这是一个开放问题，需要进一步研究

  预言3：螺旋模型对量子光学的修正
