# ROOT V70 · 多星体 × 组成 × 空间运动 × 微观引力环境联合研究包

**可运行 / 可审计 / 无伪造的统一场论成功宣告**

## 核心结果

- 将星体平均密度、参考半径、GM、地球 J₂、旋转、纬度、高度、潮汐梯度、微观钟差分开计算。
- 球对称外部引力无法独立识别天体内部密度分层；不同内部密度模型可产生完全一致的外场。
- 在明确定义的三特征合成模型中，“固定环境仅更换材料”的设计矩阵秩为 1；多星体 × 纬度 × 高度 × 材料设计满秩 3。
- 引入假设性 Yukawa 点源组成依赖测试，但所有 Q 值是任意数学代理值，**不是**真实元素或天体物理属性。
- 给出更稳定的 1 mm 引力红移公式，避免浮点数相减损失有效位。
- 第五力、独立预测 G、量子引力和四力大统一均未得到证实。

## 运行

Python 3.10+、numpy、matplotlib：

```bash
pip install -r requirements.txt
python run_all.py
```

查看 `results/verification.json` 和 `results/tests_verbose.txt`；详细报告见 `book/ROOT_V70_星体_元素_空间运动_引力起源_联合研究总集.md`。网页 `web/index.html` 可直接离线打开，Canvas2D 透视球体是交互示意，不是完整 WebGL 数字孪生。

## 文件

- `rootv70/physics.py`：牛顿、J₂、旋转、潮汐、弱场钟差、密度分层、螺旋几何、玩具 Yukawa。
- `rootv70/inference.py`：实验设计矩阵、奇异值、结构可辨识性和合成拟合。
- `tests/`：单元测试，比较解析推导、差分、极限及假设模型。
- `data/`：近似 NASA/IERS 参考参数导出的场景数据和**明显标记的合成数据**。
- `plots/`：真实计算的六张 PNG 曲线，非外部观测图。
- `results/`：数值摘要、测试输出、浏览器检验（如可运行）。
- `web/index.html`：独立离线互动展示。
- `archive/ROOT_V69_历史版.zip`：上一版完整研究包（来自已有本地文件）。
- `SOURCES.md`：公开来源及模型边界。
- `RELEASE_CHECK.json` 和 `SHA256SUMS.txt`：打包完整性文件。

## 重要限制

**地球物理和微观引力的环境校正≠发现新的基本力。** 计算平台自洽≠自然科学证实。不要将本包玩具组成耦合用于现实实验的置信区间声明。真实多星体对照还需星历、非球形引力、内部模型、源材料组成及实际原始测量数据。
