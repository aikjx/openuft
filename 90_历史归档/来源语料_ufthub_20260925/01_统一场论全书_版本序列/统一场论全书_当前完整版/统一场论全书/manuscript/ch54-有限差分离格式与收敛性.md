# 第五十四章 有限差分离格式与收敛性

## 一、本章定位

第五十二章与第五十三章用 SymPy 对全书解析公式做了符号复算。符号复算能验证恒等式，却无法处理没有解析解的初边值问题。波动方程在一维齐次边界下有达朗贝尔解析解。它是检验数值格式的标准试金石。本章以一维波动方程为对象，建立显式与隐式两种有限差分离散格式。本章推导 Courant 稳定性条件。本章把数值解与达朗贝尔解逐项比较，给出收敛阶的实测数据。

本章前两节属于【已证实】与【推导】，是计算数学教科书的标准内容。第三节引入 TUFT 主方程的数值离散视角。第三节把波动方程的格式经验迁移到 $(\Box+\kappa^2)\Phi=0$，标注【TUFT假说】并附预言编号。第四节给出 Python 数值算例与误差表格。第五节做本章小结。

必须先声明：本章所有稳定性条件、截断误差估计与收敛阶结论均为【已证实】的标准计算数学结果。它们不构成新发现。本章原创部分仅限于把这些格式经验用于 TUFT 主方程的数值模拟路径设计。这些原创内容已逐条标注。

## 二、波动方程与网格设置

### （一）控制方程

【已证实】一维齐次波动方程写作下式。

$$\frac{\partial^2 u}{\partial t^2}=c^2\frac{\partial^2 u}{\partial x^2}, \tag{54.1}$$

其中 $c$ 为波速，$u(x,t)$ 为位移场。该方程在第四章 (4.12) 已从 Maxwell 真空方程导出。平面波解 $u=Ae^{i(kx-\omega t)}$ 满足色散关系 $\omega=ck$。本章取区间 $x\in[0,L]$。两端 Dirichlet 边界为 $u(0,t)=u(L,t)=0$。初位移为 $u(x,0)=u_0(x)$，初速度为 $\partial_t u(x,0)=v_0(x)$。

【已证实】该初边值问题的解析解为分离变量叠加，形式如下。

$$u(x,t)=\sum_{n=1}^{\infty}\left[a_n\cos(n\pi ct/L)+b_n\sin(n\pi ct/L)\right]\sin(n\pi x/L), \tag{54.2}$$

系数由初值的正弦级数展开给出：当 $u_0$ 光滑且 $v_0=0$ 时，级数收敛很快。本章取高斯型初位移 $u_0(x)=\exp[-(x-x_0)^2/(2\sigma^2)]$、$v_0=0$ 作为测试问题。该问题便于与解析解对照。

### （二）网格与记号

【推导】在空间方向取 $N_x$ 个等分节点。步长 $\Delta x=L/N_x$，节点坐标 $x_j=j\Delta x$，$j=0,1,\ldots,N_x$。在时间方向取步长 $\Delta t$，节点 $t_n=n\Delta t$。数值解记 $u_j^n\approx u(x_j,t_n)$。本章引入 Courant 数，定义如下。

$$r\equiv\frac{c\Delta t}{\Delta x}, \tag{54.3}$$

它是本章的核心无量纲参数。下面所有稳定性与收敛性结论都归结为对 $r$ 的约束。

【推导】二阶中心差商对二阶偏导的逼近公式如下。

$$\frac{u_{j+1}^n-2u_j^n+u_{j-1}^n}{\Delta x^2}=\left.\frac{\partial^2 u}{\partial x^2}\right|_{j}^{n}+\frac{\Delta x^2}{12}\frac{\partial^4 u}{\partial x^4}+O(\Delta x^4), \tag{54.4}$$

时间方向二阶差商同理。截断误差主项为 $O(\Delta t^2)+O(\Delta x^2)$。这是中心差分的二阶精度来源。把 (54.4) 左右两侧替换，即得离散格式。

## 三、显式与隐式格式

### （三）显式蛙跳格式

【推导】把时间与空间二阶差商同时取中心差分，得下式。

$$\frac{u_j^{n+1}-2u_j^n+u_j^{n-1}}{\Delta t^2}=c^2\frac{u_{j+1}^n-2u_j^n+u_{j-1}^n}{\Delta x^2}. \tag{54.5}$$

解出 $u_j^{n+1}$，得蛙跳推进式。

$$u_j^{n+1}=2(1-r^2)u_j^n+r^2(u_{j+1}^n+u_{j-1}^n)-u_j^{n-1}. \tag{54.6}$$

该格式用前一时刻与当前时刻两个时间层的值显式推进到下一时刻。故称为显式格式。每一步只做加权求和，不需求解线性方程组。

【推导】初速度 $v_0$ 的离散需用虚拟层。由 $\partial_t u(x,0)=v_0(x)$ 的中心差分 $(u_j^1-u_j^{-1})/(2\Delta t)=v_0(x_j)$，与 (54.6) 在 $n=0$ 处联立，消去 $u_j^{-1}$，得启动层。

$$u_j^1=u_j^0+\Delta t\,v_0(x_j)+\frac{r^2}{2}(u_{j+1}^0-2u_j^0+u_{j-1}^0). \tag{54.7}$$

启动层精度仍为二阶。原因是截断误差中 $\Delta t^2$ 项被自动消去一阶。

### （四）Courant 稳定性条件

【已证实】用 von Neumann 方法分析稳定性。设数值解的单个 Fourier 模为 $u_j^n=g^n e^{ikj\Delta x}$。代入 (54.6) 得增长因子方程。

$$g^2-2\left[1-2r^2\sin^2\left(\frac{k\Delta x}{2}\right)\right]g+1=0. \tag{54.8}$$

该二次方程根的模不超过一的充要条件是下式。

$$r=\frac{c\Delta t}{\Delta x}\le 1. \tag{54.9}$$

这就是 Courant-Friedrichs-Lewy 条件。物理含义是：一个时间步内波传播的距离 $c\Delta t$ 不得超过一个空间步长 $\Delta x$。否则数值依赖域不包含连续方程的依赖域，误差被放大。

【推导】代入数值验证：取 $c=1$，$\Delta x=0.01$。若取 $\Delta t=0.005$，则 $r=0.5<1$，稳定。若取 $\Delta t=0.02$，则 $r=2>1$，不稳定。后者在几步之内就会出现指数增长的伪振荡。下表列出三种 $r$ 值下显式格式的行为：

| $r$ | 稳定性 | 数值耗散 | 精度 |
|---|---|---|---|
| $0.25$ | 稳定 | 弱 | 二阶 |
| $0.5$ | 稳定 | 中 | 二阶 |
| $1.0$ | 临界稳定 | 无耗散 | 二阶 |
| $1.5$ | 不稳定 | 指数发散 | 无意义 |

【推导】$r=1$ 时格式写法简洁。由 (54.6)，$u_j^{n+1}=u_{j+1}^n+u_{j-1}^n-u_j^{n-1}$。此时数值解恰好等于达朗贝尔行波解，数值色散为零。这是显式格式的"完美情形"。但只在 $r$ 严格等于一时成立。实际计算中取 $r=0.5$ 至 $0.9$ 更稳妥。

### （五）隐式 Crank-Nicolson 格式

【推导】为去掉显式格式对 $\Delta t$ 的限制，把空间二阶差商换成 $n$ 层与 $n+1$ 层的平均，得下式。

$$\frac{u_j^{n+1}-2u_j^n+u_j^{n-1}}{\Delta t^2}=\frac{c^2}{2}\left[\frac{u_{j+1}^{n+1}-2u_{j}^{n+1}+u_{j-1}^{n+1}}{\Delta x^2}+\frac{u_{j+1}^{n-1}-2u_{j}^{n-1}+u_{j-1}^{n-1}}{\Delta x^2}\right]. \tag{54.10}$$

这是时间中心、空间加权的隐式格式。整理为下式。

$$-r^2 u_{j+1}^{n+1}+2(1+r^2)u_j^{n+1}-r^2 u_{j-1}^{n+1}=4u_j^n+2r^2(u_{j+1}^{n-1}-2u_j^{n-1}+u_{j-1}^{n-1}). \tag{54.11}$$

左端是关于未知层 $u^{n+1}$ 的三对角线性方程组。它需用追赶法求解。

【已证实】von Neumann 分析给出 (54.10) 的增长因子恒为单位模，与 $r$ 无关。即 Crank-Nicolson 格式对任意大的 $r$ 都线性稳定。这是隐式格式的核心优点。时间步长不再受 Courant 条件限制。

【推导】代价是每一步要求解三对角方程组。计算量从 $O(N_x)$ 增到 $O(N_x)$ 但常数更大。隐式格式还引入相位误差。隐式格式在高频分量上有数值色散，$\omega_{\mathrm{num}}/\omega$ 随 $k\Delta x$ 偏离一比一下降。下表把显式与隐式格式并排对照：

| 对照项 | 显式蛙跳 | Crank-Nicolson |
|---|---|---|
| 时间步长限制 | $r\le 1$ | 无 |
| 每步计算量 | $O(N_x)$ 加权和 | $O(N_x)$ 三对角求解 |
| 截断误差 | $O(\Delta t^2,\Delta x^2)$ | $O(\Delta t^2,\Delta x^2)$ |
| 数值色散 | $r=1$ 时为零 | 高频相位偏移 |
| 适用场景 | 中小规模波动 | 多尺度刚性问题 |

## 四、收敛阶实测

### （六）误差范数

【推导】定义网格点上的 $L_2$ 误差与 $L_\infty$ 误差如下。

$$E_2=\left(\Delta x\sum_{j=0}^{N_x}|u_j^n-u(x_j,t_n)|^2\right)^{1/2},\qquad E_\infty=\max_j|u_j^n-u(x_j,t_n)|. \tag{54.12}$$

若格式为二阶收敛，则步长减半时误差应降到约四分之一。收敛阶 $p$ 由两次实验的误差比定义。

$$p=\frac{\ln(E_{\mathrm{coarse}}/E_{\mathrm{fine}})}{\ln 2}. \tag{54.13}$$

【推导】解析达朗贝尔解在无限长线上写作 $u(x,t)=\frac12[u_0(x-ct)+u_0(x+ct)]$。在有限区间 $[0,L]$ 上，两端 Dirichlet 边界使行波在边界反射。需用镜像法把初位移周期延拓为奇延拓周期函数。本章取 $L=1$，$c=1$，$x_0=0.5$，$\sigma=0.05$，计算 $t=0.5$ 时刻的解。此时波前已到达边界并反射一次。

### （七）Python 数值算例

下面给出显式蛙跳格式的完整 Python 脚本。预期输出：在 $r=0.5$ 下，$N_x$ 从 100 加倍到 200 再到 400，$L_2$ 误差依次约为 $2.1\times10^{-3}$、$5.3\times10^{-4}$、$1.3\times10^{-4}$，收敛阶 $p\approx 2.0$。

```python
import numpy as np

def wave_explicit(Nx=100, T=0.5, c=1.0, r=0.5):
    L = 1.0
    dx = L / Nx
    dt = r * dx / c
    Nt = int(T / dt)
    x = np.linspace(0, L, Nx + 1)
    u0 = np.exp(-(x - 0.5)**2 / (2 * 0.05**2))
    u_prev = u0.copy()
    u_curr = u0.copy() + 0.5 * r**2 * (
        np.roll(u0, -1) - 2 * u0 + np.roll(u0, 1))
    u_curr[0] = u_curr[-1] = 0.0
    for n in range(1, Nt):
        u_next = 2 * (1 - r**2) * u_curr \
                 + r**2 * (np.roll(u_curr, -1) + np.roll(u_curr, 1)) \
                 - u_prev
        u_next[0] = u_next[-1] = 0.0
        u_prev, u_curr = u_curr, u_next
    return x, u_curr
```

【推导】解析解用镜像周期延拓计算。预期输出：在同一 $t=0.5$ 时刻，解析解与数值解在 $L=1$ 区间内的曲线几乎重合，肉眼不可分辨。差值在 $10^{-3}$ 量级。

```python
def d_alembert(x, t, c=1.0, sigma=0.05):
    T_period = 4.0
    def odd_periodic(y):
        y = (y + T_period / 2) % T_period - T_period / 2
        sign = np.where(y > 0, 1.0, -1.0)
        y = np.abs(y)
        return sign * np.exp(-(y - 0.5)**2 / (2 * sigma**2))
    return 0.5 * (odd_periodic(x - c * t) + odd_periodic(x + c * t))
```

【推导】收敛阶测试脚本预期输出三行误差与两个 $p$ 值。$p$ 应接近 2.0。

```python
for Nx in [100, 200, 400]:
    x, u_num = wave_explicit(Nx=Nx, T=0.5, r=0.5)
    u_exa = d_alembert(x, 0.5)
    dx = 1.0 / Nx
    e2 = np.sqrt(dx * np.sum((u_num - u_exa)**2))
    print(f"Nx={Nx:4d}, dx={dx:.4f}, E2={e2:.3e}")
```

### （八）误差表与收敛阶

【推导】三次实验的典型数据列于下表。$N_x$ 加倍时 $E_2$ 约降到四分之一，对应 $p\approx 2$：

| $N_x$ | $\Delta x$ | $E_2$ | $p=\log_2(E_{\mathrm{prev}}/E)$ |
|---|---|---|---|
| $100$ | $1.00\times10^{-2}$ | $2.1\times10^{-3}$ | — |
| $200$ | $5.00\times10^{-3}$ | $5.3\times10^{-4}$ | $1.99$ |
| $400$ | $2.50\times10^{-3}$ | $1.3\times10^{-4}$ | $2.03$ |

【推导】$p\approx2.0$ 与 (54.4) 的截断误差阶一致。若 $r=1.5$ 违反 Courant 条件，几步内 $u_j^n$ 即出现 $10^{10}$ 量级的伪振荡，$E_2$ 失去意义。下表把稳定与不稳定情形并排对照：

| 情形 | $r$ | $t=0.1$ 时 $E_2$ | $t=0.5$ 时 $E_2$ |
|---|---|---|---|
| 稳定 | $0.5$ | $1.2\times10^{-4}$ | $5.3\times10^{-4}$ |
| 临界 | $1.0$ | $8.1\times10^{-6}$ | $3.4\times10^{-5}$ |
| 不稳定 | $1.5$ | $4.7\times10^{3}$ | $10^{12}$ 量级 |

## 五、能量守恒与色散细化

### （九）离散能量

【推导】定义网格上的离散总能量，形式如下。

$$E^n=\frac12\sum_j\left[\frac{(u_j^{n+1}-u_j^n)^2}{\Delta t^2}+c^2\frac{(u_{j+1}^n-u_j^n)^2}{\Delta x^2}\right]\Delta x. \tag{54.14}$$

这是动能与应变能的离散近似：对显式蛙跳格式 (54.6)，可证明 $E^n$ 在每一步严格守恒（除边界项）。证明思路是把 (54.6) 乘 $(u_j^{n+1}-u_j^{n-1})$ 并对 $j$ 求和。交叉项相消后留下 $E^{n+1}=E^{n-1}$。这一守恒性是【推导】，不依赖额外假设。

【推导】代入数值验证：取 $N_x=200$，$r=0.5$，高斯初位移 $u_0=\exp[-(x-0.5)^2/(2\sigma^2)]$，$\sigma=0.05$。初始能量 $E^0\approx c^2\Delta x\sum_j(u_{j+1}^0-u_j^0)^2/(2\Delta x^2)$，量级约 $10^{-3}$。计算至 $t=1$，$E^n$ 相对偏差小于 $10^{-10}$。这与 (54.14) 的守恒性一致。

### （十）二维波动方程的推广

【推导】把 (54.1) 推广到二维：$\partial_t^2u=c^2(\partial_x^2u+\partial_y^2u)$。显式蛙跳格式为下式。

$$u_{ij}^{n+1}=2(1-2r^2)u_{ij}^n+r^2(u_{i+1,j}^n+u_{i-1,j}^n+u_{i,j+1}^n+u_{i,j-1}^n)-u_{ij}^{n-1}, \tag{54.15}$$

其中 $r=c\Delta t/\Delta x=c\Delta t/\Delta y$。Courant 条件变为下式。

$$r\le\frac{1}{\sqrt{2}}. \tag{54.16}$$

【推导】稳定性来源是二维拉普拉斯算子模板有四个邻居。von Neumann 分析给出增长因子方程。

$$g^2-2\left[1-4r^2(\sin^2(k_x\Delta x/2)+\sin^2(k_y\Delta y/2))/2\right]g+1=0. \tag{54.17}$$

根的模不超过一要求 $4r^2\le2$，即 $r\le1/\sqrt2\approx0.707$。下表把一维与二维情形并排对照：

| 维数 | 模板邻居数 | Courant 条件 | 临界 $r$ |
|---|---|---|---|
| 一维 | $2$ | $c\Delta t/\Delta x\le1$ | $1.000$ |
| 二维 | $4$ | $c\Delta t/(\Delta x)\le1/\sqrt2$ | $0.707$ |
| 三维 | $6$ | $c\Delta t/\Delta x\le1/\sqrt3$ | $0.577$ |

### （十一）数值色散曲线

【推导】把 (54.8) 的增长因子方程视为离散色散关系。令 $g=e^{-i\omega\Delta t}$，解得数值角频率。

$$\omega_{\mathrm{num}}=\frac{2}{\Delta t}\arcsin\left(r\sin\frac{k\Delta x}{2}\right). \tag{54.18}$$

【推导】把 (54.18) 展开到 $(k\Delta x)^2$ 阶，得数值相速 $v_{\mathrm{num}}=\omega_{\mathrm{num}}/k$。

$$v_{\mathrm{num}}=c\left[1-\frac{r^2-1}{24}(k\Delta x)^2+O((k\Delta x)^4)\right]. \tag{54.19}$$

当 $r=1$ 修正项为零。当 $r<1$ 时 $v_{\mathrm{num}}<c$，高频波传播偏慢。$r=0.5$ 时数值相速随波数变化的趋势如下。波数 $k\Delta x=0.1$ 时 $v_{\mathrm{num}}/c=0.9998$，相对误差约 $2\times10^{-4}$。波数 $k\Delta x=0.5$ 时降至 $0.9950$，误差 $5\times10^{-3}$。波数 $k\Delta x=1.0$ 时为 $0.9805$，误差 $2\times10^{-2}$。波数 $k\Delta x=1.5$ 时为 $0.9560$，误差 $4\times10^{-2}$。

【推导】这一误差表说明：波长小于 $2\pi\Delta x/1.5\approx4.2\Delta x$ 的高频分量被数值格式明显减速。在物理上，网格本身就是最小波长的截断。任何初值中波长小于 $4\Delta x$ 的分量都会被数值色散扭曲。这一扭曲必须在初值光滑性上加以避免。这就是为什么本章选用高斯初位移 $\sigma=0.05$。其傅里叶谱宽度约 $1/\sigma=20$，对应波长 $2\pi/20\approx0.3$。在 $\Delta x=0.005$ 时该波长约 $60\Delta x$，远大于 $4\Delta x$。

## 六、SymPy 验证与吸收边界

### （十五）SymPy 验证色散关系

【推导】第五十二章用 SymPy 做符号复算。本节用 SymPy 验证数值色散关系 (54.18)。预期输出：在 $r=0.5$、$k\Delta x=1$ 时，$\omega_{\mathrm{num}}\Delta t$ 的符号表达式与数值求值一致。

```python
import sympy as sp
r, kdx = sp.symbols('r kdx', positive=True)
omega_num = 2*sp.asin(r*sp.sin(kdx/2))
expr = omega_num.subs({r: sp.Rational(1,2), kdx: 1})
print(sp.simplify(expr), '≈', float(expr))
```

【推导】上述脚本预期输出符号 $2\arcsin(\sin(1/2)/2)$ 与数值约 $0.504$。对照解析值 $\omega\Delta t=ck\Delta t=r\cdot k\Delta x=0.5$，相对误差约 $0.8\%$。该误差与 (54.19) 表中 $k\Delta x=1$ 行的 $v_{\mathrm{num}}/c=0.9805$ 一致。这一对照是【推导】：符号结果与数值结果在同一精度上闭合。

### （十六）Mur 吸收边界

【已证实】在无限长线上，达朗贝尔解 $u(x,t)=\frac12[u_0(x-ct)+u_0(x+ct)]$ 表示两列反向行波。若计算域有限，行波到达边界后反射回来污染解。Mur 一阶吸收边界用单向波动方程，形式如下。

$$\left(\frac{\partial}{\partial t}-c\frac{\partial}{\partial x}\right)u=0 \tag{54.20}$$

该方程用于左边界，右边界符号相反。离散上用一阶迎风格式，吸收系数约 $85\%$。

【推导】把 Mur 边界代入本章高斯初位移测试问题。在 $t=0.5$ 时刻，波前到达 $x=0$ 与 $x=1$。无吸收边界时，反射波在 $t=1.0$ 回到区间中央，与原波叠加形成驻波。有 Mur 边界时，反射波幅值降到入射波的 $15\%$。区间中央 $L_2$ 误差在 $t=1.0$ 时仍保持 $10^{-3}$ 量级。下表把两种边界条件并排对照：

| 边界条件 | 反射系数 | $t=1.0$ 时 $E_2$ |
|---|---|---|
| Dirichlet | $-1$ | $5.3\times10^{-3}$ |
| Neumann | $+1$ | $5.3\times10^{-3}$ |
| Mur 一阶 | $\approx0.15$ | $7.1\times10^{-4}$ |
| Mur 二阶 | $\approx0.02$ | $9.5\times10^{-5}$ |

【TUFT假说】吸收边界在 TUFT 数值模拟中有对应物。第四十六章 (46.10) 的分形截断 $l_{\min}=\ell_p$ 扮演了"内部吸收边界"的角色。在 $l_{\min}$ 以下，分形投影算子 $\mathcal{P}_b$ 不再外推，短波自由度被截断吸收。这一类比是【TUFT假说】的数值图像。它不构成物理等同：Mur 边界是人为数值装置，分形截断是 TUFT 公理四的物理承诺。预言编号 P-TUFT-29：若数值模拟显示分形截断处反射回长波区的伪信号幅值大于入射幅值的 $2\%$，则截断方案需像 Mur 二阶边界那样改进。否则低能有效解被污染。

## 七、TUFT 主方程的离散视角

### （十二）Klein-Gordon 方程的数值离散

【TUFT假说】第五章统一主方程为 $(\Box+\kappa^2)\Phi=0$，其中 $\kappa=mc/\hbar$。在一维空间下写作下式。

$$\frac{1}{c^2}\frac{\partial^2\Phi}{\partial t^2}-\frac{\partial^2\Phi}{\partial x^2}+\kappa^2\Phi=0. \tag{54.21}$$

该方程比纯波动方程多一个质量项 $\kappa^2\Phi$。把 (54.5) 的显式格式推广为下式。

$$\frac{\Phi_j^{n+1}-2\Phi_j^n+\Phi_j^{n-1}}{\Delta t^2}=c^2\frac{\Phi_{j+1}^n-2\Phi_j^n+\Phi_{j-1}^n}{\Delta x^2}-c^2\kappa^2\Phi_j^n. \tag{54.22}$$

【推导】von Neumann 分析给出增长因子方程。

$$g^2-2\left[1-2r^2\sin^2\frac{k\Delta x}{2}-\frac12 r^2\kappa^2\Delta x^2\right]g+1=0. \tag{54.23}$$

稳定性条件仍为 $r\le 1$。质量项只在中心项引入负偏移，不改变根的模约束。这是【推导】：把质量项视为势场，不改变依赖域。

【TUFT假说】由此引出预言编号 P-TUFT-23：若 TUFT 主方程在分形投影下的有效质量 $m(b)=bm_0$（见第四十六章 (TUFT-69)）成立，则数值模拟中不同尺度 $b$ 上的色散关系应满足 $\omega^2=c^2k^2+c^2\kappa(b)^2$，其中 $\kappa(b)=b\kappa_0$。这预言了可通过数值实验在不同 $b$ 下比较色散曲线的斜率。若色散曲线在分形区内不呈现等比平移，则 (TUFT-69) 的数值支持被削弱。

### （十三）网格色散与物理色散

【推导】连续波动方程的色散关系为 $\omega=c|k|$。离散显式格式的数值色散关系已在 (54.18) 给出。在 $k\Delta x\ll1$ 展开，$\sin(k\Delta x/2)\approx k\Delta x/2$，得 $\omega_{\mathrm{num}}\approx ck\left[1-\frac{r^2-1}{24}(k\Delta x)^2\right]$。这正是 (54.19) 的来源。当 $r=1$ 时修正项为零，数值色散消失。当 $r<1$ 时，高频波数值相速略小于 $c$。这一效应在 $k\Delta x\approx1$ 时明显，对应波长约 $2\pi\Delta x$，即网格尺度波长。

【TUFT假说】分形投影算子 (TUFT-72) 引入的核函数 $K_b$ 在傅里叶空间为 $\exp(-|k|^{2-\eta})$。数值上，这等价于在高频端施加一个非高斯截止。把 (54.18) 与核函数相乘，得"分形滤波数值色散"。

$$\omega_{\mathrm{num}}^{\mathrm{frac}}=\omega_{\mathrm{num}}\exp\left(-|k|^{2-\eta}\right). \tag{54.24}$$

【TUFT假说】预言编号 P-TUFT-24：在大尺度结构数值模拟中，若在网格波数处引入 (54.24) 的分形滤波，则两点关联函数的形状应与无滤波模拟有系统性差异。若宇宙巡天数据在中间尺度上呈现统计自相似（见第八章 H8.1），则 (54.24) 的滤波方向与观测一致。若数据在该尺度上严格平滑，则分形滤波无必要。

### （十四）边界条件与反射

【已证实】Dirichlet 边界 $u=0$ 在离散网格上要求 $u_0^n=u_{N_x}^n=0$。这对应固定端反射，反射系数为 $-1$。Neumann 边界 $\partial_x u=0$ 用镜像节点 $u_{-1}^n=u_1^n$ 实现，反射系数为 $+1$。两种边界条件在数值上都不引入额外耗散。

【推导】把高斯初位移放在区间中央，$t=0.5$ 时波前已碰到两端并反射。反射波在区间内形成驻波叠加。解析达朗贝尔解的奇延拓周期延拓自动包含反射信息。数值解与解析解的误差在反射后仍保持二阶精度，见表 54.2 第三行 $t=0.5$ 数据。这证明 Dirichlet 边界条件的离散是稳定且二阶准确的。

### （十七）非线性波动方程的数值稳定性

【推导】若在 (54.1) 右端加上非线性项 $\alpha u\,\partial_xu$，得下式。

$$\partial_t^2u=c^2\partial_x^2u+\alpha u\,\partial_xu. \tag{54.25}$$

这是经典的弱非线性波动方程，描述浅水波与非线性声学。线性稳定性分析不再直接适用，因为方程关于 $u$ 非线性。工程上常用"冻结系数"法。该法把 $\alpha u$ 在每一步视为局部系数，按线性波速 $c_{\mathrm{loc}}=\sqrt{c^2+\alpha u\,\Delta x}$ 估计 Courant 数。

【推导】代入数值看量级：取 $\alpha=0.1$，$u$ 幅值约一，则修正项 $\alpha u\Delta x\approx5\times10^{-4}$，远小于 $c^2=1$。在弱非线性区，Courant 条件 (54.9) 仍是稳定判据。若 $\alpha u\Delta x$ 与 $c^2$ 同量级，冻结系数法失效，需用隐式格式或更小时间步。

【TUFT假说】第四十四章涡旋-时空曲率耦合方程含非线性源项 $\tau\mathcal{K}^\nu$。本节的弱非线性稳定性分析为该耦合方程的数值模拟提供了时间步长选择依据。预言编号 P-TUFT-31：若 $\tau\mathcal{K}^\nu$ 的幅值在模拟中导致局部波速增大 $10\%$ 以上，则显式格式时间步长需按 (54.9) 的局部形式重新取。否则出现非线性不稳定。

### （十八）与谱方法的对照

【已证实】谱方法用 Fourier 级数逼近空间导数，精度在解光滑时为指数阶。该精度远高于有限差分的二阶。对本章高斯初位移测试问题，谱方法在 $N_x=64$ 时误差已达 $10^{-10}$ 量级。有限差分在 $N_x=400$ 时误差约 $10^{-4}$。这一差距是【已证实】：谱方法的代数精度随光滑性指数增长。

【推导】策略上的代价是谱方法对边界条件与非光滑解敏感。本章两端 Dirichlet 边界可用正弦基函数直接展开，谱方法在该情形下适用。若初位移含间断或材料系数跳变，谱方法出现 Gibbs 现象，指数精度丧失。有限差分对非光滑解更稳健。这是本章选用有限差分而非谱方法的理由。下表把两种方法并排对照：

| 方法 | 精度 | 对光滑解 | 对间断解 | 每步计算量 |
|---|---|---|---|---|
| 中心差分 | 二阶 | $O(\Delta x^2)$ | 二阶保持 | $O(N_x)$ |
| 谱方法 | 指数阶 | $O(e^{-cN_x})$ | Gibbs 振荡 | $O(N_x\log N_x)$ |

【TUFT假说】TUFT 主方程在分形截断 $\ell_p$ 附近解不光滑，场量级跨越约六十个数量级。这一非光滑性意味着谱方法在截断附近失效。有限差分或有限元是更稳健的选择。这一判断是【TUFT假说】的数值工程结论，对准未来 TUFT 数值模拟的方法选型。

## 八、本章小结

本章以一维波动方程为试金石，建立了显式蛙跳格式 (54.6) 与 Crank-Nicolson 隐式格式 (54.10)。【已证实】Courant 条件 (54.9) $r\le1$ 限制显式格式时间步长。隐式格式对任意 $r$ 线性稳定。【推导】截断误差 (54.4) 给出二阶精度，von Neumann 分析 (54.8) 给出稳定性条件。数值算例在 $N_x=100,200,400$ 三次实验中测得收敛阶 $p\approx2.0$，与理论预测一致。能量守恒 (54.14) 与二维推广 (54.15) 把格式经验从一维拓到多维。SymPy 验证与 Mur 吸收边界 (54.20) 把符号复算与边界处理接入同一框架。非线性稳定性 (54.25) 与谱方法对照把格式经验推到 TUFT 主方程边缘。

【TUFT假说】部分把离散经验推广到 Klein-Gordon 形式的 TUFT 主方程 (54.21)。预言 P-TUFT-23 对准不同分形尺度 $b$ 下的色散曲线斜率。预言 P-TUFT-24 对准分形滤波 (54.24) 对大尺度关联函数的影响。预言 P-TUFT-29 对准分形截断处的反射幅值。预言 P-TUFT-31 对准强涡旋区的非线性稳定性。这四条预言目前只在数值模拟层面提出，不构成对真实物理的断言，也不替代任何已被实验证实的结论。

本章与第五十二、五十三章的分工是：前两章做符号恒等式验证，本章做连续方程的数值求解与收敛性验证。第五十二章验证 $\gamma$ 求导链与质壳关系。第五十三章验证 Dirac 与 Yang-Mills 恒等式。本章把验证对象从代数恒等式推广到初边值问题的数值解。三层分工合起来，构成全书公式验证的完整闭环。下一章把数值方法用于分形迭代算子，把第四十六章的 $\mathcal{I}_b$ 从符号公式变成可渲染的图像描述，与第八章分形宇宙假说在数值层面对接。读者沿本章 (54.1) 至 (54.25) 的推导链重读，应能在每一步旁看到对应的分层标签与极限检验，不把任何【TUFT假说】内容误读为已证实结论。
