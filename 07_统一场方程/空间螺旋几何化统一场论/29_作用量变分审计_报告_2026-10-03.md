## 1. 决定性反证：耦合项迹的精确闭式

来稿全文**从未给出** `T^int` 的定义式，其 §2"缩并得到右侧源项"是缺失的一步。本审计补上：

```
L_int = −c·F ,  c := α/(2ρ_c)
F    := (∇^μρ)(∇_μρ)/D ,  D := ρ + ρ_min + β□ρ
T^int_{ab} := −(2/√−g)·δ(√−g L_int)/δg^{ab} = c·g_{ab}·F + 2c·∂F/∂g^{ab}
```

### 1.1 一般时空（张量齐次性，精确）

对 `g^{ab} → λ g^{ab}` 缩放（ρ 固定）：协变联络不缩放，`∂_aρ` 分量不变 ⇒
`N := ∇^μρ∇_μρ → λN`，`□ρ → λ□ρ`，故 `D → ρ+ρ_min+βλ□ρ`，`F(λ) = λN/D(λ)`。Euler 定理给出

```
g^{ab} ∂F/∂g^{ab} = dF/dλ|_{λ=1} = N(ρ+ρ_min)/D² = F(ρ+ρ_min)/D
```

于是

```
g^{ab} T^int_{ab} = 2c[2F + F(ρ+ρ_min)/D]
                 = 2cF·[3(ρ+ρ_min) + 2β□ρ] / D                ……（★）
```

用 `3(ρ+ρ_min)+2β□ρ = 3D − β□ρ` 改写得更直观：

```
trace = 6cF − 2cF·β□ρ/D                                    ……（★′）
```

**B02 / B03b 条目**：两条独立路径（缩放论证 + 平直空间直接缩并）互洽。

### 1.2 平直空间特例（独立确认，B02/D02）

若 Γ ≡ 0（Cartesian），则 □ρ 与 g 无关 ⇒ `∂F/∂g^{ab} = ∂_aρ∂_bρ/D`，直接缩并得

```
trace = 4cF + 2cF = 6cF
```

与（★′）在 β□ρ → 0 时一致。数值验证：4 个泛点、60 位精度，最大偏差 `7.8e-62`；
把系数 2c 换成 c 或 3c 时偏差升到 `4.2e-2`，确认系数唯一。

### 1.3 与来稿口径的差（精确）

来稿隐含的缩并结果等价于假定 `g^{ab}∂F/∂g^{ab} = 0`，即 **trace = 2cF**。而实际是（★）。
两者之差精确为

```
2cF·[2(ρ+ρ_min) + β□ρ] / D        （B03b）
```

该差仅在 `β□ρ → 0` **且** `ρ+ρ_min → 0` 时趋于零，而后者要求 ρ → 0（耦合项整体消失）。
**即"β 协变阻尼"这一核心创新项，恰恰是使式(1) 不可被导出的那一项。**

## 3. Λ 归一化：来稿把同一个 Λ 用在两处（C05 / A03）

Einstein–Hilbert 作用量取迹（**A03 机器零**）：

```

```

故 `S_g` 取迹后左端是 `R − 4Λ_act`，而来稿目标左端写的是 `R − 2Λ`。
要一致必须 `Λ_act = Λ/2`。来稿在 `S_g` 的 `(R−2Λ)` 与式(1) 的 `R−2Λ` 两处用了同一个 Λ，
把取迹后的 `R−4Λ_act` 当作 `R−2Λ` 使用。

**附带的第三个不匹配（B04）**：来稿 §2 写 `8πG T^int = −2Λ + (α/ρ_c)F`，其中 `−2Λ` 项
在 `S_int` 中**无来源**——`L_int` 的自变量是 `(ρ, ∇ρ, □ρ)`，对 Λ 的泛函导恒为 0。
这一项只能事后手工塞入，是"先写方程、再补作用量"的直接证据。

## 5. Bianchi 恒等式：过定性（D01 / D03 / D04）

`T^int` 的协变散度在一般情形下**必含 ρ 的三阶导数**：

* **结构论证（D01-a）**：把候选闭式（仅含 `F`、`□ρ`、`∂_bD`、`∂_bF`）与精确散度相减，
  残差中 `Derivative(rho,(xi,3))` 出现 **6 处** ⇒ 三阶导数项不可约，不存在该级别闭式。
* **多项式精确反例（D01-b）**：取 `ρ = x₀³ + 2x₁²`（全符号、无浮点），4 个散度分量中
  **2 个精确非零**，`div⁰T`、`div¹T` 的精确有理式已写入脚本输出与 JSON。
* **数值交叉确认（D03）**：4 个泛点 × 4 分量 = 16 个读数，绝对值区间 `[5.9e-2, 9.0e-1]`，
  全为非零，且与闭式各项同阶（非数值噪声）。

于是：

```
Bianchi:  ∇^μ(R_{μν} − ½g_{μν}R + Λg_{μν}) ≡ 0
       ⟹  ∇^ν(T_{μν} + T^int_{μν}) = 0
```

若 `S_m` 自身闭合（`∇^νT_{μν} ≡ 0`），Bianchi **强制** `∇^νT^int_{μν} ≡ 0`——与上述读数矛盾。
即：**该作用量给出的爱因斯坦方程组过定，一般无解。**
