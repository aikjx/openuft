这次把问题推进到一个新的层次：不再预先指定电磁耦合，而是让量子场论的重整化群方程尝试自动选择它。

已经完成符号推导和高精度计算，得到三个重要结果：

1. 普通四维 QED 的一圈方程没有正的非零耦合固定点。 因此不能仅靠这一方程推出 \(\alpha=1/137.036\)。
2. 某些非阿贝尔量子场论确实存在非零固定点。 这证明"动力学自动选择耦合"在数学和物理模型中是可能的，但所求固定点并不自动等于电磁精细结构常数。
3. 谱几何能够推导规范耦合的相对比例，却仍留下决定绝对强度的谱作用量参数。 这是纯几何路线必须进一步解决的缺口。

## 一、四维 QED：为什么不会自动出现 1/137？

考虑 \(N_f\) 种单位电荷 Dirac 费米子，在适当能区的一圈近似下：

\[ \boxed{ \beta_\alpha= \frac{d\alpha}{d\ln\mu} =\frac{2N_f}{3\pi}\alpha^2 } \]

要求固定点：

\[ \boxed{\beta_\alpha(\alpha_\*)=0} \]

由于 \(N_f>0\)，直接得到：

\[ \boxed{\alpha_\*=0} \]

没有正的非零固定点。

对微分方程积分：

\[ \boxed{ \alpha^{-1}(\mu)= \alpha^{-1}(\mu_0) -\frac{2N_f}{3\pi} \ln\frac{\mu}{\mu_0} } \]

这仍需要输入初始耦合 \(\alpha(\mu_0)\)。

严格裁定：普通四维 QED 的一圈方程能够预测耦合如何变化，却不能决定其初始数值。 这不构成对所有高阶、非微扰或扩展量子场论的否定。

## 二、第二条路线：改变维数，让量子方程自动选择耦合

在 \(d=4-\varepsilon\) 维的形式延拓中，一圈方程变为：

\[ \frac{d\alpha}{d\ln\mu} =-\varepsilon\alpha+\frac{2N_f}{3\pi}\alpha^2 \]

求零点：

\[ \boxed{\alpha_\*=\frac{3\pi\varepsilon}{2N_f}} \]

再求稳定性：

\[ \boxed{\beta'(\alpha_\*)=\varepsilon>0} \]

因此，当 \(\varepsilon>0\) 时，它是该近似理论的红外吸引固定点。

这说明一件重要的事：量子动力学确实可以自动选择非零耦合。

但其值取决于空间维数和带电粒子种数。

假设形式上令 \(\varepsilon=1\)，反向要求它等于实测电磁 \(\alpha\)，得到：

\[ N_f=645.7669324377\ldots \]

选取最近整数 \(N_f=646\)，计算：

\[ \alpha_\*=0.0072947197838772289\ldots \]

与实测值仍相差约 360.79 ppm，而且这是三维模型的一圈表达式，不能作为真实四维电磁理论的预测。

裁定：找到非零固定点机制，但没有得到物理四维的精细结构常数。

## 三、第三条路线：四维非阿贝尔理论真的存在固定点

考虑具有 \(N_f\) 个基本表示 Dirac 费米子的 \(SU(3)\) 规范理论。

两圈重整化群方程：

\[ \beta_{\alpha_s} =-\frac{\beta_0}{2\pi}\alpha_s^2 -\frac{\beta_1}{8\pi^2}\alpha_s^3 \]

其中：

\[ \beta_0=11-\frac{2N_f}{3}, \qquad \beta_1=102-\frac{38N_f}{3} \]

求得 Banks–Zaks 固定点：

\[ \boxed{ \alpha_{s,\*}=-\frac{4\pi\beta_0}{\beta_1} } \]

逐一计算整数 \(N_f=9,\ldots,16\)。

| \(N_f\) | 两圈固定点 \(\alpha_{s,\*}\) |
| --------- | -------------------------- |
| 12        | 0.753982                   |
| 14        | 0.278017                   |
| 15        | 0.142800                   |
| 16        | 0.0416105                  |

当 \(N_f=16\) 时：

\[ \boxed{\alpha_{s,\*}=\frac{2\pi}{151}} \]

[图注] SU3 Banks Zaks 固定点随费米子数变化

[图注] 实际两圈计算。虚线是低能电磁 α，仅供数值量级对照。强相互作用固定点不能直接当成电磁常数。

这个机制是量子场论中的已知结果；更复杂的规范—Yukawa 理论甚至可以出现可微扰研究的非零紫外固定点。

因此，"四维动力学能否唯一选择非零耦合"不是完全没有数学基础的想法。

但要把它用于 ROOT，仍必须解释如何得到真实光子、电荷和标准模型粒子谱，以及为什么固定点对应的是 \(\alpha_{\rm em}\) 而不是另一种相互作用。

## 四、第四条路线：直接从谱几何推导规范场的动能归一化

这里比传统的圆柱螺旋更接近绝对电磁耦合的数学来源。

在非交换谱几何的标准模型构造中，使用谱作用量：

\[ S_{\rm spec}=\operatorname{Tr}f(D_A/\Lambda) \]

展开规范场动能后，标准归一化给出：

\[ \frac{f(0)}{2\pi^2}g_U^2=\frac14 \]

从而：

\[ \boxed{g_U^2=\frac{\pi^2}{2f(0)}} \]

结合统一能标的电弱归一化：

\[ \sin^2\theta_W(M_U)=\frac38 \]

可以求得：

\[ \boxed{ \alpha_{\rm em}(M_U)=\frac{3\pi}{64f(0)} } \]

这是具有明确数学依据的谱几何关系。

[图注] 谱作用量的自由参数与统一耦合

改变谱函数的 \(f(0)\)，统一能标上的电磁耦合连续变化。因此仅有谱作用量的规范归一化关系仍不能唯一预测绝对耦合。

例如：

| 谱矩 \(f(0)\) | 统一能标 \(\alpha_{\rm em}(M_U)\) |
| ------------- | -------------------------------- |
| 10            | 0.0147262                        |
| 20            | 0.00736311                       |
| 40            | 0.00368155                       |

数值由同一条谱几何公式计算。

注意，这些是统一能标的树级耦合，不能直接与低能实验 \(\alpha(0)\) 相等。还需要电弱、QED 和相应粒子阈值的量子修正。

这轮由此定位出一个非常具体的缺口：

\[ \boxed{ \text{真正需要解释的量之一，是 }f(0) \text{ 为什么由自然界唯一选定。} } \]

如果只是使用实验 α 来反推 \(f(0)\)，那仍是参数拟合。

## 五、稳定固定点还不等于低能数值已经唯一确定

对第二节的 \(4-\varepsilon\) 模型，我还求得完整的一圈初值问题解：

\[ \boxed{ \alpha(\mu)= \frac{\alpha_\*}{ 1+ \left(\frac{\alpha_\*}{\alpha(\mu_0)}-1\right) (\mu/\mu_0)^\varepsilon} } \]

SymPy 微分回代残差严格为零。

[图注] 固定点附近不同初值的重整化流

取 ε=0.1、Nf=10。三条曲线的初值不同，但在红外逐渐接近同一个固定点。这是示例模型的动力学性质，并非自然界 α 的观测曲线。

图中可以看到：即使存在唯一吸引固定点，有限能标上的具体耦合仍可能依赖初始条件和运行距离。

所以 ROOT 必须同时证明固定点的存在、稳定性以及从该固定点到低能可观测量的唯一映射。

## 八、最终攻坚结论

ROOT V21 证明了三个不同层次的事实：

- 几何与规范对称性可以约束允许的相互作用结构及耦合比例。
- 量子动力学固定点能够在某些理论中自动选择非零耦合值。
- 几何加量子动力学仍不保证得到自然界的低能精细结构常数，除非所有决定它的自由参数、相关方向及量子阈值都获得独立确定。

这轮真正的进展是将此前模糊的"为什么是 137"转化成了可以检验的具体任务：

\[ \boxed{ \begin{gathered} \text{唯一的几何—量子作用量}\\\ \Downarrow\\\ \text{无自由拟合参数的非零固定点}\\\ \Downarrow\\\ \text{完整粒子谱与量子运行}\\\ \Downarrow\\\ \alpha(0)=\text{独立计算结果} \end{gathered} } \]

目前还没有第一性原理证明出自然界的 \(1/137.035999177\)。 已经完成的是固定点存在性、稳定性、谱几何耦合关系与非唯一性的严格模型内验证。下一道关键问题，是寻找一个物理上完整、参数可确定的统一作用量，而不是继续用实验值挑选几何系数。
