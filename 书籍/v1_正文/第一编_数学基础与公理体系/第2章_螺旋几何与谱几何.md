## 2.1 曲线论基础：Frenet-Serret 标架

研究一条空间曲线 $\boldsymbol{r}(s)$，其中 $s$ 为弧长参数。Frenet-Serret 标架由三个正交单位向量构成：

- 切向量 $\boldsymbol{T} = d\boldsymbol{r}/ds$
- 法向量 $\boldsymbol{N} = (d\boldsymbol{T}/ds)/\kappa$
- 副法向量 $\boldsymbol{B} = \boldsymbol{T} \times \boldsymbol{N}$

**Frenet-Serret 公式**：

$$
\frac{d}{ds}\begin{pmatrix}\boldsymbol{T}\\\boldsymbol{N}\\\boldsymbol{B}\end{pmatrix}
=
\begin{pmatrix}0 & \kappa & 0\\-\kappa & 0 & \tau\\0 & -\tau & 0\end{pmatrix}
\begin{pmatrix}\boldsymbol{T}\\\boldsymbol{N}\\\boldsymbol{B}\end{pmatrix}
$$

其中 $\kappa$ 为**曲率**，$\tau$ 为**挠率**。二者是曲线的几何不变量——与参数化方式无关。

### 元数据表（五字段）

| 符号 | 定义 | 来源方程 | 量纲（ℓⁿ） | 数值/闭式 | 验证状态+出处 |
|---|---|---|---|---|---|
| $\kappa$ | Frenet 曲率 | $\kappa = |d\boldsymbol{T}/ds|$ | $\ell^{-1}$ | $\kappa = R\omega^2/v^2$ | 已验证（sympy，`frenet.py`） |
| $\tau$ | Frenet 挠率 | $\tau = -\boldsymbol{B}'\cdot\boldsymbol{N}$ | $\ell^{-1}$ | $\tau = \omega b/v^2$ | 已验证（sympy，`frenet.py`） |
| $v$ | 曲线运动速率 | $v = ds/dt$ | $\ell^{0}$（自然单位 c=1） | $v^2 = R^2\omega^2 + b^2$ | 结构已证（S01-A1） |

## 2.2 螺旋参数化与三重奏恒等式（核心定理）

### 2.2.1 圆柱螺旋参数化

**S01-A1（螺旋参数化）**：

$$\boldsymbol{r}(t) = (R\cos\omega t,\; R\sin\omega t,\; bt)$$

其中 $R$ 为圆柱半径，$\omega$ 为角频率，$b$ 为轴向螺距参数。速率为：

$$v^2 = R^2\omega^2 + b^2$$

### 2.2.2 曲率与挠率的闭式

**S01-A2（Frenet 条件性结构）**：对圆柱螺旋线，直接计算得：

$$\kappa = \frac{R\omega^2}{v^2}, \qquad \tau = \frac{\omega b}{v^2}$$

推导约 6 步（叉积微分+归一化），sympy 精确验证。

### 2.2.3 三重奏恒等式（核心定理）

**定理（螺旋三重奏恒等式）**：

$$\boxed{\kappa^2 + \tau^2 = \left(\frac{\omega}{v}\right)^2}$$

**推导链**：

```text
S01-A1 参数化 r(t)
  → 求一阶导 r'(t) = (-Rω sinωt, Rω cosωt, b)
  → 求二阶导 r''(t) = (-Rω² cosωt, -Rω² sinωt, 0)
  → Frenet 公式 κ = |r' × r''| / |r'|³
  → 计算叉积 r' × r'' = (-bRω² cosωt, -bRω² sinωt, R²ω³)
  → |r' × r''| = ω²√(b² + R²ω²) = ω²v
  → κ = ω²v / v³ = ω²/v² = Rω²/v² · R  ... 即 κ = Rω²/v² ✓
  → τ = (r' × r'')·r''' / |r' × r''|² = ωb/v² ✓
  → 代数求和：κ² + τ² = (R²ω⁴ + b²ω²)/v⁴ = ω²(R²ω²+b²)/v⁴ = ω²v²/v⁴ = (ω/v)²
  → 结论：κ² + τ² = (ω/v)²  ∎
```

**验证状态**：

- sympy 符号推导差 = 0（精确恒等式）
- mpmath 50 位数值对标：残差 ≤ 1.4×10⁻¹⁶（机器零级）
- 电子回旋数值对标：B=1 T，$v_\perp=0.6c$, $v_\parallel=0.5c$，相对差 0.0

**v→c 极限**：当 $v\to c$ 时，恒等式精确恢复为 $\kappa^2+\tau^2=(\omega/c)^2$——这就是 S02/S07/S12 各体系借用的"三重奏公理"的真正来源：它不是公理，是**定理**。

## 2.3 全维生成元与 D 维推广

**S01-A3（全维生成元推广）**：D 维世界线有 D−1 个 Frenet 曲率 $\kappa_1, \kappa_2, \ldots, \kappa_{D-1}$。

关键公式：

$$\sum_{i=1}^{D-1}\kappa_i^2 = \sum_{j=1}^{D-1}\frac{\omega_j^2}{v^2} = \frac{-\mathrm{tr}(A^2)}{2v^2}$$

其中 $A$ 为反对称生成元矩阵。

**验证状态**：R9 已证，数值自洽。

**退化检验**：

- $D=3$（三维空间）：$\kappa_1=\kappa$, $\kappa_2=\tau$，上式退化为 $\kappa^2+\tau^2=(\omega/v)^2$，与三重奏恒等式一致。
- $D=2$（平面曲线）：$\kappa_1=\kappa$, $\tau=0$，退化为 $\kappa=\omega/v$。

## 2.4 Planck 重组与量纲修复

### 2.4.1 Planck 重组恒等式

**恒等式（de Broglie–Planck 重组）**：

$$\kappa\ell_P = \frac{E}{E_P} = \frac{\ell_P}{\lambda_C}$$

其中 $\ell_P = \sqrt{\hbar G/c^3}$ 为普朗克长度，$\lambda_C = \hbar/(mc)$ 为约化康普顿波长，$E_P = \sqrt{\hbar c^5/G}$ 为普朗克能量。

**验证状态**：mpmath 250 位精度，5 粒子（电子、质子、中子、μ子、W 玻色子）对标，相对差 ≤ 1×10⁻²⁵¹。

**诚实标注**：这是恒等式重写——把 $\kappa = 1/R$ 与 de Broglie 波长 $\lambda_C$、普朗克尺度 $\ell_P$ 三者通过 $R = \hbar/(mc)$ 联立。**它不增加新物理内容**，只是把已知量重新组合。

### 2.4.2 量纲修复式

原始三重奏写作 $\kappa^2+\tau^2=(\omega/c)^2$。量纲分析发现严重断裂：

- 左端 $\kappa^2+\tau^2$：量纲 $L^{-2}$
- 右端 $(\omega/c)^2$：$\omega$ 量纲 $T^{-1}$，$c$ 量纲 $L/T$，故 $(\omega/c)^2$ 量纲 $L^{-2}$ ——等等，这看起来量纲是对的？

**真正的问题**：原稿曾写作 $(\omega\ell_P/c)^2$——右端无量纲，左端 $L^{-2}$，断裂约 70 个数量级（$\ell_P^{-2} \sim 10^{70}$ m⁻²）。修复后：

$$\boxed{(\kappa\ell_P)^2 + (\tau\ell_P)^2 = \left(\frac{\omega\ell_P}{c}\right)^2}$$

两端均为无量纲——量纲断裂修复。

**方法论注记**：这就是量纲分析作为质检工具的价值——它能抓到"差 70 个数量级"的笔误。第4章将系统展开量纲系统。

## 2.5 数学边界与负结果（诚实记录）

S01 不仅有正面成果，还有一系列重要的**负结果**——这些负结果同样是数学事实，而且比正面定理更能划定理论的边界。

### 2.5.1 S5：常数生成数学上不可能

**问题**：能否从螺旋几何出发，**反向生成**物理常数（如牛顿常数 $G$）？

**方法**：sympy 求解方程组 $\kappa^2+\tau^2=(\omega/v)^2$ 中 $G$ 的解。

**结果**：解 $G$ 为空集。原因：

1. **欠定**：方程数少于未知数。
2. **循环论证**：若从 $G$ 出发定义 $\ell_P$，再从 $\ell_P$ 反推 $G$，构成循环。

**结论**：三重奏恒等式不能用来生成 $G$ 等物理常数。数学上严格不可能。

### 2.5.2 QA-6：KK 额外维解读被排除

**问题**：把三重奏解读为卡鲁扎–克莱因额外维效应，是否自洽？

**方法**：数值对比 KK 紧致化半径预言与观测约束。

**结果**：矛盾 6.8–11 个数量级。**KK 解读排除。**

### 2.5.3 τ↔电磁映射成立但平凡

**问题**：挠率 $\tau$ 是否对应电磁相互作用？

**结果**：映射在几何上成立——磁场使带电粒子螺旋运动（$\tau\neq0$），三重奏的 $(\kappa,\tau,\omega)$ 恰好编码回旋几何。

**但这是已完全理解的经典电磁物理的几何化重述**——不产生新预言。把"回旋运动的几何描述"包装成"统一场论对电磁力的解释"，是把已知物理换个说法，不是新发现。

## 2.6 S01 作为数学底座的借用规则

S01 是数学框架，不是物理理论。它在 openuft 中的角色是**公共数学底座**——多个体系借用它的螺旋几何语言：

| 借用方 | 借用内容 | 证据等级传递规则 |
|---|---|---|
| S02 | 三重奏作几何基石 | S01 数学成立 ≠ S02 本体成立 |
| S07 v4 | Frenet 公式、复曲率 $\Xi=\kappa+i\tau$ | 几何定义成立，物理诠释独立审查 |
| S10 | 复曲率模方 $|\Xi|^2 = \kappa^2+\tau^2$ | 数学恒等成立，频率本体独立审查 |
| S12 | v=c 特化三重奏 $\kappa^2+\tau^2=(\omega/c)^2$ | 定理特化成立，v≡c 本体独立审查 |
| S13 | 借用曲线论语言 | 不继承 S01 任何物理结论 |

**核心规则：数学结果不直接认证物理公设。** S01 证明了 $\kappa^2+\tau^2=(\omega/v)^2$——这是一个关于圆柱螺旋线的数学定理。它不告诉我们"空间本身在做螺旋运动"，也不告诉我们"电子是一个螺旋线"。那些是各借用体系自己的物理公设，需要独立验证。

## 2.7 本章小结

S01 螺旋三重奏与谱几何是 openuft 中数学最干净的体系：

1. **核心定理** $\kappa^2+\tau^2=(\omega/v)^2$：sympy 差=0，mpmath 50 位残差 ≤ 1.4×10⁻¹⁶。
2. **全维推广** $\sum\kappa_i^2=-\mathrm{tr}(A^2)/(2v^2)$：D 维一致。
3. **Planck 重组** $\kappa\ell_P=E/E_P$：恒等改写，250 位对标。
4. **量纲修复**：$(\kappa\ell_P)^2+(\tau\ell_P)^2=(\omega\ell_P/c)^2$。

但 S01 同样诚实记录了它的边界：反向生成物理常数数学上不可能；KK 解读被排除；τ↔电磁映射平凡；五项 OPEN 未闭合。

S01 的价值在于：它提供了一套**严格可复现的几何语言**，让后续各体系在同一数学平台上对话。它不提供物理本体——本体是各体系自己的事。
