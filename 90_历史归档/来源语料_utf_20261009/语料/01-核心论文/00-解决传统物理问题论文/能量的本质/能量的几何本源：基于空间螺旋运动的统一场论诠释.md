根据质能方程，物体的相对论性能量为：

E = m'c² = γmc²

从空间螺旋运动的几何角度来看，当物体运动时，其内部的空间螺旋运动状态会发生变化。具体来说，空间螺旋运动的角速度会减小，而线速度会增加。

根据空间螺旋运动的几何特性，我们可以证明：

E = γmc²

其中，γ反映了空间螺旋运动状态的变化。

### A.4 能量与动量关系的详细推导

物体的动量p = mv = mγv。

根据质能方程，E = γmc²。

将动量和能量代入关系式，得到：

(pc)² + (mc²)² = (mγvc)² + (mc²)² = m²c⁴(γ²v²/c² + 1)

由于γ² = 1/(1 - v²/c²)，因此：

γ²v²/c² + 1 = v²/c²/(1 - v²/c²) + 1 = (v²/c² + 1 - v²/c²)/(1 - v²/c²) = 1/(1 - v²/c²) = γ²

因此，(pc)² + (mc²)² = m²c⁴γ² = (γmc²)² = E²

这证明了能量与动量的关系，表明这一关系是空间螺旋运动几何特性的必然结果。
