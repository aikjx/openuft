## §4 裁定：选定候选 3（χ² 联合拟合模块）

**裁定：选定第 3 项。** 理由四条，逐条对应仓库既有判据：

1. **它攻的是唯一的硬缺口**。README 与《统一场论达成度》均记：**18 个体系登记的无量纲预测数为 0**，
   `claims_schema_升级.py` 已给 `claims.csv` 加出 `prediction_value` / `prediction_urel` 两列（UFT-3 登记必填），
   但**至今没有任何引擎消费这两列**——登记链路「能登记、无人算」。χ² 层正是那个「算」。
2. **它不与既有工具重复**。仓库的判别式体系（V / V3 / V4 / V5，定理 C/D/E/F/G/H/I/J/K/L/T）回答的是
   **「能不能派生」**（信息论与秩层）；`spiral_c35_beta_universality.py` 回答的是**单靶判决力**。
   **无人回答「多个靶联合起来，某个参数被约束到几位、Δχ² 多大、协方差如何」**——这正是统计层。
3. **它与红线相容**。它**不新造判据**（复用既有 V 与秩口径做独立性判定，只补统计量），
   输出仍是「四态 + 判定册 + `数据/*.json,md`」的仓库标准形态；且它**天然可被证伪**：
   变异体测试（缩 σ、换理论值、破坏协方差正定性、置 ρ 越界）必须全部被咬住。
4. **它可直接复用既有成果、不外扩承诺**。输入侧复用 `源码/无量纲靶场审计.py` 的 10 靶定义与
   定理 Σ_cov 的相关系数**可识别性判据**（`ρ(m_p,m_e)=+0.9812`、余量 254× 可用 / `m_μ/m_e` 0.11× 不可识别），
   输出侧复用 `07_.../验证脚本/` 的牙齿（teeth）范式。**不主张它会产生 L3**——见 §5.6 诚实边界。

> **与候选 1 的关系（不是二选一的对立）**：候选 1 的**唯一正当前置**是把 §2 ①② 的口径按台账改写；
> 而这一改写所需的「判决力读数」恰由候选 3 提供。⇒ **候选 3 是候选 1 的前置件**，顺序上应先 3 后 1。
> 候选 2 定位为**可选展示件**，其正确做法是**收敛到既有 `04_公共成果/可视化/` 与归档 three.js 站点**，
> 不新起一套。

### 5.3 计算规格（不新造判据）

| 量 | 定义 | 复用来源 |
|---|---|---|
| 单靶 χ² | $\chi^2_i=\big((T_i-O_i)/\sigma_i\big)^2$，$\sigma_i=\lvert T_i\rvert\cdot u_{\rm rel,i}$ | 标准统计 |
| p 值 | $p_i=\operatorname{erfc}\big(\sqrt{\chi^2_i/2}\big)$ | 标准统计 |
| 判决力 | $\Delta\chi^2_i(\delta)=(\delta/\sigma_i)^2$ ⇒ 输出「理论须偏离实测多少倍 σ 才能被判出」$\delta_{\min}=\sigma_i\sqrt{\chi^2_{\rm crit}(1,CL)}$ | 与 C50 的 `n_detect`、C51 的 1.6e-3″/百年 **同族** |
| 联合 χ² | $\chi^2=\mathbf r^{\mathsf T}\Sigma^{-1}\mathbf r$，$\Sigma_{ij}=\rho_{ij}\sigma_i\sigma_j$ | 标准统计 |
| 相关系数 | $\rho_{ij}=\dfrac{\sigma_i^2+\sigma_j^2-\sigma_{ij}^2}{2\sigma_i\sigma_j}$ + **可识别性判据**（余量不足则置 0） | **定理 Σ_cov**（第七册，已登记） |
| 自由度 | $\nu=N_{\rm tgt}-\operatorname{rank}(J)$，$J=\partial\ln T/\partial\ln(\text{旋钮}\cup\text{锚})$ | **定理 I / K / L**（秩口径，已登记） |
| 信息增益 V | 原样复用，不修改 | `源码/无量纲靶场审计.py` |

### 5.4 输出规格

1. **逐靶表**：`target_id`、$T$、$O$、$\sigma$、$\chi^2_i$、$p_i$、$\delta_{\min}$、是否标定靶；
2. **联合表**：$\chi^2$、$\nu$、$p$、协方差矩阵（含相关系数与可识别性判定）；
3. **UFT-3 登记看板**：`claims.csv` 中 `prediction_value` / `prediction_urel` 非空的条目数（**当前预期 = 0**），
   以及「若填入则本模块给出的 χ² 档位」——即所谓**「可审计且仍为 0」**；
4. **四态判定**：`PASS` / `BOUNDARY` / `INFO` / `FAIL`，逐条带引擎证据编号。

### 5.5 牙齿（变异体，必须全 CAUGHT）

| # | 种缺陷 | 期望 |
|---|---|---|
| T1 | 把某靶 σ 人为缩小 10× | 检测到 χ² 抬升并报 `σ` 不自洽 |
| T2 | 理论值替换为观测值（零残差） | 报「χ²≡0 且 ν≤0 ⇒ 无判别力」（**不得**判 PASS） |
| T3 | 破坏 Σ 正定性（置 $\lvert\rho\rvert>1$） | 拒绝求逆并报 `FAIL` |
| T4 | ρ 超出可识别余量（如 `m_μ/m_e` 0.11×） | 强制置 0 并报 `BOUNDARY` |
| T5 | 目标数为 0 时仍宣称联合 χ² | 拒绝，报「无对象」 |
| T6 | 自由度按「靶数 − 1」而非秩口径计算 | 报 `ν` 口径不符（定理 I） |
| T7 | 全靶被标定（`calibrated_by` 非空） | 报「零独立判别力」（C51 的机器版） |
| T8 | δ_min 报成 1σ 而非 χ²_crit 对应值 | 报阈值口径错 |
| T9 | 阳性对照：SM/GR 已知预言（水星 43.03±0.13 等） | 必须 **CLEAN**（χ² 通过，仪器有效） |
| T10 | 阳性对照：SM 的 `sin²θ_W` 独立测量 | 必须 **CLEAN**（χ² 通过，判「在格内/自洽」而非「派生」） |

### 5.6 验收标准（完成与否以此为准）

1. 引擎自检 **N/N 全绿**，`--teeth` 下 8 个种缺陷全 CAUGHT + 2 个阳性对照全 CLEAN；
2. 对照算例（SM / GR 已知预言）χ²、p、协方差反解与闭式手算**逐位一致**（口径见 §5.3）；

### 5.8 诚实边界（必须先写在引擎文档头）

1. **本模块不会自己产生 L3**。它把「判决力」变成读数；读数在目标登记为 0 时必然是「不可判」。
