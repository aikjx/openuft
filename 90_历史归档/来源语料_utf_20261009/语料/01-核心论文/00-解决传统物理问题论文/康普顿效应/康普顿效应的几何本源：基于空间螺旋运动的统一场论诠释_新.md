### A.1 康普顿散射公式的详细推导

#### A.1.1 能量守恒方程

在康普顿散射中，能量守恒方程为：

E + E_e = E' + E_e'

其中，E = hc/λ为入射光子能量，E' = hc/λ'为散射光子能量，E_e = m_e c²为电子静止能量，E_e' = γm_e c²为反冲电子能量，γ = 1/√(1 - v²/c²)为洛伦兹因子。

整理能量守恒方程：

hc(1/λ - 1/λ') = m_e c²(γ - 1)

#### A.1.2 动量守恒方程

动量守恒矢量方程为：

**p** + **p**_e = **p**' + **p**_e'

假设电子初始静止，**p**_e = 0，入射光子沿x轴方向，则动量守恒在x和y方向的分量为：

x方向：p = p'cosθ + p_e'cosφ

y方向：0 = p'sinθ - p_e'sinφ

其中，p = h/λ，p' = h/λ'，p_e' = γm_e v。

#### A.1.3 推导康普顿散射公式

将动量守恒的两个分量方程平方后相加：

p² + p'² - 2pp'cosθ = p_e'² = γ²m_e²v²

利用能量守恒方程，我们可以将γ表示为：

γ = 1 + hc(1/λ - 1/λ')/(m_e c²) = 1 + h(1/λ - 1/λ')/(m_e c)

又因为γ² = 1 + (γ² - 1) = 1 + (γm_e v/c)²/c² = 1 + p_e'²/(m_e² c²)

将p_e'²代入上式：

γ² = 1 + (p² + p'² - 2pp'cosθ)/(m_e² c²)

将γ的表达式代入：

[1 + h(1/λ - 1/λ')/(m_e c)]² = 1 + (p² + p'² - 2pp'cosθ)/(m_e² c²)

展开左边：

1 + 2h(1/λ - 1/λ')/(m_e c) + h²(1/λ - 1/λ')²/(m_e² c²) = 1 + (p² + p'² - 2pp'cosθ)/(m_e² c²)

消去1，整理得：

2h(1/λ - 1/λ')/(m_e c) = (p² + p'² - 2pp'cosθ - h²(1/λ - 1/λ')²)/(m_e² c²)

注意到p = h/λ，p' = h/λ'，代入得：

2h(1/λ - 1/λ')/(m_e c) = (h²/λ² + h²/λ'² - 2h²/(λλ')cosθ - h²(1/λ - 1/λ')²)/(m_e² c²)

化简右边：

= h²[1/λ² + 1/λ'² - 2/(λλ')cosθ - (1/λ - 1/λ')²]/(m_e² c²)

= h²[1/λ² + 1/λ'² - 2/(λλ')cosθ - 1/λ² + 2/(λλ') - 1/λ'²]/(m_e² c²)

= h²[2/(λλ')(1 - cosθ)]/(m_e² c²)

因此：

2h(1/λ - 1/λ')/(m_e c) = 2h²(1 - cosθ)/(m_e² c² λλ')

两边同时除以2h/(m_e c)：

(1/λ - 1/λ') = h(1 - cosθ)/(m_e c λλ')

两边同时乘以λλ'：

λ' - λ = h(1 - cosθ)/(m_e c)

这就是康普顿散射公式，其中h/(m_e c)为电子的康普顿波长λ_c。
