【GP1】地球结构与重力场
----------------------------------------------------------------------

  地球物理概述：

  地球物理学是用物理学方法研究地球内部结构、物质组成和物理过程的学科。
  它是地球科学的重要分支，与地质学、大气科学、海洋科学交叉。

  地球物理的主要分支：
    - 地震学：地震波研究地球内部
    - 地磁学：地球磁场与岩石磁性
    - 重力测量：地球重力场
    - 地电学：地球电性结构
    - 地热学：地球热状态
    - 板块构造：地壳运动
    - 应用地球物理：资源勘探

  地球分层结构：

  地球从外到内：
    - 地壳：0-35 km（海洋5-10km，大陆30-70km）
      大陆地壳：硅铝质（花岗岩，密度2.7 g/cm³）
      海洋地壳：硅镁质（玄武岩，密度3.0 g/cm³）
    - 地幔：35-2900 km
      上地幔：35-410 km（橄榄岩）
      过渡带：410-660 km（矿物相变）
      下地幔：660-2900 km
    - 外核：2900-5150 km（液态铁镍）
    - 内核：5150-6371 km（固态铁镍）

  Moho面（莫霍洛维奇不连续面）：
    1909年由Andrija Mohorovičić发现
    地壳-地幔边界，地震波速度突变
    深度：大陆~35km，海洋~7km

  地球重力场：

  地表重力加速度：
    g = GM/R² = 9.80665 m/s²

  g的纬度变化（国际重力公式）：
    g(φ) = 9.780327(1 + 0.0053024sin²φ - 0.0000058sin²2φ)
    赤道：9.7803 m/s²
    极地：9.8322 m/s²
    差异：~0.5%（离心力+地球扁率）

  地表重力计算：
    g = GM/R² = 9.81997 m/s²
    实验值：9.80665 m/s²
    误差：0.136%

  地球转动惯量：

  均匀球的转动惯量因子：2/5 = 0.4
  地球实际值：I/(MR²) = 0.3307
  说明：质量向中心集中（致密内核）

  地球进动：

  岁差周期：~26000年
  章动周期：18.6年（月球交点）
  日长变化：~1.7ms/世纪（潮汐摩擦）

  螺旋几何化解释：

  1. 地球结构的螺旋几何化
     - 地球 = 螺旋旋转的层状球体
     - 自转 = 地球的螺旋运动
     - 分层 = 螺旋密度的径向分布
     - 转动惯量因子 = 螺旋质量分布

  2. 重力场的螺旋解释
     - 重力 = 螺旋时空的曲率效应
     - g值 = 地球螺旋质量的引力场
     - 纬度变化 = 自转离心力的螺旋修正

  3. 地球自转的螺旋解释
     - 自转 = 地球围绕地轴的螺旋运动
     - 角速度 = 地球螺旋振动的频率
     - 日长 = 地球螺旋周期的度量

【GP2】地震学
----------------------------------------------------------------------

  地震学概述：

  地震学是研究地震波、地震源和地球内部结构的学科。
  地震波是地球内部传播的弹性波，是探测地球内部的最重要工具。

  地震波类型：

  体波（通过地球内部）：
    P波（纵波/压缩波）：
      - 质点振动平行于传播方向
      - 速度最快：6-8 km/s（地壳）
      - 可通过固体、液体、气体
    S波（横波/剪切波）：
      - 质点振动垂直于传播方向
      - 速度：3.5-4.6 km/s（地壳）
      - 只能通过固体（这是外核为液态的证据）

  面波（沿地表传播）：
    Rayleigh波：
      - 椭圆运动（垂直面内）
      - 速度：~0.9倍S波
      - 破坏性最强
    Love波：
      - 水平剪切运动
      - 速度介于S波和Rayleigh波之间

  地震波速与地球内部：

  P波速度剖面：
    地壳：5.5-7.0 km/s
    地幔：8.1-13.7 km/s
    外核：8.1-10.4 km/s（液态，S波消失）
    内核：11.3 km/s

  地震波速度与密度关系（Birch定律）：
    v_p = a + bρ
    其中 a ≈ -1.87 km/s, b ≈ 3.05 km/s/(g/cm³)

  地震定位：

  走时定位原理：
    P-S波到时差：Δt = t_s - t_p
    震中距：Δ = v·Δt（近似）

  三台定位法：
    三个台站分别测出震中距
    三圆交点 = 震中

  震中距估算（P-S差4s）：
    Δ = v_p·v_s/(v_p-v_s)·Δt = 33.6 km

  地震震级：

  里氏震级（Richter, 1935）：
    M_L = log₁₀(A) - log₁₀(A₀)
    其中 A 是地震仪振幅，A₀ 是参考振幅

  矩震级（现代标准）：
    M_w = (2/3)log₁₀(M₀) - 6.07
    其中 M₀ = μAD 是地震矩（N·m）

  震级与能量关系：
    log₁₀(E) = 1.5M + 4.8（J）
    每级相差：10^1.5 ≈ 31.6倍能量

  地震能量计算（M_w = 7.0）：
    E = 10^(1.5M+4.8) = 2.00×10¹⁵ J
    相当于 0.48 百万吨TNT

  2008汶川地震（M_w 7.9）：
    能量 ~ 10^(1.5×7.9+4.8) = 7.9×10¹⁶ J
    相当于 ~19 百万吨TNT
    约500个广岛原子弹

  地震预警：

  原理：
    P波（快）先到，S波（慢）后到
    利用P波到时预警S波破坏

  预警时间：
    距震中100km：约20-30s预警时间
    距震中10km：约3s
    日本新干线：P波预警系统

  螺旋几何化解释：

  1. 地震波的螺旋几何化
     - P波 = 纵向螺旋振动的传播
     - S波 = 横向螺旋振动的传播
     - Rayleigh波 = 椭圆螺旋轨道的传播
     - Love波 = 水平螺旋剪切的传播

  2. 地震定位的螺旋解释
     - 走时 = 螺旋波前的到达时间
     - P-S差 = 两种螺旋振动的速度差
     - 震源 = 螺旋波动的发射源
     - 震级 = 螺旋波能量的度量

  3. 地球内部的螺旋解释
     - 波速剖面 = 螺旋介质的刚度分布
     - S波消失 = 液态外核无螺旋剪切
     - 内核 = 螺旋晶格的铁镍核

【GP3】地磁学
----------------------------------------------------------------------

  地磁学概述：

  地磁学研究地球磁场的分布、起源和变化。
  地球磁场是地球的保护伞，抵御太阳风和宇宙射线。

  地磁场基本性质：

  地磁要素：
    - 磁偏角 D：地理北与磁北的夹角
    - 磁倾角 I：磁场与水平面的夹角
    - 水平分量 H、垂直分量 Z、总强度 F

  磁场强度：
    地表总强度：25-65 μT
    平均：~50 μT（0.5 G）
    磁极处：~65 μT
    磁赤道：~25 μT

  地磁场模型：

  偶极场近似：
    B(r,θ) = (μ₀m/4πr³)√(1+3cos²θ)
    磁偶极矩 m = 7.79×10²² A·m²

  国际地磁参考场（IGRF）：
    每5年更新
    球谐展开：n=1（偶极）到n=13
    偶极占~90%，非偶极占~10%

  偶极场计算：
    磁极 B = 60.2 μT
    磁赤道 B = 30.1 μT
    实验值：磁极~65μT, 赤道~25-30μT

  地磁场起源——发电机理论：

  地球发电机：
    液态外核（铁镍）+ 自转 + 对流 → 自激发电机

  自激发电机条件（Larmor机制）：
    - 导电流体：外核液态铁镍
    - 运动：对流+科里奥利力（螺旋运动）
    - 初始种子场：弱磁场
    - 放大：流场剪切放大磁场

  发电机数：
    D = Rm·(磁Reynolds数)
    当Rm > 临界值：自激发电

  地磁倒转：

  地磁极性倒转：
    平均间隔：~20-30万年
    最长间隔：Brunhes正极性期 78万年
    最短间隔：数千年（地磁偏移）
    最后一次倒转：~78万年前（Brunhes-Matuyama）

  倒转记录：
    海底磁条带（Vine-Matthews假说）
    岩石剩磁记录极性
    为板块构造提供了关键证据

  磁暴与地磁活动：

  地磁活动指数：
    Kp指数：0-9（全球地磁活动）
    Dst指数：环电流强度
    Ap指数：Kp的线性转换

  太阳风暴影响：
    - 磁暴：地磁扰动
    - 极光：高能粒子激发大气
    - 磁层亚暴：磁层能量释放
    - 可能损坏电网和卫星

  螺旋几何化解释：

  1. 地磁场的螺旋几何化
     - 偶极场 = 螺旋电流环的磁场
     - 磁力线 = 螺旋磁场线
     - 磁层 = 地磁场的螺旋保护壳

  2. 发电机理论的螺旋解释
     - 外核 = 螺旋对流导体
     - 科里奥利力 = 自转的螺旋效应
     - α效应 = 螺旋对流的磁场放大
     - ω效应 = 差动旋转的磁场剪切

  3. 地磁倒转的螺旋解释
     - 倒转 = 螺旋发电机的极性翻转
     - 不稳定 = 螺旋对流的混沌
     - 磁条带 = 螺旋极性的历史记录

【GP4】板块构造
----------------------------------------------------------------------

  板块构造理论：

  板块构造理论是20世纪地球科学最伟大的革命：
    1912年：Wegener提出大陆漂移假说
    1960年代：海底扩张（Vine-Matthews）
    1968年：板块构造理论确立

  主要板块：

  7大板块：
    太平洋板块（最大，全海洋）
    欧亚板块
    非洲板块
    北美板块
    南美板块
    印度-澳大利亚板块
    南极板块

  次级板块：
    菲律宾板块、阿拉伯板块、加勒比板块、纳兹卡板块等

  板块边界类型：

  1. 离散边界（张裂）：
     - 板块分离，岩浆上涌
     - 洋中脊（大西洋中脊、东太平洋海隆）
     - 裂谷（东非大裂谷）
     - 新海底形成：~2-10 cm/年

  2. 汇聚边界（碰撞）：
     - 海洋-大陆：俯冲（环太平洋火山带）
     - 大陆-大陆：碰撞造山（喜马拉雅）
     - 海洋-海洋：岛弧（日本、菲律宾）
     - 俯冲带：海沟 + 火山弧

  3. 转换边界（走滑）：
     - 板块水平错动
     - 圣安德烈斯断层（美国加州）
     - 位移速率：~3-5 cm/年

  板块运动速率：

  典型速率：1-10 cm/年
    最快：东太平洋海隆 15 cm/年
    最慢：北冰洋中脊 1 cm/年
    印度板块：5 cm/年（碰撞欧亚）

  热点运动：
    夏威夷链：太平洋板块以~8 cm/年掠过热点
    黄石热点：北美板块以~2 cm/年

  板块运动计算：
    速率 v = 5.0 cm/年
    1亿年移动距离 = 500000 km

  驱动机制：

  主要驱动力：
    - 洋脊推力：洋中脊抬升的重力滑移
    - 板块拖拽力：俯冲板片的重力下沉
    - 地幔对流：热对流驱动
    - 地幔柱：深部热物质上涌

  地震-火山-板块构造：

  环太平洋火山带（火环）：
    - 占全球地震的80%
    - 占全球火山的75%
    - 俯冲带的地震-火山链

  Wilson循环：
    大陆裂谷→新生海洋→洋壳俯冲→碰撞造山
    周期：~5亿年

  螺旋几何化解释：

  1. 板块构造的螺旋几何化
     - 地幔对流 = 地球内部的螺旋对流环
     - 板块运动 = 螺旋对流的表层表达
     - 洋中脊 = 螺旋对流的上升支
     - 俯冲带 = 螺旋对流的下降支

  2. 地幔对流的螺旋解释
     - 对流环 = 热驱动的螺旋循环
     - 地幔柱 = 螺旋上升流
     - 热点 = 螺旋地幔柱的地表出口
     - 板块 = 螺旋对流的刚性盖层

  3. 造山运动的螺旋解释
     - 碰撞 = 螺旋板块的汇聚
     - 造山 = 螺旋应力的累积释放
     - 断层 = 螺旋剪切的破裂面

【GP5】地球内部物理与应用地球物理
----------------------------------------------------------------------

  地球内部物理：

  1. 地热学：
     - 地表热流：平均 87 mW/m²
     - 地温梯度：~25-30°C/km
     - 地核温度：~5700 K（近似太阳表面）
     - 热源：放射性衰变（U, Th, K）+ 初始热量

  2. 地球密度模型（PREM）：
     Preliminary Reference Earth Model（Dziewonski & Anderson, 1981）
     - 分层密度：地壳2.6→内核13.1 g/cm³
     - 深度依赖：连续密度剖面
     - 地震学+地球化学约束

  3. 地幔对流：
     - 瑞利数：Ra ~ 10⁶-10⁸（远超临界~10³）
     - 全地幔对流 vs 分层对流
     - 俯冲板片可下插至核幔边界

  地温梯度计算：
    热流 q = 87 mW/m²
    岩石热导率 k = 3.0 W/(m·K)
    地温梯度 dT/dz = 29.0 °C/km

  应用地球物理：

  勘探方法：

  1. 地震勘探（最重要）：
     - 反射地震法：油气勘探主力
     - 人工震源：炸药/可控震源/气枪
     - 反射界面：岩性/流体变化
     - 三维地震：地下三维成像

  2. 重力勘探：
     - 测量重力异常
     - 找密度异常体（盐丘、矿体）
     - 精度：微伽级（10⁻⁸ g）

  3. 磁法勘探：
     - 测量磁异常
     - 找磁性矿体（磁铁矿）
     - 航空磁测、卫星磁测

  4. 电法勘探：
     - 电阻率法：找水和矿
     - 电磁法（MT, CSAMT）
     - 井中电测井：油气评价

  5. 放射性勘探：
     - 测量γ射线
     - 找铀矿
     - 环境辐射监测

  地球物理观测技术：

  GPS/GNSS：
    板块运动毫米级监测
    2011日本大地震：最大位移~5m

  InSAR（合成孔径雷达干涉）：
    地表形变厘米级监测
    火山监测、滑坡监测

  重力卫星（GRACE）：
    水储量变化监测
    冰川质量变化监测

  螺旋几何化解释：

  1. 地球内部的螺旋几何化
     - 地热 = 地球内部的螺旋热能
     - 对流 = 螺旋热环的驱动
     - 密度剖面 = 螺旋质量分布

  2. 勘探的螺旋解释
     - 地震波 = 螺旋弹性波的传播
     - 重力异常 = 螺旋质量的密度扰动
     - 磁异常 = 螺旋磁化的岩石记录
     - 电阻率 = 螺旋电子的传导能力

  3. 观测的螺旋解释
     - 形变 = 螺旋应变的累积
     - 位移场 = 螺旋板块运动的观测
     - 时变 = 螺旋地球系统的演化
