## 〇、一句话结论

**不可行**，但不可行的位置不是「找不到」，而是三条互斥约束各自顶住：

1. **几何墙**：能同时给出 dim 12 与 rank 4 的含 su(3) 内部构造，构造族内最小 n = 7 ⇒ D = 11（**奇**）
   ⇒ 无手征（Witten 正定理）；要 D 偶 ⇒ n ≥ 8 ⇒ D = 12 ⇒ 超出超引力维数上限 11。
2. **单群墙**：SU(5)/SO(10)/E6 在表示层**全部装得下**（24=8+3+1+6+6 / 45=24+10+10+1 / 78=45+16+16+1，
   每代 15 Weyl 亦可容纳）⇒ NC1 判力 **0**；但单群 ⇒ 一个归一化 ⇒ 至多一个规范耦合与一个 beta，
   与 M_Z 三耦合（比值 4.33 : 1 : 15.11）及两个质量标度（v/Λ_QCD = 1231.1，7.116 e-fold）冲突。
3. **度规墙**：4 维对称无迹张量只有 9 个分量，**零个 4-矢量** ⇒ 纯引力扇区**结构上**给不出 J_mu。
   正对照：D=5 的 14 = 9 + 4 + 1 精确配平 ⇒ 「单一作用量统一引力+电磁」在两力层**是可行的**。

⇒ 要「单一」就要放弃多耦合/多标度；要手征就要放弃 11 维几何；要四力全就只能是直积（不叫单一）。

## 二、NC1 规范代数秩（T01–T06）

机器读数（全部整数配平，无浮点）：

- dim su(3)+su(2)+u(1) = 8+3+1 = **12**；rank = 2+1+1 = **4**。
- SU(5)：**24 = 8 + 3 + 1 + 6 + 6**（SM 伴随全量 + X/Y 玻色子）⇒ SM 代数是 SU(5) 子代数。
- SO(10)：**45 = 24 + 10 + 10\* + 1**；E6：**78 = 45 + 16 + 16\* + 1**，且 **27 = 16 + 10 + 1**。
- 每代 15 Weyl：SU(5) 需 5\*+10（**2 个**不可约表示）；SO(10) 的 16 与 E6 的 27 各 **1 个**。

**T06（FAIL，本册最重要的诚实项）**：上述配平只证明「装得下」，不证明「必然采用」。
NC1 对 SU(5)/SO(10)/E6 **三条路线全部放行，判别力 = 0**。真正有牙的是 NC3（单耦合）与质子衰变，
不是代数秩。若把 NC1 当作否证工具，就是拿零判别力的判据冒充定理。

## 三、NC2 联络容量（T07–T11）

- **T07**：4 维仿射联络 4^3 = **64** = 度规相容 4×10 = **40** 约束 + 挠率 4×6 = **24** 自由。
  ⇒ 联络的 64 个分量**全部被时空指标用掉**，没有「内部指标」的空位。
- **T08（BOUNDARY）**：朴素比较 4 < 12（缺口 8）。这条**依赖编码方式**，不是定理。
- **T09（PASS）**：必要条件 A（Myers–Steenrod）dim Iso ≤ n(n+1)/2 ⇒ dim ≥ 12 要求 n ≥ **5**。
- **T10（FAIL，方法自我否证）**：首版用「单因子最大对称空间 rank = floor((n+1)/2)」推 n ≥ 7，
  **这是错的**——乘积流形的等距群是直积，维数与秩相加。反例 **S^3 × S^3**（n=6）
  已有 dim = 6+6 = **12**、rank = 2+2 = **4**，同时满足 A/B。若不修，n ≥ 7 会被当成定理。
- 由此迫出**必要条件 C**：Iso(M) 的代数分解必须含 su(3)（8 维单因子）⇒ S^3 × S^3 的因子全是 su(2)，被 C 排除。
- **T11（BOUNDARY）**：在含 su(3) 载体的构造族内，最小 n = **7**（CP^2×S^2×S^1 与 CP^2×S^3 并列）
  ⇒ D = **11（奇）**。**n=6 是否可能未被穷举证明**（6 维齐性空间分类未纳入）⇒ 标 BOUNDARY，不称定理。

## 四、NC3 单一耦合（T12–T15）

- **T12（PASS）**：alpha_em(M_Z)=7.8156e-3 / alpha_2=3.3804e-2 / alpha_3=0.1181；
  比值 **4.3252** 与 **15.1108**；对均值的偏差 **-85.3% / -36.5% / +121.8%**。
- **T13（FAIL）**：一个作用量归一 ⇒ 树图至多一个规范耦合 g。要把三值拉到同一 g 需要 -85%~+122% 的修正
  ⇒ 不是「微调」，是**缺两个自由度**（等价于缺两个标度，见 T15）。
- **T14（FAIL）**：单尺度类 S = {G=c_G/M^2, sigma=c_sigma·M^2, ...} 的不变量是 G·sigma。
  机器由 SI 换算 **G = 6.7088e-39 GeV^-2**、**G·sigma = 1.1875e-39**（sigma = 0.177 GeV^2），
  与类允许区 [1e-4, 1e4] 差 **34.9 个数量级** ⇒ 单一质量标度类被排除。
  独立交叉印证：`_chk_g9.py` 给 6.7e-39 / 1.19e-39（同一读数，两条独立路径）。
- **T15（FAIL）**：v/Lambda_QCD = **1231.1**（7.116 e-fold）。一个群只给一个 beta ⇒ 一个量纲嬗变标度
  ⇒ 要同时给 v 与 Lambda_QCD 必须 ≥2 个 beta ⇒ ≥2 个群。

## 五、NC4 手征与维数（T16–T20）

- **T16（FAIL）**：D = 11 为奇 ⇒ 紧化不能给手征费米子（Witten 1981 正定理，**引用**）。
- **T17（BOUNDARY）**：要手征 ⇒ D 偶 ⇒ n 偶 ⇒ n ≥ 8 ⇒ D ≥ **12**。

## 六、NC6 表示配平（T21–T25）

- **T21（PASS）**：恒等式 **D(D+1)/2 - 1 = 9 + 4n + n(n+1)/2**（n = D-4），D=4..12 十二个值全配平：
  D=5 → 14 = 9+4+1；D=6 → 20 = 9+8+3；D=7 → 27 = 9+12+6；…；D=12 → 77 = 9+32+36。
- **T22（FAIL，承重）**：D=4 只有 **9** 个分量、**零个矢量位置** ⇒ 纯引力扇区结构上给不出 J_mu。
  这不是「算不出来」，是「没有那个位置」。
- **T23（PASS，正对照）**：D=5 的 **14 = 9 + 4 + 1**（引力子 + 光子 + radion）⇒ KK 在**两力**层成立。
  判据因此不是恒否——这是本册最重要的反自欺证据。
- **T24（BOUNDARY）**：阿贝尔 KK 塔下界：12 个规范场 ⇒ n ≥ **12** ⇒ D ≥ **16**（旋量 2^8 = 256）。
- **T25（INFO）**：两条下界并存且**不可混用**：等距群构造族 n≥7（给非阿贝尔但撞手征）；
