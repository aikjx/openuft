图 1 · 整性定理：三行证明与它的判别力

上排 = 证明三步（x = a/b 既约、p | b）：每个因子 a − ib ≡ a (mod p) ⇒ p ∤ 分子；而 pⁿ | 分母（n ≥ 1）⇒ 约分后分母仍带 p ⇒ 不是整数。下排 = 整值率：只有 b=1 是 100%，b ≥ 2 全是 0 —— 1700 个非整点，一个例外都没有。

图 2 · 格重建：算术反解出的格，与 r325 的 Freed–Witten 格逐个重合

蓝实心 = 由「C(q+(n−1)/2, n) ∈ Z」在 1/4 步长上反解出的 q；红空心圈 = r325 定理 A 的 Freed–Witten 格（n 奇 Z、n 偶 Z+1/2）。圈恰好套在点上（12 个 n 全部），对称差 0。注意 n 奇时点是整数、n 偶时点是半整数 —— 这个奇偶交替的图案是算术自己长出来的，红圈没有参与生成。
为什么这条不是「换个说法」：r325 的输入是 c₁(CPⁿ)=(n+1)H、w₂=c₁ mod 2、以及 D-brane 带 spin^c（物理假设）；本卷的输入只有 q ∈ Q 与 nR ∈ Z。假设更弱而结论相同 ⇒ 判词用 ASSUMPTIONS-WEAKENED-SO-THE-RESULT-IS-STRENGTHENED。守卫 G17 给的是源码级证据：B 组代码剥掉注释后，chi_sheaf( / chern_cp( / todd_root( / ahat_A_ 的调用次数是 0。

图 3 · k 坐标把负半轴「折」回正半轴（以 n=3 为例）

左列 = k 从 −8 到 4，旁边是 nR(3,k) = χ(O(k)) 的值；右列 = M，旁边是 C(M,3)。虚线是折返：k ≥ 0 直着走（M = k+3），k < 0 镜像回去（M = −k−1）。所以 M=3 同时对应 k=−4（给 −1）与 k=0（给 +1）—— 同一个 M、两支符号相反。这就是「四个支点变两个」的全部机制。

图 4 · 四支点塌成两段：r327 的 x 切片 vs 本卷的 M 切片

上栏 = r327 在 x 轴上切四段（x<0 / 0≤x<n / x=n / x≥n+1）；下栏 = 本卷在 M 轴上只有两段（M<n 给 0 / M≥n 严格递增）。上栏的第 2、3 段在下栏被吸进「M<n ⇒ C=0」一句，第 1 段被折进「M≥n」。而解集不变（3 个）⇒ 这是简化而非修正。
本卷六处自伤（如实登记）：① E01 首版断言「M ≠ x 恒成立」—— 事实是 x=(n−1)/2 时相等（奇数 n 各一次）；② D11 首版拿 len(range(-60,61)) 和自身比（同义反复）；③ G17 首版带 or True（恒真守卫）；④ C01/C02 首版把「非零个数」当「全部点数」（64 里只有 16 个负，其余是零）；⑤ CTL5 首版「偏移改 (n+1)/2 ⇒ 格变」测不出东西（差整数 1，格不变）；⑥ G07 首版判 A_NONINT == 0（应为 == A_TOT）。
⑤ 的处理方式值得记：负对照失败时不要删掉它 —— 把失败升级成结论：(n−1)/2 与 (n+1)/2 给同一张格 ⇒ 决定格的只是偏移的模 1 类。这正好解释了为什么 r325 的「移位」只有 0 或 1/2 两种情形：不是物理只允许两种，是算术只看得见两种。
