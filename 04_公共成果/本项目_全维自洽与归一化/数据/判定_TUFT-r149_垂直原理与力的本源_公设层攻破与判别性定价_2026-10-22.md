## 4. 逐条裁定

### A1 · 名实之辩：自承「是定理不是假设」却列为第二公设　【FAIL】

**问**：垂直原理作为「第二公设」，有没有任何「公设」该有的内容？

**机读**：三条形态完全不同的曲线（螺旋 / 扭线 / 李萨如）上 T.N、N.B、T.B 最坏绝对值 1.110e-16；来料原文自承：正交性是微分几何定理，不是额外假设；正交解耦是四力可独立叠加、互不串扰的几何根基。

来料 §1.2 原文：**「正交性是微分几何定理，不是额外假设」** —— 它**自己承认**这不是假设。
机读验证：在三条形态**完全不同**的曲线上（圆柱螺旋 / 扭线 (t,t²,t³) / 李萨如 (cos t, sin 2t, t/2)），
|T·N|、|N·B|、|T·B| 的最坏值均为 **1.110e-16**（机器零）。
⇒ 正交性对**任意**正则曲线成立，不含任何关于螺旋的断言 ⇒ **零判别力、零信息**。
理由也很直白：B ≡ T×N 由叉乘定义自动垂直于 T 与 N；而 T·N = 0 来自 |T| = 1 ⇒ T·T' = 0。
**两步都是定义，没有一步是假设。** 一个自承为定理的命题被列为「第二公设」，其作为公设的信息含量为 **0**。
**靶自承**：本条与来料自述一致（attack16 判据④），不是外部强加的指控。

*控制组1：标准螺旋上正交性成立（正对照）；控制组2：kappa=0 处标架退化（负对照，证明检测有分辨力）*

### A2 · ★公设互斥：公设 1（|v|=c 类光）使 Frenet 标架无定义，公设 2 无法陈述　【FAIL】

**问**：垂直原理要用到 Frenet 标架 (T,N,B)。第一公设说空间点以光速走螺旋，这条世界线类光吗？

**机读**：号差(-,+,+,+)，ds^2/dt^2 = v^2 - c^2：v=c 时 0.000000e+00；v=0.5c 时 -6.740664e+16；v=1.001c 时 1.798409e+14

螺旋世界线 x^μ = (ct, R cos ωt, R sin ωt, h t)。取号差 **(-,+,+,+)**：
  ds² = -c²dt² + (R²ω² + h²)dt² = (v² - c²) dt²。
机读三档：v = 0.5c ⇒ ds²/dt² = **-6.740664e+16**（类时，< 0）；v = c ⇒ **0.000000e+00**（**类光，= 0**）；v = 1.001c ⇒ 1.798409e+14（类空，> 0）。
而第一公设恰恰要求 **|v| = c**（空间点以光速运动）⇒ **ds² ≡ 0** ⇒ **弧长 s ≡ 0**。
Frenet 标架必须**用弧长参数化**：T = dr/ds、N = (dT/ds)/κ。s 恒为 0 时 d/ds **无定义**，于是 T、N、B、κ、τ **全部无法构造**。
⇒ **公设 1（类光螺旋）杀死了公设 2（Frenet 垂直原理）的定义域**：垂直原理在最核心的那条世界线上**连陈述都写不出来**。
（这是本库 65 号卷 B5 的同一结论在 V9 线上的落地：v_total = c ⇒ ds ≡ 0 ⇒ Frenet 无定义。）

*控制组3：同一公式在 v<c 给负、v>c 给正 ⇒ 计算有分辨力，v=c 的 0 不是数值巧合*

### A3 · ★两难：4D 口径无定义 / 3D 口径有定义但零内容　【FAIL】

**问**：V9.11 用「3D 投影弧长」把垂直原理救回来，这个规避站得住吗？

**机读**：3D 投影弧长口径下（s_3D=|v|t=ct，与 t 只差常数）：kappa=0.5000000000、tau=0.5000000000；正交性最坏 0.000e+00 ⇒ 有定义但恒真

V9.11（第十七章）确实用「3D 投影弧长 + |v| = c 速度约束」把 Frenet 标架救了回来。机读该口径：κ = 0.5000000000、τ = 0.5000000000，正交性最坏 **0.000e+00**（机器零）—— **有定义了**。
**但这样一来内容就归零了**：3D 投影弧长 s_3D = |v|·t = c·t，与坐标时间 t **只差一个常数**，所以该口径下的 κ、τ 描述的是**空间投影曲线的形状**，而正交性（A1 已机读）对**任意**曲线恒成立。
⇒ **两难**：
  - 口径一（4D 时空弧长）：类光 ⇒ ds ≡ 0 ⇒ **无定义**；
  - 口径二（3D 投影弧长）：**有定义，但恒真、零判别力**（且不再是时空量）。
**没有任何一种口径让垂直原理既有定义又有内容。**

*控制组1：3D 投影口径下标准螺旋的 κ、τ 与教科书一致*

### B1 · §1.3 的 Frenet 方程组缺了第二式 dN/ds = -kappa T + tau B　【FAIL】

**问**：§1.3 列出的 Frenet–Serret 方程组完整吗？

**机读**：数值 dN/ds·T = -0.5000000000（理论 -kappa = -0.5000000000，相对误差 2.54e-11）；dN/ds·B = 0.5000000000（理论 +tau = 0.5000000000，相对误差 2.54e-11）

**不完整**。§1.3 只列了两式：dT/ds = κN、dB/ds = -τN。（来料自己在别处也注明「§1.3 只列两式，第三式由正交性补齐」—— 但那个「补齐」指的是 dB/ds，不是 dN/ds。）
**漏掉的正是第二式**：
  **dN/ds = -κ T + τ B**
机读验证（螺旋，中心差分）：dN/ds·T = **-0.5000000000** vs 理论 -κ = -0.5000000000（误差 2.54e-11）；dN/ds·B = **0.5000000000** vs 理论 +τ = 0.5000000000（误差 2.54e-11）。
⇒ 该式成立且被证实。**而这一式恰恰是全套 Frenet 方程里唯一同时含 κ 与 τ 的一式。**

*控制组5：完整 Frenet 三式（含 dN/ds）在标准螺旋上全部成立*

### B2 · ★「弯曲与扭转天然解耦」被漏掉的那一式否证　【FAIL】

**问**：§1.3 声称「弯曲动力学与扭转动力学天然解耦」，这成立吗？

**机读**：dN/ds 的 T 分量 = -0.5000000000（-kappa，非零）、B 分量 = 0.5000000000（+tau，非零）；两者比值 1.000000；均非零 = True

**不成立**。解耦与否要看**承载演化的那一式**——即 §1.3 漏掉的 dN/ds：
  **dN/ds = -κ T + τ B**
机读：T 方向分量 = **-0.5000000000**（= -κ，**非零**），B 方向分量 = **0.5000000000**（= +τ，**非零**）。
⇒ **N 的演化由 κ 与 τ 共同驱动**：弯曲与扭转在 N 方向上**耦合**，不是解耦。
若真解耦，两个分量应有一个恒为 0；实测两者比值 |τ/κ| = **1.000000**，都在同一量级。
⇒ 「天然解耦」这一论断建立在**一个缺了关键一式的方程组**上 —— **恰恰是漏掉的那一式承载了 κ 与 τ 的耦合项**。这是本卷最重要的一条新发现。

*控制组5：完整三式成立 ⇒ 耦合项不是数值噪声*

### B3 · ★自相矛盾：§9.5 用垂直原理解释主力解的力的方向，而主力解最大违反垂直原理　【FAIL】

**问**：§9.5 说垂直原理给出四力解耦的几何根由。全书主力解满足垂直原理吗？

**机读**：旗舰汤川解 tau=alpha*kappa ⇒ nabla tau = alpha*nabla kappa，梯度平行；四档 r 的 cos(theta) 绝对值 = 1.0000000000（要求垂直原理 cos=0）

**不满足，而且是最大程度违反。** 旗舰 L2 汤川解为 κ(r) = q e^{-μr}/r、**τ(r) = α κ(r)** ⇒
  ∇τ = α ∇κ ⇒ 两梯度**平行**，球对称下 cos θ = **+1**（垂直原理要求 cos θ = **0**）。
四档半径机读：cos θ 的绝对值恒为 **1.0000000000**。
**注意这里的结构性荒谬**：§9.5 声称「垂直原理给出四力解耦的几何根由」，并用它解释**力的方向**；可全书**主力解**恰恰是**最大程度违反**垂直原理的那一族（梯度完全平行）。
⇒ **用一个主力解违反的原理，去解释主力解的力的方向** —— 这是自相矛盾。
（V9 线自己在第十五章已判该 no-go，但**没有回头修订 §9.5 的力的方向论述** —— 本卷登记这个**跨章不一致**，不重判 no-go 本身。）

*控制组：V9.9 第十五章同结论（∇κ·∇τ = α|∇κ|² ≠ 0），本卷为独立复算*

⇒ **对照结论**：「同一个模板套四次」与「耦合常数在高能统一」是两种完全不同的「统一」，前者**不含任何可检验内容**。这是本卷对「力的本源」最硬的定价。

### D1 · 低阶算子枚举：修好垂直原理的唯一办法是删掉它　【FAIL】

**问**：对垂直原理施加 {KEEP, FLIP, DEL}，哪些能解除它与主力解的互斥？

**机读**：3 个算子：KEEP 保留（仍与主力解互斥/类光无定义）、FLIP 不构成约束、DEL 关闭但代价=2；存活 1 个，零代价 0 个

全枚举 3 个算子：
  - **KEEP**：保留 ⇒ 仍与主力解互斥（B3）、仍在类光世界线上无定义（A2）⇒ 不关闭；
  - **FLIP**：翻成「≠ 0」或「∥」⇒ **不等式不构成约束**，无法作为公设使用 ⇒ 不可行；
  - **DEL**：删去 ⇒ 关闭 B3 与 A2，但代价 **2 项** = 放弃公设 2 + 放弃 §9.5 的「解耦解释」。
⇒ **存活 1 个，且零代价的 0 个** —— 修好它的唯一办法是**把它删掉**，而删掉之后「四力为何解耦」就重新变成**无解释**。

*控制组：枚举流程有分辨力（既非 0 个也非全部存活）*

## 5. ★本卷两条最重要的新发现

### 5.1 漏掉的那一式，正是承载耦合的那一式

§1.3 只列了 dT/ds = κN 与 dB/ds = −τN，**缺了 dN/ds = −κ T + τ B**。
全套 Frenet 方程中**唯一**同时含 κ 与 τ 的，就是这一式。机读：
dN/ds·T = **-0.5000000000**（= −κ）、dN/ds·B = **0.5000000000**（= +τ），两者**均非零**。
⇒ **N 的演化由 κ 与 τ 共同驱动**，弯曲与扭转在 N 方向上**耦合**。
「天然解耦」这一论断建立在一个**残缺的方程组**上。

### 5.2 「同一个模板套四次」≠「耦合常数统一」

参数计数门 n_自由 ≤ n_观测 − 1：**TUFT 模板 8 ≤ 7？否**；**SU(5) 2 ≤ 2？是**。
前者能对**任意** (强度, 力程) 观测组零残差拟合（机读最坏 1.7e-16）⇒ 无交叉约束 ⇒ 不可证伪；
后者给出树级 sin²θ_W = 0.375000（实测 0.231210，偏离 62.19%）—— **这个偏离本身就是可检验信息**。
