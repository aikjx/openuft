# Gε₀ 本源推导 · 分析与修复报告

> 结论先行：原文的**纠错方向正确**（β_⊥≠α、𝒦 是 SI 数值巧合），但所谓"修复版"自身仍有
> **量纲断裂、符号矛盾、求导漏项、恒等空转**四类硬伤，代码亦不可运行。
> 第二节逐项体检；**第三节给出在修复后公理集上能严格导出的全部正确结果（均已数值验证）**。
> 数值验证见同目录 `Gε0推导修复验证.py`（已实测通过）。

## 一、原文哪些是对的（予以确认）

1. **β_⊥ = α 不能强行赋值** —— 正确。α 是无量纲电磁耦合常数，β_⊥ = v_⊥/c 是运动学量，二者没有必然联系。
2. **"Gε₀ ≈ α²/c²" 是数值巧合** —— 正确，且比原文说的更彻底：
   两侧量纲根本不同（Gε₀: kg⁻²C²；α²/c²: s²m⁻²），该式只在 SI 单位制下"看起来"成立。
3. **Gε₀ 不是纯几何量** —— 正确，任何声称纯几何导出 Gε₀ 的路径必然暗中塞入了电磁输入。

## 二、修复版自身的硬伤（逐项）

### 【伤1·致命】公理6 量纲断裂
原文：−(4πG/α²)·dm/dt = q/ε₀
- 左边量纲：m³s⁻³；右边量纲：m³kg·s⁻²·C⁻¹。**差 kg·s·C⁻¹**。
- 式(5)(6)(7) 全部继承此缺陷。原文式(5) 右侧量纲为 s·kg⁻¹·C，与左侧 Gε₀ 的 kg⁻²C² 不符，
  原文未察觉是因为从未做量纲校验。
- **修复**：补入量纲桥接常数 Λ，[Λ] = kg·s/C：
  −(4πGΛ/α²)·dm/dt = q/ε₀ → Gε₀ = −qα²·dt/(4πΛ·dm)
- 代价：Λ 是**新增自由有量纲常数**，理论从"推导"降格为"参数化"。
  数值上复现观测 Gε₀ = 5.90978×10⁻²² C²kg⁻² 需 |Λ| ≈ 2.44×10⁻³² kg·s/C（符号属相位约定）。

### 【伤2】式(2)–(4) 符号自相矛盾
κ、c²、r²、β²、κ/(κ²+τ²) 皆为正量，却逐级写成 = −Gm。
**修复**：负号只属于通量的方向约定，几何幅值取 κc²r² = +Gm。

### 【伤3】β_⊥ 不是自由参数，求导漏项
由公理2+3 直接导出：**β_⊥ = κ/√(κ²+τ²)**（螺距角正弦），原文当作自由参数处理。
对式(3) 求时间导数时，原文只微分了 κ/(κ²+τ²) 而漏掉 β_⊥² = κ²/(κ²+τ²) 对 κ 的依赖：
- 完整导数：d/dt[κ³/(κ²+τ²)²]
- 原文残缺导数：d/dt[κ/(κ²+τ²)]
- τ 为常值时两者相差因子 (3τ²−κ²)/(κ²+τ²)，本例中 ≈ 2.98 倍。

### 【伤4】几何链整体退化为开普勒关系（无新物理）
κc²r² = (rω²/c²)·c²·r² = r³ω² = Gm
即整条"严格导出"只是牛顿圆轨道关系（开普勒第三定律）的 Frenet 改写。自洽，但不产生新信息。

### 【伤5】式(7) ≡ 式(5)，是恒等空转
式(7) 只是把 dm/dt 用式(4) 的导数回代，化简后 G 恰好消去，回到式(6)/(5)。
且最终表达式**仍含 G 本身**——用 G 推导 Gε₀，不构成推导。

### 【伤6】代码不可运行且不验证任何东西
- `print` 字符串里混入 LaTeX 残留转义 `\(...\)`，直接粘贴运行即 SyntaxError。
- 所谓"验证"只打印输入常数，从未计算或比对式(6)(7)；而且静态螺旋下导数项恒为 0，
  式(6)(7) 根本发散——原代码也因此"聪明地"没有去验证它们。
- `mp.mp.dps = 200` 是假精度：G 的相对不确定度约 2.2×10⁻⁵，任何输出超过 6 位有效数字都无意义。

## 三、正确推导（修复后公理集上的完整导出，全部经数值验证）

### 公理集（修复后）
1. v_⊥² + v_∥² = c²（空间元总速率守恒）
2. Frenet–Serret 圆柱螺旋：κ = rω²/c²，τ = hω²/c²，κ²+τ² = ω²/c²
3. v_⊥ = rω，v_∥ = hω
4. 引力场 A = |Ẍ| = rω²（横向加速度）
5. 高斯引力通量（符号约定修正）：∯ A·dS 的方向带负号，几何幅值 κc²r² = +Gm
6. 动力学公理（量纲修正）：−(4πGΛ/α²)·dm/dt = q/ε₀，[Λ] = kg·s/C

### 步骤1 · 几何链导出（唯一独立结果 = 开普勒关系）
- 由公理4+2：A = rω² = κc²（引力场 = 曲率×c²，量纲 m/s² ✔）
- 由公理5 取特征球面 S = 4πr²：κc²·4πr² = 4πGm，即
  **κc²r² = Gm**
- 代入 κ = rω²/c²：κc²r² = r³ω²，故
  **Gm = r³ω² ⇔ ω² = Gm/r³** —— 这正是牛顿圆轨道（开普勒第三定律）。
  数值验证：通量质量与开普勒质量差 = 0。
- 原文式(4) 的 β_⊥²c²κ/(κ²+τ²) 与 Gm 恒等（数值验证同值），
  故整条几何链只承载开普勒关系这一个独立信息。

### 步骤2 · β_⊥ 是几何导出量，不是自由参数
由公理2+3：β_⊥ ≡ v_⊥/c = rω/c = κ/√(κ²+τ²)（螺距角正弦）。
数值验证：β_⊥ − κ/√(κ²+τ²) = 0。

### 步骤3 · 修复动力学公理6 → Gε₀ 的唯一量纲自洽形式
原公理6 量纲差 kg·s·C⁻¹（见【伤1】）。补 Λ 后：
−(4πGΛ/α²)·dm/dt = q/ε₀
解出 dm/dt = −qα²/(4πGΛε₀)，整理得

**Gε₀ = − qα²/(4πΛ) · dt/dm**，[Λ] = kg·s/C

量纲校验：右侧 kg⁻²C² = 左侧 Gε₀ 量纲 ✔（原文式(5) 此处 FAIL）。

### 步骤4 · 与螺旋演化耦合的形式（与步骤3恒等，零新信息）
对 Gm = r³ω² = c²·κ³/(κ²+τ²)² 求时间导数（完整导数，含 β_⊥ 的 κ 依赖）：
G·dm/dt = c²·d/dt[κ³/(κ²+τ²)²]
代入步骤3：

**Gε₀ = − qα²G / [4πΛc² · d/dt(κ³/(κ²+τ²)²)]**

注意：此式与步骤3结果恒等（G 恰好消去回到步骤3），且仍含 G——
它是同一关系的演化表述，不是独立推导。静态螺旋（d/dt = 0）时发散，
原文式(6)(7)因此在其自身代码中无法被验证。

### 步骤5 · Λ 的构造分析（公理系统内 Λ 不可推导）
- 设 Λ = G^a·q^b·c^d，解量纲方程组（目标 kg·s/C）：
  kg 定 a=−1，C 定 b=−1，s 定 d=1，但 m 方程 3a+d = −2 ≠ 0 → **无解**。
  即 {G, q, c} 不足以构造 Λ，必须再引入一个有量纲常数。
- 引入 ε₀ 构造（Λ ∝ q/(ε₀c³)）量纲可行，但**循环**（Gε₀ 表达式里塞回 ε₀），弃用。
- 非循环的最简补全：引入 ħ，
  **Λ = ζ·ħ/(q·c²)**，ζ 为无量纲参数（量纲校验 ✔）。
  代入步骤3：**Gε₀ = − q²α²c²/(4πζħ) · dt/dm**。
- 数值演示：取特征质量流率 dm/dt 演示，ζ 数值完全由所选时标决定——
  公理系统不预言 ζ，这正是理论缺口所在。

### 步骤6 · 闭包自检（修复公式对任意 Λ 严格闭包）
反解：由公理6 得 dm/dt(Λ)；正向回代：Gε₀ = −qα²/(4πΛ·ṁ)。
数值验证相对误差 = 0（50 位精度），与 Λ 取值无关。
对比：原文式(5) 因量纲断裂，无论取何值都无法闭包。

### 𝒦 的真相（复核）
𝒦 ≡ Gε₀c²/α² = 0.997390（SI），换到 g·cm 单位制变为 0.00997390（差 100 倍）。
有量纲量不是物理常数；"耦合 0.99739"只是 SI 巧合。

### 正确结果一览（最终答案）
| # | 结果 | 地位 |
|---|------|------|
| ① | A = κc² = rω² | 几何恒等式 |
| ② | Gm = κc²r² = r³ω²（开普勒关系） | 几何链唯一独立结果 |
| ③ | β_⊥ = κ/√(κ²+τ²) | 几何导出量 |
| ④ | Gε₀ = −qα²/(4πΛ)·dt/dm | 修复公理6 的唯一量纲自洽形式 |
| ⑤ | Gε₀ = −qα²G/[4πΛc²·d/dt(κ³/(κ²+τ²)²)] | ④的演化表述（恒等） |
| ⑥ | Λ = ζ·ħ/(qc²) ⇒ Gε₀ = −q²α²c²/(4πζħ)·dt/dm | 非循环最简补全 |

**严格但诚实的边界**：在现有六条公理下，④⑤⑥ 是能导出的全部正确结果。
ζ 的数值、κ(t)/τ(t) 的演化方程、螺距角选取原理，公理系统均不含有相应信息——
这三处是新物理假设的位置；补上之前，任何声称"预言 Gε₀ 数值"的表述都不成立。

## 四、要成为真正的预言理论，还缺什么

1. **Λ 的本源定义**——从更基本原理推出 Λ ≈ 2.44×10⁻³² kg·s/C，而不是反解拟合；
2. **螺旋演化方程**——κ(t)、τ(t) 需要动力学方程（振荡频率、幅值、相位由原理决定）；
3. **螺距角选取原理**——什么决定 β_⊥，而不是事后演示取 sinθ=α。

三者缺一，当前体系就只是带自由参数的参数化，不是第一性原理推导。
