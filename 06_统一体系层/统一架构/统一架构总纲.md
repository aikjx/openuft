# UAF 统一架构总纲

[统一体系层](../README.md) · [体系坐标系](../体系坐标系/README.md) · [关系图谱](../关系体系图/README.md)

## 1. 为什么是八层

任何统一场论研究，无论本体如何，要成为可审查的对象，都必须回答同一组问题。把这组问题固定下来，就得到一套与具体理论无关的骨架。称为 **UAF（Unified Architecture Framework，统一架构框架）**。

UAF 的作用是让不同体系**在同一组问题上逐层对照**，而不是让它们在同一套公式下互相翻译。

## 2. 八层骨架

| 层 | 名称 | 该层必须回答的问题 | 常见取值举例 |
|---|---|---|---|
| **L1** | 本体层 | 世界最终由什么构成？ | 空间自身运动、离散几何元胞、0/1 对偶基元、信息场、频率振动、时空挠率 |
| **L2** | 几何层 | 用什么几何结构承载？ | Frenet–Serret (κ,τ)、复曲率 Ξ=κ+iτ、主丛 (P,G)、因果集、离散元胞、Clifford 丛 |
| **L3** | 代数层 | 内禀对称性是什么？ | U(1)×SU(2)×SU(3)、Cl(4,4)、SO(3)、SU(3) 根系 A₂、E₈、ℤ₄ |
| **L4** | 动力学层 | 作用量与场方程是什么？ | S=∫√−g[R/2κ−¼F²−¼W²−¼G²+…]、六方程闭环 M1–M6、代数比关系 |
| **L5** | 物质层 | 费米子代数与质量谱如何出现？ | 三代、SO(3) 本征方向、拓扑荷量子数、Koide 关系 |
| **L6** | 破缺层 | 对称性如何破缺、在哪个能标？ | 真空约束 \|Ψ\|²=v²、手征锁定、能标 Λ |
| **L7** | 可观测量层 | 承诺了哪些可检验预测？ | 精细结构常数、质量比、QNM 谱与回波、CMB B 模手性、电子 EDM |
| **L8** | 验证层 | 证据处于什么等级？ | conjecture、numerical_check、mathematical_result、observational_support、falsified |

## 3. 三条定理

**T1（本体隔离）**：若两体系 L1 不同，则 L2–L7 的任意相似都不能转移证据。

这是 [WORKFLOW](../../00_项目治理/WORKFLOW.md)"按论证的原始假设归属"原则在八层语言下的重述。典型误用：s01 的螺旋三重奏恒等式 κ²+τ²=(ω/v)² 是数学结果，s10/s12 借用该形式后，不能反过来用 s01 的数学地位为 s10/s12 的本体主张背书。

**T2（可公度判据）**：两体系可公度，当且仅当存在 L1→L7 的保结构映射，且 L8 的证据可独立复核。

据此，s07/s08/s09 与 s03 之间是可公度的版本演进（同一 L1，L4/L5/L6 逐版改），而 s13 与 s14 之间**不可公度**（L1 互斥），只能并列比较。

**T3（实现中立）**：L8 的证据等级只由该体系的推导、计算与观测记录决定，与其实现方式的数量、代码行数、书稿篇幅、图谱美观度无关。

## 4. 用八层读一个体系：示例

以 [S14 挠率统一场论 TUFT](../../01_独立体系/S14_挠率统一场论TUFT/README.md) 为例：

- L1 本体：时空光速螺旋形变，一切结构为其表现
- L2 几何：曲率 K 与挠率 T 两分量，主丛结构群 SO(1,3)×U(1)×SU(2)×SU(3)
- L3 代数：挠率内禀子代数 U(1)/SU(2)/SU(3)
- L4 动力学：S=∫√−g[R/2κ−¼F²−¼W²−¼G²+ψ̄(iγD−m)ψ+L_Ω]
- L5 物质：挠率表示论给出代结构
- L6 破缺：几何权重场 Ω 的势能 V(Ω)=V₀Ω(1−Ω)
- L7 可观测量：sin²θ_W、M_GUT 汇聚、CMB 手性 B 模、黑洞 QNM 回波
- L8 验证：**多项已登记 falsified**（见其 claims.csv），不可引用为支持证据

八层读法暴露出：S14 在 L4 有明确作用量，但 L5 的"从挠率导出代结构"已被判定为标准模型表示论重述（S14-C0001，falsified）。这正是统一层的价值——它让缺陷在固定位置显形。

## 5. 八层与全生命周期的关系

`01_独立体系` 的各体系按 [17 个研究阶段](../../00_项目治理/WORKFLOW.md)（00_研究立项 … 15_版本发布）组织文件；UAF 八层是**横向的描述坐标**，与 17 个阶段正交：

- 阶段回答"研究进行到哪一步"
- 八层回答"这个理论在每组问题上主张什么"

两者不能互换。阶段完备不等于八层完备（多数体系 L6/L7 为空），八层填满也不等于阶段审查通过。
