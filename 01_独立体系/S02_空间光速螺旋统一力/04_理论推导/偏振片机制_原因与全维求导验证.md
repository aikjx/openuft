# 偏振片：作用原因 · 全维求导 · 验证计算

> 接《光速螺旋_超光速与偏振辨析》。红线：偏振机制是电动力学标准结论（各向异性介质 + 矢量投影），非框架独有；框架「空间光速螺旋」指光子空间轨迹的几何模型，偏振片作用于电场矢量，两者层级不同，偏振片不能验证空间轨迹假设。

## 0. 结论速览

- 偏振片的**原因**是介质对电场方向的**各向异性响应**：沿吸收轴的 E 分量被阻尼吸收，垂直分量透过。数学上是各向异性介电/电导张量只允许一个本征偏振无衰减传播。
- 对任一场做投影 → 输出强度服从**马吕斯定律** `I = I0 cos²θ`；圆偏振过偏振片塌缩为线偏振且强度减半（即「螺旋 → 直线」）。
- 偏振片作用对象是**电场矢量**（及其螺旋/圆轨迹），不是光子空间轨迹。

## 1. 物理原因（cause 链）

1. 偏振材料内部存在择优方向：二色性分子长轴、金属栅线、或双折射晶轴，使介电张量 / 电导张量各向异性 `ε ≈ diag(ε_∥, ε_⊥)`、`σ ≈ diag(σ_∥, σ_⊥)`。
2. 沿吸收轴（长轴）的 E 分量驱动束缚电子沿链振荡 → 电阻 / 辐射阻尼把电磁能耗散为热（`σ_∥` 大 ⇒ 衰减常数大）；垂直分量无长链振荡通道 → 低耗散透过。
3. 净透射场 = 入射场在透过轴上的**投影**，故输出为线偏振。
4. 布儒斯特角型：在 `θ_B` 处反射光为纯 **s 偏振**（垂直入射面）——因 p 分量对应介质偶极沿反射方向辐射为零（此时反射光与折射光垂直，p 偶极辐射方向因子为零）。

## 2. 求导证明：马吕斯定律

设入射为线偏振光，振幅 `E0`，偏振方向与透光轴夹角 `θ`。电场分解：

```text
E_parallel = E0 cos θ     （沿透光轴，透过）
E_perp    = E0 sin θ     （垂直透光轴，被吸收）
```

光强 `I ∝ ⟨|E|²⟩`（对时间平均），只有平行分量抵达输出端：

```text
I = I0 cos²θ                                  … 马吕斯定律（证毕）
```

**Jones 投影形式**（对任意偏振态通用）：偏振片即投影算符 `P = |â⟩⟨â|`，

```text
E_out = P · E_in ,      I_out = |⟨â|E_in⟩|²
```

## 3. 与螺旋模型的对接（圆偏振 → 线偏振 = 螺旋 → 直线）

圆偏振电场：

```text
E(t) = E0 [ cos(ωt) x̂ + sin(ωt) ŷ ]
```

其矢量尖端在横截面画圆；叠加上传播方向 `z` 即在时空描出**螺旋**（即框架「螺旋」的场论对应）。投影到透光轴 `â = cosφ x̂ + sinφ ŷ`：

```text
E_proj(t) = E(t)·â
          = E0 [ cos(ωt)cosφ + sin(ωt)sinφ ]
          = E0 cos(ωt − φ)
```

⇒ 振幅 `E0`、相位偏移 `φ` 的**线偏振**振荡。证毕：偏振片把「螺旋」投影退化为「直线」。

强度：`<E_proj²> = E0²/2`，与未偏振、圆偏振经偏振片后的时间平均一致。

## 4. 验证计算

- **马吕斯**：`θ=0° → I=I0`；`θ=45° → I0/2`；`θ=90° → 0`。
- **圆偏振过 x 轴偏振片（Jones）**：输入 `(1/√2)[1, i]^T`，`P = diag(1,0)` → `(1/√2)[1, 0]^T`（线偏振 x），`I_out = I0/2`。
- **非偏振光**：`θ` 均匀时 `<cos²θ> = 1/2` → `I = I0/2`（自然光减半的根本原因）。

## 5. 诚实边界（红线）

- 偏振机制是电动力学标准结论（各向异性介质 + 矢量投影），并非框架独有发现。
- 框架「空间光速螺旋」（光子空间轨迹）与偏振（场矢量）是**不同层级**，偏振片不能验证空间轨迹假设。
- 本分析不扩展框架边界（S02-A4：三重奏非万有理论，不解释引力、不生成常数、不完成四力统一）。
