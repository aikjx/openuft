==========================================================================
  B1 · 母螺旋子螺旋投影算子 · 符号变分求导 (结构的本源)
==========================================================================
  母螺旋点 (κ̃,τ̃)=(cosφ,sinφ) on 单位圆 κ̃²+τ̃²=1
  子螺旋投影算子 P_nq(φ)=√[ mean_k (cos(φ-kθ_k))² ], θ_k=k·π/(2·n_q)
  净相干投影 = √(Σ_k cos²(φ-kθ_k)/n_q), 这是子螺旋对母螺旋的'几何投影读值'
  P_nq(φ) 数值扫描 (φ=0..π/2, 200点):
    极大值 φ*=0.335·π, P_nq(φ*)=0.912861
    极小值 φ*=0.005·π, P_nq(φ*)=0.585221

  [本源判定] 子螺旋投影算子的极值不落在任何'特殊结构点'(非 1/n_q, 非 1/(1+n_q))
    => τ_int 无'从母螺旋投影极值'导出的唯一第一性原理值
    => τ_int 仍是'单位圆等分节点投影比'的结构假设, 三种口径均合法:
     1/n_q=0.333   -> sin²θ_W_geo=0.25, 偏差 8.2% (最接近实验)
     1/(1+n_q)=0.25 -> sin²θ_W_geo=0.2, 偏差 13.0% (50号口径)
     sin(π/9)=0.342  -> sin²θ_W_geo=0.25485, 偏差 10.0% (48/49号口径)
  [诚实收口] τ_int 无公理唯一派生; 本号确认'接近实验'≠'本源唯一', 51号裁决维持

==========================================================================
  B2 · α_S 精确 RG 积分闭合 (推进 52号'量级论证' → 数值积分, 对齐54号分段法)

  QCD 1-loop β 函数: β(α_S) = -b0·α_S²/(4π), b0=(33-2n_f)/3 (分阈)

    口径 sin(π/9)=0.342: α_S(裸)=1.026, μ_geo(占位: 2GeV处α已≥裸值, 需反向低能扫描, 非有效RG尺度)
  [注] 仅 50号口径(0.75<1.0)往高能精确得 μ_geo=3.43 GeV; 另两口径裸值≥1.0, 循环仅正向(高能)扫描,
       其 μ_geo 为'2GeV处α已≥裸值'的占位(已不在常数表作为有效RG尺度), 精确低能定位需反向扫描(非本号重点, B1已证三口径并存)

  [对齐54号] 50号口径 τ_int=0.25: μ_geo=3.429 GeV (与54号 3.43 GeV 一致 ✓)
  反向验证: 令几何裸值位于 μ0=M_Planck=1.22e+19 GeV, 精确积分到 2GeV:
    口径 1/n_q=0.333: α_S(2GeV)=-0.01305 (RG 跑入非物理负耦合区)
    口径 1/(1+n_q)=0.25: α_S(2GeV)=-0.0131 (RG 跑入非物理负耦合区)

    => 剩余开放项: 2-loop/全阶 RG 修正 + 几何裸值 0.75 的 2-loop 微调 (非'不可闭合')
