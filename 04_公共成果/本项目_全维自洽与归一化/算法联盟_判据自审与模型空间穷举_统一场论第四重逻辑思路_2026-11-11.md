## 一、本轮换的是什么思路

前三轮依次做了：46 项实验锚的全链路审计 → 10 类机制类型的两遍迭代 → `p_exp` 加留一法加实验存活层。它们都在**找候选**：更多来料、更多机制、更严的实验门。三轮的结论一次比一次精确，但都是同一个动作。

本轮换到**元层级**：把前三轮的**判据本身**当作审查对象，问三个此前没问过的问题。

| 编号 | 新逻辑思路 | 问的是什么 |
| --- | --- | --- |
| M1 | 判据相容性穷举 | 三重门在逻辑上相不相容？有没有满足构型？满足构型里有没有不该被放行的？ |
| M2 | 描述压缩增益（MDL 有限影子） | 统一是否真的压缩了描述，还是只把标准模型换个写法？ |
| M3 | 「统一」谓词自指反噬 | 判据用到「统一」这个词本身时，它是不是一个装饰谓词？ |

这三个问题的共同点：**不需要任何新实验数据，也不需要新物理假设**，只需要把已有的判定结构当对象重算。这正是「新的逻辑思路」能推进的地方。

## 三、M1：三重门逻辑相容，但不完备

构造一个 6 维离散的**逻辑模型空间**（不是物理理论全集，是逻辑影子，标 `BOUNDARY`）：

| 维度 | 取值 | 含义 |
| --- | --- | --- |
| `p_free` | 0 / 1 / 2 | 可调自由度账 |
| `lto` | 0 / 1 | 留一法是否通过（非回述） |
| `obs_type` | two-sided / lower / upper / identity | 观测量类型 |
| `survive` | 0 / 1 | 是否通过实验存活层 |
| `power` | 0 / 1 | 该实验对该候选是否有判别力 |
| `axiom_injected` | 0 / 1 | 陈述是否由注入假设直接给出 |

共 `3×2×4×2×2×2 = 192` 个构型。两条一致性约束（恒等式构型必须 `power=0, survive=1, lto=0`；`axiom_injected=1` 必须 `p_free≥1`）剔掉 67 个自相矛盾构型，剩 **125 个一致模型**。

在这 125 个上重跑第三轮三重门 `C1 ∧ C2 ∧ C3`，命中 **3 个**。所以第一结论是：

> **三重门在逻辑上相容。** 攻破不是逻辑矛盾，第三轮那句「还没找到更好的方程」并不等于「永远不可能」。缺口在别处。

但第二结论更重要：这 3 个命中构型里，**2 个是单侧型**（`lower` 与 `upper`），即 `p_free=0, lto=1, survive=1, power=1` 的下界／上界候选。第三轮的 C3 只要求「存活 + 判别力 + 非恒等式」，**没有要求观测量是双侧的**。于是三重门会把「尚未被下界排除」或「落在上界之内」误当成阳性证据。

> **三重门不完备：存在判据逃逸构型。**

## 四、漏洞不是假想的：现候选里就有实例

第三轮 K09（MSSM dim6 质子寿命 `2.78656E+36 yr`，高于 Super-K 下限）的实际读数是：`C2 = True`、`C3 = True`、`is_identity = False`、`obs_type = lower`，只因 `p_free = 1`（注入维度六算符假设）挂了 C1 才没被放行。

把它的 `p_free` 改成 0，第三轮判据就会判它突破。也就是说第三轮突破 0 次**有一部分是运气**：靠的是那条候选恰好带了可自由选择的假设，而不是判据把它挡住了。第三轮 C3 为真的候选共 2 条（K05 回述对照、K09），前者靠 C2 挡、后者靠 C1 挡，两道门都是「恰好」而不是「必然」。

这类「靠具体候选的属性侥幸挡住、判据本身留了口子」的情形，是审计链里最该修的东西。

## 五、C4：补上第四道门

本轮新增 **C4 双侧阳性证据门**：`obs_type == two-sided`。理由是第三轮自己已经证明的口径——下界／上界型实验只给单侧，「存活」只意味尚未排除，不构成阳性证据；双侧带误差棒的观测量才同时存在判负与判正的读数。

`突破 = C1 ∧ C2 ∧ C3 ∧ C4`。

补门后：

- 满足构型从 **3 降到 1**，且唯一剩下的构型是 `two-sided`；
- 两个单侧逃逸构型被封住；
- **最小满足模型的必要结构**被机算出来：`p_free=[0]`、`lto=[1]`、`obs_type=[two-sided]`、`survive=[1]`、`power=[1]`。

这把第三轮用自然语言写下的 OPEN 出口（构造一条带双侧误差棒、理论值落在其可判负区间之外的新实验读数）**形式化成了可机算的必要条件**。这是本轮最实在的增量：出口从一句话变成了一个五元组。

把第三轮 10 条候选映射进模型空间重算：三重门命中 0 条、四重门命中 0 条 ⇒ **升级判据不改变任何既有判决**，只堵住了未来的假阳性。

## 六、一个需要修正的直觉：双侧观测量并不缺

回读 46 项实测锚，其中带非零 sigma 的双侧型读数有 **27 项**（α_s、sin²θ_W、M_W、M_Z、m_top、H₀ 各口径等）。所以缺的**不是双侧观测量本身**。

缺的是：一条**由理论给出确定值、非回述、零可调参数、且恰好落在这 27 项里某一项置信区间内**的数值陈述。第三轮 10 条候选的双侧型全部被卡方排除，剩下的存活项全是回述／恒等式／单侧。这个区分把第三轮出口收窄了很多：**不必等新实验，先把现有 27 项双侧锚与理论候选做穷举配对**。

## 七、M2：描述压缩增益为零

统一若只是把标准模型与广义相对论换个写法，它没有压缩任何东西。本册用 MDL 的**有限可算影子**（Kolmogorov 复杂度不可计算，标 `BOUNDARY`，这里只算参数账和陈述账）：

`n_in = p_free + p_exp`，`n_out` = 非回述、非恒等式的数值陈述数，`gain = n_out − n_in`。

- **原始增益**：只数陈述，`>0` 的候选 **1 条**（K01 纯群论 `3/8`，`n_in=0, n_out=1`）。看似压缩了描述。
- **有效增益**：只认通过实验存活层的陈述，`>0` 的候选 **0 条**，最大有效增益 **0**。K01 被 `χ²=1.337976E+7` 排除，压缩出来的那条陈述是错的。

> 目前的「统一」只是重述写法，没有压缩出任何经得起检验的新陈述。

有意思的是模型空间层：最小满足模型的描述增益是 **+1** ⇒ **逻辑上统一是可以压缩描述的**，前提仍是必须消费一个双侧观测量。所以「参数不灭」不是逻辑定律，是当前来料的结构性结果。

## 八、M3：把判据用到「统一」这个词自己身上

`unifies(m)` 若对模型扰动不敏感、或恒真、或由公理直接注入，它本身就是个装饰谓词。机算四组读数：

| 配置 | 四重门命中数 |
| --- | --- |
| 基准 | 1 |
| 全部模型 `p_free + 1` | 0 |
| 全部模型 `lto` 置 1 | 2 |
| 全部模型 `power` 置 0 | 0 |
| `unifies := True` | 125 |

三路扰动都与基准不同 ⇒ 谓词有判别力；恒真配置凭空造出 **125 个假突破**（真实 1 个）⇒ 「统一」不能是恒真装饰。这与前三册反复强调的「守卫 ok 禁写死」「一个 100% 通过的谓词判别力为 0」是同一条纪律，只是第一次用在了「统一」这个谓词本身。

## 十一、诚实边界

- 192 个构型是 6 维离散属性的**逻辑影子**，不是物理理论全集。本册结论只对这 6 维抽象层全称成立；扩维（例如加入「拟合／非拟合」「多观测量联合」「相关误差」）可能检出新的逃逸构型，对此保持开放，标 `BOUNDARY`。
- MDL 用的是可算的参数／陈述账，不是 Kolmogorov 复杂度；后者不可计算（第二轮外部锚），本册不冒充证明。
- 四重门比三重门严，但**不保证完备**。它只是把本轮在 6 维空间里能看见的口子堵上。任何「判据已经封闭」的宣告都超出本册可算范围。
- 数学自洽 ≠ 实验证实；本册只产元逻辑层的可算判决，不产新物理。四力 2/6、四力大统一 0 条正确解、独立实验预言 0，**不宣称攻破统一场论**。
