## 2. 【坍缩 #2】核心发现：`G_eff` 被原稿**自身**的关系抵消

原稿同时给出两条：
- (R1) `ρ_c = c⁴τ₀²/(8πG)` ⇔ `τ₀² = 8πGρ_c/c⁴`（"临界密度就是背景挠率的等效能量密度"）
- 升级版 `G_eff/G = 1 + α·c⁴τ₀(x)²/(8πGρ_c)`

**把 (R1) 代回 `G_eff`**（实跑）：
```
由 (R1) 反解：ρ_c = 3.6765e-47 GeV^4  =>  τ0 = 2.4898e-42 GeV
α=0.01  ->  G_eff/G = 1.0100000000  （= 1+α = 1.0100000000）
α=0.10  ->  G_eff/G = 1.1000000000  （= 1+α = 1.1000000000）
α=1.00  ->  G_eff/G = 2.0000000000  （= 1+α = 2.0000000000）
```
> ⇒ **`G_eff/G ≡ 1+α`，与 `x` 无关**。原稿的「唯一新物理」（`G_eff` 空间变化）**被它自己的定义消掉了**。
> ⇒ 模型 `≡ GR + 常数重整化 G→G(1+α)`。因 `G` 由实验测量，`α` **不可分离** ⇒ **局域不可观测**（撞**定理 D**重参数化）。

**且更根本**：(R1) 与「`τ₀(x)` 空间变化」**互不相容**——(R1) 蕴含 `ρ_c` 随 `x` 变，而 `ρ_c` 是**观测到的全局常数**。二者只能择一：
- 取 `τ₀ = const` ⇒ `G_eff = const` ⇒ 无新物理；
- 取 `τ₀(x)` ⇒ (R1) 失效 ⇒ 需**另一条**独立关系定义 `ρ_c`（原稿未给）。

## 3. 【公理不相容】A1（EC 挠率基底）与 A2/A3（耦合到 `ρ`）冲突

**事实**：在**爱因斯坦–嘉唐**理论中，挠率是**代数（非传播）**场，由**自旋密度** `s^λ_μν` 决定：
`T^λ_μν ∝ κ s^λ_μν`。⇒ **无自旋物质（尘埃、理想流体、辐射）⇒ `τ ≡ 0`**。

**实跑检查**：
```
理想流体/尘埃（ρ 的来源）   自旋密度=0.0  ->  EC 挠率 = 0.0
辐射                        自旋密度=0.0  ->  EC 挠率 = 0.0
极化费米子（自旋对齐）       自旋密度=1.0  ->  EC 挠率 = 1.0
```
> ⇒ 原稿把 `τ₀` 耦合到**能量密度 `ρ`** ⇒ **无 EC 依据**。
> ⇒ 「锚定爱因斯坦–嘉唐挠率几何基底」是**形式装饰**：真实动力学 = **GR + 一个标量场**（dilaton，其"挠率"只是命名），属**标量–张量类**理论。
> ⇒ **A1 与 A2/A3 不相容**——若忠于 EC，则 `τ₀ ≡ 0`，主方程 (2) 的第二项消失；若保留第二项，则必须放弃「EC 挠率」这一名号。

## 4. 【精细调节搬家】`τ₀` 的量级与层级（未解决 Λ 问题）

由 (R1) 与观测 `ρ_c` 反解 `τ₀`（**SI 与自然单位两路交叉核对，一致**）：
```
SI 路径：τ0 = 1.2618e-26 m^-1  ->  2.4898e-42 GeV
自然单位：τ0 = 2.4898e-42 GeV
τ0/M_Pl        = 2.039e-61
ρ_c/M_Pl^4     = 1.655e-123
τ0²/M_Pl²      = 4.159e-122
两者之比 = 1/(8π) = 0.0398  ⇒  同一个精细调节
```
> ⇒ **`ρ_c/M_Pl⁴ = (τ₀/M_Pl)²/(8π)`**：Λ 的 **~123 量级**调节与 `τ₀` 的 **~122 量级**调节是**同一个**调节。

## 5. 【局域无新物理】「还原牛顿引力」靠**删掉新项**


> ⇒ 「局域自动还原 GR/牛顿」**成立**，但机制是 **`δ→0`（新项消失）**。
