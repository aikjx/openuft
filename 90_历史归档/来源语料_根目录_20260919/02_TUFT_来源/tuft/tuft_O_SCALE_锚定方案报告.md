# TUFT-O-SCALE 外部锚定方案设计（秩检验 · method_F 精算报告）

> 对象：R3/R4 遗留的开放项 **O-SCALE**（尺度简并 `k²L³ = C`）
> 方法：把「能否打破简并」形式化为**约束雅可比秩检验**，并按 `method_F`（无量化判据 / 循环检测 / 双锚点检验 / 自由度审计）逐项判定 7 类锚定方案
> 脚本：`tuft_O_SCALE_锚定方案设计.py` → `tuft_O_SCALE_锚定方案_report.txt`
> 结果：**PASS 7 · FAIL 1 · BOUNDARY 1 · INFO 4**

**红线**：数学自洽 ≠ 物理证实。本报告只做量纲/秩/约定的诚实分析，不主张 TUFT 物理真实性。

---

## 一、问题：简并的形式化

R3/R4 已证：纯几何孤子的能量守恒约束

```
E_tot = 4π α k² L³ J = E_electron       ⇒      F1(k, L) = k² L³ − C = 0,   C = 2.6189e−21
```

**未知量 (k, L) = 2 个，独立约束 = 1 个 ⇒ 残留 1 个自由参数**：绝对尺度 `L` 不可由方程自定。

---

## 二、秩检验（本轮方法升级）

用 sympy 对约束求**数值雅可比秩**：

```
rank(∂F1/∂k, ∂F1/∂L) = 1        [PASS]
```

⇒ 解流形为 **1 维**，与自由度审计一致。
⇒ **打破简并的充要条件**：追加 1 条与 F1 **独立**的关系（使 `rank: 1 → 2`）。

这把 R3/R4 的定性讨论升级为**可判定的秩检验**——「是否有效」不再靠叙述，而看秩是否提升。

## 五、最小锚定定理（O-SCALE 的可判定结论）

> **定理**：在 TUFT 纯几何孤子体系内，约束 `F1(k,L)=k²L³−C=0` 的雅可比秩**恒为 1**，
> 故绝对尺度 `L` 是 1 维解流形方向；**仅凭 TUFT 方程无法锁定 L**。
> 打破简并 ⇔ 追加 1 条与 F1 独立的关系（`rank 1→2`）。

**推论 1**：该独立关系必须**来自 TUFT 外部**（额外观测量或额外约定）：
- 来自约定（A5 `kL=2πn` / A7 `kL=α`）→ **亚普朗克** `L`（非物理）；
- 来自额外观测量（A6 `H₀`）→ 成立但给出**宏观 `L≈9.3 cm`**（动机待释）；
- 来自公理 II（A2 `κ_e`）→ `L≈1.4e8 l_P`，**唯一「半内」方案**，但复用 `m_e` + 依赖峰值约定（`L∝s^{−2/3}`）。

**推论 2**：A4 证明**不能同时要求「康普顿尺度」与「电子高曲率」**——偏离 `1.131e+45` 倍
（等价于能量守恒被破坏 `1.1e45` 倍）。这与 R3 的"三角冲突"同源，此处给出了**秩视角的精确表述**。

**推论 3**：与 **openuft M02（普朗克锚定谬误）同构** —— 纯几何/量纲方程无尺度锚，自然锁定普朗克尺度；
电子的绝对尺度/质量是**第一性不可导出**的（须外部锚定），这是诚实边界，**非证伪宣告**。

## 七、结论

1. **简并秩 = 1**，绝对尺度 `L` **不可由 TUFT 方程锁定**（自由度审计确证）。
2. **打破简并须追加 1 条独立关系，且必来自外部**（观测量或约定）。
3. **7 类锚定方案扫全场，无 1 个能「第一性」给出电子尺度**；结果跨 **56 个数量级**。
4. **A4 证明康普顿尺度 ∧ 电子高曲率互斥**（偏离 `1.131e+45` 倍）。
5. 与 openuft M02 **同构**：O-SCALE 是 TUFT 的**诚实边界**（降级为"两层锚定 + 残留约定自由度"），非证伪。
