## 四、定理 K：完全交的牛顿系数闭式

> **定理 K**　设 `X = X_{d_1..d_r} ⊂ CP^N` 是 `r` 个次数为 `d_1..d_r` 的超曲面的光滑完全交，`n = N − r`。
> 则 `χ(O_X(k))` 的牛顿系数
> ```
> a_m = Σ_{S⊆[r]} (−1)^{|S|} C(N − d_S, N − m),    d_S = Σ_{i∈S} d_i
> ```
> 其中 `C(x, r)` 是**广义二项式** `C(x,r) = x(x−1)…(x−r+1)/r!`（`x` 可为负，`r < 0` 时为 0）。

**三行证明（仍不需 td）**

1. **Koszul 复形**：`0 → O(k−Σd) → … → ⊕_{|S|=j} O(k−d_S) → … → O(k) → O_X(k) → 0`
2. **χ 加性**：`χ(O_X(k)) = Σ_{S⊆[r]} (−1)^{|S|} χ(O(k−d_S)) = Σ_S (−1)^{|S|} C(N+k−d_S, N)`
3. **差分**：`Δ^m C(x+k, N)|_{k=0} = C(x, N−m)`，取 `x = N − d_S` 即得。

第 1、2 步**不需要消灭定理**（Koszul 对任意完全交都对），故定理 K 对 **CY 与一般型同样成立**，与 r366 定理 H 的情形一致。

**`r = 1` 的退化**：`N = n+1`、`d_S ∈ {0, d}` ⇒
`a_m = C(n+1, N−m) − C(n+1−d, N−m) = C(n+1,m) − C(n+1−d, n+1−m)`，即 r366 定理 H。
（`A02`：30 组逐项核对，失配 **0**；用到 `C(n+1, n+1−m) = C(n+1, m)`。）

## 八、为什么偏偏是半整数

`n` 为奇数 `≥ 3`、`d` 为偶数时，`P` 的首项系数 `a_n / n! = d/n!` 在 `n!` 含高次 2 因子时
被 `c` 的分母 2 恰好补平一次 —— 这不是巧合而是**阶的平衡**：

- `n = 1`：由 r346 **定理 C**，`S = (1/d)Z` ⇒ 陪集上要么全整要么全不整，**没有中间态**。
  `D03` 实测 144 个组，PARTIAL **0** —— 与定理 P 的「`n ≥ 3`」条款一致。
- `n` 偶：首项 `d/n!` 与次项的 2 阶错位，`c` 半整数带来的半整数偏移无法被后续项吸收 ⇒ 无 PARTIAL（`CTL7` 460 组 0）。
- `d` 奇：半整数偏移不被 `d` 整除 ⇒ 无 PARTIAL（`CTL6` 84 组 0）。

三条**缺一不可**：`B02`（30/30 全中）与 `B03`（0/1058 全不中）分别压住充分与必要两侧，
`CTL6`/`CTL7` 再把「去掉任一条就失效」单独测一遍。

> **诚实声明**：定理 P 是**在枚举窗口内验证的充要条件**（`n = 1..5`、`d` 各档、`q = 1..6`），
> 不是解析证明。本卷只说「1088 个陪集上零违例、且跳过的 112 组无盲区」。

## 十、对照构造：`C(m,2)/2` 证明「类数恒 1」不是通有性质

一个 100% 通过的谓词判别力为 0。`C01` 的「类数恒 1」若对**任何**整值多项式都成立，它就是空话。
本卷给出反证构造（`C04` + `CTL9`）：

```
Q(m) = C(m,2)/2 = m(m−1)/4      b = [0, 0, 1/2]   D = 2   β = [0, 0, 1]
解集（m = 0..7 直算）            = {0, 1, 4, 5}
mod 4 的剩余类                    = {0, 1}   ⇒ 类数 2
周期                              = 4 ≠ D = 2
```

⇒ **类数可以不是 1、周期可以不是 `D`**。`C01` 的「类数恒 1」因此**有信息量**：它说的是几何类
落在整值多项式里的一个真子集上。

## 十一、方法：整数化 + 有限差分递推（快一个量级）

朴素做法要对每个 `m` 求 `P(c+m)` 的精确有理值，代价 `O(D·n!)`（还要大整数阶乘）。
本卷换挡：

1. **整数化**：`β_i = D·b_i ∈ Z`，判 `Q(m) ∈ Z` 变成判 `Σ_i β_i C(m,i) ≡ 0 (mod D)`
2. **有限差分递推**：`g_j(m+1) = g_j(m) + g_{j+1}(m)`，`g_{n+1} ≡ 0`，全程 `mod D`
   ⇒ 每个 `m` 只需 `O(n)` 次小整数加法，总代价 `O(D)`

`CTL3`：快递推与 Fraction 直算在 **224 个点**上判定不一致 **0** 个。

> ★★ **本卷踩出的第一处自伤（递推顺序）**：`g_j(m+1) = g_j(m) + g_{j+1}(m)` 要求右端的
> `g[j+1]` 取**旧值**，故循环必须 **j 递增**（`for j in range(0, n)`）。
> 若写成 j 递减，会用到**已被更新**的 `g[j+1]`，算出的是另一个多项式。
> 阴险之处：在**几何类上这个错法巧合地不出错**（4232 个点上失配 0），
> 只在 `C(m,2)/2` 这种非几何构造上才暴露（正确 `[0,1,4,5]` vs 错误 `[0,3,4,7]`）。
> 已修三处，并写入门禁族。

## 十五、自审三处（本卷踩出）

### ① `GRID_A` 的 `r ≠ len(ds)` —— 家族自伤第八卷，落点仍是「对象错位」

网格生成时 `r ≥ 4` 的分支沿用了 `r = 3` 的三元组，于是网格里记的 `r` 与次数向量的长度不等：
`n = N − r`（网格）与 `n = N − len(ds)`（路径内部）**不是同一个 `n`**，
`pathK(...)[n]` 取到的是别人家的系数。

首跑表现：`A05`（`a_n = Πd_i`）68 违例、`A06`（CY 自检）13 违例 ——
而同一批数据上 `A01`（两路径对拍）却是 **0 失配**。
**对拍抓不到它**：两条路径内部都用 `len(ds)`，错的是**外部取下标用的 `r`**，两条路径同步地错。

修法：让 `r ≥ 4` 的元组长度真正等于 `r`（`product(range(1,3), repeat=r)`），
网格从 256 组变 **239** 组（`G09` 门限 200 仍满足），并**新增 `G20` 常驻**。

> 家族序列：`r327 → r331 → r335 → r339 → r346 → r358 → r366 → r367`。
> 这八卷的落点**全部是「守错了门」**：该盯 `len(ds)` 时盯了 `r`，该盯 `g[j+1]` 旧值时盯了新值。
> 沉淀：**凡是「从容器取下标」的地方，下标与容器必须在同一行代码里同时确定。**

### ② 有限差分递推的更新顺序（见 §十一）

j 递减会用已更新的 `g[j+1]`。危险在于**几何类上巧合不出错**（4232 点 0 失配），
只有换到 `C(m,2)/2` 这种非几何构造才暴露。三处已改为 j 递增。

### ③ 探查 4 的「9 条假违例」

判「`c` 是否半整数」时用了循环变量 `q`，而 `F(0,2)` 的既约分母是 **1** 不是 2
⇒ 把整数陪集误判成半整数。改用 `F(p,q).denominator` 后 **1430 组 0 违例**。
教训：**判「既约」必须问既约之后的对象，不能问约分之前的写法。**
