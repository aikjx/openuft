# ROOT V136｜实验验收协议：地球 + 月球 + 微观粒子

## 1. 外部观测数据（本版未下载或导入原始测量）

必须先确定地球与月球各自权威基线。地球使用 ICGEM/EGM2008 球谐系数、时变 GRACE-FO 或 GOCE 的产品，独立 SLR 卫星轨道测量；月球使用 NASA GRAIL 高阶引力与轨道数据。考虑参考框架、潮汐、月球 mascon、太阳及行星的第三体影响、非引力加速度、低轨大气与残差协方差。

## 2. 数据准备与单元制

从轨道/加速度数据派生惯性系中的径向场分量，然后减去高阶非球形和非目标引力、非引力扰动。该预处理必须独立于 ROOT 参数并保留协方差矩阵，不允许将原始 GPS 轨道误当成“绝对引力”。地面有效重力须反除自转惯性项。必须统一球心、经纬度、球谐归一化、地形及地球/月球半径定义。

## 3. 盲分析与显著性

1. 预先冻结候选假设 `α_Y=1/3`、`λ=124.6 km`，不得按结果修改后声称预测成功。
2. 从独立基线重建真实的 `r² |g|` 与全误差，分别报告 `D(r1,r2)`、`Q3`，考虑残差相关性。
3. 对比标准模型（GR+高阶引力场等）与候选模型，计算合适的似然和模型复杂度惩罚；将 `GM`、`J2`、密度、仪器参数一并纳入协方差或边缘化。
4. 若候选预测与数据矛盾，明确判定**这个候选参数/模型被削弱或排除**；不能把失败解释为“新引力已证实”。
5. 即便拟合改善，也必须用不同卫星、不同高度和月球 GRAIL 数据做**样本外盲预测**，不是使用同一数据拟合并验证。
6. 四力统一还须通过标准模型粒子性质、散射、弱衰变、强子谱、能动守恒等独立检验；地月引力无法替代这些实验。

## 4. 目前明确缺口

- 尚未导入正式原始观测轨道、重力场系数和完整协方差；无统计置信区间。
- 示意分层密度不是 PREM 或 GRAIL 的测量结果。
- 近圆轨道进动不含 J2/GR/第三体，不能直接与实测进动定量对比。
- 任何可检验的 ROOT 螺旋场拉格朗日量及其粒子谱仍是开放问题。
