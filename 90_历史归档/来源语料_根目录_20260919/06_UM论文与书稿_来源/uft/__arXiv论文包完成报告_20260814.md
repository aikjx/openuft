## 五、提交步骤

### 方案 A：Overleaf（最简，无需安装 TeX）

```
1. 打开 https://overleaf.com
2. 注册/登录
3. 点击 "New Project" → "Upload Project"
4. 上传 arxiv/ 目录下的所有 .tex 和 .bib 文件
5. Overleaf 自动编译
6. 下载编译好的 PDF
7. 上传到 arXiv：https://arxiv.org/submit
8. 上传 main.tex + references.bib + figures/
```

### 方案 B：本地 LaTeX

```
1. 安装 MiKTeX：winget install MiKTeX.MiKTeX
2. 打开 cmd 进入 arxiv/ 目录
3. pdflatex main.tex
4. bibtex main
5. pdflatex main.tex
6. pdflatex main.tex
7. 上传到 arXiv
```

### 方案 C：GitHub Pages（先发布代码）

```
1. 在 https://github.com/new 创建仓库
   - 名称：perpendicular-mode-geometry
   - Public
   - 不勾选 README

2. 运行 github_init.py
   python D:\a10\aikjx\code\my_lib\uft\github_init.py

3. 推送
   git push -u origin main
```

## 六、arXiv 提交详细步骤

```
1. 打开 https://arxiv.org/submit

2. 登录/注册

3. 选择分类
   Primary: hep-th (High Energy Physics - Theory)
   Secondary: physics.gen-ph (General Physics)

4. 上传文件
   - 方式 1：直接上传 main.tex + references.bib
   - 方式 2：上传 main.tar.gz（用 build_package.py 生成）

5. 填写摘要
   （使用论文中的摘要）

6. 添加评论
   "6 pages, 1 table. Code available at GitHub.
   Honest acknowledgment of unsolved problems."

7. 预览 PDF

8. 提交

9. 等待（通常 24 小时内处理完成）
```
