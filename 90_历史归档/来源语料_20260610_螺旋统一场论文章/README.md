## 一、核心框架（本批次主线）

- 宇宙第一公理：时空基元为圆柱螺旋线，切向速度恒等于真空光速（`ωρ = c`）。
- 几何量：`κ = ρ/(ρ²+b²)`（曲率），`τ = b/(ρ²+b²)`（挠率）。
- 精细结构常数本源：`α = κ/τ = ρ/b`（拓扑不变量，与尺度无关）。
- 物理常数几何化：ħ、m、e、ε₀、μ₀、G 全部由 κ、τ、c 导出。
- 四大力归一化：引力（曲率主导）+ 电磁力（挠率主导）+ 强核力 + 弱核力 = 1。

该框架与 openuft 现有体系同宗：`S02_空间光速螺旋统一力`、`S12_空间光速螺旋统一体系`、`S14_挠率统一场论TUFT`、`S03–S10_GAQ几何原子/常数/粒子谱体系`。
