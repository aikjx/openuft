# ROOT V127 — 三大根波物理一致性审计

## 研究状态
此研究为候选线性有效场模型，不是四力统一的证明。S/V/T 是示意性模式幅度，不能直接替代自旋0/1/2完整场表示。

## 可检验模型
在平直背景和固定优选参考系中，设三个实模式 q=(S,V,T)，二次作用量

L₂ = 1/2 (∂t q)^T K (∂t q) - 1/2 (∇q)^T C (∇q) - 1/2 q^T M² q。

K,C,M² 为实对称常矩阵。平面波给出 det(ω²K-k²C-M²)=0。

K 正定是避免此简化模型 ghost 的必要条件。K 正定后，定义 K^(-1/2)CK^(-1/2) 和 K^(-1/2)M²K^(-1/2)，检查梯度本征值和频率平方。高频特征速度平方为梯度矩阵本征值；若大于1，则相对于指定的 Minkowski 光锥超光速。对于含约束、色散、高阶导数的理论，单凭此项不能证明微观因果性。

负质量平方可能表示围绕所选背景的不稳定，但在完整非线性势下也可能意味着对称性自发破缺，不能一概排除理论。所有示例矩阵均为人为构造，不是物理测量。

## 理论一致性
任何协变有效理论可从 S_EH + S_SM + ΔS 构造，但单纯相加不是统一。若 ΔS 是任意函数，则没有预测力。需要无自由调参的构造和严格的观测约束。

## 黎曼谱论关系
谱分析的数学工具可以用于研究稳定性，但没有已知定理将黎曼零点等同于基本粒子谱或引力源。数值谱拟合不能替代证明。

## 人工引力
等效重力可由旋转/加速产生。电磁能量通过能动张量参与引力，但不能据此宣称低能耗引力操控。
