## 2. 方法与口径声明

### 2.1 β 函数（双源互证，禁凭记忆硬编码）

- **S1**：arXiv:1412.8230v1 §2（GUT 归一化约定 $g_1^2=\tfrac53 g_Y^2$）；
- **S2**：arXiv:1202.5717 附录 A Eq.(21)–(24)（超荷 $g_Y$ 约定，引自 Machacek–Vaughan + Arason et al.）。
- **CT1**：两源在 $g_1=\sqrt{5/3}\,g_Y$ 换算下逐项一致（机读残差 $2.7\times10^{-253}$，250 位精度地板）。
- 系数全部以 `Fraction` 固化后预计算为模块级常量（热路径禁重复解析字符串）。

### 2.2 跑动与匹配

- **积分**：RK4、对数步长（$t=\ln(\mu/{\rm GeV})$，$\mathrm{d}t=0.01$，末步补齐到终点——与 float64 独立实现严格同构，见 §6 引擎 bug 登记）；规范耦合自 $M_Z$ 跑到 $M_t$，在 $M_t$ 匹配 $(\lambda,y_t)$，再跑到 $M_{\rm Pl}$；过零点用轨迹上二分细化。
- **精度**：mpmath 250 位主链 + float64 独立全链路交叉核对（CT7：$\Lambda_I$ 相对差 $1.7\times10^{-13}$）。
- **匹配口径二分**（本卷 B3 的定价对象）：
  - **Case A** $=$ LO 朴素树匹配（$\lambda(M_t)=m_h^2/2v^2$、$y_t(M_t)=\sqrt2 m_t/v$），即文献 Table 3 LO 列口径；
  - **Case B** $=$ 文献 NNLO 匹配值直接代入（$\lambda=0.12604$、$y_t=0.94018$），即 Table 3 NNLO 列口径。
  - Case A 与 Case B 之差 $=$ **匹配约定的系统差**（pole 朴素 vs MSbar 阈值修正），不是数值误差。

### 2.3 诚实边界（本卷不做什么）

1. **不跑 3-loop**：文献 NNLO 实为「2-loop 阈值匹配 + 3-loop RGE」；本卷跑动只到 2-loop，对标是**同圈阶口径内的复算**（$\lambda(M_{\rm Pl})$ 差 $0.0037$、$m_h^{\rm crit}$ 差 $1.5$ GeV 量级即为此差）。
2. **不自算 NNLO 阈值修正**：Case B 直接代入文献 Table 3 匹配值（那是完整 2-loop 阈值计算的结果，本卷不重推）。
3. **不算 $\Lambda_V$（势垒定义）**：文献 Eq.(67) 的敏感度是对 $\Lambda_V\equiv(\max_h V_{\rm eff})^{1/4}$（规范/方案无关）做的；本卷算的是 $\Lambda_\lambda$（$\lambda$ 过零标度，方案依赖），文献明确 $\Lambda_\lambda\approx2\Lambda_V$（MSbar）。敏感度对标已声明此定义差（§4 CT5）。
4. **不含 $b/\tau$ Yukawa、不跨味数阈值**：$N_f=6$ 固定为声明约定（文献称 $b/\tau$ 对 $\lambda$ 跑动影响极小）。
5. **不算真空寿命/bounce**：亚稳寿命（指数作用量）不在本卷范围；本卷只给「亚稳判定」的 $z$ 距离。
