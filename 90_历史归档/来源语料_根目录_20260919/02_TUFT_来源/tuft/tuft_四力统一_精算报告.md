## 二、数值证据（可直接复现）

```
sin^2 theta_W(3:1 维度比)   = 0.25000    vs 实测(M_Z) 0.23122  -> 偏差 8.12%
sin^2 theta_W = 1/4  出现在 mu = 3.679e+03 GeV
sin^2 theta_W = 3/8  出现在 mu = 1.031e+13 GeV
M_Z 处:  g1=0.46143  g2=0.65174  g3=1.21823        (g1<g2<g3, 单调序成立)
1-loop SM 两两交点: 1.031e13 / 2.439e14 / 9.822e16 GeV, 1/alpha = 42.41 / 40.35 / 47.03
1e16 GeV: 1/alpha = (37.924, 45.878, 44.484) -> alpha 最大/最小 = 1.210  (21.0% 分散)
MSSM 对照: 交点 1e16.30 / 1e16.33 / 1e16.37 GeV, 1/alpha = 24.33 / 24.26 / 24.31  (汇聚)
反常消除: sum(Y)=0, sum(Y^3)=0, SU(2)^2U(1)=0, SU(3)^2U(1)=0, SU(3)^3=0   (Fraction 精确)
```

- **S2.5 尤为关键**：3:1 = 生成元数之比，其自然读数是 g′²/g² = 1/3 → `sin²θ_W = 1/4`。
  原文写 "≈ 0.231 与实验吻合"，但 0.231 是 **M_Z 处**的 MS-bar 测量值，不是任何"几何比值"。
  **把 IR 测量值当作 UV 几何定值 = 循环论证**。
- **S4.6 直接否证 §4.2**：`g1(M_GUT)=g2(M_GUT)=g3(M_GUT)` 在 SM 中不成立（21% 分散）；
  只有 **MSSM** 才汇聚（1/α≈24.3 @ 1e16.3 GeV）——即"汇聚"是超对称的结果，不是 TUFT 几何的结果。

## 四、结论：本分册"四大相互作用完整统一"不成立

1. **群论层**：结构群是**直积**（18 维）而非单群（SU(5) 24 维）→ 参数不减少，"归一"未发生；
2. **代数层**：挠率多分量"相加"是类型错误，正确结构（张量积）恰是标准模型表示论；
3. **参数层**：sin²θ_W 的"几何定值"差 8.1%，v=246 GeV 量纲不符且为外部输入；
4. **能标层**：SM 三耦合在 1e16 GeV **不汇聚**（21% 分散）；汇聚需超对称；
5. **作用量层**：所谓 TUFT 最终拉格朗日量 = SM+GR 逐字照搬，**零 TUFT 特有项**；
6. **可证伪性**：由于 (5)，本分册不产生任何"区别于 SM+GR"的预言。

> 与前一册（色挠率 SU(3)，FAIL 16）判定一致：
> **TUFT 的"四力统一"目前是 SM+GR 的重新命名（re-labelling），不是几何归一。**
