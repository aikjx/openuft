# openuft/code · 全域物理审计图谱系统

<a id="top"></a>

> **红线**：数学自洽 ≠ 有物理内容 ≠ 实验证实。本系统只整理与可视化 openuft 已机读审计的结论，**不重判、不发明新物理**。

<a id="s1"></a>
## 1. 系统定位

本系统是 openuft（全域物理审计库）的前端呈现层，把 53 卷核心公式体系总册、54 卷全物理现象覆盖矩阵、r100–r137 攻破链与 62–65 号螺旋几何化子卷的结构化审计成果，整合为一个可浏览、可关联、可持续攻破的企业级 Web 应用。

三件事：

1. **整理全部物理**：五主题攻破射程、40 轮攻破链、22 条正确核（16 保留 + 6 降级）、14 条黑名单、22 个物理域槽位，全部来自机读引擎产物，无人工叙事加工。
2. **可视化关联**：主题（枢纽）— 攻破轮 — 正确核/黑名单三层力导向关联图谱；攻破链时间线；宇宙运动本质判读。
3. **可不断攻破**：攻破工作台复用本库 8 条审计判据，对新宣称逐条守卫自检，生成机读 verdict，立即成为图谱与攻破链的新节点；支持导出与 53 引擎同 schema 的 JSON 以便真入账本。

<a id="s2"></a>
## 2. 技术架构

| 项 | 选型 | 理由 |
|---|---|---|
| 框架 | Vue 3.5（`<script setup>`） | 组合式 API，视图即数据派生 |
| 路由 | vue-router 4（hash 模式） | 静态托管零配置；404 兜底 |
| 构建 | Vite 6 | 秒级 HMR，生产构建 ~4s |
| 可视化 | 手写 SVG 力导向模拟 | 零图表重依赖，节点/边/颜色全部可控 |
| 样式 | 手写 CSS（设计令牌） | 无 UI 框架锁定，企业级暗色主题 |
| 持久化 | localStorage（`openuft_user_rounds_v1`） | 工作台新增攻破轮仅留本机 |

**依赖只有 2 个运行时**（`vue` + `vue-router`），其余全部手写——这是有意为之：审计系统的可视化层不应引入不可审计的第三方代码。

## 6. 攻破工作台（持续突破机制）

这是系统「可以不断地突破攻破」的入口：

1. **登记新宣称**：标题（必填，内联校验）/ 关联主题 / 靶宣称 / 内容依据 / 自定义编号；
2. **套用判据自检**：8 条判据逐条勾选 通过 / 失败 / 不适用，失败须留证据；
3. **机读 verdict**：任一守卫失败 ⇒ FAIL；全不适用 ⇒ BOUNDARY；否则 PASS（机读规则与 r 系列一致：失败一票否决）；
4. **入图谱**：确认后立即进入关联图谱节点、攻破链时间线与总览统计；
5. **导出入账本**：导出 JSON 与 53 引擎 round 记录同 schema（`id/title/verdict/theme/date/target/conclusion/blacklists/downgrades`），可直接并入 `04_公共成果/本项目_全维自洽与归一化/数据/` 走治理链。

> 注意：工作台 verdict 是**登记性质的机读判定**，与 r 系列引擎产物（json + 判定册 md + 报告三件套）地位不同——它记录「你的判定」，不替代引擎复算。

**8 条判据**：量纲审计 / 数值稳定性守卫 / 控制组对照 / 抄录检测 / 反解闭环检测 / 判据判别力 / 洛伦兹协变 / 可证伪性（定义见术语表视图与 `auditCriteria` 字段）。

## 7. 与 53 卷及治理链的关系

- **数据同源**：前端 JSON 的每个数字都可回溯到 53 卷合账总册（`07_统一场方程/53_核心公式体系总册_2026-10-19.md`，由 `53_core_ledger_calc.py` 机读生成，守卫 22/22）；

- **提交边界**：前端成果仅留盘不提交（外层 my_lib 仓库按 openuft 惯例治理；`code/node_modules` 已被两个治理脚本排除）。

## 8. 开发指南


**新增一个攻破轮的正确做法**：改 `53_core_ledger_calc.py` 入账并复跑（守卫须全过）→ 同步更新 `openuft-graph.json`（rounds / blacklist / counts / meta）→ 前端刷新即生效。禁止只改前端不改账本。

**修改数据底座后必查**：`meta.counts` 与各数组长度一致；主题 `hex` 字段存在（否则 chip 背景合成失效）。

### 10.2 攻破层：26 条断裂边界（定价到 dex）

同一套判据压测正确理论自身。三册条目**不可相加**（重叠项是不同截断口径或射程）：

- **r127（SM+GR 自身缺口）**：中微子质量 7.01 dex / 宇宙学常数 52.79–120.74 dex / 暗物质 5.364 倍 / 暗能量巧合 z=0.3036 / 重子不对称 CP 不足 8 dex / 强 CP θ<1e−10 / 等级 16.99 dex / 味谱 5.53 dex / 引力未量子化 / 三耦合离散 3.86 dex + 1 OPEN（代数未解释）；

### 10.3 最深攻破：18 条推导链 0 闭合（r130）

对正确理论体系的推导链逐条查前提（POSTED/ASSUMED/DERIVED/OPEN）：**总闭合率 0.327，0 条闭合**——11 条前提开放（GR 8 链中 EH 作用是公设、等价原理 closure=0；SM 7 链中规范原理与场内容是输入；X-3 测量公设 closure=0）、3 条域限（奇点定理/微扰 QFT/RG 外推）、4 条猜想（Kerr 唯一性/Wightman 基础/GR+QM 兼容/时间问题）。判定 **SOUND-BUT-PREMISE-OPEN**：方程对，但方程从哪来仍未闭合。

## 12. Glossary

| 术语 | 定义 |
|---|---|
| 攻破轮 (rNNN) | 对某一宣称的可机读判决单元；产物 = json + 判定册 md + 报告三件套 |
| 主题射程 | 五主题把 r 轮按攻击对象归类，看「一个宣称被几轮合流攻破」 |
| 退守路径 | 主宣称被判否后的弱化版本；攻破链铁律要求封死主路后立刻堵退守（r123 即 r120 的退守封堵增补卷，条目不可相加） |
| 质子衰变安全线 | 由 Super-K 上限反算的 M_GUT ≥ 6.12e15 GeV；越线方案是「已被排除」而非「未检验」 |
| 正确核 | 53 卷保留清单：教科书物理的记号改写 / 代数恒等 / 已证几何定理，全部非本库新增 |
| 黑名单 | 不可作为推导前提的登记；讨论时只能以「已被 X 号卷判否」形式出现 |
| 机读守卫 | 引擎自检门（如 `g_theme_force_all_fail`）；失控时退出码 2，全过退出码 0 |
