## 关键公式速查

### 基石恒等式
$$\kappa^2 + \tau^2 = \left(\frac{\omega}{c}\right)^2$$

### 速度分解
$$v_\parallel = c\frac{\tau}{\sqrt{\kappa^2+\tau^2}}, \quad v_\perp = c\frac{\kappa}{\sqrt{\kappa^2+\tau^2}}$$

### 洛伦兹因子
$$\gamma = \frac{\sqrt{\kappa^2+\tau^2}}{\kappa} = \frac{1}{\sqrt{1-v^2/c^2}}$$

### 质量-曲率
$$m_0 = \frac{\hbar\kappa_0}{c}, \quad \lambda_C = \frac{1}{\kappa_0} = \frac{\hbar}{m_0 c}$$

### 质能统一
$$E_0 = \hbar\omega_0 = m_0 c^2$$

### 标准螺旋参数
$$\kappa = \frac{a}{a^2+b^2}, \quad \tau = \frac{b}{a^2+b^2}, \quad a = \frac{\kappa}{\kappa^2+\tau^2}, \quad b = \frac{\tau}{\kappa^2+\tau^2}$$

### N维推广
$$\kappa_1^2 + \kappa_2^2 + \cdots + \kappa_{N-1}^2 = \left(\frac{\omega}{c}\right)^2$$
