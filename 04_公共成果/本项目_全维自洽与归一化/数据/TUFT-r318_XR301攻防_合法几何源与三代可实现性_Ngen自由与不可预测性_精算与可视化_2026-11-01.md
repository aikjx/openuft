# r318 · X-R301-1 攻防 · 合法几何源下的代数可实现性与可预测性（N_gen 自由 · 三代非结构性禁止）

条目总数 22（主 8：PASS 4 / FAIL 1 / INFO 3）；控制组 4/4；守卫 10/10。

## [P1] INFO · X-R301-1 精确重述与本卷改造
**X-R301-1（r306 判定册 §遗留）**：要把 X-R296-2 真正翻盘，须给出**具体的非比例耦合矩阵 A 且证明其来自合法几何**。本卷沿用 r296/r306 的规范 FCSRE 通量模型（**A=diag(d_i)**，6 个独立电荷自由度 X_i）并加**单个**轨道扭转源 g∈{0,1}^6（Schur，r305 Thm N / r307 Thm Q），即 A=[diag|g]、t=(X;Y)，检验 A·t=N_gen·𝟙。

## [P2] PASS · 结构定理：合法源 = 自由通量 + 0/1 扭转
**定理（源分类）**：(F) 通量/Wilson/曲率 ⇒ 每表示独立电荷 X_i（A 的对角部分 d_i）；(T) 轨道扭转 ⇒ 单扭转对每个不可约表示给 0 或 1 份常数截面（k_i∈{0,1}），扭转**份数** Y∈Z 是独立的拓扑整数（扭结扇区数 / 不动点数）。故合法源系统的耦合矩阵 = [diag(d_i) | g]，g 为 0/1 列。★本卷只允许**一个** 0/1 扭转列（比 r306 的多源更受限、更保守）。

## [P3] PASS · 单扭转穷举：64 个 0/1 源中 16 个使 N=3 可解（非平凡，非仅全 1）
对全部 64 个 g∈{0,1}^6，令 A=[diag|g]，检验 A·t=3·𝟙。**可解数 = 16**；且全部满足 **g[0]=1 且 g[3]=1**（即 d=6、d=2 这两行必须开扭转，因为 6∤3、2∤3），其余 4 位任意 ⇒ 恰为 2^4=16 个，与实测一致。★与 r306 不同：r306 用**单列** d 建模得「仅全 1」，本卷用规范的 **diag** 建模，可解面大得多 ⇒ **三代远非「结构性不可能」**。

## [P4] PASS · ★显式构造：g=(1,0,0,1,0,0)、Y=3 ⇒ 逐表示 index 全=3（非平凡、非均匀）
取 **非均匀** 扭转 g=[1, 0, 0, 1, 0, 0]（只在 d=6 与 d=2 两行开扭转），扭转份数 **Y=3**，则 X=(3−Y·g_i)/d_i = [0, 1, 1, 0, 3, 3]（全整数）。t=[0, 1, 1, 0, 3, 3, 3]。机检 **A·t = [3, 3, 3, 3, 3, 3] = 3·𝟙** ✓，行列式因子判据判可解=True（rank=6）。⇒ 一个**单个、非平凡、非均匀**的 0/1 扭转即可给出 3 代，无需多源、无需答案注入型向量。

## [P5] PASS · ★N_gen 完全自由：N=1..12 每个都可构造（三代无特殊性）
对每个 N∈[1,12]，取 g_i = (d_i∤N ? 1 : 0)（在不能被 N 整除的行开扭转），Y=N，X_i=(N−N·g_i)/d_i。逐 N 机检 A·t=N·𝟙：[(1, True, True), (2, True, True), (3, True, True), (4, True, True), (5, True, True), (6, True, True), (7, True, True), (8, True, True), (9, True, True), (10, True, True), (11, True, True), (12, True, True)]。**12/12 全通过** ⇒ **任何代数 N 都能由「对应 0/1 扭转 + 扭转份数 Y=N」实现**（N=6 且无扭转时即纯 FCSRE lcm=6）。⇒ 框架对 N_gen **无选择性**，3 代与 1、2、4、5…代地位相同。

## [P6] INFO · 关键辨析：可及 ≠ 可预测（3 是输入不是预言）
P3/P4/P5 证明 N_gen 可及（无结构性禁令），但**每个解都把 N 作为扭转份数 Y 显式拨入**（P4 中 Y=3；P5 中 Y=N）。物理上 Y = 扭结扇区数 / 不动点数，是**几何/拓扑输入**。⇒ 框架**不能预言 3**，只能容纳 3（需一个恰有 3 份扭转扇区的几何）。这与 r307 的独立结论「3 是拓扑输入、N_gen≤π0」**完全一致**，构成一条独立交叉验证。

## [P7] FAIL · 判据集 R1–R9（R9 = 机制能否预言 N_gen=3）
在 r306 的 R1–R8 上新增 **R9「机制是否预言 N_gen=3（而非仅容纳）」**。结论：R9=否（P5 证明任意 N 都可及、Y=N 显式拨入）⇒ **R1–R9 = 0/9**。★这是本卷对 r306 的**双面修正**：(a) r306 的「三代结构性不可能」被**推翻**（3 可及）；(b) 但「不可能」降级为「不可预测」——三代问题从「被禁止」变成「未被选中」，判据集整体仍 FAIL（框架不预言 3）。

## [P8] INFO · 结论与诚实边界（对 r306 的精确重定位）
**结论（判词 NO-GO-DOWNGRADED-TO-FREE）**：r306 的 `NO-GO-STABLE` 在「合法源 = 自由通量 + 0/1 扭转」口径下**过强**——单个非平凡 0/1 扭转 + 扭转份数 Y=3 已给出逐表示 index 全=3 的显式解（P4），且任意 N 均可（P5）。正确表述：**三代不被结构禁止，N_gen 是自由/拓扑输入，框架不预言 3**（与 r307 一致）。**诚实边界**：(i) 本卷只允许**单个** 0/1 扭转列，多扭转只会让可及面更大，不改变「N 自由」结论；(ii) Y=N 的几何实现（需恰 N 份扭结扇区）是拓扑选择，未在此构造具体模型；(iii) 本卷**不宣称「三代已从第一原理推出」**——恰恰相反，它证明 3 不是推出来的而是拨进去的。
