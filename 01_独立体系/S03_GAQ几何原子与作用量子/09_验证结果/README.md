## S03-V7 补充（2026-10-07）：加框可导出性与闭合性二难

**任务**：落实 S03-V6 §11 约束 1——给 GAQ 螺旋场线定义一个体系内的加框。

**读数**：条目 9（PASS 2 / FAIL 2 / BOUNDARY 3 / INFO 1 / CORRECTED 1），自检 7/7，退出码 0。

**结论 A（解除约束）**：**加框不是公设边界**。Frenet 加框由曲线唯一确定、自动闭合（`max|u(2π)−u(0)| = 7.769e-16`）、无残余自由度 ⇒ 体系内可导出。V18.6 §11 约束 1 就此解除。

**结论 B（发现更上游的阻塞）**：**闭合性二难**。由 F-S 基本定理，`κ`、`τ` 为常数 ⇒ 曲线只能是圆（`τ=0`）或圆螺旋（`τ≠0`，`z` 分量严格单调 ⇒ 永不闭合）。⇒ GAQ「闭合轴向螺旋孤子」与「常 `κτ` 解析式（`κ=Rω²/c²`、`τ=ωu/c²`、`κ²+τ²=Ω²`）」**不可兼得**（机器扫描四组 `(R,a)`，`min|r(T)−r(0)|` 恒 > 0）。加上光子侧本就是开式（V18.6 V6-e）⇒ **两个孤子类都没有良定义的 `Lk`** ⇒ 来稿 §5 判据表与 §6 重联命题失去地基。

**非平凡数值成果（White 公式在真扭结上的检验）**：trefoil 上 `Tw = −2.481760769`（非整数，合法）、`Wr = −3.518143`、`Lk = −6.000642 ≈ −6`（整数）。`|Lk − (Tw+Wr)| = 7.38e-04`，`|Lk − (−6)| = 6.42e-04`（`N=800`、`ε=0.06`）。这是 V18.6 V6-a（平面圆 `Wr=0` 的退化情形）的非平凡推广——整数性由 `Wr` 补偿 `Tw` 的小数部分，正是 Călugăreanu–White 定理的内容。

**Bishop 不可用**：holonomy `∮τ ds = −2.481760769` 圈（非整数）⇒ Bishop 加框不闭合，无法构造闭合 ribbon；且依赖初始角 ⇒ 即使闭合 `Tw` 也需外加约定。⇒ 需要闭合场线时加框候选实质只有 Frenet 一个（代价：`κ→0` 处奇异）。

**一处自我更正（V7-e）**：V18.6 V6-b「`Tw ∝ ∮τ ds` 隐含加框闭合条件」表述不准确——Frenet 加框自动闭合，`Tw` 是实数不需整数，V18.6 中 `n=0.5` 不闭合是**本册自己构造的人工加框**的问题，不构成对来稿的指摘。射程收窄为「若采用非 Frenet 加框须额外声明闭合性」。V18.6 其它条目不受影响。

**对分支三的净效果**：约束 1 解除，但新增阻塞（闭合性二难）。可行输入仍只有 V18.6 V6-f 的**手性符号**（镜像 `Wr = ∓3.517997`，机器零反号）——它只依赖构型，不依赖闭合性或 `Lk`。
