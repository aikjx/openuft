# 第七章｜诱导引力：热核计算、正确系数与裸耦合问题

## 7.1 固有时间热核展开 [COND]

考虑一个实标量在欧氏背景的算子 `D=−∇²+m²+ξR`。单圈形式有效作用量 `Γ^(1)=1/2 Tr ln D`，可用固有时间表示为 `−(1/2)∫_{ℓ²}^∞(ds/s) Tr e^{−sD}`，其中 ℓ 是明确选择的 UV 截止长度。在四维，`Tr e^{−sD}≈(4πs)^(−2)∫√g e^{−sm²}[1+s(1/6−ξ)R+…]`。热核曲率项的系数与裸 Einstein–Hilbert 项进行匹配，出现一个依赖质量阈值、非最小耦合和截止方案的有效重整化结果。

在前述正则化约定中，可把模型的主要效应参数化为：

`1/G_eff = 1/G_bare + [N(1−6ξ)ℏ/(12π c³ℓ²)] F(μ)`，`μ=m cℓ/ℏ`，`F(μ)=exp(−μ²)−μ²E₁(μ²)`，`F(0)=1`。

该表达式是特定简化假设、单圈展开及截止方案中的系数表达；多种场类型和高能完成会改变结果，且裸耦合不能任意忽略。声称这条公式在没有输入任何尺度时“独立证明 G”是逻辑错误。

## 7.2 质量截止函数的独立积分

有 `F(μ)=∫_1^∞ dt e^{−μ²t}/t²`，μ≥0。对 μ>0，令 `z=μ²` 并分部积分，得到 `F=e^{−z}−z E₁(z)`。导数 `dF/dz=−E₁(z)<0`，因此 `F` 随 μ 单调不增。程序同时实现 E1 的小 z 收敛级数和大 z 连分式，对 SciPy `exp1` 以及直接数值积分逐点交叉检验，避免此前固定步长积分误差。

## 7.3 G 的无限多组反向拟合

取零裸项、ξ=0、μ=0 的玩具极限，有 `G_ind=12π c³ℓ²/(Nℏ)`。使用已知实验 G 反求 `ℓ=√[GNℏ/(12π c³)]`。任意正整数 N 都能产生一条这样的拟合解曲线，不能据此确定真实微观尺度。即使结果接近普朗克长度，也只是测得 G 的尺度重写，非实验独立预测。

## 7.4 宇宙学常数与重整化问题

相同热核展开的首项还会对真空能产生高度敏感的贡献，朴素高截止估计与观测暗能量量级之间存在巨大差距。该差距受正则化与重整化选择的影响，但其自然性问题无法凭计算一个 R 项而消失。要使诱导引力成为可信的微观本源机制，还需同时解释稳定性、低能 Newton 极限、UV 一致性、物质场谱及小宇宙学常数。
