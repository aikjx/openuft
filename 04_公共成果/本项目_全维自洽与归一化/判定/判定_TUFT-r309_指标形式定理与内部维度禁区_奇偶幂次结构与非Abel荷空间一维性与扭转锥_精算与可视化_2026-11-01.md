## 一、判决主文

三条并立，互不推导：

**Ⅰ. 指标形式已定（定理 R）。**
`M⁴ × M_int^{2n}` 上的扭折 Dirac 指标是 `q_R` 的 **parity 多项式**：

```
n_R = Σ_{k=0}^{⌊n/2⌋} A_k q_R^{n−2k}     A_k = 几何矩（∫ω^k Â）
```

幂次 `n, n−2, n−4, …` 降到 0 或 1 为止，**电荷系数只有 ⌈n/2⌉ 个**。
`A_k` 是几何输入，`n_R` 的比值与通量取值无关（r302 定理 B 由此升格为一般事实）。

**Ⅱ. 荷空间严格一维（定理 S）。**
SM 五个多重态的四个线性反常有精确解空间，**秩 4 / 5 未知数 ⇒ 维数 1 ⇒ 解就是 `Y` 本身**。
`AFF`、`AYF` 在该线上恒为零 ⇒ 完整反常自由集 `= span(Y)`。
⇒ **`m` 个 U(1) 的荷全部共线，加 U(1) 不增加任何自由度。**

**Ⅲ. 内部维度 ≤ 10 只有加权纯复制（定理 U）。**
Z₃×Z₂ 中心扭转的可实现 k 向量构成一个四约束锥，锥里还有一条结构等式 **`k₂ ≡ k₃`**
（`u^c` 与 `d^c` 同为 `3̄`）。与 parity 幂次联立后，**`n ≤ 5` 的齐次锥精确塌成 `{0}`**：

```
唯一解：  P ≡ 0（零通量）  +  k ≡ 3（三份都不带扭转）  +  c = 3
```

⇒ ROOT 的 **2 维**内部空间、r307 讨论的 4 维、r295 的 E3/E4 的 **6 维**，全部落在死区里。
三代在本框架内有一实现，但它对「3」的贡献恒为 0 —— **`c = 3` 是拓扑输入**。

**Ⅳ. 唯一不靠复制的活口：内部维度 18（定理 V）。**
`c_min` 谱：`n=6 → 187`、`n=7 → 12`、`n=8 → 20`、`n ≥ 9 → 1`。
`c = 1` 意味着**单一连通内部空间 + 一个非平凡扭转 T32** 就能等重 —— 代价 18 个内部维度。

## 二、为什么「指标形式」值一整节

因为前四卷一直在攻击**机制的参数**，而这个形式决定了**机制的参数空间本来有多大**。

r294 攻 `dim(R) | N_gen`；r302 攻 `q_R` 的等谱锁定；r305 攻通量量子与 `K_min`；
r307 攻 Schur 标量性与复制。四卷的靶全在「通量 / 荷 / 扭转 / 复制」这一层。
但 `n_R` 到底长什么样，从 r292 起就默认是 `index = q_R·dim(R)·M`（一代线性式），
**没有人检查过这个默认式在更高内部维度上还成不成立**。

它不成立。`Â` 只含偶数阶 Pontryagin 项，所以一旦 `dim M_int ≥ 4`，
`n_R` 里必然出现**与电荷无关的项**（`(1/24)∫p₁` 或 `(7p₁²−4p₂)/5760`）。

**这一项改变了整个问题的结构**：它让 `n_R` 的「常数项」对所有多重态、以及对所有**中性**体场一视同仁。
如果三代来自这一项，那么引力多重态、规范多重态也应当是三代 —— 观测不是。
所以三代**必须**来自电荷依赖项；而电荷依赖项的自由度只有 `⌈n/2⌉` 个，被 4 个等重条件一夹，
禁区就出来了。

**换句话说：栅栏不在通量上，在幂次上。**

## 三、荷空间一维：一条把「加 U(1)」整类逃逸关掉的判据

r300/r301 一路都留着一个默认退路：「多加一个 U(1)，多一条自由方向」。
这条退路在本卷被一个 4×5 的矩阵直接封死。

四个线性反常作系数矩阵，秩 4，五个未知数 ⇒ 零空间 1 维 —— 而且**基向量就是 `Y`**。
不是「包含 Y 的某个高维空间」，是**恰好那一根线**。

于是对任意 `m`，每个 `q^{(a)}` 都落在 `span(Y)` 里 ⇒ 所有 U(1) 的荷向量**互相共线**。
一个物理上可以独立规范化的新 U(1)，其荷向量必须与 `Y` 不成比例才有意义 —— 而这被反常自由禁止。

**本卷全部判据里没有出现 `m`。** 这不是遗漏，是定理。

负对照写死在引擎里（C06 / CTL3）：删掉 `AYY` 那一行（`Y²` 权），零空间从 1 维涨到 2 维
⇒ 那条方程是真的承重。若当初只写三个方程就宣布"一维"，这条判据会是假的。

## 四、parity 幂次：为什么是 ⌈n/2⌉ 而不是 n+1

这是本卷唯一有点技术性的地方，也是最容易被"优化"掉的地方。

`∫ e^{c₁} Â` 里 `c₁` 的幂是任意的，但 `Â` 的幂是**偶数**的。
所以 `c₁^k Â_{2n−2k} ≠ 0` 要求 `2n−2k` 是偶数 ⇒ 恒成立，但 `Â_{2n−2k}` 只在偶数阶非零
⇒ `2n−2k` 必须是偶数 ⇒ **`k ≡ n (mod 2)`**。

于是 `k = n, n−2, n−4, …`，共 `⌊n/2⌋ + 1` 项，其中电荷依赖项 `⌈n/2⌉` 个。

**如果丢掉 parity**（把 `Â` 当成任意阶都有），系数个数变成 `n` 个，
「4 个条件 vs `n` 个系数」的阈值从 `n ≥ 9` 掉到 `n ≥ 5`，
内部维度门槛从 18 掉到 10。**所以两个口径必须都报**（D06 = 18，D07 = 10），
不能只挑一个 —— 挑 10 会显得本卷的禁区弱一半，挑 18 又隐含了一个未论证的假设。

本卷的判词用的是**严格档 18**，但把 10 同时写在判据表里（CTL5 专门盯这件事）。

## 五、扭转锥：为什么 `k₂ ≡ k₃` 是全卷最锋利的一刀

四个扭转生成元是 `T0=(1,1,1,1,1)`、`T3=(0,0,0,1,1)`、`T2=(0,1,1,0,1)`、`T32=(0,0,0,0,1)`。

看 `T3` 与 `T2`：
- `T3` 的第 4、5 分量是 1 —— 它只"看见" `L` 与 `e^c`（单态）；
- `T2` 的第 2、3、5 分量是 1 —— 它"看见" `u^c`、`d^c`、`e^c`。

`u^c` 与 `d^c` **永远同时出现或同时不出现**，因为它们同为 `3̄`，中心荷相同（`zc3 = 2`）。
于是任何扭转组合都给 `k₂ = k₃`。

而 `Y₂ = −2/3`、`Y₃ = 1/3` —— **完全不同的超荷**。

等重要求 `P(Y_R) + k_R = N`，于是

```
P(Y₂) + k₂ = P(Y₃) + k₃   ⇒   P(Y₂) = P(Y₃)      （因为 k₂ = k₃）
```

**扭转制度对一个超荷简并的多重态对，但超荷本身不简并。**
这一条在 `n = 1, 2` 时直接给出 `β = 0`（因为那时 `P` 只有一个电荷系数）；
在 `n = 3, 4` 时把唯一的射线夹死；在 `n = 5` 时把二维锥夹成一点。

**这是本卷真正的"小事实定生死"**：一个「`3̄` 的中心荷是 2」的群论常识，
决定了整段内部维度 ≤ 10 的死区。它不漂亮，但它硬。

## 六、复制数谱为什么非单调

`n=6 → 187`、`n=7 → 12`、`n=8 → 20`、`n ≥ 9 → 1`。

看着像乱，其实由**左零条件数**完全决定：

| n | 电荷系数 | 左零条件数 | `c_min` |
|---|---|---|---|
| 6 | 3 | 2 | 187 |
| 7 | 4 | 1 | 12 |
| 8 | 4 | 1 | 20 |
| 9 | 5 | 0 | 1 |

- `n=6`：3 个系数被 2 条左零条件锁住 ⇒ 只剩 1 维，`c` 被推到 187；
- `n=7,8`：4 个系数、1 条条件 ⇒ 3 维；但 `n=7` 的幂次是 `{7,5,3,1}`（无常数项），
  `n=8` 是 `{8,6,4,2}`（也无常数项），两者几何矩的整数实现相差一档 ⇒ 12 vs 20；
- `n ≥ 9`：5 个系数、0 条条件 ⇒ 任意 `v` 都能解出 ⇒ `c = 1`。

**为什么 n=8 的 20 大于 n=7 的 12？** 因为 `n=8` 的 4 个系数是 `{8,6,4,2}`，
`u_R` 的 8 次幂量级到 `6⁸ = 1.7×10⁶`，几何矩要凑成整数 × 使 5 个取值落在同一条水平差上，
代价比 `n=7` 的 `{7,5,3,1}` 更大。这是数值事实，不是定理 —— 本卷只用它做**存在性**报数。

**这张表最容易误读的一点**：`c_min` 小不代表「更自然」。
`n ≥ 9` 的 `c = 1` 要求 5 个几何矩精确满足一条线性约束，
在「存在某几何」的意义上自由，在「典型几何」的意义上概率为零。

## 七、口径轴：trace vs family —— 一条会让整卷自毁的混用

r294 的式子是 `index = q_R · dim(R) · M`。本卷对这个 `dim(R)` 做了一次独立审计：

```
trace 口径（含 dim R）：n_R = dim R · (…)
   ⇒ 等重 N ⇒ 每个 dim R 都整除 N ⇒ lcm(6,3,3,2,1) = 6 | N
   ⇒ N = 3 ⇒ 3 mod 6 = 3 ≠ 0 ⇒ **三代在此口径下算术上不可能**

family 口径（除 dim R）：n_R = …
   ⇒ 唯一让「3」可问的读法
```

**r294–r307 全程报的都是 family 口径的数**（r307 的「`n_R ≡ 1` ⇒ 一代」就是在 family 下说的），
但式子里一直挂着 `dim(R)`。这不是错，但它是一根**未登记的口径轴**：
一旦有人在 trace 口径下引用那几条判词，「`n_R ≡ 1`」会被读成「`n_R ≡ 6`」，整卷自毁。

本卷把它显式登记（G01–G04），并给出结论：**`dim(R)` 在 r294 的结论里是装饰性的**
（除与不除，`q_R M = N` 这个条件一模一样）。所以后续各卷不应据 `dim(R)` 因子判断三代。

## 八、判定纪律与自查：三轮伪值，全部自己抓掉

本卷从首版到定稿产生过 **三个伪值**。三条根因不同，说明"一处对"不等于"处处对"。

**① `n=5` 的 `c = 59`，`k = (10,11,11,2,59)`**

可实现性锥里**只写了 `k₁ ≤ k₂` 与 `k₄ ≤ C`，漏了 `k₁ ≤ k₄`**。
反解 `b = k₄ − k₁ = 2 − 10 = −8 < 0` ⇒ 这个 k 根本不是任何扭转组合的和。
抓法：`reconstruction()` 反解回验写进控制组（CTL8）与守卫（G14），
并在守卫里**字面登记**这个假解 —— 它必须留在本文里，不能悄悄删掉。

**教训**：一个"多面体约束"必须把**每一张面**都写出来。
四张面（`k₁≤k₂`、`k₁≤k₄`、`k₄≤C`、`k₁≥k₂+k₄−C`）少一张，解集就不是多面体而是一个更大的锥。

**② `c_min` 表整体错位（`n=6 → 18`、`n=8 → 1`）**

线性系统右端符号写反：`λ·(3−k) = 0` 展开得 `A x = −3Σλ + λ₄ c`，
我一度把它当成 `3Σλ − λ₄ c`。探针脚本带着这个错还给"通过"——
因为它回验时用的是同一套错系数（**同源回验抓不到同源错误**）。

抓法：另写一段**无技巧暴力枚举**（`c ≤ 60`，三个坐标全穷举，不做任何代数化简）作为第三方基准。
一次对出真值：`n=7 → 12`、`n=8 → 20`、`n≥9 → 1`、`n≤6 → 60 内无解`。

**教训**：再漂亮的代数化简，也要有一个不会撒谎的笨办法对一次。

**③ `n=6` 的 `c = 235`**

解析搜索里 `for k₂` 循环内放了 `break`（"每个 `k₁` 只取第一个可行 `k₂`"）。
而 `c = 512k₁ − 161k₂ − 1050` 随 `k₂` **递减** ⇒ `break` 恰好砍掉了更优解。
去掉 `break` 重算得 **187**，与引擎一致。

**教训**：搜索里任何 `break` 都要先问「目标函数在这个方向上是升还是降」。

**三条方法学结论（已写进 MEMORY）**：
1. 「另一条判据」必须真的**独立**；
2. **暴力枚举不可省**；
3. 提前退出（`break` / 剪枝）必须对目标函数的方向有明确论证。

## 九、诚实边界

1. **本卷没有证明三代不可能。** 本卷证明的是：在「五个 SM 多重态各自独立由扭折 Dirac 指标给出重数」+
   反常自由 + Z₃×Z₂ 中心扭转移矩下，**内部维度 ≤ 10 时唯一解是零通量 + 3 份无扭转复制**。
   三代仍然存在，只是它没被解释。
2. **框架本身没被证明是对的。** 「每多重态各自一个指标」是 r294–r307 的隐含假设。
   真实异弦模型构建的做法正相反：一整个 `27` of E6 内含整代，**一个指标给全部**。
   在那个框架里本卷的定理 T/U 完全不适用。**这是本卷最重要的边界**，见 §十一 `X-R309-1`。
3. **`c_min` 是存在性下界，不是充分判据。** 表里的数只说明「存在某组几何矩使等重成立」，
   没有说这组矩由哪个几何给出，也没有说它稳定。
4. **`n ≥ 9` 的 `c = 1` 不是"解出来了"。** 它要求 5 个几何矩满足一条精确线性约束；
   在"存在"意义上是解，在"典型"意义上概率为零。
5. **锥判定只覆盖 `n ≤ 5` 的无解性。** 对 `n ≥ 6` 我只给存在性构造，没给穷尽性证明。
6. **`m` 个 U(1) 的无关性依赖 SM 五重态内容。** 若加入右手中微子（关闭 B−L），
   荷空间会变成 2 维，本卷定理 S 需要重算 —— 本轮**未做**，登记为 `X-R309-2`。
7. **本卷不产新物理。** 它只把一个此前默认的式子写下来，然后量出这个式子的自由度有多大。

## 十二、最终一句

前四卷一直在问「**哪个机制不给三代**」，本卷把问题换成「**这个式子本来允许多少个自由度**」。

答案是一个整数：`⌈n/2⌉`。被 5 个多重态一除，剩下的只有"死"，或者"抄"。
