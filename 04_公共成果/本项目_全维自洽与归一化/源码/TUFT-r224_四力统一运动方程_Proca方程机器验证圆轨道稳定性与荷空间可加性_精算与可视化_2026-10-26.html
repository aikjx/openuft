① Proca/Yukawa 场方程：机器验证 通过

自写精确微分引擎走「×r² → d/dr → ÷r²」：∇²V = K e^{−r/λ}/(r λ²) = V/λ² ⇒ ∇²V − V/λ² = 0，残差机器为 0。线性势复算 (∇²−1/λ²)(σr) = σ(2/r − r/λ²) ≠ 0 ⇒ 禁闭项确被排除（靶此处诚实）。但对靶有利的两条都要配一条限制： 「齐次」只在 r>0 成立，而该方程正被用于定义点粒子之间的力（r→0 处有 δ 源）。

② 圆轨道稳定性：解析判据（本卷核心）

有效势 U(r) = −μ e^{−r/λ}/r + h²/(2r²)；圆轨道条件 U′=0 ⇒ h² = μ e^{−x}(r²/λ + r)，代回二阶导得闭式

U″(r_c) = (μ e^{−x} / r_c³) · (−x² + x + 1)　，　x ≡ r_c/λ

稳定 ⟺ −x² + x + 1 > 0 ⟺ x < φ = (1+√5)/2 = 1.6180339887（黄金比）。 数值复核：闭式与直接二阶导在 8 个点上相对差 ≤ 6.135e-12，二分变号点 1.6180339887 与 φ 相对差 5.489e-16。

③ 荷空间可加性：判决项

四个 Q 是三种互不相容的数学对象：连续量（m/m_P）、离散整数×常数（√α·Z）、 普适耦合常数（g_W/√4π、g_π/√4π）。塞进同一个 Q₁Q₂ 意味着弱/强通道的力 不随物体身份变化——与实际弱相互作用（味/弱荷/手征）矛盾。 靶中「统一荷/总荷/合成荷/同时作用」命中 0 ⇒ 无法定义 Q_total² ⇒ 「把四力写进一个方程」在同一次相互作用的意义上不成立。
