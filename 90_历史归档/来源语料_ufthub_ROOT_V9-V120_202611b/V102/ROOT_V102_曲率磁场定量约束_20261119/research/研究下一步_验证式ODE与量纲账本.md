# V103 待攻坚的四项硬问题

1. **连续场周期轨道验证**：给有限截面电流源建立区间 Biot–Savart 误差，再用区间 ODE / Newton–Krawczyk 证明存在唯一或至少存在指定周期根；报告严格误差盒。
2. **非自交/结类型证书**：覆盖所有参数时刻，证明非邻接轨迹弧段间隔正；给出可靠的投影结图并算结多项式及可重现的拓扑同胚证据。单一“结行列式=9”不足以唯一确定结类型。
3. **带辐射源的闭环**：在点电荷辐射反作用、有界外源供电和感应电场中求周期吸引子，满足完整能量—动量收支、表面及远区辐射通量。
4. **协变与四力起源**：先写出无循环的 Lorentz/GR 协变局域作用量，检查规范群、手征性、异常抵消、标准模型的低能极限；在没有独立预言与实验验证前保持开放。
