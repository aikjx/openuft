## 9. 术语表（本卷口径）

| 术语 | 本卷定义/口径 |
|---|---|
| 有效场论窗口（EFT window） | SM 自洽（微扰 + 真空稳定或亚稳）的能量区间；Higgs 扇区由 Λ_I（下沿）与平庸性边界（上沿）夹成 |
| 真空稳定性 / 亚稳 | λ_eff(h)>0 直到 M_Pl ⇒ 绝对稳定；λ 在高能变负但 EW 真空仍是局域极小 ⇒ 亚稳（metastable） |
| 三层不稳定标度（文献口径） | ① Λ_V≡(max_h V_eff)^{1/4}（规范/方案无关，log₁₀(Λ_V/GeV)=9.5，Eq.67）；② Λ_λ≡λ(MSbar) 过零（方案依赖，≈2Λ_V）；③ Λ_I≡λ_eff(Landau) 过零（规范依赖，≈13Λ_V）。**本卷算 ②** |
| 非单调回升（本卷机读发现） | λ 过零后并非继续下降：高标 y_t 衰减 ⇒ β_λ 负驱动减弱 ⇒ λ² 项主导 ⇒ β_λ 变正，λ 触底回升（本卷机读触底 μ≈10^16–10^17 GeV；文献 §4.1：β_λ 于 10^17–10^18 GeV 消失，互为印证）。回升不改变亚稳判定 |
| 平庸性 / 平凡性（triviality） | 大场值下 λ 增长到非微扰（本卷约定 λ=π）或现 Landau 极点 ⇒ 上沿失效；临界质量 m_h^triv（H5） |
| 近临界性（near-criticality） | m_h 实测值靠近绝对稳定边界 ⇒ 高能行为对输入/圈阶/匹配指数敏感（本卷机读：敏感度 O(1)/GeV；Λ_λ 的 1→2 圈差即 1.455 dex） |
| 四操作点（本卷分解工具） | A_our = LO 匹配 @ 本卷输入；A_BM = LO 匹配 @ 文献锚点；B_BM = NNLO 匹配 @ 文献锚点（头条对标）；B_our = NNLO 匹配 @ 本卷输入。B3 用 A_BM 把「匹配差」从「输入锚点差」中隔离 |
| LO 树匹配（Case A） | λ(M_t)=m_h²/2v²、y_t(M_t)=√2m_t/v，pole 质量直接代入（文献 Table 3 LO 列） |
| NNLO 匹配（Case B） | 文献 2-loop 阈值修正后的 MSbar 匹配值直接代入（λ=0.12604、y_t=0.94018） |
| β 函数 / 跑动耦合 | β_θ=dθ/dlnμ；本卷 t=ln(μ/GeV)；文献 β_λ 于 10^17–10^18 GeV 消失（y_t 衰减致） |
| Machacek–Vaughan（MV） | 2-loop SM β 函数标准文献；本卷系数经 arXiv:1202.5717 附录 A 与 arXiv:1412.8230v1 双源互证（CT1 残差 2.7e-253） |
| Landau 极点 / 绕极点 | λ(μ)→∞ 的能标；固定步长 RK4 跨极点后 λ(M_Pl) 被甩成巨大值（正负不定）⇒ λ(M_Pl) 类判据在极区失效，H5 改用「λ 首触 π 的上穿谓词」 |
| 上穿探测器（crossing_up） | 轨迹上首次 f(state)>0 的定位（与「首次 ≤0」互补）；λ=π 的上穿必须用它——旧版把 λ=π 交给「首次 ≤0」探测器因 λ 起点恒 <π 而静默永返 None |
| z 距离（σ） | (m_h^crit−m_h)/σ；σ=1.5 GeV 取文献 Eq.65 合成值；本卷机读 z≈3.9σ（Case B 口径） |
| 攻破层判定约定 | 攻破条目 FAIL = 攻击命中（靶宣称被证伪/脆弱性被定价），PASS = 靶在声明阈值内幸存；与控制组/守卫的 PASS/FAIL 语义不同 |
| 规范纪元（gauge epoch） | 缓存防腐机制：规范输入全局量变化 ⇒ 纪元 +1 ⇒ 缓存键失效（防 α₃ 扰动命中陈旧条目） |
