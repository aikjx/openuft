# 第零章｜科研地位、问题定义与严格审计摘要

**版本：** ROOT V67，2026-11-17。**文献性质：** 面向独立复核的理论研究与计算手册，不是被同行评审接受的物理新定律，不是四力大统一成功公告。研究主题为“光速螺旋几何、微观量子场、引力来源及四种基本相互作用的可能统一”。

统一场论至少存在三种不同的“统一”含义。第一种是**表示统一**：把牛顿引力、Maxwell 电磁场、强弱规范场写进同一符号和计算框架。第二种是**动力学统一**：存在单一作用量和更大的对称性，低能展开产生各个已知方程。第三种是**解释与预测统一**：模型从不依赖待解释数据的公设出发，导出耦合强度、粒子谱、质量、混合参数、时空动力学和可事先测试的新结果。已知的 GR + 标准模型满足第一种；若加上充分明确的扩展场，部分满足第二种的形式要求；ROOT 目前没有达到第三种。

本卷会给出严格数学事实、条件下的场论推导、带参数的可运行模型及可证伪清单，特别修正以往版本中“数值重现 = 预测成功”“用角度代替规范荷”“光速相位等于有质量粒子速度”“用测得的 G 反求尺度再宣称计算出 G”的混淆。新进展还包括一圈标准模型规范耦合不交于同一能标的精确复算，以及单代标准模型规范异常抵消的有理数验证。这些分别是既有理论的数值与代数复现，不是本研究发现的新实验事实。

本书的标记固定为 `[MATH]` 纯数学定理；`[COND]` 在已明确物理作用量/边界/对称性下成立；`[EST]` 已确立理论；`[TOY]` 演示性假设；`[FIT]` 使用实验值反求；`[OPEN]` 没有证明；`[FAIL]` 与数学或实验冲突。这些标签适用于书、代码、CSV、图表和最终报告。

**主要结论：** 能从规范的微观场构造能动张量；给定引力理论时该张量构成引力源；在特定方案中，量子涨落可诱导曲率项；在五维圆形纤维度规中，坐标对称性体现一个四维 U(1) 规范结构。但是，从一个三维螺旋角独立推出 G、全部规范群、粒子表象和实验常数仍是未解决的问题。没有任何数学程序可把这些缺失的公设自动变成证明。
