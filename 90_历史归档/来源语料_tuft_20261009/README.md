## 三、关键判定依据（为什么这么分）

1. **`tuft/` 顶层大量文件其实已登记。** 20260919 根目录归集批已把 `my_lib/tuft/`
   当时的快照收进 [`来源语料_根目录_20260919/02_TUFT_来源/tuft/`](../来源语料_根目录_20260919/02_TUFT_来源/)。
   本批逐文件 SHA256 比对：
   - **28 个文件哈希完全一致** → 记「已登记」，不重复；
   - **5 个短文件是 R28 同步存根**（卷十九/二十/二十五/二十六 + 卷二十九较早修订版），
     文件内自注「正文与语料根版本一致，详见语料根副本」，全本在归档 → 记「已登记」；
   - **4 个等长复跑漂移产物**（report.txt / 覆盖矩阵.json）同名条目已归档，仅内容为脚本复跑再生 → 记「已登记」。
2. **`tuft/` 的 9 个字母前缀子目录是 20260919 之后新增**（F_FDTD/G_BSSN/H_CMB/I_LaTeX/
   J_Rust/K_KnowledgeGraph/M_Docker/N_Supplemental/soliton_v3），归档里没有 → 新登记。
   内容均为 TUFT 数值/工程束（FDTD/BSSN/CMB/LaTeX/Rust/知识图谱/Docker/孤子），
   线索指向 S14（挠率统一场论TUFT）/ S16（TUFT归一化主册）生态，但**未自动并入**，待人工裁定。
3. **`tuft-theory/全域双向分形统一场论.html` 归属明确为 S13**（全域双向分形统一场论），
   且 ≤5 MB、S13 文献来源区原本只有占位 README、全仓检索无同名文件 → **本批唯一实际复制件**，
   复制进 `01_独立体系/S13_全域双向分形统一场论/01_文献来源/`，原名保留，源文件原位未动。
