## E1 观测事实

- GR 无质量自旋-2 引力子含 2 个张量极化；Fierz-Pauli 有质量自旋-2 含 **5 个极化**（2 张量 + 2 矢量 + 1 标量），多出的标量模在静态源通道直接耦合。
- 太阳系观测：GR 势 `V_GR = −GM/r`、GR 光线偏折 `δ_GR`（引用，不复算）。vDVZ 裸极限给出的 4/3 倍势与 3/4 倍偏折均与太阳系观测冲突（vDVZ 1969；Will 2014）。
- 注记：Vainshtein 机制在非线性区恢复 GR，仅作背景注记，本件不计算。

## E2 核心公式第一性推导 + 精算

Fierz-Pauli 线性化有质量作用量（标准推导，vDVZ 1969）：静态源通道中标量模与张量模同相位叠加，引力势增强 1/3；光子只耦合张量迹，标量模贡献不进入光线偏折。

```
V_massive(r) = −(GM/r)(1 + 1/3) e^{−mr} = −(4/3)(GM/r) e^{−mr}
m→0 ⇒ V_massive → −(4/3) GM/r        （V/V_GR = 4/3）
δ_massive = (3/4) δ_GR                （光子不耦合标量模）
偏折缺额 |δ/δ_GR − 1| = 1/4 ≠ 0
```

## E3 解析求导验证（用户指定「极限存在 ≠ 连续」线）

```
f(m) = e^{−mr}
df/dm = −r e^{−mr}                         （Yukawa 因子闭式导数）
dV/dm = −(GM/3) r e^{−mr}                  （Yukawa 修正项导数，GM=1、r=1e10 演示值 = −3.3333333333e9）
```

- 250 位数值互验：中心差分（h=1e-120）与闭式 `−r e^{−mr}` 之差 = 2.00494e-132 < 1e-100 ✓。
- **不连续判据（核心）**：

```
lim_{m→0} δ(m) = (3/4) δ_GR  ≠  δ_GR(0) = δ_GR
```

  函数在 m>0 一侧的极限存在（Yukawa 因子导数有限、极限值 3/4 δ_GR 确定），但该极限不等于无质量 GR 分支在 m=0 的值 δ_GR —— **极限存在 ≠ 连续**。势通道同理：lim V = −(4/3)GM/r ≠ −GM/r。两条通道在 m=0 处发生 vDVZ 跳变。
