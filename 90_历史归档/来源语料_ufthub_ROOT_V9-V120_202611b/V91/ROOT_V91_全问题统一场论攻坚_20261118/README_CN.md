## Windows 解压后一键复算

安装 Python 3.10+，双击 `RUN_WINDOWS.bat`；或者在该目录命令行执行：

```bash
python -m pip install -r requirements.txt
python run_all.py
```

Linux/macOS 执行：

```bash
sh RUN_LINUX_MAC.sh
```

仅做符号／测试：`python src/symbolic_audit.py` 和 `python -m unittest discover -s tests -v`。

`run_all.py` 将自动重建台账、符号校核、100 位高精度与理论图表，执行 V91 单元测试，并在临时文件夹解压 **ZIP 中原样 V90**，重新执行 V90 的 65 项测试。无真实仪器或云服务依赖；首次安装依赖可能需要联网。

## 新数学定理（条件必须明确）

- 对 μ=1/λ、`d>(a+b)/2`，`dF_Y/dμ=4e^(−μd)sinh(μa/2)sinh(μb/2)>0`；所以 `F_N<F_Y<0`。
- 对全部正 λ 有 `0<F_Y−F_N≤ab/(3λ³)`，以及依赖 d 与最小分支距离的更紧上下界。
- 若背景有未知 p 次多项式距离项、同一 a,b 且几何固定，长程 Yukawa 可分离信号最多从 `λ^{−(p+4)}` 开始；其幅度 Fisher 信息最多按 `λ^{−2(p+4)}` 级别缩小（固定协方差等必要前提）。
- 电荷反向不能从同为 `1/r` 形状的**电荷偶背景**中自动辨别 Newton 幅度；须独立校准。

## 证据与局限

所有扫描、相位、Fisher 和模拟噪声均为 THEORETICAL 或 SYNTHETIC。大量自动化检查可发现错误但**不是物理实验，也不说明理论正确描述宇宙**。本包没有发明已验证的新力、没有无自由参数推导 G、没有完成标准模型和引力量子高能统一。
