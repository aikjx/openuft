## 〇、结论先行

**纯空间几何难派生 α**（张力 T1/T2）；α 更可能来自 QED 型 UV 调节（与 C0092 重定位一致——反常磁矩已归 QED）。本框架给出合法 α 派生的充分条件清单 **A1–A6** 与诊断目标量 **D1–D4**；满足 A1–A6 且复现 D1–D4 的作用量 `U_Q(ρ)` 即合法预言 α。

## 一、约束 A1–A6（候选 U_Q(ρ) 必须同时满足）

| # | 约束 | 说明 |
|---|---|---|
| A1 | 静态解存在性 | E-L 稳定点给两尺度晕轮廓（exp 尾）或相容；能量有下界 |
| A2 | 无 α 调参 | 不含为凑 α=1/137 设的无量纲自由参数；耦合由作用量自身固定 |
| A3 | 质量一致性 | Mc²=M_core c²+U_EM；自能为明确定义占比（兼容 C0089 4.28% 张力） |
| A4 | 点状电形状因子（C0091 硬约束） | 电子尺度电 F≈1；电荷有效半径 ≪ λ_C |
| A5 | 涌现尺度 | 晕尺度由 λ_C=1/M 涌现（C0081）；自能不改变 M 物理定义 |
| A6 | 可检验预言 | 至少给一个与 α 独立可测的量（c_geom、UV 调节函数）供证伪 |

## 二、诊断目标量（候选作用量须复现）

| # | 目标量 | 值 |
|---|---|---|
| D1 | 电磁自能占比 U_EM/Mc² = c_geom·α | 5.87·α ≈ 4.28% |
| D2 | 点状电约束：电有效半径 r_E | 需 < ~1e-19 m（实验上限 1e-18 m）；λ_C=3.86e-13 m ⇒ 差 ~6 量级 |
| D3 | 质量分离：裸核 M_bare | M_e(1−5.87α)=0.957·M_e=8.72e-31 kg |
| D4 | 涌现尺度 | λ_C=1/M=3.86e-13 m；g=2 涌现 |

## 三、张力（为什么难）

- **T1**：A4（点状电） vs 自能来自空间分布——点状电荷自能发散 ⇒ 需 UV 调节（核尺度 l_P~1.6e-35 m）⇒ 即重整化。
- **T2**：A2（无调参） vs 固定 α——含耦合常数的作用量总有调 α 自由，除非耦合由更深原理固定。

## 四、结论与登记

1. 纯空间几何难派生 α（T1/T2）；α 更可能来自 QED 型 UV 调节。
2. 合法 α 派生 = 满足 A1–A6 且复现 D1–D4 的作用量 U_Q(ρ)。
3. 诚实分级：框架为 `axiomatic / structural`（无虚构预言）；T1/T2 为 `tension_analysis`；D1–D4 为 `numerical_check`。
