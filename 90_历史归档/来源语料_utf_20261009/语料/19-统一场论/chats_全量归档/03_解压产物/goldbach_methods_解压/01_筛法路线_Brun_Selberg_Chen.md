# 筛法路线：Brun / Selberg / 陈氏定理

> 对应总览 M1, M2, M3。筛法是哥德巴赫猜想研究中历史最悠久、结果最具体的路线，但存在**奇偶性障碍**这一根本限制。

---

## M1. Brun 纯筛法（1919）

### 原理

Viggo Brun 发明组合筛法，用于估计区间中满足若干同余条件的整数个数。对哥德巴赫问题，考虑集合

$$A = \{n(N-n) : 1 \leq n \leq N\}$$

需要估计其中**两个因子均为素数**的 $n$ 的个数。用筛法去掉所有使 $n$ 或 $N-n$ 有小素因子的 $n$。

### 关键公式

Brun 筛的基本形式：设 $A$ 为有限整数集，$P$ 为素数集，$S(A,P,z)=\#\{a\in A:p\nmid a\ \forall p<z\}$，则

$$S(A,P,z) = X\prod_{p<z}\left(1-\frac{\omega(p)}{p}\right)(1+O(e^{-s})) + O\left(\sum_{d|P(z)}3^{\nu(d)}|R_d|\right)$$

其中 $s=\log z/\log w$ 为筛参数，$R_d$ 为余项。

### 已证结果

- **上界**：$r_2(N) \leq C \cdot \frac{N}{\log^2 N}$（$C$ 为绝对常数）
- **Brun 定理**：孪生素数的倒数和收敛（$\sum_{p,p+2\in\mathbb{P}}1/p < \infty$），同理哥德巴赫素数对的倒数和收敛
- 这是历史上首次证明素数对的"稀疏性"

### 未闭合卡点

- **只有上界，无下界**。筛法的组合性质使其天然擅长"不超过多少"，不擅长"至少多少"
- 余项 $R_d$ 的累积在 $z$ 较大时失控，无法将筛水平推到 $\sqrt{N}$

## M2. Selberg 上界筛（1947）

### 原理

Atle Selberg 用二次型优化取代 Brun 的组合取舍，得到最优上界。引入权重 $\lambda_d$，满足

$$\sum_{d|n}\lambda_d \geq \mathbf{1}_{n=1}$$

则

$$S(A,P,z) \leq \sum_{a\in A}\left(\sum_{d|(a,P(z))}\lambda_d\right)^2$$

通过最小化二次型得到最优 $\lambda_d$。

### 关键公式

Selberg 筛的最优权重：

$$\lambda_d = \mu(d)\frac{\left(\sum_{d_1d_2\ldots}\frac{1}{g(d_1d_2\ldots)}\right)^{-1}}{\prod_{p<z}(1-g(p))}$$

其中 $g(d)=\prod_{p|d}\frac{\omega(p)}{p-\omega(p)}$。

对哥德巴赫问题，$\omega(p)=2$（$p\nmid N$）或 $\omega(p)=1$（$p|N$），得到：

$$r_2(N) \leq 16\,\mathfrak{S}_2(N)\frac{N}{\log^2 N}(1+o(1))$$

其中 $\mathfrak{S}_2(N)$ 为奇异级数（见圆法文档）。

### 已证结果

- 精确的上界常数（16 倍于猜想的主项）
- 筛法理论的基础工具，被后续所有筛法工作使用

### 未闭合卡点

- **仍为上界**。Selberg 筛本质是上界筛，无法给出正下界
- **奇偶性障碍的雏形**：筛法无法区分"恰好 1 个素因子"和"恰好 2 个素因子"

## M3. 陈氏定理 "1+2"（1966 宣布，1973 全文）

### 原理

陈景润结合 Kuhn 加权筛与 Jurkat-Richert 筛，证明每个充分大偶数可表为一个素数与一个**至多两个素因子之积**（记为 $P_2$）之和。

**加权筛的核心思想**：不直接筛出 $n$ 和 $N-n$ 均为素数的 $n$，而是筛出 $N-n$ 至多有 2 个素因子的 $n$。通过给不同素因子个数的整数赋予不同权重，绕过部分奇偶性障碍。

### 关键公式

陈氏定理的精确表述：存在 $N_0$，对所有偶数 $N>N_0$，

$$r_{1,2}(N) = \#\{p : p\leq N,\ N-p = P_2\} > 0$$

更精确的下界：

$$r_{1,2}(N) \geq 0.67\,\mathfrak{S}_2(N)\frac{N}{\log^2 N}$$

### 证明结构（五步）

1. **大筛法**：估计 Bombieri-Vinogradov 型均值定理，控制余项
2. **Jurkat-Richert 筛**：处理主项，得到 $N-p$ 无小素因子的 $p$ 的个数
3. **Kuhn 权重**：引入权重 $w(n)=\sum_{p|n, p\leq N^{1/10}}1$，区分素因子个数
4. **Switching Principle（转换原理）**：陈景润的独创技巧——将某些 $P_2$ 的计数转换为另一种形式，避免直接估计
5. **下界合成**：加权后证明剩余集合非空

### 已证结果

- **充分大偶数 = 素数 + 半素数**（$P_2$）
- 这是筛法路线在哥德巴赫问题上的**最强结果**，至今无人超越
- 方法被推广到孪生素数问题（Chen 定理的孪生版本）

### 未闭合卡点 —— 奇偶性障碍

**奇偶性障碍（Parity Barrier）**是筛法理论中的根本限制：

- 纯筛法只能确定一个整数的素因子个数的**奇偶性**，不能区分"恰好 1 个"和"恰好 2 个"
- 形式化表述：设 $A$ 为区间 $[x,2x]$ 中无小于 $x^{1/2}$ 素因子的整数集，则 $A$ 中素数个数与 $P_2$ 个数在筛法看来是"不可区分的"
- 陈景润用加权筛部分绕过了这个障碍（降到 $P_2$），但**无法进一步降到素数**
- 普遍认为：**纯筛法不可能证明哥德巴赫猜想**，需要本质上的新思想

> **【OPEN-1】** 能否突破筛法奇偶性障碍？当前共识是需要筛法之外的新工具（如圆法的实质性改进、或代数几何方法），但具体路径未知。

## 筛法路线小结

| 方法 | 年份 | 结果 | 类型 |
|------|------|------|------|
| Brun 筛 | 1919 | $r_2(N)\ll N/\log^2 N$ | 上界 |
| Selberg 筛 | 1947 | 常数 16 的精确上界 | 上界 |
| 王元 | 1956 | "3+4" | 逼近 |
| 王元 | 1962 | "1+4" | 逼近 |
| 潘承洞 | 1962 | "1+5" | 逼近 |
| 巴尔巴恩 | 1963 | "1+5"（独立） | 逼近 |
| 陈景润 | 1966/1973 | **"1+2"** | 最强筛法结果 |

从 "a+b" 到 "1+2" 花了近 50 年，而从 "1+2" 到 "1+1"（即哥德巴赫猜想本身）已过去 50 年仍无进展——这本身就是奇偶性障碍的证据。
