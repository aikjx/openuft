## 一、一句话判决

> **`16` 里只有一个 SM 单态（右手中微子 `ν^c`），而 `16` 能分辨自对偶 `J` 与反自对偶 `K` —— 这是 r396 那条「边界」的解除。**
>
> - `Cl(10,0)` 的最小表示是 **32 维**（10 个 Hermitian `Γ`，55 对 Clifford 关系违例 0）；`16` **不是** Clifford 模，只是 `so(10)` 的模 —— 它是被手征算子 **投影**出来的（A1 / A2）；
> - 手征算子 `CHIR = −i·Γ₁⋯Γ₁₀` 在本基下**对角**，±1 各 **16** 维，且 `CHIR² = 1`、虚部和 0、非对角和 0 ⇒ 可以用「取子矩阵」代替「求本征矢量」，避开了「本征矢量归一化带根号」这个精确算术的破口；
> - 45 个 `Σ_ab`（归一化 **1/4**）实化后全部反对称、秩 **45**、**990 对**换位子与「向量表示里的换位子系数」逐元素一致（A3）；
> - SM 的 12 个生成元在 32 维实旋量空间上秩 **12**、全部反对称（A4）；
> - 解 `X v = 0`：**384 行 × 32 列**，秩 **30**，实零空间 **2** 维 ⇒ 复单态 **1** 维（A5）；
> - 这个单态被 12 个 SM 生成元**全部**熄灭（12/12），但 45 个 `Σ_ab` **基元素**里逐个熄灭它的有 **0** 个；熄灭子空间（核）= 45 − 轨道秩 **21** = **24** 维 ⇒ 它是「SM 单态、但不是 `so(10)` 单态」（A6）；
> - `Y` 的幂和 `p₁..p₅` 与分解表多重集的**逐项一致**（A7）；
> - **核心争点**：同一手征块内 `su(2)_J` 给 **2** 个实方向、`su(2)_K` 给 **0** 个 ⇒ **`16` 能分辨** `J` 与 `K`；而 `p_k` **四格全同**、**手征块不改读数**（A8 / K1）；
> - 两步阶梯：只用 `45` 的约束秩 **32** ⇒ 稳定子 **13**；再加 `X v = 0` 的 32 行，秩只到 **33** ⇒ 复合稳定子 **12 = `G_SM`**。r396 说的「差 1 个 `u(1)_{B−L}`」，机核形态就是这一个 **+1**（A9）。

★ 本卷**不产生**新物理预言。它做的是一件更窄的事：把 r396 §十四 留下的两个待办 —— 「`16` 的单态维数」与「两步够不够」—— 变成两组可复算的秩，并顺手解除了 r396 K2 那条边界（`10/45/54` 分不出 `J`/`K`，`16` 分得出）。

## 三、地基一：为什么必须是 32 维（A1）

`Cl(10,0)` 的不可约表示维数是 32。构造：取 5 对 2×2 因子（`C1 = (σ₁,0)`、`C2 = (0,iJ) = σ₂`、`C3 = (σ₃,0)`），把 10 个 `Γ` 写成 5 重张量积，每个因子位置上放 `C3` 或某个 `C1/C2`：

```
Γ_{2j+1} = C3 ⊗ … ⊗ C1 ⊗ … ⊗ I     （第 j 位放 C1）
Γ_{2j+2} = C3 ⊗ … ⊗ C2 ⊗ … ⊗ I     （第 j 位放 C2）
```

读数：

```
维数 32；Hermitian = True；Clifford 对数 55；违例 0
```

★ 55 = `C(11,2)`：含 `a = b` 的 10 对（要求 `{Γ_a,Γ_a} = 2`），加 45 对 `a < b`（要求 0）。**全部逐元素验证，不抽查**（G11 另行核对「45 个基去重后 45、换位子对数 990 = C(45,2)」）。

★★★ 本卷第一处「不能想当然」：我第一版用 4 个 2×2 因子搭 16×16 的 `Γ`，得到 **19/55 违例** —— 因为 4 个因子只给 16 维，而 `Cl(10,0)` 的最小表示是 32 维。**`16` 不是 Clifford 模**，它是 `so(10)` 的模，靠手征投影从 32 里切出来。这个错在「数量上看着很像对的」（16 正是我们要的那个数），只有把 55 对全算一遍才会露出来。

## 四、地基二：`16` 是投影出来的（A2）

```
CHIR = (−i)·Γ₁⋯Γ₁₀
读数：对角谱 {−1, +1}；+1 维数 16；−1 维数 16；非对角和 0；虚部和 0；CHIR² = 1 是 True
```

★★ 「非对角和 = 0」是这一条真正的价值，不是「16 维」那两个数。因为 `CHIR` 在本基下**对角**，取 `+1` 的本征空间就等于「取那 16 个下标对应的子矩阵」：

```
PLUS  = {i : CHIR[i][i] = +1}      （16 个）
MINUS = {i : CHIR[i][i] = −1}      （16 个）
Sigma|16 = restrict(Sigma, PLUS)   ← 不需要求本征矢量
```

★ 若 `CHIR` 不对角，就必须求本征矢量，而本征矢量带 `1/√2` 这类根号 ⇒ 整个「纯 `Fraction`、零浮点」的框架当场破掉。这一步省下的不只是时间，是**精确算术的可行性本身**。

★ 45 个 `Σ_ab` 全部与 `CHIR` 交换（这是 `Σ` 属于 `so(10)` 的必然结果），所以限制到 `PLUS` 是良定义的 —— 本卷用「抽查块无泄漏 + A3 的秩 45」两道读数代替了「逐对验证 45 个都交换」这条更贵的检查，**这一点在诚实边界里认领为「未逐对验证」**。

## 五、45 个生成元的实化与闭合（A3）

```
Σ_ab = (1/4)[Γ_a, Γ_b]，限制到 PLUS（复 16×16），再实化成 32×32 实矩阵：
[[R, −I], [I, R]]      ← −I 是关键：反 Hermitian ⇒ 实化后反对称
读数：反对称 = True；秩 = 45；换位子对数 990；不一致 0
```

★★ 闭合性**不是引结构常数**，而是两条不同对象的路径对拍：

1. 在**向量表示**（10×10）里真算 `[E_ab, E_cd]`，把结果展开成系数 `coef`；
2. 用**同一组** `coef` 线性组合复 16×16 的 `Σ`；
3. 与**直接**算的 `[Σ_ab, Σ_cd]` 逐元素比。

990 对全部一致 ⇒ 「这 45 个矩阵确实是 `so(10)` 在 `16` 上的表示」。★ 这是两个不同维数的对象（10 维向量 / 16 维旋量）走同一条系数 —— 若系数写错，一条腿会立刻歪掉。

★ 归一化是 **1/4** 而不是 1/2：`[Γ_a,Γ_b]` 给 4·M，除 4 才得 M。写成 1/2 时 `p₁ = 40/3`（正确 `10/3`，恰 4 倍）—— 这条错被保留为控制组 K4。

## 六、`16` 只有一个 SM 单态（A5）

12 个生成元（`i·λ_a` 实化到 `C³ = R⁶` 嵌 1..6 号指标；`so(4)` 自对偶支嵌 7..10；`Y = −(1/3)U_a + (1/2)U_k`）叠成 `12 × 32 = 384` 行：

```
384 行 × 32 列；秩 = 30；实零空间 2 维 ⇒ 复单态 1 维
```

★★★ 本卷第一个「对象错位」风险点：`16` 是**复**表示，我算的是**实** 32 维零空间。复单态 `v` 与 `i·v` 是两个实方向 ⇒ 实维数必为**偶**，除以 2 才是复维数。把 2 当 1 报（或把 4 当 1 报）都会「看起来对」，而且**任何数值守卫都不会红**。所以：

- 判据写成 `_d_J % 2 == 0 and _d_J // 2 == 1`（先查偶性，再除 2）；
- 另有一条独立路径 G12：不做投影、直接在 64 维 Dirac 上解，得 **4**，÷2 块 ÷2 复 = 1。

★ 期望的「1」不是猜的：它由 A7 的谱独立支持（16 的多重集里恰好只有一个 `y = 0`）。

## 七、它是 SM 单态，但不是 `so(10)` 单态（A6）

对 A5 给出的那个单态 `v`，逐个手算 `Σ_ab · v`：

```
Y v = 0 是 True
12 个 SM 生成元里熄灭它的：12 个
45 个 Sigma 基元素里逐个熄灭它的：0 个        ← 全卷信息量最大的读数
轨道秩（45 个 Σ_ab·v 张成的维数）= 21
熄灭子空间（核）= 45 − 21 = 24 维
```

★★★ 第三条与第一条**看起来矛盾**：12 个 SM 生成元都熄灭它，可 45 个**基元素**里一个都不熄灭它。答案很简单也很重要：那 12 个是**线性组合**（例如 `Σ₁₂ − Σ₃₄`），不是基元素。所以正确的问题是：

> 不是「哪些生成元熄灭它」，而是「熄灭它的**子空间**有多大」。

★★ 24 这个数落在 `[12, 45)` 内，正是「SM 单态、但 `so(10)` 不单态」的精确形态：

| 核的取值 | 含义 | 本卷 |
|---|---|---|
| 45 | 平凡单态（整卷空转） | 否 |
| **24** | **SM 单态、非 `so(10)` 单态** | **是** |
| 12 | `so(10)` 纯单态（`16` 里不存在） | 否 |

★★ 第二处「不能猜」：第一版把期望写成「轨道秩 = 32（满维）」，实测 **21**。原因：`16` 里的一个向量不可能被 `so(10)` 在 32 维实空间里推满 —— 它是纯旋量，轨道远小于全空间。**猜满维是「把上界当期望」的典型错误**；改法是只报核维数落在区间内 + `kill_sm == 12`，不去猜轨道本身。

## 八、`Y` 的幂和与分解表多重集（A7）

```
p₁..p₅ = 10/3, 95/54, 2525/1944, 78755/69984, 2655545/2519424
预测   = 同上（由多重集求和）
多重集维数和 = 16
```

多重集（`16` 的 SM 分解）：`6×(1/6) + 3×(−2/3) + 1×(1) + 3×(1/3) + 2×(−1/2) + 1×(0)`，维数和 `6+3+1+3+2+1 = 16`。

★★ 两条路**不同源**：

- 左边 `p_k = (−1)^k · tr(Y^{2k}) / 2`，来自 **32×32 实矩阵幂的迹**（`Y` 实反对称 ⇒ 本征值 `±i·y` ⇒ `tr(Y^{2k}) = 2(−1)^k Σ y^{2k}`）；
- 右边 `Σ n·y^{2k}`，来自**多重集直接求和**。

★ 为什么用迹而不用本征值：本征值要开根号，会破精确算术；迹只做加减乘除。

★ 手算一个对齐（不是代码）：
`p₁ = 6/36 + 3·(4/9) + 1 + 3·(1/9) + 2·(1/4) = 20/6 = 10/3` ✓；
`p₂ = 6/1296 + 3·(16/81) + 1 + 3·(1/81) + 2·(1/16) = 380/216 = 95/54` ✓。

★★ 第一版**漏了 `e^c`（`y = 1`）这一项**，维数和只有 15 —— 是「维数和必须 = 16」这条自查把它抓出来的，不是 p_k 对不上（漏一项时 p_k 会**一起错**，两条路仍然一致！）。这是「两条路同错则同时绿灯」的又一例。

★ 幂和只定 `|y|`，**不定符号**。符号（更准确说：手征信息）不在谱里，见图 3 / A8。

## 九、核心争点：`16` 能分辨 `J` 与 `K`（A8 / K1）

r396 的 K2 说：`10 / 45 / 54` 都是（自共轭的）张量表示，`J₃ → K₃` 换法读数**一律不变** ⇒ 「哪个 `su(2)` 是弱作用」在这些表示上**不可见**。本卷换成 `16` 再问一次。

四格读数（`{16, 16bar} × {J, K}`，每格是实零空间维数）：

```
{'+J': 2, '+K': 0, '-J': 2, '-K': 0}
同一手征块内 J vs K = 2 vs 0（复 1 vs 0）⇒ 不同 = True
手征块不可见（J 跨块同、K 跨块同）= True
p_k 四格全同 = True（Y 谱对 J/K 与手征块皆不变）
```

★★★ 所以：**`16` 能分辨 `J` 与 `K`**。`su(2)_J` 定义的 SM 在 `16` 里有一个单态（`ν^c`），`su(2)_K` 定义的 SM 一个都没有。

★★★ 但**分辨力的来源**必须说准，这是本卷改了两轮才改对的一处（见 §十三 E09）：

- 分辨**不**来自 `Y` 的谱（`p_k` 四格**全同**，因为 `[Y, su(2)] = 0` 无论取 `J` 还是 `K` 都成立，16 个本征值由 `16` 的 SM 分解固定）；
- 分辨**也不**来自「`16` 与 `16bar` 不等价」（手征块对这些计数**根本不改**：`J` 在两块都得 2、`K` 在两块都得 0）；
- 分辨来自 **`Y` 与哪一个 `su(2)` 占用同一条不变量空间**。K1 的证据：单用 `su(2)` 两档都给 **16**（分不开），**加上 `Y`** 才分成 2 与 0。

K1 的九格表（`16` 与 `16bar` 逐格相同，**0 格不同**）：

| 子代数 | `su(3)_C` | `su(2)_J` | `su(2)_K` | `u(1)_Y` | `su(3)+Y` | `su(2)_J+Y` | `su(2)_K+Y` | `su(3)+su(2)_J` | `su(3)+su(2)_K` |
|---|---|---|---|---|---|---|---|---|---|
| 单态维数（实） | 8 | 16 | 16 | 2 | 2 | **2** | **0** | 4 | 4 |

★ 判别力自证：`su(3)_C` 给 8、`su(2)` 给 16、`u(1)_Y` 给 2 —— 三档互不相同，说明这不是一张空表。

★ 机制（**认领，不是本卷的推导**）：把 `16` 看成复 `8 + 8`，`V_J` = `su(2)_J` 的不变量空间、`V_K` = `su(2)_K` 的不变量空间，两者互补；`ν^c`（唯一的 `y = 0`）落在 `V_J` 而不在 `V_K` ⇒ 加 `Y` 后 `J` 档剩 1 维、`K` 档剩 0 维。本卷**没有**构造 `V_J` / `V_K` 的显式基，所以这段是解释，不是证明。

## 十、两步阶梯：`13 → 12` 的机制是「秩 +1」（A9）

```
未知量 45（X 在 so(10) 里的系数）
约束 1：[X, M45] = 0    → 45 行（行 = 坐标 b'，列 = 基 b），秩 32 ⇒ 稳定子 13 维
约束 2：X v = 0（v 是 A5 的零空间基）→ 32 行
合并：77 行，秩 33 ⇒ 复合稳定子 12 维（只多熄灭 1 维）
```

★★★ 三条读数都是**独立算出来的**，没有一条从 r396 的 13 反推：

1. `45 − 32 = 13` —— 与 r396 的 `45(2,1)` 读数**互印**（两卷不同对象、不同约束矩阵写法，给同一个 13）；
2. `45 − 33 = 12` —— 复合稳定子；
3. **`33 − 32 = 1`** —— r396 §八 说的「差 1 个 `u(1)_{B−L}`」，在本卷机核里的精确形态就是**秩的增量 +1**。它不是「13 减 12 算出来的那个 1」，而是「加 32 行只让秩涨 1」这个独立读数。

★ 这一个 +1 还是一条**好的判别力来源**：若 `v` 或 `M45` 写错，最可能的表现是增量变成 **0**（那意味着 SM 已经是稳定子，与 r396 的判负矛盾）或 **> 1**（意味着第二个约束多杀了东西）。

★★ r396 判词里的 `TWO-STEP-NEEDED` 在本卷**升级为已算事实**：`Stab(v₄₅) ∩ Stab(v₁₆)` = 12。★ 但要说准范围：本卷证明的是「以这两个具体的 VEV 做两步，交恰好是 12」，**不是**「任意两步可行」，也不是「12 之后的破缺」。

★ r396 E01 的同一个坑（约束矩阵**行 = 坐标、列 = 基**）本卷从一开始就按这个顺序写，`_cols1` / `_rows1` 分两个变量名。

★ 我第一版做的负对照是「把 `realify` 的 `−B` 写成 `+B`」，实测**反对称 4/12、零空间仍 2** ⇒ 控制组恒 FAIL，因为那个错根本不影响单态数；第二版「强行对称化」直接算不动。**换成本卷真实犯过的错（归一化）才既有效、又有教学价值**。

## 十四、诚实边界（六条）

1. **本卷只做计数与谱**：单态维数、`Y` 的幂和、复合稳定子维数。**不碰**质量谱、Yukawa、混合角、重整化群。
2. 「`16` 能分辨 `J`/`K`」是**在已算的读数上**的结论，**不是定理**：本卷没有证明「不存在任何不可分辨的不变量」。它的硬核只有一句：**同一手征块内 `su(2)_J` 给 2、`su(2)_K` 给 0**。
3. **手征块对单态计数不可见**（`J`、`K` 各自跨块不变，9 格表 0 格不同）是本卷的**读数**；本卷**没有**构造显式共轭算子，也**没有**用它推出任何等价性。早先把这条读成「`16bar` 等价于把 `J` 换成 `K`」是**错的**（§十三 E09），已撤回。
4. `Y` 的幂和只定 `|y|` 的多重集、**不定符号**；且 `p_k` **四格全同** ⇒ 手征/符号信息**不在谱里**，只在「哪些态被熄灭」里。
5. §九 的机制（`16` = `V_J ⊕ V_K`、`ν^c ∈ V_J`）是**认领**，不是本卷的推导；本卷**没有**构造 `V_J` / `V_K` 的显式基。
6. 那个 24 维核里，除已确证的 12 维 SM 之外还剩 12 维，本卷**不认领**它们是什么子代数。

★ 第 2 条是最重要的一条：**本卷的正面结论（能分辨）是硬的，它的「解释」是软的。**
