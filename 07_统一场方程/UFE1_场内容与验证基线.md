# UFE-1 场内容与验证基线（00_统一场方程 锚点）

## 1. 场内容（UFE-1 = ECSK + SM + 3ν_R）

- **引力扇区（ECSK）**：以 Cartan 结构方程表述的 Einstein–Cartan–Sciama–Kibble
  引力，含自旋-挠率耦合；规范群因子 SO(1,3)。
- **规范扇区（SM）**：SU(3)×SU(2)×U(1)_Y 规范场 + Higgs 双重态。
- **费米扇区**：三代夸克与轻子 + **3 个右手中微子 ν_R**（SU(3)×SU(2) 单态、Y=0，
  对五类规范反常贡献为零）。
- 规范群为直积：$G = SO(1,3)\times SU(3)\times SU(2)\times U(1)$；参数 26 个（19 SM 内核 + 7 ν 扇区）。

## 2. 拉氏量结构（卷II ch08 展开）

$$
\mathcal L = \mathcal L_{\rm ECSK}(e,\omega,\psi) + \mathcal L_{\rm SM}(A,W,B,H,\psi) + \mathcal L_\nu(\nu_R, H),
$$
ECSK 部分以 vierbein $e^a{}_\mu$ 与自旋联络 $\omega^{ab}{}_\mu$ 表述，
挠率 $T^a = de^a + \omega^a{}_b\wedge e^b$ 通过自旋密度代数性耦合（ch07/ch09 展开）。
