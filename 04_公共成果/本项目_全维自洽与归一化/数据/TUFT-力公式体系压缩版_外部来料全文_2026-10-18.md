下面把“力的**起源、本质、本源、大小、距离标度、方向**”压缩成一套可直接引用的公式体系，并给出论文框架下的**统一场论方程**。记号：\(\mathbf V\) 为螺旋时空本体场，\(Q_t\) 为拓扑荷，\(\mathbf A=\nabla_{\mathbf V}\mathbf V\)，\(m_i=k_iQ_t\)，\(m_g=k_gQ_t\)，\(m_0=k_mQ_t\)。

---

## 1. 五层本质—本源公式

### ① 力的本源：光速范数螺旋场

\[
\boxed{
\mathbf V=r\omega\,\mathbf e_\theta+v_z\mathbf e_z,\qquad
|\mathbf V|^2=(r\omega)^2+v_z^2=c^2
}
\tag{1}
\]

这是最终本源：空间本体是范数恒为 \(c\) 的螺旋矢量场。\(\omega\) 是螺旋场自身角向角速度，\(c\) 是真空光速。

### ② 力的起源：拓扑奇点产生拓扑荷

\[
\boxed{
Q_t=\frac{1}{4\pi}\oint_S\mathbf V\cdot d\mathbf S,
\qquad
\nabla\cdot\mathbf V=0\ \text{（除奇点外）}
}
\tag{2}
\]

\(S\) 包围单个拓扑奇点，通量不为零，形成拓扑荷。质量、引力、惯性都从 \(Q_t\) 读出。

### ③ 力的本质：拓扑荷对协变加速度的耦合

\[
\boxed{
\mathbf F=k_iQ_t\,\nabla_{\mathbf V}\mathbf V
=m_i\mathbf A
}
\tag{3}
\]

力不是外加“拉拽”，而是拓扑荷 \(Q_t\) 在螺旋场流线上对协变加速度 \(\mathbf A=\nabla_{\mathbf V}\mathbf V\) 的耦合响应。若 \(k_i=k_g=k_m\)，则

\[
\boxed{
\mathbf F=m_0\mathbf G=k_mQ_t\nabla_{\mathbf V}\mathbf V
}
\tag{4}
\]

等效原理由 \(k_i=k_g\) 导出，而非独立公设。

### ④ 力的大小

\[
\boxed{
F=k_iQ_t\,|\mathbf A|
=k_iQ_t\sqrt{(\nabla_{\mathbf V}\mathbf V)\cdot(\nabla_{\mathbf V}\mathbf V)}
}
\tag{5}
\]

弱场柱坐标分量：

\[
\boxed{
A_r=-r\omega^2,\qquad
A_\theta=r\dot\omega,\qquad
A_z\approx-\frac{r^2\omega}{c}\dot\omega
}
\tag{6}
\]

\[
\boxed{
F=\sqrt{F_r^2+F_\theta^2+F_z^2},\quad
F_r=k_iQ_tA_r,\ F_\theta=k_iQ_tA_\theta,\ F_z=k_iQ_tA_z
}
\tag{7}
\]

### ⑤ 力的方向

\[
\boxed{
\hat{\mathbf F}
=\frac{\nabla_{\mathbf V}\mathbf V}{|\nabla_{\mathbf V}\mathbf V|}
=\frac{\mathbf A}{|\mathbf A|}
}
\tag{8}
\]

柱坐标分量形式：

\[
\boxed{
\hat{\mathbf F}
=\frac{A_r\mathbf e_r+A_\theta\mathbf e_\theta+A_z\mathbf e_z}
{\sqrt{A_r^2+A_\theta^2+A_z^2}}
}
\tag{9}
\]

方向本质：力沿“空间本体流线弯曲方向”\(\nabla_{\mathbf V}\mathbf V\)，不是简单指向拓扑荷中心。

### ⑥ 距离标度与距离比

一般距离公式：

\[
\boxed{
F(r)=k_iQ_t\left|(\mathbf V(r)\cdot\nabla)\mathbf V(r)\right|
}
\tag{10}
\]

距离比：

\[
\boxed{
\frac{F(r_1)}{F(r_2)}
=\frac{|\mathbf A(r_1)|}{|\mathbf A(r_2)|}
}
\tag{11}
\]

距离标度指数：

\[
\boxed{
n\equiv\frac{d\ln F}{d\ln r}
\quad\Longrightarrow\quad
\frac{F(r)}{F(r_0)}=\left(\frac{r}{r_0}\right)^n
}
\tag{12}
\]

球对称通量极限下：

\[
\oint_S\mathbf V\cdot d\mathbf S=4\pi r^2V_r=4\pi Q_t
\]

\[
\boxed{
V_r(r)=\frac{Q_t}{r^2}
}
\tag{13}
\]

\[
A_r=V_r\frac{dV_r}{dr}
=\frac{Q_t}{r^2}\left(-\frac{2Q_t}{r^3}\right)
=-\frac{2Q_t^2}{r^5}
\]

\[
\boxed{
F_r(r)=k_iQ_t|A_r|
=\frac{2k_iQ_t^3}{r^5}
}
\tag{14}
\]

因此通量主导、纯径向情形：

\[
\boxed{
n=-5,\qquad
\frac{F(r)}{F(r_0)}=\left(\frac{r_0}{r}\right)^5
}
\tag{15}
\]

注意：论文框架中距离依赖**不是普适平方反比**，而由 \(\mathbf V(r)\) 剖面决定；轴向螺旋主导时 \(A_z\approx-\frac{r^2\omega}{c}\dot\omega\)，显含 \(r^2\omega\dot\omega\)。

## 2. 力的统一场论方程

### 严格论文版：引力—惯性统一

\[
\boxed{
\mathbf F_{\rm grav\text{-}inert}
=m_i\mathbf G
=k_iQ_t\nabla_{\mathbf V}\mathbf V,
\qquad
m_i=k_iQ_t
}
\tag{16}
\]

约束：

\[
\boxed{
|\mathbf V|^2=(r\omega)^2+v_z^2=c^2,\qquad
Q_t=\frac{1}{4\pi}\oint_S\mathbf V\cdot d\mathbf S
}
\tag{17}
\]

自由下落：

\[
\boxed{
\nabla_{\mathbf V}\mathbf V=0
\quad\Longrightarrow\quad
\mathbf F=0
}
\tag{18}
\]

严格版只统一引力与惯性，不显式包含电磁力。

### 最小电磁扩展版：引力—惯性—电磁同源统一

定义拓扑荷到电磁荷的有效转换：

\[
\boxed{
q_{\rm eff}=\kappa_qQ_t
}
\tag{19}
\]

统一力方程：

\[
\boxed{
\mathbf F_{\rm unif}
=m_i\mathbf G
+q_{\rm eff}\left(\mathbf E+\mathbf u\times\mathbf B\right)
}
\tag{20}
\]

代入论文同源映射：

\[
m_i=k_iQ_t,\quad
q_{\rm eff}=\kappa_qQ_t,\quad
\mathbf G=\nabla_{\mathbf V}\mathbf V,\quad
\mathbf E=k_Ev_z\mathbf e_z,\quad
\mathbf B=k_B\omega\mathbf e_z
\]

得到展开式：

\[
\boxed{
\mathbf F_{\rm unif}
=Q_t\left[
k_i\nabla_{\mathbf V}\mathbf V
+\kappa_qk_E\,v_z\mathbf e_z
+\kappa_qk_B\,\mathbf u\times(\omega\mathbf e_z)
\right]
}
\tag{21}
\]

约束：

\[
\boxed{
\frac{k_E}{k_B}=c
}
\tag{22}
\]

其中：
- 第一项 \(k_iQ_t\nabla_{\mathbf V}\mathbf V\)：引力/惯性统一力；
- 第二项 \(\kappa_qk_EQ_tv_z\mathbf e_z\)：同源电场力；
- 第三项 \(\kappa_qk_BQ_t\,\mathbf u\times(\omega\mathbf e_z)\)：同源磁场力；
- 三者共享同一拓扑荷 \(Q_t\)，只是耦合系数不同。

若取 \(\kappa_q=0\)，退回严格论文版式（16）。

## 3. 大小、方向、距离的统一写法

\[
\boxed{
\mathbf F_{\rm unif}(r)
=Q_t\left[
k_i(\mathbf V(r)\cdot\nabla)\mathbf V(r)
+\kappa_qk_Ev_z(r)\mathbf e_z
+\kappa_qk_B\,\mathbf u\times(\omega(r)\mathbf e_z)
\right]
}
\tag{23}
\]

大小：

\[
\boxed{
F_{\rm unif}(r)=|\mathbf F_{\rm unif}(r)|
}
\tag{24}
\]

方向：

\[
\boxed{
\hat{\mathbf F}_{\rm unif}
=\frac{\mathbf F_{\rm unif}}{|\mathbf F_{\rm unif}|}
}
\tag{25}
\]

距离比：

\[
\boxed{
\frac{F_{\rm unif}(r_1)}{F_{\rm unif}(r_2)}
=\frac{|\mathbf F_{\rm unif}(r_1)|}{|\mathbf F_{\rm unif}(r_2)|}
}
\tag{26}
\]

距离标度指数：

\[
\boxed{
n_{\rm unif}(r)=\frac{d\ln F_{\rm unif}}{d\ln r}
}
\tag{27}
\]

## 5. 一句话总结

**力的本源公式：**

\[
\boxed{
\mathbf F=k_iQ_t\nabla_{\mathbf V}\mathbf V,\qquad
|\mathbf V|=c,\qquad
Q_t=\frac1{4\pi}\oint_S\mathbf V\cdot d\mathbf S
}
\]

**力的统一场论方程：**

\[
\boxed{
\mathbf F_{\rm unif}
=Q_t\left[
k_i\nabla_{\mathbf V}\mathbf V
+\kappa_qk_E\,v_z\mathbf e_z
+\kappa_qk_B\,\mathbf u\times(\omega\mathbf e_z)
\right],
\qquad
\frac{k_E}{k_B}=c
}
\]

其中 \(k_i=k_g=k_m\) 时引力质量与惯性质量相等，等效原理由拓扑荷耦合系数相等导出；力的大小为 \(F=|\mathbf F|\)，方向沿 \(\nabla_{\mathbf V}\mathbf V\)，距离标度由螺旋场剖面 \(\mathbf V(r)\) 与通量守恒共同决定。论文严格版只统一引力与惯性；式（20）—（21）的电磁项需引入 \(\kappa_q\) 作为补充公设。
