# ROOT V123：理论推导及严格审计

## 1. 几何关系
取 r(t)=(R cos(ωt),R sin(ωt),pt)，施加 R²ω²+p²=1，则 κ=Rω²，τ=pω，从而 κ²+τ²=ω²。该结论为运动学恒等式，并非引力定律。注意：若曲线代表有质量粒子的物理三速度，速率恒等于光速与狭义相对论不相容；可将其视为辅助几何曲线，不能直接认定是物质世界线。

## 2. 圆周谱和规范不变量
令 D_a=-i d/ds+a，定义域为长度 L 的圆周周期 Sobolev H¹ 函数，a 为实常数。该算子自伴，谱为 λ_n=2πn/L+a。a→a+2πk/L 只重排谱，物理可观测量应依赖 W=exp(i a L)。这并未产生黎曼 ζ 零点或标准模型粒子质量谱。

## 3. 协变场作用量
度规 (-,+,+,+)，c=1，取
S=∫d⁴x √(-g) [ R/(16πG) - g^{μν}(D_μΨ)*D_νΨ - V(|Ψ|²) - 1/4 F_{μν}F^{μν} ]。
D_μ=∇_μ-iqA_μ，F_{μν}=∂_μ A_ν-∂_ν A_μ。
变分给出：G_{μν}=8πG T_{μν}；D_μ D^μ Ψ - (dV/d|Ψ|²)Ψ=0；∇_μ F^{μν}=j^ν，其中 j^ν=i q[Ψ*(D^νΨ)-Ψ(D^νΨ)*]，符号约定与上述 D 一致（由变分核对）。
该作用量是已知 Einstein-Maxwell-charged-scalar 类型，不能宣称是新四力统一理论。它缺少 SU(2)×SU(3) 规范部门、手征费米子、希格斯机制、量子重整化论证。

## 4. 引力本质与有效理论
在广义相对论中，局部引力现象由时空度规及曲率描述；微观量子起源尚未确立。谱作用量、黎曼零点、螺旋几何之间不存在已证明的自然界一一对应。若加入标量-张量耦合 F(χ)R/(16πG)，须推导 F,V 的唯一形式、排除鬼模并计算 PPN/引力波/等效原理约束。

## 5. 理论状态
已证：指定模型中的几何恒等式、谱公式、作用量的经典场方程。
待证：螺旋场微观公设、唯一耦合、四力统一、无自由参数新预测、实验可重复的额外引力效应。
