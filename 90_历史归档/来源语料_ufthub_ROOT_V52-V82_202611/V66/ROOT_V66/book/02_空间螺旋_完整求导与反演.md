# 第二章｜圆柱螺旋：从轨迹到曲率、挠率、加速度的严格推导

## 2.1 运动学定义

`r⃗(t)=(a cosωt, a sinωt, ut)`，令 `a>0, ω>0, u∈R`。速度 `v⃗=(-aω sinωt,aω cosωt,u)`，因此 `v²=a²ω²+u²`，加速度 `a⃗=(-aω² cosωt,-aω² sinωt,0)`。常速条件下 `v⃗·a⃗=0`，说明沿轨迹速度与向心加速度正交，与任何三种物理力是否垂直无关。

设 `v_θ=aω`，以 `λ=atan2(u,v_θ)` 定义升角，则 `v_θ=v cosλ`、`u=v sinλ`。只有在把 `v=c` 作为**数学假设**时，才可写 `aω=c cosλ`、`u=c sinλ`，但此时不能同时把该线作为有质量物质点的相对论世界线。

## 2.2 曲率、挠率

曲率定义 `κ=|r'×r''|/|r'|³`。直接计算 `|r'×r''|=aω² v`，所以 `κ=aω²/v² = cos²λ/a`。挠率定义 `τ_FS=[(r'×r'')·r''']/|r'×r''|²`，结果 `τ_FS=uω/v²=sinλ cosλ/a`。`κ²+τ_FS²=cos²λ/a²`，当 `κ>0` 时可反演出 `a=κ/(κ²+τ_FS²)`、`ω=v√(κ²+τ_FS²)`、`u=vτ_FS/√(κ²+τ_FS²)`，且 `v_θ=vκ/√(κ²+τ_FS²)`。

边界条件：当 `κ=0` 时轨迹退化为直线，螺旋半径和轴线不再有唯一物理意义，不能机械套用逆公式。改变坐标轴取向可改变 `τ_FS` 符号，不会自动造成物理粒子手征性或 CP 破缺。

## 2.3 Frenet 三方向的几何意义

单位切向 `T=r'/v`；主法向 `N=T'/|T'|`；副法向 `B=T×N`。这些构成局域正交坐标架。Frenet–Serret 方程 `dT/ds=κN`、`dN/ds=-κT+τ_FS B`、`dB/ds=-τ_FS N`，分别描述曲线运动的局部旋转；它们不含质量、电荷、色荷、弱同位旋或场的源项，因此不足以产生基本相互作用的动力学定律。

任何具有上述轨迹的质点都可以由不同外力或外部约束实现同一轨迹。对轨迹求导只得到运动学需求 `m a⃗`，不能从中唯一求得“是什么力”使它运动。逆动力学必须提供物质组成、场方程、边界/初值及耦合常数。

## 2.4 相对论相容条件

惯性系中有质量粒子 `dτ_proper/dt=√(1-v²/c²)`。当 `v=c` 时固有时间速率为零，曲线为光型而非有质量粒子的时间型世界线。因此 ROOT 若要保留“内部光速螺旋”，应将它定义为场的相位/结构模态，不称为每个质点实际穿越空间的速度。波的相位速度、群速度、能量流速度各不相同：对 Klein–Gordon 色散 `ω²=c²(k²+q²)+m²c⁴/ℏ²`，纵向群速度 `∂ω/∂k=c²k/ω`，通常严格小于 c。

## 2.5 数值验证要求

验证 `|v⃗|=v`；`v⃗·a⃗=0`；`|a⃗|=v²κ`；用有限差分逼近各阶导数；在正、负升角上反演 `(a,ω,u)`；以随机 boost 复核 Minkowski 间隔，而不是把角度分解直接称为 Lorentz 协变理论。
