一、命题 S 与链式法则

前六册把「换观测量（测距 / Shapiro / LLR / 红移 / 周期）」写成未判的出口。本册把它写成命题 S 并判掉：在 β=0 处，任何势泛函对 λ 的导数都精确为零。

Phi(r; beta, lambda) = -(mu/r) * (1 + beta*lambda^2*exp(-r/lambda))
beta = 0 => Phi(r) = -mu/r（逐点不含 lambda）
dQ/dlambda |_(beta=0) = ∫ (delta Q / delta Phi) * (dPhi/dlambda) = 0
