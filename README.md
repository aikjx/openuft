## 阅读顺序

1. 在 [理论路线](01_hypotheses/README.md) 选择体系，阅读八阶段目录及候选资料。
2. 按 [研究协议](03_research_protocol/README.md) 建立可追溯记录。
3. 在 [比较矩阵](02_comparison/README.md) 对照预测与证据。
4. 在 [综合区](04_synthesis/README.md) 登记候选、冲突和缺口。
