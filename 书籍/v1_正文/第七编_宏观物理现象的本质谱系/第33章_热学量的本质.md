## 33.2 温度 $T$

### 33.2.1 本源定义

标准物理：温度是平衡态系统内能对外做功能力的"测度"，严格定义在热力学极限下的宏观参量。统一场论映射（[B]）：温度是 S10 振动本体中微观自由度振动频率的统计平均——$T \propto \langle\omega\rangle$。S10 postulates §1 自述"频率 $\omega$ 是第一物理量"，温度因此被读作"频率系综的标量均值"。

### 33.2.2 本源方程（第一性原理推导）

**热力学定义**：

$$\frac{1}{T}=\left(\frac{\partial S}{\partial U}\right)_{V,N}\qquad[A]\tag{33.1}$$

**理想气体动理论推导**（[A]）：

1. [A] $N$ 个单原子分子在体积 $V$ 内，第 $i$ 个分子动量 $\boldsymbol p_i$，壁面单位面积单位时间碰撞数 $\sim n\bar v/4$，单次冲量法向分量 $\sim 2p_x$。
2. [A] 压强 $p = (1/3)n\langle m v^2\rangle = (2/3)n\langle E_k\rangle$。
3. [A] 理想气体状态方程 $pV = N k_B T$（实验定律）。
4. [A] 联立：$\langle E_k\rangle = (3/2)k_B T$。

**统一场论映射**（[B]）：

5. [B] 由 S10 postulates §2，$E = \hbar\omega$（A2 量子原理），$m = \hbar\sqrt{\kappa^2+\tau^2}/c$。把第 4 步的单粒子动能读作振动频率 $\omega$ 的能量：$\langle E_k\rangle = \hbar\langle\omega\rangle$。
6. [B] 故 $T \propto \langle\omega\rangle$——温度是"频率系综的标量均值"。

**诚实边界**：第 5–6 步只是把 $\langle E_k\rangle$ 改写为 $\hbar\langle\omega\rangle$ 的符号映射，未证明"平衡态温度"与"振动频率平均"在非理想气体、量子简并情形下严格等价。标 [B]。

### 33.2.3 量纲定位

自然单位 $k_B=1$，$T$ 与能量同量纲：

$$[T]=[E]=[M]=\ell^{-1}\tag{33.2}$$

**维度谱定位表**：

| 维度层级 | 温度对应物 | 量纲 $\ell^n$ |
|---|---|---|
| 0D（基元/荷） | 单个 $0/1$ 基元的振动频率 $\omega$ | $\ell^{-1}$ |
| 1D（线密度/绕数） | 一维链上频率的沿线分布 $\langle\omega\rangle_1$ | $\ell^{-1}$ |
| 2D（面密度/分形） | 二维表面温度场均值 | $\ell^{-1}$ |
| 3D（体密度/霍普夫） | 三维体相温度场 | $\ell^{-1}$ |
| 3+1D（物理时空） | 平衡态宏观温度 $T(t,\boldsymbol x)$ | $\ell^{-1}$ |
| 4D（标度空间） | 重整化群标度对应的特征温标 | $\ell^{-1}$ |

温度是"跨维度不变量纲"——无论在哪个维度层级，只要是"能量/频率的统计平均"，量纲都是 $\ell^{-1}$。

### 33.2.4 数值验证

- 室温 $T \approx 300\,\mathrm{K}$。换算为能量：$k_B T \approx 4.14\times10^{-21}\,\mathrm{J} \approx 0.0259\,\mathrm{eV}$（实验常识值）。
- 换算为长度倒数：$\ell_T = \hbar c/(k_B T) \approx 7.6\,\mu\mathrm{m}$——室温对应的热德布罗意波长数量级。
- 与 S10 映射对照：室温对应频率 $\nu = k_B T/h \approx 6.25\,\mathrm{THz}$，在远红外波段——与"分子振动频率"实测范围一致（实验常识值）。

### 33.2.5 精算示例

室温下氮气分子平均动能：

$$\langle E_k\rangle = \frac{3}{2}k_B T = 1.5 \times 1.38\times10^{-23} \times 300 \approx 6.21\times10^{-21}\,\mathrm{J}\approx 0.0388\,\mathrm{eV}$$

方均根速率 $v_{\rm rms} = \sqrt{3RT/M} = \sqrt{3\times 8.314\times300/0.028} \approx 517\,\mathrm{m/s}$（实验常识值，可复算）。

## 33.3 热量 $Q$ 与内能 $U$

### 33.3.1 本源定义

热量是系统与环境之间因温差传递的能量；内能是系统总能量。统一场论映射（[B]）：热量是 S10 振动频率谱在温差驱动下的"流"——频率高处向频率低处净流动。

### 33.3.2 本源方程（第一性原理）

$$\Delta U = Q - W\qquad[A]\tag{33.3}$$

热力学第一定律，步骤：[A] 能量守恒；[A] $Q$ 与 $W$ 是过程量，$U$ 是态函数。映射：[B] $Q$ 对应"振动能量流"，但未从 S13 场方程严格导出热流。

### 33.3.3 量纲定位

$$[Q]=[U]=[E]=\ell^{-1}$$

| 0D | 单基元能量 $\hbar\omega$ | $\ell^{-1}$ |
| 1D | 一维链总能量 | $\ell^{-1}$ |
| 2D | 面能量 | $\ell^{-1}$ |

## 33.4 比热容 $c$（质量比热）

### 33.4.1 本源定义

单位质量物质升温单位温度所需热量。统一场论映射（[B]）：比热是"单位质量内可参与热振动的自由度数目"的度量——自由度越多，同样温升吸的能量越多。

### 33.4.2 本源方程（第一性原理）

**定义式**：

$$c = \frac{1}{m}\left(\frac{\partial Q}{\partial T}\right)\qquad[A]\tag{33.4}$$

**杜隆-珀蒂极限（[A]）**：高温下每个原子贡献 $3k_B$（三维谐振子，动能 $3/2$ + 势能 $3/2$）：

$$c_V \to \frac{3R}{M_{\rm mol}}\qquad[A]\tag{33.5}$$

**推导步骤**：[A] 三维谐振子哈密顿量 $H = p^2/2m + (1/2)m\omega^2 x^2$，每个平方项贡献 $k_B T/2$（能量均分定理）；[A] 一个原子 6 个平方项（3 动 + 3 势）→ $3k_B T$；[A] 摩尔比热 $3R$。

**爱因斯坦/德拜低温修正**（[A]）：$c_V \propto T^3$（德拜 $T^3$ 定律）。

**统一场论映射**：[B] 比热 $\leftrightarrow$ "可激发振动模的数目"与 S10 频率谱的密度态 $g(\omega)$ 直接相关；[C] 从 S13 分形维度 $D=4-\gamma$ 严格推出 $g(\omega)$ 与 $c_V(T)$ 的函数关系——**推导待建**。

### 33.4.3 量纲定位

$$[c] = \frac{[Q]}{[m][T]} = \frac{\ell^{-1}}{\ell^{-1}\cdot\ell^{-1}} = \ell^{+1}\tag{33.6}$$

| 维度层级 | 对应物 | 量纲 |
|---|---|---|
| 0D | 单基元"比热"（无意义） | — |
| 1D | 一维链比热（per 单位长度） | $\ell^{+2}$ |
| 2D | 二维膜比热 | $\ell^{+1}$ |
| 3D | 三维体材料比热 $c_V$ | $\ell^{+1}$ |
| 3+1D | 宏观可测比热 | $\ell^{+1}$ |
| 4D | 标度空间比热 | $\ell^{+1}$ |

### 33.4.4 数值验证

- 液态水 $c_p \approx 4186\,\mathrm{J/(kg\cdot K)}$（实验常识值）。
- 铜 $c_p \approx 385\,\mathrm{J/(kg\cdot K)}$，接近杜隆-珀蒂极限 $3R/M = 3\times8.314/0.0635 \approx 392\,\mathrm{J/(kg\cdot K)}$（实验常识值，复算一致）。
- 空气 $c_p \approx 1005\,\mathrm{J/(kg\cdot K)}$。

### 33.4.5 精算示例

铜的杜隆-珀蒂预测：$c_V = 3R/M_{\rm mol} = 24.94/0.06354 \approx 392.5\,\mathrm{J/(kg\cdot K)}$，实测 $385\,\mathrm{J/(kg\cdot K)}$，相对误差约 $2\%$——高温经典近似良好。

## 33.5 热导率 $\kappa$

### 33.5.1 本源定义

单位温差梯度下单位面积流过的热流。统一场论映射（[B]）：热导率是"能量载流子（声子/电子）在拓扑缺陷间自由程的几何度量"。

### 33.5.2 本源方程（动理论严格推导）

**傅里叶定律**：

$$\boldsymbol J_q = -\kappa\nabla T\qquad[A]\tag{33.7}$$

**动理论推导**（[A]）：

1. [A] 单位体积热容量 $C_V$，载流子平均速率 $\bar v$，平均自由程 $\lambda$。
2. [A] 相邻两层 $\lambda$ 处温差 $\Delta T = \lambda\,|\nabla T|$，单位体积能量差 $C_V\lambda|\nabla T|$。
3. [A] 单位面积单位时间净流：$J_q \sim -(1/3)C_V\bar v\lambda\nabla T$（因子 $1/3$ 来自各向同性平均）。
4. [A] 得 $\kappa = \frac{1}{3}C_V\bar v\lambda$。

**声子/电子分解**（[A]）：

$$\kappa = \kappa_{\rm ph} + \kappa_e\qquad[A]\tag{33.8}$$

金属以电子为主，绝缘体以声子为主。

**统一场论映射**：[B] 平均自由程 $\lambda$ 可读作 S13 因果畴壁（M6）之间的典型距离；[C] 从 S13 拓扑荷 $Q_H$ 的碰撞统计严格推出 $\lambda$ 与 $\kappa$——**推导待建**。

### 33.5.3 量纲定位

$[J_q] = [E]/(L^2 T) = \ell^{-1}/(\ell^2\cdot\ell) = \ell^{-4}$；$[\nabla T] = \ell^{-1}/\ell = \ell^{-2}$；故

$$[\kappa] = \ell^{-4}/\ell^{-2} = \ell^{-2}\tag{33.9}$$

| 维度层级 | 对应物 | 量纲 |
|---|---|---|
| 0D | 单基元无导热概念 | — |
| 1D | 一维热导（per 单位温度差） | $\ell^{-1}$ |
| 2D | 二维面热导 | $\ell^{-2}$ |
| 3D | 三维体热导率 $\kappa$ | $\ell^{-2}$ |
| 3+1D | 宏观热导率 | $\ell^{-2}$ |
| 4D | 标度空间热输运 | $\ell^{-2}$ |

### 33.5.4 数值验证

- 铜 $\kappa \approx 401\,\mathrm{W/(m\cdot K)}$；铝 $237$；不锈钢 $15$；水 $0.6$；空气 $0.026$；玻璃 $1$（实验常识值）。
- 动理论估算铜电子热导：$C_V \approx \pi^2 n k_B^2 T/(2E_F)$，$n\approx 8.5\times10^{28}\,\mathrm{m^{-3}}$，$E_F\approx 7\,\mathrm{eV}$，$\bar v\approx v_F\approx 1.6\times10^6\,\mathrm{m/s}$，$\lambda\approx 40\,\mathrm{nm}$，代入得 $\kappa_e \sim 400\,\mathrm{W/(m\cdot K)}$，与实测同量级（实验常识值，复算一致）。

### 33.5.5 精算示例

空气 $\kappa = (1/3)C_V\bar v\lambda$：$C_V\approx 1.2\times718\approx 860\,\mathrm{J/(m^3\cdot K)}$，$\bar v\approx 470\,\mathrm{m/s}$，$\lambda\approx 68\,\mathrm{nm}$，得 $\kappa\approx (1/3)\times860\times470\times6.8\times10^{-8}\approx 0.0092\,\mathrm{W/(m\cdot K)}$。低估约 3 倍（动理论粗估，系数与 $\lambda$ 定义敏感），但量级正确——这正是 [A] 类框架 + 实验修正的典型案例。

## 33.6 熵 $S$

### 33.6.1 本源定义

玻尔兹曼熵：平衡态宏观态对应的微观态数的对数。统一场论映射（[B]）：S13 ch18 明示"统计/热力学 ↔ 分形维度 $D=4-\gamma$"——熵是分形路径在拓扑空间上"可分辨构型数"的对数；S04 IEG 信息熵引力思路把熵与几何自由度直接挂钩。

### 33.6.2 本源方程（第一性原理）

**玻尔兹曼公式**：

$$S = k_B \ln\Omega\qquad[A]\tag{33.10}$$

**吉布斯推广**：

$$S = -k_B\sum_i p_i\ln p_i\qquad[A]\tag{33.11}$$

**热力学形式**：

$$dS = \frac{\delta Q_{\rm rev}}{T}\qquad[A]\tag{33.12}$$

**推导步骤**：[A] 平衡态系综等概率假设；[A] 宏观态对应微观态数 $\Omega$；[A] $S$ 可加性 → $\ln\Omega$；[A] 热力学第二定律 → $dS\ge 0$。

**统一场论映射**：[B] S13 分形维度 $D=4-\gamma$ 中 $\gamma$ 为奇异维修正；若把 $\Omega$ 读作 $D$ 维分形曲面上的"可分辨节点数"，则 $S \sim (D-1)\ln L$——这是结构对应，候选；[C] 从 S13 M1–M6 严格推出 $\gamma$ 与宏观熵增率的关系——**推导待建**。

### 33.6.3 量纲定位

自然单位 $k_B=1$：

$$[S] = [k_B] + [\ln\Omega] = \ell^0\qquad[A]\tag{33.13}$$

| 维度层级 | 对应物 | 量纲 |
|---|---|---|
| 0D | 单基元信息（$Q=\pm1$） | $\ell^0$ |
| 1D | 一维分形路径熵 | $\ell^0$ |
| 2D | 二维表面熵（贝肯斯坦候选） | $\ell^0$（面积/ℓ_P²） |
| 3D | 三维体熵 | $\ell^0$ |
| 3+1D | 宏观热力学熵 | $\ell^0$ |
| 4D | 标度空间信息熵 | $\ell^0$ |

熵是少数在全维度谱上恒为 $\ell^0$ 的量——这与"熵是对数、对数无单位"的数学事实一致。

### 33.6.4 数值验证

- $1\,\mathrm{J/K} \approx 1.5\times10^{23}\,k_B$（$1/k_B = 7.24\times10^{22}\,\mathrm{J^{-1}K}$）。

### 33.6.5 精算示例

理想气体从 $V_1$ 等温膨胀到 $V_2$：$\Delta S = nR\ln(V_2/V_1)$。取 $n=1\,\mathrm{mol}$，$V_2/V_1=10$，则 $\Delta S = 8.314\times\ln10 \approx 19.1\,\mathrm{J/K}$——与实验一致（[A]）。

## 33.7 热膨胀系数 $\alpha_{\rm th}$

### 33.7.1 本源定义

单位温升引起的相对长度变化。统一场论映射（[B]）：热膨胀是原子间结合势不对称性的宏观表现——势阱不是抛物线，平均位置随能量升高而外移；在 S13 框架下对应对偶势 $V(\rho)\sim \kappa(|\Psi|^2-v^2)^2$ 的非简谐项。

### 33.7.2 本源方程（第一性原理）

**定义式**：

$$\alpha_{\rm th} = \frac{1}{L}\left(\frac{\partial L}{\partial T}\right)_p\qquad[A]\tag{33.14}$$

**格林艾森关系**（[A]）：

$$\alpha_{\rm th} = \frac{\gamma_G C_V}{3B V}\qquad[A]\tag{33.15}$$

其中 $\gamma_G$ 为格林艾森常数，$B$ 为体积模量。

**推导步骤**：[A] 原子间势 $u(x)$ 展开至三阶 $u(x)=u_0+(1/2)ax^2-(1/3)bx^3$；[A] 玻尔兹曼平均 $\langle x\rangle \propto b\,k_B T/a^2$；[A] 故 $\alpha_{\rm th}\propto b/a^2$——非简谐项 $b$ 是热膨胀之源；[A] 简谐势（$b=0$）→ $\alpha=0$，与实验一致。

**统一场论映射**：[B] S13 有效势 $V=\kappa(|\Psi|^2-v^2)^2$ 本身是四次势，非简谐项天然存在；[C] 从 $\kappa$ 与 $\tilde\kappa$ 严格推出宏观 $\alpha_{\rm th}$——**推导待建**。

### 33.7.3 量纲定位

$$[\alpha_{\rm th}] = \frac{[L]}{[L][T]} = \frac{1}{[T]} = \ell^{+1}\tag{33.16}$$

| 维度层级 | 对应物 | 量纲 |
|---|---|---|
| 0D | 无意义 | — |
| 1D | 一维链线膨胀系数 | $\ell^{+1}$ |
| 2D | 二维面膨胀系数 | $\ell^{+1}$ |
| 3D | 三维体膨胀系数 $\alpha_V\approx 3\alpha_L$ | $\ell^{+1}$ |
| 3+1D | 宏观热膨胀 | $\ell^{+1}$ |
| 4D | 标度空间"热膨胀" | $\ell^{+1}$ |

### 33.7.4 数值验证

- 钢 $\alpha_L\approx 12\times10^{-6}\,\mathrm{K^{-1}}$；铝 $23\times10^{-6}$；玻璃 $9\times10^{-6}$；水（体积）$2.1\times10^{-4}\,\mathrm{K^{-1}}$（实验常识值）。
- 格林艾森常数典型值 $\gamma_G\approx 1$–$2$（金属），与理论框架一致。

### 33.7.5 精算示例

钢轨 $L=100\,\mathrm{m}$，冬夏温差 $\Delta T=60\,\mathrm{K}$，$\Delta L = \alpha_L L\Delta T = 12\times10^{-6}\times100\times60 = 0.072\,\mathrm{m} = 72\,\mathrm{mm}$——这是钢轨必须留伸缩缝的工程依据（[A]）。
