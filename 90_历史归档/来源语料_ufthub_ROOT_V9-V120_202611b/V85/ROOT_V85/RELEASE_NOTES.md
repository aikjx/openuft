# ROOT V85 发布说明

相对于 V84，本版把问题从单源“第五力拟合”提升为“**星球环境耦合 vs 组成耦合 vs 源质量标定**”的三模型对照：

1. 补充源强独立的径向 Q 诊断及 Yukawa 精确式；
2. 推导单一可分离新媒介的跨源材料差矩阵秩≤1；
3. 用人工注入双媒介和噪声分别展示秩约束可违反的不同原因；
4. 跨星体参数统一采用 GM，避免利用 G 反算天体质量又声称证明 G；
5. 区分不同 Eötvös 材料自由落体观测与普适环境依赖 G_eff；
6. 建立系统的微观 G 和四力统一证明状态，保留独立尺度、规范谱、相对论极限、实验排错的开放缺口。

**发布等级：理论软件研究包，绝非实测新物理发现。**
