## 一、一句话结论

**是，单因子结构确实重现 —— 但重现出来的东西比 r331/r335 说的弱得多：因为 `n_R(k) = χ(O_X(kH))` 的 Newton 系数 `a_j = Δ^j χ(0)` 全是整数，所以 `Z` 永远含于整性集，整性从不排除任何整数通量。**

## 二、为什么这一卷值得单独立册

r335 把「整性 ⟹ 格」划到 **rank 1**，并留下 `X-R335-2`：`H²` 秩 1 但非 `CP^n` 的 Fano，格还在不在？

单因子结构**当然**在 —— `H²` 秩 1 ⇒ `n_R` 是**单变量**多项式 ⇒ r335 的机制原样适用。所以这一问回答起来几乎是同义反复。

**但回答它的过程暴露了一件更重要的事**：单因子结构给出来的，从来不是「格」，而只是「`Z` 的**超集**」。

r325→r327→r331→r335 四卷一直在说「整性逼出格」。本卷把它拆成两句：

| 命题 | 真伪 | 依据 |
|---|---|---|
| 整性把 `q` 限制在一个**离散集** | **真** | 单变量多项式 `∈ Z` |
| 这个离散集是一个**格** | **假**（本卷 7/30 反例） | 仿射封闭失败 |
| 这个格**比几何量子化更紧** | **假**（0 例外） | `Z ⊆ S` 恒成立 |

第三行是本卷最硬的一条：**整性从来不比 `H²(X,Z) = Z·H` 更紧。**

## 三、口径与工具

### 3.1 坐标：`k` 不是 `q`

本卷用 `k`（`χ(O_X(kH))` 的自变量）。**与 r325/r327/r331/r335 的 `q` 差一个偏移**：

```
k = q − (n+1)/2
```

`n` 偶时偏移是**半整数**。这就是为什么 r325 在 `q` 坐标下看到 `CP²` 的格是 `Z+1/2`，而在 `k` 坐标下它就是 `Z`（`E01` 4/4）。

> **纪律（r305「口径自守」的加强版）**：换坐标不是换结论，但会把「几何内容」和「坐标偏移」混在一起。**凡报「格」，必须同时报它在哪个坐标下。**

### 3.2 超曲面上的 `χ`：adjunction + td 除法

```
X = X_d ⊂ CP^{n+1},  dim_C = n
td(T_X) = td(T_{CP^n}) · T(h)/T(dh)      T(h) = h/(1−e^{−h})
χ(O_X(kH)) = d · ⟨h^n, e^{kh} · td(T_X)⟩
```

`d=1` 时校正因子恒 1 ⇒ 自动退化成 `CP^n`（`A02` **36/36**）。

### 三条硬约束（都是本卷踩过才写下的）

1. **窗口必须 ≥ `n/2 + 2`**。`d=2` 的额外点恰在 `k = −n/2`，`n=7` 时是 `−7/2`；窗口 `[-3,3]` 装不下 ⇒ 把非陪集误判成陪集（`D04` 首版）。
2. **陪集判据只能用仿射封闭** `u−v+w ∈ S`，不能用差封闭（r335 §八.1，本卷首版又踩一次）。
3. **`k=1` 不是好测试点**：`C(1,2) = 0`，人为非整系数 `1 + k²/2` 在 `k=1` 上仍整（`CTL7` 首版判据选错点）。

## 五、定理 B（本卷最硬一条）：`Z` 恒含于整性集

### 5.1 陈述

设 `P(k) = Σ_{j=0}^{n} a_j C(k,j)` 为 `χ(O_X(kH))` 的 Newton 展开，`a_j = Δ^j P(0)`。则

```
a_j ∈ Z  对所有 j  =>  P(k) ∈ Z  对所有 k ∈ Z   =>  Z ⊆ S
```

### 5.2 读数

| 条目 | 内容 | 读数 |
|---|---|---|
| `B01` | 30 组 `a_j` 全为整数 | **0 组非整** |
| `B02` | `Z ⊆ S`（`k = −8..8` × 30 组 = 510 点） | **0 违例** |
| `B03` | 判别力对照：人为 `a_2 = 1/2` | **7 个整数点立刻不整** |

### 5.3 为什么这不是废话

因为 `χ(O_X(kH))` 本身就是**欧拉示性数**（维度交替和），在整数 `k` 上必为整数。所以 `a_j ∈ Z` 是它的直接后果，`Z ⊆ S` 也就必然。

**但这句话的分量在于它反过来打掉了什么**：如果 `Z` 永远在里面，那么「整性逼出格」就**不能**被读成「整性把连续的通量离散化了」—— 通量早就被 `H²(X,Z) = Z·H` 离散化了。整性只是**不反对**它。

## 六、定理 C：整性集的真实结构

### 6.1 四类，没有一类比 `Z` 更紧

| 类型 | 组数 | 形态 | 例子 |
|---|---|---|---|
| **`S = Z`** | **20** | 零增量 | `n=2` 全部 5 组、`n=4` 全部 7 组 |
| **`S = (1/d)Z`** | **4** | 严格**更宽** | `n=1`（曲线） |
| **`S = Z ∪ (等差半整数列)`** | **7** | 非陪集 | `n=3,5` 且 `d` 偶 |
| 其它 | 0 | — | — |

合计 20 + 4 + 7 = 31，但 `n=1,d=1` 同时属于第一类与第二类（`(1/1)Z = Z`），去重后 **30**。

### 6.2 `n=1`：解析可证

曲线 `X_d ⊂ CP²` 上 Riemann–Roch 给 `χ(O(kH)) = dk + 1 − g`。所以

```
χ ∈ Z  ⟺  dk ∈ Z  ⟺  k ∈ (1/d)Z
```

机检 `S == (1/d)Z` 对 `d = 1,2,3,4` **4/4**（`C02`）。

> **读法**：`n=1` 时整性把格**放大 `d` 倍**。这不是「更紧」，是**更松**。

### 6.3 `n ≥ 3` 奇、`d` 偶：非陪集

`S = Z ∪ {c + 2mZ}`（或间距 4）。具体：

| `(n,d)` | 额外点 | 间距 |
|---|---|---|
| `(3,2)` | `…, −11/2, −3/2, 5/2, …` | 4 |
| `(3,4)` | `…, −9/2, −5/2, −1/2, 3/2, …` | 2 |
| `(3,6)` | `…, −7/2, 1/2, 9/2, …` | 4 |
| `(5,2)` | `…, −5/2, …` | 孤立（`[-6,6]` 内） |

**非陪集见证**（`C04`，7 组全部给出）：

```
n=3, d=2 :  u=−6, v=−11/2, w=−4  =>  u−v+w = −9/2 ∉ S
```

> `S` 含 `−11/2` 与全部整数，却不含 `−9/2` ⇒ **不是加法子群的陪集**。r335 在 rank 2 上看到的「非格」现象，**在 rank 1 上也有，只是稀疏**。

### 6.4 规律与可证伪预测

**规律**：非陪集 ⟺ `n ≥ 3` 且 `n` 奇 且 `d` 偶（`C05`，预测 7 组、实测 7 组，完全一致）。

**外推 `n=7`**（`D04`）：`d = 2,4,6,8` 全部非陪集，**4/4 命中**。

> ★ 首版这条**失败**（3/4），原因不是规律错，是**窗口 `[-3,3]` 装不下 `d=2` 的额外点 `−7/2`**。放大到 `[-6,6]` 后 4/4。这次失败直接生成了本卷的第一条硬约束。

## 七、定理 D：`Z+1/2` 是坐标假象（判词主轴）

| 条目 | 内容 | 读数 |
|---|---|---|
| `D01` | `Z ⊆ S` ⇒ 整性不比几何格更紧 | **0 违例** |
| `D02` | `n ≥ 2` 的 26 组里 `S = Z` 的组数 | **19** |
| `D03` | `n=1` 整性集严格大于 `Z` | **3/4**（`d=1` 时 `(1/d)Z == Z`，不放大） |
| `D04` | `n=7` 外推检验 | **4/4** |

### 7.1 `r325` 的 `Z+1/2` 怎么回事

r325：`c₁(CP^n) = (n+1)H` ⇒ 非自旋圈 `[F] ∈ H²(Z) + c₁/2` ⇒ `CP²` 的格是 `Z+1/2`。

换成 `k = q − (n+1)/2`：`n` 偶 ⇒ 偏移半整数 ⇒

```
q ∈ Z + 1/2   ⟺   k = q − 3/2 ∈ Z
```

**同一张格，两个名字**（`E01` 4/4：`n = 1,2,3,4` 平移后一律是连续的 `Z`）。

所以 r325 的 `spin^c` 论证与 r331 的「不需要 `spin^c`」**不是两个结论，是同一个结论的两个坐标**。r331 的 `B06`（「判据只是偏移的模 1 类」）说的就是这件事，本卷把它钉到具体数值上。

> **这不推翻 r325**：它的格是对的，只是「`Z+1/2`」这个名字让人以为那里有几何内容。**几何内容在 `k` 坐标下为零。**

### 7.2 那 r331 到底证明了什么

r331 证明的是：**`n_R ∈ Z` 这一条算术条件，足以把 `q` 逼到 `Z` 或 `Z+1/2` 上**（不需要 `spin^c`）。这是对的。

本卷补的是：**这个「`Z`」不是它逼出来的** —— `H²(X,Z) = Z·H` 早就把它放在那儿了。r331 的功绩是**削掉了一条假设**，不是**新增了一条约束**。

## 八、判据与方法（沉淀给后续卷）

1. **窗口必须 ≥ `n/2 + 2`**，否则 `−n/2` 处的额外点漏掉 ⇒ 非陪集被误判成陪集。
2. **陪集只能用仿射封闭测**（`u−v+w ∈ S`）。
3. **测试点不要取 `k=1`**（`C(k,2)` 在那里恒零）。
4. **判「格是否更紧」必须与几何格逐点比对**，不能只报「是格」。
5. **凡报整性集，必须同时报 `Z ⊂ S` 是否成立** —— 否则读者会以为「整性约束了通量」。
