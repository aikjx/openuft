【公理】omega*rho = c (空间光速螺旋运动)

------------------------------------------------------------------------------------------------------------------------
第一性原理推导
------------------------------------------------------------------------------------------------------------------------
  [1] omega*rho = c
    空间全维度以光速做柱螺旋运动

------------------------------------------------------------------------------------------------------------------------
求导证明
------------------------------------------------------------------------------------------------------------------------
  1. 统一场动量：P = m*(C - V)
  2. 总力方程：F_total = dP/dt = (C - V)*dm/dt + m*d(C - V)/dt
  3. 能量守恒：E = m*c^2 = hbar*omega
  4. 场互变：E = -f*dA/dt, curl(A) = B/f
