## 1. 唯一有明确阈值的可检验项：人工场（原文 §7.5）

核心方程：

```
∂B/∂t = −(g × E)/c²
g = (c²/|E|²) · ((∂B/∂t) × E)
```

五项可观测预言：

| 编号 | 预言 |
|---|---|
| P1 | 交变电磁场附近存在微小引力场振荡 |
| P2 | 信号频率等于电磁场频率（同频） |
| P3 | 信号幅度正比于 `E·∂B/∂t` |
| P4 | 信号方向垂直于 E 与 ∂B/∂t |
| P5 | 效率因子 `η ≈ 10⁻²⁶`（能量守恒约束） |

四条证伪标准（原文给定）：

| 编号 | 证伪条件 |
|---|---|
| F1 | 信噪比 < 1（未探测到信号） |
| F2 | 信号频率与电磁场频率不同 |
| F3 | 信号幅度不满足正比于 `E·∂B/∂t` |
| F4 | 效率因子 `η > 1`（违反能量守恒） |

原文推荐参数：`E = 10⁵ V/m`、`∂B/∂t = 10³ T/s`、`f = 1 kHz`，预期 `g ≈ 10⁻¹³ m/s²`，估计 `SNR ≈ 3.2`。

## 2. 物理层空白：A1–A3 没有失效阈值

已登记的三条本源公设（垂直原理、光速约束、螺旋参数化）在原文中**没有给出任何可使其失效的定量条件**：

| 公设 | 现有失效阈值 | 说明 |
|---|---|---|
| S12-A1 垂直原理 `r·v = 0` | 无 | 原文未给出偏离垂直的可测上限 |
| S12-A2 光速约束 `v ≡ c` | 无 | "内部运动"不可直接观测，原文未将其转写为可观测量 |
| S12-A3 螺旋参数化 | 无 | 参数 R、ω、b 的独立测量手段未定义 |

这意味着：本体系当前**不可证伪的部分多于可证伪的部分**。在补齐阈值前，A1–A3 只能作为 conjecture 登记，不得计入已验证结论。

## 3. 已识别的负结果与未解决项（原文 §10.2、§10.3）

- 人工场核心方程量纲自洽，但原方程预言比 LIGO 可探测强度大约 `10²⁰` 倍而至今未观测到；原文以效率因子 `η ≈ 10⁻²⁶` 修正，该修正本身是**为消除矛盾而引入**的待检验假设。
- 黑洞熵：螺旋几何化给出 `S ∝ A`，但系数与 Bekenstein-Hawking 差 0.882 倍，原文自述"待精确"。
- 宇宙学常数：视界截断解决量级，精确值依赖未定数值因子。
- GUT（SU(5) 已证伪）、SUSY（超伴子未探测到）、量子引力（弦论与 LQG 互不兼容）均非本体系结论，不得计入。
- 原文 §10.4 诚实声明：人类物理学目前没有被实验证实、逻辑自洽的万有理论；本体系"不是完整的万有理论"。
