## 〇、一句话结论

**「所有物理的最底层本质本源」在本库语境下的答案，不是「还没算出来」，而是「有一半在数学上就不是产生式的」。**

三条可机检的定理把这件事钉死：

1. **三本源 {kappa, tau, omega} 的张成格秩 = 2，且质量分量的指数恒为 0**
   ⇒ 「用螺旋导出质量」不是精度不够，是格子里没有这一维。
2. **{c, hbar, G} 在 (M,L,T) 上满秩（det = −2）** ⇒ 三个常数张成全部力学量纲，
   而它们的数值全是测量输入 ⇒ **任何有量纲量的「本源」都不可能是产生式的**。
3. **力学常数集的零空间为 0 维** ⇒ 不可能生成任何非平凡无量纲数 ⇒
   **alpha 不可能是量纲层的产物**（第二条独立路径：螺旋扇区唯一的无量纲坐标是圆周角 theta，而 theta 不被任何方程固定）。

**无量纲离散（整数 / 拓扑 / 表示论）→ 唯一可能内生**。
本库全部真成功（r67 的 U(1)、电荷量子化；r302 的三代、r305 的通量量子化）恰好都落在第三段，
全部失败（alpha、质量、Lambda）恰好都落在前两段。**这不是巧合，是维数。**

## 二、T02 · 常数基定理与冗余恒等式定理

以 (M,L,T) 为行、{c, hbar, G} 为列的 3x3 行列式 = **-2**（精确有理数，非浮点）。
⇒ 秩 3 = 满秩 ⇒ **任何力学量都可唯一写成三常数的幂次组合**。这就是普朗克单位制的定理形式：
量纲层的自由度只有 3。加入 e（Q 分量 1，其余 0）后秩升为 **4**。

但**冗余**出现了：再把 m_P、l_P 加进来（它们本来就是 {c,hbar,G} 的函数），
5 个常数在 3 维空间里必线性相关 ⇒ 零空间升为 **2 维**，整数基为：

- 系数 `[-1, -1, 1, 2, 0]` ⇒ 单式数值 = `1.0`（偏差 `1.55575e-61`）

- 系数 `[3, -1, -1, 0, 2]` ⇒ 单式数值 = `1.0`（偏差 `0.0`）

两条基向量对应的正是**普朗克单位的定义式本身**（m_P·l_P = hbar/c 与 G·m_P = c^2·l_P）。
⇒ **任何声称「由这批常数推出了一个新的无量纲数」的方案，其输出只可能等于 1。供给 0。**

## 三、T03 · 质量桥接：缺口是 1 维（theta），不是无穷维

解 `a[kappa] + b[tau] + x[hbar] + y[c] = [M]`：

```
(1 - b, b, 1, -1)
```

⇒ x = 1、y = −1 被钉死，只剩 `a + b = 1` 一维自由。任何「从螺旋导出质量」的式子必形如
`m = (hbar/c) * kappa^a * tau^(1-a)`，**唯一自由度就是 kappa/tau 的分配比（即角度 theta）**。

而 `m = hbar*omega/c^2` 与 `omega = m*c^2/hbar` 是同一式的双向重排（sympy 残差 `0`）⇒
**「由螺旋频率导出质量」不携带任何信息，omega 就是 m 的改名**（与 r264 一致，本册给出指数层证明）。

> **本册对本源问题唯一正面的产出**：缺口的形状是 **1 维**。
> 要给出质量绝对值，只需补 **1 条独立的 theta 定值方程**（且该方程不得使用质量数据）。
> 这比「我们还缺一整套理论」是一个可执行的 TODO，而不是一句安慰。

## 四、T04 · alpha 不可达定理（两条独立路径）

**路径一（零空间 0 维）**：{c,hbar,G} 满秩 ⇒ 要求无量纲则指数向量在零空间内，
而零空间为 **0 维** ⇒ 只有全零指数 ⇒ 结果恒等于 1。alpha = 7.2973525693e-3 ≠ 1，QED。

**路径二（单位圆角度）**：螺旋扇区的两个无量纲量 `Pi1 = kappa*c/omega`、`Pi2 = tau*c/omega`
在 `omega = c*sqrt(kappa^2+tau^2)` 下恒落单位圆（5 组样本最大残差 `1.56e-61`）。
⇒ 该扇区贡献的无量纲自由度是 1（圆周角），而 2 参数族被塌缩为 1 —— **与 r365 R16 的读数同构**，
本册把它升级为「因此 alpha 不可达」的结论。

两条路径的独立性很重要：路径一说明「搜不到」，路径二说明「搜到了也不是」。

## 十、诚实边界（红线）

1. **数学自洽 ≠ 物理证实**。本册是可算判决，**不产出新物理**，也不声称证明了「宇宙本源是什么」。
2. **本册不否证几何纲领**。定理说的是「几何是本源的形式，不是本源的数值」，
   而几何在定性结构（对称性 / 量子化 / 表示）上是唯一成功的部分 —— 这一点 r67 已单列。
3. **本册不约束其他机制**。弦紧致化、渐近安全、因果集等不受本册结论约束，
   因为它们未必把 {kappa,tau,omega} 当生成元。
4. **分层纪律**：r67（经验普查 14 项）、r137（判据层审计）、r377（结构定理）三册并存，
   **条目不可相加**，判词方向一致而论证层次不同。
5. **未做**：本册没有解出 theta 定值方程（那需要新物理输入），只证明了它「是 1 个方程的事」。
   把「1 维缺口」说成「已解决」是越界。
