2 · 三代链：V137 的流程图与本册的裁决

六维候选谱 16₁ + 16̄₀→ 纯规范项抵消 ✓→ 可约异常 I₈=y²Y₄→ GS 单张量 ✗ 无解→ S² 磁通唯一 ✓→ ind(D)=N→ 3×16 四维 ✓→ N=3 ✗ 不可辨识→ 味层级 ✗ 严格简并

2.1 双张量形式 = 代数恒等式

½[ ((X+Y)/√2)² − ((X−Y)/√2)² ] − XY ≡ 0　　对任意 X, Y　⇒ 判别力 0

任何乘积形式的八形式都能这样重写，包括明显不可消的反常。所以「存在实现 GS 的代数形式」这句话没有内容。

2.2 完美平方无解 ⇒ 六维单张量 GS 不可实现

求 X = αp₁ + βQ + γy²　使　X∧X = κ·I₈^total p₁² 系数 α² = 0 ⇒ α = 0 Q² 系数 β² = 0 ⇒ β = 0 Qy² 系数 2βγ = 1/2 ⇒ 要求 β ≠ 0　　← 矛盾，无解

第二路（α,β,γ ∈ [−6,6]³ 整数枚举，要求六项同比例、零项为零）：0 命中。与 r390（ROOT V56）「GS 平方不可分解」一致，按同源计 1 份。

2.3 四维侧反而自洽，代价是 U(1)_F 变重

I₆ = y₄ ∧ ( 3Q − 2p₁ + 8y₄² )　　残差 0 ⇒ 单个轴子即可消四维反常 ⇒ U(1)_F 反常、被轴子吃掉相位、必须变重

「精确匹配」的含义是四维确实带反常，不是「反常无害」。V137 全篇未引入 B 场/轴子，四维消反常这一步并未落地。

4 · 背景与稳定性

4.1 记分项：S² 是常曲率二维内空间中的唯一解

内空间k外方程 k/R² = 2Λ₆ > 0判定
S²+1R² = 1/(2Λ₆)唯一相容
T²00 = 2Λ₆排除
H²−1−1/R² = 2Λ₆排除

适用范围：二维、常曲率、唯一源为磁通。非常曲率二维几何与维度 >2 的内空间未被覆盖。

4.2 radion：「稳定」是背景方程的同义反复

V(0)=0 ∧ V′(0)=0 ⇒ B=A, C=2A（唯一，仅差标度） ⇒ V = A·u(1−u)², u=e^{−2σ} ⇒ V≥0 恒真、V″(0)=8A 恒正 ⇒ σ→∞ 时 V→0：与 σ=0 简并的渐近真空（退紧致化渐近免费）

两条「稳定性结论」都由背景方程直接推出，判别力 0；且「稳定」只能是局部的，不构成模量固定。

4.3 中性 16̄ 无零模：成立，但依赖曲率符号

Lichnerowicz D²=∇*∇+R/4，S² 上 R/4=1/(2R₀²)>0；独立第二路圆球谱 ±(l+1)/R₀ 无零。负对照：平坦 T² 有常数零模 ⇒ 结论随曲率符号反转，不能独立支持「选 S²」，只能与 4.1 联用。

5 · 味结构：三重态简并定理

N=3 的三个零模 = 单极荷 3 的零模：l=(|N|−1)/2=1，dim=2l+1=3 ⇒ SO(3) 不可约三重态 与 J_z、J± 同时交换的 3×3 矩阵空间维数 = 1（Schur） ⇒ 树级 Yukawa ∝ 1₃ ⇒ 三代严格简并

模型对 13 个味观测（9 个带电费米子质量 ＋ 4 个 CKM 参数）解释 0 个。要破简并必须显式破坏 SO(3)：第二磁通、内部缺陷或非平凡 Higgs 剖面——都是新输入。即使 N=3 被推导出来，味层级问题也原封不动。
