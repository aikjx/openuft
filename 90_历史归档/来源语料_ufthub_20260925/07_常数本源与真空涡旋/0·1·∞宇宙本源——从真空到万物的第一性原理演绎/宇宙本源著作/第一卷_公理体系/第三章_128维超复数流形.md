# 第三章 128维超复数流形$\mathcal{M}^{128}$的拓扑与微分结构

## 3.1 拓扑空间的基本概念回顾

拓扑学是研究空间在连续变换下不变性质的数学分支，它不依赖于距离、角度等度量概念，只关心空间的"连通性"、"紧致性"、"洞"等最基本的几何性质。我们的真空流形首先是一个拓扑空间，然后才具有微分结构和度量结构。

**定义3.1.1（拓扑空间）**：一个拓扑空间是一个集合$X$加上一个子集族$\tau\subseteq 2^X$（称为开集族），满足：
1. 空集$\emptyset$和全集$X$属于$\tau$
2. 任意多个开集的并集属于$\tau$
3. 有限多个开集的交集属于$\tau$

$\tau$称为$X$上的拓扑，$(X,\tau)$称为拓扑空间。

**定义3.1.2（连续映射）**：两个拓扑空间$X,Y$之间的映射$f:X\to Y$称为连续的，如果$Y$中任意开集的原像都是$X$中的开集。

**定义3.1.3（同胚）**：如果连续映射$f:X\to Y$是双射且其逆映射也连续，则称$f$是同胚，称$X$和$Y$是同胚的拓扑空间。同胚的空间在拓扑学中是等价的。

拓扑空间的这些定义完全可以从0·1·∞三元本体论导出：开集对应"存在"（1），闭集对应"非存在"（0），连续映射对应"生成过程"（∞）。拓扑学本质上是三元辩证结构在空间上的表现。

## 3.2 超复数流形的定义

流形是局部看起来像欧几里得空间的拓扑空间，它是现代几何学的基本研究对象。我们的真空不是平直的欧几里得空间，而是一个弯曲的流形，物质和能量就是这个流形的弯曲和扭转的表现。

**定义3.2.1（全域超复数流形$\mathcal{M}^{128}$）**：128维全域超复数流形$\mathcal{M}^{128}$是一个第二可数豪斯多夫拓扑空间，且满足：对任意点$p\in\mathcal{M}^{128}$，存在$p$的开邻域$U$和同胚$\varphi:U\to\mathbb{U}$（其中$\mathbb{U}$是全域超复数系，作为128维实线性空间），使得任意两个这样的坐标卡$(U,\varphi)$和$(V,\psi)$的转移函数：
$$\psi\circ\varphi^{-1}: \varphi(U\cap V)\to\psi(U\cap V)$$
是$\mathbb{U}$上的光滑（无限可微）函数，且保持$\mathbb{U}$的超复数乘法结构，即对任意$u,v\in\varphi(U\cap V)$，有：
$$\psi\circ\varphi^{-1}(uv) = \psi\circ\varphi^{-1}(u)\cdot\psi\circ\varphi^{-1}(v)$$

也就是说，$\mathcal{M}^{128}$是一个以全域超复数系$\mathbb{U}$为模型空间的光滑流形，且其转移函数是$\mathbb{U}$的自同构，因此$\mathcal{M}^{128}$不仅是实流形，还是一个超复流形。

**命题3.2.1（$\mathcal{M}^{128}$的拓扑性质）**：$\mathcal{M}^{128}$是连通、单连通、可定向、仿紧的光滑流形。

**证明**：
- **连通性**：任意两个点都可以通过连续路径连接，因为坐标卡之间的转移函数是光滑的，局部连通性推出整体连通性。
- **单连通性**：所有闭曲线都可以连续收缩到一点，因为$\mathbb{U}$作为128维欧几里得空间是单连通的，流形的单连通性是局部性质。
- **可定向性**：$\mathbb{U}$的自同构保持定向（因为超复数乘法的行列式为正），因此流形可定向。
- **仿紧性**：第二可数的局部紧豪斯多夫空间是仿紧的，这是拓扑学中的基本定理。$\square$

## 3.3 切空间与余切空间

流形上每一点都有一个切空间，它是流形在该点的"线性近似"，描述了流形在该点的所有可能的运动方向。

**定义3.3.1（切向量）**：点$p\in\mathcal{M}^{128}$处的切向量$v$是一个映射$v:C^\infty(\mathcal{M}^{128})\to\mathbb{R}$，满足：
1. **线性性**：$v(af+bg) = av(f)+bv(g)$对任意$a,b\in\mathbb{R}, f,g\in C^\infty(\mathcal{M}^{128})$
2. **莱布尼茨法则**：$v(fg) = f(p)v(g) + g(p)v(f)$

点$p$处所有切向量构成的线性空间称为切空间，记为$T_p\mathcal{M}^{128}$，其维数为128，与模型空间$\mathbb{U}$同构。

在局部坐标$\{x^I | I\subseteq\{1,\dots,7\}\}$下，切空间的自然基为$\{\partial_I = \frac{\partial}{\partial x^I}\}$，任意切向量可以表示为：
$$v = \sum_I v^I \partial_I$$

**定义3.3.2（余切向量）**：切空间的对偶空间称为余切空间，记为$T_p^*\mathcal{M}^{128}$，其元素称为余切向量，是切空间上的线性泛函。余切空间的自然基为$\{dx^I\}$，满足$dx^I(\partial_J) = \delta^I_J$。任意余切向量可以表示为：
$$\omega = \sum_I \omega_I dx^I$$

由于$\mathcal{M}^{128}$是超复流形，切空间和余切空间都自然地具有$\mathbb{U}$-模结构，即可以用全域超复数数乘切向量和余切向量，而不仅仅是实数。这是超复流形比普通实流形更丰富的结构。

## 3.4 张量场与微分形式

张量是多重线性代数的基本对象，它描述了流形上的几何量和物理量。在我们的理论中，所有物理量本质上都是流形上的张量场。

**定义3.4.1（张量）**：点$p$处的$(k,l)$型张量是多重线性映射：
$$T: (T_p^*\mathcal{M}^{128})^k \times (T_p\mathcal{M}^{128})^l \to \mathbb{R}$$
所有$(k,l)$型张量构成的线性空间记为$T^k_l(T_p\mathcal{M}^{128})$，维数为$128^{k+l}$。

在局部坐标下，$(k,l)$型张量可以表示为：
$$T = T^{I_1\dots I_k}_{J_1\dots J_l} \partial_{I_1}\otimes\dots\otimes\partial_{I_k}\otimes dx^{J_1}\otimes\dots\otimes dx^{J_l}$$

**定义3.4.2（微分形式）**：$(0,k)$型反对称张量称为$k$次微分形式，所有$k$次微分形式构成的空间记为$\Lambda^k(T_p^*\mathcal{M}^{128})$。外积运算$\wedge$使得所有微分形式构成外代数$\Lambda^*(T_p^*\mathcal{M}^{128}) = \bigoplus_{k=0}^{128}\Lambda^k(T_p^*\mathcal{M}^{128})$。

特别地，1次微分形式就是余切向量，2次反对称张量描述了旋转和电磁场，4次反对称张量描述了体积元和引力场。

**定义3.4.3（外微分）**：外微分算子$d:\Lambda^k(\mathcal{M}^{128})\to\Lambda^{k+1}(\mathcal{M}^{128})$定义为：
$$d\omega = \frac{1}{k!}\frac{\partial \omega_{I_1\dots I_k}}{\partial x^J} dx^J\wedge dx^{I_1}\wedge\dots\wedge dx^{I_k}$$
外微分满足$d^2=0$，这是庞加莱引理的内容，它是麦克斯韦方程组和 Bianchi 恒等式的数学基础。

## 3.5 联络与协变导数

为了比较流形上不同点的张量，我们需要联络的概念，它描述了张量如何从一个点"平行移动"到另一个点。

**定义3.5.1（仿射联络）**：仿射联络$\nabla$是一个映射：
$$\nabla: \mathfrak{X}(\mathcal{M}^{128})\times\mathfrak{X}(\mathcal{M}^{128})\to\mathfrak{X}(\mathcal{M}^{128}),\quad (X,Y)\mapsto\nabla_X Y$$
满足：
1. **线性性**：$\nabla_{fX+gY}Z = f\nabla_X Z + g\nabla_Y Z$
2. **莱布尼茨法则**：$\nabla_X(fY) = f\nabla_X Y + (Xf)Y$
其中$\mathfrak{X}(\mathcal{M}^{128})$是流形上的光滑向量场空间，$f,g\in C^\infty(\mathcal{M}^{128})$。

在局部坐标下，联络由克里斯托费尔符号$\Gamma^I_{JK}$表示：
$$\nabla_{\partial_J}\partial_K = \Gamma^I_{JK}\partial_I$$
因此协变导数对向量场$Y=Y^I\partial_I$的作用为：
$$\nabla_J Y^I = \partial_J Y^I + \Gamma^I_{JK}Y^K$$

**定义3.5.2（超复联络）**：在超复流形$\mathcal{M}^{128}$上，我们要求联络与超复结构相容，即对任意超复数$u\in\mathbb{U}$和向量场$X,Y$，有：
$$\nabla_X(uY) = u\nabla_X Y$$
这意味着联络不仅保持线性结构，还保持超复数乘法结构，这样的联络称为超复联络。

## 3.6 曲率与挠率

曲率和挠率是联络的两个基本不变量，它们描述了流形的弯曲和扭转程度。在广义相对论中，曲率对应引力，而在我们的理论中，挠率同样是基本的物理量，对应自旋和弱相互作用、强相互作用。

**定义3.6.1（挠率张量）**：联络$\nabla$的挠率张量$T$是一个(1,2)型张量，定义为：
$$T(X,Y) = \nabla_X Y - \nabla_Y X - [X,Y]$$
其中$[X,Y] = XY-YX$是向量场的李括号。在局部坐标下，挠率张量的分量为：
$$T^I_{JK} = \Gamma^I_{JK} - \Gamma^I_{KJ}$$
挠率为零的联络称为无挠联络，广义相对论中使用的列维-奇维塔联络就是无挠联络，但我们将看到，真空的基本联络是有挠的，挠率是自旋相互作用的几何起源。

**定义3.6.2（曲率张量）**：联络$\nabla$的曲率张量$R$是一个(1,3)型张量，定义为：
$$R(X,Y)Z = \nabla_X\nabla_Y Z - \nabla_Y\nabla_X Z - \nabla_{[X,Y]}Z$$
在局部坐标下，曲率张量的分量为：
$$R^I_{JKL} = \partial_K\Gamma^I_{JL} - \partial_L\Gamma^I_{JK} + \Gamma^I_{MK}\Gamma^M_{JL} - \Gamma^I_{ML}\Gamma^M_{JK}$$
曲率张量描述了流形的弯曲程度，当绕一个小闭合回路平行移动一个向量时，向量的转动量由曲率张量决定。

**定义3.6.3（嘉当结构方程）**：我们可以用标架（活动标架）语言重新表述曲率和挠率。取局部标架$\{e_a\}$和对偶标架$\{e^a\}$，联络1形式为$\omega^a_b = \Gamma^a_{bc}e^c$，挠率2形式为$T^a = \frac{1}{2}T^a_{bc}e^b\wedge e^c$，曲率2形式为$R^a_b = \frac{1}{2}R^a_{bcd}e^c\wedge e^d$，则嘉当结构方程为：
$$de^a = -\omega^a_b\wedge e^b + T^a$$
$$d\omega^a_b = -\omega^a_c\wedge\omega^c_b + R^a_b$$
这两个方程是微分几何中最基本的方程，它们将外微分、联络、挠率、曲率联系在一起，是我们推导引力场方程和其他相互作用场方程的基础。

## 3.7 度量与列维-奇维塔联络

度量是流形上的内积结构，它定义了长度、角度、体积等几何量。

**定义3.7.1（黎曼度量）**：$\mathcal{M}^{128}$上的黎曼度量$g$是一个对称、正定的(0,2)型张量场，即对任意点$p$和任意切向量$v,w\in T_p\mathcal{M}^{128}$，$g_p(v,w)$是一个实数，满足：
1. **对称性**：$g(v,w) = g(w,v)$
2. **正定性**：$g(v,v)\geq0$，且$g(v,v)=0$当且仅当$v=0$
3. **光滑性**：$g$在流形上光滑变化

在局部坐标下，度量表示为$g = g_{IJ}dx^I\otimes dx^J$，向量的长度平方为$|v|^2 = g_{IJ}v^Iv^J$。

在超复流形上，我们要求度量与超复结构相容，即对任意$u,v,w\in T_p\mathcal{M}^{128}$，有：
$$g(uv,uw) = |u|^2 g(v,w)$$
也就是说，超复数数乘保持向量的长度比例，这样的度量称为超复厄米度量。

**定理3.7.1（嘉当第一结构定理）**：对于给定的度量$g$，存在唯一的无挠联络$\nabla$（称为列维-奇维塔联络），使得度量与联络相容，即$\nabla g=0$，也就是平行移动保持内积不变。

列维-奇维塔联络的克里斯托费尔符号可以通过度量表示为：
$$\Gamma^I_{JK} = \frac{1}{2}g^{IL}\left(\partial_J g_{LK} + \partial_K g_{LJ} - \partial_L g_{JK}\right)$$

然而，我们将在第二卷中看到，真空的基本联络不是列维-奇维塔联络，而是嘉当联络，它同时具有曲率和挠率，是度量相容的有挠联络。列维-奇维塔联络只是嘉当联络在忽略挠率时的低能近似。

## 3.8 本章小结

本章我们定义了128维全域超复数流形$\mathcal{M}^{128}$，这是真空的基本几何舞台。我们回顾了拓扑空间、切空间、余切空间、张量场、微分形式、联络、曲率、挠率、度量等微分几何基本概念，定义了超复流形特有的超复联络和超复度量，给出了嘉当结构方程，为后续的物理推导奠定了几何基础。

特别重要的是，我们引入了挠率的概念，这是广义相对论中被忽略的几何量，但在我们的理论中，挠率与曲率同等重要，它们分别对应不同类型的基本相互作用。下一章我们将研究流形上的双向对偶算子群，也就是真空的对称群，所有的物理守恒律都将来自这个群的对称性。
