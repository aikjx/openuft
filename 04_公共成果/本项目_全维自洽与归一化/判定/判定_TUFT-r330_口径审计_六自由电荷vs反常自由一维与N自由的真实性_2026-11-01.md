# 判定_TUFT-r330_口径审计 · 六自由电荷 vs 反常自由一维

**★本卷攻 r306/r318/r322 自身的口径**：它们的 `A=diag(d_i)` 是 6 维自由电荷（=任意电荷、破反常自由）；r305 证反常自由荷空间 1 维（span Y）。本卷机检 m=1 下 N=3 是否仍自由。

## §判决（主条目 10：PASS 7 / FAIL 0 / INFO 3）

- **[P1] INFO · 口径审计的问题：六自由电荷 vs 反常自由一维**：**疑点（本卷攻自身前卷）**：r306 的 `A=diag(d_i)` 被描述为「任意多 U(1) 通量 + 任意电荷，每个表示独立电荷 X_i」——这是 **6 维自由电荷空间**。但 r305 Thm S 证明：**反常自由下荷空间严格 1 维、就是 `span(Y)`**（SM 超荷），且 r309 Thm S 进一步证 m 个 U(1) 全共线。若电荷被钉死为超荷，则 `X_i = Y_i·M`（单一通量量子 M），**不是 6 个独立自由度**。⇒ 必须机检：r318/r322 的「N 自由」是否依赖了**破反常自由**的假设？

- **[P2] PASS · 机检:超荷 Y 反常自由;且 r318 的 X=(0,1,1,0,3,3) 不平行于 Y（破反常自由）**：① **超荷 Y=['1/6', '-2/3', '1/3', '-1/2', '1', '0'] 的四条反常系数 = ['0', '0', '0', '0']**（SU3² / SU2² / grav / U³ 全为 0）⇒ Y 反常自由。② `d_i·Y_i = [1, -2, 1, -1, 1, 0]`（整数，True）。③ r318 的显式构造只用 X=[0, 1, 1, 0, 3, 3] 作通量贡献；检验是否存在 M 使 `X_i = Y_i·M`：**Y_ν=0 但 X_ν=3≠0** ⇒ **不存在这样的 M**（平行检测返回=False）⇒ **r318 的 X 不在 span(Y) 内，其构造破反常自由**。

- **[P3] PASS · 反常自由（m=1，X=Y·M）下 N=3：64 个 0/1 模式中仅 g=全1（纯复制）**：令 A=[d_i·Y_i | g]（2 列：单通量 M 与扭转份数 Ytw），枚举 64 个 g 检验 A·t=3·𝟙。**可解集 = [[1, 1, 1, 1, 1, 1]]（仅 1 个）**，且就是 g=全1；此时解为 t=[0, 3]（M=0，Ytw=3，index=[3, 3, 3, 3, 3, 3]）。⇒ **反常自由下 N=3 只有「全向 3 份复制」一条路**（无通量、无差别扭转）——正是 r306 说的「把 3 代写进去」。★N=6 正对照：1-dim 下可解（纯通量 lcm=6 仍成立）=True。

- **[P4] PASS · 对照（m=6，r318 模型）：64 个中 16 个可解（复现 r318）**：同一 64 个 g，但用 r318 的 m=6 模型 `A=[diag(d_i)|g]`（X_i 独立）：可解 = **16** 个（即 g0=g3=1，其余任意）。⇒ **r318 的「16/64」确实是 6 维电荷模型的产物**；一旦把电荷钉到反常自由 1 维，可解面从 16 塌到 **1**。

- **[P5] PASS · 结论：r318/r322 的「N 自由」是反常破缺模型的产物；物理（m=1）下 N=3 强制纯复制**：r318 判词 `NO-GO-DOWNGRADED-TO-FREE`、r322 `NO-GO-NOT-RESURRECTED` 均在 **m=6（任意电荷、破反常自由）** 模型内成立。本卷证明：**反常自由（m=1）下 N=3 只剩纯复制（全向 3 份）**，与非平凡扭转无关。⇒ **判词修正**：r318 的「N 自由」应降级为「**N 自由仅在破反常自由的任意电荷模型内成立；反常自由最小 SM 下 N=3 由纯复制给出（=注入 3）**」。这与 r305/r307/r309 的 NO-GO 一致。

- **[P6] INFO · 诚实边界：m≥2（额外反常自由 U(1)）与 5/6 表示数未定**：本卷结论**条件于**：(i) 规范群为**最小 SM**（仅 U(1)_Y 一个），故 m=1；(ii) 表示内容含 ν^c 且 Y_ν=0（这是 1-dim 下 N=3 强制全 1 的关键——若第 6 个表示超荷非零，结论会变）。**未覆盖**：(a) 若模型额外含反常自由的 U(1)（如 B-L 或其它），m≥2，电荷空间升维，N=3 可能重新可达——这是**模型依赖**的，本卷不假设；(b) 表示数 5（无 ν^c）vs 6 的差异（r302 用 5、r296/r306 用 6，本库已知不一致）——5 表示下需另算。这些列 X-R330-1/2。

- **[P7] PASS · 判据集 R1–R11（R11 = 反常自由下 N 自由是否仍成立）**：在 r306 的 R1–R8、r318 的 R9、r322 的 R10 上新增 **R11「反常自由（m=1）下 N_gen 是否仍自由」**。结论：R11=**否**（P3 机检只有纯复制）⇒ 对「框架能自由产出任意 N」这一命题，判据集 **0/11**（框架不能；只能注入）。★这是**自我修正**，如实登记：r318/r322 的乐观判词被本卷下调。

- **[P8] INFO · 判词修正声明（对 r318/r322 的降级）**：**修正链**：r306 `NO-GO-STABLE`（m=6 下 3 不可）→ r318 `NO-GO-DOWNGRADED-TO-FREE`（m=6 下加扭转可 3）→ r322 `NO-GO-NOT-RESURRECTED`（结构约束不救回）→ **本卷 r330**：r318/r322 全在 **m=6（破反常自由）** 模型内；**反常自由（m=1，最小 SM）下 N=3 强制纯复制**。⇒ **净结论（与 r305/r307/r309 一致）**：本框架**不预言 3**，只能把 3 作为**复制份数/扭转份数**注入；「N 自由」是电荷模型自由度的假象，不是物理机制。

- **[P9] PASS · 新定理：等指标超荷 ⟺ 破反常自由；反常自由强制 d_i·Y_i 非均匀（含负、含零）**：「纯通量给出每代一份的等指标谱」需要 `d_i·Y_i` 为**常数**（∀i），此时单个 M 使 `index_i = d_iY_i·M` 全等。检验该唯一可能电荷 `Y^eq_i = 1/d_i = ['1/6', '1/3', '1/3', '1/2', '1', '1']`：四条反常系数 = **['1/2', '1/2', '6', '5/2']** ⇒ **非零，破反常自由**（Y^eq 反常自由 = False）。反过来，反常自由（唯一方向 span(Y)，前提取自 r305 Thm S）强制 `d_i·Y_i ∝ (1,−2,1,−1,1,0)`，它 **含负项（位 [1, 3]：[Fraction(-2, 1), Fraction(-1, 1)]）与零项（位 [5]：0）且非常数（False）**。⇒ **在反常自由下，纯通量结构上不可能给出等指标谱**；`n_R≡N` 只能由常数扭转（复制）提供。★这一步把「三代不可得」的原因从「通量不够」改判为「**超荷非均匀**」，是比 r306/r318 更硬的机制定位。

- **[P10] PASS · 非平凡解计数（剔除纯复制）：m=6 有 15，m=1 恰为 0；三段负对照全部真移动**：**非平凡解 = 可解且 g≠全1**（真扭转/真通量）。读数：m=6（r318 模型）可解 16、其中非平凡 **15**；m=1（反常自由）可解 1、其中非平凡 **0**（唯一解就是纯复制）。⇒ **反常自由下「用机制造出 3」的非平凡解数 = 0**。★三段判别力档（每一档都必须改变读数，否则是恒绿装饰）：①`d_i` 全改 4（4∤3）⇒ 可解 1、非平凡 **0**；②`d_i` 全改 3（3|3）⇒ 可解 64、非平凡 **63**；③把 `d_i·Y_i` 全改 1（等指标超荷，破反常）⇒ 可解 64、非平凡 **63**。⇒ 计数器在 15 / 0 / 63 三点间真实移动，判别力已证。

## §判词

**EQUAL-INDEX-UNDER-ANOMALY-FREEDOM-IMPOSSIBLE / N-FREE-IS-ANOMALY-VIOLATING-ARTIFACT**：

① r318/r322 的「N 自由 / NO-GO 降级」依赖 6 维任意电荷（破反常自由）模型；反常自由（最小 SM，m=1）下 N=3 **非平凡解 = 0**，只剩纯复制。

② 更硬的机制定位（本卷新增）：挡住「通量给三代」的**不是通量自由度不足，而是超荷非均匀性** —— 反常自由把 `d_i·Y_i` 钉在 `(1,−2,1,−1,1,0)`（含负、含零），单通量不可能给出等指标谱；而唯一能给出等指标谱的「等指标超荷」`Y_i=1/d_i` **破反常自由**（残差 ['1/2', '1/2', '6', '5/2']）。两条要求互斥。

③ ⇒ 净结论（与 r305/r307/r309 一致）：本框架**不预言 3**，3 只能作为复制份数注入；r318 的「N 自由」是电荷模型自由度的假象。
