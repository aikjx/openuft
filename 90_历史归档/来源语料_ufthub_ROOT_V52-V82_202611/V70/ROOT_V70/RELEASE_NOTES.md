# ROOT V70 发布记录

- 以 V69 为基线，但不复制未审查的四力大统一推断。
- 加入地球 J₂ 三维解析加速度与有限差分交叉检验。
- 增加同外部场不同内部密度分层的严格反例。
- 区分旋转系离心/科里奥利与真实引力及潮汐。
- 加入微观 1 mm 红移差分式，并在测试中发现且修复直接相减造成的浮点消去误差。
- 新增三个假设性来源的可辨识性线性代数：固定环境秩 1，多条件合成设计秩 3。
- 新增 54 个行星纬度/高度物理计算场景、162 个标记为合成的材料特征行、六张计算图和网页。
- 核验时必须实际运行测试；不预填测试通过数量。
- 仍未从空间螺旋独立推导 G、统一标准模型规范群、证明量子一致性或取得新实验支持。
