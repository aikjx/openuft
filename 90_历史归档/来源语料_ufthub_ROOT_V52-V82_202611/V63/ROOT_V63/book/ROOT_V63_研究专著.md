# ROOT V63｜空间螺旋、有效引力与四力统一的严格数学审计

**工作性质：研究型文稿 / 模型可计算性审计，而非新的四力大统一证明**  
**日期：2026 年 11 月 17 日**  
**关键词：** 空间螺旋、曲率、挠率、场的作用量、热核、诱导引力、规范理论、参数不可识别、可证伪性

## 摘要

提出的问题是：空间以光速进行螺旋运动能否产生引力、确定牛顿常数 G 并统一电磁、强、弱相互作用？本文将问题分解为可严格推导的曲线运动学、假设性圆柱场波模、通用能动张量和特定正则化下的单圈诱导引力四个模块。计算得到：速度分解与曲线曲率挠率为欧氏数学恒等式；圆柱波动模式在给定场方程下满足确定的色散关系；由标量场量子涨落可得到一个依赖紫外截止与曲率耦合的有效 Einstein–Hilbert 项；并明确指出这个曲率系数不具有在未指定微观谱及重整化条件下独立确定 G 的能力。将 GR 与标准模型写入一个总作用量是合法的数学并列，而不是四力具有共同本原的证明。程序包含数值扫描、自动测试、浏览器交互、反例审核及证伪路线图。

## 1. 问题拆解与证明等级

### 1.1 三种截然不同的“统一”

1. **记号层统一**：把多种力写到一个公式，例如 `F=m g+q(E+v×B)+...`，但该式并未统一动力学本源。
2. **共同形式层统一**：变分原理统一组织 GR、SM 的方程，可能仍有独立的度规、规范群、多个耦合和物质表示。
3. **本原动力学层统一**：从少数无需输入观测值的公设，导出粒子谱、作用量、全部耦合、G 与可测可证伪的数值结果。

本研究完成第一层、已知理论的第二层组织和一部分候选机制审计，尚未完成第三层。

### 1.2 “空间光速螺旋”必须先指定本体

对一条欧氏曲线设定速率 c，只是指定参数化。若把它当作有静质量粒子的物理轨迹，将与惯性系中有质量粒子局域速率小于 c 的事实不兼容。若把它当作光子轨迹，真空 Minkowski 时空中的自由光子沿零测地线传播，螺旋的非零空间向心加速度需要外场、几何或其他可写出的动力学来源。更合理的研究候选是把螺旋视为**场的内部相位模式**，而不是普通粒子的经典轨道；但两者之间的映射必须另行证明。

## 2. 几何层：完整的可证明螺旋方程

取

`r(t)=(R cos(ωt), R sin(ωt), ut)`，`R>0`，`ω,u` 为常数。计算

`v=(-Rω sin(ωt),Rω cos(ωt),u)`；`a=(-Rω² cos(ωt),-Rω² sin(ωt),0)`。

故 `|v|²=R²ω²+u²`，`a·v=0`。把速率设为常数 `v0`，定义 `Rω=v0 cos λ`、`u=v0 sin λ`，得

`κ=|v×a|/|v|³=Rω²/v0²=cos² λ/R`，

`τ=[(v×a)·r'''(t)]/|v×a|²=uω/v0²=sin λ cos λ/R`，

`|a|=v0² κ=v0² cos²λ/R`。

当选取 `v0=c`，这些式子保持成立，但**没有因此证明任何物理对象必须以速率 c 螺旋**。当 `λ→90°` 时曲线退化为直线，其曲率为零，Frenet 法向量不再唯一，避免将数值公式误解释为物理作用消失。

**角度与垂直性**：Frenet 三标架 `T=v/|v|`，`N=a/|a|`，`B=T×N` 在曲率非零时正交。此正交仅是运动曲线的局部几何关系，不能推出 `F_g ⟂ F_e ⟂ F_b`。反例：若重力和电场均沿 `-z`，则二者点积不为零。相反 `q(v×B)` 必与 `v` 和 `B` 正交，这是洛伦兹力结构的直接结果。

## 3. 场论层：可复算的圆柱波模

为了避免“光子在光速传播中内部仍以光速旋转”带来的速度相加矛盾，将研究对象改为半径 `R` 的理想圆柱面上的标量波：

`[∂_t² - c²(∂_z²+R⁻²∂_θ²) + (mc²/ℏ)²] φ = 0`。

对 `φ=exp(i(nθ+k_z z-Ωt))`，`n` 为非零整数，得到

`Ω²=c²[k_z²+(n/R)²+(mc/ℏ)²]`。

对连续波数形式的色散关系，有 `v_g,z=c²k_z/Ω`，形式上的环向分量 `v_g,φ=c²(n/R)/Ω`。因此

`v_g²/c²=[k_z²+(n/R)²]/[k_z²+(n/R)²+(mc/ℏ)²]≤1`。

对于 `m=0`，形式群速为 c；对于 `m>0`，低于 c。由于 `n` 在圆柱面上离散，环向“群速度”并非普通连续微分变量的直接测量量。上述色散关系描述指定自由波动方程，不证明时空由这种圆柱壳构成，亦不自动包含光子自旋、规范不变性或粒子全部质量谱。

## 4. 引力从微观运动产生：已经成立与没有成立的部分

相对论动理学中，对适当归一化的质量壳不变动量测度 `dP`，粒子分布 `f(x,p)` 给出

`T^{μν}(x)=∫ p^μ p^ν f(x,p) dP`。

当粒子分布具有各向同性，得到理想流体应力能量张量，能量密度、压强、动量流等由微观运动产生。若另外采用爱因斯坦–希尔伯特作用量

`S_grav= (c⁴/16πG)∫√(-g)(R-2Λ)d⁴x`

并进行度规变分，得到

`G_{μν}+Λ g_{μν}=8πG T_{μν}/c⁴`。

弱场、慢速、近静态下由 `g_{00}≈-(1+2Φ/c²)` 得 `∇²Φ=4πGρ`，球对称外部 `g=GM/r²`。**这一推导采用了预先含有 G 的 GR 作用量，因此不构成“从微观运动独立算出 G”的证明**。

## 5. 第一条可计算候选路线：诱导引力

### 5.1 指定系统及近似

在欧氏四维背景上考虑 `N` 个独立相同的实标量场。二次型算子

`D=-∇² + m² + ξR`。

把标量量子涨落积掉得到单圈有效作用量

`Γ^(1)= 1/2 Tr log D = -1/2∫_{ell²}^∞ (ds/s) Tr exp(-sD)`，

其中以自然单位 `ℏ=c=1` 表示，`ell²` 是硬固有时间 UV 截止。热核在小 `s` 下

`Tr exp(-sD) ≃ (4πs)^-2∫√g exp(-sm²)[1+s(1/6-ξ)R+O(s²)] d⁴x`。

故局部 `R` 项为

`Γ_R^(1)=-(1/32π²)(1/6-ξ) [∫_{ell²}^∞ exp(-sm²) ds/s²]∫√g R d⁴x`。

定义 `μ=m ell` 和无量纲函数

`F(μ)=∫_0^1 exp(-μ²/t) dt`，则括号积分为 `F(μ)/ell²`。对 `μ>0` 也有 `F(μ)=exp(-μ²)-μ² E1(μ²)`；在 `μ=0`，`F=1`。

按欧氏引力作用量 `S_E,grav=-(1/16πG)∫√g R+...` 的相同曲率约定匹配，得

`1/G_eff=1/G_bare + N(1-6ξ)F(μ)/(12πell²)`（自然单位）。

恢复 SI 单位，其中 `μ=m c ell/ℏ`：

**`1/G_eff = 1/G_bare + N(1-6ξ) ℏ F(μ)/(12π c³ ell²)`**。

如果并且仅如果额外设定 `G_bare^{-1}=0`、`m=0`、`ξ=0`，可写为

**`G_ind = 12π c³ell²/(Nℏ)`**。

这是指定正则化与假设的计算结果，不是从光速螺旋独立推导出来的物理定律。热核有效作用量中还可能出现宇宙学常数项、二阶曲率项和非局域项，不能只保留 R 项就宣布得到完整引力理论。

### 5.2 不能忽略的正规化与物理限制

- **正则化方案依赖**：二次发散系数与 cutoff 方案有关，需物理重整化条件；物理 G 必须通过完整模型和观测定义。
- **裸参数自由度**：如果未解释为什么 `1/G_bare=0`，即使知道涨落修正也不能唯一决定 `G_eff`。
- **粒子谱未知**：`N, ξ, m`、统计符号、物质表示都没有从 ROOT 几何公设推出。
- **宇宙学常数难题**：相同热核含约 `ℏc/ell⁴` 量级的真空能项，极大，不能直接等同于实测暗能量；需反项或机制解释。
- **动力学度规缺口**：在先验曲背景上计算 `Γ[g]` 并不意味着基础微观理论已经证明了度规自身的动力学存在或重整化一致性。

### 5.3 从观测 G 反向标定，明确不能误标成预测

令 `G_obs=6.67430×10⁻¹¹ m³ kg⁻¹ s⁻²`，`ell_P=sqrt(ℏG_obs/c³)`。上述最简模型的反求长度

`ell_fit=sqrt[N(1-6ξ)/(12π)] ell_P`。

例如 `N=1, ξ=0` 时 `ell_fit≈2.6323542×10⁻³⁶ m`。这只是 `G_obs` 的改写，不是第一次原理的新预测。如果使用 `ell=ell_P` 再令 `N=1`，得到 `G_ind/G_obs=12π≈37.699`，说明随意把“截止长度”定为普朗克长度并不能自动得到观测 G。

量纲限制更严格：`[G]=L³ M⁻¹ T⁻²`，单独由 `[c]=LT⁻¹` 与 `[ℏ]=ML²T⁻¹` 不能构造 G；至少需要有独立长度平方或对应的质量/能量尺度。`G∝c³ell²/ℏ` 是量纲形式，不决定 `ell` 的物理来源。

## 6. 四力统一的正确数学表述

标准模型规范群为 `SU(3)_C×SU(2)_L×U(1)_Y`，与引力的几何描述不同。可以并列写出

`S_total= S_EH[g] + ∫d⁴x√(-g) L_SM(g, A^A_μ, ψ, H) + S_ROOT_candidate`。

对于 U(1)，定义 `F_{μν}=∂_μA_ν-∂_νA_μ`，对规范势变分得 Maxwell 方程 `∇_μF^{μν}=μ₀J^ν`（SI 的规范归一化）；Bianchi 恒等式是 `∇_[ρ F_{μν]}=0`。对于一般 Yang–Mills 场，

`F^a_{μν}=∂_μA^a_ν-∂_νA^a_μ+g_af^a_{bc}A^b_μA^c_ν`，

相应的变分方程为 `D_μF^{aμν}=j^{aν}`（在将作用量系数吸收到电流和场约定的单位下）。

度规变分能得到规范场与物质的应力能量贡献，规范场的局部作用方程则来自各自的规范势变分。**虽然这些方程都由总作用量产生，但这仍是 GR+SM 的合并表述，而不是引力与 SU(3)×SU(2)×U(1) 由单一对称群和唯一耦合值导出。**

另有真正的“大统一理论”研究，例如 SU(5)、SO(10)，试图合并 SM 规范群；它们本身一般也没有把量子引力纳入同一可检验理论。任何 ROOT 提案都必须面对规范表示、手征性、异常抵消、粒子质量、耦合跑动、核衰变约束及引力实验。

## 7. 可以做什么样的“新物理检验”？

作为**独立附加的表型假设**，可选 Yukawa 势

`V(r)= -GMm/r [1+α_Y exp(-r/λ_Y)]`。

于是径向相对加速度偏差

`Δg/g_N=α_Y(1+r/λ_Y) exp(-r/λ_Y)`。

软件展示的是该表型的参数化与曲线，没有从微观螺旋导出 `α_Y,λ_Y`，也没有声称有实测证据。设计实验时必须与已有第五力、等效原理、行星轨道与引力波限制逐项比较。只有由螺旋基本公设无拟合地导出参数之后，才可能称之为可独立检验的 ROOT 预言。

## 8. 程序结果与审计

运行 `python -m unittest discover -s tests -v`，检查曲线速度恒定、曲率挠率、数值求导、几何正交、Lorentz 间隔、自由电磁平面波、标准牛顿与理想偶极场、热核积分、单标量诱导系数、反向标定、质量截止、反例公式以及第五力表型数学性质。测试证明**软件按已写定的方程计算一致**，不是新物理获得实验证实。

`data/*.csv` 共七类模拟数据，`results/numerical_summary.json` 给出参数和关键结果。可用任何表格工具查看。`web/index.html` 为可交互 WebGL2 绘制与备用 Canvas2D 的教育/研究演示，不是 GR 场方程的实时数值解，也没有接入 IGRF/EGM2008 实测模型。

## 9. 面向“真正完成”的最小证明义务

对一个成功的 ROOT 微观理论，至少需要：

1. 明确微观基本场 `q`、态空间、局域对称性、洛伦兹性质与稳定真空，并给出无需引力先验的作用量 `S_micro[q]`。
2. 证明何种可观测或有效几何变量 `g_{μν}[q]` 涌现，包括自旋-2 模式、正确极化、因果锥及耦合普适性。
3. 在可控微扰或非微扰极限产生 `R√(-g)` 项及**量纲正确、可由独立微观参数确定的系数**，并保证有效理论无 ghost、异常和不可控的调谐。
4. 由相同公设产生规范群、手征费米子和表象、Yukawa/质量机制及一组可独立预测的耦合关系。
5. 导出至少一个以未参与拟合的数据检验的定量可证伪预言，并在已有 GR、SM 和精密实验边界内通过对照。

没有上述证明，即使几何、热核或数值拟合的每一步正确，也不能诚实宣称已攻破引力起源或四力统一。

## 10. 结论

本研究将 ROOT 的直觉图景转化为三类可审查对象：**已证明的螺旋几何、已指定的量子波动玩具模型、已知诱导引力单圈计算机制**。其中诱导 `R` 项是最接近宏观引力方程的一条现有理论路径，同时清楚暴露了紫外尺度、场内容、裸耦合与真空能的障碍。现阶段没有从“空间光速螺旋”推导出已测 G 或唯一的四力统一方程；这不是计算量大小可以直接填补的空白，而是微观理论定义和可证伪预测尚不充分。
