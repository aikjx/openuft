## E1 观测事实

- 原初氦质量分数观测基准：Y_p^obs = 0.245 ± 0.003（Planck 2018 相容；引用，不复算）。
- 其余轻元素（D/H、He-3/H、Li-7/H）由标准 BBN 核反应网络输出，本件不复算核反应链；D/H ≈ 2.5×10⁻⁵、Li-7 疑点等均属标准宇宙学结果（PDG BBN 综述 / Kolb-Turner，引用不复算）。
- BBN 物理流程（标准叙述）：T ≫ 1 MeV 时弱相互作用 n ↔ p 维持热平衡；温度降至冻结温度 T_f ≈ 0.8 MeV 时弱作用速率落后于宇宙膨胀，n/p 比冻结；其后中子在 t_BBN ≈ 180 s 内按 τ_n = 879.4 s 衰变，剩余中子进入氦核。

## E2 核心公式第一性推导 + 精算

弱作用热平衡分布为 Boltzmann 比值，冻结时（标准推导，本件不复算弱作用速率平衡方程）：

```
(n/p)_f = exp(−Q/T_f)，  Q = m_n − m_p = 1.293332 MeV（PDG，引用不复算）
x       = (n/p)_f · exp(−t_BBN/τ_n)
Y_p     = 2x / (1 + x)          （每个氦核含 2 质子 2 中子，质量分数闭式）
t_BBN = 180 s（核合成时标，引用）；τ_n = 879.4 s（PDG，引用不复算）
```

中子衰变抑制因子：

```
s = exp(−t_BBN/τ_n) = exp(−180/879.4) = 0.8149039605437686993812
```

### 诚实边界（本件必读）

- 本件 Y_p 为**解析 2 参数教学闭式**（仅 T_f、t_BBN 两个可调量），不含弱作用速率精确求解、不含完整核反应网络、不含 D/He-3/Li-7 分支；Y_p 绝对读数与数值 BBN 标准结果 Y_p ≈ 0.247 存在约 5–15% 的差异属正常模型简化范围。
- 本攻破的要点不是「闭式复现数值 BBN 精度」，而是：**轻元素丰度是标准宇宙学（弱相互作用速率 + 核反应网络）的输出，TUFT 供给 0**；不得宣称本闭式在数值精度上对标数值 BBN 计算。

## E3 解析求导验证（用户指定「求导证明」线）

链式法则（基准点 T_f = 0.8 MeV；Y = 2x/(1+x) ⇒ ∂Y/∂x = 2/(1+x)²；x = r·s，r = exp(−Q/T_f)，s = exp(−t_BBN/τ_n)）：

```
① dY_p/dT_f  = (2/(1+x)²) · x · Q/T_f²  > 0
   物理：T_f 升高 → 冻结时中子留存更多 → 氦更多。
   闭式 = 0.4844954314690213
   中心差分（δ = 1e-50，250 位）互验差 = 3.34×10⁻¹⁰² < 1e-100 ✓

② dY_p/dτ_n  = (2/(1+x)²) · x · t_BBN/τ_n²  > 0
   物理：中子寿命变长 → t_BBN 内衰变更少 → 留存中子更多 → 氦增加。
   闭式 = 5.580321485550914×10⁻⁵
   中心差分互验差 = 6.16×10⁻¹¹¹ < 1e-100 ✓

③ dY_p/dQ    = −(2/(1+x)²) · x / T_f  < 0
   物理：Q 增大 → Boltzmann 比值 (n/p) = exp(−Q/T_f) 下降 → Y_p 下降。
   闭式 = −0.2996882047109459
   中心差分互验差 = 2.19×10⁻¹⁰² < 1e-100 ✓
```

- 符号结论三条与物理直觉完全一致；导数本身是标准闭式代数性质，TUFT 内部不提供任何系数、指数或符号来源。
