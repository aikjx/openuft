# ROOT V138 准入门槛与任务

| 优先级 | 检验问题 | 必须交付的证据 | 失败判据 |
|---|---|---|---|
| P0 | 单一高维作用量能否产生全部低能物质谱？ | 同一背景下各束 Dirac 零模及 SU(3)×SU(2)×U(1) 表示 | 只能逐个手工选 q,m/Y |
| P0 | 规范群全局提升是否存在？ | Spinᶜ 丛上的中心作用、跃迁函数与规范群商 | SU(3) 三重态或 SU(2) 双重态无法全局定义 |
| P0 | 十维异常是否抵消？ | 完整 I12 与下降公式；必要的 GS/inflow | 未抵消的局部或全局异常 |
| P0 | 低能手征与弱相互作用是否正确？ | 所有左右 Weyl 模式和镜像质量机制 | 矢量化或遗留未观测轻镜像粒子 |
| P1 | KK 模与尺度稳定性？ | 二次涨落谱/边界条件与质量平方 | 任意不稳定传播模式未经可接受机制处理 |
| P1 | G_4, 超荷、耦合、质量？ | 无使用实验数值反求的独立预测 | 将未知量改名后继续标定 |
| P1 | 螺旋原理是否产生新可观测量？ | 与 GR/QED/SM 不同且唯一的实验预言 | 仅复制旧理论而无独特可测效应 |

**禁止混淆**：几何指标=3、SU(3) 颜色三重态、SU(2) 自旋 1 三重态、三代费米子是四个不同概念。
