### 1.2 空间光速螺旋 v≡c（核心突破）

**参数方程**：
$$\mathbf{r}(t) = (R\cos\omega t,\ R\sin\omega t,\ bt)$$

**光速约束**：
$$v^2 = R^2\omega^2 + b^2 \equiv c^2$$

**参数化**：
$$b = \pm\sqrt{c^2 - R^2\omega^2},\quad \text{约束 } R\omega \leq c$$

**退化情形**：
- b=0：纯圆周运动（v⊥=c）
- R=0：纯直线运动（v∥=c）

### 1.3 三重奏定理（TS1，严格证明）

**定理**：对任意满足光速约束v≡c的螺旋运动，曲率κ、挠率τ与角频率ω满足：
$$\boxed{\kappa^2 + \tau^2 = \left(\frac{\omega}{c}\right)^2}$$

**证明**（sympy符号证明，差精确为0）：
- 曲率：κ = Rω²/c²
- 挠率：τ = bω/c²
- κ² + τ² = (R²ω⁴ + b²ω²)/c⁴ = ω²(R²ω² + b²)/c⁴ = ω²c²/c⁴ = (ω/c)²

**验证**：
- sympy符号证明：差精确为0 ✅
- 250位高精度数值验证：相对差~1e-251 ✅
- 电子光速螺旋：相对差~1e-251 ✅
