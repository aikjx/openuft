# 第二章 超流与超导的拓扑解释
超流和超导是宏观量子现象，超流是液体在低温下无粘滞流动，超导是材料在低温下电阻为零，完全抗磁，传统理论用玻色爱因斯坦凝聚和BCS理论解释，但是它们的很多性质本质上是拓扑的。

## 2.1 超流的拓扑本质
超流是玻色子（比如氦4原子）在低温下玻色爱因斯坦凝聚，形成宏观的量子相干态，所有原子都在同一个量子态，用一个宏观波函数描述：ψ = |ψ| e^{iθ}，相位θ是宏观相位，超流的速度v_s = (ℏ/m)∇θ，因为相位是单值的，绕闭合回路积分∮v_s·dl = (ℏ/m)∮∇θ·dl = 2πnℏ/m = n h/m，n是整数，这就是超流的环流量子化，是拓扑不变量，因为绕数n是整数，不能连续改变。

超流中的涡旋是拓扑缺陷，涡旋中心是正常流体，周围是超流，绕涡旋一周相位变化2π，涡旋的环流量是h/m，是量子化的，涡旋是拓扑稳定的，不能连续消失，因为绕数是拓扑不变量，就像我们之前说的粒子是拓扑螺旋，涡旋也是拓扑螺旋，是二维或三维流体中的拓扑缺陷。

超流的无粘滞流动是因为宏观相干态，散射需要改变整个宏观态的相位，需要很高的能量，所以没有散射，没有粘滞，就像超导没有电阻一样。超流的喷泉效应、第二声、第三声等现象，都是宏观量子相干态的表现，本质上是拓扑相位的集体运动。

氦3超流是p波超流，配对的是费米子（氦3原子），形成p波配对，有更复杂的拓扑结构，是拓扑超流，有马约拉纳零能模在涡旋中心，和我们之前说的拓扑超导体一样，氦3超流是天然的拓扑超流，已经被实验观测到。

## 2.2 超导的拓扑本质
超导是电子在低温下形成库珀对，库珀对是玻色子，玻色爱因斯坦凝聚形成宏观量子相干态，宏观波函数ψ = |ψ| e^{iθ}，超导电流j_s = (n_s e*/m*) (ℏ∇θ - e* A/c)，其中e*=2e是库珀对电荷，A是矢量势，绕闭合回路积分∮j_s·dl = 0（超导体内电流为零），所以∮∇θ·dl = (e*/ℏ c)∮A·dl = 2πn，也就是磁通量子化Φ = ∮A·dl = n hc/(2e) = n Φ_0，Φ_0是磁通量子，约为2.07e-15 Wb，这是拓扑不变量，绕数n是整数，磁通是量子化的。

超导体的迈斯纳效应是完全抗磁，磁场不能进入超导体，因为磁场会破坏宏观相干态，超导体表面的超导电流屏蔽磁场，这是宏观量子态的集体效应。第二类超导体有混合态，磁场以量子化磁通涡旋的形式进入超导体，每个涡旋带一个磁通量子Φ_0，涡旋是拓扑缺陷，和超流涡旋类似，绕涡旋一周相位变化2π，涡旋中心是正常态，周围是超导态，涡旋是拓扑稳定的。

高温超导体是d波超导体，配对对称性是d波，有更复杂的拓扑结构，可能是拓扑超导体，表面有马约拉纳零能模，现在还在研究中。超导的约瑟夫森效应是两个超导体之间的隧道效应，电流是相位差的函数，I = I_c sin(Δθ)，这也是宏观相位的拓扑效应，约瑟夫森结可以用来做超导量子干涉仪（SQUID），测量极微弱的磁场，是拓扑相位的应用。

## 2.3 拓扑相变
超流和超导的相变是热力学相变，但是也有拓扑相变，比如KT相变（Kosterlitz-Thouless相变），二维超流/超导在低温下涡旋是束缚的，正反涡旋成对，高温下涡旋对拆开，自由涡旋运动破坏超流/超导，这是拓扑相变，没有对称破缺，是涡旋的拓扑束缚-解束缚相变，是拓扑缺陷的相变，和我们之前说的时空拓扑相变是同一个道理，都是拓扑缺陷的集体行为。

KT相变是二维系统特有的相变，没有潜热，是连续相变，但是和朗道相变不同，没有对称破缺，是拓扑序的相变，本质上是拓扑螺旋的成对和自由的转变，和我们之前说的粒子成对产生是同一个拓扑过程。

## 2.4 本章小结
超流和超导都是宏观量子相干态，本质上是拓扑相位的集体运动，环流量子化、磁通量子化、涡旋、约瑟夫森效应都是拓扑现象，是拓扑螺旋在宏观凝聚态系统的表现，和微观粒子的拓扑本质一致，拓扑相变是拓扑缺陷的集体行为，没有对称破缺，是拓扑序的转变。
