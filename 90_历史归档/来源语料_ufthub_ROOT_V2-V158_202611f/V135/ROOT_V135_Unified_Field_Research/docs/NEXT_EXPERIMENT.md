# V136 优先任务：从“预测”走向“独立测量”

必须先解决 V135 在地表给出约 0.058 m/s² 额外加速度的明显一致性压力。建议顺序：

1. 获取 PREM 原始密度表，独立数值积分，核对质量/惯量，不使用 JPL 质量重新拟合微观动力学。
2. 获取 ICGEM EGM2008 的球谐系数以及可追溯的地面重力/卫星测量，构造含协方差、旋转参考系与地形潮汐的预测模型。
3. 获取 GRAIL 月球场模型和轨道跟踪观测；同步使用共同的 \(\alpha,\lambda\)，不能对地月各自调参。
4. 令 \(\lambda\) 也未知，扫描参数剖面似然 \(\chi^2(\alpha,\lambda)\)，并在固定虚警率下检验灵敏度，留出测试高度/时间区间。
5. 若真实残差与候选模型显著不相容，报告排除界而不是“修复”为可任意解释一切的模型。
6. 若理论要从螺旋出发独立推出规范群，必须先定义基本场 \(X\)、作用量 \(S[X]\)、局域对称性与 Noether 流，再通过量子化得到谱和散射计算；不能只用三正交基底替代该推导。

最低验收标准：外部模型许可证及版本固定、哈希、数据清洗、回归测试、残差分布、协方差、参数可辨识矩阵、留出验证和复现实验脚本。未达到之前保持“待验证”状态。
