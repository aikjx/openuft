# 冲突记录：螺旋半径普适性矛盾（普朗克锚定谬误）

> 体系：GAQ 复曲率融合体系（S07） · 假设版本 v4（继承登记）
> 出处：算法联盟全维自洽引擎 M01 / M02 组（2026-09-15，mpmath 80 位 + sympy 符号求导）
> 状态：**内部冲突（internal_conflict）**——非实验证伪，是公设与派生式之间的**第一性不自洽**；由联立推导坐实，不可通过补充假设回避，只能二选一修正。

## 一、冲突现场

本体系 v4 的两条登记内容：

- **S07-A3（复曲率完备公理）**：`|Ξ|² = κ² + τ² = 1/R²`
- **派生式**：`G = c³/(ℏ(κ² + τ²))`，`m = ℏ/(cR)`

把 A3 代入 G 的派生式：

```
G = c³/(ℏ · 1/R²) = c³R²/ℏ
```

由于 **G 是普适常数**，该式强制 `R = √(ℏG/c³) = ℓ_P`（唯一解），
进而由 `m = ℏ/(cR)` 得 `m = ℏ/(cℓ_P) = m_P`（唯一解）。

**即：本体系的公设组预言「所有粒子质量都等于普朗克质量」。**

## 二、与实测的对照

| 量 | 本体系联立预言 | 实测值 | 偏差 |
|---|---|---|---|
| 电子质量 | `m_P = 2.176e-8 kg` | `9.109e-31 kg` | 2.39e+22 倍 |
| 质子质量 | `m_P = 2.176e-8 kg` | `1.673e-27 kg` | 1.30e+19 倍 |
| `m_p/m_e` | **1** | **1836.15** | **1835.15 倍** |

引擎记录 `M01-n`：`m_p/m_e − 1 = 1835.15`，判定 **FAIL**。

## 三、根因诊断：普朗克锚定谬误

问题的实质是——

> **`G = c³/(ℏ(κ²+τ²))` 与 `m = ℏ√(κ²+τ²)/c` 是「普朗克尺度恒等式」的变形，
> 被误用为「任意粒子的关系式」。**

在 `m = m_P` 时 `α_grav = Gm²/(ℏc) = 1` 恒成立，这本是普朗克单位制的**定义性事实**；
把它写成含 `(κ,τ)` 的形式后，看起来像是对任意粒子都成立的物理定律，实则只在普朗克锚点成立。

**代数精确形式**（引擎 `H02b`）：把 `κ²+τ² = (m c/ℏ)²` 代入 G 式得

```
G = c³/(ℏ · (mc/ℏ)²) = ℏc/m²    ⟹    G m² = ℏ c    ⟹    m = m_P 唯一
```

**正确形式**应为：

```
α_grav = G m²/(ℏ c) = (m/m_P)²
```

它对任意 m 成立，且**不含任何矛盾**。数值佐证（引擎 `M02-n`，PASS，残差 1.69e-81）：
电子 `α_grav = G m_e²/(ℏc) = 1.75e-45 = (m_e/m_P)²`，**而非 1**。

## 四、不可兼得的二选一

体系若要保留质量谱（这是任何粒子物理理论的最低要求），必须**放弃其一**：

| 选项 | 放弃内容 | 后果 |
|---|---|---|
| **甲** | 放弃「A3 中的 R 是普朗克尺度」 | 则 `κ²+τ² = 1/R²` 的 R 只能是粒子自身的几何尺度（≈ 约化康普顿波长 `ƛ_C = ℏ/(mc)`），G 不能再由同一组 (κ,τ) 给出 |
| **乙** | 放弃「G 由同一组 (κ,τ) 给出」 | 则 G 必须重新引入为独立输入或另寻几何来源，本体系的「常数全几何化」主张收缩 |

**二者不可兼得**：只要同时保留，就必然推出 `m = m_P`。

## 六、为什么此前未被发现

1. **循环项被重复计数**：`ħ = mcR` 与 `m = ℏ/(cR)` 是同一约束的两种写法，
   e 的导出式代入后化为恒等式 `e² = e²`（引擎 `H03`）。这些项在「精算清单」中各自计为一次通过。
2. **测量噪声伪装成独立约束**：`ε₀` 与 `e²/(4παℏc)` 的 CODATA 残差约 `3e-12`，
   使理论上线性相关的约束在 80 位精度下被判为**独立**（引擎 `H01c`）。
3. **只在普朗克锚点做数值检验**：若取 `m = m_P` 检验，所有式子都精确成立（残差 `1.84e-81`），
   于是「通过」；一旦换到电子尺度立刻失败 `5.7e+44` 倍（引擎 `D06` / `D07` 对照）。

> 教训：**「多项精算 100% 通过」不能证明约束独立，也不能证明在任意尺度成立。**

## 七、修正建议

1. 把 `G = c³/(ℏ(κ²+τ²))` 降级为**普朗克锚点定义式**，明确标注「仅在 `m = m_P` 时成立」；
2. 粒子尺度的引力耦合一律改用 `α_grav = Gm²/(ℏc) = (m/m_P)²`；
3. `m = ℏ/(cR)` 中的 R 明确为粒子的**约化康普顿波长** `ƛ_C = ℏ/(mc)`，
   不再与普朗克长度 `ℓ_P` 混用（二者对电子相差 `2.39e+22` 倍）；
4. 重算全部依赖 G 式的派生链，剔除其中因恒等变形而「通过」的循环项。

**诚实声明**：本记录是**理论内部自洽性审计**的结果，不是实验证伪；
它说明现有公设组在数学上无法同时成立，不构成对复曲率本体（S07-A1/A2）的直接否定，
但确证「由 (κ,τ) 导出 G 并与粒子质量谱共存」这一具体主张**已失败**。
修正后的派生链仍需重新接受独立复现与观测检验。
