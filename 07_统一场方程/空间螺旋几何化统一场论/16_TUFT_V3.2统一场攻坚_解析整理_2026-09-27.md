## 3. 代码审查（mpmath 路线2，2026-09-27）

来稿路线2 的 mpmath 打靶代码存在**四项需先修正**的问题，否则数值结果不可信、且与 V3 审计的修复方向冲突：

1. **ODEs 缺 ω 项（最关键）**：`d2psi = -(2/r)*dpsi + V1*psi**3 - V2*psi**5` 对应的是**静态（ω=0）**径向方程
   −∇²ψ = V₁ψ³ − V₂ψ⁵。但 V3 审计已解析证明「三维有限能量静态纯三次孤子不存在」，正确的修复候选是
   **时间谐振 Q-ball**：ψ = σ(r)e^{−iω₀t} ⇒ 径向方程应含 ω₀²/c² 项（∇²σ = (ω₀²/c²)σ − V₁σ³ + V₂σ⁵）。
   当前代码求解的是已被判定不存在的静态解分支，方向错误。
2. **注释与代码符号相反**：注释 `# -psi'' - (2/r) psi' = V1*psi^3 - V2*psi^5` 推得
   ψ'' = −(2/r)ψ' − V₁ψ³ + V₂ψ⁵；代码行 `d2psi = -(2/r)*dpsi + V1*psi**3 - V2*psi**5` 推得
   ψ'' = −(2/r)ψ' + V₁ψ³ − V₂ψ⁵。二者非线性项差一符号，必有一处与场方程(1)不符，需统一。
3. **E₀ 缺相位动能项**：时间谐振 Q-ball 的能量密度含 (1/2)|∂ψ/∂t|² = ½ω₀²σ² 与势能项，代码只算了
   (1/2)(∇ψ)² + V₁/4ψ⁴ − V₂/6ψ⁶，**漏掉 ω₀²σ²/2**，E₀（进而 M=E₀/c²）会被低估。
4. **`mp.odefun` 非 mpmath 标准接口**：mpmath 无 `odefun`（需自写定步长/自适应积分器，或用数值库）；
   当前脚本引用不存在函数，直接运行会报错，无法产出 `sol_sol`。

> **修正建议**（供路线2 执行时落地，本稿不改动代码本体）：改用带 ω₀ 的时间谐振径向方程做打靶（ω₀ 由
> E/Q<1 稳定性条件 + 电荷守恒共同扫描），E₀ 补入 ½ω₀²σ²，积分器用自写 RK/自适应步长实现于 mpmath 高精度。
