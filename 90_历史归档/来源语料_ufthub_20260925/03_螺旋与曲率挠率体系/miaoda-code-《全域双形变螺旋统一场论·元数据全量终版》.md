# 第三卷 物理现象层：所有可观测现象的几何解释
本卷覆盖所有七大类物理现象，每一个现象都是螺旋运动、形变、相互作用的必然结果。
## 第10章 经典力学现象的几何解释
所有经典力学现象都是宏观螺旋的运动与相互作用：
1. **平动/转动**：螺旋整体沿轴向平动、绕中心转动；
2. **简谐振动/共振**：螺旋形变在平衡位置附近的周期振荡，外场频率与螺旋固有频率匹配时振幅最大；
3. **碰撞**：两个螺旋拓扑碰撞，交换动量和能量，弹性碰撞是螺旋形变完全恢复，非弹性碰撞是螺旋形变部分耗散为热涨落；
4. **机械波/声波**：介质中螺旋形变的轴向/切向传播，纵波是疏密形变，横波是剪切形变；
5. **多普勒效应**：波源运动导致螺旋波的频率压缩/拉伸；
6. **流体现象**：
   - 层流/湍流：流体螺旋规则流动为层流，螺旋破碎为小尺度涡旋为湍流；
   - 伯努利效应：流速快的地方螺旋轴向速度大，径向压力小；
   - 毛细现象：表面螺旋的张力导致液体沿管壁上升；
   - 涡街：流体绕过障碍物时螺旋周期性脱落形成涡旋；
   - 激波：流体螺旋运动速度超过波速时形成的突变面；
7. **引力宏观现象**：天体周围曲率螺旋导致的轨道运动、潮汐、自由落体，和广义相对论完全一致。
## 第11章 热学与统计现象的几何解释
1. **热传递**：
   - 热传导：螺旋涨落通过相邻螺旋碰撞传递；
   - 热对流：携带高动能螺旋的流体宏观运动；
   - 热辐射：螺旋形变以电磁波形式向外辐射；
2. **相变**：温度变化导致介质螺旋有序/无序转变，如熔化是晶体螺旋有序排列被热涨落破坏，超导是电子螺旋配对形成相干螺旋拓扑；
