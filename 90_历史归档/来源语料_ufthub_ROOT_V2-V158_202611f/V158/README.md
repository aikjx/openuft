# ROOT V158 — 零间隔相位、局域束缚与洛伦兹协变性

## 1. 范围
延续 V157 的经典复标量 Q-ball 候选模型。只设 c=1；保留 ħ、G。采用 (-+++) 度规。计算以 L0 为长度单位、ħ/L0 为能量单位、L0^-1 为场幅单位，Q 无量纲。此处未引入重力反作用，未进行卫星原始数据或物理实验拟合。模型势能为输入，不是从空间螺旋独立推导的结果。

## 2. 求导与证明
S=-ħ∫[∂f·∂f/2+f²∂θ·∂θ/2+U(f)]d⁴x，U=f²/(2L0²)-f⁴/2+L0²f⁶/4。振幅方程 □f-f k²-U'=0，相位方程 ∂μ(f²k^μ)=0，其中 kμ=∂μθ。若 k²=0，振幅静态且局域，积分分部得 ∫(|∇f|²+fU')=0。又 fU'=f²[3L0²(f²-2/(3L0²))²/2+1/(3L0²)]，故只能 f=0。该证明也适用于光滑静态振幅的空间非球对称构型，要求积分存在且边界项消失；不适用于任意动态振幅、外部边界、曲率时空或修改动能的模型。
更一般地，若 U≥0，严格零间隔相位使静态振幅满足 Δf=U'。对该振幅方程的静态能量 K+V 进行尺度变分 f_s(x)=f(x/s)，得到 K+3V=0，因此非平凡光滑有限能解同样不可能。这个 Derrick 型论证要求尺度变分合法；不把它解释为全部光速理论的否定。多标量正定标准动能且每个相位均为零间隔、共同非负势时，同样对所有振幅同时尺度变分即可。若相位 θ=ωt+nφ+kz，零间隔要求 -ω²+n²/ρ²+k²=0；n≠0 时仅可能在固定柱面（若 ω²>k²），非零光滑有限厚度振幅不能仅支撑在该柱面。绕轴奇点需排除或振幅消失。

## 3. 协变性
休止系 θ=ωt，Boost 后 θ=γω(t-βz)，k²=-ω²。变换后的场包络也必须变换：f(sqrt(x²+y²+γ²(z-βt)²))。只改变相位而保留包络，不是洛伦兹变换后的解。积分实际变换后的应力能量和 Noether 荷，得到 E'=γE、Pz'=γβE、Q'=Q；相对误差见 boost.csv。标准波动算子的特征传播为光速，与相位梯度类时并不矛盾。上述结果不等于独立推出质量的单位、G、α 或四力。

## 4. 计算设计
- 从 V157 的 probe.py 延续 w=.83 至 .8 的非零边值解，R=50；尾端用线性衰减 Robin 条件，近似无穷远。
- 零间隔振幅方程等效 w=0 的边值问题，使用三种初始猜测半径 2,5,8。数值收敛不代替上述解析证明。
- 7 组轴向 Boost，径向 Simpson 积分、16 点 Gauss-Legendre 角积分，实际对场导数与变换后的空间体积积分。
- 3D 非线性 Klein-Gordon：周期立方体边长 40，N=48,64,96，二阶中心差分与 velocity-Verlet，t=0..6。初始 f 为 w=.8 静态振幅；对照组 θ=ωt，实验组初始 θ=ω(t-z)，初始幅度时间导数为零。后续自由演化，不施加零间隔约束；两组初始能量与动量不同，不是相同能量的对照，也不是精确 Boost。计算的相位不变量为 ∫(Σ(Im(Ψ*∂iΨ))²−(Im(Ψ*∂tΨ))²)/∫|Ψ|⁴，即幅度四次方加权平均，不能推断每一点的符号。初始理论值 0 的数值偏差来自空间差分及有限边界；随网格加密减小。有限时间不能证明永久稳定、解体或完整扰动谱。周期边界而非开放边界。数值最大速度及质量只针对给定模型。

## 5. 运行
Python 3，安装 requirements.txt 后运行 python run_all.py。输出 results/*.csv、summary.json、evolution.png；运行末尾 10 项 unittest。Linux 实测，Windows 脚本提供未实机测试。SHA256SUMS.txt 校验交付时文件快照；重跑生成文件可能因软件版本不同而改变。
