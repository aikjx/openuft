## 研究结论与边界
仅 c=1，保留 [hbar]=ML、[G]=L/M。数值采用明确参考尺度归一化，不将 hbar 或 G 设为 1。没有真实实验、卫星原始数据或量子四力统一证明。三条路线是已知模型的独立数学/数值复核；不是 ROOT 的独立微观推导。

### A. Maxwell Hopfion：拓扑闭环不等于稳定粒子
定义无量纲坐标 x/L0,t/L0；令 a=x-iy, b=t-i-z, d=r²-(t-i)²。复场 F=E+iB=4(d^-3)(b²-a²,-i(a²+b²),2ab)。物理场可取 F_phys=L0^-2 F；在规范场能量归一化 hbar/g² 下物理总能量为 hbar/(g² L0) 乘无量纲能量。
符号检查 F·F=0, div F=0, ∂t F+i curl F=0（复数多项式分子精确展开）。故 E·B=0, E²=B²，非零场处 |E×B|/rho=1。已知 Hopfion 的链接场线结构来自文献；本程序没有直接追踪所有场线，不把场线视为光子路径。
积分使用球坐标及轴对称能量密度，径向 r=tan(pi*(q+1)/4)，两个方向 Gauss-Legendre 256/512 节点，实际对每个时刻执行两次积分。4096 随机点检查零场不变量、局部通量速度与轴对称性。E=2pi², Pz/E=-1/2；初始能量密度 16/(1+r²)^4，故 I(0)/E=1, I'(0)=0（由对称性或初始矩积分）。平直时空中 ∂mu T^munu=0 且 T^mu_mu=0，在边界项消失时 I''=2E，质心 X'=P/E。于是中心均方半径 1+(1-|P/E|²)t²=1+3t²/4。计算与此一致。即使拓扑链接在演化中保留，能量仍扩散。M/E=sqrt(3)/2；非零不变质量不等于局域稳定。

### B. Skyrme：拓扑 + 两种尺度项形成尺度平衡
内部 SU(2) 方向场 U=cos F+i sigma·rhat sin F，边界 F(0)=pi, F(inf)=0。拓扑荷 B=-2/pi int F' sin²F dr=1。归一化 E2=4pi int(r² F'²+2sin²F)dr，E4=4pi int(2sin²F F'²+sin⁴F/r²)dr。能量 E=E2+E4。
Euler-Lagrange: (r²+2sin²F)F''+2rF'+sin(2F)(F'²-1-sin²F/r²)=0。
Derrick 伸缩 E(s)=s E2+E4/s（结构大小乘 s），E'(1)=E2-E4, E''(1)=2E4>0。若 E4=0，收缩可降低能量，即拓扑本身不阻止尺度塌缩。能量下界：设局部三个非负应变主值 l1,l2,l3，能量密度 sum_i li²+sum_{i<j}li²lj² >=6 l1 l2 l3，由三次平方不等式。积分得 E>=12pi²|B|。该归一化下数值 B=1 的能量 E/(12pi²)≈1.2314457。
求解使用 solve_bvp，原点截断 eps=0.001、正则近似 F(eps)=pi+eps F'(eps)，远端 Robin 边界 RF'(R)+2F(R)=0（无质量尾部 F≈C/r²）。对 R=20,40,80 分别求解，能量积分使用 24000 个对数网格点，并补偿 E2 的领先阶尾部 8pi R F(R)^2。近原点遗漏能量 O(eps³)，没有声称所报小数全部具有物理精度。初次 eps=1e-4、tol=1e-8 的 R=80 求解未收敛；改用上述截断及 3e-8 容差后复跑通过。能量尺度扫描独立重积分。仅尺度方向稳定，未做完整三维动态谱或量子稳定性，不是严格零间隔物质模型。

### C. 同一几何不能唯一确定质量、半径及耦合
恢复独立有量纲系数 a>0 ([a]=L^-2), b>0 ([b]=1)。对于相同无量纲 SU(2) 构型，物理能量 E_phys(L)=hbar[a L E2 + b E4/L]，由尺度极小值 L*=sqrt(b E4/(a E2))，若已归一化平衡 E2=E4，则 L*=sqrt(b/a)。整个模型换元后 M=hbar sqrt(ab) (E2+E4)（在 c=1 的静止系）。同样拓扑、同样归一化形状可以具有不同的物理质量及尺寸。数值扫描 5 组系数。因而四个基本原理不足以固定这些系数；不能由几何拓扑本身推导 G 或 alpha。
弱场 GR 中完整孤立静态场的空间应力迹积分为零，领先阶主动引力质量等于总能量；本轮没有耦合求解 Einstein 方程，G 仍是输入。文献已有有限厚度的静态 Einstein-Vlasov 光子壳，但本轮没有计算它们的稳定谱，不把 V159 薄壳结论推广给所有光子壳。
