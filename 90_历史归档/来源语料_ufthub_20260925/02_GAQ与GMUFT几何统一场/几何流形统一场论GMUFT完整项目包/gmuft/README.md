## 项目简介

几何流形统一场论（GMUFT）是一套基于仿射-度量几何的统一场论框架。其核心思想是：时空流形具有最一般的几何结构，包含四个独立的几何自由度——度规曲率、挠率、非度规性、射影联络，分别对应四种基本相互作用（引力、电磁力、强力、弱力）。

GMUFT不是自定义公理体系，而是在标准物理框架内的几何重构与唯象拓展：
- **基础部分**：纯数学规范化变换，不改变现有物理规律
- **拓展部分**：高能标统一耦合假设与宇宙流体唯象修正，具备可证伪性
- **严格区分**：已实验证实结论 / 数学等价重构 / 理论猜想三层标注

## 核心理论

### 四大公理

1. **流形实在性**：物理时空是一个D维（D=4+n）可微分流形M，具有度规张量g_μν和最一般的仿射联络Γ^λ_μν
2. **几何即物理**：流形的所有几何性质（度规、挠率、非度规性、射影结构）都是物理实在，对应可观测的物理场
3. **四几何自由度对应四力**：度规曲率→引力，挠率→电磁力，非度规性→强力，射影联络→弱力
4. **最小几何作用量**：物理规律由流形的几何作用量极值原理决定

### 联络分解定理

$$\Gamma^\lambda_{\mu\nu} = \left\{\begin{matrix}\lambda\\ \mu\nu\end{matrix}\right\} + K^\lambda_{\mu\nu} + L^\lambda_{\mu\nu}$$

- 列维-奇维塔联络{ }（度规曲率）→ 引力
- 扭率张量K（挠率）→ 电磁力
- 非度规性联络L（非度规性）→ 强力
- 射影联络等价类Π → 弱力

### 第一层：已实验证实（✓）
- 广义相对论的所有检验
- 量子电动力学（QED）
- 量子色动力学（QCD）
- 电弱标准模型
- ΛCDM宇宙学标准模型

- 射影联络=弱力的几何对应（等价于标准模型）
- 联络分解定理（纯数学定理）

## 适用范围

### 已证实范围
- 引力：全部能量/距离范围（等价于GR）
- 电磁力：全部范围（等价于QED）
- 强力：<1 TeV（等价于QCD）
- 弱力：<1 TeV（等价于标准模型）
- 宇宙学：<10¹⁶ GeV（等价于ΛCDM）

### 不适用范围
- 量子引力能标（>10¹⁹ GeV）：需要完整量子化
- 时空奇点内部：经典几何失效
- 超弦/M理论尺度：额外维度效应

## 理论局限与开放问题

### 理论局限
1. 唯象参数未消除（粒子质量、耦合常数仍需实验输入）
2. 量子引力未完成（经典几何框架，引力不可重整性仍存在）
3. 紧致化机制不明（如需高维，额外维度如何紧致化）
4. 拓扑缺陷精确解未知（费米子质量/自旋的精确计算）
5. 非度规性物理约束不充分（40个分量如何约束到8个胶子）

### 物理开放问题
1. 暗物质本质（几何暗物质 vs WIMP）
2. 暗能量本质（宇宙学常数的几何本源）
3. 等级问题（电弱能标 vs 普朗克能标）
4. 中微子质量（狄拉克 vs 马约拉纳）
5. 正反物质不对称
6. 精细结构常数精确值（1/137能否从几何推导）
