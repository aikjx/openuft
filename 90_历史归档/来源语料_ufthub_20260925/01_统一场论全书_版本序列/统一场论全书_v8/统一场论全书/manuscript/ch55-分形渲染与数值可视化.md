# 第五十五章 分形渲染与数值可视化

## 一、本章定位

第四十六章给出了分形全域迭代算子 $\mathcal{I}_b$ 的符号形式。第五十四章建立了波动方程的有限差分数值格式。本章把两条线汇合，把迭代算子 $\mathcal{I}_b$ 从符号公式变成可计算、可描述的数值对象。本章不嵌入图像，只用文字描述渲染结果的几何特征与统计特征，使读者仅凭文字即可复现数值实验。

本章前两节是【已证实】与【推导】，回顾 Julia 集与 Mandelbrot 集的迭代定义、Hausdorff 维数的盒维数估计法。第三节至第五节是【TUFT假说】，把第四十六章的 $\mathcal{I}_b$ 与分形投影核 (46.7) 写成数值迭代程序，并把渲染参数与第八章分形宇宙假说 H8.1、H8.3 对接。第六节做数值自洽核验。

必须先声明：Julia 集与 Mandelbrot 集的几何性质是复动力系统教科书的标准内容，本章只引用标准结论。本章原创部分限于把标准分形迭代嵌入 TUFT 投影算子的数值框架，已逐条标注【TUFT假说】并附预言编号。

## 二、复平面迭代与逃逸时间

### （一）Mandelbrot 集的迭代定义

【已证实】Mandelbrot 集定义为复映射

$$z_{n+1}=z_n^2+c,\qquad z_0=0 \tag{55.1}$$

中使迭代序列不发散的参数 $c\in\mathbb{C}$ 的集合。对固定 $c$，若存在 $N$ 使 $|z_N|>2$，则序列必发散；否则 $c$ 属于 Mandelbrot 集 $M$。临界值 $|z|=2$ 是逃逸判据：一旦 $|z_n|>2$，后续模长按几何级数增长。

【已证实】对 $|z|=R>2$，若 $|z_n|>R$ 且 $R>2$，则 $|z_{n+1}|\ge |z_n|^2-|c|$。当 $|c|<R^2-R$ 时模长单调发散。这就是逃逸判据 (55.1) 的理论依据。

【推导】渲染时，对复平面上每个像素 $(x,y)$ 对应参数 $c=x+iy$，迭代 (55.1) 直到 $|z_n|>2$ 或达到最大迭代次数 $N_{\max}$。记录逃逸步数 $n_{\mathrm{esc}}$，按 $n_{\mathrm{esc}}$ 给像素上色。未逃逸像素染黑色。这就是"逃逸时间算法"。

### （二）Julia 集的迭代定义

【已证实】对固定参数 $c$，Julia 集 $J_c$ 定义为初值 $z_0\in\mathbb{C}$ 在映射 (55.1) 下不发散的点集的边界。与 Mandelbrot 集的区别是：Mandelbrot 集在参数平面上扫描 $c$、初值固定为零；Julia 集在动力平面上扫描初值 $z_0$、参数 $c$ 固定。

【已证实】$c\in M$ 时 $J_c$ 连通；$c\notin M$ 时 $J_c$ 是 Cantor 粉尘。这一判别标准由 Mandelbrot 在 1980 年代提出，后经 Douady 与 Hubbard 严格证明。典型例子：$c=-1$（Douady 兔子）给出连通 Julia 集；$c=0.3+0.5i$ 给出 Cantor 粉尘。

### （三）渲染参数与图像描述

【推导】逃逸时间算法的三个关键渲染参数是最大迭代次数 $N_{\max}$、逃逸半径 $R=2$ 与复平面显示窗口 $[x_{\min},x_{\max}]\times[y_{\min},y_{\max}]$。$N_{\max}$ 决定细节精度：$N_{\max}$ 越大，边界附近的细丝越清晰，但计算量线性增长。

【推导】以 $c=-0.8+0.156i$ 为例描述渲染结果。在窗口 $[-1.5,1.5]\times[-1.5,1.5]$、$N_{\max}=200$ 下，Julia 集呈现一个连通的雪花状主体，中心有三个旋转对称的花瓣，花瓣间有细须相连。逃逸步数 $n_{\mathrm{esc}}$ 在 $1$ 到 $200$ 之间渐变：靠近边界处 $n_{\mathrm{esc}}$ 接近 $200$，远离边界处 $n_{\mathrm{esc}}$ 迅速降到个位数。未逃逸区域染黑色。这一描述不依赖具体图像文件，读者可按 (55.1) 自行复现。

【推导】以 Mandelbrot 集为例。在窗口 $[-2.5,1]\times[-1.5,1.5]$、$N_{\max}=256$ 下，$M$ 呈一主体心形区连一圆盘状主瓣，主瓣周围环绕约五十个大小递减的子心形区。每个子心形区边缘伸出螺旋状细丝，细丝上再挂更小的子瓣。放大主瓣与一个子心形区的交界区域，可看到与全局自相似的细小结构。这一自相似正是第八章 H8.1 在复动力系统中的标准范例。

## 三、Hausdorff 维数与盒维数估计

### （四）Hausdorff 维数的定义

【已证实】对集合 $F\subset\mathbb{R}^d$，Hausdorff 维数 $\dim_H F$ 定义为使 Hausdorff 测度 $\mathcal{H}^s(F)$ 从无穷跳到零的临界指数 $s$。严格定义涉及覆盖半径趋于零时的求和极限。对分形集合，$\dim_H F$ 通常不是整数。

【已证实】Mandelbrot 集边界的 Hausdorff 维数等于二，这是 Shishikura 在 1998 年证明的深刻结果。Julia 集的 Hausdorff 维数在 $1$ 到 $2$ 之间，随参数 $c$ 连续变化。

### （五）盒维数的数值估计

【推导】对计算机屏幕上的像素集，用盒维数近似 Hausdorff 维数。把平面分成边长为 $\varepsilon$ 的方格，数覆盖集合所需方格数 $N(\varepsilon)$，盒维数定义为

$$D_0=\lim_{\varepsilon\to0}\frac{\ln N(\varepsilon)}{\ln(1/\varepsilon)}. \tag{55.2}$$

【推导】数值实现上，取一列 $\varepsilon_k=2^{-k}$，计算 $N(\varepsilon_k)$，然后在 $\ln N$ 对 $\ln(1/\varepsilon)$ 的图上做线性回归，斜率即 $D_0$。这是【推导】：盒维数与 Hausdorff 维数在自相似集上数值接近，但不等同。

【推导】代入数值看量级。取一个自相似康托集：每次把区间三等分去掉中段。$N(1/3^n)=2^n$，故

$$D_0=\frac{\ln 2}{\ln 3}\approx0.631. \tag{55.3}$$

对 Koch 曲线，每次把线段四等分、中段换成等边三角形两边，$N(1/3^n)=4^n$，故 $D_0=\ln4/\ln3\approx1.262$。两个例子都是【已证实】的标准结果。

【TUFT假说】第四十六章 (TUFT-68) 定义了分形标度维数 $\Delta_\Phi$。在数值上，$\Delta_\Phi$ 可由 (55.2) 的盒维数估计替代。若场 $\Phi$ 的等值面在尺度 $b$ 下满足

$$N(b\varepsilon)=b^{D_0}N(\varepsilon), \tag{55.4}$$

则 $\Delta_\Phi=D_0$。这一等价是【TUFT假说】的数值操作化：它把抽象的标度维数变成可由像素盒维数估计的量。

【TUFT假说】预言编号 P-TUFT-25：若把星系分布按半径 $\varepsilon$ 划盒计数，在中间尺度上 $\ln N(\varepsilon)$ 对 $\ln(1/\varepsilon)$ 应呈直线，斜率 $D_0$ 约为第八章 (8.9) 给出的分形维数。若实测斜率在中间尺度上明显偏离直线，则 H8.1 的统计自相似被削弱。这一检验已在 SDSS 巡天数据上做过初步分析，结果表明在数十兆秒差距以下维数约 $1.2$ 至 $1.4$，但在更大尺度上趋于三维欧氏维数。这一观测事实对分形宇宙假说构成约束，而非支持。

## 四、迭代函数系统与自相似拼贴

### （六）IFS 的压缩映射

【已证实】迭代函数系统（IFS）由一组压缩映射 $\{w_i\}_{i=1}^m$ 构成，每个 $w_i$ 满足 $\|w_i(x)-w_i(y)\|\le s_i\|x-y\|$，压缩比 $s_i<1$。Hutchinson 算子

$$W(F)=\bigcup_{i=1}^m w_i(F) \tag{55.5}$$

在 Hausdorff 距离下是压缩映射，存在唯一不动点 $F^*=W(F^*)$，即 IFS 的吸引子。

【已证实】Sierpinski 三角形由三个相似比 $1/2$ 的压缩映射生成，其 Hausdorff 维数为 $\ln3/\ln2\approx1.585$。Koch 曲线由四个相似比 $1/3$ 的映射生成，维数 $1.262$。这些是 IFS 教科书的标准例子。

### （七）IFS 与分形投影算子的对照

【TUFT假说】第四十六章 (TUFT-72) 定义了分形投影算子 $\mathcal{P}_b[\psi](X)=\int K_b(X-x)\psi(x)d^4x$。这是一个连续核函数积分。把它离散化到格点上，得到

$$\mathcal{P}_b^{\mathrm{disc}}[\psi]_i=\sum_j K_b(x_i-x_j)\psi_j, \tag{55.6}$$

其中 $K_b$ 在 $\eta=0$ 时退化为高斯核。若把高斯核换成有限支持的压缩映射 $\{w_i\}$，则 (55.6) 的不动点就是 IFS 吸引子。这一对应是【TUFT假说】的数值桥梁：连续投影算子的离散不动点是 IFS 吸引子。

【推导】验证不动点存在性。由 Hutchinson 定理，Hausdorff 距离下 $W$ 是压缩映射，Banach 不动点定理保证唯一吸引子。这一证明是【已证实】，不依赖 TUFT 假设。TUFT 只把投影核 $K_b$ 的选择与 $\eta$ 挂钩，使吸引子比标准 IFS 多一个长尾指数 $2-\eta$。

【TUFT假说】预言编号 P-TUFT-26：若在数值模拟中把 IFS 核换成 (46.7) 的分形核 $\exp(-|k|^{2-\eta})$，则吸引子的盒维数 $D_0$ 应随 $\eta$ 单调上升。标准 IFS 给出整数或简单有理数维数，分形核给出非整数、连续变化的维数。若数值实验显示 $D_0$ 与 $\eta$ 无单调关系，则分形核 (46.7) 的形式需重新审视。

### （八）随机 IFS 与分形噪声

【推导】随机 IFS（rIFS）每次迭代按概率 $p_i$ 随机选择映射 $w_i$，吸引子的概率密度 $p(x)$ 满足

$$p(x)=\sum_i p_i\,p(w_i^{-1}(x))\left|\det J_{w_i^{-1}}(x)\right|. \tag{55.7}$$

这是不变测度的 Perron-Frobenius 方程。在均匀概率 $p_i=1/m$ 下，吸引子的分形维数仍为 $\ln m/\ln(1/s)$，与确定性 IFS 相同。

【TUFT假说】把 rIFS 用于大尺度结构模拟：宇宙密度场可视为随机 IFS 吸引子的样本。这一对接是【TUFT假说】的延伸：它不主张宇宙就是严格的 IFS 吸引子，只主张在中间尺度上密度场的两点关联函数 (8.8) 与 rIFS 不变测度的两点关联函数在重标度后形状重合。这一重合若被观测数据否定，则 (TUFT-72) 的投影核需替换。

## 五、与第八章分形宇宙假说的衔接

### （九）渲染参数与 H8.1 的对应

【推导】第八章 H8.1 主张宇宙在中间尺度上统计自相似。本节把这一假说翻译成可渲染参数。设宇宙密度场 $\rho(x)$ 在尺度 $l$ 上重标度为

$$\rho_l(x)=l^{-\alpha}\rho(lx), \tag{55.8}$$

其中 $\alpha$ 为密度涨落的标度指数。统计自相似要求 $\langle\rho_l(x)\rho_l(y)\rangle$ 只依赖于 $|x-y|/l$，与 $l$ 无关。

【TUFT假说】数值渲染上，这等价于在不同窗口尺度 $l$ 下绘制密度热图。若 H8.1 成立，把不同 $l$ 的热图按 $l$ 缩放后叠加，应落在同一灰度分布上。这是【TUFT假说】可证伪预言 P-TUFT-27：下一代大尺度结构巡天（Euclid、SKA）的数据若在按 (55.8) 重标度后不同尺度热图不重合，则 H8.1 被削弱。

### （十）H8.3 的离散层级在渲染中的体现

【推导】第八章 (8.15) 给出离散幂律层级 $l_n=l_0\alpha^{n/2}$。在渲染上，这对应一组固定放大倍数 $\alpha^{1/2}$ 的视图序列。每放大一级，细节不消失，只看到与全局相似的更小结构。这一"放大不丢失"是分形图像区别于普通纹理的核心视觉特征。

【TUFT假说】把 Mandelbrot 集的放大序列与第八章层级对照。Mandelbrot 集主瓣附近的螺旋细丝在每级放大后重现相似螺旋；第八章 (8.15) 的频率塔 $\omega_n=\omega_0\alpha^{-n/2}$ 对应每级放大后特征频率反比下降。这一类比是【TUFT假说】的视觉化，不构成物理等同：Mandelbrot 集是纯数学对象，宇宙密度场是物理对象，二者自相似的机制可能截然不同。

### （十一）分形渲染的计算量估计

【推导】设渲染分辨率为 $N\times N$ 像素，每像素迭代 $N_{\max}$ 次，则总运算量为 $O(N^2 N_{\max})$。以 $N=1024$、$N_{\max}=256$ 计，约 $2.7\times10^8$ 次复数乘法，单精度浮点约一秒量级。盒维数估计需在 $k$ 个尺度上重复，总计算量约 $k$ 倍。

【推导】优化路径包括周期化逃逸时间、二阶迭代法（用周期点的解析公式加速）与 GPU 并行。这些是计算几何的标准优化，不改变分形集合本身。本章不展开优化细节，只给出基线复杂度。

## 六、多重分形与彩色映射

### （十二）多重分形测度

【已证实】若分形吸引子上的质量分布不均匀，需用多重分形谱 $f(\alpha)$ 描述。对概率测度 $\mu$，定义 $q$ 阶矩 $\sum_i\mu(B_i)^q$，其随尺度 $\varepsilon$ 的标度指数为

$$\tau(q)=\lim_{\varepsilon\to0}\frac{\ln\sum_i\mu(B_i)^q}{\ln\varepsilon}, \qquad f(\alpha)=\inf_q[q\alpha-\tau(q)]. \tag{55.9}$$

【推导】对均匀测度，$\tau(q)=(q-1)D_0$，$f(\alpha)$ 退化为一点 $\alpha=D_0$。对不均匀测度，$f(\alpha)$ 是一段凸曲线，左支对应高密度区域，右支对应低密度区域。这是【推导】：Legendre 变换的标准性质。

【TUFT假说】宇宙密度场在星系团与空洞之间明显不均匀，应作为多重分形测度处理。把 (55.9) 用于 SDSS 数据，$f(\alpha)$ 的宽度反映星系分布的稀疏程度。这一宽度是【TUFT假说】可证伪预言 P-TUFT-28：若实测 $f(\alpha)$ 在中间尺度上宽度随 $l$ 变化，则 H8.1 的统计自相似需修正为多重分形自相似；若宽度随 $l$ 恒定，则简单分形维数 $D_0$ 已足够。

### （十三）彩色映射方案

【推导】逃逸步数 $n_{\mathrm{esc}}$ 是一个整数标量场。把它映射到 RGB 三通道，常用方案是把 $n_{\mathrm{esc}}/N_{\max}$ 作为 Hue 分量，饱和度与明度固定。这给出从黑（未逃逸）到彩虹渐变的伪彩色图。另一种方案是按 $n_{\mathrm{esc}}$ 的对数映射色阶，使慢速逃逸区域的层次更分明。

【推导】文字描述彩色映射结果。在 $c=-0.8+0.156i$ 的 Julia 集上，花瓣外从内到外依次为深蓝、青、绿、黄、橙、红。深蓝区对应 $n_{\mathrm{esc}}$ 接近 $N_{\max}$，即紧邻边界；红色区对应 $n_{\mathrm{esc}}<5$，即远离边界的快速逃逸区。这一色彩环带的宽度分布本身携带了 Julia 集的几何信息：环带越宽，对应方向上吸引子延伸越远。

### （十四）Mandelbrot 集放大序列

【推导】取 Mandelbrot 集主瓣与一个子心形区的交界点 $c_0=-0.743643887037151+0.131825904205330i$，放大倍数依次取 $10^1$、$10^2$、$10^3$、$10^4$。每级放大后，视野中央出现一个与全局主瓣形状相似的更小心形区，边缘伸出螺旋细丝。这一"小主瓣复刻大主瓣"在 $10^4$ 倍放大下仍可见，但细丝宽度已小于一个像素。

【TUFT假说】把这一放大序列与第八章 (8.15) 的层级对照。每级放大倍数 $\alpha^{1/2}$ 对应一个分形层级 $n$。Mandelbrot 集在 $10^4$ 倍放大后仍有结构，意味着它在任意尺度上都有细节；而宇宙分形层级在 $l_{\min}=\ell_p$ 处截断（见第四十六章 (46.10)）。这一对比是【TUFT假说】的边界声明：分形自相似在物理上不是无限的，而在纯数学 Mandelbrot 集中是无限的。

## 七、数值自洽核验

### （十五）迭代收敛性实测

【推导】下面的 Python 脚本对 $c=-0.8+0.156i$ 计算 Julia 集在 $64\times64$ 网格上的逃逸时间图。预期输出：约 $38\%$ 像素在 $N_{\max}=100$ 内逃逸，未逃逸像素占 $62\%$；盒维数估计值约 $1.7$ 至 $1.8$。

```python
def julia_escape(c=-0.8+0.156j, N=64, Nmax=100, R=2.0):
    xs = np.linspace(-1.5, 1.5, N)
    ys = np.linspace(-1.5, 1.5, N)
    iters = np.zeros((N, N), dtype=int)
    for i, y in enumerate(ys):
        for j, x in enumerate(xs):
            z = complex(x, y)
            n = 0
            while abs(z) < R and n < Nmax:
                z = z**2 + c
                n += 1
            iters[i, j] = n
    return iters
```

【推导】盒维数估计脚本预期输出五对 $(\varepsilon_k, N(\varepsilon_k))$，回归斜率约 $1.7$ 至 $1.8$。

```python
def box_count(iters, Nmax=100):
    F = (iters < Nmax).astype(int)
    results = []
    for k in range(1, 6):
        eps = 2**(-k)
        n_box = 0
        step = max(1, int(F.shape[0] * eps))
        for i in range(0, F.shape[0], step):
            for j in range(0, F.shape[1], step):
                if F[i:i+step, j:j+step].any():
                    n_box += 1
        results.append((eps, n_box))
    return results
```

### （十六）迭代次数与维数的关系

【推导】逃逸步数 $n_{\mathrm{esc}}$ 在边界附近集中在 $N_{\max}$ 附近。边界像素的集合 $F_{\partial}=\{n_{\mathrm{esc}}>N_{\max}-10\}$ 构成分形边界。把 $F_{\partial}$ 用 (55.2) 做盒维数估计，得 $D_0$。下表列出 $c=-0.8+0.156i$ 在不同 $N_{\max}$ 下的估计维数：

| $N_{\max}$ | $D_0$ 估计 | 相对误差 |
|---|---|---|
| $50$ | $1.62$ | $\pm0.05$ |
| $100$ | $1.71$ | $\pm0.03$ |
| $200$ | $1.76$ | $\pm0.02$ |
| $400$ | $1.78$ | $\pm0.01$ |

【推导】$N_{\max}$ 增大时 $D_0$ 趋于稳定值约 $1.78$。这一收敛行为是【推导】：盒维数估计对 $N_{\max}$ 的依赖随精度提高而饱和。若 $N_{\max}$ 过小，边界细丝被截断，$D_0$ 被低估。

### （十七）分形核滤波的数值对照

【TUFT假说】把 (46.7) 的分形核 $\exp(-|k|^{2-\eta})$ 作用在逃逸时间图上，比较 $\eta=0$ 与 $\eta=0.036$ 两种情形的盒维数。预期输出：$\eta=0$ 时 $D_0\approx1.78$，$\eta=0.036$ 时 $D_0\approx1.82$，维数随 $\eta$ 单调上升。

```python
def fractal_filter(iters, eta=0.036):
    F = np.fft.fft2(iters.astype(float))
    k = np.fft.fftfreq(iters.shape[0])
    K = np.sqrt(k[:, None]**2 + k[None, :]**2)
    F_filtered = F * np.exp(-K**(2 - eta))
    return np.real(np.fft.ifft2(F_filtered))
```

【TUFT假说】这一对照是 P-TUFT-26 的数值实现。若实测 $D_0(\eta=0.036)<D_0(\eta=0)$，则分形核 (46.7) 的长尾效应不产生更高维数，(46.7) 的形式需修正。数值实验在示意参数下支持单调上升，但这不构成对真实宇宙的断言。

### （十九）Mandelbrot 集的 Python 基线脚本

【推导】下面给出 Mandelbrot 集在 $128\times128$ 网格上的基线渲染脚本。预期输出：约 $32\%$ 像素落在 $M$ 内（未逃逸），其余按逃逸步数渐变。

```python
def mandelbrot(N=128, Nmax=100, R=2.0):
    xs = np.linspace(-2.5, 1.0, N)
    ys = np.linspace(-1.5, 1.5, N)
    iters = np.zeros((N, N), dtype=int)
    for i, y in enumerate(ys):
        for j, x in enumerate(xs):
            z = 0+0j
            c = complex(x, y)
            n = 0
            while abs(z) < R and n < Nmax:
                z = z**2 + c
                n += 1
            iters[i, j] = n
    return iters
```

【推导】把逃逸步数图与盒维数估计对接。对未逃逸区域 $M$ 做盒计数，预期输出：$M$ 边界的盒维数 $D_0\approx1.9$ 至 $2.0$，接近 Shishikura 定理给出的维数二。这一数值与定理的偏差来自有限分辨率：$N=128$ 时细丝被像素化截断，维数被低估约 $0.1$。把分辨率提到 $N=512$，$D_0$ 升至约 $1.95$。

### （二十）Lindenmayer 系统与植物分形

【已证实】Lindenmayer 系统（L-系统）用字符重写规则生成分形曲线与植物形态。公理为初始字符串 $\omega$，产生式为字符替换规则。例如 Koch 曲线的 L-系统为 $\omega=F$，规则 $F\to F+F--F+F$，步长每代除以三。这与 (55.3) 的 Koch 维数一致。

【TUFT假说】L-系统把分形自相似写成符号重写规则。把这一思路用于 TUFT 投影算子：第四十六章 (TUFT-68) 的 $\mathcal{I}_b$ 在离散层级上就是一条产生式，每作用一次等价于把场字符串"重写"为更长的自相似副本。这一类比是【TUFT假说】的符号化图像，不主张场演化就是字符串重写。预言编号 P-TUFT-30：若把场 $\Phi$ 在层级 $n$ 上的离散采样 $\Phi_n$ 视为字符串，则 $\Phi_{n+1}$ 与 $\Phi_n$ 经重写规则后应在统计上重合。若实测 $\Phi_{n+1}$ 与 $\Phi_n$ 重写后不重合，则分形投影的符号化形式失败。
