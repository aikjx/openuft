# ROOT V135 — 科学研究及复算包

**状态**：数学模型审计，不代表四力统一已完成。日期：2026-11-24。

## 本轮可验证成果

- 推导 \(\mathbb{CP}^2\) 的 Spinᶜ Dirac 指标：\(q(q+1)/2\)。
- 推导 \(\mathbb{CP}^2\times S^2\) 的指标：\(mq(q+1)/2\)。
- 指出从 6D 指标 3 跳到 11D 四维弱手征三代的逻辑错误。
- 显式检查 11D Clifford 反对易关系和四维手征投影秩。
- 检查纯 Einstein 或仅添加 \(\Lambda\) 时平直四维与正曲率内部空间的不兼容。
- 给出规范群全局表示及引力常数的剩余障碍。

- `研究报告.md`：带假设、推导、量纲检查及失败判据的完整中文报告。

- `src/verify_v135.py`：独立验证程序，标准库可跑；安装 NumPy 时额外测试 Clifford 矩阵。
- `data/*`：自动产生的精确指标扫描、结果、每项断言。
- `docs/*`：研究路线与来源。
- `archive/ROOT_V134_...zip`：当轮可访问的 V134 完整历史包，V134 内包括先前归档的 V2、V130–V133 文件，原样保留。
- `SHA256SUMS.txt`：包内文件哈希，除该清单本身。

## 运行方法

### Windows

双击 `一键验证.bat`。如需完整 Clifford 矩阵测试，预先运行 `py -m pip install numpy`。

### Linux / macOS

运行 `bash 一键验证.sh`。如需矩阵检查，先安装 NumPy。

如无 NumPy，所有基础拓扑及算术检查仍可运行；矩阵检查报告 `not_run`，不能称为通过。
