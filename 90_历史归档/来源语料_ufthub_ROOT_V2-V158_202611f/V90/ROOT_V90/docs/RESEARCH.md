# ROOT V90 | 独立判据研究报告

## 1. 科学结论和限制
- 牛顿双体受控相位可以成为纠缠方案的输入；其观测不等同于测到引力子或一圈量子引力修正。
- 经典局域操作与经典通信 (LOCC) 不能由可分离初态产生纠缠；这一不可能性定理并未排除所有非局域、非马尔可夫或具有其他自由度的“经典引力”模型。
- 长程 EFT 势修正中的 41/(10π) 是常见匹配表达式的系数；单独势项不是无条件规范不变的直接观测量。
- 一阶后牛顿项取演示性等质量系数 6，忽略速度相关和实验协议依赖；不能用它声称完整 1PN 预言。

## 2. 显式模型
取两个质量相同的点物体 m，分支间距参数 δ，四个分支相互距离为 r, r+δ, r+δ, r+2δ。非局部相位组合：

Φ[f] = (G m² t / ℏ) [f(r)-2 f(r+δ)+f(r+2δ)].

在 SI 中分别取：

f_N(r)=1/r;
f_PN(r)=6 G m/(c² r²) (仅演示);
f_Q(r)=[41/(10π)] G ℏ/(c³ r³) (长程 EFT 势的演示性项)。

采用理论单位 c=1，但 ℏ、G 不设为 1；代码 SI 计算恢复 c。

## 3. 三距离零化的精确含义
令 a1_i=1/r_i，a2_i=1/r_i²，a3_i=1/r_i³。求解矩阵 A w=(0,0,1)，其中 A 的三行是 a1,a2,a3。三个互异正距离保证可逆；由此消除恰好符合 1/r 和 1/r² 的两种模板，保留 1/r³ 模板。

**重要限制**：实际干涉的双分支距离组合并非简单 1/r^n，应该先把每一种模型映射到真实仪器观测量，再计算权重；真实电磁背景可能有相同的距离幂次。零化不等于鉴别量子引力。三点精确消元还可能极大放大噪声，必须评估协方差。

## 4. 统计与实验升级
对观测向量 y，候选模板矩阵 X=[n,p,q,b1,...]，协方差 Σ，拟合参数 θ：

θ_hat=(XᵀΣ⁻¹X)⁻¹XᵀΣ⁻¹y。

只有在矩阵满秩且误差模型可信时才可用此式；应优先使用 SVD/QR，检查条件数。对 q 的识别必须在投影掉牛顿、后牛顿和所有已知背景模板之后仍有非零分量。选择测量距离以最大化信噪比而不是只要求代数可分。

## 5. 下一步的可证伪门槛
1. 给出协变作用量、自由度和局域性/因果性条件。
2. 推出可实际测量的密度矩阵、关联函数或散射可观测量；不得只给规范依赖势函数。
3. 给出至少一个与 GR+量子物质+标准 EFT 不同的参数固定预言。
4. 联合拟合电磁耦合、有限尺寸、振动、退相干、温度与校准误差。
5. 在公开真实数据中盲测并报告置信区间与排除区间。

## 6. ROOT 螺旋假设的地位
几何螺旋可作为运动学参数化；要成为动力学理论必须定义作用量、洛伦兹变换、应力能量守恒和可计算散射/引力观测量。仅以曲率、挠率和频率建立恒等关系不能证明四力统一。
