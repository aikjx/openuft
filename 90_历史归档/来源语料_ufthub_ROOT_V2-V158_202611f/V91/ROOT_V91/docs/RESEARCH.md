# ROOT V91 研究记录与审计

## 问题
三距离零化消除两个模板后，第三模板未必是量子引力独有；例如电磁和有限尺寸背景可与它同形。零化权重也可能放大测量噪声。

## 推导
假定 y=B beta + A q + epsilon，epsilon~N(0,Sigma)，Sigma 已知、正定且不随 A 变化。白化后 q'=L^-1 q、B'=L^-1 B，L L^T=Sigma。令 P_B=B'(B'^T B')^+ B'^T，则 I_A=|| (I-P_B)q'||²。A 的条件标准差下界是 1/sqrt(I_A)，当 I_A=0 时不可辨识。SVD 计算 P_B，避免法方程病态。

## 模型
用四分支距离二阶差分 D_n(r)=r^-n - 2(r+delta)^-n+(r+2delta)^-n 构建三种距离形状。候选 q=D_3，背景 D_1,D_2。每列按欧氏范数归一化，因而只比较距离形状，绝对信号振幅和真实噪声并未输入。选 5 个不同距离，从 13 个候选点中枚举 1287 种组合，选择 Fisher 信息量最大的组合。注意扫描后择优可能导致选择偏差，真实实验需预注册与独立验证。

## 反例
把 D_3 也加入背景模板，量子信号与背景完全退化，Fisher 信息趋零。这是方法无法独立识别量子引力的构造性反例。

## 重要限制
1. V90 的 1PN 系数仅为演示；其势函数不构成规范不变观测量。
2. EFT 一圈势项必须连同可测散射量/干涉协议匹配，不能直接把独立 1/r³ 系数当成唯一量子信号。
3. 当前归一化噪声不是现实仪器的相位噪声，结果不表示量子引力可测。
4. 未建模质量分布、Casimir-Polder、电荷残留、振动、波包动力学、退相干、时序关联与系统校准。
5. 需要密度矩阵演化和明确的经典替代理论类，才能进一步比较纠缠见证。
6. c=1 用于理论记号，SI 数值恢复 c；不设 hbar=G=1。
