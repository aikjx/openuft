# 实验设计与判伪路线｜从模型参数到观测

## E1. 材料依赖的 Yukawa 比较模型

不是由 ROOT 已证明产生的额外力，而是一个**标准化假设测试模板**。若对两材料 A、B 的自由落体加速度定义

\[a_A(r)=g_N(r)[1+\alpha_A f(r/\ell)],\qquad a_B(r)=g_N(r)[1+\alpha_B f(r/\ell)],\]

\[f(r/\ell)=(1+r/\ell)e^{-r/\ell},\]

则其 Eötvös 参数严格为

\[\boxed{\eta(r)=\frac{2(a_A-a_B)}{a_A+a_B}=\frac{2(\alpha_A-\alpha_B)f}{2+(\alpha_A+\alpha_B)f}.}\]

这严格建立了**假定耦合差 -> 仪器可比较量**的算法映射，但并非从螺旋公设推出 \(\alpha_i\) 和 \(\ell\)。若 \(\alpha_A=\alpha_B\)，则 \(\eta=0\)，MICROSCOPE 不能据此排除成分完全相同的第五力耦合。

## E2. MICROSCOPE 真实观测和示例检查

MICROSCOPE（Phys. Rev. Lett. 129, 121102, 2022）报告 \(\eta(Ti,Pt)=(-1.5\pm2.3_{stat}\pm1.5_{syst})\times10^{-15}\)（1σ）。用**仅作示意的独立高斯合成** \(\sigma=\sqrt{2.3^2+1.5^2}\times10^{-15}\)，有示意约 95% 双侧区间 \(\eta_{obs}\pm1.96\sigma\)。这不是任务组发布的正式统一置信限，实际拟合应考虑完整的系统误差、轨道仪器、源特征和耦合模型。

本项目 `src/root_v65.py` 的 `eotvos_eta` 与 `microscope_interval` 提供这一简化估算。`data/TEST_ONLY_...csv` 的参数全部是人工选值，**不是 MICROSCOPE 的官方数据集**。

## E3. 其余必须比较的物理观测

- 弱等效原理；绝对引力/反平方律及地球重力图谱；精密 G 测量。
- 水星近日点进动、引力红移、光偏折、Shapiro 延迟、GPS 时钟校正。
- 双星与黑洞的引力波传播、极化和波形；与电磁信号的多信使比较。
- QED 精密检验、标准模型粒子质量、散射截面、电弱精密观测、强相互作用 QCD。
- 源与物质组成、频率、温度、旋转与实验系统误差的区别。

## E4. 必须先预测再比较

**预注册流程**：冻结作用量、参数与先验 -> 推导预测和不确定度 -> 选择独立样本与测量装置 -> 盲法计算对照 -> 公开代码与残差 -> 更新或否决模型。不得用被检验的结果反向选择参数后再说“成功预测”。

最小候选预言模板：

\[\Delta g_i(r)=g_N(r)\alpha_i (1+r/\ell)e^{-r/\ell}.\]

若模型在冻结参数下预测 \(|\eta|\) 远大于实测精度且无法在系统误差中解释，相关参数区域被否决；如果 \(\alpha_i\) 可任意调至 0，则模型在该实验上难以被证伪，不能把未被排除视为支持其机制。
