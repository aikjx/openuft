## 问题定义

弦论与 LQG 是量子引力两大主流路线，出发点截然不同：弦论（高维、微扰、含物质、背景依赖）vs LQG（4 维、非微扰、纯引力、背景无关）。统一目标：建立既含弦论物质统一性、又含 LQG 背景无关量子几何的框架。
