# 第十六章｜来源、数据版本与引用伦理

1. **2026 Review of Particle Physics** — Particle Data Group, F. Takahashi et al., Int. J. Mod. Phys. A 41, 2630011 (2026), https://pdg.lbl.gov/2026/ 。为标准模型、质量谱、粒子现象学的优先综合参考；研究中的替代理论不应自创已定实验值。
2. **CODATA 2022 adjustment** — Mohr, Newell, Taylor, Tiesinga, Rev. Mod. Phys. 97, 025002 (2025), DOI https://doi.org/10.1103/RevModPhys.97.025002；NIST 常数库 https://physics.nist.gov/constants 。G=6.67430(15)×10^-11 SI，h 和 c 精确定义。
3. **MICROSCOPE final result** — Touboul et al., Phys. Rev. Lett. 129, 121102 (2022), DOI https://doi.org/10.1103/PhysRevLett.129.121102 。对成分相关新增引力的关键检验。
4. **Cassini Shapiro delay** — Bertotti, Iess, Tortora, Nature 425, 374–376 (2003), DOI https://doi.org/10.1038/nature01997 。测量 PPN γ。
5. **Sakharov induced gravity modern perspective** — Matt Visser, Mod. Phys. Lett. A 17 (2002), DOI https://doi.org/10.1142/S0217732302006886 ，预印本 https://arxiv.org/abs/gr-qc/0204062 。诱导引力并非 ROOT 首创，需要对 UV regulator 的依赖明确标注。
6. **GW170817/GRB170817A** — LIGO/Virgo/Fermi/INTEGRAL 联合观测与 NASA NTRS https://ntrs.nasa.gov/api/citations/20170011356/downloads/20170011356.pdf ，到达时差的天体物理发射假设应保留。

**引用伦理：**研究报告原创文字和自己推导的公式可以作为本项目自有工作；不应直接大段转载文章正文。链接仅用于核查；本项目未自动下载或再发行付费论文全文。后续替代理论若引用最新实验，须同时记录数据提取时间、文献版本和不确定度。
