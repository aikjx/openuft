## §2 量纲秩不变量定理（本册承重结果）

取四元量纲 `(M,L,T,Q)`，几何基组每个元素的 M 分量均为 0：

| 量 | 量纲 | M 分量 |
|---|---|---:|
| c | L·T⁻¹ | 0 |
| ω, ω_max | T⁻¹ | 0 |
| κ, τ | L⁻¹ | 0 |
| l₀, a₀ | L | 0 |
| A₀ | L² | 0 |
| ℏ | M·L²·T⁻¹ | 1 |

机器读数：

- rank(几何基)=2，且该 2 维子空间完全落在 M=0 平面；
- rank(几何基 + ℏ)=3，ℏ 不在几何基张成空间，`reachable_geo=False`；
- 加入质量标度 m 后 rank=3，且 ℏ 可达；这说明**质量输入是必要外部项**，不是可省略的细节；
- 加入 ρ₀ 后 rank=3，ℏ 同样可达；但 ρ₀ 自带 M，仍是外部项。

因此方向 A（再引入 l₀、ω_max、作用量量子化公理）只增加 L/T 方向或把 h 写进公理，补不出 M。所谓「几何公理突破」若包含 h，就不是从几何推出 ℏ，而是**把待证物写进公理**。

## §4 两处新增硬错

### 4.1 质量量子量纲

手稿写 `m_quantum = ℏ/(a₀² c)`，并注明「从 [ML²T⁻¹]=[M]·[L⁻²]·[LT⁻¹]」。该括号乘法本身就是错的：

- `[ℏ/(a₀²c)] = M·L⁻¹`，是线密度，不是质量；
- 正确的 `ℏ/(a₀ c)` 才是 M；
- 因此「基本质量量子」不能支撑其后 `m_e/m₀` 的整数倍讨论。

### 4.2 α 指数算术滑移

用常量 `α=7.2973525693e-3`、`m_e=9.1093837015e-31 kg`、`ℏ=1.054571817e-34 J·s` 与 `m_P=√(ℏc/G)`：

- `m_e/m_P = 4.1854622147319578E-23`；
- `ln(m_e/m_P)/ln(α) = 10.472619563880568`；
- 手稿写 `9.6`，指数相对偏差 `8.3323905596E-2`；
- `α^9.6/(m_e/m_P) = 73.22236267466246`，即数值高估约 73 倍。

所以手稿从该句得到的「不是 α 的简单幂次」方向虽对，但给出的数值例证本身错误；不能直接引用。
