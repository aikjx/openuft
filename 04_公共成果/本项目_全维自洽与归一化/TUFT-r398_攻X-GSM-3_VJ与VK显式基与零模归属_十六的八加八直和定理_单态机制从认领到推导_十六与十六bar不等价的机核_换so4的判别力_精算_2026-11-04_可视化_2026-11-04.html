TUFT-r398 · 攻 X-GSM-3：V_J / V_K 的显式基与零模归属

图 1｜`16 = V_J ⊕ V_K` 是**定理**：两半各 16 维实（= 复 8），rank(V_J + V_K) = 32、交维数 0。★ 机核是秩不是「维数相加」：两个 16 维子空间在 32 维里可以重合、也可以交 16 维。
图 2｜`J3` 的两半谱：`8×1 + 4×2`：`V_J` 上恒 0（8 个复态，全是弱单态）；`V_K` 上 A² = −I 且 tr = 0 ⇒ 谱必是 `±i` 各 8 维实 ⇒ 4 个二重态。★★ 归一化说清：`Σ_ab = (1/4)[Γ,Γ]` 是反 Hermitian，实化后实反对称，故本征值是**纯虚**；`SU2J_C` 每平面系数取 1（= 标准 Cartan 的 2 倍）⇒ 谱是 `±i` 而非 `±i/2`。
图 3｜`Y` 谱分半总表（本卷结构总图）：候选取 11 个 `y` 值且**两侧符号都放**，结果 `V_J` 只点亮 4 行、`V_K` 只点亮 2 行 —— 两值集**互不相交**、合起来铺满全谱。★ 符号是算出来的：若我先定好符号再验，候选集里那些空行就没有意义了。
图 4｜零模归属与「平移换边」：基线 `ker(Y∣V_J) = 2`、`ker(Y∣V_K) = 0`；把 `y` 整体减 `1/2` 后变成 0 / 4。★★ 注意这**不是对调**：`V_J` 的零模来自 `y = 0`（单态，1 个），`V_K` 的新零模来自 `y = 1/2`（二重态，2 个）—— 零模维数跟着「被平移到 0 的那个 `y` 值的**重数**」走。
图 5｜`16` 与 `16bar` **不等价**的机核：`ker(iY−1)` 在两边是 0 vs 2、`ker(iY+1)` 是 2 vs 0 ⇒ `y = +1` 的重数 0 vs 1。★★★ 但这条**不是** `J`/`K` 可分辨的原因 —— r397 的四格里 `J` 在两块都得 2、`K` 在两块都得 0，说明分辨与否只取决于 `J`/`K`；真正的原因是图 4 的零模落点。把两者混为一谈正是 r397 E09 的错法。
图 6｜判别力与三路互印：换到 1..4 号指标后仍 `8 + 8`，但 `dim(V_J ∩ V_J') = 8`（< 16）且 `nu^c` **整个换边**（`∈ V_J' = False`、`∈ V_K' = True`）⇒「`nu^c ∈ V_J`」是这一组嵌入的性质，不是废话。★ 下方三条幂和路径：本卷用**两个 16×16 子矩阵的迹**、r397 用 32 维上 `Y^{2k}` 的迹、再加 `tr((iY)²)` ⇒ 三路一致；但两半各自的 `s1`（8/3 与 2/3）都不等于任何 `p_k`，故全谱矩看不见分半。
