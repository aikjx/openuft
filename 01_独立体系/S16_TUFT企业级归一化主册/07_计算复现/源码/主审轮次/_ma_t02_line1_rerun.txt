[1] 10^2 假设的拆解
----------------------------------------------------------------------
几何乘积定义: G = α * Q * τ
  α = R/r   环面长短径比（基态 Hopfion 近胖环面）
  Q         Hopf 荷（π_3(S^2)=Z，整数）
  τ         纤维缠绕/扭转因子（整数）
=> 10^2 = 三个 O(1..10) 因子的经验乘积，非解析定理。

  即基态几何乘积上界 ~ 60  ≈ 10^1.8

[4] 核心张力：10^3 因子来源
----------------------------------------------------------------------
  几何基态乘积上界 G_max ~ 60 = 10^1.78
  汤川跨度         Y_span   ~ 3.41e+05 = 10^5.53
  缺口 = Y_span/G_max = 5.69e+03 = 10^3.76

  10^3 缺口的来源拆解：
  (i)   几何内部：G 三因子均为 O(1..10)，乘积封顶 ~10^2，
        这是'纯几何/拓扑'能给的全部。
  (ii)  几何外的 10^3.5 必须由非几何量提供：
        - 动力学标度（Derrick 长度 vs 基本长度，量纲换算）
        - 势 V(n) 简并破缺，选取耦合幅值
        - 重整化群跑动（GUT 标度 -> EW 标度）
  (iii) 这些都不是 Hopfion 的几何量（R,r,Q,τ），
        因此'纯几何路径'在原理上就差 ~10^3，无法靠更精细的
        几何量计算缩小——几何算得再准，也只能从 10^2.4 到 10^2，
        动不了 10^3 这一阶。

----------------------------------------------------------------------
[5] 10^2 能否放宽？
----------------------------------------------------------------------
  情形                          上界行为        物理地位
  ----------------------------   ------------   --------------------------
  基态/能量极小 (Q 固定)         ~10^2 紧       经验，受 Derrick+紧性保护
  激发/非极小构型               可放大约10倍    但能量代价高，不被选中
  任意光滑构型 (无能量约束)      无有限上界      α 可任意大 -> G 无界
  纯几何 + 基态选取             封顶 ~10^2      本轮核心结论

  => 放宽 10^2 的唯一途径是放弃'基态选取'或引入非几何因子；
     前者破坏物理合理性，后者已超出'纯几何路径'。

[6] 四态分级
======================================================================

  【严格定理】
   - Q = Hopf 荷 ∈ π_3(S^2) = Z，整数、离散。
   - 能量亚线性缩放 E >= c Q^{3/4}（Vakulenko-Kapitanskii 型下界）。
   - Derrick 标度：静态孤子要求 E_2 = E_4，存在特征长度 R*。

  【条件定理】
   - 在"能量极小 + Q 固定 + 紧性"条件下，α=R/r 有有限上界
     （数值 ~5）；常数非解析已知，依赖模型/势。
   - 若放松到任意光滑构型，α 无有限上界（G 无界）——条件一旦去掉，
     定理失效。

  【定义识别】
   - "几何量乘积 G = α Q τ" 的具体拆法是本轮定义选择，非唯一；
     换一组几何量（如体积比、表面/体积比）会改 G 的绝对值，
     但不改"纯几何封顶 ~10^2"的量级结论。

  【开放命题】
   - G_max 的精确常数（解析）未知。
   - 10^3 缺口究竟由动力学/势/RG 中哪一项主导，未决。
   - "纯几何路径能否经更精细计算逼近 10^5"——本轮判定为否（原理性），
     但这是基于玩具能量模型的推断，严格证明待补。
