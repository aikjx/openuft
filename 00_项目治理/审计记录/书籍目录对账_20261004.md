## 2 判据（这台仪器凭什么算「对上」）

| 项 | 口径 | 明确不算缺陷的情形 |
|---|---|---|
| 「目录有名而无文件」 | 目录里的 `[显示名]\(目标\)` 按**该目录所在目录**解析后，盘上没有这个文件 | 外链、`#` 文内锚点（本轮 0 条被跳过，若有会逐名印出） |
| 「文件有而目录无名」 | 活动树上的 `.md` 未被三份目录中任何一份链接到 | `目录.md` 自身（它是目录不是内容）；本层 2 份见第 3 节 |
| 「章号连续」 | 文件名前缀解析出的章号在 [最小, 最大] 内无缺口 | 「第36章补充」这类同号带「补充」字样的——按名点名并与总目录自述并置，不自动算重号缺陷 |
| 「声明与现测一致」 | 总目录自述表的阿拉伯数字与现测唯一章号数／目录内 `[附录` 条目数逐格相等 | 自述里「＋1 篇章后补充」这类附加声明不参与等式，只与重号形状并置 |

## 5 未测与盲区（不许由第 1 节外推）

1. **覆盖面**：只校 `01_完整版`、`02_大众精编版` 两棵活动树与三份目录；`90_版本档案/` 305 份（md 278）**未校**——那里另有 8 份自述目录，它们与封存版本谱系是否自洽是另一个问题。
2. **链接形式口径**：仪器只认 `[显示名]\(目标\)`。`书籍/README.md` 第 20 行把 README 的路径写在**反引号里**而不是链接里，所以它「点名」了 README 而仪器看不见——第 3 节第 2 条的见证因此来自 grep，不来自面G。
   要么给仪器加一条「反引号路径」通道（并配变异体，防止把普通反引号词都当路径），要么承认 README 的入口登记形式与目录不同。**这是口径差，不是「没有引用」。**
3. **汉字数自述**（270 624／149 687）**未核**：那是内容级计量，需要另一枚按文件字节／字符数现算的尺；本文只数文件名，不数正文。
4. **面名是写死的**：`book_toc_check.txt` 与 `book_toc_selftest.txt` 各自只有一个名字，复跑一次就原地顶掉上一代——这与面A／面B 已经接上的「版次链＋旧面 [1] 行并置」是**同一笔债，本仪器还没还**。所以本文 §0 钉的是**这一代**的面；引这些数之前先现跑，跑完面就换了代。
5. **章号解析只覆盖前缀**：`第N章`／`第N章补充` 之外的命名（如「序」「前言」「附录一」）不进章号账，它们的在册性由第 1 节第 1、2 条的链接通道覆盖。
6. 自检 9 例覆盖的是**自述表解析**与**章号覆盖**两条通道的判据；链接解析那条通道的变异体是面G [5] 里的按盘正对照（取错基准时它红），**没有**「链接存在而文件被改名」的活体注入测试——本轮靠 0 条 MISS 的反向事实支持，不靠变异体。
7. **面E 对本文的覆盖面也有它自己的形状**：它只认表格行里「`文件名.扩展名` ＋ 尺寸 B／`12 位 md5`」这一种形状，且扩展名名单是 `txt|py|md`。本文 §0 之外若有别的形状（反引号路径、行内 hash、13 位 hash 的旧写法），**不在它的判据里**。13 位那一类本轮刚从「两侧都不命中＝隐身」修成「宽口数到、窄口抽不出＝SKIP-RED」，修的证据是面G2 同族的 8 枚自检；其余形状仍未修，也仍未测。
