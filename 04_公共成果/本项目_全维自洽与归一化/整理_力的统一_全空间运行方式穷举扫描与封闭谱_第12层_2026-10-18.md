## 2. 两个新定理（本层提出并机器验证）

### 定理 T1：维度-自由度守恒定理（W-01/W-02/W-04）

由作用量无量纲性 + 相互作用项同维，符号解线性系统得：

$$[A]=\frac{d-2}{2},\qquad [g]=\frac{4-d}{2}$$

- **d = 4**：[g] = 0，耦合是无量纲纯数 ⇒ "三个耦合相等"才是真正的纯数命题。
- **d ≠ 4**：g 带质量维数，等式 $g_1=g_2$ 必须先乘一个标定标度 $\mu^{|4-d|/2}$（物理上即紧化半径 R 或 $M_{KK}$）。

**账本**：4D GUT 的未知是 $(g_G, M_{GUT})$ 共 2 个，约束是低能三个耦合值共 3 个 ⇒ **净 1 条可检验关系**（这就是 GUT 有预测力的全部来源）。d ≠ 4 时未知 +1、约束不变 ⇒ **净 0 条关系，退化为参数化**。

> 含义：偏离 4D 所换来的每一个"统一"，都恰好被新引入的尺度自由度抵消，**净预测力不增**。这正是第 89 章三条额外维图景"带价封档"的一般机制——不是那三个模型不好，而是任何 d ≠ 4 的统一都要付这个价。

### 定理 T2：δ_TUFT 供需量级定理（W-22/W-23/W-24/W-25）

**能标依赖分支（W-25）**：若 δ 只在某能标以上激活，则必须引入阈值标度 $(M_\*, p)$ 共 2 个自由度换 2 个约束 ⇒ 净预测力 0，且该阈值与 $M_{GUT}$ 的关系仍需外部给定（回链第 88 章 C7：分量级阈值调谐已封死）。

## 3. 穷举扫描结果（三张表）

### 3.1 时空维扫描（W-05~W-08）

| 发现 | 内容 |
|---|---|
| 规范耦合无量纲 | **仅 d = 4**（其余 d 给 [g] = −0.5 ~ −11） |
| 引力可重整 | 仅 d ≤ 2；d > 2 全不可重整 |
| YM ∩ EH 可重整窗口 | **空集**（YM 需 d ≤ 4，EH 需 d ≤ 2，交集 d ≤ 2 无引力波、无手征费米子、无 S 矩阵） |
| 孤子（D = d−1） | D=1 可（第 ⑨ 层 P-04 解析 sech）；**D ≥ 2 纯标量被 Derrick 排除**，须加 sextic 或规范场 ⇒ 我们所在的 D=3 这一格是"有条件" |

> 重要推论：**不存在任何时空维使规范力与引力同时可重整**。这不是模型的缺陷，是量纲的必然 ⇒ 任何"四力统一作用量"只能是 EFT 或紫外完备框架的低能极限。

### 3.2 拓扑/紧化扫描（W-09~W-13）—— 等距群容量判据

n 维紧致流形的等距群维数上限 = n(n+1)/2：

- SM 需要 12 个规范生成元（8+3+1）⇒ 需 **n ≥ 5**（上限 15）
- 装下含 SM 的最小紧单群 SU(5)（24 个）⇒ 需 **n ≥ 7**（上限 28）
- 手征费米子要求（Witten no-go：奇维 Dirac 指标恒零，正确理由见第 89 章 F13）⇒ n 需偶且带非平凡指标 ⇒ 最小候选 n = 8
- **而 K3、CY₃ 对通用度量的等距群维数是 0** ⇒ 等距群容量与"我们需要的规范群"之间隔着结构性缺口
- 每个紧化还必产生 radion/模量，ω = 2 远低于实验下限 ω > 40000 ⇒ 必须额外提供模量冻结机制

### 3.3 联络扫描（W-14~W-17）—— 闸门位置

| 联络 | 判定 | 理由 |
|---|---|---|
| Levi-Civita | FAIL | Coleman-Mandula / Weinberg-Witten：内部群只能**直积** |
| EC 含挠率 | FAIL | 轴挠率是**代数辅助场、无传播模**；PPN γ=β=1（≡GR 重述）；G_torsion/G_F = 5.4×10⁻³³ |
| Weyl / 非度量 | FAIL | 同 radion 问题（ω 远低于实验下限） |
| 共形 / 无质量隙 | FAIL | SM 有质量，破缺须额外输入 |
| **超对称** | **BOUNDARY** | 唯一绕开 CM 的既有通道；库内**未被取用（不是被否证）**，但 LHC 可判谱 0 条 |
| **离散 / 拓扑序** | **BOUNDARY** | 本库零建模；须先证低能恢复 GR+SM |

> **闸门位置很清楚**：所有"连续几何 + 4D 局域 + 非超对称"的格子全部封死；剩下两格都要靠引入新结构。

## 7. 诚实边界与红线

- **"封闭谱"是在既有定理与本层判据下的封闭，不等于自然界排除**。
- 维度扫描中的"可重整 / Derrick / Coleman-Mandula 适用域"是**教科书标准结论（标 [A] 外部）**，本层只做穷举编排与数值代入，**不声称重新证明**这些定理。

- **红线**：不把"穷举后仅剩三条缝"读作"力统一已攻破"；不把排除性判据（η 量级、M_GUT 下限）包装成正面预言；不把超对称/涌现规范/AS 三条未做的方向记为已完成。
