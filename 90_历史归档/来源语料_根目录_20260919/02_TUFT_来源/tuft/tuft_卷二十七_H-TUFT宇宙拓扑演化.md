## 0. 诚实边界声明（必读，覆盖原稿乐观框架）

H-TUFT 宇宙拓扑分支是一次**框架层重述**（把标准拓扑缺陷宇宙学换成丛语言）。作为研究方向合法；但它**不解决** TUFT 既有的经验事实，且原稿含三处须先修的**内部矛盾/逻辑倒置**。动笔前第一性事实：

### 0.1 四个 TUFT 观测窗口全部关闭（未因升维改变）
按卷十九实算审计 + 记忆 84665624（2026-09-30 更正）：EDM（CUR-01）超 ACME 16.5 量级 → ❌排除；g-2（CUR-02）偏差 ~75% → ❌排除；ringdown（CUR-03）OPEN_v3 5.74σ / OPEN_v4 尺度冲突 26 量级 → ❌窗口关；β-running（CUR-04）固定螺旋 β≡0 → ✅内部自洽([B])无预言。H-TUFT 的低能投影继承这些已关窗口（卷二十五 §0.1）。**本卷宇宙拓扑预言不改变任何已排除预言的数值**。

### 0.2 「螺旋宇宙弦是必然导出」是**条件命题**，不是必然
原稿 §1 断言：丛群 `G` 自发破缺后 `π₁(G/H)≠∅`，故「螺旋宇宙弦是理论的必然导出结果，不是人为外加假设」。
> **诚实修正**：`G` 与破缺模式 `H` 是**输入**（卷二十五 A1「G 外生」、卷二十九 §1 A1「规范群未从丛拓扑导出」）。是否产生弦**完全取决于** `π₁(G/H)` 是否非平凡——取一个 `π₁(G/H)=0` 的破缺模式则不产生弦。故正确表述是**条件命题**：**若** `G,H` 满足 `π₁(G/H)≠∅`，**则** Kibble 机制产生弦。条件（`G` 的选择）恰是未证的输入。原稿「必然导出」= 把未证输入伪装成结论。

### 0.3 内部矛盾：暴胀的定位三处不一致（须统一）
- 卷二十二 CUR-06：**挠率势**驱动暴胀（修正后平台区 `n_s≈0.96`、`r~1e-4`）；
- 本卷 §1：「宇宙暴胀对应**丛模空间**的全局弛豫相变」；

> 三者互斥：若暴胀**就是**丛相变，则不可能「相变在暴胀之后」；且「丛模空间弛豫」与卷二十二「挠率势」是两个不同的暴胀机制。**本卷未解决该矛盾**（§9.3 只作兼容性宣称）。

### 0.4 单极子问题逻辑倒置
原稿 §2 称「单极子因丛拓扑约束被抑制，不会过量产生，**规避传统单极子宇宙学灾难**」。

## 1. 范式切换：ΛCDM 拓扑空白 vs H-TUFT 丛弛豫（诚实重述）

**标准图景**（成熟领域，非本卷新发现）：ΛCDM 中暴胀由标量场驱动；拓扑缺陷宇宙学（Kibble 1976；Zurek 1985；Vilenkin–Shellard 1994）给出「宇宙相变 → 拓扑缺陷」的普适机制；宇宙弦是**条件产生**的（取决于破缺模式 `π₁(G/H)`）。

**H-TUFT 重述**：把序参量从标量场换成**丛截面 `Ψ`**，把相变换成「丛模空间弛豫」。这是**表述层**升级。
- 高温（普朗克时代）：丛对称相，纤维螺旋取向全局对齐；
- 降温：全局取向无法跨宇宙同步弛豫，不同哈勃补丁取不同拓扑真空；
- 补丁边界形成**螺旋宇宙弦**，弦芯囚禁非零 `Q_hel`。

> 诚实注记：①「弦是必然导出」为条件命题（§0.2）；②「丛相变=暴胀」与 §9.3「相变在暴胀后」矛盾（§0.3）。本节的定位须先按 §0.3 统一，否则后续动力学无确定背景。

## 3. 螺旋宇宙弦的丛几何

弦沿 `z` 轴，弦芯径向尺度 `~l_Pl`。弦芯丛截面 ansatz：
`Ψ(ρ,φ,z) = v·exp(i Q_hel φ + i k_s z)`，`Q_hel`=环绕拓扑荷，`k_s`=轴向螺旋波数（螺距）。

有效张力（**ansatz**）：
`T_s = T_0 + τ_corr·Q_hel²`，`T_0`=经典弦张力，`τ_corr`=挠率自耦合修正（系数未导出）。

> 诚实注记：①原稿该行公式排版损坏（`\mathcal{T}*s = \mathcal{T}*0 + \tau*\text{corr}, Q*\text{hel}^2`），已清理为上式；②`τ_corr` **无第一性推导**，「不同 `Q_hel` 形成多族螺旋弦」是 ansatz 的**直接后果**，非导出；③弦芯内挠率集中、芯外指数衰减——是**设定**，未从 §5 世界面作用量导出。低能（`Q_hel→0`）应退回普通宇宙弦（consistency check，§5）。

## 4. Kibble 机制在丛上的推广

标准 Kibble（诚实重述，非新机制）：相变时刻 `t_c`、哈勃半径 `H_c^{-1}`；每个哈勃补丁独立随机选取真空相位；补丁边界相位不连续 → 诞生弦；初始弦密度由同伦类概率测度定；相变后网络交叉/重联/环衰变。

**H-TUFT 的「推广」仅在于**：序参量换成丛截面、随机变量换成 `Q_hel` 真空相位。

> 诚实注记（关键）：原稿「重联时**总螺旋拓扑荷守恒**、重联后螺距重新分配」是**额外假设**（普通 Nambu-Goto 弦无此约束），**未从作用量导出**。若真守恒，它是个可证伪的结构预言；但本卷只作断言，未给守恒流/Noether 推导。

## 5. 弦动力学：世界面作用量与运动方程

世界面参数化 `X(σ,τ)`，作用量：
`S_string = -∫ d²σ T_s(Q_hel) √(-det h_ab) + S_torsion`，`h_ab`=诱导度规，`S_torsion`=弦芯挠率耦合项（**未导出**）。

变分 EOM（**schematic**）：
`Ẍ^μ − X''^μ + Γ^μ_{αβ}(Ẋ^α Ẋ^β − X'^α X'^β) + F^μ_τ = 0`，`F^μ_τ`=挠率额外力（H-TUFT 新增项）。

> 诚实注记：①`F^μ_τ` 是**ansatz**（未从 `S_torsion` 变分得到，因 `S_torsion` 本身未写具体形式）；②`Q_hel→0 ⇒ F^μ_τ→0` 退回 Nambu-Goto 是**必要条件**而非充分（形式满足退化不等于物理正确）；③原稿 EOM 中 `\ddot X^μ − X''^μ` 的指标/坐标约定未明确（应为世界面 (τ,σ) 二阶导），已按标准 Nambu-Goto 形清理。

## 6. 拓扑缺陷的随机引力波背景（SGWB）

弦网络振荡/环衰变产生 SGWB。原稿唯象式：
`Ω_GW(f) = A_gw (f/f_*)^{n_gw(Q_hel)}`，`n_gw = 0.5 + α_t·Q_hel`。

> 诚实注记（承 §0.5）：①这是**唯象幂律**，非弦网络模拟输出；真实弦 SGWB 谱须由 BOS/VDOS 类模拟给出「上升-峰值-截断」形状；②`α_t` 自由、`A_gw` 人为 → 谱指数偏移与幅度**均不可预言**（§11 [A][B]）；③**手征偏振**在标准 Nambu-Goto 弦中**不产生**，原稿未给机制；④「nanoHz PTA 贡献 / LISA 次级峰 / 手征偏振」三条预言**均为定性**，无法与现有 PTA 数据（如 NANOGrav 15yr）做定量拟合——因缺 `Gμ` 与谱形。

# H-TUFT 螺旋宇宙弦 SGWB（脚手架：幂律唯象式，谱指数由自由 alpha_t 决定）
def omega_gw_phenom(f, f_star, A_gw, Q_hel, alpha_t):
