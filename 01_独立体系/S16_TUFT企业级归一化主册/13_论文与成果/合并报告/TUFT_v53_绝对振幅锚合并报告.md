- **toy（E489 上界处方）**：壁=理想镜 |r_wall|=1、垒=无耗阶跃、垒顶满通量入射。单程透射幅 |t_B|=√(1−|R_B|²)；双程场幅 = |t_B|² = 1−|R_B|²。物理 = 入射透射入腔 |t_B| → 壁反射 |r_wall|=1 → 再透射外出 |t_B|；出腔回波幅 = |t_B|²|r_wall| = 1−|R_B|² = **0.4697**（E431/E489 上界）。
- **strict（双程穿垒，从壁反射核 R=b/a 出发）**：
  - (a) 垒透射：单程功率 |t_B|² = 1−|R_B|² = 0.469746；双程 |T_B|² = (1−R)² = 0.220661。
  - (b) 壁反射核 R=b/a：TUFT 壁 |r_wall|²=1（D25/E488，Γ=0 机器精度）；近壁 s^β Frobenius 有界支 β=1.263763；反射相位 = 腔共振 round-trip。
  - (c) 垒顶有效通量：GR 频隧穿区 |R_B|²=0.530；TUFT 频垒顶之上更透；垒物理双程场幅 ε_barrier = 1−|R_B|² = 0.469746（与 toy 同阶）。

## 3. 6.28× 来源（垒透射物理本身不致 6.28×）

- toy prompt loudness L = **11.993** SNR·Gpc（E431 上界，|R_B|=0.729 反射幅作回波幅）。
- E444 严格真实-PSD 锚 = **1.91** SNR·Gpc（双程穿垒 + 真实 PSD）。
- 比值 = 11.993 / 1.91 = **6.2791 ≈ 6.28**。
- 分解：toy 用垒反射幅 |R_B|=0.729 作回波幅（乐观上界）；strict 用双程穿垒（垒→壁→垒）+ 真实 PSD。
- **结论：因 TUFT 频垒顶之上更透，垒透射物理本身不致 6.28×；6.28× 残余 = 源激发能绝对标度（e/f_π 升层项，OPEN）。**
