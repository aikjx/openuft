## 01. 核心结论

> **{v=c} 与 {ωr=c} 两条约束联立，在数学上唯一允许的解是轴向速度 u ≡ 0，即螺旋退化为平面圆、挠率 τ ≡ 0。**

这不是参数取值问题，而是**由求导直接推出的结构性后果**：

```
约束 I   v² = (rω)² + u²    ⇒  d/dt:  2(rω)(ṙω + rω̇) + 2u u̇ = 0
约束 II  ωr = c             ⇒  d/dt:  ṙω + rω̇ = 0
----------------------------------------------------------
代入 I： 2(rω)·0 + 2u u̇ = 0   ⇒   u u̇ = 0
  情形 a) u ≡ 0          → 合法，与 II 相容
  情形 b) u̇ = 0, u ≠ 0   → 此时 v² = c² + u² > c²，违反约束 I
⇒ 唯一解 u ≡ 0  ⇒  b = u/ω = 0  ⇒  τ = b/(a²+b²) = 0
```

**且 r(t) 任意时变都不救场**：只要 ω(t) = c/r(t)，则 v² = c² + u² 与 r 完全无关，v 恒 ≥ c，等号仅当 u = 0。
