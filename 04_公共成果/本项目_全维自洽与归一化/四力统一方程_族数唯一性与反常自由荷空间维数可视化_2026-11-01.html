§1 · 反常自由荷空间到底几维

四条反常（y_i = d_i·q_i）：[SU3]²Y = y0+y1+y2 ; [SU2]²Y = y0+y3 ; grav = Σy ; U(1)³ = Σ y³/d² 前三条线性 ⇒ RREF 秩 3 ⇒ 零空间 3 维（不是 1） 三次条件在该零空间上精确分解：F = (b+c)·Q/12 ⇒ 解集 = 一个平面 {b+c=0} ∪ 一个二次曲面 {Q=0} ⇒ 至少 2 维
平面分支显式：q = (0, −a, a, 0, b, −b)，例如 a=1,b=0 → (0,−1,1,0,0,0)，反常自由。

§2 · 「1 维」的真身：不是反常、也不是 Yukawa，而是「5 表示」

6 表示（带 ν^c）：线性反常三条 秩3 → 3 维；叠 Yukawa 后 秩 4 → 2 维（Y 与 B−L 并存） 5 表示（无 ν^c）：线性三条 秩3 → 2 维；叠 Yukawa（只剩 3 条）后 秩 4 → 1 维 = span(Y)
Yukawa 表面给两条相容条件，但 μ 项把二者合成 2X₀+X₁+X₂=0，恰是 [SU3]²Y 那条反常 ⇒ 只有一条独立。⇒ 本库长期记的「r302 用 5 / r296,r306 用 6」的不一致，根源就是 1 维 vs 2 维。

§3 · 主约束与单扭转唯一性

n_i = y_i + k_i·T = N ，对 i 求和并用 grav 反常 Σy_i = 0 ⇒ T·K = 6N （K = Σk_i ∈ {0..6}） ⇒ y_i = N − k_i·T 被 k 唯一确定 ⇒ 只需逐个模式查反常 K=3: y∈{N,−N} → y0+y1+y2 ∈ {±3N,±N} ≠ 0 ⇒ 排除 K=2: y∈{N,−2N} → y0+y3 ∈ {2N,−N,−4N} ≠ 0 ⇒ 排除 K=1: y∈{N,−5N} → y0+y3 ∈ {2N,−4N,−10N} ≠ 0 ⇒ 排除 K=6: y≡0 ⇒ 纯复制（唯一）
机检 N=1..12：总存活恒为 1，非平凡存活恒为 0。

§4 · 反例：两条扭转列下唯一性失效

n_i = M·d_iY_i + k¹_i·T₁ + k²_i·T₂ （Yukawa + 反常自由全合规） 取 M=3, T₁=6, T₂=3 y = M·d_iY_i = ['3', '-6', '3', '-3', '3', '0'] n = [3, 3, 3, 3, 3, 3] ⇒ 全等于 3
⇒ 承重前提不是「反常自由」，而是「扭转自由度只有一个群元」。r330 的判词范围需下调。
