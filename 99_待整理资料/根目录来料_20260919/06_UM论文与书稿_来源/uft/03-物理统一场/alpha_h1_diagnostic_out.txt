P1 收口诊断：H1 = alpha 数值缺口与方向矛盾（高精度，不声称突破）

[1] 拓扑 alpha_geom = Phi_T^2 = 2^-7
    alpha_geom = 7.812500000000e-03  (= 1/128.000000)
    alpha_exp  = 7.297352569300e-03  (= 1/137.035999)
    alpha_exp / alpha_geom = 0.934061  (缺口 -6.594%, 实验值比拓扑值大)
    alpha_geom / alpha_exp = 1.070594  (拓扑值比实验小 -7.059%)
    [残差] |alpha_exp/alpha_geom - 137.036/128| = 0.136533
    => 拓扑值 1/128 比实验 1/137 大 -6.594%, 是 7% 量级硬缺口；
       方向：拓扑(1/128) > 实验(1/137)，即框架给的耦合偏'大'。

[2] 单圈 QED 跑动方向检验（是否可能把 1/128 -> 1/137）
    从 alpha(0)=1/128 单圈跑到 Z 标度: alpha(M_Z) = 9.262157229443e-03 (= 1/107.966209)
    真实实验 alpha(M_Z)_phys = 1/128.943  (约 7.76e-3)
    而若用 alpha(0)=alpha_exp=1/137.036 单圈跑: alpha(M_Z) = 8.546847271980e-03 (= 1/117.002208)
    方向判定：单圈跑动使 alpha 朝 1/139.2 (更小耦合) 走，
             而实验 1/137.036 比 1/128 朝 更大耦合 走 —— 方向相反，
             故单圈(或任何仅正 beta 的跑动) 无法把 1/128 修正到 1/137。
    [残差] |alpha(M_Z from 1/128) - 1/139.236| = 0.00208011

[3] 旋转支标定点 u* = arctan(alpha_exp)
    u*            = 7.297223042136e-03 rad
    kappa(u*)     = 2.589536129171e+12
    tau(u*)       = 1.889675812550e+10
    tau/kappa     = 7.297352569300e-03  vs alpha_exp = 7.297352569300e-03
    sqrt(k^2+t^2) = 2.589605076406e+12  vs Qtop     = 2.589605076406e+12
    [残差] |tau/kappa - alpha_exp| = 9.58807e-94
    [残差] |sqrt(k^2+t^2) - Qtop|  = 5.39761e-79
    => '选点' u* 能令 alpha_def=实验值，且自动留在 Qtop 壳上 (残差~0)。
       但这是 选择 u* 的结果，不是从拓扑 独立 推出的 alpha；
       拓扑只给 Qtop 壳，不给 u* 的选取规则 —— 此即 H1 的本质：
       框架能 容纳 实验 alpha，但 不能 从第一性原理 预测 它。

  框架状态: 能 容纳(选点) 实验 alpha, 但 不能 从拓扑预测 alpha。
  这是框架当前最硬的诚实边界, 非粉饰可消除。
