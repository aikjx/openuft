## 三、定理 K：完全交的牛顿系数闭式（已证）

> `X_{d_1..d_r} ⊂ CP^N`，`n = N − r`：
> **`a_m = Σ_{S⊆[r]} (−1)^{|S|} C(N − d_S, N − m)`**，`d_S = Σ_{i∈S} d_i`（广义二项式）。

**三行证明**　① Koszul 复形 `0 → O(k−Σd) → … → O(k) → O_X(k) → 0`；
② χ 加性 + `χ(O(k)) = C(N+k, N)`；③ `Δ^m C(x+k,N)|_{k=0} = C(x, N−m)`。

**承重读数**

| 条目 | 判据 | 读数 |
|---|---|---|
| `A01` | 两条独立路径（td 级数 / Koszul 闭式）对拍 | **239 组**失配 **0** |
| `A02` | `r=1` 退化回 r366 定理 H | 30 组失配 **0** |
| `A05` | `a_n = Π d_i`（混合差分，可解析证明） | 239 组违例 **0** |
| `A06` | CY 自检 `a_0 = 1+(−1)^n` | 55 组违例 **0** |
| `A03`+`CTL8` | K3 两种嵌入 `a_0` 同为 2、但 `a_1` 为 2 vs 3 | ⇒ `A03` **不是恒等式** |

**判词**：**定理 K 成立**，且又一次证明 r339/r346/r358 绕 Todd 类算 χ 的路径是**充分不必要**的 ——
Koszul + χ 加性三行就够，而且第 ①②步不需要消灭定理 ⇒ **跨 CY 与一般型同样成立**。
这是本卷唯一可以写「已证」的结论。

## 六、对照构造与判别力：为什么 `C01` 不是空话

一个 100% 通过的谓词判别力为 0。若「类数恒 1」对任何整值多项式都成立，它就是句废话。
`C04` + `CTL9` 给出反证构造：

```
Q(m) = C(m,2)/2      b = [0, 0, 1/2]   D = 2   β = [0, 0, 1]
直算解集 (m=0..7)     = {0, 1, 4, 5}
mod 4 剩余类          = {0, 1}  ⇒ 类数 2
周期                  = 4 ≠ D = 2
```

⇒ **类数可以是 2、周期可以不等于 `D`**。`C01` 的「几何类恒为 1」因此**有判别力**。
机理差异（`C03`）：几何类的 `β_n = D·a_n = D·d ≡ 0 (mod D)` ⇒ 模 `D` 后最高次项消失；
一般整值多项式没有这条约束。

> 这条同时是 r366「判别力必须两侧都测」纪律的落实：只测几何类（全绿）不叫测过，
> 必须找一个**非几何构造**看它会不会变红。

## 七、方法换挡与递推顺序（本卷踩出的自伤）

- **整数化 + 有限差分递推**：`β_i = D·b_i ∈ Z`；`g_j(m+1) = g_j(m) + g_{j+1}(m)`，`g_{n+1} ≡ 0`，
  全程 `mod D` ⇒ 代价从 `O(D·n!)` 降到 **`O(D)`**。`CTL3` 与 Fraction 直算在 224 个点上不一致 **0**。
- ★ **更新顺序**：右端 `g[j+1]` 必须取**旧值** ⇒ 循环**必须 j 递增**。
  j 递减会用到已更新的 `g[j+1]`，算出另一个多项式。
  **阴险之处**：在几何类上这个错法**巧合地不出错**（4232 点 0 失配），
  只在 `C(m,2)/2` 上暴露（正确 `{0,1,4,5}` vs 错误 `{0,3,4,7}`）。
  ⇒ 印证纪律：**对照类必须换一个，同族对照抓不到同族的错。**

## 十二、自审三处（本卷踩出）

### ① `GRID_A` 的 `r ≠ len(ds)` —— 家族自伤第八卷

网格生成时 `r ≥ 4` 的分支沿用了 `r = 3` 的三元组 ⇒ 网格记的 `r` 与 `len(ds)` 不等。
后果：`pathK(...)[n]` 里的 `n` 取自网格（`N − r`），而路径内部用的是 `N − len(ds)` ⇒ **取错下标**。

诊断价值最高的一点：**`A01`（两路径对拍）在这批数据上是 0 失配**。
对拍抓不到它，因为两条路径内部都错在同一个方向上。
首跑暴露它的是 **`A05`（68 违例）与 `A06`（13 违例）** —— 这两条的期望值来自**第三条路径**
（混合差分恒等式 / CY 的 `1+(−1)^n`），不在对拍里。

修法：`r ≥ 4` 用 `product(range(1,3), repeat=r)`（网格 256 → 239 组，`G09` 门限 200 仍满足），
并新增 `G20` 常驻。

> 家族序列 `r327 → r331 → r335 → r339 → r346 → r358 → r366 → r367`，八卷落点**全是守错门**。
> 沉淀：**凡「从容器取下标」处，下标与容器必须在同一行代码里同时确定；
> 凡对拍全绿的卷，必须另有至少一条期望值来自第三条独立路径的条目。**

### ② 递推更新顺序（见 §七）

j 递减用新值。几何类上巧合不出错 ⇒ 同族对照抓不到，靠 `C(m,2)/2` 才暴露。

### ③ 探查 4 的「9 条假违例」

判「`c` 为半整数」时用了循环变量 `q` 而非既约分母（`F(0,2)` 的既约分母是 **1**）
⇒ 把整数陪集误判成半整数。改用 `F(p,q).denominator` 后 1430 组 **0 违例**。
教训：**判「既约」必须问既约之后的对象。**
