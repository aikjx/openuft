# ROOT V118｜版本修复与研究增量

1. **修复 V117 地球密度近似**：均匀球表面第五力由 0.97749% 改为 2026 地球解析密度基准 0.59544%，五层球参考 0.59313%。误差主要来自物理源分布，而非单一算术错误。
2. **稳定数值形式**：计算 e^{-R/ℓ} Φ(R/ℓ) 避免大 x 的双曲函数溢出；使用高精度积分验证结果。
3. **三高度严格唯一性**：证明表观 GM 差值比对 1/ℓ 全局严格单调，排除数值根的偶然性。
4. **源参数独立微分条件**：消掉 GM、球形密度、第五力强度与作用程，得到 K″²−K‴K′−K′²/r²=0。
5. **第四高度留出验收**：一标量自洽闭合；两标量合成模型单尺度伪装的留出残差约 −1.162936×10⁻⁴。
6. **轨道频率审计**：从势能求近圆轨道径向/方位频率，明确和真实地球 J2、潮汐、GR、拖曳不相同。
7. **误差传播**：独立合成高斯噪声 2500 次，给出 ℓ 和第四高度留出残差分布，不冒充实际轨道数据。
8. **软件回归**：新增 215 项 pytest，V117 原始归档的 59 项 unittest；Chromium 11 项真实 UI 检查。
9. **工程修复**：浏览器范围控件输入数值格式和极小作用程求根区间造成的测试问题已处理。
10. **科学状态**：原版 396 项台账逐字节保留，全部五大根本 OPEN 未擅自变更。
