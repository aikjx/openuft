## 💡 为什么是2不是1/2？关键在于"定义基准"！

### 📊 **两个不同的比值**

```
【比值1】平均投影比例 = 2π/4π = 1/2
↑ 这是"有效区域占总区域的比例"（缩小）

【比值2】几何转换因子 = 4π/2π = 2  
↑ 这是"从摊薄密度到聚焦密度的倍数"（放大）
```

### 🍕 **披萨类比（最直观）**

想象一个圆形披萨：

1. **三维场 I₃ᴅ**：料均匀铺在整个披萨上（4π面积）
   - 每单位面积的料密度 = 总量/4π

2. **一维力 F**：把所有的料都集中到半个披萨上（2π面积）
   - 每单位面积的料密度 = 总量/2π

3. **密度变化**：
   ```
   聚焦密度 / 摊薄密度 = (总量/2π) / (总量/4π) = 4π/2π = 2
   ```

### ⚡ **物理本质**

```
I₃ᴅ = Z·m₁m₂/(r²c)  ← 基于4π立体角定义（摊薄状态）
                        "每sr的平均强度"

F = 2Z/c·m₁m₂/r²     ← 基于2π有效角观测（聚焦状态）
                        "实际测到的单方向强度"

转换：从"4π上的平均"到"2π上的实际" → 乘以 4π/2π = 2
```

### 🔬 **数学严格性**

更新后的可视化现在清晰展示：

✅ **4π（摊薄态）** - 三维场定义基准  
✅ **2π（聚焦态）** - 一维力有效贡献  
✅ **因子2 = 4π÷2π** - 从摊薄到聚焦的密度倍增  
✅ **投影比0.5 = 2π÷4π** - 有效区域占比

### 🎓 **终极理解**

**不是"3D比1D大2倍，所以除以2"**  
**而是"要把4π的料集中到2π上，密度要乘以2"**

这就是为什么公式里是 **2Z/c** 而不是 **Z/(2c)**！
