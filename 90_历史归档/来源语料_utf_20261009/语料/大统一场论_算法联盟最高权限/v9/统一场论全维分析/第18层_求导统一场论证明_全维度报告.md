## 三、引力-电磁微分统一（模块2）

### 3.1 核心定理

这是本层最重要的数学结果：

> **定理2（引力-电磁微分统一）**：设 $V_\mu = \partial_\mu \Psi$，则二阶导数 $\partial_\mu V_\nu$ 有唯一的对称-反对称分解：
>
> $$\partial_\mu V_\nu = \underbrace{\frac{1}{2}(\partial_\mu V_\nu + \partial_\nu V_\mu)}_{\text{对称部分}} + \underbrace{\frac{1}{2}(\partial_\mu V_\nu - \partial_\nu V_\mu)}_{\text{反对称部分}}$$
>
> - **对称部分** $\partial_{(\mu}V_{\nu)} \propto g_{\mu\nu}$ → **引力**（度规动力学）
> - **反对称部分** $\partial_{[\mu}V_{\nu]} = F_{\mu\nu}$ → **电磁**（场强）

### 3.2 证明

**第一步（代数恒等式）**：任意二阶张量 $T_{\mu\nu}$ 可唯一分解为对称+反对称：

$$T_{\mu\nu} = T_{(\mu\nu)} + T_{[\mu\nu]}, \quad T_{(\mu\nu)} = \frac{1}{2}(T_{\mu\nu}+T_{\nu\mu}), \quad T_{[\mu\nu]} = \frac{1}{2}(T_{\mu\nu}-T_{\nu\mu})$$

这是线性代数基本定理，对 $T_{\mu\nu} = \partial_\mu V_\nu$ 直接应用。

**第二步（反对称=电磁）**：

$$F_{\mu\nu} = \partial_\mu V_\nu - \partial_\nu V_\mu = \partial_\mu\partial_\nu \Psi - \partial_\nu\partial_\mu \Psi$$

对纯标量 $\Psi$，混合偏导可交换，故 $F_{\mu\nu}=0$。但当 $V_\mu$ 是**规范联络**（即 $V_\mu = A_\mu$，不是纯梯度）时，$F_{\mu\nu} = \partial_\mu A_\nu - \partial_\nu A_\mu$ 正是麦克斯韦场强。在主场框架中，$V_\mu = \partial_\mu \Psi$ 的**非可积部分**（或非阿贝尔协变导数的对易子）产生电磁场强。

**第三步（对称=引力）**：

弱场展开 $g_{\mu\nu} = \eta_{\mu\nu} + h_{\mu\nu}$，其中 $|h_{\mu\nu}| \ll 1$。线性化爱因斯坦方程中：

$$h_{\mu\nu} \propto \partial_{(\mu} V_{\nu)} - \frac{1}{2}\eta_{\mu\nu}\partial^\lambda V_\lambda$$

这正是对称二阶导数的迹调整形式。度规的涨落由 $V_\mu$ 的对称导数确定。

**第四步（同源验证）**：引力和电磁都服从 $r^{-2}$ 定律——

$$F_{\text{grav}} = \frac{Gm_1m_2}{r^2}, \qquad F_{\text{em}} = \frac{k_e q_1 q_2}{r^2}$$

两者都是二阶导数的 $1/r^2$ 行为（对 $\Psi \sim 1/r$ 求两次导）。数值验证：

| 量 | 数值 |
|---|---|
| 质子-质子引力 $F_g$ (1 fm) | $1.87\times10^{-34}$ N |
| 质子-质子电磁 $F_e$ (1 fm) | $2.31\times10^2$ N |
| $F_e/F_g$ | $1.24\times10^{36}$ |

强度差 $10^{36}$ 倍不影响**结构统一**——统一要求的是同一导数结构，不是等强度。耦合系数的差异正是对称/反对称分量各自的耦合常数不同。

> **结论**：引力与电磁是同一个二阶导数 $\partial_\mu V_\nu$ 的两个面。这不是类比，是代数恒等式。$\square$

## 四、非阿贝尔扩展：弱力与强力（模块3）

### 4.1 协变导数

将主场提升为李代数值 $\Psi = \Psi^a T^a$，定义协变导数：

$$D_\mu = \partial_\mu - i g V_\mu^a T^a$$

场强为协变导数的对易子：

$$F^a_{\mu\nu} = \frac{i}{g}[D_\mu, D_\nu] = \partial_\mu V^a_\nu - \partial_\nu V^a_\mu + g f^{abc} V^b_\mu V^c_\nu$$

### 4.2 导数阶数分析

| 项 | 表达式 | 导数阶数 | 对应力 |
|---|---|---|---|
| 线性项 | $\partial_\mu V^a_\nu - \partial_\nu V^a_\mu$ | 二阶导数 | 全部（阿贝尔部分） |
| 二次项 | $g f^{abc} V^b_\mu V^c_\nu$ | 一阶导数乘积 | 非阿贝尔（弱/强） |

- **U(1)**：$f^{abc}=0$ → 纯二阶导数（线性）→ 电磁
- **SU(2)**：$f^{abc}=\varepsilon^{abc}$ → 二阶导 + 一阶导乘积 → 弱力
- **SU(3)**：$f^{abc}$ 非零 → 渐近自由 → 强力

### 4.3 耦合跑动 = 导数方程

重整化群方程本身就是导数：

$$\frac{d\alpha_i^{-1}}{d\ln\mu} = -\frac{b_i}{2\pi}$$

这是 $\alpha_i^{-1}$ 对能量对数 $\ln\mu$ 的一阶导数。耦合常数的"跑动"由微分方程决定。

**SM 一圈 β 系数**：$b_1 = 41/10,\ b_2 = -19/6,\ b_3 = -7$

**MSSM 一圈 β 系数**：$b_1 = 33/5,\ b_2 = 1,\ b_3 = -3$
