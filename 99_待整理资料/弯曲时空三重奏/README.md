# 弯曲时空三重奏

> 将螺旋三重奏（曲率、挠率、运动生成元）推广到弯曲时空，研究非平直背景下的螺旋几何与统一场论。

## 问题定义

openuft S01 螺旋三重奏与谱几何建立在平直空间的 Frenet-Serret 框架上。弯曲时空三重奏的核心问题：**如何将螺旋几何自洽地推广到一般弯曲流形，并与广义相对论兼容？**

**关键数学**：
- 弯曲时空的 Frenet-Serret 公式需含联络修正
- 曲率 $\kappa$ 与挠率 $\tau$ 的协变定义
- 螺旋参数在弯曲时空中的推广
- 与 Einstein-Cartan 挠率的关系
