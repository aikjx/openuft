### A.1 一维矩形势垒的隧道贯穿概率推导

考虑一维矩形势垒，其势能分布为：

V(x) = 0, x < 0 或 x > a
V(x) = V₀, 0 ≤ x ≤ a

其中，V₀为势垒高度，a为势垒宽度。我们需要求解薛定谔方程：

-ħ²/(2m)d²ψ/dx² + V(x)ψ = Eψ

对于E < V₀的情况，我们将空间分为三个区域：

**区域1（x < 0）**：V = 0，薛定谔方程的解为：

ψ₁(x) = Aexp(ik₁x) + Bexp(-ik₁x)

其中，k₁ = √(2mE)/ħ，A为入射波振幅，B为反射波振幅。

**区域2（0 ≤ x ≤ a）**：V = V₀，薛定谔方程的解为：

ψ₂(x) = Cexp(κx) + Dexp(-κx)

其中，κ = √(2m(V₀-E))/ħ，C和D为常数。

**区域3（x > a）**：V = 0，薛定谔方程的解为：

ψ₃(x) = Fexp(ik₁x)

其中，F为透射波振幅（没有反射波，因为x > a区域没有边界）。

利用波函数及其导数在x = 0和x = a处的连续性条件，我们可以求解常数之间的关系。

在x = 0处：

ψ₁(0) = ψ₂(0) ⇒ A + B = C + D

dψ₁/dx(0) = dψ₂/dx(0) ⇒ ik₁(A - B) = κ(C - D)

在x = a处：

ψ₂(a) = ψ₃(a) ⇒ Cexp(κa) + Dexp(-κa) = Fexp(ik₁a)

dψ₂/dx(a) = dψ₃/dx(a) ⇒ κ(Cexp(κa) - Dexp(-κa)) = ik₁Fexp(ik₁a)

解这些方程，我们可以得到透射系数T = |F|²/|A|²：

T = 1 / [1 + (V₀²/4E(V₀-E))sin²(κa)]

对于宽势垒和能量远小于势垒高度的情况，sin²(κa) ≈ 1，透射系数近似为：

T ≈ 16E(V₀-E)/V₀²exp(-2κa)

如果E << V₀，进一步近似为：

T ≈ 16E/V₀exp(-2κa)

这一近似表达式表明，透射系数随着势垒宽度的增加而指数衰减，这是量子隧道效应的重要特征。
