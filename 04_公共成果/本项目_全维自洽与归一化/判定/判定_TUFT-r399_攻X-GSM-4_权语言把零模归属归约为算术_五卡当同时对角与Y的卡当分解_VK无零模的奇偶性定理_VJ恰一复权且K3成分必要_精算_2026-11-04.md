## 一、一句话判决

> **`Y` 不是神秘矩阵，它在卡当基上是 `Y = −(1/3)(H₁+H₂+H₃) + (1/2)(H₄−H₅)`（逐元素相等）；给定这一条，「零模落在 `V_J`」就不再是解出来的读数，而是一条奇偶性 + 一次枚举。**

> - 5 个 Cartan `H_i = Σ_{2i,2i+1}` 在 16 维手征块上**同时对角**，16×5 个对角值**全部是 `±1/2`**（非对角非零 0 处）（A1）；
> - 16 个权向量两两不同 ⇒ 确是权基；`V_J` / `V_K` 在权基上就是两条**符号约束**：`ε₄+ε₅ = 0` 与 `ε₄−ε₅ = 0`，各 8 个权 ⇒ 8 复 = 16 实（A2）；
> - **`Y` 的卡当分解是矩阵等式**：`Y = −(1/3)(H₁+H₂+H₃) + (1/2)(H₄−H₅)`，逐元素相等（A3）；
> - `J₃ = H₄+H₅`、`K₃ = H₄−H₅`，正是 `su(2)_J` / `su(2)_K` 的第 3 个生成元，逐元素相等（A4）；
> - **定理 W(i)**：在 `V_K` 上 `K₃ ≡ 0`，于是 `y = −s/3`（`s = ε₁+ε₂+ε₃`）；而三个 `±1/2` 之和**恒为 `1/2` 的奇数倍**（`2s = ±1, ±3`）⇒ `s ≠ 0` ⇒ **`ker(Y|V_K) = 0` 是定理**（A6）；
> - **定理 W(ii)**：在 `V_J` 上 `J₃ = 0 ⇒ ε₅ = −ε₄`，于是 `y = −s/3 + ε₄`；零化 ⟺ `s = 3ε₄` ⟺ **`ε₁=ε₂=ε₃=ε₄`** ⇒ **恰 1 个复权**（2 维实 = `ν^c`）（A7）；
> - 这 2 维实空间就是 r398 的 `ker(Y|V_J)`（用秩验证同一空间，不是「维数都等于 2」）（A8）；
> - **`K3` 成分是零模存在的必要条件**：去掉它（`Y = −(1/3)A`）⇒ 两边都退化成 `s = 0` ⇒ **零模完全消失**（K1）；
> - **零模位置跟着「`Y` 含哪一个 `su(2)` 的 Cartan」走**：把 `K3` 换成 `J3` ⇒ 零模整体搬到 `V_K`，**个数不变**（K2）；
> - **边界**：`Y → −Y` 零模数不变（仍 `(2, 0)`）⇒ 任何「数零模」的判据都**没有**定符号的能力（A9）。

★ 本卷**不产生**新物理预言。它做的是把 r398 §十四 第 3 条那条「A6 只给读数、不解释为什么 `ν^c` 落在 `V_J`」推到底 —— **能推的推完了，剩下的正好是一条输入边界**（见 §十四 第 1 条）。

## 三、权基：为什么可以「不算本征值」（A1 / A2）

`so(10)` 的 Cartan 是 `H_i = Σ_{2i,2i+1}`（`i = 0..4`），恰好 5 个 —— 与 `Γ` 的 5 个张量积因子一一对应。本卷**验证**（不是假设）它们在 16 维手征块上同时对角：

- 非对角非零 **0 处**；Re 对角 **全 0**；16×5 个对角值**全部** `∈ {±1/2}`。

于是「解 16×16 本征值」退化成「读 5 个符号」。这一步的代价是必须**真验**：`Σ_ab = (1/4)[Γ_a,Γ_b]` 是不是对角，完全取决于 `Γ` 的张量积构造，因子写错就立刻露（非对角非零数不会为 0）。

★★ **翻译表**：`V_J = ker(su(2)_J)` 原本是「解 3 个 32×32 生成元的零空间」，在权基上它就是 `ε₄ + ε₅ = 0`；`V_K` 是 `ε₄ − ε₅ = 0`。两边维数必须对上（8 复 = 16 实），这是权语言与矩阵语言的**字典检验**。

★ 顺带一个本卷用得上的事实：本块 `#(ε = −1/2)` 的取值集合是 **`{0, 2, 4}`**（恒为**偶数**）。这一条在 §八 决定「镜像权住在哪一块」。

## 四、`Y` 的卡当分解（A3 / A4）

| 量 | 读数 |

| 矩阵等式 | `Y == −(1/3)(H₁+H₂+H₃) + (1/2)(H₄−H₅)` 逐元素 **True** |

★★★ 这一条是本卷的**全部内容**：`Y` 就是「`so(6)` 的 `U(1)_A` 取 `−1/3`」加上「`su(2)_K` 的 Cartan 取 `+1/2`」。

★★ 为什么必须**逐元素**而不是「迹相等 / 谱相等」：若把 `(H₄+H₅)` 写成 `(H₄−H₅)`，两者的迹都是 0、谱都是 `{±1}` 各半 —— **弱检验抓不到**。只有逐元素才分得开。

## 五、定理 W(i)：`V_K` 上没有零模是**奇偶性**（A6）

在 `V_K` 上 `K₃ ≡ 0`（因为它就是 `su(2)_K` 的核），于是

`y = −(1/3)(ε₁+ε₂+ε₃) =: −s/3`。

三个 `±1/2` 之和 `s` 只能是 `±1/2` 或 `±3/2` —— 等价地「`2s` 恒为奇数」。零模要求 `s = 0`，**不可能**。

读数：`V_K` 的 8 个态 `y` 取值集 `{−1/2, 1/6}`，全非零；`y = −s/3` 逐项成立 True；`2s` 恒为奇数 True。

★★★ 这个论证**不依赖任何矩阵**：它是一条整数奇偶性。所以 `ker(Y|V_K) = 0` 是**定理**，不是读数 —— 这是本卷最硬的一条。

## 六、定理 W(ii)：`V_J` 上恰 1 个复权（A7 / A8）

在 `V_J` 上 `J₃ = 0 ⇒ ε₅ = −ε₄`，于是 `K₃ = H₄−H₅` 在该半边上等于 `2ε₄`，

`y = −s/3 + ε₄`。

零化 ⟺ `s = 3ε₄`。由 `s ∈ {±1/2, ±3/2}`、`3ε₄ ∈ {±3/2}` ⇒ 必有 `ε₄ = ±1/2` 且 `s = 3ε₄` ⇒ **`ε₁ = ε₂ = ε₃ = ε₄`**，权向量被完全钉死成 `(±1/2, ±1/2, ±1/2, ±1/2, ∓1/2)`。

读数：`V_J` 的 8 个态里**零模权 1 个**；`y = −s/3 + ε₄` 逐项成立 True；条件 `ε₁=..=ε₄` 且 `ε₅=−ε₄` True；**镜像权不在本块** True。

★★★ **`2 维实 = 1 维复` 是 realify 的倍增，不是「两个权」**（本卷 E02 号自伤：我第一版写「恰 2 个权」，把「一个复权态 = 一对实向量 `e_k`、`i·e_k`」错当成了「两个不同的权」）。A8 用秩验证：`e_k` 与 `i·e_k` 都在 `V_J` 内、都在 `ker(Y|V_J)` 内，且叠上去秩不长（仍 16）⇒ 与 r398 的 2 维零空间**是同一空间**。

★ 镜像权 `−w` 为什么不在同一块：它的 `#(−1/2)` 是 `5 − 4 = 1`（奇数），而本块恒为偶数 ⇒ 它住在 `16bar` 里。

★★★ 这一步顺带把 r398 A8 的「`16` 与 `16bar` 不等价」接上了：**零模在两块各有一个，权重互为相反数** ⇒ 两块 `y` 谱整体取反。

## 七、`y` 谱：与 r398 的谱**逐项取反**（A5）

权路径读数：`{+1:1, +1/6:6, −2/3:3, +1/3:3, −1/2:2, 0:1}`，合计 16。

r398 公布的谱是 `{−1:1, −1/6:6, 2/3:3, −1/3:3, 1/2:2, 0:1}`。`== r398 清单 = False`、`== r398 清单取反 = True`。

★★★ 这是**约定**问题，不是物理问题，而且能定位到源头：r398 的 `y` 是用「`ker(iY∓1)` 落在哪一块」**钉**出来的（其 A8），本卷的 `y` 是「`Y` 的复本征值除以 `i`」直接读出来的 —— 两者差一个整体符号 ⇒ **本卷的 PLUS 块就是 r398 记的 `16bar`**。

★ 这个符号差**不影响任何零模数**（A9 单独证明），所以它不改变任何结论，只改变标签。**把约定当结论、或把结论当约定，都是 r397 E09 那一族错。**

## 十三、诚实边界（五条）

1. `Y = −(1/3)(H₁+H₂+H₃) + (1/2)(H₄−H₅)` 里两个系数（`−1/3` 与 `+1/2`）是**输入**（超荷嵌入），不是本卷算出来的；本卷推的是「**给定**这组系数，零模落在哪一半」，**不是**「系数为什么这样」。这是本卷唯一剩下的硬边界，且它是**输入边界**，不是计算边界；
2. 定理 W(i)/(ii) 的三条前提都可枚举：5 个 Cartan 同时对角（A1）、权值是 `±1/2`（A1）、`ε₅ = −ε₄` 来自 `J₃ = 0`（A2+A4）。三条任一不成立，结论不成立；
3. 「1 个复权 = 1 个复单态」用的是 realify 的倍增 + 秩验证（A8），不是「实维数 ÷ 2」这种算术；
4. A5 的两条路径**同源**（同一批生成元、同一套 `Γ`）：它验证的是**实现**，不是**前提** —— 不能当作「`Y` 的谱正确」的独立证据；
5. 本卷不含质量谱 / Yukawa / 混合角；也不构造 `16 → 16bar` 共轭算子。
