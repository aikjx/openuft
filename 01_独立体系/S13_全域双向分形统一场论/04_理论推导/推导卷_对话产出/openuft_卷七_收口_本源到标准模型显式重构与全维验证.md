## 一、本源作用量（收束前六卷）

取本源单群 $G_{\text{本源}}=SO(10)$（卷三），场内容含旋量 $\mathbf{16}$、规范场 $A_\mu$、标量 Higgs 多重态。本源作用量（规范不变、最简可重整，奥卡姆）：

$$S_{\text{本源}} = \int d^4x\sqrt{-g}\Big[\underbrace{\tfrac14 F^a_{\mu\nu}F^{a\mu\nu}}_{\text{规范动能}} + \underbrace{i\bar\psi\gamma^\mu D_\mu\psi}_{\text{旋量动能}} + \underbrace{(D_\mu H)^\dagger(D^\mu H)}_{\text{Higgs 动能}} - \underbrace{V(H,\psi)}_{\text{势能}} + \underbrace{\tfrac{R}{16\pi G}+\alpha R^2}_{\text{诱导引力}} \Big]$$

其中 $D_\mu=\partial_\mu-igA_\mu$，$F_{\mu\nu}=F^a_{\mu\nu}T^a$，$\psi\sim\mathbf{16}$，$H$ 为破缺标量。

## 二、求导：从本源 Lagrangian 显式重构标准模型

### 2.1 破缺级联的两级 Higgs

【 **精算：两级破缺** 】$SO(10)$ 经两级标量真空期望破缺（卷三路径）：

$$SO(10)\xrightarrow{\langle\Sigma\rangle\sim M_{\text{GUT}}} SU(3)_c\times SU(2)_L\times U(1)_Y \xrightarrow{\langle H\rangle=v=246\,\text{GeV}} SU(3)_c\times U(1)_{em}$$

第一级 $\langle\Sigma\rangle$ 由伴随/高阶表示给出，第二级 $\langle H\rangle=(0,v/\sqrt2)^T$ 由电弱双线态给出。

### 2.2 显式重构：标准模型 Lagrangian 的每一项本源溯源

破缺后，本源 Lagrangian 展开为标准模型形式，逐项求导溯源：

$$\mathcal{L}_{SM}=\underbrace{\tfrac14 G^a_{\mu\nu}G^{a\mu\nu}}_{\text{强}} + \underbrace{\tfrac14 W^i_{\mu\nu}W^{i\mu\nu}}_{\text{弱}} + \underbrace{\tfrac14 B_{\mu\nu}B^{\mu\nu}}_{\text{超荷}} + \underbrace{i\bar\psi\gamma^\mu D_\mu\psi}_{\text{费米子动能}} + \underbrace{|D_\mu H|^2 - V(H)}_{\text{Higgs}} + \underbrace{y_f\,\bar\psi_L H \psi_R + \text{h.c.}}_{\text{Yukawa}}$$

| 标准模型项 | 本源起源 | 求导/精算溯源 |
|---|---|---|
| 规范项 $F^2_{\mu\nu}$ | $SO(10)$ 规范动能 | 破缺后 $SO(10)\to SM$，规范场投影到 $SU(3),SU(2),U(1)$ 分量 |
| 费米子动能 | $\mathbf{16}$ 旋量动能 | $\mathbf{16}=\mathbf{10}\oplus\bar{\mathbf{5}}\oplus\mathbf{1}$ 分解为夸克/轻子 |
| Higgs 势 $V(H)$ | 本源平衡势 | $\langle H\rangle=v$ 驱动电弱破缺，$m_f=y_f v/\sqrt2$ |
| Yukawa $y_f$ | 本源 $0/1$ 对偶锁定 | 质量层级 = 破缺强度分布（卷三） |
| 强耦合 $\alpha_s$ | $SU(3)_c$ 分量 | 渐近自由 $\beta_0=11-\tfrac{2N_f}{3}$（卷二） |
| 引力 $R$ | 诱导引力 | 本源旋量真空涨落（卷二） |

【 **求导验证：破缺后质量谱** 】电弱破缺后，Higgs 势二阶展开给出 $W^\pm$、$Z$ 质量（卷三精算）：

$$m_W=\frac{gv}{2},\qquad m_Z=\frac{m_W}{\cos\theta_W},\qquad m_H=v\sqrt{2\lambda}$$

【 **收口结论** 】标准模型 Lagrangian **每一项都能在本源作用量中找到对应项**——没有一项是凭空外加的。这就是"统一场论实现"的显式证明：**本源 Lagrangian = 标准模型 + 统一预言（质子衰变、新粒子谱）的母体。**

## 三、本源可检验预言的显式导出

### 3.1 质子衰变（本源单群的必然推论）

$$\tau_p \sim \frac{M_X^4}{\alpha_{\text{GUT}}^2 m_p^5}\sim10^{34\text{–}36}\,\text{yr}$$

（最小 $SU(5)$ 的 $10^{30}$ 已被 Super-K 排除，见卷三。）

### 3.2 新粒子谱（本源单群的完整成员）

- $\nu_R$（$\mathbf{1}$ 表示）：右手中微子，seesaw 机制给 $\sim10^{-2}\,\text{eV}$ 质量；

- 额外规范玻色子 $X,Y$：传递轻子—重子转化，$M\sim M_{\text{GUT}}$。
