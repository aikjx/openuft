## 本区两类内容

| 子目录 | 语义 | 校验 |
|---|---|---|
| `迁移记录/` | 历次迁移的 manifest 与快照 zip | **校验器硬依赖**：`verify.py` 会读取并校验这些 zip 的 SHA-256，缺任一即崩溃。故 `.gitignore` 为它们开了 `*.zip` 的否定规则 |
| [`来源语料_根目录_20260919/`](来源语料_根目录_20260919/README.md) | 工作区根目录散落语料的**原样封存区**（287 条目 / 36.73 MB，8 个来源分箱） | 豁免「目录名必须含中文」与链接检查——目录名与内部结构照搬上游，改名会毁掉可追溯性 |

封存区不是体系目录：其内材料一律记 `待归属`，只登记线索。逐件归属后应移出并留痕。
