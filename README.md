# OpenUFT · 多模型统一场论研究

[目录设计论证与最优性评估](00_governance/DIRECTORY_DESIGN_REVIEW.md) · [全部目录逐项分析](00_governance/DIRECTORY_AUDIT.md)

以不同基础假设、宇宙认知与建模机制组织研究。目标是探索统一描述；目录规范和计算通过都不等于统一场论成立。本布局是适合本项目的研究约定，不声称存在唯一通用的物理学目录标准。

## 大模块

| 目录 | 用途 |
|---|---|
| [00_governance](00_governance/README.md) | 项目治理、总索引、研究流程和迁移记录 |
| [01_models](01_models/README.md) | 按宇宙认知与基础假设分开的六条研究路线 |
| [02_shared](02_shared/README.md) | 共享研究协议、数学文献和复现工具 |
| [03_comparative](03_comparative/README.md) | 跨模型公平比较、物理领域检验和综合候选 |
| [04_publications](04_publications/README.md) | 跨模型综述、公共图表和待确认归属的历史报告 |
| [90_archive](90_archive/README.md) | 历史资料、旧工具及完整迁移快照 |
| [99_inbox](99_inbox/README.md) | 尚未立项、归属待审的输入与问题 |

## 六条独立路线

- [空间运行与螺旋运动](01_models/h01_space_motion/README.md)
- [空间压缩与密度梯度](01_models/h02_space_compression/README.md)
- [物体驱动与源场耦合](01_models/h03_matter_driven/README.md)
- [几何与作用量](01_models/h04_geometry_action/README.md)
- [规范对称与相互作用](01_models/h05_gauge_symmetry/README.md)
- [量子结构与涌现](01_models/h06_quantum_emergence/README.md)

每条路线覆盖：立项 → 文献 → 假设 → 数学形式 → 推导 → 一致性 → 预测 → 计算与数据 → 验证 → 不确定度 → 证伪 → 结论 → 论文 → 评审 → 发布与归档。允许迭代返回前序阶段。
