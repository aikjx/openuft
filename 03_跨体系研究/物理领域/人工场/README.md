## 分析进展（求导证明验证 + 精算分析 · M03 证伪复算）

脚本 `verify_artificial_field_falsification.py`：

- **静止极限**：S02 P=m(c−v) 在 v=0 给 P=mc≠0（物体静止动量应为 0）→ 违反惯性/相对论（M03 冲突①，FAIL）
- **力符号**：F=dP/dt=−ma，与牛顿第二定律 F=ma 反号（M03 冲突②，FAIL）
- **灵敏度标定**：典型 (v/c) 反常引力修正 ~3×10⁻⁹ g，现有 Cavendish/冷原子已达 ~10⁻¹⁵ g → 无任何确认信号（FAIL）
