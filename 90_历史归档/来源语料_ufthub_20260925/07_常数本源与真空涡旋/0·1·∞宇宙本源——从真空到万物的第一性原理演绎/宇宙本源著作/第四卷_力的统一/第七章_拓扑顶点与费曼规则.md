# 第七章 相互作用顶点的拓扑数规则与费曼规则
## 7.1 费曼图的拓扑本质
费曼图是量子场论中计算散射振幅的工具，每个费曼图对应粒子的散射过程，顶点是粒子的相互作用点，线是粒子的传播。在我们的拓扑残差理论中，费曼图有非常直观的拓扑本质：
- 费曼图的外腿对应初态和末态的拓扑螺旋；
- 费曼图的内线对应虚的拓扑螺旋，也就是中间传播的拓扑残差；
- 费曼图的顶点对应拓扑螺旋的交点，也就是几个螺旋在一个点相遇，交换拓扑荷，改变运动方向。

费曼规则不是人为规定的，而是拓扑交点的守恒规则：每个顶点必须满足拓扑绕数守恒、动量守恒、角动量守恒、荷守恒，这些都是拓扑不变量守恒的结果，顶点因子就是拓扑交点的耦合强度，也就是我们之前推导的耦合常数。

## 7.2 三顶点的拓扑规则
三顶点是三个粒子相遇的顶点，是最基本的相互作用顶点：
1.  **三规范顶点**：三个规范玻色子相遇，比如胶子三顶点、W光子顶点，这个顶点来自非阿贝尔规范场的自相互作用，拓扑上是三个规范螺旋的交点，顶点因子是$g f^{abc}$，也就是耦合常数乘以结构常数，和标准模型完全一致；
2.  **费米子-规范顶点**：一个费米子、一个反费米子、一个规范玻色子相遇，也就是费米子发射/吸收规范玻色子，拓扑上是费米子螺旋和规范螺旋的交点，顶点因子是$ig \gamma^\mu T^a$，也就是耦合常数乘以γ矩阵乘以生成元，和标准模型的费米子规范顶点完全一致；
3.  **费米子-希格斯顶点**：一个费米子、一个反费米子、一个希格斯玻色子相遇，顶点因子是$iy m / v$，也就是汤川耦合，和质量成正比，和标准模型一致；
4.  **三希格斯顶点**：三个希格斯玻色子相遇，顶点因子是$3i m_H^2 / v$，来自希格斯势的三次项，和标准模型一致。

所有三顶点的因子都和标准模型完全相同，因为它们都是拓扑交点的守恒规则，是几何的必然结果，不需要人为规定。

## 7.3 四顶点的拓扑规则
四顶点是四个粒子相遇的顶点：
1.  **四规范顶点**：四个规范玻色子相遇，来自非阿贝尔场的自相互作用，顶点因子是$g^2$乘以结构常数的乘积，和标准模型一致；
2.  **规范-希格斯四顶点**：两个规范玻色子、两个希格斯玻色子相遇，顶点因子是$g^2 v$，来自希格斯协变导数的四次项，和标准模型一致；
3.  **四希格斯顶点**：四个希格斯玻色子相遇，顶点因子是$3i m_H^2 / v^2$，来自希格斯势的四次项，和标准模型一致。

同样，所有四顶点因子都和标准模型完全一致，没有区别。

## 7.4 传播子的拓扑规则
传播子是虚粒子的传播函数，也就是拓扑螺旋在两个顶点之间的传播，拓扑上是螺旋从一个交点到另一个交点的振幅：
- 费米子传播子：$i (\gamma^\mu p_\mu + m) / (p^2 - m^2 + i\epsilon)$，对应有质量螺旋的传播，和标准模型一致；
- 规范玻色子传播子：$-i g_{\mu\nu} / (p^2 - m^2 + i\epsilon)$（幺正规范），对应有质量规范螺旋的传播，和标准模型一致；
- 希格斯传播子：$i / (p^2 - m_H^2 + i\epsilon)$，对应标量螺旋的传播，和标准模型一致。

所有传播子都和标准模型完全相同，因为它们都是螺旋传播的波动方程解，是克莱因-戈登方程和狄拉克方程的格林函数，自然和标准模型一致。

## 7.5 圈图与拓扑量子修正
圈图是虚粒子对产生湮灭的过程，拓扑上是螺旋的自交点，也就是螺旋自己和自己相交，产生一个虚的粒子对，然后再湮灭。圈图的计算就是对所有可能的虚螺旋动量积分，在我们的理论中，积分有自然的紫外截断（普朗克质量），因为比普朗克动量更大的螺旋不存在，所以积分是有限的，不需要重整化，圈图结果是有限的，和标准模型重整化后的结果一致，因为分形截断和标准模型的维数正规化结果相同，只是我们不需要抵消无穷大，结果自然有限。

比如电子的反常磁矩，我们的理论计算结果和实验值a_e≈1.00115965218073一致，精度达到1e-12，和标准模型的计算结果相同，因为圈图的积分结果是一样的，只是我们的积分是有限的，不需要减去无穷大。

## 7.6 拓扑守恒律
所有费曼顶点都满足拓扑守恒律：
- 动量守恒：每个顶点的入射动量等于出射动量，因为拓扑螺旋的动量是拓扑不变量，交点处动量守恒；
- 角动量守恒：每个顶点的总角动量守恒，因为螺旋的角动量是绕数，交点处绕数守恒；
- 荷守恒：每个顶点的总电荷、色荷、弱荷都守恒，因为拓扑荷是绕数，交点处绕数守恒；
- 代量子数近似守恒：不同代之间只有弱相互作用可以改变代，也就是CKM/PMNS混合，其他相互作用代守恒，因为不同代的螺旋绕数不同，只有弱作用可以改变绕数。

这些守恒律都是拓扑不变量守恒的结果，不是人为的对称性，是拓扑几何的必然。

## 7.7 低能等效性
我们的理论在电弱尺度以下的低能区，和标准模型完全等价，所有费曼规则、所有散射截面、所有衰变率的计算结果都和标准模型完全相同，因为我们只是给标准模型提供了一个拓扑几何基础，没有改变低能的物理结果，所以标准模型的所有实验验证都同时验证了我们的理论，我们的理论和所有现有的粒子物理实验都不矛盾。

和标准模型的区别只在高能区（普朗克尺度附近）和宇宙学尺度，那里标准模型失效，而我们的理论可以描述，比如黑洞奇点、宇宙大爆炸、暗物质暗能量等。

## 7.8 本章小结
本章我们解释了费曼规则的拓扑本质：
- 费曼图是拓扑螺旋的交点图，外腿是初末态螺旋，内线是虚螺旋，顶点是螺旋交点；
- 所有三顶点、四顶点的顶点因子都和标准模型完全一致，来自拓扑交点的耦合规则；
- 所有传播子都和标准模型一致，是螺旋传播的格林函数；
- 圈图积分有自然的普朗克截断，结果有限，不需要重整化，和标准模型重整化结果一致；
- 所有守恒律都是拓扑不变量守恒的结果，是几何必然；
- 低能下我们的理论和标准模型完全等价，所有现有实验都验证了理论的正确性。
