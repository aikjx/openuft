## 一、结论先行

前十六轮把「力的本源」一路逼到一条单句：**≤3 参数生成不了四力**。这条单句此前分散在四册里（第七轮方程层、第八轮标签层、第九轮公理层、第十六轮谱层），各自给出一个下界 `5/4/4/4`。本轮不造理论、不放宽判据，只问三个审计问题：

2. 十六册产物的**总账**，能不能两路机拼互证？
3. 四条下界**是不是四份独立证据**？

三句话给结论：

1. 十六册总账 **16/16 全一致**，失配字段 `0`；`662` 条断言、`227` 个去重读数键。同册支撑 `178` 条（`26.888%`），负对照（跨册错配）掉到 `72` 条（`10.876%`）⇒ 匹配器有判别力。

## 五、★层数 ≠ 份数：真实单点故障

四层同时挡门，很自然会写成「四份独立证据」。本轮专门查这句话，结论是**不能这么写**。

**（1）层间依赖边。** 四条下界不是平行的，后一条要用前一条的结论：

| 依赖边 | 含义 |
|---|---|
| `R8←R7` | 标签层的参数预算下界借用方程层的**耦合谱类数**（谱类 −1 这个加数） |
| `R9←R7` | 公理层的 I1 引用「现有零参数宣称都含观测副本」这一第七轮结论 |
| `R9←R8` | 公理层的 A5 引用「标签须外部注入」这一第八轮结论 |

边数 `3`，独立源 `2` 个（R7 / R16），依赖深度 `2` ⇒ **四条下界背后只有 2 个互不引用的支点**。关掉 `R7`，`R8` 与 `R9` 的加数同时失去来源；门数从 4 掉到 2，而不是掉到 3。

**（2）形式同构对。** 检测到的同构对：[['R8', 'R16']]。`R8` 的加数是 `3+1`、`R16` 的也是 `3+1`，**加数多重集相同（`{1,3}`）**，但加数对象不同：前者是「离散标签数 + 统一尺度」，后者是「参数预算 + 缺口」。⇒ **形式同构，不是同一条算式的两次独立验证**，单列 `IDENTITY`，不计证据。

**（3）同值支点去重（按值聚合，只报不改判）。**

| 数值 | 出现次数 | 共用的加数 |
|---|---|---|
| 3 | 3 | R16·参数预算、R7·耦合谱破缺、R8·离散标签（树口径） |
| 1 | 2 | R16·缺口、R8·统一尺度 |

★ 纪律：**数值相同不等于同源**。值 `3` 上的三项里，`R7·耦合谱破缺` 与 `R8·离散标签（树口径）` 确实是**同一个量**（谱类 −1），属真实重复计数；`R16·参数预算` 只是数值巧合。值 `1` 上的两项同理是巧合。因此这张表**只用于去重提示，不用于改判**。

⇒ **真实承重支点 = 2 个**。这是第十四轮「门数 N ≠ N 份独立证据」的第二次精确落地；两次是不同对象（那一次查门之间的冗余度，这一次查层之间的依赖），**不相加、不比较、不互相印证**。

## 六、预算相变：临界预算 3 是怎么来的

把参数预算 `k` 从 0 加到 6，数「还有几层在挡」：

| 参数预算 k | 仍在挡的层数 |
|---|---|
| `0` | `4`（四层全挡） |
| `1` | `4`（四层全挡） |
| `2` | `4`（四层全挡） |
| `3` | `4`（四层全挡） |
| `4` | `1` |
| `5` | `0` |
| `6` | `0` |

四层全挡的预算上限 = `3`，等于 `min(5/4/4/4) − 1 = 3`（`crit_budget`）。预算放到 `4` 时只剩 `1` 层承重 ⇒ 这不是「预算再大一点也没关系」，而是**在 k=4 处发生相变**。

敏感性：把耦合谱类数 `c` 从 1 调到 6，看哪一层先失效：

| 谱类数 c | R7 方程层 | R8 标签层 | 在挡层数 |
|---|---|---|---|
| `1` | `2`（破） | `1`（破） | `2` |
| `2` | `3`（破） | `2`（破） | `2` |
| `3` | `4`（挡） | `3`（破） | `3` |
| `4` | `5`（挡） | `4`（挡） | `4` |
| `5` | `6`（挡） | `5`（挡） | `4` |
| `6` | `7`（挡） | `6`（挡） | `4` |

⇒ `R7` 在 `c ≥ 3` 仍挡；`R8` 要 `c ≥ 4` 才挡 ⇒ **最脆弱层 = `R8`**。但公理层与谱层**不依赖谱类数**，所以任一 `c` 下至少 `2` 层恒在挡（最多 `4` 层）⇒ **把谱类数往下调，打不穿全链**。

## 七、三次单点反噬：承重读数必须两两不同

每次只关一个门，要求 `final` 转 `GATES-FAIL`，并且**承重读数四值两两不同**（否则等于没有判别力）。承重读数定义为 `CREDIT = 册命中 + 层复算通过数 + 敏感性档数`：

`CREDIT(led, rec, sen) = (16 if led else 0) + (4 if rec else 0) + (6 if sen else 0)` ⇒ 基线 `26`。

## 十、实现事故与纪律增量

本轮 `5` 处事故，全部是既有纪律被违反，如实登记：
