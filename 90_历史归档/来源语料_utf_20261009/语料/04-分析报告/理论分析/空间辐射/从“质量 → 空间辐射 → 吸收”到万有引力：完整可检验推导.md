# 从“质量 → 空间辐射 → 吸收”到万有引力：完整可检验推导

**摘要（结论）**
在一个假设框架下：每单位质量以速率 ( \alpha ) 发射能量流，每单位质量对该流具有吸收截面 ( \beta )，并且能量以光速传播且能量—动量关系 (E=pc) 适用时，可以把两物体间的吸收转化为一个库伦型的 (1/R^2) 力。该模型在形式上等价于牛顿引力，要求并仅确定乘积 (\alpha\beta)，得出关键恒等：
[
\boxed{\alpha\beta = 2\pi G c, \quad Z\equiv\frac{\alpha\beta}{4\pi}=\frac{G c}{2}.}
]
单独的 (\alpha) 或 (\beta) 并不由该静态匹配唯一确定，需借助物理机制与观测约束来分别固定。下面为完整的推导、量纲检验、数值验证、物理含义、可观测约束与实验可检验建议。

---

## 1. 模型前提与符号说明

* 两个点质量 (m_1, m_2)， 互相分隔距离 (R)（假定 (R) 远大于质点本身尺度，可用点近似）。
* 假设每单位质量以**恒定的比例**向全空间连续辐射某种可携动量的量（形式上类似光子或无质量场的能量流）。辐射功率与质量成正比：
  [
  P_1 = \alpha , m_1,\quad [\alpha] = [\text{功率}]/[M] = L^2 T^{-3}.
  ]
* 另一质量对该流有**有效吸收截面**与质量成正比：
  [
  \sigma_2 = \beta , m_2,\quad [\beta]=\frac{[L^2]}{[M]}=L^2M^{-1}.
  ]
* 能量以光速 (c) 传播，能量—动量关系 (E=pc)（对传播的单元适用），功率与力联系 (F = \dfrac{P}{c})。

注：以上假设是模型的物理起点，必须在后续讨论中验证其自洽性与实验一致性。

## 2. 推导（逐步、带量纲检验）

### 步骤 1 — 质量 (m_1) 的辐射功率

设：
[
P_1=\alpha m_1.
]

### 步骤 2 — 球面处的能量通量密度（功率/面积）

能量均匀向球面分布（各向同性）：
[
S_1(R) = \frac{P_1}{4\pi R^2} = \frac{\alpha m_1}{4\pi R^2}.
]
量纲：([S_1]=\dfrac{[\text{功率}]}{L^2}=[M T^{-3}])。一致。

### 步骤 3 — 质量 (m_2) 的吸收截面

定义有效截面：
[
\sigma_2 = \beta m_2.
]
量纲：([\sigma_2]=L^2) → ([\beta]=L^2 M^{-1})。一致。

### 步骤 4 — (m_2) 吸收的功率

被吸收的功率：
[
P_{abs} = S_1 \sigma_2 = \frac{\alpha m_1}{4\pi R^2}\cdot \beta m_2 = \frac{\alpha\beta}{4\pi}\cdot\frac{m_1 m_2}{R^2}.
]

### 步骤 5 — 功率转为力（关键）

能量—动量关系 (E=pc) 意味着每单位能量携带动量 (p=E/c)。因此吸收功率 (P_{abs}=dE/dt) 对应动量变化速率：
[
F_{1\to2} = \frac{dp}{dt} = \frac{1}{c}\frac{dE}{dt} = \frac{P_{abs}}{c}.
]
代入 (P_{abs})：
[
F_{1\to2} = \frac{\alpha\beta}{4\pi c}\cdot\frac{m_1 m_2}{R^2}.
]
量纲检查：右侧量纲为 (\dfrac{[L^4 M^{-1} T^{-3}][M^2]}{L^2 [LT^{-1}]} = MLT^{-2})，为力。通过。

### 步骤 6 — 双向对流（互相辐射）

由于两物体均辐射并互相吸收，存在两个方向的相同项（在对称情形下大小相同）：
[
F_{\rm total} = F_{1\to2} + F_{2\to1} = 2\cdot\frac{\alpha\beta}{4\pi c}\cdot\frac{m_1 m_2}{R^2}.
]
因子 (2) 来源于“双方都在发射并被对方吸收”的耦合。

### 步骤 7 — 与牛顿万有引力对比，得到恒等式

牛顿引力：
[
F_N = G\frac{m_1 m_2}{R^2}.
]
匹配形式系数：
[
G\ =\ \frac{2}{c}\cdot\frac{\alpha\beta}{4\pi}\ \ \Longrightarrow\ 
\boxed{\frac{\alpha\beta}{4\pi} = \frac{G c}{2} \equiv Z.}
]

等价写法：
[
\boxed{\alpha\beta = 2\pi G c.}
]

## 3. 数值验证（逐位算术）

[
G = 6.67430\times10^{-11}\ \mathrm{m^3,kg^{-1},s^{-2}},\qquad
c = 2.99792458\times10^8\ \mathrm{m,s^{-1}}.

先算 (Gc)：

* 因此 (Gc = 0.020009048024294)（单位 (\mathrm{m^4,kg^{-1},s^{-3}})）。
  令 (Z=\dfrac{Gc}{2})：
  [
  Z = \frac{Gc}{2} = 0.010004524012147\ \mathrm{m^4,kg^{-1},s^{-3}}.
  ]
  再得：
  [
  \alpha\beta = 4\pi Z = 2\pi G c \approx 0.125720556624294\ \mathrm{(SI\ units)}.
  ]

（上述数值步骤可逐位复核；我们得到的数值与先前估计一致。）

## 4. 物理含义与关键问题（为什么 (\alpha,\beta\neq0)，但不唯一）

1. **为什么 (\alpha,\beta) 必须非零？**

   * (\alpha=0) 表示没有辐射源，模型里就没有传播媒介 → 无法产生力。
   * (\beta=0) 表示不能吸收传播的能量 → 同样无法把能量流转化为动量改变。
     因此两者都要 (>0)。

2. **为什么单独的 (\alpha) 或 (\beta) 未被固定？**

   * 推导中力只依赖于乘积 (\alpha\beta)。因此只凭静态力匹配（即只要求产出 (G\frac{m_1m_2}{R^2})）无法区分这两个耦合常数的分配。
   * 要分别确定 (\alpha) 和 (\beta)，必须引入额外物理输入（例如微观发射机制、散射/吸收截面理论、实验测量质量随时间的变化率等）。

3. **这是不是在“偷换”能量守恒？**

   * 若每单位质量不断把质量转为能量发射（质能转换），必须考虑质量损失，以及该能量的最终归宿（是否被其他质量完全吸收或散逸到宇宙背景）。模型允许局部发射—被对方吸收，从而总体上形成“中介动量交换”而非净耗散，但全宇宙能量守恒仍需检查（例如宇宙中孤立区域的能量是否积累或损耗）。这是模型的关键检验点。

## 5. 可观测约束（示例：太阳）——把 (\alpha,\beta) 映射到可测量量

若 (\alpha) 表征质量衰减率（因为辐射来自质量→能量），则
[
\frac{dm}{dt} = -\frac{P}{c^2} = -\frac{\alpha}{c^2} m
]
解为指数衰减 (m(t)=m(0)e^{-t/\tau})，时间常数
[
\tau=\frac{c^2}{\alpha}.
]
由于 (\alpha = \dfrac{2\pi G c}{\beta})（由 (\alpha\beta=2\pi G c) 得出），得到
[
\boxed{\tau = \frac{c , \beta}{2\pi G}.}
]

**示例计算（太阳）**
太阳年龄约 (t_\odot \approx 4.6\times10^9) 年。换算秒数：
(1\ \text{yr}=3.1536\times10^7\ \mathrm{s}) → (t_\odot\approx 4.6\times10^9\times3.1536\times10^7=1.450456\times10^{17}\ \mathrm{s}.)

若要保证在该时间尺度内太阳质量变化可忽略（例如质量损失小于百亿分之一），需要 (\tau \gg t_\odot)。令 (\tau \gtrsim t_\odot) ，代入解出对应的 (\beta) 门限：
[
\beta \gtrsim \frac{2\pi G t_\odot}{c}.
]
代入数值（逐位计算，近似）得出：
[
\beta_{\min} \approx 0.20\ \mathrm{m^2/kg}\ \text{（当 }\tau=t_\odot\text{）}.
]
因此若 (\beta \sim 1\ \mathrm{m^2/kg}) 则
[
\tau \approx \frac{c,\beta}{2\pi G} \approx 7.15\times10^{17}\ \mathrm{s}\approx 2.27\times10^{10}\ \mathrm{yr},
]
即可保证天体在宇宙历史尺度上质量相对稳定。若 (\beta) 非常小（例如 (10^{-10}\ \mathrm{m^2/kg})），则 (\tau) 会降到年级，显然与观测矛盾。

**结论**：天体演化与精密质量观测会给 (\beta)（进而 (\alpha)）提供强约束。上面只是简单示例；更严格的约束来自行星动力学、恒星演化与核合成约束、以及激光测距和重力测试。

## 6. 与现有引力理论（广义相对论）和实验的兼容性问题（必须检验的）

任何替代理论或机制若要取代或解释引力，需至少满足这些实验/观察约束：

1. **等效原理（弱/强）**

   * 物质组成不应影响自由落体加速度（Eötvös 实验）。在本模型中，若 (\beta) 随物质成分不同而不同，会违反等效原理。要恢复等效性，必须要求 (\beta) 对所有实测物质的“质量本征”相同（或在实验精度下相同）。

2. **光线弯曲与时间延迟**

   * 爱因斯坦广义相对论给出了太阳附近光线弯曲、Shapiro 延迟等精确预测。任何基于粒子交换的机制需能复现这些现象或解释为何观测相符。

3. **水星近日点进动**

   * GR 能解释水星近日点的超额进动（43″/世纪）。若本模型仅给出 (1/R^2) 力且无额外修正，则可能无法复现这一精细偏差（需要额外的势项或相对论校正）。

4. **引力波观测**

   * LIGO/Virgo 的引力波信号与 GR 的预言高度一致。若引力由连续流/吸收产生，需检查该机制在强场动态下是否会生成与 GR 相同的波形与能量损失率。

5. **天体演化、一致性与能量守恒**

   * 若辐射导致不可忽视的质量损失，会对恒星演化、银河动力学产生可测效应。

因此，本模型在“复刻”牛顿力上是可能的（形式上），但要完整替代或同化 GR 需要极多额外工作并经受严格检验。

## 7. 可观测的、可实验的检验（建议）

下面列出一些直接/间接可以实验或观测检验该模型的方案——每一项都能给出 (\alpha) 或 (\beta) 的上/下界：

1. **精密质量稳定性测量**

   * 测量恒星/行星的质量随时间的变化率（或上限），将其映射为对 (\tau) 的下限，从而限制 (\beta)（或 (\alpha)）。

2. **等效原理实验（Eötvös 型）**

   * 比较不同材料（不同化学成分）在相同重力场中的加速度差异。若 (\beta) 与材料相关，会产生可测偏离。

3. **光线偏折与延迟测量**

   * 观测太阳掩星或射电源掩通过程中的光线弯曲与延迟，比较与 GR 预测的精确残差。

4. **围绕双星/脉冲星系统的能量损耗**

   * 类似于 Hulse–Taylor 双中子星系统的轨道衰变——若本模型引入不同的辐射机制，其能量辐射率或形式可能不同，影响轨道衰变速率。

5. **室内屏蔽/阴影实验**（若该空间流可被遮挡）

   * 在理想情形下制造一个大遮挡体或对称孔隙，观测被遮挡区域内微小的重力异常（这类实验历史上有很多尝试，结果通常为 null，给出屏蔽效应的上限）。

6. **高精度天文力学拟合**

   * 把该模型引入太阳系动力学数值积分，拟合行星位置数据（雷达/激光测距、VLBI），比较残差与传统模型，得到参数上限。

## 9. 反驳点与局限（诚实列出）

* **等效原理难保**：若 (\beta) 与材料或质子数成分有关，会违反强等效原理；这需要特殊对称性或深层次原因来保证 (\beta) 对任何物质都相同。
* **引力的传播速度**：该模型将传播速度设为 (c)，这与 GR 的引力波传播速度一致（好点），但在动态强场中是否产生同样的延迟/回路效应尚不清楚。
* **能量来源问题**：恒常发射需要质量转化成能量，除非能证明发射并非质量损耗（例如只是场的重分布），否则必须解释质量长期不消失的机制。
* **无法直接得到 GR 的弯曲时空几何解释**：本模型产生的仅为力学效果，要解释时间膨胀、空间弯曲等 GR 关键预言需额外结构。
