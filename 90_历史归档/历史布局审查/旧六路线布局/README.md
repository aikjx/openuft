# 理论大模块

主分类轴是基础假设与宇宙模型。六条路线是研究容器，彼此可能交叉；不是互斥的完备物理学分类。未制定公设与可检验预测前，不能称为成立的理论。

| 模块 | 研究方向 |
|---|---|
| 历史路线01_空间运动 | [空间运行与螺旋运动](历史路线01_空间运动/README.md) |
| h02_space_compression | [空间压缩与密度梯度](h02_space_compression/README.md) |
| h03_matter_driven | [物体驱动与源场耦合](h03_matter_driven/README.md) |
| 历史路线04_几何作用量 | [几何与作用量](历史路线04_几何作用量/README.md) |
| h05_gauge_symmetry | [规范对称与相互作用](h05_gauge_symmetry/README.md) |
| h06_quantum_emergence | [量子结构与涌现](h06_quantum_emergence/README.md) |

新增路线从 [新体系模板](新体系模板/README.md) 复制；建立 model.json 后登记，不复制其他路线的结论作为证据。
