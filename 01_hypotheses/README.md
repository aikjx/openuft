# 理论假设与独立研究路线（主分类轴）

以**不同假设 / 体系**为主轴，每条自成全链路「假设(00) → 定义(01) → 求导(02,D) → 证明(03,P) → 预测(04) → 验证(05,V) → 精算(06,A) → 证伪(07) → 结论(08)」。
各体系允许竞争、交叉和淘汰，不预设最终统一场论已成立。

## 如何新增体系

1. 复制 [`_template/`](_template/README.md) 为 `h07_xxx/`
2. 填写 `README.md` 的研究问题与状态
3. 在本总表登记 h07
4. 沿 00 → 08 逐阶段填充
