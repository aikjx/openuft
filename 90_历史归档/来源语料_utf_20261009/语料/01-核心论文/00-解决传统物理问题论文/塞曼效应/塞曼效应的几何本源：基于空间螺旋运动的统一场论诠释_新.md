
其中，R(t)表示空间点的位置矢量，R₀为螺旋半径，ω为角频率，φ为初始相位，v₀为轴向速度，i、j、k为三维空间单位矢量。

```
V(t) = -ωR₀sin(ωt + φ)i + ωR₀cos(ωt + φ)j + v₀k
```

```
L = mR × V = mR₀²ωk
```
