# 定理 D｜GR + 标准模型 + 螺旋场的协变作用量与变分方程

> 本节全部使用自然单位 \(\hbar=c=1\)、度规号差 \((-+++)\)，曲率标量记 \(\mathcal R\)（避免和螺旋半径 R 混淆）。给出**可定义的候选有效场论**，不是已证明共同本源。

## D1. 已经成功的理论结构

标准模型规范群为 \(SU(3)_C\times SU(2)_L\times U(1)_Y\)。在表示给定的前提下，规范场强

\[F^a_{\mu\nu}=\partial_\mu A^a_\nu-\partial_\nu A^a_\mu+g f^a{}_{bc}A^b_\mu A^c_\nu\]

与作用量的项 \(-\tfrac14 F^a_{\mu\nu}F^{a\mu\nu}\) 给出规范场 Euler–Lagrange 方程 \(D_\mu F^{a\mu\nu}=J^{a\nu}\)，其中电流与耦合常数按一致约定归一。电弱对称性破缺后电磁 \(U(1)_{em}\) 保留，W/Z 获得质量。

注意：统一写在一个作用量里不会解释为何恰好有三代费米子、为什么各自具有所观测的质量与电荷或为什么规范耦合在某能标可能相交。

## D2. ROOT 最小可检验候选（非实验发现）

引入**规范单态复标量** \(X\) 来表示一种可能具有螺旋相位的场模态。定义

\[\boxed{S=\int d^4x\sqrt{-g}\left[\left(\frac{M_0^2}{2}-\xi |X|^2\right)\mathcal R
-\nabla_\mu X^*\nabla^\mu X -m_X^2|X|^2-\frac\lambda2|X|^4-\rho_{vac}+\mathcal L_{SM}\right].}\]

本式是一个带非最小曲率耦合的标量—张量有效理论。对 X 变分得到

\[\boxed{(\Box-m_X^2-\lambda |X|^2-\xi\mathcal R)X=0.}\]

记 \(f=|X|^2\)，在把 \(\rho_{vac}\) 视为物质应力张量的一部分且 \(T_{\mu\nu}^{X,min}\) 为不含非最小耦合项的 X 应力张量时，对度规变分：

\[\boxed{(M_0^2-2\xi f)G_{\mu\nu}=T_{\mu\nu}^{SM}+T_{\mu\nu}^{X,min}+T_{\mu\nu}^{vac}+2\xi(g_{\mu\nu}\Box-\nabla_\mu\nabla_\nu)f.}\]

其中

\[T_{\mu\nu}^{X,min}=2\operatorname{Re}(\nabla_\mu X^*\nabla_\nu X)
-g_{\mu\nu}\big(\nabla_\alpha X^*\nabla^\alpha X+m_X^2f+\frac\lambda2 f^2\big).\]

\(T^{vac}_{\mu\nu}=-\rho_{vac}g_{\mu\nu}\)。包含物质相互作用时，各单项张量不必独立守恒；完整 diffeo 不变性及全套场方程保证总能动守恒的正确恒等式。

## D3. 能否从这个作用量“算出” G？

若 \(X=X_0\) 在研究尺度近似常量，则有效爱因斯坦—希尔伯特系数为

\[\boxed{M_{\rm eff}^2=M_0^2-2\xi|X_0|^2=\frac1{8\pi G_{\rm eff}}.}\]

该结论是有效系数的**定义/匹配**，而非对 G 的独立推导，因为 \(M_0,\xi,|X_0|\) 尚未由 ROOT 原理确定。\(M_{\rm eff}^2>0\) 是正常引力动能的必要条件之一，但还不足以排除全部 ghost/梯度不稳定或满足实验。

特别地，若设置 \(X=0\)，就退回已输入的 GR+SM；它是一个一致性极限，**不能说 X 产生了已知四力**。

## D4. 从“已知结构的相加”到“真正统一”所缺少的推导

1. 解释为什么基础 Hilbert 空间产生\(SU(3)\times SU(2)\times U(1)\) 及特定表示。
2. 从微观作用量推出自旋 2、规范场的不同自旋和相应规范冗余；不能只由 Frenet T,N,B 三方向定义。
3. 正确处理标准模型的手征费米子、规范异常抵消、希格斯与 Yukawa 质量矩阵、三代与中微子质量。
4. 证明量子幺正性、因果性、UV 完成及至少适当范围内的重整化/有效场论一致性。
5. 从事前确定的基本参数定量预测可测实验，并通过观测；仅恢复拟合过的原有公式不构成新理论验证。

## D5. 重要防伪证据

- “\(F=d\mathbf p/dt\)”描述运动学/动力学法则，不生成标准模型的规范群。
- “\(F_g,F_e,F_b\) 在特殊坐标下相互垂直”不能解释强弱相互作用的群表象。
- 单个 `X` 复标量只有有限的场自由度，**无法仅凭其相位几何导出强弱相互作用**。
- 有限个 classical toy 测试即使全部通过，也仅证明程序执行了输入方程。
