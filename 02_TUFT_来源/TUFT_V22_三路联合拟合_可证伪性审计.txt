========================================================================================
TUFT V22 · 三路联合 χ² 拟合的可证伪性审计 · 报告
========================================================================================

审计对象：TUFT V21（水星进动 + 原子高阶精细结构 + CMB 双谱；JAX AutoDiff Hessian + emcee MCMC）

核心结论
----------------------------------------------------------------------------------------
1. 【P0·数据】三路中两路不可信：原子数据与氢精细结构实测趋势反号（随 n 增大 vs
   实测 ∝1/n³ 递减）；CMB 数据的中心值等价于 4.7σ/3.7σ/2.8σ 已探测到原始非
   高斯性，与 Planck 未探测的结论冲突。两路均无来源标注。
2. 【P0·模型】模型形状与数据不可调和：float64 下 n 依赖恒为零；即便无限精度，
   「量级」与「n=2→3 的比值」也不可兼得（闭式证伪）；CMB 观测幂律指数 +1.300
   与模型 ℓ^-3 反号；τ 在 ℓ=2000 处相位 0.00240 rad ⇒ 挠率不可辨识。
3. 【P0·结构】β/V0/A_topo 三参数严格解耦（Hessian 非对角/对角 0.0e+00 机器零）
   ⇒ 「三路联合」是三个独立一维拟合的平凡并列，无跨探针约束。
4. 【拟合】χ²_min = 71103.2，χ²/dof = 23701.1，最大残差 213.3σ ⇒ 模型被否决。
5. 【统计】原 walker 初始化（p_best + 1e-4 绝对扰动）对 V0 是 4.4e+33 倍相对扰动，
   是尺度灾难；修好后 MCMC 与解析 σ 偏差 <10%。模型线性 ⇒ 后验为精确截断
   高斯，Σ=2H⁻¹ 是精确解，V21「MCMC 比高斯近似更可靠」在本案不成立。
6. 【候选判定】贝叶斯因子因先验体积任意而不可定义（先验放大 10 倍 ⇒ lnB 平移
   6.91）；AIC/BIC 在剔除原子路的子集上偏好 TUFT，但收益来自「自由振幅 vs
   B≡0 稻草人基准」，不含 TUFT 物理内容。
7. 【预言证伪】四项「固定参数预言」中两项不可预测（缺 (a,e,M) 闭式 / 缺度规），
   两项与已知标度偏差 28× ~ 93×。

逐条结果
----------------------------------------------------------------------------------------
[BOUNDARY] D1-0   JAX 不可用·改走解析路线
           本机 Python 3.8.8 无 jax/jaxlib（Windows 无 Py3.8 wheel）；改用 sympy 解析梯度+Hessian，并由 mpmath 250 位中心差分交叉验证。解析二阶导严格优于 float64 AD：无浮点截断、无 AD 图近似。
[    PASS] D1-1   解析 Hessian 交叉验证
           sympy 解析 Hessian 与 mpmath 250 位中心差分最大相对偏差 = 7.54935e-62（符号常量与 mpmath 常量同源为十进制字面值；若常量只用 float64 精度，该偏差会退化到 ~3e-16，无法体现高精度）
[    PASS] D1-1b  解析梯度交叉验证（远离最优点）
           在 χ²≈1e45 的远点，sympy 解析梯度与 250 位中心差分相对偏差 = 2.659e-59 / 7.549e-62 / 9.119e-63；该处 float64 有限差分会彻底失效（见 D6-1），解析导数不受影响。
[    PASS] D1-2   Hessian 与参数点无关（二次型）
           三个模型对各自参数均为线性 ⇒ χ² 是正定二次型，Hessian 为常数矩阵；两个相距 20 个量级的检验点上 Hessian 相对偏差 = 0.000e+00
[    PASS] D2-1   水星数据可溯源
           φ_obs=43.03±0.03 arcsec/century、GR=42.979 与太阳系进动标准余差一致（残差 1.7σ）
[    FAIL] D2-2   原子数据与原子物理冲突
           V21 数据 E(2)=1.082e-04eV, E(3)=2.415e-04eV 随 n 增大（比值 2.232）；氢精细结构实测 E(2)=4.531e-05eV→E(3)=1.345e-05eV 随 n 减小（比值 0.2967 ≈ (2/3)³=0.2963）。趋势反号且量级差 2.4×/18.0×，数据集来源未标注 ⇒ 不可用作检验基准。
[    FAIL] D2-3   CMB 数据宣称非高斯性探测
           三个构型的中心值/误差 = 4.67σ, 3.68σ, 2.83σ，等价于「已探测到原始非高斯性」；而 Planck 2018 等边/局域型 f_NL 未探测（|f_NL| ≲ O(10) 上限内与 0 相容）。数据集来源未标注且与公开结果冲突 ⇒ 不可用作检验基准。
[    PASS] D3-1   float64 下 n 依赖恒零
           n²ħ²/Ntop² = 4.448e-74（n=2）/ 1.001e-73（n=3）相对 V0≈2.250e-38 为 1.98e-36，远低于 float64 eps=2.22e-16 ⇒ V0 + n项 在 float64 下与 V0 严格相等(= True)；模型对 n 的敏感度恰为零，无法产生任何 n 依赖的分裂。
[    FAIL] D3-2   量级与比值不可兼得（闭式证伪）
           即便用无限精度：要使 E(3)/E(2)=2.232 需 V0=6.50754e-76 eV-量纲，此时 E(2)=3.1345e-40 eV，与观测 1.082e-04 eV 差 35.54 个量级 ⇒ 不存在任何 V0 能同时满足观测的量级与比值，模型被数据结构性否决（非数值失败）。
[BOUNDARY] D3-3   宇宙挠率 τ 不可辨识
           τ·ℓ̄ 在 ℓ=2000 处仅 0.00240 rad ⇒ ∂lnB/∂lnτ = -x·tan x ≈ -5.760e-06，CMB 双谱对该挠率参数的可辨识度 ≈ 0 ⇒ 该观测量不是挠率探针。
[    FAIL] D3-4   CMB 形状指数反号
           观测 B(ℓ) 的幂律指数 = +1.300（B 随 ℓ 增大而增大）；模型 B ∝ ℓ^-3 指数 = -3.000。两者相差 4.30 个指数单位，符号相反 ⇒ 单振幅参数无法弥合形状矛盾。
[    PASS] D4-1   三参数完全解耦
           Hessian 非对角元/对角元 最大 = 0.000e+00（机器零）⇒ β、V0、A_topo 三参数严格解耦，每个参数只进入单一数据集 ⇒ 「三路联合」= 三个独立一维拟合的平凡并列，不产生任何跨探针约束；corner 图无相关性是数学必然而非物理发现。
[    FAIL] D4-2   候选 1（加 EHT 第四观测组）无判别力
           在参数解耦结构下，新增第四观测组必然引入第四个独立参数 A_EHT 由该组数据单独吸收，χ² 改善恒为「1 参数吃 1 组中心值」，跨探针约束仍为零 ⇒ 增加观测组不增加判别力。判别力的唯一来源是让参数跨探针共享（同一 β/τ 同时进入多个数据集）。
[    INFO] D5-1   解析最优点
           β*=1.000000, V0*=2.249052e-38, A_topo*=1.154047e-10（闭式线性最小二乘，与 L-BFGS-B 原空间 837286169328825145759208440906945512431681536.000000 / log 空间 71121.823183 对照）
[    FAIL] D5-1b  原空间 L-BFGS-B 灾难性失败（V21 代码路径）
           V21 直接对 [β,V0,A] 做 minimize(L-BFGS-B, bounds=[0,∞)) 得到 χ²=8.3729e+44，比闭式真值 71103.2285 高 40.1 个量级（V0 初值 1e-18 与真值 2.249e-38 跨 20 个量级，数值尺度病态）⇒ V21 报告的「最优参数」在该路径下并不收敛；改在 log 参数空间后 χ²=71121.8232（与真值差 18.59，仅剩停止准则残差）。
[    FAIL] D5-2   拟合优度：模型被否决
           χ²_min = 71103.2，χ²/dof = 23701.1（dof=3），最大单残差 = 213.3σ；原子路单独贡献 χ²=71075.6。按任何常规显著性标准该 TUFT 模型都被数据彻底否决。
[BOUNDARY] D5-3   β*=1 是「参数化残差」而非物理结果
           0.051 恰等于 φ_obs-φ_GR = 0.051 ⇒ β*=(φ_obs-φ_GR)/0.051=1.0000 恒为 1，水星路 χ² 恒等于 0。这是把残差本身写成模型系数的事后参数化，零解释力；且 TUFT 未给出 0.051 的 (a,e,M) 依赖闭式 ⇒ 不可外推到其它行星。
[    FAIL] D6-1   绝对步长有限差分：三个方向全废
           scipy 默认绝对步长 eps=1.49e-8 下的梯度相对误差 = β 1.000e+00 / V0 7.451e+09 / A 1.000e+00。β 与 A 方向的差分结果恰为 0（χ² 基数 8.37e+44 把 ~1e-7 量级的差分增量完全抵消），V0 方向则因步长相对参数大 1.5e+10 倍而爆炸 ⇒ 三个方向无一可用。
[BOUNDARY] D6-2   相对步长只救回一个方向：真正的病灶是抵消而非步长
           改用相对步长 h=1e-6·p 后相对误差 = β 1.00e+00 / V0 1.46e-10 / A 1.00e+00，只有 V0 方向恢复。逐方向动态范围 log10(χ² / |∂χ²/∂p_i|) = 44.2 / -18.3 / 33.5 个量级：V0 方向梯度本身比 χ² 基数还大（无抵消），β/A 方向则需从 8.37e+44 的 χ² 基数里分辨出 5.774 / 2.723e+11 的增量，超出 float64 的 ~16 位分辨能力 ⇒ 差分增量被吞掉、结果恰为 0。这不是步长选错，是抵消绝症：有限差分在此无解，解析导数（本册 / JAX AD）是唯一出路。
[BOUNDARY] D6-3   对目标 2 的最终答复
           V21 的动机「有限差分有噪声」是弱的；真实病灶是「χ² 基数与待提取导数之间的动态范围达 33~44 个量级」⇒ 差分增量被抵消吞没（绝对/相对步长皆然）。JAX AutoDiff 的价值正在于此：AD 不做差分、无抵消。本机无 JAX，改用 sympy 解析导数达成同一目标且精度更高（D1-1/D1-1b 验证到 1e-59 以下）。另需配合：优化与采样应在对数尺度进行（D5-1b、D7-1）。
[    FAIL] D7-1   walker 初始化尺度灾难
           p_best + 1e-4·randn 对 V0*=2.25e-38 施加的是 4.4e+33 倍相对扰动（对 A_topo* 是 8.7e+05 倍）；初始 χ² 中位数 = 1.523e+71，正参数 walker 比例 = 0.28。该初始化把 walker 抛到先验外的荒谬位置，MCMC 产生的不是后验而是初值漂移轨迹。
[BOUNDARY] D7-2   后验为「截断」高斯，非高斯
           似然是精确二次型（D1-2），但均匀正先验在 β 方向距 0 边界仅 1.70σ、A_topo 方向 3.96σ（仅 V0 方向 651σ 远离边界）⇒ 后验是被先验边界截断的高斯，偏斜不可忽略。
[    FAIL] D7-3   高斯协方差与 MCMC 后验不一致（截断效应，非采样问题）
           用 Cholesky(cov) 扰动初始化后（已排除 D7-1 的尺度灾难），MCMC 标准差与解析 σ 的相对偏差仍达 10.0% / 0.8% / 0.7%：距先验边界仅 1.70σ 的 β 方向偏差 10.0%，显著大于远离边界的方向（V0 651σ、A 3.96σ，偏差 ≤1.0% 属 MCMC 采样噪声量级）⇒ 均匀正先验下 Σ=2H⁻¹ 不是精确解，V21 用解析协方差报 1σ 在近边界参数上系统性偏大。
[BOUNDARY] D7-3b  诚实更正：V21「MCMC 比高斯近似更可靠」在本案成立（但理由不同）
           本册原预期反驳该论断（因似然为精确二次型），实测推翻了预期：先验边界截断使后验偏斜，MCMC 确实给出了高斯近似给不出的信息（β 方向 σ 相差 10.0%）。但机制是「先验边界截断」而非 V21 文档所称的「局部近似 vs 完整非线性后验」——本案似然恰为精确二次型，全部非线性来自先验而不来自模型。
[    INFO] D7-4   corner 图产出
           已保存（尺度修正版 MCMC）：tuft_v22_corner.png
[    FAIL] D8-1   贝叶斯因子不可定义
           拉普拉斯近似下 lnZ_TUFT 含 -Σln(先验宽度) 项：先验上界整体放大 10 倍，lnZ 下降 6.908（= 3·ln10 = 6.908）⇒ lnB(TUFT/GR) 可随任意先验选择连续平移。TUFT 未给出 β/V0/A_topo 的第一性先验范围 ⇒ 贝叶斯因子在本问题上是不可定义的量，候选 2 按原形态无法执行。
[BOUNDARY] D8-2   AIC/BIC 替代（水星+CMB 子集，N=4）
           TUFT(2 参) χ²=27.67 ⇒ AIC=31.67 / BIC=30.44；GR基准(0 参) χ²=46.27 ⇒ AIC=46.27 / BIC=46.27。ΔAIC=-14.60 偏好 TUFT，但该收益完全来自两个可调振幅吸收两个非零中心值——任何「带一个自由振幅」的模型对「B≡0 的稻草人基准」都会赢，不含 TUFT 物理内容。
[BOUNDARY] D8-3   全 6 点口径：数据集内部矛盾导致双输（ΔAIC 符号不可解读）
           以 Dirac 精细结构 (∝1/n³，n=2 校准) 为原子路基准：基准 χ²=325157.0(0 参) vs TUFT χ²=71103.2(3 参)，ΔAIC=-254047.8。两者都是天文数字且基准更差——但这不是 Dirac 被证伪，而是 §2 已证的数据与 1/n³ 标度矛盾（观测比值 2.232 vs Dirac 0.296）被计入 χ²。⇒ 在可疑数据集上做模型比较无意义，ΔAIC 的符号不代表任何物理结论。
[    FAIL] D9-1   金星/地球进动：不可预测
           V21 的 TUFT 修正是常数 delta=β·0.051，无 (半长轴 a, 偏心率 e, 中心质量 M) 依赖，TUFT 未给出 delta(a,e,M) 闭式 ⇒ 锁定 β 后对金星/地球不作任何预测。这不是「预言」而是「无模型」。
[    FAIL] D9-2   n=4,5,6 精细结构：偏差 1~2 量级
           锁定参数后 TUFT 预测恒为 E=1.5619e-04 eV（对 n 零依赖，见 D3-1）；Dirac 标度 (∝1/n³) 给 5.664e-06 / 2.900e-06 / 1.678e-06 ⇒ 偏差 28× / 54× / 93×。
[    FAIL] D9-3   其它 ℓ 的 CMB 双谱：外推与观测趋势背离且走向相反
           锁定 A_topo 后 TUFT 预测 B(500)=9.232e-19、B(3000)=4.274e-21；按观测自身幂律指数 +1.300 外推为 3.452e-20 / 3.545e-19 ⇒ 比值 26.7× / 0.0121×（后者即低估 83×），随 ℓ 走向与观测相反。
[    FAIL] D9-4   M87*/SgrA* 光子环：不可预测
           TUFT 未给出 σ_abs=0 体的具体度规与表面反射系数（R20/R21/R22 已如实标注），光子环位置/宽度需光线追迹所用度规 ⇒ 当前 TUFT 无法生成该预言。
[    FAIL] D10-1  V21 三路拟合不构成对 TUFT 的检验
           综合 §2(两路数据不可信) + §3(形状/挠率不可辨识) + §4(参数解耦) + §5(χ²/dof≈23701)：该拟合既不是对数据的好拟合，也不是对 TUFT 的检验——三个模型形式(β·0.051 / V0+n²ħ²/Ntop² / A·cos(τℓ̄)/ℓ³) 中未出现任何 TUFT 第一性量(κ, τ, Ω, Lk, W, 结类型)，属贴标签式的唯象拟形；250 位精度常数在本链路中未被任何一步使用（计算全程 float64），属精度剧场。
[BOUNDARY] D10-2  下一步的正确排序
           ① 先让参数跨探针共享（同一 β/τ 同时进水星·原子·CMB），否则「联合」永远零判别力；② 再把三个唯象形式替换为从 TUFT 第一性量导出的闭式；③ 之后贝叶斯因子才可能定义（先验有了第一性范围），AIC/BIC 才有意义；④ 在此之前，加观测组(候选1)与画图(候选3)都不产生科学增量。
