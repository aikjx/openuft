# 第17章 全域量纲系统与物理常数归约

## 17.1 导读

【 **大白话** :物理方程必须有量纲自洽——等式两边的"单位"必须对得上。本章把整个理论放进一把统一尺子：自然单位 $c = \hbar = 1$ 下，一切物理量的量纲都化成一个数——长度 $\ell$ 的幂次。做完之后发现三件实事：① 全部物理常数在 $\ell$ 幂次谱上排成整齐的序列；② 量纲分析抓到并修正了此前参数归约的一处笔误（$\kappa$ 本来无量纲）；③ 常数个数多于参数个数——所以常数之间存在可检验的比例关系。这就是"量纲系统化"的价值：不是装饰，是质检。】

## 17.2 量纲公理与统一标尺

【 **量纲公理（自然单位）** :约定 $c = 1$、$\hbar = 1$（光速与约化普朗克常数为纯数）。在此约定下：

$$L \cong \ell,\qquad T \cong \ell,\qquad M \cong \ell^{-1}$$

长度、时间、质量全部折算为长度幂——时间是长度、质量是长度倒数。任何物理量 $X$ 的量纲唯一地写作 $[X] = \ell^{n}$。】

【 **为什么可行** :$c$ 把时间换成长度（$t = x/c$），$\hbar$ 把质量换成长度倒数（$m \sim \hbar/L$）。两个常数做"单位转换器"，不做物理输入——物理内容全部留在 $\ell$ 的幂次谱里。】

【 **大白话** :不是"长度很重要"，而是"只有长度是尺子，其他都是长度换了个说法"。对偶公理的"最短尺度 $\ell$"因此成为量纲的原点——理论内部只有一把尺。】

## 17.4 量纲分析抓到的修正

【 **修正记录（重要）** :此前参数归并写作 $\kappa = \tilde{\kappa}\,\ell^{-2}$。量纲分析判它错：有效势 $V = \kappa\left( |\Psi|^{2} - v^{2} \right)^{2}$ 中，能量密度 $[V] = \ell^{-4}$，括号 $|\Psi|^{2} - v^{2}$ 量纲 $\ell^{-2}$（因 $v^{2}$ 与 $|\Psi|^{2}$ 同类），平方后 $\ell^{-4}$——故 $[\kappa] = \ell^{-4}/\ell^{-4} = \ell^{0}$。**$\kappa$ 直接无量纲，$\kappa = \tilde{\kappa}$。** 已同步修正总纲、报告、附录A。】

【 **自洽检验（验证B）** :$m_{H}^{2} = 8\kappa v^{2}$ 量纲 $\ell^{-2}$ ✓（$m_{H}$ 是质量）；随机三组参数下"谱闭式 $m_{H} = \sqrt{8\kappa v^{2}}$"与"公式 $m_{H} = 2\sqrt{2}\sqrt{\tilde{\kappa}}/\ell$"机器一致（差 $0$ / $2.2 \times 10^{-16}$）。量纲修正后方程完全自洽。】

【 **方法论注记** :这不是"理论错了"，而是"账本记错了"——量纲系统化把它抓了出来。这正是本书承诺的第二裁判：每一处可数的地方都用数检验。】

## 17.5 常数归约与可检验比例

【 **定理 17.1（常数归约，V1.3.1 统一口径）** :在 $\left\{ \tilde{g}, \tilde{g}', \tilde{\kappa}, \ell \right\}$ 基下（生成元取 $\tau/2$ 归一化，与第21章验证D一致），全部物理常数写为：

$$m_{H} = \frac{2\sqrt{2}\sqrt{\tilde{\kappa}}}{\ell}, \qquad m_{W} = \frac{\tilde{g}}{2\ell}, \qquad m_{Z} = \frac{\sqrt{\tilde{g}^{2} + \tilde{g}'^{2}}}{2\ell} = \frac{m_{W}}{\cos\theta_{W}}, \qquad \alpha = \frac{\tilde{g}^{2}\sin^{2}\theta_{W}}{4\pi}$$

其中 $\tan\theta_{W} = \tilde{g}'/\tilde{g}$，$e = \tilde{g}\sin\theta_{W} = \tilde{g}'\cos\theta_{W}$。$\ell$ 只定标度，物理由三个无量纲参数 $\left\{ \tilde{g}, \tilde{g}', \tilde{\kappa} \right\}$ 决定。】

【 **定理 17.2（比例可检验，V1.3.1 修正）** :质量比与标度无关：

$$\frac{m_{H}}{m_{W}} = \frac{4\sqrt{2}\sqrt{\tilde{\kappa}}}{\tilde{g}}, \qquad \frac{m_{Z}}{m_{W}} = \sqrt{1 + \frac{\tilde{g}'^{2}}{\tilde{g}^{2}}} = \frac{1}{\cos\theta_{W}}$$

（V1.3.1 勘误：此前写作 $m_{H}/m_{W} = 2\sqrt{2}\sqrt{\tilde{\kappa}}/\tilde{g}$，系生成元归一化取 $\tau$ 而非 $\tau/2$ 所致；统一到 $\tau/2$ 口径后因子为 $4\sqrt{2}$。比例形式与可检验性不变，因子由约定决定。）例：$\tilde{g} = 0.3, \tilde{\kappa} = 0.5 \Rightarrow m_{H}/m_{W} = 13.33$；$\tilde{g} = 0.5, \tilde{\kappa} = 0.5 \Rightarrow 8.00$（与第21章示例一致）。实验测出 $m_{H}/m_{W}$ 即定出 $\tilde{g}/\sqrt{\tilde{\kappa}}$——这是理论对"常数关联"的可检验承诺。】

【 **大白话** :参数只有两个，常数有一堆——多余的关系不是巧合，是理论说"这些常数其实是一个数的不同投影"。比例就是理论的指纹。】

## 17.6 未归约项（诚实边界）
