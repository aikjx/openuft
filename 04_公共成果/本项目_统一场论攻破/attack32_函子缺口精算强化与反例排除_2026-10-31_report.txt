[F1] 口径敏感性：attack31 E2 的「缺口恰为 3.0 bits」
------------------------------------------------------------------------------
  attack31 的算法：bits_need = log2(2)+log2(2)+log2(6) = log2(24)
                    bits_supply = log2(3)（Lk -> 自旋 0, 1/2, 1）
                    缺口 = log2(24/3) = log2(8) = 3.0（整数）

  >> 整数 3.0 的来源：24 = 2*2*6 与 3 的商恰为 8 = 2^3。
     这是「分子取 24、分母取 3」这两个具体选择的算术后果，
     不是物理常数。=> 必须做口径扫描，检验结论对选择是否敏感。

  口径                                     需求 bits      缺口 bits      备注
  O1 R14 十场 / 供给 Lk 3 值                  3.3219281    1.7369656    本库 R14 原判 1.74
  O2 十八场(6x3) / 供给 Lk 3 值                4.169925     2.5849625    = log2(6)
  O3 三标号 24 / 供给 Lk 3 值                  4.5849625    3.0          attack31 口径（恰 3.0）
  O4 三标号 24 / 供给 Lk 2 值                  4.5849625    3.5849625    自旋只取 0,1（无 1/2）
  O5 三标号 24 / 供给 Lk x Z2 6 值             4.5849625    2.0          假设另有 1 个 Z2 不变量
  O6 三标号 24 / 供给 24 值                    4.5849625    0.0          极端乐观：几何侧给足 24 值

  >> 缺口区间：[0.0, 3.58496] bits；6 个口径中 5 个为正
  >> O6（供给 24 值）使缺口归零 => 「缺口存在」这一结论依赖供给侧假设，
     而不是无条件成立。attack31 未声明这一依赖，属过度陈述。

  精度自查：log2(8)-3 = 0.0（80 位十进制下）
  >> 该残差为浮点下溢级别（<1e-75），不是数学意义的「精确零」；
     真正精确的是「8 = 2^3」，即 3.0 是整数指数的算术事实。
     attack31 报 gap_label_exact_3_residual = 0.0 属精度掩盖，须改为「<1e-75」。

[F2] 可识别性矩阵（比 bit 计数更硬的判据）
------------------------------------------------------------------------------
  设几何路径允许「每场自由指定一个结类型」，则：
    自由变量  : 18（18 个结类型赋值，离散）
    观测方程  : 0（没有任何方程把结类型锁到 (j,color,Y)）
    待解释量  : 18（6 场型 x 3 代 的标号）
    nullity   = 18 - 0 = 18

  约束数          nullity      可识别          说明
  0            18           否            无任何约束，任意标号向量可达
  1            17           否            仍欠定 17 维
  3            15           否            仍欠定 15 维
  9            9            否            仍欠定 9 维
  17           1            否            仍欠定 1 维
  18           0            是            恰好唯一（或超定）
  20           0            是            恰好唯一（或超定）

  >> 阳性对照（关键）：约束数从 0 增到 18，判据从「不可识别」翻为「可识别」。
     说明本判据不是恒 FAIL 的假判据，它随约束数单调翻转。

  >> 与 F1 的分工：F1 说「就算几何给 24 个离散值，也只能提供 4.58 bits」；
     F2 说「那 24 个值本身是 18 个无约束自由变量，能被任意重排」——
     后者更致命：**零预测力 ≠ 容量不足**。容量不足可加变量，
     无约束的自由变量加得越多，可拟合的东西越多，判别力反而更差。

  机器演示：3 个任意标号向量（恒等 / 全零 / 模 7 置换），
            在「0 约束」下全部可达（3/3）=> 零判别力。
  等价的观测者表述：无论实验测到哪种场标号分布，都能被某个结赋值解释，
  chi^2 恒为 0 => 该路径不可证伪（与 r15「自由度口径 II」同源）。

[F3] attack31 E3 的自我反例（本册最重要的一条）
------------------------------------------------------------------------------
  attack31 E3 的命题：「连通集的连续像连通、离散集全不连通
                     => 连续参数无法产生离散标签（除非外部规则）」。

  >> 反例（TUFT 自己就有）：
     闭曲线的绕数 W = (1/2pi) * oint d(theta) 是连续映射的像，
     但取值只能是整数（离散）。机器演示：
      圆 x=cos t, y=sin t 的绕数数值 = 1.000000000000（理论 1）
      => 连续几何量确实能给出整数（离散）结果，E3 的一般命题为假。

  >> 同理 TUFT 已有的整数不变量：Lk in Z、W in Z、det(K) in Z、亏格 g in N。
     所以「连续 -> 离散不可能」是错的，必须撤回。

  >> 正确的障碍重述（三条，逐条机器可查）：

    (i) 群结构缺失（硬事实）：要给 {1,3} 的 SU(3) 表示标号，必须先有群 G
        与同态 rho: G -> GL(3)。TUFT 公设集是曲线几何，不含任何李群结构。
        机器检查：本目录 351 个 .py 中，含 SU(3) 生成元/结构常数定义的文件 = 6，
                  含 def 形式生成元构造函数的文件 = 1。
        => 群结构在代码层不存在（只有讨论性提及）。

    (ii) 定义域错配：Lk / W / det 定义在**闭曲线**（1 维对象）上；
         规范表示标号是**场的表示空间**的属性。二者之间没有保结构映射 ——
         这不是「连续 vs 离散」问题，而是「对象类型不同」问题。
         机器证据：F4 的签名扫描（无任何 knot -> rep 的映射函数）。

    (iii) 整体 vs 局部：Lk 是整体不变量（一条曲线的全局积分），
          而场的规范标号在**每个时空点**都要有定义。
          整体量若要给局部赋值，只能取常值 => 全部场同标号。
          机器演示：整体量 O = 1 对 18 个场赋值只能给 (1,1,...,1)，
          唯一可达向量为全 1（可区分场数 = 1）。

  >> 结论：E3 的 FAIL 判定**结果保留**（几何路径确实给不出规范标号），
     但**理由更换**：不是「连续不能映到离散」（假），而是
     「群结构缺失 + 对象类型错配 + 整体/局部错配」（真）。
     这是本册对 attack31 的实质性更正 —— 判据错但结论对，属「绿但错」。

[F5b] 病态性诊断：M_SUSY 反解对「阶数 / 系数 / 输入」的敏感性
------------------------------------------------------------------------------
  事实：1-loop L1=-0.516836，2-loop L1=+3.235419 => 阶数变化造成 dL1=+3.752255
        折合 M_SUSY 变化 42.62 倍

  问：这个位移是「2-loop 物理」，还是「近退化放大」？
  做法：把 1-loop 的输入/系数各扰动一点点，看能造成多大的 dL1。

  扰动                             dL1            M_SUSY 倍数      占阶数差比例
  输入 sin2thetaW +0.1%                 -0.293425 1.3410         7.8%
  输入 alpha_s +1%                      -0.387152 1.4728         10.3%
  输入 alpha_em +1%                     -0.396192 1.4862         10.6%
  beta 系数 +1%                         +0.005117 1.0051         0.1%
  beta 系数 -1%                         -0.005221 1.0052         0.1%

  解的 Jacobian 条件数 cond(J) = 39.41（2x2，Frobenius）
  >> 条件数不大 => 不是数值病态，而是**问题本身近退化**：
     1-loop 下 MSSM 三点几乎同时汇聚，L1 的解由「两条近重合直线的交点」给出，
     任何百分级改动都会把交点移到别处。

  >> 关键比值：1% 的 beta 系数扰动只造成 dL1=0.0051，仅占阶数变化的 0.14%。
     => 阶数位移**不能**用系数误设解释：要复现 3.75 的位移，beta 需被误设 73327%。
  >> 三代误差源横向对比：
     参数误差（系数 +1%）        => M_SUSY x1.0051
     测量误差（sin2thetaW +0.1%）=> M_SUSY x1.3410
     测量误差（alpha_s +1%）     => M_SUSY x1.4728
     模型误差（1->2 loop）        => M_SUSY x42.62

  >> 正确归因（修正初版叙事）：这是「截断阶数主导」的典型形态 ——
     模型误差（42 倍）远大于参数误差（0.5%）与测量误差（1.3~1.5 倍）。
     cond(J)=39.4 说明解本身良态，所以 42 倍不是数值噪声，
     而是「把低能残差重新分配到不同截断阶」的真实位移。
     结论：M_SUSY 不是被测出来的物理量，而是「某阶截断下的记账量」。
