## 0 本册的准确定位（先划红线）

**本册不宣称「ROOT 已被否证」。** 一个几何概念无法被否证——它只能**失去内容**。本册的工作是：在 V4.0 自己给出的前提内，把「空间光速螺旋作为光子实体运动」的**全部六条出路**逐一处理，对每一条给出下列三种结局之一：

| 结局 | 含义 |
|---|---|
| **封死** | 在 V4.0 自身前提下导出与观测/自身矛盾的后果 |
| **空洞** | 不与任何观测冲突，但与 Maxwell 完全等价，零新增物理内容 |
| **退出** | 主张者通过「不可观测」使命题脱离可检验范围；**这不是被否证，而是自动放弃科学地位** |

红线：**数学自洽 ≠ 实验证实**；本册是可算判决，不产生新物理。本册属 openuft S15 独立登记，**不占用**另一仓库（`本项目_全维自洽与归一化`）的 r 系列度数链。

## 2 核心新判据：速度—角动量夹逼（K 组）

这是本册最强的一条，也是唯一一条**不依赖如何取值即可下结论**的判据。

### 2.1 两条反向的界

记 `ω_h = α·c/λ`（文档取 α=1.2），俯仰角 θ，`sinθ = v⊥/c`：

| 界 | 来源 | 表达式 | θ 变小时的走向 |
|---|---|---|---|
| **速度侧上界** | `v⊥ = R·ω_h` | `R = λ·sinθ/α` | **R ↓** |
| **角动量侧下界** | `L_z = R·(E/c)·sinθ = ℏ` | `R = (λ/2π)/sinθ` | **R ↑** |

两条界对 `sinθ` 的走向**相反**，因此构成夹逼。相容条件：

```
λ·s/α ≥ (λ/2π)/s   ⇔   s² ≥ α/(2π)      (s ≡ sinθ)
```

### 2.2 结论：光只能以不到九成的 c 沿轴前进

代入文档的 α=1.2：

| 量 | 机器读数 |
|---|---|
| 相容条件 `sin²θ ≥ α/(2π)` | **0.1909859** |
| ⇒ `sinθ ≥` | 0.4370200 |
| ⇒ **轴向速度上界 `u/c ≤`** | **0.8994521** |
| ⇒ **轴向亏损下界 `ε_min =`** | **10.0548%** |
| 边界处速度侧 R | 200.3005 nm |
| 边界处 AM 侧 R | 200.3005 nm |
| **两界相等（互证）** | **残差严格 0** ✓ |
| 该亏损对应每米延迟 | **372.89 ps** |

> **判据：只要要求螺旋承担光子的 ℏ，且沿用文档自己的 `ω_h=1.2c/λ`，光沿轴的速度就必然 ≤ 89.945% c。**
> 换句话说，**「螺旋承担自旋」与「光以 c 传播」不可兼得**——两者至少必须让出一个 10.05% 的轴向亏损。

### 2.3 阶梯表：允许亏损越小，冲突越不可收拾

| 允许轴向亏损 ε | 速度侧 `R ≤` | AM 侧 `R ≥` | 冲突倍率 |
|---|---|---|---|
| 1e-2 | 64.656 nm | 620.5 nm | **9.60×** |
| 1e-3 | 20.492 nm | 1.9578 μm | **95.5×** |
| 1e-6 | 0.64818 nm | 61.897 μm | **9.55×10⁴** |
| 1e-8 | 0.064818 nm | 618.97 μm | **9.55×10⁶** |
| 1e-9 | 0.020497 nm | **1.9573 mm** | **9.55×10⁷** |

读法：若坚持螺旋承担 ℏ 又要求光速偏差小于 1e-9，则可见光的螺旋半径**至少要有 1.96 毫米**、螺距数百米——而文档自己的 §6 还要求 `R ≤ λ/2π = 87.5352 nm`，二者相差 **2.24×10⁴ 倍**。

### 2.4 控制组（证明判据不是恒等式）

| 控制组 | 预期 | 实测 | 判定 |
|---|---|---|---|
| `α=2π`（即 `ω_h=ω_EM`） | 应退化为 `u/c=0`，与 G3 一致 | **0**（严格） | ✓ 互证 |
| `α=4π` | 相容条件 `sin²θ ≥ 2` > 1 ⇒ **无解** | **2.000** | ✓ |

第一条尤其重要：K 组用一条**完全独立**的推导路径重现了 G 组的 `u=0` 结论，两条路径互为交叉验证。

### 2.5 关于 SI 循环性的诚实标注（必须写明）

一个**与波长无关**的轴向亏损，在 SI 中存在约定性：米本身由 `c` 定义，故「光跑得多快」在绝对意义上不能被直接测量，只能通过**光基计量 vs 物质基计量**的比对（如硅晶格 XRCD 与光学干涉比对，一致到 ~1e-8 量级）来检验。

- 文档取 `R ∝ λ`、`ω_h ∝ c/λ` ⇒ `v⊥ = R·ω_h = 0.42c` **与波长无关** ⇒ 亏损无色散 ⇒ **恰好落在这一约定性区间内**。这一点必须如实登记，不能假装约束比实际更强。
- 但 **§2.2 的结论不受此影响**：10.05% 的亏损比物质基计量的一致水平（~1e-8）高出约 **7 个数量级**，任何计量学比对都会立刻看到。因此 R5/R2 的封口是**实质**的，不依赖约定。
- 阶梯表（§2.3）则应读作**条件式**：「若允许亏损为 ε，则冲突倍率为…」，其用途是显示**该理论每向实验靠近一步，参数就被逼得越荒谬**。

## 3 逐路封口详述

### R1「只保留场螺旋几何」——空洞

圆偏振的电场方向旋转确实画出螺旋图样，`|S|/w_EM = c` 严格沿轴（F 组残差 2.17e-14，受限于 `ε₀μ₀c²−1 = −4.35e-14` 的 SI 常数自身精度）。但这一层完全在 Maxwell 内成立。

**判定：空洞。** 保留它等于承认 ROOT 在这一层没有超出 Maxwell 的内容。文档第十节自己走的就是这条路。

### R2「调小 θ 以拟合群时延」——封死

Giovannini 2015 的轴向延迟，标准解释是**倾斜直线**（`k_z<k`）。螺旋给出 `u=c·cosθ`，倾斜直线给出 `v_gz = c·cosγ`——**同一个函数形式**。

- H1：两模型对 `u/c` 的预测差 **严格为 0** ⇒ 该观测量对 κ≠0 vs κ=0 **零判别力**。
- 更致命的是自我移除：θ→0 时 `R = c·sinθ/ω_h → 0`、`κ = (ω/c)sinθ → 0`，**螺旋退化为直线**。也就是说，**该理论越与实验一致，它自己就越不存在**。

### R3「引入新动力学」——封死（代价极高）

要让 `κ≠0` 的曲线成为平直真空的自由光线，必须修改 Maxwell 或 SR。代价：
1. 必须解释为何真空中从未观测到 J 组预言的边带（文档自取参数下为 **461.8 nm / 679.8 nm**，双双落在可见光波段）；
2. 必须同时满足 LHAASO 对能量依赖速度修正的严格约束，以及 GW170817 类对引力波与光速比的约束（~1e-15 量级）；
3. 必须解释真空的各向同性如何挑选螺旋轴（真空本身无法选轴，轴只能来自源的几何 ⇒ 又回到标准结构光物理，即 R1）。

**判定：封死。** 未被逻辑排除，但所需修改与全部现有约束的兼容空间极小，且未有任何具体机制被提出。

### R4「声明不可观测」——退出

若主张横向位移不与电磁场耦合、因而不可观测，则该命题**按定义不属于可检验物理**。这不是被否证，而是自动放弃科学地位。登记为**退出**而非**封死**，以示区别。

### R5「取 ω_h = ω_EM」——封死

G 组与 K 组两条独立路径导出同一结论：`u/c = 0`（G3 残差 1.4e-30；K12 严格 0）。光原地打圈，不前进。

### R6「取 ω_h ≠ ω_EM」——封死 / 退回 R4

物体的转动频率与它的辐射频率不相等，且无动力学给出二者关系 ⇒ 必产生边带 `ω_EM ± ω_h`。文档自取 `ω_h=1.2c/λ` 时 `f_h = 104.1021 THz`，边带落在 **461.8023 nm** 与 **679.8398 nm**。若辩称「横向运动不耦合」，则退回 R4。

## 4 尚存的三个开放项（诚实标注）

| 项 | 内容 | 为何不能封死 |
|---|---|---|
| **O-A** | SI 约定性（§2.5） | 与波长无关的亏损在 SI 内存在约定空间；只能靠物质基计量比对，约束远弱于色散类约束 |
| **O-B** | 耦合前提未定 | 「横向振荡是否耦合电磁场」未被 V4.0 回答；这决定了 R3/R6 是**封死**还是**退回 R4** |
| **O-C** | 概念本身不可否证 | 若主张者不断把 R、ω_h 重定义为不可测量，命题就永远滑出检验范围。**这是方法论问题，不是物理结论** |

## 5 攻破结论

在 V4.0 自设前提下，六条出路的结果为：**空洞 1 条（R1）、封死 4 条（R2/R3/R5/R6）、退出 1 条（R4）**，无一通往新物理。其中最具约束力的一条是：

> **「螺旋承担自旋 ℏ」与「光以 c 传播」不可兼得——沿用文档自己的参数，前者强制轴向亏损 ≥ 10.0548%（即光最多以 89.945% c 沿轴前进，每米延迟 ≥ 372.89 ps）。**

同时应当记载：V4.0 在第八、十两节主动承认第三层未建立，未用绝对化措辞捍卫自己。这份诚实不改变裁定，但在同母题来源普遍宣称「万物统一」的背景下，应予明确记录。

体系状态维持 **`candidate_theory / unreviewed`**，不上调。
