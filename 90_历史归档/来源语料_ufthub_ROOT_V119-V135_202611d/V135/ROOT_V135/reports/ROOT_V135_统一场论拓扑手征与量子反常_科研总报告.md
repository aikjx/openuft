> 本报告承接 ROOT V132–V134。全部理论单位只约定 **c=1**，保留 **ℏ、G、ε₀** 的实际量纲，不暗中令它们为 1。离散代码只在链接变量中使用无量纲角度 `q∫A/ℏ`，这不是将 ℏ 设为 1。所有图和数据均为数学模型输出，不是粒子实验。

## 摘要

V134 从单个内部圆周的 Abelian 相位升级到了非阿贝尔的联络、场强与守恒荷，但没有推出真实的手征粒子。本轮选择严格的低维数学试验场：六维乘积时空 `M4×Σ2`，其中 `Σ2` 为紧致二维定向 spin 流形，其上存在 `U(1)` 规范线丛。利用带电 Dirac 算符、Atiyah–Singer 指数公式及 2D Wilson–Dirac/overlap 晶格算符，验证**内部磁通量与四维净手征零模之间的拓扑关系**。还证明两个直接的限制：**(a) 由全局单值纯螺旋相位生成的平坦联络无法制造非零通量；(b) 所有 6D 母场同一手征性、仅靠一个共同 Abelian 通量产生 4D 手征性的最简模型，会产生不能自动抵消的 Abelian 规范反常。** 这些限制表明几何可以参与解释量子谱的部分结构，却不能单独完成四力统一。

## 1. 物理与数学对象的严格区分

- 曲线曲率 `κ` 与挠率 `τ`：一条 1D 曲线的局部运动学信息。
- 内部角相位 `θ`：`S¹` 上的变量，给出可能的相位联络。
- 局域规范势 `A_m`：内部复线丛的局部联络形式，可在不同图册之间拼接。
- 场强 `F=dA`：规范联络的曲率；**局部**公式可写 `dA`，但对非平凡线丛未必存在全局单值的 `A`。
- `N=(q0/(2πℏ))∫ΣF∈ℤ`：规范线丛的第一 Chern 数，依赖全局拓扑；这里 `q0` 是规定的单位荷。
- `ind(D_Σ^+)`：正手征核与负手征核的**差**，不等于所有零模数。

它们不是一个物理量。特别是 `κ、τ` 的一个代数封装并没有自动指定内禀紧致曲面的 `N`。

## 2. 为什么要从 4D 增加二维内部空间？

这是被**提出**的建模选择，不是观测证明。考虑 `M6 = M4 × Σ2` 和具有六维确定手征性的自旋场。适当的乘积度规与静态背景中，六维 Dirac 算符可以分解为：

`D6 ≃ D4 ⊗ 1 + γ5^(4) ⊗ DΣ`（具体 Clifford 约定有符号调整）。

若 `DΣ χ_j=0`，则对应的四维模式没有由内部 Dirac 非零本征值产生的 KK 质量。六维手征性把四维手征与二维内部手征联系起来：因此内部净手征指标成为四维净手征谱的计数器。要做成真实粒子理论，还需规范表示、Yukawa 耦合、完整 Dirac 作用量与 6D/4D 反常一致性。

## 3. 核心拓扑指标定理：非自由参数的整数约束

对紧致无边界定向 **spin** 曲面 `Σ` 上与复线丛 `L^q` 耦合的二维 Dirac 算符：

`ind DΣ^+ = ∫Σ Â(TΣ) ch(L^q)|₂ = (q/(2πℏ)) ∫ΣF = qN`。

此处 `q` 是以单位荷 `q0` 计的**整数权**，而 `F` 的归一化采用该单位荷下的联络；若直接写实际电荷 `Q=q q0`，则是 `Q∫F/(2πℏ)`。这一式依赖 Atiyah–Singer 已有定理，不是凭 ROOT 螺旋公设独立新证。

严格能够推出的是 `n_+−n_−=qN`（符号由定向、γ 手征约定决定）。当 `qN≠0` 时，必有至少 `|qN|` 个内部零模。不能只由指标判断是否额外存在成对的正负手征零模。

### 3.1 实测“三代”的条件性尝试

如果 `q=1,N=3`，那么净手征指标是 3。在均匀磁通环面、适当单一费米场表示的具体情况下可以出现恰好 3 个同手征零模。可是 `N=3` 本身作为一个**背景整数被输入**，既未从曲率/挠率推出，也未推导三代粒子质量。因此这不是三代起源的无参数证明。

## 4. 全局纯相位不能产生拓扑通量：一个严格障碍

如果所谓内部螺旋仅由一个**全局光滑单值**的实标量 `θ` 给出 `A=dθ`，则 `F=dA=d²θ=0`，所以 `∫ΣF=0`、`N=0`、`ind D^+=0`。

即便 `A` 是全球定义的一形式，但不是纯梯度，若 `F=dA` 在闭曲面上是全局正合二形式，则 `∫ΣF=∫ΣdA=0`（Stokes）。因此非零第一 Chern 数要求非平凡拼接线丛、非全局单值的联络表示或额外全局拓扑数据。

**重要限制**：真正在弯曲流形上的法标架自旋联络或法丛联络可能有非零曲率；不能把全部几何联络都笼统归为 `dθ`。但是要声称它产生某个 `N`，就必须明确给出曲面、丛、过渡函数与积分后的整数，而不是仅列出局部螺旋曲率 `κ` 与挠率 `τ`。

## 5. 正曲率零模禁戒：没有规范通量的 S²

对于无规范扭曲的紧致 spin 曲面，Schrödinger–Lichnerowicz 恒等式为：

`D² = ∇*∇ + R/4`。

如果曲面标量曲率 `R>0`，一个零模 `Dψ=0` 必须满足

`0=∫(|∇ψ|² + (R/4)|ψ|²)`，从而 `ψ=0`。

标准圆球 `S²` 半径 `a` 时 `R=2/a²>0`，故无通量时不能依靠球面正曲率本身得到这类零模。带规范线丛的 Dirac 平方含有额外规范曲率 Clifford 项，可以改变这个结论。这说明**有几何曲率**与**有净手征零模**不是同一命题。

## 6. 晶格数值实现：如何真正计算指标

选取 `L×L` 周期晶格和量子化总通量 `N`，建立链变量

`U_x(x,y)=exp[−2π i N y/L²]`，

`U_y(x,y)=1 (y≠L−1)`，`U_y(x,L−1)=exp[2π i N x/L]`。

每个基本 plaquette 的相位在主支内约为 `2πN/L²`，`N=(1/(2π))Σ arg P`。

在 `r=1, 0<m0<2` 的合适区间，用二维 Pauli 矩阵构造 Wilson 算符 `D_W(−m0)`，令 `H_W=γ5D_W`。再计算

`νov=−½ Tr sign(H_W)`，以及 `Dov=I+γ5 sign(H_W)`。

本报告的晶格 `γ5` 和环面方向给出 `νov=−N`；**负号仅表示约定**，不能把正负符号差误写成物理失败。只有在核谱不穿越零、场足够光滑及对该离散化有效的条件下，数值指标才稳定。

|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|

当 `N=0` 时，在所选周期 spin 结构下有正、负各一个零模，指标为零。这是 `指标 ≠ 零模总数` 的直接反例。

## 7. 更强的量子一致性限制：单一六维手征源的 U(1) 反常

做一个前提极为明确的最简模型：

1. 所有六维母场是**同一六维手征方向**；
2. 只用一个共同内部 `U(1)` 背景，通量为固定的 `N≠0`；
3. 第 i 个母场具有整数归一化的荷 `q_i`，规范表示的额外正整数简并为 `d_i`；
4. 四维谱仅由内部 Dirac 净指标决定，不额外引入相反 6D 手征扇区、局域零模、反常流入或 Green–Schwarz 等抵消机制。

以共同六维手征符号 `s6=±1` 表示从内部指标到四维净手征的关系，则

`I_i = s6 N q_i`。

四维 `U(1)^3` 规范反常系数正比于

`A_YYY = Σ_i d_i I_i q_i³ = s6 N Σ_i d_i q_i⁴`。

四维混合引力–U(1) 反常系数正比于

`A_grav,Y = Σ_i d_i I_i q_i = s6 N Σ_i d_i q_i²`。

**结论（条件性 no-go）**：由于 `d_i>0` 且 `q_i⁴`、`q_i²` 非负，只要至少有一个带电母场，且 `N≠0`，这两个和就不可能自动为零。单一共同通量和同一六维手征的这种极简方案不能单独构成无反常的四维规范理论。

这是对**已定义模型类别**的代数排除，并非对磁通紧致化、SO(10)、弦理论或所有 ROOT 扩展模型的排除。添加另一 6D 手征、多重线丛、异常流入等可改变结论，但会引入新的机制并需独立核验。

|---|---:|---:|---:|
| Q_L | 1 | 6 | 3 |

根据这些条件，`Σ d_i q_i² =120`，`Σ d_i q_i⁴ =2280`。选 N=3，得到反常诊断量 `A_grav,Y∝360`、`A_YYY∝6840`（差一个共同的符号 `s6`）。这并不是在重新计算**真实标准模型一代**的反常：真实标准模型手征谱有确定的左右分配，反常能够抵消；这里是在显示本轮极简紧致化机理错误地生成了不同的左右指数。

## 8. 这与 ROOT 空间螺旋的关联在哪里？

可以研究一个**候选**内部联络组合：

`A_int = dθ + Ω_⊥ + A_gauge`，

其中 `Ω_⊥` 是经过精确定义的法丛或其它内部几何联络；`A_gauge` 是独立可具有非零曲率的规范联络。规范变换可以让局部表示改变而物理曲率不变。

但是：

- `κ、τ` 是 1D 曲线局部不变量；2D Chern 数 N 是全局整数，不可直接从 1D 局部恒等式推出。
- 纯螺旋角度的 `dθ` 不能产生非零通量。
- 一个非平凡法丛的全局拓扑**可能**贡献量子数，但需要明确度规、丛拓扑和粒子表示；目前 ROOT 没有给出这些。
- 即便得到了 N=3，仍没有生成标准模型全部手征表示，也没有预测 α、ℏ 或 G。

本轮的「突破」准确说是：找到了能够将内部几何拓扑与量子手征谱**形式上连接**的明确数学门槛，并证明一个最简单候选机制必然失败。

## 9. 引力耦合：紧致化只给比例关系，不预测 G

对于未扭曲、无 warp 的 `M4×Σ2`，假设内部体积 `V2` 不依赖四维坐标，则六维 Einstein–Hilbert 项

`S_EH^(6)=1/(16πG6)∫ d⁶x √|g6| R6`

积分内部坐标后，四维 R4 的系数满足

`1/G4 = V2/G6`，即 `G4=G6/V2`。

这说明内部体积影响有效引力强度，但 **G6 与 V2 仍是输入**；不能因量纲或数值关系就声称独立推导了引力常数。若内部 gauge 场是 bulk 场，类似地会出现体积对规范动力学前因子的影响，仍然需指定高维耦合和规范归一化。

此外，保持 `c=1`，量子相位仍然是 `exp(iS/ℏ)`，精细结构常数仍为 `α=e²/(4πε₀ℏ)`。拓扑整数 N 没有确定连续参数 α。

## 10. 为何尚不能统一四种相互作用

四力统一要求至少：

1. 唯一明确的 Lorentz / diffeo 协变作用量，其场方程产生观测到的引力低能极限；
2. `SU(3)×SU(2)×U(1)` 正确规范表示、三代手征谱、Higgs 与质量混合；
3. 无局域规范异常及无致命全局异常，高维及低维都需检查；
4. 重整化、量子一致性或严格控制的有效理论，能够处理引力与高能紫外行为；
5. 没有用观测值回填自由参数的独立数值预言，并能同质子寿命、粒子实验、GPS/GR/引力波及第五力观测相容。

本轮只推进了其中第 2、3 项的候选验证方法，其它大部分仍 OPEN。
