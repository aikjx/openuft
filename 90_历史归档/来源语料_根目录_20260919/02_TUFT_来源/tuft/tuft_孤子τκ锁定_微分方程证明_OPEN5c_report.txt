== 1. 稳态条件与公理 A 的等价性 ==
  公理 A : κ² + τ² = Ω²
  稳态   : κ∇_μκ + τ∇_μτ = 0
  d/ds(κ²+τ²−Ω²) = 2*kappa(s)*Derivative(kappa(s), s) + 2*tau(s)*Derivative(tau(s), s)
  2×(稳态式)      = 2*kappa(s)*Derivative(kappa(s), s) + 2*tau(s)*Derivative(tau(s), s)
  差值            = 0  ⇒ 二者等价（仅差常数因子 2）
  [PASS] 稳态条件是公理 A 的微分推论  |  Ω 为常数时自动成立，不是独立假设，也不额外约束 τ/κ

== 2. 圆参数化：公理 A 是否锁定 τ/κ？==
  参数化 κ=Ωcosθ, τ=Ωsinθ
  代入公理A: κ²+τ²−Ω² = 0  ⇒ 恒等成立（任意 θ）
  τ/κ = tan(theta)  ⇒ θ 连续 ⇒ τ/κ ∈ (0,∞) 连续
  自由度审计: 变量(κ,τ) 2 个 − 约束(公理A) 1 个 = 1 个自由度(θ)
  [INFO] 公理 A 不锁定 τ/κ  |  它只把 (κ,τ) 限制在半径 Ω 的圆上，角度 θ 自由；τ/κ=0.00202 是【额外孤子解】选定的，非公理 A 必然

== 3. 检验：θ 自由度能否同时满足 g-2 与 EDM？==
  当前孤子: τ/κ = 2τ/κ ÷ 2 = 0.002020  ⇒ θ0 = 0.002020 rad
  匹配 g-2: 需 2tanθ = 0.0023193044 ⇒ tanθ = 0.00115965 ⇒ θ = 0.00115965 rad

  EDM ∝ κτ = Ω² sinθcosθ = (Ω²/2)sin2θ
  调 θ 至匹配 g-2 时，EDM 缩放因子 = sinθcosθ|_g2 / sinθcosθ|_0 = 0.574087
  （小角下 sinθcosθ≈tanθ ⇒ 缩放因子 ≈ tanθ_g2/tanθ0 = g-2_exp/g-2_TUFT = 0.574085）
  → 调 θ 匹配 g-2 后：EDM = 8.0872e-14 e·cm，仍超 ACME 15.9 个量级 ❌

  反向检验：要把 EDM 压到 ACME 以内需 κτ 缩放 ≤ 7.809e-17
  即 sin2θ 需缩小 16 量级 ⇒ θ→0 或 θ→π/2
  但 θ→0 ⇒ g-2=2tanθ→0；θ→π/2 ⇒ g-2→∞ ⇒ 均严重偏离实验 0.0023193 ❌

  [FAIL] θ(即 τ/κ)自由度无法调和双约束  |  EDM 的 16 量级超额来自 Ω²=1/ƛ_C²（康普顿尺度 ~6.71e+24 m^-2）本身，角度 θ 只能提供 O(1) 系数(sin2θ≤1)；调 θ 匹配 g-2 时 EDM 仅按同比例(0.574)缩放

== 4. 结论（对三个修复方向的最终裁定）==
  (1) 稳态条件是公理 A 的微分推论，非独立约束；公理 A 留给 τ/κ 一个连续自由度 θ。
      ⇒ 严格说『τ/κ 被孤子自洽锁死』应修正为：『τ/κ 由额外孤子解选定』，
         公理 A 本身不锁死（这为『调参』留了名义空间）。
  (2) 但该自由度【无用】：EDM 的超额量级由 Ω²（康普顿尺度）决定，
     θ 只能给 O(1) 因子；调 θ 匹配 g-2 ⇒ EDM 仍超 15.9 量级；
     压 EDM 至达标 ⇒ g-2 归零/发散。与 OPEN5b 的结论一致（16 量级分裂）。
  ⇒ 方向2（改孤子稳态条件/调 τ/κ）同样【不可行】；
  ⇒ 方向1（单一屏蔽因子）已被 OPEN5b 否；方向2 本册否；
  ⇒ 方向3（承认低能孤子图像失效，理论仅适用于高能/普朗克尺度）为唯一诚实结论。
  [FAIL] 三方向仅剩方向3  |  低能映射层失效，非孤子几何(公理A)之过
