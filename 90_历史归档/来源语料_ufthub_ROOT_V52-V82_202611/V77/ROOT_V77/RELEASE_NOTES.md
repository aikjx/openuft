# ROOT V77 Release Notes

- 首次把原有 `G=2Z/c` 的量纲、不确定度及“Z=精确 0.01”的候选假设纳入独立统计核验。
- 正确区分 Einstein 场方程的 `8πG/c⁴` 与 SI 引力作用量在 `x⁰=ct` 时的 `c³/(16πG)`。
- 建立无量纲引力耦合 `α_g` 与引力半径/康普顿长度比的严谨对应。
- 给出“仅使用 c、ħ 和无量纲螺旋参数无法构造 G”的完整量纲证据。
- 修正历史尝试中把同一 r 同时解释为任意粒子引力半径与康普顿长度的普遍化错误。
- 通过 4 组不同额外固定量展示 `G(c)` 标度不唯一，避免把代数重写误称为动力学定律。
- 明确 JPL 星历能精确给出 `GM`，并不意味着独立测出了地球质量和 G。
- 新增完全离线 HTML 参数实验室、标准库 Python 精算模块、58 项单元测试、15 条 SymPy 审计和数据/图表。
