# ROOT V141｜协变螺旋相位—规范场动力学：完整求导与审计

> 本工程研究的是一个**候选建模路线的数学一致性**；它没有从螺旋运动独立推出标准模型，也没有证实新粒子或第五力。核心耦合采用已有的类轴子电动力学数学形式，不属于新发现的物理定律。

## 0. 单位、约定与状态

- **仅令** `c=1`；不令 `ℏ=1`，也不令 `G=1`。
- 坐标为 `(t,x,y,z)`，`[t]=[x]=L`，度规号差 `(-,+,+,+)`；重复指标求和。
- `θ` 是 **无量纲的候选内部旋转相位**，不是已证实的光子内部轨迹。
- `A_μ` 是独立 U(1) 规范势，`F_{μν}=∂_μA_ν−∂_νA_μ`，`[A]=L^{-1}`。
- `g_F`、`λ` 无量纲，`[f]=L^{-1}`；`[ℏ]=M L`，`[G]=L/M`，`[Gℏ]=L²`。
- 以下所有计算是理论模型或合成输入，不是卫星/实验观测。

## 1. V140 最小几何模型的动力学障碍

已考虑 `Ω=Σ_a dq_a∧dp_a`，并令 `S∝−∫Ω_{μν}Ω^{μν}`。在常量内部背景处令

`q_a=q_{a0}+εξ_a`, `p_a=p_{a0}+εη_a`，则 `Ω=ε²Σ dξ_a∧dη_a`，故 `S=O(ε⁴)`。

因此在这样的真空附近没有通常的二次自由传播项。若引入独立 `A`，则其扰动 `A=εa` 产生 `F(A)=O(ε)`，Maxwell 作用量包含 `O(ε²)` 项。

## 2. 额外的“可吸收”障碍：局部场重定义

如果只通过 `H=dA+ηΩ` 出现，注意 `Ω=dβ`, `β=Σ q_a dp_a`。令

`A_eff=A+ηβ`，则严格有 `H=dA_eff`。

这说明**单靠将原有两种曲率相加不能得到独立可观测的耦合**。在局部光滑构型中，这只是重新定义了规范势。若存在另外的独立动力学、物质耦合、非平凡整体拓扑/边界结构，结论需要逐项重新检查。本工程中的 `src/field.py` 对此做了严格符号检验。

## 3. 一个兼容局部 U(1) 规范对称性的真实耦合候选

考虑如下作用量（括号中具有 `L^{-4}` 量纲）：

\[
\boxed{S=\hbar\int d^4x\sqrt{-g}\left[\frac{R}{16\pi G\hbar}
-\frac1{4g_F^2}F_{\mu\nu}F^{\mu\nu}
-\frac{f^2}{2}(\nabla\theta)^2
-\frac{\lambda\theta}{4}F_{\mu\nu}\widetilde F^{\mu\nu}
\right]}
\]

其中 `\widetilde F^{μν}=(1/2)ε^{μνρσ}F_{ρσ}`，`ε^{0123}=+1/√(-g)`，并选取标准 `E=-∂_t A-∇A_0`、`B=∇×A` 的三维约定。

注意 **R/(16πGℏ)** 与 Maxwell 动力学由我们明确写入，**并未从单一螺旋运动推导出来**。

### 3.1 U(1) 局部规范不变性

`A_μ→A_μ+∂_μχ` 导致 `F_{μν}→F_{μν}`，θ 不变，全部局部作用量密度保持不变。`src/field.py` 给出对一般多项式势的符号校验。θ 是空间时间标量，因此整个作用量写法一般协变；具体非平凡背景可自发选择传播方向，但不改变基础方程的协变性。

### 3.2 对 A 的变分

`δF_{μν}=2∇_[μ δA_{ν]}`，积分分部并利用 Bianchi 恒等式 `∇_μ \widetilde F^{μν}=0`：

\[
\boxed{\nabla_\mu\left(\frac{1}{g_F^2}F^{\mu\nu}+
\lambda\theta\widetilde F^{\mu\nu}\right)=0.}
\]

对常量 θ，恢复普通真空 Maxwell 方程 `∇_μF^{μν}=0`，且 `dF=0`。

### 3.3 对 θ 的变分

\[
\boxed{f^2\Box\theta=\frac\lambda4 F_{\mu\nu}\widetilde F^{\mu\nu}.}
\]

在 `(-,+,+,+)` 约定中 `\Box θ=−\partial_t² θ+∇²θ`；空间均匀 θ 时 \(\Box θ=-\ddot θ\)。

### 3.4 量纲审计

| 项 | L 幂次 | 是否通过 |
| --- | ---: | --- |
| `R/(Gℏ)` | `-2-2=-4` | 是 |
| `F²/g_F²` | `-4` | 是 |
| `f²(∂θ)²` | `-2-2=-4` | 是 |
| `λθ F \widetilde F` | `-4` | 是 |
| `d⁴x` | `+4` | 是 |
| 整体 S | `[ℏ]` | 是 |

这不是在数值计算中设 `ℏ=1`。对长度基准 `L₀` 使用无量纲坐标时，能量密度需乘回 `ℏ/L₀⁴`。

## 4. 可严格检验的“空间螺旋场”简化模型

取一个实的空间螺旋 Beltrami 模式（不是自由光子的实际螺旋轨迹）：

\[
\mathbf A(t,z)=a(t)(\cos kz,-\sin kz,0),\quad A_0=0,
\qquad \nabla\times\mathbf A=k\mathbf A.
\]

`E=−a'(t)e(z)`，`B=k a(t)e(z)`，所以 `E·B=−k a a'`。这个构型在空间方向上呈螺旋，但属于**非传播的模态展开/驻波型解空间**；不能直接视为一束沿 z 传播的光。定义 `v=da/dt`, `w=dθ/dt`、均匀 θ(t)，把作用量密度对一个空间周期取平均（这里局部密度已与 z 无关）：

\[
\frac{\mathcal L_{red}}{\hbar}=\frac{v^2-k^2a^2}{2g_F^2}
+\frac{f^2 w^2}{2}-\lambda k\theta a v.
\]

注意微扰稳定性只保证标准二次 Maxwell 和正能标量结构；任意强时变背景下的有效频率仍需检查。

### 4.1 Euler–Lagrange 联立方程

对 a 与 θ 分别求导，得到

\[
\boxed{\ddot a+k^2 a-g_F^2\lambda k\dot\theta\,a=0,}
\quad
\boxed{f^2\ddot\theta=-\lambda k a\dot a.}
\]

这里 θ 与电磁旋转模态是**双向耦合**：不能将持续变化的 θ 外部背景当作无反作用的精确解。

### 4.2 Noether 能量和相位荷

由 Legendre 变换（导出的能量密度以 `ℏ` 为单位）得到：

\[
\boxed{\mathcal E/\hbar=\frac{v^2+k^2 a^2}{2g_F^2}+\frac{f^2 w^2}{2}.}
\]

对上述微分方程求导：

\[
\frac{d}{dt}\left(\frac{\mathcal E}{\hbar}\right)
=\frac{v}{g_F^2}(\ddot a+k^2a)+f^2w\ddot\theta
=\lambda k w a v-\lambda k w a v=0.
\]

此外在固定边界/周期条件下，θ 的常数平移使作用量仅差一个总时间导数，故

\[
\boxed{Q=f^2\dot\theta+\frac{\lambda k}{2}a^2=\mathrm{const}.}
\]

再次求导：`dQ/dt=f²θ̈+λk a ȧ=0`。

## 5. 独立的自由传播和偏振检验

令 θ 恒定，规范场在平直时空中可有 `A_x=cos(kz−ωt)`，其场方程给出 `ω²=k²`。其 E 与 B 正交，能量沿直线传播：**电磁场的旋转、光速传播与光子路径螺旋三者不能混同**。

若在“外部缓慢变化的均匀 θ(t)”近似下分析圆偏振的局部 Fourier 模式，可得到采用本文件符号约定的形式

\[
\ddot a_{\sigma}+[k^2-\sigma g_F^2\lambda k\dot\theta]a_{\sigma}=0,
\quad \sigma=\pm1.
\]

这个局部系数可反映偏振不同的相位响应。但若 θ 不随光场反作用改变，则并非完整耦合系统的严格解；更不能把其数值系数当作实测双折射。

## 6. V141 的突破与未解决问题

| 问题 | 结论类型 | 结果 |
|---|---|---|
| 几何合成是否自动产生新相互作用？ | 严格局部结论 | **否**，在给定前提下可被场重定义吸收 |
| 常量背景可否有自由传播？ | 严格模型结论 | 独立 A 可恢复 Maxwell 二次项；原纯复合场不能 |
| 内部相位能否和电磁场真正交换能量？ | 理论构造、数值交叉校验 | 可以，需单独加入动力学和耦合 |
| Lorentz 协变、U(1) 规范不变性？ | 数学结构检查 | 在规定条件下成立 |
| 能量守恒？ | 解析守恒式+数值回归 | 本轮简化模型通过 |
| 从螺旋独立推出 U(1) 规范场及耦合？ | 开放 | **没有完成** |
| 从同一微观结构推出 SU(2)×SU(3)、引力与 G？ | 开放 | **没有完成** |
| 真实卫星或实验数据约束？ | 开放 | **本轮未做** |

这个新作用量不是统一场论证明；它是一个**可以检验是否正确、可以暴露缺陷的最小动力学模型**，与已有类轴子电动力学结构等价到所选规范化约定。

## 7. 下一道真正的推导门槛（V142）

1. 在不先添加 U(1) 场、耦合常数 λ 的条件下，从一个微观变量得到质量为零的两种横向物理偏振及规范冗余。
2. 独立从微观对称性推导标准模型规范群的生成元及场表示。
3. 证明理论无鬼模、无异常不一致，并提供能量正定性与良定义的初值问题。
4. 给出不能用已知参数重定义吸收、可由现有数据独立检验的新预测。
5. 除此之外，要独立推出 G 的数值或与其他常数的必然关系，不能将其作为输入后再声称获得推导。
