## 四、为什么「补齐输入」不能完成统一场

### 4.1 类别互斥

W3 的机器定义是「至少输出一个**无量纲量数值**且非测量锚」；整合全集三闸门写「**[C] 不纳入**」；状态看板把 `α` 标为「**测量锚**」，并把第一性内容定义为「无量纲量的数值」。因此 GUT 谱、阈值、Yukawa 张量、\(\alpha_H\)、\(M_{\mathrm{SUSY}}\)、螺旋轴等若被作为外部输入补齐，只落在 [C] / 测量锚类别，与 W3 的输出类别互斥。把 W3 定义中的「非测量锚」替换为「测量锚」的变异测试会使 C03 结论翻转，证明判据有牙。

### 4.2 输入数不是验证数

外部输入链已由库内三册登记为 `6 → 12 → ≥15 → UNBOUNDED`。本册把每个输入数注入到类别账本中，`validated / UFT-3 / L3 / W3.pass / full_pass / W3.debt` 全部不变。原因是这些字段是**类别通过数**，不是输入参数数；`W3.debt=35/2` 是 17 个 FAIL + 0.5×1 个 PART 的验收矩阵欠账，不会因为外部补了谱就自动下降。

### 4.3 最小闭合集要求的是新类别产出

W 册的 C1–C6 不是「补输入」清单，而是：

- C1/C6：收口与编号治理，零物理代价；
- C2：W3 全域瓶颈，要求至少一个**非测量锚无量纲数值**并通过 method_F 双锚点；
- C3：W6 质量层级，需 Yukawa / 动力学输入，但输入本身仍不能替代通过数；
- C4：W4 耦合统一，需一般群乘积两环 β 系数矩阵；
- C5：W7 新窗口，依赖 C2/C3，否则只能开在已关闭族里。

执行序 `C1 → C6 → C2 → (C3 ∥ C4) → C5` 说明：治理先做，实质开路仍是 C2/C3/C4；外部输入只是这些开路的原材料，不是验收通过本身。

### 4.4 PASS 不可迁移

完成度审计明确「L3 的闭合不迁移到 L4」。本册用变异测试证明：若错误地把 L3→L4 闸门置 1，伪造 22 个 PASS 会立刻造出 22 个假 `validated`；闸门置 0 时仍为 0。README 末 8 行「不计攻破数」命中 5 处，说明 attack36b/37/38/39/40 的 PASS 都按同一纪律不计攻破数。

### 4.5 计数口径与治理债

C08 发现跨源档位计数不一致：达成度 JSON 与数据 md 为 `未完成=21 / 纲领草案=1`，判定册与整合全集引用为 `未完成=19 / 纲领草案=3`。本册只登记 MISMATCH，不修改任何上游事实源。C09 同时区分 22 体系现测 `C6/O10/H2/U4` 与 18 体系快照 `2H/3O/9C/4U`，以及 `UFT 达成度 1/6` 与 `score_machinable=3` 的不同口径。
