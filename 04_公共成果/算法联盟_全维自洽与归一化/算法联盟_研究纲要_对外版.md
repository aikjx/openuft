# 算法联盟 · 研究纲要（对外版）

> **给读者的第一句话**：这是一支以「**第一性原理自洽审计**」为核心方法的研究小组。
> 我们不靠形容词评价理论，而是把「一个统一场论到底做到哪一步」翻译成**机器可判定的读数**。
> 本文是**研究说明**，不是认证；所有结论都指向可复跑的引擎与产物，读者可以自己跑出来验证。

## 1. 我们做什么

对一组独立提出的统一场论候选（本仓库内 **19** 个体系）做**全维度、可复算、可证伪**的体检：

```
全维分析 → 精算验证 → 冲突探测 → 融合 → 归一化
```

最终回答三个问题，且每个答案都带数字：

- **数学上自洽吗？**（精算 + 量纲 + 冲突探测）
- **与已知实验一致吗？**（χ² / 判决力读数）
- **真正预测了新东西吗？**（无量纲靶 + 相对不确定度登记）

我们的产出分三类，且都以「**退出码 + 产物**」落地，不以文字断言落地：

| 产出 | 含义 | 例子 |
|---|---|---|
| **判定**（verdict） | 某条主张成立 / 边界 / 被证伪 | 空间螺旋台账 `falsified 18` 条 |
| **定理**（theorem） | 某类路线不可能 / 某条件下可行 | 量纲代数不能给可检验预言（定理 C） |
| **门禁**（gate） | 防止已判结论被悄悄改回 | 写入侧校验器，自证 9/9 |

## 2. 方法：把「程度」变成「读数」

### 2.1 四级评级 + 四态判定

- **健康度**：`H`（自洽可信） / `O`（欠定待定） / `C`（不自洽） / `U`（未展开）
- **层级**：`L0`（恒等） → `L1`（重述） → `L2`（部分推导，依赖外部锚） → `L3`（第一性推导 + 带误差棒的可检验预言）
- **四态**：`PASS` / `BOUNDARY` / `INFO` / `FAIL`——**任何产物必须四态齐备**，不允许退化成「通过 / 不通过」两态。

> **口径纪律（贯穿全文）**：「数学自洽」≠「实验证实」≠「L3 第一性推导」。
> 「精算通过」只说明没被本次复算推翻，不代表理论成立。

### 2.2 判别式体系：先回答「能不能派生」

我们用一整套判别式判断「一个量到底是不是真从公设推导出来的」：

| 判别式 | 作用 |
|---|---|
| **V / V3 / V4 / V5** | 信息增益与秩层判定：派生必须 `V>0`，否则判伪派生 |
| **定理 C** | 量纲代数**不可能**给出可检验无量纲预言 |
| **定理 H** | 7 个几何作用量中 5 个不能固定精细结构常数，其余只到阶 1 值 |
| **定理 T** | 算子谱路线即便可行，也**钉不死**参数（自指循环） |
| **定理 W** | 十余条定理可归约为一条：`派生不产生信息，只产生记账方式` |

### 2.3 统计层：再回答「多靶联合时可靠性如何」

判别式解决「单靶能不能派生」；统计层解决「多靶联合时 χ² / 自由度 / 协方差如何」：

- 单靶 χ²/p/δ_min 读数；
- 联合拟合（独立 / 共模 profile）；
- **关键拆分**：把「自洽性」（轴 A）与「可检验性」（轴 B）分成两条轴——自洽 ≠ 可检验，轴 B 不过判 `FAIL`（不可判 ≠ 通过）。

## 3. 三个结构性结论

这些是审计中反复出现、且彼此印证的发现——它们不是某个体系的缺陷，而是**结构性的**：

### 3.1 普朗克锚定谬误（M02）

一个看起来「导出 G」的公式，联立后必然推出质量等于普朗克质量。
正确形式是 α_grav = (m/m_P)²。这类「导出常数其实是单位换算」的陷阱，曾藏在「113 项精算 100% 通过」的表象下。

### 3.2 UFT-3 = 0 是结构性的，不是努力问题

- 扫描 18 个体系：动力学本征值 **1** · 量纲代数 **9** · 计数匹配 **2** · 无主张 **2**；
- 三条候选路线被定理 **C / H / T** 依次封死（量纲代数、几何作用量彻底；算子谱的钉死带自指性）；
- 唯一未封死的路线是**动力学本征值**（由解的谱给出无量纲数）。

⇒ 在路线不变的前提下，「再写多少个体系，登记数都是 0」。要改变它，需要某个体系真的给出一个无量纲数 + 误差棒。

### 3.3 「数学自洽 ≠ 实验证实」被机器化

`L3 = 0`、`UFT-3 = 0`、`falsified` 基线不缩水、门禁负向测试——这些把一条方法论纪律变成了**可执行的不变量**。
任何人（包括后续会话）想把已判 `falsified` 的主张改回 `pass`，门禁立刻以非零退出码报警。

## 4. 门禁与防回潮

我们不相信「写下来就对了」，所以给每一条结论都配了**会咬人的门禁**：

| 机制 | 内容 | 证据 |
|---|---|---|
| 守卫 G1–G8 | 字段宽度 / 编号连续 / 状态词表 / `falsified` 基线不缩水 / 产物齐备 / 归档防篡改 | 8/8 通过；负向测试证明会咬 |
| 登记列写入侧校验 | 两列语义（数值 + 相对不确定度）+ **只许不增**基线 | 自证 9/9；测试模式遇错即退出码 1 |
| 一键复跑 | 四阶段串行 + 聚合退出码 | **PASS 4/4**，可入 CI |

> **一条值得说的设计教训**：对他人台账做写操作时，校验必须发生在「截断文件」**之前**；
> 「先备份」救过一次事故，但我们不依赖备份兜底——门禁在写入前就拒绝错位文件。

## 5. 诚实边界（我们自己的规矩）

1. 精算只证「数学自洽」与「与已知值一致」，**不证第一性推导**。
2. 第一性真正靶心是**无量纲量**（α、质量比、α_grav）；「导出 c/ℏ/G」是伪目标。
3. 冲突一律标 `FAIL`/`BOUNDARY`，**不粉饰**；「用了更多符号」≠「解释力增加」。
4. 已判 `falsified` 为终态，**不删除**不利结果。
5. **不使用夸大表述**（「终极 / 颠覆 / 最伟大」等）；任何「认证通过」式宣称都记为**自封**。
6. 目录完整、代码跑通、文档成文**都不构成理论认证**。
