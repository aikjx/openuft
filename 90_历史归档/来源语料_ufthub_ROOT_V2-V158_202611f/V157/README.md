# ROOT V157 — 协变内部相位、局域束缚与引力应力审计

## 研究范围
延续 V156：不再只指定整体半径势能，而采用一个局部复标量场作用量求解。这里借用已知 Q-ball 模型，势能、尺度 L0 和全局 U(1) 对称性均为输入假设，不是从光速螺旋推导。无真实物理实验或卫星数据拟合；不证明四力统一。

## 1. 单位和变分
仅 c=1，度规 (-+++)，[hbar]=ML，[G]=L/M。物理复标量 Psi 的量纲 L^-1；S=hbar ∫d4x[-(∂Psi*∂Psi)/2-U(|Psi|)]，U=|Psi|²/(2L0²)-|Psi|⁴/2+L0²|Psi|⁶/4，所有 U 项 L^-4。S 量纲 ML。令 x=L0 xbar，Psi=f(rbar) exp(i w tbar)/L0，w=omega L0。此后各式为归一化量；物理能量 E_phys=(hbar/L0) E，质量相同（c=1），守恒 Q 无量纲，物理 Noether 荷按规范化为 hbar Q。角频率不等于某个点的空间速度。

Euler-Lagrange: f''+2 f'/r=(1-w²)f-2f³+1.5f⁵。f'(0)=0，f(∞)=0，外边界以线性衰减 Robin 条件近似。U>=0 且 2U/f²=1/2+(f²-1)²/2。通常存在区间 1/sqrt(2)<w<1，不能由区间 alone 保证任一解稳定。模型具有质量尺度 hbar/L0，非由螺旋推导。

## 2. 能量和固定荷稳定性
T=∫(w² f²/2)d³x，K=∫|∇f|²/2 d³x，V=∫U d³x，E=T+K+V，Q=w∫f² d³x。
固定 Q，空间尺度伸长 f_s(x)=f(x/s)，角频率 w_s=w/s³。E(s)=T/s³+K s+V s³。
E'(1)=-3T+K+3V=0；E''(1)=12T+6V>0。只证明这一方向的二阶能量稳定，不等于全部模式稳定。
以 u=r f 表示固定荷径向实振幅变分，H=-d²/dr²+1-6f²+7.5f⁴-w² + 4 w² |u><u|/<u,u>。第二项为约束荷的非局域秩一修正。用有限差分、Dirichlet 边界及稀疏特征值求解验证，两个网格分别比较。负特征值说明该离散约束能量有下降方向；正值仅支持此有限域径向实振幅子空间的稳定性，非完整谱证明。E/Q<1 只表明比同荷自由粒子能量低，不等同于排除裂变、量子或其他衰变。

## 3. 平衡应力与弱场引力
局部 t=w²f²/2，k=f'²/2，v=U。能量密度 e=t+k+v，径向压强 pr=t+k-v，切向 pt=t-k-v。由径向场方程 pr'=-2(pr-pt)/r=-2 f'²/r。积分空间应力迹为 3T-K-3V=0（边界消失时）。弱场静态 GR 的主动质量源为 e+pr+2pt，整体积分为 E。恢复物理量后 ∇²Phi=4πG (rho+sum p_i)，该结论依赖已知 GR、弱场和孤立条件，而非独立推导 G。自引力未纳入本轮场求解。

## 4. 光速约束的反例
非零场区域 theta=w t，(∂theta)²=-w²/L0²<0，是类时相位梯度；空间 Noether 电流为零。故本模型不是三维空间光速螺旋轨迹的实现。虽然标量方程的主符号为波算子、特征传播速度 c=1，但相位旋转、特征速度、粒子速度不可混淆。静止有限结构的存在需要非线性与守恒荷，不由正交或发散单独推出。无质量单自由度、纯无迹守恒应力的 V156 扩张限制仍有效。

## 5. 数值方法与局限
probe.py: SciPy solve_bvp，非零解延拓；21 个 w 从 0.78 到 0.98。run_all.py: Simpson 积分、三组半径/容差收敛、brentq 能量阈值求根、两网格约束 Hessian、四组非线性径向 PDE 演化。PDE 用 u=r Psi，中心和外端 Dirichlet；速度 Verlet 步进，离散能量与荷监控，初始振幅 +3% 且反向调整相位速度以固定荷；有限域 R=65，t=60，外边界反射不可用于无限时间稳定结论。高频尾部在 r=50 截断，影响未系统扫描。RMS 以 |Psi|² 加权，不是能量 RMS。仅 .8 的 BVP 域和容差收敛完整对照；其余频率及完整非球对称、相位耦合谱未做。图表使用实际计算数据。
