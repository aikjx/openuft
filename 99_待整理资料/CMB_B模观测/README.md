# CMB B 模观测

> 原初引力波在宇宙微波背景（CMB）上留下的 B 模式偏振信号，是暴胀与量子引力的关键观测窗口。

## 问题定义

宇宙暴胀期间的量子涨落被拉伸为原初引力波，在 CMB 偏振上产生**B 模式**（旋度型）偏振。张量-标量比 $r$ 量化原初引力波振幅：

$$r = \frac{P_t}{P_s}$$

其中 $P_t$ 为张量功率谱，$P_s$ 为标量功率谱。

**核心目标**：探测 $r > 0$，即原初引力波的存在证据。

## 当前进展（2020–2026）

| 实验 | 结果 |
|---|---|
| Planck 2018 | $r < 0.06$（95% CL） |
| BICEP/Keck 2021 | $r < 0.036$（95% CL，联合分析） |
| BICEP/Keck 2023 | $r < 0.032$（95% CL） |
| 未发现 | 尚无 $r > 0$ 的确认信号 |

**理论预期**：
- 简单单场慢滚暴胀预言 $r \sim 0.01$–$0.1$
- $r < 0.03$ 已排除部分大场暴胀模型
- 宇宙微波背景 B 模 foreground（尘埃同步辐射）是主要系统误差

## 证伪条件

- 若 $r$ 被精确定为 $0$（无原初引力波），则标准暴胀范式需修正
- 若 B 模谱形状不符慢滚预言，则暴胀模型被排除
- 若发现非高斯性或手性 B 模，则需超出标准暴胀的新物理
