## 一、公理体系与核心定理

### 1.1 三条本源公理

**公理1（垂直原理）**：空间中任意一点的运动方向总是垂直于该点的空间位置矢量。
- 数学形式：r(t)·v(t) = 0（瞬时垂直）
- 物理意义：空间本身在以光速运动，物体的运动是空间运动的叠加

**公理2（光速约束）**：所有基本粒子的内部运动速度恒等于光速c。
- 数学形式：v² = R²ω² + b² ≡ c²
- 物理意义：静止质量m₀∝1/R，静止动量p₀=m₀c是螺旋旋转分量的动量

**公理3（螺旋参数化）**：基本粒子的内部运动是光速螺旋运动。
- 参数方程：r(t) = (R cosωt, R sinωt, bt)
- 光速约束：b = ±√(c² - R²ω²)，约束Rω ≤ c

### 1.2 核心定理：全维三重奏定理

**定理（空间光速螺旋三重奏）**：对满足v≡c的光速螺旋，曲率κ和挠率τ满足
$$\kappa^2 + \tau^2 = \left(\frac{\omega}{c}\right)^2$$
其中κ = Rω²/c²，τ = bω/c²。

**证明**：
1. 螺旋参数方程：r(t) = (R cosωt, R sinωt, bt)
2. 速度：v(t) = (-Rω sinωt, Rω cosωt, b)，v² = R²ω² + b² = c²
3. 加速度：a(t) = (-Rω² cosωt, -Rω² sinωt, 0)，|a| = Rω²
4. 曲率：κ = |v×a|/|v|³ = Rω²/c²
5. 挠率：τ = (v×a)·a'/|v×a|² = bω/c²
6. 三重奏：κ² + τ² = (R²ω⁴ + b²ω²)/c⁴ = ω²(R²ω² + b²)/c⁴ = ω²c²/c⁴ = (ω/c)²

**sympy符号验证**：差精确为0（非近似）。

$$\mathbf{F} = \frac{d\mathbf{P}}{dt}, \quad \mathbf{P} = m(\mathbf{c} - \mathbf{v})$$

**四力分解**：
$$\mathbf{F} = \underbrace{\mathbf{c}\frac{dm}{dt}}_{\text{电场力}} - \underbrace{\mathbf{v}\frac{dm}{dt}}_{\text{磁场力}} + \underbrace{m\frac{d\mathbf{c}}{dt}}_{\text{引力/核力}} - \underbrace{m\frac{d\mathbf{v}}{dt}}_{\text{惯性力}}$$
