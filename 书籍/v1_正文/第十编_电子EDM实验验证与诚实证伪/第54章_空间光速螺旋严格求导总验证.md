## 53.1 本源定义

空间光速螺旋模型的核心公设：真空微元以光速沿圆柱螺旋线运动。

**螺旋参数方程**（自然单位 c=1，此处保留c量纲）：

$$\mathbf{r}(t) = (\rho\cos\omega t,\; \rho\sin\omega t,\; b\omega t)$$

其中：
- $\rho$ = 横向半径（修正后 = 经典电子半径 $r_e$）
- $b$ = 螺距参数
- $\omega$ = 角频率
- 光速公设：$|\mathbf{v}| = c$，即 $c^2 = \omega^2(\rho^2 + b^2)$

## 53.2 求导证明（符号求导，[A]数学恒等）

### 53.2.1 运动学链：r → v → a

**一阶导（速度）**：

$$\mathbf{v}(t) = \frac{d\mathbf{r}}{dt} = (-\omega\rho\sin\omega t,\; \omega\rho\cos\omega t,\; b\omega)$$

横向速度：$v_\perp = \omega\rho$
轴向速度：$v_\parallel = b\omega$

光速验证：
$$|\mathbf{v}|^2 = \omega^2\rho^2 + b^2\omega^2 = \omega^2(\rho^2 + b^2) = c^2$$

**二阶导（加速度）**：

$$\mathbf{a}(t) = \frac{d\mathbf{v}}{dt} = (-\omega^2\rho\cos\omega t,\; -\omega^2\rho\sin\omega t,\; 0)$$

|v| = ω²ρ（向心加速度）

**速度-加速度点积验证**：

$$\mathbf{v} \cdot \mathbf{a} = 0$$

（径向分量做功为零，能量守恒）

### 53.2.2 微分几何：Frenet-Serret → κ, τ

**弧长参数化**：$s = ct$

单位切向量：$\mathbf{T} = d\mathbf{r}/ds$，$|\mathbf{T}| = 1$

**曲率**：

$$\kappa = \left|\frac{d\mathbf{T}}{ds}\right| = \frac{\omega^2\rho}{c^2} = \frac{\rho}{\rho^2 + b^2}$$

（代入 $c^2 = \omega^2(\rho^2+b^2)$）

**挠率**：

$$\tau = -\frac{d\mathbf{B}}{ds} \cdot \mathbf{N} = \frac{b\omega^2}{c^2} = \frac{b}{\rho^2 + b^2}$$

### 53.2.3 动力学链：p → F

动量：$\mathbf{p} = m\mathbf{v}$

力：

$$\mathbf{F} = \frac{d\mathbf{p}}{dt} = m\mathbf{a} = m(-\omega^2\rho\cos\omega t,\; -\omega^2\rho\sin\omega t,\; 0)$$

$$|\mathbf{F}| = m\rho\omega^2 = m v_\perp \omega$$

（向心/螺旋恢复力）

**机电对偶**：$m \leftrightarrow L$，$v \leftrightarrow \dot{q}$，则 $|\mathbf{F}_{em}| = L\rho\omega^2$（对偶电感惯性力）

### 53.2.4 三重奏恒等式

$$\kappa^2 + \tau^2 = \frac{\rho^2 + b^2}{(\rho^2 + b^2)^2} = \frac{1}{\rho^2 + b^2} = \frac{\omega^2}{c^2}$$

**验证通过**：$\kappa^2 + \tau^2 = (\omega/c)^2$

**α的几何定义**：

$$\alpha = \frac{\kappa}{\tau} = \frac{\rho}{b} = \frac{v_\perp}{v_\parallel}$$

## 53.4 新发现：sinθ=α 精确关系

### 53.4.1 螺旋升角

螺旋升角 $\theta$ 定义为：

$$\sin\theta = \frac{v_\perp}{|\mathbf{v}|} = \frac{\alpha c}{c} = \alpha$$

$$\cos\theta = \frac{v_\parallel}{|\mathbf{v}|} = \sqrt{1-\alpha^2}$$

$$\tan\theta = \frac{v_\perp}{v_\parallel} = \frac{\alpha}{\sqrt{1-\alpha^2}}$$

### 53.4.2 S12 闭式矛盾修正

**S12原主张**：$\alpha = \tan\theta$

**修正后**：$\alpha = \sin\theta$

**修正原因**：
- 原S12将横向半径取为康普顿半径 $\rho = \lambda_C$
- 修正后横向半径为经典电子半径 $R = \alpha\rho = r_e$
- $\kappa/\tau = R/b = \alpha/\sqrt{1-\alpha^2} = \tan\theta$，而非 $\alpha$
- 直接几何关系：$\sin\theta = v_\perp/c = \alpha$

**误差分析**：
- 若误用 $\tan\theta = \alpha$，误差为 $\alpha^2/2 \approx 2.7×10^{-5}$
- 数值验证：$\kappa/\tau = 0.0072975469$，CODATA $\alpha = 0.0072973526$，误差2.66e-05 = $\alpha^2/2$ 量级
- **结论：S12的"α=tanθ"应修正为"α=sinθ"**

## 53.5 EDM修正：螺旋对称性严格论证

### 53.5.1 命题

**螺旋对称电荷分布的电偶极矩 $\mathbf{d} = \int \rho(\mathbf{r}) \mathbf{r}\, d^3r = 0$**

### 53.5.2 证明

1. **横向分量**：对镜像对称分布
   - $d_x = \int \rho x\, d^3r$，经反射 $S_{xz}: x \to -x$ 不变 $\rho$，则 $d_x = -d_x = 0$
   - $d_y = \int \rho y\, d^3r$，经反射 $S_{yz}: y \to -y$ 不变 $\rho$，则 $d_y = -d_y = 0$

2. **轴向分量**：束缚螺旋对 $z \to -z$ 反对称翻转
   - $d_z = \int \rho z\, d^3r = 0$

3. **结论**：$\mathbf{d}_e = (0, 0, 0)$  **[A]类对称性论证，与SM一致**

### 53.5.3 数值旁证

均匀螺旋采样平均：
- $\langle x \rangle = 9.654×10^{-19}$（≈0）
- $\langle y \rangle = 1.654×10^{-29}$（≈0）
- $\langle z - \langle z \rangle \rangle = 6.617×10^{-29}$（≈0）

**结论：$d_e = e\langle \mathbf{r} \rangle = 0$（螺旋对称性数值确认）**

### 53.5.4 g2_EDM.py假设被排除

g2_EDM.py假设：$d_e = e\alpha\rho/2 = 2.257×10^{-34}\;\mathrm{C·m} = 1.409×10^{-13}\;\mathrm{e·cm}$

JILA HfF+上限（2023）：$|d_e| < 4.1×10^{-30}\;\mathrm{e·cm}$

**排除倍数：$1.409×10^{-13} / 4.1×10^{-30} = 3.44×10^{16}$（约16.5个数量级）**

**结论：g2_EDM.py的"电荷沿b方向固定偏移"假设破坏螺旋对称性，属[C]类无依据假设，已被实验证伪。**
