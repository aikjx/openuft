## 4.2.1 空间光速螺旋：曲率、挠率、角频率定义

考虑三维欧氏空间内类光圆柱螺旋世界线，采用**弧长参数 s**，满足 |r'(s)| = 1。参数化形式：

$$ \boldsymbol r(s) = \left(R\cos\frac{s}{\mathcal L},\; R\sin\frac{s}{\mathcal L},\; \frac{Hs}{\mathcal L}\right) $$

其中尺度参数 $\mathcal L = \sqrt{R^2+H^2}$。

Frenet–Serret 活动标架 {t, n, b}（切向量、主法向量、副法向量）满足：

$$ \frac{d\boldsymbol t}{ds}=\kappa\boldsymbol n,\qquad
\frac{d\boldsymbol n}{ds}=-\kappa\boldsymbol t+\tau\boldsymbol b,\qquad
\frac{d\boldsymbol b}{ds}=-\tau\boldsymbol n $$

κ>0 为曲线空间曲率，τ 为空间挠率，量纲均为 $\mathcal L^{-1}$。圆柱螺旋的解析表达式：

$$ \kappa=\frac{R}{R^2+H^2}=\frac{R}{\mathcal L^2},\qquad
\tau=\frac{H}{R^2+H^2}=\frac{H}{\mathcal L^2} $$

几何恒等式：

$$ \kappa^2+\tau^2=\frac{1}{\mathcal L^2} $$

TUFT 引入普适几何倾角 θ，作为曲率与挠率的耦合公理：

$$ \kappa=\sqrt{\kappa^2+\tau^2}\,\sin\theta,\qquad
\tau=\sqrt{\kappa^2+\tau^2}\,\cos\theta $$

直接得到耦合关系 τ = κ·cotθ。

光速条件：世界线弧长与坐标时间满足 s = ct。

- ω：Frenet 活动标架沿世界线演化的**内禀标架旋转角频率**；
- Ω：实验室坐标系中螺旋绕对称轴的**轨道角速度**。

$$ \omega = c\sqrt{\kappa^2+\tau^2}=\frac{c}{\mathcal L}=\frac{c\kappa}{\sin\theta} $$
$$ \Omega=\frac{d\varphi}{dt}=\frac{c}{\mathcal L}=\omega=\frac{c\kappa}{\sin\theta} $$

> 重要结论：在等曲率等挠率圆柱光速螺旋构型下，**轨道角速度与 Frenet 标架内禀旋转角频率大小相等**，
> 二者物理图像不同，但数值一致。此前错误 Ω = cκ 删除。

几何关系汇总盒式公式：

$$ \boxed{\tau=\kappa\cot\theta,\qquad \omega=\frac{c\kappa}{\sin\theta}=c\sqrt{\kappa^2+\tau^2},\qquad \Omega=\omega=\frac{c\kappa}{\sin\theta}} $$

## 4.2.2 总作用量与稳态基态定义（量纲修正，两套约定说明）

> 约定选择：采用标准广义相对论形式 $S=\int d^4x\sqrt{-g}\,\mathcal L$，坐标 $x^0=ct$，
> 四维体积元 $d^4x = dx^0dx^1dx^2dx^3$。作用量量纲 [S] = J·s；拉格朗日密度 ℒ 量纲 J·s/m^4。

总作用量分解为引力项、螺旋场体项、边界项：

$$ S_\text{total}=S_\text{grav}+S_\text{spiral,bulk}+S_\text{boundary} $$
$$ S_\text{spiral,bulk}=\int_\Omega d^4x\sqrt{-g}\left[\frac{\hbar}{2}\,g^{\mu\nu}\nabla_\mu\kappa\nabla_\nu\kappa-V_\text{constraint}(\kappa)\right] $$

> 重要标注：$V_\text{constraint}(\kappa)$ **不是能量型势能密度**，是用于强制光速螺旋色散关系的**罚约束项**，
> 量纲不必匹配拉氏密度；形式：
> $$ V_\text{constraint}(\kappa)=\frac12\left(\frac{c^2\kappa^2}{\sin^2\theta}-\omega^2\right)^2 $$
> 当约束严格满足时 $V_\text{constraint}=0$，对应基态。

> **定义 4.1（TUFT-V4.8 稳态基态）**
> 稳态基态是总作用量 $S_\text{total}$ 在**微小场扰动**与**微小边界形变**下同时取驻点、且总能量取极小的场构型。
> 稳态基态同时满足体域欧拉–拉格朗日方程、约束极小条件、时间稳态条件、边界力学平衡、紫外正则边界约束。

> **引理 4.1（稳态基态方程组）** 场构型属于稳态基态当且仅当以下全部条件成立：

1. **体域欧拉–拉格朗日场方程**

$$ \frac{\partial\mathcal L_\text{sp}}{\partial\kappa}-\nabla_\mu\left(\frac{\partial\mathcal L_\text{sp}}{\partial(\nabla_\mu\kappa)}\right)=J_\kappa $$

代入修正后的作用量得：

$$ \hbar\nabla^2\kappa=-\frac{dV_\text{constraint}}{d\kappa}+J_\kappa $$

源内部（螺旋世界线邻域）J_κ ≠ 0，为有源泊松型方程；源外真空区 J_κ = 0，∇²κ = 0。

2. **约束极小条件（光速螺旋运动学约束）**

$$ V_\text{constraint}(\kappa)=0,\qquad \frac{dV_\text{constraint}}{d\kappa}=0 $$

等价于 Frenet 标架色散关系 ω = cκ/sinθ；基态下约束罚项归零。约束满足时场方程简化为 ħ∇²κ = J_κ。

3. **时间稳态条件**：∂_t κ = 0，∇_0κ = 0，哈密顿密度守恒。

> 哈密顿量采用 $S=\int dt\,d^3x\sqrt{g}\,\mathcal H$ 约定（3+1 分解），能量密度
> $$ \mathcal H_\text{spiral}=\frac{\hbar c}{2}|\nabla\kappa|^2 $$
> 量纲核验：[ħc] = J·m，|∇κ|² = m^-4，[ℋ] = J/m^3（正确，能量密度）。
> 自能积分：$U_\text{self}=\int d^3x\sqrt{g}\,\mathcal H_\text{spiral}$。

4. **边界力学平衡条件**（边界变分驻定）

$$ \frac{\hbar c}{2}(\nabla\kappa)^2\bigg|_{\partial\Omega}=\sigma\,K $$

σ 为边界几何表面能密度，K 为边界曲面外主曲率；球面边界 K = 2/R_c。
量纲核验：左侧 J/m^3；σ 为 J/m^2，K ~ m^-1，σK ~ J/m^3，左右匹配。
物理含义：曲率场梯度产生的内场压强与边界几何表面张力力学平衡，保证局域粒子包稳定。

5. **紫外正则内边界条件**：r < l_P 为量子引力内核不求解；r ≥ l_P 场方程有效；
   内边界 r = l_P 处场连续，κ(l_P) = κ_0（核心曲率）。

6. **总能量极小条件**

$$ E=\frac{\hbar c\kappa_0}{\sin\theta}-U_\text{self}(\kappa_0),\qquad \frac{dE}{d\kappa_0}=0 $$

该极值给出理论允许的最大稳态静质量 m_max，是基态存在的能量阈值。

> **推论 4.1**：稳态基态下螺旋几何参数满足自洽耦合（同盒式公式）。

# 4.3 稳态质量隐式关系（同步更新，沿用修正后的哈密顿）

## 4.3.1 前置关系回顾（边界力学平衡 + 泊松场解，R_c ≫ l_P）

$$ R_c(\kappa_0)=\left(\frac{\kappa_0\,l_P^2}{\sqrt{2}\,c}\right)^{2/3} $$

自能积分（能量密度 ℋ = ħc/2·|∇κ|²）：

$$ U_\text{self}\approx\int_{l_P}^{R_c} d^3x\,\frac{\hbar c}{2}|\nabla\kappa|^2
=\frac{4\pi\hbar c R_c^3}{2\,l_P^3}=\frac{2\pi\hbar c R_c^3}{l_P^3} $$
$$ R_c^3=\left(\frac{\kappa_0 l_P^2}{\sqrt2 c}\right)^2=\frac{\kappa_0^2 l_P^4}{2c^2} $$
$$ U_\text{self}=\frac{2\pi\hbar c}{l_P^3}\cdot\frac{\kappa_0^2 l_P^4}{2c^2}
=\frac{\pi\hbar l_P}{c}\,\kappa_0^2 $$

✅ 量纲核验（来料自述）：[ħ l_P/c] = J·s·m/(m/s) = J·s²；乘以 κ_0² ~ m^-2，[U_self] = J，能量量纲正确。

定义常数：

$$ \alpha=\frac{\hbar}{c\sin\theta},\qquad \beta_U=\frac{\pi\hbar l_P}{c^3} $$

总静能公理 $mc^2=\dfrac{\hbar c\kappa_0}{\sin\theta}-U_\text{self}$，两边除以 c² 得

$$ m(\kappa_0)=\alpha\kappa_0-\beta_U\kappa_0^2 $$

## 4.3.2 质量上界 m_max

$$ \frac{dm}{d\kappa_0}=\alpha-2\beta_U\kappa_0=0 \;\Rightarrow\; \kappa_\text{crit}=\frac{\alpha}{2\beta_U} $$
$$ m_\text{max}=\alpha\kappa_\text{crit}-\beta_U\kappa_\text{crit}^2=\frac{\alpha^2}{4\beta_U} $$
$$ m_\text{max}=\frac{\left(\frac{\hbar}{c\sin\theta}\right)^2}{4\cdot\frac{\pi\hbar l_P}{c^3}}
=\frac{\hbar c}{4\pi l_P\sin^2\theta} $$

✅ 量纲（来料自述）：[ħc/l_P] = J，除以 c² 得到质量。

> **引理 4.2（修正）**：V4.8 稳态基态在 R_c ≫ l_P 近似下，质量–核心曲率满足二次关系
> m(κ_0) = ακ_0 − β_Uκ_0²，在 κ_crit = α/(2β_U) 达到稳态质量上限
> m_max = α²/(4β_U) = ħc/(4π l_P sin²θ)。稳态基态仅存在于 m < m_max。

## 4.3.3 反常磁矩

$$ a_\text{TUFT}=-\frac{3c\cot\theta}{4e\hbar}\,m\kappa_0 $$

代入 m(κ_0)：mκ_0 = ακ_0² − β_Uκ_0³。

- 轻粒子（电子）：β_Uκ_0³ ≪ ακ_0²，修正项近似 ∝ m²，数值微小；
- 接近临界曲率（τ 子）：三次项贡献显著，抵消二次项，防止磁矩修正发散爆炸。

## 4.3.4 普朗克质量改写

普朗克质量 m_P = ħ/(l_P c)，ħc/l_P = m_P c²：

$$ m_\text{max}=\frac{m_P c^2}{4\pi c^2\sin^2\theta}=\frac{m_P}{4\pi\sin^2\theta} $$

m_P ≈ 1.22×10^19 GeV；要求 m_max > m_τ ≈ 1777 MeV，约束 sin²θ 为极小值，θ 趋近 π/2，自洽。

```python
import mpmath as mp
mp.mp.dps = 250
c    = mp.mpf('299792458')
hbar = mp.mpf('1.0545718176461565e-34')
e    = mp.mpf('1.602176634e-19')
me   = mp.mpf('9.1093837015e-31')
mmu  = mp.mpf('1.883531627e-28')
mtau = mp.mpf('3.16754e-27')
lP   = mp.mpf('1.616255078e-35')
Gexp = mp.mpf('6.67430e-11')

def Rc_of_kap(kap):
    return ((kap * lP**2)/(mp.sqrt(2)*c))**(2/3)

def U_self(kap):
    return (mp.pi*hbar*lP/c) * kap**2

def m_eq(kap, theta):
    sin_th = mp.sin(theta)
    return (hbar*c*kap / sin_th - U_self(kap)) / (c**2)

def kappa(m, theta):
    def f(kap):
        return m_eq(kap, theta) - m
    return mp.findroot(f, 1e34)

def a_tuft(m, theta):
    cot_th = mp.cot(theta)
    kap = kappa(m, theta)
    return -3*c*cot_th/(4*e*hbar) * m * kap

def chi2(theta):
    ae_qed  = mp.mpf('1.15965218128e-3')
    ae_exp  = mp.mpf('1.15965218059e-3')
    amu_qed = mp.mpf('1.16591810e-3')
    amu_exp = mp.mpf('1.16592040e-3')
    sin_th = mp.sin(theta)
    G_th = c**3 * lP**2/(hbar*sin_th)
    ae_pred = ae_qed + a_tuft(me,theta)
    amu_pred = amu_qed + a_tuft(mmu,theta)
    chi_e  = ((ae_pred - ae_exp)/1e-12)**2
    chi_mu = ((amu_pred - amu_exp)/4e-7)**2
    chi_G  = ((G_th - Gexp)/(Gexp*1e-5))**2
    try:
        kap_tau = kappa(mtau,theta)
        chi_tau = 0
    except:
        chi_tau = 1e12
    return chi_e + chi_mu + chi_G + chi_tau

def log_likelihood(params):
    theta = params[0]
    return -0.5 * chi2(theta)

def ptform(u):
    delta = 10**(-48 + u[0]*8)
    theta = mp.pi/2 - delta
    return [theta]
```
