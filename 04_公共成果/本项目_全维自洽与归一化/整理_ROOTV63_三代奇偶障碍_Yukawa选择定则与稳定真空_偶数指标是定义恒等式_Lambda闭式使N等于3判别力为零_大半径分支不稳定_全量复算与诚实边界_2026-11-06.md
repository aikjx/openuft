## 三 主定理 A：63-4 / 63-5 是阶数奇偶定理，不是四个数字凑成 1024

来料给出两条分解式并强调「两边维数都严格等于 1024」。本册不停在维数相加，而是从组合公式重建结构：

- 12 维反对称形式的全阶和：偶阶 `C(12,0)+C(12,2)+C(12,4)+C(12,6)+C(12,8)+C(12,10)+C(12,12) = [1, 66, 495, 924, 495, 66, 1]` 合计 **2048**；奇阶 `[12, 220, 792, 792, 220, 12]` 合计 **2048**；两者相加 `4096 = 2¹²`。
- Hodge 对偶把 `k` 与 `12−k` 配对，故各取一半：同手征侧取 `k = 0, 2, 4` 加 `C(12,6)/2 = 462`（自对偶 6-形式），得 `1+66+495+462 = 1024`；异手征侧取 `k = 1, 3, 5`，得 `12+220+792 = 1024`。
- **选择定则在阶数层成立**：`792 = C(12,5)` 属 `Λ⁵`，阶数 5 不在偶阶集合 `{0,2,4,6}` 而在奇阶集合 `{1,3,5}`，所以 `792 ⊄ 32_+ ⊗ 32_+` 且 `792 ⊂ 32_+ ⊗ 32_-`。

**负对照（`A05`）**：把 792 误认成 2-形式，则 `C(12,2)=66` 恰好落在偶阶侧，「792 不在同手征侧」立刻翻转。这证明判据测的确实是阶数奇偶，而不是「四个数加起来等于 1024」——与 V62 整理册 `E01`（同一误认事故）形成正向利用。

> 口径限制（`D02`）：`462_+` 中的「+」是手征标签。维数账对 `462_+` 与 `462_-` 给出**同一个读数 462**，所以该标签不是本册算出来的。按「关键表里的话也要由计算拼出」的纪律，本册不认领这个下标，只把它记为引文层的记号。

## 四 主定理 B：偶数指标是定义恒等式，它的真前提是「整数磁通」

### 4.1 恒等式与它的口径

来料 `(63-2)` 写 `I_Q = 2(N_F+N_Y) ∈ 2ℤ`。本册独立枚举 `N_F, N_Y ∈ [−8,8]`（289 组），得偶 289、奇 0、零指标 17 组。但按纪律这条记 **IDENTITY** 而非 PASS：`2 × 整数 = 偶数` 展开后没有残差可算，「相符」是规定不是推导。来料把它列为「第一项关键发现」，而 r391 已登记「偶数族模二定理对任意族数成立」、r393 已登记「净手征恒偶故三代不可达」——本册 `D01` 记 INFO，不新增证据。

**计数约定双读数（`A09`）**：取 `N_F=3, N_Y=0`，合并共轭的 `I_net = 6`（偶），单个 16 的 `I_16 = 3`（奇）。「偶数」是合并 `16` 与 `16bar` 计数的后果，不是指标本身的性质。本册只报这两个口径的读数，**不主张**哪一个物理上更合法——这是「读数支持不了的解读」刀的适用处。

### 4.2 半整数出口（`A08`）

允许磁通取半整数时，`I_Q = 2(N_F+N_Y) = 3` 在整数网格 **0 解**、半整数网格 **14 解**。也就是说，只要松开「整数磁通」这一个前提，来料 §一 的偶数障碍在纯代数层立刻消失。来料列出的三条出路（严格构造的边界投影、不同表示的手征内容、新的内部几何）**未列这条最便宜的第四条**。

### 4.3 质量配对与唯一判负

`(63-3)` 的 `n'_L − n'_R = n_L − n_R` 在显式 `5×3` 配对矩阵（rank 2）上复现：差 `2 → 2`（`B01`）。负对照只从 L 侧去掉 `r` 个 ⇒ 差变为 `0`（`B02`），证明恒等式依赖「成对消去」而非任何秩不变性。全秩档 `[0,1,2,3]` 中 `r=0` 的退化档有 `1` 个（`B03`），按纪律显式报零的个数，不把退化点当证据。

### 5.3 `Λ_6 = 41/144` 不是「人为选取」，是闭式唯一解（`C07`）

> **冻结参数刀**：把可调参数冻结在某一个样本上的解，再对其他样本扫描，必然造出「该样本唯一」的假象。识别方法是把参数放回自由状态再测一次通过率。

来料 §四 其实**已经诚实写明**「这不是从零自由参数推出了三代数，而是一个参数调谐的示范解」。本册不纠正来料，只把这句定性承认升级为可算定理（闭式 `Λ*(N)` + 7/7 判别力 0），并明确：从这张表里读不出任何关于「宇宙为何选三代」的信息。

另有一处同型判别力限制（`C06`）：`V''(φ_0) = 2μ²` 与 `λ` 无关，`λ=1,2,3` 给出同一个读数。因此「中性标量质量平方 = 1」是四次势形式的**输入**，不是稳定性成就；只要实极小点存在，标量方向恒正。真正带信息的是半径方向 `f''(9/4) = 256/6561 > 0`，它依赖 `A` 与 `N` 的调谐。
