# 判定册 · TUFT-r389 · 攻 `X-R387-2`：手性耦合量子化能不能定出 `theta`

**日期** 2026-11-03 · **对象** `X-R387-2`（r387 §八 留下的路：若 `g` 来自挠率拓扑荷则量子化）
**判词** `R389-CHIRAL-QUANTIZATION-CANNOT-FIX-THETA-OK-DENSE-SET-CANNOT-PIN-OK-LARGE-N-THRESHOLD-OK-INTEGER-RATIO-RELOCATES-ALPHA-OK-TARGET-CENTER-NOT-MONOTONE-OK-EXACT-MATCH-IMPOSSIBLE-OK-N-NOT-INTERNAL-FAIL-UNIQUE-PREDICTION-0`

**账** 条目 **39**（**28 PASS / 5 FAIL / 6 INFO**），守卫 **7/7**，`SURVIVE=0` ⇒ **不占度**，度数链维持 **36**，入池 **0** 条。
**口径** 一切公式按 r387 的**约定 A**：`tan(theta_A) = kappa/tau`、内点驻点 `g* = N cos(theta_A)`、`N := 2(a1-a2)`。r387 的混用版不再使用。

---

## 一、一句话答案

量子化**确实**把连续的 `theta` 换成了可数的整数比 `n/N` —— 但换掉的是**容器**不是**自由度**：`N = 2(a1-a2)` 在本框架内没有内生来源，于是 `n/N` 可取任意有理数，谱在 `[0,pi/2)` 上**稠密**，判别力仍是 **0**。

反过来，**只有当 `N` 被独立钉住时**量子化才真给有限谱，那时它变成一个**靶心问题**：要 `theta ≈ arctan(alpha)` 必须把 `N` 精确对准 `N* = 1/alpha^2 + 1 = 18779.865…`（最近整数 **18780**），偏差 `2.62E-8`。而这个 `N*` 是 `alpha` 的**算式**，不是理论的产出。

⇒ **`X-R387-2` 条件性关闭**：路线判负，条件是「`N` 无内生来源」这一条保持。

---

## 二、两种量子化，一个集合

`g` 的量纲是能量（`A01`：`hbar*w` 与 `hbar*c/R` 都用原语量纲加出来等于 `(1,2,-2)`），所以量子化只能写成 `g = n * E0`。问题是**用哪个 E0**。

| 能量单位 | `g` 的形式 | 方程 | 归一后的集合 | 相位组数 |
|---|---|---|---|---|
| `E0 = hbar*w` | `g = n` | `n = N cos(theta_A)` | `tan^2(theta_A) in Q` | 4/4 精确 0 |
| `E0 = hbar*c/R` | `g = n/cos(theta_A)` | `n = N cos^2(theta_A)` | `tan^2(theta_A) in Q` | 4/4 精确 0 |

两式**形式不同、集合相同**（`C01` 正对照：同一相位下两式都等于 `(S/C)^2`）。`A02` 记下两者在物理点上的比值恰为 `1/cos(theta_A)`，偏离 1 的量是 `2.662E-5` 量级 —— 只在 `theta -> 0` 时合并。

所以量子化允许的全部 `theta` 就是
```
S = { arctan(sqrt(q)) : q in Q, q >= 0 }
```
这个集合**可数**且在 `[0,pi/2)` 上**稠密**。「可数」听起来像钉住，「稠密」意味着没钉住。

## 三、分岔点不在物理，在分母

| `N` 的地位 | 谱 | 判别力 | 实测锚点 |
|---|---|---|---|
| 固定整数 | 恰 `N+1` 个值 | 1（真钉住） | `A05`：`N=10` 只 11 个值；`C02` 负对照：`n` 一旦允许非整数，11 个值立刻失效 |
| 自由（无内生来源） | 可数稠密 | 0 | `B08`：最佳有理逼近使偏差低到 `5.03E-17` |

**这是本卷最便宜也最贵的一条**：同一个量子化，`N` 固定就是「分立谱」，`N` 自由就是「什么都没有」。r387 已经证明 `a1,a2` 无内生来源 ⇒ `N` 无来源 ⇒ **落在右列**。

> `C02` 的负对照值得单独记：`n = 5/2, 13/3, 37/10` 三个非整数给出三个落在谱外的 `cos` 值。有限性**完全**来自「`n` 与 `N` 都是整数」这一条，与公式形式无关。

## 四、若 `N` 固定：靶心是 V 形，不是单调

先解靶心。`k := N - n` 是整数空隙，`cos^2(theta_A) = n/N = 1 - k/N`。取最小的非零空隙 `k=1`，令其等于物理值 `1/(1+alpha^2)`：
```
1/N* = alpha^2/(1+alpha^2)  =>  N* = 1/alpha^2 + 1 = 18779.865…
```
最近整数 **18780**（`B03`：解析靶心给 `N*=18780`，扫描 `N*-1, N*, N*+1` 实测最优也是 `18780`）。两条路径独立，读数一致。

| 量 | 读数 |
|---|---|
| `theta_A = arctan(alpha)` | `7.29722304214E-003` rad |
| `cos^2(theta_A)` | `9.99946751481E-001` |
| `sin^2(theta_A)` | `5.32485189649E-005` |
| `alpha^2` | `5.32513545207E-005` |
| `1/alpha^2` | `1.87788650449E+004` |
| 靶心 `N*` | `1.87798650449E+004` |
| 最近整数 `N` | `18780` |
| 该点 `theta` | `7.29719682230E-003` rad |
| 偏差 `dtheta` | `2.62198E-008`（相对 `3.59312E-006`） |
| 解析界 `1/(4N^{3/2})` | `9.71397E-008` ⇒ 实测在界内（`B04`） |

**`B05` 是本卷唯一一条被自己的读数推翻的断言。** 首版写「`N` 越大越准」；实测：

| `N` | `dtheta` 绝对值 | 在靶心哪侧 |
|---|---|---|
| `1000` | `2.43E-002` | 左 |
| `10000` | `2.70E-003` | 左 |
| `18779` | `1.68E-007` | 左 |
| **`18780`** | **`2.62E-008`** | **极小** |
| `100000` | `4.13E-003` | 右 |
| `1000000` | `6.30E-003` | 右 |
| `10000000` | `6.98E-003` | 右 |

偏差在 `N*` 处取**唯一极小**，两侧都回升 —— 因为 `theta(N) = arcsin(1/sqrt(N))` 从 `pi/2` 严格单调降到 `0`，与 `theta_A` 的**唯一**交点就是 `N*`。所以「想更准就把 `N` 放大」是错的，**必须对准靶心**。

两个配套定量：

| 断言 | 读数 | 条目 |
|---|---|---|
| 阈值：小 `theta` 要求 `N >= 1/alpha^2` | `1/alpha^2 = 1.87788650449E+004` | `B07` |
| 空隙：`N < 1/alpha^2` 时谱在 `(0, theta_A)` 内**为空** | `theta_min/theta_A`：`N=1:215.26`、`10:61.81`、`100:19.40`、`1000:6.13`、`18778:1.41` | `A07` |
| 小 `N` 完全不在物理量级 | `N=1:215.259` 倍、`2:107.630`、`3:84.344`、`5:63.538`、`10:44.092` | `B06` |
| 有限谱分辨率 `gap(N) ∝ N^{-1/2}` | `5.85808E-3 → 5.85787E-4 → 5.85786E-5`（`N=1e4/1e6/1e8`），两档比值 `9.99964E-2`、`1.000000E-1` | `B10` |

`B10` 的比值判据是刻意的：等比网格上「差值」不能判幂次，只有**比值**能（r383「等比网格退化刀」）。分辨率 `1/sqrt(N)` 意味着要把 `theta` 定到 `1e-9` 需要 `N ~ 3e17` —— 有限谱虽「真钉住」，代价是天文数字。

## 五、精确匹配：不是「很难」，是「不可能」

`cos^2(theta_A) = n/N` 精确等于 `1/(1+alpha^2)` 要求
```
N = n(1 + alpha^2) 为整数  <=>  n * alpha^2 为整数  <=>  (q/gcd(p,q)) | n
```
其中 `alpha^2 = p/q`。用 CODATA 定点值 `alpha = 72973525693 / 10^13`（分母 `10^13`）：

| 条件 | 数值 | 结论 |
|---|---|---|
| `alpha^2` 的分母 `q` | `10^26` | — |
| `gcd(p, q)` | `1`（分子为奇数且不含因子 5） | — |
| 需要的 `n` | `10^26` 的倍数 | 荒谬量级 |
| `n = 1..10` 实测 | `10/10` 全非整数 | 谱里没有该点 |

**口径自守**：`alpha` 是实测量，十进制写法是约定。所以这条只说明「用给定有效位数的 `alpha` 时精确解不存在」，不说明 `alpha` 在物理上不是有理数。这是本卷唯一一条带此限定语的判负（`G05`）。

## 六、结论：整数比搬家定理

把两边的自由度账摆在一起：

| 方案 | 未知量 | 独立方程 | 剩余维数 | 结果 |
|---|---|---|---|---|
| 零模 + 手性驻点（r385/r387） | `theta`、`N` | 1（驻点条件） | 1 | `theta` 自由 |
| 加量子化 `g = n E0`（`N` 自由） | `theta`、`N`、`n` | 2 | 1 | 稠密 ⇒ 判别力 0 |
| 加量子化 + `N` 钉住（`N` 固定） | `theta`、`n` | 2 | 0 | 有限谱，靶心 `N*` |

`N` 一旦被钉住，`theta` 确实被唯一确定 —— 但钉住的代价是**换一个新的输入 `N`**。而 `N` 的靶心值 `N* = 1/alpha^2+1` 是 `alpha` 的算式。于是：

> **整数比搬家定理**：手性耦合量子化把「`theta` 连续」换成「`cos^2(theta) = n/N`」，它**没有减少输入**，只是把 `alpha` 从 `theta` 的容器搬到 `N` 的容器。判别力的全部来源是「`N` 是否被独立钉住」，而这一点在本框架内**不可得**（r385 自由度账、r387 定理 A + 五个落选候选）。

这条与 r387 的两条旧结论同构：
- 与「构造性满射」同构：`tan theta = x/sqrt(c^2-x^2)` 满射 ⇔ `n/N` 稠密。
- 与「定义恒等式刀」同构：`cot(arctan alpha) = 1/alpha` 零信息 ⇔ `N* = 1/alpha^2+1` 零信息。**本卷是定义恒等式刀的第三次变体命中。**

一条副产物（`C04`）：`theta = 0`（纯圆）是**所有** `N` 共享的唯一谱点。量子化能无歧义定出的唯一点恰好是 r387 说的边界解 —— 而物理点不是它。

## 八、仪器自捕（`E01`–`E03`）

| 编号 | 首版怎么错的 | 改法 |
|---|---|---|
| `E01` | 把「量子化 ⇒ 离散 ⇒ 能定值」当链条，漏了「分母是否固定」 | `A05`（`N` 固定）与 `B08`（`N` 自由）分开判 |
| `E02` | 断言「`N` 越大越准」，被 `B05` 的 V 形直接否掉 | 拆成左侧递减 / 右侧递增 / 极小在靶心三条 |
| `E03` | 靶心整数写成 `18779`：漏了 `arcsin` 的立方项，且把 `sin^2(theta_A)` 当成了 `alpha^2` | `N* = 1/alpha^2+1` ⇒ `18780` |

`E03` 是 `alpha` 三口径刀的第 **4** 次命中：`sin^2(theta_A) = alpha^2/(1+alpha^2)` 与 `alpha^2` 差 `alpha^2/2` 相对。这条在 `B08` 上留下了可量化的痕迹 —— 若把靶错写成 `alpha^2`，会引入
```
arcsin(alpha) - arctan(alpha) = 1.943E-007
```
的**假偏差**。这不是算错，是**对象错位**（拿 `sin` 的靶去喂 `tan` 的量），而它在判据上是**全绿的**：偏差 1.94e-7 仍小于四舍五入界 3.65e-4。抓到它的是 `E03` 的复算，不是判据。

`C06` 把这条自伤固化成了负对照：错版恒等式 `k = N sin^2(theta)`（本卷首版原话）的残差是 `6/5`，非零 ⇒ 正版 `A06` 的检验确实有判别力。
