## 二、场方程组（变分导出）

### E1｜约束方程（δλ̃）

$$\kappa^2+\tau^2-\omega^2 \;=\; 0 \quad\Longleftrightarrow\quad R(\Gamma)+\tfrac{1}{2}T^{abc}T_{abc}=\omega^2$$

- **来源**：δS/δλ̃=0。
- **大白话**：几何总量（曲率+挠率平方和）被 ω 钉死；这是 P-H3 以约束形式进入动力学的结果。

### E2｜ω 标量场方程（δω）

$$\Box\,\omega + V'(\omega) + \frac{\tilde\lambda}{8\pi G_N}\,\omega = 0$$

- **来源**：对 ω 的欧拉–拉格朗日（L_ω 动能 + 势 + L4 约束项）。
- **大白话**：ω 像克莱因–戈登场一样演化，但额外多了一个"乘子项"（λ̃ω），是 P-H3 约束在动力学上的体现。

### E3｜Dirac 方程（δψ）

$$i\gamma^a D_a\psi - m_\psi\psi + \text{(挠率–旋量耦合修正)} = 0$$

- **来源**：δS/δψ̄。D_a 含自旋联络，挠率通过 contorsion 进入。
- **ζ=0 时标准 EC 结果**：挠率由自旋张量代数消去，Dirac 方程约化为含轴向–轴向四费米子接触项的修正 Dirac 方程（系数含 G_N，因子约定依赖，阶段3 数值对标时以文献锚核对）。
- **大白话**：旋量跟着"拧过的时空"走，拧的效应会折进费米子动力学——这是 g-2/EDM 预言的结构源头。

### E4｜Cartan 挠率方程（δΓ）

$$\big(1+\tilde\lambda\big)\,\big[\text{挠率–曲率结构}\big] + \big(\zeta+\tfrac{\tilde\lambda}{2}\big)\,\big[T\text{ 项}\big] = 8\pi G_N\,\sigma^{a}{}_{bc}\ (\text{自旋张量})$$

- **来源**：对 Γ 的 Palatini 变分（L1+L3+L4+Dirac 自旋联络共同贡献）。
- **两种情形的诚实判定**：
  - **ζ=0**：挠率项无导数 → T 由自旋张量 σ 代数决定（标准 EC Cartan 方程），可消去 → 四费米子接触项；**无幽灵**。
  - **ζ≠0**：T² 项带来 T 的运动导数 → 挠率传播 → 接触项约化失效 → **R1 幽灵风险进入检验区**（传播子符号需显式计算，本轮 OPEN）。
- **大白话**：物质自带"旋转"（自旋）就会拧出挠率；ζ≠0 时这个拧还可以自己传播——是利是弊取决于传播子符号。

### E5｜爱因斯坦方程（δg）

$$G_{ab}(\Gamma) + (\zeta+\tfrac{\tilde\lambda}{2})\big[T\text{ 修正}\big] + \Lambda\,g_{ab} = 8\pi G_N\big(T^{\omega}_{ab} + T^{\psi}_{ab} + T^{\text{SM}}_{ab}\big)$$

- **来源**：δS/δg^{ab}。注意 (1+λ̃) 调制出现在曲率项系数侧（有效引力强度时空变化风险，见 R5）。
- **大白话**：时空弯曲由物质能量–动量驱动，ω 场、旋量、SM 各自贡献；λ̃ 约束可能改变有效引力强度。

### E6｜Bianchi 一致性（δλ̃ × δω 交叉 + 能动守恒）

$$\nabla_a\big(G^{ab}+\cdots\big)=0 \;\Longleftrightarrow\; \nabla_a\big(T^{ab}_{\omega}+T^{ab}_{\psi}+T^{ab}_{\text{SM}}\big) + \frac{\tilde\lambda}{16\pi G_N}\,\nabla^b\big(\kappa^2+\tau^2-\omega^2\big) = 0$$

- **来源**：Bianchi 恒等式 + 约束 E1 的梯度；当 E1 处处成立时第二项消失 → 标准能动守恒恢复。
- **大白话**：几何的一致性（Bianchi）要求物质能量守恒；P-H3 约束如果处处成立，守恒自动恢复——这是"无隐藏矛盾"的第一道关卡（阶段1-4 还要逐项细查）。

### E7｜SM 场方程

$$\text{标准模型场方程在带挠率联络 }D_a\text{ 下整体协变化}$$

- **来源**：δS/δSM 场。
- **大白话**：标准模型的麦克斯韦/杨-米尔斯/希格斯方程原样成立，只把普通导数换成带挠率协变导数。
