## 下载后马上运行

1. 解压后打开 `ROOT_V64/web/index.html`，体验可旋转、缩放的交互 3D 地球近似场与真实几何参数一致的螺旋曲线。使用 WebGL2 的浏览器将尝试 GPU 渲染；如果没有 WebGL2，会自动使用 Canvas2D 降级。
2. 点击页面的“**打开精算和错误审计仪表盘**”，或直接打开 `ROOT_V64/web/v64_audit.html`。可切换 KG 能量分布、螺旋曲率/挠率、柱对称引力、诱导 G 的参数退化、Yukawa 第五力假设五种曲线。
3. 阅读 `research/00_结论与证明边界.md` 和 `research/01_失败原因逐条修复矩阵.md`，先掌握哪些结果已证明、哪些仍是开放问题。
4. 运行测试与重算：

   ```bash
   cd ROOT_V64
   python -m unittest discover -s tests -v
   python experiments/run.py
   ```

   Windows 可双击 `RUN_TESTS.bat`；Linux/macOS 可运行 `sh run_tests.sh`。Python 3.10+，核心和测试**只需标准库**。如果环境有 matplotlib，会重新生成 PNG 曲线；否则仍能生成 CSV、JSON。

5. 可选的**真实浏览器 UI 自动化冒烟测试**：`python experiments/browser_smoke.py`。需要安装 playwright，并且本机有 Chromium；此测试不是交付物的运行前置条件。

## 核心计算（最小可复现）

### 微观圆柱螺旋模态

`Ψ=A J1(qr) exp[i(θ+kz−Ωt)]`，`q=j11/a`，`Ω²=q²+k²+μ²`。这是理想圆柱边界中的经典复 Klein–Gordon 场解；**不是空间真实光速内部粒子结构的实验发现**。

- 解析截面能量 `U/L=15.700663592240126`（自然单位，指定参数）；
- 独立积分 `U/L=15.700663274067972`；
- 相对积分误差 `2.0265×10⁻⁸`；
- 轴向群速度 `0.19108996 c`，来自波导边界条件，不能解读为真空自由光子减速。

### 从能量密度到引力场

采用已知牛顿/GR 弱场模型：`g(r)=2G μ_enclosed(r)/r`（无限长柱对称）。若人为选 `μ_line=10kg/m`，在柱外 `r=0.3m`、使用实测 G：`g=4.4495333333×10⁻⁹m/s²`。这里真实测得的 G 是**输入**，而线密度 10kg/m 是**假设**。

### 一圈诱导曲率项

`1/G_ren = 1/G_bare + N(1−6ξ)ℏ F(μ)/(12π c³ℓ²)`，属于指定单实标量、sharp proper-time 截止下的系数。`N->4N,ℓ->2ℓ` 不改变最简系数；裸项还能抵消任意校正，因此目前不能独立决定 G。

## 三件绝对不要混淆的事

- **数值验证 ≠ 物理实验验证**：`63/63` 只代表代码与指定数学模型测试通过。
- **反求 `ℓP(G_obs)` ≠ 预测 G**：所有使用观测 G 定义尺度的结果都标注 `FIT/OBS`。
- **同一作用量写入四种已知力 ≠ 证明共同起源**：尚未从一个新原理推出规范群、粒子谱、耦合参数、量子引力和完整观测约束。

## 模拟真实性边界

没有真实 IGRF 地磁系数/EGM2008 地球重力数据库；3D 地球是理想球面 + 牛顿径向引力 + 对齐磁偶极，专用于演示方向。WebGL2 代码经过静态 JS 检查；本次 headless Chromium 环境 **未成功创建 WebGL2 上下文**，自动化测试实际走 Canvas2D fallback，并成功检验控件和无脚本异常，因此不能宣称原生 GPU 分支已在真 GPU 上验证。

`results/browser_smoke.json` 给出具体测试结果；未安装 Chromium/playwright 时不影响 Python 核心的数学测试。

已确立物理方程、Sakharov 诱导引力和 Bessel 场解属于已有数学/物理知识。本版的主要贡献是将它们组织成一条可追溯的条件推导链，标记反例、参数退化、可重复代码与明确的未证明命题。没有声称提出经过证实的原创大统一方程。
