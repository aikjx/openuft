## 特别禁止的捷径

- 把 \(n_+-n_-=3\) 直接称为三代夸克轻子。
- 把 \(SU(3)\times SU(2)\times U(1)\) 的 **李代数** 匹配直接称为有完整标准模型粒子表示。
- 把未知几何半径从已测 \(G\) 或粒子质量反算之后再说“独立预测”。
- 把分立的数学检查次数当成独立实验次数或统一理论已经证实的概率。
- 把纯 Einstein 真空作用量没解出的曲率问题，通过文字描述中的“通量”自动修好。
