# ROOT V149 测试与证据等级审计

日期：2026-11-24

## 已执行测试

- **66 项 Python unittest：通过**。涵盖零间隔螺旋、曲率-挠率、轴向 Lorentz boost、圆偏振 Maxwell 方程、能量-频率变换对照、NIST 常数换算、量纲、55 位十进制数值计算。
- **12 项 SymPy 符号恒等式：通过**。涵盖 null boost、螺旋恒等式、Maxwell 齐次/非齐次方程、场不变量、平面波相位、纯梯度联络。
- `results/high_precision_decimal.json`：55 位十进制执行结果，独立于普通 double precision 实现；额外小数位不等于实际物理测量精度。
- `results/frame_scan.csv`：200 组参考系 boost 值，包括 `β=u`，展示同一螺旋几何比例变化。
- `results/alpha_is_input_not_prediction.csv`：不同目标 α 都能被反向匹配，证明不能把匹配当作独立预测。
- `figures/boost_frame_dependence.svg`：比值随 boost 改变的示意图，非实测观测。

## 验证等级

| 命题 | 验证等级 | 结论 |
|---|---|---|
| 理想螺旋的曲率、挠率、频率关系 | 数学恒等式 | 在明确假设下成立 |
| χ=κ²/(κ²+τ²) 定义电磁精细结构常数 | 严格反例 | 不成立：同一世界线另一惯性系 χ=1 |
| 圆偏振 Maxwell 真空解 | 数学求解与一致性检查 | 成立；并非新发现 |
| h 或 ħ 从几何独立推出 | 尚未证明 | 仅量纲审计通过 |
| 电子引力耦合数值 | NIST 常数计算 | 数值量级可复算，非 ROOT 预测 |
| 四力具有共同微观运动起源 | 未得到独立理论和实验验证 | 尚未完成 |

所有“PASS”仅意味着程序/数学检查一致。没有在本轮对任何新力假说进行真实实验拟合。
