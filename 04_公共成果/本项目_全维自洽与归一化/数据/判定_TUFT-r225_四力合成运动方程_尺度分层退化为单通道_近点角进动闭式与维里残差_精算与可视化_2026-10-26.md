## 三、闭式核心

```
U(r) = -mu e^{-r/lam}/r + h^2/(2 r^2)
U'=0 => h^2 = mu e^{-x}(r^2/lam + r)          , x = r/lam
kappa^2 = U''/m = mu e^{-x}(1+x-x^2)/r^3
omega^2 = h^2/r^4 = mu e^{-x}(1+1/x) x / r^3
=> kappa/omega = sqrt((1+x-x^2)/(1+x))
稳定 <=> kappa^2 > 0 <=> x < phi = 1.6180339887   （与 r224 同源）
小 x 展开：domega = 2pi(omega/kappa - 1) = pi x^2 + O(x^3)
闭式反解：lam(a,e) = a^1.5 sqrt((1-e^2)/(3 r_s))
```

## 六、未闭合项

1. 本卷所有数值均使用**靶自报的** α_w = 1/29、α_π = 14.3（实验输入，非第一性）；若换成跑动耦合，B2 的「弱永不主导」在极高能（r ≲ λ_W）处需重审，但靶方程本身不含能标跑动机制（r218 已记）。
2. B2 的「弱通道永不主导」是针对**质子-质子**这一对物体；对不含强荷的轻子对结论不同，本卷未枚举所有物体对。
3. L4 只标定**进动层**的偏心修正 C(e)；圆轨道稳定性边界 x<φ 的 e 修正需 Floquet 分析，仍是开放项。
4. L5 的维里残差是**圆轨道**恒等式的严格结果；一般偏心轨道需用轨道平均，本卷未做。
5. 用无量纲耦合 α_w 乘 Yukawa 势来表征低能弱相互作用，与标准模型中低能弱力由费米常数 G_F（量纲 [E]⁻²）描述存在层级差异；本卷不作终审，标记为开放项。
6. 图 4 直接复用靶自产 JSON，纵轴跨度 92 个数量级，仅为示意。
