# 引力光速统一方程求导与精确验证工具

## 项目介绍

本工具提供了引力光速统一方程Z = Gc/2的权威求导与精确验证，通过多种数学方法严格证明了方程的正确性和物理合理性。

该方程揭示了引力与光速之间的深刻联系，为统一场论提供了坚实的数学基础，是物理学常数统一化进程中的重要里程碑。

## 核心功能

### 1. 几何因子2的严格数学证明
- 极角积分法
- 双重立体角积分法
- 三维空间向量投影法
- 多维几何对称法
- 张量分析证明法
- 群论对称性证明法

### 2. 符号求导分析
- 方程的一阶导数计算
- 高阶导数分析
- 链式法则应用
- 全微分与误差传播分析

### 3. 高精度Z值计算
- 理论Z值的高精度计算（支持小数点后20位以上）
- 论文精确值验证
- 近似值Z=0.01的误差分析
- 反向验证（从Z反算G值）

### 4. 量纲分析
- 基本量纲定义
- 引力常数G和光速c的量纲推导
- Z值的量纲推导
- 方程量纲一致性验证
- 不同单位制下的量纲分析
- 量纲的物理意义解释

### 5. 可视化功能
- 几何因子验证图示
- 三维球面积分可视化
- Z值比较图示
- 误差分析图
- 导数关系可视化
- Z-G-c三维关系图（交互式）
- 公式展示

### 6. 综合验证报告
- 支持多格式输出（控制台、JSON、Markdown）
- 多语言支持（中文、英文）
- 性能监控
- 可配置的验证选项

## 使用方法

### 基本用法

直接运行Python脚本：

```bash
python 权威引力光速统一方程求导与精确验证.py
```

这将使用默认参数执行完整的验证流程，并显示可视化结果。

### 命令行参数

本工具支持丰富的命令行参数来自定义验证过程：

#### 验证参数
- `--precision`: 高精度计算的小数位数（默认为20位）
- `--language`: 输出语言，支持'zh'（中文）和'en'（英文）（默认为中文）
- `--performance`: 启用性能优化

#### 报告参数
- `--report-format`: 验证报告输出格式，可选值：'console', 'json', 'markdown', 'all'（默认为console）
- `--report-dir`: 报告保存目录（默认为'./reports'）

#### 可视化参数
- `--no-visualization`: 不生成可视化图表
- `--vis-formats`: 可视化图表输出格式，可指定多个，如'png' 'pdf' 'svg'
- `--interactive`: 启用交互式图表

#### 特定验证选项
- `--skip-geometric`: 跳过几何因子证明
- `--skip-derivative`: 跳过符号求导分析
- `--skip-precision`: 跳过高精度计算
- `--skip-dimensional`: 跳过量纲分析

### 示例命令

1. 生成JSON和Markdown格式的报告，并保存为PNG和PDF格式的图表：

```bash
python 权威引力光速统一方程求导与精确验证.py --report-format all --vis-formats png pdf
```

2. 使用英文输出，精度设为30位：

```bash
python 权威引力光速统一方程求导与精确验证.py --language en --precision 30
```

3. 只执行几何因子证明和量纲分析：

```bash
python 权威引力光速统一方程求导与精确验证.py --skip-derivative --skip-precision
```
