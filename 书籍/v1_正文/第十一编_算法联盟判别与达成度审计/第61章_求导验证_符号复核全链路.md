## 61.1 验证对象与方法

本书第十编完成了圆柱螺旋运动的"严格求导总验证"，`07_统一场方程` 给出了统一场方程的变分推导。这些推导的可信度不能只靠原作者自证——必须**独立符号复核**。

本引擎（`源码/求导验证精算引擎.py`）用 sympy 从参数方程出发重新求导，逐项与书中闭式比对；EDM 链做单位换算复核。方法与第56章量纲零空间定理同源：**能符号闭合的，给 PASS；符号上不成立或定义性混淆的，给 FAIL/INFO**。零第三方依赖，仅 sympy + mpmath。

三条被复核的链：

- **A 组 圆柱螺旋链**（第54章）：`r(t) → v → a → Frenet–Serret(κ,τ) → 三重奏恒等式 → κ/τ 与 α 的关系`
- **B 组 Higgs 破缺链**（`07_统一场方程/02_变分推导` 推论 4.2/4.3）：质量矩阵对角化 → m_W, m_Z, m_γ → ρ = 1
- **C 组 挠率代数方程**（`07_统一场方程` 推论 1.1）：24×24 线性系统的 rank–nullity → "挠率不传播"
- **D 组 EDM 单位换算链**（第52/54章）：`d_e = eαρ/2` 的 C·m → e·cm 换算与证伪倍数

### 61.2.1 唯一 FAIL：A7 的符号定义混淆

符号求导给出：

$$\frac{\kappa}{\tau} = \frac{R}{b} = \frac{\alpha}{\sqrt{1-\alpha^2}} = \tan\theta \neq \sin\theta = \alpha$$

即 **κ/τ 严格等于 tanθ，不等于 α = sinθ**。第54章 §53.4.2 自己已经承认这一点（"α=tanθ 应修正为 α=sinθ"），但 §53.3.3 数值表、§53.7 五字段表、§53.9 已确认第5条仍在使用被自己否定的公式——把 κ/τ = 0.0072975469 标为"α 的预测值"，把 tanθ−sinθ = 2.66e-05 标为"误差"。

**这是定义性系统偏差，不是数值误差**：A8 证明 tanθ−α = α²/2 = 2.6626e-05 精确成立，A9 证明表中数值 0.0072975469 与 tanθ 吻合到 1e-7、与 sinθ=α 差 2.66e-05。第54章把"两个不同三角函数之差"误读成了"一个预言的残差"。

**勘正**：本章写作期间已修订第54章 §53.3.3、§53.7、§53.9 三处，明确 κ/τ ≡ tanθ，2.66e-05 为定义性偏差，α 取 sinθ 的 CODATA 值。这是全书中被符号复核抓出的唯一硬伤。

## 61.4 C 组：挠率代数方程 rank–nullity

UFE-1 的推论 1.1"挠率不传播"依赖 Cartan 方程

$$T^\lambda_{\mu\nu} + \delta^\lambda_\mu T^\sigma_{\nu\sigma} - \delta^\lambda_\nu T^\sigma_{\mu\sigma} = \kappa^2 s^\lambda_{\mu\nu}$$

未知量 T^λ_{μν} 对 (μν) 反对称，共 4×6 = 24 个分量；方程对每个 (λ, μ<ν) 一条，共 24 条。构造 24×24 整数矩阵 M 使 M·vec(T) = κ²·vec(s)。

| 编号 | 检查项 | 结论 |
| --- | --- | --- |
| C1 | Cartan 方程 (C') 的 rank–nullity | ✅ |
| C2 | 全反对称自旋流 ⇒ 全反对称挠率（推论 1.2） | ✅ |
| C3 | 与量纲零空间定理的方法同构性 | ℹ️ |

**C1 结果：rank = 24，nullity = 0**。M 可逆 ⇒ T 完全由 s 代数决定 ⇒ 挠率无独立传播自由度，**UFE-1 推论 1.1 成立**。C2 进一步验证：取 s = ε^{λμνρ}J_ρ 时解出的 T 亦为全反对称，与书中 T_{λμν} = (κ²/2)ε_{λμνρ}J^ρ 的系数比为 2（度规约定差异，如实保留）。

**C3 的元层次洞察**：本判定与第56章量纲零空间定理用同一套线性代数（nullity = n − rank），但语义相反：

- 量纲零空间（第56章）：nullity(D_A) = 0 ⇒ **什么都导不出**（{c,ℏ,G} 无法组合出无量纲常数）
- 挠率零空间（本章）：nullity(M) = 0 ⇒ **一切都由源决定、无自由度**（挠率被自旋流唯一固定）

两个零空间都为 0，却推导出相反的物理学结论。这正说明"秩-零度"是中性工具，结论取决于它在哪类方程上施用。

## 61.5 D 组：EDM 单位换算链

第54章 §53.5.4 引用的 EDM 值 d_e = eαρ/2 = 1.409e-13 e·cm，依赖横向半径 ρ 的取值。复核发现一个关键事实：

| 编号 | 检查项 | 结论 |
| --- | --- | --- |
| D1 | d_e = eαρ/2 在 ρ = 康普顿半径下的取值 | ✅ |
| D2 | 改用第54章修正后的 r_e 时 d_e 的变化 | ✅ |
| D3 | 证伪结论的稳健性（对 ρ 取值不敏感） | ✅ |
| D4 | 对称性论证与数值预言的并置关系 | ℹ️ |

- **D1**：ρ = ℏ/(m_e c) = 3.8616e-13 m（康普顿半径）时，d_e = 2.257e-34 C·m = 1.409e-13 e·cm，**与第54章引用值精确吻合**。即该数值用的是康普顿半径。
- **D2**：ρ = r_e = 2.8179e-15 m（第54章自己在 §53.3.1 判定应当替换掉的经典电子半径）时，d_e = 1.647e-36 C·m = 1.028e-15 e·cm。两值之比 = 137.036 ≈ 1/α——**第54章引用的 EDM 数值用的是它自己判定应替换的半径**。
- **D3**：JILA HfF⁺ 2023 上限 4.1e-30 e·cm。ρ=康普顿时超出 3.44e16 倍（16.5 个数量级）；ρ=r_e 时超出 2.51e14 倍（14.4 个数量级）。**两种取值下结论一致：均已被证伪**。预言值对横向半径敏感（差 137 倍），但证伪结论不敏感（差 2 个数量级但都远超上限）。
- **D4（INFO）**：第54章 §53.5 用螺旋对称性论证 d_e = 0（[A] 对称性结论），§53.5.4 又列出 d_e = eαρ/2（附加偏移假设）。二者不矛盾，但必须切割：**被证伪的是"破坏螺旋对称性的附加假设"，不是螺旋对称性本身**。书中把两者并置于同一节，未显式切割，易被误读。

## 61.6 全链路诚实结论

22 项复核给出明确的结构性结论：

1. **求导链本身是闭合的**。A1–A6（螺旋运动学）、B1–B5（Higgs 破缺）、C1–C2（挠率不传播）全部符号验证通过。本书的数学推导层可信。
2. **唯一硬伤是符号定义的混淆，不是推导错误**（A7）。κ/τ ≡ tanθ 是恒等正确结论，错在第54章部分表格把它当成了 α 的"预测值"。这是表述/登记错误，已勘正，不影响螺旋几何本身的数学正确性。
3. **EDM 证的不是螺旋模型，是附加假设**（D4）。螺旋对称性预言 d_e = 0（与实验相容）；非零 EDM 来自一个破坏对称性的额外假设，该假设被实验排除。S13 的 EDM 预言走的是同一路径（第55章 §55.5.1）。
4. **证伪结论对输入半径稳健**（D3）。无论取康普顿半径还是经典半径，预言都超出实验上限 14 个数量级以上。

**一句话**：本书的导数/推导层经独立符号复核，除一处定义混淆（已勘正）外全部成立；但推导成立 ≠ 统一场论成立——这正是第55–60章六条判据要衡量的那一层。
