# ROOT V102—V105：正向动力学攻坚路线（非已完成工作）

1. **V102：存在性与拓扑证书**：将 V100 21阶数值磁场换成连续源磁场，给出 Gaussian quadrature 截断误差的区间界，建立约化 Poincaré 返回映射及其 interval Newton/Krawczyk 证书。若 Jacobian 退化，改变射击参数或进行共振分支延拓。对无自交间隙和多边形结多项式建立严格区间包络，方可宣称连续真实方程的严格结分类。
2. **V103：辐射补偿的动力学实现**：选用确定的辐射反作用近似（Landau–Lifshitz 而非简单常数摩擦），加入时间变化电场与电源能量账本，验证完整周期的功 = 辐射 + 储能差。检查外部源是否位于粒子通道之外，源电流/线圈热噪声/有限尺寸限制。
3. **V104：轨道—场不可辨识逆问题**：加入扰动传感器和场测量点，比较仅轨道的 Jacobian 秩与联合场、加速度、磁通测量后的秩，证明能区分多少场参数，不能将三维曲率/挠率当作全部场的充分数据。
4. **V105：协变内部自由度**：尝试局域协变的标量/旋量/规范联络作用量；检查自由度、异常、幺正性、CPT/Lorentz、经典与量子极限，给出不依赖预设轨迹的可证伪观测量。未在此版本完成。

**优先级**：先物理理论的逻辑真实性，再数值精度；先可辨识和可证伪，后宣传统一。每个候选都需明确解是否严格存在、参数是否独立预测及实验能否排除。
