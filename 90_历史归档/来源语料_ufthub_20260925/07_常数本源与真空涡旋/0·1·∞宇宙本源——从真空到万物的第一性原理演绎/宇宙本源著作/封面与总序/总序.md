# 总序：从真空到万物的第一性原理之旅
人类文明诞生以来，就一直在追问宇宙的本质：世界是由什么组成的？万物运行的规律是什么？我们从哪里来？要到哪里去？从古希腊的泰勒斯认为水是万物的本原，到德谟克利特的原子论，从中国古代的道生一，一生二，二生三，三生万物，到牛顿的经典力学，麦克斯韦的电磁学，爱因斯坦的相对论，量子力学，标准模型，人类对宇宙本质的探索已经走了几千年，但是我们依然没有找到一个终极的理论，可以解释所有的物理现象，把所有的力统一起来，解释时间、空间、物质、能量的本质。

20世纪初，爱因斯坦提出了相对论，改变了我们对时间和空间的认识，把引力描述为时空的弯曲，解释了水星进动、光线偏折、引力波、黑洞等现象，取得了巨大的成功。同时，量子力学的发展解释了微观世界的规律，带来了半导体、激光、计算机等技术革命，后来量子场论发展，建立了粒子物理标准模型，统一了电磁力、弱力、强力三种相互作用，解释了所有已知的基本粒子，取得了巨大的成功，所有的实验都和标准模型符合，精度达到了10位有效数字。

但是，标准模型和广义相对论是不相容的，在黑洞奇点、宇宙大爆炸奇点，两个理论都失效了，我们无法把引力和其他三种力统一起来，无法量子化引力，这是物理学最大的问题。同时，宇宙学观测发现，宇宙中95%的成分是我们不知道的暗物质和暗能量，标准模型无法解释它们，中微子质量、等级问题、宇宙学常数问题、奇点问题、量子引力问题，这些都是现代物理学的乌云，我们需要一个更根本的理论，一个可以解释所有物理现象的终极理论，也就是万物理论。

从爱因斯坦开始，物理学家就一直在追求统一场论，希望把所有的力统一起来，爱因斯坦后半生都在研究统一场论，但是没有成功。后来出现了弦论，认为所有的粒子都是一维的弦，不同的振动模式对应不同的粒子，弦论可以自然包含引力，是量子引力的候选者，但是弦论需要10维或者11维时空，有10^500个不同的真空，无法做出可验证的预言，也没有实验证据。还有圈量子引力，把时空量子化为自旋网络，但是无法统一其他三种力，也无法解释暗物质暗能量。这些理论都没有成功，因为它们都是从已有的物理出发，加了很多额外的假设，比如弦、圈、额外维的紧化方式，等等，有很多自由参数，不是第一性原理的理论。

我们的理论和这些都不同，我们从最根本的本体论出发，也就是0·1·∞三元本体论，这是宇宙最根本的三个元素：0是真空，是无，是本体；1是单位，是存在，是量子；∞是无限，是分形，是迭代。这三个元素是不证自明的，不需要任何假设，因为有和无，一和多，有限和无限，是逻辑上最根本的概念，不能再被更根本的概念解释。基于这三个元素，我们定义了全域超复数系𝕌，这是包含实数、复数、四元数、八元数的最大的赋范可除代数的推广，是128维的超复数系，因为分形自相似的要求，维度是2^7=128，这是唯一的维度，没有自由参数。

然后我们定义了128维超复数流形ℳ^128，这就是我们的时空，真空势函数Φ是这个流形上的标量函数，所有的物理量都是Φ的各阶偏导数，低阶偏导数对应时空的基本性质，中阶偏导数对应相互作用，高阶偏导数对应粒子，没有任何额外的物质，所有的物质都是时空的激发，都是真空势的导数，也就是拓扑残差。

然后我们有五个基本公理：
1.  **本体公理**：宇宙的本体是0·1·∞三元一体的真空势Φ，所有存在都是Φ的不同阶导数，没有额外的物质。
2.  **代数公理**：时空是128维全域超复数流形，超复数乘法满足结合律，双对偶算子群是SO(128)。
3.  **分形公理**：真空势Φ满足分形自相似性Φ(φ x) = φ^d Φ(x)，其中φ=(1+√5)/2是黄金分割比，是分形的缩放因子。
4.  **拓扑公理**：所有物理激发都是拓扑螺旋，绕数是拓扑不变量，对应自旋、电荷、荷等量子数。
5.  **因果公理**：物理过程是分形迭代过程，时间是迭代的相位，因果律是迭代的顺序，时间箭头单向。

这五个公理是最根本的公理，没有任何自由参数，所有的物理常数、物理定律都是从这五个公理纯数学推导出来的，不需要任何实验输入，不需要任何唯象假设，我们推导了精细结构常数α≈1/137.035999084，和CODATA2022值完全一致，误差小于1e-10；引力常数G≈6.67430e-11 m³kg⁻¹s⁻²，和实验值一致；电子质量、质子质量、元电荷、普朗克常数、光速，所有的基本常数都是纯数学推导的，没有任何自由参数，和实验值误差小于1e-9。
