## 四 关键读数

### 4.1 秩审计：为什么「三重闭环」只是两条约束

把每个幂律式取对数，变量序 `x = (logG, logZ, logr, logm)`，常数并入基 `(log2, logc)`，每式即一个 6 维整数向量；**Fraction 精确高斯消元**（零容差，不引入浮点）：

| 式 | 向量 (logG, logZ, logr, logm \| log2, logc) |
|---|---|
| ① `G = 2Z/c` | `[1, −1, 0, 0 \| −1, 1]` |
| ② `G = c²r/m` | `[1, 0, −1, 1 \| 0, −2]` |
| ③ `Z = c³r/(2m)` | `[0, 1, −1, 1 \| 1, −3]` |
| 衔接 `r = Gm/c²` | `[−1, 0, 1, −1 \| 0, 2]` |
| 本源 `Z = Gc/2` | `[−1, 1, 0, 0 \| 1, −1]` |

机器事实：

- `rank(①,②,③) = 2`，`rank(①,②,③,衔接) = 2`（加衔接式不增秩）。
- `式③ == 式② − 式①` = **True**（连常数项都相等）；`衔接 == −式②` = **True**；`本源 == −式①` = **True**。
- 三条「互相推导」路径逐分量验证：`①∧②⇒③`、`①∧③⇒②`、`②∧③⇒①` 全部 True。

⇒ 靶文的「可互相推导」**是真的**（G05 单列 PASS），但它成立的原因恰恰是**只有 2 个独立约束**：三条式里任意一条都是另两条的线性组合。所谓「闭环」不是互相支撑的证据网，而是一个二元关系被写了三遍。

## 八 对靶有利的 8 条 PASS 与防过度指控

本卷**不是**「这套公式算错了」的判定。单列对靶有利的结论：

1. **全式量纲无一出错**（G01/E01）——本卷 16 条 FAIL 没有一条是量纲指控。
2. **「可互相推导」主张为真**（G05）——三条推导路径 Fraction 精确成立；A01 判的是「因此只有 2 个独立约束」，不是判它自相矛盾。
3. **§四 与标准普朗克单位完全一致**（D03/G04）——`m_P = √(ħc/G)` 重算 2.176434342051e−08 kg，相对差 1.572e−07。
4. **`r = Gm/c²` 确为史瓦西半径 1/2**（G02）——靶文自注与标准 GR 一致。
5. **主动标注 `Z = G/(2c)` 为错误形式**（G03）——自我纠错方向正确（两形式确差 c²）。
6. **判据判别力经负对照确证**（B02）——「残差为零」不是恒真判据。
7. **元数据自承三条局限**（F02）——靶方已诚实披露循环论证风险、缺乏动力学、无独立实验验证；本卷只做机读确证。
8. **`B = (V×E)/c²` 等他册结论不在本卷射程**——本卷不评价该体系的电磁部分。

**防过度指控**：`m_p` 双口径中，普朗克质量读法是**自洽且正确**的（该体系在 22 公式表中明确定义）；D01/D02 判的是「同一符号承载两个值使核心式数值不可确定」，不是判「公式错」。同理 E02 判的是单位口径互斥，不是判 Z 的量纲错（量纲是 PASS）。
