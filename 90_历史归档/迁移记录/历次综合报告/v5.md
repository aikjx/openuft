## 3.1 TS1：三重奏定理 κ²+τ²=(ω/c)²

**定理**：对满足光速约束v≡c的圆柱螺旋r(t)=(R cosωt, R sinωt, bt)，曲率κ和挠率τ满足
$$\kappa^2 + \tau^2 = \left(\frac{\omega}{c}\right)^2$$

**严格证明（sympy符号计算）**：
- 速度：v = r' = (-Rω sinωt, Rω cosωt, b)
- 加速度：a = v' = (-Rω² cosωt, -Rω² sinωt, 0)
- 加加速度：a' = (-Rω³ sinωt, -Rω³ cosωt, 0)
- 曲率：κ = |v×a|/|v|³ = Rω²/c²
- 挠率：τ = (v×a)·a'/|v×a|² = bω/c²
- 验证：κ²+τ² = (R²ω⁴+b²ω²)/c⁴ = ω²(R²ω²+b²)/c⁴ = ω²c²/c⁴ = (ω/c)² ✅

**sympy验证**：差精确为0
