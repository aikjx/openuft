## A 段 · 位下界的形式化

### A01 · 位成本定义与候选规格集显式化 · [PASS]

候选规格 S = (颜色代数 G_c, 弱代数 G_w, 超荷解 Y)，其中 G_c、G_w 各取 7 个 dim<=21 的紧致单代数，Y 取固定 N_c=3 后的解 ⇒ |S| = 7 x 7 x 2 = 98，位成本 log2(98) = 6.614710 bit。

- 证据：log2 7 = 2.807355；2*log2 7 + 1 = 6.614710 = log2 98
- 注：位 = log2(先验候选数/后验候选数)；先验界（dim<=21、N_c=3、N_gen=3）为显式声明，不是框架输出（见 E03/B06 的界依赖声明）

### A02 · 反常抵消对色数 N_c 的判别力 = 0 bit（严格、无界） · [PASS]

对一般 N_c 求解四类非平凡反常条件（[SU(N_c)]^2Y、[SU(2)]^2Y、[grav]^2Y、Y^3），解族为 Y_Q=1、Y_L=-N_c、Y_e=-2N_c、Y_d=2-Y_u、(Y_u-1)^2=N_c^2 ⇒ **每个 N_c>=2 恰有 2 个解**。机验 N_c=2..12 共 22 个解，全部六类系数精确 0（22/22）。

- 证据：判别力 = log2(N_c 先验数 / 后验数) = log2(N/N) = 0 bit，对任意先验界成立
- 注：这不是「数值上没筛出来」而是**代数恒等**：解族对 N_c 全参数存在，故反常抵消在任何 N_c 先验下都不删除任何 N_c ⇒ 0 bit（无界，与候选界无关）

### A03 · 反常抵消对代数 N_gen 的判别力 = 0 bit · [PASS]

N 代手征谱的反常系数按代**线性相加**，故给定单代解后任意 N_gen>=1 均为 0。机验 N_gen=1..12 全 0，且 A(N_gen)/A(1) = N_gen 逐位成立（比值精确）。

- 证据：线性缩放检验：ratio == N_gen 对六类系数全部成立 = True
- 注：与 G7 §2.2 的定性备注「N 代仍 0 ⇒ 反常自由不解释为何 3 代」一致；本册把它升级为**位计量 = 0 bit**

### A04 · 判别力的方向定位：3 条线性条件 = 0 bit，全部判别力来自 [U(1)_Y]^3 · [PASS]

线性条件（[SU(N_c)]^2Y、[SU(2)]^2Y、[grav]^2Y）秩 = 3、零空间维 = 2 ⇒ 解是**连续二维族**（对任何离散先验删除数为 0 ⇒ 0 bit）。反例：Y=(1,1,1,-3,-6) 满足三条线性条件、但 [U(1)]^3 = 162 != 0 ⇒ **判别力全部集中在三次条件**。

- 证据：秩 3 / 零空间 2（Fraction 精确高斯消元，见 B05）；反例 [U(1)]^3 = 162
- 注：这更正了一个常见表述「六类反常共同锁定超荷」——机器显示**只有一条**（Y^3）有判别力，另三条只是把 5 个未知压到 2 维连续族（不产生位）

## B 段 · 超荷解族与残余

### B01 · 一般 N_c 的反常自由解族闭式（本册承重事实 F1） · [PASS]

以 Y_Q=1 定标，令 Y_L=-N_c、Y_e=-2N_c、Y_d=2-Y_u，则 [SU(N_c)]^2Y 与 [grav]^2Y 自动为零；[U(1)]^3 化为 (Y_u-1)^2 = N_c^2 ⇒ **Y_u = 1 ± N_c**。机验 N_c=2..12 全部 22 个解六类系数精确 0。

- 证据：闭式 + 22 个精确解全零；N_c=3 退化为 Y_u in {4,-2}（与 B02 一致）
- 注：该闭式是「反常对 N_c 零判别力」的**代数根源**：N_c 不是被约束掉的，而是解族的一个自由参数

### B05 · 线性条件秩 = 3、解空间维 = 2（Fraction 精确消元） · [PASS]

三个线性反常条件对 (Y_Q,Y_u,Y_d,Y_L,Y_e) 的系数矩阵秩 = 3，零空间维 = 2 ⇒ 解为连续二维族。

- 证据：rank=3, nullity=2（精确有理数消元，非浮点）
- 注：连续族 ⇒ 线性条件单独不能产生任何位（这是 A04 的算据）

### B02 · N_c=3 退化为 2 支：SM 与「SM 的 u↔d 重标号」 · [PASS]

Y_u=4 支按 Y_Q=1/6 归一即 (1/6, 2/3, -1/3, -1/2, -1) = SM 超荷（逐位一致）；Y_u=-2 支归一即 (1/6, -1/3, 2/3, -1/2, -1)，等于把 u_R 与 d_R 的 Y 互换。两支六类系数均精确 0。

- 证据：SM 六类系数 = {'A_c3': '0', 'A_w3': '0', 'A_c2Y': '0', 'A_w2Y': '0', 'A_gY': '0', 'A_Y3': '0'}（全 0）；重标号支 = {'A_c3': '0', 'A_w3': '0', 'A_c2Y': '0', 'A_w2Y': '0', 'A_gY': '0', 'A_Y3': '0'}（全 0）
- 注：与 G7 §2.1「SM 谱反常自由」一致；本册补的是**解的个数**（2）而非仅「是/否」

### B03 · 解族六类反常系数为**精确零**（Fraction，非浮点噪声） · [PASS]

对 B01 的全部解逐个代入六类系数，非零项计数 = 0。（G7 原文用浮点，[U(1)]^3 报 2.22e-16；本册为精确有理数运算 ⇒ 逐位 0。）

- 证据：非零项 = 0 个（0 才 PASS）
- 注：口径升级：浮点零 ⇒ 精确零。这消除了「残差是否噪声」的解释空间

### B04 · 两支互为 u↔d 置换 ⇒ 无序解唯一；残余为「标号 bit」 · [PASS]

对 N_c=2..12 逐值验证：Y_u(支1) == Y_d(支2) 且 Y_d(支1) == Y_u(支2)，其余三个分量相同（True）⇒ 两支只差 u_R/d_R 的**标号**。有序解 2 个（残余 1.000000 bit），无序解 1 个（残余 0 bit）。

- 证据：置换等价 = True；残余 1 bit 只在「u 型/d 型标号算不算规格的一部分」口径下存在
- 注：本册**不代选**该口径（见 B06）：若把「哪一支叫上型」算外部输入 ⇒ 1 bit；若视为同一物理（只差命名）⇒ 0 bit

### B06 · 「残余 1 bit」的口径依赖（不代选） · [BOUNDARY]

B04 显示两支只差 u/d 标号。两种口径给出不同的位账本：
  口径 I（标号是规格的一部分）：超荷残余 = 1 bit，位下界 = log2 98 = 6.6147 bit；
  口径 II（标号不参与规格）：残余 = 0 bit，位下界 = log2 49 = 5.6147 bit。
两口径的**公共结论**是：反常抵消不消除「颜色代数 × 弱代数」这 5.614710 bit，且框架对它们供给 0 bit。

- 证据：6.6147 (口径 I) vs 5.6147 (口径 II)，差恰 1 bit
- 注：按 r59 的容差同源纪律：口径必须先声明再报数；本册两口径并列，不取平均

### D02 · R10「3 代 = SU(2)_k 的 k+1 个单值表示」——**SU(2) 是前提不是结论** · [CORRECTED]

R10 §LCS-3 的链条是：存在费米子 ⇒ k=2 ⇒ SU(2)_k 单值表示数 = k+1 = 3 ⇒ 3 代。其中「表示数 = k+1」**只在 A1 型（SU(2)）成立**（SU(N)_k 的单值表示数 = C(N+k, k) 而非 k+1）。⇒ 该链条**预设了群是 SU(2)**，因此它对「为何是 SU(2)」提供 0 bit。

- 证据：SU(N)_k 单值表示数 = binom(N+k-1, k)，仅 N=2 时退化为 k+1（binomial(2+k-1,k)=k+1）
- 注：不推翻「3 代 = k+1」在其自身域内的正确性；收窄的是它对**群选择**的贡献（0 bit）

### D03 · TUFT 拓扑路对「群选择」的位贡献 = 0 bit（供给侧不足） · [FAIL]

把 TUFT 能输出的拓扑/几何量逐项对位账本核账：
  (i) CS level k：只给 k，不指定 N（D01：5 个候选）⇒ 0 bit，且缺口 log2 5 = 2.321928 bit；
  (ii) Lk（Hopf 链环数）∈ 半整数：与群维数/秩无函数关系；
  (iii) 结行列式 det(K) ∈ Z：同上；
  (iv) 几何不变量（κ、τ、ω）连续：对离散群因子无约束。
⇒ 四条路径对「颜色/弱因子是哪一代数」全部 0 bit ⇒ FAIL（供给侧不足，非计算失败）。

- 证据：缺口最低估计 = log2 5 = 2.321928 bit（仅 k 一路）；若同时要求 c 则 N 唯一，但 TUFT 未输出 c
- 注：可修：若 TUFT 能输出中心荷 c 或量子维数 d（WZW 可算），缺口可补到 0 bit。本册只登记该补法存在，不自推 c 的第一性来源
