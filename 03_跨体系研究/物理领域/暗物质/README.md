# 暗物质直接探测（研究主题档案）

> 通过地下实验直接探测暗物质粒子与普通物质的相互作用，确定暗物质的粒子性质（WIMP / 轴子 / 暗光子 / 惰性中微子）。

## 问题定义

宇宙约 27% 能量密度由暗物质构成，粒子本质未知。核心候选：WIMP（~100 GeV–TeV，热遗迹）、轴子（~10⁻⁶ eV，解强 CP）、暗光子（U(1)′ 规范玻色子）、惰性中微子（keV，温暗物质）。核心目标：探测暗物质–靶核弹性散射/吸收信号。

## 当前进展（2020–2026）

| 实验 | 结果 |
|---|---|
| LUX-ZEPLIN (LZ) 2023 | 未发现 WIMP；排除自旋无关截面 σ < 9.2×10⁻⁴⁸ cm²（30 GeV） |
| XENONnT 2023 | 未发现；LZ/XENONnT/PandaX 联合排除 |
| ADMX 2023 | 轴子搜索，排除部分参数空间 |
| 总体 | 无确认暗物质直接探测信号 |

## 证伪条件

- 若长期无信号且灵敏度达中微子背景，WIMP 路线受压
- 若引力修正（MOND 类）解释全部观测，粒子暗物质假设削弱
- 若发现确定信号，粒子暗物质方案获确认

## 入库触发与状态

- **入库触发**：给出可测量截面/质量预言，且目标体系过第一性审查并登记 claims
- **当前状态**：开放问题，无确认信号；WIMP 参数空间被大幅压缩，轴子与暗光子为活跃方向

## 分析进展（求导证明验证 + 精算分析）

脚本 `verify_dark_matter_direct_detection.py` 复算：

- **WIMP 奇迹**：标称 <σv>=3×10⁻²⁶ cm³/s 给出 Ωh²≈0.120，与观测 Ω_c h²=0.120 同阶（PASS）
- **质量网格反解**：m_χ~10² GeV 最自然（弱尺度窗口）
- **上限标定**：热遗迹典型 σ_SI≈3×10⁻⁴⁶ cm²，相对 LZ 上限高 ~10³ 倍 → WIMP 窗口被覆盖但未全闭（BOUNDARY）
- **轴子窗口**：m_a~10⁻⁶ eV，ADMX 排除部分带

## 诚实边界（红线，不粉饰）

1. 本册仅复算标准 WIMP 热遗迹与实验上限标定，非 openuft 体系的新推导
2. 数学自洽 ≠ 实验证实：截至 2026-09 无任何确认直接探测信号
3. 若达中微子背景灵敏度仍无信号，WIMP 路线将承压
