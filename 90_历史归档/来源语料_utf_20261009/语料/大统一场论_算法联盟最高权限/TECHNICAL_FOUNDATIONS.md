### 2.2 e^(-π²/2) 的数学本质

e^(-π²/2) 不是一个随机数。它在多个核心数学结构中出现：

**高斯函数**：
```
e^(-π²/2) = f(π), 其中 f(x) = e^(-x²/2)
∫_{-∞}^{∞} e^(-x²/2) dx = √(2π)
```

**Theta 函数**：
```
θ₃(0, e^(-π²)) = Σ_{n=-∞}^{∞} e^(-π²n²)
                 = 1 + 2e^(-π²) + 2e^(-4π²) + ...
                 ≈ 1.0001034...
```

**热核**：
```
G(x,t) = (4πt)^(-1/2) e^(-x²/(4t))
G(√(2π), 1/2) = (2π)^(-1/2) e^(-π²/2)
```

**谐振子基态**：
```
ψ₀(x) = (ω/πℏ)^(1/4) e^(-ωx²/(2ℏ))
ψ₀(π) ∝ e^(-π²/2)
```

**解释 A：时空量子涨落**
- 真空的零点能遵循高斯分布
