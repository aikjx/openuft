## 1　攻破目标

§26 发现：eq(20)（一循环 lead-log）用 §25 裸 m_Z 耦合 + 简并谱反推 M_Hc=5.3×10¹⁷ GeV（>M_GUT，非物理），如实标注为"失效边界"。失效原因诊断：① 一循环公式不含两循环跑动修正（对组合 c1=3/α₂−2/α₃−1/α₁ 的量级 ~−1.8）；② 谱内漏了 SM+gaugino 与 gaugino 阈值。

**§27 的修复**：把三条缺失补进两循环链——
- **SM+gaugino 跑动**（eq(12)(13)：b=(41/10, −11/6, −5)，b2=b2_SM+b2_gaug）；
- **gaugino 阈值**（eq(18)：1/α₂ 减 (2/3π)ln(M_S/M₂)、1/α₃ 减 (1/π)ln(M_S/M₃)，α₁ 不变）；
- **GUT 阈值组合**（eq(17)：c1 = −(6/5π)ln(μ/M_Hc)，c2 = −(6/π)ln(μ³/(M_X²M_Σ))）。

## 2　方法

### 2.1 阈值链（脚本实现）

```
m_Z →(SM+gaugino 两循环)→ M_S →(gaugino 阈值 eq18 + Yukawa 匹配 eq19)→(MSSM 两循环)→ 交叉点(α₁=α₂)

        c2 = 5/α₁−3/α₂−2/α₃ → (M_X²M_Σ)^(1/3) = μ·exp(+(π/18)·c2)
```

### 2.2 符号修正记录（§26 遗留易错点）

eq(17) 换算 1/α 形式：c1 = −(6/5π)·ln(μ/M_Hc)。M_Hc < μ（色三重态在 GUT 之下）时 ln(μ/M_Hc)>0 → **c1<0** → M_Hc = μ·exp(**+**(5π/6)·c1)。初版误用负号 → M_Hc 虚大 38 倍并引发 Hc 迭代步数爆炸卡死；修正后与文献精确吻合。此修正记录在案，防后续重踩。

### 2.3 Hc 入 β 的两种约定

- **无 Hc 入 β（文献 eq(20)(21) 约定）**：M_S→M_GUT 全程 MSSM β，Hc 阈值效应全部由 eq(17) 吸收。
- **Hc 入 β（物理完整约定）**：M_Hc→M_GUT 区间 β 加入 Hc 一循环贡献 Δb=(35/18, 2/3, 1)，迭代自洽。

### B. 工程 bug 修正记录（本节）

1. **eq(17) 符号**：M_Hc = μ·exp(+(5π/6)c1)（初版负号 → M_Hc 虚大 38 倍 → Hc 迭代步数爆炸卡死；修正后命中文献）。
2. **n1 无界**：Hc 分段步数公式未钳制 → 二分下界逼近 M_S 时 n1 爆炸至百万级（挂死）；修复为 min(steps, ·)。
3. **n2=0 除零**：n1 钳制后 n2 可为零 → 加 `if n2>0` 保护。
4. 纯 Python 版本 ~2 亿次运算卡死 → numpy 向量化（单次 run_chain 0.06 s → 全流程 <30 s）。
