## 三、结论边界（一屏摘要）

**可导出（🔵 可复算）**
- 强扇区：亥姆霍兹点源解 κ = A e^{−μr}/r、**E1 势** V = −c²A·E₁(μr)（V(∞)=0；大 r = 汤川尾 g²_eff = c²A/μ，小 r = 对数核）、量纲链。
- 电磁扇区**运动学 + 齐次动力学**：A^μ = k τ^EM,μ ⇒ F=dA；(E,B)↔F↔τ 三向一致；I₁ = 2(B²−E²/c²)、I₂ ∝ E·B 洛伦兹不变；boost 与标准式一致；**Bianchi 自动成立**；[k] = V·s。
- 数值（模型内）：E1 vs 汤川在 **μr≳8 严格同尾**；差异全在 r≲1/μ（0.5 fm 时 |U_E1|/|U_Y| = 0.396）；临界耦合比 **1.508**、氘核口径 β* 比 **1.588**；δ_{l=0} 最大差 **142.2°**；量子层 Λ_c = (l+1/2)²，对数核 Λ_eff = 0 < 1/4 ⇒ **H 本质自伴且有下界**。

**不可导出 / 已被排除（🔴）**
- **Maxwell 源项不可由几何导出**（R19-6 决定性判定：自由作用量变分给无源方程；自源 J^ν = σ τ^ν 不守恒 **且** 非规范不变；Proca 被 μ_EM=0/O16 排除 ⇒ 源必须来自外部守恒电流）。
- O15（α/电荷量子化）、O16、O17、R2；规范量子数编码（信息缺口 1.74 bit，TUFT 定位 = 自旋/统计的拓扑编码框架）。

**已修正的审计自身缺陷**：`AL-D5-5e` 同义反复（R15）、「PASS 24」口径高估（R15，引入 `kind` 计算型/声明型）、R7 过陈述（R16）、R8 循环性（R17）。
