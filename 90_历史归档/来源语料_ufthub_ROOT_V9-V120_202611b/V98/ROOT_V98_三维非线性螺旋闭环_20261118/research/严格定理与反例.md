# ROOT V98｜严格恒等式、有限条件结论与反例

1. **磁力不做瞬时功（严格）**：`v·(q v×B)=0`；在无电场、没有辐射反作用的测试粒子模型中，动能和速率保持常数。
2. **轴对称正则动量（严格，在轴对称规范与静场条件下）**：`P_phi=γm r²φdot+qψ(r,z)`；机械角动量不是独立守恒量。
3. **固定源真空区 Maxwell 条件（已知电磁理论）**：对处在电流支撑之外的连续 Biot–Savart 场，`div B=0`，`curl B=0`；本轮有限差分验证仅在测试点成立，不可把网格差分当作解析证明。
4. **非线性返回的检验逻辑**：对某个径向极大值点要求 `phi-10π=0` 与 `vz=0` 是搜索条件，但不足以自动证明整条六维相轨道返回；必须核验 `x,y,z,vx,vy,vz` 全部残差。
5. **反例：三维运动并不自动空间闭合**。弱聚焦中径向与轴向频率一般无理，纵使各自有界，也不保证共同周期。
6. **反例：数值残差小不等于严格存在性**。射击依赖源求积、时间积分和数值求根；需要区间证据才能提升为严格周期轨道存在定理。
7. **反例：闭合不等于无耗能**。加速带电粒子在给定轨迹上经典辐射非零；静磁场不提供补偿功。
8. **反例：空间三维闭环不等于四力统一**。本项目的力完全来自输入的 Maxwell–Lorentz 动力学，并未产生新的基本相互作用。
9. **反例：三维周期轨道不自动是非平凡结**。必须单独证明没有自交并计算适当拓扑不变量。
10. **反例：数值单周期靠近初态，不证明无限时稳定**。多周期 Floquet 谱需要高精度变分积分与剔除中性乘子，否则近单位特征值的误差不可辨。

**等级标注**：1–3 属于明确条件下的既有物理或精确代数；4–10 是必须遵守的审计准则及具体反例；V98 的三维候选解属于数值模型证据，不是新的基础物理定理。
