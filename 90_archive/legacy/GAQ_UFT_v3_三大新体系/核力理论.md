## 一、核力的几何本源

### 1.1 强力的几何来源

核力的根源是**强力**，对应曲率张量的**对称无迹张量模式**（Weyl 张量 $C_{\mu\nu\rho\sigma}$，10 个独立分量）。

```
曲率张量 R_μνρσ (20分量)
├── 标量迹 (1)     → 引力
├── 对称无迹 (10)  → 强力  ← 核力来源
├── 反对称 (6)     → 电磁
└── 轴矢量 (3)     → 弱力
```

### 1.2 从强力到核力（剩余相互作用）

核子（质子/中子）由夸克组成，夸克间通过胶子交换受强力束缚。核子间的"核力"是夸克束缚的**剩余相互作用**——类似分子间的范德华力是电磁力的剩余作用。

```
曲率对称无迹张量 → 胶子场 → 夸克confinement → 核子
                                                      ↓
                                         剩余相互作用(核力)
                                                      ↓
                                              π介子交换 → 汤川势
```
