[E1] 标准 QCD 质量方案事实（pole / MS-bar 定义 + PDG 外部输入，只引用不复算）
  极点质量 = 夸克传播子自能零点（on-shell 极点），定义上与重整化标度 μ 无关
  MS-bar 质量 = MS-bar 方案重整化后的跑动质量，显式依赖 μ（QCD 跑动）
  PDG 外部输入：m_t^pole = 172.69 GeV；α_s(M_t) = 0.1080；m_t^MS(M_t) = 162.5 GeV；v = 246.22 GeV
  => PDG 夸克质量表 + α_s 跑动（标准 QCD 外部输入，只引用不复算）；本册只做换算与跑动精算，质量值不归因 TUFT。

[E2] 一阶 pole↔MS(M_t) 换算核算（本册核心，Decimal 48 位逐位精算）
  题给一阶关系：m_pole - m_MS = (4α_s/3π) m_MS ⇒ k1 = 4α_s/(3π)
  k1 = 4×0.1080 / (3π) = 0.04583662（= C_F·α_s/π，C_F=4/3）
  正向：m_pole^(1) = m_MS(M_t)×(1+k1) = 162.5×1.045837 = 169.948 GeV
  反向：m_MS^(1)(M_t) = m_pole/(1+k1) = 172.69/1.045837 = 165.121 GeV
  --- PDG 双质量对照 ---
  实测比 R = m_pole/m_MS(M_t) = 172.69/162.5 = 1.062708
  正向一阶距实测 pole 缺口 = 172.69 - 169.948 = 2.742 GeV
  反向一阶距 PDG MS 高出 = 165.121 - 162.5 = 2.621 GeV
  => 一阶 QCD 关系把 pole 与 MS(M_t) 差钉死在 ~4.58%；双向缺口一致（~2.5 GeV），
     缺口即高阶（2 圈+3 圈）匹配修正（见 E4）。标准 QCD 换算算术复核。

[E3] 标度依赖核算：μ=M_t vs μ=2 GeV 的 MS 质量跑动（领头对数，n_f=5）
  跑动式 m(μ)=m(μ0)[α_s(μ)/α_s(μ0)]^{γ0/(2β0)}；β0=23/3、γ0=4 ⇒ 指数=0.260870（=6/23）
  ln(μ/μ0)=ln(2/172.69)=-4.458351
  1 圈跑动：α_s(2 GeV) = 0.261833（由 α_s(M_t)=0.1080 跑下）
  质量跑动比 m(2GeV)/m(M_t) = [α_s(2)/α_s(M_t)]^{6/23} = 1.259884
  ⇒ m_t^MS(2 GeV) ≈ 162.5 × 1.2599 = 204.73 GeV（> m_MS(M_t)，跑向低标度质量增大）
  => MS 质量强标度依赖：μ 从 172.69 GeV 降到 2 GeV，质量涨 ~26.0%；
     而 pole 质量定义上 μ 无关——这正是两种方案不可互换的根源（阈值匹配本册不展开）。

[E4] 一阶 vs 高阶修正量分解 + 方案歧义向 y_t 传播（衔接 C0194）
  总修正 δ_total = R-1 = 0.062708；一阶 k1 = 0.045837；高阶残差 δ_ho = δ_total-k1 = 0.016871
  高阶/一阶 = 0.3681（即 2 圈+3 圈修正达领头项的 ~37%，非可忽略）
  --- Yukawa 方案传播（v=246.22 GeV，衔接 C0194 y_t=0.993660）---
  y_t(pole) = sqrt(2)×172.69/246.22 = 0.99187938
  y_t(MS)   = sqrt(2)×162.5/246.22 = 0.93335108
  Δy_t = 0.058528（相对 MS 方案 6.27%）——质量方案歧义直接进 Yukawa，不可忽略。
  => 一阶关系仅抓住 ~64% 的修正（k1/δ_total），高阶贡献 ~36%；方案选择使 y_t 漂移 ~6%，与 C0194 的 O(1) 结论相容但读数依赖方案。
