## §二　主定理：偶数族模二定理

### 2.1 陈述与证明

设谱里有 m 个六维手征 16，第 i 个带家族电荷 `q_i ∈ ℚ`、手征符号 `s_i = ±1`，其零模数 `Q_i = q_i N`（`N` 为球面单极磁通量子数）。若

```
Q_i ∈ ℤ   对每个 i        （零模数必须是整数）
Σ s_i q_i² = 0              （两个 16 的局域反常相消，A2 已证这是充要条件）
```

则净手征族数 `n = Σ s_i Q_i` 必为偶数。证明三行：

```
①  Σ s_i Q_i² = N² Σ s_i q_i² = 0
②  Q² ≡ Q (mod 2)        对任意整数 Q
③  n = Σ s_i Q_i ≡ Σ s_i Q_i² ≡ 0 (mod 2)     ∎
```

**为什么它对任意族数成立**：`s_i = ±1 ≡ 1 (mod 2)`，所以 `s_i` 在模 2 下**全部相同**，族数与符号分配都不进入结论。这正是「加一个额外 16 也改不了奇偶」的代数原因。

### 2.2 两条独立代码路径

| 路径 | 做法 | 读数 |
| --- | --- | --- |
| A（A4） | 先按 `(Σq², Σq⁴)` 建多重集键，再左右配对，最后逐项翻号求 `n` | 107 组构型、n≠0 的 92 组、全偶、`min\|n\|≠0 = 2` |
| B（G14） | 直接在 `(Q_i, s_i) ∈ [−6,6]^k` 上遍历，不经过任何配对或开方 | k=1..4 解数 0 / 48 / 0 / 6336、全偶、`min\|n\|≠0 = 2` |

两条路径不共享中间量（B 连 `q = √(q²)` 这一步都没有，用 `isqrt` 也不用）⇒ 排除「多重集键写错」「从 q² 反推 q 写错」两类自伤。

### 2.3 三条抗反驳

1. **「你只验了小 q」**：模二定理不依赖穷举 —— 穷举只是复核，证明是那三行。B 路径把上界放到 6 仍全偶，A 路径放到 22。
2. **「加额外 16 就能凑成奇数」**：`n` 是**偶数个奇偶性相同的量之和**，加项只会让 `n` 按 `±Q` 变，而每个 `Q` 与 `Q²` 同奇偶 ⇒ 加任何项都保持偶。A4 的构型里已含 2/3/4 族三种族数。
3. **「`Σ s_i q_i² = 0` 太强」**：这不是本卷加的，是 A2 从 `I₈` 三项（`x⁴`、`x²T`、`x²p₁`）同时为零推出的**充要**条件。放宽它等于允许局域反常不抵消。

### 2.4 边界（诚实）

前提是「球面单极磁通 + 零模数整数」与「两个 16 的局域反常相消」。若改用 orbifold / Wilson line / 环面，零模数不必是整数，`Q² ≡ Q (mod 2)` 失效 ⇒ 结论不适用（见 §九 X-R391-1）。这不是修补，是换理论结构。

| `min\|n\|≠0` | — | **2** | — | **2** | **2** | **2** |

### 3.2 k=1、3 无解不是整数性问题

一侧 1 项、另一侧 ≥2 项时，令 `u = q²`：`Σu = u₀` 且 `Σu² = u₀²` ⇒ `(Σu)² = Σu²` ⇒ `2Σ_{i<j}u_iu_j = 0` ⇒ `e₂ = 0` ⇒ **至多一个 u 非零** ⇒ 退化解。这是**代数结论**，在 ℚ、ℝ 上同样成立（K3 用四元组另测一遍，四次相等全为 False）。

所以来料只讨论「两族」不是偷懒 —— 它是**唯一非退化**的族数。k=4 的 (2,2) 分法只是同一多重集换符号。

### 3.3 最小非零族数 = 2

最省配置：两族、`q₊ = −q₋`、取 `q₊N = 1` ⇒ `n = 2q₊N = 2`。要 `n = 3` 需 `q₊N = 3/2 ∉ ℤ`，与零模数整数性冲突 ⇒ **不可达**。与 r350（框架不预言 3）、r389（整数比搬家）同型，**不可相加**计为三条发现。

## §四　角动量禁戒的正确定式

### 4.1 把两个角动量都写成 Q

`j_f = (Q−1)/2`（Q 个零模给出 j = 0..Q−1 的等差谱，最大 `j_max = Q−1 = 2j_f`）；Higgs 侧 `j_H,min = |q_H|N/2`，而 `q_H = −2q_f` ⇒ `j_H,min = q_f N = Q`。于是

```
j_H,min − 2j_f = Q − (Q − 1) = 1        对任意 Q、任意 q_f、任意 N
```

### 4.2 两条独立参数化

| 路径 | 参数化 | 点数 | 读数 |
| --- | --- | --- | --- |
| B1 | 按 `Q` | 12（Q=1..12） | 间距全为 1 |
| B2 | 按 `(N, k)`，`q_f = k/N` | 35 | 全为 1 |

B2 的用处：证明禁戒**与 `q_f` 的归一化无关**。若只做 B1，会留下「是不是 q_f=1 才对」的漏洞。

### 4.3 与来料的关系

来料写 `j_{H,min} = N > N−1 = j_max`，只在 `q_f = 1` 下成立，且是不等式。本卷的等式对任意 `q_f` 成立 ⇒ **结论对、形式弱**，记 PASS 但注明可强化。这也是本卷唯一「比来料更强且对来料有利」的一条 —— 障碍确实存在。

## §五　两条出路的关闭

### 5.1 Green–Schwarz：不是独立出路，是和前提同一个条件

若 `I₈^net = ½X₄∧X₄` 且 `X₄ = αx² + β·trF² + γ·p₁`（G12 枚举：`deg=4` 单项式恰这 3 个），则

```
½X₄∧X₄ = α²/2·x⁴ + αβ·x²T + αγ·x²p₁ + β²/2·T² + γ²/2·p₁² + βγ·Tp₁
```

净 8 形式里 `T²`、`p₁²` 系数**恒为 0**（A1：两个 16 是同一表示、系数相同，相减逐项抵消）⇒ `β = γ = 0` ⇒ `x²T`、`x²p₁` 也为 0 ⇒ 只能 `I₈ = 0`。

| 情形 `(q₊, q₋)` | GS 可分解？ | `I₈ = 0`？ |
| --- | --- | --- |
| (1, 0) | 无解 | 否 |
| (1, 2) | 无解 | 否 |
| (2, −2) | 可分解 | 是 |
| (3, −3) | 可分解 | 是 |
| (1/2, −1/2) | 可分解 | 是 |

5 组 5 组吻合 ⇒ **`GS 可分解 ⟺ I₈ = 0`**。所以「或 GS」这条退路不存在：GS 能救的谱，本来就不需要救。

### 5.2 额外场：被奇偶性堵死

加 16 只增加 `±Q` 项，而每项的奇偶性与 `±Q²` 相同 ⇒ `n` 保持偶（§二）。更直接地看：任何满足 `Σ s q² = 0` 的谱，`n` 都偶 ⇒ 加项不改变结论。

这两条合起来就是 E1 的判负：**来料「这不是不可能性证明」的依据，在本题设内不成立**。

## §八　可复用的方法与判据

1. **模 2 归约刀**　判「某量能否取到奇数」时，先把所有约束取模 2。`s = ±1 ≡ 1`、`Q² ≡ Q` 这两条把「族数依赖」整块抹掉 —— 结论比枚举强得多，也解释了「为什么加项改不了」。
2. **同一量的两种表示刀**　来料用 `N` 写角动量，本卷用 `Q = q_f N` 写。换表示后不等式变成等式，且暴露出「与 `q_f` 归一化无关」这一层。**凡结论里出现某个规范选择，就该换一次表示。**
3. **线性 vs 平方刀（本卷新）**　`j_H,min` 是**一次**量、`j_f` 是**半整数**，比较时一边乘 2 一边不乘，间距就恒为常数 1。若两边都用「2j」或都用「j」，会得到 `Q+1` 这种随 Q 变的假间距 —— **先写死「每个量是 j 还是 2j」，再写差值。**
4. **修错对象刀**　报「修复入口」前先回答：**待修的对象存在吗？** 本卷的 3×3 矩阵在偶族谱里不存在，所以「解除禁戒」是空转。与 r367 的对象错位守卫同族，但方向相反：那次是取错对象，这次是对象不存在。
5. **出路枚举刀**　只要出现「或 …」「或 …」，就逐条问「它比原条件更弱吗」。GS 看似更弱，实测**等价**（A3）⇒ 不是出路。等价性比强弱更容易被漏。
6. **守卫的自指刀**　凡是「扫源码找坏模式」的守卫，必须把扫描区切在自己之前，否则它会命中自己的字面量。G03 首版正是这么红的 —— 与库内「负对照自己也会恒绿」同族。
7. **两种族数不得相加**　A4（107 组构造）与 G14（6336 组遍历）是**同一结论的两条路径**，不是两条发现；同理 k=1/3 无解的代数证明与穷举复核也不相加。
