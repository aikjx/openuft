## 1 引言

### 1.1 纲领与审计背景

空间螺旋几何化统一场论（TUFT）主张：空间中每一点作光速螺旋运动 `R(θ)=(ρcosθ, ρsinθ, bθ)`，由曲率 κ 与挠率 τ 的参数化试图导出精细结构常数 α、引力常数 G、四力归一化乃至可计算的可观测预言。纲领以《空间螺旋修复版·第一性审计与伪派生判定》为申报文本，在 claims.csv 中登记 70 条主张。

审计组自 V21 续修起对该纲领执行系统审计，历经：C25/C35 数值复核与合并、全量批量审计（54→70 条）、C26–C37 专项复核、五个可计算模块攻坚（EHT 光子环、CMB 双谱、引力泡、RG 流、轨道进动）、防回潮守卫建设。本报告为整链审计的正式终结汇总。

### 1.2 审计纪律

- **只认引擎证据**：任何草稿自评 PASS 未过引擎复核即不予采信；标记改写须有复算记录。
- **完整闭环**：每项判定执行「登记 → 引擎重跑 → 守卫复核 → 产物交付」，状态以 claims.csv 与不变量基线为唯一权威来源。
- **诚实口径**：草稿乐观标记（如 open=可证伪谱）与引擎结论（open=退化谱 / 零内容 / 无映射方程）不一致时，采用引擎语义并书面注明差异。
- **并发隔离**：台账与基线写入前实读 mtime 与内容核对，防并发轮（V21续修③④ 等）改写冲突。

## 2 审计方法与协议

### 2.1 C38 三审计算法

审计引擎（`空间螺旋_全量claims批量审计与L3层级判定.py`）对每条主张执行三类判定：

- **R1 矛盾自检**（algo_contradiction_selfcheck）：对 ortho / unit / eq / sign 四类声明做有限步一致性校验（已捕获 V21 §0 副法向量叉乘错误等实例）。
- **R2 拓扑归一**（algo_topo_normalize）：按 Buckingham Π 定理做量纲降维，拒绝无量纲量产出有量纲量的"推导"（C31 判例）。

## 4 讨论

### 4.1 结构性失败：映射层缺失

八类候选几何量（κ/τ、β、ω/A、N、Φ、p/κ₀/κ、引力泡、RG 系数）无一能挂载到可观测。失败不是系数错误、不是精度不足，而是**中间结构整体缺失**：

```
几何对象（κ/τ、ω/A、N、Φ…）
        │
        ✕   ← 断点：无作用量 → 无变分方程 → 无测地线 / 无引力涨落谱
        │
可观测（α 谱、近日点进动、EHT 光子环、CMB 双谱、f_NL / n_s）
```

五个可计算模块全部借用了外部理论（GR、标准宇宙学）的场方程才做出"预测"——而这些预测要么与外部理论恒等（零内容），要么根本不可计算。

### 4.2 失败模式分类学

对 70 条判定与模块攻坚归纳，失败呈现四种可复现模式：

| 模式 | 判例 | 特征 |
|---|---|---|
| 量纲死亡 | C29、C31、C33、C36、C53、C56、C58 | [K₀] 反解为力而非曲率；无量纲量产出有量纲量；能量密度三口径全非法 |
| 零内容（借壳） | C35、C42、C47/C51、C60 | 修正因子恒等于 1；β₀≡GR 1PN；r_g/r_ph=1/3 精确 ⇒ 与外部理论恒等 |
| 无映射方程 | C53、C54、C60、C61 | 几何量到可观测之间无任何映射方程，预言不可计算 |
| 自由度配平 / 数值伪迹 | C25、C28、C54、C55、C56 | 未知数=方程数即"有解"；显式 Euler 步长越界 986 倍；固定点位于截断最不可靠处 |

### 4.3 借壳预言（零内容）的定量证据

- 轨道进动：β₀=3h²/c² 使草稿 Binet 方程与 GR 1PN 方程**逐项恒等**（u² 系数 3GM/c² 精确相等）⇒ "几何修正"即 GR 本身；金星/地球修正量 4.93e-3 / 1.59e-3 角秒每百年，低于历表约束。
- EHT：b_crit/r_s=3√3/2 与 r_g/r_ph=1/3 均为 Schwarzschild 几何的精确结果，纲领未贡献任何新预测。
- CMB：靶基准全部取自标准宇宙学（Planck 2018 公开锚点），纲领无「涨落源从哪来」的回答；f_NL 已被实测压到 O(1)，观测精度越高，纲领的失败越确定。

### 4.4 并发轮与审计独立性

审计期间观测到并发工作线（V21续修③④）抢注 C55/C56/C58/C59（双圈 RG、泡动力学、谱量纲、进动符号，均 falsified）及 EHT/CMB 编号顺延（C60/C61）。审计组在每次登记前实读台账 mtime 与内容核对，独立反演结论与并发轮全部吻合（双圈固定点不存在、泡动力学量纲非法、谱退化、Binet 符号错误），未发现相互污染；守卫基线经总攻登记扩至 26 条后仍 8/8 全绿。

### 4.5 体系级重启前置条件

本审计否定的是**当前申报形态**，不否定议题本身。体系级 open 项与重启路线（逐项登记在 C53/C54/C55/C56/C60/C61 等条）：

1. **作用量**：给出纲领自身的场论作用量（非外部理论借用），并完成变分；
2. **场方程**：由作用量导出场方程（含几何源项的量纲自洽闭合）；
3. **测地线 / 涨落谱**：由场方程导出粒子测地线与引力涨落谱（原初功率谱/双谱）；
4. **带误差棒预言**：在此之上登记可检验靶（如 α、进动、光子环、CMB 双谱）的预测值与误差棒。

在补齐第 1、2 步之前，任何新观测（引力波、宇宙学距离、粒子截面）都会重复同一失败模式，不再值得单独攻坚。

## 5 结论

1. **申报不成立**：70 条主张无一条达到 L3（第一性推导闭环）；全部可计算模块死于同一整层缺失。
2. **失败是结构性的**：不是个别公式错误，而是「几何对象 → 场方程 → 可观测」映射层整体缺失。
3. **否定可复核**：每个 falsified 判定均附可复算数值证据（量纲非法、恒等消去、固定点不存在、映射单项 FAIL）与体系级 open 前置条件，否定本身可复核、可重启。
4. **守卫闭环**：falsified 不变量基线 26 条，8/8 全绿，台账/基线/引擎/产物四方一致。
5. **唯一可行路线**：作用量 → 场方程 → 测地线 → 引力涨落谱 → 带误差棒的预言。
