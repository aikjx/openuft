# method_F · 第一性判据（无量纲化 / 循环检测 / 自由度审计）

> 本方法是 `02_共享基础/研究规范` 的第五支（D 求导 / P 证明 / V 验证 / F 第一性）。
> 配套实现：[`04_公共成果/算法联盟_全维自洽与归一化/源码/算法联盟_全维自洽引擎.py`](../../04_公共成果/算法联盟_全维自洽与归一化/源码/算法联盟_全维自洽引擎.py)
> 建立日期：2026-09-15（首轮全维自洽审计后沉淀）

**适用**：任何声称「从第一性原理导出某物理量」的登记，在计入 claims 之前应先过本判据。

---

## 0. 为什么需要本方法

首轮全维自洽审计发现，openuft 内的「精算 100% 通过」与「零自由参数」两类主张，
在数学自洽的外表下可以完全失效——原因是三类机制：

1. **循环项重复计数**：同一约束换写法后被计为两次独立验证；
2. **单点锚定检验**：只在使式子成立的特殊锚点（如 `m = m_P`）检验；
3. **量纲常数冒充物理成就**：把单位定义常数（c、ℏ、k_B）当作被导出的物理量。

本方法给出可机器执行的判据，用于把「数学自洽」与「第一性导出」区分开。

---

## 1. 第一性层级 L0–L4（登记时必填）

| 层级 | 名称 | 判定标准 | 证据价值 |
|---|---|---|---|
| **L0** | 定义式 / 代数恒等 | 由定义直接推出，恒真 | 零经验内容，不计为证据 |
| **L1** | 循环重排 / 定义回指 | 用测量锚反解另一常数 | 伪导出，无预言力 |
| **L2** | 结构约束（含自由参数） | 给出量间关系但未闭合 | 有结构价值，闭合后才成预言 |
| **L3** | 独立可证伪预言 | 定量、可检验、非回指 | **唯一计为第一性产出** |
| **L4** | 本体 / 形而上学主张 | 不可由数学判定真假 | 研究纲领，不作证据 |

登记要求：每条 claim 必须标注层级；**只有 L3 可计入「已验证结论」**，L0/L1 不得计入。

---

## 2. 判据一：无量纲化判据（dimensionless criterion）

> **第一性内容 ⟺ 无量纲量的数值。**

**理由**：在自然单位制（`c = ℏ = G = k_B = 4πε₀ = 1`）下，全部量纲常数的值都被归一为 1；
残留的只有无量纲数。因此：

| 主张 | 判定 |
|---|---|
| 「由几何导出 `c`、`ℏ`、`G`、`k_B`」 | **伪目标**——单位换算因子，不是物理预言 |
| 「由几何导出 `α = 1/137.036`」 | 真目标 |
| 「由几何导出 `m_μ/m_e = 206.768`、`m_τ/m_e = 3477.2`」 | 真目标 |
| 「由几何导出 `α_S(M_Z)`、`α_grav`」 | 真目标 |

**执行**：对声称「导出 X」的公式，检查 X 的量纲向量（基 `[L, M, T, I, Θ]`）。
若 X 量纲非零 → 判为 L1（单位换算），不计为第一性成就。

**SI 2019 事实**（判据基础）：`c`、`h`、`k_B`、`e` 为**定义常数**，不确定度为零；
其数值由单位制约定固定，不是自然界的待解释量。

## 3. 判据二：循环检测（cycle detection）

### 3.1 恒等变形检验（手算即可）

把声称的「导出式」与体系中其他式子联立代入，若化为 `X = X` 形式的恒等式，则为循环。

已知实例（GAQ 谱系）：

- `ħ = mcR` 与 `m = ℏ/(cR)` → **同一约束**的两种写法；
- `e = √(4πε₀·τ/κ·ℏc)` 代入 `α = τ/κ` 与 `ε₀ = e²/(4παℏc)` → 恒等式 `e² = e²`。

### 3.2 雅可比秩亏损检验（机器执行）

对声称的 `n` 条派生关系、关于 `m` 个变量构造雅可比 `J`，则

```
独立约束数 = rank(J)        循环/冗余方程数 = n − rank(J)        自由度 = m − rank(J)
```

**实施要点（踩过的坑）**：

1. **必须先做列归一化**：跨量纲雅可比的列范数可相差 `10^40`，
   不归一化会被绝对阈值误判为 0，把秩从 12 低估到 4。
2. **区分两种口径**：
   - *一般位置秩*（随机点求值，Schwartz–Zippel 式）：反映方程作为多项式的独立性；
   - *解流形秩*（在真实解点求值）：反映实际约束数，通常更低（相关性只在解流形上成立）。
   两者都要报。
3. **测量噪声会伪装循环为独立**：`ε₀` 与 `e²/(4παℏc)` 的 CODATA 残差约 `3e-12`，
   足以使理论上线性相关的行在 80 位精度下被判为独立。
   → 判定时须声明所用精度与容差，并对理论相关性与实测相关性分别报告。

**判定**：若 `自由度 > 0`，则「零自由参数」主张**不成立**，
应改述为「无拟合参数」（形式自洽），而非「无外部输入」（第一性导出）。

## 4. 判据三：双锚点检验（two-anchor test）

对任何含自由尺度的关系式，**至少在两个物理锚点检验**：

- **普朗克锚点**：`m = m_P`、`R = ℓ_P`
- **粒子锚点**：`m = m_e`、`R = ƛ_C = ℏ/(m_e c)`（或其他实测粒子）

**判定**：若只在普朗克锚点精确成立而在粒子锚点崩塌，则该式是**普朗克锚点定义式**，
不是普适定律。

### 标志性案例：普朗克锚定谬误

```
G = c³/(ℏ(κ²+τ²))   ∧   m = ℏ√(κ²+τ²)/c   ⟹  G m² = ℏ c  ⟹  m = m_P（唯一解）
```

| 锚点 | `G_式` | 与实测 G 偏差 |
|---|---|---|
| 普朗克 `m = m_P` | `6.6743e-11` | 残差 `1.84e-81`（PASS） |
| 电子 `m = m_e` | `ℏc/m_e² = 3.81e+34` | **5.71e+44 倍**（FAIL） |

偏离闭式：`G_old(m)/G = (m_P/m)²` —— 旧式等价于把 G 换成随粒子质量平方反比变化的量，
**不可能是普适引力常数**。

**正确形式**：`α_grav = G m²/(ℏ c) = (m/m_P)²`（对任意 m 成立，无矛盾）。

> **教训**：在使式子成立的锚点上检验，必然「通过」；必须换到另一个锚点才能暴露结构错误。

## 5. 判据四：自由度审计（归一化后）

在自然单位（`c = ℏ = G = 4πε₀ = 1`）下重做判据三，得到需要外部输入的**无量纲**参数个数。
这个数字就是该体系的**第一性欠账**。

首轮结果（GAQ/螺旋谱系）：7 个变量被 5 条约束压缩 → **剩余 2 个自由度**
（`α` 与 `m/m_P`）。

**解读模板**：若某体系归一化后自由度与标准模型相当，则它并未减少自由参数，
只是把参数换成了几何语言——**形式增益，非信息增益**。

---

## 6. 判据五：L3 门槛（什么才算独立预言）

一条 claim 要计为 L3，必须同时满足：

1. 给出**定量数值**（不是量级、不是存在性声明）；
2. 该数值**不由体系中其他式子反解得到**（过判据二）；
3. 存在**可执行的检验路径**（实验或独立数值实验），且当前**尚未被该体系自身用于拟合**；
4. 在**至少两个锚点**上不自相矛盾（过判据三）。

不满足任一条件者，登记为 L0–L2 或 L4，**不得计入已验证结论**。

## 8. 诚实边界（本方法自身的限制）

1. 本方法只判**自洽性与独立性**，不判**物理真伪**——过检不代表理论成立。
2. 秩与自由度依赖所登记的方程集合；漏登记方程会高估自由度，多登记恒等式会低估。
3. 数值秩判定依赖精度与容差设定，须在记录中显式声明。
4. 本方法不能替代实验检验；L3 条目仍需实验确认才算「已验证」。
