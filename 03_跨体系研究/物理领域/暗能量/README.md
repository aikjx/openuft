## 问题定义

1998 年 Ia 型超新星观测发现宇宙加速膨胀，归因于"暗能量"，占宇宙能量密度约 68%。核心候选：

1. **宇宙学常数 $\Lambda$**：真空能，状态方程 $w = -1$
2. **动力学暗能量**：quintessence 标量场，$w$ 随时间演化
3. **修改引力**：大尺度修改 GR，无需暗能量
4. **全息暗能量**：全息原理导出的有效暗能量

**核心问题**：暗能量是常数还是动力学？其微观起源是什么？

## 证伪条件

- 若 $w$ 被精确测量为 $-1$，则宇宙学常数获得支持
- 若 $w$ 随时间演化被观测，则动力学暗能量获得支持
- 若哈勃张力被新物理解释，则暗能量模型需修正
- 若引力修正方案能解释所有观测，则暗能量假设被削弱

## 诚实边界（不粉饰）

1. **DE2 对 DESI+Planck+SN 组合处于 ~2.2σ 边界**（该组合略偏向 $w<-1$），框架不粉饰为契合；
2. **DE3 固定系数 $c=1$**（框架无自由参数）使 $w_0$ 偏离 ΛCDM，构成对 DESI Y5 / Euclid / Rubin / Beijing-AIP 的可证伪判别——两条路径（ΛCDM vs HDE）互斥可检验；
3. **$\Lambda$ 推导依赖框架公理「视界截断」**，其 O(1) 系数为视界定义细节，非自由拟合；
4. 数学自洽 ≠ 实验证实——主预言与 Planck 2018 在 1σ 内，但仍待下一代巡天在 $\Lambda$CDM 与动力学暗能量之间做更锐判别。
