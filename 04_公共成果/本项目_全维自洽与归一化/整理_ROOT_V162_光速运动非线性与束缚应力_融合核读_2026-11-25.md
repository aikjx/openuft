## 0. 一句话结论

V162 把“束缚应力从哪来”推进为可计算的非线性电动力学问题：交叉光速场可产生非零 `X,Y`，从而给出夹角、偏振和振幅依赖的作用量密度；弱非线性满足 `qu<1/5` 时空间应力迹严格为正，静态孤立束缚被排除；但强非线性在该低阶模型中先触发传播不稳定，且一维仿真中脉冲仍分离。因此它证明的是“运动夹角—非线性作用—应力障碍—传播稳定性”的链条，不是三维修复、物质形成或四力统一。

## 2. 量纲、作用量与本构关系核算

采用 `c=1`、`[hbar]=ML`、`[G]=L/M`，并取归一化的 `[E]=[B]=L^-2`。于是

- `X=(E²-B²)/2` 与 `Y=E·B` 的量纲都是 `L^-4`；
- `d⁴x` 的量纲是 `L⁴`，所以 `∫d⁴x X` 无量纲，乘 `hbar` 后确为作用量；
- `a,b` 必须为 `L⁴`，使 `aX²`、`bY²` 仍为 `L^-4`。

来料给出 `L=X+aX²+bY²`，则

`∂L/∂E = E + 2aX E + 2bY B`，
`H = -∂L/∂B = B + 2aX B - 2bY E`，

与 `D=(1+2aX)E+2bYB`、`H=(1+2aX)B-2bYE` 一致。单个严格 null Maxwell 解满足 `X=Y=0`，于是 `D=E`、`H=B`，仍是该模型的解；但两束 null 波的线性叠加一般不保证 `X=Y=0`，所以“单束是解”不能推出“交叉叠加仍是解”。这正是非线性项出现的逻辑位置。

## 3. 两束交叉的夹角—偏振核算

取来料的标架：

`n1=z`，`E1=A1 x`；
`n2=(sinθ,0,cosθ)`，`E2=A2(cosψ cosθ, sinψ, -cosψ sinθ)`，`Bi=ni×Ei`。

逐项展开：

- `E1·E2 = A1A2 cosψ cosθ`；
- `B1·B2 = A1A2 cosψ`；
- 因而 `E²-B² = 2A1A2 cosψ(cosθ-1)`，即 `X=-A1A2(1-cosθ)cosψ`；
- `E1·B2 + E2·B1 = A1A2(1-cosθ)sinψ`，单束自项为零，故 `Y=A1A2(1-cosθ)sinψ`。

代入 `L_int=aX²+bY²` 得

`L_int=A1²A2²(1-cosθ)²(a cos²ψ + b sin²ψ)`。

数值例 `θ=90°`、`ψ=45°`、`a/L0⁴=0.2`、`b/L0⁴=0.35` 给 `(1-cos90°)²=1`、`cos²ψ=sin²ψ=1/2`，故归一化密度 `0.2/2+0.35/2=0.275`，与来料一致。角度因子 `(1-cosθ)²` 在 0° 为 0、180° 为 4，符合表格。

边界：这是“给定两束叠加场”的局部作用量密度，不是两物体间有效势，也不是证明叠加场本身是动力学解。

## 4. 应力下界核算

令 `u=(E²+B²)/2`。由 `X²+Y²≤u²` 与 `|X|≤u`：

- `T^μ_μ = 4(L-XL_X-YL_Y) = -4(aX²+bY²)`；
- `E·D = u+X+2aXu+2aX²+2bY²`；
- `rho=E·D-L = u+2aXu+aX²+bY²`；
- `ΣTii = rho+T^μ_μ = u+2aXu-3aX²-3bY²`。

若 `a,b≥0`、`q=max(a,b)`，最坏情形可由 `a=q` 且 `X=-u` 达到线性项与 `X²` 项同时最负；再用 `X²+Y²≤u²` 控制 `Y` 项，得到

`ΣTii ≥ u(1-5qu)`。

所以若全场满足 `qu<1/5`，非零场有 `ΣTii>0`，无法满足完整静态孤立系统在平直时空中的 Laue 条件 `∫ΣTii d³x=0`。这是指定低阶 NLED 的弱场障碍，不是对所有 NLED 或所有引力体系的普适 no-go。

## 5. 背景场传播速度与临界点

纯磁背景 `B0` 下线性化来料给出

`v_perp²=(1-3aB0²)/(1-aB0²)`，
`v_parallel²=(1-aB0²)/(1-aB0²+2bB0²)`。

在 `a=0.2`、`b=0.35`、`B0=0.5` 时，`aB0²=0.05`：

- `v_perp≈0.945905`，`v_parallel≈0.918937`，与本机 `summary.json` 一致；
- 纯磁背景 `u=B0²/2`，`qu=aB0²/2=0.025`，相对空间应力迹下界为 `1-5qu=0.875`，与来料一致。

两个临界点必须分列：

- `aB0²=1/3`：`v_perp²=0`，垂直偏振特征速度先降为零；
- `aB0²=2/5`：`qu=1/5`，纯磁背景空间应力迹的下界才允许非正。

因为 `1/3<2/5`，在这条纯磁背景分支上，传播先失稳，尚未到达所需负应力条件。增大耦合不能简单换来稳定束缚。

## 7. 证据分级与红线

1. **可保存为数学事实**：作用量量纲、本构关系、两束交叉不变量、弱场应力下界、纯磁背景特征速度临界关系。
2. **可保存为数值事实**：16384 组交叉验证、16384 组应力验证、1D 碰撞网格收敛、45/45 程序断言、同环境复跑一致。
3. **不能升级为实验事实**：QED 低能截面是已知理论计算；ATLAS 光光散射来自高能重离子碰撞，不能直接与低能光学公式比较；本轮没有真实光学实验。
4. **不能升级为统一结论**：`G` 未推导；V163 候选作用量预先引入 `R/(16πG)` 与 `hbar L_nl`，仍不是四力统一；三维自引力非线性场未求解；一维仿真中脉冲最终仍分离，没有形成稳定物质。
