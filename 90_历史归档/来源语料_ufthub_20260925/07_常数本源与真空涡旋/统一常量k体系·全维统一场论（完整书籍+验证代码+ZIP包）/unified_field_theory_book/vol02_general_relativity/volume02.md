## 第7章 等效原理与广义协变性

### 7.1 等效原理的历史与表述

#### 7.1.1 伽利略自由落体实验

1589年，伽利略在比萨斜塔进行了著名的自由落体实验（历史真实性存疑，但思想实验成立），发现不同质量的物体在重力场中以相同的加速度下落。这一观测揭示了引力质量与惯性质量的等价性。

**引力质量** \(m_g\)：出现在牛顿引力定律 \(F = G M_g m_g / r^2\) 中，描述物体产生和响应引力场的能力。

**惯性质量** \(m_i\)：出现在牛顿第二定律 \(F = m_i a\) 中，描述物体抵抗加速度的能力。

自由落体实验表明：

\[
m_g = m_i
\]

或至少 \(m_g/m_i\) 对所有物体相同（可通过单位选择使其等于1）。

#### 7.1.2 弱等效原理

**弱等效原理（Weak Equivalence Principle, WEP）**：

> 惯性质量与引力质量之比对所有物体相同，与物体的组成、结构无关。

数学表述：

\[
\frac{m_g}{m_i} = \text{常数} \quad (\forall \text{ 物体})
\]

通过选择合适的单位，可使该常数等于1。

#### 7.1.3 爱因斯坦等效原理

**爱因斯坦等效原理（Einstein Equivalence Principle, EEP）**：

> 在足够小的时空区域内，物理定律与无引力的惯性系中相同（即狭义相对论定律）。

这是一个更强的表述，包含三个子原理：
1. **WEP**：弱等效原理
2. **局部洛伦兹不变性（LLI）**：局部非引力实验结果与参考系的速度无关
3. **局部位置不变性（LPI）**：局部非引力实验结果与时空位置无关

EEP是广义相对论的基石，它意味着引力可以通过坐标变换在局部被"消除"。

#### 7.1.4 强等效原理

**强等效原理（Strong Equivalence Principle, SEP）**：

> EEP对自引力物体（如恒星、黑洞）也成立，即引力物体的引力质量与惯性质量之比与物体的引力自能无关。

SEP比EEP更强，它要求等效原理对包含引力相互作用的系统也成立。广义相对论满足SEP，而大多数替代引力理论（如布兰斯-迪克理论）不满足SEP。

### 7.2 等效原理的实验检验

#### 7.2.1 厄特沃什实验

厄特沃什（Loránd Eötvös）于1885年开始使用扭秤精确检验不同物质的引力质量与惯性质量之比。实验精度达到 \(10^{-9}\)。

现代版本的厄特沃什实验（如华盛顿大学的Eöt-Wash实验）将精度提升到 \(10^{-13}\) 量级。

#### 7.2.2 月球激光测距

通过测量地球与月球之间的距离（精度达到厘米级），检验地球和月球作为自引力物体是否满足等效原理。这是对SEP的检验，精度约为 \(10^{-13}\)。

#### 7.2.3 MICROSCOPE卫星实验

法国MICROSCOPE卫星（2016-2018年）在太空中进行自由落体实验，检验不同材料（铂和钛合金）的等效原理，精度达到 \(10^{-15}\)。

### 7.3 广义协变性原理

#### 7.3.1 协变性的概念

**广义协变性原理（Principle of General Covariance）**：

> 物理定律在所有坐标系中具有相同的形式，即物理方程在任意坐标变换下是协变的。

这意味着物理方程应该用张量来表述，因为张量在坐标变换下具有明确的变换规律。

#### 7.3.2 协变性与物理内容

需要注意的是，广义协变性本身是一个数学要求，而非物理假设。任何物理理论都可以写成广义协变的形式（通过引入适当的张量）。广义相对论的物理内容不在于广义协变性本身，而在于**等效原理**和**场方程**的具体形式。

### 7.4 从等效原理到弯曲时空

#### 7.4.1 引力的几何化

等效原理意味着引力与加速度在局部不可区分。爱因斯坦的洞见是：如果引力可以通过坐标变换在局部消除，那么引力本身不是一种"力"，而是时空几何的表现。

具体来说：
- 在无引力的惯性系中，自由粒子沿直线运动
- 在引力场中，自由粒子沿"最直的可能路径"运动，即测地线
- 测地线的弯曲反映了时空本身的弯曲
- 物质的存在导致时空弯曲，时空弯曲决定物质的运动

这就是**引力的几何化**：引力 = 时空曲率。

#### 7.4.2 测地线方程

自由粒子在弯曲时空中沿测地线运动，测地线方程为：

\[
\frac{d^2 x^\mu}{d\tau^2} + \Gamma^\mu_{\alpha\beta} \frac{dx^\alpha}{d\tau} \frac{dx^\beta}{d\tau} = 0
\]

其中 \(\tau\) 是固有时（对类时粒子），\(\Gamma^\mu_{\alpha\beta}\) 是克里斯托费尔符号。

在弱场低速近似下，测地线方程退化为牛顿引力定律：

\[
\frac{d^2 \mathbf{x}}{dt^2} = -\nabla \Phi
\]

其中 \(\Phi\) 是牛顿引力势，且 \(g_{00} \approx -(1 + 2\Phi/c^2)\)。

## 第8章 爱因斯坦场方程的k形式

### 8.1 场方程的推导路径

#### 8.1.1 希尔伯特作用量方法

大卫·希尔伯特于1915年几乎与爱因斯坦同时推导出广义相对论场方程，他采用的是作用量原理方法。

**希尔伯特作用量（Hilbert action）**：

\[
S_H = \frac{c^4}{16\pi G} \int R \sqrt{-g} \, d^4x
\]

其中：
- \(R\) 是里奇标量
- \(g = \det(g_{\mu\nu})\) 是度规行列式
- \(\sqrt{-g} \, d^4x\) 是不变体积元

对作用量关于度规 \(g^{\mu\nu}\) 求变分，令 \(\delta S_H = 0\)，得到真空场方程：

\[
R_{\mu\nu} - \frac{1}{2} R g_{\mu\nu} = 0
\]

即 \(G_{\mu\nu} = 0\)。

#### 8.1.2 物质作用量与能量动量张量

物质场的作用量 \(S_M\) 对度规的变分定义了**能量动量张量（energy-momentum tensor）**：

\[
T_{\mu\nu} \equiv -\frac{2c}{\sqrt{-g}} \frac{\delta S_M}{\delta g^{\mu\nu}}
\]

（不同教材的定义可能相差常数因子，此处采用与场方程一致的定义。）

总作用量 \(S = S_H + S_M\)，对度规求变分令其为零：

\[
\delta S = \frac{c^4}{16\pi G} \int \left( R_{\mu\nu} - \frac{1}{2} R g_{\mu\nu} \right) \sqrt{-g} \, \delta g^{\mu\nu} d^4x + \frac{1}{2c} \int T_{\mu\nu} \sqrt{-g} \, \delta g^{\mu\nu} d^4x = 0
\]

由于 \(\delta g^{\mu\nu}\) 任意，得到：

\[
R_{\mu\nu} - \frac{1}{2} R g_{\mu\nu} = \frac{8\pi G}{c^4} T_{\mu\nu}
\]

即**爱因斯坦场方程**：

\[
\boxed{G_{\mu\nu} = \frac{8\pi G}{c^4} T_{\mu\nu}}
\]

### 8.2 k形式的场方程

#### 8.2.1 代入k = 4πG

将 \(k \equiv 4\pi G\) 代入场方程：

\[
G_{\mu\nu} = \frac{8\pi G}{c^4} T_{\mu\nu} = \frac{2 \cdot 4\pi G}{c^4} T_{\mu\nu} = \frac{2k}{c^4} T_{\mu\nu}
\]

即**k形式的爱因斯坦场方程**：

\[
\boxed{G_{\mu\nu} = \frac{2k}{c^4} T_{\mu\nu}}
\]

#### 8.2.2 k形式的希尔伯特作用量

将 \(k = 4\pi G\) 代入希尔伯特作用量：

\[
S_H = \frac{c^4}{16\pi G} \int R \sqrt{-g} \, d^4x = \frac{c^4}{4k} \int R \sqrt{-g} \, d^4x
\]

即：

\[
\boxed{S_H = \frac{c^4}{4k} \int R \sqrt{-g} \, d^4x}
\]

#### 8.2.3 场方程的对称性与守恒律

爱因斯坦张量 \(G_{\mu\nu}\) 满足**比安基恒等式（Bianchi identity）**：

\[
\nabla^\mu G_{\mu\nu} = 0
\]

因此场方程蕴含能量动量守恒：

\[
\nabla^\mu T_{\mu\nu} = 0
\]

这是广义相对论的一个重要自洽性：场方程本身保证了能量动量张量的协变散度为零。

在k形式下，这一性质完全保留，因为k仅是常数重定义，不影响微分结构。

### 8.3 宇宙学常数的k形式

#### 8.3.1 宇宙学常数项

爱因斯坦于1917年引入宇宙学常数 \(\Lambda\)，以构建静态宇宙模型。场方程变为：

\[
G_{\mu\nu} + \Lambda g_{\mu\nu} = \frac{8\pi G}{c^4} T_{\mu\nu}
\]

k形式：

\[
G_{\mu\nu} + \Lambda g_{\mu\nu} = \frac{2k}{c^4} T_{\mu\nu}
\]

#### 8.3.2 宇宙学常数作为真空能

宇宙学常数可以等效为具有状态方程 \(p = -\rho c^2\) 的理想流体（真空能）：

\[
\rho_\Lambda = \frac{\Lambda c^2}{8\pi G} = \frac{\Lambda c^2}{2k}
\]

\[
p_\Lambda = -\rho_\Lambda c^2 = -\frac{\Lambda c^4}{2k}
\]

注意：此处 \(\Lambda\) 是正统宇宙学常数，不由k体系闭环定义，其数值由宇宙学观测确定。

### 8.4 弱场近似与牛顿极限

#### 8.4.1 弱场度规

在弱引力场中，度规可写为闵可夫斯基度规加微扰：

\[
g_{\mu\nu} = \eta_{\mu\nu} + h_{\mu\nu}, \quad |h_{\mu\nu}| \ll 1
\]

对于静态弱场，非相对论性物质（\(T_{00} \approx \rho c^2\)，其他分量可忽略），场方程的00分量给出：

\[
\nabla^2 h_{00} = \frac{8\pi G}{c^2} \rho = \frac{2k}{c^2} \rho
\]

与牛顿泊松方程 \(\nabla^2 \Phi = 4\pi G \rho = k \rho\) 对比，得到：

\[
h_{00} = \frac{2\Phi}{c^2}
\]

因此：

\[
g_{00} \approx -\left(1 + \frac{2\Phi}{c^2}\right)
\]

（采用东海岸约定，\(\eta_{00} = -1\)。）

#### 8.4.2 测地线的牛顿极限

在弱场低速近似下，测地线方程退化为：

\[
\frac{d^2 x^i}{dt^2} \approx -\frac{1}{2} c^2 \partial_i h_{00} = -\partial_i \Phi
\]

即牛顿第二定律在引力场中的形式。这验证了k形式场方程在弱场极限下与牛顿引力的一致性。

### 8.5 后牛顿近似

#### 8.5.1 参数化后牛顿形式

参数化后牛顿（Parameterized Post-Newtonian, PPN）形式是描述弱引力场中广义相对论及替代理论的通用框架。在PPN框架中，度规的后牛顿展开包含10个参数，不同的引力理论对应不同的参数值。

广义相对论的PPN参数：

| 参数 | GR值 | 物理意义 |
|---|---|---|
| \(\gamma\) | 1 | 空间曲率产生的单位质量光偏折 |
| \(\beta\) | 1 | 非线性叠加引力的程度 |
| \(\xi\) | 0 | 优先位置效应 |
| \(\alpha_1\) | 0 | 优先框架效应 |
| \(\alpha_2\) | 0 | 优先框架效应 |
| \(\alpha_3\) | 0 | 优先框架效应 |
| \(\zeta_1\) | 0 | 总动量守恒 |
| \(\zeta_2\) | 0 | 总动量守恒 |
| \(\zeta_3\) | 0 | 总动量守恒 |
| \(\zeta_4\) | 0 | 总动量守恒 |

k形式的广义相对论与标准GR完全等价，因此所有PPN参数与GR相同。

#### 8.5.2 经典检验

广义相对论的三大经典检验：

1. **水星近日点进动**：每世纪43角秒，与观测一致
2. **光线偏折**：太阳引力使星光偏折1.75角秒，爱丁顿1919年观测证实
3. **引力红移**：庞德-雷布卡实验（1959年）验证

这些检验在k形式下完全保留，因为k形式与标准GR等价。

## 第9章 史瓦西解与黑洞物理

### 9.1 史瓦西度规的推导

#### 9.1.1 球对称真空场方程

考虑球对称、静态的真空时空。球对称性意味着度规在空间旋转下不变，静态性意味着度规不依赖于时间坐标，且不存在交叉项 \(g_{0i}\)。

采用球坐标 \((t, r, \theta, \phi)\)，最一般的球对称静态度规为：

\[
ds^2 = -A(r) c^2 dt^2 + B(r) dr^2 + r^2 (d\theta^2 + \sin^2\theta \, d\phi^2)
\]

其中 \(A(r)\) 和 \(B(r)\) 是仅依赖于 \(r\) 的待求函数。

#### 9.1.2 真空场方程求解

真空中 \(T_{\mu\nu} = 0\)，场方程为 \(G_{\mu\nu} = 0\)，等价于 \(R_{\mu\nu} = 0\)（四维时空中真空场方程可缩并为里奇张量为零）。

计算克里斯托费尔符号、里奇张量，令其为零，得到微分方程：

\[
\frac{A'}{A} + \frac{B'}{B} = 0
\]

\[
\frac{A''}{A} - \frac{1}{2}\left(\frac{A'}{A}\right)^2 - \frac{A'}{A}\frac{B'}{B} + \frac{A'}{Ar} = 0
\]

\[
1 - B + \frac{r}{2}\left(\frac{A'}{A} - \frac{B'}{B}\right) = 0
\]

由第一个方程得 \(AB = \text{常数}\)。在 \(r \to \infty\) 时度规趋近闵可夫斯基度规，故 \(A(\infty) = B(\infty) = 1\)，因此 \(AB = 1\)，即 \(B = 1/A\)。

代入第三个方程：

\[
1 - \frac{1}{A} + \frac{r}{2}\left(\frac{A'}{A} + \frac{A'}{A}\right) = 1 - \frac{1}{A} + r \frac{A'}{A} = 0
\]

\[
A - 1 + r A' = 0 \implies \frac{d}{dr}(rA) = 1 \implies rA = r + C
\]

其中 \(C\) 为积分常数。因此：

\[
A(r) = 1 + \frac{C}{r}, \quad B(r) = \frac{1}{1 + C/r}
\]

#### 9.1.3 积分常数的确定

在弱场极限下，\(g_{00} = -A(r) \approx -(1 + 2\Phi/c^2)\)，而牛顿引力势 \(\Phi = -GM/r\)，因此：

\[
A(r) = 1 - \frac{2GM}{c^2 r}
\]

对比得 \(C = -2GM/c^2\)。

用k表示：

\[
C = -\frac{2GM}{c^2} = -\frac{kM}{2\pi c^2}
\]

#### 9.1.4 史瓦西度规

最终得到**史瓦西度规（Schwarzschild metric）**：

\[
\boxed{ds^2 = -\left(1 - \frac{2GM}{c^2 r}\right) c^2 dt^2 + \frac{dr^2}{1 - \frac{2GM}{c^2 r}} + r^2 (d\theta^2 + \sin^2\theta \, d\phi^2)}
\]

k形式：

\[
ds^2 = -\left(1 - \frac{kM}{2\pi c^2 r}\right) c^2 dt^2 + \frac{dr^2}{1 - \frac{kM}{2\pi c^2 r}} + r^2 (d\theta^2 + \sin^2\theta \, d\phi^2)
\]

定义**史瓦西半径（Schwarzschild radius）**：

\[
r_s \equiv \frac{2GM}{c^2} = \frac{kM}{2\pi c^2}
\]

则度规可写为：

\[
ds^2 = -\left(1 - \frac{r_s}{r}\right) c^2 dt^2 + \frac{dr^2}{1 - r_s/r} + r^2 d\Omega^2
\]

### 9.2 史瓦西半径与事件视界

#### 9.2.1 坐标奇点与物理奇点

在 \(r = r_s\) 处，度规分量 \(g_{rr} \to \infty\)，这看起来像是一个奇点。但实际上，这是**坐标奇点（coordinate singularity）**，由史瓦西坐标的选择造成，而非时空本身的奇点。

可以通过坐标变换（如克鲁斯卡尔坐标）消除 \(r = r_s\) 处的奇异性。

真正的**物理奇点（physical singularity）**位于 \(r = 0\) 处，此处曲率标量（如克雷奇曼标量 \(R_{\mu\nu\rho\sigma} R^{\mu\nu\rho\sigma}\)）发散，且无法通过坐标变换消除。

#### 9.2.2 事件视界

\(r = r_s\) 处的球面是**事件视界（event horizon）**：视界内部的任何信号（包括光）都无法逃逸到外部。

对于静止质量不为零的粒子，一旦越过事件视界，就不可避免地向 \(r = 0\) 的奇点坠落。

视界的面积：

\[
A_H = 4\pi r_s^2 = 4\pi \left(\frac{2GM}{c^2}\right)^2 = \frac{16\pi G^2 M^2}{c^4}
\]

k形式：

\[
A_H = 4\pi \left(\frac{kM}{2\pi c^2}\right)^2 = \frac{k^2 M^2}{\pi c^4}
\]

### 9.3 克鲁斯卡尔坐标与最大延拓

#### 9.3.1 乌龟坐标

定义**乌龟坐标（tortoise coordinate）**：

\[
r_* = r + r_s \ln\left|\frac{r}{r_s} - 1\right|
\]

在乌龟坐标下，径向光的传播方程简化为：

\[
ds^2 = \left(1 - \frac{r_s}{r}\right)(-c^2 dt^2 + dr_*^2) + r^2 d\Omega^2
\]

径向光满足 \(dt = \pm dr_*/c\)，即光在 \((t, r_*)\) 平面上沿45度线传播。

#### 9.3.2 克鲁斯卡尔-塞凯赖什坐标

定义**克鲁斯卡尔-塞凯赖什坐标（Kruskal-Szekeres coordinates）** \((U, V)\)：

对于 \(r > r_s\)（外部区域）：
\[
U = e^{-r_*/(2r_s)} \cosh\left(\frac{ct}{2r_s}\right), \quad V = e^{-r_*/(2r_s)} \sinh\left(\frac{ct}{2r_s}\right)
\]

对于 \(r < r_s\)（内部区域）：
\[
U = e^{r_*/(2r_s)} \sinh\left(\frac{ct}{2r_s}\right), \quad V = e^{r_*/(2r_s)} \cosh\left(\frac{ct}{2r_s}\right)
\]

在克鲁斯卡尔坐标下，度规为：

\[
ds^2 = \frac{4r_s^3}{r} e^{-r/r_s} (-c^2 dV^2 + dU^2) + r^2 d\Omega^2
\]

其中 \(r\) 由 \(U^2 - V^2 = \left(\frac{r}{r_s} - 1\right) e^{r/r_s}\) 隐式定义。

在克鲁斯卡尔坐标中，事件视界对应 \(U = \pm V\)，奇点对应 \(U^2 - V^2 = -1\)（即 \(r = 0\)）。

#### 9.3.3 最大延拓时空

克鲁斯卡尔坐标描述了史瓦西时空的**最大延拓（maximal extension）**，包含四个区域：

- **I区**：\(r > r_s, U > |V|\)，我们的宇宙（外部）
- **II区**：\(r < r_s, V > |U|\)，黑洞内部
- **III区**：\(r > r_s, U < -|V|\)，另一个宇宙（白洞外部）
- **IV区**：\(r < r_s, V < -|U|\)，白洞内部

III区和IV区在物理上被认为是数学延拓的产物，对于由引力坍缩形成的黑洞并不存在。

### 9.4 黑洞热力学

#### 9.4.1 黑洞力学四定律

1973年，巴丁、卡特和霍金提出了**黑洞力学四定律**，与热力学四定律形式上完全对应：

**第零定律（稳态）**：稳态黑洞的表面引力 \(\kappa\) 在整个视界上是常数。

\[
\kappa = \text{常数} \quad \text{（在视界上）}
\]

对应热力学第零定律：热平衡时温度均匀。

**第一定律（能量守恒）**：

\[
dM = \frac{\kappa}{8\pi G} dA + \Omega dJ + \Phi dQ
\]

其中 \(A\) 是视界面积，\(J\) 是角动量，\(Q\) 是电荷，\(\Omega\) 是角速度，\(\Phi\) 是电势。

对应热力学第一定律：\(dE = TdS + pdV + \ldots\)

**第二定律（面积不减）**：经典黑洞的视界面积永不减少：

\[
dA \geq 0
\]

对应热力学第二定律：熵不减。

**第三定律（不可达性）**：不可能通过有限次物理过程将黑洞的表面引力降为零。

对应热力学第三定律：不可能通过有限过程达到绝对零度。

#### 9.4.2 霍金辐射与黑洞温度

1974年，霍金发现黑洞并非完全"黑"，而是会发出热辐射（霍金辐射）。黑洞的温度为：

\[
T_H = \frac{\hbar \kappa}{2\pi k_B c}
\]

对于史瓦西黑洞，表面引力 \(\kappa = c^4/(4GM) = c^2/(2r_s)\)，因此：

\[
T_H = \frac{\hbar c^3}{8\pi G M k_B} = \frac{\hbar c^3}{2k M k_B}
\]

k形式：

\[
\boxed{T_H = \frac{\hbar c^3}{2k M k_B}}
\]

注意：此处 \(\hbar\) 是独立的普朗克常数，不使用 \(\hbar = 4\pi kc\) 关系（该关系仅在高能区近似，且此处为低能黑洞热力学）。

#### 9.4.3 贝肯斯坦-霍金熵

黑洞的熵为：

\[
S_{BH} = \frac{k_B c^3 A}{4G \hbar} = \frac{2\pi k_B c^3 A}{k \hbar}
\]

对于史瓦西黑洞，\(A = 16\pi G^2 M^2 / c^4 = k^2 M^2 / (\pi c^4)\)，代入得：

\[
S_{BH} = \frac{k_B c^3}{4G\hbar} \cdot \frac{16\pi G^2 M^2}{c^4} = \frac{4\pi G k_B M^2}{\hbar c} = \frac{k k_B M^2}{\hbar c}
\]

k形式：

\[
\boxed{S_{BH} = \frac{k k_B M^2}{\hbar c}}
\]

或用普朗克质量 \(m_p = \sqrt{\hbar c/G} = \sqrt{4\pi \hbar c/k}\) 表示：

\[
S_{BH} = 4\pi k_B \left(\frac{M}{m_p}\right)^2
\]

#### 9.4.4 黑洞蒸发

由于霍金辐射，黑洞会缓慢损失质量。质量损失率为：

\[
\frac{dM}{dt} = -\frac{\hbar c^6}{15360\pi G^2 M^2} = -\frac{\pi \hbar c^6}{960 k^2 M^2}
\]

k形式：

\[
\boxed{\frac{dM}{dt} = -\frac{\pi \hbar c^6}{960 k^2 M^2}}
\]

黑洞的寿命（从质量 \(M\) 蒸发到零）：

\[
\tau \approx \frac{5120\pi G^2 M^3}{\hbar c^4} = \frac{320 k^2 M^3}{\pi \hbar c^4}
\]

k形式：

\[
\boxed{\tau \approx \frac{320 k^2 M^3}{\pi \hbar c^4}}
\]

对于太阳质量的黑洞，\(M = M_\odot \approx 2 \times 10^{30} \, \text{kg}\)，寿命约为 \(10^{67}\) 年，远大于宇宙年龄。

### 9.5 雷斯纳-诺德斯特洛姆解（带电黑洞）

#### 9.5.1 爱因斯坦-麦克斯韦场方程

考虑球对称、静态的带电黑洞。时空度规仍为球对称静态形式，但能量动量张量包含电磁场的贡献。

**爱因斯坦-麦克斯韦场方程**：

\[
G_{\mu\nu} = \frac{8\pi G}{c^4} T_{\mu\nu}^{\text{EM}}
\]

其中电磁场能量动量张量：

\[
T_{\mu\nu}^{\text{EM}} = \frac{1}{\mu_0} \left( F_{\mu\alpha} F_\nu{}^\alpha - \frac{1}{4} g_{\mu\nu} F_{\alpha\beta} F^{\alpha\beta} \right)
\]

麦克斯韦方程：

\[
\nabla_\mu F^{\mu\nu} = \mu_0 J^\nu, \quad \nabla_{[\mu} F_{\nu\rho]} = 0
\]

#### 9.5.2 雷斯纳-诺德斯特洛姆度规

对于球对称静态电场 \(F_{0r} = -E(r)\)，求解爱因斯坦-麦克斯韦方程，得到**雷斯纳-诺德斯特洛姆度规（Reissner-Nordström metric）**：

\[
ds^2 = -\left(1 - \frac{2GM}{c^2 r} + \frac{G Q^2}{4\pi\varepsilon_0 c^4 r^2}\right) c^2 dt^2 + \frac{dr^2}{1 - \frac{2GM}{c^2 r} + \frac{G Q^2}{4\pi\varepsilon_0 c^4 r^2}} + r^2 d\Omega^2
\]

k形式（令 \(k = 4\pi G\)，\(k' = 1/\varepsilon_0\)）：

\[
ds^2 = -\left(1 - \frac{kM}{2\pi c^2 r} + \frac{k k' Q^2}{16\pi^2 c^4 r^2}\right) c^2 dt^2 + \frac{dr^2}{1 - \frac{kM}{2\pi c^2 r} + \frac{k k' Q^2}{16\pi^2 c^4 r^2}} + r^2 d\Omega^2
\]

定义特征半径：

\[
r_\pm = \frac{GM}{c^2} \pm \sqrt{\left(\frac{GM}{c^2}\right)^2 - \frac{G Q^2}{4\pi\varepsilon_0 c^4}} = \frac{kM}{4\pi c^2} \pm \sqrt{\left(\frac{kM}{4\pi c^2}\right)^2 - \frac{k k' Q^2}{16\pi^2 c^4}}
\]

- \(r_+\)：外事件视界
- \(r_-\)：内柯西视界

当 \(Q = 0\) 时，退化为史瓦西解。

当 \(M^2 < G Q^2 / (4\pi\varepsilon_0 c^4)\) 时，不存在视界，形成**裸奇点（naked singularity）**。宇宙监督假设认为自然界不存在裸奇点。

### 9.6 克尔解（旋转黑洞）

#### 9.6.1 克尔度规

1963年，罗伊·克尔发现了旋转黑洞的精确解。**克尔度规（Kerr metric）**在博耶-林德奎斯特坐标下为：

\[
ds^2 = -\left(1 - \frac{2GMr}{\Sigma c^2}\right) c^2 dt^2 - \frac{4GMa r \sin^2\theta}{\Sigma c^2} c dt d\phi + \frac{\Sigma}{\Delta} dr^2 + \Sigma d\theta^2 + \left(r^2 + a^2 + \frac{2GMa^2 r \sin^2\theta}{\Sigma c^2}\right) \sin^2\theta \, d\phi^2
\]

其中：
- \(a = J/(Mc)\) 是单位质量的角动量（比角动量）
- \(\Sigma = r^2 + a^2 \cos^2\theta\)
- \(\Delta = r^2 - \frac{2GMr}{c^2} + a^2\)

k形式：将 \(G = k/(4\pi)\) 代入即可。

#### 9.6.2 克尔黑洞的结构

克尔黑洞具有以下特征曲面：

- **外事件视界**：\(\Delta = 0\) 的较大根 \(r_+ = GM/c^2 + \sqrt{(GM/c^2)^2 - a^2}\)
- **内事件视界**：\(\Delta = 0\) 的较小根 \(r_- = GM/c^2 - \sqrt{(GM/c^2)^2 - a^2}\)
- **静态极限（能层外边界）**：\(g_{tt} = 0\)，即 \(r_e(\theta) = GM/c^2 + \sqrt{(GM/c^2)^2 - a^2 \cos^2\theta}\)

**能层（ergosphere）**：位于静态极限和外视界之间的区域。在能层内，\(g_{tt} > 0\)，时间坐标变为类空的，粒子无法静止，必须被黑洞的旋转拖曳着一起转动（参考系拖曳效应）。

#### 9.6.3 彭罗斯过程

1969年，罗杰·彭罗斯发现可以从旋转黑洞的能层中提取能量，这一过程称为**彭罗斯过程（Penrose process）**。

原理：一个粒子进入能层后分裂为两个粒子，其中一个落入黑洞（具有负能），另一个逃逸到无穷远（具有比入射粒子更大的能量）。能量来自黑洞的旋转能。

可提取的最大能量（对于极端克尔黑洞 \(a = GM/c^2\)）约为黑洞静能的29%。

#### 9.6.4 黑洞无毛定理

**黑洞无毛定理（No-hair theorem）**：稳态黑洞完全由三个宏观参数描述：质量 \(M\)、角动量 \(J\)、电荷 \(Q\)。所有其他信息（"毛"）都在黑洞形成过程中丢失了。

最一般的稳态黑洞解是**克尔-纽曼度规（Kerr-Newman metric）**，描述带电旋转黑洞。当 \(Q = 0\) 时退化为克尔解，当 \(J = 0\) 时退化为雷斯纳-诺德斯特洛姆解，当 \(Q = J = 0\) 时退化为史瓦西解。

## 第10章 引力波

### 10.1 线性化引力与引力波

#### 10.1.1 线性化爱因斯坦方程

在弱场近似下，度规写为 \(g_{\mu\nu} = \eta_{\mu\nu} + h_{\mu\nu}\)，\(|h_{\mu\nu}| \ll 1\)。保留 \(h_{\mu\nu}\) 的一阶项，爱因斯坦场方程线性化为：

\[
\square \bar{h}_{\mu\nu} = -\frac{16\pi G}{c^4} T_{\mu\nu} = -\frac{4k}{c^4} T_{\mu\nu}
\]

其中 \(\bar{h}_{\mu\nu} = h_{\mu\nu} - \frac{1}{2} \eta_{\mu\nu} h\) 是迹反转微扰，\(\square = \eta^{\mu\nu} \partial_\mu \partial_\nu = -\frac{1}{c^2}\partial_t^2 + \nabla^2\) 是达朗贝尔算符。

k形式：

\[
\boxed{\square \bar{h}_{\mu\nu} = -\frac{4k}{c^4} T_{\mu\nu}}
\]

#### 10.1.2 横向无迹规范

选择**横向无迹规范（Transverse-Traceless gauge, TT gauge）**，满足：
- \(\partial^\mu \bar{h}_{\mu\nu} = 0\)（横向条件）
- \(\bar{h} = \eta^{\mu\nu} \bar{h}_{\mu\nu} = 0\)（无迹条件）

在TT规范下，真空中的线性化方程变为波动方程：

\[
\square h_{\mu\nu}^{\text{TT}} = 0
\]

平面波解沿z方向传播：

\[
h_{\mu\nu}^{\text{TT}} = \begin{pmatrix}
0 & 0 & 0 & 0 \\
0 & h_+ & h_\times & 0 \\
0 & h_\times & -h_+ & 0 \\
0 & 0 & 0 & 0
\end{pmatrix} \cos(\omega t - kz)
\]

其中 \(h_+\) 和 \(h_\times\) 是引力波的两个独立偏振模式（加号偏振和叉号偏振）。

### 10.2 引力波的产生

#### 10.2.1 四极辐射公式

引力波的主要辐射机制是**质量四极矩辐射**。在慢运动近似下，辐射功率为：

\[
P = \frac{G}{5c^5} \left\langle \dddot{Q}_{ij} \dddot{Q}_{ij} \right\rangle = \frac{k}{20\pi c^5} \left\langle \dddot{Q}_{ij} \dddot{Q}_{ij} \right\rangle
\]

其中 \(Q_{ij} = \int \rho(x) (x_i x_j - \frac{1}{3} r^2 \delta_{ij}) d^3x\) 是约化质量四极矩，\(\langle \cdot \rangle\) 表示时间平均，三个点表示对时间的三阶导数。

k形式：

\[
\boxed{P = \frac{k}{20\pi c^5} \left\langle \dddot{Q}_{ij} \dddot{Q}_{ij} \right\rangle}
\]

#### 10.2.2 双星系统的引力波辐射

对于两个质量 \(m_1, m_2\) 在圆轨道上运动的双星系统，轨道半径 \(a\)，轨道频率 \(f_{\text{orb}}\)，开普勒定律给出 \(f_{\text{orb}}^2 = G(m_1+m_2)/(4\pi^2 a^3)\)。

引力波频率为轨道频率的两倍：\(f_{\text{GW}} = 2 f_{\text{orb}}\)。

辐射功率：

\[
P = \frac{32 G^4}{5 c^5} \frac{m_1^2 m_2^2 (m_1+m_2)}{a^5} = \frac{2 k^4}{5 \pi^3 c^5} \frac{m_1^2 m_2^2 (m_1+m_2)}{a^5}
\]

k形式：

\[
\boxed{P = \frac{2 k^4}{5 \pi^3 c^5} \frac{m_1^2 m_2^2 (m_1+m_2)}{a^5}}
\]

轨道衰减率：

\[
\dot{a} = -\frac{64 G^3}{5 c^5} \frac{m_1 m_2 (m_1+m_2)}{a^3}
\]

这一效应已在脉冲双星PSR B1913+16中被精确观测到，赫尔斯和泰勒因此获得1993年诺贝尔物理学奖。

### 10.3 引力波的探测

#### 10.3.1 激光干涉引力波天文台

LIGO（Laser Interferometer Gravitational-Wave Observatory）使用迈克尔逊干涉仪探测引力波。引力波经过时会交替拉伸和压缩干涉仪的两条臂，产生可测量的光程差。

LIGO的臂长为4公里，灵敏度达到 \(h \sim 10^{-22}\)，相当于质子直径的千分之一。

2015年9月14日，LIGO首次直接探测到引力波（事件GW150914），来自两个黑洞的并合。

#### 10.3.2 引力波天文学

引力波天文学开启了观测宇宙的新窗口。已探测到的引力波事件包括：
- 双黑洞并合（GW150914等）
- 双中子星并合（GW170817，伴随电磁对应体）
- 中子星-黑洞并合（GW200105等）

未来的空间引力波探测器（如LISA）将能够探测更低频率的引力波，包括超大质量黑洞并合、极端质量比旋近等。

## 第11章 第二卷总结与过渡

### 11.1 本卷核心成果

第二卷完成了广义相对论在k形式下的完整重构，核心成果包括：

1. **等效原理与广义协变性**：建立了引力几何化的物理基础
2. **k形式场方程**：\(G_{\mu\nu} = \frac{2k}{c^4} T_{\mu\nu}\)，与标准GR完全等价
3. **k形式希尔伯特作用量**：\(S_H = \frac{c^4}{4k} \int R \sqrt{-g} d^4x\)
4. **史瓦西解**：\(r_s = \frac{kM}{2\pi c^2}\)，完整推导了黑洞物理
5. **黑洞热力学**：\(T_H = \frac{\hbar c^3}{2k M k_B}\)，\(S_{BH} = \frac{k k_B M^2}{\hbar c}\)
6. **引力波**：线性化方程、四极辐射公式、双星系统辐射
7. **经典检验**：水星进动、光线偏折、引力红移在k形式下完全保留

### 11.2 关键性质验证

**等价性验证**：所有k形式的公式均可通过 \(k = 4\pi G\) 还原为标准GR公式，证明二者完全等价。

**量纲验证**：所有公式的量纲均自洽，k的量纲 \(L^3M^{-1}T^{-2}\) 在所有推导中保持一致。

**无循环验证**：本卷所有推导均基于正统GR，不使用 \(\hbar = 4\pi kc\) 关系（该关系仅在第四卷高能区作为唯象假设出现）。

### 11.3 向第三卷的过渡

第二卷建立了经典引力的k形式。第三卷将进入**量子力学与标准模型**，探讨：

- 量子力学的基本框架与k体系的兼容性
- 量子场论基础：正则量子化与路径积分
- 电弱统一理论与希格斯机制
- 量子色动力学（QCD）与渐近自由
- 精细结构常数的标准定义与耦合跑动
- 标准模型的参数化与k体系的接口

第三卷将严格遵守"兼容不修改"原则：标准模型的所有方程保持不变，k仅作为引力耦合常数出现在引力-量子接口处。
