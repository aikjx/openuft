PART 1: VELOCITY = THE UNIVERSAL CONSTANT c
========================================================================

[1.1] The speed of light c
  c = 299,792,458 m/s (EXACT, by definition)
  This is not a measurement, it's a DEFINITION
  Since 1983: meter = distance light travels in 1/c seconds

[1.2] What IS c?
  Traditional physics: c = speed of light propagation
  Framework: c = speed of SPACE ITSELF

  Space moves in eternal helical motion at speed c
  Light 'travels' at c because it IS space motion
  c is not 'photon speed', it's 'spacetime speed'

[1.3] Velocity in the helix
  Light helix has THREE velocity components:

  1. RADIAL velocity: v_r = 0
     - Radial is oscillation, not translation
     - 'Inward/outward' but no net motion

  2. TANGENTIAL velocity: v_t = c (at helix surface)
     - Circular motion at radius R
     - v_t = R * omega = c
     - This is the 'rotation' of the helix

  3. AXIAL velocity: v_a = c
     - Forward motion along helix axis
     - 'Propagation' direction

  Total velocity: |v| = sqrt(v_r^2 + v_t^2 + v_a^2) = c*sqrt(2)
  But: v_r=0, v_t and v_a are components of the SAME c
  Correct: v_tangential + v_axial = c (vector sum)

[1.4] Perpendicular decomposition of c
  c_total = c (the fundamental speed)
  Decomposed into perpendicular components:

    c^2 = v_perp^2 + v_para^2

  where:
    v_perp = perpendicular to helix axis (radial rotation)
    v_para = parallel to helix axis (axial advance)

  Ratio: v_perp/v_para = alpha (fine structure constant!)
  Proof: tau/kappa = alpha
  tau (torsion) controls axial advance
  kappa (curvature) controls perpendicular rotation

PART 2: VELOCITY IN FOUR FORCES
========================================================================

[2.1] Electromagnetic Force and Velocity
  Photon velocity: c (massless, travels at c)
  Charged particle velocity: v < c (massive)
  Relativistic effects: gamma = 1/sqrt(1 - v^2/c^2)

  EM field propagation: c
  Information transfer: c (causality)
  Light in medium: v = c/n (n = refractive index)
    But: photons always travel at c between interactions

  Geometric interpretation:
    EM force = radial mode
    Radial oscillation propagates at c along helix
    E and B fields oscillate perpendicular to propagation

[2.2] Strong Force and Velocity
  Gluon velocity: c (massless)
  But: gluons are confined, no asymptotic states
  Quark velocity: v < c (confined in hadrons)
  Inside proton: v_quark ~ c (relativistic)

  Strong field propagation: c (within confinement)
  Confinement: gluons cannot escape
  Range: ~1 fm, crossing time ~ 10^-23 s

  Geometric interpretation:
    Strong force = tangential mode
    Tangential mode is 'trapped' in helix
    Cannot propagate freely -> short range
    But the mode itself oscillates at speed c

[2.3] Weak Force and Velocity
  W/Z boson velocity: c (massive, but relativistic)
  W/Z rest mass: M_W ~ 80 GeV, M_Z ~ 91 GeV
  At low energy: v_W << c
  At high energy: v_W ~ c

  Weak field propagation: < c (massive mediators)
  Range: ~10^-18 m, Yukawa potential

  Geometric interpretation:
    Weak force = chiral mode
    Chiral mode is 'perpendicular' to 3D space
    Higgs mechanism gives mass -> slows down propagation
    Short range because massive mediators

[2.4] Gravitational Force and Velocity
  Graviton velocity: c (massless, predicted)
  Gravitational wave velocity: c (observed, GW170817)
  Newtonian gravity: instantaneous (approximation)
  GR: gravitational effects propagate at c

  Gravitational field propagation: c
  Information transfer: c (causality)
  Binary black hole merger: waves travel at c

  Geometric interpretation:
    Gravity = axial mode
    Axial mode extends along helix axis
    Propagates at c along the axis
    Long range because massless mediator

    Massive particle = helix with internal oscillation
    Energy -> infinity means omega -> infinity

  Classical behavior valid
