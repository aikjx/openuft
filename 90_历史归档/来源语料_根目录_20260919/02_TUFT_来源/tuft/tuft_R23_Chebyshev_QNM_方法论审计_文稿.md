# TUFT · R23 —— Chebyshev 谱配点求 QNM 的方法论审计（诚实记录一次失败）

> 一句话：尝试用 Chebyshev 谱配点 + 广义特征值补上 R20/R21/R22 共同记录的「特征值级精确谱」缺口，**失败**——谱中只有**域箱模**（阻尼随域长变化 4.1×，而物理 QNM 应域长无关），算子装配与网格已各自验证正确（1e-11 / 1e-12），故根因定位于「QNM 解沿两端指数增长 + 有限域出波 BC」，并据此说明为何 Leaver 连分式才是正确工具。R20/R21/R22 的物理结论不受影响。

评级 **O / L2**（诚实负面结论 + 根因诊断，非 TUFT 缺陷）。红线：数学自洽 ≠ 实验证实。

## 零、动机

R20/R21/R22 三册都把「特征值级精确解」留作后续：
- R20：外向射击法对复 QNM 有经典指数不稳定（根随 r_max 漂移）
- R21/R22：时域拟合精度 ~0.3~1%

本册尝试通用谱方法（Chebyshev 谱配点 + companion 线性化）跨过该限制。

---

## 一、方法

```
Ψ'' + (ω² − V(r*))Ψ = 0
· r*∈[a,b] → Chebyshev 点 y∈[−1,1]；D_r*=(2/L)D_y，D2_r*=(2/L)²D2_y
· 边界：GR 左端入波 (DΨ)_L = −iωΨ_L；右端出波 (DΨ)_R = iωΨ_R
· 边界含 ω ⇒ 用 Φ=ωΨ 做标准 companion 线性化：
  (ω²M + ωC + K)Ψ = 0  →  A z = ω B z,  z=[Ψ;Φ]
  A = [[0, I], [−K, −C]]，B = [[I, 0], [0, M]]
```
索引约定：0 = 右端（∞侧），N = 左端（视界侧）。

## 三、失败（V3 FAIL）

基准：GR Schwarzschild l=2 基模 **ωM = 0.373672 − 0.088962 i**。

| r_max | 域长 L | Im ω × L | 最接近文献的模 | \|Δ\| |
|---|---|---|---|---|
| 20 | 37.6 | −2.17 | +0.35369 −0.05764 i | 3.72e-02 |
| 25 | 43.1 | −2.47 | +0.38140 −0.05741 i | 3.25e-02 |
| 30 | 48.5 | −2.95 | +0.40344 −0.06080 i | 4.10e-02 |
| 40 | 59.1 | −2.99 | +0.38715 −0.05052 i | 4.07e-02 |
| 60 | 79.9 | −3.21 | +0.36640 −0.04020 i | 4.93e-02 |
| 100 | 121.0 | −3.73 | +0.37287 −0.03082 i | 5.82e-02 |
| 300 | 323.2 | −4.76 | +0.37333 −0.01471 i | 7.43e-02 |

**判据**：物理 QNM 的阻尼应与域长无关（变化 ≲1%）；箱模则 |Im ω| ∝ 1/L。

**实测**：所有 r_max 下 |Δ| > 1e-2（最小 3.25e-02）；**阻尼随域长变化 4.1×**（0.0147→0.0608），Im ω×L 为 O(1)（−2.2 ~ −4.8）。

**判定（FAIL）**：谱中所求是**域箱模**，物理 QNM 未出现在谱中。

## 四、根因诊断

1. **QNM 解沿两端指数增长**：|Ψ| ~ e^{|Im ω|·|r*|}。本系统 L≈320 时动态范围 ~e^{28} ≈ 10¹²，全局 Chebyshev 展开不可表示。
2. **有限域出波 BC 使离散谱退化为箱模**：其阻尼由端泄漏决定，|Im ω| ≈ ln(1/|R|)/L ⇒ 随 L→∞ 而 →0——与实测 ∝1/L 完全一致。
3. **缩短域无救**：r_max=20 时 Im ω=−0.058 仍远离 −0.089，且出波 BC 误差已升至 ~6%（V(r_max)/ω²）。两端不可兼得。

**为何 Leaver 可行**：其 ansatz
```
Ψ = e^{iωr} (r−2M)^{−2iMω} Σ a_n (1−2M/r)^n
```
**解析地因子化掉**上述指数增长，把问题化为系数递推 + 连分式求根，从而绕开谱方法的表示能力限制。

## 五、影响评估

**不受影响（PASS）**：R21/R22 时域演化得到的 γ（0.02606 / 0.02968）与 R20 的 |T_h|²、R22 的精细度判据 γ·T_echo=0.36 三方交叉一致，**均不依赖本册失败的谱方法**；时域法的 0.3~0.6% 精度仍是当前最佳可用精度。

**缺口仍在**：「特征值级（≤1e-6）精确 QNM 谱」仍开放——需 Leaver 连分式，或复合坐标延拓 / 完美匹配层（PML）改造边界以消除箱模。

## 七、结论

1. **算子装配与网格已验证正确（1e-11 / 1e-12）** ⇒ 失败定位明确，不是低级装配错误。
2. **谱配点求 QNM 失败并已根因诊断**（指数增长 + 有限域出波 BC ⇒ 箱模）。
3. **该失败是有价值的信息**：它解释了为何通用谱方法不适用、为何 Leaver 的 ansatz 必须显式因子化指数增长——避免后续重复无效尝试。
4. **R20/R21/R22 的物理结论不受影响**；特征值级精确谱缺口仍开放。

**红线**：本册是数值方法审计，不改 R20/R21/R22 的物理结论；数学自洽 ≠ 实验证实。
