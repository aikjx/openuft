## 核心理论

### 五大公理

1. **光速恒常公理**：$v_\text{总}\equiv c$，$v_\parallel^2+v_\perp^2=c^2$

3. **几何-物理对应公理**：$E=\hbar\omega$，$p=\hbar\tau$，$m=\hbar\kappa/c$，$s=\pm\hbar/2$
4. **全域等效原理**：局域惯性系中广义联络对称部分为零
5. **量子化公理**：螺旋参数满足拓扑量子化条件

### 核心公式

$$
\boxed{
\begin{aligned}
\kappa &= \frac{a}{a^2+b^2},\quad \tau = \frac{b}{a^2+b^2} \quad \text{（螺旋曲率/挠率）}\\
\omega &= c\sqrt{\kappa^2+\tau^2} = c\kappa_0 \quad \text{（角频率）}\\
E &= \hbar\omega = \hbar c\kappa_0 \quad \text{（能量）}\\
p &= \hbar\tau \quad \text{（动量）}\\
m_0 &= \frac{\hbar\kappa}{c} \quad \text{（静止质量）}\\
v_\parallel &= c\frac{\tau}{\kappa_0},\quad v_\perp = c\frac{\kappa}{\kappa_0}\\
\gamma &= \frac{\kappa_0}{\kappa}\\
E^2 &= p^2c^2 + m_0^2c^4
\end{aligned}
}
$$

## 关于"所有角速度是否一样"

**答案：不一样，但可以统一。**

不同物理情境中的角速度有不同的起源和物理意义，但在光速螺旋框架下，**所有角速度都可以统一表示为 $\omega = c\cdot\kappa_\text{eff}$**，其中 $\kappa_\text{eff}$ 是不同来源的"有效曲率"：

| 角速度类型 | 公式 | 有效曲率来源 |
|-----------|------|------------|
| 内禀自旋（康普顿频率） | $\omega_C=mc^2/\hbar$ | 粒子螺旋曲率 $\kappa_0=mc/\hbar$ |
| 引力轨道 | $\omega_\text{orb}=\sqrt{GM/r^3}$ | 时空曲率 $\kappa_g=\sqrt{GM/(c^2r^3)}$ |
| 参考系拖拽 | $\omega_\text{drag}=2GJ/(c^2r^3)$ | 挠率时空扭转 $\kappa_\text{drag}=2GJ/(c^3r^3)$ |
| 回旋频率 | $\omega_c=qB/m$ | 电磁有效曲率 $\kappa_c=qB/(mc)$ |
| 拉莫尔进动 | $\omega_L=gqB/(2m)$ | 磁矩耦合曲率 $\kappa_L=gqB/(2mc)$ |
| 原子轨道 | $\omega_\text{atom}=\alpha^2\omega_C$ | 原子尺度曲率 $\kappa_\text{atom}=\alpha^2mc/\hbar$ |

**内禀自旋角速度远大于其他所有角速度**：电子的康普顿频率 $\omega_C\sim10^{21}$ rad/s，而原子轨道频率 $\sim10^{16}$ rad/s（是康普顿频率的 $\alpha^2\sim5\times10^{-5}$ 分频），地球轨道角速度 $\sim10^{-7}$ rad/s。
