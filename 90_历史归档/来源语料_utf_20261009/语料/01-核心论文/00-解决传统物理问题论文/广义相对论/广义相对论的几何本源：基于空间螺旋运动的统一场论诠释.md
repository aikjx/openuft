### A.1 爱因斯坦场方程的详细推导

基于空间螺旋运动假设，我们可以详细推导出爱因斯坦场方程。

#### A.1.1 时空度规的变分

考虑时空度规g_μν的变分δg_μν，我们可以定义引力作用量S_G为：

S_G = (1/16πG)∫R√(-g)d⁴x

其中，R为标量曲率，g为度规行列式，G为引力常数，积分范围为整个时空。

物质的作用量S_M为：

S_M = ∫L_M√(-g)d⁴x

其中，L_M为物质的拉格朗日密度。

总作用量S为：

S = S_G + S_M

根据变分原理，δS = 0，我们可以得到：

δS_G + δS_M = 0

#### A.1.2 引力作用量的变分

引力作用量的变分为：

δS_G = (1/16πG)∫(δR√(-g) + Rδ√(-g))d⁴x

其中，δ√(-g) = (-1/2)√(-g)g_μνδg_μν，δR = R_μνδg_μν + g_μνδR_μν。

通过分部积分，我们可以得到：

δS_G = (1/16πG)∫G_μνδg_μν√(-g)d⁴x

其中，G_μν = R_μν - (1/2)Rg_μν为爱因斯坦张量。

#### A.1.3 物质作用量的变分

物质作用量的变分为：

δS_M = ∫(∂L_M/∂g_μνδg_μν + L_Mδ√(-g))d⁴x

定义能量动量张量T_μν为：

T_μν = -2(1/√(-g))∂(L_M√(-g))/∂g_μν = -2∂L_M/∂g_μν + g_μνL_M

则物质作用量的变分为：

δS_M = (1/2)∫T_μνδg_μν√(-g)d⁴x

#### A.1.4 爱因斯坦场方程的推导

根据变分原理δS = 0，我们有：

(1/16πG)∫G_μνδg_μν√(-g)d⁴x + (1/2)∫T_μνδg_μν√(-g)d⁴x = 0

由于δg_μν的任意性，我们得到：

G_μν = (8πG/c⁴)T_μν

这就是爱因斯坦场方程。
