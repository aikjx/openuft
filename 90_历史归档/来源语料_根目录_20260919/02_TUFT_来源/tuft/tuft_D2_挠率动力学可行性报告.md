## 二、量纲桥接（§1，PASS 1 / INFO 3）

挠率分量 `T^λ_{μν}` 是联络之差 ⇒ `[T] = 1/m`；R5/R6 使用 `s⁻¹` 口径，桥接为 `T[s⁻¹] = c · T[m⁻¹]`。

| 量 | `s⁻¹` 口径 | `m⁻¹` 口径 |
|---|---|---|
| R6 的 EC 自然源 | `7.32e-33` | `2.442e-41`（R6 记录 `2.44e-41`，相对偏差 `7e-4`）✓ |
| R5 探测目标 | `1e-4` | `3.336e-13` |

EC 源方程 `T = (8πG/c³)·s_spin` 量纲闭合：`[G/c³]=s/kg`、`[s_spin]=kg/(m·s)` ⇒ `[T]=1/m` ✓

> **结论**：R6 的口径换算自洽，本册后续可直接使用其数字。

## 三、EC 中挠率为何不传播（§2，PASS 3 / INFO 1）

用 `sympy.calculus.euler.euler_equations` 对三类拉氏量做符号变分：

| 拉氏量 | EOM | 判定 |
|---|---|---|
| `(1/2)(∂φ)² − (1/2)m²φ²` | `−m²φ − ∂²φ/∂t² + ∂²φ/∂x²` | **含二阶导数 ⇒ 传播** ✓ |
| `−(1/2)m²φ²`（无导数） | `−m²φ` | **代数 ⇒ 不传播** |
| `(1/2)(□φ)²` | 四阶 | **Ostrogradsky 鬼** |

第二行正是 EC 中挠率的结构：一阶（Palatini）形式下 `R = dω + ω∧ω`，用 `T = de + ω∧e` 反解 `ω = ω_LC + K`（`K` 为 contortion，与 `T` 代数线性相关）后，作用量中 `K` 只以 `K²` 的代数二次型出现 ⇒ `δS/δK = 0` 是**代数**方程 `K ∝ 自旋流`，不含 `∂²K/∂t²` ⇒ 无色散关系、无本征模、无传播。

> 与 R6「EC 挠率不传播」互为印证（本册是符号层复现，R6 是量级层判定）。

## 五、尺度困境定理（§4，本册核心 · FAIL 4）

### 5.1 由 TUFT 自身的尺度锚定反推挠率质量

O-SCALE 方案 A2（唯一「半内」锚定）给出 `L = 1.4406e8 l_P = 2.328e-27 m`。若挠率元胞的特征尺度就是 `L`，则其 Compton 波长 `λ = L`：

```
m_T = ħ/(λc) = 1.511e-16 kg
E   = m_T c² = 13.578 J = 8.475e19 eV = 8.475e10 GeV
```

### 5.2 宏观可探测的必要条件

有质量场在距离 `r` 处按 `exp(−r/λ)` 衰减。要在 `r_lab = 0.1 m` 处不被压制，需 `λ ≳ r_lab`：

```
m_T ≤ ħ/(r_lab·c) = 3.518e-42 kg  ⇒  E ≤ 1.973e-6 eV
```

### 5.3 冲突（D2-4.3，FAIL）

```
E_req / E_allow = 8.475e19 eV / 1.973e-6 eV = 4.295e25  ≈ 26 个数量级
```

坚持尺度锚定时，实验室处的抑制因子为 `exp(−0.1 / 2.328e-27) = exp(−4.3e25)`——**数值上就是 0**。

## 六、F1/F5 终判与范式连锁（§5，FAIL 4 / INFO 2）

### 6.1 F1 不可执行（D2-5.1，FAIL）

三条动力学路径全部关闭：**有质量** ⇒ Yukawa 压制；**无质量** ⇒ 缺口 `1.37e28` 且新耦合被排除；**谐振** ⇒ 需 `Q~1e28`。

### 6.2 F1 的性质变更（D2-5.2，FAIL）——本册最重要的哲学后果

> 若 TUFT 的尺度锚定成立，则**地面无挠率信号是 TUFT 的预测，而不是它的反例**。

也就是说 F1 的"被满足"既不构成证伪、也不构成支持——它从**证伪通道**退化为**自洽推论**。白皮书把它列为"核心证伪实验"属**判据错置**。

### 6.3 F5 同步失效（D2-5.3，FAIL）

F5 依赖同一自旋-挠率耦合强度，受同一压制。

把 `m_T` 作为**独立自由参数**与粒子尺度 `L` 解耦（`m_T ≲ 1.973e-6 eV`）。代价三条：

## 七、本册结论

1. **挠率可以有健康的动力学项**（Proca 型 C2，3 DOF，无鬼无 tachyon）——这是本册唯一的建设性结论。
2. **但动力学化救不了 F1**，反而暴露一个新冲突：**「挠率元胞 = 粒子（`λ ~ 1e-27 m`）」与「挠率可地面探测（`λ ≳ 0.1 m`）」相差约 26 个数量级，不可兼得**。
3. **F1/F5 应降级**：从"核心证伪通道"改为"TUFT 的自洽推论"；白皮书的可证伪性论述需据此修订。
4. **T1′ 陷入二难**：保留"挠率承载粒子"就放弃地面检验；保留地面检验就放弃"挠率承载粒子"的本体论动机。
