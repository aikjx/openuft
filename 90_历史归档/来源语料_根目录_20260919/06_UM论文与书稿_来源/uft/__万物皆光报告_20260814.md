```

τ/κ = 螺旋节距/螺旋半径 = 螺旋的"扭转程度"
    = α（精细结构常数）

电荷不是"基本量"，而是"光的扭转几何"。
```

### 3.2 电荷公式

```
α = e²/(4πε₀ℏc) = τ/κ

→ e² = 4πε₀ℏc × τ/κ
→ e = √(4πε₀ℏc) × √(τ/κ)

电荷 = 几何单位 × √(螺旋扭转)

√(4πε₀ℏc) = 1.875×10⁻¹⁸ C（几何单位电荷）
√(α)      = 0.0854（螺旋扭转因子）
乘积      = 1.60×10⁻¹⁹ C = e ✓

电荷的本质 = 光螺旋的扭转程度。
```


### 5.2 真空电容率

```
ε₀ = 1/(μ₀c²) = 1/(4πκ²c²)

电容率 = 光螺旋对扭转的响应。
电场   = 光螺旋的扭转扰动。
```

### 5.3 Maxwell 方程 = 光螺旋动力学

```

∇×E = -∂B/∂t   → 扭转的变化产生旋转
∇×B = μ₀J + μ₀ε₀∂E/∂t  → 旋转的变化产生扭转

Maxwell 方程组 = 光螺旋的扭转-旋转耦合动力学。
```
