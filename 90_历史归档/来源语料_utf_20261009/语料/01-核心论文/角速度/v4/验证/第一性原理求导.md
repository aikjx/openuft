# 一、第一性公设（只保留最小集合）

[

### 公设 2：空间为光速圆柱螺旋结构

[
\mathbf R(t)

r\cos(\omega t)\mathbf i

# 二、从纯几何出发

对时间求导：

[
\mathbf V=
-r\omega\sin\omega t,\mathbf i
+
r\omega\cos\omega t,\mathbf j
+
p\mathbf k
]

模平方：

[
|\mathbf V|^2
=============

(r\omega)^2+p^2
]

根据公设 1：

[
(r\omega)^2+p^2=c^2
]

到这里为止，只是几何结构约束。

# 四、真正第一性重建思路

在三维空间中，圆周运动曲率：

[
\kappa=\frac{1}{r}

[
\omega=\frac{v}{r}

若空间本底速度固定为 c：

[
\omega=\frac{c}{r}
]

这是纯几何结论。

# 五、引力作为“空间曲率调制”

若质量 M 造成空间曲率变化：

根据牛顿势：

[
\Phi=-\frac{GM}{R}

[
g_{00}\approx 1+\frac{2\Phi}{c^2}

[
\omega(R)
=========

\omega_0
\sqrt{\frac{|\Phi|}{c^2}}

代入：

[
\omega
======

\frac{c}{r}
\sqrt{\frac{GM}{Rc^2}}
]

利用

[
r_g=\frac{2GM}{c^2}
]

得到：

[
\omega
======

\frac{c}{r}
\sqrt{\frac{r_g}{2R}}
]
