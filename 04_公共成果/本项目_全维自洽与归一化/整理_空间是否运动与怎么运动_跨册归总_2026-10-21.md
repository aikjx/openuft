## §1 P1：空间点以光速走螺旋线

### 1.1 数学层：恒真，但零信息量

库内被反复机器验证的两条关系式（r95 A06 / A07，S01 全维三重奏）：

- `κ² + τ² = (ω/c)²`（r95 A06：残差机器零）
- `κ/τ = v_θ/v_z`（r95 A07：残差 `2.83e−70`）

**这两条是 Frenet–Serret 标架的定义式推论，不是物理定律。** 给定一条以速率 `c` 走螺旋线的曲线，其曲率 κ、挠率 τ、角频率 ω 之间必然满足上述关系——这是曲线微分几何的恒等式，对**任意**螺旋线成立，对**非螺旋**曲线不成立，因此它**不区分任何两种物理相互作用**，也**不蕴含任何动力学**。

库内结论一致：这条式子的「残差趋机器零」只能证明「你确实构造了一条螺旋线」，不能证明「空间是螺旋运动的」。**「残差趋机器零」≠「公式正确」更≠「公式有物理内容」**（r26 纪律：须先验代码真跑过；恒等式复读在库内已复发 ≥9 次）。

### 1.2 物理层：要它产生引力，即被否证

一旦把 P1 从「几何描述」升级为「引力来源」，立刻撞上 r95 的三条硬判据：

- **G03 三选二互斥**：公理 (1) `(rω)² + v_z² = c²`、牛顿势 `A_z = −GM/z²`、开普勒 `v_θ = √(GM/z)` 三者不可同时成立。联立要求 `C = c² − 3GM/z` 为常数，而它随 z 变：水星处 `C = 8.9875510998458222685178470E+16` vs 地球处 `8.9875515212298161472561085E+16`，**差 `4.213840E+9`**。
- **G04 实测否证（两路）**：以地球定 `C`，水星 `v_θ² = −1.9221E+9 < 0`（公理 (1) 崩为虚数）；以水星定 `C`，地球 `v_θ = 7.1421E+4 m/s` vs 真实 `2.9785E+4`，**比 2.398**。
- **G05 开普勒判别（本命题唯一的正面物理判据）**：火星周期实测 `686.98 d`；`1/r²` 预测 `686.9704 d`（相对 `1.4E−5`，符合）；取公理 (1) 的自然读法 `v_θ = const` 得 `1/r` 预测 `556.53 d`，**差 19%，被排除** ⇒ **`1/r²` 只能是外部输入**，不能由空间螺旋导出。

### 1.3 两难：ω(r) 固定则被排除，自由则不可证伪

- **ω(r) 固定**（取牛顿型）：附加进动为 0，而观测值 `42.98″/世纪` ⇒ **被排除**。
- **ω(r) 自由**：可任取以拟合任何进动曲线 ⇒ **不可证伪**。

这正是本册元结论（§8）中「**固定则被排除、自由则不可证伪**」的第一处复发。

**⇒ P1 小结**：作为几何描述恒真且零信息量；作为引力理论被开普勒判据否证；唯一能解除两难的出路是给 `ω(r,t)` 一个**场方程**（r95 记为 P4 修法，代价最大——引入函数级自由度、撞 Ω5），本册不代选。

## §3 P3：曲率 κ、挠率 τ 是传播场

**裁定：κ/τ 不传播，是代数 slave。** 三条独立路径给出同一结论：

   - 系统为**抛物型**（时间 1 阶 < 空间 2 阶）⇒ **无限传播速度**；
   - `κ≡0` 零模上 `ω = −iαk²` **纯虚** ⇒ 来稿所称「`ω=ck` 是边界条件导出」实为**传播解不存在**。

## §9 直答

**问：空间是否运动？**

- **数学层**：P1 的 `κ²+τ²=(ω/c)²`、`κ/τ=v_θ/v_z` **恒真**——但它们是 Frenet–Serret 定义式推论，**零信息量**，不蕴含任何动力学，不区分任何两种相互作用。
- **物理层**：四条「运动方式」**全部碰壁**——P1 导出引力被开普勒判据否证（19%）；P2 度规流动在框架内结构性不可行（五族全关、`M_neg` 达宇宙质量 `6.92e6` 倍）；P3 κ/τ 不传播（变分给 `R=0` 与代数 slave、PDE 违反 Clairaut）；P4 与 GR 逐字相同、呼吸模已 5.74σ 排除。
- **观测层**：**零证据**。四个窗口（g−2 α/(8π) 口径 / EDM / ringdown）已被否决，β 跑动无预言；μ 子 g−2 异常本身也已消失。

**问：怎么运动？**

三条走法各撞一面不同的墙：
- **空间点走螺旋** → 撞「开普勒 + 固有时 + 光速无动力学角色」；
- **度规整体流动** → 撞「QEI 五族 + 能量账 + `v_s>c` 固有时为虚」；
- **κ/τ 场传播** → 撞「无作用量（Clairaut）+ 尺度困境 26 量级」。

**唯一能解除 P1 两难的是给 `ω(r,t)` 一个场方程与螺旋轴取向的选择规则**——这是代价最大的修法（引入函数级自由度、撞 Ω5），**本册不代选**。

**唯一存活的实验判据**：曲速泡内时钟减速 `g = √(1−β²)`，三档语义见 §2.2 的**更正后**表述（**(i) `g_obs=1` ⇒ `v_s=0` ⇒ 排除该族全部 `v_s>0`**），适用范围限于**同族度规 Ansatz**。
