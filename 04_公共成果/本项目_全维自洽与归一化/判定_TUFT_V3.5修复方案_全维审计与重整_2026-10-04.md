## 二、参量空间与 Ω（来料第二节）· B 组 8 条

### 2.1 Ω 的自由度：Π 定理给出的硬约束（B-01 / B-02）

κ、τ **同量纲 L⁻¹**。由 Buckingham Π 定理：2 个变量、1 个独立量纲 ⇒ **只有 1 个无量纲组合**（比值 r = τ/κ，等价射线角 θ = atan2(τ,κ)）。

⇒ **Ω(κ,τ) ≡ Ω(r)**：它感知不到 (κ,τ) 的**绝对尺度**，只感知**方向**。机器验证（λ = 1e-3 … 1e9）缩放变化 **0.000e+00**。

**直接后果（尺度简并）**：(κ,τ) 与 (λκ,λτ) 给出**同一个强度**，却给出**相差 λ 倍的力程** `L ~ 1/√(κ²+τ²)`。
⇒ **强度与力程在 Ω 框架内结构性脱钩**，不可能由同一个 Ω 同时决定两者。
（与 TUFT 尺度册同型：O-SCALE 简并秩 = 1、K_sat 电子/普朗克差 5.7e44。）

### 2.2 分区：示例既不完备也不互斥（B-03 / B-04 / B-05）

| ID | 判定 | 机器读数 |
|---|---|---|
| **B-03** | **FAIL** | 边界 `\|κ\| < B_i` 左侧量纲 **L⁻¹**、右侧自称无量纲 ⇒ 比较非法（如「5 米 < 3」）。四条边界实为 **4 个有量纲外锚**，违反来料自己的 Ω 公理 4。真正无量纲的写法只能是比值式，如 `\|κ\|/√(κ²+τ²) < b_1` |
| **B-04** | **FAIL** | 网格 58080 点：未覆盖 **96.42%**（如 κ = τ = 5 四个条件全不满足）、重叠 **0.028%**（如 κ = 0.2, τ = −0.2 同时命中 EM 与 Weak）⇒ 该分区**不是流形的一个分割** |
| **B-05** | **FAIL** | 「证明映射是单射」是**概念错配**：D: ℝ² → {4 类} 必然多对一，单射数学上不可能。真正需要的是**互斥 + 完备的分割** ⇒ 按「单射」去做会得到一个永远做不出来的任务 |

### 2.3 唯一自洽的替代：角度分区（B-06 · 本册的构造性交付）

把边界写成角度形式 θ = atan2(τ, κ) 的四段扇区：网格 58080 点 **未覆盖 0** ⇒ **互斥 + 完备 + 无量纲（换单位不变）**，且满足来料 Ω 公理 3（跨边界可连续）。

**代价**：扇区只定「类的方向」，**定不了力程**——四类的力程必须由**四个独立的尺度外锚**给出。

### 2.4 两个不可消除项（B-07 / B-08）

- **B-07（H3）**：无限力程 ⇒ κ = τ = 0 ⇒ `τ/κ = 0/0` ⇒ **Ω 无定义** ⇒ 引力与电磁在 Ω 框架内**没有强度**。这不是参数未标定，是框架内部极限不相容。
- **B-08（D-01 定价）**：来料公理 2 要求「Ω 的符号由 κ,τ 代数关系自动决定，D_G 区自然给出 Ω < 0」。
  在 Ω = Ω(θ) 框架下只有两条路：(a) 先划定哪段 θ 属引力、再规定该段 Ω < 0 —— **正是要消除的循环**；(b) 由动力学导出 —— 需要 Ω 的场方程，而体系当前没有（回链 O-OMEGA）。
  **机器旁证**：对任意满足四条公理的 Ω(θ)，乘 −1 后**仍满足全部四条公理**（实值、无量纲、光滑、常数个数不变）⇒ **公理集对 Ω 的符号没有唯一性约束力**。
  ⇒ **D-01 在当前框架内不可由公理约束消除**（与终极正确性册 N1「平凡包含」同构）。来料自己也把它标为「核心难点」，本册给出的是**否定性定价**。
