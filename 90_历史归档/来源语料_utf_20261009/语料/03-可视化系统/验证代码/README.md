# 引力光速统一方程验证工具集

本目录包含引力光速统一方程的验证代码和工具，用于确保理论推导的数学正确性和计算一致性。

## 工具列表

### 1. 核心验证脚本

#### `comprehensive_z_verification.py`
**综合验证脚本**，提供完整的Z常数验证和分析功能：
- 验证不同来源的Z值（精确计算值、论文值、项目使用值、近似值）
- 进行反向验证（使用Z值计算G并与CODATA值比较）
- 验证几何因子2的数学推导
- 生成详细的可视化图表
- 输出完整的验证报告

```bash
python comprehensive_z_verification.py
```

#### `verify_z_calculation.py`
**基础Z值验证脚本**，验证Z值的基本计算：
- 使用CODATA 2018年的G和c值计算Z
- 比较计算结果与论文中给出的Z值
- 检查两者是否一致

```bash
python verify_z_calculation.py
```

#### `verify_calculation.py`
**理论计算验证脚本**，验证Z值的理论计算：
- 根据公式Z = G·c/2计算Z的理论值
- 验证与论文中Z值的一致性
- 分析反向验证的意义和局限性

```bash
python verify_calculation.py
```

#### `verify_geometric_factor.py`
**几何因子验证脚本**，验证几何因子2的数学推导：
- 验证关键积分的正确性
- 计算平均投影效率
- 生成积分结果的可视化图表

```bash
python verify_geometric_factor.py
```

### 2. 项目修复工具

这些工具位于`../06-工具脚本/`目录下：

#### `scan_z_usage.py`
**文件扫描工具**，用于定位项目中所有使用Z值的文件：
- 扫描指定目录下的所有相关文件
- 识别Z值的直接赋值和计算公式
- 生成详细的扫描报告，按文件类型和路径分类

```bash
python ../06-工具脚本/scan_z_usage.py
```

#### `constants.py`
**统一常量定义文件**，提供标准化的物理常数引用：
- 定义CODATA 2018年的G和c值
- 提供精确Z值、近似Z值和旧Z值的定义
- 定义几何因子和辅助常数
- 便于所有模块导入使用，避免重复定义和不一致

## 使用流程

### 1. 初步分析
1. 运行`scan_z_usage.py`扫描项目中的Z值使用情况
2. 查看生成的扫描报告，了解问题的范围和分布

### 2. 验证问题
1. 运行`comprehensive_z_verification.py`进行综合验证
2. 查看生成的验证报告和可视化图表，确认问题细节

### 3. 实施修复
1. 根据`Z值修复指南.md`中的建议制定修复计划
2. 优先修改核心代码和验证脚本
3. 使用`constants.py`作为统一的常数来源

### 4. 验证修复
1. 修复完成后，重新运行验证脚本
2. 确认所有验证项都通过
3. 检查反向计算结果是否与CODATA值一致

## 注意事项

1. **数据备份**：在进行大规模修改前，请备份相关文件

2. **兼容性考虑**：注意修改可能对现有计算结果和可视化产生的影响

3. **文档更新**：修改代码后，同步更新相关文档和说明

4. **近似值使用**：在概念说明和教学中仍可使用Z=0.01的近似值，但需明确标注

5. **理论完善**：认识到反向验证的局限性，未来研究应致力于从独立物理原理推导Z值

通过使用这些工具和文档，可以系统地解决项目中的Z值不一致问题，提高引力光速统一方程研究的理论严谨性和计算一致性。
