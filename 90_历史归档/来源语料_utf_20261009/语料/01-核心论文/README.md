# 核心论文目录

## 最顶尖、最伟大论文格式要求

### 1. 格式与结构规范（Nature级别）

#### 1.1 基本格式要求
- **标题**：≤20词，简洁、准确、吸引人，使用英文
- **摘要**：≤150-200词，独立完整、突出重要性，包含关键发现和数值结果
- **正文**：≤2,000-3,000词，极致简洁，突出核心贡献
- **参考文献**：≤50篇，优先引用核心文献和Nature格式
- **补充材料**：详细推导、额外数据、计算代码

#### 1.2 结构框架
- **引言**（300词）：问题背景+研究意义+主要贡献
- **主体**（1,200词）：理论框架→推导过程→验证结果→讨论分析
- **结论**（200词）：总结发现→科学意义→未来展望
- **Methods**（300词）：技术细节→可重复性描述
- **Extended Data**：≤10项图表和补充分析

### 2. 数学证明与严格求导验证

#### 2.1 严格求导验证方法
- **多角度交叉验证**：几何因子2需通过至少6种不同数学方法严格证明
  - 极角积分法
  - 立体角积分法
  - 矢量场论法
  - 张量分析法
  - 群论对称分析法
  - 量纲分析与能量守恒法
- **形式化数学验证**：将证明转化为形式化逻辑语句，使用证明助手验证
- **代数几何方法**：利用概型理论、同调代数、动机理论等高级工具

#### 2.2 数学严谨性标准
- **逻辑推理严密性**：每一步推导都有明确的数学依据
- **计算过程准确性**：提供详细的计算步骤和中间结果
- **结论普适性与局限性**：明确指出结论的适用范围和边界条件
- **量纲分析**：对所有公式进行严格的量纲一致性检验

### 3. 数据与计算要求

#### 3.1 数值验证标准
- **高精度计算**：相对误差<0.001%，使用CODATA最新常数
- **一致性检验**：验证符号导数和数值导数的一致性
- **误差分析**：评估数值方法的误差范围和置信区间
- **大规模验证**：如黎曼ζ函数零点验证前10^12个

#### 3.2 代码验证要求
- **提供完整可运行代码**：Python/Mathematica等
- **详细注释**：中英文双语注释说明验证过程
- **参数敏感性分析**：测试不同参数下的结果稳定性
- **计算结果可视化**：展示关键计算结果的图表

### 4. 可视化与图表规范

#### 4.1 图表质量标准
- **高分辨率**：≥300 dpi，使用矢量图(EPS/PDF)
- **专业软件**：使用Illustrator/Inkscape/Matplotlib等专业工具
- **Nature风格**：配色、字体、比例符合Nature标准
- **几何直观验证**：通过可视化增强证明的可理解性

#### 4.2 图表内容要求
- **清晰标题**：准确描述图表内容
- **坐标轴标签**：包含物理量名称和单位
- **图例**：清晰标识不同数据系列
- **标注说明**：关键特征和几何因子来源的标注
- **对比数据**：理论值与实验值的对比展示

### 6. 突破性与创新性要求

#### 6.1 突破性表述
- **避免模糊表述**：避免"可能"、"也许"等不确定性词语
- **采用肯定表述**："Here we show that"、"This work transforms"等
- **关键词选择**：First principles、Geometric derivation、Theoretical breakthrough

#### 6.2 创新点突出
- **首次性贡献**：强调理论首次揭示的物理关系
- **跨学科影响**：展示对其他学科的潜在影响
- **方法论创新**：突出新的数学工具或研究方法
