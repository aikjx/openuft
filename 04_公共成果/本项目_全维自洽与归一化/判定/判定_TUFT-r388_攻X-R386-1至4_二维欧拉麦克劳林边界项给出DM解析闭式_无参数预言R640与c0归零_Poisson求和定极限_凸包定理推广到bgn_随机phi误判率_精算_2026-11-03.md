## §二 X-R386-1：二维 Euler–Maclaurin 边界项闭式

### 2.1 陈述

设 `A = r² + M²`，`S(M) = Σ_{|m|≤M} Σ_{|n|≤M} (r²+m²+n²)^{-3/2}`，`I_box(M) = ∫∫_{[-M,M]²}` 同一被积函数，`D_M ≡ S(M) − I_box(M)`。则

```
D_M = 2·Σ'  +  3·f_角  +  (1/12)·∮∂_n f  +  O(M^-5)

Σ'      = Σ_{n=-M+1}^{M-1} (A + n²)^{-3/2}        （四条边内点和，系数 2）
f_角    = (r² + 2M²)^{-3/2}                        （4 个角，系数 3）
∮∂_n f = 4∫_{-M}^{M} ∂_x f(M,y) dy
        = −8M²(3A + 2M²) / (A²(A + M²)^{3/2})
```

### 2.2 三项的来历（两段分解，缺任一段都算不出）

```
S_full − Σ_trap = (1/2)·Σ_{边,非角} + (3/4)·Σ_角 = 2Σ' + 3f_角      ← 格点侧：把矩形和改成梯形和
Σ_trap − ∫∫     = (1/12)·∮∂_n f                                    ← 连续侧：一维 EM 沿四条边积分
```

第一段用二维 EM 的**顶点权**（角点权 1/4、边内点权 1/2），第二段用一维 EM 的一阶修正 `(1/12)(f'(b)−f'(a))` 逐边累加。两段的量级分别是 1e-3 与 1e-3，**净剩 1e-4**。

## §四 X-R386-2：`c0` 精确为 0（Poisson 求和）

### 4.1 推导两步

**① Poisson 求和**：`Σ_{Z²} f(n) = Σ_m f̂(2πm)`。**`f̂` 的自变量是 `2πm` 而不是 `m`**。

**② 二维 FT 闭式**：`f = (ρ² + r²)^{-3/2}`，`ν = 3/2`：

```
f̂(k) = 2π (k/2r)^{ν−1} K_{ν−1}(kr) / Γ(ν)
     = 2π (k/2r)^{1/2} K_{1/2}(kr) / Γ(3/2)
K_{1/2}(z) = √(π/2z)·e^{-z}   ⇒   f̂(k) = 2π·e^{-rk}/r
```

关键在 **`K_{1/2}` 给的是指数衰减 `e^{-rk}`，不是幂律**。若把 `K_{ν−1}` 记成 `I_0K_0` 那类幂律，非零模修正会从 `e^{-40π}` 变成 `e^{-20}`，结论相差 **46 个量级**（G08 专盯这个）。

于是 `S_∞ = (2π/r)[1 + O(e^{-2πr})]`，`R_∞ = 2π·Σ_{m≠0} e^{-2πr|m|}`：

```
r = 20  ⇒  e^{-40π} = 2.66e-55   ⇒   R_∞ = 6.686e-54
```

### 4.2 结论的强度

`c0` **不是「定不出」，而是精确为 0**。任何数值方法都不可能分辨 `6.7e-54`——所以 r384/r386 的 3.480e-01 散布，**根源不是数据乱，而是被拟合的形状选错了**。

### 4.3 「1/M 项与 1/M² 项同量级」（B4）

| M | 20 | 40 | 80 | 160 | 320 |
|---|---|---|---|---|---|
| `R_M` | −4.1312 | −2.5475 | −1.3706 | −0.7004 | −0.3524 |
| `R_M·M` | −82.62 | −101.90 | −109.65 | −112.06 | −**112.78** |

`R_M·M` 从 −82.6 漂到 −112.8，**仍在动、未到渐近** ⇒ 在这组 M 上 `1/M` 项与 `1/M²` 项同量级，任何「`c0 + c1/M + ck/M^k`」的三点基都定不出 `c0`。`R_M` 的真渐近是 `−A/M`（`A≈113`），`c0=0` 被 `1/M` 项完全淹没。

## §五 X-R386-3：凸包定理推广到 `b·g(n)`

### 5.1 陈述

设 `E(n) = E₀(n) + b·g(n)`，`g` **严格单增**。则

> **定理.**　`k` 是某个 `b` 的 argmin ⟺ `(g(k), E₀(k))` 是点集 `{(g(n), E₀(n))}` 的**下凸包顶点**。

### 5.2 一行证明

`min_n [E₀(n) + b·g(n)]` 就是把点 `(g(n), E₀(n))` 与方向 `(b, 1)` 作内积取最小 ⇒ 最小值必在**下凸包顶点**。`g` 单增保证 `n ↦ g(n)` 单射，故「顶点 ↔ n」一一对应。

★替换规则：旧式里的 `(m − k)` 全部换成 `(g(k) − g(m))`，即可从 r386 的线性版直接搬运。

### 5.3 三路对拍（H1）

| `g(n)` | 凸包顶点 | min-max 非空 | 内点反演失败 | 网格暴力命中 |
|---|---|---|---|---|
| `n`（线性） | 10 | 10 | 0 | 10 |
| `n²` | **3** | 3 | 0 | 3 |
| `√n` | 11 | 11 | 0 | 11 |
| `ln(n+1)` | 11 | 11 | 0 | 7 |

前三条路（凸包 / 半直线之交 / 内点反演）在四个 g 上**给同一集合**；第四列「网格暴力」只作旁证。`ln(n+1)` 一档网格只命中 7 个，是因为暴力网格在 `ln` 尺度上分辨不出密集的相邻顶点——这是**旁证方法的局限**，不是定理的反例。

### 5.4 换 `g` 真的改变可达集（H2）

`g=n` 时 10 个 n 可达，`g=n²` 时只剩 3 个（丢掉 `{4, 9, 10, 15, 16, 21, 23}`，共 7 个）。

★这条防止「定理恒真」的误读：换 `g` 就是**换坐标**，可达集随之变。`g=n²` 把 `n²` 与 `a n²` 并成一项，等于把曲率锁死 ⇒ 可调自由度更少 ⇒ 可达集更小。这与 r384 的「含 `1/N` 项更难被窗口约束」是同一件事的两面。

### 5.5 单增不可省（C1，负对照）

取 `g(n) = n + 2·sin n`（非单增）：min-max 预测只给 **1** 个 n（`{4}`），网格暴力实得 **7** 个，其中 **6 个**落在预测集外（`{2, 3, 8, 14, 20, 21}`）。

★若 H1 在 `g` 非单增时也「成立」，H1 就是**恒真的空判据**。这条负对照正是 H1 的判别力来源。
