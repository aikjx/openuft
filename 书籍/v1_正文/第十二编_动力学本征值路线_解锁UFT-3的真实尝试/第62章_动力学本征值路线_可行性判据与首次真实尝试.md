## 62.1 为什么需要动力学可行性判据

第十一编（第55–61章）用六条判据回答「什么才算实现了统一场论」，结论是：当前联盟 **2/6**、定理 C 锁死量纲代数路线、唯一的解锁路径是「无量纲数作为**动力学本征值**出现，而非作为常数的乘幂乘积出现」。

> 「动力学路线的可行性判据：本章只说『要走动力学路线』，未给出『如何判断一条动力学路线是否有望』的判据。这是解锁 UFT-3 所必需但本书尚未完成的一步。」

## 62.2 定理 A 的动力学类比：旋钮零空间

量纲零空间定理（第56章定理 A）说：锚集 $A$ 能生成的独立无量纲数个数 $=n-\operatorname{rank}(D_A)$。当 $\{c,\hbar,G\}$ 作锚时该数为 0，故「从 $c,\hbar,G$ 导出 $\alpha$」原理上不可能。

动力学路线换了一类方程，但零空间的语言依然适用。设某动力学路线给出的算子为

$$O\big[\,\text{geometry};\ p_1,\dots,p_k\,\big]$$

其中 $p_i$ 是理论为固定 $O$ 而引入的**无量纲旋钮**（任何可由作者自由选取、不被解固定的参数）。定义

$$\boxed{\ \operatorname{nullity}_{\rm dyn} \;=\; k\ }$$

即旋钮空间的维数。则

> **动力学可行性判据（定理 A 的动力学类比）**：靶 $q$ 作为 $O$ 的谱不变量被**真派生**，当且仅当 $\operatorname{nullity}_{\rm dyn}=0$——即 $q$ 不由任何可调旋钮决定，而由解的结构决定。

两类比并置如下：

| | 量纲代数路线 | 动力学路线 |
|---|---|---|
| 零空间所在 | 锚集量纲矩阵 $D_A$ | 算子旋钮空间 |
| 零空间维数 | $\operatorname{nullity}(D_A)=n-\operatorname{rank}(D_A)$ | $\operatorname{nullity}_{\rm dyn}=k$ |
| 维数 = 0 的含义 | 一个无量纲数都造不出 | 无任何可调旋钮，$q$ 由解固定 |
| 维数 ≥ 1 的含义 | 产物由锚集预先决定（M02） | $q$ 随旋钮连续变化，是拟合非预言（C2） |

这条判据是「自由度的零空间」的同一思想在两类方程上的投影。它与定理 C 完全相容：动力学路线之所以能避开定理 C，不是因为换了名字，而是因为它把无量纲数放进了一个**由解固定、无自由旋钮**的谱问题里。

**裁定规则**：$\operatorname{nullity}_{\rm dyn}=0\Rightarrow$ 路线有望；$\operatorname{nullity}_{\rm dyn}\ge 1\Rightarrow$ 路线当前为拟合，未解锁 UFT-3。

## 62.3 尝试 #1：螺旋曲线上的 da Costa 几何势薛定谔算子

把约束在螺旋曲线上的粒子量子化，其哈密顿量为

$$\hat H = -\frac{\hbar^2}{2m}\frac{d^2}{ds^2} + V_{\rm geo}(s)$$

其中 da Costa 几何势为 $V_{\rm geo}(s)=-\dfrac{\hbar^2}{8m}\big(\kappa^2(s)-\tau^2(s)\big)$。对螺旋曲线，曲率 $\kappa$ 与挠率 $\tau$ 均为常数，故 $V_{\rm geo}$ 为常数偏移，**谱 = 自由粒子谱 + 常数**，不含任何 $\alpha$ 尺度的本征结构。

为与本书设定对齐，取螺距比 $b/R = 1/\alpha = 137.0360$，使 $\kappa/\tau = R/b = \tan\theta \approx \alpha$。真实计算（mpmath + sympy）给出：

| 量 | 值 |
|---|---|
| 螺旋半径 $R$（任意旋钮） | $1.0\times10^{-15}\ \mathrm{m}$ |
| 曲率 $\kappa$ | $5.32485\times10^{10}$ |
| 挠率 $\tau$ | $7.29696\times10^{12}$ |
| $\kappa/\tau$ | $0.00729735$ |
| da Costa 几何势 $V_{\rm geo}$ | $8.12521\times10^{-14}\ \mathrm{J}$ |
| sympy 数值本征值 vs 闭式最大偏差 | $1.262177448\times10^{-29}$（验证通过） |

最后一行是关键：对 $N=6$ 离散哈密顿量矩阵，sympy 数值本征值与闭式 $E_n=V_{\rm geo}+2t\big(1-\cos(n\pi/(N+1))\big)$ 的最大偏差仅 $1.26\times10^{-29}$，确认谱确为自由粒子谱的常数平移。

**候选无量纲本征值 $q=E_1/(m c^2)$ 对自由旋钮 $L$（盒子长度）的依赖**：

| $L$ (m) | $q$ |
|---|---|
| $1\times10^{-12}$ | $1.728313$ |
| $1\times10^{-10}$ | $9.925135\times10^{-1}$ |
| $1\times10^{-8}$ | $9.924399\times10^{-1}$ |
| $1\times10^{-6}$ | $9.924399\times10^{-1}$ |

**以螺旋半径 $R$ 为旋钮时 $q(R)=(\lambda_C/R)^2$**：

| $R$ (m) | $q(R)$ |
|---|---|
| $1\times10^{-16}$ | $1.491190\times10^{7}$ |
| $1\times10^{-15}$ | $1.491190\times10^{5}$ |
| $1\times10^{-14}$ | $1.491190\times10^{3}$ |
| $1\times10^{-13}$ | $1.491190\times10^{1}$ |

$q$ 随 $L$ 或 $R$ 连续变化且跨越多个数量级，证明存在自由旋钮——$\operatorname{nullity}_{\rm dyn}\ge 1$。这条朴素动力学路线没有解锁 UFT-3：$\alpha$ 仍藏在 $\kappa/\tau$（即 $b/R$）的定义里，这正是定理 C 情形 2（C2）的动力学重述。

## 62.4 尝试 #2：螺距 $b/R$ 是否由第一性原理变分固定？

书中 $\alpha=\sin\theta$，且 $\kappa/\tau=\tan\theta=R/b$，故 $\alpha$ 由螺距比 $x=b/R$ 决定。要让 $\alpha$ 成为「派生量」而非「输入」，必须有第一性原理变分原理固定 $x$。

在已陈述的纯螺旋几何中，三重奏恒等式给出 $\kappa^2+\tau^2=(\omega/c)^2$，与 $x=b/R$ **无关**；没有任何第一性原理项显式依赖 $x$。构造作用量 $A=a(\kappa^2+\tau^2)+\mathrm{const}$，则

$$\frac{\partial A}{\partial x} \equiv 0$$

真实符号计算确认：

- 作用量是否显式依赖 $x=b/R$：**否**
- $\partial A/\partial x =$ `0`
- $x=b/R$ 是否为平移方向（不被固定）：**是**

故 $b/R$ 是作用量中的平移方向，不被变分固定。$\alpha=\sin\theta\approx\kappa/\tau$ 因此仍是输入（C2），不是本征值。

## 62.6 总论

UFT 联盟层达成度仍为 **2/6（未实现）**。动力学本征值路线是唯一可行的解路径（定理 C），但本次首次真实尝试证明：朴素地把螺旋几何动力学化并不能解锁 UFT-3——

1. 螺旋曲线（恒定曲率）上的 da Costa 薛定谔谱是自由粒子谱的常数平移，不含 $\alpha$ 尺度结构；
2. $\alpha$ 仍编码在 $\kappa/\tau$（即 $b/R$）的定义中，且螺距比 $b/R$ 是作用量里的平移方向，不被变分固定。

要真正走通，必须补上三块砖：

- **砖一**：一个显式依赖 $b/R$ 的第一性原理变分项，使螺距被固定而非输入；
- **砖二**：一个具非平凡结构的势（非恒定曲率），使算子产生可被观测约束的本征值；
- **砖三**：$\operatorname{nullity}_{\rm dyn}=0$ 的形式化证明。

在补上这三块砖之前，UFT-3 = 0 是结构性的——这与第56章的结论一致，只是现在它被一次可复算的计算所支撑，而不再只是一句断言。

## 62.8 诚实边界与待研究问题

### 已确认 [A]

1. 螺旋恒定曲率上的 da Costa 薛定谔谱确为自由粒子谱的常数平移（sympy 数值本征值 vs 闭式偏差 $1.26\times10^{-29}$）。
2. 候选无量纲本征值 $q$ 显含任意旋钮 $L$（盒子长度）或 $R$（螺旋半径），证明 $\operatorname{nullity}_{\rm dyn}\ge 1$。
3. 螺距比 $x=b/R$ 是作用量中的平移方向（$\partial A/\partial x\equiv 0$），不被变分固定。
4. 本次尝试审计得分 1/6，低于联盟自身 2/6，说明「改说动力学」不等于「解锁 UFT-3」。

### [B] 框架映射

1. 动力学可行性判据是定理 A 的**类比**而非定理——它依赖「旋钮」的直观定义，尚未形式化为严格的自由度计数（类比第56章定理 A 的线性代数严格性）。
2. 尝试 #1 选用 da Costa 几何势是「约束粒子」的标准模型；若改用体积/边界条件不同的算子，谱结构会变，但「恒定曲率 ⇒ 势无结构 ⇒ 无 $\alpha$ 尺度本征值」的定性结论预计不变。

### [C] 待建

1. **砖一的具体候选**：需要一份「显式依赖 $b/R$ 的第一性原理变分项」的清单与评估；本书尚未提供。
2. **砖三的形式化**：把 $\operatorname{nullity}_{\rm dyn}$ 从「旋钮计数」提升为严格的算子自由度计数（类比 $\operatorname{nullity}(D_A)=n-\operatorname{rank}(D_A)$）。
3. **S13 的真正路线**：S13（全域双向分形统一场论）是唯一被第56章记为走在动力学本征值路线上的体系——本章程的尝试是通用螺旋几何版，尚未触及 S13 自身的谱问题；把本判据应用到 S13 是下一步。

### 核心结论

- **定理 A 有动力学类比**：旋钮零空间 $\operatorname{nullity}_{\rm dyn}=0$ 才是真预言的判据。
- **朴素螺旋动力学不解锁 UFT-3**：本次尝试 $\operatorname{nullity}_{\rm dyn}\ge 1$，审计 1/6。
- **UFT 仍 2/6（未实现）**；解锁需补三块砖（固定螺距的变分项 / 具结构势 / $\operatorname{nullity}_{\rm dyn}=0$ 证明）。
- **本章程不宣称任何进展，只把「为什么仍失败」变成了一次可复算的计算。**
