**唯一正面项及其自限**：$d\to u$ 恰对应 unknotting 一步且放能（缺口 O-S03-C2 获自然答案），但属自洽性非验证，且 unknotting number 不能作身份标签（$u\to s$ 需打结、非单射非单调），已被独立否证。

**方法论建议（已写入 V2 判定册 §10）**：在 G4（$\hbar$ 第一性导出）未闭合前，不要再新建质量标度类构造——已连续两轮证明该类构造欠定，第三次同类尝试期望收益接近零。

**S03-V3 补充（2026-10-05）**：上条建议的理由**升级**。V18.3 证明 $\hbar$ 在公设层面即被封锁（纯几何量集量纲封锁 + A1/A4/A5 自由度 2），故「停止新建质量标度构造」不再只是经验判断，而是**公设边界**。同时本轮含一处自我推翻记录（`V3-c-falsified`）：原断言「量纲允许的形式全部循环」被 11 组反例推翻，实际否决理由是「所有量纲可行情形都依赖外加尺度初值」。缺口 G4 已从「待导出的缺口」**改判为「公设边界」**——改判不意味问题被解决，只意味从「可攻克」变为「须显式承担」。

**实现验证 / 数值收敛 / 独立观测检验 三者区分**：
