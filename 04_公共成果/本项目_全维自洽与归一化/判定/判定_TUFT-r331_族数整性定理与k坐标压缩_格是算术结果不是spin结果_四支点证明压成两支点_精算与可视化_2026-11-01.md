## 二、为什么这一卷值得单独立册

r327 是这条链上少见的「结论很硬」的一卷（`n_R = C(q+(n−1)/2, n)`，1060 组零失配）。**但硬的结论容易掩盖软的前提。** 它有两处前提没被审：

1. **格是从上面借的**。r327 定理 D 说「`x ∈ Z` ⟺ FW 格」，而 FW 格是 r325 用 `c1(CP^n)=(n+1)H` + `w₂` + **「D-brane 必须带 spin^c」** 建出来的。最后一条是**物理假设** —— 换个模型（比如 M-理论 `G₄`）就可能不同。若格的合法性只挂在它上面，那 r327 的二项式也跟着挂在那儿。
2. **四个支点没被质疑过**。「跳过 3」用四个支点证完，读者会默认四个都必要。**没有一个支点被单独测过「去掉它会不会垮」**。

本卷把这两件事都做了。结果：

- 前提 (1)：**格根本不需要 spin^c** —— 只要「族数是整数」，格自己就出来了。
- 前提 (2)：**四个支点里两个是影子**，换坐标后自动消失。

> 这一卷的价值不在新结论（解集一个没变），在于**把承重结构换成更弱的**。审计册的价值有一半在这里：不是「又证了什么」，是「原来不需要那么多」。

## 三、定理 A · 族数整性定理

```
x ∈ Q，n ≥ 1，C(x, n) ∈ Z   ⇒   x ∈ Z
```

### 证明

设 `x = a/b` 既约，`b ≥ 2`，取 `p | b`（素数）。则

```
C(a/b, n) = ∏_{i=0}^{n−1} (a − i b) / (b^n · n!)
```

- 对每个 `i`：`a − i b ≡ a (mod p)`；
- `gcd(a,b) = 1 ⇒ p ∤ a` ⇒ **每个因子都 `≢ 0 (mod p)`** ⇒ `p ∤ 分子`；
- 而分母含 `b^n ⊇ p^{n·v_p(b)}`，`n ≥ 1` ⇒ 分式约分后**分母仍带 `p`**。

⇒ `C(x,n) ∉ Z`。∎

**这条证明只用了一个事实**（分子与 `p` 互素），不依赖 `n!` 的结构、不依赖 `n` 有界、不依赖 `p` 是哪个。

### 机检分档

| 条目 | 断言 | 分母 | 实测 |
|---|---|---|---|
| `A01` | **全部**非整有理点都给非整值 | 1700 | 1700 |
| `A02` | 反向：整点全给整值 | 810 | 0 例外 |
| `A05` | 加强：约分后分母**仍被 `p` 整除**（`p`=`b` 最小素因子） | 1700 | 1700 |
| `A08` | 推到 `n=12,15`（远离 `n≤10`） | 7×20 | 0 |

> **`A01` 的 `exp` 是 1700 不是 0。** 这条断言的是「**全部**非整点都给非整值」—— 若样本为空（`A_TOT=0`），`exp=act=0` 会假通过。写成 `exp=A_TOT` 之后，样本一空就必然红（`G12` 另外守分母）。

### 三条判别力对照（缺一条就只剩「自说自话」）

- `A06`：一次式 `2x` 在同批点上有 **20** 个整值 ⇒ 定理 A **不是**「有理点代入多项式就不整」这种废话。
- `A07`：`n=0` 时 `C(x,0) ≡ 1` 恒整（**170/170**）⇒ 定理 A **需要 `n ≥ 1`**；`n=0`（零代，`CP⁰` = 一点）是唯一的例外，且是平凡情形。
- `A04`：手算 `C(1/2,2) = −1/8`、`C(1/2,3) = 1/16`、`C(3/2,2) = 3/8`，分母都带 2 ⇒ 与证明里的 `p=2` 对得上。

## 四、定理 B · 格重建：算术路径 ⟺ 几何路径

### 方向反过来

r327/r325 是「先有格，再验整性」；本卷是「**先要整性，反解出格**」。

做法：在 `q ∈ [−6,6]` 上取 **`1/4` 步长**（**49 个候选，刻意比格更细**，这样就不存在「按格取样」的循环），筛掉所有让 `C(q+(n−1)/2, n)` 非整的点，**剩下的就是格**。

### 结果

| 条目 | 断言 | 实测 |
|---|---|---|
| `B01` | 反解集合 == r325 的格（逐 `n`） | 12/12 |
| `B02` | 12 个 `n` 的**对称差** | **0** |
| `B03` | 格上全给整数 | 188/188 |
| `B04` | 离格给整数 | **0**（分母 547） |

`B03` 只说「格 ⊆ 整性」，`B04` 才说「整性 ⊆ 格」—— 只做一条是**半张表**。

### 「假设更弱」的实证

| 输入 | r325 定理 A | 本卷定理 B |
|---|---|---|
| 1 | `c1(CP^n) = (n+1)H` | `q ∈ Q`（通量量子化） |
| 2 | `w₂ = c1 mod 2` | `n_R ∈ Z`（族数是整数） |
| 3 | **D-brane 带 spin^c（物理假设）** | —— |

`G17` 是**源码级**证据，不是口头声明：把 B 组代码剥掉注释后（2285 字符），`chi_sheaf(` / `chern_cp(` / `todd_root(` / `ahat_A_` 的**调用次数 = 0** ⇒ 这条路径一次性把所有示性类都避开了。

> 所以判词用 `ASSUMPTIONS-WEAKENED-SO-THE-RESULT-IS-STRENGTHENED`。**这不是把 r325 降级，是把它加固** —— 同一张格，现在有两个互不相干的理由。

### 副产物：上指标只确定到模 1（一次失败升级为结论）

首版负对照：「把偏移从 `(n−1)/2` 改成 `(n+1)/2` ⇒ 格必然变」。**它失败了** —— 两者差 **1**，而整平移在格上不可见。

处置不是删掉这条对照，而是**把失败变成结论**（`B06`，12/12）：`(n−1)/2` 与 `(n+1)/2` 反解出**完全相同**的格 ⇒ 决定格的只是偏移的**模 1 类**（整数 vs 半整数）。这正好解释了为什么 r325 的「移位」只有 **0 或 1/2** 两种情形 —— 不是物理只允许两种，是**算术只看得见两种**。

`CTL5` 因此改成真能测出来的：偏移差 **1/2**（`(n−1)/2 → n/2`）⇒ 奇偶翻转 ⇒ 格变。

## 五、定理 C · 非负性：砍一半，但一个解都不砍

| | `k<0` 点数 | 非零 | 符号 | 结论 |
|---|---|---|---|---|
| 奇 `n` | 64 | **16** | 全负 | 非物理 |
| 偶 `n` | 56 | **12** | 全正 | 物理 |

- `C01`：奇 `n` 非零点 **16/16 全负**。
- `C02`：偶 `n` 非零点 **12/12 全正**（另 44 个为**零**）。
- `C03`：格上负 `n_R` 共 **21** 个 —— 奇 `n` 占 21、偶 `n` 占 **0**。
- `C04`：**三个解的 `n_R` 都是 `+3`** ⇒ 非负性**不砍解**。
- `C05`：把 `≥0` 换成 `>0` 也不砍解 ⇒ 两者在这题上等价。

> **这一组最容易滑过去的地方**：如果只写「奇 `n` 的 `k<0` 区全非物理」，读者会以为砍掉 64 个。真相是**大部分是零**（`C(−k−1,n)=0` 当 `k ≤ −n−1`），真正为负的只有 16 个。**凡统计符号，必须同时报零的个数。**
> 而且非负性**对结论零贡献** —— 本卷只主张它是「免费的」，不主张它「救了这卷」。

## 六、定理 D · k 坐标：四个支点塌成两个

### 换什么坐标

```
x = q + (n−1)/2          → 让二项式的上指标成为整数
k = q − (n+1)/2 = x − n  → 让线丛 O(k) 成为整对象
```

只差常数 `n`（`D01` 失配 0），但**常数的方向决定证明长度**。

### 统一形式

```
n_R = σ · C(M, n)
M = k + n   (k ≥ 0)      σ = +1（k ≥ 0 或 n 偶）
M = −k − 1  (k < 0)      σ = −1（k < 0 且 n 奇）
```

| 条目 | 断言 | 实测 |
|---|---|---|
| `D02` | `k ≥ 0` 支 | 失配 0 |
| `D03` | `k < 0` 支 | 失配 0 |
| `D04` | 统一形式 | 失配 0 |
| `D11` | `M` 值域**无洞**（`[0, n+40]` 全覆盖） | 不等者 0 |

### 承重一行

```
n_R ≠ 0   ⟺   M ≥ n
```

`D05` 失配 **0**。**这一行吃掉零段**：r327 的支点③「`0 ≤ x < n` ⇒ `C=0`」在这里是 `M<n` 的**同义话**，不是支点。

### 两个支点

- **① 单调**：`C(M+1,n) − C(M,n) = C(M,n−1) = M!/((n−1)!(M−n+1)!) > 0`（`M ≥ n ≥ 1`）。`D07`：`n=1..15` × `M=n..n+40` = **615** 组恒等式失配 0，正性由显式公式给出。
- **② 端点跳跃**：`C(n,n) = 1 < 3 < n+1 = C(n+1,n)`（`n ≥ 3`）。`D08`：`n=3..15` 反例 **0**。

严格递增 + 相邻值跨 3 ⇒ 中间无整数落点 ⇒ **跳过 3**。`D06`：**915** 组（`n=1..15` × `M=n..n+60`）里给出 3 而 `n≥3` 的 = **0**。

### 等价性门

`D09` + `G16`：解集 `{(1,3), (2,−5/2), (2,5/2)}` === r327 的解集，**逐个 `q` 值**比对。**换坐标若改了结论，那是算错不是简化。**

> 顺带一个几何来源：`n=2` 的两个解在 `M` 坐标下是**同一个 `M=3`** 的两次命中 —— `k=1`（`q=5/2`）与 `k=−4`（`q=−5/2`，`M=−k−1=3`）。所以「两个解」其实是「一个 `M`、两次实现」。

## 七、定理 E · 支点③④是支点①的影子

| r327 支点 | `M` 坐标下的身份 | 机检 |
|---|---|---|
| ③ `0 ≤ x < n` ⇒ `C=0` | `M = n−x−1 < n` ⇒ `C(M,n)=0` | `E02` 失配 0 |
| ④ `x < 0`（负整数支） | `M = n−x−1 ≥ n` ⇒ 落进支点① | `E03`：`x=−40..−1` 落在 `M<n` 的 = **0** |

`E01` 登记一个小事实：`M = x` 只在 `x = (n−1)/2` 处成立 ⇒ 巧合次数 = 奇数 `n` 的个数（**8**）。所以 `M` 不是 `x` 的别名，它是**把 x 的负半轴折回正半轴的反射坐标** —— 这正是它能吸收支点④的原因。

`E04`：解集仍是 3 个 ⇒ **简化而非修正**。

> 方法论（`E05`）：x 坐标把负半轴与正半轴切成两段，k 坐标把它们**折成一段**。**选坐标的自由度就是证明长度的自由度。**

## 十、诚实边界（六条）

1. **只做算术**。整性定理是纯算术，不解释为什么取 `CP²`，也不解释为什么要通量。
2. **格的唯一性只到模 1**（`B06`）：`(n−1)/2` 与 `(n+1)/2` 给同一张格。
3. **非负性只对奇 `n` 有杀伤**（偶 `n` 的 `k<0` 区全正），且**不砍任何解** ⇒ 对结论零贡献。
4. **「跳过 3」仍是 r327 的定理**，本卷只改证明长度与坐标选择。
5. **`CP^n` 之外未查**：整性对任何 `n` 成立，但 `n_R = C(x,n)` 的闭式只在 `CP^n` 上（`X-R331-1`）。
6. **全 `Fraction` 精确**，`Decimal prec=60` 仅格式化；无随机成分（`G05`）。
