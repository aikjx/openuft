## 一、一句话判决

> **`16` 不是「碰巧分成 8 + 8」，而是 `V_J` 与 `V_K` 两个核的交为零、维数和恰为 32 的直和；r397 那个「`J` 档留 2、`K` 档留 0」的读数，其机制是「`Y` 的零模落在 `V_J` 而不在 `V_K`」，不是「`Y` 被换掉了」。**

> - 复结构 `JMAP`（32 维实化空间上乘 `i`）：`JMAP² = −1`，与 45 个 `Σ_ab` + 12 个 SM 生成元**共 57 项逐项交换、不交换 0 个**（A1）；
> - `V_J = ker(su(2)_J)` 与 `V_K = ker(su(2)_K)` 各是**实 16 维**（= 复 8 维）、都是 `JMAP`-不变的（A2 / A3）；
> - `rank(V_J + V_K) = 32`、交维数 **0** ⇒ `16 = V_J ⊕ V_K` 是**定理**（A4），不是认领；
> - `J3` 在 `V_J` 上**恒 0**（8 个弱单态），在 `V_K` 上 `A² = −I` 且 `tr = 0` ⇒ 谱 `±i` 各 8 维实 ⇒ **4 个二重态**，于是 `16 = 8×1 + 4×2`（A5）；
> - **核心**：`ker(Y|V_J) = 2` 维实（复 1 = `ν^c`）、`ker(Y|V_K) = 0` ⇒ r397 的「2 vs 0」是**推导出来的**，不是解出来的（A6）；
> - `Y` 的谱在一组候选值（**±1 / ±2/3 / ±1/3 / ±1/2 / ±1/6 / 0，两侧符号都放**）下分半：`V_J` 只点亮 `{−1, 2/3, −1/3, 0}`、`V_K` 只点亮 `{1/2, −1/6}`，**两值集互不相交、合起来铺满全谱**（A7）；
> - 两半的幂和都不同，而和恰好是 r397 的 `p₁ = 10/3` 与 `p₂ = 95/54`；`tr((iY)²) = 20/3 = 2·p₁`（第三条路径）—— **三路一致**（A7）；
> - 两半各自的 `s₁`（`8/3` 与 `2/3`）**都不等于**任何 `p_k` ⇒ 全谱矩里**没有**「哪一半出多少」的信息，与 r397「`p_k` 四格全同」的边界一致（A7 的 `not _s1_hit`）；
> - `16` 与 `16bar` **不等价**的机核：`ker(iY−1)` 在两边是 **0 vs 2**，`ker(iY+1)` 是 **2 vs 0** ⇒ `y = +1` 的重数 0 vs 1（A8）；
> - 判别力：把 `so(4)` 换到 1..4 号指标，仍是 8+8，但 `dim(V_J ∩ V_J') = 8`、且 `ν^c` **整个换边**（`∈ V_J' = False`、`∈ V_K' = True`）⇒「`ν^c ∈ V_J`」是这一组嵌入的性质，不是废话（A9）。

★ 本卷**不产生**新物理预言。它做的是把 r397 §十六 第 1 优先级那条「机制认领」换成**一条直和定理 + 一张谱分半总表**：`J`/`K` 之所以可分辨，是因为零模落在其中一半（A6），而不是因为 `16` 与 `16bar` 不等价（A8 明写此句不成立为原因）。

## 三、地基一：复结构 `JMAP`（A1）

实化后的空间是 32 维实。**「乘 `i`」不是一句口号**，它是一个 32×32 实矩阵 `JMAP`（`JMAP[i][16+i] = −1`、`JMAP[16+i][i] = +1`）。要它真的代表复结构，必须两件事同时成立：

1. `JMAP² = −1` —— 实测成立；
2. 一切复线性映射与它交换 —— 实测 **57 项**（45 个 `Σ_ab` + 12 个 SM 生成元）不交换 **0 个**。

★★ 这一条不是装饰。r397 把 16×16 复矩阵用 `[[R, −I],[I, R]]` 实化成 32×32 实矩阵；「实化 = 复线性映射」的机核就是「与 `JMAP` 交换」。若某处把 `−B` 的负号写丢，矩阵会立刻不再与 `JMAP` 交换 —— 本卷把它做成了第一道门。

★ 45 + 12 = 57 项**逐项验证，不抽查**（r397 E01/E02 的教训：抽查会漏，全量枚举才抓得到 55 对里那 2 对）。

## 四、地基二：`V_J` 的显式基（A2）

`V_J = ker(su(2)_J)`：把 `SU2J_C` 的 3 个生成元实化后叠成 96 行 × 32 列，解零空间，得 **16 个有理基向量**（每个 32 维，非零分量均为整数，例如基[0] 只有 1 个非零：5 号分量 = 1）。

★★ **「实 16 维」不等于「复 8 维」**：只有子空间 `JMAP`-不变时，才能把实向量 `v` 与 `i·v` 配成对、做除法。这一条是 r397 A5「实 2 ÷ 2 = 复 1」的**结构性版本** —— 那里只对**一个**零空间做了除法，这里对**整个 16 维子空间**验证了复结构。

★ 基向量是有理数，可以直接复算，不需要任何数值容差。

## 五、`V_K` 与直和（A3 / A4）

`V_K = ker(su(2)_K)`：同一算法、只换 3 个生成元（`SU2J_C → SU2K_C`）—— **口径自守：换对象不换算法**。读数：实 16 维、`JMAP`-不变。

★★ 但**维数相同不能说明子空间相同**。A4 直接算 `rank(V_J + V_K)`：

- `rank(V_J + V_K) = 32`；`dim V_J = 16`、`dim V_K = 16` ⇒ 交维数 = **0**。

★★★ 这一条把 r397 §十四 第 5 条的「认领」变成**定理**。机核是**秩**不是「维数相加」：两个 16 维子空间在 32 维里可以完全重合、也可以交成 16 维，只有 `rank(V_J + V_K)` 能分开这三种情形。控制组 K2 就是这件事的负对照（见 §十一）。

## 六、`J3` 在两半上的谱（A5）

不去解本征值，只用**代数恒等式**给谱：

| 半边 | 读数 | 推论 |
|---|---|---|
| `V_J` | `J3` 限制上去**全零** | 8 个复态全是弱单态（`su(2)_J` 平凡） |
| `V_K` | `A² = −I`（16×16 逐元素核验）且 `tr = 0` | 本征值只能取 `±i`；`tr = 0` ⇒ 正负各 8 维实 ⇒ **4 个二重态** |

于是 `16 = 8×1 + 4×2`。**全程有理数，没有一次开方、没有一次浮点。**

★★★ 归一化必须说清（本卷 E01 号自伤的现场）：`Σ_ab = (1/4)[Γ_a, Γ_b]` 是**反 Hermitian**，实化后是**实反对称**，所以 `J3` 的本征值是**纯虚**的；又因为 `SU2J_C` 每个平面系数取 **1**（= 标准 Cartan 的 2 倍），二重态上的谱是 `±i` 而**不是** `±i/2`。第一版把期望写成 `A² = +(1/4)I`（Hermitian 口径）⇒ 当场判 FAIL。

## 七、核心：零模落在哪一半（A6）

把 `Y` 限制到两半，各解一次零空间：

- `ker(Y|V_J) = 2` 维实 = **复 1 维**（就是 `ν^c`）；
- `ker(Y|V_K) = 0`。

★★★ 这就是 r397 A8「`J` 档留 1、`K` 档留 0」的**推导**：不是「解 12 个生成元的 384×32 得 2」，而是「`su(2)_J` 先把空间切成 `V_J ⊕ V_K`，再看 `Y` 的零模落在哪一半」。

★ 机制一句话：**零模落在哪一半，哪一半就留一个单态。**

★★ 这一条同时解释了 r397 K1 表里 `su(2)_J + Y` 给 2、`su(2)_K + Y` 给 0 —— 不是 `Y` 变了，是**被问的那一半变了**。

★ 守卫 G12 用两条**不同源**的路径复核这个 2：一路把 4 个生成元叠成 128 行直接解（得 2），另一路先算 `V_J` 再把 `Y` 限制上去（得 2）。

|---|---|---|
| `−1` | **2** | 0 |
| `+1` | 0 | 0 |
| `−2/3` | 0 | 0 |
| `+2/3` | **6** | 0 |
| `−1/3` | **6** | 0 |
| `+1/3` | 0 | 0 |
| `−1/2` | 0 | 0 |
| `+1/2` | 0 | **4** |
| `−1/6` | 0 | **12** |
| `+1/6` | 0 | 0 |
| `0` | **2** | 0 |
| **合计** | **16** | **16** |

读法：

- `V_J` 收 `{−1, 2/3, −1/3, 0}`：**4 个值、16 维实 = 复 8**；
- `V_K` 收 `{+1/2, −1/6}`：**2 个值、16 维实 = 复 8**；
- 两值集**互不相交**，合起来正好铺满全谱 ⇒ `16` 的 `y` 谱是 `{−1×1, −1/6×6, 2/3×3, −1/3×3, 1/2×2, 0×1}`（复，合计 16）。

★ **符号是算出来的**：候选集把 `±1、±2/3、±1/3、±1/2、±1/6、0` 全放进去，结果 `V_J` 侧非零 4 行、`V_K` 侧非零 2 行 —— 不是我先定好符号再去验。

★★ **两条幂和都与 r397 互印**：

| 量 | `V_J` 侧 | `V_K` 侧 | 和 | r397 的对应量 |
|---|---|---|---|---|
| `s₁ = Σy²` | `8/3` | `2/3` | **`10/3`** | `p₁ = 10/3` |
| `s₂ = Σy⁴` | `44/27` | `7/54` | **`95/54`** | `p₂ = 95/54` |
| `tr((iY)²)` | — | — | **`20/3`** | `= 2·p₁` |

路径完全不同：r397 是在 32 维上直接算 `Y^{2k}` 的迹；本卷是**用两个 16×16 子矩阵的迹**分别算再相加；第三条是 `tr((iY)²)` 在 32 维上直接算 ⇒ **三路一致**。★ 这一条只在 `V_J`、`V_K` 都是 `H = i·Y` 的不变子空间时才成立，故它同时**回验**了 A2 / A3 的不变性。

★★ **反面也报**：两半各自的 `s₁`（`8/3` 与 `2/3`）**都不等于** `p₁` 或 `p₂`（判据里的 `not _s1_hit`，实测 True）。也就是说 —— 全谱矩里**没有**「哪一半出多少」的信息，这与 r397「`p_k` 四格全同」的边界**一致**：分辨 `J`/`K` 靠的是**零模落点**（A6）与**值集分块**（本条），**不是**谱矩。

## 九、`16` 与 `16bar` 不等价（A8）

工具先说清：`Y` 在实化空间的本征值是 `±i·y`，所以 `ker(Y − 1)` **恒为 0**（本卷 E02 号自伤）。要问「`y` 等于多少」必须用 `i·Y`（实对称、本征值恰是 `y`）。

| 块 | `ker(iY − 1)` | `ker(iY + 1)` |
|---|---|---|
| `16` | **0** | **2** |
| `16bar` | **2** | **0** |

⇒ `16` 的 `y` 谱含 `−1×1` 而**不含** `+1`；`16bar` 反过来 ⇒ **`16bar` 的 `y` 谱是 `16` 的逐项取反**。

★★ 这与 r397 清单 `{1/6×6, −2/3×3, 1×1, 1/3×3, −1/2×2, 0}` **整体反号**：r397 只用偶次幂 `p_k`，对符号完全不敏感（其诚实边界第 4 条已声明「只定 `abs(y)` 不定符号」）。本卷把符号定下来了 —— `16` 在本卷口径下是 `{−1/6×6, 2/3×3, −1×1, −1/3×3, 1/2×2, 0}`。

★★★ **不等价**：等价表示必须有相同的本征值重数；这里 `y = +1` 的重数在两边是 **0 与 1**（复）⇒ 不等价。

★★★ **但归属必须说清**：这条不等价**不是** `J`/`K` 可分辨的原因。r397 的四格里 `J` 在两块都得 2、`K` 在两块都得 0，说明分辨与否只取决于 `J`/`K`；真正的原因是 A6「零模落在 `V_J` 而不在 `V_K`」。**把「不等价」当成「可分的原因」正是 r397 E09 的错法**，本卷把这两句话拆开、各归各位。

## 十、判别力：换一个 `so(4)`（A9）

如果「8 + 8」是任何 `so(4)` 都成立的恒等式，A4 就毫无信息。于是把 `so(4)` 换到 **1..4 号指标**（`SU2J2_C` / `SU2K2_C`）再算一遍：

| 量 | 值 |
|---|---|
| `dim V_J'` | 16 |
| `dim V_K'` | 16 |
| `dim(V_J ∩ V_J')` | **8**（< 16 ⇒ 是两个不同的子空间） |
| `ν^c ∈ V_J` / `∈ V_K` | True / **False** |
| `ν^c ∈ V_J'` / `∈ V_K'` | **False** / True |

⇒ 「8 + 8」只依赖「`16` 是 `so(6)` 的旋量与 `so(4)` 的自旋的乘积」这一结构；但 **「`ν^c ∈ V_J`」是这一组特定嵌入的性质**，换一组就整个换边。这也是 r397 §十四 第 2 条边界的精确形态：可分辨依赖**这一组** `J`/`K` 的选择。

## 十一、控制组（4 条）

| 条目 | 设计 | 读数 |

| K1 | 退化档：一个约束都不加 | 秩 0 ⇒ 零空间 **32**（全空间） |

## 十四、诚实边界（五条）

1. 本卷只做**子空间结构与零模归属**：不含质量谱 / Yukawa / 混合角；
2. 「8 + 8 直和」是对**这一组** `so(4)`（作用在 7..10 号指标）证明的，不是对任意 `so(4)`；A9 已给出反例方向 —— 换到 1..4 号指标后 `dim(V_J ∩ V_J') = 8`（≠ 16，两子空间不同）、`ν^c ∈ V_J' = False`、`∈ V_K' = True`（归属整个换边）；
3. A6 只给出 `ker(Y|V_J) = 2`、`ker(Y|V_K) = 0` 这两个读数，**不解释**「为什么 `ν^c` 落在 `V_J`」—— 后者的成因（`ν^c` 的 `su(2)_J` 归属）属分解表层面，本卷未从第一原理导出；
4. A8 只证明「`16` 与 `16bar` 不等价」这一件事（`ker(iY−1) = 0 vs 2`），**不**主张它是 `J`/`K` 可分辨的原因（见 A6）；
5. 本卷不构造显式的 `16 → 16bar` 共轭算子；A8 用的是「本征空间维数不同」这条**否定性**证据。
