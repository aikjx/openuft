## 二、T1｜M5 尺度简并定理（精确有理）

对偶镜像条件 `g^eff(r) = g^eff(ℓ²/r)` 的解析族取 S13 验证 E 同型式：

```
g_ℓ(r) = 1 − r_s·r/(r² + ℓ²)
```

展开 `g_ℓ(ℓ²/r)` 后分母为 `ℓ²(ℓ²+r²)/r²`，分子 `r_s ℓ²/r`，商恰为 `r_s r/(ℓ²+r²)`，与 `g_ℓ(r)` 逐项相同 ⇒ **对任意 ℓ 恒成立**。

| ℓ | r | 自对偶残差（Fraction） | 通过 |
|---|---|---|---|
| 1/7 | 4/11 | 0 | True |
| 2/7 | 7/11 | 0 | True |
| 3/7 | 10/11 | 0 | True |
| 4/7 | 13/11 | 0 | True |
| 5/7 | 16/11 | 0 | True |
| 6/7 | 19/11 | 0 | True |

固定 `r₀=5/3`、令 ℓ=1/7…6/7，6 个形状值互异：

`499/1234, 526/1261, 571/1306, 634/1369, 143/290, 814/1549`

- 结论：条件固定**形状**、不固定 ℓ；族只有一个连续参数（ℓ）⇒ 对 ℓ 的**信息量 = 0 bit**，归一化秩 0。
- 边界：这只说明「M5 不能设定 ℓ」，**不**说明几何无意义（红线第 2 条）。

## 四、T3｜R2 维度嬗变：符号更正与 RG 不变式

r194 使用 `S = μ·exp(−2πA/b)`。对该式求导可得 `dlnS/dlnμ = 2`（随参考系平方漂移），**不是 RG 不变尺度**。本卷改用单圈 RG 不变式：

```
S(μ) = μ · exp(2π A(μ)/b),   A(μ) = A(μ₀) − b·ln(μ/μ₀)/(2π)
```

则 `S(μ₀)` 与 `S(v)` 在 6/6 扇区一致，最大相对残差 **5.6e-58**（Decimal(60)）。含义按 b 的符号：

- `b < 0`（渐近自由）⇒ S = **Λ_AF**；
- `b > 0` ⇒ S = **Landau 极点**。

| β 集 | 扇区 | b | α(v) | 类型 | S (GeV) |
|---|---|---|---|---|---|
| SM | 1 | 4.1000 | 0.01714 | Landau-pole | 1.6972e+41 |
| SM | 2 | −3.1667 | 0.03323 | AF-Lambda | 2.9739e−24 |
| SM | 3 | −7.0000 | 0.10386 | AF-Lambda | 4.5036e−2（≈45 MeV） |
| MSSM | 1 | 6.6000 | 0.01726 | Landau-pole | 2.2636e+26 |
| MSSM | 2 | 1.0000 | 0.03400 | Landau-pole | 4.6509e+82 |
| MSSM | 3 | −3.0000 | 0.11144 | AF-Lambda | 1.7582e−6 |

- 与 M*/v 靶（M*=3675.24 GeV）最近 ln 间隙：**11.31**；
- 与 M_GUT 靶最近 ln 间隙：**23.09**（最近者是 MSSM SU(2) 的 Landau 极点 ≈2.3e26 GeV）；
- **0 命中**：r194 的 5.98/13.26 是符号约定错误（旧值/新值比在 QCD 扇区 ≈3.21e7）。
- 结论方向不变且更强：更正后间隙变大，1e-9 命中的不可能性更加明确。

## 六、T5｜希格斯谱：比值固定、尺度不固定

`m_H² = 8κv²` ⇒ `m_H/v = 2√(2κ)`；`κ = κ̃` 是**自由无量纲**（equations.md §四）。取 200 个 κ 值（0.01…2.00）得到 **200 个互异** `m_H/v` 比值。⇒ 固定的是比值，尺度仍由 v 输入（与 C4′ 前的秩保持一致）。

## 七、T6｜秩不变性定理与规格强化 C4′

| 操作 | 输入 → 输出 | 尺度秩变化 |
|---|---|---|
| RG 流 | (μ, 纯数 A,b) → 同一 μ 乘纯数 | 0（保持 1） |
| 拓扑/整数 | 拓扑类 → 整数 | 0（尺度盲） |
| M5 对偶镜像 | 形状条件 → 一参数族 | 0（对 ℓ 0 bit） |
| 希格斯谱 | v → v×纯数 | 0（比值） |

**定理（当前清单）**：上述操作都把「一个尺度 + 纯数」映到「同一尺度 × 纯数」⇒ 尺度空间秩恒为 **1**，不能自发生成第二个独立尺度。

**规格强化**：原 C4「新增连续参数 ≤1」过弱（任何自由 κ 都能满足）。改为 **C4′：新增连续参数必须由离散/拓扑条件固定，不得由数据反标定**。于是

- C1（显式破共形）+ C2（只用框架自有内容）+ C4′（新参数须离散固定）
- 与**当前清单联合不可满足**（no-go 的结构性表述）。
