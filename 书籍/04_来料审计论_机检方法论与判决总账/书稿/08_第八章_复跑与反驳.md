# 第八章　如何复跑，以及如何反驳本书

一本书如果不能被复跑和被反驳，它就只是排版好看的声明。本章给出两条：可复跑的路径，和每类判决的**反例形状**。

## 8.1　复跑：三台仪器，三种代价

工作目录：本库根 `D:/a10/aikjx/code/my_lib`。Python 一律 `python -X utf8 <脚本>`，输出重定向到文件后再读，**不要** `| tee`（会吞退出码），**不要** `python -X "脚本"`（会起 REPL 并安静返回 0）。

**T1 语料普查（只读，秒级，本书聚合数的唯一来源）**

```bash
cd openuft/书籍/04_来料审计论_机检方法论与判决总账/精算
python -X utf8 audit_corpus_census.py > _census_report.txt 2>&1; echo "RC=$?"
```

期望：`RC=0`、`对照 10/10 绿`、末行 `CENSUS-GREEN`。语义：

- 对照不全绿 ⇒ 脚本 `return 2` 并**什么都不印**（此时不得引用任何聚合数）；
- 被审路径缺失 ⇒ 同样 `return 2`（不印 0、不印空表）。
- 复核其只读性：跑 `git status`，除本目录两个产物外不应有任何被审册变动。

**T2 卷级收口尺（只读，r351 样例）**

```bash

python -X utf8 -c "print(open('源码/_out_r351_closing.txt',encoding='utf-8').read()[-400:])"
```

期望 `RC=0`，见证件末行 `CLOSING-CHECK-GREEN…`。该件已归档为 `源码/_out_r351_closing.txt`（只新增、不覆盖；内含落盘前后两行同值的字节自证）。

**T3 卷引擎（写盘，勿在有并发写入者时跑）**

```bash
python -X utf8 "源码/TUFT-r351_ROOTV27…_精算与可视化_2026-11-02.py" > 源码/_out_r351.txt 2>&1; echo "RC=$?"
```

期望 `RC=0`、`SELF-CHECK 12/12 闸门 PASS`、五产物 md5 幂等（重跑不改字节）。⚠️ 这台仪器**会写盘**，且会重写 stdout 载体；本书正文引用的 `_out_r351.txt` 是它的一次历史输出，重跑前请确认工作树状态与并发情况。本库另有门禁 `scratch/_verify_all.py`（J 线时点读数 69/69 PASS，载体 `95_…J72….md` §六——**只作当下观察**，号段与断言数会随并发落地移动）。

## 8.2　复跑时的三条安全纪律

1. **不要在共享工作树上做破坏性清理。** 本库有并发提交者；字节数、面数、号段「最新值」都在移动。本书凡引用他卷读数都点名载体并标「现扫／只作当下观察」。
2. **文档编辑一律二进制读写、保持行尾。** README 是纯 LF，判定册与 `_out` 是 CRLF；文本模式改写会把整册变成 CRLF，而行级判据仍可能「通过」。
3. **任何计数不许手打。** 需要计数时，让**产生它的那台仪器印出来**，正文只引用文件名。本书正文的聚合数一个也不在文字里推导，全部来自 T1。

## 8.4　如何反驳本书本身

1. **反驳聚合数**：跑 T1，指出 `_census_report.txt` 里任一行与你现扫不一致处（注意先确认没有并发落地）。
2. **反驳覆盖面表述**：本书说「28/139 可解析」。若你能加出一把尺把第 29 份面解析出来，必须**同批交付一对变异体**（改一个数⇒读数变），否则新尺不合法。
3. **反驳判决**：按 §8.3 造反例，反例要在**原卷引擎**上跑，不能只在散文里描述。
4. **不许的反驳方式**：引用本书正文里的数字去否定该数字的载体。数字住在载体里，本书只是转述；若载体移动了，以载体为准。
