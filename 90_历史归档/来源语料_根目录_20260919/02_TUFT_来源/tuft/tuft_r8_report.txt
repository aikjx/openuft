============================================================================
  1. 求导证明（sympy 符号求导）
============================================================================
  (a) 由 ds = c·dt 与 dτ = ds/c：d/dτ = c·(d/ds)
  [PASS] 1a: 算子变换 d/dτ = c·d/ds  |  dτ=ds/c ⇒ d/dτ = c·d/ds；又 ds=c·dt ⇒ dτ=dt（模型内无 SR 膨胀，已标 O-SR）
      Frenet 第一式 dT/ds = κN ⟹ dT/dτ = c·κN ✓（曲率正比、指向主法向）
  [PASS] 1b: dT/dτ = cκN  |  由 dT/ds=κN 与 d/dτ=c·d/ds 直接推出 ✓
  (b) β₁ = exp(2GM/(c²r))，g = (c²/2)·d(lnβ₁)/dr 的符号求导：
      d(lnβ₁)/dr = -2*G*M/(c**2*r**2)
      g = -G*M/r**2
  [PASS] 1c: g(β₁) = −GM/r²（牛顿吸引）  |  符号求导给出 g = −GM/r²，负号=吸引 ✓；该符号由牛顿极限唯一固定，不可翻转

  (c) 逐阶展开（ε ≡ GM/(c²r)）：
      TUFT(修正) 1/√β₁ = exp(−ε) = -epsilon**3/6 + epsilon**2/2 - epsilon + 1
      GR          √(1−2ε)          = -epsilon**3/2 - epsilon**2/2 - epsilon + 1
      差 (TUFT − GR)               = epsilon**3/3 + epsilon**2
  [PASS] 1d: 1 阶是否一致?  |  1 阶系数均为 −1 ⟹ 一阶完全一致 ⇒ 与 Pound–Rebka/GPS/光钟相容 ✓
  [FAIL] 1e: 2 阶是否一致?  |  2 阶差 = 1·ε²（TUFT 为 +ε²/2，GR 为 −ε²/2）⟹ **存在可检验的特征偏差**

============================================================================
  2. 归一化（无量纲化）
============================================================================
  以无量纲紧致度 ε ≡ GM/(c²r)（= ξ·(a/r)，致密系数 ξ=GM/(c²a)）为唯一变量：
      β₁ = exp(2ε)                     （无量纲 ✔）
      √β₁ = exp(ε)，1/√β₁ = exp(−ε)   （无量纲 ✔）
      GR 对照 = √(1−2ε)                （无量纲 ✔）
      m/m₀ = √β₁ = exp(ε)              （质量比，无量纲 ✔）
  ⟹ 全部物理量化为 ε 的函数；量纲常数（c,ℏ,G）只出现在 ε 的定义中（method_F 判据一）
  [INFO] 2  |  归一化后 TUFT 与 GR 的差异**仅是 ε 的解析函数不同**：exp(−ε) vs √(1−2ε)
