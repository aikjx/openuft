## §二 X-R384-1：下凸包定理

### 2.1 陈述

设 `E(n) = a n² + b n + φ(n)`，`a > 0`，`b ∈ ℝ` 加在 **N 的一次项**上。记 `E₀(n) = a n² + φ(n)`，`P = {(n, E₀(n))} ⊂ ℝ²`。则

> **定理.**　`k` 是某个 `b` 的 argmin ⟺ `(k, E₀(k))` 是 `P` 的**下凸包顶点**。
>
> 且此时的窗口为 `b ∈ [−s_right, −s_left]`，其中 `s_left / s_right` 是 `k` 在下凸包上的**左/右相邻边斜率**；宽度 `W = s_right − s_left`。

### 2.2 为什么「近邻」不够

把 `b` 想成「在 `E₀` 上叠加一条斜率为 `−b` 的直线、取最下方的点」。
这是**支撑函数**的语言：`k` 可达 ⟺ 存在斜率 `−b` 使 `k` 是切点 ⟺ `k` 是凸包顶点。
只看 `k±1` 的差分（r384 的 Laplacian 通式）等于**假设** `k±1` 就是凸包上的邻居——
这只在局部凸（`Δ²E > 0` 且邻域内无更远点压线）时成立。反例见 §二.4。

### 2.3 三路对拍（A1/A2）

三条**互不共用代码**的算法给同一集合：① 单调链求下凸包；② 半直线之交（对每个 `m` 解 `E(m) ≥ E(k)` 得 `b` 的半直线，取交）；③ 在窗口内点 `(lo+hi)/2` 反算 `argmin`。

| 配置 | 凸包顶点数 | min-max 非空数 | 内点反演失败 | 相同 | 端点最大差 |
|---|---|---|---|---|---|
| φ = 0（a=1） | 23 | 23 | 0 | ✓ | 0.00e+00 |
| c/N（a=1, c=3） | 23 | 23 | 0 | ✓ | 6.00e-48 |
| cos（a=0.1） | 10 | 10 | 0 | ✓ | 2.00e-49 |

★端点差在 `Decimal(prec=50)` 下只有 1e-48 量级 ⇒ 三种定义**精确相等**，不是数值巧合。

### 2.4 `Δ²E(k) > 0` 只是必要条件（A3/C1）

cos 配置（`a = 0.1`）里，`k ∈ [2, 24]` 的 23 个候选中只有 **10 个可达**：
`{2, 3, 4, 9, 10, 15, 16, 21, 22, 23}`；其余 **13 个**窗口为空。

其中 **4 个**满足 `Δ²E(k) > 0` 却仍然不可达：**k = 8, 11, 14, 17**。

| k | 真宽度 W(k) | `Δ²E(k) ≡ 2a + Δ²φ(k)`（r384 通式） | 判定 |
|---|---|---|---|
| 2 | 0.5826 | 0.5826 | **相等**（k±1 都是顶点） |
| 4 | **0.2122** | **0.8010** | 通式高估 **3.8 倍** |
| 8 | **空** | 0.3338 | 通式给正数，实际不可达 |
| 11 | **空** | 0.1959 | 同上 |
| 14 | **空** | 0.0743 | 同上 |
| 17 | **空** | 0.4530 | 同上 |

★注意 **`2a + Δ²φ ≡ Δ²E`**：因为 `Δ²(a n²) = 2a` 恰好抵消，两者是**同一个数**，
不是两个不同的量。本卷首版把橙线写成 `2a + Δ²E`，等于把 `2a` 加了两遍
（图 2 整体抬高 0.2、k=4 处把「高估 3.8 倍」误报成「高估 4.7 倍」，见 §六 第 11 项）。

★误判**方向单一**：`Δ²>0` 是必要条件 ⇒ 用错了只会「以为能选到」，**不会**「以为选不到」。
可数：cos 配置上恰好 4 个（C1）。

### 2.5 凸情形回归（A4）

`c/N` 族 `k = 2..12`、`c ∈ {3, 1/2}` 共 **22 组**，凸包斜率差与 r384 的
`W = 2a + φ(k−1) + φ(k+1) − 2φ(k)` **恒等**，最大差 `9.00e-49`。

⇒ r384 的通式是凸包定理的**特例**（此时 `k±1` 恰是相邻顶点）。两卷不冲突：
r386 是把 r384 通式**缺的前提**补上，不是推翻它。**两卷条目不可相加**（P2）。

## §三 X-R384-2：残余分解

设 `S(M) = Σ_{|n₁|,|n₂| ≤ M} (r² + n₁² + n₂²)^{-3/2}`，`R_M = S(M)·r − 2π`。记

```
I_box(M) = ∫∫_{|x|,|y|≤M} (r²+x²+y²)^{-3/2} dx dy
Tail_box(M) = 2π/r − I_box(M)          （方形截断缺掉的尾）
D_M = S(M) − I_box(M)                   （格点离散项）
```

**B1 必须先降级**：`R_M + r·Tail_box ≡ r·D_M` 是把 `D_M` 定义成 `S − I_box` 的
直接展开，**定义级重言式，零信息**。按本库纪律「定义使然的相符不得记 PASS」，B1 记 **INFO**。

有信息的是下面两条：

| M | R_M | −r·Tail_box | 尾解释掉 | 残差 r·D_M |
|---|---|---|---|---|
| 20 | −4.1312235052 | −4.1887902048 | 98.61% | +5.757e-02 |
| 40 | −2.5474733441 | −2.5740044352 | 98.96% | +2.653e-02 |
| 80 | −1.3706401200 | −1.3788047192 | 99.40% | +8.165e-03 |
| 160 | −0.7003856911 | −0.7025490903 | 99.69% | +2.163e-03 |
| 320 | −0.3524301487 | −0.3529793913 | **99.84%** | +5.492e-04 |

**B2**：几何尾解释掉 99.84%（M=320），剩下的 0.16% 才是格点离散项。

**B3**：`D_M` 按 **1/M²** 衰减，实测 `D_M/D_2M = 2.170 → 3.250 → 3.774 → 3.939 → 4`。
量级论证：边界长 ~`M`、被积函数 ~`M⁻³` ⇒ 首项 `M⁻²`，与 Euler–Maclaurin 一致。
★必须与「`R_M` 本身按 1/M 衰减」并列报（G08）——把格点项的 1/M² 误记成残余的 1/M 是常见混淆。

**C2（判别力）**：把 box 尾换成 disk 尾，残差从 `5.492e-04` 涨到 `3.950e-02`（涨 72 倍）。
⇒ 「解释掉 99.84%」不是随便一条尾巴都能做到的，**尾形状必须与求和形状一致**。

## §四 自否证：外推未收敛（B4/B5/B6）

### 4.1 本卷原本想做的事

r384 在 `1/M` 外推上看到 `c0` **变号**（−4.475e-03 → +4.078e-03），据此把长距残余降级为
「截断主导」。本卷原拟**撤回**这个降级，理由是「尾只含奇次幂 ⇒ 没有 1/M² 项 ⇒ 变号是外推模型错」。

### 4.2 自己的数据否掉了这个理由

同一组 `R_M`（M = 20..320），换三种幂次基外推：

| 基 | 参数个数 | c0 |
|---|---|---|
| 仅 1/M | 1 | **−3.524e-01** |
| 1/M + 1/M² | 2 | **−4.475e-03** |
| 1/M + 1/M³ | 2 | **−3.027e-01** |

三者散布 **3.480e-01**（判据 1e-3）。★自由度须对齐：`仅 1/M` 只有 1 个参数，
它的 `c0` 就是最外点 `R_320`，**并未外推**；只比两个**双参数**基，散布仍有 **2.982e-01**，结论不变。

三点精确插值（M = 80, 160, 320，3 点定 3 参，仅作量级诊断）给：

```
c0 = +4.0776e-03    c1 = -1.1545e+02    c2 = +4.3787e+02    |c2|/|c1| = 3.79
```

**1/M² 项并不小**（比 1/M 项还大 3.8 倍，只是两个大项在 M ≥ 20 处近似抵消）。
所以「尾无 1/M² 项」这个前提**在数值上不成立**，由它得到的「变号是模型错」也就不成立。

### 4.3 hold-out 佐证「能外推一格 ≠ 已收敛」

用 M = 40..160 拟合 `1/M + 1/M³` 模型，**先预测** M=640，再实算（新增 1.6M 个格点）：

```
预测 R_640 = -1.8107e-01      实测 R_640 = -1.7657e-01      相对误差 2.55e-02
```

2.55e-02 远大于 B4 的判据 1e-3 ⇒ 模型「能外推一格」并不等于「极限已定」。
B5 记 PASS 是在说「这次外推的**预测**准到 2.6%」，不是在说「c0 收敛」——两者别混。

### 4.4 记档（B6）

**r384 的「截断主导」保持，撤回申请被自己的数据否掉。** 保留这条的价值在于：
若当时直接写「已撤回」，就会把一条 **1e-1 量级**的不确定性当成已解决。
这是本卷唯一一条真判负，也是本卷最该被记住的一条。

## §八 诚实边界

1. 下凸包定理只对「`b` 是加在 `N` 上的一次项」成立；参数加在 `N²` 或 `φ` 上时凸包对象要改（X-R386-3）。
2. B 组把尾当**连续积分**算，未含 Euler–Maclaurin 的边界修正解析式；`D_M` 的 `1/M²` 是数值观察 + 量级论证（X-R386-1）。
3. 只在单参数族上验证（`a = 1` 或 `0.1`），`a` 与 `φ` 的比值跨 3 个量级，但**未做随机 φ 大样本**（X-R386-4）。
4. 本卷**未能**撤回 r384 的降级：三种基的极限散布 `3.480e-01` 远大于判据，本组 M 上定不出 M→∞ 的残余。
5. 本卷是**方法 + 数值**卷：不产生新物理，供给 **0**、不占度、独有预言 **0**。
