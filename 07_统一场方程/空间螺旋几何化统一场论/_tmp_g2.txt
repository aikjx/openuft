引擎算出的非零 Gamma（Schwarzschild）：
   Gam(1, 1, 1) = MM/(r*(-2*MM + r))  <== 与解析式不符, 解析=MM/(r**2*(-2*MM + r))
   Gam(1, 2, 2) = r**2/(2*MM - r)  <== 与解析式不符, 解析=-r/(-2*MM + r)
   Gam(1, 3, 3) = r**2*sin(th)**2/(2*MM - r)  <== 与解析式不符, 解析=-r*sin(th)**2/(-2*MM + r)
   Gam(2, 1, 2) = 1/r  OK
   Gam(2, 2, 1) = 1/r  OK
   Gam(2, 3, 3) = -sin(2*th)/2
   Gam(3, 1, 3) = 1/r  OK
   Gam(3, 2, 3) = 1/tan(th)  OK
   Gam(3, 3, 1) = 1/r  OK
   Gam(3, 3, 2) = 1/tan(th)  OK
缺失: []
多余: [(2, 3, 3)]

Ric_rr 逐项（variant B）：
  T1 = d_c Gam^c_rr          = 2*MM*(MM - r)/(r**2*(2*MM - r)**2)
  T2 = d_r Gam^c_cr          = (-MM*r + MM*(2*MM - r) - 2*(2*MM - r)**2)/(r**2*(2*MM - r)**2)
  T3 = Gam^c_cL Gam^L_rr     = MM*(-3*MM + 2*r)/(r**2*(2*MM - r)**2)
  T4 = Gam^c_rL Gam^L_cr     = MM**2/(r**2*(2*MM - r)**2) + 2/r**2
  Ric_rr = T1-T2+T3-T4 = 2*MM/(r**2*(-2*MM + r))

显式黎曼 R^rho_{r rho r} 逐 rho：
   rho=0 -> 0
   rho=1 -> 0
   rho=2 -> MM/(r**2*(-2*MM + r))
   rho=3 -> MM/(r**2*(-2*MM + r))
