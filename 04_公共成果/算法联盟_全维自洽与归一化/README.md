## 四、关键判定（H/O/C/U 摘要）

- **C（已切除）**：量纲冲突 · 光子环换算 · 红移 8.6 量级 · 偏折误归因 · 强场因子 · 虚假两难 · **C-X7 圈系数路径 M3 证伪** · 自旋放大证伪。
- **U（需新公理）**：内部维数 N=3 起源 · 引力 UV 截断无关性 · 分形→复结构纲领（FRACTAL-GAUGE M1–M5）。
