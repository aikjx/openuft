## 问题定义

1976 年霍金：黑洞热辐射蒸发，辐射纯热（与物质无关），信息丢失——违反幺正性。核心矛盾：GR（视界禁逃逸）vs QM（纯态演化为纯态）vs 霍金辐射（混合态）。候选解：信息守恒、残余物、防火墙、全息原理、ER=EPR、岛公式。

## 分析进展（求导证明验证 + 精算分析）

脚本 `verify_black_hole_information_paradox.py` 复算 Page 曲线：

- **Page 时刻**：t_page/t_evap = (3−√5)/2 ≈ 0.382，与标准 Page 时间（约半数蒸发）一致（PASS）
- **端点**：S(0)=0、S(t_evap)=0，纠缠熵从 0 出发最终回到 0 → 幺正性不丢失（PASS）
- **峰值**：Page 熵 S_page < S0，信息部分保留于辐射/岛
