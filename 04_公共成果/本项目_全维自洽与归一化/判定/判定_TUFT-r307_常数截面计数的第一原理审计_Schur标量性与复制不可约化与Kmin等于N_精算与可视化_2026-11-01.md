## 一、判决主文

**三条并立的结论，每条都可单独检验。**

**（1）`k_R ≤ 1` 从公设降为「两条假设的定理」。**
扭转取中心元 `g ∈ Z(G)` 时，Schur 引理强制 `g|_R = ω_R(g)·1_R`；常数截面的扭折周期性要求 `ω_R = 1`，
于是 `k_R = [ω_R = 1] ∈ {0,1}`。链条「表示 → Dynkin 标号 → 中心荷 → 相位 → k」全程机械，
**给出 r302 手工编码 `k_of()` 表的推导**，6 个扭转元给出 4 个不同 k 向量，与 r302 **逐项一致（4/4）**。

**（2）r305 的 `K_min = 3t` 被修正为 `K_min(N) = N`。**
等谱族 `k = (N−t, N+2t, N−t, N+t, N−t)` 的最大分量是 `N+2t` ⇒ **`N ≤ K`**。
r305 的 `3t` 是 λ=0（即 `N = t`）这条切片上的关系，它把**通量量子 `t`** 当成了**代数 `N`**。
⇒ **三代需 `K ≥ 3`，不是 9**；最小构造 `k = (3,3,3,3,3)`、`t = 0`、`q = 0`、六条反常全零。
⇒ **no-go 的门槛比 r305 自述的低 3 倍**，这是**削弱**，必须如实登记。

**（3）`X-R305-1` 判负：`k_R ≤ 1` 不能由第一原理推出。**
它等价于「内部空间连通（`c = 1`）」。放开连通性 ⇒ 复制 ⇒ `K = c` ⇒ **`N_gen ≤ c = π_0(M_int)`**，
三代 ⟺ `c ≥ 3`。而 `c` 是**拓扑输入**，方程对它没有选择性（`c = 1..6` 全部自洽）。
⇒ **三代仍不被解释，但「3 从哪来」被压成一个可以正面攻的拓扑问题。**

★**一句话**：这一轮没有关掉任何门，但把门的**铰链**换了 —— 从「一个未证明的不等式」换成「一个拓扑数」。

## 二、为什么「Schur 标量性」值一整节

因为它是本轮唯一的**真推导**，其余都是重述或修正。

r302/r305 的 `k_of()` 是一张**手写表**：

```
T0=(1,1,1,1,1)、T3=(0,0,0,1,1)、T2=(0,1,1,0,1)、T32=(0,0,0,0,1)
```

这张表在 r302 里是「由中心荷机械算出」的**说法**，但代码里是硬编码的常量元组。本卷把它变成**推导**：

| 输入 | 机制 | 输出 |
|---|---|---|
| `(3,2)` vs `(3̄,1)` vs `(1,1)` | `zc3 = (p−q) mod 3` | `(1, 2, 2, 0, 0)` |
| 双态 vs 单态 | `zc2 = 2j mod 2` | `(1, 0, 0, 1, 0)` |
| 扭转元 `(a,b) ∈ Z₃×Z₂` | `m = (2a·zc3 + 3b·zc2) mod 6` | 相位指数 |
| `m = 0` ? | **Schur**：`ω` 是标量 | `k_R = 1` |

**三个独立校验**让这条链不是自说自话：

- **CTL6 / G12**：推导出的 4 个 k 向量与 r302 手写表**逐项相同** —— 历史编码与本卷推导互证。
- **CTL2**：把相位公式的系数换错（`3a + 2b` 而非 `2a + 3b`）⇒ 4 个 k 向量**崩掉** ⇒ 链条有牙、不是恒真。
- **CTL3**：把 `e_R^c` 的中心荷人为改成 `(1,1)` ⇒ k 表改变 ⇒ 对每个表示的荷**敏感**。

> **方法论上的意义**：一旦 `k_R ∈ {0,1}` 有了推导，「**三代 no-go**」这个结论就**不再依赖作者的手写表**。
> 这是把「公设」换成「定理 + 两条假设」的标准做法 —— 而两条假设（中心扭转、连通）都是**可以单独攻击**的。

## 三、定理 P：为什么这是自我纠正，而不是又一次「更强」

r305 的 F 组代码是：

```python
for t in range(0, 7):
    for K in range(0, 40):
        for lam in range(0, K + 1):      # ← λ 从 0 起扫
            k = kfam(F(t + lam), F(lam)) # ← N = t + λ
            if all(0 <= x <= K for x in k):
                ...
```

**λ 从 0 开始扫，所以最优解必然落在 λ = 0**，此时 `N = t + 0 = t`。
于是那张表读作「`t` 与最小 `K` 的关系」是对的，读作「**代数**与最小 `K` 的关系」就错了 —— 因为
**它只扫了 `N = t` 这一条对角线**。`N` 与 `t` 在对角线上相等，所以数字一个不差，标签却错了。

**本卷的复算把两者分开**：

| t | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| r305 的 K_min（= 3t） | 0 | 3 | 6 | 9 | 12 | 15 | 18 |
| 该行的 N（= t） | 0 | 1 | 2 | 3 | 4 | 5 | 6 |

| N | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|---|
| **修正后 K_min（= N）** | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
| 取到最小的 t | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 0 | 0 |

**为什么必须公开这一条**：修正方向是**削弱自己的判词** —— 门槛从「某表示要有 9 份常数截面」
降到「3 份」，而 `k_R ≤ 1` 与 `k_R ≤ 2` 都还挡得住三代，`k_R ≤ 3` 就挡不住了。
**一个只在对自己有利时才严格的判据是不可信的**；反过来，主动下调门槛是这类自审册唯一能积累信用的方式。

★另外，`N ≤ K` 这个结论本身**与符号无关**：即使允许 `k` 取负，`k₂ = N+2t ≤ K` 仍给出 `N ≤ K − 2t ≤ K`。
所以 r305 用 `{0,1}` 而不是 `{−1,0,1}` 也不是漏洞（定理 O）。

## 四、定理 Q：把「逃逸」精确分成三类，并杀掉最诱人的那一类

`k_R > 1` 是唯一能救三代的路。本卷问：**它到底能怎么来？**

**(a) 非中心扭转 —— 拿不到，且破 SM。**
按「固定子空间维数」的读法，`Q_L` 六权的相位重合在 20736 个环面元上取 {1,2,3,4,6}，**不是常数**。
恒等元给 6、一般元给 1 ⇒ 这个量**依赖连续模**，不能当固定偏移。
而这些 `g` 的中心化子是极大环面 ⇒ 残存 `U(1)²` ⇒ **SU(3) 完全破缺**。代价是 S1。

**(b) 非阿贝尔 flavor 表示 —— 想当然的逃逸，被证伪。**
「取 A_4 的三维不可约表示，`k_R` 就该是 3」是这条路上最自然的一步。**它是错的**：

A_4 的 3 维表示是「坐标和为零」子空间上的置换作用，固定维数 `= max(0, Fix(g) − 1)`；
三个阶 2 元是**双对换**，`Fix = 0`（不是 2！这点极易算错）⇒ 固定维数 0；
3-轮换 `Fix = 1` ⇒ 0；只有恒等元给 3。**全体共同固定的维数 = 0**。
⇒ **不可约表示给 `k = 0`，不给 `d`**。只有 `ρ = 1⊕1⊕1` 才给 3 —— 而那是**复制**。

> 这一条如果算错（把双对换当 `Fix=2`），就会得出「固定维数 = 1」，从而误判「A_4 能给 k=1」，
> 进而漏掉整条逃逸路线。**首跑正是在这里报错（见 §七）**，这也是本卷最值得记的一处。

**(c) 复制 —— 唯一来源，代价是把 3 变成拓扑输入。**
`c` 个连通分量、**各带独立扭转** ⇒ `k = Σ_j k^(j)`、`k^(j) ∈ {0,1}⁵` ⇒ 可达 `[0,c]⁵` ⇒ `K = c`。
代入定理 P：**`N_gen ≤ c`**，三代 ⟺ `c ≥ 3`，`c = 3` 用 `k = (3,3,3,3,3)` 实现。

**三条路都通向「3 是输入」**：非中心破 SM、非阿贝尔给 0、复制把 3 变成 `π_0`。
没有一个给出「为什么是 3」。

## 五、`X-R305-1` 判负意味着什么（以及不意味着什么）

**意味着**：r305 的 `k_R ≤ 1` **不是**从 `G_SM` 的表示论内部能推出的东西。它需要**两条外部假设**：
内部空间连通、扭转取中心元。把它当公设是**必要的**，不是作者偷懒。

**不意味着**：no-go 失效。恰恰相反 —— 现在挡三代的是一个**更明确的东西**：

```
N_gen ≤ π_0(M_int)
```

这是一个**不等式**，不是「某个机制失灵」。要推翻它，只需给出一个 `c ≥ 3` 的紧致化**并且说明 c 为何等于 3**。
后者才是真问题，而它是**拓扑/宇宙学输入**，不是群论问题。

★**这解释了为什么前面几轮一直卡住**：从 r292 到 r305，攻击面一直在「通量、反常、维数、扭转」上，
而真正的承重点在 `π_0`。**宣称缺失的那一层，往往正是可判决的那一层**（承本库通用刀）。

## 八、诚实边界（本卷不主张什么）

1. **不否证 r302/r305**。它们的判词（`k_R ≤ 1` ⇒ 至多一代）成立；本卷把它改写成「H1∧H2 下的定理」。
   两卷不可相加，强度取较新的一轮。
2. **修正 r305 的标签错误后，门槛下降**：三代需 `K ≥ 3`（不是 9）。这是**削弱**，不是加强，必须明写。
3. **`k_R ≤ 1` 仍不是第一原理**。本卷给的是「假设分解」，不是推导。真正的第一原理问题变成
   「为什么 `π_0(M_int) = 1`」，本卷**没有回答**它。
4. **`N ≤ c` 依赖「每个分量可带独立扭转」**。若强制各分量扭转相同，可达集合收缩为 `N ∈ {0,c}`。
5. **口径 (i)(ii) 的选择是承重的**。本卷沿用 (i)（轮廓数），并证明 (ii) 不是整数不变量；
   但**没有**从指标定理推出 `n_R` 的正确形式（`X-R307-1`）。
6. **「非中心扭转破 SM」只对一般环面元给了论证**（中心化子 = 极大环面 ⇒ 残存 `U(1)²`），
   没有穷尽所有非中心 `g`（例如含 Weyl 群部分的 `g`）—— 那类 `g` 不保持表示标签，属另一类问题（`X-R307-2`）。
7. **本卷没有给出任何新预言，也没有提出新的统一方案。它是一次减法** —— 但这次减法把「3 从哪来」
   从「某个未知机制」压成「`π_0(M_int) ≥ 3`」这样一个可以正面攻的拓扑问题。
