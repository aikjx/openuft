## 关键定量（首算，非沿用 v31 字面量）

- κ/τ 场紫外零点能（最优截断 k_max=1/(√2 ℓ_P)）：
  ρ_local = ℏc k_max⁴/(16π²) = c⁷/(64π² ℏ G²) ≈ 7.4×10^110 J/m³
- 观测真空能：ρ_Λ = Λc⁴/(8πG) ≈ 5.3×10^-10 J/m³
- 局域层/观测 gap = ρ_local/ρ_Λ ≈ **10^120.14**
- 观测/Planck 比：ρ_Λ/ρ_P ≈ **10^-105.99**（= (ℓ_P/L_Λ)²·(c²/8π)）

## 诚实口径澄清（重要）

v31 沿用的「10^118.55 / 10^-122.95」与 v32 首算的「10^120.14 / 10^-106」之差，
**非矛盾，是约定差**：
- 宇宙学常数问题的标准量级 10^120 指 (QFT零點能@Planck截断) / (观测ρ_Λ)——v32 首算 10^120.14 命中此量级；
- ρ_Λ/ρ_P = 10^-106 指 (观测) / (Planck密度)，是另一个比值；
- 两者仅差 κ/τ 场零點能相对 Planck 密度的系数 (ρ_local/ρ_P = c²/64π² ≈ 1.4×10^14)。
v29/v31 的「10^118.55」与 v32「10^120.14」差一个 √2 截断 prefactor，同属 order 10^120。

## 核心结论

1. **拓扑层归零是真实的、但不足以解释 Λ**（Q12/Q15）：v31 Q02 的拓扑层 H≡0 结构性移除了
   局域真空灾难，但「移除后剩什么」由 **Weyl 规范固定 / 宇宙初始边界条件** 决定，
   Λ 在框架内=1 个自由积分常数，不可从第一性推出。

2. **局域层 10^120 残差与观测 10^-106 之间无任何框架内抵消机制**（Q13/Q16）：
   - 体-边界精确抵消要求 fine-tuning 10^-120，框架无方程锁定该系数 → FAIL；
   - 非微扰指数 exp(-c/α) 无自然 c 命中 10^-122 → FAIL；
   - 即 Λ 的「非零小值」在框架内仍是外部边界输入，非几何派生。

3. **唯一诚实收口**：Λ = 边界/初始条件常数（与 v12/v15 世界线作用量、v9/v10 κ/τ 场的
   Weyl 不变表述同源）。框架解释「为何紫外不爆」（拓扑层），但不解释「为何残值恰为 10^-106」。
