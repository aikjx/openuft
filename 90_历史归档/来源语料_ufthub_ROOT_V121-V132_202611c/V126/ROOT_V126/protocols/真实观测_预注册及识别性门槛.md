# ROOT V126 / V127 真实观测预注册协议

## 已固定的待检验模型
- 线性单作用程、未屏蔽、普适 Yukawa；`ell=124600 m`、`alpha_Y=1/3`，不允许在确认性检验时事后改值。
- 外部源需要实际密度/非球形重力模型；共同校准偏置须先指定产品级假设。
- V126 球面法并非优先采用真实 GOCE 单轨数据的程序；必须先有**真正覆盖三维真空球面**的独立可追溯观测。

## 验收闸门
1. 获取原始可追溯的 GOCE 或其他梯度/轨道数据文件及产品说明，记录 SHA256、来源、UTC 时间范围、误差模型与使用许可。
2. 明确每个产品的 Laplace 零迹先验、滤波、外部标定、低频传递函数与坐标约定。若迹在目标频段不可辨识则中止这条实验路线，不制造置信度。
3. 检查三维覆盖：单颗卫星轨迹上的二维球面平均属于**模型插值重建**，不是直接观测。记录真实采样矩阵和先验。
4. 预先定义留出观测集合（至少四球面且模型/干扰参数自由度可校核），并明确独立噪声、相关误差和仪器偏置协方差。
5. 报告含系统误差下的似然或置信上界；只报数学拟合值、纯随机噪声 Monte Carlo 不算完成验证。
6. 不因候选失败就把预注册 `ell`、`alpha` 改成拟合自由度；探索性新候选必须重新登记，并换新的独立数据集检验。
7. 通过以上条件后，仍须在时钟、卫星轨道、光传播与实验室测量等独立通道检验同一组参数。

## 失效与停止条件
- 任何完整采样球穿过局域质量源、非真空大气或未建模的非线性屏蔽区；
- 几个球面的偏置不共同或高相关误差未计入；
- 仪器处理利用了被检验的真空 `T=0` 先验；
- 测量只覆盖一个轨道圆，无法无先验地估计完整球面平均；
- 梯度在目标频率不具备校准传递函数。
