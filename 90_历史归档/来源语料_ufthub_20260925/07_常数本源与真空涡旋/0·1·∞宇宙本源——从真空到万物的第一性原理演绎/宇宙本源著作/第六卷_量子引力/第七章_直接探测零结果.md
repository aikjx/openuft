# 第七章 暗物质直接探测零结果的解释
## 7.1 直接探测实验的零结果
几十年来，暗物质直接探测实验（LUX、XENON、PandaX等）都没有发现暗物质粒子和原子核碰撞的信号，得到的都是零结果，对WIMP的截面限制越来越强，几乎排除了所有热WIMP参数空间。

在我们的模型中，暗物质不是粒子，是高维挠率场，它只通过引力和普通物质相互作用，没有其他相互作用，所以暗物质和原子核的碰撞截面几乎为0，直接探测实验永远不会得到信号，这就是为什么所有直接探测实验都是零结果，不是因为实验不够灵敏，而是暗物质根本不是粒子，不会和原子核碰撞。

## 7.2 对撞机探测的零结果
LHC没有发现任何暗物质粒子，也没有发现任何超出标准模型的粒子，这也和我们的理论一致，因为暗物质不是粒子，不能在对撞机中产生，超对称粒子也不存在，所以LHC没有发现新物理是自然的。

## 7.3 间接探测
暗物质间接探测（比如暗物质湮灭产生伽马射线）也不会有信号，因为暗物质是场，不是粒子，不会湮灭，所以银河系中心的伽马射线超出不是暗物质湮灭，是其他天体物理过程。

## 7.4 第六卷总结
第六卷我们解释了暗物质和暗能量的本质：
1.  暗物质是高维紧致挠率场在4维的投影，是几何效应，不是粒子；
2.  暗物质自然解释星系旋转曲线、星系团、引力透镜、大尺度结构，解决小尺度问题；
3.  暗能量是真空拓扑零点能，分形结构自然得到小的宇宙学常数，解决120个数量级的问题；
4.  暗物质直接探测零结果是自然的，因为暗物质不是粒子，没有非引力相互作用；
5.  我们的模型和所有宇宙学观测一致，不需要新粒子，不需要修改引力。
