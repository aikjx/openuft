## 一、Dirac 量子化：求导证明 + 数值双路复核

磁单极（磁荷 `g`）的 Dirac 弦矢势（弦沿 `−z` 轴）：

```
A_φ(θ) = g·(1 − cos θ) / (r·sin θ)
```

沿固定 `θ` 的纬线求环量：

```
∮A·dl = ∫₀^{2π} A_φ · (r sin θ) dφ = 2πg(1 − cos θ)  →(θ→π)  4πg
```

**数值复核**（mpmath 40 位，误差 < 1e-25）：

| θ | ∮A·dl（数值） | 2πg(1−cosθ)（解析） | 误差 |
|---|---|---|---|
| 90° | 6.2831853072 | 6.2831853072 | 0 |
| 150° | 11.7245833999 | 11.7245833999 | 0 |
| 179° | 12.5654136548 | 12.5654136548 | 0 |
| →180° | — | 4πg = 12.5663706144 | — |

**独立路径复核**：球面积分磁通 `∮B·dS = 4πg = 12.5663706144`，与弦环量一致。

波函数绕 Dirac 弦一周的相位必须单值：

> **Dirac 量子化条件**　`e·4πg = 2πn` ⇒ **`eg = n/2`**（ℏ=c=1，Heaviside-Lorentz）

数值：`α = 1/137.036` ⇒ `e = √(4πα) = 0.30282` ⇒ 最小磁荷 `g_min = 1/(2e) = 1.6511`。

> **关键限定**：Dirac 条件给出的是**电荷离散性**（`Q ∈ Q_min·ℤ`），
> **不是**电荷的具体数值。这一点决定了 §2 的结果。

## 二、新公式：Dirac + 反常消除 ⇒ 整数电荷超荷离散族

沿用 R10 分支 A（`x = 3q`）的电荷谱，以 `e ≡ |Q(e_L)| = |1/2 + 3q/2|` 为单位。
Dirac 要求 `Q(u_L)/e ∈ ℤ` 且 `Q(u_R)/e ∈ ℤ`，联立解得：

> **公式（新）**　`q_p = p / (2 − 3p)`，`p ∈ ℤ`

| p | q_p | Q(u_L)/e | Q(u_R)/e | Q(d_R)/e | 说明 |
|---|---|---|---|---|---|
| −2 | −1/4 | 3 | −4 | 2 | |
| −1 | −1/5 | 2 | −2 | 1 | |
| 0 | 0 | 1 | 0 | 0 | 退化：u_R/d_R 不带电 |
| 1 | −1 | 0 | −2 | 1 | **整数电荷解（Han–Nambu 型）** |
| 2 | −1/2 | 1 | −4 | 2 | |
| 3 | −3/7 | 2 | −6 | 3 | |

代入 `[U(1)]³` 得 **0** ⇒ **全族自动满足反常消除**（分支 A 对任意 `q` 成立）。

### 诚实结论：Dirac 不能唯一锁定超荷

Dirac 只把 `q` 从**连续统**压成**可数离散族** `{p/(2−3p)}`，仍有无穷多个候选。

> **约束强度守恒律（本册方法论要点）**
>
> | 路径 | 本源性 | 结果 | 唯一性 |
> |---|---|---|---|
> | R10：U(1)_em 未破缺 | 唯象 | `q = 1/3` | **唯一** |
> | 本册：Dirac 整数电荷 | 第一性 | `q ∈ {p/(2−3p)}` | **离散但不唯一** |
>
> **本源性 ↑ 则唯一性 ↓。** 二者不可互相替代。

## 三、分数电荷：Dirac 族与真实世界互斥

SM 观测：`Q(u) = 2/3`、`Q(d) = −1/3`（分数电荷）。取 `q = 1/3` 检验：

```
Q(u_L)/e = 2/3,  Q(d_L)/e = −1/3,  Q(u_R)/e = 2/3,  Q(d_R)/e = −1/3,  Q(ν_L)/e = 0
```

全部精确命中（sympy 有理数），且**同一 `q` 值同时满足 R10 的 U(1)_em 未破缺条件** ⇒ 两条独立路径自洽。

但检验 `q = 1/3` 是否属于整数电荷族：

```
p/(2 − 3p) = 1/3  ⇒  3p = 2 − 3p  ⇒  p = 1/3 ∉ ℤ
```

> **诚实结论**：`q = 1/3` **不在** Dirac 离散族内。
> 观测的分数电荷夸克与「所有电荷为 e 的整数倍」**不能同时成立**。
> 夸克确为分数电荷 ⇒ 必须放弃整数电荷假设 ⇒ **Dirac 族对真实世界不适用**。

**这正是 R10 的唯象条件不可替代的原因**：更强的本源条件反而**排除**了真实世界所在的解。
超荷 `q = 1/3` 的最终依据仍是**观测**（分数电荷存在），不是纯理论推导。

## 五、证伪：耦合常数不能由 level k 编码

LCS-1 把 level `k` 与链环相位联系。若耦合常数也由 `k` 编码，则 `k` 应为**整数**。

观测输入（`M_Z` 标度，PDG）：`α₁ = 0.016943`、`α₂ = 0.033803`、`α₃ = 0.1180`。

| 候选关系 | α₁ | α₂ | α₃ | 联合（三耦合同时） |
|---|---|---|---|---|
| `α = 4π/k` | 2.4σ ? | **3.5σ ✗** | 0.6σ ? | **3.5σ ✗ 排除**（瓶颈 α₂） |
| `α = 1/k` | 1.9σ ? | 74.3σ ✗ | 7.8σ ✗ | 74.3σ ✗ 排除 |
| `α = 4π/k²` | 93.1σ ✗ | 159.6σ ✗ | 8.5σ ✗ | 159.6σ ✗ 排除 |
| `α = 1/(2πk)` | — | — | — | 312.3σ ✗ 排除 |

> 注：`α = 2π/k` 与 `α = 4π/k` 仅差 `k→2k` 重标度，属**同一候选**，未重复列出。

**诚实的细节**：最接近的候选 `α = 4π/k` 中，**单看 α₃ 仅 0.6σ，未被排除**（数值巧合）。
证伪由 α₂ 承担（3.5σ）。这一点必须写明，不能笼统宣称"全部排除"。

> **开放项 O-COUPLING（更决定性的是范畴论证，非数值拟合）**：
> level `k` 是**整数**，而耦合常数 `α_i(μ)` 是**随能标连续跑动**的量。
> 整数无法编码连续变化，除非 `k` 也随 `μ` 变——但那与 `k` 的拓扑量子化（整数、拓扑不变）直接冲突。
> **LCS 的 level 与规范耦合属不同范畴，不应强行等同。**

| 模型 | b 系数 | L₁₂ | L₂₃ | L₁₃ | ΔL | 结论 |
|---|---|---|---|---|---|---|

**SM**：三交点跨越 `e^9.147 = 9.38e3` 倍能标（~4 个数量级）⇒ **最小 SM 无大统一**。

**MSSM**（对照）：`M_GUT ≈ 2.29e16 GeV`，`α_GUT ≈ 1/24.3`，三者在 ΔL < 0.2 内汇聚
⇒ 大统一在 MSSM 成立，但**代价是引入超对称**（每个 SM 粒子配一个超伴子）。

> **诚实 FAIL**：TUFT 未提供任何使三耦合汇聚的机制——未引入超伴子、未给出额外轻态、未修正 β 函数。
> 在 TUFT 框架内 SM 三耦合**仍不汇聚**。「TUFT 实现大统一」目前**不成立**。
>
> 唯一诚实的可行路径：TUFT 若要大统一，必须给出新态或修正 β 函数的具体机制；
> 仅靠链环拓扑这类**整数**不变量，无法填补 `9.4e3` 倍的能标缺口。

## 八、本册对「实现物理大统一」的答复

### 可复算的新结果

1. Dirac 量子化的求导证明（环量 `4πg` ⇒ `eg = n/2`），数值与解析双路复核；
2. **【新公式】** Dirac + 反常消除 ⇒ 整数电荷超荷离散族 `q_p = p/(2−3p)`；
3. **【诚实】** 该族与观测分数电荷**互斥**（`p = 1/3 ∉ ℤ`）⇒ Dirac 路径对真实世界不适用；

### 对「大统一」的答复

**未实现，且本册证明它不能靠所检验的路径实现：**

- 拓扑整数（`Lk`、level `k`）无法编码连续跑动的耦合常数——**范畴冲突**，非数值问题；

- 质量谱、Λ、暗物质、暗能量、中微子、强 CP、暴胀、量子引力**全部开放**（§7）。
