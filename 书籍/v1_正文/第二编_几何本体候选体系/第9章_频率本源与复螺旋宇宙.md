# 第9章 频率本源与复螺旋宇宙（S10）

> **整合体系**：S10_频率本源与复螺旋宇宙（振动本体、作用量子、复曲率轨迹三项原理）。当前状态 `unreviewed`。
> **诚实分级**：部分统一（三原理已登记 + 原著闭环叙述）/ 未解（核心常数为定义式回代、外部预测未复现）。
> **关键事实**：与 S12 共用数学骨架但本体与 $c$ 的用法根本不同（$v\le c$ vs $v\equiv c$），互不认证；`claims.csv` 空；`03_数学形式/`、`04_理论推导/`、`12_研究结论/` 仅 README 空模板。

S10 与 S12 在字面上像双胞胎——都出现"螺旋"、都写 $\kappa^2+\tau^2=(\omega/c)^2$。但算法联盟的治理规则要求把它们切开：S12 说"空间本身以光速螺旋运动"，S10 说"宇宙的本源是频率/振动，螺旋只是振动显现的轨迹"。S10 对光速的用法是 $v\le c$（光速是**极限**），而 S12 是 $v\equiv c$（内部速度**恒等**于光速）。这一章审查 S10：它的三原理、常数关系、以及一组写得很漂亮但体系侧未登记的宇宙学预言。

## 9.1 三项原理

| 编号 | 名称 | 数学形式 | 状态 |
|---|---|---|---|
| S10-A1 | 存在原理（振动本体） | $v\le c$（$c$ 为**极限速度**） | 已登记，未审查 |
| S10-A2 | 量子原理 | 作用量以 $\hbar$ 为最小单元离散存在 | 已登记，未审查 |
| S10-A3 | 几何原理（复曲率） | $\Xi=\kappa+i\tau$ | 已登记，未审查 |

本体宣言（`postulates.md` §1）："宇宙是一条以光速振动的螺旋；频率 $\omega$ 定时间，曲率 $\kappa$ 定质量引力，挠率 $\tau$ 定电荷电磁。"依赖四个独立量纲常数 $c,\hbar,e,R$，其中 $R=\sqrt{\rho^2+b^2}$ 为螺旋特征长度。

与 S12 的切割（`postulates.md` §3，本表必须照录）：

| 维度 | S10 | S12 |
|---|---|---|
| 本源 | 振动/频率 $\omega$ | 空间本身的螺旋运动 |
| 螺旋地位 | 振动的**轨迹**（结果） | 空间运动的**形式**（前提） |
| 对 $c$ 的用法 | $v\le c$，光速是**上限** | $v\equiv c$，内部速度**恒等**于光速 |
| 曲率结构 | 复曲率 $\Xi=\kappa+i\tau$（含相位） | 模方恒等式 $\kappa^2+\tau^2=(\omega/c)^2$ |
| 动力学输入 | 第四部由 $\kappa\tau$ 直接定义 $G,\alpha,\varepsilon_0,\mu_0$ | 借用 S02 的 $F=dP/dt$ |

一句话判别：**S10 是"振动的螺旋"，S12 是"以光速运动的空间的螺旋"**。共同出现"螺旋"不构成合并依据，也不允许一方借用另一方的证据等级。

## 9.2 核心骨架与常数关系

### 9.2.1 复曲率与三重奏

A3 定义复曲率 $\Xi=\kappa+i\tau$，其模方

$$|\Xi|^2=\kappa^2+\tau^2=1/R^2$$

为对偶不变量。结合圆柱螺旋 $\boldsymbol r(\theta)=(\rho\cos\theta,\rho\sin\theta,b\theta)$ 的 Frenet 结果 $\kappa=\rho/(\rho^2+b^2)$、$\tau=b/(\rho^2+b^2)$，由 $\omega=c/R$ 得

$$\sqrt{\kappa^2+\tau^2}=\frac{1}{R}=\frac{\omega}{c} \tag{骨架}$$

**这与 S12 共用同一数学骨架**，但本体不同：S10 是 $v\le c$ 的振动极限，S12 是 $v\equiv c$ 的空间恒速。二者互不认证——同一个方程在不同本体下成立，不说明任一本体为真。

### 9.2.2 质量关系（定义式重排级别）

原著第十八章给出质量本源：

$$m=\frac{\hbar\sqrt{\kappa^2+\tau^2}}{c}=\frac{\hbar}{cR} \tag{m}$$

**推导**（原著自列 4 步）：① 螺旋角频率 $\omega=c/R$（几何）；② $E=\hbar\omega$（A2）；③ 定义质量使 $E=mc^2$；④ 联立 $mc^2=\hbar c/R\Rightarrow m=\hbar/(cR)$。

**诚实标注**：这 4 步中第③步是"定义质量使 $E=mc^2$"，第④步是代数联立。它本质是把 $E=mc^2=\hbar\omega$ 两条定义式联立、再用 $\omega=c/R$ 代入的**定义式重排**，不是从第一性原理独立导出质量。原著 V1 表把它与"普朗克质量定义"对照、误差 $<10^{-10}$，正说明它是定义恒等。

### 9.2.3 精细结构常数（形状参数回代）

$$\alpha=\frac{\tau}{\kappa}=\frac{b}{\rho}\approx\frac{1}{137.036} \tag{α}$$

**诚实标注**：$\tau/\kappa=b/\rho$ 是圆柱螺旋的几何形状比（螺距/回转半径），这一步是几何恒等。但把它**赋值**为 $\alpha\approx1/137.036$，是把 CODATA 测量值回代为 $b/\rho$ 的比值，而非从几何推出 $\alpha$。原著自己把 $\theta_0=\arctan\alpha\approx0.418^\circ$ 称为"宇宙螺旋的基本倾角"——这个角度是由测量 $\alpha$ 反算的。V2 表标"定义一致"。

### 9.2.4 引力常数（测量锚闭合）

$$G=\frac{c^3R^2}{\hbar}=\frac{c^3}{\hbar(\kappa^2+\tau^2)} \tag{G}$$

**诚实标注**：这是令 $R=l_P$（取最紧螺旋半径=普朗克长度）后闭合的测量锚。$R=l_P$ 本身由 $l_P=\sqrt{\hbar G/c^3}$ 定义，故 $G=c^3l_P^2/\hbar$ 是普朗克定义的逆运算——方向不可逆：要给 $R$ 赋 SI 数值仍须用 $G$ 定标。V3 表误差 $<10^{-5}$ 来自测量值回代。

## 9.3 复曲率 $\Xi=\kappa+i\tau$ 的数学结构

A3 的复数结构是 S10 区别于 S12 的关键：$\Xi=\kappa+i\tau$ 携带相位信息。原著主张弯曲定质量引力（实部 $\kappa$）、扭转定电荷电磁（虚部 $\tau$）。$|\Xi|^2=1/R^2$ 在 $\kappa\leftrightarrow\tau$ 对偶下不变。但 `postulates.md` §5 自承：去掉复数结构、只保留 $\kappa^2+\tau^2$，则"相位信息丢失，$\alpha=\tau/\kappa$ 的赋值失去依据"——这说明 $\alpha$ 的几何赋值是依赖于复数分解的，而该分解本身的物理对应（哪部分曲率=引力、哪部分=电磁）仍是名目指派，非群论导出。

## 9.6 诚实边界与待研究问题

1. **V1–V8"已验证"实为 CODATA 定义式回代。** 第五十四章表头写"100%通过"，但逐行看：V1 $m=\hbar/(cR)$ 是普朗克质量定义；V2 $\alpha=\tau/\kappa=b/\rho$ 标"定义一致"；V5 $\varepsilon_0=e^2/(4\pi\alpha\hbar c)$ 是 $\alpha$ 的定义式本身。这些"验证"用的是理论要解释的那些常数去回代理论式，误差自然接近零。`postulates.md` §2 末句自己承认："这些是定义式重排级别的对应，其数值吻合不等于 A1–A3 被独立证实。"
2. **原著 §0.2 自述曾犯三重旧错误。** 危机一：旧体系把圆柱螺旋的 $\kappa$ 与 $\tau$ **对调**（违背 Frenet 定理）；危机二：同时声称 $\alpha=\tau/\kappa$ 与 $\alpha=\kappa/\tau$，二者差 $1/\alpha^2\approx18769$ 倍，不可调和；危机三：核心关系 $\mu_0=4\pi\kappa^2$ 存在量纲灾难（$[\mu_0]$ 与 $[\kappa^2]$ 量纲不符，系循环定义）。本书按原著自承如实记录——这些是已订正的旧错误，但说明该体系曾在基本几何与量纲上出过错。
3. **宇宙学预言体系侧未登记。** `claims.csv` 空；`postulates.md` §6 自承"原著声称与 CODATA 2022、Planck 2018、DESI 2024 精确吻合，本仓库内无对应 run 与数据登记，未复现"。
4. **`03_数学形式/`、`04_理论推导/`、`12_研究结论/` 仅有 README 空模板。** 真正的推导全在 `13_论文与成果/论文正文/频率螺旋_原著.md` 一部 4400 余行的大书里，治理目录没有把它拆成可审查的数学形式与研究结论。
5. **自评标签不作证据。** 原著页眉"认证编号 ALG-UNION-GAQ-UFT-V∞-MASTER-2026""理论层级 第一性原理终极版""AI科技星最高权限"均为自评标签；`postulates.md` §6 明确规定 hypothesis_revision 只按年份登记为 `original-2026`，本书照此办理。

**待研究问题**：① 把 F1–F7 七条证伪判据正式登记进 `06_可检验预测/` 与 `claims.csv`，补上 run_id 占位，否则预言停留在"原著声称"；② 区分"定义式回代通过"与"前向新预言"——目前 V1–V8 全是前者；③ $m_{\mathrm{dm}}=57.7\,\mathrm{GeV}$ 的三条逃生口（附录 C）应收敛为一条明确的可观测判据，否则 F4 形同虚设；④ 解决"振动本体 $v\le c$"如何转写为可观测量，否则 A1 无失效阈值。

## 9.7 与 S12 的对照

S10 与 S12 共用 $\sqrt{\kappa^2+\tau^2}=\omega/c$ 这条骨架，却站在不同本体上：S10 是"振动的螺旋"（$v\le c$，$c$ 是极限），S12 是"以光速运动的空间的螺旋"（$v\equiv c$，$c$ 是恒等速度）。按 `postulates.md` §3 的切割，二者**不得互相认证**：S10 的 $\alpha=\tau/\kappa=b/\rho$ 与 S12 的 $\alpha=\tan\theta$ 表面相似，但 S12 另有一条 $\alpha^{-1}=2\pi/\theta$ 的矛盾闭式（见第8章 8.4.2），S10 不应、也不能因为"长得像"就继承 S12 的结论，反之亦然。S10 的复数结构 $\Xi=\kappa+i\tau$ 是它自己的特色，也是它比 S12 多出来的一点（携带相位），但该复数分解的物理对应仍未群论化。

## 9.8 本章小结

S10 以振动为本体、以复曲率 $\Xi=\kappa+i\tau$ 为几何语言，搭起了一条与 S12 同骨架但不同本体的螺旋体系。它的常数关系 $m=\hbar/(cR)$、$\alpha=\tau/\kappa=b/\rho$、$G=c^3R^2/\hbar$ 写得干净，但拆开后都是定义式联立或测量锚回代；它真正有特色的是写了一组具体的宇宙学预言（$H_0=67.84\pm0.05$、$m_{\mathrm{dm}}\approx57.7\,\mathrm{GeV}$、$z_{\mathrm{eq}}\approx3414$、$\Omega_k=0$、$\Delta c/c\sim10^{-20}$）和 F1–F7 证伪判据——这在第二编各体系里难得。但这些预言在体系治理目录里完全未登记、无 run 记录，$z_{\mathrm{eq}}$ 还是对齐 Planck 后的修正值，$m_{\mathrm{dm}}$ 又留了逃生口。S10 因此定位为：三原理已登记的部分统一体系，其宇宙学预言值得跟踪 Euclid/CMB-S4/DARWIN 的数据，但在体系侧补齐登记与复现之前，不能算作已验证。
