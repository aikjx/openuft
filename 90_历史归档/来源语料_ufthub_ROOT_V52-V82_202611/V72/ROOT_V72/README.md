# ROOT V72 · 新思想攻坚科研包

**交付内容：原创的组合研究思路 + 严格数学审计 + 可复算统计模拟 + 离线交互实验台。不是四力大统一证明。**

## 这次与 V71 有何不同

- **联络—曲率统一表达**：把引力自旋联络和三个内部规范场放入一个协变导数，在有限维 SO(3)×SU(2) 玩具模型中验证环路曲率、小环极限、共轭不变性，并证明“记号统一 ≠ 动力学统一”。
- **手性×旋转的双反转检验**：构造宇称允许的候选标量 χ(Ω·g)，从四态观测推导精确消偏组合、Fisher 信息与不可辨识反例；提供固定随机种子的**完全合成**数据。
- **明确的伪阳性**：四状态以固定次序读取时，二次时间漂移会生成相同信号。对照、盲测和随机化列为必要条件。
- **跨星体物理对照**：使用实测 G、近似质量和半径计算太阳、地球、月球、火星、木星的引力、潮汐、自转；**没有**从星体参数算出新的 G。
- **可审计目录**：55 条核心方程、25 条研究路线、51 项单元测试，以及一套 Python 实验代码与四张实际计算图。
- **完整中文研究专著**：`book/ROOT_V72_新思想统一场论攻坚与证伪专著.md`，约 2 万字符。

## 快速开始

Python 3.10+，先安装依赖（安装可能需要访问包仓库）：

```bash
pip install -r requirements.txt
python run_all.py
```

无需 Python：直接用浏览器打开 `web/index.html` 即可操作。网页的三维螺旋是 Canvas2D 透视模型，不是 WebGL 真实物理仿真。浏览器工作台上所有新力参数都是人工设定的。

## 主要文件

- `rootv72/physics.py`: 引力、自转、潮汐、红移及螺旋几何；G 只作为**实测输入**。
- `rootv72/holonomy.py`: 有限维联络对易子与 Wilson 环玩具模拟。
- `rootv72/experiment.py`: 四反转状态、统计估计、Fisher 信息、伪阳性与零假设模拟。
- `experiments.py`: 生成完整 CSV、JSON 与四张图。
- `data/ROOT_V72_核心方程与证明状态.csv`: E/C/H/O 标注公式目录。
- `data/ROOT_V72_新路线与失败条件矩阵.csv`: 候选路线与缺口。
- `results/numerical_summary.json`: 全部数值与 120 次人工零假设模拟结果。
- `results/tests_log.txt`: 单元测试的逐项记录。
- `results/browser_test.json`: Chromium 交互检查（如可用）。
- `web/index.html`: 纯本地 HTML/Canvas2D，不依赖第三方 CDN。
- `archive/ROOT_V71_历史研究包.zip`: 上一版的未经重新审查的历史归档。
- `SOURCES.md`: 主要物理与实验出处。

## 如何理解结果

合成输入 β=3.00×10⁻¹⁵，程序拟合值接近该输入，仅代表模拟算法可以识别自己注入的信号。显著性也来自人工注入，**不是科学发现**。如真实未知的 hs×X 仪器伪差存在，就会与候选参数完全不可辨识，需独立仪器或新的实验变量破解。

依然未完成的是：从独立公设计算 G、从单一微观动力学生成粒子谱/规范群、证明 UV 完备，以及独立实测新效应。
