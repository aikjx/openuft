验证 07

∇·B = 0 验证（无磁单极）

磁偶极子场：B_r = 2μcosθ/r³，B_θ = μsinθ/r³

$$\nabla \cdot \mathbf{B} = \frac{1}{r^2}\frac{\partial(r^2 B_r)}{\partial r} + \frac{1}{r\sin\theta}\frac{\partial(B_\theta \sin\theta)}{\partial\theta}$$

解析计算

$$\frac{1}{r^2}\frac{\partial(r^2 B_r)}{\partial r} = \frac{1}{r^2}\frac{\partial(2\mu\cos\theta/r)}{\partial r} = -\frac{2\mu\cos\theta}{r^4}$$ $$\frac{1}{r\sin\theta}\frac{\partial(B_\theta \sin\theta)}{\partial\theta} = \frac{1}{r\sin\theta}\frac{\partial(\mu\sin^2\theta/r^3)}{\partial\theta} = \frac{2\mu\cos\theta}{r^4}$$
验证结论

∇·B = -2μcosθ/r⁴ + 2μcosθ/r⁴ = 0

磁感线全部闭合，无磁单极存在 ✓
