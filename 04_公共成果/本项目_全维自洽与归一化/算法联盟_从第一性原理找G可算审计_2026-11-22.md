## 0. 五句话结论

1. **「求 G」本身不成立，需要换一个问法**：G 有量纲，c、ħ、G 三者之间**没有任何无量纲组合**（零空间维数 0）。G 只决定单位制（普朗克单位），不能被「推出」。加入质子质量后，才出现唯一可预言的纯数 **α_G = G m_p²/(ħc) = 5.906×10⁻³⁹**，等价于 **m_p/M_Pl = 7.69×10⁻²⁰**，即 **ln(M_Pl/m_p) = 44.01**。
2. **唯一已知的第一性机制是 QCD 量纲嬗变**：质子质量来自强耦合在低能变强，`Λ_QCD ≈ M_Pl · exp(−2π/(b₀ α_s(M_Pl)))`。指数里只需要一个 1/α_s ≈ 53 的数，就能自然得到 10⁻¹⁹ 的比值。这解释了**为什么引力这么弱**，但没有给出数值。
3. **α_s(M_Pl) 是输入，不是输出**：从 M_Z 处的实测值 α_s = 0.1180 往上跑，得到 1/α_s(M_Pl) = **52.48（单圈）/ 53.02（双圈）**。两个圈阶之间就差 0.54；跑回 M_Z 的残差为 1.3×10⁻¹²。
4. **指数放大让精度要求极高**：数值求得 `d ln α_G / d(1/α_s(M_Pl)) = −1.31`（与单圈 nf=3 解析值 −2π/9 ≈ −0.70 的两倍相符，误差在 6% 以内）。1/α_s(M_Pl) 每变 1，G 就变 **3.7 倍**。要达到 CODATA 的 2.2×10⁻⁵，需要把 1/α_s(M_Pl) 定到 **±1.7×10⁻⁵**，即相对精度 **3×10⁻⁷**，约 7 位有效数字。
5. **差距是 4 个数量级以上**：仅 α_s(M_Z) 的 0.76% 测量误差就让「推出的 G」浮动 **8.5%**。另一方面，各家实测 G 互相相差约 **5.3×10⁻⁴**（CODATA 给出误差的 24 倍）。即便如此，测量也比任何理论推导准 4 个数量级以上。**G 仍然只能测，不能算。**

## 2. 为什么「找 G」等于「找 44」

`α_G = (m_p/M_Pl)²`。在标准模型里，质子质量约 99% 来自 QCD 束缚能，正比于 Λ_QCD；夸克质量（Higgs 部分）只贡献约 1%。因此：

```
ln(M_Pl / m_p) ≈ 2π / (b₀ · α_s(M_Pl)) + O(1)      （单圈示意，b₀ 随味数分段）
```

**一个 O(50) 的 1/α_s 经过指数放大，自然变成 10¹⁹。** 这是「引力为什么这么弱」的标准答案（Wilczek 等人反复强调的观点）。但它把问题**转移**成了：为什么 1/α_s(M_Pl) ≈ 53.02？要回答这一点，需要一个在普朗克能标固定规范耦合的理论，例如：

| 候选机制 | 能否给出 1/α_s(M_Pl) | 现状 |
|---|---|---|
| 大统一 + 耦合交汇 | 只给出 α_GUT 的关系，不给出数值 | 需要新物质含量；耦合交汇本身未证（本仓第二十轮） |
| 渐近安全引力 | 规范耦合可能有不动点，从而被预言 | 不动点值依赖截断方案，远达不到 7 位精度 |
| 弦论 / 模空间稳定 | 由模场真空值决定，原则上可算 | 真空选择（landscape）问题未解 |
| 诱导引力（Sakharov） | `1/G ~ N Λ²` | 需要截断 Λ，等于把 G 改名成 Λ |

## 3. 对「螺旋 / 几何本源」路线的含义

- 「螺旋角」「标架」「c=1」这类几何量都是 O(1) 的数。**只靠 O(1) 的数，经过有理运算，得不到 10⁻³⁹**，必须有指数或对数机制。本仓既有 G 相关册中，没有一册给出过这样的机制。
- 任何声称「推出了 G」的来料，验收时先问三件事：
  ① 预言的是哪个**纯数**（α_G 还是 m_p/M_Pl）？
  ② 有没有**指数机制**？如果有，指数里的数从哪里来？
  ③ 精度能否达到 **3×10⁻⁷** 量级的耦合精度？至少要能落在实测 G 的 5×10⁻⁴ 散布之内。

## 4. 局限（本册自己承认的部分）

- 跑动采用 MSbar 示意：阈值处连续匹配，未包含阈值修正和 3–4 圈项。H3 中单圈与双圈相差 0.54，正说明这类修正本身就超过所需精度好几个数量级。
- 「α_s=1 的能标」只是强耦合标度的代理，不等于 Λ_MSbar 或 m_p。m_p/Λ 需要格点 QCD（非微扰的第一性计算，精度约 1%）。这个代理只影响 O(1) 前因子，不影响**敏感度**结论（H4 已与解析值对照）。
- M_Pl 在跑动中视为固定。如果理论同时改变 M_Pl 的含义（例如额外维），需要另立一册。
