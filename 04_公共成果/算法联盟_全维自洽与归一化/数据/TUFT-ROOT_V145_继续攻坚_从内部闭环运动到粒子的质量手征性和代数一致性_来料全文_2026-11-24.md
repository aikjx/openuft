# ROOT V145｜继续攻坚：从内部闭环运动到粒子的质量、手征性和代数一致性

这次把研究重点从“怎样产生规范场”推进到一个更难的问题：

**为什么自然界存在特定的基本粒子、左右手不对称，以及三代夸克和轻子？**

V144 证明了一个限制：在未加入额外规范背景的正曲率紧致空间中，内部 Dirac 算子不能产生所需的零模。因此，下一步需要检验**闭环的拓扑性质**，而不只是螺旋的局部曲率和挠率。

## 一、从闭环运动构造可量化的拓扑结构

采用一个研究模型：

\[ \mathcal M_6=M_4\times S^2 \]

在内部球面上，选取南北两个局部规范势：

\[ A_N=\frac n2(1-\cos\theta)d\phi \]

\[ A_S=-\frac n2(1+\cos\theta)d\phi \]

两个区域的规范势之差为：

\[ A_N-A_S=n\,d\phi \]

要求闭环后的相位变换单值：

\[ e^{i2\pi n}=1 \]

便得到：

\[ \boxed{n\in\mathbb Z} \]

这里的 \(n\) 是拓扑绕数，而不是人为指定的连续参数。

对应场强：

\[ F=dA=\frac n2\sin\theta\,d\theta\wedge d\phi \]

因此：

\[ \boxed{ \frac{1}{2\pi}\int_{S^2}F=n } \]

这是严格的拓扑量子化关系。

该构造属于已有的磁单极子纤维丛与规范理论，并不是 ROOT 已经独立推导出的新相互作用。

## 二、拓扑绕数如何对应粒子零模？

对内部带规范耦合的 Dirac 算子，指标定理给出：

\[ \boxed{ \operatorname{ind}(D)=N_+-N_-=n } \]

对于这个标准的球面对称磁通背景，确实存在 \(|n|\) 个同一内部手征性的零模。

不同拓扑绕数对应的内部零模数量：

- n = 0：0 零模
- n = 1：1 零模
- n = 2：2 零模
- n = 3：3 零模

这个机制的意义是：

当 \(n=3\)，模型中可以出现三个内部零模；在合适的六维 Weyl 费米子和降维条件下，可能产生三个四维手征模态。

**但这还没有解释自然界为什么必然选择 \(n=3\)，更没有得到完整的标准模型三代粒子。**

## 三、本轮发现的关键限制：一个闭环场不能直接产生全部三代粒子

假设把唯一的内部 \(U(1)\) 磁通直接等同于标准模型的超荷场。

对于内部电荷 \(q\)，指标定理给出：

\[ \boxed{N_+-N_-=qn} \]

标准模型粒子的超荷并不相同。将超荷统一乘以 6，使其成为整数，令 \(n=3\)：

| 粒子表示 | 整数化超荷 6Y | 指标 3(6Y) |
|---|---:|---:|
| 左手夸克双重态 Q_L | 1 | 3 |
| 左手反上夸克 u_L^c | −4 | −12 |
| 左手反下夸克 d_L^c | 2 | 6 |
| 左手轻子双重态 L_L | −3 | −9 |
| 左手正电子 e_L^c | 6 | 18 |

这说明：**如果只有一个公共磁通，而且各粒子只通过实际超荷与它耦合，就不会自动产生五类粒子各三代的结构。**

一种可能的修复是引入独立于超荷的家族对称性 \(U(1)_F\)，让不同粒子具有相同的内部家族荷；但这种新对称性目前仍是额外假设，需要重新检验异常抵消及其可观测后果。

## 四、进一步计算粒子激发质量

对于半径 \(R\) 的内部球面、磁通数 \(n\)，标准扭曲 Dirac 算子的非零谱满足：

\[ \boxed{ \lambda_k^2=\frac{k(k+|n|)}{R^2}, \qquad k=1,2,\ldots } \]

对应的四维质量尺度为：

\[ m_k=\hbar|\lambda_k| \]

其中仍只采用 \(c=1\)，没有设置 \(\hbar=1\)。

例如令 \(n=3\)，选择示意半径 \(R=10^{-18}\,\mathrm m\)，最低非零激发能量约为：

\[ \boxed{E_1\approx394.654\ \mathrm{GeV}} \]

这个半径是测试输入，不是独立推导出的自然常数。因此该计算展示的是模型的质量尺度规律，而不是预测发现一种 394.654 GeV 的新粒子。

## 五、量子一致性验证：又发现一个必须解决的障碍

如果仅产生三个电荷为 \(+1\) 的四维左手 Weyl 费米子，其规范异常系数为：

\[ \boxed{ \mathcal A_{U(1)^3}=3,\qquad \mathcal A_{\mathrm{grav}^2U(1)}=3 } \]

它们没有抵消，因此这样的孤立粒子谱不能直接构成一致的量子规范理论。

使用精确分数运算，交叉验证了标准模型一代粒子中的四类局部异常抵消关系：

\[ \boxed{ \begin{aligned} \mathcal A_{U(1)^3}&=0\\ \mathcal A_{\mathrm{grav}^2(U1)}&=0\\ \mathcal A_{SU(2)^2U(1)}&=0\\ \mathcal A_{SU(3)^2U(1)}&=0 \end{aligned} } \]

这也符合现有标准模型的量子一致性要求。

另一个关键区别是：**六维 Dirac 费米子通常产生四维左右配对的零模；要得到净手征结构，需要额外的六维手征条件或其他机制。** 拓扑绕数本身还不足以完成粒子谱推导。
