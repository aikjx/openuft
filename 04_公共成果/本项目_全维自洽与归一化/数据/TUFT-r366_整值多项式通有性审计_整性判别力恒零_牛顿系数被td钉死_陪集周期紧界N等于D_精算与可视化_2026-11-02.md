## 一、一句话结论

**整性判不出几何，系数值判得出。** r346 的引理 L 与 r358 的定理 E/F 对任意整值多项式都 100% 成立 ⇒ 判别力恒为零；而本卷的**定理 H**（牛顿系数的闭式）在随机整值多项式上 **0/16000** 命中 ⇒ 判别力接近于 1。同时，定理 H 的证明只需要 **Koszul 短正合列加 χ 的加性**（三行），**不需要 Todd 类** ⇒ r339/r346/r358 绕 td 级数算 χ 的路径是充分不必要的。

## 二、定理 H：牛顿系数被完全钉死

对 `X_d ⊂ CP^{n+1}`（`dim_C X = n`），χ 的牛顿展开 `χ(O_X(kH)) = Σ_m a_m C(k,m)` 满足

```
a_m = C(n+1, m) − C(n+1−d, n+1−m)      （广义二项式）
```

其中 `C(x,r) = x(x−1)…(x−r+1)/r!`，`d > n+1` 时上标 `n+1−d` 为负，由 `C(−p,r) = (−1)^r C(p+r−1,r)` 定义。

**要点**：`(a_0,…,a_n)` 由 `(n,d)` 两个参数完全决定，**零自由度**。而一般的整值多项式有 `n+1` 个自由整数参数 ⇒ 几何类是 `Int(Z)` 中的零测真子集。

**证明（三行，不需要 td）**

1. Koszul：`0 → O_{CP^{n+1}}(k−d) → O_{CP^{n+1}}(k) → O_X(k) → 0`
2. χ 在短正合列上加性，且 `χ(O_{CP^N}(k)) = C(N+k, N)` ⇒ `χ(O_X(k)) = C(n+1+k, n+1) − C(n+1+k−d, n+1)`
3. `Δ^m C(x+k, N)|_{k=0} = C(x, N−m)` ⇒ 闭式

注意第 2 步**不需要任何消灭定理**，故定理 H 对 CY 与一般型同样成立。

## 三、三条独立计算路径（互不共享中间量）

| 路径 | 算法 | 中间量 |
|---|---|---|
| **A（td 级数）** | `χ(k) = d·[h^n](e^{kh} T(h)^{n+2}/T(dh))`，`T(h)=h/(1−e^{−h})` 用 Bernoulli 展开 | `c_j`、Stirling 数 |
| **C（Koszul 计数）** | `χ(k) = C(n+1+k, n+1) − C(n+1+k−d, n+1)` | 广义二项式 |
| **H（闭式）** | `a_m = C(n+1,m) − C(n+1−d, n+1−m)` | 同上，但不走 `χ` |

**主校验**：51 组（n=1..6，d=1..n+5）两两失配 **A−C=0、A−H=0、C−H=0**。

## 四、适用范围：跨出 Fano

r339/r346/r358 一直工作在 Fano 范围（大致 `d ≤ n+1`），因为要用消灭定理把 `χ` 等同于 `h⁰`。定理 H 不需要这个前提：

| 类型 | 条件 | 组数 | 失配 |
|---|---|---|---|
| Fano | `d ≤ n+1` | 27 | 0 |
| CY | `d = n+2` | 6 | 0 |
| 一般型 | `d > n+2` | 18 | 0 |

**自检（A04/A06）**：`d=n+2` 时 `a_0 = χ(O_X) = 1+(−1)^n` ⇒ 椭圆曲线（n=1）0、K3（n=2）2、五次三维 CY（n=3）0、六次四维 CY（n=4）2，全部吻合；四次曲线（n=1,d=4）`χ(O) = 1−g = −2`，吻合。

## 五、判别力翻转（本卷核心）

同一批样本（16000 个随机整值多项式，n=3/4/5/6 各 4000，`a_m ∈ [−40,40]`）上的通过率：

| 判据 | 几何类 | `Int(Z)` | 判别力 |
|---|---|---|---|
| r346 引理 L（牛顿系数全整） | 100% | **16000/16000** | **0** |
| r358 定理 E（整数陪集整段） | 100% | **16000/16000** | **0** |
| **本卷定理 H（系数值）** | **51/51** | **0/16000** | **≈1** |

这是三代主线（r331→r335→r339→r346→r358→r366）第一次拿到**判别力非零**的判据。

**敏感性（B05/B06）**：几何 `a` 上单独扰动一位（+1）后仍通过定理 H 的只有 **4/126** 次，且这 4 次**全部是族内移动**（`closedH(n,n)` 与 `closedH(n,n+1)` 只差末位），**无族外漏网**。期望值由解析路径独立给出：`closedH(n,d+1) − closedH(n,d) = (C(n−d, n−m))_{m}`，该差向量是单位向量当且仅当 `d=n`。

## 六、`X-R358-2` 的答案：`D(c)` 的素因子来自 `c` 的分母

140 个陪集（`n=1..4`、`d=1..n+1`、`c=p/q` 其中 `q=1..4`）上：

- **`D(c)` 的素因子集合 ⊆ `c` 的分母 `q` 的素因子集合**，违例 **0/140**
- 空陪集 78 个，其中 `D>12` 的 56 个，**最大 `D = 2048`**

⇒ r358 见到 `D` 爆到 `3.6e7` 的原因**不是几何复杂**，而是 `c` 的分母的算术。这回答了 `X-R358-2` 中「`D(c)` 随 `c` 的闭式」这一半（素因子支撑部分）。

## 七、`X-R358-1` 的推进：`N=D` 归约到「解集单轨道」

分流（140 组）：**EMPTY 78 / FULL 58 / PARTIAL 4**（部分陪集只占 2.9%，与 r358 的 11/396≈2.8% 一致）。

- **C01**：部分陪集上 `N = D`，**4/4**（加上 r358 的 11/11，共 15/15）
- **C02**：解密度 `|S| = H/D = n!`（一周期内恰一个整点）
- **C05**：恒等式 `N = H/|S|` 4/4 成立 ⇒ 因 `H = D·n!`，得 **`N = D` 等价于「解集在 `Z/H` 上是一条轨道」**

⇒ `X-R358-1` 从「`N=D` 是否成立」归约为「解集是否单轨道」。后者**未独立证明**（r358 定理 F 是实测 11/11），故本卷**不宣称证明了 `N=D`**。

## 八、周期计算的坑（C06）

平移不变性必须在环 `Z/H` 上检查（`(m+T) mod H`）。若按线性窗口检查（`m+T ∈ sols`），右端必然越界 ⇒ 求不出周期（本卷探查 3 首跑即此 bug，`N=None`）。C06 把两种算法并列：环形 `N=4`、非环形 `N=None`，两者不同才说明该对照有判别力。

## 十、判据与方法（沉淀给后续卷）

1. **先闭式再取样**：只要能写出系数的闭式，「整段 / 部分 / 空」就都变成系数的算术性质，与枚举窗口无关。（r358 的「先 Vandermonde 再取样」在本卷升级为「先闭式」）
2. **判别力必须两侧都测**：只报几何侧 100% 会误导；必须同时报 `Int(Z)` 侧的通过率。（G11 已固化为守卫）
3. **源码级检查一律走 AST**：`S.count("random")`、`S.count("float(")` 会把守卫自己的描述文字算进来（本库第三次）。（G02/G16/G18 已固化）
4. **「值相等」≠ 同义反复**：`exp="0" act="0"` 是合法的（违例数为 0）；同义反复只能在**源码字面量层**判。（G04 已固化）
5. **负对照的扰动要落在敏感方向**：把 `BERN[2]` 设为 `1/6` 时因 `T_2 = B_2^+/2! = 1/12` 而**等于没改**，负对照恒绿；必须设 `B_2^+ = 1/3` 才真正改到 `T_2`。
6. **凡报「空」必须报 `D`**，且空/全/部分三类必须分流统计——空集的周期退化为 1，混进来会把 `N=D` 冲掉。

## 十五、诚实边界

- 定理 H 是**关于超曲面 χ 的初等事实**：它证明了「给不出别的牛顿系数」，但**没有证明框架必须给出这个系数**。这与 r327 的教训同型——**证了「给不出」，没证「所以必须给」**。
- 判别力 ≈1 是**在「随机整值多项式」这个对照类上**测的。若换成别的对照类（如「满足某些自然性的多项式」），判别力可能下降。本卷只报了这一个对照类的结果。
- 框架**依然不预言 3**。
