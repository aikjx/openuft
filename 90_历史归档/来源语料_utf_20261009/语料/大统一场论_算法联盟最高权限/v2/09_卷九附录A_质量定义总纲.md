## A.3 六类质量定义的全情况互推

### 类 I：频率-能量（m = ℏω/c²）

由公理 II（E=ℏω）与质能等价（E=mc²）：
$$m = \frac{E}{c^2} = \frac{\hbar\omega}{c^2}$$
- 单束：m₀ = ℏω₀/c²
- N 束：M = N·ℏω₀/c²

### 类 II：几何曲率挠率（m = ℏ√(κ²+τ²)/c）

由类 I 代入核心恒等式 ω = c√(κ²+τ²)（公理 I 光速 + 公理 III 螺旋）：
$$m = \frac{\hbar\omega}{c^2} = \frac{\hbar\cdot c\sqrt{\kappa^2+\tau^2}}{c^2} = \frac{\hbar\sqrt{\kappa^2+\tau^2}}{c}$$

### 类 III：特征长度（m = ℏ/(cR)）

由对偶不变量 1/R² = κ²+τ²（卷一）：
$$m = \frac{\hbar\sqrt{\kappa^2+\tau^2}}{c} = \frac{\hbar}{cR},\qquad R = \frac{1}{\sqrt{\kappa^2+\tau^2}}$$
- 单粒子 R 即**康普顿半径** R = ℏ/(m₀c)。
- 反过来，由 R 可反解质量：m₀ = ℏ/(cR)。

### 类 IV：条数计数（M = N·m₀）

宏观/复合体的质量是条数 N 的整数倍（卷九定理 9.1）：
$$M = N\cdot\frac{\hbar\sqrt{\kappa^2+\tau^2}}{c} = N\,m_0$$
- 单粒子 N=1：M = m₀。
- 质子 N≈1836.153：M = m_p。
- 宏观体 N~10³⁰：M 连续近似。

### 类 V：立体角密度 ZUFT（M = k·(dn/dΩ)）

对类 IV 沿全立体角积分并令 k=m₀（卷九定理 9.2）：
$$M = k\oint\frac{dn}{d\Omega}\,d\Omega = k\,N = m_0\,N$$
- k 由几何固定（非拟合参数）。
- 局域微分形式：dm = m₀·dn。

### 类 VI：特征尺度（m_P, m_e, m_p）

主方程在两端的标定：
- **普朗克质量**（N_P 束，N_P = m_P/m₀ ≈ 2.389×10²²）：
  $$m_P = \sqrt{\frac{\hbar c}{G}} = N_P\,m_0$$
- **电子**（N=1 束）：m_e = m₀ = ℏ√(κ²+τ²)/c
- **质子**（N_p 束）：m_p = N_p·m_e，N_p = m_p/m_e ≈ 1836.153
