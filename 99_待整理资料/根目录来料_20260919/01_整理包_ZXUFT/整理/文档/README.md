# 统一场论研究平台

基于张祥前统一场论的专业研究平台，提供引力光速统一方程的理论推导、数学验证、3D可视化和数据分析功能。

## 🌟 项目特色

- **理论推导**: 完整的引力光速统一方程数学推导过程
- **公式验证**: 17个核心公式的数学正确性和物理合理性验证
- **3D可视化**: 基于Three.js的引力场与电磁场三维可视化
- **数据分析**: 实验数据与理论预测的对比分析系统
- **专业界面**: 深空科技主题，玻璃态设计，响应式布局

## 🚀 快速开始

### 环境要求

- Node.js 16.0+ 
- npm 7.0+ 或 yarn 1.22+

### 安装依赖

```bash
# 使用 npm
npm install

# 或使用 yarn
yarn install
```

### 启动开发服务器

```bash
# 开发模式
npm run dev

# 或使用 yarn
yarn dev
```

访问 http://localhost:3000 查看应用。

### 构建生产版本

```bash
# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```

```
├── App.jsx             # 主应用组件
├── main.jsx            # 应用入口
└── index.css           # 全局样式
```

## 📊 物理常数

平台支持的主要物理常数：

- 万有引力常数 G = 6.67430 × 10⁻¹¹ m³·kg⁻¹·s⁻²
- 光速 c = 299792458 m/s
- 电磁光速几何耦合常数 Z‘
- 真空介电常数 ε₀ = 8.854187817 × 10⁻¹² F/m
- 真空磁导率 μ₀ = 1.2566370614 × 10⁻⁶ N/A²
