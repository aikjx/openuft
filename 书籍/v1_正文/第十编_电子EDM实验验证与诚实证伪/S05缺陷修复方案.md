## 一、缺陷确认（独立复核）

### S05-C0001：定理 H2 紧致化半径公式量纲错误

原文：$R_{11} = \left(\dfrac{\hbar}{2\pi}\right)^{1/3} G^{1/3} c^{-2/3} \approx 1.616\times10^{-35}$ m（声称 $=L_p$）

**独立量纲分析**（基 M/L/T）：
- $\hbar^{1/3}$：$(ML^2T^{-1})^{1/3} = M^{1/3}L^{2/3}T^{-1/3}$
- $G^{1/3}$：$(M^{-1}L^3T^{-2})^{1/3} = M^{-1/3}L\,T^{-2/3}$
- $c^{-2/3}$：$(LT^{-1})^{-2/3} = L^{-2/3}T^{2/3}$
- 乘积：$M^0 L^1 T^{-1/3}$ —— **量纲为 $L\cdot T^{-1/3}$，不是长度**

**独立数值复核**（Decimal 50 位）：
- 原式实算：$R_{11} = 2.318570\times10^{-21}$ m
- 普朗克长度：$L_p = 1.616255\times10^{-35}$ m
- **比值 $R_{11}/L_p = 1.4345\times10^{14}$** —— 与原文"恰好=普朗克长度"矛盾

### S05-C0002：定理 H3 数值错误

原文：$M_{11} = M_p(2\pi)^{1/3} = 3.18\times10^{19}$ GeV
独立复核：$M_{11} = 2.252872\times10^{19}$ GeV/c²
**原文偏大 1.4115 倍**（公式形式正确，数值声明错误）

## 二、修复方案（量纲正确 + 数值一致）

### 修复 H2：改用普朗克长度标准组合

$$R_{11} = \left(\frac{\hbar G}{c^3}\right)^{1/2} = L_p = 1.616255\times10^{-35}\ \text{m}$$

- 量纲：$L$ ✓
- 数值：精确等于普朗克长度（与原文"紧致化半径=L_p"的物理意图完全一致）
- 指数组合从 $(1/3,\,1/3,\,-2/3)$ 修正为 $(1/2,\,1/2,\,-3/2)$

### 修复 H3：数值更正

$$M_{11} = M_p(2\pi)^{1/3} = 2.252872\times10^{19}\ \text{GeV/c}^2$$

- 或重核 $(2\pi)^{1/3}$ 系数来源（若原意是 $M_{11}=M_p$ 则直接取 $1.22089\times10^{19}$ GeV）

### 不受影响

- H1：$M_{11}cL_{11} = 2\pi\hbar$（量纲为作用量，形式自洽）
- H5 投影关系、S05-A1 公设
