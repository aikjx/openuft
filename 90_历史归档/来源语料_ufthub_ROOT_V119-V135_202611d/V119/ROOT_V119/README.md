# ROOT V119 — 黎曼谱论与空间光速螺旋的统一场论可证伪研究

**日期：2026-11-21**。研究性原型，不是四力统一的证明，也不是黎曼猜想的证明。

## 运行

Python 3.10+：`python -m pip install -r requirements.txt`，然后 `python src/verify.py`，`python -m unittest discover -s tests -v`。

输出位于 `data/`：螺旋几何残差、20个ζ零点的数值检查、玩具模型的周期算子谱和 JSON 汇总。

## 研究原则

采用自然单位 **c=1**，**不**设 ℏ=1 或 G=1。长度和时间以同一单位表示；质量、作用量、耦合常数须通过单独的物理定义和量纲检查。

### A. 已证明的几何恒等式

r(t)=(R cos(ωt), R sin(ωt),pt)，速率归一化 R²ω²+p²=1。曲率 κ=Rω²，挠率 τ=pω，故 κ²+τ²=ω²。非退化时 R=κ/(κ²+τ²)，p=τ/sqrt(κ²+τ²)。这是常速螺旋的几何，不是四力的动力学。

### B. 谱算子原型

长度为 L 的闭合周期参数 u 上，H=-d²/du²，周期边界下 λ_n=(2πn/L)²。引入边界相位 θ 后 λ_n=[2π(n+θ)/L]²。这些谱是自伴、非负、离散的。**它们不等于黎曼零点的虚部**；如要建立联系，必须证明精确的谱等价、谱计数律和迹公式，不能只对若干零点拟合。

### C. 统一场论的严格目标

提出待研究的协变作用量 S=∫d⁴x sqrt(-g)[R_g/(16πG)-1/4 F_{μν}F^{μν}-1/4 Σ_a W^a_{μν}W^{aμν}+L_matter+L_new]。其中 R_g 是Ricci标量而不是螺旋半径。此表达只是已知引力/规范场项加未知新项的组织框架；规范群、手征性、Higgs、质量谱、量子反常抵消、重整化与量子引力尚未导出。

### D. 四条证伪关卡

1. 洛伦兹协变：固定坐标时间的 |dr/dt|=1 对有质量粒子不具备一般洛伦兹不变性，不能未经证明当作普适物理速度。应明确区分内部参数、坐标速度和局域观测速度。
2. 规范不变性：仅凭 κ,τ,ω 不可能唯一确定电荷、SU(2)、SU(3) 的表示和耦合。
3. 引力检验：必须恢复等效原理、GR 弱场极限、引力波传播和精密实验；不能由 c=1 推出 G 的数值。
4. 谱检验：必须证明算子自伴性、谱与真实观测量的映射、连续极限和谱计数；与ζ零点的统计相似不是同一性证明。

### E. 可行的新研究假说（未证实）

把螺旋的 Frenet–Serret 连接作为几何背景，研究其上带规范联络的 Dirac 算子 D_A；考察谱作用量 Tr f(D_A²/Λ²) 的热核展开是否在指定维度、场内容及边界条件下恢复 Einstein–Hilbert 与 Yang–Mills 形式。该思路借鉴谱几何，不声称由黎曼猜想推出标准模型。关键难点是构造非任意的内部有限几何、手征谱和可测的新预测。

## 结论

计算能验证几何恒等式、数值零点和玩具算子谱，不能证明 ζ 所有零点性质或四力统一。未来工作的优先级：协变参数化 → Dirac/谱算子严格构造 → 规范表示与手征性 → 引力弱场 → 新的无自由调参实验预测。
