## 0. 摘要与记号

四力统一必须解释三个层次：**动力学**（什么场源于什么作用量）、**谱与对称性**（为什么这些场及粒子存在）、**数值及观测**（为什么它们具有这些耦合与质量）。过去 ROOT V50—V72 的螺旋角和曲率工作只严格覆盖第一层中的部分运动学。我们重新审计：从 `c, ħ` 与无量纲螺旋角无法量纲上构造 `G`；量纲嬗变确实可以生成尺度但依赖输入耦合；总联络的曲率虽然是统一数学表达，却可能只是直积丛上的并列联络；宏观自旋耦合并非普适引力；实验中的有限尺寸、化学组成、空间运动和仪器交互会产生强混淆。本文新增一套完全交叉的 `2×2×2` 三反转实验，精确消掉所有低于三阶的符号依赖，但展示完全同形的系统项不能被消除。

本文采用：`E` 已有确立理论，`C` 在给定前提下严格推导，`H` 特定新物理假设，`O` 尚未解决，`X` 已找到反例或失效条件。局部场论部分采用**自然单位** `ħ=c=1`；天体重力和引力常数计算采用 **SI 单位**。质量尺度采用 GeV 时显式写明。**两个约定不可直接混用。**

## 1. 为何原先的光速螺旋不能独立说明四种力

设螺旋世界图形（纯三维空间轨迹）为

\[\mathbf r(t)=(R\cos\omega t,R\sin\omega t,ut).\]

其速度与加速度严格为

\[\mathbf v=(-R\omega\sin\omega t,R\omega\cos\omega t,u),\quad\mathbf a=(-R\omega^2\cos\omega t,-R\omega^2\sin\omega t,0).\]

若 `v=√[(Rω)²+u²]` 为常数，则

\[\kappa=\frac{R\omega^2}{v^2},\qquad \tau=\frac{u\omega}{v^2},\qquad |\mathbf a|=\frac{(R\omega)^2}{R}.\]

设定 `v=c` 只是给这条**空间曲线**施加了特殊速度条件，并没有由此推导出真实粒子的能量动量、规范荷或传播场。带质量粒子的中心质心速度不能等于 `c`；若把其内部场相位称为光速，则需要定义实际守恒流和与观察量之间的映射。`κ`/`τ` 与时空度规的 Riemann 曲率/联络挠率也不是同一个对象。

**反例 1**：两粒子质量和空间轨迹完全相同、电荷 `q` 和 `−q`，处于相同外电场 `E`，则 `F_e=qE` 的方向相反；几何曲率和挠率完全相同。故仅由螺旋角不可能确定电磁相互作用。**反例 2**：中性的自旋平均样品与自旋极化样品的自旋轴矢量耦合不同，而普通引力仍主要取决于能量与质量。几何运动可成为新场的候选变量，却不足以替代规范荷与普适耦合结构。

## 2. 更具潜力的方向 A：尺度不是“给定半径”，而是动力学生成

引力常数的 SI 量纲是

\[[G]=L^3 M^{-1}T^{-2}.\]

如果 `G=c^a ħ^b`，质量维要求 `b=−1`，长度维要求 `a+2b=3` 所以 `a=5`，时间维要求 `−a−b=−2` 所以 `a+b=2`；前两式却给出 `a+b=4`，矛盾。**在只含 `c,ħ` 和无量纲角的输入集合内，无法产生正确的 `G` 量纲。**

这是一项在给定变量集上的限制证明，并不排除新的场动力学**动态生成**独立质量尺度。量子场论的经典途径是重整化群量纲嬗变。假定一圈 beta 函数

\[\mu\frac{dg}{d\mu}=\beta(g)=-\frac{b_0}{16\pi^2}g^3,\qquad b_0>0.\]

分离变量：`d(g^-2)/d ln μ = b0/(8π²)`，积分得

\[\frac1{g^2(\mu)}=\frac1{g^2(\mu_0)}+\frac{b_0}{8\pi^2}\ln\frac\mu{\mu_0}.\]

定义不变量的对应一圈特征尺度

\[\boxed{\Lambda=\mu\exp\left[-\frac{8\pi^2}{b_0g^2(\mu)}\right]}.\]

此处生成一个真实的有量纲标度，且其依赖 `g` 的关系是非解析的指数形式。但仍须输入**规范动力学、`b0`、边界条件、某个参考能标上的耦合**，不能把输入隐藏为“无参数”。

### 2.1 直接数值检验：指数层级与参数敏感性

取仅作教学的固定 `b0=7` 一圈模型，设 `μ=2.435×10^18 GeV`，希望 `Λ=0.2 GeV`，反求

\[g(\mu)=\sqrt{\frac{8\pi^2}{b_0\ln(\mu/\Lambda)}}\simeq0.506625.\]

这不是从 ROOT 公设“预测出了 0.2 GeV”，而是反算所需的紫外耦合。它也不是对跨越所有夸克质量阈值的真实 QCD 精确运行，因为 `b0=7` 被固定，忽略阈值、两圈及更高阶修正。对耦合求导：

\[\frac{\partial\ln\Lambda}{\partial g}=\frac{16\pi^2}{b_0 g^3}.\]

小小的紫外输入变化可以导致红外标度的显著变化。新理论要以“对外部输入的敏感程度”和“预测新的无量纲比”评价，而不是以能否写出指数关系评价。

### 2.2 诱导引力不能靠大数消除耦合来源

对具体选定的单圈截止模型，在自然单位中可有示意匹配：

\[\frac1{G_{\rm ind}}\sim \frac{N\Lambda_{\rm UV}^2}{12\pi},\qquad \overline M_P^2=\frac1{8\pi G}\sim\frac{N\Lambda_{\rm UV}^2}{96\pi^2}.\]

**注意**：数值因子只对之前指定的最小耦合实标量、固有时间截断等特殊约定成立，真正重整化后的可观测 `G` 还受裸项、场谱、非最小耦合、阈值与方案影响。若把 `Λ_UV` 直接取为 `0.2 GeV`，并要求产生观测的约化普朗克质量 `2.435×10^18 GeV`，本玩具模型需 `N≈1.40×10^41` 个相同贡献场。它不是一个合理的简单解释，而且会引入额外一致性问题。

**推导结果**：RG 可以生成维度尺度，诱导引力可把 UV 物质尺度映射到有效引力系数；**缺失环节**：为什么 `g_UV`、场数 `N`、截止处理、场谱和裸作用量取特定值，并给出一个能被独立验证的 `G`。这是与“螺旋半径等于普朗克长度”有本质区别的研究方向，却未完成独立预测。

## 3. 路线 B：真正区分“总联络”与“相互作用统一”

给定洛伦兹自旋联络与内部规范丛，定义

\[\mathcal D_\mu=\nabla_\mu^{\rm spin}+ig_1 B_\mu Y+ig_2 W_\mu^aT_a+ig_3 G_\mu^AT_A.\]

其曲率对易子有形式展开

\[[\mathcal D_\mu,\mathcal D_\nu]=\tfrac14R_{\mu\nu ab}\gamma^{ab}+ig_1B_{\mu\nu}Y+ig_2W_{\mu\nu}^aT_a+ig_3 G_{\mu\nu}^AT_A.\]

如果四个生成元属于互相对易的直和代数，分别相互对易，就只是在一个表示空间中**并列放置四种已知联络**。要得到物理的大统一，至少需要说明“内部规范群在高能如何嵌入更大的结构”“哪些重态使交叉生成元真的改变粒子量子数”“低能谱与异常如何出现”“规范耦合如何匹配”。

作为**已知的条件例子**，`SU(5)` 的维数为 24，在标准模型子群下规范生成元按维数分解为 `8+3+1+12`，其中额外 12 个生成元对应重玻色子的候选自由度。它不是 ROOT 螺旋公设得出的结论，也要受质子衰变和耦合运行约束。`SO(10)` 及其他路线类似：只写群名不等于获得正确粒子谱。

### 3.1 一个严格的代数判别

如果 `𝔤=𝔤₁⊕𝔤₂`，对任意 `X∈𝔤₁`,`Y∈𝔤₂` 有 `[X,Y]=0`，那么不同扇区的协变导数曲率不会因为并入大矩阵就产生新的混合结构。**形式统一与动力学统一的判别标准是作用量中是否有可推导的约束、共同耦合边界和跨扇区可检验关联，不是能否写成大矩阵。**

### 3.2 引力的自旋 2 结构带来更严的障碍

弱场中普适长程引力通常需要正确传播的自旋 2 自由度。若尝试把无质量自旋 2 粒子当作普通平直时空、具有 Lorentz 协变守恒应力张量的局域量子场之复合态，还受到 Weinberg–Witten 定理的适用条件约束。该定理并不是对所有“涌现引力”模型的一概否决：广义协变理论的局域引力能量不是普通意义上的规范不变局域应力张量，某些高维、非局域或全息机制可以规避前提。**本研究的要求是逐一说明候选微观模型满足或违反哪些前提，而不是以“螺旋运动”绕过定理。**

## 4. 路线 C：从可变手性背景得到真正可变分的相互作用

这是一个可以算出明确场方程的**既有有效场论结构**，作为 ROOT 假说的检验平台，而非将其宣称原创四力统一。在自然单位下引入一个**赝标量** `a(x)`：

\[S=\int d^4x\sqrt{-g}\left[\frac{M_*^2}{2}R-\frac12(\nabla a)^2-V(a)-\frac14F_{\mu\nu}F^{\mu\nu}-\frac{\zeta}{4f_a}aF_{\mu\nu}\widetilde F^{\mu\nu}+\mathcal L_{\rm matter}\right].\]

`f_a` 是需独立决定的质量尺度，`ζ` 为无量纲常数。`a` 作为赝标量才能在正常宇称定义下使 `aF~F` 组合具有适当宇称性。对 `a` 的变分：

\[\boxed{\Box a-V'(a)-\frac{\zeta}{4f_a}F_{\mu\nu}\widetilde F^{\mu\nu}=0}.\]

对 `A_\mu` 的变分，在通常的电流符号约定下：

\[\boxed{\nabla_\mu F^{\mu\nu}+\frac{\zeta}{f_a}(\nabla_\mu a)\widetilde F^{\mu\nu}=J^\nu}.\]

**关键严格限制**：因 Bianchi 恒等式 `∇_μ \widetilde F^{μν}=0`，若 `a` 在整个无边界局部区域为常数，那么 `aF~F` 的 bulk Maxwell 修正项为零。只有 `∇a`、边界、拓扑或其他动态场效应才能造成局部影响。故“均匀的空间螺旋角”不会仅仅因角度存在，就自动在真空中修正 Maxwell 方程。

这是一个可证伪的理论工具：先明确新增场如何从微观螺旋产生，再推导 `a(x)` 的观测值，最后计算光传播、偏振、实验相位或材料响应。如果必须再次任意输入 `f_a`、`ζ` 和 `V`，这仍不是无参数统一。

## 5. 路线 D：把元素与地球内部结构真正算进去

针对球对称密度 `ρ(r')` 的 Yukawa 类型候选作用，定义无量纲 `x=R/λ` 与 `y=r/λ`，`r≥R`。均匀球的相对附加径向加速度是：

\[\frac{\Delta g}{g_N}=\alpha\,\mathcal F(x)(1+y)e^{-y},\quad \mathcal F(x)=\frac{3(x\cosh x-\sinh x)}{x^3}.\]

在地表 `r=R+h`，直接计算 `cosh(x)e^{-x}` 可避免大 `x` 指数溢出。定义

\[\boxed{S(x)=e^{-x}\mathcal F(x)=\frac{3[(x-1)+(x+1)e^{-2x}]}{2x^3}}.\]

于是

\[\frac{\Delta g}{\alpha g_N}=S(x)(1+x+h/\lambda)e^{-h/\lambda}.\]

当 `x→0` 时，`𝓕(x)=1+x²/10+x⁴/280+...`，因而恢复点源长程极限；当 `x≫1` 时，星体表面同样有可能受到靠近地表物质的较大贡献，直接用总质量置于中心将严重低估短程作用。这里的新内容是**稳定的算法实现及与分层质量源的交叉核验**，不是新的基本相互作用发现。

任意同心密度层 `ρ_i` 的体积平均型形状因子为

\[\mathcal F_{\rm layered}=\frac{4\pi\lambda^3}{M}\sum_i\rho_i\bigl[f(r_{i+1}/\lambda)-f(r_i/\lambda)\bigr],\quad f(z)=z\cosh z-\sinh z.\]

其中 `M=4π∑ρ_i(r_{i+1}³-r_i³)/3`。可见当源荷比例随材料变化时，还要把 `ρ_i` 换为相应源荷密度；质量密度的纯分层模型只是第一阶段近似。**两球总质量相同不代表它们对有限程新作用的外部响应相同**。但是它们对牛顿外场的响应可相同，这是辨别不同机制的重要对照。

在取地球参考半径 `R=6.371×10⁶ m`、`λ=10⁶ m`、假设 `α=1` 的纯数学比较中，程序得

- 点源约 `0.01261`；
- 均匀球约 `0.22964`；
- 保持总质量不变的两层球约 `0.19408`。

其中 `α=1` **完全不是被实验允许或已观察到的真实新力强度**，它只作为归一化比较。

## 6. 路线 E：从二反转升级为八状态三重反转

V72 的四状态方案消除了只与一个符号变量有关的背景项，但仍有双符号同形伪差。新方案再加入可控的第三个符号 `s`，它可以代表一种事先定义的源方向反转。注意 `h,r,s` 是实验开关，**不先假定它们必定由某种新物理哈密顿量耦合**。

设 `h,r,s∈{−1,+1}`，在同一环境做全部八种状态测量，最一般的三开关多项式为

\[y_{hrs}=\beta_0+\beta_h h+\beta_r r+\beta_s s+\beta_{hr}hr+\beta_{hs}hs+\beta_{rs}rs+\beta_{hrs}hrs+\varepsilon_{hrs}.\]

令八列矩阵 `H=[1,h,r,s,hr,hs,rs,hrs]`，则 `H^T H=8I`。因此在固定环境、完整平衡实验中，

\[\boxed{\widehat\beta_{hrs}=\frac18\sum_{h,r,s=\pm1}(hrs)y_{hrs}},\qquad\operatorname{Var}(\widehat\beta_{hrs})=\frac{\sigma^2}{8}\]

后式在**独立、同方差、零均值**的测量误差下成立。八状态确实严格消除所有常量、一阶和二阶符号依赖，但**仍不能消除真正也随 `hrs` 变化的仪器项**。针对不同环境 `e`，可写

\[D_e=\delta+\beta X_e+\varepsilon_e.\]

如果 `X_e` 非常数，`[1,X_e]` 两列满秩，可以识别常量的三反转伪差 `δ` 与真实候选响应 `βX_e`；若仪器也存在 `\gamma X_e` 并带同样 `hrs` 符号，设计矩阵出现两列完全一样，只有 `β+γ` 可辨认。**严禁把这种参数不可辨识性误写成“统计显著 = 发现第五力”。**

这个统计设计是本项目可实际实施的实验工程成果：与观察到新力是两回事。实际工程需要乱序、盲测、零耦合样品、独立仪器结构、独立源场变化、条件功效分析、校准变化以及预注册失效判据。

## 7. MICROSCOPE 对组成依赖模型的数量级排除

已发表的 MICROSCOPE 结果 `η(Ti,Pt)=[−1.5±2.3_stat±1.5_syst]×10⁻¹⁵`，是地球引力环境中的真实组成依赖自由落体比较。我们先做一个**刻意简化**的模型，用元素 `Z/A` 代表未知的新源荷/质量比：

\[a_i\simeq g_N\bigl[1+\alpha q_s q_i\,\mathcal K(R/\lambda)\bigr],\quad q_i=Z_i/A_i.\]

小 `α` 极限下

\[\eta_{AB}\simeq \alpha q_s(q_A-q_B)\mathcal K.\]

若人为设地球平均源荷 `q_s=0.5`，令 `q_Ti=22/47.867`、`q_Pt=78/195.084`，再把发表的统计与系统误差平方和作为近似不确定度，使用保守的 `|−1.5|+1.96√(2.3²+1.5²)` × 10⁻¹⁵ 作为示意界限，则在 `λ=10⁷ m` 下估计 `|α|` 约小于 `2.55×10⁻¹³`。

**绝不能把这个界限当作普适的第五力实验约束。** 真实的材料是合金，原子能量与核束缚、实际质量分数、轨道取向、噪声协方差、系统误差、不同标量理论的源荷都不同；若要发表新的实验上界，必须使用完整实验数据和似然。这里唯一证明的是：**任何明确写出组成源荷的候选 ROOT 模型，都可以在给定测量下计算一条条件限制。**

## 8. 两种“统一失败”的不同意义

**数学失败**：方程自相矛盾、量纲不符、数值函数在合法范围溢出、候选作用量无界、负能态等。这些可以通过修复定义、正确变分和数值稳定实现部分解决。**物理失败**：无法唯一得到观测值、实验排除、额外自由参数过多、没有与已知理论不同的可检验预测。这些不能用更多 Python 测试弥补。

同样，**可重现现有数据**与**可独立预测数据**完全不同。例如用 `M_P=2.435×10^18 GeV` 作为 UV 输入、由目标低能 `0.2 GeV` 反推耦合 `g≈0.506625`，属于“条件拟合”而不是“从无输入预测高低能比例”。同理，用 `G` 反算螺旋半径再将其代回 `G` 是循环定义。

## 9. 现有理论与候选统一路线的对照

- **广义相对论 + 标准模型**：已知低能成功理论，具有协变、规范结构和大量观测支持；但不是已经证明 UV 统一的理论。
- **自旋 2 引力自耦合**：在特定洛伦兹不变与一致性前提下与 GR 相关；不会给出全部粒子表象和 `G` 的绝对值。
- **SU(5)/SO(10) GUT**：可为三个内部规范群提供共同高能嵌入；没有自动完成量子引力且需满足核子衰变等约束。
- **高维 Kaluza–Klein**：能以几何方式说明某些规范场；紧化、手征性、粒子谱和有效耦合尚需独立动力学。
- **诱导引力**：某些量子物质场可产生 `R` 项；绝对系数、裸项及宇宙学常数仍是困难。
- **量纲嬗变**：可从边界耦合产生指数尺度；不能凭自身唯一预测边界条件。
- **自旋—挠率/轴矢量场**：提供可检验的自旋相关相互作用；不能直接等同普通引力。
- **ROOT 螺旋运动学**：正确描述选定曲线，尚缺基本场变量、源荷、对称性、量子一致性、非拟合预测和实验支持。
- **本稿八态三反转方案**：改善对某些背景的消除、提升实验设计可审计性；既不是新力理论，也无法防止与信号完全同形的伪差。

## 10. 可以进一步做的真实攻坚，而不是反复发明公式

设计一个具有以下最小内容的候选微观模型：

1. 明确初始场空间、自由度及其洛伦兹/内部规范变换；
2. 定义**局域作用量和能量条件**，分析真空与扰动谱是否稳定；
3. 给出导致三代手征费米子与规范群的机制，而不是写出最终谱作为输入；
4. 若假设涌现自旋 2，明确怎样避开适用的无质量复合粒子限制；
5. 如果目标是 `G`，展示哪个物理量能真正独立确定质量尺度与曲率项前因子；
6. 低能极限必须复现 Einstein、Maxwell、弱强规范场的预测，并接受原子钟、等效原理、引力波、轨道数据约束；
7. 新预测必须包含**事前固定**的参数与误差传播，独立实验结果将其与 GR/SM 区别。

此列表是**尚需完成的证明义务**。没有完成就不应宣布成功。研究的价值在于将开放问题逐步转换为定理、反例或可执行观测。

## 11. 软件数值验证与误差控制

`rootv73/models.py` 包含螺旋曲线几何、单圈 RG、诱导引力参数退化、稳定的有限球/分层球 Yukawa 因子、MICROSCOPE 条件界限、八态 Walsh–Hadamard 对照及不可辨识性检查。`experiments.py` 输出标注来源的五组 CSV、四张真实计算生成的 PNG 和 JSON 摘要。`tests/test_models.py` 使用 Python 标准 `unittest` 完成边界、极限、单调性、对称性、反例、噪声方差和满秩验证。离线网页只是这些数学结构的参数演示，**不进行宇宙的第一性原理模拟**。

特别注意：本版在小 `R/λ` 使用 Taylor 展开，在大 `R/λ` 使用已经乘以指数的形状因子，在多层体源上采用适当的指数缩放，避免直接算 `e^{R/λ}` 溢出。测试通过的是模型内数值一致性，不是物理正确性证明。

## 12. 最终裁定与新突破评价

本轮最强的**方法论突破**是把“三个方向反转 + 不同源场的尺度预测 + 有限尺寸积分”组织成一个可以明确判定参数是否可辨识的实验链。另一项有价值的**基础理论突破方向**是把“螺旋参数作为预设尺度”改为“由规范或多体动力学自行生成尺度”，但这个方向已经有丰富文献，本文没有优先权或创新定理的充分证据。

**严格裁定**：

- `E/C`：螺旋曲率与挠率、RG 一圈积分、统一联络直和展开、有限球因子、八态对照消偏、部分 axion 电动力学变分，是明确前提下可证明的数学结果。
- `X`：仅靠 `c,ħ` 与角度得到 `G`，以及仅靠几何方向得到规范荷，已有直接量纲或物理反例。
- `H`：真实空间微观螺旋源场、其可能的额外耦合、三重反转物理信号，目前只是待检验的模型假说。
- `O`：独立预测 `G`、唯一推出 `SU(3)×SU(2)×U(1)` 与完整粒子谱、量子 UV 完备、获得新的独立实验支持，仍未完成。
