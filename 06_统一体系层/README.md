## 这一层解决什么问题

`01_独立体系` 按**原始假设**把研究分成 18 个互不合并的体系。这是正确的归属原则，但分散登记带来三个无法回避的困难：

1. **无法回答"这些体系在争什么"**。s02 与 s12 都叫"空间光速螺旋"，但一个的 c 是速度上限、另一个的 c 是恒等约束；不并排看不出来。
2. **术语同名异义**。"螺旋""曲率""拓扑荷""分形"在不同体系里指代不同的东西，跨体系讨论必然失真。
3. **分不清可公度差异与纯表述差异**。GAQ 谱系 s03→s07→s08→s09 是同一研究的版本演进，而 s13 与 s14 是本体互斥的独立候选；两者在目录上看不出区别。

统一体系层不合并任何体系的物理结论，只提供三样东西：**共同坐标系、关系图谱、实现方式清单**。

## 统一层不是什么（必读）

> **本层提供的是架构统一（architectural unification），不是物理统一（physical unification）。**

- 建立统一层，不等于任何一个统一场论成立，也不等于这些体系可以合并。
- 本层不产生新的物理主张，不提升任何体系的证据等级。
- 体系中已登记为 `falsified` 的结论（例如 [S14](<../01_独立体系/S14_挠率统一场论TUFT/claims.csv>) 中的多项），在本层**照旧为 falsified**，不因"进了统一图"而改变。
- 坐标相同不代表理论相同；关系边是**谱系与借用标注**，不是已证明的逻辑依赖。

## 三条判定原则

沿用 [研究流程](../00_项目治理/WORKFLOW.md)，在统一层额外明确：

1. **本体优先**：L1 本体不同的体系，L2–L7 的任何相似都不能转移证据。
2. **借用显式化**：一个体系使用另一个体系的数学工具，必须在关系边中标 `borrows_math`，并说明借用的是形式还是结论。
3. **实现不等于理论**：代码运行成功、书稿成文、图谱美观，都不构成物理主张的证据。实现方式在 [实现方式总览](实现方式总览/README.md) 中登记，与体系的证据等级分列。
