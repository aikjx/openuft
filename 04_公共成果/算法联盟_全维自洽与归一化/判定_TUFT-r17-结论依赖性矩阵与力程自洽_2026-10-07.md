| 比例 | 判定 |
|---|---|
| 100% | **归属无关**（结构性质） |
| < 100% | **依赖归属** |

**A-02 为何要紧**：扇区归属已被合并为「未声明的外部输入」。**若多数既有结论依赖它，则 ③（零外部输入）的代价不止「窗口 3→2」，还要丢掉这些结论** ⇒ ③ 的代价此前被低估。

## 三、力程-耦合自洽性（C 段 · 本册新发现）

### 3.1 比值矛盾

| 量 | 值 |
|---|---|
| 实际 f_S/f_W = (alpha_s/lambda)/(alpha_W/lambda) | **6.9517** |
| L_S/L_W = 6.283e-15 / 6.283e-18 | **1000** |
| 若 **L = c/f** 成立则预测 f_S/f_W = L_W/L_S | **1.000e-03** |
| **矛盾倍数** | **6.95e+03** |

### 3.2 幂律标度同样不成立

若按三维力常见的 f 正比于 1/L^2：f_S/f_W=1.000e-06 => 与实际 6.9517 相差 **6.95e+06 倍** => **问题不在幂次选择，而在 f 与 L 的定义不匹配**。

### 3.3 ADD-02 自带检查未捕获此矛盾

ADD-02 只检查了绝对值：ħc/L_S=31.4 MeV（vs Λ_QCD 200-300，低 7.7 倍）、ħc/L_W=31.4 GeV（vs M_W 80.4，低 2.6 倍）=> 两者绝对值均偏低 2.6-7.7 倍，**而比值矛盾达 6.95e+03 倍** => **比值问题未被该检查捕获**。

### 3.4 定性边界与依赖关联

- **C-04**：本册只指出「L = c/f」与其自身耦合表**不自洽**（纯算术，无可争议）。**不判定哪一方错**——可能是 (a) L 的定义不含归属、(b) f 不等于该 L 处的耦合、(c) 两者由不同机制决定 => **须人工核对定义后才能定案**，本册不代作者下结论。
- **C-05**：L 取自**代表点**（ADD-02 给出 L_S、L_W、L_em 各值）=> L 本身也依赖扇区归属 => 「力长与耦合的关系」是一条**双重依赖**的结论：既依赖归属，又与 f 的定义不自洽 => **不应作为定量的独立预言使用**。
