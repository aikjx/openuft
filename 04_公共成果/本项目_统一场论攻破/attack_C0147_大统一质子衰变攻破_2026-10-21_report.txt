[E1] 边界事实（外部值只引用不复算）
  Super-K(2024, 90% CL, p->e+pi0)：τ_p > 2.4e+34 yr
  sin²θ_W(M_Z, MS-bar) = 0.2312
  三耦合反演(M_Z, MS-bar)：α1^{-1}=59.01、α2^{-1}=29.57、α3^{-1}=8.44
  => 边界事实：质子尚未观测到衰变（寿命 > 2.4e34 yr）；三耦合在 M_Z 并不同值。

[E2] 核心公式体系（本册核心：第一性推导 + Decimal 48 位精算）
  (a) SU(5) 树级混合角：g1=sqrt(5/3)g'、统一点 g1=g2 => tan²θ_W=g'²/g²=3/5
      sin²θ_W = tan²/(1+tan²) = (3/5)/(8/5) = 3/8 = 0.3750
      观测 sin²θ_W(M_Z) = 0.2312；树级预言/观测 = 1.6220（超 62.20%）
  (b) 维6算子 τ_p = M_X⁴/(α_GUT² m_p⁵)，m_p=0.938 GeV，GeV⁻¹→yr 因子=2.086e-32
      minimal SU(5)：M_X=1.0e+15 GeV、α_GUT⁻¹=40 ⇒ τ_p≈4.60e+31 yr
      vs Super-K 下限 2.4e+34 yr：比值(预言/下限)=1.91e-3 ⇒ 预言短于下限 => 被排除
      MSSM 汇聚标度：M_X=2.0e+16 GeV、α_GUT⁻¹=25 ⇒ τ_p≈2.87e+36 yr
      vs Super-K 下限：比值(预言/下限)=1.20e+2 ⇒ 预言长于下限 => 超界（质子太稳定，当前探测带外）
  (c) 攻破⑨ P03 读数引用：minimal SU(5) 最短预言 1e32 yr vs SK 下限 1.6e34 yr = 短 160 倍
      （本册 naive 维6估计落在 1e31–1e32 量级，与教科书/minimal SU(5) 量级一致，独立确认被排除）。
  => **阈值-可见两难**：树级 GUT 标度(1e15)质子衰太快(被排除)；汇聚标度(2e16)质子太稳(探测带外)。

[E3] 耦合汇聚性（引用 C0140 精确读数，本册不复算）
  SM 单圈 ΔL = 9.146 e-折 => 三耦合**不汇聚**（无共同统一能标）。
  MSSM：M_GUT=1.539743e+16 GeV、α_GUT⁻¹=25.7198、τ_p≈3.513e+34 yr（唯象标度律[C]）。
  => 汇聚唯一已知方案是 MSSM，代价：①新标度 M_SUSY ②整族超伴子 ③M_GUT/α_GUT 无第一性来源。

[E4] 几何供给：GUT 群 / X,Y 超重玻色子能否从几何第一性原理生成？
  C0137 读数：SM 签名(dim=12,rank=4) 至少 3 个互不同构代数共享 => 签名非唯一，SU(5)(dim24)/SO(10)(dim45) 更不在几何输出内。
  attack24 读数：so(1,3) Killing 型惯性(3,3) => 紧致子代数 dim ≤ 3；KK 逃逸最小额外维 n=5（so(1,8)）。几何自旋联络代数装不下 SM，更装不下 SU(5)。
  doublet-triplet 劈裂：triplet 须在 M_GUT(~1e16) 压质子衰变，doublet 在 v(~1e2)，层级比=1e+14 => 需 1e14 量级精细调节（撞 C2/C3）。
  => 几何框架**不能**从第一性原理生成 GUT 群，也不能生成 X,Y 超重玻色子及其质量标度。

[E5] 裁定
  大统一/质子衰变问题被精确翻译成三件事：(a) GUT 群与 X,Y 玻色子从哪来；(b) M_GUT 绝对标度从哪来；
  (c) 三耦合是否在某处汇聚、质子是否衰变。
  (a) 几何供给 0（E4）：SU(5)/SO(10) 是群论公设，非几何第一性产物 => 撞 C1。
  (b) M_GUT≈1e16 GeV 是绝对能标，几何常数 (ℏ,G,c) 满秩给不出（承接 C0140 E4 nullity=0）=> 撞 C2。
  (c) SM 不汇聚（E3 引用 C0140）；唯一汇聚方案 MSSM 需整族新粒子+新标度；
      minimal SU(5) 质子衰变被 Super-K 排除 160×（E2 + P03）。
  => **P08 结构性负面（对 TUFT/几何框架）**；撞 C1（GUT 群 / 新重玻色子 X,Y）+ C2（M_GUT 绝对标度）。
