## 二、关键判读：R17 的「派生」是**给定场内容后复算**，不是从几何导出

这是本轮最重要的一条澄清，也是既往容易被误读成「T(R)、Y² 已经能从 TUFT 导出」的地方。

R17 §2 的派生链为：

$$Y = Q - T_3$$

其中：

- **Q**（电荷）：「已由 R10 §4 用 U(1)_em 未破缺 + 反常消除锁定为 SM 值」——**外部一致性条件**，非几何产物；
- **T₃**：由 R15 §3 的 SU(2) 表示给出——这部分**是**结群表示的产物；
- **场清单**（Q_L, u_R, d_R, L, e_R, ν_R）：直接取用 **SM 场清单**。

R17 §5 逐场列出 T(R) 与 Y² 时，输入的就是这份 SM 清单。R17 自己诚实地把这条路径定性为**收窄而非推翻**：

```
36:  [INFO] 2b | 这是对 R15 §6 FAIL 的**收窄而非推翻**：U(1)_Y 作为额外规范因子（群结构）仍不可从结群导出
```

而 R19 明确记录了「一个结 → 场名」这一步仍然缺失：

```
25:  [BOUNDARY] 残余(b)：同一代内 (j,color) 组合 → 具体场名（Q_L 双重态 vs e_R 单态、L vs ν_R）的标记是字典约定
```

⇒ **结论**：R17 证明的是「**给定** SM 场清单后，TUFT 能复算出这些场的 T(R) 与 Y²」；它**没有**证明「TUFT 能导出 SM 场清单本身」。后者正是 O-KNOTMAP，R19 判定其残余两项未消除。

这一点直接决定了第四轮 M4 的性质：M4 要求「把 $T(R),Y^2$ 编进几何」，而进去的这份谱**只能是从外部注入的 SM 谱**——第四轮原文即已点破：

```
87:  M4 谱匹配几何 | 可复现任意 b_i | 否 | 需**外部注入**规范量子数 T(R),Y² —— 正是 R12/R14 的缺口，非几何导出
```

## 三、双封口：M4 的两把锁

### 锁 A（派生侧）：导不出谱

1. **从 (Lk, κ, τ) 单独导出**：R14 范畴论证封死——结拓扑不变量与规范表示属不同数学范畴，**不存在自然函子**；信息量 1.58 bits < 需求 3.32 bits；且 R12 的 L3 路径被判为「不可计算（缺定义）」。
2. **走结群表示 π₁→G 这条唯一补救路**：R15/R16/R17 推进了 SU(2)/SU(3) 半边与 Y 的派生，但 **R19 判定 O-KNOTMAP 仍 FAIL**，残余两项（首选结 3₁ 的选择规则、场名标记字典）非派生。
3. **要有新态**：R12 判 **O-NEWSTATE**——TUFT 场内容只有螺旋结世界线，没有任何可作为规范表示新态的激发。

### 锁 B（即使侧）：导出了也不统一

这是本轮新提出的判读，且它是**独立于锁 A** 的、更强的一道封印：

> 假设锁 A 被完全攻破——即 TUFT 真的能从第一性导出完整的场内容。那么它导出的必然是 **SM 谱**（因为 TUFT 的派生目标就是 SM 的场内容与三代）。
> 而 SM 谱的 β 系数是 $b_{SM}=(41/10,\,-19/6,\,-7)$，代入第四轮的共线判据得残差 **0.0723（不共线）**，$\alpha_s$ 偏 **52.06σ**。

即：**把 T(R)、Y² 的缺口完全补上，得到的恰恰是那个 52σ 不共线的谱**。补缺口的动作本身不改变判决。

要改变判决必须有 **Δb（新态）**，而新态这边：

- R12 判 TUFT **无**新态；
- R12 §5 扫描的 12 种最简表示 × n≤8 拷贝，ΔL<1 的解全部被质子衰变排除（最优 H-like 标量×7：τ_p=4.38e24 vs 下限 2.4e34，**差 5×10⁹ 倍**）；τ_p 通过者（O₈ 标量）ΔL=20.5 根本不汇聚；
- 第四轮 M3 独立给出几何侧理由：一般双参数几何 $\mathrm{rank}\,J\le2<3$，秩亏，给不出 3 个独立 $b_i$；
- 1 TeV 带色新态被 LHC 质量下限（2–3 TeV）排除，更重的 M_new 又削弱汇聚帮助 ⇒ 「汇聚 vs 对撞机排除」张力。

⇒ **锁 A 与锁 B 同时成立，且逻辑上独立**：锁 A 说「导不出谱」，锁 B 说「就算导出了也没用」。二者任一成立即足矣封门，今二者俱在。

## 五、诚实边界与红线（本轮刻意不判）

1. **不判**「统一场论不存在」——只判「靠几何跑动 + 谱派生攻不下」。若存在真正的统一，其来源必为第四轮 §六 所指的外部物理输入（新物理/扩群/非微扰），而非本框架内的几何派生。
2. **不否定 TUFT 已成立的部分**：自旋量子化、自旋-统计、LCS 链环–CS 对接、R15/R16 的 SU(2)/SU(3) 表示可构造性、R17 的 Y=Q−T₃ 与 3 代派生、R19 的结行列式与代=3 桥接——这些均**成立**，本轮只是指出它们「给定场内容后复算」的性质，并不推翻其正确性与价值。
3. **不判** MSSM/弦论/额外维度等具体构造：第四轮已排除 MSSM 作为出路（参数数、LHC、维度-5 质子衰变），本轮不重复；弦论等未在射程内。
4. **不主张**本轮提出了新物理——本轮是**闭合性审计**，产物为文档，无新计算引擎。
5. 锁 B 的推理依赖一个前提：**TUFT 派生谱的目标即 SM 谱**。若未来出现「TUFT 派生出非 SM 的新谱」的机制，则锁 B 需重估——但那已等价于要求 TUFT 给出新态，而 R12 已判其无（O-NEWSTATE）。
