## 三、圆轨道稳定性（解析核心）

```
U(r)   = -mu e^{-r/lam}/r + h^2/(2 r^2)          （单位质量，引力 K<0）
U'=0   =>  h^2 = mu e^{-x} (r^2/lam + r)         ,  x = r/lam
U''(rc)= (mu e^{-x} / rc^3) * ( -x^2 + x + 1 )
稳定  <=>  -x^2 + x + 1 > 0  <=>  x < phi = (1+sqrt5)/2 = 1.6180339887
```
