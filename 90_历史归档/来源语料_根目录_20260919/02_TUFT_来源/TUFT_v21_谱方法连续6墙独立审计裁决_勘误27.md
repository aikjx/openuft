## 2. 联盟 v21 三条路线——逐输出复核（数字照抄落盘 out）

### 2.1 R1 包络约化全局谱（`_v21_envelope_spectrum_out.txt`）——FAIL，采纳联盟自纠

- 原判"GR 门 PASS"系判据只看 findroot 未抛异常、未看根值。按铁律（≥6 位 + N 三值收敛 + 跨盒根不变）：n0 根 0.1117/0.1536/0.3313（仅 ~1 位）、n1 实部 5.58e-10（荒谬）、跨 s_max 根 0.207/0.154/0.136 乱漂；`|det M|` 在已知根处随 N 由 1.8e-8(N24) 涨到 2.6e21(N60)（条件数，非离散误差）；findroot 被伪盒模 0.2797−0.2234 劫持。
- **唯一正面残留**：corrected O(1/s²) 出射 Robin 残差随 N 1.37e-2→1.6e-6 下降，而 bare 裸 iω 饱和在 8.8e-4（正是 v20 E443 的失败指纹）。**"出射渐近必须补到 O(1/s²)"这一方向被证实**，但深盒双侧 WKB 仍有 1e-6 残差地板、w* 邻域仅浅最小，门未过。

### 2.2 R2 本质奇点因子化递推（`_v21_essential_singularity_out.txt`）——GR 侧＝旧门复现，TUFT 侧结构墙

- 所报 GR"15/14/11 位"（mpmath dps=45，N=100/200/400/1000）参数与方法即 **Leaver s=−2 三项连分数在 Schwarzschild 上的引擎**——这是 MainAgent 早已独立采纳的 **E436–438 门（2.1e-11）的复现，不是新方法硬资产**。Schwarzschild 势为有理函数、视界/无穷均正则奇点，三项递推本就收敛。
- TUFT 侧的结构观察**成立但需限定**：因子化 ψ=e^{−2/ρ}u 消不掉动能项 ω²e^{4/ρ}P；ρ=0 处零收敛半径；物理核 ρ_h=0.6099 的 Frobenius 指标 1.8956/−0.3956，受最近奇点限制级数半径 ≈0.81、只延到 ρ≈1.42，够不到无穷远；系数 c[60]≈1.68e105 爆炸。
- **限定（重要）**：TUFT 物理域是 ρ≥ρ_h≈0.61，ρ=0 在不可达核内。该结果否定的是"**单段**有理递推/单段 Frobenius 直接贯通无穷远"，不是"TUFT QNM 原则上不可求"。多段 Frobenius 逐段 Wronskian、或紧化坐标把视界与无穷都映成正则端点，仍未被排除。

### 2.3 Cook–Zalutskas 渐近权谱（`tuft_v21_cook_zalutskas_out.txt`）——4.2e-10 **不采纳**（勘误 #27 核心）

## 6. 唯一正路（下一轮硬规格，先过 GR 再谈 TUFT）

1. **真 Cook–Zalutskas / Leaver 型紧化线性广义特征值**：共形坐标把视界 ρ_h 与无穷远映到有限两 (−1,+1)；波函数显式吸收视界入射因子与无穷远出射因子（含 O(1/s²) Robin 修正）；Chebyshev-Gauss（不含端点）；按 ω 幂分解为二次铅笔并 companion 线性化成 **(A−ωB)F=0，一次 eig，无打靶/无 findroot/无行列式门**。
2. **GR 自证门**：必须给出随 N（小 N 起）**单调指数下降**、加大 N 不崩的误差序列（拒收 N30 平台/N60 崩型），复现 0.373671684−0.088962316i **≥1e-8（争取 1e-10）**；R0/映射参数扫描一致。
3. GR 过后才把内边界换 TUFT **Neumann 反射核（壁端 Frobenius 正则权，非裸行替换）**，报 TUFT 极点必须对 N / 紧化尺度 / 近壁偏移三参数稳定 <1e-6；否则继续如实报 OPEN。
4. 备选：多段 Frobenius（核段到 ρ≈1.42 + 垒段 + 远场出射段）逐段 Wronskian。
5. **禁止重复**：腔内单向 IVP 隔离 r_b（E442）、单指数回声拟合（#25）、单端复打靶（#18/#19）、朴素有限盒 Cheb QEP（6e-3 平台）、Riccati-findroot 积分匹配（可动极点）、行列式门（条件数爆炸）、裸 iω 有限盒 Robin/CAP（8.8e-4 饱和）。
