## 10.1 sympy 验证 $d\gamma/dv=\gamma^3 v/c^2$

### 10.1.1 脚本

第二章至第三章反复使用了洛伦兹因子的导数

$$\gamma(v)=\frac{1}{\sqrt{1-v^2/c^2}},\qquad \frac{d\gamma}{dv}=\gamma^3\frac{v}{c^2}. \tag{10.1}$$

下面这段脚本用符号计算直接求导，并在 $\beta=0.6$ 处作数值验证。脚本要求安装 `sympy`，标准环境下 `pip install sympy` 即可。

```python
# verify_gamma.py — 符号验证 dγ/dv = γ^3 v / c^2
import sympy as sp

v, c = sp.symbols('v c', positive=True, real=True)

beta = v / c
gamma = 1 / sp.sqrt(1 - beta**2)          # γ(v) = (1-β^2)^(-1/2)

dgamma_dv = sp.diff(gamma, v)             # 对 v 求导
rhs = gamma**3 * v / c**2                 # 公式右边

print("dγ/dv  =", sp.simplify(dgamma_dv))
print("γ^3 v/c^2 =", sp.simplify(rhs))
print("差值 =", sp.simplify(dgamma_dv - rhs))   # 应为 0

# 数值验算：β = 0.6，取 c = 1 单位制
c_val = 1.0
beta_val = 0.6
v_val = beta_val * c_val
gamma_val = float(gamma.subs({v: v_val, c: c_val}))
lhs_val = float(dgamma_dv.subs({v: v_val, c: c_val}))
rhs_val = float(rhs.subs({v: v_val, c: c_val}))

print(f"β={beta_val}, γ={gamma_val:.6f}")
print(f"数值 dγ/dv = {lhs_val:.6f}, 数值 γ^3 v/c^2 = {rhs_val:.6f}")
print(f"相对误差 = {abs(lhs_val - rhs_val)/rhs_val:.2e}")
```

### 10.1.2 运行结果应当是什么

【推导】脚本运行后，符号部分应输出

```
dγ/dv  = v/(c**2*(1 - v**2/c**2)**(3/2))
γ^3 v/c^2 = v/(c**2*(1 - v**2/c**2)**(3/2))
差值 = 0
```

即左右两边符号表达式完全相同，差值为 `0`。这一步直接验证了第三章 (3.x) 的求导结果，不依赖任何数值近似。

数值部分代入 $\beta=0.6$：$\gamma=1/\sqrt{1-0.36}=1/0.8=1.25$；$\gamma^3=1.953125$；$v/c^2=0.6$（取 $c=1$），故 $\gamma^3 v/c^2=1.953125\times0.6=1.171875$。脚本应输出

```
β=0.600000, γ=1.250000
数值 dγ/dv = 1.171875, 数值 γ^3 v/c^2 = 1.171875
相对误差 = 0.00e+00
```

这一数值可与手算对照：$\sqrt{1-0.36}=0.8$，$1.25^3=1.953125$，乘积 $1.171875$。若脚本输出与此不同，说明符号求导或代入环节出错。

## 10.2 弹簧振子与 LC 回路的数值对照

### 10.2.1 对偶关系回顾

【推导】第二章建立的阻抗型对偶为 $m\leftrightarrow L$、$v\leftrightarrow\dot q$、$\Delta x\leftrightarrow q$、$k\leftrightarrow 1/C$。两边方程同构：

$$m\ddot x+kx=0,\qquad L\ddot q+\frac{1}{C}q=0. \tag{10.2}$$

角频率分别为 $\omega_m=\sqrt{k/m}$ 与 $\omega_e=\sqrt{1/(LC)}$。【推导】只要令 $L=m$、$1/C=k$，则 $\omega_e=\omega_m$，两系统轨迹在时间尺度上完全重合。

### 10.2.2 脚本

下面脚本用 `scipy.integrate.odeint` 数值求解两组方程，并比较 $x(t)$ 与 $q(t)$ 的相对偏差。要求 `scipy`、`numpy`。

```python
# oscillator_lc_compare.py — 弹簧振子 ↔ LC 回路数值对照
import numpy as np
from scipy.integrate import odeint

# 机械侧参数
m = 1.0
k = 4.0                       # k/m = 4  =>  ω_m = 2 rad/s
x0, v0 = 1.0, 0.0             # 初始位移 1，初速 0

# 电路侧参数（对偶：L=m, 1/C=k）
L = m
C = 1.0 / k                   # 1/(LC) = k/m = 4  =>  ω_e = 2 rad/s
q0, i0 = x0, v0               # q ↔ x, i = q̇ ↔ v = ẋ

def mech(y, t):
    x, v = y
    return [v, -k/m * x]

def elec(y, t):
    q, i = y
    return [i, -q/(L*C)]      # L q̈ + q/C = 0  =>  q̈ = -q/(LC)

t = np.linspace(0, 10, 1000)
sol_m = odeint(mech, [x0, v0], t)
sol_e = odeint(elec, [q0, i0], t)

x_m, v_m = sol_m[:, 0], sol_m[:, 1]
q_e, i_e = sol_e[:, 0], sol_e[:, 1]

# 能量
E_mech = 0.5*m*v_m**2 + 0.5*k*x_m**2
E_elec = 0.5*L*i_e**2 + 0.5*q_e**2/C

max_dev = np.max(np.abs(x_m - q_e))
print(f"机械角频率 ω_m = {np.sqrt(k/m):.4f} rad/s")
print(f"电路角频率 ω_e = {np.sqrt(1/(L*C)):.4f} rad/s")
print(f"x(t) 与 q(t) 最大偏差 = {max_dev:.3e}")
print(f"机械能量 E = {E_mech[0]:.4f} → {E_mech[-1]:.4f}")
print(f"电路能量 E = {E_elec[0]:.4f} → {E_elec[-1]:.4f}")
print(f"解析解 x(0)=1, ω=2, x(5)=cos(2*5)={np.cos(10.0):.4f}")
print(f"数值解 x(5)≈{np.interp(5.0, t, x_m):.4f}")
```

### 10.2.3 运行结果应当是什么

【推导】两组方程在 $L=m$、$C=1/k$ 下完全同构，因此 $x(t)$ 与 $q(t)$ 的最大偏差应在 $10^{-12}$ 量级（数值积分误差），而不是 $10^{-2}$ 量级。脚本应输出

```
机械角频率 ω_m = 2.0000 rad/s
电路角频率 ω_e = 2.0000 rad/s
x(t) 与 q(t) 最大偏差 = ~1e-12
机械能量 E = 2.0000 → 2.0000
电路能量 E = 2.0000 → 2.0000
解析解 x(0)=1, ω=2, x(5)=cos(10)=-0.8391
数值解 x(5)≈-0.8391
```

能量初值为 $\tfrac12 k x_0^2=0.5\times4\times1=2$，终值应保持在 $2$ 附近（误差 $10^{-10}$ 量级），这直接验证了第二章能量守恒的数值表述。解析对照 $\cos(10)\approx-0.83907$ 与数值解一致，说明 odeint 在该时间步长下收敛。

【推导】若把 $C$ 改为任意非 $1/k$ 值（例如 $C=0.3$），则 $\omega_e=\sqrt{1/(1\times0.3)}\approx1.826$，与 $\omega_m=2$ 不再重合，两条轨迹在 $t\approx 4$ 后开始明显分离。这一对照可作为对偶关系成立与否的反向测试。

### 10.2.4 量纲核对

【推导】对偶映射 $m\leftrightarrow L$、$k\leftrightarrow 1/C$ 在量纲上必须自洽。机械侧：$[m]=\mathrm{kg}$，$[k]=\mathrm{N/m}=\mathrm{kg/s^2}$，故 $\sqrt{k/m}=1/\mathrm{s}$；电路侧：$[L]=\mathrm{H}=\mathrm{kg\,m^2/(s^2\,A^2)}$，$[C]=\mathrm{F}=\mathrm{s^4\,A^2/(kg\,m^2)}$，故 $[LC]=\mathrm{s^2}$，$\sqrt{1/(LC)}=1/\mathrm{s}$。两边角频率量纲同为时间倒数，对偶才不是形式游戏。脚本中 $m=1$、$k=4$、$L=1$、$C=0.25$（即 $1/C=4$）正是按这一量纲关系取的无量纲单位。若读者想改用 SI 单位制重跑，只需把 $m$ 取真实质量（如 $0.1\,\mathrm{kg}$）、$k$ 取真实劲度（如 $4\,\mathrm{N/m}$）、$L$ 取真实电感（如 $0.1\,\mathrm{H}$）、$C$ 取 $0.25\,\mathrm{F}$，两条轨迹的相对偏差仍应保持在数值积分误差量级。

## 10.3 分形层级迭代示意脚本

### 10.3.1 脚本

【假说】第九章 (9.10) 给出从普朗克尺度到哈勃尺度的分形层级数 $N$ 与尺度比 $\mu$ 的关系。下面脚本仅作数值演示，不引入新物理。

```python
# fractal_hierarchy_demo.py — 分形层级迭代（假说层数值演示）
import numpy as np

ell_p = 1.616e-35          # 普朗克长度，m
r_H   = 4.4e26             # 哈勃半径，m

ln_ratio = np.log(r_H / ell_p)
print(f"ln(r_H / ℓ_p) = {ln_ratio:.3f}")

for N in [30, 60, 100, 200]:
    mu = np.exp(ln_ratio / N)
    # 反向重建：从 r_0 = ℓ_p 开始，每级乘 μ，验证第 N 级是否到达 r_H
    r = ell_p
    for k in range(N):
        r *= mu
    print(f"N={N:3d}: μ={mu:8.3f}, 第{N}级半径={r:.3e} m（应≈{r_H:.2e}）")

# 同时输出前 6 级半径，便于核对自相似结构
mu60 = np.exp(ln_ratio / 60)
print("\nN=60 时前 6 级半径：")
r = ell_p
for k in range(6):
    print(f"  第{k}级: {r:.3e} m")
    r *= mu60
```

### 10.3.2 运行结果应当是什么

【推导】$\ln(r_H/\ell_p)=\ln(4.4\times10^{26}/1.616\times10^{-35})=\ln(2.72\times10^{61})\approx141.6$。脚本应输出

```
ln(r_H / ℓ_p) = 141.586
N= 30: μ= 117.749, 第30级半径=4.400e+26 m
N= 60: μ=  10.851, 第60级半径=4.400e+26 m
N=100: μ=   4.134, 第100级半径=4.400e+26 m
N=200: μ=   2.033, 第200级半径=4.400e+26 m
```

【假说】这一结果对应第九章 (9.10) 的结论：$N=60$ 时尺度比约 10.85，$N=100$ 时约 4.13，$N=200$ 时约 2.03。前 6 级半径依次为 $\ell_p, 10.85\ell_p, 10.85^2\ell_p,\ldots$，构成一条离散的自相似几何序列。

【假说】必须强调：该脚本只是数学上的尺度重建，不证明宇宙真的按此分形。第九章已给出可证伪预言——CMB 大尺度功率谱应出现与 $\mu$ 相关的离散调制；在该观测结果出来之前，本节数值仅作为假说层的内部自洽性检验。

## 10.5 扩写到百万字的路线思路
