## 2. 脚本用法

### 2.1 运行

```powershell
cd D:\a10\aikjx\code\my_lib
.venv\Scripts\python.exe scripts\o4\tuft_ringdown_judge.py --input scripts\o4\regression_events.csv --output scripts\o4\regression_result.json
```

或命令行 JSON：

```powershell
.venv\Scripts\python.exe scripts\o4\tuft_ringdown_judge.py --json "{\"events\":[{\"name\":\"GWxxxx\",\"M_f\":70.0,\"a_f\":0.6,\"delta_f_percent\":3.0,\"sigma_f_percent\":2.5}]}" --output out.json
```

### 2.2 输入（CSV 列名，按需给）

- 残差模式（推荐，已破 M–χ 简并）：`delta_f_percent, sigma_f_percent, delta_tau_percent, sigma_tau_percent`。
- 原始观测模式：`M_f, a_f, f_n0_obs_Hz, f_n0_err_Hz, tau_n0_obs_ms, tau_n0_err_ms`（脚本用内置 GR 锚自算预测归算残差；未边际化，乐观上限）。
- 每行一个事件；残差列优先于原始列。

### 2.3 内置锚（照抄硬编码）

- GR n0 = 0.3736716844180418 − 0.0889623156889357i；GR n1 = 0.3467109968791653 − 0.2739148752912331i（v57 Leaver）。
- 缩放：f[Hz]=32312.5/M_f·ω_R；τ[ms]=4.9255e-3·M_f/(2|ω_I|)。
- TUFT 标称：频移 +16.26%、阻尼时间 +57.6%；灵敏带 c_m∈[−0.369,−0.218]→δω +8.82%~+21.17%。
- c_m→δω：δω(%)=−8.20−81.58·c_m（v41 E490 五点）。

### 2.4 输出（result.json 关键字段）

逐事件残差；频率/阻尼两通道 `d_hat±σ`、ΔlnL、Bayes 因子、dB、H1 排除 nσ、95% 上限；c_m 反演（及是否在 EHT 内）；四态判定 `SUPPORT / EXCLUDE / GR_WEAK / NO_RESOLUTION`。
