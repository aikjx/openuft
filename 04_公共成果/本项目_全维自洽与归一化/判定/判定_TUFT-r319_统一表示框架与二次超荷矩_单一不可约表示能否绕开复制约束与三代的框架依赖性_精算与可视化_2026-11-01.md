## 一、判决主文

**`X-R309-1` 判负关闭。**

1. **框架是必要的**，而且是**被迫**的 —— 不是因为「我们选了逐多重态」，而是因为**常数荷分配必然反常**。
2. 障碍是**四条线性反常的残差全为正**：`(4, 4, 15, 10/3)`。同号 ⇒ 无法抵消 ⇒ 唯一解 `q = 0` ⇒ `n_R = 0` ⇒ **零代**。
3. 第二路线（`q_a = q·f_a`，E6 嵌入）也被封：反常自由**强迫** `f ∝ Y` ⇒ 回到逐分量 ⇒ r309 定理 T 的 `n ≥ 9`。**无逃逸。**
4. 唯一活口是放弃「`U(1)_F` 精确无反常」。那时 `CP^n` 族上 `n_R = 3` **只有 `CP^1`，`q` 恰为 3** —— 但 `n_R` 成了自由输入。

**三代仍未被解释。** 但从 r292 到 r309 一直含在「框架假设」里的那个自由度，本卷证明它**其实不是假设**。

## 二、为什么这一卷值一整份判定册

前五卷（r294/r302/r305/r307/r309）全在攻**机制参数**：通量、荷、扭转、复制、内部维度。
r309 §十一 自己登记了下一个战场：

> 「**`X-R309-1`** ｜「每多重态各自独立指标」这个框架本身是否必要？若改用**单一统一表示**（如 `27` of E6 内含整代），本卷定理 T/U **完全不适用** —— 在那个框架里三代是**一个**指标的读数｜ **本卷最重要的边界，且是唯一可能真正解决三代问题的方向**」

这是一个**框架级**问题：如果换框架能绕过全部 NO-GO，那前五卷的结论就都是「框架产物」，价值要打折。
**本卷的答案让前五卷站住了，理由却不是维数或幂次，而是一个符号。**

## 三、§二 定理 X：先把 `27` 真拆开

不做这一步，后面全是空谈 —— 因为「`27` 无反常」是教科书结论，**引用它等于没算**。

`27 = 10 + 5 + 2·5̄ + 2·1`（经 SO(10) 的 `16 + 10 + 1`）。逐分量列出 11 个不可约块、共 27 个左手 Weyl，
逐条算五条规范反常（`[SU(3)]²Y` / `[SU(2)]²Y` / `g-g-Y` / `Y³` / `SU(3)³`）：

- `27` 整体：**五条全零**；
- **代（15 个）**：五条全零；
- **额外物（12 个）**：五条全零。

> ★ 真正重要的是第三条。如果代与额外物只是**互相抵消**，那么把代单独拿出来做判据就是错的。
> 实测是**各自独立为零** —— 这一步为后面所有「只看代」的论证买了保险。

副产物：`27` 的二次超荷矩 = `10/3 + 5/3 = 5`。

## 四、§三 定理 Y：`10/3` 这个数

一代 SM 的三个超荷矩：

```
Σ dim·Y  = 0
Σ dim·Y² = 10/3      ← 唯一的非零
Σ dim·Y³ = 0
```

**一次与三次为零，二次不为零。** 这不是巧合：`Σ dim·Y = 0` 与 `Σ dim·Y³ = 0` 是 SM 反常自由的两个条件，
而 `Σ dim·Y²` **不受任何反常条件约束** —— 它是个自由的正数，恰好等于 `10/3`。

按 SU(5) 分块复算（不同分组，同一个结果）：

| 块 | `Σ dim·Y²` |
|---|---|
| `10 = Q + u^c + e^c` | `5/2` |
| `5̄ = d^c + L` | `5/6` |
| `5 + 5̄`（额外） | `5/3` |
| `1 + 1` | `0` |
| 合计 | `5` |

**SO(10) 的 `16 = 15 + ν^c` 给 `10/3 + 0 = 10/3`** —— 与 E6 完全一样。
⇒ 障碍**不是 E6 的特征**，是「一代 SM 内容」的特征。

## 五、§四 定理 Z：为什么统一框架必然死

单一不可约表示只有**一个**指标 ⇒ 所有分量共享**同一个** `q`。于是 `A_YYF = q·Σ dim·Y²`，
`27` 给 `5q`，`16` 给 `(10/3)q`。要它为零只有 `q = 0`。

### 比预想更强：四条同时出问题

把常数向量 `(1,1,1,1,1)` 代入 r309 的四个线性反常方程，**逐条残差**：

| 反常 | 残差 |
|---|---|
| `A3 = 2q₁+q₂+q₃` | `4` |
| `A2 = 3q₁+q₄` | `4` |
| `Ag = Σ dim·q` | `15` |
| `AYY = Σ dim·Y²·q` | `10/3` |

**四条全部非零，且全部为正。**

> ★ **这才是本卷最锋利的一刀，而且它比「`10/3`」更朴素。**
> 最初步的那条是**引力反常**：`Σ dim = 15 ≠ 0`。这条谁都不能反对 —— 它不需要知道任何超荷值。
> 最模型相关的那条是 `Σ dim·Y² = 10/3`。四条一起，构成一个**过定**的否决。

### 符号论证

逐多重态时 `Y = (1/6, −2/3, 1/3, −1/2, 1)` **正负混合**，四条方程精确抵消（`A = 0`）。
常数荷没有正负混合，**结构上不可能**抵消。

**「为什么必须逐多重态分荷」的答案就是这一句：因为要抵消，就得有正有负；而一个不可约表示只给一个数。**

### 与 r309 定理 S 的对接

r309：四个线性反常矩阵**秩 4 / 5**，零空间**恰好 1 维且基向量就是 `Y` 本身** ⇒ 反常自由集 = `span(Y)`。
本卷：`Y` 有 **5 个互异值** ⇒ 「常数荷」等价于「`Y` 为常值」—— **假**。
⇒ 常数向量不在 `span(Y)` 里（除 `q = 0`）。

**两条路径不共享中间量**：r309 走的是矩阵秩，本卷走的是残差符号。

## 六、§五 定理 AA：第二路线也封

有人会说：`U(1)_F` 可以嵌在 E6 里，不同 SM 分量带不同 `f` 荷，那就不是常数荷了。

**对，但那正好回到逐多重态。** 链条：

1. 允许 `q_a = q·f_a`；
2. 反常自由（定理 S 的唯一性）**强迫** `f ∝ Y`；
3. ⇒ `U(1)_F = U(1)_Y`，通量即超荷通量；
4. ⇒ 5 个 `n_a` 必须**全部相等**；
5. ⇒ `P(Y_i)` 全等 ⇒ `P − P*` 有 **5 个根** ⇒ **4 个独立条件**；
6. ⇒ 再加 1 个非齐次（`n_R = 3`）⇒ 需 `⌈n/2⌉ ≥ 5` ⇒ **`n ≥ 9`**。

**与 r309 定理 T 逐字一致。这条路不是逃逸，是同一个牢房的另一扇门。**

### 三档判决

| 档 | `U(1)_F` | 结论 |
|---|---|---|
| ① | 精确无反常 | **零代**（定理 Z） |
| ② | 反常而重（Stückelberg / GS） | **三代**，但 `n_R = 3` 是自由输入 |
| ③ | 整体 | 无通量可言，框架自毁 |

**三档都不解释三代。** 档②唯一「有产出」，也正是 `X-R319-1` 的位置。

## 七、§六 定理 AB：档② 里能得到什么

放弃「`U(1)_F` 精确无反常」后，`A_YYF` 不再是一致性条件，障碍消失。此时在 `CP^n` 上：

```
n_R(q) = Σ_j a_j q^{n−j}/(n−j)!
```

| `n` | `dim M_int` | `n_R(q)` | `n_R = 3` 的整数解 |
|---|---|---|---|
| 1 | 2 | `q` | **`q = 3`** |
| 2 | 4 | `½q² − 1/8` | 无 |
| 3 | 6 | `⅙q³ − ⅙q` | 无 |
| 4 | 8 | `⅟24 q⁴ − 5/48 q² + 3/128` | 无 |
| 5 | 10 | `⅟120 q⁵ − 1/24 q³ + 1/30 q` | 无 |
| 6 | 12 | `⅟720 q⁶ − 7/576 q⁴ + 259/11520 q² − 5/1024` | 无 |

**只有 `CP^1`，`q` 恰为 3。** 最小内部空间 + 最小整数通量，正好三代。

★ **这不是「凑巧单调」**：`CP^6` 在 `q = 4` 处给 `2.9327`，离 3 只差 `0.0673` —— **很近但不是**。
「恰好 3」是等式，不是逼近。

★ **诚实**：`Â` 只截断到 6 阶，`n ≥ 7` 未算；`CP^n` 只是一族。**族内唯一 ≠ 全局唯一。**

## 九、§八 判定纪律与自查

本轮**没有出现伪值**（首跑 fail=2 是我抄错期望，不是引擎算错），但仍如实登记三件事：

### 1. 我抄错了两处期望值（不是引擎错）

- `B07`：我凭印象写残差是 `(4, 3, 27, 20/3)`，实测 `(4, 4, 15, 10/3)`。
  错因：把 `A2 = 3q₁+q₄` 的 `q₄` 系数算成 3（漏了一项），把 `Σ dim` 当成场数 27（应为 15），把二次矩当 20/3（应为 10/3）。
- `B09`：我原以为「只有 Y² 那条残差非零」，实测**四条全非零**。

> ★ **这两处抄错反过来改变了结论的表述**：本卷的核心不再是「`10/3` 这一条打死」，而是「四条全正 ⇒ 符号论证」。
> **抄错不可怕，可怕的是抄错后拿去凑结论。** 反抄法（从引擎读数反抄）救了这一卷。

### 2. 一个负对照自己失效了

`CTL8` 原设计：「`CP^2` 上把 `Â` 截断到 2 阶，`n_R(3)` 应该变」。
**实测不变** —— 因为 `n = 2` 时 `p₂` 项是 `x⁴`，本来就超出 `x^n`，`a_4` 根本进不来。
⇒ 负对照**恒绿**，等于没测。改为在 `n = 4` 上做（那里 `a_4 = 3/128` 真进来），才真正有判别力。

> ★ **负对照自己也要被检验。** 一个恒绿的负对照比没有负对照更危险，因为它给人「测过了」的错觉。

### 3. 守卫 G13 也抄错了

`A_FFF = Σ dim·q³ = 15q³`（不是 `27q³` —— 27 是场数，15 是维数和）。改后过。

## 十、§九 诚实边界（七条，逐条对应可能的反驳）

1. **前提可以被攻击。** 定理 Z 依赖「`U(1)_F` 是精确无反常规范对称」。这不是数学必然，是 r294–r309 一路的物理假设。放弃它 → 否决失效。
2. **放弃后的结果是真结果，但代价明确。** `CP^1` + `q = 3` 是精确整数解；但 `n_R = 3` 成了自由输入，问题从「为什么被禁止」变成「为什么取这个数」——**没变好，只变了形状**。
3. **`27` 分解是标准分解，不含具体破缺路径。** 不同破缺给不同额外物；但**代的部分 `10 + 5̄` 固定**，故 `10/3` 不变。
4. **`CP^n` 只是一族。** `n ≥ 7` 未算，非 `CP^n` 几何未算。族内唯一 ≠ 全局唯一。
5. **`c = 3` 仍是拓扑输入。** 纯复制依旧是唯一廉价解，本卷没有改变这一点。
6. **不否认前五卷任何一条。** 本卷是把「框架」当变量重算；旧结论全部保留，只在「框架是否可选」这一点上加了限定。
7. **没有新预言、没有新方案，是一次框架级审计。** 若读者要的是「三代被解释」，本卷没有给。

## 十二、§十一 遗留 OPEN

**`X-R319-1`（本卷唯一真正的第一原理问题）**
`q = 3` 由什么选定？
本卷证明：放弃反常自由后，`CP^1` + `q = 3` 是精确解。但**为什么是这个整数**？
在有通量紧致化里 `q` 是拓扑量子数，其取值由**通量量子化 + 稳定性（D 项、tadpole）**共同决定。
本卷只做了量子化（`q ∈ Z`），**没有做稳定性**。这是下一卷的正面战场。

**`X-R319-2`**
`27` 的额外物（`5 + 5̄ + 1 + 1`）抬质量后的**阈值相容性**。
本卷只核验了它们无反常（A05），**没有算 RG**。若抬到 GUT 标度，规范耦合统一是否仍成立？
量级上应该成立（E6 GUT 的标准谱），但**没算就是没算**。

**`X-R319-3`**
指标可加性在**非紧**或**带边界** `M_int` 上失效。
本卷的「常数荷 ⇒ 一个指标」依赖 `M_int` 紧致无边界（Atiyah–Singer 的前提）。
若内部空间带边界（domain wall / orbifold fixed plane），指标定理要加边界项，**结论可能改变**。

**承前仍 OPEN**：`X-R307-2`（含 Weyl 群成分的非中心扭转）｜`X-R307-3`（`π_0 = c` 能否被动力学选定）｜`X-R309-2`（加 `ν^c` 后荷空间是否升维）｜`X-R309-3`（定理 R 的 `A_k` 几何实现）。
