### A.1 氢原子线性斯塔克效应的详细推导

考虑氢原子在外电场作用下的情况，我们可以使用微扰理论来计算能级分裂。

#### A.1.1 微扰哈密顿量

外电场对氢原子的微扰哈密顿量可以表示为：

H' = -**p**·**E** = eEz

其中，**p**为氢原子的电偶极矩，**E**为外电场，假设外电场沿z轴方向，即**E** = (0, 0, E)。

#### A.1.2 氢原子的n=2能级

氢原子的n=2能级包括一个2s态和三个2p态（2p_x, 2p_y, 2p_z），这些态在没有外电场的情况下是简并的。我们需要计算这些态在外电场作用下的能级分裂。

首先，我们写出这些态的波函数：

2s态：ψ₁ = (1/(2√2πa₀^(3/2)))(1 - r/(2a₀))exp(-r/(2a₀))

2p_z态：ψ₂ = (1/(4√2πa₀^(3/2)))(r/a₀)exp(-r/(2a₀))cosθ

2p_x态：ψ₃ = (1/(4√2πa₀^(3/2)))(r/a₀)exp(-r/(2a₀))sinθcosφ

2p_y态：ψ₄ = (1/(4√2πa₀^(3/2)))(r/a₀)exp(-r/(2a₀))sinθsinφ

#### A.1.3 微扰矩阵元的计算

我们需要计算微扰哈密顿量在这些态之间的矩阵元。由于对称性，许多矩阵元为零。非零的矩阵元主要是连接2s态和2p_z态的矩阵元：

⟨ψ₁|H'|ψ₂⟩ = ⟨ψ₂|H'|ψ₁⟩ = eE⟨ψ₁|z|ψ₂⟩

计算这一矩阵元：

⟨ψ₁|z|ψ₂⟩ = ∫ψ₁^* z ψ₂ dτ = ∫ψ₁^* r cosθ ψ₂ dτ

代入波函数表达式，计算积分：

⟨ψ₁|z|ψ₂⟩ = (1/(2√2πa₀^(3/2)))(1/(4√2πa₀^(3/2))) ∫(1 - r/(2a₀))(r/a₀)r cosθ * r cosθ * r² sinθ dr dθ dφ exp(-r/a₀)

化简后得到：

⟨ψ₁|z|ψ₂⟩ = (1/(16πa₀^4)) ∫(r³ - r^4/(2a₀))exp(-r/a₀) dr ∫cos²θ sinθ dθ ∫dφ

计算积分：

∫dφ = 2π

∫cos²θ sinθ dθ = 2/3

∫(r³ - r^4/(2a₀))exp(-r/a₀) dr = a₀^4(6 - 24/2) = -6a₀^4

因此：

⟨ψ₁|z|ψ₂⟩ = (1/(16πa₀^4)) * (-6a₀^4) * (2/3) * 2π = -3a₀/2

#### A.1.4 能级分裂的计算

现在，我们需要求解微扰哈密顿量的本征值，以得到能级分裂。对于2s态和2p_z态，微扰矩阵可以表示为：

| 0        -3eEa₀/2 |
| -3eEa₀/2 0        |

这一矩阵的本征值为：

ΔE = ±3eEa₀/2

因此，氢原子的n=2能级在外电场作用下分裂为三个能级：一个中间能级（对应2p_x和2p_y态，它们的能级不变）和两个分裂能级（分别对应2s和2p_z态的混合态，能级移动±3eEa₀/2）。
