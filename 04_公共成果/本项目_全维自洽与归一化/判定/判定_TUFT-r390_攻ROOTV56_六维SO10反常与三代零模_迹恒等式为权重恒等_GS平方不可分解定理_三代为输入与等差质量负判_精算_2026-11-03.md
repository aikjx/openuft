## §〇　一句话结论

来料把一个**乘积**（`x²·J₄`）当成了**平方**（`½X₄∧X₄`），而 6D Green–Schwarz 抵消要求的正是平方；这不是拟合误差，是代数上无解。

展开成四句：

1. **主定理**：`I₈^net` 在 `span{x², trF², p₁}` 内**不可**写成 `½X₄∧X₄`。两处**独立**矛盾 —— `T²` 系数为 0 要求 `β=0`，而 `x²T` 系数为 `1/2` 要求 `αβ≠0`；`p₁²` 系数为 0 要求 `γ=0`，而 `x²p₁` 系数为 `−1/3` 要求 `αγ≠0`。
2. **迹恒等式不是证据**：`V56-1/V56-2` 是 SO(10) 权重系统的恒等式，对任意模型成立 ⇒ 判别力 0，记 IDENTITY。
3. **三代是输入**：`ind = q_F·N` 使族数**恒等于** N，N=3 是手选 ⇒ 该式是定义（与 r350、r389 同型）。
4. **等差质量被否**：最佳等差拟合要求 `m_e = −260.50 MeV`（负质量）；无量纲比 `r = (m₂−m₁)/(m₃−m₁)` 对任意等差恒为 `1/2`，实测 `0.059193`，差 **8.45 倍** —— 两条独立路径同一结论。

「16/16 通过」中，可重算的 8 个公式块里只有 **2 条**是真判据，且都不支持模型：一条不通过、一条负判。

## §二　主定理：`I₈^net` 不是完全平方

### 2.1 六维反常 8 形式的展开

`I₈ = [Â(TM)·ch₁₆(F)·(e^x − 1)]₈`，其中 `x` 是 2 形式、`T = tr₁₀F²`、`p₁`、`p₂` 是 Pontryagin 类。按形式次数拆分，只有两类配对能凑出 8 形式：

- `deg=0(Â·ch) = 16` 配 `x⁴/24` ⇒ `x⁴` 系数 `2/3`；
- `deg=4(Â·ch) = T − (2/3)p₁` 配 `x²/2` ⇒ `x²T` 系数 `1/2`、`x²p₁` 系数 `−1/3`；
- `deg=8(Â·ch)` 只能配 `(e^x−1)` 的 **deg=0** 项 —— 而它**不存在** ⇒ 纯引力项与 `trF⁴` 系数**恒为 0**。

三个系数逐位复现来料 V56-4（B1 = PASS），所以「系数算错」不成立。

### 2.2 平方结构方程

设 `X₄ = αx² + β·trF² + γ·p₁`（G12 已枚举：`deg=4` 的可用单项式恰为这 3 个），则

```
½X₄∧X₄ = α²/2·x⁴ + αβ·x²T + αγ·x²p₁ + β²/2·T² + γ²/2·p₁² + βγ·Tp₁
```

与 `I₈ = 2/3·x⁴ + 1/2·x²T − 1/3·x²p₁ + 0·T² + 0·p₁² + 0·Tp₁` 逐项比对：

| 单项式 | 平方给出 | 实测需要 | 后果 |
| --- | --- | --- | --- |
| `x⁴` | `α²/2` | `2/3` | `α² = 4/3`，可解 |
| `x²T` | `αβ` | `1/2` | 需 `αβ ≠ 0` |
| `x²p₁` | `αγ` | `−1/3` | 需 `αγ ≠ 0` |
| `T²` | `β²/2` | `0` | **⇒ β = 0**，与上一行冲突 |
| `p₁²` | `γ²/2` | `0` | **⇒ γ = 0**，与 `x²p₁` 冲突 |

**结论**：无解。两条矛盾互不依赖，任一成立即够。

### 2.3 三条抗反驳

1. **归一化无关**：把 `½` 换成任意 `λ`，得 `λβ² = 0` 与 `λαβ ≠ 0`，矛盾不变。
2. **`p₁` 块的归一化没有自由约定**（由 `Â = 1 − p₁/24 + (7p₁²−4p₂)/5760` 固定），所以「`trF²` 的归一化可疑」这条反驳只打击 T 块，打不掉 `p₁` 块。
3. **乘积 ≠ 平方**：来料写的「严格因子化」`I₈ = x²·J₄` 确实成立，但 GS 抵消要求 `I₈ = ½X₄∧X₄`。强行把 `x²T` 对上要付出 `T²` 项 `= 3/128`（B4 的精确值），而该项在原 `I₈` 里根本不存在 ⇒ 平方化会**改变**反常多项式，不是重写它。

### 2.4 边界（诚实）

「无解」限定在 `X₄ ∈ span{x², trF², p₁}`，即**当前场内容**。若引入第二族 2 形式（另一 `U(1)` 磁通）、或按来料提到的另一条路引入边界/缺陷反流，`deg=4` 空间会变大，`β`、`γ` 不再被逼为零 ⇒ 结论不适用。那属于**改变理论结构**，需另行建卷（见 §九 X-R390-1/2）。

## §三　三代数 = 输入，不是预言

`ind(Ď_q) = q·N` 是 S² 上指标定理的直接代入。取 `q_F = 1`（把完整 16 的电荷规范成 1）后：

| N | 1 | 2 | 3 | 4 | 5 | 6 |
| --- | --- | --- | --- | --- | --- | --- |
| 族数 | 1 | 2 | 3 | 4 | 5 | 6 |

族数**恒等于 N**。所以「磁通解释了三代」= 「把 3 写进磁通」。

与库内两条既有结论同型，且**不可相加**：

- **r350**：框架不预言 3（0/13）；
- **r389**：整数比搬家定理 —— 量子化不减少输入，只把参数从 `θ` 的容器搬到 `N` 的容器。

本卷新增的一点是**定位**：`N` 在 V56 里既没有内生来源，也不受拓扑约束 ⇒ 它落在「自由参数」一侧，因此 V56 对「为什么是 3」的回答信息量为 0（C3）。

## §四　质量结构：三条独立读数

### 4.1 Schur 机核（D1）

与 `J_z`、`J_x` 都对易的 3×3 实矩阵，解空间 `dim = 1`（RREF 实算）⇒ `M_f = m₀I₃`。**V56-5 正确**，但它是**负结论**：只要 Higgs 与 Yukawa 保持该 SO(3)，三代**必然**简并。

### 4.2 等差不是自动的（D4）

`⟨cosθ⟩ ∝ m`、`⟨cos²θ⟩ = m²/2` 都是 j=1 的精确矩。按 `m=+1` 对齐后：

| 剖面 | 谱 `(m=−1, 0, +1)` | 等差？ |
| --- | --- | --- |
| `cosθ` | `(1−δ, 1, 1+δ)` | **是** |
| `cos²θ` | `(1+δ, 1, 1+δ)` | **否** |

即「等差」等价于「扰动剖面严格线性」，来料 V56-6 隐含了这一假设却未声明。

### 4.3 两条独立负判

**D3（拟合路径）**：两参数等差 `(a−d, a, a+d)` 最小二乘 ⇒ `a = 627.676`、`d = 888.175`，`m_e` 的预言是 **−260.498 MeV**（负质量）。相对偏差 `m_e 510.78 / m_μ 4.94 / m_τ 0.15`。

**D5（无量纲路径）**：对任意等差三元组，

```
r ≡ (m₂ − m₁)/(m₃ − m₁) = d/(2d) = 1/2        （与 a、d、单位、归一化全无关）
```

实测 `r = 0.059193`，相对偏离 `0.8816`，即 **8.45 倍**。这条判据不含自由参数、不依赖拟合，绕开了「你拟合得不好」的反驳。

两条路径**同一结论**，按纪律不可相加计为两条发现。

## §五　四维 U(1)_F 反常：48 全来自外部

单个 16 内 SM 超荷：`Σ Y³ = 0`、`Σ Y = 0`（精确，含右手中微子 `Y=0`）⇒ SM 部分的反常在 16 内部已抵消。因此 `V56-7` 的

```
A(U(1)_F³) = 3 × 16 × 1 = 48,     A(U(1)_F·grav²) = 48
```

**完全**来自外部 `U(1)_F`，不是 SM 没配平。来料判断正确，但这也意味着：「三代 + 单一 `U(1)_F`」这条路必须破缺或引入额外轻态，否则该 `U(1)` 不是无异常的四维轻规范场。

## §八　可复用的方法与判据

1. **乘积 ≠ 平方刀**　报告「因子化/可分解」时，先问目标结构要的是**乘积**还是**平方**。`x²·J₄` 是乘积，`½X₄∧X₄` 是平方，两者差一个交叉项。
2. **纯项为零刀**　若某多项式要写成平方，则**纯项系数必须是某参数的平方**（`β²/2`、`γ²/2`）。一旦实测纯项系数为 0，对应参数被逼为零；再看混合项是否要求它非零 —— 这是最省力的不可分解判据。
3. **两条腿刀**　判负只靠一个块时，先找第二个独立块。本卷 T 块与 p₁ 块互相独立，任一被质疑都不影响结论。
4. **完备性守卫**　任何「限定在 span{…}」的结论，必须**枚举**该次数下的全部单项式（G12），否则限定是假设不是定理。
5. **无量纲比刀**　对「结构 X 是否成立」，优先找**与参数无关的比值**（如等差 ⇒ `r = 1/2`）。它同时绕开拟合质量、单位约定与归一化三个争议源。
6. **剖面线性刀**　报告等差/等比层级时，先问「哪个物理量的期望值对 `m` 线性」。换成 `cos²θ` 就破；且**只查前两个分量必假绿**（K3 已固化为读数）。
7. **对齐约定必声明**　凡比较两套谱，先写死「按哪个点对齐」。本卷按 `m=+1`；若改按 `m=−1`，K3 的假绿就复现不出来 —— 结论依赖约定时必须明说。
8. **判负要登记**　`GATES-PASS-WITH-N-NEGATIVE` + `DECLARED_NEG` 逐条登记，未登记的 FAIL 或登记了却不是 FAIL 都中断（G11）。
