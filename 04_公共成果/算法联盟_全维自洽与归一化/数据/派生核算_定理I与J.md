# 派生核算体系 UFS-Delta：定理 I / K / J / 判别式 V4

## 定理

- **定理 I（靶独立性秩定理）**：h_eff = rank(指数矩阵)；推论 I'：锚仅靶 = 依赖靶；推论 I''：h_eff <= kappa + k
- **定理 K（代数派生不可能定理）**：代数型派生 V4 <= (-rank(D_A) - nu)/(kappa + k) <= 0，判定 A 不可达
- **定理 J（纯数因子可提取定理）**：xi = q_obs/(锚组合·旋钮组合)，量纲与秩矩阵对其全盲
- **判别式 V4**：V4 = (h_eff - (f + a + nu))/h_eff

## 本册闭合的缺口

- 门槛第 2 条：h_eff 由人工判定 -> 矩阵秩可计算（定理 I）
- 定理 A7 的纯数因子盲区：单例观察 -> 逐靶机械提取（定理 J）
- V2 对 nu 盲：空口写常数会被误判 A -> V4 判 B（定理 J）
- 统一既有结论：C/E 封死代数路线、F/G 放行算子谱，是同一条秩上界的两面（定理 K）

## 已登记未闭合项（诚实）

- '先验性'无法自动核实：谎报 xi/旋钮为先验仍可刷分（自攻击 A1）
- 派生链递归未闭合：旋钮若'由另一层理论导出'，本册不再递归核算
- 谱/拓扑型靶的 h_eff 计数规则未建立：按现定义里德伯谱的无穷多条线在函数意义上只是 1 个靶，会低估'把大量测量压进一个公式'的价值（自攻击 A4）
