## 附录：角速度公式详细求导过程（基于ZUFT空间螺旋运动，无β因子）

求导核心依据：严格遵循ZUFT两大第一性原理——时空同一化公设、空间光速圆柱螺旋运动公设，结合质量几何化定义、引力场的几何诠释，全程仅通过空间螺旋运动方程求导，不引入任何额外调制因子（包括β），步骤严谨、无外来假设，具体推导如下：

### 步骤1：自由空间点螺旋运动方程定义

根据ZUFT空间光速圆柱螺旋运动公设，自由空间点（纯粹空间几何单元）的运动参数化方程为（三维圆柱坐标系，以源质量质心为原点）：

\(\boldsymbol{R}(t) = r\cos(\omega t)\boldsymbol{i} + r\sin(\omega t)\boldsymbol{j} + pt\boldsymbol{k}\)

参数说明：\(r\)为螺旋半径（空间固有几何量），\(\omega\)为空间本底角速度（待推导核心物理量），\(p\)为轴向运动速度分量，\(\boldsymbol{i}\)、\(\boldsymbol{j}\)、\(\boldsymbol{k}\)分别为x、y、z方向单位矢量，\(t\)为时间；所有参数均为空间几何固有属性，不随时间变化。

### 步骤2：速度矢量求导（一阶求导）

对自由空间点的位移矢量\(\boldsymbol{R}(t)\)求时间一阶导数，得到速度矢量\(\boldsymbol{V}(t)\)（自由空间点的运动速度）：

\(\boldsymbol{V}(t) = \frac{d\boldsymbol{R}(t)}{dt} = \frac{d}{dt}\left[r\cos(\omega t)\boldsymbol{i} + r\sin(\omega t)\boldsymbol{j} + pt\boldsymbol{k}\right]\)

分别对各分量逐项求导（利用复合函数求导法则，\(r\)、\(\omega\)、\(p\)为常量）：

- x方向分量：\(\frac{d}{dt}\left[r\cos(\omega t)\boldsymbol{i}\right] = -r\omega\sin(\omega t)\boldsymbol{i}\)

- y方向分量：\(\frac{d}{dt}\left[r\sin(\omega t)\boldsymbol{j}\right] = r\omega\cos(\omega t)\boldsymbol{j}\)

- z方向分量：\(\frac{d}{dt}\left[pt\boldsymbol{k}\right] = p\boldsymbol{k}\)

合并各分量，得到速度矢量完整表达式：

\(\boldsymbol{V}(t) = -r\omega\sin(\omega t)\boldsymbol{i} + r\omega\cos(\omega t)\boldsymbol{j} + p\boldsymbol{k}\)

### 步骤3：光速约束条件推导

根据ZUFT核心公设，自由空间点的运动速度模长恒等于真空光速\(c\)，即\(|\boldsymbol{V}(t)| = c\)。矢量模长的平方等于各分量平方和，因此对速度矢量求模的平方：

\(|\boldsymbol{V}(t)|^2 = \left[-r\omega\sin(\omega t)\right]^2 + \left[r\omega\cos(\omega t)\right]^2 + p^2\)

利用三角恒等式\(\sin^2(\omega t) + \cos^2(\omega t) = 1\)化简上式：

\(|\boldsymbol{V}(t)|^2 = (r\omega)^2\left[\sin^2(\omega t) + \cos^2(\omega t)\right] + p^2 = (r\omega)^2 + p^2\)

结合光速约束条件\(|\boldsymbol{V}(t)| = c\)，得到核心约束方程（1）：

\(c^2 = (r\omega)^2 + p^2\)  ——（1）

物理内涵：自由空间点的光速运动由“旋转分量（\(r\omega\)）”与“轴向分量（\(p\)）”构成，二者此消彼长、相互制约，总速度模长始终保持为光速\(c\)，这是空间螺旋运动的固有属性。

### 步骤4：加速度矢量求导（二阶求导）与引力场几何化

在ZUFT理论中，引力场\(\boldsymbol{A}\)的本质是空间本身的加速度，即空间位移矢量\(\boldsymbol{R}(t)\)的二阶时间导数：

\(\boldsymbol{A} = \frac{d^2\boldsymbol{R}(t)}{dt^2}\)

对速度矢量\(\boldsymbol{V}(t)\)再次求导（二阶求导），得到加速度矢量：

\(\boldsymbol{A} = \frac{d}{dt}\left[-r\omega\sin(\omega t)\boldsymbol{i} + r\omega\cos(\omega t)\boldsymbol{j} + p\boldsymbol{k}\right]\)

逐项求导（\(r\)、\(\omega\)、\(p\)为常量，轴向速度\(p\)的导数为0）：

- x方向分量：\(\frac{d}{dt}\left[-r\omega\sin(\omega t)\boldsymbol{i}\right] = -r\omega^2\cos(\omega t)\boldsymbol{i}\)

- y方向分量：\(\frac{d}{dt}\left[r\omega\cos(\omega t)\boldsymbol{j}\right] = -r\omega^2\sin(\omega t)\boldsymbol{j}\)

- z方向分量：\(\frac{d}{dt}\left[p\boldsymbol{k}\right] = 0\)

合并各分量，得到加速度矢量表达式：

\(\boldsymbol{A} = -r\omega^2\left[\cos(\omega t)\boldsymbol{i} + \sin(\omega t)\boldsymbol{j}\right]\)

加速度的模长（即径向引力加速度，体现引力的几何本源）为：

\(|\boldsymbol{A}| = r\omega^2\)  ——（2）

根据ZUFT质量几何化定义，由源质量\(M\)激发的静态球对称引力场加速度（空间本身的加速度）为：

\(|\boldsymbol{A}| = \frac{2ZM}{cr^2}\)  ——（3）

其中\(Z = \frac{Gc}{2}\)为引力光速统一常数（纯几何化常数，无任何外来参数，由G和c耦合而成）。

### 步骤5：动力学平衡与角速度公式最终推导（无β因子）

考虑测试质点（非自由空间点集合，物质粒子/天体）在源质量\(M\)的场中做稳定圆周运动：此时质点运动完全跟随自由空间点的本底旋转，空间本身的径向加速度（引力加速度）提供质点圆周运动所需的向心力，二者达到动力学平衡。

1.  圆周运动向心力公式（质点角速度与自由空间点本底角速度\(\omega\)一致）：

\(F_{\text{向心}} = m\omega^2r\)（\(m\)为测试质点质量）

2.  质点所受几何化引力（空间加速度施加的效应）：

\(F_{\text{引力}} = m|\boldsymbol{A}|\)

3.  动力学平衡条件（向心力与引力相等）：\(F_{\text{向心}} = F_{\text{引力}}\)，代入式（2）和式（3）：

\(m\omega^2r = m \cdot \frac{2ZM}{cr^2}\)

消去测试质点质量\(m\)（\(m \neq 0\)，两边同时除以\(m\)），整理得：

\(\omega^2r = \frac{2ZM}{cr^2}\)

\(\omega^2 = \frac{2ZM}{cr^3}\)

开方后，得到**纯空间螺旋运动求导的角速度公式**（无任何额外因子，仅由空间几何参数与源质量决定）：

\(\omega = \sqrt{\frac{2ZM}{c r^3}}\)  ——（4）

### 补充说明：β因子的定位（非求导必需，仅实际场景适配）

上述步骤1-5为**纯空间螺旋运动求导的完整过程**，全程未引入β因子，公式（4）是ZUFT框架下，从第一性原理推导得出的、描述空间本底角速度的核心公式，适用于理想基准态（三维欧几里得空间，无时空几何扰动）。

β因子并非求导过程的必需项，仅为适配实际宇宙的非理想场景而补充：实际中，源质量（尤其是大质量天体、微观量子系统）会对周围时空产生轻微几何扰动，导致观测角速度与理想公式（4）存在微小偏差。此时可引入几何调制因子\(\beta\)（\(\beta \propto 1+\delta\)，\(\delta\)为时空扰动程度），将源质量\(M\)修正为有效质量\(M_{\text{eff}} = \beta M\)，代入公式（4）得到适配实际观测的公式：

\(\omega = \sqrt{\frac{2Z \beta M}{c r^3}}\)  ——（6）

核心结论：空间螺旋运动纯求导可完全剔除β因子，公式（4）是纯几何动力学的核心结果，无任何外来假设；β因子仅为实际观测场景的适配补充，不影响纯求导的完整性与严谨性，也不改变公式的核心几何内涵。
