# 第一章 凝聚态拓扑现象
凝聚态物理研究大量粒子组成的宏观系统的性质，传统凝聚态物理用朗道对称破缺理论分类物相，但是近几十年发现的拓扑物相（拓扑绝缘体、拓扑超导体、量子霍尔效应等）无法用对称破缺解释，它们的性质由拓扑不变量决定，是拓扑物相。

在我们的拓扑残差理论中，凝聚态系统是低能下的拓扑螺旋集合，它们的集体激发形成宏观的拓扑结构，拓扑物相就是宏观的拓扑缺陷或者拓扑序，和我们之前说的粒子、黑洞的拓扑本质是一样的，都是拓扑螺旋的不同表现。

## 1.1 量子霍尔效应
量子霍尔效应是二维电子气在强磁场下的现象，霍尔电导是量子化的，σ_H = ν e²/h，ν是整数或者分数，这个量子化是精确的，和材料细节无关，由拓扑不变量（陈数）决定。在我们的理论中，量子霍尔效应是二维平面上的拓扑螺旋形成的朗道能级，每个朗道能级对应一个拓扑绕数，陈数就是绕数，所以霍尔电导是量子化的，是拓扑不变量，和材料无关，这是拓扑保护的结果。

整数量子霍尔效应的ν是整数，对应绕数为整数，分数量子霍尔效应的ν是分数，对应分数绕数，也就是任意子，是二维系统特有的拓扑激发，它们的统计是分数统计，不是玻色或费米统计，这是因为二维空间的拓扑和三维不同，绕数可以是分数，任意子交换会产生一个相位，不是0或者π，而是分数相位。

## 1.2 拓扑绝缘体
拓扑绝缘体是体内绝缘，表面导电的物相，表面态是拓扑保护的，不受杂质散射，时间反演对称保护的拓扑绝缘体的表面态是狄拉克锥，电子无质量，自旋和动量锁定。在我们的理论中，拓扑绝缘体是三维空间中的拓扑结，体内的电子螺旋是闭合的，所以绝缘，表面的螺旋是开放的，所以导电，表面态受拓扑保护，因为拓扑结不能被连续变形解开，所以表面态不会被杂质破坏，除非系统的能隙关闭，拓扑相变发生。

拓扑绝缘体的Z2拓扑不变量就是我们之前说的绕数模2，对应时间反演对称下的拓扑分类，和粒子的自旋模2是同一个拓扑数，都是螺旋绕数的模2结果。

## 1.3 拓扑超导体
拓扑超导体是体内超导，表面有马约拉纳零能模的物相，马约拉纳零能模是自己的反粒子，满足非阿贝尔统计，可以用来做拓扑量子计算。在我们的理论中，拓扑超导体是超导配对的电子形成的拓扑螺旋，表面的马约拉纳零能模是螺旋的端点，是拓扑保护的零能激发，非阿贝尔统计是因为交换两个马约拉纳模会产生一个非平凡的幺正变换，对应拓扑螺旋的编织，和我们之前说的粒子拓扑交换是同一个道理。

马约拉纳零能模的存在已经在实验中被观测到，比如铁基超导体的磁通涡旋中的零能模，就是马约拉纳零能模，未来可以用来做拓扑量子计算机，容错性更高，因为拓扑保护的量子比特不会被局域噪声干扰。

## 1.4 拓扑序与长程纠缠
拓扑序是一种长程纠缠的物相，没有对称破缺，但是有拓扑基态简并，分数激发，拓扑序的本质是量子纠缠的拓扑结构，在我们的理论中，拓扑序是宏观尺度的拓扑螺旋纠缠，是高维拓扑残差在低能凝聚态系统的表现，和量子引力的时空纠缠是同一个道理，时空本身就是量子纠缠的拓扑结构，凝聚态的拓扑序是时空拓扑的低能复刻。

量子纠缠的拓扑本质是拓扑螺旋的连接，两个纠缠的粒子就是两个连接的拓扑螺旋，不管距离多远，它们都是同一个拓扑结构的一部分，所以测量一个会瞬间影响另一个，这不是超光速，因为它们本来就是同一个东西，没有信息传递，只是拓扑结构的非局域性。

## 1.5 本章小结
凝聚态拓扑现象都是拓扑螺旋的宏观表现，量子霍尔效应、拓扑绝缘体、拓扑超导体、拓扑序都是不同的拓扑结构，和粒子、黑洞、时空的拓扑本质一致，都是128维超复数流形的拓扑残差在不同尺度的表现，没有新的物理，只是拓扑结构的不同尺度表现。
