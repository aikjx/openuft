G. 数值关 —— ω 场方程量纲复核 与 乘子 λ 的单位依赖（决定性问题）
------------------------------------------------------------------------------

  磁盘文档第59行给出 ω 的欧拉-拉格朗日方程：
      -□ω + (1/lambda_omega^2) omega + (2 lambda / c^2) omega = 0

  逐项量纲（提取公共因子 omega ~ T^-1 后，比较算符量纲，应为 L^-2）：
    [□]                 = L^-2
    [1/lambda_w^2]      = L^-2    (要求 lambda_w ~ L)
    [lambda/c^2]        = (M L T^-2)/(L^2 T^-2) = M L^-1      <<< 不一致
    [lambda/(hbar c)]   = (M L T^-2)/(M L^2 T^-1 * L T^-1) = L^-2   <<< 正确形式

  >>> 文档第59行【漏掉 hbar】。正确方程为
      □omega - (1/lambda_w^2) omega - (2 lambda/(hbar c)) omega = 0
      该文档宣称『量纲 12/12 闭合』，但场方程本身量纲不闭合 —— 量纲审计
      只审了拉氏量，没有审由它导出的场方程，审计覆盖面断裂。

  符号表 vs 量纲表的第二处矛盾：
    符号表写 'lambda_omega 特征波数尺度 (L^-1)'，但 ½(hbar/c)(omega/lambda_omega)^2
    要闭合到 M L^-1 T^-2，必须 lambda_omega ~ L（长度）。
    若按符号表取 L^-1，则 omega/lambda_omega ~ L T^-1，该项量纲为 M L^3 T^-2 ≠ M L^-1 T^-2。


  G3 决定性：λ 是【有量纲自由参数】(量纲=力)，而 ω 的有效质量平方 = 2λ/(ħc)。
     => 理论的一切数值预言随 λ 的取值连续变化，而 λ 的数值只能靠【选单位】确定。
    令 lambda = eta * c^4/(16 pi G)，则 lambda/(hbar c) = eta/(16 pi l_P^2)，
     有效长度标度 l_eff = sqrt(hbar c/(2 lambda)) = 4 sqrt(pi) l_P / sqrt(2 eta)：
      lambda = 1 N (SI)               -> l_eff = 1.25728e-13 m   (eta = 4.15329e-43)
      lambda = 1 dyn = 1e-5 N (CGS)   -> l_eff = 3.97588e-11 m   (eta = 4.15329e-48)
      lambda = 1 lbf = 4.448 N (英制)   -> l_eff = 5.96129e-14 m   (eta = 1.84748e-42)
      lambda = c^4/(16 pi G)  (eta=1) -> l_eff = 8.1027e-35 m   (eta = 1.0)

    >>> 同一个理论，把力的单位从牛顿换成达因，有效标度就从 1.3e-13 m 跳到 4.1e-11 m。
        物理预言依赖单位制 = 该式不是物理定律，而是【未定标的定义式】。
        这与 P-H5『不预先植入常数』一并构成：λ 本身就是一个未被任何动力学固定的有量纲输入。


  G4 文档第53行『250 位锚点』的信息含量审计：
      kappa = 1.0e-8 m^-1, tau = 2.0e-8 m^-1  ->  omega = c*sqrt(k^2+t^2) = 6.7035631523 s^-1
      (i) 这是【定义式回代】：omega 被定义成 c*sqrt(kappa^2+tau^2)，残差必然为机器零。
          残差 -> 0 不能作为公式正确的证据（代码与解析式同源，对该类错误结构性免疫）。
      (ii) kappa, tau 的取值 1e-8 / 2e-8 m^-1 无任何动力学或代数来源：
          kappa/(1/l_P) = 1.61626e-43  => 比普朗克曲率低 42.79 dex
          omega/omega_P  = 3.61406e-43  => 比普朗克频率低 42.44 dex
      (iii) 比值 tau/kappa = 2 亦为任意取值。
      >>> 该锚点判定降级为 INFO（零信息量），不得计入『250 位数值关 PASS』。
