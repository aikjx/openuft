## 一、攻靶：r295 自己留下的那个洞

r295 的定理 B 说：单一 U(1)_Y 通量给出的多重度比恒为 **1:2:1:1:1**，任何通量量子 M 都给不出等代数三代。但 r295 在判定册里自己写明了一条**未判决**的退路：

> **X-R295-1** ｜ Z_N 't Hooft 分数通量下，SM 五个表示各自的零模数如何随 Ω 的不可约分解变化？能否出现 1:1:1:1:1 的谱型？（本卷只证零曲率给零指标，未处理分数通量支）

"分数通量"意味着电荷可以不是整数，r295 的**比值**论证在字面上绕得过去——这正是它必须留成 OPEN 的原因。本卷正面处理它。

**本卷的策略不是逐个数分数通量，而是把整个可能性空间参数化**：在不引入新规范群的前提下，任何保持 `G_SM` 的背景都只由两部分刻画：

| 参数 | 含义 | 取值 |
|---|---|---|
| `M` | 沿 U(1) 的通量量子（含 Z_N 分数情形） | ±1 … ±12（穷举），符号任一 |
| `k_R` | 中心 `Z₃ × Z₂` 的 't Hooft 扭转给出的**常数截面计数** | 由中心荷机械算出，取 0/1 |

于是「等谱」变成一条**线性 + 整数**条件，而**反常自由性**把它钉死。

## 三、定理 G · 等谱锁：六条反常同时指向 c = 0

**命题**：若五个表示的多重度**完全相等**（`n_R = N` 对所有 R），且扭转项 `k_R` 均匀，则通量荷必须满足

```
q_R · dim_R = c    (c 与 R 无关，c = (N−k)/M)
```

即 **`q = c·(1/6, 1/3, 1/3, 1/2, 1)`** —— 这是"等谱"唯一允许的荷型（差一个整体标度）。

**机检**（取 c = 1，六条反常系数逐个算出）：

| 反常 | 表达式 | c=1 时的系数 |
|---|---|---|
| [SU(3)]²U(1)_F | `2q₁+q₂+q₃` | **1** |
| [SU(2)]²U(1)_F | `3q₁+q₄` | **1** |
| grav-U(1)_F | `Σ dim_i q_i` | **5** |
| U(1)_Y²U(1)_F | `Σ dim_i Y_i² q_i` | **11/6** |
| U(1)_Y U(1)_F² | `Σ dim_i Y_i q_i²` | **2/3** （∝ c²） |
| U(1)_F³ | `Σ dim_i q_i³` | **3/2** （∝ c³） |

**六条系数全部非零**（B09 = 6/6）⇒ 反常自由要求 `c = 0` ⇒ **q ≡ 0**。

> **为什么这一条是硬的**：不是"某一条反常恰好给出 c=0"，而是**六把独立的刀各自都给出 c=0**。任何试图靠调参绕开一条的尝试都会被另外五条抓住。CTL3 反证检测器有牙齿（c=1 时 A3 确实算出 1 而不是 0）。

**推论（B10，登记 INFO）**：c = 0 ⇒ 通量对谱的贡献为零 ⇒ `n_R = k_R`，只剩扭转计数。

## 四、定理 H · 扭转表：唯一等谱的扭转是平凡扭转

**'t Hooft 扭转的物理**：在 `Z₃ × Z₂` 中心上做非平凡扭转时，与扭转所在因子中心荷非零的表示**失去常数截面**（`k = 0`）；中心荷为零的表示不受影响（`k = 1`）。

**k 向量由中心荷机械算出**（`k_of()`，非手填；C02 前有 `assert` 逐项校验）：

| 扭转 | k 向量 | 不同的值 |
|---|---|---|
| T0 平凡扭转 | (1,1,1,1,1) | 1 种 ⇒ **可等谱** |
| T3 仅 Z₃ 扭转 | (0,0,0,1,1) | 2 种 |
| T2 仅 Z₂ 扭转 | (0,1,1,0,1) | 2 种 |
| T32 双因子扭转 | (0,0,0,0,1) | 2 种 |

**C03 = 3/3**：三种非平凡扭转的 k 向量**全部取两个不同的值** ⇒ 纯扭转本身已经给不出等谱。**C04 = 1**：只有平凡扭转的 k 全为 1。

**C05（闭式阻碍，与 M 无关）**：以 T3 为例，谱方程给 `q₁=q₂=q₃=N/(3M)`、`q₄=(N−1)/(2M)`；`[SU(3)]²` 方程迫使 `N = 0`；代入 `[SU(2)]²` 得残差

```
A₂ = 3q₁ + q₄ = −1/(2M) ≠ 0   对全部 24 个 M 都非零
```

⇒ **阻碍是闭式的、与通量量子完全无关**。这与 r295 的比值型阻碍同一性质：不是"某个 M 不行"，是"任何 M 都不行"。

## 五、穷举：4 扭转 × 24 个 M = 96 组

每组解一个 **9×6 的精确线性系统**（未知量 `q₁…q₅, N`；6 条方程来自谱条件，4 条来自 A3/A2/Ag/AYY；解出后再复核 AYF/AFF 两条非线性反常，最后检查 `n_R` 必须是非负整数）：

| 结果 | 组数 |
|---|---|
| 线性系统不相容 / 非线性反常不为零 | **72** |
| 线性解存在且六条反常全零 | 24 |
| 被整数性/非负性否决 | **0** |
| **给出等谱** | **24** |

- **D02 = 72**：恰为 3 种非平凡扭转 × 24 个 M ⇒ **非平凡扭转无一例外全部出局**。
- **D03 = 0**：没有一组走到整数性检查那一层才被拦下（CTL8 正对照证明该过滤器对分数谱/负谱确实判否，0 不是过滤器失灵）。
- **D04/D05 = 24 个组合，但只有 1 种谱型**：`(1,1,1,1,1)`。
- **D05b**：这 24 个全部出自 **T0 平凡扭转**、`q ≡ 0`。也就是说 **`M` 在 `q = 0` 时退化为不可观测参数** —— 24 个组合是**同一个物理**，不是 24 个解。
- **D05c = 0**：非平凡扭转给出等谱的组合数 = 0 ⇒ 定理 H 的机检形式。
- **D06 = 0**：目标 `(3,3,3,3,3)` 不可达。

### 关键负对照 CTL9

把 `n ≡ 3` 直接凑出来（`M=3`、均匀 `k=1`、`q = 2/(3·dim)`）**确实得到三代**：

```
q = (1/9, 2/9, 2/9, 1/3, 2/3)  ⇒  n = (3,3,3,3,3)  ✓
但 A₃ = 2/3 ≠ 0，A₂ = 2/3 ≠ 0  ✗
```

**三代离得只有一步，挡住它的正是反常自由** —— 这条负对照的作用是排除"是不是算术算错了"这一整类怀疑：机制真的能凑出 3，只是凑出来的东西不是自洽的 4D 理论。

## 八、分层声明（诚实边界）

1. **本卷关闭 `X-R295-1`，但不关闭高维逃逸**：CY3 / T⁶/Z₃ 仍给得出 3 代，代价是换理论 + 加 4 维 + 放弃预言力（承 r295 §六）。
2. **本卷的"全部情形"是有界的**：参数化只覆盖「保持 G_SM 的 U(1) 通量 + 中心 Z₃×Z₂ 扭转」这一族。若允许**非阿贝尔通量**（破缺 SM），等价于换理论 —— 由 S1 槽定价，不在本卷的"保持"前提内。
3. **M 的穷举是 ±1…±12**，不是全部整数。但 C05 给出的 T3 阻碍是 `−1/(2M)` 的**闭式**，与 M 无关；其余非平凡扭转同型。**有限穷举只是机检的呈现形式，判决由闭式给出**。
4. **"恰好一代"不是"预言一代"**：定理 H 说的是「在同一机制下，能等谱的只有 n≡1」，**不是**说"宇宙应该只有一代"。真实世界有三代，而机制给不出三代 —— 这正是 no-go 的内容。
5. 本卷 **41 条不可与 r142–r301 相加**（与 r295 是同一命题的两轮攻防，强度取较新的一轮）。
6. **路径依赖提醒**：本卷的荷型参数化假定了 `q_R` 只依赖表示本身（`q_R = q(R)`）。若允许荷依赖**代指标**，则"等谱"退化为逐代调节，问题不再是"机制能否给 3"，而是"3 是否被手工输入"—— 那属另一类（与 r267「独有可预言 = 0」同构）。
