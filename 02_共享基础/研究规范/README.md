## 诚实原则

- 任何未被精算审视的物理理论不能算「被验证」。
- 凡标注「【推测 / 未验证】」的内容，请勿当作已确立事实。
- 分层标注：L0 已验证 / L5–L6 理论自洽未验证 / L7–L8 推测。
