# 第一章 嘉当几何的基本公式与爱因斯坦-嘉当理论

## 1.1 黎曼几何的局限

广义相对论建立在黎曼几何基础上，使用无挠的列维-奇维塔联络。在广义相对论中，引力被解释为时空的曲率，物质的能量-动量张量是时空弯曲的源，爱因斯坦场方程为：
$$G_{\mu\nu} = 8\pi G T_{\mu\nu}$$
其中$G_{\mu\nu}=R_{\mu\nu}-\frac{1}{2}g_{\mu\nu}R$是爱因斯坦张量，$T_{\mu\nu}$是能量-动量张量。

然而，黎曼几何有一个根本的局限：它人为地将挠率设为零，忽略了物质的内禀角动量（自旋）对时空几何的影响。在1920年代，嘉当提出了更一般的几何——嘉当几何，它同时包含曲率和挠率，曲率对应能量-动量的源，挠率对应自旋的源。爱因斯坦和嘉当合作发展了爱因斯坦-嘉当理论，将自旋纳入几何描述。

**命题1.1.1（黎曼几何是嘉当几何的特例）**：当挠率$T=0$时，嘉当联络退化为列维-奇维塔联络，嘉当几何退化为黎曼几何，爱因斯坦-嘉当场方程退化为爱因斯坦场方程。因此黎曼几何是嘉当几何在忽略自旋时的低能近似。

在我们的理论中，真空的基本几何是嘉当几何，挠率和曲率是同等基本的几何量，分别对应不同的物理效应。广义相对论在描述宏观引力时非常成功，因为宏观物体的自旋密度非常小，挠率效应可以忽略；但在微观尺度（普朗克尺度）和高密度天体（中子星、黑洞）内部，挠率效应非常显著，不能忽略。

## 1.2 嘉当联络的分解

嘉当联络可以分解为列维-奇维塔联络加上挠率相关的扭率张量。

**定义1.2.1（扭率张量）**：设$\nabla$是嘉当联络，$\nabla^{LC}$是列维-奇维塔联络，定义扭率张量$K$为：
$$\nabla_X Y = \nabla^{LC}_X Y + K(X,Y)$$
扭率张量$K$与挠率张量$T$的关系为：
$$K(X,Y) = \frac{1}{2}\left(T(X,Y) - T(Y,X) - T(X,Y)\right)$$
在指标记号下：
$$K^i_{jk} = \frac{1}{2}\left(T^i_{jk} - T^j_{ik} - T^k_{ij}\right)$$

**命题1.2.1（嘉当曲率的分解）**：嘉当联络的曲率张量可以分解为黎曼曲率张量加上挠率的贡献：
$$R(X,Y)Z = R^{LC}(X,Y)Z + (\nabla^{LC}_X K)(Y,Z) - (\nabla^{LC}_Y K)(X,Z) + K(X,K(Y,Z)) - K(Y,K(X,Z))$$
因此，当挠率不为零时，即使黎曼曲率为零，嘉当曲率也可以不为零，这对应自旋产生的时空几何效应。

## 1.3 爱因斯坦-嘉当场方程

爱因斯坦-嘉当理论的场方程由最小作用量原理导出，作用量为：
$$S = \int \left(\frac{1}{16\pi G}R + \mathcal{L}_m\right) d\mu$$
其中$R$是嘉当曲率标量，$\mathcal{L}_m$是物质拉格朗日量。对度量和联络变分，得到两个场方程：

**场方程1（曲率方程）**：
$$G_{\mu\nu} - \nabla^\lambda K_{\lambda\mu\nu} + K^\lambda_{\sigma\mu}K^\sigma_{\lambda\nu} - \frac{1}{2}g_{\mu\nu}\left(K^{\lambda\sigma\rho}K_{\sigma\lambda\rho} - K^\lambda K_\lambda\right) = 8\pi G T_{\mu\nu}$$
这是爱因斯坦场方程的推广，左边是几何量，右边是能量-动量张量。

**场方程2（挠率方程）**：
$$T^\lambda_{\mu\nu} + \delta^\lambda_\mu T^\sigma_{\sigma\nu} - \delta^\lambda_\nu T^\sigma_{\sigma\mu} = 8\pi G S_{\mu\nu}^\lambda$$
其中$S_{\mu\nu}^\lambda$是自旋张量，描述物质的内禀角动量密度。

**命题1.3.1（挠率的代数性质）**：挠率方程是代数方程，不是微分方程，这意味着挠率不会传播，它是局域的，只在有自旋的地方非零，在真空中挠率为零。这与曲率不同，曲率是传播的，引力波就是曲率的传播。

这个性质非常重要，它解释了为什么我们在日常生活中观察不到挠率效应：挠率只在有自旋的物质内部存在，在真空中迅速消失，它是一种接触相互作用，其作用范围与康普顿波长相当，对于宏观物体来说这个范围可以忽略。

## 1.4 挠率的物理效应

虽然挠率在宏观尺度可以忽略，但在微观尺度和极端条件下，挠率会产生显著的物理效应：

1. **自旋-自旋相互作用**：两个具有自旋的粒子之间会通过挠率产生相互作用，这种相互作用是短程的、排斥的，它可以防止黑洞奇点的形成——当物质被压缩到普朗克密度时，挠率产生的排斥力会超过引力的吸引力，形成反弹，避免奇点。

2. **费米子的自能**：电子的自能发散问题在量子场论中需要重整化，而在爱因斯坦-嘉当理论中，挠率会给费米子提供一个自然的紫外截断，消除发散，不需要重整化。

3. **宇称破缺**：挠率是一个赝张量，它在空间反射下改变符号，因此挠率相互作用自然破坏宇称守恒，这正好对应弱相互作用的宇称破缺。我们将在第四卷证明，弱相互作用本质上就是挠率的传播效应。

4. **质子衰变**：挠率相互作用可以导致重子数不守恒，这是质子衰变的理论基础，我们将在第九卷讨论这个效应的实验检验。

## 1.5 嘉当结构方程的分量形式

为了后续计算方便，我们给出嘉当结构方程在局部正交标架下的分量形式。取正交标架$\{e_a\}$，满足$g(e_a,e_b)=\eta_{ab}$，其中$\eta_{ab}$是闵可夫斯基度量（在4维时空中是$\text{diag}(-1,1,1,1)$）。对偶标架为$\{e^a\}$，满足$e^a(e_b)=\delta^a_b$。

联络1形式$\omega^a_b$满足$\omega_{ab}=-\omega_{ba}$（度量相容性），挠率2形式$T^a$和曲率2形式$R^a_b$的分量为：
$$T^a = \frac{1}{2}T^a_{bc}e^b\wedge e^c$$
$$R^a_b = \frac{1}{2}R^a_{bcd}e^c\wedge e^d$$

嘉当第一结构方程：
$$de^a = -\omega^a_b\wedge e^b + T^a$$
分量形式：
$$T^a_{bc} = C^a_{bc} + \omega^a_{cb} - \omega^a_{bc}$$
其中$C^a_{bc}$是标架的对易子系数：$[e_b,e_c] = C^a_{bc}e_a$。

嘉当第二结构方程：
$$d\omega^a_b = -\omega^a_c\wedge\omega^c_b + R^a_b$$
分量形式：
$$R^a_{bcd} = e_c(\omega^a_{bd}) - e_d(\omega^a_{bc}) + \omega^a_{ec}\omega^e_{bd} - \omega^a_{ed}\omega^e_{bc} - C^e_{cd}\omega^a_{be}$$

比安基恒等式：
对第一结构方程外微分，得到第一比安基恒等式：
$$dT^a + \omega^a_b\wedge T^b = R^a_b\wedge e^b$$
分量形式：
$$R^a_{[bcd]} + \nabla_{[b}T^a_{cd]} + T^a_{e[b}T^e_{cd]} = 0$$

对第二结构方程外微分，得到第二比安基恒等式：
$$dR^a_b + \omega^a_c\wedge R^c_b - R^a_c\wedge\omega^c_b = 0$$
分量形式：
$$\nabla_{[a}R^b_{c]de} + T^f_{[ac}R^b_{|f|de]} = 0$$

这些恒等式是几何上的恒等式，不依赖于场方程，它们对应物理上的守恒律。

## 1.6 超复数空间中的嘉当联络

在128维超复数流形$\mathcal{M}^{128}$中，嘉当联络具有更丰富的结构，因为切空间具有超复数乘法结构。我们可以将联络1形式分解为不同次数的超复数分量：

**定义1.6.1（联络的超复数分解）**：联络1形式$\omega$作为$\mathbb{U}$值1形式，可以按超复数的次数分解为：
$$\omega = \omega^{(0)} + \omega^{(1)} + \omega^{(2)} + \omega^{(3)} + \omega^{(4)} + \omega^{(5)} + \omega^{(6)} + \omega^{(7)}$$
其中$\omega^{(k)}$是$k$次齐次超复数分量，即对应$k$个虚单位元乘积的分量。

不同次数的联络分量对应不同的物理相互作用：
- $\omega^{(0)}$：标量分量，对应希格斯场
- $\omega^{(1)}$：向量分量，对应引力场
- $\omega^{(2)}$：2-形式分量，对应规范场（电磁场、弱场、胶子场）
- $\omega^{(3)}$：3-形式分量，对应轴子场和拓扑项
- $\omega^{(4)}$：4-形式分量，对应宇宙学常数和暗能量
- 更高次分量：对应高维相互作用，在低能下被紧致化

这个分解是我们统一所有相互作用的关键：所有基本相互作用都是同一个嘉当联络的不同分量，它们的区别仅仅是超复数次数的不同，本质上是同一种几何效应。

## 1.7 真空解：常曲率常挠率空间

最简单的嘉当几何解是真空解，即没有物质的解，此时能量-动量张量和自旋张量都为零。我们寻找具有最大对称性的真空解，即常曲率常挠率空间。

**定义1.7.1（常曲率常挠率空间）**：如果嘉当流形的曲率和挠率都是协变常数，即：
$$\nabla R = 0,\quad \nabla T = 0$$
则称为常曲率常挠率空间，也称为对称空间。

**命题1.7.1（128维真空解）**：128维超复数流形的最大对称真空解是德西特-嘉当空间，其曲率和挠率为：
$$R^a_{bcd} = \frac{\Lambda}{3}(\delta^a_c g_{bd} - \delta^a_d g_{bc})$$
$$T^a_{bc} = t \epsilon^a_{bcd_1\dots d_{124}} e^{d_1}\wedge\dots\wedge e^{d_{124}}$$
其中$\Lambda$是宇宙学常数，$t$是挠率的真空期望值。

这个真空解就是我们的基态真空，它具有很小的正宇宙学常数$\Lambda\approx10^{-120}M_p^2$（自然单位制），对应我们观测到的暗能量。挠率的真空期望值为零？不，实际上挠率在真空中的期望值为零，因为挠率是赝张量，洛伦兹不变性要求真空挠率为零，只有曲率的标量部分（宇宙学常数）有真空期望值。

## 1.8 本章小结

本章我们介绍了嘉当几何的基本公式，说明了黎曼几何是嘉当几何在挠率为零时的特例，推导了爱因斯坦-嘉当理论的场方程，讨论了挠率的物理效应。我们将嘉当联络按超复数次数分解，指出不同分量对应不同的基本相互作用，这是力的统一的几何基础。最后我们给出了最大对称真空解，即德西特-嘉当空间，对应暗能量的几何起源。
