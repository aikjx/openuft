## 一、SU(3) 色挠率张量（修订）

**修订（来源）**：把"群从 U(1) 升级为 SU(3)"**如实标注为假设**——本框架（TUFT）不产生 SU(3) 结构，
故 SU(3) 是**外部输入**，不是"导出"。

**修订（代数）**：`T^λ_μν = T^a_μν·(λ^a/2)` 形式可用（8 个分量对应 8 个生成元 ✓）。
但**"色荷 = 本征值"应改为**：

> SU(3) 的**基础表示是 3 维**复矢量空间，基矢记作 (r, g, b) —— 它们是**权重态**。
> 本征值只在 **Cartan 子代数**（对角生成元 `λ₃, λ₈`，秩 2）上定义，给出 **2 个量子数** `(I₃, Y)`。
> **不存在**"3 个相互独立的色本征态"。

**修订（映射）**：`A^a_μ` 被称为"色挠率诱导势"，但**未给出 `T^a_μν → A^a_μ` 的构造**。
本修订版如实写：

> TUFT 直接采用 **SU(3) 规范场 `A^a_μ`**，其与挠率的对应关系**待建立**（属开放项）。

**修订（拉氏量）**：

```
L = −¼ F^a_μν F_a^μν + ψ̄(iγ^μD_μ − m)ψ
```

**如实声明**：这是**标准 QCD 拉氏量**（`F^a_μν = ∂_μA^a_ν − ∂_νA^a_μ + g_s f^{abc}A^b_μA^c_ν`）。
本框架"采用"它，不声称从中"导出"。

## 二、曲率饱和与势能（修订）

`K_sat = α_s/l_P²` 量纲 **PASS**（`L⁻²`）。

> **概念张力（保留标注）**：`α_s` 是**跑动耦合**（能标依赖），却在"拓扑不变量 `K_sat`"中出现——
> 拓扑不变量不应依赖跑动量。

**修订（势能标度 · 关键）**：原稿称 `K∝r ⇒ V≈σr`（线性）。
实际积分 `V(r) = ∫_{r₀}^{r} α_s K T Ω dr'`，若 `K∝r`，则

```
V ~ ∫ r' dr' ~ r²   （二次，非线性）
```

数值拟合（§6）：**`V ~ r^1.94`**。故**线性禁闭势不成立**。
要得到线性 `V=σr`，需 `α_s·T·Ω ≈ const` **且** `K ≈ const`（或 `K~r` 但 `α_s~1/r` 等补偿），原稿未给。

**修订（渐近自由类比）**：

> 渐近自由是关于**耦合随能标跑动**（`α_s(Q²)→0` 当 `Q²→∞`），**不是**"曲率不再随距离变化"。
> 原稿把"导数趋零"等同于"耦合减弱"，是**类比**，非推导。

## 三、跑动耦合（修订 · 核心）

原稿：`α_s(K) = α_s0/(1 + b0·α_s0·ln(K_sat/K))`。

**修订 1（文字与公式相反）**：

- `K → K_sat`：`ln(K_sat/K) → ln1 = 0` ⇒ **`α_s → α_s0`（有限，非 0）**；
- `K → 0`：`ln → ∞` 才是发散侧。

> 原稿文字称"`K→K_sat` 时 `α_s→0`"，与自身公式**方向相反**。

**修订 2（b0 系数）**：

| 来源 | 表达式 | 数值 |
|---|---|---|
| 原稿代码 | `(33 − 12·3)/(12π)` | **−0.0796**（错误，符号反） |
| 标准 1-loop | `(11N_c − 2N_f)/(12π) = (33−6)/(12π)` | **+0.7162** |

> 原稿把 `2N_f = 6` 误写成 `12×3 = 36`。`b0<0` 会使 `α_s` 在 `K→0` 时变为**负值**（非物理）。

**修订 3（跑动变量）**：标准 QCD 的跑动变量是**能标 `Q²`**（或 `μ²`）。
原稿用**曲率 `K`** 代替，需给出 `K ↔ Q²` 的映射（几何量→能标），否则"和标准 QCD 数学形式一致"
只是**形式巧合**（把 `Q²` 换个字母）。

## 四、胶子（修订）

- 胶子无质量（`K=0 ⇒ m=0`）**PASS**（与标准 QCD 一致）；
- 自耦合来自场处于**伴随表示**（非阿贝尔）—— 是标准 Yang-Mills 结果；
  原稿归因于"色挠率"，属**重新命名**；
- 禁闭（无自由胶子）是 QCD 的**未完全解析**现象，原稿的"锁在曲率饱和区"是**定性类比**。

## 五、夸克质量（修订 · 量纲）

原稿：`m_q = α K T^a Ω/c²` ⇒ `[m_q] = L⁻⁵T²`，**非质量 [M]**（FAIL）。

**修订**：采用量纲合法的形式（与续篇修订版一致）：

```
m_q = ℏ·Ω_w/c² ,   Ω_w = c·√(κ²+τ²)
```

量纲核验：`[ℏ]=ML²T⁻¹, [Ω_w]=T⁻¹, [c²]=L²T⁻² ⇒ [m_q]=M` ✓。

**色中性约束**：严格应为 `3⊗3⊗3` 中的**全反对称单态**（`ε_ijk`），
而非简单的"矢量和为零"。

## 六、数值验证（修订 · 正确输出）

原稿代码的可复现结果（**如实**）：

```
b0(原稿)        = -0.079577          <-- 反号（标准 +0.716197）
alpha_s(K_sat)  = 0.11800            <-- 非 0（原稿称"趋近 0"）
V(r) 标度指数    p = 1.942             <-- ~r²（原稿称"线性"）
```

**修订后的代码**（关键修正：b0 符号 + 如实输出 + 势能标度）：

```python
import numpy as np
alpha_s0 = 0.118
K_sat = 1.0
r0 = 1.0
Nc, Nf = 3, 3
b0 = (11*Nc - 2*Nf) / (12*np.pi)     # = +0.7162（修正）

def alpha_s(K):
    return alpha_s0 / (1 + b0*alpha_s0*np.log(K_sat/K))

r = np.logspace(-2, 2, 300)
K = np.where(r < r0, K_sat, K_sat*(r/r0))
al = alpha_s(K)
dr = np.diff(r, prepend=r[0])
V = np.cumsum(al*K*dr)

print("alpha_s(K_sat) =", alpha_s(K_sat))   # ~0.118（非 0）
print("alpha_s(k->0)  =", alpha_s(1e-6))    # -> 1/b0 (~1.4)，增强
# V(r) 标度：r>>r0 时 V ~ r^2（非线性），非 sigma*r
```

> 修正后：`α_s` 在 `K→K_sat` 时 → `α_s0`（有限）；`K→0` 时**增强**（`→1/b0`）——
> 与"高能/短距渐近自由"的**方向相反**（因为把 `K` 当作 `Q²` 的替换是错的）。
> 这进一步说明 §3.3 的"跑动变量替换"是核心症结。

## 八、诚实边界与结论

1. **本框架未产生 SU(3)**：色挠率是把 U(1) 手性挠率**命名升级**为 SU(3) 值，而不是推导出 SU(3)。
2. **"解析导出渐近自由/色禁闭"不成立**：线性弦势被证否（`V~r²`）；跑动公式与文字相反、`b0` 反号。
3. **质量公式量纲非法**（与续篇同一缺陷），须改用 `m=ℏΩ_w/c²`。
4. **红线**："色挠率 → QCD"作为**方向性类比**可以讨论，但作为"解析推导"在本册中**未成立**；
   与标准 QCD 的一致性也不构成对 QCD 的新解释。
