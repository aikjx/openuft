# ROOT V19.0｜从规范对称性进一步追查精细结构常数的本源

这一轮找到了一条比继续增加六维带电零模更有效的路线：直接利用标准模型一代粒子的手征表示，实现规范反常抵消，再检验统一规范群能否决定电磁耦合。

这条路线已有可靠的物理基础。Particle Data Group 在 2025 年大统一理论综述中明确讨论了标准模型的粒子表示、SU(5) 的电荷量子化，以及 SO(10) 使用一个 16 维旋量容纳一代物质的机制。

## 一、从一代物质出发，而不是制造大量额外粒子

采用全部左手 Weyl 场表示，并令电荷算符：

\[ Q_{\rm em}=T_3+Y \]

| 场              | \(SU(3)\times SU(2)\) | 超荷 \(Y\) | Weyl 分量数 |
| -------------- | ----------------------- | ---------- | -------- |
| \(Q_L\)      | \((3,2)\)             | \(1/6\)  | 6        |
| \(u^c\)      | \((\bar3,1)\)         | \(-2/3\) | 3        |
| \(d^c\)      | \((\bar3,1)\)         | \(1/3\)  | 3        |
| \(L\)        | \((1,2)\)             | \(-1/2\) | 2        |
| \(e^c\)      | \((1,1)\)             | \(1\)    | 1        |
| 可选 \(\nu^c\) | \((1,1)\)             | \(0\)    | 1        |

这一套物质的规范反常抵消不需要 V18 中那种额外的 30 个带电手征零模。

最关键的问题随之改变：规范群为什么能够确定电荷的相对比例，却仍然可能无法决定电磁作用的绝对强度？

下面将通过精确反常计算以及三种规范耦合的实际运行验证这一点。

## 二、精确证明：规范反常全部抵消

对上一节的一代粒子，分别计算：

\[ \mathcal A_{SU(3)^2U(1)} =2\left(\frac16\right)-\frac23+\frac13=0 \]

\[ \mathcal A_{SU(2)^2U(1)} =3\left(\frac16\right)-\frac12=0 \]

\[ \mathcal A_{U(1)^3} =6\left(\frac16\right)^3+ 3\left(-\frac23\right)^3+ 3\left(\frac13\right)^3+ 2\left(-\frac12\right)^3+1=0 \]

混合引力反常同样为零。实际运行 SymPy 后，四项恒等式均严格化简为 0。

而且，一代标准模型有：

\[ N_{\text{SU(2)双重态}}=3+1=4 \]

为偶数，因此满足避免 Witten \(SU(2)\) 全局反常的奇偶条件。

这提供了一条比 V18 更好的研究基准：先使用已知一致的手征规范结构，再考虑空间几何如何产生它。

## 三、更深一步：反常抵消甚至不能唯一决定电荷

在加入右手中微子 \(\nu_R\) 的情况下，定义连续变化的超荷：

\[ \boxed{Y_t=Y_{\rm SM}+t(B-L)} \]

其中 \(t\) 是任意实数。

我对这组电荷重新执行了四类反常计算，结果为：

\[ \boxed{ \begin{aligned} \mathcal A_{SU(3)^2U(1)}(t)&=0\\ \mathcal A_{SU(2)^2U(1)}(t)&=0\\ \mathcal A_{U(1)^3}(t)&=0\\ \mathcal A_{\mathrm{grav}^2U(1)}(t)&=0 \end{aligned} \quad\forall t\in\mathbb R} \]

甚至四个常规 Yukawa 项仍然保持规范不变。

[图注] 连续超荷家族的实际计算图

即使局域反常全部消失，仍可以连续改变超荷。此类变化一般会使中微子带电，因而与真实电磁实验不符；它证明的是反常条件本身不具有唯一选择能力。

重要结论：对称性、反常抵消、质量项规范不变性，单独放在一起仍不足以唯一决定电磁耦合。

自然界的粒子电荷必须通过更完整的结构或实验约束来确定。

## 四、SU(5) 能从群论算出什么？

从五维基本表示中的超荷生成元：

\[ Y_5=\operatorname{diag} \left(-\frac13,-\frac13,-\frac13,\frac12,\frac12\right) \]

得到：

\[ \operatorname{Tr}(Y_5^2)=\frac56 \]

利用 \(SU(5)\) 生成元的标准归一化：

\[ \operatorname{Tr}(T^2)=\frac12 \]

严格推出：

\[ g'=\sqrt{\frac35}\,g_U,\qquad g_2=g_U \]

所以：

\[ \boxed{\sin^2\theta_W(M_U)=\frac38} \]

进一步：

\[ \boxed{\alpha_{\rm em}(M_U)=\frac38\alpha_U} \]

这是非常重要的数学结果：统一规范群能够固定耦合之间的相对关系。

但 \(\alpha_U\) 仍然未定。例如，无论取 \(\alpha_U=0.02\) 还是 \(0.04\)，群表示与上述 \(3/8\) 关系都依然成立。

[图注] SU5 的连续统一耦合参数

群论决定直线斜率 3/8，却不决定沿着直线的具体位置。因此仍缺乏唯一的 α 数值。

这与 PDG 2025 GUT 综述（rpp2025-rev-guts）中的标准 SU(5) 归一化一致。

## 五、实际精算：三个规范耦合能否汇聚？

从标准模型三代费米子和一个 Higgs 双重态出发，我独立计算了规范耦合的一圈系数：

\[ \boxed{ (b_1,b_2,b_3) =\left(\frac{41}{10},-\frac{19}{6},-7\right) } \]

使用一圈重整化群方程：

\[ \frac1{\alpha_i(\mu)} = \frac1{\alpha_i(M_Z)} -\frac{b_i}{2\pi}\ln\frac{\mu}{M_Z} \]

以 PDG 2025 的 \(\overline{\mathrm{MS}}\) 电弱参数和强耦合中心值为输入：\(\alpha_{\rm em}^{-1}(M_Z)=127.930\)、\(\sin^2\theta_W(M_Z)=0.23122\)、\(\alpha_s(M_Z)=0.1180\)。

得到：

| 规范耦合                | \(M_Z\) 处的倒数 |
| ------------------- | -------------- |
| \(\alpha_1^{-1}\) | 59.010015      |
| \(\alpha_2^{-1}\) | 29.579975      |
| \(\alpha_3^{-1}\) | 8.474576       |

### 消去统一耦合与统一能标

如果最简的一圈无阈值统一成立，那么：

\[ \boxed{ \frac{\alpha_1^{-1}-\alpha_2^{-1}} {\alpha_2^{-1}-\alpha_3^{-1}} = \frac{b_1-b_2}{b_2-b_3} } \]

这是一项不依赖未知统一耦合与统一能标的检验。

## 六、改变物质结构之后，结果会发生什么？

为了验证问题确实来自粒子谱与量子运行，而不是单纯计算错误，我使用理想化 MSSM 的一圈系数：

\[ (b_1,b_2,b_3)= \left(\frac{33}{5},1,-3\right) \]

重新计算同一个无参数比值：

\[ \boxed{ \frac{b_1-b_2}{b_2-b_3} =\frac75=1.4 } \]

这与前述实验输入计算的 1.394432 接近。

| 比较                           | 最简标准模型  | 理想化 MSSM |
| ---------------------------- | ------- | -------- |
| 耦合差值预测比                      | 1.89565 | 1.40000  |
| 实验输入比                        | 1.39443 | 1.39443  |
| 由电弱输入预测的 \(\alpha_s(M_Z)\) | 0.07115 | 0.11684  |
| 实验 \(\alpha_s(M_Z)\)       | 0.11800 | 0.11800  |

MSSM 这里的计算假定整个区间使用同一组一圈系数，尚未正确加入超对称粒子阈值。因此只能视为诊断性对照，不能据此证明超对称存在。

但它清楚揭示：规范耦合的运行由量子物质谱决定，不能只靠一个孤立的空间曲率常数得到完整答案。

## 九、下一步真正值得集中攻破的地方

接下来不宜再只改变整数磁通、旋转角或增加粒子数量，而应研究能否由一个确定的几何作用量固定统一规范场的动能归一化。

在规范场作用量：

\[ S_{\rm gauge} =-\frac{1}{2g_U^2} \int\operatorname{Tr}(F\wedge *F) \]

中，群论能够决定 \(\operatorname{Tr}\) 的规范化关系，却没有自动决定前面的 \(1/g_U^2\)。

所以 ROOT V20 的决定性数学问题是：

\[ \boxed{ \text{几何与量子动力学} \overset{?}{\Longrightarrow} g_U^2=\text{唯一确定值} } \]

然后才可能计算：

\[ g_U \longrightarrow g_1(M_Z),g_2(M_Z) \longrightarrow \alpha_{\rm em}(M_Z) \longrightarrow \alpha(0) \]

所有阈值和量子修正也必须明确。

本轮确实缩小了未知问题：相对电荷、规范反常和部分统一比例能够从代数结构中求出；绝对耦合强度仍然需要独立的动力学选择机制。 目前还没有证明出自然界的 \(1/137.035999177\)，但现在可以更精确地判断下一种候选理论究竟有没有真正解决它。
