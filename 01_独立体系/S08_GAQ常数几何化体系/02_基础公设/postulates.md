## 1. 本体立场

本体系（GAQ v5）在 v4 复曲率本体上推进"终极几何化"：把光速 c 与作用量子 ħ 从公理常数降为螺旋几何的运动学/量子化桥梁，电荷 e 降为导出量。声称为"100% 零人为常量，仅 (κ, τ) 两个几何量"。

## 4. 空缺

- "2 个常数即完备"是压缩主张，未提供对 (κ, τ) 的独立测量手段或失效阈值。
- 自称"104 项精算 100% 通过"，多属代数恒等与 CODATA 回算；无独立观测检验。

## 5. 第一性冲突登记（2026-09-15）

- **冲突一（继承 v4）**：S08-A2 与 `G = c³/(ℏ(κ²+τ²))` 联立 ⇒ `m = m_P` 唯一解，与 `m_p/m_e = 1836.15` 冲突 **1835.15 倍**。完整推导见 [普朗克锚定谬误冲突记录](../11_证伪与反例/普朗克锚定谬误冲突记录.md)。
- **冲突二（方向误置）**：`c`、`h`、`k_B`、`e` 在 SI 2019 后是**定义常数**（精确值，不确定度为零）。「由几何导出 c、ħ」等价于「导出米与千克的定义」，属**单位换算而非物理预言**。在自然单位（`c = ℏ = G = 4πε₀ = 1`）下它们全部归一为 1，残留的只有无量纲量。
- **第一性靶心**：`α = 1/137.036`、`m_μ/m_e = 206.768`、`m_τ/m_e = 3477.2`、`α_S`、`α_grav` ——本体系压缩掉的是单位换算因子，**这些无量纲量一个都未被导出**。
- **自由度裁决**：归一化后仍剩 **2 个**外部输入（α 与 m/m_P）。故「零自由参数」应表述为「**无拟合参数**」，而非「无外部输入」；本体系并未比标准模型减少自由参数，只是把参数换成了几何语言（形式增益，非信息增益）。
