## 一、LCS-4：反常消除作为超荷的拓扑约束

### 1.1 约束系统

取一代费米子，手性加权（左手 +、右手 −）。设超荷为 `Y_Q, Y_L, Y_u, Y_d, Y_e`（及可选的 `Y_ν`）。

| 反常 | 系数表达式 | 物理含义 |
|---|---|---|
| `[SU(3)]²U(1)` | `2Y_Q − Y_u − Y_d` | 色流与超荷流的混合 |
| `[SU(2)]²U(1)` | `3Y_Q + Y_L` | 弱流与超荷流的混合（3 为色数） |
| `[grav]²U(1)` | `6Y_Q + 2Y_L − 3Y_u − 3Y_d − Y_e − Y_ν` | 引力–超荷混合 |
| `[U(1)]³` | `6Y_Q³ + 2Y_L³ − 3Y_u³ − 3Y_d³ − Y_e³ − Y_ν³` | 纯超荷三角图 |

SM 值代入四条**全部精确为 0**（sympy 有理数，非数值近似）——这是 SM 最非平凡的内部自洽性。

### 1.2 最小 SM（无 ν_R）：立方反常的闭式约化

由三条线性约束直接解出（以 `q ≡ Y_Q`、`x ≡ (Y_u − Y_d)/2` 参数化）：

```
Y_Q = q,   Y_L = −3q,   Y_u = q + x,   Y_d = q − x,   Y_e = −6q
```

代入 `[U(1)]³`，sympy 精确给出：

> **公式 ①（新）**　`[U(1)]³ = 18·q·(9q² − x²)`

即反常消除**不是**给一个孤立解，而是给出两个分支：

| 分支 | 条件 | 说明 |
|---|---|---|
| **A** | `x = +3q` | 含 SM |
| **B** | `x = −3q` | u↔d 互换（电荷共轭镜像解） |
| 退化 | `q = 0` | 夸克无超荷，被观测排除 |

**关键**：反常消除**直接锁定了 `x = ±3q`**——上、下型夸克的超荷差被约束为 `6q`，不再是自由参数。

### 1.3 U(1)_em 未破缺：唯一的物理输入，锁死全部超荷

分支 A 下的电荷谱（`Q = I₃ + Y/2`）：

```

Q(d_L) = −1/2 + q/2     Q(d_R) = −q
Q(ν_L) = 1/2 − 3q/2     Q(e_L) = −1/2 − 3q/2
                        Q(e_R) = −3q
```

物理条件：**电磁 U(1)_em 未破缺** ⇒ 每个 Dirac 费米子左右手电荷必须相等（否则质量项禁戒、光子获得质量）。

> **公式 ②（新，本册核心）**　`Q(u_R) = Q(u_L)` ⇒ `2q = 1/2 + q/2` ⇒ **`q = 1/3`** 唯一

代入分支 A 得 `x = 3q = 1`，于是：

```
Y_Q = 1/3,  Y_u = 4/3,  Y_d = −2/3,  Y_L = −1,  Y_e = −2      ← 精确等于 SM
```

**这条链的力度在于它不是拟合**：`q = 1/3` 这一个值同时使 `Q(d_R)=Q(d_L)`、`Q(e_R)=Q(e_L)` 自洽（sympy 交叉验证通过），

## 四、LCS-3：为何 3+1 维只有玻色与费米

这是本册唯一带"解释力"的结构性结论。

| 维度 | 世界线拓扑 | 交换群 | 允许统计 |
|---|---|---|---|
| 2+1 | 辫（braid） | 辫群 `B_n` | 任意子（相位连续） |
| **3+1** | 可互相绕过 | **`B_n` 退化为置换群 `S_n`** | **仅 ±1** |

`S_n` 的一维表示只有两个：平凡表示 `(+1)` 与符号表示 `(−1)`。代入 LCS-1 的 `φ = −2π·Lk/k`，
要求 `exp(iφ) ∈ {±1}`，对 `Lk = 1` 得 **`k ∈ {1, 2}`**：

```
k = 1  ⇒  exp(−2πi) = +1  ⇒  玻色
k = 2  ⇒  exp(−πi)   = −1  ⇒  费米
k ≥ 3  ⇒  相位非 ±1  ⇒  任意子（仅 2+1 维可实现）
```

**于是 TUFT 的"Lk 奇/偶 ⇒ 费米/玻色"判据（R2/R9）获得了定位**：
它正是 **level `k = 2` 分支的 Z₂ 统计**。这不是新预言，但它解释了 TUFT 判据**为何成立**——
因为在 3+1 维，辫群退化使统计只能是 Z₂。

> **诚实边界**：3+1 维只允许玻色/费米是标准结论（DHR / 拓扑自旋公理）。
> 本册未产生新粒子、新统计或新可检验信号。

## 五、Witten 全局反常：一个"恰好失效"的约束

`π₄(SU(2)) = Z₂` ⇒ 左手 SU(2) 双重态个数 `N_d` 为奇数时理论不自洽。
每代双重态数 = `N_c`（Q_L 有色）+ 1（L 无色），故：

> `N_d = N_gen · (N_c + 1)`，要求 `N_d ≡ 0 (mod 2)`

| N_gen \ N_c | 2 | 3 | 4 | 5 |
|---|---|---|---|---|
| 1 | 3 ✗ | 4 ✓ | 5 ✗ | 6 ✓ |
| 2 | 6 ✓ | 8 ✓ | 10 ✓ | 12 ✓ |
| **3** | 9 ✗ | **12 ✓ ← SM** | 15 ✗ | 18 ✓ |
| 4 | 12 ✓ | 16 ✓ | 20 ✓ | 24 ✓ |

SM `(3, 3)` 满足。但：

> **开放项 O-NGEN（诚实负结论）**：`N_c = 3` 为奇数 ⇒ `(N_c+1) = 4` 为偶数
> ⇒ `N_gen(N_c+1)` 对**任意** `N_gen` 恒为偶数，**约束退化为恒真**。
> 观测的 `N_c = 3` 恰好使这条约束对代数完全失效。TUFT 亦无 `N_gen=3` / `N_c=3` 的拓扑推导。

> 可算推论：若 `N_c` 为偶数，则 `N_c+1` 为奇数 ⇒ 必须 `N_gen` 为偶数。
