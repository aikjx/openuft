## 第一部分：理论谱系与已证明定理

### 1.1 三重奏定理（核心几何基石，已严格证明）

**定理（全维三重奏定理，R4–R9 完整证明）**：

对匀速 m 平面超螺旋曲线 $\mathbf{r}(t)$ 满足 $\mathbf{r}''=A\mathbf{r}'$（$A=\mathrm{diag}(\omega_1 J,\dots,\omega_m J,0)$ 斜对称常数），其 Frenet 曲率满足：

$\sum_{i=1}^{D-2} \kappa_i^2 = \frac{\sum_{j=1}^{m} \omega_j^2}{v^2} = -\frac{\mathrm{tr}(A^2)}{2v^2}$

D=4,m=1 退化为经典三重奏：

$\boxed{\kappa^2 + \tau^2 = \left(\frac{\omega}{v}\right)^2}$

**证明方法**：Frenet 标架归纳法（R9），基础步 $B\mathbf{e}_1=\mathbf{x}''=\mathbf{e}_1'$，归纳步利用 $B$ 斜对称性 $+\mathbf{x}^{(i+1)}\cdot\mathbf{e}_j=-\mathbf{x}^{(i)}\cdot\mathbf{e}_j'$ 证明 $W_i'=|W_i|\cdot B\mathbf{e}_i$，再由 $\mathbf{e}_i\cdot B\mathbf{e}_i=0\Rightarrow|W_i|'=0\Rightarrow\mathbf{e}_i'=B\mathbf{e}_i$ ∎

**验证精度**：250 位 mpmath，4/6/8/10 维相对差≤1e-30；20 组随机参数全维定理全部成立（≤8.3e-29）。

### 1.2 梯度磁场精确性定理（R11，新突破）

**定理**：对方向不变的任意空间梯度磁场 $\mathbf{B}(\mathbf{x})$，带电粒子轨迹的三重奏精确成立：

$\kappa^2 + \tau^2 = \left(\frac{qB(\mathbf{x})}{mv}\right)^2$

**解析证明**：由运动方程 $x''=-\omega_c(x)y',\ y''=\omega_c(x)x'$ 代数推导 $\kappa^2=\omega_c^2 v_\perp^2/v^4,\ \tau^2=\omega_c^2 v_\parallel^2/v^4\Rightarrow\kappa^2+\tau^2=\omega_c^2/v^2$ 精确恒等。

**验证精度**：mpmath 50 位，梯度磁场 $B(x)=B_0+gx$（g=50 T/m）中电子轨迹三重奏中位相对差 **1.17e-18**（浮点极限）。

### 1.3 绝热三重奏定理（R10）

对缓变频率 $\theta(t)=\omega_0 t+\frac{1}{2}\varepsilon t^2$，$\sum\kappa_i^2=(\theta'/v)^2[1+O(\varepsilon^2)]$（小 ε 斜率≈2，一阶修正自动抵消）；**b=0 纯圆周时修正精确为 0**（相对差 3.9e-31）。

## 第二部分：大统一力方程

### 2.1 核心方程

基于空间光速螺旋统一场论动量定义 $\mathbf{P}=m(\mathbf{c}-\mathbf{v})$（静止动量 $\mathbf{p}_0=m_0\mathbf{c}_0\neq0$），对时间求导得：

$\boxed{\mathbf{F} = \frac{d}{dt}[m(\mathbf{c}-\mathbf{v})] = \underbrace{\mathbf{c}\frac{dm}{dt}}_{\text{电场力}} - \underbrace{\mathbf{v}\frac{dm}{dt}}_{\text{磁场力}} + \underbrace{m\frac{d\mathbf{c}}{dt}}_{\text{引力/核力}} - \underbrace{m\frac{d\mathbf{v}}{dt}}_{\text{惯性力}}}$

### 2.2 四力分解



| 分量      | 表达式                  | 物理意义        | 力程                |
| ------- | -------------------- | ----------- | ----------------- |
| 电场力     | $\mathbf{c}\,dm/dt$  | 沿光速矢量（直线方向） | 长程                |
| 磁场力     | $-\mathbf{v}\,dm/dt$ | 沿物体速度（旋转方向） | 长程                |
| 引力 / 核力 | $m\,d\mathbf{c}/dt$  | 光速矢量方向变化    | 引力长程 r⁻²，核力短程 r⁻³ |
| 惯性力     | $-m\,d\mathbf{v}/dt$ | 加速度反方向      | —                 |

**极限验证**：



* 当 $\mathbf{c}=$常矢量，$dm/dt=0$：$\mathbf{F}=-m\,d\mathbf{v}/dt=m\mathbf{a}$ ← 牛顿第二定律 ✓

* 电 / 磁力比 $|\mathbf{F}_e|/|\mathbf{F}_b|=c/v$ ← 电磁波 E=cB ✓

### 2.3 能量 - 动量关系分析

**关键发现**：统一场论动量定义 $\mathbf{P}=m(\mathbf{c}-\mathbf{v})$ 与相对论 $\mathbf{P}=\gamma m_0\mathbf{v}$ 本质不同（静止动量≠0），导致能量 - 动量关系形式不同。

4 种质速 × 能量组合分析（F1 验证）：



* 组合 A（m=m₀/(1-v/c), E=mc²√(1-v²/c²)）：$E^2-(Pc)^2=m_0^2c^4\cdot 2(v/c)/(1-v/c)$ ≠ 常数

* 组合 B（m=m₀/(1-v/c), E=mc²）：≠ 常数

* 组合 C（m=γm₀, E=m₀c²）：≠ 常数（因 P=m (c-v)≠γmv）

* 组合 D（标准相对论 P=γmv, E=γm₀c²）：$E^2-(Pc)^2=m_0^2c^4$ ✓

**结论**：若保持统一场论动量定义 P=m (c-v)，则能量 - 动量关系不为常数；若要求 E²-(Pc)²=m₀²c⁴，须改用相对论动量。这是框架差异，非简单不自洽，需实验判定。

## 第三部分：核力场与短程相互作用

### 3.1 核力场方程

$\mathbf{D} = -\frac{Gm}{r^3}\left(\mathbf{c} - 3\frac{\mathbf{r}}{r}\dot{r}\right)$

当 $\dot{r}=0$ 时：$\mathbf{D}=-Gm\mathbf{c}/r^3$，势能 $V_N=-Gmc/(2r^2)$。

### 3.2 短程性验证



| 尺度 r (fm) | 核力 / 引力比 | 备注    |
| --------- | -------- | ----- |
| 0.5       | 6.0e23   | 原子核内部 |
| 1.0       | 3.0e23   | 核表面   |
| 1000(1pm) | 3.0e20   | 原子尺度  |
| 1m        | 3.0e8    | 宏观    |

**核力 / 引力比 = c/r**，在原子核尺度 (r\~10⁻¹⁵m) 核力比引力强 3e23 倍 ✓

### 3.3 耦合常数问题

用引力常数 G 计算核力势能：V\_N (1fm)=1e14 MeV，比实验值 (\~50MeV) 大 13 个数量级。

**反推核力耦合常数**：$k_N = 2|V_{\text{target}}|r^2/(mc) \approx 3.2\times10^{-23}\ \text{m}^3/(\text{kg·s}^2)$，$k_N/G \approx 4.8\times10^{-13}$（注：此处 k\_N 比 G 小，因 G 用于引力场定义而核力场需重新定义耦合）。

**结论**：核力场的 r⁻³ 短程结构正确，但耦合常数需替换为强耦合常数，不能直接用 G。
