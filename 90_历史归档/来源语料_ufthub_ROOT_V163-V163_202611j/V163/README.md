# ROOT V163：非线性电动力学与引力联合审计

## 结论及范围
本轮是已知 Einstein–NLED 理论的独立推导与数值复算，不是新四力统一证明。仅设 c=1；[ħ]=M L，[G]=L/M。模型为单不变量 H(F)，纯磁、静态球对称，非零磁通量；场方程在 r>0 成立。非零磁通量不能穿过一个光滑、无源且可收缩的球面而保持非零，故即使度规中心正则，也不代表完整规范场在中心光滑或已构造真实粒子。

## 求导
S=∫√(-g)[R/(16πG)-ħ H(F)]d⁴x，F=FμνF^μν/4，度规 -+++。[F]=[H]=L^-4。Tμν=ħ(H_F Fμα Fν^α -gμνH)。磁场 B=Q_m/r²，F=Q_m²/(2r⁴)。ρ=ħH，p_r=-ρ，p_t=ħ(2FH_F-H)。

A=1-2Gm/r；m'=4πr²ρ，取 m(0)=0（无独立中心点质量）。由于 p_r=-ρ，另一度规函数可取常数。应力守恒 p_r'+(ρ+p_r)A'/(2A)+2(p_r-p_t)/r=0，由 F'=-4F/r 恢复。径向类时测地线 r¨=-A'/2=-Gm/r²+4πGrρ（以固有时间求导），不是任意加速度测量仪读数。R_scalar=32πGħ(H-F H_F)。

## 传播判据
局部惯性系纯磁背景 B 沿 z，波矢沿 x。δD=H_F δE，δH_vec=H_F δB + H_FF B(B·δB)。由 Maxwell 旋度方程得到一个速度平方 1，另一个 v²=1+2F H_FF/H_F。H_F>0 且 H_F+2F H_FF≥0 是所检验方向的必要条件，不等于全局动态稳定性。若两者对所有 F≥F0 成立，则 (√F H_F)'≥0，积分得到 H(F)≥H(F0)+2√F0 H_F(F0)(√F-√F0)，中心必有发散密度。这是已知正则磁黑洞限制的一种简单推导。对 H∼C F^p（C>0,p>0，导数同阶渐近），局部 v²→2p-1；质量中心积分∫r^(2-4p)dr 当且仅当 p<3/4 收敛。故 1/2≤p<3/4 可以兼有有限质量和非负渐近 v²，但中心仍奇异；p=1/2 需要检查次领先项。

## 无量纲计算
x=r/L0，f=L0^4 F=x^-4（选择 Q_m=√2），H=L0^-4 h(f)，γ=4πGħ/L0² 独立无量纲参数，I(x)=∫0^x t²h(t^-4)dt，m=4πħ I/L0。A=1-2γI/x，r¨L0=γ(x h-I/x²)，R_scalar L0²=8γ(h-f h')。扫描 γ=0.1；未用物理数据拟合。Rational 和 Arctan 有有限度规曲率中心，但规范场强发散且 v²<0；Log 总质量有限、中心曲率发散且 v²<0；Born-Infeld 一栏仅指 H(F)=√(1+2F)-1 的单不变量纯磁分支（不是完整双不变量 BI），总质量有限、中心曲率发散，所检验特征速度在任意有限 F>0 为正。Maxwell 的中心总质量积分发散；不绘制 m(0)=0 的曲线。
