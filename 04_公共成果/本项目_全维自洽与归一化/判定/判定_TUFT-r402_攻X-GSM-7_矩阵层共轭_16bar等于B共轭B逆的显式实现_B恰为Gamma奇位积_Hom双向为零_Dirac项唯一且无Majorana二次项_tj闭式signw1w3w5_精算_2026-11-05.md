## 十五、结论

1. **矩阵层不等价的机制**：交缠算子须与 5 个 Cartan 同时对易 ⇒ 支撑只能在同权位，而两类权互为取反且宇称不同 ⇒ `Hom(16,16bar)` 与 `Hom(16bar,16)` 支撑双向为 0；`Hom(16,16)` 只有标量（实维 2 = 复 1）。
2. **共轭算子显式存在且不是外来构造**：`B = T0^T` 满足 `rhoM·B == B·conj(rhoP)`（`0/45`）、`B·B^T = I`、实化秩 32 ⇒ `16bar = B·conj(16)·B^{-1}`；`t_j = sign(w1·w3·w5)` 给出其全部列值。
3. **B 的身份**：`B` 就是 Clifford 代数奇位 Gamma 积 `Γ₀Γ₂Γ₄Γ₆Γ₈`（mask `341`）的换块作用；解空间的另一个复方向是偶位积 mask `682`（块标量 `(−i, +i)`）。
4. **质量项的可算账**：`16×16` 与 `16bar×16bar` 二次不变量支撑均 0 ⇒ 单个 16 无 Majorana 二次项；`16×16bar` 不变量复维 1 ⇒ Dirac 质量项唯一。
5. **边界**：以上均为表示论读数，绑定 r397 起的 Gamma 相位口径；质量数值、Yukawa、混合角、`126bar` 三线性不在本卷。独有预言 0、不占度。
