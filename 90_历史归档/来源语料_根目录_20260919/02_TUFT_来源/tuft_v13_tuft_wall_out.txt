------------------------------------------------------------------------------
E354  TUFT 度规与内壁 (定义层)
------------------------------------------------------------------------------
  ds^2 = -A(r) dt^2 + B(r)^{-1} dr^2 + r^2 dOmega^2,  M=1
  A(r) = exp(-2/r)
  B(r) = exp(+2/r) (1 + c_m/r^2 + d/r^3)
  内壁 (B=0, 度规退化处 = 量子引力壁/Planck star 反射面):
      1 + c_m/r_h^2 + d/r_h^3 = 0  <=>  r_h^3 + c_m r_h + d = 0
  无 d 时: r_h = sqrt(-c_m)
    c_m=-0.50, d=0     -> r_h = 0.70711 M
    c_m=-0.29, d=-0.05 -> r_h = 0.60990 M  (核验: 0.6099^3-0.29*0.6099-0.05=0)

------------------------------------------------------------------------------
E355  乌龟坐标与 RW 主方程
------------------------------------------------------------------------------
  dr*/dr = sqrt(B/A) = exp(+2/r) sqrt(1 + c_m/r^2 + d/r^3)
  壁面处 B->0, 故 dr*/dr ~ sqrt(r-r_h) -> 0, r*_h 有限 (可积).
  RW 主方程 (l=2 引力, s=-2 主势沿用 v8/v12 线约定):
      d2psi/dr*2 + [ omega^2 - V(r) ] psi = 0
      V(r) = A(r) l(l+1)/r^2 = exp(-2/r) * 6 / r^2
  势垒峰: dV/dr=0 -> r=1, Vmax=6 e^{-2}=0.8120 (与 c_m 无关).

------------------------------------------------------------------------------
E356  外边界条件 (r* -> +inf)
------------------------------------------------------------------------------
  V->0,  psi ~ A_out e^{+i omega r*}  (纯出射; 无 e^{-i omega r*} 入射支).
  对数导数匹配:  (psi_{,r*}/psi) |_{r*_out} = + i omega.

------------------------------------------------------------------------------
E357  内壁反射边界  *** 公设 W1 (AXIOM, 非 GR 导出) ***
------------------------------------------------------------------------------
  公设 W1: TUFT 壁为理想反射镜, 吸收率 sigma_abs=0, |R|=1 (E114).
  主边界 (Neumann, 沿用 v8 线):  psi_{,r*} |_{r*=r*_h} = 0
      -> 波腹, 反射振幅 R=+1, 反射相位 phi_R = 0.
  敏度变体 (Dirichlet): psi|_{r*_h}=0 -> 波节, R=-1, phi_R=pi;
      该变体把腔模频率平移半阶, 作为量级不确定度单列, 不吸收进结论.
  为何标为公设: 量子引力壁的反射相位无法由经典 GR 固定; 此处显式取
  Neumann 为工作假设, 其阶数效应由 Dirichlet 对照检验.

------------------------------------------------------------------------------
E358  混合特征条件 (内壁 Neumann + 外出射)
------------------------------------------------------------------------------
  从壁面 s=r*-r*_h=0 出发, 取 psi(0)=1, psi_{,s}(0)=0 (Neumann),
  向外积分至 s_out, 要求
      F(omega) = psi_{,s}/psi - i omega = 0   (复方程 -> 两实条件).
  与 GR Leaver 的差别: GR 在 r*->-inf 用正则性锁死纯入射支 e^{-i omega r*};
  TUFT 壁在有限 r*_h, 两支都有限, 由公设 W1 的 Neumann 锁相对系数.
