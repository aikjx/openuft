# ch18 可证伪性检验清单

> 本章核心问题：**框架在哪一步会被实验杀死？每一句"预言"的证伪条件是什么？**

## 18.1 可证伪性原则波普尔科学划界标准：**一个理论必须说出"什么实验结果会证明我错了"**。不可证伪的陈述不是科学断言，而是信仰或叙事。本书据此为框架的每个核心主张配一份"证伪卡"。## 18.2 框架核心主张的证伪卡| # | 框架主张 | 证伪条件（什么结果=框架错） | 当前约束 ||---|---|---|---|| F1 | $v\equiv c$ 全域约束 | 发现超光速信号传播或洛伦兹破坏的方向依赖效应 | 未发现（Lorentz 检验极严） |
| F2 | 32 维流形 | 若额外维尺度可测且与预言不符；或严格证明最大维数≠32 | 亚毫米额外维已被排除，但高维可紧化到不可测 |
| F3 | 曲率谱=频率（公理二） | 找到不满足 $\kappa^2+\tau^2=k^2$ 的自由几何结构且其物理对应矛盾 | 几何部分恒成立，物理对应无法直接检验 |
| F4 | 从几何导出 α | 框架给出推导但与实验 α 不符；或无法给出推导（现状） | 无推导（OPEN-M1） |
| F5 | 暗物质=几何投影 | 几何预言的质量分布与旋转曲线/透镜数据不符；或暗物质被直接探测且非几何 | 无预言（OPEN-C1） |
| F6 | 暗能量=几何 | 状态方程 $w(z)$ 的测量与几何预言不符 | 无预言（OPEN-C1） |
| F7 | 调解哈勃张力 | 机制预言与 CMB-S4/DESI/Euclid 结果冲突 | 无机制（OPEN-H1） |
| F8 | 意识=几何自我指涉 | 无法定义任何可测指标（当前即此状态） | 不可检验（OPEN-C2） |

## 18.3 框架的"最弱环节"排序按"最容易被证伪/最影响全局"排序：1. **OPEN-M1（常数推导）**：没有它，框架的"统一"落空——但也不能"证伪"，只能"证伪未完成"；
2. **OPEN-C1（暗物质/能量）**：这是框架唯一可能被天文数据直接判死刑的环节；
3. **OPEN-H1（哈勃张力）**：下一代巡天数据将在 5 年内收敛；
4. **OPEN-G1（几何→规范群）**：框架统一叙事的数学根基，缺失即"断裂"而非"证伪"。

## 18.4 已受实验约束、仍与框架相容的空间框架的普适主张目前**没有**与任何已确认实验冲突（因为它没有可检验预言）。这既是优点也是问题：**不与实验冲突 ≠ 被实验支持**。本书明确：相容性是必要条件，不是证据。## 18.5 证伪与验证的不对称：为什么"没被推翻"不值钱科学方法论有一条常被忽略的规则：**证伪是决定性的，验证是累积的**。- 一个预言被实验推翻 → 理论（在那一处）**死**；
- 一个预言被实验确认 → 理论（在那一处）**活一天**，但永远可以等下一个更严的检验。

框架目前的状态是"**既没被推翻，也没被确认**"——因为它还没有输出任何能被检验的具体预言。**这既不是优势也不是污点，而是"尚未进入科学检验阶段"的客观描述**。本书把它写进证伪卡的意义在于：让框架的每一项主张都有明确的"死亡条件"，从而把它从"叙事"推向"可检验理论"。

## 18.6 什么证据才算"支持框架"（而非"不排除框架"）**不合格的支持**（经常被误用）：- "框架与现有数据相容"——任何未做预言的理论都与数据相容；
- "框架的方向与某候选相似"——相似不是机制；
- "框架能重新表述已知事实"——重述不是预言。

**合格的支持**（三条至少其一）：

1. **新预言被确认**：框架独立预言了某个 SM/ΛCDM 之外的量，且实验确认；
2. **老谜题被解开**：框架独立推出 α / Koide / 暗物质分布 / $H_0$，精度达实验水平；
3. **竞争被排除**：框架预言与某候选互斥，而数据支持框架。

**目前三项支持均为零**。这不是坏事——它意味着框架的"支持度评分表"还是空白，而空白与"满分"之间的每一步都清晰可查。

## 18.7 一张"反证追踪表"的使用方法本书为框架研究者提供一张实用表：每当框架做出新预言，就登记一行：| 预言 | 发布时间 | 实验 | 灵敏度 | 结果 | 判定 |
|---|---|---|---|---|---|
| （示例）几何暗物质晕轮廓 $v(r)$ | 待填 | DESI / 旋转曲线 | 待填 | 待填 | 待填 |

**用法的纪律**：预言一旦登记，不可在结果不利时悄悄修改；要改必须重新登记并注明变更。这张表若能被认真维护，框架就从"叙事"变成了"可审计的科研项目"——这正是诚实审计宪章第 8 条（可证伪性优先）的落地工具。

## 18.8 一个"证伪演练"：如果框架声称了暗物质轮廓为了让证伪方法落地，做一个完整的演练（假设框架未来给出如下预言）：**假想预言**：几何暗物质晕的旋转曲线为 $v(r)=v_0\tanh(r/r_0)$（示意）。

**证伪流程**：

1. **预登记**：在反证追踪表登记 $v_0,r_0$ 的预测值及误差；
2. **数据对照**：用数千个星系的旋转曲线数据拟合，比较预测与实测；
3. **判据**：若实测 $\chi^2$ 与预测相差 $\gg1\sigma$，或形状系统偏离，则**该预言被证伪**；
4. **后果**：若预言被证伪，框架的"几何暗物质=该函数"版本死亡——但框架可提出新预言并重新登记（这是允许的，只要明确变更）。

**这个演练说明三件事**：证伪是**具体的**（必须针对可计算的量）、**可反悔的**（换个预言可重来，但要透明）、**不伤害纲领本身**（一次证伪杀死的是一句话，不是整个方向）。框架要成熟，就必须学会在这种"预言-证伪-修正"的循环里生存，而不是躲在没有预言的舒适区。

## 18.9 框架当前的"舒适区"与"必答题"**舒适区（无风险地带）**：重述已知物理、整理恒等式、给出方向性叙事——这些永远不会被证伪，也永远不会被证实。**必答题（有风险地带）**：给出可计算的 α、暗物质轮廓、$H_0$ 机制、质量谱——这些可能被证伪，但也只有它们才能让框架成为科学。
**本书的明确态度**：框架必须离开舒适区，走进必答题。**停留舒适区的统一理论，是安全的，也是无效的**——它既不会被杀死，也不会活过来。ch18 的意义，就是把"离开舒适区"从一句忠告变成一张可操作的清单。

## 18.10 与主流候选的"证伪交叉点"框架不是在与真空辩论——它要与在场的其他候选同台竞技。列出这些交叉点，有助于判断框架的每一次"新预言"是否真正区分于现状：| 竞争对手 | 主战场 | 框架若想胜出的证伪交叉点 |
|---|---|---|
| WIMP/轴子（粒子暗物质） | 直接探测实验 | 框架必须解释：为何粒子暗物质至今零发现（LZ/XENONnT），且同时给出能与直接探测区分的天文预言 |
| MOND（修改引力） | 星系旋转曲线 | 框架与 MOND 共享"尺度选择性"难题：为何小尺度无效应、星系尺度有效；框架必须比 MOND 多做一步——在星系团尺度不自相矛盾 |
| 早期暗能量（EDE） | CMB + 距离阶梯 | 框架的 $H_0$ 机制与 EDE 在参数空间重叠，必须给出可区分的 $w(z)$ 特征 |
| 弦论/圈量子（量子引力） | 普朗克尺度 | 框架的 32 维假设与弦论高维猜想共享"额外维"舞台，必须给出弦论/圈量子无法给出的可测预言 |
| 标准量子力学解释（测量问题） | 贝尔实验、退相干 | 框架的意识主张（OPEN-C2）若不能给出区别于标准退相干叙事的实验，就与"最小解释"不可区分 |

**这张表的用途**：它不是"对手名单"，而是"区分度清单"。框架的每一个新预言，都应该能回答一个问题——"这个预言如果是真的，会不会让上面某个候选死亡？"如果答案是"不会"，那这个预言就是"相容性"而非"竞争性"，价值有限。**科学的进步，恰恰发生在两个候选说出互相排斥、而数据只让一个活下来的时刻**（ch18 全章的方法论在 18.10 落地为一张可操作的交叉点表）。

## 18.11 【审计框 18】- 可证伪性标准 → 【已证实-方法论】。- F1–F8 全部主张 → 无一条已通过"预言-验证"闭环；F1–F3 是重述/恒等式，F4–F8 未兑现。- 框架当前状态：**无实验冲突，也无实验支持**——这正是"纲领"而非"理论"的标志。

## 18.12 【大白话】科学的"入场券"不是"说得通"，而是"敢被推翻"。本书给框架发了一张清单：**每句大话旁边都写明了"什么情况算你错"**。比如你说暗物质是几何投影——好，那请给出星系转得多快的具体预言；如果算出来和天文望远镜看到的不一样，你就错了。现在这张清单的诚实状况是：**框架一句大话都还没到"被验证或被杀"的环节，因为它还没把话说到能测的程度。** 这不是坏消息，而是它现在的位置——站在科学的起跑线上，还没起跑。
