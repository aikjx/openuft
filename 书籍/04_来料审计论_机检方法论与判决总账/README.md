## 一、这本书回答的唯一大问题

来料几乎不算错——那么「它算对了」和「它预言了」之间差什么？本书的答案是四类可印出来的形状：**双射（0 bit）、坐标伪影（任意目标可造）、自由除数（整数住在定义因子裡）、状态条件（codim 零测）**，以及一条准入线：**自由度账 $n_{\text{free}}\le n_{\text{obs}}-1$** 与**通过率定价**。

## 五、诚实边界

1. **覆盖面由针的形状决定**：28/139 是现有三把尺可解析的面数；111 份未提取是模板异代，不是缺陷，也不许并入平均。
2. **PASS 高不等于主张成立**：568 条 PASS 绝大多数住在 A/B 层，含义是「来料没算错」；判决层几乎单向转否。
3. **不裁定不是否证**：BOUNDARY 与 O 层全部标「未算」。
4. **无观测侧**：本书审计文本的内部一致性与既有常数（CODATA/PDG）的归属关系，不做测量、不与实验装置对接。
5. **不裁物理真**：不判「空间光速螺旋是否为真实自然图景」，只判「这句话此刻是否构成可被否证的预言」。
6. **收录 ≠ 背书**：来料原文以正本形式逐字留档于各卷 `数据/`，本项目不因本书而认可其物理主张，也不因本书否认其代数计算。

## 六、复跑（三台仪器，见第八章）

```bash
cd openuft/书籍/04_来料审计论_机检方法论与判决总账/精算
python -X utf8 audit_corpus_census.py > _census_report.txt 2>&1; echo "RC=$?"
```

期望 `RC=0`、`对照 10/10 绿`、末行 `CENSUS-GREEN`。对照未全绿 ⇒ 脚本 `return 2` 且**不印任何聚合数**——此时本书上表的读数一律不得引用。
