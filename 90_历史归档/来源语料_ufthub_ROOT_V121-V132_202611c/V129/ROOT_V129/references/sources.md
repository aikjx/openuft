# ROOT V129 文献与数据来源（截至 2026-11-21）

1. **C. Giunti and A. Studenikin, Neutrino electromagnetic interactions: a window to new physics.** *Reviews of Modern Physics* **87**, 531–591 (2015). DOI: 10.1103/RevModPhys.87.531. https://harvest.aps.org/v2/journals/articles/10.1103/RevModPhys.87.531/fulltext 。特别见第 578–579 页、Eqs. (7.1)–(7.16)：超荷异常抵消、添加右手中微子的 B-L 混合，以及 Majorana 质量的限制。注意其 Y 约定是 `Q = I3 + Y/2`，而本报告的 Y 是一半。
2. **D. Harlow, B. Heidenreich, M. Reece, T. Rudelius, The Weak Gravity Conjecture: A Review.** *Reviews of Modern Physics* **95**, 035003 (2023). DOI: 10.1103/RevModPhys.95.035003. https://link.aps.org/accepted/10.1103/RevModPhys.95.035003 。见 Eq. (51)–(56)：圆周紧致、KK 光子规范耦合和 KK 质量谱。此处借用的是明确写出的维度约化数学式，不是把 WGC 猜想当成已被证实的物理定律。
3. **Phys. Rev. D 100, 075016 (2019), Scherk–Schwarz orbifolds at the LHC.** https://journals.aps.org/prd/abstract/10.1103/PhysRevD.100.075016 。说明普通 5D 圆周模型存在手征零模障碍，以及 orbifold 等边界条件的一个常见应对途径。
4. **Hattori, Matsunaga, Matsuoka, Semidirect product gauge group and quantization of hypercharge.** *Phys. Rev. D* **83**, 015009 (2011). https://doi.org/10.1103/PhysRevD.83.015009 。说明超荷分配与规范群全局结构及量子反常的共同关系，群的 Lie algebra 名字本身不唯一确定超荷。
5. **Coleman–Mandula / Haag–Łopuszański–Sohnius 相关讨论。** https://link.springer.com/article/10.1007/s00220-017-2951-5 。空间时间对称性与内部对称性的非平凡合并存在特定假设下的严格限制；不应无条件拿此定理否定高维场论或超对称。
6. **Particle Data Group, 2025 particle properties listings** https://pdg.lbl.gov/2025/listings/particle_properties.html 。电子、μ 子有相同大小的电荷但不同质量；数值校验中固定 `m_e = 0.51099895000 MeV`、`m_mu = 105.6583755 MeV`（两者为所选参考数值）。
7. **CODATA constant conventions**: speed of light exactly `299792458 m/s`; Planck length numerical input `1.616255e-35 m`, reduced Planck length defined here as `sqrt(8π) × l_P`; fine structure inverse `137.035999177`, hbar `1.054571817e-34 J s`, electronic mass `9.1093837015e-31 kg`。数值精度仅表示运算输入，不构成独立实测。

**审计声明**：所有涉及“ROOT 新发现”的文字严格以该版独立计算和可验证公式为限。本报告的反常消除定理、KK 质量塔和规范耦合关系均来自已有文献。文献的存在及其数学结构支持所列前提，不能作为 ROOT 四力统一成立的证据。
