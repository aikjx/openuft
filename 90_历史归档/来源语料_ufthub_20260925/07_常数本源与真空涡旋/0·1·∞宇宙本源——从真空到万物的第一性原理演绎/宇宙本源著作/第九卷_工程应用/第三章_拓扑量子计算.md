# 第三章 拓扑量子计算
量子计算是下一代计算技术，利用量子叠加和纠缠进行计算，但是传统量子计算的量子比特很容易退相干，对噪声很敏感，需要量子纠错，很难扩展。拓扑量子计算利用拓扑保护的量子比特，不受局域噪声影响，不需要量子纠错，是容错的量子计算，是量子计算的终极方案。

## 3.1 马约拉纳零能模与拓扑量子比特
我们之前说过，拓扑超导体的涡旋中心有马约拉纳零能模，马约拉纳零能模是非阿贝尔任意子，交换两个马约拉纳零能模会产生非平凡的幺正变换，也就是编织操作，这些编织操作就是量子门，量子信息存储在多个马约拉纳零能模的拓扑态中，局域的噪声不能改变拓扑态，所以量子比特是拓扑保护的，不会退相干，容错性极高。

拓扑量子比特的信息是非局域存储的，不是存储在单个粒子上，是存储在多个马约拉纳零能模的整体拓扑结构中，局域的扰动不能改变拓扑结构，所以不会有退相干，这是拓扑保护的本质，和我们之前说的拓扑稳定性是一样的，拓扑结构不能被局域扰动改变。

## 3.2 拓扑量子计算的实现
现在拓扑量子计算的主要实现方案是用半导体纳米线和超导体近邻效应，或者铁基超导体的磁通涡旋，产生马约拉纳零能模，然后进行编织操作，实现量子门。微软已经研究了很多年，最近已经观测到马约拉纳零能模的证据，未来10-20年可能实现拓扑量子比特。

拓扑量子计算一旦实现，就可以解决经典计算机不能解决的问题，比如大数分解（破解RSA加密）、量子化学模拟（设计新药、新材料）、优化问题、人工智能等，会带来计算技术的革命，比传统量子计算更容易扩展，因为不需要复杂的量子纠错。

## 3.3 我们的理论对拓扑量子计算的指导
我们的拓扑残差理论可以指导拓扑量子计算的材料设计，因为我们知道拓扑物相的拓扑本质，知道什么样的材料会有马约拉纳零能模，什么样的拓扑结构可以实现更多的量子门，甚至可以设计更高维的拓扑物相，实现更强大的拓扑量子计算，比如利用高维拓扑螺旋的非阿贝尔任意子，实现更高效的量子计算。

## 3.4 本章小结
拓扑量子计算是容错的量子计算，利用马约拉纳零能模等非阿贝尔任意子的拓扑保护，实现不退相干的量子比特，我们的理论可以指导拓扑量子材料的设计，拓扑量子计算会带来计算技术的革命。
