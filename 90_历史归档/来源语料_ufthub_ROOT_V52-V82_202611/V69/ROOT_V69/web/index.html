为什么微重力不等于没有地球引力？

MICROSCOPE 在约 710 km 高空实验，仍受约 7.95 m/s² 的地球万有引力。卫星与试样共同自由落体，因此加速度计的支持力接近零。

为何元素影响星体结构？

元素、温度、状态方程决定内部密度与质量分布；在固定 M、R 的球对称牛顿外部场中，元素标签并不单独改变单极引力。组成依赖新力需由实验验证。

为什么不能由各星体反求 G？

轨道通常测得的是 μ=GM，变换 G→kG 与 M→M/k 不改变 μ。想独立预测 G，必须提供与观测 G 无关的微观尺度和耦合机制。
