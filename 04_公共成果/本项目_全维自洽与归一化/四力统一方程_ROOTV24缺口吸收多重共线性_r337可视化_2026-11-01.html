A01 · 缺口分解与守恒：R=9.04800000000000000000000E+0 = ΣH(轻子 4.30604007178719421644711E+0 + 夸克 4.97907010390643756155610E+0) + 过头量 2.37110175693631778003206E-1（PASS）

定义总缺口 R ≡ α⁻¹(0)−α⁻¹(m_Z) = 137 − 1.27952000000000000000000E+2 = 9.04800000000000000000000E+0（这是「把 137 搬到 m_Z」必须发生的下降量）。机器分解：轻子三味贡献 4.30604007178719421644711E+0、五味夸克（流质量）贡献 4.97907010390643756155610E+0，合计施加下降 9.28511017569363177800321E+0；而只需 9.04800000000000000000000E+0 ⇒ **越过锚 2.37110175693631778003206E-1**（α⁻¹(m_Z)=1.27714889824306368221997E+2 vs 锚 1.27952000000000000000000E+2）。守恒恒等式 ΣH + R_full − R = 3.80000000000000000000000E-58（机器零）⇒ 分解无遗漏、无重复计数。

A02 · 真空极化工具与 r321/r328 同源自算（H(1)=1.92353209028294044992602E-2，相对差 4.62267611654367767351285E-59）（PASS）

本卷独立实现闭式与 mpmath 90 位求积，在 q=1 给 H(1)=1.92353209028294044992602E-2，与求积相对差 4.62267611654367767351285E-59；与 r321 的 1.92353209028294044992602E−2、r328 A02 同值 ⇒ 三卷工具同源且各自可复现（交叉印证·不重复计数）。

A03 · 方向反转：轻子档欠 4.74195992821280578355289E+0、加夸克后**过** 2.37110175693631778003206E-1 ⇒ 锚被夹在中间（PASS）

只用轻子三味：α⁻¹(m_Z)=1.32693959928212805783553E+2，**高于**锚 4.74195992821280578355289E+0（欠）；再把五味夸克（流质量）加进来：1.27714889824306368221997E+2，**低于**锚 2.37110175693631778003206E-1（过）。⇒ 场内容旋钮**从上方扫到下方、跨过锚**，而 r328 已证明换一套夸克质量口径还能再动 1.81 ⇒ 该旋钮的扫描区间严格覆盖锚。**这是本卷 X1 的事实基础：缺口不是「差一点没凑上」，而是「旋钮一转就跨过去」**。

B01 · ★K1 耦合坐标旋钮：容量**无界**（α⁻¹=150−c，c 连续）；吸收 R 只需 c=2.20480000000000000000000E+1（PASS）

Möbius v=u/(1−cu) 把两参数 (A,B) 压成一个不变量，u*=1/150 与 v*=1/137 只差一个 c。由于 c 是**连续实数**，α⁻¹=150−c 可取任意实数 ⇒ 该旋钮的容量**无界**，单独就足以 100% 吸收任何缺口（吸收 R=9.04800000000000000000000E+0 只需 c=2.20480000000000000000000E+1；来料取 c=13 恰好落在 137）。⇒ 「137」不是预测值，而是 c 的**一次取值**。（与 r321 坐标冗余同源，本卷只做容量定价。）

B02 · ★K2 能标旋钮：单电子圈吸收 R 只需跑到 Q*=3.86943851667860582847312E+15 GeV（=3.16935884205670111842436E-4 M_Pl）（PASS）

把 137 挂在 Q=0 上、只保留电子一圈，则 α⁻¹(Q)=137−H(Q/m_e)。解 H(Q*/m_e)=R=9.04800000000000000000000E+0 得 Q*=3.86943851667860582847312E+18 MeV = 3.86943851667860582847312E+15 GeV，仅为普朗克能量的 3.16935884205670111842436E-4 倍 ⇒ **远在 Planck 之下就能吸收全部缺口**。而 H(q) 随 q→∞ 无上界 ⇒ 该旋钮容量同样无界（上界=把 α⁻¹ 压到 0）。⇒ 「挂哪个能标」是一个连续输入，其容量足以单独解释任何缺口。

B03 · ★K3 场内容旋钮：吸收轻子档缺口 4.74195992821280578355289E+0 只需 1.98476759505849059267160E+0 个电子当量，或一个质量 7.82162016561168874009255E-3 eV、电荷 1 的无色费米子（PASS）

（口径甲·个数）在 m_Z 处每个 m=m_e 的单位电荷费米子贡献 H_e=2.38917641542462881605930E+0 ⇒ 需 1.98476759505849059267160E+0 个；（口径乙·单味质量）解 H(m_Z/m*)=4.74195992821280578355289E+0 得 m*=7.82162016561168874009255E-6 MeV = 7.82162016561168874009255E-3 eV ⇒ **一个 ~8 eV、电荷 1、无色、目前未被计入的费米子就能把 α(m_Z) 拉到锚上**。⇒ 场内容旋钮的灵敏度高到「一个不可见粒子就能顶掉全部缺口」，而它同样无界（可任意加场）。观测吻合因此**无法归因于固定点**。

B04 · K4 圈阶旋钮：二圈残余量级 1.00021536991403455454917E-2，只占轻子档缺口 4.74195992821280578355289E+0 的 2.10928684564191389041343E-3 ⇒ **不是有效旋钮**（BOUNDARY）

一圈施加的下降 Δ₁=4.30604007178719421644711E+0；微扰下一阶相对量级为 α/π=2.32281946577171912624903E-3 ⇒ Δ₂≈1.00021536991403455454917E-2。相对缺口 4.74195992821280578355289E+0 只有 2.10928684564191389041343E-3，**远不足以**吸收 ⇒ 在五个旋钮里，**圈阶是唯一一个「拨不动」的**。但反过来它给出 X3 的硬读数：这个残余 1.00021536991403455454917E-2 是 CODATA 不确定度 2.10000000000000000000000E-8 的 4.76293033292397406928176E+5 倍 ⇒ **一圈处方本身在精度上就不够格谈「预言 α」**。（诚实：本条为量级估计 (α/π)·Δ₁，非精算二圈系数，登记 BOUNDARY 不作硬判据。）

B05 · K5 非微扰强子旋钮：容量 4.97907010390643756155610E+0 = 轻子档缺口 4.74195992821280578355289E+0 的 1.05000256840698273868958E+0 ⇒ 有效但**不可微扰计算**（BOUNDARY）

五味夸克的微扰真空极化项（流质量口径）为 4.97907010390643756155610E+0，已达轻子档缺口 4.74195992821280578355289E+0 的 1.05000256840698273868958E+0 ⇒ **单独就能 100% 吸收**。但诚实边界（同 r328 C02）：用微扰式配流夸克质量在m_Z 附近的轻夸克区间**物理上不成立**；正确的 Δα_had 需色散关系（e⁺e⁻ 数据）或格点。⇒ 这个旋钮的**容量是真的大，但它的值不在微扰可及范围内** —— 缺口恰好落在「必须由非微扰输入填」的区间，而那部分不是固定点给出的。

C01 · ★缺口吸收多重共线性：方程 1 个、有效旋钮 4 个 ⇒ 欠定 3 维 ⇒ 吻合**无归因力**（PASS）

把「从 UV 值到 α(m_Z)」的缺口写成 1 个方程 R_lep=4.74195992821280578355289E+0；能单独 100% 吸收它的旋钮有 4 个（K1 坐标 ∞ / K2 能标 ∞ / K3 场内容 ∞ / K5 强子 1.05000256840698273868958E+0），只有 K4 圈阶无效（2.10928684564191389041343E-3）。⇒ 未知量 4 个、方程 1 个 ⇒ **欠定 3 维**：给定任意观测值，都存在无穷多组(c, Q, 场内容, 强子输入) 与之吻合。这不是「还没算准」，而是**解空间本身不唯一** —— 与 r12 的 Fisher 可识别性判据同构（cross_ref 登记）。⇒ **判词 ATTRIBUTION-FAILURE**：观测吻合不能归因于「固定点预测了 α」。

C02 · ★处方依赖：同一场内容下三种**都合法**的一圈处方给 α⁻¹(m_Z) = 1.32693959928212805783553E+2 / 1.32694201735820377310020E+2 / 1.32163685258847392857457E+2，跨度 5.30516476972984452562946E-1（PASS）

P_a 精确闭式（含阈值平滑）= 1.32693959928212805783553E+2；P_b 阶跃渐近**含**有限常数 −5/(9π) = 1.32694201735820377310020E+2；P_c 阶跃渐近**不含**常数（教科书常见写法）= 1.32163685258847392857457E+2。三者差别只是「有限常数项要不要、阈值要不要平滑」，**都是一圈 QED 真空极化的合法表述**，却在 α⁻¹ 上散开 5.30516476972984452562946E-1 = CODATA 精度 9.00000000000000000000000E-3 的 2.52626893796659263125212E+7 倍（此处比的是**预言精度**，不是实测锚的不确定度）。⇒ 即使坐标/能标/场内容**全部钉死**，「用哪套处方」仍然是一个未声明输入，且其量级远超「命中 137」所需的精度。

C03 · ★圈阶截断定价：一圈残余 1.00021536991403455454917E-2 是「预言 α」所需精度 2.10000000000000000000000E-8 的 4.76293033292397406928176E+5 倍 ⇒ 结构上不够格（PASS）

要把 α 声明到实验精度，α⁻¹ 的允许误差是 2.10000000000000000000000E-8；而一圈处方自带的截断残余量级 1.00021536991403455454917E-2 是它的 4.76293033292397406928176E+5 倍。⇒ **即使所有输入（坐标/能标/场内容/质量）全部给定，来料 §四 的一圈闭合也不可能把 α 预言到 CODATA 精度** —— 缺口不是输入不够，而是**阶数不够**。这条不依赖外部锚（只用 CODATA 不确定度），是本卷最不依赖外部输入的一条读数。

C04 · 剩余缺口的归属：轻子档欠 4.74195992821280578355289E+0 落在**非微扰可及区间之外**的待填项，而填它的 K5 本身不可微扰计算（BOUNDARY）

轻子档缺口 4.74195992821280578355289E+0 与五味夸克微扰项 4.97907010390643756155610E+0 同量级（1.05000256840698273868958E+0），但后者的物理值只能由色散关系/格点给出 ⇒ **缺口恰好落在必须由非微扰实验输入填的区间**。这意味着来料 V25 目标链第 4 步（实际粒子质量与量子阈值）在这一段上**不是「待推导」，而是「待输入」**。本卷不代做该计算。

C05 · ★冗余账扩表：坐标 3.27338541217033817191315E+1 + 能标 2.91143583101872304558821E+1 + 场内容 2.74027457384277303104469E+1 + **处方 2.45905048959013882103105E+1** = 1.13841463066219730695771E+2 bit ≫ 需要 3.26034465570706804935941E+1 bit（PASS）

与 r321/r328 同口径（bits = log₂(跨度 / 目标分辨率)，分辨率取 α⁻¹ 的绝对不确定度 2.10000000000000000000000E-8）。本卷**净新增**只有处方一项 log₂(5.30516476972984452562946E-1 / 2.10000000000000000000000E-8) = 2.45905048959013882103105E+1 bit；坐标/能标/场内容三项为引用登记，不重复计数。合计 1.13841463066219730695771E+2 bit vs 声明 α 到实验精度所需 3.26034465570706804935941E+1 bit ⇒ **净信息 -8.12380165091490502021769E+1 bit**。

CTL1 · 空运行：五个旋钮容量全 0 ⇒ 「有效 0 个」⇒ 判据报**可归因**（PASS）

把所有旋钮容量置 0（等价于理论无任何可调输入），判据给 n_eff=0 <2 ⇒ **不触发**归因失败 ⇒ 判据不是「怎么说都对」，它有明确的放行条件。

CTL2 · ★区分力：只留一个有效旋钮 ⇒ n_eff=1 ⇒ 判据报**可归因**（PASS）

构造场景：K1 无界、其余四个容量仅为缺口的 0.1% ⇒ n_eff=1 <2 ⇒ 判据**不**报失败。⇒ C01 的「归因失败」不是恒真结论，而是**由实测容量分布推出**的；若将来有人把其它四旋钮钉死（例如给出唯一处方、唯一场内容、唯一能标），归因就恢复了 —— 判据把「该钉死什么」精确地指了出来。

CTL3 · 对偶面：缺口取 1.00000000000000000000000E+30（远超一切容量）⇒ n_eff=0 ⇒ 判据报**可归因**（PASS）

当缺口大到任何旋钮都吸收不了，判据给 n_eff=0 <2 ⇒ 不报归因失败，此时正确的结论是**理论被否证**（吻合不成立），而不是「无法归因」。⇒ 判据的两个出口语义不同：n_eff≥2 = 吻合但无归因力；n_eff=0 且 |R|>0 = 不吻合。

CTL4 · 处方跨度的**不可消下限**：单味 q→∞ 处 P_b 与 P_c 仍差 1.76838825657661484187649E-1（PASS）

即使 q→∞（阈值平滑修正 → 0），「含不含有限常数 −5/(9π)」的差别仍恒为 1.76838825657661484187649E-1，不随 q 消失 ⇒ **处方不确定度有一个不可约下限**（每味 1.76838825657661484187649E-1）。三味即 5.30516476972984452562946E-1，与 C02 实测跨度 5.30516476972984452562946E-1 同阶 ⇒ 该跨度不是数值巧合。

CTL5 · 圈阶估计线性：α 缩到 1/10 ⇒ Δ₂ 缩到 1/10（比值 1.00000000000000000000000E+1）（PASS）

Δ₂ 的量级估计取 (α/π)·Δ₁，对 α 线性 ⇒ 比值恰为 10.000…（实测 1.00000000000000000000000E+1）。⇒ B04/C03 的「圈阶无效 / 但截断致命」两条读数对 α 的取值方式是**自洽**的：α 越小，圈阶残余越小，但 CODATA 精度门槛不变 ⇒ 结论方向不翻转。

CTL6 · 单调性：H(q) 在 q ∈ [1e−3, 1e6] 严格增（最小相对增幅 1.77365094687495441626625E-1）（PASS）

B02/B03 的两个反解（Q* 与 m*）都靠二分，其有效性依赖 H 严格单调。机器检验 10 个十倍程：全部严格增，最小相对增幅 1.77365094687495441626625E-1 ⇒ **反解唯一、无多解风险**。
