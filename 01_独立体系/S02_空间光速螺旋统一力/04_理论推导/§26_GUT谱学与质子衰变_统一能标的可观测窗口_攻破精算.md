## 1　攻破目标与 §26 定位

§19 得到 M_GUT≈1.6×10¹⁶ GeV（几何中心），§25 全链给出 M_GUT=1.341×10¹⁶ GeV。但"统一能标"本身是理论量——**它的可观测后果是什么？**

答案：**质子衰变**。若四力确在 ~10¹⁶ GeV 统一，X 玻色子交换（dim-6）将诱导 p→e⁺π⁰，其寿命 ∝ M_X⁴。Super-K 已给出下界 τ>1.29×10³⁴ yr，Hyper-K 等未来实验将把灵敏度推到 ~10³⁵ yr。于是：

- **Q1**：§25 的 M_GUT 预言对应多长质子寿命？是否已被 Super-K 排除？
- **Q2**：谱学反推（eq(20)(21)：由低能耦合反推 M_Hc 与 M_GUT）在 §25 的输入口径下是否自洽？
- **Q3**：M_GUT 对 gaugino 质量的依赖（∝(M₃M₂)^(−1/9)）有多大，对质子衰变可检验性有何影响？

## 2　方法：谱学反推公式与质子衰变标度

### 2.1 反推公式（1304.0343 eq(20)(21)，本脚本解析重导出）

```
3/α₂(m_Z) − 2/α₃(m_Z) − 1/α₁(m_Z) = (1/2π)[(12/5)ln(M_Hc/m_Z) − 2ln(M_S/m_Z) + 4ln(M₃/M₂)]   (20)
5/α₁(m_Z) − 3/α₂(m_Z) − 2/α₃(m_Z) = (1/2π)[12ln(M_X²M_Σ/m_Z³) + 4ln(M₂/m_Z) + 4ln(M₃/m_Z)]  (21)
```

**系数解析重导出**（V1，闭合推导链）：

- 组合 3/α₂−2/α₃−1/α₁ 的跑动系数 (3b₂−2b₃−b₁)：SM=0.4=2/5、MSSM=2.4=12/5（脚本验证精确）；
- GUT 阈值 eq(16) 对该组合的贡献：Σ 项消零、X 项消零、仅剩 Hc 项 −(12/5)ln(μ/M_Hc)/(2π)；
- 两段合并（SM 到 M_S、MSSM 到 M_GUT）→ eq(20) 的 (12/5) 与 −2 系数精确闭合；
- eq(21) 同理：36=12·3 来自 M_GUT³=M_X²M_Σ，4+4 为 M₂/M₃ 阈值项。

### 2.2 质子衰变标度

锚点（1304.0343 原文）：M_X≈0.8×10¹⁶ GeV → τ(p→e⁺π⁰)≈5×10³⁴ yr，略高于 Super-K 界。dim-6 振幅 ∝1/M_X² → τ∝M_X⁴：

```
τ(p→e⁺π⁰) = 5×10³⁴ yr × (M_X / 8×10¹⁵ GeV)⁴
```

### 2.3 输入（§25 全链 DR 耦合，M₂=M₃=M_S=1 TeV 简并）

α₁=0.016959、α₂=0.033784、α₃=0.119526 → 1/α₁=58.966、1/α₂=29.599、1/α₃=8.366。

## 3　数值结果

### 3.1 V1：谱学反推公式与失效边界

| 项 | 值 | 判定 |
|---|---|---|
| (3b₂−2b₃−b₁)_SM / _MSSM | 0.4 / 2.4 | = 2/5、12/5，eq(20)(21) 结构闭合 |
| eq(20) LHS（§25 耦合） | 13.104 | — |
| 简并谱 M_Hc（lead-log 反推） | **5.316×10¹⁷ GeV** | **> M_GUT，非物理 → 失效边界** |
| 文献工作值（两循环+非简并+阈值） | M_Hc ∈ [8.6×10¹⁴, 1.4×10¹⁵] GeV | 1304.0343 Fig1 蓝线 |

**关键诚实结论**：§25 的"简并谱 + 裸 m_Z 耦合 + 一循环 lead-log"组合在 M_Hc 通道上**不能自洽**（反推出 M_Hc 高于统一能标，minimal SU(5) 中无物理意义）。原因：M_Hc 对 m_Z 处阈值修正（顶夸克/W/Z/SUSY 粒子 decoupling 的 leading-log 匹配）极敏感——该修正使有效 1/α₂ 偏移 ~1.5–2 单位，足以把 M_Hc 从 5×10¹⁷ 压回 10¹⁵ 量级。**这一发现定义了 §25 简化谱的有效边界：sin²θ_W 预言不受影响（§25 V3 已证），但谱学反推必须用完整阈值链。** 文档不掩盖这一失败，反将其作为边界声明。

### 3.4 V4：判定

1. **一致性**：§25 全链 M_X=M_GUT=1.341×10¹⁶ GeV → τ=3.95×10³⁵ yr，高于 Super-K 界 1.29×10³⁴ yr（30.6× 余量）——**与当前实验一致**（判据 4 通过）。
2. **可检验性**：Hyper-K（灵敏度 ~10³⁵ yr）恰可覆盖 §25 参数区（τ≈4×10³⁵ 在其边缘内）；若未来观测到质子衰变，将直接确认 10¹⁶ GeV 统一能标——**这是"四力统一"最清晰的实验前景**。
3. **边界与通道**：dim-5 通道在低能 SUSY 需 M_Hc 抑制机制（文献）；高能 SUSY（M_S~10³ TeV）天然抑制 dim-5，X 玻色子通道主导（1304.0343）。
4. **S02 关联**（判据 5）：质子衰变窗口全部来自标准 SUSY-GUT，S02 零参与——**S02 定级维持"组织性语言"**。
