# ROOT V132 — 空间螺旋曲率挠率封装与精细结构常数

**研究定位**：研究专著第一卷 + 可复现程序 + 反例审计；不是已经完成的量子本源或四力统一理论。

## 本次重要结果

- 严格几何：在速度归一化 `c=1` 的圆柱螺旋上，`κ=Rω²`、`τ=uω`、`ω²=κ²+τ²`。
- 定义性封装：`H_geo=(κ+iτ)/sqrt(κ²+τ²)`，`h_geo=Im(H_geo)=u`，无量纲。
- 可能的假设 `h_geo=α` 只是条件性识别；还可以用环向比例=α构造完全不同的几何。
- **反例**：沿轴以 `β=0.6` Lorentz 变换，`u=α≈0.00729735` 会成为 `u'≈-0.59530916`，因此普通三维轨迹的 `h_geo` 不是普适的低能精细结构常数。
- `h_geo` 与 `h_P=2πℏ` 量纲不同，不能直接等同。
- 量子薄层曲线约束下曲率可产生几何势；挠率是否进入有效 Hamilton 算符取决于横向内部模式，不能普遍添加。
- 数值：2022 CODATA 数据核对、43 项新单元测试、2,000 个随机螺旋及 500 个随机 boost，SymPy 符号检验。

## 数学与复现

所需 Python 建议 3.10+；新单元测试仅依赖标准库，符号审计使用 SymPy，绘图使用 numpy/matplotlib。

```bash
cd ROOT_V132
python -m unittest discover -s tests -v
python scripts/symbolic_audit.py
python scripts/generate_results.py
python verify.py
```

`verify.py` 检查测试、SymPy、科研专著、EPUB、数值 JSON、SHA-256 清单。完整重建图表应先进行，最后再生成校验清单；否则图像重生成可能改变二进制摘要。详细输入位于 `data/`，历史 V131 ZIP 仅保留供溯源，本轮**没有**声称重新运行 V131 的历史测试。

## 科学结论等级

**严格成立**：规定模型下的 Frenet 几何、Lorentz 变换、单位/量纲关系。  
**已知理论**：玻尔模型、QED 运行、曲线受限量子势、条件性挠率规范相位。  
**探索性假设**：将普适 α 与某个内部螺旋参数联系起来。  
**未完成**：从几何独立导出 α、ℏ、G、电子自旋、三代质量和四力统一。
