# 第七章 · 形状判别器与壁厚反解

## 7.1 从"哪个 λ"到"什么形状"

第六章的结论很硬：背景只有一维解空间，三代必须靠味依赖分开。但"味依赖"有三个层次：

| 层次 | 形式 | `n_free` | 能否被实验排除 |
|---|---|---|---|
| 一 | 三个独立的 `λ_i` | 3 连续 | 否（任意三代都能拟合） |
| 二 | 味荷量子化 `λ_i∝ε^{q_i}` | 1 连续 ＋ 2 整数 | 能（比值离散） |
| 三 | 味算符的本征值谱 | 0（若算符已定） | 能 |

本书只做到层次一，并给出层次二、三的**准入门槛**（§7.5）。层次一的结论是负面的：**3↔3，自由度不变**。但本章有一个正面的副产品——**谱塔是背景形状的判别器**。

## 7.2 一个精确可解的背景

### 7.2.1 为什么用 kink

V48 的提案要求 `Φ` "由自身作用量变分求出"。若随便指定一个函数，就违反了这条要求。找一个**真正是某个作用量的精确解**的 `Φ`，是最低限度的诚实。

取 `φ⁴` 型势

$$\tag{7.1} V(\phi)=\frac{(\phi^2-1)^2}{2w^2},\qquad \Phi(y)=\tanh\Bigl(\frac{1.5-y}{w}\Bigr).$$

它精确满足

$$\tag{7.2} \Phi''=\frac{2\Phi(\Phi^2-1)}{w^2}=V'(\Phi).$$

机核：在 `w=0.25/1.5`、`y=0.2/0.5/0.8` 六个点上，`|Φ''−V'(Φ)|=0.000e+00`（**解析代入，非差分**，`T0`）。

### 7.2.2 它在区间里是什么样

壁在 `y=1.5`，区间是 `[0,1]`。所以区间内看到的是 kink 的**尾部**：`Φ` 单调下降、恒正、无零点。这不是"一个好看的函数"，是"一个真实的解的一个片段"。

**边界诚实（本章最重要的一句）**：`Φ` 只是背景 ansatz。本书**没有**对 `[0,1]` 做端点变分（真实边值问题需要镜像或周期延拓）。所以成立的命题是：

$$\boxed{\;\text{"它是 } \phi^4 \text{ 的精确解"，不是"它是本区间边值问题的解"。}\;}$$

### 7.2.3 求解与拟合

零模方程

$$\tag{7.3} \bigl[\partial_y+\lambda\Phi(y)\bigr]f_L=0\;\Longrightarrow\;f_L=N\exp\Bigl[-\lambda\int_0^y\Phi(s)ds\Bigr].$$

质量仍按第三章的重叠算。用 `brentq` 反解三个 `λ`：

| 量 | 数值 |
|---|---|
| 拟合 `λ`（`w=1.5`） | `[28.318812, 18.194710, 12.616122]` |
| 复算质量 | `[0.510999, 105.658375, 1776.930000]` MeV（与输入一致到 `1e-12`） |
| 等效总指数 `λ_i∫₀¹Φ` | `[16.108785, 10.349822, 7.176516]` |
| V44 的 `z_i` | `[16.218066, 10.446620, 7.260337]` |
| 两者相对差 | 约 `0.7%` |

（`T2`）

那个 `0.7%` 就是**形状效应**：kink 剖面不是纯指数，所以"等效指数"与真正的指数型 `z` 差一点点。

## 7.3 计数定理

`m(λ)` 在 `λ∈[1,60]` 的 300 点网格上**严格单调下降**：`Δm` 最大值 `−1.83e-9`、最小值 `−6.15e3`，**无变号**（`T2a`）。

$$\tag{7.4} \boxed{\;\text{3 个质量}\;\Longleftrightarrow\;\text{3 个 }\lambda_i\;,\quad n_{\text{free}}=3\;.}$$

(7.3) 在"能复现三代"的意义上**可解**——本书给出了一个精确可解背景＋三个拟合值。在"预测三代"的意义上**无进展**：`λ_i` 是反演量，与第三章的 `z_i` 同一性质。

$$\boxed{\text{V49 的 }(7.3)\text{ 只是把 }z_i\text{ 改名为 }\lambda_i\text{；净预测自由度不变。}}$$

这与既有册记录的"KK 参数 4↔4"是同一种病，记作 `3↔3`。**换名不约化。**

## 7.4 形状判别器：本章的正结果

### 7.4.1 做法

固定同一组三代质量（`0.51099895 / 105.6583755 / 1776.93`），只改壁厚 `w`，重新拟合 `λ`，再重算 `S`，与 V44 矩阵比较：

| `w` | `‖ΔS‖/‖S‖` |
|---|---|
| 0.25 | `0.0866%` |
| 0.50 | `1.2156%` |
| 0.75 | `2.7872%` |
| 1.00 | `4.0188%` |
| 1.25 | `4.8680%` |
| 1.50 | `5.4454%` |
| 2.00 | `6.1292%` |

（`T3d`）

### 7.4.2 三条读法

**读法一：单调递增。** 形状越"厚"，偏离指数型越远。这不是拟合出来的趋势，是同一个函数族的连续变形。

**读法二：薄壁回到指数型。** `w=0.25` 时 `Φ≈1`（在 `[0,1]` 上近似常数），剖面 `≈e^{−λy}`，`S` 与 V44 只差 `0.0866%`（`T3b`）。

$$\boxed{\text{V44 的 }S\text{ 矩阵能用三个 }z\text{ 描述，是因为它隐含了"}\Phi=\text{常数"这一从未被写出的假设。}}$$

这一条是本链上第一次有人把"隐含假设"指出来并量化。它不是新物理，是**补一句漏掉的话**。

**读法三：厚壁 vs 薄壁。** 同一组质量下，两者相差 `5.35%`（`T3a`）。

### 7.4.3 味改变随之改变

同一组质量、同一组示范角，`Q_eμ` 由

$$0.000683980\ (\text{指数型})\;\longrightarrow\;0.000550276\ (\text{厚壁})$$

比值 `0.8045`，降 `19.5%`（`T3c`）。

$$\tag{7.5} \boxed{\;S\ \text{是}\ \Phi\ \text{形状的泛函，而不只是}\ z_i\ \text{的记账表.}\;}$$

### 7.4.4 为什么这是正结果

因为它是**唯一一条把"形状"接上"可观测量"的通道**：

$$\text{形状 }w\;\longrightarrow\;S\;\longrightarrow\;Q_{\alpha\beta}\;\longrightarrow\;\text{（若再接实验）排除区间}.$$

如果将来 `S` 被某个独立途径确定（例如从 KK 规范耦合的精密测量反演），它能**反过来排除背景形状**。反过来说，**任何只用三个 `z` 报价 `S` 的结论，都在暗中假设了指数形状**。

这就是"判别器"三个字的含义：`S` 不是被动记账，它**能反过来问背景**。

## 7.5 准入线（审计判据，不是物理定理）

若一个方案声称"预测三代质量"，它至少须给出两个无量纲比值

$$\tag{7.6} \frac{\lambda_\mu}{\lambda_e},\qquad\frac{\lambda_\tau}{\lambda_\mu},$$

且不含连续自由参数。

**理由**：三代只有一个整体标度可由 `v` 吸收，剩下两个比值是全部信息量。任何连续可调的比值，等价于两个拟合参数。

据此判：

| 方案 | 是否满足 | 结论 |
|---|---|---|
| V48 `(48-10)` 单式 | ✘ 不含固定比值 | 预测力 0 |
| V49 三 `λ_i` | ✘ 三个连续参数 | `[反演]` |
| 味荷量子化 `λ_i∝ε^{q_i}` | ✔ 至多 2 个整数 | 可被实验排除 |
| 味算符本征值谱 | ✔ 若算符已写出 | 比值自动固定 |

**注意**：准入线是**审计判据**，不声称"自然必须如此"。它只回答一个问题：

$$\boxed{\;\text{这个方案是在预测，还是在拟合？}\;}$$

## 7.6 一条不应被忽略的精度教训

上游两套结果的矩阵六位一致（差 `2.16e-7`），但 `eig_min` 相对差 `1.47e-3`，条件数 `κ` 从 `3.3633e4` 变成 `3.3683e4`（`S12`）。

$$\boxed{\text{六位一致 ≠ 谱一致。}}$$

若 `S` 被用作判别量（第七章它正是判别量），**必须同时报 `eig_min` 与 κ**，不能只报六位矩阵。一个条件数 `3e4` 的矩阵，末位差 1e-7 会在最小本征值上放大成 1e-3。
