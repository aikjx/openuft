# 附录：数学基础与物理公式汇总

## 1. 数学基础

### 1.1 矢量代数

#### 1.1.1 矢量的定义
矢量是既有大小又有方向的量，通常用黑体字母表示，如 **A**、**B** 等。

#### 1.1.2 矢量的运算
- **加法**：**A** + **B** = **B** + **A**（交换律）
- **减法**：**A** - **B** = **A** + (-**B**)
- **标量乘法**：k**A**，其中 k 是标量
- **点积**：**A** · **B** = |**A**||**B**|cosθ，其中 θ 是两矢量的夹角
- **叉积**：**A** × **B** = |**A**||**B**|sinθ**n**，其中 **n** 是垂直于 **A** 和 **B** 的单位矢量

#### 1.1.3 矢量的分量表示
在直角坐标系中，矢量可以表示为分量形式：
**A** = Aₓ**i** + Aᵧ**j** + A_z**k**
其中 **i**、**j**、**k** 分别是 x、y、z 方向的单位矢量。

### 1.2 微积分

#### 1.2.1 导数
函数 f(x) 的导数表示为 f'(x) 或 df/dx，它表示函数在某一点的变化率。

#### 1.2.2 积分
积分是导数的逆运算，包括不定积分和定积分：
- 不定积分：∫f(x)dx = F(x) + C，其中 F'(x) = f(x)
- 定积分：∫ₐᵇf(x)dx = F(b) - F(a)

#### 1.2.3 多元微积分
- **偏导数**：对于函数 f(x,y,z)，偏导数 ∂f/∂x 表示在 y 和 z 固定时，f 对 x 的变化率。
- **梯度**：∇f = (∂f/∂x, ∂f/∂y, ∂f/∂z)，表示函数变化最快的方向。
- **散度**：∇·**A** = ∂Aₓ/∂x + ∂Aᵧ/∂y + ∂A_z/∂z，表示矢量场的发散程度。
- **旋度**：∇×**A**，表示矢量场的旋转程度。
- **拉普拉斯算子**：∇²f = ∂²f/∂x² + ∂²f/∂y² + ∂²f/∂z²，表示函数的二阶导数之和。

### 1.3 张量分析

#### 1.3.1 张量的定义
张量是矢量的推广，标量是0阶张量，矢量是1阶张量，矩阵是2阶张量，以此类推。

#### 1.3.2 张量的运算
- **张量加法**：同阶张量可以相加
- **张量乘法**：张量可以相乘，结果的阶数是两个张量阶数之和
- **缩并**：张量的两个指标相同并求和，结果的阶数减2

#### 1.3.3 爱因斯坦求和约定
在张量分析中，通常使用爱因斯坦求和约定：当一个指标在表达式中出现两次时，表示对该指标求和。

### 1.4 微分方程

#### 1.4.1 常微分方程
常微分方程是含有未知函数及其导数的方程，如：
- 一阶常微分方程：dy/dx = f(x,y)
- 二阶常微分方程：d²y/dx² + P(x)dy/dx + Q(x)y = R(x)

#### 1.4.2 偏微分方程
偏微分方程是含有未知多元函数及其偏导数的方程，如：
- 拉普拉斯方程：∇²u = 0
- 泊松方程：∇²u = ρ
- 波动方程：∇²u = (1/c²)∂²u/∂t²
- 热传导方程：∇²u = (1/k)∂u/∂t

### 1.5 复变函数

#### 1.5.1 复数的定义
复数可以表示为 z = x + iy，其中 i 是虚数单位，i² = -1。

#### 1.5.2 复数的运算
- **加法**：(x₁ + iy₁) + (x₂ + iy₂) = (x₁ + x₂) + i(y₁ + y₂)
- **乘法**：(x₁ + iy₁)(x₂ + iy₂) = (x₁x₂ - y₁y₂) + i(x₁y₂ + x₂y₁)
- **除法**：(x₁ + iy₁)/(x₂ + iy₂) = [(x₁x₂ + y₁y₂) + i(x₂y₁ - x₁y₂)]/(x₂² + y₂²)

#### 1.5.3 复变函数的导数和积分
- **导数**：f'(z) = limₕ→₀ [f(z+h) - f(z)]/h
- **积分**：∫ₐᵇf(z)dz，表示沿复平面上某一路径的积分

## 2. 物理公式汇总

### 2.1 经典力学公式

#### 2.1.1 牛顿运动定律
- 第一定律：任何物体都保持静止或匀速直线运动状态，直到外力迫使它改变这种状态为止。
- 第二定律：物体的加速度与所受的合外力成正比，与物体的质量成反比，加速度的方向与合外力的方向相同。F = ma
- 第三定律：作用力和反作用力大小相等，方向相反，作用在不同物体上。

#### 2.1.2 动量和能量
- 动量：p = mv
- 动能：Eₖ = (1/2)mv²
- 势能：根据不同的力场有不同的表达式，如重力势能 Eₚ = mgh
- 机械能守恒定律：在只有保守力做功的系统中，机械能守恒，即 Eₖ + Eₚ = 常量

#### 2.1.3 角动量
- 角动量：L = r × p
- 角动量守恒定律：在合外力矩为零的系统中，角动量守恒，即 L = 常量

### 2.2 相对论公式

#### 2.2.1 洛伦兹变换
- 时间变换：t' = γ(t - vx/c²)
- 空间变换：x' = γ(x - vt)
- 其中 γ = 1/√(1 - v²/c²) 是洛伦兹因子

#### 2.2.2 相对论效应
- 时间膨胀：Δt' = γΔt
- 长度收缩：L' = L/γ
- 质量增加：m' = γm

#### 2.2.3 质能方程
- E = mc²
- 能量动量关系：E² = (pc)² + (mc²)²

### 2.3 电磁学公式

#### 2.3.1 库仑定律
- F = kq₁q₂/r²，其中 k = 1/(4πε₀)

#### 2.3.2 电场和磁场
- 电场强度：E = F/q
- 磁场强度：B = F/(qv)
- 洛伦兹力：F = q(E + v × B)

#### 2.3.3 麦克斯韦方程组
- 高斯电场定律：∇·E = ρ/ε₀
- 高斯磁场定律：∇·B = 0
- 法拉第电磁感应定律：∇×E = -∂B/∂t
- 安培-麦克斯韦定律：∇×B = μ₀J + μ₀ε₀∂E/∂t

#### 2.3.4 电磁波
- 电磁波的速度：c = 1/√(μ₀ε₀)
- 电磁波的能量密度：u = (1/2)(ε₀E² + B²/μ₀)
- 坡印廷矢量：S = E × H，其中 H = B/μ₀

### 2.4 引力公式

#### 2.4.1 万有引力定律
- F = Gm₁m₂/r²，其中 G 是万有引力常数

#### 2.4.2 引力场
- 引力场强度：g = F/m
- 引力势：φ = -GM/r

#### 2.4.3 爱因斯坦场方程
- Gμν + Λgμν = (8πG/c⁴)Tμν
- 其中 Gμν 是爱因斯坦张量，Λ 是宇宙学常数，gμν 是度规张量，Tμν 是能量动量张量

### 2.5 量子力学公式

#### 2.5.1 波函数
- 波函数 ψ(x,t) 描述粒子的状态
- 波函数的概率解释：|ψ(x,t)|² 表示在位置 x 处发现粒子的概率密度

#### 2.5.2 薛定谔方程
- 时间-dependent 薛定谔方程：iħ∂ψ/∂t = Ĥψ
- 时间-independent 薛定谔方程：Ĥψ = Eψ
- 其中 Ĥ 是哈密顿算符，E 是能量本征值

#### 2.5.3 算符
- 位置算符：x̂ψ = xψ
- 动量算符：p̂ψ = -iħ∇ψ
- 能量算符：Êψ = iħ∂ψ/∂t
- 角动量算符：L̂ = r̂ × p̂

#### 2.5.4 不确定性原理
- ΔxΔp ≥ ħ/2
- ΔEΔt ≥ ħ/2

### 2.6 统一场论公式

#### 2.6.1 核心方程
- 统一动量方程：P = m(C - V)
- 其中 P 是统一动量，m 是质量，C 是光速矢量，V 是物体运动速度

#### 2.6.2 时空同一化原理
- R = ct，其中 R 是空间距离，c 是光速，t 是时间

#### 2.6.3 质量的几何定义
- 质量是空间运动状态的表现，与空间的旋转运动有关

#### 2.6.4 电荷的几何定义
- 电荷是空间旋转运动的表现，与空间的旋转角速度有关

#### 2.6.5 引力场的几何定义
- 引力场是空间直线加速运动的表现，与空间的加速度有关

#### 2.6.6 电磁场的几何定义
- 电场是空间旋转运动的表现，与空间的旋转角速度有关
- 磁场是空间环绕运动的表现，与空间的环绕运动速度有关
