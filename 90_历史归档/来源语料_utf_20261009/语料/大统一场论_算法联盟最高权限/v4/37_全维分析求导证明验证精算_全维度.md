## 一、全维分析（结构层）

### 1.1 公理设定（不可再分起点）
- A1 瞬时光速：`|v|=ωR=c`（空间动态，非静态容器）
- A2 质量标度：`R=ℏ/(mc)`（ℏ 以此唯一入口进入几何）
- A3 电磁扭转：`α=τ/κ`（挠率/曲率比 = 精细结构常数，测量锚）

### 1.2 母方程与主恒等式
```
κ = ρ/(ρ²+b²),  τ = b/(ρ²+b²)        (Frenet 直接定义)
ρ = R/√(1+α²),  b = ρα                (A3 代入)
κ² + τ² = 1/R² = (mc/ℏ)² = (ω/c)²    (主恒等式 *)
```

### 1.3 无量纲归一化（19 号核心分析）
```
κ̃ = κR = 1/√(1+α²),  τ̃ = τR = α/√(1+α²)
κ̃² + τ̃² = 1                           (与质量无关)
```
→ 全粒子归一到同一单位螺旋。这是"万物同构"的分析根基。

### 1.4 三大同构定理（19 号）
- **结构普适**：`κ̃²+τ̃²=1` 只依赖 α，与 m 无关。
- **标度不变**：`4π√(κτ)·R = 4π√α/√(1+α²)` 普适（电子 1.073448，普朗克 8.885766）。
- **粒子谱**：`κ=mc/(ℏ√(1+α²))`，`τ=αmc/(ℏ√(1+α²))`。

### 1.5 力的同构分析（30 号）
```
G  : c³/[ℏ(κ²+τ²)]   —— 由 κ²+τ² 总幅决定 → 几何"总量"涌现
ε₀ : q0²/(64π³c³κτℏα) —— 由 κτ 耦合积决定 → 几何"耦合"涌现
```
G 与 ε₀ 同构于 κ,τ，但分别取"总幅"与"耦合积"两个不同投影。

### 1.6 中性粒子边界分析（19/27 号）
中性粒子外部净 `τ=0`，但内部 τ 结构存在（中子磁矩≠0、自旋 ℏ/2）。电荷=挠率净投影，自旋=内禀挠率拓扑存量。

## 二、全维求导证明（来源层，第一性原理）

主脚本：`17_全维求导证明_空间动态与粒子运动.py`（sympy 实跑 ALL PASS）

### 2.1 空间动态性 — 一阶导 `|v|=c`
```
r(t) = (ρcosωt, ρsinωt, bωt)
v    = (-ρωsin, ρωcos, bω)
|v|² = ω²(ρ²+b²) = ω²R²  —代入 ωR=c→  |v| = c   ✅
```
**结论**：空间以光速持续螺旋运行，非静态容器。

### 2.2 曲率挠率唯一确定 — Frenet 求导
```
κ = |r'×r''|/|r'|³ = ρ/(ρ²+b²)
τ = (r'×r''·r''')/|r'×r''|² = b/(ρ²+b²)
```
κ,τ 由轨迹求导唯一确定（`κ闭合:True, τ闭合:True`）。

### 2.3 粒子属性本源 — 由 κ,τ,ω 派生
| 属性 | 本源式 | 几何主导 |
|:---|:---|:---|
| ω | `c√(κ²+τ²)` | 母方程直接解 |
| m | `ℏω/c² = ℏ/c·√(κ²+τ²)` | κ（弯曲）|
| e | `√(4πε₀ℏcα)`, `α=τ/κ` | τ（扭转）|
| s | `ℏ/2`（4π 拓扑周期）| 螺旋手征 |
| p | `ℏ√(κ²+τ²)` | 投影 |

### 2.4 运动方式 — 与二阶导
```
a = (-ρω²cos, -ρω²sin, 0)
a_z = 0            ⇒ 轴向匀速（观测"匀速直线"=轴向投影）
a_n = ρω² = v_t²/ρ ⇒ 法向恒向心加速（观测"圆周/轨道"=κ约束）
```
当 κ,τ 成为空间函数：`引力~∇κ`，`电磁~∇τ` —— 四力统一于空间梯度。

### 2.5 G 双变量对称性 — 符号偏导（30 号）
```
G(κ,τ) = c³/[ℏ(κ²+τ²)]
∂G/∂κ = -5.1099...e+59 · κ/(κ²+τ²)²
∂G/∂τ = -5.1099...e+59 · τ/(κ²+τ²)²
⇒ ∂G/∂κ ≡ ∂G/∂τ （κ↔τ 互换不变）✅
```
普朗克极限 `τ=κ` 时挠率贡献 G 的 50%，修复 28 号单变量缺憾。

### 2.6 α 级联结构 — 级联投影（33 号）
```
α = tan(k·atan(α0)),  k=137
α0 = tan(atan(α)/137) ≈ α/137
```
对任意整数 k 机器零闭包（数学恒等）；k=137 承载"137 圈"直觉。
