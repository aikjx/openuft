## 1. 本体立场

本体系提供**统一力动力学输入**，不主张"空间以光速螺旋运动"之类的几何本体。其核心是把动量重新定义为 `P=m(c−v)` 并据此定义统一力。

## 3. 与 S12 的区分（重点）

[S12 空间光速螺旋](../../S12_空间光速螺旋统一体系/README.md) 在第 2.1 节直接使用 `P=m(c−v)`、`F=dP/dt`，并已将这两条登记为借用项 S12-A4。两者关系：

- S02 提供动力学方程，但**不主张**内部运动恒等于 c 的几何本体。
- S12 借用 S02 的动力学，再叠加"空间以光速螺旋运动"的独立本体约束。
- S02 原文明确：三重奏是几何基石，但**不是万有理论**——不解释引力、不生成常数、不完成四力统一。该诚实边界适用于两者。

## 4. 与 S01 的关系

[S01 螺旋三重奏](../../S01_螺旋三重奏与谱几何/README.md) 的 `κ²+τ²=(ω/v)²` 在匀速螺旋/梯度磁场下是严格定理，被 S02 用作几何基石；数学成立不转移到 S02 的物理结论。

## 6. 第一性冲突登记（2026-09-15）

- **硬冲突**：S02-A1（`P = m(c − v)`）在 `v = 0` 时给出 `P = mc ≠ 0`（电子为 `2.73e-22 kg·m/s`），与「静止粒子动量为零」的常规定义冲突；若 `m`、`c` 恒定，则 `F = dP/dt = −ma`，与牛顿第二定律 `F = +ma` **反号**。
- **根因**：恢复 `F = +ma` 需要额外前提（明确 `c` 的数学身份、引入 `(c − v)·dm/dt` 项、或声明低速退化条件），但公设文件**均未登记**。这是「公设替换」类工作典型的衔接缺口（新定义须显式给出与旧理论的衔接条件）。
- **影响范围**：[S12](../../S12_空间光速螺旋统一体系/README.md) 把本体系的 `P = m(c − v)`、`F = dP/dt` 登记为借用项 S12-A4，因此该冲突**同时命中 S12**——借用不带来独立证据，也不隔离借入方的缺陷。
- 检出工具：算法联盟全维自洽引擎（mpmath 80 位 + sympy 符号求导），记录 `M03`；已同步登记 `claims.csv`（S02-C0001，falsified），详见 [统一动量低速极限冲突记录](../11_证伪与反例/统一动量低速极限冲突记录.md)。
- **不受影响的断言**：S02-A4 三重奏 `κ²+τ²=(ω/v)²` 在 S01 框架内是严格代数恒等式，与本冲突无关。
