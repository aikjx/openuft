### 20.2 含挠率的 TOV 方程推导

度规拟设（Schwarzschild 坐标）：

ds² = −e^{2ν(r)}dt² + e^{2λ(r)}dr² + r²(dθ² + sin²θ dφ²)

物质模型：理想流体 + 自旋密度

T_{μν} = (ε+p)u_μu_ν + p g_{μν}

s^{λμν} = s(r) ε^{λμνσ}u_σ （纯轴矢自旋密度）

挠率解（EC 代数方程）：

T_{λμν} = (κ/4) ε_{λμνσ} J_5^σ = (κ/4) ε_{λμνσ} s u^σ

有效能量-动量张量的挠率修正：

Σ_{μν}^{(torsion)} = (1/κ)[K_{μαβ}K_ν^{αβ} − ½ g_{μν}K_{αβγ}K^{αβγ} + ⋯]

对于纯轴矢挠率 A^μ = (κ/4) s u^μ，contortion 的二次项化简为：

K_{αβγ}K^{αβγ} = −(3/2)A_μA^μ = −(3/2)(κs/4)² u_μu^μ = (3/2)(κs/4)²

完整计算给出有效能量密度和压强的修正：

**ε_eff = ε − (3κ/32)s²**

**p_eff = p − (3κ/32)s²**

物理解释：挠率修正项 −(3κ/32)s² 是负的，等价于一种排斥力。这是因为自旋-自旋接触相互作用在同向自旋费米子之间是排斥的（Pauli 原理 + 引力耦合）。

### 20.3 修改的 TOV 方程

标准 TOV 方程：

dp/dr = −(ε+p)(m + 4πr³p) / [r(r − 2Gm)]，其中 m(r) = ∫₀^r 4πr'²ε(r')dr'

在 EC 理论中用有效量替换：

**dp_eff/dr = −(ε_eff + p_eff)(m_eff + 4πr³p_eff) / [r(r − 2G m_eff)]**，其中 m_eff(r) = ∫₀^r 4πr'²ε_eff(r')dr'

由于 ε_eff = ε − Δε_T 且 p_eff = p − Δp_T（Δε_T = Δp_T = 3κs²/32 > 0），挠率效应使有效密度和有效压强都减小。

但注意 dp/dr = dp_eff/dr + d(Δp_T)/dr，完整的修改 TOV 方程需要更仔细地处理。

重新推导：定义 ε_T = 3κs²/32，则 ε_eff = ε − ε_T，p_eff = p − ε_T。质量函数 m_eff(r) = m(r) − m_T(r)。

TOV 方程变为：

d(p − ε_T)/dr = −(ε + p − 2ε_T)(m − m_T + 4πr³(p − ε_T)) / [r(r − 2G(m − m_T))]

展开：dp/dr − dε_T/dr = −(ε+p)(m + 4πr³p)/[r(r−2Gm)] + δ_torsion(r)，其中 δ_torsion(r) 包含所有挠率修正项。

### 20.4 自旋密度与物态方程

非相互作用中子气体，零温下：

n(p_F) = p_F³/(3π²ℏ³)

ε(p_F) = (1/(π²ℏ³))∫₀^{p_F} √(p²c² + m_n²c⁴) p² dp

p(p_F) = (1/(3π²ℏ³))∫₀^{p_F} [p²c²/√(p²c² + m_n²c⁴)] p² dp

完全自旋极化（所有自旋朝上）时：

**s = nℏ = p_F³/(3π²ℏ²)**

挠率修正能密度：

**ε_T = (3κ/32)s² = (3/32)·(8πG/c⁴)·(p_F³ℏ/(3π²ℏ³))²·ℏ² = G/(12π³c⁴)·p_F⁶/ℏ²**

与费米动能密度的比值（非相对论极限 p_F ≪ m_nc）：

ε_kin ≈ p_F⁵/(10π²m_nℏ³)

**ε_T/ε_kin = (G p_F⁶/(12π³c⁴ℏ²)) / (p_F⁵/(10π²m_nℏ³)) = 10π²Gm_nℏp_F/(12π³c⁴) = 5Gm_nℏp_F/(6πc⁴)**

代入数值 G = 6.67×10⁻¹¹, m_n = 1.67×10⁻²⁷, ℏ = 1.05×10⁻³⁴, c = 3×10⁸：

ε_T/ε_kin = [5×6.67×10⁻¹¹×1.67×10⁻²⁷×1.05×10⁻³⁴ / (6π×(3×10⁸)⁴)]·p_F = **3.63×10⁻⁸⁷·p_F** (SI)

核密度 n₀ = 0.16 fm⁻³：

p_F = ℏ(3π²n₀)^{1/3} = 1.05×10⁻³⁴×(3π²×1.6×10⁴⁴)^{1/3} ≈ **1.8×10⁻¹⁹ kg·m/s**

**ε_T/ε_kin ~ 3.63×10⁻⁸⁷ × 1.8×10⁻¹⁹ ~ 6.5×10⁻¹⁰⁶**

**结论：对于理想中子气体，挠率修正完全可忽略。**

#### 但：铁磁相变可以放大效应

在某些核物态方程模型（如 Skyrme 力参数化）中，n ~ 3–5 n₀ 时可能出现铁磁相变（自旋极化），使 P_s ~ 0.5–1。更关键的是，若考虑夸克物质核心（色超导相），自旋-1 的 Cooper 对可产生更大自旋密度。此外在 quarkyonic matter 或 hyperon matter 中，Λ 超子的极化可贡献额外自旋密度。

### 20.5 挠率排斥对最大质量的影响

即使挠率修正很小，它对最大中子星质量的影响可能是不成比例的，原因：最大质量对物态方程的高密度行为极为敏感（因果极限 M_max ≲ 3M_⊙）。

Rhoades-Ruffini 因果极限：假设 n > n_match 时取因果极限 p = ε（声速 = 光速），则

**M_max ≈ 4.0 (n₀/n_match)^{1/2} M_⊙**

挠率的排斥效应等价于使物态方程变硬（stiffer），因为 ε_eff < ε 但 p 不变（在给定密度下，有效密度减小相当于有效声速增大）。

定量估计（Delsate & Kleban, 2015 的推广）：设挠率修正使有效压强增加 δp_T，则最大质量的相对变化

δM_max/M_max ~ ½ (δp_T/p₀)|_{r=0}，其中 p₀ 是星体中心压强。

完全自旋极化中子星：δp_T = ε_T = G p_F,0⁶/(12π³c⁴ℏ²)。

中心费米动量 p_F,0 ~ 2m_nc（超相对论性）：

ε_T ~ G(2m_nc)⁶/(12π³c⁴ℏ²) = 64Gm_n⁶c²/(12π³ℏ²)

~ [64×6.67×10⁻¹¹×(1.67×10⁻²⁷)⁶×(3×10⁸)²] / [12π³×(1.05×10⁻³⁴)²]
~ [64×6.67×10⁻¹¹×2.2×10⁻¹⁶²×9×10¹⁶] / [12π³×1.1×10⁻⁶⁸]
~ 8.5×10⁻¹⁵⁴/4.1×10⁻⁶⁶ ~ **2×10⁻⁸⁸ Pa**

而中子星中心压强 p₀ ~ 10³⁵ Pa。

**δp_T/p₀ ~ 10⁻¹²³**

**最终结论：在 EC 理论中，挠率对中子星最大质量的修正 δM_max/M_max ~ 10⁻¹²³，完全不可观测。**

### 20.6 传播挠率的情况（PGT 理论）

若挠率可传播（有独立动力学自由度），情况完全不同。

PGT 中挠率的传播模可以有质量 M_T 和宏观力程 λ_T = ℏ/(M_T c)。

若 M_T ~ 10⁻³ eV（实验允许的最小值），则 λ_T ~ 0.2 mm。

在中子星尺度（R ~ 10 km）上，传播挠率场可在星体外部产生长程力：

V_T(r) ~ −α_T (GM/r) e^{−r/λ_T}

对 λ_T ~ 0.2 mm ≪ R_NS，此力在星体内部是短程的，但在表面附近可以修改引力势。

对 TOV 方程的修正：有效引力常数变为 G_eff = G(1 + α_T e^{−r/λ_T})。

在星体内部深处（r ≫ λ_T），G_eff ≈ G（无修正）。在表面附近（r ~ R_NS），e^{−R/λ_T} ~ e^{−10¹³} ≈ 0（同样无修正）。

因此，即使传播挠率在中子星上也几乎没有效应——因为力程太短。

例外：若挠率传播模无质量（M_T = 0），则力程无限，α_T 被 PPN 参数严格约束（|α_T| < 10⁻⁵）。

## 21. Strominger 系统的精确构造

### 21.1 背景：标准 CY 紧致化的局限

CHSW（1985）标准嵌入方案：紧致流形 K⁶ 是 Calabi-Yau（SU(3) holonomy，Ricci 平坦）；规范丛 V 的联络 A 等于切丛联络（standard embedding）；H₃ = 0；伸缩子 Φ = const。

优点：满足所有超对称条件、数学优美。问题：① standard embedding 要求 V = TK，给出规范群 E₆，但其 **27** 含 exotic particles；② H₃ = 0 太严格；③ Φ = const 要求零阶 α' 修正，高阶下不稳定。

### 21.2 Strominger 系统（1986）

问题：保持 N=1 超对称的最一般 10D 背景是什么？要求存在 Killing spinor ε。

**条件一（引力微子）**：δψ_M = (∇_M − ¼H_{MNP}Γ^{NP})ε = 0 ⇒ ∇^{(−)}_M ε = 0，其中 Γ^{(−)P}_{MN} = Γ̊^P_{MN} − ½H^P_{MN}。

**条件二（gaugino）**：δχ = F_{MN}Γ^{MN}ε = 0 ⇒ Hermitian-Yang-Mills：F_{ab} = F_{ā b̄} = 0（全纯性）、g^{a b̄}F_{a b̄} = 0（零斜率/稳定性）。

**条件三（dilatino）**：δλ = (Γ^M∂_MΦ − (1/12)H_{MNP}Γ^{MNP})ε = 0 ⇒ dΦ = ½ ι_v H。

**条件四（Bianchi / 反常抵消）**：dH = (α'/4)[tr(R∧R) − tr(F∧F)]。

### 21.3 Strominger 系统的几何等价表述

**定理（Strominger, 1986）**：存在满足所有超对称条件的解 ⟺ 存在 (M⁶, J, ω, H, Φ, V) 满足：

1. M⁶ 是复流形：dJ = 0（J 可积，Nijenhuis 张量为零）
2. 存在全纯 (3,0)-形式：Ω ∈ H^{3,0}(M) 无零点
3. H-flux 与几何的关系：H = i(∂̄ − ∂)ω = d^c ω，等价于 dω ≠ 0，即 M⁶ 不是 Kähler 的
4. conformally balanced：d(‖Ω‖_ω ω ∧ ω) = 0，或等价地 d^*ω = d^c ln‖Ω‖_ω
5. HYM 规范丛 V
6. Bianchi 恒等式：i∂∂̄ω = (α'/4)[tr(R^{(−)}∧R^{(−)}) − tr(F∧F)]

**关键洞察**：条件 (3) 表明 ω 不是闭的 ⇒ M⁶ 不是 Kähler 流形 ⇒ 不是 Calabi-Yau。

### 21.4 Bismut 联络与 torsional geometry

Bismut 联络（KT 联络）∇^{(+)} 满足：∇^{(+)}g = 0、∇^{(+)}J = 0、挠率 T^{(+)} 全反对称。

其挠率 T^{(+)}_{ijk} = −H_{ijk} = −(d^c ω)_{ijk}；Christoffel：Γ^{(+)i}_{jk} = Γ̊^i_{jk} + ½H^i_{jk}。

Bismut Ricci 曲率：Ric^{(+)}(X,Y) = Ric(X,Y) − ½d^*H(X,Y) + ¼Σ_i H(e_i,X,·)H(e_i,Y,·)。

Strominger 的 dilatino 条件等价于 Ric^{(+)}_{a b̄} = 2∇^{(+)}_a ∂_b̄ Φ。

### 21.5 Fu-Yau 解（2006）

第一个精确解析解。构造：设 M⁴ 是 K3 或 T⁴，其上构造主 T²-丛 π: M⁶ → M⁴。

ω = π^*ω_{M⁴} + (i/2)(θ₁ + iθ₂)∧(θ̄₁ − iθ̄₂)，其中 θ_i 含 connection 1-forms。

关键要求：主丛曲率 Ω₁, Ω₂ 满足 (i/2π)(Ω₁∧Ω̄₁ + Ω₂∧Ω̄₂) = (α'/4)[tr(R∧R) − tr(F∧F)]。

Fu-Yau 证明可化简为 M⁴ 上的 Monge-Ampère 型方程，用连续性方法证存在性。

物理解释：M⁶ 是 K3 上的 T²-丛 → 拓扑上等价于 IIA 弦论中的 NS5-brane 包裹 K3 的近地平线几何。

## 22. 传播挠率的宇宙学印记

### 22.1 挠率作为暗能量候选

若矢量挠率 V_μ 获得极小质量 m_V ~ H₀ ~ 10⁻³³ eV，其宇宙学行为类似暗能量。

模型：L_V = −¼F^{(V)}_{μν}F^{(V)μν} + ½m_V²V_μV^μ，其中 F^{(V)}_{μν} = ∂_μV_ν − ∂_νV_μ。

FRW 背景 ds² = −dt² + a²(t)dx² 上，V_μ = (V₀(t),0,0,0)：L_V = ½m_V²V₀²。

有效能量密度和压强：ρ_V = ½m_V²V₀²，p_V = −½m_V²V₀²。

**状态方程：w_V = p_V/ρ_V = −1**

这与宇宙学常数 Λ 完全等价！但关键区别是：V₀ 是动力学场，可以随时间缓慢演化。

### 22.2 修改的 Friedmann 方程

H² = (8πG/3)(ρ_m + ρ_r + ρ_V)

ρ̇_V + 3H(ρ_V + p_V) = 0 ⟹ ρ̇_V = 0 ⟹ ρ_V = const

在最低阶，这与 ΛCDM 完全等价。

高阶修正：若 V₀ 与曲率耦合（如 ξRV₀²），则 p_V = −ρ_V + δp，w_V = −1 + δw，δw ~ ξṘ/(m_V²V₀H) ~ O(α')。这可被未来暗能量状态方程测量（DESI, Euclid, Roman 目标精度 σ(w) ~ 0.02）约束。

### 22.3 挠率与暴胀

模型（Shapiro & Sola, 2009）：假设矢量挠率 V_μ 有非零真空期望值，且暴胀期 m_V ≫ H_inf。

缓慢滚动给出有效势能：V(V₀) = ½m_V²V₀² + λV₀⁴ + ξRV₀²。

暴胀参数：ε = (M_Pl²/2)(V'/V)²，η = M_Pl² V''/V；n_s = 1 − 6ε + 2η，r = 16ε。

如果 λ ~ 10⁻¹⁰（小耦合），则 **n_s ~ 0.965, r ~ 0.01**，与 Planck 2018 数据兼容。

### 22.4 CMB 中的挠率信号

挠率（特别是轴矢挠率 A_μ）与光子耦合：L_int = (c_A/M_Pl)A_μ J^μ_EM + (d_A/M_Pl)A_μ F_{νλ}ε^{μνλρ}∂_ρΦ + ⋯

**效应一：CMB 偏振旋转（cosmic birefringence）**

L_int ~ (d_A/M_Pl)A₀ E·B ⇒ Δα = (d_A/M_Pl)∫_{t_dec}^{t₀}A₀ dt ~ d_A A₀/(M_Pl H₀)。

最新限制（ACT/SPT, 2023）：|Δα| < 0.35° (95% CL) ⟹ **|d_A A₀| < 0.006 M_Pl H₀ ~ 5×10⁻⁵⁴ GeV²**

**效应二：CMB B-模偏振**

若 A₀ 有空间涨落 δA(x)，Δα(n̂) = ᾱ + δα(n̂)，将 E-模部分转为 B-模：C_ℓ^{BB,torsion} ~ (δα)² C_ℓ^{EE}。当前限制 δα < 0.5°（Planck 2018），未来 CMB-S4 目标 δα < 0.1°。

## 23. 大统一群与 Calabi-Yau 拓扑的精确对应

### 23.1 E₈ 的子群链

E₈ ⊃ E₇×SU(2) ⊃ E₆×SU(3) ⊃ SO(10)×U(1) ⊃ SU(5)×SU(3)×U(1) ⊃ SU(3)_C×SU(2)_L×U(1)_Y×SU(3)_family×U(1)ⁿ

在 CY 紧致化中，和乐群 SU(3) 嵌入 E₈ 的方式决定 4D 规范群：

G_4D = C_{E₈}(SU(3)_hol) = {g ∈ E₈ : [g,h] = 0 ∀h ∈ SU(3)_hol}

对于标准嵌入 SU(3)_hol ↪ E₈：**C_{E₈}(SU(3)) = E₆** ⇒ 4D 规范群为 E₆×E₈'。

### 23.2 非标准嵌入与 SO(10)/SU(5)

方案 A：SU(3)_hol → SU(2) ⊂ E₈ ⇒ C_{E₈}(SU(2)) = E₇（太大）。
方案 B：SU(3)_hol → SU(3) ⊂ SU(5) ⊂ E₈（非对角嵌入）⇒ C_{E₈}(SU(3)) = E₆（仍 E₆，但物质含量不同）。
方案 C：用 SU(4) 或 SU(5) 结构群的全纯矢量丛 V：**C_{E₈}(SU(4)) = SO(10)**，**C_{E₈}(SU(5)) = SU(5)** ⇒ 直接得 GUT 规范群。

### 23.3 代数数的拓扑约束

手征费米子代数由 Atiyah-Singer 指标定理给出：N_gen = ind(∂̄_V) = ∫_K Td(K)·ch(V)。

对 SU(n) 丛：ch(V) = n + c₂(V) + ½(c₂(V)² − 2c₃(V)) + ⋯
Td(K) = 1 + ½c₁(K) + (1/12)(c₁(K)² + c₂(K)) + (1/24)c₁(K)c₂(K)

对 CY₃：c₁(K) = 0 ⇒ N_gen = ∫_K[½n c₂(K) + ½c₂(V) + (n/24)c₁(K)c₂(K) − ½c₃(V) + ⋯]

化简（利用 c₁(K) = 0）：

**N_gen = ½ ∫_K c₃(V)**

要求 N_gen = 3 ⇒ ∫_K c₃(V) = 6。

### 23.4 Donaldson-Uhlenbeck-Yau 定理与丛的稳定性

**定理（DUY, 1986）**：全纯矢量丛 V 上存在 HYM 联络 ⟺ V 是 poly-stable（Mumford-Takemoto）。

稳定性定义：对所有全纯子丛 W ⊂ V，μ(W) = (1/rank(W))∫_K c₁(W)∧ω∧ω ≤ μ(V) = 0（SU(n) 丛 c₁(V)=0）。

Spectral construction（Friedman-Morgan-Witten, 1997）：椭圆纤维化 K → B² 上构造稳定 SU(n) 丛：选 spectral cover C ⊂ K（n-叶覆盖底空间 B）；选 C 上的线丛 L；通过 Fourier-Mukai 变换构造 V = FM(C, L)。稳定性自动满足（适当条件下）。

三代模型：取 B = F₁（第一 Hirzebruch 曲面），spectral cover 为 5-叶覆盖（SU(5) 丛），选适当 L 使 c₃(V) = 6（Braun, Ovrut 等, 2005）⇒ 规范群 SU(3)_C×SU(2)_L×U(1)_Y×U(1)_{B−L}，三代手征费米子。

## 24. 终极综合：两条路线在弦论中的统一

### 24.1 弦论低能有效作用量中的挠率

10D 超弦有效作用量（弦 frame，到 α'³）：

S = (1/2κ₁₀²)∫d¹⁰x √|g| e^{−2Φ}[R + 4(∂Φ)² − (1/12)H_{MNP}H^{MNP} + (α'/8)(trR^{(+)}∧R^{(+)} − trF∧F) + (α'³/(2¹¹·3·5!))ζ(3)t₈t₈R⁴ + ⋯]

其中 H₃ = dB₂ + (α'/4)(ω_{3L} − ω_{3YM})。

关键识别：**T^P_{MN} = ½H^P_{MN}** —— 这就是时空挠率。

### 24.2 挠率-规范-引力的统一方程

| 路线一概念 | 弦论对应 | 新含义 |
|---|---|---|
| 挠率 T_{λμν} | H-flux | 基本场（非代数约束） |
| 自旋密度 s_{λμν} | 弦世界面流 | 弦端点携带自旋 |
| 四费米子耦合 | 弦散射振幅 | α' 修正 |
| PPN 参数 | 弦振幅低能极限 | 由模空间稳定化决定 |
| 挠率不传播 | H₃ 有质量（compactification） | 取决于紧致化 |

### 24.3 最终方程——广义 Einstein 方程

弦论 β 函数 = 0：

R_{MN} − ¼H_{MPQ}H_N^{PQ} + 2∇_M∇_NΦ + O(α') = 0

∇^P H_{PMN} − 2(∇^PΦ)H_{PMN} + O(α') = 0

R − (1/12)H² + 4□Φ − 4(∂Φ)² + (D−10)/(3α') + O(α') = 0

当 D = 10 且 H = 0 时：回到标准广义相对论 + 伸缩子。当 D = 4 且 H ≠ 0 时：得到含挠率的 4D 引力理论。

### 24.4 终极图景

路线一（EC 挠率：独立几何量 / 来源=物质自旋密度 / 强度=G / 不传播）→ 弦论低能极限（H₃ ↔ T）→ 10D 超弦/M 理论（挠率 = H-flux / 来源=弦世界面拓扑 / 强度=α' / 传播）→ 紧致化（CY/torsional）→ 路线二（KK + 超对称：4D 规范群 = f(CY 拓扑) / 代数 = |χ(CY)|/2 / 耦合统一 = SUSY RGE / 暗物质 = LSP）。

两路线在弦论中交汇：①路线一的挠率是路线二中 B 场的低能表现；②路线二的超对称保证路线一中挠率量子效应可控；③路线一的自旋-挠率耦合对应弦端点 (Chan-Paton) 自旋；④路线二的 CY 拓扑决定路线一中挠率的有效强度和质量。

## 附录 C：重要定理的精确陈述

- **C.1 (Yau, 1977)**：设 (M,J) 是紧致 Kähler 流形，c₁(M) = 0。则在每个 Kähler 类 [ω] 中，存在唯一的 Ricci 平坦度量 g。
- **C.2 (Witten no-go, 1981)**：设 K^d 是光滑、紧致、无奇点的 Riemann 流形。从高维 Dirac 算子零模得到的 4D 费米子谱总是矢量型的，除非：(a) K^d 上有非平凡规范丛，或 (b) K^d 允许奇点，或 (c) 高维理论包含反对称张量场。
- **C.3 (Donaldson-Uhlenbeck-Yau, 1986)**：紧致 Kähler 流形 (M,ω) 上的全纯矢量丛 V 允许 HYM 联络 ⟺ V 是 Mumford-Takemoto poly-stable。
- **C.4 (Strominger, 1986)**：10D N=1 超引力 + 超 YM 的 N=1 紧致化 M₁₀ = M₄×K⁶ 等价于五条（复流形 + 全纯 Ω + conformally balanced + H = i(∂̄−∂)ω + 全纯稳定丛 HYM + Bianchi）。
- **C.5 (Fu-Yau, 2006)**：Strominger 系统在小扰动下存在解；在 K3 或 T⁴ 上的主 T²-丛构造的 non-Kähler 流形上可化简为 Monge-Ampère 型方程，用连续性方法证存在性。
