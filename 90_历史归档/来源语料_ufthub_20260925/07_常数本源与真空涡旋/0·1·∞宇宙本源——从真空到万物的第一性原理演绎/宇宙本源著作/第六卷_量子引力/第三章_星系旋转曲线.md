# 第三章 星系旋转曲线的挠率解释
## 3.1 星系旋转曲线问题
漩涡星系的恒星旋转速度v(r)，根据牛顿引力，应该随半径r减小，v∝1/√r，但是观测发现v(r)在星系外围保持常数，也就是平坦旋转曲线，这是暗物质最早的证据，需要暗物质晕提供额外的引力。

我们的挠率场暗物质自然产生平坦旋转曲线：挠率场在星系外围形成暗物质晕，密度ρ∝1/r²，所以引力加速度a∝M(r)/r²∝(∫ρ r² dr)/r²∝r/r²=1/r，所以v²=ar∝常数，v是常数，正好是平坦旋转曲线，和观测一致。

## 3.2 重子图利-费希尔关系
观测发现星系的旋转速度v和重子质量M_b满足关系M_b∝v^4，也就是重子图利-费希尔关系，这个关系在冷暗物质模型中是巧合，但是在我们的模型中，挠率场和重子物质是耦合的，重子物质的引力势阱吸引挠率场，所以暗物质质量和重子质量成正比，自然产生M_b∝v^4的关系，和观测一致。

## 3.3 星系旋转曲线的普适性
观测发现星系旋转曲线有普适的形状，也就是核心密度是常数，不是尖点，我们的挠率场是相干场，暗物质晕中心密度平坦，自然产生核心，没有尖点问题，和观测一致。

## 3.4 本章小结
挠率场暗物质自然解释平坦旋转曲线、重子图利-费希尔关系、核心密度，和星系观测一致，没有冷暗物质的小尺度问题。
