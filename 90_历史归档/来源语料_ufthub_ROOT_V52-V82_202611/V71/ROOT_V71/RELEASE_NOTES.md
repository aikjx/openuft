# ROOT V71 版本验收公告（2026-11-17）

## 与 V70 的可检验改进

- 修正 V70 假设性第五力采用整体点质量源的建模限制：新增均匀球解析有限尺寸 Yukawa、分层球稳定积分、等质量不同分层对照、长短程渐近和源荷符号反转。
- 明确以 2026 年已发表的有限尺寸形状因子文献为基础，不声称原创发现此数学形式。
- 从前版多天体环境拓展为 95 条核心方程索引、67 项跨领域方法矩阵、22章研究正文和 192 行合成实验设计。
- 采用 `exp[-(R-s)/lambda]` 稳定核以及大尺度解析原函数；避免 `cosh(R/lambda)` 溢出或 `exp(-R/lambda)` 下溢错误。
- 浏览器端提供离线可交互演示，并与 Python 独立计算交叉测试。
- 明确 `G` 仍为输入、量子 UV 完备性未建立、真实新力未检测、四力统一未完成。

## 已解决的模型错误与未解决的根本问题

**解决（数值计算/前提内推导）：** 有限球源形状、分层结构影响、稳定短程极限、规范耦合交点、异常和多条件可辨识性。  
**未完成（物理发现/独立证明）：** G 的无实验反标定预测；手征规范群/三代谱的单一本源；所有量子一致性；任何新相互作用的独立实验发现；完整四力统一。

**重要：** 工程验收报告核对的是指定数学模型的软件实现，绝非实验上的发现证明。
