### 1.2 H1 硬边界：α_geom vs α_exp

```
α_geom = Φ_T² = 1/128 = 0.00781250
α_exp  = 1/137.036 = 0.00729735
偏差：7.06%
```

**跑动修正尝试（已证伪）**：
- 单圈跑动使 α 变大（从 1/128 单圈跑到 Z 标度 → 1/107.966；从 1/137 跑 → 1/117.002）
- 实验 α(M_Z) = 1/128.9（比 1/128 更小）
- **方向矛盾**：跑动使 α 更大（朝 1/107.966），但实验更小（朝 1/128.9），方向相反
- 旧叙事 "1/128 经单圈跑动校准到 1/139.236 即闭合" 亦**证伪**：1/139.236 既非真实实验值（实验=1/128.9），也非 1/128 跑动结果（=1/107.966），属误记

**结论**：
- ~~"1/128 经跑动校准到 1/137"~~ → **撤回**（被 alpha_h1_diagnostic.py EXIT=0 证伪）
- 框架能**容纳**实验 α（旋转支选点，残差~10⁻⁸⁰）
- 但**无法预测** α 绝对值

**H1 边界**：这是一个**硬性未解问题**

**P2 诚实推进（已实装 `03-物理统一场/p2_constraint.py`，EXIT=0）**：
- 把旋转支自由选点 `phi* = arctan(alpha_exp)` 降级为**拓扑约束解**：`tan(phi) = Phi_T²`（Phi_T = 2^(-3.5) 为框架内部拓扑相位，零实验输入）
- 解出 `phi_geom = arctan(1/128)`，框架**纯拓扑预测** `alpha = 1/128`，约束自洽残差 = 0
- P2 **消除自由选点质疑**（phi 不再引用 alpha_exp），但**仍输出 1/128 而非 1/137.036**
- 实验与 1/128 的 7.06% 缺口 P2 不弥合，仍属 H1 开放项；如需闭合须引入 M1 级非微扰/边界修正（未来工作）
