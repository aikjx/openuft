## 1. 拓扑量子指标与维数投影

32 维 Dirac 旋量复维数为 2¹⁶ = 65536，投影至 4 维得 2² = 4。指标比：

```
N2_ratio = 2¹⁶ / 2² = 2¹⁴ = 16384
```

为整数，满足整数周期抵消条件，使 32 维内部反常可按 2¹⁴ 整数比被 4 维扇区吸收。

内部 28 维模空间（32−4=28）的手征流守恒要求 28 为 Bott 周期 8 的倍数，但 `28 = 4×7` 不满足 `8k`。因此必须引入 4 维边界项补偿（Bott 周期亏缺 `(28 mod 8)/8 = 1/2`）。这一边界项同时是 α 跑动校准的物理来源。

## 2. 电荷几何化与精细结构常数（N1b · v2 精确化）

## 4. 牛顿常数 G 的诚实处理与宇宙学定标（F2b）

普朗克单位 `ℓ_P²c²/ℏ` 量纲虽为 G，但数值 = G/c。任何 `G = Ξ·ℓ_P²c²/ℏ` 的构造要求 `Ξ = c`（不独立）。200 位实测 `Ξ_required = 299792458.0 = c`，证明 G 无法在纯拓扑框架内生成数值。

```
S_dS = πc³/(GℏH₀²)   ⟹   G = πc³/(S·ℏH₀²)
```

其中 S 为视界信息容量。取最自然的 Bekenstein 面积律 `N_area = (R_H/ℓ_P)²`、`S_BH = N_area/4`：

| 量 | 数值 |
|---|---|
| R_H = c/H₀ | ≈ 1.37×10²⁶ m |
| N_area | ≈ 7.21×10¹²¹ |
| S_BH = N_area/4 | ≈ 1.80×10¹²¹ |
| S_dS（观测 G 下） | ≈ 2.52×10¹⁰⁵ |
| **S_dS / S_BH** | **≈ 1.40×10⁻¹⁶** |
| G_area / G_obs（面积律反推） | ≈ 1.40×10⁻¹⁶ |

**诚实结论**：`S_dS/S_BH ≈ 1.4×10⁻¹⁶` 即著名的**宇宙学常数问题**（10¹²⁰ 量级精细调节）。若强行用面积律反推 G 会偏小 16 个数量级——框架给出 G 的结构式，但 S 的边界锚点（为何 S_dS ≪ S_BH）乃未解决的宇宙学常数问题。G 的数值真正生成须待该问题解决，不虚假闭环。
