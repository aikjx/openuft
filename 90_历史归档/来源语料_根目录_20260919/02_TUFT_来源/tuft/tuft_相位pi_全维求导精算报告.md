## 二、9 处 FAIL（真实缺陷）

### F1 类光曲线不能用"固有时 τ"参数化（S1a.2）
原文 `dx/dτ = c·û` 并沿 τ 积分，但**类光曲线 ds = 0 ⇒ 固有时 dτ = ds/c = 0**（处处为零）。类光曲线的合法参数是**仿射参数 λ**，不是固有时。下文"沿固有时绕行一圈 `Δτ = L/c`"随之失去依据。

### F2 Frenet-Serret：切矢导数由**曲率**驱动，不是挠率（S1b.2）
原文 `dû/dτ = T·n̂`。标准 Frenet-Serret：
- `d t/ds = κ·n`（**曲率 κ** 驱动切矢变化）
- `d n/ds = −κ·t + τ·b`
- `d b/ds = −τ·n`（**挠率 τ** 是副法矢的导数）

原文把 **κ 与 τ 的角色互换**——这是实质性概念错误，使"挠率 T 构造莫比乌斯拓扑"的链条失去几何依据。

### F3 "∮T dτ = ℏπ/(αKΩ)" 是为凑 π 而**反设**的（S2.2）
由通式 `Δφ = (αKΩ/ℏ)·X`（X = ∮T dτ），要得 `Δφ = π` **必须** `X = ℏπ/(αKΩ)`。
原文直接把该值当作"挠率线积分"给出 —— 属**倒推**：以"莫比乌斯给出 π"（已知拓扑事实）为输入反解 ∮T dτ，再回到 π。**无任何独立推导**给出 ∮T dτ 的这一取值。

### F4 末尾 `1/(2π)` 是事后补丁（S2.3）
`ω = dφ/dτ` 本已定义相位，再乘 `1/(2π)` 等于把 ω 里多塞的 2π 人为扣回 —— 为凑 π 而加的补偿因子，非几何必然。

### F5 "外部空间旋转 2π" ≠ "莫比乌斯绕行一圈"（S3.1）
- (a) 外部空间旋转 2π：SO(3) 绕固定轴转一圈，自旋-1/2 表示给 −1（标准）；
- (b) 莫比乌斯带中心线走一圈：法向翻转（带子单侧性）。

原文把 (a) 与 (b) **直接等同**，但未证明两者相位相等 —— 核心的未证明跳跃。

### F6 "挠率是费米子自旋的必要条件" 与已知物理**矛盾**（S5.1）
纯黎曼时空（T=0）中，只要存在**自旋结构**，Dirac 旋量场与自旋-1/2 表示**完全良定义**（弯曲时空 Dirac 方程成熟）。挠率（爱因斯坦-嘉当）是**可选扩展**，不是自旋的必要条件。自旋 1/2 的拓扑根源是 **SO(3) 的 ℤ₂ 双覆盖**，与挠率无逻辑必然关系。

### F7 玻色子行概念混淆（S7.2）
"一圈空间旋转 2π 得 +ψ"（轨道/标量相位）与"交换两玻色子得 +ψ"（交换对称性）**不是同一操作**；原文用前者推后者，属混为一谈。

### F8 §8 数值代码的曲线**不闭合**（S8.1）
参数化 `x=(2+0.5cos(τ/2))cos τ` 把莫比乌斯的半扭转混入了**中心线半径**：
- 起点 `(2.5, 0, 0)`，终点 `(1.5, 0, 0)`，间距 = **1.0000（不闭合）**
- 对非闭合曲线，W 积分**无拓扑意义**（任意值）

### F9 原文"W ≈ 0.5"与代码实跑不符（S8.5）
复现原代码得 **W(open curve) = −0.0029 ≈ 0**，**不是**原文声称的 0.5。该"验证"无效。

> 对照（正确做法）：**闭合**平面圆 writhe = `0.0000`（与解析 0 一致）；闭合非平面三叶曲线 writhe = `−6.1211`（闭合间距 4.5e-16）——证明该积分**只对闭合曲线**才给出稳定拓扑值。

## 三、6 处 BOUNDARY（需澄清）

1. **S1a.3**：若把 τ 退读为"任意仿射参数"，则 `dx/dτ=c` 只是归一化约定，"固有时绕行"随之失去物理含义。
2. **S2.4**：上游 `ω=(2π/ℏ)αKTΩ` 依赖 `E=ℏf=αKTΩ` —— 该能量式**上一章已被量纲审查判非法**，故本链条建立在一个量纲非法的式子上。
3. **S6.1**：`W=(1/4π)∮û·(dû×d²û)dτ` 是切标架的 **writhe（自链接数）**，不是"全挠率扭转积分 Tw"；原文把二者等同属混用。
4. **S6.2**：半整数/整数区分方向正确，但与 ∮T dτ 是**两个不同的量**。
5. **S7.1**：费米子行结论（π, −ψ）作为已知量子力学结论正确，但"由莫比乌斯挠率拓扑导出"未成立。
6. **S7.3**：winding number 是整数；半整数属自链接数 Lk/writhe（与上一章一致）。

## 四、通过项（PASS 6）

- 类光条件 `ds²=0` 成立（S1a.1）。
- 标准 Frenet-Serret 方程本身（S1b.1）。
- 原文链条**代数上**确实给出 π（在反设 ∮T dτ 后，S2.1）。
- `SO(3)` 双覆盖给出 `ψ(θ+2π)=−ψ`、`ψ(θ+4π)=+ψ`（**表示论**事实，S3.2/S3.3）——正确，但**不需**莫比乌斯/挠率。
- 闭合平面圆 writhe = 0（S8.3）。

## 五、结论

1. **正确内核**：`ψ(θ+2π)=−ψ, ψ(θ+4π)=+ψ` 是 SU(2)（SO(3) 双覆盖）的**表示论事实**，完全正确——但它的根源是**旋转群的双覆盖**，不是"莫比乌斯挠率拓扑"。
2. **9 处 FAIL 集中在**：参数化矛盾（类光固有时）、Frenet κ/τ 角色互换、`∮T dτ` 反设、`1/(2π)` 补丁、旋转等同跳跃、挠率必要性错误、玻色子混淆、数值曲线不闭合、W 声称与实跑不符。
3. **诚实定位**：本稿是"用拓扑语言**重述**已知自旋-1/2 结论"的尝试；关键跳跃（莫比乌斯 ⇒ π ⇒ 自旋统计）**未被证明**，且包含一处概念性错误（κ/τ）与一处数值不实（W≈0.5）。
4. **红线**：以上均为框架内自洽性审查，不构成对 TUFT 物理真实性的主张。
