## 二、六条原理逐条

统一记法：`κ₆` 归一到 1（`N_T` 只依赖比值 `Z/κ₆`），`N_T(Z)=1+4/Z`，ghost-free 域 `Z>0` 或 `Z<−4`。读数：`N_T(1)=5`、`N_T(2)=3`、`N_T(12/5)=8/3`、`N_T(−2)=−1`（域外）。

### 2.1 P1 规范/引力对称性（局部标度）

`d=6` 时 `w(√g R)=6−2=4`，`w(√g T²)=6+2=8`（`e→e^σ ⇒ T→e^σT`）。无补偿场时每个单项必须各自权重 0：`4a=0`、`8b=0` ⇒ 系数矩阵秩 **2**、零空间 **0**，唯一不变量为 0。加补偿场 `χ`（权重 1）后 `χ⁻⁴√gR`、`χ⁻⁸√gT²` 各自不变，零空间升到 **2**——任意系数都行，仍不钉 `Z`，且多一个场。

**判决：否证。** 权重不同 ⇒ 对称性给不出 `Z` 的方程；加 dilaton 只增成本。

### 2.2 P2 拓扑指数（η 不变量 / index）

拓扑项 `S_θ = θ·n`，`n = index(D_T) ∈ ℤ`；项表 `{θ, n, index}` **不含 Z**（`Z` 只乘动力学的 `T²` 项）⇒ `∂S_θ/∂Z ≡ 0`。三点读数：`Z=1,2,12/5` 给同一 `θ·n=1`，而 `N_T=5,3,8/3` 互异。

**判决：族（自由度 1）。** 拓扑数只约束 `θ`，对 `Z` 是 0 约束——`Z` 可取 ghost-free 全域。

### 2.3 P3 单圈/真空能抵消

热核 `a₀ = Tr(1)`，其导数预算为 0；`T²` 算子是两导（预算 2 > 0）⇒ `1/Z` 进不了 `a₀`，系数 **0**。抵消方程 `Σ_b N_b − Σ_f N_f = 0` 的项表 `{N_b,N_f}` 也不含 `Z`，系数 **0**。

**判决：否证。** 方程与 `Z` 无关，不可能定出 `Z`。即使某一圈数组合刚好抵消，也只是把 `κ₆` 重正化，不碰 `Z`。

### 2.4 P4 谱条件（谱三元组单迹）

单迹假设（规范动能与扭率动能同源）给

```
1/Z = r · (Tr T²/Tr 1) / (4κ₆)，  r = f₂/f₀，  Tr T²/Tr 1 = 5/3（J85）
⇒ N_T = 1 + (5/3) r
```

| `r=f₂/f₀` | `Z/κ₆` | `N_T` |
|---|---|---|
| 1/3 | 36/5 | 14/9 |
| **1** | **12/5** | **8/3** |
| 3 | 4/5 | 6 |
| 5 | 12/25 | 28/3 |

**判决：族（自由度 1：`r`）。** `r=1` 给条件点 `Z=12κ₆/5`、`N_T=8/3`，但 `f₂=f₀` 不是原理，只是 cutoff 约定；本仓没有固定 `f₂/f₀` 的仪器（缺 cutoff 的前三个矩）。

### 2.5 P5 边界条件 / δ-brane 匹配

Israel 方程 `[K_μν] = −κ₄(σ_μν−…)`，项表 `{K, σ, κ₄}` **不含 Z**。brane 扭率项只把 `1/Z_eff = 1/Z + 1/Z_b` 平移：`Z_b=1,2,5` 给 `Z_eff=1/2, 2/3, 5/6`，bulk `Z` 仍自由。

**判决：否证。** 匹配方程与 `Z` 无关；`Z_b` 只改有效系数，不钉 bulk `Z`。

### 2.6 P6 作用量对 Z 的变分驻定

`S_Z = ∫√g T²/(2Z)` ⇒ `∂S/∂Z = −∫√g T²/(2Z²)`。`Z=1` 时读数 `−1/2 ≠ 0`；驻定要求 `∫T²=0`，被积函数非负 ⇒ **`T≡0`**。

**判决：否证。** 驻定把扭率整个关掉，16 载体消失；且 `T=0` 时任何 `Z` 都给同一解，`Z` 仍不定。把 `Z` 升成动力学场只会多一个模量/平坦方向，不构成钉死。

## 五、逃逸口②：非常数整函数无正谱表示

判据：若传播子 `G(z)=1/E(z)` 有 Källén–Lehmann 正谱表示，则 `G` 是 Stieltjes 函数：`G(z)=a+∫₀^∞ dμ(t)/(z+t)`，`μ≥0`，`a≥0`；必要条件是 `G(z)>0` 且 `G'(z)≤0`（更强：`(-1)^nG^{(n)}≥0`）。

**定理（解析）**：非常数整函数 `E`（`E(0)=1`、无零点）的 `1/E` 不可能是 Stieltjes 函数。非常数 Stieltjes 函数必在 `(−∞,0)` 有割线（谱密度 `ρ≢0`）；`1/E` 是整函数、无割线 ⇒ `ρ≡0` ⇒ `1/E` 为非负常数 ⇒ `E` 为常数；`E(0)=1` 时唯一幸存者 `E≡1`（无动力学）。故**任何非常数整函数 form factor 都没有正谱表示**。

机器只验有限截断与 `e^z` 的符号：

| form | N | 正实轴极点 | `G'(1/2)` | Stieltjes | 判词 |
|---|---|---|---|---|---|
| `exp(−z)` | — | 0 | `G'(0)=1` | 否 | 定理：非常数整函数与正谱互斥 |
| 截断 | 2 | 0 | 1.280000 | 否 | 导数反号 |
| 截断 | 3 | **1** | 1.712247 | 否 | 正实轴极点 = 快子 |
| 截断 | 4 | 0 | 1.640995 | 否 | 导数反号 |
| 截断 | 5 | **1** | 1.649484 | 否 | 正实轴极点 = 快子 |
| 截断 | 6 | 0 | 1.648658 | 否 | 导数反号 |
| 截断 | 7 | **1** | 1.648726 | 否 | 正实轴极点 = 快子 |
| 截断 | 8 | 0 | 1.648721 | 否 | 导数反号 |

**判决：封死（正谱口径）。** 逃逸口只剩两条，都不构成新路：① 放弃正定性（indefinite metric / PT 型量子化）——与 I1 的 ghost 判据同类；② 放弃粒子解释（谱表示不适用）——那就没有低能有效项可对照，等于放弃统一目标。边界：定理是纸面论证，机器只覆盖有限截断。
