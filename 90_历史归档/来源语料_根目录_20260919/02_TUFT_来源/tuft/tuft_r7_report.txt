
============================================================================
  TUFT-R7 拓扑UFT 证明链 · 量纲与符号审查
============================================================================
  约定：ds=c dt, dτ=ds/c, β₁=(κ²+τ²)/⟨κ₀²+τ₀²⟩, m=(ℏ/c)√(κ²+τ²), ω=c√(κ²+τ²)

============================================================================
  1. 量纲审查（符号推演）
============================================================================
  设 [κ]=[τ]=L⁻¹  ⟹ [κ²+τ²]=L⁻²
  β₁ = (κ²+τ²)/⟨κ₀²+τ₀²⟩  ⟹ [β₁]=L⁻²/L⁻²=1（无量纲）✓
  [PASS] 1a: β₁ 无量纲  |  分子/分母同为 L⁻² ⟹ 无量纲 ✓
  m = (ℏ/c)√(κ²+τ²)：[ℏ/c]= (J·s)/(m/s)= kg·m ；×L⁻¹ ⟹ kg ✓
  [PASS] 1b: m 量纲 = 质量  |  [ℏ/c]·L⁻¹ = (kg·m)·m⁻¹ = kg ✓
  ω = c√(κ²+τ²)：[(m/s)·L⁻¹] = s⁻¹ ✓
  [PASS] 1c: ω 量纲 = 频率  |  (m/s)·m⁻¹ = s⁻¹ ✓
  g = (c²/2)∇lnβ₁：[c²]=L²/T²，[∇]=L⁻¹ ⟹ L/T²（加速度）✓
  [PASS] 1d: g 量纲 = 加速度  |  (L²/T²)·L⁻¹ = L/T² ✓
  □ = ∇² − (1/c²)∂_t²：两项同为 L⁻² ✓
  [PASS] 1e: □ 量纲自洽  |  ∇²=L⁻²；(1/c²)∂_t² = (T²/L²)·T⁻² = L⁻² ✓

  注（如实标注）：dτ = ds/c 且 ds = c·dt ⟹ **dτ = dt**。
     即本模型的『固有时』恒等于坐标时，**模型内不含狭义相对论的时间膨胀**（γ 因子缺失）。
  [INFO] 1f  |  dτ=dt ⟹ 无 SR 时间膨胀；模型的时钟快慢改由 ω(β₁) 承担

============================================================================
  2. 弱场审查：β₁ 静态解 → 引力加速度
============================================================================
  静态球对称解：β₁ = exp(2GM/(c²r))； ln β₁ = 2GM/(c²r)
  g = (c²/2)·d(lnβ₁)/dr · r̂ = (c²/2)·(−2GM/(c²r²)) r̂ = −(GM/r²) r̂
  [PASS] 2a: g(β₁) 与牛顿 g=−GM/r² 一致  |  g=-9.820302 m/s²；牛顿=-9.820302 m/s²（负号=指向地心，吸引 ✓）
  [INFO] 2b  |  β₁=exp(+2GM/(c²r)) 给出吸引；若取负号则 g 变排斥 ⟹ 该符号由牛顿极限唯一固定

============================================================================
  3. 符号审查（关键）：ω=ω₀√β₁ 作为局域时钟速率 vs GR/观测
============================================================================
  TUFT：ω(r)/ω_∞ = √β₁(r) = exp(GM/(c²r)) ≈ 1 + GM/(c²r)
  GR  ：局域钟速率 / 无穷远钟速率 = √(1 − 2GM/(c²r)) ≈ 1 − GM/(c²r)
  ⟹ 一阶**量值相同、符号相反**。

  【地球表面】 2GM/(c²r)=1.3923e-09
     TUFT ω/ω_∞ = √β₁      = 1 +6.9613e-10
     GR   钟速率比         = 1 -6.9613e-10
     两者之差              = 1.3923e-09（符号相反）
  【太阳表面】 2GM/(c²r)=4.2461e-06
     TUFT ω/ω_∞ = √β₁      = 1 +2.1230e-06
     GR   钟速率比         = 1 -2.1230e-06
     两者之差              = 4.2461e-06（符号相反）
  [FAIL] 3a: TUFT 与 GR 红移一阶符号一致?  |  TUFT 为 +GM/(c²r)（深势处钟**更快**）；GR/观测为 −GM/(c²r)（更慢）。符号相反 ⇒ 冲突

  实验判决：Pound–Rebka、GPS、光学原子钟均确认『深势处钟更慢』（即 GR 符号）。
  ⟹ 若把 ω 直接解释为**局域时钟速率**，TUFT 该式已被现有实验排除。

  可能的澄清路径（三选一，须在模型中显式声明）：
    (i)  ω 不是钟速率，而是『单位坐标时间内的本征振荡数』，观测频率需另乘传播因子 1/β₁
         ⟹ ω_obs = ω₀/√β₁ ≈ 1 − GM/(c²r) 与 GR 一致；
    (ii) β₁ 与本征频率的关系应为 ω = ω₀/√β₁（即 ω∝β₁^(−1/2)）；
    (iii) 承认差异并给出可检验区分（但当前实验已倾向 GR）。
  [INFO] 3b  |  推荐 (i)/(ii)：使钟速率 ∝ β₁^(−1/2)，方与弱场 GR 及 Pound–Rebka/GPS 相容

============================================================================
  4. 第五部分：统计涌现的形式一致性（微观→宏观）
============================================================================
  定义：⟨κ²+τ²⟩_macro = (1/N)Σ_i (κ_i²+τ_i²)（系综平均）
  则 β₁_macro = ⟨κ²+τ²⟩_macro / ⟨κ₀²+τ₀²⟩
  ⟹ m_macro 与 ω_macro 由同一 β₁_macro 决定：m=m₀√β₁, ω=ω₀√β₁（形式不变）✓
  [PASS] 4a: 宏观 β₁ 与微观同形式  |  β₁ 为比值 ⟹ 取系综平均后形式不变，m/ω 关系可平移到宏观 ✓（形式层面）
  [INFO] 4b  |  ⚠ 粗粒化是否保持 β₁ 的场方程（即 ⟨□β₁⟩ = □⟨β₁⟩ 是否成立）——非线性场方程下一般**不成立**，需重整化/闭合假设；属开放命题

============================================================================
  5. 判定汇总
============================================================================
  [量纲层]  PASS —— β₁ 无量纲、m 为质量、ω 为频率、g 为加速度、□ 自洽。
  [弱场层]  PASS —— β₁=exp(2GM/(c²r)) 给出吸引的牛顿 g（符号由牛顿极限唯一固定）。
  [符号层]  FAIL（关键）—— ω=ω₀√β₁ 作钟速率时与 GR/观测红移符号相反；需按 (i)/(ii) 澄清。
  [涌现层]  BOUNDARY —— 形式平移 PASS；非线性粗粒化闭合属开放命题。
