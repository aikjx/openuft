## 三 主定理 A：三路推出整数性，但必须标明哪一路是同源的

来料 63-7 取 `F_{θφ} = (N/2) sinθ`。Chern-Weil 给出

```
∫_{S²} F = 2π · (N/2) · ∫₀^π sinθ dθ = 2πN  ⇒  c₁ = (1/2π)∫F = N
```

`∫sinθ = 2` 由 Simpson 1/3 独立核过量级（实算 `2.000000000001`，仅作 sanity，精确结论走 Fraction）。由 `H²(S²,ℤ)=ℤ`，半整数网格 17 个值里只有 9 个给出合法 U(1) 主丛；`c₁(3/2)=3/2` 不是陈类。

**负对照（`A02`）**：把 `1/2` 改成 `1/3`，得 `c₁_bad = 2N/3`；N=1..6 只有 N=3 与 N=6 合法（`2/6`），而 A01 口径下 `6/6` 全合法。判据确实测的是「F 的归一系数」，不是任意标量——这也堵住了「换个磁通归一就能把半整数洗成整数」的侥幸。

> **同源性判定（`A04`，本册最自觉的一刀）**：Wu-Yang 南北极规范 `A_N=(N/2)(1−cosθ)dφ`、`A_S=−(N/2)(1+cosθ)dφ` 给 `A_N−A_S = N dφ`，过渡函数 `g=e^{iNφ}` 要求 `g(2π)=1`，与 `c₁=N` 是**同一个 `H²` 类的两种表述**。按「同源回验抓不到同源错误」刀，本册把它显式标为 INFO，不单列 PASS、不冒充独立证据，并加守卫 `SAME-SOURCE-TAGGED` 强制该标注存在。

真正独立的第三路是**物质场 holonomy**：它依赖「谱里有哪些电荷」，而前两路只依赖丛。对电荷 `q` 的场，绕赤道一圈 `exp(i·q·2πN)=1` 要求 `qN ∈ ℤ`。四条 `q` 档与四条 `N` 档的合法矩阵：

| q \ N | 1 | 2 | 1/2 | 3/2 |
|---|---|---|---|---|
| 1 | 是 | 是 | 否 | 否 |
| 2 | 是 | 是 | 是 | 是 |
| 1/2 | 否 | 是 | 否 | 否 |
| 3/2 | 否 | 是 | 否 | 否 |

**归一不变性（`A07`）**：`Q → λQ` 时 `q → λq`、`k → k/λ`，乘积 `q·k` 不变。λ 取 `1/2, 1, 2, 3, 4` 五档，基准 `q=1, k=3/2` 给 `q·k = 3/2` 全同。所以「半整数磁通」不是可换归一消掉的记号问题。

## 四 主定理 B：旋量是唯一含奇数 U(1)_F 荷的表示

取 `U(1)_F = 2H₆`（承接 V62 `vec_weights` 的矢量归一）。按权枚举：

- **矢量 12**：荷多重集 `0×10, +2, −2`，全偶，最小非零 `2`。
- **`Λᵏ(12)` 全 13 档**：每档取 `k` 个矢量权求和，权数恰为 `C(12,k)`，`q_min=−2`、`q_max=+2`，**全档全偶**；零荷个数依次为 `1, 10, 46, 130, 255, 372, 420, 372, 255, 130, 46, 10, 1`（k=5 的 372 与 V62 整理册 `A08` 的 5-形式荷划分同一读数，此处不新增证据）。
- **旋量 32**：权是 `(±1/2)⁶`，`2H₆` 使 `U(1)_F` 荷恰为 `±1`；32 个权，**含奇数荷**。

⇒ **定理（`B04`）**：张量侧最小电荷 `2`，旋量侧最小电荷 `1`。谱只要含旋量，`q=1` 的场就存在，半整数磁通必被 `A05/A06` 关闭。

按「关键表里的话也要由计算拼出」的纪律，这条不是「我记得旋量荷是 1」，而是 13 档张量枚举 + 32 个旋量权枚举共同拼出的读数。

## 五 主定理 C：两难判决，以及 14 个代数解的回代

**最小电荷敏感刀（`A06`）**：`q=2` 时 `N=1/2` 合法（`qN=1`），`q=1` 时非法（`qN=1/2`）。所以「半整数磁通是否合法」不是绝对问题，必须问「谱里有没有 `q=1` 的场」。

于是出现一个可算的两难：

- 要半整数磁通**开放** ⇒ 谱的最小电荷须为 2 ⇒ 谱只能由张量表示构成 ⇒ **没有 16 / 16bar** ⇒ 没有 SM 的 `(3,2)_{1/6}` 等手征物质。
- 要 SM 三代手征物质 ⇒ 谱必须含 32 旋量 ⇒ 最小电荷 1 ⇒ 半整数陈类非法。

遍历 289 组半整数双磁通，「至少一个陈类半整数」且「`q=1` 场 holonomy 单值」且「谱含 16」的组数为 **0**。`B06` 对「可兼得」判负（已登记 FAIL）。

**回代上一卷（`C01`）**：V63 整理册 `A08` 给出 14 个满足 `I_Q = 2(N_F+N_Y) = 3` 的半整数解。逐个检查两个陈类是否都是整数 ⇒ **合法解 0 个**。它们满足代数方程，却不能实现为紧致化上的场。整数网格上 `I_Q=3` 同样是 0 解（`C02`）。

⇒ **总判定（`C06`）**：三代奇偶障碍不是「整数磁通这一约定」的产物，而是「U(1) 主丛 + 含旋量谱」的**拓扑定理**。边界必须写明：这是「Spin(12) → SO(10)×U(1)_F 嵌入、物质场为 32 旋量、底流形为闭曲面」的条件定理，**不是**「所有高维统一模型都不可能」。
