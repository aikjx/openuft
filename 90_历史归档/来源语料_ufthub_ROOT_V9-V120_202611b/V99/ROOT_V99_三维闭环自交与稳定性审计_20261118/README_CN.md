# ROOT V99｜三维周期螺旋自交、稳定性与结拓扑审计

**日期：2026-11-18。科学证据：数学条件定理、Maxwell–Lorentz 模型计算和自动化测试。未发现新基本作用、未攻破四力统一、无真实实验。**

## 最新发现（与 V98 相比）

1. 从固定 \(H\)、固定 \(P_\phi\) 的相对论哈密顿约化，严格推导了五圈转折对称轨道必然具有四对不同时间的**空间重合**（若精确轨道存在、方位角单调）。
2. 在 V98 的 **13、17、21 阶线圈数值模型**中，分别确认四组近乎三维自交，空间位置差异约 `6.8e-14`—`7.5e-14 m`。这些是计算残差，不能当成物理距离测量。
3. 因原始曲线含潜在自交，**不能直接归类为普通空间结**。人工增加 `0.15 μm` 周期 z 扰动后的离散闭合多边形（并非动力学轨道）在 3 种投影下可计算 Fox 结行列式 `9`；这个结果不能赋予原始轨道。
4. 通过固定能量/正则角动量的二维 Poincaré 截面、事件时间导数和 6D 联合变分积分获得近抛物返回矩阵（迹约 2，行列式约 1）；**不能证明长期稳定或不稳定**。
5. 保留 V98 的 297 项任务，新增 16 项具体修复与待证任务，总计 313 项，非 313 项全部解决。

## 一键运行

推荐 Python 3.10+。安装依赖（首次需要从环境依赖库获取）：

```bash
python -m pip install -r requirements.txt
python verify_checksums.py
python run_all.py
```

重新计算 V99 数值和图表（数值运算相对较多）：

```bash
python run_all.py --regenerate
```

重新解压 V98 并独立执行其 35 项历史测试：

```bash
python run_all.py --historical
```

可选：如果安装 Playwright 与本地 Chromium，可单独运行：

```bash
python web/browser_smoke.py
```

打开 `web/index.html`，完全离线操作界面。

**注意**：重新生成数据和 PNG 图像后，文件的字节级 SHA-256 可能变化，应在 `--regenerate` 前先验收原始 ZIP 快照；重新生成后不要把哈希变化误称为原始 ZIP 已损坏。

## 研究分级

- **已严格证明（条件性）**：自治轴对称固定 \(P_\phi\) 哈密顿动力学转折点对称，若发生五圈精确周期回归，至少得到四对不同时间对应相同空间位置。
- **已独立数值计算**：离散双线圈源和周期候选的近自交、约化返回映射、人工扰动的折线代数不变量。
- **尚未证明**：连续物理源中严格存在精确周期解；无自交的真实结轨道；非线性长期稳定；无外部供电和辐射耗散的自发闭环；统一引力、强弱、电磁四种相互作用；独立推算 \(G\)。
