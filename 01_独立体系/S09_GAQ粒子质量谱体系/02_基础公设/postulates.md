## 4. 诚实空缺与结构性失败确认（2026-09-16）

- **结构性失败确认**：质量谱派生链被普朗克锚定污染——`G = c^3/(hbar*(kappa^2+tau^2))` 与 `m = hbar*sqrt(kappa^2+tau^2)/c` 联立退化出 `m = m_P` 唯一解。在已退化链上做质量比拟合必然系统性失败（40%-2000% 偏差不是精度问题，是链式退化）。
- **第二重边界**：归一化后 `kappa_tilde = 1/sqrt(1+alpha^2)`、`tau_tilde = alpha/sqrt(1+alpha^2)` **与质量无关**，质量全部寄于未解释的绝对尺度。本源方程解释的是 kappa/tau 相对比例（即 alpha），不是质量绝对值或比值。
- **修正建议**：
  1. 切断 G 式依赖，不再从 G 式派生链推导质量
  2. 引入 alpha_grav = (m/m_P)^2 作为引力质量比，而非绝对质量
  3. 质量层级移交 Yukawa 动力学（标准模型 Yukawa 耦合）
  4. A1-A3（三代拓扑分类）保留为 conjecture，不受派生链污染影响
- **收敛结论**：与仓库 v30 一致——代质量层级在拓扑结构层内无解，缺口收敛为**动力学 Yukawa 起源**单点；拓扑层贡献是代结构而非绝对质量。

## 5. 第一性冲突登记与修复（2026-09-15 检出 / 2026-09-16 确认结构性失败）

- **上游污染**：本体系的质量表达式建立在 v5/v4 派生链上，联立退化出 `m = m_P` **唯一解**。登记 `S09-C0001`，状态：`falsified -> structural_failure`。
- **第二重边界**：归一化后 kappa_tilde/tau_tilde 与质量无关，本源方程不携带质量信息。
- **区分对待**：A1-A3 属计数匹配，与 G 式派生链无代数耦合，**不受本冲突影响**，可继续作为 conjecture 保留。
