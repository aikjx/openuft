## 如何新增 doc

1. 在本目录创建 `YOUR_TOPIC.md`；新全球文献来源登记进入 [全球文献目录](../../05_全球研究/01_文献来源/README.md)
2. 在本 README.md 中添加索引
3. 在项目治理 CHANGELOG.md 添加变更记录
4. 提交 Pull Request
