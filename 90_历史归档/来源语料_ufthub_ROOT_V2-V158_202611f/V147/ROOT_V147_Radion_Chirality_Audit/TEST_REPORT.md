# ROOT V147 测试与证据边界

## 实际运行检查

- `python run_all.py`：**63 项 Python unittest 全部通过**，核心模型与测试无需第三方 Python 库。
- `python symbolic_audit.py`：**12/12 项 SymPy 代数恒等式全部通过**（安装 SymPy 时运行）。
- 完整性：静态文件 SHA-256 `MANIFEST.sha256`，ZIP CRC、解压独立复测在封包流程中执行。

## 核心测试覆盖

1. 6D Einstein–Maxwell 磁通紧化势，`n↔-n` 的反号简并。
2. 平直条件能够对多个不同整数 `n` 通过自由参数调节实现，证明不能唯一选 3。
3. `n=3` 示例的局部最低能量、质量、势垒及去紧化极限。
4. 驻点、Hessian、有限差分和临界点的解析灵敏度。
5. 保持 `ℏ,G` 量纲、第五力条件性耦合和正作用程。
6. 中性测试标量球谐模式，简并与 Legendre 正交积分。
7. `U(1)_F` 异常（精确有理数）；单态无法修复非阿贝尔异常。
8. 已知异常可消 `U(1)_{B-L}+N_R` 作为对照例。

## 不能称为通过的事项

- 四力统一的最终理论证明、在 ROOT 体系下重新推导标准模型。
- 六维 Einstein–Maxwell—量子物质的**完整**混合 KK 扰动谱及所有模稳定性。
- 从基础光速螺旋独立推导六维作用量、`n=3`、`G`、`ℏ`、精细结构常数。
- 用真实实验拟合提出的条件性第五力强度与作用程。
- 适用于所有形式的物质耦合、屏蔽机制或边界条件的普适第五力结论。

## 复算可重复性

`python run_all.py` 会重新生成 `results/`，因此这类重新生成的文件**不包含在静态 SHA manifest** 内，以避免运行耗时日志和平台浮点差异导致误判。ZIP 中所有文件仍有归档 CRC 完整性校验。
