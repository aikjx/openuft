[1] 问题：g := G1/(hbar*w) 若来自挠率拓扑荷，则量子化；它能否定出 theta_A？
    约定 A（与 r387 一致）：tan(theta_A)=kappa/tau，内点驻点 g* = N cos(theta_A)，N:=2(a1-a2)

[2] 两种自然的量子化
    (i)  E0=hbar*w    => g=n      => n = N cos(theta_A)   => cos(theta_A) = n/N
    (ii) E0=hbar*c/R  => g=n/cos  => n = N cos^2(theta_A) => cos^2(theta_A) = n/N
    两式都归一到 tan^2(theta_A) ∈ Q（A04，4 组相位精确 0）

[3] 关键分岔
    N 自由 => 谱 = {arctan(sqrt(q)) : q∈Q} 在 [0,pi/2) 稠密 => 判别力 0（B08，偏差 ~ 1/(4*alpha*N)）
    N 固定 => 只剩 N+1 个值 => 真钉住（A05），但分辨率 ~ 1/sqrt(N)（B10）
    而 N 无内生来源（r385/r387 已证）=> 缺口只是从 theta 挪到 N（整数比搬家）
