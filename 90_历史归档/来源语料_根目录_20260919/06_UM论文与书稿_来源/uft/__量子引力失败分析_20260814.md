## 维度1：标度层级（43个数量级）

```

  α_G = G·m_e²/(ℏ·c) = 1.75×10⁻⁴⁵

```

```
标度层级使得量子引力在实验上不可及。

这是第一个、也是最根本的障碍。
```

## 维度3：时间问题

### QM的时间观

```
时间 t = 参数，不是算符
状态演化：ψ(t) = exp(-iHt/ℏ)ψ(0)
时间 = 外部、绝对、背景
哈密顿量 H 生成时间演化
在时刻 t 测量 → 概率 |ψ(t)|²
```

### GR的时间观

```
时间 = 时空的一部分
度规 g_μν 决定固有时：dτ = √(-g)dt
没有外部时间参数
时间 = 动力学的、弯曲的、相对的
不同观察者看到不同的时间
```

### 核心冲突

```
QM：需要外部时间 t 来定义演化
GR：时间是动力学几何的一部分
组合：用哪个时间？

选项A：选一个坐标时间 → 破坏微分同胚
选项B：用固有时 → 观察者依赖，非全局
选项C：Wheeler-deWitt方程 → Hψ = 0，没有时间！

Wheeler-deWitt："时间问题"
宇宙波函数 ψ[g]
H_universe · ψ[g] = 0
没有时间演化，只有约束
如何恢复动力学？未知
```

### 结论

```
时间问题是概念性的，不只是技术性的。
没有外部时间的量子力学是什么？
至今没有答案。
```

```

这是10^105 - 一个宇宙学数字
不能从纯拓扑（无量纲Φ_T）推导
```

### 基本不对称性

```
拓扑常数（α_i）：
  - 由几何决定

  - 纯粹理性，无偶然性

宇宙学常数（G）：
  - 依赖宇宙历史

  如何量化历史偶然？
```

### 结论

```

"第四力"在本质上是不同的
```

## 维度8：数学结构不兼容

### 量子力学的结构

```
Hilbert空间：矢量 |ψ⟩
线性算符：H, p, x, ...
叠加：|ψ⟩ = a|1⟩ + b|2⟩
幺正演化：U(t) = exp(-iHt/ℏ)
线性性是基本的
```

### 广义相对论的结构

```
带度规的流形 g_μν
非线性方程：G_μν = 8πGT_μν
微分同胚不变性：坐标是标签
曲率在度规中是非线性的
非线性性是基本的
```

### 不兼容性

```
线性（QM）+ 非线性（GR）= ？

半经典：⟨G_μν⟩ = 8πG⟨T_μν⟩
问题：左边经典，右边量子
反作用？如何？

完全量子化：g_μν → 算符
问题：度规决定因果性
如果 g_μν 是量子的，因果性不确定
如果度规是叠加的，A能导致B吗？
没有明确定义的"之前"和"之后"
```

### 结论

```
线性QM + 非线性GR = 结构不兼容
没有已知的方法调和
```
