## 二、关键发现：PROOF 2 失败

### 2.1 框架声称的ODE

```
d(κ)/d(ln ω) = -τ
d(τ)/d(ln ω) = +κ
```

### 2.2 数值验证结果

```
约束：κ² + τ² = ω²/c²  且 α = τ/κ 固定

数值计算：
  d(κ)/d(ln ω) = +κ = +3.16×10⁻⁴  ← 正比缩放
  d(τ)/d(ln ω) = +τ = +2.31×10⁻⁶  ← 正比缩放

框架声称：
  d(κ)/d(ln ω) = -τ = -2.31×10⁻⁶  ← 负值！
  d(τ)/d(ln ω) = +κ = +3.16×10⁻⁴  ← 正确

差异：
  d(κ)/d(ln ω)_num / d(κ)/d(ln ω)_frame = -137  ← 差138倍！
```

### 2.3 错误原因分析

```
如果 α = τ/κ 保持恒定：
  κ = ω/(c·√(1+α²))
  τ = α·κ

求导：
  d(κ)/d(ln ω) = κ  ← 正比缩放，不是 -τ
  d(τ)/d(ln ω) = τ  ← 正比缩放

框架的 ODE d(κ)/d(ln ω) = -τ 需要：
  一个不同的约束条件
  或者 κ 和 τ 不以 α=τ/κ 的方式关联
```

### 2.4 正确的螺旋ODE

```
标准 Frenet-Serret 公式（弧长参数 s）：
  d(κ)/ds = 0  （曲率常数）
  d(τ)/ds = 0  （挠率常数）

对于 d(κ)/d(ln ω)，需要明确 ω 与 κ, τ 的关系。
框架的 ODE 看起来是一个**猜想**，而非标准结果。
```
