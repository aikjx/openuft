# 经典基准

[经典作用量](经典作用量/README.md) · [经典实验基准](经典实验基准/README.md)

数学方法与既有理论演示不单独冒充新的宇宙本体。经典基准是 openuft 所有体系的**对照标尺**——候选体系必须在相应极限下恢复这些已知正确结果。
