# ROOT V74 版本发布记录｜2026-11-17

**版本主题**：严格区分微观运动学、宏观引力、曲率不变量、宇称手性、规范群及新力的独立检验。

## V73 → V74 的实质性升级

1. **新判据**：正式证明球对称非旋转外部的 `K(R)=256π²G²ρ̄²/(3c⁴)`；同密度不同 R 时 K 相等而 g 不等；同 g 不同 R 时 K 不等。
2. **新候选 EFT**：以明确的标量–Gauss–Bonnet 耦合作为可变分的强场/密度响应研究对象；明确 χ=0 是解、局部负有效质量平方不是全局不稳定证明。
3. **宇称纠错**：偶曲率不变量不能自动解释左右手性；加入 Pontryagin 赝标量的数学要求与未验证耦合。
4. **更严格的标准模型检查**：4 类规范异常使用精确有理数计算、三耦合一圈演化；不把已输入的粒子谱冒充 ROOT 生成。
5. **有限尺寸与组成效应**：均匀/分层球 Yukawa 力使用稳定数值表示，并与独立 SciPy 径向积分核验。所有新力数值均为模拟值。
6. **企业级追踪**：64 条分类方程，47 条方法审计，严格证明状态清单，55 项单元测试，14 项符号检查，15 项离线页面检查，6 张 CSV 表、4 张计算图、SHA-256 及 ZIP 复验。
