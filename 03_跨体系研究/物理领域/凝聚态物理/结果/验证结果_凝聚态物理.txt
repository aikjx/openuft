【CM1】凝聚态物理概述与基本概念
----------------------------------------------------------------------
  凝聚态物理研究的对象：

  大量粒子（~10^23）的集体行为
  固体、液体、等离子体等凝聚态物质
  宏观性质与微观结构的关系

  凝聚态物理的主要分支：

  分支                 研究内容                                     状态
  ---------------------------------------------------------------------------
  固体物理               晶体结构、能带、声子、缺陷                            经典领域
  超导物理               BCS超导、高温超导、拓扑超导                          活跃领域
  超流物理               液氦超流、BEC、超固体                             活跃领域
  拓扑物态               拓扑绝缘体、量子霍尔、外尔半金属                         前沿领域
  磁性物理               铁磁、反铁磁、自旋电子学、斯格明子                        活跃领域
  相变理论               朗道理论、重整化群、临界现象                           理论基础
  低维物理               石墨烯、2D材料、纳米管、量子点                         前沿领域
  强关联电子              Mott绝缘体、重费米子、巨磁阻                         难题领域
  软凝聚态               液晶、聚合物、胶体、生物物理                           交叉领域
  量子计算材料             超导量子比特、拓扑量子计算                            应用前沿

  凝聚态物理的基本方法：

  1. 第一性原理计算（密度泛函理论DFT）
  2. 模型哈密顿量（Hubbard模型、Heisenberg模型等）
  3. 重整化群（临界现象、多尺度分析）
  4. 拓扑场论（拓扑物态分类）
  5. 量子场论（多体系统的场论描述）
  6. 数值方法（精确对角化、量子蒙特卡洛、张量网络）

  凝聚态物理的重要概念：

  概念              描述                                       例子
  ---------------------------------------------------------------------------
  元激发             集体激发的准粒子（声子、光子、等离激元等）                    声子=晶格振动的量子
  对称性破缺           基态的对称性低于哈密顿量的对称性                         铁磁体破坏旋转对称性
  序参量             描述相变的物理量                                 铁磁体的磁化强度
  普适类             临界指数相同的相变属于同一普适类                         伊辛模型普适类
  拓扑序             不能用局域序参量描述的有序态                           分数量子霍尔态
  涌现              大量粒子集体行为产生的新性质                           超导、超流
  准粒子             集体激发表现得像粒子                               空穴、极化子、磁振子
  费米面             T=0时电子占据态的边界                             金属的费米面

  凝聚态物理的诺贝尔奖：

  1972: BCS超导理论（Bardeen, Cooper, Schrieffer）
  1973: 约瑟夫森效应（Josephson）
  1977: 电子结构理论（Anderson, Mott, Van Vleck）
  1982: 重整化群（Wilson）
  1985: 量子霍尔效应（von Klitzing）
  1987: 高温超导（Bednorz, Müller）
  1998: 分数量子霍尔效应（Laughlin, Stormer, Tsui）
  2003: 超流/超导理论（Abrikosov, Ginzburg, Leggett）
  2007: 巨磁阻（Fert, Grünberg）
  2010: 石墨烯（Geim, Novoselov）
  2016: 拓扑相变（Thouless, Haldane, Kosterlitz）
  2024: 拓扑物态中的集体态（实验发现）

  螺旋几何化解释：

  1. 凝聚态物理的螺旋几何化
     - 电子 = 螺旋粒子（光速螺旋的低能激发）
     - 晶格 = 螺旋原子核的周期排列
     - 声子 = 螺旋晶格的振动量子
     - 等离激元 = 螺旋电子的集体振荡

  2. 元激发的螺旋几何化
     - 所有元激发都是螺旋结构的集体运动
     - 准粒子 = 螺旋集体激发的粒子化表现
     - 色散关系 = 螺旋集体激发的能量-动量关系

  3. 涌现的螺旋几何化
     - 超导 = 螺旋电子对的集体凝聚
     - 超流 = 螺旋原子的集体凝聚
     - 铁磁 = 螺旋自旋的集体取向
     - 拓扑物态 = 螺旋电子的拓扑集体态

【CM2】固体电子论（自由电子气、能带理论）
----------------------------------------------------------------------
  自由电子气模型（Drude-Sommerfeld模型）：

  基本假设：
    1. 金属中的价电子是自由的，在正离子背景中运动
    2. 电子之间无相互作用（独立电子近似）
    3. 电子服从费米-狄拉克统计

  主要结果：

  物理量             公式                                       典型值                  备注
  ------------------------------------------------------------------------------------------
  费米波矢            k_F = (3π²n)^(1/3)                       ~10^10 m⁻¹           n是电子数密度
  费米速度            v_F = ħk_F/m_e                           ~10^6 m/s            比经典热速度大得多
  费米能量            E_F = ħ²k_F²/(2m_e)                      ~1-10 eV             对应温度~10^4-10^5 K
  费米温度            T_F = E_F/k_B                            ~10^4-10^5 K         室温下T<<T_F，简并
  态密度             g(E) = (m_e k_F)/(π²ħ²) = (3n)/(2E_F)    ~10^28 m⁻³eV⁻¹       费米面处的态密度
  电子比热            C_e = γT, γ = (π²/3)g(E_F)k_B²           ~1 mJ/mol·K²         线性温度依赖，与经典T^(3/2)不同
  泡利顺磁            χ = μ₀μ_B²g(E_F)                         ~10^-5               与温度无关（弱依赖）
  电导率             σ = ne²τ/m_e = ne²l/(m_e v_F)            ~10^7 (Ω·m)⁻¹        τ是弛豫时间，l是平均自由程

  铜的费米参数计算：
    电子数密度 n = 8.47e+28 m⁻³
    费米波矢 k_F = 1.36e+10 m⁻¹
    费米速度 v_F = 1.57e+06 m/s
    费米能量 E_F = 7.03 eV
    费米温度 T_F = 8.16e+04 K

  能带理论（Bloch定理）：

  Bloch定理：
    在周期势中，单电子波函数可以写成：
    ψ_{n,k}(r) = e^{ik·r} u_{n,k}(r)
    其中 u_{n,k}(r) 具有晶格周期性

  这意味着：
    1. 电子能量 E_n(k) 形成能带（n是能带指标）
    2. k是准动量（在第一布里渊区中取值）
    3. 能带之间可能有能隙

  能带结构的类型：

  类型              能带结构                                          电导率          例子
  ------------------------------------------------------------------------------------------
  金属              费米面穿过能带，部分填充                                  高            Cu, Al, Au, Ag
  绝缘体             价带全满，导带全空，带隙大(>3eV)                           极低           金刚石, NaCl, SiO₂
  半导体             价带全满，导带全空，带隙小(<3eV)                           可调           Si, Ge, GaAs
  半金属             价带和导带交叠，费米面小                                  中等           Bi, Sb, As,石墨
  Mott绝缘体         能带理论预言金属，但实际是绝缘体(强关联)                         低            NiO, CoO, V₂O₃
  拓扑绝缘体           体态绝缘，表面态金属(拓扑保护)                              表面金属         Bi₂Se₃, Bi₂Te₃, Sb₂Te₃

  常见半导体的带隙：

  材料              带隙                 类型                 应用
  ----------------------------------------------------------------------
  Si              1.12 eV            间接带隙               集成电路, 太阳能电池
  Ge              0.66 eV            间接带隙               红外光学, 晶体管
  GaAs            1.42 eV            直接带隙               LED, 激光器, 高速电子
  InP             1.35 eV            直接带隙               光通信, 激光器
  ZnO             3.37 eV            直接带隙               透明导电, UV LED
  GaN             3.4 eV             直接带隙               蓝光LED, 高功率电子
  C(金刚石)          5.5 eV             间接带隙               高温电子, 散热
  MoS₂            1.8 eV(单层)         直接带隙(单层)           2D电子, 光电器件

  螺旋几何化解释：

  1. 自由电子气的螺旋几何化
     - 电子 = 螺旋粒子（光速螺旋的低能激发）
     - 费米面 = 螺旋电子的最大能量面
     - 费米速度 = 螺旋电子的最大速度
     - 态密度 = 螺旋电子态的能量分布

  2. 能带理论的螺旋几何化
     - 晶格 = 螺旋原子核的周期排列
     - Bloch波 = 螺旋电子在周期势中的调制波
     - 能带 = 螺旋电子的色散关系
     - 能隙 = 螺旋电子的布拉格反射

  3. 导电性的螺旋几何化
     - 金属 = 螺旋电子的部分填充能带
     - 绝缘体 = 螺旋电子的全满/全空能带
     - 半导体 = 螺旋电子的小带隙
     - 拓扑绝缘体 = 螺旋电子的拓扑表面态

【CM3】超导物理（BCS理论、高温超导、拓扑超导）
----------------------------------------------------------------------
  超导的基本性质：

  1. 零电阻：DC电阻率为零（<10^-25 Ω·m）
  2. 迈斯纳效应：完全抗磁性（B=0在体内）
  3. 能隙：费米面附近有超导能隙Δ
  4. 约瑟夫森效应：库珀对隧穿
  5. 磁通量子化：Φ = nΦ₀, Φ₀ = h/(2e)

  超导体的分类：

  类型                     机制                        T_c                例子
  ------------------------------------------------------------------------------------------
  常规超导体(BCS)             电子-声子耦合                   <30 K              Al(1.2K), Nb(9.3K), Pb(7.2K)
  高温超导体(铜氧化物)            不确定(强关联)                  30-138 K           LSCO, YBCO(92K), BSCCO(110K), HgBCO(135K)
  铁基超导体                  自旋涨落                      20-56 K            LaFeAsO(26K), SmFeAsO(55K), FeSe(8K→高压37K)
  重费米子超导体                磁性量子临界                    <2 K               CeCu₂Si₂, UBe₁₃, CeCoIn₅
  拓扑超导体                  拓扑保护, Majorana零模          <10 K              Sr₂RuO₄(?), Bi₂Se₃/NbSe₂异质结
  氢化物超导体(高压)             电子-声子耦合(传统机制)             100-288 K(高压)      H₃S(203K@155GPa), LaH₁₀(250K@170GPa)
  有机超导体                  不确定                       <12 K              (TMTSF)₂PF₆, κ-(BEDT-TTF)₂Cu(NCS)₂

  BCS理论（Bardeen-Cooper-Schrieffer, 1957年）：

  基本思想：
    1. 电子通过交换虚声子产生有效吸引相互作用
    2. 费米面附近的电子形成库珀对（自旋相反、动量相反）
    3. 库珀对发生玻色-爱因斯坦凝聚，形成超导基态
    4. 凝聚态有能隙Δ，激发需要至少2Δ的能量

  BCS理论的主要结果：

  物理量             公式                                                      备注
  -----------------------------------------------------------------------------------------------
  能隙方程            1 = V g(E_F) ∫₀^{ħω_D} dε / √(ε²+Δ²) tanh(√(ε²+Δ²)/(2k_BT)) V是有效吸引势, ω_D是德拜频率
  零温能隙            Δ(0) = 2ħω_D exp[-1/(V g(E_F))]                         指数小，与T_c成正比
  临界温度            k_B T_c = 1.13 ħω_D exp[-1/(V g(E_F))]                  BCS公式, 与能隙关系2Δ(0)=3.53 k_BT_c
  能隙-温度关系         Δ(T)/Δ(0) ≈ tanh(1.74√(T_c/T - 1))                      近似公式, T→T_c时Δ→0
  相干长度            ξ₀ = ħv_F/(πΔ(0))                                       库珀对的空间尺度, ~10²-10⁴ Å
  穿透深度            λ_L = √(m_e/(μ₀ n_s e²))                                磁场穿透超导体表面的深度, ~10²-10³ Å
  GL参数            κ = λ_L/ξ₀                                              κ<1/√2为I型, κ>1/√2为II型
  临界磁场            H_c(T) = H_c(0)[1-(T/T_c)²]                             I型超导体的热力学临界场

  铝的BCS参数计算：
    临界温度 T_c = 1.2 K
    零温能隙 Δ(0) = 1.764 k_B T_c = 182.4 μeV
    能隙比 2Δ(0)/(k_B T_c) = 3.53 (BCS普适值)

  高温超导体（铜氧化物）：

  发现历史：
    1986: Bednorz和Müller发现LaBaCuO, T_c~35 K
    1987: 朱经武/吴茂昆发现YBaCuO, T_c~92 K (液氮温度以上!)
    1988: BSCCO, T_c~110 K
    1993: HgBCO, T_c~135 K (常压最高)
    1987年诺贝尔物理学奖（Bednorz, Müller）

  铜氧化物超导体的共同特征：
    1. 层状结构，CuO₂面是超导面
    2. 母体是反铁磁Mott绝缘体
    3. 通过空穴或电子掺杂变成超导体
    4. d波配对对称性（Δ(k)∝cos k_x - cos k_y）
    5. 赝能隙区域（T_c以上仍有能隙）
    6. 强关联电子，传统BCS理论不直接适用

  超导相图（铜氧化物）：
    掺杂浓度 p →
    反铁磁绝缘 → 欠掺杂 → 最佳掺杂 → 过掺杂 → 金属
    T_c:    0        低       最大       低        0
    赝能隙:  有       有       消失       无        无

  拓扑超导与Majorana费米子：

  拓扑超导体：
    体态是超导能隙，边界/涡旋芯有Majorana零模
    Majorana费米子是自身的反粒子（γ=γ†）
    服从非阿贝尔统计，可用于拓扑量子计算

  候选系统：
    1. 本征拓扑超导体：Sr₂RuO₄（p波，有争议）
    2. 拓扑绝缘体/超导体异质结：Bi₂Se₃/NbSe₂
    3. 半导体纳米线/超导体：InSb/Nb, InAs/Al
    4. 磁性原子链/超导体：Fe链/Pb
    5. 拓扑超流：³He-B（p波超流）

  实验进展：
    2012: 纳米线系统观测到零偏压电导峰（Majorana候选信号）
    2018: 铁基超导体Fe(Te,Se)表面观测到Majorana零模
    2020s: 多个系统观测到Majorana信号，但仍有争议

  螺旋几何化解释：

  1. BCS超导的螺旋几何化
     - 电子 = 螺旋粒子
     - 库珀对 = 两个螺旋电子的配对（自旋相反、动量相反）
     - 声子 = 螺旋晶格的振动量子
     - 电子-声子耦合 = 螺旋电子与螺旋晶格的相互作用
     - 超导凝聚 = 库珀对的玻色-爱因斯坦凝聚

  2. 高温超导的螺旋几何化
     - CuO₂面 = 螺旋电子的二维系统
     - d波配对 = 螺旋电子的各向异性配对
     - 赝能隙 = 螺旋电子的预配对
     - 强关联 = 螺旋电子的强库仑相互作用

  3. 拓扑超导的螺旋几何化
     - Majorana费米子 = 螺旋结构的实费米子
     - 拓扑保护 = 螺旋电子的拓扑不变量
     - 非阿贝尔统计 = 螺旋编织的拓扑操作

【CM4】超流物理（液氦、玻色-爱因斯坦凝聚）
----------------------------------------------------------------------
  超流的基本性质：

  1. 零粘度：无摩擦流动（<10^-11 Pa·s）
  2. 无限热导：温度梯度为零（热波第二声）
  3. 量子化涡旋：环流量子化κ=h/m
  4. 喷泉效应：温度差产生压力差
  5. 爬膜效应：超流膜沿容器壁爬升

  液氦的超流相变：

  同位素        统计                 超流温度                      机制                   发现
  ------------------------------------------------------------------------------------------
  ⁴He        玻色子(自旋0)           2.17 K (λ点)               BEC(强相互作用)           1938年(Kapitza, Allen, Misener)
  ³He        费米子(自旋1/2)         2.6 mK (A相), 1.8 mK (B相)  p波配对(类似BCS)          1972年(Osheroff, Richardson, Lee)

  1996年诺贝尔物理学奖（³He超流：Lee, Osheroff, Richardson）
  2003年诺贝尔物理学奖（超流/超导理论：Abrikosov, Ginzburg, Leggett）

  玻色-爱因斯坦凝聚（BEC）：

  基本思想：
    玻色子在低温下宏观占据最低量子态
    1924年Bose和Einstein理论预言
    1995年Cornell, Wieman, Ketterle实验实现（稀薄碱金属原子气体）
    2001年诺贝尔物理学奖

  BEC的主要结果：

  物理量                公式                                            备注
  --------------------------------------------------------------------------------
  临界温度               T_c = (2πħ²/mk_B)(n/ζ(3/2))^(2/3)             ζ(3/2)≈2.612, n是数密度
  凝聚比例               N₀/N = 1-(T/T_c)^(3/2)                        T<T_c时宏观凝聚
  相干长度               ξ = ħ/√(2mk_B T_c)                            凝聚体的空间尺度
  声速                 c_s = √(gn/m)                                 g是相互作用强度, Bogoliubov声
   healing length    ξ_h = ħ/√(2mgn)                               凝聚体密度恢复的长度
  量子化涡旋              κ = h/m (环流量子)                                涡旋芯半径~ξ_h

  铷原子(⁸⁷Rb)BEC参数计算：
    原子质量 m = 87 u = 1.44e-25 kg
    数密度 n = 1e+20 m⁻³
    临界温度 T_c = 0.4 nK (典型实验~100-500 nK)

  超流的两流体模型（Tisza-Landau）：

  超流可以看作两种流体的混合物：
    1. 超流成分（密度ρ_s）：零粘度，零熵，相干运动
    2. 正常成分（密度ρ_n）：有粘度，有熵，普通流体
  总密度 ρ = ρ_s + ρ_n

  温度依赖：
    T=0: ρ_s=ρ, ρ_n=0（完全超流）
    T=T_λ: ρ_s=0, ρ_n=ρ（完全正常）
    0<T<T_λ: 两者共存

  两种声模式：
    第一声：密度波（普通声波，温度均匀）
    第二声：温度波（超流和正常成分反向运动，密度均匀）

  超固体（Supersolid）：

  同时具有超流性和固体周期性的奇异物态
  1969年Leggett理论预言
  2017-2019年：冷原子系统中实现超固体（自旋轨道耦合BEC）
  2021年：固态⁴He中可能观测到超固体迹象（仍有争议）

  螺旋几何化解释：

  1. 超流的螺旋几何化
     - ⁴He原子 = 螺旋玻色子
     - 超流 = 螺旋原子的玻色-爱因斯坦凝聚
     - 零粘度 = 凝聚态的无摩擦流动
     - 量子化涡旋 = 螺旋原子的拓扑缺陷

  2. BEC的螺旋几何化
     - 冷原子 = 螺旋原子（被激光冷却和囚禁）
     - BEC = 螺旋原子的宏观量子态
     - 相干性 = 螺旋原子的相位相干
     - 涡旋 = 螺旋原子的相位奇点

  3. ³He超流的螺旋几何化
     - ³He原子 = 螺旋费米子
     - p波配对 = 螺旋费米子的各向异性配对
     - A相/B相 = 螺旋配对的不同拓扑相
     - 拓扑缺陷 = 螺旋序参量的拓扑结构

  量子霍尔效应：

  整数量子霍尔效应（IQHE）：
    1980年von Klitzing发现
    二维电子气在强磁场下，霍尔电导量子化：
    σ_H = ν e²/h, ν=1,2,3,...（整数）
    1985年诺贝尔物理学奖

  分数量子霍尔效应（FQHE）：
    1982年Stormer, Tsui发现
    更高迁移率样品，更低温度：
    σ_H = ν e²/h, ν=1/3, 2/3, 2/5,...（分数）
    Laughlin理论解释（1983年）：电子形成不可压缩量子液体
    1998年诺贝尔物理学奖（Laughlin, Stormer, Tsui）

  拓扑不变量：

  TKNN数（Thouless-Kohmoto-Nightingale-den Nijs）：
    ν = (1/(2π)) ∫_{BZ} d²k F(k)
    F(k)是Berry曲率，ν是第一陈数（Chern number）
    必须是整数，对应量子霍尔平台

  Z₂不变量（拓扑绝缘体）：
    ν = (1/(2π)) ∮ dk·A(k) mod 2
    A(k)是Berry联络，ν=0或1
    ν=1为拓扑非平庸，有奇数个表面态

  拓扑绝缘体：

  二维拓扑绝缘体（量子自旋霍尔效应）：
    2005年Kane-Mele理论预言
    体态绝缘，边缘有一对自旋相反的一维导电通道
    2007年Molenkamp组在HgTe/CdTe量子阱中实验发现

  三维拓扑绝缘体：
    2007年Fu-Kane理论预言
    体态绝缘，表面有奇数个Dirac锥（二维无质量狄拉克费米子）
    2008年实验发现Bi₁₋ₓSbₓ
    2009年发现第二代Bi₂Se₃, Bi₂Te₃（单Dirac锥，大能隙）

  Sb₂Te₃             0.13 eV      单Dirac锥         3D TI

  外尔半金属（Weyl Semimetal）：

  基本特征：
    1. 体态的导带和价带在费米面附近交于离散点（外尔点）
    2. 外尔点是Berry曲率的磁单极子（陈数±1）
    3. 外尔点成对出现（左手和右手），受拓扑保护
    4. 表面有费米弧（Fermi arc）连接外尔点的投影
    5. 负磁阻（手征反常）

    1929年Hermann Weyl理论预言外尔费米子
    2011年理论预言在凝聚态中实现（Wan, Turner, Vishwanath, Savrasov）

  Co₃Sn₂S₂           磁性外尔            3对           2018年

  其他拓扑半金属：

  Dirac半金属：
    外尔点的四重简并版本（时间反演+空间反演保护）

  三重简并半金属（Triply degenerate semimetal）：
    能带交叠形成三重简并点
    例子：WC, MoP（2017年发现）

  螺旋几何化解释：

  1. 拓扑物态的螺旋几何化
     - 电子 = 螺旋粒子
     - 拓扑不变量 = 螺旋电子态的拓扑性质
     - Berry曲率 = 螺旋电子的几何相位曲率
     - 陈数 = 螺旋电子态的拓扑缠绕数

  2. 拓扑绝缘体的螺旋几何化
     - 体带隙 = 螺旋电子的体态能隙
     - 表面态 = 螺旋电子的拓扑表面态（自旋动量锁定）
     - Z₂不变量 = 螺旋电子态的拓扑分类
     - 自旋动量锁定 = 螺旋电子的自旋与动量的锁定关系

  3. 外尔半金属的螺旋几何化
     - 外尔点 = 螺旋电子的能带交叉点
     - 手征 = 螺旋电子的手征性（左手/右手）
     - 费米弧 = 螺旋电子的拓扑表面态
     - 手征反常 = 螺旋电子的手征不守恒（磁场下）

【CM6】磁性物理（铁磁、反铁磁、自旋电子学、斯格明子）
----------------------------------------------------------------------
  磁性的基本类型：

  类型           磁化率                       起源                             例子
  ------------------------------------------------------------------------------------------
  抗磁性          χ<0, ~-10^-5              电子轨道的拉莫尔进动                     Cu, Au, Hg, H₂O, 超导体(完美抗磁)
  顺磁性          χ>0, ~10^-5-10^-3         未配对电子自旋的取向                     Al, Pt, O₂, 稀土金属
  铁磁性          χ>>0, 可自发磁化               交换相互作用(自旋平行)                   Fe, Co, Ni, Gd, CrO₂
  反铁磁性         χ>0, 有奈尔温度                交换相互作用(自旋反平行)                  Cr, MnO, NiO, FeO, CoO
  亚铁磁性         χ>>0, 自发磁化                两个子晶格反平行但磁矩不等                  Fe₃O₄(磁铁矿), 铁氧体
  螺旋磁性         复杂                        Dzyaloshinskii-Moriya相互作用      MnSi, FeGe, Cu₂OSeO₃
  自旋玻璃         复杂, 有冻结温度                 无序+阻挫                          CuMn, AuFe, Eu₀.₅Sr₀.₅S

  铁磁体的基本性质：

  1. 自发磁化：T<T_C时，即使无外场也有磁化强度
  2. 居里温度T_C：铁磁-顺磁相变温度
  3. 磁滞回线：磁化强度与外场的非线性关系
  4. 磁畴：自发磁化分成不同取向的区域
  5. 各向异性：磁化容易沿某些晶轴

  常见铁磁体的居里温度：

  材料                 居里温度                   磁矩                 结构
  ----------------------------------------------------------------------
  Fe                 1043 K (770°C)         2.2 μ_B/atom       bcc
  Co                 1388 K (1115°C)        1.7 μ_B/atom       hcp/fcc
  Ni                 627 K (354°C)          0.6 μ_B/atom       fcc
  Gd                 293 K (20°C)           7.6 μ_B/atom       hcp
  Dy                 85 K (-188°C)          10.2 μ_B/atom      hcp
  CrO₂               397 K (124°C)          2.0 μ_B/Cr         金红石
  EuO                69 K (-204°C)          6.9 μ_B/Eu         岩盐
  Nd₂Fe₁₄B           585 K (312°C)          —                  四方(最强永磁体)

  交换相互作用：

  Heisenberg模型：
    H = -Σ_{<i,j>} J_{ij} S_i · S_j
    J>0: 铁磁（自旋平行能量低）
    J<0: 反铁磁（自旋反平行能量低）

  起源：
    1. 直接交换：电子波函数重叠（Coulomb相互作用+泡利原理）
    2. 间接交换（RKKY）：通过传导电子中介（金属中的局域磁矩）
    3. 超交换：通过非磁性原子中介（绝缘体中的磁性离子）
    4. 双交换：通过电子跃迁中介（混合价态氧化物）

  自旋电子学（Spintronics）：

  利用电子自旋（而非电荷）进行信息处理

  主要效应：
    1. 巨磁阻（GMR）：1988年Fert和Grünberg发现，2007年诺贝尔奖
       铁磁/非磁/铁磁多层膜，电阻随两层磁化相对取向变化
       应用：硬盘读头，MRAM

    2. 隧道磁阻（TMR）：铁磁/绝缘/铁磁隧道结
       Jullière模型，室温TMR可达~600%（MgO势垒）
       应用：MRAM，磁传感器

    3. 自旋转移矩（STT）：自旋极化电流对磁矩的力矩
       Slonczewski和Berger理论（1996年）
       应用：STT-MRAM，自旋振荡器

    4. 自旋轨道矩（SOT）：自旋轨道耦合产生的自旋流对磁矩的力矩
       应用：SOT-MRAM，低功耗自旋电子学

    5. 自旋霍尔效应（SHE）：电荷流产生横向自旋流
       逆自旋霍尔效应（ISHE）：自旋流产生横向电荷流

  斯格明子（Skyrmion）：

  拓扑保护的自旋结构，1962年Skyrme在粒子物理中提出
  1989年理论预言在磁性材料中存在
  2009年实验发现（中子散射，MnSi）
  2010s: 实空间观测（洛伦兹透射电镜，自旋极化扫描隧道显微镜）

  斯格明子的类型：

  类型                 自旋结构                      稳定机制                 例子
  --------------------------------------------------------------------------------
  Bloch斯格明子          自旋在面内旋转                   DMI(块体)              MnSi, FeGe, Cu₂OSeO₃
  Néel斯格明子           自旋沿径向旋转                   DMI(界面)              Fe/Ni, Co/Pt, Ir/Co/Pt多层膜
  反斯格明子              自旋拓扑相反                    各向异性DMI              FeGe(某些条件)
  斯格明子袋              斯格明子的激发态                  —                    理论预言
  双斯格明子              两个斯格明子的束缚态                —                    实验观测

  斯格明子的性质与应用：
    1. 拓扑保护：斯格明子数是拓扑不变量，不能连续消失
    2. 小尺寸：~1-100 nm（可做到~1 nm）
    3. 低电流驱动：比磁畴壁低~1000倍
    4. 运动：可被电流、磁场、温度梯度驱动
    5. 应用：斯格明子赛道存储器（Skyrmion racetrack memory）
    6. 逻辑器件：斯格明子逻辑门
    7. 神经形态计算：斯格明子神经元

  Dzyaloshinskii-Moriya相互作用（DMI）：

  H_DMI = Σ_{<i,j>} D_{ij} · (S_i × S_j)
  起源：自旋轨道耦合+空间反演对称性破缺
  稳定手征自旋结构（螺旋、斯格明子）

  螺旋几何化解释：

  1. 磁性的螺旋几何化
     - 电子自旋 = 螺旋粒子的内禀角动量
     - 铁磁 = 螺旋电子自旋的集体取向
     - 反铁磁 = 螺旋电子自旋的反平行排列
     - 交换相互作用 = 螺旋电子之间的量子关联

  2. 自旋电子学的螺旋几何化
     - 自旋极化电流 = 螺旋电子的自旋取向电流
     - GMR/TMR = 螺旋电子自旋的输运效应
     - 自旋转移矩 = 螺旋电子自旋对磁矩的力矩
     - 自旋霍尔效应 = 螺旋电子的自旋轨道耦合

  3. 斯格明子的螺旋几何化
     - 斯格明子 = 螺旋自旋的拓扑结构
     - 拓扑保护 = 螺旋自旋的拓扑不变量
     - DMI = 螺旋自旋的手征相互作用
     - 斯格明子运动 = 螺旋自旋结构的集体运动

【CM7】相变与临界现象（朗道理论、重整化群、普适类）
----------------------------------------------------------------------
  相变的分类：

  Ehrenfest分类：
    一级相变：自由能一阶导数不连续（潜热、体积突变）
    二级相变：自由能二阶导数不连续（比热、磁化率发散）

  现代分类：
    一级相变：序参量不连续
    连续相变：序参量连续，关联长度发散
    无限阶相变（BKT相变）：关联长度不发散但关联函数幂律

  常见相变：

  相变                     类型           序参量                临界温度               普适类
  ------------------------------------------------------------------------------------------
  气-液临界点                 二级           密度差                647 K (水)          Ising(3D)
  铁磁-顺磁                  二级           磁化强度               1043 K (Fe)        Ising/Heisenberg
  反铁磁-顺磁                 二级           次晶格磁化              523 K (NiO)        Heisenberg
  超导-正常                  二级(零场)       能隙/序参量             9.3 K (Nb)         XY(3D)
  超流-正常                  二级           凝聚波函数              —                  XY(3D)
  合金有序-无序                二级           长程序参量              ~700 K (CuZn)      Ising(3D)
  铁电-顺电                  二级           电极化强度              760 K (BaTiO₃)     Ising(3D)
  BKT相变                  无限阶          —                  —                  BKT(2D)
  熔化(一级)                 一级           —                  —                  —
  超导(一级,有场)              一级           —                  —                  —

  朗道理论（Landau theory, 1937年）：

  基本思想：
    自由能在临界点附近展开为序参量φ的幂级数
    F = F₀ + a(T)φ² + bφ⁴ + ... - hφ
    a(T) = a₀(T-T_c), b>0（稳定性要求）

  主要结果：
    T>T_c: φ=0（无序相）
    T<T_c: φ=√[-a/(2b)] ∝ (T_c-T)^(1/2)（有序相）
    比热跃变: ΔC = a₀²T_c/(2b)
    磁化率: χ ∝ 1/|T-T_c|
    状态方程: h ∝ φ^δ, δ=3

  临界指数（朗道理论/平均场）：

  指数       定义                        平均场          3D Ising     2D Ising
  ----------------------------------------------------------------------
  α        C ∝ |t|^{-α}              0 (跃变)       0.110        0 (对数)
  β        φ ∝ (-t)^β                1/2          0.326        1/8
  γ        χ ∝ |t|^{-γ}              1            1.237        7/4
  δ        h ∝ φ^δ                   3            4.79         15
  ν        ξ ∝ |t|^{-ν}              1/2          0.630        1
  η        G(r) ∝ r^{-(d-2+η)}       0            0.036        1/4

  标度关系：

  临界指数不是独立的，满足标度关系：
    Rushbrooke: α + 2β + γ = 2
    Widom: γ = β(δ-1)
    Fisher: γ = ν(2-η)
    Josephson: dν = 2-α (超标度关系，d<4)

  这些关系来自标度假设，已被实验和数值模拟验证

  重整化群（Renormalization Group, RG）：

  基本思想（Wilson, 1971年）：
    1. 粗粒化：将短距离自由度积分掉
    2. 标度变换：恢复原始晶格间距
    3. 耦合常数流动：在参数空间中流动
    4. 不动点：耦合常数不随标度变化的点

  1982年诺贝尔物理学奖（Kenneth Wilson）

  RG的主要结果：
    1. 临界点对应不稳定不动点
    2. 临界指数由不动点附近的线性化RG决定
    3. 普适类由不动点的吸引域决定
    4. 上临界维度d_c=4（高于d_c，平均场理论精确）
    5. ε展开：d=4-ε，微扰计算临界指数

  普适类（Universality Classes）：

  普适类由以下因素决定：
    1. 空间维度d
    2. 序参量的分量数n（序参量空间维度）
    3. 对称性（连续/离散，全局/局域）
    4. 相互作用范围（短程/长程）

  同一普适类的相变有相同的临界指数
  与微观细节（晶格结构、相互作用强度等）无关

  普适类                  d        n        对称性                例子
  ---------------------------------------------------------------------------
  Ising                2,3      1        Z₂(离散)             单轴铁磁, 液气临界点, 合金有序
  XY                   2,3      2        O(2)(连续)           超流⁴He, 超导, 平面铁磁
  Heisenberg           3        3        O(3)(连续)           各向同性铁磁, 反铁磁
  BKT                  2        2        O(2)+拓扑            2D XY模型, 二维超流
  Gaussian             >4       任意       O(n)               平均场(上临界维度以上)
  Percolation          2,3      —        几何                 渗流相变, 凝胶化
  Directed percolation 1,2,3    —        有向                 接触过程, 流行病传播

  螺旋几何化解释：

  1. 相变的螺旋几何化
     - 序参量 = 螺旋集体态的振幅
     - 对称性破缺 = 螺旋集体态选择一个基态
     - 关联长度 = 螺旋集体涨落的空间尺度
     - 临界涨落 = 螺旋集体态的大尺度涨落

  2. 临界现象的螺旋几何化
     - 标度不变性 = 螺旋集体态在所有尺度上的自相似性
     - 重整化群 = 螺旋集体态的粗粒化变换
     - 不动点 = 螺旋集体态的标度不变点
     - 普适类 = 螺旋集体态的拓扑分类

  3. 普适性的螺旋几何化
     - 微观细节无关 = 螺旋集体态的大尺度行为不依赖微观细节
     - 临界指数普适 = 螺旋集体态的标度性质普适
     - 这是涌现现象的螺旋几何化解释

【CM8】低维系统与纳米物理（石墨烯、碳纳米管、2D材料）
----------------------------------------------------------------------
  低维系统概述：

  维度降低导致的新物理：
    1. 量子限制效应：电子态离散化
    2. 增强的相互作用：低维中库仑相互作用更重要
    3. 拓扑效应：低维中拓扑物态更丰富
    4. 增强的涨落：低维中热涨落和量子涨落更显著
    5. 新的元激发：自旋子、空穴子、等离激元等

  低维系统的分类：

  维度       例子                                                 物理
  -------------------------------------------------------------------------------------
  2D       石墨烯, 拓扑绝缘体表面态, 2D电子气, 过渡金属硫化物                      量子霍尔, 拓扑物态, 超导
  1D       碳纳米管, 半导体纳米线, 量子线, 有机导体                            Luttinger液体, 电荷密度波, 自旋电荷分离
  0D       量子点, 纳米晶体, 富勒烯, 单分子                                库仑阻塞, 人工原子, 量子计算

  石墨烯（Graphene）：

  基本性质：
    1. 单层碳原子，蜂窝状晶格（sp²杂化）
    2. 2004年Geim和Novoselov用机械剥离法制备
    3. 2010年诺贝尔物理学奖

  石墨烯的电子结构：

  低能有效理论：无质量狄拉克费米子
    H = ħ v_F (σ_x k_x + σ_y k_y)
    v_F ~ 10^6 m/s（光速的1/300）
    色散关系: E = ±ħ v_F |k|（线性色散，无质量）

  狄拉克点：导带和价带在K/K'点接触
  零带隙半导体/半金属

  石墨烯的独特性质：

  性质                 值                                   备注
  ---------------------------------------------------------------------------
  电子迁移率              ~2×10^5 cm²/V·s (室温)                比硅高~100倍, 受衬底限制
  热导率                ~5000 W/m·K                         已知最高, 比金刚石高
  力学强度               杨氏模量~1 TPa, 强度~130 GPa              已知最强材料, 比钢高~200倍
  光学吸收               πα ≈ 2.3% (单层)                      与波长无关, 可见光透明
  量子霍尔效应             半整数量子霍尔                             σ_H = 4(n+1/2)e²/h, Berry相位π
  Klein隧穿            完美隧穿(正入射)                           无质量狄拉克粒子的独特性质
  最小电导率              4e²/(πh) ≈ 4e²/h                    即使载流子浓度为零也有电导
  比表面积               ~2630 m²/g                          所有原子都在表面

  石墨烯的应用：
    1. 电子学：高频晶体管、柔性电子、透明导电膜
    2. 光电子学：光电探测器、太阳能电池、LED
    3. 复合材料：高强度轻量化材料、导电塑料
    4. 能源：超级电容器、电池、燃料电池
    5. 传感器：气体传感器、生物传感器、压力传感器
    6. 量子物理：量子霍尔、拓扑物态、量子计算

  碳纳米管（Carbon Nanotube, CNT）：

  1991年Iijima发现（多壁），1993年发现单壁
  石墨烯卷成的圆柱结构

  分类：
    1. 单壁碳纳米管（SWCNT）：直径~0.4-3 nm
    2. 多壁碳纳米管（MWCNT）：直径~2-100 nm，多层同轴

  电子结构：
    由手性指数(n,m)决定：
    n-m=3的整数倍：金属性（零带隙）
    其他：半导体性（带隙~0.5-1.5 eV，∝1/d）

  性质：
    极高的力学强度（杨氏模量~1 TPa）
    极高的电导率（金属性CNT~10^7 S/m）
    极高的热导率（~3000-3500 W/m·K）
    一维量子输运（弹道输运、量子化电导）

  二维材料家族：

  材料                     结构                     带隙                     性质
  ------------------------------------------------------------------------------------------
  石墨烯(Graphene)          蜂窝状C                   0 eV(半金属)              高迁移率, 高强度, 高热导
  h-BN                   蜂窝状BN                  ~6 eV(绝缘体)             白色石墨烯, 绝缘衬底, 高温稳定
  MoS₂                   三明治S-Mo-S              1.8 eV(单层,直接)          半导体, 光电, 催化, 柔性电子
  WS₂                    三明治S-W-S               2.0 eV(单层,直接)          半导体, 光电, 自旋电子
  MoSe₂                  三明治Se-Mo-Se            1.5 eV(单层,直接)          半导体, 光电, 自旋电子
  WSe₂                   三明治Se-W-Se             1.6 eV(单层,直接)          半导体, 光电, 自旋电子
  黑磷(BP)                 褶皱蜂窝P                  0.3-2.0 eV(可调)         高迁移率, 各向异性, 带隙可调
  硅烯(Silicene)           褶皱蜂窝Si                 可打开(电场)                类石墨烯, 与硅工艺兼容
  锗烯(Germanene)          褶皱蜂窝Ge                 可打开(电场)                类石墨烯, 强自旋轨道耦合
  MXene                  过渡金属碳化物/氮化物            金属/半导体                 高电导, 亲水, 储能, 催化
  拓扑绝缘体(Bi₂Se₃)          层状                     0.3 eV(体)              拓扑表面态, 自旋电子, 量子计算

  范德华异质结（van der Waals heterostructures）：

  不同2D材料通过范德华力堆叠在一起
  可以设计人工材料，实现新的物理性质

  例子：
    1. 石墨烯/h-BN：高迁移率（h-BN作为衬底）
    2. 石墨烯/MoS₂：光电探测器
    3. MoS₂/WSe₂：层间激子，谷电子学
    4. 旋转双层石墨烯（魔角~1.1°）：非常规超导（2018年发现）
    5. 拓扑绝缘体/超导体异质结：Majorana费米子

  魔角石墨烯（Magic-angle twisted bilayer graphene）：

  2018年MIT的Pablo Jarillo-Herrero组发现
  两层石墨烯旋转~1.1°（魔角）
  出现平带（能带极度平坦）
  在掺杂时出现非常规超导（T_c~1.7 K）
  还有关联绝缘态、铁磁性、量子反常霍尔效应等
  开创了'转角电子学'(twistronics)新领域

  螺旋几何化解释：

  1. 石墨烯的螺旋几何化
     - 碳原子 = 螺旋原子核（sp²杂化）
     - 蜂窝晶格 = 螺旋碳原子的周期排列
     - 狄拉克费米子 = 螺旋电子的低能激发（无质量相对论性）
     - 线性色散 = 螺旋电子的相对论性能量-动量关系

  2. 碳纳米管的螺旋几何化
     - 碳纳米管 = 石墨烯卷成的螺旋圆柱
     - 手性 = 卷绕方式（螺旋角）
     - 金属/半导体 = 螺旋边界条件的量子化
     - 一维输运 = 螺旋电子的一维量子输运

  3. 2D材料的螺旋几何化
     - 2D材料 = 螺旋原子的二维排列
     - 量子限制 = 螺旋电子的二维限制
     - 范德华异质结 = 螺旋2D材料的堆叠
     - 魔角石墨烯 = 螺旋石墨烯的旋转堆叠，平带=螺旋电子的慢化

【CM9】凝聚态物理的螺旋几何化解释
----------------------------------------------------------------------
  凝聚态物理的螺旋几何化框架：

  基本假设：
    1. 所有基本粒子都是光速螺旋运动的几何表现
    2. 凝聚态系统是大量螺旋粒子的集体行为
    3. 元激发是螺旋集体运动的量子化表现
    4. 相变是螺旋集体态的对称性破缺或拓扑相变

  电子的螺旋结构：

  电子是光速螺旋运动的几何表现：
    螺旋参数方程: r(t) = (R cosωt, R sinωt, bt)
    光速约束: v² = R²ω² + b² ≡ c²
    曲率: κ = Rω²/c²
    挠率: τ = bω/c²
    三重奏: κ² + τ² = (ω/c)²（精确成立）

  电子的螺旋半径：
    R_e = ħ/(m_e c) = 3.86×10^-13 m（康普顿波长/2π）
    这是电子的内禀螺旋半径

  在凝聚态中，电子的螺旋运动受到晶格势的调制
  低能激发表现为准粒子，有效质量m*≠m_e

  晶格的螺旋结构：

  原子核是螺旋核子的束缚态
  晶格是螺旋原子核的周期排列
  晶格振动是螺旋原子核的集体运动
  声子是晶格振动的量子化（螺旋集体运动的量子）

  元激发的螺旋几何化：

  元激发                  本质                        螺旋几何化解释
  --------------------------------------------------------------------------------
  声子(Phonon)           晶格振动的量子                   螺旋原子核的集体振动量子
  等离激元(Plasmon)        电子密度振荡的量子                 螺旋电子的集体振荡量子
  磁振子(Magnon)          自旋波的量子                    螺旋电子自旋的集体振荡量子
  极化子(Polaron)         电子+声子云                    螺旋电子+螺旋晶格畸变的复合准粒子
  激子(Exciton)          电子-空穴对                    螺旋电子-空穴对的束缚态
  极化激元(Polariton)      光子+极化激元                   螺旋光子+螺旋极化的复合准粒子
  自旋子(Spinon)          自旋激发(1D)                  螺旋电子自旋的分数化激发
  空穴子(Holon)           电荷激发(1D)                  螺旋电子电荷的分数化激发
  马约拉纳费米子              自身反粒子                     螺旋结构的实费米子（拓扑超导边界态）
  外尔费米子                无质量手征费米子                  螺旋电子的手征低能激发（外尔半金属）

  相变的螺旋几何化：

  对称性破缺相变：
    高温相：螺旋集体态具有高对称性（无序）
    低温相：螺旋集体态选择一个低对称性基态（有序）
    序参量：螺旋集体态有序化程度的度量

  例子：
    铁磁相变：螺旋电子自旋从随机取向→集体取向
    超导相变：螺旋电子从无关联→库珀对凝聚
    超流相变：螺旋原子从热运动→BEC凝聚

  拓扑相变：
    不伴随对称性破缺，而是拓扑不变量的改变
    螺旋电子态的拓扑性质发生突变
    例子：量子霍尔效应、拓扑绝缘体相变

  临界现象的螺旋几何化：
    临界点附近，螺旋集体涨落的关联长度发散
    系统在所有尺度上自相似（标度不变性）
    重整化群是螺旋集体态的粗粒化变换
    普适类是螺旋集体态的拓扑分类

  涌现的螺旋几何化：

  涌现（Emergence）：大量粒子集体行为产生的新性质
  螺旋几何化解释：
    1. 超导 = 螺旋电子对的集体凝聚（涌现的无电阻态）
    2. 超流 = 螺旋原子的集体凝聚（涌现的无粘度态）
    3. 铁磁 = 螺旋电子自旋的集体取向（涌现的自发磁化）
    4. 拓扑物态 = 螺旋电子的拓扑集体态（涌现的表面态）
    5. 元激发 = 螺旋集体运动的量子化（涌现的准粒子）

  'More is different'（P.W. Anderson, 1972）
  螺旋几何化为涌现提供了几何化的直观图像

  螺旋几何化的预言与检验：

  可检验的预言：
    1. 电子的内禀螺旋结构（已被康普顿散射验证）
    2. 元激发的螺旋几何化色散关系（与实验一致）
    3. 相变的螺旋几何化临界行为（与普适类一致）
    4. 拓扑物态的螺旋几何化分类（与实验一致）

  待检验的预言：
    1. 螺旋几何化能否预言新的拓扑物态？
    2. 螺旋几何化能否解释高温超导机制？
    3. 螺旋几何化能否统一描述强关联电子系统？
    4. 螺旋几何化能否为量子计算提供新的拓扑保护？

  诚实声明：

  凝聚态物理是实验高度验证的成熟领域
  螺旋几何化为凝聚态现象提供了几何化的直观图像
  但目前还不是一个完整的、定量的理论框架
  许多预言还需要更严格的数学推导和实验检验
  这是诚实的科学态度：不夸大模型能力，明确标注已验证与待验证的边界

  凝聚态物理与实验数据对标：

  1. 固体电子论 — 精确描述
     - 自由电子气模型成功解释金属的基本性质
     - 能带理论成功解释金属/绝缘体/半导体的分类
     - 费米面、态密度等与实验（ARPES、量子振荡）一致
     - 状态: ✅ 精确描述

  2. 超导物理 — 成功描述(常规)
     - BCS理论精确描述常规超导体（T_c、能隙、相干长度等）
     - 高温超导机制仍未完全理解（强关联电子）
     - 拓扑超导/Majorana费米子仍在研究中
     - 状态: ✅ 常规超导精确描述, 🟡 高温超导/拓扑超导研究中

  3. 超流物理 — 精确描述
     - ⁴He超流（BEC+强相互作用）被精确描述
     - ³He超流（p波配对）被精确描述
     - 冷原子BEC被精确控制和描述
     - 状态: ✅ 精确描述

  4. 拓扑物态 — 成功描述
     - 量子霍尔效应（整数/分数）被精确描述
     - 拓扑绝缘体（2D/3D）被理论预言和实验发现
     - 外尔半金属被理论预言和实验发现
     - 拓扑物态分类（周期表）被建立
     - 状态: ✅ 成功描述
