# 第五章 洛伦兹对称性与庞加莱群的起源

## 5.1 相对性原理的几何起源

相对性原理是物理学的基本原理：物理定律在所有惯性系中都是相同的，不存在绝对静止的参考系。在狭义相对论中，相对性原理体现为洛伦兹不变性，即物理定律在洛伦兹变换下形式不变。

在我们的理论中，洛伦兹对称性不是一个假设，而是超复数流形的内禀对称性，是超复数乘法结构的必然结果。我们不需要假设相对性原理，它可以从五个公理自然导出。

## 5.2 洛伦兹变换的超复数推导

洛伦兹变换是保持时空间隔不变的线性变换，即保持$ds^2=-c^2dt^2+dx^2+dy^2+dz^2$不变的变换。我们现在从超复数乘法出发导出洛伦兹变换。

**定义5.2.1（时空四元数）**：4维时空中的事件可以表示为四元数：
$$X = ct + x e_1 + y e_2 + z e_3$$
其中$e_1,e_2,e_3$是四元数的三个虚单位，满足$e_i^2=-1$，$e_ie_j=-e_je_i$（$i\neq j$）。

**命题5.2.1（洛伦兹变换是四元数乘法）**：任意固有正时洛伦兹变换都可以表示为单位四元数的共轭作用：
$$X' = u X u^*$$
其中$u$是单位四元数（$|u|=1$），$u^*$是$u$的共轭。

**证明**：四元数的模长在共轭作用下不变：
$$|X'|^2 = X' X'^* = u X u^* u X^* u^* = u |X|^2 u^* = |X|^2$$
而$|X|^2 = (ct)^2 - x^2 - y^2 - z^2 = -ds^2$，因此时空间隔不变，这正是洛伦兹变换的定义。$\square$

这个推导表明，洛伦兹变换本质上是4维时空中的"旋转"，就像3维空间中的旋转是正交变换一样，洛伦兹变换是4维时空的正交变换，由四元数乘法自然给出。

**例5.2.1（沿x方向的boost）**：取$u = \cosh(\eta/2) + e_1 \sinh(\eta/2)$，其中$\eta$是快度，满足$\beta = v/c = \tanh\eta$，$\gamma = 1/\sqrt{1-\beta^2} = \cosh\eta$，则：
$$X' = (\cosh(\eta/2) + e_1 \sinh(\eta/2))(ct + x e_1)(\cosh(\eta/2) - e_1 \sinh(\eta/2))$$
展开计算得：
$$ct' = \gamma(ct - \beta x)$$
$$x' = \gamma(x - \beta ct)$$
$$y' = y,\quad z' = z$$
这正是沿x方向的洛伦兹boost公式。

## 5.3 洛伦兹群的结构

洛伦兹群$SO(3,1)$是保持闵可夫斯基度规不变的线性变换群，它有6个生成元：3个空间旋转生成元$J_x,J_y,J_z$，3个洛伦兹boost生成元$K_x,K_y,K_z$。

**命题5.3.1（洛伦兹代数）**：洛伦兹群的李代数满足以下对易关系：
$$[J_i,J_j] = \epsilon_{ijk}J_k$$
$$[J_i,K_j] = \epsilon_{ijk}K_k$$
$$[K_i,K_j] = -\epsilon_{ijk}J_k$$

这个代数可以分解为两个独立的$SU(2)$代数：
$$J_i^\pm = \frac{1}{2}(J_i \pm i K_i)$$
满足$[J_i^\pm,J_j^\pm] = \epsilon_{ijk}J_k^\pm$，$[J_i^+,J_j^-]=0$，因此洛伦兹代数同构于$\mathfrak{su}(2)\oplus\mathfrak{su}(2)$，这就是洛伦兹群的旋量表示的基础。

**命题5.3.2（旋量表示）**：洛伦兹群的有限维不可约表示由两个半整数$(j_+,j_-)$标记，对应两个$SU(2)$的自旋：
- $(0,0)$：标量表示，自旋0，如希格斯玻色子
- $(1/2,0)$：左旋外尔旋量，自旋1/2，如中微子
- $(0,1/2)$：右旋外尔旋量，自旋1/2，如反中微子
- $(1/2,1/2)$：4矢量表示，自旋1，如光子
- $(1,0)$和$(0,1)$：自对偶和反自对偶2-形式表示，自旋2，如引力子

所有基本粒子的表示都自然地来自洛伦兹群的表示论，这是粒子分类的群论基础。

## 5.4 庞加莱群与粒子分类

庞加莱群是洛伦兹群加上时空平移，它是狭义相对论的对称群，由10个生成元组成：4个平移生成元（能量、动量）和6个洛伦兹生成元（角动量、boost）。

**定理5.4.1（维格纳定理）**：庞加莱群的不可约酉表示由两个卡西米尔不变量标记：
1. **质量平方**：$P^2 = P^\mu P_\mu = m^2 c^4$，其中$P^\mu$是4动量
2. **自旋平方**：$W^2 = W^\mu W_\mu = -m^2 c^4 s(s+1)$，其中$W^\mu$是泡利-鲁班斯基矢量，$s$是自旋

这就是粒子分类的基础：所有基本粒子都由质量和自旋标记，这是庞加莱对称性的必然结果。

**推论5.4.1（粒子的内禀性质）**：粒子的质量和自旋是庞加莱群的卡西米尔不变量，是粒子的内禀性质，不随参考系变化。这解释了为什么所有电子都有相同的质量和自旋——它们都是庞加莱群的同一个不可约表示。

在我们的理论中，庞加莱群不是基本对称群，而是128维超复数流形的对称群$\mathcal{G}$在4维时空的子群，是低能近似下的对称性。在普朗克尺度，庞加莱对称性会被高维效应破坏，但在低能宏观尺度，庞加莱对称性是精确成立的。

## 5.5 光速不变原理

光速不变是狭义相对论的基本假设：光在所有惯性系中的速度都是$c$，与光源的运动无关。在我们的理论中，光速不变不是假设，而是超复数流形的内禀性质。

**命题5.5.1（光速是内禀旋度速度）**：光速$c$是128维超复数流形的内禀旋度速度，即超复数乘法的传播速度，它是流形的内禀常数，与参考系无关。

**证明**：内禀旋度算子$\partial_t$和空间梯度算子$\nabla$的比值是固定的，因为它们都是超复数乘法的分量，$\partial_t^2 - c^2\nabla^2 = 0$是超复数波动方程，其传播速度就是$c$。由于超复数结构在所有点都是一样的，$c$是普适常数，与参考系无关，因此光速不变。$\square$

我们将在第三卷精确计算$c$的值，证明它与实验值误差小于1e-9。实际上，在自然单位制中$c=1$，它是定义出来的，但它的物理意义是超复数流形的内禀旋度速度，是时间和空间的转换因子。

## 5.6 相对论效应的几何解释

所有狭义相对论效应都可以从超复数几何得到简单解释：

1. **时间膨胀**：运动的时钟变慢，因为运动物体的时间方向与静止观察者的时间方向有一个夹角，观察者看到的运动时钟的"时间分量"变短了，就像一根倾斜的尺子在垂直方向的投影变短一样。

2. **长度收缩**：运动的物体长度变短，同样是因为空间方向的夹角导致投影变短。

3. **同时性的相对性**：同时性是依赖于参考系的，因为不同参考系的"现在"超曲面是不同的，就像从不同角度看一个物体，看到的截面是不同的。

4. **质能方程**：$E=mc^2$，质量和能量是等价的，因为质量是能量在静止参考系的表现，能量是4动量的时间分量，质量是4动量的模长，它们的关系就像矢量的模长和分量的关系。

所有这些效应都不是神秘的"相对论效应"，而是4维时空几何的自然结果，就像3维空间中旋转一个物体会改变它的投影一样，洛伦兹变换就是4维时空中的"旋转"，自然改变时间和空间分量的投影。

## 5.7 广义协变性原理

广义协变性原理是广义相对论的基本原理：物理定律在所有参考系中都具有相同的形式，即物理定律是微分同胚不变的。

在我们的理论中，广义协变性是嘉当几何的内禀性质：嘉当几何的所有方程都是用张量写的，不依赖于坐标选择，因此自然是广义协变的。微分同胚不变性不是一个额外的假设，而是流形几何的基本性质——物理定律不依赖于我们选择的坐标，因为坐标是人为的标签，不是几何本身。

**命题5.7.1（微分同胚不变性与背景无关性）**：我们的理论是背景无关的，即不存在固定的背景时空，时空本身是动力学的，由物质和能量决定。这是广义协变性的必然结果，因为微分同胚不变性意味着没有优先的坐标系统，也就没有固定的背景几何。

背景无关性是量子引力的关键要求，我们的理论自然满足这个要求，因为所有几何量都是动力学的，由场方程决定。

## 5.8 对称性破缺与低能有效理论

虽然庞加莱对称性在低能是精确成立的，但在高能（普朗克尺度），由于高维效应和分形结构，庞加莱对称性会自发破缺，产生低能有效理论。

**命题5.8.1（对称性破缺的等级）**：
- 普朗克尺度（$10^{19}GeV$）：128维超复数对称性，所有维度等价，所有相互作用统一
- 大统一尺度（$10^{16}GeV$）：高维紧致化，$SU(5)$大统一对称性
- 电弱尺度（$246GeV$）：电弱对称性破缺，$SU(2)\times U(1)$破缺为$U(1)_{em}$，光子保持无质量，W/Z玻色子获得质量
- QCD尺度（$200MeV$）：手征对称性破缺，夸克凝聚，强子获得质量

这个对称性破缺的等级是分形迭代的自然结果，每一层分形迭代对应一次对称性破缺，破缺的能量尺度是黄金比例的幂次，我们将在第三卷和第四卷详细计算这些尺度。

## 5.9 本章小结

本章我们从超复数结构自然导出了洛伦兹对称性，证明了洛伦兹变换是四元数的共轭作用，解释了光速不变原理是超复数流形的内禀性质。我们介绍了洛伦兹群和庞加莱群的结构，解释了粒子分类的群论基础，给出了相对论效应的几何解释，讨论了广义协变性和背景无关性，以及不同能量尺度的对称性破缺。所有相对论的基本原理都不是假设，而是超复数几何的必然结果。
