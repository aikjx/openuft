## 四 主定理 A：严格下界从平方和来，且有限截断的边界项不能省

径向能量（已除 `2*pi`）写成

```
E/(2*pi) = int r dr [ B^2/2 + f'^2/2 + n^2 (1-a)^2 f^2/(2 r^2) + beta (1-f^2)^2/8 ],
B = n a'/r。
```

`beta=1` 时配平方给出

```
E/(2*pi) = boundary(R) + S,   S = int r dr [ (B - (1-f^2)/2)^2/2 + (f' - n(1-a)f/r)^2/2 ] >= 0。
```

`S` 是两个平方的积分，**非负是结构性的，不是拟合出来的**；令 `R` 取无穷即 `E(n) >= n/2`。本册在 `n=1, 2, 3, 4, 8` 五档上把「直接积分」与「边界项加 `S`」两路对账，最大残差 `1.601e-08`；五档 `alpha` 的独立对账最大残差 `1.627e-07`。

**最容易自伤的一处**：`R` 有限时 `boundary(R)` 不是 `n/2`。对试探剖面 `(1-a)(1-f^2) = (alpha^2/(r^2+alpha^2))^2`，故

```
boundary(R) = n sqrt(beta)/2 · [1 - (alpha^2/(R^2+alpha^2))^2]。
```

`R=60`、`alpha=1.5` 时漏掉的那一项是 `1.950685881e-07`，正好伪装成「数值误差」：`alpha=1.5` 档朴素残差 `1.931e-07`，带修正后 `2.001e-09`，相差约两个量级。四档 `R=20/40/60/100` 上修正后残差逐档为 `2.469e-11 / 3.951e-10 / 2.001e-09 / 2.002e-09`，全部小于各自朴素残差。**这是「残差不随网格下降时先怀疑闭式少项」的一次实算**，处理办法是补项，不是放宽门限。

`A03` 同时钉死口径：交叉项系数之比是 `sqrt(beta)/2` 对 `1/2`，只有 `beta=1` 相等。五档 `beta` 的失配表 `0.124999953 / 0.073223278 / 2e-09 / 0.103553348 / 0.249999899` 里只有一档配平，`beta` 不等于 1 的档本册不给任何严格结论。

## 五 主定理 B：夹逼严格证明 E(3) > E(1)，但不能判「分裂是否有利」

上界侧取显式试探剖面 `f=r/sqrt(r^2+alpha^2)`、`a=r^2/(r^2+alpha^2)`，任意剖面的能量都是真实最小值的上界。五档 `alpha` 取最小给 `U(1)=0.538685217`（`alpha=1.50`）。数值上 Simpson 四档 `0.5386858274 / 0.5386852529 / 0.5386852172 / 0.5386852150`，相邻差 `5.745e-07 / 3.567e-08 / 2.226e-09` 逐档缩小；尾截断四档 `0.5379787093 / 0.5385751790 / 0.5386852172 / 0.5387415203` 相邻差亦递减。

于是

```
E(3) >= L(3) = 1.5  >  U(1) = 0.538685217  >=  E(1)   ⇒   E(3) > E(1)。
```

**全程没有解径向 ODE，也没有用到变分最小化的收敛性。** `B02` 把 `n=1..8` 全网格列出：`n=2..8` 七档 `L(n) > U(1)` 成立，而 `n=1` 不成立——「范围内全对必须报范围外第一条就错」，否则七档全过的谓词单独看判别力为 0。

**本册最该被引用的是下一段，不是上面那个不等式。** 若固定总绕数为 3，可比的两个构型是「3 个 `n=1`」与「1 个 `n=3`」。已知 `E(1)` 落在 `[0.5, 0.538685217]`，故 `3·E(1)` 落在 `[1.5, 1.616055652]`；而 `E(3)` 只有下界 `1.5`。两个区间**重叠**：`3·U(1)=1.616055652 > L(3)=1.5`。所以夹逼对「分裂是否更有利」的判别力为 0（`B04`）。临界耦合下 `3·L(1)=1.5 = L(3)` 恰好简并（`B03`），但简并只说明 BPS 饱和，不说明哪个构型被选中。

> **读数支持不了的解读刀**：起草时差点把 `3·U(1) > L(3)` 写成「1 个 `n=3` 更省」。那是用**上界**当 `E(1)` 的精确值。正确的说法只能是「夹逼判不了」，并把这条无能写进判词与诚实边界，由 `OVERLAP-TAGGED` 守卫强制。
