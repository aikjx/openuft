[1] E329 守恒律是否覆盖高温早期宇宙?
----------------------------------------------------------------------

E329 的命题结构:
  (a) 对象: 质子 p (B=1, 稳定重子), 末态 e+ pi0 (B=0).
  (b) 条件: T ~ 0 (现代宇宙, 零温真空), 微扰衰变道.
  (c) 机制: TUFT 反射壁拓扑荷 Q (类比 pi_3(S^3)=Z / pi_3(S^2)=Z) 守恒,
            Delta Q = 0 => 初态与末态拓扑荷不可连接 => 矩阵元为零.

覆盖范围审计 (逐项):
  (i)   零温 vs 有限温:
        E329 的证明在零温真空截面/寿命意义下成立. 它没有构造热密介质中的
        瞬子鞍点 (sphaleron saddle), 也没有对有限温路径积分做拓扑 sectors
        求和. => 字面上, E329 是 T=0 定理, 不是 T > T_c 定理.

  (ii)  微扰 vs 非微扰:
        p -> e+ pi0 是微扰算符 (维度 6, 如 X Y Y / M_X^2). E329 禁的是
        微扰算符对应的衰变. sphaleron 是非微扰场位形 (Chern-Simons 数
        突变 N_CS -> N_CS +/-1), 不走微扰算符展开. 两类过程在路径积分中
        属于不同 sector. => E329 的 Delta Q=0 若只约束微扰跃迁矩阵元,
        则不自动约束 N_CS 隧穿.

  (iii) Q 到底是什么荷? (定义识别, 关键)
        - 若 E329 的 Q = B (重子数):
            SM 反常:  d(B)/dt = (g_2^2/(32 pi^2)) W	ilde W * N_gen ...
            高温下 B 不守恒. E329 与标准宇宙学直接冲突, 必须额外公设.
        - 若 E329 的 Q = B - L:
            SM 中 B-L 是无反常守恒量 (B+L 反常, B-L 不反常).
            sphaleron 守恒 B-L, 只重排 B 与 L. => 与 E329 不冲突,
            但 E329 也不排除 sphaleron.
        => "E329 的 Q 是 B 还是 B-L" 必须在 TUFT 主册中显式登记;
           在登记之前, "E329 覆盖高温宇宙" 是未定义命题.

----------------------------------------------------------------------
[3] TUFT 反射壁框架下有无 SU(2) 瞬子 / sphaleron 对应?
----------------------------------------------------------------------

TUFT 反射壁 (reflection wall) 是零温静态孤子类位形 (Hopfion/Skyrme 类,
基于 pi_3(S^2)=Z 的整数荷 Q). 审计其能否承载 sphaleron 型过程:

  (A) 若 TUFT 低能约化为 SM (必须, 否则 E329 质子稳定与对撞机现象学都无
      法对接): 则 TUFT 的场论路径积分在 SU(2)_L  sector 自动继承
      瞬子/反瞬子鞍点. sphaleron 是这些鞍点在有限温下的势垒顶点.
      => 只要 TUFT 含 SU(2) 规范自由度, sphaleron 型过程在原理上就存在,
         与反射壁是零温孤子这一点不矛盾 (两者是不同 saddle).

  (B) 若 TUFT 把反射壁拓扑荷 Q 直接等同于 Chern-Simons 数 N_CS, 并公设
      Delta Q = 0 在有限温路径积分中也成立 (即冻结 N_CS):
      => sphaleron 被人为禁掉. 代价见 [4].

  (C) 若 TUFT 根本不含 SU(2) 规范场 (纯几何孤子论):
      => 无法约化到 SM, E329 失去物理对应. 此路不通, 不展开.

结论: 在 (A) 情形下, sphaleron 速率应取 [2] 的 SM 基准值 (至多被 TUFT
      修正 prefactor kappa, 不改 T^4 标度与指数压制结构);
      在 (B) 情形下, sphaleron 被额外公设禁掉.

[4] 若 TUFT 公设 sphaleron 不存在 (B 破坏被定理级排除): 代价核算
----------------------------------------------------------------------
最小公设 (除 E329 之外必须额外补一条):
  P_T: 在有限温 SU(2)_L 路径积分中, 所有拓扑 sector 之间的跃迁振幅
       被反射壁边界条件强制为零 (N_CS 是守恒荷, 而非荷轨道数).
  该公设与 E329 (T=0) 是两件事: E329 是推论, P_T 才是有限温冻结.

物理代价:
  (i)  Y_B = 8.70e-11 变成纯初始条件 (reheating 时刻手放).
       无 leptogenesis (leptogenesis 需要 sphaleron 把 L 转 B).
       无 EW baryogenesis (本身就靠 sphaleron 偏离平衡).
  (ii) B-L 与 B 在 TUFT 中等价守恒, 传统轻子生成温窗 (T > 10^8.8 GeV)
       的全部现象学 (CP 破坏相位、右手中微子质量等) 被 TUFT 拒认.
  (iii) 与 SM 对撞机/重离子现象学对接时, 必须解释为何 SU(2) 瞬子
       在 T ~ 100 GeV 的重离子实验中 (虽被指数压制) 不留痕迹.
  (iv) 精细调节: Y_B 从 ~O(1) 调到 8.7e-11, 是 10^-11 量级初始
       微调, 无动力学机制可解释.

----------------------------------------------------------------------
[5] 判定: B 破坏在 TUFT 内部是否存在?
----------------------------------------------------------------------

  - 在 T=0 微扰 sector:  不存在 (E329 严格定理, tau_p = inf).
  - 在有限温 SU(2) 非微扰 sector: 取决于 P_T 是否被公设.
      * 不设 P_T  (情形 A): sphaleron 存在, 速率按 [2], B+L 破坏在
        T_c < T < T_eq 窗口内热平衡. 此时 E329 的 Q 必须登记为 B-L
        (否则自相矛盾).
      * 设 P_T    (情形 B): sphaleron 被冻结, B 与 B-L 双双守恒,
        Y_B 降级为初始条件.
  - 本审计不在 A/B 之间替 TUFT 做选择; 这是主册必须登记的公设层级问题.

[6] 四态分级
======================================================================

【严格定理】
  - E329: T=0 微扰 sector 下 tau_p = inf (v8 已证).
  - SM 反常恒等式:  d(B+L)/dt = (g2^2 N_gen/(32 pi^2)) W~W  (经典场论恒等式).
  - 对称相 sphaleron 速率标度 Gamma/V ~ alpha_w^5 T^4 (重求和微扰论 + 晶格).
  - 破缺相势垒压制 Gamma/V ~ exp(-E_sph/T), E_sph = 4 pi v/g * 1.56.

【条件定理】
  - sphaleron 热平衡窗口  160 GeV < T < 6.84e+08 GeV,
    依赖 g_* = 106.75, kappa = 1.0, alpha_w = 0.0339;
    换 prefactor 到 0.5~2, T_eq 同比例移动, 窗口结论不变.
  - Y_B = (28/79) Y_{B-L} 重排因子, 依赖 SM 全部汤川耦合在 T_c 以上
    均平衡 (top/Yukawa 平衡条件).

【定义识别】
  - E329 的守恒荷 Q 究竟 = B 还是 = B-L: 主册未显式登记.
    该登记直接决定 A/B 两种情形走哪条, 是本轮最大的定义级缺口.
  - '反射壁拓扑荷 Q' 与 'Chern-Simons 数 N_CS' 是否同一几何对象,
    是定义选择, 不是定理.

【开放命题】
  - TUFT 有限温路径积分中, N_CS sector 之间是否存在非零跃迁振幅:
    本审计未证明, 需 TUFT 主册补 P_T 公设或补 sphaleron saddle 的
    存在性证明.
  - 反射壁框架的热密介质有效作用量是否修正 sphaleron 势垒形状因子
    eps_SPH: 未算.
  - Y_B = 8.7e-11 在 TUFT 中由初始条件还是动力学产生: 未决,
    取决于 A/B 选择.
