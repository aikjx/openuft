# ROOT V50—V84 历史研究归并索引

此文件并非声称重新独立审稿每个版本；是根据现存 V50—V84 归档、README、研究专著和本次复核建立的**研究路线索引**。标注“已达成”仅指模型/软件层面，不代表新物理被证实。

| 阶段/代表版本 | 主要研究对象 | 能保留的有效成果 | 仍未解决的问题 |
|---|---|---|---|
| V50–V56 | 三维空间螺旋、速度分解、地球可视化 | 螺旋运动学、曲率/挠率形式及视图实验 | 不能单靠运动学证明物理基元或决定 G |
| V57–V64 | 作用量、与 Maxwell/GR 比较、场几何 | 量纲/协变性与已知极限的审查方向 | 缺少完整无额外自由参数的微观作用量 |
| V65–V69 | G 的量纲障碍、标准模型规范结构、各星体差异 | 区分 G、GM、星体 g、场能量和规范群 | 未独立推导 G；不能仅靠几何角预言耦合 |
| V70–V72 | 多星体、有限程新力、三重反转、实验可辨识 | Yukawa 形状因子、材料/距离扫描、零实验思路 | 真实可复核仪器证据缺失 |
| V73–V74 | 量纲生成、曲率不变量、奇偶性与手性 | 明确假设及对称性否决条件 | 并非四力统一理论 |
| V75–V76 | 电磁场能动张量、微观能量与绑定质量 | 电磁场是真实 GR 引力源，完整 Tmunu 防双重计数 | 不表明磁场决定 G |
| V77 | G 与 c 关系 | Z=Gc/2 的恒等式、Planck/粒子引力耦合、量纲退化 | 独立 G 起源缺口 |
| V78–V79 | 电磁奇偶、伪标量和谐波 | f/2f 的条件筛选、偶/奇响应与闭合能量账本 | 没有实测超 GR 的电磁引力效应 |
| V80–V81 | 磁星、强场与跨尺度比较 | 紧致度、场能量/静能及规范异常核对 | 未独立得到新引力定律 |
| V82 | 引力控制实验语言 | 移动真实源质量可调制引力；开源合成协议 | 没有硬件采集，不能宣称反重力 |
| V83 | 双传感器反转 | 共模奇信号、梯度偶信号、误差传播 | 源体同步的伪差仍可能假冒信号 |
| V84 | 多距离与有限球第五力 | 有限源体修正、长程退化、模拟假阳性反例 | 未通过新力的真实实验证据门槛 |
| **V85** | **跨源—跨材料 Q/D 双诊断** | **Q 测距形状；单可分离媒介 D 的 rank≤1；区分普适环境型 u 与材料型 α** | **仍未解释 G 的独立数值或四力统一** |

包含在本包 `history/` 下的 V76、V77、V81、V84 ZIP 是重要的历史节点副本；其他历史版本的本地文件清单见 `previous_archive_index.csv`，本包不重复复制所有 35 个历史版本（避免体积过大及重复科研内容）。
