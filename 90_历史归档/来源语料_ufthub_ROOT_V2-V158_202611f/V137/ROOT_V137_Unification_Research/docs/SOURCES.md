# 权威公开来源与使用边界（2026-11-23 检索）

1. NASA JPL Astrodynamic Parameters — Earth/Moon μ： https://ssd.jpl.nasa.gov/astro_par.html
2. NIST CODATA 2022 G 数据 — 标准不确定度： https://physics.nist.gov/cuu/Constants/ ; https://www.nist.gov/publications/codata-recommended-values-fundamental-physical-constants-2022
3. GFZ ICGEM 重力球谐模型与下载说明： https://icgem.gfz.de/faq ; https://icgem.gfz.de/tom
4. ESA GOCE 资料： https://www.esa.int/articles/about-us/directorates/earth-observation-programmes/futureeo/goce/data-products
5. NASA PDS GRAIL 月球重力衍生数据： https://data.nasa.gov/dataset/grail-moon-lgrs-derived-gravity-science-data-products-v1-0-b0393
6. NASA PDS GRAIL harmonics： https://pds.nasa.gov/ds-view/pds/viewCollection.jsp?identifier=urn%3Anasa%3Apds%3Agrail_gravity_derived%3Adata_shbdr&version=2.0
7. f(R) 线性化 Yukawa (α=1/3, λ=√(6a))： https://arxiv.org/abs/1004.2014
8. 卫星激光测距对额外 Yukawa 作用的既有检验： https://pmc.ncbi.nlm.nih.gov/articles/PMC6828690/

说明：本程序采用从前版本继承的**示意球对称密度**与 JPL μ、NIST G，其他在线数据集未下载并用于本轮数值拟合。因此这些网址是下一步数据来源，而不是本轮“实测已通过”的证据。
