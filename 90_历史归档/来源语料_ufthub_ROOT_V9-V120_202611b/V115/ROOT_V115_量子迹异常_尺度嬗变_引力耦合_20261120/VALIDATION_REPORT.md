## 禁止误读

1. 未证明强作用、弱作用、电磁力与引力的独立共同起源。
2. 没有从第一性原理无循环预测 G；诱导引力数值需要把实测 G 输入来反算 ζ。
3. 没有用单圈 QCD 预测真实核子质量；没有计算质子 QCD 格点矩阵元。
4. 没有把单一迹异常算符系数误称为质子某个质量百分比。
5. 没有重新拟合 LVK、Cassini、MICROSCOPE 或 2026 格点论文的原始实验数据。
6. 已经验证的 Python 单元测试只检查给定模型与理论规范，不是物理新定律的实验确认。
