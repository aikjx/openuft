## 修复候选方程（本册唯一提出的新方程）

```
L  = g^{mu nu} d_mu Psi* d_nu Psi - m^2 |Psi|^2 + (lam/2) |Psi|^4      (3D 再加 -(kap/3)|Psi|^6)
EOM: box(Psi) + m^2 Psi - lam |Psi|^2 Psi = 0,   m = omega/c
解  : Psi = sqrt(2a/lam) * sech(sqrt(a) x) * exp(-i Omega t),  a = m^2 - Omega^2/c^2 > 0
守恒: j^mu = i g^{mu nu}(Psi* d_nu Psi - Psi d_nu Psi*),  d_mu j^mu = 0（在壳）
```

三处修改对应第 ⑧ 层的三条硬伤：系数实数化（F-03/F-04b）、加自洽势（F-04）、非线性化（A-06）。

## 突破点

1. **P-03 + P-04 + P-07 + P-08**：V2' 的 EOM、精确解、U(1) 守恒、线性稳定性全部由符号求导验证；
   四条分别对应第 ⑧ 层的 F-03 / F-04 / F-04b / A-06 的一半。
2. **S-01（本册最经济的一条）**：沿螺旋对称窗口的周期平均给出 <r> = 0 ⇒ 若 EDM 来自一阶矩，
   d_e = 0 由**对称性**直接给出，**V2 特设的 f'(r) 屏蔽因子在逻辑上不必要**。
3. **S-02**：同一螺旋在不同窗口给出互不相同的 <z>（0 / pi*b/2 / pi*b），说明 V1 的「<z> = b/2」不是几何不变量；
   这与既有《书籍》第十编第 52 章的独立结论一致。

## 诚实边界与红线

- V2' 是**修复候选**，不是 TUFT 的既有内容；本册不宣称已导出任何新的实验数。
- T-01 是必须记住的原则：**每闭合一条硬伤支付至少一个自由度**，不存在免费的内生机制；
  「振幅被锁定」在 V2（线性）中不可能，在 V2' 中可能但需支付 lam。
- 本册未闭合且明确登记：g-2 的 2r 映射、delta_TUFT、绝对标度、alpha、sigma_abs=0；
  3D 稳定性只给 Derrick 判据与 sextic 修正式，**未给出 3D 解**。

**红线**：数学自洽 != 物理成立；可解 != 可检验；一致性修复 != 预测力进展。
