## 0. 通用约定（全专题统一）

| 项目 | 约定 |
|---|---|
| 单位制 | 国际单位制 SI；基本量纲 $\mathrm{M}$（质量）、$\mathrm{L}$（长度）、$\mathrm{T}$（时间）、$\mathrm{I}$（电流） |
| 时空指标 | 希腊字母 $\mu,\nu,\rho,\sigma$ 为 4 维时空指标，取值 $(0,1,2,3)\leftrightarrow(t,x,y,z)$ |
| 空间指标 | 拉丁字母 $i,j,k$ 为 3 维空间指标，取值 $(1,2,3)\leftrightarrow(x,y,z)$ |
| 求和约定 | 爱因斯坦求和约定默认开启 |
| 4 维坐标 | $x^\mu=(ct,\ x,y,z)$（时间分量乘以 $c$ 取得长度量纲） |
| 度规签名 | $(+,-,-,-)$，$\eta_{\mu\nu}=\mathrm{diag}(1,-1,-1,-1)$ |
| 量纲记号 | $[X]$ 表示物理量 $X$ 的量纲；$\square\equiv\partial_\mu\partial^\mu$ |

**三层严格分离**：本专题每个结论都区分

1. **数学定义**——符号定义与代数/微分结构，可由符号计算复算；
2. **量纲分析**——基本量纲指数运算，只判自洽性，不给数值；
3. **本体论解释**——物理含义与因果陈述，属于解释层，必须有实验或理论依据支撑，不得由前两层推出。
