## 问题定义

宇宙暴胀期量子涨落拉伸为原初引力波，在 CMB 偏振产生 B 模式（旋度型）。张量–标量比 r=P_t/P_s 量化原初引力波振幅。核心目标：探测 r>0，即原初引力波存在证据。

## 证伪条件

- 若 r 精确定为 0（无原初引力波），标准暴胀范式需修正
- 若 B 模谱形状不符慢滚预言，暴胀模型排除
- 若发现非高斯性或手性 B 模，需超出标准暴胀的新物理

## 分析进展（求导证明验证 + 精算分析）

脚本 `verify_cmb_bmode.py`：

- **观测上限**：BICEP/Keck 2023 r<0.032（95% CL），Planck r<0.06（INFO，无确认信号）
