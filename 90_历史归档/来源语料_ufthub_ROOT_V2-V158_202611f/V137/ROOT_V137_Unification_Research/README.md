## V137 独立新发现

1. **单高度 GM 退化定理**：\(g(r)=\mu r^{-2}(1+\alpha_Y h(r))\)；一个高度只能测到 \(\mu(1+\alpha_Y h)\)，无法单独区分 μ 和 α。
2. **带 GM 标定的新残差公式**：\(g(r)/(\hat\mu/r^2)-1=\alpha_Y[h(r)-h(r_*)]/[1+\alpha_Yh(r_*)]\)，严格考虑了在某个高度通过牛顿模型拟合 GM 的影响。
3. **弱信号对旧三高度比值的致命噪声敏感性**：相对噪声 1e-7、1000 次模拟，在假设 α=1e-5 时形状比中位绝对误差 5.09585，约 49% 为负；alpha=1/3 时误差约 0.000495。均是模拟而非观测。
4. **多高度 GLS**：Cholesky 白化、联合拟合偏移+第五力+示意干扰项，带相关误差及 Monte Carlo 覆盖模拟。参数之间不可辨识时明确报错。
5. **数学限制**：只有 SO(3) 三个旋转生成元的单个三维标架，不能独立产生 SM 内部规范群的 12 个独立生成元。必须再引入由动力学决定的内部自由度。
6. **f(R) 可解释性**：α=1/3、λ=√(6a) 已是已知 R+aR² 弱场结果，尚未从 ROOT 螺旋原理推出。
