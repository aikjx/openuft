# 一、几何层核心公式

## 1.1 空间螺旋方程

$$\boxed{\boldsymbol{r}(\theta) = \rho\cos\theta \boldsymbol{i} + \rho\sin\theta \boldsymbol{j} + b\theta \boldsymbol{k}}$$

**参数说明**：
- $\rho$：螺旋半径（回转半径）
- $b$：螺距参数（轴向推进系数）
- $\theta$：旋转角度（$\theta = \omega t$）

## 1.2 导数公式

$$\boxed{\boldsymbol{r}'(\theta) = -\rho\sin\theta \boldsymbol{i} + \rho\cos\theta \boldsymbol{j} + b \boldsymbol{k}}$$

$$\boxed{\boldsymbol{r}''(\theta) = -\rho\cos\theta \boldsymbol{i} - \rho\sin\theta \boldsymbol{j}}$$

$$\boxed{\boldsymbol{r}'''(\theta) = \rho\sin\theta \boldsymbol{i} - \rho\cos\theta \boldsymbol{j}}$$

## 1.3 曲率公式

$$\boxed{\kappa = \frac{|\boldsymbol{r}' \times \boldsymbol{r}''|}{|\boldsymbol{r}'|^3} = \frac{b}{\rho^2 + b^2}}$$

**物理意义**：空间弯曲程度

## 1.4 挠率公式

$$\boxed{\tau = \frac{(\boldsymbol{r}' \times \boldsymbol{r}'') \cdot \boldsymbol{r}'''}{|\boldsymbol{r}' \times \boldsymbol{r}''|^2} = \frac{\rho}{\rho^2 + b^2}}$$

**物理意义**：空间扭转程度

## 1.5 螺旋密度

$$\boxed{\rho_{\text{spiral}} = \kappa^2 + \tau^2 = \frac{1}{\rho^2 + b^2}}$$

## 1.6 归一化约束

$$\boxed{\kappa^2 + \tau^2 = \frac{1}{\rho^2 + b^2}}$$

## 1.7 精细结构常数关系

$$\boxed{\alpha = \frac{\kappa}{\tau} = \frac{b}{\rho}}$$

**物理意义**：螺旋紧致度

## 1.8 螺旋长度元素

$$\boxed{ds = \sqrt{(d\rho)^2 + (\rho d\theta)^2 + (db)^2} = c dt}$$

## 1.9 弧长公式

$$\boxed{s(\theta) = \sqrt{\rho^2 + b^2} \cdot \theta}$$

## 1.10 螺旋体积

$$\boxed{V = \pi \rho^2 \cdot b\theta}$$

# 二、运动层核心公式

## 2.1 速度分解

$$\boxed{\vec{v} = \frac{d\boldsymbol{r}}{dt} = -\rho\omega\sin(\omega t) \boldsymbol{i} + \rho\omega\cos(\omega t) \boldsymbol{j} + v \boldsymbol{k}}$$

**横向速度**：$v_\perp = \rho\omega$  
**轴向速度**：$v_\parallel = v$  

## 2.2 光速约束（第一性原理）

$$\boxed{|\vec{v}| = \sqrt{v_\perp^2 + v_\parallel^2} = \sqrt{(\rho\omega)^2 + v^2} = c}$$

**物理意义**：空间任意点的合运动速率恒等于光速c

## 2.3 静质量态（v=0）

$$\boxed{\rho\omega = c}$$

**物理意义**：静止物体的空间螺旋只有旋转运动

## 2.4 光子态（ρω=0）

$$\boxed{v = c}$$

**物理意义**：光子的空间螺旋只有轴向运动

## 2.5 运动质量态（0<v<c）

$$\boxed{\rho\omega = \sqrt{c^2 - v^2}}$$

**物理意义**：运动物体的空间螺旋同时具有旋转和轴向运动

## 2.6 加速度公式

$$\boxed{\vec{a} = \frac{d\vec{v}}{dt} = -\rho\omega^2\cos(\omega t) \boldsymbol{i} - \rho\omega^2\sin(\omega t) \boldsymbol{j}}$$

## 2.7 向心加速度

$$\boxed{a_c = \rho\omega^2 = \frac{c^2 - v^2}{\rho}}$$

## 2.8 角动量公式

$$\boxed{L = m\rho^2\omega = \hbar}$$

**物理意义**：基态角动量为约化普朗克常数ℏ

## 2.9 角速度与频率关系

$$\boxed{\omega = 2\pi f}$$

## 2.10 周期公式

$$\boxed{T = \frac{2\pi}{\omega} = \frac{h}{E}}$$
