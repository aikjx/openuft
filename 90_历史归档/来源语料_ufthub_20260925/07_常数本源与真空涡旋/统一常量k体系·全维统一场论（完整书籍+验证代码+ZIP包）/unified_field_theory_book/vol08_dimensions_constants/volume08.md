# 第八卷 · 物理量纲与常数本源溯源

## 从量纲哲学到人择原理的常数层级分析

## 第39章 量纲分析的深层哲学

### 39.1 量纲的本质

#### 39.1.1 量纲作为物理量的等价类

量纲（dimension）的本质是物理量在单位变换下的等价类。两个物理量具有相同的量纲，当且仅当它们可以用相同的单位来测量，即它们在单位变换下按相同的方式变换。

从数学角度看，量纲构成一个阿贝尔群：
- 群运算：量纲的"乘法"（对应物理量的乘法）
- 单位元：无量纲（量纲为1）
- 逆元：量纲的"倒数"（对应物理量的除法）

在力学中，量纲群是由 \(L, M, T\) 生成的自由阿贝尔群，元素形如 \(L^a M^b T^c\)。

#### 39.1.2 量纲的约定性与客观性

量纲的选择在某种意义上是约定的：
- 我们可以选择不同的基本量（如用速度 \(V\) 代替长度 \(L\) 作为基本量）
- 不同的单位制（SI、cgs、自然单位制）对应不同的基本量选择

但量纲关系本身是客观的：
- 速度的量纲是 \(L/T\)，这不是约定，而是由速度的定义 \(v = dx/dt\) 决定的
- 量纲一致性原理是客观的物理要求

#### 39.1.3 量纲与对称性

量纲分析与对称性密切相关。量纲一致性本质上是理论在"尺度变换"下的不变性：

\[
x \to \lambda x, \quad t \to \lambda^a t, \quad m \to \lambda^b m
\]

物理方程在这种变换下的不变性对应于量纲一致性。

更一般地，量纲分析可以被视为重整化群思想的先驱：物理量在不同尺度下的行为由其量纲决定。

### 39.2 基本量纲的选择

#### 39.2.1 SI的七个基本量

国际单位制（SI）选择七个基本量：
1. 长度（米）
2. 质量（千克）
3. 时间（秒）
4. 电流（安培）
5. 热力学温度（开尔文）
6. 物质的量（摩尔）
7. 发光强度（坎德拉）

这七个基本量的选择有其历史原因，也有其实用性。但从理论物理的角度，并非所有这些量都是"基本"的。

#### 39.2.2 理论物理中的基本量纲

在理论物理中，通常只需要三个基本量纲：\(L, M, T\)（或等价地，能量、长度、时间）。其他量纲可以通过物理定律导出：
- 电流量纲可以通过库仑定律或安培定律与力学量纲联系
- 温度可以通过能量均分定理 \(E = k_B T\) 与能量联系
- 物质的量本质上是计数（无量纲）
- 发光强度是生理物理量，依赖于人眼的响应函数

因此，从基础理论的角度，\(L, M, T\)（加上电磁量纲 \(I\)，如果不将电磁完全几何化）是最基本的量纲。

#### 39.2.3 自然单位制中的量纲约化

在自然单位制中，通过令基本常数等于1，可以进一步约化量纲：
- 令 \(c = 1\)：长度和时间量纲合并（\(L = T\)）
- 令 \(\hbar = 1\)：质量和能量与长度/时间的倒数合并（\(M = L^{-1} = T^{-1}\)）
- 令 \(G = 1\)（或 \(k = 4\pi\)）：所有量纲都约化为无量纲（普朗克单位制）

在普朗克单位制中，所有物理量都是无量纲数。但这并不意味着量纲分析失去意义——在自然单位制中，量纲被"隐藏"在常数的幂次中，需要时可以通过量纲分析恢复。

### 39.3 量纲分析的威力与局限

#### 39.3.1 量纲分析的成功案例

量纲分析在物理学中有着辉煌的成功：
- **布朗运动**：爱因斯坦通过量纲分析推导出扩散系数与温度的关系
- **湍流**：柯尔莫哥洛夫的 \(-5/3\) 定律可以通过量纲分析得到
- **原子弹当量**：泰勒通过量纲分析从爆炸火球的照片估算出原子弹当量
- **黑体辐射**：普朗克定律的形式可以通过量纲分析约束
- **引力波**：四极辐射公式的标度关系可以通过量纲分析得到

#### 39.3.2 量纲分析的局限

量纲分析也有其局限：
- 量纲分析只能给出物理量之间的标度关系，不能给出无量纲常数
- 量纲分析不能区分具有相同量纲的不同物理量
- 量纲分析依赖于正确识别相关的物理量和常数
- 量纲分析不能替代动力学方程的求解

## 第40章 基本物理常数的分类与层级

### 40.1 物理常数的分类

#### 40.1.1 按性质分类

物理常数可以按性质分为几类：

**1. 普适常数（Universal constants）**：
- 出现在所有物理理论中，不依赖于具体物体或相互作用
- 例如：光速 \(c\)、普朗克常数 \(\hbar\)、引力常数 \(G\)（或 \(k = 4\pi G\)）

**2. 相互作用常数（Coupling constants）**：
- 描述特定基本相互作用的强度
- 例如：精细结构常数 \(\alpha\)（电磁）、强耦合常数 \(\alpha_s\)（强力）、弱混合角 \(\sin^2\theta_W\)（弱力）

**3. 物质常数（Material constants）**：
- 描述基本粒子的性质
- 例如：电子质量 \(m_e\)、质子质量 \(m_p\)、夸克质量、CKM矩阵元

**4. 宇宙学常数（Cosmological parameters）**：
- 描述宇宙的整体性质
- 例如：哈勃常数 \(H_0\)、宇宙学常数 \(\Lambda\)、重子密度、暗物质密度

#### 40.1.2 按量纲分类

**有量纲常数**：
- 光速 \(c\)：\(LT^{-1}\)
- 普朗克常数 \(\hbar\)：\(ML^2T^{-1}\)
- 引力常数 \(G\)（或 \(k\)）：\(L^3M^{-1}T^{-2}\)
- 玻尔兹曼常数 \(k_B\)：\(ML^2T^{-2}\Theta^{-1}\)

有量纲常数的数值依赖于单位制的选择，因此它们的"大小"没有绝对意义。

**无量纲常数**：
- 精细结构常数 \(\alpha \approx 1/137\)
- 强耦合常数 \(\alpha_s(M_Z) \approx 0.118\)
- 弱混合角 \(\sin^2\theta_W \approx 0.231\)
- 电子-质子质量比 \(m_e/m_p \approx 1/1836\)
- 引力耦合常数 \(\alpha_G = G m_p^2/(\hbar c) \approx 10^{-38}\)
- 宇宙学常数与普朗克密度之比 \(\rho_\Lambda/\rho_p \approx 10^{-120}\)

无量纲常数的数值不依赖于单位制，因此它们才是真正"有意义"的物理常数。任何终极物理理论应该能够解释这些无量纲常数的数值。

### 40.2 常数的层级结构

#### 40.2.1 能标层级

物理常数可以按其对应的能标组织成层级结构：

| 能标 | 数值 | 物理 |
|---|---|---|
| 普朗克能标 | \(10^{19}\) GeV | 量子引力、时空泡沫 |
| 大统一能标 | \(10^{16}\) GeV | 强、弱、电磁统一 |
| 超对称破缺能标 | \(10^3 - 10^{16}\) GeV | 超对称粒子（如果存在） |
| 电弱能标 | \(10^2\) GeV | W±、Z⁰、希格斯质量 |
| QCD能标 | \(2 \times 10^{-1}\) GeV | 夸克禁闭、强子质量 |
| 电子质量 | \(5 \times 10^{-4}\) GeV | 电子静质量 |
| 中微子质量 | \(< 10^{-10}\) GeV | 中微子振荡 |
| 宇宙学常数 | \(10^{-30}\) GeV | 暗能量 |

这个层级结构中最引人注目的是**巨大的能标间隔**：
- 电弱能标与普朗克能标相差17个数量级（等级问题）
- 宇宙学常数与普朗克能标相差约120个数量级（宇宙学常数问题）

#### 40.2.2 等级问题

**等级问题（Hierarchy Problem）**：为什么电弱能标（\(M_W \sim 100\) GeV）远小于普朗克能标（\(M_p \sim 10^{19}\) GeV）？

在标准模型中，希格斯玻色子的质量平方受到量子修正，其修正量正比于紫外截断能标的平方。如果紫外截断在普朗克能标，那么为了让希格斯质量在电弱能标，需要对裸质量进行约34位有效数字的精细微调——这是极不自然的。

解决等级问题的方案包括：
- **超对称（SUSY）**：超对称粒子抵消了二次发散
- **大额外维度**：引力在额外维度中扩散，使得有效普朗克能标降低
- **复合希格斯**：希格斯不是基本粒子，而是更强相互作用的复合态
- **人择原理**：我们观测到的能标是因为只有在这样的能标下智慧生命才能存在

#### 40.2.3 宇宙学常数问题

**宇宙学常数问题（Cosmological Constant Problem）**：为什么观测到的宇宙学常数（暗能量密度）比量子场论预言的真空能密度小约120个数量级？

量子场论中，每个场模式都贡献零点能 \(\frac{1}{2}\hbar\omega\)。积分到普朗克能标，得到真空能密度：

\[
\rho_{\text{vac}} \sim \frac{M_p^4}{\hbar^3 c^5} \sim 10^{96} \, \text{kg/m}^3
\]

而观测到的暗能量密度：

\[
\rho_\Lambda \sim 10^{-26} \, \text{kg/m}^3
\]

二者相差约120个数量级。这是物理学中最严重的自然性问题，目前没有公认的解决方案。

## 第41章 自然单位制的多种方案

### 41.1 普朗克单位制

#### 41.1.1 定义

普朗克单位制令 \(c = \hbar = G = k_B = 1\)（有时也令 \(4\pi\epsilon_0 = 1\)）。在普朗克单位制中，所有物理量都变为无量纲数。

基本单位：
- 普朗克长度 \(l_p = \sqrt{G\hbar/c^3}\)
- 普朗克质量 \(m_p = \sqrt{\hbar c/G}\)
- 普朗克时间 \(t_p = \sqrt{G\hbar/c^5}\)
- 普朗克温度 \(T_p = \sqrt{\hbar c^5/(G k_B^2)}\)

#### 41.1.2 k形式的普朗克单位

在k体系中，\(k = 4\pi G\)，因此普朗克单位可以写为：
- \(l_p = \sqrt{k\hbar/(4\pi c^3)}\)
- \(m_p = \sqrt{4\pi \hbar c/k}\)
- \(t_p = \sqrt{k\hbar/(4\pi c^5)}\)

在普朗克单位制中，\(k = 4\pi\)（因为 \(G = 1\)）。

#### 41.1.3 约化普朗克单位

有时使用约化普朗克质量 \(M_p = \sqrt{\hbar c/(8\pi G)} = m_p/\sqrt{8\pi}\)，使得爱因斯坦场方程中的 \(8\pi G\) 因子变为1。在约化普朗克单位中，\(k = 8\pi^2\)（因为 \(G = 1/(8\pi)\)，所以 \(k = 4\pi/(8\pi) = 1/2\)... 等等，让我重新算）。

实际上，约化普朗克单位令 \(8\pi G = 1\)，即 \(G = 1/(8\pi)\)，因此 \(k = 4\pi G = 4\pi/(8\pi) = 1/2\)。

### 41.2 原子单位制

#### 41.2.1 定义

原子单位制（Hartree原子单位）令 \(\hbar = m_e = e = 4\pi\epsilon_0 = 1\)，常用于原子物理和量子化学。

基本单位：
- 长度：玻尔半径 \(a_0 = 4\pi\epsilon_0 \hbar^2/(m_e e^2) = \hbar/(\alpha m_e c)\)
- 质量：电子质量 \(m_e\)
- 时间：\(\hbar^3 (4\pi\epsilon_0)^2/(m_e e^4)\)
- 能量：哈特里能量 \(E_h = m_e e^4/((4\pi\epsilon_0)^2 \hbar^2) = \alpha^2 m_e c^2\)

在原子单位中，光速 \(c = 1/\alpha \approx 137\)，引力常数 \(G\) 是一个极小的数。

### 41.3 几何单位制

#### 41.3.1 定义

几何单位制令 \(c = G = 1\)，常用于广义相对论。在几何单位中：
- 质量和长度具有相同量纲（\(GM/c^2\) 具有长度量纲）
- 时间和长度具有相同量纲（\(ct\) 具有长度量纲）
- 所有物理量都可以用长度的幂次表示

在几何单位中，\(k = 4\pi G = 4\pi\)。

### 41.4 自然单位制的选择原则

选择哪种自然单位制取决于研究的物理问题：
- **量子引力/高能物理**：普朗克单位制（\(c = \hbar = G = 1\)）
- **量子场论/粒子物理**：自然单位制（\(c = \hbar = 1\)）
- **广义相对论/天体物理**：几何单位制（\(c = G = 1\)）
- **原子物理/量子化学**：原子单位制（\(\hbar = m_e = e = 1\)）
- **统计物理/热力学**：令 \(k_B = 1\)

k体系的有理化常数 \(k = 4\pi G\) 在各种单位制中都有对应的简洁形式，这是有理化的优势之一。

## 第42章 物理常数的时间变化

### 42.1 狄拉克大数假说

#### 42.1.1 大数的巧合

1937年，狄拉克注意到一些基本物理常数组合成的无量纲大数之间存在惊人的巧合：

\[
\frac{e^2}{4\pi\epsilon_0 G m_p m_e} \sim 10^{39}
\]
\[
\frac{\text{宇宙年龄}}{\text{光穿越原子的时间}} \sim 10^{39}
\]
\[
\frac{\text{宇宙中粒子数}}{\text{}} \sim 10^{78} \sim (10^{39})^2
\]

这些大数都约为 \(10^{39}\) 或其幂次，狄拉克认为这不是巧合，而是暗示了某种深刻的物理联系。

#### 42.1.2 大数假说

**狄拉克大数假说（Dirac Large Numbers Hypothesis）**：这些大数之间的等式不是巧合，而是随宇宙时间保持的关系。由于宇宙年龄随时间增加，这意味着某些"常数"实际上随时间变化。

具体来说，狄拉克提出引力常数 \(G\) 随时间反比减小：

\[
G \propto \frac{1}{t}
\]

这意味着早期宇宙的引力更强。

### 42.2 常数变化的观测约束

#### 42.2.1 引力常数变化的约束

多种观测对 \(G\) 的时间变化给出了严格约束：

**月球激光测距**：通过测量地月距离的变化，约束 \(\dot{G}/G\)：
\[
\left|\frac{\dot{G}}{G}\right| < 10^{-12} \, \text{yr}^{-1}
\]

**脉冲星计时**：双星脉冲星的轨道演化对 \(G\) 的变化敏感：
\[
\left|\frac{\dot{G}}{G}\right| < 10^{-11} \, \text{yr}^{-1}
\]

**宇宙学**：大爆炸核合成和CMB对早期宇宙的 \(G\) 值给出约束：
\[
\frac{G_{\text{BBN}}}{G_0} = 1 \pm 0.1
\]

这些约束表明，在宇宙年龄的时间尺度上，\(G\) 的变化极其微小，狄拉克大数假说的原始形式（\(G \propto 1/t\)）已被排除。

#### 42.2.2 精细结构常数变化的约束

**类星体吸收线**：通过观测高红移类星体的吸收线，测量早期宇宙的精细结构常数：
\[
\frac{\Delta\alpha}{\alpha} = (-0.5 \pm 1.3) \times 10^{-5} \quad (z \sim 0.5 - 3)
\]

**原子钟**：实验室中不同原子钟的频率比对 \(\dot{\alpha}/\alpha\) 给出约束：
\[
\left|\frac{\dot{\alpha}}{\alpha}\right| < 10^{-16} \, \text{yr}^{-1}
\]

目前没有确凿证据表明 \(\alpha\) 随时间或空间变化。

### 42.3 k体系中的常数变化

在k体系中，\(k = 4\pi G\)，因此 \(G\) 的任何变化都等价于 \(k\) 的变化：

\[
\frac{\dot{k}}{k} = \frac{\dot{G}}{G}
\]

k体系不主动预言常数的时间变化，因为这不是k定义的必然推论。如果未来实验发现 \(G\)（或 \(k\)）随时间变化，可以将其作为额外的唯象参数纳入k体系，但这需要修改广义相对论（因为 \(G\) 为常数是GR的基本假设）。

## 第43章 无量纲常数与"本源"问题

### 43.1 无量纲常数的意义

#### 43.1.1 真正的物理常数

如前所述，有量纲常数的数值依赖于单位制，因此它们的"大小"没有绝对意义。真正有意义的是无量纲常数，它们的数值不依赖于单位制的选择。

目前，标准模型有约20个无量纲参数：
- 3个规范耦合常数（\(\alpha_1, \alpha_2, \alpha_3\) 或等价地 \(\alpha, \sin^2\theta_W, \alpha_s\)）
- 9个费米子质量（6个夸克 + 3个带电轻子，以希格斯VEV为单位）
- 4个CKM矩阵参数（3个混合角 + 1个CP相位）
- 1个希格斯质量（或四次耦合 \(\lambda\)）
- 1个强CP相位 \(\bar{\theta}\)
- 宇宙学常数 \(\Lambda\)（以普朗克密度为单位）

如果中微子有质量，还需要增加约9个参数（3个质量 + 4个PMNS矩阵参数 + 可能的马约拉纳相位）。

#### 43.1.2 终极理论的目标

任何终极物理理论（如弦理论）的一个重要目标是解释这些无量纲常数的数值：
- 它们是唯一确定的吗？
- 还是有多种可能（真空景观）？
- 我们观测到的数值是随机的吗？
- 还是由某种原理（如人择原理）选择的？

目前，这些问题都没有确定的答案。

### 43.2 人择原理

#### 43.2.1 人择原理的表述

**弱人择原理（Weak Anthropic Principle, WAP）**：

> 我们观测到的宇宙必须与我们作为观测者的存在相容。

这是一个几乎自明的陈述：我们只能观测到允许智慧生命存在的宇宙。

**强人择原理（Strong Anthropic Principle, SAP）**：

> 宇宙必须具有那些在其历史的某个阶段允许生命在其中发展的性质。

这是一个更强的陈述，暗示宇宙的性质在某种意义上是"为了"生命而设计的。

#### 43.2.2 人择原理的应用

人择原理被用来解释一些看似"微调"的物理常数：

**宇宙学常数**：如果 \(\Lambda\) 太大（正或负），宇宙要么膨胀太快无法形成结构，要么重新坍缩，生命无法存在。我们观测到的 \(\Lambda\) 值恰好允许星系和生命的形成。

**强相互作用强度**：如果强力稍强或稍弱，恒星核合成的产物会完全不同，可能无法形成碳和氧等生命必需的元素。

**电磁相互作用强度**：精细结构常数 \(\alpha\) 的值影响原子和分子的稳定性，以及恒星的寿命。

**引力强度**：如果引力太强，恒星会太小太短命；如果太弱，可能无法形成恒星和星系。

#### 43.2.3 人择原理的争议

人择原理在物理学中是一个有争议的话题：
- **支持者**认为，在多重宇宙/弦景观的框架下，人择原理是解释常数微调的自然方式
- **批评者**认为，人择原理是不可证伪的，不科学，而且阻碍了对更基本解释的追求

k体系对人择原理持中立态度：k体系不依赖于人择原理，也不排除人择原理作为常数解释的可能性。

### 43.3 k体系中的常数层级

在k体系中，常数的层级结构与标准物理完全一致：
- \(k = 4\pi G\) 是引力耦合常数，量纲 \(L^3M^{-1}T^{-2}\)
- \(k' = 1/\varepsilon_0\) 是电磁耦合常数，量纲 \(ML^3T^{-4}I^{-2}\)
- \(\eta, \xi\) 是实验拟合参数，量纲分别为 \(M^{-1}IT\) 和相应的色荷-质量比
- \(\hbar, c\) 保持独立常数地位
