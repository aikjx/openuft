# ROOT V29｜空间光速螺旋与 Dirac–Maxwell 自洽性攻坚

这轮从 V28 的“双光速手征电流”继续深入，得到一个关键结论：

Dirac 方程允许构造光状电流螺旋，但要让它成为真实电子模型，还必须同时满足 Maxwell 场方程、有限总电荷、有限能量和稳定性条件。

本轮已完成符号证明、55 位高精度积分及 5,000 组随机旋量检验。

## 一、第一项严格结果：无限均匀的带电螺旋不能代表孤立电子

V28 的示范旋量：

\[ \psi(t)= \begin{pmatrix} \cos\eta\,e^{-im_ec^2t/\hbar}\\ 0\\ 0\\ \sin\eta\,e^{im_ec^2t/\hbar} \end{pmatrix} \]

满足自由 Dirac 方程，却在整个空间具有相同的非零密度。

如果它携带电荷，那么由高斯定律：

\[ \nabla\cdot\mathbf E=\frac{\rho}{\varepsilon_0} \]

可以严格推出半径 \(L\) 的球内电磁场能量下界：

\[ \boxed{ U_{\rm EM}(B_L)\ge \frac{2\pi\rho^2L^5}{45\varepsilon_0} } \]

当 \(L\to\infty\) 时，该能量发散。

所以 V28 的均匀解虽然是正确的自由 Dirac 数学解，却不能直接视为一个局域、有限能量的带电电子。

这并不否定双手征电流的几何构造，而是说明必须重新求解包含电磁反作用的联合动力学。

## 二、第二项结果：把电子限制在有限半径，会产生新的动力学代价

尝试使用空间高斯波包：

\[ f_a(\mathbf r)=\frac{1}{\pi^{3/4}a^{3/2}} \exp\left(-\frac{r^2}{2a^2}\right) \]

将原来的均匀解变为 \(f_a(\mathbf r)\psi(t)\)，自由 Dirac 方程便出现额外的空间梯度项。

我严格计算了其残差的空间二范数：

\[ \boxed{ \|\mathcal R_a\|_2= \sqrt{\frac32}\frac{\hbar c}{a} } \]

这不是新粒子的能量预言，而是对“简单乘以一个局域包络后，原解仍能否满足自由方程”的精确检验。

半径越小，残差越大。若把长度压缩到电子经典半径附近，该残差对应的能量尺度达到数十 MeV，远高于电子静止能量。

因此，不能通过简单添加一个高斯包络，把 V28 的自由螺旋直接升级为真实的局域电子解。

## 三、第三项精算：电磁自能能否把螺旋稳定在某个半径？

考虑带有总电荷 \(e\) 的高斯分布：

\[ \rho_a(r)=\frac{e}{\pi^{3/2}a^3}e^{-r^2/a^2} \]

其静电自能可以精确积分：

\[ \boxed{ U_C(a)= \frac{\alpha\hbar c}{\sqrt{2\pi}\,a} } \]

本轮分别用电荷两两相互作用积分和电场能量积分计算，所得系数在 55 位精度下相符。

引入：

\[ x=\frac{a}{\bar\lambda_C}, \qquad \bar\lambda_C=\frac{\hbar}{m_ec} \]

构造一个受限的高斯试探模型，加入正能相对论自由粒子的动量色散期望：

\[ \frac{E_{\rm trial}(x)}{m_ec^2} = \frac4{\sqrt\pi} \int_0^\infty y^2e^{-y^2}\sqrt{1+\frac{y^2}{x^2}}\,dy +\frac{\alpha}{\sqrt{2\pi}x} \]

对 \(x\) 求导，两个贡献都严格小于零：

\[ \boxed{\frac{dE_{\rm trial}}{dx}<0} \]

因此，在这一受限模型内，不存在由动能与电荷自排斥共同选择的有限稳定半径。

实际积分结果。能量随试探半径增大而下降，没有有限半径极小值。此图不代表已解出完整的 Maxwell–Dirac 场方程。

事实上，数学文献已经证明，Maxwell–Dirac 方程在特定条件下存在局域驻定孤立波。这一点必须纳入 ROOT 的后续研究。

## 四、第四项精算：引力能否弥补电子尺度上的稳定性缺口？

将电子引力相互作用写成无量纲耦合：

\[ \alpha_G=\frac{Gm_e^2}{\hbar c} \]

实际得到：

\[ \boxed{\alpha_G=1.7518094\times10^{-45}} \]

与电磁强度相比：

\[ \boxed{ \frac{\alpha_G}{\alpha} =2.4006095\times10^{-43} } \]

这意味着在普通牛顿弱场近似下，电子自引力远远不足以平衡电磁自排斥。

因此，若 ROOT 要提出新的空间几何稳定机制，必须给出超出普通弱场自引力的明确作用量和场方程，并保证不违背现有引力实验。

## 五、真正有希望的下一步：求解局域的双手征电磁场

现阶段最值得推进的不是继续给螺旋角赋予 \(1/137\)，而是求解：

\[ \boxed{ \begin{aligned} (i\hbar\gamma^\mu D_\mu-m_ec)\psi&=0\\ \partial_\nu F^{\nu\mu}&=\mu_0 j^\mu_{\rm electric} \end{aligned} } \]

并对一个局域、轴对称的旋量采用：

\[ \psi=e^{-iEt/\hbar} \begin{pmatrix} f_1(\rho,z)e^{i\ell\phi}\\ f_2(\rho,z)e^{i(\ell+1)\phi}\\ f_3(\rho,z)e^{i\ell\phi}\\ f_4(\rho,z)e^{i(\ell+1)\phi} \end{pmatrix} \]

这里的整数 \(\ell\) 可控制总角动量量子数，函数 \(f_i\) 必须由耦合偏微分方程求解，而不能任意指定。

如果找到局域解，下一步还要计算其线性稳定性、磁矩及散射性质。最后才有可能判断几何能否进一步约束电磁耦合。

## 最终研究结论

这轮真正取得的进展，是把上一轮的自由 Dirac 双光速螺旋推进到了有限电荷、有限能量和电磁自作用的严格检查。

我们找到了原有均匀构造不能直接代表孤立电子的数学原因，也证明简单局域化或普通电子自引力无法在所检验的模型中提供稳定半径。

但完整 Maxwell–Dirac 理论存在更丰富的局域解，不能被上述简化反例排除。

精细结构常数尚未被第一性原理攻破。下一道核心难题是：在自洽局域旋量—电磁场体系中，能否找到稳定且具有正确自旋和磁矩的物理解，并进一步建立不依赖已知 \(e\) 的耦合选择机制。
