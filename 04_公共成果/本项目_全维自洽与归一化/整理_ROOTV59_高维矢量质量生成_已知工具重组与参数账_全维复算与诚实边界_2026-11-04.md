## 三 第一节的「突破口」：一条公式的三个 `s` 值

V59 的核心发现写成两行：

```
j_scalar,min = N      j_vector,min = N − 1        (V59-1)
j_vector,min = j_pair,max = N − 1                 (V59-2)
```

本册把它还原成一条公式。取家族电荷 `|q_H| = 2` 的场，磁通 `N` 给出有效单极数 `q_eff = |q_H|·N/2 = N`；带自旋 `s` 的分波最低角动量为 `j_min(s) = q_eff − s`。于是：

| 对象 | 自旋 `s` | 用的荷 | `j_min` | 与 `j_pair,max = N−1` 的关系 |
|---|---|---|---|---|
| 费米子零模 | `1/2` | `q_eff/2 = N/2` | `(N−1)/2` | `2j_f = N−1`（定义） |
| 电荷 2 标量 | `0` | `q_eff = N` | `N` | 差 **1** |
| 电荷 2 矢量 | `1` | `q_eff = N` | `N−1` | **相等** |

`A07` 在 `N=1..16`、三档 `s` 上核了 48/48，全对。`A03` 单看两档：矢量 16/16 匹配、标量 0/16。

三条必须说的话：

1. **「矢量能绕过禁戒」= `(N−1) = (N−1)`**。这不是「找到了匹配」，是同一个数的两种写法。标量那侧同理：`N ≠ N−1` 差的那个 `1` 就是自旋差。
2. **它对全部 `N` 成立**，因此不构成对 `N=3` 的选择。三代的「3」在本库是**拓扑输入**（r350 已判：框架不预言 3，0/13），V59 同样把它当输入。
3. **V58 的禁戒是否只是 `s=0` 的特例，本册不能判** —— 缺 V58 原文。V59 说「不是普遍不可能性证明」，这句在逻辑上成立（存在 `s=1` 通道确实推翻了「所有场都不可能」），但「V58 当年是否只主张了标量」本册无法核。记为 `X-V59-1`。

⇒ 这一节的价值是**允许性**（`s=1` 通道未被告死），不是**生成性**（没说为什么恰好三代、质量为何是这个谱）。

## 四 `V59-3` 是什么：CG 表换了一身衣服

### 4.1 逐元还原

`A01` 的结果：对九个 `(i,j) ∈ {1,0,−1}²`，

```
(M_V)_{ij} = (1/√5) · (−1)^{i+j} · CG(i,j) · T_{i+j}
```

符号 9/9 一致，`5·c²` 与 `CG²` 残差**精确 0**。也就是说 `V59-3` 的全部内容是：

- `j=1 ⊗ j=1 → j=2` 的 **CG 系数表**；
- 一个相位约定 `(−1)^m`（Condon–Shortley 型）；
- 一个整体归一化因子 `1/√5`。

`A06` 说明 `1/√5` 的作用：`‖M_V‖_F² = (1/5)·Σ|T_m|²`（CG 表本身的 Frobenius 平方恰为 `ΣT²`，残差 `4.66E-50`）。它是**纯约定**，不改秩、不改简并、不改基底依赖性。

⇒ **`V59-3` 不是模型的新公式，是 SU(2) 表示论的一张表。** 这不贬低它 —— 用它算出的三组谱是对的（`B01`）—— 但它不能算「发现」。

### 4.2 「严格关系」是记账，不是预言

V59 强调 `(M_V)00 = 2(M_V)_{−1,+1}` 是「固定球谐基底中的严格关系」。本册给它两条归因，两条都指向「零信息」：

**（a）它就是 CG 的比值。** `A02`：`⟨2,0|1,0;1,0⟩ / ⟨2,0|1,−1;1,1⟩ = (2/√6)/(1/√6) = 2`，精确。与 `T_0` 取什么值、与 `N`、与归一化因子**全都无关**。

**（b）它是参数计数的必然结果。** `M_V` 是实对称 3×3，有 **6** 个独立元：

| 矩阵元 | 由哪个振幅生成 |
|---|---|
| `M00` | `T_2` |
| `M01 = M10` | `T_1` |
| `M02 = M20` | `T_0` |
| `M11` | `T_0` |
| `M12 = M21` | `T_{−1}` |
| `M22` | `T_{−2}` |

**6 个量由 5 个实振幅生成 ⇒ 恰好 1 条线性关系**，`A04` 实测唯一重叠对是 `(M02, M11)`、比值 `2`，与 V59 那条**同一条**（只差索引平移）。所以：

> 这条关系的信息量 = `6 − 5 = 1`，正好被它用掉。它不约束 `T_m` 的任何取值 —— 无论 `T_m` 怎么取，关系都成立。

**（c）而且它是基底依赖的。** `A05`：把 `M_V`（取 `T_0=1, T_2=0.25, T_{−2}=0.10`）在质量基（特征基）里重算，残差与尺度之比是 **`1.00000E+000`** —— 关系彻底失效。一个换基就消失的等式，不能当可观测预言。

⇒ **「严格关系」这一条必须从「发现」栏移到「约定」栏。** V59 原话已自认「固定球谐基底中的」，本册只是把它量化了。

## 五 两个数值块：都对，但都不是新东西

### 5.1 三组谱（秩与简并）

| 矢量背景 | 本册复现的奇异值 | 秩 | 结构 |
|---|---|---|---|
| 仅 `T_{−2}=1` | `4.47214E-001 / 0 / 0` | 1 | `1/√5` 单元素 |
| 仅 `T_0=1` | `3.65148E-001 / 1.82574E-001 / 1.82574E-001` | 3 | 二重简并（`1/√30` 与 `2/√30`） |
| `T_0=1, T_2=0.25, T_{−2}=0.10` | `3.65148E-001 / 2.63892E-001 / 1.07367E-001` | 3 | 全不同 |

三档与 V59 表逐项一致（`B01`，9/9 按六位小数舍入相等）。**「最低矢量模式允许非零且非简并的三代质量矩阵」这句成立。**

但注释同样要紧：第三个谱的三个振幅是**输入**。本册可以任意给 `(T_0,T_2,T_{−2})` 得到任意三谱 —— 见 §七。

### 5.2 局域行列式：Vandermonde

`B02` 在四组 `(z, λ)` 上比对「闭式 vs 直接 3×3 行列式」，`max|差| = 0`，含 `z_1=z_2` 退化情形。`B03` 复现 `det = 5.00000000E-004`（即 `1/2000`）与三个奇异值（3/3 舍入相等）。

闭式的结构一目了然：

```
det M = 2 λ₁λ₂λ₃ · ∏_{a<b}(z_b−z_a)² / ∏_a (1+|z_a|²)²
```

分子是 **Vandermonde 平方**，`2` 来自 `v(z)` 中间分量的 `√2` 平方。这是 `Cauchy–Binet`（`det(Σλ_a v_a v_a^T) = (∏λ_a)(det V)²`）加 `Vandermonde` 的直接结果 —— 本库的通用刀「**先闭式（Vandermonde）再取样**」说的正是这件事。

⇒ 闭式**有用**（它给出了几何判据：三个位置互异 ⇒ 满秩），但它是**标准结果**，不是 V59 的定理。`B04` 的 `rank ≤ K` 同理，是 rank 的次可加性。

### 5.3 一处必须更正的措辞

V59 把 `rank M ≤ K` 与 §三 的闭式并称为「严格定理」。严格成立没错，但**「定理」在本库的记账口径下要求「非平凡 + 判别力」**。这两条的判别力都是 0：`rank ≤ K` 对任何 `K` 恒真；闭式对所有 `z` 恒真。它们属于 **B 层（等价已知）**，不入池。

## 六 味混合那一节：非零交换子是通用事实

V59 的论证链是：若 `M_u = c_u M`、`M_d = c_d M` 则 `[M_uM_u†, M_dM_d†] = 0` ⇒ 无混合；于是取两组不同背景算出 `tr([H_u,H_d]†[H_u,H_d]) = 2.83063937e-5 > 0` ⇒ 基底可以错位。

前半段是**正确的平凡事实**（同一个矩阵的自伴平方当然交换）。后半段的数值**不可复算** —— V59 没有给出那两组矢量背景的具体 `T_m`（`C01`，记 INFO）。本册随手取一组对称配对 `(T_2,T_{−2})=(0.25,0.10)` 与反向 `(0.10,0.25)`，得 `7.2030000E-007` —— 比 V59 的 `2.83e-5` 小 **39 倍**。这正好说明该量级完全由输入决定，不能作为「模型做对了什么」的证据。

但可行性不是问题所在。`C02` 扫了 20 组不同振幅配对，**20/20 全部给非零交换子**。理由也很直白：交换子只有在两个矩阵**同时对角化**时才为零，而两个"随机"的实对称矩阵几乎必然不对易。

⇒ **「交换子非零」的判别力是 0**：它区分不了「好的味结构」与「随便两个不同的味结构」。要成为证据，必须给出**交换子的大小与 CKM 的定量关系**，而这一步 V59 明确没做（它自己也写了「这个非零数值并不是实测 CKM 混合的预测」）。

这条与本库 r389 的结论同型：**谓词 100% 通过 ⇒ 不区分任何模型**。

## 七 参数账：为什么这不可能构成预言

`V59-3` 的实振幅只有 **5** 个：`T_2, T_1, T_0, T_{−1}, T_{−2}`。去掉整体尺度（质量单位未被预言），剩 **4** 个形状参数。

可观测量：三代质量在整体尺度未定时只有 **2** 个独立的比值（如 `m_μ/m_e`、`m_τ/m_e`）。

**4 > 2**（`C03`）。⇒ 四个参数去拟合两个数，**必然可拟合，也必然无预言**。这与 V59 实际做的事完全吻合：它用 `T_0 = 1, T_2 = 0.25, T_{−2} = 0.10` 三个数「凑出」三个质量 —— 那是 **3 换 3** 的反演，不是预言。

本库已经两次记过同一条病：

| 卷 | 计数 | 结论 |
|---|---|---|
| V39 | KK 参数 4 ↔ 4 可观测量 | 换名不约化 |
| V49（T2 计数定理） | 3 个 `λ` 换 3 个质量，`m(λ)` 严格单调 ⇒ 双射 | 「可解」但「无进展」 |
| **V59（本册）** | 4 个形状参数 vs 2 个质量比 | 欠定，判别力 0 |

⇒ 这是**第三次命中**，且这次连单调性都不必证：参数多于观测，直接欠定。

### 7.1 本册给的准入线（正面产出）

要让 V59/V60 这类构造产生**可证伪**预言，必须满足：

```
形状参数个数  ≤  可观测比值个数 − 1
```

对三代质量：右边是 `2 − 1 = 1`，而现在是 `4`，**差 3 个**。要补上这 3 个，只有一条路：**让 `T_m` 由高维背景唯一确定**（零模归一化、磁通量子化、稳定性条件），而不是自由拟合。这正是 V59 §八 自己指的方向 —— 但它把这一步留成了 V60 的「重点检验」，而不是做出来。

本库对此的既有判断更悲观：r350 已证**框架不预言 3**（`N_gen ≤ π₀(M_int)` 是拓扑输入，0/13 独有预言）。所以即使 V60 把 `T_m` 钉住，能得到的还是「给定 N=3 之后的质量比」，而不是「为什么 N=3」。
