# 体系坐标系

[统一体系层](../README.md) · [八层骨架](../统一架构/统一架构总纲.md) · [机器可读坐标](体系坐标表.csv)

## 用途

坐标系把"体系之间怎么比"变成可执行的检查项。每个体系在 10 个维度上取值，取值空缺必须显式写 `—`，不得留空、不得猜测填写。

## 10 个维度

| 编号 | 维度 | 取值规范 | 空缺含义 |
|---|---|---|---|
| C1 | 本体 ontology | 一句话，不含数学符号 | 无本体主张（纯数学框架） |
| C2 | 本源参数 primitives | 参数集合与个数 | 未指定 |
| C3 | 几何载体 geometry | 具体几何结构名 | 未建立几何 |
| C4 | 内禀代数 algebra | 群/代数及表示 | 未建立代数 |
| C5 | 时空维度 dimension | 整数或维度约化方案 | 未指定 |
| C6 | 动力学完备性 dynamics | complete / partial / none | 无场方程 |
| C7 | c 的地位 c_role | limit（上限）/ identity（恒等）/ geometric（几何化）/ n_a（不涉及） | 未讨论 |
| C8 | 自由参数 free_params | 可调连续参数个数 | 未审计 |
| C9 | 冻结预测 frozen_predictions | 已预先登记、有阈值的预测条数 | 0（未冻结任何预测） |
| C10 | 最高证据等级 max_evidence | 见 [证据等级](#证据等级) | 无 |

## 证据等级

沿用 `01_独立体系` 的 claims 状态与 [诚实红线](../../00_项目治理/CONTRIBUTING.md)：

`conjecture`（主张，未验） < `numerical_check`（数值自检） < `mathematical_result`（数学结论） < `observational_support`（独立观测支持）；`falsified` 为终态，不参与排序。

**numerical_check 只能否证，不能确证**。一个体系若最高只到 numerical_check，则不得表述为"已验证"。

## 填写纪律

1. 坐标取自该体系 `system.json` 与 `claims.csv`，不得从综述文字推断。
2. 一个维度内出现多个互斥取值（例如同一体系不同版本对 c 地位不同），填**最新版本**并注明版本 revision。
3. 坐标相同不构成理论等价（见八层 T1）。
4. 本表随体系身份变更刷新；坐标本身不是证据。
