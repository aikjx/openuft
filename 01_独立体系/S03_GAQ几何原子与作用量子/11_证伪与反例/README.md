**自我推翻留痕（S03-C0052）**：S03-V18.5 曾把分支三裁为「可行且建议作为下一步主线」。执行后表明该表述过强——分支三的**输入**存活属实，但**结论为不可判决**。「输入存活」不能读作「可行」。

**方法论教训（已写入判定册 §3.4）**：

1. **单分量变号不是闭合证据**：脚本首版只监视位置差的分量 $g_z$ 的符号变化即判根，二分出 amp≈1.0085 的伪根（二分后残差仍 2.898 m）。闭合要求三分量同时为零，判根必须用全矢量残差。
2. **步长收敛检验是必需的**：残差在 6000→48000 步之间逐位一致，据此把根因从「数值误差」纠正为「判据错误」。若无这一步，会把判据缺陷误归罪于积分器。

**不作为否证登记的项（防过度否定）**：步长收敛是**数值方法的正面读数**（积分已达机器精度），不是物理正面证据；「唯一存活的相变图像」（挠率释放，$\kappa'/\kappa_0\in[1,1.0073]$）是可描述的形式推论，**只能被否证、不能被确认**。
