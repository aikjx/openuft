# ROOT V121 — 严格推导与开放问题

## 1. 单位与螺旋几何
使用 c=1（几何关系），G 和 ℏ 不设为1。曲线 r(t)=(R cos ωt,R sin ωt,pt)，速度归一化 R²ω²+p²=1，曲率 κ=Rω²，挠率 τ=pω，因此 κ²+τ²=ω²。注意该关系仅在给定曲线及速率归一化下成立；不能从中推出引力定律。

## 2. 圆周谱算子
在长度 L 的圆周上，D_a=-i∂_s+a，取周期边界条件 ψ(s+L)=ψ(s)，特征值 λ_n=2πn/L+a。a 是常数实连接；自伴性依赖明确的定义域。规范等价 a→a+2πk/L 仅改变谱标签。谱并不能仅从 κ,τ 唯一确定。与黎曼猜想的关联是谱方法的类比，绝非零点物理起源证明。

## 3. 候选标量—张量作用量
S=∫√(-g)[F(χ)ℛ/(16πG) -(1/2)g^{μν}∂μχ∂νχ -V(χ)+ℒ_m]d⁴x，度规号差(-,+,+,+)。χ 为待定义的几何序参量，F 为无量纲正函数。对度规变分：
F G_{μν}=8πG(T^{(m)}_{μν}+T^{(χ)}_{μν})+∇_μ∇_ν F-g_{μν}□F，T^{(χ)}_{μν}=∂_μχ∂_νχ-g_{μν}[(1/2)(∂χ)²+V]。
对 χ 变分：□χ-V'(χ)+F'(χ)ℛ/(16πG)=0。
这些是标量—张量理论的标准形式，不能宣称独创或实验证实。F=1、χ为常数且V=0时回到 Einstein 方程。

## 4. 物理瓶颈
(1) 无协变定义 χ(κ,τ)；(2) 无第一性原理唯一指定 F,V；(3) 无标准模型规范群及粒子谱；(4) 未证明量子一致性、能量条件与稳定性；(5) 未提供超越 GR 的可证伪数值预测；(6) 未给出可行人工真实引力工程机制。

## 5. 下一阶段可执行研究
先选择一个明确的协变世界线/场构造，证明场方程守恒与稳定性；再在弱场线性化计算 PPN 参数、第五力和引力波传播；最后与太阳系、等效原理、实验室短程引力及双星观测比对。若仅复制现有标量—张量理论，则不能算四力统一。
