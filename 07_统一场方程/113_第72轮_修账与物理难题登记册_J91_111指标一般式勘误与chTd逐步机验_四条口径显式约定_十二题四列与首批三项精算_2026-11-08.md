## 二、A1：111 §5.2 的勘误（含由 `ch·Td` 推出的每一步）

### 2.1 卷内原式（111 §5.2 第 140 行，逐字）

```
index(D_V) = ∫ c₃(V) + (1/12)∫ c₁(V)·c₂(TM)
```

### 2.2 正确式

```
index(D_V) = ∫ ch₃(V) + (1/12)∫ c₁(V)·c₂(TM)，    ch₃ = (c₁³ − 3c₁c₂ + 3c₃)/6
```

### 2.3 逐步推导（脚本 §1 用形式多项式引擎逐项复算，非只核打印系数）

1. `index(D_V)=∫_M ch(V)·Td(TM)`（Atiyah–Singer 指标密度）。
2. `ch(V)=r + c₁ + (c₁²−2c₂)/2 + (c₁³−3c₁c₂+3c₃)/6 + …`（次数 0／2／4／6）。
3. `Td(TM)=1 + c₁(TM)/2 + (c₁(TM)²+c₂(TM))/12 + c₁(TM)c₂(TM)/24 + …`。
4. CY3 条件 `c₁(TM)=0` ⇒ `Td(TM)=1 + c₂(TM)/12 + …`。
5. 取 6-形式部：只有 `ch₃(V)·1` 与 `ch₁(V)·c₂(TM)/12` 存活；`ch₂·c₁(TM)/2` 与 `ch₀·c₁(TM)c₂(TM)/24` 因 `c₁(TM)=0` 归零。
6. 得 `index=∫ch₃(V)+(1/12)∫c₁(V)c₂(TM)`。∎
7. 情形 α（`V=TM`）：`c₁(V)=c₁(TM)=0` ⇒ `ch₃(TM)=c₃(TM)/2` ⇒ `index=(1/2)∫c₃(TM)=χ/2`（用 Gauss–Bonnet `∫c₃=χ`）。
8. 情形 β（线丛 `L`）：`c₂=c₃=0` ⇒ `ch₃(L)=x³/6` ⇒ `index=∫x³/6+(1/12)∫xc₂`；`index=3 ⇔ 2∫x³+∫xc₂=36`。
9. 三代链：`χ=2(h¹¹−h²¹)`，`index=3 ⇔ χ=6 ⇔ h¹¹−h²¹=3`（标准嵌入）。

脚本机读产物（G03）：`ch·Td` 的 6-形式部（`c₁(TM)=0`）为

```
{ c₁³ : 1/6,  c₁c₂ : −1/2,  c₃ : 1/2,  c₁·c₂(TM) : 1/12 }
```

与第 6 步逐项相同；打印式的 c₃ 系数为 1，与上表的 1/2 不符。

### 2.4 判决表

| 条目 | 卷内原式/读数 | 独立重算 | 判决 |
|---|---|---|---|
| 一般式 | `∫c₃(V)+(1/12)∫c₁c₂` | `∫ch₃(V)+(1/12)∫c₁c₂` | **不一致** |
| c₃ 系数 | 1 | 1/2 | **不一致** |
| `V=TM` | `index=χ/2=−100`（同卷自洽） | χ=−200 ⇒ 打印式给 −200 | **不一致**（打印式与同卷差 2 倍） |
| `ch` 展开 | 111 §5.2 第 135 行 | 逐项复算 | 一致 |
| `Td` 展开 | 111 §5.2 第 136 行 | `1+c₂/12` | 一致 |
| `index=3⇔χ=6⇔h¹¹−h²¹=3` | 111 §5.2 第 142 行 | 算术恒等 | 一致 |
| 线丛 36 条件 | 111 §5.2 第 143 行 | `2∫x³+∫xc₂=36` | 一致（打印的条件式本身对，但由打印一般式推不出来） |

### 2.5 波及面（三层）

1. **同卷自相矛盾**：`V=TM` 时打印式给 `∫c₃(TM)=χ`，而同段又写 `index=χ/2`；χ 为奇数时给半整数。
2. **三代判据失效**：若沿用 `index=3 ⇒ χ=3 ⇒ h¹¹−h²¹=1.5`（非整数），三代条件不成立。
3. **两个分支互不污染**：标准嵌入（`index=χ/2`）与线丛（`2∫x³+∫xc₂=36`）各自单算仍正确，错的只是「一般式」这一行本身；`G33` 的机验口径（只核打印式自身系数）已记入新债 #19，本轮由 G03 补齐。

## 四、A3：债务 #19 的机器化（由 `ch·Td` 推出，不只核打印系数）

`#19` 的漏洞是：`G33` 只验「打印式两两系数是否相加正确」，没有验「打印式是否真由 `ch·Td` 推出」。本轮把这一步做成**形式多项式乘法**：

- 表示：`dict[monomial → Fraction]`，`monomial = ((symbol, exponent),…)`；`symbol` 带次数（`c₁,t₁:2；c₂,t₂:4；c₃:6；r:0`）。
- 乘法：`pmul` 逐项相乘、`pslice` 取总次数 6、`pzero_syms` 代入 `t₁=0`。
- 三条独立测试：① `V=TM`（`c₁=0`）⇒ 只剩 `c₃/2`（G05）；② 线丛（`c₂=c₃=0`）⇒ `x³/6+xc₂/12`（G06）；③ 一般 `c₁≠0` ⇒ 四项全在（G03）。
- 错误式在测试 ① 给 `c₃` 整系数 1（差 2 倍）、测试 ② 漏 `2∫x³`（G04、V-CHTD-7）。

结论：`#19` 关闭——一般式的推出链已被机器复算，`111 §5.2` 第 140 行的首项确应写作 `∫ch₃(V)`。

## 六、首批三项精算（负结果照写、不调参）

### 6.1 B1 宇宙常数：`ρ_vac=(5/7)v⁴`

由 A8（105 B1）：`V_min=−28/45`，`v²=14/15`（A8 单位 `u`）。换算 `v²=(14/15)u² ⇒ u⁴=(15/14)²v⁴`，故

```
ρ_vac = |V_min|·u⁴ = (28/45)(15/14)² v⁴ = (5/7) v⁴     （精确，无 O(1) 歧义）
```

取 `v=246.22 GeV`（外贴，声明于脚本）：`ρ_vac=2.625×10⁹ GeV⁴`；取 `ρ_Λ≈1.912×10⁻⁴⁷ GeV⁴`（外贴）：**比值 1.373×10⁵⁶**。反解「要让 A8 的真空能等于观测值」所需标度：`M=(7ρ/5)^{1/4}≈2.28 meV`，与 `246.22 GeV` 差 **1.08×10¹⁴ 倍**。

判决：A8 对真空能**给得出数、给不出预言**——`V_min` 与电弱标度同源（`μ²=4/3`），把它放到 meV 需要另一个原理。P02 判「可算」，附此负结果。

### 6.2 B2 中微子：seesaw 结构可求导，`M_R` 无原理

126 在 SU(5) 下 `1⊕5⊕10⊕15⊕45⊕50`，**单态恰一枚**（104 A5），故 Majorana 项允许且只有一个标度。取 `m_ν=y²v²/M_R`、`y=1`：

| `M_R` | `10¹⁴` | `10¹⁵` | `10¹⁶` GeV |
|---|---|---|---|
| `m_ν` | 0.606 eV | 0.0606 eV | 6.06 meV |

要让 `m_ν=0.05 eV`（`√Δm²_atm`），需 `M_R=1.212×10¹⁵ GeV`。这只是把「一个自由参数」换成「一个外部数」：126 单态 VEV 是自由输入，**不构成预言**（P03 判「可算」的条件义）。

### 6.3 B3 质量层级：缺口 ×1159

`m_τ/m_e=1776.86/0.51099895=3477.18`（外贴质量值，精确算术）；框架 L2 的质量比上确界为 3（102/J76）⇒ **缺口 1159**。同一分段另给规范层级：`v/M_Pl=246.22/1.220×10¹⁹=2.018×10⁻¹⁷`，`v²/M_Pl²≈4.07×10⁻³⁴`；框架无机制压此比值（P04）。

判决：两项都是**可算的负结果**——数字算得出，机制不在框架内。
