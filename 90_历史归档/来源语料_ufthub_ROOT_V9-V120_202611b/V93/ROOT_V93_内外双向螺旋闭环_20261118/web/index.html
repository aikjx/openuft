参数控制

ρ(u) = R + a cos(nu)
z(u) = a sin(nu)
θ(u) = mu
σ(u) = √[(an)² + m²ρ²]
Ω(u) = mβc/σ(u)
dt/du = σ/(βc)
当 β=0.8 时可作为有质量粒子的条件运动学模型，但轨迹仍需要实际合力与场源支持。几何闭合本身不生成一种新力。

该网页不连接外部服务，不使用实验数据。空间闭合不等于时空闭合，闭合轨迹不意味着零能耗、自发产生场或四力统一。模型及计算源码见 ZIP 的 src/ 与 research/。
