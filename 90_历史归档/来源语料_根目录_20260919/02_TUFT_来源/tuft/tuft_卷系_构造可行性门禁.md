# TUFT / H-TUFT 卷系·构造可行性门禁（定理 A~I 机器化）

> **定位**：本册是**工程化/对账工具册**——**不新增物理主张**、**不占 CUR 编号**、**不改动任何 CURATED 真源状态**。
> 它把 `tuft_卷系_结构障碍定理族.md` 的 no-go 定理族 **A~I** 变成**进入门槛**，并独立复核最新的补充卷I（CUR-21）。
> **红线**：数学自洽 ≠ 实验证实。机检为**关键词启发式**，只用于**对账与提醒**；判定以人工矩阵为准。
> **配套**：`tuft_卷系_构造可行性门禁.py`（可复跑）+ `_report.txt`（实跑报告）+ `tuft_卷系_覆盖矩阵_机器版.json`（机器视图）。

## §1 九条门禁问句（由定理**陈述**推得；**未按全矩阵调参**）

| 定理 | 门禁问句 | 机检可靠性（自检准确率） |
|---|---|---|
| **A** 总导数不源引力 | 是否把某可观测量归因于**拓扑项（全导数）**？ | **可用**（1.00） |
| **B** 离散整数不编码连续/层级 | 是否用**离散整数/拓扑荷**去确定**连续量或层级**？ | **可用**（1.00） |
| **C** 无跑动 ⇒ 无内生尺度 | 是否在 `β≡0` 前提下声称**内生标度/层级**？ | ⚠️ **不可用**（0.33） |
| **D** 重参数化 ≠ 派生 | 是否含**≥1 自由参数**却称作「派生量」？ | ⚠️ **弱**（0.50） |
| **E** 窗口不可逆 | 是否依赖**已被排除的窗口**（或把已关窗口当未来优先级）？ | **可用**（1.00） |
| **F** 无破缺源 ⇒ 无破缺量 | 是否生成**破缺量**（CP/手征）而未给不可消除的破缺源？ | **可用**（1.00） |
| **G** 同伦不唯一选群 | 是否声称**仅凭拓扑/同伦数据导出规范群**？ | **可用**（1.00） |
| **H** 约束自证循环 | 是否以**取小自由参数**达成约束满足并声称「已检验」？ | ⚠️ **弱**（0.67） |
| **I** 模态谱增量比有界 | 是否用**固定算符的束缚态谱（模态）**生成**代/质量层级**？ | **可用**（1.00） |

> **可靠性分级的用途**：自检准确率 **= 1.00 ⇒ 机检可用于对账**；**0.5 ≤ acc < 1 ⇒ 仅作检索提示**；
> **acc < 0.5 ⇒ 禁用作门禁**（C 落在此类）。
> **注意**：本轮**未**为提升准确率而调参——按「不过拟合」原则**保留由定理陈述导出的原规则**，并**降级**其权重。这本身是**定理 D** 的自律应用：让规则拟合人工矩阵，等于制造一个无预言力的重参数化。

## §2 实跑结果（`PASS=4 / FAIL=0 / BOUNDARY=9 / INFO=78`）

### 2.1 §V0 独立复核补充卷I（CUR-21）

| 项 | 独立重算 | CUR-21 声明 | 结论 |
|---|---|---|---|
| 普朗克标度超限 | `(1.220910e19 / 8.5e3)^3 = 2.9634e+45` | 2.97e45 | ✅ 一致 |
| 相变标度超限 | `(1.000e15 / 8.5e3)^3 = 1.6283e+33` | 1.63e33 | ✅ 一致 |

> **结构提示（诚实）**：两个「超限倍数」**只是立方比恒等式** `(尺度/上限)³`，不含额外信息。
> CUR-21 的结论强度**完全取决于外部上限** `σ_max = (8.5 TeV)³` 本身（**[B] 级外部锚，非本理论导出**）。
> 故其可检验性 = 「外部 BBN 上限是否可信」，而非「本理论预言了什么」。

### 2.2 §V1 判别力自检

自检样本取自人工矩阵的**高置信子集**（非全矩阵）：A/B/E/F/G/I 全部 1.00；**C = 0.33、D = 0.50、H = 0.67**。
按不过拟合原则**保留原规则**，并据此**降级**其在门禁中的权重（见 §1 表）。

## §3 本轮**发现并修复的真缺陷**

> **门禁的首次实跑即发现一处真缺陷**（这正是它存在的意义）：

| 项 | 内容 |
|---|---|
| 现象 | `V3a` FAIL：**CUR-07**（主线全局 MCMC，**❌ 已触发**）**未被 A~I 矩阵的任何一行覆盖** |
| 严重性 | 高——它是 **❌ 条目**，而卷系标准要求「每条排除都要有结构性依据」 |
| 根因 | 人工覆盖矩阵的 **E 行**漏列 CUR-07（E 行原为 `CUR-01、02、03、13 + CUR-10~21`） |
| 判据 | CUR-07 的 `Z=0` 正是由**三窗 CLOSED（EDM/g-2/ringdown）导出** ⇒ **定理 E（已窗口不可逆）就是它的结构性依据** |
| 修复 | 已在 `tuft_卷系_结构障碍定理族.md` **E 行补登 CUR-07** 并注明"由本门禁的覆盖完整性审计补登" |
| 复跑 | V3a/V3b/V3c **全部 PASS**；实跑计数 `PASS=4 / FAIL=0` |
