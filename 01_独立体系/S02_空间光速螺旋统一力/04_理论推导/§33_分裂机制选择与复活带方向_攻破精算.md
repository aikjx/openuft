## 0. 目标与前值

§32 已严格求出：完整 50 表示的 Δb_c1 = 3·T2 − 2·T3 − T1 = **0**（精确）；**非零 Δb 只能来自分裂**——S1（弱类活跃）= +15、S2（色类活跃）= −15、50+50̄ 对 ±30；10TeV 复活带门槛：单 50（S1）需 M_extra ∈ [1.79, 2.23] M_GUT、50 对需 [1.34, 1.49] M_GUT；1TeV 复活带在微扰界下排除。

本节回答：**哪种分裂机制给出 Δb = +15（S1 方向）且微扰安全？**

## 2. V2 — Missing Partner Mechanism（MPM）

超势（TTP14 eq.2.1）：
```
W_MPM = H̄₅·H₇₅·Z₅₀ + Z̄₅₀·H₇₅·H₅ + M₅₀·Z₅₀·Z̄₅₀
```
⟨H₇₅⟩(1,1,0) 通过量子数匹配把 5̄ 的色三重态 T̄=(3̄,1,1/3) 与 50 的同量子数分量配对 → 质量矩阵 m_T = [[0,V],[V,M₅₀]]（eq.2.2）、有效三重态质量 M_T^eff = −V²/M₅₀（eq.2.6）。

**关键：50 中与 T̄ 同量子数分量 = B = (3̄,1,1/3)（唯一）**。两种情形：

| 情形 | 锁重 | 活跃（低标度） | Δb_c1 | 判读 |
|---|---|---|---|---|
| 最简 MPM | 仅 B | A+C+D+E+F | **+1.20** | < +15 → **10TeV 复活带不可达** |
| 色类全锁（DMPM 型） | B+E+F | A+C+D | **+15.00** | = S1 → **复活带方向可达** |

**新结论（较 §31/§32 更尖锐）**：§31/§32 只说"要分裂才有 Δb"；本节给出**分裂必须是色类全锁型**——MPM 最简（只锁 B）只有 +1.2，远低于 +15 门槛。

## 3. V3 — Sliding Singlet

PDG §92.3 [51]：5H 的色三重态 T 与 singlet 通过势能滑动保持轻。**天然方向 = 色类活跃于低标度 = S2 型 Δb=−15**，与复活带所需 +15 **反号** → ✗ 排除。

## 4. V4 — Orbifold 投影（P2′）

P2′ = diag(−1,−1,−1,1,1)，KK 零模奇偶 = (−1)^{Σ色指标}。按**色表示谱**判定（表示论标准，非权重格依赖）：

| 分量 | 色谱 Σ色 mod 2 | 投影 |
|---|---|---|
| A=(6,3,1/3) | 偶（6 表示全偶） | 保留 |
| B=(3̄,1,1/3) | 奇（3̄ 表示全奇） | 投影 |
| C=(8,2,−1/2) | 偶（8 adjoint 全偶） | 保留 |
| D=(3,2,7/6) | 奇（3 表示全奇） | 投影 |
| E=(6̄,1,−4/3) | 偶（6̄ 全偶） | 保留 |
| F=(1,1,2) | 偶 | 保留 |

保留 A+C+E+F：Δb_c1 = **+3.60**；投影 B+D：−3.60（互补 ✓，Σ=0）。标准 DTS 校验：5 的 T(−1/3) 投影、D(+1/2) 保留 ✓（PDG §92.3）。

**判读**：orbifold 单投影 +3.6 仍 < +15 → **单 BC 不足复活**，需叠加 BC 组合（P1′/P3′）或额外色类分裂。PDG 微扰比 M*/Mc ≲ 100 为上限锚。

## 5. V5 — M_T^eff 复活带对照（文献锚 + 诚实修正）

10TeV 复活带（§29/§31）：M_Hc_eff ∈ [3.54e17, 1.39e18] GeV（κ ∈ [38,149]）；1TeV：[2.98e19, 1.16e20]（κ ∈ [3200,12500]）；100TeV：[4.38e15, 1.69e16]（κ ∈ [0.47,1.81]）。

- **MPM 单表示**：V=1e16 → M_T^eff = V²/M₅₀。M₅₀=1e15 → 1.0e17 GeV（κ≈11）；M₅₀=5e11 → 2.0e20 GeV（κ≈2.1e4）——**PTEP 2022 锚 κ~2×10⁴ 恰落 §31/§32 已排除的 1TeV 复活带量级**，且 M₅₀≲1e15 使 50 低标度进入 RGE → **SU(5) 非微扰**（TTP14）。→ **机制级永久排除确认**。
- **DMPM（eq.2.9）诚实修正**：M_T^eff = V⁴/(μ′M₅₀M₅₀′)。在 V=1e16、μ′=10 TeV 下要入 10TeV 复活带需 M₅₀M₅₀′ = 2.9e42–7.1e41 GeV² → M₅₀≈8.5e20–1.7e21 **> M_Pl=1.22e19 → 简单式不可达 ✗**。TTP14 例子的 M_T^eff≈2e18（κ≈215，10TeV 带上界 149 的邻域）靠**高阶 VEV 结构**（⟨S⟩ 型、eq.4.7 的 V⁸ 结构）实现 → **微扰安全方向正确，但参数区需专门构造**。

## 6. V6 — 判定汇总

- **[J1]** 复活带 Δb=+15 的唯一方向 = **色类全锁分裂**（保留弱类 A+C+D、锁 B+E+F）。MPM 最简 +1.2、orbifold P2′ +3.6 均不足；sliding singlet −15 反号。
- **[J2]** 微扰安全要求 50 质量 Planck 级（DMPM 型）或 orbifold KK 阈值；MPM 单表示（M₅₀≲1e15）非微扰。
- **[J3]** **MPM 单表示 κ~2e4 非微扰且恰落 1TeV 复活带量级 → §32 的 1TeV 排除找到机制根源**：不是跑动参数巧合，而是 missing partner 的固有质量标度结构（V²/M₅₀）必然给出 κ~1e4 级并伴随 50 低标度非微扰。
- **[J4]** orbifold 单投影 +3.6 不足 +15，需叠加 BC 组合或额外分裂。
- **[J5]** **S02 定级**：延续 §23"组织性语言"定级不变；本轮闭合"分裂机制→Δb 方向→复活带可达性"的选择链，但 DMPM 高阶 VEV（⟨S⟩ 型）的完整数值参数区仍开放。

## 7. 局限与开放窗口（§34 候选）

1. **V-耦合的权重格判定局限（诚实披露）**：初版曾用"权重和为零"判 5̄⊗75⊗50 单态收缩，对 75 的零权重（重数 5）方向不敏感（需张量 Clebsch–Gordan）→ 改用量子数匹配 + TTP14 m_T 结构锚定。这是 §33 的边界，不隐藏。
2. **50 权重构造路径**：§32 的 sym(10⊗10)−5̄（norm 空间）权重多集含多重度，与表示权重谱不完全一一对应；分量级判据（T3/T2/T1、Δb、奇偶）均用表示论标准值，与 §32 T(50)=280/16 锚一致。
3. **§34 开放窗口**：DMPM 高阶 VEV 结构（⟨S⟩ 型 V⁸）的参数区扫描——找到微扰安全且 Δb=+15、M_T^eff ∈ 10TeV 复活带的完整实现；或 orbifold 双 BC 组合（P2′P3′ 等）的 Δb 叠加。
