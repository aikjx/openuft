# ROOT V125 三大根波候选模型验证

约定 c=1，G 和 ħ 保留独立。三大根波在此暂定义为标量 S、矢量 V、张量 T 的独立物理模式；不是用户术语的已确认定义。

线性有效模型：[(∂t²−∇²)I+M²]Ψ=0。平面波频率满足 det[(ω²−k²)I−M²]=0。对于实对称且半正定的 M²，本征值 μ²≥0，ω²=k²+μ²，群速度 vg=k/ω≤1。

计算使用示例无量纲 M²=[[0.04,0.01,0],[0.01,0.09,0.02],[0,0.02,0.16]]，k=1。所有数值是人为指定的示范参数，不是实验拟合，也不是新物理预测。

结果：本征值 [0.03794968,0.08668599,0.16536433]；频率 [1.01879816,1.04244232,1.07952042]；群速度 [0.98154869,0.95928569,0.92633727]。

验证边界：线性代数、正频率、亚光速群速度通过。尚未验证：三根波确实存在、其规范一致性、洛伦兹协变完整理论、引力耦合、量子化、标准模型粒子谱、实验信号。简单的 S/V/T 混合可能违反旋转对称性或规范不变性，不能直接视为基本作用量；需从协变作用量与约束推导允许的耦合。
