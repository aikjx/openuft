# ROOT V118｜四高度引力一致性 + 地球形状因子修复

## 这是一个什么包

继承 ROOT V117 的单标量线性弱场玩具模型，使用 2026 地球 Yukawa 形状因子文献完善地球密度模型，给出球外三高度逆作用程**严格唯一性定理**、源密度/耦合/G 无关的**微分闭环条件**、第四高度的**留出式反例检查**以及近圆轨道**径向频率与进动**计算。

**本包没有攻破四力统一**。历史 396 项科研问题原样保留，已完成的是明示假设下数学与数值的子任务。

## 一键运行

```bash
python -m pip install -r requirements.txt
python run_all.py
python -m pytest tests/test_v118.py -q
```

可选浏览器回归（需要系统安装 Chromium 及 Python playwright）：

```bash
python tests/browser_smoke.py
```

从项目根目录运行。输出 `results/V118_RESULTS.json` 与 5 张计算图；`web/index.html` 可离线打开。

## 目录说明

- `src/model.py`: 量纲保持、Yukawa 球外模型、四类密度形状因子、三高度单调反演、四高度留出检查、微分残差、近圆轨道频率。
- `tests/test_v118.py`: 独立 mpmath 积分、SymPy 精确证明、多个密度/高度/作用程随机组合和数值异常测试。
- `research/01_完整中文科研总论.md`: 公式、实验边界、量纲及最新相关文献。
- `research/02_严格证明_唯一性_四高度_进动.md`: 推导、单调唯一性定理、微分一致性条件。
- `research/03_396项OPEN_验收与下一步.md`: 科学问题逐项审计与下一次真实观测验收协议。
- `ledger/V118_ALL_396_PRESERVED.csv`: V117 完整历史台账，编号及状态不改。
- `archive/V117_original.zip`: 原始完整历史科研包（可继续追溯更早版本）。
- `web/index.html`: 无网络依赖的离线参数实验室。

## 五个实质成果

1. V117 均匀密度球表面第五力 ≈0.9775%，改进地球解析密度得到 ≈0.5954%，五层球文献拟合约0.5931%。
2. 三高度表观 GM 差值比，独立于耦合、地球质量和球内密度；严格证明逆作用程唯一性。
3. `K(r)=r²g(r)` 的微分闭合恒等式 `(K'')²−K'''K'−(K')²/r²=0`，无需输入 G、M、密度或 ℓ。
4. 第四高度可识别伪装为单一 Yukawa 的两个不同作用程反例；独立评估噪声放大。
5. 从同一引力势求导得近圆轨道额外进动；400km 的条件模型值约 2.47°/径向周期。

## 最重要的边界

没有读取或拟合真实卫星遥测/轨道测量；没有得到独立的新力信号，也没有从任何原理无参数求出 G。研究目的在于建立**严格可证伪**的候选理论测试接口。
