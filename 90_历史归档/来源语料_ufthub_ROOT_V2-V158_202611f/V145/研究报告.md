# ROOT V145：三条路线攻坚
仅 c=1；ħ、G 保留量纲。本文为已知理论的重推导与条件性判伪，非统一场论证明。

## 1. 软定理
在 Lorentz 不变散射矩阵、标准软极点及无质量自旋 2 的前提下，软因子与 Σ s_i g_i p_i^μ p_i^ν/(p_i·q) 成正比。偏振规范替换 ε_μν→ε_μν+q_μζ_ν+q_νζ_μ 给出 Σ s_i g_i p_i^μ=0。对一般交换动量的两种粒子，四动量守恒给出 (g_A−g_B)Δp_A=0，故普适耦合。不能由此推出自旋2的存在或G值。自旋1软因子对应 Σ s_i e_i=0，电荷可不同。

## 2. 真实合金输入
使用 Ti90 Al6 V4 与 Pt90 Rh10 质量百分比；原子质量采用 NIST 代表值，电子质量/u 与 u 能量当量为 CODATA 2022。电子静质量占比 f_e=Z m_e/M_atom；核库仑能占比代理 f_C=0.71 Z(Z−1)/(A^(1/3) M_atom[MeV])，近似以平均原子质量数代替同位素质量数。并非完整电磁能量分解。合金按质量权重平均。
MICROSCOPE 2022: η=(-1.5±2.3_stat±1.5_syst)×10^-15。假定误差独立、近似高斯，保守绝对上界 |mean|+1.96σ=6.882e-15；不是重新拟合原始数据。
若 g∝f_e 或 g∝f_C，则 η=2(f_A−f_B)/(f_A+f_B)，分别为 0.1320 和 −0.6594，条件性排除。若 g=g0(1+δ_e f_e+δ_C f_C)，在小修正、固定地球源下 η≈δ_e Δf_e+δ_C Δf_C。单参数近似上界分别 2.20e-10、3.51e-12；两参数存在零方向 δ_C≈0.0159564 δ_e，不能同时独立约束。不是通用第五力耦合常数限制。

## 3. 完整应力能量
T_{μν}=−2/√−g δS_m/δg^{μν}；总张量含相互作用、物质及场，分解依赖方案，不能重复计数。弱静态线性引力 ∇²Φ=4πG(T00+Σ Tii)。静止孤立局域系统 ∂_k T^{kj}=0，积分 ∂_k(x^i T^{kj})=T^{ij} 得 ∫T^{ij}=0（边界项消失），故远场单极引力质量为总能量 E。辐射本身 ΣTii=T00；封闭容器应力补偿，不能遗漏容器能量。代码仅验证理想六束辐射的代数关系，不求解真实容器。
弱场远距离 g=−G E r/r³（忽略自引力高阶修正）。一般情况回到 Einstein 方程和物质场方程。
G=ħ/M_P² 是定义而非预测；必须独立求 M_P。维度 [G]=L/M、[ħ]=ML。光子机械螺旋不能由软定理推出，四力统一仍开放。
