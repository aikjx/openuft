## 一、判决主文（八段，逐段挂读数）

**（一）`a_j ∈ Z` 有一般证明，但它是一行有限差分恒等式。**
`a_j = Δ^j P(0) = Σ_i (−1)^{j−i} C(j,i) P(i)` 是整数的整数组合。`A01`：130 项逐项一致、失配 0。

**（二）证明的前提是 `P(Z) ⊆ Z`，而 `χ` 自动满足它，故整条证明零几何输入。**
`A02`：三个反例族（`k/2`、`k²/2`、`C(k,2)+k³/3`）在去掉前提后 Newton 系数全非整，3/3 命中。`A03`：纯组合多项式 `C(k,2)+3C(k,3)`（不对应任何簇）同样满足，17 个整数点全整 ⇒ 主语是多项式。

**（三）因此 r339 的「定理 B」是定义恒等式，不是几何定理；其 30/30 是引擎自检。**
`A04`：72 组全整、非整 0 —— 一条 100% 通过的谓词判别力为 0。`D01`：r339 的 30 组读数逐项复现；`G11`：与 r339 落盘 JSON 逐项字符串相等，30 组差异 0。

**（四）但「全整」确实能检出算错——只是必要非充分。**
`A05`：算错 td 两种，非整 27/30 与 29/30。`A06`：算错却仍全整的 3 组与 1 组（`(1,2)` 错给 `(0,2)` vs 正确 `(1,2)`）⇒ 通过筛选 ≠ 算对。

**（五）`Z ⊆ S` 对任意射影簇成立，是 `S` 的定义，信息量 0。**
`S` 由「`χ` 是否整」定义，而 `χ` 是欧拉示性数 ⇒ 整数处必整。这条不是「削弱」，是**读法要改**：有信息量的是 `S \ Z` 与 `S` 的上界。

**（六）真定理是「分母整除首项」，而且无假设。**
定理 C：`k = r/M` 最简、`P(k) ∈ Z` ⇒ `M | a_n`。证明四行（乘 `M^n n!`、取模 `M`、`N_j ≡ r^j`、只剩 `a_n r^n`）。`B01`：72 组 × `M ≤ 24`，违例 0；`B02`：900 个三元组上 `N_j ≡ r^j` 失配 0；**证明不需要 `a_j ∈ Z`**。

**（七）推论 `S ⊆ (1/d)Z`，对 `n = 1` 尖锐、对 `n ≥ 2` 只是上界。**
`B03`：`M` 扫到 `6d`，292446 组合命中 0。`B06`：分母全落在 `divisors(d)`，37 对越界 0。`B04`：`n=1` 时 `S = (1/d)Z` 精确，`d = 1..24` 全中 24/24。`B05`：`M = d` 可达仅 13/72。

## 二、为什么值得单独立册

因为这不是一卷「又算了点东西」，而是**把前四卷的一句判词读高了一格**。

r325 → r327 → r331 → r335 → r339 这条线，一直在回答「整性能不能把通量逼成格」。r339 的答案给到了 `...INTEGRALITY-NEVER-EXCLUDES-AN-INTEGER-FLUX`，并把它挂在两个承重件上：`a_j ∈ Z`（定理 B）与 `Z ⊆ S`（推论）。本卷证明这**两个承重件都不承重**：

- `a_j ∈ Z`：三行初等算术，与流形无关；
- `Z ⊆ S`：`S` 的定义，与簇无关。

**判词本身仍成立**（整性从不排除整数通量），但**它成立的理由换了**：不是「算出一个全整的定理」，而是「`S` 本来就包含所有整数」。这不是修辞差别 —— 它决定了这条结论**能不能被当成框架的约束**。答案是不能。

而本卷同时补上 r339 缺的那条**真有内容**的定理（定理 C），它给的是一个**界**（`S ⊆ (1/d)Z`），而不是一句恒真。

## 三、引理 L 与降级（定理组 A）

**引理 L**。`P ∈ Q[k]`、`deg P = n`、`P(Z) ⊆ Z` ⇒ `a_j = Δ^j P(0) ∈ Z`。
证明：`Δ^j P(0) = Σ_{i≤j}(−1)^{j−i}C(j,i)P(i)`，整数组合。∎

**套用**：`P(k) = χ(O_X(kH))` 是欧拉示性数 ⇒ `P(Z) ⊆ Z` 无条件成立 ⇒ 引理 L 直接给出 r339 的定理 B。

**降级的机读依据**：

**`A06` 为什么重要**：`(1,2)` 上错算给 `a = (0,2)`，正确是 `(1,2)`。`χ` 差 1，Newton 系数仍全整 —— 这说明「整数守恒的错」能整块穿过这道筛子。**任何把 `a_j ∈ Z` 当正确性证书的用法，都必须先声明白名单外还有多少这样的错。**

## 四、定理 C：分母整除首项（定理组 B）

> **定理 C**（**无假设**）。`P(k) = Σ_{j≤n} a_j C(k,j)`，`a_n ≠ 0`，`a_j ∈ Q` 任意。若 `k = r/M` 最简（`M ≥ 2`）且 `P(k) ∈ Z`，则 `M | a_n`。

**证明**。`M^n n! P(r/M) = Σ_j a_j (n!/j!) M^{n−j} N_j(r)`，`N_j(r) = Π_{i<j}(r − iM)`。左端被 `M` 整除。模 `M`：`N_j(r) ≡ r^j`，`j<n` 项带 `M^{n−j}`（`≥ M`）全部消失，得 `a_n r^n ≡ 0 (mod M)`；`gcd(r,M)=1 ⇒ M | a_n`。∎

**与 r339 的关系**：r339 从未给出这个界；它的四类分类（`S=Z` / 非陪集 / `(1/d)Z` / `CP¹`）里，`(1/d)Z` 那一类此前只由 `n=1` 的解析特例支撑（`d ≤ 4`）。定理 C 把它变成**所有 `n`、所有 `d` 的上界**，并解释了为什么 `d` 含 5、7、11 时额外点只在 `1/d` 上出现。

**尖锐性**：`n = 1` 时 `χ = dk + 1 − g`，`P(r/M) ∈ Z ⇔ M | d r ⇔ M | d`，故 `S = (1/d)Z` **精确**（`B04` 24/24）。

**不尖锐处**：`M = d` 只在 13/72 组可达（`B05`）⇒ 对 `n ≥ 2`，`(1/d)Z` 是**真上界**，真实 `S` 落在更细的分母谱里（`{2}` 最常见，14 组）。

## 五、定理 D：陪集内周期性（定理组 C）

> **定理 D**。`Q(m) = P(c+m)`，`b_i = Δ^i Q(0)`。则 `M^n n! b_i ∈ Z`；取 `N0 = (M^n n!)^2`，`Q(m+N0) − Q(m) ∈ Z` ⇒ 积分性以 `N0` 为周期。

推导要点：`b_i = Σ_{j≥i} a_j C(c,j−i)`（`C01` 396 陪集失配 0）；`Q(m+N0) − Q(m) = Σ_i C(m,i)[Σ_{j>i} b_j C(N0,j−i)]`，括号内为整数（因为 `N0` 取成 `M^n n!` 的平方可保证 `C(N0,k)` 被 `M^n n!` 整除）⇒ 差为整数 ⇒ 周期。

**结构推论**：`M | d` 只给**有限个**陪集，每个陪集上积分性周期 ⇒ **`S` 是有限个算术级数之并**（`C05` 重构 == 直接算，30 组失配 0）。

**这解释掉了 r339 的 `C04 非陪集 7/30`**：r339 的判据是仿射封闭 `u−v+w ∈ S`，在 `(3,2)` 上见证 `u=−6`、`v=−11/2`、`w=−4` ⇒ `u−v+w = −9/2 ∉ S`（`CTL6/CTL7` 复现：`P(−11/2) = −21 ∈ Z`，`P(−9/2) = −35/4 ∉ Z`）。这不是「S 无序」，而是 `−11/2` 属于 `c=1/2` 的周期 4 级数、`−6,−4` 属于 `Z` 级数 —— **两个级数不同模数，仿射封闭必然失败**。

**稀疏化警告**：`C06` 显示 `n` 增大时额外点迅速消失（`n=6, d=2` 在 `[-240,240]` 内 0 点）。故定理 D 是**结构陈述**，不保证「稠密」，也不保证「周期可见」。

## 十、诚实边界（七条）

1. **只做算术**：三条定理都是关于多项式的命题，套到 `χ` 上不增加几何内容；本卷没有证明任何关于流形的新事实。
2. 定理 C 一般成立，但「`S ⊆ (1/d)Z`」用了 `H^n = d`（超曲面）；一般极化簇要换成 `H^n`。
3. 定理 D 的周期界是粗界，且实测周期随 `n` 迅速变长；「有限并」是结构陈述，不排除几乎为空。
4. `C03` 的周期在窗口 `[-96,96]` 内测，只报「实测最小周期 ≤ 64」，不主张全局最小。
5. 72 组样本非穷举；定理 C 的证明是一般的，但尖锐性只机检到 `d = 24`。
6. 「判别力 0」只针对 `Z ⊆ S` 这一个谓词，不是说 r339 无价值（其 `X-R335-2` 关闭与 `Z+1/2` 坐标假象不受影响）。
