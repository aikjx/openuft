## 二、E348 标量 KG Leaver 三项递推（严格定理）

几何单位 2M=1（M=1，视界 r=2），令 λ=l(l+1)、z=1−2/r，视界入射 Frobenius 约定

R(r) = e^{iωr*} z^{−4iω} Σ_{n=0}^∞ a_n z^n

三项递推 α_n a_{n+1} + β_n a_n + γ_n a_{n−1} = 0（a_0=1，γ_0=0）：

```
α_n = (n+1)(n+1 − 4iω)
β_n = −λ − 2n² + 16 i n ω − 2n + 32ω² + 8iω − 1
γ_n = (n − 4iω)²
```

视界指标方程 ρ² + 4ω² = 0 ⇒ ρ = ±2iω（确认 2iω 约定）。QNM 由 Nollert/Leaver 有限连分数的复根 F(ω)=0 给出，Muller/复根搜索。

**推导**：sympy 严格展开（v10，`tuft_v10_line1_scalar.py`）；**独立验证**：MainAgent 另写 55 位 mpmath 独立连分数（`_ma_v10_indep_scalar.py`），再由第三方库 qnm 背书。
