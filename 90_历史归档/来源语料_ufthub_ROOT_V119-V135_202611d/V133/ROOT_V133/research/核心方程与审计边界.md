# ROOT V133｜核心方程及证明边界

**单位约定：仅 c=1。保留 ℏ、G、所有粒子质量与耦合常数；不设 ℏ=1 或 G=1。**

## A. 最小世界线动力学

时空签名 (-,+,+,+)，固有时 `ds = √(-g_{μν}dx^μ dx^ν)`，世界线必须类时。

令 `θ∈S¹` 为新增内部自由度，`I>0`、`λ` 为新增参数：

\[
S[x,\theta]=-m_0\int ds +\frac I2\int ds\bigl[\dot\theta+\lambda A_\mu u^\mu\bigr]^2.
\]

- `u^μ=dx^μ/ds`；点号表示对固有时求导。
- 电磁规范变换 `A_μ→A_μ+∂_μΛ`，`θ→θ−λΛ(x)`，括号不变。
- 内部守恒动量 `J=I(θ̇+λA·u)`，满足 `dJ/ds=0`。
- 固定 `J` 做 Routh 约化：

\[
S_R=-\left(m_0+\frac{J^2}{2I}\right)\int ds
+\lambda J\int A_\mu dx^\mu.
\]

- 用变分得到 `m_J D_s u^μ = q_J F^μ{}_ν u^ν`，其中 `m_J=m_0+J²/(2I)`、`q_J=λJ`。
- **注意**：上式是给定背景时空和给定 Maxwell 场上的探针方程。它没有从几何独立导出 Maxwell 方程或 Einstein 方程。

## B. 紧致角变量的条件性量子结果

给定标准量子规则 `Ĵ = -iℏ∂_θ`、周期条件 `ψ(θ+2π)=ψ(θ)`，有：

\[
J_n=n\hbar,\quad
q_n=n\lambda\hbar,\quad
m_n=m_0+\frac{n^2\hbar^2}{2I},\quad
\alpha_n=\frac{q_n^2}{4\pi\varepsilon_0\hbar}=\frac{n^2\lambda^2\hbar}{4\pi\varepsilon_0}.
\]

最后一式采用 `c=1` 且显式保留 `ε₀` 的有理化电磁单位约定。**这是对经典世界线模型施加量子条件后的结果，不是从经典螺旋独立证明量子力学。**

`λ` 连续可调：对于任意给定 `α>0`，均可令 `λ=√(4πε₀α/ℏ)`。模型**没有**独立计算出 `α^{-1}=137.035999177(21)`。

## C. 可协变化的曲率／挠率连接

选择沿类时世界线实际定义的两个正交、空间样内部矢量 `e_1^μ,e_2^μ`，并令它们与 `u^μ` 正交。定义：

\[
\Omega_\perp=e_{1\mu}D_s e_2^\mu,\qquad
\Xi=\dot\theta+\Omega_\perp+\lambda A_\mu u^\mu.
\]

内部标架旋转角 `χ(s)` 时 `Ω_⊥→Ω_⊥−χ̇`；同时取 `θ→θ+χ−λΛ`，`Xi` 不变。

\[
S_\mathrm{geo}=-m_0\int ds +\frac I2\int ds\,\Xi^2.
\]

固定角动量 `J` 后：

\[
S_{R,\mathrm{geo}}=-\left(m_0+\frac{J^2}{2I}\right)\int ds
+J\int\Omega_\perp ds +q_J\int A_\mu dx^\mu.
\]

在纯**欧氏三维** Frenet 标架 `(T,N,B)` 中，如果选 `e_1=N,e_2=B`，则 `Ω_⊥=N·dB/ds=−τ`，产生与积分挠率相关的相位。这是类比；不能将选定三维参考系的 `τ` 无条件当作 Lorentz 标量。四维协变版本必须指定真实存在的二维内部平面及其传输规律。

## D. 最大的四个空缺

1. `I、λ、m0` 的第一性原理来源仍未知；因此既未预测 `α`，也未预测三代质量。
2. 圆周 `S¹` 只有 Abelian `U(1)` 结构，不能单独推导 `SU(2)_L` 和 `SU(3)_C` 的手征表示与自相互作用。
3. 世界线探针作用量并未导出 `G`、可量子化的度规动力学或引力子。
4. 规范异常消除、自旋 1/2、电子 g 因子、Born 概率规则等仍需额外量子场论结构。

**裁定**：存在一个数学自洽且可数值验证的 U(1) 纤维探针模型；它不是四力大统一的证明。原 ROOT 外部三维光速螺旋不能直接视为有质量粒子的类时世界线。
