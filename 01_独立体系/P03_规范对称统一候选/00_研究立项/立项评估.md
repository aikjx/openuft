## 2. 立项理由（支持）

1. **标准路径**：规范对称统一（SU(5) → SO(10) → E6 大统一）是标准模型扩展的公认主流方向，四力统一的正统路线之一，具备清晰的群论与表示论工具链。
2. **不受 M02 根因污染**：M02 普朗克锚定谬误是 GAQ 几何化谱系（把 `c/ħ/G` 当作几何导出量）的结构性错误；P03 走**群论 + 表示论 + 耦合常数跑动**，不依赖「常数几何化」主张，可独立健康发展，与 M02 谱系的证伪结论**边界清晰**。
3. **补 S13 的缺口**：S13（对偶分形）已验证对偶代数自洽且唯一含 `verified` claims，但未触四力统一；P03 若立项正确可补这一核心缺口，二者（几何对偶 vs 规范对称）可并行推进。
4. **第一性友好**：大统一的可检验预言（质子寿命、`sin²θ_W(M_Z)`、`α_s(M_Z)`）天然是 L3 级独立预言，便于过 `method_F` 的 L3 门槛。

## 3. 立项风险与必答题（立项前必须给出其一）

- **标准大统一的已知硬约束**：质子衰变 `p → e⁺π⁰` 与 Super-K 实验下限（τ > 1.6e34 年量级）冲突需正面面对；耦合常数在 `M_GUT` 处的跑动汇聚须数值复现并与实测 `sin²θ_W(M_Z) ≈ 0.231`、实验 `α_s(M_Z) ≈ 0.118` 比对。
- **P03 当前未指定**：① 群 `G`（SU(5)? SO(10)? E6?）；② 破缺链 `G → SU(3)×SU(2)×U(1)`；③ 费米子表示填充（三代如何进表示）；④ 作用量形式。**立项前必须选定其一**，否则仍是占位。
- **隔离要求**：不得把 GAQ 谱系的「几何常数导出」当作 P03 的成就；P03 应独立从群论出发，不得继承 S07/S08/S09/S10 已被标 `falsified` 的派生链。
