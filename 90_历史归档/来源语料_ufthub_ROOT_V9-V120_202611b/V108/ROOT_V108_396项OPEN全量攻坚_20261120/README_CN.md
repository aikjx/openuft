# ROOT V108｜396 项 OPEN 全量审计、条件性排除和拓扑数学证明

**版本日期：2026-11-20。** 这是一份可复现的**科研审计包**，不是四力统一完成证明。完整历史 V107 ZIP 保存在 `archive/ROOT_V107_original.zip`，未对旧文件进行静默覆盖。

## 主要新增成果

1. `U107-05`：V107 两组分裂 SU5 多重态的逆问题设计矩阵严格秩 3、未知数 4，精确存在一维零空间；拟合三线交点不等于独立预测。
2. `U107-06`：若额外假设重 X 玻色子质量等于 V107 交点且维度六质子衰变没有特殊抑制，特定标准归一化寿命约 `5.2158×10^25` 年，低于 `p→e+π0` 限制 `2.4×10^34` 年；仅排除该模型假设，不排除所有 GUT。
3. `U107-09`：SU2 BPST 瞬子给出非零正规整体二陈数 `|Q|=1`；18 个场强分量符号核验及高精度径向积分，未证明其源于 ROOT 内部螺旋。
4. `U107-10`：平坦内部相位环面的**纯平移**代数必为阿贝尔，无法仅从平移自动产生强、弱相互作用的非阿贝尔规范群。
5. `U107-11`：`c,ħ` 不能单独构造 `G`；允许独立曲率虽能匹配量纲，但不构成无循环的数值预测。
6. `U107-12`：原目标 OPEN，因尚无新实验结果；所有 396 行原状态和验收标准均被保留，不把局部证明当作全球问题关闭。

## 文件结构

- `research/01_总论.md`：完整研究结论、数值、来源与失败条件。
- `research/02_证明与反例.md`：七项条件定理及其假设、证明和不可推广边界。
- `research/03_所有OPEN优先任务与验收.md`：按照 396 行专属 acceptance 汇总的攻坚路线。
- `ledger/V107_ALL_396_original.csv`：未修改的 396 项原始任务表。
- `ledger/V108_ALL_396_AUDITED.csv`：严格一一对应，增加新审计结论和证据路径；禁止覆盖原状态。
- `src/theory.py`、`src/ledger.py`、`src/generate.py`：符号、数值、全量任务追溯。
- `tests/test_v108.py`：数学条件测试、精确场强、独立积分、回归与边界测试。
- `results/*.json`、`figures/*THEORY.png`：仅理论模型/算法数据，非真实实验。
- `web/index.html`：完全离线、可检索 396 项任务及进行模型参数交互。
- `archive/ROOT_V107_original.zip`：原始旧包，可独立查历史资料。
- `CHECKSUMS.sha256`、`verify_integrity.py`、`VALIDATION_REPORT.md`：独立文件验证。

## 一键复现

需要 Python 3.10+，已测试 Python 3.13。建议干净虚拟环境。

```bash
python -m pip install -r requirements.txt
python run_all.py
python verify_integrity.py
# 可选：系统装好 Chromium 和 playwright 后
python web/browser_smoke.py
```

`run_all.py` 会重新生成 396 项审计、BPST 积分曲线与质子寿命对比图，然后运行 pytest。系统没有联网也可以运行核心代码；联网只用于外部来源的人工更新，不影响现有模型计算。

## 科学证据分级

- **[M]** 在明确前提下成立的数学定理；
- **[C]** 特定动力学/耦合模型中的条件性排除；
- **[N]** 数值模拟和高精度积分（不得称作真实实验）；
- **[O]** 基础物理仍开放；
- **[E]** 外部真实实验结果（本文无自主新实验）。

**没有发现四力共同第一性作用量；没有无循环求出 G；没有量子引力 UV 完备证明；没有新力真实实验。**
