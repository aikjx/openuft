# ROOT V77 证明状态清单

## 严格成立（定义、代数或已确立模型）
- G = 2Z/c，前提是 Z = Gc/2，且 Z 具有物理量纲。
- G = c² r_g / M，前提 r_g=GM/c²。
- G = c³ℓP²/ħ，前提 ℓP=√(ħG/c³)。
- G = α_g ħc/m²，前提 α_g=Gm²/(ħc)。
- r_g/λ̄C = α_g(m)，并且当 r_g=λ̄C 时 m=mP。
- Einstein 方程的耦合系数是 8πG/c⁴；引力作用量的系数在 x⁰=ct 时为 c³/(16πG)。
- 轨道主要测到 GM 而非 G、M 分别；仅使用 GM 存在重参数化退化。
- 仅 c、ħ 与无量纲角度不能构造 G 的质量、长度和时间量纲。

## 条件成立（需指出附加固定条件）
- Z 恒定时，在思想实验中 G∝c⁻¹。
- r_g 与 M 恒定时，G∝c²。
- ℓP 与 ħ 恒定时，G∝c³。
- 标量张量模型可产生有效可变引力耦合，但必须给出标量方程与实验约束。

## 本轮判定不支持
- 若 Z 在 SI 中等于精确 0.01，则与 CODATA G 约差 20.12 个标准不确定度。
- 电子或质子的引力半径等于其约化康普顿波长（并不成立）。
- Z 与 Z′=c/(8πε₀) 在 SI 中可以直接相加（量纲不同）。

## 尚未证明

- 从内部光速螺旋公设计算普适的 G。
- 从变化电磁场的变化率独立确定 G。
- 不含新增自由参数地推导全部规范群、粒子质量和量子引力。
