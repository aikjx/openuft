--------------------------------------------------------------------------------
E360  度规与壁 (定义层)
--------------------------------------------------------------------------------
  ds^2 = -A(r) dt^2 + B(r)^-1 dr^2 + r^2 dOmega^2,  M=1
  A = exp(-2/r)
  B = exp(+2/r) (1 + c_m/r^2 + d/r^3)
  壁 (B=0, 度规退化处):  1 + c_m/r_h^2 + d/r_h^3 = 0  <=>  r_h^3 + c_m r_h + d = 0
  无 d 时 r_h = sqrt(-c_m):  c_m=-0.50 -> r_h=0.70711 M;  c_m=-0.29,d=-0.05 -> r_h=0.60990 M

--------------------------------------------------------------------------------
E361  乌龟坐标 & RW 主方程
--------------------------------------------------------------------------------
  dr*/dr = sqrt(B/A) = exp(+2/r) sqrt(1 + c_m/r^2 + d/r^3)
  壁处 B->0 => dr*/dr ~ sqrt(r-r_h) -> 0, r*_h 有限 (可积, 正则点).
  RW 主方程 (l=2, s=-2 主势沿用本线约定):
      psi_{,r*r*} + [ omega^2 - V(r) ] psi = 0,   V(r) = A l(l+1)/r^2 = 6 e^{-2/r}/r^2
  势垒峰 dV/dr=0 -> r=1, Vmax = 6 e^{-2} = 0.81203  (与 c_m 无关).

--------------------------------------------------------------------------------
E362  外边界 (无穷远纯出射, 解析)
--------------------------------------------------------------------------------
  r*->+inf: V->0, psi ~ A_out e^{+ i omega r*} (纯出射, 无入射支 e^{-i omega r*}).
  对数导数:  psi_{,r*}/psi |_{inf} = + i omega.

--------------------------------------------------------------------------------
E363  内壁 Neumann (公设 W1)
--------------------------------------------------------------------------------
  公设 W1: 量子引力壁理想反射, |R|=1. 主边界 (Neumann):
      psi_{,r*} |_{r*=r*_h} = 0  (波腹, R=+1, phi_R=0).
  壁面 r* 正则, Neumann 取 psi(r*_h)=1, psi_{,r*}(r*_h)=0.

--------------------------------------------------------------------------------
E364  为何指数度规无闭合 Schwarzschild 型三项连分数 (诚实声明)
--------------------------------------------------------------------------------
  GR Leaver 闭合于 z=1-2/r: 因 Schwarzschild f=1-2/r 是 z 的一次式,
  提取 e^{-i w r*} 与两端 Frobenius 幂后, 残差 ODE 系数是 z 的多项式 -> 三项递推.
  TUFT 度规 A=e^{-2/r}, B=e^{2/r}(...) 含 e^{-2(1-z)/r_h}, e^{4(1-z)/r_h} 指数因子,
  提取出射因子后残差 ODE 系数仍是 z 的整函数 (无穷泰勒阶), 不闭合为有限三项式.
  故 TUFT 'Leaver' 推广 = 解析级数/连续分数的数值实现:
  (a) GR 门用闭合三项连分数 (解析, 无盒);
  (b) TUFT 壁因 r*_h 正则, 用'无穷远精确出射 -> 向内积分 -> 壁 Neumann 归零',
      残差 F(w)=psi_{,r*}(r*_h)/psi(r*_h); 有限 s_out 误差按 Richardson 外推到 inf.
