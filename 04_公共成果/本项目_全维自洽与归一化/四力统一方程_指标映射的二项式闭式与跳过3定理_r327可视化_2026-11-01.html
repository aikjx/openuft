定理 C（二项式闭式 · 核心）　nR(q) = C(q + (n−1)/2, n)，精确恒等。证明：Â = td·e−c₁/2，log td = Σm (log T)mPm，由幂和引理 Pm = (n+1)Hm 得 td ≡ T(H)n+1，再由 Todd–Hirzebruch 得二项式。
定理 C′（它就是 Riemann–Roch）　nR(q) = χ(O(q − (n+1)/2))，用完全不碰示性类的层上同调维数公式核过 150 组，失配 0 ⇒ 二项式不是巧合，是 RR 在 CPn 上的显式形式。
定理 D（FW 移位 = 上指标整数化）　x = q + (n−1)/2 ∈ Z ⟺ q 在 Freed–Witten 格上（n 奇：Z；n 偶：Z+1/2）—— r325 的「格」与本卷的「二项式」是同一结构的两个面。
定理 E（跳过 3）　nR = 3 有格点解 ⟺ n ∈ {1, 2}；四个支点覆盖全部整数 x，无扫描上界 ⇒ 这是定理，不是「扫到 60 没找到」。
定理 F/G（3 vs 4）　n = 2 可实现 N ⟺ N 是三角形数；3 = T₂ ⇒ CP² 给得出三代，4 不是 ⇒ 四代需 CP³。

图 1 · 闭式：nR(q) = C(q+(n−1)/2, n)，只有 n=1,2 碰到 3

横轴 q，纵轴 nR。虚线 = nR = 3。蓝 n=1（nR=q，恒等映射，零信息）在 q=3 处命中；绿 n=2（三角形数）在 q=±5/2 处命中两次；橙/红/紫 n=3,4,5 整条曲线都不碰虚线 —— 因为它们的取值只有 0 或 ≥ n+1 ≥ 4。

图 2 · 定理 D 的 2×2 列联表：格与 x 整数性是同一件事

每个点 = 一个 (n, q) 对（n=1..12，每 n 取 25 个 q，共 300 对）。左块 150 个全在 FW 格上 ⇒ 全部给整数 x；右块 150 个离格 ⇒ 全部给非整数 x。零例外，两个方向都查了。
这张表背后是一次真实的失败。初版的格判据写成「q ∈ Z 且 q ∈ Z+shift」，对偶数 n 恒假 ⇒ 实际只数到 78 对，却仍然「通过」了一条写死 exp = 300 的条目。表没做，洞就在。改成 2×2 之后，两个方向（格太宽 / 格太窄）都被覆盖。

图 3 · 定理 E 的证明结构：四个支点覆盖全部整数 x

以 n = 4 为例（其余 n ≥ 3 同构）。① x ≥ n+1：C ≥ n+1 ≥ 4（严格递增 + 端点跳跃）；② x = n：C = 1；③ 0 ≤ x ≤ n−1：C = 0；④ x < 0：|C| = C(n−x−1, n)，x=−1 给 1、x ≤ −2 给 ≥ n+1 ≥ 4，符号 (−1)n。四段并起来就是整条整数轴 ⇒ 不需要任何扫描上界。

图 4 · 可实现的族数 = 二项式系数，3 是三角形数、4 不是

每一行是一个 CPn 能实现的前 6 个族数。绿 = 3（三代），红 = 4（四代）。n=1 行全绿 —— 因为 C(x,1)=x，任何数都能「实现」，这是恒等映射、零信息，必须显式标出。n=2 行恰是三角形数，3 在里面、4 不在；n=3 行才有 4。这就是「三代比四代便宜一维」的全部内容。
读者最容易误读的一点：本卷证明了「n ≥ 3 给不出 3」，没有证明「所以必须给 3」。中间差一步（S5：一条不引用 N 的选 3 机制），而这一步仍然空着。定价里最硬的一条正是 S5 ∧ S6 = 0 —— 「真能选出 3」与「用三角形数解释」互斥，因为三角形数表 1, 3, 6, 10, … 里 3 与 6 并列，它解释不了凭什么单单是 3。
