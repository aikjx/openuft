# 弦论-LQG 统一

> 寻找弦论与圈量子引力这两条主要量子引力路线的统一或互补框架。

## 问题定义

弦论与圈量子引力（LQG）是量子引力的两大主流路线，但出发点截然不同：
- **弦论**：高维、微扰、含物质、背景依赖
- **LQG**：4维、非微扰、纯引力、背景无关

统一目标：建立一个既包含弦论的物质统一性，又包含 LQG 的背景无关量子几何的框架。

## 当前进展（2020–2026）

| 方向 | 进展 |
|---|---|
| 弦场论 | 非微扰弦论的尝试，进展缓慢 |
| 矩阵理论 | M 理论的矩阵模型（BFSS），与 LQG 的自旋泡沫有形式相似 |
| 全息原理 | 弦论的 AdS/CFT 与 LQG 的全息熵计算有交叉 |
| 自旋泡沫与弦网 | tensor network 框架可能统一离散几何与弦世界面 |
| 统一方案 | 无公认统一框架；两者在数学结构上仍有根本差异 |

**核心障碍**：
- 弦论需固定背景，LQG 背景无关
- 弦论高维（10/11D），LQG 4D
- 弦论含物质，LQG 纯引力
- 量子化方法根本不同

## 证伪条件

- 若弦论预言（如超对称粒子）被排除，则弦论路线受压
- 若 LQG 预言（如面积量子）被观测，则 LQG 路线获得支持
- 若发现统一框架的数学自洽性证据，则统一路线获得支持
