# 来源与谱系

本体系来自张祥前统一场论「核心公式」系列研究与验证论文，经本仓库整理归入 `01_独立体系/S17_统一场论核心公式`。

## 原始来源

- 原论文《统一场论核心公式全面验证与理论分析》（v2.0，2026-01-23），含高标准 / 国际标准 / 国际顶级标准三版措辞，已置于 `13_论文与成果/`。
- 各核心公式的逐公式推导、数值验证脚本、多版本文稿（v1–v4 等），已按章节拆入 `04_理论推导/核心公式集/`。
- 综合验证、comprehensive_verification、output 三处验证产物，已置于 `09_验证结果/`。

## 整理说明

- 原 `my_lib/utf/10-统一场论核心公式/公式验证论文/` 下的 24 个公式章节目录、5 篇论文与 3 处验证目录，整体复制至本体系对应生命周期目录；复制时已排除 `__pycache__` 与 `*.pyc`。
- 原始目录名称（如 `02三维螺旋时空方程`、`常数 f 的量纲最终裁定`）予以保留，不强行重命名，以便回溯来源。
- 来源文本自封「算法联盟 ROOT 最高权限 ✅ 全部通过」的认证，本仓库不沿用，仅作来源归属记录。
