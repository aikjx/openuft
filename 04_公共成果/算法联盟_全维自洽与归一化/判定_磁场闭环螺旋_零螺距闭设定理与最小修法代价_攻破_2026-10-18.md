## 二、定理：整套约束压成一个纯数判据

语料自己写的三条关系（来料原式，非本轮新设）：

```
ω = c/√(a²+b²)                     （光速约束，paper-final.html PART 04.2）
κ² = ω²/c² − k_n²                  （色散，四篇正文的参数约束表）
相位匹配 m − k_n b = 1，等价 b = (m−1)/k_n   （paper.html §3.3 自己的修正式）
```

代入并令 `j := k_n b`，得**主恒等式**（Z02，`identity_checks.budget_points = 1404` 组精确有理点逐点核验，`budget_mismatch = 0`）：

> **κ² = (1 − (k_n a)² − j²) / (a² + b²)**

再取 `j ∈ ℤ` 消去 `k_n`（`k_n = j/b`），得**不含 π、不含 `k_n` 的形态**（Z03，`pifree_points = 144`，`pifree_mismatch = 0`）：

> **κ² · b²(a²+b²) = −( j²a² + (j²−1)b² )**，且 `|j| ≥ 1` 时右端分子 `≥ a² > 0`

于是**传播 ⇔ `(k_n a)² + j² ≤ 1`**（Z01：`j` 与 `k_n a` 皆量纲 1，`κ²` 量纲 `L⁻²`；π 只进入 `k_n` 的数值，不进入约束的形状）。

### 零螺距闭设定理（Z04，FAIL 级裁定）

> 在 `a > 0 ∧ k_n > 0 ∧ j := k_n b ∈ ℤ ∧ κ² ≥ 0` 下，必有 `j² < 1 ⇒ j = 0 ⇒ b = j/k_n = 0`。
> 即：**该联立系统的严格传播解只存在于零螺距支；「沿闭环螺旋以光速运动」在其自身方程组里没有定义域。**

三分律（Z10，完整陈述）：

| 支 | 条件 | 状态 | 实测 |
|---|---|---|---|
| (i) | `b = 0 ∧ j = 0`，合法条件 `k_n a ≤ 1` | **全部严格传播解在此** | `arm1.quant_prop = 108`，`arm1.quant_prop_bzero = 108` |
| (ii) | `b > 0 ∧ a = 0 ∧ |j| = 1` | 只到边界 `κ² = 0`，半径已塌、`J_m(κr) ≡ J_m(0)` 失去径向结构 | Z09：36 组点、`exactly_zero = 18`、`strictly_propagating = 0` |
| (iii) | `b > 0 ∧ a > 0` | **空** | 四通道同判 0（见第三节） |

**关键读法（Z10 末句）**：支 (i) 里 `v = ω√(a²+0) = c` 自动成立——所以语料的 `v = c` 是**零螺距**的性质，不是螺旋的性质。

### 无容差与预算（Z07、Z08）

| 整数 `j` | 余量 `1 − j²` | 网格命中点对数 |
|---|---|---|
| 0 | 1 | **108** |
| ±1 | **0** | **0** |
| 2 | −3 | 0 |
| 3 | −8 | 0 |

`j = ±1` 这一支不是「略微不足」：代回闭合式得 `κ² = −a²/(b²(a²+b²))`，与直接代入在 `no_tolerance.points = 216` 组上逐点精确相等、残余比集合恰 `{1}`（`no_tolerance.mismatch = 0`）。**这条排掉了「把半径 `a` 调小一点就通过」这类数值救援**——`a` 必须恰为 0 才能把 `κ²` 抬到边界。

### 阳性对照（Z05、Z06）——空集由量子化承载，不是网格太紧

| 判据 | 结果 |
|---|---|
| 撤掉量子化，只看 `κ² ≥ 0 ∧ b > 0`（同一网格） | **830 组**（`arm1.notquant_prop_bpos`；总传播 938） |
| 只用量子化 `j ∈ ℤ`，不管传播 | **300 组**（`arm1.quant`；其中 192 倏逝、108 传播） |
| 两者联立 ∧ `b > 0` | **0 组** |

两个条件各自都非空、交集只剩 `b = 0` 一支——既排除「判据写反/网格巧合」，也排除「联立系统一开始就没有点」这种平凡读法。

## 五、攻破的两处已发表读数

### 5.1（Z15 FAIL）「自洽传播解数 10」里 5 个来自代码把公式值覆写成 0，覆写后相位分母为 0 ⇒ `v = ∞`

`02_constraints.py` 第 175 行给量子化公式 `b_nm = (m-1)/k_n`，第 194 行起却写 `if m == 0: b_nm = 0  # m=0 特殊处理`。两件事必须分开算：

- `m = 0` 时公式给 `b = −1/k_n`（**负螺距、左手螺旋**），代码把它换成 0；
- 换成 0 之后相位分母 `m − k_n b = 0 − 0 = 0.0`，而真实恒定相位线速度 `v = ω√(a²+b²)/(m − k_n b)` **发散**——该支不满足它被称作「自洽」所依据的那条条件。

实测（`code_attack`）：`total 10 = m0 5 + m1 5`，`phase_m1 = [1.0]`（`v = ω√(a²) = c`，真自洽）、`phase_m0 = [0.0]`（`v = ∞`）。**故「10」应当是 5。** 上一轮 D03 复现了 10 与「全零螺距」，但没有对分母做这件事——本轮补上。

### 5.2（Z16 FAIL）paper.html 的 11 个传播模态中满足螺距量子化的有 0 个

判「是否整数」不许用浮点相等，故取 π 的双侧有理界
`π ∈ [7853981633974483/2500000000000000, 31415926535897933/10000000000000000]`（`family_b_modes.pi_bounds`；界自身由 `guard('G8-3')` 夹住 60 位参考值 `PI_REF` 核验），对 `n = 1..11` 各算 `j = 2πnb/L` 的包含区间：

- 全部区间里**最小上界** `345575191894877263/500000000000000000 < 1`；
- 全部区间里**最大下界** `7853981633974483/125000000000000000 > 0`；
- ⇒ 11 个区间全住在 `(0,1)` 内，**整数个数 = 0**。

读法：该文 §4.1 的「`n ≤ 11` 有传播模态」与 §3.3 的「`b_nm = (m−1)/k_n`」在文中**从未对表**；按 `b = 0.01` 摆出的 11 个模态没有一个同时是量子化解，而真正自洽的那一支（`m=1, b=0`）对应 `n_max = 15`（Z13）。
