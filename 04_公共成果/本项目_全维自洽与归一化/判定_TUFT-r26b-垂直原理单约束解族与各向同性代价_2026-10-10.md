## 一、本册为什么只做一件事：把 A 项从「族内不可能」推进到「构造存在 + 代价」

来料把 BOUNDARY 项写成「**场量 κ、τ 在空间上的梯度正交 ∇κ·∇τ = 0 未验证**」，并在末尾把选项 A 定为「解析推导 ∇κ⊥∇τ，解决 BOUNDARY 项」。

此前三册 + r25 对 A 的既有读数是：

- r22 **C09**：`∇κ·∇τ=0` 是**一个**标量方程；把它当成「∇ρ·∇b=0 **且** |∇ρ|=|∇b|」两条 ⇒ 过约束 1 维。
- r22 **C10**：在来料自设的**径向汤川解 + 双质量 + 球对称统一势**三条前提下，三者不可同时成立。
- r25 **G01**：既有 A 项的「约束 ⟺ W=ρ+ib 全纯」是**过断言**（全纯是充分非必要条件）。
- r25 **G03/G04/G06**：径向族穷尽 ⇒ 非平凡径向解全不在约束空间内；全纯族 ⇒ κ,τ 调和 ⇒ 有质量场不可嵌入；**射程声明为「已覆盖三族，未覆盖一般 3D 非球对称非平面调和解」**。

**缺口就在那条射程声明上**：A 项究竟是「方程不允许」，还是「我们只会这三族解」？本册正面攻这一点，结论是——

> **单约束 ∇κ·∇τ=0 本身完全可满足，且两个场可以各自带不同的质量 μ_κ ≠ μ_τ ≠ 0；但任何这样的解必然放弃球对称或放弃点源，而 L3 的实证资产全在中心势上。**

于是 A 项的定性从「不可解」改写为「**可解，但按三选二的定价出售**」。

## 二、七条机器裁定

### J01（PASS）机器恒等式：单约束是 Q1、Q2 的一个线性组合

由 L1-7 对偶反演 `Ξ = κ+iτ = 1/W̄`（`W = ρ+ib`）的复导数 `λ = dΞ/dW̄ = −1/W̄²`，取实虚部：

```
A = (b²−ρ²)/D² ,  B = −2ρb/D²      （D = ρ²+b²）
dκ = A dρ + B db ,   dτ = B dρ − A db
⇒ ∇κ·∇τ = A·B·Q2 + (B²−A²)·Q1 ,   Q1 = ∇ρ·∇b ,  Q2 = |∇ρ|²−|∇b|²
```

四个测试场（两组随机多项式 + 全纯 `e^z` + 平面反例 ρ=x,b=z）× 4 点，差分与解析式一致到 **2.32E−10**（自然归一化尺度 |λ|²·|∇ρ|²）。
**意义**：r22 C09 的「过约束 1 维」从**计数论证**升级为**可复算的结构恒等式** —— 约束是 Q1、Q2 的一条**随点变系数**的线性组合，不是二者同时为零。

### J02（MISMATCH）显式反例：Q1、Q2 各自显著非零，而单约束精确成立

构造（详见 J03）：`κ = cos(kx)e^{−az}`（a=√(μ_κ²+k²)）、`τ = e^{−μ_τ y}`，反演回位形场 `ρ = κ/(κ²+τ²)`、`b = τ/(κ²+τ²)`。

| 读数 | 值 |
|---|---|
| ∇κ·∇τ 相对残差 | **0.00E+00**（精确：∂yκ≡0 且 ∇τ∥ŷ） |
| max\|Q1\|/scale、max\|Q2\|/scale | **9.07E−01**（各自显著非零） |

**意义**：来料正文与既有 A 项把 BOUNDARY 写成两条约束，在此获得**构造性证明**（不是仅计数），且证明方向是「双条件 ⊊ 单约束」。

### J03（PASS）存在性：单约束 + 两个不同质量的可解构造

| 读数 | 值 |
|---|---|
| μ_κ = 1，μ_τ = 2.5，k = 2，a = √(μ_κ²+k²) = 2.2360679775 | |
| `(∇²−μ²)` 方程最大相对残差（两场） | **1.65E−07**（差分精度） |
| ∇κ·∇τ 相对残差 | **0.00E+00** |

**意义（订正既有定性）**：r25 G04/G06 的「有质量场不可能嵌入」是**解族依赖**的（全纯族 / 平面调和反例族 / 球对称族），**不是原理性的**。本册不推翻其「A 不可作修复方案」的结论，**只取消其「原理性不可能」的定性**。

### J04（PASS）该构造确实落在 L1 结构内

对偶反演是**对合**：把构造出的 (κ,τ) 反演为 (ρ,b) 再正演回来，往返相对残差 **2.17E−16**。
**意义**：不是「拿外部标量场作弊」，它是该框架自己 L1 结构内的合法位形 ⇒ 存在性结论不打折。

### J05（FAIL，代价一）局域性定理：这样的解不可能是点粒子场

φ 乘方程后分部积分：`∫|∇φ|² + μ²∫φ² = ∮φ∂_nφ`；若无源、无奇点且全域衰减 ⇒ 右端 → 0 而左端两项皆 ≥0 ⇒ **φ≡0**。

| 读数 | 值 |
|---|---|
| 格林恒等式体积分 vs 边界积分（矩形域，401 点梯形） | 相对 **1.71E−04** |
| 本册构造沿 z→−5 的增长因子 | **7.17E+04**（τ 沿 y→−∞ 同理） |

**意义**：单约束 + 双质量的非零解**必然在某个方向增长** ⇒ 拿不到 δ 点源 ⇒ 拿不到任何 1/r 型势 ⇒ L3 的全部中心势还原失去载体。

### J06（FAIL，代价二）各向异性随半径爆炸

球对称中心势要求「同一半径上 |Ξ| 与其梯度为常数」（最大/最小 = 1）。构造解的实测偏离：

| R | \|Ξ\|max/min | \|∇\|Ξ\|\|max/min |
|---|---|---|
| 0.35 | **3.30E+00** | **4.27E+00** |
| 0.8 | **2.01E+01** | **2.95E+01** |
| 1.6 | **1.62E+03** | **8.16E+02** |
| 3.0 | **3.09E+05** | **2.85E+05** |

（上半球与全球并列给出，全球读数仅略高 ⇒ 半球口径是保守下界。）
［C］外部实验事实：库仑定律与牛顿引力的各向同性/平方反比在多尺度上有极强实验约束；本册只做结构层比值计量，不代引具体实验界。

### J07（BOUNDARY）三选二定理（三条腿均机器核实）

| 腿 | 机器读数 | 结论 |
|---|---|---|
| (i) 球对称 + 两个不同质量 | 两径向梯度夹角 **cos = 1.000000000000** | 单约束必破 |
| (ii) 球对称 + 单约束 | `∇κ·∇τ = κ'τ'` ⇒ 必有一场导数恒零 | 该场退化为无源常数场，第二个力消失 |
| (iii) 单约束 + 双质量 | 本册构造存在 | 但非球对称、非点源、各向异性（J05/J06） |

⇒ `{球对称中心势 U∝e^{−μr}/r}`、`{两个不同质量的有质量场}`、`{∇κ·∇τ=0}` **三选二，不可兼得**。

## 五、本册自抓 4 处（已修，留痕）

1. **`rel()` 误用（最严重）**：J03 首版写 `rel(∇²κ−μ²κ, μ²κ)`，第二个参数应是「应等于的值」而非残差基准 ⇒ 相对残差恒 ≈1.0。**守门 guard 用的是直算式因而照样全绿** ⇒ 条目数值错而自检全过。**教训复现（库内第 4 次）：条目数值与 guard 必须由同一表达式产出。**
2. **J01 归一化尺度错**：首版用 |lhs| 归一化，在全纯族（Q1=Q2=0 ⇒ rhs 因相消而 ≈0）上给假 NG（42.20）。改按恒等式自然量纲 |λ|²·|∇ρ|² 归一 ⇒ 2.32E−10。
3. **差分器对照组取错**：拉普拉斯对照组选了 Laplacian 恰为 0 的函数（除零 ⇒ 1.11E+292 假 NG），改 `x²+3y²−z²`（=6）。
4. **球对称腿代入真实质量导致下溢**：代入 μ(π⁰)、μ(W)（~1e14、~1e18）使 Yukawa 值下溢为 0 ⇒ ZeroDivisionError；改同单位无量纲质量（该腿结论是几何性质，与 μ 数值无关）。

## 六、诚实边界

- 本册结论限于「单约束 ∇κ·∇τ=0 的这一类构造 + 三条腿」，**不构成对一般三维非球对称解空间的穷尽**。
- J03–J06 是**存在性与代价**的判定，不是「框架被推翻」；框架在 L0/L1 的数学自洽性不受本册影响。
- 本册**不产生新物理**，也**不判断 QCD 本身**（禁闭是既定事实；本册只判它不能由该框架的特定方程结构内生）。
- ［C］外部实验事实只做登记，不代引具体数值界。
- 交叉印证：λ(π⁰)=1.4619325716596959E−15 m、λ(W)=2.4550179819898284E−18 m 与 r22/r23 读数一致（相对差 2.9E−07 / 2.5E−05）。
