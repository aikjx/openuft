# 引力非重整化突破

> 解决广义相对论作为量子场论不可重整化的问题，建立紫外完备的量子引力理论。

## 问题定义

广义相对论的 Einstein-Hilbert 作用量：

$$S_{\rm EH} = \frac{1}{16\pi G_N} \int d^4x \sqrt{-g} \, R$$

作为量子场论，引力耦合 $G_N$ 具有**质量量纲 $-2$**，导致微扰展开**不可重整化**——圈图发散需要无穷多个抵消项。

**突破方向**：
1. **渐近安全**：非高斯固定点使理论紫外完备（FRG 证据支持）
2. **弦论**：延展客体消除点粒子发散
3. **圈量子引力**：非微扰量子化，离散几何
4. **因果集/CDT**：离散时空正则化
5. **霍拉瓦引力**：破坏 Lorentz 对称换取可重整化

## 证伪条件

- 若引力波观测发现量子色散，则量子引力效应存在
- 若某方案预言被实验排除（如质子衰变排除 SU(5)），则该方案收窄
- 若长时间无量子引力信号，则所有方案均受压
