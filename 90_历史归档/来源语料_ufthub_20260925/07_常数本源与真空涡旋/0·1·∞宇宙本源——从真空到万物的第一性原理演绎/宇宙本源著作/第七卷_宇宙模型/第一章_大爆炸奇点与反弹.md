# 第一章 大爆炸奇点消解与宇宙反弹
## 1.1 大爆炸奇点问题
标准宇宙学中，宇宙从一个密度无限大、温度无限高的奇点爆炸产生，物理定律在奇点失效，这是广义相对论的必然结果，和黑洞奇点一样，是因为忽略了挠率。

在我们的有挠引力理论中，当宇宙密度达到普朗克密度时，挠率产生巨大的排斥力，阻止宇宙进一步坍缩，宇宙会从收缩相反弹到膨胀相，也就是大反弹，没有奇点，宇宙在反弹之前是收缩的，反弹后开始膨胀，我们的大爆炸就是这次反弹。

## 1.2 反弹宇宙学
宇宙的演化是循环的？不，因为有暗能量，宇宙永远膨胀，不会再收缩，所以这次反弹是唯一的？不对，暗能量是常数，宇宙永远加速膨胀，不会再坍缩，所以我们的宇宙是从一次反弹开始，然后永远膨胀，没有奇点，没有开端？不，反弹之前的宇宙是收缩的，收缩到普朗克密度反弹，然后膨胀，但是暗能量会让宇宙永远膨胀，不会再收缩，所以只有一次反弹。

反弹解决了奇点问题，宇宙没有无限密度的开端，所有物理定律在反弹时都成立，没有失效的地方。

## 1.3 本章小结
大爆炸奇点被挠率排斥力消解，宇宙从大反弹开始，没有奇点，物理定律在所有时间都成立。
