## 一、本卷统一散射方程（承 UFE-4F⁺ 同一势）

```
经典管线：m(d²r/dt²) = −∇U(r)，U = A·f(r)   →θ(b)→   dσ/dΩ = b/sinθ·|db/dθ|
量子管线：f(q) = −(2μ/(ħc)²q)·∫V(r)·sin(qr)·r·dr   →   dσ/dΩ = |f(q)|²，q = 2k·sin(θ/2)
库仑（两条管线同给）：dσ/dΩ = (A/4E)²·csc⁴(θ/2)          ← 经典=量子的著名巧合
Yukawa：f(q) ∝ A/(q²+m²)，m = 1/λ                        ← 力程在动量空间 = 传播子质量
弱：q≫1/λ_W 点粒子 / q≪1/λ_W 各向同性接触                ← λ_W 短到实验全在接触区
色：禁闭 ⇒ 无渐近色荷态 ⇒ 散射截面不可定义               ← 散射层的诚实表述
```

「求导证明 + 机器验证」的对应关系：解析式（csc⁴ 与 1/(q²+m²)）是**求导证明**；
RK4 直积分与振荡积分是**机器验证**；两者由守卫逐位钉死。

## 六、诚实边界

- **B1 库仑长程**：Born 积分发散，需屏蔽正则化（Yukawa λ→∞ 极限承担）；经典 θ(b) 的 1/L 远场截断尾由 Richardson 外推 2θ(2L)−θ(L) 解析消去（G2 验证标度比≈2）。
- **B2 色道**：本卷只登记「不可定义」，未给出强子道的有效截面模型。
- **B3 弱道**：标量 Yukawa 接触极限只复现量级口径，不复现 V−A 流结构（承 r221 U27 / r226 Q05）。
- **B4 非相对论**：E=5–10 MeV ≪ μ=469 MeV，Born 与经典轨道均为非相对论口径。
- **B5 数值方法**：G1 核心区残差 1.48e−5 = RK4（N=16 万步）+ Richardson 外推后的方法误差，非物理效应；dσ 差分用 121 点细网格（间隔 6.6%）压到 1.48e−3。
