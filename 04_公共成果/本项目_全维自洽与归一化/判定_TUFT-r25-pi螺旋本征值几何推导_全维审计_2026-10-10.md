## 一、五条核心裁定

### 裁定一（P0）：pi 并没有被「推导」出来——决定性反例是「同闭合条件、不同 C/r」

来料全部论证的承重句是：*先由公理与闭合条件求 `theta0`，再定义 `2*pi := theta0`，于是 `C=2*pi*r` 是推导结果而非前置公理。*

**B2 直接否证**：取同一族周期函数构建的邻近 ansatz `x = a*cos^3(u)`、`y = a*sin^3(u)`，它的闭合条件与来料**逐字相同**（`x(T)=x(0)` 且 `y(T)=y(0)` ⟺ `cos(u0)=1` 且 `sin(u0)=0` ⟹ 最小正解 `u0 = 2*pi`），但它的周长

- 机器值 `C = 6.000000000000060E+0 * a`（步长收敛残差 `3.186784E-12`）
- 而 `2*pi*a = 6.283185307179586E+0 * a`
- 比值 `C/(2*pi*a) = 9.549296585514E-1`（解析值 `3/pi`）

**闭合条件完全相同，两条轨迹给出不同的 C/r** ⇒ `C=2*pi*r` 不可能由闭合条件导出，它由**所选的函数族（圆的参数化）**决定。

**B1 补充**：`x=a*cos(u)`、`y=a*sin(u)` 恒满足 `x^2+y^2=a^2`（残差 `4.000000E-59`，且对任意 `u` 成立、与 `theta0` 数值无关）⇒ **圆在选择 cos/sin 作轨道函数的那一刻就已在场**。来料声称的「因果顺序反转」并未发生，被换掉的只是**命名次序**。

**A4 补充**：`pi` 对全部动力学参数 `(a, b, omega, v_z, c)` 严格不敏感——18 组网格（含 `b=0` 与量纲反常的 `c=1`）反解 `pi` 的最大偏差 `1.540769E-59` ⇒ 来料 §3.3「pi 的数值由空间运动的动力学约束决定」被机器直接否证：动力学参数可自由变动而 pi 不动。

**A1（保留）**：`2*pi := theta0` 作为 pi 的**定义**是合法的、无逻辑循环的等价定义（Newton 求根残差 `0E+0`）。但它是数学上已知的等价定义之一，不改变 pi 的任何数值内容，也不使 pi 成为物理量。

### 裁定二（P0）：螺旋前提在三处关键结论上被自身取消（隐式退化 `b → 0`）

| 位置 | 来料结论 | 成立条件 | 机器读数 |
| --- | --- | --- | --- |
| §5（C3） | `omega = c*kappa` | **仅当 `b=0`** | `b/a=0` 残差 `0E+0`；`b/a=0.05` → `1.247661E-3`；`b/a=1` → `2.928932E-1`；`b/a=10` → `9.004963E-1` |
| §8.2（B3） | 「找 `T>0` 使三维位置 `r(T)=r(0)`」 | **仅当 `b=0`** | `b=0.001` → 一周期后 `|z(T)-z(0)|=6.283185E-3 m`；`b=1` → `6.283185E+0 m` |
| §9（E1） | `lambda = s0 = 2*pi*r` | **仅当 `v_z=0`** | 比值恰为 `sqrt(1+(b/a)^2)`：`b/a=1` → `1.414213562373E+0`；`b/a=4` → `4.123105625618E+0` |

三处的失效因子都恰是 `lambda_helix/r` 或其倒数。**每逢需要得到一个具体结论，就必须回到 `b → 0`；而 `b → 0` 时 `tau ≡ 0`、螺旋坍缩为平面圆** ⇒ 来料的核心 claim「pi 不是平面专属常数，是闭合旋转轨道的本征谱元」在自己的三处关键推导中被取消前提。

**正确的不变量**（G1/M1，机器残差 `3.592595E-60`）：`omega = c*sqrt(kappa^2+tau^2)`，即本库主线已知的 `kappa^2+tau^2=(omega/c)^2`。来料的 `omega = c*kappa` 是**把该恒等式丢掉 tau 后**写成的新形式。

### 裁定三（P0）：`∮|Omega|ds = 2*pi*n` 是恒等式复读，且其一般性不成立

- **D1 零筛选力**：`|Omega| = 1/lambda` 与 `Delta_s = 2*pi*lambda` 两个定义的代数乘积。16 组 `(a,b)`（含 `b=0` 与极端轴径比）**全部精确成立**，与 `2*pi` 最大偏差 `1.000000E-59`，且 `n` 恒为 1、不随参数变化 ⇒ 它不选中任何东西，**不是量子化条件**。（恒等式复读缺陷族复发）
- **D2 一般性被定量否证**：光滑简单闭合（带深凹）曲线 `rho(t)=1-0.8*exp(-(t-pi)^2/(2*0.5^2))` 的极坐标轨道，`∮|kappa|ds = 1.011050404370693E+1 rad`，相对 `2*pi` 偏差 `6.091367E-1`、相对 `4*pi` 偏差 `1.954317E-1`；`psi'` 变号 2 次（切向角非单调）；两条独立离散化互校差 `2.255877E-8`，切向角全变差 `1.011050403618737E+1`；`rho_min = 0.2 > 0`（确为简单闭合），端点周期残差 `0E+0`。真命题是 **Fenchel 定理**（`∮|kappa|ds >= 2*pi`，等号当且仅当凸平面曲线），**上界不存在、取值连续** ⇒ 不存在 `2*pi` 的整数量子化。
- **D3 方法层自由度**：「一周总转动」有两种同样自然的读法：Darboux 模长恒给 `6.283185307180E+0`，切向 indicatrix 读数在 `b/a=1` 时给 `4.442882938158E+0`、`b/a=3` 时给 `1.986917653159E+0` ⇒ 只有选 Darboux 模长才恒等于 `2*pi`。量的选择被调参到想要的结果，须显式登记而不能作为证据。

### 裁定四（P0）：两处量纲硬缺陷

- **C2**：`kappa = c_perp/c^2`。量纲层 `[c_perp/c^2] = L^-1*T` vs `[kappa] = L^-1` ⇒ **多出一个时间量纲**；数值层 `a=b=1` 时来料式 `2.358654336750E-9` vs 正确式 `5.000000000000E-1`，比值 `4.717308673499E-9 s`（恰为 `lambda/c`）。最小修复：右端补一个 `omega`（M2：`kappa = c_perp*omega/c^2`、`tau = c_parallel*omega/c^2`，残差 `6.290000E-59`）。这是典型的「单位约定未登记」型缺陷——隐含要求 `lambda = c` 的数值。
- **F1**：`h = 2*pi*c^3*r_e/G`。量纲层 `[c^3*r_e/G] = M*L*T^-1`（**动量**）vs `[h] = M*L^2*T^-1`（作用量）⇒ 差一个长度。数值层 `c^3*r_e/G = 1.137596316635E+21`，得上式后比 `h` 大 `1.716849189462E+54` 倍；即便按最小补维（再乘一个长度）`c^3*r_e^2/G = 3.205678535581E+6 J*s`，仍大 `4.837978564989E+39` 倍。**双重 FAIL**，不得作为「普朗克常数几何导出」的证据。
- **C4 跨章口径冲突（MISMATCH）**：同一物理量，§5 读出 `2.358654336750E-9`、§7 读出 `5.000000000000E-1`，相差 `4.717308673499E-9`（`lambda/c`）。若两章被分别引用，读数差约 9 个量级。

### 裁定五（P1）：「已数值验证」不可复现；`E = hbar*omega` 是代数重排

- **A3**：来料第五章的输出样例（`theta0=6.283185307179586` / `pi=3.141592653589793`）**无法由其自身代码产生**——网格最近点残差 `3.071796E-7` 远大于容差 `1e-12`；前 3000 圈内最佳网格残差 `1.936300E-10`（第 1950 圈）仍 `>1e-12`；若按漂移后的第 `k` 圈返回 `theta`，则 `pi=theta/2` 得到的是 `k*pi` 而非 `pi`；只看 cos 条件则 `n=1` 处 `|cos(h)-1| = 5.000000E-13 < 1e-12`，首步即返回 `pi ≈ 5e-7`。**根因（A2）**：两条件不独立——`cos-1` 在该点是二重根（`|d(cos-1)/dtheta| = 0E+0`），故用 `|cos-1|<eps` 判根精度只能到 `sqrt(eps)`；要判出 15 位 pi 需 `eps ≈ 5.000000E-31`，而 IEEE double 在 1 附近 `ulp = 2.220446E-16` ⇒ **双精度下不可达**。
- **E2**：`E=hbar*omega` 是 `{E=pc, p=h/lambda, omega=2*pi*c/lambda, hbar=h/(2*pi)}` 的纯代数重排（残差 `5.034117E-60`）。链条中唯一来自螺旋的项 `lambda = 2*pi*c/omega` 正是 `lambda = s0` 的同义改写。**真输入是两条**：沿轨迹 `E=pc` 与德布罗意关系 `p=h/lambda`——两者皆非本框架推导所得。
