# ROOT V93｜从内向外、从外向内的螺旋闭环：几何定理、动力学逆问题与统一场论审计

版本：2026-11-18；性质：数学定理 + 条件模型 + 高精度理论计算 + 反例与开放问题。**不是新物理发现，不是完整统一场论的证明。**

## 摘要

将此前 V92 无限延伸的圆柱螺旋改为在欧氏三维空间真正闭合的环面螺旋。选取环面大半径 R、小半径 a，以及两个无量纲整数绕行数 m,n。推导内/外半径、空间闭合、原始周期、速度归一化、变频、曲率与挠率、力的反演以及匀强磁场下 Wilson 环路积分。独立实施 SymPy 检查、85 位高精度积分、时间重参数化、随机扰动和广泛量纲对碰。对于 R=10 mm、a=2 mm、m=2、n=3 的模型，长度 0.1312986594444883 m、总曲率 13.03204942973894 > 4π，静止实验室三维速度设 v=0.8c 时一周需 5.47456481729138e-10 s。虽然任何这样的正则闭曲线可以用 v=c 数学重参数化，但这**不意味着带静质量粒子能以光速运动，也不意味着真空自由光子的世界线是闭合螺旋**。

## 1. V92 至 V93：改变了什么

V92 的圆柱螺旋 `r=(R cos ωt,R sin ωt,pt)`，当 p≠0 时 z=pt 单调，空间轨迹不闭合。它满足 `κ=Rω²/v²` 和 `τ=pω/v²`，这些是常速圆柱螺旋恒等式。新模型改变了**曲线几何**，不能将 V92 常曲率/常挠率的闭合恒等式直接套用到新曲线。这里“闭环”仅指**三维空间位置、切线和高阶曲线导数回到初态**，不意味着四维世界线回到同一时空事件，也不意味着能量或力产生了永动式闭环。

## 2. 环面螺旋公设（数学模型，非自然定律）

给定 R>a>0、整数 m,n>0，参数 u∈R，定义

```
ρ(u)=R+a cos(nu), θ(u)=mu, z(u)=a sin(nu)
r(u)=(ρ cos θ,ρ sin θ,z)
```

立即有 `(ρ−R)²+z²=a²`。空间轨迹始终在环面上；最大/最小柱半径为 R±a；如果 `m,n` 互素，u 从 0 到 2π 完成 m 次主轴绕行及 n 次管截面绕行，构成标准的 T(m,n) 环面结；若 `g=gcd(m,n)>1`，最短回归相位为 `U=2π/g`，只沿原始 T(m/g,n/g) 分支完成一次，不应将“完整参数影像”误称为 g 条不同的环面链环（该链环需要另外给出不同相位的 g 条曲线）。当 m,n 互素且都大于 1，例如 (2,3)，为非平凡三叶结。曲线无自交，因为环面坐标 (θ,nu) 在一个原始周期上的同时相同当且仅当 u 差为整数周期。

### 定理 A：充要闭合条件（对于指定非退化参数化）

取正实数 m,n（先不强制为整数）。存在 U>0 使 r(u+U)=r(u) 及其各阶导数同时成立，当且仅当 mU,nU 都属于 2πZ，即 m/n∈Q。对于 m,n 正整数，最短正周期 U=2π/gcd(m,n)。证明：`R>a>0` 使柱面角坐标唯一；闭合同时要求主轴和管截面相位返回。反向代入三角周期即可。注意：如果参数不是周期变化、轴向坐标一直单调，不能发生欧氏三维闭合。

## 3. 严格速度分解、频率、内外调制

令带撇表示 d/du，则

```
r'(u)=ρ' e_ρ+mρ e_θ+z' e_z
ρ'=-an sin(nu), z'=an cos(nu)
σ²=|r'|²=(an)²+m²ρ²>0.
```

弧长微分 ds=σdu。对于指定**常数空间速度** v0（数学上可选 0<v0≤c，真实有静质量粒子必须 v0<c），定义

```
dt/du=σ(u)/v0>0,   du/dt=v0/σ(u)
Ω_θ=dθ/dt=m v0/σ(u)
v_ρ=−an sin(nu) v0/σ(u)
v_θ=mρ v0/σ(u)
v_z=an cos(nu) v0/σ(u)
```

所以 `v_ρ²+v_θ²+v_z²=v0²` 是恒等式，不是额外动力学定律。内侧 ρ=R−a 的 σ 比外侧 ρ=R+a 小，因而保持总速时内侧角速度大、外侧角速度小：

```
Ω_inner/Ω_outer = sqrt[(an)²+m²(R+a)²]/sqrt[(an)²+m²(R−a)²].
```

此等式同样不表明内向运动必有引力或与四力本源相关。**非退化时不可能同时令 du/dt 为常数而 v0 恒定**：σ² 含非常数的 cos(nu)，所以必须调制角速度。若 β=1，则回归周期 `T=(1/c)∫_0^Uσdu`；对一个有静质量粒子则 `T=(1/βc)∫_0^Uσdu`，β<1。

## 4. 曲率、挠率与完整求导

取柱坐标正交基 `(e_ρ,e_θ,e_z)`，记 C=cos(nu), S=sin(nu), ρ=R+aC，三阶导数在该基中的分量：

```
r'  = ( −an S, mρ, an C)
r'' = ( −an² C−m²ρ, −2amn S, −an² S)
r'''= ( an(n²+3m²)S, −3amn²C−m³ρ, −an³C)
```

叉积 Q=r'×r'' 的三个分量：

```
Q_ρ=am n² S(aC−R)
Q_θ=−an(an²+m²ρC)
Q_z=m[2a²n² S²+an²ρC+m²ρ²]
```

定义 `D=Q_ρ²+Q_θ²+Q_z²`。在 D>0 的正则曲线点，

```
κ(u)=sqrt(D)/σ(u)³
τ(u)=[Q·r''']/D
```

重要：本模型 κ 和 τ 通常随 u 改变，不能拿 V92 的 `|ω|=v sqrt(κ²+τ²)` 当做普遍恒等式。κ=0 时 Frenet 挠率的上述公式失效，必须分段处理；本包选用的数值基准 κ 始终严格为正。

## 5. 内外闭环力学的必要外力，而不是四力本源

由 `v=v0 r'/σ`、`du/dt=v0/σ`，严格求导得

```
a_vec = v0² [r''/σ² − r'(r'·r'')/σ⁴],
v·a=0, |a|=v0² κ.
```

对于静质量 m0、0<β=v0/c<1 的粒子，动量 `p=γm0v`，因 v0 常数有

```
F_3=γm0 a_vec,   |F_3|=γm0 v0² κ.
```

这给出了**已知轨迹反求所需合力**，没有唯一决定产生它的是电磁力、机械导轨、引力还是其他受约束机制。

### 定理 E：空间闭合产生周期性动量而非自生动力

设空间曲线正则、时间参数化周期 T 且速度周期重复，m0、β 保持不变。则三维动量 `p=γm0 v` 周期一致，精确有 `∫_0^T Fdt=p(T)−p(0)=0`；并且从 `|v|=常数` 可得 `F·v=0`，因此 `∮F·dr=0`。这**绝不**推出各时刻 F=0，也不保证设备无需维持约束磁场、阻尼、辐射或外部能量。数值对三维加速度积分所得净冲量除以 βc 的相对残差约 9.1×10⁻¹⁵。这是对已经指定的周期动力学模型的积分恒等式。
若粒子电荷为 q≠0，沿轨迹可形式上取局部理想磁场

```
B_required(u) = [γm0/(q v0²)] a_vec × v_vec,
|B_required| = γm0 v0 κ/|q|.
```

因为 `v×(a×v)=v0² a`，这个表达式满足 `q v×B_required=γm0 a`。但**沿路径给出 B 并不构成在整个空间满足 ∇·B=0、Maxwell 方程、边界约束、控制稳定性的全球电磁装置设计**。实际磁场在闭环中的构造仍开放。磁场不做功，常速仍需要初始动能及维持场的设备；不能由轨迹闭合推断“力闭合产生自由能”。在 β→1 且 m0>0 的极限 γ→∞，合力不再有限。

## 6. 匀强磁场环路相位的封闭解析式

对沿 z 方向均匀磁场 B_z，在对称规范中 `A=(B_zρ/2)e_θ`，闭合路径的环路积分为

```
∮A·dr = (B_z m/2)∫_0^U (R+a cos nu)²du
       = πB_z(m/g)(R²+a²/2), g=gcd(m,n).
```

这一结果在**固定 m/g,R,a** 时不依赖具体 n。这是常规 Stokes 定理及理想 AB 干涉几何的应用，不是新电磁定律。带电波函数可能获得闭合回路相位 `φ_AB=(q/ħ)∮A·dl`，但可测干涉还需要至少两条相干路径、动力学相位控制、磁场穿透/分布等实验条件。曲率和挠率不同的两条闭合曲线可以拥有相同磁环路积分。因此“曲率、挠率决定全部作用力或全部量子相位”不成立。没有附加单值性/凝聚态条件时，闭合路径**本身并不强制磁通量量子化**。

## 7. 闭环、缠绕数、总曲率与总挠率不是同一概念

- 空间几何闭合：r(U)=r(0)，可直接证明。
- 切向/曲率等周期性：对正则解析曲线同样成立。
- 节点拓扑：互素 m,n>1 时 T(m,n) 为非平凡结，不能仅由数值角频率描述。
- 总曲率：`K=∫κds`，闭合曲线满足 Fenchel `K≥2π`，非平凡结满足 Fáry–Milnor `K>4π`（已知数学定理）。本次数值基准 K≈13.03204943，超过 4π≈12.56637。
- 有向总挠率：`∫τds` 一般不是整数，也不代表无条件的拓扑量子数；本次基准 ≈0.499003673。
- 四维因果闭合：在 Minkowski 中 t(U)>t(0)；三维闭合**不是**“回到同一时空事件”，并不构成闭合类时曲线。

## 9. 量纲全面审计

SI 基础量纲向量 `[M,L,T,I]`；`[κ]=[τ]=L⁻¹, [Ω]=T⁻¹, [a]=LT⁻², [v]=LT⁻¹, [F]=MLT⁻², [B]=MT⁻²I⁻¹, [Φ_B]=ML²T⁻²I⁻¹, [ħ]=ML²T⁻¹, [q]=IT`。

本包逐一枚举 40 个物理量的 780 对两两同量纲关系，及 32 条候选等式，其中 8 条**直接量纲不匹配**；其它量纲相同的等式也不能仅凭量纲判定动力学正确。

特别地 `[G]=M⁻¹L³T⁻²`，而 `[c,κ,τ,Ω]` 无任何质量量纲，所以不存在不带额外质量/作用量输入的幂乘表达 `G=f(c,κ,τ,Ω)`。允许形式如 `G∝c³/(ħκ_*²)` 只有量纲一致，若 κ_* 由 G 反求仍是循环论证。

## 11. 因果性与 V≡c 的三种定义禁止混用

- `|d r/dt|=c`：实验室惯性系中的**真实三维空间速度**。有静质量的自由粒子不可能达到 c；平直真空无外场光线是直线 null geodesic 而不是本模型的扭结曲线。
- `U^μ U_μ=−c²`：有质量粒子的四速度不变量，它不是三维 `|v|=c`。
- “内部螺旋每一点以 c 运动”：仍为假设。必须定义内部自由度、协变变换、能量应力与可测预测，才能判断是否物理成立。

任一“从螺旋证明所有力统一”的主张，如果没有独立作用量、粒子荷及其表示、规范异常检查和实测差异，仍未被证明。

## 12. 可证伪路线与下一阶段

1. 将速度归一化后的曲线形状作为**待预测输出**而非公设，提出能在物理场方程中独立选出 R,a,m,n 的机制；不应事后自由调参。
2. 对给定粒子、磁场源、边界条件求完整 Maxwell–Lorentz 自洽轨道；验证稳定性、束缚与辐射反作用。
3. 在量子力学中构造沿闭合路径的完整干涉仪（两个路径、时间、散射、相位包裹），而不仅计算理想 Wilson 环路。
4. 若推测普遍内部螺旋，给出 Lorentz 协变作用量，计算自旋、粒子谱和具体可证伪差异；对比已知加速器/谱线/引力实验。
5. 如果要主张四力共同起源，必须恢复 Einstein 方程和 `SU(3)×SU(2)×U(1)`，严格处理耦合常数、奇偶对称性与量子异常。
