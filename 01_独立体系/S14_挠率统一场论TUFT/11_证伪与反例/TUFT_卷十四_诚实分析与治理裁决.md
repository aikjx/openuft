## 0. 一句话结论

卷十四的**方法学骨架正确**（联合似然 + NUTS MCMC + 收敛诊断 + 贝叶斯因子/LOO 模型比较属标准贝叶斯统计），其**可证伪判据（§10）写得清楚**，**局限性（§9）诚实**。但其**数值精度主张不可复现**、**核心多信使同源性是强假设而非推导**、**§9 的"框架不可证伪"声明违反波普尔可证伪性**，且与本体系 2026-09-30 审计已关闭的 ringdown 窗口存在张力。代码含 3 处真实缺陷（已修复并提供可运行版）。

**登记结论**：卷十四作为"多信使联合贝叶斯方法论 + 新 CMB 通道提案"框架可保留；其物理主张（t_c–T_B 同源、挠率 QNM 修正）当前**无实证支撑、且 TUFT 既有的四个实验窗口（g-2 / EDM / β 跑动 / ringdown）均已被排除**（见 README §三 与 claims S14-C0059~C0070）。

## 1. 正向价值（应当保留的部分）

1. **多信使联合贝叶斯方法学正确**：联合对数似然分解、先验设定、NUTS 采样、`R̂<1.05` 与 `N_eff>1000` 收敛判据、模型比较（贝叶斯因子 + LOO/ELPD）均为教科书级正确实践。
2. **可证伪判据（§10 A/B/C）清晰且可操作**：给出了 CMB 阶跃不存在、ringdown 偏移被压低、`t_c–T_B` 无关联且 `B_{20}<1` 三类具体的实验排除边界——这是好的科学实践。
3. **局限性（§9）诚实**：明确列出了数值、物理近似、观测三类误差源。
4. **CMB 通道是 genuinely 新提案**：TUFT 此前审计未覆盖 CMB 双谱 f_NL 阶跃，故该通道目前**既未被证伪也未被支持**（开放窗口），属合理的新探索方向。

## 2. 批判性发现（诚实登记）

### 2.1 代码三处真实缺陷（已修复，见 07_计算复现/源码 洁净版）

| # | 原稿缺陷 | 后果 | 修复 |
|---|---|---|---|
| 1 | `r_of_rstar` 反解写错：用 `rstar` 自身代入 RHS（`r = rstar + 2M ln(|rstar/2M-1|)`），数学上不成立 | 反解出的 `r` 落到视界内（负值），势函数错乱，本征值全错 | 改用 Lambert W：`r = 2M(W(exp(r*/(2M)-1))+1)` |
| 2 | `eigs` 移位直接用 ω 空间目标 `0.37-0.09j`，但广义本征值 `AΨ=ω²BΨ` 特征空间是 ω² | 移位空间错误，求解器目标错位 | 改为 `sigma=OMEGA_REF**2` |
| 3 | `h_obs` 被置为全零 | GW 似然在 `A→0` 处退化，无法约束 `T_B`，`t_c–T_B` 关联根本无法被检验 | 改为注入已知 `T_B` 的合成 ringdown + 高斯噪声 |

此外原稿拟合系数写作 `388`/`300`（LaTeX `\(0.0\)` 复制残留），依 §5 扫描表反解应为 `3.88`/`3.00`，已修正。

### 2.2 数值精度主张不可复现（关键）

文档宣称基准「`N=1600` 误差 ≈ 1.9e-4」。实测（用洁净版、正确乌龟映射）：

- 原错误映射：N=1600 误差 **8.8e-2**（文档声称的 ~460 倍）。
- 修正映射后：N=1600 误差 **9.7e-2**，且 `ω_I ≈ -0.00002`（应为 `-0.08896`）——**虚部几乎为零，抓到的是无损腔模而非真实 QNM**。
- 改进 PML（域 r*∈[-60,60]、分级 σ 升至 30）：N=1600/2400 仍 `ω_I≈0`、误差 9.67e-2 且**不随 N 收敛**；N=800 甚至给出 `ω_I>0` 的非物理不稳定模。

**裁决**：该 FDTD-PML 方案**不能**复现 QNM 精度。这与本体系审计 R23/R25 的既定教训完全一致——朴素离散化（谱配点/FDTD）只产生箱模（`|Im ω|∝1/L`，阻尼被边界反射抹平），只有 Leaver 连分式（R25 已达 4.46e-7）能取真实阻尼 QNM。文档 §4 的精度表（1.2e-3 / 4.1e-4 / 1.9e-4）**未被提供的代码支撑，属未经验证的声称**。

### 2.3 信号恢复测试是 tautology，不验证 FDTD 求解器

洁净版 `recovery_test` 注入与拟合**都用同一线性代理模型** `ω_R=0.37352+3.88·T_B`，故回收 `T_B` 误差 0% 只证明"最小二乘能拟合一条阻尼正弦"，**不证明 FDTD 求解器可用**——而 FDTD 求解器本身已被 §2.2 证伪不可用。该测试应理解为"证明 GW 似然在注入信号后不再退化"，而非"验证 QNM 求解器"。

### 2.4 多信使同源性是强假设，非推导

§1 假设 5 声明 `t_c` 与 `T_B` 来自同一套 TUFT 复张量场动力学、**存在统计关联**——这是被"断言"的，不是从 TUFT 方程导出的。模型中 `T_B ~ Uniform(0,1e-4)` 是**自由均匀先验**，挠率势 `V_torsion` 是"指数衰减启发式近似，尚未从 TUFT 场方程解析导出"（§1 假设 3 自承）。MCMC 只能**发现**数据中的关联，不能**证明**同源。换言之：该框架检验的是"若同源则数据应显示关联"，而非"已证明同源"。

### 2.5 §9「重要声明」违反可证伪性

> "即使本模型所有预言被实验排除，TUFT 复张量 EC 几何框架本身不会被证伪；仅排除……这个特定低能分支。"

该声明使**框架本身对经验证据免疫**，违背波普尔可证伪性原则。结合 claims 表已记录的史实——TUFT 多个具体分支（g-2、EDM、β 跑动、ringdown）屡被实验排除，而框架仍被宣称"未被证伪"——此声明将"具体分支可弃、框架永存"的模式**制度化**。科学上可接受的表述应是：被排除的是该低能分支的具体参数化，而非整个复几何框架；但框架须给出**可独立检验的新预言**才算可证伪。

### 2.6 与 2026-09-30 审计已关闭 ringdown 窗口的张力

README §三 与 claims S14-C0059~C0070（OPEN5/OPEN6 否决态）记录：TUFT 的四个实验窗口（g-2、EDM、β 跑动、ringdown）**全部关闭/排除**；其中 ringdown 窗口关闭的根因是"σ_abs=0 反射壁非 TUFT 可导出结构，三尺度锚定差 26–79 数量级"（OPEN_v4，2026-09-30）。

本卷的 `T_B` 机制**不同于** σ_abs=0 反射壁（它是背景挠率对 QNM 的线性微扰），故不是同一窗口；但它继承了更深层问题：**TUFT 挠率在宏观（天体物理）尺度与所需值差约 1e28**（R6 审计：曲率饱和与真实黑洞差 76–152 数量级，见 S14-C0028）。本卷用 `T_B` 作自由唯象参数**回避**了该尺度问题，代价是"TUFT 启发式"而非"TUFT 第一性预言"——同源关联的"TUFT 来源"主张因此缺乏推导支撑。

## 4. 建议的后续行动

1. **若要保留 QNM 数值精度主张**：改用 Leaver 连分式（R25 已验证 4.46e-7）替换 FDTD-PML 求解器，或显式标注 FDTD 结果仅作示意。
2. **若要主张 t_c–T_B 同源**：须从 TUFT 复张量场方程**推导出** `T_B` 与 `t_c` 的函数关系（而非自由先验 + 假设），否则该关联在科学上不可证伪。
3. **弱化 §9 声明**：改为"被排除的是该低能分支的具体参数化；复几何框架仍须给出可独立检验的新预言方具可证伪性"。
4. **CMB 通道务实化**：用真实 Planck/CMB-S4 双谱数据（非本卷合成的平坦 `~-0.4±0.2`）重新评估阶跃是否存在。
5. **代码**：已提供可运行洁净版；若需完整 MCMC，安装 `numpyro`/`arviz`/`jax` 后取消 `__main__` 末段注释即可，但须先解决 §2.2 的 QNM 求解器问题。
