攻破⑩：S10 几何到耦合常数 路径 独立复核
======================================================================

[① Wyler] 1/α = 9/(16π³)·(π/5!)^(1/4) = 137.036082448
  CODATA = 137.035999084; 差 = 6.08e-07 (0.6 ppm)
  [攻破] 为什么 D5^IV? 为什么 SO(5,2)? 空间选择任意 → 选择性建模
         物理界共识：Wyler 公式是数论巧合（无动力学理由选该空间）

[② π 多项式] 1/α = 4π³+π²+π = 137.036303776
  CODATA = 137.035999084; 差 = 2.22e-06 (2.2 ppm)
  [攻破] π 的任意多项式拟合 α——任何常数都能用 π 多项式凑到 ppm
         且与 Wyler 公式(0.6ppm) 矛盾(2.2ppm)——多重拟合，自由度多

[③ Koide] K=(m_e+m_μ+m_τ)/(√m_e+√m_μ+√m_τ)² = 0.666660512
  声称 K=2/3=0.666666667; 差 = 9.23e-06
  [攻破] K=2/3 是经验拟合值(Koide 1981)，非第一性推导
         用 K=2/3 反解 m_τ = 借实验值（K 本身来自实验拟合）

[④ sin²θ_W] 3/13 = 0.230769 vs MS-bar 0.23122; 差 = 1950 ppm (0.2%)
  [攻破] 0.23122 附近简单分数有 1/4=0.25、3/13=0.2308、5/22=0.227…总有一个近
         3/13 是事后凑分数；S13 用 1/4、S10 用 3/13——同一目标各自凑

======================================================================
攻破⑩ 判定：S10『几何→耦合常数』全部落入预言注入缺口
======================================================================
  Wyler = 选择性建模(选D5^IV/SO(5,2)，数论巧合)
  π 多项式 = 纯数字拟合(π任意多项式，与Wyler矛盾)
  Koide = 经验公式复述(K=2/3借实验拟合，反解m_τ)
  sin²θ=3/13 = 事后凑分数(0.23附近总有一个简单分数近)
  → S10 即使『最努力从几何推α』，其几何→α也是注入的，非第一性
  → 为 O3(几何-规范涌现)提供决定性反证：几何→耦合常数无一第一性
