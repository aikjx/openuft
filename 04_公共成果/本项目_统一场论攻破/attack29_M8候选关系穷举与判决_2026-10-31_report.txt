[方法 A] 由实测 sin2thetaW 反解破缺能标
------------------------------------------------------------------------------
  给定 3 个低能测量（alpha_em, alpha_s, sin2thetaW）+ 2 个 GUT 条件
  => 解出 2 个能标（M_SUSY, M_GUT）。这是标准的「由数据定能标」做法。

  解：L1 = ln(M_SUSY/M_Z) = -0.51683576
      L2 = ln(M_GUT/M_SUSY) = 33.687471
      M_SUSY = 54.384716 GeV
      M_GUT  = 2.3214509e+16 GeV

  >> L1 < 0 意味着 M_SUSY < M_Z：在该一阶两段模型下，
     要让 sin2thetaW 精确等于实测值，破缺能标必须落在 M_Z 以下。

  对照 LHC：M_SUSY 解 = 54.3847 GeV  vs  粗略排除下限 1000.0 GeV
  >> 存在张力：解出的破缺能标落在已被对撞机排除的区间

[方法 D] 无量纲常数关系穷举
------------------------------------------------------------------------------
  基集 {G, c, hbar, m_e, m_P}，指数范围 [-3,3]，要求量纲无量纲。
  （量纲 = (M,L,T)：G=(-1,3,-2), c=(0,1,-1), hbar=(1,2,-1), m=(1,0,0)）
  无量纲组合数 = 25（其中全零解 1 个）
  以 alpha^-1 = 137.036 为靶，相对偏差 < 0.1% 的组合：0 个
