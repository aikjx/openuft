## 2.2 引力核心公式详证

### 公式1：牛顿万有引力
$$F=G\frac{m_1m_2}{r^2}$$
- 螺旋映射：引力 = κ 曲率场，F_g = ℏc(κ²+τ²)/r²
- **验证**：经典确立

### 公式2：引力常数 G
$$G=\frac{c^3}{\hbar(\kappa^2+\tau^2)}=\frac{c^5}{\hbar\omega^2}$$
- **验证**：普朗克尺度机器零（误差 1.6×10⁻⁶¹）
- **诚实**：含循环论证（ω_P 含 G），TAUT

### 公式3：引力场强度
$$g=\frac{GM}{r^2}=c^2\kappa$$
- 螺旋映射：引力加速度 = 曲率×光速²

### 公式5：开普勒第三定律
$$T^2=\frac{4\pi^2 a^3}{GM}$$
- 源于螺旋圆周运动，与向心力 mω²R=mc²κ 协调

### 公式7：爱因斯坦场方程
$$G_{\mu\nu}=\frac{8\pi G}{c^4}T_{\mu\nu}$$
- 螺旋映射：G_{μν} = ℐ_{μν}（纯几何形式）
- **诚实**：⚠️ 形式对应，非严格推导

### 公式9-10：普朗克尺度
$$l_P=\sqrt{\frac{\hbar G}{c^3}},\qquad m_P=\sqrt{\frac{\hbar c}{G}}$$
- 螺旋映射：l_P ≡ R = 1/√(κ²+τ²)，m_P = ℏω/c²
- **验证**：机器零

### 公式11：施瓦西半径
$$R_S=\frac{2GM}{c^2}=2\kappa R^2$$
- 螺旋映射：施瓦西半径 = 2×曲率×半径²

### 公式12：Gε₀ 统一
$$G\varepsilon_0=\frac{e^2}{4\pi\alpha m_P^2}$$
- 螺旋三形式：c²e²κ/[4πℏ²τ(κ²+τ²)] = c⁴e²/(4παℏ²ω²) = e²/(4παm_P²)
- **验证**：机器零（A级）

## 2.3 螺旋框架引力场核心

### 引力 = 曲率场
$$F_g=\frac{\hbar c(\kappa^2+\tau^2)}{r^2}=\frac{\hbar c\omega^2}{c^2r^2}=\frac{\hbar\omega^2}{c r^2}$$

### 引力波 = 螺旋曲率辐射
$$h\sim\frac{2Gm_1m_2}{c^4 r a}$$

### G 与 ε₀ 的统一
$$G\varepsilon_0=\frac{e^2}{4\pi\alpha m_P^2}$$
