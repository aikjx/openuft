[B0] 自校准：本册 tau_p 闭式是否复现 attack27b 的 2.7755e34 yr
------------------------------------------------------------------------------
  闭式：tau_p = 1e+35 yr x (M_GUT/2e+16)^4 x (alpha_GUT^-1/35)^2 x (0.015/alpha_H)^2
  attack27b 输入：M_GUT=1.6899061e16 GeV, alpha_GUT^-1=25.826977
  本册复算 tau_p = 2.7755e+34 yr
  attack27b 报值   = 2.7755e+34 yr ；相对偏差 3.29e-07

[B1] attack30 的 b33=-14 vs 它自己声明的文献源
------------------------------------------------------------------------------
  attack30 源码注释：「2-loop 系数矩阵 B2_ij（标准 MSSM，来源：Pierce et al. 1997 / Martin 2000）」
  其 B_MS[2][2] = -14 ；attack32（同样自称标准 MSSM）用 +14 。
  枚举判据：在两册共用的【标准 SM 阵 u 标准 MSSM 阵】全部 18 个元素中，
  能与 -14 匹配的解 = [('-(14)', 14.0)]
  >> 唯一解释：-14 = -(MSSM 的 +14)，即 b33 的符号翻转。
     而 -14 不等于 SM 阵的任何一个元素（-26 是最近的），排除「误用 SM 阵」解释。

[B2] attack30 自带 flip33 开关却以 flip33=False 报出
------------------------------------------------------------------------------
  源码：def da_dt(a, b, B2, lam, flip33):  if flip33: B[2][2] = -B[2][2]
  solve_forward / solve_backward 的默认参数均为 flip33=False，
  且最终报出的 M_SUSY=193.04415 GeV 来自 flip33=False（即 -14）。
  >> 作者已把 b33 符号做成可切换的事实 => 该符号在该册内【未被定死】；
     但报出时未声明用的是哪一支 => 引用者无法知道该数对应哪套系数。

[B3] 物理域判据：M_SUSY 必须 >= M_Z（否则 SM 段是反向积分）
------------------------------------------------------------------------------
  两段模型的定义：M_Z --(SM)--> M_SUSY --(MSSM)--> M_GUT，要求 L1 = ln(M_SUSY/M_Z) >= 0。
  1-loop 后向解(attack32 F5)            M_SUSY=    54.38472 GeV  L1=-0.516836  违规(<0)
  2-loop b33=+14(attack32 V0)        M_SUSY=  2317.71643 GeV  L1=+3.235419  OK
  2-loop b33=-14(attack32 V3)        M_SUSY= 17918.76520 GeV  L1=+5.280685  OK
  1-loop 固定 M_SUSY=1TeV(attack27b)   M_SUSY=  1000.00000 GeV  L1=+2.394836  OK
  >> 违规分支 1 个：1-loop 后向解(attack32 F5)
     其中 1-loop 后向解 54.38 GeV 被 attack29/28/30 用作【自校准基准】引用。

[B6] 更正 attack27b 的「余量 1.16 倍 / 与窗口重叠」：该结论依赖 1-loop 的 M_GUT
------------------------------------------------------------------------------
  attack27b 基准（1-loop，M_SUSY 固定 1 TeV）：M_GUT=1.6899061e16 -> tau_p=2.7755e+34（余量 1.156 倍）
  attack32/33 的 2-loop 自洽解：                M_GUT=1.117972e16 -> tau_p=5.2508e+33（差 4.571 倍）
  M_GUT 比值 0.6616 ；tau_p 比值 0.1892（~ 四次方放大）
  >> attack27b 的「与窗口重叠」只在 1-loop M_GUT 下成立；换成库内更自洽的 2-loop M_GUT，
     tau_p 掉 5.29 倍，落到被排除区。
