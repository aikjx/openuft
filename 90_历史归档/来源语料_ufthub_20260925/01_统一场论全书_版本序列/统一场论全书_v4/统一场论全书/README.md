## 一、本书是什么

本书是一份**理论专著草稿**：从已被实验证实的经典力学、狭义相对论、电动力学与量子场论出发，经严格推导建立统一主方程的对照表，再过渡到用户原创的假说层（环面涡旋拓扑荷、分形自相似宇宙、因果畴动力学）。

**三分层纪律（全书强制执行）**：
- 【已证实】——标准物理学结论；
- 【推导】——从已证实前提出发的可验算推导；
- 【假说】——用户原创拓展，**未被实验证实**，均附可证伪预言。

本书**不声称任何假说是已发现的新物理定律**；边界声明见 `appendix/C-边界声明.md`。

## 三、核心推导链（已在本会话完成求导验证）

1. 机电对偶：$m\ddot x+kx=0$ ↔ $L\ddot q+\frac{1}{C}q=0$（阻抗型类比 $m\leftrightarrow L$，$k\leftrightarrow 1/C$）；
2. $\gamma=(1-\beta^2)^{-1/2}$，求导 $\dfrac{d\gamma}{dv}=\gamma^3\dfrac{v}{c^2}$；四速度 $u^\mu=\gamma(c,\vec v)$，$u_\mu u^\mu=c^2$，$u\cdot a=0$；质壳 $E^2=p^2c^2+m^2c^4$，光子 $E=pc$；
3. $\Box=\partial_\mu\partial^\mu=\dfrac{1}{c^2}\partial_t^2-\nabla^2$，平面波 $\omega=ck$，$c=1/\sqrt{\mu_0\varepsilon_0}=299792458\ \mathrm{m/s}$；
4. 统一主方程：$(\Box+\kappa^2)\Phi=0$，有源 $D_\mu D^\mu\Phi-\kappa^2\Phi=J$；电磁 U(1)、Yang-Mills、线性化引力、Klein-Gordon 共用同一二阶协变算符与传播速度 $c$；
5. 本源回环：$A\ddot\Phi+K\Phi=0$ 的相对论完备化 $A\Box\Phi+\dfrac{K}{c^2}\Phi=0$，对照 KG 得 $\hbar\omega_0=mc^2$——**粒子 = 场的相对论谐振模式**（弹簧振子↔LC↔场模式↔粒子闭环）。
