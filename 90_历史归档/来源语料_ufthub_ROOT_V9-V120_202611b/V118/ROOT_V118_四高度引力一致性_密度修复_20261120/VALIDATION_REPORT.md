## 适用边界与禁止误用

1. 上述理论并未使用任何真实卫星测量或独立重力观测数据，**不能声称已经发现/排除了实际第五力**。
2. 模型是给定单标量作用程的已知线性 Yukawa 弱场近似，**不是四力的原始基础作用量，也未导出 G 或完整粒子谱**。
3. 球体密度基准是文献近似；真实地球需要 PREM、球谐、潮汐与地球不确定性联合处理。
4. MICROSCOPE 的物质成分差异约束不能直接作为对普遍耦合标量的相同数值上限。
5. 轨道进动示范不包括 GR、J2、潮汐、非保守轨道力，不是 LAGEOS 或近地卫星实测残差。
6. 无噪声唯一性定理不自动说明实际卫星数据能精确反演——当信号低于误差时逆问题会病态。
