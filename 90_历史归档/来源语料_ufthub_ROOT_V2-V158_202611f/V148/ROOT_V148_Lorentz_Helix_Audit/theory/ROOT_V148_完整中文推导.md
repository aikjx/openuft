# ROOT V148：空间光速螺旋、三方向正交、洛伦兹协变与场论检验

版本日期：2026-11-24。状态：**严格几何与已知麦克斯韦定律的验证工程，不是四力统一的证明**。

## 0. 研究的可证伪命题

ROOT 的核心猜想是：一种以光速传播的螺旋微观运动，借由正交局部方向、曲率、挠率、频率与角速度生成四种基本相互作用。本轮检验其最基础的必要条件，而不预先认定结果：

- C1：光速螺旋的数学结构、方向及加速度是否自洽？
- C2：以三维轨迹的曲率或挠率作力的来源，是否满足洛伦兹协变性？
- C3：几何旋转频率能否直接当作量子关系 `E=ℏω` 的频率？
- C4：空间正交标架的旋转是否产生非零的独立场强？
- C5：圆偏振场的“旋转”是否意味着光子能量沿螺旋轨迹传播？
- C6：已有的地月引力观测能否替代从微观运动独立计算 G 和 GM？

**单位约定：只用 c=1。ℏ 和 G 独立、保留量纲。** 记质量、长度基本量纲为 `M,L`，从而 `[ℏ]=M L`, `[G]=L/M`, `[ω]=[κ]=[τ]=L^{-1}`。数值观测资料在输入/输出处仍显示常见 SI 单位，以方便对照。

## 1. 三维光速螺旋的严格求导

采用平直时空、签名 `(-,+,+,+)`，在一个惯性参考系中假设

\[
\mathbf r(t)=(a\cos\omega t,\; a\sin\omega t,\;ut),\quad a>0,\quad\omega\ne0.
\]

逐阶求导：

\[
\begin{aligned}
\mathbf v&=(-a\omega\sin\omega t,a\omega\cos\omega t,u),\\
\mathbf a_s&=(-a\omega^2\cos\omega t,-a\omega^2\sin\omega t,0),\\
\mathbf j&=(a\omega^3\sin\omega t,-a\omega^3\cos\omega t,0).
\end{aligned}
\]

速度约束 `|v|=1` 等价于

\[
a^2\omega^2+u^2=1.
\]

空间曲率和挠率的一般表达：

\[
\kappa=\frac{|\mathbf v\times\mathbf a_s|}{|\mathbf v|^3}
=\frac{a\omega^2}{a^2\omega^2+u^2},
\qquad
\tau=\frac{\mathbf v\cdot(\mathbf a_s\times\mathbf j)}{|\mathbf v\times\mathbf a_s|^2}
=\frac{u\omega}{a^2\omega^2+u^2}.
\]

在光速条件下，得到

\[
\boxed{\kappa=a\omega^2,\quad \tau=u\omega,\quad
\kappa^2+\tau^2=\omega^2.}
\]

切线、法线、副法线定义为 `T=v`（仅速度为 1 时）、`N=a_s/|a_s|`、`B=T×N`，对非退化曲线满足 `T·N=N·B=B·T=0`。这三个**几何方向**绝不自动等于重力、电场和磁场，也不自动产生三种力。

### 1.1 零间隔不是自由运动

世界线

\[
X^\mu(t)=(t,\mathbf r(t))
\]

满足 `ημν Ẋμ Ẋν = -1+|v|²=0`。但

\[
\ddot X^\mu=(0,-a\omega^2\cos\omega t,-a\omega^2\sin\omega t,0)\neq0.
\]

由于 `Ẋ^0=1`，而 `Ẍ^0=0`，`Ẍ` 不可能与 `Ẋ` 成比例（除非曲线退化）。因此**它不是平直时空中的自由零测地线**。此结论与选取何种曲线参数无关，尽管上述 `Ẍ²` 的数值依赖当前参数 `t`。要让物理粒子沿非退化螺旋运动，必须给出约束力或内部运动机制。不可把“速率等于光速”当作自由光子的完整动力学。

## 2. 关键结果：空间曲率、挠率不是洛伦兹标量

沿 `+z` 方向以 `β` 作洛伦兹变换，令

\[
\gamma=(1-\beta^2)^{-1/2},\quad
D=\gamma(1-\beta u),
\quad t'=Dt.
\]

由于横向坐标不变、纵向坐标变换为 `z'=γ(u-β)t`，因此同一世界线在新惯性系仍可写成螺旋形式，参数为

\[
\boxed{
\omega'=\frac{\omega}{D},\quad
u'=\frac{u-\beta}{1-\beta u},\quad
 a'=a.
}
\]

这里 `u'` 是新参考系的轴向速率。与新参考系空间速率为 1 的条件相结合：

\[
\boxed{\kappa'=a\omega'^2,\qquad\tau'=u'\omega'.}
\]

当 `β=u` 时 `u'=τ'=0`，原三维螺旋在新参考系成为平面圆轨迹。示例 `a=0.6 L0, ω=1/L0,u=0.8,β=0.8`：

| 项目 | 原系 | 新系 |
|---|---:|---:|
| 空间速率 | 1 | 1 |
| κ L0 | 0.6 | 1.666666666667 |
| τ L0 | 0.8 | 0 |
| ω L0 | 1 | 1.666666666667 |
| u | 0.8 | 0 |

因此，将某个参考系测得的 `κ`、`τ`、`ω` 直接认作“绝对的力源”或基本耦合常数会遇到协变性困难。须定义世界线、时空张量、场强及其作用量，而非一个观察者的三维图像。

### 2.1 更强的频率一致性判据

为检验一个常见的、但**尚无理论支持**的假设，假设某光速点状激发具有切向四动量 `pμ=E(1,v)`；在本参考系还假设 `E=ℏ|ω|`，并企图在所有惯性系都使用该同一形式。

轴向 boost 后瞬时能量 `E'=DE`，而几何角频率 `|ω'|=|ω|/D`。故

\[
\boxed{\frac{E'}{\hbar|\omega'|}=D^2\frac{E}{\hbar|\omega|}.}
\]

只要 `D≠1`，就不能保持原始等式。示例 `β=u=0.8` 得 `D=0.6`，比例由 1 变成 `0.36`。

这**不是**否定量子能量频率关系：实际的 `E=ℏω_quantum` 使用与四维波矢相联系的量子相位频率；它与三维空间轨迹的螺旋角速度不是同一个可自动互换的量。若 ROOT 希望它们相等，必须增补使等式协变成立的动力学机制或补偿结构。

## 3. 正确的光速旋转场：圆偏振电磁波

在真空、无源、选定归一化下，令 `ϕ=k(t-z)`，并选取

\[
\begin{aligned}
\mathbf E&=E_0(\cos\phi,\sin\phi,0),\\
\mathbf B&=E_0(-\sin\phi,\cos\phi,0).
\end{aligned}
\]

可直接算出

\[
\nabla\cdot\mathbf E=\nabla\cdot\mathbf B=0,
\quad \partial_t\mathbf B+\nabla\times\mathbf E=0,
\quad \nabla\times\mathbf B-\partial_t\mathbf E=0.
\]

且

\[
\boxed{\mathbf E\cdot\mathbf B=0,\quad
|\mathbf E|^2-|\mathbf B|^2=0,\quad
\mathbf E\times\mathbf B=E_0^2\hat z.}
\]

场的横向分量旋转，但能量动量沿 `+z` **直线传播**。这是物理上最精确、现有实验支持的“光速传播伴随旋转结构”例子；它不表明单个光子在真空中沿空间螺旋世界线前进。

沿 `z` 轴 boost：

\[
\boxed{k'=\gamma(1-\beta)k,\quad E'_0=\gamma(1-\beta)E_0.}
\]

若单光子能量 `E_ph=ℏ k`（`c=1`），则在新参考系能量与 `k` 以**同一** Doppler 因子变化，符合协变性。这与上一节的**点状轨迹旋转角速度**的变换截然不同。

## 4. 纯旋转标架、单相位为何不足以生成电磁场

任何光滑局部旋转标架 `R(x)∈SO(3)`，定义 `Ω=R^{-1}dR`。通过 Maurer–Cartan 恒等式：

\[
\boxed{\mathcal F_\Omega=d\Omega+\Omega\wedge\Omega=0.}
\]

一个光滑的单标量相位 `θ` 若仅令 `A=dθ`，也满足

\[
\boxed{F=dA=d^2θ=0.}
\]

因此，局部“旋转/振荡/闭环”本身并不保证有独立的可传播电磁场。必须有非纯规范的曲率（例如独立规范联络、额外场、非平凡拓扑或其他受动力学约束的结构）。

即使有 `SO(3)` 标架，其三个旋转生成元也不能仅靠相互正交就自动构成 `SU(3)×SU(2)×U(1)` 的 12 个规范生成元。需要额外内部自由度及其一致的场论。

### 4.1 光子自由度计数

四维矢量势有 4 个分量。对在壳无质量平面波，Lorenz 条件 `k_μ A^μ=0` 去掉一个独立分量，残余规范等价 `A^μ∼A^μ+ζk^μ` 再去掉一个，留下**2 个横向物理偏振**。必须从统一作用量和约束代数导出，而不是从“三力垂直”直接命名。

### 4.2 三力垂直原理的反例

局部取 `E=(0,0,E_z)`、`B=(0,0,B_z)`，两者均可恒定并满足局部无源 Maxwell 方程（忽略无穷均匀场的全局边界条件），有 `E·B=E_z B_z≠0`。在地球近地面重力方向也可沿 `z`。所以 `g⊥E⊥B` **不能当作对所有物理构型都成立的自然定律**；正确的正交性出现在某些特殊场解，如真空平面电磁波。

## 5. 地球和月球：力大小、距离、方向基准（没有反向证明）

引用 JPL DE440 天体历表的引力参数（单位 `km³/s²`）：

- 地球 `GM_E=398600.435507`；取近似平均球半径 `R_E=6371 km`；
- 月球 `GM_M=4902.800118`；平均半径 `R_M=1737.4 km`。

取球对称近似 `g(r)=GM/r²`，计算：

| 高度 | 地球 g (m/s²) | 月球 g (m/s²) |
|---|---:|---:|
| 0 km | 9.820250332 | 1.624218877 |
| 100 km | 9.519079836 | 1.452234547 |
| 200 km | 9.231554426 | 1.306187722 |
| 400 km | 8.694250346 | 1.073180018 |
| 800 km | 7.751367431 | 0.761493704 |
| 2000 km | 5.688307755 | 0.350998310 |

矢量形式：`g_vec(r)=-GM r_vec/r³`，方向指向中心。数值 CSV 同时计算 `r²g(r)/(GM)=1`，这是平方反比模型的自洽性检查，不是独立轨道观测检验。地球并非完全球体、月球也存在质量瘤、潮汐以及其他扰动，真实场应使用球谐系数和协方差。**这里的 GM 来自已有观测输入，不是通过 ROOT 螺旋原理自行算出的。**

## 6. 量纲审计与可检验的统一作用量目标

只取 `c=1`：

| 量 | 量纲 |
|---|---|
| `a` | `L` |
| `u` | `1` |
| `ω, κ, τ` | `L⁻¹` |
| `ℏ` | `M L` |
| `G` | `L/M` |
| `ℏω` | `M` |
| `sqrt(ℏ/G)` | `M` |
| `∫ d⁴x R/G` | `M L`（作用量） |

因此不能既把频率视为标架角速度，又把它视为四维波的协变能量频率，除非建立精确连接。

未来的统一动力学需至少包含：

\[
\boxed{S_{\rm candidate}=\int d^4x\sqrt{-g}\,\mathcal L(g_{\mu\nu},\Psi,\mathcal A_\mu,\nabla\Psi,\ldots).}
\]

但关键不是形式上加入这些变量，而是证明从**单一已定义的微观螺旋变量**自然得到：

1. 正确的局部 Lorentz 协变性和无异常的内部规范群；
2. 无质量自旋 1 场的两个物理偏振、正确场方程、守恒律；
3. 引力场的适当低能极限，正确的粒子质量与手征谱；
4. 不把 `G`、精细结构常数、地月质量倒灌回公式的独立新预测；
5. 能被观察数据（包括真实误差协方差）证伪的量化指标。

## 7. 判定结果

| 被测试命题 | 本轮结果 | 局限 |
|---|---|---|
| 理想恒速螺旋的几何恒等式 | 严格成立 | 运动学，不是新动力学 |
| `κ,τ` 是洛伦兹标量 | 反例否定 | 只检验了典型空间曲线和轴向 boost，已足以否定普适性 |
| 非退化零速率偏差的光速螺旋是自由光子轨迹 | 与平直时空自由零测地线不符 | 需要外力/内部机制 |
| `E=ℏω_geom` 任意惯性系保持 | 在所设切向四动量模型中不成立 | 不影响真实量子波频率关系 |
| 圆偏振场是严格无源 Maxwell 解 | 严格成立 | 现有已知理论，不是新发现 |
| 纯旋转 SO(3) 标架自动产生非零规范曲率 | 不成立 | 只对纯规范连接的局部情况 |
| 三力始终两两正交 | 反例否定 | 特定平面波可正交 |
| 地月基准反平方结果 | 与输入 GM 自洽 | 没有 ROOT 的独立引力预测 |
| 四力统一 | **未证明** | 作用量、量子一致性、耦合与粒子谱尚缺 |
