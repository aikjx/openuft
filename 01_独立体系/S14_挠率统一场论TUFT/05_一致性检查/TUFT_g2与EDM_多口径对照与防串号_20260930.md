## 三、两处会串号的地方

### 串号一：反向碰撞——档案里有两个看起来互相抵消的「75%」

同一份普查面上，α/(8π) 的偏差是 **74.962 %（偏低）**，2τ/κ 的偏差是 **74.19 %（偏高）**，两者只差 **0.7719 个百分点**，
而对照对象还分别是 a_e 与 2a_e（差一个因子 2）。结论：**「TUFT 的 g−2 偏差约 75%」这句话在不点名口径时
无法判定该往哪边修**——一个口径要求把预言放大，另一个要求把它缩小。
这条不是新的物理主张，是把 TUFT_双分量干涉屏蔽因子_g-2与EDM联合约束_审计.md §一 已记名的「方向相反」补上价格。

### 串号二：α/π 是假朋友

不含任何挠率的 α/π = 0.002322819466 与 2a_e = 0.002319304361 的比值已达 1.00151559（差 0.15156 % 量级）。
所以「g−2 量级对得上」不能当 TUFT 的证据：一个几何映射只要落在 α 的某个整数分母附近就能撞过量级。
任何后续声称必须给出**与 α/π 不同的、由挠率决定的结构因子**，否则该声称被这条参照线直接吃掉。

## 四、0.00404 这个基线从哪来：循环定价，且判定带牙

普查面 C3 用 ast 读源码结构（不读文案）得到：

- OPEN5b.py 行 36：`G2_TUFT` 右侧类型 = `Constant`，值 = 0.00404 —— 字面常量，不是算出来的。
- OPEN5b.py 行 65：`tau_over_kappa = Rational` → 0.00202，注释自称「由 g-2_TUFT=0.00404 反解」。
- 闭式检验：0.00202 与 0.00404/2 之差 = 9.40914e-20（同一赋值链的两个成员；判定阈写死在普查件源码 C3 分支里，本件不复述其位数）。
- 判定：**CIRCULAR**。
- 独立见证（不同目录、另一条弧，与本件不共享代码）：`04_公共成果/算法联盟_全维自洽与归一化/数据/v_eq_c_TUFT_V2_双分量孤子_可证伪性审计.md` 行 32 的 B-05 判语把同一件事记为「来料把 g-2_0=2r 当作起点，全文无推导 ⇒ 属映射层注入」，其行 55 另引 V1 的同一个 0.00404 作对照。
- 而同一份档案里那句「τ/κ 被孤子自洽锁死」已由 OPEN5c.py 行 127 撤回为「由额外孤子解选定」。

后果：以 2τ/κ 口径算出的 74.1902 % 偏差**不是与实验值的偏差，而是与自身输入之偏差**。
把它当预言的失败证据、或当预言的成功证据，都不成立——它没有被产出。要让它成为可判定的量，
必须有一次不含 g−2 数据的动力学产出（同一个 0.00404 由场方程与边界条件给出）。

- 白皮书口径引用的是 8.7e-34 C·m，比 ACME 严 12643.68 倍（派生）。
- 单位换算链在第 4 位分叉：2.2570e-34 C·m 自洽化为 1.408708598e-13 e·cm；OPEN5b 印 1.4087e-13（与自洽值同），OPEN6 印 1.4089e-13（相对偏 0.000136，派生）。
- 规矩：引用「超限 N 个量级」必须同句点名上限口径与单位换算链；否则这句话在语料里至少对应三个不同数值。

## 七、判定：本轮没有突破，推进的是口径的可判定性

1. **未发现新的理论体系公式。**本轮所有产出是对既有口径的对照与定价；未提出任何新映射、未改任何既有公式。
2. g−2 侧当前**不可判定**：唯一被当作 TUFT 预言的 0.00404 是字面常量反解（§四），
   而 α/π 参照线（§三 串号二）表明「量级对上」不构成证据。
3. EDM 侧超限 1.2806e+16 倍那笔冲突**仍存活**（§五），且它不依赖 §四 的缺陷——这是档案里唯一一把不靠循环输入的否证。
4. 准入门槛（要谈突破必须同时满足，逐条可查）：
   (a) 唯一化磁矩口径：从三套映射中由同一电磁流算符选定一套，另两套降级为参照；
   (b) 0.00404 由不含 g−2 数据的动力学产出，闭合差 9.40914e-20 那种自比必须消失；
   (c) 给出与 α/π 不同的挠率结构因子；
   (d) EDM 的 γ 定出量纲与数值（此前「最有利修复」的结论挂在 TUFT_双分量干涉屏蔽因子_g-2与EDM联合约束_审计.md §四 与 claims S14-C0062 上，本件不复制其读数）。
