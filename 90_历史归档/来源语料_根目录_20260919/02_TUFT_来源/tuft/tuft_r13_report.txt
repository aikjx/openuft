  1. 求导证明复核：两套系统的能量守恒（sympy 符号求导）
==============================================================================
  机械系统：E = ½mẋ² + ½kx²
    dE/dt = (k*x(t) + m*Derivative(x(t), (t, 2)))*Derivative(x(t), t)
    因式分解 = (k*x(t) + m*Derivative(x(t), (t, 2)))*Derivative(x(t), t)
  [PASS] 1a: 机械能守恒求导验证  |  dE/dt = ẋ(mẍ + kx)；代入运动方程 mẍ+kx=0 ⇒ dE/dt = 0 ✓（sympy 精确因式分解确认）

  电磁系统：E = ½Lq̇² + ½(1/C)q²
    dE/dt = (C*L*Derivative(q(t), (t, 2)) + q(t))*Derivative(q(t), t)/C
    因式分解 = (C*L*Derivative(q(t), (t, 2)) + q(t))*Derivative(q(t), t)/C
  [PASS] 1b: 电磁能守恒求导验证  |  dE/dt = q̇(Lq̈ + q/C)；代入 Lq̈+q/C=0 ⇒ dE/dt = 0 ✓（与机械逐项同构）

  dsolve 机械：C1*sin(sqrt(k)*t/sqrt(m)) + C2*cos(sqrt(k)*t/sqrt(m))
  dsolve 电磁：C1*sin(t/(sqrt(C)*sqrt(L))) + C2*cos(t/(sqrt(C)*sqrt(L)))
  [PASS] 1c: 两套系统的解同为正弦/余弦（调和振荡）  |  机械 x(t) = C1*sin(sqrt(k)*t/sqrt(m)) + C2*cos(sqrt(k)*t/sqrt(m))；电磁 q(t) = C1*sin(t/(sqrt(C)*sqrt(L))) + C2*cos(t/(sqrt(C)*sqrt(L))) ⇒ 同为 A·cos(ωt)+B·sin(ωt) 结构（sympy dsolve）

  3. 对偶的严格定性：这是**辛同构**，不是物理等价
==============================================================================
  机械：正则坐标 (x, p)，p = mẋ，H = p²/(2m) + kx²/2，{x, p} = 1
  电磁：正则坐标 (q, Φ)，Φ = Lq̇（磁通链），H = Φ²/(2L) + q²/(2C)，{q, Φ} = 1
    H_mech = k*x**2/2 + p**2/(2*m)
    H_em   = Phi**2/(2*L) + q**2/(2*C)
  两者同为「½·(动量)²/惯量 + ½·刚度·(坐标)²」的正则形式 ⇒ 辛结构相同。
  [PASS] 3a: 对偶的严格身份 = 辛同构（正则变换）  |  两套系统共享同一哈密顿形式与泊松括号结构 ⇒ 数学同构；该同构保证 ODE、守恒律、量子化程序全部一一对应
  [BOUNDARY] 3b: 【关键边界】辛同构 **≠** 物理等价  |  同构只保证「方程结构相同」，不保证「物理实体相同」。m↔L 的正确解读是：二者在各自的哈密顿量中占据**同一个结构槽位**（广义惯量），**不是**「电感真的是质量」。把数学映射读成物理同一，是此类类比最常见的误用

  7. 涡旋拓扑解：绕数 n ∈ ℤ
==============================================================================
  二维谐振场的涡旋解：φ(r,θ,t) = f(r)·exp(i(nθ − ωt))，n ∈ ℤ
  单值性 φ(θ+2π) = φ(θ) ⇒ exp(i·n·2π) = 1 ⇒ **n 必须为整数**（拓扑量子化）
  拓扑荷（绕数）：Q = (1/2π)∮∇θ·dl = n
    n = +0  ⇒  相位 e^{i0θ}，绕数 Q = 0
    n = +1  ⇒  相位 e^{i1θ}，绕数 Q = 1
    n = +2  ⇒  相位 e^{i2θ}，绕数 Q = 2
    n = -1  ⇒  相位 e^{i-1θ}，绕数 Q = -1
    n = +3  ⇒  相位 e^{i3θ}，绕数 Q = 3
  [PASS] 7a: 涡旋绕数量子化为整数（拓扑不变）  |  单值性强制 n∈ℤ ⇒ 与 TUFT 的 Lk∈ℤ、W∈ℤ 同属「整数拓扑不变量」族（结构同构）
