02三重门

突破必须同时通过三道门；任一门被抹掉，机器立刻报 GATES-FAIL 并出现假突破。

C1 · 自由度门
p_free == 0
无可调参数、无可自由选择的注入假设。实验输入计入 p_exp，但不算自由选择。LAF 逐项置零机算依赖度，全表最大 p_exp = 3。
挡下 3 条：K03 / K09 / K10（均注入额外假设）
C2 · 留一法门
LTO：目标观测非输入
目标观测量不得作为输入，理论值不得等于观测值。抓回述型伪预言与循环版本。attack28 的 SM / MSSM 三条真预测在此门确实通过。
挡下 3 条：K04 循环版 / K05 回述 / K06 恒等式
C3 · 实验存活门
存活 ∧ 判别力 > 0
卡方 / 下界 / 上界判决通过，且存在使其失败的观测读数，且不是恒等式。恒等式 6 个读数全绿 ⇒ 判别力 0；上界型三个 r 值全存活 ⇒ 判别力 0。
