== 1. 关键不对称性：g-2 与 EDM 对 (Ω,θ) 的依赖 ==
  参数化 κ=Ωcosθ, τ=Ωsinθ（OPEN5c 已证）
  g-2 = 2τ/κ      = 2*tan(theta)   ← 只含 θ，【与 Ω 无关】
  EDM ∝ κτ        = Omega**2*sin(2*theta)/2  ← 含 Ω²【依赖尺度】
  ⇒ 重标度 Ω→λΩ：g-2 不变（θ 未动），EDM → λ²·EDM
  [INFO] 存在『调尺度压 EDM 而保住 g-2』的通道  |  需检验其物理代价

== 2. 通道所需的重标度因子 λ ==
  EDM 需压低 F_d = 7.8086e-17
  λ² = F_d ⇒ λ = 8.8366e-09
  即 Ω 需缩小 1.132e+08 倍（Ω → 8.837e-09 · Ω₀）

== 3. 物理代价检验：Ω = m_e c/ħ ⇒ 缩 Ω 等价缩 m_e ==
  Ω₀ = m_e c/ħ = 2.5896e+12 m^-1  (≈1/ƛ_C，康普顿尺度)
  Ω ∝ m_e ⇒ 缩 Ω 到 λ 倍 ⇔ m_e → λ·m_e
  要求 m_e = 8.0496e-39 kg （实测 9.1094e-31 kg）
  ⇒ 要求电子质量【缩小 1.132e+08 倍】

  测量约束：m_e 相对不确定度 ≈ 2.9e-11
  要求相对改变 |1−λ| ≈ 1.000000（即 ~100% 的改变）
  超出测量不确定度 3.448e+10 倍 ⇒ 约 10.5 个量级
  [FAIL] 尺度重标度通道与质量测量矛盾  |  压 EDM 需 m_e 缩小 1.13e+08 倍，而 m_e 高精度测量仅允许 ~3e-11 相对改变 ⇒ 超 ~11 量级，彻底矛盾

== 4. 尺度三难（本册结论）==
  (a) 保 g-2(θ 匹配) + 保 m_e(Ω 锁定) ⇒ EDM 超 ACME 16.1 量级 ❌
  (b) 保 g-2 + 压 EDM ⇒ 需 m_e 缩小 1.13e+08 倍，与测量矛盾 ~11 量级 ❌
  (c) 保 m_e + 压 EDM（调 θ）⇒ g-2 归零/发散（OPEN5c 已证） ❌

  ⇒ 三个角全部堵死：EDM 的 16 量级超额是【尺度锚定被质量测量锁死】的必然后果。
  ⇒ 根源钉死：不是 τ/κ 比值（OPEN5c），不是屏蔽因子（OPEN5b），
     而是 Ω = m_e c/ħ 这一【康普顿尺度】本身——Ω² 天然巨大，
     而 m_e 是外部测量输入，TUFT 无第一性机制给出/改变它（O-SCALE 开放项）。
  [FAIL] EDM 超额根源 = 尺度锚定 + 质量测量锁死  |  TUFT 若要有救，须给出第一性尺度机制（O-SCALE 已证当前无），且该机制还须与 m_e 高精度测量相容——双重不可能
