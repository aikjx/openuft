# 第一部分：理论基础

## 1.1 垂直原理

**公理**：三维空间中，物体运动方向不断变化 → 曲线运动 → 圆周只有2条垂直切线 → 必须叠加垂直方向直线 → **圆柱螺旋运动**。

**数学形式化**：
- 螺旋运动参数方程：$\mathbf{r}(t) = (R\cos\omega t,\ R\sin\omega t,\ bt)$
- Frenet标架 $\{\mathbf{T},\mathbf{N},\mathbf{B}\}$ 两两垂直
- 速度分解：$v^2 = v_\perp^2 + v_\parallel^2 = R^2\omega^2 + b^2$

## 1.2 三重奏定理（严格证明，R4–R9）

**定理**：对任意匀速螺旋运动，Frenet曲率和挠率满足
$$\kappa^2 + \tau^2 = \left(\frac{\omega}{v}\right)^2$$

**证明**（R9归纳证明闭合）：
1. 螺旋满足 $\mathbf{r}'' = A\mathbf{r}'$，其中 $A = \mathrm{diag}(\omega J, 0)$ 为常数斜对称生成元
2. 归纳证明 $B\mathbf{e}_i = \mathbf{e}_i'$（Frenet标架的导数由生成元给出）
3. $\sum \kappa_i^2 = -\mathrm{tr}(K^2)/2 = -\mathrm{tr}(B^2)/2 = \sum \mu_j^2 = (\sum \omega_j^2)/v^2$
4. D=4, m=1退化为 $\kappa^2 + \tau^2 = (\omega/v)^2$

**验证**：
- sympy精确差=0
- 20组随机参数全维定理全部成立（相对差≤8.3e-29）
- 250位精度相对差≤1e-251

**全维推广**（R6）：D维多平面超螺旋满足
$$\sum_{i=1}^{m} \kappa_i^2 = \frac{\sum_{j=1}^{m} \omega_j^2}{v^2}$$

**梯度磁场精确性定理**（R11）：对方向不变的任意空间梯度磁场 $\mathbf{B}(x)$，电子轨迹的三重奏恒等式**精确成立**（非近似），mpmath 50位验证中位相对差1.17e-18。

## 1.3 大统一力方程

**方程**（张祥前统一场论）：
$$\mathbf{F} = \frac{d}{dt}[m(\mathbf{c}-\mathbf{v})] = \mathbf{c}\frac{dm}{dt} - \mathbf{v}\frac{dm}{dt} + m\frac{d\mathbf{c}}{dt} - m\frac{d\mathbf{v}}{dt}$$

**四力分解**：
| 分量 | 表达式 | 对应力 |
|---|---|---|
| 电场力 | $\mathbf{c}\,dm/dt$ | 沿光速方向 |

| 引力/核力 | $m\,d\mathbf{c}/dt$ | 沿光速变化率方向 |
