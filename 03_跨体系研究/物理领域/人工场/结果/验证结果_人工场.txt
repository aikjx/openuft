核心方程：∂B/∂t = -(g × E)/c²

======================================================================
A1: 方程量纲验证与严格推导
======================================================================
  方程：∂B/∂t = -(g × E)/c²

  【量纲验证】
    [∂B/∂t] = T/s = kg/(C·s²)
    [g×E] = (m/s²)(kg·m/(C·s²)) = kg·m²/(C·s⁴)
    [g×E/c²] = kg·m²/(C·s⁴) / (m²/s²) = kg/(C·s²) = T/s
    → 量纲自洽 ✓

  【反解引力场】
    假设g⊥E（引力场垂直于电场）：
    g = c² (∂B/∂t × E) / |E|²
    大小：|g| = c² |∂B/∂t| / |E| （当∂B/∂t⊥E时）

  【特殊情况】
    当∂B/∂t⊥E时：|g| = c² |∂B/∂t| / |E|
    产生1g(9.8m/s²)需要：|∂B/∂t| = g·E/c²

A6: 三重奏定理与人工场的关联
======================================================================
  【三重奏定理】
    匀速螺旋运动：κ²+τ²=(ω/v)²
    κ=曲率, τ=挠率, ω=角频率, v=速度

  【与人工场的关联】
    变化电磁场产生引力场 → 空间运动模式改变
    空间运动模式 = 螺旋运动 → 由κ,τ,ω描述

  【对应关系】
    电场E ↔ 螺旋的直线分量（z方向速度b）
    磁场B ↔ 螺旋的旋转分量（xy平面角速度ω）
    引力场g ↔ 螺旋的曲率κ（向心加速度）
    挠率τ ↔ 电磁耦合强度（E×B方向）

  【数学关联】
    螺旋：r(t)=(R cosωt, R sinωt, bt)
    速度：v²=R²ω²+b²
    曲率：κ=Rω²/v²
    挠率：τ=bω/v²
    三重奏：κ²+τ²=(ω/v)² ✓

    引力场g = 向心加速度 = Rω² = κv²
    → g = κv²（引力场∝曲率）

    变化磁场∂B/∂t ↔ 变化的角速度∂ω/∂t
    → ∂g/∂t = v² ∂κ/∂t = v² (R/v²) ∂ω/∂t = R ∂ω/∂t
    → 引力场变化率∝角速度变化率 ↔ 磁场变化率

  【结论】
    三重奏定理为'变化电磁场产生引力场'提供了几何基础：
    电磁场变化 → 螺旋运动参数(ω,b)变化 → 曲率κ变化 → 引力场g变化
    这是统一场论的核心几何机制，三重奏定理是其严格数学表达。
