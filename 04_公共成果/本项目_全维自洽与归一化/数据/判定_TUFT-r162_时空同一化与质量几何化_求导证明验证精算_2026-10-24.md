## 三、机读推导

```
R(t) = C(t)·t，  |C| = c = 常数  ⇒  C·dC/dt = 0
⇒ dR/dt = C + t·dC/dt，   |dR/dt| = sqrt(c^2 + t^2 |dC/dt|^2) >= c
⇒ dC/dt = 0  ⇒ |dR/dt| = c        ⇒ ds^2 = 0    （类光，有质量粒子不存在）
⇒ dC/dt ≠ 0  ⇒ |dR/dt| > c        ⇒ ds^2 < 0    （类空，超光速）
```

求导本身经**自适应中心差分**复核：解析 dR/dt = C + t·Ċ 与差分残差 **4.621e-12**，三档步长单调下降。

## 八、条目总表

- **A0** [PASS] 求导本身正确：dR/dt = C + t·Ċ，|dR/dt| = √(c²+t²|Ċ|²)（对靶有利） — 先复核「求导」本身：对 R(t) = C(t)·t（C = c·(cos ωt, sin ωt, 0)）做**自适应中心差分**（解析求截断≈舍入的平衡点 h_opt = 7.63e-04，取 h0 = 4·h_opt = 3.05e-03），解析 dR/dt = C + t·Ċ 与差分残差 = **4.621e-12**，三档步长残差单调下降（4.62e-12 → 1.14e-12 → 2.88e-13）⇒ 收敛阶正确。且 |dR/dt| 的解析模长与闭式 √(c²+t²|Ċ|²) 一致（相对差 0.0e+00）。**这是本卷对靶有利的结论，诚实登记**：求导这一步没错，|C| = 常数 ⇒ C ⊥ Ċ 的推论也对。问题出在把这个求导结果**当作物体的速度**时会发生什么（见 A3/A6）。
- **A1** [FAIL] 两难·R 指什么：物体位置 ⇒ 共球面塌缩；空间位移场 ⇒ 与力方程脱钩 — 原文 §2.1 只说 R 是「空间位移」，未指明它是**物体的位置矢量**还是**空间点自身的位移场**，两支都不利：① 若 R 是物体位置 ⇒ |R| = c·t 强制**所有物体在同一时刻到原点的距离都等于 ct** ⇒ 空间塌为一个**球面**（二维）。机读：地球需 t = **499.005 s**、比邻星需 t = **1.340093e+08 s**（4.2465 年），两者**不可能同时满足**（距离比 = **2.685532e+05**）。② 若 R 只是空间位移场（空间自身以光速流动）⇒ |R| = c·Δt 是标准的**光行距**关系，无矛盾（见 A7 的诚实登记），**但**此时 R 与物体的位置/速度**无关** ⇒ 它无法为 m = k∮dn/Ω（「物体周围的 R 条数」）和 P = m(C−V) 提供几何依据 ⇒ **公设与力方程脱钩**。
- **A2** [FAIL] C 全局均匀 ⇒ 所有物体位置矢量相同（空间塌为一点） — 原文 §3.1 自承「空间光速矢量 C 的方向被认为**均匀且不变**」。若 C 在空间中均匀，则 R = C t 对**每一个**物体给出**同一个**位置矢量 ⇒ **所有物体位置重合**，空间塌为一点。机读：取两个物体，实测间距 **1.0 m**，公设预测 **0.0 m** ⇒ 偏差 **-100.00%**。唯一的退路是让 C 因物体而异，但那样 C 就不再是「空间本底光速场」，而是由位置反定义的量（C = R/t），公设退化为恒等式重排 ⇒ 零内容。
- **A3** [FAIL] 两难·类光或类空：Ċ=0 ⇒ ds²≡0（有质量粒子不存在）；Ċ≠0 ⇒ 超光速 — 由 A0 的求导结果 |dR/dt| = √(c² + t²|Ċ|²)（C ⊥ Ċ）：① 若 Ċ = 0（原文 §3.1 宏观假设「方向不变」）⇒ |dR/dt| = c ⇒ ds²/(c²dt²) = 1 − 1 = **0（精确，Fraction 层相消）** ⇒ 世界线**类光** ⇒ 固有时 dτ ≡ 0 ⇒ **有质量粒子（类时）在该公设下不存在**。② 若 Ċ ≠ 0（原文又称 C「方向可变」）⇒ |dR/dt| = c·√(1+(|Ċ|t/c)²) **> c** ⇒ ds²/(c²dt²) = −(ωt)² = **-1.0000e+06 < 0** ⇒ **类空、超光速**。机读示例（ω = 1e+03 s⁻¹，t = 1 s）：|dR/dt| = **1.000000e+03·c**。⇒ **两支都死，无第三支**（与 r152/r153 的 √2·c 超光速同型，但那里是两条约束联立的后果，这里只由 R = C t 一条推出）。注意：②的数值依赖 ω（ω 是自由参数），故只作**存在性**指控；①不依赖任何自由参数。
- **A4** [PASS] 读法 P（t = 固有时）确实救回类时性：ds² = c²dt²(1−1/γ²) > 0（★对靶有利） — ★防漏判：本卷先登记对靶有利的分支。若把 R = C t 中的 t 读作**固有时 τ**（读法 P，与 r161 读法层同构），则 |dR/dt| = c·(dτ/dt) = **c/γ**，ds²/(c²dt²) = 1 − 1/γ² = **1 − β² = +8.100000e-01 > 0**（β = 0.9 ⇒ γ = 2.2941573387）⇒ **类时** ✓，A3①的「有质量粒子不存在」被避开。**这是本卷对靶有利的结论，诚实登记为 PASS。**但它救不回空间维度（A5），也救不回共球面（A5），故不构成翻案。
- **A5** [FAIL] 读法 P 救不回空间：相对位置恒 ∥ C ⇒ 横向维度塌缩（一维化） — 读法 P 虽救回类时性（A4），但**救不回空间维度**。在同一坐标时 t，R_A = C·τ_A、R_B = C·τ_B ⇒ 相对位置 R_B − R_A = **C·(τ_B − τ_A) 恒平行于 C**。机读（β = 0.9 ⇒ γ = 2.294157，t = 1 s）：τ_A = 4.358899e-01 s、τ_B = 1.000000e+00 s ⇒ |ΔR| = **1.691160e+08 m**，方向 ∥ C ⇒ **横向分量恒为 0**。而实测相对位置的横向分量 = **1.0 m** ⇒ 偏差 **-100.00%**。⇒ 读法 P 下空间**退化为沿 C 的一条直线**（一维），三维空间不再存在。读法 C 下更差（A2：所有物体位置重合）。⇒ 两种读法都救不回空间。
- **A6** [FAIL] 两难·V 与 dR/dt：V=dR/dt ⇒ P = m(C−V) 恒零；V≠dR/dt ⇒ R 与物体脱钩 — 原文从未说明物体的速度 V 与 R 的关系，两支都不利：① 若 V ≡ dR/dt（R 是物体位置，速度是位置导数）⇒ 在 Ċ = 0 下 V = C ⇒ **P = m(C − V) ≡ 0**，即**一切动量恒为零**。机读：原文 §3.1 自承「静止动量 P_静 = mC」（电子 2.730925e-22 kg·m/s），本支预测 **0** ⇒ 偏差 **-100.00%**。② 若 V ≠ dR/dt ⇒ 物体的位置变化率**不等于**空间位移的变化率 ⇒ R 不是物体的位置 ⇒ 回到 A1 的第二支：**R 与物体运动学脱钩**，R = C t 对物体的 P、V、m 没有任何约束力 ⇒ 该公设对力方程**零内容**。⇒ 想让力方程有内容就必须让 R 与物体挂钩，一挂钩动量就恒零。
- **A7** [INFO] |R| = c·Δt 作为「光行距」定义是标准且正确的 ⇒ 该式本身不判错 — ★防过度指控：若把 R = C t 只读作 **|R| = c·Δt**（光行距/光行时关系），它是**标准且实验证实**的（雷达测距、 lunar laser ranging 都基于它）。机读自检：地月往返光行时 Δt = **2.564434 s** ⇒ r = c·Δt/2 = **3.843990e+08 m**，与月距 3.843990e+08 m 偏差 0.00e+00。⇒ 本卷**不指控这个关系本身**。指控的是：原文把它列为「基本公设」并**由此**去定义质量（m = k∮dn/Ω）、动量（P = m(C−V)）与电荷（经 q = k′dm/dt）——**从光行距定义推不出这些**，这才是本卷判决的对象。
- **B1** [BOUNDARY] 记号不自洽：∮ dn/Ω 分子是微分、分母是总量（4π）⇒ 得平均值而非总量 — 原文写 m = k ∮ dn/Ω。分子 dn 是**微分增量**（条数的微元），分母 Ω 若不写 dΩ 则是**总立体角**（4π）——微分除以非微分，记号本身不成形。两种补救读法给出不同的量：① 读作 (1/4π)∮dn = N/(4π) ⇒ 与总条数 N 成正比，只差常数 1/4π；② 读作 ∮(dn/dΩ) dΩ = N ⇒ 就是总量。⇒ 无论哪种，都**必须**先把 Ω 明确为 dΩ 或 4π，原文未做 ⇒ 记为 BOUNDARY（记号缺陷，不单独证伪）。
- **B2** [PASS] 总量读法可加：m ∝ N ⇒ 2×1kg = 2kg（★对靶有利，诚实登记为 PASS） — 先给靶应得的：若把 ∮dn/Ω 读作 (1/4π)∮dn = **N/(4π)**（N = 总条数），则 m **正比于总条数**，只差一个常数因子 4π ⇒ **质量可加** ✓。机读：两个 1 kg 砝码合称 ⇒ **2.0 kg**，与天平实验一致（相对不确定度 ~1e−6）。**这是本卷对靶有利的结论，诚实登记为 PASS** —— 该公设不是「一算就错」，问题出在原文的**措辞**（B3）与「条数」**无定义**（B5）。
- **B3** [FAIL] 两难·措辞：原文称 m 为「密度」⇒ 不可加（−50%），与一切称重实验冲突 — 原文措辞称 m 为「单位立体角内……的**条数密度**」。**密度不可加**：两个 1 kg 砝码合称，密度不变而质量是 **2 kg**。机读：按「密度」读法给 **1.0 kg**，按「总量」读法给 **2.0 kg** ⇒ 偏差 **-50.00%**，与天平实验（相对不确定度 ~1e−6）相差 **5 个数量级以上**。⇒ 原文要么把「密度」改口为「总量」（记号修正，零代价，见 C 组 M3），要么承认质量不可加（与一切称重实验冲突）。**两支中只有改口那一支能活，而活着的那支只是改了个说法。**
- **B4** [FAIL] 量纲：[k] = (M) ⇒ k 是**有量纲自由参数** ⇒ 该式不是定律 — 真做 (M, L, T) 元组运算：「条数」n 是**计数** ⇒ 无量纲 (0,0,0)；立体角 Ω（sr）⇒ 无量纲 (0,0,0) ⇒ [∮dn/Ω] = (0,0,0)，而 [m] = (1,0,0) ⇒ **[k] = (1,0,0)**，即 k 带**质量量纲**。按本线既有纪律：**有量纲自由参数 = 非定律** —— 一个含待定有量纲常数的式子可以拟合任意一组质量值，不构成约束。且原文**从未给出 k 的数值或量级** ⇒ B5 的「不可操作」成立。（与 r161 的 k′ 同型：两条几何化公设各引入一个有量纲的未定常数。）
- **B5** [FAIL] 「条数」n 无定义：无测度、无密度函数、无归一化 ⇒ 公设不可计算 — 要由 m = k∮dn/Ω 算出质量，必须知道：① dn 在球面（或立体角）上如何分布；② 该分布的**测度**（是 dΩ 还是别的）；③ n 的**归一化**（一条「空间位移矢量」算几条）；④ k 的数值。**这四项原文一项都没给**。机读自由度计数：给定 m_e 一个观测值，只能反解出组合量 k·N_e/4π 的**一个**等式 ⇒ **欠定**，无法预测 m_p、m_μ、m_τ 中的任何一个。⇒ 该公设在现有文本下**不可操作**（不是算错，是**算不出来**）。
