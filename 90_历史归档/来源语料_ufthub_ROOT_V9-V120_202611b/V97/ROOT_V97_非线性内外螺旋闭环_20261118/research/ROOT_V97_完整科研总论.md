# ROOT V97｜从线性双频共振到非线性平面内外周期轨道

**版本**：2026-11-18 · ROOT V97 · 研究类型：数学证明 / Maxwell–Lorentz 已知动力学 / 合成数值与程序验收。

**科学状态**：本研究没有发现新的基本作用力，没有从曲率挠率计算基本引力常数 G，没有证明全粒子光速螺旋，也没有统一强、弱、电磁和引力。所有运行输出均标明 `THEORY`，没有真实实验数据。

## 摘要

V93–V95 研究从人为指定的环面螺旋转向外场逆设计，V96 进一步使用两只真实连续有限截面外部电流线圈在无电流粒子通道内生成 Maxwell 磁场，获得弱聚焦稳定圆轨道及内外往复振荡。

V97 解决两道可明确计算的问题。其一，对 V96 的线性弱聚焦频率关系 `νr²+νz²=1` 和同步闭环条件，给出完整**正整数勾股三元组分类**，最短的双向正频率线性闭环为五圈，`νr=4/5,νz=3/5`。其二，在同一外部线圈场中不预设平面轨迹形状，而是积分真实相对论 Lorentz 方程，在 `z=0` 对称不变子空间内对径向最大点建立 Poincaré 返回映射，并通过射击使**有限振幅平面非圆形轨道数值闭合**：4 次径向呼吸 / 5 次方位旋转。

这些结果是已有加速器物理与整数论的可复现结合，形成模型内的精算进展，而非一个新统一场论。

## 1. 物理模型、参数和前提

使用 V96 的连续有限截面双环形电流源：中心半径 10 mm、轴向中心 `z=±8 mm`、各截面半径 1 mm。光滑电流密度仅有方位角分量 `Jφ`。磁场由对该连续分布的 Biot–Savart 积分生成，采用每个截面 `21×21` Gauss–Legendre 求积近似。对粒子所在环状通道，`J=0`，符合静态 Maxwell 方程 `∇·B=0`、`∇×B=0`；磁场在通道内可以非零。

电子参数取 `β=0.1, v=βc`、`q=-e`、`γ=1/sqrt(1-β²)`。将参考圆轨道半径记 `r0`，在各次模型续接中都通过 `|q|Bz(r0,0)=γm v/r0` **重新标定每线圈电流**。这点极重要：在扫描 `r0` 时，并非始终保持相同供电电流；但射击成功后的单个最终轨道则处在固定的静态外场里。

本轮忽略辐射反作用、真实电源电场、空间电荷和器件反馈。模型不是自洽有限温度加速器设计。

## 2. 第一条严格定理：双频线性共振的勾股分类

在中面对称、轴对称静磁场的圆形参考轨道附近，弱聚焦磁场指数为

\[
n=-\frac{r_0}{B_z(r_0,0)}\left.\frac{\partial B_z}{\partial r}\right|_{r_0,0}.
\]

当 `0<n<1` 时，线性频率比

\[
\nu_r=\sqrt{1-n},\qquad\nu_z=\sqrt n,\qquad\nu_r^2+\nu_z^2=1.
\]

要求存在正整数 `N,a,b`，使径向、轴向在 `N` 圈后都回到初始相位，`Nνr=a`、`Nνz=b`。平方相加直接得到

\[
\boxed{a^2+b^2=N^2}.
\]

反过来，任一正整数勾股三元组都可定义数学上允许的频率 `νr=a/N, νz=b/N` 和 `n=b²/N²`。**但能否利用某一台外部线圈装置达到这个 n，还必须另外计算磁场梯度与几何范围。**

正整数非零勾股三元组的最小斜边为 5，因而最少需要五圈。所有互素原始三元组可由欧几里得参数化生成：

\[
a=m^2-k^2,\quad b=2mk,\quad N=m^2+k^2
\]

其中 `m>k≥1`、`gcd(m,k)=1` 且一奇一偶，再允许交换两直角边。不是所有质量、粒子或自然力都满足这条共振条件，它只属于上述线性模型。

## 3. 第二条严格定理：轴对称静磁场的平面动力学约化

洛伦兹力动力学来自作用量

\[
S=-mc^2\int d\tau+q\int A_\mu dx^\mu.
\]

空间静态、轴对称且中面镜像对称时，在 `z=0,vz=0` 初值下，由反射对称性保证运动保持在 `z=0`。能量 `E=γmc²` 与正则方位角动量

\[
\boxed{P_\phi=\gamma m r^2\dot\phi+q\Psi(r,0)},\qquad \Psi(r,0)=rA_\phi(r,0)
\]

均守恒。在 `z=0` 平面上，磁通函数满足 `∂r Ψ=r Bz(r,0)`。令机械动量大小 `p=γmv`，得到

\[
p_r^2=p^2-\frac{(P_\phi-q\Psi)^2}{r^2}.
\]

若存在两个简单径向转折点 `r_-<r_+`，径向一个完整周期对应的方位旋转角为

\[
\boxed{\Delta\phi=2\int_{r_-}^{r_+}
\frac{P_\phi-q\Psi(r)}{r^2\sqrt{p^2-(P_\phi-q\Psi(r))^2/r^2}}\,dr}.
\]

如果这个旋角是 `2πM/K`（`M,K` 互素的正整数），则 `K` 次径向周期后，平面完整位置与速度闭合，其中方位角绕行 `M` 圈。对于本轮，取 `M=5,K=4`，要求 `4Δφ=10π`。

此为满足轨道转折点与正则守恒前提时的**条件精确定理**。对给定外线圈具体参数是否存在解，需要求出实际根。

## 4. 第三项：用非线性射击找到指定线圈模型中的周期轨道

先调谐线性梯度 `n=9/25`，得到参考半径 `5.15310696822251 mm`，电流约 `643.444 A/线圈`，`νr=4/5`、`νz=3/5`。随后将运动设为平面，初始半径 `r0+30 µm`、初始切向速度 `0.1c`、零径向速度。积分相对论 Lorentz ODE，检测后续第 4 个径向极大点，用该时刻的方位角与 `10π` 的差作为射击残差。

将 `r0` 在以线性值为中心的 ±70 µm 范围内连续调整，同时对每个 `r0` 重新标定磁场电流。两端分别给出约 `−0.3214` 与 `+0.3424 rad` 的相位残差，表明存在数值夹逼。求解得到：

| 指标 | 理论数值 |
|---|---:|
| 线性共振半径 | `5.15310696822251 mm` |
| 非线性平面周期半径 | `5.153022596900997 mm` |
| 修正量 | `−84.3713215 nm` |
| 实际径向初始偏移 | `30 µm` |
| 求得的4次径向/5圈周期 | `5.40003921258 ns` |
| 方位角返回残差 | `5.33×10⁻¹⁴ rad` |
| 全状态位置返回残差 | `1.58×10⁻¹³ m` |
| 归一化速度返回残差 | `3.30×10⁻¹¹` |
| 正则角动量归一化漂移 | `3.53×10⁻¹¹` |

上面的极小残差是**给定求积外磁场模型的 ODE 求解精度**，不是严格区间算术存在性证明，不表示实际线圈制造具有这样的精度。由于模型源的离散求积误差，物理解释的可靠精度明显更低。

独立于 ODE 的守恒量约化积分，通过从磁通积分计算 `r_-` 与 `Δφ` 得到 `4Δφ−10π≈1.1×10⁻⁸ rad`，从不同数学路线支持了近似周期闭合，仍有端点消去误差。

## 5. 非线性偏离及源模型求积误差

对同时具有径向、轴向偏移、未经射击校正的线性 `n=9/25` 半径，固定五圈时间的返回残差随初始幅度增大明显增加。原先 V96 的 `10 µm` 双向扰动五圈返回误差约 `5.44×10⁻¹⁰ m`；本轮对 2–80 µm 做了多幅度扫描，结果记录于 `FIVE_TURN_NONLINEAR_DETUNING_THEORY.csv`。

源截面求积阶数为 `21` 与 `49` 时，求得的闭环半径相差约 `3.632×10⁻¹⁰ m`（0.363 nm），显著大于指定 ODE 返回位置的 `1.58×10⁻¹³ m`。较高阶 `37` 与 `49` 的结果相差约 `9.9×10⁻¹² m`，提示趋于收敛，但这仍不能代替解析误差界及真实线圈公差控制。

因此，不能声称观测精度或模型几何精度已达到 `10⁻¹³ m`。文件把源求积误差和 ODE 数值残差明确分开。

## 6. 稳定性：周期解存在不等于稳定

近共振返回映射的特征值可能紧贴单位圆，直接做差分 monodromy 时会严重病态，甚至随差分步长从略大于 1 的实特征值切换为近单位复特征值。因此仅凭有限误差的返回谱，**目前不能给出已严格证明的无限时间非线性稳定性结论**。

必须使用辛积分、Poincaré 映射、随机相位初值与更可靠的误差界对非线性周期轨道继续验证。非零垂直振荡的三维完整共振也尚未解决。

## 7. 能量：磁场不做功，辐射仍然存在

在给定 Lorentz ODE（忽略辐射反作用）中：

\[
\frac{d}{dt}(\gamma mc^2)=q\mathbf v\cdot(\mathbf v\times\mathbf B)=0.
\]

但经典 Liénard 公式给定该速度和轨道尺度后，估计每圈辐射约 `1.91×10⁻²⁸ J`；实际电子持续辐射，必须由外部电场/射频源补偿，否则不可能无限时维持一模一样的恒速周期解。

线圈电流规模仍高于 600 A/线圈，实际供电、冷却、机械应力、绝缘和辐射反作用都没有完成可制造设计。不存在“无需外部能量而永恒闭合”的证明。

## 8. 量纲审计与模型边界

- `n,νr,νz,a/N,b/N` 均无量纲；`ω` 单位 `s⁻¹`；`Pφ` 单位 `kg m²/s`；`qΨ` 同量纲。
- `qvB` 与 `mvω` 均具有力的 SI 量纲 `kg m/s²`。
- `Ψ=rAφ=∫rBz dr` 具有磁通量纲 `T m²`。
- 磁场曲率形成特定运动方向，**不是**已发现四种力之间的新耦合定律。
- 弱聚焦频率比依赖参考系、轨道与源场；它们并不是 Lorentz 标量意义下的时空本征不变量。
- 有质量电子实际三维速度 `0.1c<c`；与全部粒子三维速度恒为 `c` 的旧假说不同。
