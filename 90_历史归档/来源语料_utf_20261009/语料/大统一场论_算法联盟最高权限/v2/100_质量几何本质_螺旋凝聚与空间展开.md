## 核心概念

```
质量 = 光速运动的螺旋凝聚态
空间 = 螺旋的平铺展开态

直线 (ω=0, κ=0) → 空间 (m=0, 平直)
螺旋 (ω≠0, κ≠0) → 质量 (m=ℏω/c², 弯曲)
```

## 数学框架

**核心方程链**（全部严格推论）：

$$\kappa^2 + \tau^2 = \left(\frac{\omega}{c}\right)^2 = \left(\frac{mc}{\hbar}\right)^2$$

| 步骤 | 方程 | 来源 |
|:---|:---|:---|
| 1 | (ωR)² + v_z² = c² | 光速螺旋公理 |
| 2 | κ² + τ² = (ω/c)² | Frenet-Serret 恒等式 |
| 3 | m = ℏω/c² | Einstein-Planck 关系 |
| 4 | κ² + τ² = (mc/ℏ)² | 步骤 2+3 直接消元 |

**验证**：κ²+τ²=(ω/c)² 误差 0（机器零），(ω/c)²=(mc/ℏ)² 误差 3.53×10⁻²⁰¹
