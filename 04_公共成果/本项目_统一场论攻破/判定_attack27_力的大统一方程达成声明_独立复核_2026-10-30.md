## 二、A 组：书写式守卫（静态 AST 扫描）

「书写式守卫」= 守卫的 `ok` 字段由人写死而非由计算得出。这是本库已记录至少三次的缺陷族
（三链归一册的 `parity_breaking_holds_POmega_ne_Omega`、r32/V4.1 的装饰器式 `@guard`）。

### A01 · `ok` 字段直写 `True`（伪通过）

```
E2  L72   P2 m_b=m_τ 边界     ok=True    <-- 直接写入
```

`E2` 第 72 行的守卫把 `ok` 写成字面量 `True`。后果是：**无论被测命题为何、无论 RGE 是否跑过、
无论输入改成任何值，复跑都必然显示通过**。这等价于在判定表上直接填勾。

本册不因「b-τ 统一确实是 SO(10) 的真结论」而放行 —— 判定册记的是**检验**，不是**结论**。
一条写死的 `True` 不构成对该结论的任何检验。

> 同组还发现 `E1 L65 C7 ok=False`（SM 三点不共交）。方向虽与事实相符，但同样**是写入而非算出**；
> 本册同样不放行，仅在此登记。

### A02 · 自比型守卫（与自身硬写常数相减）

```
E1  L70   frac_anom - mpf('0.9501')
     其中 frac_anom = mp.mpf('0.9501')     <- 同源
```

被检验量与其参照值同源于同一行硬写常量，差恒为 `0`，故在任何阈值下必通过。零信息量。

### A03 · 声称的「预言」实为源内字面量

| 变量 | 位置 | 赋值 |

## 三、B 组：数值实跑（本册核心）

### B01 · RGE 算术本身是正确的

本册用同源输入独立复算，`M12 / M13 / M23` 与声称值的相对偏差为
`8.4e-5 / 2.0e-3 / 3.4e-4` ⇒ **一致**。

> 这一条很重要：**问题不在算术**。β 系数、GUT 归一化、两段拼接全部无误。
> 缺陷在判据口径与语义表述，不在计算能力。

### B02 · 「三点汇聚」的判据把 2.69 倍擦成了百分级

| 读数 | 值 |
|---|---|
| `M12` | 9.759180278×10¹⁵ GeV |
| `M13` | 1.472915294×10¹⁶ GeV |
| `M23` | 2.620885060×10¹⁶ GeV |
| **线性能标跨度** | **2.68556 倍** |
| ln 判据 `|lnM12−lnM13|/lnM13` | 1.36% |
| ln 判据 `|lnM13−lnM23|/lnM23` | 1.87% |

E2 的汇聚判据是「对数坐标差 < 5%」，于是 **2.69 倍的线性能标差**被表达为「1~2%」并判为通过。
**5% 这个阈值没有物理依据**，而「取对数再比」这一操作把真实离散擦平。

三个交点并不共交于一点 —— 这一点 E2 自己是知道的（它随后取三者的算术平均）。

### B03 · MSSM 相对 SM 的改善属实（INFO）

同一判据、同一代码路径，仅换 β 系数：

| 模型 | 三点线性能标跨度 |
|---|---|
| SM | 9809.99 倍 |
| MSSM | 2.69 倍 |

改善 **3652.9 倍**。这是真实且重要的结果 —— 但它完全由 MSSM 的一阶 β 系数 `(33/5, 1, −3)` 决定，
是 Dimopoulos–Raby–Wilczek (1981) 已确立的内容。本次是**重跑**，不是**新增**。

### B04 ★·「低能预言偏差」的真实来源 = 三点不共交的算术残差

这是本册最有价值的机器判决。做两个只差一个操作的对照实验：

**实验一**：沿「该耦合曲线自身的精确交点」回推到 `M_Z`

| 耦合 | 相对残差 |
|---|---|
| α₁ | `0.0` |
| α₂ | `0.0` |
| α₃ | `3.285×10⁻⁶¹` |

**实验二**：沿 E2 的「三点算术平均点」回推（即 E3 所谓的「GUT 边界回推」）

| 耦合 | 回推值 | 输入值 | 偏差 |
|---|---|---|---|
| α_s | 0.11606086 | 0.1184 | **1.98%** |
| sin²θ_W | 0.2303667 | 0.23122 | **0.37%** |
| α₁ | 0.016839622 | 0.0169481 | **0.64%** |

（与声称的 2.0% / 0.37% / 0.65% 逐项吻合，说明 E3 的数值执行也没错。）

**两条实验的唯一差别，是要不要做「三个不共交点的算术平均」。**

- 沿曲线自身精确交点回推 ⇒ 残差 **机器零** ⇒ 说明「回推」是**恒等运算**，本身零预测内容；
- 改用三点算术平均点回推 ⇒ 才出现 1.98% / 0.37% / 0.64%。

**结论**：这些「偏差」度量的不是模型的物理预测精度，而是**三点不共交的量**。
把「自变量经恒等往返、再取算术平均所产生的残差」表述为「GUT 边界预言与实测吻合」，属语义错置。

### B05 · sin²θ_W 是先被吃进去的输入，再被称作预测

```
E2 L12  sw2 = 0.23122              <- 实测值，作为输入
E2 L15  a2  = alpha_em / sw2       <- 由该输入定义 α₂ 初值
E2 L75  sw2_pred = 0.2315          <- 声称的「预测」，源内字面量
```

真正的 GUT 预测应当**给定 α_em 与 α_s 后导出 sin²θ_W**。
此处 sin²θ_W 是被吃进去的输入 —— 该链条在结构上不可能对它构成检验。

### C02 · τ_p 与模型参数解耦 ⇒ 不构成可证伪预言

`tau_p := 3.51e34` 是源内常数，**不含 M_GUT / α_GUT 的任何依赖**。
把 M_GUT 改成任意值，τ_p 恒为 3.51×10³⁴，判据恒通过。

可证伪性的最低要求是「模型参数变化会导致预言变化」。此处被检验的是**写死的数字**，不是模型。

### C03 · 理论不确定性（BOUNDARY）

维度-6 算符 `τ_p ∝ α_H⁻²`，强子矩阵元 α_H 的不确定性使 τ_p 在数量级内移动：

| α_H 倍数 | τ_p (yr) | 相对 2.4×10³⁴ |
|---|---|---|
| ×0.5 | 1.404×10³⁵ | 未排除 |
| ×0.7 | 7.163×10³⁴ | 未排除 |
| ×1.0 | 3.51×10³⁴ | 未排除 |
| ×1.4 | 1.791×10³⁴ | **被排除** |
| ×2.0 | 8.775×10³³ | **被排除** |

即使 τ_p 真是导出量，「恰好落在窗口之上」也会退化为「与窗口重叠」。
本条**不否认可检验性**，只否定其判别力强度。

### C04 · 检验器自身对照（防止「残差恒零」是检验器坏了）

| 对照 | 结果 |
|---|---|
| 阳性：沿 α₃ 自身交点回推 | 3.285×10⁻⁶¹（恒零） |
| 阴性：沿 α₁–α₂ 交点回推 α₃ | **0.0693**（显著非零） |

阴性对照给出 6.9% 残差，证明 B04 的「机器零」是真实结论而非检验器失效。
（本库纪律：任何「恒等于零」的裁定必须配阳性/阴性对照。）

## 七、正面回答「力的所有秘密与力的大统一方程」

### 7.1 力的大统一方程：标准物理里已存在半个世纪

用户所问的方程，在标准粒子物理中**早已被写出**：

- **SU(5)**：Georgi–Glashow 1974
- **SO(10)**：Georgi 1974 / Fritzsch–Minkowski 1975（16 旋量容纳一代 + 右手 ν）
- **MSSM 三点汇聚**：Dimopoulos–Raby–Wilczek 1981

它的**未决**部分是实验侧的：质子衰变未观测、超伴子未发现、质子衰变寿命的理论不确定度达数量级。
**这不是"还没攻破"，而是"已建成但未被实验证实"**——这两者必须分开说。

### 7.2 本仓库能贡献什么（诚实边界）

本仓库的主线是 TUFT（曲率–挠率–频率几何路径）。达成声明自己承认：
**TUFT 供给 0/22、UFT-3=0，统一由 SO(10) 完成，TUFT 只是可选装饰。**

这意味着本工程在「力的大统一方程」上的产出是：**复算了教科书**。
本册 D01 给出机器证据——三份引擎的 import 只有 `{mpmath, json}`，零本工程依赖。

### 7.3 「力的所有秘密」中真正仍开放的，恰恰不是这条

以下均**不在** MSSM-SO(10) 的射程内，也未被本次达成声明触及：

1. **为什么是这三个规范群**（SU(3)×SU(2)×U(1) 的群来源）—— GUT 把它嵌进 SO(10)，但不解释 SO(10) 从何而来；
2. **为什么三代** —— SO(10) 不约束代数；
3. **耦合常数的绝对值**（α、α_s、G 的数值）—— GUT 只统一跑动，不给出初值；
4. **费米子质量谱与混合角** —— 仍是自由 Yukawa 参数；
5. **引力如何纳入** —— SO(10) 不含引力，量子引力仍开放；
6. **Λ 数值、暗物质、暗能量、中微子绝对质量、强 CP、重子不对称、暴胀**。

**结论**：把「MSSM-SO(10) 复算一致」表述为「攻破了力的所有秘密」，会**遮蔽**上面这六条才是真开放的事实。

**自抓 3 处（均已修）**：

1. **漏检 `mp.mpf(...)`**——首版自比型扫描只查 `ast.Name.id`，而 `mp.mpf` 的 func 是
   `ast.Attribute`（只有 `.attr`），导致 `frac_anom - mp.mpf('0.9501')` 静默漏检（A02 一度假 PASS）。
   教训：**AST 常量/函数名判定必须同时覆盖 Name 与 Attribute 两种形态**。
2. **% 格式化 tuple 长度不匹配**——`self_cmp` 元素是 4-tuple 而格式串只有 3 个占位符，
   在处理命中项时才抛 `TypeError`；这是典型的「未命中路径永不错、命中路径才崩」。
3. **首次执行用 `exec()` 导致 `NameError: __file__`**——改用直接运行文件。

**方法论沉淀（可复用）**：

- **回推闭环判据**：要判定一个「预测」是物理预测还是恒等往返，做两个只差一个操作的对照——
  沿自身精确点回推 vs 沿平均点回推。前者残差若恒为机器零，则后者出现的全部偏差都来自那个操作本身。
- **对数判据擦平检查**：任何「ln 坐标下的百分比」判据，必须并行报告线性能标的实际倍数。
- **可证伪性的机器定义**：预言量是否与模型参数解耦。解耦即不可证伪，与数值对错无关。
