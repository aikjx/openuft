## 一、先撤回：r385 的 E02 修错了方向

### 1.1 出错的机制

r385 同时用了两套角度定义，而它们并不等价：

| | 定义 | 曲率挠率参数化 | 被积密度 | 导数 | 内点驻点 |
|---|---|---|---|---|---|
| 约定 A | `theta_A = atan(kappa/tau)` | `kappa=(w/c)sin`，`tau=(w/c)cos` | `N_A=a1 s^2+a2 c^2+g c` | `N_A' = sin*[2(a1-a2)cos - g]` | `g* = 2(a1-a2)cos(theta_A*)` |
| 约定 B | `theta_B = atan(tau/kappa) = pi/2 - theta_A` | `kappa=(w/c)cos`，`tau=(w/c)sin` | `N_B=a1 c^2+a2 s^2+g s` | `N_B' = cos*[2(a2-a1)sin + g]` | `g* = 2(a1-a2)sin(theta_B*)` |

因为 `sin(theta_B*) = cos(theta_A*)`，**两套给同一个物理值**（A02/A03 精确验证，两套残差同时为 0）。r385 的 A 层用约定 A 定义 θ（`A04: theta=atan(kappa/tau)`），B 层却用约定 B 的公式，再把约定 A 的角度代进去。

### 1.2 后果

| 量 | r385 报出 | 正确 | 说明 |
|---|---|---|---|
| `g* = G1*/(hbar w)` | `-2.91886331204E-02` | **`-3.9998935015443`** | 相差 `cot(theta_A*)` |
| 量级 | 宣称 `O(alpha)` | **`O(1)`** | 3.9999 不是小量 |
| 耦合上界 | 宣称「从不 binding」 | **用掉 99.9973%** | 几乎饱和 |
| 「差 137 倍」 | 当作 `1/alpha` 出现 | **恒等式，零信息** | 见 §1.3 |

**必须撤回的三条叙述**：① 内点耦合是 `O(alpha)`；② 上界 `|g| <= 2|a1-a2|` 从不 binding；③「两个读数差 137 倍 ≈ 1/α」是结构证据。

### 1.3 第二层问题：137 是定义恒等式

`cot(theta_A*) = cot(arctan(alpha)) = 1/alpha` **精确成立**（B03：比值 `1.37035999084E+002` 与 `1/alpha` 逐位相同）。所以那个 137 倍不是巧合，是「输入里已经有 α，输出的初等函数又把它带回 1/α」——**零信息**。

这是「定义恒等式刀」在本库的第 5 次命中（E05）。凡是「算出一个著名常数」，第一件事是查这个常数的定义式里是否已经含它。

### 1.4 没有受影响的部分

r385 的四条结构性结论仍然成立（B10）：**判别力 0、不占度、θ 零模、唯一内禀尺度**。撤回只动 `g*` 的量值与「饱和」叙述。

修正后的新结论反而更有意思：

> `g*` 几乎顶到允许上界（`|g*|/gmax = cos(theta_A*) = 0.9999734`）。而 `g*` 取满上界时内点驻点与边界解 `theta_A=0`（纯圆）**合并**。也就是说：物理点（`theta_A = arctan(alpha) = 0.0073`）离这条分支的终止点只有 **α** 那么远。

这直接回答了 r385 的 `X-R385-4`（θ 零模稳定性）：物理点不是稳定的内点，而是紧贴分支端点的近简并点。

## 二、定理 A：同域第二方程不存在（`X-R385-1` 的第一半）

问：能不能再写一条**只由 `(kappa,tau)` 构造**、且在零模曲面上恒成立的方程，用来选 θ？

答案：**不能，而且这是可证的**。

| 步 | 内容 | 机核 |
|---|---|---|
| 1 | `f = kappa^2+tau^2-K` 在 `Q[kappa,tau]` 中不可约 | `ad=be=1` 与 `ae+bd=0` 逼出 `e^2=-d^2`，Q 上 `d,e != 0` 无解（A06） |
| 2 | `f` 不可约 ⇒ `(f)` 是素理想 | 标准代数 |
| 3 | Nullstellensatz：`G` 在 `V(f)` 上恒零 ⇔ `G` 属于 `(f)` | 引用，配合步 1 |
| 4 | 机核判据：`G` 属于 `(f)` ⇔ 用 `kappa^2 -> K-tau^2` 做除法归约后余式为空 | 归约器双重守卫（RED-ENGINE / RED-NEGCTL） |
| 5 | 族 `G = f + lam*(kappa*tau - m)`：15 组里只有 `lam=0` 的 3 组余式为空 | A07 |
| 6 | `lam != 0` 时余式含 `kappa` 一次项；`V(f)` 上 `(kappa,tau)` 与 `(-kappa,tau)` 使其反号 ⇒ 不可能恒零 | A08，`v1 = -v2 != 0` |
| 7 | 「选 θ」的约束 `\|kappa/tau - tan(theta*)\|=0` 在 6 个零模点上只命中 1 个 | A09 |

**结论**：任何要在零模解集内部再切一刀的方程，要么是 `f` 的倍数（等价，没有新信息），要么**必然在某些零模点取非零值**（那就不是「恒成立的约束」，而是带来了新数据）。后者正是 `|kappa/tau - tan(theta*)|` 的情形：它必须携带目标 `theta*` 作输入。

> 这句话可以压缩成一句：**能唯一选出 θ 的方程，一定已经把 θ 装进去了。**

这一条把 r385 的「余维 1、未知 2」从计数论证升级为**代数不可能性定理**。

在现有的全部候选里，只有一个同时满足「第二条独立方程」和「不含新自由参数」：

## 四、它钉不钉 θ：取决于 ω 算不算输入

| 情形 | 未知 / 方程 | 维数 | θ 的命运 |
|---|---|---|---|
| `omega` 自由 | 3 / 2 | **1** | **满射**，判别力 0 |
| `omega` 由 `E=hbar*w` 给定 | 2 / 2 | **0** | **被钉死**，且只留 `n=1` |

### 4.1 ω 自由：构造性满射

`x := R w`，则 `tan(theta_A) = x / sqrt(c^2 - x^2)`。对任意目标 `T`，反解 `x = T/sqrt(1+T^2)`，回代相对偏差 `4.5E-38`（B04，六档 `T` 从 `1e-6` 到 `1e6`）。`x` 从 0 到 `c` ⇒ `tan` 从 0 到 `∞` ⇒ θ 覆盖整个 `(0, pi/2)`。

> 这是**构造性**满射，不是"扫了一遍没找到反例"。

### 4.2 ω 给定：只留 n=1，且 θ=0

`omega = w_C = m c^2/hbar` 时，`n hbar w/m = n c^2`，于是 `u^2 = c^2(1-n)`：

| n | `u^2/c^2` |
|---|---|
| 1 | `0`（纯圆，`theta_A = 0`） |
| 2 | `-1` |
| 3 | `-2` |
| 4 | `-3` |

`n >= 2` **无实解**。所以「频率给定 + 角动量量子化」把世界线钉成唯一一条：**纯圆**，`u=0`。

### 4.3 它与 α 锚定的关系：差 α，不可反推

`theta_A` 严格为 0（G08），而库内 α 锚定给 `theta_A = arctan(alpha) = 0.0073`。两者**恒差 α**（G09 FAIL）。因此：

> 不能用「频率给定 + 角动量量子化」去反推 α。它不是「α 的推导」，而是「α 被假设」之后的一个自洽分支。

### 4.4 `R = a0` 是口径差，不是预言

在 `omega` 自由、`theta_A = arctan(alpha)`、`n=1` 的解上：

| 量 | 值 |
|---|---|
| `omega` | `4.13391719935E+16` rad/s |
| `R` | `5.29191300094E-11` m |
| `u` | `2.9978448E+08` m/s |
| 玻尔半径 `a0` | `5.29177210580E-11` m |

`R` 与 `a0` 的相对差 `2.66253E-5`，而 `alpha^2/2 = 2.66257E-5`（B07：落在这条二阶级数的交错区间内）。原因是 `R = (hbar/(m alpha c))*sqrt(1+alpha^2)`，展开首项就是 `alpha^2/2`。

**这不是新尺度，是「α 三口径互差 `alpha^2/2`」的同一条**（整理册 §1 与 r385 G07 同源）。看起来像"算出玻尔半径"，实际是定义式往返（E04）。

## 五、为什么"能钉住"不是优点：量纲负对照

把角动量**少写一个 R**，写成 `m R w = n hbar`（量纲是动量，不是角动量），则 `R w` 被钉死：

| | `m R^2 w`（正确） | `m R w`（少一个 R） |
|---|---|---|
| 量纲 | `(1,2,-1)` = 角动量 | `(1,1,-1)` = 动量（C04） |
| 结果 | `R w` 自由 ⇒ θ 满射 | `R w` 固定 ⇒ `u ≈ c`、`theta_A ≈ pi/2`（B08） |

**「能钉住 θ」是量纲错误的副产品**。这条负对照的意义是：判据「是否能定出唯一值」本身不带方向——一个错的方程比对的方程"更能定值"。所以"能定值"永远不能当作正确性的证据。

- **灾难性相消**：B04 首版用 `u = sqrt(1-x^2)` 回代，`x -> 1` 时把自己的舍入误差放大成 `4.5E-38` 的相对偏差，被误判 FAIL。正解是改用 `1/u = sqrt(1+T^2)` 直接回代。**精度不足会把自身误差误判成错**（与 MEMORY 既有条目同族）。

## 八、遗留 OPEN

- **`X-R387-1`**：定理 A 只覆盖 `(kappa,tau)` 的多项式（及由素理想推出的解析函数）。若允许**积分型**泛函（如 `∫ kappa ds` 的总挠率 `∫tau ds`），它在 `V(f)` 上是否可能给出新约束？初步看不行（它们仍是零模曲面上的函数），但未机核。
- **`X-R387-2`**：`g` 的物理来源。若手性项来自挠率拓扑荷，`g` 应量子化 ⇒ 上界 `2|a1-a2|` 与 `cos(theta_A*)` 的近乎饱和会变成一条**整数方程** `n_g = 2|a1-a2|cos(theta_A*)`，那才是真正可能定出 θ 的结构。这是本卷指出但未走通的路。
- **`X-R387-3`**：`omega` 到底算不算输入？这是 §4 两个分支的分水岭，而框架本身没说清（r383 用 `E=hbar*w` 把 ω 当内禀量，r385 又把 ω 当自由参数）。**这条不澄清，任何"钉住 θ"的结论都不可靠。**
- **`X-R387-4`**：近简并点的物理后果。`|g*|/gmax = cos(theta_A*)` 意味着物理点紧贴分支端点；若 `g` 有涨落，θ 会跨过端点跳到 `theta_A = 0` 分支。这是可算的稳定性问题。
