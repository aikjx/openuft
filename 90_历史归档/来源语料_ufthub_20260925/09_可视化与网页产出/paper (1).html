1 引言

经典电磁理论中，柱坐标下的麦克斯韦波动方程在圆波导/谐振腔边界条件下导出贝塞尔型本征模态。本文在这一数学基础上，引入两个额外物理假设：

  1. 纵向拓扑闭环：磁场沿 $z$ 方向满足周期 $L$ 上的周期性，即 $k_n = 2\pi n/L$ 量子化；
  2. 螺旋光速运动诠释：磁场流形沿半径 $a$、螺距 $b$ 的螺旋轨迹以光速 $c$ 运动，即 $v = \omega\sqrt{a^2+b^2} = c$。

这两个假设将连续波数量子化为离散谱，并将场的波动诠释为闭环螺旋流形的光速运动。本文完整推导其数学自洽性，并给出数值验证。

2 推导全链路

2.1 麦克斯韦方程组到波动方程

真空中无外源麦克斯韦方程组：

$$\nabla\cdot\mathbf{E}=0,\quad \nabla\cdot\mathbf{B}=0,\quad \nabla\times\mathbf{E}=-\frac{\partial\mathbf{B}}{\partial t},\quad \nabla\times\mathbf{B}=\frac{1}{c^2}\frac{\partial\mathbf{E}}{\partial t}$$

对法拉第定律两边取旋度，利用矢量恒等式 $\nabla\times(\nabla\times\mathbf{E})=\nabla(\nabla\cdot\mathbf{E})-\nabla^2\mathbf{E}$ 及 $\nabla\cdot\mathbf{E}=0$：

$$\nabla^2\mathbf{E} = \frac{1}{c^2}\frac{\partial^2\mathbf{E}}{\partial t^2}$$

对 $\mathbf{B}$ 同理。这就是电磁波动方程。

2.2 时谐场与亥姆霍兹方程

设时谐场 $\mathbf{B}(\mathbf{r},t)=\tilde{\mathbf{B}}(\mathbf{r})e^{-i\omega t}$，代入波动方程得亥姆霍兹方程：

$$\nabla^2\tilde{\mathbf{B}} + k_0^2 \tilde{\mathbf{B}} = 0,\qquad k_0 = \frac{\omega}{c}$$

2.3 柱坐标分离变量

在柱坐标 $(r,\theta,z)$ 下设 $\tilde{\mathbf{B}}(r,\theta,z)=R(r)\Theta(\theta)Z(z)$。柱坐标拉普拉斯算子为：

$$\nabla^2 = \frac{1}{r}\frac{\partial}{\partial r}\left(r\frac{\partial}{\partial r}\right) + \frac{1}{r^2}\frac{\partial^2}{\partial\theta^2} + \frac{\partial^2}{\partial z^2}$$

代入亥姆霍兹方程并除以 $R\Theta Z$，分离三个常微分方程：

定理 1（角向方程）

$\displaystyle \frac{1}{\Theta}\frac{d^2\Theta}{d\theta^2} = -m^2 \quad\Longrightarrow\quad \Theta(\theta) = C\,e^{im\theta}$

证明（角向闭环）：场的单值性要求 $\Theta(\theta+2\pi)=\Theta(\theta)$，即 $$e^{im(\theta+2\pi)}=e^{im\theta}\Rightarrow e^{i2\pi m}=1\Rightarrow m\in\mathbb{Z}$$ $\blacksquare$
定理 2（纵向方程）

$\displaystyle \frac{1}{Z}\frac{d^2Z}{dz^2} = -k^2 \quad\Longrightarrow\quad Z(z) = D\,e^{ikz}$

证明（纵向闭环）：周期 $L$ 上闭环要求 $Z(z+L)=Z(z)$，即 $$e^{ik(z+L)}=e^{ikz}\Rightarrow e^{ikL}=1\Rightarrow k_n L=2\pi n\Rightarrow k_n=\frac{2\pi n}{L},\quad n=1,2,3,\ldots$$ $\blacksquare$
定理 3（径向方程——贝塞尔方程）

代入分离常数后径向部分满足： $$r^2 R'' + r R' + (\kappa^2 r^2 - m^2)R = 0,\qquad \kappa^2 = k_0^2 - k^2 = \frac{\omega^2}{c^2}-k^2$$ $r=0$ 处有限性排除第二类贝塞尔函数 $Y_m$，故 $R(r)=A\,J_m(\kappa r)$。

证明（SymPy 符号验证）：将 $R=J_m(\kappa r)$ 代入方程，SymPy 计算返回严格为 0 的残差： $$r^2 J_m'' + r J_m' + (\kappa^2 r^2 - m^2)J_m = 0 \quad \checkmark$$ $\blacksquare$

3 闭环螺旋光速约束

3.1 螺旋几何

螺旋轨迹定义为 $r=a$，$z=b\theta$。弧长元：

$$ds = \sqrt{dr^2 + r^2 d\theta^2 + dz^2} = \sqrt{0 + a^2 d\theta^2 + b^2 d\theta^2} = \sqrt{a^2+b^2}\,d\theta$$

3.2 光速约束

若场沿螺旋以角速度 $\omega$ 运动（$\theta=\omega t$），则线速度：

$$v = \frac{ds}{dt} = \omega\sqrt{a^2+b^2}$$

设 $v=c$，得：

$$\omega_n = \frac{c}{\sqrt{a^2+b^2}}$$

3.3 相位匹配与螺距量子化（关键发现）

注意：沿螺旋轨迹，相位 $\phi=m\theta-k_n z-\omega t=(m-k_nb)\theta-\omega t$。若场以角速度 $\omega_{\text{rot}}$ 沿螺旋运动，刚性运动（恒定相位）要求： $$(m-k_nb)\omega_{\text{rot}}=\omega$$ 线速度 $v=\omega_{\text{rot}}\sqrt{a^2+b^2}$。若直接令 $\omega_{\text{rot}}=\omega$，则隐含： $$m-k_nb=1\quad\Longrightarrow\quad b=\frac{m-1}{k_n}=\frac{(m-1)L}{2\pi n}$$ 这是一个额外的螺距量子化条件。若不满足，则光速约束应修正为 $\omega = c(m-k_nb)/\sqrt{a^2+b^2}$。

3.4 传播条件

$$\kappa^2 = \frac{\omega^2}{c^2}-k_n^2 = \frac{1}{a^2+b^2} - \left(\frac{2\pi n}{L}\right)^2 \geq 0$$

由此得传播模态数上限：

$$n \leq n_{\max} = \left\lfloor \frac{L}{2\pi\sqrt{a^2+b^2}} \right\rfloor$$

关键差异：

  • 径向量子化：传统理论由金属壁边界 $J_m(\kappa R)=0$ 量子化 $\kappa$；本算法无径向壁，$\kappa$ 由色散关系和光速约束确定。
  • 纵向量子化：传统波导 $k$ 连续取值；本算法引入周期 $L$ 后 $k_n=2\pi n/L$ 离散。
  • 频率关系：传统 $\omega^2=c^2(k^2+\kappa^2)$ 是色散曲面；本算法由光速约束将 $\omega$ 固定为 $c/\sqrt{a^2+b^2}$。
  • 物理图像：传统是腔体内的导行波；本算法将场诠释为沿闭环螺旋以光速运动的流形。

6 算法伪代码

ALGORITHM ClosedLoopSpiralModes(a, b, L, c, m_max, n_max): INPUT: helix radius a, pitch b, period L, speed c, max m,n OUTPUT: propagating modes list ds = sqrt(a² + b²) omega = c / ds k0 = omega / c modes = [] FOR n = 1, 2, ..., n_max: k_n = 2π * n / L FOR m = 0, ±1, ±2, ..., ±m_max: # phase matching pitch IF m == 0: b_nm = 0 ELSE: b_nm = (m - 1) / k_n # propagation condition kappa² = 1/(a² + b_nm²) - k_n² IF kappa² ≥ 0: kappa = sqrt(kappa²) mode = {n, m, k_n, kappa, omega, b_nm} modes.append(mode) END IF END FOR END FOR RETURN modes

7 结论
