# ROOT V116 更新与修复

1. 从 V115 原始 ZIP 实际提取基础问题和 396 项原始台账；不更改任何历史科学状态。
2. 将 V115 的 QCD 单圈尺度与 V113 的 Brans–Dicke Cassini 限制放入同一个正动能、普遍物质耦合的协变标量–张量作用量，得到明确的条件性 no-go。
3. 修复 V115 在长程标量尚未冻结时以 EH 系数直接校准实测 Newton G 的不一致：改为 G_N=(1+α_phi²)/(8πF)。
4. 证明无质量纯诱导引力 ω=1/(4ξ)、γ=(1+4ξ)/(1+8ξ)；对给定 Cassini 简化 2σ 区间反推 ξ 上限。
5. 增加独立 EH 项后推导诱导份额上限 ≈9×10^-23（QCD 固定五味单圈 VEV 示例，长程标量条件）。
6. 区分光学势、局部度规比值及轨道质量校准；避免把 1AU 的局部 Yukawa 示例错当 Cassini 真实质量限。
7. 增加 QCD 单圈的 SymPy RG 恒等式核验、参数限制、失败输入测试、自动生成曲线和离线页面。
8. 修正初轮自动测试的相对/绝对容差及未完全化简符号式比较；不将测试设计错误误判为物理失败。
9. 对所有主要物理式标注适用范围、已知理论来源和无新预言的边界。
