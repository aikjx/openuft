## 一、参数定义

### 1.1 空间本征曲率 κ

**符号**: κ (kappa)

**数值**: 
```
κ = 3.162277660168379 × 10⁻⁴ m⁻¹
```

**量纲**: [L⁻¹]

**定义**: κ 是描述本源空间 Ω 弯曲程度的几何量，定义为空间单位长度内的曲率变化率。

**物理意义**:
- 空间"刚性"的度量
- 引力效应的几何本源
- 决定真空磁导率：μ₀ = 4πκ²

### 1.2 空间本征挠率 τ

**符号**: τ (tau)

**数值**:
```
τ = 2.307625500826972 × 10⁻⁶ m⁻¹
```

**量纲**: [L⁻¹]

**定义**: τ 是描述本源空间 Ω 扭曲程度的几何量，定义为空间单位长度内的挠率变化率。

**物理意义**:
- 空间"柔韧性"的度量
- 电磁效应的几何本源
- 决定精细结构常数：α = τ/κ

### 1.3 光速 c

**符号**: c

**数值**:
```
c = 299792458 m/s
```

**量纲**: [LT⁻¹]

**定义**: c 是空间本体运动的永恒速度，是信息传播的极限速度。

**物理意义**:
- 空间几何的内禀属性
- 连接时间与空间的基本常数
- 所有物理定律的协变基准
