# V74 权威来源、性质与数据边界（2026-11-17）

1. **NIST/CODATA 2022**（数值常数实测/调整）：https://www.nist.gov/publications/codata-recommended-values-fundamental-physical-constants-2022。`G=6.67430(15)e-11` 是输入，不是理论预测。
2. **PDG 2026 标准模型**（既有理论和实验综述）：https://pdg.lbl.gov/2026/reviews/standard_model_and_related.html。规范群、三代、各耦合属于已确立物理基线。
3. **PDG 2026 总目录**：https://pdg.lbl.gov/2026/。统一理论必须满足粒子谱及实验限制。
4. **MICROSCOPE 最终观测**（真实实验）：https://pubmed.ncbi.nlm.nih.gov/36179190/。η(Ti,Pt)=(-1.5±2.3_stat±1.5_syst)×10^-15。
5. **NASA Sun/Earth Fact Sheet**（质量与半径参考）：https://nssdc.gsfc.nasa.gov/planetary/factsheet/sunfact.html?level=1。
6. **David Tong GR Notes**（Schwarzschild 与曲率不变量的教学推导）：https://www.damtp.cam.ac.uk/user/tong/gr/grhtml/S6.html。

**非外部观测**：白矮星、中子星是人为代表数值；所有 Yukawa α、λ、源荷 q、RG 紫外输入、Gauss–Bonnet 标量参数都是模型设定或演示数据。天体模型无精密自转、多极矩及真实密度剖面，不能当成高精度地球物理数据库。
