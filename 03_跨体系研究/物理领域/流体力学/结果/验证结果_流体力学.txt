【FM1】流体静力学
----------------------------------------------------------------------

  流体力学概述：

  流体力学是研究流体（液体和气体）运动规律及其与固体相互作用的学科。
  它是连续介质力学的重要分支，在航空航天、海洋、气象、生物医学等领域有广泛应用。

  流体力学的主要分支：
    - 流体静力学：静止流体的力学
    - 流体动力学：运动流体的力学
    - 空气动力学：气体流动
    - 水力学：液体流动
    - 计算流体力学（CFD）：数值模拟
    - 磁流体力学（MHD）：导电流体
    - 非牛顿流体力学：非牛顿流体行为

  流体基本性质：

  1. 密度 ρ = m/V：
     - 水：1000 kg/m³
     - 空气：1.225 kg/m³（15°C海平面）
     - 水银：13600 kg/m³

  2. 黏度 μ：
     - 水：8.9×10⁻⁴ Pa·s（20°C）
     - 空气：1.81×10⁻⁵ Pa·s
     - 蜂蜜：~10 Pa·s
     - 动力黏度 vs 运动黏度：ν = μ/ρ

  3. 可压缩性：
     - 液体：近似不可压缩
     - 气体：可压缩
     - 马赫数 Ma = v/c_sound 衡量压缩性影响

  流体静力学基本方程：

  静止流体中的压强分布：
    dp/dz = -ρg
    对于不可压缩流体：p = p₀ + ρgh
    对于大气：p = p₀ exp(-z/H)（等温近似）

  水压计算：
    深度 h = 10.0 m
    压强 p = p₀ + ρgh = 1.97 atm

  Pascal原理：
    封闭容器中流体压强处处相等
    应用：液压机 F₂/F₁ = A₂/A₁

  Archimedes原理：
    浮力 = 排开流体重量：F_B = ρ_fluid g V_displaced
    应用：船、潜艇、气球

  浮力计算：
    排开体积 V = 50.0 m³
    浮力 F_B = ρgV = 490.3 kN

  螺旋几何化解释：

  1. 流体静力学的螺旋几何化
     - 压强 = 流体分子螺旋运动的动量传递
     - 静水压 = 螺旋分子碰撞的统计结果
     - 浮力 = 螺旋分子密度差产生的净力

  2. 分子运动与螺旋
     - 分子 = 内部光速螺旋的粒子
     - 热运动 = 螺旋分子的随机平移
     - 压强 = 螺旋分子对壁面的碰撞
     - 温度 = 螺旋分子平均动能

【FM2】流体动力学
----------------------------------------------------------------------

  流体动力学基础：

  理想流体（无黏、不可压缩）的流动：

  连续性方程（质量守恒）：
    ρ₁A₁v₁ = ρ₂A₂v₂

  Bernoulli方程（能量守恒）：
    p + ½ρv² + ρgz = 常数

  三项物理意义：
    - p：静压强（压强能）
    - ½ρv²：动压强（动能）
    - ρgz：位置水头（势能）

  Bernoulli计算（水平管）：
    v₁ = 1.0 m/s, v₂ = 3.0 m/s
    p₂ = p₁ + ½ρ(v₁²-v₂²) = 0.9605 atm
    压差 Δp = 4.00 kPa

  连续性方程应用——文丘里管：
    A₁v₁ = A₂v₂
    缩颈处速度增大，压强降低
    应用：流量计、飞机机翼（升力）

  Reynolds数：

  Re = ρvL/μ = vL/ν
    其中 L 是特征长度，ν = μ/ρ 是运动黏度

  流动状态判据：
    Re < 2300：层流
    2300 < Re < 4000：过渡流
    Re > 4000：湍流

  Reynolds数计算：
    水管（D=5cm, v=1m/s）：Re = 56180（湍流）
    气管（D=5cm, v=1m/s）：Re = 3384（过渡流）

  层流流动（Hagen-Poiseuille）：

  圆管层流速度分布（抛物线）：
    v(r) = (Δp/4μL)(R² - r²)

  体积流量：
    Q = πR⁴Δp/(8μL)

  Poiseuille定律：Q ∝ R⁴
    半径减半 → 流量降为1/16
    对血管流动有重要生理意义

  Poiseuille流量计算：
    管半径 R = 1.0 cm, 管长 L = 1.0 m
    压差 Δp = 1000.0 Pa
    流量 Q = 4412.3 mL/s

  螺旋几何化解释：

  1. 流体动力学的螺旋几何化
     - 流线 = 流体元的螺旋运动轨迹
     - 涡量 = 流体旋转的螺旋结构
     - 环量 = 螺旋流场的循环积分
     - 升力 = 环量产生的螺旋效应（Kutta-Joukowski）

  2. 涡旋与螺旋
     - 涡 = 流体绕轴线的螺旋运动
     - 自由涡：v_θ = Γ/(2πr)
     - 强迫涡：v_θ = ωr
     - 龙卷风 = 大气中的螺旋涡旋
     - 螺旋桨/涡轮 = 人工螺旋流动装置

  3. 升力的螺旋解释
     - 机翼 = 产生环量的螺旋剖面
     - Kutta-Joukowski定理：L = ρvΓ
     - 升力 = 环量×动量的螺旋叉积

【FM3】Navier-Stokes方程
----------------------------------------------------------------------

  Navier-Stokes方程：

  Navier-Stokes方程是描述黏性流体运动的基本方程：

  矢量形式（不可压缩）：
    ρ(∂v/∂t + v·∇v) = -∇p + μ∇²v + ρg

  分量形式：
    连续性：∇·v = 0
    动量：ρ Dv/Dt = -∇p + μ∇²v + ρg

  各项物理意义：
    - ρ∂v/∂t：非定常项（局部加速度）
    - ρ(v·∇)v：对流项（惯性）
    - -∇p：压力梯度力
    - μ∇²v：黏性力（扩散）
    - ρg：体积力

  无量纲参数：

  Reynolds数：Re = ρvL/μ（惯性/黏性）
  Froude数：Fr = v/√(gL)（惯性/重力）
  Euler数：Eu = Δp/(ρv²)（压差/惯性）
  Mach数：Ma = v/c（流速/声速）
  Weber数：We = ρv²L/σ（惯性/表面张力）
  Rossby数：Ro = v/(fL)（惯性/科里奥利）

  Millennium问题（七大千禧年难题之一）：

  Navier-Stokes光滑解的存在性与唯一性（Clay数学研究所，100万美元）：
    - 问题：3维不可压缩Navier-Stokes方程是否存在全局光滑解？
    - 光滑解：速度场和压强场无限可微
    - 3维情况尚未解决（1维和2维已解决）
    - 关键困难：湍流的非线性能量级串

  物理意义：如果解不唯一，则经典流体力学方程需要修正

  Stokes流（低Reynolds数）：

  Re << 1时，惯性项可忽略：
    ∇p = μ∇²v（Stokes方程）

  Stokes阻力：
    F_drag = 6πμRv（球体）
    F_drag = 6πμRv·(1+3Re/8+...)（Oseen修正）

  沉降速度（Stokes沉降）：
    v_s = (2R²g(ρ_p-ρ_f))/(9μ)

  Stokes沉降计算：
    颗粒半径 R = 10.0 μm, 密度 ρ = 2000.0 kg/m³
    沉降速度 v_s = 0.24 mm/s

  螺旋几何化解释：

  1. Navier-Stokes的螺旋几何化
     - 对流项 v·∇v = 螺旋流场的惯性弯曲
     - 黏性项 μ∇²v = 螺旋速度的扩散
     - 涡量方程 = 螺旋涡度的输运
     - 能量耗散 = 螺旋动能转化为内能

  2. 涡量动力学
     - 涡量 ω = ∇×v：螺旋旋转的矢量场
     - 涡线 = 螺旋涡场的积分曲线
     - 涡管 = 螺旋涡线的管状集合
     - Helmholtz定理：涡管强度守恒

  3. 湍流的螺旋结构
     - 湍流 = 多尺度螺旋涡的级串
     - Kolmogorov级串：能量从大涡到小涡
     - 螺旋度 = 湍流的手征性
     - 湍流中螺旋结构普遍存在（龙卷风、旋涡）

【FM4】湍流
----------------------------------------------------------------------

  湍流概述：

  湍流是流体在高Reynolds数下的不规则流动状态：
    - 随机性：速度场时间空间不规则
    - 扩散性：湍流增强动量/热量/质量扩散
    - 耗散性：湍流能量最终耗散为热能
    - 多尺度性：涡从大到小级串
    - 三维性：湍流是本质三维的
    - 连续性：湍流仍是连续介质现象

  Reynolds实验（1883）：

  染色线实验发现：
    - 低流速：染色线直线（层流）
    - 中等流速：染色线波动（过渡流）
    - 高流速：染色线破碎混合（湍流）
    - 临界Reynolds数：Re_c ≈ 2300（圆管）

  Kolmogorov理论（1941）：

  K41理论的三大假设：
    1. 局域各向同性：小尺度湍流各向同性
    2. 自相似性：惯性区涡结构自相似
    3. 能量耗散率：ε = 常数（不依赖尺度）

  Kolmogorov标度律：
    - 能量谱：E(k) = C_K ε^(2/3) k^(-5/3)
    - 速度结构函数：⟨|δv(l)|²⟩ = C ε^(2/3) l^(2/3)
    - Kolmogorov长度：η = (ν³/ε)^(1/4)
    - Kolmogorov时间：τη = (ν/ε)^(1/2)

  Kolmogorov尺度计算（水，ε=1 m²/s³）：
    运动黏度 ν = 8.90e-07 m²/s
    Kolmogorov长度 η = 29.0 μm
    Kolmogorov时间 τη = 0.94 ms

  湍流能量级串：

  能量从大尺度注入，经过惯性区级串，在耗散区耗散：
    - 含能尺度 L：能量注入尺度（~流动特征尺度）
    - 惯性区：L >> l >> η，无黏性无外力
    - 耗散尺度 η：黏性耗散主导
    - 级串时间尺度：每个涡的寿命 ~ l/v_l

  大涡模拟（LES）：
    - 直接数值模拟（DNS）：分辨所有尺度（Re^(9/4) 格点数）
    - LES：解析大涡，模拟小涡（亚格子模型）
    - RANS：时间平均方程（Reynolds平均）

  螺旋几何化解释：

  1. 湍流的螺旋几何化
     - 湍流涡 = 螺旋涡旋的多尺度级串
     - Kolmogorov级串 = 螺旋涡的能量传递
     - 螺旋度 = 湍流手征性（三维拓扑不变量）
     - 湍流耗散 = 螺旋运动的能量耗散

  2. 螺旋度在湍流中的作用
     - 螺旋度 H = ∫v·ω dV（速度与涡量的螺旋内积）
     - 理想流体中螺旋度守恒（三维拓扑不变量）
     - 螺旋度影响湍流级串效率
     - 螺旋涡 = 湍流的螺旋结构单元

  3. 螺旋涡管模型
     - 涡管 = 螺旋涡线束
     - 涡丝 = 细涡管（~η尺度）
     - 涡环 = 环形涡管（螺旋拓扑）
     - 螺旋涡的相互作用 = 湍流的微观机制

【FM5】边界层与流体中的波
----------------------------------------------------------------------

  边界层理论：

  Prandtl边界层理论（1904）：
    高Reynolds数流动分为：
    - 边界层：紧贴固壁的薄层（黏性主导）
    - 外部流：边界层外的无黏流

  边界层厚度：
    层流边界层：δ(x) = 5.0x/√Re_x
    湍流边界层：δ(x) = 0.37x/Re_x^(1/5)

  边界层分离：
    逆压梯度下边界层从壁面分离
    产生尾流、阻力增加、升力丧失（失速）

  边界层厚度计算（平板，空气 v=10m/s）：
    Re_x = 6.77e+05
    层流边界层 δ(x=1m) = 6.1 mm

  水波：

  表面重力波色散关系：
    ω² = gk tanh(kh)

  深水波（kh >> 1）：
    ω² = gk, v_phase = √(g/k) = g/ω
    v_group = ½v_phase

  浅水波（kh << 1）：
    ω² = gk²h, v = √(gh)

  波高、波长与波速：
    典型海浪：波长~100m，周期~8s，波速~12.5m/s

  深水波计算（λ=100m）：
    波数 k = 0.0628 m⁻¹
    角频率 ω = 0.785 rad/s
    周期 T = 8.0 s
    相速度 v_p = 12.5 m/s
    群速度 v_g = 6.2 m/s

  声波（可压缩流体）：

  声速：
    c_sound = √(∂p/∂ρ)|_S（等熵）
    理想气体：c = √(γRT)
    空气中：c ≈ 331.5 + 0.6T(°C) m/s

  声速计算：
    空气 T = 20.0°C: c = 343.5 m/s

  螺旋几何化解释：

  1. 边界层的螺旋几何化
     - 边界层 = 螺旋涡的生成区
     - 层流边界层 = 有序螺旋流动
     - 湍流转换 = 螺旋涡失稳
     - 边界层分离 = 螺旋涡脱落

  2. 水波的螺旋几何化
     - 水波 = 流体元的螺旋（轨道）运动
     - 深水波：流体元做圆周运动（直径随深度衰减）
     - 浅水波：流体元做椭圆运动
     - 破波 = 螺旋轨道的失稳

  3. 声波的螺旋几何化
     - 声波 = 分子的螺旋振动传播
     - 纵波 = 螺旋振动沿传播方向
     - 声速 = 螺旋振动的传播速度
     - 压缩/稀疏 = 螺旋密度的交替
