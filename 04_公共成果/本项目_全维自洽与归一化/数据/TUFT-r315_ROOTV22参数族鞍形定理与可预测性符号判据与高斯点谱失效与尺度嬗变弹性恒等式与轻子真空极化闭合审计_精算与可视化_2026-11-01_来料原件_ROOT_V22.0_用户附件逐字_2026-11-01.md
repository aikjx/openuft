# ROOT V22.0｜攻克“固定点为什么仍不能唯一决定 α”的关键问题

这轮继续深入上一版留下的核心缺口：即使量子理论存在非零耦合固定点，是否就能从第一性原理唯一计算自然界的精细结构常数？

已经完成 SymPy 符号证明、75 位高精度计算及实际重整化群数值积分。得到一项很重要的结论：

固定点、稳定性和低能耦合的唯一性是三个不同的数学条件。存在固定点本身，不等于解决了 \(1/137.035999177\) 的本源。

## 一、真正需要求解的不是一个方程，而是一整套边界值问题

设统一理论有一组无量纲耦合：

\[ \mathbf g=(g_1,g_2,\ldots,g_n) \]

它们的量子演化满足：

\[ \frac{d\mathbf g}{d\ln\mu}=\boldsymbol\beta(\mathbf g) \]

第一步，求固定点：

\[ \boxed{\boldsymbol\beta(\mathbf g\_\*)=0} \]

第二步，计算稳定性矩阵：

\[ \boxed{ B\_{ij}= \left.\frac{\partial\beta_i}{\partial g_j}\right|\_{\mathbf g\_\*} } \]

第三步，证明允许的重整化轨道是否唯一。

若固定点附近存在一个紫外吸引方向，则沿这个方向的偏离：

\[ \delta\mathbf g(\mu) =C\left(\frac{\mu}{\mu_0}\right)^\lambda\mathbf v, \qquad \lambda<0 \]

在 \(\mu\rightarrow\infty\) 时自动趋于零。

但其中的 \(C\) 可以有不同取值。因此，不同低能耦合可能具有相同的紫外固定点。

这不是 ROOT 独有的难题。渐近安全规范—Yukawa 理论的研究明确指出，紫外临界面上可能保留相关方向和自由的轨道参数。

## 二、实际构造一个具有非零固定点的双耦合系统

定义两个无量纲变量 \(a,y\)，尝试以下数学模型：

\[ \boxed{ \begin{aligned} \beta_a&=a^2\left(\frac1{25}+a-4y\right)\\\ \beta_y&=y(2y-a) \end{aligned} } \]

这是用于研究固定点唯一性的示范动力系统，并非已经从标准模型或 ROOT 作用量推导出的物理 beta 函数。

直接求解：

\[ \beta_a=\beta_y=0 \]

得到非零固定点：

\[ \boxed{a\_\*=\frac1{25}=0.04,\qquad y\_\*=\frac1{50}=0.02} \]

在此点求 Jacobian：

\[ \boxed{ B\_\*= \begin{pmatrix} 1/625&-4/625\\\ -1/50&1/25 \end{pmatrix} } \]

两个特征值一负一正，说明固定点有一个紫外吸引方向和一个紫外排斥方向。

因此，即使固定点坐标已经完全求出，紫外吸引方向上的轨道幅度仍可能作为独立参数存在。

这是一项对固定点预测能力的严格线性化检验，而不是单纯观察数值曲线。

## 三、第二项证明：即使有渐近自由，仍可能存在未知的物理尺度

考虑一圈非阿贝尔规范理论：

\[ \frac{d\alpha_s}{d\ln\mu} =-\frac{\beta_0}{2\pi}\alpha_s^2 \]

积分得：

\[ \boxed{ \Lambda=\mu\exp\left[-\frac{2\pi}{\beta_0\alpha_s(\mu)}\right] } \]

这叫作尺度嬗变：一个无量纲耦合可以对应一个有量纲的动力学尺度。

但积分常数 \(\Lambda\) 并不会因为存在紫外固定点而自动确定。

实际计算取固定 \(n_f=5\) 的一圈 QCD 近似，\(\beta_0=23/3\)，参考能标为 100 GeV：

| 输入 \(\alpha_s(100\,\mathrm{GeV})\) | 计算出的 \(\Lambda\) |
| ------------------------------------- | ------------------ |
| 0.10                                  | 0.02759036 GeV     |
| 0.12                                  | 0.10813454 GeV     |
| 0.14                                  | 0.28686913 GeV     |

三种初值都具有相同的紫外渐近自由行为，但对应不同的动力学尺度。

这些数值属于固定味数的一圈示例，不能不经阈值和高阶匹配就直接当作精密 QCD 的 \(\Lambda\_{\rm QCD}\)。

结论：自然产生一个尺度，与唯一预测该尺度的数值，是两回事。

## 五、将固定点、几何与量子修正联合起来

目前 ROOT 的真正目标可以写成：

\[ \boxed{ \begin{aligned} &\text{唯一的几何—量子作用量}\\\ &\Downarrow\\ &\text{固定点及其稳定性}\\\ &\Downarrow\\ &\text{消除或独立确定全部自由轨道参数}\\\ &\Downarrow\\ &\text{正确的质量谱、阈值与量子运行}\\\ &\Downarrow\\ &\alpha\_{\rm predicted}(0) \end{aligned} } \]

这比直接设定：

\[ \alpha=\frac{\kappa}{\tau} \]

要求更严格，因为最后必须解释规范场为何具有特定的电荷耦合强度，而不仅是特定的空间几何形状。

本轮示范双耦合模型的三条有限尺度数值轨迹。它们用固定点及其线性特征方向附近的不同初值初始化，用于检验轨道依赖性；不宣称这些曲线全部已被证明为精确 UV 完备解。

## 八、下一项最关键的攻坚任务

这轮把问题进一步收窄了：

以前需要证明“为什么存在某个非零固定点”。

现在还必须证明“为什么这个固定点所允许的物理轨道只能产生一个低能电磁耦合值”。

真正有希望的下一条路线，是建立一个同时包含规范耦合、Yukawa 耦合、几何尺度与质量阈值的完整固定点系统，求出其紫外临界面的维数，再检验剩下的自由参数是否能被独立对称性或动力学固定。

最终裁定： 已经完成固定点可预测性、尺度嬗变和真实轻子量子修正三方面的严格攻坚，但自然界 \(\alpha\) 的第一性原理独立数值仍然是开放问题。数学上最缺的不是更多精度，而是一个能够唯一选择完整物理轨道的理论条件。
