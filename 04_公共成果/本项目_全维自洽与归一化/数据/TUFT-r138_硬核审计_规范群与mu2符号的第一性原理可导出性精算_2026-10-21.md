# TUFT-r138_硬核审计_规范群与mu2符号的第一性原理可导出性精算_2026-10-21（机读）

> 硬核 ②规范群 / ③μ² 的第一性原理可导出性精算。非加和。

## 判定

- **HARD-CORE-NOT-DERIVABLE**
- ②规范群 e=0（不被导出，仅被约束）；U(1) 非渐近自由 ⇒ 形式 UV 不完备
- ③μ² e=0（由数据读出）；自然逃逸（μ²=0 / μ²~M_Pl）均被排除

## 机检（精确有理数，带反向对照）

| 检查 | 内容 | 判定 |
|------|------|------|
| G1 | 一圈 β 系数（GUT 归一化）；b<0 ⇒ 渐近自由 | PASS |
| G2 | U(1)_Y 非渐近自由 ⇒ 存在 Landau 极点；但跨普朗克 ⇒ 形式上的 UV 不完 | PASS |
| G3 | 渐近自由是约束而非选择：本例下 SU(2)..SU(8) 全通过 ⇒ 不唯一确定 SU(3) | PASS |

| H2 | μ²=0（尺度不变）在树图不给 EWSB；辐射诱导（CW）为文献项，本册不重算 | PASS |

- 一圈 β 系数 (b1,b2,b3) = (41/10, -19/6, -7)
