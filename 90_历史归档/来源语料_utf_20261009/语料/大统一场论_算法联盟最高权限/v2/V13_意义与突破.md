## 二、三大突破

### 1. 参数化统一：R 不再是"二选一"难题

```
           过去二选一：      V11 (R=λ_C/√(1+α²))  或  V15.5 (R=λ_C)
                                           ↓
         V13 重参数化：   L = λ_C （唯一）
                         R = L·cosθ = λ_C/√(1+α²)  ← V11几何
                         h = L·sinθ = αλ_C/√(1+α²)
```

**意义**：这不是"选哪个R"的妥协，而是发现 **L 才是基本量子，R 只是几何投影**。类比：不是地球绕太阳还是太阳绕地球的等价，而是换了参考系后发现 **L 才是真正的不变量**（类似 SR 中的固有时）。

### 2. 磁矩突破：抛弃 80 年半经典错误

**之前所有版本（含V15.5）** 都用半经典 **安培环流模型**：

```
μ = I·A = (eω/2π) · πR² = eωR²/2
```

这个公式要求 R=λ_C 才能匹配 μ_B，于是与 Frenet 几何冲突。

**V13 的新方式（§4 磁矩推导）：**

从 A2 量子化条件 `mcL = ℏ` 出发：

```
μ_B = eℏ/(2m) = e·(mcL)/(2m) = ecL/2
```

**突破点：**
- **μ 只依赖 L，完全不依赖 R！**
- 本质：磁矩是量子内禀量（来自 ℏ=mcL），**不是**经典电流环的半经典结果
- 相当于"从玻尔模型跃迁到量子力学"：不再把电子看作半径 R 的电荷球，而是用量子作用量 L 直接定义

这解决了 **V11/V15.5 冲突的根源**：V11和V15.5都不该用 πR² 算自旋磁矩！
