# ROOT V82：真实引力调制与电磁候选的“实验语言”科研包

**科学界限：可通过移动质量调节局部真实引力场；目前不能证实通过电磁装置修改引力常数 G 或制造反重力。**

本包把上一轮 V81 的星际/电磁与引力讨论转化为可审计、可复现的 `ROOT-GCL/1.0` 实验语言和模拟。

## 快速运行

- Python 3.10+，只使用标准库：`python run_all.py`
- 查看独立单元测试：`python -m unittest discover -s tests -v`
- 完全离线实验网页：浏览器打开 `web/index.html`
- 设计协议：`spec/protocol_*.json`；JSON Schema 参考：`spec/experiment.schema.json`
- 计算数据：`data/*_synthetic.csv`，数值报告：`results/synthetic_summary.json`
- 完整研究：`book/ROOT_V82_引力控制实验语言与全链路验证研究总集.md`

## 已覆盖

1. 可移动球形源质量引力的点源等效和反转信号。
2. 微观储能的质量当量、EM 能量审计，区分净注入与内部转移。
3. 规范化的实验协议、参数校验、随机化和可复现实验模拟。
4. 模拟采集、仪器漂移、共形开关伪差、盲测/空载对照与线性代数不可辨识性。
5. 安全控制、校准、环境协变量、质量密度分布、导出记录、验收范围。

**全部 CSV 和统计结果为人工合成数据。程序没有物理硬件控制能力，不可用于控制强磁体、高压设备或重物执行机构。**

## 最小必要装备（由专业实验室评估）

真实源质量实验：经溯源的质量、可靠载台及位置编码器、扭秤/引力梯度仪或原子干涉装置、磁/温度/倾斜/震动传感器、独立时钟、环境隔离与联锁。本文不包含真实设备驱动、操作授权或未经监管的实验步骤。

## 通过与未通过

- 本包不能验证某新物理是否真实，也不具备改变 G 的真实装置。
