## 第一章 3维螺旋几何垂直原理

### 1.1 公理基石：$v_{总}=c$ 的三维分解

GAQ-UFT 的核心公理是：**任何物理体系的总速度恒等于光速 $c$**。

在三维空间中，将运动分解为**横向（xy平面圆周）** 和 **纵向（z方向螺旋推进）**：

$$\boxed{v_{\perp}^2 + v_{\parallel}^2 = c^2}$$

| 分量 | 物理意义 | 几何对应 |
|:---|:---|:---|
| $v_{\perp} = \omega\rho$ | 横向切向速度 | 半径为 ρ 的圆周运动 |
| $v_{\parallel} = \omega b$ | 纵向推进速度 | 螺距为 2πb 的螺旋推进 |
| $c$ | 总速度（常数） | 螺旋线的"弦长"约束 |

### 1.2 三大垂直定理

#### 垂直定理 I：速度分量正交

$$v_{\perp} \perp v_{\parallel}$$

横向速度矢量位于 xy 平面，纵向速度矢量沿 z 轴方向。二者恒正交，这是三维空间本身的几何性质。

**验证结果**：200位精度下 $v_{\perp}^2 + v_{\parallel}^2 = c^2$，残差 ≤ $1.63 \times 10^{-201}$（S级·机器零）

#### 垂直定理 II：Frenet 标架正交（T-N-B 三元组）

Frenet-Serret 公式定义了单位速度曲线上的三个正交矢量：

| 矢量 | 定义 | 物理意义 |
|:---|:---|:---|
| $T = d\mathbf{r}/ds$ | 单位切向 | 速度方向 |
| $N = dT/ds / \|dT/ds\|$ | 主法向 | 指向曲率中心（xy平面内） |
| $B = T \times N$ | 副法向 | 扭转方向（z 与 N 的叉积） |

**正交关系**：$T \cdot N = 0,\ N \cdot B = 0,\ T \cdot B = 0$

这三个正交关系是**微分几何的恒等式**，对任意光滑曲线成立，不是物理假设。

#### 垂直定理 III：频率勾股（核心恒等）

$$\boxed{\kappa^2 + \tau^2 = \left(\frac{\omega}{c}\right)^2}$$

其中：
- $\kappa = 1/R_{curvature} = \omega^2 \rho / c^2$：曲率（横向弯曲强度）
- $\tau = \omega^2 b / c^2$：挠率（纵向扭曲强度）
- $\omega/c$：总频率强度

**几何意义**：频率 $\omega$ 是"总几何强度"，$\kappa$ 和 $\tau$ 是其在横向和纵向上的正交分量。这恰如一个矢量的模方等于其正交分量的平方和。

**验证结果**：200位精度下 $\kappa^2 + \tau^2 = (\omega/c)^2$，残差 ≤ $10^{-201}$（S级·机器零）

在三大垂直定理之上，精细结构常数 $\alpha$ 获得了纯粹的几何定义：

$$\boxed{\alpha = \frac{\tau}{\kappa} = \tan\theta}$$

其中 $\theta$ 是螺旋线的倾角（tanθ = 纵向推进 / 横向旋转 = b/ρ）。

**这是 GAQ-UFT 唯一真正的物理突破**：
- α 不再是一个随意的"耦合常数"
- α 是频率矢量的**两个正交分量的比值**
