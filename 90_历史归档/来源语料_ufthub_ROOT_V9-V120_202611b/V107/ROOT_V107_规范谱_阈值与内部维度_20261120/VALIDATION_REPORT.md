## 核心输出（计算，不是观察）

- 最简 SM 单圈统一缺陷：I₀ = −40.5507387360451977401129943503。
- 一组 5+5̄ 分裂要求：ln(MT/MD)=43.4297396286813583；MT/MD=7.2660146845×10¹⁸。
- N=2、MD=1 TeV：MT=2.695554615×10¹² GeV；数学交点 µ=5.053091634×10¹³ GeV。
- 交点三个逆规范耦合 α₁⁻¹=α₂⁻¹=α₃⁻¹=37.9782163193515894（在指定一圈模型和输入下）。
- 最小五场一代超荷在给定 Yukawa/异常要求下相对比例固定；νR Dirac 扩展存在自由 B−L 方向。
- 仅由 k≤3 光滑内部相位拉回的规范联络，Tr(F∧F) 局部必为零；k=4 有局部非零例子。

## 不得被报告为“完成”的科学问题

- 不能由这些结果宣布 SU(5) 就是自然界最终的规范群；群及额外粒子种类属于人为选择。
- 两套 split multiplet 的交点未通过质子衰变、两圈 RGE 和精密实验联合筛选；若当作传统 SU(5) 的破缺尺度，较低能标是严重风险。
- 没有严格证明电子、夸克、中微子质量谱从螺旋曲率和挠率产生。
- 没有第一性无循环推导 G 或证明引力子量子化。
- k≥4 仅产生可能的局部四形式，不证明非零整数量子拓扑荷。
- 未进行任何原始实验；图表全标理论示范或模型假设。

## 复现方式

在解压后的项目根目录执行：

```bash
python -m pip install -r requirements.txt
python run_all.py
python verify_integrity.py
python legacy_regression.py
# 选做：在已安装 Chromium / Playwright 的机器上
python web/browser_smoke.py
```

若自定义版本的 matplotlib、Chromium 重新生成图形或截图，像素级哈希可能因渲染环境而变化，仍应以指定数学数值和自动断言为主要复现标准。
