## 77.1 问题的位置：从"物理学有一把自造的尺子"到"openuft 能不能自己造"

第76章把全物理的尺度生成归为三棵树、两类机制，并证明 QCD 维度转化是唯一把扇区 nullity 打到 0 的通道。但那里有一个必须被追问到底的隐患：openuft 的中心本体是"真空微元做空间光速螺旋流"，且第八编已论证该涡旋流与 Navier–Stokes 涡量方程同构。如果螺旋/涡旋场本质上就是一种流场，那么它似乎"天然有非线性、有涡"，**为什么不能像 QCD 一样量子化后自己跑出 β、自己长出 Λ？**

本章不回避这个问题，正面把它做成一个可判定的命题。结论不是含糊的"还需要量子化"，而是精确的三件事：

1. **[A]** 从配分函数的结构看，一条**给定的**螺旋世界线在数学上不可能有重整化群——它缺的不是某个系数，而是"被积分的场"和"cutoff"这两个范畴（77.2–77.3）；
2. **[A]** 即使把螺旋提升为场并量子化，要在红外自锁出一个质量尺度，β 的**符号**必须为非阿贝尔反屏蔽；这个符号只来自带荷媒介的自耦合（b₀ 的 11N_c/3），阿贝尔/经典场给不出（77.3，数值见 77.5）；
3. **[A]＋[C]** 把这两样补齐，理论在标准公理下**塌缩为 Yang–Mills**（定理 N）；openuft 想把这称为"自己的推导"而非"给 QCD 改名"，唯一的出路是证明一个明确的、目前未证的数学命题 OPEN-M（77.6–77.8）。

## 77.2 第一步·本源定义：β 跑动在范畴上需要什么

重整化群不是"耦合会变"这句口号，它有严格的存在性前提。先把两种"配分函数"摆清楚，差别是范畴级的。

**世界线（给定一条曲线 γ，无泛函积分）：**

$$Z_{\rm wl}[\gamma]=\exp\!\left(\frac{i}{\hbar}S[\gamma]\right),\qquad \ln Z_{\rm wl}=\frac{i}{\hbar}S[\gamma].\qquad [A]$$

- γ 是一条**给定的**螺旋，κ(s)、τ(s) 是它的确定性几何属性，没有"对其它可能螺旋求和"；
- 指数上是纯相位，整个表达式里**不出现任何紫外截断 Λ_UV**（没有需要被截断的模求和）；
- 经典无质量作用量标度协变（第62章砖二·定理 L），故 S 不含固定尺度。于是 μ∂lnZ/∂μ=0 是平凡的——**不是 RG 不变量，而是 μ 这个变量根本不存在**。

**场论（场 A 是泛函变量，对模空间积分）：**

$$Z_{\rm field}[J]=\int_{|k|<\Lambda_{\rm UV}}\mathcal D A\ \exp\!\left(\frac{i}{\hbar}\big(S[A]+\text{反项}[\Lambda_{\rm UV}]\big)+iJ\!\cdot\! A\right).\qquad [A]$$

- 一旦对场的无穷多涨落模积分，就必须引入 UV 截断 Λ_UV 使积分有定义；
- 物理可观测量不得依赖这个人为截断，迫使裸参数（裸耦合 g₀）成为 Λ_UV 的函数，等价地定义了跑动耦合 g(μ)；
- **β(g)=μ∂g/∂μ 由此而生**。没有泛函积分的模空间，就没有 cutoff，就没有 β。

> **与定理 C/L 的分工**：定理 C（量纲零空间）讲"量纲代数产不出耦合"，定理 L（标度继承）讲"固定形状势的本征值齐次继承外部尺度"；本章定理 N 的第一部分从另一个入口——**统计结构**——独立得到同一结论：单点世界线不是统计系综，不存在有效作用量 Γ[μ]，自然没有 RG 流。三个定理互相印证，不互相替代。

**[B] openuft 对位**：S01/S02/S12 的螺旋是曲线几何（κ,τ 为参数）；S13/S14 与第八编把它推广为涡旋**场** ω=∇×u，这一步确实引入了场变量，但第八编的 NS 方程是**确定性偏微分方程**（给定初边值求一条/一族解），仍不是对场做泛函积分的统计场论。所以"有场"还不够，要的是"对场做带权重的模求和"（M1）。

## 77.3 第二步·本源方程：从动量壳积模到 β，以及决定生死的符号

### 77.3.1 Wilson 积模给出 β

把动量壳 [Λ/s, Λ] 内的涨落积掉（s>1），有效耦合的 1 圈变化：

$$g(\Lambda/s)=g(\Lambda)+\beta\!\left(g(\Lambda)\right)\ln s+O(g^5),\qquad \beta(g)=\mu\frac{\partial g}{\partial\mu}.\qquad [A]$$

非阿贝尔规范理论 1 圈（α_s=g²/4π）：

$$\mu\frac{dg}{d\mu}=-\frac{b_0g^3}{16\pi^2},\qquad b_0=\frac{11N_c}{3}-\frac{2n_f}{3},\qquad \frac{1}{g^2(\mu)}=\frac{1}{g^2(\mu_0)}+\frac{b_0}{8\pi^2}\ln\frac{\mu}{\mu_0}.\qquad [A]$$

积分形式与第76章的 α_s 跑动、RG 不变量 Λ=μe^{−2π/(b₀α_s)} 完全衔接。

### 77.3.2 符号决定红外能否自锁尺度（本章最关键的一步）

- **b₀>0（非阿贝尔，胶子反屏蔽主导）**：μ 下降时 g 增大 → 红外强耦合 → 禁闭与质量隙 → 维度转化在红外选出 Λ。正号里的 **11N_c/3 全部来自带色规范玻色子的自耦合**（非阿贝尔三顶点）；−2n_f/3 是夸克圈的屏蔽。
- **阿贝尔（QED）符号相反**：μ de/dμ=+(4/3·ΣQ²)e³/(16π²)>0，能量越低耦合越小，红外自由，**没有禁闭、没有红外质量隙**；电子质量只能显式/Higgs 输入。
- **φ⁴/经典涡旋**：无带荷自耦合的反屏蔽结构，给不出 b₀>0 的红外自锁（φ⁴ 在 4D 是平凡理论，β>0 但无渐近自由、无质量隙）。

这一条直接判了"只要把涡旋场量子化就能自造尺度"的死刑：**量子化（M1）只给你一个 β，但是否在红外长出尺子，取决于 β 的符号，而那个符号由非阿贝尔自耦合（M2）决定。**

### 77.6.3 定理 N（塌缩/代价定理）的准确陈述与适用边界

> **定理 N（限定形式）**：在 **4 维、局域、幺正、洛伦兹协变、且要求 UV 完备（渐近自由）的规范型量子场论**中，一个经典无尺度（M3）理论要在红外经维度转化自锁出质量尺度，其必要增补 M1（泛函量子化）与 M2（带荷自耦合，b₀>0）的标准实现，就是非阿贝尔 Yang–Mills：场强 F=dA+A∧A、β=−b₀g³/(16π²)、b₀=11N_c/3−2n_f/3、质量隙即 Yang–Mills 千禧年问题（OPEN-7）。

**因此 openuft 面临非此即彼的两岔：**

- **(a) 换名岔**：直接把 A、F∧F、规范群写进螺旋理论——那规范动力学部分就是 QCD/Yang–Mills，螺旋语言退为对场强的几何比喻。S11 联合场方程审计、S14 终审已证明"并排抄写/直积群不含特有项"不满足 UFT-2，**结构同构 ≠ 物理等价**；此岔不给 openuft 任何独立的常数派生（UFT-3 仍 0 靶）。
- **(b) 推导岔（唯一可能有新物理的路）**：**不预设规范群**，只从"光速螺旋/涡旋场的泛函量子化"出发，证明被积场的统计结构**唯一蕴含**非阿贝尔场强 F=dA+A∧A 与某个紧致单李群（且 N_c=3、正确的表示内容）。这就是 OPEN-M。

**诚实边界（不夸大唯一性）**：定理 N 的"唯一性"限定在"渐近自由的规范型 UV 完备理论"。一般局域 QFT 中还存在非规范的强耦合红外理论（NJL、非线性 σ 模型等），但它们或带显式 UV 截断/对手征结构敏感、或需有量纲耦合，不满足"经典严格无尺度＋零量纲输入＋UV 完备"的合取。openuft 若要援引这类例外，同样要先给出其泛函积分并证明质量隙——负担不减。定理 N 不是对所有数学可能的穷尽定理，而是对"用最小标准零件自造尺子"这一**工程**的代价核算：**零件凑齐，装出来的就是 Yang–Mills。**

### 77.6.4 openuft 满足度计数（脚本 E）

4. **不修改任何体系 status**：本章为算法联盟元层审计章；S01–S14、P01–P04 候选身份与 UFT 2/6 不变。定理 N 与 C/D/E/F/H/J/K/L 并列，属"判不可行"类，不产生物理四态迁移。
