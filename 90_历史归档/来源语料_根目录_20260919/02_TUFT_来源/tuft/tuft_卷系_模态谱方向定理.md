### 2.2 模型侧：标准几何的谱能隙方向（§V1~§V4）

**(a) Pöschl-Teller（sech²）阱有精确解**：算符 `L = −d²/dx² − V₀ sech²(x/a)`，令 `λ ≡ V₀a²`：

```
s(s−1) = λ  ⇒  s = [1+√(1+4λ)]/2 ；E_n = −(s−1−n)²/a² ， n = 0..N−1
束缚态数  N(λ) = ⌈(√(1+4λ) − 1)/2⌉        （≈ √λ）
阈值：N = k  ⟺  λ ∈ (k(k−1), k(k+1)]
```

| N | λ 区间 | 窗口宽 | 上下界之比 |
|---|---|---|---|
| 1 | (0, 2] | 2 | — |
| 2 | (2, 6] | 4 | 3.000 |
| **3** | **(6, 12]** | **6** | **2.000** |
| 4 | (12, 20] | 8 | 1.667 |
| 5 | (20, 30] | 10 | 1.500 |

**λ=8（∈ (6,12]）的精确谱**：`s = 3.372281`，`|E_n| = [5.627719, 1.883156, 0.138593]`，能隙 `= [3.744563, 1.744563]` ⇒ **能隙严格递减**（比 0.4659 < 1）。

**(b) 一般有限阱的数值谱**（有限差分 + `scipy.linalg.eigh_tridiagonal`，`N=12001`；先用 sech² 精确谱**自检**，相对误差 < 0.2%）：

| 阱型 | N | 能隙（前 4） | 首增量比 | 方向 |
|---|---|---|---|---|
| sech² (λ=8) | 3 | 3.7445, 1.7446 | **0.466** | 递减 |
| sech² (λ=30) | 5 | 8.9996, 6.9996, 4.9999, 3.0003 | **0.778** | 递减 |
| 高斯阱 (V₀=80, σ=1.5) | 15 | 8.0944, 7.7476, 7.3908, 7.0228 | **0.957** | 递减 |
| **方阱 (V₀=200, a=1)** | 9 | 6.5069, 10.8213, 15.0969, 19.3097 | **1.663** | **递增** |

**(c) 紧致内部空间**（球面/紧致流形 Laplacian `E_l = l(l+1)/R²`）：能隙 `= 2, 4, 6, 8, …`，**递增但相邻比 = 2.000 → 1.5 → 1.333 → … → 1**。

### 2.3 关键发现：能隙方向**分两支**（本册最重要的诚实修正）

> **⚠️ 方法论留痕（自查修正）**：本册初版曾断言「**所有**标准阱的能隙均单调递减」，并在深方阱（V₀=200）上被自己的数值**证伪**——深方阱的低阶能隙是**递增**的（趋于「粒子在盒」的 `E_kin ∝ n²` ⇒ 能隙 `∝ 2n+1`）。
> 修正后的稳健表述如下（只它有资格称定理）。

| 分支 | 触发条件 | 能隙方向 | 增量比上界 |
|---|---|---|---|
| **支 1** | 浅阱 / **阈值累积**（任意阱的高阶态） | **递减** | < 1（实测 0.466 / 0.778 / 0.957） |
| **支 2** | 深阱（→ 粒子在盒）/ 紧致几何 | **递增** | **≲ 3**（实测方阱 1.663；紧致空间首步 2.000，随后 → 1） |

**两支的增量比上界均 ≲ 3，而观测需 15.8939**：
- 支 1（最大实测 0.957）⇒ 相差 **≥ 16.6 倍**；
- 支 2（最大实测 1.663，理论上界 ~2~3）⇒ 相差 **≥ 9.6 倍**（对紧致空间首步 2.000 ⇒ 7.9 倍）。

## §3 谱族排除与「零预言力」实例化（实跑 §V6/§V7）

### 3.1 两参数谱族被**双约束**排除

| 谱族 | 由 `r₁₂` 定参 | 预测 `r₂₃` | 实测 `r₂₃` | 偏差 |
|---|---|---|---|---|
| 指数谱 `m_n ∝ e^{an}` | `a = ln 206.7683 = 5.3316` | `e^a = 206.768` | 16.817 | **12.30×** |
| 幂律谱 `m_n ∝ (n+1)^p` | `p = 7.6919` | `1.5^p = 22.619` | 16.817 | **1.34×** |

**交叉检验（排除两参数版）**：由增量比 15.8939 反解 `p = 6.9533`，与 `r₁₂` 给出的 `p = 7.6919` **相差 9.6%**；用 `p = 6.9533` 预测 `r₁₂ = 2^p = 123.92`（实测 206.768）⇒ **偏 40.1%** ⇒ **单一两参数幂律谱同时拟合 `r₁₂` 与增量比不可能**。

### 3.2 三参数族 ⇒ **精确拟合、零预言力**（定理 D 的实例化）

`m_n = m_top + c·(n+1)^p`，消去 `(m_top, c)` 后须满足 `(m_μ−m_e)/(m_τ−m_e) = (2^p−1)/(3^p−1)`：

```
左端 = 0.05919297  ⇒  唯一解 p* = 6.953281
c* = 0.855404 MeV ；m_top* = −0.344405 MeV
回代最大相对误差 = 1.87e-05
```

⇒ **三数据点 / 三参数 = 精确拟合**（定理 D / 卷二十九 T5 的实例化）。且 `p* ≈ 6.95` **不是任何标准几何的指数**（紧致内部空间 `E ∝ l(l+1) ⇒ p = 2`；幂律拟合 `r₁₂` 要求 `p = 7.69`）⇒ 该拟合**不带来任何独立约束**。

> **诚实注记**：3.1 的 `p = 6.9533` 与 3.2 的 `p*` 由同一代数恒等式 `(1−A)/A` 决定，故**必然相等**——它们是**同一方程**的两种读法，**不是两个独立检验**。3.1 的独立价值仅在于**排除两参数版**。

## §4 定理 H 的陈述、论证强度与边界

### 定理 H（模态谱增量比有界）

**陈述**：对**固定算符的束缚态谱**（1D 形状模阱、或紧致内部空间的 Laplacian），其按模序排列的能隙增量比 `J_model ≡ gap₂/gap₁` 满足：
- **支 1（浅阱 / 阈值累积）**：`J_model < 1`（能隙递减）；
- **支 2（深阱 / 紧致几何）**：`J_model ≲ 3`（能隙递增但**有界**，且随后递减趋 1）。

而观测带电轻子层级要求 **`J_obs = 15.8939`**。**两支均不能企及**（相差 ≥ 9.6 倍）。
⇒ **「三代 = 前 3 个径向/形状模态」机制被结构性排除**；要得到 `J = 15.89`，须谱指数 `p ≈ 6.8`（**非任何标准几何的 p = 2**）或等价的新机制。

**论证强度**：**计算级 + 一般论证**（**不是**对所有阱型的严格定理）：
- 计算级：4 种阱型（sech² λ=8/30、方阱 V₀=200、高斯阱 V₀=80）+ 紧致几何，解析/数值全覆盖，且数值机器经 sech² 精确谱**自检**（相对误差 < 0.2%）；
- 一般论证（两条）：① 阈值累积 ⇒ 任意阱的**靠上**能隙必趋 0（`J_model → 0`）；② 深阱 ⇒ 趋于粒子在盒 ⇒ 能隙 `∝ 2n+1` ⇒ **比值 → 1**。

### 诚实边界

| # | 边界 |
|---|---|
| ① | 定理 H 针对**固定算符的束缚态谱**；**不排除「指数型谱」类机制**——但那需要**新自由度**（标度不变性 / 维度嬗变），且其两参数版已被 §3.1 排除 |
| ② | **不排除**「三代不是同一孤子的前 3 个模，而是三类不同孤子」——但那退化为 O-KNOTMAP 的**字典赋值**，回到**定理 D**（重参数化 ≠ 派生） |
| ③ | 数值用有限差分 + 三对角对角化（N=6001/12001，L=40~60）；已用 sech² 精确谱自检后才用于单调性判据 |
| ④ | 观测质量取 PDG pole 值（MeV）；用 pole 或 MS-bar **不改变方向性结论**（`J = 15.9 ≫ 3`） |
| ⑤ | **不排除**多阱 / 周期势 / 能带结构（它们给带隙而非孤立束缚态谱，机制不同）——但卷系从未提出该类机制 |
| ⑥ | 定理 H 是**结构诊断**：它**否定**的是「标准模式的形状模机制能给出观测层级」，**不是**「带电轻子质量不能被任何机制解释」 |
