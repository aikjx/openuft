### 定理

把来料自己的三条关系（`ω = c/√(a²+b²)`、`κ² = ω²/c² − k_n²`、`m − k_n b = 1`）合起来，只留一个纯数判据：

> **κ² = (1 − (k_n a)² − j²)/(a²+b²)，`j := k_n b`；传播 ∧ `j ∈ ℤ` ∧ `a > 0` ∧ `k_n > 0` ⇒ `j = 0` ⇒ `b = 0`。**

消去 `k_n` 后得到完全不含 π 的形态 `κ²·b²(a²+b²) = −(j²a² + (j²−1)b²)`，`|j| ≥ 1` 时分子 `≥ a² > 0`——所以「非零螺距 ⇒ 倏逝」**不依赖 `k_n` 的定义族**，只依赖 `j` 是整数。`j = ±1` 一支的残余恰为 `−a²/(b²(a²+b²))`（216 组逐点精确、比值集 `{1}`），**没有容差**；`a = 0` 的退化支只能拿到 `κ² = 0` 的边际（18 组全在边界、0 组严格传播）。

四通道同判一个 0：臂一网格穷举（`quant_prop_bpos = 0`）、臂二按 `b=(m−1)/k_n` 构造（`prop_bpos = 0`，且能给传播解的 `m` 只有 `[1]`）、1404/144 组逐点 Fraction 恒等式、`k_n = 2πn/L` 族用 π 的有理双侧界判整（11 个模态 **0** 个自洽）。阳性对照（撤量子化）在同一网格给 **830** 组非零螺距传播点，故空集由量子化承载而非网格巧合。
