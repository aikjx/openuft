# 判定册 · TUFT-r400（攻 X-GSM-5：超荷方向由电荷谱唯一确定）

> 日期 2026-11-04 · RID **r400** · `FINAL = GATES-PASS-ALL-POSITIVE`
> 判词 `COEFFS-DERIVED--LA-MINUS-1/3-UNIQUE--LK-MAG-1/2--LK-SIGN-IS-SYMMETRY--T3L-CHOICE-DECIDABLE--R398-LIST-IS-CONJUGATE`
> 主册 10（PASS 10 / FAIL 0）/ 控制组 4 / 守卫 14 / 合计 28 / 判负 0

**本册不产生新物理。** 它只做一件事：把 r399 留下的「两个系数是输入」这条边界，换成两条可算的唯一性，并把剩下那点自由度精确地指认为一条**对称性**。

---

## 一、一句话判决

`Y = −(1/3)(H1+H2+H3) + (1/2)(H4-H5)` 里那两个系数**不是输入**：

1. `B-L` 在 su(4) 方向上是**唯一**的线性泛函 —— 两条独立方程（`B-L` 在 4 上取 `(−1, 1/3, 1/3, 1/3)`）给出同一个 `alpha = −2/3`（A2）；
2. `T3` 的归一化只有 `|lambda| = 1/2` 一种（A3）；
3. 把这两个装回 `Y`，与 r398/r399 一直用的矩阵**逐元素相等**（A4）；
4. 而 `Y` 里给 `B-L` 的那个 `1/2`，等于两个系数之比 `lambda_A / alpha = 1/2` —— 它是**算出来的**，不是抄来的（A5）。

剩下的一点自由度：`lambda_K` 的**符号**。本卷证明它没有物理内容 —— `eps4 <-> eps5` 是权集的对称（16/16 闭环），它把 `lambda_K` 变号而谱、多重集、电荷**全不变**（A8）。

## 三、三个谱与 `B-L` 的字典（A1 / A2）

- `A = h1+h2+h3` 的 16-态多重集：`{−3/2:2，−1/2:6，1/2:6，3/2:2}`
- `T3L = (h4+h5)/2`：`{−1/2:4，0:8，1/2:4}`；`T3R = (h4-h5)/2`：`{−1/2:4，0:8，1/2:4}` —— **两者完全相同**
- `B-L = alpha · A`，`alpha = −2/3`；16-态多重集 `{−1:2，−1/3:6，1/3:6，1:2}`，迹 0

★ 为什么 `A` 能把 16 分成 8+8：`A > 0` 的 8 个态是 `(4,2,1)`、`A < 0` 的 8 个是 `(4bar,1,2)`。这件事是 A2 能写成「两条方程」的前提 —— 因为 `B-L` 在 su(4) 的 4 上只认这一个和。

★ 为什么 `T3L` 与 `T3R` 的谱一样却仍然可判：它们的**联合分布**不一样（一个态只属于一个 su(2)，见 G05）。所以「谱相同」不等于「不可分」—— 这一点在 A7 里兑现。

## 四、`T3` 的归一化唯一性（A3）

- `K3 = h4 - h5` 的本征值集：`['−1', '0', '1']`（两个 `±1/2` 相减，只有这三种）
- 要求 `lambda · {−1,0,1}` 全落在 `{−1/2, 0, 1/2}` 内 ⇒ 解集 `['−1/2', '1/2']`

★ 这是**绝对值唯一**：`±1/2` 都合法。符号的问题不在这里解决，而由 A8 说明「它不是一个问题」。

## 六、扇区式精确解（A5，本卷核心）

- 扇区 1（`K3 = 0`，8 态）：解 `['−1/3']` ⇒ `lambda_A` **唯一**
- 扇区 2（`K3 != 0`，8 态）：解 `['−1/2', '1/2']` ⇒ `lambda_K` 定到符号
- `lambda_A / alpha = 1/2`

★ 两段互不相交的理由是 G05：没有任何态同时带 `T3L` 与 `T3R`。这是 `16 = (4,2,1) + (4bar,1,2)` 在权层面的像，不是人为切分。

★★ **这一条带一层物理指认**：它默认「`K3 = 0` 的 8 个态装的是 `Q(6) + L(2)`」。这是一层弱指认（只说哪个扇区装夸克与轻子双重态，不说哪个态是 u），但它确实存在。A6 会把它去掉，去掉之后多出来的正好是共轭。

## 七、全网格互印与「多出来的一倍」（A6 / G11）

- 全网格（`lambda_A x lambda_K`，刻度 `1/12`，盒 `±2`）：49x49 = 2401 个格点，去掉原点后 2400 个候选；解 **4** 个
- 刻度外第一点违例 `8`；盒外第一点违例 `16`

★★ 与 A5 的**关系**（不是相等）：`全网格 = 扇区解 ∪ (−扇区解)`。多出来的那一对是 `Y -> −Y`，即**共轭**。G11 把这个关系机核（并且要求两边**不相等**，否则这条关系就没内容）。

★★★ 第一版我要求两个解集**相等**，直接判 FAIL —— 那是本卷的头号自伤（E01）：把「共轭」当成「算错」。判据要报**关系**，不要报相等。

## 九、`lambda_K` 的符号是权集的对称（A8）

- 权集在 `eps4 <-> eps5` 下闭环：`True`
- 该置换下 `T3L` 不变：`True`
- 两解的 `Q` 多重集全同：`True`；`y` 多重集全同：`True`

★★ 于是「`+1/2` 还是 `−1/2`」不是能被任何谱、任何矩判定的问题 —— 它是一个**编号约定**。
★★ 这条同时把 r399 的困惑定性了：r399 只看到两个谱互为相反数，本卷指出了**那条对称性**，并证明它不改变任何可观测量。
