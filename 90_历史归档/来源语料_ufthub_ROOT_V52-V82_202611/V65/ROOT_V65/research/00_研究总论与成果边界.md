# ROOT V65｜从 V50—V64 的整体审计到统一相互作用的证明义务

**冻结日期**：2026-11-17。**性质**：数学证明、标准物理复现、玩具模型实验与反例审计。**成果等级**：已复现部分已知规律与条件推导；没有完成新的四力大统一，也没有无参数预测 G。

## 0. 定义成功：必须满足而不是自我宣告

所谓真正的新四力统一理论，应在**单一原始动力学**之下，独立恢复 (i) 广义相对论及其量子一致的适用极限；(ii) 标准模型的 SU(3)_C×SU(2)_L×U(1)_Y、粒子表象、手征性、三代和质量生成；(iii) 所有必要的守恒律与无异常条件；(iv) 常数的独立数值或有额外解释力的预测；(v) 超出既有理论、受实验支持的可证伪预测。

“把 GR 与 SM 写进同一 S”只证明已知方程能够共享**变分记号**，不证明相互作用同源。本版提供了直接反例与可运行代码。

## 1. 研究路线的逻辑图

1. **几何**：圆柱螺旋的正交分解、κ、τ、ω，逆问题在 κ>0 时有唯一几何重构（已证）；力学上没有普适三力正交。
2. **微观场**：圆柱 Klein–Gordon 模态支持 e^{i(nθ+kz−Ωt)} 的旋转相位（由给定场方程推出）。群速度 |v_g|<c，不意味着粒子世界线按 c 作螺旋。
3. **引力源**：微观场具有能动张量，输入 GR 的场方程或牛顿极限后产生重力（条件成立）；G 是输入。
4. **诱导引力**：选定量子场谱及固有时间截止方案得到局域 R 项（条件成立）；由于裸项、截止尺度和场谱可变，不能预测 G。
5. **规范作用**：引力/电磁/强/弱可写在同一协变作用量（现有 EFT 工具）；与独立推导标准模型规范群、参数及量子引力相隔多项尚未证明的条件。
6. **实验**：用 Eötvös 参数、第五力 Yukawa 形状等可检验模式限定参数，代码只计算假设的预言，不伪装为观测数据。

## 2. V65 新增的实质性修复

- **几何反演定理**：由 (κ,τ,v) 唯一构造圆柱螺旋的半径、轴向速度、环向速度和角速度；直线退化清楚排除。
- **Lorentz 禁区证明**：对有质量粒子把世界线三速度设为 c，则平直度规下 dτ=0，无法作为有质量粒子物理世界线；换为场的相位旋转避免此冲突。
- **数值误差修复**：旧固定步数 F(μ) 积分在 μ 小时存在边界层误差。改用指数积分的收敛级数和自适应积分，并与 scipy.special.exp1 独立交叉验证（SciPy 非运行依赖）。
- **结构性不可辨识证明**：给出 N/ℓ² 参数族和 log-Jacobian 秩为 1 的理由；无法用无限精度拟合替代新数据或独立尺度。
- **可判别的第五力测试**：定义带材料依赖耦合 α_A、α_B 的玩具 Eötvös 参数，观察其是否与 MICROSCOPE 相容；不把这一实验扩大成所有第五力的普适排除。
- **共变场方程**：明确含非最小曲率耦合的候选标量作用量和度规/场变分，指出其自由参数及稳定性限制。
- **回归验证**：独立运行新旧两层测试，保留 V64 历史项目作为基线；CSV/PNG 的模拟数据标有 TOY，来源与观测值分离。

## 3. 成功与未成功的准确区分

| 研究项 | 本轮状态 | 结果属性 |
|---|---|---|
| 螺旋曲率/挠率与反演公式 | **证明**（在指定圆柱模型内） | 数学定理 |
| 圆柱 KG 场能量积分与弱场外部重力 | **条件推导和数值复现** | 已知模型，不是新的实验事实 |
| 类比场的群速度、物体世界线与 c 的差别 | **已说明并数值校核** | 相对论一致性 |

| 产生标准模型粒子表象与所有相互作用 | **开放** | 候选模型未完成 |
| 无 ghost、无异常、可量子化和 UV 完成 | **开放** | 尚无完整证明 |
| 新物理被实际观测确认 | **未发生** | 本包只含理论与 toy 数据 |

## 4. 创新性定位

本版的新工作是“可审计的几何逆定理 + 误差修复 + 参数不可辨识与实验归因”的工程化结合。其数学积木（Frenet、KG、诱导引力、GR、Yang–Mills 等）均不当作本团队原创发现。真实突破须给出并证实与现有理论不同的可测预测。
