# ROOT V55 地球多场几何实验室

## 使用
- 双击 `index.html`，在现代浏览器中离线运行二维交互式地球场图。可以切换引力、电场、磁场、合力，并点击采样点查询数值。
- Python 3.9+：`python model.py` 输出地球外部采样点的三维矢量结果。
- `python -m unittest -v test_model.py` 运行自动化测试。

## 模型范围
地球外部、球形牛顿引力、居中且与 z 轴对齐的磁偶极、可设定的均匀电场、非相对论洛伦兹力。磁场不等于实测 IGRF，电场是用户设定而非地球真实场。强弱核力、广义相对论强场、真实地球地壳与空间天气未纳入。二维显示是三维模型在 x-z 截面上的投影，磁力取指定 vy 后在该截面可显示。

## 文件
`研究专著.md`：理论章节；`model.py`：三维数值计算；`test_model.py`：验证；`index.html`：可视化；`sample.json`：计算样例；`test_results.txt`：测试输出。
