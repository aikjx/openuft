【MP1】微分几何
----------------------------------------------------------------------

  微分几何概述：

  微分几何是用微积分方法研究几何对象（曲线、曲面、流形）的学科。
  它是广义相对论、规范场论、弦论等现代物理理论的数学基础。

  流形（Manifold）：

  流形是局部类似于欧几里得空间的拓扑空间。
  物理中的时空、相空间、规范群轨道等都是流形。

  流形的例子：
    - 1维流形：直线、圆周
    - 2维流形：平面、球面、环面、莫比乌斯带
    - 3维流形：欧几里得空间、3球面、3环面
    - 4维流形：闵可夫斯基时空、弯曲时空
    - 高维流形：弦论中的10维/11维时空

  切空间与切向量：

  流形上每一点都有一个切空间，切空间中的向量称为切向量。
  切向量可以理解为流形上曲线的速度向量。

  物理中的切向量：
    - 时空中的4-速度：U^μ = dx^μ/dτ
    - 相空间中的速度向量
    - 规范群轨道中的生成元

  余切空间与微分形式：

  余切空间是切空间的对偶空间，余切向量是线性泛函。
  微分形式是余切空间的反对称张量。

  微分形式的例子：
    - 0-形式：标量函数 f(x)
    - 1-形式：梯度 df = (∂f/∂x^μ) dx^μ
    - 2-形式：电磁场张量 F = (1/2) F_{μν} dx^μ ∧ dx^ν
    - 3-形式： Hodge 对偶 *F
    - 4-形式：体积元 √(-g) d^4x

  外微分（Exterior derivative）：

  外微分 d 将 k-形式映射为 (k+1)-形式，满足：
    1. d(α + β) = dα + dβ（线性）
    2. d(α ∧ β) = dα ∧ β + (-1)^k α ∧ dβ（莱布尼茨法则）
    3. d² = 0（幂零性）

  物理中的外微分：
    - 麦克斯韦方程组：dF = 0, d*F = *J
    - 比安基恒等式：dR = 0（曲率的外微分为零）
    - 诺特定理：对称性与守恒量的对应

  联络（Connection）与协变导数：

  联络定义了流形上向量的平行移动，协变导数是联络的具体实现。

  协变导数：
    ∇_μ V^ν = ∂_μ V^ν + Γ^ν_{μρ} V^ρ
    其中 Γ^ν_{μρ} 是克里斯托费尔符号（联络系数）

  物理中的联络：
    - 广义相对论：克里斯托费尔符号描述时空弯曲
    - 规范场论：规范势 A_μ 是主丛上的联络
    - 杨-米尔斯场强：F_{μν} = ∂_μ A_ν - ∂_ν A_μ + [A_μ, A_ν]

  曲率（Curvature）：

  曲率描述流形的弯曲程度，是联络的反对称导数。

  黎曼曲率张量：
    R^ρ_{σμν} = ∂_μ Γ^ρ_{νσ} - ∂_ν Γ^ρ_{μσ} + Γ^ρ_{μλ} Γ^λ_{νσ} - Γ^ρ_{νλ} Γ^λ_{μσ}

  里奇张量：R_{μν} = R^ρ_{μρν}
  标量曲率：R = g^{μν} R_{μν}
  爱因斯坦张量：G_{μν} = R_{μν} - (1/2) g_{μν} R

  物理中的曲率：
    - 广义相对论：爱因斯坦方程 G_{μν} = 8πG T_{μν}
    - 规范场论：杨-米尔斯场强是规范丛的曲率
    - 弦论：卡拉比-丘流形的曲率决定物理参数

  螺旋几何化解释：

  1. 微分几何的螺旋几何化
     - 流形 = 螺旋运动的参数空间
     - 切向量 = 螺旋运动的速度向量
     - 曲率 = 螺旋运动的弯曲程度（κ）
     - 挠率 = 螺旋运动的扭转程度（τ）
     - 联络 = 螺旋运动的平行移动规则

  2. Frenet标架的螺旋几何化
     - Frenet标架 {T, N, B} = 螺旋运动的局部坐标系
     - 切向量 T = 螺旋运动的方向
     - 法向量 N = 螺旋运动的弯曲方向
     - 副法向量 B = T × N = 螺旋运动的扭转方向
     - Frenet方程：dT/ds = κN, dN/ds = -κT + τB, dB/ds = -τN

  3. 三重奏定理的微分几何意义
     - κ² + τ² = (ω/c)² = 螺旋运动的曲率挠率恒等式
     - 这是Frenet标架在光速约束下的必然结果
     - 曲率描述螺旋的弯曲，挠率描述螺旋的扭转
     - 二者之和由螺旋频率和光速决定

【MP2】拓扑学
----------------------------------------------------------------------

  拓扑学概述：

  拓扑学研究几何对象在连续变形下保持不变的性质。
  它不关心距离和角度，只关心连接关系和整体结构。

  拓扑学的分支：
    - 点集拓扑：研究拓扑空间的基本性质
    - 代数拓扑：用代数工具（同调、同伦）研究拓扑
    - 微分拓扑：研究光滑流形的拓扑性质
    - 几何拓扑：研究低维流形的拓扑

  同伦（Homotopy）：

  两个连续映射 f, g: X → Y 称为同伦的，如果存在连续映射
  H: X × [0,1] → Y，使得 H(x,0) = f(x), H(x,1) = g(x)。

  同伦群：
    - 基本群 π₁(X)：环路的同伦类组成的群
    - 高阶同伦群 π_n(X)：n维球面映射的同伦类

  物理中的同伦：
    - 规范场论中的瞬子（instanton）：π₃(SU(2)) = Z
    - 磁单极子：π₂(SU(2)/U(1)) = Z
    - 涡旋：π₁(U(1)) = Z
    - 畴壁：π₀(Z₂) = Z₂

  同调（Homology）：

  同调群 H_n(X) 描述流形中 n维'洞'的数量。

  常见流形的同调群：
    - 球面 S^n：H₀ = Z, H_n = Z, 其他 = 0
    - 环面 T²：H₀ = Z, H₁ = Z², H₂ = Z
    - 实射影空间 RP²：H₀ = Z, H₁ = Z₂, H₂ = 0

  贝蒂数（Betti numbers）：b_n = rank(H_n)
  欧拉示性数：χ = Σ (-1)^n b_n

  物理中的同调：
    - 德拉姆上同调：微分形式的等价类
    - 陈-西蒙斯理论：拓扑量子场论
    - 拓扑绝缘体：拓扑不变量保护的表面态

  示性类（Characteristic classes）：

  示性类是向量丛的拓扑不变量，描述丛的'扭曲'程度。

  常见示性类：
    - 陈类（Chern classes）：复向量丛，c_n ∈ H^{2n}
    - 庞特里亚金类（Pontryagin classes）：实向量丛，p_n ∈ H^{4n}
    - 欧拉类（Euler class）：有向实向量丛，e ∈ H^n
    - 斯蒂弗尔-惠特尼类（Stiefel-Whitney classes）：模2示性类

  物理中的示性类：
    - 陈-西蒙斯形式：规范场论中的拓扑项
    - 阿哈罗诺夫-玻姆效应：拓扑相位
    - 量子霍尔效应：陈数描述的拓扑不变量

  螺旋几何化解释：

  1. 拓扑学的螺旋几何化
     - 拓扑不变量 = 螺旋运动的整体性质
     - 同伦类 = 螺旋运动的连续变形等价类
     - 同调群 = 螺旋运动的'洞'的结构
     - 示性类 = 螺旋丛的扭曲程度

  2. 螺旋拓扑不变量
     - 螺旋数 = 螺旋绕轴的圈数（拓扑不变量）
     - 环绕数（linking number）= 两条螺旋的环绕次数
     - 扭转数（twist number）= 螺旋截面的扭转次数
     -  writhe = 螺旋轴的扭曲程度
     - Călugăreanu定理：Lk = Tw + Wr（螺旋拓扑恒等式）

  3. 物理中的螺旋拓扑
     - 磁通量量子化 = 螺旋磁场的拓扑量子化
     - 涡旋 = 螺旋流体的拓扑缺陷
     - 瞬子 = 螺旋规范场的拓扑非平庸配置
     - 螺旋度（helicity）= ∫ A·B dV = 磁场的拓扑不变量

【MP3】群论与李群
----------------------------------------------------------------------

  群论概述：

  群是描述对称性的数学结构。物理学中的对称性都由群来描述。

  群的定义：
  群 G 是一个集合，配备二元运算 ·，满足：
    1. 封闭性：a·b ∈ G 对所有 a,b ∈ G
    2. 结合律：(a·b)·c = a·(b·c)
    3. 单位元：存在 e ∈ G，使得 e·a = a·e = a
    4. 逆元：对每个 a ∈ G，存在 a⁻¹ ∈ G，使得 a·a⁻¹ = a⁻¹·a = e

  常见群：

  群                         类型                   维数         物理应用
  --------------------------------------------------------------------------------
  Z (整数加法群)                 离散阿贝尔群               0维         电荷量子化, 角动量
  U(1) (幺正群)                连续阿贝尔李群              1维         电磁相互作用, 相位旋转
  SU(2) (特殊幺正群)             连续非阿贝尔李群             3维         弱相互作用, 自旋, 同位旋
  SU(3) (特殊幺正群)             连续非阿贝尔李群             8维         强相互作用, 色荷
  SO(3) (特殊正交群)             连续非阿贝尔李群             3维         空间旋转, 角动量
  SO(1,3) (洛伦兹群)            连续非阿贝尔李群             6维         狭义相对论, 时空对称性
  Poincaré群                 连续非阿贝尔李群             10维        时空平移+洛伦兹变换
  E8 (例外李群)                 连续非阿贝尔李群             248维       大统一理论, 弦论

  李代数（Lie algebra）：

  李代数是李群单位元处的切空间，配备李括号 [X,Y]。
  李代数描述李群的无穷小变换。

  李括号的性质：
    1. 双线性：[aX+bY, Z] = a[X,Z] + b[Y,Z]
    2. 反对称：[X,Y] = -[Y,X]
    3. 雅可比恒等式：[X,[Y,Z]] + [Y,[Z,X]] + [Z,[X,Y]] = 0

  结构常数：[T^a, T^b] = i f^{abc} T^c
    其中 f^{abc} 是结构常数，T^a 是生成元

  表示论（Representation theory）：

  群的表示是群到线性变换群的同态。
  物理中的粒子态都是对称群表示的载体。

  常见表示：
    - SU(2)的表示：自旋 j = 0, 1/2, 1, 3/2, ...，维数 2j+1
    - SU(3)的表示：(p,q)，维数 (p+1)(q+1)(p+q+2)/2
    - 洛伦兹群的表示：(j_L, j_R)，描述粒子的自旋

  标准模型中的表示：
    - 夸克：SU(3)的3表示，SU(2)的2表示
    - 轻子：SU(3)的1表示，SU(2)的2表示
    - 规范玻色子：伴随表示（8, 3, 1）

  诺特定理（Noether's theorem, 1915）：

  每个连续对称性对应一个守恒量。

  对称性与守恒量的对应：
    - 时间平移对称性 → 能量守恒
    - 空间平移对称性 → 动量守恒
    - 空间旋转对称性 → 角动量守恒
    - 相位旋转对称性（U(1)）→ 电荷守恒
    - 同位旋对称性（SU(2)）→ 同位旋守恒（近似）
    - 色对称性（SU(3)）→ 色荷守恒

  螺旋几何化解释：

  1. 群论的螺旋几何化
     - 对称群 = 螺旋运动的变换群
     - 李群 = 螺旋运动的连续变换群
     - 李代数 = 螺旋运动的无穷小生成元
     - 表示 = 螺旋运动在态空间中的实现

  2. 螺旋运动的对称群
     - 螺旋旋转对称性 = 绕螺旋轴的旋转（U(1)）
     - 螺旋平移对称性 = 沿螺旋轴的平移
     - 螺旋缩放对称性 = 螺旋半径的缩放
     - 螺旋共形群 = 螺旋运动的共形变换群

  3. 粒子自旋的螺旋几何化
     - 自旋 = 螺旋运动的内禀角动量
     - 自旋1/2 = 螺旋运动的半整数角动量
     - 自旋1 = 螺旋运动的整数角动量（光子）
     - 自旋2 = 螺旋运动的双螺旋角动量（引力子）
     - SU(2)表示 = 螺旋自旋的数学描述

【MP4】泛函分析与变分法
----------------------------------------------------------------------

  泛函分析概述：

  泛函分析研究无穷维向量空间及其上的线性算子。
  它是量子力学、量子场论、偏微分方程的数学基础。

  希尔伯特空间（Hilbert space）：

  希尔伯特空间是完备的内积空间。
  量子力学中的态空间就是希尔伯特空间。

  内积的性质：
    1. 线性：<aψ+bφ|χ> = a<ψ|χ> + b<φ|χ>
    2. 共轭对称：<ψ|φ> = <φ|ψ>*
    3. 正定性：<ψ|ψ> ≥ 0，等号当且仅当 ψ=0

  常见希尔伯特空间：
    - L²(R)：平方可积函数空间（量子力学波函数）
    - L²(R³)：三维平方可积函数空间
    - ℓ²：平方可和序列空间
    - Fock空间：多粒子态空间

  线性算子（Linear operators）：

  线性算子是希尔伯特空间之间的线性映射。
  量子力学中的可观测量都是自伴线性算子。

  常见算子：
    - 位置算符：X̂ ψ(x) = x ψ(x)
    - 动量算符：P̂ ψ(x) = -iħ dψ/dx
    - 哈密顿量：Ĥ = P̂²/(2m) + V(X̂)
    - 角动量：L̂ = X̂ × P̂
    - 产生/湮灭算符：â†, â

  谱定理（Spectral theorem）：

  自伴算子的谱是实数，且算子可以对角化。
  这保证了量子力学中可观测量的测量值是实数。

  谱的类型：
    - 点谱：离散本征值（束缚态）
    - 连续谱：连续本征值（散射态）
    - 剩余谱：非自伴算子可能有

  变分法（Calculus of variations）：

  变分法研究泛函的极值问题。
  物理学中的基本方程几乎都可以从变分原理导出。

  欧拉-拉格朗日方程：
  对于泛函 S[q] = ∫ L(q, q̇, t) dt，极值满足：
    d/dt (∂L/∂q̇) - ∂L/∂q = 0

  场论中的欧拉-拉格朗日方程：
    ∂_μ (∂L/∂(∂_μ φ)) - ∂L/∂φ = 0

  物理中的变分原理：
    - 最小作用量原理：δS = 0 → 运动方程
    - 费马原理：光走最短光程路径
    - 哈密顿原理：力学系统的真实路径使作用量取极值
    - 变分法在广义相对论中导出爱因斯坦方程

  泛函导数（Functional derivative）：

  泛函导数是变分法中的核心概念，描述泛函对函数的变化率。

  定义：
    δS/δφ(x) = lim_{ε→0} [S[φ+εδ] - S[φ]] / ε
    其中 δ 是狄拉克δ函数

  物理中的泛函导数：
    - 欧拉-拉格朗日方程：δS/δφ = 0
    - 能量-动量张量：T_{μν} = (2/√(-g)) δS/δg^{μν}
    - 诺特定理流：j^μ = (∂L/∂(∂_μ φ)) δφ

  螺旋几何化解释：

  1. 泛函分析的螺旋几何化
     - 希尔伯特空间 = 螺旋波函数的函数空间
     - 态矢量 = 螺旋波函数的数学表示
     - 自伴算子 = 螺旋可观测量的数学表示
     - 谱定理 = 螺旋可观测量的本征值分解

  2. 变分法的螺旋几何化
     - 作用量 = 螺旋运动的泛函
     - 最小作用量原理 = 螺旋运动取极值路径
     - 欧拉-拉格朗日方程 = 螺旋运动的运动方程
     - 泛函导数 = 螺旋运动对参数的变化率

  3. 螺旋路径的变分原理
     - 螺旋运动是作用量的极值路径
     - 螺旋参数（R, ω, b）由变分原理决定
     - 光速约束 v≡c 是变分原理的约束条件
     - 三重奏恒等式 κ²+τ²=(ω/c)² 是变分原理的推论

【MP5】微分方程
----------------------------------------------------------------------

  微分方程概述：

  微分方程是描述物理量变化规律的数学工具。
  几乎所有物理定律都可以表示为微分方程。

  常微分方程（ODE）：

  常微分方程描述单变量函数的导数关系。

  物理中的常微分方程：
    - 牛顿第二定律：m d²x/dt² = F(x, v, t)
    - 简谐振动：d²x/dt² + ω²x = 0
    - 阻尼振动：d²x/dt² + γ dx/dt + ω²x = 0
    - 受迫振动：d²x/dt² + γ dx/dt + ω²x = F₀ cos(Ωt)
    - 开普勒方程：行星运动的微分方程

  偏微分方程（PDE）：

  偏微分方程描述多变量函数的偏导数关系。

  物理中的偏微分方程：

  方程              形式                                       类型              应用
  ------------------------------------------------------------------------------------------
  波动方程            ∂²u/∂t² = c² ∇²u                         双曲型             电磁波, 声波, 引力波
  热传导方程           ∂u/∂t = α ∇²u                            抛物型             热传导, 扩散, 布朗运动
  拉普拉斯方程          ∇²u = 0                                  椭圆型             静电势, 引力势, 稳态温度
  泊松方程            ∇²u = -ρ/ε₀                              椭圆型             静电场, 引力场
  薛定谔方程           iħ ∂ψ/∂t = Ĥψ                            抛物型(量子)         非相对论量子力学
  克莱因-戈登方程        (□ + m²c²/ħ²)ψ = 0                       双曲型             相对论性标量粒子
  狄拉克方程           (iγ^μ ∂_μ - mc/ħ)ψ = 0                   双曲型(旋量)         相对论性费米子
  麦克斯韦方程组         ∂_μ F^{μν} = μ₀ J^ν, ∂_μ *F^{μν} = 0     双曲型             电磁学
  爱因斯坦场方程         G_{μν} = 8πG T_{μν}                      椭圆-双曲混合型        广义相对论, 引力
  杨-米尔斯方程         D_μ F^{μν} = J^ν                         双曲型(非阿贝尔)       强/弱相互作用

  偏微分方程的分类：

  二阶线性偏微分方程的一般形式：
    A u_xx + 2B u_xy + C u_yy + ... = 0

  判别式 Δ = B² - AC：
    - Δ > 0：双曲型（波动方程），特征线实，描述波传播
    - Δ = 0：抛物型（热方程），特征线重合，描述扩散
    - Δ < 0：椭圆型（拉普拉斯方程），特征线复，描述稳态

  格林函数方法：

  格林函数是微分方程的基本解，可以用来构造任意源的解。

  定义：L G(x, x') = δ(x - x')
    其中 L 是微分算子，δ 是狄拉克δ函数

  解的构造：u(x) = ∫ G(x, x') f(x') dx'

  物理中的格林函数：
    - 静电势：φ(r) = (1/4πε₀) ∫ ρ(r')/|r-r'| d³r'
    - 传播子：量子场论中的格林函数
    - 费曼图：格林函数的微扰展开图示
