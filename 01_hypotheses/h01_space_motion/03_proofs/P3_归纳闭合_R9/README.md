## 核心命题

> 对 D 维匀速 m 平面超螺旋曲线 $\mathbf{r}(t)$ 满足 $\mathbf{r}'' = A \mathbf{r}'$
> （$A = \text{diag}(\omega_1 J, \ldots, \omega_m J, 0)$ 斜对称常数），
> Frenet 曲率族满足：
> $$\sum_{i=1}^{D-2}\kappa_i^2 = \frac{\sum_{j=1}^m \omega_j^2}{v^2} = -\frac{\text{tr}(A^2)}{2v^2}$$

## 四步严格证明

| Step | 内容 | 状态 |
|---|---|---|
| 1. 匀速 | A 斜对称 ⟹ d(v²)/dt = 2r′·Ar′ = 0 | ✅ 严格代数 |
| **2. Beᵢ=eᵢ′** | **★ 归纳证明闭合** | ✅ **★ 关键** |

| 4. 封闭 | Σκᵢ² = −tr(A²)/2v² | ✅ 严格代数 |
