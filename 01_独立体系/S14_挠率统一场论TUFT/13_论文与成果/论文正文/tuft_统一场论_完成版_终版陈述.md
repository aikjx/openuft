## 二、TUFT v3 完整作用量

```
S = ∫ { R/(2κ)
      + (1/κ²)[ α₁ R² + α₂ R_{μν}R^{μν} + α₃ R_{μνρσ}R^{μνρσ} ]      ← 曲率二次型（无鬼扇区）
      + ξ l_P (Ω R T)/(2κ)                                            ← TUFT 特有耦合（物理惰性）
      + L_φ  +  L_int  +  L_T^axial  }  √-g d⁴x

L_φ   = -½(∂φ)² - V(φ),   V(φ)=V₀(φ/f-θ₀)² + Λ_eff,   Ω ≡ φ/f
L_int = GR + SM 原样
```

几何基础为 **Cartan 几何** `(P→M, ω)`（模型空间 `ISO(1,3)/SO(1,3)`），`T = de + ω∧e`、`R = dω + ω∧ω`。
量纲账本 **7/7** 配平（`ħ=c=1`，拉氏密度均为 `[M]⁴`；曲率二次型须以 `1/κ²` 归一化，`α_i` 无量纲）。

## 三、挠率扇区（本轮新增，机器核验）

### 3.1 不可约分解 `24 = 4 ⊕ 4 ⊕ 16`

在 `T_{a[bc]}`（4×6 = 24 个分量）上构造线性算符并用 sympy 求秩：

| 算符 | 含义 | 实算 |
|---|---|---|
| `A`（完全反对称化） | 轴 / 赝标量部分 | **投影算符 `A²=A` ✓，`rank = 4`** |
| `V`（迹映射 `v_c = η^{ab}T_{abc}`） | 矢量部分 | **`rank = 4`** |
| `ker A ∩ ker V` | 张量部分 | `24 − rank([A;V]) = 24 − 8 =` **`16`** ✓ |

> 调试记录：初稿把 `-T_cba` 错误地化为 `+T_bca`（应为 `+T_cab`），导致 `A` 非幂等（`rank=24`）；
> 已修正并按「幂等 + 秩 + 正交」三重检验通过。**该坑值得记入工程笔记：反对称化的指标位置不可凭直觉化简。**

### 3.2 无鬼条件

在基 `{R², Weyl², GB}` 下符号求解：

```
L_Q = a R² + b R_{μν}R^{μν} + c R_{μνρσ}R^{μνρσ}
    = x R² + y Weyl² + z GB,     y = (b + 4c)/2
```

`Weyl²` 携带**有质量自旋 2**的传播子且留数为负（鬼）⇒ **无鬼条件：`b + 4c = 0`（即 `α₂ = −4α₃`）**。
满足时 `L_Q = (a−c)R² + c·GB` ⇒ 退化为 **f(R) 型 + 拓扑项**，只留健康的有质量标量（scalaron）。

**推论（承接 C0031）**：`T²` 不含 `∂T` ⇒ 纯代数；`R(ω)²` 含 `∂T` 但 Weyl 分量是鬼 ⇒
**挠率的传播只能来自「不含 Weyl 的曲率二次型 + 轴分量」**。这就是 v3 把挠率动力学限定在轴分量的技术理由。

## 四、传播谱与质量标度

| 自由度 | dof | 质量标度 | 来源 |
|---|---|---|---|
| 无质量引力子 | 2 | 0 | `R/(2κ)` |
| scalaron | 1 | `M_red/√(6(α₁−α₃))` | `R²` 扇区 |
| 轴挠率（赝标量） | 1 | `~ M_red/√|β_T|` | 轴分量动能 |
| 其余挠率分量 | 20 | 代数约束（由自旋密度决定） | 迹 4 + 张量 16 |

- 系数取 `O(1)~1e10` ⇒ 新自由度质量 **10^14 ~ 10^18 GeV**（普朗克附近）；要降到可及能区需 `~1e60` 级微调。
- 轴挠率与费米子的耦合为**轴向**：`L_int ~ (1/f_T)(∂_μP)ψ̄γ^μγ₅ψ`，`f_T ~ M_red` ⇒ 宏观表现为**引力强度的自旋相关 Yukawa 势**。

⇒ 三个新自由度**全部为普朗克质量或普朗克压制耦合**。叠加 ξ 三视界 no-go（C0030）⇒
**v3 在被检验的意义上仍是「不可检验」的** —— 这是「把新物理挂在普朗克标度」的必然后果，不是写形缺陷。
