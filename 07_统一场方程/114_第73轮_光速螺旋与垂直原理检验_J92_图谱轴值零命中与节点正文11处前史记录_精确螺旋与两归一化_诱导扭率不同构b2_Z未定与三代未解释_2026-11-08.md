## 三、精确形式化（全有理、两取样点机验）

度规 `η=diag(−1,+1,+1,+1,+1,+1)`，光线取

```
x(τ) = (cτ, R cos ωτ, R sin ωτ, 0, 0, 0)        # 后三维为内坐标，恒定
```

### 3.1 `ds²=0 ⇔ Rω=c`

```
ds² = −c²dτ² + R²ω²(sin²ωτ + cos²ωτ)dτ² = (R²ω² − c²)dτ²
```

⇒ `R=c/ω`（`c=1` 归一下即 `R=1/ω`）。两个有理取样点：

| 点 | ω | cos／sin | R=c/ω |
|---|---|---|---|
| ① | 7/5 | 3/5、4/5 | 5/7 |
| ② | 3/2 | 5/13、12/13 | 2/3 |

### 3.2 切矢、加速度、垂直

```
T = dx/dτ = (c, −Rω sin ωτ, Rω cos ωτ) = (c, −c sin, c cos)      # 用 Rω=c
A = dT/dτ = (0, −cω cos, −cω sin)                                  # 横向加速度
```

- `η(T,T) = −c² + c²(sin²+cos²) = 0` ⇒ **T 是零矢**（这是「光速」的全部内容）。
- `η(A,A) = c²ω²(sin²+cos²) = ω²`。
- `η(T,A) = 0·(−c) + (−c sin)(−cω cos) + (c cos)(−cω sin) = c²ω(sin cos − cos sin) = 0`。

**「垂直」= 加速度与切矢正交**，即 `η(T,A)≡0`，逐点精确，不是比喻；也不需要额外假设。

### 3.3 曲率与挠率（两种归一化，差因子 2）

| 归一化 | 曲率 | 挠率 | 两个取样点取值 |
|---|---|---|---|
| 零曲线（用 τ、`|T⁰|` 归一） | `κ = |A|/|T⁰|² = ω = 1/R` | `τ = ±κ` | 7/5 与 3/2 |
| 三维欧氏 Frenet（空间部分、弧长） | `κ₃ = |T×A|/|T|³ = ω/2 = 1/(2R)` | `τ₃ = det(T,A,A′)/|T×A|² = ω/2` | 7/10 与 3/4 |

两式机验均精确有理（`|T×A|²=2ω²`、`det(T,A,A′)=ω³`）。**`κ₃=τ₃` 是恒等式**，对每个 R 都成立——这一点是第五节成败判据的全部根据。

差因子 2 的来源：零曲线用 `τ` 与 `|T⁰|`，欧氏 Frenet 用空间弧长（空间速率 `√2`）。**本卷以下一律标注用的是哪一支**（H-05 记歧义）。

### 3.4 `τ=±κ` 的符号 = 手性

镜像 `x(τ)=(cτ, R cos ωτ, −R sin ωτ)` ⇒ 机验 `τ₃=−ω/2`。故 `τ=±κ` 的 `±` 就是右手／左手螺旋，不是两个物理分支。

### 3.5 只有一个自由参数

`(R, ω, h)` 三写一物，`Rω=c` ⇒ **自由度 1**（`h=2πc/ω=2πR` 连续可变）。几何本身不产离散量子数；要离散量必须另加闭合条件（见第七节）。

## 五、成败判据：曲率=挠率能否把 `Z` 钉死

### 5.1 约束计数

`κ₃=τ₃=1/(2R)` 在 R=5/7 与 R=2/3 两个**互异**取值上同时成立 ⇒ 它不是对 R 的方程，是零质量螺旋的**恒等式**。因此：

```
新增约束 = 0     （不是 1，也不是把 r 固定）
```

### 5.2 Z 的两层缺口

```
N_T = 1 + 4κ₆/Z          （108 卷 EC 约化）
Z   = 12κ₆/(5r)          （110 卷 P4 单迹）
⇒ N_T = 1 + (5/3)r       （三点闭合：r=1,2,12/5 ⇒ N_T=8/3,13/3,5）
```

- **第一层**：`r=f₂/f₀` 由外部给（110 卷已证 `r` 是泛函，不是数）。
- **第二层**：`Z=12/(5r)` 里的 `κ₆` 由归一约定给（110 卷把 `κ₆` 归一到 1），螺旋对 `κ₆` 给 **0** 约束。

⇒ **Z 不唯一**。即便外部给 `r`，得到的也只是「归一约定下的数」，不是原理定出的唯一值。

### 5.3 判词

```
螺旋不是原理，是「参数重述」（R ↔ 沿曲线单位的选择）
```

理由：螺旋是 `ds²=0` 的一条**运动学曲线**，不是 `S₆` 里新增的场或项。把它写进作用量只会重述「沿零方向传播」，`{g₆, κ₆, Z, L}` 仍是 4 个参数，一个也没少。**不允许**含糊成「螺旋给了尺度」——它给的是坐标重标，不是新约束。
