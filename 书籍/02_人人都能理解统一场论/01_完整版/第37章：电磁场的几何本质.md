## 37.1 电磁力是什么？

### 37.1.1 电磁力的直观感受

电磁力是我们日常生活中经常接触到的另一种基本力，它的直观感受包括：

- **摩擦起电**：当两个物体相互摩擦时，会产生静电，这是电磁力的表现。

- **磁铁吸引**：磁铁可以吸引铁、钴、镍等金属，这是磁场力的表现。

- **电流作用**：电流通过导线时，会产生磁场，电磁铁就是利用这一原理制成的。

- **雷电现象**：雷电是云层之间或云层与地面之间的放电现象，这是强电磁场的表现。

- **光的传播**：光是电磁波的一种，它的传播是电磁力的表现。

这些直观感受都与电磁力有关，电磁力是宇宙中第二强的力，它影响着从微观粒子到宏观电器的一切带电物体。

### 37.1.2 电磁力的特点

电磁力具有以下基本特点：

1. **长程力**：电磁力的作用范围非常广，理论上可以延伸到无限远。两个电荷之间的距离越大，电磁力越小，但永远不会完全消失。

2. **强力**：电磁力是四种基本力中第二强的力，其强度是引力的10³⁶倍，但只有强力的1/100。

3. **吸引力和排斥力**：电磁力既有吸引力（异性电荷），又有排斥力（同性电荷）。这与引力不同，引力只有吸引力。

4. **与电荷成正比**：电磁力的大小与物体的电荷量成正比，电荷量越大，电磁力越强。

5. **与距离的平方成反比**：电磁力的大小与两个电荷之间距离的平方成反比，距离越远，电磁力越小。

6. **与介质有关**：电磁力的大小与电荷之间的介质有关，不同介质的介电常数不同，会影响电磁力的大小。

7. **能产生波**：变化的电磁场可以产生电磁波，电磁波以光速传播，光就是一种电磁波。

这些特点使电磁力在日常生活和科技领域中起着主导作用，它决定了电器的工作原理和电磁波的传播。

### 37.1.3 电磁力的应用

电磁力的应用非常广泛，几乎渗透到我们生活的方方面面：

1. **电力系统**：发电、输电、配电等电力系统都是利用电磁力工作的。

2. **电子设备**：计算机、手机、电视、收音机等电子设备内部的电路和元器件都是利用电磁力工作的。

3. **通信技术**：无线电通信、有线通信、光纤通信等通信技术都是利用电磁波传递信息的。

4. **医疗技术**：X光机、CT扫描仪、MRI等医疗设备都是利用电磁力成像的，治疗癌症的放疗也利用电磁力。

5. **工业技术**：电动机、发电机、变压器、电焊机等工业设备都是利用电磁力工作的。

6. **交通技术**：电动汽车、磁悬浮列车、电动自行车等交通工具都是利用电磁力驱动的。

7. **军事技术**：雷达、导弹制导、电磁炮等军事设备都是利用电磁力工作的。

这些应用都与电磁力有关，电磁力是现代科技的基础，它推动了人类文明的进步。

## 37.2 电场的几何本质：空间变化的表现

### 37.2.1 电场的几何化

在统一场论中，电场是空间旋转状态的分布，它描述了空间旋转方向的分布。正电荷对应空间的顺时针旋转，负电荷对应空间的逆时针旋转。

电场的几何化可以用矢量场来表示，电场强度**E**是一个矢量，它的大小表示电场的强度，方向表示正电荷在该点所受电场力的方向。

对于点电荷q，其电场强度的公式为：

**E** = kq/r² r̂

其中，k是库仑常数，r是距离点电荷的距离，r̂是指向场点的单位矢量。

从几何角度来看，电场强度的大小与距离的平方成反比，方向沿径向指向（正电荷）或背离（负电荷）点电荷。电场线是描述电场分布的直观工具，电场线从正电荷出发，终止于负电荷，电场线的密度表示电场强度的大小。

### 37.2.2 电场与空间旋转的关系

电场与空间旋转的关系可以用以下方式理解：

- 正电荷对应空间的顺时针旋转，当空间以顺时针方向旋转时，会产生正电场。
- 负电荷对应空间的逆时针旋转，当空间以逆时针方向旋转时，会产生负电场。
- 电场强度的大小与空间旋转角速度成正比，旋转角速度越大，电场强度越强。
- 电场强度的方向与空间旋转方向垂直，符合右手螺旋定则。

具体来说，当空间以角速度ω旋转时，产生的电场强度**E**与ω的关系为：

**E** ∝ ω × r

其中，r是旋转半径。这个关系表明，电场强度与空间旋转角速度和旋转半径的叉积成正比，方向由右手螺旋定则确定。

### 37.2.3 电场强度的计算

电场强度的计算可以通过库仑定律或高斯定理进行：

1. **库仑定律**：对于点电荷q，电场强度**E** = kq/r² r̂。对于多个点电荷，电场强度可以通过矢量叠加得到。

2. **高斯定理**：对于闭合曲面S，通过曲面的电通量等于曲面内电荷量的1/ε₀倍，即∮ₛ**E**·d**S** = Q/ε₀。利用高斯定理可以方便地计算具有对称性的电场，如球对称、轴对称、平面对称等。

3. **电势梯度**：电场强度是电势φ的负梯度，即**E** = -∇φ。电势是标量，计算电势比直接计算电场强度更方便，因此可以先计算电势，再通过梯度得到电场强度。

这些计算方法可以定量地描述电场的分布，它们是电磁学的重要工具。

## 37.3 磁场的几何本质：空间旋转的表现

### 37.3.1 磁场的几何化

在统一场论中，磁场是空间旋转运动的分布，它描述了空间旋转角速度的分布。电流是电荷的定向运动，当电荷运动时，会带动周围的空间一起旋转，从而产生磁场。

磁场的几何化可以用矢量场来表示，磁感应强度**B**是一个矢量，它的大小表示磁场的强度，方向表示小磁针北极在该点所指的方向。

对于电流元Id**l**，其磁感应强度的公式由毕奥-萨伐尔定律给出：

d**B** = (μ₀Id**l**×r̂)/(4πr²)

其中，μ₀是真空磁导率，r是距离电流元的距离，r̂是指向场点的单位矢量。

从几何角度来看，磁感应强度的大小与距离的平方成反比，方向由右手螺旋定则确定。磁感线是描述磁场分布的直观工具，磁感线是闭合曲线，没有起点和终点，磁感线的密度表示磁感应强度的大小。

### 37.3.2 磁场与空间旋转的关系

磁场与空间旋转的关系可以用以下方式理解：

- 电流是电荷的定向运动，当电荷运动时，会带动周围的空间一起旋转，从而产生磁场。
- 磁场的方向与空间旋转方向符合右手螺旋定则：右手四指沿电流方向弯曲，拇指指向磁场方向。
- 磁感应强度的大小与空间旋转角速度成正比，旋转角速度越大，磁感应强度越强。
- 磁场是空间旋转运动的表现，它与电场密切相关，变化的电场可以产生磁场，变化的磁场也可以产生电场。

具体来说，当电荷以速度v运动时，会产生环形的空间旋转，这种旋转的角速度ω与v的关系为：

ω ∝ v × r/r³

其中，r是距离电荷的距离。这种环形旋转的空间分布就是磁场，它的方向由右手螺旋定则确定。

### 37.3.3 磁场强度的计算

磁感应强度的计算可以通过毕奥-萨伐尔定律或安培环路定理进行：

1. **毕奥-萨伐尔定律**：对于电流元Id**l**，磁感应强度d**B** = (μ₀Id**l**×r̂)/(4πr²)。对于有限长载流导线、载流圆线圈、载流螺线管等，可以通过积分得到磁感应强度的分布。

2. **安培环路定理**：对于闭合环路L，磁感应强度的环流等于环路内电流的μ₀倍，即∮_L**B**·d**l** = μ₀I。利用安培环路定理可以方便地计算具有对称性的磁场，如长直载流导线、载流螺线管、载流螺绕环等。

3. **矢量势**：磁感应强度是矢量势**A**的旋度，即**B** = ∇×**A**。矢量势是矢量，计算矢量势比直接计算磁感应强度更方便，因此可以先计算矢量势，再通过旋度得到磁感应强度。

这些计算方法可以定量地描述磁场的分布，它们是电磁学的重要工具。

## 37.4 电磁场的统一：麦克斯韦方程组

### 37.4.1 麦克斯韦方程组的几何解释

麦克斯韦方程组是描述电磁场分布和变化规律的基本方程，它由四个方程组成：

1. **高斯电场定律**：∮ₛ**E**·d**S** = Q/ε₀
   几何解释：电场线从正电荷出发，终止于负电荷，电通量与电荷量成正比。

2. **高斯磁场定律**：∮ₛ**B**·d**S** = 0
   几何解释：磁感线是闭合曲线，没有起点和终点，磁通量恒为零。

3. **法拉第电磁感应定律**：∮_L**E**·d**l** = -dΦ_B/dt
   几何解释：变化的磁场产生电场，电场强度的环流等于磁通量变化率的负值。

4. **安培-麦克斯韦定律**：∮_L**B**·d**l** = μ₀I + μ₀ε₀dΦ_E/dt
   几何解释：电流和变化的电场都可以产生磁场，磁感应强度的环流等于电流和电通量变化率的和乘以μ₀。

这些方程从几何角度描述了电磁场的分布和变化规律，它们是电磁场理论的核心。

### 37.4.2 电磁场的统一描述

麦克斯韦方程组将电场和磁场统一为电磁场，它们是同一事物的两个不同方面，相互依存，相互转化：

- 变化的电场可以产生磁场（安培-麦克斯韦定律）。
- 变化的磁场可以产生电场（法拉第电磁感应定律）。
- 电场和磁场都是空间状态的分布，它们是空间变化的不同表现形式。

这种统一描述揭示了电磁场的本质，它是空间旋转状态和旋转运动的结合，是空间变化的综合表现。

电磁场的统一描述可以用张量来表示，电磁场张量是一个二阶反对称张量，它有6个独立分量，分别对应电场强度的3个分量和磁感应强度的3个分量。电磁场张量的变换规律符合洛伦兹变换，这表明电磁场是相对论协变的，它在不同参考系中具有相同的形式。

### 37.4.3 电磁波的产生与传播

麦克斯韦方程组预言了电磁波的存在，电磁波是电磁场的传播，它以光速在真空中传播。电磁波的产生与传播过程如下：

1. 当电荷加速运动时，会扰动周围的空间旋转状态，产生变化的电场。
2. 变化的电场会产生变化的磁场（安培-麦克斯韦定律）。
3. 变化的磁场会产生变化的电场（法拉第电磁感应定律）。
4. 这种相互激发的电场和磁场会以光速向周围传播，形成电磁波。

电磁波的传播速度等于光速c，这是因为光速是空间运动的基本速度，而电磁波是空间状态的传播，因此其传播速度必然是光速。

电磁波的频谱非常广，包括无线电波、微波、红外线、可见光、紫外线、X射线、γ射线等，它们的区别在于频率不同，但本质都是电磁波。

## 总结

本章我们探讨了电磁场的几何本质，主要内容包括：

1. **电磁力的概念**：电磁力是宇宙中第二强的力，它既有吸引力，又有排斥力，作用范围广，与电荷成正比，与距离的平方成反比。

2. **电场的几何本质**：电场是空间旋转状态的分布，正电荷对应空间的顺时针旋转，负电荷对应空间的逆时针旋转，电场强度是空间旋转状态的梯度。

3. **磁场的几何本质**：磁场是空间旋转运动的分布，电流是电荷的定向运动，电荷运动时会带动周围的空间一起旋转，从而产生磁场，磁感应强度是空间旋转运动的旋度。

4. **电磁场的统一**：麦克斯韦方程组将电场和磁场统一为电磁场，它们是同一事物的两个不同方面，相互依存，相互转化，变化的电场产生磁场，变化的磁场产生电场，这种相互激发的过程形成了电磁波，以光速传播。

通过对电磁场几何本质的探讨，我们可以更好地理解电磁力的本质，以及电场和磁场的关系。这是统一场论的核心内容之一，也是电磁学的重要基础。

## 37.5 电磁场与引力场的转化

### 37.5.1 变化的引力场产生电磁场

在张祥前统一场论的20个核心公式中，**变化的引力场产生电磁场**（第12个公式）为：

$$\frac{\partial^{2}\vec{A}}{\partial t^{2}} = \frac{\vec{v}}{f}\left(\vec{\nabla}\cdot\vec{E}\right) - \frac{c^{2}}{f}\left(\vec{\nabla}\times\vec{B}\right)$$

**符号解释**：
- $\vec{A}$ 是引力场强度矢量（与第4个公式中的定义一致）
- $\vec{E}$ 是电场强度矢量
- $\vec{B}$ 是磁感应强度矢量
- $\vec{v}$ 是物体速度矢量
- $c$ 是光速
- $f$ 是场转化耦合常数

**物理意义**：
- 引力场的二阶时间导数可以产生电磁场
- 电场的散度和磁场的旋度对引力场变化有贡献
- 这揭示了引力场与电磁场的内在联系

### 37.5.2 变化的引力场产生电场

**变化的引力场产生电场**（第14个公式）为：

$$\vec{E} = -f\frac{d\vec{A}}{dt}$$

**物理意义**：
- 引力场的时间变化率产生电场
- 场转化耦合常数 $f$ 描述了转化效率
- 这为电磁感应现象提供了新的解释

### 37.5.3 变化的磁场产生引力场和电场

**变化的磁场产生引力场和电场**（第15个公式）为：

$$\frac{d\vec{B}}{dt} = -\frac{\vec{A}\times\vec{E}}{c^2} - \frac{\vec{v}}{c^{2}}\times\dfrac{d\vec{E}}{dt}$$

**物理意义**：
- 磁场的变化同时产生引力场和电场
- 引力场与电场的叉乘对磁场变化有贡献
- 这揭示了磁场、引力场和电场的统一机制

### 37.5.4 磁矢势方程

**磁矢势方程**（第13个公式）为：

$$\vec{\nabla} \times \vec{A} = \frac{\vec{B}}{f}$$

**物理意义**：
- 磁矢势的旋度等于磁场强度除以耦合常数
- 这将磁矢势与磁场联系起来
