## 四 主定理 A：APS `η` 项真的算出来了，不是抄结论

边界算子取 `H = −i∂_θ + a`，谱 `λ_m = m + a`（`m` 为整数）。`0 < a < 1` 时热核 `η` 函数可精确重排为

```
eta_t(a) = sum_{m>=0} exp(-t(m+a)) - sum_{m>=1} exp(-t(m-a))
         = (exp(-a t) - exp(-(1-a) t)) / (1 - exp(-t))
         = sinh((1/2 - a) t) / sinh(t/2)
```

`sinh` 形式是**本册自己做的重排**：原式分子与分母在 `t→0` 时各自相消，重排后只剩一次相消，数值稳定性显著提升。`t→0` 的极限是 `1−2a`。

数值侧完全独立：用 `Decimal(prec=60)` 自算 `exp`，对 `t = 2^{-k}`（`k=1..14`）取 14 个值，做**三级 Richardson** 依次消 `t² / t⁴ / t⁶`；再用 `t = 3^{-k}` 的第二条数值路径复核。七档闭式与三级外推的最大残差为 `2.067...E-37`，两条底数路径的最大差同量级。

> **口径自守（本册最贵的方法修正）**：换 `t` 底时 Richardson 系数必须同步换成 `base^p`。`base=2` 用 `4 / 16 / 64`，`base=3` 用 `9 / 81 / 729`。首版把系数写死成 `2^p`，base=3 路径直接给出 `3.38E-13` 的假偏差，被 `A01` 判据当场抓住。

**退化点必须显式报（`A01`）**：`a=1/2` 时 `b=1/2−a=0`，`sinh(0)≡0` 使 `η_t` 精确恒为 0，`res_raw` 精确为 0。相对基准若取全表最小值就会变成 0，把非退化档全部拖红。按「退化点恒绿」「凡统计符号必须同时报零的个数」的纪律，本册把该档单独标为退化档、从相对判据中排除，并要求它的三级残差与两底差都精确为 0。**这不是放宽门限，是把对象分开。**

其余三条边界侧判决：

- **反对称（`A02`）**：数值两路分别算 `η(a)` 与 `η(1−a)`，7 档最大和 `0E-60`；读数确实不同的 `6` 对、相同的 `1` 对（`a=1/2` 退化档）。显式报相同对数，防负对照自己恒绿。
- **输入选支（`A03`）**：`a` 越出基本域 `(0,1)` 时直接代入热核式给 `1−2a`，而先归约到 `a mod 1` 再算给 `0`。三档 `3/2 / 5/2 / −1/2` 的偏差为 `−2 / −4 / +2`，两两不同，证明判据测的确实是规范等价类。
- **谱流（`A05` / `A06`）**：显式枚举 `λ_m` 从 `a₁` 到 `a₂` 跨过 0 的净次数，6 对逐对等于 `floor(a₂) − floor(a₁)`；其中 `2` 对给 3、`4` 对不给 3。所以**奇数 3 在谱流意义下可达**——但 `A06` 的 note 立刻写明「可达不等于被作用量挑中」。

> `A07` 记 **IDENTITY** 而非 PASS：`ζ(0,a)=1/2−a` 与 `η=1−2a` 是同一解析延拓的两面，展开后无残差可算。按「同源回验抓不到同源错误」刀，显式标注、不冒充第三条独立证据，并由守卫 `SAME-SOURCE-TAGGED` 强制该标注存在。

## 五 主定理 B：V63 自带的标量没有 `π₁`，做不出拓扑涡旋

V63 整理册 `C01` / `C06` 的标量势是实四次势 `V(φ) = −μ²φ²/2 + λφ⁴/4`，且 `V''(φ₀) = 2μ²` 与 `λ` 无关。本册取归一 `μ²=1, λ=2`（使 `φ₀² = μ²/λ = 1/2` 与 V63 一致），在有理网格上精确解 `V'(φ)/φ = −1 + 2φ² = 0`：

- 唯一正驻点 `t = φ² = 1/2`，二阶导 `2 > 0` ⇒ 极小；
- 原点 `t=0` 二阶导 `−1 < 0` ⇒ 极大，不是真空；
- 真空流形 `M_vac = {+φ₀, −φ₀}`，**两个孤立点**，即 `π₀ = Z₂`、`π₁ = 0`。

`π₁=0` 在本册不是引用，而是**枚举**：把 `S¹` 离散成 8 个采样点、值域取两个真空点，共 `2⁸ = 256` 个候选环路。要求相邻采样点相同（离散集上连续的充要条件），只有 `2` 个常值环路通过，`254` 个不连续，**连续且非常值的环路 `0` 个**。

对照侧真算：复标量 `V = λ(abs(φ)² − v²)²` 的真空流形是 `S¹`，相位 `φ(θ)=v·exp(i n θ)` 的离散绕数对 `n=0..5` 给 `0..5` 六个互异整数且环路全闭合；`n=1/2` 时终点相位落在 `M/2`、环路不闭合，单值性失败。

⇒ **结论**：想要拓扑稳定的涡旋（以及由涡旋数 `n` 索引的局域零模），必须把 V63 的实标量换成**带电复标量**，也就是新增场、新增势能、新增破缺动力学。`B07` 从另一侧给出同一判定：中性标量 `q=0` 时 8 档 `n` 的相位耦合计数全为 `0`。**两条独立路径都堵住「用 V63 已有场做缺陷」这条路。**
