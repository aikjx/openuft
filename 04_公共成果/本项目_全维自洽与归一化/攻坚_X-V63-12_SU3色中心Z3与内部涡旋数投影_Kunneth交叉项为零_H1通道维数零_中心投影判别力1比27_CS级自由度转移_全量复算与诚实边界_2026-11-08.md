## 四 主定理 A：上同调账——两个磁通属于不同直和分量

`S^2` 取四面体边界单纯复形：4 顶点 / 6 边 / 4 面，系数 `F_3`。边缘映射矩阵在有限域上做整数高斯消元真算：

```
rank d1 = 3 , rank d2 = 3
H^0 = 4 - 3 = 1
H^1 = (6 - 3) - 3 = 0
H^2 = 4 - 3 = 1
```

`d1` 复合 `d2` 的最大元 `0`，链层欧拉数 `4 - 6 + 4 = 2` 与同调层欧拉数 `1 - 0 + 1 = 2` 相符（`A02` 两路独立：一个是矩阵乘法，一个是维数交替和）。**这是实算，不是抄球面上同调结论**（`A01`）。

Künneth 用最小 CW 复形（微分全零）：`M_4 = S^2 x S^2` 的胞腔维数表 `{0:1, 1:0, 2:2, 3:0, 4:1}`，内部 `S^2` 为 `{0:1, 1:0, 2:1}`。张量积给 `X = M_4 x S^2` 的七档链维数表 `{0:1, 1:0, 2:3, 3:0, 4:3, 5:0, 6:1}`，故

```
H^2(X) = H^2(M_4) 乘 H^0(S^2)  +  H^1(M_4) 乘 H^1(S^2)  +  H^0(M_4) 乘 H^2(S^2)
       = 2 + 0 + 1 = 3
```

色 `Z_3` t Hooft 磁通属于 `H^2(M_4, Z_3)`（M 分量），内部 U(1) 线丛第一陈类属于 `H^2(S^2, Z_3)`（S 分量）。二者**是直和的不同分量，交叉项为 0**。把色群中心搬来当内部空间投影，正是把不同分量相加——这是本册最核心的一次**对象错位**抓法（`A05`）。
