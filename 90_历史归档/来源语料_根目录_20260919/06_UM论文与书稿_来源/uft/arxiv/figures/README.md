1. `helix_geometry.pdf` - Helix structure diagram
   - 3D helix with radius R and pitch P

2. `four_forces.pdf` - Four perpendicular modes diagram

   - Show EM (radial), Strong (tangential), Weak (chiral), Gravity (axial)

3. `coupling_ratios.pdf` - Gauge coupling comparison
   - Bar chart: framework vs experiment
   - Show 15:4:1 ratio
   - Include error bars

Generate figures using:
  python code/generate_figures.py
