## 一、记号与两支的定义

记源稿所列能量密度中的势能为

```
U(ψ) := V₁/4·ψ⁴ − V₂/6·ψ⁶ ,   U′(ψ) = V₁ψ³ − V₂ψ⁵          （源稿 ODE 的右端）
E₀[ψ] := ∫ 4πr² [ ½ψ′² + U(ψ) ] dr                            （源稿所列能量）
```

对 `E₀` 取一阶变分（`η` 紧致支撑）给出

```
δE₀[η] = ∫ 4πr² [ ψ′η′ + U′(ψ)η ] dr
       = 边界项 − ∫ 4πr² [ ψ″ + (2/r)ψ′ − U′(ψ) ] η dr
```

⇒ **`E₀` 的 EL 方程**为 `ψ″+(2/r)ψ′ = U′(ψ)`，等价写法 `−ψ″−(2/r)ψ′ = −(V₁ψ³−V₂ψ⁵)`。
而**源稿字面式**为 `−ψ″−(2/r)ψ′ = +（V₁ψ³−V₂ψ⁵）`，即 `ψ″+(2/r)ψ′ = −U′(ψ)`，它是

```
Ẽ₀[ψ] := ∫ 4πr² [ ½ψ′² − U(ψ) ] dr                            （势能项整体反号）
```

的 EL 方程。把任一支的方程代入另一支的驻点条件，剩余 `2U′(ψ)` 项（`ψ′η′` 分部积分后与
`U′` 项的系数差 `1−(−1)=2`），只要 `ψ ∉ {0, √(V₁/V₂)}` 便非零。仪器用参数 `s ∈ {−1,+1}`
同时积分两支：

```
ψ″ = −(2/r)ψ′ + s·U′(ψ)      s=−1 → 源稿字面支 ；  s=+1 → E₀ 的 EL 支
```

前序分析文 `tuft_v32_参数拟合_伴随梯度与自旋约束_分析.md` §（伴随）段的**勘误块**（2026-09-28 轮追加）
已记下同一代数事实："与所列 `𝓕` 的非线性块**反号**，差 `2(V₁−V₂ψ²)ψ³≠0`""`𝓕` 是势能反号泛函
`∫[½ψ′²−V₁/4ψ⁴+V₂/6ψ⁶]` 的 EL 方程"（其符号读数挂在 `07_统一场方程/…/V3_8_paramfit_branch_checks.json`
的 `checks.T1_el_sign`，台账 C80）。**该代数不据为本轮新发现**；本文的增量是：(i) 把它变成**可复跑的
数值判据**（弱形式 2×2 表 + 三枚变异体），(ii) 用它把已落盘 C0039 的机理文字与 C0037 的前提**归支**，
(iii) 在 S14 台账补登相应主张（此前 `claims.csv` 无任何 EL 配对条目）。

## 二、为什么必须用弱形式（而不是代回式）—— 方法学一节

**代回式验算**（"数值剖面是否满足它所积分的那条方程？"）在本问题上是**空通道**：它对两支同时成立，因而对"配的是哪条能量"毫无判别力。运行记录 `[S4] M1` 把它测成了可复跑的读数：

| 支 | 对**自身**方程的归一化强残差 h=1e-2 | h=1e-3 | 比值（应≈100） | 对**对方**方程 |
|---|---|---|---|---|
| `s=−1` 字面支 | `9.097e-06` | `9.222e-08` | `98.6` | `2.000000` |
| `s=+1` EL 支 | `1.943e-04` | `1.943e-06` | `100.0` | `1.999998` |

自身残差按 `h²` 收缩 ⇒ 它是中心差分的**截断误差**，不是物理剩余（这正是"验算通过"的幻觉来源）；把方程换成对方，残余立刻精确等于 `2·U′` 的幅度（归一化后 `2.000`）。所以本工具采用**弱形式残差** `δE₀[η]`：只需一阶导数（`ψ′` 由 RK45 稠密输出解析给出，`η` 取 5 个紧致支撑于 `(5,200)` 的独立闭式函数），且"对一切 `η` 为零"才是驻点的定义。

## 三、弱形式 2×2 表：驻点身份随能量符号互换（判定 #1 #2）

`[S2]` 与 `[S4] M3` 的残差比（`|δE₀[η]| / ∫4πr²|U′||η|dr`，5 个 `η` 的中位数）：

| | `sig=+1`（所列 `E₀`） | `sig=−1`（势能反号 `Ẽ₀`） | 倍率 |
|---|---|---|---|
| `s=−1` 源稿字面支 | `1.287e+00` | `3.855e-11` | `x2.996e-11` |
| `s=+1` `E₀` 的 EL 支 | `1.327e-10` | `2.318e-04` | `x1.747e+06` |

读法：**每一支都是"某一条能量"的驻点，但源稿把方程与能量配错了对象**。字面支配 `Ẽ₀`（残差 `3.855e-11`）、EL 支配 `E₀`（`1.327e-10`）；一旦按源稿的样子（字面方程 + 所列 `E₀`）组合，残差比是 `1.287`——与非线性块同阶，不是数值误差量级。

两处**量级为何未达理论上界 2** 已在记录中说明，避免误读：EL 支反号值 `2.318e-04` 之所以远小于 2，是因为该剖面停在 `U′≈0` 的平台、`U′` 在 `η` 支撑内变号相互抵消；字面支基线 `1.287<2` 同理来自 `ψ` 过零。判据因此按"配对互换"（`<1e-4` 与 `>1e3` 倍）书写，而非按"达到 2"——后者在此语料上不可满足，属于误定价的针。

## 五、对 C0037（包络定理）的适用条件补充（判定 #5）

C0037 的结论"E0 不走伴随、应用包络定理 `dE₀/dV₁=¼∫ψ⁴4πr²dr`、`dE₀/dV₂=−⅙∫ψ⁶4πr²dr`"依赖**包络定理的前提**：被积剖面是所论能量的驻点。本文的读数是：

- 在 **EL 支**（仓库实现支、亦即落盘 `[C]` 表所属支）上前提成立（残差比 `1.327e-10`）⇒ C0037 的公式在**该支**上可直接用；
- 在**源稿字面约定**下前提不成立（同一条 `E₀` 的残差比 `1.287`，与非线性块同阶）⇒ 若有人在字面支上照抄包络定理，就丢掉一整支 `O(1)` 贡献，`dE₀/dV₁` 不再是"只积显式 `V₁` 依赖"。

故给 C0037 补的适用条件应写成：**"ψ_s 取 E₀ 的 EL 支剖面"**（等价：源稿需先把 ODE 与 E₀ 的符号约定配成一对）。这是一条**范围收窄**，不是撤回；C0037 原文与状态行不改（台账 append-only，新编号承载订正）。
