# ROOT V139｜严谨几何审查 + 可复算工具

**研究性质**：条件性理论模型检验，不是统一场论成功证明。重点检查 S9/Spin10/Hopf 结构、普通 Dirac 无零模、Einstein 背景障碍及真实机械内旋对四维光速的影响。

## 一键运行

Windows: 双击 `一键验证.bat`，或执行 `py -3 src\verify_v139.py`。
Linux/macOS: `bash 一键验证.sh`，或 `python3 src/verify_v139.py`。

Python >=3.10，**仅标准库**。默认输出在 `data/`；可执行 `python3 src/verify_v139.py --out /tmp/root-v139-results`。运行不需要网络访问。

## 内容

- `研究报告.md` —— 中文完整假设、求导、界限、科学状态、可否证条件、参考文献。
- `核心公式.tex` —— 全部核心式（可合并至 LaTeX 项目）。
- `src/verify_v139.py` —— 整数 so10 矩阵交换子、分数秩、球面 Dirac、量纲、null 螺旋、数据导出。
- `data/` —— 光谱、质量尺度、真实螺旋速度参数、测试分组和结果 JSON。
- `docs/ROOT_V140_实验与理论判伪清单.md` —— 下一轮的硬性准入标准。
- `archive/ROOT_V138_统一场论_电荷量子化_Spin10_四力审查_完整研究包.zip` —— 未更动的上一版历史归档，V138 包又含更早历史版。
- `SHA256SUMS.txt` —— 核对主要文件哈希；外部 ZIP 另进行独立解压检查。

**单位约定**：在理论公式里仅设 `c=1`；ħ、G_4、G_13 均保留独立量纲。表中的 GeV 与 m 为 SI 对照计算。

**科学诚信**：程序通过的是输入假设下的代数/数值断言。H²(S9)=0、Lichnerowicz 定理等属于已知数学结果，有限计算不证明这些定理；没有新物理观测，也没有证明四力统一。
