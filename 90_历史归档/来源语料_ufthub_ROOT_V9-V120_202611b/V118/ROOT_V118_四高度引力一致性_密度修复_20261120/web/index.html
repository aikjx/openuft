数学身份与科学边界

K(r)=GM[1+C(1+r/ℓ)e⁻ʳ/ℓ]

1/ℓ=1/r−K″(r)/K′(r)

K″²−K‴K′−K′²/r²=0，其中 K′≠0。

这些结论仅针对球外、线性、单一作用程的模型。它们是测试模型的必要条件，不是已经测量到第五力，也不意味着建立了四力共同本源。
