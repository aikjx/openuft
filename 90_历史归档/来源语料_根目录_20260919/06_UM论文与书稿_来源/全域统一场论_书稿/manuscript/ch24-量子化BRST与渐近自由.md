## 24.1 量子化台阶：从经典到量子

经典 Yang–Mills 作用量（第21章）：$S_{\mathrm{YM}} = -\frac{1}{2\tilde{g}^{2}}\int \mathrm{tr}\left( F_{\mu\nu}F^{\mu\nu} \right)$。量子化需要路径积分 $\int \mathcal{D}A\, e^{iS}$。但规范变换 $A \to U^{\dagger}AU + U^{\dagger}\mathrm{d}U$ 沿规范轨道方向使作用量不变 → 路径积分发散（重复计数）。Faddeev–Popov 程序在规范超曲面 $\mathcal{F}\left( A \right) = 0$ 上积分，引入 Faddeev–Popov 行列式，用格拉斯曼鬼场 $c, \bar c$ 表示：

$$S_{\mathrm{FP}} = S_{\mathrm{YM}} + S_{\mathrm{gf}} + S_{\mathrm{ghost}}, \qquad S_{\mathrm{ghost}} = \int \bar c^{a}\left( -\partial^{\mu}D_{\mu}c \right)^{a}$$

## 24.2 BRST 代数与幂零性

【 **定理 24.1（BRST 幂零性）** :规范固定后的作用量拥有 BRST 对称 $s$（尼科莱–图皮金–别科夫型变换）：$sA = Dc$、$sc = -c^{2}$、$s\bar c = iB$、$sB = 0$，且 $s$ 是**幂零超导子**：

$$s^{2} = 0$$

（在伴随表示与格拉斯曼系数下，$s^{2}A = 0$、$s^{2}c = 0$ 是李代数雅可比恒等式与超导子莱布尼茨规则的推论。）物理态空间 = $s$-闭模 $s$-恰（BRST 上同调），保证可重整化性与幺正性。】

【 **验证（机器精度）** :`quantum_brst_verify.py` 用格拉斯曼外代数矩阵表示（$\xi_{i}\xi_{j} = -\xi_{j}\xi_{i}$）数值实现 $s$，检验 $s^{2}A = \left[ sA, c \right]_{s} + \left[ A, sc \right]_{s} = 0$ 与 $s^{2}c = 0$——**残差精确为零**（$0.0$，矩阵运算恒等成立）。】

## 24.3 单圈 β 函数与渐近自由

【 **定理 24.2（单圈 β 函数）** :$SU(N)$ 规范理论（含 $n_{f}$ 个费米子）的单圈 $\beta$ 函数：

$$\beta\left( g \right) = -\frac{b_{0}}{16\pi^{2}}g^{3}, \qquad b_{0} = \frac{11}{3}C_{2}\left( A \right) - \frac{4}{3}T\left( R \right)n_{f}$$

对 $SU(3)$：$C_{2}\left( A \right) = 3$、$T\left( \mathbf{3} \right) = 1/2$ → 纯规范 $b_{0} = 11$；$n_{f} = 6$ 时 $b_{0} = 7$。$b_{0} > 0$ ⟺ 渐近自由（高能耦合变弱）。临界值 $n_{f}^{*} = 33/2$；整数窗口 $n_{f} \le 16$。标准模型有效 $n_{f} = 6 \ll 16$——**深在渐近自由区**（验证B/D 实测）。】

## 24.4 双向对称公理的量子层对应

【 **定理 24.3（量子-公理对应）** :标准单圈 $\beta\left( g \right) = -b_{0}g^{3}/16\pi^{2}$ 是 $g$ 的**奇函数**，故精确满足第9章双向分形公理：

$$\beta\left( -g \right) = -\beta\left( g \right)$$

验证C 实测：任意 $g$ 下左右两侧逐点相等（差 $0$）。**意义**：本框架公理层要求的双向对称，在标准量子场论的耦合跑动中**自动成立**——这不是外加约束，而是标准结构的内在性质。量子层与公理层在此相容（对应原理锚点）。】

【 **进一步（诚实）** :更高圈 $\beta$ 含 $g^{5}$ 等奇次幂项（所有已知量子修正都是 $g$ 的奇函数，因 $\beta$ 是"乘性电荷"重整化的对数导数），双向对称在微扰论中全阶保持。非微扰区（强耦合、禁闭）的 $\beta$ 行为超出本章范围（OPEN）。】

## 24.5 渐近自由的意义：与第23章的衔接

色禁闭（强耦合区）与渐近自由（弱耦合区）是同一耦合跑动的两端：紫外（高能）$g \to 0$（渐近自由），红外（低能）$g$ 增长 → 禁闭。本框架第23章给出了色单态的代数必要条件；本章给出耦合跑动的方向性：$SU(3)$ 的 $b_{0} = 11 > 0$ 保证紫外安全。**但"红外禁闭 = 质量间隙存在"的严格证明仍 OPEN**（Yang–Mills 千禧年问题）。
