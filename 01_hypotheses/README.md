# 理论假设与独立研究路线

以不同假设为主轴，逐条完成“假设 → 定义 → 推导 → 证明 → 预测 → 检验 → 证伪 → 结论”。各路线允许竞争、交叉和淘汰，不预设最终统一场论已成立。

- [H01_SPACE_MOTION：空间运行与螺旋运动](h01_space_motion/README.md) — 空间运动、速度场或螺旋结构是否能够产生可观测的场？
- [H02_SPACE_COMPRESSION：空间压缩与密度梯度](h02_space_compression/README.md) — 空间压缩量如何定义、测量，并与质量、引力及场方程联系？
- [H03_MATTER_DRIVEN：物体驱动与源场耦合](h03_matter_driven/README.md) — 物体运动及源分布如何驱动场，场又如何反作用于物体？
- [H04_GEOMETRY_ACTION：几何与作用量](h04_geometry_action/README.md) — 给定几何结构与作用量，能否一致导出动力学和已知极限？
- [H05_GAUGE_SYMMETRY：规范对称与相互作用](h05_gauge_symmetry/README.md) — 规范群、对称破缺及耦合能否形成一致的统一描述？
- [H06_QUANTUM_EMERGENCE：量子结构与涌现](h06_quantum_emergence/README.md) — 量子自由度或微观结构如何产生时空及有效相互作用？
