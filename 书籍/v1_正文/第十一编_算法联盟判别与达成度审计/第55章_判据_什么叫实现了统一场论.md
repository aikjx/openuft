> **【整合体系】** 算法联盟审计层（`04_公共成果/算法联盟_全维自洽与归一化`）；判据覆盖全部 18 个独立体系

> **【关键事实】** 联盟层 UFT 达成度 **2/6**；单体系最高 **2/6**（S13）；18 体系中已实现 0、候选框架 0、纲领草案 1、未完成 17

## 55.1 为什么必须先立判据

本书前十编写完了十八个体系。到这里必须回答一个问题，而且这个问题必须**可判定**：

> **算法联盟是否实现了统一场论？**

这个问题之所以难，不是因为答案复杂，而是因为在立判据之前，它根本没有答案。

考虑两句话：

- 甲："我用螺旋几何统一了四种基本力。"
- 乙："我用对偶分形统一了四种基本力。"

在没有判据的情况下，这两句话**无法区分**——不是因为我们不够聪明，而是因为"统一了"这个词没有被赋予可操作的含义。任何体系都可以声称自己统一了四力，而任何反驳都可以被"你没理解我的框架"挡回来。这是一场没有记分牌的比赛。

因此本章的做法是：**先立判据，再逐条打分**。判据在打分之前公开，打分时不得修改判据。这是审计与辩护的根本区别——辩护是"先有结论再找理由"，审计是"先有尺子再量东西"。

### 55.1.1 一个必须先说清的区分

"没实现"不等于"没进展"。

本联盟真正建成的，不是统一场论，而是**一把能判定"什么才算实现"的尺子**。在没有尺子之前，"我统一了"和"我统一了"不可区分；现在可以区分了。这本身是实质进展，但它属于**方法论进展**，不属于**物理学进展**。本书拒绝把前者包装成后者。

## 55.2 六条判据 UFT-1 … UFT-6

判据的设计原则有三条：

1. **可判定**：每条必须能给出 ✅/❌，不能给出"部分满足"的模糊态。
2. **数据可得**：判定所需数据必须来自仓库内既有审计产物，不得临时采集。
3. **不可被自评绕过**：判定不能依赖体系自己的声明，只能依赖登记的机器可读记录。

| 编号 | 判据 | 判定方式 | 数据来源 |
|---|---|---|---|
| **UFT-1** 数学自洽 | 审计判定的硬冲突数 = 0，**且有公设可自洽** | 计数 | 体系第一性健康度总览 |
| **UFT-2** 四力统一 | 给出规范群 + 统一作用量，且作用量含**本体系特有项** | 判词 | 全维自洽图谱 |
| **UFT-3** 常数派生 | 登记的无量纲靶 ≥ 3 且 $V_2>0$ | 计数 + 判别式 | 无量纲靶场审计 |
| **UFT-4** 观测复现 | 复现 SM 粒子谱／耦合，偏差落在观测不确定度内 | 判词 | 全维自洽图谱 |
| **UFT-5** 可证伪预言 | 有已登记的、与已知理论**不同**的可检验预言 | 计数 | 各体系 predictions |
| **UFT-6** 外部验证 | 生命周期进入 `reviewed` / `validated` | 状态 | `system_registry.json` |

### 55.2.1 逐条的设计理由

**UFT-1（数学自洽）** 是六条中唯一一条"必要条件而非成就"的判据。一个体系自洽，只说明它没有自相矛盾，不说明它正确。它得 1 分，是因为不给自己挖坑确实需要工作量，但读者应当清楚：**这一分是地板，不是天花板**。

**UFT-2（四力统一）** 中"含本体系特有项"这七个字是全部要害所在。它的作用是排除一类最常见的伪统一：把已知理论的拉格朗日量逐字抄进一个"统一"的外壳。第 55.6.2 节的 S14 是这一条的教科书级反例。

**UFT-3（常数派生）** 要求"无量纲靶 ≥ 3 且 $V_2>0$"。为什么必须是**无量纲**的量？因为带量纲的等式总能凑对——你可以用 $c$、$\hbar$、$G$ 的某个乘幂组合凑出任何你想要的量纲，然后宣称"导出了"某个常数。**无量纲的数凑不对**：它是一个纯数字，对或错一目了然，没有单位换算的腾挪空间。这一条的设计动机将在第 56 章由量纲零空间定理给出严格证明。

**UFT-4（观测复现）** 是标准模型已经做到的事。一个统一理论若连标准模型的粒子谱与耦合常数都复现不了，它就不是"超越标准模型"，而是"不如标准模型"。

**UFT-5（可证伪预言）** 要求预言"与已知理论不同"。若一个体系只预言标准模型已经预言的东西，它没有提供任何新信息。

**UFT-6（外部验证）** 是唯一一条**不在本联盟权限内**的判据。同行评审无法由自检替代。这一条的存在是为了防止本书把"我们检查过自己"误当成"别人检查过我们"。

### 55.2.2 档位划分

| 得分 | 档位 | 含义 |
|---|---|---|
| 6/6 | 已实现 | 六条全过 |
| 4–5 | 候选框架 | 结构成立，验证未完 |
| 2–3 | 纲领草案 | 有纲领、有诚实记录，尚未构成理论 |
| 0–1 | 未完成 | 方向或雏形 |

| 判据 | 结果 | 依据 |

| UFT-4 观测复现 | ❌ | 无一体系复现 SM 谱／耦合 |
| UFT-5 可证伪预言 | ✅ | S13 / S14 有登记，但定量不足 |
| UFT-6 外部验证 | ❌ | 全部 `unreviewed` / `unformulated` |

**联盟层：2 / 6。**

### 55.3.1 ⚠️ UFT-3 的判定后来被修正过一次，必须如实登记

上表 UFT-3 的判定依据"18 体系登记的无量纲预测数 = 0"来自 `无量纲靶场审计.py`。后来发现该脚本中这一行：

```python
"n_registered_predictions": 0,   # 需体系自行登记，扫描无法判定
```

是**硬编码的常量 0**，不是读数。后果是：无论体系实际登记了多少，这条结论永远成立。它不是审计结果，它是一个**不可被推翻的常量**——这正是本书反复警告的「看起来在验证、实则永不报警」那一类缺陷，只是这次发生在审计工具自己身上。

修正后的读数（第 57 章详述）：**43 条已登记、26 条受评、17 条按规则排除**；在"仅自身公设"口径下通过的独立靶 **= 1**。

**判据结论不变（仍为 ❌），但失败的性质变了**：从"一个不可推翻的常量"，变成"一组可重算、可推翻的数字"。这两个状态在科学上完全不同——前者是死胡同，后者是起点。

### 55.3.2 最刺眼的一条

十八个体系，在修正读数之前，没有**任何一个**写下过这句话：

> "我预测无量纲量 $X$ 的值为 $v$，相对误差不超过 $u$。"

一个不给出数字的理论，无法被任何实验推翻。**这不是"暂时没验证"，是"还没有可被验证的东西"。**

这句话值得单独强调，因为它是本书全部工作中最不讨人喜欢、也最有价值的一句。它把一个听起来像是"阶段性困难"的状态，重新描述为一个**结构性的缺失**。

## 55.5 三条需要单独说明的

### 55.5.1 S13：唯一的纲领草案，也是全库最诚实的体系

S13 三公理代数全部机器零（F01–F09），是唯一含 `verified` claims 的体系；4 项 L3 候选预言有明确的证伪标准，其中包括电子 EDM

$$d_e = 2.257\times10^{-34}\ \mathrm{C\cdot m}$$

**但 S13 卡在 UFT-2 与 UFT-3 上**：未给出含强作用的完整统一作用量，也未登记无量纲靶的数值与误差棒。

⚠️ **重要勘误（与第九编第48/49章冲突，以本章为准）**：上述 EDM 预言已在第十编第53章被裁定为**已证伪**——JILA HfF⁺ 2023 年实验上限 $|d_e|<4.1\times10^{-30}\ \mathrm{e\cdot cm}$ 比该预言小 **16.5 个数量级**（排除 $3.44\times10^{16}$ 倍）。第九编称其为"第一个可检验独立预言"，该表述在预言被提出时尚属合理；经实验比对后，它的正确状态是**已证伪**，不再是活跃预言。

这条勘误本身是正面的：它证明了 S13 的预言**确实是可证伪的**——它给出了一个数字，而这个数字被实验排除了。一个不可证伪的理论不会发生这种事。S13 是本书唯一一个"预言 → 检验 → 证伪"完整走完的体系。

### 55.5.2 S14：离"四力统一"名义最近，却判 0 项通过

S14（挠率统一场论 TUFT）确实给出了主丛作用量，结构群为

$$G = SO(1,3)\times U(1)\times SU(2)\times SU(3)$$

单看形式，这是全库最接近"统一场论"的东西。但审计判定是：

| 检查项 | 结果 |
|---|---|
| 作用量是否含 TUFT 特有项 | **否**——EH + YM + Dirac 逐字照搬 |
| 结构群是否单群 | **否**——是直积，不是单群 |
| 三耦合是否汇聚 | **否**——在 $10^{16}$ GeV 处 **21% 分散** |
| 反常消除是否为 TUFT 导出 | **否**——五类反常精确为零是**继承自 SM** |

**这一条最值得记住**：

> **把已知理论抄进一个"统一"的外壳，不构成统一。**

S14 的教训是普适的。凡是"统一"的形式要件（一个群、一个作用量、一个拉格朗日密度）都齐备，而统一的实质要件（特有项、耦合汇聚、导出而非继承）一个都不具备。**形式齐备恰恰是最容易做到、也最容易误导人的部分。**

### 55.5.3 S01：最干净，也最谦虚

S01（螺旋三重奏与谱几何）是纯数学框架。它的核心定理

$$\kappa^2+\tau^2=\left(\frac{\omega}{v}\right)^2$$

是 L0 层代数恒等式，mpmath 50 位残差 $\leq 1.4\times10^{-16}$。它的 `claims.csv` **为空**——零物理 claim，并诚实声明不引入本体。

它得 1/6，只因为"自洽"。**S01 是本书全部体系中距离过度声称最远的一个。**

把 S01 与 S14 并置是有教益的：S01 什么都没声称，得 1 分；S14 声称了四力统一，也得 1 分。这个并列本身就是判据设计成功的证据——**它没有奖励声称，只奖励登记。**

## 55.6 判据自身的诚实边界

判据是工具，工具必须有标定的边界。以下四条是 UFT-1..6 **做不到**的事：

1. **不产生任何关于世界的预言。** UFT 判据衡量的是"体系登记了什么"，不是"世界是怎样的"。6/6 也不能证明理论正确，只能说明它在六项审计口径下未被推翻。

2. **UFT-1 的 ✅ 很廉价。** 自洽是地板。一个只写"1+1=2"的体系也能通过 UFT-1。读者不应把 UFT-1 的 ✅ 读作成就。

3. **UFT-6 不可由自检达成。** 外部同行评审无法由自己替代。在此之前，任何"已实现"的表述都不成立——包括本书自己的。

4. **档位是审计结论，不是物理结论。** "纲领草案"这个词描述的是**该体系当前登记内容的状态**，不构成对该研究方向本身的否定。统一场论作为一个研究方向，不因本联盟未实现而有任何减损。

## 55.8 诚实边界与待研究问题

### 已确认 [A]

1. 联盟层 UFT 达成度 = 2/6（UFT-1 ✅、UFT-5 ✅，其余 ❌）。
2. 单体系最高 = 2/6，仅 S13；其余 17 个体系 ≤ 1/6。
3. UFT-2、UFT-4、UFT-6 三列在全部 18 个体系上**无一个 ✅**。
4. `无量纲靶场审计.py` 中 `n_registered_predictions` 原为硬编码 0，已由登记引擎改为真读数。
5. S13 的电子 EDM 预言 $d_e=2.257\times10^{-34}\ \mathrm{C\cdot m}$ 已被 JILA 2023 排除 16.5 个数量级，状态为**已证伪**。

### [B] 框架映射

1. 六条判据是本书自建的审计口径，与物理学界通行的理论评价标准**方向一致但不等价**——后者还包含自然性、微扰可控性、紫外完备性等本书未纳入的维度。
2. 档位划分（6/4–5/2–3/0–1）的边界是人为设定的，换成别的切法结论会动。
3. 判据的"可判定"要求本身有代价：它倾向于奖励**容易登记的东西**（计数、整数靶），低估难以登记的东西（定性洞见、结构性重构）。

### [C] 待建

1. **判据的外部校准**：UFT-1..6 从未与任何已公认理论（如标准模型、广义相对论）做过对照打分。若把它们打到 6/6，说明判据太松；若打到 2/6，说明判据可能有误。**这个校准不做，判据的信度无从谈起。** 这是本章最大的弱点。
2. **UFT-2 的"特有项"缺乏形式化定义**：目前靠人工判词。什么叫"特有"？多一项 $R^2$ 算不算？需要一个可判定的准则。
3. **UFT-4 的"复现"门槛未量化**：偏差落在"观测不确定度内"——哪个观测量？多少个？全谱还是抽样？
4. **UFT-6 的达成路径缺失**：从 `unreviewed` 到 `reviewed` 需要什么？本书未定义。

### 核心结论

- **联盟层 UFT 达成度 2/6，未实现统一场论。**
- 十八个体系中：已实现 0、候选框架 0、纲领草案 1（S13）、未完成 17。
- UFT-2 / UFT-4 / UFT-6 三列全空，根因是**全部体系停留在纲领阶段，未进入求解并对照阶段**。
- UFT-3 的判定依据曾为硬编码常量，已修正为真读数；结论不变，但性质从"不可推翻"变为"可重算"。
- **本联盟建成的是一把尺子，不是一个理论。** 这一点必须写在前头，不能写在后头。

## 55.9 本章小结

本章做了本书前十编没有做的事：**给"实现了统一场论"这句话赋予一个可判定的含义**。

六条判据，联盟层过两条。这个数字不体面，但它是**第一个**能被外界复核、也能被未来推翻的数字。下一章要回答的是：为什么十八个体系会集体停在 UFT-3 这一条上——答案不是"不够努力"，而是一条关于量纲的定理。

> **本章结论**：算法联盟 UFT 达成度 2/6，未实现统一场论。单体系最高 2/6（S13，判为纲领草案）；18 体系中已实现 0、候选框架 0、纲领草案 1、未完成 17。UFT-2（含特有项的统一作用量）、UFT-4（复现 SM 谱）、UFT-6（外部验证）三列在全部体系上无一个通过。S13 的电子 EDM 预言经实验比对已证伪（排除 16.5 个数量级），第九编相关表述以本章勘误为准。**"没实现"不等于"没进展"——本联盟建成的是一把能判定"什么才算实现"的尺子，这是方法论进展，不是物理学进展。**
