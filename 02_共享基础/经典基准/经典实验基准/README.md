# 经典实验基准总览

经典实验基准是 openuft 候选体系的**观测对照标尺**。候选体系的预言必须与这些已确认实验结果一致。

## 实验基准清单

| 编号 | 实验/观测 | 核心结果 |
|---|---|---|
| [E0](E0_水星近日点进动/README.md) | 水星近日点进动 | 每世纪 43″ 异常，GR 精确预言 |
| [E1](E1_光线偏折/README.md) | 光线引力偏折 | 1.75″（太阳边缘），GR 预言 |
| [E2](E2_引力红移/README.md) | 引力红移 | $z = \Delta\Phi/c^2$，GR 预言 |
| [E3](E3_CMB温度谱/README.md) | CMB 温度谱 | 黑体谱 $T = 2.725$ K，声学峰 |
| [E4](E4_粒子质量谱/README.md) | 粒子质量谱 | PDG 2026 粒子质量表 |

## 使用说明

- 候选体系在 `09_验证结果/` 中需对照相应实验基准
- 实验基准的确认不自动转移到候选体系
- 若候选体系预言与实验冲突，则登记为证伪 claim
