# 派生核算 XI：前缀码与不变性常数的收紧## 1. 定理 Ξ-10：前缀码形式的 c̄_ij 显式且严格紧于 8×字节构造：`gamma(长度) ‖ 算术编码体`（gamma 用 n+1 编码 ⇒ 严格前缀、无特例；体用 32 位整数算术编码 + order-0/1 自适应频率模型，编解码共享模型 ⇒ 往返逐字节一致）。| 常数 | 8×字节基线（X） | 前缀码 c̄ | 收紧 ||---|---|---|---|| c_{L→Python} | 44400 bit | 25967 bit | 1.710× || c_{Python→L} | 23840 bit | 13911 bit | 1.714× |## 2. 定理 Ξ-11：更紧的码 = 同样可转移的下界 + 更小的余项- 不变性定理对 c 的**具体值无关**，只对「c 出现在不等式里」敏感；故把 c 换成 c̄ ≤ c，  **下界的可转移性完全不变**（任何在 c 下成立的转移在 c̄ 下同样成立，且更紧）。- 余项（c − margin）随 c 单调减 ⇒ c̄ 使余项下降，**且不损失下界强度**（免费改进）。- 双向对称成立（承 X 的 O-23 闭合），收紧后 O-23 的对称性保持。## 3. 反例对照与防平凡性- **随机数据不可压**（order-0: 4903 bit > 8×600=4800 bit）⇒ 本册收紧来自源码真实冗余，  **不是**编码器取巧——这是防止「压缩器什么都能压」伪证的关键对照。- **码阶非普适改善**：本规模 order-1 反而劣于 order-0（上下文稀释）⇒ 取 min(各阶)，不预设方向。## 4. 诚实边界- c̄ 仍是**上界**；K(解释器) 不可计算 ⇒ **O-24 只被「收紧」，不被「闭合」**。- 收紧后余项 (c̄ − margin) 仍 ≫ 0 ⇒ 语言无关下界**数值仍不紧**，**不声称闭合 O-17**。- **新 OPEN O-25**：c̄ 依赖所选模型（阶/量化），非最优前缀码；「最优前缀码」问题未决。## 5. 自检 21/21> 红线：数学自洽 ≠ 实验证实。本册只把「语言依赖余项」从 8×字节收紧到显式前缀码 c̄，> 不给统一场论任何新的实验支持。
