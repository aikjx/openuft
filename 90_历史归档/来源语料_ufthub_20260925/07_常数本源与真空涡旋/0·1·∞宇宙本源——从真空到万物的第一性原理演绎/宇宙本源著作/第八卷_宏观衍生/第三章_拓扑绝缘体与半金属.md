# 第三章 拓扑绝缘体与拓扑半金属
拓扑绝缘体是2005年之后发现的一类新的拓扑物相，它们体内是绝缘的，表面是导电的，表面态受拓扑保护，不受杂质和缺陷的影响，和普通的表面态不同，普通表面态很容易被杂质破坏，而拓扑表面态是拓扑保护的，只要系统的体能隙不关闭，表面态就存在。

## 3.1 二维拓扑绝缘体：量子自旋霍尔效应
二维拓扑绝缘体也就是量子自旋霍尔效应，是张首晟等人在2006年预言的，2007年在碲化汞量子阱中被实验观测到。二维拓扑绝缘体的边缘是一维的导电边缘态，电子自旋和动量锁定，向上自旋的电子沿一个方向运动，向下自旋的电子沿反方向运动，没有背散射，因为背散射需要翻转自旋，而时间反演对称禁止自旋翻转，所以边缘态是无耗散的，电阻是量子化的，和量子霍尔效应类似，但是不需要强磁场，是时间反演对称保护的拓扑态。

在我们的理论中，二维拓扑绝缘体的边缘态是拓扑螺旋的边缘，体内的螺旋是闭合的，所以绝缘，边缘的螺旋是开放的，沿着边缘运动，自旋向上和向下的螺旋方向相反，所以形成手征边缘态，背散射需要把螺旋的方向反过来，也就是翻转自旋，这需要破坏时间反演对称，所以只要有时间反演对称，背散射就被禁止，边缘态无耗散，这是拓扑保护的本质。

量子自旋霍尔效应的Z2拓扑不变量是时间反演对称下的绕数模2，也就是边缘态的数目模2，Z2=1是拓扑绝缘体，有奇数个边缘态对，Z2=0是普通绝缘体，有偶数个边缘态对，可以被散射掉。

## 3.2 三维拓扑绝缘体
三维拓扑绝缘体是2007年预言的，2008年在铋锑合金、碲化铋、碲化锑等材料中被实验观测到，它们的表面是二维的狄拉克锥，电子是无质量的狄拉克费米子，自旋和动量锁定，表面态是自旋分辨的，没有背散射，输运是无耗散的。三维拓扑绝缘体的拓扑不变量是四个Z2数，一个强拓扑不变量，三个弱拓扑不变量，强拓扑绝缘体的所有表面都有狄拉克锥，弱拓扑绝缘体是堆垛的二维拓扑绝缘体，只有特定表面有表面态。

三维拓扑绝缘体的表面狄拉克锥和石墨烯的狄拉克锥类似，但是石墨烯有两个狄拉克锥，自旋简并，而拓扑绝缘体的表面狄拉克锥只有一个，自旋非简并，自旋和动量锁定，这是拓扑保护的结果。拓扑绝缘体的表面态可以用来做低功耗电子器件，因为无耗散输运，也可以用来做拓扑量子计算，因为 proximity effect 可以在拓扑绝缘体表面诱导拓扑超导，产生马约拉纳零能模。

## 3.3 拓扑半金属
拓扑半金属是体能隙为零的拓扑物相，导带和价带在费米能级附近交叉，交叉点是拓扑保护的，不能被能隙打开，分为外尔半金属、狄拉克半金属、节点线半金属等。外尔半金属的交叉点是外尔点，是手征的，外尔费米子，有确定的手性，表面有费米弧，是连接两个相反手性外尔点的表面态。狄拉克半金属的交叉点是狄拉克点，是四重简并的，两个相反手性的外尔点重合，比如碲化镉、砷化镉等。

外尔半金属的外尔点是拓扑磁单极子，在动量空间，外尔点是贝里曲率的源或者漏，也就是动量空间的磁单极，陈数为±1，这是拓扑保护的，只要晶格的对称性不被破坏，外尔点就存在，不能被打开能隙。外尔半金属有手征反常效应，也就是平行的电场和磁场会产生负磁阻，这是手征反常的表现，已经在实验中被观测到。

在我们的理论中，外尔点就是动量空间的拓扑螺旋的端点，是拓扑缺陷，和实空间的涡旋类似，是动量空间的拓扑奇点，贝里曲率就是动量空间的曲率，外尔点是曲率的源，也就是动量空间的“磁单极”，和实空间的引力源类似，都是拓扑残差的奇点，只是在动量空间。费米弧是表面的拓扑螺旋，连接两个相反手性的外尔点，是拓扑保护的表面态。

## 3.4 拓扑光子学与拓扑声学
拓扑物相不仅存在于电子系统，也存在于光子、声子、冷原子等系统，也就是拓扑光子学、拓扑声学、拓扑冷原子等，这些系统中也有拓扑边缘态，无背散射，不受缺陷影响，可以用来做鲁棒的光波导、声波导，不怕缺陷和弯曲，在通信和信息处理中有应用。

这些经典波系统的拓扑物相和电子系统的拓扑物相本质是一样的，都是波的拓扑性质，是拓扑螺旋在不同波系统的表现，不管是电子波、电磁波、声波，只要是波，都有拓扑相位，都可以形成拓扑物相，因为拓扑是波的内禀性质，是相位的绕数，和波的载体无关，这也说明拓扑是宇宙的普遍性质，不管是微观粒子还是宏观波，都遵循同样的拓扑规则。

## 3.5 本章小结
拓扑绝缘体、拓扑半金属、拓扑光子/声学系统都是拓扑螺旋在不同系统的表现，拓扑保护的边缘态、外尔点、费米弧都是拓扑不变量的结果，和粒子、时空的拓扑本质一致，拓扑是普遍的几何性质，存在于所有尺度和所有系统中。
