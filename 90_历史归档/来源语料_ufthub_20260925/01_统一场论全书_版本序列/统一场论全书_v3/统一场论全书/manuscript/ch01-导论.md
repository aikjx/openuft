# 第一章 导论：宇宙本源之问与三分层方法论

## 一、本书的问题与方法

本书追问一个问题：表面上服从不同定律的物理系统，其控制方程是否在结构上存在统一的数学形式？回答这一问题的路径是严格的推导：从牛顿力学出发，经狭义相对论与经典场论，抵达量子场论的边界。推导链条上每一步均可独立验算，尚未验证的拓展则标注为假说。

【已证实】当代物理学的两块基石是狭义相对论（爱因斯坦，1905）与广义相对论（爱因斯坦，1915）；量子场论标准模型建立在量子力学与狭义相对论的结合之上，经过七十余年的实验检验，其主要预言在各自精度范围内未被推翻。本书不重新证明这些结果，只引用作为推导前提。

【已证实】物理学史上真正的"统一"案例有明确的数学特征：牛顿把行星运动与地面落体统一在万有引力之下；麦克斯韦把电与磁统一在四个偏微分方程之中并预言电磁波；爱因斯坦把时间与空间统一为四维时空连续统；温伯格、格拉肖、萨拉姆把电磁相互作用与弱相互作用统一为电弱相互作用。每一次统一都伴随方程形式的精简与新实验预言的增加。

【推导】从数学角度看，统一表现为不同物理系统的控制方程在变量替换后取同一形式。本书所谓"统一场论"，并非宣称已完成牛顿式综合，而是指出：经典力学、电磁学、狭义相对论、量子场论的交界处，存在一条可严格书写的推导链，使"一个振子方程"在不同层次上反复出现。第二章即将展示的机电对偶是这一观察的第一个实例：机械振子与电路振荡服从同一个二阶线性微分方程，变量一一对应，守恒量形式相同，周期公式相同。

本书不覆盖标准模型的全部细节。夸克混合矩阵、希格斯势的重整化群跑动、QCD 禁闭的非微扰处理等专门内容不在范围之内。本书只取与"统一方程形式"直接相关的骨架部分：二阶协变微分算符、传播速度 $c$、静质量与康普顿波数的关系。本书也不提出新的基本常数，所有常数 $c, \hbar, G$ 均取自实验值；不替代量子力学的概率诠释；不涉及弦论或圈量子引力的技术细节；第十章仅给出符号验证框架而非完整数值仿真。

承认这些边界是必要的。一份理论专著的价值，不在于它声称覆盖了多少，而在于它清楚地划出了自己能负责的范围。

## 二、三分层方法论

本书的核心写作纪律是把所有论断分为三个互不混淆的层级。

**第一层：已证实。** 指标准物理学中已被大量实验验证、写入研究生教材的结论。例如牛顿第二定律 $F=ma$、麦克斯韦方程组、洛伦兹变换、质壳关系 $E^2=p^2c^2+m^2c^4$、爱因斯坦场方程等。这一层的论断只引用并注明来源，不重新"证明"。

**第二层：推导。** 指从已证实前提出发、用严格数学步骤得到的中间结论。推导层的每一步都应当可以被读者用一张纸、一支笔独立验算。例如从 $\gamma(v)=(1-v^2/c^2)^{-1/2}$ 求导得到 $d\gamma/dv=\gamma^3 v/c^2$，或从平面波代入达朗贝尔算符得到色散关系 $\omega=ck$，均属推导层。本书对推导层的要求是：公式编号、步骤完整、数值可验。

**第三层：假说。** 指本书作者原创的、尚未被实验证实的拓展性主张。例如把粒子诠释为"场的相对论谐振模式"、把环面涡旋诠释为旋量拓扑荷解、设想宇宙在所有尺度上具有自相似分形结构等。假说层需满足两个条件：一是明确标注"假说"二字，不与已证实层混写；二是尽量给出可证伪预言，即指出什么样的观测结果将否定该假说。

这一分层遵循波普尔的可证伪性原则与费曼对"已知物理"和"猜测"的区分。本书将其贯彻到每一段落、每一个公式。原因在于：在"统一场论"这一题目下，历史上充满把哲学遐想写成"新物理定律"的尝试。读者若不区分教科书内容与作者猜测，就会误把猜测当成知识。本书宁可在假说处反复标注"假说"，也不愿让读者产生任何混淆。

【推导】为了说明三层之间的区别，考虑一个具体例子。牛顿万有引力定律 $F=Gm_1m_2/r^2$ 属于【已证实】；由该定律推导出行星椭圆轨道方程属于【推导】；若在此基础上提出"引力在极近距离下偏离平方反比律"并给出具体修正函数，则该修正属于【假说】，须等待实验检验。本书的写作纪律正是把这一区分制度化。

【已证实】历史上不乏自称"统一场论"而未能经受住时间检验的方案。爱因斯坦后半生致力于把引力与电磁力统一在某种几何框架中，未获成功；卡鲁扎–克莱因理论引入第五维，数学上优雅但未能导出可观测的新预言。这些案例暴露了哪些数学结构在物理上不工作，为后来的规范理论提供了教训。本书在提出假说时将回顾这些前车之鉴。

## 三、记号与约定

全书采用统一记号，以下逐项给出定义。

光速：$c=299792458\ \mathrm{m/s}$，在国际单位制中被定义为精确值（标准常数，见附录B）。无量纲速度比：
$$\beta \equiv \frac{v}{c} \tag{1.1}$$

洛伦兹因子：
$$\gamma(v) \equiv \frac{1}{\sqrt{1-\beta^2}} = (1-\beta^2)^{-1/2} \tag{1.2}$$

四速度（约定号差为 $+---$）：
$$u^\mu = \gamma(c, \vec{v}) \tag{1.3}$$
满足归一化条件 $u_\mu u^\mu = c^2$，该式将在第三章严格推导。四动量：
$$p^\mu = \left(\frac{E}{c}, \vec{p}\right) \tag{1.4}$$

达朗贝尔算符：
$$\Box \equiv \partial_\mu \partial^\mu = \frac{1}{c^2}\frac{\partial^2}{\partial t^2} - \nabla^2 \tag{1.5}$$

康普顿波数：
$$\kappa = \frac{mc}{\hbar} \tag{1.6}$$
其中 $m$ 为静质量，$\hbar=h/(2\pi)$ 为约化普朗克常数。

本源振子方程（本书原创公设式写法）：
$$A\ddot{\Phi} + K\Phi = 0 \tag{1.7}$$
该方程在第六章被相对论完备化为 $A\Box\Phi + (K/c^2)\Phi=0$，并与克莱因–戈尔登方程对照。

协变导数：
$$D_\mu = \partial_\mu - igA_\mu \tag{1.8}$$
其中 $g$ 为规范耦合常数，$A_\mu$ 为规范势。广义相对论记号包括里奇张量 $R_{\mu\nu}$、标曲率 $R$、度规 $g_{\mu\nu}$、宇宙学常数 $\Lambda$、能量动量张量 $T_{\mu\nu}$。真空电磁常数为 $\mu_0$（真空磁导率）与 $\varepsilon_0$（真空介电常数）。波场记号：角频率 $\omega$、波数 $k$，自由平面波满足 $\omega=ck$。公式按章编号，跨章引用写作"见 (3.4)"。

## 四、演示性推导：无阻尼弹簧振子

本节用一个完整的求解示例展示推导层应达到的标准。

【已证实】胡克定律：弹簧对位移为 $x$ 的质点施加线性回复力
$$F = -kx \tag{1.9}$$
其中 $k>0$ 为劲度系数。牛顿第二定律：
$$F = m\ddot{x} \tag{1.10}$$

【推导】将 (1.9) 代入 (1.10)：
$$m\ddot{x} = -kx \tag{1.11}$$
即
$$\ddot{x} + \omega_0^2 x = 0, \quad \omega_0 \equiv \sqrt{\frac{k}{m}} \tag{1.12}$$

这是二阶常系数齐次线性常微分方程。设试探解 $x(t)=e^{st}$，代入得特征方程 $s^2+\omega_0^2=0$，根为 $s=\pm i\omega_0$。通解为
$$x(t) = A\cos\omega_0 t + B\sin\omega_0 t \tag{1.13}$$
其中 $A, B$ 由初始条件 $x(0), \dot{x}(0)$ 决定。等价地可写成 $x(t)=X\cos(\omega_0 t+\varphi)$。

周期为
$$T = \frac{2\pi}{\omega_0} = 2\pi\sqrt{\frac{m}{k}} \tag{1.14}$$

能量守恒验证：总能量
$$E = \frac{1}{2}m\dot{x}^2 + \frac{1}{2}kx^2 \tag{1.15}$$
对时间求导：
$$\frac{dE}{dt} = m\dot{x}\ddot{x} + kx\dot{x} = \dot{x}(m\ddot{x}+kx) = 0 \tag{1.16}$$
最后一步用了运动方程 (1.11)。故 $E$ 为常数。

数值验算：取 $m=1.00\ \mathrm{kg}$，$k=4.00\ \mathrm{N/m}$，则 $\omega_0=\sqrt{4}=2.00\ \mathrm{rad/s}$，$T=2\pi/2.00=\pi\approx3.1416\ \mathrm{s}$。若初始条件 $x(0)=0.100\ \mathrm{m}$，$\dot{x}(0)=0$，则 $A=0.100$，$B=0$，$x(t)=0.100\cos(2.00t)$（米）。最大动能出现在平衡位置 $x=0$：$v_{\max}=\omega_0 A=0.200\ \mathrm{m/s}$，对应 $\tfrac12 mv_{\max}^2=\tfrac12\times1.00\times0.0400=0.0200\ \mathrm{J}$；最大势能出现在端点：$\tfrac12 kA^2=\tfrac12\times4.00\times0.0100=0.0200\ \mathrm{J}$，两者相等，与能量守恒一致。

推导链条为：物理定律 (1.9)(1.10) → 微分方程 (1.11) → 通解 (1.13) → 周期 (1.14) → 能量守恒 (1.16) → 数值验算。本书后续章节按此标准推进。

【推导】进一步说明初值如何决定系数。设初始位移为 $x_0$、初始速度为 $v_0$。由通解 (1.13)，$t=0$ 时 $x(0)=A=x_0$。对 $x(t)$ 求导得 $\dot{x}(t)=-A\omega_0\sin\omega_0 t+B\omega_0\cos\omega_0 t$，故 $\dot{x}(0)=B\omega_0=v_0$，即 $B=v_0/\omega_0$。因此初值问题的解为
$$x(t)=x_0\cos\omega_0 t+\frac{v_0}{\omega_0}\sin\omega_0 t \tag{1.20}$$

若 $v_0=0$，退化为 $x(t)=x_0\cos\omega_0 t$，振幅 $X=|x_0|$。若 $x_0=0$，解为 $x(t)=(v_0/\omega_0)\sin\omega_0 t$，振幅 $X=|v_0|/\omega_0$。一般情形下，振幅为
$$X=\sqrt{x_0^2+\left(\frac{v_0}{\omega_0}\right)^2} \tag{1.21}$$
总能量 $E=\tfrac12 kX^2=\tfrac12 kx_0^2+\tfrac12 m v_0^2$，与初始时刻的动能加势能一致，再次验证守恒律。

第二组数值验算：取 $m=2.00\ \mathrm{kg}$，$k=8.00\ \mathrm{N/m}$，初始条件 $x_0=0$、$v_0=0.400\ \mathrm{m/s}$。则 $\omega_0=\sqrt{8/2}=2.00\ \mathrm{rad/s}$，与前例相同。振幅 $X=v_0/\omega_0=0.400/2.00=0.200\ \mathrm{m}$。总能量 $E=\tfrac12 m v_0^2=\tfrac12\times2.00\times0.160=0.160\ \mathrm{J}$。端点势能 $\tfrac12 kX^2=\tfrac12\times8.00\times0.0400=0.160\ \mathrm{J}$，与总能量一致。平衡位置速度 $v_{\max}=\omega_0 X=2.00\times0.200=0.400\ \mathrm{m/s}=v_0$，符合物理预期。

## 五、二阶线性方程的一般结构

本书反复出现二阶线性（偏）微分方程，本节明确其分类与量纲检查方法，避免后续章节重复求解步骤。

【推导】考虑未知函数 $y(t)$ 满足的二阶常系数齐次线性常微分方程：
$$a\ddot{y} + b\dot{y} + cy = 0 \tag{1.17}$$
其中 $a, b, c$ 为实常数，$a\neq 0$。除以 $a$ 后写成
$$\ddot{y} + 2\zeta\omega_0\dot{y} + \omega_0^2 y = 0 \tag{1.18}$$
其中 $\omega_0^2 = c/a$，$2\zeta\omega_0 = b/a$，$\zeta$ 称为阻尼比。

无阻尼情形 $\zeta=0$ 即 (1.12) 式。欠阻尼情形 $0<\zeta<1$ 时，特征根为 $s=-\zeta\omega_0 \pm i\omega_d$，其中阻尼角频率
$$\omega_d = \omega_0\sqrt{1-\zeta^2} \tag{1.19}$$
通解为 $y(t)=e^{-\zeta\omega_0 t}(A\cos\omega_d t + B\sin\omega_d t)$。过阻尼 $\zeta>1$ 时无振荡，临界阻尼 $\zeta=1$ 是两种情形的分界。

本书主体讨论无阻尼情形，因为守恒律与波动解都要求能量不被耗散。阻尼概念在工程上有重要意义，读者应知道它是同一方程族的一员。

量纲检查是推导的基本自检方法。方程中每一项的量纲应当相同。对 (1.11) 式，$m\ddot{x}$ 的量纲为 $\mathrm{kg}\cdot\mathrm{m}/\mathrm{s}^2=\mathrm{N}$，$kx$ 的量纲为 $(\mathrm{N/m})\cdot\mathrm{m}=\mathrm{N}$，两者一致。对 $\omega_0=\sqrt{k/m}$，量纲为 $\sqrt{(\mathrm{N/m})/\mathrm{kg}}=\sqrt{1/\mathrm{s}^2}=\mathrm{s}^{-1}$，与角频率量纲一致。若量纲不一致，推导中必有误。

数值补充：取阻尼比 $\zeta=0.100$，$\omega_0=2.00\ \mathrm{rad/s}$，则阻尼角频率 $\omega_d=2.00\sqrt{1-0.01}=2.00\times0.9950=1.990\ \mathrm{rad/s}$。振幅衰减时间常数为 $1/(\zeta\omega_0)=1/(0.200)=5.00\ \mathrm{s}$，即每经过 5 秒振幅衰减到原来的 $1/e\approx0.368$。阻尼比很小时振荡频率几乎不变，只是振幅缓慢衰减。本书后续自由场方程对应 $\zeta=0$ 的理想无耗散极限。

【推导】特征方程法的有效性可作如下说明。对常系数线性算子 $L=a d^2/dt^2+b d/dt+c$，试探 $y=e^{st}$ 时 $dy/dt=se^{st}$、$d^2y/dt^2=s^2 e^{st}$，代入得 $L[e^{st}]=(as^2+bs+c)e^{st}$。若 $as^2+bs+c=0$，则 $e^{st}$ 满足方程。两个线性无关解 $e^{s_1 t}$ 与 $e^{s_2 t}$ 的线性组合给出通解。当 $s_{1,2}$ 为共轭复数 $\alpha\pm i\omega_d$ 时，$e^{\alpha t}(A\cos\omega_d t+B\sin\omega_d t)$ 即欠阻尼通解。这一方法将在第三章推广到偏微分方程：那时 $e^{st}$ 替换为平面波 $e^{i(kx-\omega t)}$，特征方程替换为色散关系。

## 六、全书论证路线

全书十章按"经典 → 相对论 → 场 → 统一方程 → 假说"的顺序展开。

第二章建立弹簧振子与 LC 回路的严格同构（机电对偶），是全书第一个对偶案例。第三章推导洛伦兹因子及其导数、四速度归一化、$u\cdot a=0$、质壳关系 $E^2=p^2c^2+m^2c^4$，并在 $v=c,\,m=0$ 极限下得到 $E=pc$。第四章引入达朗贝尔算符 $\Box$，讨论平面波色散关系 $\omega=ck$，并从麦克斯韦真空方程导出光速 $c=1/\sqrt{\mu_0\varepsilon_0}$。第五章把电磁 $U(1)$ 场、线性化引力波、杨–米尔斯场、克莱因–戈尔登场放在同一二阶协变方程框架下，说明它们共用传播速度 $c$。第六章完成"本源回环"：把本源振子 $A\ddot\Phi+K\Phi=0$ 相对论完备化为 $A\Box\Phi+(K/c^2)\Phi=0$，与克莱因–戈尔登方程对照得到 $\hbar\omega_0=mc^2$。

第七章至第九章为【假说】层，分别处理拓扑荷与环面涡旋、分形宇宙与重整化群、奇点化解与因果畴动力学，每章核心主张均标注【假说】并给出可证伪预言。第十章为计算篇，给出符号验证框架。第一至第六章主体属于【已证实】与【推导】，第七至第九章属于【假说】。

各章之间的逻辑依赖为：第二章的机电对偶是第三章狭义相对论的预备，因为后者要求读者熟悉"变量替换后方程不变"这一结构概念；第三章的四速度与质壳关系是第四章达朗贝尔算符的前置，因为 $\Box$ 正是四速度归一化在时空导数上的推广；第四章的平面波色散关系是第五章统一主方程的特例；第五章的协变导数结构是第六章本源回环的数学语言。读者跳章阅读时可能在这些接口处遇到未解释的记号。本书附录B提供术语对照表，附录C提供标准物理与原创假说的边界声明。读者在阅读过程中若对某个论断的层级归属存疑，应查阅附录C。

## 七、可证伪性的分层要求

科学主张区别于数学游戏的标准是可证伪性：存在某种可能的观测结果，若该结果出现则主张被否定。本书对三层内容的可证伪性要求不同。

【已证实】层的可证伪性已被历史上无数次实验检验。例如光速不变原理经迈克尔逊–莫雷实验及后续数百次实验检验，质壳关系被高能物理实验反复验证。本书不重复这些检验。

【推导】层的可证伪性是逻辑可检验性：只要前提成立，每一步均可算术或代数核验。推导若有逻辑错误，读者可在纸纸上指出。

【假说】层的可证伪性由作者显式陈述。例如，若"粒子=场的相对论谐振模式"这一诠释要成为科学假说，就应指出：什么样的观测会否定它？若未来实验发现某类粒子的静质量与场模式频率之间不满足 $\hbar\omega_0=mc^2$ 关系，则该诠释被否定。再如，若分形宇宙假说声称宇宙在所有尺度上具有自相似结构，则对宇宙大尺度结构的统计分析若在足够大的尺度上偏离自相似预测，该假说即被削弱。有些假说目前难以立刻给出实验判据，本书会诚实标注"目前尚无可行的实验判别方案"。科学史上许多重要假说从提出到实验检验相隔数十年，但"目前无法检验"不等于"不需要标注为假说"。

## 八、本章小结

本章确立了全书的方法论框架。第一，所有论断分为【已证实】【推导】【假说】三层，三层不混写。第二，统一记号见 (1.1)–(1.8)，公式按章编号。第三，弹簧振子的完整求解（(1.9)–(1.16)）演示了推导层标准：物理定律→微分方程→通解→守恒量→数值验算，环环可验。第四，论证路线为：经典对偶（第二章）→狭义相对论（第三章）→波动与场（第四章）→统一主方程（第五章）→本源回环（第六章）→拓扑荷/分形/因果畴假说（第七至九章）→计算验证（第十章）。第五，可证伪性原则贯穿全书，假说层应给出可证伪预言，暂不可检验者应如实说明。
