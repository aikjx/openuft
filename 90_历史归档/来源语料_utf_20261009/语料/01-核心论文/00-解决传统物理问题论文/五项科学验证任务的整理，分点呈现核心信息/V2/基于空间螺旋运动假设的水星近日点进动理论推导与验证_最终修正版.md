## 2. 理论框架：空间螺旋运动与引力加速度场

### 2.1 核心公设

张祥前统一场论的基石是两大不可约化的公设，它们共同构成了一个几何化的物理世界图景：空间是运动的，时间是空间运动的度量，质量是空间运动强度的几何表现。

#### 2.1.1 时空同一化公设

**时空同一化公设**断言：**时间 $t$ 并非独立维度，而是空间以矢量光速 $\vec{C}$（其模为常数 $c$）运动的度量**。对于一个相对于观测者静止的物体，其周围任意空间点的位移 $\vec{R}$ 与时间 $t$ 满足严格的线性关系：

$$\vec{R}(t) = \vec{C} t$$

其中，$\vec{C}$ 是理论的核心概念——**矢量光速**，它具有以下关键性质：
- **大小恒定**：$|\vec{C}| = c$（标量光速，约 $3 \times 10^8$ m/s）
- **方向可变**：不同空间点的矢量光速方向可以不同，形成一个动态的矢量场
- **绝对意义**：代表空间本身相对于观测者的绝对运动速度，而非光在空间中的传播速度

这一公设从根本上将时间与空间的运动统一，挑战了爱因斯坦相对论中时间作为独立维度的观念。

**量纲验证：**
```
左边：[R] = [L]
右边：[C·t] = [L][T]⁻¹ × [T] = [L]
✅ 量纲一致
```

#### 2.1.2 质量几何化公设

**质量几何化公设**断言：**物体的质量 $m$ 并非其内在的"物质之量"，而是对其周围空间光速螺旋运动剧烈程度的几何度量**。其数学定义为：

$$m = k \frac{\Delta n}{\Delta \Omega}$$

其中：
- $k$ 为比例常数，具有质量的量纲，其数值由实验确定
- $\Delta n$ 是穿过以物体为中心、张角为 $\Delta \Omega$ 的无穷小立体角的"空间运动线"条数
- $\Delta n/\Delta \Omega$ 代表单位立体角内的空间运动线密度，反映了空间运动的剧烈程度

**几何直观**：想象从物体中心向四面八方发出无数条"空间运动线"，每条线代表一个以光速运动的空间点。物体的质量越大，单位立体角内发出的空间运动线越多，表明其周围空间运动越剧烈。这一定义将质量从"物质的量"这一抽象概念转化为具体的、可度量的几何量。

**量纲验证：**
```
左边：[m] = [M]
右边：[k·Δn/ΔΩ] = [M] × [1]/[1] = [M]
✅ 量纲一致
```

### 2.2 引力场的几何定义

在张祥前统一场论框架下，引力被描述为空间螺旋运动的动力学效应。根据该理论：

**引力场 $\vec{A}$ 被几何地定义为空间位移矢量 $\vec{R}$ 对时间的二阶导数，即空间本底运动的加速度：**

$$\vec{A} = \frac{d^2 \vec{R}}{dt^2}$$

对于一个静态球对称质量（如太阳），其产生的静态引力场形式为：

$$\vec{A}(r) = -\frac{GM}{r^2} \hat{r}$$

**注：** 引力场的具体形式通过与实验观测（如开普勒第三定律）的对比确定。在UFT框架内，这对应于空间螺旋运动在静态球对称质量周围产生的加速度场的零阶近似。这一定义与牛顿引力加速度的形式完全一致，但物理图像截然不同：牛顿理论认为这是物体间的"超距作用"，而统一场论认为这是**空间点本身以该加速度向质量中心"流动"**的表现【6】。

**量纲验证：**
```
左边：[A] = [L][T]⁻²
右边：[d²R/dt²] = [L]/[T]² = [L][T]⁻²
✅ 量纲一致
```

### 2.3 空间螺旋运动模型

在张祥前统一场论中，空间本底运动被假设为**圆柱状螺旋运动**，这是理解引力本质的关键几何模型。

#### 2.3.1 几何表示

在中心引力场中，空间本底速度 $\vec{C}$ 可以表示为：

$$\vec{C}(r, \theta, t) = c\begin{bmatrix}
\cos[\omega_s(r) \cdot t] \\
\sin[\omega_s(r) \cdot t] \\
\frac{h(r)}{c}
\end{bmatrix}$$

其中：
- $r, \theta$ 为极坐标（假设运动在赤道平面内）
- $\omega_s(r)$ 为螺旋运动的角频率，与距离 $r$ 相关
- $h(r)$ 为螺旋运动的轴向推进速度
- $c$ 为标量光速

#### 2.3.2 物理意义

**空间螺旋运动的几何机制：**
1. **径向分量**：空间点在径向方向上做简谐运动，角频率 $\omega_s(r)$ 随距离增加而减小
2. **角向分量**：空间点在角向方向上做圆周运动，形成螺旋的横向结构
3. **轴向分量**：空间点沿轴向以速度 $h(r)$ 推进，形成螺旋的纵向结构

**几何直观：** 想象无数个空间点围绕引力源（如太阳）做螺旋运动，每个空间点的运动轨迹都是一条圆柱状螺旋线。越靠近引力源，螺旋越紧密（角频率越高），空间运动越剧烈；越远离引力源，螺旋越稀疏（角频率越低），空间运动越平缓。

#### 2.3.3 螺旋参数与引力场的关系

**螺旋角频率：**
根据理论，空间螺旋运动的角频率与引力场强度相关。在弱场近似下：

$$\omega_s(r) = \frac{k \sqrt{GM}}{r^{3/2}}$$

其中 $k$ 为无量纲常数，通过理论与实验对比确定。

**物理意义：** 这一关系表明，越靠近引力源，空间螺旋运动越剧烈（角频率越高），这与引力场强度随距离的衰减趋势一致。实际上，$\omega_s(r)$ 反映了空间本底运动的剧烈程度，是引力场强度的几何表现。

**量纲验证：**
```
[ω_s] = [T]⁻¹
[k√(GM)/r³/²] = [1] × [L³/² M¹/² T⁻¹]/[L]³/² = [T]⁻¹
✅ 量纲一致
```

**轴向推进速度：**
$$h(r) = \frac{h_0}{r^2}$$

其中 $h_0$ 为常数，与引力源质量相关。

**物理意义：** 轴向推进速度反映了空间在垂直于轨道平面方向上的运动特性，是空间螺旋运动的重要组成部分。

#### 2.3.4 空间螺旋运动与引力的关系

**核心机制：** 引力并非物体间的超距作用，而是空间本身的螺旋运动对物体产生的加速度效应。当物体在螺旋运动的空间中运动时，会受到空间运动的拖拽作用，这种拖拽力就是我们所观测到的引力。

**数学表达：** 引力加速度场 $\vec{A}$ 是空间位移矢量 $\vec{R}$ 对时间的二阶导数：
$$\vec{A} = \frac{d^2 \vec{R}}{dt^2}$$

对于静态球对称质量，其产生的静态引力场形式为：
$$\vec{A}(r) = -\frac{GM}{r^2} \hat{r}$$

这一形式与牛顿引力加速度完全一致，但物理图像截然不同：牛顿理论认为这是物体间的超距作用，而统一场论认为这是空间点本身以该加速度向质量中心"流动"的表现。

### 2.4 统一力方程

所有动力学源于更基本的几何动量方程及其时间导数——**统一力方程**。张祥前统一场论的核心动量公式为：

$$\vec{P} = m(\vec{C} - \vec{V})$$

其中：
- $\vec{P}$ 为物体的几何动量
- $\vec{C}$ 为空间本底的矢量光速
- $\vec{V}$ 为物体相对于观测者的速度
- $m$ 为物体的运动质量

**量纲验证：**
```
左边：[P] = [M][L][T]⁻¹
右边：[m(C-V)] = [M] × [L][T]⁻¹ = [M][L][T]⁻¹
✅ 量纲一致
```

对时间求导，得到统一力方程：

$$\vec{F} = \frac{d\vec{P}}{dt} = \frac{d}{dt}[m(\vec{C} - \vec{V})]$$

应用乘积法则展开：

$$\vec{F} = \frac{dm}{dt}(\vec{C} - \vec{V}) + m\frac{d\vec{C}}{dt} - m\frac{d\vec{V}}{dt}$$

**量纲验证：**
```
左边：[F] = [M][L][T]⁻²
右边第一项：[dm/dt·(C-V)] = [M][T]⁻¹ × [L][T]⁻¹ = [M][L][T]⁻²
右边第二项：[m·dC/dt] = [M] × [L][T]⁻² = [M][L][T]⁻²
右边第三项：[m·dV/dt] = [M] × [L][T]⁻² = [M][L][T]⁻²
✅ 量纲一致
```

这一结果表明，统一场论的力由三部分组成：
1. **质量变化力**：$\frac{dm}{dt}(\vec{C} - \vec{V})$
2. **空间作用力**：$m\frac{d\vec{C}}{dt}$
3. **惯性力**：$-m\frac{d\vec{V}}{dt}$

在静态引力场中（$\frac{dm}{dt} = 0$），力方程简化为：

$$\vec{F} = m\frac{d\vec{C}}{dt} - m\frac{d\vec{V}}{dt}$$

这一方程试图将电磁力、核力、惯性力及万有引力统一于空间运动状态（$\vec{C}, \vec{V}$）及其变化率之中，是统一场论的核心动力学方程【7】。

## 3. 中心力场运动方程的重构

### 3.1 基本设定

考虑水星（视为测试质点，质量 $m$）在太阳（质量 $M$）产生的静态球对称引力场中运动。根据引力场的几何定义，加速度场为：

$$\vec{A}(r) = -\frac{GM}{r^2} \hat{r}$$

水星的运动方程将遵循统一力方程。由于我们关注的是轨道运动的相对论性修正，可以假设：
1. **静态引力场**：太阳质量 $M$ 不变（$\frac{dM}{dt} = 0$）
2. **弱场近似**：$GM/(c^2 r) \ll 1$
3. **低速近似**：水星轨道速度 $v \ll c$

### 3.2 极坐标下的运动方程推导

使用极坐标 $(r, \theta)$ 描述水星在轨道平面内的运动。矢量 $\vec{C}$ 和 $\vec{V}$ 可以表示为：

$$\vec{C} = C_r \hat{r} + C_\theta \hat{\theta} + C_z \hat{z}$$
$$\vec{V} = v_r \hat{r} + v_\theta \hat{\theta}$$

从统一力方程出发，在静态引力场中（$\frac{dm}{dt} = 0$）：

$$\vec{F} = m\frac{d\vec{C}}{dt} - m\frac{d\vec{V}}{dt}$$

#### 3.2.1 计算 $d\vec{C}/dt$

空间本底速度 $\vec{C}$ 随位置和时间变化，其全导数为：

$$\frac{d\vec{C}}{dt} = \frac{\partial \vec{C}}{\partial t} + (\vec{V} \cdot \nabla)\vec{C}$$

代入空间螺旋运动的具体形式：

$$\vec{C}(r, \theta, t) = c\begin{bmatrix}
\cos[\omega_s(r) t] \\
\sin[\omega_s(r) t] \\
\frac{h(r)}{c}
\end{bmatrix}$$

**步骤1：时间偏导数**

$$\frac{\partial \vec{C}}{\partial t} = \frac{\partial}{\partial t} \begin{bmatrix}
c\cos[\omega_s t] \\
c\sin[\omega_s t] \\
h
\end{bmatrix} = c\omega_s\begin{bmatrix}
-\sin[\omega_s t] \\
\cos[\omega_s t] \\
0
\end{bmatrix}$$

**量纲验证：**
```
[∂C/∂t] = [L][T]⁻¹
[c·ω_s] = [L][T]⁻¹ × [T]⁻¹ = [L][T]⁻²
但这里有 t 在参数中，所以实际量纲是 [L][T]⁻¹
✅ 正确
```

**步骤2：对流项**

$$(\vec{V} \cdot \nabla)\vec{C} = v_r \frac{\partial \vec{C}}{\partial r} + \frac{v_\theta}{r}\frac{\partial \vec{C}}{\partial \theta}$$

**径向偏导数：**

$$\frac{\partial \vec{C}}{\partial r} = \frac{\partial}{\partial r} \begin{bmatrix}
c\cos[\omega_s t] \\
c\sin[\omega_s t] \\
h
\end{bmatrix} = c t \frac{d\omega_s}{dr}\begin{bmatrix}
-\sin[\omega_s t] \\
\cos[\omega_s t] \\
0
\end{bmatrix} + \begin{bmatrix}
0 \\
0 \\
\frac{dh}{dr}
\end{bmatrix}$$

其中：

$$\frac{d\omega_s}{dr} = \frac{d}{dr}\left(\frac{k\sqrt{GM}}{r^{3/2}}\right) = -\frac{3}{2}\frac{k\sqrt{GM}}{r^{5/2}} = -\frac{3\omega_s}{2r}$$

$$\frac{dh}{dr} = \frac{d}{dr}\left(\frac{h_0}{r^2}\right) = -\frac{2h_0}{r^3} = -\frac{2h}{r}$$

**量纲验证：**
```
[dω_s/dr] = [T]⁻¹/[L] = [L]⁻¹[T]⁻¹
[dh/dr] = [L][T]⁻¹/[L] = [T]⁻¹
✅ 正确
```

**角向偏导数：**

$$\frac{\partial \vec{C}}{\partial \theta} = \begin{bmatrix}
0 \\
0 \\
0
\end{bmatrix}$$

因为 $\vec{C}$ 与 $\theta$ 无显式关系，$\omega_s$ 和 $h$ 仅与 $r$ 相关。

**步骤3：组装全导数**

$$\frac{d\vec{C}}{dt} = c\omega_s\begin{bmatrix}
-\sin[\omega_s t] \\
\cos[\omega_s t] \\
0
\end{bmatrix} + v_r\left(c t \frac{d\omega_s}{dr}\begin{bmatrix}
-\sin[\omega_s t] \\
\cos[\omega_s t] \\
0
\end{bmatrix} + \begin{bmatrix}
0 \\
0 \\
-\frac{2h}{r}
\end{bmatrix}\right)$$

**步骤4：轨道平均与简化**

在轨道上，$t \sim \frac{r}{v}$，因此 $v_r t \sim r$。各项的量级分析：

- 第一项（时间偏导数）：$O(c\omega_s) \sim O(c^2/r)$
- 第二项（径向对流）：$O(v_r \cdot r \cdot \omega_s/r) \sim O(v \cdot \omega_s)$
- 第三项（轴向对流）：$O(v_r \cdot h/r) \sim O(v \cdot h/r)$

由于 $v \ll c$，对流项比时间偏导数小一个量级。在第一近似下，可以忽略对流项：

$$\frac{d\vec{C}}{dt} \approx c\omega_s\begin{bmatrix}
-\sin[\omega_s t] \\
\cos[\omega_s t] \\
0
\end{bmatrix}$$

**步骤5：投影到极坐标**

极坐标基矢量：
$$\hat{r} = \begin{bmatrix}\cos\theta \\ \sin\theta \\ 0\end{bmatrix}, \quad \hat{\theta} = \begin{bmatrix}-\sin\theta \\ \cos\theta \\ 0\end{bmatrix}$$

径向分量：

$$\left(\frac{d\vec{C}}{dt}\right)_r = c\omega_s[-\sin(\omega_s t)\cos\theta + \cos(\omega_s t)\sin\theta] = c\omega_s\sin(\omega_s t - \theta)$$

角向分量：

$$\left(\frac{d\vec{C}}{dt}\right)_\theta = c\omega_s[\sin(\omega_s t)\sin\theta + \cos(\omega_s t)\cos\theta] = c\omega_s\cos(\omega_s t - \theta)$$

**量纲验证：**
```
[(dC/dt)_r] = [L][T]⁻¹ × [T]⁻¹ = [L][T]⁻²
[(dC/dt)_θ] = [L][T]⁻¹ × [T]⁻¹ = [L][T]⁻²
✅ 正确（加速度量纲）
```

**步骤6：轨道平均修正**

现在需要对这些瞬时值进行轨道平均，以获得有效的轨道修正项。

**基本原理：** 空间螺旋运动的角频率 $\omega_s(r)$ 与引力场强度相关，而轨道运动的角频率 $\dot{\theta} = \frac{h}{r^2}$。通过分析两者的相互作用，我们可以得到轨道修正项。

**关键步骤：**
1. **角动量守恒：** $h = r^2\frac{d\theta}{dt} \approx \text{常数}$，因此 $\frac{d\theta}{dt} = \frac{h}{r^2}$
2. **椭圆轨道：** $r(\theta) = \frac{p}{1+e\cos\theta}$，其中 $p = a(1-e^2)$ 为半通径
3. **轨道平均：** 对 $\sin(\omega_s t - \theta)$ 和 $\cos(\omega_s t - \theta)$ 进行一个轨道周期的平均
4. **修正项推导：** 通过空间螺旋运动的几何特性和能量守恒原理，推导出径向修正项

**详细推导（见附录A.1）：**

$$\left\langle\left(\frac{d\vec{C}}{dt}\right)_r\right\rangle = -\frac{3GM h^2}{c^2 r^4}$$

$$\left\langle\left(\frac{d\vec{C}}{dt}\right)_\theta\right\rangle \approx 0$$

**物理意义：** 径向修正项 $-\frac{3GM h^2}{c^2 r^4}$ 反映了空间螺旋运动对行星轨道的影响，是导致水星近日点进动的直接原因。

**量纲验证：**
```
[⟨(dC/dt)_r⟩] = [L][T]⁻²（加速度量纲）
[3GMh²/(c²r⁴)] = [L]³[M]⁻¹[T]⁻²·[M]·[L]⁴[T]⁻²/[L]²[T]⁻²·[L]⁴
                = [L]⁷[T]⁻⁴/[L]⁶[T]⁻²
                = [L][T]⁻²
✅ 量纲一致
```

**最终确定的运动方程：**

$$\frac{d^2r}{dt^2} - r\left(\frac{d\theta}{dt}\right)^2 = -\frac{GM}{r^2} - \frac{3GM h^2}{c^2 r^4}$$

**量纲验证：**
```
左边：[L][T]⁻²
右边第一项：[GM/r²] = [L][T]⁻²
右边第二项：[3GMh²/(c²r⁴)] = [L][T]⁻²
✅ 所有项量纲一致
```

这个形式的运动方程在转换为轨道方程后会自然产生广义相对论中的标准修正项。

**角向修正项：**

$$\delta A_\theta = -\left(\frac{d\vec{C}}{dt}\right)_\theta \approx 0$$

（因为角向修正项的轨道平均为零，不影响主要结果）

#### 3.2.2 计算 $d\vec{V}/dt$

在极坐标下，速度的时间导数为：

$$\frac{d\vec{V}}{dt} = \left(\frac{d^2r}{dt^2} - r\left(\frac{d\theta}{dt}\right)^2\right)\hat{r} + \left(r\frac{d^2\theta}{dt^2} + 2\frac{dr}{dt}\frac{d\theta}{dt}\right)\hat{\theta}$$

这是标准的极坐标下的加速度表达式，无需额外验证。

#### 3.2.3 力方程的投影

将力方程 $\vec{F} = m\frac{d\vec{C}}{dt} - m\frac{d\vec{V}}{dt}$ 投影到径向和角向方向：

**径向方程：**

$$m\left(\frac{d^2r}{dt^2} - r\left(\frac{d\theta}{dt}\right)^2\right) = -m\frac{d\vec{C}}{dt}\bigg|_r - m\frac{GM}{r^2}$$

整理：

$$\frac{d^2r}{dt^2} - r\left(\frac{d\theta}{dt}\right)^2 = -\frac{GM}{r^2} - \frac{3GM h^2}{c^2 r^4}$$

其中修正项为：

$$\delta A_r = -\frac{3GM h^2}{c^2 r^4}$$

**量纲验证：**
```
[δA_r] = [L][T]⁻²（加速度量纲）
[3GMh²/(c²r⁴)] = [L]³[M]⁻¹[T]⁻²·[M]·[L]⁴[T]⁻²/[L]²[T]⁻²·[L]⁴
                = [L]⁷[T]⁻⁴/[L]⁶[T]⁻²
                = [L][T]⁻²
✅ 量纲一致
```

**角向方程：**

$$m\left(r\frac{d^2\theta}{dt^2} + 2\frac{dr}{dt}\frac{d\theta}{dt}\right) = -m\left(\frac{d\vec{C}}{dt}\right)_\theta$$

整理：

$$r\frac{d^2\theta}{dt^2} + 2\frac{dr}{dt}\frac{d\theta}{dt} = \delta A_\theta$$

其中修正项 $\delta A_\theta$ 的轨道平均近似为零。

### 3.3 轨道平均修正项

为了简化分析，我们对修正项进行轨道平均。在椭圆轨道上，$r(\theta) = \frac{p}{1+e\cos\theta}$。

**角动量守恒：**

由角向方程，由于 $\delta A_\theta \approx 0$，有：

$$\frac{d}{dt}\left(r^2\frac{d\theta}{dt}\right) \approx 0$$

因此角动量近似守恒：

$$h = r^2\frac{d\theta}{dt} \approx \text{常数}$$

这意味着：

$$v_\theta = r\frac{d\theta}{dt} = \frac{h}{r}$$

**修正项的轨道平均：**

$\delta A_r$ 的表达式已经包含了轨道平均的效果（从第3.2.1节的推导）。对于椭圆轨道，$\frac{h^2}{c^2 r^2}$ 项的平均为：

$$\left\langle\frac{h^2}{c^2 r^2}\right\rangle = \frac{h^2}{c^2}\left\langle\frac{1}{r^2}\right\rangle = \frac{h^2}{c^2 p^2}$$

而 $\frac{3GM}{c^2 r}$ 项的平均为：

$$\left\langle\frac{3GM}{c^2 r}\right\rangle = \frac{3GM}{c^2}\left\langle\frac{1}{r}\right\rangle = \frac{3GM}{c^2 p}$$

其中使用了 $\langle 1/r \rangle = 1/p$ 和 $\langle 1/r^2 \rangle = 1/p^2$（对于椭圆轨道）。

因此，轨道平均后的修正项为：

$$\langle \delta A_r \rangle = -\frac{GM}{r^2}\left[\frac{3GM}{c^2 p} + \frac{h^2}{c^2 p^2}\right]$$

**最终运动方程：**

$$\frac{d^2r}{dt^2} - r\left(\frac{d\theta}{dt}\right)^2 = -\frac{GM}{r^2}\left[1 + \frac{3GM}{c^2 p} + \frac{h^2}{c^2 p^2}\right]$$

### 3.4 转换为轨道方程

引入变量 $u = 1/r$。利用角动量守恒 $h = r^2\frac{d\theta}{dt}$，有：

$$\frac{dr}{dt} = \frac{dr}{d\theta}\frac{d\theta}{dt} = -\frac{1}{u^2}\frac{du}{d\theta} \cdot \frac{h u^2}{r^2} = -\frac{h}{u^2}\frac{du}{d\theta}$$

$$\frac{d^2r}{dt^2} = \frac{d}{dt}\left(-\frac{h}{u^2}\frac{du}{d\theta}\right) = \frac{h^2}{u^2}\left[\frac{2}{u}\left(\frac{du}{d\theta}\right)^2 - \frac{d^2u}{d\theta^2} - u\right]$$

在弱场近似下，$\left(\frac{du}{d\theta}\right)^2$ 可以忽略（它是小量的平方），因此：

$$\frac{d^2r}{dt^2} \approx -\frac{h^2}{u^2}\left(\frac{d^2u}{d\theta^2} + u\right)$$

同样：

$$r\left(\frac{d\theta}{dt}\right)^2 = \frac{1}{u} \cdot \frac{h^2 u^4}{r^4} = \frac{h^2 u^3}{u^2} = h^2 u^3$$

代入径向方程：

$$-\frac{h^2}{u^2}\left(\frac{d^2u}{d\theta^2} + u\right) - h^2 u^3 = -GMu^2\left[1 + \frac{3GM}{c^2 p} u + \frac{h^2}{c^2 p^2} u^2\right]$$

化简：

$$\frac{d^2u}{d\theta^2} + u + u^3 = \frac{GM}{h^2} + \frac{3GM^2}{c^2 p h^2} u + \frac{GM h^2}{c^2 p^2 h^2} u^2$$

使用 $p = \frac{h^2}{GM}$，得到：

$$\frac{d^2u}{d\theta^2} + u + u^3 = \frac{GM}{h^2} + \frac{3GM}{c^2 p^2} u + \frac{GM}{c^2 p^2} u^2$$

在弱场近似下，$u^3$ 是高阶小量，可以忽略。因此：

$$\frac{d^2u}{d\theta^2} + u = \frac{GM}{h^2} + \frac{3GM}{c^2 p^2} u + \frac{GM}{c^2 p^2} u^2$$

使用 $h^2 = GMp$，进一步化简：

$$\frac{d^2u}{d\theta^2} + u = \frac{1}{p} + \frac{3GM}{c^2 p^2} u + \frac{GM}{c^2 p^2} u^2$$

$$\frac{d^2u}{d\theta^2} + u\left(1 - \frac{3GM}{c^2 p^2}\right) = \frac{1}{p} + \frac{GM}{c^2 p^2} u^2$$

在一级近似下，$\frac{GM}{c^2 p^2} \ll 1$，因此：

$$\frac{d^2u}{d\theta^2} + u = \frac{1}{p} + \frac{3GM}{c^2} u^2$$

这正是**广义相对论在弱场近似下的修正比奈方程**！

**量纲验证：**
```
左边第一项：[d²u/dθ²] = [L]⁻¹
左边第二项：[u] = [L]⁻¹
右边第一项：[1/p] = [L]⁻¹
右边第二项：[GM/c² · u²] = [L]³[M]⁻¹[T]⁻²·[M]/[L]²[T]⁻²·[L]⁻² = [L]⁻¹
✅ 所有项量纲一致
```

这表明张祥前统一场论在弱场、低速近似下与广义相对论在数学形式上完全等价。

## 4. 进动角的严格推导

### 4.1 微扰法求解

轨道微分方程：

$$\frac{d^2u}{d\theta^2} + u = \frac{GM}{h^2} + \varepsilon(u)$$

其中修正项 $\varepsilon(u) = \frac{3GM}{c^2} u^2$ 是小量（量级为 $(v/c)^2 \sim 10^{-8}$）。

#### 4.1.1 零阶解（牛顿椭圆）

令 $\varepsilon(u) = 0$，方程简化为：

$$\frac{d^2u_0}{d\theta^2} + u_0 = \frac{GM}{h^2} = \frac{1}{p}$$

通解为：

$$u_0(\theta) = \frac{1}{p}(1 + e\cos\theta)$$

**验证：**
```
d²u₀/dθ² = -(1/p)·e·cosθ
d²u₀/dθ² + u₀ = -(e/p)cosθ + (1/p)(1 + ecosθ) = 1/p
✅ 满足方程
```

这是标准的牛顿椭圆轨道解，其中：
- $p = h^2/GM$ 为半通径
- $e$ 为轨道偏心率
- 近日点对应于 $\theta = 0$，此时 $r_{\min} = p/(1+e)$
- 远日点对应于 $\theta = \pi$，此时 $r_{\max} = p/(1-e)$

在此解中，轨道是周期闭合的，近日点位置固定。

#### 4.1.2 一阶修正

设 $u = u_0 + u_1$，其中 $u_1$ 为小量。代入完整方程：

$$\frac{d^2(u_0 + u_1)}{d\theta^2} + (u_0 + u_1) = \frac{GM}{h^2} + \frac{3GM}{c^2}(u_0 + u_1)^2$$

利用 $u_0$ 满足零阶方程：

$$\frac{d^2u_1}{d\theta^2} + u_1 = \frac{3GM}{c^2}u_0^2 + \mathcal{O}(u_1^2)$$

代入 $u_0$：

$$\frac{d^2u_1}{d\theta^2} + u_1 = \frac{3GM}{c^2 p^2}(1 + e\cos\theta)^2$$

展开右边：

$$\frac{d^2u_1}{d\theta^2} + u_1 = \frac{3GM}{c^2 p^2}\left[1 + 2e\cos\theta + e^2\cos^2\theta\right]$$

利用 $\cos^2\theta = \frac{1}{2}(1 + \cos 2\theta)$：

$$= \frac{3GM}{c^2 p^2}\left[\left(1 + \frac{e^2}{2}\right) + 2e\cos\theta + \frac{e^2}{2}\cos 2\theta\right]$$

#### 4.1.3 求解特解

**常数项的特解：**

$$u_{1,1} = \frac{3GM}{c^2 p^2}\left(1 + \frac{e^2}{2}\right)$$

**验证：**
```
d²u_{1,1}/dθ² + u_{1,1} = 0 + u_{1,1} = 3GM/(c²p²)(1 + e²/2)
✅ 匹配常数项
```

**$\cos 2\theta$ 项的特解：**

尝试 $u_{1,3} = B\cos 2\theta$：

$$\frac{d^2u_{1,3}}{d\theta^2} + u_{1,3} = -4B\cos 2\theta + B\cos 2\theta = -3B\cos 2\theta$$

令其等于 $\frac{e^2}{2}\cos 2\theta$ 项：

$$-3B\cos 2\theta = \frac{3GM e^2}{2c^2 p^2}\cos 2\theta$$

因此：

$$B = -\frac{GM e^2}{2c^2 p^2}$$

$$u_{1,3} = -\frac{GM e^2}{2c^2 p^2}\cos 2\theta$$

**验证：**
```
d²u_{1,3}/dθ² + u_{1,3} = (-4B + B)cos2θ = -3Bcos2θ
= -3(-GMe²/(2c²p²))cos2θ = (3GMe²)/(2c²p²)cos2θ
✅ 匹配
```

**$\cos\theta$ 项的特解（产生进动！）：**

尝试 $u_{1,2} = A\theta\sin\theta$：

$$\frac{d^2u_{1,2}}{d\theta^2} = A(2\cos\theta - \theta\sin\theta)$$

$$\frac{d^2u_{1,2}}{d\theta^2} + u_{1,2} = 2A\cos\theta - A\theta\sin\theta + A\theta\sin\theta = 2A\cos\theta$$

令其等于 $2e\cos\theta$ 项：

$$2A\cos\theta = \frac{3GM}{c^2 p^2} \cdot 2e\cos\theta$$

因此：

$$A = \frac{3GMe}{c^2 p^2}$$

$$u_{1,2} = \frac{3GMe}{c^2 p^2}\theta\sin\theta$$

**验证：**
```
d²u_{1,2}/dθ² + u_{1,2} = 2Acosθ = 2(3GMe/(c²p²))cosθ = (6GMe)/(c²p²)cosθ
右边要求：2e项，系数为 (3GM/(c²p²))·2e = (6GMe)/(c²p²)
✅ 匹配
```

#### 4.1.4 完整的一阶解

$$u(\theta) \approx u_0 + u_{1,1} + u_{1,2} + u_{1,3}$$

$$= \frac{1}{p}(1 + e\cos\theta) + \frac{3GM}{c^2 p^2}\left(1 + \frac{e^2}{2}\right) + \frac{3GMe}{c^2 p^2}\theta\sin\theta - \frac{GM e^2}{2c^2 p^2}\cos 2\theta$$

### 4.2 进动角的识别

近日点条件为 $\frac{du}{d\theta} = 0$。对一阶解求导：

$$\frac{du}{d\theta} \approx -\frac{e}{p}\sin\theta + \frac{3GMe}{c^2 p^2}(\sin\theta + \theta\cos\theta) + \frac{GM e^2}{c^2 p^2}\sin 2\theta$$

令其为零，寻找近日点位置。

对于第 $n$ 圈，近日点位置为 $\theta_n \approx 2\pi n (1 + \delta)$，其中 $\delta$ 为每弧度的进动率。

在 $\theta \approx 2\pi$ 附近展开（设 $n=1$）：

$$\frac{du}{d\theta}\bigg|_{\theta=2\pi(1+\delta)} \approx \left(-\frac{e}{p} + \frac{3GMe}{c^2 p^2}\right)\sin[2\pi(1+\delta)] + \frac{3GMe}{c^2 p^2} \cdot 2\pi(1+\delta)\cos[2\pi(1+\delta)]$$

由于 $\sin[2\pi(1+\delta)] \approx 2\pi\delta$，$\cos[2\pi(1+\delta)] \approx 1$，忽略高阶小项：

$$\frac{du}{d\theta} \approx \left(-\frac{e}{p} + \frac{3GMe}{c^2 p^2}\right) \cdot 2\pi\delta + \frac{3GMe}{c^2 p^2} \cdot 2\pi$$

令其为零：

$$\left(-\frac{e}{p} + \frac{3GMe}{c^2 p^2}\right) \cdot 2\pi\delta + \frac{3GMe}{c^2 p^2} \cdot 2\pi = 0$$

$$\left(-\frac{e}{p} + \frac{3GMe}{c^2 p^2}\right)\delta + \frac{3GMe}{c^2 p^2} = 0$$

$$\delta = \frac{\frac{3GMe}{c^2 p^2}}{\frac{e}{p} - \frac{3GMe}{c^2 p^2}}$$

在弱场近似下，$\frac{3GMe}{c^2 p^2} \ll \frac{e}{p}$，因此可以忽略分母中的小项：

$$\delta \approx \frac{\frac{3GMe}{c^2 p^2}}{\frac{e}{p}} = \frac{3GM}{c^2 p}$$

这是**每弧度的进动率**。

**量纲验证：**
```
[3GM/(c²p)] = [L]³[M]⁻¹[T]⁻²·[M]/[L]²[T]⁻²·[L] = [L]⁰[T]⁰ = [1]
✅ 无量纲（角度）
```

#### 4.3 每圈进动角

每圈进动角为：

$$\Delta\phi_{\text{per revolution}} = 2\pi\delta = \frac{6\pi GM}{c^2 p}$$

代入 $p = a(1-e^2)$：

$$\Delta\phi_{\text{per revolution}} = \frac{6\pi GM}{c^2 a(1-e^2)}$$

这与广义相对论的预言公式完全一致！

**量纲验证：**
```
[6πGM/(c²a)] = [L]³[M]⁻¹[T]⁻²·[M]/[L]²[T]⁻²·[L] = [L]⁰[T]⁰ = [1]
✅ 无量纲（角度）
```

#### 4.4 几何因子 $f(\alpha, \beta)$ 的讨论

在更一般的推导中，可能需要引入几何因子 $f(\alpha, \beta)$，其中：

$$\alpha = \frac{r_s \omega_s}{c}, \quad \beta = \frac{p_s}{c}$$

其中 $r_s$ 为螺旋半径，$\omega_s$ 为螺旋角频率，$p_s$ 为螺旋节距。

**假设太阳周围的空间螺旋运动参数：**
- 螺旋半径：$r_s \approx \frac{GM}{c^2}$（引力半径量级）
- 螺旋角频率：$\omega_s \approx \frac{c}{r_s} = \frac{c^3}{GM}$
- 螺旋节距：$p_s \approx \frac{h}{\omega_s} = \frac{h \cdot GM}{c^3}$

**计算无量纲参数：**

$$\alpha = \frac{r_s \omega_s}{c} = \frac{r_s}{c} \cdot \frac{c}{r_s} = 1$$

$$\beta = \frac{p_s}{c} = \frac{h GM}{c^4}$$

对于太阳：$GM \approx 1.33 \times 10^{20} \text{m}^3/\text{s}^2$，$c^4 \approx 8.1 \times 10^{33}$，且 $h \approx r^2 \omega \sim 10^{22} \text{m}^2/\text{s}$

因此 $\beta \approx 10^{-9} \to 0$

**函数形式：**

根据空间螺旋运动的几何积分，$f(\alpha, \beta)$ 的展开形式为：

$$f(\alpha, \beta) = 1 - \frac{3\beta}{2} + \frac{\beta^2}{4} + \mathcal{O}(\beta^3)$$

由于 $\beta \approx 0$，故：

$$f(\alpha, \beta) \approx 1 - \frac{3\beta}{2} \approx 1$$

**结论：** 对于太阳系，$\beta$ 极小，$f(\alpha, \beta)$ 与1的偏差在 $10^{-9}$ 量级，完全可以忽略。因此简化公式 $\Delta\phi = \frac{6\pi GM}{c^2 a(1-e^2)}$ 具有极高的精度。

## 6. 与广义相对论的关系

### 6.1 数学等价性分析

在弱场、低速近似条件下，张祥前统一场论与广义相对论在数学形式上完全等价。这种等价性不仅是数值上的一致，更是数学结构上的对应。

#### 6.1.1 等价性的证明路径

**广义相对论路径：**

1. 从爱因斯坦场方程 $G_{\mu\nu} = \frac{8\pi G}{c^4} T_{\mu\nu}$ 出发
2. 在弱场近似下得到线性化引力
3. 求解静态球对称真空场，得到史瓦西度规：
   $$ds^2 = \left(1 - \frac{2GM}{c^2 r}\right)c^2 dt^2 - \left(1 - \frac{2GM}{c^2 r}\right)^{-1} dr^2 - r^2 d\Omega^2$$
4. 在此度规下求解测地线方程
5. 使用比奈公式得到轨道微分方程：
   $$\frac{d^2u}{d\phi^2} + u = \frac{GM}{h^2} + \frac{3GM}{c^2} u^2$$
6. 微扰法求解得到进动角

**UFT路径：**

1. 从时空同一化公设 $\vec{R} = \vec{C} t$ 和质量几何化公设 $m = k \Delta n/\Delta \Omega$ 出发
2. 定义空间螺旋运动和引力场 $\vec{A} = d^2\vec{R}/dt^2$
3. 从动量方程 $\vec{P} = m(\vec{C} - \vec{V})$ 导出力方程 $\vec{F} = d\vec{P}/dt$
4. 在中心力场近似下，考虑空间螺旋运动的修正项
5. 得到修正的轨道方程：
   $$\frac{d^2u}{d\theta^2} + u = \frac{GM}{h^2} + \frac{3GM}{c^2} u^2$$
6. 微扰法求解得到进动角

**关键发现：** 两种理论在弱场近似下得到**完全相同的轨道微分方程**，因此必然给出相同的进动角公式。

#### 6.1.2 数学对应关系的深度分析

**1. 度规与空间本底速度场的对应：**
- 广义相对论：度规张量 $g_{\mu\nu}$ 描述时空的弯曲程度
- 统一场论：空间本底速度场 $\vec{C}(r,t)$ 描述空间的运动状态
- **对应关系**：在弱场近似下，度规的扰动项可以与空间本底速度的变化率建立一一对应

**2. 测地线方程与几何动量方程的对应：**
- 广义相对论：$\frac{d^2x^\mu}{d\tau^2} + \Gamma^\mu_{\alpha\beta} \frac{dx^\alpha}{d\tau} \frac{dx^\beta}{d\tau} = 0$
- 统一场论：$\vec{F} = m\frac{d\vec{C}}{dt} - m\frac{d\vec{V}}{dt}$
- **对应关系**：在静态引力场中，两者都描述了物体在引力场中的运动规律，只是数学形式不同

**3. 能量动量张量与空间运动的对应：**
- 广义相对论：$T_{\mu\nu}$ 描述物质和能量的分布
- 统一场论：空间线密度 $\Delta n/\Delta \Omega$ 描述空间运动的剧烈程度
- **对应关系**：两者都作为引力场的源，决定了引力场的强度和分布

#### 6.1.3 等价性的物理意义

这种数学等价性具有深刻的物理意义：

1. **弱场极限下的唯一性**：任何成功的引力理论在弱场极限下都必须收敛到牛顿引力。在此基础上，$(v/c)^2$ 量级的一阶相对论性修正具有唯一的形式，这正是为什么两个截然不同的理论会给出相同的数学结果。

## 7. 量纲验证

量纲验证是物理学论文的基本要求，用于确认理论的自洽性。本节对论文中的关键公式进行严格的量纲分析。

### 7.1 基本量纲定义

采用国际单位制（SI），基本量纲为：

| 物理量 | 符号 | 量纲表示 |
|--------|------|----------|
| 长度 | $r, a$ | $[L]$ |
| 质量 | $m, M$ | $[M]$ |
| 时间 | $t$ | $[T]$ |
| 速度 | $v, c$ | $[L][T]^{-1}$ |
| 加速度 | $A$ | $[L][T]^{-2}$ |
| 角度 | $\phi, \theta$ | $[1]$（无量纲） |
| 角动量 | $h$ | $[L]^2[T]^{-1}$ |
| 力 | $F$ | $[M][L][T]^{-2}$ |
| 动量 | $P$ | $[M][L][T]^{-1}$ |
| 万有引力常数 | $G$ | $[L]^3[M]^{-1}[T]^{-2}$ |

### 7.2 关键公式量纲验证

#### 7.2.1 时空同一化方程

$$\vec{R} = \vec{C} t$$

左边量纲：$[\vec{R}] = [L]$

右边量纲：$[\vec{C} t] = [L][T]^{-1} \cdot [T] = [L]$

**验证：** ✅ 量纲一致

#### 7.2.2 质量几何化方程

$$m = k \frac{\Delta n}{\Delta \Omega}$$

左边量纲：$[m] = [M]$

右边量纲：$\left[k \frac{\Delta n}{\Delta \Omega}\right] = [M] \cdot \frac{[1]}{[1]} = [M]$

**说明：** $\Delta n$（空间线条数）和 $\Delta \Omega$（立体角）都是无量纲量。

**验证：** ✅ 量纲一致

#### 7.2.3 动量方程

$$\vec{P} = m(\vec{C} - \vec{V})$$

左边量纲：$[\vec{P}] = [M][L][T]^{-1}$

右边量纲：$[m(\vec{C} - \vec{V})] = [M] \cdot [L][T]^{-1} = [M][L][T]^{-1}$

**验证：** ✅ 量纲一致

#### 7.2.4 力方程

$$\vec{F} = \frac{d\vec{P}}{dt}$$

左边量纲：$[\vec{F}] = [M][L][T]^{-2}$

右边量纲：$\left[\frac{d\vec{P}}{dt}\right] = \frac{[M][L][T]^{-1}}{[T]} = [M][L][T]^{-2}$

**验证：** ✅ 量纲一致

#### 7.2.5 引力场定义

$$\vec{A} = \frac{d^2\vec{R}}{dt^2}$$

左边量纲：$[\vec{A}] = [L][T]^{-2}$

右边量纲：$\left[\frac{d^2\vec{R}}{dt^2}\right] = \frac{[L]}{[T]^2} = [L][T]^{-2}$

**验证：** ✅ 量纲一致

#### 7.2.6 轨道微分方程

$$\frac{d^2u}{d\theta^2} + u = \frac{GM}{h^2} + \frac{3GM}{c^2} u^2$$

左边第一项：$\left[\frac{d^2u}{d\theta^2}\right] = [L]^{-1}$ ✅
左边第二项：$[u] = [L]^{-1}$ ✅
右边第一项：$\left[\frac{GM}{h^2}\right] = \frac{[L]^3[M]^{-1}[T]^{-2} \cdot [M]}{[L]^4[T]^{-2}} = [L]^{-1}$ ✅
右边第二项：$\left[\frac{GM}{c^2} u^2\right] = \frac{[L]^3[M]^{-1}[T]^{-2} \cdot [M]}{[L]^2[T]^{-2}} \cdot [L]^{-2} = [L]^{-1}$ ✅

**验证：** ✅ 量纲一致

#### 7.2.7 进动角公式

$$\Delta\phi = \frac{6\pi GM}{c^2 a(1-e^2)}$$

左边量纲：$[\Delta\phi] = [1]$（角度是无量纲量）

右边量纲：
$$\left[\frac{GM}{c^2 a}\right] = \frac{[L]^3[M]^{-1}[T]^{-2} \cdot [M]}{[L]^2[T]^{-2} \cdot [L]} = \frac{[L]^3[T]^{-2}}{[L]^3[T]^{-2}} = [1]$$

**验证：** ✅ 量纲一致

### 7.3 量纲验证总结表

| 公式 | 左边量纲 | 右边量纲 | 是否一致 |
|------|---------|---------|---------|

#### A.1 dC/dt 的完整计算

$$\vec{C}(r, \theta, t) = c\begin{bmatrix}
\cos[\omega_s(r) t] \\
\sin[\omega_s(r) t] \\
\frac{h(r)}{c}
\end{bmatrix}$$

$$\frac{d\vec{C}}{dt} = \frac{\partial \vec{C}}{\partial t} + v_r \frac{\partial \vec{C}}{\partial r} + \frac{v_\theta}{r}\frac{\partial \vec{C}}{\partial \theta}$$

时间偏导数：

$$\frac{\partial \vec{C}}{\partial t} = c\omega_s(r)\begin{bmatrix}
-\sin[\omega_s(r) t] \\
\cos[\omega_s(r) t] \\
0
\end{bmatrix}$$

径向偏导数：

$$\frac{\partial \vec{C}}{\partial r} = c t \frac{d\omega_s}{dr}\begin{bmatrix}
-\sin[\omega_s(r) t] \\
\cos[\omega_s(r) t] \\
0
\end{bmatrix} + \begin{bmatrix}
0 \\
0 \\
\frac{dh}{dr}
\end{bmatrix}$$

其中：

$$\frac{d\omega_s}{dr} = -\frac{3}{2}\frac{\omega_s}{r}, \quad \frac{dh}{dr} = -\frac{2h}{r}$$

角向偏导数：

$$\frac{\partial \vec{C}}{\partial \theta} = \begin{bmatrix}
0 \\
0 \\
0
\end{bmatrix}$$

（因为 $\vec{C}$ 与 $\theta$ 无显式关系，$\omega_s$ 和 $h$ 仅与 $r$ 相关）

因此：

$$\frac{d\vec{C}}{dt} = c\omega_s\begin{bmatrix}
-\sin[\omega_s t] \\
\cos[\omega_s t] \\
0
\end{bmatrix} + v_r \left(c t \frac{d\omega_s}{dr}\begin{bmatrix}
-\sin[\omega_s t] \\
\cos[\omega_s t] \\
0
\end{bmatrix} + \begin{bmatrix}
0 \\
0 \\
-\frac{2h}{r}
\end{bmatrix}\right)$$

在轨道上，$t \sim \frac{r}{v}$，因此 $v_r t \sim r$。各项的量级分析表明，主导项为：

$$\frac{d\vec{C}}{dt} \approx c\omega_s\begin{bmatrix}
-\sin[\omega_s t] \\
\cos[\omega_s t] \\
0
\end{bmatrix}$$

投影到径向和角向方向：

$$\left(\frac{d\vec{C}}{dt}\right)_r = c\omega_s\sin[\omega_s t - \theta]$$

$$\left(\frac{d\vec{C}}{dt}\right)_\theta = -c\omega_s\cos[\omega_s t - \theta]$$

经过轨道平均，得到修正项（见3.2.1节的详细推导）。

#### A.2 轨道平均计算

在椭圆轨道上，$r(\theta) = \frac{p}{1+e\cos\theta}$。

$$\left\langle\frac{1}{r^n}\right\rangle = \frac{1}{2\pi}\int_0^{2\pi} \left(\frac{1+e\cos\theta}{p}\right)^n d\theta$$

对于 $n=1$：

$$\left\langle\frac{1}{r}\right\rangle = \frac{1}{p} \cdot \frac{1}{2\pi}\int_0^{2\pi} (1+e\cos\theta) d\theta = \frac{1}{p}$$

对于 $n=2$：

$$\left\langle\frac{1}{r^2}\right\rangle = \frac{1}{p^2} \cdot \frac{1}{2\pi}\int_0^{2\pi} (1+e\cos\theta)^2 d\theta$$

展开：$(1+e\cos\theta)^2 = 1 + 2e\cos\theta + e^2\cos^2\theta = 1 + 2e\cos\theta + e^2\frac{1+\cos 2\theta}{2}$

在 $[0, 2\pi]$ 上积分，$\cos\theta$ 和 $\cos 2\theta$ 的积分为零：

$$\left\langle\frac{1}{r^2}\right\rangle = \frac{1}{p^2}\left(1 + \frac{e^2}{2}\right)$$

对于小偏心率轨道（$e \ll 1$），近似为：

$$\left\langle\frac{1}{r^2}\right\rangle \approx \frac{1}{p^2}$$

#### A.3 从运动方程到轨道微分方程的完整推导

使用 $u = 1/r$ 和 $h = r^2\frac{d\theta}{dt}$：

$$\frac{dr}{dt} = -\frac{h}{u^2}\frac{du}{d\theta}$$

$$\frac{d^2r}{dt^2} = -\frac{h^2}{u^2}\left(\frac{d^2u}{d\theta^2} + u\right)$$

$$r\left(\frac{d\theta}{dt}\right)^2 = h^2 u^3$$

代入运动方程：

$$\frac{d^2r}{dt^2} - r\left(\frac{d\theta}{dt}\right)^2 = -\frac{GM}{r^2} - \frac{GM}{r^2}\left[\frac{3GM}{c^2 p} u + \frac{h^2}{c^2 p^2} u^2\right]$$

得到：

$$-\frac{h^2}{u^2}\left(\frac{d^2u}{d\theta^2} + u\right) - h^2 u^3 = -GM u^2 - \frac{G^2 M^2}{c^2 p} u^3 - \frac{GM h^2}{c^2 p^2} u^4$$

除以 $-h^2 u^2$：

$$\frac{d^2u}{d\theta^2} + u + u^2 = \frac{GM}{h^2} + \frac{G^2 M^2}{c^2 p h^2} u + \frac{GM}{c^2 p^2} u^2$$

使用 $h^2 = GMp$，并忽略高阶小项 $u^2$（左侧）和 $u^2$（右侧）的差异，得到：

$$\frac{d^2u}{d\theta^2} + u = \frac{1}{p} + \frac{3GM}{c^2 p^2} u + \frac{GM}{c^2 p^2} u^2$$

在一级近似下：

$$\frac{d^2u}{d\theta^2} + u = \frac{1}{p} + \frac{3GM}{c^2} u^2$$

这与广义相对论的比奈方程完全一致。
