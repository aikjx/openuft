### 1.1 凯莱-迪克森递归构造

32维超复数通过凯莱-迪克森递归公式构造：

```
给定 n 维数系 Aₙ，构造 2n 维数系 A₂ₙ：
(a, b) ∈ A₂ₙ，其中 a, b ∈ Aₙ

加法：(a, b) + (c, d) = (a+c, b+d)
乘法：(a, b) × (c, d) = (ac - d*b, da + bc*)
```

其中 * 表示共轭运算。

其中 x₀ 为实部，x₁ 到 x₃₁ 为虚部。

### 2.2 共轭运算

```
x* = (x₀, -x₁, -x₂, ..., -x₃₁)
```

### 2.3 模长

```
|x|² = x × x* = x₀² + x₁² + ... + x₃₁²
```

### 2.4 逆元

