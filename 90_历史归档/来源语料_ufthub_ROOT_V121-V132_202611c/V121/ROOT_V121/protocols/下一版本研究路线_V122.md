# ROOT V122 研究计划：从待证伪曲线到高可信度物理约束

## 任务 A：闭合中心力频率观测

对静态球对称中心势，定义 \(K(r)=r^3\Omega^2(r)\)，那么

\[
\mathcal S(r)=\frac{d\ln K}{d\ln r}
=3+2\frac{d\ln\Omega}{d\ln r};\qquad
\frac{\kappa^2}{\Omega^2}=4+2\frac{d\ln\Omega}{d\ln r}.
\]

因此可以将近圆轨道角频率沿半径的斜率与径向振动频率相互校核。这是经典中心力恒等式（不是新物理），可做 ROOT 相关“曲率—频率”方案与真实轨道动力学的兼容验收。

V119 固定候选在 400 km 处：\(d\ln\Omega/d\ln r=(-3-0.0136047993)/2\approx-1.50680240\)，而 Kepler 中心反平方力给 \(-1.5\)。实测需要非球形地球和相对论轨道处理，不能把不同卫星直接视作同一圆轨道。

## 任务 B：处理参数退化和真实数据

在任何真实数据拟合中，使用共同 \(\mu\)、多极场、初轨、钟差与拖曳项，比较两种固定模型；检验参数协方差和时间域残差。要求由不同卫星、独立测量渠道重现信号，不允许为每个高度单独重拟合 \(\alpha,\ell\)。

## 任务 C：理论结构突破

从 5D 零线元构造可量子化、正确自旋、符合 SM 表示和量子反常抵消的实际场论。若引入紧化半径，必须解释其来源与新的 KK 质量塔的实验界；不要仅将约化康普顿半径等同“螺旋半径”后声称已预测质量。

## 任务 D：终极可证伪判据

锁定模型后导出**多种互不等价的**可测预测（轨道、红移、光线、粒子谱等）。若与其中之一高精度数据矛盾，应明确宣布相应模型版本 REJECTED；不能不停增加新参数使模型无法被证伪。
