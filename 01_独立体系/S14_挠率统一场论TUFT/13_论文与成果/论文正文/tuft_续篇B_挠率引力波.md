## 一、最关键结论（先讲诚实边界）

TUFT 的引力扇区（R1 已验证：`g=(c²/2)∇lnβ1`，场方程 `□u=−(8πG/c²)ρexp(−u)`）在弱场下满足**与广义相对论完全相同的无质量波动方程**。因此：

- **传播**：波速 = c、无色散、1/r 衰减、张量偏振 —— 与 GR **完全一致，无 TUFT 独有增量**。
- **TUFT 唯一可区分预言**：一个**标量"呼吸"引力波模式** —— 由挠率/拓扑结的振荡直接驱动 `β1` 的径向脉动（`δ(lnβ1)=δu` 即度规径向应变 `h_radial=δu`）。GR 只有张量 TT 模，没有标量呼吸模。

> 这是诚实且可证伪的：TUFT 在引力波*传播*上不做任何新预言，只在*源/模态*上多一个标量通道。

## 二、符号证明（§1，PASS）

线性化 TUFT 场方程：

```
(1/c²) ∂²δu/∂t² − ∇²δu = −(8πG/c²) δρ
```

与 GR 弱场牛顿势波动方程 `(1/c²)∂²Φ−∇²Φ = −4πGδρ`（取 `Φ=(c²/2)h_{00}`）同构（差常数因子 2）。算子无质量项 ⇒ 速度 c，无色散。

## 四、对标 LISA（§3，INFO 标度估计）

物理标度（δu 为无量纲应变比，单位无关）：

```
h(r_phys) = h_toy · (ξ/A_src) · (r_det_toy / r_phys_in_L0)
r_phys_in_L0 = r_phys / (G·M_src/c²)
ξ = 自由挠率-度规耦合（尚未由 TUFT 作用量变分固定）
```

代表源：星系中心超大质量拓扑结，`M=1e6 M_⊙`，`d=100 Mpc`，LISA mHz 带：

| 量 | 值 |
|---|---|
| ξ = 1 时标量模应变（量级） | **h ~ 2.5e-10** |
| LISA 可检测（h~1e-21）所需 ξ 阈值 | **ξ_thr ~ 4e-12** |

### 可证伪约束（诚实标注）

- 若 `ξ ~ O(1)`，TUFT 标量呼吸模应变（~1e-10）**远超**现有 GW/PTA 上限 ⇒ 要么 `ξ ≪ 1`，要么该标量模**不与检验质量耦合**（仅挠率自作用）。这是 TUFT 的硬性边界，而非已观测信号。
- TUFT 张量模预言 = GR，无增量；唯一可区分预言即标量呼吸模。LISA 对纯标量偏振灵敏度弱于张量，更干净检验在**脉冲星计时阵列（nHz）**。
- 下一步：将 ξ 在 TUFT 总作用量中具体化为"挠率-度规耦合项"，方可给出定量 `h(f)` 曲线；当前只能量级标度阈值。
