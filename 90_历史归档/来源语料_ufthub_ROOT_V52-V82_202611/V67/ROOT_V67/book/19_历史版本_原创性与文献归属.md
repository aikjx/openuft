# 第十九章｜研究史、原创性与资料引用

ROOT V50–V66 形成了大量公式、可视化与科研工程。其有用之处是提出了用空间几何统一表达不同动力学现象的研究组织法，并逐步建立独立数学审计、可追踪错误和计算复核。关键的微分几何、KG 场、Einstein–Hilbert 作用量、Maxwell 与 Yang–Mills 规范结构、Kaluza–Klein 降维和诱导引力，均属于已有物理数学知识，不能因为被纳入 ROOT 体系就改称其为原创、首次发现或世界首创。

本版的新增工作是系统组合这些理论，给出若干可重复数值与精确有理数审计，明确从哪一步开始还没有证明；它不声称已通过同行评议。先前的历史资料保存在 `archive` 中作为研究轨迹，读取时应根据最新的审计结论修正历史错误；历史 ZIP 包的存在不代表其科学声明成立。
