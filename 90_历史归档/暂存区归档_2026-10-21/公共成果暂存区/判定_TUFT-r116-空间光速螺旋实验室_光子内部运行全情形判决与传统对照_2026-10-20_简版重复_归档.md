## 〇 一句话结论

**光子以 c 传播时，其内部不运行。** 精确含义有三层，彼此独立且互为印证：

1. **没有"内部时间"** —— 类光世界线 ds² ≡ 0 ⇒ 固有时 Δτ ≡ 0，无法为光子定义"内部经历了多久"；
2. **没有"内部变化"** —— 沿光子世界线，平面波相位增量 dΦ = −ω dt + k·dx ≡ **0**（机器精确零），光子沿自身路径走完，相位一点没变；
3. **没有"内部时钟"** —— de Broglie 内时钟频率 ω_int = mc²/ħ，光子 m = 0 ⇒ ω_int ≡ 0（以 PDG 上限代入，内部周期 ≥ 4136 s ≈ 69 分钟，比观测光学周期慢 1.53×10¹⁸ 倍）。

**那么"频率 ν"是什么？** 它不是光子内部在振荡，而是**外部观察者**的两种读数：固定空间点看场随时间变化 ⇒ 得到 ν；固定时刻看场沿空间变化 ⇒ 得到 λ。振荡发生在**场**里，不发生在光子的"内部"。这就是"内部不运行、外部全在运行"的准确表述。

**若强行要求"内部运行"，怎么运行？** 本册枚举 6 种载体 × 3 种时标 × 2 种速率预算 = **36 格**，逐格定价：仅 A3（偏振场矢量旋转）2 格 PASS，但该读法与 Maxwell 圆偏振**逐字相同、零新增**；A4（坡印廷涡旋）是真实现象，却属**光束横模**属性而非单光子内部；A5（亚结构）**不可判定**。⇒ 没有任何一种读法能同时满足「成立」与「新增」。

## 一 操作性定义（先定义，再判决）

「光子内部还在运行」在没有操作定义时不是可判命题。本册把它拆成三个可判分量的合取：

| 分量 | 机读形式 | 判定含义 |
|---|---|---|
| **载体** | 什么在动：A1 质心轨迹螺旋 / A2 刚体自转 / A3 偏振场矢量旋转 / A4 坡印廷能流涡旋 / A5 内部亚结构 / A6 内禀时钟 | 6 种穷尽（轨迹 · 自转 · 场 · 能流 · 组分 · 时钟） |
| **时标** | 以什么计：B1 固有时 τ / B2 坐标时 t / B3 光源时 t′ | 3 种穷尽（内禀 · 外部 · 源系） |
| **速率预算** | 横向运动是否占用 c：C1 占预算 ⇒ v_z < c；C2 不占预算 ⇒ v_z = c | 2 种穷尽（排中） |

**6 × 3 × 2 = 36 格，无一格留空**（守卫 G-A1）。判决分布 FAIL 26 / PASS 2 / BOUNDARY 8（守卫 G-A2 守恒）。

## 二 关键定理（把"想不通"变成"算得出"）

| 代号 | 定理 | 机读数字 | 后果 |
|---|---|---|---|
| **B01** | **光速预算定理**：沿圆柱螺旋以切向速率 c 前进 ⇒ v_z = c·H/√(H²+R²) < c；要求 \|1−v_z/c\| ≤ δ ⇒ R/H ≤ √(2δ) | λ=500 nm 时：δ=1e-3 ⇒ R ≤ 3.56e-9 m；**δ=1e-18 ⇒ R ≤ 1.125e-16 m**（仅电子约化康顿波长 3.862e-13 m 的 2.91e-4 倍），曲率半径 **56.27 m = 波长的 1.125e8 倍** | 轨迹必然是直线；任何可观测的螺旋半径都被压到核子尺度以下 |
| **B02** | **自转载荷定理**（与半径/波长无关）：S = Iω = ħ、I = a·m·R²，以 m_eff = ħω/c² 顶替 ⇒ **v_eq = c/√a**（R 与 ω 全部约掉） | 实心球 a=2/5 ⇒ **1.5811 c**（超光速 58.11%）；盘 ⇒ 1.4142 c；薄环 a=1 恰给 c，但环上无质量可束缚 | 任何 a<1 的刚体自转光子必超光速；薄环要求 R=7.96e-8 m，光速预算只许 R ≤ 1.125e-16 m，**超出 7.07e8 倍** ⇒ 双杀 |
| **B03** | **内禀性判据**：ω 随参考系变，m_e 不变 | 多普勒（源 500 nm）：β=0.1 ⇒ 552.8 nm；β=0.5 ⇒ 866.0 nm；β=0.9 ⇒ 2179.4 nm。对照电子 β=0.9：√(E²−p²c²) 与 m_ec² 相对残差 **2.81e-59** | 不变质量是洛伦兹标量，**频率不是** ⇒ 把 ω 称作"内部运行速率"＝把关系量当内禀量 |
| **B04** | **「螺旋角频率 = 光子频率」是反解定义** | Ω = c/L 与 ω = 2πc/λ 相等 ⇔ L = λ/2π（残差 0）。换参检验：L = 2λ/2π ⇒ Ω 相对 ω 偏差 **0.5** | L 是被 E = ħω 反解锁定的，该式信息量等价于"每周期前进一个波长"，**零新增** |

## 三 七种"内部运行"读法逐一比价（C06）

机器比对结果 `['FAIL','FAIL','FAIL','FAIL','PASS','BOUNDARY','BOUNDARY']`：

| 读法 | 判决 | 理由 |
|---|---|---|
| A1 质心走螺旋轨迹 | **FAIL**（6 格全 FAIL） | C1 ⇒ v_z < c 与真空光速冲突（R ≤ 1.125e-16 m）；C2 ⇒ 切向速率超 c ⇒ 自斥。两路互斥且穷尽 |
| A2 刚体自转 | **FAIL**（6 格全 FAIL） | m=0 ⇒ I=0，无法承载 ħ；以 m_eff 顶替触发 B02 超光速定理 |
| **A3 偏振场矢量旋转** | **PASS**（2 格） | 圆偏振 E=E₀(cos(kz−ωt), sin(kz−ωt), 0)，场矢量以 ω = 3.767e15 s⁻¹ 旋转，能流 S ∝ ẑ、E·ẑ ≡ 0 ⇒ 旋转**不占**平动预算，v_z = c 不变。**代价：与 Maxwell 圆偏振逐字相同，零新增物理** |
| A4 坡印廷能流涡旋 | **BOUNDARY** | 结构光（OAM）能流线确为螺旋，v_z = c·cos α，减速 ≤ α²/2（l=1、r=10 μm ⇒ 3.17e-5）。属**横模结构**，随束宽增大而消失，非单光子内部属性 |
| A5 内部亚结构 | **BOUNDARY（不可判定）** | m=0 且自旋>0 的粒子不存在 Newton–Wigner 位置算符 ⇒ "光子内部"缺乏定域中心 ⇒ 命题**无定义**，机器既不给 PASS 也不给 FAIL |
| A6 内禀时钟 | **FAIL**（3 格全 FAIL） | B1 ⇒ Δτ ≡ 0 ⇒ N = Δτ·ν = 0；B2/B3 ⇒ N = Δt·ν 随观测者变 ⇒ 与"内禀"直接矛盾 |

## 五 稳健性矩阵与分歧归因（D01–D03）

五套方法论立场 × 六种载体 = 30 格（守卫 G-D2）。结果：

- A2（自转）、A6（内禀时钟）在五套下**全 FAIL** ⇒ 稳健否定；
- A3、A4 稳健成立；A5 稳健不可判定；
- **唯一分歧格是 A1（轨迹螺旋）**：S3「几何主义」给 PASS（恒等式 κ²+τ² = (ω/c)² 残差 2.53e-60，确实自洽），其余四套给 FAIL。

**归因（D02）**：S3 的判据集**缺一条「洛伦兹协变性」**。κ、τ、ω 都不是洛伦兹不变量（r54 N14：boost 下 ω′/ω 可变、τ 可翻号），S3 只要求恒等式自洽而不要求协变 ⇒ 它把"在某一参考系下画得出螺旋"当成物理。**分歧可精确定位到缺失条款，不是价值观分歧 ⇒ 可仲裁，不必停在"见仁见智"。**

**元结论（D03）**：传统支 4/5 全胜，螺旋内部运行支 **0 胜**。在 36 格 + 30 格两重穷举下，"光子以 c 平移、无内部时钟、无自转、场以 ω 振荡、偏振二态"是**唯一全部通过**的一支。
