  1. 模块 C（前置）：τ/κ 方向裁决 —— 严格 Frenet 给的是 κ/τ = tanθ
==============================================================================
  圆柱螺旋 r(t) = (a·cos t, a·sin t, b·t) 的严格 Frenet 不变量：
      κ = a/(a²+b²)      τ = b/(a²+b²)
      ⇒ κ/τ = a/b       且 κ² + τ² = 1/(a²+b²)
  取 S12 裁决的电子螺旋几何： a = R = α·ρ_C,  b = ρ_C·√(1−α²),  ρ_C = ħ/(m_e c)
      ⇒ κ/τ = α/√(1−α²) = tanθ     （与 sinθ = α 严格自洽）

  α            = 7.2973525692838e-03
  θ = arcsin α = 7.2974173364873e-03 rad
  tanθ（闭式） = 7.2975468739984e-03
  κ/τ（数值）  = 7.2975468739984e-03   残差 vs tanθ = 0.000e+00
  τ/κ（数值）  = 1.3703235035914e+02   残差 vs √(1−α²)/α = 0.000e+00
  [PASS] 严格几何自洽（κ/τ = tanθ）  |  Frenet 数值回算与 tanθ 闭式残差 0.00e+00（机器零）；对照 S12 裁决 sinθ=α 完全一致

  白皮书系 S07/S08/S10 主张： α = τ/κ
  严格几何实际给：             τ/κ = √(1−α²)/α = 137.032350 ≈ 1/α = 137.035999
  ⇒ 二者相差因子 = 1.8778e+04  ≈ (1/α)² = 1.8779e+04
  [FAIL] 『α = τ/κ』方向写反  |  τ/κ ≈ 1/α = 137.0360，与 α = 7.2974e-03 相差 1.878e+04 倍；凡用 τ/κ 代入 α 处的公式数值全错

  【附带闭合】公理 A 在该螺旋几何下：κ²+τ² = 1/ρ_C²
      ⇒ ω/c = 1/ρ_C ⇒ ω = c/ρ_C = m_e c²/ℏ = 7.763441e+20 rad/s（康普顿角频率）
  [PASS] 公理 A 与螺旋几何相容  |  κ²+τ²=(ω/c)² 在 a=αρ_C, b=ρ_C√(1−α²) 下给出 ω = m_ec²/ℏ（康普顿频率），无自由参数

  3. 模块 B：ακ·g_{μν} 与 Λ·g_{μν} 的结构不可辨识性
==============================================================================
  场方程两边同型项合并：
      G_{μν} + Λ g_{μν} = 8πG(ακ g_{μν} + βτ S_{μν})
      ⇒ G_{μν} + [Λ − 8πG·ακ] g_{μν} = 8πG·βτ S_{μν}
  因 S^{μν} 反对称、g^{μν} 对称 ⇒ 二者在张量空间正交，βτ 项不参与此简并；
  唯一简并发生在 Λ 与 ακ 之间。以观测 s = Λ − 8πG·ακ 为可观测量，对 θ=(Λ,α) 求雅可比：

    情形1（κ 取单值 1.0）：J = [ ∂s/∂Λ , ∂s/∂α ] = [1, −8πG·κ]
        rank(J) = 1 < 2 ⇒ 不可辨识；可辨识组合数 = 1，退化方向 = 1
  [FAIL] Λ 与 ακ 结构不可辨识（单 κ）  |  rank=1：任何观测只能定出组合 Λ_eff = Λ − 8πG·ακ；声称『Λ 由孤子几何导出』属定义回代（TAUT）
    情形2（κ 取多值 [1.0, 2.5, 7.0]）：rank(J) = 2 ⇒ 可辨识（当且仅当 κ_i 已知且互异）
  [PASS] 破简并的充要条件  |  需 ≥2 个不同 κ 的同型观测且 κ_i 数值已知。注意：TUFT 现无第一性 κ(μ) 剖面（O-SCALE 锚定定理 / D3 K_sat 审计 / 定理 N M2 三处同源结论）⇒ 简并不能被真正打破

  ⇒ 与既有结论的同源闭合：O-SCALE（尺度秩=1 须外部锚定）+ D3（K_sat=1/l_P² 手写锚定）
    + 定理 N M2（尺度生成缺第一性）三处，与本模块指向同一结构性边界。
