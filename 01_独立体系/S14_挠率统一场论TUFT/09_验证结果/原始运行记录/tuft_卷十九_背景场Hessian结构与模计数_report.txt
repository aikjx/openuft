  理由：Hessian 的系数必须来自二阶变分 + York 分解 + 规范固定 + 鬼场的显式迹计算，
  任何'凭记忆写出'的系数都会把引用值伪装成推导值（卷十八 V18-H1 已立此纪律）。
  因此本卷【不给出】NGFP 数值 (g_*, lambda_*)。
  [OPEN    ] V19-H1: 未做背景场 Hessian 的二阶变分 ⇒ 系数组 (c_i, d_i) 与阈值宗量系数 a 未定 ⇒ 本卷不给出 GR 扇区 NGFP 数值 (g_*, lambda_*)，列为卷二十第 1 项

【本卷做】在不依赖系数的层面上，EH 截断流方程的通用结构。
  假设 A1（EH 截断 + 一圈精确结构，本卷显式声明而非默认）：
    beta_g = (d-2) g + g^2 * G(lam)          —— 量子部分正比于 g^2
    beta_l = -2 lam + g    * L(lam)          —— 量子部分正比于 g
    G, L 为阈值函数的有理组合，宗量 u = 1 + a*lam，极点在 u = 0。
  （g^{d-2} 结构来自 Hessian 正比 1/G；见卷十八定理 1 的正则项部分。）
  [BOUNDARY] V19-A1: 假设 A1：EH 截断下 beta 的量子部分分别为 O(g^2) 与 O(g)，lambda 依赖全部进入阈值函数；该假设是'截断'的定义，不是推导结论，超出的算符（R^2 等）会破坏它

 步骤 3  EH 截断流方程的【系数无关】结构定理
==============================================================================
设（假设 A1，d = 4）：
    beta_g = 2 g + g^2 * G(lam)
    beta_l = -2 lam + g * L(lam)
    G(lam) = c1/u + c2/u^2 ,  L(lam) = d0 + d1/u + d2/u^2 ,  u = 1 + a*lam
  （阈值函数有理结构来自卷十八 V18-P1：Phi ~ 1/(Gamma(n+1) u^p)，p <= 2。）

定理推导（纯代数，不含任何系数）：
  T19-2  g != 0 的不动点： 2 g + g^2 G = 0  =>  G(lam_*) = -2/g_*   （耦合求和规则）
  T19-3  代入 beta_l = 0： lam_* = g_* L(lam_*)/2 = -L(lam_*)/G(lam_*)
  T19-7  消去 g_*：      lam_* G(lam_*) + L(lam_*) = 0  —— NGFP 归约为【一维求根】
  T19-4  稳定性矩阵 (g,g) 元： B_gg = 2 + 2 g G(lam) ；在 NGFP 上代 G = -2/g
         => B_gg = 2 - 4 = -2  【精确、系数无关】
  T19-1  高斯不动点 (0,0)： B = [[2, 0], [L(0), -2]] （下三角）
         => 本征值恰为 {+2, -2}  【精确、系数无关】
  T19-5  定义域：阈值在 u = 0 有极点 => 物理域为 u > 0 => a*lam_* > -1
         （标准 a = -2 即 w = -2 lam 时： lam_* < 1/2）
  T19-6  符号判据： g_* > 0  <=>  G(lam_*) < 0（牛顿耦合为正的充要条件）

机器核对方案：随机取 (c1,c2,d0,d1,d2)，求出全部不动点，逐点验算 T19-1..T19-7。
  检查不动点数 = 45 ；高斯点检查 60 次
  [PASS    ] V19-T1: 高斯不动点稳定性矩阵下三角，本征值恰为 {+2, -2}（60 组随机系数，最大偏差 0）⇒ 高斯点恰有 1 个 UV 吸引方向（对应 lam），与'G 在 d>2 为无关耦合、Lambda 为相关耦合'一致；同时修正卷十七 V17-G2（草稿无正则项时全零）
  [PASS    ] V19-T2: 耦合求和规则 G(lam_*) = -2/g_*（最大偏差 2.22e-16） ⇒ g_* 由量子系数在 lam_* 处的取值直接给出（卷十八 V18-R3 的一般化）
  [PASS    ] V19-T3: lam_* = g_* L(lam_*)/2 = -L(lam_*)/G(lam_*)（最大偏差 1.24e-14）
  [PASS    ] V19-T4: NGFP 处稳定性矩阵 (g,g) 元恰为 -2（最大偏差 1.96e-11） ⇒ B_gg 在 高斯点(+2) 与 NGFP(-2) 之间插值，与系数、规范、截断无关
  [PASS    ] V19-T7: NGFP 的 lam_* 由一维方程 lam*G(lam) + L(lam) = 0 决定，g_* 随后由 T19-2 给出（最大偏差 1.82e-12）⇒ 二维不动点问题归约为一维求根
  [PASS    ] V19-T5: 阈值极点在 lam = 1/2（标准 a = -2）⇒ 物理域 lam < 1/2；本卷只在域内取根（越界计数 0） ⇒ 任何被使用的 NGFP 必须满足 lam_* < 1/2，系数无关的硬界
