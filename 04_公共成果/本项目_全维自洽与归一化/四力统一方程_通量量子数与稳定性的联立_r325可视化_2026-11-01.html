攻靶：r319 判定册 §十二 交接的 X-R319-1 —— q = 3 由什么选定？

定理 A（量子化格不是 Z）　CPn 是 spin 当且仅当 n 奇；非自旋圈上 [F] ∈ H²(Z) + c₁/2，故 CP² 的通量格是 Z + 1/2 —— 整数在那里根本不是合法通量。
定理 B（唯一性撤回）　在正确格上 nR = 3 的解不止一个：CP¹ + q=3 与 CP² + q=±5/2（25/8 − 1/8 = 3，Fraction 精确）⇒ r319 的「CP¹ 是唯一真空」判负撤回。
定理 C（稳定性零约束）　slope / DUY / HYM / D 项 / tadpole / 模稳定化，对 rank-1 线丛的 q 给出的独立约束数 = 0。最狠的一条：CP¹ 实维 2，F∧F ≡ 0 ⇒ tadpole 在给出三代的几何上信息量恰好为零。
定理 D（恒等映射）　CP¹ 上 nR(q) = q 是恒等式 ⇒ 「q=3」与「三代」是同一句话的两种写法 ⇒ 该路线结构性无法回答。
定理 E（问题倒置）　真问题不是「什么选 q」，而是「nR=3 的解集有多大、按什么排序」。

图 1 · 格不是 Z：spin 性决定移位

c₁(CPn) = (n+1)H，w₂ = c₁ mod 2 ⇒ CPn 是 spin 当且仅当 n 奇。蓝 = 整数格 Z；红 = 半整数格 Z + 1/2。r319 只看了 n=1 这一行（两张格在这里重合），于是看不出格的差别。

图 2 · 为什么 CP² 的整数点上找不到 3，而半整数点上有

绿线 = CP¹ 的 nR = q（恒等映射，任何 N 都能取到 ⇒ 判别力为 0）。蓝线 = CP² 的 nR = q²/2 − 1/8。红虚线 = nR = 3。整数竖线（灰）与蓝线的交点没有一个是 3；半整数竖线 q = ±5/2（橙）与蓝线交于 恰好的 3。
这一步不是「发现新解」，而是「发现上一卷的格选窄了」。 CP² 不是 spin（c₁ = 3H 为奇），其 D-brane 必须带 spinc 结构， 规范通量满足 [F] ∈ H²(Z) + c₁/2 —— 于是 q 只能是半整数。 在 q ∈ Z 上扫，当然扫不到 5/2。

图 3 · 解集的两张格对照：左 = r319 用的格，右 = 物理上正确的格

每格是真算出的 nR(n, q)（Â 的 H 幂次恒偶 ⇒ 6 阶截断对 n ≤ 7 精确）。绿 = 恰好等于 3；灰 = 该 q 不在这张格上（右图专有）；白 = 算了但不是 3。左图只有 1 个绿格；右图有 3 个。n ≥ 3 两张图都全白 —— 只有 n = 1, 2 有解，这一条本卷只报不解释（X-R325-1）。
撤回的精确范围：r319 定理 AB 里「CP² 上整数 q 无解」仍然成立（本卷 A08 复现）； 「只有 CP¹ 有整数解」在 q ∈ Z 前提下仍然成立； 被撤回的只是最后那一句「CP¹ 是唯一真空」。 理由不是算错，是格选窄了。凡报「唯一性」，必须报它是在哪张格上唯一。
