# 派生核算 VIII：不可计算性、码不变性与可证伪阈值
> 前七册把判别式从「维数」换成「比特」，但留下两个条件命题：
> O-17（裕度与码同阶）、O-18（天花板由位数决定）。本册把它们量化。

## 1. 定理 Ξ_alg：ν 不可计算，但「ν > c」可机器验证
| 结论 | 内容 |
|---|---|
| Ξ-1 | ν_eff = K_L(ξ) 是 Kolmogorov 复杂度 ⇒ **不可计算**（Berry 悖论） |
| Ξ-2 | 但「K_L(ξ) > c」是**半可判定的**：穷举长度 ≤ c 的表达式即可证明 |
| Ξ-3 | 最短非零 ν = **10.64 bit**，由穷举确立（非样本最小值） |
| Ξ-4 | Chaitin 界：可证 c ≤ K(F) + O(1)；实测 K(F) ≈ 2.87 Mbit ≫ 10.64 |
| Ξ-5 | **方向性修正**：VII 的 ν_eff 是上界，用于 Ω-2 时方向错误；补下界后结论成立 |

穷举结果（语言 L：p/q 与 N/10^d，码长 ≤ 14 bit，建表 162 个）：
| ξ | 穷举判定 | 连分数下界 ν ≥ |
|---|---|---|
| 1 | ξ ∈ G ⇒ **ν = 0**（单位制假象） | 0.00（G-artifact） |
| 1/(4*pi) | ξ ∈ G ⇒ **ν = 0**（单位制假象） | 0.00（G-artifact） |
| 2 | ξ ∈ G ⇒ **ν = 0**（单位制假象） | 0.00（G-artifact） |
| 3/2 | 命中 0.375 ⇒ ν = 10.64 | 10.64（convergent） |
| 5 | 命中 0.625 ⇒ ν = 10.64 | 10.64（convergent） |
| 137.035999084 | 未命中 ⇒ ν > 10.64 | 51.86（convergent） |
| 1.23456789012 | 未命中 ⇒ ν > 10.64 | 51.86（Q-bound(p,q>=636396)） |

**Ξ-5 的实质**：`Net = gain − K(n) − ν`，ν 越大 Net 越小。VII 取 ν̄ = min(已找到的表示) ≥ ν_true ⇒ Net_VII ≤ Net_true，故 **Net_VII < 0 不蕴含 Net_true < 0**。四条声明 ν̲ = ν̄ = 0 ⇒ ν_true = 0 ⇒ 结论不变，但论证此前有缺口。

## 2. 定理 Π_code：码不变性的显式常数（诊断 O-17）
| 码族 | K_min | ν_min | C | margin = ν_min − (C − K_min) |
|---|---|---|---|---|
| Elias-gamma | 8.64 | 10.64 | 8.15 | 11.14 |
| Elias-delta | 8.64 | 10.64 | 8.15 | 11.14 |
| Elias-omega | 8.64 | 10.64 | 8.15 | 11.14 |
| Fibonacci | 9.64 | 12.64 | 8.15 | 14.14 |
| Fixed-8 | 15.64 | 24.64 | 8.15 | 32.14 |
| Fixed-16 | 23.64 | 40.64 | 8.15 | 56.14 |
| Fixed-32 | 39.64 | 72.64 | 8.15 | 104.14 |
| Fixed-64 | 71.64 | 136.64 | 8.15 | 200.14 |
| Fixed-128 | 135.64 | 264.64 | 8.15 | 392.14 |

**二分律分裂**：「Net > 0 ⇒ 零内容」只依赖 ξ ∈ G 的成员资格 ⇒ **码无关** ✓；「有内容 ⇒ 净负」需要 ν_min > C − K_min，两端都随码变 ⇒ **码相关** ✗。

**O-17 不能闭合**：9 支码下 margin ∈ [11.14, 392.14] 全为正，且随码冗余度**单调增大**（结构性，非随机）⇒ 实用稳健；但最小 margin 11.14 bit **小于**不变性常数 c_ij 的保守估计（≥ 64 bit，差 5.7 倍）⇒ 严格意义下二分律不是码无关的定理。降级为「在 9 支码下实用稳健」。

## 3. 定理 Ρ_crit：可证伪阈值（O-18 → 定量预言）
| 声明 | K(n) | ν_min | Δ*（真偏差下限） | W*（临界位数） |
|---|---|---|---|---|
| alpha | 29.00 | 10.64 | 1.744e-22 | 23.2 |
| alpha_grav_e == (m_e/m_P)^2 | 29.00 | 10.64 | 2.558e-17 | 18.0 |
| m_mu/m_e | 16.14 | 10.64 | 1.931e-16 | 16.7 |
| m_p/m_e | 16.14 | 10.64 | 5.200e-19 | 19.3 |

> **二分律的物理形式**：任何声称「由锚推出靶、且带非单位制纯数因子」的关系，其**真相对偏差**必须 > Δ* = s_T / 2^(K(n)+ν_min)。

最紧的一条 Δ* = 1.744e-22；临界位数 W* = 16.7 位（当前 SI-2019 只记 6–12 位，差 5 位）。这不再是「提高位数即可证伪」的空话。

## 4. 定理 Σ_self：自指闭包
| 结论 | 内容 |
|---|---|
| Σ-1 | Net_bits 对判别式自身**无定义**（不预言数值 ⇒ s_T 无定义） |
| Σ-2 | **不可完备性定理**：ν 不可计算 ⇒ 无算法判定所有声明的「ν > 0」 |
| Σ-3 | 自指声明 S = 「Net(S) > 0」无解（定义域外，非悖论） |

**O-5 由「元结论免责」升级为定理（不可完备性）**。
