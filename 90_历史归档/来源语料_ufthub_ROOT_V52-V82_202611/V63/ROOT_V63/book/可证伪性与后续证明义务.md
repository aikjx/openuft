# ROOT V63｜证伪、理论完备性与独立数据核验路线

## 1. 选择可严格判真的问题

**主问题 A：** 是否存在从光速螺旋内部变量 `q` 独立产生低能无质量自旋 2 激发、普适引力耦合的作用量？

必须交付：`S_micro[q]`；其基本对称群及场内容；从 `q` 到 `g_{μν}` 的局部/有效映射；规范冗余的处理；无鬼态的色散关系；低能 Ward 恒等式；计算出正确 Einstein–Hilbert 系数。

**主问题 B：** 能否在没有使用 G 进行拟合的情况下计算 `G_pred`？

参数账本必须分别列出：理论先验固定值、独立测量值、拟合值及自由参数。只有由与 G 无关的观测/推导确定所有额外尺度、截止、耦合后，才可能获得预测。不能用 `ell_P(G_obs)` 标定尺度后再把所得 `G_pred` 宣称是发现。

**主问题 C：** 能否以相同独立公设推出强-弱-电磁规范结构与量子化/手征物质？

必须给出规范群（或涌现机制）、手征费米子表象、异常抵消和重整化/有效场论范围；计算真实的谱、耦合流动、质量关系，比较粒子数据、宇宙学、核子衰变和精度实验。

## 2. 可运行的中间数值检验

| 测试 | 可观测/比较量 | 对照 | 通过含义 |

| 旋转速度分解 | `v²` | `c²` | 特定参数化一致 |
| 圆柱波模 | `Ω²` | 解析色散 | 波动模型一致 |

## 3. 实际新物理数据的最低条件

1. 在读取测试数据之前冻结理论模型和自由参数（预注册/版本管理）。
2. 选用未用于构造或拟合参数的独立观测数据集；说明系统误差及协方差。
3. 用同条件 GR/SM 或至少 Newton/Maxwell 基准比较残差、置信区间和自由度惩罚。
4. 有一条被证伪时会明确放弃或修改理论的参数无关预测，不能所有残差都靠追加参数解释。
5. 对涉及宇宙学、GPS、黑洞、粒子加速器或强场引力的断言，必须对应真实公开数据版本、单位、误差模型与引用。

## 4. 推荐先执行的三道挑战

- **挑战 1（微观结构）**：给出一种不借用已知引力参数的螺旋场作用量，严格证明其低能谱中有健康的自旋 2 模态，并有普适的无质量长程耦合。
- **挑战 2（G 的独立求值）**：从该模型独立得到 `ell`, `N`, `ξ` 和必要反项及重整化条件，再推导 `G_pred`；若仍存在参数退化，明确作为不确定性而不是宣告完成。
- **挑战 3（非仅图示的四力）**：推导规范场、手征谱及相互作用，计算与现有理论有差别且可检验的量，并预先定义判错标准。

## 5. 结案规则

可将“代码包创建、测试与 ZIP”标为已完成；不得将“引力的完整微观本源已经证明”或“四力统一数学定理已经成立”标为完成。后两项没有当前可验证的严格证明，必须保持开放状态。
