## 15.1 问题的精确定位

项目记忆（V18 批评、V18.2 重构）已确立铁律：**必须放弃数值拟合公式（Lambert W、127、e⁻π²/² 等）的"推导"声称**。因此本卷不做"再凑一个算 137 的公式"，而是对以下科学问题做**形式化严格分析**：

> **三条公理 {光速 c, 量子 ℏ, 螺旋几何} 能否唯一确定 α = b/ρ = tanθ = 137.035999084⁻¹？**

这是"α 可否第一性原理推导"的精确化。

### 关键区分：角色 vs 数值

框架对 α 的唯一定义是**角色**：

$$\alpha = \frac{\tau}{\kappa} = \frac{b}{\rho} = \tan\theta$$

公理只声明 α 是螺距比 b/ρ；**b/ρ 是否、以及如何被固定为 1/137**，是本题的全部核心。

## 15.2 检验一：三条公理对 b/ρ 的约束力（UNDERDETERMINED）

逐条公理检验 b/ρ 是否出现在任何约束方程中：

| 公理 | 内容 | 对 b/ρ 的约束 | 判定 |
|:---|:---|:---|:---|
| I | \|v\| = c，ω√(ρ²+b²)=c | 仅约束 ωR=c，b/ρ 自由 | 不约束 |
| II | S=nℏ，E=ℏω | 仅标定 ω 尺度，b/ρ 自由 | 不约束 |
| III | κ=ρ/R²，τ=b/R² | 恒等式 κ²+τ²=1/R²，b/ρ 自由 | 不约束 |

**数值证明**：b/ρ = 10⁻⁶、1/137、1、10、10⁶ 全部合法满足三条公理（ωR=c、κ²+τ²=1/R² 均通过，[脚本 §一](verify_v2_alpha_firstprinciples.py)）：

| 1/137 | ✓ | ✓ | 是 |
| 1 | ✓ | ✓ | 是 |

> **⇒ b/ρ 不出现在任何公理方程中，是自由参数。1/137 只是无数合法值之一，公理从未选中它。**

## 15.3 检验二：框架内部张力（TENSION）

卷一极限态定义"静质量态：v_z=0，v_⊥=c → 纯旋转圆"。由 v_z = cb/R = 0：

$$b = 0 \quad\Rightarrow\quad \alpha = \frac{b}{\rho} = 0 \;\neq\; \frac{1}{137}$$

**若电子是"静质量螺旋"（v_z=0），则 b=0 ⇒ α=0，与实测 1/137 直接矛盾。**

框架须额外说明：电子的 α=b/ρ 究竟取自哪个**非静止**螺旋？此问题在当前公理下无解——b/ρ 无几何第一性来源。这是框架内部自洽性需要正视的张力。

## 15.4 检验三：引入 QED 重整化跑动能否消除欠定性？（候选①）

为了排除"引入合法物理机制即可导出"的可能，本卷检验了最正当的候选——标准 QED 单圈重整化群跑动：

$$\alpha(\mu) = \frac{\alpha(\mu_0)}{1 - \frac{\alpha(\mu_0)}{3\pi}\sum Q_f^2 \ln\frac{\mu}{\mu_0}}$$

### 结果（[脚本 §一](verify_v2_alpha_running.py)）

- RG 公式是标准物理、可复现：正确给出 α⁻¹(m_Z) ≈ 131.6（与实验 ≈128 同量级，差异来自简化质量阈值，不影响结论）。
- **但跑动是标度变换，不是绝对值推导**：

```
α(0) = 1/137.036（输入）  →  α(m_Z) ≈ 1/128（导出）
```

一个方程、两个变量（α(μ)、α(μ₀)），**必须给定一个实验边界值才能解出另一个**。跑动把 137 "搬"成 128，但 **137 这个绝对数值从未被推导**。

> **⇒ 引入最合法的物理机制后，欠定性依然存在。要推出 137，需知道 UV 边界 α(μ_UV) 的几何来源——这正是 15.2 证明欠定的位置。**

## 15.6 诚实结论与下一步

> **在当前 {c, ℏ, 螺旋} 公理体系内，α = 137.036 的数值不可由第一性原理推导。这是欠定性，而非可解的难题。强行造闭式 = 拟合（已被 V18.2 明确排除）。**
