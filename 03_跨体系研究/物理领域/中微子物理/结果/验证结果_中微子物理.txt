【NU1】中微子的发现与基本性质
----------------------------------------------------------------------
  中微子的发现历史：

  年份       事件                                  备注
  -------------------------------------------------------------------------------------
  1930     Pauli假设中微子存在                        为解释β衰变的能量守恒，提出'中子'(后改名中微子)
  1933     Fermiβ衰变理论                          建立弱相互作用理论，中微子正式进入理论
  1956     Cowan-Reines实验探测电子反中微子              首次直接探测中微子，1995年诺贝尔奖
  1962     Lederman/Schwartz/Steinberg发现μ中微子   证明存在不同味的中微子，1988年诺贝尔奖
  1968     Davis探测太阳中微子（Homestake）             发现太阳中微子缺失（太阳中微子问题），2002年诺贝尔奖
  1987     SN1987A中微子探测                        首次探测到超新星中微子，验证了超新星核心坍缩模型
  1998     超级神冈发现大气中微子振荡                       首次确凿证据中微子有质量，2015年诺贝尔奖
  2001     SNO实验解决太阳中微子问题                      证明太阳中微子振荡，2015年诺贝尔奖
  2000     DONUT实验发现τ中微子                       最后一个被发现的标准模型粒子
  2012     Daya Bay发现θ₁₃非零                     最后一个混合角被测量，开启轻子CP破坏研究

  中微子的基本性质：

  性质              值                              意义
  ---------------------------------------------------------------------------
  电荷              0                              电中性
  自旋              1/2                            费米子
  质量              <0.8 eV (Σmν)                  极轻，比电子轻~10^6倍
  相互作用            弱相互作用 + 引力                     不参与电磁/强相互作用
  手征性             左手中微子/右手反中微子                   弱作用V-A结构，宇称破坏
  味               3种 (ν_e, ν_μ, ν_τ)             对应三代轻子
  振荡              味之间振荡                          证明中微子有质量且混合
  速度              ≈c (SN1987A: |v-c|/c < 2×10^-9) 接近光速
  磁矩              <1.5×10^-10 μ_B                极小（标准模型预言~10^-19 μ_B）
  寿命              >10^12年（ν_μ→ν_eγ）              极稳定

  中微子的种类：

  标准模型中微子（左手）：
    ν_e  — 电子中微子，参与β衰变、太阳中微子
    ν_μ  — μ中微子，参与π衰变、大气中微子
    ν_τ  — τ中微子，2000年DONUT发现

  反中微子（右手）：
    ν̄_e — 电子反中微子，反应堆中微子
    ν̄_μ — μ反中微子
    ν̄_τ — τ反中微子

  假设的右手中微子（ν_R）：
    - 标准模型中不存在，但跷跷板机制需要
    - 质量可能很大（~10^14 GeV），是暗物质候选
    - 螺旋几何化: 右手中微子是螺旋的右手模式

【NU2】中微子振荡理论（Pontecorvo-Maki-Nakagawa-Sakata矩阵）
----------------------------------------------------------------------
  中微子振荡的基本原理：

  1. 味本征态 vs 质量本征态：
     味本征态 |ν_α> (α=e,μ,τ) 是质量本征态 |ν_i> (i=1,2,3) 的混合
     |ν_α> = Σ_i U_αi* |ν_i>
     其中 U 是PMNS矩阵（3×3幺正矩阵）

  2. 时间演化：
     质量本征态以不同频率演化
     |ν_i(t)> = exp(-i E_i t/ħ) |ν_i(0)>
     不同质量导致相位差，产生振荡

  3. 振荡概率：
     P(ν_α → ν_β) = |Σ_i U_αi* U_βi exp(-i m_i² L/(2E))|²
     其中 L 是传播距离，E 是中微子能量

  PMNS矩阵参数化：

  标准参数化（3个混合角 + 1个CP相位）：

  U = R₂₃(θ₂₃) · Γ(δ_CP) · R₁₃(θ₁₃) · Γ†(δ_CP) · R₁₂(θ₁₂)

  其中 R_ij(θ) 是ij平面的旋转矩阵，Γ(δ)=diag(1,1,e^{iδ})

  PMNS矩阵元素：

  |U_e1|² = c₁₂² c₁₃²
  |U_e2|² = s₁₂² c₁₃²
  |U_e3|² = s₁₃²
  |U_μ1|² = (s₁₂ s₂₃ - c₁₂ c₂₃ s₁₃ e^{iδ})²
  |U_μ2|² = (c₁₂ s₂₃ + s₁₂ c₂₃ s₁₃ e^{iδ})²
  |U_μ3|² = c₂₃² c₁₃²
  |U_τ1|² = (s₁₂ c₂₃ + c₁₂ s₂₃ s₁₃ e^{iδ})²
  |U_τ2|² = (c₁₂ c₂₃ - s₁₂ s₂₃ s₁₃ e^{iδ})²
  |U_τ3|² = s₂₃² c₁₃²

  其中 c_ij = cos θ_ij, s_ij = sin θ_ij

  实验测量值（NuFIT 5.1, 2024）：

  参数              值                                   来源
  ----------------------------------------------------------------------
  sin²θ₁₂         0.307 ± 0.013                       太阳+反应堆
  sin²θ₂₃         0.545 ± 0.023 (正常排序)                大气+加速器
  sin²θ₁₃         0.02219 ± 0.00075                   反应堆(Daya Bay等)
  δ_CP            1.24π ± 0.19π (正常排序)                T2K+NOvA
  Δm²₂₁           7.41 × 10⁻⁵ eV²                     太阳+反应堆
  Δm²₃₁           2.51 × 10⁻³ eV² (正常排序)              大气+加速器

  两味振荡概率计算：

  P(ν_μ → ν_e) = sin²(2θ) sin²(1.27 Δm² L/E)
  其中 Δm² [eV²], L [km], E [GeV]

  T2K实验 (L=295 km, E~0.6 GeV):
    θ₁₃ = 8.57°
    Δm²₃₁ = 2.51e-03 eV²
    振荡相位 = 1.27 × 2.51e-03 × 295 / 0.6 = 1.567
    P(ν_μ → ν_e) ≈ 0.0868 = 8.68%

  Daya Bay实验 (L=1.6 km, E~4.0 MeV):
    振荡相位 = 1.27 × 2.51e-03 × 1.6 / 0.0040 = 1.275
    P(ν̄_e → ν̄_e) 存活 = 1 - 0.0794 = 0.9206
    缺失比例 ≈ 7.94%

  螺旋几何化解释：

  1. 中微子振荡 = 螺旋模式的拍频
     - 不同质量本征态 = 不同频率的螺旋模式
     - 混合 = 螺旋模式的线性组合
     - 振荡 = 不同频率螺旋的拍频现象

  2. PMNS矩阵 = 螺旋基的变换矩阵
     - 味基 = 相互作用基（弱作用本征态）
     - 质量基 = 螺旋传播基（自由哈密顿量本征态）
     - PMNS矩阵 = 两个基之间的幺正变换

  3. 中微子质量 = 螺旋半径的倒数
     - m_i = ħ/(c R_i)（螺旋几何化质量公式）
     - 质量差 Δm²_ij = (ħ/c)²(1/R_i² - 1/R_j²)
     - 混合角 = 螺旋模式之间的重叠

【NU3】太阳中微子问题与解决方案
----------------------------------------------------------------------
  太阳中微子问题：

  1. 理论预言（标准太阳模型 SSM）：
     太阳核心的核聚变反应产生电子中微子
     主要反应链：pp链（98%）和CNO循环（2%）

  太阳中微子源：

  反应                             能量                 通量                        占比
  ------------------------------------------------------------------------------------------
  pp → d + e⁺ + ν_e              0-0.42 MeV         6.0×10^10 cm⁻²s⁻¹         ~91%
  ⁷Be + e⁻ → ⁷Li + ν_e           0.862 MeV (90%)    4.8×10^9 cm⁻²s⁻¹          ~7%
  ⁸B → ⁸Be* + e⁺ + ν_e           0-15 MeV           5.5×10^6 cm⁻²s⁻¹          ~0.01%
  pep + p → d + e⁺ + ν_e         1.44 MeV           1.4×10^8 cm⁻²s⁻¹          ~0.2%
  hep → ⁴He + e⁺ + ν_e           0-18.8 MeV         8×10^3 cm⁻²s⁻¹            ~10^-5%
  CNO循环 (¹³N, ¹⁵O, ¹⁷F)          0-1.7 MeV          ~5×10^8 cm⁻²s⁻¹           ~1%

  2. 实验探测历史：

  实验                   年份           靶               能量阈值         观测/预言
  ---------------------------------------------------------------------------
  Homestake (Davis)    1968-1994    Cl (615吨)       >0.814 MeV   0.30
  Kamiokande           1987-1995    水 (3000吨)       >7 MeV       0.51
  Super-Kamiokande     1996-2020    水 (50000吨)      >3.5 MeV     0.45
  GALLEX/GNO           1991-2003    Ga (30吨)        >0.233 MeV   0.52
  SAGE                 1990-2009    Ga (50吨)        >0.233 MeV   0.51
  SNO                  1999-2006    重水 (1000吨)      >5 MeV       CC:0.34, NC:1.0
  Borexino             2007-2021    液体闪烁体 (300吨)    >0.15 MeV    各成分不同

  3. SNO实验的关键结果（2001-2002）：

  SNO使用重水，可以同时测量：
    - 带电流(CC): ν_e + d → p + p + e⁻  (只对ν_e敏感)
    - 中性流(NC): ν_x + d → p + n + ν_x  (对所有味敏感)
    - 弹性散射(ES): ν_x + e⁻ → ν_x + e⁻  (对所有味敏感，但ν_e截面大6倍)

  结果：
    CC通量 = 1.76 × 10^6 cm⁻²s⁻¹ (只有ν_e)
    NC通量 = 5.09 × 10^6 cm⁻²s⁻¹ (所有味总和)
    NC/CC ≈ 2.9 → 证明太阳中微子从ν_e振荡到了ν_μ/ν_τ
    总通量与标准太阳模型预言一致！

  这解决了持续30年的太阳中微子问题
  2015年诺贝尔物理学奖（McDonald和Kajita）

  4. Mikheyev-Smirnov-Wolfenstein (MSW) 效应：

  太阳中微子振荡不是真空振荡，而是物质增强振荡（MSW效应）

  原理：
    - 中微子在太阳物质中传播时，ν_e与电子有带电流相互作用
    - 这给ν_e一个有效势 V = √2 G_F n_e
    - 改变了有效质量平方差和混合角
    - 在特定密度处发生共振（MSW共振）
    - 高能⁸B中微子主要通过MSW效应转换（绝热转换）
    - 低能pp中微子主要是真空振荡

  LMA-MSW解（大混合角解）：
    Δm²₂₁ ~ 7×10⁻⁵ eV², tan²θ₁₂ ~ 0.45
    这是被所有实验确认的解

  螺旋几何化解释：

  1. 太阳中微子振荡 = 螺旋模式在物质中的演化
     - ν_e在太阳核心产生，是螺旋的味本征态
     - 在太阳物质中传播时，物质势改变了螺旋的有效频率
     - MSW共振 = 螺旋模式的能级交叉
     - 到达地球时，已经振荡成ν_μ/ν_τ

  2. 物质势的几何化
     - 电子密度n_e改变了时空的螺旋背景
     - ν_e与电子的带电流相互作用 = 螺旋模式的耦合
     - 有效势V = √2 G_F n_e = 螺旋背景的频率移动

【NU4】大气中微子振荡与超级神冈实验
----------------------------------------------------------------------
  大气中微子的产生：

  1. 初级宇宙线（质子、原子核）撞击地球大气
  2. 产生π介子和K介子
  3. π/K衰变产生中微子：
     π⁺ → μ⁺ + ν_μ
     μ⁺ → e⁺ + ν̄_μ + ν_e
  4. 因此大气中微子包含ν_μ, ν̄_μ, ν_e, ν̄_e
  5. 预期比例: (ν_μ+ν̄_μ)/(ν_e+ν̄_e) ≈ 2

  大气中微子的能谱和方向：

  - 能量: ~100 MeV - 100 GeV
  - 通量: 随能量下降，E^-2.7
  - 方向: 各向同性（初级宇宙线近似各向同性）
  - 天顶角依赖: 下行中微子传播~10km，上行中微子传播~13000km

  超级神冈实验（Super-Kamiokande）：

  参数              值
  ------------------------------------------------------------
  位置              日本岐阜县神冈矿山，地下1000m
  探测器             50000吨超纯水，圆柱形
  光电倍增管           11146个20英寸PMT（内探测器）
  运行时间            1996年至今（SK-I到SK-V）
  能量阈值            ~100 MeV（中微子）
  主要目标            大气中微子、太阳中微子、超新星中微子、质子衰变

  1998年重大发现：大气中微子振荡

  关键观测：
    1. μ中微子事件的天顶角分布异常
       - 下行μ中微子（短距离）: 数量正常
       - 上行μ中微子（长距离，穿过地球）: 数量减少~50%
    2. e中微子事件的天顶角分布正常
    3. 能量依赖: 高能中微子振荡更明显（L/E更大）

  解释：ν_μ → ν_τ振荡

  振荡参数（最佳拟合）：
    Δm²₂₃ ≈ 2.5×10⁻³ eV²
    sin²θ₂₃ ≈ 0.5（近最大混合）

  这是人类首次确凿证据中微子有质量
  2015年诺贝尔物理学奖（Kajita和McDonald）

  其他大气中微子实验：

  实验                   年份              结果
  ----------------------------------------------------------------------
  IMB                  1982-1991       首次观测到μ/e比值异常
  Kamiokande           1988-1995       确认μ/e比值异常，天顶角依赖
  Super-Kamiokande     1996-           确凿证据ν_μ→ν_τ振荡，精确测量参数
  Soudan-2             1989-2005       确认大气中微子振荡
  MACRO                1989-2000       确认上行μ中微子缺失
  MINOS                2005-2012       加速器中微子确认大气振荡参数
  IceCube              2010-           高能大气中微子振荡，τ中微子出现
  ANTARES/KM3NeT       2008-           地中海中微子望远镜，大气中微子

  螺旋几何化解释：

  1. 大气中微子振荡 = 螺旋模式的长距离演化
     - 上行中微子穿过地球，传播距离~13000km
     - L/E足够大，螺旋模式的相位差累积到π
     - ν_μ螺旋模式振荡到ν_τ模式

  2. 近最大混合θ₂₃~45°
     - ν_μ和ν_τ的螺旋模式几乎对称
     - 混合角接近45°，振荡幅度最大
     - 这是PMNS矩阵与CKM矩阵的重要区别
     - CKM矩阵小混合，PMNS矩阵大混合

  3. 地球物质效应
     - 上行中微子穿过地球时，物质势影响振荡
     - ν_e的物质势较大，ν_μ/ν_τ的物质势较小
     - 这可以用来区分质量排序（正常vs反常）

【NU5】反应堆中微子振荡（Daya Bay、RENO、Double Chooz）
----------------------------------------------------------------------
  反应堆中微子：

  1. 产生机制：
     核反应堆中，铀/钚裂变产生的富中子碎片发生β衰变
     产生电子反中微子 ν̄_e
     每个裂变产生~6个ν̄_e

  2. 能谱：
     - 连续谱，能量~1-8 MeV
     - 平均能量~3-4 MeV
     - 总通量: ~10^20 ν̄_e/s/GW

  3. 探测方法（逆β衰变 IBD）：
     ν̄_e + p → e⁺ + n
     - 正电子湮没产生快信号（511keV×2）
     - 中子被俘获产生慢信号（~2.2MeV，延迟~100μs）
     - 符合探测可以有效排除本底

  θ₁₃的测量：

  反应堆中微子实验是测量θ₁₃的最佳方法
  因为：
    - 纯ν̄_e束流
    - 已知能谱和通量
    - 多个探测器在不同距离（近点+远点）
    - 可以精确测量ν̄_e的存活概率

  振荡概率（近似）：
  P(ν̄_e → ν̄_e) ≈ 1 - sin²2θ₁₃ sin²(Δm²₃₁ L/(4E))
  （忽略Δm²₂₁的影响，因为L较短）

  主要实验：

  【Daya Bay】
    位置: 中国广东大亚湾
    反应堆: 6个反应堆，总功率~17.4GW
    探测器: 8个探测器（2近+4远+2补充），每个20吨液体闪烁体
    基线: 近点~500m, 远点~1.5-2.0km
    结果: sin²2θ₁₃ = 0.0841 ± 0.0037
    显著性: 5.2σ (2012年首次发现)
    状态: 2011-2020运行，已完成

  【RENO】
    位置: 韩国灵光
    反应堆: 6个反应堆，总功率~16.4GW
    探测器: 2个探测器（1近+1远），每个16吨液体闪烁体
    基线: 近点~400m, 远点~1.5km
    结果: sin²2θ₁₃ = 0.089 ± 0.006
    显著性: 4.9σ (2012年)
    状态: 2011-运行中

  【Double Chooz】
    位置: 法国绍兹
    反应堆: 2个反应堆，总功率~8.4GW
    探测器: 2个探测器（1近+1远），每个8吨液体闪烁体
    基线: 近点~400m, 远点~1.05km
    结果: sin²2θ₁₃ = 0.090 ± 0.014
    显著性: 3.1σ
    状态: 2010-2017运行，已完成

  综合结果（NuFIT 5.1）：
    sin²θ₁₃ = 0.02219 ± 0.00075
    sin²2θ₁₃ = 0.0868 ± 0.0029
    θ₁₃ ≈ 8.5°

  θ₁₃非零的重要意义：

  1. 可以测量轻子CP破坏（δ_CP）
     - CP破坏需要所有三个混合角非零
     - θ₁₃非零使得T2K/NOvA等加速器实验可以测量δ_CP

  2. 可以区分质量排序（正常vs反常）
     - 物质效应依赖于质量排序
     - θ₁₃越大，物质效应越明显

  3. 轻子味不对称（leptogenesis）
     - 宇宙中物质-反物质不对称可能来自轻子 sector
     - 需要CP破坏和右手中微子

  螺旋几何化解释：

  1. 反应堆中微子振荡 = 螺旋模式的短基线演化
     - ν̄_e在反应堆核心产生，是螺旋的味本征态
     - 传播~1-2km后，部分振荡到ν̄_μ/ν̄_τ
     - 远点探测器观测到ν̄_e缺失

  2. θ₁₃小但非零
     - ν_e与ν₃的螺旋模式重叠较小
     - 但非零，使得CP破坏可观测
     - 这与CKM矩阵的θ₁₃(Cabibbo角~13°)类似但更小

【NU6】加速器中微子振荡（T2K、NOvA、MINOS）
----------------------------------------------------------------------
  加速器中微子束流：

  1. 产生机制：
     - 高能质子打靶产生π/K介子
     - 磁喇叭聚焦π/K
     - π/K衰变产生中微子束流
     π⁺ → μ⁺ + ν_μ (主要)
     K⁺ → μ⁺ + ν_μ

  2. 束流成分：
     - 主要是ν_μ（>90%）
     - 少量ν_e（~1%，来自K和μ衰变）
     - 可以通过反向磁场产生ν̄_μ束流

  3. 能量：
     - 离轴束流（T2K/NOvA）: ~0.5-3 GeV
     - 宽频带束流（MINOS）: ~1-10 GeV

  主要实验：

  【T2K】

【NU7】中微子质量排序与轻子CP破坏
----------------------------------------------------------------------
  中微子质量排序：

  两种可能的排序：

  正常排序 (Normal Ordering, NO):
    m₁ < m₂ < m₃
    Δm²₃₁ > 0
    m₃最重
    与太阳振荡(Δm²₂₁)和大气振荡(Δm²₃₁)一致

  反常排序 (Inverted Ordering, IO):
    m₃ < m₁ < m₂
    Δm²₃₁ < 0
    m₃最轻
    m₁和m₂接近简并

  质量谱示意：

  正常排序:          反常排序:
    m₃  ────────      m₂  ────────
                      m₁  ────────
    m₂  ──            m₃  ──
    m₁  ──

  其中 m₂-m₁ ~ √(Δm²₂₁) ~ 0.009 eV
       m₃-m₁,₂ ~ √(|Δm²₃₁|) ~ 0.05 eV

  质量排序的实验测量：

  ------------------------------------------------------------------------------------------

  反应堆中微子谱畸变                 远点探测器能谱的快速振荡依赖于质量排序                           JUNO, RENO-50
  中微子双β衰变                   0νββ衰变率依赖于有效Majorana质量，对排序敏感                  GERDA, CUORE, EXO, nEXO

    P(ν_μ→ν_e) ≠ P(ν̄_μ→ν̄_e)

  需要下一代实验确认

  CP破坏的重要意义：

  1. 轻子味不对称（Leptogenesis）：

     - 轻子CP破坏可能比夸克CP破坏更强

     - 正常排序: m₁<m₂<m₃，螺旋半径R₁>R₂>R₃

【NU8】跷跷板机制与右手中微子（螺旋几何化）
----------------------------------------------------------------------
  中微子质量的起源问题：

  标准模型中：
    - 只有左手费米子参与弱相互作用
    - 中微子只有左手分量ν_L
    - 没有右手中微子ν_R
    - 标准模型预言中微子质量为零

  但实验证明中微子有质量（振荡）
  因此需要扩展标准模型

  跷跷板机制（Seesaw Mechanism）：

  1. 基本思想：
     - 引入右手中微子ν_R（标准模型单态）
     - ν_R可以有Majorana质量M_R（很大，~10^14 GeV）
     - ν_L和ν_R通过Yukawa耦合y_ν混合
     - 狄拉克质量m_D = y_ν v ~ 100 GeV（与其他费米子同量级）

  2. 质量矩阵：
     M_ν = [[0, m_D],
            [m_D, M_R]]
     其中左上为0（ν_L没有Majorana质量）

  3. 对角化（M_R >> m_D时）：
     轻质量本征态: m_ν ≈ -m_D²/M_R
     重质量本征态: m_N ≈ M_R

  4. 跷跷板效应：
     M_R越大，m_ν越小（跷跷板）
     如果M_R ~ 10^14 GeV，m_D ~ 100 GeV
     则m_ν ~ (100 GeV)²/10^14 GeV ~ 0.1 eV
     与实验测得的中微子质量~0.05 eV量级一致！

  数值计算：
    m_D = 100 GeV
    M_R = 1e+14 GeV
    m_ν = m_D²/M_R = 0.100 eV
    实验: √Δm²₃₁ ~ 0.050 eV
    ✅ 量级一致！

  右手中微子的性质：

  性质              值                         备注
  ------------------------------------------------------------
  电荷              0                         电中性
  自旋              1/2                       费米子
  质量              ~10^9-10^15 GeV           很重（跷跷板）
  弱作用             不参与                       标准模型单态

  轻子味不对称（Leptogenesis）：

  1. 基本思想（Fukugita-Yanagida 1986）：
     - 宇宙早期，重右手中微子N_i非平衡衰变
     - N_i → l + H 或 N_i → l̄ + H†
     - CP破坏导致两种衰变率不同
     - 产生轻子数不对称 L
     - 通过sphaleron过程，部分转化为重子数不对称 B
     - B = -(8/23) L ~ -0.35 L

  2. 成功条件：
     - 右手中微子质量 M_N > 10^9 GeV（热leptogenesis）
     - CP破坏相位非零
     - 非平衡衰变（偏离热平衡）

  3. 与观测的一致性：
     - 可以解释观测到的重子不对称 η_B ~ 6×10^-10
     - 是目前最成功的重子生成机制之一

  螺旋几何化解释：

  1. 右手中微子 = 螺旋的右手模式
     - 标准模型中只有左手螺旋参与弱作用
     - 右手中微子是螺旋的右手模式，不参与弱作用
     - 这解释了为什么右手中微子是标准模型单态

  2. 跷跷板机制的几何化
     - m_D = 左手和右手螺旋的耦合
     - M_R = 右手螺旋的自耦合（Majorana质量）
     - m_ν = m_D²/M_R = 左手螺旋的有效质量
     - 跷跷板 = 左右手螺旋的质量反比关系

  3. 轻子味不对称的几何化
     - 重右手中微子 = 重螺旋模式
     - 衰变 = 重螺旋模式衰变为轻螺旋模式
     - CP破坏 = 螺旋的手征不对称
     - 轻子不对称 = 螺旋模式的数量不对称
     - 这是螺旋几何化对宇宙物质-反物质不对称的解释

  实验检验：

  1. 中微子双β衰变（0νββ）：
     - 如果中微子是Majorana粒子，则0νββ衰变可以发生

  2. 轻子味破坏（LFV）：
     - 跷跷板机制预言μ→eγ等轻子味破坏过程
     - 当前上限: BR(μ→eγ) < 4.2×10^-13（MEG）
     - 下一代实验: MEG II, Mu2e, COMET

  3. 对撞机探测：
     - Type II/III跷跷板的重粒子可能在LHC探测
     - 目前未发现，质量下限~几百GeV
