# ROOT V65 真实计算、交叉验证与验收报告

**本报告记录实际执行结果；不是物理新发现的报告。**

## 一、执行环境与结果

- `python -m unittest discover -s tests -v`：**65/65 通过**，包括历史候选常数和 ISCO 纠错回归、新几何反演、Lorentz 间隔、KG 群速度、热核 F、场方向、地球 toy 与 Eötvös 模型、旧模型绕数输入错误回归检查。
- `cd legacy_v64 && python -m unittest discover -s tests -v`：**63/63 通过**。该目录为旧版代码及必要的 n=1 参数验证 backport；每一项通过不意味着验证真实物理。
- `python experiments/generate.py`：已生成 5 组 CSV、5 个 matplotlib PNG 图和 JSON 摘要。它们全部是基于给定公式的 MATH/TOY/FIT 数据。
- `python experiments/browser_smoke.py`：当前环境中的 Chromium 页面脚本与控件检查通过，未报告 JS 运行时异常。**环境阻止本地 HTTP 导航，因此以 set_content 加载 HTML 测试（不是本地端到端站点导航）。** 独立 GPU / WebGL2 验证仍不在此范围。

## 二、定量参考

`results/v65_numerical_summary.json` 提供机器可读计算原始值。主要数字：

- CODATA 2022 推荐 G 输入：`6.67430e−11 m³ kg⁻¹ s⁻²`，标准不确定度 `1.5e−15` SI。
- 利用该 G 计算的普朗克长度：`1.6162550244237053e−35 m`。**不是 G 的独立预测**。
- 最简 N=1, ξ=0、无裸项、质量可忽略的反向截止拟合：`2.6323542160304588e−36 m`。**FIT**。
- 球形地球合成重力：`9.820302293385645 m/s²`；未纳入自转、椭球形状、EGM/真实地磁。
- MICROSCOPE 中心 η=-1.5e−15（真实论文输入）。示意合成 95% 区间 `[-6.881975845356424e−15, 3.881975845356424e−15]`；这不是论文给出的正式 95% 区间。
- V65 质量截止函数与 SciPy `exp1` 在扫描区间的最大绝对误差：约 `3.4976732746e−13`。SciPy 是仅用于交叉核验的可选包。

## 三、未完成及不可宣告事项

1. 未证明 ROOT 内部运动与实验中粒子内部动力学一一对应；无直接新物理观测。
2. 未从不包含 G 的独立微观输入决定 G；已有参数辨识定理说明单个 G 测量不足以推定谱与尺度。
3. 未由单一微观动力学产生标准模型手征、颜色荷和全部规范/粒子谱。
4. 未完成新理论的 ghost/异常/UV 等严密验证，也未提出经独立实验确认的区别性预测。
5. 未核验原生 GPU WebGL2 代码在所有系统上表现一致。
