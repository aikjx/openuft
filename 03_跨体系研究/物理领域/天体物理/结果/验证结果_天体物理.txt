【AP1】恒星物理
----------------------------------------------------------------------

  天体物理概述：

  天体物理学是应用物理学的原理和方法研究天体（恒星、星系、宇宙）的学科。
  它是物理学与天文学的交汇，研究宇宙中物质的物理性质和行为。

  天体物理的主要分支：
    - 恒星物理：恒星结构和演化
    - 太阳物理：太阳的结构和活动
    - 致密天体：白矮星、中子星、黑洞
    - 星际介质：恒星间的气体和尘埃
    - 星系物理：星系的形成和演化
    - 宇宙学：宇宙的起源和演化
    - 高能天体物理：X射线、γ射线天体

  恒星基本参数：

  太阳参数：
    质量 M☉ = 1.989×10³⁰ kg
    半径 R☉ = 6.957×10⁸ m
    光度 L☉ = 3.828×10²⁶ W
    表面温度 T☉ = 5772 K
    年龄：46亿年

  恒星分类（OBAFGKM）：
    O：蓝巨星（>30000K）
    B：蓝白（10000-30000K）
    A：白（7500-10000K）
    F：黄白（6000-7500K）
    G：黄（5200-6000K，太阳）
    K：橙（3700-5200K）
    M：红（<3700K）
    记忆：Oh Be A Fine Girl/Guy Kiss Me

  恒星结构方程：

  四个基本方程（球对称稳态）：
    1. 流体静力学平衡：dP/dr = -Gm(r)ρ/r²
    2. 质量守恒：dm/dr = 4πr²ρ
    3. 能量产生：dL/dr = 4πr²ρε
    4. 能量输运：dT/dr = -3κρL/(64πσr²T³)

  恒星类型：
    主序星：氢燃烧（~90%恒星）
    红巨星：壳层氢燃烧
    白矮星：简并物质（碳氧核）
    中子星：中子简并压

  太阳核心压强估算：
    P_c ≈ GM²/(8πR⁴) = 0.4×10¹⁴ Pa
    标准太阳模型：~2.5×10¹⁶ Pa

  恒星核聚变：

  pp链（太阳主能量）：
    p + p → d + e⁺ + ν (5.5×10⁹年)
    d + p → ³He + γ
    ³He + ³He → ⁴He + 2p
    总：4p → ⁴He + 2e⁺ + 2ν + 26.7 MeV

  CNO循环（大质量恒星）：
    C,N,O作为催化剂
    4p → ⁴He + 2e⁺ + 2ν + 25.0 MeV
    T > 1.7×10⁷K时主导

  核聚变能量：
    ΔE = Δm·c²（质量亏损）
    4个质子质量：4.03255u
    α粒子质量：4.00260u
    质量亏损：0.02995u = 26.7 MeV

  太阳核聚变计算：
    每次反应释放 E = 4.278e-12 J
    每秒反应数 = 8.95e+37
    每秒消耗质子质量 = 5.99e+11 kg
    每年消耗 = 1.89e+19 kg（~4.3×10⁹ kg）

  螺旋几何化解释：

  1. 恒星物理的螺旋几何化
     - 恒星 = 螺旋自转的聚变反应堆
     - 自转 = 恒星的螺旋运动
     - 对流 = 恒星内部的螺旋热循环
     - 磁场 = 恒星螺旋电流的磁场

  2. 恒星结构的螺旋解释
     - 平衡 = 螺旋重力与压强平衡
     - 能量输运 = 螺旋光子的扩散
     - 核聚变 = 螺旋质子隧穿的融合
     - 光度 = 螺旋能量的辐射

  3. 与三重奏的联系
     - 恒星振动 = 螺旋声学振荡（日震学）
     - 自转频率 = 螺旋角频率
     - 磁场结构 = 螺旋电流回路

【AP2】恒星演化
----------------------------------------------------------------------

  恒星演化：

  恒星的一生取决于初始质量：

  低质量恒星（<0.5 M☉）：
    主序（氢燃烧，~10¹¹年）→ 红巨星 → 氦闪
    → 行星状星云 → 白矮星

  中等质量恒星（0.5-8 M☉）：
    主序（~10¹⁰年）→ 红巨星 → 氦燃烧
    → AGB星（渐近巨星分支）→ 行星状星云
    → 白矮星（碳氧）

  大质量恒星（>8 M☉）：
    主序（~10⁷年）→ 红超巨星 → 多阶段核燃烧
    → 铁核坍缩 → 超新星II型 → 中子星/黑洞

  主序寿命：

  τ_main ≈ 10¹⁰年 × (M/M☉)^(-2.5)
    太阳：~10¹⁰年
    10 M☉：~3×10⁷年
    0.5 M☉：~5×10¹⁰年

  主序寿命计算：
    10 M☉恒星：τ = 10¹⁰ × 10^(-2.5) = 3.16e+07 年

  恒星终点：

  白矮星：
    质量：<1.4 M☉（Chandrasekhar极限）
    半径：~地球（~10⁴ km）
    密度：~10⁶ g/cm³
    支撑：电子简并压

  中子星：
    质量：1.4-3 M☉
    半径：~10 km
    密度：~10¹⁵ g/cm³（核密度）
    支撑：中子简并压+强核力

  黑洞：
    质量：>3 M☉（Tolman-Oppenheimer-Volkoff极限）
    事件视界：r_s = 2GM/c²
    没有任何力能支撑坍缩

  Chandrasekhar极限：

  M_Ch = 1.457(2/μ_e)² M☉ ≈ 1.4 M☉
    电子简并压无法支撑更大质量
    超过则坍缩为中子星

  Tolman-Oppenheimer-Volkoff（TOV）极限：
    M_TOV ≈ 2-3 M☉（中子星最大质量）
    2020年GW190814：2.6 M☉中子星

  超新星：

  II型（核坍缩）：
    铁核坍缩 → 反弹激波 → 爆发
    峰值光度：~10⁴²-10⁴³ W（全星系亮度）
    抛射物质：~10 M☉
    合成重元素（快中子俘获r过程）

  Ia型（白矮星爆炸）：
    白矮星吸积超Chandrasekhar极限
    碳引爆 → 完全瓦解
    标准烛光：宇宙学测距

  史瓦西半径计算：
    太阳：r_s = 2GM/c² = 3.0 km
    10 M☉黑洞：r_s = 29.5 km

  螺旋几何化解释：

  1. 恒星演化的螺旋几何化
     - 演化 = 恒星螺旋生命周期的推进
     - 主序 = 螺旋平衡态
     - 红巨星 = 螺旋壳层燃烧
     - 坍缩 = 螺旋塌缩的引力

  2. 致密天体的螺旋解释
     - 白矮星 = 螺旋简并电子的抵抗
     - 中子星 = 螺旋中子的简并态
     - 黑洞 = 螺旋时空的临界态
     - 视界 = 螺旋逃逸速度=c的界面

  3. 超新星的螺旋解释
     - 坍缩 = 螺旋核心的失稳
     - 爆发 = 螺旋激波的能量释放
     - 重元素 = 螺旋过程的核合成
     - 脉冲星 = 旋转的螺旋辐射灯塔

----------------------------------------------------------------------

  白矮星：

  电子简并气：
    P = Kρ^(5/3)（非相对论）
    P = K'ρ^(4/3)（相对论）
    质量-半径关系：R ∝ M^(-1/3)

  中子星：

  结构：
    外壳：~1 km（铁晶格）

  1967年由Jocelyn Bell发现
  旋转中子星的灯塔效应：
    - 磁轴与自转轴不重合
    - 辐射束随自转扫描

    蟹状星云脉冲星周期 P = 33 ms
    角速度 ω = 190.4 rad/s
    转动动能 E = ½Iω² = 1.81e+42 J

  黑洞分类：
    恒星质量：3-100 M☉（超新星坍缩）

  人马座A*计算：

  引力波与致密天体：

【AP4】星际介质与星云
----------------------------------------------------------------------

  星际介质（ISM）：

  星际介质是恒星间稀薄的气体和尘埃：
    平均密度：~1个原子/cm³
    温度范围：10K（分子云）到10⁶K（热气体）
    组成：~73%氢, 25%氦, 2%重元素

  ISM组分：

  1. 分子云：
     - T ~ 10-30 K
     - n ~ 10²-10⁶ cm⁻³
     - 恒星形成区（猎户座分子云）
     - 分子：H₂, CO, NH₃, H₂O

  2. 冷中性介质（H I）：
     - T ~ 100 K
     - n ~ 50 cm⁻³
     - 21cm辐射（氢自旋翻转）

  3. 热中性介质：
     - T ~ 8000 K
     - n ~ 0.3 cm⁻³

  4. 热电离介质（H II）：
     - T ~ 10⁴ K
     - 恒星电离区（猎户星云）
     - Balmer线辐射

  5. 热气体（星系晕）：
     - T ~ 10⁵-10⁶ K
     - X射线辐射

  星际尘埃：

  尘埃性质：
    尺寸：0.01-1 μm
    组成：硅酸盐、碳、冰
    消光：蓝光衰减>红光（星际红化）
    再辐射：红外发射

  尘埃作用：
    - 遮挡光学观测
    - 红外巡天（Spitzer, JWST）
    - 行星形成（尘埃聚集）
    - 分子形成表面催化

  星云：

  发射星云：
    猎户星云（M42）：恒星形成区
    船底座星云：大质量恒星
    鹰状星云：创生之柱

  反射星云：
    昴星团星云：反射星光
    蓝色（瑞利散射）

  暗星云：
    马头星云
    煤袋星云

  行星状星云：
    环状星云（M57）
    猫眼星云（NGC 6543）
    恒星演化终点（白矮星形成）

  恒星形成：

  Jeans不稳定性：
    引力 > 压强 → 坍缩

  Jeans质量：
    M_J ≈ (5kT/Gμm_H)^(3/2)(3/4πρ)^(1/2)
    分子云：M_J ~ 10⁴ M☉

  形成过程：
    分子云 → 坍缩 → 原恒星 → T Tauri星
    → 主序（氢点燃）
    吸积盘：行星形成场所

  Jeans质量计算：
    分子云 T = 20.0 K, n = 10⁴ cm⁻³
    M_J = 24 M☉

  螺旋几何化解释：

  1. 星际介质的螺旋几何化
     - 分子云 = 螺旋气体的巨型聚集
     - 密度波 = 螺旋臂的压缩波
     - 湍流 = 星际气体的螺旋运动
     - 磁化 = 螺旋磁场的冻结

  2. 恒星形成的螺旋解释
     - 坍缩 = 螺旋引力的内聚
     - 角动量 = 螺旋自转的守恒
     - 吸积盘 = 螺旋下落的盘
     - 喷流 = 螺旋磁场的准直

  3. 与三重奏的联系
     - 密度波 = 螺旋压缩模式
     - 磁场 = 螺旋电流结构
     - 湍流 = 螺旋涡的级串

  银河系：

  结构：
    银盘：直径~10万光年，厚~1000光年
    核球：中心~1万光年
    银晕：球状星团+暗物质
    旋臂：4条主旋臂（英仙、人马、猎户、盾牌-半人马）

  太阳位置：
    距银心：~2.6万光年
    位于猎户臂内缘
    轨道速度：~230 km/s
    轨道周期：~2.3亿年（银河年）

  质量：
    恒星质量：~6×10¹⁰ M☉
    总质量：~10¹² M☉（含暗物质）
    恒星数：~2000亿

  银河系质量估算（太阳轨道）：
    M(<R) = v²R/G = 9.80e+10 M☉

    银河系暗物质晕：M ~ 10¹² M☉
