## 一、一句话结论

**统一表示框架不是逃逸。** 单一不可约表示（E6 的 `27`、SO(10) 的 `16`）**强迫所有 SM 分量共享同一个通量** `q`；
而把常数荷向量代入四个线性反常方程，残差是 `(4, 4, 15, 10/3)` —— **四条全部非零、全部同号**。
⇒ 只有 `q = 0`；`q = 0` ⇒ `n_R = 0` ⇒ **零代，不是三代**。

**唯一的活口**是放弃「`U(1)_F` 精确无反常」（Stückelberg / Green–Schwarz / 整体）。那时障碍消失，
在 `CP^n` 族上 `n_R = 3` 精确可解 —— **只有 `CP^1` 有整数解，且 `q` 恰为 3**。
但此时 `n_R = 3` 是**自由输入**，三代仍不被解释。

**所以：三代仍未解释。但「为什么必须逐多重态分荷」第一次有了一个数值理由 —— 逐多重态的 `Y` 正负混合，能精确抵消；常数荷不可能抵消。**

| 矩 | 值 |
|---|---|
| `Σ dim·Y` | **0** |
| `Σ dim·Y²` | **10/3** |

三个矩里**唯一非零的是二次的，且值是 `10/3`**。

⇒ **障碍不是 E6 的特征，而是「一代 SM 内容」的特征。**

## 四、定理 Z：统一框架必然反常

单一不可约表示只有一个指标 ⇒ 所有分量共享**同一个** `q`。于是

```
A_YYF = Σ dim·Y²·q  =  q · Σ dim·Y²  =  (10/3) q        [16 of SO(10)]
                                    =  5 q               [27 of E6]
```

要 `A_YYF = 0` 只有 `q = 0` ⇒ `n_R = 0` ⇒ **零代**。

### 比预想更强：不是只有一条反常，是四条全部

把**常数荷向量** `(1,1,1,1,1)` 代入 r309 的四个线性反常方程，逐条残差：

| 反常 | 常数荷下的残差 |
|---|---|
| `A3 = 2q₁+q₂+q₃` | **4** |
| `A2 = 3q₁+q₄` | **4** |
| `Ag = Σ dim·q` | **15** |
| `AYY = Σ dim·Y²·q` | **10/3** |

**四条全部非零，且全部为正** ⇒ 不存在正负抵消的可能 ⇒ 唯一解 `q = 0`。

★ **符号论证**：逐多重态时 `Y = (1/6, −2/3, 1/3, −1/2, 1)` **正负混合**，四条方程能精确抵消（`A=0`）；
常数荷没有正负混合，**结构上不可能**抵消。这就是「为什么必须逐多重态分荷」的全部理由。

### 与 r309 定理 S 的对接

r309 Theorem S：四个线性反常矩阵**秩 4 / 5 未知数**，零空间**恰好 1 维且基向量就是 `Y` 本身**
⇒ 反常自由集 = `span(Y)`。

而 `Y` 有 **5 个互异值** ⇒ 「常数荷」等价于要求 `Y` 为常值 —— **假**。
⇒ 常数向量不在 `span(Y)` 里（除 `q = 0`）。两条路径完全独立，结论一致。

## 五、定理 AA：第二路线（`q_a = q·f_a`）也不通

若允许每个分量带 `q_a = q·f_a`（`U(1)_F ⊂ E6` 的嵌入给不同 `f`），那么：

1. 反常自由**强迫** `f ∝ Y`（由定理 S 的唯一性）；
2. ⇒ `U(1)_F = U(1)_Y`，通量变成超荷通量；
3. ⇒ 回到逐分量，5 个 `n_a` 需**全部相等**；
4. ⇒ `P(Y_i)` 全等 ⇒ `P − P*` 有 5 个根 ⇒ **4 个独立条件**；
5. ⇒ 再加 1 个非齐次（`n_R = 3`）⇒ 需 `⌈n/2⌉ ≥ 5` ⇒ **`n ≥ 9`（内部维度 ≥ 18）**。

**与 r309 定理 T 逐字一致。无逃逸。**

### 三档判决表

| 档 | `U(1)_F` 的地位 | 结论 |
|---|---|---|
| ① | 精确无反常规范对称 | 统一框架给 **零代**（定理 Z） |
| ② | 反常而重（Stückelberg / GS） | 统一框架给 **三代**，但 `n_R = 3` 是**自由输入** |
| ③ | 整体对称 | 无通量可言，框架自毁 |

**三档都不解释三代。** 档②是本卷唯一「能得到三代」的分支，也就是 `X-R319-1` 的位置。

## 六、定理 AB：放开反常前提后，`CP^n` 上的精确解

设 `M_int = CP^n`（复维 `n`），`c₁(L) = q·x`。则

```
n_R(q) = ∫_{CP^n} e^{qx} Â(TCP^n) = Σ_j a_j · q^{n−j} / (n−j)!
```

其中 `a_j` 由 `Â = 1 − p₁/24 + (7p₁²−4p₂)/5760 − (31p₁³−44p₁p₂+16p₃)/967680 + …`、
`p_k(CP^n) = C(n+1,k)·x^{2k}` 给出（**截断到 6 阶**）。

| `n` | `dim M_int` | `n_R(q)` | `n_R = 3` 的整数解 |
|---|---|---|---|
| 1 | 2 | `q` | **`q = 3`** |
| 2 | 4 | `½q² − 1/8` | 无（`q² = 25/4`） |
| 3 | 6 | `⅙q³ − ⅙q` | 无（`q³ − q = 18`） |
| 4 | 8 | `⅟24 q⁴ − 5/48 q² + 3/128` | 无 |
| 5 | 10 | `⅟120 q⁵ − 1/24 q³ + 1/30 q` | 无 |
| 6 | 12 | `⅟720 q⁶ − 7/576 q⁴ + 259/11520 q² − 5/1024` | 无 |

★ **只有 `CP^1`，且 `q` 恰为 3。** 最小内部空间 + 最小整数通量，正好给三代。

★ **反例对照**：`CP^6` 在 `q = 4` 处 `n_R = 2.9327`，离 3 只差 `0.0673` 但**不是** 3 —— 说明「恰好 3」不是单调性带来的自动结果。

### 诚实边界

- `Â` 只截断到 6 阶（`p₁,p₂,p₃`），**`n ≥ 7` 未算**；
- `CP^n` 只是**一族**内部空间，不是所有 Calabi–Yau；
- 所以「唯一」是**族内唯一**，不是全局唯一。

## 八、方法学：本轮做了什么、没做什么

**做了**：
1. 把 `27` 真分解成 11 个 SM 不可约分量，逐条算五条规范反常（不是引用「`27` 无反常」这个结论）；
2. 分开核验「代」与「额外物」各自反常自由（这一步决定了后续判据是否失真）；
3. 按两种不同分组（直接求和 / SU(5) 分块）复算二次超荷矩，得同一个 `10/3`；
4. 用两条独立路径（残差符号论证 / r309 秩-零空间）得同一结论；
5. 在 `CP^n` 上真解多项式方程，不是估量级。

**没做**：
- 没有新预言、没有新方案；
- 没有回答「`q = 3` 由什么选定」；
- 没有算 `n ≥ 7` 的 `CP^n`；
- 没有处理非 `CP^n` 的几何。

## 十、诚实边界（七条）

1. **不否认** r294/r302/r305/r307/r309 任何一条；本卷是把「框架」当变量重算，旧结论全部保留。
2. 定理 Z 的**前提**是「`U(1)_F` 是精确无反常规范对称」。这不是数学必然，是 r294–r309 一路沿用的物理假设。放弃它，否决失效。
3. 放弃后得到的 `CP^1` + `q = 3` 是**真结果**（精确整数解），但 `n_R = 3` 变成**自由输入**。
4. 定理 X 的分解是**标准** `27` 分解（`16 + 10 + 1`），不含 `E6` 破缺到 SM 的具体路径；不同破缺路径可能给不同的额外物，但**代的部分 `10 + 5̄` 固定不变**。
5. `CP^n` 只是内部空间的一族；`n ≥ 7` 未算。族内唯一 ≠ 全局唯一。
6. `c = 3`（纯复制）仍是**拓扑输入**，本卷没有解释。
7. **没有新预言、没有新方案，是一次框架级审计。**
