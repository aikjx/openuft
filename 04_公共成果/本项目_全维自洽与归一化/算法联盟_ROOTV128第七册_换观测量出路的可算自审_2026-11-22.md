## 0. 一句话

**前六册一直把「换观测量」写作未判的出口；本册判掉它：在 β=0 处，任何势泛函——线性的、非线性的、Shapiro 的、测距的、红移的、周期的——对 λ 的导数都精确为零。**

原因不是仪器精度，也不是泛函选得不好，而是 β=0 时势本身逐点不含 λ：

```
Phi(r; beta, lambda) = -(mu/r) * (1 + beta*lambda^2*exp(-r/lambda))
beta = 0  =>  Phi(r) = -mu/r  逐点成立  =>  dPhi/dlambda |_(beta=0) = 0

dQ/dlambda |_(beta=0) = ∫ (delta Q / delta Phi) * (dPhi/dlambda) = 0
```

链式法则对**任意** `Q[Phi]` 成立，不需要 `Q` 线性。因此这不是「第五力不存在」的证明，而是「零假设处的 λ 不是可观测量」的代数证明。

## 3. 逐个读数

### 3.1 P1 自检（守卫）

- β=0 时，对 r = `0.1 / 1 / 5 / 20 AU`、λ 三对（`0.5↔3`、`3↔100`、`100↔1e5 AU`），势逐点差最大值 **0**（机器零）。
- 五类泛函在 λ=1 与 100 AU 的差最大值 **0**（机器零）。
- 积分器四阶自检：预渐近段逐次比 `1.672E+03`（**只作诊断、不进门**）；渐近段 n=`200/400/800/1600` 的两段比值为 **`1.600E+01 / 1.600E+01`**，落在未放宽的门限 `12 < o < 20` 内。

这里留了一次自抓：**首跑 P1 FAIL**。原因不是 Simpson 不是四阶，而是自检取了 n=`100/200/400/800`，第一段还在预渐近区（该解析 integrand 早期收敛快于 h⁴）。修法是把自检移到渐近段，并把预渐近比值如实登记为诊断；**没有放宽四阶门限**。失败版 JSON/报告已移入 `_scratch/`（文件名含 `_P1FAIL`），不混入交付。

### 3.2 P2 五类泛函的 λ 导数（承重）

五类观测量 × 四个 λ（`0.5 / 1 / 10 / 100 AU`）：

| 读数 | 值 |
|---|---|
| β=0 处 `max abs(dQ/dλ)` | **0**（20/20 配置全零） |
| 同批配置 `min abs(dQ/dβ)` | **`1.213511E−02`**（>0，说明观测量对信号本身不是瞎的） |

| 观测量 | β=0 处 `min abs(dQ/dβ)` | β=0 处 `max abs(dQ/dλ)` |
|---|---|---|
| Shapiro 延迟 | `5.694694E−02` | 0 |
| 光线偏折 | `1.398659E−01` | 0 |
| 引力红移 | `1.493425E−02` | 0 |
| 雷达测距 | `1.213511E−02` | 0 |
| 轨道周期 | `1.691691E−02` | 0 |

**关键**：观测对象对 β 敏感（非零列），却对 λ 完全盲（零列）。这正是「换观测量救不了 λ」的机读形式——不是所有导数都为零，只有 λ 方向为零。

### 3.3 P3 非线性泛函（承重）

取 `Q₂ = ∫Phi² dl`（不是线性泛函），四个 λ 上：

| λ (AU) | `max abs(dQ₂/dλ)` at β=0 | `abs(dQ₂/dβ)` |
|---|---|---|
| 0.5 | 0 | `1.871409E−02` |
| 1 | 0 | `2.898964E−01` |
| 10 | 0 | `1.132347E+02` |
| 100 | 0 | `1.311560E+04` |

障碍不是「泛函线性」，而是 β=0 时 `Phi` 不含 λ。**即使把势平方、取任意非线性函数，链式法则仍给零。**这是本册比第五册更硬的一步：第五册只覆盖了线性泛函。

### 3.4 P4 正对照：非零 β 恢复 λ 信息（结构）

注入 `β = 1e−3` 后，五类泛函在网格上的 `min abs(dQ/dλ)` 全部 >0，总体最小 **`1.043543E−04`**：

| 观测量 | `min abs(dQ/dλ)` at β=1e−3 |
|---|---|
| Shapiro | `5.075195E−04` |
| 光线偏折 | `1.015039E−03` |
| 红移 | `1.043543E−04` |
| 雷达测距 | `1.149687E−04` |
| 轨道周期 | `1.353284E−04` |

**边界必须同时给**：本册不证明「Yukawa 的 λ 永远不可测」，只证明「零假设处不可测」。这与第六册 N7 的注入-恢复结论一致。

### 3.5 P6 设计研究（结构，不是观测约束）

统一假定相对精度 `sigma_Q/|Q| = 1e−9`（**设计假定，不是任何实验读数**），得：

| 观测量 | `Q` at β=0 | `dQ/dβ` | 假定 `sigma_beta` |
|---|---|---|---|
| Shapiro | `−7.379008E+00` | `8.420489E−01` | `8.763158E−09` |
| 光线偏折 | `1.997505E+00` | `1.203814E+00` | `1.659313E−09` |
| 红移 | `1.666667E−01` | `1.168843E−01` | **`1.425912E−09`**（最优） |
| 雷达测距 | `−1.098612E+00` | `2.063356E−01` | `5.324396E−09` |
| 轨道周期 | `1.000000E+00` | `1.839397E−01` | `5.436564E−09` |

换观测量可以把 β 的假定精度改善约 6 倍（Shapiro → 红移），但 P2 已证 β=0 处 `sigma_lambda = ∞`，该发散**不随观测量改变**。这张表是设计研究，**没有一条来自真实星历或真实测距数据**。

### 3.6 P7 反噬（守卫）

⇒ P2 不是「100% 通过的空谓词」；它能把循环论证的配置识别出来。但这类 Q_fake 等于把待测量写进仪器，不属于任何合法观测量。

### 3.8 P5 自噬判决（承重）

`P2`（线性泛函全零）+ `P3`（非线性泛函也零）⇒ **S = REFUTED**。
