## 一、一句话结论

在 `CP^n` 上，通量量子数 `q` 给出的族数**就是一个二项式系数**：

```
n_R(q) = C( q + (n-1)/2 , n )
```

而且这**不是**某个凑巧的代数恒等式 —— 它等于 `CP^n` 上某个线丛的 Euler 示性：

```
n_R(q) = chi( O(q - (n+1)/2) )      ← 就是 Riemann–Roch
```

所以「第 `n_R` 代」这件事，被彻底算术化了：**族数只能是某个二项式系数**。于是「三代」变成一道初等数论题 `C(x, n) = 3`，而这道题在 `n ≥ 3` 时**无解**，且**可证**（不需要扫描上界）。

**但**：`C(x, 2) = 3` 有两个根，对应三角形数 `T_2 = 3`；而三角形数有无穷多个 ⇒ 这套机制仍然**不预言 3**，它只把「为什么是 3」翻译成「为什么内部空间是 `CP²`」。

## 三、定理 A · Chern 根的幂和引理（L1）

`CP^n` 的 Chern 根取 `x_1 = … = x_{n+1} = H`（因为 `c(CP^n) = (1+H)^{n+1}`）。于是

```
P_m := sum_i x_i^m = (n+1) H^m     对 m <= n 成立
```

**机检**：`n = 1..12`、`m = 1..n` 共 **78 组，全部相符，失配 0**（`A02`）。

**它不能恒真**（这是关键，否则是恒绿装饰）：`m = n+1` 时立刻失效。`CP²` 的 `P_3 = 0`，而 `(n+1)H³ = 4H³`（`A03`、`CTL11`）。原因很直白：`H^{n+1} = 0`（`CP^n` 的实维是 `2n`），所以 `P_m = 0` 对 `m ≥ n+1`，与 `(n+1)H^m` 不再相等。

> **纪律**：凡「等式在某范围内全对」，必须同时报「范围外第一条就错」。否则这条 PASS 没有判别力。

## 四、定理 B · Todd–Hirzebruch 引理（L2）

记 `T(x) = x/(1-e^{-x})`（Todd 乘法序列的生成函数）。则

```
[H^n]  e^{lam H} · T(H)^{n+1}  =  C(lam + n, n)
```

**机检**：`n = 1..8` × `lam ∈ [-4, 4]` 步长 `1/3`（25 个点），共 **200 组，失配 0**（`B01`）。

这条是教科书事实 `chi(O(k)) = C(k+n, n)` 的多项式延拓 —— `lam` 允许是任意有理数，而不只是整数 `k`。

### 证明里真正承重的中间步

`Â = td · e^{-c1/2}`，且 `log td = sum_m (log T)_m · P_m`。把 L1 代进去（`P_m = (n+1)H^m`）：

```
log td = (n+1) · sum_m (log T)_m H^m = (n+1) · log T(H)     mod H^{n+1}
```

即

```
td(CP^n) === T(H)^{n+1}     mod H^{n+1}
```

**机检**：`n = 1..12`，把左边（`Chern 根 + log/exp` 两条乘法序列）与右边（`T(H)` 直接取 `n+1` 次幂）逐系数比，**0 条不符**（`B02`）。这一步是整条证明的铰链：没有它，`Â` 是一堆混在一起的 `a_2, a_4, …`，二项式不会浮现。

## 五、定理 C · 二项式闭式（本卷核心）

```
n_R(q) = [H^n] e^{qH} Â(CP^n)
       = [H^n] e^{(q - (n+1)/2)H} T(H)^{n+1}          （代入定理 B 的中间步）
       = C( q - (n+1)/2 + n , n)                        （用 L2）
       = C( q + (n-1)/2 , n )
```

**机检（三档，逐档独立）**：

| 档 | 范围 | 组数 | 失配 |
|---|---|---|---|
| `B03` | `n = 1..12` × `q ∈ [-15, 15]` 步长 `1/2` | 732 | **0** |
| `B04` | `n = 1..8` × `q` 分母为 3（**非格点**） | 328 | **0** |
| `B06` | `n = 1..12`，FW 格上 `q` | 150 | **0** |

`B04` 的意义：恒等式在**非格点**上也成立 ⇒ 这是**多项式恒等式**，不是「格上的巧合」⇒ 可以当定理用。

### 第三条独立路径：它就是 Riemann–Roch

`B06` 走的是**完全不碰示性类**的一条路。对 `CP^n` 上的线丛 `O(k)`，只用两个层上同调维数公式：

```
k >= 0 :  h^0 = C(k+n, n)，其余为 0        ⇒ chi = C(k+n, n)
k <= -1:  Serre 对偶 H^i(O(k))^* = H^{n-i}(O(-k-n-1))，且 -k-n-1 >= 0
          ⇒ 只有 h^n 非零，h^n = C(-k-1, n) ⇒ chi = (-1)^n C(-k-1, n)
```

取 `k = q - (n+1)/2`，则 `k ∈ Z ⟺ q 在 FW 格上`，且

```
chi( O(q - (n+1)/2) )  ==  n_R(q)        150 组，失配 0
```

> **这条把定理 C 的性质改了。** 原来它读作「`n_R` 恰好等于一个二项式（好巧）」；现在它读作「`n_R` **就是** `O(k)` 的 Euler 示性（RR 的直接后果）」。二项式不是巧合，是 RR 在 `CP^n` 上的显式形式。

## 六、定理 D · Freed–Witten 移位 = 上指标为整数

`x := q + (n-1)/2` 是二项式的上指标。定理 C 要把 `C(x, n)` 当**整数**读（`n_R` 是族数），前提是 `x ∈ Z`。而

```
x ∈ Z   ⟺   q ∈ Z (n 奇)  或  q ∈ Z + 1/2 (n 偶)
```

这**正好**就是 Freed–Witten 移位给出的格 —— r325 定理 A 用 `c1(CP^n) = (n+1)H` 与 spin 性独立得到的那张格。

**机检：2×2 列联表**（`C01`，`n = 1..12` × 25 个 `q`，共 300 对）：

| | `x` 整数 | `x` 非整数 |
|---|---|---|
| **在 FW 格上**（150 对） | **150** | **0** |
| **离格**（150 对） | **0** | **150** |

两个方向都成立，且格点集非空、奇偶两类都被覆盖（`C02`：奇 `n` 各 13 个、偶 `n` 各 12 个，`G17` 守这条）。

> **为什么这张表比一句「恒成立」有价值**：初版的格判据写成「`q ∈ Z` 且 `q ∈ Z+shift`」，对**偶数 n 恒假** ⇒ 只统计到 6 个奇数 `n`（78 对），却仍「通过」了一条写死 `exp = 300` 的条目。2×2 表把这个洞补上了 —— 见 §十二 自伤②。

**同一条格的第三种读法**（`B07`）：离格的 150 对里，`k = q-(n+1)/2` 为整数的有 **0** 对 ⇒ 层上同调这条路在离格点上**根本没有对象可算**（不是「算出来不一样」）。所以 r325 的格不是技术细节，它是定理 C 的**定义域**。

## 七、定理 E ·「跳过 3」（主结论）

要解 `C(x, n) = 3`，`x ∈ Z`，`n ≥ 1`。**四个支点覆盖全部整数 `x`，不需要任何扫描上界。**

| 支点 | 范围 | 结论 | 机检 |
|---|---|---|---|
| **1 单调 + 跳跃** | `x ≥ n` | `C(x,n)` 在 `x ≥ n` 上严格递增，且 `C(n,n)=1 < 3 < n+1 = C(n+1,n)`（`n ≥ 3`）⇒ 值只能取 `1` 或 `≥ 4` ⇒ **跳过 3** | `D04` 12/12；`D05` Pascal 差分 492 组失配 0 |
| **2 端点** | `x = n, n+1` | 同上，把「跳跃」本身机检出来 | `D06` 反例 0 个 |
| **3 零段** | `0 ≤ x < n` | `C = 0` | `D08` 失配 0 |
| **4 负整数支** | `x < 0` | `|C(x,n)| = C(n-x-1, n)`；`x = -1` 给 `1`，`x ≤ -2` 给 `≥ n+1 ≥ 4`；符号 `(-1)^n` ⇒ **不能等于 +3** | `D07` 命中 0 |

支点 1 的**证明**（不是窗口观察）：Pascal 恒等式

```
C(m+1, n) - C(m, n) = C(m, n-1) = m! / ((n-1)! (m-n+1)!)  >  0     对 m >= n >= 1
```

`D05` 在 `n = 1..12` × `m = n..n+40`（492 组）上逐点核这条差分恒等式，失配 0，而正性由右端的显式公式给出。

**解集**：

```
n = 1 :  x = 3                       ->  q = 3
n = 2 :  x = -2, 3                   ->  q = -5/2, 5/2
n >= 3:  无解（已证，非扫描）
```

**机检**：`D01/D02/D03`（在 `x ∈ [-60, 60]` 上清点，与上面的证明结论一致，`n = 3..12` 全空）。

> 本卷相对 r325 的实质升级：r325 只**报**了「`n ≥ 3` 无解」；本卷给出**证明**，`D09` 是这句的机读登记。

## 八、定理 F · 可实现族数 = 二项式系数表

`n_R = C(x, n)` ⇒ 在 `CP^n` 上，可实现的正整数族数**就是** `n` 阶二项式系数。

| `n` | 前 5 个可实现族数 | 名称 |
|---|---|---|
| 1 | 1, 2, 3, 4, 5 | 全正整数（**恒等映射，零信息**） |
| 2 | 1, 3, 6, 10, 15 | **三角形数** `T_k` |
| 3 | 1, 4, 10, 20, 35 | 四面体数 |
| 4 | 1, 5, 15, 35, 70 | 五胞体数 |
| 5 | 1, 6, 21, 56, 126 | 单纯形数 |

**核心命题（`E04`，12/12）**：

```
n = 2 可实现 N   ⟺   N 是三角形数   （因为 C(x,2) = T_{x-1}）
```

**`n = 1` 那一列为什么必须标成零信息**：`C(x,1) = x` ⇒ 任何正整数都「可实现」⇒ 它与「三代」是同一句话，没有解释力。r325 定理 D 已经点过这一刀（`CP¹` 上 `n_R(q) = q` 恒等，反向可及 12/12，判别力 0）。所以**非平凡**的最小 `n` 才是真问题。

## 九、定理 G · 3 与 4 的算术判别

| | 3 | 4 |
|---|---|---|
| 是三角形数？ | **是**（`T_2 = 3`） | **否** |
| 最小非平凡 `n` | **2**（`CP²`） | **3**（`CP³`） |
| 机检 | `E07` | `E08` |

**读法**：给得出三代，`CP²` 就够（`C(3,2) = 3`，也 `C(-2,2) = 3`）；给得出四代，`CP²` **不够**，必须升到 `CP³`（`C(4,3) = 4`）。所以「三代」在算术上比「四代」**便宜一维**，而「六代」与「三代」**同一维**（都在 `CP²`：`C(4,2) = 6`）。

> 这才是 r325「解集有多大」那句话的真正内容：不是「两个解」，而是**一整张三角形数表**。三代只是表里的一项。

## 十、副产品 · r319/r325 的 `hat_a` bug 及其无害性

r319/r325 的 `hat_a` 在 `k > n` 时仍取 `c_k = C(n+1, k)`（正确应为 `0`，因为 `CP^n` 的 `c_k = 0` 对 `k > n`）。差异共 **9 处**（`A05`：`n=1` 的 `a2..a6`、`n=2` 的 `a4,a6`、`n=3` 的 `a4,a6`、`n=4,5` 的 `a6`），最大偏差 `n=1` 的 `a_2: -1/12 vs -1/6`（真值 `-1/6`，手算 `H/sinh H = 1 - H²/6 + …`，`A08`）。

**但它无害**（`A06`、`A07`、`G16`）：所有 9 处错位都落在 `H^j` 且 `j > n`，而 `n_R` 只取 `j ≤ n` 的项（`n_R = [H^n]`）⇒ 对任何 `n_R` 的读数**零影响**。

> 登记这个 bug 的理由不是认错，而是：**它给出了一次「影响范围」的实测**（9 处差异 / 0 处影响），这比「应该没问题」强。`CTL14` 守住「bug 确实存在」（否则 `A05` 是恒绿）。

## 十三、诚实边界（七条）

1. **本卷只做算术，不做动力学**。`n_R = C(x, n)` 是**指标映射**的闭式，它不解释为什么宇宙要选 `CP²`，也不解释为什么通量要取 `±5/2`。
2. **「跳过 3」是定理，但「3 被选中」不是**。定理 E 说的是「`n ≥ 3` 给不出 3」，不是「所以必须给 3」。差一步，而这一步本卷没走。
3. **三角形数有无穷多个** ⇒ 「3 是三角形数」既不唯一也不预言（`F02`：`S5 ∧ S6 = 0`）。它只解释「为什么 6 和 3 一样便宜」。
4. **`n = 1` 那一列是零信息**，必须显式标出，否则「`n=1` 也有解」会被误读成机制有解。
5. **`q` 的符号未被钉死**：`n = 2` 有 `q = ±5/2` 两个解，本卷没有排除其一（r325 遗留 `X-R325-2`：tadpole 整体闭合能否排除）。符号若影响别的物理量（手征性、`B-L`），本卷不涉及。
6. **`CP^n` 族之外的内部空间未查**。`S1` 是显式假设；`CY3`（`|Δ| = 3` 配对 35）与 `T⁶/Z₃`（27）是 r295 的逃逸路线，它们不在本卷的算术框架内。
7. **数值全为 `Fraction` 精确**，不是浮点。`Decimal` `prec = 60` 仅用于显示格式化。没有随机成分（`G05` 守）。
