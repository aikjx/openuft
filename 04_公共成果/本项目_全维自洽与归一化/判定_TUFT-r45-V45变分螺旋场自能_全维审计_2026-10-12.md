## 〇 一句话结论

**「从变分导出自能」的方法方向是对的，但 V4.5 的执行在承重链条上有三处互相独立的塌陷，且卖点的落点恰好在最不设防的那一行。**

2. **「驻波约束」是公理1 的恒等改写，势项整体消失**（T03）：公理1 已强制 `ω = cκ/sinθ`，代入后 `V(κ) ≡ 0` **处处成立**（sinθ=1 时 4/4 逐位精确零，一般 θ 下 25 组最大相对残差 `1.17E-120`）。于是运动方程退化为 `∇²κ = 0`，而球对称调和函数的唯一有界解是常数 ⇒ **这套公设组合下没有粒子**（T04/T05）。

## 一、承重裁定（四条）

### C1【FAIL · 最重】「量纲完全自洽」的卖点在自家核验行上即破

机器量纲（T11）：

    [U_self] = [ħ l_P κ² / c] = M     （来料声称 ML^2T^-2）
    缺口 = [E]/[U] = L^2 T^-2 = c^2

来料核验行写 `ML²T⁻¹·L ÷ LT⁻¹ · L⁻² = ML²T⁻²`。逐步展开：`ħ·L = ML³T⁻¹`；`÷c = ML²T⁻¹/(LT⁻¹) = ML`；`·L⁻² = M`。**错在最后一步把 `ML` 当成了 `ML²T⁻²`。**

同一缺陷在**上游**同源（T12）：`S_spiral` 的梯度动能项 `[ħ/(2c)·(∇κ)²] = ML⁻³`，而拉氏密度中该项须为能量密度 `ML⁻¹T⁻²`，**缺口恰为 `c²`**。

⇒ 最小修复（零代价，两处同改）：`ħ/(2c) → ħc/2`，得 `U_self = πħc·l_P·κ²/2`（量纲 `ML²T⁻²` 合，T13）。

### C2【FAIL · 决定性】公理1 使势项恒等于零，「变分」无事可做

`V(κ) = ½(c²κ²/sin²θ − ω²)²`，公理1 给 `ω = cκ/sinθ` ⇒ 括号内恒为 0 ⇒

    V(κ) ≡ 0   （处处，不是在某个壳上）

机器证：5 组 θ × 5 组 κ，`sinθ=1` 时 **4/4 逐位精确 0**；一般 θ 下 25 组最大**相对**残差 `1.167E-120`（阳性对照：撤掉公理1 让 ω 独立取 `1e3` 时 `V = 5.0E+11`，非零 ⇒ 检验器非恒零）。

⇒ 三条连锁：
- **T04**：`dV/dκ ≡ 0` ⇒ 运动方程退化为 `∇²κ = 0`（无质量项、无势阱、无自洽源，与 ω/θ/粒子全部无关）。
- **T05**：球对称调和函数通解 `κ = C + C′/r`。`C′` 分支在 `r=1e-6` 处达 `1.0E+03`（发散）且在 `r=1e30` 处仍为 `1.0`（无穷远不衰减）；`C` 分支严格不衰减（r=1 与 r=100 差值 `0`）。**唯一有界且衰减的球对称调和函数是 `κ ≡ 0`** ⇒ 无粒子。
- **T03**：「取驻波约束」这句话本身是公理1 的恒等改写，零信息量。

### C3【FAIL】「打破 m²」在弱场极限被自己取消（第 2 次复发）

自能只给相对修正 `δ`：

    δ = 自能 / 线性项 = (π/2)(m/m_P)·sin²θ

| 粒子 | δ（sin²θ=1） |
|---|---|
| 电子 | `6.57450867E-23` |
| 缪子 | `1.35939987E-20` |
| τ 子 | `2.28347290E-19` |
| 顶夸克 | `1.22611695E-19` |

⇒ 全射程 ≤ 1e-19，**机制在目标区间内等于不存在**。弱场 `κ = mc·sinθ/ħ` 精确成立（T19，r44 T22 独立给出同一结论，互为交叉印证）⇒ `a ∝ cotθ·m·κ ∝ m²cosθ`，`sinθ` 消去：

    a_μ / a_e = (m_μ/m_e)² = 4.275312284808E+4   （原封不动，guard 与 r44 T31 对齐）

### C4【FAIL】「机制生效区」与「方程有定义区」完全不相交

- 实解需 `1/sin²θ > 2πmc²/ħ`。电子该量 = `4.87791366E+21`，而 `1/sin²θ` 上确界为 1 ⇒ 需 `θ < 1.4318E-11 rad`；τ 子需 `1.694E+25`（更严）。**全部真实粒子在全部实 θ 上无实根。**
- 二次项显著需 `δ ~ 1` 即 `m ~ m_P = 2.176E-8 kg`。
- 两者相差 **44.07 个量级**（T24）。

⇒ 来料 §3「二次项显著，抑制大质量粒子的 κ 增长」与 §5「根号为正」所要求的区间**互斥**。

## 五、本册新增判据（五条，可直接复用）

1. **公理回代恒等检验**：凡把某公理代入模型后**某个函数项整体消失**，必须先检查该项是否本就恒为零。本册中 `V(κ) ≡ 0` 使整条变分链无事可做 —— 只看「驻波条件」会误以为势参与物理。
2. **「额外约束」同族检验**：声称某条件是「额外约束」时，先在公理集内穷举它是否已是某条公理的推论；是则标 FAIL 并注明恒等来源（本册 T03）。
3. **有界-衰减调和函数的唯一性判据**（本册最实用）：任何「局域包 + 无源稳态场」组合，先问该 PDE 在「有界 + 衰减」边界下是否有非零解；球对称情形下唯一解是常数，可一步否证整条路线（T05/T34）。
4. **机制生效区 ⊆ 方程定义区**（T24）：带非线性自能修正的映射，必须先比较「修正项 O(1) 的质量区间」与「根号为正的质量区间」。两者可差 40+ 个量级，导致声称的机制永远打不到目标射程。
