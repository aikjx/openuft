# D5 · 大统一力方程（张祥前统一场论）

> 方法①：从公理到方程。统一动量 `P = m(c − v)`，统一力 `dP/dt = F`。

## 核心方程

```
统一动量：   P = m (c − v)
统一力：     F = dP/dt
电/磁力比： F_e / F_m = c / v
电磁波关系： E = c B        （由 Maxwell 已证，c = 1/√(ε₀μ₀)）
```

## 三重奏作为几何基石

张祥前统一力框架下，电磁力被分解为与速度相关的几何部分，其回旋频率
`ω = qB/(γm)` 正是三重奏中的 ω（见 P1 洛伦兹力字典）。因此：

```
κ² + τ² = (ω/v)² = (qB/(γ m v))²        （匀速螺旋 / 梯度磁场）
```

三重奏是统一力框架的**几何基石**（已严格证明），但本身不是"万有理论"——
它不解释引力、不生成常数、不完成四力统一（见 A4 开放问题）。
