## 一、求导证明复核（用户推导全部正确）

### 机械系统
```
E = ½mẋ² + ½kx²
dE/dt = ẋ(mẍ + kx)          ← sympy 精确因式分解
```
代入 `mẍ + kx = 0` ⇒ `dE/dt = 0` ✓

### 电磁系统
```
E = ½Lq̇² + ½(1/C)q²
dE/dt = q̇(Lq̈ + q/C)        ← 与机械逐项同构
```
代入 `Lq̈ + q/C = 0` ⇒ `dE/dt = 0` ✓

### dsolve 验证
```
x(t) = C₁sin(√(k/m)·t) + C₂cos(√(k/m)·t)
q(t) = C₁sin(t/√(LC))   + C₂cos(t/√(LC))
```
同为 `A·cos(ωt) + B·sin(ωt)` 结构 ✓

### 频率对偶
`√(k/m)` 在 `m↔L`、`k↔1/C` 下变为 `√((1/C)/L) = √(1/(LC))`，与电磁频率**精确相等**（sympy 差 = 0）。

## 二、对偶的严格定性：**辛同构**，不是物理等价

| | 正则坐标 | 正则动量 | 哈密顿量 | 泊松括号 |
|---|---|---|---|---|
| 机械 | x | p = mẋ | `p²/(2m) + kx²/2` | {x,p} = 1 |
| 电磁 | q | Φ = Lq̇（磁通链） | `Φ²/(2L) + q²/(2C)` | {q,Φ} = 1 |

两者共享同一形式：`H = ½·(动量)²/惯量 + ½·刚度·(坐标)²`

> **正确的解读**：`m` 与 `L` 在各自哈密顿量中占据**同一个结构槽位**（广义惯量）。
> **错误的解读**："电感真的是质量"。
>
> 辛同构保证：ODE、守恒律、量子化程序**一一对应**；
> 但它**不**保证物理实体相同。这是此类类比最常见的误用。

## 三、关键修正：集中参数 ODE → 连续场 PDE

用户的通用本源方程：

```
A·φ̈ + K·φ = 0
```

这是**常微分方程**（只有时间导数，0 空间维），只能描述**单个振子**。

正确的连续极限：

| 系统 | 连续极限 | 方程 | 波速 |
|---|---|---|---|
| 弹簧链 → 弹性介质 | ρ∂²u/∂t² = Y∂²u/∂z² | `∂²u/∂t² = v_s²∂²u/∂z²` | `v_s = √(Y/ρ)` |
| LC 梯形网络 → 传输线 | ∂²V/∂z² = L'C'∂²V/∂t² | `∂²V/∂t² = v²∂²V/∂z²` | `v = 1/√(L'C')` |

统一形式：**波动方程** `(1/v²)∂²φ/∂t² − ∇²φ = 0`
有质量场：**Klein–Gordon** `(□ + m²)φ = 0`

> **遗漏 `∇²φ` 的后果**：丢掉 ①传播 ②色散 ③光锥因果 ④粒子产生。
> 这是从「振子」跨到「宇宙」的**质变点**，不是可有可无的补充。

**KG 色散数值**（电子，`ω_k² = c²k² + m²c⁴/ℏ²`）：

| k (m⁻¹) | ω_k (rad/s) | ℏω_k (MeV) |
|---|---|---|
| 1×10¹⁰ | 7.763×10²⁰ | 0.5110（静能） |
| 1×10¹² | 8.322×10²⁰ | 0.5478 |
| 2.590×10¹²（=mc/ℏ） | 1.098×10²¹ | 0.7227 |
| 1×10¹⁴ | 2.999×10²² | 19.74 |

`k→0` 时 `ℏω→mc²`；`k≫m` 时 `ω→ck` ✓ 两端自洽。

### 失效点二（本册**真实新贡献**）：**证伪**"粒子 = 单个谐振子"

> 谐振结构能给出**频率/色散/对偶**，但给不出**粒子数、零点能归属、相互作用**。
