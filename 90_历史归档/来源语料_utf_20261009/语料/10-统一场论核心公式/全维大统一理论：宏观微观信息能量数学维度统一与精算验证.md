# 第七章 一步步证明求导

## 7.1 证明1：空间螺旋方程的导数

### 一阶导数

$$\boldsymbol{r}(\theta) = \rho\cos\theta \boldsymbol{i} + \rho\sin\theta \boldsymbol{j} + b\theta \boldsymbol{k}$$

$$\frac{d\boldsymbol{r}}{d\theta} = -\rho\sin\theta \boldsymbol{i} + \rho\cos\theta \boldsymbol{j} + b \boldsymbol{k}$$

$$\left|\frac{d\boldsymbol{r}}{d\theta}\right| = \sqrt{(-\rho\sin\theta)^2 + (\rho\cos\theta)^2 + b^2} = \sqrt{\rho^2 + b^2}$$

### 二阶导数

$$\frac{d^2\boldsymbol{r}}{d\theta^2} = -\rho\cos\theta \boldsymbol{i} - \rho\sin\theta \boldsymbol{j}$$

$$\left|\frac{d^2\boldsymbol{r}}{d\theta^2}\right| = \sqrt{(-\rho\cos\theta)^2 + (-\rho\sin\theta)^2} = \rho$$

### 三阶导数

$$\frac{d^3\boldsymbol{r}}{d\theta^3} = \rho\sin\theta \boldsymbol{i} - \rho\cos\theta \boldsymbol{j}$$

### 曲率计算

$$\kappa = \frac{\left|\frac{d\boldsymbol{r}}{d\theta} \times \frac{d^2\boldsymbol{r}}{d\theta^2}\right|}{\left|\frac{d\boldsymbol{r}}{d\theta}\right|^3}$$

$$\frac{d\boldsymbol{r}}{d\theta} \times \frac{d^2\boldsymbol{r}}{d\theta^2} = \begin{vmatrix}
\boldsymbol{i} & \boldsymbol{j} & \boldsymbol{k} \\
-\rho\sin\theta & \rho\cos\theta & b \\
-\rho\cos\theta & -\rho\sin\theta & 0
\end{vmatrix}$$

$$= b\rho\sin\theta \boldsymbol{i} - b\rho\cos\theta \boldsymbol{j} + (\rho^2\sin^2\theta + \rho^2\cos^2\theta) \boldsymbol{k}$$

$$= b\rho\sin\theta \boldsymbol{i} - b\rho\cos\theta \boldsymbol{j} + \rho^2 \boldsymbol{k}$$

$$\left|\frac{d\boldsymbol{r}}{d\theta} \times \frac{d^2\boldsymbol{r}}{d\theta^2}\right| = \sqrt{(b\rho\sin\theta)^2 + (-b\rho\cos\theta)^2 + (\rho^2)^2}$$

$$= \sqrt{b^2\rho^2(\sin^2\theta + \cos^2\theta) + \rho^4} = \sqrt{b^2\rho^2 + \rho^4} = \rho\sqrt{b^2 + \rho^2}$$

$$\kappa = \frac{\rho\sqrt{b^2 + \rho^2}}{(\sqrt{\rho^2 + b^2})^3} = \frac{\rho}{\rho^2 + b^2}$$

**修正**：之前的曲率公式有误，正确的曲率公式为：

$$\kappa = \frac{\rho}{\rho^2 + b^2}$$

## 7.2 证明2：光速约束的推导

### 速度计算

$$\vec{v} = \frac{d\boldsymbol{r}}{dt} = \frac{d\boldsymbol{r}}{d\theta} \cdot \frac{d\theta}{dt} = \omega \cdot \frac{d\boldsymbol{r}}{d\theta}$$

$$\vec{v} = -\rho\omega\sin(\omega t) \boldsymbol{i} + \rho\omega\cos(\omega t) \boldsymbol{j} + b\omega \boldsymbol{k}$$

### 速度大小

$$|\vec{v}| = \sqrt{(-\rho\omega\sin(\omega t))^2 + (\rho\omega\cos(\omega t))^2 + (b\omega)^2}$$

$$= \sqrt{\rho^2\omega^2(\sin^2(\omega t) + \cos^2(\omega t)) + b^2\omega^2}$$

$$= \sqrt{\rho^2\omega^2 + b^2\omega^2} = \omega\sqrt{\rho^2 + b^2}$$

### 光速约束

**设定**：$|\vec{v}| = c$

$$\omega\sqrt{\rho^2 + b^2} = c$$

$$\omega = \frac{c}{\sqrt{\rho^2 + b^2}}$$

**归一化后**（ρ² + b² = 1）：
$$\omega = c$$ ✅
