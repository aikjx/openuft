# D5 · 标准模型作用量

## 完整作用量

$$S_{\rm SM} = \int d^4x \left( -\frac{1}{4} F_{\mu\nu}^a F^{a\mu\nu} - \frac{1}{4} W_{\mu\nu}^i W^{i\mu\nu} - \frac{1}{4} B_{\mu\nu} B^{\mu\nu} + |D_\mu H|^2 - V(H) + \sum_f \bar{\Psi}_f (i\gamma^\mu D_\mu - y_f H) \Psi_f \right)$$

## 规范群

$$G_{\rm SM} = SU(3)_C \times SU(2)_L \times U(1)_Y$$

- $SU(3)_C$：强相互作用，8 个胶子
- $SU(2)_L$：弱相互作用，3 个 $W^\pm, Z$ 玻色子
- $U(1)_Y$：超荷，与 $SU(2)_L$ 破缺为 $U(1)_{\rm EM}$

## 自由参数（19 + 3 中微子 = 22）

- 3 个规范耦合 $g_1, g_2, g_3$
- Higgs 质量 $m_H$ 与 vev $v$
- 9 个 Yukawa 耦合（6 夸克 + 3 轻子）
- 4 个 CKM 参数 + 4 个 PMNS 参数
- QCD θ 角
- 中微子质量与混合
