## 一 受理范围与分工

r95–r101 五轮攻的是「不自洽 / 无内容 / 反统一 / 生成能力封闭」。本册换**资格正面**：一个自称「统一场论」的公式系统，对它声称统一的对象（牛顿引力 + 电磁）的现存实验现象学，必须至少能**表述**。该要求机读化为「接口槽位」判据——把公式集的 18 个符号提取为语义标签集（12 个语义），对 14 项标准检验各列「最小必需输入语义集」，机器求交并按上游判决分类：

| 类别 | 判据（机读） | 含义 |
|---|---|---|
| NO_SLOT | 槽位交集为空 | 结构上无法表述该现象 |
| BLOCKED | 交集非空 + 上游 FAIL/BOUNDARY | 接口被 r95–r101 判死 |
| CIRCULAR | 交集非空 + 上游命中循环词（恒等/反解/重述） | 接口活着但输出是输入的重新呈现 |
| COVERED | 交集非空 + 上游全 PASS 且无循环词 | 真覆盖 |

## 三 S 段：结构性原因——覆盖率 0 是语法容量的必然

- **S01（FAIL）**：公式集 18 个符号的语法类别统计——**local_kinematics 17 个 + external_input 1 个（G 为牛顿常数）+ 场/度规/多体语法量 0 个**。公式集连「场」的语法都没有：V 是给定了剖面函数的局部速度场，不是待解的动力学子。⇒ 覆盖率 0 是结构性必然，不是遗漏。
- **S02（INFO）**：来稿全文算子模式机读——对流导数 ∇_VV 21 处、一阶时间导 4 处；**d'Alembertian 0、度规 g_μν 0、曲率/挠率张量 0、Lagrange 量 0**（注：全文 29 处 `\boxed` 是 LaTeX 显示框，不是波动算子——初版模式 `\\box` 误匹配，已修正为 `\\Box\\b`）。公式集的「动力学」止于一阶运动学，二阶结构（波动/辐射/进动）在其语法容量之外——与 r95 P4（ω(r,t) 无场方程）、r101 守恒律封闭互洽。
