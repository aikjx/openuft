# ROOT V140：光速螺旋—几何方向场—规范动力学的精确校验

> 研究性质：对候选模型的**严格局部数学审计**，不是统一场论证明，也不构成独立实验发现。
> 约定：仅设 c=1；ℏ 与 G 保持独立量纲。闵可夫斯基号差 (-,+,+,+)，x^μ=(t,x,y,z)。

## 1. 从局部正交运动出发

三维理想螺旋 r(t)=(a cos ωt,a sin ωt,ut) 满足 a²ω²+u²=1 时，
κ=aω²，τ=uω，ω²=κ²+τ²。Frenet–Serret 标架 (T,N,B) 的旋转向量为 Ω_FS=τT+κB。
这是纯粹运动学，未说明力的来源。场的内部旋转与粒子世界线的弯曲运动不是同一命题。

## 2. 方向场和两对 Euler 变量

单个局部单位方向场 n=(sinθ cosφ,sinθ sinφ,cosθ)，对应二形式

    f = (1/2) n·(dn×dn) = (1/2) sinθ dθ∧dφ.

选 q=(1−cosθ)/2、p=φ，即 f=dq∧dp。局部可采用任意等面积变换 (q,p)→(Q,P)，使 dQ∧dP=dq∧dp。
允许两对独立内部坐标，定义

    F = dq₁∧dp₁ + dq₂∧dp₂,
    A = q₁ dp₁ + q₂ dp₂,   F=dA   (仅为局部规范势)。

由于 d²=0，始终有 dF=0，即齐次 Maxwell 方程。注意全局拓扑及奇点仍须单独处理，dF=0 是光滑局部结论。

## 3. Pfaffian 和秩判据

令 h=(q₁,p₁,q₂,p₂)，D_{aμ}=∂μ h_a。四维中的 2-形式满足

    (1/2)F∧F = dq₁∧dp₁∧dq₂∧dp₂
    Pf(F) = F₀₁F₂₃−F₀₂F₁₃+F₀₃F₁₂ = det(D).

使用 E_i=F_{0i}, B=(F₂₃,F₃₁,F₁₂)，则 Pf(F)=E·B。
所以四个内部梯度独立 ⇔ det D ≠0 ⇔ E·B≠0。
这也意味着：恰恰在 E·B=0 的电磁退化构型（包括平面电磁波），这一“满秩推出完整 Maxwell”论证不适用。

## 4. 从作用量求变分

    S_F = −ℏ/(4g_F²) ∫d⁴x sqrt(-g) F_{μν}F^{μν}.

设 J^ν=∇μF^{μν}，独立标量变分给出

    δA_ν = Σ_a [δq_a∂ν p_a −δp_a∂ν q_a] + ∇ν(Σ_a q_aδp_a).

利用 ∇ν J^ν=0、边界项消失，得到

    J^ν∂ν q_a=0；J^ν∂ν p_a=0 (a=1,2).

若 det D≠0，则 J^ν=0，局部与**无源 Maxwell 方程**一致。
若 det D=0，投影方程只规定 J 与这些梯度正交，可能存在 J≠0 的附加解。
因此“候选几何作用量全部满足方程”并不自动等价于“满足真空 Maxwell”。

## 5. 一个精确反例：场方程投影成立、真空 Maxwell 却失败

令 q₁=z，p₁=x sin(kz)−y cos(kz)，q₂=p₂=0，k≠0。
在一个足够小的局部坐标片中，可经伸缩/平移映射到单位方向场的 q∈(0,1) 取值范围。
于是 E=0，B=(cos kz,sin kz,0)。

    J^μ=∂νF^{νμ} = (0,k cos kz,k sin kz,0) ≠0.

但是 J·dq₁=0，J·dp₁=k[cos kz sin kz−sin kz cos kz]=0，
第二对常数场的投影也为零。故此构型**满足该复合场的无源作用量标量 EOM，却不满足真正的无源 Maxwell**。

同时 J 平行 B，F_{μν}J^ν=0，电磁应力张量仍局部守恒。
**所以连“场的能量动量守恒”都不能单独排除这个伪真空解。**
这与已有的力自由场、电磁 Euler 势的研究具有结构联系；不能当成新发明的物理效应。

## 6. 圆偏振场：场的旋转并不要求光的轨迹弯曲

令 s=t−z， q=s， p=x cos(ks)+y sin(ks)。
则 E=(cos ks,sin ks,0)，B=(sin ks,−cos ks,0)。

    E·B=0， |E|²=|B|²=1，F²=0，J=0，dF=0.

这是平直时空中沿 z 轴传播的无源、圆偏振平面波。其电磁矢量转动，但能量沿直线传播，
并不意味着单个自由光子在空间中做非测地线的螺旋运动。
所以“空间光速螺旋”的物理解释应优先考虑协变场内部运动/偏振结构。

## 7. 洛伦兹协变和应力—能量

当 q_a,p_a 按洛伦兹标量变换，F 为二形式，因此其几何变换是协变的。
程序检验了 F_{μν}F^{μν} 和 Pfaffian 在沿 x 方向 proper Lorentz boost 下的不变性。

    T_{μν} = (ℏ/g_F²)[F_{μα}F_{ν}{}^α−(1/4)g_{μν}F²].

无源 Maxwell 满足 ∂μT^{μν}=0；对于上面的 Beltrami 反例，尽管 J≠0，因 F·J=0 也守恒。
所有示例的 T_{00}=(ℏ/2g_F²)(E²+B²) ≥0。
这里只检验了经典平直时空背景；尚没有构造并验证该复合场与完整 GR 的耦合方程和初值问题。

## 8. 量纲审计 (c=1，ℏ、G 独立)

[t]=[x]=L， [m]=M， [ℏ]=ML， [G]=L/M；
[q]=[p]=1， [∂]=L⁻¹， [F]=L⁻²， [R]=L⁻²。

    [∫ℏ F² d⁴x] = (ML)(L⁻⁴)(L⁴)=ML=[作用量].
    [∫R/G d⁴x] = (L⁻²)/(L/M)·L⁴=ML=[作用量].

规范耦合 g_F 无量纲，但其数值并未从几何推导。无自由参数目标未实现。

## 9. 对四力统一的现实判据

1. 本次 F 是局部 Abelian U(1) 型二形式；它没有自动生成 SU(2) 或 SU(3) 的 Lie 代数、荷表示、质量谱和相互作用顶点。
2. 理想螺旋的 κ、τ、ω 关系不决定 g_F、精细结构常数或 G。
3. 为避免附加解，必须增加适当约束/动力学，并证明在 E·B=0 物理区间也得到正确光子自由度和 Maxwell 方程。
4. 需要全协变作用量、应力—能量守恒、量子幺正性、无异常、GR 极限及独立可测预测。
5. 任何新预测都要在不反向拟合参数的情况下与地月引力及粒子实验核验。

**当前科学状态：实现了严格数学审计与反例；尚未完成四力统一理论。**

## 10. 新增关键障碍：常量背景上缺少二次传播作用量

对两对标量取常量真空背景 `q_a=q_a0`, `p_a=p_a0`，令扰动幅度为 ε：

    q_a=q_a0+ε ξ_a,   p_a=p_a0+ε η_a.

则

    F=ε² Σ_a dξ_a∧dη_a，
    S_F ∝∫F² = O(ε⁴).

所以围绕这个常量背景，`S_F` 的二次项为零，不能由通常的线性化理论得到传播的 Maxwell 光子波动方程；标准微扰传播子也不存在。
在有梯度的非常量背景上可出现线性 F 扰动，但须额外解释真空为什么选择这种背景、其洛伦兹对称性、稳定性及传播自由度。
此项不能靠“多做数值拟合”修复，而需要新动力学或独立规范联络。

**V140 的两个核心拦截器：**（A）退化背景出现标量方程满足但真空 Maxwell 不满足的伪解；（B）常量背景缺少传播性的二次作用量。两者均来自明确模型，而非关于全部可能统一理论的普遍不可能性定理。
