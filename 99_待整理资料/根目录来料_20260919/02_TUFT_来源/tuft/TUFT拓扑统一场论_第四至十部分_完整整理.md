## 第四部分　固有时、时间演化、坐标变换

### 引理 4‑1　固有时定义（模型内部）

由公理 Ⅰ（`v_total ≡ c`），单条孤子世界线弧长微分 `ds = c·dt`。模型把弧长除以光速定义为局域固有时：

$$\mathrm d\tau = \frac{\mathrm ds}{c}$$

算子变换：

$$\frac{\mathrm d}{\mathrm d\tau}=c\frac{\mathrm d}{\mathrm ds}$$

对切向量求固有时导数：

$$\frac{d\boldsymbol T}{d\tau}=c\frac{d\boldsymbol T}{ds}=c\kappa\,\boldsymbol N$$

**物理含义**：固有时意义下切向量变化率正比曲率、指向主法向（引力方向）。

> ⚠️ **模型边界（如实标注）**：`ds=c·dt` 与 `dτ=ds/c` 联立 ⟹ **`dτ = dt`**。
> 即本模型的「固有时」恒等于坐标时，**模型内部不含狭义相对论的时间膨胀**（无 `γ` 因子）。
> 这与 SR 的 4 维流形固有时（`dτ = dt/γ`）不同——本处是**三维世界线弧长的模型定义**，不是相对论原生定义。
> 后果：模型的「钟速变化」不由度规 `g₀₀` 承担，而完全由 `β₁` 经 `ω` 承担（见 4‑2）。

### 引理 4‑2　`β₁` 与局域质量／频率

由 `κ²+τ² = β₁·⟨κ₀²+τ₀²⟩` 与 `m = (ℏ/c)√(κ²+τ²)`：

$$m = \frac{\hbar}{c}\sqrt{\beta_1}\sqrt{\langle\kappa_0^2+\tau_0^2\rangle}$$

真空基准 `β₁=1`，记 `m₀ = (ℏ/c)√(⟨κ₀²+τ₀²⟩)`：

$$\boxed{m = m_0\sqrt{\beta_1}}$$

本征角频率 `ω = c√(κ²+τ²)`，记 `ω₀ = c√(⟨κ₀²+τ₀²⟩)`：

$$\boxed{\omega = \omega_0\sqrt{\beta_1}}$$

**量纲审查（精算 1a–1e，全 PASS）**：`β₁` 无量纲（`L⁻²/L⁻²`）；`[m]=(ℏ/c)·L⁻¹=kg` ✓；`[ω]=(m/s)·m⁻¹=s⁻¹` ✓；`[g]=(c²/2)∇lnβ₁ = L/T²` ✓；`□` 两项同 `L⁻²` ✓。

### 4‑3　引力红移 —— **符号修正（本轮关键）**

弱场展开 `β₁ = 1+δβ₁`，`√β₁ ≈ 1 + δβ₁/2`；结合静态球对称解 `lnβ₁ = 2GM/(c²r)`（弱场 `δβ₁ ≈ 2GM/(c²r)`）：

$$\omega \approx \omega_0\left(1+\frac{GM}{c^2 r}\right)$$

**但标准 GR 与实验给出的是相反符号**：

| | 局域钟速率 / 无穷远钟速率 | 一阶 |
|---|---|---|
| TUFT（原稿 `ω=ω₀√β₁`） | `√β₁ = exp(GM/(c²r))` | `1 + GM/(c²r)` |
| **GR** | `√(1 − 2GM/(c²r))` | `1 − GM/(c²r)` |
| **实验**（Pound–Rebka / GPS / 光钟） | — | **更慢**（GR 符号） |

数值（`tuft_r7` 实算）：

| 位置 | `2GM/(c²r)` | TUFT | GR |
|---|---|---|---|
| 地球表面 | `1.392e−9` | `1 + 6.961e−10` | `1 − 6.961e−10` |
| 太阳表面 | `4.246e−6` | `1 + 2.123e−6` | `1 − 2.123e−6` |

**判定（R7）：FAIL（符号冲突）** —— 一阶**量值相同、符号相反**。若把 `ω` 直接解释为局域时钟速率，则 TUFT 该式**已被现有实验排除**（深势处钟应更慢，而非更快）。

#### 修复（R8）：可观测钟速 `∝ β₁^(−1/2)`

采用澄清路径 (i)/(ii)：`ω` 是「单位坐标时间内的本征振荡数」，**可观测钟速**须再乘传播因子，即

$$\boxed{\frac{\omega_{\mathrm{clock}}(r)}{\omega_0}=\frac{1}{\sqrt{\beta_1(r)}}=\exp(-\varepsilon)},\qquad
\varepsilon\equiv\frac{GM}{c^2 r}$$

> **注意**：`β₁ = exp(+2GM/(c²r))` 的符号由**牛顿极限唯一固定**（取负号则 `g` 变排斥），不可为迁就红移而翻转；须改的是 `ω` 与钟速率的**映射方式**。

#### 求导证明（sympy，R8 1a–1e）

- **1c（符号求导）**：`d(lnβ₁)/dr = −2GM/(c²r²)` ⟹ `g = (c²/2)·d(lnβ₁)/dr = −GM/r²` ✓（负号=吸引）
- **逐阶展开**（`ε ≡ GM/(c²r)`）：

$$\text{TUFT(修正)}\ e^{-\varepsilon}=1-\varepsilon+\tfrac{\varepsilon^2}{2}-\tfrac{\varepsilon^3}{6}+\cdots$$
$$\text{GR}\quad \sqrt{1-2\varepsilon}=1-\varepsilon-\tfrac{\varepsilon^2}{2}-\tfrac{\varepsilon^3}{2}-\cdots$$
$$\text{差（TUFT−GR）}=\varepsilon^{2}+\tfrac{\varepsilon^{3}}{3}+\cdots$$

- **1d PASS**：1 阶系数同为 `−1` ⟹ **一阶完全一致** ⇒ 与 Pound–Rebka / GPS / 光钟相容；
- **1e**：2 阶差 `= ε²`（TUFT `+ε²/2` vs GR `−ε²/2`）⟹ **存在可检验的特征偏差**。

#### 精算（mpmath 50 位）

## 第五部分　微观孤子 → 宏观统计涌现

> 本体层：单条闭合拓扑孤子（基本粒子尺度）；连接层：大量孤子的统计系综 → 宏观场量。
> **本部分是形式统计框架推导；严格粗粒化证明属开放命题。**

### 定义 5‑1　系综统计平均（补全原稿截断处）

设系综含 `N` 个拓扑孤子，第 `i` 个具有局域 `κ_i(r,t)`、`τ_i(r,t)`。宏观场取系综平均：

$$\langle\kappa^2+\tau^2\rangle_{\mathrm{macro}}(\boldsymbol r,t)
= \frac{1}{N}\sum_{i=1}^{N}\Big(\kappa_i^2(\boldsymbol r,t)+\tau_i^2(\boldsymbol r,t)\Big)
\;\xrightarrow[N\to\infty]{}\;
\int \big(\kappa^2+\tau^2\big)\,P(\kappa,\tau;\boldsymbol r,t)\,\mathrm d\kappa\,\mathrm d\tau$$

其中 `P` 为孤子几何量的局域概率密度。

### 定义 5‑2　宏观 `β₁` 与宏观量

$$\beta_{1,\mathrm{macro}} = \frac{\langle\kappa^2+\tau^2\rangle_{\mathrm{macro}}}{\langle\kappa_0^2+\tau_0^2\rangle}$$

于是 `m` 与 `ω` 的**形式不变地**平移到宏观：

$$m_{\mathrm{macro}} = m_0\sqrt{\beta_{1,\mathrm{macro}}},\qquad
\omega_{\mathrm{macro}} = \omega_0\sqrt{\beta_{1,\mathrm{macro}}}$$

**判定：PASS（形式层）** —— `β₁` 是比值，取平均后形式不变，`m`/`ω` 关系可平移。

### 5‑3　粗粒化闭合 —— **开放命题（BOUNDARY）**

宏观场方程是否保持微观形式，取决于

$$\langle\,\square\beta_1\,\rangle \stackrel{?}{=} \square\langle\beta_1\rangle$$

- 若 `β₁` 场方程**线性** ⟹ 等式成立，宏观即微观的平均；
- 若**非线性**（实际含 `exp(−u)` 自屏蔽项）⟹ 等式**一般不成立**，需重整化与闭合假设（如 `⟨e^{−u}⟩ ≈ e^{−⟨u⟩}` 的累积量展开）。

**判定：BOUNDARY** —— 形式平移 PASS；非线性粗粒化的闭合**未证明**，列为开放命题 O‑COARSE。

## 第六部分　`β₁` 场方程：弱场 / 强场解析

### 6‑1　场方程与弱场极限

文献采用的 `β₁` 层方程（`u = ln β₁`）：

$$\nabla^2 u = -\frac{8\pi G}{c^2}\,\rho\,e^{-u},\qquad g=\frac{c^2}{2}\nabla u$$

- **弱场**（`u ≪ 1`，`e^{−u}≈1`）：`∇²u = −(8πG/c²)ρ` ⟹ `u = 2GM/(c²r)`，`g = −GM/r²`（**牛顿，精算 2a PASS**）；
- 线性化后等价于 GR 弱场（`u = −2Φ/c²`），故**弱场扇区 TUFT ≡ GR**，无独有信号。

### 6‑2　强场：非线性自屏蔽

`e^{−u}` 使源项被自身势抑制 ⟹ `M_eff < M`。定义致密系数 `ξ = GM/(c²a)`：

| 天体 | `ξ` | 偏离 `1 − M_eff/M` |
|---|---|---|
| 白矮星 (1.4 M☉, 6000 km) | `3.4e−4` | 0.03% |
| 中子星 (1.4 M☉, 12 km) | `0.172` | **26.2%** |
| 恒星级黑洞 (10 M☉, `r_s`) | **`0.5`** | **46.8%** |
| 超大质量黑洞 (1e8 M☉, `r_s`) | **`0.5`** | **46.8%** |

黑洞 `a=r_s` ⟹ `ξ=1/2`（**与质量无关**）⇒ 偏离恒 ~47%。

**判定：FAIL（已被观测排除）** —— LIGO/Virgo 对 GR 波形相位约束 ~10%，47% 远超 ⟹ **R1 自屏蔽效应若真实已被引力波观测排除**（`ξ_max ≈ 0.049`）。

**修复三选一（沿用既有判定）**：(a) 重审 `e^{−u}` 因子是否多余（去掉则退化 GR，无自屏蔽）；(b) 引入 UV 完成抑制；(c) 接受偏离并寻 TUFT 独有观测。

## 第七部分　宇宙学形式推演

> **本部分为形式类比，非严格推导**——TUFT 尚未给出独立的 Friedmann 方程推导。

### 7‑1　均匀各向同性 ansatz

取 `β₁ = β₁(t)`（空间均匀），`u(t)=lnβ₁(t)`。场方程退化为

$$\ddot u + 3H\dot u = -\frac{8\pi G}{c^2}\rho\,e^{-u},\qquad H=\frac{\dot a}{a}$$

### 7‑2　与 Friedmann 的形式对照

| GR | TUFT（形式类比） |
|---|---|
| `H² = (8πG/3)ρ` | 需由 `β₁` 场方程导出 `H(β₁,\dotβ₁)` —— **未建立** |
| `ä/a = −(4πG/3)(ρ+3p/c²)` | **未建立** |
| 守恒 `ρ̇+3H(ρ+p/c²)=0` | **未建立** |

### 7‑3　判定

**BOUNDARY / 开放** —— 均匀 ansatz 可写，但 `H`、加速度方程、物态演化**均未从 `β₁` 场方程导出**。
在补齐前，任何「TUFT 宇宙学预言」都是**形式类比**，不计入 L3。列为 O‑COSMO。
