## 摘要

本研究选定两体量子质量的四分支冻结路径模型，沿着**广义相对论 → 牛顿弱场极限 → 量子相位 → 双体纠缠 → 低能引力有效场论 → 可辨识性与实验审计**的路径开展独立推导。最重要的量化结论是：一个在量子力学上产生非零 concurrence 的 Newtonian 双体相位，在实验室质量和长度尺度上，并**不**对一圈引力量子修正提供可观灵敏度。对两个 $10^{-14}$ kg、中心距离 450 μm、分支间距各 200 μm、持续 1 s 的模型，理论给出非局部 Newton 相位 $-0.0692394597354$ rad、代表性 1PN 势修正 $-2.39425\times10^{-38}$ rad 与一圈 EFT 势修正 $-9.85910\times10^{-64}$ rad。

第二个严格结果是：**任何仅使用相同 $1/r$ 距离核的引力和残余库仑相位，在多距离观测中参数完全不可辨识**；必须通过独立电荷测量、主动反转及其它物理通道打破退化。第三个结果是：可以构造跨三个距离点的零化组合，同时消去 $1/r$ 和 $1/r^2$ 形状项，形式上留下 $1/r^3$ 候选项，但普通浮点求差会制造超过目标 EFT 项约 $10^{46}$ 倍的伪残差。90 位有效数字十进制核验避免这一数值错误，却不改变实际实验不可行的数量级局限。

该项目包含 91 项实际 Python 单元测试、19 项 SymPy 符号审查、独立球面 Gauss–Legendre 积分核对、数值扫描、明示合成的零效应实验及离线交互页面。并对 2025—2026 年“经典引力是否能介导纠缠”的公开争论给出有前提的结论，不把一种具体经典模型的排除推广为全部可能的经典引力描述。

## 第二章｜从爱因斯坦方程到 Newton–Poisson 方程 [E]

以 $(-,+,+,+)$ 号规，取缓变弱场度规 $g_{00}\simeq-(1+2\Phi/c^2)$。低速、低压、弱场时，爱因斯坦方程的一阶时间—时间分量变为

$$\nabla^2\Phi=4\pi G\rho,\qquad \mathbf a=-\boldsymbol\nabla\Phi.$$

点源球对称外场 $\Phi=-GM/r$，因此 $\mathbf g=-GM\hat{\mathbf r}/r^2$。这是 GR 的条件极限，不是两套互相竞争的基本定律。高压、强场、动态场以及引力波必须返回四维 Einstein 方程。

## 第三章｜从固有时作用量到量子引力势 [E]

对相对于静态弱场缓慢运动的试验粒子，

$$S=-mc^2\int d\tau,\quad \frac{d\tau}{dt}\simeq\sqrt{1+2\Phi/c^2-v^2/c^2}.$$

展开得到 $L\simeq-mc^2-m\Phi+mv^2/2$，所以

$$H\simeq mc^2+\frac{\mathbf p^2}{2m}+m\Phi.$$

去除总体静质量相位并量子化 $\mathbf p\to-i\hbar\boldsymbol\nabla$，得到

$$i\hbar\partial_t\psi=\left[-\frac{\hbar^2}{2m}\nabla^2+m\Phi\right]\psi.$$

这一过程说明**为何经典引力势给量子物质添加相位**，而非证明引力源本身量子化。

## 第四章｜两质量四分支模型 [C]

质量 A、B 分别有两个固定位置分支 $i,j\in\{0,1\}$。将 A 的位置设为 $(-s_A/2,+s_A/2)$；B 的位置设为 $(d-s_B/2,d+s_B/2)$，约束 $d>(s_A+s_B)/2$，且两个固体球在任何分支均不重叠。四个中心距离：

$$r_{00}=d+(s_A-s_B)/2,\quad r_{01}=d+(s_A+s_B)/2,$$
$$r_{10}=d-(s_A+s_B)/2,\quad r_{11}=d+(s_B-s_A)/2.$$

当牛顿势为 $V_{ij}=-Gm_Am_B/r_{ij}$，其演化贡献相位 $\theta_{ij}=Gm_Am_B t/(\hbar r_{ij})$；两个初始等幅位置量子比特的末态

$$|\psi\rangle=\frac12\sum_{i,j=0}^{1}e^{i\theta_{ij}}|ij\rangle.$$

该模型忽略运动分支在相互作用期间的轨道反作用、波包展宽、磁场操控、材料环境及探测器测量全过程。

## 第五章｜纠缠判据与局部相位不变量 [E/C]

定义非局部相位

$$\boxed{\Delta=\theta_{00}-\theta_{01}-\theta_{10}+\theta_{11}}.$$

如果加入任意局部相位 $a_i+b_j$，它在 $\Delta$ 中严格消去。等幅初始纯态的 concurrence 和 negativity 分别为

$$\boxed{C=|\sin(\Delta/2)|,\qquad\mathcal N=C/2.}$$

这两式是所选纯态模型内的严格结论；一般混合态不能把纯态公式直接照搬。若 $s_A=0$、$s_B=0$ 或 $\Delta\in2\pi\mathbb Z$，则对应的纯态纠缠为零。

## 第六章｜局部退相干与部分转置 [C]

采用一个明确定义的局部相位退相干通道：对计算基 $|ij\rangle\langle kl|$，每个发生 $0\leftrightarrow1$ 的局部标签差使非对角元分别乘上 $e^{-\gamma_A t}$ 或 $e^{-\gamma_B t}$。构造 $\rho$ 后，以 B 系统部分转置 $\rho^{T_B}$ 计算

$$\mathcal N=\sum_{\lambda_j(\rho^{T_B})<0}|\lambda_j|.$$

这只是指定噪声模型。真实实验还应纳入振动、气体碰撞、散射光子、热辐射、磁场梯度、反馈测量等。误差不可仅由单一 $\gamma$ 捕获。

## 第七章｜精算基准：Newton vs 1PN vs EFT [C]

一种常见的低能散射匹配势的代表性写法是

$$V(r)=-\frac{Gm_Am_B}{r}\left[1+\underbrace{3\frac{G(m_A+m_B)}{rc^2}}_{\mathrm{1PN\ representative}}+\underbrace{\frac{41}{10\pi}\frac{G\hbar}{r^2c^3}}_{\mathrm{1\ loop\ EFT}}+\cdots\right].$$

**警告：** 势函数的经典高阶展开依赖坐标、匹配及哈密顿量约定，完整的可测相位必须包含同阶动力学、传播和观测流程；本包对 1PN / EFT 项仅做代表性**数量级审计**，并不声称已经算出某台装置的规范不变 1PN 或一圈可测读数。

对 $F_n=\sum_{ij}(-1)^{i+j}r_{ij}^{-n}$，定义 $A=Gm_Am_Bt/\hbar$，

$$\Delta_N=A F_1;\quad \Delta_{1PN}=A\frac{3G(m_A+m_B)}{c^2}F_2;\quad\Delta_q=A\frac{41}{10\pi}\ell_P^2F_3,$$

$$\ell_P^2=G\hbar/c^3.$$

## 第八章｜量纲、自由参数与 $G$ 的来源 [E/O]

$$[G]=L^3M^{-1}T^{-2},\quad[c]=LT^{-1},\quad[\hbar]=ML^2T^{-1}.$$

即使知道 $c$ 和 $\hbar$，没有额外独立质量或长度尺度，也不能仅靠乘幂构造 $G$。允许的量纲形式为

$$G=\gamma\frac{\hbar c}{m_*^2}\quad\text{或}\quad G=\gamma'\frac{c^3\ell_*^2}{\hbar},$$

但 $\gamma,\gamma',m_*,\ell_*$ 若来自先验 $G$ 就是恒等式循环。ROOT 的 $G=2Z/c$，若 $Z\equiv Gc/2$，同样属于重参数化。[E] 从真实第一性原理独立确定这些量是 [O]。

## 第九章｜电磁伪信号的精确退化定理 [E/C]

对于未屏蔽且固定净电荷的理想点源，库仑相互作用 $V_C=k_eq_Aq_B/r$，因此

$$\boxed{\Delta_{\mathrm{total}}=\frac t\hbar\left(Gm_Am_B-k_eq_Aq_B\right)F_1.}$$

对多个距离点 $d_k$，观察量对 $g=Gm_Am_B$、$e=k_eq_Aq_B$ 的设计矩阵两列为 $[F_1(d_k),-F_1(d_k)]^T$，**无论添加多少距离点，秩均为 1**。这在指定模型中严格成立。改变距离曲线不能解除 $g$、$e$ 的代数退化。

对于相同大小的两净电荷，如果

$$q_{\rm eq}=\sqrt{4\pi\varepsilon_0Gm_Am_B},$$

则同号电荷的库仑相位恰能抵消牛顿相位。示例 $q_{\rm eq}=8.6175172\times10^{-25}$ C，约为单个基本电荷 $5.38\times10^{-6}$ 倍。**该数值是等效耦合的尺度，不表示孤立物体能任意具有分数净电荷。** 若实际净电荷按整数元电荷量子化，单个残余电子将产生远超这条示例引力耦合的静电作用；同时实际材料还存在极化、斑块电势与磁相互作用，需要单独分析。

## 第十章｜已知经典通信模型为什么不能产生纠缠？[E/C]

设两个系统本来处于乘积态，由共享随机变量 $z$ 驱动各自**局部**相位门 $U_A(z)\otimes U_B(z)$。平均态必是

$$\rho=\int p(z)\,\rho_A(z)\otimes\rho_B(z)\,dz,$$

它由可分离态的凸组合构成，所以 $\mathcal N=0$。这是受限 LOCC / 局部随机通信模型的严格结论。

**重要限定：** 不能据此无条件声称“所有经典引力模型都无法让量子物质纠缠”。2025—2026 年一些量子场论及经典—量子混合模型对此有公开争议；具体结论涉及信息论局域性、时空局域性、物质传播、约束及可观测量定义，需要分模型审查。

## 第十二章｜新构造：跨三距离的双重零化滤波器 [E/C]

对同一实验几何在三个中心距离 $d_1,d_2,d_3$ 测量非局部相位。先定义列向量

$$\mathbf a_n=\big(F_n(d_1)L^n,F_n(d_2)L^n,F_n(d_3)L^n\big)^T,\ n=1,2,3$$

其中 $L$ 为纯粹的参考归一化长度。构造 $\mathbf w=\mathbf a_1\times\mathbf a_2$。则

$$\boxed{\mathbf w\cdot\mathbf a_1=\mathbf w\cdot\mathbf a_2=0},$$

$$\boxed{\mathbf w\cdot\mathbf a_3=\det[\mathbf a_1,\mathbf a_2,\mathbf a_3]}. $$

所以，只要三个几何形状列线性独立，该权重能够**形式上**消去严格 $1/r$ 形状项和 $1/r^2$ 形状项，保留更高阶形状。它是一个**线性代数的形状诊断器**，不是一台可测 Planck 量级信号的机器。

注意：该滤波器也消去了与牛顿核完全相同的库仑 $1/r$ 项，并不能单独说明残留一定为量子引力；非点源结构、近场电磁多极矩、动态效应和仪器误差同样可能产生高阶距离形状。

## 第十三章｜双精度灾难：本轮发现并修复的关键漏洞 [R]

取 $d=(450,600,850)$ μm，$s_A=s_B=200$ μm。利用归一化的权重 $\hat{\mathbf w}$ 得到目标一圈项约为 $1.37594\times10^{-65}$ rad，然而先在 IEEE 754 双精度中分别计算完整相位再做投影，会留下约 $-6.63\times10^{-19}$ rad 的舍入残差，**假信号比目标项大约 $4.82\times10^{46}$ 倍**。

数值修复有两部分：

- **解析保留分项**：不要先把比 Newton 项小 62 个数量级的 EFT 项加到 Newton 项上；双精度会直接舍入掉该项。
- **90 位十进制独立计算**：用 $\det[\mathbf a_1,\mathbf a_2,\mathbf a_3]$ 和已知物理系数单独算高阶项，检查 Newton/1PN 消零误差与 EFT 项比例。

双精度和 90 位十进制在“模型系数”上可以一致，但这一切**不改善任何实验设备的噪声**；数值精度不能替代测量灵敏度。

## 第十四章｜多距离不可辨识性：不是加数据就能解决 [E]

从 $\Delta(d)=(g-e)\,tF_1(d)/\hbar$，求参数向量 $\mathbf p=(g,e)$ 的雅可比

$$J_{k\alpha}=\frac{tF_1(d_k)}\hbar(1,-1).$$

$\operatorname{rank}J=1$，有一条严格不可辨识方向 $(1,1)$。即使测无限多无误差距离点，只有这类观测量也无法区分 $g$ 和 $e$。必须改变电荷、材料、磁屏蔽或加入另一个独立观测量。量子干涉并未神奇地消除这一退化。

## 第十五章｜有限尺寸物体的适用边界 [E/C]

对均匀球、**不重叠**且距离超出球半径的 Newton 静态引力，壳层定理保证外部势等于球心点源势。本包用独立 Gauss–Legendre 球面积分复核了这一性质。若球体重叠，或者考虑 Yukawa 型非 $1/r$ 相互作用、真实非球对称磁性结构，该结论不再可直接套用。

示例两个 $10^{-14}$ kg、密度 3500 kg/m³ 的实心球各半径约亚微米级，最短分支中心距离 250 μm，满足非重叠条件。但**存在空间分离的波包、相干维持一秒**是实验所需额外技术条件，不会由球体半径几何自动保证。

## 第十六章｜真实实验中的关键误差预算 [C]

只要想从纯量子相位中提取引力，至少必须测量/排除以下机制：

| 干扰 | 如何与引力混淆 | 独立控制 |
|---|---|---|
| 净电荷与表面斑块势 | 相同的 $1/r$ 或近似形状 | 独立电荷诊断、主动电荷操作、屏蔽对照 |
| 磁偶极和磁梯度 | 与控制场同步产生分支相位 | 磁场反向、隔离控制、空样品路径 |
| Casimir/表面极化 | 近程距离规律可能强于重力 | 材料/间隙扫描、独立电磁模型 |
| 背景气体与热辐射 | 造成退相干与失相干选择偏差 | 真空、温控、碰撞率记录 |
| 器件运动与振动 | 同步位移伪差 | 双通道惯性测量、假动作、盲化 |
| 分支重新合并不完全 | 降低见证值或制造后选择偏差 | 可见度、全样本计数、预注册 |
| 时钟/驱动漂移 | 同步相位偏移 | 独立时基与随机化调度 |
| 有限波包、装置应力 | 失效冻结路径假设 | 动力学仿真及误差上界 |
| 经典媒介非局域约定 | 纠缠解释依赖理论假设 | 明确模型、局域性条件与通道 |

不能以“结果显著”代替这些通道的物理验证。

- **层 C**：观测到明确不能由可接受的经典场模型解释的延迟传播相关、独立引力量子涨落特征或其他排他预测，并完成系统误差控制。最有鉴别意义，但实验门槛远高于本包的理想模型。

**本项目没有产生任何 A、B、C 层的自主实验观测。**

## 第十八章｜广义相对论与四种力的兼容性 [E/O]

标准模型的动力学场群是 $SU(3)_C\times SU(2)_L\times U(1)_Y$；电磁和弱作用在电弱模型中统一，强作用还没有经实验证明归入同一简单规范群。GR 把这些场的完整能动张量作为引力源，能够做经典耦合，不能因此推断整个系统具备 UV 完备的量子统一。量子异常抵消、粒子表示、手征性、耦合跑动等必须同步通过审计。

ROOT 的螺旋曲率/挠率可以作为**物理解释候选或参数化表述**；若要成为更深层动力学理论，必须给出 Lorentz 协变、局域作用量、规范群表示、无异常、应力能量守恒、可计算的新预测，并被实验区别于 GR+SM。

## 第十九章｜历史研究路线的正式汇总与去重复

| 研究路线 | 此前关键贡献 | V89 核验结论 |
|---|---|---|
| ROOT $G=2Z/c$ | 量纲与常数代换 | 恒等式，未独立预测 $Z$ |
| 微观场能动张量累加 | EM/热能/核能参与引力 | 必须保留交叉项、应力和总能量账本 |
| 星际多天体 $GM$ 比较 | 太阳系—中子星尺度检验 | 没有独立质量信息不能确定变化 $G$ |
| Yukawa 有限尺寸与分层 | 生成不同距离/材料预测 | 受实验约束，尚无新力观测 |
| $Q$ 径向形状检验 | 消去 Newton 幅度 | 天体多极矩可形成伪信号 |
| 组成差矩阵 / Eötvös | 识别新力媒介数量 | 必须正确归一化和计入相关噪声 |

| 本轮跨距离零化 | 消去 $1/r$ 与 $1/r^2$ | 数值圆整与高阶伪差可能占主导 |

## 第二十章｜新的突破口：可实现与不可实现的任务分流

**短期可验证任务**：

1. 在独立电荷诊断下重复质量、时间和路径分离标度，直接检验 Newton 非局部相位模型的系统误差预算。
2. 使用能实际测量的退相干与相位见证条件，而不是单个想象中的无噪声 concurrence。
3. 在多个独立实验平台上比较理论预测与盲测观测，并用假动作、材料差、空间方向反转排除常见伪差。
4. 对不同经典—量子模型写出具体可比较的噪声或相关结构：不能笼统只对比“经典/量子”两个模糊标签。

**目前不宜作为现阶段实验成功标准的任务**：

- 直接提取示例中的 $10^{-64}$ rad EFT 圈修正。
- 把三距离滤波器的 $10^{-19}$ rad 双精度残差宣布为引力子信号。
- 仅由 $G=2Z/c$ 或 Planck 长度定义宣称求出 $G$。
- 把双量子系统纠缠等价为无条件证明时空量子化。

**最具科研价值的下一道问题**：在不预先指定媒介类型的情况下，给出具有有限传播速度、明确相互作用区域、可计算退相干和电磁耦合的统一量子—经典实验通道，推导两个候选理论在**可观量级**上可区分的关联统计量。这依然是开放研究任务，而不是本包宣称解决的定理。

## 第二十一章｜独立测试与证伪结论

本项目实现的检验范围：

- Python 单元测试覆盖单位、几何矩阵、参数边界、纯态 concurrence、密度矩阵正定性、退相干、经典随机局部通道、电子电荷抵消、1PN/EFT 比率、雅可比退化、零化滤波、有限球不重叠及多参数扫描。
- SymPy 符号检查验证局部相位抵消、引力导数、弱场粒子拉氏量极限、三重乘积、量纲和 $\hbar\to0$ 极限。
- 使用独立高斯求积检查 Newton 外部球壳势；独立十进制高精度验证三个距离的零化滤波器。
- Chromium 仅验证浏览器计算与界面逻辑，不能替代独立物理实验。

### 明确的尚未解决项目

1. 完整量子引力动力学与时空量子态的直接观测。[O]
2. 第一性原理无自由参数预测数值 $G$。[O]
3. 强、弱、电磁、引力四力的独立无异常量子统一。[O]
4. 排除全部可能的经典引力/量子物质混合模型。[O]
5. 在实际装置上发现超出已知理论的独立信号。[O]

## 第二十二章｜结论

本轮最重要的“攻坚突破”属于**概念上的模型区分、严格的参数不可辨识性证明及数值伪差修复**，而非新的宇宙物理定律。Newton 势量子相位、受限经典通信无法产生纠缠、GR 低能 EFT 的环修正，可以在统一的计算框架里共存，但它们的物理含义与测量难度极不相同。

**目前没有证据可以宣告量子力学与 Einstein 场方程已实现 UV 完备统一，更不能称 $G$ 已从光速独立求出。** 真正走向可检验新物理的方法，是提出可实现的独立预测，并先解决电磁耦合退化、退相干与仪器伪信号的问题。
