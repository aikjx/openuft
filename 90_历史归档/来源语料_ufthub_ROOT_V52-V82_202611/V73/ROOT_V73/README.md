# ROOT V73｜新方法统一场论攻坚：尺度生成、有限尺寸、三重反转与反例审计

**项目定位：可重复计算的理论/实验设计研究，不是四力统一证明。**

本版本把 V72 的“总联络 + 二反转”改造成更严格的三条研究路线：

1. **尺度来源**：用一圈重整化群量纲嬗变替代“人为指定普朗克螺旋半径”，真实计算耦合敏感性，并证明这依然不等于独立预测 G。
2. **星体有限尺寸 + 元素组成**：做点源、均匀球、分层球的有限程力解析积分与高稳定数值实现，加入 MICROSCOPE 已发表数据的**特定代理源荷模型**条件限制；绝不宣称实测发现新力。
3. **三重反转**：8 状态 Walsh–Hadamard 完全正交设计，可消去所有低阶开关伪差；特意构造与信号同形的不可辨识伪差，证明显著性不等于新物理。

另包括：`a F \tilde F` 的条件有效场论变分、恒定赝标量场不产生 bulk Maxwell 修正的边界判据、总联络直和只是数学打包的判别、Weinberg–Witten 适用条件审计等。

## 如何运行

Python 3.10+，项目根目录：

```bash
pip install -r requirements.txt
python run_all.py
```

可选的独立符号核验：

```bash
pip install sympy
python symbolic_checks.py
# 或一次性运行全部
python run_all.py --symbolic
```

可选浏览器自动化测试：

```bash
pip install playwright
python browser_smoke.py
```

浏览器测试默认使用当前系统的 `/usr/bin/chromium`；如果你的安装路径不同，在脚本中调整 `executable_path`。由于本运行环境限制 `file://` 自动导航，浏览器测试通过 `page.set_content` 装载**完全相同的本地 HTML 字节**。人工使用时直接双击 `web/index.html` 即可。

Windows 可以运行 `RUN_ALL.bat`，Linux/macOS 可以执行 `sh RUN_ALL.sh`。如果安装依赖失败，网页仍可独立离线查看。

## 本轮科学结论

| 核心目标 | 状态 | 说明 |
|---|---|---|
| 从 c、ħ 与螺旋角独立生成 G | **不成立** | 在限定输入变量下量纲线性方程矛盾 |
| 量纲嬗变产生物理尺度 | **条件可推导** | 需要 UV 耦合、beta 函数和能标边界 |
| 星体有限尺寸改变假设性短程力 | **条件可推导** | 不表示自然界存在这种力 |
| 总联络写成一个曲率 | **数学可并列** | 不会自动产生共同动力学和粒子谱 |
| 完整三重反转隔离三阶信号 | **条件可推导** | 不能排除同形系统误差 |
| ROOT 四力大统一证明 | **仍未完成** | 缺独立 G、规范谱、UV 一致性、独立实测 |

## 重要科研纪律

- NIST/CODATA 的 G 是外部实验常数，不能标成 ROOT 预测。
- `SU(3)×SU(2)×U(1)` 是已建立的标准模型输入，不是由螺旋角推出。
- 数值积分精度/测试通过不能代替新物理的实验证据。
- `α=1` 只是用于比较点源/球源形状因子；它不是实验允许的实际耦合。
- `Z/A` 是人为代理源荷，并非验证过的新相互作用荷。
- 任何“无自由参数统一完成”的说法，必须先通过研究总集的完整证明责任清单。
