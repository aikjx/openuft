## 1. 本体主张

本体系的本体是**振动（频率）**：频率 ω 是第一物理量，螺旋是振动显现出的轨迹，不是空间自身的运动。核心宣言为"宇宙是一条以光速振动的螺旋；频率定时间，曲率定质量引力，挠率定电荷电磁"。

## 3. 与 S12 空间光速螺旋的区分（重点）

两者共用同一数学骨架 `√(κ²+τ²) = ω/c`，但本体与约束不同，**不得互相认证**。

| 维度 | 本体系 S10 | S12 空间光速螺旋 |
|---|---|---|
| 本源 | 振动 / 频率 ω | 空间本身的螺旋运动 |
| 螺旋的地位 | 振动的**轨迹**（结果） | 空间运动的**形式**（前提） |
| 对 c 的用法 | `v ≤ c`，光速是**上限** | `v ≡ c`，内部速度**恒等**于光速 |
| 曲率结构 | 复曲率 `Ξ = κ + iτ`（复数，含相位信息） | 模方恒等式 `κ² + τ² = (ω/c)²` |
| 质量表达 | `m = ℏ√(κ²+τ²)/c` | 由 `Rω ≤ c`、`m₀ ∝ 1/R` 给出 |
| 动力学输入 | 原著第四部由 κτ 直接定义 G、α、ε₀、μ₀ | 借用 S02 的 `F = dP/dt`、`P = m(c − v)` |

一句话判别：**S10 是"振动的螺旋"，S12 是"以光速运动的空间的螺旋"**。共同出现"螺旋"与 `κ²+τ²` 不构成合并依据，也不允许一方借用另一方的证据等级。

与其他体系：[S01 螺旋三重奏与谱几何](../../S01_螺旋三重奏与谱几何/README.md) 提供 Frenet/曲率挠率数学工具，本体系借用其语言；数学框架成立不能认证振动本体。

## 5. 可替代假设（替换其一即改变体系身份）

1. 把 A1 的"振动本体"换成"空间运动本体"→ 与 S12 趋同，应重新评估独立身份。
2. 把 `v ≤ c` 改为 `v ≡ c` → 由极限约束变为恒等约束，进入 S12 的公设域。
3. 去掉 A3 的复数结构 `Ξ = κ + iτ`、只保留 `κ² + τ²` → 相位信息丢失，α = τ/κ 的赋值失去依据。
