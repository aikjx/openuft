# 一、关系图谱总览

## 1.1 核心枢纽：α（精细结构常数）

α 是连接几何、运动学、电磁、原子物理的**核心枢纽**，有 **5 个独立等价表达**：

```
                    ┌────── τ/κ=α (几何: 挠率/曲率)
                    │
                    ├────── h/R=α (几何: 螺距/半径)
                    │
        α ──────────┼────── v∥/v⊥=α (运动学: 纵向/横向速度)
                    │
                    ├────── r_e/λ_C=α (电磁: 经典半径/Compton波长)
                    │
                    └────── λ_C/a₀=α (原子: Compton/Bohr半径)
```

## 1.2 长度阶梯（α 等比序列）

```
r_e ───×α───→ λ_C ───×α───→ a₀
 │                              │
 经典电子半径                    Bohr半径
 (α²·a₀)                       (λ_C/α)
```

- $r_e = \alpha\lambda_C = \alpha^2 a_0$
- $\lambda_C = \alpha a_0$
- **新发现**：$r_e \cdot a_0 = \lambda_C^2$（三体恒等式，S 级）

## 1.3 质量比的四重表达

$$\frac{m_e}{m_P} = \frac{\ell_P}{\lambda_C} = \frac{\kappa_e}{\kappa_P} = t_P\omega = 4.185 \times 10^{-23}$$

质量比 = 长度比 = 曲率比 = 频率·时间

## 1.4 速度正交（3D 垂直原理）

$$v_\perp^2 + v_\parallel^2 = c^2$$

| 分量 | 表达式 | 数值 |
|:---|:---|:---|
| $v_\perp$ | $c/\sqrt{1+\alpha^2}$ | 2.99784×10⁸ m/s |
| $v_\parallel$ | $\alpha c/\sqrt{1+\alpha^2}$ | 2.1876×10⁶ m/s |
| $v_\parallel/v_\perp$ | $\alpha$ | 0.007297 |

## 1.5 核心恒等式（第一性原理推导）

$$\kappa^2 + \tau^2 = \left(\frac{\omega}{c}\right)^2$$

- 来源：Frenet-Serret 对螺旋 $r(\theta)=(R\cos\theta,R\sin\theta,h\theta)$ 求导
- 精度：4.3×10⁻³¹ S 级

## 1.6 质量本源公式

$$m = \frac{\hbar}{c}\sqrt{\kappa^2+\tau^2}$$

- 来源：A2 公理（ℏ=mcL）+ 核心恒等式联立
- 精度：1.0 S 级（精确恢复 m_e）
