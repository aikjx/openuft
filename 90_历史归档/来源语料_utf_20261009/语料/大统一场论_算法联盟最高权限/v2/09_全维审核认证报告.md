## 二、核心方法：v=c 光速螺旋求导链

理论的本源是一条几何公理 + 一条物理公理：

**螺旋参数方程**（θ=ωt）：

$$\boldsymbol r(\theta) = (\rho\cos\theta,\ \rho\sin\theta,\ b\theta)$$

**速度求导**：

$$\boldsymbol v = \omega(-\rho\sin\theta,\ \rho\cos\theta,\ b),\qquad |\boldsymbol v| = \omega\sqrt{\rho^2+b^2} = \omega R$$

**光速公理** |v| = c：

$$\omega R = c \quad\Longrightarrow\quad \omega = \frac{c}{R}$$

**曲率与挠率**（Frenet-Serret）：

$$\kappa = \frac{\rho}{R^2},\qquad \tau = \frac{b}{R^2},\qquad \boxed{\kappa^2+\tau^2=\left(\frac{\omega}{c}\right)^2 = \frac{1}{R^2}}$$

**精细结构常数**（升角）：

$$\alpha = \frac{\tau}{\kappa} = \frac{b}{\rho} = \tan\theta,\qquad \theta = \arctan\alpha$$

**质量本源**（由 E=mc²=ℏω 与 ω=c√(κ²+τ²)）：

$$m = \frac{\hbar\sqrt{\kappa^2+\tau^2}}{c}$$

> 验证要点：`v_⊥²+v_∥²=c²` 归一化、`√(κ²+τ²)=ω/c`、`α=tanθ` 均 S 级通过。
