# ROOT V125：原始观测预注册协议（未执行）

## 1. 冻结待检验假设

H0：GR + 标准地球多极/非引力模型，不含额外 Yukawa。

H1：在同一前向模拟中添加固定参数 `alpha=1/3, ell=124600m` 的线性未屏蔽吸引标量。地球径向密度采用可审计的已公开地球模型，形状因子的不确定性作为**预先声明**的系统误差处理。不能按结果改动参数来保护 H1。

## 2. 原始数据与模型约束

优先：GOCE EGG_NOM_2 和相应姿态、角速度、加速度校准记录；确认每一个处理阶段是否借助 `tr(E)=0`、强制保留 Laplace 谐函数、自动扣除 DC 或高通滤波。任何已经强制零迹的产品均不得直接用于 `tr(E) !=0` 的检验。

必须：查明通道零频与 0.1–5mHz 噪声/传递函数。在未完成校准之前不能把精密带宽内 `mE/sqrt(Hz)` 映射到低频非零迹的置信上界。

互补：不同高度卫星 GNSS/激光跟踪轨道，以及钟差/势差信息；将 GR、引力多极、海洋/固体潮、稀薄大气阻力、太阳/月球摄动、仪器参数、地球自转系与非惯性修正纳入同一联合解。

## 3. 预先注入-恢复检验

建立 `y=θs+Nβ+noise` 的设计矩阵。投影后 Fisher 信息

`Iθθ=s^T C^-1 (I-P_N,C) s`

如 I≈0，不允许汇报“α 已排除”；应汇报“此数据处理/频带不可识别”。先在 H0/H1 模拟中注入固定信号，再检验能否经过相同仪器模拟与数据处理恢复正确幅度。对 zero-trace 投影、高通滤波、低频漂移的损失必须定量公开。

## 4. 事先锁定的评价指标

- 完整联合似然/GLS 的 `Δχ²`、后验/置信区间及所用全部先验与协方差；
- H1 残差是否具有所预注册的高度、方位与时间依赖；
- 正样本与零样本的注入恢复与假阳性；
- 至少一个独立观测源（轨道或红移）的一致性；
- 失败时明确标记 H1 被排除或无法识别，而非事后换 `ell` 和 `alpha`。

## 5. 诚实的状态

**当前所有步骤均为设计方案；没有运行任何真实卫星联合拟合。**
