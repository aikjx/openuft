## 1. 审什么：判定册与两路来料

整理册的对象是**已存在的判定册**，不是新的物理候选。判定册定义为带 `final` 字段的 `_ALG_*_recompute_*.json`，共 `36` 册；report 共 `36` 份。历史册 report 命名不统一（`_ALG_*_recompute_report_日期.txt` 与 R25 起 `_ALG_*_日期_report.txt`），故按 `STEM = _ALG_(.+?)_recompute` 提取 stem 一一配对，禁硬匹配 `_report.txt`。

两路机拼**数据源互不引用**：`act` 走判定 JSON 的结构化 `final／verdict／guards`；`exp` 走 report 纯文本的行首锚定正则抽列。逐册比对得 mismatch `0`、缺字段 `0`、未配对 JSON `0`／report `0`。另有 `2` 份来料／外部锚 JSON 天然无 report，属预期结构，不是断链。

负对照：只改第一册 report 的 `final` 一个词，两路立刻报 mismatch `1`；这证明 `exp` 真读 report，而不是把 `act` 抄一遍充作独立来料（同源存档回验的惯用陷阱）。

## 3. 核心新发现：全维覆盖只需 4 册

把全链文本归到 12 个攻击面维度（方程层、自由度层、信息层、生成元层、代数层、求导层、统计层、量纲层、证据质量层、目录层、模拟层、力的统一），两路分别算维度命中矩阵：`act` 取自 report 前 2400 字，`exp` 取自 JSON 的 `title／verdict／key_numbers` 键名，两路矩阵相异 `29` 册（禁同源回验）。贪心 set cover 得覆盖全部 12 维的上界：**`act` 路 4 册、`exp` 路 6 册**，未被覆盖维度 `0`；阈值取 `n_books/2`。

`act` 路的极小覆盖集为：`fullchain_scope`、`vc_spiral`、`verdict_catalog`、`r25_cosmos_sim`。

每册平均命中 `4.16666667E+0` 维、最多 `8` 维；11 个维度至少有 2 册提及。模拟层仅 `1` 册、生成元层与证据质量层各 `5`／`5` 册，是全链最薄的维度。**结论**：所谓「全维」是文本覆盖度，不是 12 份独立证据；维度数不能当承重份数。

## 4. 全链「突破 0」的结构性：不是 36 份证据的合取

`act` 与 `exp` 两路宣称突破册数分别为 `0`／`0`，PRED 非零册数 `0`／`0`。逐册移除做结构性枚举：移除任一单册后，BREAK 读数仍为 `(0, 0)`，变化的册数 `0`，`structural_invariance = 1`。

因此不存在「移除几册就推翻」的有限最小割。全链结论是**同一份 46 锚实验来料在不同判据下的结构投影**：R20 的 χ² 阈值层、R22 的求导层、R23 的生成元层、R24 的代数可解性层、R25 的宇宙演化模拟层，各自在同一批输入上换了判据，而不是各自添了一份独立证据。这与 R14 的最小承重割、R17 的承重支点、R19 的最小翻转割、R21 的合取门割都是不同对象，不相加。
