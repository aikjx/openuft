## 01. 核心结论

> **加上 `h·f = c` 可以把半径与螺距都定标，但代价是总速度变成 √2·c —— 超光速 41.42%。**
>
> **『尺度确定』与『因果性』不可兼得。**

```
ωr  = c   ⇒ 横向速度 = c
h·f = c   ⇒ 轴向速度 u = c    （螺距 h = u/f ⇒ u = h·f）
v²  = (rω)² + u²
────────────────────────────────
⇒ v = √(c² + c²) = √2·c ≈ 1.4142135624 c
```

## 02. 附带结论：统一参数被锁死

完整关系组把螺距角锁死：

```
tan α = u/(rω) = c/c = 1  ⇒  α = 45°
τ/κ   = b/a = u/(rω) = 1  ⇒  κ = τ
```

v1 称 τ/κ 是『纯几何的统一参数』。完整组确实给出了它的**唯一值 1**，但该值只在超光速构型下取得。

## 03. 量纲口径冲突

`h` 在来料里有两种互斥读法：

| 读法 | 量纲 | 出处 | `h·f=c` 是否成立 |
|---|---|---|---|
| S（速度） | LT⁻¹ | v1 的 r⃗ = (...) + h t k | **否**（LT⁻² ≠ LT⁻¹） |
| P（螺距） | L | S12 的 p = uT | 是 |

v1 的轨迹方程要求 h 为速度，而 `h·f=c` 要求 h 为螺距 ⇒ **同一符号两种互斥量纲**。
（若来料显式声明 h 为螺距，则此项降级为符号标注问题；但超光速结论不受影响，它只依赖 u = h·f = c。）
