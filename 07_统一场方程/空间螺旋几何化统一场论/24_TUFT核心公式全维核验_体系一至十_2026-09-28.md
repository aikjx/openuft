## 1. 体系一 · 螺旋几何本体论 —— PASS（唯一整块通过的部分）

sympy 从 $\mathbf R(\theta)=(\rho\cos\theta,\rho\sin\theta,b\theta)$ 用
$\kappa=\frac{|R'\times R''|}{|R'|^3}$、$\tau=\frac{\det(R',R'',R''')}{|R'\times R''|^2}$ 直接算：

| 读数（`checks.S1_frenet_helix`） | 值 |
|---|---|
| `kappa_from_param` | `rho/(b**2 + rho**2)` |
| `tau_from_param` | `b/(b**2 + rho**2)` |
| `resid_kappa` / `resid_tau` | `0` / `0` |
| `mutant_resid_kappa` / `mutant_resid_tau` | `2*b**2*rho/(b**4 - rho**4)` / `2*b/(b**2 + rho**2)` |
| `ell_identity_resid` / `mutant_ell_resid` | `0` / `-b**2 - rho**2 + sqrt(b**2 + rho**2)` |

⇒ $\kappa=\rho/(\rho^2+b^2)$、$\tau=b/(\rho^2+b^2)$、$\ell=1/\sqrt{\kappa^2+\tau^2}$ **三条全部第一性复现**。
每个恒等式旁边都印了一枚"故意写错"的对照残差（分母改号、挠率改号、根号漏掉），三者均非零 ⇒ 上面那三个 `0`
不是"什么都没算"。**但**：$\kappa,\tau,\ell$ 只是曲线不变量，与物理无关；体系一的"每点作光速螺旋运动"是**诠释**，
本轮不可验算，维持 `01` 稿的评级。

## 2. 体系二 · α 的几何化与本源 —— 参数化 PASS、本源 FAIL，且 01A §3.2 自身有错

**(a) `α = τ/κ = b/ρ` PASS**：`checks.S2_alpha_and_ntwist.resid_tau_over_kappa_minus_b_over_rho = 0`。

**(b) N1（新增）· 同一个 θ 在三处指不同对象。** 总纲体系一把 θ 用作**螺旋参数**（$R(\theta)$ 的分量），
体系四用 $\cos^2\theta=\rho^2/\ell^2$；而 $\rho/\ell$ 沿螺旋线是**常数**，$\cos\theta$ 不是。仪器直接对此下了判据
（`checks.N1_theta_conflation`）：`resid_d_of_rho_over_ell_wrt_spiral_parameter = 0`（ρ/ℓ 与 θ 无关，恒等），
对照 `resid_d_of_cos_theta_wrt_spiral_parameter = -sin(theta)`（非零）。
只有把 θ 读成**倾角**时等式才成立：`cos_of_pitch = rho/sqrt(b**2 + rho**2)`、
`resid_cos_pitch_minus_rho_over_ell = 0`、`tan_of_pitch = b/rho`。
⇒ 结论：体系四的阴阳式与体系二的 $\alpha=\tan\theta$ 要求 θ＝倾角；体系一的 $b\theta$ 要求 θ＝弧参数。
**同一符号不能同时是两者**；这是 X 台账未登记的**符号复用**（记 N1），修法是把体系一的参数改记 $t$ 或 $\varphi$。
