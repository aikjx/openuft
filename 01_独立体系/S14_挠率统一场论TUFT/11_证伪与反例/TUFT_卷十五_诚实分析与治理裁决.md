# TUFT 卷十五 诚实分析与治理裁决（Kerr-EC 旋转黑洞 + 自旋-挠率耦合 QNM）

> 归属：`01_独立体系/S14_挠率统一场论TUFT`，阶段 `11_证伪与反例`。
> 审查对象：用户提交文档《TUFT｜卷十五：Kerr-Einstein-Cartan 旋转黑洞 + 自旋-挠率耦合 QNM 理论与数值框架》（含 §1–§12 论述与 §12 Jax+SciPy 附录代码）。
> 复算脚本：[`tuft_卷十五_kerr_clean_test.py`](../07_计算复现/源码/tuft_卷十五_kerr_clean_test.py)（numpy 1.24.3 / scipy 1.10.1 / Python 3.8.8）。
> 红线：数学自洽 ≠ 实验证实；文档主张须独立核验，不把声称当结论。

## 0. 一句话结论

卷十五的**论述组织是好的**（旋转黑洞扩展、角向分离、m-劈裂、a–T_B 简并性分析、四组可证伪判据均写得清楚），其**a–T_B 参数简并的诚实讨论是正向贡献**。但：
1. **附录代码原样非法 Python**（标识符混入 LaTeX 残片 `\(\mathbf{B}\)`/`\(\mathbf{A}\)` → `SyntaxError`），且 `eigs` 的 `sigma` 取在 ω 空间而本征值实为 ω²（移位空间错位）；
2. **修正后可运行，但 FDTD-PML 求解器仍抓箱模且完全丢失自旋依赖**——实测 `a=0/0.5/0.9` 的 `ω_real≈0.400` 几乎恒定（真实 Kerr 应 `0.374→0.414→0.567`），`Im ω≈+1e-4~3e-4`（阻尼被边界反射抹平），`|err|=9e-2…1.8e-1`；继承卷十四/R23 已证伪的数值失败；
3. **文档内部不一致**：PDE 求解器的挠率势 `V_tors` 给出的频移项比 §7 代理模型 `kR_schw=3880` 小 **4 个数量级**；
4. **最关键的张力**：本卷把 ringdown 重新当作挠率探针，但 TUFT 体系 **2026-09-30 审计已关闭 ringdown 窗口**（OPEN_v4：LIGO 排除 σ_abs=0 反射壁；挠率宏观尺度 R6 差 1e28）。卷十五未处理该张力。

**登记结论**：卷十五作为"旋转黑洞 + 自旋-挠率耦合的**方法学提案**"可保留，但其数值精度主张（§6 基准校验、§7 QNM 曲面）**不成立**，其物理探针主张（§8 修正 ringdown、§11 判据 D）与已关闭的 ringdown 窗口**存在未解决的冲突**。所有"挠率探测"结论须降为"若 ringdown 通道被重新开放"的条件命题。

## 1. 正向价值（应当保留的部分）

1. **旋转扩展方向正确**：真实引力波事件来自旋转黑洞，引入自旋 `a` 是卷十四静态 Schwarzschild-EC 的自然推广。
2. **角向分离与 m-劈裂是 genuine 新物理点**：§3 提出挠率项 `C1·a·m` 产生 `m` 依赖的频率偏移，在 `a→0` 自动退化为卷十四——这一"退化性检验"设计正确，是可证伪性的好结构。
3. **§9 参数简并性分析诚实且重要**：明确指出"增大 `a` 带来的频率升高可被增大 `T_B` 抵消"，单事件 ringdown 无法分离二者；提出多事件联合 + 普适 `T_B` 假设——这是贝叶斯可识别性分析的正确思路（尽管其先验假设本身可被证伪，见 §2.6）。
4. **§11 判据 D 可操作**：用"高自旋黑洞无 m-劈裂 + 多事件 T_B 与 0 兼容"作为排除条件，是可检验边界。

## 2. 批判性发现（独立复算证据）

### 2.1 附录代码存在两类真实缺陷（一类致命、一类逻辑）

| # | 缺陷 | 后果 |
|---|---|---|
| 1 | 标识符混入 LaTeX 残片：`def V_tors_kerr(r,\(a,m\),T_\(\mathbf{B}\))`、`\(\mathbf{A}\)=...`、`T_\(\mathbf{B}\)_list` 等 | **非法 Python**（`\(` 为转义、`\mathbf` 未定义），`python` 直接 `SyntaxError`，附录代码**原样无法 import**（与卷十四 `\(a=0\).0` 残片同族）|
| 2 | `V_kerr` 含 `a*m/omega` 项（omega 在分母），却用固定 `omega_ref` 装配矩阵后 `omega=sqrt(vals)` 求解——且附录 `eigs(A,M=B,sigma=omega_guess)` 的 `sigma` 取在 ω 空间，而本征值实为 ω² | 移位空间错位（同卷十四 bug #2）；装配与求解逻辑不自洽，需自洽迭代闭环 |

**复算处理**：本报告以下结果用"可运行洁净投影"——去除 LaTeX 残片、把 `sigma` 改到 ω² 空间（`sigma=Re(ω)²`）、并对非线性项加自洽迭代。**说明**：两类缺陷修正后求解器**能够运行并收敛**（Mode A 迭代 1~4 次收敛）；故下文判定重点不在"能否跑"，而在"跑出的数值是否为真实 QNM"（见 §2.2）。

### 2.2 修正后可运行，但 FDTD-PML 仍抓箱模，且**完全丢失自旋依赖**（决定性）

对 `a=0/0.5/0.9`（`l=2, m=2`）分别测：模式 A = 原稿非线性势（含 `a*m/omega`）；模式 B = 正则化势（去奇点）。文献参考（Berti 目录）随自旋上升：`0.37367→0.41380→0.56730`。

| a | 模式 A 数值 ω | 模式 B 数值 ω | 文献参考 ω (l=2,m=2) | 模式 B \|err\| |
|---|---|---|---|---|
| 0.0 | 0.40009 **+0.00008i** | 0.39789 **+0.00028i** | 0.37367 −0.08896i | 9.25e-2 |
| 0.5 | 0.40011 **+0.00007i** | 0.40170 **+0.00026i** | 0.41380 −0.08670i | 8.78e-2 |
| 0.9 | 0.40009 **+0.00004i** | 0.39901 **+0.00023i** | 0.56730 −0.07140i | 1.83e-1 |

**两条决定性证据**：

1. **`ω_real ≈ 0.400` 对**所有**自旋几乎恒定**（模式 A：0.40009/0.40011/0.40009；模式 B：0.39789/0.40170/0.39901）。真实 Kerr `ω_real` 应随 `a` 明显上升（0.374→0.414→0.567，升幅 52%）。求解器**完全丢失自旋 `a` 的物理依赖**——因为主导模是与 `a` 无关的箱/域模，`a` 只通过被淹没的细微项进入。这直接证伪"§7 QNM 复频率曲面（含 a 依赖）"。
2. **`Im ω ≈ +1e-4 ~ +3e-4`（近零且多为非物理正号）**：阻尼被 PML/有限域边界反射抹平，正是卷十四/R23 已诊断的"箱模"签名（`|Im ω|∝1/L`）。相对误差 24%–260%。

- **裁决**：§6 基准"误差 <2e-4 合格"与 §7"QNM 复频率曲面"均**未被代码支撑**，属未验证声称。此结论与卷十四 S14-C0072、体系审计 R23/R25 完全一致——朴素 FDTD/PML 只产箱模，要得真实 QNM 须用 Leaver 连分式（R25 已验证 4.46e-7）。

### 2.3 文档内部不一致：PDE 求解器 vs 代理模型差 4 个量级

- §7 代理模型：`ω_R = ω_R0 + kR(a,m)·T_B`，附录全局 `kR_schw = 3880.0`。
- 实测 PDE 求解器（`V_tors_kerr` 给出 `C0+C1·a·m` 包络项）：`dω_R/dT_B ≈ +9.58e-2`（每单位 T_B），在扫描上限 `T_B=1e-4` 处偏移仅 **+9.58e-6**（≈基模 0.003%）。
- `kR=3880` 在 `T_B=1e-4` 处偏移 **+0.388**（≈基模 100%），与"小线性微扰"叙事矛盾，且与 PDE 求解器实测差 **~4 个数量级**。
- 此外 `kR=3880` 本身量级荒谬：背景挠率振幅 `T_B~1e-4`（几何单位 1/M²）就把频率挪动 100%，意味着"微扰"已非微扰。该数值疑似卷十四同款 `388` LaTeX 残片放大的 10 倍误写（卷十四 审计记为 `388`→`3.88`）。

### 2.4 MCMC 架构性缺陷（同卷十四 bug #3 类）

- §12 `tuft_kerr_joint_model` 在 numpyro 模型内调用 `solve_kerr_qnm`（scipy.sparse.linalg.eigs，非 jax 可微）。NUTS 要求模型可 `jit`/可微，**此代码无法运行**（每次采样都建 1600×1600 矩阵 + ARPACK，且不可微）。
- `h_obs = jnp.zeros_like(t_obs)`、`Sn=1.2e-22`：观测 GW 数据全零，似然在 `A→0` 退化，T_B 不可约束——与卷十四 §2.2 bug #3 完全相同。
- `t_c_to_lc`：`t_c~Uniform(-3,1)`→`exp(t_c)*12 ∈ [0.6, 32]`，而 `obs_l ∈ [20,500]`（共动距离），阶跃 `obs_l>lc` **永远不触发** → `t_c–T_B` 关联在注入数据下**永远无法被检验**。
- 结论：§9 联合 MCMC "打破 a–T_B 简并"的**数值实现不存在可运行版**；现有代码是骨架，且含使关联不可检的退化设定。

### 2.5 §12 "入口"基准打印将误导

`__main__` 调 `solve_kerr_qnm(a=0.5, m=2, T_B=0.0)` 打印 `omega=...`——但①原样因 LaTeX 残片连 `import` 都失败；②即使去残片，该调用走原稿非线性势（Mode A），实测给出的是箱模 `ω≈0.4001+0.0001i`（而非文献 `0.4138-0.0867i`）。文档 §6 的基准"通过"是**未发生**的。

### 2.6 与 2026-09-30 审计已关闭 ringdown 窗口的张力（最关键）

README §三 与 claims S14-C0059~C0070（OPEN5/OPEN6/OPEN_v4，2026-09-30）记录：TUFT 四个实验窗口（g-2、EDM、β 跑动、**ringdown**）**全部关闭/排除**；ringdown 窗口关闭根因 =「σ_abs=0 反射壁非 TUFT 可导出结构，三尺度锚定差 26–79 数量级」（OPEN_v4）+ 挠率宏观尺度 R6 差 1e28。

卷十五的探针机制（`T_B` 背景挠率对 QNM 的线性微扰）**不同于** σ_abs=0 反射壁，故非同一窗口；但它仍落在"ringdown 作为挠率探针"这一已被 LIGO 排除的大类之下，且用 `T_B` 作自由唯象参数**回避**了 R6 的宏观尺度问题（代价："TUFT 启发式"而非"TUFT 第一性预言"）。§11 判据 D 若要用，须先回答"为何 ringdown 通道在 OPEN_v4 被排除后在此重新开放"——卷十五未处理此张力，属**论证缺口**。

## 4. 建议后续行动

1. **若要保留 QNM 数值精度主张**：用 Leaver 连分式（R25 已验证 4.46e-7）替换 FDTD-PML 求解器；FDTD 结果仅作示意并明确标注"箱模，非真实 QNM"。
2. **若要保留 a–T_B 简并分析**：须用可运行的 MCMC——把 (a, T_B)→(ωR, ωI) 的映射预计算为查找表/代理（用 Leaver 离线算），再在 numpyro 模型内插值；`h_obs` 须注入合成 ringdown 而非全零；`t_c→lc` 尺度须与 `obs_l` 范围匹配。
3. **须直面 ringdown 窗口已关闭**：在 §1/§11 显式写入"OPEN_v4 (2026-09-30) 已排除 ringdown 挠率探针；本卷假设若被 LIGO 多事件 m-劈裂非检测坐实，则自旋-挠率分支关闭"——把可证伪性落到实，而非回避。
4. **修正 §7 量级**：若保留代理模型，须令 `kR` 与 PDE 求解器 `V_tors` 的实测偏移自洽（~1e-1/单位 T_B，而非 3880）；或删除代理模型，直接以求解器输出为准。
5. **代码清理**：删除所有 `\(\mathbf{B}\)`/`\(\mathbf{A}\)` LaTeX 残片；把非线性 `a*m/omega` 项改为自洽迭代或分离常数近似；补 `if __name__=='__main__'` 的收敛守卫。
