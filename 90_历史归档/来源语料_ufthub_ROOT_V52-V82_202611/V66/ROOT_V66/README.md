## 开箱运行

- **查看交互模拟：** 双击 `web/index.html`，无需联网和服务器。包含 3D 数学透视螺旋、球形地球/理想磁偶极、诱导引力截止参数与第五力等效原理敏感性图。**渲染使用 Canvas2D 绘制三维坐标投影，不是 WebGL GPU 地球数字孪生。**
- **运行数学测试：** Python 3.10+，在项目根目录运行 `python run_all.py`，检查 V66 新测试以及打包的 V65/V64 历史回归测试；也可使用 `RUN_ALL.sh` 或 `RUN_ALL.bat`。
- **重算 CSV / PNG：** `python experiments/generate.py`。完整图表需要 `numpy scipy matplotlib`（已在本次制作环境验证）；数学主引擎 `src/root_v66.py` 不需外部库，实验脚本可在无 SciPy 时跳过 Bessel 独立积分而保留其他数据。
- **浏览器自动化：** `python experiments/browser_smoke.py`，需要可用 Playwright 与 Chromium；手动交互可以直接用浏览器打开 HTML。
- **前版追溯：** `archive/` 保存已验证路径的 V50—V65 研究 ZIP 历史版本，不代表它们全部结论正确。

## 新增数学问题的具体处理

1. **量纲修复：** 取 `x⁰=ct`，Einstein–Hilbert SI 作用量前因子为 `c³/(16πG)`，Einstein 场方程系数为 `8πG/c⁴`。
2. **微观模态：** 有螺旋相位的复 Klein–Gordon 场，在圆柱 Dirichlet 边界获得可积分能量，检验解析式与数值式。
3. **引力起源：** 热核诱导曲率项按 regulator 与耦合条件计算；展示为何 `N/ℓ²` 数据不足以决定 G 的微观来源。
4. **Cavendish 修复：** 标量—张量作用量中 `1/(8πF0)` 是张量耦合强度，一般与实际测试体的静态引力测量系数不同；增加了条件下 `G_Cav` 和 `PPN γ` 的计算。
5. **规范统一审核：** 明确 GR+SM+新增场相加，只是形式合并，未推导强/弱规范群、粒子谱或四力独立预测。
6. **精密验证：** 使用权威 CODATA、PDG、MICROSCOPE、Cassini、GW170817；程序输出以 `[MATH]`、`[TOY]`、`[FIT]` 标示。
7. **复现：** 每张示意图可由生成代码重算，所有模型数据和测试说明均打包。
