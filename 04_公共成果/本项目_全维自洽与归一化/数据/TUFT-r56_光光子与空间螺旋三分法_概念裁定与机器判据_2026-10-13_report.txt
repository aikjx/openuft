[C03] INFO Omega 的三条式子（c/L、c*sqrt(kappa^2+tau^2)、c*kappa/sin(theta)）是同一约束的三种写法，非三个独立预言

[C04] FAIL 【核心·对"自由光子"读法】四维加速度 a^mu != 0：类光但绝非测地线（正面机器证明）
  来料 §2 断言"上面这条螺旋类光曲线有四维加速度 a^mu != 0"，本册给出显式机器验证：a^mu = (0, -R*Omega^2*cos, -R*Omega^2*sin, 0)，故(i) |a| = R*Omega^2 = c^2*kappa（机器逐位）；(ii) a.u = 0（机器零）⇒ 加速度**垂直于**四速度，即类光曲线的定义性性质；(iii) a^2 = -R^2*Omega^4 < 0 ⇒ 在本册 (+---) 号约定下加速度**类空**；(iv) a^0 = 0 ⇒ 沿螺旋行进的共动标架中该加速度纯空间。⇒ 类光（a.u=0）但 a!=0，即它**是**一条合法的类光曲线，**不是**任何平坦时空中的测地线。测地线条件是 a^mu=0（用弧长或任意仿射参数），与 a.u=0 是两个不同条件；来料把二者区分清楚是正确的。补充：加速度矢量方向随方位角同步旋转（a_x:a_y = cos:sin），故曲率**每绕轴周期 2pi/Omega 转一整圈** ⇒ 是螺旋而非圆。

[C05] FAIL 【核心·协变判据】挠率可被有限 boost 精确清零（beta=cos(theta)），曲率恒正但随 beta->1 趋零
  沿柱轴做 boost（速度 beta*c）后横向半径 R 不变，螺距标度与弧长标度变换为 L'=gamma*(L-beta*H)、H'=gamma*(H-beta*L)，且 L'^2-H'^2=R^2 恒成立（机器零）。在此族内：kappa'=R/L'^2、tau'=H'/L'^2。**新读数一（最强非协变量）**：取 beta=cos(theta)=H/L，得 gamma=L/R，于是 L'=gamma*(L-H^2/L)=(L^2-H^2)/R=R（机器零）、H'=gamma*(H-H)=0（机器零）、tau'=0、kappa'=1/R、Omega'=c/R、v_z'=0 ⇒ **存在一个合法惯性系使挠率精确为零**。这比"挠率不是不变量"更强：**挠率可以被 boost 完全消掉**（对圆柱螺旋对称轴的 boost 即可）。⇒ 任何把 tau 当作协变内禀量（尤其 tau 与自旋/螺旋度挂钩）的读法，在 boost 下自毁。**新读数二（曲率的硬边界）**：kappa'=R/L'^2>0 对一切合法有限 beta 恒成立（R>0 是横向 boost 不变量），故**没有任何惯性系能把这条曲线变成直线** ⇒ 它是"非测地线"的协变说法（强于来料 §2 只在实验室系陈述的 a^mu!=0）。但 inf kappa'=0 在 beta->1 达成（beta*=2LH/(H^2+L^2) 使 kappa'=kappa，beta>beta* 后 kappa'<kappa）。**新读数三（必须警惕的极限混淆）**：beta->1 时 L'、H' 同发散，比值 kappa'/tau'=R/H'->0，螺旋被轴向拉伸成"极扁的螺旋"，视觉上收敛为沿 -z 的直线（v_z'->-c，kappa'->0）。⇒ **在光速极限（共动）系中，类光螺旋会伪装成自由光子的直线轨迹。**这正是"自由光子沿螺旋"这一误读最可能产生的极限来源，必须在体例中显式禁止在 beta->1 系中做曲率判据。注：本条与 r51 册 N14/N15 互补——N14 给出变换律并指出"非不变量"，本条给出"可被打到零"（tau）与"不能被打到零但可趋零"（kappa）的定量边界，且不重复其推导。

[C06] PASS 绕轴缠绕数在沿轴 boost 族内不变（螺旋的协变内容仅剩缠绕拓扑）
  类光曲线（无论其曲率是否为零）绕对称轴的总缠绕数 N=Delta(phi)/2pi 在沿轴 boost 下不变：boost 沿 z 轴，只重标度 z 与 t，不改变绕 z 的方位角。机器给出一周对应的方位角增量在 beta=0/0.3/0.6/0.9/cos(theta) 五点恒为 2*pi（机器零）。⇒ 结合 C05 的 tau 可清零、kappa 可趋零，得到一条干净的**分层结论**："螺旋"在惯性系变换下唯一稳定的读数是**缠绕拓扑**，而不是 kappa 或 tau 的具体数值。这为体例裁定提供了依据（见判定册第七节）：凡以 kappa/tau 的数值作为物理量的读法，必须同时声明参考系；而缠绕数是唯一可直接跨系引用的螺旋读数。

[C07] INFO 轴向速率边界：v_z=c*cos(theta)=cH/L，R>0 时严格小于 c；与 S02 三约束互斥定理的兼容性裁定

[C08] BOUNDARY R=0（螺旋退化为直线）处 Frenet–Serret 不适用：(kappa,tau)->(0,1/H) 的连续延拓值与直线的 (0,0) 定义值不一致

[C10] PASS 【核心·概念层】螺旋度 h=±1 与轨道角动量 l∈Z 是两个不同群的不同表示标签，机器可判定地区分

[C11] PASS 【核心·概念层】圆偏振的螺旋是**场矢量**现象（E 模恒定、E_z≡0、满足 div E=0），与空间轨迹螺旋机器可分
  对圆偏振 E=E0(cos phi, sin phi, 0)（phi=kz-omega_em t）机器验证：|E| 恒等于 E0（最大偏差 3.3022807447228263300204131E-61，机器零）、E_z 恒等于 0、E_x^2+E_y^2 = E0^2 恒成立 ⇒ 场矢量端点画在**垂直于传播方向的平面内的圆**上。因 E_z ≡ 0 且 E_x,E_y 只依赖 z 与 t，故 div E = 0 自动成立，满足自由真空横波条件。**与空间轨迹螺旋的可分判据（机器可判定）**：偏振矢量的旋转平面与传播方向 z 的点积恒为 0；而类光螺旋世界线的切矢与 z 的点积为 v_z = c*H/L = 2.6395859524363253100515002E+8 ≠ 0（R>0 时 cos(theta) 非零）。⇒ 二者在数学上是**不同对象**（一个是场矢量在横截面内的旋转，一个是含轴向分量的空间轨迹），机器可分。**这一区分正是库内第7章（S02）§7.3 的核心裁定**（"标准电动力学圆偏振：场值螺旋，不是真实空间质点轨迹"），本条为其提供**机器可分判据**，把该裁定从定性升级为可复算。

[C12] INFO 口径对照：螺旋相位（波前螺旋，l 个相位卷绕）、能流线螺旋、空间轨迹螺旋是三件不同的事，不可互相代入
  来稿 §3.2 已正确指出螺旋相位 e^{i l phi} 的螺旋是**相位波前**、中心有相位奇点、携带 l*hbar 的轨道角动量，而整束传播方向仍基本是直线。本条补齐第三层，避免与前两层混用：(1) **相位波前螺旋**：相位 arg = l*phi，绕轴一周期相位卷绕 |l| 次，对象是**波前**（等相位面），中心为相位奇点（|E|=0）；(2) **能流线螺旋**：涡旋光束的坡印廷矢量线可以是锥面/柱面螺旋，r51 册 N18 已机器验证 m 阶涡旋的能流线恰是半径 rho 的圆柱螺旋（S_phi/S_z = (m/rho)/k_z 与 z 无关，螺距标度 H = rho^2*k_z/m），**但其沿螺旋的速度是 v_E < c ⇒ 世界线类时而非类光**；(3) **空间轨迹螺旋**：本册审计对象（类光但非测地线，见 C04/C05）。⇒ 三者的"螺旋"分别住在**相位、场、粒子轨迹**三个不同对象上；其中只有第 (2) 类有真实实验实现（结构光/涡旋光束/波导模式），而它恰好是**类时**的（r51 N17：真空无源场 v_E/c<=1，等号仅当单平面波）。**裁定**：来稿 §3.2/§3.3 的表述与该分层一致，无需修改；但凡后续要把"螺旋"一词用于物理量，必须指明它属于上述哪一层。

[C13] BOUNDARY 类光世界线的"曲率/挠率"需协变算子：Frenet–Serret 需弧长参数而类光曲线 ds=0；不自推系数
  **方法论裁定（肯定来稿的做法）**：来稿把 Frenet–Serret 的 kappa/tau 用在**三维空间曲线** r(s)=(R cos(s/L), R sin(s/L), H s/L) 上（弧长参数 |r_s|=1），而把类光性声明在**四维世界线**上——这是正确的分工，本册全部判据沿用。**为什么必须这样分工**：Frenet–Serret 定理要求以弧长 s 参数化（|r_s|=1）；而类光世界线满足 ds^2=0，**不存在非零的四维弧长微元**，故"类光曲线的 Frenet 挠率"在黎曼几何意义下不是一个良定义的不变量。**双对照（机器验证，证明检验器可区分"不立"与"合法为零"）**：(a) 沿 z 的直线（r(u)=(0,0,H*u)，即 R=0）：r_u x r_uu = 0，公式返回 kappa=tau=None，**不立**（不是 0）；(b) 平面圆（r(u)=(R cos u, R sin u, 0)，即 pitch=0, R=1）：返回 kappa=1.0000000000000000000000000E+0、tau=0.0000000000000000000000000E-35，即 kappa=1/R、tau=0，**Frenet 标架存在且挠率合法为零**。⇒ 检验器能区分"挠率不立"与"挠率为零"，不是恒零检验器。平直时空类光测地线为直线，故其 Frenet 量落在情形 (a)（不立）；这与 r51 册 N19 的定性裁定一致，本条为其补上"不立 vs 合法零"的可分对照。**弯曲时空的协变算子（BOUNDARY，不自推）**：弯曲时空中类光测地线可以有非零的"扭转"，但它必须用 **Newman–Penrose 光学标架**（沿类光方向的 l^a, m^a, m̄^a）中纵向四极矩的投影来定义，而非 Frenet 挠率。**本册不给出该算子的具体表达式与系数**（未推导、不引未经核对的数值），登记为开放项。任何后续工作若要把本册 C04/C05 的 kappa/tau 与引力透镜类效应比较，必须先完成这一步换算，且必须声明换算口径。

  把本次与前两册的全部读数按证据强度分层，避免跨层引用：**L1 几何层（机器零，零信息量）**：kappa=R/L^2、tau=H/L^2、kappa^2+tau^2=1/L^2、Frenet–Serret 三方程、Omega=c/L、Omega!=c*kappa、有效域 R>0（r51 S01–S19 + 本册 C02/C02b/C03/C08）。**L2 类光层（机器零，但依赖 ds=c*dt 公设）**：|v|=c <=> dsigma^2=0、a.u=0（本册 C01/C04）。**L3 协变层（强判据）**：tau 可被 boost 精确清零、kappa 恒正但可趋零、缠绕数 boost 不变、轴向速率边界（本册 C05/C05b/C06/C07）。**L4 可实现层（物理否决）**：真空无源场 v_E/c<=1 等号仅单平面波 ⇒ 类光螺旋在真空 Maxwell 中不可实现；光学涡旋能流线是类时的（r51 N17/N18，本册 C12 引用）。**L5 概念层（本册）**：螺旋度 vs 角动量（C10）、圆偏振 vs 空间轨迹（C11）、三层"螺旋"口径（C12）、omega 三义（C09）。⇒ 结论：**来稿的核心判断"自由光子在真空中不沿空间螺旋轨迹运动"在 L3/L4/L5 三层同时成立**，且 L4 给出了"不是自由光子"的**物理**理由（不只是几何），L5 给出了"三个螺旋不可混同"的概念理由。**红线**：L1 层的机器零**不构成**任何物理支持；本册与前两册均不产生新物理，只固化已有判断并补上从未被显式登记的边界。
