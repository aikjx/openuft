## 一、一句话结论

r327 有三处**没有审过的假设**，本卷把它们逐个拆开：

1. r327 定理 D 说「`x = q+(n−1)/2 ∈ Z` ⟺ `q` 在 Freed–Witten 格上」，但那张格是**从 r325 借来的**（结构依赖 `c1(CP^n)=(n+1)H`、`w₂`、以及「D-brane 必须带 spin^c」这条**物理假设**）。本卷证明：**只需要两条更弱的输入** —— `q ∈ Q` 与 `n_R ∈ Z` —— 就能**独立**逼出同一张格。
2. r327 定理 E 用**四个支点**证「跳过 3」。本卷证明：换一个坐标（`k` 而不是 `x`），**四个塌成两个**，而且少的两个不是省掉的，是**被吸收**的。
3. 副产物：`(n−1)/2` 与 `(n+1)/2` 给出**同一张格**（差整数 1）⇒ 上指标只确定到**模 1 类**。

## 二、定理 A · 族数整性定理

```
x ∈ Q，n ≥ 1，C(x, n) ∈ Z   ⇒   x ∈ Z
```

### 证明（三行）

设 `x = a/b` 既约、`b ≥ 2`。取素数 `p | b`。则

```
C(a/b, n) = ∏_{i=0}^{n−1} (a − i b)  /  (b^n · n!)
```

每个因子 `a − i b ≡ a (mod p)`，而 `gcd(a,b)=1 ⇒ p ∤ a` ⇒ **整个分子与 `p` 互素**。但分母含 `b^n ⊇ p^{n v_p(b)}`，`n ≥ 1` ⇒ 约分后分母仍带 `p` ⇒ **不是整数**。∎

**这条证明不依赖 `n!` 的结构，也不依赖 `n` 有界** —— 它只用「分子与 `p` 互素的因子」这一个事实。

### 机检（三档，互相独立）

| 条目 | 内容 | 分母 | 结果 |
|---|---|---|---|
| `A01` | 非整有理点给整值的个数 | `n=1..10` × `b=2..8` × 既约 `\|a\| ≤ 20`，**1700** 点 | **1700**（全都不整，一个例外都没有） |
| `A02` | 反向：整点全给整值 | `n=1..10` × `x=−40..40`，**810** 组 | 非整 **0** 组 |
| `A05` | 加强：约分后分母**仍被 `p` 整除**（`p` = `b` 的最小素因子） | 同上 1700 点 | **1700/1700** |
| `A08` | 推到 `n = 12, 15`（远离 `A01` 的 `n ≤ 10`） | 分母 2..8 × 20 个素数分子 | **0** |

> **纪律落点**：`A01` 的 `exp` 是 `A_TOT`（1700）而不是 `0` —— 断言的是「**全部** 1700 个非整点都给非整值」，若样本为空这条会**立刻红**（守卫 `G12` 守分母非空）。这是「0 条即通过」的反面写法。

### 三条判别力对照

- `A06`（负对照）：把 `C(x,n)` 换成一次式 `2x`，在同批非整点上有 **20** 个整值（`x=1/2 → 1` 等）⇒ 定理 A 是**二项式特有**的，不是「有理点代入多项式就不整」这种废话。
- `A07`（诚实边界）：`n = 0` 时 `C(x,0) ≡ 1`，对**任何**有理 `x` 都整（**170/170**）⇒ 定理 A 需要 `n ≥ 1`。而 `n = 0` 恰好是「零代」的平凡情形（`CP⁰` = 一点）。
- `A04`（手算三值）：`C(1/2,2) = −1/8`、`C(1/2,3) = 1/16`、`C(3/2,2) = 3/8`，分母都带 2，与证明里的 `p=2` 一致。

## 三、定理 B · 格重建（不借 spin^c）

### 做法

不再「先假设格、再验证整性」，而是**反过来**：在 `q ∈ [−6,6]` 上按 **`1/4` 步长**（刻意比格更细，避免「按格取样」的循环）取 49 个候选，筛掉所有让 `C(q+(n−1)/2, n)` 不是整数的点，**剩下的就是格**。

### 结果

```
反解出的 q 集合  ===  r325 的 Freed–Witten 格（n 奇：Z；n 偶：Z+1/2）
```

- `B01`：逐 `n` 集合相等，**12/12**。
- `B02`：12 个 `n` 的**对称差 = 0** ⇒ 不是「大致相同」。
- `B03`（正向）：格上 **188** 个点**全部**给整数 `n_R`。
- `B04`（反向）：离格 **547** 个点给整数 `n_R` 的 **0** 个。

> `B03` 与 `B04` 缺一条只证了一半：`B03` 只说「格 ⊆ 整性」，`B04` 才说「整性 ⊆ 格」。

### 为什么这条是「假设更弱」而不是「换个说法」

| | r325 定理 A | 本卷定理 B |
|---|---|---|
| 输入 1 | `c1(CP^n) = (n+1)H` | `q ∈ Q`（通量量子化） |
| 输入 2 | `w₂ = c1 mod 2` | `n_R ∈ Z`（族数是整数） |
| 输入 3 | **D-brane 必须带 spin^c 结构**（物理假设） | —— |
| 结论 | 格 = `Z − (n+1)/2` | 格 = `Z − (n−1)/2`（同一张） |

`G17` 的源码级证据：B 组的代码（剥掉注释后 **2285** 字符）里，`chi_sheaf(` / `chern_cp(` / `todd_root(` / `ahat_A_` 的调用次数 **0** ⇒ 这条路径**没有碰任何示性类**。

> 所以判词里用 `ASSUMPTIONS-WEAKENED-SO-THE-RESULT-IS-STRENGTHENED`：**假设更弱 ⇒ 结论更强**。这不是把 r325 降级，是把它**加固**。

### 副产品 · 上指标只确定到模 1（如实登记一次失败）

首版的负对照写成「把偏移从 `(n−1)/2` 改成 `(n+1)/2` ⇒ 格必然变」——**失败了**，因为两者差 **1**，而整平移在格上是**不可见**的。

这条失败被转成正面结论（`B06`，12/12）：**`(n−1)/2` 与 `(n+1)/2` 反解出完全相同的格** ⇒ 决定格的只是偏移的**模 1 类**（整数还是半整数），不依赖具体取哪个。这正好解释了为什么 r325 的「移位」只有 **0 或 1/2** 两种情形。

`CTL5` 因此改成真正能测出来的对照：偏移差 **1/2**（`(n−1)/2 → n/2`）⇒ 奇偶翻转 ⇒ 格必须变（实测变）。

## 四、定理 C · 族数非负性（`n_R ≥ 0`）

族数不能是负的。这条约束在 `k < 0` 区上的效果**不对称**：

| | `k < 0` 区的点数 | 非零点数 | 符号 | 结论 |
|---|---|---|---|---|
| **奇 n** | 64 | **16** | **全负**（`−C(−k−1,n)`） | **非物理** ⇒ 砍掉 |
| **偶 n** | 56 | **12** | **全正**（`+C(−k−1,n)`） | 物理 ⇒ 一刀不砍 |

- `C01`：奇 `n` 的非零点 **16/16 全负**。
- `C02`：偶 `n` 的非零点 **12/12 全正**，另 44 个为**零**（`k ≤ −n−1` 时 `C(−k−1,n)=0`）。
- `C03`：FW 格上负 `n_R` 共 **21** 个 —— 奇 `n` 占 21、偶 `n` 占 **0**。

> **两个必须说清楚的点**：
> ① 这一区**大部分是零不是负**（64 个里只有 16 个负）—— 若只报「奇 n 的 k<0 全非物理」而不报分母，会让人以为砍掉了 64 个。
> ② 非负性**不砍任何解**（`C04`：三个解的 `n_R` 都是 `+3`）⇒ 本卷不主张「非负性是必要的」，只主张它是**免费的**。
> ③ `C05`：把 `≥ 0` 换成 `> 0` 也不砍解 ⇒ 两者在这题上等价，如实登记。

## 五、定理 D · k 坐标：四支点塌成两支点

### 换坐标

```
x = q + (n−1)/2          （r327 用的：让二项式上指标为整数的坐标）
k = q − (n+1)/2 = x − n  （本卷用的：让线丛 O(k) 成为整对象的坐标）
```

`D01`：`k = x − n`，逐格点（188 个）失配 **0**。两个坐标只差**常数**，但这个常数的**方向**决定了证明长度。

### 统一形式

```
n_R = σ · C(M, n),      M = { k + n   (k ≥ 0)
                            { −k − 1  (k < 0)
                        σ = +1（k ≥ 0 或 n 偶），否则 −1
```

- `D02`：`k ≥ 0` 支 `n_R = C(k+n, n)`，失配 **0**。
- `D03`：`k ≤ −1` 支 `n_R = (−1)^n C(−k−1, n)`，失配 **0**。
- `D04`：统一形式，失配 **0**。
- `D11`：`M` 的**值域没有洞** —— `k≥0` 给 `M ∈ [n, n+40]`、`k<0` 给 `M ∈ [0, 39]`，并起来恰是 `M ∈ [0, n+40]`，逐 `n` 不等者 **0**。

### 关键一行

```
n_R ≠ 0   ⟺   M ≥ n
```

`D05`：失配 **0**（非零格点全体）。

**这一行把零段吃掉了**。r327 的支点③「`0 ≤ x < n` ⇒ `C=0`」在这里**不是一条支点，是 `M<n` 的一句同义话**。

### 只需要的两条支点

**① 单调**：`C(M+1,n) − C(M,n) = C(M,n−1) = M!/((n−1)!(M−n+1)!) > 0`，`M ≥ n ≥ 1`。
`D07`：`n=1..15` × `M=n..n+40`（**615** 组）逐点核这条**恒等式**，失配 **0**，正性由右端显式公式给出。

**② 端点跳跃**：`C(n,n) = 1 < 3 < n+1 = C(n+1,n)` 对 `n ≥ 3`。
`D08`：`n = 3..15` 反例 **0** 个。

严格递增 + 相邻值跨越 3 ⇒ 中间没有整数落点 ⇒ **跳过 3**。`D06`：`n=1..15` × `M=n..n+60`（**915** 组）给出 3 而 `n ≥ 3` 的 = **0**。

### 解集（等价性门）

`D09`：`n=1, q=3`；`n=2, q=±5/2` —— **3 个，与 r327 相同**。换坐标若改变了结论，那是算错，不是简化。

`G16` 逐个 `q` 值比对：`{(1,3), (2,−5/2), (2,5/2)}` === r327 的解集。

> 注意 `n=2` 的两个解在 `M` 坐标下是**同一个 `M=3`** 的两次实现：`k=1`（`q=5/2`）与 `k=−4`（`q=−5/2`，此时 `M = −k−1 = 3`）。所以「两个解」其实是「同一支点的两次命中」—— 这是 `S2 ∧ S4 = 3` 的几何来源。

## 六、定理 E · r327 的支点③④是支点①的两个影子

| r327 的支点 | 在 `M` 坐标下是什么 | 机检 |
|---|---|---|
| ③ `0 ≤ x < n` ⇒ `C = 0` | `M = n−x−1 < n` ⇒ `C(M,n) = 0` | `E02`：失配 **0** |
| ④ `x < 0`（负整数支） | `M = n−x−1 ≥ n`（因 `x<0`）⇒ **落进支点①** | `E03`：`x=−40..−1` 全部 `M ≥ n`，落在 `M<n` 的 **0** 个 |

`E01` 顺带登记一个小事实：`M = x` 只在 `x = (n−1)/2` 处成立 ⇒ 巧合次数 = 奇数 `n` 的个数（**8**）。所以 `M` 不是 `x` 的别名，它是**把 x 的负半轴折回正半轴的反射坐标** —— 这正是它能吸收支点④的原因。

> **这是简化而不是修正**：解集不变（`E04` = 3）。本卷没有推翻 r327 的任何结论，只是指出它的证明**用了四个支点做两个支点的事**。
> 方法论落点（`E05`）：x 坐标把「负半轴」和「正半轴」切成两段，k 坐标把它们**折成一段**。**选坐标的自由度就是证明长度的自由度。**

## 九、诚实边界（六条）

1. **只做算术，不做动力学**。整性定理是纯算术；它不解释为什么取 `CP²`，也不解释为什么要通量。
2. **格的唯一性只到模 1**。`(n−1)/2` 与 `(n+1)/2` 给同一张格（`B06`）⇒ 「上指标」不是被唯一确定的，被确定的是它的**模 1 类**。
3. **非负性只对奇 `n` 有杀伤**（`C02`：偶 `n` 的 `k<0` 区全正，一刀不砍）。本卷不主张它对结论有贡献。
4. **「跳过 3」仍是 r327 的定理，本卷只改证明长度**。解集不变（`G16`）。
5. **`CP^n` 之外未查**。整性定理对任何 `n` 成立，但「`n_R = C(x,n)`」这个闭式只在 `CP^n` 上成立（r327 已界）。
6. **全 `Fraction` 精确**，`Decimal prec=60` 仅格式化；无随机成分（`G05` 行首正则守）。
