## 一、判决主文

本庭审理的问题是：**`q = 3` 是被什么选定的？**

上一卷（r319）的答案是一个「悬置」：它证明了 `CP¹` 配 `q = 3` 精确给出三代，
但没说清为什么是这个整数，并把原因归到「本卷只做了量子化，没做稳定性」。

本卷做了两件事——重查量子化、真算稳定性——结论是：

1. **量子化那一半查出来是错的。** r319 用的是 `q ∈ Z`。但 `CP^n` 的通量格由 Freed–Witten 条件决定，
   而 `CP^n` 是 spin **当且仅当 `n` 为奇**。`CP²` 不是 spin，其通量格是 **`Z + 1/2`**，
   **整数在那里根本不是合法通量**。
2. **在这一格上，`n_R = 3` 的解不止一个。** `CP²` 配 `q = ±5/2` 精确给 `25/8 − 1/8 = 3`。
   ⇒ r319「`CP¹` 是唯一真空」**判负撤回**（其内部推理无误，前提过窄）。
3. **稳定性那一半算完是空的。** slope / DUY / HYM / D 项 / tadpole / 模稳定化，
   对 rank-1 线丛的 `q` 给出的**独立约束数 = 0**。
   最锋利的一条：给出三代的几何恰是实维 2 的 `CP¹`，
   而 `F∧F` 在 2 维流形上**恒等于零** ⇒ **tadpole 在这个几何上信息量恰好为零**。
4. **于是「`q` 由什么选定」这个问题本身要改。** 在 `CP¹` 上 `n_R(q) = q` 是恒等式，
   `n_R = 3` 与 `q = 3` 是同一句话的两种写法 ⇒ 该路线**结构性无法回答**。
   正确的问题是：**`n_R = 3` 的解集有多大、按什么排序**。

**因此：`q` 没有被选定，它是自由拓扑输入。三代仍是输入。**

## 二、为什么这一卷值得单独立册

因为它是本链上**第一次由后一卷撤回前一卷的正面结论**，而且撤回的理由不是「算错了」，
而是「**口径选错了**」。

前八卷（r292 / r294 / r295 / r296 / r302 / r305 / r307 / r309 / r318 / r319）的相互否决，
全部是「前提太强」或「范围太窄」的限定；本卷第一次出现这样的情形：

> 一个被当作**几何事实**报出去的「唯一性」，其实是**量子化口径的产物**。

这件事的方法论价值高于结论本身：**凡报「唯一性」，必须报它是在哪张格上唯一。**
一张格换成另一张，唯一就变成二选一——而二选一里的「更经济」那个，恰好不是原来那个。

## 三、定理 A · 通量格由 spin 性决定

`c₁(CP^n) = (n+1)H`，`w₂ = c₁ mod 2`，故 `CP^n` 是 spin **当且仅当 `n` 奇**。
非自旋圈上 D-brane 带 spin^c 结构，`[F] ∈ H²(Z) + c₁/2`：

| `n` | `c₁` | spin | 移位 | 格 |
|---|---|---|---|---|
| 1 | 2H | 是 | 0 | `Z` |
| 2 | 3H | 否 | **1/2** | `Z + 1/2` |
| 3 | 4H | 是 | 0 | `Z` |
| 4 | 5H | 否 | **1/2** | `Z + 1/2` |
| 5 | 6H | 是 | 0 | `Z` |
| 6 | 7H | 否 | **1/2** | `Z + 1/2` |
| 7 | 8H | 是 | 0 | `Z` |

`A01–A05` 逐条机检；`|q| ≤ 4` 时 `CP²` 的格是 `{±1/2, ±3/2, ±5/2, ±7/2}`（8 个），**无整数**。

**推论**：`CP¹` 的 `q = 3` 合法**只因为** `CP¹` 是 spin（`A14`：移位 0）。
两张格在 `n = 1` 上重合，所以从 `CP¹` 这一个例子上**看不出格的差别**——这正是 r319 踩空的地方。

## 四、定理 B · 解集的真实大小

`n_R(q) = Σ_j a_j q^{n−j}/(n−j)!`（`Â` 的 `H` 幂次恒偶 ⇒ 6 阶截断对 `n ≤ 7` **精确**，`A15`）。

| `n` | naive `Z` | Freed–Witten 格 |
|---|---|---|
| 1 | `[3]` | `[3]` |
| 2 | `[]` | **`[−5/2, +5/2]`** |
| 3 | `[]` | `[]` |
| 4 | `[]` | `[]` |
| 5 | `[]` | `[]` |
| 6 | `[]` | `[]` |
| 7 | `[]` | `[]` |

核心一行（`A06`，Fraction 精确）：

```
n_R(CP², 5/2) = (5/2)²/2 − 1/8 = 25/8 − 1/8 = 3
```

### 撤回的范围

| r319 定理 AB 的分句 | 本卷处置 |
|---|---|
| `n_R(q) = Σ_j a_j q^{n−j}/(n−j)!` | **保留** |
| `CP²` 上整数 `q` 无解 | **保留**（`A08` 复现，解集确为空） |
| 「**只有** `CP¹` 有整数解」 | **保留**（在 `q ∈ Z` 前提下成立） |
| 「**`CP¹` 是唯一真空**」 | **撤回**——正确格上解集为 3 |

**撤回的精确表述**：不是「r319 算错」，而是「r319 的唯一性**依赖一张未经论证的格**，
而物理上正确的格在 `n` 偶时是半整数格」。

### 计数分列（按「退化重复 ≠ 多解」纪律）

| 量 | 值 |
|---|---|
| 总解数（计符号） | 3 |
| 不同 `\|q\|` | 2（`3` 与 `5/2`） |
| 不同几何 | 2（`CP¹`, `CP²`） |
| 最小 `\|q\|` | `5/2`（在 `CP²`） |

### 挡住一个必然的反驳（`A17`）

`q² = 25/4` 非整数**不**违反电荷量子化：总诱导电荷 `= ∫[F∧F/2 − p₁/24] = 25/8 − 3/24 = 3`，整数。
`Â` 修正恰好补上 `1/8`。半整数通量与整数族数**自洽**。

| 机制 | 读出 | 约束 |

⇒ 判据是活的；`q` 上的零是**结构性**的，不是工具失灵。

## 六、定理 D · `CP¹` 上「选定 `q`」与「选定三代」是同一句话

`n_R(q) = q` 是恒等式（`C01`：`q = −20..20` 逐点 41/41）。于是：

| 检验 | 读出 | 含义 |
|---|---|---|
| 反向可及性 `N = 1..12` | **12/12** | 没有 `N` 被排除 ⇒ 判别力为 0 |
| `N` 无解个数 | 0 | 三代不是被**筛**出来的 |
| 非零系数个数（`CP¹` / `CP²`） | 1 / 2 | 一次单根 vs 二次两根 |
| 每个 `N` 对应几个 `q` | 恰好 1 | 这里的「唯一性」是**零信息** |

**结论**：在 `CP¹` 上问题无内容可判。`n_R = 3` 不是被推出的，是被**写进去**的。

## 七、定理 E · 问题倒置

> 不是「什么选 `q`」，而是「`n_R = 3` 的解集有多大、按什么排序」。

解集 `= {CP¹, q=3} ∪ {CP², q=±5/2}`，最小 `|q| = 5/2` 在 `CP²`。

**本庭对「更经济 ⇒ 是真空」的主张不予支持**：通量是拓扑量子数，不进能量，
**没有任何动力学理由要求 `|q|` 极小**。`5/2 < 3` 只是一个有序关系，不是选择判据。
报告它 ≠ 主张它——这一条写进 `D05` 作为自我否定。
