# TUFT-r358 · 整性集的精确结构

**攻靶**：`X-R339-2`（非陪集的机制）+ `X-R346-2`（额外点的存在判据），并压 `X-R346-1`（周期界）。

`P(c+m) = Σ_i b_i(c) C(m,i)`（Vandermonde）。一旦有 `b`，陪集的命运就被 `n+1` 个数完全决定。

## 一、一句话结论

**整性集 `S` 被完全刻画：`S = Z ∪（每个陪集至多一条公差 `D(c)` 的等差级数）`。**
判定一个陪集是「整段 / 部分 / 空」**只需要 `n+1` 个值**（定理 E′），而部分陪集的最小周期
**实测恰等于 `D(c) = lcm_i den b_i(c)`**（定理 G），一个周期内**恰 1 个整点**（定理 F）。
r339 看到的「非陪集」因此有了机制：**它只是「`Z` 与一条公差 4 的等差级数之并」**。
另外，固定窗口法在原理上不可靠——`D` 可达 **3.58×10⁷**，任何小窗口都会把真命题看成空集。

## 二、方法：把陪集上的多项式整个算出来

```
P(k) = Σ_j a_j C(k,j)                      （Newton 基，a_j = Δ^j P(0)）
Vandermonde:  C(c+m, j) = Σ_i C(c, j−i) C(m, i)
⇒  P(c+m) = Σ_i b_i(c) C(m,i),    b_i(c) = Σ_{j≥i} a_j C(c, j−i)
```

这一步把问题从「在网格上取样」变成「解析地知道整个陪集」：

| 旧办法（r339/r346） | 本卷 |
|---|---|
| 在 `(1/24)Z` 或 `[-6,6]` 上取样 | 一次算出 `b`，陪集命运由 `b` 决定 |
| 周期靠观察点间距 | 周期有可证上界 `D·n!`，实测等号 `N = D` |
| 「空」与「没看见」无法区分 | 「空」= `f(m) ≡ 0 (mod D)` 无解，是**可判定**的 |

**整数化（本卷的计算核心）**：令 `D = lcm_i den b_i(c)`、`β_i = D·b_i(c) ∈ Z`，则

```
Q_c(m) := P(c+m) ∈ Z   ⟺   f(m) := Σ_i β_i C(m,i) ≡ 0 (mod D)
```

右边是**纯整数**运算，比 `Fraction` 快一个量级，也是所有精确判定的基础。

## 三、定理 E′：只需 `n+1` 个值

**命题**：`c + Z ⊆ S ⟺ P(c), P(c+1), …, P(c+n) ∈ Z`。

**证明**：设 `Q(m) = P(c+m)`。Newton 系数 `b_i = Δ^i Q(0) = Σ_t (−1)^{i−t} C(i,t) Q(t)`
只用到 `Q(0), …, Q(i) ⊆ Q(0), …, Q(n)`。若这 `n+1` 个值全整，则所有 `b_i ∈ Z`，
再由 `C(m,i) ∈ Z`（`m` 为整数）得 `Q(m) ∈ Z` 对一切 `m` 成立。∎

**`n+1` 不可减**（`A06`、`CTL10`）：`Q(m) = C(m,n)/2` 在 `m = 0…n−1` 上全整，而
`Q(n) = 1/2 ∉ Z` ⇒ 少看一个值就会把「部分」误判成「整段`（4/4` 命中）。

**机检**：`A01` Vandermonde 主校验 **395** 个 (组,陪集,平移) 组合，左（td 级数算 `χ`）右（`Σ b_i C(m,i)`）
**失配 0**；`A02` 判据 vs `b` 全整，**304** 个已判定陪集一致率 100%。

## 五、定理 G：周期

**可证上界**：`N | D·n!`。

```
f(m+H) = Σ_i Δ^i f(m) · C(H,i)，  H = D·n!
i! | n!  ⇒  H/i! = D·(n!/i!) ∈ D·Z  ⇒  C(H,i) ≡ 0 (mod D)
Δ^i f 整值  ⇒  f(m+H) ≡ f(m) (mod D)
```

**实测是等号**：`B02` **11/11** 个可精确测定的部分陪集上，最小周期 **恰好等于 `D`**。
（`CTL4` 方向性对照：把平移换成 `D·n! − 1`，一致性立刻崩掉 **0/220** ⇒ `B01` 不是恒绿。）

**界的压缩（`B04`，`X-R346-1` 的答案）**：

| | 界 | 备注 |
|---|---|---|
| r346 | `(M^n n!)²` | 分母谱层面的粗界 |
| 本卷（可证） | `D·n!` | 且 `D | M^n n!` ⇒ `≤ M^n (n!)²` |
| 本卷（实测） | `N = D` | **等式**，疑为真界 |

实测最大压缩倍数 **14 117 880 倍**（`B04`，304 个陪集上的 `old/new` 最大值）。
**注意 `N | M^n` 早被 r346 否证**（`(5,2)` 的 `N=64 > M^n=32`），本卷的 `D` 才是那个真量。

**方向性提醒**：`D·n!` 是**已证**的，`N = D` 是**实测**的。本卷不把后者说成定理。

## 六、定理 F：单剩余类

每个部分陪集在一个周期内**恰 1 个整点**（`C01` **11/11**）⇒ `S ∩ (c+Z)` 是**一条**等差级数，
公差 `= D`。于是

```
S = Z  ∪  ⋃_{c} ( 一条公差 D(c) 的等差级数 )      每个陪集至多贡献一条
```

**分类器自检（`C02`）**：`C(m,2)/2` 的解集是 `{0,1} mod 4`，是**两**条 AP ⇒
分类器必须报 2。它报 2，说明「报 1」不是分类器的默认行为，`C01` 的 11/11 才有意义。

**但判别力为 0（`C03`）**：随机整值多项式的部分解集 **265** 个里，**265** 个都是单剩余类
⇒ 「单剩余类」对 `χ` **没有判别力**，按本库门禁**不得当判据用**，只能当**结构陈述**。
判据本身不是恒真（`C04`：`C(m,2)/2` 给 2 类），只是随机样本碰不到反例。

## 八、否证一个诱惑：窗口法不可靠（`D03`）

r339 在 `[-6,6]` 上看到 `(5,2)` 只有 1 个孤立点 `-5/2`，本卷给出解释：`D = 64`，
整点间距 64，窗口里自然只剩 1 个。更严重的是——**11 个部分陪集里有 6 个 `D > 12`**，
而 UND 区的 `D` 高达 **3.58×10⁷**：窗口法不只「看不全」，它在原理上会把真命题判成空集。

> **纪律**：凡用有限窗口判定「某陪集为空」，必须同时报窗口长度与 `D` 的量级比较；
> 窗口 `< 2D` 时，「空」这个结论不成立。

## 十、判据与方法（沉淀给后续卷）

1. **先做 Vandermonde，再谈取样**。把 `P(c+m)` 展成 `Σ b_i C(m,i)` 之后，
   「整段 / 部分 / 空」都变成 `b` 的算术性质，与取样窗口无关。
2. **整数化**：`β_i = D·b_i`、`f(m) ≡ 0 (mod D)`。纯整数、快一个量级、且让判定可证。
3. **最小周期不能用 gap 的 gcd 求**。解集若是**多条** AP，gcd 会低估
   （`C(m,2) mod 2` 的解集 `{0,1}` 的 gcd 是 1，真周期是 4，类是 2）。
   正解是「最小正平移使解集不变」+「类数 = |S|·N/P」。
4. **「未钉住」≠「从任意可行点翻转都安全」**。位 2（`S3`）未钉住，但在 `S2=0` 的基准组合上
   单独翻它会违反 `S3⇒S2`（首跑 `CTL13` 就是这样误报 4/5）。
5. **凡报「某陪集为空」，必须报 `D`**；`D` 大于窗口时该结论作废。
