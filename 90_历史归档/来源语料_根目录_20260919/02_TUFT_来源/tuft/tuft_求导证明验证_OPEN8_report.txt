== V2. 圆参数化恒等 ==

== V3. 比值关系 τ/κ = tanθ ==

== V4–V6. 核心不对称性：g-2 与 EDM 对 Ω 的依赖 ==

  EDM ∝ κτ = Omega**2*sin(2*theta)/2
  ∂(g-2)/∂Ω   = 0
  ∂(EDM)/∂Ω   = Omega*sin(2*theta)

== V7. 重标度不变性 Ω → λΩ ==

  g-2(λΩ)/g-2(Ω) = 1

== V8. 角度 θ 只提供 O(1) 因子 ==

  在 θ0=arctan(0.00202) 处：cos2θ = 0.999991839233299 ≈ 1 ⇒ ∂(κτ)/∂θ ≈ Ω²
