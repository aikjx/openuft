# 附录 A｜空间光速螺旋：三维冲突、五维可实现版本及质量谱缺口

## A1. 三维柱面螺旋的硬约束

取 \(\mathbf r(t)=(a\cos\omega t,a\sin\omega t,pt)\)，则

\[
\dot{\mathbf r}=(-a\omega\sin\omega t,a\omega\cos\omega t,p),\qquad
|\dot{\mathbf r}|^2=(a\omega)^2+p^2.
\]

若把 \(v_\theta=a\omega=c\) 与 \(v_z=\beta c\) 同时解释为**同一三维物理轨迹的速度分量**，则 \(v_{3D}=c\sqrt{1+\beta^2}\)，对任何 \(\beta\ne0\) 都超光速；这与狭义相对论物质信号传播相冲突。若轴向行进速度 \(p=c\)，同时要求总速率 \(c\)，则 \(a\omega=0\)，非退化的三维螺旋不可能存在。

这不证明“内部运动”任何概念绝对错误，只排除了**把两个正交三维速度分量都照字面赋值为 c 和 \(\beta c\)** 的写法。若一个速度是相位速度、内部坐标速度或不可观测额外维度的参数，则必须重新给出数学空间、可观测性与动力学，不能直接套用三维速度加法。

## A2. 一个不矛盾、但不是原创统一论的示例：五维零测地线

考虑平直五维 \(\mathbb R^{1,3}\times S^1\)，定义环形额外维度 \(y\equiv y+2\pi R_5\)，线元

\[
 ds_5^2=-c^2dt^2+d\mathbf x^2+dy^2.
\]

五维零线元条件 \(ds_5^2=0\) 对坐标时间给出

\[
\boxed{v_{3D}^2+v_y^2=c^2}.
\]

于是 \(v_{3D}<c\) 与 \(v_y>0\) 可以同时成立，且总“五维空间速度”形式上为 c。这是已知 Kaluza–Klein 类型构造的**玩具示例**，并非对 ROOT 公设的独立证明；额外维度的物理存在尚未证实。

### A2.1 质量来自额外维度动量的谱

五维无质量模满足

\[
E^2=c^2(\mathbf p^2+p_y^2),\quad p_y=\frac{n\hbar}{R_5},\quad n\in\mathbb Z.
\]

与四维色散关系 \(E^2=c^2\mathbf p^2+m_n^2c^4\) 比较，得到

\[
\boxed{m_n=\frac{|n|\hbar}{cR_5}}.
\]

这是一个具有明确动态与量纲背景的“内部运动生成有效质量”的数学桥梁，相比单独写 \(m=\hbar/(cr)\) 更清楚：当 \(n=1\) 时它**仍需额外给定**紧化半径 \(R_5\)。若强行令最低非零模等于电子，则 \(R_5=\hbar/(m_ec)\approx3.86\times10^{-13}\) m ——这只是用测量电子质量反定半径，不是预测电子质量。

### A2.2 最简同半径整数谱的反例

如果错误地要求电子、质子都完全是**同一个圆维度纯 KK 质量模**，且最低电子模取 \(n_e=1\)，则 \(m_p/m_e\) 必须是整数 \(|n_p|\)。CODATA 2022 的实测质量比为 \(1836.152673426(32)\)，显然不是整数。特别是质子属于 QCD 复合束缚态，因此这个反例**只否定错误的“纯单圆整数质量谱解释”**，不否定有额外维度及 QCD 复合能的更复杂模型。

### A2.3 四力统一仍缺失

要让五维玩具模型解释真实世界，还必须证明：

1. 四维 Lorentz 协变及相容的局域规范变换；
2. 电子为何是自旋 1/2，且具有正确的反粒子、磁矩与费米统计；
3. 为什么存在手征 SU(2)L 弱相互作用、色 SU(3)c、已测规范耦合；
4. 粒子质量、混合角、振荡、质子作为 QCD 束缚态的结构；
5. 不产生与实验冲突的低能 KK 激发谱、第五力和紧化引起的 Lorentz/等效原理偏离；
6. 量子场论的规范异常消除及高能一致性。

没有这些，\(ds_5^2=0\) 仅是一个可行的几何解释候选，不是四力统一理论。

## A3. ROOT 可执行的下一步理论检验

以规范不变的作用量而非口头“螺旋运动”作为第一步：设场 \(\Psi(x,y)\) 是五维 Lorentz 标量或 spinor，写出 \(S_5=\int d^4x\,dy\sqrt{-g_5}\,\mathcal L_5\)，进行 Fourier 模分解 \(\Psi=\sum_n \psi_n(x)e^{iny/R_5}\)，积分掉 y 后检验是否得到上述谱、正确传播子及与 4D 的运动学对应。再尝试超越玩具模型引入自旋与真实规范表示，同时让模型能被实验否定。
