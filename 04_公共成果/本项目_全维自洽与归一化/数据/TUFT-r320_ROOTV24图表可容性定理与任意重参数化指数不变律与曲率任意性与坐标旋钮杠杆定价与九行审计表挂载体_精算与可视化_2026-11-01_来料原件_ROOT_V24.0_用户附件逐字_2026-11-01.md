# ROOT V24.0｜精细结构常数第一性原理攻坚：固定点的真假判别

这轮找到一个此前 V1—V23 没有充分解决的关键问题：一个理论算出接近 \\(1/137\\) 的固定点，不一定意味着它预测了物理精细结构常数。

我已经实际完成符号证明和 90 位高精度数值检验，得到一个非常明确的反例：

原始动力学固定点

# 1/150

仅改变耦合变量后的固定点

# 1/137

两个数来自完全相同的动力学系统，没有改变任何物理可观测量。

## 一、严格求导：为什么可以“算出 137”，却没有预测 α？

构造一个具有非零紫外吸引固定点的模型：

\\[ \frac{du}{d\ln\mu}=Au-Bu^2 \\]

选取数学示例参数：

\\[ A=\frac1{50},\qquad B=3 \\]

求固定点：

\\[ \boxed{u\_\*=\frac AB=\frac1{150}} \\]

现在作可逆变量变换：

\\[ \boxed{v=\frac{u}{1-13u}} \\]

通过链式法则：

\\[ \beta_v=\frac{dv}{du}\beta_u \\]

得到：

\\[ \boxed{ \frac{dv}{d\ln\mu} =\frac1{50}v-\frac{137}{50}v^2 } \\]

所以新变量的非零固定点为：

\\[ \boxed{v\_\*=\frac1{137}} \\]

但是，稳定性特征值并没有改变：

\\[ \boxed{ \beta_u'(u\_\*)=\beta_v'(v\_\*)=-\frac1{50} } \\]

甚至令一个示范可观测量为 \\(\mathcal O=u^2\\)，改变变量后必须同时写成：

\\[ \mathcal O=\frac{v^2}{(1+13v)^2} \\]

代入固定点：

\\[ \boxed{ \mathcal O\_\*=\frac1{150^2} } \\]

两种写法的物理结果严格相同。

因此，仅仅得到一个固定点坐标 \\(1/137\\)，不足以证明它就是真实电磁耦合。必须先明确规范场如何归一化、怎样定义可测量电荷，以及如何从理论变量得到实验可观测量。

这与精确重整化群中关于固定点坐标和临界指数的区别一致：可逆耦合重参数化可以改变固定点的坐标，而精确稳定性矩阵的特征值保持不变。

## 二、多耦合系统：证明真正不变的是稳定性结构

对于包含引力、规范场、Yukawa 耦合等多个参数的系统：

\\[ \frac{dg_i}{d\ln\mu}=\beta_i(\mathbf g) \\]

作可逆参数变换：

\\[ g'\_a=f_a(\mathbf g) \\]

定义变换的 Jacobian：

\\[ J\_{ai}=\frac{\partial f_a}{\partial g_i} \\]

在精确固定点处，稳定性矩阵满足：

\\[ \boxed{B'\_\*=J\_\*B\_\*J\_\*^{-1}} \\]

这意味着两个矩阵相似，其特征值完全相同。

我使用一个非对角双耦合系统实际执行 SymPy 符号检验，所得结果为：

\\[ \lambda\_\pm=\frac1{100}\pm\frac{\sqrt{42}}{200} \\]

改变耦合坐标后，矩阵的具体元素发生变化，但迹、行列式和特征值保持不变。

因此，未来 ROOT 求出量子引力固定点后，至少要同时报告固定点、物理相关方向、稳定性指数，以及它们在不同计算方案下的可靠性。

## 三、紫外固定点仍然允许不同的低能 α

对前面的模型：

\\[ \frac{du}{d\ln\mu}=Au-Bu^2 \\]

直接积分：

\\[ \boxed{ u(\mu)= \frac{u\_\*}{ 1+\left(\frac{u\_\*}{u_0}-1\right) (\mu/\mu_0)^{-A}} } \\]

选择三个不同的低能初始值，固定点均为 \\(1/150\\)。

同一紫外固定点的三条不同重整化轨道

三条曲线都趋向同一个紫外固定点，但在有限能标上具有不同耦合。这是实际求解的数学示例，不代表真实电磁耦合的实验运行曲线。

| \\(\ln(\mu/\mu_0)\\) | 初值 0.002 | 初值 0.004 | 初值 0.010 |
| -------------------- | -------- | -------- | -------- |
| 0                    | 0.002000 | 0.004000 | 0.010000 |
| 100                  | 0.005067 | 0.006115 | 0.006982 |
| 250                  | 0.006563 | 0.006637 | 0.006682 |
| 500                  | 0.006666 | 0.006666 | 0.006667 |

这给出了另一项严格限制：具有相同的紫外固定点，不代表低能电磁耦合已经唯一确定。

除非有独立的物理条件选择某一条轨道，否则初始值仍是自由参数。

## 四、真实物理闭环：加入电子真空极化

为了让上述数学判断能够接入真实 QED，本轮重新计算了类空间动量下的一圈电子真空极化。

定义：

\\[ H(q)=\frac2\pi\int_0^1 x(1-x) \ln[1+q^2x(1-x)]\\,dx \\]

其中 \\(q=Q/m_e\\)。

有效电磁耦合满足：

\\[ \boxed{ \alpha\_{\rm eff}(Q)= \frac{\alpha(0)}{1-\alpha(0)H(q)} } \\]

这一步还可以反向求解：

\\[ \boxed{ \alpha(0)= \frac{\alpha\_{\rm eff}(Q)} {1+\alpha\_{\rm eff}(Q)H(q)} } \\]

实际采用 90 位计算精度，对两个不同初值和五组动量进行了积分与反演，全部通过设定的高精度残差检验。

两种不同电磁初始值的量子阈值计算

两种初始耦合都满足同一个电子真空极化计算公式，但给出不同结果。单靠阈值积分不能自动选出自然界的低能 α。

例如 \\(Q=m_e\\) 时：

| 输入 \\(\alpha(0)\\) | 计算的 \\(\alpha\_{\rm eff}(m_e)\\) |
| ------------------ | -------------------------------- |
| \\(1/137\\)        | 0.00730029506218                 |
| \\(1/150\\)        | 0.00666752167946                 |

这里的 \\(1/137\\) 和 \\(1/150\\) 都是测试输入，不是精细结构常数的独立预言。

## 八、接下来的真正攻坚目标

ROOT V25 应该集中解决一个更强的问题：

\\[ \boxed{ \begin{gathered} \text{几何—量子作用量}\\\ \Downarrow\\\ \text{排除冗余耦合坐标}\\\ \Downarrow\\\ \text{唯一物理重整化轨道}\\\ \Downarrow\\\ \text{实际粒子质量与量子阈值}\\\ \Downarrow\\\ \alpha(0)\ \text{及独立实验预言} \end{gathered} } \\]

最终裁定： 本轮严格证明了为什么一个看似精确的 \\(1/137\\) 固定点可能只是坐标选择，解决了此前研究的一个关键逻辑漏洞。但自然界的精细结构常数仍未获得无参数的第一性原理证明。

下一步应该争取的不是一个更漂亮的数字，而是一个连改变理论变量、规范选择和计算方案都无法破坏的物理预测。只有做到这一点，才能真正接近精细结构常数的本源。
