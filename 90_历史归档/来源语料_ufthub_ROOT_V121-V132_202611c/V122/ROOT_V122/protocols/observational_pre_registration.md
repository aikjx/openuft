# V123 真实观测预注册与失败判据（V122 定稿）

## 一、比较对象
- H0：GR / 地球地心惯性系精密轨道动力学，含 ICGEM 符合精度的球谐重力场、太阳/月球三体、潮汐、地球自转与极移、相对论、辐射压、阻力、星载时钟与测量方程。
- H1：在同样所有 H0 项基础上，加入一项固定 **α_Y=1/3, ell=124600m** 的单标量弱场贡献；使用同一地球源质量分布，不能把 R 的球对称形状因子静默拓展到非球形环境。若源数值模型近似导致偏差，应按事前限定误差检验，不得挑数据随意替换。
- H0 和 H1 **共同**使用可剖面的地心 GM、轨道初值及相同类别的校准/拖曳干扰项；其先验和参数边界须基于仪器与物理数据，而非为固定候选减小 χ² 定制。

## 二、数据
- 首选低轨卫星：GOCE、GRACE、GRACE-FO（选择具备可公开复算的原始测量、时间标准、卫星姿态、背景重力场和处理规范的产品）。
- 强制使用独立来源、不同高度、不同轨道倾角的验证集。
- 对 200–500 km 的球外场，球谐项、地形等效引力、潮汐、大气阻力常会影响径向响应，不能把轨道半径一个函数代替时序轨道反演。

## 三、验收统计
- 首先做模型内自洽：端到端轨道/时钟模拟 + 盲数据注入恢复 + 非注入误报率；连续/离散时间残差、谱自相关、交叉验证。
- 比较 H0 和 H1 的似然差、联合后验预测残差；记录完整协方差矩阵、自由度、系统误差先验敏感性。
- 不能把单独显著性数直接当发现；若固定 H1 连独立观测与误差模型都无法描述，则 **REJECT 固定 H1**，保留更一般 ROOT 理论空间的独立审计。

## 四、禁止
- 禁止在同一试验结论中事后改 ℓ、α、地球密度模型或把未知 drift 曲线调到与 H1 一样。
- 禁止把“GOCE 重力场精度”直接当作 Yukawa α 的百分之九十五上界。
- 禁止把 MICROSCOPE 组分相关耦合上界套到完全普适的 f(R) 耦合。
- 禁止说 ROOT 已证明四力统一、已发现第五力或已用真实卫星数据验证，本归档只做模型内数学数值和研究方案。
