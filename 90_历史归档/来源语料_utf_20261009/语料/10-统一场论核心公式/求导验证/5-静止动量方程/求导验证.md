# 静止动量方程 - 求导验证报告

## 1. 公式信息
**公式名称**：静止动量方程  
**公式编号**：5  
**数学表达式**：$ec{p}_{0} = m_{0}ec{c}_{0}$  
**物理意义**：描述静止质量与光速相关的内在动量，体现质能等价

## 2. 关键参数
- $ec{p}_{0}$: 静止动量 [MLT⁻¹]
- $m_{0}$: 静止质量 [kg] = [M]
- $ec{c}_{0}$: 静止参考系中的光速 [$m/s$] = [LT⁻¹]

## 3. 导数验证

### 3.1 对静止质量 $m_{0}$ 的导数
**目标**：计算 $frac{dec{p}_{0}}{dm_{0}}$

**求导过程**：
1. 对 $ec{p}_{0} = m_{0}ec{c}_{0}$ 关于静止质量 $m_{0}$ 求导：
   $$frac{dec{p}_{0}}{dm_{0}} = frac{d}{dm_{0}}eft(m_{0}ec{c}_{0}ight)$$
2. 应用常数乘法求导法则：$ec{c}_{0}$ 是常数，$frac{d}{dm_{0}}(km_{0}) = k$
   $$frac{dec{p}_{0}}{dm_{0}} = ec{c}_{0} frac{d}{dm_{0}}(m_{0})$$
3. 质量的导数为 1：
   $$frac{dec{p}_{0}}{dm_{0}} = ec{c}_{0} dot 1 = ec{c}_{0}$$

**验证结果**：$frac{dec{p}_{0}}{dm_{0}} = ec{c}_{0}$，表示静止动量随静止质量的变化率等于光速

### 3.2 对光速 $ec{c}_{0}$ 的导数
**目标**：计算 $frac{dec{p}_{0}}{dec{c}_{0}}$

**求导过程**：
1. 对 $ec{p}_{0} = m_{0}ec{c}_{0}$ 关于光速 $ec{c}_{0}$ 求导：
   $$frac{dec{p}_{0}}{dec{c}_{0}} = frac{d}{dec{c}_{0}}eft(m_{0}ec{c}_{0}ight)$$
2. 应用常数乘法求导法则：$m_{0}$ 是常数，$frac{d}{dec{c}_{0}}(m_{0}ec{c}_{0}) = m_{0}$
   $$frac{dec{p}_{0}}{dec{c}_{0}} = m_{0} frac{d}{dec{c}_{0}}(ec{c}_{0})$$
3. 光速的导数为单位张量（在矢量求导中，$frac{dec{v}}{dec{v}} = athbf{I}$）：
   $$frac{dec{p}_{0}}{dec{c}_{0}} = m_{0} dot athbf{I}$$

**验证结果**：$frac{dec{p}_{0}}{dec{c}_{0}} = m_{0} dot athbf{I}$，表示静止动量随光速的变化率与静止质量成正比

## 4. 时间导数验证

### 4.1 静止动量的时间导数
**目标**：计算 $frac{dec{p}_{0}}{dt}$

**求导过程**：
1. 对 $ec{p}_{0} = m_{0}ec{c}_{0}$ 关于时间 $t$ 求导：
   $$frac{dec{p}_{0}}{dt} = frac{d}{dt}eft(m_{0}ec{c}_{0}ight)$$
2. 应用乘积求导法则：$frac{d}{dt}(uv) = ufrac{dv}{dt} + vfrac{du}{dt}$
   $$frac{dec{p}_{0}}{dt} = m_{0}frac{dec{c}_{0}}{dt} + ec{c}_{0}frac{dm_{0}}{dt}$$
3. 根据光速不变原理，$ec{c}_{0}$ 是常数，因此 $frac{dec{c}_{0}}{dt} = 0$
4. 代入得：
   $$frac{dec{p}_{0}}{dt} = m_{0} dot 0 + ec{c}_{0}frac{dm_{0}}{dt} = ec{c}_{0}frac{dm_{0}}{dt}$$

**验证结果**：$frac{dec{p}_{0}}{dt} = ec{c}_{0}frac{dm_{0}}{dt}$，表示静止动量的变化率与静止质量的变化率成正比

## 5. 分量导数验证

### 5.1 分量形式
将 $ec{p}_{0}$ 和 $ec{c}_{0}$ 分解为笛卡尔分量：
- $ec{p}_{0} = p_{0x}ec{i} + p_{0y}ec{j} + p_{0z}ec{k}$
- $ec{c}_{0} = c_{0x}ec{i} + c_{0y}ec{j} + c_{0z}ec{k}$

则静止动量方程的分量形式为：
- $p_{0x} = m_{0}c_{0x}$
- $p_{0y} = m_{0}c_{0y}$
- $p_{0z} = m_{0}c_{0z}$

### 5.2 分量导数
**目标**：计算 $frac{dp_{0x}}{dm_{0}}, frac{dp_{0y}}{dm_{0}}, frac{dp_{0z}}{dm_{0}}$

**求导过程**：
1. 对 $p_{0x} = m_{0}c_{0x}$ 关于 $m_{0}$ 求导：
   $$frac{dp_{0x}}{dm_{0}} = c_{0x}$$
2. 同理可得：
   $$frac{dp_{0y}}{dm_{0}} = c_{0y}, uad frac{dp_{0z}}{dm_{0}} = c_{0z}$$

**验证结果**：分量导数与矢量导数的分量一致，验证了矢量导数的正确性

## 6. 洛伦兹变换下的导数

### 6.1 运动质量与静止质量的关系
根据相对论，运动质量 $m$ 与静止质量 $m_{0}$ 的关系为：
$$m = frac{m_{0}}{qrt{1 - frac{v^{2}}{c^{2}}}}$$
其中 $v$ 是物体速度，$c$ 是光速。

### 6.2 对速度 $v$ 的导数
**目标**：计算 $frac{dm}{dv}$

**求导过程**：
1. 令 $amma = frac{1}{qrt{1 - frac{v^{2}}{c^{2}}}}$，则 $m = amma m_{0}$
2. 对 $m = amma m_{0}$ 关于速度 $v$ 求导：
   $$frac{dm}{dv} = m_{0}frac{damma}{dv}$$
3. 计算 $frac{damma}{dv}$：
   $$frac{damma}{dv} = frac{d}{dv}eft(1 - frac{v^{2}}{c^{2}}ight)^{-1/2}$$
4. 应用链式法则：令 $u = 1 - frac{v^{2}}{c^{2}}$，则 $amma = u^{-1/2}$，$frac{damma}{dv} = frac{damma}{du}frac{du}{dv}$
   $$frac{damma}{du} = -frac{1}{2}u^{-3/2}$$
   $$frac{du}{dv} = -frac{2v}{c^{2}}$$
5. 代入得：
   $$frac{damma}{dv} = -frac{1}{2}eft(1 - frac{v^{2}}{c^{2}}ight)^{-3/2} dot eft(-frac{2v}{c^{2}}ight) = amma^{3}frac{v}{c^{2}}$$
6. 因此：
   $$frac{dm}{dv} = m_{0}amma^{3}frac{v}{c^{2}} = frac{m_{0}v}{c^{2}eft(1 - frac{v^{2}}{c^{2}}ight)^{3/2}}$$

**验证结果**：$frac{dm}{dv} = frac{m_{0}v}{c^{2}eft(1 - frac{v^{2}}{c^{2}}ight)^{3/2}}$，表示运动质量随速度的变化率
