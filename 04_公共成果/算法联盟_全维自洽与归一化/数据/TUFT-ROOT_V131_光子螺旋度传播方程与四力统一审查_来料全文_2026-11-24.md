# ROOT V131｜继续攻坚：从光子螺旋度推导传播方程，寻找四力统一的突破口

本轮研究的目标是回答：

**如果空间存在某种内禀螺旋或手性结构，它能否产生光子的自旋、电磁作用与引力，并最终解释强、弱两种相互作用？**

经过进一步推导，可以先确定三个重要结果：

1. 一种手性场确实能够使两种光子螺旋度出现不同的传播关系。不需要假设光子内部有机械旋转的小球。
2. 这种机制也会产生可检验的低频不稳定性。如果 ROOT 要采用它，必须解释稳定性及能量来源。
3. 单一手性场还无法生成全部四种基本相互作用。必须进一步解决规范对称性、粒子谱、耦合常数和引力起源。

以下全部理论推导使用：

\[ \boxed{c=1,\quad \hbar\text{ 保留量纲},\quad G\text{ 保留量纲}} \]

## 一、从 V130 的候选作用量严格求导

考虑最小的电磁—手性场模型：

\[ \boxed{ S=\int d^4x\sqrt{-g} \left[ \frac{\mathcal R}{16\pi G} -\frac14F_{\mu\nu}F^{\mu\nu} -\frac{f_\theta^2}{2}\nabla_\mu\theta\nabla^\mu\theta -V(\theta) -\frac{\eta}{4}\theta F_{\mu\nu}\widetilde F^{\mu\nu} \right] } \]

其中 \(\theta\) 是无量纲赝标量场，而不是预先假定的机械螺旋半径。

在平直时空、无电荷电流条件下，变分得到：

\[ \boxed{ \begin{aligned} \nabla\cdot\mathbf E &=-\eta\nabla\theta\cdot\mathbf B\\ \nabla\times\mathbf B-\partial_t\mathbf E &=\eta\left( \dot\theta\mathbf B+\nabla\theta\times\mathbf E \right) \end{aligned} } \]

另外两条麦克斯韦方程不变：

\[ \nabla\cdot\mathbf B=0,\qquad \nabla\times\mathbf E+\partial_t\mathbf B=0 \]

这个模型属于已有的轴子电动力学理论框架。我们使用它来检验 ROOT 的手性空间假设，而不是宣称已经创造了一套新电磁学。

## 二、推导两种光子螺旋度的传播方程

假设手性背景在空间上均匀，但随时间变化：

\[ \theta=\theta(t) \]

采用横向规范：

\[ \nabla\cdot\mathbf A=0,\qquad A_0=0 \]

则：

\[ \boxed{ \ddot{\mathbf A}-\nabla^2\mathbf A =\eta\dot\theta\,\nabla\times\mathbf A } \]

把电磁场分解为两种圆偏振模式：

\[ \mathbf A=\sum_{\sigma=\pm1} A_\sigma(t)\mathbf e_\sigma e^{ikz} \]

其中：

\[ i\mathbf k\times\mathbf e_\sigma =\sigma k\mathbf e_\sigma \]

便得到：

\[ \boxed{ \ddot A_\sigma+ \left(k^2-\sigma\eta\dot\theta k\right) A_\sigma=0 } \]

若在分析时间窗内把 \(\dot\theta\) 视为常数，定义：

\[ b=\eta\dot\theta \]

则出现关键色散关系：

\[ \boxed{ \omega_\sigma^2=k^2-\sigma bk } \]

这是本轮最有用的可计算结果。

它表明，在这种特定手性背景中，不同螺旋度可以具有不同的传播相位。

**但要严格区分：这个方程是已有手性电动力学的一项结果，不是 ROOT 已经独立发现的新物理。**

## 三、检验是否发生超光速

对稳定的实频传播分支：

\[ \omega_\sigma=\sqrt{k^2-\sigma bk} \]

求导得群速度：

\[ \boxed{ v_{g,\sigma} =\frac{2k-\sigma b} {2\sqrt{k^2-\sigma bk}} } \]

进一步计算：

\[ \boxed{ v_{g,\sigma}^2-1 =\frac{b^2}{4k(k-\sigma b)} } \]

因此在稳定分支上，若 \(b\ne0\)，该理想模型可以出现：

\[ v_{g,\sigma}>1 \]

这是不是推翻了相对论？

**不是。**

这里大于 1 的是特定背景下的群速度，而非信号前沿速度。该模型的最高阶波动算符仍是标准的：

\[ \Box=\partial_t^2-\nabla^2 \]

所以局域扰动的因果传播仍受到光锥限制。2020 年《Physical Review D》对动态轴子背景进行了专门研究，确认这种模型可以同时具有超光速群速度与因果性的信号传播。

还要注意：群速度公式不应被解释为“单个光子在空间中实际以超光速飞行”。

## 四、发现一个必须处理的低频不稳定区间

还是从：

\[ \omega_\sigma^2=k^2-\sigma bk \]

出发。

对于 \(b>0\) 的正螺旋度分支，如果：

\[ \boxed{0<k<b} \]

则：

\[ \omega_+^2<0 \]

此时不再是普通的稳定振荡解，而会出现指数增长模式：

\[ A_+(t)\propto e^{\gamma t} \]

其中：

\[ \boxed{\gamma=\sqrt{bk-k^2}} \]

增长率在：

\[ k=\frac b2 \]

处达到最大：

\[ \boxed{\gamma_{\max}=\frac{|b|}{2}} \]

当 \(b<0\) 时，对应的不稳定分支交换为负螺旋度。

这告诉我们：如果空间真的具有某种持续变化的手性背景，就必须研究它是否在某些波长范围引发电磁场增长。

不过，不能据此直接判定完整模型不稳定或不守恒。因为上面的计算把 \(\dot\theta\) 当作固定背景，没有计算手性场被电磁场反作用后的变化。

这正是下一项检查。

## 五、能量到底从哪里来？完整耦合系统的守恒证明

电磁场能量密度：

\[ u_{\mathrm{EM}}=\frac12(E^2+B^2) \]

在这个模型下，能量平衡方程变为：

\[ \boxed{ \partial_tu_{\mathrm{EM}} +\nabla\cdot(\mathbf E\times\mathbf B) =-\eta\dot\theta\,\mathbf E\cdot\mathbf B } \]

手性场能量密度：

\[ u_\theta= \frac{f_\theta^2}{2} \left(\dot\theta^2+|\nabla\theta|^2\right) +V(\theta) \]

对应：

\[ \boxed{ \partial_tu_\theta+\nabla\cdot\mathbf S_\theta =+\eta\dot\theta\,\mathbf E\cdot\mathbf B } \]

其中：

\[ \mathbf S_\theta=-f_\theta^2\dot\theta\nabla\theta \]

将两式相加：

\[ \boxed{ \partial_t(u_{\mathrm{EM}}+u_\theta) +\nabla\cdot(\mathbf S_{\mathrm{EM}}+\mathbf S_\theta) =0 } \]

**这是一条明确的结论：电磁场可以从变化的手性背景中获得能量，但在完整的封闭模型中，总能量仍然守恒。**

### 数值积分验证

初始无量纲模型能量 2.0000005，最大绝对能量数值漂移 1.72×10⁻¹³，初始 \(\dot\theta\) 为 2.0000，末态 \(\dot\theta\) 为 1.1436。数值实验使用归一化示例参数 \(k=f_\theta=\eta=1\)、\(V=0\)，积分至模型时间 8，步长 0.002。能量数值检查通过，但这不是自然界中手性场存在的证据。

## 六、找到一个更适合实验验证的突破口

经过公式展开，得到两种效应对手性耦合参数 \(b\) 的不同依赖：

对于 \(|b/k|\ll1\)：

\[ \boxed{ \Delta\beta\simeq\frac b2L } \]

而群速度偏差是：

\[ \boxed{ v_{g,\sigma}-1 \simeq\frac{b^2}{8k^2} } \]

因此：

**偏振旋转是一阶效应，群速度偏离是一项二阶效应。**

这意味着，在弱耦合情况下，精密偏振测量可能比测量光子的到达时间更容易识别这种手性耦合。

取纯假设参数：

\[ b=10^{-6}\ \mathrm{m^{-1}} \]

550 nm 真空光经过 1 km：

| 物理量 | 计算值 |
|---|---|
| 波数 \(k\) | \(1.1423973\times10^7\ \mathrm{m^{-1}}\) |
| 无量纲耦合 \(b/k\) | \(8.754\times10^{-14}\) |
| 偏振旋转角 | \(0.028648^\circ\) |
| \(v_{g,+}^2-1\) | \(1.916\times10^{-27}\) |
| 可否由该数值证明 ROOT？ | 不能，参数是假设输入 |

注意，群速度即使略大于 1，也不能据此推断信息超光速。

\[ \beta=(0.277\pm0.057)^\circ \]

这是一个值得关注的宇宙偏振旋转信号，但论文明确保留了仪器校准和其他系统误差方面的不确定性。

在本轮候选模型中，如果暂时按照该测量结果反推：

\[ \boxed{ \eta\Delta\theta \simeq0.009669\pm0.001990 } \]

也只能约束两个参数的乘积，并不能分别预测它们，更不能证明空间存在光速机械螺旋。

## 七、将手性场扩展到电磁、弱、强相互作用

可以研究一个共同的手性自由度 \(\theta\) 与三类规范场的耦合：

\[ \boxed{ \mathcal L_{\mathrm{int}} =-\frac{\theta}{4} \left( \eta_1 B_{\mu\nu}\widetilde B^{\mu\nu} +\eta_2 W^a_{\mu\nu}\widetilde W^{a\mu\nu} +\eta_3 G^A_{\mu\nu}\widetilde G^{A\mu\nu} \right) } \]

它具有一定的统一研究价值，因为相同的 \(\theta\) 自由度可以参与多个相互作用领域。

例如，在规范场动能已经正则归一化的前提下，电弱混合给出：

\[ \boxed{ \eta_\gamma =\eta_1\cos^2\theta_W +\eta_2\sin^2\theta_W } \]

但这里仍然存在三个自由耦合参数，而且规范群本身是预先引入的。

因此它是**跨相互作用的候选耦合机制**，还不是从单一原理推导四力统一。
