## 一、一句话判决

> **「n 恒偶」不是族数的后果，是「零模数 Q ∈ ℤ」这个前提的后果。**
> 把 Q 放宽到 `Q ∈ (1/M)ℤ` 之后，`n = 3` 恰好可达，且**当且仅当 M 为偶数**；
> 此时 `trF⁴` 与 `p₂` 两项反常仍**精确**抵消（`I₈ = ∅`，不是近似、不是拟合）。
> ⇒ **挡住三代的是量子化条件，不是反常自由。**

本卷**不产生**「预言 3 代」。它只**撤销**「禁止 3 代」这条禁令，并把禁止它的那一条前提指名点姓写出来。这是本卷与 r390/r391 的分野：那两卷说的是「在整数零模下 3 不可达」，本卷说的是「整数零模**就是**全部障碍」。

构造：`I₈(q) = Â · CH_S · exp(qx)` 截到 8 次，`Â = 1 − p₁/24 + (7p₁² − 4p₂)/5760`，`CH_S = 16 + T + trF⁴/24`。全程 `Fraction`，无浮点。

## 四、两条腿（A3 / A4）

| 腿 | 卡住什么 | 为什么 | 机核读数 |
|---|---|---|---|
| A | `trF⁴` 与 `p₂` 必须为 0 | `½X₄∧X₄` 在 `span{x², T, p₁}` 内**产生不出**这两项（G11 完备性枚举：deg-8 共 8 个单项式，平方只能产生 6 个，缺口正是这两项） | 单 16 / 两同号 / 四同号 全判死；`n = 0` 两组可解 |
| B | `T²` 与 `x²T` 必须为 0 | 谱的 `T²` 系数恒 0（A1）⇒ 平方要求 `β²/2 = 0` ⇒ `β = 0` ⇒ `x²T` 系数 `αβ = 0` | `Σ s q² = 0` 的 2 组可解、`Σ s q² ≠ 0` 的 3 组判死 |

两腿合起来：**GS 可解 ⟺ `Σ s = 0` 且 `Σ s q² = 0` 且 `Σ s q⁴ = 0`**。

★ 两条腿**互不依赖**：腿 A 只看 `n`（净手征数），腿 B 只看 `q` 的二次/四次矩。所以这不是一个条件换三种说法，而是两个独立条件同时成立。

★★ 腿 A 的杀伤面比 r390 的「两族配对抵消」更宽：它**不要求谱有任何对称性**，只要求「所有 16 是同一个表示」。

## 五、主定理：GS 可解 ⇒ n 偶（A5）

在 `Q ∈ ℤ` 下扫 `q₊ = 1..8`、`q₋ = −8..8`（`s = +1, −1`）：**16 组 GS 可解**，其中 `n = 0` 8 组（`q₋ = +q₊`，平凡支）、`n = 2,4,…,16` 8 组（`q₋ = −q₊`，非平凡支）。**`n` 全偶，`n = 3` 一次未出现。**

证明链（三行）：

1. GS 可解 ⇒ `Σ s q² = 0`（腿 B）⇒ `Σ s Q² = N²·0 = 0`；
2. `Q² ≡ Q (mod 2)` ⇒ `Σ s Q² ≡ Σ s Q (mod 2)`；
3. `Σ s Q² = 0` ⇒ `n = Σ s Q ≡ 0 (mod 2)`。∎

★ 第 2 步里的 `s = ±1 ≡ 1 (mod 2)` 是关键：它让结论对**任意族数、任意符号**成立，多余的 16/反 16 对不改变奇偶。这一条是 r391 A9 与本卷 A3/A4 的**合取**：r391 只说「前提成立则 n 偶」，本卷说「GS 可解**就是**那个前提」。

**A6（两族完整解集）**：`I₈ = 0` 在 `q₋ = ±q₊` 两支上成立（`q₋ = 2q₊` 当负例，18 组逐项核对：`I₈ = ∅` ⟺ `Σ s q² = Σ s q⁴ = 0`）。非平凡支一律 **`n = 2q₊`**。

★★ 所以「三代」在这条线上被压缩成一个数：**`2q₊ = 3` ⟺ `q₊ = 3/2`**。整个问题从「群论」变成了「一个分母」。

## 六、唯一缺口与分母判据（A7 / A8 / A9 / A10）

### 6.1 缺口（A7）

`q₊ = 3/2`、`q₋ = −3/2`（`s = +1, −1`）：

- `Σ s q² = 9/4 − 9/4 = 0`（精确）
- `Σ s q⁴ = 81/16 − 81/16 = 0`（精确）
- `n = 3/2 − (−3/2) = 3`
- `I₈` 的系数个数 = **0**（空）

★ 对照 A8：同一对电荷放到整数侧 `q = ±3` ⇒ `n = 6`。**同一机制、同一抵消、只差分母**。这就是模 2 定理的全部内容。

★★ 所以「三代」不需要新机制，只需要**半个量子**。这句话是本卷最短的结论，也是唯一一条能同时对上 r390（代数不许）与 r391（整数不许）的说法。

### 6.2 分母判据（A9）—— 首次修正后的版本

在 `Q = k/M` 的格上**真枚举**（`q₊ = k/M`、`q₋ = −k/M`，判据只看 `I₈` 是否为空 + 净手性是否等于目标）：

| M | n=3 命中的 k | n=2 对照命中的 k |
|---|---|---|
| 1 | 无 | 1 |
| 2 | **3** | 2 |
| 3 | 无 | 3 |
| 4 | **6** | 4 |
| 5 | 无 | 5 |
| 6 | **9** | 6 |
| 7 | 无 | 7 |
| 8 | **12** | 8 |
| 9 | 无 | 9 |
| 10 | **15** | 10 |
| 11 | 无 | 11 |
| 12 | **18** | 12 |

**结论：`n = 3` 可达 ⟺ M 偶**（6 命中 / 6 未命中）。命中的 k 依次为 `3M/2`。

★ 正对照 `n = 2`（`q₊ = 1`）**12 档全部命中** —— 这一半是必须的：没有它，「6 档命中」与「0 档命中」在读数上无法区分。

★★ 尺度的正确说法：条件 `Σ s q² = Σ s q⁴ = 0` 乘 `M²` 后**与 M 无关**，但 `n = Σ s q = Σ s k / M` **随 M 变**。⇒ 半整数**不是重标（rescaling），而是新的点**。初稿在这里把它当成重标，见 §九 E01。

### 6.3 半整数侧的 n 分布（A10）

| M | 可达 n 的样本 | 奇 n |
|---|---|---|
| 2 | 1, 2, 3, 4, 5 | 1, 3, 5, 7 |
| 3 | 2/3, 4/3, 2, 8/3, 10/3 | 无 |
| 4 | 1/2, 1, 3/2, 2, 5/2 | 1, 3 |

★ M = 2 时 `n = 2k₊/2 = k₊` ⇒ **任意整数 n 可达**（含 3）。⇒ 「半个量子」解锁的**不是只有 3**，而是全部奇数。这一条堵住了「3 有什么特殊」的误读：3 不特殊，奇偶才特殊。

## 十、诚实边界、回链与不可相加声明

### 10.1 诚实边界（四条）

1. 本卷只做**指标层与反常层**：`n = 3` 是「净手性数」，**不是**「三代质量谱」。质量矩阵、Yukawa、混合角一概未触及。
2. 半整数零模的**几何实现未给出**：光滑紧化下指标必为整数，半整数只能来自奇点/扭曲边界。本卷只证明「若允许半整数，则代数上完全通」，**不证明**某个具体紧化会给出半整数。
3. `E1` 的代价被定价为「几何」，但那个几何的价格本卷没有算：orbifold 扭曲扇区里 6D 有效场论失效，必须在 5D/4D 重建 —— 重建之后 `I₈` 还是不是同一个 8 形式，本卷没有回答。
