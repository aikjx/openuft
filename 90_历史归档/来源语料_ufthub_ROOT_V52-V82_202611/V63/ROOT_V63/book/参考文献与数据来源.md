# 来源与研究文献（用户可自主核对）

1. NIST / CODATA 2022 recommended constants（2025 出版）：https://www.nist.gov/publications/codata-recommended-values-fundamental-physical-constants-2022 ，数据页 https://physics.nist.gov/constants 。采用 G=6.67430(15)×10^-11 SI、c 与 h 的精确定义。
2. Matt Visser, *Sakharov's induced gravity: a modern perspective* (2002)：https://arxiv.org/abs/gr-qc/0204062 。用于理解诱导引力的方案依赖与物质场积分机制；不是 ROOT 证据。
3. D. V. Vassilevich, *Heat kernel expansion: user's manual* (2003)：https://arxiv.org/abs/hep-th/0306138 。用于标量 Laplace 型算子和热核系数。
4. Particle Data Group, *Grand Unified Theories* (2025 review)：https://pdg.lbl.gov/2025/reviews/rpp2025-rev-guts.pdf 。用于标准模型规范群与 GUT 研究的背景参考。
5. 普适自由落体与时空几何：广义相对论 Einstein–Hilbert 作用量的标准形式，本文使用签名 (-+++)，欧氏曲率项记号在正文定义。模型等式推导独立于从这些资源复制的叙述。

**来源性质说明**：文献是现有物理背景和参考，不是对 ROOT 假说的验证；任何未经重新推导的特定 cutoff 系数都不可当作通用物理常数。
