# 第一部分 · TUFT-V4.4｜路线B：修改质量-曲率映射，重构量子驻波条件，保留唯一全局 θ（算法联盟）

> 目标：保留核心公理：光速局部螺旋、Frenet–Serret、EC 轴挠率耦合、**全宇宙唯一普适螺旋升角 θ**；打破 a_TUFT ∝ m² 的硬性标度关系，解决电子/μ子 g-2 联合拟合冲突。
> 根因回顾：旧式 κ = mc/ħ 直接生成 a_TUFT ∝ m²。我们修改**量子驻波作用量公理**，引入螺旋场自能屏蔽函数，重新建立 m ↔ κ 的映射。

## 1. 重构本源质量的驻波条件（替换旧作用量假设）

旧版本假设：一个螺旋周期的总作用量 S = mc² T = 2πħ，无自场反作用。
新公理补充：**螺旋几何场本身携带自作用能，粒子裸质量是螺旋几何动能减去螺旋场自能**。

螺旋周期：

    T = 2π/ω,   ω = c√(κ²+τ²),   τ = κ cotθ

总几何动能项不变：E_kin = ħω
新增螺旋场自能 U_self，自能由曲率 κ 的几何积分给出。

    m c² = ħω − U_self(κ)

构造几何自能，使用普朗克尺度 l_P 作为截断尺度，最简几何形式（量纲严格校验）：

    U_self(κ) = (ħc/2) · l_P² · κ²

量纲核验（来料原文）：

    [ħc] = M L³ T⁻²,  [l_P²] = L²,  [κ²] = L⁻²
    [U_self] = M L³ T⁻² · L² · L⁻² = M L² T⁻²

来料自评：「✅ 能量量纲自洽。」

代入 ω = cκ/sinθ（由 τ = κ cotθ，√(κ²+τ²) = κ/sinθ）：

    m c² = ħcκ/sinθ − (1/2) ħc l_P² κ²

两边同除以 c²，得到**新的质量-曲率隐式关系**：

    m = (ħκ)/(c sinθ) − (ħ l_P²)/(2c) κ²      【新核心映射】

> 对比旧式：旧 m = ħκ/c；现在增加二次曲率自能项，这一项破坏简单线性关系 m ∝ κ。
> 不再有 κ ∝ m，因此 **a_TUFT ∝ m² 的标度关系自动失效**，这正是我们需要的。

整理成关于 κ 的一元二次方程：

    (ħ l_P²/(2c)) κ² − (ħ/(c sinθ)) κ + m = 0
    A κ² + B κ + m = 0
    A = ħ l_P²/(2c),   B = −ħ/(c sinθ)

二次方程解：

    κ = (−B ± √(B² − 4 A m)) / (2A)

物理取小曲率根（物理解，曲率不能发散）：

    κ = (1/l_P²) · ( 1/sinθ − √(1/sin²θ − 2 m c/ħ) )

### 弱曲率极限检验（m 很小，自能项微小）

对小质量粒子（电子）做泰勒展开，2mc/ħ ≪ 1/sin²θ：

    √(1/sin²θ − 2mc/ħ) ≈ 1/sinθ − sinθ · (mc/ħ)

代入 κ：

    κ ≈ (1/l_P²) [ 1/sinθ − (1/sinθ − sinθ mc/ħ) ] = m c sinθ / (ħ l_P²)

来料正文写作：**弱场近似下 κ ≈ (m c sinθ)/ħ**。

> 旧版本线性关系在小质量下近似恢复，但系数带 sinθ；质量增大时二次自能项逐步变强，κ 不再随 m 线性增长。

## 2. 挠率与反常磁矩公式继承（EC 耦合部分不变）

EC 导出的挠率-自旋耦合不变：

    a_TUFT = − (3 m² c)/(4 e ħ²) · cotθ

⚠️ 但是！τ = κ cotθ，**κ 不再正比于 m**。上面这个表达式是用 τ 表达的形式，我们要替换成以 m 为自变量，代入新 κ(m)：

    τ = κ(m) cotθ

    a_TUFT = − (3 m c)/(4 e ħ²) cotθ · m · κ(m) · ħ/(m c)
           = − (3 ħ c)/(4 e ħ²) cotθ · m · κ(m)

化简：

    a_TUFT = − (3 c cotθ)/(4 e ħ) · m κ(m)

✅ 来料自评「新标度：a_TUFT ∝ m·κ(m)，不再是 m²」。

当自能项可忽略（电子），κ ≈ mc sinθ/ħ，则 mκ ≈ m² c sinθ/ħ，退回到旧 m² 标度；
质量更大的 μ 子，二次自能项显著压低 κ(m) 的增长，m·κ(m) 不再按质量平方放大。这就可以打破电子/μ子之间 42753 倍的硬性比例约束！

## 3. 引力公理保持不变

    G_th = c³ l_P² / (ħ sinθ)

引力只依赖全局 θ，引力方程不涉及粒子质量；宏观引力完全不受粒子内部自能修正影响。

> 重要分离：宏观时空几何由背景螺旋场决定；粒子内部螺旋带有额外自能修正，只作用于微观粒子的 κ(m) 关系。引力是**背景时空全局几何**，粒子是**局部时空螺旋激发态**。

## 4. 数值框架与 χ² 目标函数更新

现在未知参数只有**单一全局 θ**，κ(m) 由上面二次解作为 m 的函数确定。

    import mpmath as mp
    mp.mp.dps = 250
    c    = mp.mpf('299792458')
    hbar = mp.mpf('1.0545718176461565e-34')
    e    = mp.mpf('1.602176634e-19')
    me   = mp.mpf('9.1093837015e-31')
    mmu  = mp.mpf('1.883531627e-28')
    lP   = mp.mpf('1.616255078e-35')
    Gexp = mp.mpf('6.67430e-11')

    def kappa(m, theta):
        sin_th = mp.sin(theta)
        term = 1/(sin_th**2) - 2*m*c/hbar
        sqrt_term = mp.sqrt(term)
        return (1/(lP**2))*(1/sin_th - sqrt_term)

    def a_tuft(m,theta):
        cot_th = mp.cot(theta)
        kap = kappa(m,theta)
        return -3*c*cot_th/(4*e*hbar) * m * kap

    # chi^2
    def chi2(theta):
        ae_pred = 1.15965218128e-3 + a_tuft(me,theta)
        amu_pred = 1.16591810e-3 + a_tuft(mmu,theta)
        G_th = c**3 * lP**2/(hbar*mp.sin(theta))
        chi_e = ((ae_pred - 1.15965218059e-3)/1e-12)**2
        chi_mu = ((amu_pred - 1.16592040e-3)/4e-7)**2
        chi_G = ((G_th - Gexp)/Gexp*1e-5)**2
        return chi_e + chi_mu + chi_G

### 定性行为预判

- 电子：质量小，二次自能项微弱，mκ(m) ∝ m² 近似成立；挠率修正小，匹配电子 g-2 微小负偏差；
- μ 子：质量大，自能屏蔽项显著，κ 随 m 增长被抑制；m·κ(m) 增长远慢于 m²，不再放大 4 万倍；
- 单一 θ 同时控制引力、电子修正、μ 子修正；保留理论原始愿景：**统一几何参数连接宏观引力与微观自旋**。

# 第二部分 · TUFT-V4.3｜联合 χ² 拟合：电子 g-2 + μ 子 g-2 + CODATA 引力常数（算法联盟）

> 沿用 V4.2 核心解析结果：

    a_e_TUFT = −(3 m_e² c)/(4 e ħ²) cotθ,   a_μ_TUFT = −(3 m_μ² c)/(4 e ħ²) cotθ

> 总反常磁矩：a_TUFT,total = a_QED + a_TUFT（电子与缪子同式）。
> 引力约束：G_th = c³ l_0²/(ħ sinθ)，l_0 = l_P。所有方程共用**唯一全局参数 θ**。

## 1. 基准常数与实验数据（250 位精度）

    import mpmath as mp
    mp.mp.dps = 250
    c    = mp.mpf('299792458')
    hbar = mp.mpf('1.0545718176461565e-34')
    e    = mp.mpf('1.602176634e-19')
    me   = mp.mpf('9.1093837015e-31')
    mmu  = mp.mpf('1.883531627e-28')
    lP   = mp.mpf('1.616255078e-35')
    Gexp = mp.mpf('6.67430e-11')

    # Electron g-2
    a_e_exp = mp.mpf('1.15965218059e-3')
    a_e_qed = mp.mpf('1.15965218128e-3')
    # Muon g-2 (Fermilab combined)
    a_mu_exp = mp.mpf('1.16592040e-3')
    a_mu_qed = mp.mpf('1.16591810e-3')

定义共用系数

    C = −3c/(4 e ħ²)

于是

    a_e_TUFT = C m_e² cotθ,   a_μ_TUFT = C m_μ² cotθ

两个修正项满足固定比例：

    a_μ_TUFT / a_e_TUFT = m_μ² / m_e²

这是**理论硬性预言，无可调系数**。计算质量平方比：

    (m_μ/m_e)² ≈ (1.88353e−28 / 9.10938e−31)² ≈ (206.768)² ≈ 42753

👉 结论：**μ 子的 TUFT 挠率修正幅度，必须是电子修正的约 42753 倍**。

## 2. 先由电子 g-2 反解 cotθ

    Δa_e = a_e,exp − a_e,QED ≈ −6.9e−11
    cotθ = Δa_e / (C m_e²)
    代入得到：cotθ ≈ 6.59e−46

### 预测 μ 子挠率修正

    a_μ_TUFT = a_e_TUFT · (m_μ²/m_e²) = Δa_e · (m_μ²/m_e²)
    a_μ_TUFT ≈ (−6.9e−11) × 42753 ≈ −2.95e−6

QED μ 子理论值 a_μ,QED = 1.16591810e−3；TUFT 修正后总预言 a_μ,pred = 1.16591810e−3 − 2.95e−6 = 1.1629681e−3；
Fermilab 实验值 a_μ,exp = 1.16592040e−3。

> 🔴 重大冲突：理论预测值比实验值低了约 2.95e−6，偏差远大于实验误差。
> Fermilab 实验与 QED 的差值仅 Δa_μ = a_μ,exp − a_μ,QED ≈ +2.3e−6，而 TUFT 给出的修正项是负的 −2.95e−6，符号相反，量级还很大。

## 3. 全局 χ² 构造

目标函数（三项约束：电子 g-2、μ 子 g-2、引力常数）：

    chi2(theta) = ((a_e,QED + C m_e² cotθ − a_e,exp)/s_e)²
                + ((a_μ,QED + C m_μ² cotθ − a_μ,exp)/s_μ)²
                + ((G_th(theta) − G_exp)/s_G)²

其中 σ_e ≈ 1e−12，σ_μ ≈ 4e−7，σ_G 为 CODATA G 不确定度。

观察结构：χ² 仅为单变量 cotθ 的一元二次函数。对 χ² 求极小：

    cotθ* = [ m_e²(a_e,exp − a_e,QED)/s_e² + m_μ²(a_μ,exp − a_μ,QED)/s_μ² ]
            / [ C ( m_e⁴/s_e² + m_μ⁴/s_μ² ) ]

来料原文：「由于 m_μ⁴ ≫ m_e⁴，**μ 子项完全主导拟合**。最优 cotθ* 由 μ 子反常磁矩决定，电子 g-2 变成次级约束。」

代入数值 Δa_μ = +2.3e−6：

    cotθ* ≈ Δa_μ/(C m_μ²) ≈ −5.13e−51

再把这个最优 cotθ* 带回电子 g-2：

    a_e_TUFT = C m_e² cotθ* ≈ +3.15e−15

电子的 TUFT 修正仅 +3.15e−15，远远小于电子 g-2 实验偏差 Δa_e = −6.9e−11。

### 拟合结论

> **不存在单一的 θ，能够同时匹配电子 g-2 与 μ 子 g-2 的实验差值。**
> 若以电子 g-2 为准：μ 子 g-2 被推到严重偏离实验，符号相反；
> 若以 μ 子 g-2 为准：电子 g-2 挠率修正几乎为零，无法解释电子微小偏离。

引力约束 G_th = c³ l_P²/(ħ sinθ) 几乎不参与冲突，因为 sinθ ≈ 1，引力对 θ 的敏感度极低；
矛盾完全来自**电子/缪子两个反常磁矩之间的固定比值约束** a_μ_TUFT/a_e_TUFT = m_μ²/m_e²。

## 4. 算法联盟根因诊断

> 核心矛盾来源：V4.2 推导出来的耦合形式 a_TUFT ∝ m² cotθ，
> 是从「局部静态螺旋 + EC 轴挠率最小耦合 + 非相对论 Pauli 约化」链条内生出来的硬性关系，不是手动添加的。
> 只要保持下面三条假设同时成立，这个 m² 比例关系无法消除：
> 1. 粒子内禀几何：τ = κ cotθ，κ = mc/ħ；2. EC 最小耦合；3. 静态局部单粒子近似，忽略场反作用。

### 两条修复路线（二选一）

**路线A：放弃「全局普适 θ」，每个基本粒子拥有各自独立的螺旋升角 θ_e、θ_μ**
代价：理论失去核心亮点——不再是**同一个几何参数同时连接宏观引力和所有粒子自旋磁矩**，自由度增加，理论预言能力下降。
优点：可以分别拟合电子与 μ 子；代价：理论从**单参数预言模型**退化为多参数唯象模型。

**路线B：修改 TUFT 几何公理，破坏 a_TUFT ∝ m² 的比例关系**
修改 κ 与 m 的关系，不再采用 κ = mc/ħ。比如引入粒子依赖的几何屏蔽因子 ξ(m)：κ = (mc/ħ) ξ(m)，
ξ(m) 是质量的函数，从而打破 a_TUFT ∝ m²。
代价：必须重新推导本源质量的量子驻波条件，重写 Frenet-Serret 映射，重新审计全部量纲，重推引力场方程。

> 否决路线C：单纯调整耦合常数。耦合系数 3/8 来自 EC + Dirac 旋量几何，不能随意修改；
> 修改系数不会改变 m² 比例，只能整体缩放两个修正项，无法解决**符号与相对比例冲突**。
