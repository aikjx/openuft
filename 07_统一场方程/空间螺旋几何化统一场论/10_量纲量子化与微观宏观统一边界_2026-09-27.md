# OpenUFT：量纲、量子化与微观—宏观联系

日期：2026-09-27。性质：候选模型的推导及研究边界；不是已完成的统一场论。前接 [固定荷稳定性求导](09_固定荷稳定性求导与谱验证_2026-09-27.md) 与 [局域数值解](08_修复包络的局域数值解与验证边界_2026-09-27.md)。没有把既有证伪结果或 L3 状态改为通过。

本轮确实得到的是：修复后的六次势标量模型具有一个非零局域数值解；固定荷约束修正消除了离散径向二阶变分的负方向；推导出同一形状的尺度族和低能流体极限。它们不足以推出电子、标准模型、量子引力或全部观测现象。

## 1. 一个约定贯穿所有公式

先取 ħ=c=1，平直时空符号为 (−,+,+,+)。

\[
\mathcal L=|\dot\psi|^2-|\nabla\psi|^2-U(s),\quad
s=|\psi|^2,\quad U(s)=\mu_0^2s-\lambda s^2+g_6s^3.
\]

参数满足 λ>0、g₆>0、μ₀²>λ²/(4g₆)，从而真空势有下界且零场为全局最低势点。变分给出

\[
\ddot\psi-\Delta\psi+(\mu_0^2-2\lambda|\psi|^2+3g_6|\psi|^4)\psi=0.
\]

这里采用正频背景 ψ=f exp(−iωt) 的正荷约定：

\[
\rho_N=i(\psi^*\dot\psi-\dot\psi^*\psi),\quad
\mathbf j_N=-i(\psi^*\nabla\psi-\nabla\psi^*\psi),\quad
Q_N=\int\rho_N=2\omega\int f^2.
\]

场方程直接给出 ∂ₜρ_N+∇·j_N=0；能量 E=∫(|ψ̇|²+|∇ψ|²+U)。该无量纲 Noether 荷不是已经测得的电荷。

## 2. 量纲总表及换算

以能量维数 E 为基准，四维作用量 S/ħ 无量纲，拉格朗日密度维数 E⁴。

| 对象 | 自然单位维数 |
|---|---|
| x、t | E⁻¹ |
| ∂、μ₀、ω、规范势 A | E |
| 规范场强 F、曲率 R | E² |
| 规范归一化复标量 ψ | E |
| Dirac 场 | E³ᐟ² |
| λ、电磁耦合 e、度规、Q_N | E⁰ |
| g₆、牛顿常数 G | E⁻² |
| 荷流 j、膜面张力 σ | E³ |
| 能量密度、势 U | E⁴ |
| 总能量 | E |

例如 [μ₀²s]=[λs²]=[g₆s³]=E⁴；运动方程各项都是 E³。前面圆柱表面模型的场归一化不同，不能直接套用此处体场 ψ 的量纲。

在 SI 中以 M、L、T、Q 分别表示质量、长度、时间、电荷的独立维数：

| 量 | SI 维数 |
|---|---|
| ħ、c、G | ML²/T；L/T；L³/(MT²) |
| 能量、动量、角频率、波数 | ML²/T²；ML/T；T⁻¹；L⁻¹ |
| 电场、磁场 | ML/(QT²)；M/(QT) |
| 电势、电矢势 | ML²/(QT²)；ML/(QT) |
| 电荷密度、电流密度 | Q/L³；Q/(L²T) |
| ε₀、μ₀（真空磁导率） | Q²T²/(ML³)；ML/Q² |
| 空间曲率、挠率；时空标量曲率 | L⁻¹；L⁻² |

本稿势中的 μ₀ 是质量能标参数，与表中 SI 真空磁导率同符号但不同对象；计算中应分别命名。使用 x⁰=ct 时，A₀=φ/c 与空间矢势具有相同量纲。α=e²/(4πε₀ħc) 无量纲；这只是单位一致性，不能决定 α 的数值。

若选物理能标 μ_E，长度单位为 ħc/μ_E，时间单位为 ħ/μ_E，自由标量静质量为 μ_E/c²。场的 SI 归一化还取决于作用量中 ħ、c 的配置，不能把自然单位场值当作 SI 数字。

## 3. 精确重标度与可控性

令

\[
\hat x=\mu_0x,\quad\hat t=\mu_0t,\quad
\psi=\frac{\mu_0}{\sqrt\lambda}\hat\psi,\quad
\xi=\frac{g_6\mu_0^2}{\lambda^2}.
\]

逐项代入而非猜测，得到

\[
S=\frac1\lambda\int d^4\hat x
\left[|\partial_{\hat t}\hat\psi|^2-|\hat\nabla\hat\psi|^2
-|\hat\psi|^2+|\hat\psi|^4-\xi|\hat\psi|^6\right].
\]

因此 ξ 控制无量纲形状，λ 同时影响经典荷与半经典展开：

\[
E=\frac{\mu_0}{\lambda}\hat E,\quad
Q_N=\frac{\hat Q_N}{\lambda},\quad
\omega=\mu_0\hat\omega,\quad r=\hat r/\mu_0.
\]

已有数值形状对应 ξ=1、ω̂=√0.9；Ê=275.763627466，Q̂=279.164294263，f̂(0)=0.722693526，荷加权均方根半径 r̂_rms=4.627988502。恢复 SI 后 E_phys=μ_E Ê/λ、r_phys=(ħc/μ_E)r̂。没有指定 μ_E、λ，就不能宣布得到某种已知粒子的质量和半径。

若 g₆=c₆/Λ²，则 μ₀/Λ=λ√(ξ/c₆)。原先 μ₀=λ=g₆=1、c₆=1 的计算没有 μ₀≪Λ 的尺度分离。保持 ξ=1，取 λ=0.01、μ₀=1、g₆=10⁻⁴、c₆=1，可由精确重标度得到 Λ=100：

- μ₀/Λ=0.01，f(0)/Λ=0.072269353；
- Q_N=27916.4294263，E=27576.3627466；
- r_rms=4.627988502/μ₀，形状未改变。

若八次势项为 c₈|ψ|⁸/Λ⁴，中心处它相对六次项的量级是 (c₈/c₆)f²/Λ²≈0.005223(c₈/c₆)。这是给定系数后的估算，不是已计算的量子误差；其余高阶项、圈修正、背景量子涨落仍须计算。有效理论的组织原则可参见 [Kaplan：Five lectures on effective field theory](https://arxiv.org/abs/nucl-th/0510023)。

## 4. 从经典场到量子理论需要补什么

正则动量 π=ψ̇*、π*=ψ̇，哈密顿量

\[
H=\int d^3x\,[\pi^*\pi+|\nabla\psi|^2+U].
\]

正则量子化要求 [ψ(x),π(y)]=iδ³(x−y)，及复共轭对易关系；恢复物理归一化时包含 ħ。自由极限的模能量为 √(k²+μ₀²)，激发属于自旋零玻色子。场的复数相位或空间旋转不会自动产生自旋 1/2 与费米统计。

量子 Fock 空间中的全局 U(1) 荷可按单位归一化计数粒子减反粒子；经典连续数值 Q_N=279.164… 不等于已经量子化的整数荷态。局域背景还需要零模集体坐标、涨落谱、重整化和衰变率计算。四维六次势是有效相互作用；有限个当前系数不能证明紫外完备。

Born 概率、纠缠、测量规则不能从本轮经典求导直接推出。它们可以作为量子理论结构加入，但加入不等于从螺旋几何导出。

## 5. 低能 Schrödinger 与宏观流体极限

令 ψ=e^(−iμ₀t)Φ/√(2μ₀)。代入完整场方程，精确得到

\[
i\dot\Phi=-\frac{\Delta\Phi}{2\mu_0}
-\frac{\lambda}{2\mu_0^2}|\Phi|^2\Phi
+\frac{3g_6}{8\mu_0^3}|\Phi|^4\Phi
+\frac{\ddot\Phi}{2\mu_0}.
\]

仅在慢时间、低动量且相互作用频移相对 μ₀ 小时，才能忽略最后一项。这给出立方—五次非线性 Schrödinger 方程；再取低密度弱相互作用极限，才得到自由 Schrödinger 方程。不能只凭 ω 接近 μ₀，就认定整个 Q-ball 内部都满足该近似。

记 g₂=−λ/(2μ₀²)、g₃=3g₆/(8μ₀³)，Φ=√n exp(iS)，v=∇S/μ₀，则在非相对论近似及 n>0 的区域：

\[
\partial_t n+\nabla\cdot(n\mathbf v)=0,
\]
\[
\partial_tS+\frac{|\nabla S|^2}{2\mu_0}+g_2n+g_3n^2
-\frac{\Delta\sqrt n}{2\mu_0\sqrt n}=0.
\]

相互作用能密度 ε_int=g₂n²/2+g₃n³/3，故压力

\[
p=n\frac{d\epsilon_{int}}{dn}-\epsilon_{int}
=\frac{g_2n^2}{2}+\frac{2g_3n^3}{3},\quad
c_s^2=\frac n{\mu_0}(g_2+2g_3n).
\]

声速式只适用于均匀慢变化背景，并要求右侧为正。负值意味着此近似下的长波失稳。该状态方程只属于这个模型，不是所有物质的状态方程；相位奇点与涡旋须另行处理。

## 6. 电磁与引力的协变接口

一种已知的最小耦合写法是

\[
S=\int\sqrt{-g}\,d^4x\left[
\frac R{16\pi G}-\frac14F_{\mu\nu}F^{\mu\nu}
-g^{\mu\nu}(D_\mu\psi)^*D_\nu\psi-U(s)\right],
\quad D_\mu=\nabla_\mu-ieA_\mu.
\]

补齐适当引力边界项。变分给出

\[
D_\mu D^\mu\psi-U'(s)\psi=0,\quad
\nabla_\mu F^{\mu\nu}=J^\nu,\quad
G_{\mu\nu}=8\pi G(T^{EM}_{\mu\nu}+T^\psi_{\mu\nu}).
\]

这里 J^ν=−(1/√−g)δS_m/δA_ν；用此定义固定电流符号，不能混用不同 D 的约定。标量应力为

\[
T^\psi_{\mu\nu}=(D_\mu\psi)^*D_\nu\psi+(D_\nu\psi)^*D_\mu\psi
-g_{\mu\nu}[(D_\alpha\psi)^*D^\alpha\psi+U].
\]

场方程和对称性给出总应力协变守恒。平直时空、A=0 时回到第 1 节；弱场慢速条件下可进一步取 Newton 极限。这些是已有耦合机制，不提供 e、G 的共同来源。中性 Q-ball 的数值解及谱不能直接转移到带电或自引力模型：背景和约束都要重算。

若并入标准模型，只能先写 S_EH+S_SM+S_ψ+S_portal。对标准模型单态 ψ，可有 κ|H|²|ψ|²，Higgs 真空使质量参数移位 μ_eff²=μ₀²+κv²/2。κ 是新输入；强、弱规范表示、手征费米子、Yukawa 参数、异常消除仍要明确，不能由一个 U(1) 代替。

## 7. 两条研究路线尚未统一

本轮球对称背景 f(r)e^(−iωt) 的空间荷流为零，T₀ᵢ=0；没有局部空间螺旋能流。前面圆柱螺旋波的 n≠0 模式有不同几何约束。局域性、相位周期性和旋转的概念不能替代两个作用量之间的映射证明。

可研究旋转候选 ψ=F(r,θ)e^(inφ−iωt)。其方程出现 n²/(r²sin²θ) 项，轴上须有 F∼(r sinθ)^|n|；需解二维边值问题。轨道角动量在相容约定下满足 J_z=nQ_N，但这不是电子的内禀半整数自旋。本轮未求解该背景，也未继承球对称谱结论。

## 8. 对“所有现象”的可核查边界

| 领域 | 本轮实际覆盖 | 尚缺的决定性工作 |
|---|---|---|
| 局域经典场 | 六次势背景、能荷、维里恒等式、固定荷离散谱 | 连续谱严格包络、非线性轨道稳定、裂变比较 |
| 量子力学 | 正则量子化接口、受条件限制的 Schrödinger 极限 | 背景量子谱、量子衰变、测量结构的来源 |
| 电磁相互作用 | 协变最小耦合方程 | 带电背景、辐射、量子修正与观测拟合 |
| 强弱作用与粒子身份 | 可注明标准模型接口 | 规范群、手征费米子、质量及混合参数预测 |
| 自旋与统计 | 当前标量是自旋零玻色场 | 产生半整数自旋与费米统计的机制 |
| 凝聚态与流体 | 特定模型的低能状态方程 | 真实材料、输运、温度、核物理及多体验证 |
| 宏观引力 | Einstein 耦合形式 | 自引力解、引力波、黑洞与精密检验 |

| 紫外量子引力 | 无 | 可控高能理论与独立证据 |

“所有量纲通过”只能针对明确列出的作用量及公式，不能涵盖未定义的所有物理量。“统一场论完成”需要共同机制、已知低能理论的恢复、独立参数预测与可证伪观测；当前尚不满足。

本轮的实际推进是固定荷二阶变分、网格与频率步长收敛、精确重标度以及微观到宏观的条件推导。后续最有证据价值的工作是连续谱验证、不同荷态的能量比较，以及给定耦合后重新求解带电背景；不能用扩大标题替代这些计算。
