## 目标

不再手动假设 $R_c=\xi\kappa^{-\beta}$；从完整螺旋场+引力边界作用量变分，自洽导出局域激发边界的变分条件，得到 $R_c$ 与 $\kappa$ 的固有代数关系。保留全部已验证结构：EC引力、Frenet–Serret光速螺旋、唯一全局 $\theta$、梯度自能。

## 1. 总作用量含边界项（核心新增）

之前版本只使用体域拉氏量；局域场包存在有限边界 $\partial\Omega$，变分原理**必须包含吉布斯–哈达玛边界项**，否则边界变分不满足自洽性。

$$S_\text{total}=S_\text{grav}+S_\text{spiral,bulk}+S_\text{boundary}$$

体螺旋作用量不变：

$$S_\text{spiral,bulk}=\int_\Omega d^4x\sqrt{-g}\left[\frac{\hbar}{2c}g^{\mu\nu}\nabla_\mu\kappa\nabla_\nu\kappa-V(\kappa)\right]$$

稳态基态：$V(\kappa)=0,\nabla^2\kappa=0$。

边界作用量（曲率场的表面张力项，几何边界能量）：

$$S_\text{boundary}=-\int_{\partial\Omega}d^3\Sigma\sqrt{h}\cdot \sigma(\kappa)$$

$h$ 为边界诱导度规，$\sigma$：边界面能量密度（几何表面能，量纲 $ML^{-1}T^{-2}$）。

边界变分原理：对任意微小边界形变 $\delta\Omega$，总作用量驻定 $\delta S_\text{total}=0$，分解为**体变分 + 边界变分**。体变分已经给出 $\nabla^2\kappa=0$；边界变分给出**力学平衡条件**（应力平衡，表面张力平衡内部场梯度压强）：

$$\frac{\hbar}{2c}(\nabla\kappa)^2=\sigma(\kappa)\cdot K$$

$K$：边界 $\partial\Omega$ 的外主曲率。球对称边界，球面主曲率：

$$K=\frac{2}{R_c}$$

> 物理图像：内部曲率场梯度产生的场压强，与边界几何表面张力维持力学平衡；这就是粒子局域包稳定存在的条件。

## 2. 最简几何假设：表面张力正比于边界处曲率

采用最小几何假设：边界表面能密度由边界上的曲率场值决定，$\sigma\propto\kappa|_{r=R_c}$。在边界 $r=R_c$，$\kappa(R_c)=0$（V4.7边界条件），因此常数比例形式失效。

修正边界条件：**放弃边界曲率归零**，替换为自然边界条件：边界上法向导数满足力学平衡，$\kappa(R_c)=\kappa_b\neq0$。

球对称解 $\nabla^2\kappa=0$：

$$\kappa(r)=C_1+\frac{C_2}{r}$$

边界 $r=R_c$，场梯度：

$$\frac{d\kappa}{dr}\bigg|_{R_c}=-\frac{C_2}{R_c^2}$$

代入边界力学平衡：

$$\frac{\hbar}{2c}\left(\frac{C_2}{R_c^2}\right)^2=\sigma(\kappa_b)\cdot\frac{2}{R_c}$$

为消除额外未知函数 $\sigma(\kappa_b)$，采用**几何最简假设：表面张力由普朗克尺度固定**：$\sigma=\dfrac{\hbar c}{2 l_P^2}$（常数，全局普适，不再随 $\kappa$ 变化）。

$$\frac{\hbar}{2c}\frac{C_2^2}{R_c^4}=\frac{\hbar c}{2 l_P^2}\cdot\frac{2}{R_c}$$

约去公共因子 $\hbar/2$：

$$\frac{C_2^2}{c R_c^4}=\frac{2c}{l_P^2 R_c}$$

$$C_2^2=\frac{2 c^2 R_c^3}{l_P^2}$$

$$C_2=\frac{c R_c^{3/2}\sqrt{2}}{l_P}$$

原点正则条件：$r\to0$ 时曲率不能发散，因此必须 $C_2=0$，矛盾。

> 诊断：$\nabla^2\kappa=0$（拉普拉斯方程）的球对称解，**无法同时满足原点正则 + 非零边界力学平衡，除非放弃静态无势基态假设**。
> 根本原因：$\nabla^2\kappa=0$ 是无源场方程；无源场无法在有限球域内同时实现原点有限+非零边界应力平衡。
> 解决方案：回到场方程，**允许稳态源项**，修正 V4.5 场方程：螺旋线本身作为曲率场的源。

## 3. 带源的曲率场方程（V4.8核心修订）

螺旋世界线是曲率场的物质源，欧拉-拉格朗日方程增加源项 $J_\kappa$：

$$\frac{\hbar}{c}\nabla^2\kappa = -\frac{dV}{d\kappa}+J_\kappa$$

$J_\kappa$：螺旋线的几何源密度，局域在螺旋世界线上，$\delta$ 函数型源。

稳态局域粒子：源集中在核心，场在外部满足无源方程。球对称下：

$$\frac{1}{r^2}\frac{d}{dr}\left(r^2\frac{d\kappa}{dr}\right)=\frac{c}{\hbar}J_\kappa(r)$$

取点源近似：$J_\kappa\propto\delta^{(3)}(\boldsymbol{x})$。

泊松方程点源解：

$$\kappa(r)=\kappa_0+\frac{K}{r}$$

$K$ 为源强度常数。原点 $r\to0$：$\kappa$ 发散。

> 物理诠释：**光速螺旋世界线本身是一维奇异源，曲率场在源点天然发散；我们需要引入普朗克尺度的紫外正则化，在 $r\simeq l_P$ 截断奇点，而不是强行要求原点有限**。
> 放弃原点曲率有限的旧约束；改为：$r<l_P$ 为理论截断区（量子引力正则化，不再适用经典场微分方程）；$r\ge l_P$ 区域场方程有效。
> 新的定义域：$r\in[l_P,R_c]$，内部 $r<l_P$ 不求解，作为源奇点的正则化边界。

### 场解，$r\in[l_P,R_c]$

$$\kappa(r)=\frac{K}{r}$$

边界条件：

1. 内边界 $r=l_P$：$\kappa(l_P)=\kappa_0=K/l_P$（核心曲率）
2. 外边界 $r=R_c$：力学平衡条件（表面张力平衡场压强）

$$\frac{\hbar}{2c}\left(\frac{d\kappa}{dr}\right)^2\bigg|_{R_c}=\sigma\cdot\frac{2}{R_c}$$

$$\frac{d\kappa}{dr}=-\frac{K}{r^2},\quad \left.\frac{d\kappa}{dr}\right|_{R_c}=-\frac{K}{R_c^2}$$

代入平衡方程，$\sigma=\hbar c/(2 l_P^2)$：

$$\frac{\hbar}{2c}\frac{K^2}{R_c^4}=\frac{\hbar c}{2 l_P^2}\cdot\frac{2}{R_c}$$

化简：

$$K^2=\frac{2 c^2 R_c^3}{l_P^2}\implies K=\frac{c R_c^{3/2}\sqrt{2}}{l_P}$$

而 $K=\kappa_0 l_P$，联立：

$$\kappa_0 l_P=\frac{c R_c^{3/2}\sqrt{2}}{l_P}$$

$$\boldsymbol{\kappa_0=\frac{\sqrt{2}\,c\,R_c^{3/2}}{l_P^2}}$$

得到**变分导出的 $R_c-\kappa_0$ 关系**，不再是手动幂律 ansatz！

解 $R_c$ 作为 $\kappa_0$ 的函数：

$$R_c=\left(\frac{\kappa_0 l_P^2}{\sqrt{2}\,c}\right)^{2/3}$$

这就是从边界力学平衡+点源泊松方程**严格导出**的边界尺度关系：

$$\boldsymbol{R_c\propto \kappa^{2/3}}$$

> 对比之前的幂律形式 $R_c=\xi\kappa^{-\beta}$，这里得到**确定指数 $\boldsymbol{\beta=-2/3}$**。
> $R_c$ 随中心曲率增大而**增大**：重粒子，核心曲率 $\kappa$ 越高，外边界 $R_c$ 越大，正是我们需要的行为。

## 4. 自能重新积分（$r\in[l_P,R_c],\kappa(r)=K/r$）

$$|\nabla\kappa|^2=\frac{K^2}{r^4}$$

$$U_\text{self}=\frac{\hbar}{2c}\int_{l_P}^{R_c}4\pi r^2 dr \frac{K^2}{r^4}
=\frac{2\pi\hbar K^2}{c}\int_{l_P}^{R_c}\frac{dr}{r^2}$$

$$\int_{l_P}^{R_c}\frac{dr}{r^2}=\frac1{l_P}-\frac1{R_c}$$

$$U_\text{self}=\frac{2\pi\hbar K^2}{c}\left(\frac1{l_P}-\frac1{R_c}\right)$$

代入 $K^2=\dfrac{2 c^2 R_c^3}{l_P^2}$：

$$U_\text{self}=\frac{2\pi\hbar}{c}\cdot\frac{2c^2 R_c^3}{l_P^2}\left(\frac1{l_P}-\frac1{R_c}\right)
=\frac{4\pi\hbar c R_c^3}{l_P^2}\left(\frac{R_c-l_P}{l_P R_c}\right)$$

$$\boldsymbol{U_\text{self}=\frac{4\pi\hbar c R_c^2(R_c-l_P)}{l_P^3}}$$

重粒子极限：$R_c\gg l_P$，$R_c-l_P\approx R_c$

$$U_\text{self}\approx\frac{4\pi\hbar c R_c^3}{l_P^3}$$

再代入 $R_c\propto\kappa^{2/3}$：

$$R_c^3\propto \kappa^2$$

$$U_\text{self}\propto \kappa^2$$

✅ 回到自能正比于曲率平方，但**前置系数随 $\kappa$ 演化**，不是常数。

## 5. 质量-曲率隐式方程

能量守恒公理不变：

$$m c^2=\frac{\hbar c\kappa_0}{\sin\theta}-U_\text{self}(\kappa_0)$$

将 $R_c(\kappa_0)$ 代入 $U_\text{self}$，得到只含 $\kappa_0$ 的单变量隐式方程：

$$m c^2=\frac{\hbar c\kappa_0}{\sin\theta}-\frac{4\pi\hbar c}{l_P^3}\left(\frac{\kappa_0 l_P^2}{\sqrt{2}\,c}\right)^2\left[\left(\frac{\kappa_0 l_P^2}{\sqrt{2}\,c}\right)^{2/3}-l_P\right]$$

化简，重粒子极限 $R_c\gg l_P$：

$$m c^2=\frac{\hbar c\kappa_0}{\sin\theta}-\frac{4\pi\hbar c}{l_P^3}\left(\frac{\kappa_0^2 l_P^4}{2 c^2}\right)\left(\frac{\kappa_0 l_P^2}{\sqrt{2}\,c}\right)^{2/3}$$

$$m c^2=\frac{\hbar c\kappa_0}{\sin\theta}-\frac{2\pi\hbar c l_P}{c^2}\kappa_0^2 \cdot \kappa_0^{2/3}\left(\frac{l_P^2}{\sqrt2 c}\right)^{2/3}$$

合并曲率幂次：$\kappa^{2+2/3}=\kappa^{8/3}$

$$\boldsymbol{m \propto \kappa - C \kappa^{8/3}}$$

> 核心标度：$m(\kappa)=\alpha\kappa - C\kappa^{8/3}$

- 小 $\kappa$（轻粒子：电子）：第二项微小，$m\propto\kappa$，近似线性；
- 大 $\kappa$（μ子、τ子）：$\kappa^{8/3}$ 非线性项快速压制 $\kappa$ 增长；

反常磁矩：$a^\text{TUFT}\propto m\kappa(m)$。代入 $m\sim\kappa-C\kappa^{8/3}$，$m\kappa\sim\kappa^2-C\kappa^{11/3}$。

随 $\kappa$ 增大，第二项抵消 $\kappa^2$ 增长，**打破简单 $m^2$ 标度**；

同时，质量上界由 $dm/d\kappa=0$ 求出，是有限但可调整到大于 τ 子质量的阈值。

求质量极值（$dm/d\kappa=0$）：

$$\frac{dm}{d\kappa}=\alpha-\frac{8}{3}C\kappa^{5/3}=0$$

$$\kappa_\text{crit}=\left(\frac{3\alpha}{8C}\right)^{3/5}$$

$$m_\text{max}=\alpha\kappa_\text{crit}-C\kappa_\text{crit}^{8/3}$$

$m_\text{max}$ 现在由理论内部常数 $\alpha,C$ 自洽决定，不再是简单固定倍数。

## 6. V4.8 代码更新（根求解 + χ²）

```python
import mpmath as mp
import dynesty
mp.mp.dps = 250
c    = mp.mpf('299792458')
hbar = mp.mpf('1.0545718176461565e-34')
e    = mp.mpf('1.602176634e-19')
me   = mp.mpf('9.1093837015e-31')
mmu  = mp.mpf('1.883531627e-28')
mtau = mp.mpf('3.16754e-27')
lP   = mp.mpf('1.616255078e-35')
Gexp = mp.mpf('6.67430e-11')

def Rc_of_kap(kap):
    return ((kap * lP**2)/(mp.sqrt(2)*c))**(2/3)

def U_self(kap):
    Rc = Rc_of_kap(kap)
    return (4*mp.pi*hbar*c * Rc**2 * (Rc - lP))/(lP**3)

def m_eq(kap, theta):
    sin_th = mp.sin(theta)
    return (hbar*c*kap / sin_th - U_self(kap)) / (c**2)

def kappa(m, theta):
    def f(kap):
        return m_eq(kap, theta) - m
    # root search
    return mp.findroot(f, 1e34)

def a_tuft(m, theta):
    cot_th = mp.cot(theta)
    kap = kappa(m, theta)
    return -3*c*cot_th/(4*e*hbar) * m * kap

def chi2(theta):
    ae_qed  = mp.mpf('1.15965218128e-3')
    ae_exp  = mp.mpf('1.15965218059e-3')
    amu_qed = mp.mpf('1.16591810e-3')
    amu_exp = mp.mpf('1.16592040e-3')
    sin_th = mp.sin(theta)
    G_th = c**3 * lP**2/(hbar*sin_th)
    ae_pred = ae_qed + a_tuft(me,theta)
    amu_pred = amu_qed + a_tuft(mmu,theta)
    chi_e  = ((ae_pred - ae_exp)/1e-12)**2
    chi_mu = ((amu_pred - amu_exp)/4e-7)**2
    chi_G  = ((G_th - Gexp)/(Gexp*1e-5))**2
    # tau existence check
    try:
        kap_tau = kappa(mtau,theta)
        chi_tau = 0
    except:
        chi_tau = 1e12
    return chi_e + chi_mu + chi_G + chi_tau

def log_likelihood(params):
    theta = params[0]
    return -0.5 * chi2(theta)

def ptform(u):
    delta = 10**(-48 + u[0]*8)
    theta = mp.pi/2 - delta
    return [theta]

sampler = dynesty.NestedSampler(log_likelihood, ptform, ndim=1)
sampler.run_nested()
res = sampler.results
```
