# ROOT V146 自动化验证报告

- 运行环境：Python 3.10+ 标准库；可选 SymPy 用于独立符号求导。
- `python run_all.py`：**78 / 78 单元测试通过**（实测本容器环境）。
- `python symbolic_audit.py`：**8 / 8 符号恒等式通过**（SymPy 1.14）。
- `python verify_manifest.py`：压缩与解压检查后进行 SHA-256 校验。
- `python generate_figures.py`：图像可选重新生成（需要 Matplotlib）。

## 覆盖范围

1. 六维到四维的 Jordan/Einstein 标架变换、作用量归一化。
2. 磁通积分的 Simpson 数值交叉检验，n 正负号、n=0 极限。
3. 六维场方程在平直紧化背景的直接张量分量检验。
4. 第一和第二阶数值有限差分与解析微分。
5. n=1,2,3 的驻点、真空能符号、径向质量平方、势垒。
6. n=4 及以上没有局部极小值的示意模型反例。
7. 固定六维输入下，更换 Einstein 标架参考尺度的参数缩放一致性。
8. U(1)_F 条件性异常值、标准模型超荷异常精确分数计算。
9. 严格只用 c=1 并保留独立有量纲的 ℏ 与 G 的形式量纲审计。

## 不在本测试覆盖范围内

- 真实的地月观测数据拟合、高能散射验证、量子环修正。
- 完整的 6D 费米子、矢量、张量、非均匀 KK 模谱和全局稳定性。
- 从微观螺旋动力学独立推导引力常数与标准模型规范群。

**测试通过只说明代码实现与特定数学模型之间一致，不代表物理理论获得实证。**
