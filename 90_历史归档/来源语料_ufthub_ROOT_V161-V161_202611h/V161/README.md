# ROOT V161：应力平衡、仿射稳定性、吸引与排斥

仅 c=1；[hbar]=ML, [G]=L/M。归一化长度 L0、能量 hbar/L0、力 hbar/L0²；没有把 hbar 或 G 设为 1。此版本是对指定已知模型的数学与数值研究，并未推导四力共同起源或完成实验验证。

## A. 张量应力平衡
在 Minkowski 时空、静态、完整孤立系统、边界通量足够快消失的条件下，∂k T^{kj}=0，所以 ∂k(x^i T^{kj})=T^{ij}，积分得 ∫T^{ij}d³x=0。正能量零间隔流的 T_motion^{ij}=sum rho_a n_a^i n_a^j 为半正定，且 trace T_motion=ρ_total。若总能量非零，纯此类应力无法满足全积分为零；其余相互作用或束缚贡献必须满足 ∫T_interaction^{ij}=-∫T_motion^{ij}。不适用于忽略边界或强曲率的系统。随机数值检查 256 组、每组128个方向，共32768个方向样本；不是物理实验。

## B. 三维仿射稳定性证明
Skyrme 静态能量 E2=∫tr D，E4=∫tr cof D，D_ij=−Tr(R_i R_j)/2（反厄米右电流 R_i）。球对称 hedgehog 的 D=t I+(p−t)nn^T，p=F'^2、t=sin²F/r²；cof D=pt I+(t²−pt)nn^T。角积分 ∫n_i n_j dΩ=4πδij/3，故 ∫D=(E2/3)I、∫cof D=(E4/3)I。
令形变 x=L y，det L>0，U_L(x)=U(y)。则 D_L=L^{-T}D L^{-1}，cof D_L=(det L)^−2 L cof(D) L^T。积分体积元乘 det L。得 E_L=E2 det L tr(L^{-1} L^{-T})/3 + E4 tr(L^T L)/(3 det L)。用奇异值 s_i=e^{x_i}，S=sum x_i，得到 E_L=(E2 sum e^{S−2x_i}+E4 sum e^{2x_i−S})/3。若 E2=E4=E0/2，则 E_L/E0=sum cosh(S−2x_i)/3≥1，等号当全部 x_i=0，即 L 是刚性旋转。此为任意保持方向的常数可逆仿射形变的全局极小值；不代表一般非均匀形变、完整动态谱或量子稳定性。H=(J−2I)^T(J−2I)/3，其中 J 为全 1 矩阵；H 对角1，非对角−1/3；谱为1/3,4/3,4/3。
程序独立重求 V160 的径向 BVP：(r²+2sin²F)F''+2rF'+sin(2F)(F'^2−1−sin²F/r²)=0。原点截断0.001、远端 Robin RF'+2F=0；R=40、80 两套网格。尾部 E2 领先阶补偿，E4 尾部与原点遗漏很小但不声称所有位数是物理精度。实际三维积分通过径向积分及24×48角向求积分别计算 D 和 cof D 的变换，256组随机非对角矩阵，与解析式交叉验证；精确球对称归一化 Hessian 还通过 SymPy 和有限差分检查。未执行真正任意三维动态扰动模拟。

## C. 同一传播算子并不决定力的正负
定义静态 Green 核 K_mu(r)=exp(−mu r)/(4πr)，[mu]=L^-1。在标准正能动能、线性实标量耦合、静态同号源条件下，消去标量场的静态能量可得交叉势 V_s=−hbar g1 g2 K_mu。标准 Maxwell 或 Proca 型矢量场对静态同号守恒荷则有 V_v=+hbar q1 q2 K_mu。这里 g,q 是无量纲的模型耦合；静态势自能已去除。源运动、非线性、规范内部自由度均不在该静态近似内。对 r 求导，F_r=±hbar q1 q2 (1+mu r)exp(−mu r)/(4πr²)，矢量取正、标量取负（同号荷）。mu=0 时两种场都可以有光速自由传播，却有相反静态相互作用符号。mu 非零时特征速度仍为 c，但群速度不等于 c。牛顿引力对应静态 −Gm1m2/r，不是由上述标量模型独立推出，不能据此认定引力是标量场。
实际求积：两个归一化三维 Gaussian 源，每个标准差 σ，间距 r；交叉 Green 核 K=(2π²r)^−1∫_0^∞ dk k sin(kr) exp(−σ² k²)/(k²+mu²)。分别求解析被积导数和中心差分；mu=0 时与 erf(r/(2σ))/(4πr) 交叉验证。48组 mu,σ,r 参数。这里是静态场计算，不是实验。四力共享传播和守恒语言，不代表相同自旋、规范群、荷、耦合；尤其强力禁闭、弱力手征性不能由静态 Yukawa 核概括。
