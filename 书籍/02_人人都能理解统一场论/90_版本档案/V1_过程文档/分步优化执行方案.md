## 🔧 优化标准与规范

### 1. LaTeX公式格式规范

#### 标准格式
```markdown
# 内联公式
$E = mc^2$

# 独立公式（带空行）
$$E = mc^2$$

# 带量纲的独立公式
$$E = mc^2$$

其中：
- $E$ 是能量 [ML²T⁻²]
- $m$ 是质量 [M]
- $c$ 是光速 [LT⁻¹]
```

#### 矢量表示
```markdown
# 使用 \vec{} 表示矢量
$$\vec{F} = m\vec{a}$$
$$\vec{P} = m(\vec{c} - \vec{v})$$
```

#### 分数表示
```markdown
# 使用 \dfrac 显示分数
$$\frac{a}{b}$$  # 行内用 \frac
$$\dfrac{a}{b}$$  # 独立公式用 \dfrac
```

### 2. 量纲标注规范

#### 基本量纲
- [M]：质量
- [L]：长度
- [T]：时间
- [Q]：电荷

#### 复合量纲
- [MLT⁻²]：力
- [ML²T⁻²]：能量
- [MLT⁻¹]：动量
- [LT⁻²]：加速度、场强
- [MT⁻¹Q⁻¹]：磁场

#### 标注方式
```markdown
# 方式1：在公式后面
$$F = G\dfrac{m_1 m_2}{r^2}$$
[MLT⁻²]

# 方式2：在符号说明中
其中：
- $F$ 是力 [MLT⁻²]
- $m$ 是质量 [M]
```

### 3. 核心公式列表

根据《大道至简-统一场论.md》，必须包含的核心公式：

| 公式编号 | 公式名称 | LaTeX | 量纲 |
|---------|---------|-------|------|
| 公式1 | 时空同一化方程 | $\vec{r}(t) = \vec{c}t$ | [L] |
| 公式2 | 三维螺旋时空方程 | $\vec{r}(t) = r\cos\omega t \cdot \vec{i} + r\sin\omega t \cdot \vec{j} + ht \cdot \vec{k}$ | [L] |
| 公式3 | 质量定义方程 | $m = k \dfrac{dn}{d\Omega}$ | [M] |
| 公式4 | 引力场定义方程 | $\vec{A} = -Gk\dfrac{\Delta n}{\Delta s}\dfrac{\vec{r}}{r}$ | [LT⁻²] |
| 公式5 | 静止动量方程 | $\vec{p}_{0} = m_{0}\vec{c}_{0}$ | [MLT⁻¹] |
| 公式6 | 运动动量方程 | $\vec{P} = m(\vec{c} - \vec{v})$ | [MLT⁻¹] |
| 公式7 | 宇宙大统一方程 | $\vec{F} = \dfrac{d\vec{P}}{dt} = \vec{c}\dfrac{dm}{dt} - \vec{v}\dfrac{dm}{dt} + m\dfrac{d\vec{c}}{dt} - m\dfrac{d\vec{v}}{dt}$ | [MLT⁻²] |
| 公式9 | 电荷定义方程 | $q = k^{\prime}k\dfrac{1}{\Omega^{2}}\dfrac{d\Omega}{dt}$ | [Q] |
| 公式10 | 电场定义方程 | $\vec{E} = -\dfrac{kk^{\prime}}{4\pi\varepsilon_0\Omega^2}\dfrac{d\Omega}{dt}\dfrac{\vec{r}}{r^3}$ | [MLT⁻³Q⁻¹] |
| 公式11 | 磁场定义方程 | $\vec{B} = \dfrac{\mu_{0} \gamma k k^{\prime}}{4 \pi \Omega^{2}} \dfrac{d \Omega}{d t} \dfrac{[(x-v t) \vec{i}+y \vec{j}+z \vec{k}]}{\left[\gamma^{2}(x-v t)^{2}+y^{2}+z^{2}\right]^{3/2}}$ | [MT⁻¹Q⁻¹] |
| 公式16 | 能量方程 | $E = m_0 c^2 = mc^2\sqrt{1 - \dfrac{v^2}{c^2}}$ | [ML²T⁻²] |
| 公式18 | 核力场定义方程 | $\vec{D} = - G m \dfrac{ \vec{c} - 3 \dfrac{\vec{r}}{r} \dot{r} }{r^3}$ | [LT⁻²] |
| 公式19 | 引力光速统一方程 | $Z = \dfrac{Gc}{2}$ | [L³M⁻¹T⁻²] |
