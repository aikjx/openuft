> 本方法是 `02_共享基础/研究规范` 的第六支：**D 求导 / P 证明 / V 验证 / F 第一性 / A 精算审计 / C 判据**。

**适用**：任何「某主张成立 / 已解决 / 已导出」的登记，在计入 claims 之前应先过本判据。
**与 F 的分工**：F 判「这是不是第一性」（无量纲、非循环、双锚点）；**C 判「这条主张值不值得进入精算」**。先过 C，再过 F。

## 0. 为什么需要本方法

首轮全维审计发现，一条主张可以在**数学自洽的外表下完全失效**。三类伪装反复出现：

1. **恒等式复读**：把定义式代入后逐字还原成已知公式，却写成「推导得出」；
2. **参数吸收**：用自由常数 / 自由函数把任何观测值拟合进去，且不说明该常数从哪来；
3. **自评失真**：来料自评 `PASS:20 / OPEN:17 / FAIL:0`，台账实读却是 `pass 13 / falsified 11`。

更关键的是：一个主张被否证后**不会消失，而是退守**（换群族、加额外维、抬阈值、搬紫外完备、剔掉引力）。逐条驳退守是无限工作。

**本方法的目标**：把「这句话值不值得信」变成可执行、可复跑、可反驳的读数，并把「给退守定价」变成有限工作。

## 1. 判据的七个层次（按「它在审什么」分）

一条主张要连过七道门。**前一道不过，后面全部免谈**——不要在没有定义域的式子上做量纲，也不要在恒等式上做数值。

| 层 | 审什么 | 过不了时的典型后果 |
|---|---|---|
| **W1 语义层** | 这句话到底在说什么，有没有物理内容 | 「导出 G」实为换单位；「新预言」实为重命名 |
| **W2 量纲与口径层** | 各项能否相加、单位与约定是否登记 | 求和式里出现 $L^{-1}$ 与 $T^{-1}$；跨册同一符号两个口径 |
| **W3 定义域与存在性层** | 解是否存在、方向是否正确、场是否耦合 | 声称的孤子是盒长伪影；声称的力方向反号 |
| **W4 派生与信息量层** | 结论是推导出来的还是记账记出来的 | 「导出 α」经 $\ell_P$ 输入 $G$（循环） |
| **W5 可证伪与参数账层** | 自由参数够不够、本代能否否证 | 参数比观测多；唯一预言超可及 0.53 个量级 |
| **W6 控制组与反噬层** | 判据本身有没有判别力 | 判据对什么都判 FAIL ⇒ 零信息量 |
| **W7 数值与精度层** | 读数是不是真的，还是工具假象 | 残差恒为 0 只说明两侧同一表达式 |

**用法**：按 W1→W7 顺序过一遍，**只在失败的那一层停下定价**，不要在通过的层上反复打磨。

## 3. 使用方式：十步审查流水线

| 步 | 动作 | 命中即 |
|---|---|---|
| 0 | 归档来料原文（正本留档，后续引用指向它） | 继续 |
| 1 | 把主张拆成可独立判真伪的假设集 $A=\{a_1\dots a_N\}$ | 继续 |
| 2 | W1 语义：命名 vs 预言、抄录检测、换参零判别力 | 重命名 ⇒ **停** |
| 3 | W2 量纲口径：逐项量纲、口径登记、幂次穷举、循环自指 | 不齐 ⇒ 走「三分支修法空间」 |
| 4 | W3 定义域：解存在性、方向反演、耦合门票、正面物理判据 | 无耦合项 ⇒ **停** |
| 5 | W4 信息量：欠定性、第一性导出最低要求 F1–F5 | 记账 ⇒ 降级为 L1 重述 |
| 6 | W5 参数账与可证伪：Ω5、本代可及、噪声对照 | 超参数或不可及 ⇒ 入缺口账 |
| 7 | W6 控制组：必设「已知活着的」与「已知死的」 | 控制组不过 ⇒ **判据作废，回到第 1 步** |
| 8 | W7 数值纪律：扫收敛阶、双路径对拍、阈值取误差界 | 残差恒 0 ⇒ 不算验证 |
| 9 | 定价与判决：修复定价、退守成本核算、最小证伪集 | verdict 由机读驱动，**禁硬编码** |
| 10 | 反噬：同款准则反过来压测被审对象自身 | 反噬全部落空 ⇒ 结论可出 |

**两条总纪律**：
- **verdict 必须由机读驱动**：算出数却在代码里硬编码判定，是死代码，不是判据。
- **判据的资格由控制组授予，不由热情授予**：一套对什么都判 FAIL 的判据，信息量为零。

## 4. 八条纪律（判据自身也会错）

| 编号 | 纪律 |
|---|---|
| D-1 | 手算 / 文本启发式判据必须机器兜底（判据写错比算错更隐蔽） |
| D-2 | 阈值按工具误差界取，不按「看起来够严」取（过严 ⇒ 假失败） |
| D-3 | 单调性 / 排序类守卫先固定自变量的排序方向（排序方向本身是未声明假设） |
| D-4 | 计数类总账必须在全部条目登记之后再算（写在开头天然少算自己） |
| D-5 | 跨册口径冲突须显式双轨登记并声明采信口径 |
| D-6 | 期望值靠变异 / 控制点火校准，不靠改文本顺序校准 |
| D-7 | 外部 / 未证实数值标 `needs_official_confirmation`，核实前不得作为判据 |
| D-8 | 判据宽度须双向对照校准（过严与过宽对称致命） |

## 5. 与 D / P / V / F 的关系

```
      正向（怎么研究）                审计侧（怎么判）
  D 求导 ──> 方程                 C 判据 ──> 这条主张值不值得进精算
  P 证明 ──> 定理                      │
  V 验证 ──> 读数                      ├─> F 第一性判据（无量纲？非循环？双锚点？）
  A 精算 ──> 误差预算                  └─> Ω5 参数计数门
```

- **C 是 V 的前门**：没有判据的验证，只是在给恒等式做高精度复算。
- **C 不是 P 的替代品**：判据输出「这条不成立」，定理输出「这类不可能」。能升定理的必须升定理。
- **F 是第一性的最后闸门**：C 全过也不等于第一性，还须过 F 的六判据。

## 7. 诚实边界（本方法自身的限制）

1. 本方法只判「值不值得花时间」，**不判物理真伪**——四十条全过也不等于理论成立。
2. 判据**会老化**：本规范是 2026-10-20 的快照，新判据须增量追加。
3. 判据**需要反噬**：按 P-07，判据自身也应被同款准则压测；未被反噬的判据不得自认证。
4. 判据**依赖控制组**：失去控制组的判据应即时作废，而不是继续使用。
5. 本方法不能替代实验检验；过检条目仍需实验确认才算「已验证」。
