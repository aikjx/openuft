# ROOT 光速与光子运动全情况总表｜统一采用 \(c=1\)

> 只读来料正本。用户提供原文，整理时仅做排版归一，不改物理主张。Excel 工作簿未随正文提供，不代验收。

这次要解决的核心问题是：

**光在传播，光子是否也在移动？光子有没有内部螺旋运动？光速是否始终不变？为什么有些光能减速、停止、旋转、弯曲，甚至表现出超光速？**

先明确一个最重要的结论：

**真空中自由传播的光子始终以局部光速 \(c=1\) 运动，但光的波峰速度、光束轴向传播速度、能量传播速度、介质中的群速度以及信息传播速度，不一定都等于 1。**

另外，光子不能被加速到光速，也不能减速到真空静止状态。它是无静止质量粒子，没有合法的静止参考系。这是相对论中的基本结论。

## 一、首先统一所有物理定义

| 物理量 | 符号 | 在 \(c=1\) 下的公式或定义 |
|---|---|---|
| 真空光速 | \(c\) | **1** |
| 光子静止质量 | \(m_0\) | 0（标准理论） |
| 光子能量 | \(E\) | \(\hbar\omega\) |
| 光子动量大小 | \(p\) | \(E=\hbar k\) |
| 光子色散关系 | — | \(E^2=p^2+m_0^2\) |
| 真空频率 | \(\omega\) | \(\omega=k\) |
| 波长 | \(\lambda\) | \(2\pi/k\) |
| 周期 | \(T\) | \(2\pi/\omega\) |
| 相速度 | \(v_{\rm ph}\) | \(\omega/k\) |
| 群速度 | \(v_g\) | \(d\omega/dk\) |
| 光子自由传播速度 | \(v_\gamma\) | 1 |
| 光子固有时 | \(d\tau\) | 沿零世界线有 \(d\tau=0\) |
| 光子自旋投影 | \(S_\parallel\) | \(\pm\hbar\) |
| 光子圆柱螺旋半径 | \(R\) | 不存在已证实的通用数值 |
| 空间自身螺旋角速度 | \(\Omega_s\) | ROOT 待验证的未知量 |

这里将 \(c=1\) 作为全部理论推导的单位约定，\(\hbar\) 与 \(G\) 保留独立量纲。需要展示真实仪器数据时，另外给出 SI 对照值。根据 NIST，SI 中真空光速恰为 \(299\,792\,458\ \mathrm{m/s}\)。

| 激光 | 是 | 真空中为 1 | 多光子相干场传播 |

| 普通玻璃中的光 | 是 | 相速度约 0.658 | 受折射率影响 |

| 驻波 | 双向分量传播 | 各自由分量为 1 | 净平均能流可为零 |
| 光学腔内光 | 可以持续往返传播 | 取决于腔体介质和模式 | 被反射或约束，能形成驻波 |

| 被储存的光信息 | 可暂时不以传播光场形式存在 | 储存期间不适用 | 相干信息保存在原子等介质中 |
| 引力场中的光 | 是 | 局部仍为 1 | 世界线可弯曲 |

## 三、所有速度类型对照表

为什么科学实验有时说“光速变慢”，有时说“超光速”？

| 速度类型 | \(c=1\) 下的表达式 | 能否大于 1？ |
|---|---|---|
| 自由光子的局部速度 | \(v_\gamma=1\) | 不能 |
| 真空平面波相速度 | \(\omega/k=1\) | 不能 |
| 真空平面波群速度 | \(d\omega/dk=1\) | 不能 |
| 介质相速度 | \(1/n\) | 特殊介质或频段可大于 1 |
| 介质群速度 | \(1/n_g\) | 特殊色散条件下可以 |
| 波导轴向群速度 | \(\sqrt{1-\omega_c^2/\omega^2}\) | 理想真空波导不能 |
| 波导相速度 | \(1/\sqrt{1-\omega_c^2/\omega^2}\) | 可以 |
| 射线轴向投影速度 | \(\cos\theta\) | 不能 |
| 某些结构光的峰值速度 | 取决于波束结构 | 可以 |
| 真正信息前沿速度 | \(v_{\rm front}\leq1\) | 不能超出局部因果光锥 |
| 理想驻波节点速度 | 0 | 不适用 |
| 特定引力坐标中的光速 | 与度规、坐标有关 | 坐标值不代表局部测量 |

相速度或干涉峰速度超过 1，并不意味着光子或信息真正突破相对论的因果速度限制。

## 六、ROOT 螺旋运动模型：精算实例

如果假设光子的真实空间轨迹沿圆柱螺旋运行：

\[ \mathbf r(t)=(R\cos\Omega t,R\sin\Omega t,pt) \]

则在总速为 1 的条件下：

\[ \boxed{(R\Omega)^2+p^2=1} \]

\[ \boxed{\kappa=R\Omega^2,\quad \tau=p\Omega} \]

\[ \boxed{\Omega^2=\kappa^2+\tau^2} \]

取假设值 \(R=1\,\mu\mathrm m\)、\(p=0.9\)，得到：

| 几何量 | 精算结果 |
|---|---|
| 总速度 | 1 |
| 轴向速度 \(p\) | 0.900000 |
| 横向速度 \(R\Omega\) | 0.435890 |
| 角速度 \(\Omega\) | \(4.358899\times10^5\ \mathrm{m^{-1}}\) |
| 曲率 \(\kappa\) | \(1.900000\times10^5\ \mathrm{m^{-1}}\) |
| 挠率 \(\tau\) | \(3.923009\times10^5\ \mathrm{m^{-1}}\) |
| 每圈轴向节距 | 12.973 μm |
| 每圈 SI 时间 | 48.082 fs |

这是**数学一致的假设螺旋轨迹**，不是已经实验测出的光子螺旋半径。尤其是，当 \(R\Omega\ne0\) 时，该轨迹具有非零空间曲率，不能直接当作平直真空中不受相互作用的自由光子轨迹。

## 七、最关键的物理区别

| 问题 | 答案 |
|---|---|
| 光子向前移动时，还存在电磁振荡吗？ | 存在光场的时空振荡；单光子不能简单当成一个振动的小球 |
| 圆偏振光边移动边旋转吗？ | 电场方向随相位旋转，是 |
| 光子中心一定绕轴运动吗？ | 没有证据证明 |
| 光子自旋是不是经典物体自转？ | 不是 |
| 涡旋光能否形成螺旋能流？ | 可以，已确立 |
| 空间本身是否具有内在光速螺旋？ | 尚未确立 |
| 单凭 \((R\Omega)^2+p^2=1\) 能证明空间螺旋吗？ | 不能，只能证明速度分解几何自洽 |
| ROOT 要突破什么？ | 独立预测 \(R,\Omega,\kappa,\tau\)，并检验相对论与电磁学一致性 |

光的自旋和轨道角动量已有成熟的理论与实验研究，特别是涡旋光的螺旋波前与能流。
