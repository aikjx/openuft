# 第十章｜新增加的强判据：一代标准模型规范异常抵消

## 10.1 为什么这比“方向垂直”重要

四维手征规范量子场论可能存在量子反常。规范对称性若被未抵消的规范异常破坏，会破坏 Ward 恒等式与量子一致性。任意提议将螺旋自由度转成标准模型费米子，必须满足手征谱的异常抵消条件，否则无法接近真正统一理论。

## 10.2 用左手 Weyl 场精确计算

在标准模型每一代中，按全部场改写为左手 Weyl 场的约定，取：`Q_L=(3,2)_{1/6}`、`u^c_L=(\bar3,1)_{−2/3}`、`d^c_L=(\bar3,1)_{1/3}`、`L_L=(1,2)_{−1/2}`、`e^c_L=(1,1)_1`。下标代表超荷 Y。U(1)³ 规范异常系数（忽略共同归一化常数）是：

`6(1/6)³+3(−2/3)³+3(1/3)³+2(−1/2)³+1³ = 1/36−8/9+1/9−1/4+1 = 0`。

混合引力–U(1) 迹：

`6(1/6)+3(−2/3)+3(1/3)+2(−1/2)+1=1−2+1−1+1=0`。

SU(2)²U(1) 的系数 `T(2)[3(1/6)+(−1/2)]=(1/2)(1/2−1/2)=0`。SU(3)²U(1) 的系数 `T(3)[2(1/6)−2/3+1/3]=(1/2)(1/3−2/3+1/3)=0`。SU(3)³ 在手征表示上是 `2×3−\bar3−\bar3` 的组合，异常计数 `2−1−1=0`。以上可用 Python `fractions.Fraction` 精确复算为零，不受浮点舍入影响。

另有 SU(2) 的全局 Witten 异常约束：左手 SU(2) 双重态数必须为偶数；一代具有 3 个颜色夸克双重态和 1 个轻子双重态，共 4 个，满足条件。这个条件也不是从螺旋轨迹几何自动出现。

## 10.3 ROOT 的严格验收规则

如果 ROOT 声称从更底层产生完整标准模型，必须独立给出上述费米子表示和超荷，解释为什么恰好发生这些抵消，而不能在写出异常抵消公式后把它们称为从几何必然推得。若提出额外带电费米子，也要重新核算其所有局域和全局异常。用本章的有理数程序能快速否定不一致的候选模型，但不能单凭零异常证明该模型一定是真实自然理论。
