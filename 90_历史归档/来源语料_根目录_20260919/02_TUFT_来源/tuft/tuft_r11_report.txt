  2. 【新公式】Dirac 量子化 + 反常消除 ⇒ 整数电荷超荷离散族 q_p = p/(2−3p)
==============================================================================
  沿用 R10 分支 A（x = 3q）的电荷谱，以电子电荷 |e| = |Q(e_L)| = 1/2 + 3q/2 为单位：
    Q(u_L)/e   = (q + 1)/(3*q + 1)
    Q(d_L)/e   = (q - 1)/(3*q + 1)
    Q(u_R)/e   = 4*q/(3*q + 1)
    Q(d_R)/e   = -2*q/(3*q + 1)
    Q(ν_L)/e   = (1 - 3*q)/(3*q + 1)

  Dirac 要求整数电荷：Q(u_L)/e ∈ ℤ 且 Q(u_R)/e ∈ ℤ。设 Q(u_R)/e = 2p（p∈ℤ，见下）：
    (q/2 + 1/2)/(3*q/2 + 1/2)   ,   2*q/(3*q/2 + 1/2)
    由第二式解出 q = [-p/(3*p - 4)]
    代回第一式 ⇒ m = 1 - p/2
    m∈ℤ 要求 p 为偶数 ⇒ 令 p = 2p′ 并重命名 p′→p，得闭式 q_p = p/(2 − 3p)

  【闭式】q_p = p / (2 − 3p)，p ∈ ℤ   （e ≡ |Q(e_L)| = |1/2 + 3q/2|）
    p    q_p            Q(u_L)/e     Q(u_R)/e     Q(d_R)/e     说明
    -2   -1/4           3            -4           2            
    -1   -1/5           2            -2           1            
    0    0              1            0            0            退化：u_R/d_R 不带电
    1    -1             0            -2           1            整数电荷解（Han–Nambu 型）
    2    -1/2           1            -4           2            
    3    -3/7           2            -6           3            
  [PASS] 2a: 【新公式】Dirac + 反常消除 ⇒ 离散族 q_p = p/(2−3p)  |  要求电荷为 e 的整数倍，超出荷只能取该可数族；代入 [U(1)]³ 得 0 ⇒ 全族**自动**满足反常消除
