## 第三章 完整推导链

### 3.1 作用量 → 场方程

总作用量：

$$\boxed{S = \int d^4x\,\sqrt{-g}\left[\frac{1}{2\kappa_E}R(\omega) + \mathcal{L}_{\text{matter}} + \mathcal{L}_{\text{gauge}}\right]}$$

其中 $\omega$ 为含挠率联络，$\kappa_E=8\pi G/c^4$。

**对度规变分** → 广义爱因斯坦方程：

$$\boxed{G_{\mu\nu} = \kappa_E\,T_{\mu\nu}}$$

**对联络变分** → 嘉当方程（挠率-自旋关系）：

$$\boxed{T^\lambda{}_{\mu\nu} = \kappa_E\,S^\lambda{}_{\mu\nu}}$$

**对规范场变分** → 规范场方程（麦克斯韦/杨-米尔斯）：

$$\boxed{\partial_\mu F^{\mu\nu} = \mu_0 J^\nu \qquad (\text{电磁})}$$

### 3.2 场方程 → 测地线/运动方程

点粒子沿测地线运动：

$$\boxed{\frac{d^2x^\lambda}{d\tau^2} + \Gamma^\lambda{}_{\mu\nu}\frac{dx^\mu}{d\tau}\frac{dx^\nu}{d\tau} = 0}$$

带电粒子受洛伦兹力：

$$\boxed{m\frac{d u^\mu}{d\tau} = q\,F^{\mu\nu}u_\nu}$$

### 3.3 弱场极限 → 牛顿引力与库仑定律

弱场 $g_{00}\approx-\left(1-\frac{2GM}{c^2r}\right)$，测地线 → 牛顿第二定律：

$$\boxed{a = \frac{GM}{r^2} \qquad F = \frac{Gm_1m_2}{r^2}}$$

静态规范场 → 库仑定律：

$$\boxed{E = \frac{k_e q}{r^2} \qquad F = \frac{k_e q_1q_2}{r^2}}$$

### 3.4 常数关系（自洽导出）

$$\boxed{G = \frac{\hbar c}{m_P^2} \qquad m_P = \sqrt{\frac{\hbar c}{G}}} \qquad \boxed{\alpha = \frac{e^2}{4\pi\varepsilon_0\hbar c}}$$

$$\boxed{c = \frac{1}{\sqrt{\varepsilon_0\mu_0}} \qquad \kappa_E = \frac{8\pi G}{c^4}}$$
