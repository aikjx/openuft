# 研究贡献约定

1. 按原始假设选择 01_独立体系 下的模型；归属不明则进入 99_待整理资料。
2. 明确 system.json 中的假设版本、定义与适用边界；混合模型显式登记依赖。
3. 在 claims.csv 登记命题，链接推导、预测、代码、数据、误差和负结果。
4. 模型专属源码、图表、论文与评审记录放入本模型对应阶段；共享材料仅保留一个主版本。
5. 提交前运行 `python verify.py`，涉及计算时执行相应复算；目录调整后运行 `python 00_项目治理/维护工具/refresh_catalog.py`。
6. 在评审记录中注明具体审查人、版本、发现和处置；未经审查的历史标签不能作为结论认证。
