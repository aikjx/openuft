【PL1】等离子体概述与基本性质
----------------------------------------------------------------------

  等离子体的定义：

  等离子体是物质的第四态，由大量自由带电粒子（电子、离子）
  和中性粒子组成的准中性系统，表现出集体行为。

  物质的四态：
    1. 固态（分子/原子固定位置）
    2. 液态（分子/原子自由移动但有固定体积）
    3. 气态（分子/原子自由移动，充满容器）
    4. 等离子体态（电子从原子中电离，自由带电粒子）

  等离子体的判据：

  1. 准中性：n_e ≈ n_i（在德拜长度以上尺度）
  2. 集体行为：粒子间长程库仑相互作用主导
  3. 德拜屏蔽：λ_D << 系统尺寸 L
  4. 等离子体参数：Λ = n λ_D³ >> 1（大量粒子在德拜球内）

  等离子体的特征量：

  1. 德拜长度（Debye length）：
     λ_D = √(ε₀ k_B T_e / (n_e e²))
     这是电荷扰动被屏蔽的特征长度

  德拜长度计算示例：
    电子密度 n_e = 1e+20 m⁻³
    电子温度 T_e = 100.0 eV
    德拜长度 λ_D = √(ε₀ k_B T_e / (n_e e²)) = 7.4339 μm

  2. 等离子体频率（Plasma frequency）：
     ω_pe = √(n_e e² / (ε₀ m_e))
     f_pe = ω_pe / (2π)
     这是等离子体中电子集体振荡的特征频率

  等离子体频率计算示例：
    电子密度 n_e = 1e+20 m⁻³
    等离子体角频率 ω_pe = √(n_e e²/(ε₀ m_e)) = 5.6415e+11 rad/s
    等离子体频率 f_pe = ω_pe/(2π) = 89.79 GHz

  3. 电子回旋频率（Electron cyclotron frequency）：
     ω_ce = e B / m_e
     f_ce = ω_ce / (2π)
     这是电子在磁场中回旋运动的特征频率

  电子回旋频率计算示例：
    磁场 B = 1.0 T
    电子回旋角频率 ω_ce = eB/m_e = 1.7588e+11 rad/s
    电子回旋频率 f_ce = ω_ce/(2π) = 27.99 GHz

  4. 离子回旋频率（Ion cyclotron frequency）：
     ω_ci = e B / m_i
     比电子回旋频率小 m_i/m_e ≈ 1836 倍

  离子回旋频率计算示例（质子）：
    磁场 B = 1.0 T
    离子回旋角频率 ω_ci = eB/m_i = 9.5788e+07 rad/s
    离子回旋频率 f_ci = ω_ci/(2π) = 15.25 MHz
    比值 f_ce/f_ci = m_i/m_e = 1836

  5. 等离子体参数（Plasma parameter）：
     Λ = n_e λ_D³ = 4π n_e λ_D³ / 3（德拜球内粒子数）
     Λ >> 1 是弱耦合等离子体的判据

  等离子体参数计算示例：
    电子密度 n_e = 1e+20 m⁻³
    德拜长度 λ_D = 7.4339 μm
    德拜球内粒子数 Λ = 4πn_eλ_D³/3 = 1.7209e+05
    Λ >> 1，弱耦合等离子体

  等离子体的分类：

  类型              温度                 密度                     例子
  --------------------------------------------------------------------------------
  高温等离子体          >1 keV             10^19-10^21 m^-3       核聚变装置(托卡马克、仿星器)
  低温等离子体          1-100 eV           10^16-10^19 m^-3       荧光灯、等离子体显示器、等离子体刻蚀
  空间等离子体          0.1-100 eV         10^6-10^12 m^-3        电离层、太阳风、磁层
  天体等离子体          100 eV-100 keV     10^12-10^30 m^-3       恒星、星云、吸积盘
  强耦合等离子体         <10 eV             >10^28 m^-3            白矮星、金属、惯性约束聚变
  非中性等离子体         —                  —                      电子束、离子束、彭宁阱

  等离子体在宇宙中的分布：

  可见宇宙中约99%的重子物质以等离子体形式存在：
    - 恒星（包括太阳）：等离子体
    - 星际介质：等离子体
    - 星系际介质：等离子体
    - 吸积盘：等离子体
    - 射电星系/类星体喷流：相对论性等离子体

  地球上的等离子体：
    - 闪电：自然等离子体
    - 极光：空间等离子体
    - 电离层：空间等离子体
    - 荧光灯/霓虹灯：人工等离子体
    - 电弧焊：人工等离子体
    - 核聚变装置：人工高温等离子体

  螺旋几何化解释：

  1. 等离子体的螺旋几何化
     - 等离子体 = 大量螺旋带电粒子的集合
     - 电子 = 内部光速螺旋的负电荷粒子
     - 离子 = 内部光速螺旋的正电荷粒子
     - 集体行为 = 螺旋带电粒子的长程库仑相互作用

  2. 德拜屏蔽的螺旋几何化
     - 德拜长度 = 螺旋电荷扰动被屏蔽的特征长度
     - 德拜球 = 螺旋电荷的屏蔽区域
     - 准中性 = 德拜长度以上尺度螺旋电荷正负抵消

  3. 等离子体频率的螺旋几何化
     - 等离子体振荡 = 螺旋电子相对于螺旋离子的集体振荡
     - 等离子体频率 = 螺旋电子集体振荡的特征频率
     - 朗缪尔波 = 螺旋电子的纵向集体振荡

【PL2】磁流体力学
----------------------------------------------------------------------

  磁流体力学（Magnetohydrodynamics, MHD）概述：

  MHD是研究导电流体与电磁场相互作用的学科。
  它将流体力学方程与麦克斯韦方程组耦合起来。

  基本假设：
    1. 等离子体可以视为单流体（电子和离子一起运动）
    2. 电导率很大（理想MHD）或有限（电阻MHD）
    3. 特征尺度远大于德拜长度和拉莫尔半径
    4. 特征时间远大于等离子体周期和回旋周期

  MHD基本方程组：

  1. 质量守恒（连续性方程）：
     ∂ρ/∂t + ∇·(ρ v) = 0
     其中 ρ 是质量密度，v 是流体速度

  2. 动量守恒（运动方程）：
     ρ (∂v/∂t + v·∇v) = -∇p + j × B + ρ g + ν ∇²v
     其中 p 是压强，j 是电流密度，B 是磁场，g 是重力加速度，ν 是黏滞系数
     j × B 是洛伦兹力（电磁力）

  3. 能量守恒：
     ρ (∂/∂t + v·∇)(e/ρ) = -p ∇·v + j²/σ + ∇·(κ ∇T) + η |∇v|²
     其中 e 是内能密度，σ 是电导率，κ 是热导率，η 是黏滞系数
     j²/σ 是焦耳热，κ∇T 是热传导，η|∇v|² 是黏滞耗散

  4. 磁感应方程（法拉第定律+欧姆定律）：
     ∂B/∂t = ∇×(v × B) + (1/μ₀σ) ∇²B
     其中 ∇×(v×B) 是对流项（磁场随流体运动）
     (1/μ₀σ)∇²B 是扩散项（磁场的电阻扩散）

  5. 麦克斯韦方程组（MHD近似）：
     ∇·B = 0（磁场无散）
     ∇×B = μ₀ j（安培定律，忽略位移电流）
     E + v × B = j/σ（广义欧姆定律）

  理想MHD（σ→∞）：

  当电导率无穷大时，电阻扩散项消失：
    ∂B/∂t = ∇×(v × B)

  这导致'冻结定理'（Alfvén, 1942）：
    磁场线被冻结在导电流体中，随流体一起运动
    穿过任意随流体运动的闭合回路的磁通量守恒

  理想MHD的重要推论：
    1. 磁场线不能断裂或重新连接（理想MHD中）
    2. 磁通量守恒
    3. 交叉螺旋度守恒（∫ A·B dV）

  磁雷诺数（Magnetic Reynolds number）：

  R_m = μ₀ σ v L = 对流项 / 扩散项
    其中 v 是特征速度，L 是特征长度

  R_m >> 1：理想MHD，磁场冻结
  R_m << 1：电阻MHD，磁场扩散

  磁雷诺数计算示例：
    电导率 σ = 1e+07 S/m
    特征速度 v = 1e+05 m/s
    特征长度 L = 1.0 m
    磁雷诺数 R_m = μ₀σvL = 1.2566e+06
    R_m >> 1，理想MHD近似成立

  Alfvén波（阿尔文波，Alfvén, 1942）：

  Alfvén波是磁化等离子体中的低频横波，
  类似于弦上的波，磁场张力提供恢复力。

  Alfvén速度：
    v_A = B / √(μ₀ ρ)
    其中 B 是磁场强度，ρ 是质量密度

  Alfvén速度计算示例：
    磁场 B = 1.0 T
    质量密度 ρ = 1e-06 kg/m³
    Alfvén速度 v_A = B/√(μ₀ρ) = 8.9206e+05 m/s = 0.0030 c

  MHD波的分类：

  波型              类型         速度                                  性质
  --------------------------------------------------------------------------------
  Alfvén波         横波         v_A = B/√(μ₀ρ)                      沿磁场传播, 不可压缩
  快磁声波            混合波        v_f = √((v_s²+v_A²+√(...))/2)       主要压缩, 磁场和压强扰动同相
  慢磁声波            混合波        v_s = √((v_s²+v_A²-√(...))/2)       主要压缩, 磁场和压强扰动反相

  螺旋几何化解释：

  1. MHD的螺旋几何化
     - MHD = 螺旋带电粒子流体与螺旋电磁场的相互作用
     - 洛伦兹力 = 螺旋带电粒子在螺旋磁场中的受力
     - 冻结定理 = 螺旋磁场线随螺旋流体一起运动
     - 磁通量守恒 = 螺旋磁场的拓扑守恒

  2. Alfvén波的螺旋几何化
     - Alfvén波 = 螺旋磁场线的横向振荡（类似于弦上的波）
     - Alfvén速度 = 螺旋磁场张力与螺旋流体惯性的比值
     - 磁场张力 = 螺旋磁场线的弹性恢复力
     - 交叉螺旋度 = 螺旋磁场的拓扑不变量

  3. 磁重联的螺旋几何化
     - 磁重联 = 螺旋磁场线断裂并重新连接的过程
     - 磁能释放 = 螺旋磁场能量转化为粒子动能和热能
     - 太阳耀斑 = 太阳大气中的磁重联事件
     - 托卡马克破裂 = 聚变装置中的磁重联事件

【PL3】等离子体中的波与不稳定性
----------------------------------------------------------------------

  等离子体波的分类：

  等离子体支持多种波模式，取决于：
    - 传播方向与磁场的夹角（平行/垂直/斜向）
    - 频率范围（低频/高频）
    - 偏振（纵波/横波/椭圆偏振）
    - 粒子种类（电子波/离子波/电磁混合波）

  无磁场等离子体中的波：

  1. 朗缪尔波（Langmuir wave，电子等离子体波）：
     纵向静电波，电子相对于离子的集体振荡
     色散关系：ω² = ω_pe² + 3 k² v_te²
     其中 v_te = √(k_B T_e/m_e) 是电子热速度
     相速度 v_ph = ω/k >> v_te（弱阻尼）

  2. 离子声波（Ion acoustic wave）：
     纵向静电波，离子的压缩波（类似于空气中的声波）
     色散关系：ω² = k² c_s² / (1 + k² λ_De²)
     其中 c_s = √(k_B T_e/m_i) 是离子声速
     当 k λ_De << 1 时，ω = k c_s（无色散声波）

  离子声速计算示例（质子等离子体）：
    电子温度 T_e = 100.0 eV
    离子声速 c_s = √(k_B T_e/m_i) = 9.7872e+04 m/s

  3. 电磁波（Electromagnetic wave）：
     横向电磁波，类似于真空中的光波
     色散关系：ω² = ω_pe² + c² k²
     截止频率：ω = ω_pe（当 ω < ω_pe 时，波不能传播，被反射）
     相速度 v_ph = c / √(1 - ω_pe²/ω²) > c
     群速度 v_g = c √(1 - ω_pe²/ω²) < c

  磁化等离子体中的波：

  平行于磁场传播的波：

  1. 哨声波（Whistler wave）：
     右旋圆偏振电磁波，频率在 ω_ci << ω << ω_ce 范围
     色散关系：ω² = k² c² ω_ce / (ω_pe² + k² c²) ≈ k² c² ω_ce / ω_pe²（低密度）
     群速度 v_g ∝ √ω（高频传播更快，产生哨声效果）
     闪电激发的哨声波在电离层中传播，产生哨声（whistler）

  2. 电子回旋波（Electron cyclotron wave）：
     频率接近 ω_ce 的右旋圆偏振波
     在 ω = ω_ce 处发生回旋共振，波被强烈吸收
     应用：电子回旋共振加热（ECRH）

  3. 离子回旋波（Ion cyclotron wave）：
     频率接近 ω_ci 的左旋圆偏振波
     在 ω = ω_ci 处发生回旋共振
     应用：离子回旋共振加热（ICRH）

  垂直于磁场传播的波：

  1. 寻常波（Ordinary wave, O波）：
     电场平行于磁场的线偏振电磁波
     色散关系：ω² = ω_pe² + c² k²（与无磁场时相同）

  2. 非常波（Extraordinary wave, X波）：
     电场垂直于磁场的椭圆偏振电磁波
     色散关系较复杂，有上混合共振和下混合共振
     上混合频率：ω_UH² = ω_pe² + ω_ce²
     下混合频率：ω_LH² ≈ ω_pi² + ω_ci ω_ce（高密度近似）

  等离子体不稳定性：

  等离子体不稳定性是指等离子体中微小扰动随时间增长的现象。
  不稳定性将自由能（粒子束、温度各向异性、电流等）转化为波能。

  不稳定性                 驱动源                       频率                   应用
  ------------------------------------------------------------------------------------------
  双流不稳定性               电子束相对于离子运动                ~ω_pe                束-等离子体相互作用, 粒子加速
  Weibel不稳定性           温度各向异性(T⊥>T∥)             ~ω_pe                无碰撞冲击波, 宇宙射线加速
  离子声不稳定性              电子-离子相对漂移                 ~ω_pi                电流驱动, 反常电阻
  漂移波不稳定性              密度/温度梯度                   ~ω_* (漂移频率)          托卡马克湍流, 反常输运
  撕裂模不稳定性              电流密度梯度                    ~ω_A/L               磁重联, 托卡马克破裂
  交换不稳定性               磁场曲率+压强梯度                 ~ω_A                 磁约束, 瑞利-泰勒型
  回旋不稳定性               速度分布各向异性                  ~ω_ce/ω_ci           回旋激射, 天体射电辐射
  Kelvin-Helmholtz不稳定性 速度剪切                      ~k v_shear           行星磁层, 天体喷流

  螺旋几何化解释：

  1. 等离子体波的螺旋几何化
     - 朗缪尔波 = 螺旋电子的纵向集体振荡
     - 离子声波 = 螺旋离子的压缩波
     - 电磁波 = 螺旋电磁场的横向振荡
     - 哨声波 = 螺旋磁场中的右旋圆偏振波
     - 回旋波 = 螺旋带电粒子的回旋共振

  2. 不稳定性的螺旋几何化
     - 双流不稳定性 = 螺旋电子束与螺旋背景等离子体的相互作用
     - Weibel不稳定性 = 螺旋粒子温度各向异性导致的磁场生成
     - 漂移波 = 螺旋等离子体在梯度中的漂移振荡
     - 撕裂模 = 螺旋磁场线的断裂和重联
     - 不稳定性 = 螺旋系统自由能的释放途径

【PL4】核聚变等离子体
----------------------------------------------------------------------

  核聚变基本原理：

  核聚变是两个轻原子核结合成一个较重原子核的过程，
  同时释放大量能量（根据质能方程 E=mc²）。

  主要聚变反应：

  反应           方程                                                      截面                        优点                        缺点
  --------------------------------------------------------------------------------------------------------------------------------------------
  D-T反应        D + T → He⁴(3.5 MeV) + n(14.1 MeV)                      最大(~5 barn at 64 keV)     截面最大, 温度要求最低              产生中子, 需要氚增殖
  D-D反应        D + D → T(1.01 MeV) + p(3.02 MeV) / He³(0.82 MeV) + n(2.45 MeV) 较小(~0.1 barn at 100 keV)  燃料丰富(海水), 无放射性            截面小, 温度要求高
  D-He³反应      D + He³ → He⁴(3.6 MeV) + p(14.7 MeV)                    中等(~0.5 barn at 200 keV)  无中子(清洁), 高能质子             He³稀缺, 温度要求高
  p-B¹¹反应      p + B¹¹ → 3 He⁴(8.7 MeV total)                          很小(~0.01 barn at 500 keV) 无中子(最清洁), 燃料丰富            截面极小, 温度要求极高

  D-T反应详细分析：

  D-T反应是目前最容易实现的聚变反应，也是ITER的主要反应。

  反应方程：
    ²H + ³H → ⁴He(3.5 MeV) + n(14.1 MeV)
    总释放能量：17.6 MeV

  质量亏损：
    m_D + m_T - m_He - m_n = 17.6 MeV/c²
    质量转化效率：0.38%（比核裂变0.08%高）

  D-T反应质量亏损计算：
    m_D = 3.344495e-27 kg
    m_T = 5.008268e-27 kg
    m_He4 = 6.646479e-27 kg
    m_n = 1.674927e-27 kg
    质量亏损 Δm = 3.135578e-29 kg
    释放能量 E = Δmc² = 17.59 MeV

  劳森判据（Lawson criterion, 1955）：

  实现聚变能量增益需要满足：
    n τ_T > 10^20 m^-3·s （D-T反应，T~10 keV）
    其中 n 是等离子体密度，τ_T 是能量约束时间

  更常用的三重积：
    n T τ_T > 3×10^21 m^-3·keV·s

  聚变增益 Q = 聚变功率 / 输入加热功率
    Q = 1：得失相当（breakeven）
    Q > 1：净能量增益
    Q = ∞：点火（ignition，α粒子自加热维持燃烧）

  磁约束核聚变：

  托卡马克详细介绍：

  托卡马克（Tokamak）是目前最成功的磁约束聚变方案。
  名字来自俄语'tороидальная камера с магнитными катушками'
  （带磁线圈的环形室）。

  磁场结构：
    - 环向磁场 B_t：由环向场线圈产生，~5-10 T
    - 极向磁场 B_p：由等离子体电流产生，~0.5-1 T
    - 合成磁场 B = √(B_t² + B_p²)，形成螺旋磁场线
    - 安全因子 q = r B_t / (R B_p)，描述磁场线的螺旋程度
    - q > 1 是稳定运行的必要条件（Kruskal-Shafranov极限）

  ITER（国际热核聚变实验堆）：

  ITER是目前世界上最大的聚变实验装置，位于法国卡达拉舍。
  由欧盟、美国、中国、日本、韩国、俄罗斯、印度七方合作。

  主要参数：
    - 大半径 R = 6.2 m
    - 小半径 a = 2.0 m
    - 环向磁场 B_t = 5.3 T
    - 等离子体电流 I_p = 15 MA
    - 等离子体体积 V = 840 m³
    - 聚变功率 P_fusion = 500 MW（目标）
    - 增益 Q = 10（目标）
    - 燃烧时间 > 400 s（目标）

  时间表：
    - 2025年：首次等离子体（First Plasma）
    - 2035年：全性能D-T运行

  惯性约束核聚变：

  惯性约束聚变（Inertial Confinement Fusion, ICF）利用高功率激光
  或粒子束压缩燃料靶丸，利用燃料自身惯性约束。

  主要装置：
    - NIF（国家点火设施，美国劳伦斯利弗莫尔国家实验室）
      192束激光，总能量1.8 MJ，2022年实现Q=1.5（科学点火）
    - LMJ（激光兆焦耳，法国）
    - 神光系列（中国）

  2022年12月，NIF实现了聚变能量增益 Q=1.5（输入2.05 MJ，输出3.15 MJ），
  这是人类历史上首次实现聚变点火（scientific breakeven）。

  螺旋几何化解释：

  1. 核聚变的螺旋几何化
     - 核聚变 = 螺旋原子核克服库仑势垒后合并的过程
     - 库仑势垒 = 螺旋正电荷之间的排斥势
     - 量子隧穿 = 螺旋原子核的波函数穿透势垒
     - 质量亏损 = 螺旋原子核结合能的差异
     - 能量释放 = 螺旋原子核结合能的释放

  2. 磁约束的螺旋几何化
     - 托卡马克 = 螺旋磁场约束螺旋带电粒子
     - 环向磁场 = 螺旋磁场的环向分量
     - 极向磁场 = 螺旋磁场的极向分量
     - 合成磁场 = 螺旋磁场线
     - 安全因子 q = 螺旋磁场线的螺旋程度
     - 粒子约束 = 螺旋带电粒子沿螺旋磁场线运动

  3. 惯性约束的螺旋几何化
     - 激光压缩 = 螺旋激光烧蚀靶丸表面，产生反冲压缩
     - 燃料惯性 = 螺旋燃料原子核的惯性约束
     - 内爆 = 螺旋燃料向心加速压缩
     - 点火 = 螺旋燃料达到高温高密度后自加热燃烧

  天体等离子体概述：

  宇宙中约99%的重子物质以等离子体形式存在。
  天体等离子体涵盖从行星电离层到宇宙大尺度结构的广泛尺度。

  太阳等离子体：

  太阳结构：
    - 核心（0-0.25 R☉）：核聚变反应区，T~1500万K
    - 辐射区（0.25-0.7 R☉）：光子辐射传输，T~200万-700万K
    - 对流区（0.7-1.0 R☉）：对流运动，T~50万-200万K
    - 光球层（表面）：可见光发射，T~5778 K
    - 色球层：T~4500-20000 K
    - 日冕：T~100万-300万K（日冕加热问题）
    - 太阳风：T~10万-100万K，速度~300-800 km/s

  太阳活动：

  现象                 尺度              特征                             成因                        周期/持续
  --------------------------------------------------------------------------------------------------------------
  太阳黑子               ~10^3-10^4 km   ~3000-4500 K(比光球暗)             强磁场抑制对流                   11年周期
  太阳耀斑               ~10^4-10^5 km   ~10^20-10^25 J                 磁重联释放磁能                   分钟-小时
  日冕物质抛射(CME)        ~10^6 km        ~10^12-10^13 kg                大尺度磁结构爆发                  
  日珥                 ~10^5 km        ~5000-10000 K                  悬浮在日冕中的冷密等离子体             天-周
  太阳风                行星际             ~300-800 km/s                  日冕膨胀                      

  日冕加热问题：

  日冕温度（~100万-300万K）远高于光球温度（~5778 K），
  这违反了热力学第二定律的直觉（热量从低温流向高温）。

  主要理论：
    1. 波加热理论：阿尔文波/磁声波从光球传播到日冕并耗散
    2. 纳耀斑理论：大量微小磁重联事件（纳耀斑）加热日冕
    3. 磁重联加热：大尺度磁重联释放磁能

  目前尚无定论，是太阳物理的重大难题之一。

  星际介质（ISM）：

  星际介质是恒星之间的物质，主要由气体（99%）和尘埃（1%）组成。

  星际介质的相：
    - 冷中性介质（CNM）：T~50-100 K, n~20-50 cm^-3
    - 温中性介质（WNM）：T~5000-10000 K, n~0.5 cm^-3
    - 温电离介质（WIM）：T~8000 K, n~0.1 cm^-3
    - 热电离介质（HIM）：T~10^6 K, n~0.003 cm^-3
    - 分子云：T~10-20 K, n~10^2-10^6 cm^-3（恒星形成区）

  超新星遗迹：

  超新星爆发后抛出的物质与星际介质相互作用形成的激波结构。

  著名超新星遗迹：
    - 蟹状星云（Crab Nebula, M1）：1054年超新星遗迹，中心有脉冲星
    - 第谷超新星遗迹（SN 1572）：1572年第谷观测的超新星
    - 开普勒超新星遗迹（SN 1604）：1604年开普勒观测的超新星
    - SN 1987A：1987年大麦哲伦云中的超新星，最近的一次

  吸积盘与喷流：

  吸积盘是物质绕中心天体（原恒星、白矮星、中子星、黑洞）旋转形成的盘状结构。
  引力势能转化为热能，产生强烈辐射。

  吸积盘模型：
    - 薄盘（Shakura-Sunyaev, 1973）：几何薄，光学厚，热辐射
    - 厚盘（厚吸积流）：几何厚，光学薄，高温
    - 径移主导吸积流（ADAF）：低吸积率，径移重要

  喷流：
    - 相对论性喷流：速度~0.99c，从活动星系核/微类星体喷出
    - 原恒星喷流：速度~100-300 km/s，从年轻恒星喷出
    - 喷流准直机制：磁场螺旋结构（Blandford-Znajek机制）

  星系团与星系际介质：

  星系团是宇宙中最大的引力束缚结构，包含数百到数千个星系。
  星系团内充满高温（~10^7-10^8 K）稀薄（~10^-3-10^-1 cm^-3）等离子体，
  称为星系团内介质（ICM），在X射线波段强烈辐射。

  著名星系团：
    - 后发座星系团（Coma Cluster）：最早发现的星系团之一
    - 室女座星系团（Virgo Cluster）：最近的大星系团
    - 子弹星系团（Bullet Cluster）：两个星系团并合，暗物质直接证据
    - 英仙座星系团（Perseus Cluster）：X射线明亮，有声波振荡

  螺旋几何化解释：

  1. 太阳等离子体的螺旋几何化
     - 太阳黑子 = 螺旋磁场管浮出光球表面
     - 太阳耀斑 = 螺旋磁场线的磁重联释放能量
     - CME = 大尺度螺旋磁结构的爆发
     - 太阳风 = 螺旋日冕等离子体的膨胀
     - 日冕加热 = 螺旋阿尔文波/磁重联的能量耗散

  2. 吸积盘与喷流的螺旋几何化
     - 吸积盘 = 螺旋物质绕中心天体的旋转盘
     - 角动量传输 = 螺旋湍流/磁旋转不稳定性(MRI)
     - 喷流 = 螺旋磁场准直的等离子体流
     - Blandford-Znajek机制 = 旋转黑洞+螺旋磁场提取能量
     - 相对论性喷流 = 螺旋磁场加速到相对论速度

  3. 宇宙等离子体的螺旋几何化
     - 星际介质 = 螺旋等离子体的多相结构
     - 超新星遗迹 = 螺旋激波压缩星际介质
     - 宇宙射线 = 螺旋带电粒子被超新星激波加速
     - 星系团内介质 = 螺旋高温等离子体
     - 大尺度结构 = 螺旋宇宙网的引力坍缩
