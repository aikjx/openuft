## 附录：数学推导

### A.1 洛伦兹变换的详细推导

基于空间螺旋运动假设，我们可以详细推导出洛伦兹变换。考虑两个相对运动的惯性参考系S(x,y,z,t)和S'(x',y',z',t')，S'以速度u沿x轴正方向相对于S运动。

#### A.1.1 光速不变原理的应用

设光信号在t=0时从原点发出，在参考系S中，光信号在t时刻的位置满足：

$$x^2 + y^2 + z^2 = c^2 t^2 \tag{A.1}$$

在参考系S'中，光信号在t'时刻的位置满足：

$$x'^2 + y'^2 + z'^2 = c^2 t'^2 \tag{A.2}$$"

#### A.1.2 线性变换的假设

假设时空坐标变换是线性的，即：

$$x' = ax + bt$$
$$y' = y$$
$$z' = z$$
$$t' = cx + dt \tag{A.3}$$

其中，a、b、c、d为常数，由相对性原理和光速不变原理确定。

#### A.1.3 相对性原理的应用

根据相对性原理，参考系S和S'是等价的，因此逆变换应为：

$$x = ax' - bt'$$
$$y = y'$$
$$z = z'$$
$$t = -cx' + dt' \tag{A.4}$$"

#### A.1.4 光速不变原理的应用

将变换式（A.3）代入式（A.2），并利用式（A.1），我们可以得到：

$$(ax + bt)^2 + y^2 + z^2 = c^2(cx + dt)^2 \tag{A.5}$$

展开并整理，得到：

$$(a^2 - c^2c^2)x^2 + (2ab - 2c^2cd)xt + (b^2 - c^2d^2)t^2 + y^2 + z^2 = 0 \tag{A.6}$$

根据式（A.1），我们有$x^2 + y^2 + z^2 = c^2t^2$，代入上式，得到：

$$(a^2 - c^2c^2)x^2 + (2ab - 2c^2cd)xt + (b^2 - c^2d^2)t^2 + c^2t^2 - x^2 = 0 \tag{A.7}$$

整理后，得到：

$$(a^2 - c^2c^2 - 1)x^2 + (2ab - 2c^2cd)xt + (b^2 - c^2d^2 + c^2)t^2 = 0 \tag{A.8}$$

由于上式对任意x和t都成立，因此系数必须为零：

1. $a^2 - c^2c^2 - 1 = 0$
2. $2ab - 2c^2cd = 0$
3. $b^2 - c^2d^2 + c^2 = 0 \tag{A.9}$"

#### A.1.5 相对运动的应用

考虑参考系S'的原点(x'=0)在参考系S中的运动，代入式（A.3），得到：

$$0 = ax + bt \Rightarrow x = -\frac{bt}{a} \tag{A.10}$$

由于参考系S'以速度u沿x轴正方向相对于S运动，因此x = ut，代入上式，得到：

$$ut = -\frac{bt}{a} \Rightarrow b = -au \tag{A.11}$$"

#### A.1.6 求解变换系数

将b = -au代入式（A.9），我们可以求解出a、c、d的值：

1. $a^2 - c^2c^2 = 1$
2. $-2a^2u - 2c^2cd = 0 \Rightarrow d = -\frac{a^2u}{c^2c}$
3. $a^2u^2 - c^2d^2 + c^2 = 0 \tag{A.12}$

解得：

$$c = -\frac{au}{c^2}$$
$$d = a$$
$$a = \frac{1}{\sqrt{1 - \frac{u^2}{c^2}}} = \gamma \tag{A.13}$$

因此，洛伦兹变换为：

$$x' = \gamma(x - ut)$$
$$y' = y$$
$$z' = z$$
$$t' = \gamma\left(t - \frac{ux}{c^2}\right) \tag{A.14}$$

其中，$\gamma = \frac{1}{\sqrt{1 - \frac{u^2}{c^2}}}$为洛伦兹因子。

### A.2 相对论质量的详细推导

基于空间螺旋运动假设，我们可以详细推导出相对论质量的表达式。考虑物体在力的作用下的运动，根据牛顿第二定律，力等于动量的变化率：

$$\boldsymbol{F} = \frac{d\boldsymbol{p}}{dt} \tag{A.15}$$

其中，动量$\boldsymbol{p} = m\boldsymbol{v}$，m为物体的质量。

在相对论情况下，质量随速度变化，因此动量的变化率为：

$$\boldsymbol{F} = \frac{d(m\boldsymbol{v})}{dt} = m \frac{d\boldsymbol{v}}{dt} + \boldsymbol{v} \frac{dm}{dt} \tag{A.16}$$

考虑力做功的功率，功率等于力点乘速度：

$$P = \boldsymbol{F} \cdot \boldsymbol{v} = m\boldsymbol{v} \cdot \frac{d\boldsymbol{v}}{dt} + v^2 \frac{dm}{dt} \tag{A.17}$$

另一方面，功率也等于能量的变化率，即P = dE/dt，其中E = mc²为物体的总能量。因此：

$$mc^2 \frac{dm}{dt} = m\boldsymbol{v} \cdot \frac{d\boldsymbol{v}}{dt} + v^2 \frac{dm}{dt} \tag{A.18}$$

整理后，得到：

$$(c^2 - v^2) \frac{dm}{dt} = m\boldsymbol{v} \cdot \frac{d\boldsymbol{v}}{dt} \tag{A.19}$$

由于$\boldsymbol{v} \cdot \frac{d\boldsymbol{v}}{dt} = v \frac{dv}{dt}$，因此：

$$(c^2 - v^2) \frac{dm}{dt} = mv \frac{dv}{dt} \tag{A.20}$$

分离变量并积分，初始条件为v=0时m=m₀，得到：

$$\int_{m_0}^{m} \frac{dm}{m} = \int_{0}^{v} \frac{v dv}{c^2 - v^2} \tag{A.21}$$

积分后，得到：

$$\ln\left(\frac{m}{m_0}\right) = -\frac{1}{2} \ln\left(1 - \frac{v^2}{c^2}\right) \tag{A.22}$$

因此，相对论质量的表达式为：

$$m = \gamma m_0 = \frac{m_0}{\sqrt{1 - \frac{v^2}{c^2}}} \tag{A.23}$$"

### A.3 质能方程的详细推导

基于空间螺旋运动假设，我们可以详细推导出质能方程。物体的总能量E与质量m的关系为E = mc²，我们可以通过动能定理来推导这一关系。

物体的动能K等于力所做的功，即：

$$K = \int \boldsymbol{F} \cdot d\boldsymbol{r} \tag{A.24}$$

根据牛顿第二定律，$\boldsymbol{F} = \frac{d\boldsymbol{p}}{dt} = \frac{d(m\boldsymbol{v})}{dt}$，因此：

$$K = \int \frac{d(m\boldsymbol{v})}{dt} \cdot d\boldsymbol{r} = \int \boldsymbol{v} \cdot d(m\boldsymbol{v}) \tag{A.25}$$

展开后，得到：

$$K = \int m\boldsymbol{v} \cdot d\boldsymbol{v} + \int \boldsymbol{v} \cdot \boldsymbol{v} dm = \int mv dv + \int v^2 dm \tag{A.26}$$

代入相对论质量的表达式m = γm₀，其中γ = 1/√(1 - v²/c²)，我们可以得到：

$$dm = \frac{m_0 \gamma^3 v dv}{c^2} \tag{A.27}$$

将其代入动能表达式，得到：

$$K = \int mv dv + \int v^2 \left(\frac{m_0 \gamma^3 v dv}{c^2}\right) = \int m_0 \gamma v dv + \int \frac{m_0 \gamma^3 v^3 dv}{c^2} \tag{A.28}$$

化简后，得到：

$$K = \int m_0 \gamma v \left(1 + \frac{\gamma^2 v^2}{c^2}\right) dv = \int m_0 \gamma v (\gamma^2) dv = \int m_0 \gamma^3 v dv \tag{A.29}$$

积分后，得到：

$$K = m_0 c^2 (\gamma - 1) \tag{A.30}$$

这表明物体的动能等于总能量减去静止能量，即K = E - m₀c²，因此总能量为：

$$E = mc^2 = \gamma m_0 c^2 \tag{A.31}$$

这就是质能方程的完整形式。

### A.4 能量动量关系的详细推导

基于空间螺旋运动假设，我们可以详细推导能量动量关系。物体的动量$\boldsymbol{p} = \gamma m_0 \boldsymbol{v}$，总能量$E = \gamma m_0 c^2$，因此：

$$p^2 = \gamma^2 m_0^2 v^2$$
$$E^2 = \gamma^2 m_0^2 c^4 \tag{A.32}$$

考虑E² - (pc)²：

$$E^2 - (pc)^2 = \gamma^2 m_0^2 c^4 - \gamma^2 m_0^2 v^2 c^2 = \gamma^2 m_0^2 c^2(c^2 - v^2) \tag{A.33}$$

由于$\gamma = \frac{1}{\sqrt{1 - \frac{v^2}{c^2}}}$，因此$\gamma^2(c^2 - v^2) = c^2$，代入上式，得到：

$$E^2 - (pc)^2 = m_0^2 c^4 \tag{A.34}$$

因此，能量动量关系为：

$$E^2 = (pc)^2 + (m_0 c^2)^2 \tag{A.35}$$

这就是相对论中能量和动量之间的关系，对于光子，静止质量m₀=0，因此E=pc。
