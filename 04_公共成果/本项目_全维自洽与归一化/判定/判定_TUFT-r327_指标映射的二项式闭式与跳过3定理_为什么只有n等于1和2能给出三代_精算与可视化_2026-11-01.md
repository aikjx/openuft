## 二、为什么这一卷值得单独立册

r325 把「为什么只有 `n = 1, 2` 有解」登记为 OPEN 时，给的是两个候选解释：

> 这是 `Â` 多项式的一个纯数论性质，还是一个几何选择效应？

本卷的答复是：**都不是**。它是「几何事实经 RR 之后剩下的算术」。这条答复之所以值得立册，是因为它**改变了问题的类型**：

- 之前：`n_R(q)` 是一个积分（`∫ e^{qH} Â`），要算就得展 `Â`，`Â` 一堆 `a_2, a_4, …`，看不出结构；
- 之后：`n_R(q) = χ(O(q-(n+1)/2))`，**是一个线丛的 Euler 示性**，而 `CP^n` 上它的闭式是 `C(k+n, n)`。

于是「三代」不再是一个几何量取到 3，而是「某个二项式系数等于 3」。**这一步是可以手算完的。**

## 三、定理 A · 幂和引理（L1）

```
P_m := sum_i x_i^m = (n+1) H^m        对 m <= n
```

- `A02`：`n = 1..12`、`m ≤ n`，**78/78** 相符。
- `A03`：`m = n+1` 立刻失效（`CP²` 的 `P_3 = 0 ≠ 4H³`）。
- `CTL11`：正对照，同一条判据在 `m = n+1` 上必须红 ⇒ 证明 `A02` 不是恒绿。

**为什么在 `m > n` 处失效**：`CP^n` 的实维是 `2n` ⇒ `H^{n+1} = 0` ⇒ `P_m = 0`。所以 L1 的有效范围是 `m ≤ n`，恰是 `n_R` 需要的范围（`n_R = [H^n]` 只牵涉到 `P_m`，`m ≤ n`）。

---

## 四、定理 B · Todd–Hirzebruch 引理（L2）

```
[H^n] e^{lam H} T(H)^{n+1} = C(lam+n, n),      T(x) = x/(1-e^{-x})
```

- `B01`：`n = 1..8` × 25 个 `lam`（`[-4,4]` 步长 `1/3`）= **200 组，失配 0**。
- `CTL12`：负对照，把 `T` 的指数从 `n+1` 改成 `n` ⇒ 立刻失配 ⇒ 幂次承重。

### 承重的中间步

```
log td(CP^n) = sum_m (log T)_m · P_m  =  (n+1) log T(H)    mod H^{n+1}
⇒  td(CP^n) === T(H)^{n+1}   mod H^{n+1}
```

`B02`：`n = 1..12`，把「`Chern 根 + log/exp`」算出的 `td` 与 `T(H)^{n+1}` 逐系数比，**0 条不符**。

> 这一步是整卷的铰链。没有它，`Â = td·e^{-c1/2}` 里的 `a_2, a_4, …` 是一堆无序的分数；有了它，`Â` 塌缩成一个 `T` 的幂，二项式才浮出来。

## 五、定理 C · 二项式闭式

```
n_R(q) = C( q + (n-1)/2 , n )
```

**三档机检**（互相独立）：

| 条目 | 采样 | 组数 | 失配 |
|---|---|---|---|
| `B03` | `n = 1..12` × `q ∈ [-15,15]` 步长 `1/2` | 732 | **0** |
| `B04` | `n = 1..8` × `q` 分母 `3`（非格点） | 328 | **0** |
| `B06` | `n = 1..12`，FW 格上 `q` | 150 | **0** |

`B04` 是判别力的关键：在**非格点**上恒等式仍成立 ⇒ 它是**多项式恒等式**，不是格上的数值巧合。

### 第三条路径 —— 它不是「像 RR」，它就是 RR

`B06` 完全不碰示性类，只用层上同调维数公式：

```
k >= 0 :  chi = C(k+n, n)
k <= -1:  Serre 对偶 ⇒ 只有 h^n 非零，h^n = C(-k-1, n) ⇒ chi = (-1)^n C(-k-1, n)
```

取 `k = q - (n+1)/2`，得 `chi(O(k)) == n_R(q)`，**150 组失配 0**。

> **这条改写了定理 C 的性质。** 二项式不是被「发现」的巧合，它是 `CP^n` 上 RR 的显式形式。所以本卷的结论不是「`n_R` 可以写成二项式」，而是「**`n_R` 本来就是某个线丛的 Euler 示性**」。

### 一条必须登记的错

`chi_sheaf` 初版把 `k ≤ -n-1` 判成 `0`，漏掉 Serre 对偶支 ⇒ `B06` **36/150** 失配。修正后 0。**这个错被保留为 `CTL15` 负对照**：把 `k<0` 一律判 0，`B06` 必须被打红（实测 36 组红）。

## 六、定理 D · FW 移位 = 上指标整数化

```
x := q + (n-1)/2 ∈ Z   ⟺   q 在 FW 格上（n 奇：Z；n 偶：Z+1/2）
```

`C01` 用 **2×2 列联表**（300 对 `(n,q)`）核：

| | `x` 整数 | `x` 非整数 | 计 |
|---|---|---|---|
| 在 FW 格上 | **150** | **0** | 150 |
| 离格 | **0** | **150** | 150 |

**两个方向都查**。只查「格上 ⇒ 整数」是半张表，会漏掉「格太宽」这种错；只查「离格 ⇒ 非整数」会漏掉「格太窄」。

- `C02`：逐 `n` 的格点基数 `[13,12,13,12,…]`（奇 13、偶 12）⇒ 两个奇偶类都真被覆盖。
- `C03`：负对照，naive 整数格 ⇒ 偶数 `n` 全变半整数 ⇒ 二项式论证不适用。
- `B07`：离格 150 对里 `k` 为整数的 = **0** ⇒ 层上同调在离格点**没有对象**，不是「算得不一样」。
- `G17`：守「格非空 + 双向 + 两类都覆盖」，防这张表变恒绿。

**这张表背后是一次真实的失败**：初版判据写成「`q∈Z` 且 `q∈Z+shift`」，对偶数 `n` 恒假 ⇒ 只数到 78 对，却仍「通过」了一条写死 `exp = 300` 的条目。**表没做，洞就在。**

## 七、定理 E ·「跳过 3」——从「没扫到」升级为「证明跳过」

### 命题

`C(x, n) = 3`，`x ∈ Z`，`n ≥ 1` 的解**恰为**：

```
n = 1 :  x = 3
n = 2 :  x = -2, 3
n >= 3:  无解
```

### 证明（四支点，覆盖全部整数 `x`，**无扫描上界**）

**支点 1（`x ≥ n`，`n ≥ 3`）**：`C(x,n)` 在 `x ≥ n` 上严格递增，且

```
C(n, n) = 1  <  3  <  n+1 = C(n+1, n)
```

严格递增 ⇒ 对 `x ≥ n+1` 有 `C(x,n) ≥ C(n+1,n) = n+1 ≥ 4`；对 `x = n` 有 `1`。所以 `x ≥ n` 上取值只有 `1` 或 `≥ 4` ⇒ **3 被跳过**。

严格递增的**证明**（不是窗口观察）：Pascal 差分

```
C(m+1,n) - C(m,n) = C(m,n-1) = m! / ((n-1)!(m-n+1)!)  >  0    (m ≥ n ≥ 1)
```

`D05`：`n = 1..12` × `m = n..n+40` = **492 组**逐点核这条**恒等式**，失配 `0`；正性由右端显式公式给出。

**支点 2（端点）**：`D06`，`n = 3..12` 上 `C(n+1,n) ≤ 3` 的反例个数 = **0**。

**支点 3（`0 ≤ x < n`）**：`C = 0`。`D08` 失配 `0`。

**支点 4（`x < 0`）**：`|C(x,n)| = C(n-x-1, n)`；`x = -1` 给 `1`，`x ≤ -2` 给 `≥ n+1 ≥ 4`；符号 `(-1)^n` ⇒ 取不到 `+3`。`D07`：`n = 3..12` × `x = -40..-1` 命中 **0**。

四支点并起来覆盖 `x ∈ Z` 全体 ⇒ 定理成立。`D09` 是这句的机读登记（`INFO`，因为它不产生新数字）。

> **纪律落点**：`D07`/`D08` 的 `act = 0` 且 `exp = 0`，看起来像「什么都没查」。所以它们的**分母写在 note 里**（`12 × 40 = 480` 组、`12 × ~7` 组），并且 `D07` 的搜索范围 `x ∈ [-40,-1]` 覆盖了 `|C| ≥ 4` 的整个区间 —— 不是「扫到 40 没找到」而是「`x ≤ -2` 一律 `≥ 4`，`x = -1` 给 1」。

## 八、定理 F/G · 可实现族数表与 3 vs 4

| `n` | 可实现族数（前 5） | 名称 | 判别力 |
|---|---|---|---|
| 1 | 1, 2, 3, 4, 5 | 全正整数 | **零**（恒等映射 `n_R = q`） |
| 2 | 1, 3, 6, 10, 15 | 三角形数 `T_k` | 有 |
| 3 | 1, 4, 10, 20, 35 | 四面体数 | 有 |
| 4 | 1, 5, 15, 35, 70 | 五胞体数 | 有 |

**`n = 2` 的精确刻画**（`E04`，12/12）：

```
n = 2 可实现 N   ⟺   N 是三角形数        （C(x,2) = T_{x-1}）
```

**`n = 1` 必须显式标为零信息**：`C(x,1) = x` ⇒ 任何 `N` 都「可实现」⇒ 它与「三代」同一句话。r325 定理 D 已给出同型的一刀（`CP¹` 上 `n_R(q)=q`，反向可及 12/12，判别力 0）。所以真问题只在 `n ≥ 2`。

**3 vs 4**：

| | 3 | 4 |
|---|---|---|
| 三角形数？ | 是（`T_2 = 3`） | 否 |
| 最小非平凡 `n` | **2** | **3** |

`E07` / `E08`：`min{n ≥ 2 : N ∈ reach} = 2`（`N=3`）、`= 3`（`N=4`）。

> 三代比四代**便宜一维**；而**六代与三代同一维**（都在 `CP²`：`C(4,2) = 6`）。r325「解集有多大」的真内容是**一整张三角形数表**，三代只是其中一项。

## 九、定价（2⁶ = 64 槽）

| 槽 | 内容 |
|---|---|
| `S1` | 内部几何限于 `CP^n` 族 |
| `S2` | `n_R = 3` 可实现 |
| `S3` | 采用 FW 移位（使上指标为整数） |
| `S4` | 3 在非平凡 `n` 上只能来自 `n = 2` |
| `S5` | 存在不引用 `N` 的机制把 3 选出来 |
| `S6` | 「3 是三角形数」解释了「为什么是 3 而不是 6」 |

由定理得出的五条蕴含：`¬S1 ⇒ ¬S2`、`S2 ⇒ S3`、`S2 ⇒ S4`、`S5 ⇒ ¬S6`、`S6 ⇒ S4`。

**结果**：可达 **23** / 严格六槽 **0** / `S5 ∧ S6 = 0` / `S2 ∧ S4 = 3`。

- 最硬一条：**`S5 ∧ S6 = 0`**。若真有不引用 `N` 的机制能选出 3，就不需要「三角形数」这个理由 —— 三角形数表 `1, 3, 6, 10, …` 里 3 与 6 并列，它解释不了凭什么单单是 3。
- `CTL10`：去掉这条约束 ⇒ `S5∧S6` 变可达 ⇒ 约束承重。
- `G08`：守「定价必须覆盖本卷最硬发现」（`S5∧S6=0` 且 `S2∧S4>0`）。

## 十一、诚实边界（七条）

1. **本卷只做算术，不做动力学**。`n_R = C(x,n)` 是**指标映射**的闭式；它不解释为什么取 `CP²`，也不解释为什么要通量。
2. **「跳过 3」是定理，「3 被选中」不是**。定理 E 说 `n ≥ 3` 给不出 3，**不是**说必须给 3。差一步，本卷没走。
3. **三角形数有无穷多个** ⇒ 「3 是三角形数」既不唯一也不预言（`S5∧S6=0`）。
4. **`n = 1` 是零信息**，必须显式标出。
5. **`q` 的符号未钉死**：`n = 2` 有 `q = ±5/2`。`X-R325-2` 未关闭。
6. **`CP^n` 之外未查**（`S1` 是显式假设）。`CY3`（`|Δ|=3`，配对 35）与 `T⁶/Z₃`（27）不在本框架内。
7. **全 `Fraction` 精确**，`Decimal prec=60` 仅格式化；无随机成分（`G05`）。

## 十四、最终一句

**「三代」在这个框架里不是个几何事实，是个二项式系数取到 3 的问题 —— 而 3 是三角形数，所以 `CP²` 给得出；4 不是，所以四代得升到 `CP³`。至于为什么偏偏是 3，本卷只证明了「`n ≥ 3` 给不出」，没证明「所以必须给」—— 这一步仍然是空的。**
