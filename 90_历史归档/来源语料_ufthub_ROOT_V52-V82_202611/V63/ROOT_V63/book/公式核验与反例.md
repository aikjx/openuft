# ROOT V63｜公式核验、维度、反例与前版错误修复表

## A. 可证明的数学结论

- 预设 `|r'|=c` 且采用 `Rω=c cosλ`、`u=c sinλ`，得到 `κ=cos²λ/R`, `τ=sinλ cosλ/R`；成立条件：`R>0`、圆柱螺旋匀速且 `λ<90°` 的 Frenet 标架不退化。垂直性 `T·N=0`、`T·B=N·B=0` 是纯几何关系。
- `v·(v×B)=0` 和 `B·(v×B)=0` 是三维叉乘恒等式；重力、电场力与磁场力不必相互正交。电荷为零时磁洛伦兹力为零，但引力仍存在，这已否定把它们只看作同一运动矢量不同空间投影的简单等价。
- `Ω²=c²(k_z²+n²/R²+m²c²/ℏ²)` 是假定圆柱表面 KG 方程的色散关系。离散的整数 `n` 不允许在环向分量上不加限制地使用连续群速的量子测量解释。
- 任何系统若仅有 `c,ℏ,λ`（角度无量纲），则没有办法按量纲直接构造 `[G]=L³M⁻¹T⁻²`。至少需要新的物理尺度或参数。

## B. 热核系数重新推导

取 `D=-∇²+m²+ξR`，`(4πs)^-2 [1+s(1/6-ξ)R+...]`。固有时单圈有效作用量曲率系数 `-1/(32π²)(1/6-ξ)Λ_UV² R`。与欧氏 `-R/(16πG)` 匹配，得 `δ(1/G)=(1-6ξ)Λ_UV²/(12π)`（自然单位）；以截止长度 `ell` 恢复为 `δ(1/G)=(1-6ξ)ℏ/(12πc³ell²)`（SI）。

**检查**：

- `ξ=0`，单实标量且零质量：正曲率诱导系数。
- `ξ=1/6`，标量无质量共形耦合：**这个单圈主导的 R 项消失**，不代表真实世界 G=∞。
- `ξ>1/6`，单标量主导贡献符号翻转：模型缺少必要的其他场/重整化输入。
- `m>0`，截止积分的权重 `F(μ)=∫_0^1 e^{-μ²/t}dt`，范围 `[0,1]`、对 μ 非增。
- 当 `ell=ell_P`、`N=1`，最简模型 `G_ind/G_obs=12π`，**并不等于 1**。
- 反向拟合 `ell_fit=sqrt[G_obs N(1-6ξ)ℏ/(12π c³)]` 重新代回得到 G_obs，只检查代数闭环，不是独立证据。

## C. 以前的严重错误、未证假设

| 提案或常见说法 | 审计结果 | 修复 |
|---|---|---|
| “所有粒子运动速度均为 c” | 与有质量粒子惯性运动的局域物理相矛盾，若是内部相位速度需重新定义 | 将 c 螺旋仅视作运动学或场相位假设 |
| `r=(R cosωt,R sinωt,ct)` 同时宣称总速率 c | 实际总速率为 `sqrt((Rω)²+c²)>c`（ω非零） | 使用 `u=c sinλ`, `Rω=c cosλ`，不可两者独立均取 c |
| 三力普遍正交 | 存在简单反例：`Fg=(0,0,-1)`, `Fe=(0,0,-2)`，点积为 2 | 只保留某些配置下的正交关系 |
| 把曲线挠率 τ 直接设为时空挠率张量 | 标量与带指标张量不是同一对象 | 必须写出协变映射与耦合方程 |
| `G=2Z/c` 已预测 G | 如 `Z=Gc/2` 则属于重命名与代数恒等式 | 提供 Z 的独立物理定义和实验测量路径 |
| `G=c²r/m` 可对任意粒子/尺度成立 | 需要明确 r,m 的物理选择，否则维度正确不代表物理唯一 | 从微观动力学独立规定 r,m |
| `G` 由 `c,ℏ,角度` 唯一得出 | 无法通过量纲检验 | 引入独立的尺度与自洽动力学，不得用 G 反定 |
| `α=1/(4π³+π²+π)` 为精确常数 | 数值约 0.007297336344，CODATA 约 0.007297352564，相对误差约 `-2.22×10⁻⁶` | 改称数值近似或猜想，不是恒等式 |
| `m_p/m_e=2π·3³+2π=1836.15267343` | 左式 `56π≈175.929`，基本算术错误 | 撤销等式；不以数值拟合构成质量谱证明 |
| `ℓ=ℏ/(cE)`（E是焦耳能量） | 量纲错误 | 正确为 `ℓ=ℏc/E` |
| 理想地磁球谐/椭球重力近似叫“真实地球观测” | 模型与真实数据混淆 | 明确标注玩具模型，不声称 IGRF/EGM2008 已集成 |

## D. 四力统一判定

已知总作用量 `S_EH+S_SM` 可变分出 GR 与标准模型（需考虑数学/物理边界条件）。但它没有解释 G、三个规范耦合、手征表象、三代、质量/Yukawa 参数，因此不具备“从同一本原方程推出全部参数”的证明资格。

**审计状态：** 结论中除了明确附条件的方程以外，无任何可声称新物理被证实的结果；假设性预测表中所有数字均不是实测。
