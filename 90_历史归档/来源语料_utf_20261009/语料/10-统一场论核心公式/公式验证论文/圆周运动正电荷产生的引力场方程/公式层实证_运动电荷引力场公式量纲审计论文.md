# 统一场论「运动电荷产生引力场」公式的量纲审计与实证分析

**副标题：基于四维量纲系统的独立复算、数值量级量化与文档一致性审查**

---

## 摘要

本文针对张祥前统一场论（ZUFT）框架下"圆周运动正电荷产生引力场"的核心方程（被审代码 `verify_circular_motion_gravity_field.py` 中的 V2 方程）进行公式层实证。采用算法联盟标准的四维量纲系统（M, L, T, I）独立复算，结论为：该公式右边的量纲为 `[M L T⁻³ I⁻¹]`，即**电场强度 N/C**，而非代码 `ylabel` 所宣称的加速度量纲 `m/s²`（`[L T⁻²]`）。数值量级量化表明，将代码产出经电子荷质比折算为加速度后，比同一物理场景下真实牛顿引力场大 **~26 至 ~38 个数量级**。进一步审查发现：作者自验证脚本第 58–59 行已正确标注"量纲可能不一致"，但同目录的推导文档（§4.1、§3.1）却在中间步骤正确写出 `ε₀` 量纲后，于最后一步把本应等于 N/C 的结果错误化简为 `m/s²` 并声称"完全一致"——构成文档粉饰。本文所有数字均来自可复跑脚本 `量纲审计实证.py`。

**诚实归属**：量纲数学结论成立；但"量纲不一致"这一核心疑点作者自验证脚本已先发现，本文贡献在于标准量纲独立复算（纠正推导瑕疵、给出精确 N/C）、数值量级量化、最小修正分析与文档粉饰定位，属独立验证与整合，非首发性原创发现。

## 2. 方法论：四维量纲审计系统

采用算法联盟标准的四维基本量纲：质量 `M`、长度 `L`、时间 `T`、电流 `I`。每个物理量表示为四维指数向量，推导通过乘法（指数相加）、除法（指数相减）完成，最后与基准量纲比对：

- 加速度 `m/s²` = `[L T⁻²]`
- 电场强度 `N/C` = `[M L T⁻³ I⁻¹]`（牛顿 `N=[M L T⁻²]`，库仑 `C=[I T]`）

判定规则：若公式右边量纲与左边声明量纲相等 → PASS；否则 → FAIL，并记录偏差维度。

## 3. 量纲审计结果（符号推导）

### 3.1 独立复算：公式量纲 = N/C

基本量纲（详见 `量纲审计实证.py`）：

| 量 | 符号 | 量纲 |
|----|------|------|
| 电荷 | `q` | `[I T]`（库仑 = A·s）|
| 真空介电常数 | `ε₀` | `[M⁻¹ L⁻³ T⁴ I²]`（F/m = C²·s²/(kg·m³)，C=A·s）|
| 光速 | `c` | `[L T⁻¹]` |
| 距离 | `r` | `[L]` |
| 加速度 | `a_q` | `[L T⁻²]` |

推导：

```
分母 ε₀ c² r = [M⁻¹ L⁻³ T⁴ I²] · [L² T⁻²] · [L]
             = [M⁻¹ L⁰ T² I²]

q / (ε₀ c² r) = [I T] / [M⁻¹ T² I²]
              = [M T⁻¹ I⁻¹]

整体 (q/(ε₀ c² r)) · a_q = [M T⁻¹ I⁻¹] · [L T⁻²]
                           = [M L T⁻³ I⁻¹]
                           = N/C   ✓（电场强度）
```

独立复算确认：公式量纲为 **`[M L T⁻³ I⁻¹]` = N/C**，与代码声明的 `m/s²`（`[L T⁻²]`）**不一致**。

### 3.2 作者自验证脚本的结论

被审代码第 58–59 行作者本人已正确判断：

> "但根据方程，实际量纲应为 m/s²，这里存在问题"
> "✗ 量纲可能不一致，需要进一步分析"

**即：量纲不一致的疑点，作者自己已先发现并记录。**

### 3.3 推导文档的粉饰（确凿证据）

审查 `circle_motion_gravity_field_derivation.md` 第 90–92 行（§4.1）：

```
### 4.1 量纲一致性验证
- 左边 A 的量纲：[A] = m/s²（加速度量纲）
- 右边的量纲：( [q]·[a] ) / ( [ε₀]·[c²]·[r] )
            = ( [IT]·[LT⁻²] ) / ( [L⁻³M⁻¹T⁴I²]·[L²T⁻²]·[L] )
            = [LT⁻²]（与左边一致）
```

注意其**中间步骤正确**写出了 `ε₀ = [L⁻³M⁻¹T⁴I²]`（T 的四次方正确）。但按该中间步骤实算：

```
分母 = [L⁻³M⁻¹T⁴I²]·[L²T⁻²]·[L] = [M⁻¹T²I²]
分子 = [IT]·[LT⁻²] = [ILT⁻¹]
结果 = [ILT⁻¹]/[M⁻¹T²I²] = [M L T⁻³ I⁻¹]  = N/C  ≠  [LT⁻²]
```

推导文档却在最后一步把结果**错误写成 `[LT⁻²]`**，并声称"与左边一致"。这是一步代数错误 + 粉饰性结论。

`multi_dimension_verification.md` 第 100–105 行（§3.1）存在**完全相同的错误**：中间正确写 `ε₀=[L⁻³M⁻¹T⁴I²]`，最后却给出 `[LT⁻²]` 并声称完全一致。

### 3.4 三处结论的矛盾

| 来源 | 结论 | 正确性 |
|------|------|--------|
| 作者自验证脚本（第 58–59 行） | 量纲可能不一致 ✗ | 结论正确 |
| 推导文档 §4.1 / §3.1 最后一步 | 量纲完全一致 ✓ | **结论错误（粉饰）** |
| 本文独立复算 | 量纲 = N/C，与 m/s² 不一致 | 结论正确 |

**核心矛盾**：同目录的"验证文档"声称量纲一致，而作者自己的验证脚本标注不一致；独立复算支持后者。推导文档在中间步骤正确、最后一步出错，构成粉饰。

## 4. 数值量级实证

### 4.1 方法

被审公式实际产出（量纲 N/C）与"引力场"语义之间，必须经检验粒子的荷质比 `(q_test / m_test)` 才能折算为加速度：

```
E_v2 = |q| / (4π ε₀ c² r) · |a_q|          [N/C]
a_from_E = (e / m_e) · E_v2                [m/s²]（检验粒子取电子）
g_real = G · m_e / r²                       [m/s²]（同一运动电子作为质量源）
```

取标准物理常数 `e, ε₀, c, G, m_e`，考察三个场景，计算比值 `a_from_E / g_real`。

### 4.2 三场景结果（脚本实跑）

| 场景 | r (m) | a_q (m/s²) | E_v2 (N/C) | a_from_E (m/s²) | g_real (m/s²) | 比值 | 数量级 |
|------|-------|-----------|-----------|----------------|--------------|------|--------|
| 单位场景（代码默认量级） | 1.0 | 1.0 | 1.602e-26 | 2.818e-15 | 6.080e-41 | 4.635e+25 | **~25.7** |
| 原子尺度（玻尔半径, 电子圆周向心加速度） | 5.292e-11 | 9.0e22 | 2.725e+07 | 4.793e+18 | 2.171e-20 | 2.207e+38 | **~38.3** |
| 介观场景 | 0.01 | 100 | 1.602e-22 | 2.818e-11 | 6.080e-37 | 4.635e+25 | **~25.7** |

### 4.3 结论

若将代码产出强行当作"引力场加速度"（如 `ylabel` 所声称），其与真实牛顿引力场相差 **~26 至 ~38 个数量级**。量级本身即强烈说明该公式不是引力场。这与第 3 节量纲审计（产出为电场 N/C）互为印证。

## 5. 最小修正因子分析

### 5.1 量纲修正

要得到加速度量纲 `m/s²`，必须消去电流维 `I`。最小修正：在 `E_v2` 上乘检验粒子的荷质比：

```
A_correct = (q_test / m_test) · E_v2   ⇒  (N/C)·(C/kg) = N/kg = m/s²
```

### 5.2 机制冲突

该修正暴露更深层问题：修正后"场"仍**依赖检验电荷 `q_test` 而非检验质量 `m_test`**。而真正的引力场应对一切质量给出相同的 `g`（与检验粒子电荷无关）。因此该公式在机制上仍是**电场（依赖电荷）**，并非引力场。量纲修正只能得到"电荷在电场中受的加速度"，不能得到"质量受的引力加速度"。

## 6. 原创性与正确性声明（诚实归属）

### 6.1 正确性

量纲数学推导成立：公式右边量纲确为 `N/C`，与代码声明的 `m/s²` 不一致；数值量级量化（~26–38 个数量级）由标准物理常数计算得到，可复跑复核；最小修正因子 `(q/m)` 的分析在量纲上成立。

### 6.2 非完全原创

"运动电荷引力场公式量纲不匹配"这一**核心疑点，作者自验证脚本（第 58–59 行）已先于本文发现并标注**。本文的工作实质是：

1. **标准量纲独立复算**：用四维量纲系统给出精确结果 `N/C`，并纠正推导文档 §4.1/§3.1 最后一步的代数错误（其将 `N/C` 误写为 `m/s²`）；
2. **数值量级量化**：给出 ~26–38 个数量级的对比，使"不一致"从定性升级为定量；
3. **最小修正因子分析**：指明 (q/m) 修正及其机制冲突；
4. **文档粉饰定位**：指出"验证文档声称一致"与"作者自验证脚本标注不一致"的直接矛盾，并锁定粉饰所在的代数步骤。

本实证属**独立验证与整合**，不是首发性原创发现。

### 6.3 可复跑性

所有数字来自 `量纲审计实证.py`（纯标准库 + numpy，无第三方依赖），运行即复现第 3、4 节全部结果。本文对其中的两处自身 bug（ε₀ 量纲 T 指数、断言比较对象）已自查修正，确保结论自洽。

## 7. 结论与建议

### 7.1 结论

1. 被审 V2 公式量纲 = `N/C`（电场），非代码所声称的 `m/s²`（加速度）；
2. 数值上比真实引力场大 ~26–38 个数量级；
3. 同目录"验证文档"声称量纲一致，但最后一步代数错误且与其自验证脚本矛盾，构成粉饰；
4. 即便施加最小 (q/m) 修正，该公式机制上仍是电场，非引力场。

### 7.2 真正原创突破的建议方向（尚未被作者审计覆盖）

1. **同口径审计其余公式**：被审代码仅对 V2 做了量纲检查；V1/V3/V4 及 ZUFT 其他核心公式（如加速运动电荷引力场、统一场论其他方程）尚未经独立量纲审计——这是算法联盟方法论尚未覆盖、且真正有增量价值的空白。
2. **把 (q/m) 修正真正落入代码**：验证修正前后物理曲线差异，而非仅做量纲标注。
3. **复算理论尚未被检验的预言**：而非重复审计已知量纲问题的公式。
