# ch12 宇宙演化：从暴涨到结构形成

> 本章核心问题：**标准宇宙学如何用几个参数描述整个宇宙？宇宙从诞生到现在经历了什么？**

## 12.1 Friedmann 方程：宇宙学的引擎（已证实）宇宙学建立在"宇宙在大尺度上均匀各向同性"（宇宙学原理）之上。把该对称性代入 Einstein 方程，得到 Friedmann 方程：$$H^2=\left(\frac{\dot a}{a}\right)^2=\frac{8\pi G}{3}\rho-\frac{k}{a^2}+\frac{\Lambda}{3}$$

其中 $a(t)$ 是尺度因子，$H=\dot a/a$ 是哈勃参数，$\rho$ 是能量密度，$k$ 是空间曲率（$k=0$ 平坦），$\Lambda$ 是宇宙学常数。当前模型 **ΛCDM**：暗能量（$\Lambda$）+ 冷暗物质 + 普通重子物质 + 辐射，$k=0$ 平坦。

## 12.2 Planck 2018 参数：一张清单（已证实）附录 C 核对的 Planck 2018（TT,TE,EE+lowE+lensing+BAO）核心参数：$$\Omega_b h^2=0.02242,\quad \Omega_c h^2=0.11933,\quad H_0=67.36\pm0.54\ \mathrm{km/s/Mpc},\quad n_s=0.9649,\quad \sigma_8=0.8111,\quad \Omega_\Lambda=0.6847,\quad \Omega_m=0.3153,\quad \Omega_m+\Omega_\Lambda=1.0000$$

$$\text{宇宙年龄}=13.797\ \mathrm{Gyr},\qquad z_{eq}\approx 3434\ (\text{物质-辐射等量})\qquad \text{年龄}/H_0^{-1}=0.950$$

这些参数以 $\sim0.1\%$–$1\%$ 精度刻画宇宙【已证实】。

## 12.4 宇宙学常数问题：现代物理最大的谜若 $\Lambda$ 来自量子真空能，其"自然"大小应约为普朗克能标四次方，比观测值大 $10^{120}$ 量级。这个**天文级失配**没有任何公认解释【已证实-问题存在，解答 OPEN】。框架若把暗能量归为几何效应，必须解释为何几何产生的有效 $\Lambda$ 恰好这么小——目前无机制（OPEN-C1）。## 12.5 框架与标准宇宙学的关系- 标准宇宙学（ΛCDM）是【已证实】的基准模型，本书不否定它；- 框架对暗物质/暗能量的"几何解释"（ch13）只是并列候选，且**目前没有给出与 ΛCDM 可区分的定量预言**；- 框架若想成为真正的统一理论，必须能在 ΛCDM 成立的观测范围内复现其全部成功，再在张力处（如哈勃张力）给出可检验的改进（ch14）。

## 12.6 三个时代的三种"解法"Friedmann 方程在不同物质主导下有精确解（$k=0$ 平坦宇宙）【已证实-数学】：- **辐射主导**：$a(t)\propto t^{1/2}$，$\rho\propto a^{-4}$；
- **物质主导**：$a(t)\propto t^{2/3}$，$\rho\propto a^{-3}$；
- **暗能量主导**：$a(t)\propto e^{Ht}$，$H=\sqrt{\Lambda/3}$（de Sitter 指数膨胀）。

**当前宇宙**正处于物质主导向暗能量主导过渡的尾段（$z\lesssim0.6$ 起加速）。这三个解拼出宇宙的"减速→加速"历程，是超新星 Ia（1998 年 Nobel）发现暗能量的基础【已证实】。

## 12.7 CMB：宇宙的"婴儿照片"宇宙微波背景（CMB）是 38 万年时释放的光，温度 $T=2.725\ \mathrm{K}$，各向异性 $\Delta T/T\sim10^{-5}$。其**角功率谱**的声学峰序列编码了 $\Omega_b h^2,\Omega_c h^2,H_0,n_s$ 等参数【已证实】：- 第一个峰（ℓ≈220）→ 空间平坦性（$\Omega_{total}\approx1$）；
- 奇偶峰高比 → $\Omega_b h^2$（重子压低奇峰）；
- 峰位整体平移 → $H_0$。

**这就是为什么 Planck 的 $H_0=67.36$ 与距离阶梯的 $73.04$ 之争如此关键**：两者都来自极其精密的观测，却给出不同答案（ch14 详述）。CMB 是本书全链路 A5 层最硬的"锚"。

## 12.8 结构形成：从涨落到星系CMB 的微小密度涨落 $\delta\rho/\rho\sim10^{-5}$ 在引力作用下增长，形成今天的大尺度结构。线性增长由：$$\ddot\delta+2H\dot\delta-4\pi G\rho_m\delta=0$$

描述（$\delta$ 是密度对比度）。**暗物质在这张图里不可替代**：普通物质的声学压力会阻碍结构形成，而暗物质"只受引力"——没有暗物质，星系无法在观测到的时间内形成。**这从正面再次确认暗物质的存在性**【已证实】。

## 12.9 参数的"相关性"：宇宙学不能只看单个数字ΛCDM 的六个参数（$\Omega_b h^2,\Omega_c h^2,\theta_*,\tau,n_s,A_s$）不是独立测的——它们从 CMB 功率谱的**整体形状**联合拟合，彼此强相关【已证实】。例如：- $H_0$ 与 $\Omega_m$ 负相关：抬高 $H_0$ 需压低物质密度或引入额外成分；
- $n_s$ 与 $\tau$ 相关：谱倾斜与再电离光学深度在低 ℓ 处互相纠缠。

**对框架的含义**：框架若只想"调高 $H_0$ 到 73"，不能只动一个旋钮——它会同时破坏 $\sigma_8$、$n_s$ 等其它参数的拟合。**这正是早期暗能量模型"按下葫芦浮起瓢"的困境**（ch14 详述）。任何"调解"都必须接受**联合拟合**的检验，而不是单参数微调【已证实-方法论】。框架的几何机制若不能通过联合拟合，调解就只是一厢情愿（OPEN-H1）。

## 12.10 宇宙学在未来十年的"判决者"- **CMB-S4**：把 CMB 极化精确到 $\sim0.1\%$，直接检验 $H_0$ 与 $\sigma_8$；- **DESI / Euclid / Roman**：重子声学振荡（BAO）与弱透镜，测量暗能量状态方程 $w(z)$ 与 $H(z)$；- **引力波宇宙学**：标准汽笛给出独立于距离阶梯的 $H_0$（ET/CE 时代）。

**这些实验将在 5–10 年内决定**：ΛCDM 是否成立、哈勃张力是系统误差还是新物理、暗能量是否真是宇宙学常数。**对框架的含义**：它的"几何宇宙学"必须能搭上这班数据快车——**给出可检验预言，否则将被数据时代甩下**（OPEN-C1/H1）。
