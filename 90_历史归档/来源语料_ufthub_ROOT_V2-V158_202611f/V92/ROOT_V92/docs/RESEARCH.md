# ROOT V92 科学审计

## 模型

四分支距离按 (r,r+d,r+d,r+2d) 排列；相位 phi_ab=G*m1*m2*t/(hbar*r_ab)。状态 |psi>=sum exp(i phi_ab)|ab>/2。整体及局部相位不改变纠缠；非局部不变量 Delta=phi00-phi01-phi10+phi11。

纯态负性 N=|sin(Delta/2)|/2；负性定义为部分转置负特征值绝对值之和。独立局部相位退相干使用每个不同量子比特的非对角元乘以 visibility。此模型为有效两量子比特模型，未包含波包演化、有限尺寸、相对论场传播和测量装置。

## 关键区分

1. 受控量子双体相位可产生纠缠，属于牛顿量级现象；它不是直接测量量子引力 EFT 一圈修正。
2. 共享随机局部相位的经典混合态是可分态；但这不能排除所有具有不同假设的经典引力理论。
3. PPT/负性对于两个量子比特是完整纠缠判据，但测量负性需要足够的量子态重构或可信见证，不能仅由模型算出就声称实验检出。
4. V91 距离形状可辨识性必须扩展为多观测量、多干扰参数的实验设计。
5. 在 c=1 单位制下推导，代码为 SI 数值计算并保留 c、G、hbar 的独立单位；本模型只涉及牛顿项。

## 后续可证伪目标

推导具体经典媒介动力学与量子媒介动力学在相同实验初态、传播时延、退相干及测量条件下的可区分观测分布；再通过统计功效计算和系统误差预算确定真实实验门槛。不能把模拟结果称作实验验证。
