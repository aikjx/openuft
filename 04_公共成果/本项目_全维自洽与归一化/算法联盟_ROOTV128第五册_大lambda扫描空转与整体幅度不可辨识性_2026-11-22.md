## 0. 一句话

**`α` 不是一个物理参数，`β = α/λ²` 才是。**

理由是代数，不是拟合：把 `e^{−r/λ}` 展开，常数项 `α` 乘在 `1/r` 上，只是把 `μ` 换成 `μ(1−α)`；而 `μ` 与 `(1−α)` 在**所有**引力泛函里以乘积出现，且「源质量」本身只能由 `GM/G` 定义。于是「整体幅度」与「质量」是**同一个未知数的两种写法**，不是「精度不够」。首个真正改变势**形状**的项是 `−α r/(2λ²)`——一个常数径向加速度，量级正是 `α/λ²`。

**推论**：任何沿 λ 扫描、报告「`α < bound(λ)`」的做法，在大 λ 端只是同一个 β 约束除以 `λ²` 的换算式。第三册 11 个 λ 格点里，`λ ≥ 30 AU` 的那 6 个不是 6 次独立检验。

## 1. 攻击面为什么选这里

第四册证明了「整体幅度对近点进动精确零信息」（核 `8.86e−19` vs 信号 `O(1)`，差 18 个量级）。这个结果容易被读成「某个观测量的缺陷」——那就还有别的观测量可换。**本册要判的正是这一读法**：

> 零方向是**一个观测量的缺陷**，还是**整个理论的一个对称性**？

三条互不引用的路线同时给出后者：

1. **代数**（L2/L3）：`C ≡ c₀` 常数时，进动、Shapiro、偏折、红移、周期、`T²/a³` 六个泛函**全部**只整体乘 `(1−c₀)` 的幂。所以不是进动的毛病，是「势的线性泛函」这一整族的共同退化。
2. **等效原理**（L4）：耦合质量的第五力不破强等效原理，`η ≡ 0` 精确。所以「非引力质量标定」这条通道**结构性**不存在。
3. **跨册读数**（L5–L7）：第三册的 α 剖面在 β 化后塌成常数。所以「λ 扫描」在大 λ 端没有新信息。

三条路线各自可机读、互不引用，指向同一件事。

## 3. 逐个读数

### 3.1 L1 自检（守卫）

| 项 | 读数 |
|---|---|
| `C = 0` 时 Shapiro 积分 | `max abs(I) = 0`（机器零，不是「小」） |
| Kepler 残差 `max abs(E − e sinE − M)` | `1.000000E−59` |
| Shapiro 核四阶收敛（`n = 320/640/1280/2560`） | 误差 `6.279E−12 → 3.924E−13 → 2.453E−14 → 1.533E−15`，观测阶 **4.0000 / 4.0000 / 4.0000** |
| 偏折核 数值 vs 闭式 | `rel = 1.917370E−17` |
| Richardson（`1/(1+x²)` vs `π/4`） | `rel = 9.868238E−18` |

**这里改过一次判据对象，理由要写清**：首跑用 `L = 1000` 与被积函数 `1/√(b²+l²)`（`b = 1`）做「数值 vs 闭式 asinh」，得到 `rel = 1.006266E−02`，门判 FAIL。查因：被积函数的结构尺度是 `b = 1`，而积分区间长 `L = 1000`，`n = 400` 时步长 `h = 2.5`——**根本分辨不了 `l ~ 1` 处的结构**。这是**量程问题，不是积分器错**。

修法不是放宽容差，而是换判据对象：判「**观测阶是不是 4**」（这是积分器的性质），而不是判「绝对残差够不够小」（那取决于量程）。物理结论全程只用**比值**（同节点、同权重，求积误差精确抵消），所以 `L = 1000` 上不需要绝对精度。改后 `L = 20`，四阶收敛到 `2.5e−5` 的相对精度被观测到。

### 3.2 L2 统一零方向（结构）

对 `c₀ ∈ {0.1, 0.3, 0.5}`，`b = 1`，`L = 1000`：

| 泛函 | 理论缩放 | 实测最大偏离 |
|---|---|---|
| Shapiro `∫Φ dl` | `(1−c₀)` 一次 | `7.4E−60` |
| 偏折 `δ ∝ μ(1−c₀)/b` | `(1−c₀)` 一次 | `0` |
| 周期 `T ∝ μ^{−1/2}` | `(1−c₀)^{−1/2}` | `0` |
| 形状量（归一化后） | 不变 | `1.0E−59` |

三行合起来的最大偏离 `1.000000E−59`，即 `prec = 60` 的地板。**形状量**（`δ·b/μ`、`I/|I|`）与 `c₀` 无关，到机器精度。

进动不在本册重算——第四册已机读 `8.862149E−19`，且对纯 `1/r` 势恒为 0 是代数的。本册只声明继承。

### 3.3 L3 精确简并（**恒等，不承重**）

`Φ = −(μ/x)(1−c₀)` 要等于 `−(μ′/x)`，必须 `μ′ = μ(1−c₀)`。写成 `μ′ = μ/(1−c₀)` 会让简并方向**反过来**（本轮实测偏离 `14.571`，门以 FAIL 报出）。

| 检验 | 读数 |
|---|---|
| `Φ` 逐点差（7 个半径） | `0` |
| 固定 `μ_eff = 1` 的三成员族 `(c₀, μ) = (0, 1) / (0.3, 1.428571) / (0.5, 2)` | `Φ` 最大偏离 `1.0E−59` |
| 同一 `t` 的 `r(t)` | `0` |
| 6 个引力泛函枚举 | `0` |

所以简并是**一条精确的一维直线** `μ(1−c₀) = μ_eff`，不是「参数不好定」。族内任何成员给出同一条轨道、同一套观测量。要破它，只能靠 `c₀` 的 **r 依赖**——即有限的 `λ`。

**这是恒等，按纪律单列，不进证据份数。**

### 3.4 L4 等效原理：一条负读数

Yukawa 第五力耦合的是**质量**（`V ∝ m₁m₂`），所以荷质比 `q/m = 1` 对所有成分相同：

| 耦合假设 | Eötvös 参数 `η` |
|---|---|
| `q = m`（V128 的写法） | `max abs(η) = 0`（精确，四个 α 与三组 (r,λ) 全扫） |
| `q = B`（重子数，仅作对照） | `η(Fe,Ti) = 3.399998E−09` at `α = 1e−6`、`λ ≫ r` |

判别力：同样 `α` 下两者之比 `3.40E+291`（分母是机器零，比值只用来证明「不是都为零」）。

**结论（负读数）**：实验室等效原理实验、月球激光测距、MICROSCOPE——这一整族「非引力质量标定」通道，对 V128 这类耦合质量的第五力**结构性失效**。不是精度不够，是**没有信号**。

这条负读数把「换观测量」的路堵掉一半：既然 `η ≡ 0`，就没有第二条方程独立定出质量；而「太阳质量」本身就是 `GM/G` 的商。**所以整体幅度在太阳系内原则上不可辨识。**

### 3.5 L5 尾部 `α₉₅/λ²` 恒定（**承重**）

判的是**被报告的 95% 上界** `α₉₅ = |α̂| + 1.96σ`，不是 σ 单独——因为 `α₉₅` 才是对外发布的那个数。

EPM2011（`λ ≥ 30`）：

| λ (AU) | `α₉₅` | `α₉₅/λ²` |
|---|---|---|
| 30 | `1.032777E−09` | `1.1475E−12` |
| 100 | `1.111709E−08` | `1.1117E−12` |
| 1e3 | `1.097928E−06` | `1.0979E−12` |
| 1e4 | `1.096548E−04` | `1.0965E−12` |
| 1e5 | `1.096410E−02` | `1.0964E−12` |
| 1e6 | `1.096396E+00` | `1.0964E−12` |

- `λ ≥ 1e3` 的相对散布：**`1.397305E−03`**（EPM2011）／**`3.915141E−03`**（INPOP10a）
- 全尾（含 `λ = 30`）：`4.663826E−02` ／ `1.242203E−01`
- 判据：`λ ≥ 1e3` 散布 `< 1e−2`，实测 `3.915141E−03`（取两个数据集的较差）

**对照**：若这 6 个格点是 6 次独立检验，β 化后的散布不会塌到 `1e−3` 量级。`1.96σ_α` 按 `λ²` 增长这件事本身，就说明 σ 完全由 `λ²` 的标度决定，不含 λ 的独立信息。

**负读数（如实登记，不追因）**：`λ ≥ 1e5` 的两点在 β 化后偏离单调序列（EPM2011 约 `+3.6E−06` 与 `−1.3E−05`），方向反常。量级远小于判据阈值，不影响结论；疑为网格端点的条件数效应，**标 open，本册不据此调整任何结论**。

### 3.6 L6 尾部格点塌缩（**承重**）

相邻两点的 `σ_β` 之比：

| EPM2011 | `0.96063 / 0.98410 / 0.99838 / 0.99984 / 0.99998` |
|---|---|
| INPOP10a | `0.93262 / 0.97049 / 0.99691 / 0.99969 / 0.99997` |

尾部 `max abs(β 比 − 1) = 6.737580E−02`，且逐对单调趋向 1（`λ = 30` 那一对含 `O(1/λ)` 修正，是最大值来源）。

**结论**：尾部 6 个 λ 格点不构成 6 份独立检验，而是**同一个 β 区间的 6 次重写**。这一点与 L5 用的是不同读数（L5 看散布，L6 看逐对比值），两路互不引用。

### 3.7 L7 排除带的两端（**承重-负读数**）

第三册报告 `α = 1` 的排除带（EPM2011）`1.258925E−02 → 1.000000E+06`，`7.90 dex`，`80/111`。本册把它拆成两端：

| 数据集 | 报告上端 | β 交叉解析 `λ* = 1/√(β̂ + 1.96σ_β)` | 比 | 网格步长 |
|---|---|---|---|---|
| EPM2011 | `1.000E+06` | `1.222636E+06` | `1.2226` | `1.2589` |
| INPOP10a | `5.012E+05` | `5.732434E+05` | `1.1438` | `1.2589` |

两个比值都落在 `[1, 1.2589)` 内 ⇒ 报告的**上端就是「最后一个被排除的网格点」**，精度受网格离散化限制（`10^{0.1}` 步长），不是被某个物理尺度钉住。

- **下端** `1.258925E−02`：由 `exp(−a/λ)` 衰减决定——λ 太小时第五力在行星轨道上已被杀到 0。这是**形状机制**。
- **上端**：由 β 约束与 `α = 1` 线的交叉决定——`λ²(β̂ + 1.96σ_β) = 1`。这是**标度机制**。

**结论（负读数）**：`7.90 dex 排除带` 不是一个物理对象，而是两个互不相关条件的**交集**。它看起来连续，是因为两条边界恰好在这一段相距很远。

### 3.8 L8 判别力反噬（守卫）

| 剖面 | `α₉₅/λ²` 在 `λ ≥ 1e3` 的散布 | 应当 |
|---|---|---|
| 真剖面 | `1.397305E−03` | 通过 |
| 假：σ 恒定（`α̂ = 0`） | `9.999990E+05` | 失败 |
| 假：`α₉₅ ∝ λ³` | `9.976046E+02` | 失败 |
| 正对照：单点 `+20%` | `2.000153E−01` | 散布上升 |

两个假剖面都把散布推到阈值的 5 个数量级之上，说明 L5 的判据**不是**「所有剖面都通过」的装饰。

**这里改过一次假剖面的构造，是本轮第二个自伤**：首跑用真实的 `α̂` 去构造假剖面（只把 σ 换成常数），结果 `q_fake` 两端只差 `0.3%`，判据识别不出——因为**真的 `α̂` 本身 ∝ λ²**，它把假剖面「救活」了。改成 `α̂ = 0`（即「数据对大 λ 没有灵敏度」这个零假设）才构成正确的对照。
**纪律**：构造负对照时，不能保留被测机制赖以成立的那个成分；否则测的是它，不是你要测的东西。

## 4. 三条承重门合起来说了什么

三句话，互不引用：

1. **L5**：`λ` 扫描在大 λ 端的 α 上界**等比例**增长，β 化后恒定到 `1e−3`。
2. **L6**：这个恒定不是巧合，逐对比值单调收敛到 1。
3. **L7**：因此排除带的右端不是物理边界，是 β 约束与 `α = 1` 线的交点。

合起来：**「沿 λ 扫描得到多少条约束」这个问题，答案不是格点数**。`λ ≥ 30 AU` 的 6 个格点只给出 **1 个** `β` 约束。

这与方法论总纲里的「门数 ≠ 证据份数」是同一把刀的另一次落刀：那次是**门**的重复计数，这次是**格点**的重复计数。

## 6. 自抓与事故（本轮五处）

1. **L3 符号错**：写成 `μ′ = μ/(1−c₀)`，`Φ` 偏差 `14.571`，门 FAIL。真解 `μ′ = μ(1−c₀)`。**教训**：「简并方向」是代数事实，不能凭直觉写除法。
2. **L1 量程错**：`L = 1000`、`n = 400` 下 Simpson 给 `1e−2` 假偏离。**是量程不是积分器**。改为判「观测阶 = 4」而非「绝对残差小」。
3. **L5 极限自指**：首版用 `σ_β(λ = 1e6)` 当极限算 `dev·λ`，得 `1.791 / 1.799 / 1.802 / 1.785 / 1.621`——末项看起来「不收敛」，真因是**极限点自身偏离 1.8e−6**。改用 `α₉₅/λ²` 的散布，绕开「极限未知」的自指。
4. **L8 负对照被真值救活**：用真实 `α̂`（∝ λ²）构造假剖面，散布只差 `0.3%`。改 `α̂ = 0`。
5. **拼接器截断事故**：拼接脚本用 `src.find('# ---- 门 L4 ')` 定位，而实际标记是 `门 L4：`（冒号无空格），`find` 返回 `-1`，`src[j:]` 只剩最后一个字符 ⇒ 源码被截断到 `16,603 B`（应 `42,052 B`）。从 `_scratch/` 的分区文件重建修复。
   **纪律**：字符串定位必须 `assert idx > 0` 之后再切片；`-1` 切片是静默数据丢失。

## 7. 边界

- **没有证明统一场论成立或失败。** 本册判的是「`α` 在大 λ 端不是可观测参数」，**不是**「第五力不存在」，也**不是**「V128 被证伪」。
- 独立实验预言 **0**；证据份数按承重门计 **3**（L5/L6/L7），恒等门 L3 不计。
- 本册**不重拟合**、**不改**第三册任何判词。L7 的负读数是对第三册**表述方式**的补充，不是对其数据的否定。
- 「λ ≥ 1e5 两点反常」**标 open，不追因**，也不据此调整任何结论。
- 若将来有人在 `β` 而非 `α` 上报告约束，本册结论**不变**——这正是它的意思。
- 耦合质量的第五力不破等效原理，这是 V128 这一类模型的**结构属性**；耦合重子数的模型（quintessence 型）不受本册 L4 约束，本册不对它们表态。
