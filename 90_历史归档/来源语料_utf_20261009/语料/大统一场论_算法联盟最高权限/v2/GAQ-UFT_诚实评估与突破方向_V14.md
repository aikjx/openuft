## 2. No-Go 定理

### 2.1 No-Go 1: g-2 符号定理

**陈述**：若螺旋角动量 L = ℏ/(1+α²) 与标准自旋 S 满足 L = 2S，则 g_geom = 2/(1+α²) < 2。但实验 g > 2，因此 L ≠ 2S。

**证明**：

```
1. 假设 L = 2S（螺旋角动量 = 自旋的两倍）
2. L = ℏ/(1+α²)（V6.0 修正后的螺旋角动量公式）
3. 由 1,2：2S = ℏ/(1+α²) → S = ℏ/(2(1+α²)) ≠ ℏ/2
4. 磁矩 μ = -g·μ_B·(S/(ℏ/2))
5. S/(ℏ/2) = 1/(1+α²) ≈ 1 - α²
6. 因此 μ_geom = -g·μ_B/(1+α²)
7. 定义 g_geom = g/(1+α²)，若 g=2，则 g_geom = 2/(1+α²) < 2
8. 但实验 g_e = 2.00231930436 > 2，因此假设 L = 2S 错误
```

**定量验证**：

```python
L = 1.054515663e-34 J·s    # 螺旋角动量
2S = 1.054571818e-34 J·s   # 两倍自旋
L/(2S) = 0.999946751       # 差异 α² ≈ 5.3×10⁻⁵

若 L = 2S: g_geom = 2/(1+α²) = 1.999893503 < 2
实验 g_e = 2.002319304 > 2
Δg = -0.002425801          # 方向冲突！
```

**结论**：螺旋角动量 L 不能等同于自旋 S 的两倍。L 是额外的几何自由度或参数化，不是物理自旋。

### 2.2 No-Go 2: 质量独立 g 因子定理

**陈述**：若 g_geom = f(α) 仅依赖 α（普适常数），则 g_e = g_μ。若 g_geom = f(α, m) 且满足自然性，则无法解释 μ 子异常。

**证明**：

```
1. 电子 g-2 异常：a_e^exp = 0.00115965218, a_e^SM = 0.00115965233
   → 0.6σ 一致，无新物理迹象
2. μ 子 g-2 异常：a_μ^exp = 0.001165920, a_μ^SM = 0.001165918
   → 4.2σ 张力，暗示新物理
3. 若 g_geom = f(α)：由于 α 是普适常数，g_e = g_μ，无法解释差异
4. 若 g_geom = f(α, m)：
   • 需要 g_geom(m_e) < 2（定理 1 已证）
   • 需要 g_geom(m_μ) > 2（解释 μ 子异常）
   • 这需要 g_geom 在 m_e 和 m_μ 之间穿过 2
   • 但任何单调函数 g(m) 满足 g(m_e) < 2 时，g(m_μ) < 2（m_μ > m_e）
   • 要让 g(m_μ) > 2，g 必须在 m_e < m < m_μ 之间穿过 2
   • 这需要特殊的非单调函数形式，缺乏物理动机
```

**定量验证**：

```python

g_μ_geom = 2/(1+α²) = 1.999893503  # μ子（相同！）
g_μ - g_e = 0                       # 无差异

# 但若需要解释 μ 子异常
g_μ_target = 2.00233184             # 实验值
g_e_target = 2.00231930             # 实验值
g_μ - g_e = 0.00001254              # 微小差异
```

**结论**：单一螺旋框架（仅 α 参数）无法产生质量依赖的 g-2 修正。需要新的物理自由度。
