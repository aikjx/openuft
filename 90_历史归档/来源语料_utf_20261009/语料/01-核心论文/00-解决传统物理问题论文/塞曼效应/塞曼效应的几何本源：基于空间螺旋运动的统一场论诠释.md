### A.1 正常塞曼效应的详细推导

考虑原子在外磁场作用下的情况，我们可以使用微扰理论来计算能级分裂。

#### A.1.1 微扰哈密顿量

外磁场对原子的微扰哈密顿量可以表示为：

H' = -**μ**·**B** = (e/(2m_e))**L**·**B**

其中，**μ**为原子的轨道磁矩，**L**为轨道角动量，**B**为外磁场，假设外磁场沿z轴方向，即**B** = (0, 0, B)。

因此，微扰哈密顿量可以简化为：

H' = (eB/(2m_e))L_z = ω_L L_z

其中，ω_L = eB/(2m_e)为拉莫尔频率。

#### A.1.2 能级分裂的计算

对于原子的角动量本征态|n, l, m_l⟩，微扰能量为：

ΔE = ⟨n, l, m_l|H'|n, l, m_l⟩ = ω_L m_l ħ = m_l μ_B B

其中，μ_B = eħ/(2m_e)为玻尔磁子，m_l = -l, -l+1, ..., l-1, l为磁量子数。

这一结果表明，原本简并的能级在外磁场作用下分裂为2l+1个能级，相邻能级之间的间隔为μ_B B，这与正常塞曼效应的实验观测一致。

### A.2 反常塞曼效应的详细推导

考虑电子自旋的影响，我们需要同时考虑轨道磁矩和自旋磁矩与外磁场的相互作用。

#### A.2.1 微扰哈密顿量

考虑自旋的情况下，原子的总磁矩为：

**μ** = **μ**_l + **μ**_s = -e/(2m_e)(**L** + 2**S**)

因此，微扰哈密顿量为：

H' = -**μ**·**B** = (e/(2m_e))(**L** + 2**S**)·**B**

假设外磁场沿z轴方向，微扰哈密顿量可以简化为：

H' = (eB/(2m_e))(L_z + 2S_z)

#### A.2.2 自旋-轨道耦合

在弱磁场条件下，我们还需要考虑自旋-轨道耦合的影响。自旋-轨道耦合的哈密顿量为：

H_{so} = ξ(r)L·S

其中，ξ(r)为自旋-轨道耦合常数。

#### A.2.3 能级分裂的计算

在弱磁场条件下，我们需要使用总角动量**J** = **L** + **S**作为守恒量。此时，微扰哈密顿量可以表示为：

H' = (eB/(2m_e))J_z(1 + (J(J+1) + S(S+1) - L(L+1))/(2J(J+1)))

= (eB/(2m_e))g_j J_z

其中，g_j为朗德g因子：

g_j = 1 + (J(J+1) + S(S+1) - L(L+1))/(2J(J+1))

因此，能级分裂为：

ΔE = m_j g_j μ_B B

其中，m_j = -j, -j+1, ..., j-1, j为总角动量磁量子数。

这一结果表明，原本简并的能级在外磁场作用下分裂为2j+1个能级，分裂的大小和方式与朗德g因子相关，这与反常塞曼效应的实验观测一致。

在强磁场条件下，外磁场的作用远大于自旋-轨道耦合，此时我们可以忽略自旋-轨道耦合，直接计算轨道磁矩和自旋磁矩与外磁场的相互作用。

#### A.3.1 微扰哈密顿量

在强磁场条件下，微扰哈密顿量为：

H' = (eB/(2m_e))(L_z + 2S_z)

#### A.3.2 能级分裂的计算

在强磁场条件下，轨道角动量和自旋角动量分别与外磁场相互作用，因此我们使用|n, l, m_l, m_s⟩作为基矢。微扰能量为：

ΔE = ⟨n, l, m_l, m_s|H'|n, l, m_l, m_s⟩ = (eB/(2m_e))(m_l + 2m_s)ħ = (m_l + 2m_s)μ_B B
