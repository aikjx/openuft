# ROOT V123 — 螺旋几何、协变场论与可证伪性审查

本项目是研究原型，不是四力统一的证明。采用自然单位 c=1 讨论理论；工程数值采用 SI 单位。G 与 ℏ 保留为独立常数。

## 运行

```bash
python src/calculate.py
python -m unittest discover -s tests -v
```

## 目录
- docs/theory.md：协变作用量、变分方程及物理限制
- docs/roadmap.md：从 ROOT 到可证伪理论的条件
- docs/engineering.md：人工引力工程边界
- src/calculate.py：数值计算
- tests/test_models.py：五项单元测试
- data/results.json：计算结果
- data/test_log.txt：测试记录

结论：已有可求解的螺旋运动学和圆周谱模型；尚未从螺旋公设导出独有的四力统一动力学、粒子谱或人工引力放大机制。
