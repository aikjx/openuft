## 三、自由度账：`p_total = p_eq + p_axiom + p_exp`

上一册的 C1 是 `p_total == 0`。把实验事实纳入后若仍沿用这个写法，C1 会变成永假判据——任何物理理论都必须消费实验输入。因此本册把账拆开：

- `p_eq`：仍需外部确定的连续／离散自由度；
- `p_axiom`：为得到唯一解而注入的、可自由选择的额外假设数；
- `p_exp`：**实验给定**的事实条目数，计入账，但**不是可调自由选择**；
- `p_free = p_eq + p_axiom`：**只有这一项**进入 C1。

`p_exp` 不是手填的标签。机核用 LAF（leave-any-fact-out）逐项把某项实验事实置零，检查候选是否还能被重算，数出「使候选不可重算的事实条数」。实测：纯群论的 SU(5) `3/8` 为 `p_exp = 0`；attack28 循环版为 `p_exp = 3`；全表最大 `p_exp = 3`。这是**输入依赖度的符号级可算判决**，不是伪造一条物理公式去重解 RG；扰动方向上的真实数值灵敏度由 attack28 自己的 `alpha_s_sensitivity_spread = 0.003089` 外部读数支撑。

**D 类结构性离散事实的诚实处理**：上一册点名的电荷量子化、三代、`N_c=3`、自旋统计这 4 条，在本仓库**没有实测锚可机读**，只有教科书符号。本册把它们标为 `BOUNDARY`，只作符号输入，不计入 `p_exp`、不产生数值预言、不冒充本册证明。因此本册结论只对「有机器可读实测锚的 M 类事实」全称成立，不宣称用尽了人类知识。

## 四、三重门：把「攻破」写成三个必须同时成立的机读条件

- **C1 自由度门**：`p_free == 0`（无可调参数、无可自由选择的注入假设）。
- **C2 留一法门（LTO，leave-target-out）**：目标观测量不作为输入，且理论值不等于观测值。否则就是回述型伪预言。
- **C3 实验存活门**：卡方／下界／上界判决通过，**且判别力 > 0**（存在使其失败的观测读数），且不是恒等式。

突破 = `C1 ∧ C2 ∧ C3`。三者缺一不可：只有 C1 是「被钉死但什么也没说对」，只有 C2 是「说了个数但可能是抄的」，只有 C3 是「跟实验对上了但可能是调出来的或根本不可证伪」。

判别力不是标签，是机算的：对卡方型枚举 6 个不同观测读数（含 `obs ± σ`、`theory ± 3σ`），要求同时存在判负与判正的读数、且卡方读数不全相同；对边界型给一组不同理论值，要求同时存在被排除与存活。恒等式在这套判据下 6 个读数全绿 ⇒ 判别力 0。

## 五、留一法的两种，不能混

- **LTO（剔除目标观测）**：抓「把观测原样当预测」和「把目标量塞回输入再解出来」的循环版本。这是 C2。
- **LAF（剔除任一实验事实）**：数该候选对实验输入的依赖度，得到 `p_exp`。它**不作为突破的必要条件**——任何物理理论都依赖实验输入，把 LAF 当门会制造永假的判据。

这一区分是本册的方法论增量：上一册把「独立预言」定义为对全部连续输入扰动不变，本册改为**对目标观测量非循环**，同时把「对其他实验事实的依赖」单列记账而不是一棍子打死。

## 六、实验存活层的四种判据

1. **双侧卡方**：`χ² = ((theory − obs)/σ)²`，临界用靶场 `3.84145882069`。观测 `sin²θ_W = 0.23122`，来料表 `σ = 0.00004`。
2. **下界型**：Super-K `τ_p > 2.4e34 yr`。`theory < lower` 判排除；`theory ≥ lower` 只判「尚未排除」。
3. **上界型**：BK18 `r < 0.032`。与上界同侧的理论值无论取多少都判「尚未排除」。
4. **恒等式型**：`α_grav(e) ≡ (m_e/m_P)²`，理论值随观测锚同步变化 ⇒ 卡方恒 0、零判别力，单列 `IDENTITY` 并配 `NOT-ALL-GREEN`。

上界型的零判别力是机算出来的：取 `r = 0, 0.01, 0.03` 三个不同值，全部落在 `r < 0.032` 内，`n_alive = 3`、`n_dead = 0` ⇒ 该实验对这一组候选判别力 0。这正是项目里反复出现的「消元型检验式对被消量零判别力」。

## 八、核心读数之一：仓库里标 PASS 的「真预测」，在实验存活层被反转

`attack28` 原册标了 3 条 PASS，主题是「sin²θ_W 真预测（把输入改为输出）」，其 `sin2thetaW_is_input = false`，输入只有 `alpha_em_MZ` 与 `alpha_s_MZ`。本册先给它应得的判定：**LTO 通过**——它确实不是回述，目标观测没有进入输入集。

然后用它自己引用的观测 `0.23122` 与来料表 `σ = 0.00004` 重判：

- SM 预测 `0.2074476311` ⇒ `χ² = 3.532035E+5`，偏差 `10.28127710%`；
- MSSM 预测 `0.228925595` ⇒ `χ² = 3.290184E+3`，偏差 `0.99230387%`；
- 临界 `3.84145882069`。

两条都超临界数个量级，判 `EXCLUDED`。原册的 PASS 说的是「把循环版伪预测修复成了真预测」，这是**实现层的正确**；本册判的是「这个真预测的数值是否与实验相符」，这是**实验层的判决**。两者不矛盾，但只有后者能推进统一场论。SU(5) 树级 `3/8 = 0.375` 更极端：`χ² = 1.337976E+7`。

## 九、核心读数之二：偏差缩小是买来的

SM 偏差 `10.2813%` → MSSM `0.9923%`，看起来是「超对称修复了大统一」。本册把代价算出来：

- 两条预测的唯一差别是注入超对称假设 ⇒ `p_axiom: 0 → 1`，`p_free: 0 → 1`，**C1 直接挂**；
- 假设带来的数值位移 `|0.228925595 − 0.2074476311| = 2.147796E-2`，与偏差缩小同量级 ⇒ `p_axiom` 不是装饰判据，它真的驱动了读数；
- 即便买了 MSSM，`χ²` 仍是临界的约 856 倍 ⇒ C3 仍挂。

这与上一册的「唯一性由额外公理购得」完全同构，只是从**解集层**搬到了**实验层**：自由参数没有消失，只是从方程转移到假设，而假设买来的接近程度仍不足以通过实验门。

## 十、本册新思路：非输入性—实验存活跷跷板（第二形态）

上一册的跷跷板是「钉死 ↔ 预言」：20 次尝试中 C1 与 C2 从未同时成立。本册把 `p_exp` 纳入后，**C1 与 C2 不再互斥**——有 4 条候选同时满足零可调参数与非回述。于是问题被精确地推到了第三道门：

- 4 条 `C1∧C2` 候选中，K01 / K02 是纯群论或纯 SM 推导的数值陈述 ⇒ 卡方判负；
- K08 是最小 SU(5) 的 `τ_p = 4.58921E+31 yr`，Super-K 下限 `2.4E+34` 高出 `5.229658E+2` 倍 ⇒ 硬排除；
- K07 落在 `r < 0.032` 内，但上界型零判别力 ⇒ 存活不构成证据。

也就是说：**可以生出非输入的数值陈述，但这些陈述逐条走实验存活层后全部判负或不可证伪**。`C12_ONLY = 4`、`C123 = 0`。这不是「还没找到更好的方程」，而是把上一册的结构性缺口从「自由度层」搬到了「实验层」并重新确认了一次。

机核报 `survive_count = 4`、`positive_evidence_count = 0`。四条分别是：

## 十六、下一轮唯一明确的、可机算的出口

三重门把缺口钉在了 C3：**所有非输入、零可调参数的数值陈述，要么与实验冲突，要么所在实验对它们零判别力**。因此下一轮不该再找「更漂亮的方程」或「更多的机制类型」，而应只做一件事：

> 构造或检索一条**带双侧误差棒、且候选理论值落在其可判负区间之外**的新实验读数；然后检验：是否存在一条 `p_free = 0`、LTO 通过、且在该读数下 `χ² < 3.84145882069` 的数值陈述？

在出现这样的读数之前，任何「攻破」宣告都缺少最后一道门的输入。本册不替它预支结论。
