# 03 数学形式：几何基元与不变量

## 1 螺旋参数化

来源以圆柱螺旋为本源几何：

```
r(θ) = ρ cosθ i + ρ sinθ j + bθ k
```

曲率 κ 与挠率 τ（对单位速率参数化）为：

```
κ = ρ / (ρ² + b²)
τ = b / (ρ² + b²)
```

## 2 比值与螺旋升角

```
α = κ / τ = ρ / b = tanθ
```

- 来源称 α 为「纯几何拓扑不变量」。诚实边界（C0004）：α=κ/τ 由螺旋参数定义，不是独立拓扑推导；它随螺旋形状确定，并非来自额外不变性原理。

## 3 归一化恒律（核心恒等式）

由 κ、τ 定义直接代入：

```
κ² + τ² = 1/(ρ² + b²)
```

又因为 ωρ=c（A1），有：

```
ω²/c² = 1/ρ²
```

在来源的「尺度分层」参数化下（κ=ρ/(ρ²+b²) 等），来源给出统一恒律：

```
κ² + τ² = ω² / c²
```

- 本仓库复算（verify_ct_uft.py）残差 < 1e-30，属代数自洽（claims C0003，evidence H）。
- 注意：此式依赖于 A1（ωρ=c）与 A2（κ、τ 的特定分母 (ρ²+b²)）联合，否则不成立。

## 4 尺度变换

```
κ' = κ/k,  τ' = τ/k,  α' = α
```

- 跨尺度分层时拓扑比 α 不变（claim C0005，evidence H）。

## 5 来源使用的辅助量

- 康普顿半径 ρ = ħ/(m c)
- 普朗克长度 l_P = √(ħG/c³)（来源用以锚定普朗克层 κ_P）
- 电子层 κ_e ≈ 1.93e13 m⁻¹（由 ρ_e 推出）；普朗克层 κ_P 在来源不同文件取 10³⁰ 与 10³⁴ 量级两说（C0021）

## 数学边界

上述全部为螺旋几何的代数推论，不引入新物理本体；其作为「统一场工具」的证据等级取决于 A4 能否脱离 CODATA 输入独立给出常数——目前不能（见 C0006 等）。
