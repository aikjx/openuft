# 第12章 求导：全域微分结构

## 12.1 导读

【 **大白话** :前几卷把方程摆出来了，这一卷第一部分（本章）把这些方程"从头到尾求一遍导"——不是套公式，而是把每个导数的物理含义说清楚：导数是"怎么变"，物理是"变的代价"。本章对五板块逐一求导，共五组完整推导，全部可在第14章脚本中复现。】

## 12.2 板块一：旋量对偶方程的微分结构

【 **推导 12.1（流守恒的求导）** :从方程 5.1 出发：

$$\sigma^{\mu}\partial_{\mu}\Psi = \lambda\,\Theta\,\Psi^{*}$$

定义 $J^{\mu} = \Psi^{\dagger}\sigma^{\mu}\Psi$，求全微分：

$$\partial_{\mu}J^{\mu} = \left( \partial_{\mu}\Psi \right)^{\dagger}\sigma^{\mu}\Psi + \Psi^{\dagger}\sigma^{\mu}\left( \partial_{\mu}\Psi \right) = 2\,\mathrm{Re}\left( \Psi^{\dagger}\sigma^{\mu}\partial_{\mu}\Psi \right) = 2\lambda\,\mathrm{Re}\left( \Psi^{\dagger}\Theta\,\Psi^{*} \right)$$

计算配对：$\Psi^{\dagger}\Theta\Psi^{*} = \psi_{0}^{*}\left( -\psi_{1}^{*} \right) + \psi_{1}^{*}\psi_{0}^{*} = 0$，实部为零：

$$\partial_{\mu}J^{\mu} = 0$$

求导结论：连续方程是代数恒等式，与 $\lambda$ 大小无关。】

【 **推导 12.2（对偶协变性求导）** :对 $ \Psi^{c} = \Theta\Psi^{*} $ 再求导，利用 $\Theta$ 实矩阵与 $\Theta^{2} = -I$：

$$\sigma^{\mu}\partial_{\mu}\Psi^{c} = \Theta\left( \sigma^{\mu}\partial_{\mu}\Psi \right)^{*} = \Theta\left( \lambda\Theta\Psi^{*} \right)^{*} = \lambda\Theta\Theta^{*}\Psi = \lambda\Theta^{2}\Psi = -\lambda\Psi$$

两轮共轭得 $-\Psi$——对偶周期 4 的微分证明。】

## 12.3 板块二：拓扑荷的求导

【 **推导 12.3（1D 绕数时间导数）** :$Q_{1D} = \frac{1}{2\pi\mathrm{i}}\oint \frac{\mathrm{d}z}{z}$，求时间导数：

$$\frac{\mathrm{d}Q_{1D}}{\mathrm{d}t} = \frac{1}{2\pi\mathrm{i}}\oint \partial_{t}\left( \frac{1}{z} \right)\mathrm{d}z = \frac{1}{2\pi\mathrm{i}}\oint \frac{-\partial_{t}z}{z^{2}}\mathrm{d}z$$

在旋量干涉路径 $z\left( t \right)$ 穿过 $z = 0$ 的时刻，被积函数发散，$Q_{1D}$ 跳变——数值上 $t \approx 0.2$ 处 $1 \to 0$（第14章实验九）。求导结论：1D 荷的时间导数是"发散的跳变"，不是平滑的流——它不守恒，因为维度错。】

【 **推导 12.4（霍普夫荷的闭形式）** :$Q_{H} = \frac{1}{4\pi^{2}}\int\epsilon^{ijk}a_{i}\partial_{j}a_{k}$，其时间导数在约束下为零：

$$\frac{\mathrm{d}Q_{H}}{\mathrm{d}t} = \frac{1}{4\pi^{2}}\int\epsilon^{ijk}\left( \partial_{t}a_{i}\,\partial_{j}a_{k} + a_{i}\,\partial_{j}\partial_{t}a_{k} \right) = \frac{1}{4\pi^{2}}\int\epsilon^{ijk}\partial_{j}\left( a_{i}\partial_{t}a_{k} \right) = 0$$

分部积分后是全导数，边界为零（无穷远场归一化）。求导结论：**霍普夫荷的时间导数是全导数项，拓扑上自动为零**——这是它与 1D 绕数在微分结构上的根本区别。】

## 12.4 板块三：双向 β 流的求导

【 **推导 12.5（不动点条件）** :$\mu\frac{\mathrm{d}g}{\mathrm{d}\mu} = \beta\left( g \right) = \varepsilon g - c g^{3}$，令导数为零：

$$\frac{\mathrm{d}g}{\mathrm{d}\mu} = 0 \;\Longleftrightarrow\; g\left( \varepsilon - c\,g^{2} \right) = 0 \;\Longleftrightarrow\; g^{*} = \pm\sqrt{\varepsilon/c}$$

求导结论：不动点成对 $\pm g^{*}$，来自奇函数 $\beta$。】

【 **推导 12.6（稳定性）** :在不动点处求 $\beta$ 的导数：$\beta'\left( g^{*} \right) = \varepsilon - 3c\,g^{*2} = \varepsilon - 3\varepsilon = -2\varepsilon < 0$——$g^{*}$ 是红外吸引子，$-g^{*}$ 是紫外吸引子（$\beta'\left( -g^{*} \right) = -2\varepsilon < 0$ 但流向相反）。双向往返由奇对称保证。】

## 12.5 板块四：对偶镜像度规的求导

【 **推导 12.7（曲率闭式）** :对 $g^{\mathrm{eff}}\left( r \right) = 1 - \frac{r_{s}r}{r^{2}+\ell^{2}}$，Ricci 标量：

$$R\left( r \right) = \frac{r_{s}\,\ell^{2}\left( 3r^{2} - \ell^{2} \right)}{\left( r^{2} + \ell^{2} \right)^{3}}$$

求驻点：

$$\partial_{r}R = 0 \;\Rightarrow\; 3r^{4} - 6\ell^{2}r^{2} - \ell^{4} = 0 \;\Rightarrow\; r^{2} = \left( 3 \pm 2\sqrt{2} \right)\ell^{2}$$

代回得：

$$\left| R \right|_{\max} = \frac{\left( 3 + 2\sqrt{2} \right)r_{s}}{4\ell^{3}} = \frac{\left( 3 + 2\sqrt{2} \right)GM}{2\ell^{3}}$$

求导结论：极值位置 $r = \left( \sqrt{2}\pm 1 \right)\ell$，曲率全局有界，$(3+2\sqrt{2})/2 = 2.9142135624$。】

## 12.6 板块五：因果畴通量的求导

【 **推导 12.8（畴守恒）** :对密度 3-形式 $\omega$，莱布尼茨 + 高斯–斯托克斯：

$$\frac{\mathrm{d}}{\mathrm{d}t}\int_{\mathcal{C}}\omega = \int_{\mathcal{C}}\partial_{t}\omega = \int_{\mathcal{C}}\mathrm{d}\left( \mathrm{i}_{v}\omega \right) - \int_{\mathcal{C}}\left( \mathrm{i}_{v}\mathrm{d}\omega \right) = \oint_{\partial\mathcal{C}}\Theta - \int_{\mathcal{C}}\partial_{\mu}J^{\mu}$$

由 $\partial_{\mu}J^{\mu} = 0$，体项消失，得 $\frac{\mathrm{d}}{\mathrm{d}t}\int_{\mathcal{C}}\omega = \oint_{\partial\mathcal{C}}\Theta$。】

【 **推导 12.9（穿壁翻转）** :在零面上 $g^{\mu\nu}\partial_{\mu}f\partial_{\nu}f = 0$，沿零面的对偶翻转 $\Psi \to \Theta\Psi^{*}$ 是保度规变换（酉性），故通量 $\Theta$ 携带的荷在穿过时变号但保模：$Q \to -Q$，$\left| Q \right|$ 不变——总荷守恒的微分保证。】

## 小结

【 **本章要点** :九组求导覆盖五板块：流守恒是代数恒等式；1D 绕数时间导数发散（证伪根源），霍普夫荷时间导数是全导数（拓扑自动为零）；不动点成对且稳定性确定；曲率极值闭式可解析；畴守恒是斯托克斯的直接推论。微分结构全部闭合。】
