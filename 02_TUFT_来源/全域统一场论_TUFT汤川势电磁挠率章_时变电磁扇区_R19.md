## 1. 本册显式固定的约定（F14 的根源，三册（R9/R15/R19）遗留）

| 项 | 规定 |
|---|---|
| 坐标 | x^0 = c t，∂_0 = (1/c)∂_t |
| 度规 | η = diag(+1,−1,−1,−1) |
| 四矢势 | **A^μ = k·τ^EM,μ（全部取上指标，τ^0, τ^i 与 A^μ 同位）**；下指标 τ_μ = η_{μμ}τ^μ（τ_0 = τ^0，τ_i = −τ^i） |
| 场强 | F^{μν} = ∂^μA^ν − ∂^νA^μ = k·η^{μμ}η^{νν}(∂_μτ_ν − ∂_ντ_μ) |
| 场量 | E_i := c·F_{0i}；F^{ij} = −ε^{ijk}B_k ⇒ B_x = −F^{23}, B_y = −F^{31}, B_z = −F^{12} |

由上述约定**直接推导**（不经映射，避开 R15 指出的同义反复）：
$$E_i=-kc\,\partial_i\tau^0-k\,\partial_t\tau^i,\qquad F^{0i}=k\left(\partial_i\tau^0+\tfrac1c\partial_t\tau^i\right)=-\frac{E_i}{c},\qquad B=k\,\nabla\times\boldsymbol{\tau}^\mu$$

### F14（🟡 约定缺陷，R19 认定）
v2.1.1 §2.2 写 $E=-k(c\nabla\tau_t+\partial_t\boldsymbol\tau)$ 与 $F^{0i}=k(\nabla_i\tau_t+\frac1c\partial_t\tau_i)$：
- 若 $\partial_t\boldsymbol\tau$ 与 $\tau_i$ **都读作上指标**（与 A^μ=kτ^μ 同位）⇒ 残差 **0**（公式正确）；
- 若**统一读作下指标** ⇒ 残差 **= ±2k∂_tτ_i ≠ 0**（时变项符号相反）。

⇒ 这不是符号错误，而是**指标约定从未声明**；静态极限两种读法一致，所以 R1–R12 与 v2.1.1 全部漏检（静态仿真正确）。本册把约定固化（上表），并把该检查写入 R19-9 的静态回归。

## 3. 三层结构（本册把"电磁扇区"讲清楚）

| 层 | 内容 | 状态 |
|---|---|---|
| **① 运动学（记账）** | A^μ=kτ^μ ⇒ F=dA；E,B ↔ F^{μν} 双向一致；I1/I2 不变量；boost 变换与标准式一致 | 🔵 闭合（本册，含时变） |
| **② 齐次动力学** | ∂_μF̃^{μν}=0（Bianchi）自动成立 ⇒ ∇·B=0、∂_tB+∇×E=0 **无需任何动力学假设** | 🔵 闭合（代数后果） |
| **③ 非齐次动力学（源）** | ∂_μF^{μν}=J^ν 的 **J^ν 不能来自几何**（自源不守恒 + 失规范不变；Proca 被 μ_EM=0 排除） | 🔴 **判定为不可在几何内完成**（R19-6 FAIL） |

> **方法论要点（值得独立记住）**：①**∂_μF^{μν}=0 不是恒等式**，它是"有源方程的真空形式"；恒等式是对偶张量的散度 ∂_μF̃^{μν}=0。把二者混淆会误以为"无源方程是自动的"。②判定规范场"有没有源"必须同时检查**守恒性**与**规范不变性**（两个独立闸门，本册都用上）。③**B 的构造必须与 E 用同一指标约定**（本册 R19-2 曾因用 τ_i 造 B 导致 Faraday 检验整体反号——错误在检查自身，修正后才通过；这类错误恰是"约定未声明"的现实后果）。
