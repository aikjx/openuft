## 一、结论先行

## 三、三段对数间隔：一道 37.3 dex 的悬崖

按值升序排列后，相邻两项的自然对数差：

| 段 | 间隔（nat） |
|---|---|
| G→EM | 83.946953 |
| EM→W | 0.69061 |
| W→S | 1.249343 |

- 最大段 `G→EM` = `36.457699` dex，是最小段 `EM→W`（`83.946953` nat）的 `121.554863` 倍。
- 尾部两段 `0.69061 → 1.249343`，**上升** `1.809044` 倍 ⇒ 三段间隔**非单调**（先降后升）。
- 幂律 `t^p` 的间隔必为 `|p|·(0.693147, 0.405465, 0.287682)`，与 `p` 的符号无关地**单调**
  （`p>0` 递减、`p<0` 递增）。所以「间隔非单调」对**任意标签指派**都违背这一类种子的必要条件。

这条只覆盖单调族（幂／指数／平移／双曲），是**必要条件**，方向与数值层一致，**不独立计证据**。

## 四、解析层：中值定理给的下界，只覆盖 7/14

若 `|d ln g / dt|` 在 `[1,4]` 上处处 ≤ `L`，则 `ln g` 的总变化 ≤ `3L`；要覆盖跨度 `Δ` 必须 `3L ≥ Δ`：

```
L_MIN = Δ / (t_max − t_min) = 85.886906 / 3 = 28.628969
```

于是任何满足 `max|d ln g/dt| < L_MIN` 的种子**不可能**跨越该谱。机读结果：解析层排除 **`7/14`** 族，
其余 **`7`** 族在解析上可行（够陡）但**数值上失败**（形状不对）。
两层的相容性检查：解析层排除者**全部**也被数值层排除（必要条件不得反向）。

★ 解析层只是**充分条件式的排除**，不能反过来证明「剩下的也不行」；所以结论必须由数值层承重。

## 十一、边界与红线

1. **不是全称定理**：结论限于 14 个写出来的种子族（幂／指数／平移／倒平移／双曲／幂指复合／sigmoid 等）
   与 24 种标签指派；不覆盖隐式、无穷级数、非解析种子，也不覆盖尚未写出的方程族。
2. **1% 是口径约定**：另给两项稳健性——把容差放宽到 100% 相对误差后通过族数仍为 `0`；
   以及拟合器分辨率地板 `0.00001017`（正对照残留），最优残差是它的 `1461607.8` 倍 ⇒ 网格粗糙不足以解释失败。
3. **「A7 未被满足」≠「A7 不可满足」**：本册只证「本册枚举的族都不行」。要把它升级为不可能性，
   必须给出「所有 ≤3 参数解析种子」的完整分类——本轮没有做，也不声称做了。
4. **与第十五轮并列不相加**：第十五轮从**信息量**侧证「不存在 0 bit 程序能与 46 锚相容」，
   本轮从**结构**侧证「不存在 ≤3 参数生成器能给出该谱」。两条是不同对象，不求积、不求和。
5. **红线**：数学自洽 ≠ 实验证实；本册只产可算判决，不产新物理；四力统一未证、独立实验预言 0；
   不宣称攻破统一场论、不宣称攻破力的统一。

5. **网格分辨率未量化**：首版 refine 只 2 轮，无法回答「残差大是不是网格太粗」。修复：refine 提到 8 轮，
   并用正对照残留给出分辨率地板，正文报「残差 / 地板」的倍数。
   **纪律**：任何「全不达标」都必须配一条「地板多高」的读数，否则分不清判据与仪器。
