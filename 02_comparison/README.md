## 合并与淘汰规则

1. 同一现象使用相同数据、单位、边界条件与误差模型比较。
2. 分清用于拟合的数据与用于检验的数据，记录自由参数数目。
3. 遇到冲突保留冲突记录，不能从互不兼容前提拼接方程。
4. 被反例否定的路线保留失败原因、适用范围和历史版本。
5. 综合候选必须给出共同假设、完整推导链、跨领域检验与未解决缺口。
