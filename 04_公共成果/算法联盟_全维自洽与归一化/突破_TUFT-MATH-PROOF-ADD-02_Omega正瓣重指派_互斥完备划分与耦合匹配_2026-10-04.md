## 一、结构层落地（M1–M3）

### 1.1 重指派分区的闭式形式

放弃主册按坐标轴比值（|κ|、|κ±τ| 与 r 之比）划域，改按 **cos(3θ) 的符号瓣**划域。三个正瓣各为 60° 锥，在原坐标 (κ,τ) 下有闭式不等式（r = √(κ²+τ²)）：

| 域 | 闭式条件 | 几何 |
|---|---|---|
| **D_EM** | 2κ ≥ √3·r | 方向 0° 为中心的 60° 锥 |
| **D_Strong** | −κ + √3·τ ≥ √3·r | 方向 120° 为中心的 60° 锥 |
| **D_Weak** | −κ − √3·τ ≥ √3·r | 方向 240° 为中心的 60° 锥 |
| **D_G** | 以上三条件均不成立（补集）⟺ cos(3θ) < 0 | 三个 60° 负瓣之并（不连通） |
| 原点 | κ = τ = 0 | Ω 无定义（单点，零测度，约定排除） |

三正瓣方向两两相距 120° > 60°（半宽之和）⇒ 天然互斥；任意方向与最近锥心角距 ≤ 60° 处恰落入 cos3θ < 0 区域 ⇒ 天然完备。

- Ω(κ,τ) = λ(κ³−3κτ²)/r³ 与 λ·cos(3θ) 逐点一致（最大偏差 ~1e-16，P2）。

**公理核对**：Ω1 光滑 ✔、Ω2 无量纲（仅依赖 θ）✔、**Ω3 严格成立** ✔（主册 N1 消解）、Ω4 连续（cos3θ 全圆连续，法向导数在瓣边界有限跃变）✔、Ω5 单常数 λ ✔。
