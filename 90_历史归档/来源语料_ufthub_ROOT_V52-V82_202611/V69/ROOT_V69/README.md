# ROOT V69｜地球引力、不同星体密度、元素组成与空间运动联合审查

**科学状态：没有发现或证明四力大统一；没有无反向标定地预测 G。**

本研究包基于 NASA/JPL 的天体公共参数、IERS 的地球参考常数及已发表 MICROSCOPE/NIST 实验，对“不同星体密度、元素、旋转、公转和空间运动影响微观物理实验”的假设给出**逐项可复现的计算与限制判断**。

## 零安装运行

1. **阅读研究书籍**：`book/ROOT_V69_星体密度元素运动与空间动力学_研究总集.md`（22 章和 3 个附录）。
2. **操作 3D 交互页面**：打开 `web/index.html`，无需网络和框架。包括天体球形重力、地球椭球 J₂、自转、示例内部密度、组成依赖第五力、空间螺旋。使用 **Canvas2D 三维透视投影**，非 WebGL 天体数字孪生。
3. **全部基础测试**：`python run_all.py`，Python 3.10+，无第三方依赖，当前运行记录存储在 `results/`。
4. **重新生成数值表**：`python experiments/run_analysis.py`，仅 CSV 和 JSON 仅依赖标准库；若有 matplotlib 则生成 PNG 图表。
5. **浏览器控制测试**：需要 Playwright 和 Chromium，执行 `python experiments/browser_smoke.py`。测试环境封锁 `file://` 直连，所以本次自动化通过 `set_content` 加载**实际 HTML 内容**进行；不能声称当前平台已验证了所有本地文件权限或原生 WebGL。
6. **校验**：`python verify_package.py` 核验各源码/成果文件 SHA-256；最终 ZIP 用 zipfile CRC 读取和独立解压复跑。

## 文件索引

- `src/planetary.py`: 常数、NASA 天体参数、牛顿势、J₂、WGS84 参考椭球、地球旋转系、内部分层球、潮汐、弱场框架拖曳、元素 Z/A 代理荷、Yukawa 差分、轨道速度 Verlet、微观钟红移估算、G 的量纲和 GM 不可辨识性。
- `tests/test_planetary.py`: 正常、极限、反例、数值差分与轨道守恒测试。
- `experiments/run_analysis.py`: 一次运行产生天体、纬度、层密度、轨道、元素组成、第五力、场景审计和轨道积分 CSV。
- `web/index.html`: 可离线操作的三维透视实验台，星体选择和参数调节。
- `book/`: 中文正式科研总集。
- `data/`: 10 个天体的 NASA 参数输入、8 类数值结果和 30 场景审计矩阵。
- `sources/`: 可追溯资料清单、使用限制和精度声明。
- `results/`: 测试日志、数值摘要、图片和浏览器烟测。
- `archive/ROOT_V68_前版完整研究.zip`: 前版归档，不能把历史的假设当作正式证明。

## 本轮最重要的校核结论

- **地球环境不是遗漏的统一物理“新力”**：在 MICROSCOPE 约 710 km 高度，地球引力仍约 7.95 m/s²；卫星微重力表示自由落体而非无地球引力。已发表实验处理了轨道和差分加速度。
- **天体 g 不由密度单独决定**：对球对称模型 `g_surface=4πGρbarR/3`；木星平均密度低但半径大，其 g 可以更强。
- **元素可以影响结构但不自动改变 G**：通过状态方程影响 `ρ(r),R,Tμν`；若引入“元素荷”新力，则必须受组成依赖实验约束。
- **运动分层**：明确区分自转离心、Coriolis、公转/轨道速度、潮汐、旋转源框架拖曳与未证实的“绝对空间运动”。
- **仅凭轨道不能独立测 G**：可见的是 `GM`，缩放 `G→kG,M→M/k` 不改变单极轨道。
- **元素第五力只是示范**：`Q=Z/A`、`α`、`λ` 是人为输入，不是已观察到的新相互作用；MICROSCOPE 置信区间不能未经具体模型统计分析直接转换为通用常数上界。

## 不能用于

航天器真实导航、行星内部精密反演、完整 EGM2008/IGRF 磁场、强场 Kerr/宇宙学演化、真实 GR 数值相对论、量子引力计算、四力统一的成功证明。这些都需要额外测量、计算资源和独立模型。
