## 二、错误根源

### 2.1 β 系数低估 4.2 倍

`h1_running` 用 β = 2/(3π) = **0.2122**，这对应 **N_eff=1**（仅一个带电轻子等效）。

正确 1-loop QED β：
```
d(α⁻¹)/dlnQ = -(2/3π) · Σ_f Q_f²

活跃费米子 (M_Z ~ 100 GeV 区间)：
  e, μ, τ : 3 × 1² = 3
  u, c     : 2 × (2/3)² = 8/9
  d, s, b  : 3 × (1/3)² = 3/9
  ΣQ² = 38/9 ≈ 4.222

β_correct = (2/3π) × 4.222 ≈ 0.896
```

β_correct / β_wrong = 0.896 / 0.2122 ≈ **4.22 倍**。

### 2.2 循环匹配

`h1_running` 的目标值 α⁻¹(M_Z)=128.90 是**框架自己跑动到 M_Z 的值**（非实验 127.955），
再用错误 β 反推 Q*=6.3 TeV —— 双重错误（β 错 + 目标值循环）。

---

## 三、正确计算

### 3.1 用实验锚 α⁻¹(M_Z)=127.955 + 正确 β=0.896

```
α⁻¹(M_Z) = α⁻¹(Q*) + β·ln(Q*/M_Z)
127.955  = 128    + 0.896·ln(Q*/91.19)
ln(Q*/M_Z) = (127.955 - 128) / 0.896 = -0.0502
Q* = 91.19 × e^(-0.0502) = 86.7 GeV
```

**正确 Q* ≈ 87 GeV**（在 M_Z 尺度，非 6.3 TeV）。

### 3.2 2-loop 修正

2-loop QED β₂ ≈ 0.849，2-loop 分数修正项 ≈ 0.00053（<0.1%），
**不改变结论**：Q* 仍在 M_Z 附近（87-250 GeV 区间，取决于锚选择）。
