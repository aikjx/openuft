# 02 基础公设（冻结版）

本体系冻结 4 条公设。归属按原文 `article/zh/2026/6/9` 明示前提判断。

## A1 空间内禀光速螺旋公理

空间中每一点都在做圆柱螺旋运动，其环绕速度恒等于真空光速 c：

```
r(θ) = ρ cosθ i + ρ sinθ j + bθ k
ωρ = c
```

- ρ：螺旋半径；b：单位转角轴向间距；ω：角频率。
- 来源把「螺旋运动」视为空间本身的内禀运动，而非质点轨迹。

## A2 曲率-挠率几何公理

空间几何完全由螺旋曲率 κ 与挠率 τ 描述：

```
κ = ρ / (ρ² + b²)
τ = b / (ρ² + b²)
α = κ / τ = ρ / b = tanθ
```

- θ 为螺旋升角；α 被来源称为「纯几何拓扑不变量」（诚实边界见 C0004：α=κ/τ 是螺旋参数定义，不是独立拓扑推导）。
- 注意：S14(TUFT) 以挠率张量多分量内禀代数承载规范群；本体系以标量 κ/τ 比承载常数，二者路线不同。

## A3 尺度变换不变性公理

规律在尺度变换下不变；κ、τ 随尺度缩放而 α=κ/τ 保持不变：

```
κ' = κ / k
τ' = τ / k
α' = α
```

- 由此构造「尺度分层」：纯数学层（无实体）→ 微观量子层 → 宏观经典层 → 宇观层 → 普朗克层。
- 各层 κ 量级由来源给定，但不同文件数值不一致（见 C0021）。

## A4 万物几何化公理

所有物理常数、方程与现象可由 κ、τ、c 几何唯一描述：

```
所有物理常数 = f(κ, τ, c)
```

- 诚实边界：A4 实为「以 CODATA 常数为锚的几何重参数化」。所谓「唯一性」来自把待解释常数预先代入螺旋参数（如 ρ=ħ/(m c)），再用这些参数反推常数本身，属循环（见 C0006/C0008/C0009/C0010）。

- A1–A3 为几何/代数层，自洽。
- A4 的「万物可几何化」是纲领性主张，未给出不从属观测输入的第一性导出；本仓库据实登记为 candidate_theory / unreviewed，不沿用来源「ROOT 最高权限」认证。
