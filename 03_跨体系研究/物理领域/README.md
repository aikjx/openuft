# 50 · 跨物理领域对照（Physics Domains）

把各体系的预测 / 证明对照到具体物理领域，作为「全维度」验证的横向切片。

## 领域子目录（按需创建）

| 领域 | 目录 | 验证要点 |
|---|---|---|
| 引力 | `引力/` | 牛顿极限、黑洞熵、宇宙学常数 |
| 电磁 | `电磁/` | 麦克斯韦、电磁波 E=cB |
| 弱相互作用 | `弱/` | 电弱破缺、M_W / M_Z |
| 强相互作用 | `强/` | α_s 跑动、禁闭 |
| 宇宙学 | `宇宙学/` | 视界截断、暗能量 |
| 粒子谱 | `粒子谱/` | 质量三代机制 |

## 用法

- 每条体系在 `05_verification/` 的对照结果，按领域归入此处做横向比对。
- 领域级证明（如黑洞熵、电子自旋）原属顶层 `20_P`，本次已随结构调整为领域验证素材。
