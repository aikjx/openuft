【CP1】数值方法基础
----------------------------------------------------------------------

  计算物理概述：

  计算物理是用计算机数值方法解决物理问题的学科。
  它是理论物理和实验物理之外的'第三支柱'。

  计算物理的主要方法：
    - 常微分方程数值解（ODE）
    - 偏微分方程数值解（PDE）
    - 分子动力学（MD）
    - 蒙特卡洛方法（MC）
    - 有限元方法（FEM）
    - 格点规范理论（格点QCD）
    - 密度泛函理论（DFT）
    - 重整化群数值方法

  常微分方程数值解：

  物理中的运动方程通常是常微分方程：
    dx/dt = f(x, t), x(t₀) = x₀

  常见数值方法：

  方法                   阶数       稳定性                  应用
  ----------------------------------------------------------------------
  欧拉法                  1阶       条件稳定                 简单问题, 教学演示
  中点法                  2阶       条件稳定                 中等精度问题
  龙格-库塔法(RK4)          4阶       条件稳定                 通用高精度问题
  Verlet法              2阶       辛积分, 长期稳定            分子动力学, 天体力学
  速度Verlet法            2阶       辛积分, 长期稳定            分子动力学标准方法
  蛙跳法                  2阶       辛积分, 长期稳定            等离子体模拟, PIC方法
  隐式欧拉法                1阶       无条件稳定                刚性问题, 大时间步
  梯形法                  2阶       A稳定                  刚性问题

  辛积分器（Symplectic integrators）：

  辛积分器保持哈密顿系统的辛结构，长期能量守恒性好。
  这对分子动力学和天体力学模拟至关重要。

  速度Verlet算法：
    1. v(t+Δt/2) = v(t) + (Δt/2) a(x(t))
    2. x(t+Δt) = x(t) + Δt v(t+Δt/2)
    3. v(t+Δt) = v(t+Δt/2) + (Δt/2) a(x(t+Δt))

  偏微分方程数值解：

  物理中的场方程通常是偏微分方程：
    - 波动方程：∂²u/∂t² = c² ∇²u
    - 热方程：∂u/∂t = α ∇²u
    - 拉普拉斯方程：∇²u = 0
    - 薛定谔方程：iħ ∂ψ/∂t = Ĥψ

  常见数值方法：
    - 有限差分法（FDM）：将导数用差商近似
    - 有限元方法（FEM）：将区域剖分为单元，用基函数展开
    - 有限体积法（FVM）：基于守恒律的积分形式
    - 谱方法：用全局基函数（傅里叶、切比雪夫）展开
    - 粒子网格法（PIC）：粒子+网格混合方法

  数值稳定性与收敛性：

  CFL条件（Courant-Friedrichs-Lewy）：
    对于波动方程，显式格式要求：c Δt/Δx ≤ 1
    即信息在一个时间步内传播不超过一个网格间距

  冯·诺依曼稳定性分析：
    将解分解为傅里叶模态，分析每个模态的放大因子
    稳定条件：所有模态的放大因子 |G| ≤ 1

  螺旋几何化解释：

  1. 数值方法的螺旋几何化
     - 数值积分 = 螺旋运动的离散化
     - 时间步长 Δt = 螺旋运动的时间离散
     - 空间网格 Δx = 螺旋运动的空间离散
     - CFL条件 = 螺旋信息传播的离散约束

  2. 辛积分器的螺旋几何化
     - 辛结构 = 螺旋相空间的几何结构
     - 辛积分器 = 保持螺旋辛结构的数值方法
     - 能量守恒 = 螺旋哈密顿量的数值守恒
     - 长期稳定性 = 螺旋运动的长期数值稳定性

  3. 螺旋运动的数值模拟
     - 螺旋参数方程的数值积分
     - 螺旋轨迹的RK4/Verlet积分
     - 螺旋场方程的有限差分数值解
     - 螺旋几何化的分子动力学模拟

【CP2】分子动力学
----------------------------------------------------------------------

  分子动力学概述：

  分子动力学（Molecular Dynamics, MD）是模拟粒子系统运动的数值方法。
  它通过数值积分牛顿运动方程，研究系统的热力学和动力学性质。

  MD的基本步骤：
    1. 初始化：设置粒子位置和速度
    2. 计算力：根据粒子位置计算相互作用力
    3. 积分运动方程：更新粒子位置和速度
    4. 重复步骤2-3，模拟系统演化
    5. 统计分析：计算热力学量、关联函数等

  常见相互作用势：

  势函数                  形式                                       应用
  --------------------------------------------------------------------------------
  Lennard-Jones势       V(r)=4ε[(σ/r)^12-(σ/r)^6]                稀有气体, 简单流体
  库仑势                  V(r)=q₁q₂/(4πε₀r)                        带电粒子, 等离子体, 离子晶体
  Morse势               V(r)=D_e[1-e^{-a(r-r_e)}]^2              分子振动, 化学键
  Buckingham势          V(r)=Ae^{-Br}-C/r^6                      分子间相互作用
  EAM势                 嵌入原子法                                    金属, 合金
  REBO势                反应经验键序                                   碳氢化合物, 化学反应
  Tersoff势             三体键序势                                    硅, 碳, 半导体
  Stillinger-Weber势    两体+三体                                    硅, 锗

  Lennard-Jones势详细分析：

  LJ势是最常用的成对相互作用势：
    V(r) = 4ε[(σ/r)^12 - (σ/r)^6]

  参数：
    - ε：势阱深度（能量尺度）
    - σ：粒子直径（长度尺度）
    - r⁻¹²项：短程排斥（泡利不相容）
    - r⁻⁶项：长程吸引（范德华力）

  LJ势计算示例（氩）：
    σ = 3.40 Å
    ε = 119.51 K
    平衡位置 r_min = 2^(1/6)σ = 3.82 Å
    势阱深度 V_min = -ε = -1.0298e-08 MeV = -119.51 K

  系综（Ensembles）：

  MD模拟可以在不同的统计系综下进行：

  系综       名称              守恒量                            实现方法
  ---------------------------------------------------------------------------
  NVE      微正则系综           粒子数N, 体积V, 能量E                 标准Verlet积分
  NVT      正则系综            粒子数N, 体积V, 温度T                 Nosé-Hoover热浴, 速度标度
  NPT      等温等压系综          粒子数N, 压强P, 温度T                 Nosé-Hoover+Parrinello-Rahman
  NPH      等焓系综            粒子数N, 压强P, 焓H                  恒压积分器
  μVT      巨正则系综           化学势μ, 体积V, 温度T                 蒙特卡洛+MD混合

  温度控制方法：

  1. 速度标度法（Velocity rescaling）：
     v_i → v_i √(T_target/T_current)
     简单但不产生正确的正则系综

  2. Berendsen热浴：
     dT/dt = (T_target - T)/τ
     指数弛豫到目标温度

  3. Nosé-Hoover热浴：
     扩展系统，引入热浴变量ξ
     产生正确的正则系综，时间可逆

  螺旋几何化解释：

  1. 分子动力学的螺旋几何化
     - 粒子 = 内部光速螺旋的物质粒子
     - 粒子运动 = 螺旋中心的宏观运动
     - 相互作用 = 螺旋粒子之间的力
     - 运动方程 = 螺旋中心的牛顿方程

  2. 相互作用势的螺旋几何化
     - 排斥势 = 螺旋粒子重叠时的强排斥
     - 吸引势 = 螺旋粒子之间的长程吸引
     - 库仑势 = 螺旋电荷的静电相互作用
     - LJ势 = 螺旋粒子的有效相互作用

  3. 热力学量的螺旋几何化
     - 温度 = 螺旋粒子平均动能的量度
     - 压强 = 螺旋粒子对器壁的碰撞力
     - 内能 = 螺旋粒子动能+势能的总和
     - 熵 = 螺旋系统的微观状态数

【CP3】蒙特卡洛方法
----------------------------------------------------------------------

  蒙特卡洛方法概述：

  蒙特卡洛（Monte Carlo, MC）方法是利用随机抽样进行数值计算的方法。
  它特别适合处理高维积分、统计物理、量子场论等问题。

  MC方法的基本思想：
    - 用随机样本估计期望值
    - ⟨f⟩ ≈ (1/N) Σ f(x_i)
    - 中心极限定理保证收敛性
    - 误差 ~ 1/√N

  常见MC方法：

  方法                   原理                        应用
  ----------------------------------------------------------------------
  简单抽样MC               均匀随机抽样                    简单积分, 教学演示
  重要性抽样MC              按重要性函数抽样                  高维积分, 方差缩减
  Metropolis MC        马尔可夫链, 细致平衡               统计物理, 格点场论
  热浴MC                 条件概率抽样                    自旋系统, 格点QCD
  Wang-Landau MC       态密度抽样                     相变, 自由能计算
  路径积分MC               量子-经典对应                   量子统计, 量子场论
  量子蒙特卡洛(QMC)          变分/扩散蒙特卡洛                 电子结构, 量子多体
  格点QCD MC             规范场抽样                     强相互作用, 强子质量谱

  Metropolis算法详细分析：

  Metropolis算法是统计物理中最常用的MC方法：

  算法步骤：
    1. 从当前状态x出发，提议新状态x'
    2. 计算能量差 ΔE = E(x') - E(x)
    3. 接受概率 P_accept = min(1, e^{-βΔE})
    4. 生成随机数r ~ U(0,1)
    5. 若 r < P_accept，接受新状态 x → x'
    6. 否则拒绝，保持原状态
    7. 重复步骤1-6

  细致平衡条件：
    P(x) W(x→x') = P(x') W(x'→x)
    其中 P(x) ∝ e^{-βE(x)} 是玻尔兹曼分布

  伊辛模型（Ising model）：

  伊辛模型是统计物理中最经典的模型：
    H = -J Σ_{<ij>} s_i s_j - h Σ_i s_i
    其中 s_i = ±1 是自旋，J是交换耦合，h是外场

  伊辛模型的相变：
    - 1维：无相变（绝对零度除外）
    - 2维：Onsager精确解，T_c = 2.269 J/k_B
    - 3维：无精确解，数值结果 T_c ≈ 4.51 J/k_B

  2维伊辛模型临界温度计算：
    交换耦合 J = 1.0
    临界温度 T_c = 2J/ln(1+√2) = 2.2692 J/k_B
    Onsager精确解：T_c = 2.2692 J/k_B

  螺旋几何化解释：

  1. 蒙特卡洛方法的螺旋几何化
     - 随机抽样 = 螺旋系统的随机探索
     - 马尔可夫链 = 螺旋状态的随机游走
     - 细致平衡 = 螺旋系统的稳态条件
     - 玻尔兹曼分布 = 螺旋系统的平衡分布

  2. 伊辛模型的螺旋几何化
     - 自旋 = 螺旋粒子的内禀角动量方向
     - 交换耦合 = 螺旋自旋之间的相互作用
     - 相变 = 螺旋自旋有序-无序转变
     - 临界现象 = 螺旋系统的标度行为

  3. 量子蒙特卡洛的螺旋几何化
     - 路径积分 = 螺旋粒子的量子路径
     - 虚时间 = 螺旋运动的虚时间演化
     - 量子涨落 = 螺旋粒子的量子不确定性
     - 基态 = 螺旋系统的最低能量状态

【CP4】格点QCD
----------------------------------------------------------------------

  格点QCD概述：

  格点QCD（Lattice QCD）是将量子色动力学在离散时空格点上进行数值模拟的方法。
  它是目前研究强相互作用非微扰性质的最可靠方法。

  格点QCD的基本思想：
    - 将连续时空离散为4维欧几里得格点
    - 规范场定义在格点链接（link）上
    - 费米子定义在格点站点（site）上
    - 路径积分数值化，用蒙特卡洛方法抽样

  格点规范理论：

  Wilson规范作用量：
    S_G = (2/g₀²) Σ_{plaquette} Re Tr(1 - U_{μν}(x))
    其中 U_{μν}(x) = U_μ(x) U_ν(x+μ̂) U_μ†(x+ν̂) U_ν†(x) 是 plaquette

  格点间距 a：
    - 连续极限：a → 0
    - 格点 artifacts：O(a) 或 O(a²) 修正
    - 改进作用量：消除 leading artifacts

  格点费米子：

  费米子类型                性质                                  应用
  --------------------------------------------------------------------------------
  Wilson费米子            简单, 有O(a)误差, 加倍问题已解决                早期格点QCD计算
  扭转质量费米子              O(a)改进, 自动O(a)改进                    ETM合作组计算
  staggered费米子         便宜, 有味对称问题, 第四步方法                   MILC, RBC/UKQCD计算
  domain-wall费米子       手征对称性好, 计算昂贵                        RBC, LHPC计算
  overlap费米子           精确手征对称性, 计算最昂贵                      手征物理, 拓扑性质
  Wilson-clover费米子     O(a)改进, 平衡精度和成本                     ALPHA, CLS合作组

  格点QCD的主要计算：

  1. 强子质量谱：
     - 介子质量：π, K, ρ, D, B等
     - 重子质量：N, Δ, Λ, Σ, Ξ, Ω等
     - 与实验值对比，验证QCD

  2. 强子结构：
     - 形状因子：电磁形状因子, 引力形状因子
     - 部分子分布函数（PDF）
     - 胶子分布, 自旋结构

  3. 弱相互作用矩阵元：
     - CKM矩阵元：V_ud, V_us, V_ub, V_cb等
     - K介子衰变, B介子衰变
     - CP破坏参数

  4. 有限温度QCD：
     - 夸克-胶子等离子体（QGP）相变
     - 临界温度 T_c ≈ 155 MeV
     - 状态方程, 输运系数

  格点QCD的计算资源：

  格点QCD是计算密集型科学，需要超级计算机：
    - 日本：KEK（超算），RIKEN
    - 美国：Argonne, Oak Ridge, Brookhaven
    - 欧洲：Jülich, CERN, EPCC
    - 中国：国家超算中心

  典型计算规模：
    - 格点大小：32³×64 到 96³×192
    - 规范场配置：数千到数万个
    - 计算时间：数百万到数千万核小时
    - 存储：TB到PB级

  螺旋几何化解释：

  1. 格点QCD的螺旋几何化
     - 格点 = 螺旋时空的离散化
     - 规范场 = 螺旋规范场的格点表示
     - 费米子 = 螺旋费米子的格点表示
     - 路径积分 = 螺旋场的量子路径积分

  2. 强子的螺旋几何化
     - 强子 = 螺旋夸克和螺旋胶子的束缚态
     - 质子 = 三个螺旋夸克(uud)的束缚态
     - 介子 = 螺旋夸克-反夸克对的束缚态
     - 强子质量 = 螺旋夸克动能+螺旋胶子场能量

  3. 夸克禁闭的螺旋几何化
     - 夸克禁闭 = 螺旋夸克不能单独存在
     - 色通量管 = 螺旋夸克之间的色场管
     - 弦张力 = 螺旋色通量管的能量密度
     - 渐近自由 = 螺旋夸克在短距离自由运动

  高性能计算概述：

  高性能计算（High-Performance Computing, HPC）是使用超级计算机解决复杂计算问题的技术。
  它是计算物理、气候模拟、药物设计、人工智能等领域的核心基础设施。

  HPC的主要技术：
    - 并行计算：任务分解到多个处理器
    - 分布式计算：多台计算机协同工作
    - GPU加速：图形处理器用于通用计算
    - 量子计算：量子比特用于特定问题

  并行计算模型：

  模型              编程模型                 架构                   可扩展性
  ---------------------------------------------------------------------------
  共享内存            OpenMP, Pthreads     多核CPU, SMP           中等(数十核)
  分布式内存           MPI                  集群, MPP              高(数万核)
  混合模型            MPI+OpenMP           多核集群                 很高(数十万核)
  GPU加速           CUDA, OpenCL, HIP    GPU集群                很高(数千GPU)
  异构计算            OpenACC, SYCL        CPU+GPU+FPGA         高

     - GYRO, GENE, XGC1等
     - ITER设计优化
