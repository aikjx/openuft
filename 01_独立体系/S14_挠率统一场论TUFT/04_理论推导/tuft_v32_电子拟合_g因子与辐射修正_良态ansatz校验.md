## 一、推导（自然单位，量纲一致）

源稿可观测量（q0、ω0 为耦合常数，在 μ/Q0 中相消）：

```
Q0 = q0·ω0·N,   N=∫4πr²ψ²dr
μ  = q0·ω0·Iμ,  Iμ=2π∫r³ψ²dr   ⇒   μ/Q0 = Iμ/N = ⟨r⟩/2,   ⟨r⟩=∫r³ρdr/∫r²ρdr
g  = 2M·μ/(Q0·S),  S=ħ/2        ⇒   g = 4M·Iμ/(N·ħ) = 2M·⟨r⟩/ħ
```

取**自然单位**（ħ=1，质量以普朗克质量、长度以普朗克长度 l_P 计），量纲自动一致：

```
g = 2·M_nat·⟨r⟩_nat           （无量纲 ✓）
g=2 ⟺ ⟨r⟩_nat = 1/M_nat = λ_C(自然单位)
```

电子：`M_nat = M_e c²/E_P = 4.185462e-23`（普朗克质量）；`λ_C(nat)=1/M_nat=2.389e22 l_P`；
`g_e=2.0023` 需 `⟨r⟩_nat = g_e/2/M_nat = 2.392e22 l_P`。

> 注意：这里 ⟨r⟩ 是电荷分布加权平均半径，`g=2` 对应 ⟨r⟩=λ_C 是**自然单位**下的严格关系；若误用 SI 的 M、ħ 与物理 ⟨r⟩ 相除会得到量纲不一致的结果（已修正）。

## 二、g 因子数值校验（C0045 收敛解上）

收敛参数：`Kc=Tc=3.16e-8, lK=lT=0.0700, r0=6.999e-3, p=2.909, O0=0.9878, lO=1.185`（r 无量纲，l_P 单位）。

| 电荷密度识别 | ⟨r⟩_nat (l_P) | ⟨r⟩_phys (m) | g_TUFT | 需放大倍率 |
|---|---|---|---|---|
| ρ∝Ω−Ω_DE（真空偏差/物质场） | 3.556 | 5.747e-35 | **2.976e-22** | 6.73e21 |
| ρ∝能量密度 α·K·T·Ω | 2.346e-02 | 3.792e-37 | **1.964e-24** | 1.02e24 |
| g_e 目标 2.0023 所需 | 2.392e22 | 3.866e-13 | 2.0023 | — |

**判定**：两种合理识别下，g_TUFT 都在 1e-24~1e-22，远小于 g_e≈2.0023。根源是当前收敛解的电荷分布半径 `⟨r⟩~O(l_P)`（普朗克尺度），而 g=2 要求 `⟨r⟩=λ_C≈2.4e22 l_P`。二者相差 ~1e22~1e24 倍——**当前 E,N 拟合只钉扎了质量尺度（~l_P），从未约束电荷/磁矩尺度**。

**g 的"2"主项与反常项结构**：若把电荷半径钉扎到 λ_C，则 `g=2M·λ_C/ħ=2.000000`（玻尔磁子基线）；`g-2=0.0023193` 对应 `⟨r⟩=1.00116·λ_C`（比 λ_C 大 0.116%，场延展订正）。**这给出 TUFT 复现 g_e 的精确目标**：电荷分布加权平均半径须为 `1.00116·λ_C = 3.8654e-13 m`。

## 三、辐射修正系数 C

源稿 `C=(1/N)∫4πr⁴ψ²(3V1ψ²−5V2ψ⁴)dr` 定义在**标量孤子 ψ 与势参数 V1,V2** 上；当前物理 ansatz 是 **K/T/Ω 几何场，无 ψ、无 V1/V2** ⇒ C 不能直接计算。须先在 TUFT 中给出"电荷/辐射修正密度 ↔ K/T/Ω"的耦合映射（挂账项），再在良态 ansatz 上重算。**本报告不虚构数值。**

## 四、下一步精算分支（在 C0045 良态 ansatz 上）

- **分支 G1（g 尺度钉扎）**：把电荷分布目标 `⟨r⟩=1.00116·λ_C` 作为新约束加入 χ²（或把 Q0、μ 作为独立目标量），在良态 ansatz 参数空间重跑 SLSQP——这会把 g 维度从"未约束"变成"可拟合"。需先定义电荷密度到 K/T/Ω 的明确映射。
- **分支 G2（C 落地）**：给出辐射修正密度与 K/T/Ω 的耦合后，在良态 ansatz 上重算 C 与强加速粒子辐射偏离 Larmor 的可观测预言。
- **红线**：两者都依赖"电荷/磁矩密度映射"这一理论假设，需先明确、登记后再算；否则任何 g/C 数值都只是该假设的后果，不构成物理真实主张。
