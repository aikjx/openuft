## 三、定理 A · 半单 Cartan 通量的指标恒为零

**命题**：设 G 半单，R 为其任一有限维不可约表示，H 为 Cartan 子代数元素，则 `tr_R(H) = 0`。

**机检**（权重逐分量求和，11 个表示全部为零向量）：

| # | 表示 | 权数 | 权重和 |
|---|---|---|---|
| A01 | SU(2) 基本 dim=2 | 2 | (0, 0) |
| A02 | SU(2) 伴随 dim=3 | 3 | (0, 0) |
| A03 | SU(2) dim=4 | 4 | (0, 0) |
| A04 | SU(3) 基本 3 | 3 | (0, 0, 0) |
| A05 | SU(3) 反基本 3̄ | 3 | (0, 0, 0) |
| A06 | SU(3) 伴随 8 | 8 | (0, 0, 0) |
| A07 | SU(5) 基本 5 | 5 | (0, 0, 0, 0, 0) |
| A08 | SU(5) 反基本 5̄ | 5 | (0, 0, 0, 0, 0) |
| A09 | SU(5) 二阶反对称 10 | 10 | (0, 0, 0, 0, 0) |
| A10 | SU(5) 伴随 24 | 24 | (0, 0, 0, 0, 0) |
| A11 | SU(4) 基本 4（Pati–Salam） | 4 | (0, 0, 0, 0) |

**A12** = 11/11 全过。

**结构性理由**（A13，登记为 INFO）：不可约表示的权集在 Weyl 群下不变，而每条 Weyl 轨道的权和为零（Weyl 反射把 w 送到 −w，轨道成对抵消）。故 `Σ_w w = 0` 对一切半单代数的有限维不可约表示成立，不依赖具体表示。

**⇒ 推论**：任何沿 Cartan 子代数的通量，其指标 `n_R = Σ_w (M·w) = M·Σ_w w = 0`。**非零指标必须由 U(1) 分量提供。**

> **这不是空转**（控制组 CTL7 反证）：把 SU(5) 基本表示的权集删去 1 个权，检测器立刻报非零（权重和 (1,−1/5,−1/5,−1/5,−1/5) 型）。零是真检测的结果，不是构造上写死的。

## 四、定理 B · SM 兼容通量的多重度比恒为 1:2:1:1:1

**命题**：设背景通量保持 `G_SM = SU(3)×SU(2)×U(1)_Y`。则 `n_R ∝ M·tr_R(Y)`，且五个表示的多重度比 **与 M 无关**，恒为

```
|n_Q| : |n_u| : |n_d| : |n_L| : |n_e| = 1 : 2 : 1 : 1 : 1
```

**推导**：SM 的 Cartan 子代数为 `Cartan(SU3)₂ ⊕ Cartan(SU2)₁ ⊕ Y`（rank 4）。前三个分量由定理 A 恒给 `tr_R = 0`；只剩 Y 方向。

**机检**：
- B01 `tr_R(Y) = (1, 2, −1, −1, −1)`（Fraction 精确）
- B02 `Σ_R tr_R(Y) = 0` —— 与 SM 一代规范反常抵消 `ΣY = 0` 一致。**这是未调参即命中的外部正对照**（CTL4）
- B03 比值 `max|tr|/min|tr| = 2` ⇒ 谱型 1:2:1:1:1
- B05 反解 `n_Q = n_u`：线性式系数 `1 − 2 = −1 ≠ 0` ⇒ 唯一解 **M = 0**
- B06 强行取 M=3 ⇒ `(3, 6, −3, −3, −3)`：u_R 拿到 6 份，**不是三代，是「三代 + 额外不完整谱」**
- B07 只看手征扇区 `|n_R| = (3, 6, 3, 3, 3)`，u_R 仍是别人的 2 倍

**⇒ 任何单一 U(1)_Y 通量都不可能给出「等代数三代」。** 这个结论不依赖 M 的大小、不依赖通量的整数量子化、不依赖 Y 的归一化（CTL3：Y→(7/3)Y 后比值不变）。

## 五、定理 C · 换一个 U(1) 也救不了

「那我不用超荷，用别的 U(1)」——这是 r294 档 B 的想法。本卷用**物理的** B−L 电荷做一般线性组合 `q_R = a·Y_R + b·(B−L)_R`，逐项算 `n_R ∝ q_R·dim_R`：

| 表示 | a=1,b=0（纯 Y） | a=0,b=1（纯 B−L） | b=a 时 |
|---|---|---|---|
| Q_L | 1 | 2 | 3a |
| u_R | 2 | 1 | 3a |
| d_R | −1 | 1 | **0** |
| L_L | −1 | −2 | −3a |
| e_R | −1 | −1 | −2a |

- C03 令 `n_Q = n_u`：`(a+2b) − (2a+b)` 的系数为 **(−1, +1)** ⇒ 解为 `b = a`
- C04 代入后 `(3a, 3a, 0, −3a, −2a)`
- C05 `d_R` 分量恒为 0 ⇒ 要求 `n_d = n_Q` 必须 `3a = 0` ⇒ **a = 0 ⇒ b = 0**
- C05b `d_R` 沿纯 Y / 纯 B−L 分别是 **−1 / +1**，只在 `b = a` 方向上相加为 0 —— **消掉 d_R 的代价正是失去 d_R**

**⇒ 定理 C：`aY + b(B−L)` 下「等代数三代」只有平凡解 a = b = 0（零通量 = 无紧致化效应）。**

**一般性**（C06，INFO）：任何保持 G_SM 的 U(1) 必在 `Cartan(SU3) ⊕ Cartan(SU2) ⊕ Y` 内，而前三个分量由定理 A 归零 ⇒ **定理 B 已经是全部情形**，不需要再枚举其它 U(1)。
