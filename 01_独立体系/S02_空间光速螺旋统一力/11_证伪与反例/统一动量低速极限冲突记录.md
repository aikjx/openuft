# 冲突记录：统一动量 P = m(c − v) 的低速极限与静止行为

> 体系：空间光速螺旋统一力（S02） · 假设版本 v6.0-20260906（动力学方程登记）
> 出处：算法联盟全维自洽引擎 M03 组（2026-09-15，mpmath 80 位 + sympy 符号求导）
> 状态：**内部冲突（internal_conflict）**——非实验证伪；本体系公设在常规极限下
> 与已确立的动量/力定义矛盾，且所需的前提**未在任何公设文件中声明**。

## 一、冲突现场

本体系公设：

- **S02-A1**：统一动量 `P = m(c − v)`
- **S02-A2**：统一力 `F = dP/dt`

### 1.1 静止行为异常

标准动量 `P = mv` 在 `v = 0` 时给出 `P = 0`；
本体系给出

```
P(0) = m·c ≠ 0
```

对电子：`P(0) = m_e c = 2.73e-22 kg·m/s`（引擎 `M03-n` 登记）。

**即：静止粒子携带非零动量。**

### 1.2 低速极限符号相反

若 `m` 与 `c` 恒定（公设未作其他声明），则

```
F = dP/dt = d[m(c − v)]/dt = −m·dv/dt = −m a
```

与牛顿第二定律 `F = +m a` **符号相反**。

## 二、根因诊断：未声明的隐藏假设

要让 `F = +ma` 成立，必须额外满足下列之一，但**公设文件均未登记**：

| 可能出路 | 需要的额外假设 | 是否已登记 |
|---|---|---|
| 甲 | `c` 是**矢量内部速度**，其方向/大小随 t 变化，`dc/dt` 提供补偿项 | 否 |
| 乙 | 质量非常数，须引入 `(c − v)·dm/dt` 项 | 否 |
| 丙 | `P = m(c − v)` 只适用于 `v` 接近 `c` 的领域，低速应另行退化 | 否（无适用域声明） |

**即：本体系把动量重定义后，没有交代如何回到已确立的低速极限。**
这是「公设替换」类工作的典型缺口——新定义必须显式给出与旧理论的衔接条件。

## 三、为什么这不是「新物理」而应记为冲突

若主张「静止粒子确有动量 `mc`」，则须给出**可检验后果**（例如静止粒子的惯性、
碰撞实验中的动量守恒形式、与 `E² = p²c² + m²c⁴` 的关系）。
本体系未登记任何此类后果，也未给出失效阈值。

在缺少上述内容时，该式在低速极限与已确立理论**直接矛盾**，按诚实分级应记 L2（结构约束）
并附加冲突标注，**不得计入已验证结论**。

## 五、修正建议

1. 明确 `c` 在 `P = m(c − v)` 中的**数学身份**：标量速率、矢量速度，还是常数符号；
2. 显式写出低速退化条件与 `F = +ma` 的恢复路径；
3. 若保留 `P(0) = mc`，须登记其可检验后果与失效阈值；
4. 补充与相对论能量—动量关系 `E² = p²c² + m²c⁴` 的对照（本体系目前未登记）。

## 六、不受本冲突影响的部分

- 三重奏 `κ²+τ² = (ω/v)²` 作为几何基石（S02-A4）：该式在螺旋参数化下是**导出定理**，
  经符号求导验证为机器零，与本冲突无关；
- 电磁力比 `F_e/F_m = c/v`（S02-A3）：属结构约束，需另立判据评估。

**诚实声明**：本记录为理论内部自洽性审计结论，非实验证伪。
它不否定「以新动量定义重构动力学」这一研究方向，但确证：
**在补齐低速退化条件之前，本体系与已确立的动量/力定义不相容**，
其结论不得用于任何需要低速极限的推导或数值对照。
