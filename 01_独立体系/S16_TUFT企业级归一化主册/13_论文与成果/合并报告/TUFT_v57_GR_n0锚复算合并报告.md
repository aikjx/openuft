## 2. Leaver 求导链

- M=1，s=−2 Teukolsky 径向方程；Δ=r²−2r，K=r²ω，λ=l(l+1)−s(s+1)=4。
- ansatz：R=e^{iωr*}(r−2)^{2−2iω}r^{−2}Σa_n z^n，其中 z=(r−2)/r（视界 ingoing、无穷 outgoing）。
- 代入得三项递推：**α_n a_n + β_n a_{n−1} + γ_n a_{n−2} = 0**，Schwarzschild 闭式：
  - α_n = n² + (4−4iω)n + (3−4iω)
  - β_n = −2n² + (−2+16iω)n + (−3+8iω+32ω²)
  - γ_n = n² + (−2−8iω)n + (−16ω²+8iω)
- 连分数自底向上：r_n = −γ_{n+1}/(β_{n+1}+α_{n+1} r_{n+1})（r_N=0 tail）。
- 谱条件：**C_0(ω) = β_0 + α_0 r_0 = 0**。
