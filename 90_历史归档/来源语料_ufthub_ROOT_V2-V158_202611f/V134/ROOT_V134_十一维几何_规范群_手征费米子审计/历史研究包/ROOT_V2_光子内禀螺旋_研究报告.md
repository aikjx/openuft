# ROOT V2 — 光子以光速传播时是否存在内禀螺旋运动？

版本日期：2026-11-24。全部理论推导严格仅令 **c = 1**；**ħ、h、G 均不设为 1**。数值计算使用SI常数，再明确转换回c=1。报告不宣称ROOT统一场论已获证明。

## 总结

1. 光子是无质量自旋1的量子场激发；自由传播的动量本征态有两种物理螺旋度 σ=±1。内禀螺旋度是量子态的性质，**不是**小球机械自转；不存在已确立的可测“固有旋转半径/内部角速度”。
2. 圆偏振平面波的E方向随时间旋转、随轴向位置形成螺旋分布，但其Poynting能流方向仍是直线。此为麦克斯韦方程直接结果。涡旋结构光则可有螺旋相位和横向能流，仍不能普遍推断单光子具有唯一经典螺旋轨迹。
3. 若将ROOT螺旋设为**真实空间轨迹**且总速度c=1，则非零横向绕圈速度会带来轴向速度<1，且必有非零加速度。无附加相互作用的平直时空自由光子应沿零测地线，因而该模型不能直接取代通常自由传播描述。
4. 需要先给ROOT的新增自由度、协变作用量、应力能量守恒、参数无调节预测、以及与实验不一致时的判伪方案。

## 0. 量纲：仅c=1的换算

在SI有 c_SI=299792458 m/s (精确), h_SI=6.62607015e−34 J·s (精确), ħ_SI=h_SI/(2π), G_SI=6.67430(15)e−11 m³ kg⁻¹ s⁻² (2022 CODATA)。

若把时间坐标统一用“米”， t_L = c_SI t_SI, 则 ω_L = ω_SI/c_SI (m⁻¹)， ħ_L=ħ_SI c_SI (J·m)，保持 E=ħ_L ω_L。动量也以能量单位表达：p_c1=E，而 p_SI=E/c_SI。此处h=2πħ，绝不把h与ħ混同。G必须保留为独立有量纲常数。

## 1. 量子本源及螺旋度

在度规 (+,−,−,−) 和 c=1 下：

\[
 p^\mu p_\mu=E^2-|\mathbf p|^2=0,\qquad E=|\mathbf p|=\hbar\omega=\hbar k.
\]

自由平面模式的群速度：

\[
 v_g=\partial E/\partial |\mathbf p|=1.
\]

螺旋度量子数定义：

\[
 \Lambda=\frac{\mathbf J\cdot\mathbf P}{\hbar|\mathbf P|}=\sigma,\quad\sigma=\pm1.
\]

这没有为Ω_int、R_int、κ_int、τ_int赋值；它们不是标准理论中的光子固有机械参数。单光子并没有通用公认的经典轨迹位置函数，光子局域性问题需谨慎。

## 2. 圆偏振的显式反例：场旋转≠能流绕轴

设 φ=kz−ωt, σ=±1, 在c=1且采用归一电磁场单位：

\[
 \mathbf E=E_0(\cos\phi,\sigma\sin\phi,0),\quad
 \mathbf B=E_0(-\sigma\sin\phi,\cos\phi,0),\quad \omega=k.
\]

直接叉乘得：

\[
 \mathbf S=\mathbf E\times\mathbf B=(0,0,E_0^2),\quad
 u=(|\mathbf E|^2+|\mathbf B|^2)/2=E_0^2,
 \quad \mathbf S/u=\hat z.
\]

E矢量在任一点按ω转动，但**能量沿z传播**，没有因圆偏振而出现的普适横向环绕能流。因此不可以从圆偏振的螺旋形态推出“光子中心沿螺旋移动”。更重要：对**单光子数态**，平均电场 〈1|Ê|1〉=0，经典旋转E矢量是场或相干态图像，**不是**单光子内部存在一根确定的旋转电场箭头。

## 3. 结构光与光学轨道角动量

对于适用的傍轴模式：

\[
 \Psi(r,\varphi,z,t)=U(r,z)e^{i(kz-\omega t+\ell\varphi)},\quad L_z=\ell\hbar,
\]

\[
 S_z=\sigma\hbar,\quad J_z\simeq(\ell+\sigma)\hbar.
\]

\ell=0, ±1, ±2, ...。ℓ对应**光束横向模式**，σ对应**内禀偏振螺旋度**；二者可独立制备。对紧聚焦或非傍轴情况，自旋/轨道分解更微妙。光学涡旋的局部能流可以具有环向分量，但不等于某单光子唯一经典路径。

## 4. ROOT真实空间螺旋模型的数学检查（纯假设）

取 (长度单位的) t：

\[
 \mathbf r(t)=(R\cos\Omega t,R\sin\Omega t,qt),\qquad (R\Omega)^2+q^2=1.
\]

\[
 \kappa=R\Omega^2,\qquad \tau=q\Omega,\qquad \Omega^2=\kappa^2+\tau^2.
\]

\[
 P=2\pi q/\Omega,\quad a=R\Omega^2,\quad t_{\mathrm{flight}}=L/q.
\]

SI实测轴向飞行时间为 t_SI=L/(q c_SI)；与直线传播的时间差：

\[
 \Delta t_{\mathrm{SI}}=\frac{L}{c_{\mathrm{SI}}}\left(\frac{1}{q}-1\right).
\]

代入 R=1 µm、q=0.9（人为设置，非测量）：v_perp=0.43588989；Ω=4.358899e5 m⁻¹；κ=1.9e5 m⁻¹；τ=3.923009e5 m⁻¹；节距P≈12.973 µm。注意普通真空自由光子在平直时空应有 d²r/dt²=0；真实螺旋有加速度 |a|=κ，必须解释动力来源或场结构，不能仅靠几何恒等式将其归为已发现。

## 5. 对Ω_int=ω的必要告诫

ω是电磁场相位角频率。若另行假设Ω_int=ω_L=k，那么R_int=√(1−q²)/k，不能反过来据此宣称光子的真实半径等于1/k。特别当 R_int=1/k 时q=0，意味着轴向不前进。这只排除“经典真实螺旋+该额外参数约束”的组合，并不能排除量子自旋本身。

对 λ=550 nm，k=2π/λ≈1.1424e7 m⁻¹，1/k≈87.54 nm。若人为设 δ=1−q=10⁻⁶，则该额外假设得到R≈0.124 nm；这**不是测量上限**，且无独立证据表明Ω_int=ω。

## 6. 不同介质、停光、引力传播

真空局部自由传播c=1；介质相速度1/n；群速度1/(n+ω dn/dω)。EIT所谓“停光”，是将光的相干信息映射到介质激发，非让无质量自由光子静止。理想波导ω²=k_z²+ω_c²（c=1），轴向群速k_z/ω<1而相速ω/k_z>1，不突破因果。驻波是相向模式叠加，净平均能流可为0，但不说明“光子停止”。

在弯曲时空自由光仍沿零测地线：k^ν∇_ν k^μ=0、k^μk_μ=0，局部光速为1；三维投影可弯。宇宙学中 ν∝1/a(t)，并非局部光速减慢。
