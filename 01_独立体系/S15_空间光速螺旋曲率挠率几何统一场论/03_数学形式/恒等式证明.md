# 03 数学形式：恒等式证明（精算）

本文件对 [几何基元与不变量.md](几何基元与不变量.md) 中的核心恒等式给出代数证明与高精度数值核验。

## 证明 1：曲率-挠率定义

圆柱螺旋 `r(θ)=ρ cosθ i + ρ sinθ j + bθ k`，参数化弧长 s 后单位速率：

```
T = dr/ds,  N = dT/ds / |dT/ds|,  B = T × N
κ = |dT/ds|,  τ = −(dB/ds)·N
```

对圆柱螺旋求得（Frenet 标准结果）：

```
κ = ρ / (ρ² + b²)
τ = b / (ρ² + b²)
```

- 这与来源 A2 一致；属经典微分几何，自洽（claim C0002，evidence H）。

## 证明 2：归一化恒律 κ²+τ²=ω²/c²

由 A2：

```
κ² + τ² = (ρ² + b²) / (ρ² + b²)² = 1 / (ρ² + b²)
```

螺旋绕轴弧长参数化 `r(s)` 的角速率：弧长/圈 = `2π√(ρ²+b²)`，速率 `c` ⇒ 螺旋总角速率

```
ω = c / √(ρ² + b²)
ω² / c² = 1 / (ρ² + b²)
```

故

```
κ² + τ² = 1/(ρ²+b²) = ω² / c²
```

- 此处 ω 是**螺旋总角速率**（沿弧长），不是 `c/ρ`（后者只对应圆周分量）。来源「归一化恒律」采用前者，故对任意 (ρ,b) 严格成立。
- 数值核验（全维精算脚本，50 位）：以电子层 `ρ=ħ/(m_e c)`、`b=ρ/α` 代入，`κ²+τ²` 与 `ω²/c²` 残差 = 0（机器零）。
- 评级：几何恒等式自洽（claim C0003，evidence H）。

## 证明 3：比值 α=κ/τ 的拓扑不变性边界

```
α = κ/τ = (ρ/(ρ²+b²)) / (b/(ρ²+b²)) = ρ/b = tanθ
```

- α 由螺旋参数 (ρ,b) 决定，是螺旋几何的标量不变量。
- 诚实边界（claim C0004，evidence O）：α=κ/τ 是螺旋参数定义，不是来自额外拓扑不变性原理的独立推导；来源称其为「纯几何拓扑不变量」属过度声称。
- 尺度变换 `κ'=κ/k, τ'=τ/k` 下 `α'=α` 成立（claim C0005，evidence H）。

## 证明 4：尺度变换不变性

```
κ' = κ/k,  τ' = τ/k  ⇒  α' = κ'/τ' = α
```

- 代数结果，自洽（claim C0005，evidence H）。
