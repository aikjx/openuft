【NP1】原子核的基本性质与核素图
----------------------------------------------------------------------
  原子核的基本组成：

  原子核由质子(Z)和中子(N)组成
  质量数 A = Z + N
  核素符号: ^A_ZX_N

  原子核的基本性质：

  性质              值                                   备注
  --------------------------------------------------------------------------------
  半径              R = R₀ A^(1/3), R₀ ≈ 1.2 fm         ~10^-15 m，比原子小10^5倍
  体积              V = (4/3)πR³ ∝ A                    每个核子体积近似相同
  密度              ρ ≈ 2.3×10^17 kg/m³                 核物质密度近似常数
  结合能             B = Zm_p + Nm_n - M_nucleus         每核子~8 MeV (中等质量核)
  自旋              整数(偶偶核)或半整数(奇A核)                    核子自旋1/2的耦合
  宇称              ±1                                  强相互作用和电磁作用守恒宇称
  同位旋             I = (N-Z)/2                         质子和中子近似同位旋二重态
  磁矩              μ = g_I μ_N I                       核磁子μ_N = eħ/(2m_p)
  电四极矩            Q                                   非球形核的电荷分布偏离球对称

  核素图（核素的分类）：

  类型                   数量/定义                     备注
  -----------------------------------------------------------------
  稳定核素                 ~252种                     不发生放射性衰变
  天然放射性核素              ~50种                      半衰期>10^8年，存在于自然界
  人工放射性核素              ~3000种                    人工制造，半衰期较短
  理论预言核素               ~7000种                    滴线以内，可能存在但未发现
  同位素                  Z相同，N不同                   化学性质相同，核性质不同
  同中子素                 N相同，Z不同                   中子数相同
  同量异位素                A相同，Z不同                   质量数相同
  同核异能素                Z,N相同，激发态不同               长寿命激发态

  幻数（Magic Numbers）：

  质子数或中子数为幻数时，原子核特别稳定
  幻数: 2, 8, 20, 28, 50, 82, 126 (中子)
  双幻核: ^4He, ^16O, ^40Ca, ^48Ca, ^208Pb

  幻数的起源: 壳模型中的闭壳层结构
  类似于原子中的惰性气体（闭电子壳层）

  核素图的特征：

  1. 稳定线: N/Z ≈ 1 (轻核) → N/Z ≈ 1.5 (重核)
  2. 质子滴线: 质子过多，质子发射
  3. 中子滴线: 中子过多，中子发射
  4. 稳定谷: 稳定核素位于谷中
  5. 幻数岛: 幻数附近核素特别稳定
  6. 超重岛: Z~114, N~184附近可能有稳定超重核

  螺旋几何化解释：

  1. 原子核的螺旋结构
     - 核子 = 螺旋粒子（夸克的束缚态）
     - 原子核 = 螺旋粒子的集合
     - 核力 = 螺旋粒子之间的剩余强相互作用

  2. 幻数的几何化
     - 壳层结构 = 螺旋轨道的量子化
     - 闭壳层 = 螺旋轨道填满
     - 幻数 = 螺旋轨道的简并度

  3. 核密度的几何化
     - 常数密度 = 螺旋粒子的不可压缩性
     - 核物质 = 螺旋粒子的简并态
     - 饱和性 = 螺旋粒子的短程排斥

【NP2】核力与核子-核子相互作用（Yukawa势、介子交换）
----------------------------------------------------------------------
  核力的基本性质：

  性质              值                         备注
  -----------------------------------------------------------------
  短程性             力程~2 fm                   超过3fm可忽略
  强相互作用           ~10^4倍电磁力                 结合能~8MeV/核子
  饱和性             每个核子只与最近邻作用               结合能∝A，不∝A²
  电荷无关性           pp≈pn≈nn (扣除电磁作用)         同位旋不变性
  自旋相关性           自旋三重态>自旋单态                氘核只有三重态
  张量力             非中心力，依赖自旋-轨道夹角            氘核D态成分~4%
  自旋轨道耦合          L·S项                      壳模型的重要相互作用
  排斥芯             r<0.5fm强排斥                核物质不可压缩的起源

  Yukawa势（1935年，汤川秀树）：

  核力由介子交换产生，势的形式：
    V(r) = -g² (e^{-μr}/r)
  其中 μ = m_π c/ħ 是介子的康普顿波数的倒数
  力程 R = 1/μ = ħ/(m_π c)

  π介子质量: m_π = 139.6 MeV/c²
  π介子康普顿波长: λ_π = ħ/(m_π c) = 1.41 fm
  核力力程: R ~ 1.41 fm (与实验一致~1.5-2 fm)

  1949年诺贝尔物理学奖（汤川秀树）

  单玻色子交换势（OBEP）：

  核力由多种介子交换产生：

  介子              质量           作用                             力程
  ---------------------------------------------------------------------------
  π (赝标量)         138 MeV      长程吸引，张量力主要来源                   ~1.4 fm
  ρ (矢量)          770 MeV      短程排斥，自旋轨道耦合                    ~0.25 fm
  ω (矢量)          782 MeV      短程排斥芯                          ~0.25 fm
  σ (标量)          ~500 MeV     中程吸引                           ~0.4 fm
  η (赝标量)         548 MeV      短程作用                           ~0.36 fm
  a₁ (轴矢)         1230 MeV     短程作用                           ~0.16 fm

  现代核力模型：

  模型                   描述                                       状态
  --------------------------------------------------------------------------------
  Reid势 (1968)          phenomenological势，拟合NN散射数据              历史经典
  Paris势 (1973)        色散关系方法，更精确                               历史经典
  Bonn势 (1980s)        单玻色子交换，相对论性                              广泛使用
  Argonne V18 (1995)   高精度phenomenological势，18个算符               标准参考
  CD-Bonn (2001)       电荷相关Bonn势                                高精度
  N3LO (2000s)         手征有效场论，次到次到次领头阶                          现代标准
  N4LO (2010s)         手征有效场论，更高阶                               最新发展

  氘核（唯一的两核子束缚态）：

  性质：
    结合能: B = 2.2246 MeV
    自旋: J = 1 (三重态)
    宇称: +1
    同位旋: I = 0
    磁矩: μ = 0.8574 μ_N
    电四极矩: Q = 0.2860 fm² (非球形!)
    D态概率: ~4% (张量力的证据)
    均方根半径: ~2.1 fm

  氘核没有自旋单态束缚态（单态是虚态）
  这证明了核力的自旋相关性

  螺旋几何化解释：

  1. 核力的螺旋几何化
     - 核子 = 三个夸克的螺旋束缚态
     - 核力 = 螺旋核子之间的剩余强相互作用
     - 介子交换 = 螺旋胶子弦的激发

  2. Yukawa势的几何化
     - 介子 = 螺旋粒子（夸克-反夸克束缚态）
     - 力程 = 介子的康普顿波长 = 螺旋半径
     - 指数衰减 = 螺旋粒子的传播子

  3. 排斥芯的几何化
     - r<0.5fm时，螺旋核子完全重叠
     - 泡利不相容原理导致强排斥
     - 这是螺旋粒子的量子统计效应

【NP3】核结构模型（液滴模型、壳模型、集体模型）
----------------------------------------------------------------------
  液滴模型（Weizsäcker公式，1935年）：

  结合能半经验公式：
    B(A,Z) = a_V A - a_S A^(2/3) - a_C Z²/A^(1/3) - a_A (A-2Z)²/A + δ

  各项的物理意义：

  项            公式                        系数                   物理起源
  --------------------------------------------------------------------------------
  体积能          a_V A                     a_V ≈ 15.8 MeV       核力饱和，每个核子贡献相同
  表面能          -a_S A^(2/3)              a_S ≈ 18.3 MeV       表面核子配位数少，结合能低
  库仑能          -a_C Z²/A^(1/3)           a_C ≈ 0.714 MeV      质子之间的静电排斥
  不对称能         -a_A (A-2Z)²/A            a_A ≈ 23.2 MeV       N≠Z时，费米能升高
  对能           δ                         δ ≈ ±12/A^(1/2) MeV  同类核子配对效应（偶偶核+，奇奇核-，奇A核0）

  液滴模型计算示例：

  核素         A     Z     B计算(MeV)        B实验(MeV)        误差(%)
  ----------------------------------------------------------------------
  ⁴He        4     2     21.29           28.30           24.78%
  ¹⁶O        16    8     121.47          127.62          4.82%
  ⁴⁰Ca       40    20    336.35          342.05          1.67%
  ⁵⁶Fe       56    26    485.76          492.26          1.32%
  ²⁰⁸Pb      208   82    1618.58         1636.45         1.09%
  ²³⁸U       238   92    1798.95         1801.69         0.15%

  ✅ 液滴模型对中等和重核的结合能计算误差<1%
  对轻核（如⁴He）误差较大，因为壳效应显著

  每核子结合能曲线：

  B/A曲线的特征：
    1. 轻核: B/A随A增加而增加（表面能主导）
    2. 中等核: B/A在A~56（铁）达到最大值~8.8 MeV
    3. 重核: B/A随A增加而缓慢下降（库仑能主导）
    4. 峰区: A~50-60，最稳定的核（铁、镍）

  这解释了：
    - 核聚变: 轻核聚变成中等核释放能量
    - 核裂变: 重核裂变成中等核释放能量
    - 铁是最稳定的核（恒星核合成的终点）

  壳模型（Mayer, Jensen, 1949年）：

  基本思想：
    核子在平均场中独立运动（类似原子中的电子）
    强自旋-轨道耦合导致能级分裂
    闭壳层核特别稳定（幻数）

  1963年诺贝尔物理学奖（Mayer, Jensen, Wigner）

  壳模型的能级顺序（从低到高）：

  壳层           容量       累计       幻数

  2p₃/₂        4        32       
  1f₅/₂        6        38

  幻数: 2, 8, 20, 28, 50, 82, 126
  这些核子数的核特别稳定

  集体模型（Bohr, Mottelson, 1950s）：

  基本思想：
    原子核可以发生集体运动（转动、振动）
    远离幻数的核是形变核，有转动谱
    接近幻数的核是球形核，有振动谱

  1975年诺贝尔物理学奖（Bohr, Mottelson, Rainwater）

  转动谱（形变核）：
    E_J = (ħ²/(2I)) J(J+1)
    其中 I 是转动惯量，J是总角动量
    典型: 稀土区核(A~150-180), 锕系核(A~230-250)

  振动谱（球形核）：
    E_N = (N + 3/2) ħω
    其中 N是声子数，ω是振动频率
    典型: 接近幻数的核

  螺旋几何化解释：

  1. 液滴模型的几何化
     - 原子核 = 螺旋核子的液滴
     - 体积能 = 螺旋核子的饱和结合
     - 表面能 = 表面螺旋核子的配位数减少
     - 库仑能 = 螺旋质子的静电排斥

  2. 壳模型的几何化
     - 壳层 = 螺旋核子的量子化轨道
     - 自旋轨道耦合 = 螺旋自旋与轨道的耦合
     - 幻数 = 螺旋轨道的闭壳层

  3. 集体模型的几何化
     - 转动 = 螺旋核的整体旋转
     - 振动 = 螺旋核的形状振荡
     - 形变 = 螺旋核的非球形分布

【NP4】核衰变（α、β、γ衰变）与衰变链
----------------------------------------------------------------------
  放射性衰变的基本规律：

  指数衰变定律: N(t) = N₀ e^{-λt}
  半衰期: T₁/₂ = ln2/λ
  平均寿命: τ = 1/λ = T₁/₂/ln2
  活度: A = λN (单位: Bq = 1次衰变/秒)

  三种主要衰变方式：

  衰变方式            发射物                       变化                   典型核             能量
  ------------------------------------------------------------------------------------------
  α衰变             ⁴He核 (α粒子)                A→A-4, Z→Z-2         重核(Z>82)        4-9 MeV
  β⁻衰变            e⁻ + ν̄_e                 A不变, Z→Z+1           中子过剩核           0-几MeV
  β⁺衰变            e⁺ + ν_e                  A不变, Z→Z-1           质子过剩核           0-几MeV
  电子俘获(EC)        ν_e + X射线                 A不变, Z→Z-1           质子过剩核           —
  γ衰变             光子(γ射线)                   A,Z不变                激发态核            keV-MeV
  自发裂变(SF)        两个裂变碎片+中子                 A→A1+A2              超重核             ~200 MeV
  质子发射            质子                        A→A-1, Z→Z-1         质子滴线附近          ~1-2 MeV
  中子发射            中子                        A→A-1, Z不变           中子滴线附近          ~1 MeV
  簇衰变             ¹⁴C, ²⁴Ne等                A→A-A_cluster        重核              ~30 MeV

  α衰变：

  机制: 量子隧穿（Gamow理论，1928年）
  α粒子在核内形成，通过库仑势垒隧穿逃逸

  Geiger-Nuttall定律:
    log T₁/₂ = a + b / √E_α
  半衰期对α能量非常敏感
  例如: ²³⁸U (Eα=4.27 MeV, T₁/₂=4.5×10^9年)
        ²¹²Po (Eα=8.95 MeV, T₁/₂=0.3 μs)

  β衰变：

  机制: 弱相互作用，费米理论（1934年）
  中子→质子+电子+反中微子 (β⁻)
  质子→中子+正电子+中微子 (β⁺)

  β能谱: 连续谱（0到Q值）
  中微子带走部分能量

  费米黄金规则:
    λ = (G_F² |M_if|² / (2π³ ħ⁷ c³)) ∫ p_e E_e (Q-E_e)² dE_e

  允许跃迁: ΔJ=0,±1, 宇称不变
  禁戒跃迁: ΔJ更大或宇称改变，寿命更长

  γ衰变：

  机制: 电磁相互作用
  激发态核跃迁到低能态，发射光子

  多极性:
    电多极 (Eλ): 电偶极E1, 电四极E2, ...
    磁多极 (Mλ): 磁偶极M1, 磁四极M2, ...

  选择定则:
    ΔJ ≤ λ ≤ J_i+J_f
    宇称变化: Eλ (-1)^λ, Mλ (-1)^(λ+1)

  内转换: 激发能直接传给轨道电子，使其发射
  内转换系数 α = λ_e/λ_γ

  天然放射性衰变链：

  衰变链                母核         半衰期                终点         步骤
  ----------------------------------------------------------------------
  铀系 (4n+2)          ²³⁸U       4.47×10^9年         ²⁰⁶Pb      14步 (8α+6β)
  锕系 (4n+3)          ²³⁵U       7.04×10^8年         ²⁰⁷Pb      11步 (7α+4β)
  钍系 (4n)            ²³²Th      1.40×10^10年        ²⁰⁸Pb      10步 (6α+4β)
  镎系 (4n+1)          ²³⁷Np      2.14×10^6年         ²⁰⁹Bi      11步 (7α+4β)

  注意: 镎系的母核²³⁷Np半衰期较短，在自然界已基本衰变完
  其他三个衰变链在自然界仍然存在（母核半衰期>10^8年）

  螺旋几何化解释：

  1. α衰变的几何化
     - α粒子 = 两个质子+两个中子的螺旋束缚态
     - 库仑势垒 = 螺旋质子的静电排斥
     - 量子隧穿 = 螺旋波函数的势垒穿透

  2. β衰变的几何化
     - 中子→质子 = 螺旋下夸克→上夸克的弱作用转变
     - W玻色子 = 螺旋规范场的激发
     - 中微子 = 螺旋轻子（左手）

  3. γ衰变的几何化
     - 光子 = 螺旋电磁场的激发
     - 多极性 = 螺旋辐射的角分布
     - 内转换 = 螺旋光子与轨道电子的相互作用

【NP5】核反应与裂变（链式反应、反应堆物理）
----------------------------------------------------------------------
  核反应概述：

  核反应: 入射粒子与靶核相互作用，产生新的核和粒子
  一般形式: a + A → B + b  (或 a + A → B + b + c + ...)

  反应Q值: Q = (m_a + m_A - m_B - m_b)c²
  Q>0: 放能反应; Q<0: 吸能反应

  反应截面: σ = 反应率 / (入射流强 × 靶核数密度)
  单位: barn (1 b = 10^-28 m²)

  核反应类型：

  类型              示例                                  说明
  ---------------------------------------------------------------------------
  弹性散射            n + A → n + A                       动能守恒，内部状态不变
  非弹性散射           n + A → n + A*                      靶核被激发，发射γ
  辐射俘获            n + A → (A+1) + γ                   中子被吸收，形成更重的核
  粒子发射            n + A → (A+1)* → B + b              复合核衰变，发射粒子
  裂变              n + ²³⁵U → 两个裂变碎片 + 2-3n            重核分裂成两个中等核
  聚变              D + T → ⁴He + n                     轻核聚合成更重的核
  散裂              p + A → 多个碎片 + 多个粒子                 高能质子打碎靶核
  光核反应            γ + A → B + b                       光子引起的核反应

  核裂变（Nuclear Fission）：

  发现: 1938年，Hahn和Strassmann（化学实验）
  解释: 1939年，Meitner和Frisch（物理理论）
  液滴模型解释: Bohr和Wheeler（1939年）

  裂变过程：
    1. 中子被重核吸收，形成复合核（激发态）
    2. 复合核发生形变（液滴振荡）
    3. 形变超过临界点，核分裂成两个碎片
    4. 碎片处于激发态，发射瞬发中子（~10^-14秒）
    5. 碎片通过β衰变达到稳定（缓发中子，~秒到分）

  裂变能量释放：

  成分                        能量              比例
  -------------------------------------------------------
  裂变碎片动能                    ~167 MeV        ~82%
  瞬发中子动能                    ~5 MeV          ~2%
  瞬发γ射线                     ~7 MeV          ~3%
  β衰变能量                     ~7 MeV          ~3%
  缓发γ射线                     ~6 MeV          ~3%
  中微子能量                     ~10 MeV         ~5% (不可回收)
  总计                        ~202 MeV        100%

  每次裂变释放~200 MeV能量
  1克²³⁵U完全裂变释放~8×10^10 J（~22.8 MWh）
  相当于~2.8吨标准煤的能量

  链式反应：

  每次裂变产生~2.5个中子
  如果至少一个中子引发另一次裂变，链式反应可以持续

  有效增殖系数 k_eff：
    k_eff = (新一代裂变数) / (上一代裂变数)
    k_eff < 1: 次临界，链式反应衰减
    k_eff = 1: 临界，链式反应稳定
    k_eff > 1: 超临界，链式反应增长

  四因子公式: k_eff = η f p ε
    η: 每次吸收产生的裂变中子数
    f: 热中子利用系数
    p: 共振逃逸概率
    ε: 快裂变因子

  螺旋几何化解释：

  1. 核裂变的几何化
     - 重核 = 螺旋核子的大液滴
     - 形变 = 螺旋液滴的形状振荡
     - 裂变 = 螺旋液滴的分裂
     - 中子发射 = 螺旋中子的逃逸

  2. 链式反应的几何化
     - 中子 = 螺旋粒子（无电荷，强穿透）
     - 裂变 = 螺旋中子与螺旋核的相互作用
     - 链式反应 = 螺旋中子的级联放大

  3. 能量释放的几何化
     - 结合能 = 螺旋核子的束缚能
     - 裂变释放能量 = 螺旋液滴分裂后的结合能差
     - 质量亏损 = 螺旋结构的能量释放

----------------------------------------------------------------------
  核聚变概述：

  轻核聚合成更重的核，释放能量
  太阳和恒星的能量来源
  氢弹的能量来源
  未来清洁能源的候选

  主要聚变反应：

  反应                        Q值           截面                        备注
  -------------------------------------------------------------------------------------
  D + T → ⁴He + n           17.6 MeV     最大(100keV时~5b)            最容易实现，主流聚变堆方案
  D + D → T + p             4.0 MeV      较小                        50%概率，产生氚
  D + D → ³He + n           3.3 MeV      较小                        50%概率，产生³He
  D + ³He → ⁴He + p         18.3 MeV     中等                        无中子(先进燃料)

  p + ¹¹B → 3⁴He            8.7 MeV      很小                        无中子(先进燃料，硼聚变)

  聚变的劳森判据（Lawson Criterion）：

  实现聚变能量增益需要满足:
    n τ T > 常数
  其中 n是等离子体密度，τ是约束时间，T是温度

  D-T聚变的劳森判据:
    n τ > 10^20 m⁻³·s (T~10 keV)

  三重积: n T τ > 3×10^21 m⁻³·keV·s

  冷聚变/凝聚态核科学         凝聚态环境中的聚变                 各种实验                      有争议，未被主流接受

  恒星中的核聚变：

  质子-质子链（主序星，M<1.3M_☉）：
    1. p + p → D + e⁺ + ν_e (Q=0.42 MeV)
    2. p + D → ³He + γ (Q=5.5 MeV)
    3. ³He + ³He → ⁴He + 2p (Q=12.9 MeV)
  净反应: 4p → ⁴He + 2e⁺ + 2ν_e + 26.7 MeV

  CNO循环（大质量主序星，M>1.3M_☉）：
    碳氮氧作为催化剂，净反应也是4p→⁴He

    氦燃烧: 3α → ¹²C (Q=7.27 MeV)
    碳燃烧: ¹²C + ¹²C → ²⁰Ne + α, ²³Na + p, ...
    氖燃烧: ²⁰Ne + γ → ¹⁶O + α
    氧燃烧: ¹⁶O + ¹⁶O → ²⁸Si + α, ³¹P + p, ...
    硅燃烧: 逐步光致蜕变和α俘获，最终到铁族元素

  螺旋几何化解释：

     - 量子隧穿 = 螺旋波函数的势垒穿透
     - 聚变 = 螺旋液滴的合并

  2. 恒星核合成的几何化
     - 恒星 = 螺旋等离子体的引力束缚球
     - 核燃烧 = 螺旋核的聚变反应
     - 元素合成 = 螺旋核的逐级聚合
     - 超新星 = 螺旋核的爆炸合成(r过程)

  3. 聚变能的几何化
     - 质量亏损 = 螺旋结构的能量释放
     - 结合能 = 螺旋核子的束缚能
     - 聚变能量 = 螺旋液滴合并后的结合能差

【NP7】元素核合成（BBN、恒星核合成、超新星、r过程）

  宇宙中元素的起源：

  不同元素有不同的核合成机制：

  元素                             机制                        时期                        比例
  ------------------------------------------------------------------------------------------
  H, He, Li                      大爆炸核合成(BBN)               宇宙诞生后~3分钟                 H~75%, He~25%(质量)
  C, N, O, Ne, Mg, ..., Fe       恒星核合成                     恒星演化全过程                   中等质量元素主要来源
  Fe, Co, Ni                     超新星爆炸核合成                  大质量恒星死亡                   铁族元素主要来源
  Sr, Ba, Pb, U, ... (重元素)       r过程(快中子俘获)                超新星/中子星并合                 重元素一半以上
  Sr, Y, Zr (轻s过程元素)             s过程(慢中子俘获)                AGB星                      部分重元素
  Li, Be, B                      宇宙线散裂                     宇宙线与星际介质作用                轻元素补充
  Tc, Pm, ... (放射性元素)            宇宙线散裂/恒星                  持续产生                      痕量

  大爆炸核合成（Big Bang Nucleosynthesis, BBN）：

  时间: 宇宙诞生后~1秒到~20分钟
  温度: ~1 MeV到~0.1 MeV

  主要反应链：
    1. n + p ↔ D + γ (氘合成)
    2. D + p → ³He + γ
    3. D + D → T + p, ³He + n
    4. T + D → ⁴He + n
    5. ³He + D → ⁴He + p
    6. ⁴He + D → ⁶Li + γ (痕量)
    7. ⁴He + T → ⁷Li + γ (痕量)

  最终产物（标准BBN预言）：
    ⁴He: Y_p = 0.247 (质量分数)
    D/H: 2.5×10^-5
    ³He/H: 1.0×10^-5
    ⁷Li/H: 1.6×10^-10

  与观测的一致性：
    ⁴He: 一致 (观测~0.245-0.255)
    D/H: 一致 (观测~2.5×10^-5，来自类星体吸收线)
    ⁷Li: 不一致! (观测~1.6×10^-10的1/3，'锂问题')

  锂问题是BBN的主要未解问题
  可能的解释: 恒星中的锂消耗、新物理、非标准宇宙学等

  恒星核合成：

  不同质量恒星的核合成：

  质量范围            阶段                   产物                                  终点              备注
  ----------------------------------------------------------------------------------------------------
  <0.5 M_☉        主序                   He (慢)                              氦白矮星            寿命>宇宙年龄
  0.5-8 M_☉       主序+红巨星               He, C, N, O, s过程元素                  碳氧白矮星           行星状星云抛射外层
  8-20 M_☉        全阶段+超新星              O, Ne, Mg, Si, S, Ar, Ca, Fe        中子星             核心坍缩超新星
  >20 M_☉         全阶段+超新星              重元素, r过程元素                          黑洞              可能产生伽马射线暴

  超新星核合成：

  核心坍缩超新星（II型超新星）：
    - 大质量恒星(M>8M_☉)核心坍缩
    - 核心密度~10^17 kg/m³，温度~10^11 K
    - 核心坍缩成中子星/黑洞
    - 反弹激波抛射外层
    - 中微子驱动的风（ν-process）
    - 快速中子俘获（r过程）可能发生

  Ia型超新星：
    - 白矮星吸积伴星物质达到钱德拉塞卡极限
    - 热核爆炸，完全炸碎
    - 主要合成铁族元素（Fe, Ni, Co）
    - 宇宙中~1/3的铁来自Ia型超新星

  中子星并合：

  GW170817（2017年）证实中子星并合是r过程的重要场所

  过程：
    1. 双中子星并合，形成黑洞+吸积盘
    2. 相对论喷流产生短γ射线暴
    3. 吸积盘抛射富中子物质
    4. 快速中子俘获(r过程)合成重元素
    5. 放射性衰变加热抛射物，产生千新星

  产物: Au, Pt, U, Th, ... 等重元素
  地球上的黄金可能主要来自中子星并合！

  s过程 vs r过程：

  性质              s过程                                 r过程
  ---------------------------------------------------------------------------
  中子通量            低(~10^8 n/cm³)                      极高(~10^22 n/cm³)
  俘获时间            慢(>β衰变时间)                           快(<β衰变时间)
  路径              稳定谷附近                               富中子侧
  场所              AGB星(低质量恒星演化后期)                     超新星/中子星并合
  产物              Sr, Ba, Pb (部分)                     Eu, Au, Pt, U, Th (大部分重元素)
  时间尺度            ~10^4年                              ~1秒

  宇宙元素丰度分布：

  特征：
    1. H和He占主导(~98%质量)
    2. Li, Be, B很少(间隙)
    3. C, N, O, Ne, Mg, Si, S, Ar, Ca, Fe较多(铁峰)
    4. 铁族元素有峰值(Fe最稳定)
    5. 比铁重的元素丰度迅速下降
    6. 重元素有s过程和r过程的双峰结构

  螺旋几何化解释：

  1. 核合成的几何化
     - 元素 = 螺旋核子的不同束缚态
     - 聚变 = 螺旋核的聚合
     - 中子俘获 = 螺旋中子被螺旋核俘获
     - β衰变 = 螺旋下夸克→上夸克的弱作用转变

  2. 元素丰度的几何化
     - 铁峰 = 螺旋核最稳定的构型(每核子结合能最大)
     - 重元素丰度下降 = 螺旋核的不稳定性增加
     - s/r过程双峰 = 螺旋中子俘获的两种时间尺度

  3. 宇宙演化的几何化
     - BBN = 宇宙早期螺旋等离子体的核合成
     - 恒星核合成 = 螺旋恒星内部的核合成
     - 超新星 = 螺旋恒星的爆炸核合成
     - 中子星并合 = 螺旋中子星的并合核合成

  超新星爆发（Supernova）：

  类型：
    II型: 核心坍缩，有氢线（大质量恒星）
    Ib/Ic型: 核心坍缩，无氢线（沃尔夫-拉叶星）
    Ia型: 热核爆炸，无氢线（白矮星）

  核心坍缩超新星机制：
    1. 大质量恒星(M>8M_☉)演化到铁核阶段
    2. 铁核质量超过钱德拉塞卡极限(~1.4M_☉)
    3. 核心坍缩，密度达到核物质密度
    4. 核心反弹，产生激波
    5. 激波最初停滞（中微子损失能量）
    6. 中微子加热重新激活激波（中微子驱动机制）
    7. 激波突破恒星表面，产生超新星爆发
    8. 核心坍缩成中子星或黑洞

  超新星的能量：
    总能量: ~10^46 J (~10^53 erg)
    中微子带走: ~99% (~10^46 J)
    动能: ~1% (~10^44 J)
    电磁辐射: ~0.01% (~10^42 J)

  超新星1987A：
    1987年2月24日，大麦哲伦云，距离~51.4 kpc
