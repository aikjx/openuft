# ROOT V142：局域电磁动力学、偏振及引力审计

## 范围和状态
本轮使用已知的低能非线性电动力学作为 ROOT 候选基准。不是新统一理论的证明。理论仅置 c=1；保留 ħ 和 G 的独立量纲。采用度规 (-+++)，电磁场有理化归一化，X=E²−B²=−F²/2，Y=E·B（对偶符号约定相应选择）。SI 数据仅作单位恢复，不是实验数据。

## 1. 自由真空二次作用量
在平直、平移和洛伦兹不变的真空、单个实 U(1) 规范场、局域导数展开下，二次作用量（忽略边界与常系数的对偶全导数项）可写成 −F f(ℓ²□)F/4，f(0)=1。横向传播分支 k²f(−ℓ²k²)=0。无质量根保持 ω=|k|。其他根必须分析；例如截断传播子 1/[s(1+s/M²)] = 1/s−1/(s+M²)，若将截断式视为精确传播子则两极点残数相反。不能把 EFT 截断在适用域外的根视为真实粒子。此结论不涵盖所有非局域理论、额外场或破缺背景。

## 2. 候选作用量及量纲
S=∫√−g [R/(16πG)+L] d⁴x，L=X/2+aX²+bY²+dXY。 [S]=[ħ]=ML，[L]=M/L³，[a]=[b]=[d]=L³/M，[G]=L/M，[R]=L⁻²。a,b,d 未由 ROOT 确定。D=∂L/∂E=(1+4aX+2dY)E+(2bY+dX)B，H=−∂L/∂B=(1+4aX+2dY)B−(2bY+dX)E。无源 Maxwell 形式 ∇·D=0, ∇×H=∂tD, ∇·B=0, ∇×E=−∂tB。含物质源需计入物质应力张量。此处忽略曲率-电磁额外高阶算符。

## 3. 从二次扰动求传播矩阵
固定局部磁场 B0 沿 z，传播 k 沿 x。探测场 e, b_probe。C=1−4a B0²。展开到二阶：L2=C(e²−b_probe²)/2+4aB0² b_probe,z²+bB0² e_z²−dB0²(e·b_probe+2b_probe,z e_z)。平面波 e=ω(A_y,A_z) 横向分量，b_probe,y=−k A_z, b_probe,z=k A_y，故 e·b_probe=0；该常系数对偶项也不影响局部传播。二次型 Hessian:
M11=Cω²−(C−8aB0²)k²; M22=(C+2bB0²)ω²−Ck²; M12=M21=−2dB0²ωk. det M=0。
当 d=0，v_perp²=(1−12aB0²)/(1−4aB0²)，v_parallel²=C/(C+2bB0²)。这些是截断作用量在线性扰动下的精确相速度，不是全 QED 强场精确答案。弱场 n_perp−1≈4aB0², n_parallel−1≈bB0²。一般 d 时，n±−1≈(B0²/2)[4a+b±sqrt((4a−b)²+4d²)]，本征轴由实对称矩阵 [[4a,−d],[−d,b]] 的本征向量给出。弱场条件 |a|B0²,|b|B0²,|d|B0²≪1。该背景中领先阶两折射率修正非负的条件为 a≥0,b≥0,4ab≥d²；不是全局因果性或 UV 完备性证明。d=0 时有限小磁场内另要求 C>0,C−8aB0²>0,C+2bB0²>0。真空的群速度和信号前沿速度不能从有限阶低频 EFT 外推至无限频率。

## 4. 可辨识性与实验
Δn/B0²=sqrt((4a−b)²+4d²)。例如以共同系数 a0 为单位，(a,b,d)=(1,7,0)a0 和 (1,4,1.5)a0 给出同一领先阶分裂 3a0，但平均指数不同。平均指数与本征轴角可补充识别。理想同质磁场相位延迟 Δφ=2πLΔn/λ，45° 入射时小椭圆率 ψ≈Δφ/2。QED 弱场系数 SI Ae≈1.32e−24 T⁻²，b=7a, d=0。B=5 T、L=1 m、λ=1064 nm: Δn=9.9e−23, Δφ≈5.8462e−16 rad, ψ≈2.9231e−16 rad。参见 CSV。实验需反复改变 B²、偏振角、波长、光路长度，控制残余气体、镜片双折射、仪器热漂移，设置空白与盲测。既有 QED 基准不是 ROOT 特有预测。静态磁场中的线偏振混合不同于轴子端点旋转及 V141 的闭合方向 Berry 回路；未推出 V141 的联络修正。局部均匀的实对称本征矩阵自身不提供连续的手性 Berry 曲率。

## 5. 引力的迹方程
以 Tμν=−2/√−g δS_m/δg^μν 定义 Hilbert 张量。对度规反变分量的整体缩放，X,Y 同为二次齐次量，T=4(L−X L_X−Y L_Y)=−4(aX²+bY²+dXY)。Einstein 方程 Gμν=8πG Tμν (Λ=0) 的迹给 R=−8πG T=32πG(aX²+bY²+dXY)（仅此场源、无其他物质时）。纯磁背景 X=−B0²,Y=0，R贡献=32πG aB0⁴。SI 为 32πG_SI/c_SI⁴ × Ae B_T⁴/μ0。5 T 给 5.4534e−58 m⁻²，电磁四阶拉氏量密度约 6.5651e−16 J/m³，Maxwell 能量密度约 9.9472e6 J/m³。此为形式上的局部迹贡献，不是装置总曲率或测量值；产生磁场的物质源必须另计。Maxwell 迹为零并不代表无引力，Ricci 张量可非零。理想零不变量平面波 X=Y=0 时四阶迹为零，且其四阶作用量一阶变分为零，不代表全部曲率修正或量子效应消失。完整协变作用量及全部场方程给总应力张量协变守恒。不同 G 仍可有相同固定背景的局域光学系数，故光学测量不能独立预测 G。

## 6. 结论与后续
已建立：指定模型的二次作用量约束、非线性场方程、偏振矩阵、迹方程、精确有理数扫描与高精度 SI 计算。未完成：从空间光速螺旋推出 a,b,d；从局域本征态推出 V141 额外 Berry 联络；产生非阿贝尔规范群、三代手征粒子、量子引力和独立 G。四力统一未证明。V143 建议审查协变曲率耦合 RF²、RμνFμρFνρ、RμνρσFμνFρσ 的独立性、场重定义和可观测量；并与 QED 匹配比较，避免任意系数冒充预测。
