# ROOT V90 — Quantum-gravity distinguishability & phase nulling

This package is a reproducible *research audit*, not a claim of a completed unified theory.

## Scope
- Separate Newtonian entangling phase, post-Newtonian estimates, EFT long-range correction estimates, and classical mediator models.
- Explore three-distance weighted nulling: cancel two chosen nuisance basis shapes and retain a third candidate shape.
- Check identifiability, conditioning, and error amplification.
- Preserve `c=1` only as a convention where stated; SI constants remain explicit in the calculator.

## Run
```bash
python run_all.py
```
The run uses the Python standard library only.

## Caveats
The three-distance method is algebraic. It does not establish experimentally achievable sensitivity or distinguish quantum gravity by itself. Real experiment designs must model geometry, electromagnetic multipoles, source motion, decoherence, control errors, calibration, and covariance.
