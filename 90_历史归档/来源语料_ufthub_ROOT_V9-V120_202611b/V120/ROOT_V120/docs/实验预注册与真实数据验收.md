# ROOT V120｜预注册和数据验收规范（尚未执行真实数据处理）

## 1. 目标假设

H0：常规 GR + 标准地球非球形引力场 + 已知动力学、时钟、潮汐、非保守力及观测误差模型。

H1：在 H0 上叠加一个**固定**的球对称线性 Yukawa 势：`alpha_Y=1/3`, `lambda=124600 m`，地球半径 6371000 m，球内形状因子采用 Fayet 2026 的公开解析近似 `rho'/rho0=5/4-r/R+R/(3r)`，参数化采用 `mu_infty` 以避免重算 G_lab。

这是一个需预注册的候选，不是已经成立的理论。若允许源密度校准或环境屏蔽，应在观测前明确范围并作为**独立理论**另行测试，不能用来抢救固定模型。

## 2. 观测与最小数据清单

需要实际独立的原始/一级数据：

- GOCE：GNSS 轨道解、重力梯度、加速度计校正、姿态、时间标签、卫星仪器标定及相关协方差；不要把发布的地球重力场产品当成未经模型污染的“直接 K 值”。
- GRACE/GRACE-FO：星间测距/测距率、GNSS、非引力加速度、时间与姿态数据、潮汐与背景场；多日与多月测量要考虑共同的地球场产品与地表质量变化。
- 地面/空基钟：观测频率链路、地面势和钟高测定、卫星运动时频与链路模型，校正二阶多普勒及传播延迟。
- 独立位势模型与测高：地球球谐系数，`C20/J2`、地形/密度、潮汐与相应先验协方差。

## 3. 拟合原则

1. 锁定 H1 的 `alpha_Y`, `lambda`, 源形状公式。固定假设不得重新拟合该二者。
2. 允许在两种假设下以**同一规则**剖面化轨道初始条件、μ、潮汐和非保守力 nuisance 参数，记录先验。
3. 使用真实轨道传播，而不是把观测位置直接转换成相互独立的 K_n。
4. 观测空间做残差 `y-F(theta)` 和完整协方差 Σ，建模相邻时间噪声、不同卫星相同地球模型的系统相关性。
5. 预先指定训练窗口、留出轨道与钟验证集，在留出集计算预测误差，不能查看其结果后调模型。
6. 检查模型在改变地球密度参数、球谐截断阶数、潮汐、阻力模型与统计先验时的敏感性。
7. 报告标准引力模型与 H1 的原始/后验残差、统计量、似然差、鲁棒性诊断及可复现实验代码，必要时用 parametric bootstrap 标定比较显著性。

## 4. 噪声与测量尺度

本包 MC 中 \(\sigma=10^{-7}\) 是人为合成的 **K/μ** 噪声，不是来自 GOCE/GRACE 产品的误差协方差。不能用这些合成置信区间推论真实作用程精度。

地球非球形引力、日月潮汐、非保守加速度与时间变质量需要在完整模型中单独处理。用多轨道高度而非单一高度来切断未知 μ 的退化。实验最好覆盖短尺度作用程的多个高度、不同倾角和不同历元。

## 5. 四种可得结论

- 如果真实数据在控制系统误差后与固定 H1 明显不符：**排除固定无屏蔽候选**，不能推断所有 Yukawa 理论都排除。
- 如果 H1 拟合改善但没有独立留出确认：仅记“探索性迹象”。
- 如果跨轨道/钟联合证据通过：还需检验同理论的其他预言与与已知粒子/宇宙学约束，不自动证明四力统一。
- 如果根本拿不到数据或协方差：标注 **OPEN**，不使用“正式验收已完成”的表述。
