# ROOT V70｜建议的可证伪联合实验预登记草案（未执行）

**性质：研究设计，不代表实验完成。**

## 核心假设与零假设

- H0：在控制已知质量/非球形引力、潮汐、旋转、电磁和系统误差之后，不同材料的自由落体加速度差与零相容。
- H1：存在额外场，造成具有材料敏感性 Q_A、来源敏感性 Q_S 和特征尺度 λ 的非零差异。
- H2：若出现信号，是否随观测引力梯度、当地旋转方向或其他客观测量量发生可预言的变化。

预登记完整预测函数与未知参数、先验/拟合区域、试验材料真实核物理敏感系数。不得先看数据再选择 λ、材料与分析窗口。

## 观测量与实验分层

1. 同材 A/A 对照；异材 A/B 主样本；样品交换及反转姿态。
2. 相同地点不同高度，连同地面绝对重力仪和潮汐模型记录。
3. 不同纬度实验，必须统一地球自转、J₂、球面半径和大地高改正。
4. 电荷符号反转、去静电、低磁化率/强磁化率材料对照。
5. 以两个钟跃迁比较，分辨普适引力红移和可能的组成依赖常数变化。
6. 将时间变化信号在太阳日/恒星日、地球公转相位、磁场、温度及装置姿态之间做同步回归。

## 统计模型与秩约束

以 η_i 表示差分自由落体加速度，X_i 表示新理论给定的响应基函数，Z_i 表示已知系统误差响应：

\[\boldsymbol\eta=X\boldsymbol\theta+Z\boldsymbol\gamma+\epsilon,\quad \operatorname{Cov}(\epsilon)=\Sigma.\]

在考虑系统参数之后，有效设计不是裸 X，而是相对于 Z 的加权残差化：

\[X_{\rm effective}=\left[I-Z(Z^T\Sigma^{-1} Z)^{-1}Z^T\Sigma^{-1}\right]X.\]

必须进一步检验 rank(X_effective)，而不是只报告 rank(X)。本版数值计算只对合成 X 本身进行了秩检查，尚未引入真实系统误差矩阵 Z。这意味着跨星体“满秩 3”的发现**仍只是候选设计的必要条件之一**。如果 Z 与 X 有同样的变化规律，真实实验仍会不可辨识。

## 预设排除标准

- 明确置信区间方法和假设检验阈值（例如预设双边 95%），不能事后变更；进行多重检验改正。
- 与 MICROSCOPE 结果兼容是必要非充分条件，须使用真实材料敏感系数，而非本包任意 toy Q。
- 对不可重复的单次剩余项应优先排查电磁、温度、姿态和参考系系统误差。
- 若出现场强、材料、方向、轨道相位之间的稳定多变量可重复信号，先与现有标量-张量/第五力有效理论比较，只有其无法解释并给出新的第一性理论推导后才可讨论统一场论突破。
