# ROOT V89 修复日志

1. 不再把两体 Newton 势导致的纯态纠缠直接等同于引力子观测；增加经典通道与文献争议审计。
2. 明确区分 Newton、1PN 代表性势项、引力低能一圈 EFT 势项；修复不同理论层级混淆。
3. 对 Newton / Coulomb 相同距离核证明雅可比秩退化，要求独立电荷控制。
4. 新增三距离两级零化滤波器，标注几何可辨识、条件数与数值精度。
5. 修复用双精度对约 1e-2 和 1e-64 rad 量做相减产生的数值假信号；新增 90 位十进制独立复核。
6. 修复球体碰撞的物理域检验；任何分支重叠将拒绝计算。
7. 加入经典相关相位 LOCC 对照，避免将所有经典模型一概而论。
8. 提供带明确 SYNTHETIC 标识的合成数据、错误模型审查和机器可读协议。
9. 明确当前科学状态：尚未独立预测 G，尚未实现量子引力和四力完全统一。
