## 一、这本书回答的唯一大问题

**「全部补充完成」在物理上是什么样子？**

不是把字数堆到一亿，而是把每一件可核对的东西放回它的位置：一条主张挂到它的判据、一台仪器、一次退出码、一个判决；一个体系挂到它的类型、状态、证据等级与未解项。本书的全部工作就是**把账做平**：左栏是「说过什么」，右栏是「凭什么算数」。

## 五、诚实边界

1. **本书不裁物理真**：只裁「这条主张在本库的登记状态与证据等级」，不裁「空间光速螺旋是否为自然图景」。
2. **PASS／verified 高不等于主张成立**：列宽合格的 364 条里 verified 166 条，绝大多数住在数学恒等式层；判据层几乎单向转否。
3. **不修被审字节**：发现的列宽异常（113 行）只登记、不修改；`claims.csv` 属各体系原始记录，改写即毁溯源。
4. **未算 ≠ 错**：`unreproduced`、`open`、`unreviewed` 一律标「未判」，不许并入失败率。
5. **字形不替代计算**：本书不做新数值实验，全部数值引用自既有脚本或其 stdout；新算只发生在普查本身。
6. **收录不等于背书**：本书把 P01–P04 的空标签、S 系列的候选身份如实写出，不因收录而升级，也不因未证而除名。
7. **字数不构成知识**：本书不以字数论完成度；完成度以「账是否平」论（见卷首 §三）。

## 七、成书时的自陈

- 本书只新增本目录内文件，不改任何被审字节。
- 普查首跑把 S03（83/89）与 S14（30/140）的宽行列进了 status 分布，读出 `ALG-ROOT 75`、`O 33`、`C 32`、`H 14` 一类非状态值；这正是本书第三章要说的「错位列被当成第二本账」。修法是**只统计列宽合格行**并让「合格 + 异常 = 非空行」闭合，而不是把异常行悄悄平均掉。
- 普查把本书自身排除在被审面之外：否则每加一章，读数就自己移动，账永远平不了。
- 「一亿字」不作为交付目标；理由写在卷首 §三，不重复。
