## 38.1 核力是什么？

### 38.1.1 核力的发现

核力是在研究原子核结构时发现的。1911年，卢瑟福通过α粒子散射实验发现了原子核，提出了原子核式结构模型，认为原子由原子核和核外电子组成，原子核带正电，位于原子中心，核外电子绕核运动。

然而，原子核由质子和中子组成，质子带正电，中子不带电。根据电磁学理论，带正电的质子之间会产生强烈的排斥力，这种排斥力应该会使原子核分裂，但实际上原子核是稳定的。这表明原子核内存在一种比电磁斥力更强的吸引力，这种吸引力就是核力。

核力的发现是物理学的重要里程碑，它解释了原子核的稳定性，为原子核物理学的发展奠定了基础。

### 38.1.2 核力的作用范围

核力是一种短程力，它的作用范围非常小，只在原子核尺度内起作用。实验测量表明，核力的作用范围约为10⁻¹⁵米，这一尺度被称为费米（fm），1fm = 10⁻¹⁵米。

当两个核子（质子或中子）之间的距离小于10⁻¹⁵米时，核力表现为强大的吸引力；当距离大于10⁻¹⁵米时，核力迅速减弱，甚至消失；当距离小于0.8×10⁻¹⁵米时，核力表现为排斥力，这种排斥力阻止了核子相互靠近，维持了原子核的稳定结构。

核力的短程特性是其最显著的特点之一，它决定了核力只在原子核内起作用，而在原子核外几乎没有影响。

### 38.1.3 核力的强度

核力是四种基本力中最强的一种，其强度约为电磁力的100倍，是引力的10³⁸倍。核力的强度可以通过比较核子之间的引力、电磁斥力和核力来理解：

- 两个质子之间的引力：F_g = Gm_p²/r² ≈ 10⁻³⁴ N
- 两个质子之间的电磁斥力：F_e = kq_p²/r² ≈ 10⁻² N
- 两个核子之间的核力：F_n ≈ 10⁰ N

从这些数值可以看出，核力的强度远大于电磁斥力和引力，它能够克服质子之间的电磁斥力，将原子核中的核子结合在一起。

核力的强度是原子核稳定性的关键，它决定了原子核能够存在的最大质量和大小。

## 38.2 核力的特点：短程性、饱和性与电荷无关性

### 38.2.1 短程性：只在原子核尺度起作用

核力的短程性是指它的作用范围非常小，只在原子核尺度（约10⁻¹⁵米）内起作用。这一特点可以通过以下实验事实来验证：

1. **原子核的大小**：原子核的半径约为1.2×10⁻¹⁵A¹/³米，其中A是原子核的质量数。对于重原子核，半径约为10⁻¹⁴米，这与核力的作用范围一致。

2. **核力的强度随距离变化**：实验测量表明，核力的强度随距离的增加而迅速减弱，当距离大于10⁻¹⁵米时，核力几乎为零。

3. **核反应的截面**：核反应的截面与核力的作用范围有关，实验测量的核反应截面与核力的短程特性一致。

核力的短程性是由其本质决定的，根据统一场论，核力是空间高维结构的表现，高维结构的作用范围非常有限，因此核力的作用范围也非常小。

### 38.2.2 饱和性：一个核子只与邻近核子相互作用

核力的饱和性是指一个核子只与周围的几个核子发生相互作用，而不是与原子核内的所有核子发生相互作用。这一特点可以通过以下实验事实来验证：

1. **原子核的结合能**：原子核的结合能与质量数A成正比，而不是与A²成正比。如果一个核子与所有其他核子发生相互作用，结合能应该与A²成正比，这与实验结果不符。

2. **原子核的密度**：所有原子核的密度大致相同，约为2.3×10¹⁷千克/立方米。如果核力没有饱和性，重原子核的密度应该比轻原子核大得多，这与实验结果不符。

核力的饱和性是由其作用机制决定的，根据介子理论，核力是通过交换π介子来传递的，π介子的质量约为140 MeV/c²，根据不确定性原理，核力的作用范围约为ħ/(mc) ≈ 1.4×10⁻¹⁵米，这与核力的短程特性一致。由于π介子的质量较大，它只能在短距离内传递核力，因此一个核子只能与邻近的几个核子发生相互作用。

### 38.2.3 电荷无关性：对质子和中子的作用相同

核力的电荷无关性是指核力对质子和中子的作用相同，只与核子的自旋和相对运动状态有关，而与核子的电荷无关。这一特点可以通过以下实验事实来验证：

1. **镜像核的结合能**：镜像核是指质子数和中子数互换的原子核，例如，₁³H和₂³He是镜像核，它们的结合能非常接近，这表明核力对质子和中子的作用相同。

2. **质子-质子散射和中子-质子散射**：实验测量表明，在相同的能量和散射角度下，质子-质子散射和中子-质子散射的截面非常接近，这表明核力对质子和中子的作用相同。

3. **氘核的结构**：氘核由一个质子和一个中子组成，它的结合能和结构与核力的电荷无关性一致。

核力的电荷无关性是核力的重要特性之一，它表明质子和中子在核力作用下是等价的，这为原子核的壳层模型和集体模型提供了理论基础。

## 38.3 核力的作用范围：原子核尺度

### 38.3.1 核力的作用距离

核力的作用距离约为10⁻¹⁵米，这一距离可以通过以下方法测量：

1. **核子-核子散射实验**：通过测量核子-核子散射的截面，可以确定核力的作用范围。实验结果表明，核力的作用范围约为10⁻¹⁵米。

2. **原子核的半径**：原子核的半径可以通过电子散射实验测量，实验结果表明，原子核的半径约为1.2×10⁻¹⁵A¹/³米，其中A是原子核的质量数。这与核力的作用范围一致。

3. **介子理论**：根据介子理论，核力是通过交换π介子来传递的，π介子的质量约为140 MeV/c²，根据不确定性原理，核力的作用范围约为ħ/(mc) ≈ 1.4×10⁻¹⁵米，这与实验结果一致。

核力的作用距离决定了原子核的大小和结构，它是原子核物理学的重要参数之一。

### 38.3.2 核力的强度变化

核力的强度随距离的变化可以用核力势函数来描述，常用的核力势函数包括：

1. **汤川势**：V(r) = -g²e⁻^(μr)/r
   其中，g是耦合常数，μ = m_πc/ħ是π介子的质量倒数，r是核子之间的距离。汤川势是描述核力的基本势函数，它反映了核力的短程特性。

2. **莫尔斯势**：V(r) = D[e⁻²α(r-r₀) - 2e⁻α(r-r₀)]
   其中，D是势阱深度，α是势阱宽度参数，r₀是平衡距离。莫尔斯势可以描述核力的吸引力和排斥力，它反映了核力在短距离内的排斥特性。

3. ** Woods-Saxon势**：V(r) = -V₀/(1 + e^(r-R)/a)
   其中，V₀是势阱深度，R是核力的作用范围，a是势阱的弥散参数。Woods-Saxon势常用于描述原子核的单粒子势，它反映了核力的短程特性。

这些势函数可以定性地描述核力的强度随距离的变化：在远距离（r > 10⁻¹⁵米），核力迅速减弱；在中等距离（0.8×10⁻¹⁵米 < r < 10⁻¹⁵米），核力表现为强大的吸引力；在近距离（r < 0.8×10⁻¹⁵米），核力表现为排斥力。

### 38.3.3 核力与原子核的稳定性

核力的强度和作用范围决定了原子核的稳定性，它需要克服质子之间的电磁斥力，将原子核中的核子结合在一起。原子核的稳定性可以通过以下几个方面来描述：

1. **结合能**：原子核的结合能是指将原子核分解为单个核子所需的能量，结合能越大，原子核越稳定。

2. **比结合能**：比结合能是指原子核的结合能除以核子数，比结合能越大，原子核越稳定。中等质量原子核（A≈56）的比结合能最大，约为8.8 MeV/核子，这些原子核最稳定。

3. **核素图**：核素图是指原子核的质子数Z和中子数N的关系图，稳定核素位于核素图的稳定线上，偏离稳定线的核素是不稳定的，会通过衰变转化为稳定核素。

4. **衰变方式**：不稳定核素的衰变方式包括α衰变、β衰变、γ衰变等，衰变的类型和半衰期取决于核力和电磁力的竞争。

核力与电磁力的平衡决定了原子核的稳定性，当核力大于电磁斥力时，原子核稳定；当电磁斥力大于核力时，原子核不稳定，会通过衰变释放能量，转化为更稳定的核素。

## 38.4 核力与原子核的稳定性

### 38.4.1 核力与库仑力的平衡

原子核的稳定性取决于核力与库仑力（电磁斥力）的平衡。核力是吸引力，它将核子结合在一起；库仑力是排斥力，它试图将质子分开。当核力的吸引力大于库仑力的排斥力时，原子核稳定；当库仑力的排斥力大于核力的吸引力时，原子核不稳定。

对于轻原子核（A < 20），核子数较少，库仑力的排斥作用较弱，核力的吸引力占主导地位，因此这些原子核比较稳定。

对于重原子核（A > 20），核子数较多，尤其是质子数较多，库仑力的排斥作用增强，核力的吸引力相对减弱，因此这些原子核的稳定性降低，容易发生衰变。

当原子核的质量数A > 209时，库仑力的排斥作用超过核力的吸引力，原子核无法稳定存在，会通过α衰变或自发裂变分解为更稳定的原子核。

### 38.4.2 原子核的结合能

原子核的结合能是指将原子核分解为单个核子所需的能量，它是原子核稳定性的重要标志。结合能的计算公式为：

B = (Zm_p + Nm_n - m_N)c²

其中，Z是质子数，N是中子数，m_p是质子质量，m_n是中子质量，m_N是原子核质量，c是光速。

结合能的大小反映了核力的强度，结合能越大，核力越强，原子核越稳定。比结合能是指结合能除以核子数，即B/A，它反映了每个核子的平均结合能。

实验测量表明，比结合能随质量数A的变化规律如下：

- 对于轻原子核（A < 20），比结合能随A的增加而迅速增加，存在一些峰值，对应于稳定的原子核，如⁴He、¹²C、¹⁶O等。
- 对于中等质量原子核（20 < A < 100），比结合能随A的增加变化不大，约为8 MeV/核子，最大值约为8.8 MeV/核子，对应于⁵⁶Fe原子核。
- 对于重原子核（A > 100），比结合能随A的增加而缓慢下降，这是因为库仑力的排斥作用增强，核力的吸引力相对减弱。

原子核的结合能曲线是核能利用的基础，重核裂变和轻核聚变都可以释放能量，因为它们都向比结合能更高的方向转化。

### 38.4.3 放射性衰变的原因

放射性衰变是指不稳定原子核自发地释放射线，转化为更稳定原子核的过程。放射性衰变的原因是核力与库仑力的不平衡，具体包括以下几种情况：

1. **α衰变**：α衰变是指原子核释放一个α粒子（⁴He原子核），转化为更轻的原子核。α衰变发生在重原子核中，因为重原子核的库仑力排斥作用较强，核力无法完全束缚所有核子，因此会释放α粒子来降低库仑斥力。

2. **β衰变**：β衰变是指原子核中的一个中子转化为一个质子、一个电子和一个反中微子（β⁻衰变），或一个质子转化为一个中子、一个正电子和一个中微子（β⁺衰变）。β衰变发生在中子数与质子数比例不合适的原子核中，通过β衰变可以调整中子数与质子数的比例，使原子核更稳定。

3. **γ衰变**：γ衰变是指原子核从激发态跃迁到基态，释放γ射线（高能光子）。γ衰变通常伴随α衰变或β衰变发生，因为α衰变或β衰变后的原子核往往处于激发态，需要释放γ射线来回到基态。

4. **自发裂变**：自发裂变是指重原子核自发地分裂为两个较轻的原子核，同时释放中子和能量。自发裂变发生在非常重的原子核中，如²³⁸U、²³⁵U等，因为这些原子核的库仑力排斥作用非常强，核力无法完全束缚它们，因此会自发分裂。

放射性衰变的类型和半衰期取决于核力与电磁力的竞争，它们是原子核不稳定性的表现，也是核力特性的重要验证。

## 总结

本章我们探讨了核力的基本特性，主要内容包括：

1. **核力的概念**：核力是原子核内核子之间的强吸引力，它是四种基本力中最强的一种，作用范围非常小，只在原子核尺度内起作用。

2. **核力的特点**：核力具有短程性、饱和性和电荷无关性，短程性是指它只在原子核尺度起作用，饱和性是指一个核子只与邻近核子相互作用，电荷无关性是指它对质子和中子的作用相同。

3. **核力的作用范围**：核力的作用范围约为10⁻¹⁵米，强度随距离的增加而迅速减弱，在近距离表现为排斥力，在中等距离表现为强大的吸引力。

4. **核力与原子核的稳定性**：核力与库仑力的平衡决定了原子核的稳定性，结合能和比结合能是原子核稳定性的重要标志，放射性衰变是原子核不稳定性的表现。

通过对核力基本特性的探讨，我们可以更好地理解原子核的结构和稳定性，以及核力与其他基本力的关系。这是统一场论的核心内容之一，也是原子核物理学的重要基础。
