## 4. 逐条裁定

### A1 · P=m(c-v) 的类型读法两难　【BOUNDARY】

**问**：来料的 P = m(c - v) 到底怎么读？

**机读**：3 种读法：R1 类型错误(不可定义)；R2 可定义但 P 退化为标量；R3 可定义但引 A2/A3

三种读法必居其一，各有硬伤：
  - R1（c 标量、v 矢量）：**标量减矢量**，矢量空间无定义 —— 严格意义上的类型错误；
  - R2（c 标量、v 取速率 |v|）：可定义，但 P 变成**标量**，无法承载「力有方向」这一基本属性；
  - R3（c 为矢量 C，|C| = c，即空间光速螺旋公设）：可定义且是矢量，但引出 A2 / A3 / B1 / B2。
⇒ **没有一种读法是干净的**：R1 无定义、R2 丢方向、R3 与实验极限冲突。本卷后续按 R3 立论（对来料最有利）。

*控制组：标准 p = gamma m v 无此歧义（矢量 - 矢量同型）*

### A2 · 静止极限：静止物体动量非零　【FAIL】

**问**：按 R3 读法，v = 0 时动量是多少？

**机读**：R3 下 P(v=0) = m*|C| = 2.997925e+08 kg*m/s（m=1 kg）；标准（牛顿 p=mv 与相对论 p=gamma m v）在 v=0 均为 0

R3 下 **P(v=0) = m C**，模长 = m*c = **2.997925e+08 kg·m/s**（取 m = 1 kg）。
而动量守恒与惯性系定义的基石是：**静止物体动量为零**（牛顿 p = mv 与相对论 p = gamma·m·v 在 v=0 都给 0）。
⇒ 若静止物体带有 m*c 量级的动量，则「动量」的零点被整体平移，动量守恒定律要改写为守恒 P - mC，而 C 又随空间点运动而变（螺旋）⇒ **连「守恒量是什么」都不再确定**。
这不是小误差，是**零点错误**：量级 m*c 而非 0。

*控制组1：标准相对论动量在 v=0 给 0，判据对其不触发*

### A3 · 光速极限：动量与能量趋于零（光子能量为零）　【FAIL】

**问**：v -> c 时，来料的 P = m(c - v) 给出什么？

**机读**：beta=1-1e-9：D5 |P|=2.730925e-31、E=Pc=8.187106e-23 J；相对论 |p|=6.106533e-18、E=1.830693e-09 J；比值 E_std/E_D5=2.236068e+13。光子极限：D5 给 P=0 ⇒ E=0；标准 p=1.105110e-27、E=2.0678 eV

R3 下 v 沿 C 且 |v| -> c 时，**P = m(C - v) -> 0**，于是按 E = P c 有 **E -> 0**。
机读（电子，beta = 1 - 1e-9）：D5 给 |P| = 2.730925e-31 kg·m/s、E = 8.187106e-23 J；相对论给 |p| = 6.106533e-18 kg·m/s、E = 1.830693e-09 J ⇒ **比值 2.2361e+13 倍**。
极限情形更致命：**光子 v = c ⇒ P = 0 ⇒ E = 0**；而标准光子 p = h*nu/c = 1.105110e-27 kg·m/s、E = h*nu = 2.0678 eV（取 nu = 5e14 Hz 的可见光）。
⇒ 方向**完全相反**：相对论要求 v -> c 时动量**发散**，来料给出**趋于零**；这不是数值偏差，是**单调性反向**。

*控制组1：标准相对论动量在 beta->1 时发散，判据对其不触发*

### B1 · F = dP/dt 相对 F = m a 整体反号　【FAIL】

**问**：把 F = dP/dt 展开，符号与牛顿第二定律一致吗？

**机读**：C 恒定时 F = m(dC/dt - dv/dt) = -m*a ⇒ 与 F=+m*a 反号。弹簧(k/m=1, x0=1, t=10)：标准 x=-0.839072（解析 cos10=-0.839072，数值误差 4.37e-15）；来料 x=11013.2329（解析 cosh10=11013.2329）；比值 1.3125e+04

R3 下 P = m(C - v)，若 C 恒定则 **F = dP/dt = m(0 - a) = -m a**，与牛顿第二定律 F = +m a **处处反号**。
后果不是「差一点」而是**动力学定性改变**：以弹簧（k/m = 1，x₀ = 1，v₀ = 0）积分到 t = 10 ——
  - 标准：x(10) = cos 10 = **-0.839072**（有界振荡，数值积分 -0.839072，误差 4.37e-15）；
  - 来料：x(10) = cosh 10 = **11013.2329**（**指数发散**）。
⇒ 比值 **1.3125e+04 倍**。反号使一切束缚势变成反束缚：行星轨道、弹簧、单摆全部指数飞散。

*控制组2：标准 F=ma 弹簧有界（|x|<=1），判据对其不触发*

### B2 · 若 C 走螺旋，静止物体将受巨大的「几何力」　【FAIL】

**问**：C 不是恒定而是走螺旋（|C| = c、方向变）时，静止物体的受力是多少？

**机读**：电子：lambda_C=3.861593e-13 m，R=lambda_C/2pi=6.145916e-14 m ⇒ |dC/dt|=c^2/R=1.462362e+30 m/s^2；F_geo=m_e*a=1.332121e+00 N；重力 m_e*g=8.933254e-30 N；比值 1.4912e+29

来料把 C 定义为**空间点以光速走螺旋**（S02 公设），则 dC/dt ≠ 0，静止物体（v = 0）也要受
**F_geo = m |dC/dt| = m c² / R**。取电子、并按 S02 取参 R = lambda_C/(2 pi)：
  - lambda_C = 3.861593e-13 m，R = 6.145916e-14 m；
  - |dC/dt| = c²/R = **1.462362e+30 m/s²**；
  - F_geo = m_e * a = **1.332121e+00 N**，而电子重力仅 m_e*g = 8.933254e-30 N ⇒ **比值 1.4912e+29 倍**。
⇒ 一个静止电子要受约 1.332 N 的力（加速度 1.462e+30 m/s²）。这在 Penning 阱、单电子悬浮、以及最普通的「物体放在桌上不动」的事实面前直接否证。
（若把 R 调大以压低 F_geo，则三重奏 kappa²+tau²=(omega/v)² 的 omega 随之改变，又与回旋频率对不上 —— 两头不可兼得。）

*控制组2：标准静止物体（无外场）受力为 0*

### B3 · 退路检查：整体翻号能救 B1 吗？　【BOUNDARY】

**问**：把 P = m(C - v) 改成 P = m(v - C)（整体翻号）能否修复？

**机读**：翻号为 P=m(v-C)：C 恒定时 F=+m*a（符号修好，closes=True）；但取电子时 |P(v=0)|=m_e*c=2.730925e-22 kg*m/s 仍非零（A2 未关闭，closes=False）；光速极限 |P|->0 依旧（A3 未关闭）

翻号后 F = m(a - dC/dt)，C 恒定时确有 **F = +m a**，B1 的符号问题被修好。
**但代价是 A2 / A3 / B2 全部原样保留**：|P(v=0)| = m*c = 2.730925e-22 kg·m/s（取电子）仍非零（A2 未关闭）；v -> c 时 |P| -> 0 依旧（A3 未关闭）；C 走螺旋时静止受力 m*c²/R 不变（B2 未关闭）。
⇒ **符号问题与零点问题是两条独立的病**，翻号只治前者。这是本卷最重要的结构性结论之一：不存在「改一个符号就都好了」的修复。

*控制组：标准 p=mv 翻号为 p=-mv 会破坏动量守恒方向，标准物理不需要翻号*

### C1 · kappa^2+tau^2=(omega/v)^2 在匀速螺旋下成立（但零新增）　【INFO】

**问**：这条恒等式到底对不对？

**机读**：匀速螺旋 R=1,w=1,v_par=1：kappa=0.5000000000, tau=0.5000000000, v=1.4142135624；kappa^2+tau^2=0.500000000000 vs (w/v)^2=0.500000000000；相对误差 1.110e-16；五点扫描最坏 1.110e-16

**对**。机读（R=1, omega=1, v_par=1）：kappa = 0.5000000000、tau = 0.5000000000、v = 1.4142135624，
kappa²+tau² = 0.500000000000，(omega/v)² = 0.500000000000，相对误差 **1.110e-16**；换 5 个时刻扫描最坏 **1.110e-16** ⇒ 机器零。
**但这正是问题所在**：对匀速螺旋，kappa = omega*v_perp/v²、tau = omega*v_par/v² 是Frenet 公式 + 洛伦兹力的**直接推论**，代入即得上式，中间没有任何新物理步骤。
⇒ 按本库纪律（定义式重排不算内容），判 **INFO**：**正确，但新增含量为零**。

*控制组3：恒等式在标准匀速螺旋下残差机器零 ⇒ 本卷的 Frenet 计算工具可信*

### C2 · 恒等式越界：来料标注的「梯度磁场」下不成立　【FAIL】

**问**：来料把适用范围写成「匀速螺旋 / 梯度磁场」，梯度磁场下还成立吗？

**机读**：变速（螺距变化 dv_par/dt=A）残差：A/v_par = ['0.00', '0.01', '0.10', '0.50', '1.00'] ⇒ ['1.110e-16', '2.549e-05', '2.874e-03', '7.170e-02', '2.044e-01']；最坏 2.0444e-01；单调=True。磁镜换算 eps=0.01, v_perp0=0.5 ⇒ dv_par/dt=-1.250e-03/周期；达 1% 残差需 A/v_par=0.1836 ⇒ 约 146.9 个回旋周期

**不成立**。匀速档（A = 0）残差 1.110e-16（机器零）；一旦螺距变化（dv_par/dt = A），残差单调上升：
  A/v_par = ['0.00', '0.01', '0.10', '0.50', '1.00'] ⇒ 残差 ['1.110e-16', '2.549e-05', '2.874e-03', '7.170e-02', '2.044e-01']，最坏 **2.0444e-01**，单调性 成立。
物理对应：梯度磁场下磁镜效应使 v_par 变化 —— 由绝热不变量 mu = m*v_perp²/(2B) 与能量守恒可得
  **dv_par/dt = -v_perp0² * eps / 2 = -1.250e-03**（取 v_perp0 = 0.5、梯度 eps = 0.01/单位长度），
  即螺距**持续**变化 ⇒ 运动**不是**匀速螺旋 ⇒ 恒等式失效。按标定，达到 1% 残差约需 **146.9 个回旋周期**。
另：梯度磁场下 B 随位置变，来料的 omega = qB/(gamma m) **用哪一点的 B 并未声明** ⇒ **口径未定**，连式子右边都写不出来。
⇒ 来料把「匀速螺旋」与「梯度磁场」并列为适用范围是**越界宣称**：该式严格成立于匀速螺旋，且**仅此**。

*控制组3：同一工具在匀速档给机器零 ⇒ 变速档的残差不是工具误差*

### C3 · F_e/F_m = c/v 是标准洛伦兹力的复述（零新增）　【INFO】

**问**：力比 c/v 是新东西吗？

**机读**：平面波 E=cB 下标准洛伦兹力 F_e/F_m = qE/(qvB) = c/v；四档 v 的最坏相对偏差 1.481e-16

**不是**。标准洛伦兹力 F = q(E + v×B)：电力 qE、磁力 qvB（取垂直构型）⇒ F_e/F_m = E/(vB)；对平面波 E = cB ⇒ **恰好 c/v**。四档速率机读最坏相对偏差 **1.481e-16**（机器零）。
⇒ 判 **INFO**：正确，但**逐字复述**标准电磁学，新增含量为零。
**适用范围登记**：v = 0 时磁力为 0（比值发散，不是「电力无穷大」）；v ∥ B 时磁力亦为 0 ⇒ 该式只在 **v ⟂ B 且 E = cB**（辐射场）的构型下有意义，来料未声明此前提。

*控制组5：标准洛伦兹力复现 c/v*

### C4 · E = cB 被写成了普遍关系（实际只对辐射场成立）　【FAIL】

**问**：来料称 E = cB「由 Maxwell 已证」，它普遍成立吗？

**机读**：辐射场(平面波) E=cB 成立（偏差 0.0e+00）；静电场（电子电荷 r=1nm）E=1.4400e+09 V/m 而 B=0 ⇒ E/(cB) 发散

**不普遍成立**。E = cB 只对**平面电磁波（辐射场）**成立；静电场反例：电子电荷在 r = 1 nm（原子尺度）处
E = **1.4400e+09 V/m**，而 B = 0 ⇒ E/(cB) **发散**。
麦克斯韦方程组并不蕴含 E = cB（它蕴含的是波动方程与 c = 1/sqrt(eps0*mu0)）；把辐射场的特例写成普遍关系是**越界宣称**。
注：本条是来料行文层面的越界，不涉及实验否决，判 FAIL 但权重低于 A/B 组。

*控制组5：平面波下 E=cB 成立*
