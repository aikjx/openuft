## 34.2 密度 $\rho$

### 34.2.1 本源定义

标准物理：单位体积的质量。统一场论映射（[B]）：P01 空间压缩与密度本体把密度读作"空间被压缩的程度"——P01 README 明示本体系类型为 `unformulated_direction`，"具体公设尚未建立"。S13 M5 对偶最短尺度 $\ell$ 给出唯一标度；S10 $m=\hbar\sqrt{\kappa^2+\tau^2}/c$ 把质量锚定到曲率。

### 34.2.2 本源方程（第一性原理）

**定义式**：

$$\rho = \frac{m}{V}\qquad[A]\tag{34.1}$$

**连续介质形式**：$\rho(\boldsymbol x) = \sum_i m_i\delta^3(\boldsymbol x-\boldsymbol x_i)$，宏观平均后得光滑场。

**推导步骤**：[A] 离散质点质量求和；[A] 取宏观小微观大体积平均；[A] 得 $\rho = m/V$。

**统一场论映射**：

1. [B] S10 $m = \hbar\sqrt{\kappa^2+\tau^2}/c$（postulates §2，定义式重排级别）。
2. [B] S13 M5 对偶最短尺度 $\ell$ 给出"一个最小体积元"$\sim\ell^3$。
3. [B] 故 $\rho \sim m/\ell^3 \sim \ell^{-1}/\ell^3 = \ell^{-4}$。
4. [C] P01 "空间压缩"如何从第一性原理推出宏观物质密度（而非真空密度）——**推导待建**，P01 公设未建立。

### 34.2.3 量纲定位

$$[\rho] = \frac{[M]}{[L^3]} = \frac{\ell^{-1}}{\ell^3} = \ell^{-4}\tag{34.2}$$

| 维度层级 | 对应物 | 量纲 |
|---|---|---|
| 0D | 单基元质量 $m$ | $\ell^{-1}$ |
| 1D | 线密度 $\lambda_L=m/L$ | $\ell^{-2}$ |
| 2D | 面密度 $\sigma_A=m/A$ | $\ell^{-3}$ |
| 3D | 体密度 $\rho=m/V$ | $\ell^{-4}$ |
| 3+1D | 物质密度场 $\rho(t,\boldsymbol x)$ | $\ell^{-4}$ |
| 4D | 标度空间"压缩密度" | $\ell^{-4}$ |

密度是典型的"维度递降量"：每降一维，量纲升一级 $\ell^{-n}$。

### 34.2.4 数值验证

- 空气 $\rho\approx 1.2\,\mathrm{kg/m^3}$；水 $1.0\times10^3$；铁 $7.87\times10^3$；铂 $2.15\times10^4$（实验常识值）。
- 核物质密度 $\sim 2.3\times10^{17}\,\mathrm{kg/m^3}$（实验常识值量级）。

### 34.2.5 精算示例

空气：摩尔质量 $M=29\,\mathrm{g/mol}$，$V_m=22.4\,\mathrm{L}$（STP），$\rho = 0.029/0.0224 \approx 1.29\,\mathrm{kg/m^3}$，与实测 $1.2$ 一致（[A]）。

## 34.3 压强 $p$

### 34.3.1 本源定义

标准物理：单位面积上的法向力。统一场论映射（[B]）：S02 统一力 $F=dP/dt$（postulates S02-A2）的面密度——压强是"单位面积上动量流率"。

### 34.3.2 本源方程（第一性原理）

**力学定义**：

$$p = \frac{F}{A}\qquad[A]\tag{34.3}$$

**热力学定义**：

$$p = -\left(\frac{\partial U}{\partial V}\right)_{S,N}\qquad[A]\tag{34.4}$$

**理想气体动理论推导**（[A]）：

1. [A] 分子在边长 $L$ 立方盒内，碰撞壁面法向动量变化 $2mv_x$，单位时间碰撞 $v_x/(2L)$。
2. [A] 单面受力 $F = \sum_i m v_{ix}^2/L$。
3. [A] 利用各向同性 $\langle v_x^2\rangle=\langle v^2\rangle/3$，得 $p = Nm\langle v^2\rangle/(3V)$。
4. [A] 联立理想气体状态方程 $pV=Nk_BT$，得 $p = 2n\langle E_k\rangle/3$。

**统一场论映射**：

5. [B] S02-A2 $F=dP/dt$，$P=m(c-v)$。把壁面受力读作"单位时间动量流"。
6. [B] $p=F/A$ 即动量流的面密度。
7. [C] 从 S13 旋量场动量流严格推出宏观 $p(V,T)$ 状态方程——**推导待建**。

### 34.3.3 量纲定位

$$[p] = \frac{[F]}{[A]} = \frac{\ell^{-2}}{\ell^2} = \ell^{-4}\tag{34.5}$$

| 维度层级 | 对应物 | 量纲 |
|---|---|---|
| 0D | 单点"压强"（无意义） | — |
| 1D | 线张力（per 单位长度力） | $\ell^{-3}$ |
| 2D | 面张力/面压强 | $\ell^{-4}$ |
| 3D | 体压强 $p$ | $\ell^{-4}$ |
| 3+1D | 压强场 $p(t,\boldsymbol x)$ | $\ell^{-4}$ |
| 4D | 标度空间压强 | $\ell^{-4}$ |

### 34.3.4 数值验证

- 标准大气压 $p_0=1.013\times10^5\,\mathrm{Pa}$。
- 海平面水压强梯度 $\rho g \approx 10^4\,\mathrm{Pa/m}$。
- 钢的屈服压应力 $\sim 2.5\times10^8\,\mathrm{Pa}$；核爆炸瞬时压强 $\sim 10^{12}\,\mathrm{Pa}$（实验常识值）。

### 34.3.5 精算示例

$1\,\mathrm{atm}$ 换算：$pV = nRT$，取 $n=1\,\mathrm{mol}$，$T=273.15\,\mathrm{K}$，$V=0.022414\,\mathrm{m^3}$，$p = nRT/V = 8.314\times273.15/0.022414 \approx 1.013\times10^5\,\mathrm{Pa}$（[A]）。

## 34.4 应力 $\sigma$ 与应变 $\varepsilon$

### 34.4.1 本源定义

应力是单位面积内力；应变是相对形变。统一场论映射（[B]）：应力是 S02 统一力 $F=dP/dt$ 在固体内部的面密度；应变是对偶度规（S13 M5/M10 对偶镜像度规）偏离真空构型的相对偏移。

### 34.4.2 本源方程（第一性原理）

**应力**：

$$\sigma_{ij} = \lim_{A\to 0}\frac{\Delta F_i}{\Delta A_j}\qquad[A]\tag{34.6}$$

**小应变**：

$$\varepsilon_{ij} = \frac{1}{2}\left(\partial_i u_j + \partial_j u_i\right)\qquad[A]\tag{34.7}$$

**推导步骤**：[A] 连续介质微元体受力平衡；[A] 位移场 $\boldsymbol u(\boldsymbol x)$ 线性化；[A] 得 Cauchy 应力张量 $\sigma_{ij}$ 与小应变张量 $\varepsilon_{ij}$。

**统一场论映射**：[B] $\sigma_{ij}$ 对应 S13 对偶镜像度规 $g_{\mu\nu}$ 扰动的动量流分量；[C] 从 S13 作用量（ch21）严格推出线性本构 $\sigma_{ij}=C_{ijkl}\varepsilon_{kl}$——**推导待建**。

### 34.4.3 量纲定位

$$[\sigma] = [F/A] = \ell^{-4},\qquad [\varepsilon] = [\Delta L/L] = \ell^0\tag{34.8}$$

| 维度层级 | 应力量纲 | 应变量纲 |
|---|---|---|
| 0D | — | — |
| 1D | 线张力 $\ell^{-3}$ | 线应变 $\ell^0$ |
| 2D | 面应力 $\ell^{-4}$ | 面应变 $\ell^0$ |
| 3D | 体应力张量 $\ell^{-4}$ | 体应变张量 $\ell^0$ |
| 3+1D | 应力场 $\ell^{-4}$ | 应变场 $\ell^0$ |
| 4D | 标度空间应力 $\ell^{-4}$ | 标度空间应变 $\ell^0$ |

### 34.4.4 数值验证

- 钢中弹性应变 $\varepsilon\sim 10^{-3}$ 量级；断裂应变陶瓷 $\sim 10^{-3}$，铜 $\sim 10^{-1}$（实验常识值）。

### 34.4.5 精算示例

拉杆 $A=10^{-4}\,\mathrm{m^2}$，$F=10^4\,\mathrm{N}$，$\sigma = F/A = 10^8\,\mathrm{Pa} = 100\,\mathrm{MPa}$——已接近低碳钢屈服强度（[A]）。

## 34.5 弹性模量 $E,B,G$

### 34.5.1 本源定义

杨氏模量 $E$：单向应力/单向应变；体积模量 $B$：压强/体积相对压缩；剪切模量 $G$：剪应力/剪应变。统一场论映射（[B]）：弹性模量是原子间结合势二阶曲率的宏观平均——S13 有效势 $V=\kappa(|\Psi|^2-v^2)^2$ 的二阶导数给出"基态刚度"。

### 34.5.2 本源方程（第一性原理）

**定义**：

$$E = \frac{\sigma}{\varepsilon},\qquad B = -V\left(\frac{\partial p}{\partial V}\right),\qquad G = \frac{\tau}{\gamma}\qquad[A]\tag{34.9}$$

**微观推导（从原子势）**（[A]）：

1. [A] 双原子结合势 $u(r)$，平衡位置 $r_0$，满足 $u'(r_0)=0$。
2. [A] 晶格常数 $a\sim r_0$，原胞体积 $V_0\sim a^3$。
3. [A] 宏观能量 $U = N u(a)$，压强 $p = -\partial U/\partial V = -(N/V_0)u'(a)$。
4. [A] 体积模量 $B = -V_0(\partial p/\partial V) = (1/V_0)\cdot u''(a)\cdot a^2$（量级估计）。
5. [A] 故 $B \sim (1/V_0)u''(a_0)$——**弹性模量由结合势二阶曲率决定**。

**各向同性关系**（[A]）：$E = 2G(1+\nu) = 3B(1-2\nu)$，$\nu$ 为泊松比。

**统一场论映射**：[B] S13 有效势在真空附近展开 $V(\rho)\approx V_0 + \kappa(|\Psi|^2-v^2)^2$，其二阶曲率 $\sim \kappa v^4$ 给出"基态刚度"；[C] 从 $\tilde\kappa$、$v$ 严格推出宏观 $B,E,G$ 数值——**推导待建**。

### 34.5.3 量纲定位

$$[E]=[B]=[G]=\frac{[\sigma]}{[\varepsilon]}=\ell^{-4}\tag{34.10}$$

| 维度层级 | 对应物 | 量纲 |
|---|---|---|
| 0D | 单键刚度（per 键） | $\ell^{-3}$ |
| 1D | 一维链弹性模量 | $\ell^{-3}$ |
| 2D | 二维膜弹性模量 | $\ell^{-4}$ |
| 3D | 三维体弹性模量 | $\ell^{-4}$ |
| 3+1D | 宏观弹性模量 | $\ell^{-4}$ |
| 4D | 标度空间刚度 | $\ell^{-4}$ |

### 34.5.4 数值验证

- 钢 $E\approx 200\,\mathrm{GPa}$；铝 $70$；铜 $110$；橡胶 $0.01$；水 $B\approx 2.2\,\mathrm{GPa}$（实验常识值）。
- 微观估计铜：$u''(a_0)/a_0 \sim (10^{-9}\,\mathrm{J}/\mathrm{nm}^2)/(0.255\,\mathrm{nm}) \sim 100\,\mathrm{GPa}$ 量级——与实测同量级（[A]）。

### 34.5.5 精算示例

钢丝 $L=1\,\mathrm{m}$，$A=1\,\mathrm{mm^2}$，挂 $F=100\,\mathrm{kg}$：$\sigma = mg/A = 980/10^{-6} = 9.8\times10^8\,\mathrm{Pa}$，$\varepsilon = \sigma/E = 9.8\times10^8/2\times10^{11} = 4.9\times10^{-3}$，伸长 $\Delta L = \varepsilon L = 4.9\,\mathrm{mm}$（[A]）。

## 34.6 硬度 $H$ 与强度 $\sigma_{\rm y},\sigma_{\rm uts}$

### 34.6.1 本源定义

硬度是材料局部抵抗塑性压入的能力；强度是材料断裂/屈服的临界应力。统一场论映射（[B]）：硬度与强度是微观拓扑缺陷（位错、晶界、点缺陷）的宏观表现——S13 框架下可把位错读作"旋量场的拓扑涡旋"（霍普夫荷 $Q_H$ 的缺陷构型）。

### 34.6.2 本源方程（第一性原理）

**硬度定义**：

$$H = \frac{F}{A_{\rm indent}}\qquad[A]\tag{34.11}$$

**屈服强度（Taylor 模型）**（[A]）：

$$\sigma_{\rm y} \approx \alpha G b\sqrt{\rho_{\rm disl}}\qquad[A]\tag{34.12}$$

其中 $b$ 为伯格斯矢量，$\rho_{\rm disl}$ 为位错密度，$\alpha\approx 0.3$–$1$。

**推导步骤**：[A] 位错线能量 $\sim \rho_{\rm disl} G b^2$；[A] 位错间相互作用产生阻碍运动的应力场；[A] Taylor 统计叠加得 $\sigma_{\rm y}\propto G b\sqrt{\rho_{\rm disl}}$。

**统一场论映射**：[B] 位错 ↔ S13 旋量场拓扑缺陷（霍普夫荷 $Q_H$ 的局域化涡旋）；[C] 从 S13 拓扑荷分布严格推出 $\rho_{\rm disl}$ 与 $\sigma_{\rm y}$——**推导待建**。

### 34.6.3 量纲定位

$$[H]=[\sigma_{\rm y}]=[\sigma_{\rm uts}] = [F/A] = \ell^{-4}\tag{34.13}$$

| 维度层级 | 对应物 | 量纲 |
|---|---|---|
| 0D | 单键强度（键能/键长²） | $\ell^{-3}$ |
| 1D | 一维链断裂应力 | $\ell^{-3}$ |
| 2D | 二维膜强度 | $\ell^{-4}$ |
| 3D | 三维体硬度/强度 | $\ell^{-4}$ |
| 3+1D | 宏观硬度/强度 | $\ell^{-4}$ |
| 4D | 标度空间"强度" | $\ell^{-4}$ |

### 34.6.4 数值验证

- 金刚石硬度 HV $\sim 70$–$100\,\mathrm{GPa}$；钢 HV $\sim 2$–$8\,\mathrm{GPa}$；铜屈服 $\sim 70\,\mathrm{MPa}$，UTS $\sim 220\,\mathrm{MPa}$；玻璃屈服 $\sim 1000\,\mathrm{MPa}$（实验常识值）。

### 34.6.5 精算示例

## 34.7 黏度 $\eta$

### 34.7.1 本源定义

流体抵抗剪切变形的能力。统一场论映射（[B]）：黏度是动量输运系数——S02 统一力 $F=dP/dt$ 在流体中的扩散率。

### 34.7.2 本源方程（第一性原理）

**牛顿流体**：

$$\tau = \eta\,\frac{dv}{dy}\qquad[A]\tag{34.14}$$

**动理论推导**（[A]）：

1. [A] 单位面积动量流 = 相邻层动量差 × 分子交换率。
2. [A] 层间距 $\lambda$，速度梯度 $dv/dy$，两层动量差 $\sim \rho\lambda\,dv/dy$。
3. [A] 单位面积单位时间交换分子数 $\sim (1/3)n\bar v$。
4. [A] 得 $\eta = \frac{1}{3}\rho\bar v\lambda$。

**统一场论映射**：[B] $\lambda$ 读作 S13 因果畴壁间距；[C] 从 S13 动量流严格推出宏观 $\eta(T)$——**推导待建**。

### 34.7.3 量纲定位

$$[\eta] = \frac{[\tau]}{[dv/dy]} = \frac{\ell^{-4}}{\ell^{-1}} = \ell^{-3}\tag{34.15}$$

| 维度层级 | 对应物 | 量纲 |
|---|---|---|
| 0D | — | — |
| 1D | 一维"黏度"（无标准定义） | — |
| 2D | 二维膜黏度 | $\ell^{-3}$ |
| 3D | 三维流体黏度 | $\ell^{-3}$ |
| 3+1D | 宏观黏度场 | $\ell^{-3}$ |
| 4D | 标度空间黏度 | $\ell^{-3}$ |

### 34.7.4 数值验证

- 水（20℃）$\eta\approx 1.0\times10^{-3}\,\mathrm{Pa\cdot s}$；空气 $1.8\times10^{-5}$；机油 $0.1$；蜂蜜 $10$；玻璃（高温）$10^{12}$（实验常识值）。

### 34.7.5 精算示例

动理论估空气 $\eta = (1/3)\rho\bar v\lambda = (1/3)\times1.2\times470\times6.8\times10^{-8}\approx 1.3\times10^{-5}\,\mathrm{Pa\cdot s}$，与实测 $1.8\times10^{-5}$ 同量级（[A]，动理论粗估）。

## 34.8 表面张力 $\gamma$

### 34.8.1 本源定义

单位长度上的界面收缩力，或单位面积的界面自由能。统一场论映射（[B]）：表面张力是两相界面处"对偶场梯度能"的面密度——S13 序参量 $\Psi$ 在两相之间的过渡层产生额外能量。

### 34.8.2 本源方程（第一性原理）

**定义**：

$$\gamma = \frac{F}{L} = \frac{\sigma}{A}\qquad[A]\tag{34.16}$$

**推导步骤**：[A] 界面两侧分子受力不对称；[A] 增加界面面积需做功 $dW=\gamma\,dA$；[A] 故 $\gamma$ 既是力/长度也是能量/面积。

**统一场论映射**：[B] $\gamma$ 对应 S13 序参量 $\Psi$ 界面过渡层的梯度能 $\sim (\nabla\Psi)^2$ 的面积分；[C] 从 S13 作用量严格推出宏观 $\gamma$ 数值——**推导待建**。

### 34.8.3 量纲定位

$$[\gamma] = \frac{[E]}{[A]} = \frac{\ell^{-1}}{\ell^2} = \ell^{-3}\tag{34.17}$$

| 维度层级 | 对应物 | 量纲 |
|---|---|---|
| 0D | — | — |
| 1D | 线张力（一维界面） | $\ell^{-2}$ |
| 2D | 二维表面张力 $\gamma$ | $\ell^{-3}$ |
| 3D | 三维"体积张力"（无标准定义） | — |
| 3+1D | 宏观表面张力 | $\ell^{-3}$ |
| 4D | 标度空间界面能 | $\ell^{-3}$ |

### 34.8.4 数值验证

- 水-空气 $\gamma\approx 0.072\,\mathrm{N/m}$；汞-空气 $0.485$；酒精 $0.022$；肥皂水 $0.025$（实验常识值）。

### 34.8.5 精算示例

毛细管上升 $h = 2\gamma\cos\theta/(\rho g r)$：水 $\gamma=0.072$，$\theta=0$，$r=0.1\,\mathrm{mm}$，$\rho=10^3$，$g=9.8$，得 $h = 2\times0.072/(10^3\times9.8\times10^{-4}) \approx 0.147\,\mathrm{m} = 14.7\,\mathrm{cm}$（[A]，与实验一致）。

## 34.10 诚实边界与待研究问题

**已闭合（[A]）**：八个力学量的定义方程、量纲定位、与实验常识值的数量级对照——全部由连续介质力学/固体物理/动理论承担，不依赖 openuft 未证公设。

**框架映射（[B]）**：密度↔P01 空间压缩本体（**但 P01 公设未建立，只能做定位**）；压强↔S02 $F=dP/dt$ 面密度；应力↔S13 对偶度规扰动；弹性模量↔S13 有效势二阶曲率；黏度/表面张力↔S13 动量流/梯度能——均为**结构对应**，候选。

**待建（[C]）**：

1. P01 空间压缩与密度本体公设未建立——从第一性原理推出宏观物质密度 $\rho=m/V$ 与真空密度的关系，**推导待建**。
2. 从 S13 拓扑荷 $Q_H$ 分布严格推出位错密度 $\rho_{\rm disl}$ 与屈服强度 $\sigma_{\rm y}$（Taylor 模型的 openuft 版本）——**推导待建**。
3. 从 S13 作用量严格推出线性本构 $\sigma_{ij}=C_{ijkl}\varepsilon_{kl}$ 与弹性张量 $C_{ijkl}$ 的组分——**推导待建**。
4. 从 S13 序参量 $\Psi$ 界面过渡层严格推出表面张力 $\gamma$——**推导待建**。
5. S13 ch18 未把"统计/热力学"与"连续介质力学"列为已统一项——本章不越界宣称已统一。

**禁止越界**：任何把 P01（`unformulated_direction`）当成已证本体、任何把 [B]/[C] 写成 [A]、任何给出 openuft 对力学量的"理论预言数值"的尝试，均违反诚实红线。本章所有数值均为实验常识值，不是理论预言。
