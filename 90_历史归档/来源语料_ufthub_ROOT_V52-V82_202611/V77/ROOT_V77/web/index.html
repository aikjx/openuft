四条验证链

  1. 量纲：只用 c、ħ 及无量纲螺旋角不能构造 G 的 M⁻¹ 量纲。
  2. 相对论：Einstein 方程中耦合系数 κₑ = 8πG/c⁴；改变 c 并不能独立固定 G。
  3. 天体：轨道通常测得的是 GM，不是独立的 G 和 M。
  4. 微观：rᵍ/λ̄ᶜ = αᵍ(m)。只有独立求出无量纲 αᵍ 才可能由此预测 G。

如何获得真正的新突破？

必须给出一个不含实测 G的微观动力学模型，独立计算长度尺度 ℓ* 及无量纲常数 A，再预测 Gₚᵣₑd = A c³ℓ*²/ħ，最后用独立测量验证。
