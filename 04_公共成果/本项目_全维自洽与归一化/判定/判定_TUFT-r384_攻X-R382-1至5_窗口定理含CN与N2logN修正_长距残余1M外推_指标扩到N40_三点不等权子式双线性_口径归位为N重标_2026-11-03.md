## §五 窗口定理（X-R382-1 的答案）

设 E(N) = aN² + bN + φ(N)，a>0。argmin = k ⟺ 对所有 m≠k 有 E(m) > E(k)：

```
m > k :  b > −a(m+k) − (φ(m)−φ(k))/(m−k)      ⇒ lo = max_{m>k}
m < k :  b < −a(m+k) − (φ(m)−φ(k))/(m−k)      ⇒ hi = min_{m<k}
```

窗口是 (lo, hi)，**恒为区间**（各自是半直线的交）。宽度由端点值决定。
**若 E 在整数格上凸，端点必在 m=k±1**，代回即得通式：

```
W = hi − lo = 2a + φ(k−1) + φ(k+1) − 2φ(k)   （φ 的离散 Laplacian）
c/N 的特例：W = 2a + 2c/(k(k²−1))
```

验证：A1 基线（φ=0，8 档 W=2）；A2（c/N，21 组，端点极值点 m*=k+1 / k−1）；A5（c/N 14 组三路径 + N²logN 9 组两路径，最大差 6.00e-59）。

**边界三层（本卷新增）**：

- **域层**：c/N 使 N=0 不可取 ⇒ 域 N≥0 → N≥1 ⇒ k=1 窗口由有界变半直线（A3）。
- **参数层**：c 自由 ⇒ W 可任意放大（A4，c=24a 给 W=10a）。
- **凸性层**：非凸时端点离开 k±1，通式失效；更狠的是**窗口可为空**（A6，13/23 个 k 不可达）。

## §六 长距残余（X-R382-3 的答案）

对象：S(r) = Σ_{n∈Z²}(r²+L²|n|²)^{−3/2}，`|n|∞ ≤ M` 截断；目标是 S·r → 2π/L²。

```
M      S·r            残余 R_M        R_M/R_2M
20     2.1519618020   −4.1312235052   —
40     3.7357119631   −2.5474733441   1.6217
80     4.9125451872   −1.3706401200   1.8586
160    5.5827996160   −0.7003856911   1.9570
320    5.9307551584   −0.3524301487   1.9873
```

比值 → **2** ⇒ 领先项是 **1/M**（截断尾巴），不是 1/M²（C3 用错幂次外推给 −2.364e-01，差 50 倍，抓得住）。

## §九 子式结构（X-R382-5 的答案）

M = Σ_a y_a u_a u_aᵀ = U·diag(y)·Uᵀ。Cauchy–Binet：

```
minor_{ij,pq}(M) = Σ_{|S|=2} det(U[i,j;S]) · det(U[p,q;S]) · Π_{a∈S} y_a
```

⇒ 每个 2×2 子式都是权重的**双线性型**（只含 y_a y_b 型乘积，不含一次项）。后果：

- 「三点等权 ⇒ 满秩」不是必要条件：权重 (1,2,3)/(1,1/10,1)/(2,3,5) 全给 rank 3。
- 子式下界 ∝ **最弱的一对**权重之积：整体缩放 λ ⇒ 子式乘 λ²（9/9 精确）。
- 一个权为零 ⇒ rank 2（子式非零、det=0）；两个为零 ⇒ rank 1（9 子式全 0）。
  ⇒ **只看 det 会漏掉 rank 2**，必须同时看 2×2 子式（C7）。
