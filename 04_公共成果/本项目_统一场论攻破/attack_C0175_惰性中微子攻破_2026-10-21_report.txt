[E2] 3+1 短基线振荡概率第一性精算（本册核心，Decimal 48 位）
  公式推导：P(ν̄_μ→ν̄_e) = |Σ U_ei*U_μi e^{−iE_iL}|²；短基线 ⇒
    P ≈ 4|U_μ4|²|U_e4|² sin²(Δm²₄₃ L/4E)，Φ = Δm²·L/(ħc·4E)（自然单位）。
  ħc = 1.973e-7 eV·m（CODATA，引用）⇒ 标准常数 C_std = 1/(4·ħc·1e6) = 1.26693
    （即 Φ = 1.26693·Δm²(eV²)·L(km)/E(GeV)，与教科书 1.2669 一致）
  反解 |U_μ4|² = sin²(2θ_μe)/(4|U_e4|²) = 0.0026/(4×0.02) = 0.0325
  LSND（L=30 m、E=30 MeV）：Φ = 1.64701 rad、sin²Φ = 0.99420 ⇒ P(ν̄_μ→ν̄_e) = 2.5849e-3 = 0.258%
  MiniBooNE（L=541 m、E=0.8 GeV）：Φ = 1.11379 rad、sin²Φ = 0.80529 ⇒ P = 2.0937e-3 = 0.209%
  消失通道对照：ν̄_e 消失振幅 A_dis = 4|U_e4|²(1−|U_e4|²) = 0.07840（拟合值 0.02）
  Daya Bay（L=1500 m、E=3 MeV）：Φ = 823.50624 rad ≫1 ⇒ 快速振荡系综平均 sin²=1/2
    若拟合 |U_e4|²=0.02 成立，应观测到消失亏损 P_dis = A_dis×1/2 = 3.9200e-2 = 3.920%
    Daya Bay 实测无此亏损 ⇒ 95%CL 上界 |U_e4|² ≤ 0.005（引用）⇒ P_dis ≤ 0.995%
  出现 vs 消失张力：|U_e4|² 拟合值/消失上限 = 0.02 / 0.005 = 4.0 倍
  => 3+1 拟合参数在两组装置给出 10⁻³ 量级外观概率（与反常显著性相容），
     但同一 |U_e4|² 被反应堆消失实验约束到 ~1/4 ⇒ 出现-消失张力（3+1 全局拟合亏量）。
