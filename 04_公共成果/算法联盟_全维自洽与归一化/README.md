## 红线声明

- 精算只证「数学自洽」与「与已知实验值一致」，**不证第一性推导**。
- 量纲常数（c / ℏ / k_B）由单位定义固定，其「导出」是单位换算，不是物理预言。
- 第一性真正靶心是**无量纲量**：α、m_μ/m_e、m_τ/m_e、α_S、α_grav。
- 数学恒等成立 ≠ 本体公设成立；证据不得跨体系转移。
- 冲突一律如实标 FAIL / BOUNDARY，不粉饰为 PASS。

## 最重要的发现：普朗克锚定谬误（M02）

`G = c³/(ℏ(κ²+τ²))` 与 `m = ℏ√(κ²+τ²)/c` 联立必然推出 `G m² = ℏ c`，**唯一解 m = m_P**。
这两条式子的实质是**普朗克尺度恒等式**（m=m_P 时 α_grav=1 恒成立）被误用为**任意粒子的关系式**。
正确形式是 `α_grav = G m²/(ℏc) = (m/m_P)²`。

影响范围：S07、S08、S09、S10 及 GAQ 谱系全部派生式。
此前被「113 项精算 100% 通过」的表象掩盖。

## 三条方法论结论

1. **无量化判据**（G03/J01）：第一性内容 ⟺ 无量纲量的数值。
   「几何化导出 c、ℏ、G」是伪目标；「导出 α 或 m_τ/m_e」才是真目标。
2. **测量噪声会伪装循环为独立**（H01c）：ε₀ 与 e²/(4παℏc) 的 CODATA 残差约 3e-12，
   使理论上线性相关的约束在 80 位精度下被判为独立，制造「多项独立验证通过」的虚假确信。
3. **项数 ≠ 约束数**（H02/H03）：`ħ=mcR` 与 `m=ℏ/(cR)` 是同一约束；
   e 的导出式代入后是恒等式 `e²=e²`。循环项重复计数会虚增验证项数。
