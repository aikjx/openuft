## 与兄弟体系的边界

本体系以「张祥前 20 核心公式」为研究对象，与以下同母题体系共享「空间光速螺旋」直觉，但主张与证据各自独立登记：

- [S02 空间光速螺旋统一力](../S02_空间光速螺旋统一力/README.md)：借用了 P=m(c−v)、F=dP/dt 的动力学形式。
- [S12 空间光速螺旋统一体系](../S12_空间光速螺旋统一体系/README.md)：同 v≡c 本源公设。
- [S15 空间光速螺旋曲率挠率几何统一场论](../S15_空间光速螺旋曲率挠率几何统一场论/README.md)：把 κ/τ 作为唯一几何基元。
- [S14 挠率统一场论 TUFT](../S14_挠率统一场论TUFT/README.md)：以挠率张量多分量内禀代数承载规范群。

本仓库不沿用来源自封的「算法联盟 ROOT 最高权限 ✅ 全部通过」认证；每条公式按 H/O/C/U 诚实评级独立登记于 claims.csv。

## 诚实评级口径（必读）

来源文本大量使用「全域零误差」「全部通过」「最高权限认证」等绝对化断言。本仓库将每条核心公式登记为带 `evidence_level` 的 claim：

- `H`：数学恒等式/定义层结果（如螺旋参数化下的速度恒为 c）。
- `O`：诚实边界——几何重述成立但未给出独立于现有物理的新预言。
- `C`：冲突/缺陷——循环自证（用 CODATA 常数反算自身）、与实验冲突的预测。
- `U`：未展开方向。

目录完整、来源入口已核对、脚本可运行，都不表示本统一场论已经成立。
