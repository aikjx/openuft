- `n_q=3` 等分相干叠加 `√(Σsin²(i·π/6)) = √2`（相干规则）

### [B] 实验 g_s~1 反解 + 单位圆自洽（量级锚→推导）
- 约束 `α_S = n_q·τ_int ≈ 1` ⇒ `τ_int = 1/n_q = 1/3`
- 校验 `sin(asin(1/3)) = 1/3`，`φ_int=0.108π ∈ [0,π/2]` 合法 ✓
- **结论**：`τ_int` 由"实验 g_s~1"唯一确定，且自然落在归一化单位圆投影上
