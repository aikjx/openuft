# 第1章 导论：为什么是阴阳对偶

## 1.1 本书是什么

【 **一句话定位** :本书是"全域双向分形统一场论"的完整书稿——从两条不可再分的基元出发，用六条封闭方程、五大板块、四新方程与一次希格斯突破，试图把场、力、尺度、时空、因果收进同一个几何体系，并给出全部求导、证明、验证与精算。】

【 **一句话立场** :本书坚持三件事——第一性原理（从最少的假设出发）、奥卡姆剃刀（砍掉一切可砍的参数）、第二裁判（每个结论都用可复现的数值实验检验）。不做文学化修饰，不回避反证。】

## 1.2 全书地图

【 **第一卷（第1–4章）** :公理与哲学基础。先讲清"为什么是阴阳对偶"这一根本选择，再立三条公理，最后把河图、洛书、万字符这些东方符号学编码成数学结构。】

【 **第二卷（第5–8章）** :场方程体系。从公理推出旋量对偶方程；证明规范场从旋量相位几何自涌现（$U(1)$ 与 $SU(2) \times U(1)$）；给出拓扑荷的正版——霍普夫荷；最后是全书最重要的突破：真空约束使对偶旋量即希格斯对偶。】

【 **第三卷（第9–11章）** :尺度与时空。双向重整化群给出分形维度；对偶镜像度规化解奇点；因果畴收拢全域演化。】

【 **第四卷（第12–15章）** :求导、证明、验证、精算。第12章对五板块逐一求导；第13章给出全部定理与证明；第14章是十五项数值实验的全部实测数据；第15章完整记录一次反证与修复——绕数证伪如何被"升维定律"解释并修订。】

【 **第五卷（第16章+附录）** :预言与前景。四大可检验预言、完成度评估（$U = 58\%$）、通向完全统一的路线图，以及符号表与脚本重跑方法。】

## 1.3 阅读指南

【 **三档读法** :只想抓思想——读每章开头的导读与结尾的小结；想做计算——读第二、三卷的方程与第四卷的推导证明；想复现全部结果——照附录 B 的脚本逐条重跑，所有数据都在第14章可对照。】

【 **约定** :全书所有数理符号用 LaTeX 行内公式（$ $）包裹；强调句式用【 **内容** :描述】体例；"大白话"段落是严格内容的翻译，不是替代。】

## 1.4 是非边界

【 **本书不宣称什么** :不宣称已经推出标准模型全部粒子；不宣称已经解释 $\alpha$ 与 $\Lambda$ 的量级；不宣称"一亿字"式的无限内容——只交付一部完整、可验证、可复算的书。剩余拼图在第16章如实列出。】

【 **本书宣称什么** :三公理推出六方程闭环；拓扑荷在 3D 有正版（霍普夫荷）；对偶旋量在代数上就是希格斯对偶；全部核心结论有机器精度的数值证据。】

## 小结

【 **本章要点** :阴阳对偶不是比喻，是被选作第一公理的数学结构；本书的每个结论都经过"推导—证明—实测"三重检验；读完本书，你可以复现它的每一个数字。】
