# 冲突记录：借用项 S12-A4（P = m(c − v)）的低速极限与静止行为

> 体系：空间光速螺旋统一体系（S12） · 假设版本 v6.0-20260906
> 出处：算法联盟全维自洽引擎 M03 组（2026-09-15，mpmath 80 位 + sympy 符号求导）
> 状态：**内部冲突（internal_conflict）**——由**借用** S02 的动力学方程引入；
> 借用不带来独立证据，**也不隔离借入方的缺陷**。

## 一、冲突来源

本体系第 2.1 节直接使用 `P = m(c − v)`、`F = dP/dt`，
并已按治理要求登记为**借用项 S12-A4**（来源 `s02_light_speed_helix_force`）。

该借用同时把 S02 的缺口一并带入本体系：

### 1.1 静止行为异常

`v = 0` 时 `P(0) = mc ≠ 0`（电子为 `2.73e-22 kg·m/s`），
与「静止粒子动量为零」的常规定义冲突。

### 1.2 低速极限符号相反

`m`、`c` 恒定时 `F = dP/dt = −ma`，与牛顿第二定律 `F = +ma` **反号**。

完整诊断见 [S02 同名记录](../../S02_空间光速螺旋统一力/11_证伪与反例/统一动量低速极限冲突记录.md)。

## 二、本体系的额外负担

S02 是**动力学框架**（不主张几何本体），低速极限问题在 S02 内部尚可视为待补前提；
但本体系在该动力学之上**叠加了本体主张**（S12-A2：`v ≡ c` 光速恒等约束），
因此问题更严重：

- 若内部运动**恒等**于光速（`v ≡ c`），则 `P = m(c − v) = 0` 恒成立，
  统一力 `F = dP/dt ≡ 0`——**与「用该方程分解四力」的初衷直接冲突**；
- 若 `v` 指外部速度而 `c` 指内部速度，则二者是**不同对象**，`c − v` 的矢量差缺乏定义，
  须先声明 `c` 的数学身份（标量速率 / 矢量 / 常数符号）。

**即：本体系的本体公设与借用来的动力学方程之间存在未解决的接口问题。**

## 三、对本体系既有证伪标准的影响

本阶段已有产物 `falsification_criteria.md` 明确记载：
「仅人工场条目有原文阈值；**三条本源公设尚无失效条件**」。

本次检出的低速极限冲突，属于**本源公设层面**的问题（A2 的 `v ≡ c` 与借用的 A4 接口），
因此它不在既有阈值表覆盖范围内，需作为新增条目登记。

## 四、修正建议

1. 明确 `P = m(c − v)` 中 `c` 与 `v` 各自的**数学身份与物理所指**（内部 vs 外部）；
2. 若坚持 `v ≡ c`，须解释 `F = dP/dt ≡ 0` 如何与四力分解共存，或修改动力学方程；
3. 给出低速退化条件与 `F = +ma` 的恢复路径；
4. 在 `falsification_criteria.md` 增补「动力学接口」类阈值条目。

## 五、不受本冲突影响的部分

- **S12-A1/A2/A3 导出的三重奏** `κ² + τ² = (ω/c)²`：在参数化下是**代数恒等式**，
  经符号求导验证为机器零，与借用动力学无耦合，不受影响；
- 「空间以光速螺旋运动」的本体主张本身属 L4（不可由数学判定），不因本冲突被否定。

**诚实声明**：本记录为理论内部自洽性审计结论，非实验证伪。
它不否定本体系的整体方向，但确证两点：
①**借用的动力学方程带有未声明前提**；②**本体公设 `v ≡ c` 与该动力学方程的接口尚未定义**。
在该接口解决之前，由 `F = dP/dt` 推出的任何结论不应计入已验证结论。
