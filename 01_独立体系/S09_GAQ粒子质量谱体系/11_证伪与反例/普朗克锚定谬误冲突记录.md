## 二、上游根因：整条派生链被普朗克锚定污染

本体系 v6 的质量表达式建立在 v5/v4 的派生链之上，而该派生链含有致命联立：

```
G = c³/(ℏ(κ²+τ²))   ∧   m = ℏ√(κ²+τ²)/c
        ⟹ 消去 (κ²+τ²)  ⟹  G m² = ℏ c  ⟹  m = m_P（唯一解）
```

**即：派生链在数学上只能给出「所有粒子质量 = 普朗克质量」这一个解。**
任何试图由它推出 `m_p/m_e = 1836` 或 `m_τ/m_e = 3477` 的构造，都是在一条已经被退化的链上做拟合——
这解释了为什么 v6 的质量比构造**系统性失败且偏差巨大**（40%–2000%），而非精度不足。

正确形式：`α_grav = Gm²/(ℏc) = (m/m_P)²`（引擎 `M02-n`，PASS，残差 `1.69e-81`）。
完整根因见 [S07 同目录记录](../../S07_GAQ复曲率融合体系/11_证伪与反例/普朗克锚定谬误冲突记录.md)。

## 三、第二重边界：归一化后质量信息已经丢失

即使修复 G 式，本体系仍面临一个结构性限制（引擎 `M04` / `C03`）：

归一化本源方程 `κ̃² + τ̃² = 1` 中

```
κ̃ = κ/Ω = 1/√(1+α²)       τ̃ = τ/Ω = α/√(1+α²)       Ω = √(κ²+τ²) = mc/ℏ
```

**κ̃、τ̃ 与质量 m 完全无关**——归一化把质量信息整体除掉了，质量全部寄于 `Ω = mc/ℏ` 这一未解释的绝对尺度。

> 因此「由本源方程解释质量谱」是**不成立的表述**：
> 本源方程解释的是 κ/τ 的相对比例（即 α），不是质量的绝对值或比值。

引擎 `C02` 实测：6 个粒子（e/μ/τ/p/W/普朗克）的 `κ̃²+τ̃²−1` 残差全部为 `2.1e-81`——
正因为它与质量无关，才能对**所有**粒子同时成立。这不是成功的证据，而是**信息量不足的证据**。

## 四、自由度审计：归一化后只剩两个真问题

自然单位（`c = ℏ = G = 4πε₀ = 1`）下，7 个变量被 5 条约束压缩，剩余 **2 个自由度**：

| 自由度 | 物理含义 | 现状 |
|---|---|---|
| 1 | `α`（耦合强度） | 测量锚，未被第一性导出 |
| 2 | `m/m_P`（质量尺度） | 测量锚；**代际比值（m_μ/m_e、m_τ/m_e）更完全未定** |

（引擎 `H04` / `H05`）

这与仓库 v30 的收官结论一致：**代质量层级在拓扑结构层内无解**，
`φ^n` 幂律、`SU(2)_k` 量子维数比值等纯拓扑构造已被逐族排除，
缺口收敛为**「动力学 Yukawa 起源」单点**。

## 五、本体系公设（A1–A3）的独立身份

需要区分两件事：

| 内容 | 判定 |
|---|---|
| **A1–A3（三代 = SO(3) 三本征方向 / π₃(SU(3))=ℤ / Cl(4,4) 给出 3×2=6）** | **不受本冲突影响**——它们是**计数匹配**，与 G 式派生链无代数耦合 |
| **由派生链给出的质量数值** | **已失败**——受普朗克锚定污染，且受归一化信息丢失限制 |

即：本体系的**代结构（3 代 × 2 手征 = 6）**部分仍可作为 conjecture 保留；
**质量数值几何化**部分应明确标注为失败并停止累加拟合式构造。

## 六、修正建议

1. 切断质量谱对 `G = c³/(ℏ(κ²+τ²))` 的依赖，改用 `α_grav = (m/m_P)²`；
2. 明确「本源方程不携带质量信息」，把质量层级问题**移交**给动力学（Yukawa）而非几何；
3. 停止用 `α⁻³`、`6π⁵/α`、`eⁿ` 一类数值巧合做拟合（v29/v30 已证明此类构造可任意逼近，无证据力）；
4. A1–A3 若保留，登记为 `conjecture`，并补充「为什么是 3 代」之外的可检验推论。

它不否定「三代可能有拓扑起源」这一方向，但确证：
