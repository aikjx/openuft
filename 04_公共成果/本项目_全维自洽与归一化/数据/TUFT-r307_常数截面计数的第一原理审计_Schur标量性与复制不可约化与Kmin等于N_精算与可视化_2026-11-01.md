## 三、定理 N · Schur 标量性

**命题**：扭转取中心元 `g ∈ Z(G)`。由 **Schur 引理**，`g` 在不可约表示 R 上作用为标量：

```
g|_R = ω_R(g)·1_R ,   ω_R(g) = ζ₃^{a·n₃} · (−1)^{b·n₂}
```

常数截面 ψ 满足扭折周期性 `ψ(x+γ) = ω_R(g)·ψ(x)`；ψ 为常数且非零 ⇒ 必须 **ω_R = 1**。于是

```
k_R = 1  若 ω_R(g) = 1
k_R = 0  否则
```

⇒ **`k_R ∈ {0,1}`**。用整数相位指数（单位 2π/6）`m = (2a·n₃ + 3b·n₂) mod 6` 精确判定，全程无浮点。

**机检（B01–B11）**：6 个扭转元 `(a,b) ∈ Z₃×Z₂` 逐个算 `m` 与 `k`：

```
g=(0,0)  m=[0,0,0,0,0]  k=(1,1,1,1,1)  ← T0
g=(0,1)  m=[3,0,0,3,0]  k=(0,1,1,0,1)  ← T2
g=(1,0)  m=[2,4,4,0,0]  k=(0,0,0,1,1)  ← T3
g=(1,1)  m=[5,4,4,3,0]  k=(0,0,0,0,1)  ← T32
g=(2,0)  m=[4,2,2,0,0]  k=(0,0,0,1,1)  ← T3（与 g=(1,0) 同 k）
g=(2,1)  m=[1,2,2,3,0]  k=(0,0,0,0,1)  ← T32
```

**6 个扭转给出 4 个不同 k 向量**（B03 = 4），**与 r302 手工编码的 `k_of()` 表逐项一致**（B05 = 4/4、CTL6、G12）。

> **这是本卷最实在的一步**：r302/r305 的 k 表一直是**手写输入**；本卷给出它的推导，
> 链条是「表示 → Dynkin 标号 → 中心荷 → 相位 → k」，中间没有一处人肉判断。
> 于是「`k_R ≤ 1` 是假设」这句话被改写成「**`k_R ≤ 1` 在 H1∧H2 下是定理**」（H1 = 中心扭转，H2 = 内部空间连通）。

## 五、定理 P · `N ≤ K`（本卷的自我纠正）

由等谱族 `k = (N−t, N+2t, N−t, N+t, N−t)`（承 r305 定理 J，`t = N−λ`）：

```
k ≥ 0  ⇒  N ≥ t
max k  =  N + 2t  ⇒  N = max k − 2t ≤ K − 2t ≤ K
```

⇒ **`N ≤ K`**，等号 ⟺ `t = 0`。机检：`K = 0..9` 上 `N_max` 逐点 = `K`（D11/D12/G13）。

**于是 r305 的定理 M 需要修正**：

|  | r305 的读数 | 本卷复算 |
|---|---|---|
| K_min 序列（λ=0 切片） | `[0,3,6,9,12,15,18]` | **逐字复现**（D01） |
| 该切片上的代数 N | 被标为「t 代」 | **实际 N = t + λ = t**（D02/D03，λ_opt 全为 0） |
| 「N 代所需 K」 | 未给出 | **K_min(N) = N**（D04） |
| 三代代价 | 「需 9 份常数截面」 | **只需 3 份**（D06，k=(3,3,3,3,3)） |

★**r305 的算术没错，错的是标签**：它把「通量量子 t」当成了「代数 N」。两者在 λ=0 这条切片上恰好相等，
所以数字对得上、结论说歪了。**正确说法是：三代需 `K ≥ 3`，不是 9。**

**三代的最小构造（D06–D08）**：`k = (3,3,3,3,3)`、`t = 0`、`q = 0` ⇒ `n = (3,3,3,3,3)`，六条反常全零。
★注意 `q = 0`：这个解**不用通量**，纯靠常数截面。这使否证门槛从「9 份」降到「3 份」，**no-go 比 r305 自述的更脆弱**。

## 六、定理 Q · 复制不可约化

### (a) 非中心扭转：拿不到 `k > 1`，且破 SM

按口径 (ii)（固定子空间维数）算 `Q_L` 六权的相位重合：在 `Z₁₂³×Z₁₂ = 20736` 个环面元上，
取值集合 = **{1, 2, 3, 4, 6}**（E01）—— **不是常数**。恒等元给 6（= dim Q_L），一般元给 1。
⇒ 该量**依赖连续模、不是整数不变量**，不能当固定的多重度偏移（E02/E03/CTL9）。

而定域上（三色相位互异，共 1728 个元素）中心化子恒为极大环面 ⇒ 残存 `U(1)²` ⇒ **SU(3) 被完全破缺**（E03b）。

### (b) 非阿贝尔 flavor 表示：常数截面 = 平凡重数 = **0**

最诱人的逃逸是「取一个非阿贝尔群的三维不可约表示，`k_R = 3`」。**这条被证伪**：

A_4 的 3 维不可约表示是「坐标和为零」子空间上的置换作用，某 `g` 的固定维数 = `max(0, Fix(g) − 1)`：

| g 型 | 个数 | Fix(g) | 固定维数 |
|---|---|---|---|
| 恒等 | 1 | 4 | **3** |
| 双对换（阶 2） | 3 | **0** | **0** |
| 3-轮换（阶 3） | 8 | 1 | **0** |

全体群元**共同**固定的向量（= 平凡表示重数）= **0**（E04/E05/E05b）。

⇒ **非平凡不可约表示给 0，不给 d**。只有 `ρ = 1⊕1⊕1`（三份**平凡**表示）才给 3（CTL4）——而那已经是**复制**。

### (c) 唯一的 `k > 1` 来源：复制

内部空间有 `c` 个连通分量，**各带独立扭转** ⇒ `k = Σ_{j=1..c} k^(j)`，`k^(j) ∈ {0,1}⁵` ⇒ 可达集合 = `[0,c]⁵ ∩ ℤ⁵`
（E06 构造性分解：c=1,2,3 共 **1299** 个点全部成功分解）。

⇒ **可达的常数截面上限 `K = c`** ⇒ 由定理 P：

```
N_gen ≤ c = π_0(M_int)
```

**三代 ⟺ `c ≥ 3`**（E08），最小 `c = 3`，构造 `k = (3,3,3,3,3)`（三分量各给 `(1,1,1,1,1)`）⇒ 六条反常全零（E09/E10）。

★**特例登记（避免过度断言）**：若强制各分量扭转**相同**（简单复制），可达集合收缩为 `N ∈ {0,c}`（E11b）。
本卷取较强者 `N ≤ c`。

★**无选择性**：`c = 1..6` 每一个都能给出 `n ≡ c` 且零反常（E11 = 6/6、CTL5）⇒ **方程对 c 没有选择性**。

### `X-R305-1` 的判决

> **`k_R ≤ 1` 不能由第一原理推出。** 它等价于「内部空间连通（`c = 1`）」。
> 放开连通性 ⇒ 复制 ⇒ `N ≤ c`，**代数变成 `π_0(M_int)` 的读数**。
> ⇒ 三代仍不被解释，但它「能被解释」的唯一缺口被精确定位到 **`c ≥ 3` 这一拓扑输入**。
