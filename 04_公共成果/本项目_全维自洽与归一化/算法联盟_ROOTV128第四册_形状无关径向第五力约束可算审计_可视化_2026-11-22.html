先划清「攻」的边界：统一场论作为研究纲领不能被一次计算攻破。本册把第三册的形状假设去掉——不再问「这个 Yukawa 能不能活」，而是问「任意径向额外力，这组数据给了多少空间」。结论是：存在一个精确的零方向，整体幅度零信息；能被约束的只有形状变化，而它被压到 1e−12 量级。

1. 结构事实：C ≡ 常数是精确零方向

Phi = -(mu/r)(1 - C(r)) => dPhi = (mu/r) C(r) C == 常数 => dPhi ∝ mu/r => 轨道仍是闭椭圆 => Delta_varpi = 0 （精确，不是近似）

所以「径向第五力的整体幅度」对近点进动恰好零信息——不是约束很弱，是代数上完全无信息。机读验证：核的绝对值 8.862e−19，信号尺度 O(1) 弧度/圈，抑制 18 个数量级。

这幅图就是全册的论点。红虚线是零方向：无论如何缩放，进动都恰好为 0。彩色曲线是 Yukawa：λ 越小，profile 在采样范围内变化越剧烈，越容易被抓住；λ 越大越贴近平坦线，越接近零信息。第三册观察到的「λ 大则 σα 爆炸」，本质就是曲线在往红线上贴。

2. 形状无关的约束：只有反差被约束

把 C(r) = Σ c_k w_k(r) 参数化成 ln r 上的光滑单位分解（Σ w_k ≡ 1，这一条使 c=(1,1,…,1) 恰好落在零方向上）。整体水平不进入模型，拟合在相邻反差 e_k = c_k − c_{k+1} 上做。

3. V128 的大 λ 极限：它就是一个常数径向加速度

C = -a (1 - r/lam + r^2/(2 lam^2) - ...) dPhi = -a mu/r + a mu/lam - a mu r/(2 lam^2) + ... └ GM 重标定 ┘ └ 常数势 ┘ └ 常数加速度 ┘ 精确零方向 零力 第一个可约束项 => Delta_varpi ∝ a/lam^2 => sigma_a ∝ lam^2 （第三册 J6 的代数原因）

这一步把第三册的「σα ∝ λ²」从数值观察升级为代数归约。响应系数 J 有两条独立路径：求积核，与 Bessel 闭式的 λ→∞ 解析极限，互验到 1.18e−15。

K2 为什么门限是 1e−6 而不是更紧：所用 Φeff 是 1PN 截断势，它给出的精确进动与 6πμ/(c²p) 之差本身是 O(μ/(c²a))。水星 ε=2.55e−8，实测残差 3.91e−8 ≈ 1.5ε——这正是应当看到的 2PN 高阶项，不是机核误差。把它当 bug 收紧门限，是拿物理当 bug 修。
K3 的意义：求积侧对 α 精确、闭式侧对 α 一阶，两条互不引用的数学路径一致到 2.50e−17。这不仅验证本册机核，也回头确认第三册的核没被算错。

5. 排除了什么 / 没排除什么

被挡住

  • 相对势深在 0.2–3 AU 内变化 > ~1e−12 的任何径向力
  • 在 3–8 AU 内变化 > ~6e−9 的任何径向力
  • 特别地：λ ≲ 3 AU 的 Yukawa（profile 变化是 O(α)，α 被压到 1e−12 量级）

没挡住

  • 任何整体幅度（C≡常数 精确零信息，无论多大）
  • 完全落在无采样区（<0.05 AU 或 >3e3 AU）的力：核恰好 0
  • 在 0.2–20 AU 内近似平坦的形状
  • 只在别的观测量留痕的效应（本册一个都没做）
「支撑外核恰好 0」不能读成「该区间不存在该力」。它只说明这个观测量的信息量在那里是零。没证明统一场论成立或失败；没证明第五力不存在；没排除非 Yukawa 形状；独立实验预言 0。

6. 四册链：从「新意」到「观测」到「形状无关」

第一册V129 积分 ≡ 已发表 I₁ 闭式（6.7e−58）
新意 0；λ→∞ 只是 GM 重标定
第二册V128 的 κr² 比自述更精确；Δϖ 一阶式比自述更松；外行星把边界推远 3.00 倍
第三册真实星历拟合：Δχ² 峰 0.44 不过门槛；7.9 dex 排除带两端无约束
第四册（本册）去掉形状假设：整体幅度精确零信息；大 λ 归约为常数加速度；形状变化压到 1e−12

四册不相加，每册只判「一个具体对象 against 一组具体数据」。统一场论作为研究纲领没有被攻破，也不会被一次计算攻破。被攻破的只能是具体模型。而 V128 这个具体模型的全部处境是：

它活在一个由形状定义的盲区里，而不是活在数据支持里。
