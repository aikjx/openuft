# G·ε₀ 第一性原理修正推导（算法联盟·最高权限整理）

> 本文档整理并实操验证了"Frenet-Serret 光速螺旋"公理体系下 `G·ε₀` 的正确本源表达式，
> 纠正了此前把经验数值巧合 `G·ε₀ ≈ α²/c²` 当作理论关系、并强行令 `β⊥ = α` 的错误。
> 配套可运行验证：`derive_Geps0_first_principles.py`（mpmath 120 位，EXIT=0，0 lint）。

## 1. 原错误根源（明确拒绝）

- ❌ 直接把经验数值巧合 `G·ε₀ ≈ α²/c²` 当作理论关系 —— 这是**循环代入经验公式**，不是从公理推导。
- ❌ 强行令螺旋横向速度比 `β⊥ = α` —— `α` 是电磁测量量，不能不加证明等价于螺旋几何速度比。
- ❌ 为修补上述错误引入人造常数 `𝒦 ≈ 0.99739` —— 这是错误的人造补丁，**不是本源拓扑常数**；
  其本质就是 `β⊥⁻²`（当 `β⊥=α` 时 `𝒦≈α⁻²` 的残余），应被消除。

## 2. 公理集合（严格起点）

1. 空间元总速率：`v⊥² + v∥² = c²`
2. Frenet-Serret 圆柱螺旋：`κ = rω²/c²`，`τ = hω²/c²`，且 `κ² + τ² = ω²/c²`
3. 横向速度 `v⊥ = rω`；轴向速度 `v∥ = hω`
4. 引力场 = 空间元横向加速度：`A = |Ẍ| = rω²`
5. 高斯引力通量：`Φ_A = ∮ A·dS = -4π G m`
6. 电磁动力学本体关系（场变换公理，非恒等式）：
   `- (4π G / α²) · dm/dt = q / ε₀`

## 3. 步骤1：螺旋几何内部严格推导（不植入任何经验常数）

```
v⊥ = rω,  v∥ = hω,  v⊥² + v∥² = c²
κ = rω²/c²  ⇒  r = κ c² / ω²
A = rω² = κ c²                              ... (1) 引力场强度 = 曲率 × c²
```
> 量纲校验：`[κ]=m⁻¹`，`[c²]=m²s⁻²` ⇒ `[A]=ms⁻²` ✔

引力通量（取特征球面 `S = 4π r²`）：
```
Φ_A = A·S = κ c² · 4π r² = -4π G m
⇒ κ c² r² = -G m                              ... (2)  [这是通量公理对源质量 m 的定义式]
```
代入 `r = v⊥/ω = β⊥ c / ω`，`r² = β⊥² c² / ω²`，并用 Frenet 恒等式 `1/ω² = 1/(c²(κ²+τ²))`：
```
κ β⊥² c⁴ / ω² = -G m
κ β⊥² c² · c²/ω² = -G m
β⊥² c² · κ/(κ²+τ²) = -G m                  ... (4) 引力-螺旋几何严格导出式
```
> **式(4) 无任何经验常数植入**：`β⊥` 是横向速度占光速比例，不能令其 = α。

## 4. 步骤2：引入电荷-质量动力学公理，解 G·ε₀

动力学变换方程（场本体假设，非几何推导）：
```
- (4π G / α²) · dm/dt = q / ε₀
⇒ G ε₀ = - (q α² / 4π) · dt/dm              ... (5) 动力学本源形式
```
> ⚠️ 式(5) 是**动力学耦合假设**，不是几何推导结果。`G·ε₀` 不能由纯 Frenet 螺旋几何直接算出。

对式(4) 求时间导数（质量随螺旋振荡 `m=m(t)`）：
```
β⊥² c² d/dt[ κ/(κ²+τ²) ] = -G dm/dt
dm/dt = - (β⊥² c² / G) · d/dt[ κ/(κ²+τ²) ]
```
代入式(5) 消去 `dm/dt`，两边约掉一个 `G`：
```
ε₀ = q α² / (4π β⊥² c²) · 1 / [ d/dt( κ/(κ²+τ²) ) ]      ... (6)
G ε₀ = q α² G / (4π c² β⊥²) · 1 / [ d/dt( κ/(κ²+τ²) ) ]  ... (7) 曲率-挠率完整本源形式
```
