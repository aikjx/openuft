## 一、逐项裁定

| 前置 | 内容 | 裁定 | 关键读数 |
|---|---|---|---|
| **P1** | 指定 O_TUFT 的 Lorentz 结构 | 缺自由度 | 框架内唯一手征自由度是一个复场 Omega 的 (g_L,g_R)，其 Lorentz 结构已由「手征」定义**锁死为 V-A 型** => 候选集压缩到 {V-A}。选 S/T/P = 引入与 Omega 无关的新算符 = **超出公设集的新输入** |
| **P2** | 存在两个独立振幅 | 缺自由度 | M = M_SM(V-A,g_SM) + M_TUFT(V-A,{g_L,g_R}) 是**同一算符的两种耦合**，非两个独立振幅；干涉为强度干涉 abs(g_SM+g_L)^2，相位只进总率 |
| **P3** | 干涉项含 cos(phi)/sin(phi) | 条件闭合 | 机器展开 2Re(M1* M2) = 2 rho g_SM [cos(phi)cos(delta) - sin(phi)sin(delta)]（delta = SM 内部实相对相位）=> 公式可给，但**宇称奇项要求 delta != 0**，而 delta 是物理输入、框架内无法确定 |
| **P4** | 固定 SM 参照口径 | 可闭合 | 自由中子 A = -0.1190 ± 0.0011，v/c = 1.274e-3；**v/c 与 sigma_A 之比 = 1.16（同量级）** => 口径选择直接改变 deltaA 的可比性，分支3 未声明口径 |
| **P5** | 排除整体相位 | 可闭合 | 在**加入 S 结构后**重算：13 个 alpha 下总率比值 1.0000~1.0000（改率），电子不对称漂移 **0.00e+00（逐位零）** => 该结论**对结构选择稳健** |

**宇称本征值对照**（P1-02）：

| 结构 | V | A | S | T | P |
|---|---|---|---|---|---|
| P 本征值 | +1 | -1 | +1 | -1 | -1 |
| 新增自由度 | 否 | 否 | **是** | **是** | **是** |
| beta 形状项 b(pE) | 1+pE | 1+pE | 1 | 1+3(pE)^2+3(pE)^3 | 1-pE |

=> P-even（S, V）无法单独产生宇称奇项；P-odd（A, T, P）可以。Omega 给的是 P-odd 手征结构，但两侧 abs(g_L)=abs(g_R) => **强度上仍对称**（A02）。

## 二、机器复现的两条基线

1. **单结构 + 整体相位 => deltaA 逐位零**（P2-02）：292 点（73 个 phi × 4 个 abs(g_L)），归一化角不对称最大漂移 **0.00e+00** => 独立确认 ADD-01R/B05，并为 P5 提供对照基线。
2. **分支3 的 c_I 被重新解释**（P3-03）：c_I 在本册口径下就是 g_SM sin(delta) 的重参数化 => 「c_I 无输入来源」的判定（F04）**依然成立**，但含义被明确为「SM 与 TUFT 振幅间的实相对相位」=> delta 一旦被指定，参数账 7→6 **可能**恢复。

## 三、唯一给出的真实可证伪判据（条件性）

在 **V-A + S** 假设下（eta = abs(C_S/C_V)^2 = 1）：

| 量 | 纯 V-A | V-A + S |
|---|---|---|
| 能谱形状 b(pE) | 1+pE | 1+(1+eta)pE |
| 端点区形状比值 | 1.000 | **1.26 ~ 1.90** |
| 电子不对称 A_e | 1.00 | **0.50** |

    联合判据 = 能谱形状 + 电子不对称

两者**相关但非同义**（前者约束 b 系数、后者约束混合权重）=> 比单看 A_e 更强。

> **前提**：该判据的前提是 **P1/P2 被人工指定**。若指定 T 或 P，形状项变为 1+3(pE)^2+3(pE)^3 或 1-pE => **判据随之改变**。本册不代替用户选择。

## 五、红线与诚实边界

1. **唯象层**：本册的 b(pE)、A_e 均为**唯象层**结果（忽略核形状因子与辐射修正），**不是完整 QFT 计算**。
2. **不代替建模决策**：P1/P2 属模型设计范畴，本册只证明框架内无自由度与指定后后果如何，**不替用户选 Lorentz 结构**。
3. **不拟合常数、不新增预言**：唯一给出的判据（S-01）明确标注前提为人工指定。
4. **P4 数值来源**：A = -0.1190 ± 0.0011、v/c = 1.274e-3 取公知量级；**本仓未登记逐条出处**，使用前须回查 PDG/PDReadset 原值并核对口径。
5. **与步 3 的衔接**：本册解释了步 3 的相位观测量不存在——**不是没算出来，是框架内没有这个自由度** => 执行序列中步 5 到步 3 的重排**不能**按原计划靠推导完成，须先做上述三条出路之一。
6. **有效域**：针对 ADD-01/ADD-02 现行参数化（lambda = alpha_s、三正瓣分区、rho = 0.0261）。若 O_TUFT 被指定为 T 或 P，本册第三节的判据表须重算。
