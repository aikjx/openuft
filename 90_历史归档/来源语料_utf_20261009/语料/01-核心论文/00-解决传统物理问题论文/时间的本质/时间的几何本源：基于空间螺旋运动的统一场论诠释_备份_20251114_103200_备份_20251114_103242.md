### A.1 时空统一方程的详细推导

考虑空间螺旋运动的参数化表示：

**r**(t) = R(cosωt, sinωt, 0) + ct(0, 0, 1)

其中，R为圆周运动半径，ω为角频率，c为光速。

空间点的位置矢量可以分解为圆周运动分量和直线运动分量：

**r**₁(t) = R(cosωt, sinωt, 0)
**r**₂(t) = ct(0, 0, 1)

对时间t求导，得到速度：

**v**₁(t) = d**r**₁/dt = -rω(sinωt, -cosωt, 0)
**v**₂(t) = d**r**₂/dt = c(0, 0, 1)

总速度为：

**v**(t) = **v**₁(t) + **v**₂(t) = -rω(sinωt, -cosωt, 0) + c(0, 0, 1)

速度的大小为：

|**v**| = √[(rω)² + c²]

由于ω = c/R（因为空间点的圆周运动速度等于光速），代入得到：

|**v**| = √[(c)² + c²] = c√2

这表明，空间点的总运动速度为c√2，但由于观察者只能测量到直线运动分量，因此表观光速为c。

s(t) = rωt

s(t) = R·(c/R)·t = ct

t = z/c = s/c

这表明，时间与空间位移成正比，比例系数为1/c。从几何角度来看，时间和空间是同一事物的不同表现形式，区别仅在于观察者的测量方向。
