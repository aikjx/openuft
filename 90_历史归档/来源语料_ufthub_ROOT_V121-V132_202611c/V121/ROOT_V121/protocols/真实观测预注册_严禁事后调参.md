# ROOT V121｜地球短作用程第五力的真实观测预注册协议（提案）

## 0. 适用范围

本协议用于独立检验固定的球对称、未屏蔽、线性 Yukawa 地球候选：

- 地球半径参考 \(R=6,371,000\) m（实际分析应使用一致的参考椭球和坐标系统）；
- 耦合强度 \(\alpha_Y=1/3\)，**不准在确认性分析时重新拟合**；
- 作用程 \(\ell=124,600\) m，**不准在确认性分析时重新拟合**；
- 密度形状因子：锁定 Fayet 2026 的简化解析径向密度剖面并对精细五层/径向地球模型做预注册系统误差敏感性；
- 外场模型 \(K(r)=\mu(1+\epsilon(r))\)。\(\mu=G_\infty M\) 可作为两种模型共同拟合的尺度 nuisance。

**本包没有获得及使用真实卫星激光测距、GPS 轨道观测、GRACE/GOCE 定轨数据或原始钟记录。模拟结果不用于声称模型被实验支持或排除。**

## 1. 数据和观测通道

候选数据：GOCE 历史梯度仪及定轨产品、GRACE/GRACE-FO 卫星间测距与 GNSS/加速度计产品、卫星激光测距、可追溯到 SI 的实验室/地面重力标准和钟频差。不同卫星高度是连续分布且轨道偏心率/倾角不同，不能把名义高度 250、400、500 km 直接视作同一球面对称 g(r) 的观测。

检索卫星产品时必须保留真实版本、GPS 时间系、EOP 与地球固连坐标、时间跨度、估计对流/电离层、非引力加速度校正、数据许可与 SHA256。

## 2. 预处理

1. 锁定地球参考框架（ITRF）、惯性历元、地球引力位定义、参考椭球和潮汐约定；
2. 使用公开可追溯的球谐基准并记录极/径向截断阶数，避免把新力信号错误吸收到高阶球谐参数；
3. 加入已知 GR 修正（Schwarzschild、地球自转相关项、必要时多体摄动）；
4. 加入高层大气阻力、太阳辐射压、地球反照、温度、姿态控制与非保守加速度；
5. 明确各观测量的模型映射（相位/距离/时间戳/梯度/频率），不得直接从公开的归一化后重力场产品当成“原始 K”；
6. 严格防止同一源数据在拟合和验证集中的重复使用。

## 3. 竞争模型和共同 nuisance

H0：GR/牛顿外场 + 非球形地球/时变场 + 合法校正，无指定 Yukawa。  
H1：H0 的动力学模型上叠加**固定** αY=1/3、ℓ=124.6 km 的 Yukawa（同一 source density、没有新调参）。

两模型用同样的设备时间漂移、参考 µ、轨道初始条件和先验误差模型，不能对 H1 私下增加额外自由度而与 H0 不公平比较。虽然有共同 nuisance，H0 与 H1 并不必然是简单的一个嵌套模型，不能机械将 Δχ² 当作一自由度 χ² 分布。

## 4. 似然与稳健性

对于观测残差 \(r_i=y_i-\mathcal M_i(\theta)\)，使用已冻结的协方差模型 \(C\)：

\[
-2\ln L =r^TC^{-1}r+\ln|C|+N\ln(2\pi).
\]

开展数据切片、冗余系统、留出高度与留出时期检验；报告条件数、数据利用率、系统误差膨胀系数、潜在非高斯性和模型误差。若真实 \(C\) 随模型改变，须计算差异并说明处理方法。

## 5. 跨通道强制检验

- 低轨径向力/高度比：K(250)/K(400)-1 预测 ≈ 5.7633×10^-4（理想简化球形）。
- 400 km 近圆轨道线性近似：S ≈ -0.013605，Δϖ ≈ 0.043182 rad/径向周期。真实地球需完整轨道积分及 Jn 扰动，不可直接比较裸数。
- 地表 → 400 km 纯额外引力势差：Δν/ν ≈ 7.6492×10^-14（附带 µ 参考标度），运动钟须联合时间膨胀和链路模型。
- 如果采用二次 f(R) 的完整弱场度规，时间势与空间势的标量项相反，领先阶透镜势相消；不能把轨道新力信号等量套用为光偏折增益。

如果 H1 无法在相同参数下解释不同通道，可在当前模型前提下否定 H1；反之 H1 表现良好也不构成四力统一证明，因为同一现象可能有其他物理来源。

## 6. 决定标准与停止规则

在获取数据**之前**冻结模型、推断方案和留出验证集。主要检验使用预定义广义似然/后验预测分布，结合残差时域和空间域检查；报告包含统计、系统与密度先验的置信区间。任何参数改变必须声明为新的“探索性版本”，不得把它并入先前确认性结果。

结果标记：

- CONSISTENT：指定误差模型下暂未排除；
- REJECTED：在预注册统计规则下，与数据显著冲突；
- INCONCLUSIVE：系统误差或识别性不足；
- INVALID：数据或模型违反预设假设。

“CONSISTENT”不是“发现第五力”；独立实测、交叉预测与排除替代物理解释是后续条件。
