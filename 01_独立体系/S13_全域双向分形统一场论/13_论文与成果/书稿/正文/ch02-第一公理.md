# 第2章 第一公理：对偶公理与 0/1 基点

## 2.1 导读

【 **大白话** :两千多年来，东方哲学反复说"万物负阴而抱阳"。本书把这句话数学化：存在一对不可再分的基元 $0$ 与 $1$，分别对应阴与阳；世界上一切物理量，都是某个"东西"和它的"阴阳反转"成对出现的。这一章就干这一件事——把"对偶"变成一个严格的数学公理。】

## 2.2 基元与对偶对

【 **定义 2.1（基元）** :存在一对不可再分的基元 $0$ 与 $1$（阴与阳）。"不可再分"的意思是：不存在更基本的对象能构造它们，它们自身就是构造的起点。】

【 **定义 2.2（对偶变换）** :对偶变换 $D$ 把任意对象映射为其阴阳反转，满足 $D^{2} = 1$（反转两次回到自身）。若 $D a = \bar{a}$，则称 $\left( a, \bar{a} \right)$ 为一个对偶对。】

【 **定义 2.3（对偶表示）** :一切物理量 $X$ 皆以对偶对 $\left( a, \bar{a} \right)$ 的形式存在；任何"单独的" $a$ 都不构成完整物理量——这正是"孤阴不生、独阳不长"的数学形式。】

## 2.3 对偶算子的矩阵实现

【 **最小实现** :在二维复空间 $\mathbb{C}^{2}$ 上，满足 $D^{2} = 1$（这里实际采用 $\Theta^{2} = -I$ 的辛版本，见注）的对偶算子最小实现为：

$$\Theta = \begin{pmatrix} 0 & -1 \\ 1 & 0 \end{pmatrix}, \qquad \Theta^{2} = -I$$

注：取 $\Theta^{2} = -I$ 而非 $+I$，是因为旋量自然的对偶周期是 $4$ 而非 $2$（见 §2.4），这正是本书与朴素"对偶=正负号"的区别。】

【 **电荷共轭** :对两分量旋量 $\Psi = \left( \psi_{0}, \psi_{1} \right)^{\mathsf{T}}$，阴阳反转即电荷共轭：

$$\Psi^{c} = \Theta\, \Psi^{*}$$】

## 2.4 对偶周期 4 与旋量 $4\pi$ 回归

【 **命题 2.1（对偶周期）** :由 $\Theta$ 为实矩阵，$ \left( \Psi^{c} \right)^{c} = \Theta \Theta^{*} \Psi = \Theta^{2}\Psi = -\Psi$。故对偶变换的周期为 $4$：

$$\Psi \;\to\; \Psi^{c} \;\to\; -\Psi \;\to\; -\Psi^{c} \;\to\; \Psi$$

四步一循环，恰与旋量在转动 $4\pi$ 后回归自身对应。】

【 **物理含义** :自旋 $1/2$ 粒子转一圈（$2\pi$）不回到自身，转两圈（$4\pi$）才回来——这是量子力学最著名的"怪事"之一。本书的对偶周期 $4$ 与它同构：阴阳反转两次得到负号，四次回到自身。符号学里"四象""四季""四方"的"四"，在这里找到了代数根源。】

## 2.5 奥卡姆判据

【 **为什么只设一对基元** :任何"三个以上基元"的理论都可以归约为两两对偶；任何"一个基元"的理论无法区分任何东西。所以最少且自洽的选择就是 $0/1$ 一对——一个对偶，不能再少。】

## 小结

【 **本章要点** :对偶公理 = 基元 $0/1$ + 对偶算子 $\Theta$ + 周期 $4$；它是全书第一块基石，后续的旋量方程、规范涌现、希格斯突破全部从这块基石长出来。】
