# 旋钮零空间定理（定理 D）：动力学可行性判据的形式化

**引擎**：`源码/旋钮零空间_定理D形式化.py`（零第三方，系统 python3.8）

## 一、定理 D

> 设动力学路线由第一性原理约束 E: Θ→R^m 刻画，Θ⊆R^n 为无量纲参数空间。在满足约束的点 θ* 处，剩余自由度 D = ker(J_E(θ*))，nullity_dyn = n − rank(J_E)。靶 q 是真预言候选 iff dq|_D = 0；否则 q 可被剩余自由度调节，判为拟合。

**证明**：由秩定理 / 隐函数定理，解集 E=0 在 θ* 附近的切空间即 ker(J_E)；q 局部为常数 ⇔ dq 在 ker(J_E) 上为零。

**与定理 A 的同构**：两条定理都是 nullity = n − rank：定理 A 数『能造出几个无量纲数』，定理 D 数『还剩几个可调旋钮』。

**分级**：[A]（秩定理，sympy 可验）

## 三、例 A：螺旋螺距（第一性原理无约束）

- 参数：$x=b/R$（n=1）
- 约束雅可比 $J_E$：$[0]$ ⇒ rank = 0
- $\operatorname{nullity}_{\rm dyn}$ = **1**
- 靶 $\alpha(x)$ = 1/sqrt(x^2+1)，$d\alpha/dx$ = `-x/(x**2 + 1)**(3/2)`
- 可调节？**True**

> nullity_dyn=1 ⇒ α 可被螺距 x 连续调节 ⇒ 拟合，非预言（定理 C 情形2）

## 四、例 B：对照（原理给非平凡约束）

- 约束 $E(x)=x-x_0$ ⇒ $J_E=[1]$ ⇒ rank = 1
- $\operatorname{nullity}_{\rm dyn}$ = **0**
- 固定后的靶 $\alpha$ = 1/sqrt(x0^2+1)

> nullity_dyn=0 ⇒ x 被固定 ⇒ α 被固定 ⇒ 真预言候选（仅示判据区分力，不声称该原理存在）

## 五、例 C：多参数（看 rank 而非约束条数）

- n=3, m=2 独立约束，$J_E$ = [[1, 1, 1], [1, -1, 0]]
- rank = 2 ⇒ $\operatorname{nullity}_{\rm dyn}$ = **1**

> rank=2 ⇒ nullity_dyn=1 ⇒ 仍有 1 个自由方向；判据看 rank 而非约束条数

## 六、总论

定理 D 把第62章的可行性判据从直观『旋钮计数』提升为秩定理：nullity_dyn = n − rank(J_E)，靶为真预言候选 iff dq|_ker(J_E)=0。计算确认：螺旋螺距例 rank(J_E)=0 ⇒ nullity_dyn=1 ⇒ α 可调（拟合）；对照例 rank=1 ⇒ nullity_dyn=0 ⇒ α 被固定（真预言候选）。判据可判定、可复算，且与定理 A 同构（nullity=n−rank）。诚实边界：定理 D 只判断『一条路线是否有预测力』，不产生任何关于世界的数值预言；它把『朴素螺旋动力学为何不成立』从定性断言升级为可计算的秩判定。
