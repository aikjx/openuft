## 七、C7 · UFE-1 变分推导求导精算与系数修复

### 问题发现

对 `07_统一场方程/02_变分推导.md` 逐步求导验证时，发现形式作用量系数与张量形式存在内部矛盾：

- 形式作用量写为 $S_{\rm EC}=\frac{1}{2\kappa^2}\int\epsilon_{abcd}R^{ab}\wedge e^c\wedge e^d$
- 张量形式写为 $S_{\rm EC}=\frac{1}{2\kappa^2}\int R\sqrt{-g}\,d^4x$（标准 Hilbert）

**精算**：$\epsilon_{abcd}R^{ab}\wedge e^c\wedge e^d = 2R\sqrt{-g}\,d^4x$（关键恒等式 $\epsilon_{ab\rho\sigma}\epsilon^{\mu\nu\rho\sigma}=2(\delta^a_\mu\delta^b_\nu-\delta^a_\nu\delta^b_\mu)$，且 $R^{\mu\nu}_{\nu\mu}=-R$）。故形式系数 $\frac{1}{2\kappa^2}$ 实际给出张量系数 $\frac{1}{\kappa^2}$，为标准值的 **2 倍**。

### 修复内容

| 文件 | 修改 |
|---|---|
| `00_统一场方程.md` | 形式作用量系数 $1/2\kappa^2 \to 1/4\kappa^2$ |
| `01_作用量与场内容.md` | 同上，并添加系数精算注释 |
| `02_变分推导.md` §1 | 第一步系数 $1/2\kappa^2\to1/4\kappa^2$；第二步分部积分负号→正号（P2: $(-1)^{p+1}=+1$）；第三步系数 $-1/\kappa^2\to+1/2\kappa^2$；第四步 $s_{ab}$ 定义修正为 $\delta S_m=\int s_{ab}\wedge\delta\omega$ |
| `02_变分推导.md` §2 | vierbein 变分系数同步修正；$\Lambda$ 项 $2\Lambda/3\kappa^2\to\Lambda/6\kappa^2$ |
| `验证脚本/verify_core.py` | A2.1 描述 $(1/2\kappa^2)\to(1/4\kappa^2)$ |
| `验证脚本/验证报告.md` | A2.1 备注更新 |

### 验证

- 最终场方程 (C)、(E) 形式不变，与标准 ECSK 结果一致
- `verify_core.py`：47 项 PASS 39 / FAIL 2 / INFO 6（FAIL 为已知否定性结果，非缺陷）
- `verify.py`：1 issue（解析器对括号路径的已知限制）

### 结论

原推导因**系数翻倍**与**分部积分符号错误**恰好相互抵消，最终场方程正确但中间步骤不可靠。修复后从作用量到场方程的链条数学自洽，可逐行复现。
