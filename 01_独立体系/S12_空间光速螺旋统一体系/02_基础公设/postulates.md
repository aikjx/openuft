# 02_基础公设 · 公设清单与区分边界

所属独立体系：[空间光速螺旋统一体系](../README.md)。

本文件把 `system.json` 中登记的四条公设展开为可审查条目，并写明本体系与相邻体系的分界。登记不等于审查通过：以下条目均为原文主张，尚无独立复现与观测检验记录。

[身份与基础前提](../system.json) · [来源](../sources.md) · [证据登记](../claims.csv) · [证伪标准](../11_证伪与反例/falsification_criteria.md)

## 1. 本体主张

本体系的本体是**空间本身的运动**：空间以光速 c 作螺旋运动，粒子是这一运动的参数化表现。由此把"运动学几何"提升为本体，而非把曲率/挠率只当作描述工具。这是它与纯数学框架的根本分界。

## 2. 公设清单

| 编号 | 名称 | 来源 | 数学形式 | 状态 |
|---|---|---|---|---|
| S12-A1 | 垂直原理 | 本体系原生 | `r(t)·v(t) = 0` | 已登记，未审查 |
| S12-A2 | 光速约束 | 本体系原生 | `v² = R²ω² + b² ≡ c²`，`m₀ ∝ 1/R` | 已登记，未审查 |
| S12-A3 | 螺旋参数化 | 本体系原生 | `r(t) = (R cosωt, R sinωt, bt)`，`b = ±√(c² − R²ω²)`，约束 `Rω ≤ c` | 已登记，未审查 |
| S12-A4 | 统一力方程 | **借用** `s02_light_speed_helix_force` | `F = dP/dt`，`P = m(c − v)` | 借用，不因本体系使用而获得独立证据 |

派生核心定理（由 A1–A3 推出，非独立公设）：空间光速螺旋三重奏 `κ² + τ² = (ω/c)²`，其中 `κ = Rω²/c²`、`τ = bω/c²`。该关系在参数化下为代数恒等式，其成立**不等于** A1–A3 的物理本体为真。

## 4. 适用域与尺度（原文主张，未核验）

- 尺度跨度：普朗克长度 `ℓ_P ≈ 1.616×10⁻³⁵ m`（螺旋最小半径）至宇宙视界 `R_H`（宇宙学常数截断）。
- 已声明不适用范围：原文第 10.3 节列出引力非重整化、宇宙学常数精确值、暗物质本质、暴胀子势能形式、黑洞熵精确系数（原文自述系数差 0.882 倍）、人工场实验验证为未解决项。

## 5. 可替代假设（替换其一即改变体系身份）

1. 去掉 A2 的"内部运动速度恒为 c"→ 退化为一般螺旋运动学，不再是本体系。
2. 把 A1 的垂直原理改为一般角度约束 → 螺旋结构不再由垂直性强制，TS1 推导链断裂。
3. 把 A4 替换为标准 `P = mv` → 四力分解结构消失，本体系失去动力学输入。
4. 把本体从"空间自身运动"改为"粒子内部运动" → 与 S10 类频率本体趋同，应重新评估是否仍为独立体系。

## 7. 第一性冲突登记（2026-09-15）

- **借用项引入的冲突**：S12-A4（借用 S02 的 `P = m(c − v)`、`F = dP/dt`）带入低速极限冲突：`v = 0` 时 `P = mc ≠ 0`，且 `m`、`c` 恒定时 `F = dP/dt = −ma`，与牛顿第二定律 `F = +ma` 反号。
- **本体—动力学接口未定义**：本体系另加 A2 本体约束 `v ≡ c`；若 `v` 指内部速度则 `P = m(c − v) ≡ 0`、`F ≡ 0`，与「用该方程分解四力」的初衷直接冲突。两对象（`c` 内部速度 vs `v` 外部速度）的数学身份与差运算均未声明。
- **影响与边界**：借用不带来独立证据，也不隔离借入方（S02）的缺陷。本冲突已与 S02 同步登记；另，S12-A1–A3 导出的三重奏 `κ²+τ²=(ω/c)²` 是代数恒等式，与本冲突无关。
- **修正建议**：明确 `P = m(c − v)` 中 `c` 与 `v` 的数学身份；若坚持 `v ≡ c`，须说明 `F ≡ 0` 与四力分解如何共存；并在 `falsification_criteria.md` 增补「动力学接口」阈值。
