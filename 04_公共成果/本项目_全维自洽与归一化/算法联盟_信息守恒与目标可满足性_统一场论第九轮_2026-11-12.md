## 一、范式转换：数参数 → 数比特，找候选 → 审目标

前八轮都在数「参数个数」（`p_eq / p_axiom / p_exp / p_disc`），并把「参数不灭」记录了八次：从方程层搬到公理层、实验层、标签层。本轮做两处转换：

1. **不再数参数，改数信息比特**。参数可以靠改名藏进定义常数、靠把观测值写进源码字面量而消失；但任何精确数值都必须有来源，比特藏不住。本册机算 46 项实验锚的精确有理表示长度，以及理论脚本里全部数值字面量的长度。
2. **不再找候选，改问目标本身是否可满足**。把「攻破统一场论」公理化为 7 条原子要求，在 `2^7 = 128` 个真值指派上穷举，求最小不可满足核（MUS）。若目标公理集不可满足，前八轮的 0 突破就不是候选不够好。

同时把前八轮散落的八个实例统一成一张**跨轮比特注入账**。

## 三、精确比特账：6 项输入，40 项输出

编码口径：把既约分数的分子与分母分别用二进制写出的长度，即 `bits(q) = bit_length(|分子|) + bit_length(分母)`。这是**固定编码下的描述长度上界**，不是 Kolmogorov 复杂度，单列 `BOUNDARY`。

46 项锚按 `kind` 精确分层：

| 层 | 条数 | 比特 | 说明 |
| --- | --- | --- | --- |
| 定义 / 派生输入 | **6**（C01、C02、C03、C04、C12、C13） | **711** | SI 定义值与派生常数 |
| 实测输出 | **40**（38 measured + 2 measured-bound） | **1523** | 待解释的实验事实 |
| 全部 | 46 | **2234** | 逐位自洽：`711 + 1523 = 2234` |

输出侧另报两种口径，防止口径决定判定：

| 口径 | 读数 |
| --- | --- |
| 独立编码 | **1523** bit |
| 通分共享分母（公分母 137 bit） | **5553** bit |
| 27 项带非零 sigma 的双侧锚（另带 sigma 561 bit） | **845** bit |

★通分口径**反而更大**：公分母只有 137 bit，但每个分子被放大后各自变长。三口径两两不同，本册不预设哪个更小，全部如实报出。

理论脚本按 AST 实际形态机读 `97` 个数值字面量，共 **3759 bit** 程序侧信息（脚本写 `134.9768e6` 时 AST 折成 `134976800.0`，照抄文档写法会漏，这是第七轮已付过的学费）。

## 四、★预设被数据推翻：输入侧已经装了答案

本册最初的判据预设是「输出信息超过输入 + 程序，故差额必须由外部注入」。机算结果把这个预设直接推翻：

`输入 711 + 程序 3759 = 4470 bit > 输出 1523 bit`

三口径缺口分别为 `−2947 / +1083 / −3625` bit，**两个为负**；最小 `−3625`、最大 `+1083`。也就是说信息量上**没有缺口**，程序侧塞的字面量足够覆盖全部输出。

按项目纪律，这种情况**不许放宽守卫、不许改文案硬撑**。本册换问一个更准确的问题：这些程序比特里，有多少是直接从观测抄来的？

答案在下节。这一处反转本身是本轮最有价值的产出之一：判据反噬到了自己，且改的是数据口径而不是结论文案。

## 五、信息复制：24 / 97 个字面量与观测逐位相等

机读理论脚本 `97` 个数值字面量，其中 **24 个与 46 项锚的 value 逐位精确相等**（`13` 个不同值），包括光速 `299792458`、`α⁻¹` 的 `137.035999177`、质子质量、W 质量观测值 `80.377`、水星进动 `42.98`、光偏折 `1.751` 等。

| 量 | 读数 |
| --- | --- |
| 按出现计复制比特 | **1446** bit |
| 按唯一值计复制比特 | **935** bit |
| 占程序侧信息 | **38.467678%** |
| 占 40 项输出信息 | **61.391989%** |

> **本册核心结论**：所谓「零自由参数」不是靠信息压缩达成的，而是把观测值搬进了源码字面量。第六轮判「7 条 GAQ 理论值是字面量、来源内无推导链」，本册在信息层给出独立佐证。

这是**参数不灭的第九个实例**：第一次不在方程、公理、实验层或标签层，而是落在**源码字面量**这一层。参数个数可以记为 0，但那 935 bit 的观测副本是实打实的输入。

## 六、目标公理集与最小不可满足核

把「攻破统一场论」公理化为 7 条原子要求：

| 原子 | 含义 |
| --- | --- |
| A1 | 单一机制描述四力 |
| A2 | 零自由参数 |
| A3 | 至少一条独立数值预言 |
| A4 | 与全部既有实验相容 |
| A5 | 不把实验值当输入 |
| A6 | 数学自洽 |
| A7 | 解释谱值为何如此 |

第 8 条约束 **I1** 由第五节的机读证据驱动：当观测副本被检测到（24 条 / 935 bit），`A2 ∧ A3 ∧ A5` 不可同时成立——独立数值的信息必须有来源，而现有零参数宣称的实例里它都来自观测副本。I1 不是写死的逻辑断言，删掉复制证据就会失活。

在 `128` 个真值指派与 `2^8 = 256` 个约束子集上穷举：

- 满足全部 8 条约束的构型 **0 个** ⇒ 目标公理集在本编码口径下**不可满足**。
- **最小不可满足核 = 4 条**：`[A2, A3, A5, I1]`；第 4 层恰有 `1` 个不可满足子集。
- 核内任删一条即变可满足（极小性成立）；逐条删除后的满足构型数为 `A1:0 / A2:1 / A3:1 / A4:0 / A5:1 / A6:0 / A7:0 / I1:1`，恰好核内四条非零 ⇒ 每条都承重。

★这与第四轮不同：第四轮审的是判据 C1–C4 的相容性与完备性，本册审的是**目标公理集自身的可满足性**，输出是精确的不可满足核。结论不是「又没找到候选」，而是「这四条要求放在一起就无解」。

## 八、控制组与三次反噬

控制组四个读数 `46 / 128 / 0 / 4`（锚数／指派数／满足构型数／MUS 大小）两两不同，三个对照读数均不等于基线。

阳性对照：把输出比特翻倍 ⇒ 缺口 `−2947 → −1424`，增量恰为 `1523` bit ⇒ 守恒式由数据驱动，不是恒真式。阴性对照：程序比特取 0 ⇒ 缺口 `812`，该侧恒绿，单列 `IDENTITY` 配 `NOT-ALL-GREEN`。

核验只在内存里替换源码单点、不写回仓库，每次只动一处：

| 变体 | 动的层 | 结果 | 假突破 | 报警守卫数 |
| --- | --- | --- | --- | --- |
| 令 I1 失活 | 守恒式 | `GATES-FAIL` | `0→1` | 11 |
| 忽略复制证据 | 数据层 | `GATES-FAIL` | `0→1` | 12 |
| 删掉 A5 不注入要求 | 公理层 | `GATES-FAIL` | `0→1` | 10 |

三次分别动逻辑、数据、公理三个不同层，都让目标从不可满足变成可满足 ⇒ 三处都承重。

## 十、诚实边界、红线与结论

- **BOUNDARY**：比特数是固定编码下的描述长度上界，不是 Kolmogorov 复杂度；换编码（连分数、共享前缀、算术编码）读数会变，三口径里两个缺口为负、一个为正。I1 是「现有零参数宣称都含观测副本」的**本地归纳 + 信息守恒弱式**，不是全称元物理定理。目标不可满足性依赖这一编码口径、这 46 项来料与仓库现有理论脚本。
- 本册不解释 κ/g 谱为何如此，「力的本质本源」未被回答；数学自洽 ≠ 实验证实，只产可算判决，不产新物理。四力 2/6、四力大统一 **0 条正确解**、独立实验预言 **0**，**不宣称攻破统一场论**。册子不占 RID、不入 README、不与任何审计卷相加。
- 跨卷脊梁独立佐证：r403 四力正确解 `0 条`、r404 接受 `0`；第五／六轮 0 命中、第七轮逃逸 0、第八族突破 0、本册满足构型 0。

**对「用尽一切方法攻破统一场论」的诚实回答**：本轮换了两个根本不同的角度，得到两条硬结论——

1. **信息层**：零自由参数不是靠压缩，是靠把观测值搬进源码字面量（24 / 97 个字面量逐位相等，935 bit 占输出 61.391989%）。预设的「输出超输入」被数据推翻，本册按数据改判据而非放宽守卫。
2. **逻辑层**：「攻破统一场论」的 7 条目标公理在 `128` 个真值指派上**不可满足**，最小不可满足核恰为 `[A2, A3, A5, I1]`。前八轮的 0 突破不是运气，也不是候选不够好。

**下一轮出口**：要越过守恒式，须给出程序侧不含任何观测副本、且能生出 40 项实测数值（1523 bit）的**真正可压缩生成机制**；这仍等价于一条带双侧误差棒、理论值落在其可判负区间之外的新实验读数。在这样一条读数出现之前，本册不替任何候选预支结论。
