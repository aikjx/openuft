## §2 来稿 §1 的 White 公式：对象错置（V6-a / V6-b / V6-c）

Călugăreanu–White 公式 `Lk = Tw + Wr` 的适用对象是 **ribbon（闭曲线 + 加框）**。单条无加框闭曲线**没有 Lk**——其 Gauss 自积分给的是 `Wr`，不是 `Lk`。来稿 §1 先用双曲线 Gauss 积分定义 `Lk`，随后直接对「单根闭合扭结场线」写 `Lk = Tw + Wr`，中间缺一个 framing 声明，而 `Tw` 的定义本身依赖加框。

**检验**：平面圆（`Wr = 0` 解析）+ 显式加框 `u(t) = cos(nt)N + sin(nt)B`，ribbon 边界取 `曲线 + εu`，数值算 `Lk`：

| 加框圈数 n | 解析 `Lk = Tw + Wr` | 数值 `Lk` | 偏差 | 最佳 ε |
|---|---|---|---|---|
| 0 | 0 | 0.00000 | 0.00e+00 | 0.05 |
| 1 | +1 | 1.00020 | 2.00e-04 | 0.20 |
| 2 | +2 | 2.00074 | 7.40e-04 | 0.20 |

- **PASS（V6-a）**：加框补齐后 `Lk = Tw + Wr` 数值闭合。⇒ 来稿 §1 的缺陷是**形式错置**（缺声明），不是物理错误，可修复。这是本册唯一的建设性正面项。
- **BOUNDARY（V6-b）**：`Tw ∝ ∮τ ds` 隐含「加框沿曲线闭合」条件。`n = 0.5`（非整数）时 `u(2π) = −u(0)`，加框不闭合，离散后首末点间出现跨越整个加框的伪段，数值 `Lk = −86.541423`（既非整数也非 ±0.5，且随 ε/N 剧烈漂移，无收敛趋势）。另：来稿未处理 `κ → 0` 处 Frenet 标架奇异（须 Bishop 标架，V18.5 V5-i-5 已登记）。
- **FAIL（V6-c）**：「单根闭合扭结场线的 `Lk = Tw + Wr`」对象错置。射程：仅形式错置；但若加框来源不在体系内给出，`Tw` 与 `Wr` 的分配就是外加自由度，来稿 §1「拓扑重排只能在 Tw 与 Wr 之间转移」将失去约束内容。

## §3 来稿 §1「Wr 对应曲率 κ 的全局积分」—— 硬错（V6-d，FAIL）

`Writhe` 是 Gauss 双积分（自环绕）；`∫κ ds` 是总曲率。决定性反例：**平面圆**。

| 量 | 数值 | 说明 |
|---|---|---|
| `Wr`（Gauss 自积分） | `0.000000e+00` | 平面圆解析值 = 0 |
| `∫κ ds`（总曲率） | `6.283185` | 解析值 `2π` |
| `∫τ ds` | `0.000000e+00` | 平面圆 `τ ≡ 0` |

`Wr = 0` 而 `∫κ ds = 2π ≠ 0` ⇒ 该对应被直接否证。

**连带后果**：`Wr` 是非局域量，故「局域地在 Tw 与 Wr 之间转移」叙事不成立；再叠加 §2 的加框未定，`Tw/Wr` 分配本身任意 ⇒ 来稿 §1 的「环绕数守恒」不产生任何可观测约束。

## §4 来稿 §4/§5 对「开式横螺旋」赋 `Lk = 0`（V6-e，FAIL）

来稿 §4 称光子场线是「开式横螺旋，不存在闭合扭结」，§5 表给 `Lk = 0`、自旋 `s = 1`。但 `Lk`/`Wr` 只对闭合曲线（或闭合加框）有定义。取同一条开螺旋段，两种 closure：

| closure 方式 | Writhe |
|---|---|
| A：末点直线连回首点 | `-0.535013` |
| B：抬高 8 单位绕远路返回 | `-0.551346` |
| 差值 | `0.016333` |

同一条开螺旋给出不同的 `Wr` ⇒ `Wr`（进而 `Lk`）依赖 closure 选取，对开式曲线**没有良定义值**。§5 判据表的「光子 `Lk = 0` ⇒ 玻色」一格在数学上不成立。若要保留，必须先把光子场线闭合化并声明 closure（代价：closure 是外加约定）。

## §6 4π 判据只有 Z₂ 容量（V6-g，FAIL）

| 自旋标签 s | 来稿 §5 的旋转行为 |
|---|---|
| 0 | 2π |
| 1/2 | 4π |
| 1 | 2π |

不同旋转行为的取值数 = **2**，待区分的自旋标签数 = **3**。映射**非单射**：「2π」同时对应 `s = 0` 与 `s = 1`。

信息容量：Z₂ 提供 `1.000000000` bit，区分 3 个标签需 `1.584962501` bit，**缺口 `0.584962501` bit**。

这与 V18.4 V4-a（体系最大离散群 = Z₂，`sign Lk`）合流：2π/4π 二分恰是 Z₂，只能区分半整数/整数，**不能给出具体 s 值**。⇒ **§5 表格第三列（自旋值）不由第二列（旋转行为）推出**；给光子 `s = 1` 属外加字典。

比 V18.5 §8(3)（「连续 H 如何离散化为自旋量子数仍缺映射」，S03-C0011）更上游：即使补齐该映射，Z₂ 的容量也不够区分 `s = 0` 与 `s = 1`。

## §7 前置锚点「拓扑质量 m′ 来自全局挠率积分」（V6-h，FAIL）

V18.5 V5 已判 `∫τ ds` 无量纲。本册给出**更强**的证据：它是**尺度不变量**。

| 缩放 λ | 曲率 κ | 挠率 τ | `∫τ ds` | 与 λ=1 之差 |
|---|---|---|---|---|

## §8 来稿 §6「湮灭必须场线重联」的信息含量（V6-i / V6-j）

### 8.1 「必须重联」是重言式（BOUNDARY）

| 主张 | 是否重言式 | GAQ 特有内容 |

### 8.2 临界能量阈值不可证伪（FAIL）

`e⁺e⁻ → 2γ` 的实测阈值由能量守恒定为 `2m_e c² = 1.021998 MeV`。来稿未给出 `E_c` 的任何表达式，只称其「对应」质能条件。

| 任意目标阈值 | 目标值 (MeV) | `E_c` 取值 | 结果 |
|---|---|---|---|
| `1×m_e c²` | `5.109989e-01` | `5.109989e-01` | 可拟合 |
| `2×m_e c²`（实测） | `1.021998e+00` | `1.021998e+00` | 可拟合 |
| 100 GeV | `1.022000e+05` | `1.022000e+05` | 可拟合 |

**FAIL（V6-j）**：自由参数 1 个（`E_c`）、约束 1 个（等于实测阈值）⇒ 余量 0，但 `E_c` 无独立预测值，对**任意**观测阈值恒可事后赋值 ⇒ 不可证伪。二难：`E_c = 2m_e c²` 则恒等重述（零新内容）；`E_c ≠ 2m_e c²` 则与实验矛盾。与 V18.1 P1、V18.2 V2-e 的失败模式同构（恒可拟合）。

## §9 复核 V18.5 §9：修正后守恒律在相变点退化（V6-k，FAIL）

V18.5 §9 判分支三（孤子拓扑相变守恒律）可行的理由是「相变前后可观测量的差异」。本册用 V18.5 §3.4 修正后的守恒律复核该差异是否存在。

修正后守恒律：`m′ v⊥ = m v∥`（V18.5 V5-c-B，机器零，量纲闭合）。相变：类时孤子（`m > 0, m′ > 0`）→ 光子零模。

| 相变端点赋值 | 守恒律 `m′v⊥ = m v∥` 的解 |
|---|---|
| `m=1, m′=1` | 非退化：`v⊥/v∥ = m/m′`（有约束） |
| `m=1, m′=0` | `0 = m·v∥` ⇒ `v∥ = 0`（光子轴向速率 0，与传播矛盾） |
| `m=0, m′=1` | `m′·v⊥ = 0` ⇒ `v⊥ = 0`（退化为直线，无螺旋） |
| `m=0, m′=0` | `0 = 0`：退化为空恒等式，无约束 |

只要相变伴随「光子侧 `m = 0` 或 `m′ = 0`」（这正是零模的定义），守恒律在相变点必然退化为 `0 = 0` 或给出与光子传播矛盾的解。

**FAIL（V6-k）**：V18.5 §9 判给分支三的「独立可判决量」**不存在**。**（本册对既有裁决的修订，已登记）**

⇒ 分支三仍可选，但可行输入不是「相变守恒律差异」，而是 **V6-f 的手性符号**（可算）。

## §10 其余条目

**BOUNDARY（V6-l）· 口径冲突（须裁决）**：来稿 §3 写「交换使 `Lk` 改变 `±1`」，而 V18.4 V4-a 登记 `Lk ∈ ½ℤ`（一次交换 = 辫群生成元 σ₁，两次交换才给出 Hopf link `Lk = ±1`）。

| 单次交换 ΔLk | 相位约定 | 单次交换相位 | 两次交换相位 | 判定 |
|---|---|---|---|---|
| 0.5 | `φ = 2π·Lk` | π | 2π ≡ 0 | 自洽 |
| 0.5 | `φ = π·Lk` | π/2 | π | 不自洽 |
| 1.0 | `φ = 2π·Lk` | 2π ≡ 0 | 4π ≡ 0 | 不自洽（费米侧失效） |
| 1.0 | `φ = π·Lk` | π | 2π ≡ 0 | 自洽 |

两套组合都自洽，差别是 `Lk` 的**缩放约定**：来稿的 `Lk` 恰是 V18.4 口径的 2 倍。**不判 FAIL**——物理结论（费米交换相位 π）在两套约定下都成立。但跨册引用 `Lk` 数值时必须声明口径，否则系数错 2 倍。

**INFO（V6-m）· 来稿 §2「不需要引入狄拉克旋量」**：
1. 不可证伪——「旋量只是描述二重复盖拓扑的代数工具」无法被任何观测否证；
2. 体系内来源缺失——旋量需要 Clifford 代数 `Cl(1,3)`（4×4 矩阵代数，非交换），而 V18.4 V4-d 已判 `κ`、`τ` 是标量场量、无方向指标 ⇒ 无非交换结构来源；V4-a 已判体系最大离散群仅 Z₂ ⇒ Z₂ 装不下 `Cl(1,3)`。

不判 FAIL（属元理论陈述，不构成可算命题），但**不得作为「已导出」登记**。
