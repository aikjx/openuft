既有报告把场方程 `□u = −(8πG/c²)ρ·exp(−u)` 线性化为 `□δu = −(8πG/c²)δρ`，
**相当于把 `exp(−u)` 当 1，丢掉了背景 ρ₀ 的贡献**。

严格线性化（保留 `exp(−u)`，本报告已符号验证）：

```
□δu + m²·δu = ...      m² = (8πG/c²)·ρ₀·e^{−u₀}   （ρ₀ ≠ 0 时非零）
```

⇒ 方程是**有质量 Klein-Gordon**，**不是**无质量波动方程 ⇒ **存在色散** ⇒ 传播模与 GR **有增量**。
