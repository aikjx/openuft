## 〇、一句话结论

r423 §7 留下一条明确的 OPEN：

> 只有在 V65 六类 provenance 之外、经预注册冻结、且过 r421 C1–C4 四门的候选，才值得启动完整升级审计。**在此之前「继续」不产生新的 W3 候选。**

r428 把这条 OPEN 的现状钉成 `W3 四候选 0/4`——但那仍是**观测事实**（"实测没找到"），不是**定理**（"为什么找不到"）。本册补上后半句：

1. **来源分类穷举**：体系内全部数值输出来源 = 六类 provenance（FIT/TOY/MATH/SCHEME/DEFINITION/ISSUE，承 r423）+ SYSTEM-DERIVED（承 r421 C2「由体系其他式子反解」）= **7 类**，每类以 9 个可机核布尔特征刻画，四门禁只读特征、不读类名 ⇒ **非循环**。
2. **不可达定理（T1）**：r421 四门禁 C1–C4 对七类逐类机核，**无一类 passed=True** ⇒ 体系内 W3 候选可达数 = **0**。r421/r423/r428 的 7 个实测候选逐条归类、逐个败门，与 r428 实测 `0/4` **逐位对表**。
3. **指派熵外部性（T2）**：承 r413，4! = 24 种指派全自洽，锁定 1 种须 `log2(24) = 4.5849625007... bits` 外部输入（本册 Decimal 复算逐位一致）；"形状固定 + 指派派生"分支因此封死。
4. **唯一出口定价（T4）**：突破只能来自体系外预注册来料，须同时满足 **E1 预注册冻结 / E2 provenance 在六类之外 / E3 过 C1–C4 / E4 双锚一致**；体系内候选四项全不满足，外生阳性对照四项全满足（仅证逻辑可行，不宣称已存在）。

**关键区分**：`0/4` 从「取样不足的观测」升级为「来源穷举 + 门禁封死的结构性下界」。**不否证体系外新来料过门的可能性**（阳性对照证明门禁非死），**不否证统一场论研究方向**，**不宣称发现候选**。

## 二、靶点：把「继续不产生候选」变成定理

## 三、来源分类学（D 节）：七类穷举 + 非循环判别特征

体系内全部数值输出来源分为 **7 类**：

| `FIT` | 数值来自对观测的拟合 | r423 B03 |

| `MATH` | 纯数学恒等式 / 已知物理链 | r423 B04 |

每类以 **9 个布尔特征**刻画：`quantitative / fit / derived / definition / toy / unfitted_path / used_in_fit / planck_ok / particle_ok`。四门禁只读这些特征、**不读类名**，故分类判据不依赖「不可达」结论——这是**非循环性**的关键（G-D2/G-S2）。

## 六、定理 T2（核心，FAIL）：指派熵外部性封死「形状固定+指派派生」

承 r413 §3：4 个力强度需 4 条独立约束；`α_i = c_i·f(θ)` 只给 1 条结构关系（≠数值约束）；`4! = 24` 种项↔四力指派全部自洽，锁定 1 种须外部输入：

\[
H_{\text{assign}} = \log_2(24) = 4.5849625007211561814537\ \text{bits}
\]

本册 Decimal 60 位复算与 r413 逐位一致（G-B4，误差 < 1e-30）。现有公设集派生该熵为 0 ⇒ 缺 4.585 bits ⇒「形状固定 + 指派派生」分支不能过 C2/C3。r413 §5 已判出路 C 为伪 +1、`LU6-NOT-LANDABLE`；本册从**可达性侧**给出独立复算。

## 七、定理 T3（核心，FAIL）：0/4 是定理而非观测偶然

r421 语料扫描 0 命中、r423 V65 执行层 11/11 全败、r428 四候选 0/4 —— 三者此前都是「实测未找到」。本册给出统一解释：任何体系内输出必属七类之一，而七类在四门禁上全败，**故 0/4 是结构性下界，不是取样不足**。精确边界：本册**不否证**体系外新来料过门的可能性（阳性对照证明门禁非死）。
