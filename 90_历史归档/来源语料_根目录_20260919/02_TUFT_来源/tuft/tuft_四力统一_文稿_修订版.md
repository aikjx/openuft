## 一、统一规范群的几何本源（修订）

**修订（代数 · 关键）**：原稿写

```
T^λ_μν = T^(0)_μν + T^i_μν σ^i/2 + T^a_μν λ^a/2
```

该式在**类型上不成立**：`σ^i/2` 是 2×2、`λ^a/2` 是 3×3、`T^(0)` 是 1×1 —— 三者维数不同，
矩阵加法无定义。正确的"多分量"结构是**张量积**：

```
内禀空间 = (1 ⊕ 2) ⊗ 3    （U(1) 单态 ⊕ SU(2) 二重态，再 ⊗ SU(3) 三重态）
⇒ 单代多重态： q_L: 2⊗3 = 6 ; u_R/d_R: 1⊗3 = 3 ; l_L: 2 ; e_R/ν_R: 1
⇒ 2⊗3 + 3 + 3 + 2 + 1 = 15（SM，不含 ν_R），加 ν_R 为 16
```

**诚实标注**：维数 15/16 与标准模型一致 ✓ —— 但这是**重述标准模型表示论**，
**不构成**"从挠率导出该结构"。原稿的"全部相互作用都是同一挠率张量的投影"在修正后
退化为"标准模型的表示论分类"。

**修订（引力行）**：原稿表格把引力的"挠率内禀代数"写成"曲率联络 Γ^λ_{μν}"：
1. 联络 Γ **不是**曲率（R 才是曲率）；
2. Γ 不是张量、不是李代数值；
3. 局部洛伦兹 SO(1,3) 的代数张成的是**自旋联络 ω^{ab}_μ**（取值 so(1,3)，6 个生成元）。

应改为：引力 → `so(1,3)`（3 转动 + 3 boost）。

## 二、电弱统一（修订 · 核心）

**修订 1（混合角不是几何定值）**：

| 来源 | 数值 |
|---|---|
| 3:1 生成元数之比（自然读数 g′²/g² = 1/3） | **1/4 = 0.250** |
| SU(5) 归一化树图统一值 | 3/8 = 0.375 |
| 实测 sin²θ_W(M_Z)（MS-bar） | 0.23122 |

⇒ 偏差 **8.12%**。而由 1-loop SM 跑动：sin²θ_W = 1/4 出现在 **3.68 TeV**、
= 3/8 出现在 **1.03e13 GeV** —— **都不在 M_Z**。
故"维度比 3:1 决定 0.231"是把 **IR 测量值**当作 **UV 几何定值**（尺度混淆 + 循环论证）。

**修订 2（挠率比无构造）**：`tanθ_W = T^(Y)/T^(3)` 删去。`tanθ_W = g′/g` 是**定义**。

**修订 3（v 的量纲）**：`⟨T⟩ = v ≈ 246 GeV` 不成立：
[T] = L⁻¹（挠率/联络量纲），[v] = M（能量）。若声明挠率无量纲，则 v 只能由
实验给出：`v = (√2 G_F)^(-1/2) = 246.22 GeV`，属**外部输入**。

**保留（成立）**：A/Z 混合矩阵正交（det=1）、`m_W/m_Z = cosθ_W`（偏差 1.2e-06）、
`m_Z = √(g²+g′²)v/2`、`m_γ = 0` —— 均为标准电弱理论的重述。

## 三、主丛统一与"最终作用量"（修订 · 结构）

**修订（群结构）**：原稿的结构群 `G = SO(1,3) × U(1) × SU(2) × SU(3)` 是**笛卡尔直积**：

- 维数：6 + 1 + 3 + 8 = **18**（对比 SU(5) 单群 dim = 24）；
- 直积意味着**四个独立的规范耦合常数**，群论上**不能减少参数、不能统一**；
- 真正的统一需要单群/semi-simple 群（SU(5)、SO(10)、E6）或先把 U(1)_Y 嵌入 SU(2)。

⇒ 原稿的"最终归一"在群论层面**不成立**：G 与 "SM + GR 的直积" 完全相同。

**修订（联络）**：`𝒜_μ = Γ_μ + A_μ + W^i_μτ_i + G^a_μT_a` 四项属于不同李代数
（仿射联络 / u(1) / su(2) / su(3)），相加前须取直和并指定表示；且 Γ 是仿射联络（非张量），
不能与规范势混加。可修补为直和丛上的分块对角联络 —— 但其物理内容 = 四个独立理论。

**修订（作用量 · 关键）**：`S_TUFT = ∫√-g[ R/2κ − ¼F² − ¼W² − ¼G² + ψ̄(iγD−m)ψ + L_Ω ]`
是**教科书标准模型 + 广义相对论作用量**逐项照搬，**无任何 TUFT 特有项**：

- 无挠率动能项 `T²`；
- 无曲率平方项 `R²`/`R_{μν}²`；
- 无非最小耦合项；
- 无 `Ω`（几何权重场）的作用量。

⇒ 应如实写：**TUFT 采用 SM+GR 作用量**，不声称从中"导出"。

**修订（自由度）**：既然作用量与 SM 逐项相同，则自由参数同为
**19 个**（g1,g2,g3 / θ_QCD / m_H,v / 9 个 Yukawa / CKM 4），
无一被几何量替代 ⇒ §7 第 4 条"参数内生"不成立。

**修订（发散）**：power counting：[G] = M⁻² ⇒ 引力相互作用为**维度 5 的不可重整化算子**；
4D EH+SM 不可重整化是已知结果。原稿"几何算符自带普朗克截断"未给任何构造 ⇒ 无支撑。

## 四、耦合常数统一与 GUT 汇聚（修订 · 可判决）

**保留（成立）**：`g1 = √(5/3)·e/cosθ_W`（SU(5) 归一化标准式）；
M_Z 处 `g1=0.46143 < g2=0.65174 < g3=1.21823` —— **单调序与原文一致** ✓。

**修订（"由维度决定"）**：只有**单调序**被数据支持。3 点 2 参数幂律拟合得指数 0.464
（`g ∝ √dim` 应为 0.5）；若强读 `g ∝ √dim`（比值 1 : 1.732 : 2.828），
实测为 1 : 1.412 : 2.640（偏差 −18.4% / −6.6%）⇒ "由维度定量决定"无定式（自由度仅 1）。

**修订（GUT 汇聚 · 数值否证）**：

```
1-loop SM 两两交点： 1.031e13 GeV (1/α=42.41)
                     2.439e14 GeV (1/α=40.35)
                     9.822e16 GeV (1/α=47.03)     -> "三角形"，不是一点
1e16 GeV 处： 1/α = (37.92, 45.88, 44.48)  ->  α 最大/最小 = 1.210（21.0% 分散）
对照 MSSM：  1e16.30 / 1e16.33 / 1e16.37 GeV，1/α = 24.33 / 24.26 / 24.31  -> 汇聚
```

⇒ **"g1(M_GUT)=g2(M_GUT)=g3(M_GUT)"在 SM 中不成立**；汇聚是**超对称**的结果，
而 TUFT 的作用量（=SM）继承的是**不汇聚**。应删除 §4.2 的汇聚论断。

## 七、诚实边界与结论

1. **群论**：结构群是**直积**（18 维），不是单群 ⇒ "四大相互作用完整统一/最终归一"**不成立**；
2. **代数**：挠率多分量"相加"是类型错误；正确结构（张量积）恰是标准模型表示论；
3. **参数**：sin²θ_W 的"几何定值"差 8.1%；v = 246 GeV 量纲不符且为外部输入；
4. **能标**：SM 三耦合在 1e16 GeV **不汇聚**（21% 分散）；汇聚需超对称而非几何；
5. **作用量**：所谓 TUFT 最终拉格朗日量 = SM + GR 逐字照搬，**零 TUFT 特有项**；
6. **可证伪性**：由 (5)，本分册不产生任何区别于 SM+GR 的预言；
7. **红线**："四力统一"目前是 **SM+GR 的重新命名（re-labelling）**，
   在本分册中作为"几何归一"的**解析推导未成立**。

> 解冻条件（若要恢复"统一"主张）：(1) 群选择原理（为何是这些群）；
> (2) 挠率分量 → 规范耦合的**构造映射**；(3) 至少一个 TUFT 特有项 + 一个可判决的定量预言。
