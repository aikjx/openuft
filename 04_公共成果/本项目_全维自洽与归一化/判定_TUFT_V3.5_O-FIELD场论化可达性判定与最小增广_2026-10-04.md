## 一、单点根因（本册最硬的可算判据）

| 方程 | 时间导数阶 | 空间导数阶 |
|---|---|---|
| ω = c√(κ²+τ²) | 0 | 0 |
| κ²+τ² = (ω/v)²（三重奏） | 0 | 0 |
| E = (ℏc/2)(κ+τ) | 0 | 0 |
| F = −∇E | **0** | 1 |
| L = 1/√(κ²+τ²)（力程） | 0 | 0 |
| v_obs = c·τ/√(κ²+τ²)（群包络） | 0 | 0 |

⇒ **全部是代数/几何关系**：最高时间导数阶 = **0** ⇒ 不能给初值演化、不能定义传播、不能量子化。

**H-02（无色散）**：ω = c√(κ²+τ²) 中的 κ,τ 是**几何量**，不含波数 k ⇒ ∂ω/∂k = 0 ⇒ 无相速度、无群速度、**无光锥**。
（须区分：v_obs = c·τ/√(κ²+τ²) 是**群包络速度**（几何投影），不是色散关系给出的群速度。）

## 三、依赖图与最小增广

**拓扑序（机器验证无环）**：`W6 场变换 → W1 协变性 → W2 作用量 → W4 传播子 → W3 规范群 → W5 量子化`

⇒ **W2（作用量）是枢纽**：之前是结构层（标架、协变），之后是推论层（传播子、量子化）。

**充要性反例**：去掉 W2 ⇒ W4 / W5 / W3 共 **3 项**不可达 ⇒ W2 必要。

**H-05 收窄结论**：最小增广 **= 2 条**（① W2 作用量/场方程；② W3 规范群来源），而非 6 条。
对照分支③对 Ω 的定价（4 条：A1–A4）⇒ **两条线的瓶颈同指向 A1/W2 动力学**。

**H-06（两条增广性质不同，不可混谈）**：
- **W2** 属于「**缺方程**」——理论没写完，补齐是**工作**（虽需物理洞见）；
- **W3** 属于「**缺信息**」——R14 已证结拓扑不载规范量子数，补它等于**引入外部物理输入**。
⇒ 前者是「未完成」，后者是「当前框架内不可达」⇒ **闭合代价不可比**。
