## 一、暴胀子的几何身份（修订）

**修订 1（势能形状 · 关键）**：`V(Ω)=V₀Ω(1−Ω)` 的 V″=−2V₀<0 ⇒

- 在 (0,1) 上**凹**，唯一驻点 Ω=1/2 是**极大值**（V=V₀/4）；
- Ω=0、Ω=1 只是**边界零点**，且 V′(0)=V₀≠0 ⇒ **不是驻点**；
- 真正的"双势阱"应为 `V=λ(Ω²−Ω_DE²)²` 型（Ω_DE 为极小）。

**修订 2（暗能量基底）**：`V′(0.6875)=+0.375V₀≠0`、`V″<0` ⇒ Ω_DE=0.6875
**既非驻点也非极小值**；按 3HΩ̇=−V′>0，场会**远离**该点奔向 Ω=1。
若要把 Ω_DE 作为亚稳态真空，必须更换势能形式。

**修订 3（量纲）**：`L_Ω=½g^{μν}∂_μΩ∂_νΩ−V(Ω)`，若 Ω 无量纲则动能项量纲 M²、
势能项 M⁴ —— **不匹配**。应写 `½M_P²(∂Ω)²`（或令 φ=M_PΩ）；
这也决定了下文 κ 的单位约定（κ 应为无量纲，普朗克单位下 =1）。

**修订 4（"内生"）**：势能引入自由参数 **V₀**；前册作用量只有 `L_Ω` 占位符，
故"内生"仅指符号位置，实为**新增输入**。

## 二、慢滚动力学（修订 · 核心）

**修订 1（滚动方向）**：从 Ω_i=0.05 出发，`V′=V₀(1−2Ω)=+0.9V₀>0` ⇒ `3HΩ̇=−V′<0` ⇒
**Ω 减小、朝向 Ω=0**，**永远到不了 0.5**。要"滚向极大值"需从 Ω>0.5 一侧出发（V′<0）。
数值实测（RK4, dt=1e-3）：Ω 自 0.05 单调降至 0，并于 **t=0.3380** 越界到 **Ω=−0.0002**
（Ω̇=−0.2969），**累计 e-folds 仅 0.0421**。

**修订 2（e-folds）**：

```
∫_{0.05}^{0.45} Omega(1-Omega)/(1-2Omega) dOmega = 0.224653   ->  N = 0.2247 * kappa
kappa = 1（其代码取值）        ->  N = 0.22      （原文称 60    -> 差 267 倍）
kappa = 267.1                  ->  N = 60
```

**修订 3（谱指数与互斥 · 关键）**：

```
1 - n_s = (1/kappa) [ 3 (V'/V)^2 + 4/(Omega(1-Omega)) ] ;  Om=0.45 时括号 = 16.651
kappa = 474.4   ->  n_s = 0.9649   （但与 N=60 所需的 267.1 互斥，差 1.78 倍）
N (1-n_s) :  模型 0.2247*16.651 = 3.741   vs   观测 60*0.0351 = 2.106
```

> 因 N∝κ、(1−n_s)∝1/κ，其**乘积与 κ 无关** ⇒ **不存在任何 κ 使"N≈60"与"n_s≈0.965"同时成立**。
> 原文两处"✅ 吻合"彼此矛盾。

**修订 4（自由度审计）**：N 与 n_s 中 **V₀ 完全相消**（幂次齐次）。
故唯一的势能标度参数无法调整二者；模型的可观测预言只由 (Ω_i, Ω_f, κ) 决定，
而 κ 是物理常数（=1）⇒ **2 个观测量、0 个可调尺度参数**。

**修订 5（慢滚条件）**：ε(0.05)=**179.5**/κ、η(0.05)=−42.1/κ。
κ=1 时 ε≫1 ⇒ **慢滚在起点即失效（暴胀无法启动）**；要 ε(0.05)<1 需 κ>179.5。

## 三、原初扰动谱（修订）

**保留（成立）**：`P_R=κH²/(8π²ε)`、`P_T=2κH²/π²`、`r=16ε`、`n_s=1−6ε+2η` —— 公式结构标准 ✓。

**修订 1（r）**：κ=1（代码取值）⇒ ε(0.45)=0.0816、**r=1.306**（超 BICEP/Keck r<0.036 **36 倍**，模型被排除）；
κ=475.7 ⇒ ε=1.72e-4、r=0.00275（这才≈原文所称"传统 0.003"）。
即原文的 r 结论依赖于**被隐式选定的巨大 κ**。

**修订 2（F_T 量纲）**：`F_T=1+⟨T⟩²/K_sat²`：`[⟨T⟩]=L⁻¹`、`[K_sat]=L⁻²` ⇒
`[⟨T⟩²/K_sat²]=L²` **不是无量纲因子** ⇒ 公式非法。

**修订 3（F_T 数值）**：取第一册 `⟨T⟩=v=246 GeV=1.2467e18 m⁻¹`、`K_sat=3.8281e69 m⁻²`：
`⟨T⟩²/K_sat² = 1.061e-103` ⇒ **F_T = 1.000…0（小数点后 102 位）**，增强完全不存在。
而要让 r 从 0.00275 升到 0.01~0.05 需 F_T=**3.64~18.21** ⇒ 与公式值相差 98~102 个数量级。

**修订 4（代码 F_T=1.5）**：与 §3.2 公式（≈1）和所需值（3.6~18.2）**三处互斥**。

**修订 5（"传统 vs TUFT"）**：0.003 并非传统模型预言，而是**本模型自身**在 κ=475.7 时的 16ε；
故原文的对比属**同一模型的自我对比**（把同一数值一半归"传统"、一半靠未计算的 F_T 归"TUFT"）。

## 四、原初挠率扰动的手性（修订）

**修订 1（能标矛盾 · 关键）**：原稿称"弱相互作用的手性破缺使 T_L≠T_R"。
但暴胀/重加热能标 `T_reh≈1e14 GeV`，电弱对称破缺在 `≈100 GeV` ⇒ **差 12 个数量级**。
暴胀期间电弱对称性**未破缺**，不存在可继承的"弱作用手性破缺"。

**修订 2（Π_T 无推导）**：全篇未给左手/右手张量模式的模式方程、源项或视界外演化；
`Π_T≈0.05~0.15` 是直接给定值 ⇒ 不可计算、不可证伪。

**保留（成立）**：`纯黎曼几何 ⇒ Π_T=0` ✓（宇称守恒，左右手谱相等）。

**保留（可判决通道）**：非零 Π_T 会在 CMB 产生 **TB/EB 关联谱**，原理上可测（LiteBIRD/CMB-S4）；
但需给出定量（幅度 vs r、vs 能标），当前为零。

**跨册一致性**：前册已判"TUFT 作用量无挠率动能项 ⇒ 挠率为代数约束、真空挠率为零"（B1.9）。
若无独立挠率动力学，原初挠率涨落亦无独立自由度，Π_T 更无从产生。

## 五、暴胀结束与重加热（修订）

**修订 1（结束条件）**：原稿称"滚到 Ω≈0.5 极大值即结束"——方向反了；
且 Ω=1/2 处 ε→∞（慢滚参数发散），需要的是场**越过**该点进入另一侧，而非"到达"。

**修订 2（T_reh）**：`T_reh≈(V₀/g_*)^{1/4}` 量纲正确 ✓，但标准公式含数值因子
`T_reh≈(30V₀/(π²g_*))^{1/4}`；且 1e14 GeV 是**直接给定值**（V₀ 未定），构成循环。
数值：T_reh=1e14 GeV ⇒ V₀=g_*T_reh⁴=**1.068e58 GeV⁴**，而 M_P⁴=**2.222e76 GeV⁴** ⇒
V₀/M_P⁴=**4.80e-19**（需 1e-19 量级调节，属暴胀常见的微调问题，应如实登记）。

**修订 3（粒子生成）**：无衰变率 Γ、无耦合项系数、无产率、无暗物质丰度
（观测 Ω_dm=0.2645 无法复现）⇒ "曲率-挠率形变凝结为粒子"是命名而非机制。

## 八、诚实边界与结论

1. **公式骨架可用**（标准慢滚），但**具体的势能、参数与实现全部不成立**：
   方向反（Ω 朝 0 滚）、N=0.22（非 60）、n_s=−1160（非 0.965）、r=4308（非 0.03）；
2. **两个"✅ 吻合"互斥**：N 与 (1−n_s) 的乘积与 κ 无关（模型 3.741 vs 观测 2.106），
   且 V₀ 完全相消 ⇒ 模型无可调尺度参数；
3. **势能结构缺陷**：非双势阱、Ω_DE 非极小、Ω∉[0,1] 时无下界（H²<0）；
4. **增强因子 F_T 量纲非法**且数值为 1+1e-103（增强不存在）；
5. **手性来源在能标上不成立**（差 12 个数量级），Π_T 无推导；
6. **代码不可运行**（SyntaxError + math domain error），"预期输出"四条全错；
7. **红线**：本册**不产生**任何可检验的、区别于标准慢滚暴胀的定量预言；
   唯一原理上可判决的两项（Π_T、暗物质非粒子）**当前无定量**。

> 解冻条件：(1) 正则归一的势能（含真极小/亚稳态）；(2) 可同时复现 (N, n_s) 的参数选择；
> (3) F_T 的构造性来源（量纲合法且>1）；(4) Π_T 的模式方程与幅度。
