## 第零层：三元一体超复数公理（融合 M3 + S5）

来源：M3《0·1·∞ 宇宙本源》的"0·1·∞ 三元一体"，S5 手册的"0·1·∞ 三元一体超复数公理"。

**公理 0（本源三元）**：宇宙的本源运算由三元构成——
- `0`：真空 / 无 / 奇点消解态
- `1`：单元 / 存在 / 基态粒子
- `∞`：无限 / 演化 / 螺旋展开

三者构成超复数基 `{1, ε, ε⁻¹}`，其中 `ε` 为螺旋相位的生成元，满足 `ε·ε⁻¹ = 1`，并自然导出 Frenet 标架的 T/N/B 三元正交结构。

> **融合注**：本层为"哲学-数学"起点，不直接进入物理量推导，但为 κ/τ 的对偶（曲率-挠率）与复数曲率 `Ξ=κ+iτ` 提供代数母题。

## 第一层：螺旋世界线公理（融合 S1/S2/S3/S4）

来源：S1/V1 三条公理 → S2/V2 三条公理 → S3 UNUFT 零阶公理 + S4 公理一。

**公理 I（螺旋世界线公理）**：宇宙中一切基本实体的世界线，都是三维 Frenet-Serret 空间中**常曲率 κ、常挠率 τ** 的圆柱螺旋线。
- 曲率 κ 对应空间弯曲 → 引力、粒子性、质量（S1/S2/S3/S4 一致）
- 挠率 τ 对应空间扭转 → 电磁、波动性、自旋、手征（一致）
- 复曲率 `Ξ = κ + iτ` 为对偶不变量（S1/V1 引入，S2/S3 沿用）

**公理 II（瞬时光速公理）**：基本实体在任意时刻的瞬时切向速度恒等于真空光速 c；宏观亚光速运动只是螺旋轴线方向的平均速度，内禀环绕速度恒为 c，满足 `(ωR)² + v_z² = c²`（S1/S2/S4 一致；S3 表述为"本体运动速度恒为 c"）。

> **融合统一表述**：把 S3 的"零阶公理"与 S4 的"公理一+公理二"视为同一对公理的两种措辞，统一为 **公理 I + 公理 II**。

## 第二层：主恒等式与导出公理（融合 S2/S3 严格化成果）

来源：S2/V2 的 SymPy 符号证明 + S3 UNUFT 主恒等式。

**公理 III（主恒等式公理，机器零验证）**：对常 κ、常 τ 圆柱螺旋，角频率 ω 与 c 满足

$$ \kappa^{2} + \tau^{2} = \left(\frac{\omega}{c}\right)^{2} $$

其中 `κ = ρ/(ρ²+b²)`，`τ = b/(ρ²+b²)`，`ω` 为角频率，`ρ` 螺旋半径，`b` 螺距参数（S1/S2 推导，S3 采纳为母方程）。

**派生公理（质量-频率公理）**：由主恒等式直接得质量

$$ m = \frac{\hbar}{c}\sqrt{\kappa^{2}+\tau^{2}} = \frac{\hbar\omega}{c^{2}} $$

——这是 S1/S2/S3/S4 共同接受的质量几何本源（S4 写作 `m₀c/ℏ` 形式，等价）。
