# 第25章 常数统一：电荷量子化与参数对接（拼图四推进）

## 导读（大白话）

"常数统一"是全书最后一块拼图：精细结构常数 $\alpha \approx 1/137$ 和宇宙学常数 $\Lambda$ 能不能从理论内部推出来？本章给出**部分但真实**的推进，并诚实划清边界：

1. **对接程序闭环**：实验常数（$m_{W}, m_{Z}, m_{H}, \alpha$）→ 框架参数（$v, \tilde{g}, \tilde{g}', \tilde{\kappa}$）——理论不是"装常数"，而是"常数与参数一一对应"，任何多余自由度都被钉死；
2. **电荷量子化**：为什么所有观测粒子的电荷是 $\pm 1/3$ 的整数倍？答案：色单态条件 + 超荷谱结构（机器枚举验证：所有介子/重子电荷为整数）；
3. **$\sin^{2}\theta_{W}$ 树级候选预言**：$\mathbb{CP}^{2}$ 稳定子嵌入给出 $\sin^{2}\theta_{W} = 1/4$——与 $SU(5)$ 大统一的 $3/8$ 不同、可区分；
4. **$\Lambda$ 的诚实边界**：量纲谱容纳 $\Lambda \sim \ell^{-2}$ 型项，但观测值与 $\ell_{P}^{-2}$ 差距 $10^{122}$（自然性危机）——**如实 OPEN，不假装解决**。

## 25.1 问题陈述：α 与 Λ

精细结构常数 $\alpha = e^{2}/4\pi \approx 1/137.036$（电磁力强度）与宇宙学常数 $\Lambda \approx 10^{-52}\,\mathrm{m}^{-2}$（暗能量密度）是标准模型和宇宙学中两个最"赤裸"的数字——没有任何理论从第一性原理推出它们的量级。拼图四的目标：无自由参数解释。

## 25.2 参数对接程序（定理 25.1）

【 **定理 25.1（对接闭环，树级）** :实验输入 $\left\{ m_{W}, m_{Z}, m_{H}, \alpha, \sin^{2}\theta_{W} \right\}$ 通过第17/21章关系唯一确定框架参数：

$$\tilde{g} = \frac{e}{\sin\theta_{W}}, \quad \tilde{g}' = \frac{e}{\cos\theta_{W}}, \quad v = \frac{2m_{W}}{\tilde{g}}, \quad \tilde{\kappa} = \left( \frac{m_{H}}{2\sqrt{2}\,v} \right)^{2}$$

数值（验证A 实测，PDG 2024 值）：$e = 0.302822$；$\tilde{g} = 0.629760$、$\tilde{g}' = 0.345372$；$v = 255.26\,\mathrm{GeV}$（标准 $v \approx 246$ GeV，差来自 $\alpha$ 的跑动，树级）；$\tilde{\kappa} = 0.030095$。回代 $m_{Z} = 91.671$ GeV vs 实验 $91.188$（差 $0.53\%$ = 标度跑动效应）。**意义**：理论的所有无量纲参数被实验常数完全钉死——无隐藏自由度（与第18章"四观测四未知"一致）；完整对接需重整化跑动（OPEN）。】

## 25.3 电荷量子化（定理 25.2）

【 **定理 25.2（色单态电荷整数性）** :设夸克电荷为 $+2/3, -1/3$（$Q = T_{3} + Y$，第22章超荷表），则任何色单态组合（$k$ 个夸克 $+$ $l$ 个反夸克，$k \equiv l \pmod 3$，第23章判据）的电荷为整数。验证B 机器枚举：全部 4 种介子（$uū, ud̄, dū, dd̄$）电荷 $0, +1, -1, 0$；全部 8 种重子电荷 $+2, +1, +1, 0, +1, 0, 0, -1$——**全为整数，无一例外**。】

【 **物理读出** :可观测强子必带整数电荷（质子 $+1$、中子 $0$、π⁺ $+1$…）——这是"色单态原则"在电荷轴上的投影。单个夸克携带分数电荷（永远不能直接观测），与色禁闭一致。】

## 25.4 电荷分数化的来源（定理 25.3）

【 **定理 25.3（分数化因子）** :分数化因子 $1/3$ = 色表示维数 $3$ 的倒数。色三重态上的超荷谱由 $\lambda_{8} = \mathrm{diag}\left( 1, 1, -2 \right)/\sqrt{3}$ 给出（第23章验证D），配合弱同位旋 $T_{3} = \pm 1/2$，全部夸克电荷落在 $\pm 1/3$ 步长上：

$$u_{L}:\, \tfrac{1}{2} + \tfrac{1}{6} = \tfrac{2}{3}, \qquad d_{L}:\, -\tfrac{1}{2} + \tfrac{1}{6} = -\tfrac{1}{3}, \qquad u_{R}:\, \tfrac{2}{3}, \qquad d_{R}:\, -\tfrac{1}{3}$$

验证C 实测七场全部命中。**判定**：电荷量子化（$\pm 1/3$ 步长 + 色单态整数性）是观测事实、反常消去（第22章）与色表示结构（第23章）的共同结果——框架把三者统一为一条几何线：$\mathbb{CP}^{2}$ 的 $\lambda_{8}$ 谱。注意：这是结构解释，不是 $\alpha$ 量级的推导。】

## 25.5 sin²θ_W 的树级候选预言（定理 25.4）

【 **定理 25.4（稳定子嵌入预言，候选）** :若色 $SU(3)$ 与电弱耦合在 $\mathbb{CP}^{2}$ 稳定子嵌入下统一（同一耦合 $g_{3}$），则 $U(1)$ 块由 $\lambda_{8}/\left( 2\sqrt{3} \right)$ 归一化（使 $Q_{L}$ 的超荷 $= 1/6$），给出：

$$\frac{\tilde{g}'}{\tilde{g}} = \frac{1}{\sqrt{3}}, \qquad \sin^{2}\theta_{W} = \frac{\tilde{g}'^{2}}{\tilde{g}^{2} + \tilde{g}'^{2}} = \frac{1}{4} = 0.250$$

验证D 实测：$\sin^{2}\theta_{W} = 0.250000$ vs 实验（$\overline{\mathrm{MS}}$）$0.23122$——树级差 $8.1\%$。**与 $SU(5)$ 大统一的 $3/8 = 0.375$ 不同，是可区分的几何预言**。完整验证需把统一尺度跑动到电弱尺度（重整化，OPEN）——标注为候选，不冒充已验。】

## 25.6 Λ 的诚实边界

量纲谱（第17章）容纳 $\Lambda \sim \ell^{-2}$ 型项。若 $\ell = \ell_{P}$，则 $\Lambda\ell_{P}^{2} = O\left( 1 \right)$，而观测 $\Lambda\ell_{P}^{2} \approx 2.9\times10^{-122}$（验证E 实测）——**差距 122 个数量级**。这是著名的宇宙学常数自然性危机。本框架诚实结论：**$\Lambda$ 的量级无解释，OPEN**。量纲谱给出"$\Lambda$ 是 $\ell^{-2}$ 型量"的结构地位，但不解释其数值之小——不假装解决。
