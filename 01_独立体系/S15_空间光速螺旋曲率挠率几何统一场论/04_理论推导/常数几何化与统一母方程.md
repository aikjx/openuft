# 04 理论推导：常数几何化与统一母方程

本文件整理来源语料的核心公式。每条均标注评级（claim 编号 / evidence level），
并显式说明哪些是代数恒等式、哪些是循环自证、哪些是方向性猜测。

诚实总纲：来源把 CODATA 常数预先代入螺旋参数 ρ=ħ/(mc)，再用这些参数反推同一常数，
因此「零误差复算」是重参数化而非独立预言。

---

## 1 质量几何化

派生式（来源主用）：

```
m = ħ τ (α² + 1) / (α c) = ħ / (ρ c)
```

等价母式（来源另一写法，未证明何者第一性，见 C0007）：

```
m = ħ κ / (c cosθ)
```

- 复算：代入 CODATA 的 m_e、ħ、c、α 可精确还原 m_e（相对误差 < 1e-12）。
- 诚实边界（C0006）：输入即输出，循环自证。

## 2 普朗克常数几何化

```
ħ = m c ρ
```

- 由 ρ=ħ/(mc) 反解，复算 ħ 属循环（C0008）。

## 3 元电荷几何化

```
e = √(4π ε₀ ħ c · κ/τ)
```

- 含 ε₀ 的修正版；复算 e 属循环（C0009）。
- 来源早期版 e=√(4π ħ c κ/τ) 缺 ε₀，已在修复版补入。

## 4 真空介电常数几何化

```
ε₀ = τ / (4π c² κ)
```

- 由 κ/τ 比定义 ε₀，复算 ε₀ 属循环（C0010）。

## 5 引力常数几何化（存在多版本矛盾）

来源至少给出以下不等价写法：

```
(a) G = c³ / (2 ħ (κ_P² + τ_P²))          # 依赖 l_P=√(ħG/c³)，循环
(b) G = 2 c³ τ_P / κ_P²
(c) G = c³ τ_P² / (2 ħ κ_P²)
(d) G = 8π c³ τ_P / (3 κ_P²)
(e) G = α² μ₀                               # 来源自承量纲非法（C0011）
```

- (e) 来源在《本源几何化物理_修复版.md》第 2 节明确称「量纲非法、废弃」。
- (a) 右端含 l_P=√(ħG/c³)，故以 G 定义 G，循环。
- 五版本数值互不等价，无版本被证明为第一性（C0011，evidence C，falsified 中量纲非法的那条）。

## 6 宇宙学常数与哈勃常数

```
Λ = κ_vac² / 3        # 也与 Λ = κ_vac² 并存（未统一，见 C0012）
H₀ = c √Λ / 3
```

- 几何重写；量级未与观测独立闭合（C0012/C0013，evidence O）。

## 7 含挠率场方程（统一母方程形式）

来源把四力与物质写成一项：

```
G_μν + Λ g_μν
  = (c⁴/8πG) [ (κ/τ) F_EM
              + κτ F_weak
              + (κ² + τ²) F_strong
              + (ħ/c²) ∇∇(κ + τ)
              + T_matter ]
```

黎曼-嘉当（含挠率）场方程：

```
R_μν − ½ R g_μν + Λ g_μν + T_torsion = (8πG/c⁴) Σ α_i T^(i)
```

- 几何重写框架（C0014，evidence U / C0015，evidence O）；未给可区分的新预言。

## 8 其它几何化（方向性）

- 暗物质密度：ρ_dm(r) = ħc (κ_vac + Δκ(r))³ / c²（C0016，O）
- 几何不确定性原理：Δκ·Δτ ≥ (ħ/8π) (κ²+τ²)/(ρ²+b²)（C0017，O）
- 信息熵/全息：S = (k_B/4 l_P²) ∫ (κτ/(κ²+τ²)) dA（C0018，O）

---

## 结论

核心可独立成立者：§1 的质量派生式与 §3–§4 的常数式，作为「以 CODATA 反算自身」的代数恒等变换（残差机器零）。
核心未成立者：G 的第一性导出（多版本矛盾+量纲非法+循环）、统一母方程的可检验预言（缺独立输出）、尺度分层数值一致性（跨文件矛盾）。
