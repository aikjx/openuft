## 中文LaTeX公式作图解决方案

### 环境要求
- **Python**: 3.7+（推荐3.9+）
- **依赖库**: `matplotlib`, `numpy`
- **LaTeX发行版**: 安装支持中文的LaTeX宏包（`xeCJK`或`ctex`）
  - Windows: MiKTeX或TeX Live
  - macOS: MacTeX
  - Linux: `texlive-full`或包含中文支持的TeX Live

### 安装配置
1. 安装依赖：`pip install matplotlib numpy`
2. 下载`latex_chinese_plot.py`脚本
3. 脚本自动检测系统中文字体，如需指定字体，修改脚本中的`chinese_fonts`字典：

## 常见问题及解决方案

## 示例：1D谐振子公式图

### 提示词填写
```python
"""
Generate a publication-ready, vector-based physics visualization in Python for the equation/phenomenon:
'1D Harmonic Oscillator Energy Levels and Wavefunctions'

Objective: To accurately depict the 1D harmonic oscillator potential, energy levels, and probability densities.

Key Specifications:
1.  **Physics & Mathematical Accuracy:**
    *   Equation Representation: V(x) = 1/2 mω²x², ψ_n(x) ∝ H_n(√(mω/ħ)x) * exp(-mωx²/2ħ)
    *   Physical Parameters: m=1.67e-27 kg, ħ=1.054e-34 J s, ω=1e15 rad/s
    *   Data Range: x from -2 to 2 (normalized units), energy levels for n=0, 1

2.  **Clarity & Interpretability:**
    *   Axes Labels: r'$\text{Position } (x) \, [\text{arb. units}]$', r'$\text{Energy / Probability Density} \, [\text{arb. units}]$'

3.  **Aesthetics & Professionalism:**
    *   Plotting Style: 'seaborn-v0_8-paper' with minimal grid lines
    *   Color Palette: 'viridis' for potential, 'colorblind' for wavefunctions
    *   Line Styles: Solid for potential, dashed for wavefunctions

5.  **Technical Output:**
    *   Format: PNG and SVG
    *   Figure Size: 3.5 inches (single column)

7.  **Annotations & Emphasis:**
    *   Add horizontal lines for energy levels E_n = (n + 1/2)ħω
    *   Label energy levels and annotate potential and probability densities

**Specific Plot Type:**
*   **Function Plot:** Plot potential energy V(x) and probability densities |ψ_n(x)|² for n=0 and n=1

**Preferred Libraries:**
*   Core: `matplotlib`, `numpy`
*   Enhancements: `seaborn`, `sympy`
"""
```

### 生成代码（核心部分）

```python
import matplotlib.pyplot as plt
import numpy as np
import seaborn as sns
from matplotlib import rc

# 物理参数
m = 1.67e-27  # kg (质子质量)
hbar_val = 1.0545718e-34  # J s
omega = 1e15  # rad/s
alpha = m * omega / hbar_val

# 势能函数
V = lambda x: 0.5 * m * omega**2 * x**2

# 波函数和能量水平
from scipy.special import hermite
def get_psi(n):
    Hn = hermite(n)
    coeff = (alpha / np.pi)**0.25
    return coeff * Hn(np.sqrt(alpha) * x) * np.exp(-alpha * x**2 / 2)

def get_energy(n):
    return (n + 0.5) * hbar_val * omega

# 数值范围
x = np.linspace(-3 * np.sqrt(hbar_val / (m * omega)), 3 * np.sqrt(hbar_val / (m * omega)), 1000)

# 配置matplotlib
plt.style.use('seaborn-v0_8-paper')
rc('font', **{'family': 'serif', 'serif': ['Times New Roman']})
rc('text', usetex=True)

# 绘图
fig, ax = plt.subplots(figsize=(3.5, 3.5))

# 绘制势能
ax.plot(x, V(x) / 1e-18, color='gray', linestyle='-', linewidth=1.5, label=r'$V(x) = \frac{1}{2} m \omega^2 x^2$')

# 绘制能量水平和概率密度
for n in [0, 1]:
    E = get_energy(n)
    ax.axhline(E / 1e-18, color='k', linestyle=':' if n == 0 else '-.', linewidth=1.0, 
               label=r'$E_{} = {}\hbar\omega$'.format(n, '\frac{1}{2}' if n == 0 else '\frac{3}{2}'))
    
    # 绘制概率密度
    psi = get_psi(n)
    max_psi_sq = max(abs(psi)**2 for n in [0, 1])
    scale = (max(V(x))/1e-18) * 0.5 / max_psi_sq
    ax.plot(x, abs(psi)**2 * scale, color='cornflowerblue' if n == 0 else 'darkorange', 
            linestyle='--', linewidth=1.5, label=r'$|\psi_{}(x)|^2$'.format(n))

# 添加标注和标签
ax.set_xlabel(r'$\text{Position } (x) \, [\text{arb. units}]$', fontsize=11)
ax.set_ylabel(r'$\text{Energy / Probability Density} \, [\text{arb. units}]$', fontsize=11)
ax.legend(loc='upper right', fontsize=9)
ax.grid(False)

# 保存图片
plt.tight_layout()
plt.savefig('harmonic_oscillator.png', dpi=600, bbox_inches='tight')
plt.savefig('harmonic_oscillator.svg', bbox_inches='tight')
```
