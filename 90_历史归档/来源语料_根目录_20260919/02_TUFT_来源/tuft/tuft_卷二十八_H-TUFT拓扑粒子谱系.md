# 第 2 章 螺旋挠率丛同伦分类体系：孤子拓扑量子数全集

## 2.1 主丛与孤子
螺旋挠率主丛 `P(M,G)`，底流形 M（4 维），结构群 G（规范群）。孤子 = 丛上局域稳定拓扑截面。

命题：`{Q_hel, n_w, n_s, n_c, χ}` 唯一确定粒子类型；同拓扑类下不同高阶模态 → 三代。

## 2.3 信息量核查（关键）
SM 粒子需**六轴**标识：`(SU3 色, SU2 弱, U1 Y, 自旋, 手征, 代)`。H-TUFT 只有**五轴**：
```
所需 log2(色3 × 弱2 × Y6 × 自旋2 × 手征2 × 代3) ≈ 9.6 bits
提供 log2(Q_hel? × n_w? × n_s2 × n_c3 × χ2)          ≈ 6.2 bits（若 Q_hel 仅承载弱）
```
⇒ **信息量不足 ~3.4 bits**（与 R14「Lk 仅 1.58 bits vs 所需 3.32 bits，缺口 1.74 bits」同源问题在 H-TUFT 重现）。

## 2.4 诚实边界（第 2 章）
1. **标记→粒子的对应是字典（④级）**：如「`Q_hel=1, n_w=1, n_s=1, n_c=0, χ=-1 ⇒ 电子`」是**人为约定**，无方程从丛拓扑强制它。本卷未闭合 O-KNOTMAP，只把单层字典换成 5 维字典。
2. **Q_hel 角色冲突**：§4 把「代」交给模态 n，§2 又把 Q_hel 当同伦荷（守恒量不可激发）—— Q_hel 同时承担「弱同位旋」与「代数」两角色，分工未厘清。
3. **n_s 表述矛盾**：§2 称 `n_s`=自旋（轴向螺距），§4 称半整数自旋对应「纤维内半周期缠绕」，但 §10 引擎用 `n_s=1`（**整数**）——**整数 n_s 与半整数自旋不兼容**。
4. **分数电荷未由 n_w 导出**：`n_w` 是整数绕数，只能给整数电荷（§8.3）。
5. **规范群 G 外生**：G=SU(3)×SU(2)×U(1) 是前提，未从丛拓扑导出（R11 G1–G5 缺口）。「仅靠孤子同伦类生成全部粒子」其实**仍假设了 SM 规范群**。

|---|---|---|
| 1 | 基态 | e, u, d |
| 2 | 第一激发 | μ, s, c |

## 4.3 稳定性判据的缺失（诚实核心）

# 第 5 章 质量生成：拓扑能隙与螺距耦合，替代 Higgs VEV·Yukawa

## 5.1 质量公式（原稿）
```
m = m_top(Q_hel, n_s) + Δm_mode(n)
  = 0.21·Q_hel² + 0.08·n_s + κ(πn)²
```
`m_top`：孤子基础拓扑能隙（同伦类决定）；`Δm_mode(n)`：第 n 代模态激发能。
声称：质量来自孤子截面曲率-挠率自束缚能，而非 VEV×Yukawa；Yukawa 是低能有效近似，底层是丛截面拓扑交叠积分：
```
Y_ij ∝ ∫_P Ψ_i† ∧ F ∧ Ψ_j
```

## 5.2 实跑与量级失败（2026-09-30）
取 `Q_hel=1, n_s=1, κ=0.0035, α=0.07`：
| 代 | 总质量 | 比值（总） | 比值（仅模态） |
|---|---|---|---|
| 1 | 0.3245 | 1.000 | 1 |
| 2 | 0.4282 | 1.319 | 4 |
| 3 | 0.6009 | 1.852 | 9 |

对比实测 `m_e:m_μ:m_τ = 1 : 206.77 : 3477.2`：
- **总比偏差 157×（gen2）/ 1878×（gen3）**；
- **仅模态比 1:4:9 偏差 52×/386×**。
⇒ 「拓扑能隙 + π²n² 模态」**无法产生 SM 质量层级**（与 v30「拓扑代数数族被排除，~500× 缺口需 Yukawa」一致）。

## 5.3 形式度歧义（及卷二十八补的修复）
原稿 `Y_ij ∝ ∫_P Ψ_i† ∧ F ∧ Ψ_j`：`Ψ` 是丛截面（0-形式/旋量），`F` 是 2-形式，`Ψ†∧F∧Ψ` 是 **2-形式非标量**，P 为 4 维+丛，积分**无定义**。
**卷二十八补修复**：改为孤子截面 L² 内积（良定义）
```
Y_ij = ∫_P Ψ_i† Ψ_j dμ_P                       （0-形式截面内积 = 标量）
Y_ij = ∫_P Ψ_i† (i D_A·g) Ψ_j dμ_P             （曲率加权用厄米算符内积，非楔积）
```

## 5.4 诚实边界（第 5 章）
1. **质量公式无 GeV 标度**：`0.21·Q²+0.08·n_s` 无量纲，系数全自由 ⇒ **不能预言 0.511 MeV**。卷二十八补引入外部锚 `M0=0.511e-3 GeV`（②外部锚定）给单位，但**层级比仍失败** ⇒ M0 只补单位不解决量级。
2. **层级失败**（5.2）。
3. **形式度已修复**（5.3），但修复后交叠积分**仍无闭合链给出具体数值**。
4. **m_top 用守恒量 Q_hel 作质量项**：同 Q_hel 不同粒子（u/d）质量差须全来自 n_s/模态，而 u/d 差 ~2 MeV、e ~0.5 MeV，用整数 n_s 难以精细区分。
5. **T5 过拟合风险**：3 个自由系数 (0.21, 0.08, κ) 使公式**对任意 3 点数据可拟合** ⇒ 无可证伪力（卷二十九最严重结构弱点）。

# 第 6 章 混合矩阵拓扑起源：CKM 与 PMNS 的丛截面干涉

## 6.1 交叠积分表述
不同代的同类型孤子截面在丛模空间非完全正交，存在交叠相位 → 味混合：
```
V_CKM,ij ∝ ∫_P Ψ_u,i† ∧ Ψ_d,j       （上型第 i 代 × 下型第 j 代）
```
复相位「自动给出」CP 破坏（来自丛手征不对称）。PMNS：中微子为轻螺旋孤子，拓扑交叠结构不同给大混合角；中微子质量来自「拓扑马约拉纳能隙」（孤子自缠绕）。

## 6.2 实跑非幺正（2026-09-30）
原稿引擎 `V = 0.15·e^{iαQ(i-j)}/(1+|i-j|·0.4)`：
```
|V| = [[0.150,0.107,0.083],
       [0.107,0.150,0.107],
       [0.083,0.107,0.150]]
行范数 = 0.202 / 0.213 / 0.202      （幺正要求 ~1.0）
```
⇒ **对角元 0.15（应 ~0.97）、行范数 0.20（应 ~1.0）、|V13|=0.083（应 0.0036）——根本不是合法混合矩阵**，量级与结构全错。

## 6.3 修复（卷二十八补 · 幺正化）
改用 SM 同构结构：每味扇区有厄米质量算符，对角化给幺正 `U`，`V = U_u†·U_d` **自动幺正**。
```python
import numpy as np
def build_unitary_overlap(H):
    ev, evec = np.linalg.eigh(H - H.conj().T)   # 强制厄米 -> eigh 给幺正特征向量
    return evec @ np.diag(np.exp(1j*ev)) @ evec.conj().T   # 必幺正
```
**实跑**：行/列范数均 `[1.0, 1.0, 1.0]` → **幺正性修复**。
**但诚实二级结论**：纯拓扑 ansatz `H_ij ∝ αQ(i−j)/Δm_ij`（`Δm_ij~205/3270`）给 `H_ij~5e-5` ⇒ `V ≈ I`（近单位阵，**非 CKM 结构**）。要得 `|V12|≈0.225` 须引入**自由混合参数** `θ~0.2`（`|V12|=sinθ≈0.223`）——**与 SM Yukawa 同现状：CKM 数值需自由参数，纯拓扑不导出**。

## 6.4 诚实边界（第 6 章）
1. **非幺正已修复，数值仍开放**（6.3）。
2. **CP 破坏量级错**：`αQ(i−j)=0.07 rad` 与真实 Jarlskog `J~3e-5` 差 ~10³。
3. **马约拉纳性质未论证**：马约拉纳需场算符等于其电荷共轭（算符代数性质），非几何缠绕性质；「孤子自缠绕→马约拉纳」无论证。
4. **CKM 与 PMNS 尺度悬殊未解释**：近幺正 vs 大混合，未从拓扑参数定量说明，只说「结构不同」。
5. 形式度歧义同上（6.1 的楔积，卷二十八补未直接修混合积分形式，故仍须补）。
