attack33 v2 · 2-loop M_SUSY 跨册差异的机器定位
==============================================================================

问题：attack32 F5 报「2-loop M_SUSY=2317.72 GeV」对 attack30 的 193.04 GeV 相差 12.01 倍
      （相对偏差 11.01）；F5c 归因为「非对角 b_ij 项是否计入」（依据：V1 仅对角项
      恰好落在 193 附近）。本册检验该归因：先对拍矩阵与分段动力学，再检验 193.04 是否为解。

共同输入：alpha_em^-1=127.916  alpha_s=0.1184  sin2theta_W=0.23122  M_Z=91.1876 GeV
M_Z 处逆耦合：a1=59.003557  a2=29.576738  a3=8.445946

[A0] 自查：两段式打靶的动力学矩阵必须分段（v1 在此处出错）
------------------------------------------------------------------------------
  v1 的 flow 把同一个 mat2 同时用于 SM 段与 MSSM 段；attack32 的 flow 用
  mats[model]（SM 段用 SM 阵、MSSM 段用 MSSM 阵）。两者解的是【不同方程组】。
  单一矩阵口径（v1）：b33=+14 -> 1779.9989 GeV (res=1.60e-13) ; b33=-14 -> 24053.2157 GeV (res=1.31e-13)
  分段矩阵口径（attack32）：b33=+14 -> 2317.71643 GeV (res=7.11e-15) ; b33=-14 -> 17918.76520 GeV (res=7.11e-15)
  attack32 报值 = 2317.71643 GeV（spread 7.105e-15）; 其 V3 b33 反号报值 = 17918.76520 GeV（spread 3.553e-14）
  >> 分段口径逐位复现 attack32 的 V0 与 V3；单一矩阵口径两个都不复现。
  >> 故 v1 的 1780.00 / 24053.22 是「另一方程组」的根，本册作废该两读数。

[A1] b_ij 逐元素对拍（attack32 V0 vs attack30 B_MS）
------------------------------------------------------------------------------
  差异单元数 = 1
    b_33 : attack32 = +14.0000   attack30 = -14.0000
  两段动力学矩阵对拍（SM 段）：两册同源 -> 差异单元 0
  >> 两册矩阵只在 b_33 上不同：+14（attack32 V0）vs -14（attack30）。
     两册的一阶系数 b_i 完全一致（MSSM: 33/5, 1, -3）。
  >> 因此跨册差异不可能是「标准矩阵 vs 非标准矩阵」的整体差异，
     只能来自 (i) b33 符号 或 (ii) 求解定义 / 搜索域。

[A2] attack30 的 M_SUSY 报值 vs 其搜索域上界
------------------------------------------------------------------------------
  attack30 solve_backward 的 L1 网格：range(46) => L1 = i/20 - 1.5, i=0..45
  实际 L1 上界 = 0.7500（源码注释声称 3.0）
  域上界对应的 M_SUSY = M_Z * exp(0.7500) = 193.04415 GeV
  attack30 报出的 M_SUSY   = 193.04415 GeV
  相对偏差 = 3.703e-09
  >> 报值与域上界逐位吻合（偏差 3.7e-09，由其 8 位有效数字报价决定）=> 该报值是【搜索域边界】，不是解。

[A3] 源码静态审计：注释声称的搜索域与实际 range()
------------------------------------------------------------------------------
  attack30 源码：for L1i in range(46): L1v = L1i/20 - 1.5   # 注释写「-1.5 .. 3」
  实际：i_max=45 => L1_max = 0.7500（不是 3.0）
  等价地：M_SUSY 搜索上界 = 193.04 GeV（不是注释暗示的 1832 GeV）
  差异倍数（注释暗示上界 / 实际上界）= 9.49

[A5] 在 attack30 原始搜索域内复跑网格，读其最优残差
------------------------------------------------------------------------------
  b33=-14（attack30 矩阵）原始域最优：
    L1=0.7500  L2=31.7000  => M_SUSY=193.04415 GeV  M_GUT=1.1293e+16 GeV
    最优残差 |a1-a2|+|a1-a3| = 7.512346e-01
    attack30 报值 M_SUSY=193.04415 GeV（复现值相对差 3.70e-09）
  >> 残差量级是判据：O(1e-1) 说明它不是「汇聚解」，只是「域内最不坏点」。

[A6] 扩展搜索域 + 局部精修能否收敛到真解（决定性对照）
------------------------------------------------------------------------------
  Newton（attack32 起点 2.4/33，n=1200）：
    分段矩阵 b33=+14 : L1=+3.235419 L2=29.204540 M_SUSY=2317.71643 GeV residual=7.105e-15
    分段矩阵 b33=-14 : L1=+5.280685 L2=26.499635 M_SUSY=17918.76520 GeV residual=7.105e-15
  attack32 报值 2317.71643 / spread 7.105e-15 => 逐位一致（M_SUSY 相对偏差 2.0e-09，绝对值差 4.6e-06 全部来自其 5 位小数报价）
  扩展域(L1 up to 6.5, step 0.05)粗扫(b33=-14)：L1=4.8500 => M_SUSY=11648.3396 GeV  residual=7.113e-02
  以粗扫最优点为初值局部精修：L1=+5.280685 L2=26.499635 => M_SUSY=17918.76520 GeV  residual=7.461e-14
  与 attack32 起点(2.4,33) 的 Newton 根相对偏差 = 2.562e-11

  >> 粗扫 residual=7.113e-02 仍非零 => 网格步长本身不足以定位零点（仅降 1.02 个数量级）；
     再精修后 residual=7.461e-14 => 相对原域最优共降 13.00 个数量级。
  >> 对照 attack30：只做粗扫、不做精修、不报 residual，于是「域内最不坏点」被当成解。

[A7] b33 符号对真解的独立影响（引用必须声明矩阵）
------------------------------------------------------------------------------
  分段矩阵口径：b33=+14 => 2317.71643 GeV ; b33=-14 => 17918.76520 GeV ; 比值 7.7312
  attack32 F5c 的 V3（b33 反号）= 17918.76520 GeV，与本册 17918.76520 GeV 逐位一致
  >> 仅一个符号位就使 M_SUSY 跨 7.73 倍 => 「2-loop 的 M_SUSY」不是可跨实现比较的量。

[A9] 反解的多值性：同一矩阵 + 同一输入下有几个「解」
------------------------------------------------------------------------------
  b33=+14 的根集合（多初值 Newton，res<1e-9）：
    L1=+3.235419  L2=29.204540  => M_SUSY=2317.71643 GeV  residual=7.11e-15
    根数=1 ; M_SUSY 跨度 = 1.00 倍 (min 2317.71643 / max 2317.71643 GeV)
  b33=-14 的根集合（多初值 Newton，res<1e-9）：
    L1=+5.280685  L2=26.499635  => M_SUSY=17918.76520 GeV  residual=8.17e-14
    根数=1 ; M_SUSY 跨度 = 1.00 倍 (min 17918.76520 / max 17918.76520 GeV)

[A4] 更正 attack32 F5c 的归因：非对角项是主因吗
------------------------------------------------------------------------------
  F5c 原归因链：V1（仅对角项）=183.60 GeV，与 attack30 的 193.04 GeV 差 4.89%
                => 差异来自「非对角 b_ij 是否计入」。
  本册检验：
   (i)  两册真实矩阵只在 b33 符号上不同（A1），不存在「一方只有对角项」的事实；
   (ii) 把 attack30 的矩阵原样代入本册 Newton（分段口径）：M_SUSY=17918.76520 GeV，
        与其 193.04 相差 92.82 倍；
   (iii) 差异的真实来源是搜索域截断（A6）：193.04 = M_Z*exp(0.75) 是域上界（A2）。
  >> 结论：V1 落在 193 附近是【数值巧合】，不是机制。

[A8] 引用纪律：2-loop M_SUSY 的最小可复现字段
------------------------------------------------------------------------------
  必报五项：
   (1) b_ij 矩阵逐元素（至少 b33 符号；+14 与 -14 差 7.73 倍）
   (2) 分段动力学：SM 段用 SM 阵、MSSM 段用 MSSM 阵（A0 反例：单矩阵套用使解偏移）
   (3) 求解定义（前向解 sin2theta_W / 后向解 M_SUSY / 双段打靶）
   (4) residual（无 residual 的「解」不可作为跨册基准）
   (5) 搜索域与步长（本册证明域上界会被误读为解）
