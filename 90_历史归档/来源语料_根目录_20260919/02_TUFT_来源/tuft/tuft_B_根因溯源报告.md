# TUFT-B 根因溯源报告：自屏蔽因子 exp(−u) 从哪来？

> 问题：判决"黑洞偏离 46.82% ≫ LIGO 10%"后，回溯 R1 场方程推导——exp(−u) 是**笔误**还是**假设必然**？

## 一、推导链（符号验证）

**原文场方程（β1 层）**：`∇²β1 − (∇β1)²/β1 = −(8πG/c²)·ρ`

**P1 恒等式（sympy 符号 PASS，残差 0）**：

```
∇²β1 − (∇β1)²/β1 = β1 · ∇²(ln β1)
```

**P2 推导**：令 `u = ln β1`，则 `β1·∇²u = −Kρ`（K = 8πG/c²）

```
∇²u = −Kρ/β1 = −Kρ·exp(−u)
```

⇒ **`exp(−u) = 1/β1`，来自"场方程写在 β1 层"（源项被 β1 除）**。

**判定（PASS）**：数学链条完全正确，**未见笔误**。自屏蔽是 TUFT 场方程结构的**固有特征**，不是可简单修掉的错误。

---

## 二、弱场一致性（P3 PASS）

`u → 0` 时 `exp(−u) → 1` ⇒ `∇²u = −Kρ`（线性 Poisson）。
由 `g = (c²/2)∇u` ⇒ `∇·g = (c²/2)(−Kρ) = −4πGρ` ✓（与 GR 弱场一致）。

## 三、替代写法对比（P4）

| 假设 | 场方程 | 化为 u 的形式 | 自屏蔽？ |
|---|---|---|---|
| **H1（原文）** | `∇²β1 − (∇β1)²/β1 = −Kρ` | `∇²u = −Kρ·exp(−u)` | **有** |
| **H2** | `∇²u = −Kρ`（直接写 u 层） | `∇²u = −Kρ` | **无（纯 GR）** |
| **H3** | `∇²β1 = −Kρ`（线性 β1 层） | `∇²u = −Kρ·exp(−u) − (∇u)²` | **有，且更强** |

**关键判别（PASS）**：H1/H3 **都含** `1/β1 = exp(−u)`；只有 H2（直接写 u 层）退化为纯 GR。
⇒ **"去除自屏蔽"等价于把场方程从 β1 层改写为 u 层**。

> H3 说明：**不能**靠"把 β1 方程改成线性"来去掉自屏蔽——线性 β1 方程反而多出 `(∇u)²`，非线性更强。

## 五、对 B 路线的最终判决

1. **exp(−u) 不是笔误**：它是"场方程写在 β1 = e^u 层"的**必然产物**（P1 恒等式 + 代数，符号精确）。
2. **修复路径 (a) 的真实含义**：把场方程从 β1 层改写为 u 层 —— 但这使 TUFT 引力**退化为纯 GR**，失去唯一超越 GR 的预言。
3. **B 路线的实质结论**：TUFT 引力扇区的"自屏蔽"与引力波观测矛盾；**要么被排除，要么退化到 GR**。
4. **科学价值**：本轮把 B 从"定性方向"推进到**根因级判决**——明确指出了矛盾的位置（场方程的层级选择）与不可兼得的本质。
