## 三、3 维螺旋垂直原理（全维度几何正交）

螺旋 r(θ)=(ρcosθ, ρsinθ, bθ)，θ=ωt，速度 v=(−ωρsinθ, ωρcosθ, ωb)。全维度正交性（机器零）：

| 垂直关系 | 含义 | 误差 |
|:---|:---|:---:|
| **ρ̂ · v_⊥ = 0** | 横向半径 ⊥ 横向速度（圆周运动） | 2.4×10⁻⁶⁶ |
| **v_⊥ · v_∥ = 0** | 横向速度 ⊥ 纵向推进速度 | 0 |
| **v_⊥² + v_∥² = c²** | 光速正交分解（v总=c） | 1.6×10⁻⁶¹ |
| **κ² + τ² = (ω/c)² = 1/R²** | 曲率挠率正交合成频率 | 1.6×10⁻⁶¹ |
| **α = τ/κ = b/ρ = tanθ** | 螺距比（几何精细结构） | 1.6×10⁻⁶¹ |
| **ω²ρ = c²κ** | 向心力 = 曲率力（用 ρ） | 7.8×10⁻⁶² |
| **mc²κ = mω²ρ** | 固有力 = 向心力 | 1.6×10⁻⁶¹ |

> **关键修正**：螺旋的位置向量含 z 向漂移 bθ，故"r·v"≠0（非垂直）；真正垂直的是**横向半径 ρ̂ ⊥ 横向速度 v_⊥**、**v_⊥ ⊥ v_∥**，以及 **Frenet 标架正交**。向心力恒等式用 **ρ**（横向半径）而非 R（螺旋半径）：ω²ρ=c²κ。
