## 0. 结论先行

这一册做的事情只有一件：**把第三册的形状假设去掉**。

第三册判决的是「**单尺度 Yukawa** 能不能活」，答案是「能活，但只活在观测上与没有这个力不可区分的地方」。这句话有一个软肋：它绑死在 `Φ = −GM/r(1+α_Y e^{−r/λ})` 这个**特定形状**上。只要把形状换掉，结论就重新变成未知。

本册把形状换掉。允许**任意**径向势偏离 `δΦ(r)`，只问：同一组星历数据，对「任意径向额外力」到底给了多少空间？

三条结论：

1. **存在一个精确的零方向，不是一个近似的小量。** 势写成 `Φ = −(μ/r)(1−C(r))`，则 `δΦ = (μ/r)C(r)`。只要 `C ≡ 常数`，`δΦ ∝ μ/r`，轨道仍是**闭椭圆**，近点进动**恰好为 0**。也就是说：径向第五力的「整体幅度」这一自由度，对近点进动是**零信息**——不是约束很弱，是恰好零。机读验证：核的绝对值 `8.86e-19`，而信号尺度是 `O(1)` 弧度/圈，抑制 18 个数量级。

2. **能被约束的只有形状变化，而且约束极紧。** 用 `ln r` 上的光滑单位分解把 `C(r)` 参数化成 6 个台阶，整体水平落在零方向上不进入模型，拟合在 5 个相邻反差上做。合并两套历表（12 点、5 参、dof=7）后：

   | 反差 | 95% 区间 |
   |---|---|
   | `c₁−c₂`（≈0.2–0.5 AU） | `[−1.353e−12, 7.831e−13]` |
   | `c₂−c₃`（≈0.5–1.3 AU） | `[−1.759e−12, 6.199e−13]` |
   | `c₃−c₄`（≈1.3–3.2 AU） | `[−8.179e−13, 4.401e−13]` |
   | `c₄−c₅`（≈3.2–8.0 AU） | `[−6.312e−9, 1.581e−9]` |
   | `c₅−c₆`（≈8.0–20 AU） | `[−1.240e−10, 8.053e−11]` |

   换成可读的说法：**相对势深 `δΦ/(μ/r)` 在 0.2–3 AU 内的变化被限制在 1e−12 量级，在 3–8 AU 内限制在 1e−9 量级**；而它的**整体水平完全是自由的**。

3. **V128 的大 λ 极限被代数地识别出来了。** `C = −α e^{−r/λ} = −α(1 − r/λ + r²/(2λ²) − …)`，前两项 `−α`（GM 重标定）与 `+α/λ`（常数势、零力）都落在零方向上，**第一个可约束项是 `−α r/(2λ²)`，即一个常数径向加速度**。由此 `Δϖ ∝ α/λ²`，故 `σ_α ∝ λ²`——这正是第三册 J6 的读数，但这里是**代数原因**，不是数值观察。归约的系数由两条独立路径互验到 `1.18e−15`。

一句话：**V128 之所以能活下来，不是因为它被数据支持，而是因为它的形状在可观测径向范围内几乎不变化。它活在一个由形状定义的盲区里。**

## 3. 方法：一维精确近点角求积

给定半长轴 `a`、偏心率 `e` 与势 `Φ`，轨道在 `r_p = a(1−e)`、`r_a = a(1+e)` 折返。由两个折返条件

```
2(E − Φ(r_p)) − L²/r_p² = 0 ,   2(E − Φ(r_a)) − L²/r_a² = 0
```

关于 `(E, L²)` 是**线性**的，可直接解出：

```
L² = 2 (Φ(r_a) − Φ(r_p)) / (1/r_p² − 1/r_a²) ,   E = Φ(r_a) + L²/(2 r_a²)
```

于是近点角与每圈进动

```
Δθ = ∫_{r_p}^{r_a} L r⁻² / sqrt(2(E−Φ) − L²/r²) dr ,    Δϖ = 2Δθ − 2π
```

**这个式子对偏心率精确**（不是小 e 展开），**对势的偏离精确**（不是一阶展开）。数值实现要点：

- 换元 `r = r_m − (Δr/2)·cos(πs)`，`s ∈ [0,1]`。两个端点的平方根奇性同时被消掉，被积函数在两端**解析且关于 s 偶**；端点值用 `1.5 f(δ) − 0.6 f(2δ) + 0.1 f(3δ)` 三点外推（δ = 1e−3，误差 O(δ⁶)）。
- 折返点固定为 `1∓e`，故 `r(s)` **与 C 无关** ⇒ 节点表按 (行星, N) 缓存，`ln r`、`cos(πs)`、`sin(πs)` 只算一次，所有参数与所有求积共用。
- Simpson（阶 h⁴）+ Neville/Romberg 外推到 O(h^10)，N = 64/128/256/512。
- 全部 Decimal，`prec = 60`；π 用 Machin 公式自算。

**注意**：`Δϖ(c)` **不是** `c` 的奇函数——折返条件使 `E, L²` 依于 `C`，展开含 `O(c²)` 偶部。中心差分把偶部抵消，故 `D(h) = f′(0) + a h² + …`，Richardson `(4D(h/2) − D(h))/3` 才成立。这一点首跑时被我写错成「扰动反号必须反号」，属判据对象错误，已改正（见第 8 节）。

## 5. 形状无关的约束：只有形状变化被约束

### 5.1 参数化

取 `C(r) = Σ_k c_k w_k(r)`，`w_k` 是 `ln r` 上的光滑单位分解（`Σ_k w_k ≡ 1`）。三角不等式之外这是要紧的：单位分解使 `c = (1,1,…,1)` **恰好**对应 `C ≡ 1`，即 `δΦ = μ/r`，正好落在精确零方向上。零方向因此不是数值观察出来的，是构造出来的。

拟合在**相邻反差** `e_k = c_k − c_{k+1}` 上做（规范取 `c_N = 0`）。这 5 个（N=6）或 4 个（N=5）量张成零方向的正交补，故法方程非奇异；整体水平不进入模型。

### 5.2 合并拟合（12 点，m=5，dof=7）

```
χ²(c=0) = 10.732    χ²_min = 7.678    δχ² = 3.054
门槛 χ²_95(5) = 11.0705             cond(A) = 3.94e7
```

`δχ² = 3.054 ≪ 11.07` ⇒ **数据不需要任何形状变化**。这与第三册 J5 的结论方向一致，但强得多：第三册说的是「Yukawa 这一个形状不需要」，本册说的是「**任何**径向形状都不需要」。

### 5.3 硬限制：只有 6 颗行星 ⇒ 最多 6 个反差

这是本册必须如实登记的结构上限。两套历表（EPM2011 / INPOP10a）用的是**同样 6 颗行星**，同一行星在两套历表下的核向量**完全相同**（只有观测值与误差不同）。所以合并后的 12 行设计矩阵只有 **6 个不同的行**，秩至多 6：

- `m = 6`（N=7）时恰好定，`dof = 0`；
- `m ≥ 7`（N≥8）时**必奇异**。

机读证据：N=8 的合并拟合返回奇异（`pooled_solvable = False`），而 N=5、N=6 均可解。不是数值问题，是「只有 6 个径向采样点」的硬限制。想把径向分辨率推上去，唯一办法是增加行星/探测器，不是改进算法。

### 5.4 稳健性：两档基并报

| | N=5（0.25–16 AU） | N=6（0.20–20 AU） |
|---|---|---|
| 反差个数 m | 4 | 5 |

两档同量级、同结论。细分后条件数变差一个量级，符合预期（参数增多 ⇒ 相关性增强）。

## 6. V128 的大 λ 极限：它就是一个常数径向加速度

这一节是本册最实质的代数结果。

把 Yukawa 写成 `C = −α e^{−r/λ}`，展开：

```
C     = −α (1 − r/λ + r²/(2λ²) − …)
δΦ    = (μ/r)C = −αμ/r  +  αμ/λ  −  αμ r/(2λ²)  + …
           └─ GM 重标定 ─┘ └ 常数势 ┘  └─ 常数加速度 ─┘
             精确零方向        零力          第一个可约束项
```

于是

```
δa_r = −d(δΦ)/dr = +αμ/(2λ²)        （常数，向外）
Δϖ   ≈ A · J ,   A = −α/(2λ²)（a=1, μ=1 单位）
J     = −2π√(1−e²)                  （两条独立路径互验到 1.18e−15）
```

由此 `Δϖ ∝ α/λ²`，`σ_α ∝ λ²`。**这就是第三册 J6 的代数原因**：λ 增大时 V128 越来越接近一个纯 GM 重标定加常数势，剩下的唯一可测项是一个常数向外加速度，而它的幅度按 `λ⁻²` 衰减。

机读验证：

| λ/a | 核比 | `(1−r)·λ` |
|---|---|---|
| 1e2 | 9.900498e−1 | 9.950e−1 |
| 1e3 | 9.990005e−1 | 9.995e−1 |
| 1e4 | 9.999000e−1 | 9.99975 |
| 1e5 | 9.999900e−1 | 1.000245 |
| 1e6 | 9.999990e−1 | 1.0025 |

`(1−r)·λ → 1`，正是 `e^{−r/λ}` 展开的 `O(1/λ)` 截断项，不是机器误差。

### 6.1 一个必须记下来的事故：0.99 不是物理

首跑这一门用的是**有限振幅** `α = 1e−2`，结果核比收敛到 **0.99** 而不是 1，六个行星一致到 1e−4。一度看起来像「1% 的物理修正」。

实际是：`δΦ` 的零方向部分（`−αμ/r + αμ/λ`，量级 `O(α)`）与可约束部分（`−αμr/(2λ²)`，量级 `O(α/λ²)`）之间有一个 `O(α²)` 的交叉项。`α = 1e−2` ⇒ 交叉项正好是 1%。改了两次才对上：

- 先把探针振幅抬到 `α = 1e−2` 以压住数值地板（1e−19），结果被交叉项污染；
- 再用**核**（`α→0` 的导数）做判据，交叉项消失，比值的偏离回到 `1/λ` 标度。

本册把这个交叉项单独测出来并验证它**正比 α**：`α=1e−2` 时偏离 `9.901e−3`，`α=1e−3` 时偏离 `9.990e−4`，比 9.91（理论 10，偏差来自交叉项自身的二阶修正）。**它是二阶项，不是修正定律。**

教训与新纪律：**有限振幅探针只能用来测「信号是否高于噪声」，不能用来测标度律；标度律必须用导数。**

本册不重跑第三册的拟合，但用第三册**已登记的读数**做两个方向的自洽检查：

## 8. 排除了什么 / 没排除什么

**被挡住的（在这组数据 + 近点进动这个观测量下）**：

- 任何径向额外力，若其相对势深 `δΦ/(μ/r)` 在 0.2–3 AU 内变化超过 ~1e−12；
- 或其在 3–8 AU 内的变化超过 ~6e−9；
- 特别地：λ ≲ 3 AU 的 Yukawa（因为它的 profile 在这个范围内变化是 `O(α)`，α 被压到 1e−12 量级）。

**没被挡住的**：

- 任何整体幅度——`C ≡ 常数` 精确零信息，无论多大。这不是「约束松」，是**代数上完全无信息**；
- 任何完全落在无行星采样区的力（`r < 0.05 AU` 或 `r > 3e3 AU`）：核**恰好 0**，因为没有行星去过那里；
- 任何变化缓慢到在 0.2–20 AU 内近似平坦的形状（大 λ Yukawa 是其中一例）；
- 任何只在别的观测量上留下痕迹的效应（测距、GM 测定、时间延迟、自旋/参考系拖曳、等效原理的成分依赖）——本册一个都没做。

**「支撑外核恰好 0」不能读成「该区间不存在该力」。** 它只说明这个观测量的信息量在那里是零。

## 9. 过程纪律与事故登记

1. **判据对象错（首跑 K1）**：把「`Δϖ(c)` 是奇函数」当成前提去检验反号，实测「偏离 1.011」——其实是我把 `rel(a,b) = |a−b|/|b|` 当成 `|a|/|b|` 用了。查因后发现更根本的问题：`Δϖ(c)` **本来就不是奇函数**（有 `O(c²)` 偶部）。判据改成「中心差分 h 收敛」+「偶部/奇部比」+「线性探针乘积」三件，才有内容。
2. **换算式错（K8 首跑）**：要求 `δΦ = A·x` 却写成 `C = A·x`。因为 `Φ = −(1−C)/x`，正确应是 `C = A·x²`。错误版本给出 `δΦ = A`（常数势、零力），核算出 `1e−50`。**这个错很隐蔽，因为「核≈0」看起来像零方向的正常结果。**
3. **零方向的退化点**：`c = (1,1,…,1)` 的**有限振幅**对应 `C ≡ 1` ⇒ `μ_eff = 0`，无束缚轨道。故零方向必须用**导数**检验，另用 `c = 0.5·ones` 做有限振幅自洽（`μ_eff = 0.5`）。两个都必须为 0。
4. **单位分解的平台陷阱**：`w_1 = 1 − T_1` 在第一个节点左侧**恒等于 1**。把这样的窗口放到 `3e3…1e5 AU` 时，它会一直覆盖到行星轨道上，测到的其实是零方向而非零支撑。K5 必须改用**紧凑支撑 bump**。
5. **自由度不足**：单历表只有 6 点，5 个反差 ⇒ `dof = 1`，`δχ²` 不可作显著性判据。改为合并两套历表（12 点、m=5、`dof=7`），并**明确登记**两套历表用重叠观测数据、非严格独立，合并 χ² 的绝对值不可当严格似然读。
6. **秩上限**：合并后仍只有 6 个不同行，`m ≥ 7` 必奇异。这不是 bug，是「6 颗行星」的硬限制，作为机读证据登记（N=8 返回奇异）。
