### 1.2 严格求导证明：螺旋是空间波动方程的天然本征解
#### 前置前提：SOM矢量空间波动方程的标准形式
基于SOM时空同一化公理，我们已严格推导出矢量形式的空间波动方程（标量波动方程是其特例）：
$$\nabla^2 \boldsymbol{L} = \frac{1}{c^2} \frac{\partial^2 \boldsymbol{L}}{\partial t^2} \tag{1}$$
其中$\boldsymbol{L}(\boldsymbol{r},t)$是三维空间矢量位移场（而非标量场），这是螺旋结构能自然出现的核心前提——只有矢量场才有偏振特性，标量场无法形成螺旋。

#### 步骤1：求解三维矢量波动方程的平面波通解
设波动方程的平面波试探解为：
$$\boldsymbol{L}(\boldsymbol{r},t) = \boldsymbol{L}_0 e^{i(\boldsymbol{k}\cdot\boldsymbol{r} - \omega t)} \tag{2}$$
其中：$\boldsymbol{L}_0$为复矢量振幅（决定偏振特性），$\boldsymbol{k}$为波矢量（传播方向为$\boldsymbol{k}/k$，$k=|\boldsymbol{k}|$为波数），$\omega$为角频率。

将试探解(2)代入波动方程(1)，分别计算拉普拉斯算符和时间二阶偏导：
- 拉普拉斯算符作用：$\nabla^2 \boldsymbol{L} = -k^2 \boldsymbol{L}_0 e^{i(\boldsymbol{k}\cdot\boldsymbol{r} - \omega t)} = -k^2 \boldsymbol{L}$
- 时间二阶偏导：$\frac{\partial^2 \boldsymbol{L}}{\partial t^2} = -\omega^2 \boldsymbol{L}_0 e^{i(\boldsymbol{k}\cdot\boldsymbol{r} - \omega t)} = -\omega^2 \boldsymbol{L}$

代入方程(1)，化简得到波动方程的核心色散关系：
$$-k^2 \boldsymbol{L} = \frac{1}{c^2} (-\omega^2 \boldsymbol{L}) \implies \omega = c k \tag{3}$$
该式证明：空间波动的相速度$v_p=\omega/k=c$，天然满足光速不变原理，与SOM类光约束完全一致。

#### 步骤2：从线偏振到圆偏振——螺旋结构的数学起源
平面波的偏振特性由复矢量振幅$\boldsymbol{L}_0$的方向和相位决定：
- 线偏振：$\boldsymbol{L}_0$为实矢量，位移场始终沿固定方向振动，无旋转特性；
- 圆偏振：$\boldsymbol{L}_0$的两个垂直分量振幅相等、相位差90°，位移场在垂直于传播方向的平面内做匀速圆周运动，天然形成螺旋结构。

取最简化的物理场景：波沿$z$轴传播（$\boldsymbol{k}=(0,0,k)$），取复矢量振幅$\boldsymbol{L}_0=(A, iA, 0)$（$A$为实常数，$i$为虚数单位，代表$y$分量比$x$分量超前90°相位），代入试探解(2)并取实部，得到：
$$\boldsymbol{L}(z,t) = A \cos(kz - \omega t) \boldsymbol{i} + A \sin(kz - \omega t) \boldsymbol{j} \tag{4}$$

#### 步骤3：圆偏振解与圆柱螺旋的严格等价性证明
SOM体系中，稳态类光圆柱螺旋的标准参数方程为：
$$\boldsymbol{L}(t) = r_0 \cos(\omega t + \phi_0) \boldsymbol{i} + r_0 \sin(\omega t + \phi_0) \boldsymbol{j} + v_\parallel t \boldsymbol{k} \tag{5}$$

将式(4)与式(5)做严格对应：
1.  螺旋特征半径：$r_0 = A$，即振幅等于螺旋半径；
2.  角频率：二者完全一致，均为$\omega$；
3.  轴向传播：式(4)中$kz - \omega t = 0$的等相位面沿$z$轴以速度$v_\parallel = \omega/k = c$传播，与式(5)的轴向推进项完全等价；
4.  空间形态：固定时间$t$，式(4)的位移场随$z$的变化，就是一个沿$z$轴延伸的圆柱螺旋；固定位置$z$，位移场随$t$的变化，就是垂直平面内的匀速圆周运动，与螺旋的几何定义100%吻合。

#### 步骤4：螺旋本征解的稳定性证明
螺旋结构之所以是空间波动的「天然稳定模式」，核心在于其微分几何特性：圆柱螺旋是三维欧几里得空间中，**唯一曲率$\kappa$和挠率$\tau$均为常数的曲线**，而曲率、挠率恒定意味着位移场的空间扭曲是均匀的，无能量发散、无相位畸变，是波动方程的稳态束缚态解。

对式(4)的螺旋解，严格计算其曲率和挠率：
- 一阶导数（切向量）：$\frac{d\boldsymbol{L}}{dz} = -A k \sin(kz) \boldsymbol{i} + A k \cos(kz) \boldsymbol{j}$，模长$|\frac{d\boldsymbol{L}}{dz}|=A k$
- 二阶导数：$\frac{d^2\boldsymbol{L}}{dz^2} = -A k^2 \cos(kz) \boldsymbol{i} - A k^2 \sin(kz) \boldsymbol{j}$，模长$|\frac{d^2\boldsymbol{L}}{dz^2}|=A k^2$
- 曲率：$\kappa = \frac{|\frac{d\boldsymbol{L}}{dz} \times \frac{d^2\boldsymbol{L}}{dz^2}|}{|\frac{d\boldsymbol{L}}{dz}|^3} = \frac{A^2 k^3}{A^3 k^3} = \frac{1}{A} = \frac{1}{r_0}$（常数）
- 挠率：$\tau = \frac{(\frac{d\boldsymbol{L}}{dz} \times \frac{d^2\boldsymbol{L}}{dz^2}) \cdot \frac{d^3\boldsymbol{L}}{dz^3}}{|\frac{d\boldsymbol{L}}{dz} \times \frac{d^2\boldsymbol{L}}{dz^2}|^2} = k = \frac{\omega}{c}$（常数）

**结论**：螺旋解的曲率和挠率均为与位置、时间无关的常数，是空间中最稳定的曲线形态，对应基本粒子的长期稳定性，这是线偏振波、球面波等其他解不具备的核心特性。

### 2.2 分情况严格推导与结论
#### 情况1：轴向速度达到光速 $v_\parallel = c$
将$v_\parallel = c$代入类光恒等式(6)，可得：
$$(r_0 \omega)^2 = c^2 - v_\parallel^2 = 0 \implies r_0 \omega = 0$$

物理上有且只有两种子情况，其中仅第一种有实际意义：
##### 子情况1a：螺旋特征半径 $r_0 \to 0$，角频率$\omega$为有限值
这是**光子、引力子等无质量粒子**的唯一物理场景：
- 螺旋的特征半径$r_0$趋近于0，意味着**局域化的圆柱螺旋涡旋结构完全消失**——没有了有限的旋转半径，横向旋转的空间载体不复存在，全部运动速率都用于轴向的光速传播；
- 补充澄清：圆偏振光的「相位螺旋」≠ 局域化螺旋结构
  光速运动的圆偏振光子，确实存在螺旋形的等相位面（对应光子的自旋角动量），但这是**非局域的相位螺旋**，是无限延展的平面波的相位分布，而非SOM公理中定义的「稳态、无散、局域化的类光圆柱螺旋涡旋」。二者的核心区别是：
  - 有质量粒子的螺旋：实空间位移场的旋转，局域在有限半径$r_0$内，对应静止质量；
  - 光子的圆偏振相位螺旋：仅相位的螺旋分布，无局域化的实空间旋转半径，无静止质量。

##### 子情况1b：角频率$\omega \to 0$，螺旋半径$r_0$为有限值
该情况物理上不成立：$\omega \to 0$对应能量$E=\hbar\omega \to 0$，即无能量、无动量的静止场，无法以光速传播，无实际物理意义。

**核心结论1**：当粒子的轴向运动速度达到光速时，**对应有质量粒子的局域化圆柱螺旋结构必然消失**，螺旋的横向旋转分量必须为0，粒子从有质量的局域螺旋态，转化为无质量的非局域波动态。

#### 情况2：轴向速度低于光速 $v_\parallel < c$
将$v_\parallel < c$代入类光恒等式(6)，可得：
$$(r_0 \omega)^2 = c^2 - v_\parallel^2 > 0 \implies r_0 \omega \neq 0$$

该情况对应**所有有质量粒子**：
- 螺旋的横向旋转分量始终存在，局域化的圆柱螺旋结构稳定保持；
- 当粒子被加速，$v_\parallel$增大时，$r_0 \omega$必然减小，即内部螺旋的旋转速度降低，对应的静止能量转化为宏观动能，完全符合狭义相对论的质能关系；
- 静止粒子的极限情况：$v_\parallel = 0$，此时$r_0 \omega = c$，全部光速都用于内部螺旋旋转，对应的静止能量$E_0 = m_0 c^2 = \hbar \omega$，可直接推导出静止质量的本源公式：
  $$m_0 = \frac{\hbar \omega}{c^2} = \frac{\hbar}{c r_0} \tag{7}$$
  该式直接证明：静止质量与螺旋特征半径成反比，螺旋半径越小，静止质量越大，与康普顿波长$\lambda_c = \frac{\hbar}{m_0 c} = 2\pi r_0$完全吻合，实现了几何结构与物理量的完美统一。

**核心结论2**：低于光速运动的有质量粒子，始终保持局域化的圆柱螺旋结构，螺旋的横向旋转分量是其静止质量的本源。

---

#### 情况3：轴向速度超光速 $v_\parallel > c$
将$v_\parallel > c$代入类光恒等式(6)，可得：
$$(r_0 \omega)^2 = c^2 - v_\parallel^2 < 0$$
该式无实数解，物理上不成立。

**核心结论3**：SOM体系天然禁止超光速运动，完全符合狭义相对论的光速上限原理。
