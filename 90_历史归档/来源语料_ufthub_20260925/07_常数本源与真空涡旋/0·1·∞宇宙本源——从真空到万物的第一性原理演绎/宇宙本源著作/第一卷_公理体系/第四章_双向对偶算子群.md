# 第四章 双向对偶算子群$\mathcal{G}$与旋量表示

## 4.1 李群与李代数的基本概念

对称性是现代物理学的核心概念，而对称性的数学描述是群论。连续对称性由李群描述，李群的无穷小生成元构成李代数，诺特定理告诉我们每一个连续对称性都对应一个守恒律。

**定义4.1.1（李群）**：李群是一个同时具有光滑流形结构和群结构的集合$G$，使得群乘法$(g,h)\mapsto gh$和群逆$g\mapsto g^{-1}$都是光滑映射。

**定义4.1.2（李代数）**：李群$G$在单位元$e$处的切空间$T_eG$称为$G$的李代数，记为$\mathfrak{g}$。李代数上定义了李括号运算$[\cdot,\cdot]:\mathfrak{g}\times\mathfrak{g}\to\mathfrak{g}$，它是反对称双线性映射，满足雅可比恒等式：
$$[X,[Y,Z]] + [Y,[Z,X]] + [Z,[X,Y]] = 0$$

李括号描述了无穷小生成元之间的对易关系，是量子力学中对易子的几何起源。

**定义4.1.3（指数映射）**：李代数到李群的指数映射$\exp:\mathfrak{g}\to G$定义为：
$$\exp(X) = \gamma_X(1)$$
其中$\gamma_X(t)$是$G$中满足$\gamma_X(0)=e$，$\gamma_X'(0)=X$的单参数子群。指数映射是从李代数原点附近到李群单位元附近的微分同胚。

对于矩阵李群，指数映射就是矩阵指数：
$$\exp(X) = \sum_{n=0}^\infty \frac{X^n}{n!}$$

## 4.2 正交群与旋量群

我们最熟悉的对称群是正交群，它描述了欧几里得空间中保持内积不变的线性变换。

**定义4.2.1（正交群）**：$n$维欧几里得空间的正交群$O(n)$是所有保持内积不变的线性变换$A:\mathbb{R}^n\to\mathbb{R}^n$构成的群，即满足$A^TA=AA^T=I$的$n\times n$矩阵群。特殊正交群$SO(n)$是行列式为1的正交变换构成的子群，描述了$n$维空间的旋转。

正交群$SO(n)$是连通的，但它不是单连通的，它的基本群是$\pi_1(SO(n))=\mathbb{Z}_2$（当$n\geq3$时），这意味着旋转存在"双覆盖"：旋转360度不是恒等变换，旋转720度才是恒等变换。这个双覆盖就是旋量群。

**定义4.2.2（旋量群）**：特殊正交群$SO(n)$的泛覆盖群称为旋量群$\text{Spin}(n)$，它是$SO(n)$的双覆盖，即存在满同态$\pi:\text{Spin}(n)\to SO(n)$，其核为$\{1,-1\}$。

旋量群可以用克利福德代数构造：克利福德代数$\text{Cl}(n)$是由$n$个生成元$\{\gamma_1,\dots,\gamma_n\}$生成的结合代数，满足反对易关系$\{\gamma_i,\gamma_j\}=\gamma_i\gamma_j+\gamma_j\gamma_i=2\delta_{ij}$。旋量群$\text{Spin}(n)$是克利福德代数中所有可以表示为偶数个单位向量乘积的可逆元素构成的群。

旋量是旋量群的表示，它是比向量更基本的几何对象。在我们的理论中，所有基本粒子都是旋量，向量场（如电磁场、引力场）都是旋量场的二次型。

## 4.3 双向对偶算子群$\mathcal{G}$的定义

我们的真空流形$\mathcal{M}^{128}$的对称群不是普通的正交群$O(128)$，而是双向对偶算子群$\mathcal{G}$，它不仅包含普通的旋转和反射，还包含双向对偶变换。

**定义4.3.1（双向对偶算子群$\mathcal{G}$）**：双向对偶算子群$\mathcal{G}$是全域超复数系$\mathbb{U}$的自同构群，即所有保持$\mathbb{U}$的代数结构和双向对偶结构的可逆线性变换$g:\mathbb{U}\to\mathbb{U}$构成的群：
1. **保持加法**：$g(u+v) = g(u)+g(v)$
2. **保持乘法**：$g(uv) = g(u)g(v)$
3. **保持双向对偶**：$g(u^\dagger) = g(u)^\dagger$，$g(u^\ddagger) = g(u)^\ddagger$
4. **保持模长**：$|g(u)| = |u|$

**命题4.3.1（$\mathcal{G}$的结构）**：双向对偶算子群$\mathcal{G}$同构于：
$$\mathcal{G} \cong \text{Spin}(7) \ltimes (\mathbb{R}^+ \times \mathbb{Z}_2 \times \mathbb{Z}_2 \times \mathbb{Z}_2)$$
其中$\text{Spin}(7)$是7维空间的旋量群，对应128维超复数空间中的"旋转"部分；$\mathbb{R}^+$对应标度变换（伸缩）；三个$\mathbb{Z}_2$分别对应电荷共轭、宇称变换、时间反演三个离散对称。

**证明**：全域超复数系$\mathbb{U}$的虚单位元有7个，它们生成的旋转对称群是$SO(7)$，其双覆盖是$\text{Spin}(7)$，这是$\mathcal{G}$的连通分支。双向对偶算子$\dagger$和$\ddagger$生成离散对称群$\mathbb{Z}_2\times\mathbb{Z}_2$，加上空间反射的$\mathbb{Z}_2$，共三个离散$\mathbb{Z}_2$对称。标度变换$u\mapsto ru$（$r>0$）保持乘法结构和双向对偶结构，只是缩放模长，因此构成$\mathbb{R}^+$子群。这些子群半直积构成整个$\mathcal{G}$。$\square$

**注**：$\text{Spin}(7)$是一个非常特殊的李群，它是8维流形的和乐群，具有8维旋量表示，这正好对应我们的超复数结构。实际上，$\mathbb{U}$作为128维空间，可以分解为$\text{Spin}(7)$的不可约表示：
$$\mathbf{128} = \mathbf{1} \oplus \mathbf{7} \oplus \mathbf{21} \oplus \mathbf{35} \oplus \mathbf{64}$$
其中：
- $\mathbf{1}$：实部，对应标量（希格斯场）
- $\mathbf{7}$：虚单位元部分，对应向量（引力子）
- $\mathbf{21}$：2-形式部分，对应反对称张量（胶子、弱玻色子）
- $\mathbf{35}$：4-形式自对偶部分，对应曲率张量
- $\mathbf{64}$：奇次/偶次旋量部分，对应旋量（费米子）

这个表示分解正好对应了粒子物理中的基本粒子分类，我们将在第五卷详细讨论。

## 4.4 $\mathcal{G}$的李代数$\mathfrak{g}$

李群$\mathcal{G}$的李代数$\mathfrak{g}$由其无穷小生成元构成，这些生成元对应物理中的守恒荷。

**定义4.4.1（李代数$\mathfrak{g}$）**：$\mathcal{G}$的李代数$\mathfrak{g}$是所有满足以下条件的线性算子$X:\mathbb{U}\to\mathbb{U}$构成的李代数：
1. **导子性质**：$X(uv) = X(u)v + uX(v)$（莱布尼茨法则）
2. **对偶不变性**：$X(u^\dagger) = X(u)^\dagger$，$X(u^\ddagger) = X(u)^\ddagger$
3. **反自伴性**：$\langle Xu, v\rangle + \langle u, Xv\rangle = 0$（保持模长）

李括号为算子对易子$[X,Y] = XY-YX$。

**命题4.4.1（$\mathfrak{g}$的生成元）**：李代数$\mathfrak{g}$有以下几类生成元：
1. **旋转生成元$M_{ab}$**（$1\leq a<b\leq7$）：共21个，对应7维空间中的旋转，满足：
$$[M_{ab}, M_{cd}] = \delta_{bc}M_{ad} - \delta_{ac}M_{bd} - \delta_{bd}M_{ac} + \delta_{ad}M_{bc}$$
这是$\mathfrak{so}(7)$李代数的标准对易关系。
2. **标度生成元$D$**：1个，对应标度变换，满足$[D,M_{ab}]=0$，$D(u)=u$。
3. **对偶生成元$C,P,T$**：三个离散生成元，满足$C^2=P^2=T^2=1$，对应电荷共轭、宇称、时间反演。

总共有$21+1=22$个连续生成元，加上3个离散生成元，构成整个李代数。

**诺特定理对应**：每一个连续生成元对应一个守恒律：
- $M_{ab}$对应角动量守恒（空间旋转不变性）
- $D$对应能量守恒？不，标度变换在量子场论中是反常的，实际上$D$对应共形对称性，在低能下自发破缺
- 时间平移生成元对应能量守恒，空间平移生成元对应动量守恒，这两个生成元在流形微分同胚中，我们将在第二卷讨论时空对称性时引入

## 4.5 旋量表示与克利福德代数

旋量是旋量群的表示，它描述了费米子（电子、夸克等）的变换性质。在128维超复数空间中，旋量具有非常特殊的结构。

**定义4.5.1（全域克利福德代数$\text{Cl}(\mathbb{U})$）**：全域克利福德代数是由$\mathbb{U}$中的元素生成的结合代数，满足反对易关系：
$$\{u,v\} = uv + vu = 2\langle u,v\rangle$$
对任意$u,v\in\mathbb{U}$。

注意这里的克利福德代数是128维空间的克利福德代数，但由于我们的空间具有超复数结构，这个克利福德代数有非常特殊的性质。实际上，全域超复数系$\mathbb{U}$本身就同构于7维空间的克利福德代数$\text{Cl}(7)$，因为7个虚单位元正好满足克利福德关系$e_i^2=-1$，$\{e_i,e_j\}=0$（$i\neq j$）。

**命题4.5.1（旋量空间的维数）**：$\text{Spin}(7)$的旋量表示是8维实表示，记为$\Delta_7$。由于$\mathbb{U}$是128维的，我们可以构造16个这样的旋量表示，总共$16\times8=128$维，正好填满整个超复数空间。这意味着$\mathbb{U}$本身作为线性空间同构于旋量空间的直和：
$$\mathbb{U} \cong \Delta_7 \otimes \mathbb{R}^{16}$$
这16个旋量副本正好对应粒子物理中的16代费米子？不，实际上对应4代费米子，每代有4个自旋分量，或者说对应标准模型中的16种基本费米子（6种夸克+6种轻子+4种中微子？不对，标准模型是12种费米子，加上反粒子是24种，我们将在第五卷详细对应）。

**定义4.5.2（外尔旋量与马约拉纳旋量）**：在7维空间中，旋量是马约拉纳旋量，即旋量等于其电荷共轭，因为7是奇数维，没有手征分解。但当我们考虑4维时空子流形时，旋量可以分解为左旋和右旋外尔旋量，这对应弱相互作用的手征性。

## 4.6 旋量与向量的对应：矢量场是旋量的二次型

一个非常重要的几何事实是：向量可以表示为旋量的二次型，也就是说，旋量是比向量更基本的对象。

**命题4.6.1（旋量二次型对应向量）**：对于任意两个旋量$\psi,\phi\in\Delta_7$，存在唯一的向量$v\in\mathbb{R}^7$，使得对任意旋量$\chi$，有：
$$v^\mu \gamma_\mu \chi = \psi \phi^\dagger \chi$$
其中$\gamma_\mu$是7维伽马矩阵。换句话说，向量是旋量的"平方"：$v^\mu = \psi^\dagger \gamma^\mu \psi$。

这个事实是我们理解相互作用本质的关键：所有的矢量玻色子（光子、胶子、W/Z玻色子、引力子）本质上都是费米子对的集体激发，是旋量场的二次型。不存在独立的"玻色子场"，所有玻色子都是费米子相互作用的几何表现。

在量子场论中，这对应于"玻色化"现象：在二维时空，玻色子和费米子是等价的，玻色子可以表示为费米子对。我们的理论将这个结果推广到任意维度：所有玻色场都是旋量场的二次组合，旋量是唯一的基本场。

## 4.7 规范群与主丛

现代粒子物理的标准模型建立在规范场论基础上，规范场是主丛上的联络。我们现在从几何角度定义规范丛。

**定义4.7.1（主丛）**：设$G$是李群，流形$P$称为流形$M$上以$G$为结构群的主丛，如果存在光滑满射$\pi:P\to M$，以及$G$在$P$上的光滑右作用，使得：
1. 作用是自由的：$pg=p$蕴含$g=e$
2. $M$是$P$在$G$作用下的商空间：$M=P/G$
3. $P$局部平凡：对任意$x\in M$，存在邻域$U$和微分同胚$\phi:\pi^{-1}(U)\to U\times G$，满足$\phi(pg)=(x,g'g)$其中$\phi(p)=(x,g')$。

**定义4.7.2（规范联络）**：主丛$P$上的联络是$P$上的一个$\mathfrak{g}$值1形式$A$，满足：
1. $A(X^\xi) = \xi$对任意$\xi\in\mathfrak{g}$，其中$X^\xi$是$\xi$生成的基本向量场
2. $R_g^*A = \text{Ad}(g^{-1})A$对任意$g\in G$，其中$R_g$是右作用，$\text{Ad}$是伴随表示

局部上，规范联络可以表示为$A = A_\mu^a T^a dx^\mu$，其中$T^a$是李代数生成元，这就是粒子物理中的规范势，场强为：
$$F = dA + A\wedge A = \frac{1}{2}F_{\mu\nu}^a T^a dx^\mu\wedge dx^\nu$$
这就是规范场强，对应电磁力、弱力、强力的场强。

**命题4.7.1（标准模型规范群的起源）**：标准模型的规范群$SU(3)\times SU(2)\times U(1)$是双向对偶算子群$\mathcal{G}$的子群，它来自$\text{Spin}(7)$的子群分解：
$$\text{Spin}(7) \supset \text{Spin}(6) \cong SU(4) \supset SU(3)\times U(1)$$
$$\text{Spin}(7) \supset G_2 \supset SU(3)$$
$$\text{Spin}(7) \supset SU(2)\times SU(2)\times SU(2)$$
其中$SU(3)$对应强相互作用的色规范群，$SU(2)\times U(1)$对应电弱统一规范群，正好构成标准模型的完整规范群。这不是巧合，而是几何结构的必然结果。

## 4.8 本章小结

本章我们定义了双向对偶算子群$\mathcal{G}$，这是真空流形的基本对称群。我们回顾了李群、李代数、旋量群、克利福德代数等基本概念，证明了$\mathcal{G}$的结构是$\text{Spin}(7)$加上标度和离散对称，其李代数生成元对应物理中的守恒荷。我们指出旋量是比向量更基本的几何对象，所有矢量场都是旋量的二次型，并且标准模型的规范群自然地作为$\mathcal{G}$的子群出现。
