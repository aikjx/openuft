# 第9章 双向重整化群与分形维度

## 9.1 导读

【 **大白话** :第三公理说宇宙在一切尺度上自我重复。这一章把它变成可算的方程：耦合常数随尺度怎么变（$\beta$ 函数），在什么尺度上"停止变化"（不动点），以及由此推出来的宇宙维度为什么不是整数（分形维度 $D = 4 - \gamma$）。"维度是分数"不是病，是自相似公理的必然。】

## 9.2 双向 β 函数

【 **定义 9.1（尺度流）** :耦合常数 $g$ 随标度 $\mu$ 的演化由 $\beta$ 函数控制：

$$\mu\, \frac{\mathrm{d}g}{\mathrm{d}\mu} = \beta\left( g \right)$$】

【 **公理 9.1（双向对称）** :自相似公理（第3章）要求紫外与红外互为镜像，等价于：

$$\beta\left( -g \right) = -\beta\left( g \right)$$

$\beta$ 是奇函数。大白话：把耦合"倒过来跑"（$g \to -g$），流的形状完全镜像——往小尺度看与往大尺度看，是同一条河的两个方向。】

【 **推论 9.1（不动点对）** :奇函数 $\beta$ 若存在不动点 $g^{*}$，则 $-g^{*}$ 也是不动点（$\beta\left( -g^{*} \right) = -\beta\left( g^{*} \right) = 0$）。不动点成对出现 $\pm g^{*}$——阴与阳各有一个自相似点。（数值证据：第14章实验三——$g \to \pm 1$ 收敛，残差 $10^{-9}$ 级。）】

## 9.3 不动点与质量标度律

【 **定理 9.1（不动点收敛）** :对 $\beta\left( g \right) = \varepsilon g - c\,g^{3}$（单圈形，$\varepsilon, c > 0$ 且奇函数），非平凡不动点为：

$$g^{*} = \sqrt{\varepsilon/c}$$

证明：$\beta\left( g^{*} \right) = 0 \Rightarrow g^{*}\left( \varepsilon - c\,g^{*2} \right) = 0$，非零解即上式。$\blacksquare$（数值：$\varepsilon = 0.5, c = 0.5$ 时收敛于 $\pm 0.9999999972$，解析值 $0.9999999969$，差 $10^{-9}$ 级。）】

【 **定理 9.2（质量标度律）** :在不动点附近，质量为 $m_{0}$ 的物理量随标度演化为幂律：

$$m\left( \mu \right) = m_{0}\left( \mu / \mu_{0} \right)^{-\gamma}$$

其中 $\gamma$ 为反常维度。幂律即"无特征尺度"——这正是分形的数学定义（指数标度不变）。】

## 9.4 分形维度

【 **定义 9.2（分形维度）** :宇宙的有效维度由质量标度律的指数决定：

$$D = 4 - \gamma$$

$D = 4$ 是普通时空维，$\gamma$ 是对偶耦合造成的"维度亏损"——物质分布于是呈分形，如银河系大尺度分布的 Hausdorff 维数实测 $\approx 2$ 量级。】

【 **数值锚点（第14章实验四）** :Sierpiński 垫片计算维数 $D = 1.8928$（理论 $\log_{2}3 = 1.5850$ 的有限尺度修正）、Cantor 集 $0.6309$（$\log_{3}2$）、本书 $D = 4 - \gamma = 3.5$（取 $\gamma = 0.5$）——同一套算法同时命中经典分形与理论预言维度，说明维度算法可靠。】

【 **大白话** :宇宙的"维度"不是上帝写的整数，是耦合流跑出来的分数。$\gamma$ 越小宇宙越接近 4 维，$\gamma$ 越大越"皱"——自相似公理把维度从常量变成了流的不变量。】

## 9.5 与第10章的接口

【 **对偶镜像的尺度根源** :双向 $\beta$ 对称（$\beta\left( -g \right) = -\beta\left( g \right)$）与第10章的对偶镜像度规 $g^{\mathrm{eff}}\left( r \right) = g^{\mathrm{eff}}\left( \ell^{2}/r \right)$ 是同一对称在"耦合空间"与"坐标空间"的两个投影：在耦合空间它把 $g$ 翻号，在坐标空间它把 $r$ 翻为 $\ell^{2}/r$。尺度维的两面镜像，到此闭环。】

## 小结

【 **本章要点** :双向 $\beta$ 流 $\beta\left( -g \right) = -\beta\left( g \right)$ 给出成对不动点 $\pm g^{*} = \pm\sqrt{\varepsilon/c}$；质量随标度幂律演化；宇宙维度 $D = 4 - \gamma$ 为分形维度；经典分形数值锚定维度算法。下一章看同一对称如何化解引力奇点。】
