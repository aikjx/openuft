# 99_待整理资料

尚未立项、归属待审的输入与问题。

## 本区放什么

| 内容 | 判据 |
|---|---|
| 主题待办 | 有明确主题但尚无材料，只有占位说明（如 `暗物质直接探测/`） |
| 来源来料 | 从工作区收拢回来、**尚未逐件归属到某个体系**的材料 —— 此类已封存至 [`90_历史归档/来源语料_根目录_20260919/`](../90_历史归档/来源语料_根目录_20260919/README.md)，见下 |

## 本区不放什么

- 已归属的体系材料 → 放 `01_独立体系/S*/`，并在该体系 `claims.csv` 登记
- 历史版本与旧布局 → 放 `90_历史归档/`
- 跨体系比较与架构 → 放 `06_统一体系层/`

## 两条硬规则

1. **不做未核验的归属。** 文件名同名不等于同一体系（已知案例：`全域统一场论_*.md`
   文件名带 TUFT，本体却是 S13 的阴阳对偶旋量 + Hopf 六方程闭环）。因此来料一律
   记 `待归属`，只写**线索**，不写结论。
2. **来源来料不提升证据等级。** 材料被搬进来，只表示位置发生了变化；
   它能否作为某个体系的证据，取决于它算过什么、算到哪一步。
