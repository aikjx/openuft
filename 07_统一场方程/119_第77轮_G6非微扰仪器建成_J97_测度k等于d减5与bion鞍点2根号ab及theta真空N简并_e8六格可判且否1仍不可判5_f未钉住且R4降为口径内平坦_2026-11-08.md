## 二、G6 仪器：三件定义与机验

### 二.1 作用量测度（G6-M）

d 维里瞬子是 `(d−4)`-膜。模量测度 = 平移零模（横向体积因子 `ρ^{d−4}`）× 尺度零模 Jacobian `ρ^{−1}`，合

```
dμ = ρ^{k} dρ ，   k = d − 5 。
```

`d=6 ⇒ k=1`；`d=4 ⇒ k=−1`；`d=10 ⇒ k=5`。函数 `dmu_weight(d, ρ)` 的签名为 `("d","rho")`，**Z、f、κ₆、g₆ 均不进入**（Z 只进作用量的 `T²/(2Z)` 项，f 只进一圈谱权重）。

收敛判据（精确符号判，不做数值积分）：

```
UV：a>0（高斯压制）；a=0 退化为 ∫₀ ρ^k dρ，须 k>−1；a<0 发散。
IR：b>0；b=0 退化为 ∫^∞ ρ^k dρ，须 k<−1；b<0 发散。
d=6：测度存在 ⇔ a≥0 且 b>0。
```

IR 可积性的精确值可复算：`∫₀^∞ ρ^k e^{−bρ²}dρ = (1/2)Γ((k+1)/2) b^{−(k+1)/2}`。k=1 时 `=1/(2b)`（b=1,4,9 ⇒ **1/2、1/8、1/18**）；k=3、k=5 交叉验证给 1/8，公式一致。

### 二.2 瞬子作用量的模量依赖与鞍点（G6-S）

```
S_I(ρ) = ρ^{d−4}/g_d² ，  ρ→2ρ 的倍率 = 2^{d−4} 。
```

d=6／10／12 ⇒ **4／64／256**（与 115 §⑥ 同读数）。bion 用两参有效式

```
S(ρ) = a/ρ² + bρ² ，   b = 2/g₆² （两瞬子经典作用量，无条件 >0）
```

机验结果：`S'(ρ)=−2a/ρ³+2bρ = 0 ⇔ bρ⁴=a`；鞍点 `ρ*⁴=a/b`；`S''(ρ*)=6a/ρ*⁴+2b=8b>0`；`S(ρ*)=a/ρ*²+bρ*²` 且 `S(ρ*)²=4ab`，故 `S(ρ*)=2√(ab)`。四点全精确：`(a,b,ρ*)=(1,1,1) ⇒ S=2`；`(1,16,1/2) ⇒ S=8`；`(16,1,2) ⇒ S=8`；`(81,1,3) ⇒ S=18`。`b` 的无条件性：`g₆²=1/4,1,2 ⇒ b=8,2,1`，全部为正。

**这里就是 109 那句的破口**：只要 `a>0`，`ρ*` 是有限、非零、稳定的 bion，`S(ρ*)` 有限。「无有限作用量」不成立；缺的是 `a` 的符号与后述 `D`。

### 二.3 θ-真空的构造与 CP 性质（G6-T）

```
P(θ) = 1 + 2 Σ_{n≥1} q^n cos(nNθ) ，   q = e^{−S_I} ∈ (0,1) 。
```

- **实**：Fourier 系数 `2q^n` 全实且正 ⇒ `P` 实 ⇒ 无虚部。
- **偶**：`cos` 偶 ⇒ `P(−θ)=P(θ)` ⇒ 势无奇项 ⇒ **θ=0 真空 CP 保持**，无自发 CP 破缺。
- **N 个简并极小**：`θ=2πk/N`（`k=0,…,N−1`）处 `cos(nNθ)=cos(2πkn)=1` ⇒ 全部同值。机验 N=1..5：极小个数 N、不同值个数 1。
- **CP 分支**：`k ↔ N−k` 为共轭对（N=3 为 `(1,2)`；N=4 为 `(1,3)` 与自共轭的 `(2,2)`；N=5 为 `(1,4)`、`(2,3)`）⇒ **N≥3 时若真空落在 θ≠0 分支，CP 自发破缺**；要 CP 保持就必须落在 `θ=0`（N 偶时 `θ=π` 也是本征态）。这一条此前（115 §⑥）未写。
- **退化负控**：`S_I=0 ⇒ q=1`，部分和 `1+2M` 单调无界（n≤10,20,50 ⇒ 21,41,101）⇒ 无 θ-真空。

`N` 由中心/荷量子化决定；本卷只验证「给定 N 的结构」，**不逐群赋值**（见 §六.2）。

### 二.4 根因判据（可复算，不是描述）

仪器把「判不了」拆成四个互斥出口，按序判：

```
if a<0 or b<0        : 无下界（作用量无下界）
elif 测度不收敛       : 缺测度
elif a==0            : 无稳定构型（唯一驻点 ρ=0，退化）
elif a>0 and b>0     : 可达（鞍点 ρ*⁴=a/b，S=2√(ab)）
```

对 e8：`b=2/g₆²>0` 无条件成立；`a`（双瞬子相互作用系数）**不在 4 参作用量内**（本仓未算 6D 双瞬子谱）；`D`（单瞬子行列式/方案归一）同样不在。因此判据不闭合的位置是**第四项：作用量缺系数**，而**不是**前三项。可判的充分条件写成一条：

```
可判 ⇔ (a 已知且 a>0) ∧ (D 固定) ∧ (通道唯一 |C|=1) ∧ (N_θ 定)
```

五格至少有三项不满足（`a`、`D`、`N_θ`），`c_R` 另算。

## 四、f 是否被钉住

### 四.1 归一化不变（最小反例）

凝聚进入 `f` 的最低阶方式是把整体权重乘一个因子：`f → A·f`。于是

```
r(A) = (A f₂)/(A f₀) = f₂/f₀  ，与 A 无关。
```

机验：取 `f=(f₀,f₂)=(1,5)`，`A=1,2,5,7/3` ⇒ `r=5` 四次全同 ⇒ `Z=12κ₆/(5·5)=12κ₆/25` 也全同。**最小反例**：两个不同凝聚幅度（`A=1` 与 `A=2`）给**同一低能读数**（`r=5`，同 `Z`，同 `R`）。这就是「仍是参数化重述」的最短证据。

### 四.2 形状变形给一族

若凝聚还带一个形状分量：`f = g + A·δ`，`g=(1,5)`、`δ=(2,1)`，则

```
r(A) = (5+A)/(1+2A) ，  A=1 ⇒ 2 ，  A=2 ⇒ 7/5 。
```

两点读数不同，但 `A` 是自由幅度 ⇒ **得到一族而不是一点**；把 `r` 换成 `A` 只是换了参数名，维数不减。

### 四.3 行列式归一自由

`M = D·e^{−S_I}`，`D` 是单瞬子行列式与零模归一的合并（方案依赖）。机验（代有理元 `q=1/9`）：`D=1 ⇒ M=1/9`，`D=2 ⇒ M=2/9`——**同一 `S_I`，两倍凝聚**。`D` 不在 4 参作用量内，故 e8 给不出唯一凝聚幅度。

### 四.4 若外部给定 `r₀`：条件分支与 R3／R4

条件分支（仅当 `r₀` 由外部原理给出，本卷**未达成**）：

```
r₀=1 ⇒ Z = 12κ₆/(5r₀) = 12κ₆/5 ；N_T = 1 + (5/3)r₀ = 8/3 ；
A = 1/(4κ₆) + 1/Z = 2/(3κ₆) ；A·4κ₆ = 8/3 恒等 ；
R = R₀·N_T/g_F = 3.525×10²⁷ （g_F=5/8，R₀=1.25×10³¹/15129）。
```

R3：无条件 `4−3=+1`（`{g₆,κ₆,Z,L}` 对 SM 3）；条件点 `3−3=0`。R4 在条件点两读都消失（`Z` 被锁到 `κ₆`，`N_T` 恒 8/3），但那是**搬位置**：自由度交给 `r₀`，而 `r₀` 正是 e8 给不出的量。

### 四.5 R4 的两读（本卷新增的两点见证）

```
(Z,κ₆) = (2, 1/2) ：N_T = 1+4κ₆/Z = 2 ，G₄=κ₆N_T = 1 ，A·4κ₆ = 2 ；
(Z,κ₆) = (1/3, 1/4)：N_T = 4 ，G₄ = 1 ，A·4κ₆ = 4 。
```

同 `G₄`、不同 `N_T`（2 vs 4）、不同 `A·4κ₆`（2 vs 4）、不同 `R`（差 2 倍）。⇒ **R4 只在窄口径（只固定 `G₄,g₄`）下是平坦方向**；把 `N_T`／`R` 当读数，它就不平。故：

- 无条件：**R4 未消失**（窄口径存在、宽口径不存在）；
- 条件分支：R4 消失，但属**搬位置**；
- 凝聚：`f→A·f` 不改变归一结构 ⇒ **不使 R4 消失**（无论哪个口径）。

### 四.6 结论：卡在哪、缺什么

**f 未被钉住。** 三个独立障碍：`A`（归一幅度）、`δ`（形状方向）、`D`（行列式归一）；再加 `N_θ`（θ 分支）与 `c_R`（通道系数）。缺的是一条**归一原理**（与 #15 同根）＋一条**通道选择原理**。可复算的判据：`可判 ⇔ r(A)` 在允许的 `(A,δ,D,N_θ)` 集上是常函数（此时 e8 无信息）或单点（此时 e8 钉住）；本卷两种都不是——它是**满维的一族**，故判「参数化重述」。

## 六、边界（射程与未判项）

1. **单极凝聚不在射程。** G6 是**瞬子口径**（`π₃`、`θ`、bion）。`a9` 的「可判且否」只覆盖额外 `U(1)` 的**瞬子**通道；若该 `U(1)` 有 Higgs 且单极凝聚，那是另一个仪器（G6′ 单极测度），本卷不判。因此 `a9` 的「否」应读作**「在 G6 射程内否」**。
2. **`N_θ` 未逐群赋值。** 结构（N 个简并极小、CP 配对）已机验，但每格 `N` 的具体值需中心对称与荷量子化的实测，本卷不赋值。
3. **`a` 的符号未算。** 需 6D 双瞬子谱（经典场计算）；本卷只建仪器，不做该谱。**可证伪预测**：若该谱给 `a<0`，五格由「仍不可判」降为「可判且否（塌缩）」；若给 `a>0`，五格只剩 `D,c_R,N_θ`，仍不可判（读数层已否）。
4. **6D 非重正化。** 仪器只用经典＋一圈结构，不做数值积分、不做格点；「测度存在」是结构判据，不是数值收敛证明。
5. **`θ` 的条件。** 116 §五记「强 CP：无 θ 项」⇒ `θ≡0` ⇒ 只有一个极小、CP 保持、无域壁。若日后引入 `θ`，则 e8 再 +1 连续参数（净 +1 → +2），本卷不把这条算进账。
