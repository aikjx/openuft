# 来料原件（用户附件逐字）：ROOT V32 · 三力垂直原理
> 本文件仅为存档，供后续复核口径；不参与计算。

## 一 三力垂直的充要条件
F_g = m g，F_e = q E，F_b = q v × B。要求 F_g·F_e = F_e·F_b = F_b·F_g = 0。
令 n = (g×E)/|g×E|，则 g·E=0、v·n=0、B·n=0、v×B≠0 为三力两两垂直的充要条件（V32-1）。

## 二 非持续性（V32-2）
d(v·n)/dt|_{t0} = (q/m)(v×B)·n ≠ 0；匀速静态场＋自由运动＋三力非零 ⇒ 不能整个区间持续两两垂直。

## 三 电子实例参数
g=g x̂、E=E ŷ、B=B x̂、v(0)=v0 ŷ；B=0.5 T、E=1e5 V/m、v0=1e6 m/s、g=9.81 m/s²。
初始力：8.936e-30 N / 1.602e-14 N / 8.011e-14 N。
闭式解：v_x=gt，v_y=v0 cosΩt+(E/B) sinΩt，v_z=-v0 sinΩt+(E/B)(cosΩt-1)，Ω=qB/m。
F_e·F_b = q² E B v_z(t)。
偏离直角表：0 ps→0°；0.2 ps→1.0095°；1 ps→5.0837°；5 ps→26.3845°；10 ps→55.2836°；20 ps→62.7684°。
局域回旋周期 71.448 ps。

## 四 平面转动（ROOT-V32-M / -S）
F_b·n = -γ m ṅ·v（V32-M）；|ṅ| ≥ |F_b|/(γ m |v|)（V32-S）；本实例 |ṅ|min ≈ 8.79405e10 s^-1。

## 五 力与曲率（ROOT-V32-F）
F_total = mγ³ v̇ T + mγ v² κ N；正交时 F_g²+F_e²+F_b² = m²γ⁶v̇² + m²γ²v⁴κ²。
γ0 = 1.0000055633；κ0 = 8.7940511e4 m^-1；10 ps 交叉项占比 ≈ 36.69%。

## 六 漂移反例
v_d = E×B/B² ⇒ v_d×B = -E ⇒ F_b = -F_e。E⊥B 不能推出 F_e⊥F_b。

## 七 判决表（摘要）
瞬时严格成立 / 不能持续 / 平面转动有可能（须满足 V32-M）/ 加约束力需重析 / q=0 退化 / v∥B 退化为零 / g∥E 不可能垂直 / 强场 GR 需协变 / 强弱相互作用不可当作另两个空间方向。

## 八 核验表（摘要）
解析证明（正交条件、不可持续性、转动必要条件）；SymPy 回代；独立积分最大相对速度差 1.19e-13；相对论与非相对论最大角度差 0.00328°；5,000 组随机正交向量全部通过；曲率—合力式验证通过；漂移反例验证通过；「三力源于同一光速螺旋」尚未证明。

## 九 尚待攻破（来料自述）
