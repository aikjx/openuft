## 1.1 三条最小公理

### 公理 I：光速公理（存在性公理）

**表述**：
1. 宇宙由三维空间中的振动构成
2. 一切运动的弧长速率恒为真空光速 $c$
3. 光速不变是宇宙的基本对称性

**数学形式**：
$$\boxed{\left|\frac{d\boldsymbol{r}}{dt}\right|_{\text{弧长}} = c = \text{const}}$$

### 公理 II：量子公理（作用量公理）

**表述**：
1. 振动的作用量以 $\hbar$ 为最小单元量子化
2. 世界本质上是离散的，而非连续的
3. $E = \hbar\omega$ 是能量-频率的基本关系

**数学形式**：
$$\boxed{S = n\hbar,\quad E = \hbar\omega,\quad n = 0, 1, 2, \ldots}$$

### 公理 III：螺旋公理（几何公理）

**表述**：
1. 振动的轨迹是复曲率螺旋 $\Xi = \kappa + i\tau$
2. 模长平方 $|\Xi|^2 = \kappa^2 + \tau^2$ 为对偶不变量
3. 弯曲定质量引力，扭转定电荷电磁

**数学形式**：
$$\boxed{\Xi = \kappa + i\tau,\quad |\Xi|^2 = \kappa^2 + \tau^2 = \frac{1}{R^2}}$$

### 三条公理的独立性

**定理 1.1**：公理 I、II、III 相互独立，不存在循环依赖。

**证明**：三条公理分别约束速度（c）、作用量（ℏ）、几何形态（螺旋）三个独立维度。不存在任何一条公理可以从另外两条公理推导得出。

**证毕** ✅

### 公理体系的完备性

**定理 1.2**：公理体系 {I, II, III} 足以导出经典力学、电磁理论、广义相对论、量子力学的基本方程。

**证明思路**：
- I+II → 质能等价 $E=mc^2$、普朗克关系 $E=h\nu$
- I+III → 万有引力 $F=Gm_1m_2/r^2$、库仑定律 $F=q_1q_2/(4\pi\varepsilon_0 r^2)$
- I+II+III → 量子力学公理、量子场论框架

**证毕** ✅

## 1.2 圆柱螺旋参数方程与速度分解

### 标准参数方程

基本粒子的内禀运动轨迹为三维圆柱螺旋线：

$$\boxed{\boldsymbol{r}(\theta) = \rho\cos\theta\,\boldsymbol{i} + \rho\sin\theta\,\boldsymbol{j} + b\theta\,\boldsymbol{k}}$$

参数说明：
- $\rho$：螺旋横向回旋半径（垂直于螺旋轴平面内的圆周运动半径）
- $b$：螺旋导程参数（方位角 θ 每变化 1 弧度时沿 z 轴前进的距离）
- $\theta = \omega t$：方位角参数，ω 为角速度

### 切向量与速度

对参数方程求导：

$$\frac{d\boldsymbol{r}}{d\theta} = (-\rho\sin\theta,\ \rho\cos\theta,\ b)$$

**切向量**（单位化）：
$$\boldsymbol{T} = \frac{(-\rho\sin\theta,\ \rho\cos\theta,\ b)}{\sqrt{\rho^2+b^2}}$$

**总速度矢量**：
$$\boldsymbol{v} = \omega(-\rho\sin\theta,\ \rho\cos\theta,\ b)$$

### 光速约束与速度正交分解

由公理 I 要求 $|\boldsymbol{v}| = c$：

$$\omega\sqrt{\rho^2+b^2} = c \implies \omega = \frac{c}{R},\quad R = \sqrt{\rho^2+b^2}$$

**横向旋转速度**：
$$\boldsymbol{v}_\perp = \omega(-\rho\sin\theta,\ \rho\cos\theta,\ 0) = (v_x, v_y, 0)$$
$$|\boldsymbol{v}_\perp| = \omega\rho = \frac{c\rho}{R} = v_\perp$$

**轴向平移速度**：
$$\boldsymbol{v}_\parallel = \omega(0, 0, b) = (0, 0, v_z)$$
$$|\boldsymbol{v}_\parallel| = \omega b = \frac{cb}{R} = v_z$$

**正交性验证**：
$$\boldsymbol{v}_\perp \cdot \boldsymbol{v}_\parallel = 0 \quad \checkmark$$

**光速约束验证**：
$$v_\perp^2 + v_z^2 = \frac{c^2(\rho^2+b^2)}{R^2} = c^2 \quad \checkmark$$

### 螺旋的三种极限态

| 极限态 | 条件 | 几何形状 | 物理对应 |
|:---|:---|:---|:---|
| 静质量态 | $v_z = 0, v_\perp = c$ | 纯旋转圆 | 物质静止态 |
| 光子态 | $v_\perp = 0, v_z = c$ | 纯轴向直线 | 零质量粒子 |
| 运动质量态 | $0 < v_z < c$ | 旋进结合 | 有质量有运动 |

## 1.3 Frenet-Serret 框架与 κ、τ 推导

### Frenet 活动标架

沿螺旋轨迹运动的最自然参考系是 **Frenet 活动标架** {T, N, B}：
- **T**：切向量，指向运动方向
- **N**：主法向量，指向弯曲方向
- **B**：副法向量，B = T × N

### 曲率 κ 的严格推导

曲率度量曲线偏离直线的程度。

**一般公式**：
$$\kappa = \frac{|\boldsymbol{r}' \times \boldsymbol{r}''|}{|\boldsymbol{r}'|^3}$$

**圆柱螺旋的推导**：

计算一阶导数的叉乘：
$$\boldsymbol{r}' \times \boldsymbol{r}'' = (-\rho\sin\theta, \rho\cos\theta, b) \times (-\rho\cos\theta, -\rho\sin\theta, 0)$$
$$= (-b\rho\sin\theta,\ b\rho\cos\theta,\ \rho^2)$$

模长：
$$|\boldsymbol{r}' \times \boldsymbol{r}''| = \sqrt{b^2\rho^2 + \rho^4} = \rho\sqrt{b^2+\rho^2}$$

分母：
$$|\boldsymbol{r}'|^3 = (\rho^2+b^2)^{3/2}$$

**最终结果**：
$$\boxed{\kappa = \frac{\rho\sqrt{b^2+\rho^2}}{(\rho^2+b^2)^{3/2}} = \frac{\rho}{\rho^2+b^2} = \frac{\rho}{R^2}}$$

### 挠率 τ 的严格推导

挠率度量曲线偏离平面曲线的程度。

**一般公式**：
$$\tau = \frac{(\boldsymbol{r}' \times \boldsymbol{r}'') \cdot \boldsymbol{r}'''}{|\boldsymbol{r}' \times \boldsymbol{r}''|^2}$$

**圆柱螺旋的推导**：

计算三重标量积：
$$(\boldsymbol{r}' \times \boldsymbol{r}'') \cdot \boldsymbol{r}''' = (-b\rho\sin\theta,\ b\rho\cos\theta,\ \rho^2) \cdot (-\rho\cos\theta,\ \rho\sin\theta,\ 0) = b\rho^2$$

分母：
$$|\boldsymbol{r}' \times \boldsymbol{r}''|^2 = b^2\rho^2 + \rho^4 = \rho^2(b^2+\rho^2)$$

**最终结果**：
$$\boxed{\tau = \frac{b\rho^2}{\rho^2(b^2+\rho^2)} = \frac{b}{\rho^2+b^2} = \frac{b}{R^2}}$$

### κ, τ 的物理单位

$$[\kappa] = L^{-1},\quad [\tau] = L^{-1}$$

两者均为长度倒数，描述螺旋的紧致程度。

### κ, τ 的速度形式

利用 $\omega = c/R$，可将 κ, τ 用速度表示：

$$\kappa = \frac{\rho}{R^2} = \frac{\omega^2\rho}{c^2} = \frac{v_\perp \omega}{c^2}$$

$$\tau = \frac{b}{R^2} = \frac{v_z \omega}{c^2}$$

## 1.4 复曲率 Ξ 与对偶不变量

### 复曲率的定义

$$\boxed{\Xi = \kappa + i\tau}$$

将曲率和挠率统一为一个复数几何量。

### 复曲率的几何表示

代入 κ 和 τ 的定义：
$$\Xi = \frac{\rho}{R^2} + i\frac{b}{R^2} = \frac{\rho+ib}{R^2} = \frac{1}{R} \cdot e^{i\theta}$$

其中螺旋倾角 $\theta = \arctan(b/\rho) = \arctan(\tau/\kappa)$。

### 对偶不变量 I

$$\boxed{I = |\Xi|^2 = \kappa^2 + \tau^2 = \frac{1}{R^2}}$$

**核心性质**：
1. **旋转不变性**：$I$ 与 Frenet 标架选择无关
2. **物理对应**：$I = 1/R^2$ 对应粒子的质量-能量密度
3. **尺度不变性**：$I$ 决定相互作用强度

**证明旋转不变性**：设 Frenet 标架绕某轴旋转 φ 角，$\Xi' = \Xi e^{i\phi}$，则：
$$I' = |\Xi'|^2 = |\Xi|^2 = I \quad \checkmark$$

### κ²+τ²=(ω/c)² 恒等式

这是全书最核心的种子公式。

**证明**：

由 $\kappa = \rho/R^2$ 和 $\tau = b/R^2$：

$$\kappa^2 + \tau^2 = \frac{\rho^2 + b^2}{R^4} = \frac{R^2}{R^4} = \frac{1}{R^2}$$

由 $\omega = c/R$，有 $1/R = \omega/c$：

$$\boxed{\kappa^2 + \tau^2 = \left(\frac{\omega}{c}\right)^2}$$

**物理意义**：曲率-挠率的平方和等于频率-光速比的平方。这是连接几何（κ, τ）、运动学（ω, c）和量子（ℏω）的核心桥梁。

### 螺旋升角与精细结构常数

$$\tan\theta = \frac{\tau}{\kappa} = \frac{b}{\rho} = \alpha$$

螺旋升角的正切等于精细结构常数。这建立了几何角度与物理常数的直接联系。

## 1.5 Python 数值验证

### 验证脚本

```python
import sympy as sp
from sympy import Rational, sqrt, atan, tan, pi, E

# 定义符号
rho, b = sp.symbols('rho b', positive=True)
R = sp.sqrt(rho**2 + b**2)

# 曲率和挠率
kappa = rho / R**2
tau = b / R**2

# 验证 κ²+τ²=1/R²
identity = sp.simplify(kappa**2 + tau**2 - 1/R**2)
print(f"κ²+τ²-1/R² = {identity}")  # 应为 0

# 验证 κ/τ = ρ/b
ratio = sp.simplify(kappa / tau - rho / b)
print(f"κ/τ-ρ/b = {ratio}")  # 应为 0

# 数值验证（mpmath 200位精度）
from mpmath import mp, mpf
mp.dps = 200

rho_val = mpf('1')
b_val = mpf('1/137')  # 精细结构常数近似
R_val = mp.sqrt(rho_val**2 + b_val**2)

kappa_val = rho_val / R_val**2
tau_val = b_val / R_val**2

lhs = kappa_val**2 + tau_val**2
rhs = 1 / R_val**2
error = mp.log10(abs(lhs - rhs))
print(f"相对误差 (200位精度): 10^({error})")  # 应趋向于 -199
```
