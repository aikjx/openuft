# 守恒律与诺特定理

[主方程](00_统一场方程.md) · [变分推导](02_变分推导.md) · [四力还原](03_四力还原.md) · [现象覆盖矩阵](07_现象覆盖矩阵.md)

> 本节回答：主方程的每一个对称性给出哪一条守恒律，以及哪些"守恒"是**恒等式**（几何必然），哪些是**在壳**（依赖运动方程），哪些是**反常破缺**的。

---

## 1. Noether 第一定理（全局对称 → 在壳守恒流）

设作用量在无穷小变换 $\Phi\to\Phi+\delta\Phi$ 下不变到边界项，则存在流 $J^\mu$ 使得

$$\partial_\mu J^\mu = \frac{\delta S}{\delta\Phi}\,\delta\Phi \;\overset{\text{在壳}}{=}\;0$$

**关键区分**：上式中 $\partial_\mu J^\mu=0$ 只在**场满足运动方程时**成立。这类守恒律是动力学结果，可以被反常破坏。

## 2. Noether 第二定理（局域规范对称 → 离壳恒等式）

对局域（规范）对称性，参数 $\epsilon(x)$ 任意，分部积分后给出**不依赖运动方程**的恒等式：

$$\frac{\delta S}{\delta\Phi}\,\mathcal R(\Phi)\equiv 0\qquad(\text{离壳成立})$$

这类关系是**几何必然，不可被反常破坏**。比安基恒等式即属此类。

## 3. 逐条对称性清单

### 3.1 微分同胚不变性 $\mathrm{Diff}(M)$

| 项 | 内容 |
|---|---|
| 对称 | $x^\mu\to x^\mu+\xi^\mu(x)$ |
| Noether 定理 | 第二定理（局域） |
| 恒等式 | $\tilde\nabla_\mu\big(G^{\mu}{}_{\nu}+\Lambda\delta^\mu_\nu-\kappa^2T^{\mu}{}_{\nu}\big)\equiv0$（第二比安基恒等式 + 物质侧） |
| 在壳守恒 | $\tilde\nabla_\mu T^{\mu}{}_{\nu}=0$ |
| **反常** | **无**（微分同胚反常在 4 维可消除） |
| 物理 | 能量–动量守恒；ADM 质量、Bondi 质量定义 |

**注意**：含挠时守恒律用 $\tilde\nabla$（含挠协变导数），且 $T^{\mu\nu}$ **不对称**，其反对称部分与挠率按 (C$'$) 配对。

### 3.2 局域 $SO(1,3)$（自旋联络）

| 项 | 内容 |
|---|---|
| 对称 | $\Psi\to e^{\frac14\epsilon_{ab}\gamma^{ab}}\Psi,\ \omega\to\omega+D\epsilon$ |
| 恒等式 | $\tilde\nabla_\lambda s^{\lambda}{}_{\mu\nu}=T_{[\mu\nu]}$（自旋流不单独守恒，与能量动量的反对称部分交换） |
| 物理 | 总角动量 $\tilde\nabla_\lambda\big(x^\mu T^{\lambda\nu}-x^\nu T^{\lambda\mu}+s^{\lambda\mu\nu}\big)=0$ |

### 3.3 局域 $SU(3)_C$

| 项 | 内容 |
|---|---|
| 对称 | $\Psi\to e^{i\epsilon^A(x)T^A}\Psi$ |
| 在壳守恒 | $D_\mu j^{A\mu}=0$ |
| **反常** | **无**（$SU(N)$ 无局域反常；$SU(3)^3$ 系数精确为零，见 [A1](验证脚本/验证报告.md)） |
| 物理 | 色荷守恒；色禁闭的物理前提 |

### 3.4 局域 $SU(2)_L\times U(1)_Y$

| 项 | 内容 |
|---|---|
| 对称 | 手征规范变换 |
| 在壳守恒 | $D_\mu j^{i\mu}=0,\ \partial_\mu j_Y^\mu=0$ |
| **反常** | **手征规范理论存在潜在反常**：$[SU(2)]^2U(1)$、$[U(1)]^3$、$[\text{grav}]^2U(1)$ |
| **结果** | **全部精确为零**（每代独立消除），见 [A1](验证脚本/验证报告.md) |
| 物理 | 这是**理论自洽的必要条件**：任一系数非零，则规范不变性在量子层面破坏、理论不可重整、幺正性丧失 |

**反常消除不是"算出来刚好为零"的巧合 —— 而是场内容被唯一约束的结果。** 给定 $SU(3)\times SU(2)\times U(1)$ 与 $Q=T_3+Y$，超荷 $Y$ 的取值被反常消除条件约束到只差一个整体尺度参数。

### 3.5 全局 $U(1)_B$ 与 $U(1)_L$（偶然对称）

| 项 | 内容 |
|---|---|
| 在壳守恒 | $\partial_\mu j_B^\mu=0,\ \partial_\mu j_L^\mu=0$ |
| **反常** | $B+L$ 被**电弱反常**破坏（sphaleron）：$\partial_\mu(j_B+j_L)^\mu=\frac{3g_2^2}{16\pi^2}\,W^i_{\mu\nu}\tilde W^{i\mu\nu}$ |
| **$B-L$** | **严格守恒**（反常自由） |
| 物理 | 质子稳定性（UFE-1 中不可重整算符若被禁止）；重子生成需要 $B-L$ 破坏的新物理 |

### 3.6 全局 $U(1)_{\rm em}$

| 项 | 内容 |
|---|---|
| 对称 | $\Psi\to e^{i\alpha Q}\Psi$（破缺后残留） |
| 守恒 | $\partial_\mu j^\mu_{\rm em}=0$ |
| 反常 | **无** |
| 物理 | 电荷守恒；电荷量子化由 $Q=T_3+Y$ 与反常消除共同约束 |

### 3.7 离散对称 $C,P,T$

| 对称 | 在 UFE-1 中的状态 |
|---|---|
| $C$（电荷共轭） | **破缺**：$SU(2)_L$ 只耦合左手场 |
| $P$（宇称） | **最大破缺**：$V-A$ 顶点 |
| $T$（时间反演） | **破缺**（CKM 相 $\delta\approx1.2$ rad）；但 $CPT$ **严格守恒** |
| $CPT$ | **严格守恒**（局域、洛伦兹、幺正的 QFT 定理） |

## 4. 反常消除的显式计算（核心验证）

每一代费米子（写作左手 Weyl），记 $d_3=\dim(SU_3\text{ 表示})$，$d_2=\dim(SU_2\text{ 表示})$，$T(R)$ 为 Dynkin 指数（$T(3)=T(\bar3)=\tfrac12$，$T(2)=\tfrac12$），$A(R_3)$ 为三次指标（$A(3)=+1,\ A(\bar3)=-1$）。

| 场 | $(d_3,d_2)$ | $Y$ |
|---|---|---|
| $Q_L$ | $(3,2)$ | $+1/6$ |
| $u_R^c$ | $(\bar3,1)$ | $-2/3$ |
| $d_R^c$ | $(\bar3,1)$ | $+1/3$ |
| $L_L$ | $(1,2)$ | $-1/2$ |
| $e_R^c$ | $(1,1)$ | $+1$ |

五个反常系数：

$$\mathcal A_{[SU(3)]^3}=\sum d_2\,A(R_3)\;=\;2(+1)+1(-1)+1(-1)\;=\;0$$

$$\mathcal A_{[SU(3)]^2U(1)}=\sum d_2\,T(R_3)\,Y\;=\;2\cdot\tfrac12\cdot\tfrac16+1\cdot\tfrac12\big(-\tfrac23\big)+1\cdot\tfrac12\cdot\tfrac13\;=\;\tfrac16-\tfrac13+\tfrac16\;=\;0$$

$$\mathcal A_{[SU(2)]^2U(1)}=\sum d_3\,T(R_2)\,Y\;=\;3\cdot\tfrac12\cdot\tfrac16+1\cdot\tfrac12\big(-\tfrac12\big)\;=\;\tfrac14-\tfrac14\;=\;0$$

$$\mathcal A_{[U(1)]^3}=\sum d_3d_2\,Y^{3}\;=\;6\Big(\tfrac16\Big)^{3}+3\Big(-\tfrac23\Big)^{3}+3\Big(\tfrac13\Big)^{3}+2\Big(-\tfrac12\Big)^{3}+1^{3}\;=\;0$$

$$\mathcal A_{[\text{grav}]^2U(1)}=\sum d_3d_2\,Y\;=\;6\cdot\tfrac16+3\big(-\tfrac23\big)+3\cdot\tfrac13+2\big(-\tfrac12\big)+1\;=\;0$$

**全部精确为零**（用有理数精确算术验证，无浮点误差，见 [验证报告 A1](验证脚本/验证报告.md)）。

### 推论 4.1（代数的电荷中性）

每代 $\sum d_3d_2\,Q_{\rm em}=3(\tfrac23)+3(-\tfrac13)+0+(-1)=2-1-1=0$。

**物质整体电中性**（从而氢原子中性、宇宙大尺度电中性）是场内容的推论。

### 推论 4.2（代数的因果说明）

反常**每代独立**消除，因此标准模型**不解释为什么有 3 代**——第 4 代在反常上同样合法。代数的来源需要新物理（GUT / 弦 / 味对称）。**这是 UFE-1 明确不能回答的问题**（[L5](09_已知局限与否定清单.md)）。
