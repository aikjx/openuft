## 3. 合并似然（任务3）

TUFT n=1 预言（v32，与 n0 同比例）：频移 **+16.26%**；阻尼偏移 −36.6% → τ 比 **+57.6%**。
方法同 v58/v59：H0 δ=0(GR) vs H1 δ=TUFT；BF=exp(ΔlnL)、dB=10log₁₀ BF。

### 3.1 频率通道（H0: δf=0 vs H1: δf=+16.26%）

| 量 | 值 |
|---|---|
| 观测 | med = **−5% ± 20%**（1σ，Isi 68%） |
| lnL(H0=GR) | −0.0312 |
| lnL(H1=+16.26%) | −0.5650 |
| ΔlnL | −0.534 |
| BF / dB | 0.586 / **−2.32 dB** → 弱偏 GR |
| H1=+16.26% 距 med | 21.26% = **1.06σ**（不显著排除） |

- **(a) 保守误差放大 1σ×1.5**（σ=30%）：ΔlnL=−0.237，dB=**−1.03**，排除仅 **0.71σ** → 结论不翻转（更不显著）。
- **(b) 最乐观 c_m 端**（H1=+8.82%）：ΔlnL=−0.207，dB=**−0.90**，排除仅 **0.69σ** → 即便取灵敏带最下端，TUFT 仍在 1σ 内。

### 3.2 阻尼通道（H0: δτ=0 vs H1: δτ=+57.6%）

| 量 | 值 |
|---|---|
| 观测 | med=0%（无毛模），σ₁=32.2%（发表带 [−6%,+100%] 半宽） |
| ΔlnL | −1.598 |
| BF / dB | 0.202 / **−6.94 dB** → 偏 GR |
| H1=+57.6% 距 med | **1.79σ**（不显著） |

- **(a) ×1.5**（σ=48.3%）：dB=−3.09，1.19σ。
- **(b) 最乐观 c_m 端**（H1=+47.5%，pro-TUFT 透明收缩）：dB=−4.72，1.48σ。
- **诚实标注**：发表带 [−6%,+100%] 同时套住 GR(0) 与 TUFT(+57.6%)，阻尼通道**无分辨力**；Isi 自报无毛 BF=1.75 偏 GR。表中数字仅作高斯记账，**不得读作阻尼通道独立否定 TUFT**。

## 4. 三通道结论与四态分级（任务4）

| 通道 | TUFT 预言 | 数据残差 | 排除显著性 | 分级 |
|---|---|---|---|---|
| n0 频率 (v58) | +16.26% | +2%±2.4% | **5.86σ**（边际化联合） | 排除 TUFT / 兼容 GR |
| n0 阻尼 (v59) | +57.6% | +10%±8.5% | **5.59σ** | 排除 TUFT / 兼容 GR |
| **n1 频率（本轮）** | +16.26% | **−5%±20%** | **仅 1.06σ**（×1.5→0.71σ） | **兼容 GR，但未达分辨力** |
| **n1 阻尼（本轮）** | +57.6% | 无信息 [−6,+100] | 仅 1.79σ | **无信息** |

**三结局照写：**
1. **n1 也排除？** 否。n1 频率 TUFT +16% 仅 1.06σ、阻尼 1.79σ，均不显著。
2. **n1 兼容 GR、偏离 TUFT（同证 GR）？** **是。** 频率残差 med=−5%（GR 侧，距 GR 仅 0.25σ），无任何正频移/长阻尼指向 TUFT；与 n0 同向。但分辨力不足（±20%），**不能独立排除 TUFT**。
3. **n1 残差反贴近 TUFT（与 n0 矛盾孤例）？** 否。med=−5% 而非 +16%，无孤例。

**总判定**：n0 双通道（5.86σ / 5.59σ）已干净否定 TUFT 复谱；n1 高阶模落在 GR 侧（−5%）但误差棒 ±20% 太宽、且泛音探测本身不鲁棒（全边缘化 BF≈2.3），**既不能独立排除 TUFT，也不构成任何复活证据；与 n0 无矛盾**。不据 n1 复活理论，也不据 n1 夸大为第三重独立排除。
