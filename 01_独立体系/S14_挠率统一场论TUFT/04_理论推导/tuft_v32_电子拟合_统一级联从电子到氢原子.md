## 〇、结论先行

**统一级联（步进因子 α 或 1/α）**：

$$l_P\,(\text{质量核}) \;\xrightarrow{\;\alpha\;}\; r_e=\alpha\lambda_C \;\xrightarrow{\;\alpha\;}\; \lambda_C=\frac{1}{M}\;(\text{康普顿晕,涌现})\;\xrightarrow{\;1/\alpha\;}\; a_0=\frac{\lambda_C}{\alpha}\,(\text{玻尔})$$

- 尺度链：`1.9e-35 → 2.8e-15 → 3.9e-13 → 5.3e-11 m`（**~24 个量级**）。
- 级联比：`a_0/λ_C = 1/α = 137.036`、`λ_C/r_e = 1/α = 137.036`、`a_0/r_e = 1/α² = 18778.9`。

**氢原子束缚能（同一 {M_e, α}）**：Coulomb `U=−α²M_e c²`、动能 `T=α²M_e c²/2`、`Rydberg R_H = −α²M_e c²/2 = 13.6057 eV`；virial `T=−U/2` 自洽 ✓。

**对 CODATA 核验**：`R_H` 相对偏差 **6.4e-12**（精确）；`a_0` 相对偏差 **6.9e-5**（受限：λ_C 用核拟合质量 M_nat，其 N_core=0.999843 偏离 1 所致，非物理失效）。

**统一级联意义（conjecture 级）**：单一 {M_e, α} 同时给出电子内禀（l_P→r_e→λ_C）与原子束缚（a_0→Rydberg）；与 C0045/57/81/82/85 的电子观测量（M,N,Q,μ,g,C(ω)）共用同一两尺度结构 ⇒ **一个几何模型同时给出电子内禀 + 原子束缚**——统一场论式结构。

**诚实边界**：α 仍是输入，非由两尺度结构独立预言；本步为结构性/一致性验证。

## 一、尺度级联（统一结构）

| 尺度 | 值 (m) | 来源 |
|---|---|---|
| 质量核 ~lO | 1.92e-35 | C0045 核 |
| 经典半径 r_e = α·λ_C | 2.82e-15 | 涌现 λ_C × α |
| 康普顿晕 λ_C = 1/M_nat | 3.86e-13 | C0081 涌现 |
| 玻尔半径 a_0 = λ_C/α | 5.29e-11 | 原子束缚 |

级联比：`a_0/λ_C = 1/α = 137.035999`，`λ_C/r_e = 1/α`，`a_0/r_e = 1/α² = 18778.9`。

## 三、对 CODATA 核验（诚实）

- `R_H`：13.60569312 eV vs CODATA 13.605693122994 eV，相对偏差 **6.4e-12**（精确）。
- `a_0`：5.29214e-11 m vs CODATA 5.29177e-11 m，相对偏差 **6.9e-5**——受限原因是 λ_C 用了核拟合质量 M_nat（其 N_core=0.999843 偏离 1 约 1.6e-4），是核拟合的精度限制，非物理失效。

## 四、统一级联的意义（conjecture 级）

1. 单一 {M_e, α} 贯通电子内禀（l_P→r_e→λ_C）与原子束缚（a_0→Rydberg）：l_P 1.9e-35 → r_e 2.8e-15 → λ_C 3.9e-13 → a_0 5.3e-11 m，共 ~24 个量级。
2. 与 C0045/57/81/82/85 的电子观测量（M,N,Q,μ,g,C(ω)）共用同一两尺度结构 ⇒ 统一场论级结构：一个几何模型同时给出电子内禀 + 原子束缚。
3. 对 CODATA：R_H 偏差 6.4e-12（精确）；a_0 偏差 6.9e-5（受限核拟合质量）。
4. 诚实边界：α 仍是输入，非由两尺度结构独立预言；本步为结构性/一致性验证。
