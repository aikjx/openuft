# 07 · 统一场方程（UFE-1）

[项目根目录](../README.md) · [统一体系层](../06_统一体系层/README.md) · [验证报告](验证脚本/验证报告.md) · [已知局限](09_已知局限与否定清单.md)

> **一句话**：取一个主丛，写一个联络 $\mathcal A$，取它的曲率 $\mathcal F=d\mathcal A+\mathcal A\wedge\mathcal A$，令 $\delta S/\delta\Phi=0$。引力、强力、弱力、电磁力就是这个方程在李代数四个直和因子上的四个分量。

---

## 1. 这个板块是什么

`01_独立体系` 登记了 18 个互不相让的候选体系，`06_统一体系层` 给它们建立了**可比坐标系**。本板块做的是第三件事：

**给出一个具体的、可推导的、可验证的正式理论核心 —— UFE-1。**

它的实质是 Einstein–Cartan（含挠率）引力 + $SU(3)_C\times SU(2)_L\times U(1)_Y$ 规范场 + Higgs + Dirac，以单一总联络曲率表述。这不是一个新提出的"替代物理学"，而是**把已知四种力严格地写进同一个方程**，并把推导、验证、局限全部公开。

## 2. 主方程

$$\boxed{\;\frac{\delta S}{\delta\Phi}=0,\quad \Phi=(e,\mathcal A,H,\Psi)\;}\qquad
\boxed{\;\star D_{\mathcal A}\!\star\mathcal F=\mathcal J,\quad \mathcal F=d\mathcal A+\mathcal A\wedge\mathcal A\;}$$

详见 [00_统一场方程](00_统一场方程.md)。

## 5. 三条不能含混的界限

1. **架构统一 ≠ 物理统一 ≠ 理论完成。** 四种力写进同一个方程，不等于这个方程已解释质量的数值、代的数量、$\Lambda$ 的大小。
2. **通过检验 ≠ 正确。** 47 项检查通过说明"未被这些检验推翻"，不说明"是自然界的最终选择"。
3. **PASS 是成绩，FAIL 是情报。** 本板块剩余的 FAIL 项（耦合不统一）比多数 PASS 项更有研究价值。
