# 第十八章 交流电路与复阻抗

## 一、引言：从直流到交流

第二章讨论了无阻尼 LC 回路的自由振荡，那是一个无源、无电阻的理想系统。实际电路几乎总是由交流电源驱动、含有电阻的。当外加电压随时间作正弦变化时，电路中的电流、电荷也会以同一频率作正弦振荡，但相位可能与电压不一致。描述这一稳态过程的标准方法是**相量法**（phasor method），它把正弦时间微分转化为复数域的乘法，从而把微分方程化为代数方程。

相量法的核心产物是**复阻抗** $Z(\omega)$。在直流情形下，电路只有电阻 $R$，欧姆定律 $V=IR$ 是瞬时成立的代数关系。在交流情形下，电感和电容对电流的阻碍作用不仅依赖于元件参数，还依赖于驱动频率 $\omega$：电感阻碍电流变化，频率越高阻碍越大；电容允许交流"通过"，频率越高阻碍越小。复阻抗把这些频率依赖效应统一在一个复数 $Z(\omega)$ 中，其实部为电阻、虚部为电抗，相位角自动编码了电压与电流之间的相位差。

【已证实】相量法与复阻抗概念由斯坦梅茨于十九世纪末系统引入交流电路分析，至今仍是电路理论、电力工程与射频工程的基础工具。本章全部内容为标准教科书知识，不含原创假说。

本章路线如下：18.2 节建立正弦稳态与相量表示；18.3 节推导三种基本元件（$R,L,C$）的复伏安关系；18.4 节组合得到 RLC 串联复阻抗 $Z(\omega)$；18.5 节求解串联电路的完整稳态响应；18.6 节讨论串联谐振；18.7 节讨论并联谐振；18.8 节推导功率因数与平均功率；18.9 节与第二章机电对偶作对照；18.10 节给出两组数值例题；18.11 节为本章小结。

## 二、正弦稳态与相量法

### （一）正弦量的复数表示

【已证实】设电路中某一物理量（电压或电流）随时间作正弦变化：
$$v(t) = V_0\cos(\omega t + \phi). \tag{18.1}$$

其中 $V_0$ 为振幅（峰值），$\omega$ 为驱动角频率，$\phi$ 为初相角。利用欧拉公式 $e^{i\theta}=\cos\theta+i\sin\theta$，可将 $v(t)$ 写为复数的实部：
$$v(t) = \operatorname{Re}\left[V_0 e^{i(\omega t+\phi)}\right] = \operatorname{Re}\left[\widetilde{V}\, e^{i\omega t}\right], \tag{18.2}$$
其中
$$\widetilde{V} = V_0 e^{i\phi} = V_0(\cos\phi + i\sin\phi) \tag{18.3}$$
称为**电压相量**。相量是一个复数，模 $|\widetilde{V}|=V_0$ 为振幅，辐角 $\arg\widetilde{V}=\phi$ 为初相。时间因子 $e^{i\omega t}$ 在稳态分析中对所有元件相同，可省略不写，只需跟踪相量本身。

类似地，电流相量记为
$$\widetilde{I} = I_0 e^{i\theta}, \tag{18.4}$$
其瞬时值为 $i(t)=\operatorname{Re}[\widetilde{I}e^{i\omega t}]$。

### （二）微分运算的复数化

【推导】相量法的关键优势在于：对正弦量的时间微分，在相量域中退化为乘以 $i\omega$。

对 (18.2) 求时间导数：
$$\frac{dv}{dt} = \frac{d}{dt}\operatorname{Re}\left[\widetilde{V}e^{i\omega t}\right] = \operatorname{Re}\left[\widetilde{V}\cdot i\omega\, e^{i\omega t}\right]. \tag{18.5}$$

因此，若 $v(t)$ 的相量为 $\widetilde{V}$，则 $dv/dt$ 的相量为 $i\omega\widetilde{V}$。这一规则把微分方程化为代数方程：原来 $\dot v$ 对应相量 $i\omega\widetilde{V}$，$\ddot v$ 对应相量 $(i\omega)^2\widetilde{V}=-\omega^2\widetilde{V}$。

## 三、三种基本元件的复伏安关系

### （三）电阻

【已证实】欧姆定律对瞬时值成立：
$$v_R(t) = R\, i(t). \tag{18.6}$$

用相量表示：
$$\widetilde{V}_R = R\,\widetilde{I}. \tag{18.7}$$

电阻的电压与电流同相位：$\widetilde{V}_R$ 与 $\widetilde{I}$ 的辐角相同，比值为正实数 $R$。

### （四）电感

【已证实】电感电压与电流的时间导数成正比，见 (2.9)：
$$v_L(t) = L\frac{di}{dt}. \tag{18.8}$$

用相量表示，由 (18.5)，$di/dt$ 的相量为 $i\omega\widetilde{I}$，故：
$$\widetilde{V}_L = i\omega L\,\widetilde{I}. \tag{18.9}$$

定义**感抗**
$$X_L(\omega) = \omega L, \tag{18.10}$$
则 $\widetilde{V}_L = i X_L\widetilde{I}$。电感电压的相位比电流超前 $\pi/2$（因为乘以 $i=e^{i\pi/2}$），且感抗 $X_L$ 随频率线性增大：频率越高，电感对电流的阻碍越大。

### （五）电容

【已证实】电容电压与电荷的关系为 $v_C=q/C$（(2.8)），而电流 $i=dq/dt$，故 $i=C\,dv_C/dt$，即
$$v_C(t) = \frac{1}{C}\int i(t)\,dt. \tag{18.11}$$

用相量表示。积分运算在相量域中对应除以 $i\omega$（因为微分对应乘 $i\omega$，逆运算即除 $i\omega$）：
$$\widetilde{V}_C = \frac{1}{i\omega C}\,\widetilde{I}. \tag{18.12}$$

利用 $1/i=-i$，可写为
$$\widetilde{V}_C = -i\frac{1}{\omega C}\,\widetilde{I}. \tag{18.13}$$

定义**容抗**
$$X_C(\omega) = \frac{1}{\omega C}, \tag{18.14}$$
则 $\widetilde{V}_C = -i X_C\widetilde{I}$。电容电压的相位比电流滞后 $\pi/2$（因为乘以 $-i=e^{-i\pi/2}$），且容抗 $X_C$ 随频率增大而减小：频率越高，电容"通过"交流越容易。

### （六）元件对照表

| 元件 | 瞬时关系 | 相量关系 | 阻抗形式 | 相位关系 |
|---|---|---|---|---|
| 电阻 $R$ | $v_R=Ri$ | $\widetilde{V}_R=R\widetilde{I}$ | $Z_R=R$ | 同相 |
| 电感 $L$ | $v_L=L\,di/dt$ | $\widetilde{V}_L=i\omega L\widetilde{I}$ | $Z_L=i\omega L$ | 电压超前电流 $\pi/2$ |
| 电容 $C$ | $v_C=(1/C)\int i\,dt$ | $\widetilde{V}_C=(1/i\omega C)\widetilde{I}$ | $Z_C=1/(i\omega C)=-i/(\omega C)$ | 电压滞后电流 $\pi/2$ |

## 四、复阻抗 $Z(\omega)$ 的推导

### （七）RLC 串联电路

【推导】考虑电阻 $R$、电感 $L$、电容 $C$ 串联，接在角频率为 $\omega$ 的交流电压源 $\widetilde{V}$ 上。串联电路中电流处处相同，记为 $\widetilde{I}$。由基尔霍夫电压定律（(2.10) 的交流推广），总电压等于各元件电压之和：
$$\widetilde{V} = \widetilde{V}_R + \widetilde{V}_L + \widetilde{V}_C. \tag{18.15}$$

代入 (18.7)(18.9)(18.13)：
$$\widetilde{V} = R\widetilde{I} + i\omega L\,\widetilde{I} + \frac{1}{i\omega C}\widetilde{I} = \left[R + i\left(\omega L - \frac{1}{\omega C}\right)\right]\widetilde{I}. \tag{18.16}$$

定义**复阻抗**
$$\boxed{Z(\omega) = R + i\left(\omega L - \frac{1}{\omega C}\right)}. \tag{18.17}$$

则欧姆定律的交流形式为：
$$\widetilde{V} = Z(\omega)\,\widetilde{I}. \tag{18.18}$$

【推导】式 (18.17) 是本章的核心公式。复阻抗 $Z(\omega)$ 是一个复数，其实部为电阻 $R$（与频率无关），虚部为**电抗**
$$X(\omega) = \omega L - \frac{1}{\omega C}. \tag{18.19}$$

电抗 $X(\omega)$ 是感抗 $X_L=\omega L$ 与容抗 $X_C=1/(\omega C)$ 之差。当 $X>0$ 时电路呈感性（电感占主导），当 $X<0$ 时呈容性（电容占主导）。

### （八）阻抗的模与辐角

将 $Z=R+iX$ 写成极坐标形式：
$$Z(\omega) = |Z|e^{i\phi}, \tag{18.20}$$
其中模
$$|Z| = \sqrt{R^2 + X^2} = \sqrt{R^2 + \left(\omega L - \frac{1}{\omega C}\right)^2}, \tag{18.21}$$
辐角（阻抗角）
$$\phi(\omega) = \arctan\frac{X}{R} = \arctan\left(\frac{\omega L - 1/(\omega C)}{R}\right). \tag{18.22}$$

【推导】由 $\widetilde{V}=Z\widetilde{I}$ 及极坐标形式，$\arg\widetilde{V}-\arg\widetilde{I}=\arg Z=\phi$。即电压相位与电流相位之差为 $\phi$。当 $\phi>0$ 时电压超前电流（感性电路）；当 $\phi<0$ 时电压滞后电流（容性电路）。

## 五、RLC 串联电路的完整稳态解

### （九）电流幅值与相位

【推导】设外加电压源为
$$v(t) = V_0\cos\omega t, \tag{18.23}$$
其相量为 $\widetilde{V}=V_0$（取初相为零）。由 (18.18)，电流相量为：
$$\widetilde{I} = \frac{\widetilde{V}}{Z} = \frac{V_0}{|Z|e^{i\phi}} = \frac{V_0}{|Z|}e^{-i\phi}. \tag{18.24}$$

因此电流瞬时值为：
$$i(t) = \frac{V_0}{|Z|}\cos(\omega t - \phi). \tag{18.25}$$

电流振幅为 $I_0=V_0/|Z|$，相位比电压落后 $\phi$（或超前 $-\phi$）。当 $\phi>0$（感性）时，电流滞后电压；当 $\phi<0$（容性）时，电流超前电压。

### （十）各元件电压

电阻电压：
$$\widetilde{V}_R = R\widetilde{I} = \frac{RV_0}{|Z|}e^{-i\phi}, \tag{18.26}$$
与电流同相，振幅 $V_{R0}=I_0 R$。

电感电压：
$$\widetilde{V}_L = i\omega L\,\widetilde{I} = \frac{\omega L\,V_0}{|Z|}e^{i(\pi/2-\phi)}, \tag{18.27}$$
振幅 $V_{L0}=I_0\omega L$，相位比电流超前 $\pi/2$。

电容电压：
$$\widetilde{V}_C = \frac{1}{i\omega C}\widetilde{I} = \frac{V_0}{\omega C|Z|}e^{-i(\pi/2+\phi)}, \tag{18.28}$$
振幅 $V_{C0}=I_0/(\omega C)$，相位比电流滞后 $\pi/2$。

电感电压与电容电压相位相反（差 $\pi$），在串联谐振时两者互相抵消。

## 六、串联谐振

### （十一）谐振频率的推导

【推导】当电抗 $X(\omega)=0$ 时，阻抗退化为纯电阻 $Z=R$，电流振幅达到最大值 $I_0=V_0/R$。这一频率称为**串联谐振频率** $\omega_0$。

由 $X(\omega_0)=0$：
$$\omega_0 L - \frac{1}{\omega_0 C} = 0. \tag{18.29}$$

解得：
$$\boxed{\omega_0 = \frac{1}{\sqrt{LC}}}. \tag{18.30}$$

【推导】式 (18.30) 与第二章 LC 回路的自由振荡频率 (2.12) 完全相同。物理诠释：在驱动频率等于系统固有频率时，电感与电容的电抗互相抵消，电路对交流源呈现最小阻抗，电流达到最大。这是受迫振子共振现象在电路中的对应——第十五章将在机械振子语境中详细讨论同一现象。

### （十二）谐振时的特性

在 $\omega=\omega_0$ 处，模阻抗取最小值 $|Z|=R$，电流振幅达到最大 $I_0=V_0/R$，且相位 $\phi=0$、电压与电流同相。此时感抗与容抗相等且相反：$X_L=\omega_0 L = L/\sqrt{LC}=\sqrt{L/C}$，$X_C=1/(\omega_0 C)=\sqrt{L/C}$。相应地，电感电压振幅 $V_{L0}=I_0\sqrt{L/C}$ 与电容电压振幅 $V_{C0}=I_0\sqrt{L/C}$ 数值相等，但二者相位差 $\pi$。

定义**品质因数**
$$Q = \frac{1}{R}\sqrt{\frac{L}{C}}, \tag{18.31}$$
则谐振时 $V_{L0}=V_{C0}=Q\,V_0$。在高 $Q$ 电路中（$Q\gg1$），电感与电容上的电压可以远大于外加电压，这一现象称为**电压谐振**，在无线电调谐电路中用于选频放大【已证实】。

### （十三）阻抗随频率的变化

将 $|Z|$ 作为 $\omega$ 的函数考察。由 (18.21)：
$$|Z(\omega)| = \sqrt{R^2 + \left(\omega L - \frac{1}{\omega C}\right)^2}. \tag{18.32}$$

当 $\omega\to0$（直流极限），$1/(\omega C)\to\infty$，故 $|Z|\to\infty$：电容隔断直流。当 $\omega\to\infty$，$\omega L\to\infty$，故 $|Z|\to\infty$：电感隔断高频。在 $\omega=\omega_0$ 处 $|Z|$ 取最小值 $R$。整条阻抗曲线关于 $\omega_0$ 不对称，但在 $\omega_0$ 附近近似对称。

## 七、并联谐振

### （十四）RLC 并联电路

【推导】电阻 $R$、电感 $L$、电容 $C$ 三者并联在交流电压源 $\widetilde{V}$ 上。并联电路中各元件电压相同，总电流为各支路电流之和：
$$\widetilde{I} = \widetilde{I}_R + \widetilde{I}_L + \widetilde{I}_C. \tag{18.33}$$

各支路电流：
$$\widetilde{I}_R = \frac{\widetilde{V}}{R}, \quad \widetilde{I}_L = \frac{\widetilde{V}}{i\omega L}, \quad \widetilde{I}_C = i\omega C\,\widetilde{V}. \tag{18.34}$$

代入 (18.33)：
$$\widetilde{I} = \left[\frac{1}{R} + \frac{1}{i\omega L} + i\omega C\right]\widetilde{V} = \left[\frac{1}{R} + i\left(\omega C - \frac{1}{\omega L}\right)\right]\widetilde{V}. \tag{18.35}$$

定义**复导纳** $Y=1/Z$：
$$Y(\omega) = \frac{1}{R} + i\left(\omega C - \frac{1}{\omega L}\right). \tag{18.36}$$

### （十五）并联谐振频率

并联谐振发生在导纳虚部为零时（总电流与电压同相）：
$$\omega C - \frac{1}{\omega L} = 0 \quad\Longrightarrow\quad \omega_0 = \frac{1}{\sqrt{LC}}. \tag{18.37}$$

【推导】并联谐振频率与串联谐振频率 (18.30) 相同，均为 $1/\sqrt{LC}$。但物理图像相反：串联谐振时阻抗最小、电流最大；并联谐振时导纳最小、阻抗最大，电路对电流源呈现高阻抗。在实际电路中，并联谐振常被用于选频网络（如收音机中频变压器）。

并联谐振时，电感支路与电容支路的电流大小相等、相位相反，在回路内部循环，而总电流最小。定义并联品质因数
$$Q_p = R\sqrt{\frac{C}{L}}, \tag{18.38}$$
则谐振时支路电流是总电流的 $Q_p$ 倍，称为**电流谐振**【已证实】。

## 八、功率因数与平均功率

### （十六）瞬时功率

【推导】设电压与电流分别为
$$v(t) = V_0\cos\omega t, \qquad i(t) = I_0\cos(\omega t - \phi). \tag{18.39}$$

瞬时功率为：
$$p(t) = v(t)i(t) = V_0I_0\cos\omega t\cos(\omega t-\phi). \tag{18.40}$$

利用积化和差公式 $\cos A\cos B=\tfrac{1}{2}[\cos(A+B)+\cos(A-B)]$：
$$p(t) = \frac{V_0I_0}{2}\left[\cos(2\omega t-\phi) + \cos\phi\right]. \tag{18.41}$$

### （十七）平均功率

瞬时功率由两部分组成：第二项 $\tfrac{V_0I_0}{2}\cos\phi$ 是常数（与时间无关），第一项 $\tfrac{V_0I_0}{2}\cos(2\omega t-\phi)$ 以两倍频率 $2\omega$ 振荡，在一个周期内平均值为零。

一个周期 $T=2\pi/\omega$ 内的平均功率为：
$$P_{\mathrm{avg}} = \frac{1}{T}\int_0^T p(t)\,dt = \frac{V_0I_0}{2}\cos\phi. \tag{18.42}$$

用有效值（RMS）表示，$V_{\mathrm{rms}}=V_0/\sqrt{2}$，$I_{\mathrm{rms}}=I_0/\sqrt{2}$，则：
$$P_{\mathrm{avg}} = V_{\mathrm{rms}}I_{\mathrm{rms}}\cos\phi. \tag{18.43}$$

### （十八）功率因数

【推导】式 (18.43) 中 $\cos\phi$ 称为**功率因数**：
$$\mathrm{PF} = \cos\phi = \cos\left[\arctan\left(\frac{X}{R}\right)\right] = \frac{R}{\sqrt{R^2+X^2}} = \frac{R}{|Z|}. \tag{18.44}$$

功率因数无量纲，取值范围 $0\leq\cos\phi\leq1$。当电路为纯电阻（$X=0$）时，$\cos\phi=1$，全部功率被电阻消耗。当电路为纯电抗（$R=0$）时，$\cos\phi=0$，平均功率为零：电感与电容只在电压源与电路之间来回交换能量，不消耗任何净功率。

功率因数在电力工程中意义重大：传输相同有功功率 $P$ 时，$\cos\phi$ 越小则线路电流越大，焦耳损耗 $I^2R_{\mathrm{line}}$ 越大。工业用户通常被要求将功率因数补偿到接近 1，以减少电网损耗【已证实】。

### （十九）复功率

用相量表示，定义复功率
$$\bar{S} = \frac{1}{2}\widetilde{V}\,\widetilde{I}^*, \tag{18.45}$$
其中 $\widetilde{I}^*$ 为电流相量的复共轭。代入 $\widetilde{V}=V_0e^{i0}$、$\widetilde{I}=I_0e^{-i\phi}$：
$$\bar{S} = \frac{1}{2}V_0e^{i0}\cdot I_0e^{i\phi} = \frac{V_0I_0}{2}e^{i\phi} = \frac{V_0I_0}{2}(\cos\phi+i\sin\phi). \tag{18.46}$$

实部为平均功率 $P_{\mathrm{avg}}=\tfrac{V_0I_0}{2}\cos\phi$（有功功率，单位 W），虚部为无功功率 $Q_{\mathrm{reactive}}=\tfrac{V_0I_0}{2}\sin\phi$（单位 var）。

## 九、与第二章机电对偶的对照

### （二十）RLC 串联方程的机械对应

【推导】第二章建立了机电对偶映射：$m\leftrightarrow L$，$k\leftrightarrow1/C$，$x\leftrightarrow q$，$F\leftrightarrow V$。现在加上电阻，对应机械阻尼。

RLC 串联电路的时域方程可由 (18.16) 反推：对 (18.16) 乘以 $e^{i\omega t}$ 并取实部，或直接从基尔霍夫定律写出：
$$L\ddot q + R\dot q + \frac{1}{C}q = v(t). \tag{18.47}$$

这是一个带阻尼与驱动的二阶线性非齐次方程。对照机械受迫振子：
$$m\ddot x + \gamma\dot x + kx = F(t). \tag{18.48}$$

在映射 $m\leftrightarrow L$、$\gamma\leftrightarrow R$、$k\leftrightarrow1/C$、$x\leftrightarrow q$、$F\leftrightarrow V$ 下，两方程严格同构。电阻 $R$ 对应机械阻尼系数 $\gamma$，它在电路中以焦耳热形式消耗功率，正如阻尼力在机械系统中以摩擦热形式消耗能量。

### （二十）复阻抗与机械阻抗的对应

电路复阻抗 $Z=V/I$（电压除以电流）对应机械阻抗 $Z_m=F/v$（力除以速度）。在映射 $v=\dot x\leftrightarrow I=\dot q$ 下，电阻 $R$（电压/电流）对应阻尼系数 $\gamma$（力/速度）；感抗 $i\omega L$（来自 $L\dot I$）对应惯性项 $i\omega m$（来自 $m\dot v$，因为 $F=m\dot v$，相量域为 $i\omega m\widetilde{v}$）；容抗 $1/(i\omega C)$（来自 $q/C$，$q=\int i\,dt$）对应弹性项 $1/(i\omega k)$（来自 $kx$，$x=\int v\,dt$）。

因此机械复阻抗为
$$Z_m(\omega) = \gamma + i\left(\omega m - \frac{k}{\omega}\right), \tag{18.49}$$
与电路复阻抗 (18.17) 在映射下严格对应。

### （二十）谐振频率的同构

电路串联谐振频率 $\omega_0=1/\sqrt{LC}$（(18.30)）在映射 $L\leftrightarrow m$、$1/C\leftrightarrow k$ 下变为 $\omega_0=\sqrt{k/m}$，即机械振子的固有频率 (2.4)。这一对应表明：电路谐振与机械共振是同一数学现象在不同物理载体上的表现。第十五章将在机械受迫振子语境中推导共振曲线，其形状与本章阻抗曲线 (18.32) 完全相同。

## 十、数值例题

### （二十）例题一：谐振频率与品质因数

【推导】给定 RLC 串联电路参数：$R=10.0\ \Omega$，$L=0.100\ \mathrm{H}$，$C=100\ \mu\mathrm{F}=1.00\times10^{-4}\ \mathrm{F}$。

谐振角频率（代入 (18.30)）：
$$\omega_0 = \frac{1}{\sqrt{LC}} = \frac{1}{\sqrt{0.100\times1.00\times10^{-4}}} = \frac{1}{\sqrt{1.00\times10^{-5}}}.$$

计算 $\sqrt{1.00\times10^{-5}} = \sqrt{10}\times10^{-3} \approx 3.1623\times10^{-3}\ \mathrm{s}$。故
$$\omega_0 = \frac{1}{3.1623\times10^{-3}} \approx 316.23\ \mathrm{rad/s}.$$

谐振频率（Hz）：
$$f_0 = \frac{\omega_0}{2\pi} = \frac{316.23}{2\pi} \approx 50.33\ \mathrm{Hz}.$$

品质因数（代入 (18.31)）：
$$Q = \frac{1}{R}\sqrt{\frac{L}{C}} = \frac{1}{10.0}\sqrt{\frac{0.100}{1.00\times10^{-4}}} = \frac{1}{10.0}\sqrt{1000} = \frac{31.623}{10.0} \approx 3.162.$$

谐振时感抗与容抗：
$$X_L(\omega_0) = \omega_0 L = 316.23\times0.100 = 31.62\ \Omega,$$
$$X_C(\omega_0) = \frac{1}{\omega_0 C} = \frac{1}{316.23\times1.00\times10^{-4}} = \frac{1}{0.031623} \approx 31.62\ \Omega.$$

两者相等，验证谐振条件 (18.29)。

### （二十）例题二：非谐振频率下的阻抗与相位

【推导】仍用例题一参数，取驱动角频率 $\omega=200\ \mathrm{rad/s}$（低于谐振频率 $316.23\ \mathrm{rad/s}$），外加电压振幅 $V_0=10.0\ \mathrm{V}$。

感抗（代入 (18.10)）：
$$X_L = \omega L = 200\times0.100 = 20.0\ \Omega.$$

容抗（代入 (18.14)）：
$$X_C = \frac{1}{\omega C} = \frac{1}{200\times1.00\times10^{-4}} = \frac{1}{0.0200} = 50.0\ \Omega.$$

电抗（代入 (18.19)）：
$$X = X_L - X_C = 20.0 - 50.0 = -30.0\ \Omega.$$

电抗为负，电路呈容性。

复阻抗（代入 (18.17)）：
$$Z = R + iX = 10.0 - i\,30.0\ \Omega.$$

阻抗模（代入 (18.21)）：
$$|Z| = \sqrt{R^2+X^2} = \sqrt{10.0^2+(-30.0)^2} = \sqrt{100+900} = \sqrt{1000} \approx 31.62\ \Omega.$$

阻抗角（代入 (18.22)）：
$$\phi = \arctan\frac{X}{R} = \arctan\left(\frac{-30.0}{10.0}\right) = \arctan(-3.00) \approx -71.57^\circ.$$

负号表示电压相位滞后电流，电流超前电压约 $71.6^\circ$，符合容性电路特征。

电流振幅：
$$I_0 = \frac{V_0}{|Z|} = \frac{10.0}{31.62} \approx 0.3162\ \mathrm{A}.$$

各元件电压振幅：
$$V_{R0} = I_0 R = 0.3162\times10.0 = 3.162\ \mathrm{V},$$
$$V_{L0} = I_0 X_L = 0.3162\times20.0 = 6.325\ \mathrm{V},$$
$$V_{C0} = I_0 X_C = 0.3162\times50.0 = 15.81\ \mathrm{V}.$$

验证电压和：电阻电压与电流同相（$3.162\ \mathrm{V}$），电感电压超前电流 $90^\circ$（$6.325\ \mathrm{V}$），电容电压滞后电流 $90^\circ$（$15.81\ \mathrm{V}$）。电感与电容电压反相，净电抗电压为 $15.81-6.325=9.485\ \mathrm{V}$（容性方向），与电阻电压 $3.162\ \mathrm{V}$ 正交。总电压振幅应为 $\sqrt{3.162^2+9.485^2}=\sqrt{10.0+90.0}=\sqrt{100}=10.0\ \mathrm{V}$，与外加电压一致，验证计算自洽。

平均功率（代入 (18.42)）：
$$P_{\mathrm{avg}} = \frac{V_0I_0}{2}\cos\phi = \frac{10.0\times0.3162}{2}\cos(-71.57^\circ).$$

$\cos(-71.57^\circ)=\cos(71.57^\circ)\approx0.3162$（也即功率因数 $R/|Z|=10.0/31.62=0.3162$，与 (18.44) 一致）。故：
$$P_{\mathrm{avg}} = \frac{10.0\times0.3162}{2}\times0.3162 \approx 0.500\ \mathrm{W}.$$

作为验证，纯电阻消耗的平均功率为 $I_{\mathrm{rms}}^2R=(0.3162/\sqrt{2})^2\times10.0=(0.100)\times10.0=1.000/2=0.500\ \mathrm{W}$，两者一致。电感与电容不消耗平均功率，全部有功功率由电阻消耗。

## 十一、本章小结

本章建立了交流电路的相量分析框架。正弦量 $v(t)=V_0\cos(\omega t+\phi)$ 用相量 $\widetilde{V}=V_0e^{i\phi}$ 表示，时间微分对应相量域乘以 $i\omega$。三种基本元件的复伏安关系为 $Z_R=R$、$Z_L=i\omega L$、$Z_C=1/(i\omega C)$。RLC 串联电路的复阻抗为 $Z(\omega)=R+i(\omega L-1/\omega C)$（(18.17)），模 $|Z|=\sqrt{R^2+X^2}$（(18.21)），辐角 $\phi=\arctan(X/R)$（(18.22)）。

串联谐振频率 $\omega_0=1/\sqrt{LC}$（(18.30)），此时 $Z=R$ 最小、电流最大、电压电流同相。品质因数 $Q=(1/R)\sqrt{L/C}$（(18.31)）决定谐振峰锐度。并联谐振频率同为 $1/\sqrt{LC}$（(18.37)），但表现为阻抗最大。平均功率 $P_{\mathrm{avg}}=V_{\mathrm{rms}}I_{\mathrm{rms}}\cos\phi$（(18.43)），其中功率因数 $\cos\phi=R/|Z|$（(18.44)）。

与第二章机电对偶的对照表明：RLC 串联方程 $L\ddot q+R\dot q+q/C=v(t)$（(18.47)）在映射 $L\leftrightarrow m$、$R\leftrightarrow\gamma$、$1/C\leftrightarrow k$ 下与机械受迫振子方程同构；电路复阻抗与机械复阻抗 (18.49) 严格对应；电路谐振频率与机械固有频率在同一映射下相等。

数值例题一（$R=10.0\ \Omega$，$L=0.100\ \mathrm{H}$，$C=100\ \mu\mathrm{F}$）给出 $\omega_0\approx316.23\ \mathrm{rad/s}$、$f_0\approx50.33\ \mathrm{Hz}$、$Q\approx3.162$。例题二（$\omega=200\ \mathrm{rad/s}$，$V_0=10.0\ \mathrm{V}$）给出 $Z=10.0-i30.0\ \Omega$、$|Z|\approx31.62\ \Omega$、$\phi\approx-71.57^\circ$、$I_0\approx0.3162\ \mathrm{A}$、$P_{\mathrm{avg}}\approx0.500\ \mathrm{W}$，并验证了功率计算的自洽性。
