# 第一章 暗物质的观测证据与现有模型的问题
## 1.1 暗物质的观测证据
暗物质的存在有很多独立的观测证据：
1.  **星系旋转曲线**：漩涡星系的恒星旋转速度不随半径减小，而是保持平坦，说明星系外围有不发光的暗物质晕；
2.  **星系团速度弥散**：星系团中星系的速度弥散太大，可见物质的引力不足以束缚星系，需要暗物质；
3.  **引力透镜**：星系团的引力透镜效应显示质量比可见物质大很多，比如子弹星系团的引力透镜质量和可见物质分离；
4.  **宇宙微波背景**：CMB的各向异性功率谱显示宇宙中暗物质占27%，普通物质占5%；
5.  **大尺度结构**：宇宙大尺度结构的形成需要暗物质提供引力种子，普通物质的引力不够，无法形成现在的结构。

这些证据都说明宇宙中存在大量不发光的物质，只通过引力相互作用。

## 1.2 现有暗物质模型的问题
最流行的暗物质模型是冷暗物质（CDM），假设暗物质是弱相互作用大质量粒子（WIMP），但是：
1.  经过几十年的直接探测，没有发现任何WIMP粒子，LUX-ZEPLIN、XENONnT等实验都得到零结果；
2.  冷暗物质模型在小尺度有问题：尖点问题、缺失卫星问题、大而不能倒问题等；
3.  对撞机没有产生任何暗物质粒子，LHC没有发现超出标准模型的粒子。

其他模型比如轴子、MACHO、修改牛顿动力学（MOND）也都有各自的问题，MOND可以解释星系旋转曲线，但是无法解释星系团和CMB，MACHO被微引力透镜观测排除，轴子也没有被探测到。

## 1.3 我们的模型：几何暗物质
我们的暗物质模型是几何暗物质，暗物质不是粒子，是高维挠率场在4维时空的投影，是时空几何的效应，所以直接探测实验永远找不到暗物质粒子，因为它根本不是粒子，这解释了为什么所有直接探测实验都是零结果。同时，挠率场的引力效应可以解释所有暗物质观测，包括星系旋转曲线、星系团、引力透镜、CMB、大尺度结构，而且没有小尺度危机，因为挠率场是平滑的，不是冷的粒子。

## 1.4 本章小结
暗物质有很多独立观测证据，但是粒子暗物质模型遇到了严重问题，直接探测零结果，小尺度危机。我们的几何暗物质模型不需要新粒子，是高维挠率场的效应，可以解释所有观测，自然解释直接探测零结果。
