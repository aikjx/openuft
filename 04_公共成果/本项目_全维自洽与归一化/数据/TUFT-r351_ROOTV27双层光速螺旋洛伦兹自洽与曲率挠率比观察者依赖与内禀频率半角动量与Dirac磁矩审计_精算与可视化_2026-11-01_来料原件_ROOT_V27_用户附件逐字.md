# ROOT V27｜空间光速螺旋、内禀频率与电子自旋的联合突破

一个在自身中心参考系中以光速做圆周运动的假设性内部运动点，经过洛伦兹变换后，会在实验室参考系中形成总速度仍为光速的圆柱螺旋。但螺旋曲率与挠率的比值会随观察者速度改变。

## 一、建立一个真正可以进行洛伦兹变换的模型

假设一个电子整体具有质量 \\(m_e\\)，其中心可以静止，而另有一个假设性的内部运动点绕中心旋转。

在中心静止系：

\\[ X^\mu(\tau)= \left(c\tau,\\, R\cos\Omega_0\tau,\\, R\sin\Omega_0\tau,\\, 0\right) \\]

这里 \\(\tau\\) 是电子中心的固有时间，不是内部光速运动点的固有时间。

令内部切向速度为光速：

\\[ \boxed{R\Omega_0=c} \\]

于是该内部轨迹为光状曲线。

现在沿 \\(z\\) 轴进行速度为 \\(u=\beta c\\) 的洛伦兹变换：

\\[ t=\gamma\tau,\qquad z=\gamma\beta c\tau,\qquad \gamma=\frac1{\sqrt{1-\beta^2}} \\]

实验室里得到：

\\[ \boxed{ \mathbf r(t)= \begin{pmatrix} R\cos(\Omega_0t/\gamma)\\\ R\sin(\Omega_0t/\gamma)\\\ \beta ct \end{pmatrix} } \\]

这正是 ROOT 希望研究的空间圆柱螺旋。

其各项参数自动满足：

\\[ \omega_{\rm lab}=\frac{\Omega_0}{\gamma},\qquad v_\perp=\frac c\gamma,\qquad u=\beta c \\]

因此：

\\[ \boxed{ v_\perp^2+u^2=c^2 } \\]

这一步没有引入精细结构常数，也不需要调节螺旋角。

它给出了一种数学上洛伦兹自洽的内部光速螺旋构造。不过，这只是具有光状切线的几何运动学模型，还不是从 Dirac–Maxwell 动力学导出的真实电子内部轨迹。

## 二、重新求导：找到一个观察者依赖的曲率挠率比

对上述实验室螺旋求导：

\\[ \kappa=\frac{R\omega_{\rm lab}^2}{c^2} ,\qquad \tau_3=\frac{u\omega_{\rm lab}}{c^2} \\]

代入 \\(R\Omega_0=c\\)：

\\[ \boxed{ \kappa=\frac1{R\gamma^2}, \qquad \tau_3=\frac{\beta}{R\gamma} } \\]

从而：

\\[ \boxed{ \frac{\kappa}{|\tau_3|} =\frac1{\gamma|\beta|} =\frac{\sqrt{1-\beta^2}}{|\beta|} } \tag{V27-1} \\]

这是本轮最重要的新检验式。

它的右边包含观察者相对于电子中心的速度 \\(\beta\\)，因此不是电子的普适内禀常数。

同一内禀光速运动在不同洛伦兹参考系中的曲率挠率比

实际计算。曲线表示同一内部圆周模型在不同轴向 boost 下的三维曲率挠率比；虚线仅标出实测 α 的位置。

例如：

同一个内禀圆周模型，可以呈现完全不同的三维曲率挠率比。

而自然界的低能精细结构常数必须是一个洛伦兹不变的物理耦合参数。

因此，直接令 \\(\alpha=\kappa/\tau_3\\) 不能作为相对论一致的普适定律。

## 四、内禀频率与电子自旋：发现第二个关键检验

Dirac 方程中的 Zitterbewegung（颤动）具有一个著名的频率尺度：

\\[ \boxed{\Omega_Z=\frac{2m_ec^2}{\hbar}} \\]

在假设内部运动速度为 \\(c\\) 的圆周模型中：

\\[ R_Z=\frac c{\Omega_Z} =\frac{\hbar}{2m_ec} \\]

不使用 \\(\alpha\\)，实际得到：

| 内禀参数                     | 计算数值                                   |
| ------------------------ | -------------------------------------- |
| 内部圆周半径 \\(R_Z\\)         | \\(1.93079633718\times10^{-13}\\) m    |
| 角频率 \\(\Omega_Z\\)       | \\(1.55268814337\times10^{21}\\) rad/s |
| 普通频率 \\(f_Z\\)           | \\(2.47117993098\times10^{20}\\) Hz    |
| 内部切向速度 \\(R_Z\Omega_Z\\) | \\(c\\)                                |

若进一步假定内部运动携带能量 \\(E=m_ec^2\\)，其动量大小为 \\(p=E/c=m_ec\\)，则形式上的轨道角动量为：

\\[ L=R_Zp =\frac{\hbar}{2m_ec}m_ec \\]

即：

\\[ \boxed{L=\frac{\hbar}{2}} \\]

这个构造同时关联了质量、频率、半径、光速与半整数角动量尺度。

但必须明确：上面的角动量结果依赖指定内部动量及经典轨道的假设，不能替代对电子量子自旋的推导。

尤其值得注意，2026 年发表于 Nuclear Physics B 的 Dirac 涡旋电子研究强调，颤动运动与正负能量分量干涉、位置算符的选择有关；Foldy–Wouthuysen/Newton–Wigner 均值位置并不出现同样的横向质心颤动。

## 五、第三项检验：一个简单旋转电荷环能否产生正确的电子磁矩？

假设全部电子电荷沿这个圆周旋转。

圆周电流：

\\[ I=\frac{e\Omega_Z}{2\pi} \\]

产生的磁矩大小为：

\\[ \mu_{\rm ring}=I\pi R_Z^2 =\frac{e\Omega_ZR_Z^2}{2} \\]

代入 \\(\Omega_ZR_Z=c\\)：

\\[ \boxed{ \mu_{\rm ring}=\frac{e\hbar}{4m_e} =\frac12\mu_B } \\]

而实际电子磁矩大小为：

\\[ |\mu_e|=(1+a_e)\mu_B \\]

其中 CODATA 2022：

\\[ a_e=0.00115965218046(18) \\]

因此：

\\[ \boxed{ \frac{|\mu_e|}{\mu_{\rm ring}} =2.00231930436092 } \\]

为什么 Dirac 理论能够得到不同结果？

利用 Pauli 矩阵恒等式和电磁最小耦合：

\\[ (\boldsymbol{\sigma}\cdot\boldsymbol{\pi})^2 = \boldsymbol{\pi}^2-q\hbar\boldsymbol{\sigma}\cdot\mathbf B \\]

得到低能磁场相互作用：

\\[ H_{\rm spin}=-\frac qm\mathbf S\cdot\mathbf B \\]

这给出电子的树级旋磁比 \\(g=2\\)；量子电动力学的高阶修正进一步解释 \\(g-2\\)。

因此，ROOT 如果希望把内部光速旋转与电子真实物理统一，必须能够从完整旋量动力学得到 \\(g=2\\)，而不能只依赖一个经典环形电流。
