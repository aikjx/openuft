# 一、已知结构

我们已经得到一般式：

[
\omega
======

\frac{c}{\alpha R}
\sqrt{\frac{r_g}{2R}}
]

其中：

[
r = \alpha R
]

α 目前是待定常数。

---

# 二、唯一约束必须来自哪里？

如果 α 不是人为设定，它必须来自：

1. 几何自洽性
2. 极限一致性
3. 与弱场动力学一致
4. 强场边界条件

我们逐条筛选。

# 三、弱场极限约束（决定性条件）

在弱引力场，理论必须退化为牛顿引力：

[
\omega^2 = \frac{GM}{R^3}
]

现在计算我们的一般式：

---

## 第一步：平方

[
\omega^2
========

\frac{c^2}{\alpha^2 R^2}
\frac{r_g}{2R}
]

代入

[
r_g=\frac{2GM}{c^2}
]

得到：

[
\omega^2
========

\frac{c^2}{\alpha^2 R^2}
\frac{2GM}{c^2}
\frac{1}{2R}
]

化简：

[
\omega^2
========

\frac{GM}{\alpha^2 R^3}
]

---

# 四、与牛顿一致性

要满足：

[
\frac{GM}{\alpha^2 R^3}
=======================

\frac{GM}{R^3}
]

唯一可能：

[
\alpha^2=1
]

因此：

[
\alpha=1
]

（舍去负值，因为 r 为长度）

---

# 五、结果

[
\boxed{\alpha=1}
]

于是：

[
r = R
]

空间螺旋半径等于轨道半径。

因此：

α 不再是自由参数
而是由一致性唯一固定。
