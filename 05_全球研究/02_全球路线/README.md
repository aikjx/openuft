首批代表性研究路线。目录均为中文，来源保留实际作者；入口核对不等于全文评审、实验验证或全球完整覆盖。

| 编号 | 路线 | 研究对象 |
|---|---|---|
| G01 | [规范场与大统一](01_规范场与大统一/README.md) | 研究电弱与强相互作用的统一结构；与包括引力在内的全部相互作用统一分开讨论。 |
| G02 | [弦论与超弦](02_弦论与超弦/README.md) | 以弦论的自由度与相互作用为研究入口；不能把使用高维几何的本地候选直接视作弦论。 |
| G03 | [圈量子引力](03_圈量子引力/README.md) | 研究背景无关、非微扰的量子几何与广义相对论量子化。 |
| G04 | [渐近安全引力](04_渐近安全引力/README.md) | 以量子场论的紫外完备性和重整化群为研究入口。 |
| G05 | [因果集](05_因果集/README.md) | 以局部有限偏序集表达离散时空与因果关系。 |
| G06 | [因果动力学三角剖分](06_因果动力学三角剖分/README.md) | 通过格点正则化和尺度极限研究非微扰量子引力。 |
| G07 | [非交换几何](07_非交换几何/README.md) | 研究非交换几何框架下引力与含中微子混合的标准模型。 |
| G08 | [全息对偶](08_全息对偶/README.md) | 从大N超共形场论与超引力的对应关系进入全息研究。 |
| G09 | [熵引力与时空涌现](09_熵引力与时空涌现/README.md) | 收录以全息与空间涌现假设讨论引力起源的提案。 |
