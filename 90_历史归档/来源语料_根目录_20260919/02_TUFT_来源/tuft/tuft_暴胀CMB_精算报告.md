## 二、数值证据（可直接复现）

```
I = ∫_{0.05}^{0.45} Omega(1-Omega)/(1-2Omega) dOmega  = 0.224653        -> N = 0.2247*kappa
kappa(N=60)   = 267.1 ;  kappa(n_s=0.9649) = 474.4     -> 互斥 (差 1.78 倍)

eps(0.05) = 179.501/kappa ; eta(0.05) = -42.105/kappa
kappa=1 时: n_s(0) = -1160.2 ; r(0) = 16*eps*1.5 = 4308.0

观测锚: Planck2018 n_s = 0.9649 +/- 0.0042 ; BICEP/Keck r_0.05 < 0.036
```

**最关键的三条**：

1. **滚动方向反了**（P2.1/P6.2）：从 Ω=0.05 出发 V′>0，场向 **Ω=0** 滚，永远到不了 Ω=0.5；
   原文的"滚向极大值"与其自身方程相反，且场在 t=0.338 处越界崩溃。
2. **两个"✅ 吻合"互斥**（P2.6）：N 与 (1−n_s) 只通过 κ 耦合，其**乘积与 κ 无关**：
   模型给 3.741、观测要求 2.106（差 1.78 倍）⇒ 不存在任何 κ 使两者同时成立。
3. **势能形状与稳定性全错**（P1.1/P1.3/P6.3）：V 是凹函数（极大在 0.5）、Ω_DE 非驻点、

## 四、结论：本册"宇宙学全链条闭环"与"三个核心可证伪预言"均不成立

1. **势能层**：Ω(1−Ω) 非双势阱、Ω_DE 非极小、Ω∉[0,1] 时无下界（H²<0）；
2. **动力学层**：滚动方向与自身方程相反，暴胀在起点 ε=179.5 即失效，场越界崩溃；
3. **预言层**：N≈60（实为 0.22）与 n_s≈0.965（实为 −1160）**均不成立且互斥**；
4. **增强层**：F_T 量纲非法（L²），数值 = 1+1e-103（增强不存在），而所需 3.6~18.2；代码硬编码 1.5；
5. **手性层**：以"EW 手性破缺"作暴胀期手性来源，能标差 12 个数量级；Π_T 无推导；
6. **代码层**：按原文粘贴 SyntaxError；修好后抛 math domain error；"预期输出"四条全部不符；
7. **对比层**：把 ΛCDM 写成含 n_s/r 的动力学预言（概念错误）；0.003 实为本模型自值。

> **唯一原理上可判决的预言**是 Π_T≠0（CMB TB/EB）与"暗物质非粒子"，
> 但二者在本册均**无任何定量计算**，故当前不可检验。
> 与前三册判定一致：TUFT 的新增部分（挠率增强、手性、暗能量基底）**未被计算支撑**；
> 可用的部分全部是标准暴胀公式的复用。

(3) Π_T 的模式方程；(4) 至少一个与标准暴胀有别的定量预言（如 TB/EB 谱幅度）。
