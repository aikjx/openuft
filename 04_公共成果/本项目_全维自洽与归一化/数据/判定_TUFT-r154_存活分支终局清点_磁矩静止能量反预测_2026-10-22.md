### 3.1 内容清点：救回来的分支还剩什么

| 条目 | 标签 | 依据 |

| r = ħ/(2mc) | 已知 | 约化康普顿半波长 |

| h(螺距) = c/f = πλ̄_C | 已知重排 | 由上两条直接相除 |

（★ 禁为凑结论而硬编码「非已知项=0」—— 本卷如实记为 1，只是它不可用。）

### 3.2 ★电子磁矩：差整整一个 g=2，且与读法无关

- 旋磁比口径：μ = (e/2m)·L，L = ħ/2 ⇒ **μ = μ_B/2 = 4.637005e-24 J/T**
- 实测：**μ_e = 9.284765e-24 J/T**（μ_e/μ_B = 1.00115965）
- 偏离：**-50.0579%**；缺失因子 **2.00231931**，即 **g = 2**。
- **该结果与读法无关**：坐标读法与快度读法下 L 都是 ħ/2 ⇒ 换读法救不了它。

### 3.3 ★内部不一致：同一个模型有两个磁矩

- 环电流口径：μ = e·f_坐标·πr² = **2.677176e-24 J/T**（偏离 -71.1659%）
- 旋磁比口径：μ = **4.637005e-24 J/T**（偏离 -50.0579%）
- 两者之比 = **1.73205081 = √3 = γ** ⇒ 在存活分支下**相差整整一个洛伦兹因子**。
- 坐标读法下两者一致（比值 1）⇒ 该不一致是**快度读法带来的新病**。
- 控制组 F3 证明：经典非相对论圆环下两算法严格一致 ⇒ **不是我算错**。

### 3.4 ★静止能量两难

- 沿用「静止能量来自螺旋运动」⇒ E = γ m₀ c² = √3 m₀ c²
- 路①不做重归一化：**0.885076144 MeV** vs 实测 **0.510998950 MeV**，偏离 **73.2051%**
- 路②引入裸质量 m₀ = m/√3 ⇒ **外部输入 +1**（且 √3 仍是刚性普适常数）

### 3.5 防过度指控：角动量不构成判别

坐标读法 L = m·c·r = ħ/2；快度读法 L = γm·(c/γ)·r = ħ/2。**两者都等于 ħ/2**
⇒ 本卷**不**把角动量计入不利证据。这是本卷对靶最有利的一条，诚实登记为 INFO。
