# 地月数据实验协议（必须做，当前未执行实际观测拟合）

## 数据来源及原始格式

- JPL DE440/DE441：地球与月球标准引力参数；来源于轨道/星历拟合，不是独立无需模型的质量测量。
- GFZ ICGEM：地球重力场系数（如 EGM2008、GOCE 结合模型）。下载后确认球谐规范化、参考半径与潮汐系统。
- ESA GOCE：重力梯度与轨道信息；需要把姿态、框架和测量精度统一，并剔除非引力加速度。
- NASA PDS GRAIL：月球高阶重力球谐及可能的协方差；需要考虑月球的 mascon 与非球形。
- 激光测距/精密轨道：需要参考框架、地球自转、潮汐、第三体、辐射压、大气阻力、时钟效应和完整协方差。

## 独立检验要点

1. 使用**同一**密度分层与场模型求解牛顿/GR 基准；显式记录预先取值与自由参数。
2. 球谐至少包含多阶非球形，不能把一项 `(R/r)^2` 当作完整地球形状校正。
3. 把质量参数 μ、低阶引力场、卫星初始状态、太阳辐射压力等作为联合干扰参数处理，不能直接把已有标准 μ 当作与新物理无关的外部真值。
4. 多高度且尽可能多个纬度经度求残差，建成统一时空参考系，使用协方差或保守误差界。
5. 将数据分成拟合集与留出验证集，在拟合集上估计或限制 λ、α，在留出集做事先固定的预测。
6. 对 Earth/Moon 不同球源约束相同 λ/α，若模型不能同时解释，应排除参数组合或指出必要的新物理结构及其独立先验。
7. 输出可复算的 χ²/自由度、参数协方差、系统误差预算、置信区间与数据产品版本号。

## 可复用 CLI

从具备 `height_m,residual_fraction,sigma_fraction` 的**已完成物理改正的**输入表：

```
python fit_observations.py --csv your_processed_residuals.csv --source-note "your full source and processing provenance" --output-json results/user_fit.json
```

可选 `--covariance-json covariance.json` (N×N) 与 `--lambda-km 124.6`；输入来源 **不经程序验证**。此工具不是轨道动力学、不是原始重力梯度计数据处理、不是实测自动证据。

## 不能宣称已经完成的内容

本包未自行下载/拟合真实卫星观测时间序列，未求全阶球谐背景协方差，也未发现真实第五力。程序仅为**独立复现候选模型、证伪和下一阶段数据接入**准备。
