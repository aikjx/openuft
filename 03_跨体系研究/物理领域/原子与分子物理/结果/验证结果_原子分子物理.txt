【AM1】原子物理概述与基本概念
----------------------------------------------------------------------

  原子物理研究的对象：
    1. 原子的结构（原子核+电子云）
    2. 原子的能级与光谱
    3. 原子与电磁场的相互作用
    4. 原子的碰撞与散射
    5. 多电子原子的电子结构

  原子物理的主要分支：

  分支                   研究内容                                          状态
  --------------------------------------------------------------------------------
  原子结构理论               玻尔模型、薛定谔方程、多电子原子                              经典领域
  原子光谱学                发射/吸收光谱、精细结构、超精细结构                            实验领域
  原子碰撞物理               弹性/非弹性散射、电离、激发                                活跃领域
  激光物理                 激光原理、激光冷却、光镊                                  应用前沿
  量子光学                 光子-原子相互作用、量子纠缠、腔QED                           前沿领域
  超冷原子物理               BEC、费米简并、人工规范场                                前沿领域
  原子钟与精密测量             铯钟、光钟、时间频率标准                                  应用领域
  等离子体物理               电离气体、等离子体振荡、聚变                                交叉领域

  原子物理的诺贝尔奖：
    1922: 玻尔原子结构理论（Bohr）
    1933: 原子理论的新形式（薛定谔, 狄拉克）
    1945: 泡利不相容原理（Pauli）
    1955: 兰姆位移与电子磁矩（Lamb, Kusch）
    1964: 量子电动力学（Tomonaga, Schwinger, Feynman）
    1981: 激光光谱学（Bloembergen, Schawlow）
    1997: 激光冷却与俘获原子（Chu, Cohen-Tannoudji, Phillips）
    2001: 玻色-爱因斯坦凝聚（Cornell, Wieman, Ketterle）
    2005: 光学频率梳（Hänsch, Hall）
    2012: 量子系统的测量与操控（Haroche, Wineland）
    2018: 光镊与啁啾脉冲放大（Ashkin, Mourou, Strickland）

  螺旋几何化解释：

  1. 原子的螺旋几何化
     - 电子 = 光速螺旋粒子（内部螺旋运动）
     - 原子核 = 质子和中子的螺旋束缚态
     - 电子云 = 螺旋电子的概率分布
     - 原子轨道 = 螺旋电子的驻波模式

  2. 能级的螺旋几何化
     - 能级 = 螺旋电子的允许能量状态
     - 量子数 = 螺旋运动的拓扑量子数
     - 跃迁 = 螺旋电子在不同能级间的转换
     - 光谱 = 螺旋电子跃迁发出的光子

  3. 相互作用的螺旋几何化
     - 库仑力 = 螺旋电荷的静电相互作用
     - 自旋-轨道耦合 = 螺旋自旋与轨道运动的耦合
     - 精细结构 = 相对论效应和自旋-轨道耦合
     - 超精细结构 = 电子与原子核自旋的耦合

【AM2】氢原子与玻尔模型
----------------------------------------------------------------------

  玻尔模型（1913年）：

  基本假设：
    1. 电子在特定轨道上绕核运动，不辐射能量（定态假设）
    2. 角动量量子化：L = nħ, n = 1, 2, 3, ...
    3. 电子在定态间跃迁时吸收/发射光子：hν = E_m - E_n
    4. 对应原理：大量子数时量子理论趋近经典理论

  玻尔模型的主要结果：

  物理量             公式                                       n=1值                           备注
  ----------------------------------------------------------------------------------------------------
  轨道半径            r_n = n² a₀ / Z                          r₁ = 0.5292 Å                  a₀是玻尔半径, Z是原子序数
  轨道速度            v_n = α c Z / n                          v₁ = 2.188e+06 m/s = 0.0073c   α是精细结构常数
  轨道能量            E_n = -13.6 Z²/n² eV                     E₁ = -13.6 eV                  基态能量, 电离能13.6eV
  角动量             L_n = nħ                                 L₁ = ħ = 1.055e-34 J·s         量子化条件
  轨道频率            f_n = m e⁴ Z² / (4 ε₀² h³ n³)            f₁ = 6.580e+15 Hz              经典轨道频率
  里德伯公式           1/λ = R∞ Z²(1/n₁² - 1/n₂²)               R∞ = 689499.89 cm⁻¹            氢原子光谱

  线系           n₁    n₂              光谱区域         代表谱线
  ----------------------------------------------------------------------
  莱曼系          1     2,3,4,...       紫外           121.6 nm (Lyman-α)

  实验值：656.28 nm，相对误差：84.0886%

  玻尔模型的局限性：
    1. 无法解释多电子原子的光谱
    2. 无法解释精细结构（需要相对论和自旋）
    3. 无法解释塞曼效应（需要自旋）
    4. 无法解释谱线强度
    5. 角动量量子化不正确（实际L=√(l(l+1))ħ, l=0,...,n-1）

  螺旋几何化解释：

  1. 玻尔模型的螺旋几何化
     - 电子轨道 = 螺旋电子的圆周运动投影
     - 角动量量子化 = 螺旋运动的拓扑量子化
     - 定态 = 螺旋电子的稳定驻波模式
     - 跃迁 = 螺旋模式的拓扑相变

  2. 能级的螺旋几何化
     - E_n = -13.6/n² eV = 螺旋电子的束缚能
     - 主量子数n = 螺旋运动的径向量子数
     - 电离能 = 螺旋电子脱离束缚所需的能量

  3. 光谱的螺旋几何化
     - 光子 = 螺旋电子跃迁时释放的螺旋电磁波
     - 频率 = 螺旋模式的频率差
     - 里德伯公式 = 螺旋驻波条件的直接结果

【AM3】量子力学中的氢原子
----------------------------------------------------------------------

  薛定谔方程（氢原子）：

  哈密顿量：
    H = -ħ²/(2m) ∇² - e²/(4πε₀ r)

  定态薛定谔方程：
    H ψ(r,θ,φ) = E ψ(r,θ,φ)

  分离变量：ψ(r,θ,φ) = R(r) Y(θ,φ)
    - 径向方程：决定主量子数n和径向量子数
    - 角向方程：球谐函数Y_l^m(θ,φ)

  量子数：

  量子数                  取值                        决定                   物理意义
  -------------------------------------------------------------------------------------
  主量子数 n               1, 2, 3, ...              能量主要部分               电子壳层(K,L,M,...)
  角量子数 l               0, 1, ..., n-1            轨道角动量                轨道形状(s,p,d,f,...)
  磁量子数 m_l             -l, ..., 0, ..., +l       角动量z分量               轨道取向
  自旋量子数 s              1/2 (电子)                  自旋角动量                内禀角动量
  自旋磁量子数 m_s           +1/2, -1/2                自旋z分量                自旋向上/向下

  氢原子波函数（前几个）：

  态        n    l    m        波函数                                                     能量
  -----------------------------------------------------------------------------------------------
  1s       1    0    0        ψ₁₀₀ = (1/√π a₀³) e^{-r/a₀}                             -13.6 eV
  2s       2    0    0        ψ₂₀₀ = (1/(4√2π a₀³))(2-r/a₀)e^{-r/(2a₀)}               -3.4 eV
  2p_z     2    1    0        ψ₂₁₀ = (1/(4√2π a₀³))(r/a₀)e^{-r/(2a₀)} cosθ            -3.4 eV
  2p_x     2    1    ±1       ψ₂₁₁ ∝ (r/a₀)e^{-r/(2a₀)} sinθ e^{±iφ}                  -3.4 eV
  3s       3    0    0        ψ₃₀₀ ∝ (27-18r/a₀+2r²/a₀²)e^{-r/(3a₀)}                  -1.51 eV
  3p       3    1    0,±1     ψ₃₁ₘ ∝ (6r/a₀-r²/a₀²)e^{-r/(3a₀)} Y₁^m                  -1.51 eV
  3d       3    2    0,±1,±2  ψ₃₂ₘ ∝ (r²/a₀²)e^{-r/(3a₀)} Y₂^m                        -1.51 eV

  电子壳层与容纳电子数：

  壳层       n     亚壳层             轨道数        最大电子数        元素
  ---------------------------------------------------------------------------
  K        1     1s(2)           1          2            H-He

  P        6     6s(2), 6p(6), 6d(10), 6f(14), 6g(18), 6h(22) 36         72           Cs-Rn

  氢原子的概率分布：

  径向概率密度：P(r) = r² |R_nl(r)|²
    - 1s: 最概然半径 r = a₀ (玻尔半径)
    - 2s: 有一个节点，最概然半径 r ≈ 5.24 a₀
    - 2p: 最概然半径 r = 4 a₀
    - 3d: 最概然半径 r = 9 a₀

  角向概率密度：|Y_l^m(θ,φ)|²
    - s轨道(l=0): 球对称
    - p轨道(l=1): 哑铃形，三个取向(p_x,p_y,p_z)
    - d轨道(l=2): 四叶形/哑铃形，五个取向
    - f轨道(l=3): 更复杂形状，七个取向

  螺旋几何化解释：

  1. 波函数的螺旋几何化
     - ψ(r,θ,φ) = 螺旋电子的概率振幅
     - 球谐函数Y_l^m = 螺旋运动的角向模式
     - 径向波函数R_nl = 螺旋运动的径向模式
     - 节点 = 螺旋驻波的波节

  2. 量子数的螺旋几何化
     - 主量子数n = 螺旋运动的径向量子数
     - 角量子数l = 螺旋运动的角向量子数
     - 磁量子数m = 螺旋运动的取向量子数
     - 自旋s = 螺旋运动的内禀旋转量子数

  3. 电子云的螺旋几何化
     - |ψ|² = 螺旋电子出现的概率密度
     - 轨道形状 = 螺旋电子的最概然运动区域
     - 电子壳层 = 螺旋电子的能量分层

【AM4】精细结构与超精细结构
----------------------------------------------------------------------

  精细结构（Fine Structure）：

  成因：相对论效应 + 自旋-轨道耦合

  1. 动能的相对论修正：
     经典动能：T = p²/(2m)
     相对论动能：T = √(p²c² + m²c⁴) - mc² ≈ p²/(2m) - p⁴/(8m³c²)
     修正项：ΔE_rel = -p⁴/(8m³c²)

  2. 自旋-轨道耦合：
     电子自旋磁矩与轨道运动产生的磁场相互作用
     H_so = (1/(2m²c²)) (1/r) (dV/dr) L·S
     对于库仑势：H_so = (e²/(8πε₀ m² c² r³)) L·S

  3. Darwin项（s轨道的相对论修正）：
     H_Darwin = (π ħ² e²)/(2m² c² ε₀) δ³(r)
     只对l=0的s轨道有贡献

  精细结构能级公式（Sommerfeld, 1916）：
    E_nj = -13.6 eV / n² [1 + α²/n² (n/(j+1/2) - 3/4)]
    其中 j = l ± 1/2 是总角动量量子数

  氢原子精细结构能级（n=2）：

  态            n    l    j      E (eV)       精细修正 (eV)          简并度
  ---------------------------------------------------------------------------
  2s₁/₂        2    0    1/2    -3.4000      -4.53e-05          2
  2p₁/₂        2    1    1/2    -3.4000      -4.53e-05          2
  2p₃/₂        2    1    3/2    -3.4000      -1.13e-05          4

  兰姆位移（Lamb Shift, 1947）：
    2s₁/₂ 和 2p₁/₂ 能级在Dirac理论中简并
    但实验发现它们之间有微小能量差：ΔE ≈ 1057 MHz
    这是量子电动力学（QED）的辐射修正导致的
    兰姆位移 = 真空涨落对电子轨道的扰动
    1955年诺贝尔物理学奖（Lamb, Kusch）

  超精细结构（Hyperfine Structure）：

  成因：电子总角动量J与原子核自旋I的耦合

  哈密顿量：
    H_hfs = A I·J （磁偶极相互作用，主导项）
    + B [3(I·J)²/(2I(2I-1)J(2J-1)) - I·J/2] （电四极相互作用）

  总角动量：F = I + J, F = |I-J|, ..., I+J
  能级分裂：ΔE_F = (A/2)[F(F+1) - I(I+1) - J(J+1)]

  氢原子基态超精细结构：
    电子：J = 1/2, 质子：I = 1/2
    F = 0 (单态, 反平行) 和 F = 1 (三重态, 平行)
    能量差：ΔE = h × 1420.405751786 MHz
    对应波长：λ = 21.106 cm（21厘米线）
    这是射电天文学中最重要的谱线之一
    用于测量银河系中性氢分布

  21厘米线计算：
    频率：ν = 1420.405752 MHz
    波长：λ = c/ν = 21.1061 cm
    能量：ΔE = hν = 5.8743 μeV
    温度：T = ΔE/k_B = 68.1687 mK

  塞曼效应（Zeeman Effect）：

  外磁场中原子能级的分裂：
    H_Z = -μ·B = (e/(2m))(L + 2S)·B = μ_B (L_z + 2S_z) B/ħ

  正常塞曼效应（自旋为0或总自旋S=0）：
    ΔE = m_l μ_B B
    谱线分裂为三条（σ+, π, σ-）

  反常塞曼效应（自旋不为0）：
    ΔE = g_J m_J μ_B B
    其中g_J是朗德g因子：g_J = 1 + [J(J+1)+S(S+1)-L(L+1)]/[2J(J+1)]
    谱线分裂为多条

  螺旋几何化解释：

  1. 精细结构的螺旋几何化
     - 相对论修正 = 螺旋运动的相对论效应
     - 自旋-轨道耦合 = 螺旋自旋与轨道螺旋的耦合
     - Darwin项 = 螺旋运动的zitterbewegung（颤振）
     - 兰姆位移 = 螺旋电子与真空螺旋涨落的相互作用

  2. 超精细结构的螺旋几何化
     - 核自旋 = 原子核内螺旋运动的总角动量
     - 电子总角动量 = 电子螺旋运动的总角动量
     - 超精细耦合 = 两个螺旋系统的角动量耦合
     - 21厘米线 = 螺旋自旋翻转发出的螺旋电磁波

  3. 塞曼效应的螺旋几何化
     - 外磁场 = 外部螺旋电磁场
     - 能级分裂 = 螺旋取向与外场的相互作用能
     - 朗德g因子 = 螺旋自旋与轨道的有效磁矩比

【AM5】多电子原子与元素周期表
----------------------------------------------------------------------

  多电子原子的哈密顿量：

  H = Σ_i [-ħ²/(2m) ∇_i² - Ze²/(4πε₀ r_i)] + Σ_{i<j} e²/(4πε₀ r_ij)

  第一项：电子的动能 + 核吸引势
  第二项：电子-电子相互作用（库仑排斥）

  由于电子-电子相互作用，多电子原子无法精确求解
  需要使用近似方法：
    1. 中心力场近似（平均场近似）
    2. 哈特里-福克方法（Hartree-Fock）
    3. 密度泛函理论（DFT）
    4. 组态相互作用（CI）

  中心力场近似：
    每个电子在原子核和其他电子的平均势场中运动
    有效势：V_eff(r) = -Ze²/(4πε₀ r) + V_screening(r)
    屏蔽效应：内层电子屏蔽核电荷，有效核电荷 Z_eff < Z

  电子排布规则：

  规则                   内容                                                 结果
  ------------------------------------------------------------------------------------------
  泡利不相容原理              每个量子态最多容纳一个电子（考虑自旋则两个）                             决定电子壳层容量
  能量最低原理               电子优先占据能量最低的轨道                                      决定基态电子排布
  洪特规则                 简并轨道上电子优先分占不同轨道且自旋平行                               决定开壳层排布
  构造原理                 电子按1s,2s,2p,3s,3p,4s,3d,...顺序填充                    决定周期表结构

  轨道填充顺序（构造原理）：
    1s → 2s → 2p → 3s → 3p → 4s → 3d → 4p →
    5s → 4d → 5p → 6s → 4f → 5d → 6p → 7s → 5f → 6d → 7p

  n+0.7l规则：轨道能量按n+0.7l排序
    1s(1.0) < 2s(2.0) < 2p(2.7) < 3s(3.0) < 3p(3.7) < 4s(4.0) < 3d(4.4) < ...

  元素周期律：

  1. 原子半径：
     - 同周期：从左到右逐渐减小（核电荷增加，电子层不变）
     - 同族：从上到下逐渐增大（电子层增加）

  2. 电离能：
     - 同周期：从左到右总体增大（原子半径减小，电子更难失去）
     - 同族：从上到下逐渐减小（原子半径增大，电子更容易失去）
     - 特例：IIA > IIIA（ns²全满稳定），VA > VIA（np³半满稳定）

  3. 电子亲和能：
     - 同周期：从左到右总体增大（更容易获得电子）
     - 卤素最大，稀有气体最小（甚至为正）

  4. 电负性：
     - 同周期：从左到右增大
     - 同族：从上到下减小
     - 氟最大（4.0），铯最小（0.79）

  螺旋几何化解释：

  1. 多电子原子的螺旋几何化
     - 每个电子 = 独立的光速螺旋粒子
     - 电子-电子相互作用 = 螺旋之间的库仑排斥
     - 屏蔽效应 = 内层螺旋对外层螺旋的遮挡
     - 平均场 = 所有螺旋的平均势场

  2. 元素周期表的螺旋几何化
     - 周期 = 螺旋电子的主壳层
     - 族 = 螺旋电子的价电子构型
     - s区 = 螺旋电子填充s轨道
     - p区 = 螺旋电子填充p轨道
     - d区 = 螺旋电子填充d轨道（过渡金属）
     - f区 = 螺旋电子填充f轨道（镧系/锕系）

  3. 周期律的螺旋几何化
     - 原子半径 = 螺旋电子云的空间范围
     - 电离能 = 螺旋电子脱离束缚所需能量
     - 电负性 = 螺旋电子吸引其他螺旋的能力
     - 化学性质 = 价层螺旋的相互作用模式

【AM6】分子物理与化学键
----------------------------------------------------------------------

  化学键的类型：

  键型           机制                                  例子                        强度
  -----------------------------------------------------------------------------------------------
  离子键          电子转移，正负离子静电吸引                       NaCl, KBr, MgO            强 (~400-4000 kJ/mol)
  共价键          电子共享，原子轨道重叠                         H₂, O₂, CH₄, DNA          强 (~150-1100 kJ/mol)
  金属键          自由电子气与金属离子的吸引                       Fe, Cu, Al, 合金            中等 (~100-800 kJ/mol)
  氢键           H与电负性原子(N,O,F)的偶极吸引                 H₂O, DNA, 蛋白质             弱 (~10-40 kJ/mol)
  范德华力         瞬时偶极-诱导偶极相互作用                       稀有气体, 有机分子                很弱 (~1-10 kJ/mol)

  共价键理论：

  1. 价键理论（VB理论, Heitler-London, 1927）：
     - 原子轨道重叠形成化学键
     - 电子配对：自旋相反的两个电子占据重叠区域
     - σ键：头碰头重叠（s-s, s-p, p-p）
     - π键：肩并肩重叠（p-p）
     - δ键：面对面重叠（d-d）

  2. 分子轨道理论（MO理论, Mulliken, Hund, 1928）：
     - 原子轨道线性组合（LCAO）形成分子轨道
     - 成键轨道：能量降低，电子云在两核之间
     - 反键轨道：能量升高，电子云在两核外侧
     - 非键轨道：能量不变
     - 键级 = (成键电子数 - 反键电子数)/2

  氢分子离子H₂⁺（最简单的分子）：
    两个质子 + 一个电子
    键长：R_e = 1.06 Å
    解离能：D_e = 2.79 eV = 269 kJ/mol
    振动频率：ν = 2000 cm⁻¹

  氢分子H₂：
    两个质子 + 两个电子
    电子组态：(σ1s)²
    键级：1
    键长：R_e = 0.74 Å
    解离能：D_e = 4.52 eV = 436 kJ/mol
    振动频率：ν = 4401 cm⁻¹

  常见双原子分子的性质：

  分子       电子组态                      键级     键长(Å)      解离能(kJ/mol)        磁性
  -------------------------------------------------------------------------------------
  H₂       (σ1s)²                    1      0.74       436                抗磁
  He₂      (σ1s)²(σ*1s)²             0      —          —                  不存在
  Li₂      [He₂](σ2s)²               1      2.67       105                抗磁
  N₂       [Be₂](π2p)⁴(σ2p)²         3      1.10       945                抗磁

  NO       [O₂] (11价电子)              2.5    1.15       631                顺磁

  分子光谱：

  1. 转动光谱（远红外/微波）：
     能量：E_J = J(J+1) ħ²/(2I), I = μR²
     选择定则：ΔJ = ±1
     谱线等间距：ΔE = 2B(J+1), B = ħ/(4πI)

  2. 振动光谱（红外）：
     简谐振子：E_v = (v+1/2) ħω, ω = √(k/μ)
     选择定则：Δv = ±1
     非简谐修正：E_v = (v+1/2) ħω - (v+1/2)² ħω x_e

  3. 电子光谱（可见光/紫外）：
     电子能级跃迁，伴随振动和转动跃迁
     形成谱带（振动精细结构）和谱线（转动精细结构）
     弗兰克-康登原理：电子跃迁时核位置不变

  螺旋几何化解释：

  1. 化学键的螺旋几何化
     - 共价键 = 两个螺旋电子的轨道重叠
     - σ键 = 螺旋沿键轴方向的头碰头重叠
     - π键 = 螺旋垂直键轴方向的肩并肩重叠
     - 离子键 = 螺旋电子转移后的静电吸引
     - 金属键 = 螺旋电子在金属离子晶格中的自由运动

  2. 分子轨道的螺旋几何化
     - 成键轨道 = 两个螺旋同相叠加（ constructive interference）
     - 反键轨道 = 两个螺旋反相叠加（destructive interference）
     - 键级 = 螺旋成键与反键的净效果
     - 分子光谱 = 螺旋模式的能级跃迁

  3. 分子振动转动的螺旋几何化
     - 振动 = 螺旋原子核在平衡位置附近的振荡
     - 转动 = 螺旋分子整体的旋转
     - 振动-转动耦合 = 螺旋运动的内部耦合

【AM7】原子钟与精密测量
----------------------------------------------------------------------

  原子钟的基本原理：

  利用原子能级跃迁的频率作为时间基准
  原子跃迁频率极其稳定，不受环境影响（理想情况下）

  基本组成：
    1. 原子源（铯原子束、激光冷却原子等）
    2. 微波/光学谐振腔（产生激励电磁场）
    3. 探测器（检测原子跃迁）
    4. 反馈系统（锁定振荡器频率到原子跃迁频率）

  原子钟的发展历程：

  年份       类型                 发明者/机构                    精度              意义
  ------------------------------------------------------------------------------------------
  1949     氨分子钟               Harold Lyons (NIST)       ~10^-8          第一个原子钟
  1955     铯原子束钟              Louis Essen (NPL)         ~10^-10         第一个铯钟，定义秒的基础

  2010s    离子光钟               NIST, MPQ                 ~10^-19         单个囚禁离子，目前最高精度
  2020s    核钟（概念）             —                         ~10^-21 (预测)    利用原子核跃迁，理论上更稳定

  频率：ν = 9,192,631,770 Hz（定义值）

    1秒 = 9192631770 个周期（定义）

  原子钟的应用：

  1. 全球定位系统（GPS）：
     - 每颗GPS卫星携带4个原子钟（铯钟+铷钟）
     - 时间精度~10^-12秒，定位精度~米级
     - 相对论修正：卫星钟比地面钟快~38微秒/天

  2. 通信网络同步：

     - 高频交易需要微秒级时间戳

【AM8】激光物理与量子光学
----------------------------------------------------------------------

  激光的基本原理：

  LASER = Light Amplification by Stimulated Emission of Radiation
  受激辐射光放大

  爱因斯坦辐射理论（1917）：
    1. 自发辐射：激发态原子自发跃迁到低能态，发出光子
       速率：A₂₁ N₂
    2. 受激吸收：基态原子吸收光子跃迁到激发态
       速率：B₁₂ ρ(ν) N₁
    3. 受激辐射：激发态原子在光子激励下跃迁到低能态
       速率：B₂₁ ρ(ν) N₂

  爱因斯坦关系：A₂₁/B₂₁ = 8πhν³/c³, B₁₂ = B₂₁

  激光产生的条件：

  1. 粒子数反转：N₂ > N₁（激发态原子数多于基态）
     - 需要泵浦能量将原子激发到高能级
     - 三能级系统或四能级系统

  2. 光学谐振腔：
     - 两个反射镜组成Fabry-Pérot腔
     - 提供光反馈，使光子在腔内往返多次
     - 选频作用：只有特定频率的光才能形成驻波

  3. 增益介质：
     - 能够实现粒子数反转的物质
     - 固体（红宝石、Nd:YAG）、气体（He-Ne、CO₂）、
       液体（染料）、半导体（激光二极管）、光纤等

  常见激光器类型：

  类型                 增益介质                 波长                 泵浦                 年份     发明者
  ----------------------------------------------------------------------------------------------------
  红宝石激光器             Cr³⁺:Al₂O₃           694.3 nm           闪光灯                1960   Maiman
  He-Ne激光器           He-Ne气体              632.8 nm           气体放电               1961   Javan
  CO₂激光器             CO₂气体                10.6 μm            气体放电               1964   Patel

  自由电子激光器            相对论电子束               可调(微波-X射线)         电子加速器              1977   Madey

  激光的特性：

  1. 单色性：谱线宽度极窄（Δλ/λ ~ 10^-10 或更窄）
  2. 方向性：发散角极小（接近衍射极限）
  3. 相干性：时间相干和空间相干都很好
  4. 高亮度：能量在空间和频率上高度集中
  5. 偏振性：通常是线偏振或圆偏振

  压缩态             一个正交分量的噪声低于散粒噪声极限                             1985         Slusher

  激光冷却与超冷原子：

  基本原理：光子动量传递给原子，产生阻尼力

  1. 多普勒冷却（1975, Hänsch/Schawlow, Wineland/Dehmelt）：
     - 三对相向传播的激光（光学粘胶）
     - 原子吸收迎面而来的光子，自发辐射各向同性
     - 净效果：阻尼力，温度降到多普勒极限
     - 多普勒极限：T_D = ħΓ/(2k_B) ~ 100 μK（碱金属）

  2. 亚多普勒冷却（Sisyphus冷却, 1988, Cohen-Tannoudji）：
     - 利用偏振梯度和光移
     - 温度降到反冲极限以下
     - 典型温度：~100 nK - 1 μK

  3. 磁光阱（MOT, 1987, Raab）：
     - 四极磁场 + 光学粘胶
     - 同时实现冷却和囚禁
     - 可囚禁~10^10个原子，温度~100 μK

  4. 蒸发冷却：
     - 选择性去除高能原子
     - 剩余原子重新热平衡到更低温度
     - 可达到nK温度，实现BEC

  螺旋几何化解释：

  1. 激光的螺旋几何化
     - 受激辐射 = 入射螺旋电磁波激发原子螺旋跃迁
     - 粒子数反转 = 螺旋电子在高能级的聚集
     - 光学谐振腔 = 螺旋电磁波的驻波模式
     - 激光 = 相干螺旋电磁波的放大

  2. 量子光学的螺旋几何化
     - 光子 = 螺旋电磁波的量子
     - 相干态 = 螺旋电磁波的最经典量子态
     - 压缩态 = 螺旋正交分量的噪声压缩
     - 纠缠 = 螺旋光子的量子关联

  3. 激光冷却的螺旋几何化
     - 光子动量 = 螺旋电磁波的动量
     - 阻尼力 = 螺旋光子与螺旋原子的动量交换
     - 多普勒效应 = 螺旋频率的移动
     - 超冷原子 = 螺旋运动被极度减缓的原子

【AM9】原子分子物理的螺旋几何化统一解释
----------------------------------------------------------------------

  核心命题：原子分子物理的所有现象都可以用螺旋运动的几何来统一解释

  1. 原子结构的螺旋几何化：

    基本假设：
      - 电子是内部以光速c做螺旋运动的粒子
      - 螺旋半径R = ħ/(m_e c) = 康普顿波长/(2π)
      - 螺旋频率ω = m_e c²/ħ = 康普顿频率
      - 原子核是质子/中子螺旋的束缚态

    推论：
      a) 电子轨道 = 螺旋电子在库仑势中的运动轨迹
      b) 波函数 = 螺旋电子的概率振幅
