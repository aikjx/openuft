## 1. 突破 B1：4D/3D Frenet 桥接定理 ✅

### 1.1 定理

设类时世界线 `x^μ(τ)`（`τ` 为固有时），四维速度 `u^μ = dx^μ/dτ`，满足

$$u^\mu u_\mu = c^2$$

定义 4D 第一 Frenet 曲率（沿时空弧长 `σ = cτ`）：

$$\kappa_1\equiv\left|\frac{dT^\mu}{d\sigma}\right|=\frac{|a^\mu|}{c^2},\qquad a^\mu=\frac{du^\mu}{d\tau}$$

对**纯横向加速**（`v·a = 0`，如圆周运动、回旋运动），3D 空间轨迹曲率记为 `κ_3`，则

$$\boxed{\ \kappa_1=\kappa_3\,\gamma^2\frac{v^2}{c^2}\ },\qquad \gamma=\frac{1}{\sqrt{1-v^2/c^2}}$$

### 1.2 符号验证（脚本 1.1–1.3）

| 检验 | 结果 |
|---|---|
| `u^μu_μ = c²` | ✅ `u·u = γ²(c²−v²) → c²`（代入 `γ=(1−v²/c²)^{-1/2}`） |
| `a^μa_μ = γ⁴a_⊥²` | ✅ `|a4| = γ²ωv` |
| `κ_1/κ_3 = γ²v²/c²` | ✅ `κ_3=ω/v`、`κ_1=γ²ωv/c²`，比值恒等 |

### 1.3 数值验证

| 场景 | v | κ_3 | κ_1 | 桥接公式 vs 直接计算 |
|---|---|---|---|---|
| 电子回旋（B=1T） | 10⁷ m/s | 17578.4 m⁻¹ | 19.5804 m⁻¹ | 残差 < 10⁻¹² |
| 地球绕日圆轨道 | 29788.6 m/s | 6.68459×10⁻¹² m⁻¹ | 6.59980×10⁻²⁰ m⁻¹ | 与 `GM/(c²r²)` 残差 **0** |

> **关键比值**：电子回旋的 `κ_1/κ_3 = 1.114×10⁻³`。也就是说，**同一个物理弯曲，在两层的数值可以差 3 个数量级以上**。v2 混用两层时之所以能"看起来对"，是因为在球对称静场中把 `κ_1` 与 `κ_3` 都当成了同一个 `κ`。

### 1.4 为什么这条桥接是"钥匙"

v2 的矛盾链条是：

$$\text{定理4 } \beta_1=\frac{\kappa^2+\tau^2}{K_0}\ \Rightarrow\ \kappa=\sqrt{K_0\beta_1}\ \Rightarrow\ \kappa\propto e^{GM/(c^2r)}\ \Rightarrow\ \text{扰动}\propto\frac{1}{r}$$

$$\text{定理5 + 牛顿}\ \Rightarrow\ \kappa=\frac{GM}{c^2r^2}\propto\frac{1}{r^2}$$

**差一个 r**。桥接定理说明：这两个 `κ` **本来就不是同一个量**（一个是 4D 的 `κ_1`，一个是 3D 的 `κ_3`），差正好是 `γ²v²/c²` 因子。矛盾不是"算错了"，而是**符号混用**。

## 3. 突破 B3：Möbius framing → 自旋统计定理 ✅

### 3.1 核心构造

闭合世界线的管状邻域由一个**法向框架化（framing）**给出。设中心线的法向场为 `N(s)`，则可定义**总扭转数**

$$Tw=\frac{1}{2\pi}\oint d\theta(s)$$

其中 `θ(s)` 是 `N` 在垂直于切向的平面内相对参考方向的转角。

**闭合条件决定整数性**：

| 类型 | 闭合条件 | 后果 | 自旋 |
|---|---|---|---|
| 可定向管 | `N(2π)=+N(0)`（法向回到自身） | `Tw ∈ ℤ` | 整数（玻色） |
| **Möbius 管** | `N(2π)=−N(0)`（法向**翻转**） | `Tw ∈ ℤ+1/2` | **半整数（费米）** |

### 3.2 解析验证（脚本 3.1–3.4）

取中心线为半径 `R` 的圆，Möbius 法向场

$$N(u)=\cos\frac{u}{2}\,\mathbf e_r+\sin\frac{u}{2}\,\mathbf e_z$$

在垂直平面 `(e_r, e_z)` 中，`N` 相对 `e_r` 的转角 `θ = u/2`，故

$$Tw=\frac{1}{2\pi}\int_0^{2\pi}\frac{1}{2}\,du=\frac{1}{2}$$

✅ 解析结果恰为 **1/2**；普通 framing（`N=cos(nu)e_r+sin(nu)e_z`）给出 `Tw = n ∈ ℤ`。

### 3.3 数值验证（脚本 3.7）

200000 步离散积分：`Tw = 0.5000000000` ✅

### 3.4 这解决了什么

**v2 的 H4 死结**：v2 声称 `Lk = cos θ`，于是费米子（θ=45°）给 `Lk = 0.7071 ∉ ℤ`，违反 Călugăreanu–White。文献中的候选修复（"绕 N 圈补偿"）也无法解决，因为 `N·cos45°` 永远不是整数。

**v4 的解法**：`1/2` **不来自 `cos45°`**，而来自**定向性**。两个条件是独立的：

| 条件 | 决定 | 来源 |
|---|---|---|
| `θ = 45°`（κ=τ） | `Tw` 的连续几何值 | 内禀螺旋形状 |
| 法向翻转（Möbius） | `Tw` 的**半整数性** | 管的拓扑（不可定向） |

⇒ **费米子 = 内禀螺旋为 Möbius 型的孤子**；`θ=45°` 只是一个形状参数，不再要求它是整数。

> ⭐ 这实际上是**自旋–统计定理的拓扑实现**：标架沿闭合世界线的 holonomy 落在 `SO(3)` 的 `2πn`（恒等）或 `2π(n+1/2)`（在 `SU(2)` 双覆盖下为 `−1`）两个不同类中。

### 3.5 诚实边界

🟠 `Tw` 与"自旋角动量 `ℏ/2`"的**定量**对应（为什么正好是 `ℏ/2` 而不是别的半整数倍）仍未给出；本轮闭合的是**整数/半整数的区分机制**，不是自旋的绝对数值。

## 4. 突破 B4：对易子量纲修复（O23 候选）🟠

### 4.1 为什么 v3 的对易子必然错

v3 写 `[K̂,T̂] = i(Ω/c)ℏ`。量纲：

$$[K][T]=\mathrm m^{-2},\qquad \left[\frac{\Omega}{c}\hbar\right]=\mathrm{kg\cdot m}$$

**二者相差 `kg·m³`。** 更本质地说：

> **曲率与挠率在数学上不可能构成正则共轭对**——因为共轭对要求 `[K][T]=[ℏ]=J·s`，而两个 `m⁻¹` 的乘积只能是 `m⁻²`。

### 4.2 本轮候选构造

引入 `κ` 的共轭动量 `Π_κ ≡ ℏℓ_P²·τ`，由标准正则关系 `[κ̂, Π̂_κ] = iℏ` 得

$$\boxed{\ [\hat\kappa,\hat\tau]=\frac{i\hbar}{\hbar\ell_P^2}=\frac{i}{\ell_P^2}\ }$$

| 检验 | 结果 |
|---|---|
| `[κ][τ]` vs `[1/ℓ_P²]` | ✅ 两侧同为 `m⁻²` |
| `[ℏℓ_P²τ]` | ✅ `kg·m³/s`（= J·s·m），是 κ 的合法共轭动量量纲 |
| 数值强度 | `1/ℓ_P² = 3.82807×10⁶⁹ m⁻²` |
| 不确定度 | `Δκ·Δτ ≥ 1/(2ℓ_P²) = 1.914×10⁶⁹ m⁻²` |

### 4.3 可观测性判决（重要）

取电子 `κ ≈ 1.83×10¹² m⁻¹`，即便测到 `10⁻¹³` 的相对精度（`Δκ ≈ 0.18 m⁻¹`）：

$$\Delta\tau\ \ge\ \frac{1.914\times10^{69}}{2\times0.18}\approx1.06\times10^{70}\ \mathrm{m^{-1}}$$

—— 比 `τ` 本身大 **57 个数量级**。

> **物理判决**：该量子化效应**在任何粒子物理尺度都绝对不可观测**，只在普朗克尺度显现。这既是它的自洽性证明，也是它的可证伪性困境——🟠 仍属候选（`Π_κ` 的构造是 ansatz，未由拉格朗日量推出）。

| **L3 内禀层** | 相位螺旋（**速率 c**） | `κ_int, τ_int, ω` | **质量、自旋、电荷** | 粒子内部 |

$$\text{L2 内部：}\ \kappa_1=\kappa_3\frac{\gamma^2v^2}{c^2}\quad\text{(B1)}$$

### 5.2 公理 I 的重新定位 —— 解决 O20（类光性）✅

$$u^\mu u_\mu=c^2\quad(\text{L2，四维速度，正常 SR})\qquad
v_{3D}<c\quad(\text{固有时良定义})$$

⇒ 类光性矛盾**消除**（脚本 5.2 ✅），且 L3 的 `ω=c√(κ_int²+τ_int²)` 与 L2 的标准 SR 各居其位。

## 6. 否定性精算：EC 挠率不可能承载电磁力 ✅

v2/v3 都把"电磁 = 挠率"当作核心美学。本轮做一次量的判决：

在爱因斯坦–嘉当理论中，挠率由自旋密度**代数地**决定：

$$T^{\lambda}_{~\mu\nu}=\frac{8\pi G}{c^4}S^{\lambda}_{~\mu\nu}$$

取电子自旋密度 `S ~ ℏ/λ_C³`（`λ_C` 为康普顿波长）：

| 量 | 数值 |
|---|---|
| `S` | `1831.37 kg/(m·s)` |
| `T_EC` | **`3.80312×10⁻⁴⁰ m⁻¹`** |
| `κ_int`（电子内禀曲率） | `1.83113×10¹² m⁻¹` |
| 差距 | **52 个数量级** |

再加上力程结构：

| | 力程 | 形式 |
|---|---|---|
| EC 挠率–自旋耦合 | → 0（接触相互作用） | `δ` 函数型 |
| 库仑力 | 长程 | `1/r²` |

⇒ **结论：时空挠率（EC 意义）给不出与曲率同量级、且长程的电磁力。"电磁 = 时空挠率"在 EC 框架下不成立。**

**v4 的替代方案**：电荷改由 **L3 内禀挠率 `τ_int`** 承载（相位螺旋的手性）。这样：
- 保住了"挠率 = 手性 → 电荷符号"的直觉 ✅
- 场与质量场同样长程（同为内禀属性的通量） ✅
- 避免了 EC 挠率 52 个数量级的量级困难 ✅
