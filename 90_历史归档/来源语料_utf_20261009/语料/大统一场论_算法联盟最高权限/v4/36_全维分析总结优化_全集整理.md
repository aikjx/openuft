## 一、公理层（不可再分的起点）

体系只有 **3 条公理**，其余皆为推导：

1. **A1 · 瞬时光速公理**：本源螺旋世界线以光速运行，`|v| = ωR = c`（17 号证明）。
   - 螺旋参数式：`v(t) = (−ρω sin, ρω cos, bω)`，`R = √(ρ²+b²)`，`|v| = ωR = c`。
   - 推论：**空间不是静态容器，而是动态螺旋运动**（这是"空间动态"断言的几何来源）。
2. **A2 · 质量标度公理**：粒子以自身康普顿投影尺度为标尺，`R = ℏ/(mc)`。
   - 这是 ℏ 进入几何的**唯一入口**（详见第七章）。
3. **A3 · 电磁扭转公理**：`α = τ/κ`（挠率/曲率比 = 精细结构常数）。
   - α 为测量锚（CODATA 精确值 1/137.035999084），NG-X-2 边界。

主恒等式（A1+A2 推导）：
```
κ² + τ² = (ω/c)² = (mc/ℏ)²          (*)
```
这是连接"几何量 κ,τ"与"物理量 m,c,ℏ"的总闸门。

## 二、几何结构层（本源螺旋）

对单条螺旋，Frenet 直接求导（17 号）：
```
κ = ρ/(ρ²+b²) = ρ/R²
τ = b/(ρ²+b²) = b/R²
```
由 A3 取 `b = ρα`，代入 R = √(ρ²+b²) 得：

**归一化母方程（19 号，无量纲）**
```
ρ = R/√(1+α²),  b = ρα
κ̃ = κR = 1/√(1+α²)
τ̃ = τR = α/√(1+α²)
κ̃² + τ̃² = 1
```

→ **这是全体系的核心恒等式**：一条单位螺旋，其弯曲与扭转的归一化分量平方和恒为 1，且**只依赖 α，与质量完全无关**。

## 七、关键澄清：ℏ 为什么没写在 (κ²+τ²) 里？

这是 35 号 `G = c³/(ℏ(κ²+τ²))` 最易被质疑之处。**ℏ 从未消失，它通过标度公理 A2 先进入 R，再经几何返回。** 完整链路：

### 7.1 ℏ 的进入与返回

```
A2:  R = ℏ/(mc)                  ← ℏ 在此进入
定义: κ = ρ/R², τ = b/R²
  ⇒  κ²+τ² = (ρ²+b²)/R⁴ = R²/R⁴ = 1/R²
  ⇒  κ²+τ² = 1/R² = m²c²/ℏ²      ← ℏ 以 1/ℏ² 形式返回
```

代入 G 式：
```
G = c³ / [ℏ·(κ²+τ²)]
  = c³ / [ℏ · m²c²/ℏ²]
  = c³ · ℏ² / (ℏ · m²c²)
  = ℏc / m²
```
这正是普朗克质量定义 `m_P=√(ℏc/G)` 的变形。**ℏ 在分母显式出现一次，又被 (κ²+τ²) 里的 1/ℏ² 抵消一次，净留 ℏc/m²。**

### 7.2 为什么公式不写成 `G=ℏc/m²`？

这是**结构/标尺分离**的设计选择，刻意保留 (κ²+τ²)：

| 写法 | 角色 | 用途 |
|:---|:---|:---|
| `G = c³/[ℏ(κ²+τ²)]` | κ,τ 是**纯几何结构量**（无量纲母方程投影） | 显式展示 G 由螺旋"弯+扭"总幅决定 |
| `G = ℏc/m²` | m 是**标度**（含 ℏ 的吸收态） | 显式展示 G 由质量标度决定 |

把 ℏ 显式留在分母、c³ 留在分子，是为了让**标度律透明**：`κ ∝ mc/ℏ`（定理 3），即 κ 随质量放大、随 ℏ 缩小。若把 ℏ 全吸进 m，就掩盖了"几何形状如何随标度缩放"这一核心机制。

### 7.3 一句话总结

`(κ²+τ²)` 看着"不含 ℏ"，是因为 ℏ 已**先以 `R=ℏ/(mc)` 进入 κ、τ 的定义，再以 `κ²+τ²=1/R²` 反带 `1/ℏ²` 回来**，与显式分母的 ℏ 抵消。ℏ 在 G 还原里承担的是**尺度标尺**角色，不是结构角色——这正是该体系"结构层全几何闭合、量级由测量锚定"的写法。
