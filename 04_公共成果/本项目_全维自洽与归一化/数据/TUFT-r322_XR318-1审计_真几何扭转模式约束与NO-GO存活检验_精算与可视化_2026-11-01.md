# r322 · X-R318-1 审计 · 真几何扭转的模式约束与 r318 反例的存活检验（NO-GO 未被约束复活）

条目总数 22（主 8：PASS 6 / FAIL 0 / INFO 2）；控制组 4/4；守卫 10/10。

## [P1] INFO · X-R318-1 重述与 r318 的薄弱点
**X-R318-1（r318 判定册 §遗留）**：r318 证明「自由通量 + 0/1 扭转」下 N=3 可达（乃至 N 自由），但其 P2 **默认了任意 0/1 模式都是合法扭转**——这未证。Schur（r305 Thm N）只保证单扭转在每个不可约表示上 k_R∈{0,1}，**不保证 2^6 个 0/1 模式都能由一个真实轨道群元实现**。本卷施加可证的**结构约束**，检验 r318 的反例是否因此失效。

## [P2] PASS · 结构约束定理：真扭转的 k 模式受限（约束集 = 16 个）
**定理（结构约束）**：中心扭转（保持 SM 规范群不破）下，同一中心荷的表示其 k 必相等。SM 手征内容中：`u^c` 与 `d^c` **同为 3bar**（中心荷相同）⇒ `k_{u^c}=k_{d^c}`（索引 1=2）；`e^c` 与 `ν^c` **同为单态**（中心荷相同）⇒ `k_{e^c}=k_{ν^c}`（索引 4=5）。故合法模式集受 `g[1]=g[2]` 与 `g[4]=g[5]` 约束，自由位为 g0,g1,g3,g4 ⇒ **约束集大小 = 2^4 = 16**（全 2^6=64 个中）。来源：r307 Thm N（Schur）+ r309 Thm U（`k₂≡k₃` 结构性）。

## [P3] PASS · 约束集内 N=3 可解面 = 4 个（g0=g3=1 且满足结构约束）
对约束集 **16** 个模式逐个检验 A·t=3·𝟙：可解数 = **4**，且恰为 `{g: g[0]=1 且 g[3]=1} ∩ 约束`（即 `{g0=1,g3=1,g1=g2,g4=g5}`，共 4 个）。另复核 r318 的全 64 个可解面 = **16** 个（`{g0=1,g3=1}`）。⇒ **结构约束把可解面由 16 缩到 4，但不为零**——r318 的反例**没有被约束完全消灭**。

## [P4] PASS · ★r318 的显式构造 g=(1,0,0,1,0,0) 在约束下存活
g0=[1, 0, 0, 1, 0, 0]：满足结构约束（g1=g2=0, g4=g5=0）=True；Y=3，X=(3−Y·g_i)/d_i=[0, 1, 1, 0, 3, 3]，t=[0, 1, 1, 0, 3, 3, 3]。机检 **A·t=[3, 3, 3, 3, 3, 3]=3·𝟙**，判据判可解=True（rank=6）。⇒ 该**非平凡、非均匀**的 0/1 扭转既是合法结构模式，又给出 3 代 ⇒ **r318 反例存活**，并非靠违规模式。

## [P5] PASS · N 自由在约束下仍成立（N=1..12，且 g_for_N 自动满足约束）
对每个 N∈[1,12]，g_i=(d_i∤N ? 1 : 0)。因 **d_{u^c}=d_{d^c}=3、d_{e^c}=d_{ν^c}=1**，该 g **自动满足 g[1]=g[2] 与 g[4]=g[5]**（约束）。逐 N 机检 **12/12 通过、其中满足约束 12/12** ⇒ **N 自由性不是靠违规模式取得的**，在真扭转结构约束下依旧成立。

## [P6] PASS · 结论：结构约束不复活 NO-GO（X-R318-1 部分闭合）
r318 的 `NO-GO-DOWNGRADED-TO-FREE`（三代非结构性禁止、N 自由）在**真几何扭转的结构约束**下**依然成立**：约束集 16 个中仍有 4 个给出 N=3，且 r318 的显式构造存活，N=1..12 仍全可及。⇒ **X-R318-1 部分闭合**：施加可证的 `k_{u^c}=k_{d^c}`、`k_{e^c}=k_{ν^c}` 结构约束**不足以复活 NO-GO**。真正能复活 NO-GO 的只剩**更强的、模型依赖的**全群元约束（见 P8 / X-R322-1）。

## [P7] PASS · 判据集 R1–R10（R10 = 真扭转约束能否复活 NO-GO）
在 r306 的 R1–R8、r318 的 R9 之上新增 **R10「真几何扭转的结构约束能否复活 NO-GO」**。结论：R10 = **否**（P3/P5 机检），故对本卷命题「约束不复活 NO-GO」而言，**判据集 10/10 满足**（这是对**框架能否救回 NO-GO** 的否定，而非对三代的肯定）。★注意与 r318 一致：框架仍**不预言** 3（3 是 Y 的拓扑输入），本卷只证「约束不改变这一点」。

## [P8] INFO · 诚实边界：只做了可证的中心扭转结构约束
本卷施加的约束 `k_{u^c}=k_{d^c}`、`k_{e^c}=k_{ν^c}` 是**中心扭转**下由「同中心荷 ⇒ 同 k」可严格证明的。**未施加**的是**更强的、模型依赖的**全群元约束（例如某个具体 Z_N 作用在 6 个表示上的完整相位表、以及 Q 与 L 与体场的相对约束——这些需指定具体规范嵌入，本卷不假设）。因此本卷结论是**下界式**的：「即使加可证结构约束，NO-GO 也不复活」；若未来给出一个**具体模型**并证明其约束把 4 个可解模式也排除，才可能复活 NO-GO——那是 X-R322-1 的任务。
