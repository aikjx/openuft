# 10_D_求导_derivation/ 方法①：求导（Derivation）

> **核心命题**：统一场论不是"几条方程写在同一页"，而是"单一变分原理的求导"。
> 所有方程——Einstein 场方程、Yang-Mills 方程、Higgs 质量矩阵、大统一力方程——都是某个作用量的 Euler-Lagrange 方程。
> 求导就是"从公理到方程"的桥梁。
